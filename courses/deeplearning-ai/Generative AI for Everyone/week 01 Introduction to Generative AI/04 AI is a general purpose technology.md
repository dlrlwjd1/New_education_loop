# AI is a general purpose technology

## 개요
- AI는 자동차나 전자레인지처럼 한 가지 용도에 특화된 기술이 아니라, 전기나 인터넷처럼 다양한 작업에 쓰이는 범용 기술(general-purpose technology)이다.
- LLM의 주요 작업은 크게 쓰기(writing), 읽기(reading), 채팅(chatting)으로 나누어 생각할 수 있다.
- LLM 활용은 웹 인터페이스 기반 사용과 소프트웨어 기반 애플리케이션으로 구분할 수 있다.

## 내용

### 범용 기술로서의 AI
생성형 AI가 무엇에 유용한지 답하기 어려운 이유는 AI가 **범용 기술(general-purpose technology)** 이기 때문이다.

자동차는 이동에, 전자레인지는 음식을 데우는 데 주로 쓰인다. 반면 AI는 한 가지 목적에만 쓰이지 않고 여러 작업에 적용된다. 전기나 인터넷도 마찬가지다. "전기는 무엇에 좋은가?"라는 질문이 답하기 어려운 이유는 전기가 너무 많은 곳에서 사용되기 때문이다.

지도 학습(supervised learning)도 스팸 필터링, 광고, 음성 인식 등 여러 작업에 쓰였고, 생성형 AI 역시 다양한 작업에 활용될 수 있다.

### LLM 작업을 분류하는 세 가지 틀
LLM이 수행할 수 있는 작업은 크게 세 가지로 정리할 수 있다.

1. **쓰기(writing)**: 비교적 짧은 프롬프트를 바탕으로 더 긴 텍스트를 생성
2. **읽기(reading)**: 긴 텍스트를 읽고 짧은 결과나 판단을 생성
3. **채팅(chatting)**: 사용자와 대화하며 특정 목적을 수행

이 틀은 LLM이 수행할 수 있는 많은 작업을 체계적으로 생각하는 데 도움이 된다.

### 쓰기 작업
생성형 AI는 텍스트를 생성하므로 글쓰기 작업에 자연스럽게 유용하다.

예시:
- 제품 이름 브레인스토밍
- 글 초안 작성
- 질문에 대한 답변 생성
- 회사 내부 정보를 바탕으로 직원 질문에 답변

회사의 주차 정책처럼 특정 조직 내부 정보가 필요한 질문에 답하려면, 일반 웹 LLM보다 회사 내부 데이터에 접근할 수 있는 소프트웨어 기반 애플리케이션이 더 적합하다.

### 읽기 작업
읽기 작업은 비교적 긴 정보를 입력으로 주고, 짧은 출력이나 판단을 생성하게 하는 작업이다.

예를 들어 전자상거래 회사가 많은 고객 이메일을 받는다면, LLM이 이메일을 읽고 다음과 같이 판단할 수 있다.

- 이 이메일이 불만(complaint)인지 아닌지
- 어떤 부서로 라우팅해야 하는지

지도 학습으로도 이런 작업을 만들 수 있지만, 생성형 AI를 사용하면 이런 읽기 작업을 더 빠르고 저렴하게 구현할 수 있는 경우가 많다.

### 채팅 작업
ChatGPT, Bard, Bing Chat은 범용 챗봇(general-purpose chatbot)이다. 생성형 AI와 LLM은 이런 범용 챗봇뿐 아니라 특정 목적을 가진 챗봇도 가능하게 한다.

예시:
- 온라인 주문을 받는 음식점 챗봇
- 고객 지원 챗봇
- 회사 내부 정책 질의응답 챗봇

사용자가 "치즈버거를 배달로 주문하고 싶다"고 말하면, 챗봇은 주문을 확인하고 처리할 수 있다.

### 웹 인터페이스 기반 사용과 소프트웨어 기반 애플리케이션
LLM 기반 활용은 두 가지로 나눌 수 있다.

**웹 인터페이스 기반 사용(web interface-based application)** 은 사용자가 ChatGPT, Bard, Bing Chat 같은 웹사이트에 직접 프롬프트를 입력하고 결과를 받는 방식이다. 브레인스토밍이나 글쓰기처럼 개인이 바로 사용할 수 있는 작업에 적합하다.

**소프트웨어 기반 LLM 애플리케이션(LLM-based software application)** 은 LLM이 더 큰 소프트웨어 자동화 안에 통합되는 방식이다. 예를 들어 고객 이메일 라우팅은 사람이 이메일을 하나씩 복사해서 웹 인터페이스에 붙여넣는 방식으로 운영하기 어렵다. 이런 경우 회사의 업무 흐름 안에 LLM을 포함한 소프트웨어를 구축하는 것이 적합하다.

## 예시

### LLM 작업 분류
| 분류 | 입력 | 출력 | 예시 |
|------|------|------|------|
| 쓰기 | 짧은 프롬프트 | 긴 텍스트 | 제품 이름, 보도자료, 초안 작성 |
| 읽기 | 긴 텍스트 | 짧은 판단/요약 | 고객 이메일 분류, 문서 요약 |
| 채팅 | 대화 | 대화형 응답/행동 | 주문 챗봇, 고객 지원 챗봇 |

### 웹 인터페이스와 소프트웨어 애플리케이션 비교
| 유형 | 적합한 상황 | 예시 |
|------|------|------|
| 웹 인터페이스 기반 사용 | 개인이 직접 프롬프트를 입력해 결과를 얻는 경우 | 브레인스토밍, 글쓰기 |
| 소프트웨어 기반 LLM 애플리케이션 | 업무 흐름에 자동화가 필요한 경우 | 이메일 라우팅, 내부 정책 Q&A, 주문 처리 챗봇 |

## 요약
- AI는 전기나 인터넷처럼 여러 작업에 적용되는 범용 기술이다.
- LLM 작업은 쓰기, 읽기, 채팅이라는 세 가지 틀로 정리할 수 있다.
- 웹 인터페이스 기반 사용은 개인이 바로 시작하기 쉽고, 소프트웨어 기반 LLM 애플리케이션은 조직의 자동화와 업무 흐름에 적합하다.
- 두 방식 모두 개인과 기업에 중요한 활용 형태가 될 수 있다.
