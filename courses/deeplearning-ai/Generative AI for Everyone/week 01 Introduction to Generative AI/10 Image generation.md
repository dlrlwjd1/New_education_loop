# Image generation

## 개요
- 생성형 AI는 텍스트뿐 아니라 이미지를 생성할 수 있으며, 여러 양식(modality)을 다루는 모델은 멀티모달 모델(multimodal model)이라고 부른다.
- 오늘날 이미지 생성은 주로 확산 모델(diffusion model)을 통해 이루어진다.
- 확산 모델의 핵심에도 지도 학습(supervised learning)이 있으며, 노이즈가 있는 이미지를 조금 더 깨끗한 이미지로 바꾸는 법을 학습한다.

## 내용

### 텍스트 생성과 이미지 생성
Week 1의 대부분은 텍스트 생성에 초점을 맞췄다. 텍스트 생성은 많은 사용자가 실제로 활용하고 있고, 생성형 AI 도구 중 가장 큰 영향을 만들고 있다.

하지만 생성형 AI의 중요한 분야 중 하나는 이미지 생성이다. 프롬프트만으로 존재하지 않는 사람의 사진, 미래적인 장면, 로봇 이미지 같은 것을 만들 수 있다.

텍스트와 이미지를 모두 다룰 수 있는 모델도 등장하고 있으며, 이런 모델은 여러 양식(modality)을 다루기 때문에 **멀티모달 모델(multimodal model)** 이라고 부른다.

### 확산 모델이란 무엇인가
오늘날 이미지 생성은 대부분 **확산 모델(diffusion model)** 로 이루어진다. 확산 모델은 인터넷이나 다른 출처에서 수집한 매우 많은 이미지로부터 학습한다.

확산 모델의 핵심에는 지도 학습이 있다. 기본 아이디어는 다음과 같다.

1. 깨끗한 이미지를 가져온다.
2. 이미지에 점점 더 많은 노이즈를 추가한다.
3. 최종적으로 거의 순수한 노이즈 이미지가 되게 한다.
4. 모델은 노이즈가 있는 이미지를 입력으로 받아 조금 덜 노이즈가 있는 이미지를 출력하도록 학습한다.

예를 들어 사과 사진이 있다면, 여기에 점점 더 많은 노이즈를 추가해 여러 단계의 이미지를 만든다. 그런 다음 지도 학습 데이터셋을 만들어 "노이즈가 있는 이미지"를 입력 A로, "조금 더 깨끗한 이미지"를 출력 B로 학습시킨다.

### 이미지 생성 과정
학습이 끝난 뒤 새 이미지를 생성할 때는 순수한 노이즈 이미지에서 시작한다.

1. 모든 픽셀이 무작위로 선택된 이미지를 만든다.
2. 학습된 모델에 넣어 노이즈를 조금 제거한다.
3. 결과 이미지를 다시 모델에 넣어 노이즈를 더 제거한다.
4. 이 과정을 반복해 점점 더 선명한 이미지를 만든다.

강의에서는 설명을 위해 4단계로 노이즈를 제거하는 과정을 보여주지만, 실제 확산 모델에서는 약 100단계 정도가 더 일반적이라고 설명한다.

이 방식만 사용하면 이미지는 무작위로 생성된다. 사용자가 원하는 이미지를 만들려면 프롬프트를 함께 사용해야 한다.

### 텍스트 프롬프트로 이미지 제어하기
프롬프트를 사용하려면 학습 데이터에 이미지와 함께 텍스트 설명을 포함한다.

예를 들어 빨간 사과 이미지가 있고, 그 설명이 "red apple"이라면 학습 입력은 다음 두 가지가 된다.

- 노이즈가 있는 이미지
- 텍스트 프롬프트: red apple

모델은 이 두 입력을 보고 더 깨끗한 빨간 사과 이미지를 출력하도록 학습한다. 이렇게 많은 이미지와 캡션으로 학습하면, 나중에 "green banana" 같은 새로운 프롬프트를 입력했을 때 해당 프롬프트에 맞는 이미지를 만들 수 있다.

생성 시에는 순수한 노이즈 이미지와 "green banana"라는 프롬프트를 함께 입력한다. 모델은 노이즈를 조금씩 제거하면서 점점 더 녹색 바나나처럼 보이는 이미지를 만들어낸다.

### 지도 학습과 이미지 생성
이미지 생성은 마법처럼 보이지만, 핵심에는 다시 지도 학습이 있다. LLM이 다음 단어를 예측하도록 학습되는 것처럼, 확산 모델은 노이즈가 많은 이미지에서 조금 더 깨끗한 이미지를 예측하도록 학습된다.

즉 텍스트 생성과 이미지 생성은 겉으로는 매우 달라 보이지만, 둘 다 대규모 데이터와 지도 학습을 기반으로 한다.

## 예시

### 확산 모델 학습 과정
| 단계 | 입력 A | 출력 B |
|------|------|------|
| 1 | 약간 노이즈가 있는 사과 이미지 | 깨끗한 사과 이미지 |
| 2 | 더 노이즈가 많은 사과 이미지 | 약간 덜 노이즈가 있는 사과 이미지 |
| 3 | 순수 노이즈에 가까운 이미지 | 사과의 형태가 조금 보이는 이미지 |

### 프롬프트 기반 이미지 생성
| 입력 | 결과 |
|------|------|
| 순수 노이즈 + red apple | 빨간 사과 이미지 |
| 순수 노이즈 + green banana | 녹색 바나나 이미지 |
| 순수 노이즈 + futuristic scene | 미래적인 장면 이미지 |

## 요약
- 이미지 생성은 생성형 AI의 중요한 영역이며, 텍스트와 이미지를 함께 다루는 모델은 멀티모달 모델이라고 한다.
- 확산 모델은 이미지에 노이즈를 추가한 데이터를 이용해, 노이즈가 있는 이미지를 조금 더 깨끗하게 만드는 법을 학습한다.
- 이미지를 생성할 때는 순수한 노이즈에서 시작해 여러 단계에 걸쳐 노이즈를 제거한다.
- 텍스트 프롬프트를 함께 입력하면 사용자가 원하는 종류의 이미지를 생성하도록 제어할 수 있다.
