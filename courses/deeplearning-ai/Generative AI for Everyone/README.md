# Generative AI for Everyone

**Course URL:** https://learn.deeplearning.ai/courses/generative-ai-for-everyone
**제공:** DeepLearning.AI
**강사:** Andrew Ng

## 개요
비전공자·비즈니스 리더를 대상으로 생성형 AI(Generative AI)의 기초를 다루는 입문 과정입니다. 생성형 AI가 어떻게 동작하는지, 실생활과 업무에서 어떻게 활용하는지, 프로젝트를 어떻게 기획하는지, 비즈니스와 사회에 어떤 영향을 미치는지를 다룹니다. 코딩 실습은 없습니다.
