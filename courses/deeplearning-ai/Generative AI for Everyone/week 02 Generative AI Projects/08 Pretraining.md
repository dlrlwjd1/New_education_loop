# Pretraining

## 개요
- 많은 LLM은 이미 대형 기술 기업이나 연구팀이 사전학습(pretraining)한 모델이다.
- 자체 모델을 처음부터 사전학습하는 것은 매우 비싸고 오래 걸리므로, 대부분의 애플리케이션에서는 마지막 수단에 가깝다.
- 특정 도메인에 대한 매우 많은 데이터와 충분한 자원이 있는 경우에만 자체 사전학습을 고려할 수 있다.

## 내용

### 사전학습이란 무엇인가
많은 LLM은 사용자가 직접 학습시킨 것이 아니라, 어떤 회사나 연구팀이 미리 학습시켜둔 모델이다. 이를 **사전학습(pretraining)** 된 모델이라고 한다.

일반 목적 LLM은 보통 인터넷의 대규모 텍스트를 학습해 만들어진다. 이런 모델은 방대한 일반 지식을 갖고 있으며, 다양한 작업에 활용될 수 있다.

### 자체 사전학습은 언제 해야 하는가
자체 모델을 처음부터 사전학습할지 고민된다면, 기본 답은 "아마 하지 않는 것이 좋다"에 가깝다. 이유는 비용과 시간이 매우 크기 때문이다.

매우 큰 LLM을 사전학습하려면 다음이 필요할 수 있다.

- 수천만 달러 수준의 비용
- 전담 엔지니어링 팀
- 여러 달의 시간
- 매우 많은 데이터
- 대규모 컴퓨팅 인프라

따라서 특정 애플리케이션을 만들기 위해 처음부터 모델을 사전학습하는 것은 보통 마지막 수단이다.

### 오픈소스 모델의 가치
여러 팀이 많은 자원을 투입해 일반 목적 LLM을 사전학습하고, 이를 오픈소스로 공개하고 있다. 이는 AI 커뮤니티에 큰 기여다.

만약 충분한 자원과 역량이 있어 모델을 사전학습하고 오픈소스로 공개할 수 있다면, 이는 의미 있는 기여가 될 수 있다. 하지만 일반적인 애플리케이션 개발 관점에서는 이미 사전학습된 모델을 활용하는 것이 훨씬 현실적이다.

### 특수 도메인과 대규모 데이터가 있는 경우
자체 사전학습이 도움이 될 수 있는 경우는 고도로 특화된 도메인과 매우 많은 데이터가 있을 때다.

예를 들어 Bloomberg는 금융 서비스와 관련된 소프트웨어 및 미디어 기사를 제공하는 회사다. Bloomberg는 금융 텍스트에 대한 방대한 접근 권한을 바탕으로 금융 애플리케이션을 목적으로 한 자체 LLM인 BloombergGPT를 학습했다.

Bloomberg는 일반 인터넷 데이터 중심으로 학습된 범용 LLM과 비교했을 때, BloombergGPT가 금융 텍스트 처리에서 더 나은 성능을 보였다고 보고했다.

이 사례는 특정 도메인에 엄청난 데이터와 자원이 있을 때 자체 사전학습이 의미 있을 수 있음을 보여준다.

### 더 현실적인 접근: 기존 모델 + 파인튜닝
대부분의 실용적인 애플리케이션에서는 처음부터 모델을 사전학습하기보다, 다른 팀이 사전학습한 LLM에서 시작하는 것이 더 낫다.

현실적인 흐름은 다음과 같다.

1. 인터넷 데이터 등으로 사전학습된 범용 LLM을 선택한다.
2. 필요하다면 오픈소스 모델을 활용한다.
3. 자신의 데이터로 파인튜닝한다.
4. 특정 애플리케이션에 맞게 성능을 조정한다.

이 접근은 처음부터 모델을 사전학습하는 것보다 훨씬 경제적이며, 많은 경우 충분히 좋은 성능을 낼 수 있다.

### 모델 선택으로 이어지는 질문
사전학습된 모델과 오픈소스 모델이 많아지면서, 개발자는 여러 LLM 중 어떤 모델을 사용할지 선택해야 한다.

다음 강의에서는 어떤 크기의 LLM을 사용할지, 그리고 다양한 LLM 중에서 어떻게 선택할지 살펴본다.

## 예시

### 자체 사전학습과 기존 모델 활용 비교
| 접근 | 장점 | 단점 |
|------|------|------|
| 자체 사전학습 | 특정 도메인에 깊게 최적화 가능 | 매우 비싸고 오래 걸리며 대규모 팀과 데이터 필요 |
| 기존 사전학습 모델 사용 | 빠르고 경제적으로 시작 가능 | 특정 도메인에는 추가 조정이 필요할 수 있음 |
| 기존 모델 + 파인튜닝 | 경제성과 도메인 적응의 균형 | 파인튜닝 데이터와 평가 과정 필요 |

### 자체 사전학습을 고려할 만한 조건
| 조건 | 설명 |
|------|------|
| 특수 도메인 | 일반 LLM이 잘 처리하지 못하는 전문 영역 |
| 대규모 데이터 | 도메인에 특화된 방대한 텍스트 보유 |
| 충분한 자원 | 수개월의 시간, 전담 팀, 큰 예산, 컴퓨팅 인프라 |
| 명확한 성능 이점 | 범용 LLM보다 도메인 작업에서 확실한 개선 기대 |

## 요약
- 사전학습은 LLM을 대규모 데이터로 처음부터 학습시키는 과정이다.
- 자체 LLM 사전학습은 수천만 달러, 전담 팀, 많은 시간과 데이터가 필요한 매우 비싼 작업이다.
- BloombergGPT처럼 특수 도메인과 방대한 데이터가 있는 경우에는 자체 사전학습이 의미 있을 수 있다.
- 대부분의 애플리케이션에서는 이미 사전학습된 모델을 사용하고, 필요하면 자신의 데이터로 파인튜닝하는 것이 더 현실적이다.
