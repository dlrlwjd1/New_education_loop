# Reputation monitoring code

## 개요
- 이 두 번째 선택 활동에서는 앞서 본 감성 분류기를 확장해 기본적인 평판 모니터링 시스템을 만든다.
- 여러 식당 리뷰를 한 번에 긍정 또는 부정으로 분류하고, 긍정/부정 리뷰 개수를 집계한다.
- 코드를 자세히 이해하지 않아도 실행만으로 LLM을 활용한 비정형 텍스트 분석 흐름을 경험할 수 있다.

## 내용

### Activity 2의 목적
이 활동은 이전 활동에서 본 감성 분류(sentiment classifier)를 확장한다. 하나의 리뷰만 분류하는 것이 아니라, 여러 리뷰를 리스트로 만들고 각 리뷰를 LLM으로 분류한 뒤 긍정 리뷰와 부정 리뷰의 수를 계산한다.

실습에서는 네 개의 코드 셀을 순서대로 실행한다. 데스크톱에서는 각 셀을 클릭한 뒤 `Shift-Enter`를 누르고, 모바일에서는 재생 버튼을 눌러 실행할 수 있다.

### 코드 셀 1: 환경 설정
첫 번째 코드 셀은 이전 활동과 동일하게 프로그래밍 환경을 설정한다. 이 환경은 OpenAI에 프롬프트를 보내기 위해 필요하다.

코드 셀을 클릭하고 `Shift-Enter`를 누르면 실행된다.

### 코드 셀 2: 리뷰 목록 만들기
두 번째 코드 셀은 여러 개의 식당 리뷰를 리스트로 만든다.

예시 리뷰:
- "the mochi is excellent"
- "best soup dumplings I've ever eaten"
- 그 외 긍정 또는 부정 감성이 담긴 리뷰들

이 단계에서는 LLM에 보내기 전, 분석할 입력 데이터를 준비한다.

### 코드 셀 3: 각 리뷰 감성 분류
세 번째 코드 셀은 리뷰 목록의 각 리뷰를 긍정 또는 부정으로 분류한다. 코드가 여러 줄 있지만, 핵심은 프롬프트다.

프롬프트의 핵심 지시:

```text
Classify the following review as having either positive or negative sentiment.
Say your answer as a single word, either positive or negative.
```

소프트웨어는 이 프롬프트에 다섯 개 리뷰를 하나씩 넣고 LLM에 보낸다. 실행에는 몇 초가 걸릴 수 있다. 예시 결과는 다음과 같다.

```text
positive, positive, negative, positive, negative
```

이 결과는 다섯 개 리뷰 각각에 대응하는 감성 분류다.

### 코드 셀 4: 긍정/부정 개수 세기
네 번째 코드 셀은 분류 결과를 바탕으로 긍정 리뷰와 부정 리뷰의 수를 계산한다.

예를 들어 분류 결과가 `positive, positive, negative, positive, negative`라면 다음처럼 집계된다.

- 긍정 리뷰: 3개
- 부정 리뷰: 2개

이 방식은 리뷰가 5개가 아니라 100개여도 같은 구조로 확장할 수 있다. 각 리뷰를 분류하고, 전체 긍정/부정 수를 계산하면 기본적인 평판 모니터링 대시보드의 기초가 된다.

### 리뷰를 바꿔보기
실습에서는 리뷰 문장을 직접 바꿔보고 다시 실행해볼 수 있다. 예를 들어 부정 리뷰였던 문장을 "the pasta was amazing"처럼 긍정적인 리뷰로 바꾸면, 다시 실행했을 때 분류 결과와 집계가 바뀐다.

예시:
- 변경 전: 긍정 3개, 부정 2개
- 변경 후: 긍정 4개, 부정 1개

이처럼 입력 데이터가 바뀌면 LLM 분류 결과와 집계 결과도 함께 바뀐다.

## 예시

### 코드 셀 역할
| 코드 셀 | 역할 |
|------|------|
| 1 | OpenAI에 프롬프트를 보내기 위한 환경 설정 |
| 2 | 여러 식당 리뷰 목록 생성 |
| 3 | 각 리뷰를 긍정 또는 부정으로 분류 |
| 4 | 긍정 리뷰와 부정 리뷰 개수 계산 |

### 감성 분류 집계 예시
| 리뷰 수 | 분류 결과 | 집계 |
|------|------|------|
| 5개 | positive, positive, negative, positive, negative | 긍정 3개, 부정 2개 |
| 5개 | positive, positive, negative, positive, positive | 긍정 4개, 부정 1개 |

## 요약
- Activity 2는 여러 리뷰를 한 번에 분류해 기본적인 평판 모니터링 시스템을 만드는 실습이다.
- 핵심은 리뷰 목록을 만들고, 각 리뷰를 LLM 프롬프트로 긍정/부정 분류한 뒤, 결과를 집계하는 것이다.
- 코드를 완전히 이해하지 않아도 실행을 통해 LLM 기반 텍스트 분석 애플리케이션의 흐름을 경험할 수 있다.
- 리뷰 수가 많아져도 같은 방식으로 확장할 수 있다.
