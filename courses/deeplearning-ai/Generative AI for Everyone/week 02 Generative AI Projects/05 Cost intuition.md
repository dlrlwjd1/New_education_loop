# Cost intuition

## 개요
- LLM을 소프트웨어 애플리케이션에서 사용할 때의 비용은 많은 사람이 생각하는 것보다 저렴할 수 있다.
- LLM 비용은 보통 토큰(token) 단위로 계산되며, 토큰은 대략 단어 또는 단어의 일부에 해당한다.
- 간단한 계산으로 LLM 사용 비용의 규모를 추정하면 프로젝트 판단에 도움이 된다.

## 내용

### LLM API 비용의 기본 구조
개발자가 코드에서 LLM을 호출할 때는 보통 프롬프트 입력과 모델 출력의 길이에 따라 비용이 청구된다. 강의에서는 예시로 여러 LLM의 출력 토큰 비용을 비교한다.

예시:
- OpenAI GPT-3.5: 1,000 토큰당 0.2센트
- GPT-4: 1,000 토큰당 6센트
- Google PaLM 2, Amazon Titan Lite 등도 비교적 저렴한 옵션으로 언급됨

기술적으로는 입력 프롬프트 길이도 비용에 포함되지만, 출력 비용이 더 비싼 경우가 많기 때문에 강의에서는 직관을 위해 출력 토큰 비용에 주로 집중한다.

### 토큰이란 무엇인가
토큰(token)은 LLM이 텍스트를 처리하는 단위다. 대략 하나의 단어 또는 단어의 일부라고 생각할 수 있다.

예시:
- 흔한 단어는 하나의 토큰으로 처리될 수 있다.
- "Andrew" 같은 흔한 이름도 하나의 토큰일 수 있다.
- 덜 흔한 단어는 여러 조각으로 나뉠 수 있다.
- "translate"는 `tran`, `slate`처럼 두 토큰으로 나뉠 수 있다.
- "programming"은 `program`, `ming`처럼 두 토큰일 수 있다.
- "tonkotsu" 같은 덜 흔한 단어는 네 토큰으로 나뉠 수 있다.

대량의 텍스트를 평균하면 토큰 하나는 대략 3/4 단어에 해당한다. 따라서 300단어를 생성하면 약 400토큰 정도가 될 수 있다. 즉 토큰 수는 단어 수와 비슷하지만 조금 더 크며, 대략 단어 수보다 33% 많다고 볼 수 있다.

### 한 사람을 한 시간 동안 읽게 할 텍스트 비용 추정
LLM 애플리케이션이 팀원이 읽을 텍스트를 생성한다고 가정해보자.

일반적인 성인의 읽기 속도를 분당 250단어로 잡으면, 한 시간 동안 읽을 텍스트는 다음과 같다.

```text
60분 * 250단어 = 15,000단어
```

LLM에 입력하는 프롬프트 길이도 출력과 비슷하다고 거칠게 가정하면, 입력 15,000단어와 출력 15,000단어를 합쳐 총 30,000단어에 대한 비용을 생각할 수 있다.

토큰 하나가 약 3/4 단어라면 30,000단어는 약 40,000토큰에 해당한다.

```text
30,000단어 ≈ 40,000토큰
```

1,000토큰당 0.2센트라면 40,000토큰 비용은 다음과 같다.

```text
40 * 0.2센트 = 8센트
```

즉 이 가정에서는 한 사람이 한 시간 동안 읽을 만큼의 텍스트를 생성하고 입력하는 비용이 약 8센트다.

### 비용 해석
미국의 많은 지역에서 최저임금이 시간당 10~15달러 수준이라고 하면, 생산성을 높이는 데 한 시간당 8센트를 추가로 쓰는 것은 비교적 작은 비용일 수 있다.

물론 모든 경우에 저렴한 것은 아니다. 무료 제품을 백만 명이 사용하고, 사용자당 8센트가 들어가며, 그에 대응하는 수익이 없다면 비용은 커질 수 있다.

하지만 많은 애플리케이션에서 LLM 사용 비용은 사람들이 처음 생각하는 것보다 낮을 수 있다.

## 예시

### 단어와 토큰 관계
| 텍스트 | 토큰 예시 |
|------|------|
| Andrew | 1토큰 |
| translate | 2토큰 |
| programming | 2토큰 |
| tonkotsu | 4토큰 |
| 300단어 | 약 400토큰 |

### 비용 계산 예시
| 항목 | 값 |
|------|------|
| 읽기 속도 | 분당 250단어 |
| 1시간 읽을 분량 | 15,000단어 |
| 입력+출력 총량 가정 | 30,000단어 |
| 토큰 환산 | 약 40,000토큰 |
| 단가 | 1,000토큰당 0.2센트 |
| 총 비용 | 약 8센트 |

## 요약
- LLM 비용은 토큰 단위로 계산되며, 토큰은 대략 단어 또는 단어 일부다.
- 평균적으로 토큰 수는 단어 수보다 약 33% 많다고 볼 수 있다.
- 한 사람이 한 시간 동안 읽을 만큼의 텍스트를 생성하는 비용은 예시 단가에서 약 8센트로 추정된다.
- 대규모 무료 서비스에서는 비용이 커질 수 있지만, 많은 업무용 애플리케이션에서는 LLM 비용이 예상보다 낮을 수 있다.
