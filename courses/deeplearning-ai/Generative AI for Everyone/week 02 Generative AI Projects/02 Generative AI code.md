# Generative AI code

## 개요
- 이 강의는 선택 사항(optional)이며, 생성형 AI 코드를 직접 실행해보는 실습이다.
- 코드 셀을 실행해 OpenAI의 클라우드 호스팅 서비스에 프롬프트를 보내고 LLM 응답을 받는 흐름을 확인한다.
- 예제는 식당 리뷰의 감성을 긍정 또는 부정으로 분류하는 간단한 프롬프트 기반 애플리케이션이다.

## 내용

### 선택 실습의 목적
이 실습은 완전히 선택 사항이다. 완료하지 않아도 과정의 나머지 내용을 학습하는 데 문제가 없다. 다만 코드를 직접 실행해보면 생성형 AI 애플리케이션이 어떻게 프롬프트를 보내고 응답을 받는지 감을 잡을 수 있다.

실습 화면에는 영상 옆 또는 위에 코드 실행 영역이 있다. 데스크톱에서는 보통 영상 왼쪽에 코드 영역이 보이고, 모바일에서는 영상 위쪽에 보일 수 있다.

### 코드 셀 실행 방법
각 코드 셀을 실행하는 기본 방법은 다음과 같다.

1. 실행할 코드 셀을 클릭한다.
2. 키보드에서 `Shift-Enter`를 누른다.
3. 모바일에서는 재생 버튼을 눌러 같은 효과를 낼 수 있다.

코드 셀을 실행하면 셀 왼쪽의 숫자가 바뀌며 실행 순서를 보여준다. 같은 셀을 실수로 두 번 실행해도 문제가 생기지 않는다.

### 코드 셀 1: 환경 설정
첫 번째 코드 셀은 프로그래밍 환경을 설정한다. 이 환경은 코드에서 OpenAI의 클라우드 호스팅 서비스로 프롬프트를 보내기 위해 필요하다.

실습에서는 첫 번째 코드 셀을 클릭한 뒤 `Shift-Enter`를 눌러 실행한다. 실행 후 숫자가 `1`로 바뀌면 첫 번째로 실행된 코드 셀이라는 의미다.

### 코드 셀 2: 감성 분류 프롬프트 실행
두 번째 코드 셀은 식당 리뷰의 감성을 분류하는 프롬프트를 정의한다.

코드의 핵심 흐름은 세 단계다.

1. 프롬프트를 정의한다.
2. LLM에 프롬프트를 보내 응답을 받는다.
3. 응답을 출력한다.

예제 프롬프트는 리뷰를 긍정 또는 부정 감성으로 분류하도록 요청한다. 예를 들어 "the banana pudding was really tasty"라는 리뷰를 입력하면, LLM은 `positive sentiment`라고 응답할 수 있다.

### 프롬프트 바꿔보기
기본 예제를 실행한 뒤에는 프롬프트 안의 리뷰 문장을 바꿔볼 수 있다.

예를 들어 다음처럼 바꿔볼 수 있다.

- "the banana pudding was really tasty"
- "the banana cake was delicious"
- 다른 음식 리뷰 문장
- 긍정 또는 부정 감성이 드러나는 문장

리뷰 문장을 바꾸고 다시 코드 셀을 실행하면 LLM이 새로운 입력에 대해 감성을 분류한다. 셀을 여러 번 실행하면 실행 번호가 계속 증가한다.

### 다음 활동으로 이동
첫 번째 실습을 마친 뒤에는 내비게이션 바에서 Activity 2로 이동할 수 있다. Activity 2에서는 조금 더 복잡한 코드 예제를 다룬다.

## 예시

### 코드 실행 흐름
| 단계 | 작업 | 결과 |
|------|------|------|
| 1 | 코드 셀 1 실행 | OpenAI 서비스 호출을 위한 환경 설정 |
| 2 | 코드 셀 2 실행 | 프롬프트 정의, LLM 응답 요청, 결과 출력 |
| 3 | 리뷰 문장 수정 | 다른 입력에 대한 감성 분류 확인 |
| 4 | Activity 2 이동 | 더 복잡한 코드 예제로 진행 |

### 감성 분류 예시
| 리뷰 | 예상 출력 |
|------|------|
| the banana pudding was really tasty | positive sentiment |
| the banana cake was delicious | positive sentiment |

## 요약
- 이 optional exercise는 생성형 AI 코드를 직접 실행해보는 실습이다.
- 첫 번째 코드 셀은 환경을 설정하고, 두 번째 코드 셀은 감성 분류 프롬프트를 실행한다.
- 코드 흐름은 프롬프트 정의, LLM 응답 요청, 응답 출력의 세 단계로 구성된다.
- 프롬프트의 리뷰 문장을 바꿔보면 LLM이 다양한 입력을 어떻게 분류하는지 확인할 수 있다.
