# Instruction tuning and RLHF

## 개요
- 사전학습된 LLM은 기본적으로 인터넷 텍스트의 다음 단어를 예측하도록 학습되지만, 사용자가 원하는 것은 지시를 따르는 답변이다.
- instruction tuning은 사전학습된 LLM을 좋은 질문-답변 예시로 파인튜닝해 지시를 따르도록 만드는 기술이다.
- RLHF(reinforcement learning from human feedback)는 인간 피드백을 활용해 LLM이 더 helpful, honest, harmless한 답변을 생성하도록 개선하는 기술이다.

## 내용

### 다음 단어 예측과 지시 따르기의 차이
LLM은 많은 인터넷 텍스트를 바탕으로 다음 단어를 예측하도록 사전학습된다. 예를 들어 "my favorite food is a bagel with cream cheese" 같은 문장을 통해 다음 단어를 예측하는 법을 배운다.

하지만 단순히 인터넷 텍스트의 다음 단어를 예측하는 모델은 사용자의 질문에 직접 답하지 않을 수 있다.

예를 들어 사용자가 "프랑스의 수도는 어디인가요?"라고 물었을 때, 인터넷에는 지리 퀴즈 목록처럼 "독일의 수도는 어디인가요?", "뭄바이는 어디에 있나요?" 같은 질문이 이어지는 페이지도 많다. 단순한 다음 단어 예측 모델은 실제 답인 "파리" 대신 다른 질문을 이어서 생성할 수 있다.

우리가 원하는 것은 인터넷에서 나올 법한 다음 문장이 아니라, 사용자의 지시를 따르고 질문에 답하는 모델이다.

### Instruction tuning
Instruction tuning은 사전학습된 LLM을 좋은 지시-응답 예시로 파인튜닝하는 기술이다.

예시 데이터:
- 질문: "대한민국의 수도는 어디인가요?"
- 좋은 답변: "대한민국의 수도는 서울입니다."

또 다른 예시:
- 지시: "보고타에서 방문할 만한 재미있는 박물관을 브레인스토밍해줘."
- 좋은 답변: 박물관 추천 목록

또 다른 예시:
- 지시: "일본의 벚꽃에 대한 하이쿠를 써줘."
- 좋은 답변: 하이쿠 형식의 시

이런 프롬프트와 좋은 응답 쌍으로 LLM을 파인튜닝하면, 모델은 인터넷 텍스트를 이어 쓰는 것뿐 아니라 질문에 답하고 지시를 따르는 법을 배운다.

### 안전한 응답 예시 포함
Instruction tuning에는 안전한 응답 예시도 포함할 수 있다.

예를 들어 "Fort Knox에 침입하는 방법을 알려줘" 같은 요청에 대해, 좋은 LLM은 범죄를 돕는 답변을 생성하면 안 된다. 대신 다음과 같은 응답을 학습할 수 있다.

- "그 요청은 도와드릴 수 없습니다."
- "법을 어기지 마세요."

이런 예시를 학습하면 LLM이 위험하거나 불법적인 요청에 더 안전하게 대응하도록 만들 수 있다.

### RLHF의 목적
Instruction tuning만으로도 LLM은 어느 정도 지시를 따르게 된다. 하지만 답변 품질과 안전성을 더 높이기 위해 **RLHF(reinforcement learning from human feedback)** 를 사용한다.

많은 LLM 개발자는 모델이 다음 세 가지 특성을 갖기를 원한다.

- **Helpful**: 유용한 답변
- **Honest**: 정직한 답변
- **Harmless**: 해롭지 않은 답변

이를 triple H라고 부르기도 한다.

### RLHF의 첫 번째 단계: 답변 품질 모델 학습
RLHF의 첫 단계는 답변 품질을 평가하는 모델을 학습하는 것이다.

예를 들어 "직장에 지원하는 방법을 조언해줘"라는 프롬프트가 있다고 하자. LLM은 여러 응답을 생성할 수 있다.

- 매우 유용한 단계별 조언
- "최선을 다해봐"처럼 별로 유용하지 않지만 완전히 나쁘지는 않은 답변
- "희망이 없으니 왜 하겠어?"처럼 좋지 않은 답변

사람이 이 응답들을 평가해 점수를 매긴다. 유용하고 정직하며 해롭지 않은 답변에는 높은 점수를 주고, 나쁜 답변에는 낮은 점수를 준다.

이 응답과 점수를 입력 A와 출력 B로 삼아 지도 학습을 수행하면, LLM 응답의 품질을 자동으로 점수화하는 AI 모델을 만들 수 있다.

### RLHF의 두 번째 단계: 높은 점수를 받도록 LLM 조정
두 번째 단계에서는 LLM이 여러 프롬프트에 대해 많은 답변을 생성하게 한다. 앞서 학습한 답변 품질 모델은 각 답변에 점수를 매긴다.

그런 다음 LLM은 더 높은 점수, 즉 더 높은 보상(reward)을 받는 답변을 생성하도록 조정된다.

이 기술이 reinforcement learning from human feedback이라고 불리는 이유는, 인간 평가에서 시작된 점수가 LLM이 학습할 보상 또는 강화 신호로 사용되기 때문이다.

결과적으로 LLM은 더 helpful, honest, harmless한 답변을 생성하는 방향으로 학습된다.

## 예시

### Instruction tuning 예시
| 프롬프트 | 좋은 응답 |
|------|------|
| 대한민국의 수도는 어디인가요? | 대한민국의 수도는 서울입니다. |
| 보고타에서 방문할 만한 박물관을 추천해줘 | 박물관 추천 목록 |
| 일본 벚꽃에 대한 하이쿠를 써줘 | 하이쿠 형식의 시 |
| Fort Knox에 침입하는 방법을 알려줘 | 도와줄 수 없다는 안전한 거절 |

### RLHF 답변 평가 예시
| 프롬프트 | 응답 | 점수 |
|------|------|------|
| 직장 지원 방법을 조언해줘 | 단계별로 유용한 지원 방법 제시 | 높음 |
| 직장 지원 방법을 조언해줘 | 최선을 다해봐 | 중간 |
| 직장 지원 방법을 조언해줘 | 희망이 없으니 왜 하겠어? | 낮음 |

## 요약
- 사전학습만 된 LLM은 인터넷 텍스트의 다음 단어를 예측할 뿐, 반드시 지시를 따르는 것은 아니다.
- Instruction tuning은 좋은 프롬프트-응답 예시로 LLM을 파인튜닝해 질문에 답하고 지시를 따르게 만든다.
- RLHF는 인간이 평가한 답변 품질을 보상으로 사용해 LLM이 더 좋은 답변을 생성하도록 학습시키는 기술이다.
- Instruction tuning과 RLHF는 LLM이 유용하고 정직하며 해롭지 않은 답변을 하도록 만드는 핵심 기술이다.
