# Tool use and agents

## 개요
- LLM은 단순히 텍스트를 생성하는 것을 넘어 외부 도구(tool)를 호출해 행동하거나 추론을 보완할 수 있다.
- 도구 사용은 주문 시스템 호출, 계산기 사용처럼 LLM의 행동 수행과 정확한 계산 능력을 확장한다.
- 에이전트(agent)는 LLM이 다음 행동을 스스로 선택하고 복잡한 행동 시퀀스를 수행하려는 첨단 연구 주제이지만, 아직 중요한 애플리케이션에 안정적으로 의존할 만큼 성숙하지는 않다.

## 내용

### LLM의 도구 사용
음식 주문 챗봇에서 사용자가 "버거를 보내줘"라고 말하면, 챗봇이 "알겠습니다. 배송 중입니다"라고 답하는 것만으로는 충분하지 않다. 실제로 주문 시스템에 주문을 넣고, 주소로 배달 요청을 보내야 한다.

이를 위해 LLM은 사용자에게 보여줄 응답뿐 아니라, 소프트웨어 시스템이 실행할 명령도 출력할 수 있다.

예시:

```text
order_burger(user_id=9876, address=...)
user_message: OK, it's on its way.
```

이 경우 전체 LLM 출력 중 주문 명령은 내부 소프트웨어가 읽어 식당 주문 시스템을 호출하는 데 사용되고, 사용자에게는 마지막 메시지만 표시된다.

이것이 LLM의 도구 사용(tool use) 예시다. LLM이 출력한 텍스트가 외부 소프트웨어 시스템 호출을 트리거한다.

### 행동을 수행하는 도구의 위험
잘못된 주문은 비용이 드는 실수가 될 수 있다. 따라서 주문을 확정하기 전에 사용자에게 확인 대화상자를 보여주고, 주문 내용이 맞는지 확인받는 UI가 더 안전할 수 있다.

LLM 출력은 완전히 신뢰할 수 없기 때문에, 안전에 중요하거나 비용이 큰 행동에서는 LLM이 단독으로 실행하게 두기보다 사용자가 원하는 행동을 확인하도록 설계하는 것이 좋다.

### 추론을 돕는 도구
도구는 실제 행동뿐 아니라 추론을 돕는 데도 사용할 수 있다.

LLM은 다음 단어를 예측하고 instruction tuning을 거쳤더라도, 정밀한 수학 계산에는 약할 수 있다.

예를 들어 "연 5% 이자를 주는 은행 계좌에 100달러를 넣으면 8년 후 얼마가 되나요?"라고 물으면, LLM은 그럴듯하지만 틀린 숫자를 만들 수 있다.

이럴 때 LLM에 계산기 도구를 제공하면 정확한 계산을 수행할 수 있다. LLM은 직접 답을 만들어내기보다 다음과 같은 계산 명령을 출력할 수 있다.

```text
calculator(100 * 1.05^8)
```

외부 계산기 프로그램이 이 값을 계산하고, 결과인 약 147.74달러를 LLM의 응답에 넣어 사용자에게 정확한 답을 보여줄 수 있다.

도구 사용은 LLM의 추론 능력과 행동 수행 능력을 크게 확장할 수 있다.

### 도구 사용 설계 시 주의점
도구 사용은 많은 LLM 애플리케이션에서 중요한 구성 요소가 되고 있다. 하지만 도구가 잘못 호출되면 피해나 되돌릴 수 없는 손상이 발생할 수 있다.

따라서 애플리케이션 설계자는 다음을 고려해야 한다.

- 사용자가 중요한 행동을 확인하도록 만들기
- 비용이 큰 행동에는 안전장치 두기
- 되돌릴 수 없는 작업은 자동 실행하지 않기
- LLM 출력이 도구 호출로 해석되는 방식을 엄격히 관리하기

### 에이전트란 무엇인가
도구 사용을 넘어서는 더 실험적인 영역이 에이전트(agent)다.

에이전트는 LLM이 단일 도구 호출을 수행하는 것을 넘어, 어떤 행동을 다음에 해야 할지 스스로 판단하고 복잡한 행동 시퀀스를 수행하려는 접근이다.

예를 들어 사용자가 "Better Burgers의 주요 경쟁사를 조사해줘"라고 요청한다고 하자. LLM 기반 에이전트는 이 작업을 수행하기 위해 다음 단계를 스스로 계획할 수 있다.

1. 주요 경쟁사 목록을 검색한다.
2. 각 경쟁사의 웹사이트를 방문한다.
3. 각 홈페이지 내용을 다운로드한다.
4. 각 경쟁사에 대한 요약을 작성한다.

이 과정에서 에이전트는 웹 검색 도구를 호출하고, 웹페이지를 방문하고, 다시 LLM을 호출해 요약을 생성할 수 있다.

### 에이전트의 현재 한계
인터넷에는 에이전트의 인상적인 데모가 있지만, 이 기술은 아직 초기 단계다. 중요한 애플리케이션에서 안정적으로 의존하기에는 충분히 성숙하지 않았다.

하지만 앞으로 연구가 발전하면, LLM이 추론 엔진으로서 안전하고 책임감 있게 다음 행동의 시퀀스를 결정해 사용자의 작업을 도와주는 방향으로 발전할 수 있다.

## 예시

### 도구 사용 예시
| 목적 | 도구 | LLM의 역할 |
|------|------|------|
| 음식 주문 | 주문 시스템 | 주문 명령을 생성하고 사용자 메시지 작성 |
| 복리 계산 | 계산기 | 계산식을 만들고 결과를 응답에 반영 |
| 웹 조사 | 검색/브라우저 도구 | 필요한 정보를 찾고 요약 |

### 에이전트 작업 예시
| 단계 | 행동 |
|------|------|
| 1 | 경쟁사 검색 |
| 2 | 경쟁사 웹사이트 방문 |
| 3 | 홈페이지 내용 수집 |
| 4 | 각 경쟁사 요약 작성 |

## 요약
- LLM은 외부 도구를 호출해 실제 행동을 수행하거나 계산 같은 추론을 보완할 수 있다.
- 주문, 결제, 배송처럼 비용이 큰 행동은 사용자 확인과 안전장치가 필요하다.
- 계산기 같은 도구를 사용하면 LLM의 약점인 정밀 계산을 보완할 수 있다.
- 에이전트는 LLM이 복잡한 행동 시퀀스를 계획하고 실행하게 하는 첨단 주제지만, 아직 대부분의 중요한 애플리케이션에 안정적으로 쓰기에는 이르다.
