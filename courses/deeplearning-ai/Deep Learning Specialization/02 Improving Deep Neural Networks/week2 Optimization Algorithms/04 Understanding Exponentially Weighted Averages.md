# 04 Understanding Exponentially Weighted Averages

## 개요
- 지수 가중 평균이 왜 "지수적으로 감쇠하는 가중치의 평균"인지, 그리고 효율적인 구현을 설명.

---

## 내용

### 전개해 보면 (β=0.9)
```
V₁₀₀ = 0.1·θ₁₀₀ + 0.1·0.9·θ₉₉ + 0.1·0.9²·θ₉₈ + 0.1·0.9³·θ₉₇ + ...
```
- 즉 현재 값 θ에 **지수적으로 감쇠하는 가중치**를 곱해 합한 **가중 평균**.
- 가중치들의 합은 (거의) 1 (bias correction 세부는 다음 영상).

### "몇 일 평균"인가
- `0.9¹⁰ ≈ 0.35 ≈ 1/e` → 약 10일이면 가중치가 현재의 1/3 수준으로 감쇠 → **최근 10일 평균**처럼.
- 일반화: `(1−ε)^(1/ε) ≈ 1/e`. β=0.98이면 ε=0.02 → `0.98⁵⁰ ≈ 1/e` → **약 50일 평균**.
- 이래서 "약 `1/(1−β)`일 평균"이라는 규칙이 나옴 (엄밀한 수학이 아닌 경험칙).

### 효율적 구현
```python
V = 0
for each θ_t:
    V = beta * V + (1 - beta) * θ_t
```
- **메모리 1개(숫자 하나)** 만 있으면 됨 — 계속 덮어씀.
- 최근 N일을 명시적으로 저장·합산하는 이동평균이 더 정확하지만, **메모리·계산이 크고 복잡**.
- 지수 가중 평균은 **한 줄, 상수 메모리** → 많은 변수의 평균이 필요한 ML에서 널리 사용.

---

## 요약
- V_t = θ에 지수 감쇠 가중치를 곱해 합한 것 → "지수 가중 평균".
- β=0.9 ≈ 10일, β=0.98 ≈ 50일 (∵ (1−ε)^{1/ε}≈1/e).
- 구현은 변수 하나로 덮어쓰기 → 메모리·계산 효율적.
