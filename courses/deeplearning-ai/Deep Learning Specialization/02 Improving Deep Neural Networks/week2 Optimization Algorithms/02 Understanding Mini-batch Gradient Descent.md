# 02 Understanding Mini-batch Gradient Descent

## 개요
- 미니배치 GD의 비용 곡선 특성과 **미니배치 크기(mini-batch size)** 선택 가이드.

---

## 내용

### 비용 곡선
- **Batch GD**: 매 반복 비용 J가 **단조 감소**해야 함 (오르면 문제, 학습률 과대 등).
- **Mini-batch GD**: 매 반복 다른 배치를 쓰므로 J^{t}가 **노이즈 있게 하향(전반적 감소)**.
  - 쉬운 배치는 비용↓, 어려운 배치(오라벨 포함 등)는 비용↑ → 진동.

### 미니배치 크기 극단
| 크기 | 이름 | 특징 |
|---|---|---|
| **= m** | Batch GD | 노이즈 적고 큰 스텝, 그러나 반복당 시간 과다 |
| **= 1** | Stochastic GD (SGD) | 예제 하나마다 스텝. 매우 노이즈, 벡터화 이점 상실. 최소점에 수렴 못 하고 주변서 진동 |
| **1 < 크기 < m** | Mini-batch GD | 실무 최선 — 벡터화 이점 + 전체 데이터 안 기다리고 진전 |

- SGD의 노이즈는 학습률을 줄여 완화 가능하나, **벡터화 속도 이점을 잃는 게 치명적**.

### 미니배치 크기 선택 가이드 ⭐
1. **작은 데이터셋(≲ 2,000)** → 그냥 Batch GD.
2. 그 외 → 전형적으로 **64 ~ 512**.
3. **2의 거듭제곱**(64, 128, 256, 512)이 메모리 접근상 더 빠를 때가 많음. (1000 대신 1024)
4. **미니배치가 CPU/GPU 메모리에 맞아야** 함 — 안 맞으면 성능이 급락.
5. 미니배치 크기도 **하이퍼파라미터** → 몇 개 2의 거듭제곱을 시도해 가장 효율적인 값 선택.

---

## 요약
- Batch GD 비용은 단조 감소, mini-batch는 노이즈 있게 감소(정상).
- 크기 = m → Batch, = 1 → SGD(벡터화 손실). 그 사이가 최선.
- 소규모는 Batch, 그 외 64~512(2의 거듭제곱), 메모리에 맞게.
