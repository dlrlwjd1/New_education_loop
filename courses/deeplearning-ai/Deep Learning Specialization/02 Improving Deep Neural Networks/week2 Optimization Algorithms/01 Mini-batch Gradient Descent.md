# 01 Mini-batch Gradient Descent

## 개요
- 최적화 알고리즘은 신경망 훈련을 **훨씬 빠르게** 해준다. 딥러닝은 빅데이터에서 잘 되는데 큰 데이터 훈련은 느리므로 중요.
- **미니배치 경사 하강(mini-batch gradient descent)**: 전체 데이터를 작은 배치로 나눠 처리.

---

## 내용

### 배치(batch) vs 미니배치(mini-batch)
- **Batch GD**: 전체 훈련 세트(예: 500만 개)를 다 처리해야 **한 번** 경사 하강. 느림.
- **Mini-batch GD**: 데이터를 작은 배치(예: 1,000개씩)로 나눠, 각 배치마다 경사 하강 스텝을 밟음.
  - 500만 개 / 1,000 = **5,000개의 미니배치**.

### 표기법 ⚠️
| 표기 | 의미 |
|---|---|
| `X⁽ⁱ⁾` (소괄호) | i번째 훈련 예제 |
| `Z⁽ˡ⁾` (대괄호) | l번째 층 |
| **`X^{t}` (중괄호)** | **t번째 미니배치** |

- X^{t}, Y^{t} = 1,000개 예제. 차원: X^{t} = (nₓ × 1000), Y^{t} = (1 × 1000).

### 미니배치 경사 하강 알고리즘 (1 epoch)
```
for t = 1 to 5000:                    # 각 미니배치
    # 순전파 (X^{t}에 대해 벡터화)
    Z⁽¹⁾ = W⁽¹⁾ X^{t} + b⁽¹⁾ ;  A⁽¹⁾ = g(Z⁽¹⁾) ; ... ; A⁽ᴸ⁾ = ŷ
    # 비용 (미니배치 1000개 기준)
    J^{t} = (1/1000) Σ L(ŷ⁽ⁱ⁾, y⁽ⁱ⁾) + (λ/2·1000) Σ‖W⁽ˡ⁾‖²_F
    # 역전파 (J^{t} 기준)
    # 업데이트
    W⁽ˡ⁾ := W⁽ˡ⁾ − α dW⁽ˡ⁾ ;  b⁽ˡ⁾ := b⁽ˡ⁾ − α db⁽ˡ⁾
```
- **epoch** = 훈련 세트 전체를 한 번 통과.
  - Batch GD: 1 epoch = 경사 하강 **1스텝**.
  - Mini-batch GD: 1 epoch = 경사 하강 **5,000스텝**.
- 보통 여러 epoch를 돌린다 (바깥 루프).

---

## 요약
- 미니배치 GD = 데이터를 작은 배치로 나눠 배치마다 경사 하강 → 큰 데이터에서 훨씬 빠름.
- 표기: 중괄호 `{t}` = 미니배치 번호.
- 1 epoch에 여러 스텝을 밟아 빠르게 수렴. 대규모 데이터의 사실상 표준.
