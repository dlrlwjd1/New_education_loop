# 06 Gradient Descent with Momentum

## 개요
- **Momentum(모멘텀 경사 하강)**: 경사(gradient)의 **지수 가중 평균**을 계산해 그것으로 가중치를 업데이트.
- 표준 경사 하강보다 거의 항상 빠르다.

---

## 내용

### 문제: 진동(oscillation)
- 길쭉한 등고선에서 경사 하강은 **세로로 진동**하며 천천히 최소점으로 감.
- 진동 때문에 학습률을 크게 못 씀(발산 위험).
- 원하는 것: **세로는 느리게(진동 억제), 가로는 빠르게(최소점으로 전진)**.

### 알고리즘
```
매 반복 t:
  현재 미니배치로 dW, db 계산
  V_dW = β·V_dW + (1−β)·dW
  V_db = β·V_db + (1−β)·db
  W := W − α·V_dW
  b := b − α·V_db
```
- 경사의 이동평균 → **세로 진동은 양수·음수가 상쇄되어 0에 가까워지고**, 가로는 모두 같은 방향이라 평균이 큼 → 최소점으로 더 곧게 이동.

### 직관: 그릇을 굴러가는 공
- dW, db = **가속도(acceleration)**, V = **속도(velocity)**, β(<1) = **마찰(friction)**.
- 공이 그릇을 굴러 내려가며 모멘텀을 얻음. (물리 직관이 안 맞으면 무시해도 됨)

### 하이퍼파라미터
- α(학습률), **β(대개 0.9 — 최근 10회 경사 평균)**. 0.9가 매우 robust.
- **편향 보정은 보통 생략** — 10회면 warm-up 끝.
- 초기화: V_dW=0(W와 같은 차원), V_db=0.

### (1−β) 생략 변형
- 문헌에서 `V_dW = β·V_dW + dW` 형태도 있음 → V가 1/(1−β)배 스케일 → α를 그에 맞게 조정해야 함.
- Andrew Ng은 **(1−β) 포함 버전을 선호** (β 튜닝 시 α 재튜닝 부담이 적음). 둘 다 β=0.9는 흔함.

---

## 요약
- Momentum = 경사의 지수 가중 평균으로 업데이트 → 진동 억제, 최소점으로 빠르게.
- `V_dW=βV_dW+(1−β)dW`, `W:=W−αV_dW`. β=0.9 기본.
- 거의 항상 표준 GD보다 빠름.
