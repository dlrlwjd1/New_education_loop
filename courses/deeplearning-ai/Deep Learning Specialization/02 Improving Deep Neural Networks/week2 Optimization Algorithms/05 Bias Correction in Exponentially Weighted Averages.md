# 05 Bias Correction in Exponentially Weighted Averages

## 개요
- 지수 가중 평균의 **초기 구간(warm-up)** 값이 너무 낮게 나오는 문제를 **편향 보정(bias correction)** 으로 개선.

---

## 내용

### 문제: 초기값이 낮게 시작
- V₀=0으로 시작하므로:
  ```
  V₁ = 0.98·0 + 0.02·θ₁ = 0.02·θ₁   → θ₁=40이면 V₁=0.8 (너무 낮음)
  V₂ = 0.0196·θ₁ + 0.02·θ₂          → θ₁,θ₂보다 훨씬 작음
  ```
- 그래서 β=0.98의 실제 곡선은 (초록이 아니라) **보라색으로 낮게 시작**.

### 편향 보정
```
V_t^corrected = V_t / (1 − βᵗ)
```
- 예 t=2: 분모 `1 − 0.98² = 0.0396`. → V₂/0.0396 = θ₁,θ₂의 제대로 된 가중 평균 (분자 계수 합 = 분모).
- t가 커지면 `βᵗ → 0` → 보정이 거의 영향 없음 → 보라선과 초록선이 겹침.
- 즉 **초기 구간에서만** 추정을 개선.

### 실무
- 대부분의 ML 구현은 **편향 보정을 굳이 하지 않음** — 초기 구간을 그냥 기다리는 편.
- 초기 구간 정확도가 중요하면 보정 사용.

---

## 요약
- 초기엔 V가 0에서 시작해 과소 추정 → `V_t / (1−βᵗ)`로 보정.
- t 커지면 보정 효과 사라짐. 실무에선 생략하는 경우가 많음.
