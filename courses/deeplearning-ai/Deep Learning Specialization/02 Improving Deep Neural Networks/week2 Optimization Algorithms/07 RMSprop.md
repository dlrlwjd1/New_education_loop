# 07 RMSprop

## 개요
- **RMSprop (Root Mean Square prop)**: 경사 제곱의 지수 가중 평균으로 나눠 업데이트 → 진동을 억제하고 학습을 빠르게.

---

## 내용

### 알고리즘
```
매 반복 t:
  현재 미니배치로 dW, db 계산
  S_dW = β·S_dW + (1−β)·dW²     # dW² 는 원소별 제곱
  S_db = β·S_db + (1−β)·db²
  W := W − α · dW / (√S_dW + ε)
  b := b − α · db / (√S_db + ε)
```

### 직관 (세로 b, 가로 w 예시)
- 진동이 큰 **세로(b) 방향**은 db가 커서 S_db가 큼 → 큰 수로 나눠 **업데이트 억제**.
- 전진하는 **가로(w) 방향**은 dw가 작아 S_dW가 작음 → 작은 수로 나눠 **빠르게 진행**.
- 결과: 세로 진동이 줄어 **더 큰 학습률 α**를 써도 발산하지 않음 → 빠른 학습.
- (실제로는 고차원 — b/w는 설명용. 진동하는 차원의 경사 제곱 평균이 커져 그 방향을 감쇠.)

### 세부 사항
- **수치 안정성**: `√S`가 0에 가까우면 폭발 → 분모에 작은 **ε(기본 10⁻⁸)** 추가.
- 다음 영상(Adam)에서 Momentum과 결합하므로, 여기 β는 **β₂**로 부를 예정.
- 참고: RMSprop은 논문이 아니라 **Geoffrey Hinton의 MOOC 강의**에서 처음 제안돼 유명해짐.

---

## 요약
- RMSprop: `S=βS+(1−β)dW²`, `W:=W−α·dW/(√S+ε)`.
- 경사 제곱 평균으로 나눠 진동 큰 방향을 감쇠, 큰 학습률 사용 가능.
