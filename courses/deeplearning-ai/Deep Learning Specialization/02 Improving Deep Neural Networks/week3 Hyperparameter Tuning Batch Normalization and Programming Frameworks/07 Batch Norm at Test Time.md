# 07 Batch Norm at Test Time

## 개요
- Batch Norm은 훈련 시 **미니배치 단위**로 μ, σ²를 계산하지만, 테스트 시엔 예제를 하나씩 처리할 수 있으므로 다른 μ, σ²가 필요.

---

## 내용

### 문제
- 훈련: μ, σ²를 **미니배치(64/128/256개)** 전체로 계산.
- 테스트: 예제 하나만 있으면 그 하나로 평균·분산을 구하는 게 의미 없음.

### 해결: 지수 가중 이동평균(running average)
- 훈련 중 각 층에서 미니배치마다 나오는 μ⁽¹⁾, μ⁽²⁾, ... 와 σ²⁽¹⁾, σ²⁽²⁾, ... 을 **지수 가중 평균**으로 추적(running average).
- 테스트 시:
  ```
  z_norm = (z − μ_running) / √(σ²_running + ε)
  z̃ = γ · z_norm + β        # 훈련으로 학습한 γ, β 사용
  ```

### 실무
- μ, σ² 추정 방법에 대해 **결과가 robust** — 정확한 방식에 크게 신경 안 써도 됨.
- (이론상 전체 훈련 세트를 최종 망에 통과시켜 구할 수도 있지만) 보통 **running average** 사용.
- 딥러닝 프레임워크가 기본 방식을 제공하므로 대개 그대로 쓰면 됨.

---

## 요약
- 테스트 시 μ, σ²는 훈련 중 미니배치들의 **지수 가중 이동평균**으로 추정.
- 그 값으로 z_norm 계산 후 학습된 γ, β로 z̃ 산출. 추정 방식엔 robust.

## Batch Norm 마무리
- 은닉값 정규화로 더 깊은 망을 더 빠르게 학습 가능.
