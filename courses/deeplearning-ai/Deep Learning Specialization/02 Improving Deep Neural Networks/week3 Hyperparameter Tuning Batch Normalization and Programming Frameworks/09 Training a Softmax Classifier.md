# 09 Training a Softmax Classifier

## 개요
- Softmax 분류기의 손실 함수와 학습(경사 하강) 방법.

---

## 내용

### Softmax vs Hardmax
- **Hardmax**: 가장 큰 원소에 1, 나머지 0 (예: [1,0,0,0]).
- **Softmax**: z를 확률로 부드럽게(gentle) 매핑.
- **C=2이면 softmax는 로지스틱 회귀로 환원** — 두 확률의 합이 1이라 하나는 중복. Softmax는 로지스틱 회귀의 다중 클래스 일반화.

### 손실 함수 (cross-entropy loss)
```
L(ŷ, y) = − Σⱼ yⱼ log ŷⱼ    (j = 1..C)
```
- 예: y = [0,1,0,0] (cat), ŷ = [0.3, 0.2, 0.1, 0.4] 이면
  - y₁=y₃=y₄=0 이므로 → `L = − log ŷ₂` (정답 클래스의 확률만 남음).
- 정답 클래스의 확률 ŷ를 **최대한 크게** 만들도록 학습 (최대우도추정 형태).

### 비용 함수
```
J = (1/m) Σ L(ŷ⁽ⁱ⁾, y⁽ⁱ⁾)
```
- 벡터화: Y, Ŷ 모두 (C × m) 행렬 (각 예제를 열로).

### 역전파 초기값 ⭐
```
dZ⁽ᴸ⁾ = ŷ − y      # (C×1), 일반적으로 (C×1)
```
- 이 식으로 backprop 시작. (프레임워크를 쓰면 forward만 맞게 정의하면 backprop은 자동으로 처리됨.)

---

## 요약
- Softmax 손실 = `−Σ yⱼ log ŷⱼ` → 정답 클래스 확률을 최대화.
- 비용 = 손실 평균. 역전파 시작값 dZ⁽ᴸ⁾ = ŷ − y.
- C=2면 로지스틱 회귀와 동일.
