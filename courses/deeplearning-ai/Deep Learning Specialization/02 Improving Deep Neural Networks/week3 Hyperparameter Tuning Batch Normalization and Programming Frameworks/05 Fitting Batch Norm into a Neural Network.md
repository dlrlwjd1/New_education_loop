# 05 Fitting Batch Norm into a Neural Network

## 개요
- Batch Norm을 심층 신경망 전체·미니배치 학습에 넣는 방법.

---

## 내용

### 어디에 들어가나
- 각 층: `z → (Batch Norm) → z̃ → a = g(z̃)`. **z와 a 계산 사이**에 BN이 들어감.
- 새 파라미터: 각 층마다 **β⁽ˡ⁾, γ⁽ˡ⁾** 추가 (경사 하강/Adam 등으로 학습).
  - ⚠️ 이 β는 momentum/Adam의 하이퍼파라미터 β와 **완전히 다른 것**(이름만 같음).
- 딥러닝 프레임워크에선 대개 **한 줄**(예: TensorFlow `tf.nn.batch_normalization`).

### b⁽ˡ⁾ 파라미터 제거 ⭐
- `z⁽ˡ⁾ = W⁽ˡ⁾a⁽ˡ⁻¹⁾ + b⁽ˡ⁾` 에서, BN이 평균을 빼므로 **b⁽ˡ⁾는 상쇄되어 무의미**.
- 따라서 b⁽ˡ⁾ 제거: `z⁽ˡ⁾ = W⁽ˡ⁾a⁽ˡ⁻¹⁾`. 편향 역할은 **β⁽ˡ⁾** 가 대신함.
- 차원: z⁽ˡ⁾, β⁽ˡ⁾, γ⁽ˡ⁾ 모두 (n⁽ˡ⁾ × 1).

### 미니배치와 함께
- 각 미니배치에서 그 배치의 z에 대한 **평균·분산을 계산**해 정규화.
- 미니배치마다 다른 μ, σ²로 정규화됨.

### 경사 하강 (with Batch Norm)
```
for t = 1 to (미니배치 수):
    미니배치 X^{t}로 순전파, 각 층에서 z⁽ˡ⁾ → z̃⁽ˡ⁾ (BN)
    역전파로 dW, dβ, dγ 계산 (db는 제거됨)
    업데이트: W:=W−αdW ; β:=β−αdβ ; γ:=γ−αdγ
```
- Momentum/RMSprop/Adam으로도 β, γ 업데이트 가능.

---

## 요약
- BN은 각 층의 z와 a 사이에 삽입, 층마다 β·γ 추가.
- BN이 평균을 빼므로 b는 제거하고 β가 편향 역할.
- 미니배치별로 μ,σ² 계산해 정규화. 프레임워크에선 한 줄.
