# 10 Deep Learning Frameworks

## 개요
- 지금까지 Python/NumPy로 밑바닥부터 구현했지만, CNN·RNN 등 복잡·대규모 모델은 **프레임워크**를 쓰는 게 실용적.

---

## 내용

### 왜 프레임워크인가
- 비유: 행렬 곱을 직접 구현할 줄 알아야 하지만, 실제 대규모 앱에선 최적화된 **선형대수 라이브러리**를 호출.
- 딥러닝도 성숙해서 프레임워크를 쓰는 편이 더 효율적. (원리 이해는 여전히 도움됨.)

### 프레임워크 선택 기준 ⭐
1. **프로그래밍 용이성** — 개발·반복(iteration) + **프로덕션 배포**의 편리함.
2. **실행 속도** — 특히 대규모 데이터 학습 속도.
3. **진정한 오픈성(truly open)** — 오픈소스일 뿐 아니라 **좋은 거버넌스(governance)**.
   - 일부 회사는 오픈소스로 열었다가 점차 닫거나 자사 클라우드로 기능을 옮긴 이력 → 장기적으로 오픈 유지될지 신뢰도 고려.

### 정리
- 여러 프레임워크가 빠르게 발전 중 — 강사는 특정 프레임워크를 강하게 추천하기보다 **위 기준으로 선택**할 것을 권장.
- 선호 언어(Python/Java/C++ 등)와 응용 분야(비전/NLP/광고 등)에 따라 여러 프레임워크가 좋은 선택이 될 수 있음.
- 프레임워크는 선형대수 라이브러리보다 **높은 추상화**를 제공해 개발 효율을 높여줌.

---

## 요약
- 복잡·대규모 모델은 프레임워크 사용이 실용적.
- 선택 기준: 프로그래밍 용이성, 실행 속도, 진정한 오픈성(오픈소스 + 거버넌스).
