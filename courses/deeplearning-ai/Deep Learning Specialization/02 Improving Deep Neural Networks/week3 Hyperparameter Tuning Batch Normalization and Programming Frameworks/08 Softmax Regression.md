# 08 Softmax Regression

## 개요
- **Softmax 회귀**: 로지스틱 회귀를 **다중 클래스(C개)** 분류로 일반화. 여러 클래스 중 하나를 예측.

---

## 내용

### 설정
- 예: cat(1), dog(2), baby chick(3), 그 외(0) → **C=4** 클래스. 인덱스 0 ~ C−1.
- 출력층 유닛 수 n⁽ᴸ⁾ = C. 각 유닛이 **각 클래스일 확률**을 출력.
- ŷ 는 (C×1) 벡터, 원소들의 **합 = 1**.

### Softmax 활성화 함수 (출력층)
```
z⁽ᴸ⁾ = W⁽ᴸ⁾ a⁽ᴸ⁻¹⁾ + b⁽ᴸ⁾            # (C×1)
t = e^{z⁽ᴸ⁾}                          # 원소별 지수 (C×1)
a⁽ᴸ⁾ = t / Σⱼ tⱼ                       # 합이 1이 되도록 정규화
a⁽ᴸ⁾ᵢ = tᵢ / Σⱼ tⱼ
```

### 예시
z⁽ᴸ⁾ = [5, 2, −1, 3]:
```
t = [e⁵, e², e⁻¹, e³] = [148.4, 7.4, 0.4, 20.1],  합 = 176.3
a⁽ᴸ⁾ = [0.842, 0.042, 0.002, 0.114]   → 각 클래스 확률
```

### 특징
- softmax 활성화 함수는 **벡터(C×1)를 입력받아 벡터(C×1)를 출력** (기존 sigmoid/ReLU는 실수→실수).
- 은닉층 없는 softmax는 **선형 결정 경계**로 C개 클래스를 나눔 (두 클래스 간 경계가 선형). 로지스틱 회귀의 다중 클래스 일반화.
- 깊은 망에 softmax를 붙이면 비선형 결정 경계로 다중 클래스 분류 가능.

---

## 요약
- Softmax: z에 지수 취한 뒤 합으로 정규화 → C개 클래스 확률(합=1).
- 벡터→벡터 활성화 함수. 로지스틱 회귀의 다중 클래스 버전.
