# 03 Hyperparameters Tuning in Practice: Pandas vs. Caviar

## 개요
- 하이퍼파라미터 탐색을 조직하는 실무 팁과 두 가지 접근(Panda vs Caviar).

---

## 내용

### 직관은 오래되면 낡는다(stale)
- 한 분야의 하이퍼파라미터 직관이 다른 분야에 통할 수도, 안 통할 수도.
- (분야 간 교차 활용은 활발 — CV의 ConvNet/ResNet이 음성에, 음성 아이디어가 NLP에 적용 등.)
- 한 문제만 다뤄도 데이터 변화·서버 업그레이드 등으로 최적값이 낡을 수 있음 → **몇 달마다 재평가** 권장.

### 두 가지 탐색 방식
| | **Panda (판다)** | **Caviar (캐비어)** |
|---|---|---|
| 방식 | **한 모델을 돌보며** 매일 α·momentum 등을 조금씩 조정 | **여러 모델을 병렬로** 동시 학습 후 최선 선택 |
| 비유 | 판다: 자식 하나를 정성껏 | 물고기: 알 수억 개, 하나라도 잘되길 |
| 적합 상황 | 계산 자원 부족(큰 데이터/큰 모델) | 계산 자원 충분(병렬 학습 가능) |
| 예시 분야 | 온라인 광고, 일부 CV | — |

- 선택 기준 = **가용 계산 자원**. 자원 많으면 Caviar, 부족하면 Panda.

---

## 요약
- 하이퍼파라미터 직관은 낡으므로 주기적 재평가.
- Panda(한 모델 돌보기) vs Caviar(여러 모델 병렬) — 계산 자원에 따라 선택.
