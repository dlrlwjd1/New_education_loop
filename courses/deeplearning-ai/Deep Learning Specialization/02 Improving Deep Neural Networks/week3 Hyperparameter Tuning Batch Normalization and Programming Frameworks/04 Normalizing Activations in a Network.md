# 04 Normalizing Activations in a Network (Batch Norm)

## 개요
- **배치 정규화(Batch Normalization, Batch Norm)** — Ioffe & Szegedy 제안.
- 하이퍼파라미터 탐색을 쉽게 하고, 하이퍼파라미터에 강건하며, 아주 깊은 망도 잘 학습되게 함.

---

## 내용

### 아이디어
- 입력 특징 X를 정규화하면 학습이 빨라졌듯, **은닉층의 값도 정규화**하면 다음 층 파라미터 학습이 빨라진다.
- 어떤 은닉층의 활성값을 정규화해 그 다음 층(W, b) 학습을 효율화.
- **A가 아니라 Z를 정규화**하는 것이 일반적 (활성화 함수 적용 전). ← 기본 권장.

### 구현 (어떤 층의 z⁽ⁱ⁾, i=1..m)
```
μ  = (1/m) Σ z⁽ⁱ⁾
σ² = (1/m) Σ (z⁽ⁱ⁾ − μ)²
z_norm⁽ⁱ⁾ = (z⁽ⁱ⁾ − μ) / √(σ² + ε)      # 평균0, 분산1
z̃⁽ⁱ⁾ = γ · z_norm⁽ⁱ⁾ + β               # 학습 가능한 γ, β
```
- 이후 층 계산에서 z⁽ⁱ⁾ 대신 **z̃⁽ⁱ⁾** 사용.

### γ, β는 학습 파라미터 ⭐
- 은닉 유닛이 **항상 평균0·분산1일 필요는 없다** (예: sigmoid의 선형 구간에만 몰리면 비선형성 활용 못 함).
- **γ, β** 로 z̃의 평균·분산을 원하는 값으로 조정. 경사 하강(Adam 등)으로 W처럼 학습.
- 만약 `γ = √(σ²+ε)`, `β = μ` 이면 z̃⁽ⁱ⁾ = z⁽ⁱ⁾ (항등) → γ,β가 분포를 자유롭게 제어.

---

## 요약
- Batch Norm = 은닉층의 z를 평균μ·분산σ²로 정규화 후, 학습 가능한 γ·β로 원하는 평균·분산으로 조정.
- 입력 정규화를 은닉층까지 확장한 것. 학습 안정·가속, 하이퍼파라미터 강건.
