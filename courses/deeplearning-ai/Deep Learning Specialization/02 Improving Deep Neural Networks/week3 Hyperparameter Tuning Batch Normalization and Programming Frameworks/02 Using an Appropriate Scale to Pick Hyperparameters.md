# 02 Using an Appropriate Scale to Pick Hyperparameters

## 개요
- 랜덤 샘플링이라고 **균등(uniform) 샘플링**을 뜻하진 않는다. 하이퍼파라미터마다 **적절한 스케일**을 골라야 한다.

---

## 내용

### 균등 스케일로 충분한 경우
- **은닉 유닛 수** (예: 50~100), **층 수** (예: 2~4) → 선형(균등) 랜덤 또는 격자로 OK.

### 로그 스케일이 필요한 경우: 학습률 α
- α를 0.0001~1 사이에서 **선형 균등** 샘플링하면, 90%가 0.1~1에 몰림 (0.0001~0.1은 10%만).
- 대신 **로그 스케일**로 샘플링:
  ```python
  r = -4 * np.random.rand()   # r ∈ [-4, 0]
  alpha = 10 ** r             # α ∈ [10⁻⁴, 10⁰]
  ```
- 일반화: 10ᵃ ~ 10ᵇ 범위면 `a=log₁₀(low)`, `b=log₁₀(high)`, `r ~ Uniform(a,b)`, `값 = 10ʳ`.

### β (지수 가중 평균)도 로그 스케일
- β를 0.9~0.999에서 탐색 시, **1−β** (0.1~0.001)를 로그 스케일로:
  ```python
  r = np.random.uniform(-3, -1)   # 1−β ∈ [10⁻³, 10⁻¹]
  beta = 1 - 10 ** r
  ```
- 이유: β가 1에 가까울수록 결과가 **작은 변화에도 민감**.
  - 0.9→0.9005: 거의 무변화. 0.999→0.9995: 큰 변화 (평균 기간 1000→2000).
  - `1/(1−β)`가 β≈1에서 매우 민감 → 그 영역을 **더 촘촘히** 샘플링해야 함.

### 스케일을 잘못 골라도
- 균등 스케일로 샘플링해도 **coarse-to-fine**을 쓰면 이후 단계에서 유용한 범위에 집중하므로 괜찮은 결과를 얻을 수 있음.

---

## 요약
- 은닉 유닛/층 수 → 선형 균등 OK.
- α → 로그 스케일 (`10ʳ`). β → `1−β`를 로그 스케일.
- β≈1에서 민감하므로 그 영역을 촘촘히.
