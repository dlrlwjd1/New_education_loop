# 08 Other Regularization Methods

## 개요
- L2·dropout 외의 과적합 감소 기법: **데이터 증강(data augmentation)**, **조기 종료(early stopping)**.

---

## 내용

### 데이터 증강 (Data Augmentation)
- 새 데이터 수집이 비싸거나 불가능할 때, 기존 데이터를 변형해 **가짜 훈련 예제**를 생성.
- 이미지 예: **좌우 반전(horizontal flip)**, 랜덤 **크롭/회전/확대**.
  - 좌우 반전한 고양이도 고양이 → 데이터셋 2배 가능. (상하 반전은 안 함 — 뒤집힌 고양이는 원치 않음)
- 문자 인식(OCR): 숫자에 **회전·왜곡(distortion)** 적용 (실무에선 과하지 않게 미묘하게).
- 새로 독립적으로 수집한 데이터만큼 정보가 많진 않지만, **거의 공짜(계산 비용만)** 로 데이터를 늘려 정규화 효과.

### 조기 종료 (Early Stopping)
- 훈련 오류(또는 J)와 **dev 오류**를 반복 횟수에 대해 함께 플롯.
- dev 오류가 감소하다 **다시 증가하는 지점**에서 훈련을 멈춤 → 그 시점의 W 채택.
- 원리: W는 랜덤 초기화로 작게 시작 → 학습할수록 커짐. 중간에 멈추면 **중간 크기의 W** → L2처럼 작은 노름 → 과적합 감소.

### Early Stopping의 단점: 직교화(orthogonalization) 위배
- ML 과정은 두 작업으로 나뉜다:
  1. **비용 J 최적화** (도구: 경사 하강, Momentum, RMSprop, Adam...)
  2. **과적합 방지 = 분산 감소** (도구: 정규화, 데이터 추가...)
- **직교화(orthogonalization)**: 한 번에 한 작업만 생각하는 원칙.
- early stopping은 이 **두 작업을 뒤섞음** — 훈련을 일찍 멈춰 J 최적화를 덜 하면서 동시에 과적합을 막으려 함 → 사고가 복잡해짐.

### L2 vs Early Stopping (강사 선호)
- 대안: **L2 정규화**를 쓰고 훈련을 최대한 오래 → 하이퍼파라미터 공간 분해가 쉬움.
- 단점: λ 값을 여러 개 시도해야 해 **계산 비용↑**.
- early stopping의 장점: 경사 하강 **한 번**으로 작은/중간/큰 W를 모두 시도 (λ 여러 값 탐색 불필요).
- **Andrew Ng 개인 선호: L2 + 여러 λ** (계산 여유가 있다면).

---

## 요약
- 데이터 증강: 반전/크롭/회전/왜곡으로 값싸게 데이터 확대 → 정규화 효과.
- early stopping: dev 오류 최저점에서 멈춤 → 중간 크기 W. 단, 직교화를 깨는 단점.
- 강사는 L2 + λ 튜닝을 선호.
