# 13 Gradient Checking

## 개요
- **경사 검사(gradient checking, grad check)**: 역전파 구현이 맞는지 검증해 버그를 찾는 강력한 도구.

---

## 내용

### 절차
1. **모든 파라미터를 하나의 큰 벡터 θ로**: W⁽¹⁾, b⁽¹⁾, ..., W⁽ᴸ⁾, b⁽ᴸ⁾를 reshape·concatenate. → J는 이제 J(θ).
2. **모든 미분을 같은 순서로 dθ로**: dW⁽¹⁾, db⁽¹⁾, ... 를 reshape·concatenate (θ와 같은 차원).
3. **각 성분 i마다 양측 차분으로 근사**:
   ```
   dθ_approx[i] = [ J(θ₁,...,θᵢ+ε,...) − J(θ₁,...,θᵢ−ε,...) ] / (2ε)
   ```
   이 값이 dθ[i] (역전파가 준 미분)와 같아야 함.
4. **두 벡터가 가까운지 확인** — 유클리드 거리 비율:
   ```
   차이 = ‖dθ_approx − dθ‖₂ / (‖dθ_approx‖₂ + ‖dθ‖₂)
   ```

### 판정 기준 (ε = 10⁻⁷)
| 비율 값 | 판정 |
|---|---|
| ~10⁻⁷ 이하 | ✅ 정확할 가능성 높음 |
| ~10⁻⁵ | ⚠️ 점검 필요 (성분들이 너무 크지 않은지 확인) |
| ~10⁻³ 이상 | ❌ 버그 의심 — 심각하게 조사 |

- 값이 크면 **어느 i에서 dθ_approx[i]와 dθ[i]가 크게 다른지** 찾아 버그를 추적.
- 흐름: 순전파·역전파 구현 → grad check가 큰 값 → 디버깅 반복 → 작은 값 나오면 구현 신뢰.

---

## 요약
- 파라미터·미분을 각각 벡터 θ, dθ로 합침.
- 양측 차분으로 dθ_approx를 구해 dθ와의 상대 거리를 계산.
- 10⁻⁷ 수준이면 정상, 10⁻³ 이상이면 버그.
