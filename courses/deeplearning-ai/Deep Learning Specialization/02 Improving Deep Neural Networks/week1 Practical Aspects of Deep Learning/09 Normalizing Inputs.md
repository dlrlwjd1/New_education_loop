# 09 Normalizing Inputs

## 개요
- 입력 특징을 **정규화(normalize)** 하면 훈련 속도가 빨라진다.

---

## 내용

### 정규화 2단계
1. **평균 0으로(zero mean)**:
   ```
   μ = (1/m) Σ x⁽ⁱ⁾
   x := x − μ
   ```
2. **분산 1로(normalize variance)**:
   ```
   σ² = (1/m) Σ (x⁽ⁱ⁾)²   (평균 뺀 뒤, 원소별 제곱)
   x := x / σ
   ```
→ 각 특징의 분산이 1이 됨.

### ⚠️ test 세트도 같은 μ, σ 사용
- **훈련 세트에서 구한 μ, σ**로 test 세트도 변환. train/test를 **다르게** 정규화하면 안 됨.

### 왜 정규화하나 (직관)
- 특징들의 스케일이 크게 다르면(예: x₁ 1~1000, x₂ 0~1) 비용 함수가 **길쭉한 그릇(elongated bowl)** 모양 → 경사 하강이 지그재그로 진동, **작은 학습률**로 여러 스텝 필요.
- 정규화하면 비용 함수가 **더 둥근(spherical/symmetric)** 모양 → 어디서 시작하든 최소점으로 **곧장**, **큰 스텝** 가능 → 빠른 최적화.

### 실무
- 특징 범위가 비슷하면(0~1, −1~1, 1~2 등) 덜 중요.
- 스케일이 극단적으로 다르면(1~1000 vs 0~1) 매우 중요.
- 정규화는 **해가 없으니**, 도움 될지 불확실하면 그냥 해도 됨.

---

## 요약
- 입력 정규화 = 평균 0, 분산 1로 맞추기. test는 train의 μ,σ 사용.
- 스케일을 맞추면 비용 함수가 둥글어져 경사 하강이 빨라짐.
