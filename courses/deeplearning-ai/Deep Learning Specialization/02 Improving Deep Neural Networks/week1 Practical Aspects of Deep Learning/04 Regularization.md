# 04 Regularization

## 개요
- 과적합(high variance) 의심 시 가장 먼저 시도할 것: **정규화(regularization)** (또는 데이터 추가).
- 비용 함수에 가중치 크기 벌점(penalty)을 더해 과적합을 억제.

---

## 내용

### 로지스틱 회귀의 L2 정규화
```
J(w, b) = (1/m) Σ L(ŷ⁽ⁱ⁾, y⁽ⁱ⁾) + (λ/2m) ‖w‖₂²
‖w‖₂² = Σⱼ wⱼ² = wᵀw   (L2 norm = 유클리드 노름)
```
- **λ (lambda)** = 정규화 파라미터(하이퍼파라미터), dev 세트로 튜닝.
- **b는 보통 정규화하지 않음** — w는 고차원(파라미터 대부분)이고 b는 실수 하나뿐이라 영향이 미미.
- (프로그래밍 과제에선 `lambda`가 Python 예약어라 `lambd`로 표기)

### L1 vs L2
| | 특징 |
|---|---|
| **L2** (`‖w‖₂²`) | 가장 흔히 사용 |
| **L1** (`λ/m · Σ|wⱼ|`) | w가 **희소(sparse)** 해짐(0이 많음) → 모델 압축에 도움된다지만 실제 효과는 미미해 잘 안 씀 |

### 신경망의 L2 정규화
```
J = (1/m) Σ L(ŷ⁽ⁱ⁾, y⁽ⁱ⁾) + (λ/2m) Σₗ ‖W⁽ˡ⁾‖_F²
‖W⁽ˡ⁾‖_F² = Σᵢ Σⱼ (W⁽ˡ⁾ᵢⱼ)²
```
- 이 행렬 노름은 L2가 아니라 **프로베니우스 노름(Frobenius norm, ‖·‖_F)** 이라 부름 (관례상). 의미는 원소 제곱합.

### 경사 하강 & Weight Decay
- 역전파 dW⁽ˡ⁾에 정규화 항을 추가:
  ```
  dW⁽ˡ⁾ = (backprop 결과) + (λ/m) W⁽ˡ⁾
  W⁽ˡ⁾ := W⁽ˡ⁾ − α dW⁽ˡ⁾
  ```
- 정리하면:
  ```
  W⁽ˡ⁾ := (1 − αλ/m) W⁽ˡ⁾ − α(backprop 결과)
  ```
- **(1 − αλ/m)** 은 1보다 약간 작음 → 매 스텝 W를 조금씩 줄임 → **weight decay(가중치 감쇠)** 라고도 부름.

---

## 요약
- L2 정규화: 비용에 `(λ/2m)‖W‖²` 추가. λ는 dev로 튜닝. b는 대개 제외.
- 신경망에선 각 층 W의 프로베니우스 노름 제곱을 더함.
- 업데이트 시 W에 (1−αλ/m)을 곱하는 효과 → "weight decay".
