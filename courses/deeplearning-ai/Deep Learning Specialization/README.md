# Deep Learning Specialization

**Course URL:** https://learn.deeplearning.ai/specializations/deep-learning
**제공:** DeepLearning.AI
**강사:** Andrew Ng

## 개요
Andrew Ng이 진행하는 딥러닝(deep learning) 전문 과정. 5개 코스로 구성되며, 신경망 기초부터 CNN·시퀀스 모델·트랜스포머까지 다룬다. 모든 강의 노트는 한국어로 정리되어 있다 (강의 영상 기준, 퀴즈·프로그래밍 과제·읽기자료 제외).

## 코스 목록
1. **[Neural Networks and Deep Learning](01%20Neural%20Networks%20and%20Deep%20Learning/README.md)** — 신경망(neural network) 기초, 순전파/역전파, 심층 신경망
2. **[Improving Deep Neural Networks](02%20Improving%20Deep%20Neural%20Networks/README.md)** — 하이퍼파라미터 튜닝, 정규화, 최적화, Batch Norm
3. **[Structuring Machine Learning Projects](03%20Structuring%20Machine%20Learning%20Projects/README.md)** — ML 전략, 오류 분석, 전이/멀티태스크 학습
4. **[Convolutional Neural Networks](04%20Convolutional%20Neural%20Networks/README.md)** — CNN, 유명 아키텍처, 객체 탐지(YOLO/U-Net), 얼굴 인식, 스타일 트랜스퍼
5. **[Sequence Models](05%20Sequence%20Models/README.md)** — RNN/GRU/LSTM, 단어 임베딩, 어텐션, 트랜스포머
