# 04 Triplet Loss

## 개요
- 인코딩을 학습하는 목적 함수: **삼중항 손실(triplet loss)** — 세 이미지(A, P, N)를 동시에 비교.

---

## 내용

### 삼중항 (A, P, N)
- **Anchor(A)**: 기준 이미지.
- **Positive(P)**: A와 **같은 사람**.
- **Negative(N)**: A와 **다른 사람**.
- 목표: d(A, P) 는 작게, d(A, N) 은 크게.

### 손실 정의
```
‖f(A) − f(P)‖² − ‖f(A) − f(N)‖² + α ≤ 0
```
- **α (margin, 마진)**: 하이퍼파라미터. 자명한 해(모든 인코딩=0 또는 동일)를 막고 A-P와 A-N 사이에 **간격**을 강제.
  - 예: α=0.2, d(A,P)=0.5면 d(A,N)은 0.51로는 부족, **0.7 이상** 필요.
- 손실:
  ```
  L(A,P,N) = max( ‖f(A)−f(P)‖² − ‖f(A)−f(N)‖² + α , 0 )
  ```
  - 목표 달성(≤0)이면 손실 0, 아니면 양의 손실.
- 비용: `J = Σ L(A⁽ⁱ⁾, P⁽ⁱ⁾, N⁽ⁱ⁾)`.

### 데이터셋 요건
- **같은 사람의 여러 장**이 필요 (A-P 쌍을 만들려고). 예: 1,000명 × 평균 10장 = 1만 장.
- 학습 후엔 원샷(1장)으로 인식 가능.

### 삼중항 선택 (중요) ⭐
- A, P, N을 **무작위로** 고르면 d(A,N)≫d(A,P)라 조건이 너무 쉬워 학습이 안 됨.
- **어려운(hard) 삼중항** — d(A,P) ≈ d(A,N)인 경우 — 을 골라야 경사 하강이 실제로 일함 → 학습 효율↑. (FaceNet, Schroff 등)

### 실무
- 상용 얼굴 인식은 100만~1억 장으로 학습 → **사전 학습 모델 다운로드**가 유용.

---

## 요약
- Triplet loss: `max(d(A,P) − d(A,N) + α, 0)` → 같은 사람은 가깝게, 다른 사람은 마진 이상 멀게.
- 같은 사람 여러 장 필요. 어려운 삼중항을 골라 학습.
