# 11 1D and 3D Generalizations

## 개요
- 합성곱은 2D 이미지뿐 아니라 **1D·3D 데이터**에도 일반화된다.

---

## 내용

### 1D 데이터
- 예: **EKG(심전도)** — 시간에 따른 전압 시계열.
- 14차원 입력 * **5차원 1D 필터** → 10차원 출력.
- 채널·필터 다중: 14×1 * 5×1, 필터 16개 → 10×16 → (5×16 필터 32개) → 6×32.
- 1D 데이터는 보통 **RNN**(다음 코스)을 쓰지만 1D ConvNet도 가능. (장단점은 Course 5에서)

### 3D 데이터
- 예: **CT 스캔**(신체의 여러 슬라이스 = 3D 볼륨), 영화(시간 슬라이스로 동작 검출).
- 14×14×14 * **5×5×5 필터** → 10×10×10.
- 채널·필터 다중: 14×14×14×1 * 5×5×5×1, 필터 16개 → 10×10×10×16 → (5×5×5×16 필터 32개) → 6×6×6×32.

### 정리
- 2D의 아이디어(같은 필터를 여러 위치에 적용)가 1D·3D에도 동일하게 적용.
- 이미지가 흔해 대부분 2D ConvNet이지만 1D·3D도 유용.

---

## 요약
- 합성곱은 1D(시계열, EKG), 3D(CT·영화)로 일반화. 필터도 각각 1D·3D.
- 1D는 RNN이 흔하지만 1D ConvNet도 가능.
