# 09 Content Cost Function

## 개요
- **콘텐츠 비용 J_content(C, G)**: 생성 이미지 G가 콘텐츠 이미지 C와 내용상 얼마나 비슷한지.

---

## 내용

### 층 선택
- 콘텐츠 비용을 계산할 은닉층 **L** 선택.
- L이 너무 얕으면 → G의 **픽셀 값**이 C와 거의 같아지도록 강제(너무 빡빡).
- L이 너무 깊으면 → "C에 개가 있으면 G 어딘가에도 개가 있으면 됨" 수준(너무 느슨).
- 실무: **중간 층**을 선택.

### 정의
- 사전 학습된 ConvNet(예: VGG) 사용.
- a⁽ᴸ⁾⁽ᶜ⁾, a⁽ᴸ⁾⁽ᴳ⁾ = 층 L에서 C와 G의 활성값.
```
J_content(C, G) = ½ · ‖ a⁽ᴸ⁾⁽ᶜ⁾ − a⁽ᴸ⁾⁽ᴳ⁾ ‖²
```
- 두 활성값의 **원소별 차이 제곱합** (벡터로 펴면 L2 노름 제곱). 정규화 상수는 α로 조정 가능.
- 두 활성값이 비슷하면 두 이미지의 콘텐츠가 비슷 → 경사 하강이 G의 활성값을 C와 비슷하게 유도.

---

## 요약
- J_content = 중간 층 L에서 C와 G 활성값의 제곱 차이.
- 두 활성값이 가깝도록 G를 학습 → G가 C의 콘텐츠를 유지.
