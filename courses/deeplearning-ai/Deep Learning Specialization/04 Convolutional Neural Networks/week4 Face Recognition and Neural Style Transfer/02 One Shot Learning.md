# 02 One Shot Learning

## 개요
- 얼굴 인식의 난제: **원샷 학습(one-shot learning)** — **단 한 장의 이미지**만으로 그 사람을 인식해야 함.

---

## 내용

### 문제
- 직원 DB에 각자 사진 1장뿐. 새 사람이 오면 그 1장과 비교해 같은 사람인지 판단.
- **단순 softmax 접근(사람 수만큼 출력)** 은 실패:
  - 예제가 1장뿐이라 견고한 학습 불가.
  - 새 직원이 오면 출력 수가 바뀌어 **매번 재학습** 필요 → 부적절.

### 해결: 유사도 함수(similarity function) 학습 ⭐
- 두 이미지를 입력받아 **차이 정도 d(img1, img2)** 를 출력하는 함수를 학습.
  - 같은 사람 → d 작음, 다른 사람 → d 큼.
- 인식 시: d ≤ 임계값 τ(하이퍼파라미터)면 같은 사람, τ 초과면 다른 사람.

### recognition에 적용
- 새 이미지를 DB의 각 사진과 d로 비교 → d가 가장 작고 τ 이하인 사람으로 판정.
- 모두 크면 "DB에 없음".
- **원샷 문제 해결**: 새 사람은 DB에 사진 1장 추가만 하면 됨 (재학습 불필요).

---

## 요약
- 원샷 학습 = 1장으로 인식. softmax 대신 **유사도 함수 d(두 이미지→차이)** 를 학습.
- d ≤ τ면 동일인. 새 사람은 DB에 추가만 하면 됨.
