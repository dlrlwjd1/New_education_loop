# 08 Cost Function

## 개요
- 스타일 트랜스퍼는 생성 이미지 G에 대한 **비용 함수 J(G)** 를 정의하고 경사 하강으로 최소화해 이미지를 생성.

---

## 내용

### 비용 함수
```
J(G) = α · J_content(C, G) + β · J_style(S, G)
```
- **J_content(C, G)**: 생성 이미지 G의 **콘텐츠**가 C와 얼마나 유사한지.
- **J_style(S, G)**: G의 **스타일**이 S와 얼마나 유사한지.
- **α, β**: 상대 가중치 하이퍼파라미터. (하나면 충분해 보이지만 원저자 관례상 둘 사용. Gatys 등.)

### 생성 절차 ⭐
1. **G를 무작위로 초기화** (예: 100×100×3 white noise).
2. **경사 하강으로 J(G) 최소화**:
   ```
   G := G − (∂/∂G) J(G)
   ```
   - ⚠️ 갱신하는 대상이 파라미터가 아니라 **G의 픽셀 값 자체**.
3. 반복하면 G가 점점 **C의 콘텐츠 + S의 스타일** 이미지로 변함.

---

## 요약
- J(G) = α·콘텐츠 비용 + β·스타일 비용.
- G를 랜덤 초기화 후 경사 하강으로 **픽셀 값을 직접 갱신**해 이미지 생성.
