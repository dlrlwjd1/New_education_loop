# 03 Siamese Network

## 개요
- 유사도 함수 d를 구현하는 방법: **샴 네트워크(Siamese network)** — 같은 CNN에 두 이미지를 각각 통과시켜 인코딩을 비교.

---

## 내용

### 인코딩(encoding)
- CNN에 이미지 x를 넣어 (softmax 대신) 깊은 FC 층의 **128차원 벡터 f(x)** 를 얻음 = 이미지의 인코딩.

### 샴 네트워크
- **같은 파라미터**의 CNN에 두 이미지 x⁽ⁱ⁾, x⁽ʲ⁾를 각각 통과 → f(x⁽ⁱ⁾), f(x⁽ʲ⁾).
- 거리:
  ```
  d(x⁽ⁱ⁾, x⁽ʲ⁾) = ‖ f(x⁽ⁱ⁾) − f(x⁽ʲ⁾) ‖²
  ```
- (DeepFace, Taigman 등.)

### 학습 목표 ⭐
- 파라미터를 학습해:
  - **같은 사람**이면 `‖f(x⁽ⁱ⁾)−f(x⁽ʲ⁾)‖²` **작게**.
  - **다른 사람**이면 **크게**.
- 역전파로 모든 층의 파라미터를 조정해 이 조건을 만족시킴.

---

## 요약
- 샴 네트워크 = 같은 CNN으로 두 이미지의 128차원 인코딩을 구해 거리 비교.
- 같은 사람이면 인코딩 거리 작게, 다른 사람이면 크게 되도록 학습.
