# 05 Face Verification and Binary Classification

## 개요
- triplet loss 대신, 얼굴 검증을 **이진 분류(binary classification)** 로도 학습할 수 있다.

---

## 내용

### 이진 분류 방식
- 샴 네트워크로 두 이미지의 인코딩 f(x⁽ⁱ⁾), f(x⁽ʲ⁾)를 구한 뒤, **로지스틱 회귀 유닛**에 입력.
- 출력 ŷ = 1(같은 사람) / 0(다른 사람).

### 로지스틱 유닛 입력 (인코딩의 차이)
```
ŷ = σ( Σ_{k=1}^{128} w_k · |f(x⁽ⁱ⁾)_k − f(x⁽ʲ⁾)_k| + b )
```
- 두 인코딩의 **원소별 차이(절댓값)** 128개를 특징으로 사용, 가중치 w·b 학습.
- 변형: **카이제곱(χ²) 유사도** `(f_k − f'_k)² / (f_k + f'_k)` 등 (DeepFace 논문).

### 계산 트릭: 인코딩 사전 계산(pre-compute) ⭐
- DB 이미지의 인코딩을 **미리 계산·저장** → 새 사람이 올 때 그 사람 인코딩만 계산해 비교.
- 원본 이미지 저장 불필요, 매번 재계산 불필요 → 큰 DB에서 계산 절약.
- (triplet loss 방식에도 동일하게 적용 가능.)

### 학습
- 입력: **이미지 쌍(pair)**, 라벨: 같은 사람=1 / 다른 사람=0.
- 샴 네트워크(두 CNN 파라미터 공유)를 역전파로 학습.

---

## 요약
- 얼굴 검증 = 인코딩 차이를 로지스틱 회귀에 넣는 이진 분류로도 학습 가능(triplet loss 대안).
- 이미지 쌍(같은/다른 사람) + 라벨(1/0)로 학습. 인코딩 사전 계산으로 배포 효율↑.
