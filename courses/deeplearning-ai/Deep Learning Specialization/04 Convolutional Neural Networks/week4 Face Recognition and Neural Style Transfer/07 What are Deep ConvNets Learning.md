# 07 What are Deep ConvNets Learning?

## 개요
- 각 층의 은닉 유닛이 무엇을 검출하는지 시각화 → 스타일 트랜스퍼 직관의 기초. (Zeiler & Fergus 논문)

---

## 내용

### 시각화 방법
- 각 은닉 유닛에 대해, 훈련 세트에서 **그 유닛의 활성값을 최대화하는 이미지 패치** 9개를 찾아 표시.
- 얕은 층 유닛은 이미지의 **작은 영역(receptive field)** 만 봄 → 작은 패치. 깊은 층은 더 큰 영역.

### 층이 깊어질수록 복잡해지는 특징 ⭐
| 층 | 검출하는 것 |
|---|---|
| Layer 1 | 단순한 **엣지, 특정 색** |
| Layer 2 | 더 복잡한 **텍스처·패턴** (세로 줄무늬, 둥근 모양) |
| Layer 3 | 특정 **텍스처, 물체 일부** (자동차, 사람의 일부, 벌집 무늬) |
| Layer 4 | **복잡한 물체** (개, 물, 새 다리) |
| Layer 5 | 더 정교한 것 (다양한 개, 키보드, 텍스트, 꽃) |

- 얕은 층(단순) → 깊은 층(복잡한 물체)로 계층적 표현.

---

## 요약
- 얕은 층은 엣지·색, 깊은 층은 텍스처→물체 일부→복잡한 물체로 점점 복잡한 특징을 검출.
- 이 직관을 스타일 트랜스퍼에 활용.
