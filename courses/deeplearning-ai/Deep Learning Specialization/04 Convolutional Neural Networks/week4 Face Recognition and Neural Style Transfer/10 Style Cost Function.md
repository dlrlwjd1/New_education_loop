# 10 Style Cost Function

## 개요
- **스타일 비용 J_style(S, G)**: 스타일 = **한 층에서 채널 간 활성값의 상관(correlation)**.

---

## 내용

### 스타일 = 채널 간 상관
- 층 L의 활성값(n_H × n_W × n_C)에서, **서로 다른 채널들이 얼마나 함께 활성화되는지**(상관)를 스타일로 정의.
- 직관: 채널1(세로 텍스처) & 채널2(주황 색조)가 상관 높음 = "세로 텍스처가 있는 곳엔 주황빛이 함께 나타남" → 이런 고수준 특징의 공동 출현 패턴이 화풍.

### 스타일 행렬 (Gram matrix)
- a⁽ᴸ⁾_{ijk} = 층 L, 위치 (i=높이, j=너비), 채널 k의 활성값.
- 스타일 행렬 **G⁽ᴸ⁾ (n_C × n_C)**:
  ```
  G⁽ᴸ⁾_{kk'} = Σᵢ Σⱼ a⁽ᴸ⁾_{ijk} · a⁽ᴸ⁾_{ijk'}
  ```
  - 채널 k와 k'의 활성값을 모든 위치에서 곱해 합 (비정규화 교차 공분산). 둘이 함께 크면 값 큼.
- **Gram matrix(그람 행렬)** 라 부름 (그래서 기호 G).
- 스타일 이미지 S와 생성 이미지 G 각각에 대해 계산: G⁽ᴸ⁾⁽ˢ⁾, G⁽ᴸ⁾⁽ᴳ⁾.

### 스타일 비용 (한 층)
```
J_style⁽ᴸ⁾(S, G) = ‖ G⁽ᴸ⁾⁽ˢ⁾ − G⁽ᴸ⁾⁽ᴳ⁾ ‖²_F   (프로베니우스 노름 제곱, 정규화 상수 포함)
```

### 여러 층 결합 ⭐
- 여러 층의 스타일 비용을 합치면 시각적으로 더 좋음:
  ```
  J_style(S, G) = Σₗ λ⁽ˡ⁾ · J_style⁽ˡ⁾(S, G)
  ```
- 얕은 층(저수준: 엣지)과 깊은 층(고수준) 상관을 모두 반영. λ⁽ˡ⁾는 하이퍼파라미터.

### 최종
```
J(G) = α · J_content(C, G) + β · J_style(S, G)
```
→ 경사 하강으로 G를 최적화.

---

## 요약
- 스타일 = 채널 간 상관 → Gram matrix G_{kk'} = Σ a_{ijk}a_{ijk'}.
- J_style = S와 G의 Gram 행렬 차이(프로베니우스²), 여러 층 가중합.
