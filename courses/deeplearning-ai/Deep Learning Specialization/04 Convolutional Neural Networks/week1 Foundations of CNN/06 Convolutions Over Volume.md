# 06 Convolutions Over Volume

## 개요
- 2D가 아니라 **3D 볼륨(RGB 등)** 에 대한 합성곱과, **여러 필터**를 동시에 쓰는 법.

---

## 내용

### 볼륨 합성곱
- RGB 이미지 = 6×6×**3** (채널 3). 필터도 3×3×**3** (채널 수가 이미지와 **일치해야** 함).
- 필터의 27개(3³) 값을 대응하는 27개 픽셀과 곱해 합산 → 출력의 한 값.
- **6×6×3 * 3×3×3 = 4×4×1** (2D 출력).

### 필터 설계 예
- 빨강 채널만 엣지 검출: R=`[1 0 -1;...]`, G=0, B=0.
- 색 무관 엣지: 세 채널 모두 `[1 0 -1;...]`.

### 여러 필터 동시 사용 ⭐
- 수직 + 수평(+45도 등) 여러 특징을 동시에 검출하려면 **여러 필터** 사용.
- 각 필터가 4×4 출력 하나 → 필터 2개면 **4×4×2**로 쌓임.

### 차원 공식
```
n×n×n_C  *  f×f×n_C  →  (n−f+1) × (n−f+1) × n_C'
```
- n_C = 입력 채널 수 (필터와 동일), **n_C' = 필터 개수** (= 출력 채널 수).
- stride/padding 쓰면 앞 두 차원은 앞서 본 대로 조정.

### 용어
- 마지막 차원 = **채널(channel)** 또는 depth. (강사는 "채널"로 통일 — depth는 신경망 깊이와 혼동)

---

## 요약
- 볼륨 합성곱: 필터 채널 수 = 입력 채널 수. 6×6×3 * 3×3×3 → 4×4.
- 필터 K개를 쓰면 출력 채널이 K → 여러 특징 동시 검출.
