# 10 CNN Example

## 개요
- Conv + Pool + FC를 조합한 완전한 CNN 예제 (LeNet-5에서 영감, 손글씨 숫자 인식).

---

## 내용

### 예제 아키텍처 (입력 32×32×3)
| 층 | 연산 | 출력 |
|---|---|---|
| 입력 | | 32×32×3 |
| Conv1 | 5×5, s=1, 6필터 | 28×28×6 |
| Pool1 | max, f=2, s=2 | 14×14×6 |
| Conv2 | 5×5, s=1, 16필터 | 10×10×16 |
| Pool2 | max, f=2, s=2 | 5×5×16 |
| FC3 | flatten(400) → 120 | 120 |
| FC4 | 120 → 84 | 84 |
| Softmax | 84 → 10 | 10 |

### 층 세는 관례 ⚠️
- **가중치가 있는 층만 센다** → Conv1+Pool1을 **layer 1**로 묶음 (Pool은 파라미터 없음).

### FC 층
- Pool2(5×5×16=400)를 **평탄화** → 400.
- FC = 표준 신경망 층 (W³: 120×400, 각 유닛이 모두 연결).

### 관찰 ⭐
- 깊어질수록 **H·W 감소**(32→28→14→10→5), **채널 증가**(3→6→16).
- 흔한 패턴: **Conv→Pool 반복 → FC 몇 개 → Softmax**.
- 파라미터: Pool은 0, **Conv는 적음**, **대부분 FC에 몰림**.
- 활성값 크기는 깊어질수록 서서히 감소(급감하면 성능에 안 좋음).

### 실무 조언
- 하이퍼파라미터를 직접 발명하기보다 **문헌에서 검증된 아키텍처를 참고**해 사용.

---

## 요약
- CNN = Conv→Pool 반복 → FC → Softmax. 깊어질수록 H·W↓, 채널↑.
- 파라미터 대부분은 FC에, Pool은 0, Conv는 적음.
