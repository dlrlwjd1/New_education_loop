# 08 Simple Convolutional Network Example

## 개요
- 구체적인 CNN 예제로 전체 흐름과 표기법을 익힌다.

---

## 내용

### 예제 (고양이 분류)
| 층 | 필터 | stride | 필터 수 | 출력 |
|---|---|---|---|---|
| 입력 | | | | 39×39×3 |
| Conv1 | 3×3 | 1 | 10 | 37×37×10 |
| Conv2 | 5×5 | 2 | 20 | 17×17×20 |
| Conv3 | 5×5 | 2 | 40 | 7×7×40 |
- 출력 크기 = ⌊(n+2p−f)/s+1⌋ (예: (39−3)/1+1=37).

### 마지막 단계
- 7×7×40 = **1,960개**를 **평탄화(flatten)** → 긴 벡터.
- 이를 **로지스틱 회귀 / softmax** 유닛에 넣어 최종 예측.

### 일반적 경향 ⭐
- 깊어질수록 **높이·너비는 감소**(39→37→17→7), **채널은 증가**(3→10→20→40).
- CNN 설계의 많은 부분 = **하이퍼파라미터 선택**(필터 크기, stride, padding, 필터 수).

### CNN의 3가지 층 유형
1. **Convolutional (Conv)** — 지금까지 본 것.
2. **Pooling (Pool)** — 다음 영상.
3. **Fully Connected (FC)** — 완전연결.
- 대부분의 CNN은 Conv + Pool + FC를 조합.

---

## 요약
- CNN 예: Conv 여러 층으로 39×39×3 → 7×7×40 → flatten → softmax.
- 깊어질수록 H·W↓, 채널↑. 층 유형 3가지: Conv, Pool, FC.
