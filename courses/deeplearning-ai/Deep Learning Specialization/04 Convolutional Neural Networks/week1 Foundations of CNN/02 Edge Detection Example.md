# 02 Edge Detection Example

## 개요
- **합성곱(convolution)** 은 CNN의 기본 연산. 엣지 검출(edge detection)로 원리를 이해한다.

---

## 내용

### 합성곱 연산
- 입력 이미지(예: 6×6)를 **필터(filter, = kernel)** (예: 3×3)와 합성곱(`*`) → 출력(4×4).
- 계산: 필터를 이미지 위에 겹쳐 **원소별 곱의 합**을 구하고, 필터를 한 칸씩 이동하며 반복.
- 표기 `*`: 수학에선 합성곱, Python에선 곱셈 → 문맥 주의.
- 차원: **6×6 * 3×3 = 4×4**.

### 수직 엣지 검출 필터
```
[ 1  0  -1 ]
[ 1  0  -1 ]
[ 1  0  -1 ]
```
- **왼쪽 밝고(양수) 오른쪽 어두운(음수)** 3×3 영역을 찾는다 (가운데는 무관).

### 예시: 좌 밝고(10) 우 어두운(0) 이미지
- 이 필터로 합성곱하면 **가운데에 밝은 띠**가 나옴 → 수직 엣지 검출됨.
- (작은 6×6라 엣지가 두껍게 보이지만, 1000×1000 이미지에선 정확히 검출.)

### 프레임워크 함수
- `conv_forward`(과제), TensorFlow `tf.nn.conv2d`, Keras `Conv2D` 등.

---

## 요약
- 합성곱 = 필터를 이미지에 겹쳐 원소별 곱의 합을 이동하며 계산 (6×6 * 3×3 → 4×4).
- 수직 엣지 필터 `[1 0 -1; 1 0 -1; 1 0 -1]`는 좌-밝고 우-어두운 경계를 검출.
