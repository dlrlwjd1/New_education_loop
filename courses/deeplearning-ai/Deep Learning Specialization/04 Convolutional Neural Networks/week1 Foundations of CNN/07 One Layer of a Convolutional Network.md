# 07 One Layer of a Convolutional Network

## 개요
- 합성곱 + 편향 + 비선형(ReLU)으로 **CNN 한 층**을 구성.

---

## 내용

### 한 층의 계산
```
각 필터로 합성곱 → 4×4 출력 → + 편향 b (브로드캐스팅) → ReLU → 4×4
필터 2개면 두 4×4를 쌓아 4×4×2
```
- 완전연결망 순전파와 대응:
  - `z⁽¹⁾ = W⁽¹⁾a⁽⁰⁾ + b⁽¹⁾` ↔ (합성곱 결과) + 편향.
  - `a⁽¹⁾ = g(z⁽¹⁾)` ↔ ReLU 적용.
  - 필터 = W⁽¹⁾ 역할, 입력 = a⁽⁰⁾.
- 6×6×3 → (필터 K개) → 4×4×K.

### 파라미터 수 (과적합 방지의 핵심) ⭐
- 필터 하나(3×3×3) = 27 + 편향 1 = **28개**.
- 필터 10개 = **280개**.
- **입력 이미지가 아무리 커도(1000×1000, 5000×5000) 파라미터 수는 고정(280)** → 큰 이미지에도 적은 파라미터, **과적합에 강함**.

### 층 l 표기법
| 표기 | 의미 |
|---|---|
| f⁽ˡ⁾ | 필터 크기 |
| p⁽ˡ⁾ | 패딩 |
| s⁽ˡ⁾ | 스트라이드 |
| 입력 | n_H⁽ˡ⁻¹⁾ × n_W⁽ˡ⁻¹⁾ × n_C⁽ˡ⁻¹⁾ |
| 출력 | n_H⁽ˡ⁾ × n_W⁽ˡ⁾ × n_C⁽ˡ⁾ |
| 각 필터 | f⁽ˡ⁾ × f⁽ˡ⁾ × n_C⁽ˡ⁻¹⁾ |
| 필터 개수 | n_C⁽ˡ⁾ (= 출력 채널 수) |

- 출력 크기: `n⁽ˡ⁾ = ⌊(n⁽ˡ⁻¹⁾ + 2p⁽ˡ⁾ − f⁽ˡ⁾)/s⁽ˡ⁾ + 1⌋` (H·W 각각).
- 활성값 A⁽ˡ⁾: (m × n_H × n_W × n_C) (미니배치 m개).
- 가중치: f⁽ˡ⁾×f⁽ˡ⁾×n_C⁽ˡ⁻¹⁾×n_C⁽ˡ⁾, 편향: n_C⁽ˡ⁾개.
- ⚠️ 채널을 앞/뒤 어디에 두는지는 **표준이 없음** (강사는 H, W, C 순).

---

## 요약
- CNN 한 층 = 합성곱(선형) + 편향 + ReLU. 6×6×3 → 4×4×K.
- 파라미터 수는 입력 크기와 무관하게 필터 수로 고정 → 과적합에 강함.
- 표기: f, p, s, 필터 = f×f×n_C⁽ˡ⁻¹⁾, 출력 채널 = 필터 개수.
