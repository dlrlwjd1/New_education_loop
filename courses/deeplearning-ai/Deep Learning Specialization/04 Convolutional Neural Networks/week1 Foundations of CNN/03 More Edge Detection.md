# 03 More Edge Detection

## 개요
- 양/음 엣지(밝→어두 vs 어두→밝), 수평 엣지 필터, 그리고 **필터를 학습(learn)하는** 아이디어.

---

## 내용

### 양의 엣지 vs 음의 엣지
- 좌-밝 우-어두 → +30 (밝→어두 전환).
- 좌-어두 우-밝 → −30 (어두→밝 전환).
- 전환 방향을 구분하지 않으려면 출력의 **절댓값**을 취함.

### 수평 엣지 검출 필터
```
[  1   1   1 ]
[  0   0   0 ]
[ -1  -1  -1 ]
```
- 위-밝고 아래-어두운 영역을 검출.

### 유명한 필터들 (수직 엣지)
| 필터 | 값 |
|---|---|
| 기본 | `[1 0 -1; 1 0 -1; 1 0 -1]` |
| **Sobel** | `[1 0 -1; 2 0 -2; 1 0 -1]` (중앙 행에 가중치↑, 더 robust) |
| **Scharr** | `[3 0 -3; 10 0 -10; 3 0 -3]` |
- 90도 회전하면 수평 엣지용.

### 핵심 아이디어: 필터를 학습하기 ⭐
- 9개 숫자를 손으로 정하지 말고 **파라미터로 두고 역전파(backprop)로 학습**.
- 그러면 Sobel/Scharr 같은 것뿐 아니라 **45도, 73도 등 임의 방향 엣지**나 이름 없는 특징까지, 데이터 통계에 맞게 더 robust하게 학습 가능.
- 이것이 컴퓨터 비전에서 가장 강력한 아이디어 중 하나.

---

## 요약
- 양/음 엣지 구분(절댓값으로 무시 가능), 수평 필터는 수직 필터를 회전.
- Sobel/Scharr 등 수작업 필터가 있지만, **필터 9개를 파라미터로 학습**하는 것이 핵심.
