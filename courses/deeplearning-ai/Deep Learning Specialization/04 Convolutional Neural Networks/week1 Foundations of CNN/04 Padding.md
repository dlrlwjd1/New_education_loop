# 04 Padding

## 개요
- **패딩(padding)**: 합성곱 전에 이미지 테두리에 (0으로) 여백을 덧대는 것. 이미지 축소와 가장자리 정보 손실 문제를 해결.

---

## 내용

### 패딩 없는 합성곱의 문제
- n×n 이미지 * f×f 필터 → **(n−f+1) × (n−f+1)** 출력.
- 문제 1: 합성곱마다 **이미지가 줄어든다** (6×6→4×4). 층이 깊으면 계속 작아짐.
- 문제 2: **가장자리·모서리 픽셀은 출력에 적게 반영** → 가장자리 정보 손실.

### 패딩
- 테두리를 p픽셀만큼 0으로 덧댐 (예: p=1 → 6×6이 8×8).
- 출력 크기: **(n+2p−f+1) × (n+2p−f+1)**.
- p=1, 3×3 필터면 6×6 유지.

### Valid vs Same 합성곱
| 종류 | 패딩 | 출력 |
|---|---|---|
| **Valid** | p=0 (없음) | (n−f+1) |
| **Same** | 입력=출력 크기 유지 | n |
- Same 패딩: `p = (f−1)/2` (f가 홀수일 때).
  - f=3 → p=1, f=5 → p=2.

### 필터는 보통 홀수(odd)
- f가 짝수면 비대칭 패딩이 필요; 홀수면 대칭 패딩 가능.
- 홀수 필터는 **중앙 픽셀(central position)** 이 있어 편리.
- 실무: 3×3, 5×5, 7×7 (그리고 나중에 1×1). 홀수 권장.

---

## 요약
- 패딩으로 이미지 축소·가장자리 손실 방지. 출력 = (n+2p−f+1).
- Valid(p=0), Same(p=(f−1)/2로 크기 유지). 필터는 보통 홀수.
