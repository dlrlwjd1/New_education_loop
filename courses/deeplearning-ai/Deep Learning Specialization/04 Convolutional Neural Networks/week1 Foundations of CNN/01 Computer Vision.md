# 01 Computer Vision

## 개요
- 컴퓨터 비전(computer vision)은 딥러닝으로 빠르게 발전 중 (자율주행, 얼굴 인식, 이미지 추천, 예술 생성 등).
- 큰 이미지를 다루려면 **합성곱(convolution)** 연산이 필수.

---

## 내용

### 컴퓨터 비전 문제 예시
- **이미지 분류(image classification)**: 예) 64×64 이미지 → 고양이인가?
- **물체 검출(object detection)**: 여러 물체의 위치를 박스로 표시 (자율주행 등).
- **뉴럴 스타일 트랜스퍼(neural style transfer)**: content 이미지를 style 이미지(예: 피카소) 스타일로 재생성.

### 왜 합성곱이 필요한가 (큰 입력 문제)
- 64×64×3 = **12,288** 입력 특징 → 괜찮음.
- 1000×1000×3 = **300만** 입력 특징.
- 완전연결망(fully connected)으로 첫 은닉층 유닛이 1,000개면 W⁽¹⁾은 **1000 × 300만 = 30억 파라미터**.
  - → 과적합 방지할 데이터 확보 어렵고, 계산·메모리도 비현실적.
- 큰 이미지를 다루려면 **합성곱 연산**이 필요 (CNN의 기본 구성 요소).

---

## 요약
- 컴퓨터 비전 = 분류/검출/스타일 트랜스퍼 등. 딥러닝으로 급성장.
- 큰 이미지는 완전연결망이면 파라미터 폭발 → **합성곱(convolution)** 으로 해결.
