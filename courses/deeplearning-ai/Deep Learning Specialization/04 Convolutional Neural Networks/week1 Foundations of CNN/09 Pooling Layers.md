# 09 Pooling Layers

## 개요
- **풀링 층(pooling layer)**: 표현 크기를 줄여 계산을 빠르게 하고, 검출 특징을 더 robust하게.

---

## 내용

### Max Pooling
- 입력을 영역으로 나눠 각 영역의 **최댓값**을 출력.
- 예: 4×4 → (f=2, s=2) → 2×2 (각 2×2 영역의 max).
- 직관: 어떤 특징이 그 영역 **어디에든 검출되면** 큰 값이 출력에 보존됨. (다만 실제로 잘 되는 이유는 명확치 않고, 경험적으로 잘 작동)
- 출력 크기 공식은 합성곱과 동일: ⌊(n+2p−f)/s+1⌋.
- **3D 입력**: 각 채널에 **독립적으로** 적용 → 5×5×2 → 3×3×2 (채널 수 유지).

### Average Pooling
- 최댓값 대신 **평균**. 요즘은 max pooling이 훨씬 많이 쓰임.
- 예외: 아주 깊은 층에서 7×7×1000 → **1×1×1000** 으로 축약할 때 사용.

### 핵심: 학습 파라미터가 없다 ⭐
- 풀링은 **하이퍼파라미터(f, s, max/avg)만 있고 학습 파라미터가 없음**.
- 역전파에서 갱신할 것이 없는 **고정 함수**.

### 하이퍼파라미터
- f=2, s=2 (흔함, H·W를 약 절반으로). f=3, s=2 도 사용.
- 패딩은 거의 안 씀 (p=0).
- 입력 n_H×n_W×n_C → 출력 ⌊(n−f)/s+1⌋ × ... × **n_C** (채널 유지).

---

## 요약
- Max pooling = 영역별 최댓값, 채널마다 독립. 크기 축소 + robust.
- 학습 파라미터 없음(고정 함수). 흔한 설정 f=2, s=2.
