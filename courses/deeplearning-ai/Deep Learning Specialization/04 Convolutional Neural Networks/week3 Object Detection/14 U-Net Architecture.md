# 14 U-Net Architecture

## 개요
- U-Net 아키텍처의 상세 구성. 이름은 그림이 **U자 모양**이라 붙음. (Ronneberger 등, 원래 생의학 영상 분할용)

---

## 내용

### 전체 흐름 (U자)
입력 H×W×3 →
1. **수축 경로(왼쪽, 내려가기)**:
   - `Conv + ReLU`(검은 화살표) 반복 → 채널↑.
   - 중간중간 **Max pooling** → H·W↓, 채널↑.
   - 바닥에서 H·W가 매우 작아짐.
2. **확장 경로(오른쪽, 올라가기)**:
   - **Transpose conv**(초록 화살표) → H·W↑, 채널↓.
   - **Skip connection**(회색 화살표): 왼쪽 대응 층의 활성값을 **복사해 이어붙임** (진한 파랑=복사, 연한 파랑=전치 합성곱 결과).
   - `Conv + ReLU` 반복.
3. 원본 H×W 복원 후 **1×1 conv**(마젠타 화살표)로 분할 맵 출력.

### 출력
- **H × W × (클래스 수)**.
- 각 픽셀마다 클래스별 확률 벡터 → **argmax**로 픽셀 클래스 결정 → 분할 맵 시각화.

---

## 요약
- U-Net = 수축(conv+pool) → 확장(transpose conv) + skip connection → 1×1 conv로 H×W×클래스 출력.
- 각 픽셀을 argmax로 분류해 분할 맵 생성.
