# 05 Bounding Box Predictions (YOLO)

## 개요
- **YOLO (You Only Look Once)**: 이미지에 격자(grid)를 씌우고 각 셀에 위치추정 알고리즘을 적용해 **정확한 바운딩 박스**를 출력.

---

## 내용

### YOLO 기본
- 이미지에 격자(예: 3×3, 실제로는 19×19)를 씌움.
- 각 셀마다 라벨 y = `[P_c, b_x, b_y, b_h, b_w, c1, c2, c3]` (8차원).
- 출력 볼륨 = **격자 × 8** (3×3 격자면 **3×3×8**, 19×19면 19×19×8).

### 물체 할당 규칙 ⭐
- 각 물체의 **중심점(midpoint)** 이 있는 셀에 그 물체를 할당.
- 물체가 여러 셀에 걸쳐도 **중심이 속한 한 셀에만** 할당.
- 격자를 촘촘히(19×19) 하면 한 셀에 두 물체가 들어갈 확률↓.

### 학습
- 입력 100×100×3 → CNN(conv/maxpool) → **3×3×8** 출력. 역전파로 학습.
- 장점: ① 바운딩 박스 좌표를 명시적으로 출력(임의 종횡비·정밀 좌표), ② **합성곱 구현** — 격자 수만큼 반복하지 않고 한 번의 순전파로 계산 공유 → **매우 빠름(실시간 검출 가능)**.

### 박스 좌표 인코딩
- 셀 기준 좌상단 (0,0), 우하단 (1,1).
- **b_x, b_y** (중심): 셀 내부이므로 **0~1 사이**.
- **b_h, b_w** (높이·너비): 셀 크기 대비 비율 → 물체가 셀보다 크면 **1보다 클 수 있음**.
- (논문엔 sigmoid로 0~1, exp로 비음수 보장하는 더 나은 파라미터화도 있음.)

> 참고: YOLO 논문은 읽기 어려운 편 (숙련 연구자도 세부 파악에 애먹음).

---

## 요약
- YOLO = 격자 셀마다 [P_c, 박스, 클래스] 출력, 물체는 중심이 속한 셀에 할당.
- 합성곱 구현으로 빠름(실시간). 박스 중심은 0~1, 높이·너비는 1 초과 가능.
