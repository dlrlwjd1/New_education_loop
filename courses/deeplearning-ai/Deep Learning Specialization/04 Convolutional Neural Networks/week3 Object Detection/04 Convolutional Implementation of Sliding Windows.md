# 04 Convolutional Implementation of Sliding Windows

## 개요
- 슬라이딩 윈도우를 **합성곱으로 구현**해, 여러 창의 중복 계산을 공유하며 한 번의 순전파로 처리.

---

## 내용

### 먼저: FC 층을 합성곱으로 변환
- 예: 5×5×16 → FC 400 → ... → softmax 4.
- FC(400)를 **5×5×16 필터 400개** 합성곱으로 대체 → 1×1×400 (수학적으로 FC와 동일).
- 이후 FC는 **1×1 conv**로 대체 → 1×1×400 → 1×1×4.

### 슬라이딩 윈도우의 합성곱 구현 (OverFeat)
- 14×14 입력용 CNN을 16×16 테스트 이미지에 적용:
  - 기존: 4개 창을 각각 CNN에 4번 통과 (중복 계산 많음).
  - 합성곱 구현: **전체 이미지를 한 번** 통과 → **2×2×4** 출력 (4개 창 결과가 각 위치에 대응).
- 공통 영역의 계산을 **공유** → 훨씬 효율적.
- 더 큰 예: 28×28 입력 → 8×8×4 출력 (stride 2로 슬라이딩한 것과 동일, max pool의 2가 stride 2에 해당).

### 남은 약점 ⚠️
- 바운딩 박스 위치가 **정확하지 않음** → 다음 영상(YOLO의 박스 예측)에서 해결.

---

## 요약
- FC를 1×1 conv로 바꾸면, 슬라이딩 윈도우를 **한 번의 순전파**로 모든 위치를 동시에 예측 → 계산 공유로 효율↑.
- 단, 박스 위치 정확도가 떨어짐.
