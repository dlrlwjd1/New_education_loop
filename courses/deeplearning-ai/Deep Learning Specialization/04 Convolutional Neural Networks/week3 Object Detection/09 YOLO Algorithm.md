# 09 YOLO Algorithm

## 개요
- 지금까지의 구성 요소(격자, 앵커, IoU, non-max suppression)를 합쳐 **YOLO 물체 검출 알고리즘** 완성.

---

## 내용

### 훈련 세트 구성
- 3 클래스(보행자/차/오토바이), 앵커 2개 → 출력 Y = **3×3×2×8** (또는 3×3×16).
  - 8 = 5(P_c + 박스 4개) + 3(클래스 수).
- 각 격자 셀마다 타깃 벡터 y 작성:
  - 아무것도 없으면 두 앵커의 P_c=0, 나머지 don't care.
  - 자동차가 있으면 IoU 높은 앵커(예: 앵커2)에 P_c=1·박스·클래스 인코딩, 다른 앵커는 P_c=0.
- 실무: 19×19×2×8, 앵커 5개면 19×19×40.

### 예측
- CNN이 100×100×3 → 3×3×2×8 출력.
- 물체 없는 셀: P_c=0 (나머지 숫자는 노이즈로 무시).
- 물체 있는 셀: 정확한 박스·클래스 출력.

### Non-max suppression으로 마무리
1. 각 셀에서 앵커 수만큼(2개) 박스 예측 (박스가 셀 밖으로 나갈 수도).
2. **낮은 확률 예측 제거**.
3. **클래스마다 독립적으로** non-max suppression 실행(보행자/차/오토바이 각각).
→ 최종 검출 결과.

---

## 요약
- YOLO = 격자 + 앵커로 [P_c, 박스, 클래스]를 예측 → 낮은 확률 제거 → 클래스별 non-max suppression.
- 가장 효과적인 물체 검출 알고리즘 중 하나.
