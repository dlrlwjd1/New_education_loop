# 07 Non-max Suppression

## 개요
- **Non-max suppression(비최대 억제)**: 한 물체가 여러 번 검출되는 것을 막아 **물체당 하나의 검출**만 남긴다.

---

## 내용

### 문제
- 격자 셀마다 분류/위치추정을 돌리므로, 한 자동차 주변 여러 셀이 "내가 중심을 갖고 있다"고 검출 → **중복 검출**.

### 알고리즘 (단일 클래스 기준)
1. **낮은 확률 박스 제거**: P_c ≤ 임계값(예: 0.6)인 박스 모두 폐기.
2. 남은 박스 중 **P_c가 가장 높은 것을 선택**해 예측으로 출력.
3. 그 박스와 **IoU가 높은(많이 겹치는) 나머지 박스를 제거**(suppress).
4. 남은 박스가 없을 때까지 2~3 반복.

- 즉 **최댓값(max) 박스는 남기고, 그와 겹치는 비최대(non-max) 박스는 억제**.

### 여러 클래스
- 클래스가 3개(보행자/차/오토바이)면 **클래스마다 독립적으로** non-max suppression을 3번 수행.

---

## 요약
- non-max suppression = 낮은 확률 박스 제거 → 최고 확률 박스 선택 → 겹치는(IoU 높은) 박스 억제 반복.
- 물체당 하나의 검출만 남김. 다중 클래스는 클래스별로 수행.
