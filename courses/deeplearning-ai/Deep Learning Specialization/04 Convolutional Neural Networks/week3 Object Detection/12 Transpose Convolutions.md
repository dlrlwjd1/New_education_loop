# 12 Transpose Convolutions

## 개요
- **전치 합성곱(transpose convolution)**: 작은 입력을 **더 큰 출력**으로 키우는 연산 (예: 2×2 → 4×4). U-Net의 핵심.

---

## 내용

### 일반 vs 전치
- **일반 합성곱**: 6×6×3 * 3×3×3 필터 5개 → **4×4×5** (작아짐).
- **전치 합성곱**: 2×2 입력 * 3×3 필터 → **4×4** (커짐).

### 동작 방식 (예: 2×2 → 4×4, f=3, p=1, s=2)
- 일반 합성곱은 필터를 **입력**에 놓지만, 전치 합성곱은 필터를 **출력**에 놓는다.
1. 입력의 각 원소를 **필터 전체에 곱해**, 그 3×3 결과를 출력의 해당 위치에 **붙여넣기(paste)**.
2. 패딩 영역은 무시.
3. **stride만큼** 붙여넣는 위치를 이동 (s=2면 2칸씩).
4. 겹치는 영역은 **값을 더한다(add)**.
- 모든 위치를 처리하면 4×4 출력 완성.

### 왜 이 방식인가
- 작은 입력을 크게 만드는 방법은 여럿이지만, 전치 합성곱은 **효과적**이며 필터 파라미터를 학습하면 U-Net에서 좋은 결과.

---

## 요약
- 전치 합성곱 = 필터를 출력에 놓고, 입력 원소×필터를 stride 간격으로 붙여넣으며 겹치면 더함 → 입력을 확대.
- U-Net에서 해상도를 키우는 데 사용.
