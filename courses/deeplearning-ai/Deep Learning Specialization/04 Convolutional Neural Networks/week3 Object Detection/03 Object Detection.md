# 03 Object Detection

## 개요
- **슬라이딩 윈도우 검출(sliding windows detection)**: 창을 이미지 전체에 밀어가며 각 영역을 CNN으로 분류.

---

## 내용

### 방법
1. **꽉 잘린(closely cropped)** 자동차 이미지로 CNN을 학습 (입력=차 이미지, 출력=차 여부 0/1).
2. 테스트 이미지에서 특정 크기의 창을 잡아 CNN에 넣고 차 유무 예측.
3. 창을 일정 **stride**로 이동하며 전 위치를 분류.
4. 창 크기를 키워가며 반복(작은 창 → 큰 창).
- 어딘가에 차가 있으면 어느 창에서 1이 나와 검출됨.

### 단점: 계산 비용 ⚠️
- 수많은 영역을 잘라 **각각 독립적으로 CNN에 통과** → 매우 느림.
- **큰 stride**: 창 수↓(빠름) but 정확도↓.
- **작은 stride**: 정확도↑ but 계산량 폭발.
- 과거엔 단순 선형 분류기(수작업 특징)라 슬라이딩 윈도우가 괜찮았지만, CNN에선 너무 느림.

### 해결
- 슬라이딩 윈도우를 **합성곱으로 구현(convolutional implementation)** 하면 훨씬 효율적 (다음 영상).

---

## 요약
- 슬라이딩 윈도우 = 여러 크기의 창을 밀며 각 영역을 CNN 분류.
- 계산 비용이 커 비효율적 → 합성곱 구현으로 해결.
