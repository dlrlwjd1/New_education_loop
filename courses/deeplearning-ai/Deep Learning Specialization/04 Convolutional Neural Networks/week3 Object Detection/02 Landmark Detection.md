# 02 Landmark Detection

## 개요
- **랜드마크 검출(landmark detection)**: 신경망이 이미지 속 중요한 점(landmark)들의 (x, y) 좌표를 출력.

---

## 내용

### 예: 얼굴 랜드마크
- 눈 모서리 한 점 → (l_x, l_y) 2개 숫자 출력.
- 여러 점 → l1x,l1y, l2x,l2y, ... 확장.
- 예: **64개 랜드마크** → 출력 129개 (얼굴 유무 1 + 64×2=128).
- 감정 인식, Snapchat AR 필터(왕관/모자 씌우기, 얼굴 왜곡) 등의 기본 구성 요소.

### 예: 자세 추정(pose detection)
- 가슴 중심, 어깨, 팔꿈치, 손목 등 주요 관절 좌표를 출력해 사람의 자세를 표현.

### 핵심 조건 ⚠️
- **랜드마크 번호의 의미가 모든 이미지에서 일관**되어야 함 (landmark 1은 항상 같은 눈 모서리 등).
- 라벨링된 훈련 세트가 필요 (사람이 일일이 주석).

---

## 요약
- 랜드마크 검출 = 신경망이 주요 점들의 (x,y) 좌표를 출력 (얼굴 특징, 자세 등).
- 랜드마크 인덱스의 의미가 이미지 간 일관돼야 함.
