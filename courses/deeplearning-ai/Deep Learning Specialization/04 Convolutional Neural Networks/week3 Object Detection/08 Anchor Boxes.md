# 08 Anchor Boxes

## 개요
- **앵커 박스(anchor boxes)**: 한 격자 셀이 **여러 물체**를 검출할 수 있게 하고, 학습이 물체 형태에 **특화(specialize)** 되도록 돕는다.

---

## 내용

### 문제
- 한 셀에 보행자·자동차의 중심이 겹치면, 기존 방식은 **둘 중 하나만** 출력 가능.

### 앵커 박스
- 미리 **여러 형태의 앵커 박스**(예: 세로로 긴 것, 가로로 넓은 것)를 정의.
- 라벨 y를 **앵커 박스 개수만큼 반복** → 2개면 y는 16차원 (8×2).
  ```
  [ (앵커1: P_c, b_x, b_y, b_h, b_w, c1, c2, c3), (앵커2: ...) ]
  ```
- 보행자(세로 긴 형태) → 앵커1에, 자동차(가로 넓은 형태) → 앵커2에 인코딩.

### 물체 할당 규칙 (변경) ⭐
- 기존: 물체 → 중심이 속한 **격자 셀**.
- 앵커: 물체 → **(격자 셀, 앵커 박스) 쌍** — 물체 형태와 **IoU가 가장 높은** 앵커에 할당.
- 출력 Y = 3×3×16 (= 3×3×2×8).

### 한계
- **앵커보다 물체가 많은 경우**(2앵커에 3물체), **같은 형태 앵커에 두 물체**가 걸리는 경우는 잘 처리 못 함 → 기본 tiebreaker로 처리 (실제로 드묾).

### 앵커 박스 선택
- 손으로 다양한 형태(세로 긴 것/가로 넓은 것) 5~10개 지정.
- (고급) **k-means**로 데이터의 물체 형태를 군집화해 대표 앵커를 자동 선택 (후기 YOLO 논문).

---

## 요약
- 앵커 박스로 한 셀이 여러 물체를 검출, 물체 형태별 특화 학습.
- 물체는 (셀, IoU 최대 앵커) 쌍에 할당. Y = 격자×앵커수×8.
