# 11 Using Open-Source Implementation

## 개요
- 유명 아키텍처는 논문만 보고 재현하기 어렵다(하이퍼파라미터 세부 등). **오픈소스 구현을 활용**하라.

---

## 내용

### 왜 오픈소스인가
- 학습률 감쇠 등 세부 튜닝이 성능에 영향 → 최고 대학 PhD도 논문만으로 재현이 어려움.
- 많은 연구자가 GitHub에 코드를 공개 → **저자 구현을 받으면 훨씬 빠르게 시작** 가능.

### 사용법 (예: ResNet)
```bash
git clone <GitHub repo URL>
```
- GitHub에서 검색 → repo 페이지의 설명/라이선스 확인(예: MIT는 관대한 오픈소스 라이선스) → clone.

### 실무 워크플로
1. 마음에 드는 아키텍처 선택(강의/문헌/지인 추천).
2. **오픈소스 구현을 GitHub에서 다운로드**해 시작.
- 장점: 학습에 오래 걸리는 네트워크를 **누군가 대규모 데이터·다중 GPU로 사전 학습(pre-train)** 해둠 → **전이 학습**에 활용 가능(다음 영상).
- (연구자로서 밑바닥부터 구현한다면 자신의 코드를 오픈소스로 기여하라.)

---

## 요약
- 논문 재현은 어려우니 GitHub의 오픈소스 구현을 clone해 시작하는 게 빠름.
- 사전 학습된 모델을 전이 학습에 활용 가능.
