# 14 State of Computer Vision

## 개요
- 컴퓨터 비전의 특수한 상황: **데이터가 상대적으로 부족**해 수작업 엔지니어링과 복잡한 아키텍처에 의존.

---

## 내용

### 데이터 양 스펙트럼
- 데이터 **많음** → 단순 알고리즘 + 적은 수작업(hand engineering)으로 OK.
- 데이터 **적음** → 수작업 엔지니어링(특징 설계, 아키텍처 설계)에 더 의존.
- 학습의 두 지식 원천: **레이블 데이터 + 수작업 엔지니어링**.
- 데이터 순위: 이미지 인식 > **물체 검출(object detection)** (바운딩 박스 라벨링 비용이 커 데이터 적음).
- 컴퓨터 비전은 복잡한 함수라 데이터가 늘 부족 → 역사적으로 **복잡한 아키텍처·많은 수작업**. 데이터 적을 땐 전이 학습이 큰 도움.

### 벤치마크/대회용 팁 (실무 배포엔 잘 안 씀) ⚠️
- **앙상블(ensembling)**: 여러 신경망을 독립 학습 후 **출력을 평균**(가중치 평균 X). 1~2% 향상되나, 이미지당 3~15개 망을 돌려 **느리고 메모리 부담** → 프로덕션엔 부적합.
- **Multi-crop at test time (10-crop 등)**: test 이미지에 데이터 증강(중앙+네 모서리 crop × 원본/반전 = 10개)을 적용해 결과 평균. 벤치마크용.

### 실무 권장
- 대부분 소규모 데이터 영역이므로 **남의 아키텍처 + 오픈소스 구현 + 사전 학습 모델 fine-tuning**으로 빠르게 시작.
- 자원·의욕이 있으면 밑바닥 학습이나 새 알고리즘 개발도 가능.

---

## 요약
- 컴퓨터 비전은 데이터 부족 → 복잡한 아키텍처·수작업·전이 학습 의존.
- 앙상블/멀티크롭은 벤치마크·대회용, 프로덕션엔 잘 안 씀.
- 실무는 검증된 아키텍처 + 오픈소스 + 사전 학습 활용.
