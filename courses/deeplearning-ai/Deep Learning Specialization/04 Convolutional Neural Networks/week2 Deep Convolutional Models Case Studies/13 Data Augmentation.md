# 13 Data Augmentation

## 개요
- 컴퓨터 비전은 대체로 데이터가 부족해 **데이터 증강(data augmentation)** 이 성능 향상에 자주 쓰인다. (전이 학습이든 밑바닥 학습이든)

---

## 내용

### 주요 증강 기법
- **좌우 반전(mirroring)**: 인식 대상(예: 고양이)이 보존되면 유용.
- **랜덤 크롭(random cropping)**: 이미지의 여러 부분을 잘라 사용. 완벽하진 않지만 크롭이 원본의 충분히 큰 영역이면 잘 작동.
- (덜 쓰이지만) 회전(rotation), 전단(shearing), 국소 왜곡(local warping).

### 색 변환 (color shifting)
- R, G, B 채널에 서로 다른 값을 더하거나 빼서 색조를 왜곡.
- 조명(햇빛/실내조명)이 달라져도 **내용(라벨 y)은 동일** → 색 변화에 robust하게 만듦.
- **PCA color augmentation**(고급): AlexNet 논문. 이미지 주 색조를 유지하며 왜곡 (주성분 분석 기반).

### 구현 (대규모 데이터)
- **CPU 스레드**가 디스크에서 이미지를 계속 로드하며 왜곡(크롭/색변환/반전)을 적용해 미니배치 구성.
- 이를 다른 스레드/프로세스(CPU 또는 GPU)의 **학습과 병렬로** 진행.

### 하이퍼파라미터
- 색 변환 정도, 크롭 파라미터 등 → 남의 오픈소스 구현으로 시작, 필요하면 직접 튜닝.

---

## 요약
- 증강 기법: 좌우 반전, 랜덤 크롭, (회전/전단/왜곡), 색 변환(PCA).
- 데이터 로딩·왜곡을 학습과 병렬로 처리. 오픈소스 설정으로 시작.
