# 11 Surpassing Human-level Performance

## 개요
- 인간 수준을 능가할 때 무슨 일이 생기는지, 그리고 ML이 이미 인간을 크게 앞선 문제들.

---

## 내용

### 인간 수준 근처/능가 시 진전이 어려운 이유
- 예: 팀 0.5%, 개인 1%, 알고리즘 train 0.6% / dev 0.8% → avoidable bias ≈ 0.1%, variance ≈ 0.2% (판단 가능).
- 그러나 알고리즘 train 0.3% / dev 0.4% → Bayes 오류가 0.1%인지 0.2%인지 0.3%인지 **알 수 없어**, 편향/분산 중 무엇에 집중할지 판단 불가.
- 인간을 넘어서면 **인간 직관에 기대 개선 방향을 찾기도 어려워짐**.

### ML이 인간을 크게 앞선 문제들
- 온라인 광고 클릭 예측, 상품/영화 추천, 물류(이동 시간 예측), 대출 상환 예측.
- 공통점:
  1. **구조화된 데이터(structured data)** — 자연 지각(perception)이 아님.
  2. **방대한 데이터** — 인간이 볼 수 있는 것보다 훨씬 많음.
- 인간은 **자연 지각 작업(비전/음성/NLP)에 매우 강해**, 컴퓨터가 이를 능가하기는 더 어렵다.
- 그럼에도 일부 음성 인식·이미지 인식·의료(ECG 판독, 피부암 진단, 특정 영상의학)에서 인간 수준을 넘어서는 사례가 나오고 있음.

---

## 요약
- 인간 수준을 넘으면 Bayes 오류를 몰라 편향/분산 판단이 어렵고 진전이 더뎌짐.
- 구조화 데이터 + 대량 데이터 문제에선 ML이 인간을 크게 앞섬. 자연 지각 작업은 더 어렵지만 딥러닝으로 일부 능가.
