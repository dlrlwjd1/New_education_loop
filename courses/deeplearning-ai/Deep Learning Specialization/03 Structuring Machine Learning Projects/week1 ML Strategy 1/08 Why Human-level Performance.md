# 08 Why Human-level Performance?

## 개요
- 최근 ML 시스템을 **인간 수준 성능(human-level performance)** 과 비교하는 일이 많아졌다. 이유와 유용성.

---

## 내용

### 왜 인간 수준과 비교하나
1. 딥러닝 발전으로 ML이 많은 분야에서 인간 수준과 경쟁 가능해짐.
2. 인간이 할 수 있는 작업에서는 개발 워크플로가 훨씬 효율적.

### 성능 곡선과 Bayes Optimal Error
- 시간이 지나며 성능은 인간 수준에 다가갈 때 **빠르게** 향상되다가, **인간 수준을 넘어서면 느려짐**.
- **Bayes Optimal Error(베이즈 최적 오류)**: x→y 매핑의 **이론상 최선** — 어떤 함수도 넘을 수 없는 한계.
  - 예: 너무 시끄러운 오디오, 너무 흐린 이미지는 완벽 분류 불가 → 최적 오류가 0%가 아닐 수 있음.
- 인간 수준 넘어선 뒤 진전이 느린 두 이유:
  1. 인간 수준이 이미 **Bayes 오류에 가까워** 개선 여지(headroom)가 작다.
  2. 인간보다 못할 때 쓸 수 있는 **도구들**을 넘어선 뒤엔 쓰기 어렵다.

### 인간보다 못할 때 쓸 수 있는 도구 ⭐
(인간이 잘하는 자연 데이터 작업 — 이미지/오디오/언어)
1. **사람에게 레이블 데이터**를 얻어 더 많은 데이터 확보.
2. **수동 오류 분석(manual error analysis)** — 사람은 맞고 알고리즘은 틀린 예를 분석해 통찰.
3. **편향/분산 분석**을 더 잘 할 수 있음.
- → 인간을 넘어서면 이 세 도구를 적용하기 어려워짐.

---

## 요약
- 인간 수준 성능은 Bayes 오류의 대리(proxy)이자, 넘어서기 전엔 개선 도구(레이블·오류분석·편향분산)를 쓸 수 있어 유용.
- 인간 수준을 넘으면 진전이 느려짐(headroom 감소 + 도구 사용 어려움).
