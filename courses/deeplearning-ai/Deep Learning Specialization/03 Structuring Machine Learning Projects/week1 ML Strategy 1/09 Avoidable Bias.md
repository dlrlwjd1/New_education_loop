# 09 Avoidable Bias

## 개요
- 인간 수준 성능(≈ Bayes 오류)을 알면, 훈련 세트에서 **얼마나 잘해야 하는지(너무 잘하려 하지 말지)** 판단할 수 있다.
- **피할 수 있는 편향(avoidable bias)** = 훈련 오류 − Bayes(인간) 오류.

---

## 내용

### 같은 오류, 다른 처방
| | 예 1 | 예 2 |
|---|---|---|
| 인간(≈Bayes) 오류 | 1% | 7.5% |
| 훈련 오류 | 8% | 8% |
| dev 오류 | 10% | 10% |
| **피할 수 있는 편향** | 7% (큼) | 0.5% (작음) |
| **분산 (dev−train)** | 2% | 2% |
| **처방** | **편향 감소** (큰 망, 더 오래 훈련) | **분산 감소** (정규화, 데이터 추가) |

- 훈련·dev 오류가 같아도 인간 수준에 따라 **집중할 대상이 달라진다.**

### 개념 정리 ⭐
- **인간 수준 오류를 Bayes 오류의 대리(proxy)** 로 사용 (특히 컴퓨터 비전 — 인간이 매우 뛰어남).
- **Avoidable bias** = 훈련 오류 − Bayes 오류. (Bayes 아래로는 과적합 없이는 못 내려감)
- **Variance** = dev 오류 − 훈련 오류.
- 두 값을 비교해 더 큰 쪽을 줄이는 데 집중.

---

## 요약
- avoidable bias = 훈련 오류 − 인간(Bayes) 오류, variance = dev − 훈련.
- 같은 오류라도 인간 수준에 따라 편향/분산 중 무엇에 집중할지 달라진다.
