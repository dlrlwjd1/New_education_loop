# 10 Whether to Use End-to-end Deep Learning

## 개요
- End-to-end 딥러닝의 장단점과, 쓸지 말지 판단하는 핵심 질문.

---

## 내용

### 장점 (Pros)
1. **데이터가 말하게 한다(let the data speak)** — 충분한 X→Y 데이터가 있으면 신경망이 인간의 선입견 없이 최적 매핑을 찾음. (예: 음소(phoneme)는 언어학자의 인위적 개념일 수 있음 — 강제하지 않으면 더 나은 표현을 배울 수도)
2. **수작업 컴포넌트 설계가 덜 필요** → 설계 워크플로 단순화.

### 단점 (Cons)
1. **대량의 데이터 필요** — X(입력 끝)와 Y(출력 끝) 모두 갖춘 데이터가 많아야 함.
2. **유용한 수작업 컴포넌트를 배제** — 데이터가 적을 때는 수작업 설계가 지식을 주입하는 좋은 수단.
   - 학습 알고리즘의 지식 원천 = **데이터 + 수작업 설계**. 데이터 많으면 수작업 덜 중요, 적으면 중요.

### 핵심 질문 ⭐
> **X→Y 매핑의 (필요한) 복잡도를 학습할 만큼 충분한 데이터가 있는가?**
- 뼈 위치 찾기·얼굴 검출은 비교적 단순 → 데이터 덜 필요.
- 손→나이 직접 매핑은 복잡 → 훨씬 많은 데이터 필요.

### 예: 자율주행 (순수 end-to-end가 최선이 아닌 예)
```
센서(이미지/레이더/라이다)
  → [딥러닝] 차·보행자 검출
  → [motion planning] 경로 계획   ← 딥러닝 아님(로보틱스)
  → [control] 조향/가속/제동       ← 제어 알고리즘
```
- 이미지→조향을 직접 학습하는 순수 end-to-end는 현재 데이터·기술 여건상 **덜 유망**.
- 각 컴포넌트를 딥러닝으로 학습하되, **데이터를 얻을 수 있는 X→Y 매핑을 신중히 선택**.

---

## 요약
- 장점: 데이터가 말하게 함 + 수작업 설계 감소. 단점: 대량 데이터 필요 + 유용한 수작업 배제.
- 판단 기준: 필요한 복잡도를 배울 **충분한 데이터**가 있는가.
- 자율주행처럼 순수 end-to-end보다 다단계가 나은 경우도 많음.
