# 09 What is End-to-end Deep Learning?

## 개요
- **End-to-end 딥러닝**: 여러 단계의 파이프라인을 **하나의 신경망**으로 대체해 입력 X → 출력 Y를 직접 학습.

---

## 내용

### 예: 음성 인식
- 전통 파이프라인: 오디오 → (MFCC 등 수작업 특징) → 음소(phoneme) → 단어 → 문장.
- End-to-end: 오디오 → **신경망 하나** → 문장(transcript) 직접 출력.
- 사회적 효과: 수작업 특징/중간 단계에 커리어를 쏟은 연구자들의 작업이 무력화되기도 함.

### 데이터 양이 관건 ⭐
- End-to-end는 **아주 많은 데이터**가 있어야 잘 됨.
  - 음성: 3,000시간이면 전통 파이프라인이 더 낫고, **10,000~100,000시간**이면 end-to-end가 빛남.
- 데이터가 적거나 중간이면 **부분적 파이프라인**(예: 오디오→음소만 신경망)이 나을 수 있음.

### 얼굴 인식 개찰구 (2단계가 더 나은 예)
- 원본 이미지 → 신분 직접 학습은 **최선이 아님** (사람이 다양한 위치·거리에서 접근).
- 더 나은 방법(2단계):
  1. **얼굴 검출** → 얼굴을 중앙에 오도록 크롭.
  2. 크롭된 얼굴 → 신분 인식 (두 이미지가 같은 사람인지 비교, DB의 수만 명과 대조).
- 왜 나은가: ① 각 하위 문제가 **더 단순**, ② 각 하위 작업에 **데이터가 많음**(얼굴 검출 라벨 多, 얼굴 쌍 비교 데이터 수억 장). 반면 (개찰구 이미지→신분) end-to-end 데이터는 부족.

### 다른 예
- **기계 번역**: 영어-프랑스어 문장 쌍이 많아 **end-to-end가 잘 됨**.
- **손 X-ray로 아동 나이 추정**: 데이터 부족 → (뼈 분할 → 뼈 길이로 나이 추정) **2단계**가 더 나음.

---

## 요약
- End-to-end = 파이프라인을 신경망 하나로 대체. 잘 되면 시스템이 크게 단순해짐.
- 단, **대량 데이터**가 필요. 데이터가 적으면 하위 문제로 나눈 다단계가 더 나을 수 있음.
