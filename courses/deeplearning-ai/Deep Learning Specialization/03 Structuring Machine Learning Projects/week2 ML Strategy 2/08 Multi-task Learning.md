# 08 Multi-task Learning

## 개요
- **멀티태스크 학습(multi-task learning)**: 하나의 신경망이 **여러 작업을 동시에** 학습, 각 작업이 서로를 돕는다.
- (전이 학습은 순차적, 멀티태스크는 동시)

---

## 내용

### 예: 자율주행 물체 인식
- 한 이미지에서 보행자/차/정지 표지/신호등을 **동시에** 검출.
- 레이블 y⁽ⁱ⁾는 **4×1 벡터** (예: [보행자0, 차1, 정지1, 신호0]). Y는 (4 × m) 행렬.
- 출력층에 **4개 노드**, 각각 해당 물체 유무를 예측.

### 손실 함수
```
Loss = (1/m) Σᵢ Σⱼ₌₁⁴ L(ŷⱼ⁽ⁱ⁾, yⱼ⁽ⁱ⁾)     # L은 로지스틱 손실
```
- **Softmax와 차이**: softmax는 이미지당 **하나의** 레이블. 멀티태스크는 한 이미지에 **여러 레이블** 가능(보행자 + 차 동시).

### 일부만 레이블된 데이터도 OK
- 어떤 이미지는 일부 물체만 레이블(나머지는 `?`)이어도 됨.
- 손실 합에서 **레이블(0/1)이 있는 j만 합산**, `?`는 제외.

### 멀티태스크가 유리한 조건 ⭐
1. 작업들이 **저수준 특징을 공유**할 수 있을 때 (도로 관련 특징 등).
2. 각 작업의 **데이터 양이 비슷**할 때 (엄격한 규칙 아님). 한 작업에 집중할 때 **나머지 작업들의 데이터 합이 그보다 훨씬 많아야** 도움.
3. **충분히 큰 신경망**을 학습할 수 있을 때. (Rich Caruana: 망이 작을 때만 멀티태스크가 개별 학습보다 나쁨. 크면 대개 도움)

### 실무
- 실제로는 **전이 학습이 멀티태스크보다 훨씬 자주** 쓰임.
- 예외: **컴퓨터 비전 물체 검출** — 여러 물체를 한 망으로 검출하는 게 개별 망보다 나은 사례 많음.

---

## 요약
- 멀티태스크 = 한 망이 여러 작업 동시 학습(한 이미지에 여러 레이블 가능). 손실은 작업별 로지스틱 손실 합.
- 조건: 저수준 특징 공유, 비슷한 데이터 양, 충분히 큰 망.
- 전이 학습이 더 흔히 쓰임(예외: 물체 검출).
