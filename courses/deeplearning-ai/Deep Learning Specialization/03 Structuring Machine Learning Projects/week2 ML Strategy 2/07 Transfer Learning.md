# 07 Transfer Learning

## 개요
- **전이 학습(transfer learning)**: 한 작업(A)에서 학습한 지식을 다른 작업(B)에 옮겨 쓰는 것.
- 예: 이미지 인식으로 배운 것을 방사선 영상 진단에 활용.

---

## 내용

### 방법
1. 작업 A(예: 이미지 인식)로 신경망을 학습.
2. **마지막 출력층을 제거**하고, 그 층의 가중치를 **랜덤 초기화**.
3. 새 데이터셋(작업 B, 예: 방사선 영상)으로 재학습.
   - 데이터 적으면 → **마지막 층(들)만** 재학습.
   - 데이터 많으면 → **전체 층** 재학습.
- 필요하면 출력 노드 하나가 아니라 **여러 새 층**을 추가할 수도.

### 용어
- **Pre-training(사전 학습)**: 작업 A로 가중치를 미리 학습.
- **Fine-tuning(미세 조정)**: 작업 B 데이터로 가중치를 갱신.

### 왜 도움이 되나
- 앞쪽 층이 배운 **저수준 특징**(엣지, 곡선, 물체 일부)이 새 작업에도 유용 → 적은 데이터로도 빠르게 학습.

### 전이 학습이 유리한 조건 ⭐
(A → B로 전이, 목표는 B를 잘 하는 것)
1. A와 B의 **입력 x가 같은 종류** (둘 다 이미지, 둘 다 오디오 등).
2. **A의 데이터가 B보다 훨씬 많다.** (B의 예제 하나가 B에 더 가치 있으므로, A는 훨씬 많아야 의미)
3. A의 **저수준 특징이 B에 도움**될 것으로 기대됨.

- 반대(A 데이터 < B 데이터)면 이득이 거의 없음.

---

## 요약
- 전이 학습 = 출력층 교체 후 재학습(데이터 적으면 마지막 층만, 많으면 전체=fine-tuning).
- 조건: 같은 입력 종류, A 데이터 ≫ B 데이터, 저수준 특징 공유.
