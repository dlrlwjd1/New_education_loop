# 05 Broadcasting in Python

## 개요
- **브로드캐스팅(broadcasting)**: 크기가 다른 배열끼리 연산할 때, NumPy가 작은 배열을 자동으로 복사·확장해 맞춰주는 기능
- for 루프 없이 코드를 더 빠르고 짧게 작성 가능
- 앞선 로지스틱 회귀 코드에서 `+ b` 를 더할 때 이미 사용했던 원리
- 신경망 구현에 필요한 주요 브로드캐스팅 형태만 알면 충분

---

## 내용

### 동기 예시: 음식별 칼로리 비율 계산

4가지 음식(사과·소고기·달걀·감자)의 100g당 탄수화물·단백질·지방 칼로리가 담긴 3×4 행렬 A. 목표 = 각 음식에서 **영양소별 칼로리 비율(%)** 계산 → for 루프 없이.

```python
# A: (3, 4) 행렬
cal = A.sum(axis=0)                 # 열 방향 합계 → (1, 4)
percentage = 100 * A / cal.reshape(1, 4)
```

- `cal` = 각 음식의 총 칼로리 [59, 239, ...]
- (3×4) 행렬을 (1×4) 벡터로 나눔 → 브로드캐스팅이 자동 처리
- 예: 사과의 탄수화물 비율 = 56/59 ≈ 94.9%

### axis 파라미터

| 코드 | 의미 |
|---|---|
| `A.sum(axis=0)` | **세로(열) 방향** 합계 |
| `A.sum(axis=1)` | **가로(행) 방향** 합계 |

- axis=0 → 위아래로 합 (vertical)
- axis=1 → 좌우로 합 (horizontal)

### reshape 팁

- `cal`은 이미 (1,4)라 `reshape(1,4)`가 사실 중복(redundant)
- 하지만 행렬 차원이 확실치 않을 때 `reshape`를 호출해 원하는 모양을 **보장**하는 습관은 유용
- reshape는 **O(1)** (상수 시간)으로 매우 저렴 → 부담 없이 사용

### 브로드캐스팅 규칙 정리

**① 벡터/행렬 + 실수(스칼라)**
```
[1,2,3,4] + 100  →  [101,102,103,104]
```
실수를 벡터 크기만큼 복사해 각 원소에 적용 (로지스틱 회귀의 `+ b`가 이것)

**② (m×n) 행렬 ⊕ (1×n) 행렬**
```
(1×n)을 세로로 m번 복사 → (m×n) → 원소별 연산
```
예: 각 열에 서로 다른 값을 더함

**③ (m×n) 행렬 ⊕ (m×1) 행렬**
```
(m×1)을 가로로 n번 복사 → (m×n) → 원소별 연산
```
예: 각 행에 서로 다른 값을 더함

> ⊕ = 덧셈·뺄셈·곱셈·나눗셈 (모두 원소별로 적용)

### 일반 원리

- (m×n) ⊕ (1×n) → (1×n)을 m번 복사
- (m×n) ⊕ (m×1) → (m×1)을 n번 복사
- (m×1) 또는 (1×n) ⊕ 실수 → 실수를 복사해 확장
- 이후 **원소별(element-wise)** 연산 수행

### 참고
- 더 일반적인 정의는 NumPy 공식 문서의 broadcasting 참고
- MATLAB/Octave의 `bsxfun`과 비슷한 목적 (몰라도 무방)

## 예시

```python
import numpy as np

# ① 스칼라 브로드캐스팅
v = np.array([1, 2, 3, 4])
print(v + 100)                 # [101 102 103 104]

# ② (m×n) + (1×n) : 열마다 다른 값
A = np.array([[1, 2, 3],
              [4, 5, 6]])       # (2, 3)
print(A + np.array([100, 200, 300]))
# [[101 202 303]
#  [104 205 306]]

# ③ (m×n) + (m×1) : 행마다 다른 값
print(A + np.array([[100], [200]]))
# [[101 102 103]
#  [204 205 206]]

# 칼로리 비율 예시
A = np.array([[56.0, 0.0, 4.4, 68.0],
              [ 1.2, 104.0, 52.0, 8.0],
              [ 1.8, 135.0, 99.0, 0.9]])
cal = A.sum(axis=0)
print(100 * A / cal.reshape(1, 4))
```

## 요약
- 브로드캐스팅 = 크기가 다른 배열을 NumPy가 자동으로 복사·확장해 원소별 연산
- `axis=0` 세로 합, `axis=1` 가로 합
- (m×n) ⊕ (1×n) → 세로 m번 복사 / (m×n) ⊕ (m×1) → 가로 n번 복사 / ⊕ 스칼라 → 전체 복사
- reshape는 O(1)로 저렴 → 차원 확신 없을 때 안전장치로 사용
- for 루프 제거 + 코드 간결화, 신경망 구현의 필수 기법
- 다음 강의: 파이썬/NumPy 사용 시 버그를 줄이는 팁
