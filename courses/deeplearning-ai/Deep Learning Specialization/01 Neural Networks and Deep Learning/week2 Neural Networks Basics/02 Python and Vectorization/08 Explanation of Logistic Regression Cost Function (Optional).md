# 08 Explanation of Logistic Regression Cost Function (Optional)

## 개요
- (선택 영상) 로지스틱 회귀의 **비용 함수(cost function)** 가 왜 그 형태인지에 대한 정당화(justification)
- 핵심 아이디어: 예측 ŷ를 **확률**로 해석 → **최대 우도 추정(Maximum Likelihood Estimation, MLE)**
- 손실 함수(loss)를 최소화 = 로그 확률(log probability)을 최대화 = MLE 수행

---

## 내용

### 예측을 확률로 해석

로지스틱 회귀: ŷ = σ(wᵀx + b), 이 ŷ를 **"y=1일 확률"** 로 해석.

```
P(y=1 | x) = ŷ
P(y=0 | x) = 1 - ŷ
```
(이진 분류이므로 y는 0 또는 1만 가능)

### 두 식을 하나로 합치기

두 경우를 한 줄로 요약:

```
P(y | x) = ŷ^y · (1 - ŷ)^(1-y)
```

**왜 성립하나 (지수 활용):**

- **y = 1일 때**: ŷ¹ · (1-ŷ)⁰ = ŷ · 1 = **ŷ** ✅
- **y = 0일 때**: ŷ⁰ · (1-ŷ)¹ = 1 · (1-ŷ) = **1-ŷ** ✅

(지수가 해당 항을 "켜고 끄는" 스위치 역할)

### 로그를 취해 손실 함수 유도

log는 **단조 증가(monotonically increasing)** 함수라, P를 최대화하는 것과 log P를 최대화하는 것은 같은 결과.

```
log P(y|x) = y·log(ŷ) + (1-y)·log(1-ŷ)
```

이것이 바로 **손실 함수의 음수(negative)**:

```
L(ŷ, y) = -[ y·log(ŷ) + (1-y)·log(1-ŷ) ]
```

- 음수 부호 이유: 학습 시 **확률은 크게(maximize)** 하고 싶지만, 로지스틱 회귀에선 **손실은 작게(minimize)** 표현
- 손실 최소화 = 로그 확률 최대화

### 전체 학습 세트로 확장 — 비용 함수

학습 예제들이 **IID (독립적이고 동일하게 분포, identically independently distributed)** 라 가정하면, 전체 확률 = 각 확률의 곱:

```
P(전체 라벨) = ∏(i=1..m) P(y⁽ⁱ⁾ | x⁽ⁱ⁾)
```

로그를 취하면 곱 → 합:

```
log P = Σ(i=1..m) log P(y⁽ⁱ⁾|x⁽ⁱ⁾) = -Σ L(ŷ⁽ⁱ⁾, y⁽ⁱ⁾)
```

**최대 우도 추정(MLE)** = 이 값을 최대화하는 파라미터 선택 = `-Σ L`을 최대화.

### 비용 함수 J(w,b)

최대화(우도) → 최소화(비용)로 바꾸고, 스케일링을 위해 1/m 추가:

```
J(w, b) = (1/m) Σ(i=1..m) L(ŷ⁽ⁱ⁾, y⁽ⁱ⁾)
        = -(1/m) Σ [ y⁽ⁱ⁾ log ŷ⁽ⁱ⁾ + (1-y⁽ⁱ⁾) log(1-ŷ⁽ⁱ⁾) ]
```

- 음수 부호 제거 (최대화 → 최소화 전환)
- 1/m = 수치 스케일을 맞추기 위한 편의 인자

---

## 예시

```
[손실 함수의 직관]
y = 1인데 ŷ ≈ 1  →  -log(1) = 0        (손실 작음, 잘 맞춤)
y = 1인데 ŷ ≈ 0  →  -log(0) = +∞       (손실 큼, 크게 틀림)
y = 0인데 ŷ ≈ 0  →  -log(1) = 0        (손실 작음, 잘 맞춤)
y = 0인데 ŷ ≈ 1  →  -log(0) = +∞       (손실 큼, 크게 틀림)
```

---

## 요약
- ŷ를 P(y=1|x)로 해석 → 두 경우를 `P(y|x) = ŷ^y (1-ŷ)^(1-y)` 한 식으로 통합
- 로그를 취하면 손실 함수 `L = -[y log ŷ + (1-y) log(1-ŷ)]` 유도
- 손실 **최소화** = 로그 확률 **최대화**
- 학습 예제가 **IID**라는 가정 하에, 전체 확률의 곱 → 로그로 합 변환
- **비용 함수 최소화 = 최대 우도 추정(MLE)** 수행과 동일
- `J(w,b) = -(1/m) Σ [y log ŷ + (1-y) log(1-ŷ)]` (1/m은 스케일링 편의)
