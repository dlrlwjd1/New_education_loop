# 05 Derivatives

## 개요
- **도함수(derivative)**란 함수의 기울기(slope)를 의미 — "slope"와 동의어
- 변수를 아주 조금 움직였을 때 함수값이 얼마나 변하는지를 나타냄
- 딥러닝에 깊은 미적분 지식은 불필요하지만, 직관적 이해는 필수

---

## 내용

### 도함수 = 기울기 (Slope)
- 도함수는 어렵게 들리지만 **기울기(slope)**와 같은 개념
- 기울기 = 높이(height) / 너비(width) = Δf / Δa

### 직선 함수 예시: f(a) = 3a

| a | f(a) = 3a | a를 0.001 증가 | f(a) 변화량 | 기울기 |
|---|---|---|---|---|
| 2 | 6 | 2.001 → f = 6.003 | +0.003 | 0.003/0.001 = **3** |
| 5 | 15 | 5.001 → f = 15.003 | +0.003 | 0.003/0.001 = **3** |

- a를 0.001 오른쪽으로 nudge하면 f(a)는 **3배** 증가
- **직선**이므로 어떤 점에서도 기울기는 항상 3으로 동일

### 도함수 표기법

```
df(a)/da = 3      # f(a)를 a에 대해 미분
d/da f(a) = 3     # 위와 동일한 표현
```

두 표기 모두 같은 의미: a를 조금 nudge할 때 f(a)가 3배만큼 변한다.

### 공식 정의 vs 직관적 이해
- **공식 정의**: a를 무한히 작은(infinitesimal) 양만큼 nudge → 극한(limit) 개념
- **직관**: a를 0.001만큼 nudge했을 때 f(a)가 몇 배 변하는지
- 딥러닝 적용에는 직관적 이해로 충분

### 직선 함수의 특성
- f(a) = 3a처럼 직선 함수는 **어느 점에서든 기울기가 동일**
- 어디서 삼각형을 그려도 높이/너비 = 3/1 → 기울기 = 3

---

## 예시

```python
import numpy as np
import matplotlib.pyplot as plt

def f(a):
    return 3 * a

a_vals = np.linspace(0, 6, 100)
f_vals = f(a_vals)

# 수치적 미분 (도함수 근사)
a = 2.0
epsilon = 0.001
numerical_derivative = (f(a + epsilon) - f(a)) / epsilon

print(f"a = {a}일 때 수치 미분: {numerical_derivative}")   # 3.0
print(f"a를 {epsilon} nudge → f(a) 변화: {f(a + epsilon) - f(a):.4f}")  # 0.003
```

```
출력:
a = 2.0일 때 수치 미분: 3.0
a를 0.001 nudge → f(a) 변화: 0.003
```

## 요약
- **도함수 = 기울기(slope)** — 겁먹을 필요 없는 개념
- 기울기 = 변수를 아주 조금 변화시켰을 때 함수값의 변화 비율
- f(a) = 3a에서 df/da = 3: a를 ε만큼 nudge하면 f(a)는 3ε만큼 변화
- 직선 함수는 어느 점에서나 기울기가 동일
- 다음 강의: 곡선 함수 — 위치에 따라 기울기가 달라지는 경우
