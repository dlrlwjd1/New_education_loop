# 02 Logistic Regression

## 개요
- 로지스틱 회귀(Logistic Regression)는 출력 레이블 y가 0 또는 1인 **이진 분류(binary classification)** 문제에 사용하는 학습 알고리즘
- 선형 함수 대신 **시그모이드 함수(sigmoid function)**를 적용해 출력값을 0~1 사이의 확률로 표현

---

## 내용

### 문제 설정
- 입력: 특징 벡터(feature vector) **x** (예: 이미지 픽셀값)
- 목표: **ŷ (y-hat)** = P(y=1 | x) — 입력 x가 주어졌을 때 y=1일 확률

### 파라미터
| 파라미터 | 설명 |
|---|---|
| **w** | nx차원 가중치 벡터(weight vector) |
| **b** | 실수 편향(bias) |

### 선형 함수의 한계
- 단순 선형 함수: `ŷ = wᵀx + b`
- **문제**: wᵀx + b는 1보다 크거나 음수가 될 수 있어 확률로 사용 불가

### 시그모이드 함수 (Sigmoid Function)
로지스틱 회귀의 출력:

```
ŷ = σ(wᵀx + b)
```

시그모이드 함수 정의:

```
σ(z) = 1 / (1 + e^(-z))
```

**핵심 성질:**
- z가 매우 크면 → e^(-z) ≈ 0 → σ(z) ≈ 1
- z가 매우 작으면(큰 음수) → e^(-z) → ∞ → σ(z) ≈ 0
- z = 0 → σ(0) = 0.5 (수직축 교점)
- 출력 범위: **항상 (0, 1)** → 확률로 해석 가능

```
σ(z)
 1 |          ____-------
   |      ---/
0.5|     /
   |   /
 0 |--/_________________ z
          0
```

### 표기법 관련 참고 (Notation Note)
신경망 구현 시 **w와 b를 별도의 파라미터로 유지**하는 방식을 사용:

```python
# 이 강좌에서 사용하는 방식
ŷ = σ(wᵀx + b)   # w, b 분리
```

일부 교재에서는 x₀ = 1인 추가 특징을 정의해 θᵀx 형태로 표현하기도 하지만, 이 강좌에서는 **사용하지 않음**.

---

## 예시

```python
import numpy as np

def sigmoid(z):
    return 1 / (1 + np.exp(-z))

# 파라미터 예시 (nx = 3)
w = np.array([0.5, -0.3, 0.8])
b = 0.1
x = np.array([1.0, 2.0, 0.5])

z = np.dot(w, x) + b   # wᵀx + b
y_hat = sigmoid(z)      # ŷ = σ(z), 0~1 사이 확률값

print(f"z = {z:.4f}")
print(f"ŷ = {y_hat:.4f}")  # 예: y=1일 확률
```

---

## 요약
- 로지스틱 회귀는 이진 분류를 위한 알고리즘으로, 출력이 **확률(0~1)**이어야 함
- 이를 위해 선형 함수 wᵀx + b에 **시그모이드 함수 σ**를 씌워 확률로 변환
- σ(z) = 1/(1+e^(-z)), z가 클수록 1에, 작을수록 0에 수렴
- 파라미터 w와 b를 학습하는 것이 목표 → 다음 강의에서 **비용 함수(cost function)** 정의
