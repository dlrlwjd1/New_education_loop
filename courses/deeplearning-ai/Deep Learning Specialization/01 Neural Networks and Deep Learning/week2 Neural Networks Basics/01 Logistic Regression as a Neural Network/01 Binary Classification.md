# Binary Classification

## 개요
- 이번 주(week 2)는 신경망 프로그래밍(neural network programming)의 기초를 다룸
- 신경망 구현 시 중요한 두 가지 구현 기법(implementational technique):
  1. **명시적 for 루프 없이** 전체 훈련 세트(training set)를 처리하기
  2. 계산을 **순전파(forward propagation)**와 **역전파(backward propagation)** 단계로 나누어 구성하기
- 이 아이디어들을 이해하기 쉽도록 **로지스틱 회귀(logistic regression)**를 예로 설명
- 로지스틱 회귀 = **이진 분류(binary classification)** 알고리즘

## 내용

### 이진 분류 문제 설정
- 입력: 이미지, 출력: 레이블(label)
- 예) 고양이(cat) 이미지면 1, 아니면(non-cat) 0 출력
- 출력 레이블은 **y**로 표기

### 이미지의 컴퓨터 표현
- 컴퓨터는 이미지를 빨강·초록·파랑(RGB) 3개의 색 채널(color channel) 행렬로 저장
- 64×64 픽셀 이미지라면 → 각 채널마다 64×64 행렬, 총 3개의 64×64 행렬
- **특징 벡터(feature vector) x 만들기**: 모든 픽셀 강도(pixel intensity) 값을 한 줄로 펼침(unroll)
  - 빨강 채널의 모든 값 → 초록 채널 → 파랑 채널 순으로 나열한 긴 벡터
- 64×64 이미지의 경우 차원: 64 × 64 × 3 = **12,288**
  - 이 입력 특징의 차원을 **n_x = 12288** (간단히 소문자 **n**)로 표기
- 목표: 특징 벡터 x를 입력받아 레이블 y가 1인지 0인지(고양이/비고양이) 예측하는 분류기(classifier) 학습

### 표기법 (Notation)
- **하나의 훈련 예제(training example)**: 쌍 (x, y)
  - x는 n_x 차원 특징 벡터, y는 0 또는 1
- **훈련 세트**: 소문자 m개의 예제로 구성
  - (x⁽¹⁾, y⁽¹⁾), (x⁽²⁾, y⁽²⁾), …, (x⁽ᵐ⁾, y⁽ᵐ⁾)
  - **m** = 훈련 예제 수. 강조 시 m_train, 테스트 세트는 m_test로 표기

### 행렬 X (입력)
- 각 훈련 예제 입력 x⁽ⁱ⁾를 **열(column)로 쌓아서** 행렬 X 구성
  - x⁽¹⁾를 첫 번째 열, x⁽²⁾를 두 번째 열, …, x⁽ᵐ⁾를 마지막 열
- 크기: **n_x × m** (행 = n_x, 열 = m)
- 다른 강좌에서는 예제를 행(row)으로 쌓기도(xᵀ를 위에서 아래로) 하지만, 신경망 구현에서는 **열로 쌓는 이 방식이 구현을 훨씬 쉽게** 만듦
- Python: `X.shape` → `(n_x, m)`

### 행렬 Y (출력)
- 출력 레이블도 열로 쌓음: Y = [y⁽¹⁾, y⁽²⁾, …, y⁽ᵐ⁾]
- 크기: **1 × m**
- Python: `Y.shape` → `(1, m)`
- 핵심 관례: 서로 다른 훈련 예제의 데이터(X, Y 등)를 **서로 다른 열에 쌓는다**

## 예시

| 표기 | 의미 | 크기/형태 |
|------|------|-----------|
| x | 하나의 입력 특징 벡터 | n_x × 1 |
| n_x (= n) | 입력 특징의 차원 (예: 12288) | 스칼라 |
| m | 훈련 예제 수 | 스칼라 |
| X | 입력을 열로 쌓은 행렬 | n_x × m |
| Y | 레이블을 열로 쌓은 행렬 | 1 × m |

```python
# 64x64 RGB 이미지 한 장을 특징 벡터로 펼치는 예
n_x = 64 * 64 * 3   # = 12288
# X: 훈련 예제를 열로 쌓은 행렬
X.shape   # (12288, m)
Y.shape   # (1, m)
```

## 요약
- 로지스틱 회귀는 이진 분류 알고리즘이며, 이번 주 신경망 기초 설명의 예제로 사용
- 이미지는 RGB 3채널 행렬로 저장 → 펼쳐서(unroll) n_x 차원 특징 벡터 x 생성 (64×64면 12288)
- 훈련 예제는 (x, y) 쌍, 총 m개
- 입력 X는 예제를 **열로 쌓은 n_x × m 행렬**, 출력 Y는 **1 × m 행렬** — 열 기준으로 쌓는 관례가 신경망 구현을 쉽게 함
- 표기법이 헷갈리면 코스 웹사이트의 notation guide 참고
