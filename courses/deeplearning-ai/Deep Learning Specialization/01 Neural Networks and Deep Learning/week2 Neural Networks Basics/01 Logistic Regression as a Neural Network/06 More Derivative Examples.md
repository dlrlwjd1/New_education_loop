# 06 More Derivative Examples

## 개요
- 직선이 아닌 곡선 함수에서는 **위치마다 기울기(도함수)가 다름**
- 주요 함수의 도함수 공식을 미적분 교재에서 찾아 사용하면 됨
- 핵심 메시지: 도함수 = 기울기, 미적분 전문 지식 불필요

---

## 내용

### 곡선 함수의 도함수: f(a) = a²

a를 0.001 nudge했을 때 변화량:

| a | f(a) = a² | a + 0.001 | f(a + 0.001) | 변화 비율 | 도함수(2a) |
|---|---|---|---|---|---|
| 2 | 4 | 2.001 | ≈ 4.004 | ×4 | 2×2 = **4** |
| 5 | 25 | 5.001 | ≈ 25.010 | ×10 | 2×5 = **10** |

- 직선(f=3a)과 달리, **a 값에 따라 기울기가 다름**
- 교재 공식: `d/da (a²) = 2a`

### 주요 함수 도함수 공식 정리

| 함수 f(a) | 도함수 df/da | a=2일 때 도함수 |
|---|---|---|
| 3a (직선) | 3 | 3 |
| a² | 2a | 4 |
| a³ | 3a² | 12 |
| log(a) (자연로그) | 1/a | 1/2 = 0.5 |

### 각 함수 검증

**f(a) = a³, a = 2:**
- f(2) = 8, f(2.001) ≈ 8.012
- 변화량: 0.012 = 12 × 0.001 ✓ (도함수 = 3×2² = 12)

**f(a) = log(a), a = 2:**
- f(2) ≈ 0.69315, f(2.001) ≈ 0.69365
- 변화량: 0.0005 = 0.5 × 0.001 ✓ (도함수 = 1/2 = 0.5)

### 근사 오차가 생기는 이유
- nudge 값 0.001은 작지만 수학적 무한소(infinitesimal)가 아님
- 도함수의 공식 정의는 nudge → 0인 극한(limit)값
- 그래서 실제 계산값과 공식 예측값 사이에 미세한 오차 발생 (무시 가능)

## 예시

```python
import numpy as np

epsilon = 0.001

functions = {
    "f(a) = 3a":     (lambda a: 3*a,        lambda a: 3),
    "f(a) = a²":     (lambda a: a**2,       lambda a: 2*a),
    "f(a) = a³":     (lambda a: a**3,       lambda a: 3*a**2),
    "f(a) = log(a)": (lambda a: np.log(a),  lambda a: 1/a),
}

a = 2.0
print(f"a = {a}, epsilon = {epsilon}\n")
print(f"{'함수':<15} {'수치 미분':>12} {'공식 도함수':>12}")
print("-" * 42)

for name, (f, df) in functions.items():
    numerical = (f(a + epsilon) - f(a)) / epsilon
    analytical = df(a)
    print(f"{name:<15} {numerical:>12.5f} {analytical:>12.5f}")
```

```
출력:
a = 2.0, epsilon = 0.001

함수            수치 미분   공식 도함수
------------------------------------------
f(a) = 3a        3.00000      3.00000
f(a) = a²        4.00100      4.00000
f(a) = a³       12.00600     12.00000
f(a) = log(a)    0.49988      0.50000
```

## 요약
- 곡선 함수는 위치마다 기울기가 다름 (직선과의 차이)
- 도함수 = 기울기 — 교재 공식표에서 조회해 사용하면 됨
- 주요 공식: d(a²)/da = 2a, d(a³)/da = 3a², d(log a)/da = 1/a
- 다음 강의: **계산 그래프(computation graph)** — 복잡한 함수의 도함수를 체계적으로 계산하는 방법
