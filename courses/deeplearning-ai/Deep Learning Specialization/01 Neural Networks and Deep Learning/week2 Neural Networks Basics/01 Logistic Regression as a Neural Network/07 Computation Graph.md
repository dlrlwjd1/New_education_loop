# 07 Computation Graph

## 개요
- **계산 그래프(computation graph)**는 신경망 계산을 순전파(forward pass)와 역전파(backward pass)로 구조화하는 방법
- 왼쪽 → 오른쪽: 출력값 계산 (순전파)
- 오른쪽 → 왼쪽: 도함수/기울기 계산 (역전파)

---

## 내용

### 예시 함수
J = 3(a + bc)를 계산하는 과정을 단계별로 분해:

```
u = b × c
v = a + u
J = 3 × v
```

### 계산 그래프 구조

```
a ─────────→ [v = a + u] ──→ [J = 3v]
              ↑
b → [u = bc] ─┘
     ↑
c ───┘

← 역전파(backward) : 도함수 계산
→ 순전파(forward)  : 출력값 계산
```

### 구체적 예시 (a=5, b=3, c=2)

| 단계 | 연산 | 결과 |
|---|---|---|
| 1 | u = b × c = 3 × 2 | u = 6 |
| 2 | v = a + u = 5 + 6 | v = 11 |
| 3 | J = 3 × v = 3 × 11 | J = **33** |

검증: J = 3(a + bc) = 3(5 + 3×2) = 3×11 = **33** ✓

### 왜 계산 그래프를 사용하는가?
- 최적화하려는 특별한 출력 변수(예: 비용 함수 J)가 있을 때 유용
- 로지스틱 회귀에서 J는 최소화할 비용 함수
- 순전파로 J를 계산하고, 역전파로 J의 각 파라미터에 대한 도함수를 계산

---

## 예시

```python
# 계산 그래프를 코드로 표현
a, b, c = 5, 3, 2

# 순전파 (왼쪽 → 오른쪽)
u = b * c       # 중간 노드 1
v = a + u       # 중간 노드 2
J = 3 * v       # 최종 출력

print(f"u = {u}, v = {v}, J = {J}")  # u = 6, v = 11, J = 33
```

---

## 요약
- 계산 그래프: 복잡한 함수를 단계별 연산 노드로 분해한 방향성 그래프
- **순전파(forward propagation)**: 왼→오, 출력값 J 계산
- **역전파(backward propagation)**: 오→왼, dJ/da, dJ/db, dJ/dc 계산
- 다음 강의에서 역전파 방향으로 도함수를 계산하는 방법을 다룸
