# 02 Forward Propagation in a Deep Network

## 개요
- 심층 신경망의 **순전파(forward propagation)** 를 일반화된 식으로 정리한다.
- 층마다 "z = W·(이전 층 활성값) + b → a = g(z)"를 반복.

---

## 내용

### 단일 예제 순전파
```
z⁽¹⁾ = W⁽¹⁾ x   + b⁽¹⁾ ,   a⁽¹⁾ = g⁽¹⁾(z⁽¹⁾)
z⁽²⁾ = W⁽²⁾ a⁽¹⁾ + b⁽²⁾ ,   a⁽²⁾ = g⁽²⁾(z⁽²⁾)
...
z⁽⁴⁾ = W⁽⁴⁾ a⁽³⁾ + b⁽⁴⁾ ,   a⁽⁴⁾ = g⁽⁴⁾(z⁽⁴⁾) = ŷ
```
- X = a⁽⁰⁾ 이므로 모든 식이 동일한 형태가 됨.

### 일반 규칙 (general rule)
```
z⁽ˡ⁾ = W⁽ˡ⁾ a⁽ˡ⁻¹⁾ + b⁽ˡ⁾
a⁽ˡ⁾ = g⁽ˡ⁾(z⁽ˡ⁾)
```

### 벡터화 (전체 훈련 세트)
예제들을 열로 쌓아 대문자로:
```
Z⁽ˡ⁾ = W⁽ˡ⁾ A⁽ˡ⁻¹⁾ + b⁽ˡ⁾
A⁽ˡ⁾ = g⁽ˡ⁾(Z⁽ˡ⁾)     (A⁽⁰⁾ = X)
```
- 마지막: Ŷ = A⁽ᴸ⁾ = g(Z⁽ᴸ⁾), 모든 예제의 예측이 가로로 쌓임.

### for 루프는 허용 ⭐
- 층 l = 1 → L 을 도는 **명시적 for 루프는 피할 수 없다** (없앨 방법 없음).
- 신경망 구현에서 보통 for 루프를 없애려 하지만, **층을 도는 루프만은 예외로 OK.**

---

## 요약
- 순전파 일반식: `Z⁽ˡ⁾ = W⁽ˡ⁾A⁽ˡ⁻¹⁾ + b⁽ˡ⁾`, `A⁽ˡ⁾ = g⁽ˡ⁾(Z⁽ˡ⁾)`, A⁽⁰⁾=X.
- 은닉층 1개짜리를 여러 번 반복한 것과 동일.
- 층을 도는 for 루프(1~L)는 써도 됨.
