# 07 Parameters vs Hyperparameters

## 개요
- **파라미터(parameter)**: 모델이 학습하는 값 → W, b.
- **하이퍼파라미터(hyperparameter)**: 파라미터 W, b가 어떻게 결정될지를 **제어하는** 값 → 사람이 설정.

---

## 내용

### 하이퍼파라미터의 예
- **학습률(learning rate) α**
- **경사 하강 반복 횟수(iterations)**
- **은닉층 수 L**
- **은닉 유닛 수** n⁽¹⁾, n⁽²⁾, ...
- **활성화 함수** 선택 (ReLU/tanh/sigmoid)
- (Course 2에서 추가로) momentum, mini-batch size, regularization 파라미터 등

→ 이들이 **최종 W, b를 결정**하므로 "하이퍼(상위)" 파라미터라 부름.
→ α는 엄밀히는 파라미터지만, 진짜 파라미터를 결정하는 값이므로 일관되게 **하이퍼파라미터**로 부른다.

### 응용 딥러닝 = 매우 경험적인(empirical) 과정
- 새 문제에서 최적 하이퍼파라미터를 미리 알기 어렵다.
- **Idea → Code → Experiment** 순환을 반복하며 여러 값을 시도.
- 학습률 예: α를 바꿔가며 비용 J 곡선을 관찰 → 빠르게 낮은 J로 수렴하는 값 선택.
  - 너무 크면 발산(diverge), 적당하면 빠르게 수렴.

### 실무 팁
- 분야(비전/음성/NLP/광고/검색/추천 등)마다 하이퍼파라미터 직관이 **넘어오기도, 안 넘어오기도** 함 → 새 문제엔 여러 값을 시도.
- 한 문제를 오래 다뤄도 **최적값은 시간이 지나며 바뀔 수 있음**(CPU/GPU/데이터 변화). → 몇 달마다 다시 몇 개 값을 점검.
- 검증 세트(holdout validation set)로 평가해 최적값 선택.
- Course 2에서 하이퍼파라미터 공간을 **체계적으로 탐색**하는 방법을 배움.

---

## 요약
- 파라미터 = W, b (학습됨). 하이퍼파라미터 = α, 반복 횟수, L, 유닛 수, 활성화 함수 등 (사람이 설정, W·b를 제어).
- 최적 하이퍼파라미터는 실험으로 찾는 경험적 과정. 주기적으로 재점검.
