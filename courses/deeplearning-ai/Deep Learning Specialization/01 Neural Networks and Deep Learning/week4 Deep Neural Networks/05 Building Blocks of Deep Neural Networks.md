# 05 Building Blocks of Deep Neural Networks

## 개요
- 순전파·역전파를 **층별 구성 요소(forward/backward function)** 로 나눠 조립하는 방법.
- 두 함수를 잇는 핵심 장치가 **캐시(cache)**.

---

## 내용

### 층 l의 두 함수
**Forward function**
```
입력:  a⁽ˡ⁻¹⁾
출력:  a⁽ˡ⁾  (+ cache: z⁽ˡ⁾)
계산:  z⁽ˡ⁾ = W⁽ˡ⁾ a⁽ˡ⁻¹⁾ + b⁽ˡ⁾ ;  a⁽ˡ⁾ = g⁽ˡ⁾(z⁽ˡ⁾)
사용 파라미터: W⁽ˡ⁾, b⁽ˡ⁾
```
- **z⁽ˡ⁾를 캐시에 저장** → 나중에 역전파에서 사용.

**Backward function**
```
입력:  da⁽ˡ⁾  (+ cache의 z⁽ˡ⁾)
출력:  da⁽ˡ⁻¹⁾ , dW⁽ˡ⁾ , db⁽ˡ⁾
사용 파라미터: W⁽ˡ⁾, b⁽ˡ⁾ (내부에서 dz⁽ˡ⁾도 계산)
```

### 전체 한 번의 학습 반복
```
순전파:
A⁰=X → [층1: W¹,b¹, cache Z¹] → A¹ → [층2] → A² → ... → A⁽ᴸ⁾ = Ŷ

역전파:
dA⁽ᴸ⁾ → [층L] → dA⁽ᴸ⁻¹⁾ → ... → dA¹
        각 층에서 dW⁽ˡ⁾, db⁽ˡ⁾ 출력
(dA⁰는 입력에 대한 미분이라 지도학습 가중치 훈련엔 불필요 → 계산 안 함)

업데이트:
W⁽ˡ⁾ := W⁽ˡ⁾ − α dW⁽ˡ⁾ ;  b⁽ˡ⁾ := b⁽ˡ⁾ − α db⁽ˡ⁾
```

### 구현 팁: 캐시에 W, b도 함께 저장
- 개념적으로 캐시는 z⁽ˡ⁾를 저장하는 용도.
- 실제 프로그래밍 과제에선 **z와 함께 W, b도 캐시에 저장**하는 게 편리 — 역전파에서 파라미터를 그 지점으로 전달하기 쉬움.

---

## 요약
- 각 층 = forward function(a⁽ˡ⁻¹⁾→a⁽ˡ⁾) + backward function(da⁽ˡ⁾→da⁽ˡ⁻¹⁾, dW, db).
- 둘을 잇는 것이 **cache(z⁽ˡ⁾, 실무에선 W·b도)**.
- 한 반복 = 순전파(캐시 저장) → 역전파(gradient 계산) → 파라미터 업데이트.
