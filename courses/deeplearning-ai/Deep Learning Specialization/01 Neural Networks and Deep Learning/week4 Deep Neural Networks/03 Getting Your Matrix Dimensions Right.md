# 03 Getting Your Matrix Dimensions Right

## 개요
- 심층 신경망 구현의 대표적 **디버깅 도구**: 종이에 각 행렬의 **차원(dimension)** 을 직접 적어보며 확인하기.
- 차원 규칙을 외워두면 버그를 상당수 예방할 수 있다.

---

## 내용

### 예시 네트워크
L=5. 유닛 수: n⁽⁰⁾=2, n⁽¹⁾=3, n⁽²⁾=5, n⁽³⁾=4, n⁽⁴⁾=2, n⁽⁵⁾=1.

### 파라미터 차원 규칙 ⭐
```
W⁽ˡ⁾ :  (n⁽ˡ⁾ , n⁽ˡ⁻¹⁾)
b⁽ˡ⁾ :  (n⁽ˡ⁾ , 1)
```
유도: z⁽¹⁾(n₁×1) = W⁽¹⁾ · x(n₀×1) 이려면, 행렬 곱 규칙상 W⁽¹⁾은 (n₁×n₀).

예시 확인:
| | 차원 |
|---|---|
| W⁽¹⁾ | 3×2 |
| W⁽²⁾ | 5×3 |
| W⁽³⁾ | 4×5 |
| W⁽⁴⁾ | 2×4 |
| W⁽⁵⁾ | 1×2 |

### 역전파 차원 규칙
- **dW⁽ˡ⁾ 은 W⁽ˡ⁾와 같은 차원, db⁽ˡ⁾ 은 b⁽ˡ⁾와 같은 차원.**
- z⁽ˡ⁾, a⁽ˡ⁾ 은 같은 차원 (a = g(z) 원소별). dz, da 도 z, a와 같은 차원.

### 단일 예제 vs 벡터화 차원
| 항목 | 단일 예제 | 벡터화 (m개) |
|---|---|---|
| W⁽ˡ⁾, b⁽ˡ⁾, dW, db | (n⁽ˡ⁾×n⁽ˡ⁻¹⁾), (n⁽ˡ⁾×1) | **동일** |
| z⁽ˡ⁾, a⁽ˡ⁾ | (n⁽ˡ⁾ × 1) | **(n⁽ˡ⁾ × m)** |
| X = a⁽⁰⁾ | (n⁽⁰⁾ × 1) | (n⁽⁰⁾ × m) |

- 벡터화: Z⁽¹⁾(n₁×m) = W⁽¹⁾(n₁×n₀) · X(n₀×m) + b⁽¹⁾.
- **b⁽¹⁾ 은 여전히 (n₁×1)** 이지만 Python **브로드캐스팅**으로 (n₁×m)로 복제되어 더해짐.

---

## 요약
- 핵심 규칙: `W⁽ˡ⁾ = (n⁽ˡ⁾, n⁽ˡ⁻¹⁾)`, `b⁽ˡ⁾ = (n⁽ˡ⁾, 1)`.
- dW/db는 W/b와, dz/da는 z/a와 같은 차원.
- 벡터화하면 z, a, X의 열 차원이 1 → m으로 바뀜. W, b는 그대로.
- 차원을 종이에 적어 확인하면 역전파 버그가 크게 준다.
