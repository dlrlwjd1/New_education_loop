# 01 Deep L-layer Neural Network

## 개요
- Week 4는 지금까지 배운 개념(순전파·역전파·벡터화·랜덤 초기화)을 합쳐 **심층 신경망(deep neural network)** 을 구현한다.
- 여기서는 "심층"의 의미와 **표기법(notation)** 을 정리한다.

---

## 내용

### 얕은 vs 깊은 (shallow vs deep)
- 층 수는 정도의 문제(a matter of degree).
- 로지스틱 회귀 = 1층 신경망(가장 얕음).
- 은닉층 1개 = 2층 신경망.
- 은닉층 2개, 5개... → 점점 깊어짐.
- **깊은 신경망은 얕은 모델이 학습하지 못하는 함수를 학습**할 수 있다.
- 몇 층이 적절한지는 미리 알기 어려우므로, **층 수를 하이퍼파라미터로 두고** 여러 값을 시도해 검증 세트(dev/cross-validation)로 평가.

### 표기법 (⚠️ 중요)
예: 4층 신경망 (은닉층 3개, 유닛 5·5·3, 출력 1). 입력 특징 3개.

| 표기 | 의미 | 예시 |
|---|---|---|
| **L** | 신경망의 층 수 (입력층 제외) | L = 4 |
| **n⁽ˡ⁾** | 층 l의 유닛(노드) 수 | n⁽⁰⁾=3, n⁽¹⁾=5, n⁽²⁾=5, n⁽³⁾=3, n⁽⁴⁾=1 |
| **a⁽ˡ⁾** | 층 l의 활성값 | a⁽ˡ⁾ = g⁽ˡ⁾(z⁽ˡ⁾) |
| **W⁽ˡ⁾, b⁽ˡ⁾** | 층 l에서 z⁽ˡ⁾ 계산에 쓰는 가중치·편향 | |

- 입력층은 layer 0: **a⁽⁰⁾ = X** (n⁽⁰⁾ = nₓ).
- 마지막 층: **a⁽ᴸ⁾ = ŷ** (예측 출력).
- 잊어버리면 코스 웹사이트의 **notation guide** 참고.

---

## 요약
- 심층 신경망 = 은닉층이 여러 개. 로지스틱 회귀(1층)부터 점점 깊어짐.
- 깊이는 하이퍼파라미터 — 여러 값을 시도해 검증 세트로 선택.
- 핵심 표기: L(층 수), n⁽ˡ⁾(유닛 수), a⁽ˡ⁾(활성값), W⁽ˡ⁾/b⁽ˡ⁾, a⁽⁰⁾=X, a⁽ᴸ⁾=ŷ.
