# Supervised Learning with Neural Networks

## 개요

신경망에 대한 기대(hype)가 많고, 실제 성능을 보면 그 기대가 정당화되는 면도 있습니다. 그런데 지금까지 신경망이 만들어낸 경제적 가치의 거의 전부는 **지도 학습(supervised learning)** 이라는 한 종류의 머신러닝에서 나왔습니다. 이 강의는 지도 학습이 무엇이고 어디에 쓰이는지, 그리고 신경망의 종류와 데이터 유형을 다룹니다.

## 내용

### 지도 학습(supervised learning)이란

- 입력 **x**를 받아 출력 **y**로 가는 **매핑 함수(function mapping)** 를 학습하는 것
- 앞 강의의 주택 가격 예측이 대표 예시: 집의 특성(features)을 입력 → 가격(price) y를 출력/추정

### 주요 응용 사례

| 응용 분야 | 입력 x | 출력 y |
|-----------|--------|--------|
| **온라인 광고(online advertising)** | 광고 정보 + 사용자 정보 | 클릭 여부 |
| **컴퓨터 비전(computer vision)** | 이미지 | 분류 인덱스(예: 1~1,000) |
| **음성 인식(speech recognition)** | 오디오 클립 | 텍스트 transcript |
| **기계 번역(machine translation)** | 영어 문장 | 중국어 문장 |
| **자율주행(autonomous driving)** | 이미지 + 레이더 정보 | 다른 차들의 위치 |

- **온라인 광고**는 오늘날 딥러닝의 가장 수익성 높은(lucrative) 응용 — 영감을 주진 않아도 큰 돈이 됨. 클릭할 가능성이 높은 광고를 보여주는 것이 거대 광고 회사의 수익에 직접적 영향
- **컴퓨터 비전**: 사진 태깅(photo tagging) 등에 활용
- **자율주행**: 신경망이 자율주행 시스템의 핵심 구성 요소가 됨

> **가치 창출의 핵심**: 특정 문제에서 **무엇을 x로, 무엇을 y로 둘지 영리하게 선택**하고, 이 지도 학습 요소를 자율주행차 같은 **더 큰 시스템**에 끼워 넣는 것

### 응용마다 다른 신경망 종류

| 신경망 종류 | 용도 |
|-------------|------|
| **Standard NN (표준 신경망)** | 부동산, 온라인 광고 — 앞 강의에서 본 비교적 표준적인 구조 |
| **CNN (Convolutional Neural Network, 합성곱 신경망)** | 이미지 데이터 |
| **RNN (Recurrent Neural Network, 순환 신경망)** | 시퀀스 데이터(sequence data) — 오디오, 언어 |
| **Hybrid / Custom (혼합/맞춤형)** | 자율주행처럼 이미지(CNN) + 레이더 등 서로 다른 입력이 섞인 복잡한 경우 |

- **시퀀스 데이터(sequence data)**: 시간적 요소(temporal component)가 있는 데이터
  - 오디오는 시간에 따라 재생됨 → 1차원 시계열(time series)로 표현 → RNN 적합
  - 언어(영어, 중국어)도 단어/알파벳이 하나씩 순서대로 등장 → 시퀀스 데이터 → 더 복잡한 RNN 사용

### 구조적 데이터 vs 비구조적 데이터

| | **구조적 데이터(structured data)** | **비구조적 데이터(unstructured data)** |
|---|---|---|
| 뜻 | 데이터베이스 형태의 데이터 | 오디오·이미지·텍스트 같은 원시 데이터 |
| 특성(feature) | 각 특성이 **잘 정의된 의미**를 가짐 (집 크기, 침실 수, 사용자 나이) | 이미지의 픽셀 값, 텍스트의 개별 단어 |
| 예시 | 주택 가격 DB, 광고 클릭 예측 DB | 이미지 인식, 음성, 자연어 |

- 역사적으로 컴퓨터는 **비구조적 데이터**를 이해하기가 훨씬 어려웠음
- 사람은 진화적으로 오디오·이미지(그리고 비교적 최근의 텍스트)를 잘 해석함
- 딥러닝 덕분에 이제 컴퓨터도 비구조적 데이터를 훨씬 잘 해석 → 음성 인식, 이미지 인식, 자연어 처리(NLP)에서 새로운 응용이 폭발적으로 증가
- 미디어는 "신경망이 고양이를 알아봤다" 같은 **비구조적 데이터** 성공을 더 많이 다룸 (사람들이 직관적으로 공감하기 때문)
- 하지만 **단기 경제 가치**의 상당 부분은 **구조적 데이터**에서도 창출됨: 더 나은 광고 시스템, 상품 추천, 거대 데이터베이스 처리를 통한 정확한 예측

> 이 코스의 기법들은 구조적·비구조적 데이터 모두에 적용됨. 다만 알고리즘 설명을 위해 비구조적 데이터 예시를 조금 더 많이 활용할 예정.

## 예시

```
지도 학습의 일반 형태:
   입력 x  ──[ 신경망 ]──▶  출력 y

응용별 입력/출력:
   집 특성        → 가격           (Standard NN)
   광고+사용자    → 클릭 여부       (Standard NN)
   이미지         → 분류 인덱스     (CNN)
   오디오         → 텍스트          (RNN)
   영어 문장      → 중국어 문장      (RNN)
   이미지+레이더  → 다른 차 위치     (Hybrid)
```

## 요약

- 신경망의 경제적 가치는 거의 전부 **지도 학습(supervised learning)** = 입력 x → 출력 y 매핑 함수 학습에서 나옴
- 가치 창출의 핵심은 **x와 y를 영리하게 선택**하고 더 큰 시스템에 통합하는 것
- 응용마다 다른 구조: **Standard NN**(부동산·광고), **CNN**(이미지), **RNN**(시퀀스: 오디오·언어), **Hybrid**(자율주행)
- **구조적 데이터**(DB, 의미가 명확한 특성) ↔ **비구조적 데이터**(이미지·오디오·텍스트)
- 미디어는 비구조적 성공을 부각하지만, 단기 경제 가치는 구조적 데이터에서도 큼
- 신경망의 기본 아이디어는 수십 년 전부터 존재 → **왜 지금에서야 잘 작동하는가?** 는 다음 강의 주제
