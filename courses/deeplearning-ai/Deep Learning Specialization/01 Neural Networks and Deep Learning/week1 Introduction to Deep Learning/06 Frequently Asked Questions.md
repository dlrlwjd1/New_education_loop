# Frequently Asked Questions

## 개요
- Deep Learning Specialization 수강생을 위한 자주 묻는 질문(FAQ) 모음
- 새로운 질문이 들어오면 staff가 지속적으로 업데이트
- 강의 내용보다는 **수강 안내·기술 문제 해결·수강 규칙(Honor Code)** 성격

## 내용

### 코스 운영 / 피드백
- **개선 아이디어 제안**: Discourse에 "New ideas for the course"로 게시 → staff 또는 멘토가 확인
- **영상 오류 발견**: Discourse에 게시하면 가능한 빨리 반영
- **퀴즈 채점 오류 / 인증(verification) 문제 / 퀴즈 재응시 불가**: learner support에 직접 연락. 이런 문제는 flag하지 말고 직접 문의해야 해결됨

### 기술적 문제 해결
- **오디오 품질**: 베이스를 낮추고 트레블(treble)을 올리거나, 헤드셋 사용(고주파 강조), 영어 자막(closed captioning) 켜기로 완화 가능
- **"Math Processing Error"**: MathJax가 수식을 렌더링하려다 발생. 보통 페이지를 **새로고침**해서 완전히 로드하면 해결
- **영상 화질 저하**: 영상 settings에서 화질을 High로 올리기 (인터넷 연결이 좋을 때 권장)

### 선수 지식 (Prerequisites)
- **기초 프로그래밍 능력**: 라이브러리 import, 변수·함수·리스트·딕셔너리·for 루프 생성 가능 수준
- **기초 머신러닝 친숙도**: 데이터셋을 행렬(matrix)로 표현하는 방법 등
- **기초 선형대수(linear algebra)**: 행렬 곱셈(matrix multiplication), 벡터 연산(vector operations) 등

### 왜 Python인가
- 오픈소스 언어로 전 세계 누구나 사용 가능, 학계(연구실)·산업계에서 널리 사용
- **Numpy** 라이브러리로 수학 연산이 매우 쉬움
- Python 위에서 동작하는 여러 딥러닝 프레임워크 존재 (TensorFlow, Keras, PaddlePaddle, CNTK, Caffe 등) — 일부를 이 과정에서 배움
- 배우기 쉽고, 커뮤니티가 활발해 전망이 좋음

### Honor Code (수강 규칙) — 위반 사례
- 정답 코드를 게시하거나 공유 요청 ("내 코드는 이런데 풀었어?")
- 정답 제출 후 다른 사람 구현과 비교 요청
- 이메일을 남기며 퀴즈 정답을 요청
- → 위 행위들은 모두 **DLAI Honor Code 위반**

### 기타 표기 규칙
- **인증서(Certificate)**: 코스 완료 시 Course Certificate 발급 가능
- **1개 원소 행렬 입력**: 괄호 없이 원소만 입력
- **3-element / 3-dimensional 벡터**: 별도 설명이 없으면 아래와 같은 열벡터를 의미

  $$A = \begin{bmatrix} element_1 \\ element_2 \\ element_3 \end{bmatrix}$$

## 요약
- FAQ는 강의 개념이 아닌 **수강 안내** 문서: 운영 피드백, 기술 문제, 선수 지식, Python 사용 이유, Honor Code
- 기술 문제(오디오/화질/MathJax)는 대부분 설정 변경이나 새로고침으로 해결
- 선수 지식: 기초 프로그래밍 + 기초 ML + 기초 선형대수
- 정답 공유·요청·비교는 모두 Honor Code 위반
- 채점/인증/재응시 문제는 learner support에 직접 연락
