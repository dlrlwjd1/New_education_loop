# What is a Neural Network?

## 개요

딥러닝(deep learning)은 곧 신경망(neural network), 때로는 매우 큰 신경망을 학습(training)시키는 것을 의미합니다. 이 강의는 주택 가격 예측(housing price prediction) 예시로 신경망의 기본 직관을 설명합니다.

## 단일 뉴런 = 가장 단순한 신경망

주택 6채의 **크기(size)** 와 **가격(price)** 데이터로 가격을 예측하는 함수를 fit한다고 가정.

- 선형 회귀(linear regression)로 직선을 그을 수 있지만, 가격은 음수가 될 수 없음
- 그래서 직선을 0에서 꺾어 → 처음엔 0, 이후 직선으로 상승하는 곡선

이 함수가 **가장 단순한 신경망**입니다.

```
입력 x (size) → [ 뉴런 ○ ] → 출력 y (price)
```

- 뉴런(neuron, 작은 원) 하나가 위 함수를 구현
- 입력(size)을 받아 → 선형 함수 계산 → 0과의 max를 취함 → 추정 가격 출력

### ReLU 함수

- 0까지는 평평하다가 직선으로 상승하는 함수
- **ReLU = Rectified Linear Unit (정류 선형 유닛)**
- "rectified"는 **max(0, ...)** 를 취한다는 의미 → 그래서 이런 모양
- 지금은 자세히 몰라도 되며, 이후 강의에서 다시 등장

## 뉴런을 쌓아 더 큰 신경망 만들기

단일 뉴런을 **레고 블록(Lego brick)** 에 비유 — 여러 개를 쌓으면 더 큰 신경망이 됨.

주택 가격에 영향을 주는 **4개 입력 특성(features)**:

| 입력 특성 | 중간 개념(직관) |
|-----------|----------------|
| 크기(size) + 침실 수(#bedrooms) | 가족 규모(family size) |
| 우편번호(zip/postal code) | 보행 편의성(walkability) |
| 우편번호 + 지역 부유함(wealth) | 학군 품질(school quality) |

→ 가족 규모, 보행 편의성, 학군 품질이 최종 **가격(price)** 예측에 기여

## 신경망의 "마법"

- 구현 시 필요한 것은 학습 데이터의 **입력 X와 출력 Y뿐**
- 중간(가족 규모, 학군 등)은 신경망이 **스스로 알아냄**

### 핵심 용어

- **은닉 유닛(hidden units)**: 중간 원들. 각 유닛은 **4개 입력 특성 전부**를 입력으로 받음
  - "이 노드는 가족 규모만 담당" 식으로 지정하지 않음 → 신경망이 알아서 결정
- **밀집 연결(densely connected)**: 모든 입력 특성이 중간의 모든 원에 연결됨 (입력층 ↔ 중간층)

> 충분한 X·Y 학습 예제만 주어지면, 신경망은 X→Y로 정확히 매핑하는 함수를 놀랍도록 잘 찾아냅니다.

## 요약

- 신경망 = 뉴런(레고 블록)을 쌓아 만든 구조
- 단일 뉴런은 ReLU 같은 함수를 구현하는 가장 작은 신경망
- X와 Y만 제공하면 은닉층의 의미는 신경망이 스스로 학습
- 입력층과 은닉층은 densely connected
