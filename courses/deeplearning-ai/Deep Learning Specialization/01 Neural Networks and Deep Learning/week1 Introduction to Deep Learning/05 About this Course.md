# About this Course

## 개요
- 전체 특화과정(Specialization)은 **5개 코스**로 구성되며, 지금은 그 중 **첫 번째 코스**를 학습 중
- 첫 번째 코스는 딥러닝의 가장 중요한 기초(foundations)이자 빌딩 블록(building blocks)을 다룸
- 이 코스를 마치면 심층 신경망(deep neural network)을 직접 구축하고 동작시킬 수 있게 됨
- 강의 성격: 개념 설명보다는 앞으로의 **학습 로드맵/구조 안내**

## 내용

### 특화과정 전체 구조
- 전체 5개 코스 중 첫 번째 코스를 진행 중
- 첫 번째 코스의 목표: 딥러닝의 핵심 기초와 빌딩 블록을 익혀, 심층 신경망을 만들고 작동시키는 능력 확보

### 첫 번째 코스의 4주 구성
- **1주차** — 딥러닝 소개(introduction). 지금 마무리 중인 주차
- **2주차** — 신경망 프로그래밍 기초. 순전파(forward propagation)와 역전파(back propagation) 단계의 구조를 배우고, 신경망을 효율적으로 구현하는 법 학습
- **3주차** — 단일 은닉층 신경망(single hidden layer neural network)을 직접 코딩. 신경망 구현에 필요한 핵심 개념 습득
- **4주차** — 다층 심층 신경망(deep neural network) 구축 및 동작 확인

### 학습 점검 및 실습
- 각 주차 끝마다 **10개의 객관식 문제(multiple-choice questions)** 제공 → 이해도 점검용, 다 맞을 때까지 재시도 가능
- **2주차부터 프로그래밍 실습(programming exercise)** 시작 → 배운 알고리즘을 직접 구현하고 동작을 확인

## 예시

| 주차 | 학습 내용 |
|------|-----------|
| 1주차 | 딥러닝 소개 (현재 위치) |
| 2주차 | 신경망 프로그래밍 기초 — 순전파·역전파, 효율적 구현 |
| 3주차 | 단일 은닉층 신경망 직접 코딩 |
| 4주차 | 다층 심층 신경망 구축 |

## 요약
- 특화과정 = 5개 코스, 현재 1번째 코스 학습 중
- 1번째 코스 = 4주 구성: 소개 → 신경망 프로그래밍 기초 → 단일 은닉층 신경망 → 다층 심층 신경망
- 매 주차 끝에 객관식 10문제로 이해도 점검, 2주차부터 프로그래밍 실습 시작
- 핵심 키워드: 순전파(forward propagation), 역전파(back propagation)
