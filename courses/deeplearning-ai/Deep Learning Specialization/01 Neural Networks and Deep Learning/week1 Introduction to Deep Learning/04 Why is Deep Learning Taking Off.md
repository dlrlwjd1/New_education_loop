# Why is Deep Learning Taking Off?

## 개요

딥러닝(deep learning)·신경망(neural network)의 기본 기술 아이디어는 수십 년 전부터 있었습니다. 그런데 왜 **이제서야** 부상했을까요? 이 강의는 딥러닝 부상을 이끈 주요 동력 세 가지 — **데이터(data), 계산(computation), 알고리즘(algorithms)** — 를 설명합니다. 이를 이해하면 자신의 조직에서 딥러닝을 적용할 최고의 기회를 더 잘 찾을 수 있습니다.

## 내용

### 핵심 그림: 성능 vs 데이터 양

- **가로축(x)**: 보유한 데이터의 양
- **세로축(y)**: 학습 알고리즘의 성능(예: 스팸 분류 정확도, 광고 클릭 예측, 자율주행 차량 위치 인식 정확도)

```
성능
 |                                   ____ 큰 신경망 (large NN)
 |                              ___/
 |                         ___/______ 중간 신경망 (medium NN)
 |                    __/_/______ 작은 신경망 (small NN)
 |               __/_/ /
 |          ___/  /  /______________ 전통적 알고리즘 (SVM, 로지스틱 회귀)
 |        _/  / _/    (일정 수준에서 정체/plateau)
 |      _/ _/_/
 |____/_//________________________________ 데이터 양 (m)
```

- **전통적 알고리즘**(서포트 벡터 머신/SVM, 로지스틱 회귀/logistic regression): 데이터를 늘리면 한동안 성능이 좋아지다가 **곧 정체(plateau)** — 대량의 데이터를 활용할 줄 모르는 듯한 모습
- **신경망**: 클수록 좋음
  - 작은 신경망 → 어느 정도 성능
  - 중간 신경망 → 조금 더 나음
  - 매우 큰 신경망 → 데이터가 늘수록 성능이 **계속** 향상

### 왜 데이터가 많아졌나

- 지난 20여 년간 사회의 **디지털화(digitization)** 로 인간 활동 상당수가 디지털 영역으로 이동
- 컴퓨터·웹사이트·모바일 앱 사용이 데이터를 생성
- 휴대폰 카메라, 가속도계, IoT 센서 등 저렴한 기기 확산으로 데이터가 점점 더 많이 수집됨
- 결과적으로 **전통적 알고리즘이 효과적으로 활용할 수 있는 양을 넘어서는** 데이터가 축적됨

### "규모(scale)"가 딥러닝 발전을 이끈다

높은 성능에 도달하려면 두 가지가 필요:

1. **충분히 큰 신경망**을 학습시킬 수 있어야 함 (대량 데이터를 활용하기 위해)
2. 가로축에서 **오른쪽** — 즉 **많은 데이터**가 있어야 함

- 여기서 **규모(scale)** = (1) 신경망의 크기(은닉 유닛·파라미터·연결이 많음) + (2) 데이터의 규모
- 오늘날 성능을 높이는 가장 확실한 방법: **더 큰 네트워크를 학습**하거나 **더 많은 데이터를 투입**
- 단, 한계 존재: 결국 데이터가 떨어지거나, 네트워크가 너무 커서 학습이 너무 오래 걸림

### 그림을 더 정확하게 — 용어 정리

- 가로축은 정확히는 **레이블된 데이터(labeled data)** 의 양
  - 레이블된 데이터 = 입력 x와 레이블 y를 **둘 다** 가진 학습 예제(training examples)
- **표기법(notation)**: 소문자 **m** = 학습 세트(training set)의 크기 = 학습 예제 개수 (이후 코스에서 계속 사용)

### 데이터가 적을 때(small training set)

- 알고리즘 간 **상대적 우열이 뚜렷하지 않음**
- 이 구간에서는 **수작업 특성 공학(hand engineering features)** 실력이 성능을 좌우
- 예: 특성을 잘 설계한 SVM이 큰 신경망보다 나을 수도 있음
- **큰 데이터(large m) 구간**에서야 비로소 큰 신경망이 일관되게 우세

### 알고리즘 혁신 (특히 최근 몇 년)

- 초기 딥러닝 부상의 동력 = **데이터 규모 + 계산 규모**(CPU/GPU로 대형 신경망 학습)
- 최근에는 **알고리즘 혁신(algorithmic innovation)** 도 큰 기여
- 흥미롭게도 많은 알고리즘 혁신이 **신경망을 더 빨리 돌리는 것**에 관한 것

**대표 사례: Sigmoid → ReLU 전환**

| | Sigmoid 함수 | ReLU 함수 |
|---|---|---|
| 모양 | S자 곡선 | 0에서 꺾인 직선 |
| 문제/장점 | 양 끝에서 기울기(gradient)가 거의 0 → 학습이 매우 느림 | 양수 입력에서 기울기가 **항상 1** → 기울기가 0으로 줄어들 가능성↓ |

- **활성화 함수(activation function)** 를 sigmoid → ReLU로 바꾸자 **경사 하강법(gradient descent)** 이 훨씬 빨라짐
- 기울기가 0이면 경사 하강법에서 파라미터가 아주 느리게 변함 → 학습이 느림
- 비교적 단순한 알고리즘 혁신이지만, 결국 **계산을 도와** 더 큰 신경망을 합리적 시간 안에 학습 가능하게 함

### 빠른 계산이 중요한 또 다른 이유: 반복(iteration)

- 신경망 학습 과정은 매우 **반복적(iterative)**:

```
아이디어(Idea) → 코드 구현(Code) → 실험(Experiment)
      ↑__________________________________|
              (이 순환을 계속 반복)
```

- 학습이 오래 걸리면 이 순환 한 바퀴가 오래 걸림
- 10분~하루 만에 결과를 보는 것 vs 한 달씩 걸리는 것은 **생산성에 엄청난 차이**
- 빠르면 더 많은 아이디어를 시도 → 잘 작동하는 신경망을 발견할 가능성↑
- 실무자(practitioners)와 연구자(researchers) 모두 더 빨리 반복·개선 가능 → 딥러닝 연구 커뮤니티 전체에 큰 도움

## 예시

```
딥러닝 부상의 3대 동력:
  1. 데이터(Data)        — 디지털화·센서로 계속 증가
  2. 계산(Computation)   — GPU 등 특화 하드웨어, 빠른 네트워킹
  3. 알고리즘(Algorithms) — 예: Sigmoid → ReLU (gradient descent 가속)

→ 세 동력 모두 여전히 강하게 작동 중 → 딥러닝은 앞으로도 계속 발전 전망
```

## 요약

- 딥러닝 아이디어는 오래됐지만, **데이터·계산·알고리즘** 세 동력이 맞물려 이제서야 부상
- **규모(scale)** 가 핵심: 큰 신경망 + 많은 (레이블된) 데이터일수록 성능이 계속 향상 — 전통적 알고리즘은 일정 수준에서 정체
- 표기법: **m** = 학습 예제 개수(training set 크기)
- 데이터가 적으면 수작업 특성 공학 실력이 좌우, **큰 데이터 구간**에서 큰 신경망이 일관되게 우세
- 알고리즘 혁신의 핵심 사례 = **Sigmoid → ReLU** (기울기 소실 완화로 gradient descent 가속)
- 빠른 계산은 **아이디어→코드→실험** 반복 주기를 단축해 생산성을 크게 높임
- 세 동력 모두 여전히 강해 딥러닝은 앞으로도 계속 발전할 전망
