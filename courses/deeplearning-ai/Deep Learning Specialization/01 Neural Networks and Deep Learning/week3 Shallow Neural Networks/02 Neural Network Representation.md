# 02 Neural Network Representation

## 개요
- 신경망 그림의 각 부분에 이름을 붙이고 표기법을 정리한다.
- **단일 은닉층(single hidden layer)** 신경망 = "2층 신경망"을 기준으로 설명.

---

## 내용

### 층(layer)의 구성
```
 입력층        은닉층         출력층
(Input)      (Hidden)      (Output)
  x₁ ─┐
  x₂ ─┼──→  ( )( )( )( ) ──→ ( ) ──→ ŷ
  x₃ ─┘        4개 노드       1개 노드
```
| 층 | 이름 | 설명 |
|---|---|---|
| Input layer | 입력층 | 특징 x₁, x₂, x₃ |
| Hidden layer | 은닉층 | 훈련 데이터에서 참값이 **관측되지 않음(hidden)** |
| Output layer | 출력층 | 예측값 ŷ 생성 |

- **"hidden"의 의미**: 훈련 세트에는 입력 x와 출력 y만 있고, 중간 은닉층 노드의 참값은 보이지 않는다.

### 활성값(activation) 표기 a⁽ˡ⁾
- **a** = activation. 각 층이 다음 층으로 전달하는 값.
- **a⁽⁰⁾ = X** (입력층의 활성값 = 입력 특징). 입력 X의 다른 표기.
- **a⁽¹⁾** = 은닉층의 활성값. 노드별로 a₁⁽¹⁾, a₂⁽¹⁾, ... → 이 예시에서 **4차원 벡터**(4×1).
- **a⁽²⁾** = 출력층 활성값(실수 하나). **ŷ = a⁽²⁾**.
  - 로지스틱 회귀의 ŷ = a와 유사하나, 신경망에선 층을 나타내려 `[층번호]`를 붙임.

### 층 세는 규칙 ⚠️
- **입력층은 층 수에 세지 않는다.**
- 은닉층 = layer 1, 출력층 = layer 2 → 그래서 이 그림을 **"2층 신경망(2-layer NN)"** 이라 부름.
- 표기상 입력층은 layer 0.

### 파라미터 차원 (이 예시: 입력 3, 은닉 4, 출력 1)
| 파라미터 | 차원 | 이유 |
|---|---|---|
| W⁽¹⁾ | 4×3 | (은닉 유닛 4) × (입력 특징 3) |
| b⁽¹⁾ | 4×1 | 은닉 유닛 4개 |
| W⁽²⁾ | 1×4 | (출력 유닛 1) × (은닉 유닛 4) |
| b⁽²⁾ | 1×1 | 출력 유닛 1개 |

> 차원 규칙은 이후 영상에서 더 자세히 다룸.

---

## 요약
- 입력층 / 은닉층 / 출력층, 그리고 은닉층은 훈련 세트에서 값이 보이지 않아 "hidden".
- 활성값 a: a⁽⁰⁾=X, a⁽¹⁾=은닉층 출력, a⁽²⁾=ŷ.
- 층 수는 입력층을 빼고 세므로 은닉층 1개짜리는 "2층 신경망".
- 각 층은 파라미터 W⁽ˡ⁾, b⁽ˡ⁾를 가진다.
