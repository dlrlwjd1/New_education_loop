# 09 Gradient Descent for Neural Networks

## 개요
- 단일 은닉층 신경망의 **경사 하강(gradient descent)** 구현에 필요한 식을 정리한다.
- 순전파 4개 식 + 역전파 6개 식. (유도는 다음(선택) 영상)

---

## 내용

### 파라미터와 차원
입력 n₀, 은닉 유닛 n₁, 출력 n₂ (지금까진 n₂=1):
| 파라미터 | 차원 |
|---|---|
| W⁽¹⁾ | n₁ × n₀ |
| b⁽¹⁾ | n₁ × 1 |
| W⁽²⁾ | n₂ × n₁ |
| b⁽²⁾ | n₂ × 1 |

### 비용 함수 (이진 분류)
```
J(W⁽¹⁾,b⁽¹⁾,W⁽²⁾,b⁽²⁾) = (1/m) Σ L(ŷ⁽ⁱ⁾, y⁽ⁱ⁾)
```
- L은 로지스틱 회귀와 동일한 손실 함수(ŷ = a⁽²⁾).

### 경사 하강 루프
- **파라미터는 반드시 랜덤 초기화**(0으로 하면 안 됨 — 다음 영상에서 이유).
- 각 반복:
  1. 예측 계산 (순전파)
  2. 도함수 계산: dW⁽¹⁾, db⁽¹⁾, dW⁽²⁾, db⁽²⁾ (역전파)
  3. 업데이트:
     ```
     W⁽¹⁾ := W⁽¹⁾ − α dW⁽¹⁾ ;  b⁽¹⁾ := b⁽¹⁾ − α db⁽¹⁾
     W⁽²⁾ := W⁽²⁾ − α dW⁽²⁾ ;  b⁽²⁾ := b⁽²⁾ − α db⁽²⁾
     ```
  (α = 학습률(learning rate). 수렴할 때까지 반복.)

### 순전파 (벡터화)
```
Z⁽¹⁾ = W⁽¹⁾X + b⁽¹⁾
A⁽¹⁾ = g⁽¹⁾(Z⁽¹⁾)
Z⁽²⁾ = W⁽²⁾A⁽¹⁾ + b⁽²⁾
A⁽²⁾ = g⁽²⁾(Z⁽²⁾) = σ(Z⁽²⁾)   # 이진 분류
```

### 역전파 (벡터화, m개 예제)
```
dZ⁽²⁾ = A⁽²⁾ − Y
dW⁽²⁾ = (1/m) dZ⁽²⁾ A⁽¹⁾ᵀ
db⁽²⁾ = (1/m) np.sum(dZ⁽²⁾, axis=1, keepdims=True)
dZ⁽¹⁾ = W⁽²⁾ᵀ dZ⁽²⁾ * g⁽¹⁾′(Z⁽¹⁾)     # * 는 원소별 곱
dW⁽¹⁾ = (1/m) dZ⁽¹⁾ Xᵀ
db⁽¹⁾ = (1/m) np.sum(dZ⁽¹⁾, axis=1, keepdims=True)
```
- 앞 3개 식은 로지스틱 회귀의 경사 하강과 매우 유사.
- `dZ⁽¹⁾`: W⁽²⁾ᵀdZ⁽²⁾ (n₁×m)와 g⁽¹⁾′(Z⁽¹⁾) (n₁×m)의 **원소별 곱(element-wise)**.
- **`keepdims=True`**: np.sum이 (n,) 형태의 rank-1 배열 대신 (n×1) 벡터를 출력하게 해 이후 계산 오류 방지. (또는 reshape로 대체 가능)

---

## 요약
- 파라미터 랜덤 초기화 → (순전파 → 역전파 → 업데이트) 반복.
- 역전파 핵심: dZ⁽²⁾=A⁽²⁾−Y 에서 시작해 오른쪽→왼쪽으로 dW, db 계산.
- 미적분을 깊이 몰라도 이 식들만 정확히 구현하면 학습이 된다.
