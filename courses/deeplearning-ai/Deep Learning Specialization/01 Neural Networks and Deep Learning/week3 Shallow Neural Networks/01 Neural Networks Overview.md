# 01 Neural Networks Overview

## 개요
- 이번 주차의 큰 그림: **신경망(neural network)은 로지스틱 회귀(logistic regression)를 여러 번 반복한 것**과 같다.
- 세부 기술은 다음 영상들에서 다루고, 여기서는 전체 흐름과 표기법(notation)만 훑는다.

---

## 내용

### 로지스틱 회귀 복습
하나의 노드가 두 단계 계산에 대응:
```
x, w, b → z = wᵀx + b → a = σ(z) = ŷ → Loss L(a, y)
```

### 신경망 = 시그모이드 유닛을 쌓은 것
신경망은 작은 시그모이드 유닛을 **여러 층(layer)** 으로 쌓아 만든다. 각 층에서 z 계산 → a 계산이 반복된다.

```
x, W⁽¹⁾, b⁽¹⁾ → z⁽¹⁾ → a⁽¹⁾ = σ(z⁽¹⁾)
              → z⁽²⁾ → a⁽²⁾ = σ(z⁽²⁾) = ŷ → Loss
```

### 표기법 (Notation) ⚠️ 헷갈리기 쉬움
| 표기 | 의미 |
|---|---|
| **위첨자 대괄호 `[l]`** | **층(layer) 번호** — 예: z⁽¹⁾은 layer 1, z⁽²⁾은 layer 2 |
| **위첨자 소괄호 `(i)`** | **i번째 훈련 예제(training example)** — 예: x⁽ⁱ⁾ |

→ `[ ]`(층)과 `( )`(예제)를 혼동하지 말 것.

### 순전파 & 역전파
- **순전파(forward)**: z⁽¹⁾ → a⁽¹⁾ → z⁽²⁾ → a⁽²⁾ → Loss
- **역전파(backward)**: 오른쪽에서 왼쪽으로 미분 계산
  ```
  da⁽²⁾ → dz⁽²⁾ → dw⁽²⁾, db⁽²⁾ → da⁽¹⁾ → dz⁽¹⁾ → dw⁽¹⁾, db⁽¹⁾
  ```

---

## 요약
- 신경망은 로지스틱 회귀의 "z → a" 계산을 **층마다 반복**하는 구조.
- 층은 위첨자 `[l]`, 훈련 예제는 위첨자 `(i)`로 구분.
- 순전파로 출력·손실을 구하고, 역전파로 미분(gradient)을 구해 학습.
