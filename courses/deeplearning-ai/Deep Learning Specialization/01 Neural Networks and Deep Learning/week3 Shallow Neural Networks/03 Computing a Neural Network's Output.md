# 03 Computing a Neural Network's Output

## 개요
- 단일 은닉층 신경망이 입력 X로부터 출력 ŷ를 **어떻게 계산**하는지 단계별로 본다.
- 핵심: 각 은닉 노드는 로지스틱 회귀와 똑같이 "z → a" 두 단계를 수행하며, 이를 **벡터화(vectorization)** 해 4줄 코드로 만든다.

---

## 내용

### 노드 하나 = 로지스틱 회귀 두 단계
은닉층 i번째 노드:
```
z⁽¹⁾ᵢ = w⁽¹⁾ᵢᵀ x + b⁽¹⁾ᵢ
a⁽¹⁾ᵢ = σ(z⁽¹⁾ᵢ)
```
- 표기: a⁽ˡ⁾ᵢ 에서 위첨자 `[l]`=층 번호, 아래첨자 `i`=그 층의 노드 번호.

### 노드별 식을 벡터화
은닉 유닛 4개의 식을 for 루프로 계산하면 비효율적 → 행렬로 묶는다.

- 각 노드의 w 벡터(전치, 행벡터)를 **세로로 쌓아** 행렬 W⁽¹⁾ 구성 (이 예시 4×3).
  ```
  W⁽¹⁾ = [ —w⁽¹⁾₁ᵀ— ]
         [ —w⁽¹⁾₂ᵀ— ]
         [ —w⁽¹⁾₃ᵀ— ]
         [ —w⁽¹⁾₄ᵀ— ]   (4×3)
  ```
- **규칙(rule of thumb): 같은 층의 서로 다른 노드는 세로(수직)로 쌓는다.**

### 한 층의 계산 (벡터/행렬 형태)
```
z⁽¹⁾ = W⁽¹⁾ x + b⁽¹⁾
a⁽¹⁾ = σ(z⁽¹⁾)
```
차원 확인 (입력 3, 은닉 4):
```
z⁽¹⁾ (4×1) = W⁽¹⁾ (4×3) · x (3×1) + b⁽¹⁾ (4×1)
```
- σ는 z⁽¹⁾의 각 원소에 **원소별(element-wise)** 로 적용.
- **X = a⁽⁰⁾** 이므로 x 대신 a⁽⁰⁾로 써도 됨.

### 출력층 계산
```
z⁽²⁾ = W⁽²⁾ a⁽¹⁾ + b⁽²⁾
a⁽²⁾ = σ(z⁽²⁾) = ŷ
```
차원 (은닉 4, 출력 1): W⁽²⁾ (1×4), a⁽¹⁾ (4×1), b⁽²⁾ (1×1) → z⁽²⁾은 실수(1×1).
- 출력 유닛은 로지스틱 회귀와 동일 (w ↔ W⁽²⁾ᵀ, b ↔ b⁽²⁾).

---

## 예시: 출력 계산 4줄 코드
단일 입력 벡터 x에 대한 신경망 출력:
```python
Z1 = np.dot(W1, x) + b1   # (4,1)
A1 = sigmoid(Z1)          # (4,1)
Z2 = np.dot(W2, A1) + b2  # (1,1)
A2 = sigmoid(Z2)          # ŷ
```

---

## 요약
- 은닉 노드 각각은 로지스틱 회귀(z→a)와 동일. 같은 층 노드를 세로로 쌓아 벡터화.
- 4줄 식으로 신경망 출력 계산: z⁽¹⁾→a⁽¹⁾→z⁽²⁾→a⁽²⁾.
- 차원을 맞추는 것이 중요: W⁽¹⁾(4×3), W⁽²⁾(1×4) 등.
