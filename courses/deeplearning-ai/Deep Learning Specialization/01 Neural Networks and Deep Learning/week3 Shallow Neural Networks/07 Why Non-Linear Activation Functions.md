# 07 Why Non-Linear Activation Functions

## 개요
- 신경망이 흥미로운(복잡한) 함수를 계산하려면 **비선형(non-linear) 활성화 함수가 반드시 필요**하다.
- 선형(항등) 활성화 함수를 쓰면 층을 아무리 쌓아도 결국 **선형 함수 하나**와 같다.

---

## 내용

### 선형(항등) 활성화 함수를 쓰면?
g(z) = z (선형 = 항등(identity) 활성화 함수)로 두면:
```
a⁽¹⁾ = z⁽¹⁾ = W⁽¹⁾x + b⁽¹⁾
a⁽²⁾ = z⁽²⁾ = W⁽²⁾a⁽¹⁾ + b⁽²⁾
```
a⁽¹⁾를 대입:
```
a⁽²⁾ = W⁽²⁾(W⁽¹⁾x + b⁽¹⁾) + b⁽²⁾
     = (W⁽²⁾W⁽¹⁾)x + (W⁽²⁾b⁽¹⁾ + b⁽²⁾)
     = W′x + b′        ← 그냥 선형 함수!
```

### 결론
- **선형 함수의 합성은 여전히 선형 함수.** → 은닉층이 무의미해진다.
- 층을 아무리 많이 쌓아도 활성화가 선형이면 **은닉층 없는 것과 동일**.
- 은닉층에 선형, 출력층에 시그모이드를 써도 **은닉층 없는 로지스틱 회귀보다 나을 게 없다.**
- 그러므로 은닉층에는 **비선형(ReLU/tanh 등)** 을 꼭 넣어야 더 흥미로운 함수를 표현할 수 있다.

### 선형 활성화를 쓰는 유일한 경우: 회귀(regression)의 출력층
- y가 실수(예: **집값 예측**)이면 출력층에 선형 활성화를 써서 ŷ가 실수(−∞~∞)가 되게 할 수 있다.
- 단, **은닉층은 여전히 비선형**(ReLU/tanh 등)이어야 함.
- 집값처럼 음수가 없으면 출력층에 ReLU를 써 ŷ ≥ 0으로 만들 수도 있음.

---

## 요약
- 은닉층에 선형/항등 활성화를 쓰면 신경망 전체가 선형 함수로 붕괴 → 층이 무의미.
- 따라서 은닉층엔 반드시 비선형 활성화 함수 사용.
- 예외: 회귀 문제의 **출력층**에만 선형 활성화 사용 가능(은닉층은 비선형 유지).
