# 10 Backpropagation Intuition (Optional)

## 개요
- **(선택 영상)** 앞 영상의 역전파 6개 식이 어떻게 유도되는지 **계산 그래프(computation graph)** 와 연쇄 법칙(chain rule)으로 설명한다.
- 미적분을 깊이 몰라도 식을 구현하면 학습은 된다.

---

## 내용

### 로지스틱 회귀에서의 역전파 (복습)
순전파: x → z → a → L. 역전파:
```
da = −y/a + (1−y)/(1−a)
dz = da · g′(z) = a − y      (chain rule)
dw = dz · x
db = dz
```
- 연쇄 법칙: ∂L/∂z = ∂L/∂a · da/dz. a=σ(z)이므로 da/dz=g′(z) → dz = da·g′(z).

### 신경망 = 위 계산을 두 번
2층 신경망(입력→은닉→출력)의 역전파는 로지스틱 회귀 계산을 **두 번** 하는 것.
- 입력 x에 대해선 미분하지 않음(지도학습에서 x는 고정).
- da는 명시적으로 안 구하고 dz 계산에 합침(collapse).

단일 예제 6개 식:
```
dz⁽²⁾ = a⁽²⁾ − y
dw⁽²⁾ = dz⁽²⁾ a⁽¹⁾ᵀ        # LR의 dz·x와 유사, a¹이 x 역할 + 전치
db⁽²⁾ = dz⁽²⁾
dz⁽¹⁾ = W⁽²⁾ᵀ dz⁽²⁾ * g⁽¹⁾′(z⁽¹⁾)   # * = 원소별 곱
dw⁽¹⁾ = dz⁽¹⁾ xᵀ          # x = a⁽⁰⁾ 이므로 위와 동일 형태
db⁽¹⁾ = dz⁽¹⁾
```

### 차원 체크 = 버그 예방 팁 ⭐
- 규칙: 임의의 변수 `foo`와 `dfoo`는 **항상 같은 차원**. (W와 dW, z와 dz 등)
- dz⁽¹⁾ 차원 검산 (n₀ 입력, n₁ 은닉, n₂ 출력):
  ```
  dz⁽¹⁾ (n₁×1) = W⁽²⁾ᵀ (n₁×n₂) · dz⁽²⁾ (n₂×1)  *  g′(z⁽¹⁾) (n₁×1)
  ```
- **행렬 연산의 차원이 맞는지 확인하면 역전파 버그가 상당수 사라진다.**

### 벡터화 (m개 예제)
소문자 dz를 열로 쌓아 대문자 dZ로:
```
dZ⁽²⁾ = A⁽²⁾ − Y
dW⁽²⁾ = (1/m) dZ⁽²⁾ A⁽¹⁾ᵀ
db⁽²⁾ = (1/m) np.sum(dZ⁽²⁾, axis=1, keepdims=True)
dZ⁽¹⁾ = W⁽²⁾ᵀ dZ⁽²⁾ * g⁽¹⁾′(Z⁽¹⁾)
dW⁽¹⁾ = (1/m) dZ⁽¹⁾ Xᵀ
db⁽¹⁾ = (1/m) np.sum(dZ⁽¹⁾, axis=1, keepdims=True)
```
- `1/m`은 비용 함수 J가 손실의 평균이기 때문.

---

## 요약
- 역전파 = 연쇄 법칙으로 dz⁽²⁾→dw⁽²⁾,db⁽²⁾→dz⁽¹⁾→dw⁽¹⁾,db⁽¹⁾를 순서대로 계산.
- **변수와 그 미분은 같은 차원** → 차원 맞추기가 최고의 디버깅 도구.
- 역전파 유도는 머신러닝에서 가장 어려운 수학 중 하나지만, 식만 구현하면 잘 작동.
