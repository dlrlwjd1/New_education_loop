# 05 Explanation for Vectorized Implementation

## 개요
- 앞 영상의 벡터화 식(`Z⁽¹⁾ = W⁽¹⁾X + b⁽¹⁾`)이 **왜 올바른지** 행렬 곱으로 증명한다.

---

## 내용

### 왜 열로 쌓으면 맞는가 (b=0으로 단순화)
예제별 계산:
```
W⁽¹⁾ x⁽¹⁾ → 열벡터 z⁽¹⁾⁽¹⁾
W⁽¹⁾ x⁽²⁾ → 열벡터 z⁽¹⁾⁽²⁾
W⁽¹⁾ x⁽³⁾ → 열벡터 z⁽¹⁾⁽³⁾
```
예제들을 **열로 쌓은** 행렬 X에 W⁽¹⁾를 곱하면, 행렬 곱의 원리상 각 열이 각각의 결과가 된다:
```
W⁽¹⁾ · X = [ z⁽¹⁾⁽¹⁾ | z⁽¹⁾⁽²⁾ | z⁽¹⁾⁽³⁾ ] = Z⁽¹⁾
```
- 즉 "입력을 열로 쌓으면 → 출력도 열로 쌓여 나온다."

### b는 브로드캐스팅으로 처리
- b⁽¹⁾를 더하면 Python **브로드캐스팅(broadcasting)** 으로 각 열에 b가 개별적으로 더해져 결과가 여전히 올바름.

### 나머지 식도 동일 논리
- Z⁽¹⁾뿐 아니라 A⁽¹⁾, Z⁽²⁾, A⁽²⁾ 모두 같은 논리로 벡터화가 성립.

### 층의 대칭성 (중요한 직관)
- X = a⁽⁰⁾ 이므로 첫 식은 `Z⁽¹⁾ = W⁽¹⁾ a⁽⁰⁾ + b⁽¹⁾` 로 쓸 수 있다.
- 그러면 층 1과 층 2의 식이 **인덱스만 1씩 증가한 같은 형태**:
  ```
  Z⁽¹⁾ = W⁽¹⁾ a⁽⁰⁾ + b⁽¹⁾ ,  a⁽¹⁾ = σ(Z⁽¹⁾)
  Z⁽²⁾ = W⁽²⁾ a⁽¹⁾ + b⁽²⁾ ,  a⁽²⁾ = σ(Z⁽²⁾)
  ```
- → 신경망의 각 층은 **같은 계산을 반복**할 뿐. 심층 신경망은 이 두 단계를 더 여러 번 반복한 것(다음 주차).

---

## 요약
- 예제를 열로 쌓아 만든 X에 W를 곱하면 결과도 열로 쌓여 나오므로 벡터화가 올바름 (행렬 곱의 성질).
- b는 브로드캐스팅으로 각 열에 더해진다.
- 층 식은 인덱스만 다른 동일 형태 → 심층 신경망은 이 반복.
