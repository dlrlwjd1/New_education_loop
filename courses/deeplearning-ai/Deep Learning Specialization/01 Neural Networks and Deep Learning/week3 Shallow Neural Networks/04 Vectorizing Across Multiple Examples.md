# 04 Vectorizing Across Multiple Examples

## 개요
- 앞 영상은 **한 개** 예제의 출력 계산. 이번엔 **m개 훈련 예제 전체**를 for 루프 없이 벡터화한다.
- 로지스틱 회귀 때와 동일한 아이디어: 예제들을 **행렬의 열(column)에 쌓는다**.

---

## 내용

### 반복(비벡터화) 버전
```
for i = 1 to m:
    z⁽¹⁾⁽ⁱ⁾ = W⁽¹⁾ x⁽ⁱ⁾ + b⁽¹⁾
    a⁽¹⁾⁽ⁱ⁾ = σ(z⁽¹⁾⁽ⁱ⁾)
    z⁽²⁾⁽ⁱ⁾ = W⁽²⁾ a⁽¹⁾⁽ⁱ⁾ + b⁽²⁾
    a⁽²⁾⁽ⁱ⁾ = σ(z⁽²⁾⁽ⁱ⁾)
```
- 표기: a⁽²⁾⁽ⁱ⁾ 에서 `[2]`=층 2, `(i)`=i번째 훈련 예제.

### 벡터화 버전 (for 루프 제거)
예제들을 열로 쌓아 대문자 행렬 X, Z, A 구성:
```
Z⁽¹⁾ = W⁽¹⁾ X + b⁽¹⁾
A⁽¹⁾ = σ(Z⁽¹⁾)
Z⁽²⁾ = W⁽²⁾ A⁽¹⁾ + b⁽²⁾
A⁽²⁾ = σ(Z⁽²⁾)
```
- 소문자 벡터 x → 대문자 행렬 X (열로 쌓음), z→Z, a→A 도 마찬가지.

### 행렬의 행/열이 뜻하는 것 ⭐
X, Z, A 모든 행렬에서:
| 방향 | 의미 |
|---|---|
| **가로(열, 좌→우)** | 서로 다른 **훈련 예제(training example)** |
| **세로(행, 위→아래)** | 서로 다른 **노드/유닛** (X는 입력 특징) |

- 예: A⁽¹⁾의 좌상단 = (1번째 예제)의 (1번째 은닉 유닛) 활성값.
  - 아래로 내려가면 같은 예제의 다른 은닉 유닛, 오른쪽으로 가면 다른 예제.

### 표기의 의도
- 이 강좌의 표기법은 벡터화 단계를 쉽게 하려고 신중히 설계됨 → 정확한 구현을 빠르게 얻는 데 도움.

---

## 요약
- m개 예제를 열로 쌓으면, 단일 예제 식의 소문자를 대문자로만 바꿔 그대로 벡터화됨.
- 행렬에서 **가로=예제, 세로=노드(또는 특징)**.
- for 루프 없이 전체 훈련 세트의 출력을 한 번에 계산.
