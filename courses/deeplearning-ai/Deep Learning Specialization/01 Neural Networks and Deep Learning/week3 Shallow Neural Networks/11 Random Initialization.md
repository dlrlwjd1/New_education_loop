# 11 Random Initialization

## 개요
- 신경망 가중치 W는 **반드시 랜덤으로 초기화**해야 한다. (로지스틱 회귀는 0으로 초기화해도 됐지만, 신경망은 안 됨)
- 0으로 초기화하면 은닉 유닛들이 **대칭(symmetric)** 이 되어 모두 같은 함수를 계산한다.

---

## 내용

### 0으로 초기화하면 안 되는 이유 (대칭 문제)
예: 입력 2, 은닉 유닛 2. W⁽¹⁾ = [[0,0],[0,0]], b⁽¹⁾=[0,0]로 두면:
- 두 은닉 유닛의 활성값이 **항상 같다**: a₁⁽¹⁾ = a₂⁽¹⁾ (같은 함수 계산).
- 역전파에서도 dz₁⁽¹⁾ = dz₂⁽¹⁾ (대칭).
- dW의 모든 행이 같은 값 → 업데이트 후에도 두 유닛이 계속 동일.
- **귀납법(proof by induction)**: 아무리 오래 학습해도 두 유닛은 계속 같은 함수를 계산 → 은닉 유닛을 여러 개 둘 이유가 없어짐.
- 이를 **"symmetry breaking problem(대칭 깨기 문제)"** 이라 함.
- **b는 0으로 초기화해도 됨** (W가 랜덤이면 대칭이 이미 깨짐).

### 해결책: 랜덤 초기화
```python
W1 = np.random.randn(2, 2) * 0.01   # 작은 랜덤값
b1 = np.zeros((2, 1))               # b는 0으로 OK
W2 = np.random.randn(1, 2) * 0.01
b2 = 0
```

### 왜 0.01처럼 작은 값을 곱하나?
- W가 크면 z = Wx+b 도 커지고, tanh/sigmoid의 **평평한(saturated) 구간**에 놓임 → 기울기가 작아 **학습이 매우 느려짐**.
- 그래서 처음부터 z가 커지지 않도록 아주 작은 랜덤값으로 시작.
- sigmoid/tanh가 전혀 없으면 덜 중요하지만, 이진 분류로 출력층에 sigmoid가 있으면 특히 초기값이 크지 않아야 함.

### 0.01은 항상 최선인가?
- **얕은(shallow)** 신경망(은닉층 1개)엔 0.01이 대체로 무난.
- **아주 깊은(deep)** 신경망에선 다른 상수가 나을 수 있음 (다음 주차/Course 2에서 다룸). 어쨌든 대체로 작은 값.

---

## 요약
- W를 0으로 초기화 → 은닉 유닛 대칭 → 모두 같은 함수 학습 (무의미). b는 0 가능.
- 해결: `W = np.random.randn(...) * 0.01`로 **작은 랜덤값** 초기화.
- 작은 값을 쓰는 이유: 큰 W는 tanh/sigmoid 포화 구간에서 기울기를 죽여 학습을 느리게 함.
