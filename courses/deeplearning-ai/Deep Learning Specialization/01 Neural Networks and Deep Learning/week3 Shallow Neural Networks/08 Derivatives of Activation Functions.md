# 08 Derivatives of Activation Functions

## 개요
- 역전파(backpropagation)를 구현하려면 각 활성화 함수의 **기울기(도함수) g′(z)** 가 필요하다.
- 각 함수의 미분 공식을 정리한다. (대부분 이미 계산한 a로 빠르게 구할 수 있다.)

---

## 내용

### Sigmoid
```
g(z) = 1 / (1 + e⁻ᶻ)
g′(z) = g(z)(1 − g(z)) = a(1 − a)
```
검산:
- z=10 → g≈1 → g′≈1·(1−1)=0 ✓ (기울기 0)
- z=−10 → g≈0 → g′≈0 ✓
- z=0 → g=0.5 → g′=0.5·0.5=**0.25** ✓

### tanh
```
g(z) = tanh(z)
g′(z) = 1 − (tanh z)² = 1 − a²
```
검산:
- z=10 → tanh≈1 → g′≈1−1=0
- z=−10 → tanh≈−1 → g′≈1−1=0
- z=0 → tanh=0 → g′=**1**

### ReLU
```
g(z) = max(0, z)
g′(z) = 0  (z < 0)
        1  (z > 0)
        (z=0에서 미분 정의 안 됨 → 코드에선 0 또는 1로 둬도 무방)
```

### Leaky ReLU
```
g(z) = max(0.01z, z)
g′(z) = 0.01 (z < 0)
        1    (z > 0)
        (z=0은 마찬가지로 아무 값이나 무방)
```

### 표기와 실무 팁
- **g′(z)** = 미분의 약식 표기(prime).
- sigmoid·tanh는 도함수가 a로 표현되므로, **a를 이미 구했다면 g′를 매우 빠르게 계산** 가능.
- z=0에서 미분이 없어도 정확히 0이 될 확률이 극히 작아 실무상 문제없음 (전문가 용어로는 sub-gradient).

---

## 요약
| 함수 | g′(z) |
|---|---|
| Sigmoid | a(1−a) |
| tanh | 1−a² |
| ReLU | z<0: 0, z>0: 1 |
| Leaky ReLU | z<0: 0.01, z>0: 1 |
