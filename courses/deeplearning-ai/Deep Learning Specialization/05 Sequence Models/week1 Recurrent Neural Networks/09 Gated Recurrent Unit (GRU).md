# 09 Gated Recurrent Unit (GRU)

## 개요
- **GRU(Gated Recurrent Unit)**: RNN 은닉층을 수정해 **장거리 의존성**을 잘 잡고 경사 소실을 완화.

---

## 내용

### 핵심: 메모리 셀 c와 업데이트 게이트 ⭐
- **c⟨t⟩ (memory cell)**: 정보를 기억 (예: 주어가 단수/복수). GRU에선 **a⟨t⟩ = c⟨t⟩**.
- **후보값 c̃⟨t⟩**: c⟨t⟩를 대체할 후보.
- **업데이트 게이트 Γ_u**: 셀을 갱신할지 결정 (0~1, sigmoid). 직관상 대개 0 또는 1.

### 식 (간소화 GRU)
```
c̃⟨t⟩ = tanh(W_c·[c⟨t−1⟩, x⟨t⟩] + b_c)
Γ_u  = σ(W_u·[c⟨t−1⟩, x⟨t⟩] + b_u)
c⟨t⟩ = Γ_u * c̃⟨t⟩ + (1 − Γ_u) * c⟨t−1⟩
```
- Γ_u=1이면 새 후보값으로 **갱신**, Γ_u=0이면 **이전 값 유지**(기억 보존).
- 예: "cat"에서 단수 정보를 셀에 저장(Γ_u=1) → 중간엔 Γ_u=0으로 유지 → "was"에서 사용.

### 경사 소실 완화
- Γ_u가 아주 작으면(≈0) c⟨t⟩ ≈ c⟨t−1⟩ 로 값이 **거의 그대로 유지** → 많은 시점을 건너뛰어도 정보 보존 → 경사 소실 문제 크게 완화.

### 벡터·원소별
- c⟨t⟩는 벡터(예: 100차원), `*`는 **원소별 곱**. Γ_u는 어느 비트를 갱신할지 지정 → 일부 비트는 유지, 일부만 갱신 가능.

### Full GRU: 관련성 게이트 Γ_r 추가
```
c̃⟨t⟩ = tanh(W_c·[Γ_r * c⟨t−1⟩, x⟨t⟩] + b_c)
Γ_r  = σ(W_r·[c⟨t−1⟩, x⟨t⟩] + b_r)   # relevance: c⟨t−1⟩이 c̃⟨t⟩ 계산에 얼마나 관련있나
```
- GRU는 여러 실험 끝에 robust하다고 검증된 표준 버전. (또 다른 표준은 LSTM)

---

## 요약
- GRU = 메모리 셀 c + 업데이트 게이트 Γ_u(+ 관련성 게이트 Γ_r).
- Γ_u로 셀을 갱신/유지 → 장거리 의존성 포착, 경사 소실 완화.
