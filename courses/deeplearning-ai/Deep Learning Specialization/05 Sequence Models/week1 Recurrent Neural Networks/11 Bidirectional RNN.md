# 11 Bidirectional RNN

## 개요
- **양방향 RNN(BRNN)**: 한 시점의 예측에 **과거와 미래** 정보를 모두 활용.

---

## 내용

### 동기
- 단방향 RNN은 이전 정보만 사용 → "Teddy Roosevelt"(이름) vs "Teddy bears"(아님) 구분 불가.

### 구조
- **순방향(→)** 활성값: a⃗⟨1⟩ → a⃗⟨2⟩ → ... (왼→오).
- **역방향(←)** 활성값: a⃖⟨T⟩ → ... → a⃖⟨1⟩ (오→왼).
- 둘 다 **순전파(forward prop)** 임 (역전파 아님). 방향만 다름.
- 예측:
  ```
  ŷ⟨t⟩ = g(W_y·[a⃗⟨t⟩, a⃖⟨t⟩] + b_y)
  ```
- → ŷ⟨3⟩는 x⟨1⟩,x⟨2⟩,x⟨3⟩(순방향) + x⟨4⟩...(역방향)까지 반영.

### 실무
- 블록은 RNN/GRU/**LSTM** 아무거나 가능.
- NLP에서 **BRNN + LSTM**이 흔한 첫 시도.
- 단점: **전체 시퀀스가 있어야** 예측 가능 → 실시간 음성 인식엔 그대로 쓰기 어려움(더 복잡한 모델 필요).

---

## 요약
- BRNN = 순방향 + 역방향 활성값을 합쳐 예측 → 과거·미래 정보 모두 사용.
- NLP엔 BRNN+LSTM이 효과적. 단, 전체 시퀀스가 필요.
