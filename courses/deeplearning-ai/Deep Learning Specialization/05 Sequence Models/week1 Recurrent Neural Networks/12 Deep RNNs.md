# 12 Deep RNNs

## 개요
- **깊은 RNN(Deep RNN)**: RNN 층을 여러 개 쌓아 더 복잡한 함수를 학습.

---

## 내용

### 구조
- 표기: **a⁽ˡ⁾⟨t⟩** = 층 l, 시점 t의 활성값.
- 한 유닛은 **아래(이전 층)** 와 **왼쪽(이전 시점)** 에서 입력받음:
  ```
  a⁽²⁾⟨3⟩ = g(W_a⁽²⁾·[a⁽²⁾⟨2⟩, a⁽¹⁾⟨3⟩] + b_a⁽²⁾)
  ```
- 각 층은 **자기 파라미터**(W_a⁽ˡ⁾, b_a⁽ˡ⁾)를 시점 전체에서 공유.

### 특징 ⭐
- 일반 신경망은 100층도 흔하지만, RNN은 **시간 차원** 때문에 **3층만 돼도 이미 큼** → 깊게 쌓지 않음.
- 흔한 변형: 시간으로 연결된 순환 층 몇 개 위에, **시점 간 연결이 없는 깊은 일반 신경망**을 얹어 각 ŷ⟨t⟩를 예측.
- 블록은 RNN/GRU/LSTM 아무거나, **양방향(BRNN)** 의 깊은 버전도 가능.
- 계산 비용이 커 순환 층은 많이 쌓지 않음.

---

## 요약
- Deep RNN = 순환 층을 여러 개 쌓음(보통 3층 내외). 각 층은 아래·왼쪽 입력을 받고 층별 파라미터 공유.
- GRU/LSTM/양방향과 결합 가능.
