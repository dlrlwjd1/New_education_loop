# 04 Backpropagation Through Time

## 개요
- RNN의 역전파는 **시간 역방향(오른쪽→왼쪽)** 으로 진행 → **BPTT(Backpropagation Through Time)**.

---

## 내용

### 순전파 복습
- x⟨1⟩, a⟨0⟩ → a⟨1⟩ → a⟨2⟩ → ... (파라미터 **W_a, b_a는 모든 시점 공유**).
- a⟨t⟩ → ŷ⟨t⟩ (파라미터 **W_y, b_y 공유**).

### 손실 함수
- 시점별 손실 (교차 엔트로피/로지스틱):
  ```
  L⟨t⟩(ŷ⟨t⟩, y⟨t⟩) = −y⟨t⟩log ŷ⟨t⟩ − (1−y⟨t⟩)log(1−ŷ⟨t⟩)
  ```
- 전체 손실:
  ```
  L = Σ_{t=1}^{T_y} L⟨t⟩(ŷ⟨t⟩, y⟨t⟩)
  ```

### 시간 역전파 (BPTT)
- 순전파 화살표의 **반대 방향**으로 메시지를 전달해 미분 계산.
- 가장 중요한 재귀 계산이 **오른쪽→왼쪽(시간 역행)** 으로 흐름 → 이름 "backpropagation through time".
- 프레임워크가 자동 처리하지만 개념은 알아둘 것.

---

## 요약
- 시점별 손실을 합해 전체 손실 L 계산.
- 역전파는 시간을 거슬러(오른쪽→왼쪽) 진행 = BPTT.
