# 06 Language Model and Sequence Generation

## 개요
- **언어 모델(language model)**: 문장의 **확률 P(문장)** 을 추정. 음성 인식·기계 번역의 핵심 요소.

---

## 내용

### 언어 모델이란
- 예: "the apple and **pair** salad" vs "the apple and **pear** salad" — 발음은 같지만 후자가 훨씬 그럴듯 → 언어 모델이 P(문장)을 비교해 선택.
- 입력 문장 y⟨1⟩...y⟨T_y⟩ → 그 시퀀스의 확률 추정.

### 학습 데이터 준비
- **코퍼스(corpus)**: 대량의 문장 집합.
- **토큰화(tokenize)**: 문장을 단어로 나눠 어휘집 인덱스/one-hot으로.
- **EOS(end of sentence)** 토큰을 문장 끝에 추가(선택).
- 미등록 단어는 **`<UNK>`**.

### RNN 언어 모델
- 각 시점 t: 이전 **실제 단어** y⟨t−1⟩를 입력 x⟨t⟩로 받아, softmax로 **다음 단어의 확률 분포**(어휘집 전체) 예측.
  - x⟨1⟩=0, a⟨0⟩=0 → ŷ⟨1⟩ = P(첫 단어).
  - x⟨2⟩=y⟨1⟩(실제 첫 단어) → ŷ⟨2⟩ = P(둘째 | 첫째).
  - ... 마지막에 EOS 예측.

### 손실 & 문장 확률
- 손실: `L = Σ_t L⟨t⟩(ŷ⟨t⟩, y⟨t⟩)` (softmax 손실).
- 문장 확률:
  ```
  P(y⟨1⟩,y⟨2⟩,y⟨3⟩) = P(y⟨1⟩) · P(y⟨2⟩|y⟨1⟩) · P(y⟨3⟩|y⟨1⟩,y⟨2⟩)
  ```

---

## 요약
- 언어 모델 = 다음 단어를 한 번에 하나씩(왼→오) 예측하도록 RNN 학습.
- 각 시점 이전 실제 단어를 입력, softmax로 다음 단어 확률. 문장 확률 = 조건부 확률들의 곱.
