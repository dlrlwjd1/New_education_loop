# 03 Recurrent Neural Network Model

## 개요
- **RNN(순환 신경망)**: 시퀀스를 왼→오로 훑으며, 각 시점의 활성값을 다음 시점으로 전달.

---

## 내용

### 표준 신경망이 안 되는 이유
1. 예제마다 **입력/출력 길이가 다름**.
2. 텍스트의 **다른 위치에서 학습한 특징을 공유하지 못함** (Harry가 위치1에 있든 다른 위치에 있든 이름임을 일반화 못 함).
3. 파라미터 수가 거대 (one-hot × 큰 어휘집).

### RNN 구조
- 각 시점 t: 입력 x⟨t⟩ + **이전 시점 활성값 a⟨t−1⟩** → a⟨t⟩ → 예측 ŷ⟨t⟩.
- a⟨0⟩ = 0 벡터로 시작.
- **파라미터 공유**: 모든 시점이 같은 W_ax(입력→은닉), W_aa(은닉→은닉), W_ya(은닉→출력) 사용.
- → ŷ⟨3⟩ 예측 시 x⟨1⟩, x⟨2⟩ 정보도 활용.

### 한계
- **단방향(unidirectional)**: 이전 정보만 사용, 이후 정보는 못 씀.
  - 예: "Teddy Roosevelt..."(이름) vs "Teddy bears..."(아님) — 앞 3단어만으론 구분 불가.
- → 나중에 **양방향 RNN(BRNN)** 으로 해결.

### 순전파 식
```
a⟨t⟩ = g(W_aa·a⟨t−1⟩ + W_ax·x⟨t⟩ + b_a)     # 보통 tanh
ŷ⟨t⟩ = g(W_ya·a⟨t⟩ + b_y)                    # 이진분류면 sigmoid, 다중분류면 softmax
```

### 간소화 표기
```
a⟨t⟩ = g(W_a·[a⟨t−1⟩, x⟨t⟩] + b_a)   # W_a = [W_aa | W_ax] 가로 결합
ŷ⟨t⟩ = g(W_y·a⟨t⟩ + b_y)
```
- 두 행렬을 하나(W_a)로 압축, 두 벡터를 쌓아(stack) 곱함.

---

## 요약
- RNN = 시점마다 (이전 활성값 + 현재 입력)으로 활성값·예측 계산, 파라미터 공유.
- 순전파: `a⟨t⟩=g(W_aa·a⟨t−1⟩+W_ax·x⟨t⟩+b_a)`, `ŷ⟨t⟩=g(W_ya·a⟨t⟩+b_y)`.
- 단방향은 이후 정보를 못 쓰는 한계(→ BRNN).
