# 07 Sampling Novel Sequences

## 개요
- 학습된 언어 모델에서 **새 시퀀스를 샘플링**해 모델이 무엇을 배웠는지 파악.

---

## 내용

### 샘플링 절차
1. x⟨1⟩=0, a⟨0⟩=0 → softmax로 첫 단어 분포 → **분포에 따라 무작위 샘플**(`np.random.choice`)해 ŷ⟨1⟩ 선택.
2. 샘플한 ŷ⟨1⟩를 **다음 시점 입력 x⟨2⟩로 넣어** ŷ⟨2⟩ 샘플.
3. 반복. (이전에 샘플한 단어를 다음 입력으로 되먹임)
- **종료**: EOS 토큰이 나오면 멈춤. 또는 정해진 단어 수(20/100개)까지.
- `<UNK>`를 원치 않으면 나올 때마다 재샘플.

### Word-level vs Character-level
| | Word-level | Character-level |
|---|---|---|
| 어휘집 | 단어 | 알파벳/기호/숫자 |
| `<UNK>` | 필요 | 불필요(어떤 단어든 표현) |
| 시퀀스 길이 | 짧음 | **매우 김** |
| 장거리 의존성 | 잘 포착 | 약함 |
| 계산 비용 | 낮음 | 높음 |
- 대개 **word-level**을 씀. character-level은 특수 응용(미등록 단어 많은 경우 등)에.

### 예시
- 뉴스로 학습 → 뉴스 같은 텍스트, 셰익스피어로 학습 → 셰익스피어풍 텍스트 생성.

---

## 요약
- 샘플링: softmax 분포에서 단어를 뽑아 다음 입력으로 되먹이며 시퀀스 생성 (EOS 또는 길이로 종료).
- word-level(기본) vs character-level(UNK 불필요하나 길고 비쌈).
