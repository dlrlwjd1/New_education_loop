# 05 Learning Word Embeddings

## 개요
- 신경 언어 모델로 임베딩을 학습하는 방법. 복잡한 알고리즘 → 점점 단순화. (Bengio 등)

---

## 내용

### 신경 언어 모델 (Neural Language Model)
- "I want a glass of orange ___" 에서 다음 단어(juice)를 예측하도록 학습.
- 각 단어의 one-hot → **E·o = 임베딩(300차원)** → 여러 임베딩을 쌓아 은닉층 → softmax(1만 클래스).
- **고정 히스토리 윈도우**(예: 이전 4단어)를 쓰면 입력 크기가 고정(4×300=1200) → 문장 길이 무관.
- 파라미터: **행렬 E(모든 위치 공유)**, W₁·b₁, W₂·b₂. 역전파로 학습.
- 결과: orange·apple이 비슷한 임베딩을 갖도록 학습됨(훈련 세트를 더 잘 맞추려고).

### 다양한 컨텍스트(context) 선택 ⭐
목표가 임베딩 학습이면 컨텍스트를 다양하게 고를 수 있음:
- **이전 4단어** → 언어 모델에 자연스러움.
- **좌우 4단어씩** → 가운데 단어 예측.
- **직전 1단어**.
- **주변의 임의 1단어(nearby 1 word)** → 놀랍게도 잘 됨 = **Skip-gram** 아이디어.

---

## 요약
- 신경 언어 모델(이전 n단어→다음 단어)로 임베딩 행렬 E를 학습.
- 임베딩이 목표면 컨텍스트를 단순화(좌우/1단어/주변 단어) 가능 → 좋은 임베딩.
