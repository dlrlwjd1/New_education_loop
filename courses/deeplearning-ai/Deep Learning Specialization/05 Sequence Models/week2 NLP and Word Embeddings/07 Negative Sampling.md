# 07 Negative Sampling

## 개요
- **Negative sampling**: Skip-gram의 비싼 softmax를 **여러 개의 이진 분류**로 바꿔 효율적으로 임베딩 학습.

---

## 내용

### 새 지도학습 문제
- (컨텍스트, 타깃) 쌍이 **실제로 함께 등장한 쌍(1)인가, 무작위 쌍(0)인가**를 예측.
- 데이터 생성:
  - **양성(1)**: 컨텍스트(orange) + 윈도우 내 단어(juice) → 라벨 1.
  - **음성(0)**: 같은 컨텍스트(orange) + **사전에서 무작위로 뽑은 단어** k개 → 라벨 0 (king, book, the, of...).
  - (무작위 단어가 우연히 근처에 있어도 0으로 둠.)
- **k**: 작은 데이터셋 5~20, 큰 데이터셋 2~5.

### 모델
```
P(y=1 | c, t) = σ(θ_tᵀ e_c)
```
- 10,000개의 **이진 로지스틱 분류기**가 있는 셈이지만, 매 반복마다 **k+1개만** 학습(양성 1 + 음성 k).
- → 1만-way softmax 대신 **k+1개의 값싼 이진 분류** → 계산 비용 대폭↓.

### 음성 샘플링 분포 ⭐
- 경험적 빈도로 뽑으면 the/of 등 빈출어 과다, 균등이면 비현실적.
- 절충: **빈도의 3/4 제곱에 비례**:
  ```
  P(wᵢ) ∝ f(wᵢ)^{3/4}
  ```
  (이론적 근거는 약하나 실무에서 잘 작동.)

### 실무
- 오픈소스 구현·사전 학습 단어 벡터를 다운로드해 시작하는 것도 좋음.

---

## 요약
- Negative sampling = (양성 1 + 음성 k) 이진 분류로 skip-gram을 효율화. 매 반복 k+1개만 갱신.
- 음성은 빈도^(3/4)에 비례해 샘플.
