# 04 Embedding Matrix

## 개요
- 임베딩 학습의 결과물은 **임베딩 행렬(embedding matrix) E**.

---

## 내용

### 임베딩 행렬 E
- 어휘집 1만 단어, 임베딩 300차원이면 **E는 300 × 10,000** 행렬.
- E의 각 **열(column)** = 각 단어의 300차원 임베딩.

### one-hot과의 곱
- o₆₂₅₇ = 6257번(orange)만 1인 one-hot 벡터 (10,000×1).
- **E · o₆₂₅₇ = e₆₂₅₇** (300×1) — orange의 임베딩 열을 뽑아냄.
  - one-hot의 0들이 다 곱해져 사라지고 해당 열만 남음.

### 표기
```
e_j = E · o_j     (j번째 단어의 임베딩)
```

### 실무 참고
- 수학적으론 E·o_j 이지만, 행렬-벡터 곱은 비효율적 → 실제로는 **E에서 해당 열을 직접 조회(lookup)**.

---

## 요약
- 임베딩 행렬 E(300×10000)의 열이 각 단어 임베딩. E·o_j = e_j로 해당 열을 선택.
- 실제 구현은 곱셈 대신 열 lookup.
