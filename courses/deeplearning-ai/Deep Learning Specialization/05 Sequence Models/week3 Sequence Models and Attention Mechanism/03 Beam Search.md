# 03 Beam Search

## 개요
- **Beam Search(빔 서치)**: P(y|x)를 최대화하는 문장을 찾는 가장 널리 쓰이는 근사 탐색 알고리즘.

---

## 내용

### 빔 폭(beam width) B
- 각 단계에서 **B개**의 후보를 동시에 유지 (greedy는 B=1).
- 예: B=3.

### 절차
1. **첫 단어**: 디코더 softmax로 P(y⟨1⟩|x) 계산 → 상위 **B개** 단어 저장 (예: in, Jane, September).
2. **둘째 단어**: B개 각각에 대해, y⟨1⟩를 고정 입력해 P(y⟨2⟩|x, y⟨1⟩) 계산.
   - 쌍 확률 = P(y⟨1⟩|x) · P(y⟨2⟩|x, y⟨1⟩).
   - B × 10,000 = 30,000개 후보 중 **상위 B개** 선택 (예: "in September", "Jane is", "Jane visits").
   - → September가 첫 단어 후보에서 탈락할 수 있음.
3. **셋째 단어**: 각 후보에 대해 앞 두 단어를 고정해 P(y⟨3⟩|x, y⟨1⟩, y⟨2⟩) 계산 → 상위 B개.
4. 반복하며 EOS까지.

### 구현
- 빔 폭 B이면 네트워크 **B개 복사본**으로 각 단계의 모든 후보를 효율적으로 평가 (30,000개 복사 불필요).
- B=1이면 greedy search. B가 크면 더 나은 문장을 찾지만 계산↑.

---

## 요약
- Beam search = 각 단계에서 상위 B개 부분 문장을 유지하며 확장 (쌍 확률 = 조건부 확률들의 곱).
- B=1이면 greedy. B가 클수록 대개 더 나은 번역.
