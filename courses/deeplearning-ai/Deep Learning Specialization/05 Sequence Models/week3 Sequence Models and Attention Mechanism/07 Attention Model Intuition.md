# 07 Attention Model Intuition

## 개요
- **어텐션 모델(attention model)**: 인코더-디코더가 문장을 **부분씩** 보며 번역하도록 개선. 딥러닝에서 가장 영향력 있는 아이디어 중 하나. (Bahdanau, Cho, Bengio)

---

## 내용

### 동기
- 기본 인코더-디코더는 **긴 문장 전체를 기억**해야 함 → 30~40단어 넘으면 BLEU 급락.
- 인간 번역가는 **부분을 읽고 조금 번역, 다음 부분 읽고...** 를 반복.
- 어텐션은 이렇게 부분씩 처리 → 긴 문장에서도 성능 유지.

### 구조 개념
- **양방향 RNN(BRNN)** 으로 각 입력 단어 위치의 풍부한 특징(a⟨t'⟩) 계산.
- **디코더 RNN**(은닉 상태 s⟨t⟩)이 각 출력 단어를 생성할 때, 입력의 어느 부분을 볼지 **어텐션 가중치 α⟨t,t'⟩** 를 계산.
  - α⟨1,1⟩, α⟨1,2⟩... = 첫 단어 생성 시 입력 각 단어에 얼마나 주목할지.
  - 이 가중치로 **컨텍스트 c⟨t⟩** 를 만들어 디코더에 입력.
- 각 출력 시점 t마다 새 α, 새 컨텍스트 → 입력의 **국소 윈도우**에 집중.

### 어텐션 가중치
- α⟨t,t'⟩ (t번째 영어 단어 생성 시 t'번째 프랑스어 단어에 주는 주목도)는 BRNN의 a⟨t'⟩(순·역방향)와 이전 디코더 상태 s⟨t−1⟩에 의존. (상세는 다음 영상)

---

## 요약
- 어텐션 = 디코더가 각 단어를 생성할 때 입력의 어느 부분에 **주목(α)** 할지 정해 컨텍스트를 만듦.
- 긴 문장 기억 부담을 없애 긴 문장 번역 성능↑.
