# 08 Attention Model

## 개요
- 어텐션 모델의 상세: 어텐션 가중치 α와 컨텍스트 c의 계산.

---

## 내용

### 구조
- **양방향 RNN(BRNN, 보통 LSTM)**: 각 입력 위치 t'의 특징 **a⟨t'⟩** (순·역방향 concat).
- **단방향 디코더 RNN**(상태 s⟨t⟩): 컨텍스트 c⟨t⟩를 입력받아 y⟨t⟩ 생성.

### 컨텍스트 = 어텐션 가중합
```
c⟨t⟩ = Σ_{t'} α⟨t,t'⟩ · a⟨t'⟩
```
- **α⟨t,t'⟩**: t번째 출력이 t'번째 입력에 주는 주목도. **비음수, Σ_{t'} α⟨t,t'⟩ = 1**.

### 어텐션 가중치 계산 (softmax)
```
α⟨t,t'⟩ = exp(e⟨t,t'⟩) / Σ_{t''} exp(e⟨t,t''⟩)
```
- **e⟨t,t'⟩**: 작은 신경망(은닉층 1개)으로 계산. 입력 = **s⟨t−1⟩**(이전 디코더 상태) + **a⟨t'⟩**(입력 특징).
- 직관: t' 단어에 얼마나 주목할지는 (이전 디코더 상태, 그 단어의 특징)에 의존 → 신경망이 역전파로 자동 학습.

### 단점
- **이차 비용(quadratic)**: 어텐션 파라미터 수 = T_x × T_y. (번역은 문장이 짧아 대체로 수용 가능)

### 응용
- 기계 번역 외 **이미지 캡셔닝**(그림의 일부에 주목), **날짜 정규화** 등.
- 어텐션 가중치를 시각화하면 출력 단어가 올바른 입력 단어에 주목함을 확인 가능.

---

## 요약
- c⟨t⟩ = Σ α⟨t,t'⟩·a⟨t'⟩, α는 softmax(작은 신경망 e⟨t,t'⟩(s⟨t−1⟩, a⟨t'⟩)).
- 어디에 주목할지 역전파로 자동 학습. 비용은 O(T_x·T_y).
