# 05 Error Analysis in Beam Search

## 개요
- 번역이 나쁠 때, **beam search 탓인지 RNN(모델) 탓인지** 오류 분석으로 판별.

---

## 내용

### 두 컴포넌트
- **RNN 모델**(encoder-decoder): P(y|x) 계산.
- **Beam search**: P(y|x)를 최대화하는 y를 찾으려는 근사 탐색.

### 판별 방법 ⭐
- y* = 사람의 좋은 번역, ŷ = 알고리즘의 나쁜 번역.
- RNN으로 **P(y*|x)** 와 **P(ŷ|x)** 를 계산해 비교:

| 경우 | 결론 |
|---|---|
| **P(y*|x) > P(ŷ|x)** | **Beam search 잘못** — 더 확률 높은 y*를 못 찾음 |
| **P(y*|x) ≤ P(ŷ|x)** | **RNN 잘못** — 더 좋은 y*에 낮은 확률 부여 |

- (길이 정규화를 쓰면 확률 대신 정규화된 목적값으로 비교.)

### 오류 분석 절차
- dev 세트의 각 나쁜 출력에 대해 B(beam) 또는 R(RNN) 원인을 표시.
- **B/R 오류 비율**을 집계:
  - Beam이 대부분 → 빔 폭 늘리기.
  - RNN이 대부분 → 정규화/데이터 추가/구조 변경 등(Course 3 기법).

---

## 요약
- P(y*|x) vs P(ŷ|x)로 원인 판별: y*가 더 높으면 beam search, ŷ가 더 높으면 RNN 잘못.
- 오류 비율을 집계해 빔 폭을 키울지 모델을 고칠지 결정.
