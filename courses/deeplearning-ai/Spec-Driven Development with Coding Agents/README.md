**강사:** Paul Everett (JetBrains Developer Advocate)

## 개요
**Spec-Driven Development(SDD, 명세 주도 개발)** — 코딩 에이전트로 진지한 애플리케이션을 만들 때의 워크플로를 다루는 단발성 짧은 코스. 코드를 손으로 쓰는 대신 **명세(spec)에 맥락을 담아** 에이전트가 구현하게 한다. 프로젝트 **헌법(constitution)** 작성부터 **기능 개발 루프(계획·구현·검증)**, 재계획, MVP, 레거시(브라운필드) 도입, 스킬·표준을 통한 워크플로 자동화·에이전트 교체까지 실습 중심으로 진행한다. 예제 프로젝트는 **AgentClinic**(Next.js + React).
