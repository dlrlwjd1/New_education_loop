# Conclusion

## 개요
- 코스 전체를 마무리하며 배운 내용을 요약하는 영상.

## 코스 전체 요약

| 모듈 | 핵심 내용 |
|---|---|
| **Module 1** | 에이전틱 AI로 가능해진 새로운 애플리케이션, 핵심 디자인 패턴 소개 |
| **Module 2** | **Reflection** 디자인 패턴 — 간단하게 성능을 끌어올리는 방법 |
| **Module 3** | **Tool use / function calling** — LLM 능력 확장, 그 중요한 사례인 **코드 실행(code execution)** |
| **Module 4** | **Evaluations & Error analysis** — building ↔ analyzing을 오가며 규율 있게 성능을 개선하는 프로세스 (오래 쓸수록 가장 유용한 재료) |
| **Module 5** | **Planning & Multi-agent** — 훨씬 강력하지만 때로 제어·예측이 어려운 시스템 구축 |

## 맺음말
- 이 코스의 스킬로 다양하고 흥미로운 에이전틱 AI 애플리케이션을 만들 수 있다.
- Andrew Ng: 채용 면접에서 이 코스에서 다룬 **바로 그 스킬들**을 평가하는 경우가 많다 → 새로운 커리어 기회로 이어질 수 있음.
- 마지막 당부: **책임감 있게(responsibly)** 사용하고, 멋진 것을 만들어라(go build cool stuff).

## 요약
- Reflection → Tool use/Code execution → Evals & Error analysis → Planning & Multi-agent 로 이어지는 에이전틱 AI 설계 스킬 셋을 완성.
- 재미로든 실무로든, 이제 강력한 에이전틱 워크플로를 직접 구축할 수 있다.
