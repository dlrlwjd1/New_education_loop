# Benefits of Agentic Workflows

## 핵심 이점

Agentic 워크플로우의 가장 큰 이점은 기존 방식으로는 효과적으로 수행하기 어려웠던 태스크를 가능하게 한다는 점입니다.

주요 이점:
- 성능 향상: 단일 프롬프트 기반 생성보다 훨씬 높은 품질과 정확도
- 병렬화: 여러 하위 작업을 동시에 실행하여 속도 개선
- 모듈성: 검색 엔진, 툴, LLM 모델 등을 목적에 맞게 조합하거나 교체 가능

## 성능 향상

HumanEval 코딩 벤치마크 예시:

| 방식 | 모델 | 성능 |
|------|------|------|
| Non-agentic workflow | GPT-3.5 | 40% |
| Non-agentic workflow | GPT-4 | 67% |
| Agentic workflow | GPT-3.5 | GPT-4 직접 생성보다도 큰 개선 가능 |
| Agentic workflow | GPT-4 | 더 높은 성능 가능 |

중요한 관찰:
- GPT-3.5에서 GPT-4로의 모델 세대 향상은 매우 큼
- 하지만 이전 세대 모델(GPT-3.5)에 Agentic 워크플로우를 적용했을 때의 개선 폭이 더 클 수 있음
- 예: 코드 작성 후 스스로 검토(reflection)하고 개선하는 단계를 추가하면 성능이 크게 향상

> 최신 LLM을 사용하더라도 Agentic 워크플로우를 적용하면 더 나은 결과를 얻을 수 있음

## 병렬화

Agentic 워크플로우는 일부 태스크를 병렬로 처리할 수 있습니다.

### 블랙홀 에세이 작성 예시

1. 여러 LLM이 병렬로 웹 검색어 아이디어 생성
2. 각 검색 결과에서 상위 웹페이지 후보 식별
3. 여러 웹페이지를 동시에 다운로드
4. 수집된 자료를 LLM에 입력하여 에세이 작성

사람이 리서치한다면 9개의 웹페이지를 순차적으로 읽어야 하지만, Agentic 워크플로우는 웹페이지 다운로드와 일부 처리 단계를 병렬화할 수 있습니다.

특징:
- 단일 프롬프트 직접 생성보다는 시간이 더 걸림
- 하지만 사람이 순차적으로 수행하는 방식보다 훨씬 빠를 수 있음
- 특히 검색, 다운로드, 후보 생성처럼 독립적인 작업에서 효과적

## 모듈성

Agentic 워크플로우는 여러 컴포넌트로 구성되므로 각 부분을 교체하거나 개선하기 쉽습니다.

### 교체 가능한 컴포넌트 예시

| 컴포넌트 | 예시 |
|----------|------|
| 웹 검색 엔진 | Google, Bing, DuckDuckGo, Tavily, You.com |
| 검색 방식 | 일반 웹 검색, 뉴스 검색, 논문 검색 등 |
| LLM | 단계별로 다른 모델 또는 다른 LLM 제공자 사용 |

예:
- 일반 웹 검색 대신 최신 블랙홀 과학 뉴스를 찾기 위한 뉴스 검색 엔진 사용
- 검색어 생성 단계와 최종 글쓰기 단계에 서로 다른 LLM 사용
- 특정 단계에서 가장 좋은 결과를 내는 모델을 실험적으로 선택

## 요약

- Agentic 워크플로우의 가장 큰 장점은 다양한 애플리케이션에서 성능을 크게 높일 수 있다는 점
- 병렬화를 통해 사람이 순차적으로 해야 하는 작업을 더 빠르게 처리할 수 있음
- 모듈형 설계 덕분에 툴과 모델을 유연하게 추가, 교체, 개선할 수 있음
