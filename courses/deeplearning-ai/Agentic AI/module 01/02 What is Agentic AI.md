# What is Agentic AI

## 기존 LLM 사용 방식의 한계

기존 방식: 프롬프트를 입력하면 LLM이 처음부터 끝까지 한 번에 결과를 출력

- 사람도 백스페이스 없이 처음부터 끝까지 선형으로 글을 쓰지 않음
- LLM도 마찬가지로 이 방식이 최선이 아님
- 그럼에도 LLM은 이 제약 안에서 놀랍도록 잘 수행함

## Agentic 워크플로우란

LLM 기반 앱이 **여러 단계(multiple steps)** 를 실행하여 하나의 태스크를 완료하는 프로세스

### 에세이 작성 예시 비교

| 기존 방식 | Agentic 워크플로우 |
|-----------|------------------|
| 프롬프트 → 바로 완성본 출력 | 아웃라인 작성 → 웹 리서치 → 초안 작성 → 검토 및 수정 → 최종본 |

### Agentic 워크플로우 단계 (에세이 예시)
1. LLM으로 에세이 아웃라인 작성
2. 웹 검색 API 호출을 위한 검색어 생성
3. 다운로드된 웹페이지를 LLM에 입력하여 초안 작성
4. 별도 LLM으로 초안 검토 및 수정 필요 부분 파악
5. (선택) Human-in-the-loop — 주요 사실 관계 사람이 검토
6. 초안 수정 및 최종본 완성

> Agentic 워크플로우는 더 오래 걸리지만, **훨씬 높은 품질의 결과물**을 만들어냄

## 핵심 스킬: 태스크 분해(Task Decomposition)

복잡한 태스크를 작은 단계로 쪼개어 각 단계를 Agentic 워크플로우로 실행하는 능력

- 태스크를 단계별로 분해하는 방법
- 각 단계를 잘 실행하는 컴포넌트를 구축하는 방법

→ 이 두 가지가 다양한 애플리케이션에 Agentic 워크플로우를 구축하는 핵심 역량

## 강의 실습 예제: Research Agent

강의 전반에 걸쳐 직접 구축할 예제

**동작 방식:**
1. 리서치 주제 입력 (예: "SpaceX와 경쟁할 로켓 회사를 어떻게 만드는가")
2. 리서치 계획 수립
3. 웹 검색 → 웹페이지 다운로드
4. 결과 종합 및 순위화
5. 아웃라인 초안 작성
6. 편집 에이전트가 일관성 검토
7. 최종 마크다운 보고서 생성

**활용 분야 (강사 경험):**
- 법률 문서 컴플라이언스
- 헬스케어 분야
- 비즈니스 제품 리서치

## 다음 주제

Agentic 워크플로우의 **자율성(Autonomy) 수준** — 단순한 워크플로우부터 고도로 자율적인 워크플로우까지의 스펙트럼과 각각의 구축 난이도 프레임워크
