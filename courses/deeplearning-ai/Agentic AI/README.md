# Agentic AI

**Course URL:** https://www.deeplearning.ai/courses/agentic-ai
**제공:** DeepLearning.AI
**강사:** Andrew Ng

## 개요
에이전틱 AI 워크플로를 설계·구축하는 방법을 다루는 5개 모듈 과정. 핵심 디자인 패턴(Reflection, Tool use, Planning, Multi-agent)과 평가·오류 분석 기반의 규율 있는 개발 프로세스를 배운다. 모든 강의 노트는 한국어로 정리되어 있다.

## 모듈 구성

### module 01 — Introduction to Agentic Workflows
1. Course Introduction
2. What is Agentic AI
3. Autonomy Spectrum
4. Benefits of Agentic Workflows
5. Agentic AI Applications
6. Task Decomposition
7. Evals and Error Analysis (+ 대화정리)
8. Design Patterns (+ 대화정리)

### module 02 — Reflection Design Pattern
1. Reflection
2. Direct Generation vs Reflection
3. Reflection for Chart Generation (+ 대화정리)
4. Evals for Reflection Workflows
5. Reflection with External Feedback
6. Improving SQL Generation with Reflection

### module 03 — Tool Use
1. Tool Use Introduction
2. How LLMs Use Tools
3. Tool Use Implementation
4. Turning Functions into Tools
5. Lab - Email Assistant Workflow
6. Code Execution Tool
7. MCP (Model Context Protocol)

### module 04 — Practical Tips for Building Agentic AI
1. Evaluations (evals)
2. Error analysis and prioritizing next steps
3. More error analysis examples
4. Component-level evaluations
6. How to address problems you identify
7. Latency, cost optimization
8. Development process summary

> 5번 슬롯은 Ungraded Lab(Code Example), 9번은 Module 4 Quiz라 노트 없음.

### module 05 — Patterns for Highly Autonomous Agents
1. Planning workflows
2. Creating and executing LLM plans
3. Planning with code execution
5. Multi-agentic workflows
7. Communication patterns for multi-agent systems
10. Conclusion

> 4·6번 슬롯은 Ungraded Lab, 8·9번은 Quiz/Graded Assignment, 11번은 Acknowledgments라 노트 없음.
