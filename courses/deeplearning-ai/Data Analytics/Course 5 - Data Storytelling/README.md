# Course 5 — Data Storytelling

**Specialization:** [Data Analytics](../README.md)
**제공:** DeepLearning.AI
**강사:** Andrew Ng, Sean Barnes

## 개요
분석 결과를 **의사결정으로 이어지는 데이터 스토리**로 전환하는 코스. 내러티브 구성·리포트/메모/슬라이드 작성부터 Tableau로 차트·대시보드·스토리를 만드는 실무, 그리고 데이터 분석 **구직 과정**(탐색·네트워킹·이력서·면접)까지 다룬다.

## 모듈 구성
1. **Module 1 — Communicating insights** (영상 14개) — 기술 역량→비즈니스 가치, 데이터 스토리텔링·내러티브, 결론 도출·근거 선택/배열, 리포트 디자인·피드백, 메모·노트북·슬라이드덱·부록
2. **Module 2 — Tableau fundamentals** (영상 17개) — Tableau 입문·워크북·데이터 모델, 집계/비집계 차트·계산 필드·인코딩·필터/정렬·라벨/주석·툴팁, 날짜/계층·시계열·파이/도넛·지도·테이블·히트맵
3. **Module 3 — Dashboards and stories** (영상 12개) — 대시보드 구성 요소·인사이트 선택·레이아웃·액션·게시·채택, 선형/비선형 스토리
4. **Module 4 — Job search** (영상 7개) — 구직 과정·직무 탐색·네트워킹·이력서/포트폴리오·면접(리크루터/기술/행동/케이스)·다음 단계

> 각 모듈 하위 폴더에 영상 강의 정리본(`NN 주제.md`)이 들어간다. Quiz·Lab·Reading·Lecture Code/Notes·Capstone은 노트 대상에서 제외한다.
