# Tooltips

## 개요
- **툴팁(tooltip)** 은 데이터 점에 호버 시 나타나는 동적 팝업 — 화면을 어지럽히지 않고 **온디맨드** 로 상세를 제공한다.
- 주석처럼 정적+동적 콘텐츠를 섞고, **다른 시트의 시각화까지 삽입** 할 수 있다.

## 내용

### 텍스트 툴팁
- 툴팁에 표시할 필드는 먼저 **뷰에 있어야** 함 → units in stock·on order를 **Marks의 Tooltip 상자**에 드래그.
- **Marks → Tooltip** 편집(텍스트처럼): 기존 텍스트 삭제 후 "In stock: SUM(units in stock), On order: SUM(units on order)" 등 **Insert 메뉴**의 동적 값 사용(Insert에 없으면 뷰에 먼저 추가).

### 시각화 삽입
- 툴팁에 차트 삽입(다른 시트에 미리 생성). 호버한 제품으로 **자동 필터**.
- **Tooltip → Insert → Sheets → 시트 선택**(예 Available Units). 크기(픽셀, 예 200×200) 조정.
- 원 시트 수정(축 헤더·색 등) 시 툴팁에도 **반영**.

### 저장
- **Publish**.

## 요약
- **툴팁**은 호버 시 나타나는 동적 팝업으로 온디맨드 상세를 제공하며, 필드는 먼저 **Tooltip 상자**에 넣어야 쓸 수 있다.
- 텍스트+동적 값을 편집하고 **다른 시트 시각화를 삽입**(자동 필터)할 수 있다.
