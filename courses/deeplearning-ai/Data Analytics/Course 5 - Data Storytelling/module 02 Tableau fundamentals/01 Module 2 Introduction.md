# Module 2 Introduction

## 개요
- **Module 2 — Tableau로 차트 만들기(Creating Charts in Tableau)** 소개.
- 업계 표준 시각화 도구 Tableau로 개별 차트를 만들고, 다음 모듈에서 대시보드로 조립한다.

## 내용

### 레슨 구성
- **Lesson 1**: Tableau 핵심 — **집계(aggregated)·비집계(disaggregated) 차트**, 데이터 소스 연결·조작.
- **Lesson 2**: 차트 다듬기 — 서식·필터·주석, 디자인 선택이 가독성에 미치는 영향.
- **Lesson 3**: 시계열 시각화(날짜 계층·라인 차트), 고급 차트 유형(**지도·파이/도넛·히트맵**).

## 요약
- 이 모듈은 **Tableau**로 인터랙티브·전문가급 시각화를 만든다.
- Lesson 1(집계/비집계 차트) → Lesson 2(서식·필터·주석) → Lesson 3(시계열·고급 차트) 순으로 진행한다.
