# Introduction to Tableau

## 개요
- **Tableau** 는 가장 널리 쓰이는 데이터 시각화 도구 — 인터랙티브·전문가급 대시보드를 만든다.
- Python·스프레드시트 대비 3대 장점: **라이브 데이터·인터랙티브 시각화·로우코드 UI**.

## 내용

### 대시보드 예시 (Sample Superstore)
- 지역별 매출 지도·차트·막대 등. **필터 클릭**으로 데이터 동적 갱신(예: Central 클릭 → 중부만), 호버로 상세, **다중 필터**(Technology + West) 동시 적용.
- 상호작용 방법은 명확하지 않을 수 있음 → **청중에게 사용법 안내 필요**(다음 모듈).

### 3대 장점
1. **라이브 데이터 연결**: DB·클라우드·API에 직접 연결, 자동 갱신.
2. **인터랙티브 시각화**: 동적 필터·툴팁·링크로 사용자가 직접 탐색.
3. **로우코드 UI**: 계산은 코딩 가능하나 대부분 UI로. **속도** 이점(기술적 이점 아님 — 정교한 분석은 Python: 단순 회귀는 Tableau, 다중 회귀는 Python).

### 버전·대안
- **Tableau Public**(무료, 기능 제한 — 이 코스 사용) vs **Desktop**(더 많은 데이터 소스·오프라인 저장). Tableau Agent(AI)는 유료.
- 대안: Microsoft **Power BI**, Google **Looker Studio**(Sheets·Numbers·Excel 관계처럼 유사 — 기술 전이됨).

## 요약
- **Tableau**는 **라이브 데이터·인터랙티브·로우코드**로 대시보드를 만드는 업계 표준 도구다.
- 필터·툴팁·다중 필터로 사용자가 데이터를 탐색하며, 정교한 분석은 여전히 Python이 낫다.
- 무료 **Tableau Public**을 사용하며 스킬은 Power BI·Looker로 전이된다. 다음 강의는 새 워크북 만들기다.
