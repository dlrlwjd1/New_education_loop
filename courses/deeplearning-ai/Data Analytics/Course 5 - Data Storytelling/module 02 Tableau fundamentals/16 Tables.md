# Tables

## 개요
- **표(tables)** 는 스프레드시트 같은 형식으로 데이터를 개별 표시·비교하며, 스크롤·필터·동적 정렬을 지원한다.
- 조건부 서식으로 히트맵의 기초가 된다.

## 내용

### 표 만들기
- Country(Rows) + Count of Customers·Count of Orders·Unit Price(Columns). Unit Price 집계 **Average**.
- 막대로 나오면 **Show Me → Table**. 회사명(Company Name)을 Rows에 추가로 세분화.
- 열 정리: 구분선 드래그로 너비, 헤더 높이, 이름 변경(Average Unit Price → Average Price).
- **정렬**: 열 헤더로 정렬(주 카테고리 내에서도 정렬). 게시 후 청중이 자기 뷰 커스터마이즈.

### 조건부 서식 → 하이라이트 테이블
- Count of Orders를 **Color** 에 → 텍스트 색. Marks를 **Square** 로 → **하이라이트 테이블**(셀 음영).

### 총계 행
- **Analysis → Totals → Show Column Grand Totals**. 우클릭 → Column Totals to Top(상단으로). 전체 스냅샷(예 평균 단가 $29, 830주문, 5.1만+ 제품).

### 저장
- 보고서 부록·직접 전송에 적합. **Publish**.

## 요약
- **표**는 데이터를 개별 표시하며 Show Me → Table로 만들고, 스크롤·정렬·필터를 지원한다.
- Color + **Square** 마크로 **하이라이트 테이블**을, **Grand Totals** 로 총계 행을 추가한다.
- 다음 강의는 **히트맵**이다.
