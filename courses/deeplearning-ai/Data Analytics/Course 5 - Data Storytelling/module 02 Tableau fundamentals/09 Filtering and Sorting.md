# Filtering & Sorting

## 개요
- **필터링(filtering)** 으로 관련 데이터만 보고, **정렬(sorting)** 으로 순서를 정한다.
- Tableau는 **인터랙티브 필터**를 표시해 청중이 직접 선택하게 할 수 있다.

## 내용

### 필터링
- 필드를 **Filters 카드**에 드래그 → 기본 표시 구성(All 등) 선택.
- **인터랙티브 필터 표시**: 필드 우클릭 → **Show Filter** → 청중이 카테고리 선택. 척도(예 평균 단가)도 자동 갱신.
- **다중 필터**: 여러 필드를 Filters에 추가(예 Category Name + Price Bin), 각각 Show Filter → 조합 탐색(예 expensive만).

### 정렬
- 필터 후에도 정렬 유지. 오름/내림 전환 가능(필터에도 적용됨).

### 저장·공유
- **Publish**. 게시 뷰에서 청중이 필터 체크/해제로 맞춤 보기.

## 요약
- **필터링**(Filters 카드 + **Show Filter**)으로 관련 데이터만 보이고 청중이 직접 선택하게 한다.
- **다중 필터**·**정렬**을 함께 적용할 수 있으며 정렬은 필터에도 유지된다.
- 다음 강의는 **라벨·주석**이다.
