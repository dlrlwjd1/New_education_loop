# Data Encoding

## 개요
- **데이터 인코딩(data encoding)** 은 데이터를 시각 속성(**색·크기·모양·위치**)으로 변환하는 것.
- Tableau의 **Marks 카드**에서 색·크기 등을 조정해 핵심 인사이트에 주목을 유도한다.

## 내용

### 색 (color)
- 차원을 **Marks의 Color** 에 드래그 → 범주별 색 + 범례. **Edit Colors** 로 팔레트 변경(colorblind 등).
- **특정 항목 강조**: 시트 복사 → 색 제거·중립 회색 → Cmd/Ctrl로 여러 막대 선택 → 우클릭 **Group** → 강조. 범례는 **Edit Alias** 로 이름 변경(예 "supplier inquiry"). 막대 사이 선을 드래그해 크기 조정.
- **색 그라디언트**: 수치 필드(예 unit price)를 Color에 → 그라디언트. 집계 맞추기(average), 드롭다운 **Format → Currency** 로 통화 표시.

### 크기·모양 (size·shape)
- 산점도에 유용. 기본 원 → **Filled points**, 색·**불투명도(75%)** 조정(겹침 완화).
- **버블 차트(bubble chart)**: 수치 필드(unit price)를 **Size** 에 → 크기로 표현(고가 항목이 재고·주문 낮은 좌하단 군집 확인). Fit With로 창 확대.

### 저장
- **Publish**.

## 요약
- **데이터 인코딩**은 데이터를 **색·크기·모양·위치**로 변환하며, Marks 카드에서 조정한다.
- **색**(범주 구분·그라디언트·그룹 강조), **크기**(버블 차트), **모양·불투명도** 로 인사이트를 강조한다.
- 다음 강의는 **필터링·정렬**이다.
