# Maps

## 개요
- **지도(maps)** 는 지리 데이터 시각화 유형 — 위도·경도로 마커·음영을 배치한다.
- 여러 지역·국가 비교 시 어느 지역이 두드러지는지 한눈에 보인다.

## 내용

### 지도 만들기
- Country 필드를 워크스페이스에 드래그 → 각 국가 점의 **심볼 맵(symbol map)**(점 많을 때 유용, 예 도시).
- 국가 수가 적으면 **음영 지역**: Marks 드롭다운 → **Map**. 상단 툴바로 줌.
- **색 척도**: Count of Orders를 **Color** 에 → 단일 색 그라디언트(밝음→진함, 예 6~122). 독일 많음.
- 색 옵션: Edit Colors(팔레트·**Stepped Color** 로 색 구간). 상단 **Map** 메뉴로 지리 배경(심볼 맵에 유용), Map Options로 축척.

### 저장 주의
- **Publish 시 팬·줌 상태 그대로 게시** → 원하는 확대 수준으로 맞춘 뒤 게시.

## 요약
- **지도**는 위도·경도로 지리 데이터를 시각화하며, 점 많으면 **심볼 맵**, 적으면 **음영 지역(Map)** 을 쓴다.
- **Count를 Color** 에 넣어 단일 색 그라디언트로 강도를 표현하고, 게시 시 줌 상태가 그대로 저장된다.
- 다음 강의는 **표(tables)** 다.
