# Creating a Slide Deck

## 개요
- **슬라이드 덱(slide deck)** 은 가장 보편적인 스토리텔링 형식 — 시각적이고 청중을 단계별로 안내한다.
- 라이브 발표에 적합: 통제된 전달·시각적 스토리텔링·실시간 설명.

## 내용

### 장점
- **통제된 전달**: 정보 흐름을 발표자가 결정(순서 건너뛰기·오독 방지).
- **시각적 스토리텔링**: 차트·불릿으로 복잡한 데이터를 한눈에. 말로 설명하니 **글자 적게**.
- **실시간 설명**: 안 통하면 즉시 강조·질문 응답.

### 구조
1. **제목 슬라이드**: 주제·기대 설정(브랜드 가이드·템플릿).
2. **주요 결론 슬라이드**: 핵심 takeaway·비즈니스 질문 답(최소한, 서술은 말로).
3. **맥락 슬라이드**: 모집단·표본·기간·핵심 지표.
4. **핵심 인사이트 슬라이드**: 시각 자료로 뒷받침(여러 개, 내러티브 구축).
5. **권고 슬라이드**: 데이터 기반 해결책·명확한 call to action.
- 예(이탈): 제목 → "이탈 10%↑, 초기 참여·가격 민감성" → 맥락(1,000명 표본) → 인사이트(첫 3개월 주 2h 미만 이탈 3배) → 권고(온보딩 개인화·가격 테스트) → 피드백 초대.

### LLM 활용
- **발표자 노트(speaker notes)** 생성, 슬라이드 텍스트 다듬기, 청중별 맞춤(경영진·기술팀·마케팅).
- 단 LLM 문구는 다소 robotic → **발표자가 자연스럽게 다듬어야** 함.

## 요약
- **슬라이드 덱**은 라이브 발표에 적합하며 통제된 전달·시각·실시간 설명이 강점이다.
- 구조는 **제목 → 주요 결론 → 맥락 → 핵심 인사이트 → 권고(+CTA)** 이며 글자는 적게 둔다.
- LLM으로 발표자 노트·문구·청중 맞춤을 돕되 직접 다듬는다. 다음 강의는 **부록(appendices)** 이다.
