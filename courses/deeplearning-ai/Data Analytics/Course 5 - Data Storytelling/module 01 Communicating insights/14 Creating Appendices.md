# Creating Appendices

## 개요
- **부록(appendix)** 은 주요 스토리에 덜 핵심적인 정보를 담는 곳(노트북·메모·슬라이드 등 어디든 추가).
- 본문은 간결하게 유지하되, 부록으로 **깊이·신뢰성(credibility)** 을 제공한다.

## 내용

### 부록의 역할
- 본문(주요 인사이트) 외의 정보를 관심 있는 청중에게 제공(분석의 "사이드 퀘스트").
- **신뢰 구축**: 구체적 질문("1년 전 이탈률은?")에 문서화된 답·참조 표 제공 → 방법론 신뢰↑.
- 본문은 **의사결정용으로 간결**, 부록은 **증거·방법론 큐레이션**.

### 부록에 넣을 것
- **원시 데이터 요약**(복잡한 데이터셋의 투명성 표).
- **방법론·가정**(예: 결측 행 삭제 같은 분석 선택).
- **상세 계산·통계 검정**(참조용).
- **추가 차트·표**(본문에 안 맞는 것).
- **용어집(glossary)**(기술 용어·지표 설명).

### 넣지 말 것
- 중복·사소·핵심 메시지를 흐리는 것. 예: 지역이 이탈에 영향 있어도 **실행 불가**하면(지역별 다른 경험 제공 불가) 제외.

## 요약
- **부록**은 본문에 덜 핵심적인 정보(원시 데이터·방법론·계산·추가 차트·용어집)를 담아 깊이·신뢰성을 준다.
- 본문은 간결히 유지하고, **중복·비실행 정보**는 부록에도 넣지 않는다.
