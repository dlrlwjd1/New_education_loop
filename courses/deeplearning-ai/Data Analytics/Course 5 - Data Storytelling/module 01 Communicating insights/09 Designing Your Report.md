# Designing Your Report

## 개요
- 보고서는 데이터 스토리 요소(주요 결론·지지 증거·결론 재진술)를 담으며, **디자인 요소**로 강화한다.
- 명확한 구조 + 시각적 매력으로 메시지 전달을 높인다.

## 내용

### 보고서 구조
1. **제목·저자·메타데이터**: 서술적 제목, 저자, 최종 수정일.
2. **경영 요약(executive summary)**: 1~2문단으로 주요 결론(바쁜 경영진용, 비즈니스 질문 먼저 답).
3. **데이터 출처·방법론**: 모집단·표본·핵심 지표.
4. **지지 증거**: 데이터·시각화·설명을 엮음(상향/하향, 중요도순).
5. **결론·권고**: 실행 가능한 next steps.

### 시각적 매력 팁
- **일관된 단일 폰트**, **계층적 헤딩**(간격·볼드로 눈에 띄게), **일관 색상(2~3색)**. 회사 **브랜드 가이드라인**(로고·색·폰트) 준수.
- 좋은 예 vs 나쁜 예: 같은 정보라도 헤딩·폰트 크기·페이지 번호·로고·번호 매긴 핵심 발견이 있으면 훨씬 **스캔하기 쉬움**. 작은 변화가 큰 차이.

## 요약
- 보고서 구조: **제목/메타데이터 → 경영 요약 → 데이터·방법론 → 지지 증거 → 결론·권고**.
- **일관 폰트·계층 헤딩·2~3색·브랜드 가이드**로 스캔하기 쉽고 매력적으로 만든다.
- 다음 강의는 두 보고서 비교(디자인 효과)다.
