# Ordering Evidence

## 개요
- 지지 증거를 설득력 있게 배열한다 — 보고서는 **구조화된 논증(structured argument)**.
- 두 접근: **상향식(bottom-up)** 과 **하향식(top-down)**.

## 내용

### 상향식 (bottom-up)
- 작은 인사이트 → 큰 인사이트 → 주요 결론(자연스러운 귀결).
- 예: "평균 사용자" 두 명(Kelly=기존, Fahad=스폰서 신규) 개별 스토리 → "우리 플랫폼엔 Kelly 1.4만·Fahad 1만 명" → 거시 추세. 개별 경험 → 매크로 추세의 추론 사슬 → 분석 신뢰↑.

### 하향식 (top-down)
- 전체 모집단 → 하위 그룹 세분화.
- 예: "전체 2천만 분 시청(전월 1,710만) → 그중 8%+가 스폰서 링크". 큰 그림 → 성장 원천으로 드릴다운. 전체 성장 후 원천을 보일 때 유용.

### 주의
- 두 방식은 **지지 증거 배열** 방법이지 보고서 전체 구조가 아님.
- 전체 구조는 항상 **주요 결론 먼저 → 데이터 맥락 → (상향/하향 증거) → 결론 재진술+권고**.

## 요약
- 지지 증거는 **상향식**(작은 것→큰 것) 또는 **하향식**(전체→세분화)으로 배열한다.
- 이는 증거 배열 방식이며, 보고서 전체는 **주요 결론 먼저·재진술 마지막**을 유지한다.
- 다음 강의는 보고서를 시각적으로 디자인하는 법이다.
