# Module 1 Introduction

## 개요
- **Module 1 — 데이터 스토리텔링 기초(Data Storytelling Fundamentals)** 소개.
- 데이터를 명확하고 임팩트 있는 인사이트로 변환해 의사결정을 돕는다.

## 내용

### 레슨 구성
- **Lesson 1**: 데이터 스토리텔링이 기술 분석을 **비즈니스 가치**에 연결. 핵심 질문 식별, 인사이트 구조화, 이해관계자 요구 정렬.
- **Lesson 2**: **보고서(report)** — 데이터 형식별 정보 전달, 청중·맥락별 접근, 동료·LLM 피드백 반영.
- **Lesson 3**: 다른 산출물 — **메모·Python 노트북·슬라이드**, 부록·문서화 모범 사례.

## 요약
- 이 모듈은 데이터 기반 **내러티브**로 인사이트를 효과적으로 전달하는 법을 배운다.
- Lesson 1(비즈니스 가치·구조화) → Lesson 2(보고서·피드백) → Lesson 3(메모·노트북·슬라이드) 순으로 진행한다.
