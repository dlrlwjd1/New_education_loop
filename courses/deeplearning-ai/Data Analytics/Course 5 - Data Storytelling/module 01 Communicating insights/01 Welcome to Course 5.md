# Welcome to Course 5

## 개요
- **Data Storytelling** — 데이터 애널리틱스 전문 과정의 다섯 번째이자 마지막 코스.
- 분석 결론에 **스토리(story)** 를 입혀 더 기억에 남고 이해하기 쉬운 발표를 만든다(스토리는 사실·통계만보다 6~13배 더 기억됨).

## 내용

### 왜 스토리텔링인가
- 예: "제품 A가 B보다 20% 더 팔림"(건조한 사실) → "A가 바이럴 소셜 캠페인으로 100만 명에 도달해 급성장"(스토리) — 결론의 이유를 이해시킴.
- 데이터 스토리텔링 = **소통·공통 이해 구축**. 대개 기술 세부에 덜 익숙한 사람과 소통.
- **반복(iteration)** 이 핵심: 빠른 초안 → 피드백 → 개선. 대시보드도 많은 시각화로 시작해 피드백으로 streamline.

### 코스 내용
- **Module 1**: 핵심 산출물(보고서·메모·노트북·슬라이드), 인사이트 선택·증거 배열·디자인.
- **Module 2·3**: **Tableau** 기초 — 라이브 데이터 연결·인터랙티브 시각화(업계 표준, Power BI·Looker Studio와 유사).
- **Module 4**: 데이터 애널리스트 **구직 과정**.
- 전 모듈에 **LLM** 활용(시각화 개선·피드백).

## 요약
- 이 코스는 분석 결론에 **스토리**를 더해 기억에 남는 소통을 만든다.
- Module 1(산출물·내러티브) → 2·3(Tableau) → 4(구직) 순으로 진행하며 반복·피드백이 핵심이다.
- Tableau는 라이브·인터랙티브 시각화 강점의 업계 표준 도구다.
