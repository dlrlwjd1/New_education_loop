# Crafting a Narrative

## 개요
- 데이터 내러티브는 학교 에세이(도입→본문→결론) 구조를 **버리고**, **결론부터 시작**한다(이해관계자는 setup 볼 시간 없음).
- **관점 취하기(perspective-taking)** — 청중의 도전·결정·필요를 파악해 구조를 짠다.

## 내용

### 관점 취하기
- 청중의 관심이 다르므로 이해관계자를 알기 — 무슨 도전, 어떤 결정, 어떤 정보가 도움? 가정 말고 **질문·경청**.
- 단 **객관적**으로 — 듣고 싶은 말이 아니라 진실을 전하는 **진실의 수호자**.

### 구조: 결론 → 근거 → 결론
1. **주요 결론(main conclusion)** 부터 — 핵심 비즈니스 질문의 답. 이것만 들어도 메시지 전달.
2. **중간(근거)**: 데이터·접근·맥락·표본·범위·한계. 지지 증거(결론으로 이어지는 인사이트)에 시간 대부분.
3. **결론 재진술 + 권고(next steps)**.

### 예시 (공포 영화 시청)
- 시작: "지난달 공포 시청 17% 증가(역대 최대), 상위 공포 게임 스트리머 스폰서십 덕분. 스폰서십 확대로 타 장르도 유사 증가 가능." (30초만 들어도 핵심)
- 중간: 표본(3만 명), 접근(스폰서 링크 클릭 후 행동), 인사이트(스폰서 링크로 발견 시 시청 시간 17%↑, 1% 수준 유의) + 차트.
- 마무리: 결론 재진술 + 권고(타 장르 확대).

### "So What?"
- 이해관계자 머릿속 질문. 인사이트는 **행동을 유도할 때만** 가치. 데이터를 **임팩트·행동**에 연결(시청 증가만 말하면 "그래서?" → 원인·회사가 할 일까지).

## 요약
- 데이터 내러티브는 **결론부터** 시작하고, **관점 취하기**로 청중에 맞춘다.
- 구조는 **주요 결론 → 지지 증거(데이터·접근·맥락) → 결론 재진술+권고**다.
- 항상 **"So What?"**(왜 중요·무엇을 할까)에 답해 행동을 유도한다. 다음 레슨은 **보고서**다.
