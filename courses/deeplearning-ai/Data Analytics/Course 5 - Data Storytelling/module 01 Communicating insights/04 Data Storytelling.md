# Data Storytelling

## 개요
- **데이터 스토리텔링(data storytelling)** 은 인사이트를 내러티브로 빚어 청중을 **이해와 행동**으로 이끄는 것.
- 애널리스트는 청중을 핵심 인사이트로 안내하는 **투어 가이드** — 청중이 스스로 해석하지 않게 미리 의미를 정리.

## 내용

### 개념
- 좋은 데이터 스토리는 인사이트가 보고서에 묻히지 않고 **실제 결정**으로 이어지게 함.
- **UX 디자인**과 유사 — 잘 설계하면 해석이 자동으로 이뤄짐. 예: 3분기 매출 하락(공급망), 유지율 증가(가격 인하), 프로모션 효과 등을 한눈에.

### 산출물(artifacts)
- 슬라이드·메모·노트북·대시보드 등. 시각 디자인·레이아웃으로 안내.
- 공통 고려: **주요 결론 선택 + 지지 증거 + 증거 순서**.

### 시각화가 핵심
- 잘 만든 차트는 표보다 효과적. **인사이트에 맞는 차트** 선택 + 명료성·효율·맥락 원칙.
- 예: "Alexa" 이름 아기 추이(라인 차트, 복잡성 최소·주석·일관 색) → 단일 고품질 시각화가 완전한 스토리(아마존 Alexa 출시가 감소 원인).
- 타깃 청중 **피드백**으로 다듬기.

### 스토리 구축 절차
1. **질문·문제**로 시작(어떤 결정이 필요한가).
2. **적절한 데이터** 선택(핵심 결과 + 관련 맥락, 모든 맥락이 동등하지 않음).
3. **분석 수행**(패턴·추세·관계·이상, 근본 원인).
4. **산출물 개발**(행동 유도로 패키징).
- 이 모듈은 **4단계(산출물)** 에 집중.

## 요약
- **데이터 스토리텔링**은 인사이트를 내러티브로 빚어 행동으로 이끌며, 애널리스트는 투어 가이드다.
- **시각화가 핵심**(인사이트에 맞는 차트 + 디자인 원칙 + 피드백)이며, 단일 시각화가 완전한 스토리가 될 수 있다.
- 절차: 질문 → 데이터 선택 → 분석 → 산출물. 다음 강의는 **내러티브 구성**이다.
