# Module 4 Introduction

## 개요
- **Module 4(구직, Job Search)** 는 그동안 쌓은 분석 역량을 **적합한 역할**에 적용하도록 구직 과정 각 단계를 준비시킨다.

## 내용

### 모듈 구성
- **레슨 1**: 구직 과정 개요 + 나에게 맞는 직무 찾기, 채용 공고(job listing) 평가 실습.
- **레슨 2**: 네트워킹(networking) 기초 — 파이썬이 아닌 **대면** 관계 구축 핵심 기술.
- **레슨 3**: 이력서(resume)·포트폴리오(portfolio) — 스킬·경험을 잘 표현하는 법.
- **레슨 4**: 면접(interview) 정복 — 리크루터·행동(behavioral)·기술(technical) 면접 유형과 대응.

## 요약
- 이 모듈은 **구직 과정 전 단계**(탐색·네트워킹·이력서·면접)를 다룬다.
- 데이터 분석 직무를 자신 있게 찾고 확보하는 것이 목표다.
