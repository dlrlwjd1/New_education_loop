# Searching for Jobs

## 개요
- 미국만 매년 데이터 사이언스 직무(분석가 포함) **2만+** 개 — 방대한 공고에서 **적합한 것**을 걸러내는 탐색 전략이 필요하다.

## 내용

### 어디서 찾나
- **LinkedIn**: 네트워킹+공고, 회사·채용 매니저 프로필 확인 가능.
- **애그리게이터(Indeed 등)**: 웹 스크래핑·API로 여러 사이트 수집 — 폭넓지만 정보가 최신·정확하지 않을 수 있음.
- **회사 웹사이트**: 가장 정확·최신이나 일일이 보기엔 비효율.

### 키워드 전략
- 데이터 분석가는 **다른 이름**도 많음 — business analyst, BI analyst, (때때로) data scientist, 도메인별(marketing/product/financial analyst).
- **좁게 시작 → 점차 확대**(broad-first는 압도적).

### 공고 평가 3단계
1. **회사 적합성(company fit)**: 시작일·근무지·급여·전반 요건이 내 조건과 맞는지.
2. **하드 요건(hard requirements)**: 필수(학위·연구 경험 등). 회사는 대개 많이 나열 — 대부분 충족하면 OK.
3. **기타 요건(경력 연차·숙련도)**: 유연성 있음 — 유사 경험/역량으로 어필(예: MySQL 요구 → SQLite 경험으로 SQL 기초 강함 주장, 빠른 업스킬 가능).

### 예시 (Netflix 공고)
- LA 온사이트, 급여 $50k~$240k(배경 따라 넓음).
- **Qualifications = 하드 요건**: SQL·고급 스프레드시트(미경험이면 부적합). "highly preferred"(세무 경험)는 하드 아님 — 차별화 요소.
- **소프트 스킬**(소통·정리·문제 단순화)도 근거로 어필.

### REACH 롤
- 완전히 자격 안 되는 리치 롤 지원은 OK지만 **기회비용** 유념 — 대부분은 **강하게 자격 있는** 역할에 집중.

## 요약
- **LinkedIn·애그리게이터·회사 사이트**에서, 다양한 직함 키워드로 **좁게→넓게** 탐색한다.
- 공고는 **회사 적합성 → 하드 요건 → 기타 요건** 순으로 평가한다.
- 자격을 입증할 수 있는 역할에 집중하되, 다음 단계는 **네트워킹** 활용이다.
