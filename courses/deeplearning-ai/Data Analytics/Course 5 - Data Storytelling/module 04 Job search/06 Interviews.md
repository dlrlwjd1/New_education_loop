# Interviews

## 개요
- 데이터 분석 채용은 대개 **여러 면접**을 포함 — 주요 유형은 **리크루터·기술·행동·케이스 스터디**.

## 내용

### 리크루터 면접 (recruiter interview)
- **초기 스크리닝** — 역할 세부(책임·복지·근무지·보상) 정렬 + 기초 요건 확인. 리크루터는 실무엔 깊지 않음.
- **양방향 타당성 체크(two-way feasibility check)**: 회사는 자격, 나는 조건 적합성 평가.
- 준비: **개인 스토리** 연습 — 왜 이 기회에 왔는지, 커리어 전환(pivot)·교육 투자 설명(전환은 강력한 스토리).

### 기술 면접 (technical interview)
- 통계·프로그래밍·SQL 테스트. **동기(라이브 코딩)** 또는 **비동기(테이크홈 과제)**.
- 예: 테이블 조인으로 LEGO 테마별 세트 최다 찾기, 결측치 처리, 시간-엽록소 농도 관계 시각화.
- 라이브 코딩은 **협업적** — 질문·명확화 가능. **문제 분해·접근 설명·협업** 방식이 핵심(정답 노력 + 소프트 스킬 차별화).
- 준비: 연습 문제·책, **LeetCode**(역할에 따라 안 나올 수도).

### 행동 면접 (behavioral interview)
- **문화 적합성·소프트 스킬**(소통·끈기) 평가. 예: "비전문가에게 복잡한 분석 설명한 경험", "동료와 이견", "가장 지원이 필요한 영역".
- 성장 영역 질문은 함정 아님 — **겸손·성장 마인드셋** 평가. 직접 경험 없으면 **어떻게 접근할지** 설명 OK.
- 준비: **개인 일화(anecdotes)** 준비(협업·분석 소통·지속 학습·오너십), LLM으로 답변 연습·개선.

### 케이스 스터디 면접 (case study interview)
- **엔드투엔드 문제 해결** 능력 테스트(실무 유사 과제). 예: 초과 예산 영화 증가 분석·개선 전략.
- 3단계: ① **명확화(clarify)** — 프롬프트 재진술 + 1~2 질문. ② **도메인 맥락 확립** — 호기심으로 정보 수집(예: 영화 제작비). ③ **데이터 분석 라이프사이클** 따라 답변 — 가용 데이터·적절 분석·선택지 비교.
- **대화형**으로 — 독백 금지, 주기적으로 멈추고 더 설명할지 확인, 구체적으로.

## 요약
- 4대 면접: **리크루터**(스크리닝)·**기술**(SQL·코딩, 접근·협업 중시)·**행동**(문화·소프트 스킬)·**케이스 스터디**(명확화→맥락→라이프사이클).
- 정답뿐 아니라 **문제 분해·소통·협업**이 차별화 요소다.
- 준비는 개인 스토리·연습 문제·일화·LLM 연습으로. 다음은 **STAR 기법**이다.
