# The Job Search Process

## 개요
- 구직·지원 과정은 **탐색(Search) → 지원(Application) → 면접(Interview) → 오퍼(Offer)** 의 핵심 단계로 이뤄진다.
- 나와 회사 **양측**이 서로의 적합성을 평가한다.

## 내용

### 4단계
1. **탐색(Search)**: 지인 문의, 잡보드(Monster·LinkedIn·Indeed), 회사 채용 페이지.
2. **지원(Application)**: 온라인 폼(이름·연락처·경력) + **이력서**·때때로 **포트폴리오** 업로드.
3. **면접(Interview)**: 여러 담당자와 대면. 데이터 분석은 **기술(technical)·행동(behavioral)·케이스 스터디(case study)** 유형. (예: Netflix는 3~5라운드 — 리크루터·채용 매니저·기술 1~2회·최종 패널.)
4. **오퍼(Offer)**: 급여·복지·근무지 등 고용 조건 → **협상·수락·거절** 가능.

### 마인드셋
- 기간은 수 주~수 개월로 다양. **회복탄력성(resilient mindset)** 필요 — 거절은 자격 부족이 아닌 **매칭 문제**.
- 지원은 많이 하되 **경쟁력 높은 기회 우선**(리치 롤도 일부 OK).
- **목표(goal)에 앵커링** 하되 단일 직함·회사에 갇히지 말고 열린 마음으로 접근(궁극 목표로 가는 단계적 기회 수용).

## 요약
- 구직은 **탐색·지원·면접·오퍼** 4단계이며 양측이 서로 적합성을 평가한다.
- **거절을 우아하게** 다루는 회복탄력성과 목표 기반의 열린 태도가 핵심이다.
- 다음 강의부터 각 단계를 **탐색**부터 깊이 다룬다.
