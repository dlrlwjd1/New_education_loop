# Components of a Dashboard

## 개요
- 성공적 대시보드는 여러 요소(제목·통계·차트·주석)를 **고수준→저수준** 으로 구조화한다.
- 큐레이션 정도는 **강한 큐레이션(내러티브)** ~ **약한 큐레이션(탐색 샌드박스)** 스펙트럼에 놓인다.

## 내용

### 강한 큐레이션 예 (Crumble Cookies Instagram)
- 제목·이미지·배경 → 빠른 통계(4.7억+ 재생, 신뢰·맥락) → 시계열 → 히트맵(요일·시간대 참여) → 도넛(콘텐츠 유형) → 상위 게시물 → 워드 클라우드.
- 고수준→저수준 진행, 섹션을 **가로선**으로 구분, 브랜드 색·잡음 없음. 하나의 코어 질문("무엇이 바이럴을 만드나")에 답하는 how-to.

### 약한 큐레이션 예 (Global Internet Access)
- 한 페이지에 밀집, 전체를 한 번에 봄. 지역·국가·연도별 정렬·필터, 특정 국가 클릭 비교 등. **탐색 샌드박스** — 특정 스토리 없이 원하는 인사이트를 찾음.

### 큐레이션 스펙트럼
- **강한 큐레이션**: 하나의 내러티브로 안내, 한 질문에 답, 사용 쉬움(한 경로).
- **약한 큐레이션(exploration sandbox)**: 스토리 없는 관련 차트 모음, 정보 밀도↑·다양한 질문, 자율성↑ 하나 해석에 노력 필요.
- 대개 중간 어딘가. **큐레이션 수준 선택이 애널리스트의 역할**.

## 요약
- 대시보드는 **제목·통계·차트·주석**을 고수준→저수준으로 구조화하며 섹션 구분·브랜드 일관성을 갖춘다.
- 큐레이션은 **강함(내러티브 안내)** ~ **약함(탐색 샌드박스, 자율성)** 스펙트럼이며 용도에 맞게 선택한다.
- 다음 강의는 대시보드에 넣을 인사이트 선택이다.
