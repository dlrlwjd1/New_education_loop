# Layout Design

## 개요
- 대시보드는 복잡하므로 **레이아웃 디자인**에 주의한다 — 크기 설정, 요소 정렬, 필터 배치.
- Tableau는 **타일 기반(tile-based)** 시스템이며 요소를 **부동(floating)** 으로 만들 수도 있다.

## 내용

### 크기 설정
- 대시보드 Size(기본 Fixed) → 픽셀로 확대(예 1250×1100)해 여백 확보.

### 정렬·부동
- **Show Grid** 로 타일 확인(끄기). 범례를 **Floating** 으로 만들어 지도 우상단으로 이동(그리드 제약 벗어남).

### 필터 추가
- 지도의 **Use as Filter** 버튼(국가 클릭 시 다른 차트 필터). Options → Filters → Country. 라인 차트에서 Category Name·Quarter of Order Date 필터 추가.
- 공간 절약: 필터를 **드롭다운**으로(단일값/다중값). **Select All**(기본 뷰 전체) 필수 — 안 하면 특정 값만 열림.
- 필터를 컨테이너 위 행에 배치.

### 크기 조정 (마지막)
- 로고 축소, 필터 짧게, 아래 요소와 **정렬**(quarter를 표와, country·category를 지도 폭에 맞춤). 지도 ~60% 폭, 시계열은 가로 넓게·세로 짧게.
- Tableau가 요소를 임의 이동하면 재조정.

### 저장
- **Publish**. 편집 뷰 닫아 사용자 뷰 확인.

## 요약
- 대시보드 레이아웃은 **크기 설정 → 요소 정렬(타일/부동) → 필터 배치(드롭다운·Select All) → 크기 조정** 순으로 한다.
- 요소를 아래 차트와 정렬하고 차트별 공간 필요(시계열 가로·지도 양방향)를 고려한다.
- 다음 강의는 **액션(actions)** 으로 상호작용 추가다.
