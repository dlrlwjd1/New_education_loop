# Introduction to Dashboards

## 개요
- **대시보드(dashboard)** 는 여러 관련 차트의 인터랙티브 디스플레이 — 관련 정보를 한곳에 모아 청중이 스스로 탐색.
- 보고서·슬라이드보다 **자율성**이 크고, **동적 데이터**에 연결된다.

## 내용

### 대시보드의 특징
- 청중이 자기 페이스로 탐색·중요한 인사이트 보기·스스로 결론.
- **동적 데이터** 연결(예: 10분마다 갱신되는 매출) → 최신 정보.
- **여러 진입점**: 같은 데이터를 청중별로 다르게 조직(경영진·PM용), 차트·연결 재사용으로 시간 절약.

### 인터랙티브 기능
- **교차 필터링(cross-filtering)**: 한 차트 선택 시 다른 차트 자동 필터(예: 지도 국가 클릭 → 도넛 차트 필터).
- **액션(actions)**: 대시보드 페이지 이동·외부 링크(예: 카테고리 클릭 → 라인 차트 강조, 툴팁 링크 → 제품 페이지).
- **동적 텍스트·제목**: 선택에 따라 자동 갱신(예: India 선택 → 제목 "India Sales Overview", "인도가 지역 매출의 23%").
- 하나의 인터페이스로 각 이해관계자에 맞춤 경험 제공.

## 요약
- **대시보드**는 여러 인터랙티브 차트를 한곳에 모아 청중이 자율적으로 탐색하게 하며, 동적 데이터에 연결된다.
- **교차 필터링·액션·동적 텍스트**로 하나의 인터페이스에서 맞춤 경험을 제공한다.
- 다음 강의는 대시보드 구성요소다.
