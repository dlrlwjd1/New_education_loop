# Creating a Dashboard in Tableau

## 개요
- Tableau **대시보드**는 여러 워크시트의 차트·객체를 한 뷰로 모은 것 — 이전 차트를 재사용한다.
- 생성 전 **스케치**로 계획하고, 요소를 먼저 배치한 뒤 크기를 조정한다.

## 내용

### 계획
- 청중(혼합 리터러시)·질문(어느 국가/회사 주문 최다, 계약 종료 대상)에 맞춰 **중간 큐레이션**. 논리적 흐름(국가→회사) + 자율성.
- 스케치: 상단 제목·메타데이터·로고·사용법 → 필터 → 지도+표 나란히 → 시계열.

### 대시보드 만들기
- New Worksheet → **New Dashboard**. 왼쪽 창에 기존 워크시트 목록 → 드래그로 추가(예 Top Countries 지도).
- **텍스트 객체**: 제목·설명·수정일·작성자·데이터 출처. 브랜드 폰트는 **Format → Workbook** 로 전체 설정.
- **이미지 객체**: 로고(Fit → Image).
- **가로 컨테이너(horizontal container)**: 지도·표를 나란히. 아래에 라인 차트.

### 차트별 수정
- 색 통일은 **원본 워크시트**에서(대시보드에서 안 되면 원본 설정). 표의 중복(country) 제거. 제목 **Hide Title**.
- 크기는 동적 계산 → **모든 객체 추가 후 조정**.

### 저장
- **Publish**.

## 요약
- Tableau **대시보드**는 New Dashboard에서 기존 워크시트·**텍스트·이미지·컨테이너** 객체를 드래그해 조립한다.
- 요소를 먼저 배치 후 크기를 조정하고, 차트별 수정(색·제목)은 **원본 워크시트**에서 한다.
- 다음 강의는 **레이아웃 디자인**이다.
