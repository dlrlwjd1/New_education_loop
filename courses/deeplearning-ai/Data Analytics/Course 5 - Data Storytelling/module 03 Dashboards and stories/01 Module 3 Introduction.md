# Module 3 Introduction

## 개요
- **Module 3 — Tableau의 대시보드와 스토리(Dashboards and Stories)** 소개.
- 인터랙티브 시각화로 데이터를 실행 가능한 인사이트로 바꾼다.

## 내용

### 레슨 구성
- **Lesson 1**: 대시보드 디자인 기초 — 직관적 상호작용, 핵심 구성요소(차트·텍스트·필터·주석), 레이아웃·명확한 목표.
- **Lesson 2**: 여러 차트·표를 조립해 대시보드 생성, **액션(action)**(필터·하이라이트·URL 링크), 채택(adoption) 모범 사례.
- **Lesson 3**: **스토리(stories)** — 인터랙티브 슬라이드처럼 청중이 스스로 탐색. **선형(linear, 내러티브)** 과 **비선형(nonlinear, 인사이트 뷔페)** 배열.

## 요약
- 이 모듈은 Tableau로 **인터랙티브 대시보드**와 **스토리**를 만든다.
- Lesson 1(디자인 기초) → Lesson 2(대시보드·액션·채택) → Lesson 3(선형·비선형 스토리) 순으로 진행한다.
