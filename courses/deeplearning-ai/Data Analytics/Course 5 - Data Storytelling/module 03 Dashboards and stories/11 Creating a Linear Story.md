# Creating a Linear Story

## 개요
- **Tableau 스토리(story)** 는 **스토리 포인트(story point)** 들의 모음 — 각 포인트가 차트 또는 대시보드를 담는다(슬라이드 덱 유사).
- **선형(narrative-driven)** 스토리는 청중을 핵심 포인트로 안내한다.

## 내용

### 스토리 만들기
- New Worksheet → **New Story**. 차트를 드래그해 스토리 포인트로 추가. 대시보드도 가능.
- 스토리는 **워크시트(차트·대시보드)** 로만 구성. 객체는 **텍스트만** 추가 가능(대시보드보다 제한적).
- **Blank** 로 새 스토리 포인트 추가.
- 커스터마이즈: 크기 조정(기본 큼), **네비게이터 스타일**(Layout 창) — 캡션 박스(기본, clunky) vs **점(dots, 선형에 sleek)**.

### 예시 (지진 추세)
- 큰 질문 먼저("대지진이 증가하나?") → 스토리 포인트로 **점점 좁혀감**(전체 지진 → 대지진 → 특정 지진 → 결론). 첫 포인트는 수천 개 지도, 다섯째는 일본 앞바다 단일 지진.
- 선형 내러티브·인사이트 통제에 적합하며 **툴팁·필터 등 인터랙티브 유지**.

## 요약
- **Tableau 스토리**는 **스토리 포인트**(차트·대시보드) 모음으로 인터랙티브를 유지하며 내러티브를 전한다.
- **선형 스토리**는 청중을 좁혀가며 안내하고(점 네비게이터 권장), 인사이트를 통제한다.
- 다음 강의는 **비선형 스토리**(인사이트 뷔페)다.
