# Publishing a Dashboard

## 개요
- 대시보드를 게시하기 전 **다양한 기기**(노트북·와이드 모니터·폰)에서의 모습을 고려한다.
- 노트북·와이드 모니터에서 잘 보이게 하고, 필요 시 **모바일 레이아웃**을 따로 만든다.

## 내용

### 크기와 기기
- 수동 크기 설정은 특정 화면에 최적 — 작으면 좌우 스크롤, 크면 여백. 
- **자동(Automatic) 크기**는 대개 결과가 나쁨(가독성보다 수학적 맞춤) → 거의 안 씀.

### 모바일 레이아웃
- 좌상단 **Default·Phone** 옵션. Phone → 케밥 메뉴 → **Edit Layout** 로 모바일 전용 레이아웃(데스크톱과 별개).
- 모바일은 **선형(세로 쌓기)**. 요소 제거해도 데스크톱엔 영향 없음. 바쁜 이해관계자·오래 쓸 대시보드엔 투자 가치.
- 태블릿 뷰도 추가 가능하나 트래픽 2~4%(모바일 60%+) → 노력 대비 고려.
- **Device Preview** 로 기기별(예 iPhone) 모습 확인.

### 저장
- **Publish** (Tableau Public).

## 요약
- 게시 전 **여러 기기**에서의 모습을 확인하고, 노트북·와이드 모니터 최적화 + 필요 시 **모바일 레이아웃**(선형)을 만든다.
- **자동 크기**는 지양하고 **Device Preview** 로 확인 후 **Publish** 한다.
- 다음 강의는 대시보드 **채택(adoption)** 전략이다.
