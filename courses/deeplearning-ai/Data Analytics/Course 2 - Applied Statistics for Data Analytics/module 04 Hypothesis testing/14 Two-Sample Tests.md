# Two-Sample Tests

## 개요
- **두 표본 검정(two-sample test)** 은 한 표본을 가설값과 비교하는 대신 **두 표본을 직접 비교**한다(예: 주말 vs 평일 배달 시간).
- 스프레드시트 **T.TEST** 함수가 검정 통계량 계산을 대신해 p-값만 반환한다.

## 내용

### 언제 쓰나
- 두 그룹 비교: 2013년 vs 1934년 영화 길이, 연령대별 AI 긍정 비율, basic vs premium 구독 유지 기간 등.

### 예시 — basic vs premium 구독 기간
- H₀: **μ_basic = μ_premium**(차이 없음), H₁: **μ_basic ≠ μ_premium**(양측 검정). (한쪽이 크다는 가설이면 단측).
- α=0.05. 두 표본 각 30명: basic(x̄=9.9, s=3.3), premium(x̄=10.4, s=1.9). 두 표본은 **독립**.
- 검정 통계량은 **t-분포**를 따르며, 표준 오차·자유도 계산이 복잡 → 실무는 스프레드시트/프로그래밍.

### T.TEST 함수 (4개 인자)
- **Range 1, Range 2**: 두 그룹의 표본 데이터.
- **Tails**: 1(단측) 또는 2(양측) — 여기선 **2**(equal vs different).
- **Type** (중요, 가정 설정):
  - **1 = 대응 표본(paired)** — 전후 데이터(같은 사람의 premium 전후 등).
  - **2 = 등분산(equal variance)** — 두 모집단 분산 동일 가정(잘 안 씀).
  - **3 = 이분산(unequal variance)** — 분산 가정 없음. **대개 이걸 사용**.
- 결과: p-값 = **0.604** (중간 통계 계산 불필요).

### 해석
- p-값 0.604 > α(0.05) → **기각 실패**. 두 그룹 구독 기간이 다르다는 증거 부족.
- **독립 가정** 주의 — 프로모션으로 basic→premium 전환 유도 시 편향 유입 가능.

### 실무 활용
- 두 표본 검정이 단일 표본보다 흔함(그룹 비교). **A/B 테스트**(제품 두 버전), **임상 연구**(실험군 vs 대조군/위약).

## 예시

### 두 표본 t-검정 (T.TEST)
```
H₀: μ_basic = μ_premium,  H₁: 다름 (양측)
=T.TEST(Range1, Range2, tails=2, type=3)   # 이분산
→ p-값 = 0.604 > 0.05 → 기각 실패
type: 1=대응, 2=등분산, 3=이분산(대개 사용)
```

## 요약
- **두 표본 검정**은 두 그룹을 직접 비교하며(t-분포), **T.TEST(range1, range2, tails, type)** 로 p-값을 바로 얻는다.
- type은 대개 **3(이분산)** 을 쓰고, 표본 독립을 가정하며, A/B 테스트·임상 연구에 널리 쓰인다.
- 예시는 p=0.604로 기각 실패. 다음 강의는 그 외 다양한 가설 검정이다.
