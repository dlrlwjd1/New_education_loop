# Calculating the Test Statistic

## 개요
- **검정 통계량(test statistic)** 은 표본 데이터의 변동성과 크기를 반영해, 관측된 표본 평균이 얼마나 드문지 표준화된 척도로 나타낸다.
- 평균 검정에서는 **z-점수** 형태: **z = (x̄ − μ) / (s/√n)**.

## 내용

### 예시 — 영화 길이 (우측 검정)
- 극장 클라이언트: 영화가 평균 120분 초과인지. 50편 표본: **x̄=123분, s=12분**.
- H₀: μ=120, H₁: μ>120 (우측 검정).
- 표집 분포는 μ=120 중심, **표준 오차 SE = s/√n = 12/√50 ≈ 1.7**.

### 왜 검정 통계량이 필요한가
- 3분 차이가 기각에 충분한지 판단하려면 **변동성·표본 크기**를 함께 봐야 함.
  - 변동 크면 차이 확신 어려움, 표본 크면 정밀↑, 표본 작으면 모집단 반영 불확실.
- 검정 통계량이 이를 반영해 결과의 희소성을 알려줌.

### 계산 단계
1. **x̄ − μ** = 123 − 120 = **3** (계산을 0 중심으로).
2. **÷ SE**: 3 / 1.7 = **1.76** (가설 평균에서 몇 SE 떨어졌는지).
- σ를 모르니 SE = s/√n 사용.
- 이 값이 곧 **z-점수** — 표본 평균을 평균 0·단위 1σ의 표준 척도로 변환.

### 해석
- z=1.76 = 평균보다 1.76 표준편차 위. 그래프상 꼬리(z>3)도 아니고 흔한 중앙(z 0~1)도 아님 → 기각 여부는 유의 수준에 달림(다음 강의).

## 예시

### 검정 통계량 (영화 길이)
```
z = (x̄ − μ) / (s/√n)
SE = 12/√50 ≈ 1.7
z = (123 − 120) / 1.7 = 3/1.7 ≈ 1.76
```

## 요약
- **검정 통계량 z = (x̄ − μ)/(s/√n)** 은 표본 평균을 표준 척도(z-점수)로 변환해 희소성을 나타낸다.
- 변동성·표본 크기를 반영하며, 예시에서 z ≈ 1.76(평균 위 1.76σ).
- 이 z가 기각에 충분히 드문지는 **유의 수준·기각역**으로 판단한다 — 다음 강의.
