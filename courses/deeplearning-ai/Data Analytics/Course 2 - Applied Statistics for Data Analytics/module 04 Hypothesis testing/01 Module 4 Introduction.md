# Module 4 Introduction

## 개요
- 이 코스의 마지막 모듈 **가설 검정(hypothesis testing)** 소개 — 추론 통계의 가장 강력하고 널리 쓰이는 도구 중 하나.
- 관측된 차이가 **통계적으로 유의(statistically significant)** 한지 판단해 데이터 기반 의사결정을 돕는다.

## 내용

### 이 모듈에서 배우는 것
- **평균의 가설 검정** 기초: 가설 수립, **검정 통계량(test statistic)** 계산, **유의 수준(significance level)** 결정, **p-값(p-value)** 해석.
- **비율의 가설 검정** 및 **두 표본 검정(two-sample tests)** — 그룹 비교, 관측된 차이의 유의성 평가.
- 실무에서 만날 수 있는 **다른 유형의 가설 검정**도 간략히 탐색.
- 스프레드시트로 다양한 검정을 수행·해석하는 실습.
- 마지막 레슨: **LLM 활용** — 가설 수립, 결과 해석, 검정 수행 지원.

### 답할 수 있는 질문 예
- 무료 체험이 사용자 유지율을 높이는가?
- 배달 시간이 정말 45분보다 빠른가?

## 요약
- 이 모듈에서는 추론 통계의 핵심 도구인 **가설 검정**을 배운다.
- **평균 검정 기초(가설·검정 통계량·유의 수준·p-값) → 비율·두 표본 검정 → 기타 검정 → LLM 활용** 순으로 진행한다.
- 다음 강의는 실제 예제로 가설 검정에 바로 들어간다.
