# Determining the Significance Level and Rejection Region

## 개요
- **유의 수준(significance level, α)** 은 귀무가설 기각에 필요한 증거의 강도 — 오류를 허용할 확률. **신뢰 수준의 여사건**(95% 신뢰 → α=0.05).
- **기각역(rejection region)** 은 표집 분포에서 귀무가설을 기각하게 만드는 드문 값의 영역.

## 내용

### 유의 수준 α
- "얼마나 드문 값이면 기각할 것인가"를 결정. 신뢰 구간처럼 결정의 위험도에 따라 선택.
- **α = 1 − 신뢰 수준**: 95% 신뢰 → α=0.05(오류 5%). 더 확실히 하려면 α=0.01(99% 신뢰).
- 흔한 값: **0.10, 0.05, 0.01**.
  - α=0.05: 초기 의료 연구·제조 품질관리·사회과학.
  - α=0.01: 임상시험·환경영향·재무 감사(잘못 기각 위험 클 때).
- **큰 α**: 적은 증거로도 기각 쉬움. **작은 α**: 강한 증거 필요.

### 기각역
- 영화 예시(우측 검정, z-점수 → 표준 정규 분포):
  - **α=0.05** → 상단 5%가 기각역. 검정 통계량이 여기 들면 기각.
  - **α=0.01** → 상단 1%로 기각역 **더 작아짐** → 더 강한 증거 필요.

### 검정 유형별 기각역
- **우측/좌측(단측)**: 기각역 하나(한쪽 꼬리).
- **양측(H₁: μ≠120)**: 위·아래 양쪽. 같은 정밀도(총 5% 오류) 유지를 위해 **각 꼬리 2.5%** (합 5%). 양쪽에 5%씩 두면 오류율 10%가 되므로 절반으로 나눔.

## 예시

### 유의 수준·기각역 요약
```
α = 1 − 신뢰 수준        (95% → α=0.05, 99% → α=0.01)
우측 검정 α=0.05: 상단 5%가 기각역
우측 검정 α=0.01: 상단 1% (더 강한 증거)
양측 검정 α=0.05: 각 꼬리 2.5% (합 5%)
큰 α → 기각 쉬움 / 작은 α → 강한 증거 필요
```

## 요약
- **유의 수준 α**(=1−신뢰 수준)는 기각에 필요한 증거 강도를 정하며, 흔히 0.10·0.05·0.01을 쓴다.
- **기각역**은 귀무가설을 기각하게 만드는 드문 값 영역으로, α가 작을수록 좁아진다.
- 양측 검정은 각 꼬리에 α/2씩 둔다. 다음 강의는 희소성을 수치화하는 **p-값**이다.
