# Other Hypothesis Tests

## 개요
- 질문 유형에 따라 다양한 가설 검정이 있다: **ANOVA, 대응 t-검정(paired t-test), 카이제곱(chi-squared), 적합도(goodness-of-fit)**.
- 모두 외울 필요 없이 필요할 때 찾아보면 되며, 이미 기초 지식(가설·p-값 해석)은 갖췄다.

## 내용

### ANOVA (분산 분석, 3개 이상 그룹)
- basic·premium·business 등 **3개 이상 그룹** 비교 시. 검정을 여러 번 하면 오류가 누적되므로 **ANOVA(analysis of variance)** 사용.
- 각 그룹 평균 + 전체 평균 계산 → 그룹 평균이 전체 평균과 얼마나 다른지 vs 개별 값이 그룹 평균과 얼마나 다른지 비교.
- p-값 < 0.05면 그룹 간 차이 유의.

### 대응 t-검정 (paired t-test, 전후 데이터)
- **같은 그룹을 두 번** 측정(전후). 예: 에너지 드링크 전후 기분.
- 사람 간 변동성을 제거해 효과를 더 강력히 측정. 각 쌍의 차이(after−before) → 평균 차이 ÷ 표준 오차 = 검정 통계량.
- p-값 < 0.05면 유의.

### 카이제곱 검정 (chi-squared, 범주형 데이터)
- **범주형(categorical) 데이터**. 예: 지역별 고객 만족도 차이.
- **관측 빈도표** 작성 → 관계 없을 때의 **기대 빈도** 계산 → 관측이 기대에서 얼마나 벗어나는지 측정.
- 작은 p-값 = 관측 빈도가 기대와 유의하게 다름.

### 적합도 검정 (goodness-of-fit)
- 데이터가 **특정 분포(정규 등)를 따르는지** 검정. 예: 콜센터 응대 시간이 정규 분포인가.
- 분포와 얼마나 벗어나는지 측정하는 검정 통계량 → p-값. 작은 p-값 = 정규 분포가 아닐 가능성.

## 예시

### 검정 유형 선택 가이드
| 질문 | 검정 |
|------|------|
| 3개 이상 그룹 평균 비교 | ANOVA |
| 같은 그룹 전후 비교 | 대응 t-검정 |
| 범주형 데이터 관계 | 카이제곱 |
| 특정 분포를 따르는가 | 적합도 검정 |

## 요약
- **ANOVA**(3+ 그룹), **대응 t-검정**(전후), **카이제곱**(범주형), **적합도 검정**(분포 확인) 등 질문에 맞는 검정을 고른다.
- 모두 p-값 < 0.05로 유의성을 판단하며, 세부는 필요 시 찾아보면 된다.
- 다음(마지막) 레슨은 **생성형 AI로 가설 검정 수행·해석**이다.
