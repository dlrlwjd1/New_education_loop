# Hypothesis Testing for Proportions

## 개요
- 평균뿐 아니라 **비율(proportion)** 도 같은 절차로 가설 검정한다: 가설 정의 → 유의 수준 → 검정 통계량·p-값 → 해석.
- 비율 검정 통계량: **z = (p̂ − p₀) / √[p₀(1−p₀)/n]** — 표준 오차에 **p̂이 아닌 p₀** 를 쓴다.

## 내용

### 예시 — 지연 배달 비율
- 빵집이 동물원과 큰 계약: 지연 배달 5% 초과 시 계약 위험. "참 지연 비율이 5% 초과인가?"
- 250건 표본, 지연 비율 **p̂**(참 비율 p 추정). 
- H₀: **p=0.05**(현상 유지, 시작 시간 유지), H₁: **p>0.05**(지연 비율 초과). α=0.05.
- 비율의 표집 분포는 정규(표본 크므로 정규 적절, t도 가능). 우측 5%가 기각역.

### 검정 통계량 계산
- **z = (p̂ − p₀) / SE**, **SE = √[p₀(1−p₀)/n]**.
- **왜 p₀?** 평균 검정은 참 표준편차를 몰라 s로 추정하지만, 비율은 귀무가설(p₀)이 참이라 가정하면 **p₀·n만으로 모표준편차를 유도** — 추정 불필요.
- 계산(p̂=0.06):
  - p̂ − p₀ = 0.06 − 0.05 = 0.01.
  - p₀(1−p₀) = 0.05×0.95 = 0.0475 → /250 = 0.00019 → √ = 0.01378.
  - **z = 0.01/0.01378 ≈ 0.725**.

### 결론
- z=0.725는 평균 위 1 SE 미만 → 기각역 밖 → 기각 실패 예상.
- p-값 = P(z≥0.725) = **0.2342**. 참 지연 비율이 0.05면 표본 비율 0.06 이상이 23.42%.
- 0.2342 > α(0.05) → **기각 실패**. 지연이 5% 초과라는 충분한 증거 없음 → 시작 시간 유지, 계약 양호.

## 예시

### 비율 가설 검정 (지연 배달)
```
H₀: p=0.05,  H₁: p>0.05,  α=0.05
z = (p̂ − p₀) / √[p₀(1−p₀)/n]
  = (0.06 − 0.05) / √(0.05·0.95/250)
  = 0.01 / 0.01378 ≈ 0.725
p-값 = P(z≥0.725) = 0.2342 > 0.05 → 기각 실패
```

## 요약
- **비율 가설 검정**은 평균과 동일한 절차이며, **z=(p̂−p₀)/√[p₀(1−p₀)/n]** 로 검정 통계량을 구한다.
- 표준 오차에 **p₀** 를 쓰는 이유는 귀무가설을 참으로 가정하면 모표준편차를 유도할 수 있기 때문.
- p-값을 α와 비교해 결정한다(예: p=0.2342 > 0.05 → 기각 실패). 다음 강의는 스프레드시트 실습이다.
