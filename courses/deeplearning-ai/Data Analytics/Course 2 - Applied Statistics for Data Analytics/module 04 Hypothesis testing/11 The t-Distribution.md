# The t-Distribution

## 개요
- **t-분포(t-distribution)** 는 표본이 작거나(**n<30**) 모집단 표준편차(σ)를 모를 때 정규 분포 대신 쓰는 평균의 표집 분포.
- 정규 분포보다 **가운데가 낮고 꼬리가 두꺼워** 더 큰 불확실성을 반영하며, **자유도(degrees of freedom, df)** 로 정의된다.

## 내용

### 왜 필요한가
- CLT는 큰 표본(≥30)에서 표본 평균이 정규 분포라 함. **작은 표본**은 표집 분포 변동성↑ → 불확실성↑.
- 표준 오차에서 σ를 **표본 s로 대체**하면 불확실성이 더 커짐. 작은 표본·미지 σ는 의료 등에서 흔함.
- **n<30 또는 σ 미지** 시 **t-분포**가 더 적절.

### t-분포의 특징
- 정규 분포와 유사(부드러운 대칭, 평균 0)하나 **가운데 낮고 꼬리 큼** → 평균에서 먼 값 관측 가능성↑(불확실성 반영).
- **자유도 df = n − 1** (표본 s로 분포를 구성해 −1). df가 커질수록 **정규 분포에 수렴** → 분포 선택 중요도↓(큰 표본일수록 확실).

### 검정 절차 차이
- 가설 정의·표본 통계 수집은 동일. 단 **정규 대신 t-분포**로 희소성 판단.
- 검정 통계량은 **z 대신 t**, 함수는 **T.TEST**(Z.TEST 대신). 기각역·p-값도 t-분포 기준으로 달라짐.

### 영향 예시 (영화, μ₀=120, s=12, n=5)
- t-분포가 꼬리가 커 α=0.05 기각역이 더 멀리 시작(정규 ~128분 vs t ~132분) → **더 강한 증거 필요(엄격)**.
- 표본 평균 130분:
  - 정규: p=0.031 < 0.05 → **기각**.
  - t: p=0.068 > 0.05 → **기각 실패**.
- 작은 표본에선 t-분포 선택이 결론을 바꿀 만큼 중요(더 엄밀).

### 실무 관점
- t-분포는 원래 표본 10~15 시절에 흔했음. 요즘은 빅데이터로 30 초과가 많아 CLT 적용(테크 수천 명, 제조 전수 기록 등).
- 여전히 **희귀 질병·멸종위기종** 등 작은 표본엔 유효. **n>30이면** 정규/t 차이가 결정에 큰 영향 없음.

## 예시

### t-분포 vs 정규 분포
```
사용 조건: n<30 또는 σ 미지 → t-분포
자유도 df = n − 1
검정 통계량 t (z 대신), 함수 T.TEST (Z.TEST 대신)
꼬리 두꺼움 → 기각에 더 강한 증거 필요
df↑ → 정규 분포에 수렴
```

## 요약
- **t-분포**는 작은 표본(n<30)이나 미지 σ에서 정규 분포 대신 쓰며, 꼬리가 두꺼워 불확실성을 반영한다.
- **자유도 df=n−1**, 검정 통계량 t, **T.TEST** 함수를 쓰며, 정규보다 엄격해 결론이 바뀔 수 있다.
- df가 커지면 정규에 수렴하고, n>30이면 차이가 미미하다. 이로써 첫 레슨을 마치고 다음은 다양한 가설 검정이다.
