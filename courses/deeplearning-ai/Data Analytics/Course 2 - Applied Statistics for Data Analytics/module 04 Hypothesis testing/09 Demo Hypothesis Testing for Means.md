# Demo: Hypothesis Testing for Means

## 개요
- 스프레드시트로 평균의 가설 검정을 수행하는 데모 — 산불 데이터의 평균 면적(우측 검정)과 ISI(좌측 검정).
- 수동 계산(검정 통계량 → CDF로 p-값)과 **Z.TEST 함수** 단축 방법을 모두 다룬다.

## 내용

### 사례 1 — 평균 면적 > 10헥타르? (우측 검정, α=0.05)
- H₀: μ=10, H₁: μ>10. (10 초과면 국립소방청·항공기 투입)
- 필요 통계: x̄·s·n(신뢰 구간과 동일).
- **검정 통계량 = (x̄−10)/(s/√n)** ≈ **1** (x̄=12.85로 10보다 크나 s가 매우 커서 통계량이 작음).
- p-값(우측): **1 − NORM.S.DIST(z, TRUE)** ≈ **0.155**.
- α=0.05: 0.155 > 0.05 → **기각 실패**. 평균 화재 크기가 10 초과라는 증거 부족.
- 단축: **Z.TEST(데이터 열, 10)** → 동일한 p-값(통계량 수동 계산 불필요).

### 사례 2 — ISI < 10? (좌측 검정, α=0.01)
- ISI(초기 확산 지수) 10=빠름, 16+=극히 빠름. 10 미만 확인 필요(초과 시 통제 소각·폐쇄 등 고비용 → 높은 확신 필요).
- H₀: μ=10, H₁: μ<10.
- 검정 통계량 ≈ **−5** (x̄≈9).
- p-값(좌측): **NORM.S.DIST(z, TRUE)** 직접 사용 → 극히 작은 값. α=0.01에서도 **기각**. ISI가 10 미만이라는 강한 증거.

### Z.TEST 방향 주의
- Z.TEST는 **우측 검정**(원본보다 큰 평균이 나올 확률)을 반환.
- **좌측 검정**이면 **1 − Z.TEST(...)** 로 변환. (ISI 예: Z.TEST가 0.99999 → 1−0.99999가 실제 좌측 p-값)

## 예시

### 스프레드시트 가설 검정
```
검정 통계량:  z = (x̄ − μ₀) / (s/√n)
우측 p-값:    = 1 − NORM.S.DIST(z, TRUE)   또는  = Z.TEST(데이터, μ₀)
좌측 p-값:    = NORM.S.DIST(z, TRUE)        또는  = 1 − Z.TEST(데이터, μ₀)
면적: z≈1, p≈0.155, α=0.05 → 기각 실패
ISI:  z≈−5, p≈0,     α=0.01 → 기각
```

## 요약
- 평균 가설 검정은 **z=(x̄−μ₀)/(s/√n)** 계산 후 CDF(NORM.S.DIST)로 p-값을 구하거나 **Z.TEST**로 단축한다.
- **Z.TEST는 우측 검정 기준**이라 좌측 검정은 **1−Z.TEST** 로 변환한다.
- p-값을 α와 비교해 기각/기각 실패를 결정한다. 다음 강의는 가설 검정의 **두 가지 오류**다.
