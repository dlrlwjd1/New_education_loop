# Demo: Hypothesis Testing for Proportions

## 개요
- 스프레드시트로 비율의 가설 검정을 수행하는 데모 — 산불 데이터에서 "아주 작은 화재 비율이 0.5 초과인가"(우측 검정).
- 검정 통계량은 수동 계산해야 하며, **Z.TEST·T.TEST는 비율 검정에 쓸 수 없다**.

## 내용

### 배경과 가설
- 공원청이 새 진화법 도입 후 작은 화재가 **과반**인지 확인. `is_small` 열(0.5헥타르 미만=1).
- 우측 검정: H₀: p=0.5, H₁: p>0.5.

### 계산
1. **p̂ = AVERAGE(is_small)** ≈ **0.478**.
2. 여사건 1−p̂ 계산.
3. **n = COUNT(...)**.
4. **검정 통계량 z = (p̂ − p₀) / √[p₀(1−p₀)/n]**, p₀=0.5 → z ≈ **−1** (p̂이 가설 비율보다 1 SE 아래).
5. p-값(우측): **1 − NORM.S.DIST(z, TRUE)**. z가 평균 아래이고 우측 검정이라 p-값 매우 큼.

### 결론
- p-값이 어떤 합리적 유의 수준보다도 큼 → **기각 실패**. 참 비율이 0.5 초과라는 증거 부족.
- 공원청은 진화 조치를 계속하고 데이터를 더 모아야 함.

### 주의
- **비율 검정엔 Z.TEST/T.TEST 사용 불가** — 이 함수들은 평균의 표준편차를 쓰므로 잘못된 결론.
- 기각 실패도 괜찮음 — 효과 없음을 확인하는 것도 효과를 찾는 것만큼 유익.

## 예시

### 비율 검정 스프레드시트
```
p̂ = AVERAGE(is_small) ≈ 0.478,  p₀ = 0.5,  n = COUNT(...)
z = (p̂ − 0.5) / SQRT(0.5·0.5/n) ≈ −1
p-값 = 1 − NORM.S.DIST(z, TRUE)  → 매우 큼 → 기각 실패
⚠ Z.TEST·T.TEST 사용 금지 (평균용 표준편차라 오답)
```

## 요약
- 비율 가설 검정은 **z=(p̂−p₀)/√[p₀(1−p₀)/n]** 를 수동 계산 후 NORM.S.DIST로 p-값을 구한다.
- **Z.TEST·T.TEST는 비율에 쓸 수 없다**(평균용 표준편차 사용).
- 기각 실패도 유익한 결과다. 다음 강의는 두 평균·비율을 비교하는 **두 표본 검정**이다.
