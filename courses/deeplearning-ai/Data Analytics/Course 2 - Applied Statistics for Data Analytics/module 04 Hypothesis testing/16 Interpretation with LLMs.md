# Interpretation with LLMs

## 개요
- LLM은 가설 검정에서 **가설 수립·결과 해석·접근법 검증**을 돕는다.
- 단 LLM은 언어의 통계적 표현일 뿐이라 **매 단계 출력을 반드시 확인**해야 한다(오류 가능).

## 내용

### 가설 수립 지원
- 예: "주말 vs 평일 배달 시간 비교. 귀무·대립가설을 세워줘." → LLM이 H₀(차이 없음)·H₁(차이 있음) 제시.
- 후속 질문으로 정교화:
  - "이건 단측이야 양측이야?" → 양측.
  - "주말이 더 길다는 단측으로" → H₁: 주말이 더 김.
  - "수학 표기로" → H₀: μ_weekend ≤ μ_weekday, H₁: μ_weekend > μ_weekday. (귀무의 ≤는 검정 수행에 영향 없음)

### 결과 해석
- 예: "두 표본 t-검정, 검정 통계량 2.45, p-값 0.018. 비즈니스 관점 설명." → 유의한 차이, 귀무가설 기각 강한 증거.
- 후속: "p-값 0.018이 무슨 뜻?" → 귀무가설이 참일 때 2.45만큼 극단적인 통계량을 관측할 확률.

### 접근법 검증 — 오류 주의
- 예: "생산 일정 90% 이상이 예산 준수인지, 25개로 **평균 t-검정**(H₀: μ=0.9, H₁: μ<0.9). 1~10점 평가."
- LLM: **7/10** — 하지만 **90%는 평균이 아니라 비율(proportion)** 인데 LLM이 평균으로 잘못 진행.
- "평균 검정이 맞나?" 라고 **넌지시 유도** → LLM이 오류 인정. "비율 검정이 더 정확한가?" → 예(표준편차·검정 통계량 계산이 다름).
- **교훈**: LLM 답을 액면 그대로 받지 말고 검증. (데모는 ChatGPT 3.5, 실무엔 더 강력한 모델)

## 예시

### LLM 활용 팁
```
가설 수립: "귀무·대립가설 세워줘" → "단측/양측?" → "수학 표기로"
결과 해석: "이 검정 통계량·p-값을 비즈니스 언어로 설명"
검증: "1~10점 평가" + "평균 검정이 맞나?" (오류 유도 확인)
⚠ 90%는 비율 → 평균 검정 아님 (LLM이 틀릴 수 있음)
```

## 요약
- LLM은 **가설 수립·결과 해석·접근 검증**에 유용하며, 후속 질문(단측/양측, 표기, 1~10점 평가)으로 정교화한다.
- LLM은 평균 vs 비율 같은 **개념 오류**를 낼 수 있으니 넌지시 유도·검증하며 매 단계 확인해야 한다.
- 다음 강의는 코드 실행 가능 LLM으로 실제 가설 검정을 수행한다.
