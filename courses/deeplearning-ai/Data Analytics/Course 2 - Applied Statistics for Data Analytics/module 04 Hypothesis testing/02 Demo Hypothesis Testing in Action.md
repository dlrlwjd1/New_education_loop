# Demo: Hypothesis Testing in Action

## 개요
- 가설 검정의 직관을 보여주는 데모 — 루빅스 큐브 대결(내 시간 vs 친구 시간)로 "차이가 우연인가, 진짜 실력 차인가"를 판단.
- 관측된 차이가 **우연(random chance)** 으로 나올 확률을 계산해, 작을수록 진짜 패턴의 증거로 본다.

## 내용

### 문제 — 우연인가 실력인가
- 20회 풀이: 내 평균 80초, 친구 82초 → 내가 평균 **2초** 빠름. 친구는 "운"이라 주장.
- 가설 검정은 **차이 크기(2초, 작음)** 와 **표본 크기(20, 적음)** 를 모두 반영해 높은 신뢰로 결론.

### 20회 검정
- 각 풀이 시간 차이 계산(양수 = 내가 빠름), 평균 차이 = 2초.
- "실력이 같다면(가설 평균 = **0**, 차이 없음) 2초 이상 빠를 확률은?" → **Z-검정(z-test 함수)**.
- 결과: **24.6%**. 실력이 같아도 이런 결과가 꽤 흔함 → 변동성 크고 표본 적어 **강한 증거 아님**.

### 100회 검정
- 100회로 확대. 어떤 땐 24초 빠르고 어떤 땐 친구가 훨씬 빠름. 평균 차이 = **3초**.
- "실력이 같다면 3초 이상 차이 날 확률은?" → **0.37%**. 매우 드묾 → 100회 내내 3초 우위 유지.
- 결론: 100번의 기회에도 친구가 앞서지 못했으니, **내가 진짜 더 빠르다**는 증거(평균 3초에 불과해도).

### 핵심 아이디어
- 큰 표본일수록 같은 차이라도 **우연일 확률이 급감** → 더 강한 증거.

## 예시

### 우연 확률 비교 (실력 동일 가정)
| 표본 | 평균 차이 | 우연 확률 | 해석 |
|------|-----------|-----------|------|
| 20회 | 2초 | 24.6% | 흔함 → 약한 증거 |
| 100회 | 3초 | 0.37% | 드묾 → 강한 증거 |

## 요약
- **가설 검정**은 관측된 차이가 우연으로 나올 확률을 계산해, 낮으면 진짜 패턴의 증거로 삼는다.
- 같은 차이라도 **표본이 클수록 우연 확률이 낮아져** 강한 증거가 된다(20회 24.6% → 100회 0.37%).
- 가설 평균 0(차이 없음)을 기준으로 Z-검정을 수행한다. 다음 강의는 그 내부 원리다.
