# Calculating the p-value

## 개요
- **p-값(p-value, probability value)** 은 귀무가설이 참일 때 관측된 검정 통계량만큼(또는 더) 극단적인 값이 나올 확률이다.
- **p-값 < α** 면 귀무가설 **기각**, 아니면 **기각 실패**.

## 내용

### p-값의 정의
- 대립가설 방향으로 z만큼 또는 더 드문 표본 평균이 나올 확률. 예: z≥1.76일 확률.
- 계산엔 조견표(lookup table) 또는 스프레드시트·프로그래밍 필요.

### CDF와 여사건으로 계산 (영화 예시)
- z=1.76 이상의 확률 필요. **CDF = P(z ≤ 값)** → **여사건 규칙**: P(z>1.76) = 1 − P(z≤1.76).
- P(z≤1.76) ≈ 0.9608 → **p-값 = 1 − 0.9608 = 0.0392**.
- 즉 참 평균이 120분이면 표본 평균 123분 이상이 나올 확률은 약 **3.92%**.
- 실무 팁: 표본 데이터를 직접 다룰 땐 **Z.TEST 함수**가 가설 정의 외 모든 단계를 수행.

### α와 비교해 결론
- **α=0.05**: p-값(0.0392) < α → **귀무가설 기각**(5% 미만으로 드묾). 영화가 평균 120분 초과라는 충분한 증거.
- **α=0.01**: p-값(0.0392) > α → **기각 실패**. 증거 불충분.
- **주의**: 유의 수준은 검정 **전에** 정해야 함. 원하는 결론을 위해 조정하면 **분석 편향(analysis bias)**.

### 전체 흐름 요약
- 질문(영화 120분 초과?) → 표본(50편, x̄=123, s=12) → 검정 통계량 z=1.76 → p-값 0.0392 → α=0.05와 비교 → 기각 → "참 평균이 120분 초과라는 충분한 증거."

## 예시

### p-값 계산과 결정 (영화 길이)
```
z = 1.76 (우측 검정)
P(z ≤ 1.76) ≈ 0.9608  →  p-값 = 1 − 0.9608 = 0.0392
α=0.05: 0.0392 < 0.05 → 기각 ✅
α=0.01: 0.0392 > 0.01 → 기각 실패 ❌
스프레드시트: Z.TEST(데이터, 가설평균)
```

## 요약
- **p-값**은 귀무가설이 참일 때 관측값만큼 극단적인 결과가 나올 확률로, CDF와 여사건으로 계산한다.
- **p-값 < α → 기각**, 그 이상 → 기각 실패. 같은 p-값도 α에 따라 결론이 달라진다.
- 유의 수준은 검정 전에 정해 편향을 피한다. 다음 강의는 스프레드시트 실습이다.
