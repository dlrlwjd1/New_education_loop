# Inference with LLMs

## 개요
- 코드 실행 가능 LLM(ChatGPT-4o 고급 데이터 분석)으로 가설 검정을 **직접 수행·시각화**하는 데모.
- "perform" = LLM이 코드를 작성·실행해 실제 수학 수행. 결과는 실행된 코드를 열어 **검증**해야 한다.

## 내용

### 두 표본 검정 수행 예시 — 부서 급여
- 고객지원(x̄=$65k, s=$8k, n=40) vs 구매(x̄=$68k, s=$9k, n=35). "구매 부서 평균 급여가 더 높은지 두 표본 검정."
- 일반 LLM은 단계만 써주지만, 코드 실행 LLM은 실제로 수행.
- LLM이 **두 표본 t-검정** 선택:
  - H₀: μ_구매 ≤ μ_지원, H₁: μ_구매 > μ_지원 (**단측** — 더 높은지 관심).
  - 검정 통계량 공식 + (복잡한) 자유도 공식 제시.
  - 결과: **t ≈ 1.52, df ≈ 68, p-값 = 0.067**, 임계값(critical value, 기각역 경계) 표시.

### 코드 검증
- **View Analysis** 버튼으로 실행된 코드 확인 — 통계 정의, 검정 통계량·자유도 계산, 여사건·CDF로 p-값, α·임계값 계산(수업에서 배운 방식과 동일).

### 해석
- α=0.05, p-값=0.067 → **기각 실패**. 낮은 p-값이나 유의 수준에 못 미침 → 구매 부서 급여가 유의하게 높다고 결론 불가.

### 시각화
- "이 검정을 시각화" 요청 → t-분포 그래프: 빨간 영역=기각역(α=0.05), 수직선=검정 통계량 1.52. 통계량이 기각역 **밖**(드물지만 임계값만큼은 아님).

### 원칙
- LLM은 가설 검정 수행·시각화에 매우 유용하나 **매 단계 출력을 검증**해야 한다.

## 예시

### LLM 가설 검정 수행 (급여)
```
입력: 두 부서 x̄·s·n + "구매가 더 높은지 검정"
LLM: 두 표본 t-검정(단측), t≈1.52, df≈68, p=0.067
α=0.05: 0.067 > 0.05 → 기각 실패
검증: View Analysis로 실행 코드 확인
```

## 요약
- 코드 실행 가능 LLM은 두 표본 t-검정 등을 **직접 수행·시각화**하며(복잡한 자유도 계산도 대신), 일반 LLM엔 시키지 말 것.
- 실행된 코드를 열어 **매 단계 검증**하고, p-값을 α와 비교해 결론짓는다(예: p=0.067 > 0.05 → 기각 실패).
- 이로써 모듈 4와 코스 본 강의를 마치며, 이어 실습·평가·심장병 캡스톤이 있다.
