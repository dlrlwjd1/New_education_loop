# Module 2 Introduction

## 개요
- 모듈 2는 **확률(probability)** — 불확실성을 정량화하는 언어 — 과 **시뮬레이션(simulation)** 을 다룬다.
- 확률 규칙·개념(조건부 확률·독립), **확률 분포**(이산·연속, 이항·정규), 그리고 **시뮬레이션 기법**을 배운다.

## 내용

### 이 모듈에서 배우는 것
- **확률**: 핵심 규칙과 **조건부 확률(conditional probability)·독립(independence)** 등의 개념(실무 예제 포함).
- **확률 분포(probability distributions)**: 이산·연속, **이항(binomial)·정규(normal)** 등 실세계 현상 모델링. 표본으로 모집단 분포를 이해하고 "특정 결과가 얼마나 흔한가" 같은 질문에 답.
- **시뮬레이션**: 특정 분포를 따르는 무작위 데이터 생성으로 복잡한 시나리오 모델링·의사결정. **LLM으로 시뮬레이션 인터페이스 생성·결과 해석**.

## 요약
- 모듈 2는 **확률(불확실성 정량화)** 과 **확률 분포·시뮬레이션**을 다루며, 신뢰구간·가설 검정 같은 후속 기법의 바탕이 된다.
- 다음 강의는 **무작위성과 불확실성**이다.
