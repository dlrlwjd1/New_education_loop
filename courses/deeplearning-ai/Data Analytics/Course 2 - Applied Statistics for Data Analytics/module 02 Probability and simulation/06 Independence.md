# Independence

## 개요
- **독립(independence)**: 한 사건의 발생이 다른 사건의 확률에 **영향을 주지 않음**. 규칙: **P(A | B) = P(A)**.
- 독립 여부는 중요한 구분 — 많은 통계 방법(곱셈 규칙 등)이 독립을 가정한다. **겉보기엔 독립이지만 실제론 아닌** 경우가 많다.

## 내용

### 독립의 개념
- 주사위 6이 4번 연속 나와도 다음 6의 확률은 여전히 **1/6** — 이전 결과가 다음에 영향 없음(독립).
- 규칙: **P(A|B) = P(A)**. 예: A=6 나오기, B=1 나오기. 첫 주사위가 1이어도 다음 6의 확률은 여전히 1/6 → 독립.
- 판단법: ① 사건의 성질을 살펴 결과가 서로 영향을 주는지, ② 데이터를 모아 규칙(P(A|B)=P(A)) 충족 여부 검정.

### 겉보기 독립의 함정
- 홍역 검사 두 명 — 다른 사람이라 독립처럼 보이나, 홍역은 전염성이 강해 **같은 클리닉에서 한 명 양성이면 다른 사람도 양성일 확률↑** → 독립 아님.

### 비독립과 곱셈 규칙
- 독립이면 P(A and B)=P(A)×P(B). **비독립이면 곱셈 규칙 불가**.
- 홍역 예: 첫 사람 1%. 독립 가정 시 둘 다 양성 = 0.01×0.01 = **1/10,000**. 그러나 전염성 때문에 첫 사람 양성 시 둘째 확률이 10%로 오르면, **의존 사건 곱셈** 사용: P(둘 다) = P(첫)×P(둘 | 첫) = 0.01×0.10 = **1/1,000**. → 독립 가정이 **10배(자릿수) 오차**.
- 중요한 결정일수록 강한 증거가 필요하며, 독립 여부 판단이 엄밀함의 한 부분.

## 예시

### 독립 규칙
```
독립: P(A|B) = P(A)   → P(A and B) = P(A)×P(B)
비독립: P(A and B) = P(A) × P(B|A)
홍역: 독립가정 1/10,000 vs 실제 0.01×0.10 = 1/1,000
```

## 요약
- **독립**은 한 사건이 다른 사건 확률에 영향을 안 주는 것(**P(A|B)=P(A)**)이며, 주사위·동전이 대표적이다.
- 겉보기 독립이 실제론 아닌 경우가 많고(홍역 검사), **비독립이면 곱셈 규칙 대신 조건부 확률**을 써야 한다(오차 자릿수 차이).
- 다음(마지막) 강의는 **확률 변수(random variables)** 다.
