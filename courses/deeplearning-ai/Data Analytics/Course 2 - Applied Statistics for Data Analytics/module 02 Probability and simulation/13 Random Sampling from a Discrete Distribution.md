# Random Sampling from a Discrete Distribution

## 개요
- **무작위 표집(random sampling)** 은 알려진 확률 분포로부터 **모의 데이터(simulated data)** 를 생성하는 과정으로, 실제 표집처럼 이 데이터를 분석해 의사결정에 활용한다.
- **표준 균등 분포(standard uniform distribution)**, 즉 0~1 난수 생성기를 시작점으로 다른 분포의 표본을 만든다.

## 내용

### 시뮬레이션이 필요한 이유
- 확률 분포는 각 값의 **가능성**을 나타내지만, 시뮬레이션 모델은 **실제 발생한 구체적 결과**가 필요하다.
- 예: "동전 앞면 50%"를 아는 것만으론 부족 — 실제로 던져 앞/뒤를 관찰, 100번 던지면 앞면 몇 번? 개별 결과 없이는 "무엇이 일어날 수 있는지"만 알 뿐 "실제로 무엇이 일어났는지"는 모른다.

### 표준 균등 분포
- **U ~ Uniform(0, 1)**: 연속, 최소 0·최대 1(포함)인 난수 생성기. 스프레드시트 함수 **RAND()** 가 이를 구현(0~1 값 생성).
- 균등 분포는 범위 전체에서 확률이 동일 → 다른 분포의 표본 생성에 활용.

### 균등 → 베르누이 (2결과)
- DNA 키트 유효성(p=0.7) 시뮬레이션: RAND()로 0~1 뽑아 **≤0.7이면 유효, >0.7이면 무효**.
- 균등 분포는 범위 내 확률 균등이므로 "≤0.7일 확률 = 0.7"로 정확히 성공 확률과 일치.

### 균등 → 다결과 이산 (범위 분할)
- 음악 구독 예(basic 0.3 / premium 0.2 / cancel 0.5): 0~1을 확률에 **비례한 구간**으로 분할.
  - ≤0.3 → basic, 0.3~0.5 → premium, >0.5 → cancel.
- 핵심: 각 구간 길이 = 해당 결과의 확률.

### 시뮬레이션의 힘
- 실험을 원하는 만큼 **반복(replicate)** 가능 — 현실 표집은 비용·시간이 크지만 시뮬레이션은 자유롭다.
- **파라미터를 바꿔** 다른 시나리오 분석 가능. 생성한 표본은 또 하나의 표본 데이터 → 배운 모든 기술 통계로 분석.

## 예시

### 균등 → 이산 분포 매핑
```
2결과(p=0.7):  RAND()≤0.7 → 유효,  >0.7 → 무효
3결과:         ≤0.3 → basic,  0.3~0.5 → premium,  >0.5 → cancel
```

## 요약
- **무작위 표집**은 확률 분포에서 개별 결과를 생성해 모의 데이터를 만드는 과정이다.
- **표준 균등 분포(U~Uniform(0,1), RAND())** 를 확률에 비례한 구간으로 나누어 베르누이·다결과 이산 분포를 시뮬레이션한다.
- 시뮬레이션은 반복·파라미터 변경이 자유로우며, 다음 강의는 스프레드시트로 베르누이·이항 시뮬레이션을 만든다.
