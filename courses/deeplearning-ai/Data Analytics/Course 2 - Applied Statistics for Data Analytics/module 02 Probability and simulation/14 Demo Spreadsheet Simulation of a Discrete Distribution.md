# Demo: Spreadsheet Simulation of a Discrete Distribution

## 개요
- 스프레드시트로 이산 분포 시뮬레이션을 실행하는 실습 데모 — DNA 키트(베르누이/이항)와 음악 구독(3결과) 시나리오.
- **RAND()** 로 균등 난수를 뽑고 **IF** 문으로 결과에 매핑, **체크박스**로 재생성, 차트로 시각화한다.

## 내용

### 왜 시뮬레이션인가
- DNA 샘플은 검사 시 파괴될 수 있어 실측이 비싸고 불편 → 확률을 알면 여러 박스를 **수학적으로 시뮬레이션**해 품질관리 트리거 가능성을 파악.
- (스프레드시트·솔루션은 Downloads 탭 제공)

### 2결과 시뮬레이션 (DNA, p=0.7)
- A열: `RAND()` 로 0~1 균등 난수. 실행할 때마다 새 값 생성.
- B열: `IF(A2<=0.7, "valid", "invalid")` — ≤0.7이면 유효, 아니면 무효.
- 수식을 10행까지 **드래그**해 10개 키트 복제. **체크박스**를 셀에 넣어 새 결과 트리거.
- 시각화 시 새로고침마다 y축 스케일이 변하므로 **차트 설정에서 y축을 0~10으로 고정**.

### 3결과 시뮬레이션 (음악 구독)
- 중첩 IF: `IF(A<=0.3, "basic", IF(A<=0.5, "premium", "cancel"))` — basic 0.3 / premium 0.2 / cancel 0.5.
- 10명 시뮬레이션 시 결과 변동이 큼(세 결과 모두 중간 확률) → **표본을 더 많이** 만들면 결과가 안정화.

### 대량 표본 생성
- 100개 생성 방법 ① 드래그로 100행까지(번거로움), ② **RANDARRAY** 함수로 한 번에 100개.
  - RANDARRAY가 아래 셀에 데이터가 있으면 "array result was not expanded" 오류 → 셀을 비우고 실행.
- 차트는 자동 갱신 안 됨 → **데이터 범위·y축 스케일 수정** 필요.
- **배열 수식(array formula)** 으로 IF를 A2:A101 전체에 한 번에 적용(수식 반복 채우기 불필요).
- 결과 예: basic 30 / cancel 40 / premium 25.

## 예시

### 핵심 스프레드시트 수식
```
난수:      =RAND()                         (0~1 균등)
2결과:     =IF(A2<=0.7, "valid", "invalid")
3결과:     =IF(A2<=0.3,"basic", IF(A2<=0.5,"premium","cancel"))
대량 난수: =RANDARRAY(100)                  (100개 한 번에)
```

## 요약
- **RAND()** 균등 난수를 **IF** 문으로 결과에 매핑하면 이산 분포를 스프레드시트에서 시뮬레이션할 수 있다.
- 체크박스로 재생성, 차트 y축 고정으로 시각화하며, 표본이 많을수록 결과가 안정된다.
- **RANDARRAY·배열 수식**으로 대량 표본을 효율적으로 만든다. 다음 강의는 **LLM을 이용한 시뮬레이션**이다.
