# The Binomial Distribution

## 개요
- **이항 분포(binomial distribution)** 는 **고정된 독립 시행(trials)** 에서 **성공 횟수**의 확률을 모델링한다. 결과는 정확히 두 가지(성공/실패), 각 시행의 성공 확률 동일.
- 파라미터 두 개 **n**(시행 수)·**p**(성공 확률)로 정의. **베르누이는 n=1인 이항 분포의 특수 사례**.

## 내용

### 정의와 조건
- 이산 분포이며 성공 횟수는 0~n. "Bi" = 둘(두 결과).
- 적용 조건 4가지(DNA 박스 10개 예시):
  1. 두 결과(유효/무효),
  2. 각 시행 동일 확률(70%),
  3. **고정된 시행 수**(박스당 10개),
  4. **독립**(한 샘플이 다른 샘플에 영향 없음 — 각기 다른 주인이 채취). 단 독립은 **가정**이며 100% 확신 불가.
- 표기: **X ~ Binomial(n=10, p=0.7)**. 두 파라미터가 분포 모양을 결정.

### PMF와 모양
- x축=성공 수(0~10), y축=해당 개수가 나올 확률. n=10, p=0.7이면 **7 중심의 대략 종형(bell-shaped)**, 10을 넘을 수 없어 약간 음의 왜도.
- 극단값 확률(곱셈 규칙): 10개 모두 유효 = 0.7¹⁰ ≈ **0.025(2.8%)**, 0개 유효 = 0.3¹⁰ ≈ 극히 작음(1/1000 미만). 그 외 값은 배치 경우의 수까지 고려해 복잡 — 컴퓨터로 계산.

### 모집단 파라미터
- **평균 μ = n·p** = 10×0.7 = **7**(평균 7개 유효 기대).
- **분산 σ² = n·p·(1−p)** = 10×0.7×0.3 = **2.1**.
- **표준편차 σ = √σ²** = √2.1 ≈ **1.45**(데이터와 같은 단위=샘플). 대략 대칭이라 **±1σ(5.5~8.5개)** 범위가 흔하다고 말할 수 있음.
- 평균 7이 가장 흔함(확률 ≈ 0.27, 약 27%). 모든 확률 합 = 1이며 n·p만으로 도출 가능.

## 예시

### 이항 파라미터 (n=10, p=0.7)
| 값 | 공식 | 결과 |
|----|------|------|
| 평균 μ | n·p | 7 |
| 분산 σ² | n·p(1−p) | 2.1 |
| 표준편차 σ | √[n·p(1−p)] | 1.45 |

### DNA 박스 결과 분석
- 7개 유효: 약 27%
- 0개 유효: 1/1000 미만 (매우 드묾)
- 10개 모두 유효: 약 2.8%

## 요약
- **이항 분포**는 n번의 독립 시행에서 성공 횟수를 모델링하며 파라미터는 **n·p**(베르누이는 n=1 특수 사례).
- 모집단 파라미터: **μ=n·p, σ²=n·p(1−p), σ=√[n·p(1−p)]**, PMF는 종형에 가깝다.
- 다음 강의는 **누적 분포 함수(CDF)** 로 더 많은 질문에 답한다.
