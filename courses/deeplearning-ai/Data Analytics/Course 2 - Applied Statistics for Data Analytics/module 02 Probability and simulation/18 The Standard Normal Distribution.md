# The Standard Normal Distribution

## 개요
- **표준 정규 분포(standard normal distribution)** 는 **평균 0·표준편차 1**(따라서 분산 1)인 특수한 정규 분포: **Z ~ Normal(0, 1)**.
- 이 분포에서 값 자체가 **평균에서 몇 σ 떨어졌는지(z-점수, z-score)** 를 나타내, 서로 다른 정규 분포를 공통 척도로 비교할 수 있다.

## 내용

### 무한히 많은 정규 분포
- μ가 중심을, σ가 모양을 결정해 정규 분포는 무수히 많다(σ=2 넓고 평평, σ=0.5 높고 좁음, μ=−2 이동 등). 모두 평균=중앙값=최빈값, 시그마 규칙 성립.
- 그중 **μ=0, σ=1** 이 **표준 정규 분포**.

### z-점수 (z-score)
- 표준 정규 분포에서 값 = **평균으로부터의 σ 개수**. 값 1 = 평균 위 1σ, −2 = 아래 2σ, 0.72 = 위 0.72σ.
- 랜덤 변수 Z로 표기해 이 값을 **z-점수**라 함 — 정규 데이터의 공통 기준.
- 예: 로스쿨 친구가 중간고사 52점 → 높은지 알기 어려움. 하지만 **z-점수 1.7**이면 평균보다 1.7σ 위 = 평균 훨씬 상회.
- 백분위수(percentile)와 유사하나, 백분위는 **순위**만, z-점수는 **평균에서 얼마나 먼지**까지 알려줌.

### 표준화 (standardization)
- 원 데이터를 z-점수로 변환 = **표준화**. 일관된 척도로 분포를 해석할 때 사용.
- 공식: **z = (x − μ) / σ**.
  - 평균 빼기 → 중심을 0으로, σ로 나누기 → 값을 σ 단위로. 결과적으로 모든 정규 분포가 μ=0·σ=1이 됨 → 서로 다른 분포 비교 가능.
- 예: 점수 ~ Normal(43.5, 5), 52점 → z = (52−43.5)/5 = **1.7**.

### 역변환 (inverse transformation)
- z·μ·σ를 알면 원래 값 복원: **x = z·σ + μ**. z-점수 ↔ 원 척도 언제든 상호 변환.

## 예시

### z-점수 변환
```
표준화:   z = (x − μ) / σ        예: (52 − 43.5)/5 = 1.7
역변환:   x = z·σ + μ            예: 1.7·5 + 43.5 = 52
표준 정규: Z ~ Normal(0, 1),  분산 = 1
```

## 요약
- **표준 정규 분포**는 μ=0·σ=1인 정규 분포이며, 값 자체가 **평균에서의 σ 개수(z-점수)** 다.
- **표준화 z=(x−μ)/σ** 로 어떤 정규 분포든 공통 척도로 변환하고, **x=z·σ+μ** 로 역변환한다.
- z-점수는 이후 **신뢰 구간·가설 검정**에 쓰인다. 다음 강의는 정규 분포에서 **무작위 표집**이다.
