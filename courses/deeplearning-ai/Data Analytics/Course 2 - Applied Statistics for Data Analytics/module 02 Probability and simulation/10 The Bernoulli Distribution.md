# The Bernoulli Distribution

## 개요
- **베르누이 분포(Bernoulli distribution)** 는 **두 가지 결과**만 있는 확률 변수를 모델링한다: 성공(1, 확률 p)·실패(0, 확률 1−p).
- 파라미터 하나 **p**(성공 확률)로 정의되며, 모집단 **평균(μ)=p, 분산(σ²)=p(1−p), 표준편차(σ)=√[p(1−p)]**.

## 내용

### 정의
- 성공(1, 확률 p)·실패(0, 확률 1−p). 두 확률은 여사건 규칙으로 합 1.
- 예: 반려견 DNA 키트 샘플의 유효/무효. 유효율 70% → 두 결과 + 각 샘플 동일 확률이라 베르누이 적합. 파라미터 **p=0.7**.
- 표기: **X ~ Bernoulli(0.7)** ("~" = "is distributed as", 분포명 + 파라미터).

### PMF와 시각화
- P(valid)=0.7, P(invalid)=0.3(여사건). 결과와 확률 집합 = **PMF**(모든 이산 분포가 가짐, 합=1). 열 차트로 그리면 두 막대(p, 1−p) — 그래프가 곧 **PMF**.

### 모집단 파라미터
- **평균 μ = p** = 0.7.
- **분산 σ² = p(1−p)** = 0.7×0.3 = **0.21**.
- **표준편차 σ = √σ²** ≈ **0.458**(평균 주위 변동).
- **모집단 파라미터 μ·σ²·σ** vs **표본 통계 x̄·s²·s** — 표기가 다름.

### 확장
- 베르누이는 여러 시행을 모델링하는 **이항 분포(binomial)** 로 확장된다(예: 10개 키트 중 10개 모두 유효할 확률).

## 예시

### 베르누이 파라미터 (p=0.7)
| 값 | 공식 | 결과 |
|----|------|------|
| 평균 μ | p | 0.7 |
| 분산 σ² | p(1−p) | 0.21 |
| 표준편차 σ | √[p(1−p)] | 0.458 |

## 요약
- **베르누이 분포**는 성공(p)·실패(1−p) 두 결과를 모델링하며 파라미터는 **p** 하나다.
- 모집단 파라미터: **μ=p, σ²=p(1−p), σ=√[p(1−p)]** (표본 통계 x̄·s²·s와 표기 구분).
