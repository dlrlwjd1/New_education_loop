# Demo: Spreadsheet Simulation of a Normal Distribution

## 개요
- 스프레드시트로 정규 분포 표본을 생성하는 실습 데모 — 남성 키(μ=172, σ=7.1)를 시뮬레이션(다이빙 슈트 사이징).
- **RANDARRAY** 로 균등 난수를 만들고 **NORM.INV** 로 정규 값으로 변환, 배열 수식·차트로 요약한다.

## 내용

### 절차
1. **파라미터 입력**: 평균 172cm, 표준편차 7.1cm.
2. **균등 난수 생성**: `RANDARRAY(100)` 로 100개(수천~수만도 가능). 계산할 때마다 재생성.
3. **NORM.INV 변환**: `NORM.INV(난수, 평균, 표준편차)` — 3개 인자. 예: 난수 0.29 → 키 약 168cm (0.5 미만이라 평균보다 작음).
4. **배열 수식**: 원 수식을 배열 수식으로 감싸고 단일 셀 참조를 **열 전체**로 변경(평균·표준편차 셀은 그대로).
5. **체크박스**로 결과 재생성.

### 결과 관찰
- 키들이 대체로 평균 172cm ±몇 σ에 분포.
- 100개 표본은 항상 완벽한 종형이 아님 — 가운데 뚜렷한 정점이 없을 수도(표본 변동).
- **표본 통계 vs 모집단 파라미터**: 표본 평균 ≈ 171(≈172), 표본 표준편차 ≈ 7.04(≈7.1)로 근접. 새로고침마다 결과 변화.
- 극단 이상치(예: 191~195cm ≈ 6'3") 발생 → 분포 양 극단 사이즈도 몇 벌 재고 확보 권장.
- 파라미터를 바꾸면(예: 여성 키) 다른 시나리오 시뮬레이션 가능. (스프레드시트·솔루션은 Downloads 탭)

## 예시

### 핵심 수식
```
균등 난수:  =RANDARRAY(100)
정규 변환:  =NORM.INV(난수, 172, 7.1)
배열 적용:  =ARRAYFORMULA(NORM.INV(A2:A101, 172, 7.1))
```

## 요약
- **RANDARRAY** 균등 난수를 **NORM.INV(난수, μ, σ)** 로 변환하면 정규 분포 표본을 생성할 수 있다.
- 표본 통계(평균·표준편차)는 모집단 파라미터에 근접하며, 표본이 작으면 종형이 불완전하고 이상치가 나올 수 있다.
- 다음 강의는 **LLM을 이용한 정규 분포 시뮬레이션**이다.
