# Demo: LLM Simulation of a Normal Distribution

## 개요
- LLM으로 정규 분포 표본을 생성하는 데모와 그 **한계** — LLM은 **코드를 작성·실행할 수 있을 때만** 표집에 쓸 수 있다.
- 코드 실행 불가 LLM은 그럴듯하지만 실제 정규 분포가 아닌 값을 내며, Claude Artifacts처럼 코드 실행 가능한 도구라야 신뢰할 만하다.

## 내용

### 코드 실행 불가 LLM의 실패
- ChatGPT-4o mini(무료, 코드 실행 불가, MOOC 랩과 유사)에 "표준 정규 100개 생성"을 요청하면 값을 주지만, 이를 코드 실행 가능한 유료 ChatGPT-4o(고급 데이터 분석)로 **히스토그램**을 그리면 대략 대칭이나 **꼬리가 정규처럼 평평해지지 않음**.
- 앞 데모에선 100개만으로도 꽤 정규 형태였는데 이건 어긋남 → 통계 검정으로 정규성 여부를 판정 가능(강의 범위 밖).
- 결론: **LLM 자체는 정규 표본 생성 도구가 없다** → 표집엔 스프레드시트가 더 적합.

### 코드 실행 가능 LLM (Claude Artifacts)
- Claude에 "정규 분포 표집 인터페이스 + 히스토그램 시각화" 프롬프트 → 실제 **코드를 작성**해 앱 생성(μ·σ는 제공값).
- 오류로 데이터가 안 채워지면 두 번째 시도로 수정 가능(단 전체 앱 재작성 → 새 오류 위험).
- 결과: x축 키, y축 빈도, 상단 모집단 파라미터·우측 표본 통계.
  - 100개만으로도 표본 평균이 모집단 μ에 매우 근접, 시각적으로 정규에 가까움.
  - 개수 미지정 시 LLM이 1,000개 생성 → **표본이 클수록 표본 통계가 모집단 파라미터에 근접**. 생성마다 조금씩 변하고 이따금 정점이 덜 둥근 표본도 나옴.

### 핵심 원칙
- **어떤 LLM이든** 시뮬레이션 설계·결과 소통은 도울 수 있으나, **실제 실행은 코드 작성·실행 가능한 LLM으로만** 해야 한다.

## 예시

### LLM 시뮬레이션 판단
```
ChatGPT-4o mini (코드 X): 정규처럼 보이나 꼬리 어긋남 → 신뢰 불가
ChatGPT-4o 고급분석 (코드 O) / Claude Artifacts (코드 O): 실제 코드 실행 → 신뢰 가능
```

## 요약
- **코드 실행 불가 LLM**은 정규 표본을 제대로 못 만든다(꼬리 왜곡) → 스프레드시트가 낫다.
- **코드 실행 가능 LLM(Claude Artifacts 등)** 은 실제 코드로 정규 표집 앱을 만들며, 표본이 클수록 표본 통계가 모집단에 근접한다.
- LLM은 설계·소통엔 유용하나 실행은 코드 가능 도구로 한정. 다음 강의는 **분포로 의사결정하기**다.
