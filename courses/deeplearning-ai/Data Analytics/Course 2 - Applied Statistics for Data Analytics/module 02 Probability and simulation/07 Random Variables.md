# Random Variables

## 개요
- **확률 변수(random variable)** 는 무작위 현상의 **모든 가능한 결과**를 나타낸다(대문자로 표기, 예: X). 값은 반드시 **숫자**여야 수학적으로 다룰 수 있다.
- **이산(discrete)**(셀 수 있는 값)과 **연속(continuous)**(값 범위) 확률 변수로 나뉜다.

## 내용

### 확률 변수란
- 예: 주간 비 온 날 수 = 확률 변수 **X**. 가능한 값 0~7(8개), 각 값이 하나의 결과.
- 일반 변수(x+5=30 → x=25, 값 하나)와 달리 **여러 값**을 가질 수 있다.
- 표기 간소화: "비 3일 확률" = **P(X = 3)**.
- 비수치 결과는 **매핑**으로 숫자화(예: Y — 0=비 안 옴, 1=비 옴).

### 이산 vs 연속
- **이산(discrete)**: 셀 수 있는 distinct 값(X 8개, Y 2개). 데이터셋의 이산 특성과 같은 개념. 예: 학교 학생 수 S(0·300·1,701 가능하지만 1,700.5는 불가) → 이산.
- **연속(continuous)**: 값의 **범위**. 예: 주간 총 강수량 W(0 이상 임의 실수). 두 값 사이에 항상 또 다른 값이 존재(1~2cm 사이에 1.5, 1.25, 1.125…) → 연속. (실측 정밀도는 도구에 제한되나 이론상 임의 실수)
- 판별법: 가능한 값을 나열해 **사이에 값이 없으면 이산**, 있으면 연속.

### 중요한 구분 — 값 vs 확률
- 확률 변수는 **결과를 나타내는 값만** 담고, 각 값의 **확률은 담지 않는다**(흔한 혼동). 확률은 다음 레슨(확률 분포)에서 다룸.

## 예시

### 이산 vs 연속
| 변수 | 예 | 유형 |
|------|-----|------|
| 비 온 날 수 X | 0~7 | 이산 |
| 비 여부 Y | 0/1 | 이산 |
| 학생 수 S | 0·300·1701 | 이산 |
| 총 강수량 W | 임의 실수 | 연속 |

## 요약
- **확률 변수**는 무작위 현상의 모든 가능한 결과를 숫자로 나타내며(P(X=3) 등), 비수치는 매핑으로 숫자화한다.
- **이산**(셀 수 있는 값)과 **연속**(값 범위)으로 나뉘며, 값 사이에 다른 값이 있는지로 판별한다.
- 확률 변수는 **값만** 담고 **확률은 담지 않는다**. 이로써 확률 레슨이 마무리되고, 다음 레슨은 **추정과 이산 확률 분포**다.
