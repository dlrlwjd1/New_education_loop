# Conditional Probability

## 개요
- **조건부 확률(conditional probability)**: 다른 사건 B가 이미 일어났다고 할 때 사건 A가 일어날 확률 — **P(A | B)** ("A given B", `|` = "given").
- 공식: **P(A | B) = P(A and B) / P(B)**. B로 표본 공간을 좁힌 것.

## 내용

### 개념 (구독 예)
- "구독한 사람 중(취소 제외) premium일 확률" = **P(premium | 구독)**.
- 흐름도: ① 구독 vs 취소 → ② 구독한 경우만 basic vs premium. 조건부 확률은 **구독 가지(branch)만** 보고 그중 premium 비율을 물음.
- 직관: 표본 공간을 **구독자 5명**으로 좁힘(분모), 분자는 premium 2 → **2/5 = 40%**.
- 공식 적용: P(premium and 구독)/P(구독) = 0.2 / (0.3+0.2) = 0.2/0.5 = **40%**.

### 주의 — 방향성
- **P(A|B) ≠ P(B|A)**. 여기서 P(구독 | premium) = **100%**(premium이면 반드시 구독).

### 활용
- 데이터 애널리틱스에서 널리 사용: 제조(특정 온도에서 장비 고장 확률), 헬스케어(특정 증상 시 질병 확률), 스트리밍(슈퍼히어로 영화를 자주 보면 아이언맨을 좋아할 확률).
- **세그멘테이션과 관련** — 특정 조건(세그먼트)이 참일 때 통계를 계산하는 것이 조건부 확률과 통한다.

## 예시

### 공식
```
P(A | B) = P(A and B) / P(B)
P(premium | 구독) = 0.2 / 0.5 = 40%
P(A|B) ≠ P(B|A)
```

## 요약
- **조건부 확률 P(A|B)** 는 B가 일어난 조건에서 A의 확률로, **P(A and B)/P(B)**(표본 공간을 B로 좁힘)로 계산한다.
- **P(A|B) ≠ P(B|A)** 이며, 제조·헬스케어·스트리밍 등에서 널리 쓰이고 세그멘테이션과 관련된다.
- 어떤 사건은 서로 의존하고 어떤 사건은 독립이다. 다음 강의는 **독립(independence)** 이다.
