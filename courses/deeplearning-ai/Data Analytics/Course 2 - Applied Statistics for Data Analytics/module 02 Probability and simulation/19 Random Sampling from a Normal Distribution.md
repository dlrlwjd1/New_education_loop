# Random Sampling from a Normal Distribution

## 개요
- 정규 분포 표집은 **표준 균등 분포** 난수에서 시작해 **역 CDF 변환(inverse CDF transformation)** 으로 원하는 정규 분포 값으로 매핑한다.
- 스프레드시트 함수 **NORM.INV** 로 균등 난수를 정규 분포 표본으로 변환한다.

## 내용

### 문제 — 정규는 균등처럼 뽑을 수 없다
- 예: 다이빙 회사가 10명 그룹의 키를 시뮬레이션(슈트 사이징). 키는 균등하지 않아, 모든 값이 같은 확률인 균등 분포와 달리 **더 복잡한 함수**로 균등 난수를 정규 확률에 매핑해야 함.

### 2단계 표집 절차
1. **표준 균등 분포**에서 난수 생성(예: 0.2218) — 이산 예시와 동일.
2. **역변환**으로 1단계 값을 정규 분포 값으로 변환(예: 남성 키 μ=172, σ=7.1).

### 역 CDF 변환의 원리
- 정규 분포 **CDF는 0~1** 범위(−∞→+∞의 누적 확률). **표준 균등 분포도 0~1** → 둘을 연결.
- 균등 난수(예 0.5)를 CDF **y축**에 두고 곡선까지 수평선, 다시 x축으로 내리면 대응하는 키(0.5 → 평균 172cm, 대칭이므로 P(≤172)=0.5).
- 균등 난수들이 x축의 서로 다른 키 값으로 투영됨 = **역 CDF(inverse CDF)**.
- 스프레드시트: **NORM.INV(균등값, μ, σ)** 로 주어진 CDF 값에 대응하는 x를 구함.

### 반복과 의미
- 이 과정을 9번 더 반복해 10명 시뮬레이션 → 사이즈별 필요 수량 추정.
- 실제 변동성 모방: 표본이 평균 주위로 흩어져 현실적인 고객 분포·재고 발주에 도움.

## 예시

### 정규 분포 표집 흐름
```
1) 균등 난수:  =RAND()           (0~1)   예: 0.2218
2) 역 CDF:     =NORM.INV(RAND(), μ, σ)    예: NORM.INV(0.2218, 172, 7.1)
   → 균등 0.5  →  키 172cm (평균, 대칭이라 P(≤172)=0.5)
```

## 요약
- 정규 분포 표집은 **균등 난수 → 역 CDF 변환**의 2단계로 이뤄진다(균등·CDF 모두 0~1 범위라 연결 가능).
- 스프레드시트 **NORM.INV(균등값, μ, σ)** 로 균등 난수를 정규 표본으로 바꾼다.
- 여러 번 반복하면 현실적 변동성을 모방한 표본을 얻는다. 다음은 스프레드시트 실습이다.
