# Making Decisions with Distributions

## 개요
- 확률 분포·기술 통계를 결합해 **비즈니스 의사결정**을 내리는 종합 예제 — 타이핑 속도(정규 분포)와 SNS 게시 빈도(멱법칙 분포).
- 절차: 데이터 시각화(히스토그램·박스플롯) → 분포 가정 → 표본 통계로 모수 근사 → 분포 모델로 확률·백분위 질문에 답변.

## 내용

### 사례 1 — 타이핑 속도 (정규 분포 가정)
- 온라인 시험 회사가 타이핑 속도의 시험 영향 우려 → 100명 단순 무작위 표본.
- 히스토그램·박스플롯 → **대략 정규**(표본 100이라 변동 있음). 정규 가정 하에 진행.
- 표본 통계: x̄ = **72.47 wpm**, s = **9.59 wpm**. 정규라면 x̄·s를 모수 **μ·σ의 근사**로 사용.
- **분포 모델의 힘**: 표본에 없던 값의 확률도 추정.
  - P(속도 < 40 wpm, 시간 내 완료 임계) ≈ **0.035%(약 1/2,800명)** → 시험 시간 유효성 판단.
  - 불만 사용자 80 wpm → **78번째 백분위**(78%보다 빠름) → 불만 기각 근거.
  - 불만 사용자 51 wpm → **1번째 백분위**(매우 느림) → 시간 연장 자격 가능.

### 사례 2 — SNS 게시 빈도 (멱법칙 분포 가정)
- SNS 회사가 게시 유도 방안 필요 → 200명 1주 추적.
- 히스토그램·박스플롯 → 0 근처 집중 + 양의 긴 꼬리 → **멱법칙(양의 왜도)**. (가설 검증 추가 필요하나 확정 가정)
- 표본 통계: x̄ = **14.465**, s = **23.8**. 단 정규가 아니므로 **시그마 규칙 적용 불가**.
- 마케팅: 하위 50% 사용자가 주당 1건 더 게시하는 인센티브 →
  - **중앙값**: 3 → 4건(**+33%**).
  - **평균**: 절반에 1건씩 더해져 +0.5 → 10.47 → 10.97(**+5%**). (평균은 꼬리 값에 크게 좌우 → 중앙값보다 변화율 작음)
  - **총 게시 수**도 평균과 같은 비율로 증가 → 전체 모집단 적용 시 효과 특성화.

## 예시

### 의사결정 흐름
```
1) 시각화(히스토그램·박스플롯) → 분포 유형 추정
2) 분포 가정 (정규 / 멱법칙 …)
3) 표본 통계(x̄, s)로 모수(μ, σ) 근사   ※ 정규 아니면 시그마 규칙 불가
4) 분포 모델로 확률·백분위 질문 답변 → 의사결정
```

## 요약
- **시각화 → 분포 가정 → 표본 통계로 모수 근사 → 분포 모델로 질문 답변**의 흐름으로 의사결정을 내린다.
- 정규 분포는 표본에 없는 값의 확률·백분위까지 추정하나, **멱법칙 등 비정규 분포엔 시그마 규칙을 쓸 수 없다**.
- 이로써 모듈 2(확률·분포·시뮬레이션)를 마치며, 다음 모듈은 **신뢰 구간(confidence intervals)** 이다.
