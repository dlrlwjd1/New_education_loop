# The Cumulative Distribution Function

## 개요
- **누적 분포 함수(CDF, cumulative distribution function)** 는 확률 변수가 **주어진 값 이하**의 값을 가질 확률을 모델링한다: **P(X ≤ x)**.
- 단일 결과가 아니라 **범위(range)** 의 확률을 구할 때 쓴다. 이산 분포에서는 **덧셈 규칙**으로 계산.

## 내용

### 왜 필요한가
- 예: DNA 랩의 품질 관리 트리거가 "유효 샘플 50% 미만"(즉 4개 이하)이면 박스 폐기·재발송. "얼마나 자주 트리거가 걸리나?"는 4개 하나가 아니라 **0·1·2·3·4개 모두**의 확률이 필요 → CDF.

### CDF의 정의와 모양
- 이산 확률 변수 X에 대해 **CDF = P(X ≤ x)**.
- n=10, p=0.7 이항 분포의 CDF: PMF와 같은 축, X가 커질수록 확률이 **단조 증가**, X=10에서 확률 1로 끝난다.

### 계산 — 덧셈 규칙과 여사건
- **4개 이하**: P(X=2)+P(X=3)+P(X=4) ≈ 0.001+0.009+0.036 = **0.046(약 4.6%)** (0·1은 극히 드물어 무시).
- **평균 초과(above average, 7 초과)**: 여사건 규칙 → 1 − P(X ≤ 7) = 1 − 0.61 = **0.39(약 39%)**.
- **트리거 미발동**: 1 − 0.046 = **0.954(95.4%)**.

### 이항 분포의 활용 범위
- 예/아니오, 성공/실패 시나리오 전반: 마케팅 **전환율(conversion rate)**, 품질관리 **불량률**, HR **직원 유지율**, 금융 **대출 부도율(loan default)** 등.

## 예시

### CDF 질문 (n=10, p=0.7)
| 질문 | 방법 | 결과 |
|------|------|------|
| 4개 이하 (트리거) | P(2)+P(3)+P(4) | ≈ 4.6% |
| 평균(7) 초과 | 1 − P(X≤7) | ≈ 39% |
| 트리거 미발동 | 1 − 0.046 | ≈ 95.4% |

## 요약
- **CDF = P(X ≤ x)** 는 값 이하(범위)의 확률을 주며, X 증가에 따라 단조 증가해 1로 끝난다.
- 이산 분포는 **덧셈 규칙**으로 CDF를 계산하고, "초과/미발동" 같은 질문은 **여사건 규칙**으로 푼다.
- 이항 분포는 예/아니오 시나리오 전반에 유용하며, 다음 강의는 이 분포들에서 **표집(sampling)** 하는 법이다.
