# Demo: LLM Simulation of a Discrete Distribution

## 개요
- **대규모 언어 모델(LLM)** 로 이산 분포를 시뮬레이션하는 데모 — 단, **코드를 작성·실행할 수 있는 LLM만** 시뮬레이션에 유용하다.
- Claude의 **Artifacts** 기능으로 DNA 키트 샘플링 인터페이스를 만들어 반복 표집·시각화한다.

## 내용

### LLM의 한계
- LLM은 **수학에 약하다**. 무작위 표집은 수학적 작업이므로 LLM은 **코드를 작성·실행할 수 있을 때만** 적합.
- 코드 실행이 가능하면 실제로 확률을 계산할 수 있다. 그렇지 않은 LLM은 "다음 단어 추측"만 할 뿐 진짜 무작위성을 보장하지 못함.

### Claude Artifacts 데모
- Artifacts는 코드를 작성·실행하는 기능. 프롬프트 예:
  - "10개 반려견 DNA 키트 박스를 샘플링하는 인터페이스 생성, 유효 확률 70%"
  - 버튼 클릭 시 10개 샘플을 **유효=초록, 무효=빨강** 으로 시각화
  - 지금까지의 유효/무효 개수 및 **누적 유효 비율(%)** 추적
- Claude가 코드를 생성한다는 사실 자체가 실제로 분포에서 무작위 표집할 수 있음을 보여줌(코드 내에서 난수 생성).

### 결과 관찰 — 대수의 법칙
- 새 표본 생성 시 요청대로 동작: 초록/빨강 샘플 이미지 + 유효/무효 수 + 전체 유효 비율.
- 초기엔 80% 유효 등 변동이 크지만, **표본이 많이 쌓이면 유효 비율이 실제 확률 70%에 수렴**한다.
- 무효가 많은 박스(예: 5개 무효)도 비교적 흔함을 시각적으로 확인 가능.

## 예시

### LLM 시뮬레이션 조건
```
가능:   코드 작성·실행 가능 LLM (예: Claude Artifacts) → 실제 난수 생성
불가:   코드 실행 불가 LLM → 다음 단어 추측, 진짜 무작위성 없음
```

## 요약
- **코드 실행이 가능한 LLM만** 시뮬레이션에 쓸 수 있다(LLM은 수학·무작위성에 약하므로).
- Claude **Artifacts** 로 DNA 키트 샘플링 인터페이스를 만들어 반복 표집·시각화할 수 있다.
- 표본이 쌓이면 유효 비율이 실제 확률(70%)에 수렴한다. 다음 강의부터 **연속 확률 분포**를 다룬다.
