# Course 2 — Applied Statistics for Data Analytics

**Specialization:** [Data Analytics](../README.md)
**제공:** DeepLearning.AI

## 개요
데이터 분석을 위한 응용 통계 코스. 기술 통계(central tendency·variability·skewness)부터 확률·확률 분포·시뮬레이션, 추론 통계(신뢰 구간·가설 검정)까지 다룬다. 스프레드시트 실습과 생성형 AI(LLM) 활용이 전 모듈에 통합되어 있다.

## 모듈 구성
1. **Module 1 — Foundational statistical techniques** (영상 27개) — 모집단·표집, 편향, 히스토그램, 중심 경향(평균·중앙값·최빈값), 변동성(범위·IQR·분산·표준편차), 왜도, 박스플롯, 상관, 세분화, XLOOKUP, 피벗 테이블
2. **Module 2 — Probability and simulation** (영상 22개) — 확률·덧셈/곱셈/여사건 규칙, 조건부 확률·독립, 확률 변수, 이산 분포(베르누이·이항·CDF), 연속 분포(균등·정규·표준 정규·멱법칙), z-점수, 무작위 표집·시뮬레이션
3. **Module 3 — Confidence intervals** (영상 14개) — 추론 통계, 점·구간 추정, 표집 분포·중심 극한 정리, 신뢰 구간(평균·비율), 오차 한계, LLM 활용
4. **Module 4 — Hypothesis testing** (영상 18개) — 가설(H₀·H₁), 검정 통계량, 유의 수준·기각역, p-값, 오류(거짓 양성/음성), t-분포, 비율·두 표본 검정, 기타 검정(ANOVA·카이제곱 등), LLM 활용

> 각 모듈 하위 폴더에 영상 강의 정리본(`NN 주제.md`)이 들어간다. Quiz·Lab·Reading·Resources·Lecture Notes·Capstone은 노트 대상에서 제외한다.
