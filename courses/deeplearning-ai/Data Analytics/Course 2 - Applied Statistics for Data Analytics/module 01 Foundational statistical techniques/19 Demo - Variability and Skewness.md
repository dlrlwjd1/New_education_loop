# Demo: Variability and Skewness

## 개요
- LendingTree Paid Interest 데이터로 스프레드시트에서 **범위·분산·표준편차·왜도**를 계산하는 데모.
- 중심경향(평균 ~$617, 중앙값 ~$456)을 변동성·왜도로 보완.

## 내용

### 범위(range)
- `=MAX(...)` ≈ $3,500, `=MIN(...)` = $0 → 범위 ≈ **$3,500**(꽤 큰 변동성). 최댓값이 99번째 백분위수보다 ~$1,000 커 상위에서 큰 점프.

### 분산·표준편차
- `=VAR(...)` ≈ **$280,000**(단위 = 달러², 통화 서식 X, 소수 축소). 
- **표준편차 = √분산** → `=SQRT(...)` 로 원 단위(달러), 통화 서식. 또는 **STDEV 함수**로 직접 계산(같은 결과, 분산 단계 생략).

### 왜도(skewness)
- 히스토그램·(평균 > 중앙값)으로 **양의 왜도** 판단. `=SKEW(...)` ≈ **1.55** → **>1 = 강한 양의 왜도**. 분포에서 본 행동을 확인.

### 의미
- 중심경향·변동성·왜도만으로도 잠재 이자 수익에 대해 많은 것을 알 수 있다.

## 예시

### 함수
```
=MAX(범위)-MIN(범위)   → 범위
=VAR(범위)             → 분산(달러²)
=SQRT(VAR(...)) / =STDEV(범위) → 표준편차
=SKEW(범위)            → 왜도(>1 강함)
```

## 요약
- 스프레드시트에서 **MAX/MIN(범위)·VAR(분산)·STDEV/SQRT(표준편차)·SKEW(왜도)** 로 변동성·왜도를 계산한다.
- Paid Interest는 범위 ~$3,500, 표준편차 상당, **SKEW ≈ 1.55(강한 양의 왜도)** 로 나타났다.
