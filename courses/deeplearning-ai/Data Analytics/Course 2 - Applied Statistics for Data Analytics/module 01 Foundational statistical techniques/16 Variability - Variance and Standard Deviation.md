# Variability: Variance and Standard Deviation

## 개요
- **분산(variance)** 은 값들이 평균에서 떨어진 **제곱 거리의 평균**으로, 표준편차 등 많은 통계의 기초다.
- **표준편차(standard deviation)** = 분산의 제곱근 — 데이터와 **같은 단위**라 분포를 특성화하는 데 흔히 쓴다.

## 내용

### 분산 계산 (1934 영화 평점, 평균 7.5)
1. 각 값에서 평균을 빼 **편차(deviation)** 를 구함(예: Cleopatra 6.9 − 7.5 = −0.6).
2. **제곱**(0.36) — 부호 상쇄 방지 + 큰 편차 강조.
3. 모든 값에 반복해 **제곱 편차 합**.
4. **n−1** 로 나눔(1934는 23) → 분산 **0.13**.
- **왜 n−1?**: 전체 모집단이 아닌 **표본**을 다룰 때 정확성을 높이는 보정(특히 작은 표본). n−1이 조금 작아 추정 분산이 조금 커져 불확실성을 반영.
- 공식: **s² = Σ(xᵢ − x̄)² / (n−1)**.
- 1966 분산 = **0.42**(약 3배) → 1966 평점이 더 퍼짐(직관 확인).

### 표준편차 (standard deviation)
- 분산은 **제곱 단위(points²)** 라 해석이 어색 → **제곱근**을 취하면 원 단위로. 1934: √0.13 ≈ **0.355**.
- 표기: 표본 표준편차 **s**, 표본 분산 **s²**(=표준편차의 제곱). 1966 표준편차 ≈ **0.655**(더 큼).
- 시각화: 히스토그램에 평균±1 표준편차(빨간 점선) — 1934는 좁고 1966은 넓음(값들이 점선을 바깥으로 당김).

### 실무
- 둘 다 쓰인다 — **분산**은 다른 계산의 파생에, **표준편차**는 분포 특성화에.

## 예시

### 공식
```
분산  s² = Σ(xᵢ − x̄)² / (n−1)
표준편차 s = √(s²)
```

### 1934 vs 1966
| 척도 | 1934 | 1966 |
|------|------|------|
| 분산 | 0.13 | 0.42 |
| 표준편차 | 0.355 | 0.655 |

## 요약
- **분산 = Σ(값−평균)² / (n−1)** — 제곱으로 부호 상쇄 방지·큰 편차 강조, **n−1** 은 표본 보정.
- **표준편차 = √분산** 으로 데이터와 같은 단위라 분포 특성화에 흔히 쓴다.
- 분산은 파생 계산에, 표준편차는 해석에 유용하다. 다음 강의는 **왜도(skewness)** 다.
