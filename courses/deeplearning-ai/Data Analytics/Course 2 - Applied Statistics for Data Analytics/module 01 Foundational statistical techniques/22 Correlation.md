# Correlation

## 개요
- **상관(correlation)** 은 두 수치 특성의 관계를 정량화한다. 가장 흔한 척도는 **피어슨 상관계수(Pearson correlation coefficient) r** — 항상 **−1 ~ 1** 사이.
- r은 **직선(line of best fit)을 얼마나 잘 맞출 수 있는가** = 선형 관계의 **강도와 방향**을 나타낸다.

## 내용

### 직관
- 산점도에 직선을 얼마나 잘 맞출 수 있는지가 r. 예: TV 에피소드 수(x) vs 시청 시간(y).
- **r = +1**: 완벽한 양의 상관(모든 에피소드가 정확히 같은 길이 → y=0.75x, 기울기 0.75, 완전 예측 가능).
- **r ≈ +0.85**: 강하지만 완벽하진 않음(에피소드 길이가 조금씩 다름).
- **r ≈ −0.85**: 강한 음의 상관(TV 시청↑ → 공부 시간↓). 강도는 같고 **방향만 음(기울기 음)**.
- **r = 0**: 상관 없음(TV 시청 vs 물 섭취). 최적선 기울기 0 — x와 무관하게 y의 평균만 예측.

### r 해석 (강도와 방향)
- **강도**(절댓값): 0~0.3 약함, 0.3~0.7 중간, 0.7~1 강함.
- **방향**: 양수=함께 증감, 음수=반대로 증감.
- 왜도 해석과 유사(강도 + 방향).
- 완벽한 직선은 기울기 크기와 무관하게 r=±1(양의 기울기=+1, 음의 기울기=−1). 관계가 없으면 r=0(평평).

## 예시

### r 해석
| \|r\| | 강도 | 부호 | 방향 |
|------|------|------|------|
| 0~0.3 | 약함 | + | 함께 증가/감소 |
| 0.3~0.7 | 중간 | − | 반대로 |
| 0.7~1 | 강함 | | |

## 요약
- **상관계수 r**(피어슨, −1~1)은 두 수치 특성의 **선형 관계 강도·방향**을 나타내며, 직선을 얼마나 잘 맞출 수 있는지로 이해한다.
- 절댓값으로 강도(약<0.3<중간<0.7<강), 부호로 방향(양=함께, 음=반대)을 해석한다.
- r=±1은 완벽한 선형, r=0은 관계 없음. 다음 강의는 **상관과 인과(correlation and causation)** 다.
