# Generative AI in This Course

## 개요
- 이 코스의 핵심 요소 중 하나는 **생성형 AI(LLM)** 활용 — ChatGPT·Claude·Gemini 등. 효과적 활용이 업무를 간소화하고 차별화한다.
- 특정 제품이 아니라 **에버그린 원칙**과 **반복·회의(skepticism) 마인드셋**, 그리고 언제 LLM을 쓰고 언제 스프레드시트를 쓸지 판단하는 능력을 기른다.

## 내용

### LLM으로 배울 것
- 스프레드시트 오류 해결, 커스텀 조건부 서식 생성, **시뮬레이션 설계·실행**, **추론 통계 해석**, 통계 분석 실행.
- LLM의 **핵심 한계**와, 작업별로 LLM vs 다른 도구(스프레드시트)를 선택하는 법.

### 코스의 생성형 AI 철학
- 2025년 기준 최신 역량을 보여주되 변화를 예상 → **제품 불문 원칙 + 반복·회의 마인드셋 + 메타인지 기술**.
- 향후: 더 고급·특화 기능(앱 사용), 더 싸고 빠르고 고품질. 유료 기능도 보여주지만 **과제엔 추가 구매 불필요**. 단일 도구 추천 안 함(무료·유료 모두 대비).
- 이 모듈 **레슨 3** 에서 첫 LLM 데모·실습 랩.

## 요약
- 이 코스는 LLM을 스프레드시트 오류·서식·**시뮬레이션·추론 통계 해석·분석**에 활용하는 법과 **한계·도구 선택**을 가르친다.
- 특정 제품이 아니라 **제품 불문 원칙 + 반복·회의 마인드셋**을 기른다.
- 유료 기능 시연이 있으나 과제엔 추가 구매가 필요 없다.
