# Histograms

## 개요
- **분포(distribution)** 는 값들이 얼마나 자주 나타나는지를 보여준다. **기술 통계**는 데이터의 분포를 특성화하는 것.
- **히스토그램(histogram)** 은 연속 수치 데이터를 **구간(bin)** 으로 묶어 각 구간의 **빈도(frequency)** 를 시각화하는 특수한 열 차트다.

## 내용

### 히스토그램 vs 열 차트
- **열 차트**: 범주/이산 수치를 x축, 수치를 y축으로 범주 간 비교.
- **히스토그램**: 연속 수치 특성의 값 빈도를 시각화. x축에 값을 묶은 **구간(bin)**, y축에 **빈도**(그 구간에 속한 관측 수, 또는 비율).

### 예시 — 영화 상영 시간
- 2013년 인기 영화 25편의 상영 시간 데이터(이름·연도·IMDb 평점·평점 수·상영 시간).
- 상영 시간(연속 수치)을 7분 구간으로 묶으면 10개 bin. 10분 구간이 해석이 더 쉬움(예: "약 절반이 2시간 미만").
- **구간 크기(bin size)** 주의: 너무 적으면 과단순화, 너무 많으면 패턴 파악이 어려움.
- 좋은 시각화 원칙 유지: 명확한 라벨·적절한 스케일·색·서술적 제목·가독 폰트.
- **여러 히스토그램 나란히** 비교(1993·2003·2013, 같은 bin) → 시간에 따른 변화(약간 우측 이동?, 대체로 일관). 200분 영화는 쉰들러 리스트(1993)·반지의 제왕: 왕의 귀환(2003).

## 예시

### 히스토그램 vs 열 차트
| 구분 | x축 | y축 |
|------|-----|-----|
| 열 차트 | 범주/이산 | 수치 |
| 히스토그램 | 연속 수치의 구간(bin) | 빈도(또는 비율) |

## 요약
- **히스토그램**은 연속 수치 특성을 **구간(bin)** 으로 묶어 **빈도**를 보여주는 시각화로, 분포를 파악하는 기본 도구다.
- **구간 크기**가 중요하며(너무 적으면 과단순, 너무 많으면 패턴 불명), 좋은 시각화 원칙을 지킨다.
- 여러 히스토그램을 같은 bin으로 나란히 두면 분포 비교가 쉽다. 다음 강의는 스프레드시트에서 히스토그램 만들기 데모다.
