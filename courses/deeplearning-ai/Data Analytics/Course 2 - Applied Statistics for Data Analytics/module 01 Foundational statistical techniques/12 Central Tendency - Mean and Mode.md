# Central Tendency: Mean and Mode

## 개요
- 중심경향 측정 도구: **평균(mean)·중앙값(median)·최빈값(mode)**. 이 강의는 **평균과 최빈값**을 다룬다.
- 표기법: **x** = 표본의 특정 값, **n** = 표본 크기(행/관측 수), **x̄** = 표본 평균.

## 내용

### 평균(mean)
- 모든 값을 더해 표본 크기로 나눈 것 = **평균(average)**. 직관: 총합을 값 개수에 **균등 분배**.
- 표기: **x̄ = (Σ xᵢ) / n** (i=1..n, Σ=시그마=모두 더함).
- 예(2013 영화 25편): 총 3,035분 / 25 = **121.4분**. x₁=Man of Steel(143분) … x₂₅=A Good Day to Die Hard(98분).

### 최빈값(mode)
- 표본에서 **가장 흔한 값**. 2013 영화는 98분 3편·130분 3편으로 **최빈값이 2개** — 이런 데이터엔 별로 유용치 않음.
- 최빈값은 **이산 수치·범주형** 데이터에 더 유용(평균·중앙값이 부적용일 때). 예: 후보 A·B·C 득표 55%·30%·15% → 평균을 낼 수 없고, **최빈값=A**(최다 득표)가 중심을 잘 설명.

## 예시

### 평균 계산
```
x̄ = (x₁ + x₂ + ... + xₙ) / n
영화: 3,035 / 25 = 121.4분
```

### 평균 vs 최빈값
| 측정 | 정의 | 적합 데이터 |
|------|------|-------------|
| 평균(mean) | 총합/개수 | 수치 |
| 최빈값(mode) | 최다 등장 값 | 이산·범주형(득표 등) |

## 요약
- **평균 = Σxᵢ / n** (총합을 균등 분배), 예로 2013 영화 평균 121.4분.
- **최빈값**은 가장 흔한 값으로, 여러 개일 수 있고 **이산·범주형**(득표 등)에 특히 유용하다.
- 다음 강의에서 **중앙값(median)** 을 다룬다.
