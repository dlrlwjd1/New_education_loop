# Demo: LLMs for Spreadsheet Formulas & Errors

## 개요
- LLM은 스프레드시트 **수식 작성·오류 해결**의 사고 파트너다. 영화 데이터로 오류 수정·행 세기·조건부 서식 예시를 본다.
- 핵심: LLM에 **수식·데이터 일부·셀 참조**를 제공하고, **항상 최선의 해법을 주진 않으므로** 검증한다.

## 내용

### 오류 해결 (formula parse error)
- `COUNTIF(E, >120)` 가 **formula parse error**(모호한 메시지). LLM에 "수식과 데이터 몇 행을 붙여" 물음 → **조건을 따옴표로 감싸야 함**(`">120"`)이라고 안내(Excel 가정 → "Google Sheets도 되나?" 후속 확인). 수정 후 2시간 초과 영화 수 반환.

### 행 개수 세기 (여러 옵션 요청)
- "수식으로 행 수를 세는 방법을 몇 가지 줘" → 여러 옵션. **COUNTA**(빈 행 포함)는 헤더까지 세어 실제보다 1 많음 → **−1** 보정. 강사는 **COUNT**(숫자 열)로 정확한 수를 얻음 — **COUNT는 LLM 옵션에 없었음** → LLM이 늘 최선을 제시하진 않음을 보여줌.
- 2시간 초과 비율 계산 → 약 **31%**.

### 조건부 서식 (커스텀 수식)
- "duration이 **75번째 백분위수 이상**이면 A~E 행을 초록으로 강조, 내 75번째 백분위수는 H6" → LLM이 단계 + **커스텀 수식** 제공(외우기 어려우니 LLM이 유용). H6 같은 **셀 참조를 명시**해야 올바른 수식.
- 적용: 전체 열 선택 후 헤더 행은 Command/Control-click로 제외 → 커스텀 수식 입력. 75번째 백분위수(125분) 이상 영화(예: Marius 130분)가 강조됨(옛 영화는 짧아 초반엔 적음).

### 결론
- LLM은 스프레드시트 기능 발견·오류 해결을 돕지만 **검증**이 필요하다.

## 예시

### LLM 활용 팁
| 작업 | 팁 |
|------|-----|
| 오류 해결 | 수식+데이터 일부 제공, 플랫폼 확인 |
| 여러 방법 | "옵션 몇 개 줘" (단, 최선이 빠질 수 있음) |
| 조건부 서식 | 셀 참조(H6) 명시, 헤더 제외 |

## 요약
- LLM은 스프레드시트 **수식·오류·조건부 서식**의 사고 파트너로, 수식·데이터·셀 참조를 제공하면 도움이 된다.
- 단, **최선의 해법을 늘 주진 않으므로**(COUNT 누락 예) 결과를 검증해야 한다.
- 다음 레슨은 **상관(correlation)** 이다.
