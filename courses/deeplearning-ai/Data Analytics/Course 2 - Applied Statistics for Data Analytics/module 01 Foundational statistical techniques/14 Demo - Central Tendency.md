# Demo: Central Tendency

## 개요
- LendingTree 대출 데이터로 스프레드시트에서 중심경향(평균·중앙값·백분위수·최빈값)을 계산하는 데모.
- 히스토그램을 기술 통계로 보완해 대출 이자 수익을 파악한다.

## 내용

### 계산 (Paid Interest)
- **평균**: `=AVERAGE(paid interest 열)` → 약 **$617**.
- **중앙값**: `=MEDIAN(...)` → 평균보다 낮음 → **평균 > 중앙값**은 데이터에 **높은 값(우측 꼬리)** 이 있음을 시사.
- **백분위수**: `=PERCENTILE(범위, p)`, p는 **0~1**. 10번째=0.1 → 약 $117. 50번째=0.5 → **중앙값과 동일**. 99번째 → **$2,400+**(상위 1%).

### 최빈값 (범주형 — Homeownership)
- 주택 소유(rent/home/mortgage)는 중앙값·평균을 낼 수 없음. **MODE는 숫자만** 사용하므로 숫자 코드 열(rent=1·mortgage=2·own=3) 사용.
- `=MODE(homeownership 숫자 열)` → **2(mortgage)** → 대출자 다수가 모기지 보유 → 담보·생애 단계 파악에 도움.

### 의미
- Paid Interest의 중심경향으로 **평균적 예상 수익**의 감을 얻는다.

## 예시

### 함수
```
=AVERAGE(범위)          → 평균
=MEDIAN(범위)           → 중앙값
=PERCENTILE(범위, 0.1)  → 10번째 백분위수(p는 0~1)
=MODE(숫자 범위)        → 최빈값(숫자만)
```

## 요약
- 스프레드시트에서 **AVERAGE·MEDIAN·PERCENTILE(p=0~1)·MODE** 로 중심경향을 계산한다.
- **평균 > 중앙값**은 우측 꼬리(높은 값) 존재를 시사하며, 범주형 최빈값은 숫자 코드로 MODE를 쓴다(대출자 다수 모기지).
- 중심경향으로 평균 예상 수익을 파악했다. 다음 레슨은 **변동성과 왜도**다.
