# Demo: Pivot Tables

## 개요
- **피벗 테이블(pivot table)** 로 세그먼트별 기술 통계를 계산한다. LendingTree에서 **대출 등급(grade)별 이자율** 등을 분석.
- 핵심: 행(세그먼트)·값(집계 특성)·**요약 함수(summarize by)** 설정, 그리고 결과를 데이터로 **검증**.

## 내용

### 피벗 테이블 만들기
- 전체 데이터 선택 → **Insert → Pivot table**(새 시트). 오른쪽 **피벗 테이블 편집기**에서 설정.
- **Rows**: 세그먼트 기준(예: **grade** — A=최저 위험, G=최고 위험) → 고유 등급이 좌측에.
- **Columns**: 두 특성으로 피벗할 때(여기선 생략).
- **Values**: 집계할 특성(예: interest rate).

### 요약 함수(summarize by)
- 기본은 **SUM** → grade A 이자율 4786 같은 이상한 값(전 대출 이자율 합계). **average** 로 변경 → 등급별 합리적 평균 이자율.
- 숫자 형식(소수 2자리). 이 값들은 %이므로 **percent 형식으로 바꾸지 말 것**.
- 인사이트: **grade A 최저 이자율, 위험 등급일수록 상승**(위험↑ → 이자율↑).
- 편집기를 닫았으면 표 좌하단 **연필 버튼**으로 재오픈.

### 값 추가·검증
- 이자율을 다시 추가하고 요약 함수를 **표준편차** 로 → 등급별 변동성(위험 등급일수록 변동성 증가 경향, 이자율이 높아서). grade G의 표준편차가 **0** → 모든 값이 같거나 데이터가 하나.
- total credit utilized(average, 달러 형식) 추가 → 등급별 대출 총액(대부분 고품질 등급). grade G가 $288,000.
- **데이터 검증**: G 등급이 하나로 의심했으나 실제로는 **4개**이며 **모두 동일 이자율**(저품질 대출의 최대 이자율일 가능성), 합계가 $288,000과 일치.

## 예시

### 피벗 테이블 설정
| 영역 | 예 |
|------|-----|
| Rows | grade(세그먼트) |
| Values | interest rate |
| Summarize by | SUM(기본) → **average**/표준편차 |

## 요약
- **피벗 테이블**은 세그먼트별 기술 통계를 계산한다 — **Rows(세그먼트)·Values(특성)·Summarize by(집계 함수)** 를 설정한다.
- 기본 SUM을 **average·표준편차** 등으로 바꿔 의미 있는 값을 얻고(대출 등급↑ → 이자율·변동성↑), 결과는 **데이터로 검증**한다(grade G=4건, 동일 이자율).
- 이로써 모듈 1(기초 통계)이 마무리되고, 다음 모듈은 **확률과 시뮬레이션**이다.
