# Box Plots

## 개요
- **박스 플롯(box plot, box-and-whiskers)** 은 분포의 **사분위수**를 시각화한다 — 박스(Q1~Q3=IQR)·중앙선(중앙값)·수염(whiskers)·이상치(outlier).
- 여러 분포를 **비교**하고 이상치를 빠르게 찾는 데 특히 강하다. 히스토그램은 세부 형태 파악에 강하다.

## 내용

### 구성 요소
- **박스**: Q1~Q3(= IQR, 가운데 50%). **중앙선** = 중앙값(Q2).
- **수염(whiskers)**: 보통 Q1·Q3에서 **IQR의 1.5배** 이내의 최소·최대값까지 확장.
- **이상치(outliers)**: 수염 밖의 값, 개별 마커로 표시.
  - 비왜곡 분포: 양쪽에 이상치(예: 키 — 아주 작거나 큰 사람).
  - **왜곡 분포**: 이상치가 대개 **한쪽**에 몰림(예: 기부금 대부분 $10~20, 큰 기부 소수 → 이상치는 큰 값 쪽).

### 예시 — 영화 상영 시간
- 2013 박스 플롯: 중앙값 120분 약간 아래, 가운데 50%가 약 108~132분.
- **다중 분포 비교**(1933·1973·2013): 2013 중앙값 ~120, 1973 ~115(비슷, 변동성도 유사). 1933은 중앙값 ~90분, 40분짜리도 흔했고 박스가 겨우 120에 닿음 → 1933~2013 사이 상영 시간이 늘었고 후반부엔 변화가 대체로 마무리됨.

### 박스 플롯 vs 히스토그램
- **히스토그램**: 분포의 **세부 형태**·값 범위별 빈도·granular 검토.
- **박스 플롯**: **여러 그룹 비교**·이상치 식별·중앙값/사분위/범위를 **한눈에**.

## 예시

### 언제 무엇을
| 목적 | 선택 |
|------|------|
| 분포의 세부 형태·빈도 | 히스토그램 |
| 여러 그룹 비교·이상치·요약 통계 | 박스 플롯 |

## 요약
- **박스 플롯**은 **박스(Q1~Q3=IQR)·중앙값·수염(1.5×IQR)·이상치**로 분포를 요약하며, 왜곡 분포는 이상치가 한쪽에 몰린다.
- **여러 분포 비교·이상치 식별**에 강하고(예: 영화 상영 시간 연도 비교), 히스토그램은 **세부 형태** 파악에 강하다.
- 다음 강의는 **LLM으로 스프레드시트 오류·수식 다루기** 데모다.
