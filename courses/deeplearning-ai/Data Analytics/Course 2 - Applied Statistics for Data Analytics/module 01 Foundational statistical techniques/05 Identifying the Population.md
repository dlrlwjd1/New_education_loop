# Identifying the Population

## 개요
- 표본을 수집하기 전에 **무엇을 표본으로 삼을지(모집단)** 정해야 한다 — 다른 모집단을 분석하면 다른 인사이트가 나온다.
- 모집단 정의 프로세스: **가설/연구 질문 → 핵심 특성 식별 → 실용적 제약 → 일반화 가능성 → 이해관계자 협의**.

## 내용

### 왜 모집단 정의가 중요한가
- 예: 캐나다 AI 서비스 회사, "가입 안 하는 이유?" → "가입 안 하는 사람"은 너무 모호(전 세계 수억 명). 후보 모집단:
  - **과거 사용자(이탈)** → 유지(retention) 인사이트.
  - **경쟁사 사용자** → 부족한 기능 인사이트.
- 어떤 모집단을 고르느냐가 인사이트를 좌우한다.

### 모집단 정의 프로세스
1. **가설/연구 질문** 으로 시작("왜 우리 AI 서비스에 가입하지 않나?").
2. **핵심 특성 식별**: 나이(전 연령 vs 특정 인구), 지역(글로벌 vs 특정 시장), 기술 사용(이미 다른 AI 쓰는 사람인가).
3. **실용적 제약**: 접근성·예산·시간·윤리로 모집단을 제한할 수 있음.
4. **일반화 가능성(generalizability)**: 결론을 얼마나 넓게? **구체적일수록 정밀하나 일반화↓**, 덜 구체적이면 정밀도↓·일반화↑.
5. **이해관계자 협의**: 정의한 모집단이 비즈니스 목표와 맞는지 확인(구체안을 제시해 검토받도록 마지막에).
- 결과 예: "캐나다의 18~49세 인터넷 사용 성인 중, 최소 하나의 AI 서비스를 쓰지만 우리 것은 안 쓰는 사람" → 표집 방법·해석을 안내.

## 예시

### 모집단 정의 프로세스
| 단계 | 내용 |
|------|------|
| 가설 | 연구 질문 |
| 핵심 특성 | 나이·지역·기술 사용 |
| 실용 제약 | 접근성·예산·시간·윤리 |
| 일반화 | 구체(정밀)↔광범(일반) 트레이드오프 |
| 이해관계자 협의 | 비즈니스 목표 정렬 |

## 요약
- 표본 수집 전 **모집단을 명확히 정의**해야 하며, 어떤 모집단을 고르느냐가 인사이트(유지 vs 기능 격차 등)를 결정한다.
- 프로세스는 **가설 → 핵심 특성 → 실용 제약 → 일반화 가능성 → 이해관계자 협의**다.
- 구체적일수록 정밀하나 일반화가 낮아지는 트레이드오프를 고려한다. 다음 강의는 **확률적 표집(probabilistic samples)** 이다.
