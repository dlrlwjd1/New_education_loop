# Module 1 Introduction

## 개요
- Applied Statistics 코스의 첫 모듈. 엄밀한 분석의 **기초 통계 개념·분석·시각화**를 다룬다.
- **모집단·표본·표집 방법**, **중심경향·변동성·왜도(skewness)**, **상관(correlation)**, **세그멘테이션(segmentation)** 을 배운다.

## 내용

### 이 모듈에서 배우는 것
- **모집단(population)·표본(sample)·표집 방법(sampling methods)** 정의.
- **중심경향(central tendency)·변동성(variability)·왜도(skewness)** 로 데이터셋 특성화.
- **상관(correlation)** 으로 특성 간 관계 이해.
- **세그멘테이션(segmentation)** 으로 그룹별 인사이트 도출.
- 실전: 영화 평점 분석, 가장 수익성 높은 대출 식별, 노래 특성 분석. 스프레드시트 실습(Course 1 기반).

## 요약
- 모듈 1은 **모집단·표본·표집, 중심경향·변동성·왜도, 상관, 세그멘테이션** 등 기초 통계를 다룬다.
- 실세계 사례와 스프레드시트 실습으로 의미 있는 인사이트 추출 기법을 익힌다.
