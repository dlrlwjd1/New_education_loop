# What is Segmentation?

## 개요
- **세그멘테이션(segmentation)** 은 데이터를 의미 있는 **그룹으로 나눠 각각 분석**하는 기법 — 특정 특성/결과를 그룹별로 비교하거나 그룹 특성에 따라 다른 결정을 할 때 유용하다.
- 각 세그먼트에 **동일한 분석**(기술 통계·상관 등)을 적용해 비교하는 것이 핵심.

## 내용

### 개념
- 데이터를 그룹으로 나눠 **일관된 분석**을 각 그룹에 실행. 그래야 세그먼트 간 비교가 가능.
- 흔한 세그먼트: 연령대·지역·습관. 예: 스트리밍이 시청 습관으로 세그먼트해 추천 맞춤, 헬스케어가 위험 요인으로 세그먼트해 개입 결정.

### 예시 — 수술 후 걷기와 회복
- 전체 회복 시간 중앙값 개선 11%. 연령대별 세그먼트: 18~24세 10.3%, 25~40세 11.1%, 45~64세 10.9% → **모든 연령에 유익**. 전체 중앙값만 보면 평균에게 유익하다는 것만 알지 모두에게 그런지는 알 수 없음.
- 의료에서 특히 중요(약·개입이 성별에 다르게 작용, 아동은 다른 용량).

### 특징과 시각화
- **정해진 공식이 없다**(피어슨 r 같은 것 X) — 데이터를 나눠 하위집단을 비교하는 **접근법**.
- 시각화: 막대/열(범주별 분포), 그룹/누적 막대(2단계 세그먼트), 산점도 색상 코딩 or 그리드(세그먼트별), 선 차트(그룹별 여러 선). 명확성·효율성·맥락 원칙 유지.

## 예시

### 세그먼트별 회복 개선(수술 후 걷기)
| 연령대 | 중앙값 개선 |
|--------|-------------|
| 18~24 | 10.3% |
| 25~40 | 11.1% |
| 45~64 | 10.9% |
| 전체 | 11% |

## 요약
- **세그멘테이션**은 데이터를 그룹으로 나눠 **동일한 분석을 적용·비교**하는 접근법이다(정해진 공식 없음).
- 특성/결과를 그룹별로 비교하거나 그룹별 다른 결정을 할 때 유용하며(의료에서 특히), 막대·산점도·선 차트로 시각화한다.
- 다음 강의는 여러 파일 데이터를 다루는 **XLOOKUP** 데모다.
