# Demo: XLOOKUP

## 개요
- 고객 데이터와 제품/대출 데이터는 흔히 **별도 파일**에 저장된다. 세그멘테이션을 위해 이를 병합할 때 **XLOOKUP** 을 쓴다.
- **키(key)** = 다른 테이블에 접근하는 고유 식별자(예: Customer ID)로 두 데이터셋을 조인(join)한다.

## 내용

### 왜 병합하나 (키)
- LendingTree에서 고객 인구통계(소득 등)와 대출 데이터(이자 등)가 별도 저장 — 한 고객이 여러 대출을 가질 수 있어 반복 저장은 비효율적.
- **Customer ID(키)** 로 대출의 고객을 고객 테이블에서 찾으면 유일한 결과. 별도 저장하되 둘 다 접근 가능. 세그멘테이션(소득↔이자 등)을 하려면 병합 필요.

### XLOOKUP
- 수동 복사는 비효율(특히 정렬 안 됐거나 한 고객이 여러 대출일 때). `=XLOOKUP(검색키, 조회범위, 결과범위)`:
  - **검색키(search key)**: 해당 행의 Customer ID.
  - **조회 범위(lookup range)**: 고객 데이터의 Customer ID 열 전체.
  - **결과 범위(result range)**: 반환할 특성 열(예: 직함).
- 예: 첫 고객 → "office administrator" 반환.
- **채우기 핸들** 또는 **ARRAYFORMULA** 로 전체 적용(ARRAYFORMULA는 함수를 셀 범위에 적용 — 첫 셀 참조를 열 전체로 변경). 개별 검색·복사보다 훨씬 빠름.
- 같은 방식으로 employment length 등 다른 특성도 조인.

## 예시

### XLOOKUP + ARRAYFORMULA
```
=XLOOKUP(고객ID, 고객데이터!ID열, 고객데이터!직함열)
=ARRAYFORMULA(XLOOKUP(고객ID 열 전체, 고객데이터!ID열, 고객데이터!직함열))
```

## 요약
- 별도 저장된 데이터셋은 **키(Customer ID)** 로 조인하며, **XLOOKUP(검색키, 조회범위, 결과범위)** 으로 한 테이블의 특성을 다른 테이블에 가져온다.
- **ARRAYFORMULA** 로 전체 열에 한 번에 적용해 효율적으로 병합한다.
- 이로써 소득↔이자 같은 세그멘테이션 분석이 가능해진다. 다음(마지막) 강의는 **피벗 테이블**이다.
