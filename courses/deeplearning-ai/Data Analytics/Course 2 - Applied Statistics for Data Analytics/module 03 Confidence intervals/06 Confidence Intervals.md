# Confidence Intervals

## 개요
- **신뢰 구간(confidence interval)** 은 표본 평균에 **±(오차 한계)** 를 더해 참 모수의 범위를 추정한다.
- 오차 한계는 **표본 변동성·표본 크기·원하는 신뢰 수준** 세 요소로 결정되며, **표준 오차(SE = s/√n)** 로 앞 두 요소를 반영한다.

## 내용

### 예시 — 빵집 배달 시간
- 동물원에 7시 전 배달. 30일 관찰 → **n=30, x̄=43분, s=11분**. "평균 43분"은 점 추정 — 변동성 미반영.

### 왜 구간인가 (CLT 관점)
- 수천 개 표본을 취하면 표본 평균의 **표집 분포**는 CLT에 따라 참 μ 중심 정규 분포.
- 내 표본(43분)은 그중 하나 — 평균보다 길 수도(50%), 짧을 수도(50%).
- **2 시그마 규칙**: 임의 표본 평균이 참 μ의 ±2 표준편차 안에 있을 확률 95%. 하지만 참 μ를 모르므로 신뢰 구간으로 불확실성을 정량화.

### 계산 단계
1. 표본 평균에서 시작: 43분.
2. **표준 오차 SE = s/√n** = 11/√30 ≈ **2분**. (σ를 모르니 s로 대체)
3. **신뢰 수준 결정**: 흔히 95%(오차 5%).
4. **하한 = x̄ − 2·SE**, **상한 = x̄ + 2·SE**. (2 시그마 규칙: 95%가 ±2 SE 안)
   - 하한 = 43 − 2×2 = **39**, 상한 = 43 + 2×2 = **47**.
5. → **95% 신뢰수준으로 참 평균 배달 시간은 39~47분**.

### 의미
- 신뢰 구간 = 모수 추정 범위 + 불확실성 정량화. **넓으면 불확실성↑, 좁으면 정밀도↑**.
- 표본이 얼마나 특이한지 확신할 수 없어도 정보에 근거한 추정 가능.

## 예시

### 95% 신뢰 구간 (배달 시간)
```
SE = s/√n = 11/√30 ≈ 2
하한 = x̄ − 2·SE = 43 − 4 = 39
상한 = x̄ + 2·SE = 43 + 4 = 47
→ 95% CI: [39, 47] 분
```

## 요약
- **신뢰 구간 = x̄ ± (배수 × SE)**, SE = s/√n으로 변동성·표본 크기를 반영한다.
- 95% 신뢰 구간은 2 시그마 규칙에 따라 **x̄ ± 2·SE** 로 구하며, 좁을수록 정밀하다.
- 신뢰 구간 해석은 까다로우므로 다음 강의에서 그 의미를 자세히 다룬다.
