# Understanding Margin of Error

## 개요
- **오차 한계(margin of error) = Z·(s/√n)** 는 신뢰 구간 폭을 결정한다. 좁을수록 정밀한 추정.
- 세 요소로 결정: **신뢰 수준(Z)·변동성(s)·표본 크기(n)**. 앞 둘은 데이터에, 마지막은 내 선택에 달림.

## 내용

### 요소 1 — 신뢰 수준 (Z)
- s=10, n=100 고정 시 s/√n = 10/10 = 1.
- 90%(Z=1.645) → 폭 3.29분 / 95%(Z=1.96) → 3.92분 / 99%(Z=2.576) → 5.152분.
- **높은 신뢰 → 넓은 구간**, 단 폭 증가가 신뢰 증가에 비례하지 않음(정규 분포 꼬리).
  - 95%는 90%보다 ~19% 넓으나 상대 신뢰는 5%만↑. 99%는 95%보다 ~31% 넓으나 4%만↑.

### 요소 2 — 변동성 (s)
- n=100, Z=1.96 고정. s=10 → 폭 3.92분, s=20 → 7.84분, s=30 → 11.76분.
- **s와 오차 한계는 선형 관계** — 변동성 2배면 구간도 2배.
- 함의: 변동성 큰 데이터일수록 덜 정밀. 예: 도시 버스(변동↓)가 교외 버스(변동↑)보다 도착 시간 추정 쉬움(구간 좁음).

### 요소 3 — 표본 크기 (n)
- √n으로 나눠 관계가 복잡. Z=1.96, s=10 고정:
  - n=100 → 폭 3.92분, n=200 → 2.78분, n=300 → 2.62분.
- **큰 표본 → 좁은 구간**(오차 한계↓). 단 **수확 체감**: n 100%↑(100→200)은 폭 29%↓, 추가 100(200→300)은 6%↓.
- 그래프상 대략 **100~200 사이에서 이득이 완만**해짐. 그래서 프랑스 전 국민 여론도 비교적 작은 표본으로 추정 가능.

### 좁은 구간을 얻는 3가지 방법
1. **신뢰 수준 낮추기**(참값 놓칠 위험↑),
2. **변동성 낮은 데이터**(대개 통제 불가),
3. **표본 크기 늘리기**(수확 체감).

## 예시

### 오차 한계 요소별 영향
```
오차 한계 = Z · (s/√n)
신뢰 수준↑ (Z↑) → 폭↑ (비선형, 꼬리)
변동성↑ (s↑)   → 폭↑ (선형)
표본 크기↑ (n↑) → 폭↓ (√n, 수확 체감)
```

## 요약
- **오차 한계 = Z·(s/√n)** 로 신뢰 구간 폭이 결정되며, 신뢰 수준·변동성·표본 크기의 함수다.
- 신뢰 수준↑은 비선형으로, 변동성↑은 선형으로 구간을 넓히고, 표본 크기↑는 수확 체감하며 좁힌다.
- 좁은 구간은 신뢰 수준↓·변동성↓·표본↑으로 얻는다. 다음 강의는 신뢰 구간 직접 계산이다.
