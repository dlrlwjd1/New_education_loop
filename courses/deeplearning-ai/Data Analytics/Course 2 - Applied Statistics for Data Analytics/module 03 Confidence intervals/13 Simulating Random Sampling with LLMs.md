# Simulating Random Sampling with LLMs

## 개요
- 코드를 작성·실행하는 LLM으로 **표집 분포 시뮬레이션 인터페이스**를 만드는 데모(이 모듈의 시뮬레이션들도 Claude로 제작).
- **상세한 프롬프트**와 **반복적(iterative) 오류 수정**이 핵심.

## 내용

### 상세 프롬프트 (모범 사례)
- 길고 구체적인 프롬프트로 정확히 원하는 것을 전달:
  - 0~10 균등 난수 생성기, 버튼 클릭 시 **100개 표본** 생성.
  - 왼쪽 히스토그램에 표본 분포 + 표본 평균 x̄ 표시.
  - 오른쪽 히스토그램에 표본 평균 누적(표집 분포).
  - 새 표본마다 왼쪽은 갱신, 오른쪽은 평균을 **누적**. "100개 표본 한 번에" 버튼도.

### 반복적 오류 수정
- 실행 시 오류 발생 → 오류 메시지를 복사해 "이 오류를 고쳐줘"로 전달. LLM이 원인(빈 배열에서 히스토그램 생성 등)을 추정해 코드 재작성.
- 같은 오류 반복 시 **처음부터 다시 시도** — 모델이 한 사고 패턴에 갇힐 수 있고, 무작위성이 있어 새 시작이 도움. 페이지 새로고침 후 원 프롬프트 재제출.
- 주의: 프롬프트마다 **전체 앱 코드를 재작성** → 새 오류 유입 가능.

### 결과와 미세 조정
- 작동 후: 왼쪽은 대략 균등(x̄≈5.41), 오른쪽은 표본이 쌓일수록 5 중심 정규 분포(CLT).
- 개선 요청 예: 왼쪽을 **열 차트(비닝 없이)**, 오른쪽 x축 범위를 **3~7·작은 bin**으로(참 μ≈5 주변 형태 선명하게), "나머지는 그대로 유지"(새 오류 방지).
- 완벽하진 않음 — 과제의 복잡성 반영. **반복 접근**으로 오류를 고치며 좋은 결과에 도달.

## 예시

### LLM 시뮬레이션 워크플로
```
1) 상세 프롬프트 (분포·표본 크기·시각화 요구사항 명시)
2) 실행 → 오류 시 메시지 복사해 수정 요청
3) 반복 실패 → 새 대화로 처음부터 재시도
4) 미세 조정 ("나머지 그대로 유지"로 새 오류 방지)
```

## 요약
- 코드 실행 가능 LLM은 **상세 프롬프트**로 표집 분포 시뮬레이션 인터페이스를 만들 수 있다.
- **반복적 오류 수정**(메시지 전달·재시도)이 핵심이며, 매 프롬프트가 전체 코드를 재작성해 새 오류 위험이 있다.
- 미세 조정 시 "나머지 그대로"를 명시한다. 다음 강의는 LLM으로 신뢰 구간을 구성·시각화한다.
