# Mechanisms of Confidence Intervals

## 개요
- **95% 신뢰(confidence)** 는 추정 **방법의 신뢰성** — 장기적으로 약 95%의 경우 구간이 참 모수를 포함한다는 뜻. 특정 구간은 참값을 포함하거나 안 하거나 둘 중 하나.
- 모평균 신뢰 구간 공식: **x̄ ± Z·(s/√n)**, Z는 신뢰 수준을 통제하는 표준 정규 z-점수.

## 내용

### 95%의 진짜 의미
- "95% 신뢰로 참 평균 배달 시간 39~47분" → 이 방법이 **장기적으로 약 95% 옳도록** 설계됐다는 뜻.
- 모수는 **고정·미지** — 이 특정 구간에 들어있거나 아니거나.
- 시뮬레이션(참 μ=45, σ=10, n=30): 각 표본이 신뢰 구간 생성. 대부분 참 μ(빨간 선)를 포함, 이따금 미포함(100개 중 약 2개). 표본을 많이 생성하면 **성공률이 95%에 수렴**.
- 즉 표본 기반 신뢰 구간은 반복 시 **95%가 참 평균을 포함** — 진실을 직접 보진 못하나 강력한 추정.

### 공식
- **CI = x̄ ± Z·(s/√n)**.
  - x̄·s = 표본 통계, n = 표본 크기.
  - **Z** = 표준 정규 z-점수(신뢰 수준 통제).
- 앞 강의의 "2 시그마"는 근사 — 정확한 95% z-점수는 **1.96**(2σ는 95%보다 약간 높은 신뢰에 해당).
- 95% CI = **x̄ ± 1.96·(s/√n)**. 오른쪽 항 = **오차 한계(margin of error)** — 추정 정밀도 척도.

### 신뢰 수준별 z-점수
| 신뢰 수준 | z-점수 | 특징 |
|-----------|--------|------|
| 90% | 1.645 | 예비 연구·오류 덜 중요 (예: 신기능 7.2/10) |
| 95% | 1.96 | 가장 흔함(확신·오류 균형, 예: 배달 39~47분) |
| 99% | 2.576 | 오류 최소화(예: 강 오염 규제 검사) |

- 높은 신뢰 수준 → 큰 z-점수 → **더 넓은 구간**. 확신을 높이려면 범위를 넓혀야 함.
- 95%가 확신과 오류 가능성의 균형으로 가장 흔함. 단 99%도 오류 가능성은 있음.

## 예시

### 95% 신뢰 구간 공식
```
CI = x̄ ± Z · (s/√n)
95%: x̄ ± 1.96 · (s/√n)
오차 한계 = 1.96 · (s/√n)
z: 90%→1.645,  95%→1.96,  99%→2.576
```

## 요약
- **95% 신뢰**는 방법이 장기적으로 95% 참값을 포함한다는 의미이며, 모수는 고정·미지다.
- 공식 **x̄ ± Z·(s/√n)** 에서 정확한 95% z-점수는 **1.96**, 오른쪽 항이 **오차 한계**다.
- 신뢰 수준이 높을수록(z↑) 구간이 넓어진다. 다음 강의는 표본 크기·신뢰 수준의 상호작용(오차 한계)이다.
