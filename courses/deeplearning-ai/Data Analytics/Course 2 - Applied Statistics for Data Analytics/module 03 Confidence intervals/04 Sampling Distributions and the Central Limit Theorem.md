# Sampling Distributions & the Central Limit Theorem

## 개요
- **표집 분포(sampling distribution)** 는 표본 통계(예: x̄)가 가질 수 있는 값의 범위와 각 값의 확률이다.
- **중심 극한 정리(central limit theorem, CLT)**: 어떤 분포에서든 충분히 큰(n>30) 표본의 평균을 모으면 그 **표본 평균들이 정규 분포**를 이룬다.

## 내용

### 표집 분포란
- 표본 통계도 분포를 가짐. 예: 자격 시험 점수(0~100) 평균 추정 — 50명 표본 평균이 76.76, 다른 표본은 80.40, 또 80.02… 매번 다름.
- 2,000+ 표본(각 50명)의 평균을 히스토그램으로 그리면 **정규 분포** 형태. 참 μ ≈ 77.2 부근.
- **표집 분포** = 표본 평균 x̄의 가능한 값 범위와 확률. 참 μ에 가까운 값이 더 흔하고 멀수록 드물다.

### 중심 극한 정리 (CLT)
- 임의 분포에서 충분히 큰 표본(**n > 30**)의 평균들 → **정규 분포**.
- 그 분포의 평균 = **모집단 평균 μ**(표본 평균의 중심 경향이 μ 부근).
- 주의(혼동 지점): **표본 개수** ≠ **각 표본의 크기 n**. 크기 n 표본을 여러 번 취해 각 평균을 히스토그램에 그림.

### 표준 오차 (standard error)
- 표본 크기 증가 → 추정이 더 정밀. 양궁처럼 중심은 그대로, 화살이 더 촘촘히 모임.
- **표준 오차(SE, standard error of the mean) = σ / √n**.
- n 증가 시 √n도 증가(느리게). 작은 n에선 몇 개 추가로 정밀도 크게↑, 큰 n에선 **수확 체감(diminishing returns)**.

### 적용 범위
- CLT는 **표본 비율 p̂**, 때로 표본 분산·표준편차에도 적용.
- **모집단이 정규가 아니어도**(예: 강수량, 균등 분포) 표본이 충분히 크면 표본 평균은 정규 분포.
  - 균등 분포(0~10, μ=5) 시뮬레이션: 개별 표본은 균등해 보여도 1,000개 표본 평균은 5 중심 정규 분포.

## 예시

### 표준 오차와 정밀도
```
표준 오차 SE = σ / √n
n↑ → SE↓ (추정 정밀↑),  단 √n이라 수확 체감
CLT: 임의 분포, n>30 → 표본 평균 ~ Normal(μ, σ/√n)
```

## 요약
- **표집 분포**는 표본 통계의 값 범위·확률이며, 참 모수 근처 값이 가장 흔하다.
- **CLT**: 임의 분포라도 n>30 표본의 평균은 μ 중심 정규 분포를 이루며, **표준 오차 = σ/√n**(n↑ 시 정밀↑, 수확 체감).
- 모집단 분포를 몰라도 구간으로 모수를 추정할 수 있다 — 다음 강의부터 신뢰 구간을 만든다.
