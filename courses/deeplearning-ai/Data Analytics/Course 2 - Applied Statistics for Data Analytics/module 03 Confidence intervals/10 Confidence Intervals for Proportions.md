# Confidence Intervals for Proportions

## 개요
- 평균뿐 아니라 **모집단 비율(proportion, p)** 도 신뢰 구간으로 추정한다. 표본 비율 **p̂** 가 p의 추정치.
- 공식: **p̂ ± Z·√[p̂(1−p̂)/n]** — 오른쪽 항이 **오차 한계(margin of error)**.

## 내용

### 비율 추정 예시 — 정시 배달
- 평균 배달 시간 외에 **정시 배달 비율**(7시 전 도착)에 관심. 참 비율 = **p**.
- 30건 표본 중 18건 정시 → **p̂ = 0.6**(p 추정치, "hat"=추정).
- p̂의 표집 분포도 정규 분포, 평균 = 참 p. p̂=0.6은 그 분포 안 한 점. 2 시그마 규칙: p̂가 p의 ±2 표준편차 안일 확률 95%.

### 비율의 표준 오차 (standard error)
- **SE = √[p(1−p)/n]**. p를 모르니 **p̂** 로 대체.
- **p(1−p)** = 변동성. p̂가 **0.5에 가까울수록 변동성↑**.
  - 9정시·1지연: p̂=0.9 → p̂(1−p̂)=0.09 (낮은 변동성).
  - 6정시·4지연: p̂=0.6 → p̂(1−p̂)=0.24 (높은 변동성, 성공·실패 고른 혼합).
- **/n**: 큰 표본 → 정밀↑. **√**: 데이터 원 척도에 맞춤.

### 신뢰 구간 구성
- **CI = p̂ ± Z·√[p̂(1−p̂)/n]**. 오른쪽 항 = 오차 한계(불확실성).
- 예(95%): p̂=0.6, 1−p̂=0.4, Z=1.96, n=30 → **[0.4247, 0.7753]**.
- 해석: "95% 신뢰로 참 정시 비율은 42.47~77.53% 사이." 구간이 넓은 이유 = 높은 변동성 + 작은 표본. 비율은 대개 **더 큰 표본**이 필요.

## 예시

### 95% 비율 신뢰 구간 (정시 배달)
```
CI = p̂ ± Z·√[p̂(1−p̂)/n]
p̂=0.6, n=30, Z=1.96
SE = √(0.6·0.4/30) ≈ 0.0894
오차 한계 = 1.96·0.0894 ≈ 0.175
→ [0.4247, 0.7753]
```

## 요약
- **비율 신뢰 구간 = p̂ ± Z·√[p̂(1−p̂)/n]**, 표준 오차는 √[p̂(1−p̂)/n]다.
- 변동성 p̂(1−p̂)는 **p̂=0.5에서 최대**이며, 작은 표본은 넓은 구간을 낳아 비율 추정엔 큰 표본이 유리하다.
- 이제 평균·비율 모두 신뢰 구간을 계산할 수 있다. 다음 강의는 스프레드시트 실습이다.
