# Demo: Confidence Intervals in Action

## 개요
- 신뢰 구간의 최종 목표를 미리 보는 데모 — 30일 공부 시간 표본으로 장기 평균의 **신뢰 구간(confidence interval)** 을 구성한다.
- 흐름: 점 추정 → **오차 한계(margin of error)** 계산 → 하한·상한 → 95% 신뢰 구간.

## 내용

### 예시 — 공부 습관
- 30일간 매일 공부 시간 기록: **n=30, 표본 평균 x̄=2.5시간, 표본 표준편차 s=0.6시간**.
- "평균 2.5시간"은 **점 추정** — 정밀도나 변동 정보 없음. 참 장기 평균의 범위를 알려면 **신뢰 구간** 구성.

### 구성 단계 (큰 그림)
1. **오차 한계(margin of error)** 계산 — 표본 표준편차·표본 크기, 그리고 **약 2에 가까운 수**(이후 강의에서 상세). 이 값이 추정 구간의 **불확실성**을 나타냄: 작을수록 확신↑, 클수록 불확실↑.
2. **하한 = x̄ − 오차 한계**, **상한 = x̄ + 오차 한계**. 오차 한계 = 점 추정 양쪽으로 추정하는 오차.
3. 결과: **95% 신뢰 구간 = 2.29 ~ 2.71시간**.

### 해석
- "평균 공부 시간은 95% 신뢰수준으로 2.29~2.71시간 사이."
- 실험을 아주 여러 번 반복하면 **약 95%의 경우 구한 구간이 참 평균을 포함**한다.
- 30일 표본만으로 지난 수년 평균의 그럴듯한 범위를 만들 수 있음.

## 예시

### 95% 신뢰 구간 구성 (공부 시간)
```
n=30, x̄=2.5, s=0.6
오차 한계 ≈ 2 × (s/√n) 형태
하한 = 2.5 − 오차 한계 = 2.29
상한 = 2.5 + 오차 한계 = 2.71
→ 95% CI: [2.29, 2.71] 시간
```

## 요약
- **신뢰 구간**은 점 추정에 **오차 한계**를 ± 하여 참 모수의 그럴듯한 범위를 제공한다.
- 오차 한계가 작을수록 확신이 크며, 95% CI는 "반복 시 약 95%가 참값을 포함"으로 해석한다.
- 다음 강의부터 신뢰 구간을 직접 계산하는 법을 배운다.
