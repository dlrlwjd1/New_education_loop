# Inference and Visualization with LLMs

## 개요
- 코드 실행 가능 LLM으로 신뢰 구간을 **직접 계산·시각화**하는 데모 — "calculate"는 LLM이 코드를 작성·실행해 수학을 수행함을 뜻한다.
- 결과는 항상 실행된 코드를 확인해 **검증**해야 한다.

## 내용

### 신뢰 구간 계산
- 예: 앱 다운로드 517회, 평점 89개, 그중 5성 75개 → "5성 줄 사용자의 참 비율에 대한 95% 신뢰 구간 계산·해석."
- 표본(평점 89개)으로 전체 사용자 추론. **calculate** = 코드 작성·실행 필요.
  - 일반 LLM(예: MOOC 랩)은 단계만 써주고 직접 계산해야 함 → 이럴 땐 계산을 시키지 말 것.
  - ChatGPT-4o(고급 데이터 분석)는 실제로 계산 수행.
- 결과: 95% CI ≈ **0.767 ~ 0.918** → "5성 줄 참 비율이 76.7~91.8% 사이라 95% 신뢰."
- **코드 실행 확인**: 코드 기호 클릭 → p̂=75/89, 신뢰 95%, z=1.96, SE·오차 한계·하한·상한 계산(스프레드시트와 동일 단계) 검증.

### 시각화
- "0~1 비율 축에 이 신뢰 구간을 시각화" 요청 → 파란 점 = p̂(구간 중심), 양쪽 ±오차 한계를 빨간 선으로. 어느 쪽이든 높은 비율(80% 아래일 수도, 90% 위일 수도).

### 신뢰 수준 비교
- 후속: "99%로 바꾸면 결과·해석이 어떻게 변하나? 같은 그래프에 시각화" → 99% 구간이 95%보다 **더 넓음**(높은 신뢰 = 넓은 범위).
- 두 구간의 **중심(p̂)은 동일**, 차이는 **오차 한계 폭**뿐.

## 예시

### LLM 신뢰 구간 계산 (5성 비율)
```
입력: 평점 89개 중 5성 75개
p̂ = 75/89, z = 1.96 (95%)
LLM이 코드로: SE, 오차 한계, 하한·상한 계산
→ 95% CI ≈ [0.767, 0.918]
99% CI → 더 넓음 (중심 동일, 오차 한계만 확대)
```

## 요약
- 코드 실행 가능 LLM은 신뢰 구간을 **직접 계산·시각화**하며(일반 LLM엔 계산 시키지 말 것), 실행된 코드를 열어 **매 단계 검증**해야 한다.
- 시각화로 구간을 직관적으로 보고, 신뢰 수준을 높이면 중심은 그대로·오차 한계만 넓어진다.
- 이로써 모듈 3(신뢰 구간)을 마치며, 다음 모듈은 **가설 검정(hypothesis testing)** 이다.
