# Demo: Confidence Intervals for Proportions

## 개요
- 스프레드시트로 **비율의 신뢰 구간**을 계산하는 데모 — 산불 데이터에서 "작은 화재(small)" 비율 추정.
- 단계는 평균과 유사하나 표준 오차 공식이 **√[p̂(1−p̂)/n]** 로 바뀐다.

## 내용

### 배경
- 공원청은 작은 화재엔 소규모 인력·수공구를 배정(비용 효율). "작은 화재 비율" 추정 필요 → `is_small` 열(0/1) 사용.
- 차트로 보니 작음/큼이 대략 균등 → p̂가 0.5 근처라 **변동성 높음** 예상.

### 계산 단계
1. **p̂**: `is_small` 열이 0/1이므로 **AVERAGE** 로 비율 계산 → ≈ **0.48**.
2. **1−p̂**: 여사건 → ≈ **0.52**.
3. **n**: **COUNT** 로 표본 크기.
4. 신뢰 수준 95% → **z = 1.96**.
5. **오차 한계 = z·√[p̂(1−p̂)/n]** (√ 안에 p̂·(1−p̂)/n).
6. 하한 = p̂ − 오차 한계, 상한 = p̂ + 오차 한계 → **[0.4347, 0.5208]**.
- 해석: "95% 신뢰로 참 작은 화재 비율은 43.47~52.08%."

### 의사결정 함의
- 0.5(절반)가 구간에 포함 → 참값으로 타당. 작은 화재가 상당량이라 소규모 자원 활용 가능.
- 계획을 p̂≈47.8%로 세웠는데 참값이 하한(≈43.4%)에 가까우면 **작지 않은 화재를 과소평가**해 자원 부족 위험 → 구간이 대비를 돕는다.

## 예시

### 비율 신뢰 구간 스프레드시트
```
p̂ = AVERAGE(is_small)  ≈ 0.48
1−p̂ ≈ 0.52,  n = COUNT(...)
오차 한계 = 1.96 · SQRT(p̂·(1−p̂)/n)
하한 = p̂ − 오차 한계,  상한 = p̂ + 오차 한계
→ [0.4347, 0.5208]
```

## 요약
- 비율 신뢰 구간은 **p̂ = AVERAGE(0/1 열)**, **오차 한계 = z·√[p̂(1−p̂)/n]** 로 계산한다.
- 원리는 평균과 같으나 표준 오차 공식만 다르며, p̂이 0.5 근처면 변동성이 커 구간이 넓다.
- 구간은 자원 배분 결정을 돕는다. 다음 레슨은 **LLM을 신뢰 구간에 적용**하는 것이다.
