# Module 3 Introduction

## 개요
- **신뢰 구간(confidence intervals)** 모듈 소개 — 표본으로 모집단에 대한 결론을 이끄는 두 강력한 기법 중 첫 번째.
- 목적: 많은 비즈니스 질문에 내재한 **불확실성(uncertainty)** 을 관리하는 것.

## 내용

### 이 모듈에서 배우는 것
- **추론 통계(inferential statistics)** 정의 및 기술 통계(descriptive statistics)와의 차이.
- **신뢰 구간 구성** — 평균·비율 같은 모수를 **확실성의 척도와 함께** 추정.
- 신뢰 구간 **해석**(까다로움) 및 추정의 **정밀도(precision)** 를 조절하는 여러 레버 관리.
- **LLM 활용** — 결과 해석, 시뮬레이션 인터페이스 생성, 신뢰 구간 계산·시각화 지원.

### 실습
- 다이아몬드 가격 책정을 탐구하는 랩으로 마무리.

## 요약
- 이 모듈에서는 표본으로부터 모집단을 추론하는 첫 기법인 **신뢰 구간**을 배운다.
- **추론 통계 정의 → 신뢰 구간 구성·해석 → 정밀도 관리 → LLM 활용**의 순으로 진행한다.
- 다음 강의는 **추론 통계(inferential statistics)** 다.
