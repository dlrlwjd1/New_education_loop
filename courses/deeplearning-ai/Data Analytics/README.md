# Data Analytics (전문 과정 / Specialization)

**Course URL:** https://learn.deeplearning.ai/specializations/data-analytics
**제공:** DeepLearning.AI
**강사:** (DeepLearning.AI Data Analytics 팀)

## 개요
데이터 애널리스트가 되기 위한 5개 코스로 구성된 전문 과정(specialization). 데이터 애널리틱스의 기초, 스프레드시트·통계·Python·SQL을 활용한 데이터 처리, 그리고 데이터 스토리텔링까지 데이터 분석 전 과정을 다룬다. 생성형 AI(LLM) 활용이 전 코스에 통합되어 있다.

## 코스 구성
1. **[Course 1 — Data Analytics Foundations](Course%201%20-%20Data%20Analytics%20Foundations/README.md)** — 데이터 애널리틱스 기초, 스프레드시트, 시각화, 분석 라이프사이클
2. **[Course 2 — Applied Statistics for Data Analytics](Course%202%20-%20Applied%20Statistics%20for%20Data%20Analytics/README.md)** — 데이터 분석을 위한 응용 통계
3. **[Course 3 — Python for Data Analytics](Course%203%20-%20Python%20for%20Data%20Analytics/README.md)** — 데이터 분석을 위한 파이썬
4. **[Course 4 — Data I/O and Preprocessing with Python and SQL](Course%204%20-%20Data%20IO%20and%20Preprocessing%20with%20Python%20and%20SQL/README.md)** — Python·SQL로 데이터 입출력·전처리
5. **[Course 5 — Data Storytelling](Course%205%20-%20Data%20Storytelling/README.md)** — 데이터 스토리텔링

> 각 코스는 폴더로 분리되며, 모듈별 하위 폴더에 영상 강의 정리본(`NN 주제.md`)이 들어간다. Quiz·Lab·Reading·Resources·Lecture Notes는 노트 대상에서 제외한다.
