# Module 1 Introduction

## 개요
- **Module 1 — 웹 스크래핑과 텍스트 처리(Web Scraping and Text Processing)** 소개.
- 실제 웹사이트에서 데이터를 수집·분석 준비하는 기초 도구를 다룬다.

## 내용

### 레슨 구성
- **Lesson 1**: 다양한 데이터 출처, 수집 방법별 비즈니스 요구, **전처리(preprocessing)** 의 역할(정리·조직).
- **Lesson 2**: 웹에서 **구조화된 데이터 스크래핑**, 타입 캐스팅, 텍스트 처리(**contains·replace·split·strip**).
- **Lesson 3**: **Beautiful Soup** 으로 고급 스크래핑, HTML 구조 이해·변환.

## 요약
- 이 모듈은 웹에서 데이터를 **수집·처리**하는 기초를 배운다.
- Lesson 1(출처·전처리) → Lesson 2(스크래핑·텍스트 처리) → Lesson 3(Beautiful Soup·HTML) 순으로 진행한다.
- 다음 강의부터 시작한다.
