# Introduction to Web Scraping

## 개요
- **웹 스크래핑(web scraping)** 은 코드로 웹사이트에서 데이터를 추출하는 것 — 다른 출처가 없을 때 유용하다.
- 사람용으로 설계된 정보(비정형)를 분석용 구조화 데이터(행·열)로 변환한다.

## 내용

### 개념
- 예: 경쟁 반려동물 쇼핑몰 가격 조사 — 다운로드 불가, 수동 복사는 느리고 오류. **코드로 자동 수집**.
- 웹사이트를 평면으로 보고 표면의 콘텐츠를 "긁어(scrape)" 처리·분석.
- 웹페이지는 메뉴·이미지 등 시각적 요소가 많아 데이터프레임과 정반대. 스크래핑은 **비정형 텍스트·코드 문서**를 모아 필요한 데이터만 추출.

### 예시
- 제품 페이지에서 이름·가격·설명 추출. **페이지 소스(view page source)** 에 방대한 코드 — 그중 가격을 파싱. Python으로 훨씬 수월.
- **재사용 가능**: 같은 형식 페이지(제품 페이지들)면 하나의 스크래퍼로 여러 사이트 처리(사이트 목록 + 동일 코드).

### 도전 과제
- **비정형 사이트**: 데이터 위치 찾기 어려움. 세일 상품은 가격 위치가 달라 **결측** 유발 가능.
- **동적 콘텐츠(dynamic content)**: 레이아웃·콘텐츠 변경 시 스크래퍼 고장 → **유지보수** 필요.
- 단 **구조 일정 + 콘텐츠 동적**이면 스크래퍼가 빛남(제품 페이지 형식 일정 → 하나로 모든 가격).

## 요약
- **웹 스크래핑**은 코드로 웹사이트 비정형 정보를 구조화 데이터로 변환하며, 다른 출처가 없을 때 쓴다.
- 같은 형식 페이지엔 스크래퍼를 재사용하나, 비정형·동적 콘텐츠는 결측·고장을 유발해 유지보수가 필요하다.
- 다음 강의는 Python으로 표(table) 데이터를 스크래핑한다.
