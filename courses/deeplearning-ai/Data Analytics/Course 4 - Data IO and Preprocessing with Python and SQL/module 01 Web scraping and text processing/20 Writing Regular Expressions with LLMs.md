# Writing Regular Expressions with LLMs

## 개요
- 정규 표현식 작성은 번거로우므로 **LLM과 함께** 패턴을 작성한다.
- **구체적인 프롬프트**(형식·빈도·적용 방법·저장 위치)가 핵심이다.

## 내용

### 구체적 프롬프트
- 예: "HH:MM 또는 H:MM 형식의 시간을 매칭하는 regex를 작성. 주변 공백·문자 허용. 문자열 내 **첫 인스턴스만** 매칭. **df['description']** 열에 벡터화 적용해 새 열 **df['time']** 에 저장. **.str.extract** 에 맞게 포맷."
- LLM에 필요한 정보를 모두 제공.

### 검증
- 결과 확인: index 0(시간 없음)·index 1(시간 있음, 예 "2:50"). 손으로 짜기 어려운 패턴을 LLM이 처리.
- **항상 출력을 기대와 대조**하고, 틀리면 반복.

## 예시

### LLM으로 정규식 작성
```python
# LLM 프롬프트에 형식·빈도·적용 열·저장 열·.str.extract 호환 명시
df["time"] = df["description"].str.extract(r"(\d{1,2}:\d{2})")
```

## 요약
- 정규 표현식은 **구체적 프롬프트**로 LLM에게 작성을 맡길 수 있다(형식·빈도·적용·저장 명시).
- LLM 출력을 **기대와 대조·검증**하고 필요 시 반복한다.
- 다음(마지막) 강의는 **웹 스크래핑의 윤리**다.
