# HTML

## 개요
- **HTML(Hypertext Markup Language)** 은 태그로 웹페이지를 구조화한다. 태그+내용 = **요소(element)**.
- HTML은 요소가 요소를 담는 **트리(tree) 구조**이며, 이 구조를 알아야 스크래핑할 수 있다.

## 내용

### 태그와 요소
- **태그(tag)**: 여는·닫는(예 `<h1>`…`</h1>`, 닫는 태그엔 `/`). 태그+내용 = **요소**.
- 흔한 요소: **h1~h6**(제목), **p**(문단), **a**(anchor, 링크). 이미지 **img** 는 **자기 종료(self-closing)** 태그.

### 속성 (attributes)
- 여는 태그 안에 부가 정보. 예: **href**(a 태그의 링크 URL), img의 **src**(소스)·**alt**(대체 텍스트)·width·height.
- **class**: 요소를 묶는 특수 속성 — 일관된 스타일 적용, 여러 요소에 부여. 예: 날짜를 모두 "date-text" 클래스로 → **클래스 하나로 모든 날짜 스크래핑** 가능.

### 트리 구조
- 요소가 다른 요소를 포함(문단 안에 여러 링크). 루트는 **html 태그**. 원하는 요소를 찾으려면 트리 내 위치를 알아야 함.
- **컨테이너 요소**: **div**(division, 유연한 상자, 새 줄·전체 너비), **ul/ol**(목록)+**li**(항목), **span**(작은 텍스트, 새 줄 안 함).
- **table**(tr=행, td=데이터)도 컨테이너 — `pd.read_html`은 **table 요소에만** 작동(정보가 잘 정리돼도 table 없으면 오류).

## 요약
- **HTML**은 **태그·요소·속성(href·src·class 등)** 으로 페이지를 구성하는 **트리 구조**다.
- **class** 로 요소를 묶으면 스크래핑이 쉬워지고, **div·span·ul/ol·table** 등 컨테이너가 콘텐츠를 조직한다.
- `pd.read_html`은 table 요소에만 작동한다. 다음 강의는 **Beautiful Soup으로 HTML 파싱**이다.
