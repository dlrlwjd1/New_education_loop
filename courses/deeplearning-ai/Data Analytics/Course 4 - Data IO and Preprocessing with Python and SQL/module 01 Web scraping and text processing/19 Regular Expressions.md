# Regular Expressions

## 개요
- **정규 표현식(regular expressions, regex)** 은 검색 패턴을 정의하는 문자 시퀀스 — 유연한 텍스트 매칭에 쓴다.
- 날짜·전화번호·시간 등 **구조화된 텍스트 형식** 추출에 유용.

## 내용

### 구성 — 패턴 + 빈도
- **텍스트 패턴**:
  - 특정 문자("12", "happy").
  - **문자 클래스**: `0-9`(숫자), `A-Z`(대문자), `a-z`(소문자), 조합 가능.
  - **특수 시퀀스**: `\d`(숫자), `\s`(공백).
  - 예: `\d[A-Za-z]` = 숫자+글자(9a, 7q).
- **빈도**:
  - `{n}`: 반복 횟수. 예 `\d{2}:\d{2}` = 두 숫자:두 숫자(시:분).
  - `+`: 1개 이상. `*`: 0개 이상. 예 `\d+`(숫자 나열), `\d{3}\s*\d{4}`(3자리+공백 0개+4자리).

### pandas와 함께
- **str.contains·str.replace** 에 정규식 사용 가능. **str.extract** 는 **매치된 텍스트를 반환**(contains는 존재 여부만).
- 예: 전화번호 추출 `\d{3}-\d{3}-\d{4}`. Python에선 **raw string(r"...")** 로 작성(백슬래시 리터럴 처리).
- `df["message"].str.extract(r"(\d{3}-\d{3}-\d{4})")` — 첫 매치 반환.

## 예시

### 정규 표현식
```python
# 시간 (HH:MM)
r"\d{2}:\d{2}"
# 전화번호
df["message"].str.extract(r"(\d{3}-\d{3}-\d{4})")
# \d 숫자, \s 공백, + 1개 이상, * 0개 이상, {n} n회
```

## 요약
- **정규 표현식**은 **패턴(\d·[A-Z] 등) + 빈도({n}·+·*)** 로 유연한 텍스트를 매칭한다.
- pandas **str.contains·replace·extract**(매치 텍스트 반환)와 함께 쓰며, **raw string(r"...")** 로 작성한다.
- 패턴 작성은 번거로우니 다음 강의는 **LLM으로 정규 표현식 작성**을 다룬다.
