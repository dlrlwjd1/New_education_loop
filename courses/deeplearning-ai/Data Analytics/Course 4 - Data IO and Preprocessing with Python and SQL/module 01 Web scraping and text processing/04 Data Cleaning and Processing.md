# Data Cleaning and Processing

## 개요
- 수집한 데이터는 바로 분석 불가 — **전처리(preprocessing)** 로 원시 데이터를 분석 가능한 형태로 만든다.
- **데이터 정리(data cleaning)** 는 전처리의 한 부분(오류·불일치·중복 수정).

## 내용

### 왜 전처리인가 (Ask a Manager 예)
- 급여 열: 콤마 유무, 달러 기호·공백 등 **형식 불일치**(일부는 텍스트로 취급) → 평균 계산도 어려움.
- 위치 열: 미국·영국 도시, 일반 지역 등 **일관성 없는 텍스트** → 단순한 질문도 어려움.

### 전처리 단계
- 항상 **원시 데이터(raw data)** 에서 시작 → 분석에 적합하게 변환.
- 흔한 단계: **중복 제거, 결측 처리, 이상치 처리, 형식 통일, 특성 부분집합 선택, 공통 범위 스케일링, 범주형 인코딩**.
- 광범위한 용어 — 변환하거나 관련 데이터만 선택. **비즈니스 문제에 따라** 달라짐.
  - 예: 웹사이트용 추천글 → 영어 필터·개인정보 제거·긍정 감정만. 해시태그 순위 → 이미지·영상 제거·해시태그 추출·상위 5개.

### 전처리 vs 정리
- **전처리(preprocessing)**: 원시 데이터를 분석 준비하는 **모든** 단계(필터·변환·조직 + 정리).
- **정리(cleaning)**: 전처리의 **부분집합** — 오류·불일치 수정·중복 제거(예: 제품명 오타 수정).

### 검증
- 전처리 후 **검증(validation)** — 데이터가 기대와 맞는지, 새 문제가 없는지(제품명 표준화? 결측 처리? 매장별 판매 수 타당?). 확인 후 분석.

## 요약
- **전처리**는 원시 데이터를 분석 가능하게 만드는 모든 단계(중복·결측·이상치·형식·스케일·인코딩)이며 비즈니스 문제에 따라 다르다.
- **데이터 정리**는 전처리의 부분집합(오류·불일치·중복 수정)이다.
- 전처리 후 **검증**으로 문제를 확인한 뒤 분석한다. 다음 강의는 전처리 시점(ETL·ELT)이다.
