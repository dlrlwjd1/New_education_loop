# The Many Sources of Data

## 개요
- 데이터는 다양한 출처에서 온다: **플랫 파일(CSV)·데이터베이스·API·웹 스크래핑**.
- 데이터 성격(생성/실시간 수집/과거)과 규모·복잡성에 따라 적합한 출처가 다르다.

## 내용

### 데이터 유형별 출처
- **생성 데이터**(예: 판매 기록) — 계속 갱신되므로 **데이터베이스**.
- **실시간 수집**(경쟁사 가격·날씨) — **웹 스크래핑** 또는 **API**.
- **과거 데이터**(작년 거래) — 갱신 안 되므로 **플랫 파일(CSV)**(행·열 단일 테이블).

### 출처별 특징
- **플랫 파일(CSV)**: 작고 정적인 구조화 데이터에 적합(간편·빠름). 규모·복잡성↑ 시 느리고, 여러 테이블 관계·비정형·접근 관리 어려움.
- **데이터베이스**: 관계로 연결된 여러 플랫 파일(속도·저장 최적화). 예: 고객·구매 테이블 + 관계. 대기업은 내부 DB 보유.
- **API**: 회사 서버를 통해 데이터 직접 요청(예: 리뷰 사이트). **실시간·고품질·최신** 데이터.
- **웹 스크래핑**: 플랫 파일·DB·API로 제공 안 될 때(경쟁사 가격 등). 코드로 웹 방문 → 필요 부분 식별 → 구조화 저장.

### 공통점
- 모든 출처 데이터를 Python 노트북(pandas DataFrame)에 불러와 처리·분석. 출처에 따라 **전처리 수준**이 다름.

## 요약
- 데이터 출처는 **플랫 파일·데이터베이스·API·웹 스크래핑** 이며, 데이터 성격·규모에 따라 선택한다.
- CSV는 소규모 정적, DB는 관계형 대규모, API는 실시간 최신, 스크래핑은 제공되지 않는 데이터에 쓴다.
- 모두 DataFrame으로 불러오며 출처별 전처리가 필요하다. 다음 강의는 데이터 정리·처리다.
