# Planning HTML Parsing

## 개요
- 파싱 전에 **HTML 구조를 살펴 계획**을 세운다 — 어디에 어떤 데이터가 있는지 파악.
- **Inspect(검사)** 와 **View Source(페이지 소스)** 로 요소·클래스를 확인한다.

## 내용

### 구조 파악
- **우클릭 → Inspect**: 요소에 마우스 오버 시 웹페이지의 해당 부분 강조. **우클릭 → View Source**(Ctrl+F로 검색).
- 예(천문 이벤트): 세 번째 **div** 안에 **ul**(목록) → 각 이벤트가 **li** 안 **p** 안에:
  - **span class="date-text"**(날짜), **span class="title-text"**(제목), 그리고 컨테이너 없는 **설명**.

### 계획 (코드 주석)
1. 이벤트 저장할 **빈 리스트** 생성.
2. 클래스가 있는 모든 **li 요소** 찾기(li엔 B9 등 클래스 존재).
3. 각 li를 **루프**.
4. class="date-text" span → 변수.
5. class="title-text" span.
6. p 태그.
7. 각 요소에서 **텍스트만** 추출(HTML 태그·속성 버림).
8. [날짜, 제목, 설명] 리스트를 이벤트 리스트에 추가.
- 모든 이벤트가 같은 패턴이므로 반복 가능. **사전 계획이 복잡한 전처리에 필수**.

## 요약
- 파싱 전 **Inspect·View Source** 로 HTML 구조(요소·클래스)를 파악해 계획을 세운다.
- 반복 패턴(li마다 date-text·title-text span + p)을 찾아 루프로 추출하는 계획을 코드 주석으로 정리한다.
- 다음 강의는 **Beautiful Soup으로 계획을 구현**한다.
