# Welcome to Course 4

## 개요
- **Data I/O and Preprocessing with Python and SQL** — 데이터 애널리틱스 전문 과정의 네 번째 코스. **웹 스크래핑·API**로 데이터를 수집하고, 분석에 맞게 **전처리(preprocessing)** 한다.
- 지금까지는 깨끗한 데이터를 받았지만, 실무 애널리스트는 스스로 데이터를 수집·처리해야 한다.

## 내용

### 왜 전처리인가
- 저품질 데이터는 미국에서만 연 약 3조 달러 손실(추정) → 데이터 수집·전처리로 큰 가치 창출 기회.
- **"애널리스트 업무의 80%가 전처리"** — 화려하진 않으나 모든 인사이트의 기반.
- 흔한 작업: **중복 제거, 이상치 처리, 정규화(공통 척도)**.

### 코스 내용
- **웹 스크래핑**(Python으로 웹사이트에서 수집).
- **API**(프로그램 간 통신 웹 서비스)로 수집, 텍스트·수치 처리.
- 마지막 두 모듈: **데이터베이스 기초·SQL**(필터·그룹·조인).
- 실제 데이터: 음악 트랙·Lego·식품 안전 검사·테크 잡 등. **LLM**으로 계획·SQL/Python 코딩 지원(단 도메인 특수 맥락은 LLM이 약할 수 있음).

### AI와 데이터 분석
- AI 도구에 능숙한 애널리스트는 2배 이상 임팩트 가능. 단 문제 맥락·출력 설계는 여전히 사람 몫.

## 요약
- 이 코스는 **웹 스크래핑·API로 데이터 수집** + **전처리**(중복·이상치·정규화)를 다룬다.
- 후반부는 **데이터베이스·SQL**(필터·그룹·조인)을 배운다.
- 전처리는 분석 업무의 80%를 차지하는 핵심 기반이며, LLM을 코딩·계획에 활용한다.
