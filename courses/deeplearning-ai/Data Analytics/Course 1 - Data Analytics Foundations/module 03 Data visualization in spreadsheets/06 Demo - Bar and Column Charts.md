# Demo: Bar & Column Charts

## 개요
- Redfin 주택 판매 데이터로 Google Sheets에서 **막대(bar)/열(column) 차트**를 만드는 데모. 막대/열 차트는 가장 흔하고 다재다능하며 그룹 비교에 좋다.
- 데이터 탐색(조건부 서식·필터·요약) 후, 상위 카운티의 판매가·시장 체류일을 시각화한다.

## 내용

### 데이터 탐색
- 각 관측 = 특정 기간·카운티의 주택 판매(예: Stanislaus County, 12주). 특성: 신규 리스팅 수, 판매 수, 중앙값 리스팅가/판매가, **중앙값 시장 체류일(median days on market)의 전년 대비(YoY) 변화** 등.
- 전처리: 첫 행 고정, 조건부 서식(신규 리스팅에 색 스케일 — Santa Clara가 많음), 특정 기간 필터. **퍼센트 변화(YoY)엔 발산 색 스케일**. UNIQUE로 58개 카운티 확인, 판매 수/중앙 판매가 요약(캘리포니아 평균 약 $627k, 최고 약 $160만).

### 막대/열 차트 만들기
- 데이터 범위(상위 10 카운티 + 중앙 판매가) 선택 → **Insert → Chart**.
- x축 라벨(카운티명)이 붙으면 **열 차트를 막대 차트로 변경**해 라벨을 읽기 쉽게(가로).
- 차트 메뉴(케밥)로 다운로드·삭제·별도 시트로 이동 가능.
- 인사이트: San Mateo 최고(약 $160만), San Diego가 상위 10 중 최저(약 $883k).
- **차트 수정(Edit Chart)**: 데이터 범위를 바꿔 같은 카운티의 **중앙값 시장 체류일**로 변경 → Napa ~37일, San Mateo·Santa Clara 등은 2주 이하. 판매가와 체류일 사이 뚜렷한 관계는 없음.

## 예시

### 막대/열 차트 만들기 흐름
```
데이터 범위 선택 → Insert → Chart
→ (라벨 겹치면) 열→막대로 변경
→ Edit Chart로 데이터 범위·특성 변경
```

## 요약
- **막대/열 차트**는 범주 비교에 좋은 가장 흔한 시각화로, Google Sheets에서 범위 선택 후 **Insert → Chart** 로 만든다.
- 라벨이 겹치면 **막대(가로)** 로 바꿔 가독성을 높이고, **Edit Chart** 로 데이터 범위·특성을 바꿔 다른 인사이트를 본다.
- 탐색 단계에서 조건부 서식·필터·요약으로 데이터를 이해한 뒤 시각화한다. 다음 강의는 **차트 커스터마이즈**다.
