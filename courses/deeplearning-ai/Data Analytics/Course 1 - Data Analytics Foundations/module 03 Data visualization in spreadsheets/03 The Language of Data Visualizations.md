# The Language of Data Visualizations

## 개요
- 모든 시각화가 해석하기 쉬운 건 아니다. 시각화의 **공통 구성 요소**(제목·축·인코딩/범례·주석)를 알면 능숙하게 해석할 수 있다.
- 데이터를 색·크기·마커 같은 시각 속성으로 바꾸는 것을 **인코딩(encoding)** 이라 하고, 이를 설명하는 것이 **범례(legend)** 다.
- 어떤 차트든 **5단계 접근**(제목·부제 → 축 → 인코딩 범주 → 주석 → 큰 그림)으로 해석한다.

## 내용

### 구성 요소 (예: "Alexa" 이름 차트)
- **제목(title)**: 무엇을 볼지 알려줌("부모들이 이 이름을 안 짓기 시작했다").
- **x축**: 제목 없어도 1983~2023이면 시간(과거 왼쪽·최근 오른쪽).
- **y축**: 0~7,000, 부제("미국 여아 Alexa 수")로 y축 라벨을 대신해 공간 절약.
- **색·마커·범례**: 선이 하나뿐이면 색에 특별한 의미 없음. 2023 지점 마커로 현재 위치 강조.
- **주석(annotation)**: 정점(약 6,000명), "Amazon Alexa 출시", 2023년 490명 등 맥락 표시.
- **인사이트**: 2016년까지 인기 → 급감. 주석이 원인을 명확히("Alexa 출시 2년 뒤 부모들이 이름을 안 지음").

### 인코딩(encoding)과 범례
- **인코딩** = 데이터를 시각 속성(색·크기·마커)으로 번역. 예: 연두=맨해튼, 파랑=브롱크스 / 삼각형=iPhone, 사각형=Android. 삼각형이 본래 iPhone을 뜻하는 게 아니라 **인코딩된 범주**이며, **범례**가 이를 설명한다.
- 예(뉴욕 자치구 인구 누적 막대): x=연도(10년 간격), y=총인구 대비 %(0~100), 색=자치구. 초기 맨해튼 집중 → 1920~30년 브루클린 역전. 범주를 2010 기준으로 정렬해 추세 추적 용이.

### 5단계 해석 접근
1. **제목·부제**: 무엇에 관한 차트인가, 핵심 인사이트는?
2. **축**: x축(좌→우, 보통 증가), y축(하→상, 보통 증가). 눈금·격자 확인.
3. **인코딩 범주**: 범례에서 색·마커·크기 차이 확인.
4. **주석**: 맥락·핵심 강조 노트.
5. **큰 그림**: 비교인가 추세인가? 놀라운 정보·큰/점진적 변화를 찾고 제목·주석으로 사고를 안내.

## 예시

### 시각화 구성 요소
| 요소 | 역할 |
|------|------|
| 제목/부제 | 주제·핵심 인사이트 |
| x/y축 | 무엇이 변하는가(보통 증가) |
| 인코딩(색·마커·크기)+범례 | 데이터를 시각 속성으로 |
| 주석 | 맥락·강조 |

## 요약
- 시각화는 **제목·축·인코딩(범례)·주석** 으로 구성되며, **인코딩**은 데이터를 색·크기·마커로 번역하는 것이고 **범례**가 이를 설명한다.
- 어떤 차트든 **① 제목·부제 → ② 축 → ③ 인코딩 범주 → ④ 주석 → ⑤ 큰 그림** 의 5단계로 해석한다.
- 이 접근은 시각화 리터러시를 기르는 좋은 연습이다. 다음 강의에서 시각화 해석을 더 연습한다.
