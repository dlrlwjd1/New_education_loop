# Module 3 Introduction

## 개요
- 모듈 3은 **데이터 시각화(data visualization)** — 그래픽으로 데이터를 소통하는 실무 — 를 다룬다.
- 원시 데이터를 청중에게 와닿는 이야기로 바꾸고, 올바른 차트 선택·시각 요소 활용·효율적 시각화(데이터-잉크 비율)·LLM 활용을 배운다.

## 내용

### 이 모듈에서 배우는 것
- 인사이트를 효과적으로 전달하는 **시각화 기법**과 데이터 애널리스트가 쓰는 **주요 차트 유형**.
- 차트는 오용·오해될 수 있으니 **올바른 차트 선택**, 그리고 **색·마커·제목·축·주석(annotation)** 으로 핵심 인사이트 강조.
- **데이터-잉크 비율(data-to-ink ratio) 극대화**와 **차트 정크(chart junk) 최소화** 로 효율적 시각화.
- **LLM으로 차트 해석·생성** — 시간 절약과 실수 방지를 위해 회의적 태도로.

## 요약
- 모듈 3은 데이터 시각화의 핵심 기술을 다룬다: **차트 유형·선택, 시각 요소 활용, 효율적 시각화(데이터-잉크 비율), LLM 활용**.
- 목표는 원시 데이터를 설득력 있는 이야기로 전환해 실제 영향을 이끄는 것이다.
