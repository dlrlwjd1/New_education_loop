# Demo: Creating Data Visualizations with LLMs

## 개요
- LLM(ChatGPT 등)으로 데이터 시각화를 **생성**하는 데모(호텔 예약 데이터).
- 큰 파일(36,000행)은 **코드 실행 기능이 있는 모델**(ChatGPT)에 업로드해 처리하고, 대화로 차트 유형·축·비교를 반복 조정한다.

## 내용

### 도구 선택
- Claude에 3.6만 행 CSV를 붙이면 **너무 커서 처리 불가** → 다르게 접근해야 한다는 신호. **ChatGPT** 는 전체 업로드해도 매 프롬프트마다 읽지 않아(코드 실행) 문제없음.

### 시각화 생성·조정
- "12개월별 총 예약 수를 시각화" → 연중 증가 후 11·12월 급감.
- 조정: "x축을 월 번호 대신 **월 이름**으로, 열 차트를 **막대 차트**로"(월을 시계열이 아니라 범주로 취급).
- "마켓 세그먼트별 **취소율** 시각화" → 스프레드시트와 대조 검증(미취소 약 2/3와 일치).
- "월별 **평균 예약 가치**" → 겨울 낮고 여름 정점(여행 성수기).
- "재방문 고객 × 예약 상태별 **리드 타임** 막대"(수치 × 다중 범주) → 그룹 막대. 취소 예약의 리드 타임이 김, 재방문·미취소는 매우 짧음. (취소=파랑, 미취소=빨강은 다소 반직관적 색 선택.)
- "취소 vs 미취소의 **객실 평균가 분포**" → **박스 플롯(box plot)** 또는 바이올린 플롯 제안. 박스 플롯: 중앙선=중앙값(취소가 미취소보다 약 10유로 높음), 범위(0~550)는 유사. (박스 플롯은 다음 코스에서 상세)

### 결론
- LLM은 자기 시각화를 개선하고 새 시각화를 만드는 데 유용한 워크플로 도구이며, 결과는 스프레드시트로 검증한다.

## 예시

### LLM 시각화 생성 흐름
```
전체 CSV를 ChatGPT(코드 실행)에 업로드
→ "월별 예약 수 시각화" → 유형·축·색 조정 요청
→ 취소율·평균가치·리드타임·분포(박스 플롯) 등 반복
→ 스프레드시트로 검증
```

## 요약
- LLM으로 시각화를 **생성**할 수 있으며, 큰 데이터는 **코드 실행 기능 모델(ChatGPT)** 에 업로드해 처리한다.
- 대화로 차트 유형·축·범주·색을 반복 조정하고, 박스 플롯 같은 새 유형도 제안받는다.
- 결과는 항상 스프레드시트로 **검증**한다. 이로써 모듈 3(데이터 시각화)이 마무리되고, 다음은 최종 모듈 **데이터 애널리틱스 라이프사이클**이다.
