# What is Data Storytelling?

## 개요
- **데이터 스토리텔링(data storytelling)** 은 분석 결과를 의미 있는 인사이트로 번역하는 것 — **기술 통계 + 데이터 시각화**로 설득력 있는 서사를 전달하는 기술이다.
- 4가지 핵심 구성 요소: **비즈니스 문제·데이터·분석·시각화**.
- 시각화 없이 기술 통계만으로도 이야기를 전할 수 있지만, 잘 만든 시각화와 결합하면 훨씬 강력·감성적이 된다.

## 내용

### 데이터 스토리텔링이란
- 건조한 숫자 목록 vs 몰입되는 시각 서사의 차이. 예: 아기 이름 "Sean" vs "Shawn" 시간별 인기 그래프 — 언제 역전됐는지, 어느 철자가 더 독특한지를 이야기로 전달.
- "그림 한 장이 천 마디 말의 가치" — 잘 시각화된 데이터 이야기는 생각을 자극하고 강력하며 감성적일 수 있다.

### 4가지 핵심 구성 요소
1. **비즈니스 문제(business problem)**: 이야기를 하는 이유 — 청중과 목표에 집중.
2. **데이터(data)**: 원재료로, 어떤 이야기를 할 수 있는지 규정.
3. **분석(analysis)**: 데이터에서 인사이트 추출(평균·백분율 같은 기술 통계, 더 복잡한 분석도).
4. **시각화(visualization)**: 데이터를 청중에게 시각적으로 제시.

### 시각화 없이도 가능하지만…
- 기술 통계만으로도 완전한 이야기 가능(예: 기대수명 32→71년, 미국 5세 이상 13%가 스페인어 사용). 조건부 서식·강조로 시각성 추가 가능.
- 하지만 **잘 만든 시각화와 결합**하면 다음 단계로 — 예: 기대수명을 연도별 선그래프로 → 꾸준한 진보와 감소 지점을 한눈에.
- 스토리텔링은 대개 청중(팀·이해관계자·대중) 대상이지만, **자신을 위한** 탐색용도 가능(추세 빠르게 포착). 외부용은 더 정제, 내부 탐색용은 거친 시각화로 충분.

### 감성적 예시 — Minard의 나폴레옹 러시아 원정
- Charles Joseph Minard의 그래픽은 **지도 + 선그래프(시계열)** — 선 두께가 군대 규모(프랑스 출발 갈색, 귀환 흑색). 프랑스어를 몰라도 나폴레옹이 약 41만 명을 잃은 참담한 원정임을 알 수 있다. "잔혹한 우아함(brutal elegance)"으로 평가받는 시각화.

## 예시

### 데이터 스토리텔링 구성 요소
| 요소 | 역할 |
|------|------|
| 비즈니스 문제 | 이야기의 이유(청중·목표) |
| 데이터 | 원재료 |
| 분석 | 인사이트 추출 |
| 시각화 | 시각적 제시 |

## 요약
- **데이터 스토리텔링**은 **기술 통계 + 시각화**로 분석 결과를 설득력 있는 서사로 전달하는 기술이다.
- 핵심 4요소는 **비즈니스 문제·데이터·분석·시각화**이며, 시각화 없이도 가능하나 결합하면 훨씬 강력하다.
- 대상은 외부 청중(정제된 시각화)일 수도 자기 자신(탐색용 거친 시각화)일 수도 있다.
- Minard의 나폴레옹 원정 그래픽처럼 잘 만든 시각화는 감성적·강력하다. 다음 강의는 **시각화의 언어**다.
