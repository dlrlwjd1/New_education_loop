# Data Visualization Examples: The Good and the Better

## 개요
- 실제 시각화 세 개(탄산음료 시장 점유율, 활동별 시간 사용, 자연 접근성 버블 차트)를 비판적으로 해석하고 **개선안**을 제시한다.
- 반복 원칙: 적절한 차트 유형, 격자선·축 라벨, **핵심 인사이트를 담은 제목**, 로그 스케일·추세선 등.

## 내용

### ① 미국 탄산음료 시장 점유율 (선 차트)
- 시계열이라 선 차트 적절, 브랜드 색이 실제 브랜드 색과 유사(좋은 점). 하단 노트로 측정 단위(케이스 판매량) 맥락.
- 인사이트: 코카콜라 우위(중간에 하락), 펩시 꾸준한 하락, 닥터페퍼·스프라이트 상승, **닥터페퍼가 펩시를 추월**하는 듯(잘 안 보임).
- 개선: 더 넓게, **격자선 추가**(10%/20%만은 거침), 축 라벨 일관성·축 제목, **제목을 인사이트로**("닥터페퍼, 미국 2위 음료로 펩시 추월").

### ② 연령별 활동별 하루 시간 (그룹 가로 막대, 인터랙티브)
- 명확한 제목(맥락 설정). x=하루 시간(0~12), y=활동. 색=연령대. **인터랙티브로 관련 연령만 선택** → 8개 범주 비교 부담 완화.
- 그룹 가로 막대라 활동 내 비교 용이(예: 15~19세가 교육에 훨씬 많은 시간). 옅은 격자선이 적절.
- 인사이트: 개인관리·수면이 최다, 노동은 중년에 정점 후 감소, 여가는 나이 들수록 증가.
- 개선: x축 라벨 명확화("하루 평균 시간"), **활동이 아니라 연령별로 그룹화**하면 각 연령의 하루가 더 명확.

### ③ 자연 접근성 (버블 차트)
- x=인구 밀도(0~30,000), y=자연 점수(0~100). 산점도(두 수치 관계)로 적절. **이중 인코딩**: 색=발산 스케일(녹=높음 직관적, 보라=낮음은 덜 직관적), **크기=인구**. 범례로 크기 맥락, 주석은 대도시·이상치(Union City NJ 등)만 — 깔끔.
- 인사이트: 인구 밀도↑ → 자연 점수↓ 경향(완벽한 상관은 아님). 워싱턴 DC는 밀도 높아도 점수 높음, Union City NJ는 밀도 초고·점수 최저(이상치).
- 개선: **폰트 크게**, 데이터가 좌측에 뭉침(x축 절반을 두 도시가 차지) → **로그 스케일** 또는 이상치 제거, 격자선·추세선 추가, 제목을 인사이트로("인구 밀도 낮은 도시가 자연 접근성 우수").

### 프로 팁
- 자신의 최고 시각화 작업으로 **개인 명예의 전당(hall of fame)** 을 만들어 두면 구직에 유용.

## 예시

### 공통 개선 포인트
| 개선 | 예 |
|------|-----|
| 제목=인사이트 | "닥터페퍼, 펩시 추월" |
| 격자선/축 | 비교 용이 |
| 로그 스케일 | 좌측에 뭉친 데이터 펼치기 |
| 추세선/이상치 처리 | 관계 명확화 |

## 요약
- 실제 시각화를 **5단계로 해석하고 개선**하는 연습 — 적절한 차트, 격자선·축 라벨, **인사이트 제목**, 로그 스케일·추세선·이상치 처리가 반복 개선 포인트다.
- 인터랙티브·이중 인코딩·주석의 적절한 사용이 가독성을 높인다.
- 자신의 우수 작업으로 **명예의 전당**을 만들어 두면 구직에 도움된다. 다음 레슨은 **LLM으로 시각화**다.
