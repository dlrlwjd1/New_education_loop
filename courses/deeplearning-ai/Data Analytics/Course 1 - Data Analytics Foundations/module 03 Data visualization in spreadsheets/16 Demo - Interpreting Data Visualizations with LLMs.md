# Demo: Interpreting Data Visualizations with LLMs

## 개요
- ChatGPT-4o·Claude 3.5 Sonnet은 단순 LLM이 아니라 **대형 멀티모달 모델(Large Multimodal Model)** — 텍스트뿐 아니라 **이미지도 해석**한다.
- 차트 이미지를 올려 **해석**하거나 **비평**을 받을 수 있으나, 실수를 하므로 **사람의 판단으로 검증**해야 한다.
- 결론: LLM은 차트 **해석**에는 유용하고, **비평**에는 "괜찮은 second pair of eyes" 수준이다.

## 내용

### 차트 해석
- 자연 접근성 버블 차트를 스크린샷해 Claude에 업로드, "이 차트를 설명하고 핵심 인사이트를 알려줘".
- Claude가 정확히 파악: x=인구 밀도, y=자연 점수, 버블=도시(크기=인구, 색=자연 점수), **밀도↑ 시 점수↓ 역관계**, Union City 이상치. 다만 "큰 버블이 우하단에 뭉친다"는 표현은 부정확 — 더 정밀할 수 있음.

### 차트 비평 (자기 차트 개선)
- 새 관찰(새 종별 온도) 차트를 ChatGPT-4o에 업로드 + **역할 부여 프롬프트**("너는 데이터 시각화에 열정 있는 전문 애널리스트. 각 개선점과 구체적 수정안을 간결히"). → 역할·작업을 명확히 지시.
- ChatGPT 지적: 색 유사(bird1·2), 범례가 데이터 위에 겹침(실제론 안 겹침), 마커 과대·조밀, y축이 20까지라 공간 낭비, 격자선이 시각을 지배 등 — **진짜 문제(유사 색·겹침)와 비(非)문제가 섞임**, 제안 품질도 들쭉날쭉.
- 같은 프롬프트를 Claude에도 — 유사한 지적(오버플로팅·색·y축) + **추세선 부재** 지적(종별 패턴이 안 보임, 종별 추세선 추가 제안 — 고려할 만함). 모델마다 성능이 다르니 여러 모델 테스트가 유용.

### 결론
- LLM은 차트 **해석에 더 유용**, **비평엔 덜 유용**(그래도 second pair of eyes로 가치). 스크린샷을 Claude·ChatGPT에 넣어 인사이트를 얻되 **최종 판단은 사람**.

## 예시

### LLM 시각화 활용
| 용도 | 유용성 |
|------|--------|
| 차트 해석 | 유용(핵심 인사이트 파악) |
| 차트 비평 | 보조(진짜/가짜 문제 섞임, 검증 필요) |

## 요약
- ChatGPT-4o·Claude 3.5는 **멀티모달 모델**로 차트 이미지를 해석·비평할 수 있다.
- **해석**은 정확도가 높아 유용하고, **비평**은 진짜 문제와 비문제가 섞여 **사람의 검증**이 필수다(역할 부여 프롬프트가 도움).
- 여러 모델을 테스트하며 스크린샷을 활용하되 최종 판단은 사람이 한다. 다음 강의는 **LLM으로 시각화 생성**이다.
