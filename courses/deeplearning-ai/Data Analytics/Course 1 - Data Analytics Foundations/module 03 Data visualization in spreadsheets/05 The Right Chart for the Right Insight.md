# The Right Chart for the Right Insight

## 개요
- 데이터 시각화는 예술이자 **과학** — 전달하려는 인사이트에 **올바른 차트 유형**을 골라야 한다(맞고 틀림이 있다).
- 핵심 **4종(core four)** 으로 인사이트의 약 80%를 전달할 수 있다: **막대/열 차트, 선 차트, 산점도, 누적/그룹 막대·열 차트**.

## 내용

### 핵심 4종 차트
- **막대/열 차트(bar/column)**: **범주별 수치 비교**. 예: 대륙별 앨범 판매, 매장별 친칠라 판매 수.
- **선 차트(line)**: **시간에 따른 수치 추세**. 점 사이 기울기가 변화율 강조. 변형 **영역 차트(area)** 는 추세뿐 아니라 누적 **양(volume)** 강조.
- **산점도(scatter plot)**: **두 수치 특성 비교/관계 탐색**. 유연함. **사분면(quadrant)** 을 더해 고/저 조합 강조 가능.
- **누적/그룹 막대·열 차트**: **여러 범주에 걸친 수치 비교**.
  - **누적(stacked)**: 부분-전체 관계(책 쌓기처럼). 각 앨범이 지역별 총매출에 얼마나 기여하는가.
  - **그룹(grouped)**: 범주 간 **직접 비교**(어느 매장이 친칠라를 가장 많이 파나).
  - **상대(relative) 차트**: 원시 수 대신 **비율** 표시. 그룹 크기가 다를 때 비교 용이(유럽 매출이 아시아보다 작아도 앨범 C 비중이 높음을 강조). 규모 vs 비율 중 무엇이 중요한지는 애널리스트의 선택.

### 치트시트 (인사이트 → 차트)
- **시계열** → 선 차트
- **범주 간 비교** → 막대/열 차트
- **두 수치 특성 관계** → 산점도
- **부분-전체 or 여러 범주 비교(시간 포함)** → 누적/그룹 막대·열

### 라이트닝 라운드
- 배우별 007 영화 수 → **막대**(이름 라벨 넣기 좋게 가로 막대 선호).
- 국가별 커피 소비 50년 추이 → **선 차트**(시간, 국가별 색).
- 뉴욕 vs 시카고 피자 토핑 비율 → **누적 막대**(위치별 상대 비중).
- 국가 초콜릿 소비 vs 노벨상 수상자 상관 → **산점도**(두 수치 비교).

## 예시

### 인사이트 → 차트 매핑
| 인사이트 | 차트 |
|----------|------|
| 시간 추세 | 선(line) / 영역(area) |
| 범주 비교 | 막대/열(bar/column) |
| 두 수치 관계 | 산점도(scatter) |
| 부분-전체·다범주 | 누적/그룹 막대·열 |

## 요약
- 차트 선택은 **과학** — 인사이트에 맞는 유형이 있고, 핵심 **4종**(막대/열·선·산점도·누적/그룹)으로 대부분을 전달한다.
- 막대=범주 비교, 선=시간 추세, 산점도=두 수치 관계, 누적=부분-전체·그룹=직접 비교이며, **상대 차트**는 비율 비교에 유용하다.
- 규모 vs 비율 중 무엇을 강조할지는 애널리스트의 선택이다. 다음 강의부터 Google Sheets에서 각 차트를 만드는 법을 다룬다.
