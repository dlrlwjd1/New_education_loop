# Chart Elements

## 개요
- **차트 요소(chart elements)** = 데이터를 직접 표현하지 않는 부분(스케일·주석·제목 등).
- 핵심: **로그 스케일(log scale)**, **축에 0 포함 여부**, **주석(annotation)**, **제목(title)**.

## 내용

### 로그 스케일(logarithmic scale)
- 선형 스케일은 값 간격이 균등(10·100·1000의 두 번째 간격이 10배 큼). **로그 스케일**은 10·100·1000을 **균등 간격**으로 만들어, 작은 값은 펼치고 큰 값은 압축 → 저범위 패턴이 잘 보임.
- 예: 인터넷 호스트 수 — 선형에선 1981~1997 변화가 안 보이지만 로그 스케일에선 그 성장이 명확.
- **사용 시점**: 넓은 범위, 절대값보다 **비율적 변화** 강조, 뭉친 점 펼치기.
- **한계**: **음수·0은 불가**(로그가 정의 안 됨). 또 사람은 로그로 자연스럽게 사고하지 않으므로, 스토리텔링 가치가 복잡성을 정당화하는지 판단. (예: COVID 사망 로그 그래프는 이해도가 유의하게 낮았고, 0 시기를 표시 못 함)
- 경험칙: 선형에서 데이터가 한 곳에 뭉치면 **로그 스케일이나 축 범위 조정**을 고려하되 청중 해석을 유의.

### 축에 0 포함
- **0 포함**은 데이터의 **규모(magnitude)** 를 전달(절대값이 중요할 때). 0을 빼는 것은 오해성 그래프의 흔한 수법.
- 단, **축을 잘라 0을 빼면** 작은 차이를 강조(관심 범위 확대)할 수 있다. 예: 프레첼 매출 — 950부터 시작하면 두 브랜드 차이가 커 보이고, 0 포함하면 비슷해 보임. 상황에 따라 둘 다 적절(경쟁 분석 vs 인기 평가).

### 주석(annotations)
- 청중 시선을 안내하는 훌륭한 도구. 없으면 눈이 헤맴. **1~3개 핵심 포인트만** 강조(효율성).
- 소비 방식 고려: 대면 발표는 레이저 포인터로 대체 가능(주석 적게), 독립 열람(리포트)은 서사를 대신할 **캡션** 추가.

### 제목(title)
- 단순 설명이 아니라 **핵심 인사이트를 부각**하는 기회. "베를린 범죄 데이터" 대신 **"올해 베를린 범죄 감소"**. 오해 방지 + 시간 범위 같은 맥락 제공.

## 예시

### 선형 vs 로그 스케일
| 스케일 | 특징 | 주의 |
|--------|------|------|
| 선형 | 값 간격 균등 | 뭉친 저범위 안 보임 |
| 로그 | 10·100·1000 균등 | 음수·0 불가, 해석 난이도 |

### 축 0 포함
| 0 포함 | 0 제외(잘라내기) |
|--------|------------------|
| 규모 전달(절대값) | 작은 차이 강조(확대) |

## 요약
- **차트 요소**는 데이터를 직접 표현하지 않는 부분으로, **로그 스케일·축 0 포함·주석·제목** 이 핵심이다.
- **로그 스케일**은 넓은 범위·비율 변화에 유용하나 음수/0 불가·해석 난이도에 유의한다.
- **축 0 포함**은 규모를, 0 제외는 작은 차이를 강조하며(오해 주의), **주석은 1~3개**, **제목은 핵심 인사이트**를 담는다.
