# Demo: Line Charts

## 개요
- **선 차트(line chart)** 는 시계열 시각화의 대표 유형. Module 2의 "Ruby" 이름 데이터(카운트 + 이동 평균)로 만든다.
- 축·제목·격자선을 설정하고, 추세·주기적 패턴·노이즈를 읽는다.

## 내용

### 선 차트 만들기
- 세 열(연도·카운트·이동 평균) 선택 → Insert Chart → **Line Chart** → x축=연도(시리즈에서 연도 제거) → 별도 시트로 이동.
- 제목·부제·가로/세로 축 제목 추가. **격자선**: x축 주 격자 25년, 부 격자 count 4 → 5년 간격.

### 인사이트
- 파란 카운트: 초기 상승 → 지속적 하락 → 최근 소폭 재부상. (1963년 급증은 이 차트에선 덜 두드러짐.)
- **주기적 패턴** 이 뚜렷 — 상승·하락 후 최근 재부상. 예측은 불가했지만 역사 데이터에선 명확. 노이즈는 있으나 전체 패턴 관찰을 방해하지 않고, **이동 평균이 데이터를 잘 따라감**.

## 예시

### 선 차트 만들기 흐름
```
연도·카운트·이동평균 선택 → Insert → Line Chart
→ x축=연도, 제목·축 제목, 격자선(25년 주/5년 부)
```

## 요약
- **선 차트**는 시계열의 대표 시각화로, 축·제목·격자선을 설정해 추세를 읽기 쉽게 만든다.
- Ruby 데이터에서 상승→하락→재부상의 **주기적 패턴**과 이동 평균의 평활 효과를 확인했다.
- 이로써 Google Sheets 차트 만들기 레슨이 마무리된다. 다음 강의는 **효과적 시각화 모범 사례**다.
