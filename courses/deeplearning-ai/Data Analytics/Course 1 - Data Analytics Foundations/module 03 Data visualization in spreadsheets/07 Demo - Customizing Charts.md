# Demo: Customizing Charts

## 개요
- 밋밋한 차트를 **커스터마이즈**해 데이터 스토리를 강화하는 데모(중앙 주택가 막대 차트).
- 차트 스타일·제목·시리즈(색·데이터 라벨·특정 값 강조)·축·격자선/눈금을 조정한다.

## 내용

### 차트 스타일
- 배경색 변경 가능(생략). **3D는 산만하고 인사이트가 없어 끔**.

### 제목
- 차트·축 제목은 **최대한 서술적으로**(예: "Q3" = 3분기 명시). 부제로 "중앙 주택 판매가", 굵게·크게.
- 축 라벨이 이미 카운티임을 보여주면 **x축 제목("county")은 불필요** — 공간 절약.

### 시리즈(Series)
- 막대 채우기 색 변경(기본 파랑). **데이터 라벨** 체크 → 각 막대에 정확한 값 표시(격자선만으로 해석 안 해도 됨).
- **특정 데이터 포인트 강조(Add format data point)**: San Francisco를 주황으로, 나머지는 회색으로 **탈강조(de-emphasize)** → 청중 시선을 핵심(SF)에 집중. y축 라벨이 있어 범례 불필요.

### 축 설정
- 라벨 폰트 크기↑, **통화 서식** 적용, 굵게 → 카운티·금액을 읽기 쉽게.

### 격자선(gridlines)과 눈금(ticks)
- **격자선**: 차트 전체를 가로지르는 선(전체를 가로질러 읽을 때 유용). **눈금**: 축 위에만(간단한 참조).
- 주(major)/부(minor) 격자선. 주 격자가 $500k 간격이면 **부 격자** 추가 가능 — minor count를 4로 하면 각 간격 $100k.
- 결과: 원본도 괜찮았지만 커스터마이즈로 **전하려는 스토리(SF 강조)** 가 뚜렷해지고 개별 금액도 읽기 쉬워짐.

## 예시

### 커스터마이즈 요소
| 요소 | 조정 |
|------|------|
| 스타일 | 3D 끄기 |
| 제목 | 서술적, 불필요한 축 제목 제거 |
| 시리즈 | 색·데이터 라벨·특정 값 강조/탈강조 |
| 축 | 폰트·통화 서식 |
| 격자선/눈금 | 주/부 격자, minor count |

## 요약
- 차트 커스터마이즈로 데이터 스토리를 강화한다: **3D 끄기, 서술적 제목, 데이터 라벨, 특정 값 강조/나머지 탈강조, 축 서식, 격자선/눈금 조정**.
- 핵심은 **강조(SF 주황) + 탈강조(나머지 회색)** 로 청중 시선을 스토리의 핵심에 모으는 것.
- 실험과 디테일로 차트를 강력한 소통 도구로 만든다. 다음 강의는 **산점도**다.
