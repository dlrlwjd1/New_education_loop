# Demo: Scatter Plots

## 개요
- **산점도(scatter plot)** 는 두 수치 특성의 **관계**를 드러낸다 — 각 점이 (x, y) 값 쌍. 예: 주택 크기(면적) vs 중앙 판매가.
- Google Sheets에서 산점도를 만들고 마커 크기·투명도·추세선(trend line)·축 범위·격자선을 커스터마이즈한다.

## 내용

### 산점도 만들기
- 두 수치 열(중앙 면적, 중앙 판매가) 선택 → Insert Chart → 기본 열 차트를 **산점도로 변경** → 별도 탭으로 이동.

### 커스터마이즈
- **제목**: 제목에 "중앙 주택 판매"가 있으면 y축 라벨 생략 가능. x축 제목은 "square footage"로 명확히. (각 점 = 카운티, 개별 주택 아님)
- **마커 크기·투명도**: 데이터가 많으면 크기 작게 or **채우기 투명도(opacity)↓** 로 겹침 완화. 여기선 데이터가 적어 10픽셀로 크게.
- **데이터 라벨**: 산점도에선 너무 복잡해져 부적합.
- **추세선(trend line)**: 선형 추세 시각화. 양의 기울기 → 면적↑ 시 판매가↑ 경향.
- **축 범위**: 기본은 데이터 경계로 확대. 최솟값을 0으로 설정하면 0까지의 추세를 볼 수 있음(실제 200 sqft 주택은 없지만 참고).
- **격자선**: 데이터 라벨 대신 격자선으로 값 추정. x에 부 격자(100 sqft 간격), y에 부 격자(count 4 → $100k 간격) → 방해되지 않게 값 추정 가능.

### 인사이트
- 추세선상 면적과 판매가는 **양의 상관**. 단, 추세선이 데이터를 두 그룹으로 나눔 — 일관된 저가 그룹과 추세를 안 따르는 고가 그룹. 가장 비싼 카운티가 가장 큰 집을 갖지 않아, **다른 가격 동인**이 있을 수 있음.
- 산점도는 상관 탐색·이상치 식별·가설 생성에 강력.

## 예시

### 산점도 커스터마이즈
| 요소 | 조정 |
|------|------|
| 마커 | 크기·투명도(겹침 시) |
| 추세선 | 선형 추세 표시 |
| 축 범위 | 최솟값 0 등 |
| 격자선 | 부 격자로 값 추정 |

## 요약
- **산점도**는 두 수치 특성의 관계를 보여주며(각 점=값 쌍), Insert Chart 후 유형을 산점도로 바꿔 만든다.
- 마커 크기·투명도, **추세선**, 축 범위, 격자선을 조정해 관계를 읽기 쉽게 한다.
- 주택 면적↑↔판매가↑ 양의 상관을 확인했으나, 추세를 안 따르는 고가 그룹이 있어 다른 동인을 시사한다(상관·이상치·가설 탐색 도구).
- 다음 강의는 **그룹 막대·열 차트**다.
