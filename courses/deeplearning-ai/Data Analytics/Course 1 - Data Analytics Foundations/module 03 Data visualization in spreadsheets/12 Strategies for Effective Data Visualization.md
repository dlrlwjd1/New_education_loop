# Strategies for Effective Data Visualization

## 개요
- 부주의한 시각화는 착시(옵티컬 일루전)처럼 사람마다 다른 결론을 낳는다. 목표는 **모두가 같은(올바른) 인사이트**를 얻게 하는 것.
- 제작 프로세스: **스케치 → 초안 → 평가 → 공유·피드백 → 최종화**(중요도에 따라 반복).
- 세 핵심 원칙: **명확성(clarity)·효율성(efficiency)·맥락(context)**.

## 내용

### 제작 프로세스
- **스케치** → **초안 제작**(어떻게 소비될지 고려) → **평가**(핵심 인사이트를 잘 전달하는가) → **공유·피드백**(동료가 명확히 이해하는가) → **최종화**. 중요·고위험 시각화는 여러 번 반복.

### 원칙 1 — 명확성(clarity)
- 청중이 **의도대로 해석**하게 하는 것. 방법:
  - 데이터에 **적절한 차트 유형** 선택.
  - **불필요한 복잡성 회피** — 단순·깔끔, 잡동사니 제거.
  - **명확한 라벨·제목 + 주석**으로 핵심 강조.
  - 색·폰트·스케일 **일관성**.
  - **가독성** — 폰트가 너무 작지 않게(발표엔 큰 폰트).
  - **공유·피드백**으로 신선한 시각 확보.
- 예: 월별 매출을 **파이 차트**로 그리면 슬라이스 비교·시계열에 부적합하고 색이 과함 → **선 차트**로 바꾸면 상승 추세와 축 라벨이 명확.

### 원칙 2 — 효율성(efficiency)
- 목적에 기여하는 요소만 포함. **데이터-잉크 비율(data-to-ink ratio)**(Edward Tufte) — 실제 데이터에 쓰인 잉크/픽셀의 비율. 데이터에 집중.
  - **데이터-잉크**: 막대·마커·선·축 라벨·간결한 주석·데이터 라벨.
  - **비(非)데이터-잉크**: 3D 효과·두꺼운 테두리·그림자·과도한 격자선·장황한 주석.
- **차트 정크(chart junk)**: 이해를 돕지 않는 산만한 장식(과한 색·불필요한 이미지·로고). 예: AirPods 그림·그림자 있는 원본은 정크 → 제거하고 색으로 강조하면 훨씬 빠르게 해석됨.

### 원칙 3 — 맥락(context)
- 청중의 배경지식에 맞춰 이해를 뒷받침. **명확한 서사 구조(스토리텔링)**, 배경 정보 제공, 익숙한 개념과 비교, 전문용어 정의, 데이터의 의미 설명.
- 청중에 따라 조정하되 **맥락은 넉넉히** — 정보가 너무 많다는 불평은 드물지만, 부족하면 오해를 부른다.

## 예시

### 세 원칙
| 원칙 | 핵심 |
|------|------|
| 명확성 | 적절한 차트·단순·명확한 라벨·일관성·가독성·피드백 |
| 효율성 | 데이터-잉크 비율↑, 차트 정크 제거 |
| 맥락 | 서사·배경·용어 정의(넉넉히) |

## 요약
- 좋은 시각화의 목표는 **모두가 같은 올바른 해석**에 이르게 하는 것이며, 제작은 스케치→초안→평가→피드백→최종화로 반복한다.
- 세 원칙: **명확성**(적절 차트·단순·라벨), **효율성**(데이터-잉크 비율↑·차트 정크 제거), **맥락**(서사·배경 제공).
- 데이터가 말하게 하고 장식을 줄여라. 다음 강의에서 시각화 **디자인**을 더 다룬다.
