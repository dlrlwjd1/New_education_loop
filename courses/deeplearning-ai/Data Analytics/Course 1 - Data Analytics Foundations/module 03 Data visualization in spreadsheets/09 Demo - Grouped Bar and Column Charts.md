# Demo: Grouped Bar & Column Charts

## 개요
- **그룹 막대/열 차트(grouped)** 는 관심 결과를 **여러 그룹에 걸쳐 직접 비교**한다 — 두 특성을 동시에 시각화.
- 아기 이름 데이터로 순위별 남/여 이름 인기를 그룹 차트로 만든다.

## 내용

### 데이터 준비
- 남/여 각각 상위 10개 이름의 전 연도 합계(순위 정렬). 예: 남아 1위 James(500만+), 여아 1위 Mary(400만+).
- 그룹 차트에 필요한 형식: **공통 범주(rank)** + **그룹별(성별) 별도 카운트 시리즈**. (이런 요약은 다음 코스의 **피벗 테이블(pivot table)** 로 쉽게 만듦)

### 차트 만들기·커스터마이즈
- 이름 10개라 **막대 차트**로 전환, rank를 y축에. 남아 카운트 시리즈·여아 카운트 시리즈 각각 추가, 라벨은 남/여 이름.
- 별도 시트로 이동, 제목·부제(맥락) 추가.
- **색 부드럽게**: 여=녹색, 남=진한 파랑.
- **x축 숫자에 쉼표**: 커스텀 숫자 형식으로 쉼표 추가 → 수백만 단위 가독성↑.
- **격자선**: 주 격자 7개 + 사이에 부 격자 1개 → 50만 간격 → Elizabeth~Barbara가 약 150만 근처임을 명확히.

### 인사이트
- 상위 10 남아 이름이 여아보다 훨씬 인기 — **Mary를 제외하면 상위 10 남아 이름 각각이 상위 10 여아 이름 전부보다 더 인기**.

## 예시

### 그룹 차트용 데이터 형식
| rank | 남아 이름·카운트 | 여아 이름·카운트 |
|------|------------------|------------------|
| 1 | James / 5M+ | Mary / 4M+ |
| ... | ... | ... |

## 요약
- **그룹 막대/열 차트**는 여러 그룹에 걸친 직접 비교에 쓰이며, **공통 범주 + 그룹별 카운트 시리즈** 형식의 데이터가 필요하다(피벗 테이블로 준비).
- 색·쉼표 서식·격자선을 조정해 가독성을 높이고, 남/여 이름 인기 비교 인사이트를 얻었다.
- 다음 강의는 **누적 막대·열 차트**다.
