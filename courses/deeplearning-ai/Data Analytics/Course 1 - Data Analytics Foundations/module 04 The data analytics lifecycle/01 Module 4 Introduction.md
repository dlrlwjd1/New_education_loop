# Module 4 Introduction

## 개요
- 마지막 모듈은 **데이터 애널리틱스 라이프사이클(data analytics lifecycle)** — 데이터로 문제를 푸는 구조화된 접근 — 을 다룬다.
- 문제 정의부터 영향 평가까지 각 단계, 그리고 **도메인 지식·이해관계자 협업**, LLM을 활용한 이해관계자 분석을 배운다.
- 모듈 1~3이 하드 스킬이었다면, 이 모듈은 **소프트 스킬**(적응력·소통·전략적 사고)에 초점을 둔다.

## 내용

### 이 모듈에서 배우는 것
- 라이프사이클의 각 단계(문제 정의 → 해결책 영향 평가).
- **도메인 지식**과 **이해관계자 협업**이 결과를 크게 개선하는 법 — 이해관계자를 식별하고, 목표를 파악하고, 효과적으로 점검(check-in)하기.
- **LLM으로 이해관계자 분석**: 상충하는 요청 조율, 기회 우선순위, 좋은 점검 질문 개발.
- 마무리 **캡스톤**: 통신사 고객 데이터를 분석해 서비스 해지(cancellation)를 줄이는 과제.

## 요약
- 최종 모듈은 **데이터 애널리틱스 라이프사이클**과 **이해관계자 협업·도메인 지식** 같은 **소프트 스킬**을 다룬다.
- 문제 정의부터 영향 평가까지 프로젝트를 처음부터 끝까지 자신 있게 수행하는 능력을 기른다(캡스톤 포함).
