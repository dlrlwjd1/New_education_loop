# Analyzing Data

## 개요
- 데이터가 준비되면 **분석**으로 원시 데이터를 인사이트로 바꾼다. 데이터·질문에 따라 여러 분석을 선택한다.
- 4가지 분석 유형(복잡도 순): **기술 통계 → 데이터 시각화 → 통계 분석·모델링 → 머신러닝**. 각각 단독으로도 강력하며, 종종 **기술 통계·시각화만으로 충분**하다.

## 내용

### 4가지 분석 유형
- **기술 통계(descriptive statistics)**: 빈도·평균·중앙값·상관 등으로 특성 요약(이 코스에서 다룸).
- **데이터 시각화**: 기술 통계만으론 안 보이는 추세를 시각으로 포착. 크고 복잡한 데이터에서 특히 빛남.
- **통계 분석·모델링**: 가설 평가·특성 간 관계 이해(다음 코스에서 다룸).
- **머신러닝(ML)**: 정교한 알고리즘으로 데이터에서 학습해 **예측**.

### 예시 — 금연 캠페인(21~30세 대상) 공중보건 평가
- **기술 통계**: 인구통계(나이·소득·교육)·건강 데이터(BMI·흡연 상태·운동) 분석. **세그멘테이션** 으로 연령대별 흡연율 비교.
- **시각화**: 연령대별 흡연율 막대, 시간별 추세 선차트, 지역별 흡연율 **지도**(핫스팟 식별).
- **통계 분석**: **가설 검정** 으로 개입 그룹의 흡연율 감소가 우연 아닌 실제 효과인지 확인. **회귀 모델** 로 흡연과 강하게 연관된 요인 식별.
- **머신러닝**: **예측 모델** 로 개입 효과가 클 개인 식별(자원 타깃팅), **군집화(clustering)** 로 유사 특성 그룹으로 세분(맞춤 개입).
- 네 유형을 결합해 종합 평가 → 데이터 기반 의사결정(수용성 높은 세그먼트·지역 추세·주요 요인·맞춤 개입).

### 권장
- 프로젝트마다 **다면적(multifaceted) 접근** — 여러 범주의 방법을 시도해 다음 단계(인사이트 발견)를 준비.

## 예시

### 분석 유형 (복잡도 순)
| 유형 | 하는 일 |
|------|---------|
| 기술 통계 | 특성 요약(평균·상관 등) |
| 시각화 | 추세 포착(복잡·대규모에 강함) |
| 통계 분석·모델링 | 가설 검정·관계(회귀) |
| 머신러닝 | 패턴 학습·예측·군집화 |

## 요약
- 분석은 데이터를 인사이트로 바꾸며, **기술 통계·시각화·통계 모델링·머신러닝** 4유형에서 데이터·질문에 맞게 선택한다.
- 복잡도는 ML로 갈수록 높지만, 종종 **기술 통계·시각화만으로 충분**하다.
- 금연 캠페인 예처럼 네 유형을 **결합한 다면적 접근**이 종합 평가와 데이터 기반 결정을 돕는다. 다음 강의는 **인사이트 도출**이다.
