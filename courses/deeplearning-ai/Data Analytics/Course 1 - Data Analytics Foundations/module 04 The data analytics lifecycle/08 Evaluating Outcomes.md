# Evaluating Outcomes

## 개요
- 라이프사이클의 마지막 단계 **성과 평가** — 작업의 영향을 평가한다. 질문: 결정이 원하는 결과로 이어졌나? 이해관계자가 만족했나? 핵심 배움은? 개선할 점은?
- **측정 가능한 성공 기준(metrics)** 을 결정 전후로 계산해 영향을 측정하고, 정성 피드백으로 만족도를 파악하며, **지속적 개선**의 기회로 삼는다.

## 내용

### 결과가 목표를 달성했나 — 지표(metrics)
- 성공 기준은 이상적으로 **직접 측정 가능(metric)**. 예: 금연 개입이 21~30세의 60%에 효과 → 70%로 올리는 목표로 업데이트.
- 평가법: 결정 **전후로 핵심 지표를 계산**해 차이로 영향 측정(6개월 이상 금연 비율 전/후). 통계적으로 엄밀한 분석이 필요할 수 있음.
- **지속성 모니터링**: 지표를 장기간 관찰(금연 효과가 1년 뒤 사라질 수도). 한 지표가 오르는 동안 다른 핵심 지표가 정체·하락할 수 있음.

### 이해관계자 만족도
- 설문·인터뷰·포커스 그룹(또는 엘리베이터 잡담)으로 피드백 수집. 결과 인식·잘된 점·개선점 질문 — **정성 피드백**이 영향에 대한 귀중한 통찰.

### 지속적 개선과 실패로부터 배우기
- 평가는 성공/실패 측정만이 아니라 **지속적 개선**. 덜 이상적인 분석이나 옳은 분석 후 잘못된 결정도 배움의 기회.
- 예 — **New Coke(1985)**: 시장 점유율 하락에 더 단맛 New Coke로 교체, **맛 테스트는 신제품 선호를 시사**했지만 대중은 분노·원조 향수. **옳은 분석, 잘못된 결정**. 77일 만에 Coca-Cola Classic 재출시 → 매출 급증·브랜드 문화적 위상 강화(이후 광고는 맛보다 가족·향수·축하). 실수를 인정·학습해 재앙을 배움의 기회로.
- 데이터 기반 결정도 의도치 않은 결과를 낳을 수 있으며, **적응·학습 능력**이 장기 성공에 필수. 자기 성찰이 효과적인 애널리스트를 만든다.

## 예시

### 평가 질문
| 질문 | 방법 |
|------|------|
| 목표 달성? | 지표 전/후 비교 + 지속성 모니터링 |
| 이해관계자 만족? | 설문·인터뷰·포커스 그룹 |
| 배움·개선점? | 성찰(실패도 학습) |

## 요약
- **성과 평가**는 **측정 가능한 지표**를 결정 전후로 비교해 영향을 재고(장기 지속성·다른 지표도 모니터링), **정성 피드백**으로 만족도를 파악한다.
- 평가는 성공/실패 판정이 아니라 **지속적 개선** — New Coke처럼 "옳은 분석, 잘못된 결정"에서도 배운다.
- 데이터 기반 결정도 의도치 않은 결과를 낳으니 **적응·학습**이 핵심이다. 이로써 라이프사이클이 마무리되고, 다음 레슨은 **이해관계자와 일하기**다.
