# Identifying Insights

## 개요
- 모든 분석은 **인사이트 도출**을 위한 것 — 숫자가 무엇을 의미하고 어떻게 의사결정을 돕는가.
- 인사이트 발견 프레임워크: **① 핵심 결과 식별 → ② 비즈니스 목표와의 관계 → ③ 결과에 대한 설명 → ④ (가능하면) 의사결정 권고**.

## 내용

### 인사이트 발견 프레임워크
1. **핵심 결과(key results) 식별**
2. 결과가 **비즈니스 목표**와 어떻게 연결되는지
3. 결과에 대한 **설명(explanation)** 개발
4. 해당되면 **의사결정 권고(recommendation)**

### 예시 — 금연 통제 실험
- **핵심 결과**: 개입 그룹(맞춤 상담 + 니코틴 대체 요법) 6개월 금연율 25% vs 표준 그룹 10%, **통계적으로 유의**(우연 아닌 실제 효과).
- **비즈니스 목표 연결**: 21~30세 흡연율 감소 → 이 증거로 **개입이 표준보다 금연에 효과적**이라 결론.
- **권고(recommendation)**: 모든 21~30세 흡연자에게 개입 제공 후 효과 지속 여부 연구 / 가장 효과 본 하위집단 식별 / 이점 홍보 등.
- 즉 핵심 결과 식별 → 목표 연결 → 설명 → 이해관계자가 검토할 권고 도출.

### 핵심 메시지
- 분석은 숫자 계산 이상 — 발견을 **특정 비즈니스 결정의 근거가 되는 인사이트로 번역**하는 것.

## 예시

### 인사이트 프레임워크 적용
| 단계 | 금연 예시 |
|------|-----------|
| 핵심 결과 | 개입 25% vs 표준 10%(유의) |
| 목표 연결 | 개입이 흡연 감소에 효과적 |
| 설명 | 맞춤 상담+요법의 효과 |
| 권고 | 전면 도입·하위집단 타깃·홍보 |

## 요약
- 분석의 목적은 **인사이트 도출**이며, **핵심 결과 → 목표 연결 → 설명 → 권고** 프레임워크로 접근한다.
- 금연 실험 예처럼 유의한 결과를 비즈니스 목표에 연결해 실행 가능한 권고를 만든다.
- 분석은 숫자 계산이 아니라 **의사결정 근거로의 번역**이다. 다음 강의는 **결과 공유**다.
