# Domain Knowledge

## 개요
- **도메인 지식(domain knowledge)** = 일하는 특정 산업에 대한 이해 — 언어·프로세스·페인 포인트·목표를 아는 것.
- 이해관계자 인사이트를 최대한 활용하고, 공통 어휘를 공유하며, 문제를 미리 예측하게 해준다.

## 내용

### 도메인 지식의 4가지 이점
1. **가장 관련 있는 비즈니스 질문**을 할 수 있다(구글에 무엇을 검색할지 아는 것처럼 — 올바른 쿼리가 올바른 결과로).
2. **맥락 속에서 인사이트 식별** — 남에겐 그저 숫자지만, 도메인 지식이 있으면 그것이 무엇을 의미하고 비즈니스에 어떤 영향을 주는지 안다.
3. 산업마다 데이터 도전이 다르므로, **문제에 맞는 분석을 선택**하도록 안내.
4. **분석 검증** — 인사이트가 문제 맥락에서 말이 되는지 확인.

### 핵심
- 도메인 지식은 **기술만 가진 사람보다 우위**를 주며, 작업을 비즈니스에 진정으로 연결한다.
- 데이터 애널리틱스는 기술이 필요하지만 **소프트 스킬이 차별화** 요소. 이해관계자가 편히 있을 수 있는 **포용적 환경**을 만들면 신뢰를 얻고 더 많은 임팩트 기회를 발견한다.

## 요약
- **도메인 지식**은 산업의 언어·프로세스·목표에 대한 이해로, ① 관련 질문 ② 맥락 속 인사이트 ③ 적절한 분석 선택 ④ 분석 검증의 4가지 이점을 준다.
- 기술만으로는 부족하며, 도메인 지식과 소프트 스킬이 애널리스트를 차별화한다.
