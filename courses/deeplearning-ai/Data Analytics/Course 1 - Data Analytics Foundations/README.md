# Course 1 — Data Analytics Foundations

**강사:** Sean Barnes (Netflix)
**소속 전문 과정:** Data Analytics (DeepLearning.AI)

## 개요
데이터 애널리틱스 입문 코스. 데이터와 데이터 애널리스트 역할, 스프레드시트를 활용한 데이터 처리·요약, 데이터 시각화, 그리고 데이터 애널리틱스 라이프사이클(문제 정의~평가)과 이해관계자 협업을 다룬다. 생성형 AI(LLM) 활용이 각 모듈에 통합되어 있다.

## 모듈 구성
- **module 01 — Data and the data analyst role** (영상 20): 데이터/애널리틱스 정의, 근거 기반 의사결정, 데이터 유형(정형/비정형/빅데이터), 데이터 생태계·팀, LLM 기초
- **module 02 — Using spreadsheets for data analytics** (영상 19): Google Sheets, 정렬·필터·서식, 요약 통계(COUNTIF/SUMIF/IFS 등), LLM 데이터 탐색, 시계열(이동 평균·퍼센트 변화)
- **module 03 — Data visualization in spreadsheets** (영상 17): 데이터 스토리텔링, 차트 유형·선택, 차트 제작 데모, 시각화 디자인(데이터-잉크 비율), LLM 시각화
- **module 04 — The data analytics lifecycle** (영상 14): 라이프사이클 5단계, 이해관계자 요구사항·종합·점검, 도메인 지식, LLM 이해관계자 분석

> 영상 강의만 정리(총 70개). Quiz·Lab·Reading·Resources·Lecture Notes·Capstone은 제외.
