# Importing Data

## 개요
- Google Sheets에 데이터를 넣는 3가지 방법: **직접 입력, 기존 파일 열기, 정형 데이터셋 가져오기(import)**. 대부분은 **CSV·Excel 파일을 가져오는** 방식이다.
- 이 레슨·다음 레슨에서 쓸 **호텔 예약 데이터셋**(리조트 H1·시티 H2, 31개 변수)을 예로 가져오고 탐색한다.
- 헤더 고정, 공유(권한 설정), 자동 저장·버전 복원 등 협업·안전 기능도 다룬다.

## 내용

### 데이터 로드 3가지 방법
1. **직접 생성(입력)**: 소규모 개인용(앞의 리노베이션 예산).
2. **기존 파일 열기**: 작업하던 시트 이어서.
3. **정형 데이터셋 가져오기(import)**: 대부분의 경우. 데이터는 보통 **CSV나 Excel** 파일로 시작.

### 호텔 예약 데이터셋
- 논문이 두 호텔 수요 데이터를 기술: **H1(리조트)** 4만 관측, **H2(시티)** 7.9만 관측, 동일 구조 **31개 변수**. 각 관측 = 하나의 예약. 2015-07-01~2017-08-31 도착 예약. 실제 데이터라 호텔·고객 식별 요소는 삭제됨(공개 데이터).

### 가져오기 절차
- **File → Import** → 파일 업로드(드래그) → "현재 시트 교체" 선택 → **구분자(separator) 자동 감지** 활성화(구분자 = 값을 나누는 쉼표·탭 등).
- 가져온 뒤: 헤더 굵게+하단 경계, 필터 추가. 행이 많으면 **View → Freeze** 로 첫 행 고정(스크롤해도 헤더 보임). 첫 열 선택 시 약 36,000행 확인.

### 공유·안전
- **Share 버튼**: 동료에게 **편집자/댓글/보기** 권한 부여, 메시지 첨부, 링크 복사. 접근을 "링크가 있는 누구나"·"회사 내 누구나"로 변경 가능 — Google Sheets의 큰 장점.
- 실수로 파일을 닫아도 링크로 재접속 가능. **자동 저장**되어 작업을 잃지 않고, 시계 아이콘으로 **이전 버전 복원** 가능.

## 예시

### 데이터 로드 방법
| 방법 | 사용 시점 |
|------|-----------|
| 직접 입력 | 소규모 개인용 |
| 기존 파일 열기 | 작업 이어서 |
| Import(CSV/Excel) | 대부분(외부 데이터셋) |

### 유용한 탐색 기능
- Freeze 첫 행(헤더 고정), 필터, Share(권한), 자동 저장·버전 복원

## 요약
- 데이터 로드는 **직접 입력·기존 파일·가져오기(import)** 3가지이며, 대부분 **CSV/Excel 가져오기**를 쓴다(File→Import, 구분자 자동 감지).
- 예제 **호텔 예약 데이터셋**(H1 리조트·H2 시티, 31변수)을 가져와 헤더 고정·필터로 탐색한다.
- Google Sheets는 **공유(권한)·자동 저장·버전 복원**으로 협업과 안전성이 뛰어나다.
- 다음 강의에서 **정렬·필터·서식(sorting, filtering, formatting)** 을 다룬다.
