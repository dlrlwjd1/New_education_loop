# Real-World Time Series

## 개요
- 실세계 시계열은 앞서 배운 구성 요소(추세·계절성·주기성·노이즈)를 **전부 또는 일부** 나타낸다. 그래프를 보고 이들을 시각적으로 식별하는 법을 배운다.
- 예시: 지구 평균 기온, El Niño(주기성), S&P 500 주가.

## 내용

### 기온 (지구 평균, 1850~)
- Y축: 1850~1900(산업화 이전) 평균 대비 섭씨 온도. 여러 색 선 = 서로 다른 센서의 시계열.
- **추세**: 1850~1925는 평탄, 이후 대체로 증가(1940~1975 잠깐 정체). **계절성**(기상 계절에 따른 등락)과 **노이즈**가 섞임. **주기성**은 계절성에 가려져 판단이 어렵고, 날씨는 국지적인 경우가 많다.

### El Niño (주기성 예)
- 태평양 표면 수온이 특정 바람 패턴으로 따뜻해지는 현상. **주기적이나 고정 간격이 아님**(보통 9~12개월, 때로 수년).
- 그래프(1990~2024): 0.0 기준선 위 지속값이 El Niño 해. 97~98(강함, ~1년), 15~16(더 강함, ~1.5년), 2017 초의 약한 사례 등.
- **주기적**으로 분류 — 다시 일어날 것은 확실하나 **시점·기간·강도 예측이 어렵다**.

### S&P 500 (주가)
- 미국 500대 기업 주가의 종합 지표. **추세**는 대체로 증가하지만 단기는 거의 예측 불가.
- 구간을 확대하면 추세가 증가/감소/평탄 다양하게 보이나, 축소하면 장기 상승이 명확 — 닷컴 붕괴(2000)·대침체(2008)·코로나조차 상대적으로 작아 보임.
- 이런 경기 확장/침체가 **주기적 패턴**(광범위한 경제 상황)이며, 주가엔 이해 못 한 요인으로 인한 **노이즈**도 많다.

## 예시

### 실세계 예시별 구성 요소
| 예시 | 두드러지는 요소 |
|------|-----------------|
| 지구 기온 | 증가 추세 + 계절성 + 노이즈 |
| El Niño | 주기성(불규칙 간격·강도) |
| S&P 500 | 장기 증가 추세 + 주기(경기) + 노이즈 |

## 요약
- 실세계 시계열은 추세·계절성·주기성·노이즈를 조합해 나타내며, 그래프로 이를 식별할 수 있다.
- **기온**은 증가 추세+계절성+노이즈, **El Niño** 는 강도·시점이 불규칙한 주기성, **S&P 500** 은 장기 상승 추세 위에 경기 주기와 노이즈가 얹힌다.
- 축소 관점에서 장기 추세를, 확대 관점에서 단기 변동을 봐야 한다. 다음 강의는 **이동 평균(moving averages)** 이다.
