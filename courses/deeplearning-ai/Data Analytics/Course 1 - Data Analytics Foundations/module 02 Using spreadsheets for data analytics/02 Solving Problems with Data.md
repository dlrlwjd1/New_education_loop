# Solving Problems with Data

## 개요
- 데이터는 직감(hunch)이 맞는지 원칙적으로 검증하게 해준다. 강력한 인사이트를 얻으려면 **올바른 데이터를 선택**해야 한다.
- 데이터 선택의 두 핵심 고려사항: **① 관심 결과(outcomes of interest)** 를 정하고, **② 그 결과에 맥락(context)을 주는 데이터**를 식별하는 것.
- 맥락 데이터는 **4W(누가·무엇·언제·어디서)** 를 알려줘, 결과의 배경 요인을 이해하고 비교·분석하게 한다.

## 내용

### ① 관심 결과(outcomes of interest)
- 첫 질문: "내가 관심 있는 결과는 무엇인가?"
- 예: 태양광 사업 이익 증대 → 매출 증가/비용 감소(매출·비용 보고서). 병원 환자 예후 개선 → 환자 만족도 증가·재원일 감소(환자 설문, 입·퇴원 날짜).

### ② 맥락(context)을 주는 데이터 — 4W
- 관심 결과에 **더 많은 정보**를 주는 데이터, 즉 **누가(who)·무엇(what)·언제(when)·어디서(where)**.
- 예: 매출 데이터의 맥락 = 고객 ID(who)·제품(what)·구매일(when)·지역(where).
- 매출만 있으면 그 이상을 알 수 없다. 맥락이 있어야 "고객 973이 2024-06-15 북미에서 케이블 세트를 구매" 같은 이해와 제품·지역 간 비교가 가능.

### 맥락 데이터로 답하는 질문 (태양광 예)
- 추가 구매를 유도할 **고액 고객**이 있나? → 고객 ID + 매출.
- **어떤 제품**이 매출을 견인하나? → 제품 + 매출.
- 시간에 따른 **매출 추세**? → 구매일 + 매출.
- **지역별** 매출 차이? → 지역 + 매출.
- 더 깊이: 최대 구매 고객(예: 111)이 기업인지 개인인지, 규모·주문 횟수 등도 파고들 수 있다. 맥락 데이터는 관심 결과만큼 중요하다.

## 예시

### 매출(결과) + 맥락(4W)
| 데이터 | 역할 |
|--------|------|
| 매출(sale) | 관심 결과 |
| 고객 ID | who |
| 제품 | what |
| 구매일 | when |
| 지역 | where |

## 요약
- 문제 해결의 시작은 **올바른 데이터 선택** — ① **관심 결과**를 정하고 ② 그 결과에 **맥락(4W)** 을 주는 데이터를 식별한다.
- 맥락 데이터가 없으면 결과의 배경 요인을 이해하거나 비교할 수 없어, 관심 결과만큼 중요하다.
- 다음 강의에서 이 데이터를 정리·분석하는 **스프레드시트**를 다룬다.
