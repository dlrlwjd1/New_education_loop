# Module 2 Introduction

## 개요
- 모듈 2는 데이터 애널리스트 도구 중 가장 강력하고 다재다능한 **스프레드시트(spreadsheet)** 를 다룬다.
- 정형 데이터 처리, 정렬·필터·수식·변환, LLM으로 데이터 알아가기, 그리고 **시계열(time series)** 데이터 분석을 실습한다.

## 내용

### 레슨 구성
- **레슨 1**: 스프레드시트가 정형 데이터에 효과적인 이유, Google Sheets로 데이터 가져오기·분석 준비.
- **레슨 2**: 스프레드시트로 데이터 처리 — 정렬·필터, 수식으로 계산 필드 생성, 데이터 변환. 실전 예: 호텔 예약 데이터로 고객 예약 행동 이해.
- **레슨 3**: LLM에 프롬프트해 데이터를 알아가고 분석 수행.
- **레슨 4**: **시계열 데이터** — 추세(trend)·계절성(seasonality)·주기성(cyclicality) 등 핵심 구성 요소, 미국 인기 아기 이름 데이터셋으로 분석 실습.

## 요약
- 모듈 2는 **스프레드시트 파워 유저**가 되기 위한 모듈로, 정형 데이터 처리·정렬/필터/수식·LLM 활용·시계열 분석을 실습 중심으로 다룬다.
