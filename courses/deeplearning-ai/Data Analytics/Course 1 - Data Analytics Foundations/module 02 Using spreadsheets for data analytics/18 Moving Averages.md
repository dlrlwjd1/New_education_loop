# Moving Averages

## 개요
- **이동 평균(moving average)** 은 노이즈가 많은 시계열을 **평활화(smooth)** 해 전체 흐름을 명확히 보여준다. 작은 간격·많은 데이터에 특히 유용.
- **단순 이동 평균(simple moving average)**: 연속된 **n개 기간의 평균**을 창(window)처럼 한 칸씩 이동시키며 계산 → 원본보다 **n−1 짧은** 값의 시리즈.
- n이 크면 안정적(부드럽고), 작으면 노이즈가 많다. 이동 평균은 과거만 보므로 실제 데이터보다 **뒤처진다(lag)**.

## 내용

### 단순 이동 평균 계산
- 데이터 위에 **n칸 높이의 창**을 놓고 창 안 값의 평균을 계산 → 창을 한 기간씩 아래로 이동. 각 창은 총량을 n일에 고르게 재분배한 것.
- 결과는 단일 요약값이 아니라 **값의 시리즈**이며, 원본보다 **n−1 만큼 짧다**(창 안 데이터가 n개 미만이면 계산 불가).
- 예(n=4, 데이터 8개): 첫 창 [8,1,3,7] 평균 4.75 → 한 칸 이동 [1,3,7,8] 평균 4.75 … 끝까지. 결과 길이 = 8 − (4−1) = 5.

### 실전 — 미국 아기 이름 데이터
- 데이터 출처: **data.gov**(사회보장국, 출생 시 이름 등록). 2022년 최종 업데이트(이후 데이터 없음), 1880년 이후 신청서의 100% 표본. **편향** 고려: 등록 안 되는 미등록 이민자 누락 가능.
- 컬럼: 이름·성별·출생연도·해당 이름/성별/연도의 아기 수(예: 1880년 John 남아 9,655명). 약 106,000 관측(count·year로 정렬됨).
- 예: "Ruby" 필터 → 새 시트로 복사 → **조건부 서식**으로 시간 변화 파악(1920년대 초 증가, 이후 감소, 2000년 이후 재부상). 차트로 시각화.
- **10년 이동 평균**: 11번째 행부터 `=AVERAGE(위 10개 값)` → 채우기 핸들로 아래로 복사. 차트에 추가하면 훨씬 부드럽고 **상승 추세가 명확**(최근 평탄화). 다만 과거만 보므로 실제 데이터보다 **뒤처짐**.

## 예시

### 이동 평균 계산 (n=4)
```
창1 [8,1,3,7] = 4.75
창2 [1,3,7,8] = 4.75
...
결과 길이 = 데이터 수 − (n−1)
Sheets: =AVERAGE(직전 n개 셀)  → 채우기 핸들로 복사
```

### n 크기의 영향
| n | 특성 |
|---|------|
| 큼 | 안정적·부드러움 |
| 작음 | 노이즈 많음 |

## 요약
- **이동 평균**은 노이즈를 평활화해 전체 추세를 드러내는 시계열 도구다.
- **단순 이동 평균**은 n기간 창의 평균을 이동시켜 계산하며, 결과는 원본보다 **n−1 짧고**, n이 클수록 부드럽다.
- 과거만 참조하므로 실제 데이터보다 **뒤처지며(lag)**, 아기 이름 "Ruby" 예에서 10년 이동 평균으로 재부상 추세를 명확히 확인했다.
- 다음 강의는 시계열 분석의 또 다른 도구 **퍼센트 변화(percent change)** 다.
