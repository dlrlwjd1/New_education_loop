# Percent Change

## 개요
- **퍼센트 변화(percent change)** 는 시계열이 언제 꾸준히/갑자기 변하는지 파악하는 도구로, **원시 차이(raw difference)보다 일관되게 해석**된다.
- 공식: **(현재값 − 이전값) ÷ 이전값 × 100**. 값이 오르면 양수, 내리면 음수.
- 아기 이름 "Ruby" 데이터에 적용해 급증·급감을 발견하고(1963년 Ruby Bridges), 조사·결론 도출이라는 **데이터 애널리틱스의 본질**을 보여준다.

## 내용

### 왜 퍼센트 변화인가
- 원시 차이는 규모가 커지면 의미가 흐려진다. 예: 8→1(차이 −7)과 108→101(차이 −7)은 같은 −7이지만 중요도가 다르다.
- 표준화: 차이 ÷ 이전값 × 100. → −7/8 = **−87.5%**, −7/108 = **−6%**. 한눈에 어느 쪽이 큰 변화인지 보임.
- 공식(일반화): `(xₜ − xₜ₋₁) / xₜ₋₁ × 100`. 양수=상승, 음수=하락.
- 태양광 예: day1→2 −87.5%(큰 하락), day2→3 (1→3) **+200%**. 작은 수는 변동성이 커서 일별 변화가 큼.

### 실전 — Ruby 이름
- 새 열에 두 번째 관측부터 `=(현재 count − 이전 count) / 이전 count`, **퍼센트 서식**. 첫 셀은 비교 대상이 없어 비움.
- 1880→1881 Ruby 여아 +29%. 채우기 핸들로 아래 복사.
- **조건부 서식 — 발산 색 스케일**: 퍼센트 변화의 중간값은 **0%**(양/음 경계)라 발산 스케일이 적절. 중간값 0, 낮음=파랑·높음=주황(색맹 고려).
- 패턴: 초기엔 꾸준한 증가, 1920년대 이후 꾸준한 감소. **1963년 +20% 급증**(감소 흐름 중) 발견 → 조사하니 1963년 생존 유명인 첫 인물 **Ruby Bridges**(루이지애나 통합 학교에 다닌 첫 흑인 아동, 1998년 디즈니 영화 소재)가 많은 부모에게 영감을 준 것으로 추정.
- 이것이 데이터 애널리틱스의 핵심 — **흥미로운 추세 포착 → 조사 → 유용한 결론**.

## 예시

### 퍼센트 변화 공식
```
percent change = (xₜ − xₜ₋₁) / xₜ₋₁ × 100
Sheets: =(현재셀 − 이전셀) / 이전셀   (퍼센트 서식)
```

### 원시 차이 vs 퍼센트 변화
| 변화 | 차이 | 퍼센트 변화 |
|------|------|-------------|
| 8→1 | −7 | −87.5% |
| 108→101 | −7 | −6% |

## 요약
- **퍼센트 변화 = (현재−이전)/이전 × 100** 으로, 규모가 다른 값들의 변화를 **일관되게 비교**한다(양수=상승, 음수=하락).
- 발산 색 스케일(중간값 0%)로 상승/하락 패턴을 시각화하면 급증·급감을 쉽게 포착한다.
- Ruby 데이터의 1963년 급증을 조사해 Ruby Bridges라는 배경을 찾은 것처럼, **추세 포착 → 조사 → 결론**이 데이터 애널리틱스의 본질이다.
- 이로써 모듈 2가 마무리되고, 다음 모듈은 **데이터 시각화**다.
