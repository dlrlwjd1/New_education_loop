# Conditional Formatting

## 개요
- **조건부 서식(conditional formatting)** 은 데이터에 규칙을 적용해 **시각적 레이어**를 씌워, 추세·변화·이상치·임계값 초과 여부를 한눈에 파악하게 한다.
- 두 주요 유형: **단일 색(single color)**(yes/no 조건 강조)과 **색 스케일(color scale)**(값 범위를 색 범위로) — 색 스케일은 **순차(sequential)** 와 **발산(divergent)** 으로 나뉜다.

## 내용

### 조건부 서식의 이점
- 각 데이터가 규칙과 어떻게 비교되는지 머릿속으로 평가할 필요 없이 시각 신호를 제공 → 추세·패턴 발견, 양/음 변화 식별, 이상치 식별, 임계값 초과/미달 값 식별이 쉬워짐. 수치·범주·날짜 모두 적용 가능.

### 유형
- **단일 색(single color)**: 특정 조건을 만족하는 셀 강조(yes/no). 폰트 스타일(굵게 등)도 지정 가능. 예: "8개 이상 판매한 날" 강조.
- **색 스케일(color scale)**: 값에 따라 색 적용(굵게·기울임 등 스타일은 불가 — 값에 스케일할 수 없으므로).
  - **순차(sequential)**: 같은 색의 점점 진한 음영.
  - **발산(divergent)**: 중심값을 기준으로 양쪽에 다른 색.

### 호텔 데이터 적용 예
- **아동 수(single color)**: 조건 "0보다 큼" → 파란색+굵게. (아동 있는 예약은 드물어 대부분 0.)
  - Format → Conditional Formatting → Single color → "greater than 0".
- **리드 타임(sequential color scale)**: 낮은 값=연함, 높은 값=진함(녹색). 긴 리드 타임(224·346일 등)이 진하게. 기업(corporate) 세그먼트로 필터하면 대체로 연해 → **기업 예약은 리드 타임이 짧다**는 인사이트.
- **객실 평균 가격(divergent color scale)**: 손익분기 45유로를 **중간값(midpoint, 숫자로 지정)** 으로, 아래=손실·위=이익. 색맹 고려해 빨강/녹색 대신 **주황(낮음)/파랑(높음)** 커스텀. 대부분 파랑(수익), 가끔 주황. complementary 세그먼트로 필터하면 대부분 0 또는 45유로 미만 → **비수익 예약**.

## 예시

### 조건부 서식 유형
| 유형 | 용도 | 예 |
|------|------|-----|
| 단일 색 | yes/no 조건 | 아동 있음(>0) 파랑+굵게 |
| 순차 색 스케일 | 값 범위(단색 농담) | 리드 타임(연함→진함) |
| 발산 색 스케일 | 중심값 기준 양쪽 | 가격(45유로 기준 주황/파랑) |

## 요약
- **조건부 서식**은 데이터에 시각적 레이어를 씌워 추세·이상치·임계값을 한눈에 보게 한다.
- **단일 색**은 yes/no 조건 강조, **색 스케일**은 값 범위 표현(순차=단색 농담, 발산=중심값 기준 양쪽 색).
- 호텔 데이터에서 아동 수·리드 타임·가격에 적용해 "기업 예약은 리드 타임이 짧다", "complementary는 비수익" 같은 인사이트를 얻었다(색맹 접근성도 고려).
- 다음 강의에서 조건부 **요약 통계**(COUNTIF 등)로 인사이트를 확장한다.
