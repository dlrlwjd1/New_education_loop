# Where Does Data Come From?

## 개요
- 데이터는 거의 어디서나 오지만, **수집 방식**과 **소유 주체(누가 수집했나)**, 그리고 **윤리적 사용**을 이해해야 한다.
- 수집 방식: **직접 입력·행동 관찰·물리 센서**. 소유 주체: **1st/2nd/3rd party**, 그리고 **공개 데이터**.
- 데이터 애널리스트는 숫자 계산을 넘어 **진실의 관리자·데이터 속 사람들의 옹호자**로서 윤리적 책임을 진다.

## 내용

### 수집 방식
- **직접 입력(direct input)**: 구조화된 절차로 명시적 제공(고객 피드백 설문, 병원 등록 양식).
- **행동 관찰(behavioral observation)**: 시스템이 행동을 수동적으로 관찰(웹 분석, 앱 사용, 소셜미디어 참여, 카지노 모니터링).
- **물리 센서(physical sensors)**: 현상을 지속 측정(스마트 온도조절기, 차량 주행 패턴, 위성 등).

### 소유 주체 (누가 수집했나)
- **1st party**: 내(회사)가 직접 소유(카지노가 자체 카메라 설치). **통제력 높음**.
- **2nd party**: 다른 회사의 1st party 데이터를 신뢰할 파트너에게서 취득(인접 호텔과 고객 데이터 공유). **통제력 높음**.
- **3rd party**: 여러 구매자에게 판매 목적으로 수집(온라인 도박 사이트 방문자 데이터 구매). 관측 수가 적거나 무관한 특성·체계적 부정확성이 있을 수 있어 **통제력 낮음**.
- **공개 데이터(publicly available)**: 정부·기관·오픈소스 DB 등. 대개 무료·실세계 데이터라 애널리스트에게 훌륭한 자원. 직접 다운로드하거나 **Python으로 스크래핑**.

### 윤리적 사용
- **인가된 데이터만** 분석. 금융·개인 건강 정보는 법적 보호 대상이라 교육·보안 환경이 필요할 수 있음. 이름·주소·주민번호 등 **개인식별정보(PII) 제거**가 필요할 때도(호텔 데이터도 PII 제거됨).
- 인사이트를 **공정·유익하게** 사용. 형사사법 등 삶에 큰 영향을 주는 모델이라면 **공정성·과거 차별 재생산 방지**를 고민하고, 의도치 않은 결과를 협업으로 검토하며, 비즈니스 결정이 **실제 사람들에게 미칠 영향**을 고려한다.

## 예시

### 수집 방식 · 소유 주체
| 축 | 유형 | 예 |
|----|------|-----|
| 수집 | 직접 입력 / 행동 관찰 / 센서 | 설문 / 웹 분석 / 위성 |
| 소유 | 1st / 2nd / 3rd party / 공개 | 자체 카메라 / 파트너 / 구매 / 정부 데이터 |

## 요약
- 데이터의 **수집 방식(직접 입력·행동 관찰·센서)** 과 **소유 주체(1st/2nd/3rd party·공개)** 를 이해하면 통제력·신뢰도를 가늠할 수 있다.
- 1st·2nd party는 통제력이 높고, 3rd party는 낮으며, 공개 데이터는 무료·실세계라 유용하다(스크래핑 가능).
- 애널리스트는 **인가된 데이터만·PII 보호·공정한 사용** 등 윤리적 책임을 지는 **진실의 관리자**다.
- 다음 레슨은 **LLM으로 데이터 탐색**이다.
