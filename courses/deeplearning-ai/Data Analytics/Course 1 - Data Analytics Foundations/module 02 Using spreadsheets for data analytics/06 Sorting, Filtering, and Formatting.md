# Sorting, Filtering, and Formatting

## 개요
- 데이터셋을 처음 탐색할 때 목표는 **이해하고 올바른 형식인지 확인**하는 것. 호텔 예약 데이터로 정렬·필터·서식을 실습한다.
- **열 이동**(수동), **행 정렬**(정렬 연산 — 단일/다중 기준), **필터**(부분집합 추출), **서식**(통화 등)을 다룬다.

## 내용

### 데이터 이해와 열 이동
- 주요 특성: 성인/아동 수, 도착 연·월·일, 필요 주차 공간, **리드 타임(lead time, 예약~체크인 일수)**, 객실 평균 가격(통화), **예약 상태(취소/미취소)**. 수치형·범주형이 섞여 있음.
- **열 이동**: 열들을 클릭&드래그로 선택해 원하는 위치로 이동(예: 날짜 열을 왼쪽으로).

### 정렬(sorting)
- 행 정렬은 (열 이동과 달리) 행이 많아 **수동이 아니라 정렬 연산**으로.
- **단일 기준**: 열 필터에서 A→Z 정렬(예: 연도).
- **다중 기준**: 전체 선택 → **Sort range → Advanced range sorting** → "헤더 행 있음" 체크 → 도착 연도 A→Z + 도착 월 A→Z + 도착 일 A→Z 추가 → Sort. 전체 도착일 순으로 정렬.
- 연·월·일을 **분리 저장**하는 이유: 여름철 등 월 단위 분석에 유리(단, 전체 날짜 열이 있으면 정렬은 더 쉬움).

### 필터(filtering)
- 데이터를 부분집합으로 축소. 예: **재방문 고객(repeated guest)** 열에서 값 1만 선택 → 재방문 예약만 표시. 열 선택 후 헤더 제외하면 930건 재방문 예약 확인(상당수가 기업 고객).

### 서식(formatting)
- 객실 평균 가격을 **통화(euro)** 로 서식: 열 선택 → 통화($ 기본, 유로는 **More formats → 커스텀 통화**에서 선택) → 앞에 기호 + 소수점 2자리.

## 예시

### 정렬·필터·서식 요약
| 작업 | 방법 |
|------|------|
| 열 이동 | 클릭&드래그 |
| 단일 정렬 | 열 필터 A→Z |
| 다중 정렬 | Sort range → Advanced(연·월·일 순) |
| 필터 | 열 값 선택(예: repeated guest=1) |
| 통화 서식 | More formats → 커스텀 통화(euro) |

## 요약
- 데이터 탐색의 첫 목표는 **이해 + 형식 확인**이며, 호텔 예약 데이터로 정렬·필터·서식을 익힌다.
- **열은 드래그로 이동**, **행은 정렬 연산**(단일/다중 기준)으로 정리하고, **필터**로 부분집합(재방문 고객 등)을 추출한다.
- 통화 등 **서식**으로 데이터를 읽기 쉽게 만든다. 다음 레슨에서 데이터의 출처·알아가기·수식 작성을 다룬다.
