# Data Exploration with LLMs

## 개요
- LLM으로 데이터셋을 탐색하는 **세 가지 방식**을 호텔 예약 데이터로 실습한다: ① 정보 없이 **브레인스토밍**, ② **데이터 업로드 후 읽기 질문**, ③ **코드 실행 기능(advanced data analytics)** 으로 정확한 계산.
- LLM은 **읽기·쓰기에 강하고 수학엔 약하므로** 강점에 맞춰 질문하고, 코드 실행 기능이 있으면 수학·시각화도 정확히 수행한다.

## 내용

### ① 브레인스토밍 (데이터 없이)
- LLM이 전체 데이터셋을 이해하는 게 아니므로 개념 브레인스토밍. "호텔 예약 데이터는 어떻게 생성되나?" → 처음엔 질문을 오해할 수 있으니 **후속 프롬프트로 명확화**("실제 데이터셋이 있는데 이런 데이터가 어디서 오는지 궁금") → 호텔 예약 시스템·OTA·호텔 체인 등 출처 제시.
- 원문 초록·사양 표를 붙여 요약 요청도 가능(여러 질문을 한 프롬프트에 결합). 너무 길면 "더 간결히"로 축약.

### ② 데이터 업로드 후 읽기 질문
- 클립 아이콘으로 데이터셋 업로드(드래그). **매 질문마다 전체 데이터를 다시 읽으므로 클수록 느림** → 200행 축약본 사용.
- "이 데이터는 무엇에 관한 것?" → 호텔 예약임을 파악하고 분석 아이디어(예약 패턴·취소율·가격 등) 제안.
- "결측값(missing values)이 있나?" → **체계적 분석은 못 하지만** 대부분 0인 특성이나 이상값(가격 1) 같은 관찰 제시. 확실히 하려면 Python으로 로드해 검사.

### ③ 코드 실행 기능 (정확한 계산)
- ChatGPT Pro의 **advanced data analytics** 는 **코드를 작성·실행**한다. 매번 프롬프트로 직접 읽지 않아 큰 파일 처리 가능(전체 업로드).
- **주의**: 익명화된 공개 데이터만 업로드 — 독점 데이터는 제공사가 어떻게 쓸지 통제 불가.
- 예: 관측 36,000+·특성 19개(정확), 시간순 정렬 여부, 아동 수 범위(0~10) **히스토그램 시각화**(대부분 0, 10은 거의 안 보임), "한 달 이상 전 예약 비율" → 약 66.5% + 그래프.
- LLM이 **추측이 아니라 코드로 정확히 계산**한다는 점이 핵심.

## 예시

### LLM 데이터 탐색 3방식
| 방식 | 특징 | 유의 |
|------|------|------|
| 브레인스토밍 | 데이터 없이 개념 | 후속 프롬프트로 명확화 |
| 업로드+읽기 | 데이터 첨부 후 질문 | 매 질문 전체 읽기(느림), 체계적 수학 X |
| 코드 실행 | 코드 작성·실행 | 정확한 계산·시각화, 공개 데이터만 업로드 |

## 요약
- LLM으로 데이터를 탐색하는 세 방식: **브레인스토밍(데이터 없이)·업로드 후 읽기 질문·코드 실행 기능**.
- LLM은 읽기·쓰기에 강하고 수학엔 약하므로, 정확한 계산·시각화가 필요하면 **코드 실행 기능**을 쓴다(공개 데이터만 업로드).
- 후속 질문으로 명확화하고 회의적 태도를 유지한다. 다음 강의는 **개인정보(LLMs and privacy)** 다.
