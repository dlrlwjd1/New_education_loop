# Introduction to Time Series

## 개요
- **시계열(time series) 데이터** 는 하나 이상의 결과를 **일정한 시간 간격**으로 측정한 것으로, 시간에 따른 변화(추세·이상 사건·미래 예측)를 이해하는 것이 목표다.
- **일정한 간격**이 중요하다 — 일관된 기준이 있어야 시간 길이 계산이 아니라 결과 자체를 비교할 수 있다.
- 시계열은 **4가지 구성 요소**로 분석한다: **추세(trend)·계절성(seasonality)·주기적 변동(cyclical)·불규칙성(irregularities/noise)**.

## 내용

### 시계열 vs 횡단면
- **시계열**: 한 결과를 여러 시점에 측정(강수량 연간, 주간 활성 사용자, 월/분기 매출, 주가 등). 간격은 분·시·일·월 등 용도에 따라.
- **일정 간격의 중요성**: 간격이 들쭉날쭉하면(중간 구간만 2배 길면) 없는 급증처럼 보일 수 있다. 속도 단위가 계속 바뀌면 변환에만 신경 쓰게 되는 것과 같다.
- **횡단면(cross-sectional)**: 시계열을 뒤집은 것 — 한 시점에 여러 측정. 각 관측이 **일회성 사건**(호텔 예약 각 건).

### 4가지 구성 요소
- **추세(trend)**: 장기 방향 — **증가/감소/정체(stationary=추세 없음)**. 예: 55년간 미국 주식시장은 증가 추세.
- **계절성(seasonality)**: **규칙적 간격**의 반복·예측 가능한 패턴(일·주·월·연). 예: 영화표가 주말에 높음, 여름·휴일에 매년 반복. (기상 계절과 무관해도 됨)
- **주기적 변동(cyclical fluctuations)**: **불규칙 간격**의 반복 등락, 크기도 제각각이라 예측이 어려움. 예: 닷컴 버블·2008 금융위기·팬데믹 같은 주식시장 거품·폭락.
- **불규칙성/노이즈(irregularities/noise)**: 무작위·예측 불가한 변동. 추세·계절성·주기성을 알아보기 어렵게 만드는 배경 잡음(통화 잡음에 비유).

### 계절성 vs 주기성 예시 (도서관)
- 학기 초 공부 적게 → 시험 때 많이 = **계절성**(매 학기 규칙적 반복).
- 2~3년마다 부정기적으로 일어나는 도서관 공사 = **주기성**(주기적이나 불규칙 간격).
- 현실 데이터는 명확히 나뉘지 않고 **예측 가능성 스펙트럼의 중간**에 있는 경우가 많다.

## 예시

### 4가지 구성 요소
| 요소 | 특징 | 예 |
|------|------|-----|
| 추세 | 장기 방향(증가/감소/정체) | 주식시장 장기 상승 |
| 계절성 | 규칙적 반복 | 주말·여름 영화표 |
| 주기성 | 불규칙 간격 반복 | 버블·폭락 |
| 불규칙성(노이즈) | 무작위 변동 | 특정 일요일의 낮은 판매 |

## 요약
- **시계열**은 결과를 **일정 간격**으로 측정한 데이터로, 일정 간격이 있어야 결과 자체를 비교할 수 있다(횡단면과 대비).
- 4가지 구성 요소는 **추세(장기 방향)·계절성(규칙적 반복)·주기성(불규칙 반복)·불규칙성(노이즈)** 이다.
- **계절성 = 규칙적, 주기성 = 불규칙**이 핵심 구분이며, 현실 데이터는 그 중간에 놓이기도 한다.
