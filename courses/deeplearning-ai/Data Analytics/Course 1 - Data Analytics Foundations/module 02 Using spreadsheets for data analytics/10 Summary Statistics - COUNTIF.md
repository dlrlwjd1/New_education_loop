# Summary Statistics – COUNTIF

## 개요
- 특성이 많은 데이터셋은 **세그먼트(segment)** 로 나눠 그룹을 이해하는 것이 좋은 전략이다.
- **COUNTIF** 함수는 주어진 범위에서 **조건을 만족하는 셀만 세는** 조건부 집계다(필터와 비슷하되 표시가 아니라 카운트).
- 결과를 **총합으로 나누어 백분율**로 보면 해석이 쉽다(퍼센트 서식 활용).

## 내용

### COUNTIF 함수
- 조건(condition)이 충족될 때만 동작하는 **조건부(conditional)**. 필터와 유사하나 표시가 아니라 **개수 집계**.
- 형식: `=COUNTIF(범위, 기준)` — 입력 2개(range, criteria). 기준은 따옴표 안에("Hot Pocket"), 숫자는 `">100"`, `"<=0"` 등.
- 모든 수식은 **`=`** 로 시작(없으면 텍스트로 취급). 함수명 대소문자는 무관하지만 **기준의 문자는 정확해야** 한다(대소문자는 무관하나 하이픈 등 특수문자는 정확히).

### 예시 — 예약 취소 분석
- **취소(canceled)**: `=COUNTIF(booking status 열, "canceled")` → 약 12,000건(하루 ~17건).
- **미취소(not canceled)**: 약 24,000건(약 2배).
- 두 값 합 = 약 36,000 = 전체 관측 수(두 범주가 전체를 이룸).

### 백분율로 해석
- 11,000 / 36,000 같은 계산을 머리로 하기 어려우니, **count ÷ 총합** 을 계산하고 **퍼센트 서식**으로 표시(×100 대신).
- 취소·미취소 비율의 합 = **100%**. 취소가 예상보다 많다는 인사이트.

## 예시

### COUNTIF 사용
```
=COUNTIF(booking_status, "canceled")     → 취소 건수
=COUNTIF(booking_status, "not canceled") → 미취소 건수
취소율 = 취소건수 / 총합   (퍼센트 서식)
```

## 요약
- 특성이 많으면 **세그먼트**로 나눠 이해하고, **COUNTIF(범위, 기준)** 로 조건을 만족하는 셀을 센다(수식은 `=`로 시작, 기준 문자는 정확히).
- 호텔 데이터에서 취소 ~12,000·미취소 ~24,000(합=전체 36,000)을 계산하고, **총합으로 나눠 백분율**로 해석했다(합 100%).
- 다음 강의에서 조건부 **합계**(SUMIF·AVERAGEIF)를 다룬다.
