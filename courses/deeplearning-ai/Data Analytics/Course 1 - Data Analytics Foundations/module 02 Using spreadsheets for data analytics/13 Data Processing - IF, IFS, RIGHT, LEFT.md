# Data Processing – IF, IFS, RIGHT, LEFT

## 개요
- 데이터를 있는 그대로 쓸 필요는 없다 — 문제 해결에 맞게(유효한 범위에서) **처리(process)** 할 수 있다.
- 세 가지 처리 기법: **범주 그룹화(IF)**, **텍스트 처리(RIGHT·LEFT)**, **비닝(binning, IFS)**.

## 내용

### 범주 그룹화 — IF
- 유사한 관계의 범주를 합치거나, 빈도가 낮은 범주를 "기타"로 묶어 분석을 깔끔하게. 예: 식사 플랜을 Yes/No로 축소.
- **IF** 는 조건부 함수 — 조건을 검사해 참/거짓에 따라 다른 값 반환. 형식: `=IF(논리식, 참일때, 거짓일때)`.
  - 예: `has_meal_plan` 열 — `=IF(값="Not Selected", 0, 1)` → 식사 플랜 없으면 0, 있으면 1. (COUNTIF와 달리 셀·조건이 아니라 **전체 논리식**을 입력)
  - 결과를 0/1로 만들면 대부분 식사 플랜이 있음을 한눈에 파악하고 조건부 서식도 쉽게 적용 가능.

### 텍스트 처리 — RIGHT / LEFT
- 범주 이름 변경·일부 추출로 읽기 쉽게. **RIGHT·LEFT** 는 오른쪽/왼쪽 문자를 새 셀로 추출.
- 예: 객실 유형(room type)에서 번호만 추출 — `=RIGHT(값, 1)` (가장 오른쪽 1글자). 채우기 핸들 더블클릭으로 전체 복사.

### 비닝(binning) — IFS
- 수치형을 **범주(구간)** 로 묶기. 수치와 결과의 직접 관계가 불분명할 때 유용(예: 22세 vs 24세 차이가 크지 않으면 연령대로 묶기).
- **IFS** 는 **여러 조건**을 검사 — 논리식 + 그 조건일 때 값을 반복. 형식: `=IFS(조건1, 값1, 조건2, 값2, ...)`.
  - 예: 리드 타임을 short(<50)·medium(<100)·long(≥100)으로 비닝. `=IFS(리드타임<50, "short", 리드타임<100, "medium", 리드타임>=100, "long")`.
  - 비닝하면 개별 리드 타임을 필터하는 것보다 훨씬 쉽게 조건별 필터링 가능.

## 예시

### 처리 함수
```
=IF(값="Not Selected", 0, 1)                         → 범주 그룹화(Yes/No)
=RIGHT(값, 1)                                        → 오른쪽 1글자 추출
=IFS(x<50,"short", x<100,"medium", x>=100,"long")   → 비닝
```

### 기법과 함수
| 기법 | 함수 | 예 |
|------|------|-----|
| 범주 그룹화 | IF | 식사 플랜 → 0/1 |
| 텍스트 처리 | RIGHT/LEFT | 객실 유형 번호 추출 |
| 비닝 | IFS | 리드 타임 short/medium/long |

## 요약
- 데이터는 문제에 맞게 **처리**할 수 있으며, 대표 기법은 **범주 그룹화(IF)·텍스트 처리(RIGHT/LEFT)·비닝(IFS)** 이다.
- **IF/IFS** 는 셀·조건을 따로 받지 않고 **전체 논리식**을 입력받으며, IFS는 여러 조건을 순차 검사한다.
- 이런 처리는 이후 분석·필터링을 훨씬 쉽게 만든다. 다음 강의는 데이터가 어디서 오는지와 분석에 미치는 영향을 다룬다.
