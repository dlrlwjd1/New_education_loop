# Navigating Google Sheets

## 개요
- **Google Sheets** 는 접근성 좋고 무료이며 협업 가능한 대표 스프레드시트 앱. 여기서 배우는 기술은 Excel·Apple Numbers 등에도 **이전 가능(transferable)**.
- 홈 리노베이션 거래 데이터를 예로, 셀 탐색·서식·합계·정렬·필터·계산 열 추가 등 기본 기능으로 인사이트를 얻는 데모다.
- (세부 단계 암기보다 **어떤 기능이 가능한지** 파악이 목적)

## 내용

### 기본 탐색
- 새 시트: `sheets.new` 또는 Google Drive에서 생성. 상단 메뉴·서식 리본 제공.
- **셀(cell)**: 행과 열의 교차점. 클릭/더블클릭/수식 입력창으로 편집. 클릭&드래그로 여러 셀·행·열 선택. **방향키**로 이동, **Command+화살표**로 데이터 끝까지 이동, **Shift**로 다중 선택, **Command+Shift+화살표**로 행/열 전체 선택.

### 데이터 정리·서식
- 열 헤더 경계 더블클릭 → 자동 너비 확장. 헤더 행 굵게 + 하단 경계 + 배경색 + 가운데 정렬로 데이터와 구분.
- (개별 서식 단계 암기 불필요 — 기능 파악에 집중)

### 요약·수식
- 셀 범위 선택 시 우하단에 **합계 요약** 표시(예산 총 $1,860 vs 비용 $1,663.44 → 예산 내).
- **SUM 함수**: `=SUM(범위)` 로 합계. 총계 행 추가해 예산·비용 비교.
- 행 삽입: 행 헤더 우클릭 → 위/아래 삽입. 삽입 시 **총계 자동 갱신**.

### 정렬·필터
- **필터(깔때기 버튼)**: 열 헤더 필터로 정렬(A→Z 오름차순 등). 예: 거래일 정렬로 첫 거래(건축 허가) 확인.
- 값 필터링: paid_by 열에서 특정 인물(Joy)만 필터 → Joy가 구매한 항목 확인. 카테고리(labor)만 필터해 총 노동비 계산.

### 계산 열 추가
- 새 열 삽입(열 우클릭 → 오른쪽에 삽입) → **difference = 예산 − 비용** 수식 입력 → **채우기 핸들(fill handle)** 을 드래그해 아래로 복사 → 정렬로 가장 초과/절감된 항목 확인(식물이 가장 초과, 배관 수리는 절감).

## 예시

### 주요 기능
| 작업 | 방법 |
|------|------|
| 셀 이동 | 화살표, Command+화살표, Shift 선택 |
| 합계 | 범위 선택(우하단 요약) 또는 `=SUM(범위)` |
| 정렬/필터 | 필터(깔때기) → A→Z, 값 선택 |
| 계산 열 | 새 열 + 수식 + 채우기 핸들 드래그 |

## 요약
- **Google Sheets** 는 무료·협업 가능한 스프레드시트로, 배운 기술은 Excel 등에 이전 가능하다.
- 셀 탐색·서식·**SUM**·정렬/필터·**계산 열(채우기 핸들)** 로 원시 텍스트보다 훨씬 효과적으로 인사이트(예산 초과 여부, 첫 거래, 담당자별 구매, 최대 초과 항목)를 얻는다.
- 세부 단계 암기보다 **가능한 기능**을 파악하는 것이 핵심. 다음 강의는 **데이터 가져오기(importing data)** 다.
