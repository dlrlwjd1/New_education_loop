# Summary Statistics – COUNTIFS, SUMIFS

## 개요
- COUNTIF·SUMIF는 조건 하나만 검사하지만, **COUNTIFS·SUMIFS** 는 **여러 조건**을 동시에 검사한다(예: 예약 상태 × 마켓 세그먼트).
- **UNIQUE** 로 고유 범주를 뽑고, **채우기 핸들(fill handle)** 로 수식을 복사할 때 **상대 참조 vs 절대 참조($)** 를 구분해야 한다.

## 내용

### UNIQUE로 범주 파악
- `=UNIQUE(M2:M...)` → 마켓 세그먼트 열의 **고유 범주** 목록(헤더 제외 위해 M2부터).

### COUNTIFS (다중 조건 카운트)
- 예: 예약 상태=canceled **그리고** 마켓 세그먼트=offline인 건수. `=COUNTIFS(booking status, "canceled", market segment, A22)`.
  - 조건값을 직접 타이핑하지 않고 **셀 참조(A22="offline")** 로 두면 나중에 복사가 쉽다.
  - 결과: canceled·offline 3,153건. 대부분 취소는 **online**, 그다음 offline.

### 상대 참조 vs 절대 참조($)
- **채우기 핸들**로 수식을 복사하면 **상대 참조**가 자동 이동한다.
- 백분율 계산(취소수 ÷ 총합)에서 문제 발생: 아래로 채우면 **두 참조가 모두 이동** → 총합 셀이 빈 셀을 가리켜 **#DIV/0!** 오류.
- 해결: 고정하려는 참조에 **`$`(절대 참조)**. 예: 총합이 27행에 있으면 `$27`로 행 고정.
  - `$` 앞 대상: 행 고정 = `A$27`, 열 고정 = `$A27`, 셀 전체 고정 = `$A$27`.

### SUMIFS (다중 조건 합계)
- 예: **total value = 객실 평균가 × (주중일수 + 주말일수)** 열을 만든 뒤, 예약 상태 × 마켓 세그먼트별 총매출.
- `=SUMIFS(total value, booking status, $취소셀, market segment, 왼쪽 세그먼트셀)` — 합계 범위 먼저, 이어서 조건 범위·조건 쌍. 행 고정엔 `$`.
- 결과: canceled·offline ≈ 90만 유로. 취소 예약 총매출 ≈ **400만 유로**, 미취소 ≈ **700만+ 유로** → 취소로 놓친 매출이 상당.

## 예시

### 다중 조건 함수
```
=COUNTIFS(예약상태, "canceled", 세그먼트, A22)
=SUMIFS(total_value, 예약상태, $취소셀, 세그먼트, 세그먼트셀)
백분율 = 카운트 / 총합($행 고정)   → 채우기 핸들로 복사
```

### 참조 유형
| 표기 | 고정 대상 |
|------|-----------|
| A27 | 상대(둘 다 이동) |
| A$27 | 행 고정 |
| $A27 | 열 고정 |
| $A$27 | 셀 전체 고정 |

## 요약
- **COUNTIFS·SUMIFS** 로 여러 조건(예약 상태 × 세그먼트)을 동시에 집계하며, **UNIQUE** 로 범주를 파악한다.
- 채우기 핸들 복사 시 이동하면 안 되는 참조(총합 셀 등)는 **`$`(절대 참조)** 로 고정한다.
- 호텔 데이터에서 세그먼트·취소 여부별 건수·총매출을 계산해, 취소로 인해 놓친 매출(약 400만 유로)을 확인했다.
- 다음 강의는 **데이터 처리(data processing)** 기법이다.
