# Summary Statistics – SUMIF, AVERAGEIF

## 개요
- **SUMIF** 는 조건을 만족하는 셀들의 값을 **합산**하고, **AVERAGEIF** 는 **평균**을 낸다 — COUNTIF의 사촌 격 조건부 함수.
- 한 범위를 조건으로 검사하고 **다른 범위를 합/평균** 할 수 있어, 데이터를 조건별로 세그먼트해 분석한다.

## 내용

### SUMIF
- 조건을 만족하는 셀만 합산. 형식: `=SUMIF(범위, 조건, 합계범위)` — 입력 3개(range, condition, sum_range). 검사할 범위(IF 대상) → 조건(따옴표) → 합할 열.
- 예 — 아동 수를 성인 유무로 세그먼트:
  - 성인 없이 온 아동: `=SUMIF(성인수, "=0", 아동수)` → 약 282명.
  - 성인 동반 아동: `=SUMIF(성인수, ">0", 아동수)` → 3,500명 이상.
  - 백분율: 282 / 전체 아동 → 약 **7.38%가 성인 없이** 여행, 약 92%는 동반(합 100%).

### AVERAGEIF
- SUMIF와 입력은 같되 합 대신 **평균**. 예 — 취소 여부별 리드 타임:
  - 취소된 예약 평균 리드 타임: `=AVERAGEIF(booking status, "canceled", lead time)` → 약 **139일**.
  - 미취소 평균: 약 **58~59일**.
  - 전체 평균(AVERAGE): 약 85일(미취소가 2/3라 그쪽에 가중).
- 해석: 취소 예약은 평균 ~4개월 전 예약(계획된 휴가가 변경됐을 가능성), 미취소는 ~2개월 전(계획이 더 확정적). 리드 타임이 취소와 관련 있어 보이나 정확한 이유는 추가 분석 필요.

## 예시

### SUMIF / AVERAGEIF
```
=SUMIF(성인수, "=0", 아동수)            → 성인 없는 아동 합
=SUMIF(성인수, ">0", 아동수)            → 성인 동반 아동 합
=AVERAGEIF(예약상태, "canceled", 리드타임) → 취소 예약 평균 리드타임
```

## 요약
- **SUMIF(범위, 조건, 합계범위)** 는 조건을 만족하는 값의 합, **AVERAGEIF** 는 평균을 낸다(검사 범위와 합/평균 범위를 다르게 지정 가능).
- 호텔 데이터에서 성인 유무별 아동 합(7.38%가 성인 없이 여행)과 취소 여부별 평균 리드 타임(취소 139일 vs 미취소 59일)을 계산해 세그먼트 인사이트를 얻었다.
- 다음 강의에서 **다중 조건**(COUNTIFS·SUMIFS)을 다룬다.
