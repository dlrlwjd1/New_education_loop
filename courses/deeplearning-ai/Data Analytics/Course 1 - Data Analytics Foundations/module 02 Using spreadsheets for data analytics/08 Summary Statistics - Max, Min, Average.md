# Summary Statistics - Max, Min, Average

## 개요
- 데이터의 출처를 알았다면, **요약 통계(summary statistics)** 를 계산해 특성을 이해한다 — 분포(distribution)·범위(range)·전형적 값, 그리고 **특성 간 관계**.
- Google Sheets 함수 **MIN·MAX·AVERAGE** 로 호텔 데이터의 성인 수·아동 수·리드 타임을 탐색하며 **이상치(outlier)** 를 발견한다.

## 내용

### 요약 통계로 무엇을 볼까
- **분포(distribution)**: 예) Netflix 연령대별 빈도 → 구독자층이 젊은지 나이 든지, 콘텐츠 제작에 반영.
- **범위(range)·전형적 값**: 예) 구독 기간의 최소(신규 프로모션 3개월)·최대(서비스 출시 이후 2년)·평균.
- **특성 간 관계**: 연령대별 구독 기간 차이 등.
- **데이터셋 간 관계**: 공통 특성으로 연결(영화 데이터 ↔ 사용자 데이터, 시청 영화로 연결).

### 함수 사용법 (호텔 데이터)
- 함수는 **`=`** 로 시작, 함수명 + 괄호 안에 범위 → 예: `=MIN(성인수 열)`.
- **성인 수(adults)**: MIN=0(?!), MAX=4, AVERAGE≈1.84.
  - 성인 0인 이유? → **아동(children)** 이 있는 예약. 성인 수 오름차순 정렬 시 139건이 성인 0 + 아동 있음.
- **아동 수(children)**: MIN=0(대부분), 평균 0.11(대부분 0), 그러나 **MAX=10**. 내림차순 정렬 시 10·9·9 등 소수 이상치.
- **리드 타임(lead time, 예약~체크인 일수)**: MAX가 평균보다 훨씬 큼, 0(막판 예약)도 존재. 내림차순 정렬 시 443·433·418일 다수 → 이들의 **도착일이 동일** → 결혼식·컨퍼런스 같은 **단체 예약(bulk reservation)** 으로 추정.

## 예시

### 함수와 결과
| 함수 | 형식 | 성인 수 결과 |
|------|------|-------------|
| MIN | `=MIN(범위)` | 0 |
| MAX | `=MAX(범위)` | 4 |
| AVERAGE | `=AVERAGE(범위)` | 1.84 |

### 발견한 이상치
- 성인 0 + 아동 있음(139건), 아동 10명(소수), 리드 타임 443일(동일 도착일 = 단체 예약 추정)

## 요약
- **요약 통계**(MIN·MAX·AVERAGE)로 특성의 분포·범위·전형적 값과 관계를 파악한다(함수는 `=함수명(범위)`).
- 호텔 데이터에서 성인 0(아동 예약)·아동 10명·리드 타임 443일 같은 **이상치**를 발견하고, 정렬로 그 배경(단체 예약 등)을 추정했다.
- 이런 탐색은 데이터를 이해하는 핵심이며(추후 프로그래밍으로 더 빠르게 가능), 다음 강의는 **조건부 서식(conditional formatting)** 이다.
