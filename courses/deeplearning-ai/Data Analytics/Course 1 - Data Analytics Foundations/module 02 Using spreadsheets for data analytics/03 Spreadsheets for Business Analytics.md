# Spreadsheets for Business Analytics

## 개요
- **스프레드시트(spreadsheet)** 는 정형 데이터에 상호작용성을 부여하는 **업계 표준 도구**로, 무료로 몇 초 만에 열 수 있고 개인·비즈니스 용도가 광범위하다.
- 스프레드시트는 **정형 데이터**(행=관측치 observation, 열=특성 feature)에 주로 쓰이며, 비정형 데이터 분석에는 한계가 있다.
- 적합성 판단 두 질문: **① 행·열로 조직 가능한가? ② 데이터 측면 간 관계를 탐색하고 싶은가?**

## 내용

### 스프레드시트의 활용
- 구글·넷플릭스 등에서 상시 사용되는 업계 표준. 개인(핑퐁 점수, 가계부)부터 비즈니스(교대 근무 편성, 프로젝트 타임라인, 분기 재무 보고서)까지. **구조화된 방식으로 데이터를 수집·저장할 수 있으면** 거의 무한한 용도.

### 정형 데이터 중심
- 행 = **관측치(observation)**(고객 하나, 거래 하나), 열 = **특성(feature)**(나이·가격·색 등 각 관측치에 대해 측정하는 것).
- **비정형 데이터**(텍스트·이미지·오디오·비디오)는 수집·정리는 가능하나 **분석 능력이 제한적**(스프레드시트에서 에세이 쓰기나 사진 정리를 상상해 보라). 비정형이 필요하면 **Python이나 생성형 AI** 를 활용.

### 스프레드시트 적합성 판단
1. **행·열로 조직 가능한가?** — 스프레드시트의 근본. 가계부(지출당 한 행, 금액·거래일 열)는 가능, 에세이는 불가.
2. **데이터 측면 간 관계를 탐색하고 싶은가?** — 스프레드시트는 관계 계산에 능함(지출을 카테고리별 정리, 가장 많이 쓴 달 분석 등).
- 두 질문에 모두 "예"면 스프레드시트가 훌륭한 도구.

## 예시

### 스프레드시트 vs 다른 도구
| 데이터 | 스프레드시트 |
|--------|--------------|
| 정형(행·열) | 적합(분석 강력) |
| 비정형(텍스트·이미지 등) | 수집·정리는 가능, 분석 한계 → Python·생성형 AI |

## 요약
- **스프레드시트**는 정형 데이터용 업계 표준 도구로, 무료·즉시 사용 가능하며 개인·비즈니스에서 광범위하게 쓰인다.
- 행=관측치, 열=특성 구조에 적합하고, 비정형 데이터 분석에는 한계가 있어 Python·생성형 AI로 보완한다.
- 적합성은 **① 행·열 조직 가능 여부 ② 측면 간 관계 탐색 필요 여부** 로 판단한다.
