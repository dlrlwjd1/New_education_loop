# Collaborators on Your Data Team

## 개요
- 성숙한 데이터 팀의 세 핵심 역할: **데이터 엔지니어, 데이터 애널리스트, 데이터 사이언티스트**. 각자 데이터 생태계의 다른 단계에 시간을 배분한다.
- 데이터 애널리스트는 **가장 폭넓은 기술**(SQL·시각화·프로그래밍·이해관계자 관리)을 다루며, 인사이트 발견·소통에 집중한다.
- 조직이 성숙·데이터 중심이 될수록 역할이 **세분화**된다(초기 스타트업은 한 사람이 전 영역 담당).

## 내용

### 데이터 팀의 책임 (단계)
- 수집(collection)·저장(storage)·전처리(pre-processing)·핵심 통계 기반 인사이트·고급 통계/ML 기반 인사이트·시각화·이해관계자 소통. (비즈니스 문제 이해는 모두의 공통 책임.)

### 세 핵심 역할과 시간 배분
- **데이터 엔지니어(data engineer)**: 주로 **수집·저장**. 여러 소스에서 데이터를 포착해 분석 위치로 옮기는 **데이터 파이프라인** 구축. 일부 전처리, 약간의 이해관계자 소통.
- **데이터 애널리스트(data analyst)**: 데이터에서 인사이트를 **발견·소통**. 분석용 형식을 위한 전처리, **핵심 방법**으로 비즈니스 문제 관련 인사이트, 시각화, 그리고 **소통에 큰 비중**. 가장 폭넓은 기술(SQL·시각화·프로그래밍·이해관계자 관리).
- **데이터 사이언티스트(data scientist)**: 더 깊은 기술 적용. 전처리 후 대부분 시간을 **ML 등 복잡한 방법**의 인사이트 발견에. 실험 설계·예측 모델·새 알고리즘 개발, 일부 시각화·이해관계자 소통.

### 하이브리드 역할과 중개자 성격
- **하이브리드 역할**: 소프트웨어 엔지니어링 기술을 결합 — **시각화 엔지니어**(데이터 분석+SW), **ML 엔지니어**(ML+SW) 등.
- 이 역할들은 데이터 생태계의 **중개자(intermediary)** — 데이터를 만들지도, 최종 분석을 소비하지도 않는다. 한쪽의 요구·유스케이스를 이해해 자기 전문 영역으로 번역하고, 사슬의 다음 역할과 협업해 해결책을 전달.

### 성숙도와 세분화
- 조직이 성숙·데이터 중심이 될수록 역할이 세분화된다. 초기 스타트업은 한 사람이 엔지니어링~분석 전 영역을 담당하지만, 성장하며 데이터 니즈가 복잡해지면 **세분화**로 각 단계의 가치를 극대화.
- 데이터 생태계의 묘미: 다양한 기술·배경·성격의 사람들이 **같은 목표**로 협업한다.

## 예시

### 역할별 주 담당
| 역할 | 주 담당 |
|------|---------|
| 데이터 엔지니어 | 수집·저장(파이프라인) |
| 데이터 애널리스트 | 인사이트 발견·시각화·소통(폭넓음) |
| 데이터 사이언티스트 | ML 등 복잡한 인사이트·모델링 |
| 하이브리드(시각화/ML 엔지니어) | 데이터 + SW 엔지니어링 |

## 요약
- 데이터 팀의 세 핵심 역할은 **엔지니어(수집·저장)·애널리스트(인사이트·소통)·사이언티스트(ML·모델링)** 이며 책임이 일부 겹쳐 협업이 활발하다.
- 애널리스트는 **가장 폭넓은 기술**을 다루고 인사이트 발견·시각화·소통에 집중한다.
- 하이브리드 역할은 데이터+SW를 결합한 **중개자**이며, 조직이 성숙할수록 역할이 세분화된다.
- 다음 레슨에서 데이터 애널리틱스를 위한 **LLM**(강점·한계)과 실습을 다룬다.
