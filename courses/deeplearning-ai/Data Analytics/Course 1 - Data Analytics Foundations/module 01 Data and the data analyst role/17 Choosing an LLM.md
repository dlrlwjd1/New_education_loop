# Choosing an LLM

## 개요
- 사용 가능한 LLM은 많고 계속 늘어난다. 서로 다른 동료에게 다른 질문을 하듯, **작업에 맞는 LLM을 선택**할 수 있다.
- 대표 제공사: OpenAI, Anthropic, Meta, Google. 각각 강점·소통 스타일이 다르다.
- **폐쇄형(closed) LLM** vs **개방형(open) LLM** 의 차이를 고려해 선택하고, 두 유형을 직접 실험해 보라.

## 내용

### 인기 LLM
- 녹화 시점 강력한 선택지: OpenAI의 ChatGPT(o3, 4o), Anthropic의 Claude 3.5, Meta의 Llama 3.2, Google의 Gemini Pro. 각기 강점·어조가 달라 선호가 갈릴 수 있다.
- 일부는 **웹/모바일 인터페이스**로 편하게 쓰고, 일부는 서드파티 프로그램이나 Python이 필요. 이 코스는 **내장 웹 인터페이스**로 LLM과 대화한다(프롬프트 입력 → 중앙에 응답 표시).

### 폐쇄형(closed) vs 개방형(open)
- **폐쇄형(closed)**: ChatGPT·Claude·Gemini 등. 만든 기술은 알지만 세부는 모르는 **블랙박스**.
  - 최상위 티어는 **유료**, 응답 품질이 대체로 우수, **더 안전·덜 논쟁적**인 답 경향.
- **개방형(open)**: Llama 3 등. 코드가 공개되어 누구나 다운로드·커스터마이즈 가능.
  - 자기 컴퓨터에서 돌리면 **무료**(또는 서드파티 클라우드), 품질은 좋지만 최첨단은 아님(격차는 줄어드는 추세), 때때로 더 **과감·예측 불가**한 응답.
- 둘 다 장점이 있으니 작업에 맞게 고르고, 두 유형을 **직접 실험**해 보라.

## 예시

### closed vs open
| 구분 | 폐쇄형(closed) | 개방형(open) |
|------|----------------|--------------|
| 예 | ChatGPT·Claude·Gemini | Llama 3 |
| 코드 공개 | 아니오(블랙박스) | 예(다운로드·커스터마이즈) |
| 비용 | 최상위 티어 유료 | 자기 컴퓨터면 무료 |
| 품질 | 대체로 우수 | 좋지만 최첨단은 아님(격차↓) |
| 응답 성향 | 더 안전·덜 논쟁적 | 더 과감·예측 불가 가능 |

## 요약
- LLM 선택지는 많고(OpenAI·Anthropic·Meta·Google) 각기 강점·어조가 다르며, 이 코스는 **내장 웹 인터페이스**를 쓴다.
- **폐쇄형(closed)** 은 블랙박스·유료·고품질·안전 성향, **개방형(open)** 은 공개·무료·과감함이 특징이며 격차는 줄고 있다.
- 작업에 맞게 고르되 두 유형을 **실험**하며, LLM을 **신뢰할 만한 동료(사고 파트너)** 처럼 활용하라.
- 다음 강의는 데이터 애널리틱스를 위한 **LLM 프롬프팅 모범 사례**다.
