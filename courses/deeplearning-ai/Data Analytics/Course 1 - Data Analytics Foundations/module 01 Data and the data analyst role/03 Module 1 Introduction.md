# Module 1 Introduction

## 개요
- 데이터 애널리틱스는 **수학의 문제 해결력 + 기술의 연산력 + 비즈니스의 전략적 사고**를 결합한 다학제 분야다.
- 고대 문명의 농업 주기 추적부터 현대 비즈니스의 의사결정 최적화까지, 데이터 애널리틱스의 원리는 수천 년간 세상을 형성해 왔다.
- 이 모듈은 데이터의 유형, 조직 내 데이터 흐름, 데이터 생태계의 구성원, 그리고 **LLM** 활용의 기초를 다룬다.

## 내용

### 이 모듈에서 배우는 것
- 다양한 **데이터 유형**과 조직 안에서의 흐름.
- **데이터 생태계(data ecosystem)** 를 이루는 다양한 역할(각자의 고유 기술).
- **LLM**(ChatGPT 등)을 **사고 파트너**로 활용 — 브레인스토밍·아이디어 다듬기·분석 실행.

### 다음 예고
- 데이터 애널리스트의 하루·1년·커리어가 어떤 모습인지 살펴본다(다음 강의 "Life as a Data Analyst").

## 요약
- 데이터 애널리틱스는 수학·기술·비즈니스가 결합된 다학제 분야로, 이 모듈은 **데이터 유형·데이터 흐름·데이터 생태계·LLM 활용 기초**를 다룬다.
- 데이터 커리어 입문이든 현직 활용이든 탄탄한 기초를 제공한다.
