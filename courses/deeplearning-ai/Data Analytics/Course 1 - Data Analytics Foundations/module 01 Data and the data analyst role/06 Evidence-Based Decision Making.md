# Evidence-Based Decision Making

## 개요
- 의사결정 방법은 **우연(chance) → 직관(intuition) → 근거 기반(evidence-based)** 의 스펙트럼 위에 있으며, 정보 활용도가 클수록 일관된 성공 확률이 높다.
- 데이터 애널리틱스는 **근거 기반 의사결정** — 문제·목표를 명확히 정의하고, 관련 정보를 모아 종합해 최선의 결정을 내리는 것이다.
- 직관도 (제한된 과거 데이터에 기반한) 가치 있는 자산이며, **직관 + 데이터** 결합이 가장 효과적이다.

## 내용

### 세 가지 의사결정 방법
- **우연(chance)**: 정보 없음(동전 던지기, 매직 8볼).
- **직관(intuition)**: 개인 경험 기반, 스펙트럼 중간. 사실상 **제한된 과거 데이터 포인트**에 의존.
- **근거 기반(evidence-based)**: 고정보 측. 데이터와 타인의 식견까지 포함 — 데이터 애널리틱스가 여기 해당.

### 정보의 필요성과 이해관계(stakes)
- 큰 결정(대학 선택, 이사, 투자)엔 자연히 정보를 모은다(장단점 정리, 현지 친구 상담, 투자 성과 추적).
- **증거 수집 노력은 결정의 영향력에 비례**한다. 형사사법·의료·저널리즘처럼 결과가 중대하면 의견·경험만으론 부족(감기로 의사에게 갔는데 무작위로 독감이라 추측하면 곤란). **이해관계가 클수록 더 많은 증거** 필요.
- 반대로 저위험(장갑 vs 벙어리장갑 추천)은 정보가 적어도 된다 — 오결정 비용이 낮으므로.

### 직관의 가치와 한계
- 직관은 무용하지 않다 — 제한된 과거 데이터에 기반. 단, **경험량**이 중요(독감 환자 5명 본 의사 vs 5,000명 본 의사).
- 최선은 **직관 + 데이터 결합** = 근거 기반 의사결정. 직관은 빠른 저위험 결정과 방대한 데이터를 무작정 뒤지는 상황을 피하는 데 유용하지만, 항상 직관에만 의존해선 안 된다.

### 예시 — 이색 반려동물 가게 매출 늘리기 (고위험 결정)
- 옵션: 파충류 종류 추가 / 하루 2시간 연장 영업 / 사료 가격 인상.
- **우연**: 매직 8볼 → 추가 정보 없음, 결과 나쁨.
- **직관**: 1987년부터 가게를 운영한 할머니가 "파충류 종류 추가가 답"이라 확신 → 제한된 과거 맥락 활용.
- **근거 기반**: 문제·목표를 명확히 정의 → 관련 정보 수집(파충류 종류 데이터, 연장 영업 실험, 가격 인상에 대한 고객 설문) → 종합해 최선 결정. 할머니 직관을 먼저 시도하고 안 되면 나머지 조사.
- 모든 결정엔 운이 따르므로, 근거 기반의 목표는 **최선의 증거를 축적해 옳은 결과 확률을 극대화**하는 것.

## 예시

### 의사결정 스펙트럼
| 방법 | 정보 활용 | 예 |
|------|-----------|-----|
| 우연 | 없음 | 동전·매직 8볼 |
| 직관 | 중간(경험) | 할머니의 확신 |
| 근거 기반 | 높음 | 데이터 수집·실험·설문 후 결정 |

## 요약
- 의사결정은 **우연 → 직관 → 근거 기반** 스펙트럼에 있으며, 정보 활용도가 클수록 일관된 성공에 가깝다.
- **이해관계가 클수록 더 많은 증거**가 필요하고, 데이터 애널리틱스는 문제 정의·정보 수집·종합의 **근거 기반 의사결정**을 실천한다.
- 직관은 제한된 과거 데이터로서 유용하지만, **직관 + 데이터** 결합이 최선이다.
- 목표는 최선의 증거로 옳은 결과 확률을 극대화하는 것. 다음은 데이터 애널리틱스의 역사다.
