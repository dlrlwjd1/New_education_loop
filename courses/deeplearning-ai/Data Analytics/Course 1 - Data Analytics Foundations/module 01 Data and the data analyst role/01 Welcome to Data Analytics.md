# Welcome to Data Analytics

## 개요
- 세상이 디지털화되면서 방대한 **데이터**가 생성되고, 이를 분석·이해하면 훨씬 나은 의사결정을 할 수 있다. 데이터 직군 수요도 빠르게 성장 중이다(미 노동통계국: 2033년까지 데이터 과학 일자리 36% 성장 전망).
- 강사는 **Sean Barnes**(Netflix 데이터 사이언스/엔지니어링 리더, 前 메릴랜드대 경영대학원 교수). 실전 예제(호텔 예약, 아기 이름, 제품 매출, 집값 등) 중심으로 진행한다.
- 이 전문 과정은 기초 통계·스프레드시트·데이터 애널리틱스 라이프사이클을 손으로 익히며, **생성형 AI(LLM)** 활용이 전 모듈에 통합되어 있다.

## 내용

### 데이터가 중요한 이유
- 이메일·웹 클릭·구매·시청 선택 등 모든 활동이 데이터를 만든다. 데이터를 보고 분석할 수 있는 사람은 개인·업무 양면에서 더 나은 결정을 내린다.
- 데이터 직군은 평균 직종보다 훨씬 빠르게 성장하고 있어, 학습은 커리어에도 도움이 된다.

### 분석이 결정을 바꾼 사례
- **채용(AI Fund)**: "CEO는 펀드레이징 경험이 필요하다"는 통념을 데이터로 검증했더니 **사실이 아니었고**, 채용 기준을 바꿨다.
- **병원 운영(Sean)**: 환자 퇴원 시점 예측에서 **물리치료사 방문**이 오히려 "퇴원이 가깝지 않다"는 신호였다. 병상 같은 귀중한 자원 배분·인력 운영에 큰 영향.
- 핵심: 결정 시 데이터에 접근할 수 있는 사람이 사실·분석을 가져오면, 수 분~수십 분 만에 훨씬 깊은 근거를 얻는다. 항상 복잡한 방법이 필요한 건 아니며 **단순한 데이터 스토리**로도 최선의 결정에 이를 수 있다.

### 생성형 AI와 데이터 애널리스트
- 기초는 변하지 않지만, 생성형 AI는 같은 일을 더 낫고 효율적이고 신뢰성 있게 하는 방법을 제공한다.
- 활용: **사고 파트너**로 시각화 해석, 문제 정의, 인사이트 해석·이해관계자 소통. "경험은 적지만 저비용으로 열심히 일하는 인턴"처럼 데이터 로드·플롯 등을 맡기고 분석가는 고수준 사고에 집중.

### 코스 성격
- 기술적 배경과 무관하게 유용하며, 각 모듈에 **실습 랩(hands-on lab)** 과 LLM 소개가 포함된다. 데이터 커리어 입문·현직 레벨업 모두에 가치.

## 요약
- 데이터는 더 나은 의사결정의 핵심이며 관련 직군 수요도 급성장 중이다.
- 분석은 통념을 뒤집는 인사이트(채용 기준, 병원 퇴원 신호 등)를 주며, 항상 복잡할 필요는 없다.
- 생성형 AI는 데이터 애널리스트의 **사고 파트너·저비용 조력자**로 통합된다.
- 이 전문 과정은 스프레드시트·통계·라이프사이클·LLM을 실습 중심으로 다룬다.
