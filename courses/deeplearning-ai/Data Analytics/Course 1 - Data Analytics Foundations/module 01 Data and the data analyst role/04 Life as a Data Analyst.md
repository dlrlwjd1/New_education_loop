# Life as a Data Analyst

## 개요
- 데이터 애널리스트 업무를 **하루·중기(수년)·커리어** 세 시야로 소개한다.
- 새로운 발견이 끊이지 않아 신선하고, 거의 모든 산업이 필요로 해 **수요·연봉·고용 안정성**이 높으며, 다양한 배경의 사람들이 모이는 분야다.
- 매일의 노력·프로젝트·대화가 쌓여 다양한 커리어 경로(전문가·리더·창업 등)로 이어진다.

## 내용

### 이 일의 매력
- 늘 새로운 것을 발견해 신선하고, 여러 분야와 연결된다. 대기업·스타트업·정부·비영리 등 거의 모든 산업이 데이터 애널리스트를 필요로 함 → **경쟁력 있는 연봉·고용 안정성**.
- 물리학·심리학·경영 등 **다양한 배경**의 사람들이 모이며, 빠르게 진화하는 분야라 계속 새 기술을 배운다. 학습·문제 해결·발견을 좋아하면 잘 맞는다.

### 하루 예시(mock schedule)
- 9시 새 문제 탐색 → 10시 데이터팀 회의(우선순위·필요 데이터 확보) → 11시 집중 작업(스프레드시트·DB·코딩, 발견의 순간) → 2시 **대시보드** 제작(데이터 속 숨은 이야기를 기능적·아름답게 시각화) → 3시 진행 발표·피드백 → 3시 반 휴식 → 4시 새 기술 학습(고급 통계·새 언어) → 6시 데이터팀 해피아워(트렌드·프로젝트 논의).

### 중기(수년)
- 여러 대형 프로젝트를 완수하며 현실 세계에 미친 영향을 체감. **포트폴리오** 축적, 산업 전문성(용어·암묵적 규칙) 발전, 기술 향상, 성공적 프로젝트 리드로 **팀의 신뢰** 획득 → 흥미로운 문제를 맡을 기회로 이어짐.

### 커리어
- 여러 산업(테크·헬스케어·패션·공급망 등)을 오가며 **폭넓은 경험**을 쌓거나, 특정 기술 영역에서 **깊은 전문성**을 쌓아 스페셜리스트가 될 수 있다.
- 성장하며 **리더**(관리자·고급 개인 기여자·교육자)가 되고, 후배 멘토링, 나아가 **창업·컨설팅**도 가능하다.

## 요약
- 데이터 애널리스트는 신선하고 빠른 속도의 일로, 높은 수요·연봉·안정성과 다양한 배경의 동료를 특징으로 한다.
- 하루는 문제 탐색·회의·집중 작업·대시보드·발표·학습으로 채워지고, 수년에 걸쳐 포트폴리오·전문성·신뢰를 쌓는다.
- 커리어는 폭(여러 산업) 또는 깊이(전문성)로 발전하며 리더·창업 등 다양한 경로로 열린다.
- 다음 강의에서 데이터 애널리틱스와 그 역사를 다룬다.
