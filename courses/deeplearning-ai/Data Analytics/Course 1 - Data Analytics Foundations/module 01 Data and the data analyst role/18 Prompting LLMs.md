# Prompting LLMs

## 개요
- 데이터 애널리스트는 LLM 활용의 두 핵심 기술을 길러야 한다: **좋은 프롬프트 작성**과 **LLM의 한계 인식**.
- 프롬프팅 3가지 팁: **① 상세·구체적으로(be detailed and specific), ② 답을 단계적으로 사고하게 안내(guide to think step by step), ③ 실험·반복(experiment and iterate)**.
- LLM은 **다양하고 창의적인 동료 그룹**처럼 대하되 모든 책임의 대체는 아니다.

## 내용

### 팁 1 — 상세·구체적으로 (충분한 맥락)
- 동료에게 스프레드시트 문제를 물을 때 "안 돼요!"라고 외치지 않고 목표·시도·결과를 설명하듯, LLM에도 **충분한 배경(context)** 이 필요하다.
- 자문: "동료가 내 질문에 답하거나 함께 브레인스토밍하려면 어떤 정보가 필요할까?"

### 팁 2 — 단계적으로 사고하게 안내
- 상세한 결과를 원하면 **단계로 나눠** 지시. 예: 웹 스크랩 데이터 정제 기법을 물을 때,
  1. 5가지 데이터 정제 기법 도출,
  2. 각 기법의 스프레드시트 수식 작성,
  3. 각 기법에 기억용 이모지 추가.
- 이미 원하는 프로세스가 있다면 **명확한 단계별 지시**가 효과적이다.

### 팁 3 — 실험·반복
- 처음엔 빠르게 시도("웹 스크랩 데이터 정제 기법 5가지 브레인스토밍") → 결과가 아쉬우면 "스프레드시트 수식을 사용해서" 추가 → 더 다듬어 "Google Sheets에서 커스텀 함수 없이".
- 프롬프팅은 **처음부터 올바른 프롬프트**가 아니라, **빠르게 시작 → 결과 확인 → 이상적 응답에 가깝게 조정**하는 것이다.

### 마인드셋
- LLM을 **다양하고 창의적인 동료 그룹**처럼 대하되, 당신의 모든 책임을 대체하는 것은 아니다.

## 예시

### 단계적 프롬프트 예
```
1) 웹 스크랩 데이터 정제 기법 5가지를 제시해줘
2) 각 기법에 해당하는 스프레드시트 수식을 써줘
3) 각 기법에 기억하기 좋은 이모지를 하나씩 붙여줘
```

### 프롬프팅 3팁
| 팁 | 내용 |
|-----|------|
| 상세·구체 | 충분한 맥락 제공("동료라면 뭘 알아야 할까?") |
| 단계적 사고 | 작업을 단계로 나눠 지시 |
| 실험·반복 | 빠르게 시도 → 확인 → 조정 |

## 요약
- LLM 활용 핵심 기술은 **좋은 프롬프트 작성 + 한계 인식**이다.
- 프롬프트는 **상세·구체적으로**, 복잡하면 **단계로 나눠** 지시하고, **빠르게 시도 후 반복 조정**한다.
- 프롬프팅은 완벽한 첫 프롬프트가 아니라 **빠른 시작 → 확인 → 조정**의 과정이며, LLM은 창의적 동료처럼 대한다.
- 다음 강의는 **LLM의 한계**를 다룬다.
