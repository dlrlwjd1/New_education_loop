# Modern Industry Use Cases

## 개요
- 스포츠·정부·패션 등 거의 모든 분야에 데이터 애널리스트의 자리가 있다. 현대의 대표 활용 사례를 둘러본다.
- 스트리밍(추천), 스포츠(농구 슛 위치 최적화), 제품 디자인(HelloFresh 추천), 교육·정부(히트맵 UX 개선) 등.
- 핵심 제품을 계속 바꾸지 않는 기업(Coca-Cola·UPS)도 **목표에 맞게** 데이터로 개선한다 — 데이터는 각 비즈니스의 목표에 맞춰 도움을 준다.

## 내용

### 스트리밍/엔터테인먼트
- 스트리밍 기업은 클릭·시청 시간·검색·일시정지/되감기 등 사용자의 모든 행동을 상세 수집해 콘텐츠를 추천. 과제는 정보 획득보다 **방대한 양을 다루는 것(wrangling)**.
- YouTube는 2018년 시청의 **70%가 추천에서 온다**고 밝혔다.
- 대조: 과거 TV는 **Nielsen** 이 표본 가구에 물리적 측정 장치를 설치해 시청 습관을 측정 — 유용하나 고령 시청자 편향, 다중 TV 가구의 부정확 데이터 등 한계.

### 스포츠(농구)
- 야구에서 시작된 분석 혁명이 농구·축구 등으로 확산.
- 농구는 라인 안쪽 슛 2점, 바깥쪽 3점. 지난 수십 년간 **슛 위치가 극적으로 변화**(1997 vs 2019): 팀들이 **슛당 기대 득점이 가장 높은 위치**를 극대화 — 라인에 붙은 3점슛과 골대에 최대한 가까운 2점슛. 한 걸음 물러나 난이도가 거의 같은데 50% 더 많은 점수를 얻는 3점을 택하는 식.

### 제품 디자인 (HelloFresh)
- **고객 데이터**(인구통계·위치·입맛), **레시피 데이터**(재료·가용성·이미지·텍스트), **거래 데이터**(주문 이력·피드백·브라우징)를 수집 → 추천 제품·할인 시점·신규 레시피 결정.

### 교육·정부 (히트맵 UX)
- 세인트앤드루스 대학교는 **상호작용 히트맵**으로 웹 UX 개선. 클릭이 많은 곳(빨강)부터 파랑까지 표시.
- 분석 결과 일부 사용자가 **비클릭 요소를 클릭**하려 했고 페이지 하단 활동이 급감함을 발견 → 클릭 가능 요소 명확화, 정보를 상단으로 재배치 등 개선.

### 핵심 제품을 유지하는 기업
- Coca-Cola·UPS처럼 **한 가지 핵심을 아주 잘하는** 기업도 있다. 이들은 물류·마케팅 최적화에 데이터를 쓰되 핵심 제품은 거의 그대로. 포인트: **데이터는 각 비즈니스의 목표에 맞는 방식으로 개선**을 돕는다.

## 예시

### 산업별 활용
| 분야 | 활용 |
|------|------|
| 스트리밍 | 행동 데이터 → 콘텐츠 추천(YouTube 70%) |
| 스포츠(농구) | 기대 득점 기반 슛 위치 최적화 |
| 제품 디자인(HelloFresh) | 고객·레시피·거래 데이터 → 추천·할인 |
| 교육·정부 | 히트맵으로 웹 UX 개선 |
| Coca-Cola·UPS | 핵심 제품 유지 + 물류·마케팅 최적화 |

## 요약
- 데이터 애널리틱스는 스트리밍·스포츠·제품 디자인·교육/정부 등 거의 모든 분야에 적용되며, 각 사례는 **데이터를 목표에 맞는 결정으로 전환**한다.
- 스트리밍은 추천, 농구는 기대 득점 기반 슛 최적화, HelloFresh는 다차원 데이터 추천, 대학은 히트맵 UX 개선이 대표적이다.
- 핵심 제품을 유지하는 기업도 데이터로 물류·마케팅을 최적화한다 — 그래서 데이터 애널리스트의 기술은 전 산업에서 수요가 높다.
- 다음 레슨에서는 데이터 애널리틱스의 근원인 **데이터 자체**(정의·출처·형태)를 다룬다.
