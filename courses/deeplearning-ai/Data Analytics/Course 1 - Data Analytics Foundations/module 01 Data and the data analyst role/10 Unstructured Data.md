# Unstructured Data

## 개요
- **비정형 데이터(unstructured data)** 는 행·열에 깔끔히 들어맞지 않는 데이터 — 텍스트·사진·영상·메모 등 **사람에게 자연스러운** 형태다.
- 현실 데이터 대부분은 비정형으로 시작하며, 효과적 분석을 위해 보통 **정형(structured) 형태로 변환**된다.
- 비정형 데이터는 전처리 단계가 더 많이 필요하지만, 상세함 덕에 **예상치 못한 인사이트**를 담을 수 있다.

## 내용

### 비정형 데이터란
- "데이터"를 떠올리면 흔히 숫자의 행·열 표를 상상하지만, 현실 데이터의 상당수는 그렇지 않은 **비정형**이다.
- 사진 촬영, 영상 녹화, 일기 작성 등은 모두 비정형 데이터 생성 — 사람이 혼자 데이터를 모으면 무의식적으로 비정형으로 하게 된다.
- 예: 러닝 일지("오늘 4명이 3.2마일을 29분 32초에 달렸고 코어 근력운동을 했다") = 비정형 텍스트. 이를 운동 항목=열, 날짜=행의 **표(정형)** 로도 정리 가능 — 왼쪽(비정형)은 인간적·자연스럽고, 오른쪽(정형)은 경직됐지만 분석에 유리.
- 사진·영상도 비정형(마트 초밥 사진, 그릴 옵션 영상). 정형화하려면 가격·보증기간·선호 점수(1~5) 등을 행·열로 기록해야 한다.

### 왜 구분이 중요한가
- 데이터의 **수집·처리 방식** 때문. 비정형 데이터도 결국 효과적 분석을 위해 **정형 형태로 변환**되는 경우가 많다. 대부분의 분석은 정형 데이터에서 이뤄지나, 현대 기법은 비정형을 직접 분석하는 능력이 점점 좋아지고 있다.
- 비정형은 유용해지기까지 단계가 더 많지만, **사람이 생성하기 자연스럽고** 상세함 덕에 뜻밖의 인사이트를 담는다.

### 예시 — 여행 블로그 리뷰
- 리뷰어가 재미·접근성·가치를 1~5로 평가(정형) + **코멘트(자유 텍스트, 비정형)**.
- 코멘트는 번역, 저장용 청킹(chunking), 긍/부정 분류 등 처리가 필요. 1~5 평점은 바로 분석(위치별 평균 등)되지만, "빈대는 압도적이었지만 커피는 좋았다" 같은 코멘트가 더 통찰적일 수 있다.
- 흔히 정형·비정형을 함께 저장 — 각 행=리뷰, 숫자 평점 열들 + **코멘트 열**(여전히 비정형).

## 예시

### 정형 vs 비정형 (러닝 일지)
| 형태 | 예 | 특징 |
|------|-----|------|
| 비정형 | "오늘 4명이 3.2마일을…" | 인간적·자연스러움 |
| 정형 | 날짜=행, 항목=열 표 | 경직되나 분석 유리 |

### 비정형 데이터 예
- 텍스트(일기·리뷰 코멘트), 사진, 영상

## 요약
- **비정형 데이터**는 행·열에 안 맞는 텍스트·사진·영상 등으로, 사람에게 자연스럽고 현실 데이터 대부분이 여기서 시작한다.
- 효과적 분석을 위해 보통 **정형으로 변환**되며, 전처리가 더 필요하지만 상세함 덕에 **예상치 못한 인사이트**를 담는다.
- 여행 리뷰처럼 정형(평점)과 비정형(코멘트)이 함께 저장되는 경우가 흔하다.
- 다음 강의에서 **정형 데이터(structured data)** 와 그 존재 이유를 다룬다.
