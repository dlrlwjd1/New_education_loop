# A History of Data Analytics

## 개요
- 현대 데이터 애널리틱스는 약 100년 전 등장해 세기 전환기에 가속됐으며, 두 가지 핵심 마인드셋으로 이어진다: **지속적 개선(continuous improvement)** 과 **데이터 기반 근거(data-driven evidence)**.
- 군사(2차대전 작전 연구), 야구(세이버메트릭스), 테크 등 여러 분야가 데이터 기반 혁신의 무대였다.
- **데이터 폭증 + 컴퓨팅 발전 + 근거 기반 의사결정에 대한 관심**이 맞물려 오늘날 데이터 애널리스트 수요를 견인한다.

## 내용

### 지속적 개선(continuous improvement)
- 제품·서비스·업무 프로세스를 끊임없이 개선하려는 과정. 진화처럼, 변하지 않으면 장기 생존이 어렵다.

### 군사 작전 연구 (2차대전, 1940년대 초)
- 군대의 이동·보급·장비 배치는 결정마다 결과가 크다. 초기 대표 문제: 독일 공습으로부터 영국을 지키기 위한 **레이더 최적 배치**.
- 공습이 이미 진행 중이라 시행착오 실험 시간이 없었고, **지리 정보·적기 비행 패턴·레이더 사거리·신호 강도** 데이터로 최적 배치를 도출 → 영국 전투 승리의 주요 요인. 빅데이터·강력한 컴퓨터는 없었지만 **데이터 기반 의사결정**의 한 형태.

### 야구 (1970년대~)
- 1970년대 이전엔 스카우트의 **직관("eye test")** 이 지배 — 선수가 좋아 보이는지, 운동능력이 있는지.
- 1970년대 세 요인으로 선수 영입이 최적화: **더 정교한 분석, 컴퓨팅 파워 증가, 직관 의존 감소**.
  - 통계학자 **Bill James** 가 혁신적 통계 발표 — 단순 득점(runs)이 아니라 선수가 승리에 얼마나 기여하는지(동료 득점 돕기, 상대 득점 막기)를 상세히 측정.
  - 예산이 적은 **오클랜드 애슬레틱스** 가 이 통계로 **저평가된 좋은 선수**를 영입해 부자 구단들에 경쟁 우위 확보. (전형적이지 않은 선수들이 더 자주 이겼다 = 데이터 애널리틱스의 힘.)

### 오늘날의 편재성
- 이 흐름은 **데이터 폭증 + 컴퓨팅 발전 + 근거 기반 의사결정에 대한 관심**과 맞물렸다.
- 현재 데이터 애널리틱스는 도처에: 테크(제품 추천·UX 최적화), 소매(재고·가격 관리), 헬스케어(환자 성과 개선·비용 절감) 등.
- 미국 데이터 애널리틱스 일자리는 2030년까지 **25% 성장** 전망. 모든 비즈니스가 데이터 근거로 지속적 개선의 이점을 누릴 수 있다.

## 예시

### 데이터 기반 혁신의 역사
| 분야 | 시기 | 내용 |
|------|------|------|
| 군사 작전 연구 | 1940s | 레이더 최적 배치 → 영국 전투 승리 |
| 야구(세이버메트릭스) | 1970s~ | Bill James 통계, 오클랜드의 저평가 선수 영입 |
| 현대 산업 | 2000s~ | 테크·소매·헬스케어 전반 |

## 요약
- 현대 데이터 애널리틱스는 **지속적 개선**과 **데이터 기반 근거**라는 마인드셋에 뿌리를 둔다.
- 2차대전 레이더 배치, 야구의 세이버메트릭스(Bill James·오클랜드)는 데이터가 직관·예산의 열세를 뒤집은 사례다.
- **데이터 폭증 + 컴퓨팅 발전 + 근거 기반 사고**가 오늘날 전 산업의 수요를 이끈다.
- 다음 강의에서 현대의 대표적 활용 사례를 살펴본다.
