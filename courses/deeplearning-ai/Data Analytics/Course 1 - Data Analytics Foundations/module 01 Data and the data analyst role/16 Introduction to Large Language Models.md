# Introduction to Large Language Models

## 개요
- **LLM(대형 언어 모델)** 은 텍스트를 생성하도록 설계된 AI로, **사전학습(pre-training)** 을 통해 다음 단어를 반복 예측하는 법을 배운다(수천억~1조+ 단어 학습).
- 인간 큐레이션 데이터로 추가 훈련되어 친절하게 답하고 비윤리적 응답을 피한다.
- 데이터 애널리스트에게 "텍스트 생성"은 요약·수식 수정·코드 작성 등 많은 것을 의미해, LLM은 **사고 파트너·시간 절약 도구**가 된다.

## 내용

### LLM 작동 원리
- 사전학습으로 인터넷의 방대한 텍스트(책·기사·위키·소셜미디어)를 읽어 **다음 단어 예측**을 학습. 이후 인간 큐레이션 데이터로 질문에 친절히 답하고 비윤리적 응답을 피하도록 추가 훈련.
- **텍스트 예측 예시**: "I love learning" → "new skills" / "about different dinosaurs" / "for the sake of it"처럼 실행마다 다르게 완성. 요즘 ChatGPT는 "That's fantastic!..."처럼 도움되게 답하도록 훈련됨.
- 도움되게 답하도록 훈련되어 "발표 개요 만들어줘" → "물론이죠", "경쟁사 데이터 훔치는 법" → "불법 활동은 도울 수 없습니다"처럼 반응.

### LLM이 잘하는 것 — 읽기와 쓰기
- **쓰기(writing)**: 데이터셋을 설명/업로드하고 적절한 차트 유형을 제안받는 등.
- **읽기(reading)**: 많은 정보를 주고 짧은 출력을 생성 — 이해관계자 이메일에서 핵심 비즈니스 문제 추출, 데이터셋의 범주형 열 개수 평가 등.
- 일상 업무에서 이런 **읽기·쓰기 작업**을 발견해 LLM을 사고 파트너로 활용하라.

### 이 레슨에서 배울 것
- LLM 작동 개요 후, 데이터 애널리틱스 작업에서 직접 협업 — 프롬프팅·협업 모범 사례, 그리고 **LLM으로 데이터를 다루는 3가지 방식**.

## 요약
- **LLM**은 사전학습으로 다음 단어를 예측하도록 배운 텍스트 생성 AI이며, 인간 피드백으로 친절·안전하게 다듬어진다.
- "텍스트 생성"은 요약·수식 수정·코드 작성 등을 포함해, 데이터 애널리스트의 **사고 파트너·시간 절약 도구**가 된다.
- LLM은 특히 **읽기(정보→짧은 출력)와 쓰기** 작업에 강하다.
