# What is Data Analytics?

## 개요
- **데이터 애널리틱스**는 비즈니스가 더 나은 결정을 내리도록 돕는 **기술·도구의 집합**으로, 우연·경험이 아니라 **데이터로 인사이트를 얻어 의사결정을 지원**한다.
- **수학 + 프로그래밍 + 비즈니스 직관**을 결합한 다학제 분야이며, 과학자·탐정·기자 같은 **조사(investigative) 역할**과 닮았다.
- **데이터 분석(data analysis)** 과 구분된다: 범위(scope)·기법(techniques)·비즈니스 통합(business integration) 세 측면에서 더 넓고 정교하며 통합적이다.

## 내용

### 정의와 성격
- 핵심은 데이터를 활용해 인사이트를 얻고 의사결정을 지원하는 것. 수학·프로그래밍을 **특정 비즈니스 목표**를 위해 함께 사용한다(순수 수학 증명이나 정렬 알고리즘 개발이 목적이 아님).
- 조사 역할과 유사: **과학자**(가설을 세우고 데이터로 검증), **탐정**(증거를 모아 짜맞춤), **기자**(정보를 종합해 설득력 있는 서사 구성).

### 데이터 분석 vs 데이터 애널리틱스
- **범위(scope)**: 애널리틱스는 회고 분석을 넘어 **실시간·예측 모델링**까지 포함.
- **기법(techniques)**: 고급 프로그래밍, 시각화 소프트웨어, 빅데이터 기법 등 더 정교하고 반복적.
- **비즈니스 통합**: 일회성 질문 답이 아니라 **의사결정 시스템에 깊이 통합**되어 추세 예측·의사결정 안내.
- 예: 예산을 스프레드시트로 추적 = 데이터 **분석**. 여러 출처의 대규모 데이터를 통계 모델링·시각화로 분석해 유망 수익원을 찾고 **실시간 의사결정 시스템에 통합** = 데이터 **애널리틱스**.

### 새로운 것 vs 오래된 것
- 통계·과학·공학에서 데이터 분석은 오래됐고, 데이터 시각화도 수천 년 됨(최초 기록 시각화: 기원전 1150년경 고대 이집트 금광 지도 **Turin Papyrus Map**).
- **새로운 것**: **데이터의 폭발적 증가**(전보다 훨씬 상세한 데이터 수집) + **컴퓨팅의 발전**(강력한 분석 도구). 이 둘이 현대 애널리틱스의 확장된 범위·정교한 기법·비즈니스 통합을 정의.

### 활용 범위와 직함
- 활용 범위는 거의 무한 — 테크·병원·스포츠팀·제조·학계 등.
- 유사 직함 구분(중첩 많고 회사마다 다름):
  - **데이터 사이언티스트**: 더 정교한 모델링에 치중.
  - **데이터 애널리틱스**: 기초 통계·시각화를 폭넓게 포함.
  - **비즈니스 인텔리전스(BI) 애널리스트**: 스프레드시트 등 상용 소프트웨어 위주, 프로그래밍 비중 낮음.
- 데이터 애널리틱스는 **호기심·문제 해결력·타인을 설득하는 능력**을 보상한다.

## 예시

### 데이터 분석 vs 애널리틱스
| 구분 | 데이터 분석 | 데이터 애널리틱스 |
|------|-------------|-------------------|
| 범위 | 회고적 | 실시간·예측 포함 |
| 기법 | 기본적 | 고급 프로그래밍·시각화·빅데이터 |
| 비즈니스 통합 | 일회성 질문 | 의사결정 시스템에 통합 |

### 유사 직함
| 직함 | 특징 |
|------|------|
| Data Scientist | 정교한 모델링 |
| Data Analyst | 기초 통계·시각화 폭넓게 |
| BI Analyst | 상용 도구(스프레드시트), 프로그래밍 적음 |

## 요약
- **데이터 애널리틱스**는 수학·프로그래밍·비즈니스 직관을 결합해 데이터로 더 나은 결정을 돕는 다학제 분야다(과학자·탐정·기자 같은 조사 활동).
- **데이터 분석**보다 범위·기법·비즈니스 통합이 넓고 정교하며, 예측·실시간 의사결정까지 아우른다.
- 데이터 분석 자체는 오래됐지만, **데이터 폭증 + 컴퓨팅 발전**이 현대 애널리틱스를 새롭게 만들었다.
- 데이터 사이언티스트·BI 애널리스트 등과 중첩되며 구분은 다소 임의적이다. 다음은 **근거 기반 의사결정**이다.
