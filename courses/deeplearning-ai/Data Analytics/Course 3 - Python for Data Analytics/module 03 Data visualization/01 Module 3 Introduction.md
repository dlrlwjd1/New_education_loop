# Module 3 Introduction

## 개요
- **Module 3 — 데이터 시각화(Data Visualization)** 소개. 두 핵심 라이브러리 **Matplotlib**(맞춤 플롯)와 **Seaborn**(향상된 시각적 매력)을 다룬다.
- 실제 **P2P 대출(peer-to-peer loans)** 데이터로 스타트업 제품 전략을 돕는다.

## 내용

### 레슨 구성
- **Lesson 1 — Matplotlib 기초**: 열 차트(단일·그룹·누적), 산점도 생성. **메서드 체이닝(method chaining)** 읽기.
- **Lesson 2 — Seaborn**: 스타일·색상 팔레트로 차트 향상, 박스플롯·히스토그램 등 특수 플롯.
- **Lesson 3 — 다중 플롯**: 겹치기·나란히 배치, **반복문**으로 적은 코드로 여러 플롯.

## 요약
- 이 모듈은 **Matplotlib**(맞춤)와 **Seaborn**(미려)으로 전문가급 시각화를 만든다.
- Lesson 1(Matplotlib·열 차트·산점도·체이닝) → Lesson 2(Seaborn·스타일·특수 플롯) → Lesson 3(다중 플롯·반복) 순.
- 다음은 **Matplotlib 플로팅** 첫 레슨이다.
