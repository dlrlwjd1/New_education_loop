# Other Charts

## 개요
- Seaborn의 특수 플롯: **히트맵(heatmap)·바이올린 플롯(violin plot)·회귀 플롯(regplot)**.
- 자주 쓰진 않지만 특정 목적에 유용하다.

## 내용

### 히트맵 (heatmap) — 상관 행렬
- `df[수치열].corr()` 로 상관 표를 만들고 `sns.heatmap(...)` 으로 시각화.
- 숫자 표는 보기 어렵지만 히트맵은 색으로 한눈에: 음의 상관은 진한 파랑(금리↔총부채한도 최강 음), 양의 상관은 빨강.
- 활용: 어떤 산점도를 그릴지 선택하는 데 도움.

### 바이올린 플롯 (violin plot)
- `sns.violinplot(df, x="grade", y="loan amount", palette=...)`. 박스플롯처럼 분포를 보여주되 **데이터 질량 위치**까지(내부에 박스플롯).
- 예: A~D 등급은 중앙값 비슷하나 등급이 나빠질수록 질량이 위로. A는 양의 왜도, F는 음의 왜도 등 — 등급별 중심·변동·왜도 차이.

### 회귀 플롯 (regplot)
- 산점도 + **최적합선(line of best fit)** 자동. 코드가 낯설면 **LLM에 설명 요청**.
- 예: 지불 이자 vs 대출액 — 강한 관계(상관 0.71). 단 71%만 설명 → 신규 대출($25k인데 이자 0 등)은 금리·기간 등 다른 특성 필요.

## 예시

### 특수 플롯
```python
sns.heatmap(df[cols].corr())                     # 상관 히트맵
sns.violinplot(df, x="grade", y="loan amount")   # 분포+질량
sns.regplot(df, x="loan amount", y="paid interest")  # 산점도+회귀선
```

## 요약
- **히트맵**은 상관 행렬을 색으로, **바이올린 플롯**은 분포+데이터 질량을, **회귀 플롯**은 산점도+최적합선을 보여준다.
- 낯선 코드는 LLM에 설명을 요청하며 결과를 예상한다.
