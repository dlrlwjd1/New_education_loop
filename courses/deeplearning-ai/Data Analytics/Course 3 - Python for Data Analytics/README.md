# Course 3 — Python for Data Analytics

**Specialization:** [Data Analytics](../README.md)
**제공:** DeepLearning.AI
**강사:** Andrew Ng, Sean Barnes

## 개요
데이터 분석을 위한 Python 코스. Python 프로그래밍 기초부터 pandas·Matplotlib·seaborn·statsmodels를 활용한 데이터 조작·시각화·추론 통계·시계열 분석까지 다룬다. **챗봇(LLM)을 코딩 버디**로 활용하는 워크플로가 전 모듈에 통합되어 있다.

## 모듈 구성
1. **Module 1 — Python fundamentals** (영상 23개) — 프로그래밍·Jupyter, 타입·변수·리스트·함수, 제어 흐름(조건·루프·range), 실행 순서
2. **Module 2 — Data structures and descriptive statistics** (영상 19개) — 모듈 임포트, pandas·DataFrame·Series, CSV 읽기, 선택·정렬·필터, 기술 통계·상관·세분화
3. **Module 3 — Data visualization** (영상 18개) — Matplotlib(열 차트·산점도·주석·축), seaborn(테마·팔레트·박스플롯·히스토그램), 다중 플롯(subplots·pairplot)
4. **Module 4 — Inferential statistics and regression** (영상 20개) — 신뢰 구간·t-검정·시뮬레이션, 단순·다중 선형 회귀, 범주형 인코딩, 모델 평가·LLM 개선
5. **Module 5 — Time series and forecasting** (영상 14개) — datetime·라인 차트, 이동 평균·변화율·리샘플링, 선형 회귀 예측(추세·계절성)·오차 지표

> 각 모듈 하위 폴더에 영상 강의 정리본(`NN 주제.md`)이 들어간다. Quiz·Lab·Reading·Cheat Sheet·Lecture Code/Notes·Capstone은 노트 대상에서 제외한다.
