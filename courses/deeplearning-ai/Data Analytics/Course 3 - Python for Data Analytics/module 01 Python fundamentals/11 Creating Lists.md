# Creating Lists

## 개요
- **리스트(list)** 는 순서가 있는 값의 모음(**시퀀스, sequence**)으로, 대괄호 `[]` 안에 콤마로 구분해 저장한다.
- 같은 종류의 여러 값을 하나의 변수에 담아 `sum` 같은 함수로 효율적으로 다룬다.

## 내용

### 왜 리스트인가
- 도서관 5년(28년) 수입을 개별 변수(income2019, income2020…)로 만들면 비효율적. **리스트 하나**로 모든 데이터 저장.
- `incomes = [값1, 값2, ...]` — 대괄호가 리스트, 값은 콤마 구분. 복수형 이름(incomes) 권장(값의 모음).

### 리스트 함수
- `sum(incomes)` → 전체 합(예: 약 3.8백만). 개별 변수 합산보다 **빠르고·쉽고·오류 적음**.
- 값을 추가해도(2017·2018 발견) `sum(incomes)` 코드는 **변하지 않음** — 리스트 크기와 무관하게 전체 합산.

### 순서와 한계
- 리스트는 **순서 있는(ordered)** 자료 구조 — 원하는 위치(앞/뒤)에 값 추가 가능.
- **한계**: 어떤 값이 어느 연도인지 알 수 없음(순서에 의존). 임시 해결로 **연도 리스트를 따로** 만들 수 있으나, 더 나은 방법은 다음 모듈(pandas)에서.

### 구조 정리
- `incomes = [...]`: 오른쪽 대괄호가 리스트 생성, `incomes =` 로 변수에 저장. 리스트 안 값들을 **항목(items)** 이라 부름.

## 예시

### 리스트 생성과 활용
```python
incomes = [income2019, income2020, income2021, income2022, income2023]
print(sum(incomes))       # 전체 합
# 값 추가 (앞에 2017, 2018)
incomes = [i2017, i2018] + incomes
years = [2017, 2018, 2019, 2020, 2021, 2022, 2023]  # 연도 별도 리스트
```

## 요약
- **리스트**는 순서 있는 값의 모음으로 `[]`에 콤마로 저장하며, 같은 종류 값을 하나의 변수에 담는다.
- `sum()` 등 함수로 크기와 무관하게 효율적으로 처리하나, 값이 무엇을 뜻하는지는 순서에 의존한다(연도 리스트로 임시 보완).
- 다음 강의는 리스트로 할 수 있는 더 많은 작업이다.
