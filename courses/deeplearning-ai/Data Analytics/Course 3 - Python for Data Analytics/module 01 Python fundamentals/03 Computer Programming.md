# Computer Programming

## 개요
- **컴퓨터 프로그래밍(computer programming)** 은 명령을 통해 컴퓨터에 원하는 일을 정확히 시키는 것. Python 같은 언어로 정밀하게 지시하면 컴퓨터가 그대로 수행.
- 분석 도구로서 컴퓨터의 강점: **효율성(efficiency)·추적성(traceability)·반복성(repeatability)**.

## 내용

### 프로그래밍이란
- 컴퓨터에 정확히 지시해야 함 — 안대를 쓴 사람을 장애물 코스로 안내하듯, 정확히 말하지 않으면 실수하거나 일부만 수행. 수학·데이터 분석 같은 사고 작업을 자동화.

### 효율성 (efficiency) — 스케이트보드 상점 예
- 후디 일평균 매출 계산: 인턴 20초 vs Python 1/1000초 미만.
- 200개 제품: 인턴 1시간+ vs Python 0.5초 미만. 100개 매장: 인턴 2주+ vs Python 수 초.
- 작업이 커질수록 Python 우위↑ = **at scale(대규모)**. 수백만 건이면 분석 자체를 가능하게 함.

### 추적성 (traceability)
- 프로그래밍은 각 단계를 정의(데이터 열기 → 제품별 행 선택 → 평균 → 저장/표시). 문제 시 어느 단계인지 빠르게 파악·수정(예: May2031.csv를 May2032.csv로 잘못 참조 → 파일명 고치고 재실행).
- 인턴은 기록이 없어 다시 분석해야 할 수 있음. 추적성이 시간·오류를 줄임.

### 반복성 (repeatability)
- 같은 작업을 같은 방식으로 여러 번. 지치지 않고, 약간 수정으로 관련 작업 적응(연간 매출 평균, 그래프 등). 예: 파일명만 May2033.csv로 바꿔 재실행.
- 수작업은 수행자에 따라 변동·해석 차이에 취약.

### 왜 Python인가
- R·Julia도 쓰이지만 Python이 데이터 애널리스트 시작에 좋음: **넓은 사용자층(업계 표준)**, 뛰어난 **가독성**, 빠른 작성, 시각화·자동화·웹 등 폭넓은 지원.

## 요약
- **프로그래밍**은 컴퓨터에 정확히 지시해 사고 작업을 자동화하며, **효율성·추적성·반복성**에서 수작업을 압도한다.
- 작업 규모가 클수록(**at scale**) Python의 우위가 커진다.
- Python은 넓은 사용자층·가독성·폭넓은 지원으로 데이터 분석의 표준 선택이다. 다음은 Python 작업 환경이다.
