# State

## 개요
- **상태(state)** 는 컴퓨터가 현재 기억하는 모든 정보의 스냅샷 — 생성한 변수와 그 값들.
- Python은 변수·값을 기본적으로 **숨기므로**, print 문이나 **변수 검사기(Variable Inspector)** 로 확인해야 한다.

## 내용

### 상태란
- Python은 각 줄·셀 실행 시 효과(변수와 값)를 기억해 이후 사용 가능.
- **변수 검사기(Variable Inspector)**: 우클릭 → 열면 변수 이름·타입·값을 표시(현재 상태의 스냅샷). 예: `total = sum(expenses)` 실행 시 total 행 생성, 값 17.9백만.
- **상태(state)** = 지금 계산의 어디에 있는지, 어떤 변수를 만들었는지. Jupyter를 닫거나 커널을 재시작하기 전까지 변수 유지.

### 숨겨진 상태 (hidden state)
- 스프레드시트는 데이터·계산이 셀에 다 보임(상태를 직접 봄). Jupyter는 변수 검사기를 열지 않으면 **안 보임**.
- 장점: 출력에 집중, 중간 단계 표시에 자원 안 써서 **빠름·확장성**(100% 신뢰 계산이면 중간 단계 불필요).
- 단점: **흔한 문제의 원인** — 변수 값을 잘못 알거나 데이터가 안 불렸는데 됐다고 오해.

### 대응
- 상태를 가정하지 말고 **print 문·변수 검사기**로 실제 값 확인. 코드가 기대와 다르면 즉시 점검.

## 요약
- **상태(state)** 는 현재 변수·값의 스냅샷이며, 커널 재시작 전까지 유지된다.
- Python은 상태를 **숨겨** 빠르고 확장성 있지만, 값 오해가 흔한 문제 → **print·변수 검사기**로 확인한다.
