# Module 1 Introduction

## 개요
- **Module 1 — 데이터 애널리틱스를 위한 프로그래밍 기초(Programming Fundamentals)** 소개.
- Python 프로그래밍의 세계를 탐색하고, 스프레드시트 방식과 비교하며 데이터 분석 워크플로를 더 효율적으로 만든다.

## 내용

### 실제 예제
- 공공 도서관 수익, 식당 안전 검사 점수 등 실제 데이터로 프로그래밍 개념을 데이터 분석에 직접 적용.

### 레슨 구성
- **Lesson 1**: 데이터 분석에서 프로그래밍의 역할, Python이 강력한 이유, 스프레드시트와 비교. **Jupyter Notebook** 환경에서 코드 작성·실행 시작.
- **Lesson 2**: Python 기초 — 데이터 타입, **변수(variables)** 에 정보 저장, **리스트(lists)**, 함수 실행. 첫 Python 프로그램 작성.
- **Lesson 3**: **제어 흐름(control flow)** — 조건문(conditionals)으로 분기, 반복문(loops)으로 반복. LLM으로 코드 수정.
- Python은 한 작업에 여러 방법이 있으며, 영상은 대개 가장 직접적인 방법을 보여줌.

## 요약
- 이 모듈은 Python 프로그래밍 기초를 실제 데이터로 배우며 스프레드시트 방식과 비교한다.
- Lesson 1(프로그래밍 역할·Jupyter) → Lesson 2(타입·변수·리스트·함수) → Lesson 3(제어 흐름·LLM) 순으로 진행한다.
- 다음은 데이터 분석 워크플로에서 프로그래밍의 역할을 다루는 첫 레슨이다.
