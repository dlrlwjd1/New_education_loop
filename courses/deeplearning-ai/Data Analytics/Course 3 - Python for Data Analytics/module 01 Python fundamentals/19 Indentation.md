# Indentation

## 개요
- **들여쓰기(indentation)** 는 어떤 코드 줄이 어떤 제어 구조(조건문·루프)에 속하는지 Python에 알려준다.
- 콜론(:) 뒤에는 반드시 들여쓴 블록이 와야 하며, 들여쓰기는 **코드의 일부**다(잘못하면 오류나 조용한 버그).

## 내용

### 들여쓰기의 역할
- if/루프는 콜론(:)으로 끝나고, 이어지는 **들여쓴 블록**이 그에 속하는 코드. "루프 안/밖", "조건 안"이라 표현.
- 들여쓰지 않은 코드는 제어 구조 밖.

### 오류 유형
- **IndentationError**: 콜론 뒤 블록이 안 들여써지면 "expected an indented block". if 자체나 print를 안 들여쓰면 발생.
- **조용한 오류(silent error)**: 오류 없이 실행되나 잘못 동작.
  - 예: `A_scores.append(score)` 를 if 밖(루프 안)에 두면 **모든 점수**가 추가됨(A만이 아님).
  - 완전히 왼쪽으로 들여쓰면 루프 밖 → **마지막 값만** 추가됨.

### 디버깅
- 조용한 오류는 print 문·LLM으로 디버깅("이 코드를 이렇게 기대했는데 이렇게 됨, 왜?" + 코드). LLM이 들여쓰기 문제를 짚어줌.
- **모든 오류가 프로그램을 멈추는 건 아님** — 실행되면서도 틀릴 수 있음.

## 예시

### 들여쓰기와 조용한 버그
```python
A_scores = []
for score in scores:
    if score >= A:
        print("A")
        A_scores.append(score)  # if 안: A만 추가 ✅
#   A_scores.append(score)      # if 밖·루프 안: 전부 추가 (조용한 버그)
# A_scores.append(score)        # 루프 밖: 마지막 값만
```

## 요약
- **들여쓰기**는 코드가 어느 제어 구조에 속하는지 결정하며, 콜론 뒤 블록은 필수다.
- 들여쓰기 실수는 **IndentationError** 또는 오류 없이 잘못 동작하는 **조용한 버그**를 낸다.
- print·LLM으로 디버깅한다. 다음 강의는 셋 이상의 분기(**elif**)다.
