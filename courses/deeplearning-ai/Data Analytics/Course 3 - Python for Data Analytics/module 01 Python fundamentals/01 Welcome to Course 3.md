# Welcome to Course 3

## 개요
- **Python for Data Analytics** — 데이터 애널리틱스 전문 과정의 세 번째 코스. 스프레드시트로 하던 통계·그래프·시뮬레이션을 이제 **Python**으로 수행한다.
- Python은 세계에서 가장 인기 있는 프로그래밍 언어(Kaggle 조사 데이터 전문가 88% 이상 사용).

## 내용

### 왜 Python인가
- 필터링·그룹화·요약·플로팅 등 익숙한 작업이 Python에 그대로 대응되나 **더 강력·유연**.
- 반복 작업 **자동화**, **대규모 데이터** 처리. 예: 리뷰 1만 건 → 수백만 건 자동 처리(Netflix는 2.5억+ 사용자 콘텐츠 제공·의사결정에 Python 활용).

### 코스 내용
- Python 기초(첫 코딩) → 기술 통계 → 시각화 → 추론 통계 → 시계열 분석.
- 효율성·재현성, 대규모 데이터 적용에 초점.
- 모듈마다 실제 데이터셋 사례 연구: 공공 도서관 수익, 대출 수익성, 산호초 지속가능성, 주가 등.

### LLM을 코딩 파트너로
- LLM 시대에도 코딩 학습은 여전히 가치 있음 — 배우기 쉬워지고(질문·피드백) 더 유용해짐(빠른 코드 작성·오류 수정).
- 데모·랩 전반에서 **챗봇을 코딩 버디**로 사용(코드 조언, 오류 찾기, 코드 생성) — 명령어 암기가 아닌 **코드 감각·패턴 인식** 개발.

### 학습 조언
- **직접 해보기(get your hands dirty)** — Jupyter Notebook을 열어 따라 하고, 코드를 바꿔보며 직관을 기른다.
- 오류는 당연함 — 처음부터 완벽히 작동하는 경우는 거의 없음. 스스로 고치거나 챗봇에 물어본다.
- 목표는 **완벽한 코드가 아니라 인사이트 도달**.

## 요약
- 이 코스는 스프레드시트 기술을 **Python**으로 옮겨 자동화·대규모 처리 역량을 더한다.
- Python 기초부터 기술·추론 통계·시계열까지 실제 데이터셋 사례로 배운다.
- **챗봇을 코딩 버디**로 활용하며, 직접 코드를 실행·수정하는 실습이 핵심이다.
