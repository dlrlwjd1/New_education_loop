# Your First Graded Lab

## 개요
- 이 코스의 **채점 랩(graded lab)** 은 **자동 채점(auto-graded)** — 코드 출력을 정답과 비교해 점수를 준다.
- 제출 전 몇 번이든 테스트 가능하며, 재제출도 무제한이다.

## 내용

### 채점 규칙
- 코드 블록에 `# graded cell` 주석이 있는 셀에만 코드 추가. **start code here ~ end code here** 사이에만 작성(밖이면 인식 안 됨).
- **제공된 변수명 사용**(예: numObservations를 바꾸지 말 것 — 채점기가 인식 못 함).
- **none** 은 자리표시자 → 자신의 코드로 교체. `# graded cell` 있는 셀만 평가(다른 셀은 수정 불필요, 실험용 셀 추가는 가능).

### 인터페이스
- **JupyterLab** — 상단에 **LLM 버튼**(질문·오류 수정, 대화 기록 저장)과 **Submit assignment 버튼**.
- 제출 → Grades 탭에서 통과 여부·점수·통과 기준·문항별 점수·코드 출력 피드백 확인. 재제출 무제한.
- 돌아올 거면 창 닫기 전 **Save** 필수(안 하면 진행 손실).

### Python 치트 시트
- 다음 항목은 배운 개념 참조용 **치트 시트**. 랩마다 새 개념이 추가된 버전 제공. LLM과 함께 활용.

## 요약
- 채점 랩은 **자동 채점**이며, `# graded cell`의 start/end 주석 사이에 **제공된 변수명**으로 코드를 작성한다.
- **none 자리표시자**를 교체하고, 제출 전 무제한 테스트·재제출이 가능하며 닫기 전 Save한다.
- LLM 버튼과 치트 시트를 활용한다. 다음 모듈은 코드로 **전체 스프레드시트** 다루기다.
