# Comparison

## 개요
- **비교 연산자(comparison operators)** 는 두 값을 받아 **불리언(Boolean, 참/거짓)** 을 반환한다.
- 조건문에서 데이터 기반 의사결정의 기초가 된다.

## 내용

### 예시 — 식당 위생 점수
- 점수 0~100 → 등급: 90+ A, 80~89 B, 70~79 C, 70 미만 실패(즉시 폐쇄). 6.7만 행 → 수동 불가, 코드로 변환.
- 리스트: `names`, `scores`, 컷오프 `A = 90`.
- `score0 >= A` → 96 ≥ 90이라 **True**. `score2 >= A` → 79 ≥ 90 거짓 → **False**(C 등급).

### 불리언 (Boolean)
- 비교 결과는 **True/False** 두 값뿐 — **불리언** 타입(int·float·list처럼 하나의 데이터 타입).

### 6개 비교 연산자
- `<`, `<=`, `>`, `>=` (스프레드시트와 동일).
- **`==`** (같음, 등호 2개), **`!=`** (같지 않음).
- 왜 `==`? 단일 `=` 는 이미 **할당(assignment)** 에 쓰이므로. 같음 검사엔 반드시 **등호 2개**.

### 활용 예
- "A 받았나?" → `scores[0] >= 90`.
- "실패?" → `scores[3] < 70` (또는 정수라면 `scores[3] <= 69`; float면 69.5가 통과로 잘못 처리되어 안 됨).
- "정확히 90?" → `scores[1] == 90`.

## 예시

### 비교 연산자
```python
scores[0] >= 90   # A 여부 → True/False
scores[3] < 70    # 실패 여부
scores[1] == 90   # 정확히 90 (==, 등호 2개)
scores[0] != 100  # 100이 아닌지
```

## 요약
- **비교 연산자**(`<, <=, >, >=, ==, !=`)는 두 값을 비교해 **불리언(True/False)** 을 반환한다.
- 같음 검사는 할당(`=`)과 구분하기 위해 **`==`(등호 2개)** 를 쓴다.
- 이 연산자로 조건문에서 의사결정을 한다. 다음 강의는 **if/else 분기**다.
