# Types and Expressions

## 개요
- Python의 핵심 **데이터 타입(data type)** 세 가지: **정수(integer)·부동소수점(float)·문자열(string)**.
- 타입이 데이터에 수행 가능한 **연산**을 결정한다.

## 내용

### 세 가지 핵심 타입
- **정수(int)**: 소수점 없는 정수(음수 포함). 예: −1, 0, −177.
- **부동소수점(float)**: 소수점 있는 실수(음수 포함). 예: 0.0, 1.7, −200.03.
- **문자열(string)**: 텍스트. 반드시 **따옴표** 안에 — 그래야 Python이 명령이 아닌 텍스트로 인식. 예: "oranges".

### 타입이 중요한 이유
- 타입이 가능한 연산을 결정. 예: `400`(정수)과 `"400"`(문자열)은 같아 보이지만 다름.
  - `400 / 2` → 200. `"400" / 2` → **오류**(텍스트는 나눗셈 불가).

### 예시 — 도서관 데이터
- 코네티컷 Plainville 공공 도서관: 행=운영 연도, 열=특성.
- **2023년 총 방문 수** = 인원 × 1인당 방문. `3.8 * 17479` → 66,000 (스프레드시트처럼 `*` 사용, Shift+Enter).
- **방문당 수입** = 총수입 / 총방문 → $12.51.
- 타입: 3.8은 float(소수), 17479는 integer(소수 없음).

## 예시

### 타입과 연산
```python
400 / 2      # → 200.0 (정수 나눗셈 OK)
"400" / 2    # → 오류 (문자열 나눗셈 불가)

3.8 * 17479          # 총 방문 ≈ 66,420 (float × int)
income / total_visits  # 방문당 수입 $12.51
```

## 요약
- Python 핵심 타입은 **정수·부동소수점·문자열**이며, 문자열은 따옴표로 감싼다.
- **타입이 가능한 연산을 결정** — `400`과 `"400"`은 다르게 취급된다.
- 정수·float는 스프레드시트처럼 수식(`*`, `/`)에 쓴다. 다음 강의는 출력과 주석이다.
