# Python or a Spreadsheet?

## 개요
- Python과 스프레드시트는 모두 효율적·일관적인 디지털 도구지만, **인터페이스·데이터 형식·분석 복잡성·추적성/반복성** 에서 차이가 있어 각자의 영역이 있다.

## 내용

### 인터페이스와 서식
- **스프레드시트**: 데이터를 직접 관리(열 복제 시 위치·참조 수동 지정). 색·글꼴 서식이 풍부해 이해관계자 탐색 유도.
- **Python(Jupyter)**: 처리가 대개 **백그라운드**에서 일어남(직접 관리 X, 검사만). 서식 능력은 제한적(마크다운). 둘 다 공유·설명용.

### 데이터 형식
- **스프레드시트**: 행·열 **테이블 하나**로 저장. 비정형 데이터(텍스트·영상)나 **다층 관계**(상점→브랜드→제품)는 모델링이 복잡(여러 시트 필요).
- **Python**: 복잡한 구조도 유연하게 처리.

### 분석·시각화 복잡성
- 스프레드시트도 정렬·필터·가설 검정 등 많은 기능. **Python은 확장**: 더 정교한 통계, 시뮬레이션, **머신러닝 모델**, 맞춤 분석.
  - 예: 시트의 t-test는 p-값만 반환하나, Python은 검정 통계량·자유도·신뢰 구간을 각각 한 줄로.
  - 시각화: 시트는 진짜 박스플롯 불가하나 Python은 몇 줄로 생성·완전 커스터마이즈·여러 플롯 동시 생성.

### 추적성·반복성
- **Python 우위**. 시트는 버전 기록 정도지만, Python 코드는 **단계별 기록**(가져오기 → 결측 가격 행 필터 → 할인 열 추가 등).
- 반복성: 작은 수정으로 유사 출력 대량 생성. 예: 같은 형식 데이터셋 15개면 import 한 줄만 바꿔 재실행, 20개 특성이면 명령 살짝 바꿔 각각 95% 신뢰 구간.

### 선택 기준
- **스프레드시트**: 빠른 소규모 분석, 전체 데이터 보기, 추적성/반복성 덜 중요, 풍부한 서식.
- **Python**: 대규모 효율 분석, 복잡·맞춤 분석·시각화, 추적 가능·반복 쉬운 프로세스.

## 요약
- **스프레드시트**는 소규모·빠른 분석·풍부한 서식에, **Python**은 대규모·복잡·맞춤 분석과 추적성·반복성에 강하다.
- Python은 정교한 통계·시뮬레이션·ML·진짜 박스플롯 등으로 스프레드시트 기능을 확장한다.
- 이로써 Python 기초와 사용 이유를 마쳤다. 다음 레슨부터 직접 코딩한다.
