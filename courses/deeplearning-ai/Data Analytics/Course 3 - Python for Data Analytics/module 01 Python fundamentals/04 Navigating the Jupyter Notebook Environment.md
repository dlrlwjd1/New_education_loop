# Navigating the Jupyter Notebook Environment

## 개요
- 이 코스의 코딩 도구인 **Jupyter Notebook**(데이터 애널리스트 업계 표준) 인터페이스 소개.
- 노트북은 **셀(cell)** 로 나뉜 텍스트 문서이며, **마크다운 셀**과 **코드 셀**로 구성된다.

## 내용

### 노트북과 셀
- 특수한 텍스트 편집기(구글 독스와 유사) — 파일명, 리본 메뉴, 편집 영역.
- **마크다운 셀(markdown cell)**: 서식 있는 텍스트. 더블 클릭으로 편집, **Shift+Enter**로 렌더링.
- **코드 셀(code cell)**: 코드 실행. **Shift+Enter**로 실행(가장 중요한 단축키), 출력은 셀 바로 아래 표시. 툴바 Run 버튼도 가능.

### 실행 제어
- **Stop**: 오래 걸리는 코드 중단. **Restart**: 전부 초기화(코드 실행 전 상태로). **+ 버튼**: 새 셀 추가(실습에서 실험용).
- 셀 옆 **번호**는 실행 순서 — 재실행 시 번호 변경.
- 리본의 **Edit → Clear output**: 긴 출력 정리. Settings에서 다크 테마·글꼴 크기 변경.

### 커널 (kernel)
- 노트북은 명령을 담은 텍스트 파일일 뿐, 스스로 실행하지 않음. **커널이 노트북의 엔진** — 명령을 실제로 실행하는 부분.

### 챗봇과 실습 자료
- 왼쪽 하단에서 **챗봇** 접근(예: "What is Python for?"). 닫았다 열어도 대화 기록 저장.
- 다음 항목은 **강의에서 시연하는 노트북을 담은 practice lab** — 따라 하거나 나중에 참조. Jupyter를 직접 설치하긴 어려워, 당분간 플랫폼에서만 사용(직접 설치는 마지막 모듈에서).
- 코딩 연습용 **reading 항목**(선택, 특히 초보자에 권장).

## 요약
- **Jupyter Notebook**은 셀 기반 코딩 환경으로, 마크다운 셀과 코드 셀로 나뉜다.
- **Shift+Enter**로 셀을 실행하며(핵심 단축키), Stop·Restart·+ 버튼으로 제어하고 **커널**이 명령을 실제 실행한다.
- 챗봇과 practice lab을 활용해 따라 할 수 있다. 다음은 코드 예시 시연이다.
