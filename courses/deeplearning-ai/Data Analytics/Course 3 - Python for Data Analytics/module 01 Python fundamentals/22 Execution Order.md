# Execution Order

## 개요
- **실행 순서(execution order)** 는 프로그램이 개별 코드 줄을 실행하는 순서. 제어 흐름(반복·분기)에 따라 결정된다.
- 디버깅 시 **한 줄씩 추적(trace)** 하며 변수 값을 따라가면 이해에 도움된다.

## 내용

### 코드 추적 예시 — A/B/C 집계
- 코드: 루프 안에서 if(≥A)/elif(≥B)/elif(≥C)/else로 numAs·numBs·numCs 카운트.
- **변하지 않는 것**: A·B·C(컷오프 상수), scores(추가·변경 없음).
- **변하는 것**: numAs·numBs·numCs(집계), score(루프마다).

### 반복(iteration) 추적
- score=96: ≥90 참 → numAs=1, 나머지 elif/else 건너뜀 → 루프 top.
- score=91: ≥90 참 → numAs=2.
- score=79: ≥90 거짓 → 다음 줄 건너뜀, ≥80 거짓, ≥70(C) 참 → numCs=1.
- score=93: ≥90 참 → numAs=3.
- score=86: ≥90 거짓, ≥80 참 → numBs=1.
- 리스트 끝까지 반복 후 다음 코드(len 계산)로.

### 패턴
- 리스트에서 종류별 항목 집계 = 흔한 코딩 패턴, 스프레드시트 **SUMIF** 와 동일.

## 요약
- **실행 순서**는 제어 흐름에 따른 코드 실행 순서이며, 한 줄씩 추적하면 디버깅에 도움된다.
- 조건은 참인 분기만 실행하고 나머지는 건너뛰며 루프 top으로 돌아간다.
- 종류별 집계는 SUMIF와 같은 흔한 패턴이다. 이로써 Module 1(타입·변수·조건·루프)의 핵심을 익혔다.
