# Storing Information: Variables

## 개요
- **변수(variable)** 는 값을 저장하는 "상자"로, 반복·변경되는 값을 재사용해 코드의 반복성을 높인다.
- 변수 생성 = **선언(declare, 이름 짓기)** + **할당(assign, 값 주기)**. 스프레드시트의 이름 붙은 셀과 유사.

## 내용

### 왜 변수인가
- 같은 값을 여러 번 타이핑하면 오타 위험·수정 번거로움. 예: 도서관 총수입이 여러 곳에 반복.
- 값이 틀렸다고 밝혀지면(예: 830,696 → 830,000) 모든 곳을 수동 수정해야 함 → 변수로 **한 번 저장, 여러 번 사용**.

### 변수 생성과 사용
- `income2023 = 830696` — income2023라는 상자에 정수 저장. `print(income2023)` → 830696.
- 필요한 모든 곳에서 값 대신 이름 사용. 값이 바뀌면 **한 곳만 수정 후 재실행** → 모든 결과 갱신(스프레드시트 셀 참조와 동일).

### 선언·할당·덮어쓰기
- **선언은 한 번**, **할당은 여러 번** 가능(새 값 부여).
- 새 값을 할당하면 이전 값은 완전히 버려지고 대체됨 = **덮어쓰기(overwriting)**. 이전 값이 필요 없다고 확신할 때만; 아니면 새 변수 생성.

### Python이 변수를 처리하는 법
- `print(income2023 - 794398)` → Python이 income2023 이름의 상자를 찾아 현재 값(830696)으로 치환 → 뺄셈 수행(35,602) → 출력.

## 예시

### 변수 활용
```python
income2023 = 830696          # 선언 + 할당
print(income2023)            # → 830696
print(income2023 - 794398)   # 이익 → 35602
income2023 = 830000          # 덮어쓰기 (한 곳만 수정)
```

## 요약
- **변수**는 값을 저장하는 상자로, **선언(이름)+할당(값)** 으로 만들며 반복·변경 값을 재사용한다.
- 값을 한 곳에서 바꾸면 모든 사용처가 갱신되고, 새 값 할당은 이전 값을 **덮어쓴다**.
- Python은 변수 이름을 현재 값으로 치환해 계산한다. 다음 강의는 변수 관련 흔한 오류(디버깅)다.
