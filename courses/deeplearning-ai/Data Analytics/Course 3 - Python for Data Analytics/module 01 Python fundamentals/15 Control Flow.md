# Control Flow

## 개요
- **제어 흐름(control flow)** 은 코드 줄이 실행되는 순서 — 컴퓨터가 코드를 통과하는 경로를 결정한다.
- 네 가지: **순차(sequential)·조건(conditional)·반복(repetitive)·함수 호출(function calls)**.

## 내용

### 순차 (sequential)
- 기본 방식 — 제어 구조가 없으면 위에서 아래로 순서대로 실행.

### 조건 (conditional)
- 특정 조건이 **참일 때만** 코드 실행 → 분기(갈림길). 한 경로만 감(둘 다 아님).
- 예: 세계 도서관 데이터에서 브라질 도서관 세기 — country가 "Brazil"이면 total+1, 아니면 아무것도 안 함(브라질엔 7.5만+ 도서관).
- 스프레드시트의 **COUNTIF·SUMIF·AVERAGEIF** 와 유사.

### 반복 (repetitive)
- 100개 항목을 모두 2로 나눌 때 100줄 대신 몇 줄로 반복. 예: 1~100 출력, 리스트 각 항목을 total에 더하기.
- 스프레드시트의 **배열 수식(array formula)** 과 유사(한 수식을 여러 셀에 반복).

### 함수 호출 (function calls)
- 이후에 자세히 다룸(이번 레슨은 앞 3가지 중심).

## 요약
- **제어 흐름**은 코드 실행 순서를 결정하며 **순차·조건·반복·함수 호출** 네 가지가 있다.
- **조건**은 참일 때만 분기 실행(COUNTIF 유사), **반복**은 동작을 되풀이(배열 수식 유사)한다.
- 다음 강의는 조건에 쓰이는 **비교(comparisons)** 다.
