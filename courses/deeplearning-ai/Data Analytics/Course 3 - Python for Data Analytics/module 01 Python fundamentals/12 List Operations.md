# List Operations

## 개요
- 리스트는 **0-인덱스(zero-indexed)** — 첫 항목이 index 0. `리스트[인덱스]` 로 개별 항목에 접근한다.
- 항목 접근·수정·추가(`.append`) 등 다양한 연산을 수행한다.

## 내용

### 인덱싱 (indexing)
- **0부터 시작**: 첫 항목=index 0, 두 번째=index 1. 마지막 항목 = 길이−1(10개면 0~9).
- 접근: `incomes[0]`(1996년), `incomes[1]`(1997년). `incomes[0] + incomes[1]` 로 합산.

### 항목 수정
- `incomes[2]` 는 변수처럼 동작 → `incomes[2] = 460000` 으로 값 갱신.

### 항목 추가 (.append)
- `incomes.append(837404)` — 리스트 끝에 값 추가(28→29개).
- **점(.)** 은 데이터에 동작(함수)을 수행: `리스트.append(값)`. sum/print와 달리 특정 데이터에 붙는 함수(메서드).

## 예시

### 리스트 연산
```python
incomes[0]              # 첫 항목 (1996년)
incomes[0] + incomes[1] # 1996+1997 합
incomes[2] = 460000     # 항목 수정
incomes.append(837404)  # 끝에 추가
sum(incomes)            # 전체 합
```

## 요약
- 리스트는 **0-인덱스**이며 `리스트[i]` 로 접근하고, 마지막 인덱스는 길이−1이다.
- `리스트[i] = 값` 으로 수정, `리스트.append(값)` 으로 끝에 추가한다.
- **점(.)** 은 데이터에 동작을 수행한다. 다음 강의는 함수(functions)를 더 다룬다.
