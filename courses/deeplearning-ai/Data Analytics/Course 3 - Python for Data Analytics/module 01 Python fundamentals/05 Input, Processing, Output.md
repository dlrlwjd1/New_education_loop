# Input, Processing, Output

## 개요
- 컴퓨터 프로그램은 **입력(input) → 처리(processing) → 출력(output)** 의 흐름이다.
- 근본적으로 컴퓨터는 **숫자에 대한 수학**을 수행 — 모든 데이터는 숫자로 표현된다.

## 내용

### 모든 것은 숫자
- Python 코드는 영어+수학의 혼합처럼 보이지만 내부는 수학. 컴퓨터에서 모든 데이터는 숫자로 표현:
  - 숫자는 그대로, 텍스트는 문자별 숫자, 디지털 이미지는 픽셀별 RGB 숫자, 영상은 이미지 나열 + 부가 정보.
- 컴퓨터는 데이터를 나타내는 숫자에 수학을 수행(컬러→흑백, 신뢰 구간 계산, 리뷰 긍정/부정 판별 등).

### 입력·처리·출력 예시
- **간단한 예**: 세 숫자(3, 10, 2)를 변수에 할당 → 더함(처리) → 15 출력(Shift+Enter).
- **복잡한 예**: 영화 데이터셋 전체를 입력 → 연도별 평균 길이 계산(처리) → 라인 차트 출력.

### 각 단계
- **입력(input)**: 코드에 직접 쓴 값, 데이터셋, 이미지 폴더 등. 프로그램은 해당 형식을 예상하게 작성.
- **처리(processing)**: 코드 실행 시 명령을 단계별 수행. 화면 밖에서 일어나 다소 신비로움(마술사처럼) — 영화 예에선 실제 데이터를 보지 못함.
- **출력(output)**: 화면 표시, 파일 저장/변경, 다른 프로그램·컴퓨터로 결과 전송. 화면 표시 명령이 없으면 아무 일 없어 보일 수 있음.

## 예시

### 입력·처리·출력
```python
# 입력
a = 3
b = 10
c = 2
# 처리
total = a + b + c
# 출력
total   # → 15
```

## 요약
- 프로그램은 **입력 → 처리 → 출력** 흐름이며, 내부적으로 숫자에 대한 수학이다(모든 데이터는 숫자로 표현).
- 입력은 값·데이터셋 등, 처리는 화면 밖 단계별 실행, 출력은 표시·저장·전송이다.
- 다음 강의는 언제 프로그램 vs 스프레드시트를 쓸지 선택하는 법이다.
