# Attributes and Methods

## 개요
- **속성(attribute)** 은 데이터프레임이 **가진** 특성(예: 열 이름) — 괄호 없이 접근.
- **메서드(method)** 는 데이터프레임이 **할 수 있는** 동작(예: 요약 생성) — 괄호 사용(함수).

## 내용

### 속성 vs 메서드
- **속성(괄호 X)**: `df.columns`, `df.dtypes` — 이미 저장된 정보를 즉시 가져옴(계산 불필요).
- **메서드(괄호 O)**: `df.info()`, `sum()`, `max()`, `len()` — 동작·계산 수행. (메서드 = 함수의 다른 말)
- 비유: 이름·나이는 생각 없이 답하는 **속성**, "공원 마지막 방문 후 며칠?"은 계산이 필요한 **메서드**.
- Python도 자주 쓰는 기본 정보는 **속성**으로 빠르게 저장, 복잡한 질문(요약·고유값·합계·히스토그램 등)은 **메서드**로 계산.

### 실무 포인트
- **속성**은 괄호 없이(`df.columns`), **메서드**는 괄호와 종종 인자와 함께(`df.info()`, `df.head(3)`).
- 속성은 많지 않음 — columns, dtypes, 차원(행·열 수, `df.shape`) 정도.

## 예시

### 속성 vs 메서드
```python
df.columns     # 속성 (괄호 X)
df.dtypes      # 속성
df.shape       # 속성 (행·열 수)
df.info()      # 메서드 (괄호 O)
df.head(3)     # 메서드 (인자)
```

## 요약
- **속성**(괄호 X, 예 columns·dtypes·shape)은 데이터프레임이 가진 특성으로 즉시 접근된다.
- **메서드**(괄호 O, 예 info()·head())는 계산·동작을 수행하는 함수다.
- 다음 강의는 **열 선택(selecting columns)** 이다.
