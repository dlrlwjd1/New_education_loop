# Module 2 Introduction

## 개요
- **Module 2 — 자료 구조와 기술 통계(Data Structures and Descriptive Statistics)** 소개.
- Python 라이브러리 **pandas**로 데이터를 조직·분석하고 인사이트를 도출한다.

## 내용

### 핵심 자료 구조
- **데이터프레임(DataFrame)** 과 **시리즈(Series)** — 대규모 데이터를 효율적으로 다루는 구조.
- 코딩 습관 설문 응답 실제 데이터셋 활용.

### 레슨 구성
- **Lesson 1**: 리스트를 넘어선 자료 구조 — 데이터프레임(스프레드시트 같지만 훨씬 강력), 데이터 읽기, 히스토그램, 카운트·합계.
- **Lesson 2**: **정렬(sorting)·필터링(filtering)** — 필요한 정보에 집중.
- **Lesson 3**: pandas로 **기술 통계**(중심 경향·상관·세분화)와 시각화(막대·산점도).

## 요약
- 이 모듈은 **pandas**로 데이터를 조직·분석한다 — 핵심 구조는 **DataFrame·Series**.
- Lesson 1(자료 구조·읽기·집계) → Lesson 2(정렬·필터) → Lesson 3(기술 통계·시각화) 순으로 진행한다.
- 대규모 데이터를 실행 가능한 인사이트로 바꾸는 법을 배운다.
