# Filtering

## 개요
- **필터링(filtering)** 은 조건에 맞는 행만 선택하는 것: `df[불리언 표현식]`.
- 표현식은 **불리언 시리즈**(각 행 True/False)를 만들고, True인 행만 남긴다.

## 내용

### 조건으로 행 선택
- 예: 여성 응답자만 → `female = df[df["gender"] == "female"]`.
- 동작: 각 행의 gender를 보고 "female"이면 포함, 아니면 제외. 결과는 데이터프레임(원래 정수 인덱스 유지).
- 활용: `len(female)` → 2,840(1.5만 중 약 3천). `female["age"].hist()` 로 부분집합 분석.
- (Python은 문자열에 **작은따옴표**도 가능)

### 수치 조건
- `df[df["hours..."] > 30]`, `df[df["age"] > 30]` 등 `>`, `>=`, `<` 등 사용.
- 스프레드시트의 커스텀 필터보다 간단.

### 내부 동작 — 불리언 시리즈
- `df["gender"] == "female"` 의 타입은 **시리즈**(불리언). 예: [False, False, False, True, True…].
- `df[...]` 로 선택하면 True인 행만 포함(False는 버림). 그래서 female의 첫 인덱스가 3, 4.

## 예시

### 필터링
```python
female = df[df["gender"] == "female"]     # 조건 일치 행
above30 = df[df["age"] > 30]              # 수치 조건
df["gender"] == "female"                  # → 불리언 시리즈
```

## 요약
- **필터링**은 `df[불리언 표현식]` 으로 조건에 맞는 행만 선택한다(`==`, `>`, `<` 등).
- 표현식은 **불리언 시리즈**를 만들고 True인 행만 남긴다(원 인덱스 유지).
- 다음 강의는 여러 조건으로 필터링하는 법이다.
