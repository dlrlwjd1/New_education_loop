# Selecting Rows

## 개요
- **loc**(라벨/인덱스 기반)와 **iloc**(정수 위치 기반)로 행을 선택한다.
- `set_index` 로 커스텀 인덱스를 지정하고, 콜론(:)으로 행 범위를 **슬라이스(slice)** 한다.

## 내용

### 커스텀 인덱스 — set_index
- 기본은 0부터의 정수 인덱스. 고유 식별자(학생 ID·국가 코드·날짜 등)를 인덱스로 지정 가능.
- `indexed_df = df.set_index("id")` — id 열을 인덱스로(원 정수 인덱스 대체, id 열 제거).

### loc vs iloc
- **loc(라벨)**: 인덱스 값으로 접근. `indexed_df.loc[25447]` → 해당 ID 응답자.
- **iloc(정수 위치)**: 위치로 접근(인덱스를 바꿔도 정수 행 번호 유지, 0부터). `indexed_df.iloc[1000]` → 1001번째 행.
- 단일 행 결과는 **시리즈** — 열 이름이 인덱스가 됨. `response["age"]` 로 값 접근(문자열 인덱스 예시).

### 슬라이싱 (slicing)
- `indexed_df.iloc[8664:8669]` → 8664부터 8668까지(**8669 미포함**) 5개 행. 결과는 데이터프레임(여러 행×모든 열).
- 일반: `iloc[a:b]` → a부터 b−1까지. **끝 미포함** 이유: 슬라이스 길이가 항상 **b−a**(1006−1000=6).

## 예시

### 행 선택
```python
indexed_df = df.set_index("id")
indexed_df.loc[25447]        # 라벨(인덱스)로
indexed_df.iloc[1000]        # 정수 위치로 (1001번째)
indexed_df.iloc[8664:8669]   # 슬라이스 (8669 미포함, 5개)
```

## 요약
- **loc**(인덱스 라벨)·**iloc**(정수 위치)로 행을 선택하고, **set_index** 로 커스텀 인덱스를 지정한다.
- 콜론으로 **슬라이스**하며 `iloc[a:b]` 는 a~b−1(끝 미포함, 길이 b−a)이다.
- 이로써 정렬·필터·행/열 선택을 익혔다. 다음 레슨은 기술 통계다.
