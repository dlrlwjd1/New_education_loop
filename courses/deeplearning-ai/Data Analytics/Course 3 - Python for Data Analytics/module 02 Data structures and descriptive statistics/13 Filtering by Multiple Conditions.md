# Filtering by Multiple Conditions

## 개요
- 여러 조건으로 필터링: 각 조건을 **괄호**로 감싸고 **`&`(AND)** 또는 **`|`(OR)** 로 결합한다.
- `&` 는 두 조건 모두 참, `|` 는 적어도 하나 참인 행을 선택한다.

## 내용

### AND (&)
- 예: 여성이면서 30세 초과 → `females_above_30 = df[(df["gender"]=="female") & (df["age"] > 30)]`.
- 각 조건을 괄호로 감싸고 **`&`(앰퍼샌드)** 로 연결 → 둘 다 참인 행만.
- 부분집합이라 female 데이터프레임보다 짧음(약 1,100).

### OR (|)
- 여성 **또는** 30세 초과 → `&` 를 **`|`(파이프)** 로 변경. 적어도 하나 충족하는 행(30세 초과 남성, 30세 이하 여성 등 포함).

## 예시

### 다중 조건 필터
```python
# AND: 둘 다 참
df[(df["gender"] == "female") & (df["age"] > 30)]
# OR: 하나 이상 참
df[(df["gender"] == "female") | (df["age"] > 30)]
```

## 요약
- 다중 조건 필터는 각 조건을 **괄호**로 감싸고 **`&`(AND)** 또는 **`|`(OR)** 로 결합한다.
- `&` 는 모두 참, `|` 는 하나 이상 참인 행을 선택한다.
- 다음 강의는 개별 행·행 슬라이스 선택이다.
