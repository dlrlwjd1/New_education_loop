# The Linear Regression Process

## 개요
- 선형 회귀 전 과정을 조망 — **학습 → 평가 → (반복) → 예측**.
- 단순 회귀로 시작해 반복적으로 개선한 뒤 새 값을 예측한다.

## 내용

### 학습 준비
1. **종속 변수** 선택(예측 대상).
2. 다른 특성과의 **산점도·상관** 검토 → 강하게 상관된 **독립 변수** 식별.
3. **훈련/테스트 분리** — 10~20%를 테스트셋으로 예약, 나머지로 학습.
4. **단순 회귀**로 시작(가장 강한 상관 변수 하나), statsmodels로 학습·평가.

### 반복적 평가·개선
- **R²**(예측력, 높을수록 좋음), **계수 p-값**(유의성) 확인.
- 추가 지표: 예측 vs 실제 그래프, **다중 R**, **잔차**, **MAE**.
- 개선: **특성 추가(다중 회귀)** — 다른 변수와 함께 예측력 있는 다양한 변수, **다중공선성** 주의.

### 예측
- R²(설명력)에 만족하면 statsmodels로 단일·시리즈 예측.

## 요약
- 회귀 워크플로: **종속 변수 선택 → 상관으로 독립 변수 식별 → 훈련/테스트 분리 → 단순 회귀 → 평가·반복 개선 → 예측**.
- R²·p-값·다중 R·잔차·MAE로 평가하며, 특성 추가·다중공선성 관리로 개선한다.
- 비선형 변환·상호작용 특성은 추가 자료 참조. 이로써 Module 4를 마치고, 다음 모듈은 **시계열**이다.
