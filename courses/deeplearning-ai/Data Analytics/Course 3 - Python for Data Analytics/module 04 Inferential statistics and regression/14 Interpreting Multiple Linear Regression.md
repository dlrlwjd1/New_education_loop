# Interpreting Multiple Linear Regression

## 개요
- 다중 회귀 해석은 **모델 전체 맥락**에서 해야 한다 — R²·계수·p-값 모두 다른 변수들과 함께 고려.
- 변수 간 강한 상관은 **다중공선성(multicollinearity)** 을 일으켜 개별 계수 해석을 어렵게 한다.

## 내용

### 맥락 속 해석
- **R²**(예 0.854)는 **모델 전체**의 예측력 — 개별 변수의 기여도는 알 수 없음.
- **계수·p-값도 맥락 속**: carat의 p≈0은 **다른 변수(x·y·z)를 고정했을 때** carat이 여전히 가격에 영향(같은 치수 다이아면 무거운 게 더 비쌈). carat 계수 → 다른 변수 고정 시 1캐럿 증가마다 가격 +$10,230.

### 다중공선성 (multicollinearity)
- 계수가 직관과 어긋날 수 있음: x는 가격과 양의 관계인데 모델은 **음의 계수**(x 1단위↑ → −$884).
- 원인: carat·x가 서로 **강하게 상관**(무거우면 크다) + 둘 다 가격과 상관 → 모델이 어느 쪽이 가격을 올리는지 분리 못 함 → 한쪽 양·한쪽 음 계수로 함께 효과 포착.
- **다중공선성** = 여러 독립 변수가 서로 및 종속 변수와 강하게 상관. 다이아 데이터엔 흔함(carat·table·x·y·z 모두 크기 관련).
- **예측력엔 영향 적으나 개별 변수 해석을 어렵게 함**. statsmodels가 경고를 줄 수 있음(없을 수도).
- 대응: 상관 높은 변수 중 **하나만 남기기**, 또는 복합 특성 생성(범위 밖).
- 핵심: **계수·p-값 해석 시엔 중요, 예측만 할 땐 덜 중요**.

## 요약
- 다중 회귀는 **모델 전체 맥락**에서 해석하며, 계수는 "다른 변수 고정 시" 효과를 뜻한다.
- **다중공선성**(변수 간 강한 상관)은 계수를 직관과 어긋나게 만들지만 예측력엔 영향이 적다.
- 대응은 상관 변수 제거 등이다. 다음 강의는 **범주형 변수**를 회귀에 넣는 법이다.
