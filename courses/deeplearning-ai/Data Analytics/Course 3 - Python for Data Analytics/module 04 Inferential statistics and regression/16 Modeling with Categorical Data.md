# Modeling with Categorical Data

## 개요
- 인코딩한 범주형 변수를 회귀에 넣고, **훈련/테스트 분리(train-test split)** 로 모델을 학습·평가한다.
- 더미 변수 계수는 **제외된 카테고리 기준 상대값**으로 해석한다.

## 내용

### 훈련/테스트 분리 (train-test split)
- 일부 데이터(예: 1,000개)를 테스트용으로 남김(새 데이터 성능 평가). 슬라이싱:
  - `X_test = X[:1000]`, `X_train = X[1000:]`, `y_test = y[:1000]`, `y_train = y[1000:]` (같은 슬라이스로 행 정렬 유지).
- "시험 전 답을 보면 안 되듯" 테스트 데이터는 모델에 새것이어야 함.

### 학습
- `sm.OLS(y_train, X_train).fit()`. color 추가로 R² 약 1.5%p↑, 계수 모두 유의. carat 계수 ~$8,000/캐럿.

### 더미 계수 해석
- 각 color 계수는 **제외된 D 기준 상대값**(drop_first로 D 제거).
  - E: D보다 평균 ~$94 저렴(다른 조건 동일). I: D보다 ~$1,054 저렴.
- 모두 음수 → **같은 캐럿이면 D가 가장 비쌈**.
- 반전된 통찰: 원래 막대 그래프는 I·J가 더 비싸 보였으나, 그건 **덜 좋은 색 다이아가 더 큰** 경향 때문(색이 아니라 크기). 같은 캐럿이면 D가 더 가치↑. (color vs carat 막대로 확인 — 노란 색일수록 크기 증가)

## 예시

### 범주형 회귀·해석
```python
X_test, X_train = X[:1000], X[1000:]
y_test, y_train = y[:1000], y[1000:]
results = sm.OLS(y_train, X_train).fit()
# 더미 계수: D 기준 상대값 (E는 −$94, I는 −$1,054 …)
```

## 요약
- **훈련/테스트 분리**로 일부 데이터를 남겨 새 데이터 성능을 평가한다(슬라이싱).
- 범주형 변수 추가로 R²가 오르며, **더미 계수는 제외 카테고리(D) 기준 상대값**이다.
- 다중공선성처럼 계수가 반직관적일 수 있어 데이터로 통찰을 검증한다. 다음 강의는 새 모델로 예측이다.
