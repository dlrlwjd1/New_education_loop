# Interpreting the Output of a Regression Model

## 개요
- 회귀 결과표(`results.summary()`)에서 주목할 세 가지: **R²(결정계수)·계수의 p-값·계수 값**.
- 이들로 모델이 종속 변수를 얼마나 잘 설명·예측하는지 평가한다.

## 내용

### R² (결정계수)
- 독립 변수가 종속 변수 **분산을 설명하는 비율**(0~1, 높을수록 좋음). "carat만으로 price를 얼마나 정확히 예측하나".
- 예: **R² = 0.849** → carat이 price 변동의 **84.9%** 설명(단일 변수치곤 높음).

### 계수의 p-값
- **귀무가설**: 계수 = 0(효과 없음). **대립**: 계수 ≠ 0. 다른 가설 검정처럼 해석.
- **p < α(0.05)** → 기각 → 독립 변수가 종속 변수를 잘 예측(유의). p ≥ α면 해석·예측 진행 부적절.
- 예시: const·carat 계수 p-값 모두 0에 가까움 → 유의.

### 계수 값 → 방정식
- 유의성 확인 후 계수로 최적합선 구성. 예: **price = 7756 × carat − 2256**.
  - carat 계수 ≈ **7756** → 1캐럿 증가마다 가격 약 $7,756 상승.
  - (F-통계량과 그 p-값도 모델 전체 유의성 확인)

### LLM으로 해석
- 복잡한 summary는 LLM이 핵심을 짚어줌. 프롬프트에 **역할·과제** 부여("전문 통계학자로서... 가장 중요한 부분 위주로"). 단 **비공개·독점 결과는 공유 금지**.

## 예시

### 회귀 결과 해석
```
R² = 0.849            → carat이 price의 84.9% 설명
계수 p-값 < 0.05      → 유의 (계수 ≠ 0)
방정식: price = 7756 × carat − 2256
```

## 요약
- **R²**(설명력), **계수 p-값**(유의성), **계수 값**(방정식)이 회귀 해석의 핵심이다.
- p < α면 계수가 유의하며, 계수로 **y=mx+b** 예측 방정식을 만든다.
- LLM을 해석 파트너로 활용하되 민감 정보는 공유하지 않는다. 다음 강의는 **예측**이다.
