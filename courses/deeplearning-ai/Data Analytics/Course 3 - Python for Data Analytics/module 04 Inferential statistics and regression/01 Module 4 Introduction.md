# Module 4 Introduction

## 개요
- **Module 4 — 추론 통계(Inferential Statistics)** 소개. Python으로 예측과 결론을 도출한다.
- 신뢰 구간·가설 검정·시뮬레이션과 **선형 회귀(linear regression)** 를 다룬다.

## 내용

### 레슨 구성
- **Lesson 1**: 다이아몬드 데이터로 **신뢰 구간·평균 가설 검정** — 표준 오차·p-값 복습, 신뢰 구간 한 줄로 계산, 단일/두 표본 검정, 분포 시뮬레이션.
- **Lesson 2**: **단순 선형 회귀** — 정의·유용성, 강한 예측 변수 선택, 모델 학습·해석·예측.
- **Lesson 3**: **다중 선형 회귀** — 여러 특성 예측 변수, 범주형 데이터 반영, 모델 반복 개선.

### 선수 지식
- 선형 회귀 외 통계 개념(신뢰 구간·가설 검정)은 **Applied Statistics for Data Analytics** 코스 기반. 낯설면 그 코스를 먼저 수강 권장(이 모듈은 간략 복습만).

## 요약
- 이 모듈은 Python으로 **추론 통계**(신뢰 구간·가설 검정·시뮬레이션)와 **선형 회귀**를 적용한다.
- Lesson 1(신뢰 구간·검정) → Lesson 2(단순 회귀) → Lesson 3(다중 회귀·범주형) 순으로 진행한다.
- 통계 개념은 이전 코스 기반이며 간략 복습만 제공한다.
