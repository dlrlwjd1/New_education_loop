# What is Linear Regression?

## 개요
- **선형 회귀(linear regression)** 는 특성 간 관계를 정량화하고 **새 값을 예측**하는 추론 기법.
- 관계를 **y = mx + b**(직선) 형태로 모델링한다(m·b = 계수, coefficients).

## 내용

### 왜 회귀인가
- 예: 다이아 특성(크기·컷·투명도)으로 가격 예측. 신뢰 구간·가설 검정은 **개별 예측**에 부적합.
- 상관과 달리 **얼마나** 오르는지 정량화: "1캐럿 증가 → $10,000 상승".

### 두 단계
1. **학습(training)**: 기존 데이터로 관계 정량화 → 최적합 직선의 계수 m·b 결정. 예: price = 10000×carat + 2000.
2. **예측(prediction)**: 학습된 모델로 x에서 y 예측. 예: 0.5캐럿 → 10000×0.5+2000 = **$7,000**.

### 상관 vs 회귀
- **상관(correlation)**: 관계의 강도·방향만(예: carat–price 0.92). 얼마나 오르는지는 모름.
- **회귀**: 최적합선 방정식으로 **예측** 가능. 상관은 회귀 전 **가장 예측력 높은 변수 선택**에 사용.

### 변수 (variables)
- **독립 변수(independent, x축)**: 입력, 결과의 원인(carat).
- **종속 변수(dependent, y축)**: 예측 대상, 독립 변수에 의존(price).
- 판별: 인과 관계. 가격이 변한다고 다이아가 커지지 않지만 carat은 가격에 영향 → carat=독립, price=종속.

### 모델 구축 절차
1. 종속 변수 식별. 2. 상관·산점도·**pairplot** 으로 관계 탐색. 3. 가장 강한 상관의 독립 변수 하나 선택. 4. 통계 모듈로 학습해 m·b 결정 → 예측.
- 선형 회귀는 **선형 관계만** 모델링(독립 변수 변화가 종속 변수에 일정한 변화). 비선형 방법도 있으나 선형도 유효할 수 있음.

## 예시

### 선형 회귀
```
학습: price = m × carat + b   (예: 10000 × carat + 2000)
예측: 0.5캐럿 → 10000×0.5 + 2000 = $7,000
```

## 요약
- **선형 회귀**는 관계를 **y=mx+b** 로 정량화하고 새 값을 예측한다(학습→예측 2단계).
- **상관**은 강도·방향만, 회귀는 예측까지 하며 상관으로 최적 독립 변수를 고른다.
- **독립 변수**(입력·원인)로 **종속 변수**(예측 대상)를 예측한다. 다음 강의는 독립 변수 선택이다.
