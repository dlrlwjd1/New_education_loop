# LLMs for Model Iteration

## 개요
- LLM을 **모델 개선 파트너**로 활용 — 맥락(문제·요약표·데이터셋)을 주고 개선 제안을 받는다.
- 변환(transformation) 실험으로 모델을 반복 개선한다.

## 내용

### 맥락 제공과 제안
- 프롬프트에 문제·인코딩 방식·**summary 스크린샷**·데이터셋 업로드 → "개선안 3가지와 이유".
- LLM 제안: ① 상호작용 항, ② 다중공선성 확인, ③ **변환/비선형**(carat² 또는 로그).

### 다항 항 실험 (carat²)
- `df["carat_squared"] = df["carat"]**2` 추가 후 회귀. R² 0.864 → 0.867(미미).
- "carat과 carat² 둘 다 넣어도 되나?" → 예(선형·비선형 모두 포착). "왜 개선 미미?" → 비선형성이 미묘하거나 carat이 이미 강한 예측자, 다른 특성이 더 유익.

### 로그 변환 (log transformation)
- 예측 vs 실제 플롯이 급증 후 완만 → **y=log(x)** 형태 유사.
- LLM 제안: **price·carat 둘 다 로그 변환**. `np.log(df["price"])`, `np.log(df["carat"])`.
- 결과: R² **0.945**(약 10%p 대폭↑!). 예측 vs 실제가 훨씬 선형(단 **log(price)** 기준 값이라 해석 주의).

### 주의
- 변환은 예측력↑ 하지만 **해석 난이도↑**(복잡·모호). 개선 시 한 발 물러나 조사·동료 상의·LLM 해석 도움 활용.

## 예시

### 변환으로 개선
```python
df["carat_squared"] = df["carat"]**2   # 다항 (미미)
# 로그 변환 (대폭 개선)
y = np.log(df["price"])
x = sm.add_constant(np.log(df["carat"]))
# R² 0.945
```

## 요약
- LLM에 **맥락(문제·요약표·데이터)** 을 주고 개선 제안(상호작용·다중공선성·변환)을 받는다.
- **로그 변환**으로 R²가 0.864 → 0.945로 대폭 개선됐으나 **해석 난이도**가 커진다.
- 변환 후엔 신중히 검증한다. 다음 강의는 회귀 전 과정을 정리한다.
