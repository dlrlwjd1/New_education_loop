# Multiple Linear Regression

## 개요
- **다중 선형 회귀(multiple linear regression)** 는 **여러 독립 변수**로 종속 변수를 예측한다.
- 서로 다른 근본 원인을 포착하는 변수를 결합하면 예측력(R²)이 크게 향상된다.

## 내용

### 왜 여러 변수인가
- 단순 회귀는 좋은 출발점(예: carat이 다이아 가격의 85% 설명)이나, 여러 변수로 예측력↑.
- 예 — 졸업 소요 시간 예측: 고교 GPA(**학업 역량**), 나이(**개인 상황**, 일·가정 병행) 등 서로 다른 원인 포착.

### R² 결합 효과
- 고교 GPA만: R²≈0.2, 나이만: R²≈0.1.
- 둘 다 사용: **R² > 0.2** 기대 — 두 변수가 다른 원인을 측정하면 예측력↑.
- 변수 더 추가 가능(1학년 GPA, 성별 같은 범주형). 단 겹치는 변수(1학년 GPA는 고교 GPA와 유사 변동 설명)는 개선 적을 수 있으나 **실험해볼 것**.

### 원칙
- 종속 변수와 **강하게 상관**되고, 왜 영향을 주는지 **직관**으로 뒷받침되는 변수 조합 선택.
- 직관 + 데이터 기반 인사이트를 결합하고, 최종적으로 **summary로 강도 평가**.

## 요약
- **다중 선형 회귀**는 여러 독립 변수로 예측하며, 서로 다른 원인을 포착하는 변수 결합 시 R²가 향상된다.
- 종속 변수와 강한 상관 + 직관적 근거가 있는 변수를 고르고 실험한다.
- 다음 강의는 다중 회귀 모델을 코드로 학습한다.
