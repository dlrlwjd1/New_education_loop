# Vector Databases

## 개요
- **벡터 데이터베이스(vector database)** 는 고차원 벡터 데이터를 저장하고 ANN 같은 벡터 알고리즘을 구현하도록 **처음부터 설계된** DB로, LLM·시맨틱 검색 확산에 따라 2020년대 초 부상했다.
- 관계형 DB는 시맨틱 검색에서 비효율적인 KNN에 가깝게 작동하지만, 벡터 DB는 **근접 그래프 구축·벡터 거리 계산**에 최적화되어 대규모에서 훨씬 빠르다.
- 이 코스는 오픈소스 벡터 DB **Weaviate** 를 사용하며, 흐름은 **DB 설정 → 데이터 로드·인덱싱 → 쿼리(하이브리드 검색 + 필터)** 다.

## 내용

### 벡터 DB란
- 고차원 벡터 저장과 **근사 최근접 이웃(ANN)** 알고리즘 구현을 위해 설계된 DB.
- 표준 관계형 DB는 시맨틱 검색 성능이 비효율적 KNN에 가깝다. 벡터 DB는 **HNSW의 근접 그래프 구축**, **벡터 거리 계산** 등에 최적화되어 대부분의 벡터 기반 애플리케이션(특히 RAG)에서 잘 확장되고 빠르다.

### 이 코스의 도구 — Weaviate
- 로컬·클라우드 모두에서 실행 가능한 인기 오픈소스 벡터 DB. 다른 벡터 DB를 써도 기능은 거의 유사하다. 목표는 어떤 RAG 프로젝트에도 공통인 워크플로를 손에 익히는 것.

### 검색 준비 단계
1. **데이터베이스 설정**(인스턴스 생성 또는 기존 연결).
2. **문서 로드**.
3. 키워드 검색용 **희소 벡터(sparse vector)** 생성.
4. 시맨틱 검색용 **조밀 임베딩 벡터(dense embedding vector)** 생성.
5. ANN 검색용 **인덱스(예: HNSW 인덱스)** 생성.
- 이후 실제 검색 실행. (일부 단계는 자동 처리)

### Weaviate 사용 흐름 (개념)
- **컬렉션(collection) 생성**: 예) `article` 컬렉션(뉴스 기사의 title·body, 타입은 text). 이때 각 기사의 시맨틱 벡터를 만들 **임베딩 모델(vectorizer)** 을 지정한다.
- **데이터 추가**: `batch` 메서드로 삽입 — `batch.addObject` 가 객체를 추가하면서 오류를 집계·추적해 사후 교정하거나 오류가 많으면 중단할 수 있다.
- **벡터(시맨틱) 검색**: 컬렉션에 텍스트 쿼리를 전달. 메타데이터로 **distance**(쿼리 벡터와 객체 벡터 간 거리)를 함께 받을 수 있다.
- **키워드 검색**: Weaviate가 **역색인(inverted index)** 을 자동 생성. **BM25** 쿼리로 상위 문서를 받는다.
- **하이브리드 검색**: 키워드·벡터 검색을 백그라운드에서 **병렬** 수행하고, **alpha** 파라미터로 가중. 예: alpha=0.25 → 벡터 25% + 키워드 75%로 재랭킹해 상위 반환. 시맨틱 유사성과 엄격한 매칭을 균형 잡을 수 있어 **대다수 기업이 실전에서 사용**.
- **필터(filter)**: 특정 속성 값이 조건과 일치하는 객체만 통과시켜 반환.

### 전체 루프
DB 설정 → 데이터 로드·인덱싱 → 하이브리드 검색 + 필터 쿼리 작성.

## 예시

### 관계형 DB vs 벡터 DB (시맨틱 검색)
| 항목 | 관계형 DB | 벡터 DB |
|------|-----------|---------|
| 벡터 검색 성능 | 비효율(KNN에 가까움) | ANN 최적화, 빠름 |
| 근접 그래프/거리 계산 | 미지원/느림 | 전용 최적화 |
| 대규모 확장성 | 나쁨 | 우수 |

### Weaviate 하이브리드 검색 alpha
| alpha | 벡터 가중 | 키워드 가중 |
|-------|-----------|-------------|
| 0.25 | 25% | 75% |
| (튜닝) | 조절 가능 | 조절 가능 |

## 요약
- **벡터 데이터베이스**는 고차원 벡터 저장과 **ANN** 구현에 최적화된 DB로, 관계형 DB보다 시맨틱 검색이 훨씬 빠르고 잘 확장된다.
- 준비 단계는 **DB 설정 → 문서 로드 → 희소/조밀 벡터 생성 → 인덱스 생성**이며, 이후 검색을 실행한다.
- 이 코스의 **Weaviate** 는 벡터·키워드(BM25)·**하이브리드 검색(alpha 가중)** 과 **필터**를 제공하며, 하이브리드가 실전 표준이다.
- 다음 강의부터 프로덕션 성능을 높이는 **청킹(chunking)** 등을 다룬다.
