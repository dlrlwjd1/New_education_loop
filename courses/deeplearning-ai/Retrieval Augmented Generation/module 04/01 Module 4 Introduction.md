# Module 4 Introduction

## 개요
- 리트리버는 RAG의 핵심이지만, 실제 **두뇌(brains)** 는 **LLM** 이다. 리트리버가 유용한 정보를 찾아 준비해도, 결국 그 정보로 고품질 응답을 생성하는 것은 LLM이다.
- 모듈 4는 LLM의 작동 원리와, RAG 안에서 LLM 성능을 높이는 구체적 기법을 다룬다.

## 내용

### 이 모듈에서 배우는 것
- LLM이 기반하는 **트랜스포머 아키텍처(transformer architecture)** 심층 학습.
- 코드로 **LLM 호출(LLM call)** 구성하기.
- 그 기본 워크플로에 반복적으로 살을 붙여, LLM이 리트리버가 제공한 정보에 **근거(grounded)** 한 고품질 응답을 내도록 보장하기.
- LLM 성능의 한계를 밀어붙이는 **고급 기법**과, 전형적 RAG 프로젝트에서 실제로 통하는 실용적 조언.
- 모듈 끝의 프로그래밍 과제로 RAG 시스템 구축.

## 요약
- 모듈 4는 RAG의 **두뇌인 LLM** 에 집중해, 트랜스포머 아키텍처·LLM 호출·프롬프트 기법을 다룬다.
- 목표는 LLM이 리트리버가 제공한 정보에 **근거한 고품질 응답**을 생성하도록 만드는 것이다.
