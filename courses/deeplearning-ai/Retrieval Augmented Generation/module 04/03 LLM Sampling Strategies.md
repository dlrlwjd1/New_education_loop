# LLM Sampling Strategies

## 개요
- LLM이 추가하는 모든 토큰은 **가중 무작위 선택(weighted random choice)** 이다. 이 무작위성을 이해·제어하는 것이 LLM 활용의 큰 부분이다.
- 확률 분포의 모양을 바꾸는 **온도(temperature)**, 후보를 좁히는 **top-k / top-p 샘플링**, 개별 토큰 확률을 조정하는 **반복 페널티(repetition penalty)·로짓 편향(logit bias)** 등이 있다.
- 권장: 용도에 맞는 **temperature와 top-p** 를 먼저 정하고(사실/코드=낮게, 창의=높게), 이후 특정 문제에 따라 다른 기법을 도입한다.

## 내용

### 확률 분포와 확신도
- 예: 프롬프트 "the sky is" → blue 50%, bright 25%, 나머지는 10% 이하로 급감.
- 왼쪽에 **뾰족한 스파이크** = 모델이 **확신**(소수 토큰만 실질 후보). **평평한 분포** = **불확실**(뚜렷한 승자 없음).

### 그리디 디코딩(greedy decoding)
- 무작위 선택 없이 **항상 최고 확률 토큰**을 고름.
- 장점: **결정론적(deterministic)** — 같은 프롬프트에 항상 같은 응답.
- 단점: 텍스트가 **예측 가능·일반적·딱딱**해지고, **같은 구절을 반복하는 루프**에 빠질 수 있다(빠져나올 장치 없음).
- 적합: 코드 자동완성처럼 예측 가능·결정론적 출력이 필요할 때, 또는 디버깅용 임시 설정.

### 온도(temperature) — 가장 널리 쓰는 파라미터
- 확률 분포의 **모양을 바꾸는 다이얼**. (토큰 순서는 그대로, 선택 확률만 변함)
- **1(기본)**: 원래 분포.
- **낮음**: 더 뾰족 → 가장 그럴듯한 토큰만 기회를 가짐. **0** = 그리디 디코딩(최상위 토큰 100%).
- **약간 높임(1.1~1.3)**: 분포 평탄화 → 덜 그럴듯한 토큰에도 기회 → **다양·창의적** 텍스트.
- **너무 높음**: 거의 균등 분포 → 말이 안 되는 토큰도 비슷한 확률로 선택.

### top-k / top-p 샘플링 — 긴 꼬리(long tail) 제어
- 어떤 온도든 분포엔 오른쪽으로 **말이 안 되는 토큰의 긴 꼬리**가 남는다. 이를 제어:
- **top-k 샘플링**: 상위 **k개** 토큰에서만 선택(예: temperature 1.1 + top 5). 분포 모양과 무관하게 **항상 같은 크기 풀**.
- **top-p 샘플링**: 누적 확률이 임계값 이하인 토큰들에서 선택(예: top-p 85% → 왼쪽부터 더해 85% 넘을 때까지). 더 **동적·반응적**: 확신하면(소수 고확률) 풀이 좁아지고, 불확실하면(평평) 풀이 넓어진다.

### 개별 토큰 확률 조정
- **반복 페널티(repetition penalty)**: 이미 등장한 단어의 확률을 낮춰 반복을 줄이고 자연·다양하게.
- **로짓 편향(logit bias)**: 특정 토큰의 확률을 영구적으로 올리거나 내림. 예: 욕설 단어를 낮추기, 분류기라면 카테고리 토큰들을 높여 그중에서만 고르게 하기.

### 실무 조합 예 + 권장
- 예시 API 호출(무난한 범용): **temperature 0.8, top-p 0.9, repetition penalty 1.2** → 다소 보수적 선택, 꼬리 회피, 반복 약간 억제.
- 권장 순서:
  1. 용도에 맞는 **temperature·top-p** 설정 — 코드/사실 질문 = **낮게**, 창의 영역 = **높게**.
  2. 관찰된 특정 문제에 따라 **반복 페널티·로짓 편향** 등 추가.
  3. 프로젝트에 맞는 설정으로 **반복 조정**.

## 예시

### 무작위성 제어 기법
| 기법 | 무엇을 하나 |
|------|-------------|
| 그리디 디코딩 | 항상 최고 확률(결정론적) |
| temperature | 분포 모양 조절(낮=뾰족, 높=평평) |
| top-k | 상위 k개에서 선택(고정 풀) |
| top-p | 누적 확률 임계값까지(동적 풀) |
| repetition penalty | 반복 단어 확률↓ |
| logit bias | 특정 토큰 확률↑/↓ |

### 용도별 설정 방향
| 용도 | temperature | top-p |
|------|-------------|-------|
| 코드·사실 질문 | 낮게 | 낮게 |
| 창의적 영역 | 높게 | 높게 |

## 요약
- LLM의 토큰 선택은 **가중 무작위**이며, 이를 제어하는 핵심은 분포 모양을 바꾸는 **temperature** 와 후보를 좁히는 **top-k/top-p** 다.
- **그리디 디코딩(temp=0)** 은 결정론적이지만 반복·일반화 위험이 있고, **top-p** 는 확신도에 따라 풀이 변하는 동적 방식이다.
- **반복 페널티·로짓 편향**으로 개별 토큰 확률을 조정할 수 있다(반복 억제, 욕설 차단, 분류 강제 등).
- 권장: 용도에 맞는 temperature·top-p를 먼저 정하고(사실/코드=낮게, 창의=높게), 문제에 따라 다른 기법을 반복 조정하라.
