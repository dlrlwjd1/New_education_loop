# RAG vs. Fine-Tuning

## 개요
- **파인튜닝(fine-tuning)** 은 프롬프트를 증강하는 RAG와 달리, 기성 LLM을 자신의 데이터로 **재훈련**해 특정 맥락 성능을 높인다(보통 **지도 파인튜닝, SFT / 인스트럭션 튜닝**).
- 핵심 합의: **RAG = 지식 주입(knowledge injection)**, **파인튜닝 = 도메인 적응(domain adaptation)**.
- 둘은 경쟁이 아니라 **상보적** — 함께 쓰면 좋다(예: 검색 정보를 응답에 잘 통합하도록 모델을 파인튜닝).

## 내용

### 파인튜닝이란
- 자신의 데이터로 LLM을 재훈련해 **내부 파라미터를 갱신**. 보통 **지도 파인튜닝(SFT, supervised fine-tuning)** — 적응하려는 도메인의 **라벨된 데이터셋** 사용.
- **인스트럭션 파인튜닝(instruction fine-tuning)**: 데이터셋이 **지시(프롬프트/질문) + 기대 정답(ground truth)** 으로 구성. 모델에 입력을 주고 출력이 정답에 얼마나 가까운지 보고 파라미터를 조정 — 초기 훈련과 유사하나 **특정 도메인** 데이터를 씀.

### 예시 — 헬스케어 도메인
- 범용 모델에 "관절통·발진·햇빛 민감" 증상을 물으면 **일반적 답·톤**(의료 데이터로 특화 안 됨).
- 의료 도메인 지시·응답으로 인스트럭션 튜닝하면, 같은 프롬프트에 **더 정확·상세하고 의료 도메인에 맞는 스타일**로 답하는 전문가가 된다.

### 파인튜닝의 트레이드오프
- 특정 도메인(초기 의료 진단, 법률 브리핑 요약 등) 특화에 잘 맞지만, **다른 도메인 성능은 오히려 떨어질 수 있다**(대상 도메인만 최적화하므로). 해당 도메인 안에서만 쓴다면 감수할 가치가 있다.
- 특히 **에이전틱 시스템의 작은 모델**에 유용: "이 프롬프트가 벡터 DB 검색이 필요한지 판단"처럼 단일 작업만 할 걸 안다면, **가볍고 작은 모델을 그 한 작업에 집중 파인튜닝**하면 된다.
- 중요: 파인튜닝은 **새 정보를 가르치는 데는 대체로 부적합**. 파인튜닝은 **어떻게 응답하는지**(단어·스타일·구조)에 더 큰 영향을 주고, **무엇을 아는지**에는 영향이 덜하다.

### RAG vs 파인튜닝 — 언제 무엇을
- **RAG = 지식 주입**: LLM이 **새 정보**에 접근해야 하면 RAG. 정보를 프롬프트에 주입하면 기성 LLM이 응답에 반영.
- **파인튜닝 = 도메인/작업 특화**: 특정 작업·도메인에 특화시키려면 파인튜닝. 특히 RAG의 프롬프트 라우팅처럼 **하나의 이산적 작업**을 맡을 때 적합.
- **함께 사용**: 검색된 정보를 최종 응답에 잘 통합하도록 모델을 파인튜닝 = RAG 안의 역할에 특화. 최선은 종종 **둘 다**.

### 실무 팁
- 파인튜닝은 복잡한 주제라 이 코스 범위 밖 — 별도 코스 권장.
- 직접 안 해도 **이미 특정 작업·도메인용으로 파인튜닝된 모델**을 온라인 저장소에서 찾아 쓸 수 있다.
- 파인튜닝과 RAG는 경쟁 대안처럼 묘사되지만 **상보적 도구**로, RAG 파이프라인에 파인튜닝 모델을 넣거나 핵심 생성 LLM을 파인튜닝하면 성능이 향상될 수 있다.

## 예시

### RAG vs 파인튜닝 비교
| 항목 | RAG | 파인튜닝 |
|------|-----|----------|
| 방식 | 프롬프트 증강(검색) | 파라미터 재훈련 |
| 강점 | **지식 주입**(새 정보) | **도메인/작업 적응**(스타일·특화) |
| 새 정보 학습 | 우수 | 부적합 |
| 최신성 | 지식 베이스만 갱신 | 재훈련 필요 |
| 부작용 | — | 타 도메인 성능↓ 가능 |
| 결론 | 함께 쓰면 최선(상보적) | |

## 요약
- **파인튜닝**은 자신의 데이터로 LLM을 재훈련(SFT/인스트럭션 튜닝)해 특정 도메인·작업에 특화시키지만, 타 도메인 성능이 떨어질 수 있고 **새 정보 학습에는 부적합**하다.
- **RAG = 지식 주입, 파인튜닝 = 도메인 적응**이 핵심 구분이다.
- 둘은 경쟁이 아니라 **상보적**이며, RAG 파이프라인에 파인튜닝된(작은·특화) 모델을 결합하거나 생성 LLM을 파인튜닝하면 성능이 향상된다.
