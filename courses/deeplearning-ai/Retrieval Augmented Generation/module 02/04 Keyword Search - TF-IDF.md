# Keyword Search - TF-IDF

## 개요
- **키워드 검색(keyword search)** 은 프롬프트와 **공통 단어**를 가진 문서를 검색하는 기법으로, 수십 년간 검색을 이끈 단순·효과적 방식이다.
- 프롬프트와 문서를 **단어 가방(bag of words)** 으로 보고 단어 빈도를 **희소 벡터(sparse vector)** 로 저장하며, 이를 모아 **역색인(inverted index)/용어-문서 행렬** 을 만든다.
- 단순 점수 → 빈도 반영 → 문서 길이 정규화 → **IDF(역문서빈도)** 가중을 거쳐 **TF-IDF** 점수가 되며, 이는 키워드 검색 성능의 표준 기준선이다.

## 내용

### 단어 가방(bag of words)과 희소 벡터
- 프롬프트·문서를 **단어 가방**으로 취급 — 단어 순서는 무시하고 **어떤 단어가 몇 번** 나오는지만 본다. 예: "making pizza without a pizza oven" → pizza 2회, making·without·a·oven 각 1회.
- 이 단어 빈도를 **벡터**에 저장. 벡터는 시스템 어휘의 각 단어마다 한 칸(수만 칸 가능)을 가지며, 대부분이 0이라 **희소 벡터(sparse vector)** 라 부른다.

### 역색인(inverted index) / 용어-문서 행렬
- 각 문서의 희소 벡터를 격자로 배열 → **용어-문서 행렬(term-document matrix)**. 열=문서, 행=단어.
- 이를 **역색인(inverted index)** 이라고도 한다. 보통은 문서에서 시작해 어떤 단어가 있는지 보지만, 여기서는 **단어에서 시작해 그 단어를 포함한 모든 문서**를 찾기 때문에 "역(inverted)"이다.
- 역색인은 검색 전에 **한 번** 만들어 둔다. 프롬프트가 오면 프롬프트의 희소 벡터를 빠르게 생성한다.

### 점수 매기기 — 4단계 개선
1. **단순 점수**: 프롬프트의 각 **키워드(keyword)** 마다 그 행을 훑어, 해당 단어를 하나라도 포함한 문서에 1점. 키워드 5개면 최고 5점. → 문제: **여러 번 등장**을 반영 못 함.
2. **빈도 반영**: 등장 횟수만큼 점수(문서 열의 숫자를 더함). → 문제: **긴 문서**가 단지 길어서 키워드를 많이 포함해 유리.
3. **길이 정규화**: 문서 점수를 그 문서의 총 단어 수로 나눔 → 키워드가 차지하는 **비중**을 보상하고 긴 문서 편향을 완화.
4. **IDF 가중**: 위까지는 모든 키워드를 동등 취급("the" 같은 불용어도 "pizza"만큼) → **역문서빈도(IDF, inverse document frequency)** 로 단어별 가중.

### IDF(inverse document frequency) 계산
- 각 단어가 **몇 개 문서에 등장하는지 ÷ 전체 문서 수** = 문서빈도(document frequency).
  - 예(문서 100개): "pizza"가 5개에 등장 → 5/100 = 0.05. "the"가 100개 전부 → 100/100 = 1.
- **드문 단어를 보상**하려 분수를 뒤집는다(invert): pizza IDF = 20, the IDF = 1.
- 드문 단어를 과보상하지 않도록 보통 **IDF의 로그(log)** 를 쓴다 → 드문 단어가 여전히 높지만 과장이 완화됨.

### TF-IDF 행렬과 점수
- 역색인의 각 행 숫자에 그 단어의 **IDF를 곱함** → **TF-IDF 행렬**(term frequency × inverse document frequency).
- 채점: 프롬프트의 각 키워드 행을 훑어 각 문서에 해당 TF-IDF 점수를 부여.
- 결과: 키워드를 자주 쓰되 특히 **전체 지식 베이스에서 드문 키워드**를 많이 가진 문서가 높은 점수. 예: "pizza", "oven"을 포함한 문서가 "a", "without"만 있는 문서보다 훨씬 높다.
- TF-IDF는 키워드 검색 성능의 **표준 기준선(baseline)** 이다. 현대 시스템은 이를 다듬은 **BM25** 를 주로 쓴다(다음 강의).

## 예시

### 점수 개선 단계
| 단계 | 방법 | 해결한 문제 |
|------|------|-------------|
| 1 | 키워드 포함 시 1점 | (기본) |
| 2 | 등장 횟수만큼 점수 | 반복 등장 반영 |
| 3 | 문서 길이로 나눔 | 긴 문서 편향 완화 |
| 4 | IDF 가중(log) | 드문 단어 보상 |

### IDF 예시 (문서 100개)
| 단어 | 등장 문서 | DF | IDF(역수) |
|------|-----------|-----|-----------|
| pizza | 5 | 0.05 | 20 |
| the | 100 | 1 | 1 |

## 요약
- **키워드 검색**은 프롬프트와 공통 단어를 가진 문서를 찾는 기법으로, **단어 가방 → 희소 벡터 → 역색인** 구조를 쓴다.
- 점수는 단순 포함 → 빈도 → 길이 정규화 → **IDF 가중**으로 발전하며, 이 결합이 **TF-IDF** 다.
- TF-IDF는 키워드를 자주·특히 **드물게 등장하는** 단어를 많이 가진 문서를 높게 평가하는 표준 기준선이다.
- 현대 시스템은 이를 정교화한 **BM25** 를 쓴다 — 다음 강의 주제.
