# Hybrid Search

## 개요
- **하이브리드 검색(hybrid search)** 은 키워드 검색·시맨틱 검색·메타데이터 필터링을 **함께** 써서 각각의 강점을 취한다.
- 두 검색이 각각 랭킹된 목록을 반환하고, 메타데이터로 거른 뒤 **역순위 융합(Reciprocal Rank Fusion, RRF)** 으로 하나의 최종 랭킹으로 합친다.
- RRF의 **K**(최상위 문서 영향 조절)와 **beta**(시맨틱 vs 키워드 가중치, 보통 70:30 시작) 등 하이퍼파라미터로 시스템을 튜닝한다.

## 내용

### 세 기법 복습
- **메타데이터 필터링**: 문서 메타데이터의 엄격한 기준으로 결과를 좁힘. 빠르고 구현·해석 쉬움. 단독 검색엔 약하지만 다른 방식이 못 주는 **yes-no 필터** 제공.
- **키워드 검색**: 프롬프트와 같은 키워드로 채점·랭킹. 빠르고 구현 쉬우며, **전문 용어·제품명**에서 특히 강함(정확한 단어 포함). 단, **정확 일치**에 의존해 의미가 같아도 단어가 다르면 못 찾음.
- **시맨틱 검색**: 의미 유사성으로 채점·랭킹(벡터 임베딩 거리). 키워드보다 느리고 연산 부담이 크지만 **유연성**은 독보적.

### 하이브리드 파이프라인
1. 프롬프트를 리트리버가 받는다.
2. **키워드 검색 + 시맨틱 검색**을 모두 수행 → 두 개의 랭킹된 목록(예: 각 50개, 겹치되 순서 다름).
3. 두 목록을 **메타데이터로 필터링**해 무관 문서 제거(예: 키워드 목록 35개, 시맨틱 목록 30개 남음).
4. 두 목록을 **하나의 랭킹으로 결합** → 흔히 **역순위 융합(RRF)** 사용.
5. 요청된 개수(**top K**)만큼 최종 하이브리드 랭킹 상위 문서를 반환.

### 역순위 융합(Reciprocal Rank Fusion, RRF)
- 각 목록에서 **순위(rank)** 에 따라 점수를 준다. 문서 점수 = 각 목록에서 **순위의 역수** 합.
- K=0일 때: 1위 = 1점, 2위 = 1/2점, 10위 = 1/10점. 예: 한 목록 2위(1/2=0.5) + 다른 목록 10위(1/10=0.1) = **총 0.6점**. 이 총점으로 재랭킹.
- **K 하이퍼파라미터** — 최상위 문서의 영향력 조절:
  - K=0: 어느 목록에서든 1위면 즉시 전체 최상위로 치솟음(1위 1점 vs 10위 0.1점 → 10배 차이).
  - K=50: 1위=1/50, 10위=1/60 → 차이가 훨씬 완만. 1위가 유리하되 다른 목록을 지배하진 않음.
- 주의: RRF는 **순위만** 볼 뿐, 그 순위를 만든 **점수 자체는 무시**한다(1위가 2위보다 압도적이었어도 반영 안 함).

### beta 하이퍼파라미터 (가중치)
- 시맨틱/키워드 랭킹에 가중치를 부여. 예: beta=0.8 → 시맨틱 80%, 키워드 20%.
- **70:30(시맨틱 70, 키워드 30)** 이 보통 좋은 출발점이며 시스템에 맞게 튜닝.
  - 정확한 단어 매칭이 중요하면 **키워드**를 더 무겁게.
  - 의미 유사성이 더 중요하면 **시맨틱(벡터)** 을 더 무겁게.

### 튜닝 여지
- BM25 파라미터 조정, 필터링할 메타데이터 선택, RRF에서 키워드 vs 시맨틱 **가중치 변경** 등 다양한 튜닝 지점이 있어, 지식 베이스 데이터·프로젝트 요구에 맞춰 성능을 조정할 수 있다.

## 예시

### 하이브리드 검색 구성 요소
| 요소 | 역할 | 튜닝 파라미터 |
|------|------|---------------|
| 키워드 검색 | 정확한 단어 매칭 | BM25 하이퍼파라미터 |
| 시맨틱 검색 | 의미 기반 유연 매칭 | 임베딩 모델 선택 |
| 메타데이터 필터링 | 엄격한 배제 | 필터 기준 |
| RRF 결합 | 순위 융합 | K, beta(가중치) |

### RRF 점수 예시 (K=0)
| 문서 | 키워드 순위 | 시맨틱 순위 | 점수 |
|------|-------------|-------------|------|
| A | 2위 (0.5) | 10위 (0.1) | 0.6 |

## 요약
- **하이브리드 검색**은 키워드(정확 매칭)·시맨틱(의미 유연 매칭)·메타데이터 필터링(엄격 배제)을 결합해 각 강점을 취한다.
- 두 검색의 랭킹 목록을 메타데이터로 거른 뒤 **역순위 융합(RRF)** 으로 합치며, RRF는 점수가 아닌 **순위**만 사용한다.
- **K**(최상위 영향)와 **beta**(시맨틱:키워드 가중치, 보통 70:30 시작)로 튜닝하고, 최종 랭킹 상위 **top K** 문서를 반환한다.
- 튜닝하려면 성능 측정이 필요하다 → 다음 강의에서 **리트리버 평가(evaluating retrieval)** 를 다룬다.
