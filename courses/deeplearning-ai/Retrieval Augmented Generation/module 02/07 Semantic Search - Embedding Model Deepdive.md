# Semantic Search - Embedding Model Deepdive

## 개요
- 임베딩 모델의 임무: **유사한 텍스트는 가까운 벡터로, 이질적 텍스트는 먼 벡터로** 매핑하는 것.
- 이를 위해 **양성 쌍(positive pair)/음성 쌍(negative pair)** 을 대량 모아 **대조 학습(contrastive training)** 으로, 양성 쌍은 당겨 가깝게·음성 쌍은 밀어 멀게 하도록 파라미터를 반복 갱신한다.
- 핵심 시사점: 벡터 공간의 위치는 **추상적·무작위적**이며 학습으로 클러스터가 형성될 뿐이고, **같은 임베딩 모델이 만든 벡터끼리만** 비교해야 한다.

## 내용

### 양성 쌍 / 음성 쌍
- **양성 쌍(positive pair)**: 의미가 유사한 두 텍스트("good morning" ↔ "hello") → 가깝게 임베딩되어야 함.
- **음성 쌍(negative pair)**: 의미가 다른 두 텍스트("good morning" ↔ "that's a noisy trombone") → 멀게 임베딩되어야 함.

### 훈련 절차 — 대조 학습(contrastive training)
1. **예시 수집**: 대량의 양성·음성 쌍(흔히 수백만 쌍)을 모은다. 한 단어/텍스트가 여러 예시에 포함되어 다양한 개념과의 관계를 포착한다.
2. **무작위 초기화**: 훈련 시작 시 각 텍스트를 **무작위 벡터**에 임베딩(의미와 무관한 횡설수설). 이 상태로 검색하면 결과가 엉망이다.
3. **평가**: 모델이 양성 쌍을 얼마나 잘 붙였고 음성 쌍을 얼마나 잘 떼어놓았는지 자문한다. 양성·음성 예시의 **대조(contrast)** 로 성능을 평가하므로 **대조 학습**이라 부른다.
4. **파라미터 갱신**: 성능에 따라, 양성 쌍은 **가깝게** 음성 쌍은 **멀게** 이동시키는 알고리즘으로 내부 파라미터를 갱신.
5. **반복**: 갱신된 파라미터로 다시 임베딩 → 평가 → 갱신을 여러 번 반복하며, 쌍들을 밀고 당긴다. 결국 양성 쌍은 뭉치고 음성 쌍은 흩어진다.

### 단일 텍스트 관점 (anchor)
- **앵커(anchor)**: "he could smell the roses"
  - 양성 쌍: "a field of fragrant flowers" → 당겨 가깝게.
  - 음성 쌍: "a lion roared majestically" → 밀어 멀게.
- 3개면 시각화가 쉽지만, 실제로는 **수백만 개의 앵커·양성·음성** 점을 동시에 처리 → 모든 벡터가 여러 방향으로 동시에 밀리고 당겨진다.
- 그래서 모델은 **수백~수천 차원**을 쓴다 — 고차원이 미묘한 관계를 반영할 배치 옵션을 많이 준다.

### 핵심 시사점
- 훈련 후 벡터가 의미를 담는 이유는, 유사한 텍스트가 **벡터 공간의 유사한 영역**으로 당겨졌기 때문이다.
- **위치는 추상적·무작위적**: 훈련 전엔 위치에 의미가 없다. 훈련 후 특정 위치가 의미를 갖는 것은 그곳에 유사 개념 **클러스터**가 형성됐기 때문. (예: 사자 관련 단어 클러스터, 트롬본 관련 클러스터)
- 같은 훈련을 **다른 초기 무작위 벡터**로 두 번 하면, 같은 클러스터가 형성되지만 **위치는 달라진다**.
- **같은 임베딩 모델이 생성한 벡터끼리만 비교**하라. 모델마다 훈련 데이터·차원 수·초기값이 달라, 서로 다른 모델의 벡터를 비교하면 무의미하다.

### 실무
- RAG를 만들려고 임베딩 모델을 직접 훈련할 필요는 없다. 보통 **기성(off-the-shelf) 임베딩 모델**을 쓰며, 유사한 단어·문장·문서를 유사 위치에 놀랍도록 잘 배치한다. 거리 측정도 직접 구현할 일은 거의 없다.
- 다만 작동 원리를 알면 RAG에서 벡터를 어떻게 쓸지 더 잘 판단할 수 있다.

## 예시

### 대조 학습 요약
| 개념 | 의미 |
|------|------|
| 양성 쌍 | 유사 텍스트 → 가깝게 |
| 음성 쌍 | 이질 텍스트 → 멀게 |
| 대조 학습 | 양성·음성 대조로 평가·갱신 반복 |
| 앵커 | 기준 텍스트, 양성은 당기고 음성은 밀어냄 |

## 요약
- 임베딩 모델은 **양성/음성 쌍**을 대량 모아 **대조 학습**으로 훈련되며, 무작위 초기화에서 시작해 양성은 당기고 음성은 밀어 파라미터를 반복 갱신한다.
- 고차원(수백~수천)이 미묘한 관계를 반영하고, 훈련 후 유사 개념이 **클러스터**를 이루어 벡터가 의미를 담는다.
- 벡터 공간의 위치는 **추상적·무작위적**이며(같은 훈련도 매번 위치가 다름), **같은 모델의 벡터끼리만** 비교해야 한다.
- 실무에서는 기성 임베딩 모델을 사용하며, 다음 강의에서 이 조밀한(dense) 벡터를 리트리버에 활용하는 법을 다룬다.
