# Semantic Search - Introduction

## 개요
- **시맨틱 검색(semantic search)** 은 **공유된 의미(meaning)** 로 문서와 프롬프트를 매칭해, 키워드 검색이 놓치는 뉘앙스를 잡는다. (예: 동의어 happy·glad를 매칭하고, 프로그래밍 언어 Python과 뱀 Python을 구분)
- 큰 틀은 키워드 검색과 같다(문서·프롬프트를 벡터로 만들고 비교). 차이는 벡터를 **임베딩 모델(embedding model)** 로 생성한다는 점이다.
- 임베딩 모델은 **의미가 비슷한 것을 공간상 가까운 위치**에 매핑하며, 프롬프트 벡터와 문서 벡터의 **거리(distance)** 로 유사도를 정량화한다.

## 내용

### 키워드 검색과의 공통점·차이점
- **공통**: 모든 문서와 프롬프트를 벡터로 매핑 → 벡터를 비교해 점수 → 가장 근접한 문서를 찾음.
- **차이**: 키워드 검색은 단어 등장 횟수를 세지만, 시맨틱 검색은 문서/프롬프트를 **임베딩 모델**에 통과시켜 벡터를 생성한다.

### 임베딩 모델(embedding model) — 의미를 공간에 배치
- 단어(또는 텍스트)를 공간상 **위치(벡터)** 로 매핑한다. 예: pizza → (3,1), bear → (5,2)를 x-y 평면의 점으로.
- 핵심(거의 마법 같은 부분): **의미가 유사한 것을 가까운 위치**에 배치한다. food·cuisine은 가깝게, trombone·cat은 멀리.
- 축(x, y)에 단순한 해석("음식 축", "동물 축")은 없다. 그냥 **비슷한 의미의 점들이 뭉쳐 있는** 평면으로 생각하면 된다.
- 단어 관계는 복잡해 2차원으론 부족하다. 3차원이면 더 많은 클러스터 공간이 생기고, 실제 임베딩 모델은 **수백~수천 차원**을 써 배치 유연성이 매우 크다. 고차원은 그릴 수 없지만 수학적 원리는 동일하다: 벡터 = 공간상 좌표, 유사 개념은 가깝게, 이질 개념은 멀리.

### 단어를 넘어 — 문장·문서 임베딩
- 임베딩 모델은 개별 단어뿐 아니라 **문장·문서 전체**에도 존재한다. 입력 종류는 달라도 각각 **하나의 벡터(공간상 점)** 를 출력한다.
- 예 세 문장:
  1. "He spoke softly in class."
  2. "He whispered quietly during class."
  3. "Her daughter brightened the gloomy day."
  → 1·2 벡터는 가깝고, 3은 멀리 떨어진다.

### 거리(유사도) 측정 방법
- **유클리드 거리(Euclidean distance)**: 두 벡터를 직선으로 잇는 최단 거리(피타고라스 정리를 고차원으로 확장). 단, **아주 고차원에서는 모든 점이 서로 멀어져** 잘 안 쓰인다.
- **코사인 유사도(cosine similarity)** (가장 흔함): 두 벡터의 **방향** 유사성을 측정(거리와 무관). 예: (10,10)과 (100,100)은 멀지만 같은 방향. 값 범위 **1(같은 방향) ~ -1(정반대)**.
- **내적(dot product)**: 한 벡터를 다른 벡터에 투영한 길이. 길이·방향이 비슷하면 크고, 90도면 0, 반대면 음수. 값 범위 **-∞ ~ +∞**.
- 공통 직관: 내적·코사인 유사도 모두 **값이 클수록 벡터가 가깝고 = 개념이 유사**. (직접 구현할 일은 거의 없지만 원리를 알면 유용)

### 시맨틱 검색 흐름
1. 임베딩 모델로 모든 문서를 벡터 공간에 투영(의미 유사 문서는 가깝게).
2. 프롬프트도 임베딩해 벡터를 얻는다.
3. 프롬프트 벡터와 각 문서 벡터의 **거리 측정**.
4. 거리가 가까운 순으로 정렬해 **가장 가까운 문서 반환** = 프롬프트와 의미가 가장 유사한 문서.

## 예시

### 거리 측정 방식 비교
| 측정 | 무엇을 재나 | 값 범위 | 비고 |
|------|-------------|---------|------|
| 유클리드 거리 | 직선 거리 | 0~ | 고차원에서 약함 |
| 코사인 유사도 | 방향 유사성 | -1 ~ 1 | 가장 흔함 |
| 내적(dot product) | 투영 길이 | -∞ ~ +∞ | 길이+방향 반영 |

### 키워드가 못 잡는 것을 시맨틱이 해결
- 동의어(happy ↔ glad) 매칭
- 다의어(프로그래밍 Python ≠ 뱀 Python) 구분

## 요약
- **시맨틱 검색**은 **임베딩 모델**로 문서·프롬프트를 벡터로 만들어, **의미가 유사한 것을 공간상 가깝게** 배치한 뒤 **거리**로 유사도를 측정한다.
- 임베딩 벡터는 수백~수천 차원이며, 유사 개념은 가깝고 이질 개념은 멀다 — 단어·문장·문서 모두에 적용된다.
- 유사도는 주로 **코사인 유사도**(값이 클수록 유사)로 측정하며, 프롬프트에 가장 가까운 문서를 반환한다.
- 키워드가 못 잡는 동의어·다의어 뉘앙스를 잡는 것이 강점이며, 다음 강의에서 **임베딩 모델의 훈련 원리**를 더 깊이 다룬다.
