# A Conversation with Andrew Ng

## 개요
- Andrew Ng와 강사 **Zain Hasan**의 대담으로 코스를 여는 강의. **RAG(Retrieval Augmented Generation)** 는 LLM 응답의 품질·정확성을 높이는 가장 널리 쓰이는 기법임을 소개한다.
- RAG의 핵심 아이디어는 **고전적 검색(search) 시스템과 LLM의 추론(reasoning) 능력을 결합**하는 것이다.
- 기본 RAG부터 최신 **에이전틱 RAG(agentic RAG)** 까지, 검색과 LLM의 기초 원리와 실전 튜닝 팁을 함께 다룬다.

## 내용

### RAG란 무엇이며 왜 필요한가
- LLM은 학습된 (주로 공개 인터넷) 데이터만 안다. **독점 데이터(proprietary data, 예: 사내 문서)** 로 질문에 답하려면, RAG가 모델에 그 추가 데이터에 대한 접근을 제공한다.
- 이를 통해 LLM은 **학습하지 않은 사실**로도 답할 수 있다. ChatGPT·Claude·Gemini가 "웹을 검색 중"이라고 하는 것도 최신·정확한 응답을 위해 추가 정보에 접근하는 예다.

### 강사 소개 — Zain Hasan
- AI/ML 엔지니어·연구자·교육자. 지난 10년 대부분을 유망 AI 기업에서 근무.
  - **Weaviate**: RAG의 핵심 구성 요소인 선도적 **벡터 데이터베이스(vector database)** 회사.
  - **Together AI**: LLM 서비스 제공사.

### 왜 RAG를 배우는가
- 개념 자체는 복잡하지 않지만 **구현 방법이 무수히 많고**, 설계 선택(design choice)이 시스템의 정확도·속도를 크게 좌우한다.
- 코스에서 배우는 것: 데이터를 시스템에 맞게 준비하기, 데이터를 최대한 활용하도록 LLM을 프롬프트하기, 실제 사용자 트래픽을 평가해 고품질 응답 보장하기.
- RAG는 **오늘날 세계에서 가장 흔히 구축되는 LLM 기반 애플리케이션** 유형일 것이다. 대기업은 제품 문의·사내 정책 답변에, 스타트업은 헬스케어(의료 질문)·교육(튜터링) 등 다양한 버티컬에서 활용한다.

### RAG는 LLM 발전을 빠르게 흡수한다
- **환각(hallucination) 감소**: 최신 세대 모델은 주어진 문서/맥락에 더 잘 근거(grounded)하여, 지난 1년간 RAG 시스템의 환각률이 꾸준히 하락 추세.
- **추론 모델(reasoning model)**: 더 복잡한 질문을 다루고 제공된 맥락 위에서 추론 가능.
- **긴 컨텍스트 윈도(context window)**: 입력 컨텍스트가 커지면서, 문서를 어떻게 쪼갤지·무엇을 넣을지 등 **하이퍼파라미터 튜닝**의 모범 사례도 진화 중(작은 윈도에 억지로 욱여넣을 필요가 줄어듦).
- **에이전틱 문서 추출**: PDF·슬라이드 등 다양한 문서 위에 RAG를 더 쉽게 구축 가능.
- RAG는 종종 복잡한 **멀티스텝 에이전틱 워크플로**의 한 구성 요소로, 에이전트가 문서 처리·고객 요청 추론에 필요한 정보를 제공한다.

### 에이전틱 RAG(agentic RAG)
- **초기 RAG**: 인간 엔지니어가 규칙·코드를 작성해 "긴 문서를 어떻게 자를지, 몇 조각을 LLM 컨텍스트에 넣을지"를 직접 결정.
- **에이전틱 RAG**: AI 에이전트에게 정보 검색 **도구(tool)** 를 주고, 스스로 결정하게 한다 — 다음에 웹 검색을 할지, 어떤 키워드로 할지, 특정 전문 DB를 조회할지, 1차 검색이 충분한지 아니면 2차 검색을 할지 등.
- 이렇게 하면 시스템이 훨씬 **유연·강력**해지고, 현실의 지저분함(messiness)에 대응해 실수 시 경로를 되돌려(route back) 접근을 고칠 수 있다.
- 여러 LLM이 각자 워크플로의 한 부분을 맡고 무엇을 검색할지 **주체성(agency)** 을 갖는 방식으로, 기업들이 성능의 최전선을 밀어붙이는 지점이다.

### 코스가 주는 것
- 기본 RAG → 고급 에이전틱 RAG까지, 핵심 원리·멘탈 프레임워크와 실전(적절한 청크 크기 튜닝, 컨텍스트 관리 등)을 아우른다.
- 멀티모달·추론 모델, RAG vs 파인튜닝(fine-tuning) vs 롱 컨텍스트 모델 균형 등 다양한 고급 기법 포함.
- Gen AI 애플리케이션을 조립·평가·개선하는 폭넓은 기초를 제공한다.

## 요약
- **RAG**는 LLM 응답의 품질·정확성을 높이는 가장 널리 쓰이는 기법으로, **검색 시스템 + LLM 추론**의 결합이며 학습하지 않은 독점·최신 데이터로도 답하게 한다.
- 개념은 단순하나 구현·설계 선택이 정확도·속도를 좌우하며, 데이터 준비 → 프롬프트 → 평가의 실전 기술을 배운다.
- RAG는 LLM 발전(환각 감소, 추론 모델, 긴 컨텍스트, 문서 추출)을 빠르게 흡수하며, **에이전틱 RAG**로 진화해 에이전트가 무엇을 검색할지 스스로 결정한다.
