# Module 1 Introduction

## 개요
- 모듈 1은 강력한 RAG 시스템을 짓기 위한 **청사진(blueprint)** 을 다룬다. 기초 개념·주요 구성 요소를 익히고, 동작하는 RAG 시스템을 만들기 시작한다.
- 이 모듈이 코스 전체의 로드맵을 설정한다.

## 내용

### 이 모듈에서 배우는 것
- **RAG 개괄**: RAG가 무엇인지, 왜 쓰는지, LLM 응답 품질을 어떻게 높이는지.
- **RAG 아키텍처**: RAG는 LLM에 **리트리버(retriever)** 를 결합한다. 리트리버는 신뢰할 수 있는 정보의 **지식 베이스(knowledge base)** 에서 관련 정보를 찾아주는 구성 요소다. 각 구성 요소를 깊이 살펴보고 함께 어떻게 작동하는지 본다.
- **활용 사례**: 프로덕션 RAG 시스템 예시들을 보고, 자신의 LLM 기반 프로젝트에 RAG를 적용할 기회를 성찰한다.
- **실습**: 샘플 코드를 다루고, 모듈 끝에서 간단한 RAG 시스템 일부를 구현하는 첫 프로그래밍 과제를 완성한다.

### 코스 전체 로드맵
- 이 첫 시스템을 코스 내내 확장한다: 견고한 리트리버, 벡터 데이터베이스(vector database), 더 정교한 LLM 활용, 모니터링·평가 기법 등을 추가한다.

## 요약
- 모듈 1은 RAG의 기초 개념과 주요 구성 요소(**LLM + 리트리버 + 지식 베이스**)를 익히고 첫 RAG 시스템을 구현하는 단계다.
- 코스 전반에 걸쳐 이 시스템에 벡터 DB·평가·모니터링 등을 더해 나가며, 이 모듈이 전체 학습의 로드맵을 제시한다.
