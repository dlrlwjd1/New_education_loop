# Module 5 Introduction

## 개요
- 이제 RAG 시스템을 설계·구축할 기술은 갖췄고, 이를 **프로덕션(production)** 으로 옮길 때 생기는 새로운 고려사항을 다룬다.
- 평가 전략·관측성(observability)·로깅, 비용·메모리·지연 **트레이드오프**, 그리고 **멀티모달 RAG** 까지 프로덕션 성능을 높이는 주제들을 다룬다.

## 내용

### 이 모듈에서 배우는 것
- **평가(evaluation) 전략과 플랫폼**: 개별 구성 요소든 전체 시스템이든 성능을 관측할 수 있어야 한다.
- **로깅(logging)**: 개별 호출을 추적(trace)해 저품질 응답의 원인을 파악.
- **커스텀 데이터셋**: 애플리케이션 트래픽에서 **실제 고객 데이터**로 데이터셋을 만들어 변경을 테스트.
- **트레이드오프**: 비용·메모리 풋프린트·지연을 제어하면서 응답 품질 손실을 최소화하는 전략.
- **멀티모달 RAG(multimodal RAG)**: 텍스트 외에 이미지·PDF 데이터를 포함한 지식 베이스 활용.
- 모듈 끝의 프로그래밍 과제.

## 요약
- 모듈 5는 RAG를 **프로덕션 준비** 상태로 만드는 데 집중한다: **평가·관측성·로깅**, **비용/메모리/지연 트레이드오프**, **멀티모달 RAG**.
- 목표는 프로덕션 RAG 시스템의 성능을 더 높이는 것이다.
