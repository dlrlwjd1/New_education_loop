# Quantization

## 개요
- **양자화(quantization)** 는 LLM과 임베딩 벡터의 **압축**이다. 모델 가중치나 벡터 값을 **더 낮은 정밀도(low-precision) 데이터 타입**으로 대체해, 크기·비용·속도를 개선하되 품질 손실은 작게 유지한다.
- 이미지 압축과 같은 원리: 데이터를 줄이면 약간의 품질 저하가 있지만, 대개 그만한 메모리·비용 절감 가치가 있다.
- 핵심 조언: **정수 양자화(integer quantization) LLM·임베딩 모델을 실험해 보라** — 대부분 제공사가 8/4비트 버전을 제공하며, 절감 효과가 크고 품질 저하는 작다.

## 내용

### 이미지 압축 비유
- 24비트/픽셀 고화질 이미지를 12비트·6비트로 줄이면 크기가 1/2·1/4로 감소. 12비트는 이미 덜 예쁘고 6비트는 색 아티팩트가 보이지만, 용도에 따라 절감 가치가 있을 수 있다.

### LLM 양자화
- 일반 LLM 파라미터는 각 **16비트**. 모델이 10억~1조 파라미터라 방대한 메모리·강력한 GPU가 필요.
- 양자화는 16비트 파라미터를 **8비트·4비트**로 압축 → GPU 메모리 대폭 절감, 텍스트 생성 가속. 대가는 약간의 성능·품질 저하(주요 벤치마크에서 소폭).

### 임베딩 벡터 양자화 — 정수 양자화(integer quantization)
- 전형적 768차원 벡터는 768개의 **32비트 부동소수점** = 벡터당 3KB. 고차원·수백만~수십억 벡터면 데이터가 방대하고, 빠른 검색을 위해 비싼 **RAM**에 로드해야 한다.
- **정수 양자화**: 32비트 float를 작은 정수(예: **8비트 정수**)로 대체 → 즉시 크기 **1/4**. 계산도 단순해짐.
- 방법:
  1. 각 차원의 데이터에서 **최솟값·최댓값**을 찾아 범위 정의.
  2. 범위를 **256개**(8비트로 만들 수 있는 값 수) 등분해 0~255로 번호.
  3. 각 원래 float 값을 속한 구간의 정수로 배정. 최솟값과 구간 폭을 함께 저장하면 8비트로 원래 32비트 float의 **근사값**을 복원 가능.
- 성능: 단순해 보여도 잘 작동 — **Recall@K** 같은 지표에서 8비트 양자화로 몇 %p 하락에 그침. 저장은 줄고 검색은 빨라짐.

### 더 극단적/대안적 기법
- **1비트(바이너리) 양자화**: 차원당 32비트 → **1비트**(크기 1/32). 각 값이 1/0(양수/음수)만 표시. 극단적 압축이라 검색 성능이 눈에 띄게 떨어질 수 있지만 훨씬 작고 빠름. 다른 기법과 결합 가능 — 예: 1비트로 빠르게 검색 후 **원본 32비트 벡터로 재채점(rescore)**.
- **마트료시카(Matryoshka) 임베딩 모델**(러시아 인형에서 유래): 벡터의 **일부 차원만** 골라 유사도 비교 가능(예: 1000차원 중 앞 100·500만). 특성상 **차원이 정보 밀도순으로 정렬** — 앞 차원일수록 분산(정보)이 크고 뒤 차원은 작아, 뒤를 제외해도 손해가 적다.
  - 활용: 항상 앞 100차원만 써 공간·연산 절약, 또는 앞 100차원으로 **초기 검색** 후 나머지 900차원을 느린·싼 메모리에서 가져와 **재채점**. 저→고 정밀도를 빠르게 전환하는 **동적 환경**에 적합.

### 핵심 조언
- 최첨단 기법도 있지만, 핵심은 **정수 양자화 LLM·임베딩 모델을 실험**하라는 것. 대부분 제공사가 8/4비트 버전을 기본 모델과 함께 제공하며, 공간·비용 절감이 크고 품질 저하는 작다.

## 예시

### 양자화 수준별 트레이드오프
| 대상 | 압축 | 크기 절감 | 품질 |
|------|------|-----------|------|
| LLM 16→8/4비트 | 정수 | 1/2~1/4 메모리 | 소폭 저하 |
| 벡터 32→8비트 정수 | integer | 1/4 | Recall 몇 %p↓ |
| 벡터 32→1비트 | binary | 1/32 | 눈에 띄는 저하(재채점 결합) |
| 마트료시카 | 차원 부분 사용 | 가변 | 정보밀도순 정렬로 손실 최소 |

## 요약
- **양자화**는 LLM 가중치와 임베딩 벡터를 저정밀도로 압축해 **크기·비용·속도**를 개선하되 품질 손실은 작게 유지하는 기법이다(이미지 압축과 유사).
- **8비트 정수 양자화**는 벡터를 1/4로 줄이면서 Recall 손실이 몇 %p에 그치고, 양자화 LLM도 성능 저하가 작으면서 GPU 메모리·생성 속도를 개선한다.
- 더 극단적인 **1비트(바이너리)** 나 부분 차원 사용이 가능한 **마트료시카** 모델은 초기 검색 후 재채점 등으로 활용한다.
- 핵심 조언: 제공사의 **8/4비트 양자화 모델을 실험**하라 — 절감은 크고 품질 저하는 작다. 다음 강의부터 비용·지연 트레이드오프를 다룬다.
