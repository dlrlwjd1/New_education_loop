# Every job function needs to learn how to use data

## 개요
- 사회 전반의 디지털화로 거의 모든 직무에서 데이터가 생성되고 있다.
- 데이터 사이언스와 머신러닝은 영업, 제조, 채용, 마케팅, 농업 등 다양한 직무를 변화시키고 있다.
- 각 직무에서는 데이터 분석으로 의사결정을 개선하고, 머신러닝으로 특정 작업을 자동화하거나 보조할 수 있다.

## 내용

### 데이터가 직무를 바꾸는 이유
과거에는 설문이나 업무 기록이 종이로 처리되는 경우가 많았지만, 이제는 많은 활동이 디지털 데이터로 남는다. 의사의 메모, 고객 행동, 생산 라인 기록, 채용 과정, 마케팅 실험 등이 모두 데이터화되고 있다.

이 데이터 덕분에 거의 모든 직무가 데이터 사이언스나 머신러닝의 도움을 받을 수 있다.

### 영업
데이터 사이언스는 판매 퍼널을 분석해 어느 단계에서 고객이 이탈하는지 파악할 수 있다.

머신러닝은 영업 리드를 우선순위화하는 데 활용될 수 있다. 예를 들어 구매 가능성이 높은 리드를 먼저 연락하도록 정렬하면 영업 담당자의 효율을 높일 수 있다.

| 접근 | 예시 |
|------|------|
| 데이터 사이언스 | 판매 퍼널 분석 |
| 머신러닝 | 영업 리드 우선순위화 |

### 제조
데이터 사이언스는 제조 라인의 데이터를 분석해 불량률을 낮추는 조건을 찾을 수 있다.

머신러닝은 최종 검사 단계에서 제품 이미지를 입력으로 받아 흠집이나 찌그러짐 같은 결함을 자동으로 감지할 수 있다. 자동 시각 검사는 노동 비용을 줄이고 품질을 높이는 데 도움이 된다.

### 채용
채용도 후보자 발굴, 이메일 발송, 전화 면접, 현장 인터뷰, 오퍼 발송 같은 퍼널 구조를 가진다. 데이터 사이언스는 어느 단계에서 후보자가 많이 이탈하는지 분석해 채용 프로세스를 개선할 수 있다.

머신러닝은 이력서 스크리닝 자동화에 활용될 수 있다. 다만 채용 자동화는 편향과 공정성 문제가 중요하므로, 시스템이 사람을 공정하게 대하는지 반드시 고려해야 한다.

### 마케팅
마케팅에서는 A/B 테스트가 대표적인 데이터 활용 방법이다. 예를 들어 빨간 버튼과 초록 버튼 중 어느 쪽이 더 많은 클릭을 유도하는지 비교할 수 있다.

머신러닝은 개인화된 제품 추천에 활용된다. 사용자의 과거 행동을 바탕으로 구매 가능성이 높은 상품을 추천하면 온라인 쇼핑몰의 매출을 높일 수 있다.

### 농업
농업에서는 토양 상태, 날씨, 작물 가격 같은 데이터를 분석해 무엇을 언제 심을지 결정하는 데 데이터 사이언스를 활용할 수 있다.

머신러닝은 정밀 농업에 활용된다. 예를 들어 카메라로 작물과 잡초를 구분하고, 잡초에만 제초제를 정밀하게 뿌리면 수확량을 높이면서 환경 부담도 줄일 수 있다.

## 예시

### 직무별 데이터 활용
| 직무 | 데이터 사이언스 | 머신러닝 |
|------|----------------|----------|
| 영업 | 판매 퍼널 최적화 | 리드 우선순위화 |
| 제조 | 제조 조건과 불량률 분석 | 결함 자동 검사 |
| 채용 | 채용 퍼널 최적화 | 이력서 스크리닝 |
| 마케팅 | A/B 테스트 분석 | 개인화 추천 |
| 농업 | 작물 분석과 재배 의사결정 | 잡초 탐지와 정밀 제초 |

## 요약
- 디지털화로 거의 모든 직무에서 데이터가 생성되고 있다.
- 데이터 사이언스는 인사이트를 통해 의사결정을 개선한다.
- 머신러닝은 반복적이고 명확한 A to B 작업을 자동화하거나 보조한다.
- 채용처럼 사람에게 직접 영향을 주는 영역에서는 공정성과 윤리 문제를 함께 고려해야 한다.
