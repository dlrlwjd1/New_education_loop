# Workflow of a data science project

## 개요
- 데이터 사이언스 프로젝트의 결과물은 실행되는 모델이 아니라, 행동으로 이어질 수 있는 인사이트인 경우가 많다.
- 핵심 단계는 **데이터 수집 → 데이터 분석 → 가설과 행동 제안**이다.
- 변경을 적용한 뒤 새 데이터를 다시 분석하면서 지속적으로 개선할 수 있다.

## 내용

### 데이터 사이언스 프로젝트의 기본 흐름
데이터 사이언스 프로젝트는 머신러닝 프로젝트와 다르게, 자동 예측 시스템을 만드는 것이 아니라 데이터에서 의사결정에 도움이 되는 인사이트를 찾는 데 초점을 둔다.

| 단계 | 설명 |
|------|------|
| 1. 데이터 수집 | 분석할 데이터를 모은다. |
| 2. 데이터 분석 | 여러 가설을 검토하고 패턴을 찾는다. |
| 3. 가설과 행동 제안 | 비즈니스 의사결정에 필요한 결론과 실행 방안을 제시한다. |

이후 제안된 행동을 실제로 적용하면 새로운 데이터가 생기고, 이를 다시 분석해 더 나은 결정을 할 수 있다.

### 예시 1: 전자상거래 판매 퍼널 최적화
커피 머그를 판매하는 온라인 쇼핑몰을 운영한다고 하자. 사용자는 보통 다음 단계를 거친다.

1. 웹사이트 방문
2. 제품 페이지 확인
3. 장바구니에 상품 추가
4. 체크아웃

데이터 사이언스 팀은 각 단계에서 사용자가 얼마나 이탈하는지 분석해 판매 퍼널을 최적화할 수 있다.

예를 들어 해외 고객이 체크아웃 단계에서 많이 이탈한다면, 국제 배송비가 부담이 되는지 분석할 수 있다. 이 경우 배송비 일부를 제품 가격에 포함하는 정책을 검토할 수 있다.

또는 특정 국가에서 낮 시간대에 구매가 줄어든다면, 그 시간대에는 광고비를 줄이는 것이 더 효율적일 수 있다.

### 예시 2: 제조 라인 최적화
커피 머그를 생산하는 공장에서 목표는 불량품을 줄이고 수율을 높이는 것이다. 제조 과정은 다음과 같이 진행될 수 있다.

1. 점토 혼합
2. 머그 형태 만들기
3. 유약 추가
4. 가마에서 굽기
5. 최종 검사

데이터 사이언스 프로젝트에서는 다음과 같은 데이터를 수집할 수 있다.

- 점토 공급업체
- 혼합 시간
- 점토의 수분 함량
- 추가한 물의 양
- 생산 배치의 습도
- 가마 온도
- 굽는 시간
- 불량 여부

분석 결과, 습도가 너무 낮고 가마 온도가 너무 높을 때 머그가 갈라진다는 인사이트를 얻을 수 있다. 또는 오후에는 온도가 높아지므로 시간대에 따라 습도와 온도를 다르게 조정해야 한다는 결론을 얻을 수 있다.

### 반복 분석
데이터 사이언스 프로젝트도 반복이 중요하다. 제안된 행동을 적용하면 사용자의 행동이나 제조 라인의 결과가 달라지고, 그에 따른 새 데이터가 생긴다. 이 데이터를 주기적으로 다시 분석하면 더 나은 가설과 행동을 찾을 수 있다.

## 예시

### 머신러닝과 데이터 사이언스 비교
| 구분 | 머신러닝 프로젝트 | 데이터 사이언스 프로젝트 |
|------|------------------|--------------------------|
| 주요 결과 | 실행되는 예측 모델 | 인사이트와 행동 제안 |
| 핵심 단계 | 데이터 수집, 모델 훈련, 배포 | 데이터 수집, 분석, 가설/행동 제안 |
| 예시 | 머그 결함 자동 감지 | 제조 조건과 불량률 관계 분석 |

### 판매 퍼널 분석 질문
- 어느 단계에서 사용자가 가장 많이 이탈하는가?
- 국가별 또는 시간대별 차이가 있는가?
- 배송비, 광고, 체크아웃 정책이 전환율에 어떤 영향을 주는가?

## 요약
- 데이터 사이언스 프로젝트는 데이터에서 인사이트를 얻어 행동을 제안하는 프로젝트다.
- 기본 흐름은 데이터 수집, 데이터 분석, 가설과 행동 제안이다.
- 판매 퍼널 최적화와 제조 라인 수율 개선이 대표적인 예시다.
- 행동을 적용한 뒤 새 데이터를 다시 분석하면서 지속적으로 개선할 수 있다.
