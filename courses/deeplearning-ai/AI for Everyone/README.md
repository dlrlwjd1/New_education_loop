# AI for Everyone

**Course URL:** https://learn.deeplearning.ai/courses/ai-for-everyone
**제공:** DeepLearning.AI
**강사:** Andrew Ng

## 개요
비전공자·비즈니스 리더를 대상으로 AI가 무엇이고, 어떻게 프로젝트를 기획하며, 조직에 어떻게 도입하고, 사회에 어떤 영향을 미치는지를 다루는 4주 과정입니다. 코딩 실습은 없습니다. 모든 강의 노트는 한국어로 정리되어 있습니다.
