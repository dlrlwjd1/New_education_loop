# The terminology of AI

## 개요
- AI 분야에는 머신러닝, 데이터 사이언스, 신경망, 딥러닝 같은 용어가 자주 등장한다.
- **머신러닝**은 데이터를 통해 소프트웨어가 입력 A를 출력 B로 바꾸는 방법을 학습하게 하는 분야다.
- **데이터 사이언스**는 데이터에서 지식과 인사이트를 추출해 의사결정을 돕는 분야다.
- **신경망(neural network)** 과 **딥러닝(deep learning)** 은 오늘날 머신러닝에서 특히 강력하게 쓰이는 기술이다.

## 내용

### 머신러닝
머신러닝은 컴퓨터가 명시적으로 프로그래밍되지 않고도 학습할 수 있게 하는 연구 분야다. 강의에서는 Arthur Samuel의 정의를 소개한다.

머신러닝 프로젝트는 보통 실제로 실행되는 소프트웨어를 만든다. 이 소프트웨어는 하루 중 언제든 입력 A를 받아 출력 B를 자동으로 생성한다.

예를 들어 주택 가격 앱을 만든다면 다음과 같이 정의할 수 있다.

| 입력 A | 출력 B |
|--------|--------|
| 집 크기, 침실 수, 욕실 수, 리노베이션 여부 | 예상 집 가격 |

이 시스템이 수십 명, 수천 명, 수백만 명의 사용자에게 자동으로 가격을 예측해 준다면 머신러닝 시스템이라고 볼 수 있다.

### 데이터 사이언스
데이터 사이언스는 데이터에서 지식과 인사이트를 추출하는 과학이다. 머신러닝처럼 항상 실행되는 소프트웨어를 만드는 것이 아니라, 분석 결과를 통해 의사결정을 돕는 경우가 많다.

예를 들어 주택 데이터 분석을 통해 다음과 같은 결론을 얻을 수 있다.

- 같은 면적이라도 침실이 3개인 집이 침실 2개인 집보다 더 비싸다.
- 새로 리노베이션된 집은 약 15%의 프리미엄이 붙는다.

이런 결론은 어떤 집을 지을지, 리노베이션에 투자할지 같은 비즈니스 의사결정에 쓰일 수 있다.

### 머신러닝과 데이터 사이언스의 차이
두 용어의 경계는 다소 흐리며, 업계에서도 항상 일관되게 쓰이지는 않는다. 하지만 강의에서는 다음과 같이 구분한다.

| 구분 | 머신러닝 | 데이터 사이언스 |
|------|----------|----------------|
| 주된 결과물 | 실행되는 AI 소프트웨어 | 인사이트, 분석 결과, 발표 자료 |
| 목적 | 입력 A를 받아 출력 B를 자동 생성 | 데이터에서 의사결정에 필요한 지식 추출 |
| 예시 | 광고 클릭 예측 시스템 | 특정 산업군에 영업을 늘리라는 분석 결론 |

온라인 광고 산업에서는 광고와 사용자 정보를 입력으로 받아 클릭 여부를 예측하는 시스템이 머신러닝이다. 반면 데이터 분석을 통해 여행 업계가 광고를 적게 구매한다는 사실을 발견하고, 해당 업계에 영업을 강화하라는 결론을 내리는 것은 데이터 사이언스 프로젝트다.

### 신경망과 딥러닝
신경망 또는 인공 신경망은 입력 A를 받아 출력 B를 계산하는 소프트웨어다. 주택 가격 예측의 경우 집 크기, 침실 수, 욕실 수, 리노베이션 여부를 입력으로 받아 예상 가격을 출력할 수 있다.

신경망은 인간의 뇌에서 느슨하게 영감을 받았지만, 실제 작동 방식은 생물학적 뇌와 거의 관련이 없다. 강의에서는 인공 신경망을 뇌와 직접 비교하는 데 조심해야 한다고 설명한다.

오늘날 **신경망**과 **딥러닝**이라는 용어는 거의 같은 의미로 사용된다. 딥러닝은 A to B 매핑을 학습하는 데 매우 효과적인 머신러닝 도구다.

### AI 용어의 관계
AI는 컴퓨터가 지능적으로 행동하도록 만드는 여러 도구들의 큰 집합이다. 그중 가장 큰 하위 분야 중 하나가 머신러닝이고, 오늘날 머신러닝에서 가장 중요한 기술 중 하나가 딥러닝 또는 신경망이다.

| 개념 | 관계 |
|------|------|
| AI | 컴퓨터를 지능적으로 행동하게 하는 넓은 도구 집합 |
| 머신러닝 | AI의 큰 하위 분야 |
| 딥러닝 / 신경망 | 머신러닝 안에서 매우 강력한 기술군 |
| 데이터 사이언스 | 데이터에서 인사이트를 추출하는 분야이며 머신러닝과 겹칠 수 있음 |

그 외에도 생성형 AI, 비지도 학습, 강화 학습, 그래피컬 모델, 계획, 지식 그래프 같은 용어가 있지만, 이 강의에서 가장 중요하게 기억할 용어는 머신러닝, 데이터 사이언스, 딥러닝, 신경망이다.

## 예시

### 주택 데이터로 보는 구분
| 목표 | 분야 |
|------|------|
| 집 정보를 입력하면 가격을 자동 예측하는 앱 만들기 | 머신러닝 |
| 침실 수나 리노베이션 여부가 가격에 미치는 영향을 분석하기 | 데이터 사이언스 |

### 온라인 광고로 보는 구분
| 목표 | 분야 |
|------|------|
| 사용자가 광고를 클릭할지 실시간으로 예측하기 | 머신러닝 |
| 특정 산업군의 광고 구매가 낮다는 인사이트를 발견하기 | 데이터 사이언스 |

## 요약
- 머신러닝은 컴퓨터가 데이터로부터 학습해 입력 A를 출력 B로 바꾸는 시스템을 만드는 분야다.
- 데이터 사이언스는 데이터에서 인사이트를 추출해 의사결정을 돕는 분야다.
- 머신러닝의 결과물은 보통 실행되는 소프트웨어이고, 데이터 사이언스의 결과물은 보통 분석 결론이나 보고서다.
- 신경망과 딥러닝은 거의 같은 의미로 쓰이며, A to B 매핑을 학습하는 강력한 방법이다.
- AI는 머신러닝보다 더 넓은 개념이고, 머신러닝 안에 딥러닝이 포함된다.
