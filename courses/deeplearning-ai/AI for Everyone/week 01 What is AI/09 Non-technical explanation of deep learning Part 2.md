# Non-technical explanation of deep learning Part 2

## 개요
- 신경망은 숫자 형태의 입력을 받아 출력 B를 예측할 수 있으며, 이미지도 컴퓨터에게는 숫자의 집합이다.
- 얼굴 인식에서는 이미지의 픽셀 밝기 값을 입력 A로 받아 사진 속 인물의 정체성을 출력 B로 예측한다.
- 신경망은 초기 층에서 경계선 같은 단순한 특징을 배우고, 이후 눈, 코, 입, 얼굴 형태 같은 더 복잡한 특징을 학습한다.

## 내용

### 이미지가 컴퓨터에 보이는 방식
사람은 사진을 보면 눈, 코, 얼굴 같은 의미 있는 대상을 바로 인식한다. 하지만 컴퓨터는 이미지를 픽셀의 숫자 격자로 본다.

흑백 또는 회색조 이미지에서는 각 픽셀이 하나의 숫자로 표현된다. 이 숫자는 해당 픽셀이 얼마나 밝은지를 나타낸다.

컬러 이미지에서는 각 픽셀이 세 개의 숫자로 표현된다.

| 값 | 의미 |
|----|------|
| R | 빨간색 밝기 |
| G | 초록색 밝기 |
| B | 파란색 밝기 |

즉, 컬러 이미지의 한 픽셀은 빨강, 초록, 파랑의 밝기 값 세 개로 구성된다.

### 얼굴 인식 문제
얼굴 인식 시스템의 목표는 사진을 입력으로 받아 사진 속 사람이 누구인지 출력하는 것이다.

| 입력 A | 출력 B |
|--------|--------|
| 얼굴 사진의 픽셀 값 | 인물의 이름 또는 ID |

예를 들어 1,000 x 1,000 해상도의 이미지는 총 1,000,000개의 픽셀을 가진다.

- 흑백 이미지라면 입력은 1,000,000개의 숫자다.
- 컬러 이미지라면 각 픽셀마다 R, G, B 세 값이 있으므로 입력은 3,000,000개의 숫자다.

신경망은 이 많은 숫자를 입력으로 받아 사진 속 인물을 예측한다.

### 신경망이 이미지에서 배우는 것
신경망 내부의 뉴런들이 무엇을 계산해야 하는지는 사람이 직접 정하지 않는다. 많은 사진과 정답 라벨을 제공하면 학습 알고리즘이 중간 계산을 스스로 찾아낸다.

일반적으로 이미지 인식 신경망은 다음과 같은 방식으로 특징을 학습한다.

| 위치 | 학습하는 특징 |
|------|---------------|
| 초기 부분 | 이미지의 경계선, 선, 간단한 패턴 |
| 중간 부분 | 눈, 코, 볼, 입 같은 얼굴의 부분 |
| 후반 부분 | 다양한 얼굴 형태와 전체 얼굴 패턴 |
| 출력 부분 | 사진 속 인물의 정체성 |

이 구조 덕분에 신경망은 낮은 수준의 픽셀 값에서 시작해 점점 더 의미 있는 특징을 조합하고, 최종적으로 사진 속 사람이 누구인지 예측한다.

### 학습에 필요한 데이터
얼굴 인식 신경망을 학습시키려면 입력 A와 출력 B가 함께 있는 데이터가 필요하다.

| 입력 A | 출력 B |
|--------|--------|
| 사람 얼굴 사진 | 해당 사람의 이름 또는 ID |

많은 사진과 올바른 정답 라벨을 제공하면 신경망은 각 뉴런이 어떤 특징을 계산해야 하는지 자동으로 학습한다.

### 수요 예측과 이미지 인식의 공통점
이전 강의에서는 티셔츠 수요 예측에서 가격, 배송비, 마케팅, 소재 같은 몇 개의 숫자를 입력으로 사용했다. 얼굴 인식도 원리는 같다.

차이는 입력 숫자의 수가 훨씬 많다는 점이다. 수요 예측은 몇 개의 숫자를 입력으로 받지만, 이미지 인식은 수백만 개의 픽셀 값을 입력으로 받을 수 있다.

| 문제 | 입력 A | 출력 B |
|------|--------|--------|
| 수요 예측 | 가격, 배송비, 마케팅, 소재 | 예상 수요 |
| 얼굴 인식 | 픽셀 밝기 값 | 인물의 정체성 |

둘 다 핵심은 입력 A에서 출력 B로 가는 매핑을 학습한다는 것이다.

## 예시

### 컬러 이미지 입력 크기
1,000 x 1,000 컬러 이미지를 입력으로 사용한다고 하자.

| 항목 | 값 |
|------|----|
| 픽셀 수 | 1,000,000 |
| 픽셀당 값 | R, G, B 3개 |
| 총 입력 숫자 수 | 3,000,000 |

### 얼굴 인식 신경망의 직관
1. 이미지를 픽셀 숫자들로 입력받는다.
2. 초기 뉴런들이 선과 경계 같은 단순한 패턴을 찾는다.
3. 중간 뉴런들이 눈, 코, 입 같은 얼굴 부위를 찾는다.
4. 후반 뉴런들이 얼굴 전체의 형태를 조합한다.
5. 출력 뉴런이 사진 속 인물의 정체성을 예측한다.

## 요약
- 컴퓨터는 이미지를 픽셀 밝기 값들의 숫자 배열로 본다.
- 흑백 이미지는 픽셀당 하나의 숫자, 컬러 이미지는 픽셀당 R/G/B 세 개의 숫자를 가진다.
- 얼굴 인식 신경망은 많은 픽셀 값을 입력으로 받아 인물의 정체성을 출력한다.
- 신경망은 초기에는 경계선, 중간에는 얼굴 부위, 후반에는 전체 얼굴 형태를 학습할 수 있다.
- 사람이 중간 특징을 직접 설계하지 않아도, 충분한 이미지와 정답 라벨이 있으면 신경망이 스스로 학습한다.
