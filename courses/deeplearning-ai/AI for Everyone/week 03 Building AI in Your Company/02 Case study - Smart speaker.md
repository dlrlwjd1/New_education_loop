# Case study - Smart speaker

## 개요
- 복잡한 AI 제품은 하나의 머신러닝 모델이 아니라 여러 AI 구성 요소와 소프트웨어가 연결된 파이프라인으로 만들어진다.
- 스마트 스피커는 호출어 감지, 음성 인식, 의도 인식, 명령 실행의 여러 단계를 거친다.
- 각 단계는 서로 다른 팀이나 구성 요소가 맡을 수 있으며, 전체 제품은 이들을 조합해 동작한다.

## 내용

### 스마트 스피커 명령 처리
스마트 스피커가 "hey device, tell me a joke" 같은 음성 명령을 처리하려면 여러 단계가 필요하다.

| 단계 | 역할 |
|------|------|
| 1. 호출어 감지 | "hey device" 같은 wake word를 들었는지 판단한다. |
| 2. 음성 인식 | 호출어 뒤의 오디오를 텍스트로 변환한다. |
| 3. 의도 인식 | 텍스트가 어떤 명령을 뜻하는지 판단한다. |
| 4. 명령 실행 | 해당 명령을 수행하는 소프트웨어를 실행한다. |

### 호출어 감지
첫 단계는 사용자가 스마트 스피커를 깨우는 호출어를 말했는지 감지하는 것이다.

| 입력 A | 출력 B |
|--------|--------|
| 오디오 클립 | 호출어를 들었는지 여부 |

출력은 보통 0 또는 1처럼 호출어가 감지되었는지를 나타낸다.

### 음성 인식
호출어가 감지되면, 그 뒤에 말한 내용을 텍스트로 변환한다.

| 입력 A | 출력 B |
|--------|--------|
| 호출어 뒤의 오디오 | 텍스트 transcript |

예를 들어 사용자가 "tell me a joke"라고 말했다면, 음성 인식 시스템은 이 네 단어를 텍스트로 출력해야 한다.

### 의도 인식
텍스트가 만들어지면, 다음 단계는 사용자가 실제로 무엇을 원하는지 판단하는 것이다.

| 입력 A | 출력 B |
|--------|--------|
| "tell me a joke" | 농담 들려주기 |

사용자는 같은 의도를 여러 방식으로 표현할 수 있다.

- tell me a joke
- do you know any good jokes?
- tell me something funny

잘 설계된 의도 인식 시스템은 이런 다양한 표현을 같은 의도로 인식해야 한다.

### 명령 실행
마지막 단계에서는 일반 소프트웨어가 실제 명령을 실행한다. 예를 들어 "농담 들려주기" 의도라면, 소프트웨어가 무작위로 농담을 선택하고 스피커를 통해 재생한다.

### 타이머 설정 예시
"hey device, set timer for 10 minutes"는 조금 더 복잡한 명령이다.

이 경우 의도는 "타이머 설정"이고, 실행을 위해서는 시간 정보도 추출해야 한다.

| 단계 | 결과 |
|------|------|
| 음성 인식 | set timer for 10 minutes |
| 의도 인식 | 타이머 설정 |
| duration 추출 | 10 minutes |
| 실행 | 10분 타이머 시작 |

사용자는 같은 요구를 여러 방식으로 말할 수 있다.

- set timer for 10 minutes
- let me know when 10 minutes is up
- set alarm for 10 minutes from now

시스템은 이런 표현에서도 타이머 설정 의도와 10분이라는 시간을 추출해야 한다.

### AI 파이프라인
여러 AI 구성 요소가 데이터를 순서대로 처리하는 구조를 **AI pipeline**이라고 부를 수 있다. 스마트 스피커에서는 호출어 감지, 음성 인식, 의도 인식, 명령 실행이 하나의 파이프라인을 이룬다.

큰 회사에서는 각 구성 요소를 서로 다른 팀이 담당할 수 있다.

### 스마트 스피커의 한계
스마트 스피커는 음악 재생, 볼륨 조절, 전화 걸기, 시간 확인, 단위 변환 같은 많은 기능을 수행할 수 있다. 하지만 모든 것을 할 수는 없다.

예를 들어 "친구 세 명에게 전화해서 모두 저녁 식사가 가능한 시간을 찾아줘" 같은 복잡한 요청은 일반적인 스마트 스피커가 처리하기 어렵다.

따라서 스마트 스피커 회사들은 사용자가 무엇을 할 수 있고 무엇을 할 수 없는지 이해하도록 사용자 교육에도 많은 노력을 기울인다.

## 예시

### 스마트 스피커 파이프라인
| 입력 | 처리 단계 | 출력 |
|------|-----------|------|
| 전체 오디오 | 호출어 감지 | 호출어 여부 |
| 호출어 뒤 오디오 | 음성 인식 | 텍스트 |
| 텍스트 | 의도 인식 | 명령 종류 |
| 명령 종류와 필요한 값 | 실행 소프트웨어 | 실제 동작 |

## 요약
- 스마트 스피커는 여러 AI 구성 요소와 일반 소프트웨어가 결합된 복잡한 AI 제품이다.
- 핵심 단계는 호출어 감지, 음성 인식, 의도 인식, 명령 실행이다.
- 명령에 따라 duration 같은 추가 정보를 추출해야 할 수 있다.
- 기능이 많아질수록 각 명령을 실행하는 전문 소프트웨어도 많이 필요하다.
- AI pipeline은 여러 구성 요소가 순서대로 데이터를 처리하는 구조다.
