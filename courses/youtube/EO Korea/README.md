## 정리 원칙
- 인터뷰의 전체 전사를 반복하지 않고, 개념·주장·실행 조언을 구조화해 압축한다.
- 발화자의 관점과 사례(제품명·회사명)를 정확히 보존한다.
- 기술 용어는 한국어 설명에 영어 원문을 병기한다.
