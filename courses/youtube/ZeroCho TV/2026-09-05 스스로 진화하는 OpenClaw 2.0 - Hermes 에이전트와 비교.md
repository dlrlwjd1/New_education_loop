- Hostinger 협찬 영상이다. 호스팅 서비스 소개는 별도 구간으로 구분한다.

### AI 비서의 가치: 여러 자료를 연결해 작업을 끝내기

도입부에서는 구독자 이벤트 당첨자들의 이메일을 찾아 배송 정보를 표로 정리한다. 메일을 보낸 사람과 아직 보내지 않은 사람을 나누고, 우편번호 누락을 표시한 뒤 택배사 양식에 맞춰 옮기는 흐름이다. 단순한 질의응답을 넘어 **검색 → 정보 대조 → 누락 확인 → 지정 양식 작성**을 이어 수행하는 사례다. [00:14–01:08](https://www.youtube.com/watch?v=hniTPGEpDl8&t=14s)

### UI 개편: 시스템 설정보다 작업 중심으로 접근

발표자는 이전 화면이 게이트웨이·웹소켓 등 기술 용어를 앞세워 비개발자가 접근하기 어려웠다고 평가한다. 새 화면에서는 채팅 세션, 모델 선택, 컨텍스트 확인, 작업 패널을 중심으로 사용 흐름이 바뀌었다고 설명한다. [02:00–04:48](https://www.youtube.com/watch?v=hniTPGEpDl8&t=120s)

- 에이전트를 여러 개 두고 일반 비서·검토자·코딩·마케팅 등 역할을 나눌 수 있다.
- 사이드 패널에서 터미널과 프로젝트 파일을 확인한다.
- 사이드 채팅으로 진행 중인 작업을 중단하지 않고 별도 질문을 나눈다.
- 홈 화면에는 사용량·세션·활동과 직접 요청해 만든 대시보드를 배치한다.

총평에서는 기존에도 가능했던 기능이 많았지만 찾기 어려웠다는 점을 강조한다. 변화의 상당 부분은 기능의 존재 자체보다 **발견하기 쉽고 조작하기 쉬운 화면**에 있다. [15:40–17:02](https://www.youtube.com/watch?v=hniTPGEpDl8&t=940s)

### 원격 서버와 개인 컴퓨터를 함께 사용

시연 환경은 24시간 켜 두는 VPS와 GPU가 있는 개인 Windows 컴퓨터를 연결하는 구성이다. 서버는 상시 요청을 받고, 연결된 개인 컴퓨터에서는 로컬 파일이나 해당 장치의 자원을 활용하는 작업을 맡긴다. 발표자는 외부에서 Telegram으로 집 컴퓨터의 영상 업로드·자막 추출을 요청하는 사용법을 소개한다. 개인 컴퓨터는 켜져 있어야 한다. [03:01–05:25](https://www.youtube.com/watch?v=hniTPGEpDl8&t=181s)

기기 연결은 시연 중 한 번 실패한 뒤 수정된다. 브라우저 패널도 발표자의 VPS 환경에서는 표시되지 않았다고 한다. 이 경험을 모든 설치 환경의 일반적 제한으로 단정하지 않는다.

### 여러 에이전트의 작업 공간과 예약 자동화

발표자는 서버마다 OpenClaw 또는 Hermes를 붙이고, 버즈라고 소개한 채팅 공간에서 프로젝트별로 대화한다고 설명한다. 블로그 서버와 별도 사이드 프로젝트 서버를 한 공간에서 관리하는 예를 든다. 버즈의 자세한 설명은 후속 영상으로 미룬다. [05:26–06:41](https://www.youtube.com/watch?v=hniTPGEpDl8&t=326s)

예약 작업은 크론(cron) 작업으로 관리하며 활성화·일시 중지·실행 기록을 확인한다. 자연어 요청이 충분하지 않을 때에는 수행할 단계를 구체적으로 설명하는 방식으로 보완한다. 영상의 복권 구매 사례는 반복 작업 예시로 언급되며, 이 노트에서는 구매 절차를 재현하지 않는다. [06:44–08:09](https://www.youtube.com/watch?v=hniTPGEpDl8&t=404s)

### 플러그인은 연결 기능, 스킬은 재사용할 작업 절차

플러그인 영역에서는 메신저·모델 공급자·외부 앱 등과의 연결을 다룬다. 스킬은 모델이 작업할 때 활용할 지침과 절차로 소개한다. 예시는 YouTube 제목·썸네일 생성이다. [08:10–08:54](https://www.youtube.com/watch?v=hniTPGEpDl8&t=490s)

| 스킬을 만드는 방법 | 영상의 설명 |
|---|---|
| 자기 학습 활성화 | 반복되는 요청을 파악해 재사용할 스킬을 제안한다. |
| 명시적으로 생성 요청 | 스킬 생성 도구를 통해 특정 작업용 스킬을 만들어 달라고 요청한다. |
| 대화 후 학습 명령 | 작업을 마친 대화에서 학습 명령을 실행해 스킬 제안을 만든다. 정확한 명령 표기는 자동 자막만으로 확정하지 않았다. |

제안된 스킬은 워크숍에서 내용을 읽고 수정·적용한다. 적용 후에는 사용자가 매번 이름을 지정하지 않아도 요청에 맞는 스킬을 찾아 활용하는 모습을 설명한다. [08:58–10:53](https://www.youtube.com/watch?v=hniTPGEpDl8&t=538s)

제목의 스스로 진화한다는 표현은 이 영상에서 **반복 경험을 작업 지침으로 축적하고 다시 사용하는 흐름**으로 이해할 수 있다. 모델 가중치를 재학습했다는 설명은 아니다.

### 메모리: 대화 기록에서 지속적으로 쓸 정보를 선별

Dreaming은 대화 내용을 전부 계속 넣는 대신, 기록에서 장기적으로 유지할 정보를 선별하는 과정으로 소개한다. 발표자는 단계별 처리와 메모리 위키를 통한 연관 정보 탐색을 설명한다. Dreaming 자체는 이전 버전에도 있었고 화면이 개선됐다고 말한다. [12:48–14:00](https://www.youtube.com/watch?v=hniTPGEpDl8&t=768s)

발표자도 실제 효과가 얼마나 작동하는지는 확신하지 않는다고 밝힌다. 따라서 기억 정확도가 향상됐다는 측정 결과로 읽기보다는, 메모리 관리 기능과 설계 방향을 소개한 것으로 정리한다.

### 비밀정보·승인·접근 권한을 따로 관리

Secrets 기능은 비밀번호를 채팅에 직접 적는 대신 별도 저장된 비밀정보를 참조하도록 하는 방식으로 소개된다. 승인 관리에서는 매번 승인하거나 한 번만 허용하는 등의 선택을 보여 주고, 읽기 전용·승인 기반·전체 접근처럼 권한을 나눠 설명한다. [14:27–15:36](https://www.youtube.com/watch?v=hniTPGEpDl8&t=867s)

핵심은 에이전트가 수행할 작업과 사용할 자격정보, 허용 범위를 구분하는 것이다. 발표자는 권한을 많이 부여하면 침해 시 그 권한이 악용될 수 있다는 점도 함께 언급한다. Secrets의 존재만으로 모든 유출 위험이 사라진다는 검증은 영상에 없다.

### Hostinger 소개는 협찬 구간

10:57–12:46에는 VPS에서 OpenClaw를 설치하는 서비스, 이용 규모에 따른 상품 선택, 도메인·크레딧 옵션을 소개한다. 영상 설명과 발표 중에 협찬임을 밝힌다. 가격·쿠폰·구독 연동 조건은 현재 구매 안내로 옮기지 않고, **상시 실행할 서버를 마련하는 예시**로만 기록한다.

또한 영상의 2.0은 날짜 기반 버전과 함께 설명되지만, 자동 자막의 날짜·번호가 일관되지 않아 정확한 최소 버전이나 업데이트 명령을 이 노트에서 지정하지 않는다. [16:14–16:42](https://www.youtube.com/watch?v=hniTPGEpDl8&t=974s)

### Hermes와의 비교: 기존 사용자에게 전환을 강하게 권하지 않는다

아래는 발표자의 사용 경험에 따른 비교다. [18:52–19:43](https://www.youtube.com/watch?v=hniTPGEpDl8&t=1132s)

| 기준 | 영상의 평가 |
|---|---|
| 반복 작업의 스킬화 | Hermes의 장점이었고, OpenClaw에도 들어오면서 비슷해졌다고 평가한다. |
| 대시보드 | OpenClaw의 대화형 대시보드를 차별점으로 든다. |
| 원격 컴퓨터 제어 | Hermes에도 가능하지만 OpenClaw의 기기 선택 UI가 비개발자에게 더 쉽다고 본다. |
| 여러 사람·기기 연결 | OpenClaw를 선택할 이유로 제시한다. |
| 기존 사용자 | 이미 만족하며 쓰고 있다면 굳이 서로 갈아탈 필요는 없다고 말한다. |

## 예시

영상에 등장한 사용 사례를 작업 단위로 묶었다.

| 사용처 | 입력·상황 | 결과·역할 |
|---|---|---|
| 이벤트 배송 준비 | 당첨자 목록과 수신 이메일 | 응답 여부·누락 정보 표, 택배사 양식 |
| 외부에서 집 컴퓨터 활용 | Telegram 요청, 켜져 있는 개인 PC | 영상 업로드·자막 추출 작업 요청 |
| 반복 콘텐츠 제작 | 반복되는 제목·썸네일 작성 요청 | 작업 절차를 스킬로 저장·재사용 |
| 개발 작업 관리 | 서버별 에이전트와 프로젝트 채널 | 여러 서버의 작업을 하나의 대화 공간에서 관리 |
| 개인 업무 화면 | 필요한 대시보드를 자연어로 설명 | 작업과 연결할 대화형 대시보드 |

## 요약

- 영상이 강조하는 변화는 작업 중심 UI, 반복 작업의 스킬화, 원격 기기 연결이다.
- 스킬 제안은 내용을 검토·수정하고 적용하는 흐름으로 소개된다.
- 메모리와 보안 기능은 편의성을 높이는 구성 요소이며, 효과를 측정한 벤치마크는 아니다.
- 발표자는 두 제품이 비슷해졌다고 평가하며, 대시보드·원격 기기·공동 작업이 필요할 때 OpenClaw의 장점을 강조한다.
- 설치·가격·정확한 명령어를 제공하는 매뉴얼이 아니라 영상의 실제 설명과 사용 사례를 정리한 노트다.
