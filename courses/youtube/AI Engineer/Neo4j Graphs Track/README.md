# Neo4j Graphs Track @ AI Engineer

## 개요
- 플랫폼: YouTube
- 채널: AI Engineer
- 재생목록: [Neo4j Graphs Track @ AI Engineer](https://www.youtube.com/playlist?list=PLKLSkgrxaJAU)
- 영상 수: 12개
- 주제: 그래프 메모리, 온톨로지, 시맨틱 레이어, 실행 그래프, 출처 추적, 에이전트 데이터 맥락
- 목표: 에이전트가 데이터의 의미·관계·출처·실행 경험을 지속 가능한 구조로 기억하고 검증하는 방법을 이해한다.
