# Your Moat Is Your Data Model

## 개요
- 업로드일: 2026-07-22
- 원본: https://www.youtube.com/watch?v=jt1Pbr_n6oU
- 재생목록: Neo4j Graphs Track @ AI Engineer
- 발표자: Mike Phipps, Gates Foundation
- 핵심 주제: 모델과 에이전트 프레임워크가 평준화될수록 조직의 데이터 모델과 암묵지가 지속적인 경쟁 우위가 된다는 주장

## 내용
### 쉽게 복제되는 층과 남는 층
LLM, 프런트엔드, 에이전트 프레임워크는 빠르게 상품화(commoditization)된다. 같은 모델과 도구를 경쟁 조직도 사용할 수 있으므로 그 자체만으로는 오래가는 방어력(moat)이 되기 어렵다.

반면 조직의 질문이 실제로 무엇을 뜻하고 어떤 기준으로 답해야 하는지에 관한 지식은 쉽게 복제되지 않는다. 데이터 모델에는 단순한 필드 정의를 넘어 보고 체계, 조직 구조, 업무 규칙, 데이터 소유자의 암묵지(tacit knowledge)가 축적된다.

### Gates Foundation의 지식 그래프
발표자의 팀은 25년간의 보조금 지원 활동을 하나의 Neo4j 지식 그래프로 모델링했다. 연간 70억 달러 이상, 약 2,000개의 보조금, 4,000명의 구성원과 여러 운영 시스템을 다루는 규모다.

그래프는 대시보드보다 에이전트 검색을 위해 설계됐다.

- 자금과 관리의 계층 구조를 각각 탐색 가능한 경로로 표현한다.
- 서로 분리된 사람·조직·보조금 시스템의 엔터티를 연결한다.
- 비정형 문서를 청크로 나누고 태그한 뒤 구조화된 엔터티에 연결한다.
- 물리 데이터보다 조직이 질문을 해석하는 방식에 맞춰 모델링한다.

사용자가 여러 시스템을 가로지르는 모호한 질문을 하면 에이전트는 이를 그래프 질의 하나로 변환할 수 있다. 답은 조직의 공식 보고 관점과 계층 구조를 반영한다.

### MCP와 평가 루프
지식 그래프는 하나의 MCP 서버를 통해 Claude에 제공된다. 에이전트의 도구 표면을 단순하게 유지하면서 복잡한 데이터 연결은 그래프 내부에 둔다.

정확성은 검색 평가(retrieval evals)로 관리한다. 대표 질문과 기대 근거를 마련하고, 에이전트가 올바른 노드와 관계를 회수하는지 반복 평가한다. 오류는 단순히 프롬프트를 고치는 데 그치지 않고 데이터 모델과 큐레이션 파이프라인을 개선하는 피드백이 된다.

## 예시
```text
질문: 특정 전략 아래의 보조금과 책임자를 함께 보여줘.

기존 방식:
전략 시스템 + 보조금 DB + 인사 시스템 + 문서 검색 결과를 수동 결합

그래프 방식:
(Strategy)-[:FUNDS]->(Grant)-[:OWNED_BY]->(Person)
          └─ 조직의 공식 계층과 보고 관점을 경로에 반영
```

## 요약
- 공용 모델과 프레임워크보다 조직 고유의 데이터 모델이 더 오래가는 자산이다.
- 좋은 데이터 모델은 데이터 소유자의 암묵지와 질문 해석 규칙을 담는다.
- 구조화 데이터와 비정형 문서를 같은 그래프에서 연결하면 에이전트가 복합 질문을 다룰 수 있다.
- MCP는 그래프를 단순한 도구로 제공하고, 검색 평가는 모델과 큐레이션을 지속적으로 개선한다.
