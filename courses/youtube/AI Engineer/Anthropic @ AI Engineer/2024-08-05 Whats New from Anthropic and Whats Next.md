# What's New from Anthropic and What's Next

## 개요
- 업로드일: 2024-08-05
- 원본: https://www.youtube.com/watch?v=EuC1GWhQdKE
- 재생목록: Anthropic @ AI Engineer
- 발표자: Alex Albert, Anthropic
- 핵심 주제: 2024년 당시 Claude 3.5 Sonnet의 추론·비전 향상, Artifacts와 Projects, API 개선 및 책임 있는 확장 정책

## 내용
### 모델 능력의 변화
발표는 당시 새 모델인 Claude 3.5 Sonnet의 코딩, 복잡한 추론, 비전 능력 향상을 소개한다. 단순 벤치마크 점수보다 실제 개발 과제와 여러 단계의 reasoning을 측정하는 평가가 중요하다고 설명한다.

멀티모달 능력은 이미지 설명에 그치지 않고 차트, 화면, 문서 시각 요소를 이해해 개발 및 분석 워크플로에 활용하는 방향으로 제시된다.

### Artifacts
Artifacts는 대화에서 생성된 코드, 문서, 시각 결과물을 채팅과 분리된 작업 공간에 표시한다. 사용자는 결과물을 보면서 반복 수정하고, 대화를 단순 질의응답이 아니라 공동 제작 인터페이스로 사용할 수 있다.

```text
대화: 요구 사항과 피드백
Artifact: 현재 산출물
반복: 피드백 → 수정된 산출물 확인
```

이 구조는 모델 출력이 최종 답변 한 번으로 끝나지 않고 지속적으로 편집되는 객체가 되는 변화를 보여준다.

### Projects
Projects는 팀이나 작업별 문서와 지침을 묶어 Claude에 지속적인 맥락을 제공하는 기능으로 소개된다. 반복해서 같은 자료를 첨부하지 않고 프로젝트 지식과 대화의 기준을 공유할 수 있다.

Artifacts가 현재 산출물의 반복 작업을 돕는다면 Projects는 여러 대화에 걸친 작업 맥락을 관리한다.

### 개발자 플랫폼과 향후 방향
발표는 모델 성능뿐 아니라 API 사용성, 개발 도구, 평가와 프롬프트 모범 사례가 실제 애플리케이션 품질을 결정한다고 강조한다. 앞으로는 더 긴 작업, 풍부한 멀티모달 입력, 모델과 사용자의 공동 작업이 확대될 것으로 전망한다.

능력 향상은 안전 정책과 함께 진행되어야 한다. 발표는 Anthropic의 Responsible Scaling Policy(RSP) 방향을 언급하며 강한 모델의 배포 기준과 위험 완화도 제품 개발의 일부로 본다.

## 예시
개발자는 UI 요구를 대화로 설명하고 Artifacts에서 생성된 코드를 즉시 확인한다. 프로젝트 문서와 디자인 규칙을 Projects에 두면 이후 대화에서도 같은 맥락을 재사용할 수 있다.

## 요약
- 2024년 발표는 Claude 3.5 Sonnet의 추론·코딩·비전 향상을 실제 개발 작업과 연결한다.
- Artifacts는 대화와 산출물을 분리해 반복적인 공동 제작을 지원한다.
- Projects는 문서와 지침을 여러 대화에서 재사용할 수 있는 작업 맥락으로 묶는다.
- 모델 능력, API·제품 UX, 평가, 책임 있는 확장 정책을 함께 발전시켜야 한다.
