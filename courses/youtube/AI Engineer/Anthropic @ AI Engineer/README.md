# Anthropic @ AI Engineer

## 개요
- 플랫폼: YouTube
- 채널: AI Engineer
- 재생목록: [Anthropic @ AI Engineer](https://www.youtube.com/playlist?list=PLcfpQ4tk2k0W564IUrISLhTVZ5lOVCuwm)
- 영상 수: 14개
- 업로드 기간: 2024-08-05 ~ 2026-07-22
- 주제: Claude, Claude Code, Agent SDK, 스킬, MCP, 프롬프트, 기업 AI, 장기 실행 에이전트, 코드 보안
- 목표: Anthropic의 모델·제품·프로토콜이 단일 프롬프트에서 도구를 사용하는 장기 실행 에이전트로 발전한 흐름을 이해한다.

## 학습 흐름

| 단계 | 영상 | 핵심 질문 |
| --- | --- | --- |
| 모델·프롬프트 기초 | What's New, Prompt Workshop | 모델 능력을 제품과 프롬프트에서 어떻게 끌어내는가? |
| 기업 적용 | Anthropic in the Enterprise | 평가와 조직 협업으로 파일럿을 운영 시스템에 어떻게 연결하는가? |
| MCP | Building Agents with MCP, MCP Origins, Remote MCPs | 데이터·도구 연결을 어떤 표준과 보안 경계로 제공하는가? |
| 에이전틱 코딩 | Claude Code, Agent SDK, Fable, Claude Tag | 모델이 컨텍스트를 만들고 행동·검증하는 개발 환경은 어떻게 설계하는가? |
| 전문성·장기 실행 | Skills, Evolving APIs, Long-Horizon Tasks | 지식, 메모리, 검증, 하니스를 장기 작업에 어떻게 구성하는가? |
| 보안 자동화 | Using LLMs to Secure Source Code | 탐지 이후 검증·분류·패치를 어떻게 확장하는가? |
