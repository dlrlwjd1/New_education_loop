# AI Builder Essentials

이 폴더는 Google Cloud Tech YouTube 채널에 업로드된 **AI Builder Essentials** 시리즈 영상 노트를 정리한 저장소입니다.
토큰(Tokens), 콘텍스트 윈도우(Context Windows), 검색 증강 생성(RAG) 등의 핵심 AI 원리 설명부터, Google AI Studio를 사용해 데스크톱 및 모바일 상에서 고속으로 앱을 프로토타이핑하는 방법, 그리고 에이전트 성능을 검증하는 에이전트 하니스(Agentic Harness) 설계법까지 다룹니다.
