# 5-Days of AI Agents and Agent Factory

이 폴더는 Google Cloud Tech YouTube 채널에 업로드된 **5-Days of AI Agents** 집중 라이브 강좌 및 **Agent Factory** 팟캐스트 세션 등 다양한 AI 에이전트 개발 실무 영상을 정리한 저장소입니다.
