# Building distributed AI agents

이 폴더는 Google Cloud Tech YouTube 채널에 업로드된 **Building distributed AI agents** 시리즈 영상 노트를 정리한 저장소입니다.
GPU 기반 LLM 서빙 서버의 Cloud Run 무중단 배포 방법, 가상 로드 부하 환경에서의 인프라 오토스케일링(Autoscaling), 에이전트 다자간 음성/텍스트 통신 프로토콜 설계, 그리고 복잡한 분산 다중 에이전트 시스템(Distributed Multi-agent Architecture)의 인프라 스케일링 전 과정을 학습합니다.
