# Google Cloud Tech

이 폴더는 Google Cloud Tech YouTube 채널에 업로드된 AI 에이전트 관련 강의 시리즈의 인덱스 페이지입니다.
각 플레이리스트 코스별 세부 강의 노트 및 인덱스는 아래 개별 폴더 내의 `README.md`에서 확인하실 수 있습니다.

## 제공 코스 목록

* [AI agent crash course](AI%20agent%20crash%20course/README.md) (영상 11개)
  - Google Cloud ADK와 MCP를 사용하여 다중 에이전트 협업, 상태 관리, 메모리(단기/장기/영구) 및 에이전트 평가 기초를 다룹니다.
  
* [Modern AI Agents: From Theory to Production](Modern%20AI%20Agents%20-%20From%20Theory%20to%20Production/README.md) (영상 6개)
  - 이론부터 실제 프로덕션 수준의 AI 에이전트 및 MCP 서버 구축, 컨텍스트 엔지니어링 설계, 그리고 GCP Cloud Run 배포 파이프라인까지 다룹니다.

* [5-Days of AI Agents and Agent Factory](5-Days%20of%20AI%20Agents%20and%20Agent%20Factory/README.md) (영상 18개)
  - 5일 완성 AI 에이전트 바이브 코딩 라이브 스트림 및 Agent Factory 팟캐스트 시리즈 영상 18개

* [AI Builder Essentials](AI%20Builder%20Essentials/README.md) (영상 7개)
  - 토큰/RAG 등의 AI 기본 개념, AI Studio 기반 앱 초고속 제작, 에이전트 하니스 아키텍처를 다루는 필수 코스입니다.

* [Building distributed AI agents](Building%20distributed%20AI%20agents/README.md) (영상 7개)
  - GPU LLM 서버리스 배포, 분산 다중 에이전트 통신 및 부하 분산 설계를 다루는 분산형 에이전트 인프라 코스입니다.
