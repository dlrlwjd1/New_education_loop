# AI agent crash course

이 폴더는 Google Cloud Tech YouTube 채널에 업로드된 **AI agent crash course** 시리즈 영상 노트를 정리한 저장소입니다.
Google Cloud의 Agent Development Kit (ADK) 및 Model Context Protocol (MCP) 서버를 활용하여 신뢰할 수 있는 에이전트 시스템을 아키텍처화하고, 메모리(단기/장기/영구) 및 평가(Evaluation)를 구축하는 실전 로드맵을 다룹니다.
