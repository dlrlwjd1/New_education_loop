## 정리 원칙
- YouTube 자료이므로 module 단위가 아니라 채널 폴더 바로 아래에 영상 노트를 둔다.
- 파일명은 `YYYY-MM-DD 영상제목.md` 형식으로 고정한다.
- 도구 소개 영상은 특징·설치·설정·주의점을 구분해 정리한다.
- 영상에서 확인된 내용만 기반으로 작성하고, 발표자가 "아직 써 보지 못했다"고 밝힌 부분은 그대로 표시한다.
- 새 영상이 추가되어도 기존 영상 파일명은 바꾸지 않고, README 목록만 업로드일 최신순으로 정렬한다.
