# 무조건 쓰세요. 다른 터미널 툴을 압도하는 현존 최고의 IDE Orca의 특징은?

## 개요
- 업로드일: 2026-07-12
- 원본: https://www.youtube.com/watch?v=T9mypKihAeY
- 채널: 찐AI
- 핵심 주제: 오픈소스 AI 코딩 IDE **Orca(오르카)**의 소개와 설치·설정, 그리고 핵심 특징(git worktree 기반 병렬 실행, 디자인 모드, 모바일 연결, CLI 오케스트레이션)을 실제 화면으로 시연
- 성격: 도구 소개·튜토리얼. 강의에서 확인된 내용만 정리했으며, 발표자가 "아직 많이 써 보지 못했다"고 밝힌 부분은 그대로 표시한다.

## 내용
### Orca란 무엇인가
- **오픈소스 IDE 도구**로, 소스 코드를 직접 받아 볼 수 있다(GitHub에서 소개·특징 확인 가능).
- Cursor나 VS Code 같은 IDE 계열이지만 성격이 다르다. 핵심은 **Codex, Claude Code, opencode, Hermes(헤르메스), OpenClaude** 같은 에이전트 도구들을 **git worktree 단위로 병렬 실행·관리**하게 해 주는 것.
- macOS뿐 아니라 Windows, Linux에서도 사용 가능.
- 문서에 정리된 주요 특징:
  - **모바일 컴패니언(mobile companion)** — 모바일로 제어 가능
  - **독립적인 git worktree** — 여러 에이전트를 병렬로 굴림
  - **터미널 스플릿(split)** — 화면 분할
  - **디자인 모드(design mode)** — 웹 화면을 터미널처럼 띄우고 특정 엘리먼트를 지정해 에이전트에 지시
  - **Git 통합 기능** — IDE 안에서 PR 올리기, 이슈 등록, 머지 등
  - **SSH 접근** — 다른 서버에 SSH로 접속해 작업
  - **diff + 코멘트** — 작업 결과 diff를 보고 그 안에 코멘트를 남김
  - **드래그 앤 드롭** — 파일을 끌어다 에이전트에 넘김

### 설치와 온보딩
- 설치 시 **Orca CLI** 설치 여부를 먼저 묻는다. Orca CLI는 `orca`로 시작하는 명령을 쓸 수 있게 해 주는 도구로, 설치하면 관련 CLI와 **스킬(skill)**이 함께 설치된다.
- Orca의 CLI·스킬에는 기본 포함 도구가 있고(Codex 등), 추가로 다른 에이전트(예: Claude Code, Hermes)에도 스킬로 심고 싶으면 온보딩에서 **스페이스바로 선택**한다.
- 설치 방식: **심볼릭 링크(symlink)** 권장(전체 복사 대신).
- **온보딩 체크리스트**(설정 버튼과 동일 화면) 순서:
  1. **알림(notifications)** — 에이전트가 작업을 마쳤을 때 알림 톤 선택(봉소리/투톤/블롭 등)
  2. **기본 에이전트(default agent)** — 설치된 것 중 선택(영상에서는 갓 나온 GPT 5.6 기반 Codex를 기본으로 지정)
  3. **Enable Orca CLI** — 앞 단계에서 CLI·스킬 설치를 마쳤으면 활성화됨
  4. **Connect integrations** — GitHub, Linear, Jira 등 연동. 개발자는 주로 GitHub 연결(PR·이슈·머지 작업). GitHub CLI 설치 권장(안 해도 무방)
  5. **Automate workspace setup** — git worktree 생성 시 자동 실행할 명령을 등록
  - 참고: 위 항목을 전부 설정하지 않아도(초록불이 안 들어와도) 사용에는 지장 없다.

### 사전 지식: git worktree
Orca를 이해하려면 **git worktree**를 알아야 한다.
- 같은 서버/공간에서 두 개발자가 각각 다른 작업(예: 한 명은 intro, 한 명은 logic)을 해야 할 때, 각자 다른 디렉터리에 clone을 뜨는 대신 **worktree**로 더 간단히 해결할 수 있다.
- worktree는 **별도의 작업 디렉터리를 만들면서 브랜치를 함께 딴다**.
  ```bash
  git worktree add ../example_intro -b feature/intro
  git worktree add ../example_logic -b feature/logic
  ```
- 핵심 차이: worktree 디렉터리 안의 `.git`은 **디렉터리가 아니라 파일**이다. 실제 저장소는 부모의 `.git`을 바라보고, 내용물(작업 트리)만 딸려온 것 → **부모와 논리적으로 한 몸**, 작업 공간만 분리.
- 그래서 작업 공간이 달라도 **커밋 이력을 공유**한다. 다른 worktree의 작업을 `git diff`로 비교하고 `git merge`로 합칠 수 있다.

### Orca는 worktree 단위로 움직인다
- Orca에 프로젝트(폴더)를 추가하면 마스터 브랜치와 기존 worktree 브랜치들이 각각 **탭**으로 뜬다. 상단 탭에서 고르는 단위가 곧 **worktree**다.
- `+` 버튼으로 새 worktree를 만들 수 있고, 이때 **브랜치 이름과 담당 에이전트**를 지정한다(예: `feature/login`).
- 하나의 worktree 안에서 **여러 탭**을 열 수 있다: Codex, Hermes 등 원하는 에이전트, 그리고 **브라우저**까지.
- 각 터미널은 **좌우/상하로 스플릿** 가능(우클릭 시 더 많은 옵션).
- **여러 프로젝트를 동시에** 열 수 있고, 각 프로젝트가 다시 worktree 단위로 움직인다. 프로젝트별 아이콘·색상 변경도 가능.
- **정리**: ① Orca는 git worktree 단위로 동작하고 ② 각 worktree 안에서 터미널을 여러 개, 원하는 에이전트로 열 수 있다.

### 디자인 모드 — 웹 화면 위에서 에이전트에 지시
- 브라우저 탭에 자신의 웹 앱(예: 토큰 대시보드)을 띄운다.
- **① 페이지 요소 가져오기**: 버튼을 누르고 설명하고 싶은 엘리먼트를 클릭하면 "Copied"가 뜨고, 에이전트 탭에 붙여 넣어 "이 부분 너무 큰 것 같아"처럼 직접 가리키며 지시할 수 있다.
- **② 페이지 요소 주석 달기(annotation)**: 엘리먼트를 지정하고 "이 부분은 필요 없는 것 같다, 제거해 줘" 같은 코멘트를 달아 추가 → 보내기를 누르면 해당 엘리먼트와 코멘트가 그대로 에이전트(Codex 등)에 전달되어 바로 수정 작업에 들어간다.
- **③ 개발자 도구**: 크롬 개발자 도구처럼 DevTools 탭도 볼 수 있다.
- ⚠️ 실무에서는 마스터가 아니라 **worktree를 하나 따서** 그 안에서 작업하는 것이 낫다(영상에서는 시연상 마스터에서 실행).

### 오른쪽 패널 — 파일 탐색기 · 활동 기록 · Git
- **탐색기(파일 브라우징)**: 폴더/파일을 보고 클릭해서 바로 편집. `.md` 파일은 **리치 에디터 모드**(제목·굵게·이탤릭·취소선 등)로 편집하거나 **소스 탭**에서 원본 마크다운으로 편집.
- 탐색기의 파일을 **드래그 앤 드롭**으로 에이전트 탭에 넣으면 파일 위치가 전달되어 그 상태로 지시 가능.
- **에이전트 활동 기록**을 볼 수 있다.
- **Git 작업**: 커밋, 푸시, PR 만들기 등을 패널에서 수행.

### 모바일 연결
- 설정 → 모바일에서 **QR 코드**가 생성된다. 먼저 모바일 앱을 설치해야 한다.
  - **iOS**: 앱스토어에서 다운로드(범고래 모양 아이콘).
  - **Android**: (영상 시점 7월 중순 기준) 스토어에 앱이 없어서, GitHub 릴리즈에서 **APK**를 받아 옮겨 설치. 추후 플레이스토어 등록 예상.
- 앱에서 QR을 인식해 연결하면 **PC와 거의 동일한 UI**가 모바일에 나온다: 프로젝트 목록, worktree 선택, 에이전트 선택, 터미널 입력·출력 모두 동일.
- **최대 장점 = 작업 연속성**. Hermes에 Discord/Slack을 붙여 쓰던 방식은 세션 연속성이 떨어졌지만, Orca는 **PC에서 하던 작업을 모바일에서 거의 그대로 이어서** 할 수 있다.

### ⚠️ 모바일 연결 시 네트워크 주의점 (중요)
- Orca 서버를 띄운 PC가 공유기 안 **사설망(예: 192.168.x.x)**에 있으면, 모바일도 **같은 Wi-Fi(같은 공유망)**에 있어야 통신된다.
- 하지만 같은 집이면 그냥 PC로 하면 되므로, 모바일의 의미는 **외부(인터넷망)에서 로컬 PC에 접속**하는 것. 이 경우 사설망 ↔ 인터넷망이라 그냥은 연결되지 않는다.
- 해결책: **Tailscale(테일스케일)**. 터널링으로 사설망의 Orca 서버와 외부망의 모바일을 이어 준다.
- **원리 비교** — Hermes + Discord는 중간에 **Discord 같은 중계 서버**가 있어서 가능했다. Hermes 에이전트가 먼저 Discord로 요청해 TCP 세션을 만들어 두고, 폰이 던진 메시지를 Discord 봇이 그 세션으로 중계 → 그래서 Hermes가 사설망 안에 있어도 통신됨. 반면 Orca는 **중계 서버가 없으므로** Tailscale이 그 역할(디스코드와 비슷한 원리)을 대신한다.
- PC로 돌아오면 "핸드폰이 제어 중"이라 뜨고, **모든 터미널 제어 가져오기** 버튼을 누르면 PC에서 이어서 작업 가능.

### Orca CLI — 오케스트레이션 (아직 실험적)
- Orca CLI에는 **오케스트레이션(orchestration)** 명령이 있다: `orca orchestration ...`으로 **태스크를 만들고 디스패치(dispatch)**하는 기능.
- Hermes의 **칸반(kanban)**과 매우 비슷하며, 여러 에이전트 간 작업을 분산시킬 수 있다.
- 실행 시 태스크가 생성되고 ID·상태(OK)가 나온다.
- ⚠️ 한계: 현재는 **CLI로만 지원되고 GUI 화면은 아직 없다**. 발표자도 아직 제대로 써 보지 못해 활용법은 더 살펴봐야 한다고 밝힘.

## 예시
### git worktree 기본 명령
```bash
# 현재 저장소에 인트로/로직 작업을 위한 worktree + 브랜치 생성
git worktree add ../example_intro -b feature/intro
git worktree add ../example_logic -b feature/logic

# 다른 worktree(브랜치)의 변경 비교
git diff feature/intro

# 부모 저장소에서 worktree 브랜치 병합
git merge feature/intro
```
- `.git`이 파일로 존재 → 부모 저장소를 참조하는 논리적으로 같은 저장소.

### Orca 사용 흐름 요약
```
설치 → Orca CLI 설치 → (에이전트에 스킬 심기, symlink) → 온보딩(알림/기본에이전트/통합/워크스페이스)
프로젝트(폴더) 추가 → worktree 탭 선택(+로 새 worktree = 브랜치 + 담당 에이전트)
worktree 안 → 여러 터미널/에이전트 탭 + 브라우저 열기, 스플릿
디자인 모드 → 웹 요소 지정/주석 → 에이전트에 그대로 전달해 수정
오른쪽 패널 → 파일 편집·드래그드롭, 활동 기록, Git(commit/push/PR)
모바일 앱 + QR 연결 → PC와 동일 UI로 이어서 작업 (외부망이면 Tailscale 필요)
Orca CLI orchestration → 태스크 생성·디스패치(칸반 유사, 아직 CLI 전용)
```

## 요약
- Orca는 **오픈소스 AI 코딩 IDE**로, Codex·Claude Code·Hermes 등 에이전트를 **git worktree 단위로 병렬 실행·관리**하는 것이 핵심이다.
- 설치 시 Orca CLI·스킬을 함께 깔고(symlink 권장), 온보딩에서 알림·기본 에이전트·통합(GitHub/Linear/Jira)·워크스페이스 자동 설정을 구성한다(선택적).
- **worktree = 부모 저장소와 논리적으로 한 몸이되 작업 디렉터리만 분리** → diff·merge로 협업 가능. Orca의 탭은 이 worktree 단위이며, 각 worktree에서 여러 에이전트·터미널·브라우저를 연다.
- **디자인 모드**로 웹 화면의 요소를 지정·주석해 에이전트에 그대로 넘겨 수정할 수 있고, 오른쪽 패널에서 파일 편집·드래그드롭·Git(PR·머지) 작업이 가능하다.
- **모바일 연결**은 PC와 동일 UI로 작업 연속성이 뛰어나지만, 외부망에서 쓰려면 사설망 문제 때문에 **Tailscale** 터널링이 필요하다(중계 서버가 있던 Hermes+Discord와 대비되는 지점).
- **Orca CLI 오케스트레이션**은 태스크 생성·디스패치로 에이전트 작업을 분산하지만 현재는 CLI 전용이고 GUI가 없어 아직 실험적이다.
