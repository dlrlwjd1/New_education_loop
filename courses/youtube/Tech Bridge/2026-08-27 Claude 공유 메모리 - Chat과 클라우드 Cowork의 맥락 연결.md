# Claude 공유 메모리 - Chat과 클라우드 Cowork의 맥락 연결

## 개요

- **업로드일:** 2026-08-27
- **채널:** Tech Bridge
- **발표자·출처:** Claude 메모리 업데이트 소개·시연
- **원본:** [YouTube](https://www.youtube.com/watch?v=qLT5cGk01mQ)
- **정리 범위:** 전체 제공 스크립트(마지막 발화 10:00, 자동 자막 언어 `de-DE`). 수치·제품 상태·전망은 영상 당시 발표자의 설명을 기준으로 한다.
- **핵심:** 주제별 메모리를 확인·수정하고 Chat과 클라우드 Cowork 사이에서 정보를 이어 쓰는 시연이다.

## 내용

### 공유되는 기억과 사용자 통제 (00:00~04:33)

영상은 Chat에서 쌓은 사용자 정보와 프로젝트 맥락을 Cowork 작업에 활용하고 그 결과를 다시 Chat에서 사용하는 공유 메모리를 소개한다. 초반에는 Projects라는 표현도 섞이지만 실제 시연의 중심은 Chat과 클라우드 Cowork다.

메모리는 프로필·선호·주제별로 구분되며 사용자가 내용을 확인하고 수정하거나 삭제할 수 있다. 대화가 끝난 뒤 요약하는 방식과 달리 대화 중 정보를 추가하는 동작을 설명한다. 민감한 주제를 기억할지는 설정에서 선택하는 것으로 소개한다. Claude Code까지의 통합은 발표자가 추측하는 향후 방향이며 시연된 기능이 아니다.

### 주제별 기억 편집 (04:33~07:38)

설정의 Memory 화면에서 저장된 프로필과 주제를 열어 본다. 의류 취향 항목에는 후드티의 핏과 소재에 대한 과거 선호가 들어 있다. 발표자가 팔 부분의 여유, 길이, 면 소재 선호를 말하자 해당 주제의 기억이 갱신된다. 다른 AI에서 기억을 가져오는 메뉴도 보여 준다.

### 실행 위치에 따른 차이 (07:38~10:00)

영상에서 설명하는 공유 메모리는 클라우드에서 실행하는 Cowork에 적용된다. 로컬 컴퓨터에서 실행하는 Cowork와 동일하게 취급하지 않는다. 클라우드 작업에서 셔츠 취향을 물어 앞서 저장한 정보를 확인하고, Cowork에서 바지 취향을 추가한 뒤 Chat에서 다시 조회해 양방향 동작을 보여 준다.

메뉴·제공 요금제·동기화 범위는 영상 당시 설명이다. 핵심은 기억이 있다는 표시만 보는 것이 아니라 저장된 내용과 실제 작업의 실행 위치를 확인하는 것이다.

## 예시

시연의 확인 순서:

1. Chat의 의류 메모리에 셔츠 취향을 추가한다.
2. 클라우드 Cowork에서 같은 취향을 조회한다.
3. Cowork에서 바지 취향을 저장한다.
4. Chat에서 새 정보를 다시 물어 동기화를 확인한다.

## 요약

- 기억은 주제별로 읽고 수정·삭제할 수 있어야 한다.
- 시연은 Chat과 클라우드 Cowork 사이의 양방향 공유다.
- 로컬 Cowork와 Claude Code를 같은 공유 범위로 가정하지 않는다.
