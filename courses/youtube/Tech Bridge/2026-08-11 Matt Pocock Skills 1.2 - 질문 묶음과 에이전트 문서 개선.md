# Matt Pocock Skills 1.2 - 질문 묶음과 에이전트 문서 개선

## 개요

- **업로드일:** 2026-08-11
- **채널:** Tech Bridge
- **발표자·출처:** Matt Pocock
- **원본:** [YouTube](https://www.youtube.com/watch?v=sZrFaPMau6A)
- **정리 범위:** 전체 제공 스크립트(마지막 발화 10:52, 자동 자막 언어 `de-DE`). 수치·제품 상태·전망은 영상 당시 발표자의 설명을 기준으로 한다.
- **핵심:** 스킬을 코딩 명령 모음에서 명확한 의사소통·의사결정·설정 작업을 돕는 도구로 확장한다.

## 내용

### 1. 문서와 배포 방식 정비 (0:00~2:31)

발표자는 스킬 문서 사이트에서 `Grill with Docs → Spec → Ticket → Implement → Code Review` 흐름과 전체 기능 참조, FAQ, 용어 설명을 제공한다고 소개한다.

Claude Code 플러그인 배포와 Codex용 `openai.yaml` 지원도 설명한다. 사용자가 명시적으로 호출하는 스킬의 설정을 도구별로 전달하기 위한 보완이라는 맥락이다. 설치·호출 동작은 영상에서 소개한 버전 기준이다.

### 2. Wait what? - 프로젝트의 언어로 다시 설명하기 (2:36~4:01)

모델이 장황한 표현과 낯선 용어를 쏟아내면 문장을 짧게 만드는 것만으로는 충분하지 않다. `Wait what?`은 단순한 기술 영어 원칙과 `context.md`의 공통 용어를 이용해 설명을 다시 쓰게 한다.

핵심은 사용자가 이미 합의한 개념과 표현으로 말하게 하는 것이다. 이해되지 않는 설명을 그대로 승인하는 대신 의미를 분명하게 되묻는 용도다.

### 3. Grill me - 의존관계가 없는 질문을 함께 묻기 (4:05~6:24)

한 번에 질문 하나만 하면 후반의 단순 확인 질문 때문에 대화가 느려진다. 그렇다고 모든 질문을 묶으면 선행 결정에 따라 달라지는 질문까지 일찍 답하게 된다.

새 방식은 질문을 의존 그래프로 본다. 먼저 중요한 선행 질문을 해결하고, 그 답으로 열리는 독립 질문을 다음 묶음으로 제시한다. 각 질문에는 추천 답변을 함께 보여주어 검토와 수정이 쉽도록 한다.

### 4. Write for agents - 에이전트가 읽을 모든 문서 (6:28~7:25)

기존의 스킬 작성 기능을 `AGENTS.md`, `CLAUDE.md`, 스킬 등 에이전트용 문서 전반으로 확장한다. 문서를 정확하고 예측 가능하게 만들고, 항상 읽는 지침에 모든 내용을 몰아넣지 않도록 필요한 부분을 스킬로 분리하는 데 활용한다.

### 5. Wizard - 사람이 수행할 설정 단계 안내 (7:28~8:56)

클라우드 설정처럼 사용자가 직접 로그인하고 값을 입력해야 하는 작업을 대화형 Bash 안내 스크립트로 만든다. 필요한 페이지를 열고, 설정을 순서대로 안내하고, 값을 필요한 파일이나 비밀 저장소에 넣는 시연이다.

발표자는 시연의 입력이 에이전트 대화가 아닌 결정적인 스크립트에서 처리된다는 점을 강조한다. 이것은 보여준 스크립트의 처리 방식에 대한 설명이며, 생성된 스크립트가 모두 자동으로 안전하다는 뜻은 아니다.

### 6. Questionnaire - 다른 사람과 결정하기 (8:59~10:52)

정원 사무실을 계획하다 실제 공동 의사결정자인 배우자와 상의해야 했던 사례를 든다. 에이전트의 질문을 Markdown 문서로 내보내고, Google Docs에서 함께 검토한 답을 다시 에이전트에 전달했다.

모든 이해관계자가 에이전트 채팅에 참여하는 것은 아니다. 질문 문서는 익숙한 협업 환경에서 의견을 모으는 연결 수단이다.

## 예시

영상에 나온 질문 묶음 방식은 다음과 같다.

1. 뒤의 선택을 좌우하는 핵심 질문을 먼저 답한다.
2. 그 답으로 결정 가능한 독립 질문들을 한 번에 받는다.
3. 추천안에 동의하는 항목과 수정할 항목을 구분해 답한다.
4. 공동 결정이 필요하면 질문 문서를 다른 사람과 검토한다.
5. 확정된 답을 에이전트에게 전달해 다음 단계로 진행한다.

## 요약

- 스킬 문서는 역할별 흐름과 공통 용어를 함께 설명해야 이해하기 쉽다.
- 질문을 묶되 선행 결정의 의존관계는 유지한다.
- 에이전트가 읽는 문서, 사람이 수행하는 설정, 공동 의사결정을 각각 지원하는 도구를 둔다.
