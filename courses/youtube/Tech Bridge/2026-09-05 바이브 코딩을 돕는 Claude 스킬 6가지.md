# 바이브 코딩을 돕는 Claude 스킬 6가지

## 개요

- **업로드일:** 2026-09-05
- **채널:** Tech Bridge
- **발표자·출처:** AI Labs / 스킬 활용 시연
- **원본:** [YouTube](https://www.youtube.com/watch?v=ss4lbO8M8wk)
- **정리 범위:** 전체 제공 스크립트(마지막 발화 13:06, 자동 자막 언어 `de-DE`). 수치·제품 상태·전망은 영상 당시 발표자의 설명을 기준으로 한다.
- **핵심:** 작업 관찰, 제품 전환, 코딩 원칙, 브라우저 조작, 디자인 비교, 수요 검증으로 스킬의 역할을 나눈다.

## 내용

### 작업에서 배우는 Task Observer (00:45–03:20)

반복된 실수와 해결책을 기록해 기존 스킬의 개선 후보로 삼는다. 관찰 내용을 즉시 영구 규칙으로 만들지 않고, 로그를 검토한 뒤 반영한다. 프로젝트별 설치로 서로 다른 업무의 교훈을 분리하는 방식을 권한다.

### 제품 안의 마케팅 (03:20–06:55)

온보딩, 페이월, 해지 흐름을 개선하는 세 스킬을 하나의 활용 영역으로 소개한다. 헬스장 앱에서 최초 입력을 줄이고 나머지 설정은 이후로 미루며, 유료 기능은 미리보기를 통해 가치를 보여준다. 해지 사유에 맞춰 대안과 일시정지를 제안하는 데모도 나온다. 실제 전환율 향상을 측정한 실험은 아니다.

### 코딩을 통제하는 네 원칙 (07:00–08:38)

가정을 드러내기, 가장 단순한 해결책 선택하기, 요청 범위를 보호하기, 완료 기준을 정하고 검증하기를 제시한다. 여러 프로젝트의 공통 상위 폴더에 지침을 두는 예를 보여준다.

### OpenCLI와 Variate (08:42–11:33)

OpenCLI는 CLI·Chrome 확장·스킬을 결합해 로그인한 사이트의 반복 작업을 명령으로 제공한다. 개인 계정으로 수행하는 작업의 자동화와 판매용 제품의 공식 서비스 연동은 구분한다.

Variate는 랜딩페이지 전체를 다시 만들지 않고 히어로·버튼 같은 부분의 여러 시안을 브라우저에서 비교하도록 돕는다. 선택 결과를 에이전트에 전달해 다음 변경으로 이어간다.

### 만들기 전 수요 검증 (11:33–13:06)

Sahil Lavingia의 Minimalist Entrepreneur 기반 스킬은 아이디어보다 접근 가능한 사람들과 반복되는 문제에서 출발한다. 구체적인 10명을 찾고 최소 3명의 지불 의사를 확인하는 기준을 소개한다. 이후 최소 제품, 수작업 서비스, 가격, 성장으로 이어진다.

## 예시

브랜드 로고를 가져오는 도구를 잘못 사용한 실패를 관찰 로그에 남긴다. 올바른 SVG 출처를 찾아 사람이 검토한 뒤 스킬에 반영해 같은 오류를 줄이는 사례다.

## 요약

- 스킬은 작업 중 얻은 교훈을 검토하며 유지해야 한다.
- 구현뿐 아니라 제품 사용 흐름과 수요 검증에도 활용한다.
- 제목의 생산성 배수는 이 영상에서 검증한 보편적 성과 수치가 아니다.
