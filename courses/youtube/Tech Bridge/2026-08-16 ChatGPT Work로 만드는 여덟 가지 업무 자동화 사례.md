# ChatGPT Work로 만드는 여덟 가지 업무 자동화 사례

## 개요

- **업로드일:** 2026-08-16
- **채널:** Tech Bridge
- **발표자·출처:** Yann / 9X
- **원본:** [YouTube](https://www.youtube.com/watch?v=keUx4WhU83U)
- **정리 범위:** 전체 제공 스크립트(마지막 발화 26:20, 자동 자막 언어 `en`). 수치·제품 상태·전망은 영상 당시 발표자의 설명을 기준으로 한다.
- **핵심:** 파일·브라우저·업무 도구를 연결해 대시보드, 분석 파일, 조사와 일괄 편집을 실제 산출물로 완성하는 사례를 보여 준다.

## 내용

### 대시보드와 웹 자료 수집 (00:00–07:00)

첫 사례는 참고 스크린샷, YouTube 데이터 연결용 사용자 스킬, BigQuery 관련 분석 기능과 사이트 제작 기능을 조합한 채널 대시보드다. 조회·시청 시간·영상별 지표를 만들고 차트에 마우스를 올리면 수치가 보이도록 추가 피드백을 준다. 첫 결과에서 반복 수정했다는 점을 분명히 한다.

두 번째는 자신의 블로그 대표 이미지 20개를 수집하고 글 제목과 이미지 파일을 연결하는 CSV를 만드는 작업이다. 브라우저에서 읽은 자료를 이후 이미지 제작의 참고 자산으로 남긴다. 전용 연결이 없는 도구에서 브라우저를 활용할 수 있다는 설명이다.

### 수식 기반 Excel과 근거 있는 리드 조사 (07:03–14:32)

세 번째는 커뮤니티·활동·이벤트·결제·이전 플랫폼 등 다섯 내보내기 자료를 합쳐 코호트 분석 통합 문서를 만드는 사례다. 값만 적지 말고 수식을 사용하게 해 원자료부터 결과까지 추적할 수 있도록 요청한다. 기존 회사 분석 양식이 있다면 템플릿으로 재사용하는 방법도 소개한다.

네 번째는 지역·기업 규모·채용과 AI 사업 신호로 후보 회사를 찾는 조사다. 기존 거래 기업 목록을 제외 기준으로 제공한다. 결과에는 근거 URL, 잠재 담당자, 적합 이유와 확신도를 남기고 실제 채용 페이지를 열어 확인한다.

### 영수증 처리와 여러 도구의 일괄 수정 (14:35–21:06)

다섯 번째는 영수증 이미지의 주요 필드를 읽어 Excel에 추가하고 처리한 파일을 날짜별 폴더로 옮기는 작업이다.

여섯 번째는 YouTube 설명란에 영상별 추적 링크를 추가하는 작업이다. 먼저 전체 영상 목록과 기존 설명을 저장해 원래 구조와 복구 기준을 확보한다. 무료 자료 링크가 있으면 그 아래에, CTA가 없으면 처음에 넣는 등 조건을 정하고 작은 범위부터 실행한다. 링크 생성 도구와 YouTube 연결을 함께 사용하고 변경된 설명을 확인한다.

### 일관된 이미지 제작과 원격 후속 작업 (21:12–26:20)

일곱 번째는 앞서 수집한 블로그 이미지를 참고해 스타일·해상도를 분석하고 새 글 세 개에 각각 세 가지 이미지를 만드는 사례다. 생성 프롬프트도 파일로 남겨 수정 이유를 추적한다. 기존 자료를 참고하는 흐름이며 모델 자체를 새로 학습하는 절차는 아니다.

여덟 번째는 컴퓨터에서 시작한 작업을 휴대폰에서 확인하고 다음 범위를 요청하는 원격 사용이다. 데스크톱 파일에 접근하는 작업이므로 실행 컴퓨터가 켜져 있어야 한다고 설명한다. UI·기능·제공 조건은 영상 당시 시연 내용이다.

## 예시

| 작업 | 입력에 포함한 기준 | 확인 가능한 산출물 |
|---|---|---|
| 코호트 분석 | 다섯 원자료와 수식 사용 요구 | 원자료·분석·수식·편집 가능한 차트 |
| 기업 조사 | 지역·규모·신호·기존 고객 제외 | 근거 URL과 적합 이유 |
| 설명란 수정 | 백업·삽입 조건·영상별 추적 값 | 변경 목록과 실제 영상 링크 |
| 이미지 제작 | 기존 스타일·정확한 크기·복수 후보 | 이미지와 생성 프롬프트 |

## 요약

- 연결된 데이터와 명확한 산출물 기준이 결과를 구체화한다.
- 수식·근거 URL·백업·프롬프트를 남겨 검토 가능하게 한다.
- 작은 범위에서 확인한 뒤 반복 작업으로 확장한다.
