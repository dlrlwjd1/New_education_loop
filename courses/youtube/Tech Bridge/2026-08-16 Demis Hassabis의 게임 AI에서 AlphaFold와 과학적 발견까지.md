# Demis Hassabis의 게임 AI에서 AlphaFold와 과학적 발견까지

## 개요

- **업로드일:** 2026-08-16
- **채널:** Tech Bridge
- **발표자·출처:** Demis Hassabis / Cambridge 강연 및 Q&A
- **원본:** [YouTube](https://www.youtube.com/watch?v=naFkUqXw_Uw)
- **정리 범위:** 전체 제공 스크립트(마지막 발화 59:57, 자동 자막 언어 `en`). 수치·제품 상태·전망은 영상 당시 발표자의 설명을 기준으로 한다.
- **핵심:** 학습으로 거대한 탐색 공간을 다루는 원리를 게임에서 과학으로 확장하고, AGI와 책임 있는 연구의 방향을 설명한다.

## 내용

### 체스에서 지능 연구로 (00:00–07:04)

하사비스는 어린 시절 체스가 사고·계획·문제 해결 자체에 대한 호기심을 만들었다고 회고한다. 직접 게임 AI를 만들고 Cambridge에서 계산 이론과 과학사의 영향을 받았다. 2010년 DeepMind를 시작한 목적은 일반 지능을 이해하고 이를 다른 문제의 해결에 사용하는 것이었다.

영상의 '올해', '최근 모델'은 원강연 시점의 표현이다. Tech Bridge 업로드일을 원강연의 기술 상태와 동일시하지 않는다.

### 규칙을 직접 넣는 방식에서 경험으로 학습하기 (07:05–16:16)

전문가가 해법을 직접 프로그램하는 시스템은 예상하지 못한 상황에 취약하다. 학습 시스템은 데이터와 경험에서 구조를 찾아 설계자가 이미 아는 해법을 넘어설 가능성이 있다.

게임은 목표와 결과가 명확한 실험 환경이다. DQN의 픽셀 입력 학습, AlphaGo의 이세돌 대국과 새로운 수, AlphaZero의 자가 대국을 소개한다. 신경망이 유망한 수와 상태 가치를 추정해 탐색을 좁히므로 모든 경우를 전수 조사할 필요가 줄어든다. 체스에서 기물 수보다 활동성을 중시하는 사례로 새로운 전략 발견을 설명한다.

### 과학 문제를 선택하는 세 기준 (16:22–21:56)

- 조합이 너무 많아 무차별 탐색이 어려우나 학습할 구조가 있다.
- 최적화할 목표나 평가 기준을 정의할 수 있다.
- 학습 데이터·경험이 있고, 가능하면 정확하고 효율적인 시뮬레이터가 있다.

단백질 구조 예측은 아미노산 서열에서 3차원 구조를 추정하는 문제다. 구조는 기능을 이해하는 중요한 단서지만 기능의 전부를 설명하지는 않는다. CASP는 아직 공개되지 않은 실험 구조를 기준으로 예측을 비교해 객관적인 진전을 확인할 수 있었다.

### AlphaFold와 후속 연구를 여는 문제 (21:23–30:17)

AlphaFold 1의 성과 이후 실험에 유용한 정확도에 도달하려고 AlphaFold 2의 구조를 다시 설계했다고 설명한다. 예측 구조와 실험 구조의 비교, 대규모 예측 데이터베이스의 공개와 연구자 활용을 소개한다. 계산 예측을 실제 실험으로 전부 확인한 구조와 혼동해서는 안 된다.

플라스틱 분해 효소, 항생제 내성, 소외 질환, 복합체와 약물 전달 연구를 활용 사례로 든다. 이런 구조 예측은 하나를 해결하면 여러 연구 방향이 열리는 'root node problem'의 예다.

AlphaFold 3는 단백질과 다른 분자 사이의 상호작용으로 범위를 넓히고, AlphaProteo는 원하는 기능을 수행할 새로운 단백질 설계 방향을 다룬다고 소개한다.

### 디지털 생물학과 실험의 역할 (30:25–35:35)

바둑의 수를 찾는 탐색을 화학 공간에서 원하는 분자를 찾는 문제에 비유한다. Isomorphic Labs를 통한 신약 발견 가속과 가상 세포를 장기 목표로 설명한다. 가상 실험으로 후보를 좁히고 실제 실험실에서 검증하는 방향이다.

AI의 적용 예로 재료, 핵융합 제어, 행렬 곱셈 알고리즘, 날씨, 양자 오류 정정도 든다. 전문 분야의 좋은 문제와 AI 방법을 결합하는 학제 간 연구를 강조한다. 신약 개발을 주 단위로 줄인다는 등의 언급은 달성 사실이 아니라 장기 희망이다.

### 세계 모델·계획·책임 있는 개발 (35:38–44:52)

원강연 당시 Veo 2와 Genie 2를 세계의 시각적·상호작용 구조를 학습하는 예로 제시한다. 생성한 게임 세계의 일관성이 당시에는 짧은 시간에 제한됨을 인정한다. Gemini 같은 범용 모델에 탐색과 계획을 결합하는 것이 보조자와 로봇의 다음 단계라는 전망이다.

SynthID와 국제적 논의를 예로 들며 기회뿐 아니라 위험도 과학적 방법과 사회적 참여로 다뤄야 한다고 주장한다.

자연에 안정된 구조가 있다면 고전적 학습 시스템으로 효율적인 근사를 찾을 수 있을 것이라는 추측도 제시한다. 이는 P=NP의 해결이나 모든 양자계를 고전 컴퓨터로 효율적으로 계산할 수 있다는 증명이 아니다.

### Q&A — 학습, 신경과학, 진로와 게임 (45:09–59:57)

기억과 상상에 관여하는 해마, 창의성·의식 연구와 AI 비교의 가능성을 이야기한다. DeepMind의 초기 선택은 신경망·강화학습·GPU·신경과학의 진전이 만난 결과였으며, 초기에는 간단한 게임도 잘 학습하지 못했다고 회고한다.

뇌-컴퓨터 인터페이스는 해상도와 안전 문제가 남아 있으며 의료적 기능 회복과 장기적 인간 능력 확장을 구분해 전망한다. 진로에 대해서는 코딩과 수학의 기반을 익히고 새로운 도구와 정보를 빠르게 배우는 능력을 권한다.

게임에서는 에셋 생성, 대규모 플레이를 통한 밸런스·버그 검사, 반응하는 NPC가 활용 방향이다. 세계 모델 연구는 즉시 완성형 게임 엔진을 대체하기보다 일반적인 세계 이해를 탐구하는 목적도 있다고 설명한다.

## 예시

게임에서 과학으로 옮기는 문제 구조:

| 구성 | 게임 사례 | 과학 사례 |
|---|---|---|
| 탐색 대상 | 가능한 수와 국면 | 구조·분자 후보 |
| 목표 | 승리 또는 점수 | 예측 정확도·원하는 분자 특성 |
| 학습 근거 | 대국 기록·자가 대국 | 실험 데이터·가능한 시뮬레이션 |
| 검증 | 실제 대국 결과 | 공개되지 않은 실험 결과와 비교 |

두 분야의 알고리즘이 그대로 같다는 뜻이 아니라, 학습으로 탐색을 유도한다는 공통 관점이다.

## 요약

- 학습은 거대한 조합 공간에서 유망한 후보를 찾는 데 활용된다.
- 좋은 과학 문제에는 분명한 목표와 검증 가능한 데이터가 필요하다.
- AlphaFold의 성과, 후속 연구의 가능성, AGI에 대한 추측을 구분한다.
- 과학적 방법과 책임 있는 배포를 기술 발전의 일부로 본다.
