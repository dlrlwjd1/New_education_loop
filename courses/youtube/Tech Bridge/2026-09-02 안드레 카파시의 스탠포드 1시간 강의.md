## 내용

### 2012년 이전 — 분야마다 달랐던 수작업 파이프라인
Karpathy가 컴퓨터 비전을 시작한 2011~2012년 무렵에는 이미지 분류를 위해 색상 히스토그램, 텍스처, 기하 특징 등 수많은 특징 기술자(feature descriptor)를 사람이 골라 결합하고 그 위에 SVM을 얹었다. 구현은 복잡했으며 결과도 불안정했다.

NLP, 음성, 강화학습도 각자 다른 용어와 파이프라인을 사용했기 때문에 한 분야의 연구자가 다른 분야 논문을 읽기 어려웠다. 2012년 AlexNet은 큰 신경망과 큰 데이터셋, 충분한 연산을 함께 확장하면 성능이 크게 좋아진다는 방식을 보여줬다. 이후 여러 분야가 신경망, 파라미터, 옵티마이저라는 공통 도구를 쓰기 시작했다.

2017년 트랜스포머가 등장한 뒤에는 도구뿐 아니라 아키텍처까지 수렴했다. 입력 데이터를 토큰이나 패치 같은 조각으로 바꾸는 방식은 달라도, 핵심 계산 구조는 거의 같은 트랜스포머를 재사용할 수 있게 됐다.

### 어텐션은 인코더 병목을 해결하려고 태어났다
2003년 신경망 언어 모델은 앞의 몇 단어로 다음 단어를 예측했다. 2014년 sequence-to-sequence 모델은 가변 길이 문장을 번역하기 위해 인코더 LSTM이 전체 입력을 하나의 벡터로 압축하고, 디코더 LSTM이 그 벡터에서 출력 문장을 생성했다.

문제는 긴 입력의 모든 정보를 고정 길이 벡터 하나에 담는 **인코더 병목(encoder bottleneck)**이었다. Dzmitry Bahdanau는 디코더가 다음 단어를 만들 때 입력 문장의 관련 위치를 부드럽게 검색(soft search)하도록 만들었다. 현재 단어 생성 상태와 각 입력 상태의 관련도를 구하고, softmax로 가중치를 정규화한 뒤, 입력 상태의 가중합을 문맥 벡터로 사용하는 방식이다.

Bahdanau가 Karpathy에게 보낸 설명에 따르면, 외국어 번역 연습에서 원문과 번역문 사이로 시선을 옮기는 경험이 아이디어의 직관이었다. 초기에 RNNsearch라 불렸던 메커니즘은 Yoshua Bengio의 제안으로 attention이라는 이름을 얻었다.

### 2017년 트랜스포머가 결합한 요소
《Attention Is All You Need》는 순환 신경망을 제거하고 어텐션을 중심 계산으로 삼았다. 동시에 여러 아이디어를 안정적인 하나의 구조로 결합했다.

- 입력 순서를 알려주는 위치 인코딩(positional encoding)
- ResNet에서 가져온 잔차 연결(residual connection)
- 어텐션과 번갈아 적용되는 다층 퍼셉트론(MLP)
- 층 정규화(layer normalization)
- 여러 관계를 병렬로 학습하는 멀티헤드 어텐션(multi-head attention)
- MLP 내부 차원을 넓히는 확장 비율 등 실용적인 하이퍼파라미터

이후 layer norm의 위치를 post-norm에서 pre-norm으로 옮기거나 rotary·relative positional encoding을 쓰는 변화가 생겼지만, 핵심 구조는 오랫동안 유지됐다.

### 어텐션을 그래프의 메시지 전달로 이해하기
Karpathy는 트랜스포머를 **통신(communication)**과 **계산(computation)**이 반복되는 시스템으로 설명한다.

- 통신 단계: 멀티헤드 어텐션이 노드 사이에서 정보를 전달한다.
- 계산 단계: MLP가 각 노드의 벡터를 독립적으로 변환한다.

각 토큰을 벡터를 가진 그래프 노드라고 보면, 노드는 현재 벡터에서 query, key, value를 만든다.

- Query: 내가 찾는 정보는 무엇인가?
- Key: 내가 가진 정보의 종류는 무엇인가?
- Value: 선택되었을 때 전달할 실제 정보는 무엇인가?

수신 노드의 query와 송신 후보들의 key를 내적해 관련도 점수를 얻고, softmax로 합이 1이 되게 만든 뒤, 그 값으로 value들의 가중합을 구한다.

```text
scores  = query · keysᵀ
weights = softmax(scores / √d)
update  = weights · values
```

여러 head는 서로 다른 관계를 병렬로 찾고, 여러 layer는 이 통신과 계산을 연속해서 반복한다. 스케일링 항 `√d`는 차원이 커질수록 내적 분산이 커져 softmax가 지나치게 뾰족해지는 것을 막는다.

### Self-attention, cross-attention, causal attention
세 가지 어텐션은 기본 수학보다 정보가 어디에서 오고 어떤 연결을 허용하는지가 다르다.

| 종류 | Query | Key·Value | 연결 방식 |
| --- | --- | --- | --- |
| Self-attention | 현재 토큰 집합 | 같은 토큰 집합 | 같은 집합 내부 통신 |
| Cross-attention | 디코더 토큰 | 인코더 출력 | 디코더가 입력 표현을 조회 |
| Causal self-attention | 현재 디코더 토큰 | 현재와 이전 토큰 | 미래 토큰 연결을 마스크 |

인코더는 모든 입력 토큰이 서로 통신하도록 완전 연결된다. 자동회귀 디코더는 정답이 될 미래 토큰을 볼 수 없도록 삼각형 형태의 causal mask를 적용한다. Cross-attention에서는 query가 디코더에서, key와 value가 인코더에서 나온다.

### NanoGPT로 보는 학습 데이터와 순전파
강의는 약 300줄의 NanoGPT 구현을 이용해 decoder-only transformer를 설명한다.

1. 텍스트를 토큰 정수열로 인코딩한다.
2. 긴 정수열에서 `block_size` 길이의 조각을 여러 개 뽑아 batch를 만든다.
3. 입력과 한 칸 뒤로 이동한 target을 함께 만든다.
4. 토큰 임베딩과 위치 임베딩을 더한다.
5. 여러 transformer block을 통과시킨다.
6. 마지막 linear language-model head가 다음 토큰 확률을 출력한다.
7. 정답 토큰과 cross-entropy loss를 계산해 학습한다.

한 batch는 겉으로는 `B × T` 배열이지만, 각 위치가 이전 문맥으로 다음 토큰을 예측하는 학습 사례이므로 많은 예제를 병렬로 담는다.

Transformer block 안에서는 layer norm을 거쳐 causal self-attention으로 토큰들이 통신하고, MLP가 각 토큰을 계산한다. 잔차 경로는 두 결과를 원래 표현에 더해 깊은 네트워크에서도 기울기가 흐르기 쉽게 만든다.

생성할 때는 시작 토큰에서 다음 토큰 분포를 얻어 하나를 샘플링하고, 그 토큰을 입력 뒤에 붙여 같은 과정을 반복한다. 입력이 학습된 `block_size`보다 길어지면 오래된 문맥을 잘라야 하므로 기본 트랜스포머에는 유한한 컨텍스트 길이가 있다.

### Encoder-only, decoder-only, encoder-decoder

- GPT는 미래를 가린 상태로 다음 토큰을 예측하는 decoder-only 모델이다.
- BERT는 입력 전체가 서로 통신하는 encoder-only 모델이며, masked-token 복원이나 분류 같은 목표로 학습한다.
- T5 같은 encoder-decoder 모델은 입력을 완전히 인코딩한 뒤 디코더가 self-attention과 cross-attention을 모두 사용한다.

코드 관점에서는 causal mask를 제거하면 encoder attention이 되고, 디코더에 인코더의 key·value를 읽는 줄을 추가하면 cross-attention이 된다. 같은 연산을 그래프 연결 규칙만 바꿔 여러 구조로 사용할 수 있다.

### 이미지, 음성, 강화학습, 단백질로의 확장
트랜스포머가 처리하는 기본 단위는 순수한 집합에 가깝다. 그래서 데이터를 적절한 조각으로 만들고 위치나 종류를 알려주면 여러 도메인에 적용할 수 있다.

- Vision Transformer는 이미지를 작은 패치로 자른다.
- Whisper는 Mel spectrogram을 시간 조각으로 나눈다.
- Decision Transformer는 상태, 행동, 보상을 하나의 시퀀스처럼 다룬다.
- AlphaFold의 핵심 계산에도 트랜스포머 계열 구조가 사용된다.

새 센서나 차량 정보처럼 서로 다른 입력을 추가할 때도 각 입력을 토큰화하고 유형 임베딩을 붙여 같은 집합에 넣을 수 있다. 기존 convolution처럼 계산을 유클리드 공간 구조에 강하게 맞추지 않아도 self-attention이 필요한 상호작용을 학습한다.

데이터가 적을 때는 convolution의 지역성 같은 귀납적 편향(inductive bias)이 유용하다. 데이터가 충분히 많다면 구조를 덜 강제하고 모델이 학습하게 두는 편이 나을 수 있다. 어텐션 마스크로 지역 통신과 전역 통신을 섞는 식으로 편향의 정도를 조정할 수도 있다.

### 인컨텍스트 학습은 순전파 안의 학습이다
GPT-3는 프롬프트에 질문과 답의 예시를 더 많이 제공할수록 새로운 질문의 정확도가 높아지는 few-shot learning을 보여줬다. 이때 모델 가중치를 gradient descent로 바꾸지 않는데도 문맥 안에서 과제를 배운다.

Karpathy는 이를 두 학습 루프로 본다.

- 바깥 루프: 학습 데이터로 가중치를 갱신하는 gradient descent
- 안쪽 루프: 고정된 가중치가 프롬프트를 읽으며 활성값 안에서 수행하는 인컨텍스트 학습

트랜스포머의 순전파가 내부적으로 ridge regression이나 gradient-based update와 비슷한 계산을 구현할 수 있다는 연구들은, 모델이 단순한 패턴 완성을 넘어 프롬프트 안에서 학습 알고리즘을 실행할 가능성을 보여준다.

### 트랜스포머가 강력한 세 가지 이유
Karpathy는 성공 요인을 세 속성의 결합으로 정리한다.

1. **표현력(expressiveness)** — 순전파가 복잡한 함수와 인컨텍스트 학습을 구현할 수 있다.
2. **최적화 용이성(optimizable)** — 잔차 연결과 layer norm 덕분에 감독 신호에서 입력까지 기울기가 잘 흐른다.
3. **계산 효율성(efficiency)** — 얕고 넓은 계산 그래프로 GPU 병렬성을 효과적으로 사용한다.

RNN도 이론적으로 복잡한 프로그램을 표현할 수 있지만, 시간축을 따라 긴 직렬 계산을 수행하므로 최적화와 병렬 처리에 불리하다. 딥러닝에서는 더 큰 모델과 데이터로 확장하는 능력이 중요하므로 하드웨어 효율성이 결정적인 장점이 된다.

그는 트랜스포머를 “범용적이고 효율적이며 최적화 가능한 컴퓨터”로 해석한다. GPT는 자연어 프롬프트를 프로그램처럼 받아 문서 완성이라는 방식으로 실행되는 범용 텍스트 컴퓨터에 가깝다.

### Q&A — 자동회귀, 멀티모달, 외부 메모리
Karpathy는 한 토큰을 생성할 때마다 되돌릴 수 없이 확정하는 자동회귀 방식이 인간의 초안·수정 과정과 달라 아쉽다고 말한다. 전체 결과를 여러 차례 개선하는 diffusion 방식과의 결합 가능성을 흥미롭게 본다.

멀티모달 입력은 이미지 패치, 레이더 조각, 차량 정보 등에 서로 다른 유형 임베딩을 부여하고 한 토큰 집합에 넣는 방식으로 처리할 수 있다. 위치 정보는 학습 가능한 임베딩이나 고정된 삼각함수 인코딩으로 더한다.

유한한 컨텍스트를 넘는 방법으로는 모델이 외부 scratchpad나 노트에 기억을 쓰고 나중에 다시 조회하도록 가르치는 아이디어를 제시한다. 이는 사람이 모든 것을 머릿속에 보관하지 않고 메모장을 사용하는 것과 같다.

## 예시

### 한 번의 causal self-attention

```python
import math

# q: 현재 위치가 찾는 정보
# keys: 현재와 이전 위치가 가진 정보의 표지
# values: 선택되면 전달할 실제 정보
scores = q @ keys.T / math.sqrt(q.shape[-1])
weights = scores.softmax(dim=-1)
update = weights @ values
```

실제 구현에서는 batch, head, time 차원을 한꺼번에 처리하며, 미래 위치의 score를 softmax 전에 음의 무한대로 채워 가중치가 0이 되게 한다.

### 아키텍처를 그래프 연결로 구분하기

```text
Encoder:
각 토큰 ↔ 모든 입력 토큰

Decoder:
토큰 t ← 토큰 1..t

Encoder–Decoder:
디코더 토큰 t ← 이전 디코더 토큰 + 모든 인코더 출력
```

## 요약
- 2012년 이후 큰 신경망·데이터·연산을 확장하는 방식이 분야별 수작업 특징 설계를 대체했고, 2017년 이후 트랜스포머가 공통 아키텍처가 됐다.
- 어텐션은 sequence-to-sequence 모델의 고정 길이 인코더 병목을 해결하기 위한 입력 위치의 soft search에서 출발했다.
- Query와 key의 내적으로 관련도를 구하고 value를 가중합하는 과정은 그래프 위의 데이터 의존적 메시지 전달로 이해할 수 있다.
- 트랜스포머는 어텐션 통신과 노드별 MLP 계산을 번갈아 수행한다.
- Causal mask와 key·value의 출처를 바꾸면 encoder-only, decoder-only, encoder-decoder 모델을 같은 핵심 연산으로 구성할 수 있다.

- GPT의 인컨텍스트 학습은 가중치 변경 없이 프롬프트 안에서 과제를 배우는 내부 학습 루프로 볼 수 있다.
- 높은 표현력, 쉬운 최적화, GPU 효율성의 결합이 트랜스포머의 장기적인 성공을 설명한다.
