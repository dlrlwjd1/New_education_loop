# Reelful의 에이전트 영상 편집 파이프라인과 사용자 경험

## 개요

- **업로드일:** 2026-08-20
- **채널:** Tech Bridge
- **발표자·출처:** Kate / Reelful
- **원본:** [YouTube](https://www.youtube.com/watch?v=wxlvbMHNZsQ)
- **정리 범위:** 전체 제공 스크립트(마지막 발화 12:00, 자동 자막 언어 `de-DE`). 수치·제품 상태·전망은 영상 당시 발표자의 설명을 기준으로 한다.
- **핵심:** 실제 촬영물을 이해하고 편집 계획을 세운 뒤, 코드로 표현한 영상 구성을 검증해 완성한다.

## 내용

### 실제 촬영물 편집이 어려운 이유 (00:00–05:06)

사진과 영상을 많이 찍어도 편집이 번거로워 게시하지 못하는 문제에서 출발한다. 사용자는 미디어와 간단한 맥락을 제공하고, 에이전트는 좋은 장면을 고르고 자막·음악·내레이션을 구성한다. 말하는 영상에서 실수한 테이크와 긴 멈춤을 제거하는 것도 예로 든다.

빈 화면에서 새 영상을 생성하는 것과 달리, 실제 촬영물을 편집하려면 불완전하고 뒤섞인 자료 안에서 무엇을 남기고 버릴지 판단해야 한다. 인프라는 앱 생성 에이전트와 비슷하지만, 수정 대상은 코드베이스 대신 영상 구성이고 최종 출력은 렌더링된 영상이다.

### 이해 → 계획 → 편집 → 검증 (05:06–08:02)

먼저 장면을 이해하고 음성을 전사한다. 사용자에게 창작 계획을 제시해 승인이나 수정을 받은 뒤 원격 샌드박스를 시작한다. 에이전트의 스킬에는 장면 선택, 컷 편집, 글꼴 조합, B-roll 구성처럼 편집 취향과 기술이 들어간다.

음악·내레이션·효과음 생성과 사진 애니메이션을 별도 작업으로 수행할 수 있다. 최종 구성은 React 코드로 영상을 표현하는 Remotion으로 만든다. 코드 작성에 강한 에이전트가 미디어의 순서와 트랙을 편집하도록 하는 접근이다. 검증층은 구성이 유효하고 렌더링 가능한지 확인하고, 문제가 있으면 수정을 요청한다.

### 복잡한 백엔드를 감추는 인터페이스 (08:02–09:46)

사용자가 모든 단계를 이해할 필요가 없도록 모바일 중심 인터페이스를 택한다. 카메라를 보며 말하기, B-roll 추가, 내레이션 추가 같은 목적별 템플릿으로 프롬프트 작성 부담을 줄인다.

자동 편집 후에도 사용자가 1초를 자르거나 자막 한 단어를 고칠 수 있도록 일반 편집기를 함께 제공한다. 큰 작업은 에이전트에게 맡기고 작은 수정은 익숙한 직접 조작으로 마무리하는 방식이다.

### 시연과 제품 단계 (09:46–12:00)

발표자는 행사에서 촬영한 자료를 편집한 영상을 보여 주며 실제 소셜 미디어에 게시하고 있다고 설명한다. 발표 당시 두 번째 베타를 소개하고 사용자 피드백을 요청한다. 데모는 활용 사례이며 모든 촬영물에서 동일 품질을 보장하는 평가는 제시하지 않는다.

## 예시

영상에서 설명한 사용 흐름:

1. 행사 사진과 짧은 영상을 넣는다.
2. 에이전트가 장면을 분석하고 편집 계획을 제안한다.
3. 사용자가 계획을 승인하면 음악·자막·장면 전환을 구성한다.
4. 렌더링 검증 후 결과를 보여 준다.
5. 필요한 자막이나 길이는 내장 편집기에서 직접 수정한다.

## 요약

- 실제 촬영물 편집에는 장면 이해와 선택 기준이 필요하다.
- Remotion 구성과 검증 루프로 에이전트의 코드 작성 능력을 활용한다.
- 템플릿과 직접 편집 기능을 함께 제공해 사용자 부담을 줄인다.
