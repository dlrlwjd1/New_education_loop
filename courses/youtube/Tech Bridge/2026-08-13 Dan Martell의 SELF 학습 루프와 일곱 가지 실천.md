# Dan Martell의 SELF 학습 루프와 일곱 가지 실천

## 개요

- **업로드일:** 2026-08-13
- **채널:** Tech Bridge
- **발표자·출처:** Dan Martell
- **원본:** [YouTube](https://www.youtube.com/watch?v=UKc3SlEPlKs)
- **정리 범위:** 전체 제공 스크립트(마지막 발화 20:09, 자동 자막 언어 `de-DE`). 수치·제품 상태·전망은 영상 당시 발표자의 설명을 기준으로 한다.
- **핵심:** 당장 해결할 문제를 기준으로 배우고 자기 언어로 정리한 뒤 적용·설명·반복으로 숙련을 만든다.

## 내용

### Select — 지금 필요한 주제 선택 (00:00–05:05)

발표자는 책과 강좌를 소비하기만 하고 실행하지 않는 'shelf-help'를 비판한다. 자기주도 학습을 다음 일곱 실천으로 설명한다.

1. **Just-in-time 학습:** 현재 어떤 문제를 해결할지 정하고 필요한 내용을 고른다.
2. **AI에게 질문받기:** 목표·사업 맥락·약점을 인터뷰하게 한 뒤 자료·형식·링크·선정 이유를 받는다. 목록 전체 대신 하나를 선택해 시작한다.

### Extract — 적용할 것을 추출 (05:08–09:42)

3. **읽기보다 공부하기:** 작은 분량을 매일 읽고, 메모할 준비를 하며, 핵심을 자기 언어로 다시 쓴다. 한 번에 적용할 행동 하나를 뽑는다. 영상의 하루 10쪽은 발표자의 습관이다.

공개 인터뷰·콘텐츠에서 주제별 학습 개요를 구성하는 AI 활용도 소개한다. 이는 원저자가 실제 집필한 책과 구분해야 한다.

### Feed — 학습 자료의 유입을 설계 (09:45–12:19)

4. **정기 브리핑과 깊은 학습:** 선택한 주제에 맞는 자료만 모아 짧은 브리핑을 만들고, 별도로 원자료를 깊게 공부한다. NotebookLM의 여러 표현 형식을 활용하는 예도 든다. 피드의 양을 늘리는 것보다 목표와 무관한 정보·반복을 줄이는 것이 목적이다.

### Live — 행동하고 설명하기 (12:22–16:39)

5. **48시간 안에 적용:** 배운 내용을 자신의 상황에 옮겨 실행할 시간을 달력에 잡는다. 48시간은 행동을 촉진하는 개인 규칙이며 지식이 그 뒤 사라진다는 과학 법칙은 아니다.
6. **거울 테스트:** 다른 사람에게 설명하고 무엇을 이해했는지 다시 말하게 해 전달의 빈틈을 찾는다. 혼자라면 원자료와 자신의 음성 설명을 AI에 주고 모호함·오류·누락을 평가받는다.

### Forge — 한 번의 성공을 반복 가능한 실력으로 (16:43–20:09)

7. **안정적으로 수행할 때까지 연습:** 한 번 맞게 하는 것에서 멈추지 않고 지속적으로 반복한다. 발표자는 오랜 시간 한 주제에 집중한 개인 경험을 강조한다.

후반부의 1만 시간·천 일·백 개월·십 년은 장기 헌신을 강조하는 표현이다. 달력상의 기간 전체를 실제 연습 시간으로 환산하거나 숙련에 필요한 고정 기준으로 받아들이지 않는다.

## 예시

영상의 발표 기술 학습 사례:

`설명 프레임워크 학습 → 자기 표현으로 정리 → 당일 팟캐스트·팀 교육·짧은 영상에 적용 → 상대가 이해한 내용 확인 → 부족한 부분을 다음 실행에서 개선`

학습의 완료 기준을 콘텐츠 소비가 아니라 행동과 설명 가능성으로 둔다.

## 요약

- 현재 문제와 연결된 한 가지 학습 주제를 선택한다.
- 자기 언어로 정리하고 빠르게 적용한다.
- 설명의 빈틈을 확인하고 반복해 안정적인 수행으로 만든다.
