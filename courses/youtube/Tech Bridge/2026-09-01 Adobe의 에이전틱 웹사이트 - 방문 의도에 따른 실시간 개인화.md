# Adobe의 에이전틱 웹사이트 - 방문 의도에 따른 실시간 개인화

## 개요

- **업로드일:** 2026-09-01
- **채널:** Tech Bridge
- **발표자·출처:** Carlos Sanchez / Adobe
- **원본:** [YouTube](https://www.youtube.com/watch?v=PXHUHNX7nbI)
- **정리 범위:** 전체 제공 스크립트(마지막 발화 20:10, 자동 자막 언어 `de-DE`). 수치·제품 상태·전망은 영상 당시 발표자의 설명을 기준으로 한다.
- **핵심:** 사이트 콘텐츠와 방문 행동을 바탕으로 정해진 페이지 블록을 개인화하고, 정확도·지연 시간·비용을 함께 평가한다.

## 내용

### 고정 페이지에서 의도 기반 페이지로 (00:00~04:19)

방문자가 구매하려는지 정보를 찾는지에 따라 필요한 콘텐츠가 달라진다. 발표는 Adobe Experience Manager의 Edge Delivery와 모델 추론을 결합해 방문 의도에 맞는 페이지를 구성하는 접근을 소개한다. 사이트 자료를 검색해 사용하는 RAG를 기반으로 하며, 브랜드와 무관한 페이지 전체를 자유롭게 생성하기보다 허용된 블록을 바꾼다.

마케터가 자연어로 목표를 설정하고 방문 결과를 분석해 개인화를 개선하는 피드백 순환을 지향한다.

### 개인화의 단위와 추론 경로 (04:19~12:22)

방문 페이지, 머문 시간, 검색어 등을 이용해 관심사를 추정하고 히어로 영역·상품·블로그·내비게이션·행동 유도 문구를 선택한다. 모델과 프롬프트는 사이트별 평가 자료로 비교한다. 단순한 블록 선택에는 가장 큰 모델보다 빠르고 충분히 정확한 모델이 적합할 수 있다.

발표에서는 약 15개 프롬프트를 이용한 지연 시간 비교를 설명한다. 특정 환경에서 나온 평균값이며 모든 사이트의 응답 시간 보장은 아니다. 사용자가 탐색하는 동안 추천 페이지를 미리 계산하면 체감 지연은 줄지만 반복 추론 비용이 증가한다.

### 커피와 캠핑 사이트 시연 (12:22~18:09)

커피 장비 페이지를 탐색하면 관련 추천이 바뀌고, 캠핑 의도를 입력하면 휴대용 제품과 캠핑 팁을 포함한 화면으로 조정된다. 개발용 정보에서는 추론 시간을 확인한다. 정해진 콘텐츠와 컴포넌트를 의도에 맞게 재조합하는 것이 데모의 핵심이다.

### 확장 방향 (18:09~20:10)

음성으로 요구를 말하고 화면에 맞춤 결과를 표시하는 개인 비서 경험도 제안한다. 이미지·미디어 생성까지 확장할 때는 브랜드에 맞는 품질이 추가 과제다. 이 부분은 완성된 보편적 기능이 아니라 발전 방향으로 제시된다.

## 예시

영상의 데모 흐름:

`커피·캠핑 관련 탐색 → 방문 의도 추정 → 사이트 자료 검색 → 허용된 블록 선택 → 추천 페이지 표시 → 반응 분석`

평가에서는 추천의 관련성뿐 아니라 추론 지연, 미리 계산한 결과의 사용률, 방문당 비용을 함께 본다.

## 요약

- 개인화는 방문 의도를 근거로 콘텐츠와 블록을 선택하는 문제다.
- RAG와 제한된 컴포넌트로 브랜드·콘텐츠 범위를 관리한다.
- 빠른 추론과 선계산은 비용까지 포함해 비교해야 한다.
