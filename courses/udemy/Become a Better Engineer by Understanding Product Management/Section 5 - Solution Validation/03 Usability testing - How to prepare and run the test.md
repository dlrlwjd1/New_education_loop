# Usability testing - How to prepare and run the test

## 개요

- 사용성 테스트를 계획·진행·기록하는 절차를 다룬다.

## 내용

- 목표, 대상 사용자, 핵심 과업, 프로토타입, 성공 지표를 미리 준비한다.
- 현실적인 시나리오를 제시하되, 해법을 암시하는 표현은 피한다.
- 사용자에게 "생각을 소리 내어 말하기(think aloud)"를 요청하고, 진행자는 도움을 최소화한다.
- 과업 성공 여부, 소요 시간, 오류, 질문, 행동, 발언을 기록한다.
- 세션이 끝난 뒤 만족도와 전반적인 인상을 묻는다.

## 예시

- ❌ "검색 버튼을 클릭해 보세요"
- ✅ "지난달 리포트를 찾아서 팀에 공유해 주세요"

## 요약

- 중립적인 과업과 일관된 관찰 기준으로 사용성을 검증한다.
