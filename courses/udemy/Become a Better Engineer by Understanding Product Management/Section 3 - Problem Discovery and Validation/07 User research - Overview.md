# User research - Overview

## 개요

- 유저 리서치 전체 과정을 개괄한다.

## 내용

유저 리서치는 목표와 가설 정의 → 방법 선택 → 대상 사용자 선정 → 참여자 모집 → 데이터 수집 → 결과 분석 → 문서화의 단계로 진행된다.

유저 리서치의 목적은 고객에게 특정 기능을 물어보는 것이 아니라, 행동·문제·맥락을 이해하는 것이다. 리서치 계획은 "어떤 결정을 내리기 위해 어떤 근거가 필요한가"를 기준으로 세운다.

## 예시

```text
목표 정의 → 방법 선택 → 대상자 모집
→ 인터뷰·관찰 → 패턴 분석 → 발견 내용 공유
```

## 요약

- 유저 리서치는 질문·분석·의사결정을 포괄하는 체계적인 과정이다.
