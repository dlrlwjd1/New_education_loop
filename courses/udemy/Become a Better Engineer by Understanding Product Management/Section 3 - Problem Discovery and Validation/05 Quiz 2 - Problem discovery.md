# Quiz 2 - Problem discovery

## 개요

- 문제 발견 주제의 이해를 확인하는 9문항 퀴즈다.

## 내용

- 상태: 퀴즈 시작 화면만 확인했다.
- 학습 정직성을 위해 문항에 답하거나 정답을 확인하지 않았다.

## 예시

- 퀴즈를 풀기 전에 문제 선정, 시장 규모, 경쟁 환경을 스스로 설명해 본다.

## 요약

- 문제 발견 주제를 복습하는 항목이며, 답안은 기록하지 않았다.
