# How Engineers can build up user empathy via User Persona

## 개요

- 사용자 페르소나(user persona)로 엔지니어가 사용자의 맥락과 목적을 공유하는 방법을 다룬다.

## 내용

사용자 페르소나는 리서치에서 반복적으로 확인된 목표, 행동, 어려움, 환경을 대표한다. 가상의 캐릭터나 고정된 설정이 아니라, 실제 사용자의 제약과 성공 기준을 담은 것이어야 한다.

기술적 결정과 사용자 스토리를 검토할 때, 엔지니어는 실제 사용자의 제약과 성공 기준을 떠올려 볼 수 있다.

## 예시

- "쓰기 편하게 만들자"고 말하는 대신, 페르소나가 제한된 시간 안에 무엇을 완료할 수 있는지를 기준으로 검토한다.

## 요약

- 근거에 기반한 페르소나는 제품 팀이 사용자에 공감하고 판단을 내리는 데 도움이 된다.
