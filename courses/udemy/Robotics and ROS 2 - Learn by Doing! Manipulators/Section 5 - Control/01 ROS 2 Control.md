## 내용
### 제어의 의미
제어는 로봇에게 명령을 보내고, 그 명령이 원하는 움직임과 일치하도록 하는 과정입니다. 이는 로봇의 모든 고급 기능을 수행하는 모듈들이 로봇을 적절하게 움직일 수 있도록 기본적인 역할을 합니다.

### 제어 시스템의 구성
제어 시스템은 입력 변수와 출력 변수를 통해 작동합니다. 현재 상태와 목표 상태 사이의 차이인 오류 변수가 생성됩니다. 오류 변수는 현재 상태와 목표 상태 사이의 거리입니다.

### ROS 2 Control 라이브러리 소개
ROS 2 Control 라이브러리는 하드웨어 리소스를 관리하는 데 사용됩니다. 이 리소스는 모터, 센서 등으로 구성될 수 있으며, 실제 물리 엔진이나 시뮬레이션 환경에서 작동할 수 있습니다.

#### 인터페이스
- **Command Interface**: 로봇의 하드웨어에 명령을 보내는 인터페이스입니다.
- **State Interface**: 하드웨어의 현재 상태를 읽는 인터페이스입니다.

#### 리소스 관리자
로봇의 실제 하드웨어 컴포넌트와 드라이버를 추상화하는 역할을 합니다. 이미 구현된 하드웨어 컴포넌트 재사용 가능합니다.

#### 제어 관리자
- **컨트롤러 로드**: 여러 개의 컨트롤러를 동시에 로드하고, 각각의 컨트롤러가 하드웨어 리소스와 연결됩니다.
- **제어 로직 구현**: 시스템 출력이 원하는 입력과 일치하도록 하는 역할을 합니다.

### ROS 2 Controllers 라이브러리
ROS 2 Controllers 라이브러리는 이미 구현된 특정 제어 로직을 포함하고 있습니다. 예를 들어, 디플레리버, 로봇 등에 대한 제어 로직이 이미 구현되어 있습니다.

## 요약
- 제어는 로봇에게 명령을 보내고, 그 명령이 원하는 움직임과 일치하도록 하는 과정입니다.
- ROS 2 Control 라이브러리는 하드웨어 리소스를 관리하며, Command Interface와 State Interface를 통해 작동합니다.
