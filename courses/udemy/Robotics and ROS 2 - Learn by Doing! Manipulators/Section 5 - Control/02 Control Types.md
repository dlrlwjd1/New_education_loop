# Control Types

## 개요

- 원본: [Udemy 강의](https://www.udemy.com/course/robotics-and-ros-2-learn-by-doing-manipulators/learn/lecture/36847148#overview)

## 내용
### 핵심 내용
1. **위치 제어 (Position Control)**
   - 위치 제어는 우리가 이 강의에서 로봇을 제어할 때 사용할 것입니다.
   - 특정 시스템이 현재 위치에서 원하는 위치로 이동하고, 필요한 경우 특정 궤도를 따르며 중간 구성 요소에 도달합니다.

2. **속도 제어 (Velocity Control)**
   - 속도 제어는 로봇의 특정 위치에 도달하기 위해 시작하여 특정 속도로 회전하도록 하는 것입니다.
   - 입력은 원하는 속도이며, 오류 변수는 원하는 속도와 현재 속도 사이의 차이입니다.

3. **힘/운동량 제어 (Force/Torque Control)**
   - 이 유형의 제어는 예를 들어 약한 물체를 잡아야 할 조작 응용 프로그램에서 유용합니다.
   - 위치 제어가 너무 많은 압력을 가해 물체를 깨뜨릴 수 있고, 적절한 압력이 없으면 물체를 떨어뜨릴 수도 있습니다.

## 요약
- **위치 제어(Position Control)** — 이 코스에서 로봇을 제어할 때 사용하는 방식. 현재 위치에서 원하는 위치로 이동하며, 필요하면 특정 궤도를 따라 중간 구성 요소에 도달한다.
- **속도 제어(Velocity Control)** — 입력이 **원하는 속도**이고, 오차 변수는 **원하는 속도와 현재 속도의 차이**다.
- **힘/토크 제어(Force/Torque Control)** — 약한 물체를 잡는 조작 응용에 유용하다. 위치 제어만 쓰면 **압력이 너무 커서 물체를 깨뜨리거나**, 압력이 부족해 **물체를 떨어뜨릴 수** 있다.
