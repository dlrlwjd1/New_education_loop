# YAML Configuration File

## 개요
- ROS 2에서 사용되는 핵심 라이브러리의 역할과 장점
- Yaml 파일을 사용하여 노드의 구성 파라미터를 쉽게 설정하고 관리하는 방법

- 원본: [Udemy 강의](https://www.udemy.com/course/robotics-and-ros-2-learn-by-doing-manipulators/learn/lecture/37535524#overview)

## 내용
### ROS 2 라이브러리의 중요성
ROS 2는 로봇 공학에서 기본적인 문제를 해결하며, 모듈화되고 유연한 방식으로 작동합니다.
- 세 개의 자유도로 간단한 조종기 로봇을 활성화할 수 있습니다.
- 모바일 로봇의 휠 움직임을 제어하고, 오도미터를 계산하여 로봇 위치를 파악하는 데 사용됩니다.

### Yaml 파일의 장점
Yaml 파일은 노드 또는 애플리케이션의 구성 파라미터를 인간 읽을 수 있는 형식으로 정의하고 설정할 수 있습니다.
- 한 번의 명령어로 모든 파라미터가 런타임에 사용 가능합니다.
- 변수, 클래스 객체, 벡터 등 다양한 데이터 타입을 쉽게 표현할 수 있습니다.

### Yaml 파일의 구조
Yaml 파일은 노드 이름으로 시작됩니다.
예: `controller_manager`
그 다음에는 ROS 파라미터 태그가 사용되어 노드의 파라미터를 설정합니다.
- 파라미터는 노드에서 선언된 이름과 해당 파라미터를 구성하려는 값으로 구성됩니다.

## 예시
```yaml
controller_manager:
  ros__parameters:
    param1: value1
    param2: value2
```
