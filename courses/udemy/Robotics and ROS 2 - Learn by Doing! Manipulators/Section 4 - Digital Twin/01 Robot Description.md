# Robot Description

## 개요
- 웹이나 모바일의 소프트웨어 개발자들은 일반적인 개발자가 아닙니다. 그들은 단순히 APC를 사용하여 코드를 작성하고 테스트하는 것이 아니라, 로봇 응용 프로그램을 개발하고 테스트하기 위해 실제 로봇에서 코드를 실행하고 평가해야 합니다.

- 원본: [Udemy 강의](https://www.udemy.com/course/robotics-and-ros-2-learn-by-doing-manipulators/learn/lecture/36847118#overview)

## 내용
### 로봇 소프트웨어 개발자에게 필요한 도구
1. **로봇 모델링**: 로봇의 구조, 구성 요소, 연결 및 상호작용을 정의합니다.
2. **물리 엔진 시뮬레이션**: 로봇과 주변 환경 간의 물리적 상호작용을 시뮬레이션합니다.
3. **센서 시뮬레이션**: 레이저 스캐너, 소나라 카메라 등 다양한 센서를 시뮬레이션합니다.

### 로봇 개발과 테스트의 중요성
- 실제 로봇에서 코드를 실행하고 평가해야 합니다.
- 시간과 경제적 측면에서 실제 로봇에 접근해야 합니다.
- 이로 인해 로봇 분야의 소프트웨어 개발자와 취미인들의 수는 모바일이나 웹 분야보다 적습니다.

## 예시
원문에는 코드/명령/적용 예시가 없습니다. 강의에서 별도의 코드 예시는 다루지 않습니다.

## 요약
- 로봇 소프트웨어 개발자에게 필요한 도구: 로봇 모델링, 물리 엔진 시뮬레이션, 센서 시뮬레이션
- 실제 로봇에 접근해야 하는 이유: 시간과 경제적 측면에서
- 로봇 분야의 소프트웨어 개발자와 취미인들의 수가 적은 이유: 모바일이나 웹 분야보다 자원이 필요합니다.
