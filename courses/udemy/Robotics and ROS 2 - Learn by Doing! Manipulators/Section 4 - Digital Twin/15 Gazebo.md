## 내용
### 1. 물리 엔진의 개념
물리 시뮬레이터는 특정 물리 현상(중력, 마찰력, 가속도 등)을 모방하는 소프트웨어입니다.

### 2. Gazebo의 사용 이유와 장점
Gazebo는 로봇 분야에서 가장 많이 사용되며, ROS 2와 잘 통합됩니다. 다양한 기능이 있어 로봇 시뮬레이션과 디버깅에 유용합니다.

### 3. 실제 로봇과 시뮬레이션 로봇의 차이점
실제 로봇은 물리적인 센서와 모터를 통해 메시지를 발행하지만, 시뮬레이션 로봇은 Gazebo가 해당 메시지를 대신 발행하여 실제 로봇과 동일한 데이터와 인터페이스를 제공합니다.

### 4. Gazebo를 이용한 로봇 시뮬레이션 방법
1. **실제 로봇의 센서와 모터 설정**: 실제 로봇의 센서(예: 카메라)와 모터가 메시지를 발행하는 ROS 2 토픽을 설정합니다.
2. **Gazebo에서의 시뮬레이션**: Gazebo를 사용하여 로봇의 동작과 센서 데이터를 시뮬레이션합니다.
3. **노드 통합**: 실제 로봇과 동일한 인터페이스를 유지하면서, Gazebo에서 발행된 메시지를 처리하는 노드를 작성합니다.

## 예시
Gazebo에서의 로봇 시뮬레이션을 위한 코드 예시는 강의에서 제공되지 않았습니다.
