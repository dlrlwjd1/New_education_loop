# Parameters

## 개요
- ROS 2의 다양한 소프트웨어에서 사용되는 파라미터에 대해 이해합니다.
- MoveIt!이라는 로봇 매니퓰레이터를 위한 도구에 대한 파라미터 설정 방법을 배웁니다.

- 원본: [Udemy 강의](https://www.udemy.com/course/robotics-and-ros-2-learn-by-doing-manipulators/learn/lecture/37484656#overview)

## 내용
### MoveIt! 소개
MoveIt!은 로봇 매니퓰레이터의 주요 문제, 즉 궤도 계획과 픽업 및 놓기 애플리케이션 개발을 해결하는 오픈소스 소프트웨어입니다.

### MoveIt!의 일반적 적용
MoveIt!은 다양한 회사에서 로봇 팔의 개발에 사용되며, 모든 로봇이 공유하는 일반적인 문제를 대상으로 합니다. 이는 우리의 작은 로봇 팔에도 적용됩니다.

### 파라미터 설정의 유연성
MoveIt!은 일반적 방식으로 구현되어 있어 핵심 논리가 동일하며 모든 사용 중인 로봇 사이에서 공유됩니다. 그러나 각 로봇에 따라 기능을 구성할 수 있습니다.

### 파라미터의 종류
MoveIt!은 다양한 파라미터를 제공하여 기능을 구성할 수 있습니다. 노드 파라미터는 특정 소프트웨어 또는 애플리케이션의 동작을 사용자 정의하는 설정으로, 해당 애플리케이션이 이러한 파라미터를 해석하고 사용하여 동작을 구성합니다.

## 예시
- 강의에서 별도의 코드 예시는 다루지 않는다.

## 요약
- MoveIt!은 로봇 매니퓰레이터의 주요 문제를 해결하는 오픈소스 소프트웨어입니다.
- 일반적인 문제에 대상으로 사용되며, 모든 로봇 사이에서 공유됩니다.
- 파라미터 설정을 통해 기능을 유연하게 구성할 수 있습니다.
- 노드 파라미터는 특정 애플리케이션의 동작을 사용자 정의하는 데 사용됩니다.
