# Forward Kinematics

## 개요
- 로봇의 회전 관절과 그들의 각도를 알고 있을 때, 로봇 패드그립퍼의 위치를 3차원 공간에서 계산하는 방법 (Forward Kinematics)
- 패드그립퍼가 현재 위치로 옮겨졌을 때, 각각의 패드그립퍼의 각도를 계산하는 방법 (Inverse Kinematics)

- 원본: [Udemy 강의](https://www.udemy.com/course/robotics-and-ros-2-learn-by-doing-manipulators/learn/lecture/37574316#overview)

## 내용
### Forward Kinematics
1. 로봇의 구조 이해: 3개의 자유도(자유도)와 3개의 회전 관절이 있는 로봇을 가정합니다.
2. 참조 프레임 정의: 고정된 워드 프레임(W)과 이동 가능한 패드그립퍼에 연결된 링크 프레임(R) 두 개를 정의합니다.
3. 전방 운동학 문제 해결: 각 관절의 각도가 변경될 때마다 패드그립퍼와 그로 인해 워드 프레임과 패드그립퍼 프레임 사이의 변환 행렬을 계산하여 위치와 방향을 파악합니다.

### Inverse Kinematics
1. 문제 이해: 패드그립퍼가 특정 위치에 도달했을 때, 각각의 관절의 각도를 계산하는 방법입니다.
2. 역방향 운동학 문제 해결: 패드그립퍼의 위치와 방향이 주어졌을 때, 각각의 관절의 각도를 계산하여 해당 위치로 패드그립퍼를 이동시킵니다.

## 요약
- Forward Kinematics: 로봇의 각도와 위치를 통해 패드그립퍼의 위치를 계산하는 방법
- Inverse Kinematics: 패드그립퍼의 위치와 방향을 통해 각각의 관절의 각도를 계산하는 방법
