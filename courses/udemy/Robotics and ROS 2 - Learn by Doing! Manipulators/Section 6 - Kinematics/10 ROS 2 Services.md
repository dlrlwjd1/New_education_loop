## 내용
### 서비스의 의미
서비스는 노드 간에 다른 발행자/구독자 프로토콜을 사용하는 대신, 요청-응답 프로토콜을 사용하여 기능을 제공하는 노드입니다.

### 서비스의 구조
서비스는 클라이언트가 서버에게 요청하고, 서버는 해당 요청에 대한 응답을 반환합니다. 이 과정에서 클라이언트는 요청 메시지를 보내고, 서버는 응답 메시지를 통해 결과를 전달합니다.

### 서비스의 예시
예를 들어, 카메라 이미지에서 얼굴을 인식하고 로봇이 감지된 얼굴을 따라가는 애플리케이션을 개발한다고 가정해봅시다. 이 애플리케이션에는 얼굴 인식 기능이 포함되어 있으며, 이 기능은 카메라 프레임을 입력으로 받아 이미지 내의 얼굴 위치를 출력합니다.

새로운 기능 중 하나는 인식된 사람에게 가까워질 때 로봇이 말하는 기능입니다. 이 새로운 기능을 구현하려면 이미 구현한 얼굴 인식 기능을 재사용해야 합니다. 그러나 코드를 복사 붙여넣기는 일반적인 소프트웨어 개발에서 좋지 않습니다. 만약 알고리즘을 변경하거나 더 효율적인 라이브러리를 사용하려면, 두 가지 위치에서 동일한 변경 사항을 적용하고 모두가 올바르게 작동하도록 해야 합니다.

서비스를 사용하면 같은 기능을 여러 노드에 제공할 수 있습니다. 예를 들어, 얼굴 인식 기능은 한 개의 노드에서만 구현되고 유지 관리됩니다. 이렇게 하면 모든 노드에서 동일한 기능이 동일하게 작동하도록 보장할 수 있습니다.

### 서비스의 사용 방법
서비스를 사용하려면 클라이언트가 서버에게 요청하고, 서버는 해당 요청에 대한 응답을 반환합니다. 클라이언트는 요청 메시지를 보내고, 서버는 응답 메시지를 통해 결과를 전달합니다.

## 예시
```python
# 서비스 서버 코드 예시
def face_recognition_service(request):
    frame = request.frame  # 카메라 이미지
    face_position = recognize_face(frame)  # 얼굴 인식 함수 호출
    return FaceRecognitionResponse(face_position)

# 클라이언트 코드 예시
response = client.call_service('face_recognition', FaceRecognitionRequest(camera_image))
robot_move(response.face_position)
```
