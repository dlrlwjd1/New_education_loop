# TF2 Library

## 개요
- 변환 행렬의 중요성
- ROS 2에서 TF2 라이브러리의 활용
- URDF 모델과 TF2의 관계

- 원본: [Udemy 강의](https://www.udemy.com/course/robotics-and-ros-2-learn-by-doing-manipulators/learn/lecture/37574508#overview)

## 내용
### 변환 행렬의 의미
변환 행렬은 복잡한 수학적 문제를 쉽게, 직관적으로 해결하는 데 매우 유용하고 강력합니다. 로봇 소프트웨어 개발자가 이러한 문제들을 해결하는 데 있어 중요한 도구입니다.

### TF2 라이브러리의 중요성
TF2는 ROS 2에서 참조 프레임을 변환하여 조합할 수 있게 하는 라이브러리입니다. 로봇 시스템에서 모든 부분이 서로 연결된 트리 구조로 표현되며, 각 링크와 관절은 URDF 모델에 따라 자동으로 계산됩니다.

### URDF 모델과 TF2의 연계
URDF 모델을 통해 각 링크는 새로운 참조 프레임을 정의하고, 각 관절은 이전 링크에 대한 회전과 변환을 정의합니다. 따라서 두 개의 연결된 링크 사이의 변환 행렬을 정의하는 것입니다.

### TF2 라이브러리의 활용
TF2 라이브러리는 로봇 모델의 참조 프레임을 관리하고, 이를 통해 로봇의 구조를 시각화할 수 있습니다. 특히, `robot_state_publisher` 노드는 URDF 모델을 읽고, 링크와 변환 행렬을 TF 토픽에 게시합니다.

## 예시
TF2 라이브러리를 사용하여 로봇의 참조 프레임을 관리하는 방법은 다음과 같습니다:
1. `robot_state_publisher` 노드를 실행하여 URDF 모델을 읽고, 링크와 변환 행렬을 게시합니다.
2. 이를 통해 로봇의 구조를 시각화할 수 있습니다.

## 요약
- 변환 행렬은 복잡한 수학적 문제를 쉽게 해결하는 데 유용합니다.
- ROS 2에서 TF2 라이브러리는 참조 프레임을 변환하여 조합할 수 있게 합니다.
- URDF 모델과 TF2는 로봇의 구조를 정의하고 시각화하는데 중요한 역할을 합니다.
