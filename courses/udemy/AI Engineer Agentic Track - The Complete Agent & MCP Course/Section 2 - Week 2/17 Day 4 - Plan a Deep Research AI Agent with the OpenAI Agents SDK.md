# Day 4 - Plan a Deep Research AI Agent with the OpenAI Agents SDK

## 개요
- 질문을 검색 계획·검색·보고서·전달 단계로 나누는 Deep Research 프로젝트를 설계한다.
- 출처: [원본 강의](https://www.udemy.com/course/the-complete-agentic-ai-engineering-course/learn/lecture/49820791#overview)의 실제 자막 확인·정리 (2026-09-07).

## 내용
### 코드가 단계 순서를 제어
이미 필요한 단계가 정해져 있으므로 여러 `Runner.run`을 코드로 연결한다. 모델은 어떤 검색을 할지와 내용을 어떻게 종합할지를 판단하지만, 전체 단계의 연결은 프로그램이 담당한다.

### 네 에이전트
Search는 검색어에 대한 웹 조사와 요약, Planner는 사용자 질문을 여러 검색 항목으로 분해, Writer는 질문과 조사 결과로 보고서 작성, Emailer는 보고서의 전달을 맡는다. 각 역할의 호출을 작은 비동기 함수로 감싼다.

### 실습 설정
모델명, 이메일 사용 여부, 검색 개수를 상수로 둔다. 처음에는 다섯 검색을 계획한다. 예제 질문은 현재 인기 있는 에이전트 프레임워크에 관한 조사다. 검색 도구와 구조화 출력을 사용하며, 산업별 조사 도구로 확장할 수 있다.

### 대안 실험
이후 과제로 관리 에이전트가 도구를 선택하는 방식으로 다시 구현할 수 있다. 강사는 코드 중심의 예측 가능한 흐름과 모델 중심의 유연한 조사 사이의 차이를 직접 경험하도록 권한다.

## 예시
```text
사용자 질문 → Planner → 검색 항목들
                         ↓ Search를 항목별 실행
             Writer ← 검색 요약 모음
               ↓ 보고서
             Emailer
```

## 요약
- 검색할 내용과 전체 실행 순서의 결정 주체를 구분한다.
- 작은 역할과 함수로 조사 흐름을 구성한다.
- 모델·검색 수·전달 수단을 실험 설정으로 분리한다.
