# Day 4 - Build a Web Search Agent with OpenAI Agents SDK Hosted Tools

## 개요
- 호스팅된 웹 검색 도구를 Search Agent에 연결하고 결과와 추적을 확인한다.
- 출처: [원본 강의](https://www.udemy.com/course/the-complete-agentic-ai-engineering-course/learn/lecture/49820797#overview)의 실제 자막 확인·정리 (2026-09-07).

## 내용
### 호스팅 도구의 의미
이번 웹 검색은 로컬 Python 함수가 아니라 제공자의 관리 인프라에서 수행된다. 직접 검색 API와 래퍼를 작성하는 시간을 줄일 수 있지만 제공자 의존성과 도구 호출 비용을 고려해야 한다. 영상의 가격 예시는 촬영 당시 기준이다.

### 검색 에이전트 구성
Agent의 도구 목록에 `WebSearchTool()`을 넣는다. 검색어에 대해 웹을 조회하고 2~3문단, 300단어 미만으로 핵심만 요약하도록 지시한다. 실제 검색을 사용하도록 도구 선택 설정도 적용한다.

### 시연과 관찰
인기 에이전트 프레임워크를 검색해 요약을 받는다. 강사는 일부 결과가 예전 인지도나 부정확한 분류를 반영할 수 있음을 짚는다. 검색을 했다는 사실만으로 조사 결과가 정확해지는 것은 아니다.

### 추적과 대체 가능성
trace에서 검색이 Responses API 호출 안의 내장 기능으로 표시되는 것을 확인한다. 이 예제의 호스팅 도구를 타사 모델에 그대로 붙이는 것으로 가정하지 말고, 다른 제공자를 쓸 때는 별도 검색 함수를 연결하는 방식으로 대체한다.

## 예시
```text
검색어 → Search Agent + WebSearchTool
       → 검색 결과의 짧은 요약
       → trace에서 검색 호출과 근거 확인
```

후속 실습에서는 여러 검색 요약을 모아 하나의 보고서로 합친다.

## 요약
- 호스팅 도구는 로컬 함수 도구와 실행 위치·의존성이 다르다.
- 검색 요약의 길이를 제한해 다음 단계의 입력을 관리한다.
- 검색 수행 여부와 정보 정확성을 따로 확인한다.
