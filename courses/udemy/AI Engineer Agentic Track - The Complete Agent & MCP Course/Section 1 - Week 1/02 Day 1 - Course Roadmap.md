# Day 1 - Course Roadmap: 6 Weeks, 8 Projects in Agentic AI Engineering

## 개요
- 6주 동안 에이전트 이론·프레임워크·여덟 프로젝트를 연결하는 학습 경로를 소개한다.
- 출처: [원본 강의](https://www.udemy.com/course/the-complete-agentic-ai-engineering-course/learn/lecture/49770319#overview)의 실제 자막 확인·정리 (2026-09-07).

## 내용
### 주차별 구성
- Week 1: 직접 LLM 호출과 도구 루프를 배우고 Career Digital Twin을 배포한다.
- Week 2: OpenAI Agents SDK로 영업 에이전트와 Deep Research를 만든다.
- Week 3: CrewAI로 Stock Picker와 개발 팀을 구성한다.
- Week 4: LangChain·LangGraph의 추상화 계층을 배우고 Sidekick을 만든다.
- Week 5: Google ADK·Strands·Pydantic AI·Microsoft Agent Framework·Agno·Mastra를 비교하고 Agent Loop로 연결한다.
- Week 6: MCP를 깊이 다루고 가상 Trading Floor로 마무리한다.

### 학습 범위
이 과정은 코드를 사용해 에이전트를 만드는 과정이다. 이미 만들어진 코딩 에이전트로 코드를 생성하는 별도 AI Coder 과정과 구분한다. 프레임워크·이론을 프로젝트의 구체적인 결과로 이어 쓰며, MCP도 마지막 주 이전부터 조금씩 사용한다.

### 선행 지식과 확장
Python·LLM 기초가 약하면 제공 가이드와 기초 자료를 병행한다. 경험자는 예제 실행에서 멈추지 않고 모델·도구·과제를 바꿔 더 큰 문제로 확장하는 방향을 제시한다.

## 예시
```text
기초 루프 → SDK → CrewAI → LangChain/LangGraph
→ 여섯 프레임워크 비교·통합 → MCP 캡스톤
```

## 요약
- 이론·프레임워크·업무 프로젝트를 함께 학습한다.
- 현재 Week 5는 여섯 프레임워크와 Agent Loop로 구성된다.
