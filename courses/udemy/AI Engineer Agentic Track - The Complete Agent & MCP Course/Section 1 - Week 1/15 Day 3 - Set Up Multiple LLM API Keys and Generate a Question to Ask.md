# Day 3 - Set Up Multiple LLM API Keys and Generate a Question to Ask

## 개요
- 여러 제공자의 키를 로딩하고 공통 비교에 쓸 질문을 LLM이 생성하게 한다.
- 출처: [원본 강의](https://www.udemy.com/course/the-complete-agentic-ai-engineering-course/learn/lecture/49771145#overview)의 실제 자막 확인·정리 (2026-09-07).

## 내용
### Day 3의 Lab 2
`1_foundations`의 두 번째 실습을 사용한다. Day 2가 이론 강의였으므로 Day 3이 Lab 2다. 첫 목표는 반복적인 API 호출에 익숙해지는 것, 두 번째 목표는 여러 호출을 연결해 설계 패턴을 경험하는 것이다.

### 필요한 키만 설정
사용하려는 제공자의 키만 `.env`에 추가하고 저장한 뒤 다시 로딩한다. 강의는 OpenAI·Anthropic·Google·DeepSeek·OpenRouter 등의 키 존재 여부를 확인한다. 모든 키를 갖출 필요는 없으며, 누락 오류는 실제 사용할 제공자 기준으로 판단한다.

### 모델이 비교 질문을 만들게 하기
여덟 모델에 보낼 공통 질문도 사람이 직접 고르지 않고 LLM으로 생성한다. 프롬프트는 짧은 답으로 지적 통찰을 평가할 수 있는 도전적인 질문을 요구한다. 반복해서 수학 퍼즐이 나오는 것을 피하려고 수학 퍼즐 제외 조건을 넣고, 설명 없이 질문만 출력하도록 제한한다.

### 실제 생성 결과
시연에서는 과도하게 최적화하면 악덕이 될 수 있는 인간의 미덕과 그 이유를 두 문장 이내로 답하라는 질문이 나온다. 결과는 `response.choices[0].message.content`에 저장하고 노트북의 Markdown 표시로 확인한다. 다음 강의에서는 같은 질문을 여러 모델에 전달한다.

## 예시
```text
질문 생성 조건
- 지적 통찰이 필요한 도전적인 질문
- 수학 퍼즐 제외
- 짧게 답할 수 있을 것
- 질문만 출력하고 설명은 생략

생성된 공통 질문 → 여러 모델에 동일하게 전달
```

## 요약
- 키 추가 후에는 파일 저장과 재로딩이 필요하다.
- 질문 생성 역시 전체 비교 워크플로의 첫 LLM 호출이다.
- 같은 질문과 응답 길이 조건을 사용해 모델들을 비교한다.
