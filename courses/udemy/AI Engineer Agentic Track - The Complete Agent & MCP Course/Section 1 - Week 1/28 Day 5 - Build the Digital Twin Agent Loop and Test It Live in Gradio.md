# Day 5 - Build the Digital Twin Agent Loop and Test It Live in Gradio

## 개요
- 두 도구를 디지털 트윈 루프에 연결하고 정상·미응답·연락 요청을 시험한다.
- 출처: [원본 강의](https://www.udemy.com/course/the-complete-agentic-ai-engineering-course/learn/lecture/49771331#overview)의 실제 자막 확인·정리 (2026-09-07).

## 내용
### 프로필과 도구 사용 지시
자신의 PDF와 소개문을 읽고 시스템 프롬프트를 구성한다. 무관한 주제를 금지하는 표현을 전문적인 주제로 대화를 돌리라는 지시로 바꾼다. 모르는 답은 미응답 질문 도구로 기록하도록 시스템 프롬프트에도 명시한다.

### chat과 도구 처리 연결
시스템 메시지·이력·새 요청을 묶어 도구 목록과 함께 모델에 전달한다. 도구 요청이 있는 동안 `handle_tool_calls`를 호출한다. 모델 메시지는 `append`, 여러 도구 결과는 `extend`로 이력에 추가하고 다시 호출한다. 도구 요청이 끝나면 최종 답변을 반환한다.

### 실제 시험
기술을 묻는 질문에는 프로필 기반 답을 받는다. 좋아하는 음악가를 물으면 알 수 없는 질문이라는 알림이 전송되고 전문적인 배경으로 대화를 돌린다. 연락하고 싶다는 말과 이메일을 입력하면 이름 미제공 상태와 연락 의도를 포함한 알림이 온다. UI 답변과 실제 알림을 함께 확인한다.

## 예시
```text
시험 1: 어떤 기술이 있나요? → 프로필 기반 응답
시험 2: 좋아하는 음악가는? → 미응답 질문 알림 + 범위 안내
시험 3: 연락하고 싶어요. 이메일은 ... → 연락처 기록 알림
```

## 요약
- 도구 정의만큼 시스템 지시와 실제 시험이 중요하다.
- 한 루프에서 여러 도구 결과를 메시지 리스트에 추가한다.
- 응답 문구뿐 아니라 알림 도착으로 실행 결과를 확인한다.
