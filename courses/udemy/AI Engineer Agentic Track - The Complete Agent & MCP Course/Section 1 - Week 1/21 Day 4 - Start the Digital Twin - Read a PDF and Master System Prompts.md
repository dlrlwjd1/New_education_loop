# Day 4 - Start the Digital Twin: Read a PDF and Master System Prompts

## 개요
- Career Digital Twin의 프로필 자료를 읽고 시스템 프롬프트·대화 이력·기억을 실험한다.
- 출처: [원본 강의](https://www.udemy.com/course/the-complete-agentic-ai-engineering-course/learn/lecture/49771193#overview)의 실제 자막 확인·정리 (2026-09-07).

## 내용
### 개인 자료 준비
`1_foundations`의 Lab 3에서 `twin/linkedin.pdf`와 `twin/summary.txt`를 준비한다. LinkedIn PDF를 내보낼 수 없으면 이력서 PDF나 자신에 관한 자료를 써도 된다. 나중에 Linux에 배포하므로 파일명의 소문자 표기를 맞춘다. 강사의 소개를 자신의 정보로 바꾼다.

### PDF와 텍스트 읽기
`pypdf.PdfReader`로 PDF를 열어 페이지별 `extract_text()` 결과를 모으고, 소개 텍스트도 읽는다. 추출 결과가 정돈된 표처럼 나오지 않아도 LLM 입력 자료로 활용한다. 이 두 자료는 이후 자신을 대신해 경력 질문에 답하는 에이전트의 배경 정보가 된다.

### 시스템 프롬프트와 대화 이력
시스템 프롬프트는 역할·말투·배경을 제공한다. 사용자와 어시스턴트 메시지를 차례로 넣은 것은 대화 이력이다. 같은 자기소개를 보내도 일반적인 조력자와 재치 있고 빈정거리는 조력자는 다르게 응답한다.

### 기억의 실험
이름을 알려준 뒤 새 호출에 이름 질문만 보내면 이름을 알지 못한다. 앞선 자기소개와 답변을 메시지에 포함하면 이름을 답한다. 이 실습의 API 호출은 주어진 입력을 기준으로 처리하며, 기억처럼 보이는 동작은 대화 이력을 다시 전달해서 만든다. 별도 저장 정보도 입력에 포함되어야 모델이 사용할 수 있다.

## 예시
```text
호출 A: 시스템 + “내 이름은 Ed야”
호출 B: 시스템 + “내 이름이 뭐야?” → 앞선 정보 없음
호출 C: 시스템 + 자기소개 + 이전 답변 + 이름 질문 → 이력 활용
```

프로필 PDF와 요약문은 다음 단계에서 시스템 프롬프트에 포함한다.

## 요약
- 프로필 자료와 파일명은 배포 환경까지 고려해 준비한다.
- 시스템 프롬프트와 대화 이력의 역할을 구분한다.
- 기억 기능을 이해하려면 실제 호출에 어떤 정보가 들어가는지 확인한다.
