# Day 1 - Your First OpenAI API Call and Chaining LLM Calls in Python

## 개요
- Chat Completions 호출을 실행하고 질문 생성 → 답변 → 평가로 LLM 호출을 연결한다.
- 출처: [원본 강의](https://www.udemy.com/course/the-complete-agentic-ai-engineering-course/learn/lecture/49770895#overview)의 실제 자막 확인·정리 (2026-09-07).

## 내용
### 메시지와 응답 구조
메시지는 `role`과 `content`를 가진 딕셔너리들의 리스트다. 사용자 요청을 `role="user"`로 넣고 `client.chat.completions.create(model=..., messages=...)`를 호출한다. 응답 텍스트는 `response.choices[0].message.content`에서 읽는다. 첫 요청은 재미있는 사실을 알려 달라는 내용이며, 꿀에 관한 답변을 받는다.

### 질문 생성, 답변, 평가의 연결
다음으로 어려운 문제 하나를 만들도록 요청한다. 생성된 문제를 새 메시지의 내용으로 넣어 다른 호출에서 풀게 하고, 문제와 답변을 함께 담은 프롬프트로 정답 여부를 평가한다. 영상에서는 시계 바늘이 90도를 이루는 횟수 문제가 나오며, 평가 모델이 일반적인 시침·분침이라는 전제를 짚는다. 이 결과는 실습 출력이며 모델 평가 자체가 정답의 보증은 아니다.

### 프롬프트 체이닝과 연습 과제
핵심은 이전 호출의 출력을 다음 호출의 입력에 전달하는 것이다. 강사는 이 방식을 에이전틱 워크플로의 첫 단계로 소개한다. 과제는 사업 분야를 하나 선택하게 하고, 그 분야의 불편을 찾은 뒤, 분야와 불편을 바탕으로 에이전틱 AI 해결책을 제안하게 하는 세 번의 호출이다.

## 예시
```text
LLM 1: 해결할 사업 분야 선택
  ↓ 분야
LLM 2: 해당 분야의 구체적인 불편 도출
  ↓ 분야 + 불편
LLM 3: 에이전틱 AI 해결책 제안
```

각 단계에서 새 메시지를 구성하면서 이전 결과를 `content`에 포함한다.

## 요약
- 메시지는 딕셔너리 리스트이고 실제 답변은 응답 객체에서 꺼낸다.
- 체이닝은 호출 간 데이터 전달로 큰 작업을 나누는 방식이다.
- 강의 과제도 분야 → 문제 → 해결책이라는 동일한 구조다.
