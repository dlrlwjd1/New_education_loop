# Day 5 - Handle Multiple Tool Calls in Python with the globals Trick

## 개요
- 도구 이름을 실제 Python 함수로 매핑하는 방식과 globals() 데모의 한계를 살펴본다.
- 출처: [원본 강의](https://www.udemy.com/course/the-complete-agentic-ai-engineering-course/learn/lecture/49771329#overview)의 실제 자막 확인·정리 (2026-09-07).

## 내용
### 수동 분기 버전
`handle_tool_calls`가 요청 목록을 순회하며 함수 이름과 JSON 인자를 꺼낸다. 이름이 연락처 기록이면 해당 함수를, 미응답 질문 기록이면 다른 함수를 호출한다. 실행 결과를 요청 ID와 함께 모아 반환한다.

### globals()를 이용한 조회
문자열 이름으로 전역 이름 공간에서 함수를 찾으면 긴 조건문을 줄일 수 있다. 선택한 함수를 인자 딕셔너리의 키워드 인자로 호출한다. 강사는 미응답 질문 함수 이름을 조회해 실행하고 휴대전화 알림이 오는 것을 확인한다.

### 배포 버전에서의 제한
이 데모는 모델이 허용된 도구 이름만 반환한다고 가정한다. 전역 이름 공간에 노출된 다른 객체까지 찾을 수 있으므로 배포에 적절하지 않다고 강사도 지적한다. 후속 모듈화 강의에서는 허용된 함수만 담은 `tool_map`으로 바꾼다. `globals()`는 모든 내장 함수를 자동으로 포함하는 목록이 아니라 현재 모듈의 전역 이름 공간이라는 점을 구분한다.

## 예시
```text
모델의 함수 이름 문자열
→ 수동 if 분기 또는 이름–함수 매핑에서 조회
→ JSON 인자를 키워드 인자로 전달
→ 실행 결과 + 요청 ID를 반환
```

이 강의의 `globals()`는 동적 조회 설명용이고, 배포 예시는 명시적인 도구 매핑을 사용한다.

## 요약
- 모델의 문자열과 Python 함수 객체 사이에는 매핑이 필요하다.
- 여러 요청의 결과를 각각 원래 요청에 연결한다.
- 동적 조회의 편의성과 호출 가능 범위를 함께 고려한다.
