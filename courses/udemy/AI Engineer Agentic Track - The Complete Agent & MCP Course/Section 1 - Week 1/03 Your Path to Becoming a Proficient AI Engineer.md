# Your Path to Becoming a Proficient AI Engineer

## 개요
- 과정의 학습 경로와 실습 중심 접근을 안내한다.

## 내용
### 학습 방식
강의는 에이전트 개념을 읽는 데 그치지 않고 코드를 실행하고 프로젝트를 변형하며 익히는 방식을 강조한다. Python과 LLM 경험이 있으면 유리하지만, 저장소의 가이드와 기초 실습을 활용해 부족한 부분을 보완할 수 있다.

## 예시
```text
강의 시청 → 제공 코드 실행 → 입력·모델·도구 변경
→ 실패 원인 조사 → 프로젝트에 다시 적용
```

## 요약
- 숙련도는 프레임워크 암기보다 반복적인 구축과 디버깅에서 쌓인다.
- 필요한 기초 지식은 가이드와 자기주도 실습으로 병행한다.
