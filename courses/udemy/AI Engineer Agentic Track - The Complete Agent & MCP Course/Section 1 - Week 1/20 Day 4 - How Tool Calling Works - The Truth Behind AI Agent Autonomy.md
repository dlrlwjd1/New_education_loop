# Day 4 - How Tool Calling Works: The Truth Behind AI Agent Autonomy

## 개요
- 도구 호출과 자율성이 프롬프트, 모델 출력 해석, 실행 코드로 구성됨을 시연한다.
- 출처: [원본 강의](https://www.udemy.com/course/the-complete-agentic-ai-engineering-course/learn/lecture/49771189#overview)의 실제 자막 확인·정리 (2026-09-07).

## 내용
### 실제 도구 실행 주체
모델이 외부 컴퓨터에 직접 접속해 함수를 실행하는 것이 아니다. 애플리케이션이 사용 가능한 기능을 설명하고, 모델은 원하는 기능과 인자를 출력한다. 애플리케이션 코드가 해당 함수를 호출한 뒤 결과를 다시 모델에 전달한다. Tool calling과 function calling이라는 표현을 함께 소개한다.

### 항공권 가격 사례
항공사 상담원 역할을 주고 가격을 조회하려면 `get_ticket_price`와 도시명을 출력하도록 지시한다. 사용자가 파리에 가는 비용을 묻자 모델이 파리 가격 조회 형식으로 응답한다. 실제 도구를 등록하지 않은 일반 프롬프트만으로도 도구 선택의 기본 아이디어를 시연한다.

### LLM이 기여하는 부분
사용자의 자유로운 표현에서 비용과 가격의 의미를 연결하고 도시를 파악해 구체적인 동작으로 바꾸는 것이 모델의 역할이다. 실제 가격 조회 기능은 별도 코드가 담당한다.

### 방향 선택과 루프
방을 탐색하며 북·동·남·서 중 하나를 선택하게 하고 결과를 알려준 뒤 다음 행동을 요청한다. 프로그램이 이 출력에 따라 움직이고 피드백을 반복하면 자율적인 행동처럼 보인다. 루프와 도구 실행은 계속 애플리케이션의 책임이다.

## 예시
```text
사용자: 파리까지 가는 데 얼마인가요?
모델: 파리 가격 조회 요청
코드: 가격 조회 함수 실행
코드 → 모델: 조회 결과 전달
모델: 결과에 근거해 사용자에게 답변
```

## 요약
- 모델은 도구 요청을 생성하고 애플리케이션이 실행한다.
- 자연어의 의도를 구체적인 기능과 인자로 바꾸는 데 모델을 쓴다.
- 에이전트 루프는 판단·실행·피드백을 코드로 반복하는 구조다.
