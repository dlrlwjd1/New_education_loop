# Day 5 - Add Tools to Your Digital Twin Agent with Pushover Notifications

## 개요
- Pushover 알림을 연결하고 연락처 기록·미응답 질문 기록 도구를 만든다.
- 출처: [원본 강의](https://www.udemy.com/course/the-complete-agentic-ai-engineering-course/learn/lecture/49771327#overview)의 실제 자막 확인·정리 (2026-09-07).

## 내용
### 알림 설정과 직접 시험
Pushover의 사용자 키와 애플리케이션 토큰을 각각 `PUSHOVER_USER`, `PUSHOVER_TOKEN`으로 `.env`에 저장한다. 휴대전화 앱을 계정에 연결한 뒤 메시지 전송 함수를 직접 호출해 알림이 도착하는지 확인한다. 서비스 이용 조건은 영상 촬영 시점의 설명이며, 원하지 않으면 전날처럼 파일 기록으로 대체할 수 있다.

### 두 도구의 역할
연락처 기록 도구는 이메일과 선택적인 이름·메모를 받는다. 미응답 질문 기록 도구는 디지털 트윈이 답하지 못한 질문을 알린다. 후자는 실제 방문자가 궁금해하는데 프로필 자료에는 없는 정보를 발견해 컨텍스트를 개선하는 피드백 통로다.

### 도구 설명과 인자
두 함수에 맞는 JSON 스키마를 작성한다. 연락처 도구는 이메일만 필수이며 이름과 메모는 선택이다. 미응답 도구는 질문 문자열을 받는다. 일부 모델이 미응답 도구를 잘 쓰지 않아 설명에 사용 조건을 더 명확히 적고 시스템 프롬프트도 조정한다.

### 함수와 설명의 연결
스키마 두 개를 도구 목록으로 묶어 모델에 전달할 준비를 한다. 다음 단계에서는 모델이 어떤 함수를 선택했는지 해석하고 실제로 실행한다. 프레임워크가 자동 생성하는 스키마를 이해하기 위해 이번에는 직접 작성한다.

## 예시
```text
연락 요청 + 이메일 → 연락처 기록 도구 → 휴대전화 알림
모르는 질문 → 미응답 질문 기록 도구 → 알림 확인 → 프로필 정보 보완
```

실습에서는 먼저 알림 함수 자체를 시험하고 그 뒤 에이전트 도구로 연결한다.

## 요약
- Pushover에는 사용자 키와 앱 토큰 두 값이 필요하다.
- 미응답 질문은 컨텍스트 개선의 근거가 된다.
- 도구 설명은 사용 조건과 필수·선택 인자를 정확하게 담는다.
