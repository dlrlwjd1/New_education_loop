# Day 5 - Context Engineering for AI Agents: Memory, Tools and RAG

## 개요
- 컨텍스트 엔지니어링의 구성 요소와 평가를 통한 개선 방법을 소개한다.
- 출처: [원본 강의](https://www.udemy.com/course/the-complete-agentic-ai-engineering-course/learn/lecture/49771207#overview)의 실제 자막 확인·정리 (2026-09-07).

## 내용
### 프롬프트보다 넓은 입력 설계
컨텍스트 엔지니어링(context engineering)은 지시문뿐 아니라 모델이 사용할 정보 전체를 어떻게 구성할지 설계하는 일이다. 강사는 Phil Schmid의 도식을 바탕으로 시스템 지시, 사용자 요청, 도구 설명, 구조화 출력 형식, 검색 자료, 단기·장기 기억을 살펴본다.

### 도구와 구조화 출력
도구 설명은 모델이 선택 가능한 행동을 알려준다. 구조화 출력의 스키마는 반환 형식을 제한하고 코드가 읽을 수 있게 한다. 둘 모두 모델에 전달할 정보 설계의 일부다.

### RAG와 에이전틱 RAG
RAG는 관련 자료를 검색해 입력에 넣는 방식으로 설명한다. 에이전틱 RAG에서는 검색 도구를 제공해 에이전트가 필요한 자료를 찾아오게 한다. 검색을 한 번 미리 수행하는 방식과, 루프 안에서 필요에 따라 수행하는 방식을 비교한다.

### 기억의 의미와 평가
단기 기억은 현재 대화 이력과 상태, 장기 기억은 이전 대화 등에서 저장해 다시 가져오는 관련 정보로 설명한다. 장기 기억은 도구나 검색으로 구현할 수 있어 범주들이 겹친다. 도식을 고정 공식으로 보지 말고 테스트셋·평가 지표를 정한 뒤 지시문, 검색, 기억, 도구 구성을 바꿔 실험하라고 강조한다.

## 예시
```text
한 번의 모델 호출에 필요한 정보
= 역할·규칙 + 현재 요청 + 대화 이력·상태
  + 관련 자료 + 도구 설명 + 원하는 출력 형식

구성 변경 → 테스트셋 평가 → 이전 결과와 비교
```

## 요약
- 기억·검색·도구는 별개 제품명이 아니라 입력 구성의 수단이다.
- 에이전틱 RAG는 필요한 검색을 도구 선택 과정에 포함한다.
- 최적의 구성은 실제 평가 결과로 찾는다.
