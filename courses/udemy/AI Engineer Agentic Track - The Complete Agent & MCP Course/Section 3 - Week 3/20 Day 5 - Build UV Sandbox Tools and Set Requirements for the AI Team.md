# Day 5 - Build UV Sandbox Tools and Set Requirements for the AI Team

## 개요
- sandbox 실행을 uv 프로젝트로 확장하고 거래 시뮬레이터 요구사항을 전달한다.
- 출처: [원본 강의](https://www.udemy.com/course/the-complete-agentic-ai-engineering-course/learn/lecture/49821243#overview)의 실제 자막 확인·정리 (2026-09-07).

## 내용
### uv 실행 환경
파일 목록·읽기·쓰기 도구는 유지하고 실행 도구를 Python 직접 호출에서 uv run으로 바꾼다. 컨테이너도 uv가 포함된 이미지로 바꿔 Gradio 등 프로젝트 의존성을 사용할 수 있게 한다. 시작 시 sandbox를 초기화하는 함수도 연결한다.

### 개발 요구사항
계좌 생성, 입금, 주식 매수·매도와 잔고 관리를 하는 거래 시뮬레이션 시스템을 만든다. main.py에 요구사항을 입력하고 Crew를 시작한다. UI에서 요구사항을 받는 확장도 가능하지만 영상은 고정 입력으로 시작한다.

### 도구 캐시 문제
파일을 만든 뒤 목록을 다시 요청했는데 예전 빈 목록이 반환되는 문제가 나타난다. 같은 인수의 도구 호출 결과를 재사용하는 캐시가 원인이다. 변하는 파일 상태를 읽는 도구에는 이 캐시가 부적절하므로 예제에서 비활성화하고 trace로 확인한다.

## 예시
```text
파일 목록 조회 → 새 파일 작성 → 같은 목록 조회
기대: 새 파일 표시
문제: 캐시된 이전 목록 반환
조치: 상태가 변하는 sandbox 도구의 캐시 해제
```

## 요약
- 실행 이미지와 명령 모두 프로젝트 의존성에 맞춘다.
- 상태 조회 도구의 캐시는 최신 결과를 가릴 수 있다.
