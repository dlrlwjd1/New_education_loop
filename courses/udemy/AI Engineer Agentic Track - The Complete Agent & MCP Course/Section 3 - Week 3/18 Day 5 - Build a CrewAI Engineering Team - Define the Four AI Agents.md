# Day 5 - Build a CrewAI Engineering Team: Define the Four AI Agents

## 개요
- 개발 리드·백엔드·프런트엔드·테스트 담당으로 이루어진 네 에이전트를 설계한다.
- 출처: [원본 강의](https://www.udemy.com/course/the-complete-agentic-ai-engineering-course/learn/lecture/49821233#overview)의 실제 자막 확인·정리 (2026-09-07).

## 내용
### 역할 경계
리드는 요구사항을 모듈·클래스·함수 시그니처로 설계하되 코드를 직접 작성하지 않게 한다. 백엔드는 설계를 구현하고 프런트엔드는 Gradio 화면을 만든다. 테스트 담당은 구현을 검증한다.

### 지침과 성공 기준
모든 작업을 같은 uv 프로젝트에서 수행하도록 명시한다. 프런트엔드는 스타일 요구와 UI 기동 검증 스크립트를 포함한다. 리드가 구현까지 해버리는 경향을 막기 위해 역할 경계를 반복해서 설명한다.

### 최신 API와 반복 개선
학습 시점 이후의 Gradio API를 모델이 모를 수 있어 Context7을 통한 확인을 지시한다. 강사는 이 프롬프트가 여러 실패 뒤에 다듬어진 결과이며 다른 모델에서는 추가 조정이 필요하다고 설명한다.

## 예시
```text
요구사항 → 리드의 설계
→ 백엔드 구현 → Gradio 화면 → 테스트
공통 조건: 같은 작업 디렉터리·uv 프로젝트·합의된 인터페이스
```

## 요약
- 역할 이름보다 산출물과 책임 경계를 구체적으로 적는다.
- 최신 API 확인과 반복 검증을 과제에 포함한다.
