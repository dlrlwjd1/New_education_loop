# Upgrade to the AI Engineer Agentic Track

## 개요
- AI Engineer Agentic Track 업그레이드를 안내하는 홍보성 항목이다.

## 내용
### 핵심 개념
- 기술 강의나 실습 대본이 아닌 과정 업그레이드 안내로 구성된다.
- 별도의 에이전트 구현 개념이나 코드 실습은 포함하지 않는다.
- 학습 흐름에서는 선택적으로 확인할 수 있는 안내 항목이다.

## 예시
별도 실습 없음.

## 요약
- 핵심 학습 항목이 아닌 과정 안내 페이지다.
