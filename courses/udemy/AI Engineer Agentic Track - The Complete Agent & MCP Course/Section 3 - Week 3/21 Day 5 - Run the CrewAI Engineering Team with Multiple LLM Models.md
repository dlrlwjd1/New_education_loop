# Day 5 - Run the CrewAI Engineering Team with Multiple LLM Models

## 개요
- 여러 모델 조합으로 개발 팀을 실행하고 생성된 거래 앱을 비교한다.
- 출처: [원본 강의](https://www.udemy.com/course/the-complete-agentic-ai-engineering-course/learn/lecture/49821253#overview)의 실제 자막 확인·정리 (2026-09-07).

## 내용
### 역할별 모델 구성
리드·백엔드·프런트엔드·테스터에 서로 다른 공급자의 모델을 배정하는 실험과 단일 모델 구성 실험을 수행한다. 키와 모델 이름을 YAML·환경 설정에 맞춘다. 영상의 비용과 우열은 해당 실행의 관찰 결과다.

### 산출물 검증
리드가 Context7으로 API를 조회하고 개발 팀이 앱을 만든다. 강사는 계좌 생성과 주식 매수·매도를 직접 시험하고, 보유하지 않은 주식을 팔 때 오류가 나오는지 확인한다. UI와 테스트 결과도 비교한다.

### 평가와 확장
여러 구성의 화면과 동작, 비용을 함께 본다. 한 번 잘 나온 팀이 항상 우수하다는 결론 대신 더 저렴한 모델로도 같은 요구를 충족하는지 실험하도록 권한다. 이후 반복 수정이 가능한 흐름으로 확장하는 과제를 제시한다.

## 예시
```text
동일 요구사항 + 서로 다른 모델 팀
→ 앱 생성 → 계좌·매수·매도·초과 매도 검사
→ UI·기능·비용 비교
```

## 요약
- 팀 구성은 실제 산출물과 비용으로 비교한다.
- 정상 거래와 실패해야 하는 거래를 함께 확인한다.
