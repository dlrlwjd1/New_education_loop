# Day 4 - Trading Floor Architecture: Trader and Researcher AI Agents

## 개요
- 트레이더와 전담 조사자를 나누고 코드·LLM 조율을 함께 사용하는 구조를 설계한다.
- 출처: [원본 강의](https://www.udemy.com/course/the-complete-agentic-ai-engineering-course/learn/lecture/50768327#overview)의 실제 자막 확인·정리 (2026-09-07).

## 내용
### 역할별 도구
트레이더는 계좌·전략·시장 데이터·알림 도구를 사용한다. 전담 조사자는 Fetch·웹 검색·메모리로 정보를 수집한다. 각 트레이더가 자기 조사 기억을 축적하도록 구성한다.

### 두 조율 방식
거래 작업을 정해진 간격으로 실행하는 부분은 Python이 맡는다. 트레이더가 언제 어떤 조사를 요청할지는 researcher-as-tool을 통해 모델이 선택한다. 결정된 주기 실행을 프롬프트로 다시 지시할 필요는 없다.

### 초기 상태
계좌 모듈은 앞선 CrewAI 개발 팀의 산출물을 이어 사용한다. 새로 시작한 가상 계좌는 초기 잔액과 기본 전략을 가지며, 강사가 오래 실행한 보유 내역과는 다르다. 시장 키가 없으면 모의 가격을 사용한다.

## 예시
```text
Python 스케줄러 → 네 트레이더
각 트레이더 → 계좌·시장·알림
           → 전담 researcher → 검색·본문·기억
```

## 요약
- 역할별 문맥과 도구 요구를 근거로 분리한다.
- 주기 실행과 자율 조사 선택을 다른 계층에서 처리한다.
