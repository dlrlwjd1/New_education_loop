# Day 4 - Orchestrate the Trading Floor and Launch the Gradio Dashboard

## 개요
- 여러 트레이더를 주기적으로 실행하고 Gradio 대시보드에서 상태를 관찰한다.
- 출처: [원본 강의](https://www.udemy.com/course/the-complete-agentic-ai-engineering-course/learn/lecture/50768351#overview)의 실제 자막 확인·정리 (2026-09-07).

## 내용
### 주기 실행
trading_floor 모듈이 거래 시간 또는 강제 실행 설정을 확인하고 asyncio.gather로 네 트레이더 실행을 함께 기다린다. 간격·장 마감 시 실행·여러 모델 사용 여부를 환경 설정으로 조절한다.

### 대시보드
트레이더별 평가액 추이, 보유, 최근 거래, 도구 활동을 표시한다. 화면을 여는 것과 거래 작업 루프를 실행하는 것을 구분한다. 새 실습 계좌와 강사가 오래 실행한 계좌의 상태는 다르다.

### 성과 해석
강사는 기존 계좌가 상승했어도 같은 기간 시장 전체가 오른 영향을 구분해야 한다고 설명한다. 절대 수익만으로 에이전트 전략의 우수성을 주장할 수 없다. 수수료와 벤치마크도 결과 해석에 필요하다.

## 예시
```text
주기 도래 → 실행 조건 검사 → 네 트레이더 호출
→ 계좌·거래·로그 갱신 → 대시보드 표시
평가: 수익뿐 아니라 시장 대비 결과 검토
```

## 요약
- 스케줄러와 개별 에이전트의 자율 판단을 나눈다.
- 대시보드의 수익을 곧바로 전략 성능으로 해석하지 않는다.
