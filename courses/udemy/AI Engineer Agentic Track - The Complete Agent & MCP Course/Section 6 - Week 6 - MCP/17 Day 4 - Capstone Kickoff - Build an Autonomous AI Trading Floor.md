# Day 4 - Capstone Kickoff: Build an Autonomous AI Trading Floor

## 개요
- 여러 MCP 서버와 평가 피드백을 결합하는 가상 거래 캡스톤을 소개한다.
- 출처: [원본 강의](https://www.udemy.com/course/the-complete-agentic-ai-engineering-course/learn/lecture/50768309#overview)의 실제 자막 확인·정리 (2026-09-07).

## 내용
### 프로젝트 범위
금융 서비스라는 구체적인 업무 영역에 에이전트 기술을 적용한다. 계좌는 가상이며 교육용 거래 시뮬레이션이다. 실제 투자 권고나 주문 시스템으로 완성된 예제가 아니다.

### 구성 방식
계좌·시장 정보·검색·기억·알림 등의 MCP 도구를 연결한다. 정해진 흐름은 Python으로 조율하고, 조사 에이전트를 도구로 호출하는 선택은 LLM에 맡기는 혼합 구조를 사용한다.

### 평가의 필요
거래 이유를 설득력 있게 생성하는 능력과 좋은 거래 판단은 다르다. 결정 결과를 측정하고 피드백을 다음 결정에 반영하는 방법을 캡스톤의 핵심으로 제시한다.

## 예시
```text
가상 계좌 상태 + 시장 조사
→ 에이전트 결정 → 가상 거래 기록
→ 성과 측정 → 전략 피드백
```

## 요약
- 업무 적용과 성과 평가는 함께 설계한다.
- 가상 거래 실습의 범위를 유지한다.
