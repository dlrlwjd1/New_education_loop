# Day 1 - Welcome to MCP Week: Agent Frameworks and the Agent Harness

## 개요
- 마지막 주차를 시작하며 에이전트 프레임워크와 agent harness의 추상화 수준을 복습한다.
- 출처: [원본 강의](https://www.udemy.com/course/the-complete-agentic-ai-engineering-course/learn/lecture/50767541#overview)의 실제 자막 확인·정리 (2026-09-07).

## 내용
### 에이전트의 공통 구조
도구를 가진 LLM이 목표를 이루기 위해 반복 실행되는 구조를 기준으로 삼는다. 원시 API 호출부터 기본 구성요소, 에이전트 프레임워크, 완성된 harness까지 연속선으로 비교한다.

### 제어와 편의
낮은 계층에서는 직접 작성할 코드가 많지만 제어가 명확하다. 높은 계층은 기본 도구·메모리·위임을 제공하지만 내부 동작을 진단하기 어려울 수 있다. 어느 쪽이 좋은지는 과제에 달려 있다.

### 이번 주의 위치
OpenAI Agents SDK 기반으로 MCP를 다룬다. MCP는 이 추상화 계층의 또 다른 에이전트 프레임워크가 아니라 연결 규약이다. 앞선 도구 호출·루프 이해가 선행 지식이다.

## 예시
```text
직접 모델 호출 → 기본 구성요소 → 에이전트 프레임워크 → harness
직접 구현할 범위와 프레임워크에 맡길 범위를 비교
```

## 요약
- 도구·반복·목표라는 공통 구조를 유지한다.
- 추상화의 편리함과 내부 제어의 범위를 함께 본다.
