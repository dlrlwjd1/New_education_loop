# Day 3 - Context Engineering for AI Agents with MCP Servers

## 개요
- 프롬프트·메모리·검색·도구를 함께 설계하는 컨텍스트 엔지니어링을 설명한다.
- 출처: [원본 강의](https://www.udemy.com/course/the-complete-agentic-ai-engineering-course/learn/lecture/50767765#overview)의 실제 자막 확인·정리 (2026-09-07).

## 내용
### 문맥의 구성
시스템 지침, 대화 이력, 장기 저장 정보, 검색 결과, 도구 설명과 실행 결과가 모델의 입력 문맥을 이룬다. 긴 대화는 요약과 최근 메시지를 조합할 수 있다. 저장된 사실을 필요할 때 검색하는 장기 메모리와 구분한다.

### 기능의 겹침
RAG 검색 결과는 프롬프트에 포함되고, 검색 대상이 과거 기억일 수도 있다. 검색을 도구로 제공하면 에이전트가 필요에 따라 조회하는 Agentic RAG가 된다. 각각 독립된 유행어라기보다 입력을 구성하는 연결된 방법들이다.

### MCP 실행 위치
로컬·원격 연결 외에 모델 공급자가 연결을 대신 처리하는 hosted MCP 방식도 소개한다. 강사는 직접 제어를 선호해 이번 수업에서는 client가 관리하는 연결을 중심으로 다룬다. 이는 설계 선택에 대한 강사의 관점이다.

## 예시
```text
좋은 지침 + 필요한 대화 이력 + 검색한 사실
+ 적절한 도구 설명·결과 → 모델 입력
모델 출력 → 구조화해 후속 처리
```

## 요약
- 컨텍스트 엔지니어링은 입력 전체의 구성 문제다.
- 메모리·RAG·도구 사용은 서로 겹칠 수 있다.
