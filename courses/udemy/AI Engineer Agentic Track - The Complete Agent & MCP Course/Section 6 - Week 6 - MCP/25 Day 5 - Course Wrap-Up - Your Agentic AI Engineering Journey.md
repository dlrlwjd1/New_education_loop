# Day 5 - Course Wrap-Up: Your Agentic AI Engineering Journey

## 개요
- 6주간의 프로젝트를 돌아보고 캡스톤을 자신의 문제로 확장하는 과제를 안내한다.
- 출처: [원본 강의](https://www.udemy.com/course/the-complete-agentic-ai-engineering-course/learn/lecture/50769797#overview)의 실제 자막 확인·정리 (2026-09-07).

## 내용
### 과정 복습
직접 모델 호출과 Digital Twin에서 출발해 SDK의 영업·Deep Research, CrewAI의 Stock Picker·개발 팀, LangChain 계층과 Sidekick, 여러 프레임워크의 Agent Loop를 거쳤다. 마지막에는 MCP 기반 가상 거래 시스템으로 연결했다.

### 다음 실습
거래 시뮬레이터의 도구·평가를 개선하거나 다른 업무 영역에 적용한다. 앞선 개발 팀의 계좌 코드가 마지막 서버 실습에 재사용된 것처럼 개별 기술을 실제 산출물로 이어 쓰는 것이 핵심이다. 수강 안내와 추가 링크는 원본 페이지에서 확인한다.

## 예시
```text
기초 도구 루프 → 프레임워크 비교 → 업무 프로젝트
→ MCP 통합 → 결과 평가 → 자신의 문제에 적용
```

## 요약
- 공통 에이전트 원리를 여러 구현에서 반복했다.
- 과정의 끝은 자신의 문제에 적용하고 검증하는 출발점이다.
