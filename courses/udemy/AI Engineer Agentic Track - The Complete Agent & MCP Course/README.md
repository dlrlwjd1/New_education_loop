# AI Engineer Agentic Track: The Complete Agent & MCP Course

- 플랫폼: Udemy
- 강사: Ed Donner, Ligency
- 저장소 구성: 6개 섹션, 145개 항목 (기존 홍보 안내 13개 포함)
- 현재 수강 페이지: 132개 항목 (2026-09-07 확인)
- 자막: 영어 자동, 한국어 자동
- 마지막 확인: 2026-09-07
- [원본 강의](https://www.udemy.com/course/the-complete-agentic-ai-engineering-course/)

## 개요

OpenAI Agents SDK, CrewAI, LangGraph, Google ADK, Strands, Pydantic AI, Microsoft Agent Framework, Agno, Mastra, MCP를 프로젝트 중심으로 비교하며 에이전틱 AI 엔지니어링의 설계·구현·배포 흐름을 익히는 과정이다.

전체 과정은 Career Digital Twin, 영업 에이전트 팀, Deep Research, 주식 선정 팀, 4-Agent 엔지니어링 팀, 브라우저 Sidekick, 멀티 프레임워크 Agent Loop, MCP 기반 AI Trading Floor의 8개 프로젝트로 이어진다.

## 자료 확인 상태

2026-09-07 로그인된 Udemy 수강 페이지에서 실제 자막을 확인해, 제목만 기록했던 **126개 강의 노트**를 한국어 내용·실습 예시·요약으로 교체했다. 각 문서에 원본 강의 링크와 확인일을 기록했다. 기존 과정 로드맵도 현재 커리큘럼에 맞게 보완했다.

자막에 근거한 학습 정리이며 원문 전체 대본이나 실습 코드 전체를 복제한 문서는 아니다. 예제 코드·흐름을 재구성한 경우 이를 표시했다. 자동 자막에서 명확하지 않은 코드 이름은 임의로 확정하지 않았고, 가격·모델·버전 안내는 영상의 촬영 환경과 구분했다. 이 작업에서 강의 실습의 외부 API 호출이나 앱 배포를 재실행한 것은 아니다.

현재 수강 페이지에는 기존 `Upgrade to the AI Engineer Agentic Track` 안내 13개가 표시되지 않아 저장소의 145개 항목과 차이가 있다. 기존 참조를 유지하도록 파일 경로와 섹션별 번호를 보존했다. 해당 홍보 안내와 보너스 링크 문서는 기술 강의 정리 대상에서 제외했다.
