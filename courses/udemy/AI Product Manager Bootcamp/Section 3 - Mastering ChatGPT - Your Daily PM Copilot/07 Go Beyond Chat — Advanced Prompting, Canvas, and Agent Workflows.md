# Go Beyond Chat — Advanced Prompting, Canvas, and Agent Workflows

## 개요
- 기본 프롬프팅으로 할 수 있는 것들을 본 뒤의 마무리
- 진짜 다음 단계: **시도·테스트·학습·반복(try, test, learn, iterate)**하며 자기 방식을 찾는 것
- 더 깊은 도구(딥 리서치·에이전트 모드) 소개 + 프롬프트 구조·베스트 프랙티스 정리

## 내용

### ChatGPT의 더 깊은 도구 (직접 테스트 드라이브 권장)
- **딥 리서치(deep research)**: 다중 소스 웹 리서치·인용(citations)·종합(synthesis)
  - ⚠️ 위험: 모든 주제에 너무 깊이 들어가면 20페이지 리포트가 돌아옴 → **아껴서(sparingly) 사용**
- **에이전트 모드(agent mode)**: 태스크 수행에 활용
- 공통 조언: 여러 도구를 **테스트하며 자기 방식으로 익혀라**

### 좋은 프롬프트 구조
> 프롬프트가 좋을수록 결과가 좋다 (better prompts → better results)

권장 포맷: **Context(컨텍스트) · Role(역할) · Task(과제) · Constraints(제약) · Format(형식)**
- 더 정밀한(precise) 컨텍스트를 줄수록 좋다

### 베스트 프랙티스 (데모 전반에서 다룬 것)
1. **제품·사용자·목표에 대한 컨텍스트 제공** — 모든 데모는 일반적(generic)이므로 자기 상황에 적용해야 함
2. **형식과 제약을 구체적으로** 지정
3. **반복(iterate)** — 자기 문제에 가장 잘 맞는 방식을 직접 찾기 (PM의 DNA)
4. **후속 프롬프트(follow-ups) 활용** — 더 짧게, 예시 추가 등
5. **선호도(preferences) 라이브러리 구축** — ChatGPT가 메모리로 기억하지만 명시적으로 진술하는 것도 좋음

### 배운 것 정리 (Recap)
- **LLM은 패턴을 예측**한다 → 컨텍스트와 구체성(specificity)이 중요. "안다(know)"가 아니라 방대한 학습 데이터로 다음 단어를 통계적으로 예측
- ChatGPT가 잘하는 것: **유저 스토리, 경쟁 리서치, 글쓰기**
- 탐색한 비직관적 활용: **이해관계자 롤플레잉**(강사 최애), 학습, 프레임워크 구축·활용

## 예시
- 반복 편집은 Canvas, 장기 자료는 Project, 여러 단계의 자율 작업은 Agent 후보로 분류하고 필요한 컨텍스트와 제약을 먼저 적는다.

## 요약
- 핵심 다음 단계: 스스로 **시도-테스트-학습-반복**하며 자기 프롬프트 방식을 찾기
- 프롬프트 구조: **Context · Role · Task · Constraints · Format** — 정밀할수록 좋음
- 베스트 프랙티스 5가지: 컨텍스트 제공 · 형식/제약 구체화 · 반복 · 후속 프롬프트 · 선호도 라이브러리
- 딥 리서치·에이전트 모드는 강력하나 아껴서 사용
