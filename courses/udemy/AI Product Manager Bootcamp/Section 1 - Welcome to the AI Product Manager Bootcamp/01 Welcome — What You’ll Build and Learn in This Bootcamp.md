# Welcome — What You’ll Build and Learn in This Bootcamp

## 개요
- AI 시대에 제품 관리자(Product Manager, PM)의 일하는 방식이 근본적으로 바뀌고 있음
- **기존 패러다임**: 아이디어 → 검증까지 느리고 순차적(slow & sequential), 수 주(weeks) 소요
- **새로운 패러다임**: 빠르고 검증 중심(fast & validated), 수 주 → 수 시간(hours)으로 단축
- 이 부트캠프는 ChatGPT → Claude → Lovable을 거쳐 **실제 프로덕션 제품 출시(shipping to production)**까지 직접 만들어보는 실습 중심 과정

## 내용

### 학습 경로 (난이도 점진적 상승)
1. **ChatGPT** — 이미 익숙한 도구를 더 깊이 활용
   - 고급 프롬프트 엔지니어링(advanced prompt engineering)
   - PRD 생성(PRD generation)
   - 경쟁 분석(competitive analysis)
   - 각종 의사결정 프레임워크(decision frameworks)
2. **Claude** — ChatGPT보다 강점을 보이는 영역
   - 아티팩트(artifacts)를 활용한 프로토타이핑(prototyping)
   - 데이터 분석(data analysis)
3. **Lovable** — 빠른 반복(rapid iteration)
   - 가격 전략(pricing strategy), 테스트(testing), 온보딩 플로우(onboarding flow) 등
4. **프로덕션 레벨 애플리케이션** — PM이 직접 빌드
   - IDE: **Cursor**
   - **Claude Code** 설치, **MCP 서버**와 **서브에이전트(Subagents)** 활용
   - 배포: **Vercel**, 백엔드: **Supabase**, 버전 관리: **GitHub**

### 마스터하게 될 도구
ChatGPT · Claude · Lovable · Claude Code · Cursor · Supabase · Vercel · GitHub · MCP 서버 · Subagents

### 캡스톤 프로젝트 (Capstone Project)
- **컴플라이언스 트래커 앱(compliance tracker app)** 전체를 구축
- 0→1 시나리오의 PM에게 특히 적합하지만, 반복 개선형(iterative) PM에게도 가치가 큼
- 전체 제품을 만드는 큰 맥락(larger context)을 이해하면 작은 단위의 반복 작업에도 응용 가능
- 다루는 과정:
  - 유저 스토리 정의(defining user stories)
  - V0 프로토타입
  - 백엔드 연결(connect the back end)
  - 배포(deploy)
  - CI/CD 구성
  - GitHub 버전 관리(version control)

### 수강 대상 (Who should take this)
- **현직 PM** — 속도(speed)를 높이고 싶은 사람
- **PM 지망생(aspiring PM)** — 제품 관리로 진입하기 위한 실제 프로젝트 포트폴리오가 필요한 사람
- **PM 직함은 없지만 제품을 만드는 사람** — SLC/MVP를 출시(shipping)하는 사람
- **제품 역할로 이동하거나 제품 관점(product lens)을 이해하고 싶은 팀원**

### 최대한 활용하는 법 (How to get the most out of it)
- **실시간으로 따라 하기(follow along in real time)** — 보기만 하지 말고 함께 빌드
- 모든 데모를 직접 수행(do every demo)
- 제공되는 프롬프트를 수정해 자기 것으로 만들기(make them your own)
- **직접 해보며 배우기(learn by doing)** — 모든 프로토타입을 스스로 만들고, 도구를 직접 연결하고, 동료와 공유

## 예시
- 캡스톤의 규정 준수 앱을 기준으로 `ChatGPT → Claude → Lovable → GitHub·Supabase·Vercel`의 결과물을 한 줄씩 적어 전체 학습 흐름을 그려본다.

## 요약
- 이 부트캠프의 핵심 메시지: **"AI를 이해하는 것을 넘어 AI로 직접 만든다(build with it)"**
- 진행 흐름: ChatGPT(프롬프트·PRD·분석) → Claude(프로토타입·데이터) → Lovable(빠른 반복) → 프로덕션(Cursor·Claude Code·Supabase·Vercel)
- 최종 산출물: 컴플라이언스 트래커 앱 캡스톤 + 프로덕션 레벨 AI 워크플로 역량
- 학습 태도: 보지 말고 만들라 — 실시간으로 따라 하며 실습(learn by doing)
