# Hands-On Build — Rethink Your Onboarding Flow

## 개요
- 이탈률이 높은 온보딩을 재설계하기 전에 작동하는 테스트 흐름을 만든다.
- 원본 강의: https://www.udemy.com/course/ai-product-manager-bootcamp/learn/lecture/53243945

## 내용
### 가설과 학습 목표
- 현재 온보딩 이탈률이 40%이고, 앞단에서 묻는 정보를 줄이면 완료율이 개선된다는 가설을 둔다.
- 사용자가 모든 단계를 완료하는지, 어느 단계에서 혼란·이탈하는지, 다음에 무엇을 기대하는지 확인한다.

### 구현
- 환영 및 목적 → 사용자 정보 → 가장 큰 과제 → 워크스페이스 생성의 4단계 흐름을 만든다.
- 진행 표시기, 완료 화면, 별점과 혼란 지점 피드백 양식을 제공한다.
- 별도 분석 화면에서 단계별 시작·완료 수를 퍼널로 보여주고 평균 평점과 자유 응답을 표시한다.
- 세션·단계·피드백을 관계형 테이블과 기본키·외래키로 연결한다.

## 예시
- 15~20명에게 먼저 사용하게 해 흐름의 문제를 찾은 뒤, 실제 제품에서는 충분한 표본의 실험으로 완료율 개선을 검증한다.

## 요약
- 프로토타입은 실제 대규모 실험에 넣을 흐름을 고르는 선행 단계다.
- 단계별 이벤트와 이탈을 기록하지 않으면 온보딩 개선 여부를 판단할 수 없다.
