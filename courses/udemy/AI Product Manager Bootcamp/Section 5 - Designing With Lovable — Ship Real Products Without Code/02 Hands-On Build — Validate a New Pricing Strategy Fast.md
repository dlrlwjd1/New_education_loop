# Hands-On Build — Validate a New Pricing Strategy Fast

## 개요
- 가격 정책을 프로덕션에 넣기 전에 Lovable 테스트 앱으로 고객 신호를 수집한다.
- 원본 강의: https://www.udemy.com/course/ai-product-manager-bootcamp/learn/lecture/53243937

## 내용
### 검증 질문
- 사용자가 어떤 요금제를 선호하는가?
- 연간 결제를 먼저 보여주면 선택이 바뀌는가?
- 구매 전에 어떤 질문과 우려가 생기는가?

### 테스트 앱
- 3단 요금제, 월간·연간 토글, 추천 배지와 요금제 선택 기능을 만든다.
- 선택한 요금제와 자유 형식 피드백을 데이터베이스에 저장하고 결과 대시보드에서 집계한다.
- 먼저 10~15명에게 시험해 실제 A/B 테스트에 넣을 변형을 좁힌다. 소규모 신호가 통계적으로 유의한 본 실험을 대체하지는 않는다.

### 데이터 활용
- 응답이 많아지면 CSV로 내보내거나 AI 기능으로 자유 응답을 요약할 수 있다.

## 예시
```text
3개 요금제와 월간·연간 전환을 제공하고 사용자의 선택과 우려를 저장해줘.
관리자 화면에는 요금제별 선택 수와 피드백을 보여줘.
```

## 요약
- 가벼운 사전 검증으로 본 A/B 테스트의 후보와 질문을 개선한다.
- 선택 데이터뿐 아니라 선택 이유와 우려도 함께 수집한다.
