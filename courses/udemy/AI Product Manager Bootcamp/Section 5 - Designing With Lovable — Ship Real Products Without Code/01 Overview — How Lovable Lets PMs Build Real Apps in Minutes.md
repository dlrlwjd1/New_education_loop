# Overview — How Lovable Lets PMs Build Real Apps in Minutes

## 개요
- Lovable로 자연어 지시만으로 배포 가능한 풀스택 앱을 만드는 방법을 소개한다.
- 원본 강의: https://www.udemy.com/course/ai-product-manager-bootcamp/learn/lecture/53243903

## 내용
### Artifact와의 차이
- Lovable은 UI뿐 아니라 PostgreSQL 데이터베이스, 인증, 사용자 도메인과 배포까지 포함할 수 있다.
- 빠른 프로토타입·개념 증명·내부 도구 등 PM이 검증하려는 사례의 상당 부분을 구현할 수 있다.

### 핵심 가치
- 기술 장벽과 엔지니어링 대기 시간을 줄여 아이디어에서 검증 또는 기각까지 걸리는 시간을 단축한다.
- PRD를 쓰거나 개발팀에 넘기기 전에도 `Build → Measure → Learn` 순환을 여러 번 실행할 수 있다.

## 예시
- 무료 플랜에서 채팅으로 앱을 만든 뒤 필요한 경우 백엔드와 인증을 연결한다.

## 요약
- Lovable은 클릭형 목업보다 실제 제품에 가까운 검증 도구다.
- 빠른 제작 자체보다 더 빨리 학습하고 위험을 줄이는 것이 목적이다.
