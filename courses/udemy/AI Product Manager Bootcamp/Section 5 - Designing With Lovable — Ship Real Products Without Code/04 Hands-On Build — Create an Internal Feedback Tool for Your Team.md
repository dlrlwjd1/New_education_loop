# Hands-On Build — Create an Internal Feedback Tool for Your Team

## 개요
- Slack·이메일·메모에 흩어진 고객 피드백을 모으는 소규모 내부 도구를 만든다.
- 원본 강의: https://www.udemy.com/course/ai-product-manager-bootcamp/learn/lecture/53243953

## 내용
### 요구 사항
- 피드백 본문, 고객명, 유입 채널, 유형, 등록일을 저장한다.
- 기능 요청·버그·일반 의견 등의 태그, 유형·출처 필터, 검색을 제공한다.
- 카드 목록에서 요약을 보고 클릭하면 전문을 확인하며 유형별 건수를 빠른 통계로 보여준다.

### 배포 시 고려사항
- 생성·조회·삭제 흐름과 삭제 확인창을 직접 시험한다.
- 공개 URL은 링크를 아는 사람이 접근할 수 있으므로 실제 내부 사용 시 사내 도메인과 인증을 추가해야 한다.
- 보안 검토 없이 고객 정보를 다루는 도구를 공개해서는 안 된다.

## 예시
- 10~20명 규모 팀이 여러 채널에서 받은 고객 의견을 한곳에 등록하고 반복되는 패턴을 찾는 용도로 사용한다.

## 요약
- Lovable은 외부 프로토타입뿐 아니라 작은 내부 운영 도구에도 쓸 수 있다.
- 실제 고객 데이터가 들어가면 인증·접근 통제·보안 검토가 필수다.
