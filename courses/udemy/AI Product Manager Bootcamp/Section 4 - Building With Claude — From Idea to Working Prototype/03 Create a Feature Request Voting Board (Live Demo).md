# Create a Feature Request Voting Board (Live Demo)

## 개요
- Claude Artifacts로 기능 요청 투표 보드를 만들고 프로토타입의 가능성과 한계를 확인한다.
- 원본 강의: https://www.udemy.com/course/ai-product-manager-bootcamp/learn/lecture/53243851

## 내용
### 요구 사항
- 새 기능 요청 제출, 찬성·반대 투표, 상태 추적, 댓글·토론을 포함한다.
- 모바일 앱·대시보드·통합 등 카테고리별 필터와 정렬도 요구한다.

### 실제 검증
- 필터, 투표, 다크 모드 같은 일부 상호작용은 동작했다.
- 새 요청 제출과 최다 득표 정렬은 첫 결과나 반복 수정 후에도 제대로 작동하지 않았다.
- Artifact에는 데이터베이스와 백엔드가 없으므로 프로덕션 기능처럼 기대하면 안 된다.

## 예시
```text
반대 투표를 추가하고, 최다 득표 정렬을 고치고,
우측 상단에 라이트·다크 모드 전환을 추가해줘.
```

## 요약
- 프로토타입은 사용자가 원하는지 빠르게 확인하는 수단이다.
- 동작하지 않는 부분을 직접 시험하고 반복하되 백엔드 없는 프로토타입의 한계를 구분한다.
