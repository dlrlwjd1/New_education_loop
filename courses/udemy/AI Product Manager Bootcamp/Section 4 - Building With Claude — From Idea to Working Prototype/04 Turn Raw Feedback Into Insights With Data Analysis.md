# Turn Raw Feedback Into Insights With Data Analysis

## 개요
- CSV 사용자 피드백을 Claude에 넣어 의사결정용 분석 보고서를 만드는 흐름을 다룬다.
- 원본 강의: https://www.udemy.com/course/ai-product-manager-bootcamp/learn/lecture/53243859

## 내용
### 분석 요청
- 상위 5개 주제와 빈도, 긍정·부정·중립 감성 비율, 긴급도, 기능 요청, 빠른 개선 과제를 요구한다.
- 주제 빈도 막대그래프와 긴급도×빈도 우선순위 매트릭스를 포함한다.
- 각 차트에 제목과 핵심 해석을 붙여 경영진이 바로 읽을 수 있게 한다.

### 결과 개선
- 첫 결과의 과도하게 큰 차트와 일관성 없는 형식을 지적하고 하나의 보고서로 통합하도록 지시한다.
- 화려함보다 상위 주제, 감성, 우선순위, 실행 계획, 성공 지표가 명확한 간결한 보고서가 더 유용했다.
- 결과는 DOCX나 PDF로 내려받아 공유할 수 있다.

## 예시
```text
피드백을 주제별로 분류하고 빈도·감성·긴급도를 계산해줘.
긴급도와 빈도 매트릭스, 빠른 개선 과제, 즉시·단기·중기 실행안을 포함한
간결한 경영진용 보고서로 만들어줘.
```

## 요약
- 원자료, 분석 차원, 시각화, 독자와 출력 형식을 함께 지정한다.
- AI 결과의 분류와 표현을 검토하고 몇 차례 반복해 의사결정 가능한 문서로 다듬는다.
