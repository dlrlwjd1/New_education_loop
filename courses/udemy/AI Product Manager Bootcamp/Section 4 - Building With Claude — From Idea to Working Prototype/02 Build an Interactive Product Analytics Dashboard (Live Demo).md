# Build an Interactive Product Analytics Dashboard (Live Demo)

## 개요
- Claude Artifacts로 인터랙티브 제품 분석 대시보드를 만들고 반복 개선한다.
- 원본 강의: https://www.udemy.com/course/ai-product-manager-bootcamp/learn/lecture/53243831

## 내용
### 첫 프롬프트
- 일간 활성 사용자, 기능 채택률, 고객 만족도(CSAT), 월 매출을 포함하도록 요구한다.
- 생성된 Artifact를 게시해 이해관계자에게 공유할 수 있는 링크로 만든다.

### 검토와 반복
- 7일·30일·90일 선택에 따라 사용자 수가 갱신되는지 확인한다.
- 기능 채택률 막대그래프를 사용량이 많은 순서로 정렬하도록 후속 지시한다.
- 생성 결과를 그대로 승인하지 않고 필터·수치·정렬이 실제로 작동하는지 직접 시험한다.

## 예시
```text
총 사용자 위젯을 7일·30일·90일 선택에 맞춰 갱신하고,
기능 채택률 막대그래프를 채택률 내림차순으로 정렬해줘.
```

## 요약
- 구체적인 지표와 상호작용을 명시한 뒤 결과를 시험하고 후속 프롬프트로 수정한다.
- 목적은 완성품 제작보다 아이디어와 가설을 빠르게 검증하는 것이다.
