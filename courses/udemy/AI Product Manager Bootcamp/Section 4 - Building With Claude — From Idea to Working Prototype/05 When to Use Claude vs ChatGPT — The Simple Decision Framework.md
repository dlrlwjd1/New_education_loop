# When to Use Claude vs ChatGPT — The Simple Decision Framework

## 개요
- PM 업무에서 Claude와 ChatGPT를 선택하는 간단한 기준을 제시한다.
- 원본 강의: https://www.udemy.com/course/ai-product-manager-bootcamp/learn/lecture/53243875

## 내용
### 선택 기준
- 강의 녹화 시점에는 인터랙티브 프로토타입, 문서 분석, 데이터 시각화와 구조화된 콘텐츠에 Claude가 유리하다고 평가한다.
- 커스텀 GPT, 웹 리서치, 이미지 생성에는 ChatGPT를 선택할 수 있다.
- 회사의 IT 정책과 예산 때문에 하나만 사용할 수도 있으며, 제품 기능이 빠르게 변하므로 이 기준은 고정된 결론이 아니다.

### 공통 원칙
- 충분하고 구체적인 맥락을 제공하되 컨텍스트 창이 무한하지 않음을 고려한다.
- 한 번의 프롬프트로 완성하려 하지 말고 결과를 검증하며 반복한다.

## 예시
- 작동하는 기능 목업이나 피드백 CSV 분석은 Claude Artifacts를 먼저 검토한다.
- 최신 웹 조사나 이미지 초안이 필요하면 ChatGPT의 해당 기능을 검토한다.

## 요약
- 브랜드가 아니라 작업 유형을 기준으로 도구를 고른다.
- 어느 도구든 구체적인 맥락, 검증, 반복이 결과 품질을 좌우한다.
