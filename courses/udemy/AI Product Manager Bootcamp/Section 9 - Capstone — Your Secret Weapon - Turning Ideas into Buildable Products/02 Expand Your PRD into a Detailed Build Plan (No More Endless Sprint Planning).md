# Expand Your PRD into a Detailed Build Plan (No More Endless Sprint Planning)

## 개요
- 승인된 PRD를 부모 작업과 검증 가능한 하위 작업으로 분해한다.
- 원본 강의: https://www.udemy.com/course/ai-product-manager-bootcamp/learn/lecture/53244175

## 내용
### 생성된 상위 작업
- 규정 규칙 엔진과 데이터 모델
- 텍스트·음성 입력 처리 및 NLP 분석
- 규정 준수 판정과 누락 항목 처리
- 체크리스트 UI와 사용자 안내
- 문서 생성과 다중 형식 내보내기
- 음성 전사, DB 스키마와 마이그레이션

### 검토와 보완
- 회의록 기록을 저장·편집하는 History 기능과 Word·PDF 내보내기를 빠뜨리지 않았는지 확인한다.
- 작업 목록은 주니어 엔지니어의 분해안처럼 검토하고 필요하면 엔지니어링 담당자에게 아키텍처 검토를 받는다.
- 구현은 하위 작업 하나씩 진행하고 완료 상태를 기록한다.

## 예시
- PRD의 규정 판정 기능을 부모 작업으로 두고 데이터 모델, 판정 로직, UI, 테스트를 독립적으로 검증 가능한 하위 작업으로 나눈다.

## 요약
- 빠른 학습용 POC와 프로덕션 아키텍처의 요구 수준을 구분한다.
- 구현 전에 누락·의존성·검증 기준을 작업 목록에서 잡는다.
