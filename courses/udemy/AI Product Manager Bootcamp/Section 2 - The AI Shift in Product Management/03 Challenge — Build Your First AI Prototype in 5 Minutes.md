# Challenge — Build Your First AI Prototype in 5 Minutes

## 개요
- 앞으로 배울 내용의 맛보기(a little taste) 데모
- 프롬프트 하나를 Claude에 붙여넣어 **약 30초 만에** 상호작용 가능한 프로토타입을 생성
- Claude의 **아티팩트(artifacts)** 기능이 동작하는 것을 처음 확인

## 내용

### 데모 흐름
1. 준비된 프롬프트를 복사
2. **Open Claude AI** 클릭 → Claude에 프롬프트 붙여넣기 → "그냥 굽게 둔다(let it cook)"
3. Claude가 **아티팩트(artifacts)** 기능을 자동으로 실행
4. 약 20초 사고(thought for ~20s) 후 오른쪽에 프로토타입 생성

### 만들어진 결과물 — 할 일 목록(to-do list) 앱
- 요구사항(requirements)에 요청한 핵심 기능(core functionality) 구현
- 동작 확인:
  - 작업 추가 — 예: "Take AI PM bootcamp course" 입력 후 추가
  - 완료 표시(mark as complete)
  - 삭제(delete)

### PM 프로토타이핑 학습 포인트 (Claude가 함께 설명해 준 것)
- 상태 관리(state management)
- 이벤트 처리(event handling)
- 동적 렌더링(dynamic rendering)
- 보안(security) 및 사용자 경험(user experience) 요소

## 예시
- 할 일 추가·완료·삭제 요구사항을 한 프롬프트에 적고 Claude Artifact를 생성한 뒤 세 동작을 직접 시험한다.

## 요약
- 프롬프트 → Claude 아티팩트 → **약 30초 만에** 사용자·이해관계자가 직접 상호작용할 수 있는 프로토타입 완성
- 결과물은 추가/완료/삭제가 되는 실제 동작하는 할 일 목록 앱
- 이것은 앞으로 코스 전반에서 다룰 프로토타이핑의 예고편 (아티팩트 심화는 뒤에서)
