# Context7 — Simplifying AI Context Management

## 개요
- 라이브러리의 최신 버전별 문서와 예제를 AI 작업 맥락에 공급하는 Context7 MCP를 소개한다.
- 원본 강의: https://www.udemy.com/course/ai-product-manager-bootcamp/learn/lecture/53244251

## 내용
- LLM의 학습 지식은 Stripe·Supabase·Vercel 같은 빠르게 변하는 제품의 최신 사용법과 다를 수 있다.
- Context7은 라이브러리 ID를 찾고 공식 문서와 코드 예제를 가져와 설정·구현·문제 해결에 사용한다.
- Claude Code에 원격 서버로 설치하고, 필요하면 프로젝트 지침에 최신 문서를 우선 사용하라고 명시한다.

## 예시
```text
Context7으로 현재 Supabase 버전의 공식 문서를 확인한 뒤 이 설정 오류를 해결해줘.
```

## 요약
- 최신 버전에 민감한 코드는 기억에 의존하지 말고 현재 문서를 불러와 작성한다.
