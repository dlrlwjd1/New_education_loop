# Vercel MCP — Seamless Deployment for AI-Powered Apps

## 개요
- 공식 Vercel MCP로 프로젝트와 배포 문제를 AI 도구에서 다룬다.
- 원본 강의: https://www.udemy.com/course/ai-product-manager-bootcamp/learn/lecture/53244259

## 내용
- 원격 MCP와 OAuth를 사용해 Vercel 프로젝트에 권한을 연결한다.
- Vercel 문서 검색, 프로젝트·배포 관리, 배포 로그 분석을 지원한다.
- 배포 오류를 일반 추측만으로 해결하기보다 실제 로그와 공식 문서를 컨텍스트로 제공한다.

## 예시
- 실패한 배포의 로그를 읽고 원인을 설명한 뒤 수정안을 만들도록 요청한다.

## 요약
- 사용하는 서비스가 공식 MCP를 제공하는지 먼저 확인한다.
- OAuth 권한은 필요한 범위만 허용한다.
