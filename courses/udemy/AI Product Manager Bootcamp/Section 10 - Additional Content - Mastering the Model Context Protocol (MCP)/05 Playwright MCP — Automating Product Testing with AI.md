# Playwright MCP — Automating Product Testing with AI

## 개요
- Playwright MCP로 브라우저 UI와 프런트엔드 문제를 자동 검증한다.
- 원본 강의: https://www.udemy.com/course/ai-product-manager-bootcamp/learn/lecture/53244275

## 내용
- 픽셀 기반 화면 해석 대신 구조화된 접근성 스냅샷을 이용해 웹 요소를 다룬다.
- 클릭·드래그·브라우저 종료 같은 상호작용과 콘솔 메시지 확인을 지원한다.
- 새 UI 컴포넌트가 요구 사항과 표준을 따르는지 확인하고 브라우저에서만 나타나는 오류를 재현하는 데 쓴다.

## 예시
- 핵심 사용자 흐름을 실행하고 콘솔 오류와 잘못된 UI 상태를 보고하게 한다.

## 요약
- Playwright MCP는 프런트엔드 구현 후 실제 브라우저 검증을 자동화하는 도구다.
- 자동화 결과도 성공 조건과 테스트 데이터에 비춰 검토한다.
