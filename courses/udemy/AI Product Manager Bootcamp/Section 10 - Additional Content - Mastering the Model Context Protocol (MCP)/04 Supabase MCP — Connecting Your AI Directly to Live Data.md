# Supabase MCP — Connecting Your AI Directly to Live Data

## 개요
- Supabase MCP로 데이터베이스·인증·운영 작업을 Claude Code에 연결한다.
- 원본 강의: https://www.udemy.com/course/ai-product-manager-bootcamp/learn/lecture/53244269

## 내용
- 테이블 설계와 마이그레이션, SQL 조회와 보고서, 개발 브랜치, 프로젝트 설정, 로그 조회와 디버깅을 지원한다.
- 사용자 수준으로 설치하면 여러 프로젝트에서, 프로젝트 수준으로 설치하면 해당 프로젝트에서만 사용한다.
- 자동 선택에만 의존하지 않고 중요한 작업에는 Supabase MCP를 사용하라고 명시할 수 있다.

## 예시
```text
Supabase MCP를 사용해 이번 마이그레이션을 실행하고 실패 로그를 확인해줘.
```

## 요약
- 설치 범위와 데이터 접근 권한을 프로젝트 필요에 맞춘다.
- 라이브 데이터 변경은 실행 전 대상과 쿼리를 검토한다.
