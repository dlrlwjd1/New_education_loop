# Installing and Using a Full-Stack Developer Subagent

## 개요
- Full-Stack Developer 서브에이전트를 설치해 코드베이스 개선안을 찾고 적용한다.
- 원본 강의: https://www.udemy.com/course/ai-product-manager-bootcamp/learn/lecture/53244315

## 내용
### 선택과 설치
- 처음에는 여러 역할을 한꺼번에 쓰지 않고 프런트엔드부터 데이터베이스까지 다루는 범용 역할 하나로 사용법을 익힌다.
- 에이전트 정의 파일을 설치한 뒤 Claude Code를 재시작하고 사용 가능 여부를 확인한다.

### 감사 예시
- 성능, 확장성, 모듈화, 코딩 관행, 보안을 기준으로 영향이 크고 위험이 낮은 리팩터링 5개를 요청한다.
- 강의 결과에는 TypeScript strict mode, 큰 모듈 분리, API 응답 캐시, Supabase 클라이언트 통합, 쿼리·인덱스 최적화가 포함됐다.
- AI가 제시한 작업 시간과 효과 추정은 정확한 측정값으로 간주하지 않는다.

## 예시
```text
이 앱을 감사하고 성능·확장성·모듈화·보안 측면에서
위험이 낮고 영향이 큰 리팩터링 5개를 근거와 함께 제안해줘.
```

## 요약
- 빠른 가설 검증 단계에서는 과도한 정비를 피하고 더 넓은 사용자에게 내보낼 때 품질 개선을 강화한다.
- 제안은 테스트와 코드 검토를 거쳐 선택적으로 적용한다.
