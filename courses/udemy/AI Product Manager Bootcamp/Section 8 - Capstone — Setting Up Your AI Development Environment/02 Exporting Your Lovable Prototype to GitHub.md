# Exporting Your Lovable Prototype to GitHub

## 개요
- Lovable이 만든 프로토타입 코드를 GitHub 저장소로 내보낸다.
- 원본 강의: https://www.udemy.com/course/ai-product-manager-bootcamp/learn/lecture/53244103

## 내용
- Lovable의 GitHub 연결 기능을 사용하면 생성된 전체 파일이 새 저장소로 전송된다.
- 이미 빈 저장소를 만들었더라도 Lovable이 별도 저장소를 만들 수 있다. 둘을 합치거나 새 저장소를 기준으로 계속할 수 있다.
- 이후 Cursor 안의 Claude Code가 만드는 변경도 같은 저장소로 푸시한다.

- Lovable이 생성한 저장소를 기준 저장소로 선택하고 다음 단계에서 로컬로 가져온다.

## 요약
- 프로토타입을 GitHub로 옮기면 버전 관리되는 개발 프로젝트로 전환된다.
- 중복 저장소가 생기면 어느 저장소가 기준인지 먼저 정한다.
