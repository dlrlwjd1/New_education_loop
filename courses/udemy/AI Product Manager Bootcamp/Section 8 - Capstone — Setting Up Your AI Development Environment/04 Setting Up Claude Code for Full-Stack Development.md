# Setting Up Claude Code for Full-Stack Development

## 개요
- Artifact를 만드는 Claude 앱과 구분되는 Claude Code 개발 환경을 준비한다.
- 원본 강의: https://www.udemy.com/course/ai-product-manager-bootcamp/learn/lecture/53244119

## 내용
- Claude Code는 웹과 터미널에서 사용할 수 있으며 강의의 주 작업 표면은 터미널이다.
- 프로토타입·개념 증명 작업량에 따라 개인 또는 팀 구독의 사용 한도를 검토한다.
- 가입과 인증을 마친 뒤 Cursor에서 프로젝트를 열고 Claude Code를 연결한다.

## 예시
```bash
claude
```

## 요약
- Claude 대화형 앱과 Claude Code는 용도가 다르다.
- 결제 플랜과 가격은 변할 수 있으므로 실제 가입 시 최신 조건을 확인한다.
