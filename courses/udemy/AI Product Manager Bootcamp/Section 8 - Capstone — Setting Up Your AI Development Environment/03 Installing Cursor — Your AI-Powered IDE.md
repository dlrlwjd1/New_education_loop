# Installing Cursor — Your AI-Powered IDE

## 개요
- GitHub 프로젝트를 로컬에 준비하고 Cursor에서 연다.
- 원본 강의: https://www.udemy.com/course/ai-product-manager-bootcamp/learn/lecture/53244111

## 내용
- GitHub의 Code 메뉴에서 저장소 ZIP을 내려받아 압축을 푼다.
- Cursor를 설치하고 압축을 푼 프로젝트 폴더를 연다.
- Cursor는 VS Code 계열 통합 개발 환경(IDE)이다.
- 이 강의에서는 Cursor 자체 AI 기능보다 편집기 역할을 사용하며, VS Code나 다른 IDE로 대체할 수도 있다.

## 예시
- 로컬 폴더를 열었을 때 GitHub에서 보이던 폴더와 파일이 동일한지 확인한다.

## 요약
- 원격 저장소의 코드를 로컬 개발 환경에 준비한다.
- Cursor 사용은 필수가 아니며 핵심은 프로젝트 전체를 열 수 있는 IDE다.
