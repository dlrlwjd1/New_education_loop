# AI Product Manager Bootcamp

- **플랫폼**: Udemy
- **링크**: https://www.udemy.com/course/ai-product-manager-bootcamp

## 개요
AI 시대의 제품 관리자(AI Product Manager)를 위한 실습 중심 부트캠프. ChatGPT → Claude → Lovable을 거쳐 실제 프로덕션 제품 출시(shipping to production)까지 직접 빌드한다. 아이디어→검증에 수 주 걸리던 기존 방식을 수 시간으로 단축하는, 빠르고 검증 중심(fast & validated)의 AI 제품 개발 워크플로를 다룬다.

## 학습 경로
1. **ChatGPT** — 고급 프롬프트 엔지니어링, PRD 생성, 경쟁 분석, 의사결정 프레임워크
2. **Claude** — 아티팩트(artifacts) 기반 프로토타이핑, 데이터 분석
3. **Lovable** — 빠른 반복(가격 전략·테스트·온보딩 플로우)
4. **프로덕션 앱 빌드** — Cursor, Claude Code, MCP 서버, Subagents, Supabase, Vercel, GitHub, CI/CD
5. **캡스톤** — 컴플라이언스 트래커 앱(compliance tracker) 전체 구축
