# Service Types

## 개요
- 지금까지 앱 주변에 떠다니는 4가지 유형의 리소스를 살펴봤습니다 이 각각을 관리하기 위해 디자인할 다양한 서비스를 살펴보도록 총 5개의 다른 서비스가 될 거예요

## 내용
### 자막·본문 기반 핵심 내용
- 지금까지 앱 주변에 떠다니는 4가지 유형의 리소스를 살펴봤습니다 이 각각을 관리하기 위해 디자인할 다양한 서비스를 살펴보도록 총 5개의 다른 서비스가 될 거예요
- 인증 서비스가 있을 겁니다 간단히 중단시키죠 이 서비스는 사용자 인증과 관련된 모든 것에 비용을 청구하죠
- 로그인, 로그인, 로그아웃 그런 거죠 다음은 티켓 서비스예요 예상하시겠지만 티켓 제작이나 편집과 관련이 있을 거예요
- 이 매표소는 매표소에 대해 속속들이 알고 있죠 그러니 가격을 알 거예요 티켓을 업데이트할 수 있는지 등을 알 수 있어요

### 구현 요소
