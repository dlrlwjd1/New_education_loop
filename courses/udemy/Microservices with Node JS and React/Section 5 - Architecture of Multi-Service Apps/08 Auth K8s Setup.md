# Auth K8s Setup

## 개요
- 이 디렉터리 안에 Dot Docker라는 다른 파일을 만들게요 Docker 안은 무시하세요

## 내용
### 자막·본문 기반 핵심 내용
- 이 디렉터리 안에 Dot Docker라는 다른 파일을 만들게요 Docker 안은 무시하세요
- 이미지를 빌드하려면 Docker 파일을 작성해야 하는 걸 기억하세요 오프 디렉터리 안에서 Docker 파일이란 새 파일을 만들게요
- app:\라는 라벨이 붙은 모든 포드를 찾아야 해요 선택기로 app: auth를 입력하는 거죠
- 이 배열 안에 항목이 하나 있어요 배열 엔트리를 나타내는 작은 대시를 넣을게요 컨테이너에 auth 이름을 붙일게요.

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `Docker`, `json`, `npm`, `API`, `Docker ID`
