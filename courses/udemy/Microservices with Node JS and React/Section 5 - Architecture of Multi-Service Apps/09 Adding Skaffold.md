# Adding Skaffold

## 개요
- 오프의 컨텍스트를 열거할게요 Docker 파일을 사용하도록 지정할게요 Docker, Docker 파일 도커 파일을 입력하죠

## 내용
### 자막·본문 기반 핵심 내용
- 오프의 컨텍스트를 열거할게요 Docker 파일을 사용하도록 지정할게요 Docker, Docker 파일 도커 파일을 입력하죠
- push of false와 함께 로컬을 넣죠 다시 한 번 이미지를 빌드할 때마다 Docker Hub 같은 것으로 푸시하려 하지 말라는 겁니다 기본 동작이니까요
- 스캐폴드 구성 파일을 만들기 위해 루트 프로젝트 디렉터리를 찾고 그 안에 Sc캐폴드 .yaml 같은 다른 파일을 만들 거예요
- 스캐폴드/V2, 알파3의 API 버전을 넣을 거예요 일종의 구성이죠 배포 구역을 설정할게요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `yaml`, `API`, `Docker`, `Docker Hub`, `Docker ID/auth`
