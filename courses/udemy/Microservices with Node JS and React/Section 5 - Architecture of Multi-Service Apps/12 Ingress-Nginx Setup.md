# Ingress-Nginx Setup

## 개요
- Git에서 할 거예요 API 사용자의 현재 루트에 대한 요청을 듣고 싶어요 API 사용자의 현 사용자죠

## 내용
### 자막·본문 기반 핵심 내용
- Git에서 할 거예요 API 사용자의 현재 루트에 대한 요청을 듣고 싶어요 API 사용자의 현 사용자죠
- 필수 명령을 실행하세요 그런 다음 Mac의 Docker를 실행해요 Windows 옵션의 Docker 또는 미니 일단 설치가 끝나면요
- 슬래시 API 경로를 줄 거예요 그 말은 누군가 클러스터에 요청을 할 때마다 그 요청에 API/유저/모든 게 포함된다는 거죠 그럼 그 요청을 이 목록에 보낼 겁니다 백엔드에요
- 아주 쉬운 단어예요 인그레스 클래스는 엔진 X예요 엔진 x.인그레스.kubernetes. io/s reg x의 true를 사용하세요 true는 따옴표 안에 있어야 한다는 걸 전체적인 주석이 엔진 X에게 말하고 있다는 걸 잊지 마세요 우리가 리스트를 만들 경로가 다르다는 것을요 파일 하단의 절반은 그 안에 정규식이 사양 섹션을 같이 보죠
