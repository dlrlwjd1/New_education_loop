# App Overview

## 개요
- 스텁허브와 비슷한 걸 만들 거예요 StubHub에 관련된 속성 몇 가지를 간단히 소개할게요

## 내용
### 자막·본문 기반 핵심 내용
- 스텁허브와 비슷한 걸 만들 거예요 StubHub에 관련된 속성 몇 가지를 간단히 소개할게요
- 이 비디오에선 다음에 다룰 큰 응용 프로그램을 개요로 살펴보죠 다음 응용 프로그램은 우리가 방금 만든 것보다 훨씬 더 커요
- 훨씬 복잡하고 서비스도 많죠 연에서는 모든 게 더 커요 먼저 이미 존재하는 다른 응용 프로그램에 대해 간략히 설명할게요
- 이 앱을 들어보셨을 수도 있고 모르셨을 수도 있어요 미국에서는 스텁허브라고 부르는 게 꽤 인기 있어요 사용자가 스포츠 경기나 콘서트 표를 다른 사용자에게 파는 거죠
