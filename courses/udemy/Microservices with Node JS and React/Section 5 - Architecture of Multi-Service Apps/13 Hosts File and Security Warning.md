# Hosts File and Security Warning

## 개요
- Ingress 엔진 X를 위한 구성을 만들었어요 이제 로컬 컴퓨터에서 호스트 파일을 열어 언제든 div 티켓팅으로 탐색할 수 있도록 할게요 온라인이나 인터넷에 있는 진짜 티켓팅 개발자로 가는 대신 로컬 컴퓨터로 리디렉션해 Ingress 엔진 X 서버에 액세스하는 거죠

## 내용
### 자막·본문 기반 핵심 내용
- Ingress 엔진 X를 위한 구성을 만들었어요 이제 로컬 컴퓨터에서 호스트 파일을 열어 언제든 div 티켓팅으로 탐색할 수 있도록 할게요 온라인이나 인터넷에 있는 진짜 티켓팅 개발자로 가는 대신 로컬 컴퓨터로 리디렉션해 Ingress 엔진 X 서버에 액세스하는 거죠
- 루트 처리기로 가고 싶어요 조금 전에 auth 프로젝트에서 함께 만든 거죠 구체적으로 티켓팅. Dev/ API 사용자, 현재 사용자의 루트로 가보죠
- 그러기 위해 호스트 파일을 열게요 이 macOS나 Linux에 있다면 호스트 파일이 Etsy/ host이고 그게 실제 파일이에요
- 그게 여기 루트 처리기에 엑세스하는 방법이죠 브라우저로 가서 바로 해 보죠 티켓팅. dev/ API 사용자로 갈게요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `Ingress`, `API`, `HTTPS`
