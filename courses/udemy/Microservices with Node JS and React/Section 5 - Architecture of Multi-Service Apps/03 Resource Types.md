# Resource Types

## 개요
- 이 애플리케이션의 목적을 살펴본 것 같아요 이제 몇 개의 비디오를 통해 애플리케이션의 디자인을 살펴볼게요

## 내용
### 자막·본문 기반 핵심 내용
- 이 애플리케이션의 목적을 살펴본 것 같아요 이제 몇 개의 비디오를 통해 애플리케이션의 디자인을 살펴볼게요
- 먼저 서로 다른 데이터 조각들에 대해 알아보겠습니다 이것을 구현하기 위해 저장해야 하는 것들이죠
- 그러니까 총 네 가지 유형의 리소스가 되는 거죠 먼저 테이블이나 컬렉션 사용자의 저장소를 보겠습니다 여러분의 게스트가 앱에 등록한 모든 사용자를 저장하는 거죠
- 그리고 사용자마다 이메일과 비밀번호를 저장하겠죠 이게 각 사용자에 대한 거의 다예요 티켓 컬렉션이나 티켓 표가 있고 이 레코드들은 누군가 사거나 팔려는 단일 티켓을 나타내요

### 구현 요소
- 강의 흐름에 따라 Resource Types의 구현 목적과 적용 지점을 확인한다.
