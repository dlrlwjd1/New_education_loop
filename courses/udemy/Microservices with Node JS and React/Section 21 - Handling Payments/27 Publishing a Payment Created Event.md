# Publishing a Payment Created Event

## 개요
- 제가 이 다이어그램을 처음 만들었을 때 지불금 수금 요금이라고 부르려고 그런데 이런 비디오를 보다 보니 이 컬렉션 요금 청구와 스트라이프 API를 호출하는 게 정말 헷갈리더군요

## 내용
### 자막·본문 기반 핵심 내용

- 줄무늬도 있어요 D요 실로 연결할 수 있어요 현재 저희 응용 프로그램의 다른 부분은 스트라이프 ID 같은 게 필요하지 않아요 스트라이프 API에 도달할 수 있는 앱의 다른 부분이 없으니까요
