# Implementing the Create Charge Handler

## 개요
- 급행 닷 라우터로 새 라우터를 만드세요 그런 다음 post request handler를 이것과 연결해요

## 내용
### 자막·본문 기반 핵심 내용
- 급행 닷 라우터로 새 라우터를 만드세요 그런 다음 post request handler를 이것과 연결해요
- 이게 복제본이에요 국을 좀 손볼게요 이걸 API 결제로 바꿀게요 API 결제 요청이 들어올 때마다 CRV 플러스나 EIP 서비스로 결제 요청을 보내고 싶어요
- 이런 수입 제품은 대부분 바로 눈에 익을 거예요 Express를 불러오겠습니다 Express에서 요청과 응답 유형도요
- 그런 다음 지불 서비스에서 해당 토큰을 스트라이프 API에 후속 요청을 합니다 사용자의 신용카드를 청구하기 위해서요
