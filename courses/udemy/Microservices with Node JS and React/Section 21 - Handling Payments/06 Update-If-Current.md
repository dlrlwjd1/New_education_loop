# Update-If-Current

## 개요
- 주문에서 이동하기 전에 mongoose 업데이트를 추가하고 싶어요 현재 플러그 인이 있다면 이렇게 하면 모든 이벤트들을 올바른 순서로 프로세스 할 수 있어요

## 내용
### 자막·본문 기반 핵심 내용
- 주문에서 이동하기 전에 mongoose 업데이트를 추가하고 싶어요 현재 플러그 인이 있다면 이렇게 하면 모든 이벤트들을 올바른 순서로 프로세스 할 수 있어요
- 단말기를 백업하고 지불금 디렉터리로 바꾼 다음 Mongoose 업데이트를 모듈이 아주 작아서 금방 설치될 거예요
- 라틴어는 순서대로 된 스키마 세트예요 버전 키를 버전으로 설정해야죠 그건 Mongoose를 오버라이드하고 밑줄 v 플래그를 사용하지 말라고 하는 걸 기억하세요
- 그런 다음 모델 파일로 돌아가죠 만약 현재 플러그 인이라면 import문을 추가할 거예요.

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `mongoose`
