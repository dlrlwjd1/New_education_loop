# A More Realistic Test Setup

## 개요
- 키를 누르고 제 API 키를 변수에 할당할 거예요 스트라이프 대시보드에서 얻으실 수 있어요 개발자와 API 키로 가시면 비밀 키가 저기 보이죠

## 내용
### 자막·본문 기반 핵심 내용
- 키를 누르고 제 API 키를 변수에 할당할 거예요 스트라이프 대시보드에서 얻으실 수 있어요 개발자와 API 키로 가시면 비밀 키가 저기 보이죠
- 어떻게 하면 될까요? 스트라이프 API를 다시 살펴보죠 스트라이프 API 문서로 돌아가죠
- 이 다른 방법으로는 테스트, 환경, 라우트 핸들러에 실제 스트라이프 API와 직접 통신하게 할 거예요
- 현실적인 접근의 단점은 이런 테스트가 실행되려면 좀 더 오래 걸린다는 겁니다 진짜 스트라이프 API에 요청해야 하니까요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `API`
