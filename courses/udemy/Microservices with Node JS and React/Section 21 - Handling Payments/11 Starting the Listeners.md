# Starting the Listeners

## 개요
- 파일을 저장한 다음 스캐폴드로 돌아가죠 잔돈은 여기 있어요 제 경우 NATS 스트리밍 서버를 다시 시작한 것 같네요 이 비디오 직전에요 혹은 그 후로는 어떤 주문도 생성하지 않았죠 그래서 여기 아무것도 없는 거예요

### 자막·본문 기반 핵심 내용

- 두 청취자를 한자리에 모았네요 아직 끝난 게 아니에요 응용 프로그램이 처음 시작될 때마다 수신 이벤트에 귀를 기울이도록 인스턴스를 생성해야 한다는 걸 기억하세요
