## 내용
### 자막·본문 기반 핵심 내용
- 그 말은 우리가 해당 환경 변수에 접근할 수 없다는 거죠 진짜 스트라이프 API에 도달할 수 있도록 하려면 테스트를 실행할 때 API 키에 액세스가 있도록 해야 해요
- 이걸 하는 유일한 이유는 실제 루트 처리기 내부 때문이죠 우리가 기대하는 건 create를 호출하면 어떤 종류의 promise를 받게 되고 그 promise가 해결되기를 기다리는 거죠
- 주문을 저장한 후 실제 요청을 할 거예요 await request to app을 하죠
- CRC 디렉터리 내부에 MOX 폴더가 있습니다 그리고 이미 모조된 Nets 스트라이프 파일에도 비슷한 모의 모형을 만들 수 있어요 여기 이것과 같은 API를 가진 모의 개체를 내보내도록 할 수 있죠
