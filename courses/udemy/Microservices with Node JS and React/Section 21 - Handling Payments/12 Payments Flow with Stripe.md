# Payments Flow with Stripe

## 개요
- 이 비디오에서는 API의 개요를 살펴보겠습니다 사용자로부터 오는 진짜 신용카드 결제를 처리하기 위해서요

## 내용
### 자막·본문 기반 핵심 내용
- 이 비디오에서는 API의 개요를 살펴보겠습니다 사용자로부터 오는 진짜 신용카드 결제를 처리하기 위해서요
- 하지만 현재로선 React Application 같은 건 연구하지 않았죠 지금 처리하는 건 인증의 이상적인 거죠
- 어떤 순간에도 신용카드 번호를 직접 다루고 싶지는 않아요 스트라이프 API가 하는 일이 그거죠
- 사용자는 신용카드 세부 정보를 입력하고 제출을 클릭하면 스트라이프 JS 라이브러리가 신용카드 세부 정보를 스트라이프 API로 보낼 거예요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `API`, `JavaScript`, `React`

## 예시
`API`, `JavaScript`, `React`가 등장하는 설정·코드 위치를 찾아 강의와 같은 순서로 확인한다.
