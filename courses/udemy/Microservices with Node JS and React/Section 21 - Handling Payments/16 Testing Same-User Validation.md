# Testing Same-User Validation

## 개요
- 여기 중간쯤에 전역 기호 함수가 있어요 가장 먼저 할 일은 사용자 또는 페이로드를 만들어 임의의 ID로 JSON 웹 토큰에 고정하는 거죠

## 내용
### 자막·본문 기반 핵심 내용
- 여기 중간쯤에 전역 기호 함수가 있어요 가장 먼저 할 일은 사용자 또는 페이로드를 만들어 임의의 ID로 JSON 웹 토큰에 고정하는 거죠
- 다시 한 번 16진수 문자열에 대한 mongoose 유형 개체 ID가 되겠죠 그러면 새로운 주문을 생성하고 주문 자체에 대한 사용자 ID를 할당할 수 있습니다.
- 구매 요청을 할 수 있어요 요청을 할 때 해당 로그인 함수에 우리가 생성한 사용자 ID를 대기 요청 앱이 API 결제에 게시 요청을 만들어요
- 여기서 공기가 나오는 게 보이실 텐데요 아마 TypeScript가 약간 화난 것 때문일 이걸 저장하고 다시 로드할게요

### 구현 요소
