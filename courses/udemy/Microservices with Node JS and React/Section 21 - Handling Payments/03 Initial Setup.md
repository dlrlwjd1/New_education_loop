# Initial Setup

## 개요
- Docker 파일 패키지 json nts config는 무시하세요 이걸 다 복사해서 결제에 붙여넣을 거예요

## 내용
### 자막·본문 기반 핵심 내용
- Docker 파일 패키지 json nts config는 무시하세요 이걸 다 복사해서 결제에 붙여넣을 거예요
- Docker 이미지가 어떤지 보죠 다 만든 것 같아요 Docker Hub로 밀어 넣으세요
- 제 단말기로 돌아왔네요 할부로 바꿀게요 Docker ID에 Docker 빌드를 하죠
- 우리는 MongoDB 데이터베이스가 필요하고 이 두 레코드의 속성을 확장할 것이라고만 지불금 배포에 덧붙여서 MongoDB 복사본을 만들어 보도록 할게요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `Docker`, `json`, `YAML`, `MongoDB`, `Docker ID`, `Docker Hub`, `Docker push`

## 예시
`Docker`, `json`, `YAML`, `MongoDB`, `Docker ID`가 등장하는 설정·코드 위치를 찾아 강의와 같은 순서로 확인한다.
