# Stripe Setup

## 개요
- 노드를 설치할 거예요 js 스트라이프 SDK요 이건 본질적으로 NPM 모듈입니다 스트라이프 API와 쉽게 통신할 수 있도록 코드가 내장돼 있죠

## 내용
### 자막·본문 기반 핵심 내용
- 노드를 설치할 거예요 js 스트라이프 SDK요 이건 본질적으로 NPM 모듈입니다 스트라이프 API와 쉽게 통신할 수 있도록 코드가 내장돼 있죠
- API 키도 포함시킬 겁니다 스트라이프 API까지 우리 응용 프로그램을 식별하는 키죠
- 사실 꽤 안정적인 API로 유명해요 그래서 이 페이지에선 좀 달라 보여도 괜찮을 겁니다 API 자체가 아주 안정적이거든요
- 이메일 주소 확인을 클릭하세요 계정을 확인하고 나면 Get Test API 키를 클릭할 거예요
