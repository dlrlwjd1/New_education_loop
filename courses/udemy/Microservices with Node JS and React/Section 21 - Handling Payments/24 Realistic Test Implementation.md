# Realistic Test Implementation

## 개요
- 유효하지 않은 토큰을 테스트하기가 힘들 수 있어요 API를 조롱하는 거라면요 API 반응을 해석하는 방법을 모를 수도 있고 유효하지 않은 토큰을 주면 API가 어떻게 반응할지 좀 더 현실적인 실험은 여기까지예요

## 내용
### 자막·본문 기반 핵심 내용
- 유효하지 않은 토큰을 테스트하기가 힘들 수 있어요 API를 조롱하는 거라면요 API 반응을 해석하는 방법을 모를 수도 있고 유효하지 않은 토큰을 주면 API가 어떻게 반응할지 좀 더 현실적인 실험은 여기까지예요
- 라우트 처리기가 Gest API나 스트라이프 API로 정전을 생성하면 무작위로 생성된 양을 100배 넣게 돼요
- 친구들 이제 계획이 생겼어요 즉 테스트 파일 대신에 순서를 생성할 때 순서의 금액이나 가격을 무작위로 생성할 스트라이프 API로 가면 특정 양을 위한 양이 있어야 하죠
- 우리가 제시하는 가격은 순서에 따라 달러 단위라는 걸 기억하세요 스트라이프 API로 전송되는 비용은 단위 센트로 계산되죠
