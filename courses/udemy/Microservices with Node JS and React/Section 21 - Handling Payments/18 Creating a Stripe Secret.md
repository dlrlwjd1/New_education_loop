# Creating a Stripe Secret

## 개요
- 스트라이크 API를 위해 등록했는데 이제 이 API 키 페이지에서 게시 가능한 키와 비밀 키를 둘 다 볼 수 있어요

## 내용
### 자막·본문 기반 핵심 내용
- 스트라이크 API를 위해 등록했는데 이제 이 API 키 페이지에서 게시 가능한 키와 비밀 키를 둘 다 볼 수 있어요
- 비밀 열쇠는 우리 프로젝트 안에서 사용하고자 하는 거죠 스트라이프 API에 접근해 사용자의 신용카드를 결제하게 해주죠
- 이건 우리가 과거에 다뤘던 거예요 쿠버네츠 클러스터 안에 비밀 정보나 개인 키를 저장하기 위해 비밀이란 개체를 만들 수 비밀은 비밀 정보를 저장하는 데 사용됩니다 여기 있는 API 키처럼요
- 이 폴더 안에 결제금 배포가 나와 있어요 그런 다음 환경 섹션으로 스크롤을 이 안에 이미 JSON Web 토큰이 있는 게 보이시죠

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `API`, `JSON`
