# Don't Cancel Completed Orders!

## 개요
- 우리 탐색의 완전한 애청자에 작은 변화가 하나 더 있어요 지금은 메일이 올 때마다 해당 주문을 찾아서 항상 취소라고 표시해 둘 거예요

## 내용
### 자막·본문 기반 핵심 내용
- 우리 탐색의 완전한 애청자에 작은 변화가 하나 더 있어요 지금은 메일이 올 때마다 해당 주문을 찾아서 항상 취소라고 표시해 둘 거예요
- 이미 지불된 주문을 받아들일 수도 있고 완료라고 표시돼 있어도 취소할 수도 있어요
- 주문 상태 속성을 볼게요. 만약 이게 주문 상태. complete와 같다면 얼리 액트 메시지를 리턴할게요. 왜냐하면 이 취소 이벤트와 관련된 어떤 것도 하고 싶지 일찍 돌아가 메시지를 전달할게요
- 여기 작은 확인을 추가해야 해요 그리고 확인을 한 직후에 지불한 주문을 취소하려고 하면 안 되죠 주문이 들어왔다는 걸 확인하기 위해서요

### 구현 요소
- 강의 흐름에 따라 Don't Cancel Completed Orders!의 구현 목적과 적용 지점을 확인한다.
