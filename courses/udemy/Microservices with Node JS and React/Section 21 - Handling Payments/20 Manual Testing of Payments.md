# Manual Testing of Payments

## 개요
- 새 탭을 열게요 HTTPS 티켓팅에 게시 요청을 할 거예요 d dev/ API/계산금이죠

## 내용
### 자막·본문 기반 핵심 내용
- 새 탭을 열게요 HTTPS 티켓팅에 게시 요청을 할 거예요 d dev/ API/계산금이죠
- 스트라이프 API에 관해 아셔야 할 게 있어요 스트라이프 대시보드로 돌아갈게요 여기 있네요
- 계정이 테스트 모드인 동안에는 실제 돈으로는 어떤 일도 할 수 없어요 API 요청을 만들 수 있어요
- 스트라이프 API로 항상 성공할 수 있는 아주 특별한 토큰이 있어요 비밀 탈출구나 지름길 같은 거죠 우리가 제공할 수 있는 특정 토큰은 언제나 성공적인 충전으로 이어지고요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `API`, `HTTPS`, `JSON`
