# Another Order Model!

## 개요
- 이 안에서 CRC 폴더를 찾아 Model이라는 새 디렉터리를 만들게요 그 안에 평소처럼 Order이라는 새로운 파일을 만들게요.

## 내용
### 자막·본문 기반 핵심 내용
- 이 안에서 CRC 폴더를 찾아 Model이라는 새 디렉터리를 만들게요 그 안에 평소처럼 Order이라는 새로운 파일을 만들게요.
- 이건 문자열이 될 거예요 OrderService를 다시 떠올려 보면 OrderModel을 정의할 때 약간의 트릭을 사용했습니다. 우리가 제공하는 status 값은 OrderEnum에 있는 값 중 하나였죠.
- 실제 모델 자체를 정의하는 순간 순서가 바뀔 거예요 말 나온 김에 지금 하죠 주문은 mongoose.Model이 되겠죠
- 맨 위에 있는 ORDER status enum을 불러올게요. 일반 모듈에서 나와서 이렇게 열거를 사용하죠

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `Model`, `Mongoose`, `enum`, `TypeScript`, `JSON`
