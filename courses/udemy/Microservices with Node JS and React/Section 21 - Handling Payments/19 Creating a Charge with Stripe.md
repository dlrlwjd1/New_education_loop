# Creating a Charge with Stripe

## 개요
- API 버전을 입력할 거예요 API 버전을 위한 문자열을 입력하면 자동 완성 팝업이 뜰 수도 있어요

## 내용
### 자막·본문 기반 핵심 내용
- API 버전을 입력할 거예요 API 버전을 위한 문자열을 입력하면 자동 완성 팝업이 뜰 수도 있어요
- API 키가 클러스터 내부에 모두 설정됐어요 스트라이프 라이브러리도 우리 대금 프로젝트에 설치했고요
- 첫 번째 인수는 API 키가 될 겁니다 이미 연결한 거 기억하시죠? 프로세스 EMV. 스트라이프 _키로 우리 프로젝트 안에서 접근 가능하죠
- 늘 그렇듯 TypeScript는 우리가 이 환경 변수를 제대로 정의했다고 믿지 않아요

### 구현 요소
