# Test-Suite Wide Mocks

## 개요
- indexed 테스트로 가서 맨 위에 붙여넣기를 하고 다른 두 개에서도 반복할 수 있어요.

## 내용
### 자막·본문 기반 핵심 내용
- indexed 테스트로 가서 맨 위에 붙여넣기를 하고 다른 두 개에서도 반복할 수 있어요.
- 다양한 테스트 파일로 가서 모의 호출을 설정하도록 하겠습니다 진짜와는 반대로 가짜 구현을 할 수 있도록요
- 새 테스트 파일로 가보죠 제시 맥클레인한테 복사본을 주고 다른 테스트 루트 핸들러 파일도 찾아볼게요
- .Nets 래퍼로 설정할 거예요 우리 전체 프로젝트의 모든 다양한 테스트가 항상 실용적이거나 나탈의 가짜 버전을 사용하도록 하는 거죠

### 구현 요소
- 강의 흐름에 따라 Test-Suite Wide Mocks의 구현 목적과 적용 지점을 확인한다.

## 예시
