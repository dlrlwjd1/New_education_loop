## 내용
### 자막·본문 기반 핵심 내용
- 이 타이틀은 티켓에 있는 타이틀과 같아요 꼭 그렇진 않아요 Mongoose로 Pre와 post 저장 훅을 실행할 수 있다는 걸 기억하세요
- 우리가 만든 티켓으로 발행인을 만들었어요 루트 디렉터리로 가서 새 루트 처리기를 찾죠
- 방금 말씀드린 것처럼 티켓을 생성하고 데이터베이스에 저장한 직후에 이벤트를 게시자를 이 파일로 불러와 이벤트를 게시하죠
- 생성된 퍼블리셔 티켓을 수입할 거예요 한 디렉터리 이벤트 게시자에서요 티켓 생성 발행인이죠
