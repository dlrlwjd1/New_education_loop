# Graceful Shutdown

## 개요
- 부팅되는 동안에요 저기 냇과 연결되어 있네요 포트 3000에서 MongoDB에 연결된 커넥션이 있고요

## 내용
### 자막·본문 기반 핵심 내용
- 부팅되는 동안에요 저기 냇과 연결되어 있네요 포트 3000에서 MongoDB에 연결된 커넥션이 있고요
- Nets 테스트 프로젝트 내부의 리스너 파일을 살펴보고 있어요 이 안에서 기억하시겠지만 우리 프로세스가 신호 방해든 신호 종료든 중단되기 직전에 클라이언트를 우아하게 닫으려 했다고 했죠
- 가까이 서라고 했죠 고객은 문을 닫으려 하겠죠 일단 닫히면 닫힌 사건을 방출하죠 그 근접 이벤트를 캡처했죠
- 성공적으로 세척되었다는 걸 확인한 다음 프로세스를 종료하는 거죠 티켓팅 프로젝트에서도 비슷한 걸 할 거예요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `MongoDB`, `TS`

## 예시
`MongoDB`, `TS`가 등장하는 설정·코드 위치를 찾아 강의와 같은 순서로 확인한다.
