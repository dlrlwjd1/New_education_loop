# Fixing a Few Tests

## 개요
- 저희는 jest 테스트 러너와 Jest 라이브러리를 사용하고 있습니다 테스트 도구 모음 안에서도 멋진 기능으로, import문을 리다이렉트 합니다. 테스트 환경에서 응용프로그램을 실행하는 동안에요.

## 내용
### 자막·본문 기반 핵심 내용
- 저희는 jest 테스트 러너와 Jest 라이브러리를 사용하고 있습니다 테스트 도구 모음 안에서도 멋진 기능으로, import문을 리다이렉트 합니다. 테스트 환경에서 응용프로그램을 실행하는 동안에요.
- 잠시 워밍업을 한 후에 결과를 보도록 하죠 실패작이 너무 많아요 하지만 이런 오류의 대부분은 연결 전에 NAT 클라이언트에 엑세스해서 발생하는 것으로 Mongoose Air 주변에 다른 것도 있지만 지금 말씀드리고 싶은 건 이것들은 근본적으로 던지고 있다는 겁니다 실패한 Nets 클라이언트 때문에요
- 다른 해결책이 있을 거예요 하지만 이렇게 할 거예요 jest 안에 멋진 기능을 사용할 거예요
- 그 안에 가짜 초기화된 Nets 클라이언트가 있어요 제가 fake 초기화된 nets 클라이언트라고 한 건 정말 fake란 뜻이에요
