# Redirecting Imports

## 개요
- 아래로 내려가면 NATS 래퍼의 단일 이름의 내보내기를 보여줍니다 클래스의 인스턴스 혹은 개체의 인스턴스가 되겠죠

## 내용
### 자막·본문 기반 핵심 내용
- 아래로 내려가면 NATS 래퍼의 단일 이름의 내보내기를 보여줍니다 클래스의 인스턴스 혹은 개체의 인스턴스가 되겠죠
- NATS 래퍼를 만들거나 내보낼 수 없죠 이게 우리가 내보낼 객체예요 즉 가짜 구현을 쓰거나 이 객체 안의 진짜 내용 대신에 코드를 실행시킬 수 있는 것이죠.
- 우리 경우엔 위조하고 싶은 파일이죠 루트 CRC 디렉터리 내부의 우리 넷 래퍼 파일이죠
- 우리 경우엔 나탈의 포장지를 위조, 중복, 리다이렉트 하려는 거죠 __nerscore mock 안에 동일한 이름을 가진 파일을 만드는 거죠

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `TS`, `NATS`

## 예시
`TS`, `NATS`가 등장하는 설정·코드 위치를 찾아 강의와 같은 순서로 확인한다.
