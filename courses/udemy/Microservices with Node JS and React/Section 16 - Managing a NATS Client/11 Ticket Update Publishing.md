## 내용
### 자막·본문 기반 핵심 내용
- TypeScript는 이 안에 추가할 다양한 속성에 대한 가이드예요 티켓 타이틀 가격의 ID와 사용자 ID를 다시 입력해야 해요
- 가장 먼저 해야 할 일은 Events Publchers 디렉터리로 가는 것이죠 이 안에 새 파일을 만들 거예요 티켓 업데이트 공개자라는 거죠
- 티켓 크리에이티브 출판사는 이제 확실히 일을 하고 있어요 이와 유사한 프로세스를 진행할 거예요 티켓을 업데이트하는 것도 처리할 새 게시자를 만들 거예요
- 처음부터 모든 코드를 작성할 수 있어요 아니면 티켓과 관련된 게시자의 복사 붙여넣기를 할 수도 있어요
