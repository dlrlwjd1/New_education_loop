# NATS Env Variables

## 개요
- NATS에 연결된 제 티켓 서비스의 복사본들이 어디 있는지 알고 싶어요 각각이 뭘 하는지요 클라이언트 ID에 의미 있는 값이 있다면 그게 가장 쉬울 거예요 무작위로 생성된 값과는 반대로요

## 내용
### 자막·본문 기반 핵심 내용
- NATS에 연결된 제 티켓 서비스의 복사본들이 어디 있는지 알고 싶어요 각각이 뭘 하는지요 클라이언트 ID에 의미 있는 값이 있다면 그게 가장 쉬울 거예요 무작위로 생성된 값과는 반대로요
- 여기가 전에 Mongo URI와 JSON Web 토큰 키 환경 변수를 지정했던 곳이죠
- 상당한 노력을 들여 JWT 키와 Mongo URI를 위한 분명한 연결 변수 같은 걸 환경 변수에 추출했어요
- 배포 파일 안에 이름을 추가할 거예요 http 네트의 값도요 CRV 포트나 2-2-2요

### 구현 요소
