## 내용
### 자막·본문 기반 핵심 내용
- TypeScript는 우릴 안내하고 우리가 뭘 잘못하고 있는지 말해주려 하죠 이걸 마우스로 가리키면 어떤 주제를 정의해야 한다고 하네요
- 공용 라이브러리를 업데이트했죠 이벤트를 생성하고 듣는 것과 관련된 모든 티켓 서비스가 공동 라이브러리를 위해 사용하는 버전을 업데이트했죠
- 티켓 서비스는 모든 이벤트에도 접근할 수 있죠 이 비디오에서 가장 먼저 집중할 것은 누군가가 티켓 서비스에 게시 요청을 해서 새 티켓을 생성할 때 확인하는 거예요
- 특히 여기 이 새 처리기가 티켓을 생성하도록 할 거예요 데이터베이스에 티켓을 그 직후에 이벤트를 게시해야죠 우리 응용 프로그램 내의 모든 서비스에 누군가 새 티켓을 만들었다고 말하는 이벤트요
