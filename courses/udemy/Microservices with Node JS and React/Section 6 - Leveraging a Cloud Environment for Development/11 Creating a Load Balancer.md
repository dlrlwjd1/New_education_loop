# Creating a Load Balancer

## 개요
- 여전히 Mac이나 Windows용 Docker를 실행 중이라면 쿠버네츠 메뉴를 열어 GCC나 Google 쿠버네츠 엔진 컨텍스트에 연결됐는지 확인하세요

## 내용
### 자막·본문 기반 핵심 내용
- 여전히 Mac이나 Windows용 Docker를 실행 중이라면 쿠버네츠 메뉴를 열어 GCC나 Google 쿠버네츠 엔진 컨텍스트에 연결됐는지 확인하세요
- Ingress Gen X가 하는 일을 간략히 알려드릴게요 이 단계가 정말 의미하는 게 뭔지도요
- Ingress Controller에서 처음 생성됐죠 클러스터 내부에서 실행되는 게 이겁니다 라우팅 규칙 몇 가지가 관련돼 있죠
- Google Cloud나 Microsoft Azure 같은 거요 방금 실행한 명령이 우릴 위해 두 가지를 생성했어요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `Docker`, `Ingress`
