# Final Config and Test

## 개요
- 이 안을 들여다보면 작업 디렉터리 설정이나 패키지 JSON 파일 복사 NPM 설치 등이 보이죠

## 내용
### 자막·본문 기반 핵심 내용
- 이 안을 들여다보면 작업 디렉터리 설정이나 패키지 JSON 파일 복사 NPM 설치 등이 보이죠
- 제 단말기로 돌아갈게요 여전히 실행 중인 스캐폴드 이전 버전을 종료하도록 할게요 그런 다음 쿠버네티스나 Docker 창으로 가서 올바른 컨텍스트가 여전히 선택됐는지 그런 다음 루트 프로젝트 디렉터리 안에서 스캐폴드 개발을 하죠
- Docker 허브를 더는 사용하지 않아요 이미지가 빌드되면 스캐폴드는 배포, 서비스를 생성하려고 시도할 겁니다 Google 클라우드 클러스터에 수신 규칙을 적용하고요
- API 사용자와 현재 사용자죠 그 경로를 따라가야 해요 새 탭 안쪽에 있는 URL 붙여넣기를 쓸게요
