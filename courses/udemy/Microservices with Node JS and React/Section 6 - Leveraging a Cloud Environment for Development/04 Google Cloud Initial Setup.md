# Google Cloud Initial Setup

## 개요
- 그런 다음 우측 상단에 New Project를 클릭할게요 LC는 이런 창문이 좋아요

## 내용
### 자막·본문 기반 핵심 내용
- 그런 다음 우측 상단에 New Project를 클릭할게요 LC는 이런 창문이 좋아요
- 새 프로젝트 이름을 만들게요 티케팅 대시 dev 같은 걸로요 Create를 클릭할게요.
- 이 영상에서는 구글 클라우드 계정을 새로 만들 거예요 계정을 만들면 자동으로 무료 신용카드로 300달러가 생겨요
- 이미 구글 클라우드 계정을 만드셨다면 새 계정을 만드세요 300달러 크레디트를 무료로 받으시려면요 그럼 이 강좌에서 한 푼도 쓸 필요가 없죠

### 구현 요소
- 강의 흐름에 따라 Google Cloud Initial Setup의 구현 목적과 적용 지점을 확인한다.

## 예시
이미 구글 클라우드 계정을 만드셨다면 새 계정을 만드세요 300달러 크레디트를 무료로 받으시려면요 그럼 이 강좌에서 한 푼도 쓸 필요가 없죠
