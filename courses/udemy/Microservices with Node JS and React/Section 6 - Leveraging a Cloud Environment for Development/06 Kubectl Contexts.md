# Kubectl Contexts

## 개요
- 세계에 존재하는 다른 클러스터들과 어떻게 연결할 것인지에 대한 것들이죠 지금 우린 로컬 클러스터로 연결하고 있습니다 Windows용 Docker를 처음 설치했을 때 생성된 컨텍스트를 통해서요 여러분 컴퓨터의 Mac용 Docker도요

## 내용
### 자막·본문 기반 핵심 내용
- 세계에 존재하는 다른 클러스터들과 어떻게 연결할 것인지에 대한 것들이죠 지금 우린 로컬 클러스터로 연결하고 있습니다 Windows용 Docker를 처음 설치했을 때 생성된 컨텍스트를 통해서요 여러분 컴퓨터의 Mac용 Docker도요
- 현재 컨텍스트는 Docker Dash Desktop이죠 이 컨텍스트 안에 연결 설정이 있어요 로컬 클러스터에 연결하는 방법을 두 번째 컨텍스트를 추가해야 해요 CTL에 클러스터 연결 방법을 알려주는 새 컨텍스트요 Google 클라우드에서 방금 만든 거죠
- 사실, 지금 Docker 아이콘으로 가 쿠버넷테스에 마우스 오버하면 컨텍스트란 게 바로 보이죠
- Cube CTL에 적용되는 구성 옵션이 있어요 그런 구성 옵션을 변경하면 우리가 연결할 클러스터가 바뀌죠

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `Docker`, `Docker Dash Desktop`

## 예시
`Docker`, `Docker Dash Desktop`가 등장하는 설정·코드 위치를 찾아 강의와 같은 순서로 확인한다.
