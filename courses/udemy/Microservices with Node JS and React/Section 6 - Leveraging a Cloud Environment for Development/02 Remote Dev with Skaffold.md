# Remote Dev with Skaffold

## 개요
- 스캐폴드는 구글 클라우드 빌드라는 구글 클라우드에서 실행되는 서비스에 도달하죠 이 서비스는 docker 이미지 구축에 관한 겁니다 그래서 스캐폴드는 여러분 프로젝트에 대한 소스 코드를 모두 갖고 와 구글 클라우드에 업로드하겠죠 특정 프로젝트에 대한 Docker 그런 다음 구글 클라우드 빌드 프로세스가 우릴 위해 이미지를 빌드하죠

## 내용
### 자막·본문 기반 핵심 내용
- 스캐폴드는 구글 클라우드 빌드라는 구글 클라우드에서 실행되는 서비스에 도달하죠 이 서비스는 docker 이미지 구축에 관한 겁니다 그래서 스캐폴드는 여러분 프로젝트에 대한 소스 코드를 모두 갖고 와 구글 클라우드에 업로드하겠죠 특정 프로젝트에 대한 Docker 그런 다음 구글 클라우드 빌드 프로세스가 우릴 위해 이미지를 빌드하죠
- 지금은 인증 구역이 하나밖에 없어요 하지만 나중에는 여러 구역으로 브라우저를 열어 해당 노드에 액세스할 수 있어요 Ingress 엔진 X 서버를 사용해서요 지난 두어 비디오에서 구성했죠
- 이 도표 2개로 보여드리고 싶은 게 바로 그런 거예요 동으로 통에 삽입되지 않는 파일에 변화를 주면 어떻게 되는지 변화를 준다고 가정해 보죠 패키지 JSON 파일로요
- 패키지 JSON 파일을 변경할 때마다 오프 이미지를 완전히 재구축하고 클러스터 내부에서 대응 가능한 배포를 업데이트해야 한다는 뜻이에요
