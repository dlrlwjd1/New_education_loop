# Note on Remote Development

## 내용
### 자막·본문 기반 핵심 내용
- 브라우저에서 응용 프로그램에 접근할 수 있어요, 멋지죠 이 서버 개발을 계속하기 전에요
- 언급하고 싶은 게 있어요 이 영상과 그 직후의 영상들은 선택 섹션의 일부예요 이 볼 필요는 없지만 선택적인 섹션입니다 구글 클라우드를 통해 실행할 개발 환경을 설정하는 법을 배울 거예요
- 이걸 하는 이유는 나중에 이 응용 프로그램을 계속하면서 로컬 클러스터 안에서 실행되는 많은 다양한 포드를 보게 되기 때문이에요
- 오래된 컴퓨터라면 결국엔 많은 지연이나 크래시를 경험하게 될 겁니다 실행 중인 코드 양 때문에요
