# Installing the GCloud Context

## 개요
- 먼저 Docker 데스크톱을 닫습니다. 그러니 올라가서 종료 버튼을 누르세요. Docker 데스크탑을 실행한 다음 Google Cloud 또는 gcloud 구성 요소를 실행하여 kubectl을 설치합니다.

## 내용
### 자막·본문 기반 핵심 내용
- 먼저 Docker 데스크톱을 닫습니다. 그러니 올라가서 종료 버튼을 누르세요. Docker 데스크탑을 실행한 다음 Google Cloud 또는 gcloud 구성 요소를 실행하여 kubectl을 설치합니다.
- Docker를 계속 실행해도 괜찮거나 이 Docker 클라이언트를 계속 사용하고 싶다면, 대신 gcloud 컨테이너 클러스터 등을 실행하면 됩니다.
- Docker 데스크톱을 선택하겠습니다. 그리고 터미널에서 kubectl get pod를 실행합니다.
- 이 작업을 수행하는 방법은 사용자 측에서 약간의 결정을 내려야 합니다. 현재로서는 여전히 Mac용 Docker 또는 Windows용 Docker가 실행 중입니다.

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `Docker`, `Kubernetes`, `kubectl`, `pod`, `Docker Desktop`, `kubectl get pod`
