# Additional Deploy Files

## 개요
- GitHub/ workflow를 찾을 거예요 열어서 배포하고 HTML을 제공할 거예요

## 내용
### 자막·본문 기반 핵심 내용
- GitHub/ workflow를 찾을 거예요 열어서 배포하고 HTML을 제공할 거예요
- 정말 근사하네요 여기서 마지막으로 해야 할 것은 X세대에서의 네트워킹 외에 다른 모든 서비스로 가서 아주 유사한 배포 파일을 만들어야 이걸 GitHub에서 직접 바꿀 거예요 내장된 GitHub 편집기를 사용하죠
- 이 안에 다양한 배포 파일, 클라이언트 주문 티켓, 결제, 탐사를 만들 거예요 워크플로 안에서 deploy client HTML 파일을 만들게요.
- 워크플로 폴더에서 Off를 검색할 수 있고 deploy off와 테스트 오프의 결과만 찾을 수 있어요.

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `Docker`, `GitHub`, `workflow`, `YAML`, `Docker Hub`

## 예시
`Docker`, `GitHub`, `workflow`, `YAML`, `Docker Hub`가 등장하는 설정·코드 위치를 찾아 강의와 같은 순서로 확인한다.
