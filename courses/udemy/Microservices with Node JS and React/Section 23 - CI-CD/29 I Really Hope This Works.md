# I Really Hope This Works

## 개요
- 앱이 배포됐어요 변화를 주고 싶다면 절차가 중요해요 이미 여러 번 검토했어요 가지에 변화를 줄 거예요 그걸 GitHub에 밀어 넣고 끌어오기 요청을 만들어 마스터에 새 이미지가 클러스터에 빌드되고 적용되죠

## 내용
### 자막·본문 기반 핵심 내용
- 앱이 배포됐어요 변화를 주고 싶다면 절차가 중요해요 이미 여러 번 검토했어요 가지에 변화를 줄 거예요 그걸 GitHub에 밀어 넣고 끌어오기 요청을 만들어 마스터에 새 이미지가 클러스터에 빌드되고 적용되죠
- 난 15분, 20분 정도 됐어요 새 브라우저 탭을 열어 티켓팅 앱 제품 XYZ에서 제 응용 프로그램으로 탐색하겠습니다 새 브라우저를 열 수 있게요
- 저기서 탐색해 볼게요 보세요 앱이 정말 근사해 보이죠 보다시피 이 비디오는 전에 한두 번 녹화했어요 그래서 여기 제가 만든 티켓이 있죠
- 하지만 여기 오면 새 계정을 만들 수 있어요 새 계정을 만들 수 있을 거예요 티켓을 팔아서 이런 걸 넣을 수 있겠죠
