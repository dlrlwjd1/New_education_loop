# Reminder on Swapping Contexts

## 개요
- 노드를 선택하면 노드 하나만 보이죠 Docker 데스크톱 노드요 Docker Toolbox 같은 걸 쓰는 대신 Docker 데스크톱을 사용하신다면 언제든 트레이 아이콘으로 가서 여기서 컨텍스트를 선택하세요

## 내용
### 자막·본문 기반 핵심 내용
- 노드를 선택하면 노드 하나만 보이죠 Docker 데스크톱 노드요 Docker Toolbox 같은 걸 쓰는 대신 Docker 데스크톱을 사용하신다면 언제든 트레이 아이콘으로 가서 여기서 컨텍스트를 선택하세요
- 제 컴퓨터에서 실행 중인 로컬 Qubernetes 클러스터 사용으로 전환하고 싶다면 클러스터나 Docker 데스크톱 컨텍스트 이름을 사용하거나 Docker 데스크톱을 위한 컨텍스트 이름을 사용할 수 있어요
- 둘 다 괜찮아요 로컬 클러스터로 다시 전환하려면 컨텍스트를 사용해 CTL 구성을 하고 이름은 CTL로 컨텍스트를 사용하고 Docker 데스크톱 이름을 입력하세요
- 이게 우리가 실행할 명령입니다 dactil Qubernetes 클러스터 kube config 저장 그리고 클러스터 이름이죠
