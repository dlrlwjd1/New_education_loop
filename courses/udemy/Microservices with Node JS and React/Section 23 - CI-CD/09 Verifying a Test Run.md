# Verifying a Test Run

## 개요
- 진실의 순간이에요 채무 분과에 한 번 더 변화를 줄 거예요 그걸 GitHub로 밀어 넣어 우리 서비스 안에서 모든 테스트가 병렬로 실행되는 걸 볼 수 있도록요

## 내용
### 자막·본문 기반 핵심 내용
- 진실의 순간이에요 채무 분과에 한 번 더 변화를 줄 거예요 그걸 GitHub로 밀어 넣어 우리 서비스 안에서 모든 테스트가 병렬로 실행되는 걸 볼 수 있도록요
- pull request 탭으로 갈게요. 추가 시작 메시지로 갈게요 최신의 커밋으로 내려가면 4개의 워크플로가 병렬적으로 동작하는 것을 볼 수 있어요
- 이 처음으로 실행하거나 워크플로를 추가할 때 GitHub는 그걸 바로 처리하길 원치 않는 걸 눈치챘어요
- 데브한테 물어보세요 그 변화를 추가할 거예요 get status를 해서 성공적으로 추가했는지 확인할게요.

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `GitHub`, `request`

## 예시
`GitHub`, `request`가 등장하는 설정·코드 위치를 찾아 강의와 같은 순서로 확인한다.
