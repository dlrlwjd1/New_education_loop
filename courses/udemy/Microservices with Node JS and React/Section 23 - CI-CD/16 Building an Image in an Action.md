# Building an Image in an Action

## 개요
- Docker CLI에 로그인해야 해요 Docker 칼리는 당신이 누군지 Docker 계정이 뭔지 알 거예요

## 내용
### 자막·본문 기반 핵심 내용
- Docker CLI에 로그인해야 해요 Docker 칼리는 당신이 누군지 Docker 계정이 뭔지 알 거예요
- 이미지를 빌드한 다음 이미지를 Docker Hub에 푸시해요 Docker Hub에 이미지를 푸시하는 걸 기억하세요
- 첫 번째 워크플로를 만들겠습니다. 서비스 이미지를 만드는 것을 잊지 마세요. Docker 허브를 밀어요 그런 걸 제 GitHub 압류로 다시 보내죠
- 예를 들어 디렉터리를 변경하고 docker를 빌드 T로 만들어요 docker ID/off. 하지만 기술적으로 디렉터리로 변경할 필요는 없어요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `Docker`, `GitHub`, `Docker Hub`, `docker ID/off`, `Docker CLI`, `Docker Username`

## 예시
`Docker`, `GitHub`, `Docker Hub`, `docker ID/off`, `Docker CLI`가 등장하는 설정·코드 위치를 찾아 강의와 같은 순서로 확인한다.
