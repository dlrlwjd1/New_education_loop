# Creating a GitHub Action

## 개요
- 특별한 구문이에요 기술적으론 YAML이지만 여기에 쓴 실제 옵션은 시간이 지나면서 배우게 가장 먼저 이 워크플로 또는 GitHub action의 이름을 정할게요.

## 내용
### 자막·본문 기반 핵심 내용
- 특별한 구문이에요 기술적으론 YAML이지만 여기에 쓴 실제 옵션은 시간이 지나면서 배우게 가장 먼저 이 워크플로 또는 GitHub action의 이름을 정할게요.
- 어떻게 진행될지 알아야 해요 GitHub의 기능을 사용할 거예요 GitHub의 GitHub 액션이요
- GitHub 행동에 대해 더 알고 싶으시면 GitHub의 헬프 GitHub 공식 도움말 페이지를 보세요
- 새로운 GitHub 리포지토리를 만들었어요 약간의 코드를 GitHub 리포트에 추가해 테스트를 실행하도록 마스터 분기로 코드를 병합하기 위해 새 투표 요청을 만들 때마다 다이어그램을 살펴보죠

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `GitHub`, `YAML`, `request`, `NPM`
