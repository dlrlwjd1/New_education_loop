# Git Repository Approaches

## 개요
- 별도의 리포지토리를 만들어야 해요 GitHub나 get lab 같은 서비스에 저장소에 엑세스하기 위해 별도의 인증 키 모음을 만들어야 할 수도 있어요 별도의 CI와 CD 파이프라인을 설정해야 하죠

## 내용
### 자막·본문 기반 핵심 내용
- 별도의 리포지토리를 만들어야 해요 GitHub나 get lab 같은 서비스에 저장소에 엑세스하기 위해 별도의 인증 키 모음을 만들어야 할 수도 있어요 별도의 CI와 CD 파이프라인을 설정해야 하죠
- GitHub로 가서 일치하는 리포지토리를 생성하죠 이 과정은 여러분이 평소에 GitLab을 사용하더라도 GitHub를 이용하세요
- 우린 GitHub 자체의 일부 기능에 의존할 겁니다 특히 GitHub 액션이요 테스트를 실행하고 최종적으로 배포도 다루기 위해서요
- 왜냐하면 오류를 보게 되는 게 바로 거기거든요 Get푸시 오리진 마스터가 될 거예요 모든 게 제대로 작동하는 걸 보실 수 있을 겁니다 여기서 오류가 발생하면요 허가 거부 같은 거요 GitHub와 작동되도록 Git 클라이언트를 설정했는지 확인해야 해요

### 구현 요소
