# Testing the Image Build

## 개요
- 다 된 것 같네요 이미지를 구축해 Docker Hub에 푸시했어요 근사하죠 Docker Hub에 새 이미지가 있죠

## 내용
### 자막·본문 기반 핵심 내용
- 다 된 것 같네요 이미지를 구축해 Docker Hub에 푸시했어요 근사하죠 Docker Hub에 새 이미지가 있죠
- 새로운 워크플로가 만들어졌어요 4월에 등장할 때마다 새 이미지를 구축해 Docker Hub에 밀어 넣을 거예요
- 대본에 오타가 있을 가능성이 높아요 그러니 다시 한 번 확인해 보세요 Docker 사용자 이름과 암호 암호도 복제 내에서 성공적으로 설정했는지 확인하세요
- 우리 스크립트는 꽤 좋은 위치에 있어요 이제 이 파일을 커밋하겠습니다 오른쪽 상단의 녹색 버튼으로 가서 새 파일을 커밋하죠

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `Docker`, `Docker Hub`

## 예시
`Docker`, `Docker Hub`가 등장하는 설정·코드 위치를 찾아 강의와 같은 순서로 확인한다.
