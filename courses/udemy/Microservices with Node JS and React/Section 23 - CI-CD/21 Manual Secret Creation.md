# Manual Secret Creation

## 개요
- 우리가 제공해야 하는 두 가지 비밀은 JWT 시크릿이란 비밀과 JWT의 속성을 포함하죠

## 내용
### 자막·본문 기반 핵심 내용
- 우리가 제공해야 하는 두 가지 비밀은 JWT 시크릿이란 비밀과 JWT의 속성을 포함하죠
- 스트라이프 키가 어디서 왔는지 잊었다면 대시보드 스트라이프로 가는 걸 기억하세요 왼쪽에 개발자 API 키가 있어요 그런 다음 비밀 키를 찾죠
- 어떤 컨텍스트를 사용하고 있는지 알 수 있도록요 의 시스템으로 쉽게 돌아갈 수 있어요 쿠버네티에서 어떤 것에 연결되어 있는지 다른 방법으로는 Docker 데스크톱을 사용하지 않는다면 언제든 큐브 CTL 구성 보기를 할 수 있다는 걸 기억하세요
- 그 명령을 실행해 디지털 바다 클러스터에 수동으로 비밀을 생성할 거예요 먼저 JSON 웹 토큰 비밀 만들기요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `JWT`, `API`, `Docker`, `JSON`
