# Adding a CI Test Script

## 개요
- NPM 테스트 디렉터리를 직접 실행하는 대신 Test Colon PSI라는 새 스크립트를 정확히 한 번에 테스트 도구 모음을 실행하고 자동으로 종료될 거예요

## 내용
### 자막·본문 기반 핵심 내용
- NPM 테스트 디렉터리를 직접 실행하는 대신 Test Colon PSI라는 새 스크립트를 정확히 한 번에 테스트 도구 모음을 실행하고 자동으로 종료될 거예요
- 지난 비디오에서 첫 GitHub 훅을 만들었죠 시험해 볼 거예요 궁극적인 목표는 pull request를 생성하는 것입니다. 그리고 서비스 수행에 대한 모든 테스트를 보는 것이죠.
- 그 안에 스크립트 섹션이 있어요 Test Colon Sci의 새 스크립트를 추가할 거예요
- 그런 다음 이걸 GitHub에 밀어 넣고 그런 다음 우리 프로젝트에 작은 변화를 좀 줄 거예요 현실에서 변화를 만드는 걸 시뮬레이션하기 위해서요 그런 다음 GitHub에 밀어 넣고 전체 워크플로를 거치는 거죠

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `GitHub`, `request`, `NPM`, `JSON`
