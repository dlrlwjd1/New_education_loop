# Running Tests in Parallel

## 개요
- 먼저, 주문서 내에 JSON 패키지 파일을 찾고 test CI를 추가해요 저기 한 마리 있어요

## 내용
### 자막·본문 기반 핵심 내용
- 먼저, 주문서 내에 JSON 패키지 파일을 찾고 test CI를 추가해요 저기 한 마리 있어요
- 푸시 오리진 마스터를 구하세요 이 시점에서 우리가 같은 페이지에 있는지 확인하기 위해 GitHub로 돌아가서 저장소를 새로 고침하고 4개의 워크플로 파일을 GitHub 워크플로 파일 폴더의 마스터 분기 내에서 확인하세요
- 메인 티켓팅 디렉터리로 돌아가서 가령, 지불 서비스요 패키지 JSON 파일을 보고 그 안에 test CI 스크립트가 있죠
- 주문 지불 내부의 테스트 CI 스크립트를 볼 수 있죠 표와 서비스 패키지예요 JSON 파일요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `GitHub`, `CI`, `JSON`
