# Development Workflow

## 개요
- GitHub는 업데이트된 분기를 받을 거예요 그런 다음 Github UI를 통해 수동으로 끌어오기 요청을 만들죠

## 내용
### 자막·본문 기반 핵심 내용
- GitHub는 업데이트된 분기를 받을 거예요 그런 다음 Github UI를 통해 수동으로 끌어오기 요청을 만들죠
- 끌어오기 요청을 생성하는 순간 GitHub를 구성할 거예요 우리 프로젝트 안에서 모든 테스트를 동으로 실행하기 위해서요
- 끌어오기 요청을 생성함으로써 GitHub가 우리가 그동안 생성한 다양한 테스트를 실행하도록 하는 거죠
- 마스터 분기를 변경할 때마다 GitHub를 구성할 겁니다 그럼 모든 변화가 동으로 라이브 쿠버네티스 클러스터에 배포되죠

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `GitHub`
