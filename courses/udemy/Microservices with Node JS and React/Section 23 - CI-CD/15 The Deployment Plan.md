# The Deployment Plan

## 개요
- 다이어그램을 빨리 보여드릴게요 GitHub 액션 워크플로를 어떻게 사용할지를 요약하는 거죠 다양한 서비스를 이 실행 중인 클러스터에 자동으로 배포하기 위해서요

## 내용
### 자막·본문 기반 핵심 내용
- 다이어그램을 빨리 보여드릴게요 GitHub 액션 워크플로를 어떻게 사용할지를 요약하는 거죠 다양한 서비스를 이 실행 중인 클러스터에 자동으로 배포하기 위해서요
- 세로형 시리즈가 여기 하나 있고 다른 건 저기 있네요 서로 다른 워크플로 파일을 나타냅니다 함께 만들거나 개별 GitHub 액션이죠
- 그런 다음 그 이미지를 Docker Hub에 푸시해요 그 다음에 실행 중인 클러스터에 접근할 거예요
- 디지털 바다에 대한 클러스터죠 서비스에 대한 배포를 업데이트하고 해당 배포에 사용 가능한 인증 이미지의 최신 버전을 사용하라고 할 겁니다 방금 Docker Hub로 밀어낸 이미지죠

### 구현 요소

Hub`
