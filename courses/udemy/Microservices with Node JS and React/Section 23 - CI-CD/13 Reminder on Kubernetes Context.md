# Reminder on Kubernetes Context

## 개요
- 여기 튀어나온 창문이 안 보여도 괜찮아요 새 브라우저 탭을 열고 GitHub로 가세요

## 내용
### 자막·본문 기반 핵심 내용
- 여기 튀어나온 창문이 안 보여도 괜찮아요 새 브라우저 탭을 열고 GitHub로 가세요
- 왼쪽 아래 API를 찾을 수 있어요 그런 다음 새 토큰을 생성하죠 이건 액세스 토큰입니다 여러분의 디지털 해양 계정에 프로그램적으로 완전한 액세스를 제공하죠
- 제 클러스터는 이제 다 준비된 것 같네요 ETL을 이용해 로컬 컴퓨터에서 해당 클러스터에 연결을 시도할 거예요
- 과정 초반에 이걸 간략히 논의했죠 CTL은 컨텍스트라는 걸 이용해 주어진 클러스터에 연결하는 방법을 결정하니까요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `GitHub`, `API`
