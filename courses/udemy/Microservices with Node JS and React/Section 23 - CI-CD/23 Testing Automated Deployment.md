# Testing Automated Deployment

## 개요
- 끌어오기 요청을 생성하고 마스터로 병합해요 그걸 마스터로 병합하면 GitHub가 자동으로 이미지를 빌드해 쿠버네티스 클러스터에 알릴 겁니다 특히 그 새 이미지를 사용하도록 배포에 말이에요

## 내용
### 자막·본문 기반 핵심 내용
- 끌어오기 요청을 생성하고 마스터로 병합해요 그걸 마스터로 병합하면 GitHub가 자동으로 이미지를 빌드해 쿠버네티스 클러스터에 알릴 겁니다 특히 그 새 이미지를 사용하도록 배포에 말이에요
- GitHub에 있어요 풀 요청 탭으로 갈게요 새 끌어오기 요청을 생성하고 Dev의 모든 걸 마스터로 병합할 거예요
- 그 작업을 클릭할게요 내부 작업을 살펴볼게요 이걸 따라가면서 Docker Hub의 이미지를 빌드할 수 있어야 합니다 그런 다음 최종적으로 우리 클러스터에 배포하는 거죠
- 우리 어플리케이션을 시험할 시간이죠 서비스에 변화를 줄 거예요 그걸 개발 분기에 커밋할 거예요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `GitHub`, `Docker`, `Docker Hub`

## 예시
`GitHub`, `Docker`, `Docker Hub`가 등장하는 설정·코드 위치를 찾아 강의와 같은 순서로 확인한다.
