# Buying a Domain Name

## 개요
- 물론 오류죠 공기가 엔진 x에서 나오는 게 보이실 거예요 지금 당신은 Ingress 엔진 X 부하 분산기에 요청하고 있는데 불행히도 당신은 어떤 hostname도 사용하지 않고 있어요.

## 내용
### 자막·본문 기반 핵심 내용
- 물론 오류죠 공기가 엔진 x에서 나오는 게 보이실 거예요 지금 당신은 Ingress 엔진 X 부하 분산기에 요청하고 있는데 불행히도 당신은 어떤 hostname도 사용하지 않고 있어요.
- Name Cheap은 두어 개의 다른 도메인 이름을 관리할 때 사용하는 거죠 다시 말하지만 당신 마음이에요
- 마지막으로 해야 할 일은 도메인 이름을 얻고 디지털 오션에서 실행되는 쿠버네티스 응용 프로그램을 디지털 오션 대시보드로 돌아가죠
- 디지털 오션에서 흥미로운 걸 보여드릴게요 왼쪽을 보시면 여기 네트워킹 탭이 있어요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `Ingress`
