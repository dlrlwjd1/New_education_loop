# Deployment Options

## 개요
- 두 가지 검사만 하면 돼요 첫 번째는 이 공급자를 사용하는 비용이죠 이것들에 대한 비용은 월의 관점에서 매월마다 클러스터 내에 3개의 개별 노드가 있다고 가정하겠습니다 즉 3개의 가상 머신과 각각은 2기가바이트 RAM과 1 CPU가 있다고 가정하죠

## 내용
### 자막·본문 기반 핵심 내용
- 두 가지 검사만 하면 돼요 첫 번째는 이 공급자를 사용하는 비용이죠 이것들에 대한 비용은 월의 관점에서 매월마다 클러스터 내에 3개의 개별 노드가 있다고 가정하겠습니다 즉 3개의 가상 머신과 각각은 2기가바이트 RAM과 1 CPU가 있다고 가정하죠
- 현재 4대 기업이 있는데 디지털 오션 8과 AWS 구글 클라우드와 Azure죠 디지털 바다가 가격과 AWS를 훨씬 앞선다는 걸 쉽게 알 수 있죠
- 이 코스 초반에 이미 Google 클라우드를 다뤘죠 옵션으로 버리도록 할게요 제가 또 말씀드리고 싶은 것은 아주 빠르게 말씀 드리자면, 저는 Azure에서 쿠버네츠를 사용해 본 적이 없습니다. 그래서 좋은 의견은 못 드리겠네요.
- FAJ가 하는 일을 이해하는 건 그 자체로 도전이에요 쿠버네츠와 배포를 시작하실 거라면 솔직히 말씀드리면 AWS는 정말 안 좋은 결정입니다 더 쉬운 공급자를 먼저 시도해 보시길 권해드려요
