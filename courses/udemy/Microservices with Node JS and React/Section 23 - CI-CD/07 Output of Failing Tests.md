# Output of Failing Tests

## 개요
- 꺼진 다음 CI에서 NPM 테스트 풀을 하죠 CI 스크립트를 실행하고 있어요 왜냐하면 테스트를 한 번만 실행하고 바로 끝내고 싶거든요 제 테스트에서 시작하는 대신에요 그런 다음 여러분 모드를 보세요

## 내용
### 자막·본문 기반 핵심 내용
- 꺼진 다음 CI에서 NPM 테스트 풀을 하죠 CI 스크립트를 실행하고 있어요 왜냐하면 테스트를 한 번만 실행하고 바로 끝내고 싶거든요 제 테스트에서 시작하는 대신에요 그런 다음 여러분 모드를 보세요
- 그걸 GitHub에 올려요 이 분기에 대해 이미 요청을 생성했기 때문에 끌어오기 요청을 두 번째 만들 필요가 없어요 대신에 같은 분기에 이런 변화를 주고 있으니까요
- 그걸 푸시하면 GitHub로 돌아가 해당 요청을 살펴볼 수 있어요 막판에 변경됐어요
- 전부 실패했어요 기술적으로 우리 코드를 마스터에 병합할 순 없지만 GitHub는 병합을 강력히 여기 몇 가지 테스트를 실행하려 한다고 나오죠
