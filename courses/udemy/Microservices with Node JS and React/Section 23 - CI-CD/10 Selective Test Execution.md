# Selective Test Execution

## 개요
- 제 단말기로 돌아왔네요 get status를 하고 4개의 change workflow 파일을 볼 수 있죠.

## 내용
### 자막·본문 기반 핵심 내용
- 제 단말기로 돌아왔네요 get status를 하고 4개의 change workflow 파일을 볼 수 있죠.
- 이런 다양한 서비스를 함께 묶는 유일한 것은 공통 모듈이죠 이론상 일반 모듈 내의 모든 건 TypeScript를 이용한 유형 시스템을 통해 시행되고 있어요
- 다른 구성 파일에 한 번 더 변화를 줄 건데요 물론 GitHub에서 구성 파일을 직접 바꿀 수 있어요 기본 제공 편집기 안에서 편집하면 되죠 하지만 그 대신 로컬 컴퓨터로 끌어내린 다음 텍스트 편집기 안에서 재빨리 변경하는 거예요
- 그런 다음 다시 편집자에게 넘길게요 GitHub 파일이나 생성된 폴더를 찾을게요 그 안에 모든 다양한 워크플로 파일이 있어요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `TypeScript`, `GitHub`, `workflow`
