# Restarting the Deployment

## 개요
- 저 컨테이너 안에 덕타일을 설치할 거예요 컨테이너 안에 덕타일을 설치하고 나면 권한을 부여하거나 API 키를 이용해 초기화할 조금 전에 디지털 오션에서 만든 API 키를 주세요

## 내용
### 자막·본문 기반 핵심 내용
- 저 컨테이너 안에 덕타일을 설치할 거예요 컨테이너 안에 덕타일을 설치하고 나면 권한을 부여하거나 API 키를 이용해 초기화할 조금 전에 디지털 오션에서 만든 API 키를 주세요
- GitHub로 돌아가죠 코드 탭으로 갈게요 그런 다음 .GitHub 워크플로를 입력하죠
- 다시 한 번 이미지를 빌드해 Docker에 로그인해 Docker Hub에 밀어넣을 거예요
- 그 컨텍스트를 Cube ETL에 피드할 거예요 ETL은 GitHub 컨테이너 안에 미리 설치되어 있어서 큐브 ETL 같은 걸 설치할 필요가 없어요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `Docker`, `GitHub`, `API`, `Docker Hub`

## 예시
`Docker`, `GitHub`, `API`, `Docker Hub`가 등장하는 설정·코드 위치를 찾아 강의와 같은 순서로 확인한다.
