# Running Tests on PR Creation

## 개요
- 우리가 새 지점을 만든 것 같네요 GitHub에서요 GitHub는 이제 업데이트된 분기를 받았죠

## 내용
### 자막·본문 기반 핵심 내용
- 우리가 새 지점을 만든 것 같네요 GitHub에서요 GitHub는 이제 업데이트된 분기를 받았죠
- 끌어오기 요청을 생성하죠 끌어오기 요청을 만들면 GitHub의 새 이벤트를 촉발하고 그 이벤트가 GitHub 액션이나 우리가 만든 워크플로를 촉발해요
- 그 가지를 GitHub로 밀어 올릴 거예요 그러기 위해 Git push 오리진을 하죠
- 첫 번째 화면을 클릭할 수 있어요 이 경우엔 new pull request로 할게요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `GitHub`, `request`, `NPM`, `Git push`

## 예시
`GitHub`, `request`, `NPM`, `Git push`가 등장하는 설정·코드 위치를 찾아 강의와 같은 순서로 확인한다.
