# Configuring the Domain Name

## 개요
- 변화를 추가하고 커밋하죠 GitHub에 올릴게요 푸시하고 나면 GitHub로 가서 새로운 끌어오기 요청을 만들 거예요

## 내용
### 자막·본문 기반 핵심 내용
- 변화를 추가하고 커밋하죠 GitHub에 올릴게요 푸시하고 나면 GitHub로 가서 새로운 끌어오기 요청을 만들 거예요
- 상단의 See Name을 클릭할게요 w를 입력할게요 4는 별칭이에요 이렇게 넣을 거예요
- 시작 부분에 w도 추가할 거예요 도메인 이름에 www를 넣어야죠 이 파일을 저장하고 정확히 동일한 일련의 변화를 거치고 이런 변화를 커밋해야 하는 동일한 흐름을 거쳐서 개발자 분기로 푸시하고 pull request를 생성하고 폴라 요청을 승인할 거예요
- GitHub에 있어요 북극권 신청 탭을 누를게요 새 요청을 만들게요 그리고 Dev에서 마스터 분기로 가고 싶어요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `request`, `GitHub`
