# The Expiration Timer

## 개요
- 템플릿 문자열을 사용해 API 주문을 넣을게요 주문한 신분증요 그리고 맨 아래에서 리턴할 거예요

## 내용
### 자막·본문 기반 핵심 내용
- 템플릿 문자열을 사용해 API 주문을 넣을게요 주문한 신분증요 그리고 맨 아래에서 리턴할 거예요
- 이거면 될 거예요 마지막으로 만들거나 돌봐야 할 거예요 div 내의 left time을 사용하도록 해야 합니다 RMS left 대신에요
- 여기서 계산을 반올림해 볼게요 수학 반올림이죠 Find Time LEft를 호출할 때마다 남은 시간을 업데이트할 거예요
- 다시 한 번, fine time left 후에는 괄호가 없는 게 보이시죠. 여기에 괄호를 넣으면 그 기능을 호출하고 간격을 설정하는 결과를 전달할 그건 우리가 원하는 게 아니에요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `API`
