# Displaying the Expiration

## 개요
- 남은 시간이 0이나 그 이하로 가자마자 이런 간단한 텍스트를 보여줍니다 죄송합니다, 이 주문은 만료됐어요

## 내용
### 자막·본문 기반 핵심 내용
- 남은 시간이 0이나 그 이하로 가자마자 이런 간단한 텍스트를 보여줍니다 죄송합니다, 이 주문은 만료됐어요
- 여기서 가장 먼저 하고 싶은 것은요, 보다시피 기본값이 날짜를 사용하거나 빈 문자열에 대한 타임 레프트 상태죠
- 이해가 잘 안 되네요 가져오거나 0이라는 기본 값을 부여하세요 효과 후에 작은 체크를 추가할 거예요
- 남은 시간이 0 이하일 때요 div를 반환하죠 주문이 만료됐네요 주문 기간이 지난 플립을 구해야죠

### 구현 요소
- 강의 흐름에 따라 Displaying the Expiration의 구현 목적과 적용 지점을 확인한다.
