# Header Links

## 개요
- 이 두 개의 링크를 헤더에 두죠 티켓을 생성하는 페이지에 직접 링크를 걸고 싶어요

## 내용
### 자막·본문 기반 핵심 내용
- 이 두 개의 링크를 헤더에 두죠 티켓을 생성하는 페이지에 직접 링크를 걸고 싶어요
- 우린 여기 몇 가지 다른 링크들로 이 영리한 시스템을 만들었어요 사용자가 로그인했는지 안 했는지에 따라 하나의 링크 세트를 보여줄지 결정하기 위해서요
- 로그아웃 구성 바로 위에 추가하겠습니다 바로 저기요 다른 두 개의 링크는 현재 사용자가 있다고 할 수 있어요
- 사용자가 로그인하면 추가적인 링크를 원한다는 거죠 티켓 판매 라벨도 달았고요 사용자가 그걸 클릭하면 그리로 향하게 해야죠

### 구현 요소
- 강의 흐름에 따라 Header Links의 구현 목적과 적용 지점을 확인한다.

## 예시
사용자가 로그인하면 추가적인 링크를 원한다는 거죠 티켓 판매 라벨도 달았고요 사용자가 그걸 클릭하면 그리로 향하게 해야죠
