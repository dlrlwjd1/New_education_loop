# Showing a Stripe Payment Form

## 개요
- 그런 다음 반응 구성 요소인 것처럼 보여줄 거예요 최소한 사용자가 지불 정보를 제출할 때마다 발동되는 토큰 프로펠러에 콜백 함수를 제공해야 합니다 그리고 스트라이프 API에서 토큰을 반환받죠

## 내용
### 자막·본문 기반 핵심 내용
- 그런 다음 반응 구성 요소인 것처럼 보여줄 거예요 최소한 사용자가 지불 정보를 제출할 때마다 발동되는 토큰 프로펠러에 콜백 함수를 제공해야 합니다 그리고 스트라이프 API에서 토큰을 반환받죠
- 또 다른 필수 속성은 스트라이프 키입니다 게시 가능한 키로 스트라이프 대시보드에서 스트라이프 대시보드로 돌아가면 왼쪽 API 키에서 개발자를 찾을 수 있어요 우리가 원하는 게시 가능한 키죠
- 제 터미널로 돌아가서 클라이언트 디렉터리로 바꿀게요 리액션 스트라이프 체크아웃을 위한 NPM 설치를 하죠
- 타이머가 0까지 세는 걸 봤어요 결국 0에 도달해서 주문 만료로 자동으로 타이머가 잘 작동하는 것 같네요
