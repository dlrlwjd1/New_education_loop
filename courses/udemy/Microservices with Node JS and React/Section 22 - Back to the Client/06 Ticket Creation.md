# Ticket Creation

## 개요
- API 티켓에 게시 요청을 해야 합니다 타이틀과 가격도 포함해야 하고요 제공된 가격의 타이틀 인 가격에 뭔가 잘못된 게 있으면 API가 자동으로 과거에 구성 요소 내부에서 어떻게 요청을 했는지 살펴보죠

## 내용
### 자막·본문 기반 핵심 내용
- API 티켓에 게시 요청을 해야 합니다 타이틀과 가격도 포함해야 하고요 제공된 가격의 타이틀 인 가격에 뭔가 잘못된 게 있으면 API가 자동으로 과거에 구성 요소 내부에서 어떻게 요청을 했는지 살펴보죠
- 사용 요청을 디렉터리로 불러오죠 책은 요청을 이용하죠 주 대회가 끝난 다음에요 Request request 함수와 사용자 요청에서 발생한 에러를 가져오죠
- API 티켓에 요청하고 싶어요 우리 메서드는 post예요 여기 보시면 전부 대문자가 아니라 소문자 post죠
- 또 한 가지 언급하고 싶은 것은 여기서 전달할 onAction 콜백은 API 요청에서 돌아온 데이터와 결합된다는 거예요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `API`, `request`
