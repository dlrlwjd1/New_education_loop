# Test Credit Card Numbers

## 개요
- 여기서 가장 중요한 정보는 ID예요 저 ID가 진짜 토큰이에요 그 값을 지불 API로 보내길 원하죠

## 내용
### 자막·본문 기반 핵심 내용
- 여기서 가장 중요한 정보는 ID예요 저 ID가 진짜 토큰이에요 그 값을 지불 API로 보내길 원하죠
- 지불 API가 추가로 이 정도 금액에 대해 사용자의 신용카드를 결제할 수 있죠 할 수 있는 건 해당 ID를 확보해 게시 요청을 하는 것뿐이죠 아주 순조로워요
- 지불 모드가 나타나도록 할 수 있었어요 이제 실제 신용카드가 필요합니다 이 전체 흐름을 테스트하려면요
- 다행히 스트라이프는 우리 제품이에요 스트라이프 테스트에서 구할 이 페이지로 스크롤을 내리면 신용카드 번호가 나와 있습니다

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `API`
