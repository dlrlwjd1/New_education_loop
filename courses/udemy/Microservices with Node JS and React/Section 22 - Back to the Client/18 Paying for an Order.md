# Paying for an Order

## 개요
- UI 상태 직후에 Due request를 추가할 거예요 API 결제의 URL과 함께 사용자 요청 호출에서 오죠

## 내용
### 자막·본문 기반 핵심 내용
- UI 상태 직후에 Due request를 추가할 거예요 API 결제의 URL과 함께 사용자 요청 호출에서 오죠
- API 결제에 post request를 하고 객체 안의 ID인 토큰을 포함시켜야 합니다 주문 ID와 함께요
- 다 된 것 같네요 파일이 정말 한 줄에 있기를 원하나 봐요 USEquested훅을 사용할 때마다, Requested를 호출할 때, 추가 속성을 전달해서 request body를 추가할 수 있어요.
- 아까도 말했지만 조금요 해결 못 할 건 없어요 사용자 요청 후크에 변화를 줬어요 USE나 DEY request를 호출할 때 옵션으로 추가 속성을 요청바디에 포함시킬 수 있죠

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `API`, `request`

## 예시
