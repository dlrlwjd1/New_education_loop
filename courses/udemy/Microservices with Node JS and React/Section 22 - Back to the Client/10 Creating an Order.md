# Creating an Order

## 개요
- 주문, 서비스, CRC 경로 그리고 새 점을 찾죠 새 주문을 생성하려면 API/Order에 게시 요청을 만들어야 해요 여기서 해야 할 일은 티켓 ID를 포함하는 거죠

## 내용
### 자막·본문 기반 핵심 내용
- 주문, 서비스, CRC 경로 그리고 새 점을 찾죠 새 주문을 생성하려면 API/Order에 게시 요청을 만들어야 해요 여기서 해야 할 일은 티켓 ID를 포함하는 거죠
- 우리가 닿으려고 하는 종점이죠 우리 매표소를 잠깐 살펴봤는데 쇼 루트예요 API 티켓에 get request를 한 다음 실제 ID를 만들어야 해요
- 데이터를 추출할게요 weight Lionsgate에서요 여기서 템플릿 문자열을 사용할 테니 백 체크 API 티켓 ID가 있는지 확인하세요
- 위에는 import, use request를 해 볼게요. 디렉터리에 이르기까지도요
