# Two Quick Fixes

## 개요
- Ingress와 Gen X에 직접 연결하거나 기본 URL을 사용하죠 다른 말로 하자면 현재 도메인을 사용하고 엔드포인트, 백 엔드 서버에 요청을 인덱스 파일 안에서 봤듯이 맨 위에 빌드 클라이언트 가져오기 팀이 있었고 방금 전에 초기 소품 내부에서 클라이언트를 만들고 있었죠

## 내용
### 자막·본문 기반 핵심 내용
- Ingress와 Gen X에 직접 연결하거나 기본 URL을 사용하죠 다른 말로 하자면 현재 도메인을 사용하고 엔드포인트, 백 엔드 서버에 요청을 인덱스 파일 안에서 봤듯이 맨 위에 빌드 클라이언트 가져오기 팀이 있었고 방금 전에 초기 소품 내부에서 클라이언트를 만들고 있었죠
- 빌드 클라이언트가 뭔지 상기시켜드리자면 클라이언트 폴더 내의 API 디렉터리로 가서 빌드 클라이언트 파일을 찾을 수 있어요
- 이 비디오에서 아주 빨리 고치도록 하죠 시작하려면 인덱스 파일로 돌아가 볼게요 get 초기 기능을 찾을 거예요
- 저 안에 있는 건 지금 당장 다 삭제할게요 그 대신 빈 개체를 반환할 거예요 맨 위에 있는 Bild 클라이언트 문도 지울게요. 왜냐하면 지금은 클라이언트 함수를 가져오거나 사용하지 않을 거니까요.

### 구현 요소
