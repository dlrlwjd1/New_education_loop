# Reminder on Data Fetching with Next

## 개요
- 다음 프로세스를 상세히 살펴보죠 next jazs가 어떻게 이 구성 요소 중 하나를 보여주고 데이터를 어떻게 끌어오고 해당 구성 요소에 데이터를 제공하는지 말이에요

## 내용
### 자막·본문 기반 핵심 내용
- 다음 프로세스를 상세히 살펴보죠 next jazs가 어떻게 이 구성 요소 중 하나를 보여주고 데이터를 어떻게 끌어오고 해당 구성 요소에 데이터를 제공하는지 말이에요
- 기본값으로 Next는 앱 구성 요소만 호출합니다 이니셜 소품이죠 착륙 페이지를 호출하지 않아요
- 응용 프로그램에 추가할 다양한 경로에 관해 얘기했어요 이런 경로를 추가하기 전에 앱 내부의 한두 가지 작은 문제를 해결하고 싶어요
- 마지막으로 클라이언트 앱을 작업했을 때 이 안에 작은 이슈를 남겨뒀어요 이 문제가 뭔지 알아내고 해결 방법을 알아내고 싶어요

### 구현 요소
- 강의 흐름에 따라 Reminder on Data Fetching with Next의 구현 목적과 적용 지점을 확인한다.
