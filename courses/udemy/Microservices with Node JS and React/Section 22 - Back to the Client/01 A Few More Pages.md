# A Few More Pages

## 개요
- 여기 이 루트 구문을 보세요 저희 페이지 디렉터리 내 파일을 반영하기 위해 Express jaz에서 오셨다면 이게 말이 될 겁니다 티켓 이름, 대괄호, 티켓 ID로 파일을 작성할 수 있어요 페이지 구성 요소 내부에서 티켓 ID에 엑세스할 수 있죠

## 내용
### 자막·본문 기반 핵심 내용
- 여기 이 루트 구문을 보세요 저희 페이지 디렉터리 내 파일을 반영하기 위해 Express jaz에서 오셨다면 이게 말이 될 겁니다 티켓 이름, 대괄호, 티켓 ID로 파일을 작성할 수 있어요 페이지 구성 요소 내부에서 티켓 ID에 엑세스할 수 있죠
- indexed JS 파일을 찾을 거예요 이 indexed JS 파일은 현재 착륙 페이지 또는 클라이언트 애플리케이션으로 사용되죠
- 이건 특정 티켓에 대한 세부 사항이고 이건 특정 주문에 대한 세부 사항이에요 보통 특정 레코드를 볼 때마다 URL 안에 해당 레코드 ID를 이 URL 안에 주문 슬래시 같은 경로가 있을 수 있어요 우리가 찾는 순서의 티켓도 마찬가지예요
- 하지만 이 경우엔 일종의 매개 변수가 있어야죠 쿼리 매개 변수 URL의 일부인 URL에서 와일드카드를 만들기 위해서요
