## 내용
### 자막·본문 기반 핵심 내용
- 이렇게 말할 거예요 데이터는 클라이언트 사건 목록 API 티켓이죠 클라이언트가 데이터를 가져오기 위해 액시오스를 사용할 때마다 우린 우리가 관심 있는 실제 데이터에 큰 REZ나 응답 개체를 갖고 옵니다 데이터 속성에 구조를 짜는 거죠
- 그런 다음 티켓 키를 가진 개체를 반환합니다 그리고 그 데이터를 참조하죠 여기 이 개체는 이 안에 있는 모든 건 소품으로 병합될 거예요 상륙 페이지로 이 개체는 티켓의 키를 갖고 있기 때문에 저 소품을 티켓으로 받을 수 있어요 실제 구성 티켓은 우리가 API에서 가져온 모든 티켓의 배열이에요
- 티켓 리스트를 매핑한 결과죠 티켓 한 장당 돌아갈 거예요 다양한 요소를 구성할 때마다 React는 우리가 핵심 속성을 제공하길 원한다는 걸 명심하세요
- 서 뿌리로 돌려보내는 거죠 원한다면 매표소 페이지로 보낼 수도 있어요 하지만 단순하고 직설적으로 가죠
