# Validating Title and Price

## 개요
- Express 유효성 검사기의 본체 기능이죠 이 바디 기능을 써서 수신 요청 바디의 특정 속성을 확인하죠

## 내용
### 자막·본문 기반 핵심 내용
- Express 유효성 검사기의 본체 기능이죠 이 바디 기능을 써서 수신 요청 바디의 특정 속성을 확인하죠
- 요청 처리기와 관련해 유효성 검사를 위한 두 가지 테스트를 작성했어요 실제 구현을 해야 해요
- 이걸 미들웨어로 연결할 거예요 인증을 요구한 직후 유효성 로직을 넣을게요 사용자가 인증되지 않았다면 본체 검증을 위해 시간을 낭비하고 싶지 않아요
- 그 다음에 이것들을 바로 넣도록 하죠 그 전에 넣으면 유효성 검사를 하고 사용자가 인증을 받았는지 확인하죠

### 구현 요소
