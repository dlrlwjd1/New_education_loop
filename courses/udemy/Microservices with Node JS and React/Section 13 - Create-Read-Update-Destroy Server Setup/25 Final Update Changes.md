# Final Update Changes

## 개요
- MongoDB 데이터베이스에 업데이트를 계속하지 않아요 집합을 호출한 다음에는 A wait ticket.ave를 하고 모든 걸 지속적으로 되돌려 놓을 거예요 저장 버튼을 누른 후에는 업데이트가 데이터베이스에 지속될 Mongoose는 추가적인 업데이트를 확인하게 될 겁니다 post 저장 후크, Pre 저장 후크 MongoDB가 자체적으로 한 어떤 것에 의해서요 다른 모든 가능한 업데이트는 티켓 문서에 지속될 겁니다 이미 참조하고 있는 거죠

## 내용
