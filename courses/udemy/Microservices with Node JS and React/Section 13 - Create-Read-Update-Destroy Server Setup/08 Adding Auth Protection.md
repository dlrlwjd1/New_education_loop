# Adding Auth Protection

## 개요
- 여기에 바디를 붙일 거예요 다시 요청해 볼게요 API 티켓에 게시 요청을 하고 다시 빈 개체를 보낼 거예요

## 내용
### 자막·본문 기반 핵심 내용
- 여기에 바디를 붙일 거예요 다시 요청해 볼게요 API 티켓에 게시 요청을 하고 다시 빈 개체를 보낼 거예요
- 여기 이 시나리오에선 우린 어떤 식으로도 인증되지 않았어요 어떤 상태 코드나 쿠키 JSON, 웹 토큰 같은 것으로 이 요청을 보내지 이걸 여기로 전송하면 이 처리기에 요청하는 걸 시뮬레이트할 겁니다
- 이게 현재 사용자 미들웨어예요 이것의 목적은 수신 요청 세션 속성을 살펴보고 JSON 웹 토큰이 있는지 확인하는 거였어요
- 쿠키 세션은 먼저 실행돼야 합니다 쿠키를 살펴보고 REST 세션 속성을 설정할 수 있도록요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `API`, `JSON`, `REST`

## 예시
`API`, `JSON`, `REST`가 등장하는 설정·코드 위치를 찾아 강의와 같은 순서로 확인한다.
