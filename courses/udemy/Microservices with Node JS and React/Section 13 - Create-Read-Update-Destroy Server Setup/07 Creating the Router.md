# Creating the Router

## 개요
- Express에서 요청과 응답 유형을 가져오죠 라우터를 생성할 거예요 API 티켓에 게시 요청을 기대하라고 할게요 그런 다음 실제 경로 처리 기능을 넣죠

## 내용
### 자막·본문 기반 핵심 내용
- Express에서 요청과 응답 유형을 가져오죠 라우터를 생성할 거예요 API 티켓에 게시 요청을 기대하라고 할게요 그런 다음 실제 경로 처리 기능을 넣죠
- 여기서 첫 번째 테스트를 할 거예요 어떻게든 요청을 하거나 API 티켓에 포스팅 요청을 해야 해요
- 대답은 기다림이에요 우리 앱에 요청할게요 API/ 티켓에 게시 요청을 하고 싶어요
- 404 말고 다른 방법이 있는지 확인하고 싶어요 어떻게든 상태 코드를 되찾아 어설션을 하기 위해서는 여기 이 응답을 응답은 할당된 status code 속성을 갖게 돼요 우리가 받은 응답의 status code가 되는 거죠 기대치를 작성하고 응답에 .status라고 쓸 상태를 보세요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `API`, `Express`
