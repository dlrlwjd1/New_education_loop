# Test-First Approach

## 개요
- API 티켓에 라우트 처리기가 있어야 해요 게시 요청에 반응할 라우트 수신 요청 바디의 유효성을 확인하는 테스트를 작성하도록 해야 할 것 같아요

## 내용
### 자막·본문 기반 핵심 내용
- API 티켓에 라우트 처리기가 있어야 해요 게시 요청에 반응할 라우트 수신 요청 바디의 유효성을 확인하는 테스트를 작성하도록 해야 할 것 같아요
- 티켓 프로젝트 디렉터리 안에 있는지 확인할게요 티켓팅 안에 있지 않게요 티켓 안에 있습니다 일단 안에 들어가면 NPM 런 테스트를 실행해 테스트 모음을 제 테스트 파일이 이제 저 안에서 모든 테스트를 실행할 거예요
- 밑줄, 테스트요 그 안에 New Test라는 파일을 만들 거예요 이 파일을 새것이라고 부르는 건 결국 새 루트 처리기를 갖게 될 것이기 때문이죠
- 티켓에 대한 초기 셋업은 모두 끝났습니다 이제 실제로 실행할 시간이죠 함께요 상기시켜드리자면 이건 이 티켓 서비스 안에 만들 다양한 루트 우리가 작업할 첫 번째 루트 처리기는 티켓을 생성할 기능을 주죠

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `API`, `NPM`
