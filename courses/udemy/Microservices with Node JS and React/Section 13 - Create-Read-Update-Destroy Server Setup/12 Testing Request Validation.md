# Testing Request Validation

## 개요
- API 티켓에 포스팅하고 싶어요 이게 인증되었는지 확인할 거예요 쿠키를 설정할 거예요

## 내용
### 자막·본문 기반 핵심 내용
- API 티켓에 포스팅하고 싶어요 이게 인증되었는지 확인할 거예요 쿠키를 설정할 거예요
- 그렇지 않다면 사용자에게 어떤 종류의 공기를 반환하도록 해야 하죠 테스트 구현을 먼저 작성하죠
- 첫 번째에서 유효하지 않은 타이틀로 요청을 보내보도록 하죠 왜 제목이 유효하지 않은지는 말씀 안 드렸는데요
- 지금으로선 빈 타이틀을 넣거나 아예 타이틀을 안 넣으면 공기가 나올 거라고 앱에 대기 요청을 쓸 거예요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `API`

## 예시
`API`가 등장하는 설정·코드 위치를 찾아 강의와 같은 순서로 확인한다.
