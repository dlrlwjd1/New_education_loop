# What's that Error?!

## 개요
- 거기에 새 버전을 설정하고 NPM으로 재배포해야 합니다 티켓 서비스 내부에서 이 일반 모듈의 업데이트 버전을 설치하고요

## 내용
### 자막·본문 기반 핵심 내용
- 거기에 새 버전을 설정하고 NPM으로 재배포해야 합니다 티켓 서비스 내부에서 이 일반 모듈의 업데이트 버전을 설치하고요
- 콘솔 로그를 제거할게요 제 티켓 디렉터리로 돌아갈게요 기억하세요, 언제든 NPM 모듈을 설치하면 노드 모듈 폴더에 추가돼요
- 시대는 유효한 ID가 아니라고 말해요 MongoDB가 이해할 수 있는 유효한 ID가 아니라고요
- 그게 가능하다면 그 말은 for Show 요청 처리기의 어딘가에서… 방금 작업했던 거요 그 안의 뭔가가 오류를 던진다는 거죠

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `NPM`, `MongoDB`

## 예시
`NPM`, `MongoDB`가 등장하는 설정·코드 위치를 찾아 강의와 같은 순서로 확인한다.
