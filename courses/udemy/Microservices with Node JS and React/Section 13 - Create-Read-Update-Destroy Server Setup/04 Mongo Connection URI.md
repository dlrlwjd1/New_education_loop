# Mongo Connection URI

## 개요
- 사용자 이름과 암호가 요구된다면 여기에 일반 텍스트로 쓰고 싶지 않을 주위의 어떤 보안도 없이 일반 URL에 연결만 하면 그리고 여기에 연결하는 방법을 직설적으로 알려주는 배포 파일이 있는 한, 저는 강하게 반박할 건데요 이것은 일반 문자열로 두는 것은 문제가 되지 그것에 신경 쓴다면 MongoDB에 사용자 이름과 암호 인증 구성이 있다면 우리가 해야 할 일은 이 환경 변수를 비밀 안에서 정의하는 겁니다 JSON Web 토큰 키에서 적어도 배포 파일에는 그래야겠죠

- 티켓의 배포 파일을 저장하고 닫을게요 티켓 인덱스드 파일 안에 남았어요 이 안에서 우린 MongoDB 인스턴스에 해당 환경 변수 안에서 제공되는 URI로 연결하도록 해야만 해요
- 전에 했던 것과 아주 유사한 체크를 한 번 더 할게요 if not 프로세스 EMV Mongo URI라고 하죠
- 새 환경 변수를 여기에 추가할게요 Mongo_Uri라는 이름으로 새 변수를 추가할게요
