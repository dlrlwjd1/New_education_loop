# Project Setup

## 개요
- 저도 확장할 거예요 그런 다음 서비스 안에서 다중 구성 패키지와 JSON 패키지 락, Docker 무시 파일로 갑니다 Docker 다섯 개의 파일을 모두 복사해서 티켓에 붙여넣기를 할 거예요.

## 내용
### 자막·본문 기반 핵심 내용
- 저도 확장할 거예요 그런 다음 서비스 안에서 다중 구성 패키지와 JSON 패키지 락, Docker 무시 파일로 갑니다 Docker 다섯 개의 파일을 모두 복사해서 티켓에 붙여넣기를 할 거예요.
- 티켓 안에 두 번째 단말 창을 열 수 있게요 제 이미지를 만들 거예요 Docker ID로 Docker 빌드 T를 작성할게요 플래시 티켓과 점이죠
- JSON 패키지는요? 패키지 JSON 파일에 auth라는 이름이 있네요 티켓으로 업데이트를 하죠
- 이 비디오를 마무리하죠 이미지를 구축해 Docker Hub에 푸시하는 거예요 제 단말기로 돌아왔네요
