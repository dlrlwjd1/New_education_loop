# Ticketing Service Overview

## 개요
- 수많은 종속성을 설치해 Docker 파일을 작성해 구현을 시작할 겁니다 이미지를 빌드해 Docker Hub에 푸시하는 거죠

## 내용
### 자막·본문 기반 핵심 내용
- 수많은 종속성을 설치해 Docker 파일을 작성해 구현을 시작할 겁니다 이미지를 빌드해 Docker Hub에 푸시하는 거죠
- 모든 종속성에 기반한 파일 목록에 기초해 원시 패키지를 만들고 Docker 파일을 작업해 모든 코드를 함께 모아 Express 서버, 와이어 앱 미들웨어 등을 서비스에서 직접 많은 코드를 복사할 겁니다 시간을 좀 절약하기 복사를 좀 해볼게요 그런 다음 여기서 다시 시작할게요
- 티켓 소유자가 누군지도요 티켓 서비스는 자체적으로 MongoDB를 가지고 있어요.
- 이건 우리가 앞서 해당 서비스를 위해 이미 생성한 MongoDB 인스턴스와 100% 별개예요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `MongoDB`, `JSON`, `Docker`, `Express`, `Docker

Hub`
