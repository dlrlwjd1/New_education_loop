# Complete Index Route Implementation

## 개요
- 예상하셨겠지만 다음 줄 담당자를 만나보시죠 이 경우엔 index를 다루죠 라우트 처리기가 필요합니다 API 티켓에 요청할 수 있는 거죠 티켓 컬렉션에 있는 모든 다른 티켓을 검색할 수 있도록요

## 내용
### 자막·본문 기반 핵심 내용
- 예상하셨겠지만 다음 줄 담당자를 만나보시죠 이 경우엔 index를 다루죠 라우트 처리기가 필요합니다 API 티켓에 요청할 수 있는 거죠 티켓 컬렉션에 있는 모든 다른 티켓을 검색할 수 있도록요
- 요청을 하려고요 반응을 찍을게요 API 티켓에 get request를 하고 싶어요
- 티켓 세 장으로 하죠 그 정도면 괜찮네요 요청을 할 수 있어요 우리가 여기서 테스트하려는 건 API 티켓에 Get 요청을 해서 응답하는 개체가 3개이길 기대하는 거죠
- O8 요청을 앱에 할 거예요 API 티켓에 포스팅 요청할게요 쿠키도 넣을 거예요 쿠키가 아니라 굳힌 쿠키요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `API`, `promise`, `request`
