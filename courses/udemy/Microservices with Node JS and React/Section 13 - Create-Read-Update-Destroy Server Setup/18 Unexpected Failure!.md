# Unexpected Failure!

## 개요
- 이 안에 필요한 모든 걸 추가할 거예요 라우트 처리기를 빌드하기 위해서요 Express를 불러오죠

## 내용
### 자막·본문 기반 핵심 내용
- 이 안에 필요한 모든 걸 추가할 거예요 라우트 처리기를 빌드하기 위해서요 Express를 불러오죠
- 그런 다음 루트 처리기를 설정하죠 루트킷이 API 티켓에 대한 요청과 원하는 티켓의 ID를 받으려면요
- 그것부터 처리하죠 아니면 티켓이라고 하죠 status 코드를 반환해야 합니다. 즉 return rend status 어쩌고저쩌고 하는 것들을 반환할 하지만 멋진 에어 핸들링 시스템은 이미 설치돼 있다는 걸 기억하세요
- 이 쿼리는 REC 그램스 id를 이용해서 수행합니다 RECct params id요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `Express`, `API`
