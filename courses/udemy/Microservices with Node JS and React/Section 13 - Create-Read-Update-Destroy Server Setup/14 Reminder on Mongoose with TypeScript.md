## 내용
### 자막·본문 기반 핵심 내용
- JSON 기능도 두 개 있었죠 JSON을 기억하세요 어떻게든 이 데이터의 JSON 표시를 조작했을 거예요
- 사용자 ID도요 티켓 문서 인터페이스가 Mongoose DOT document를 확장하도록 할 거예요
- TypeScript로 몽구스 모델 빌드하는 법을 다시 한 번 알려드리죠 이 화면으로 돌아가서 맨 위에 3개 인터페이스를 생성했어요
- 우리 티켓 모델에는 그런 게 필요 없어요 그리고 빌드 함수를 정의했죠 이 빌드 함수의 목적은 TypeScript가 새 레코드를 생성하기 위해 사용하는 속성을 확인하는 유효성 검사를 하도록 하는 것이었죠
