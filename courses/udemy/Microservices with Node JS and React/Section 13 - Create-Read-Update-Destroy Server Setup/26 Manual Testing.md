# Manual Testing

## 개요
- 개발자 API 사용자 로그인으로 HTTPS 티켓팅에 게시 요청을 해요 Body SELECT Raw로 가서 JSON SELECT가 여기 있는지 확인하죠 이메일과 암호를 입력할 수 있어요

## 내용
### 자막·본문 기반 핵심 내용
- 개발자 API 사용자 로그인으로 HTTPS 티켓팅에 게시 요청을 해요 Body SELECT Raw로 가서 JSON SELECT가 여기 있는지 확인하죠 이메일과 암호를 입력할 수 있어요
- Path 섹션으로 가서 API 사용자 경로 다음에 새 경로를 추가할게요 API, 슬래시 티켓, 슬래시 모든 것에 대한 요청이라고 하죠
- 모든 게 걸린 길이죠 그걸 맨 위에 두면 모든 수신 요청은 그 1/1과 일치하고 API 사용자나 API 티켓에는 절대 접근 못 해요
- 하지만 이 티켓 서비스에 접속할 수 있어야 해요 인그레스 엔진 x 구성 파일을 업데이트하지 않았어요 API 티켓으로 요청을 받아서 티켓 서비스로 전달하라고 하지 않았죠

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `API`, `HTTPS`, `JSON`

## 예시
`API`, `HTTPS`, `JSON`가 등장하는 설정·코드 위치를 찾아 강의와 같은 순서로 확인한다.
