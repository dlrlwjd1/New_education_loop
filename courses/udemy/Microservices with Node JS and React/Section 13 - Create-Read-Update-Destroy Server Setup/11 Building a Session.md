## 내용
### 자막·본문 기반 핵심 내용
- 세션은 JWT 토큰이라고 하죠 그걸 JSON으로 바꿀 거예요 session json은 어때요? json string ify라고 할게요
- 그 다음엔 페이로드로 JSON 웹 토큰을 만들 거예요 이걸 탑재하는 거죠 JSON 웹 토큰을 만들려면 JWT 라이브러리를 사용해야 해요
- 이 파일 상단에 그걸 불러오죠 JSON 웹 토큰에서 JWT를 불러올게요 JWT 라이브러리에 그 기호 메서드가 있죠
- 서명 메서드는 JSON Web 토큰을 만드는 방법이죠 호출할 때 JSON 웹 토큰 키를 제공해야 해요 그게 우리 키죠
