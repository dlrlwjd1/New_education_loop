# Handling Updates

## 개요
- 레이더 라우터요 그 라우터에서요 put 메서드를 API 티켓에 연결할게요 비동기 라우트 처리기를 가질 거예요

## 내용
### 자막·본문 기반 핵심 내용
- 레이더 라우터요 그 라우터에서요 put 메서드를 API 티켓에 연결할게요 비동기 라우트 처리기를 가질 거예요
- 업데이트를 안 해도 적어도 모든 테스트는 즉시 해결되죠 REST 송신을 할게요 일단 표는 환불해 드릴게요
- 업데이트 요청 처리기의 초기 구현을 함께 만들어보죠 루트 디렉터리 안에서 업데이트 CSS 파일을 만들 거예요
- 티켓이 없는 사건은 우리가 맡아야 할 것 같아요 not found error 어때요?
