# Order Creation Logic

## 개요
- 차체 잔해에서 나온 신분증을 확인할게요 데이터베이스에서 티켓을 찾아보죠 이건 아주 표준적인 MongoDB 또는 Mongoose 쿼리가 되겠군요

## 내용
### 자막·본문 기반 핵심 내용
- 차체 잔해에서 나온 신분증을 확인할게요 데이터베이스에서 티켓을 찾아보죠 이건 아주 표준적인 MongoDB 또는 Mongoose 쿼리가 되겠군요
- 데이터 레이어를 합쳤어요 그 말은 이제 새 라우트 처리기로 돌아갈 수 있다는 거죠
- 조금 전에 작업했던 거요 이 구현을 함께 시작하려고요 상단의 새 라우트 처리기에서 방금 만든 두 모델을 불러올게요
- 디렉토리 모델에서 티켓을 가져올 거예요 한 디렉토리 모델의 주문을요 잠재적으로 데이터베이스에서 티켓을 페치할 수 있고 주문을 저장할 처리기로 가보죠

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `MongoDB`, `Mongoose`

## 예시
`MongoDB`, `Mongoose`가 등장하는 설정·코드 위치를 찾아 강의와 같은 순서로 확인한다.
