# Test Suite Setup

## 개요
- 이 비디오에선 주문 서비스를 설정해 몇 가지 테스트를 실행할 거예요 다음 비디오에선 이 새 요청 처리기에 대한 테스트를 작성하겠습니다 주문 서비스의 CRC 디렉터리 안에서 시작하기 위해서요 Test라는 새 폴더를 만들게요
