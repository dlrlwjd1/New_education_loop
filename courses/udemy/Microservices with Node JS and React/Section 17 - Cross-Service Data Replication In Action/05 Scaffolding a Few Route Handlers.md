# Scaffolding a Few Route Handlers

## 개요
- 인덱스에 들어왔습니다 즉, get request handler가 필요하다는 거죠 API 주문의 요청을 주시하는 거예요

## 내용
### 자막·본문 기반 핵심 내용
- 인덱스에 들어왔습니다 즉, get request handler가 필요하다는 거죠 API 주문의 요청을 주시하는 거예요
- 샷 대신에 Get request to API 명령을 만들 수 있습니다 주문 ID도요
- 사용자가 주문의 ID보다 API 주문에 요청을 하면 해당 주문의 세부 사항을 리턴하게 이 처리기에 액세스하려면 사용자가 인증돼야 해요
- 저장했다가 닫을 거예요 그리고 마지막으로 new는 API 주문에 게시 요청을 만들 수 있어야 해요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `API`, `Express`, `request`, `TypeScript`, `MongoDB`, `Docker`
