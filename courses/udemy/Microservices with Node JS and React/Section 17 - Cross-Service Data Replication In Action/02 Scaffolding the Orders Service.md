# Scaffolding the Orders Service

## 개요
- Docker 파일 안에서 시작할게요 아무 문제 없어요 패키지 JSON으로 갈게요 안에 티켓의 이름이 있는 것 같네요

## 내용
### 자막·본문 기반 핵심 내용
- Docker 파일 안에서 시작할게요 아무 문제 없어요 패키지 JSON으로 갈게요 안에 티켓의 이름이 있는 것 같네요
- Docker 빌드 대시를 더 많은 주문으로 실행할 거예요 연스럽게 그걸 더 크게 대체하고 싶을 겁니다 docker ID와 .으로요
- 개발자 종속성에 나열해둔 걸 잊었네요 좀 더 빨라야 해요 어쨌든 시간이 좀 걸릴 겁니다 NPM 설치와 Docker 빌드가 여기서 완료되려면요
- 이렇게 할 거예요 티켓 서비스에서 많은 코드를 복사할 거예요 주문 서비스에 종속성을 설치해 로컬 컴퓨터에 테스트를 Docker를 이용해 이미지를 빌드해 쿠버네테스 배포 구성 파일을 생성하죠

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `Docker`, `YAML`, `JSON`, `TS`, `NPM`, `MongoDB`, `docker ID`
