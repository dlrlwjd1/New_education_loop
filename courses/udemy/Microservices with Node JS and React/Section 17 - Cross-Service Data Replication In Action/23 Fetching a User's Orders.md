# Fetching a User's Orders

## 개요
- Mongoose에 있는 인구 생성 시스템을 이용해 그렇게 하죠 기억하시겠지만 특정 주문을 가져오는 방법과 그와 관련된 티켓을 동시에 로딩하는 우리가 할 일은 쿼리의 끝으로 연결하는 거예요.

## 내용
### 자막·본문 기반 핵심 내용
- Mongoose에 있는 인구 생성 시스템을 이용해 그렇게 하죠 기억하시겠지만 특정 주문을 가져오는 방법과 그와 관련된 티켓을 동시에 로딩하는 우리가 할 일은 쿼리의 끝으로 연결하는 거예요.
- 이 시점에서 주문 서비스를 진행할 방법은 두 가지예요 주문 주변에 이벤트를 게시하거나 발생하는 이벤트를 구독하는 방법을 살펴볼 수도 있어요
- 또 다른 방향으로는 먼저 각기 다른 루트 처리기에 집중하는 거죠 먼저 이런 라우트 처리기를 구현하고 그런 다음 이벤트와 관련된 모든 것으로 그 이유는 아직 다양한 이벤트를 어떻게 디자인하고 다양한 서비스로 어떻게 통신하는지 애플리케이션을 통해 이벤트의 흐름을 어떻게 효과적으로 생각하는지에 대해 깊이 연구하지 않았기 때문이죠
- 다양한 라우트 처리기를 먼저 다 합치고 싶어요 이걸 다 완료하면 서비스를 완료해야 하죠

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `Mongoose`
