# Convenience Document Methods

## 개요
- 키워드 함수를 사용해야 해요 이 기능은 비동기로 표시할 거예요 async await 구문을 사용할 수 있게요

## 내용
### 자막·본문 기반 핵심 내용
- 키워드 함수를 사용해야 해요 이 기능은 비동기로 표시할 거예요 async await 구문을 사용할 수 있게요
- 예약이라는 새 메서드를 추가할 거예요 이게 호출되면 부울로 해결되는 promise를 반환할 거예요
- 몽구스는 여러 번 봤어요 말하자면 옛날 방식에 갇혀 있는 거죠 JavaScript를 작성하는 옛날 방식에요
- 아뇨, 예약 안 했어요 우리 메서드 시그니처 안에 쓴 것도 바로 그거죠 promise는 예약하거나 불리언으로 해결될 거라고 했죠

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `promise`, `JavaScript`, `async`, `await`
