# A Touch More Setup

## 개요
- 주문 서비스 특정 MongoDB 인스턴스를 갖게 될 거라고 가정하면요 MongoURI를 MongoDB 주문, Mongo 서버/마지막 주문으로 업데이트 할게요.

## 내용
### 자막·본문 기반 핵심 내용
- 주문 서비스 특정 MongoDB 인스턴스를 갖게 될 거라고 가정하면요 MongoURI를 MongoDB 주문, Mongo 서버/마지막 주문으로 업데이트 할게요.
- 그런 다음 몇 가지 환경 변수를 나열하죠 이건 그대로 둘 거예요 Nets 클라이언트 ID에 대한 소스도 같아야 하고 같은 Nets URL, 같은 클러스터 같은 JSON 웹 토큰 키를 원하죠
- 하지만 주문 서비스가 티켓 서비스를 위해 만들어진 MongoDB 인스턴스에 연결되는 주문과 관련된 것들을 위한 새로운 MongoDB 인스턴스를 생성할 필요가 있어요.
- 여기 이미지 이름에요 Docker ID/Order로 바꾸죠 구글 클라우드에서 클러스터를 실행 중이라면 이 형식과 함께 여기 이미지를 넣으면 안 돼요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `Docker`, `JSON`, `MongoDB`, `Deployment`, `Docker ID/Order`
