# The Need for an Enum

## 개요
- 그런 상태로는 돈을 못 받는다고 했죠 조금 전에 다이어그램을 보여드렸었죠. status가 fail이 되었기 때문에 order가 fail 저 다이어그램과 이 다이어그램 사이에서 이 순서의 상태를 나타내는 정확한 문자열을 헷갈리거나 잘못 기억했어요
