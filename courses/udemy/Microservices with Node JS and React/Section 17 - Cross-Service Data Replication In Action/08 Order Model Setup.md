## 내용
### 자막·본문 기반 핵심 내용
- 이 비디오에서는 OrderModel을 구현해 볼게요. 몽구스와 관련된 코드를 이용해서 주문 모델에 대한 설명을 써볼게요.
- 기억하세요, Mongoose와 TypeScript가 함께 작동할 때마다 좋은 방법은 파일 상단에 3개 인터페이스를 작성하는 거죠
- 두 개가 따로 있는 거예요 하지만 당분간은 똑같을 거예요 추가한 주문서의 속성들을 모두 지우고 OrderDoc에 붙여넣기를 그런 다음 주문 모델을 하죠
- 모델이 컬렉션 전체를 대표한다는 걸 기억하세요 모델을 설명하기 위해 인터페이스를 구축합니다. 특히 여기에 추가 메소드를 추가합니다. 빌드 빌드 메서드를 함께 두는 전체적인 이유는 TypeScript가 새 문서를 생성하기 위해 사용하는 인수의 유효성 검사를 하도록 하기 위해서죠 그래서 미리 알림이 끝났어요
