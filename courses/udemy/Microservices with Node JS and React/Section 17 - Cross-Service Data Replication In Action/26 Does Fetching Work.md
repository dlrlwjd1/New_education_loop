# Does Fetching Work?

## 개요
- Express 앱에서 디렉터리 앱으로요 티켓 모델도 불러와 티켓을 생성할 수 있습니다 새 주문과 연결할 딱지 끊을 거예요

## 내용
### 자막·본문 기반 핵심 내용
- Express 앱에서 디렉터리 앱으로요 티켓 모델도 불러와 티켓을 생성할 수 있습니다 새 주문과 연결할 딱지 끊을 거예요
- API 주문에 게시 요청을 하고 싶어요 우리 스스로 인증하고 싶어요 우리가 방금 만든 사용자로서요
- 백 틱을 보세요 API 주문을 넣을 거예요 페치하려는 주문의 ID도요 해당 ID는 저 주문 변수에서 나오죠
- 한 번 더 차체에서 분리할 수 있어요 이 경우엔 body varable로 이름을 바꾸겠습니다 여기 있는 body와 구별하기 위해서요 페치드 그런 다음 예상을 써서 우리가 생성한 순서와 동일한 ID를 갖도록 주문 ID를 예상 주문 ID와 동일하게 할 수 있어요.
