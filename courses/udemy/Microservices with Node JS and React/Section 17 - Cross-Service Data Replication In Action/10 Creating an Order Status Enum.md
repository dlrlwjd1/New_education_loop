# Creating an Order Status Enum

## 개요
- on status는 Enum의 또 다른 키를 추가하고요 객체 값을 입력하고 ORDER status enum을 입력하죠

## 내용
### 자막·본문 기반 핵심 내용
- on status는 Enum의 또 다른 키를 추가하고요 객체 값을 입력하고 ORDER status enum을 입력하죠
- 주문 프로젝트로 돌아가서 주문서비스는 주문모델 파일을 찾습니다. 우리가 작업했던 맨 위에는 ORDER status enum을 가져오고요
- 기술적으로 이 위의 인터페이스는 어떤 종류의 오류도 캡처하기에 충분해야 해요 mongoose에 유효성 검사도 추가할 수 있습니다. 누군가가 status 속성을 변경하거나 설정하려고 할 때마다 Mongoose는 가능한 값들 중 하나로 설정하도록 할 수 있어요.
- 그리고 형식 내에서 Order Status라는 새 파일을 만들게요. 내부 정상 상태예요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `NPM`, `enum`, `mongoose`
