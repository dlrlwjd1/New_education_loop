# Asserting Tickets Exist

## 개요
- 티켓 ID에 대한 유효한 ID를 요청의 본문에서 제공해야 여기서 유효 ID란 유효한 MongoDB 개체 ID를 의미하죠

## 내용
### 자막·본문 기반 핵심 내용
- 티켓 ID에 대한 유효한 ID를 요청의 본문에서 제공해야 여기서 유효 ID란 유효한 MongoDB 개체 ID를 의미하죠
- 상단에서 Mongoose를 가져와야 합니다 상단에서 무작위로 유효한 개체 ID를 생성할 몽구스한테 몽구스 받을게요
- Mongoose 타입 객체 ID죠 새로운 랜덤 ID를 만드는 방법이죠 이미 한 번 봤잖아요
- 바로 요청할게요 하지만 앱에 대한 요청은 기다릴 거예요 API 주문에 게시 요청을 할 거예요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `MongoDB`, `Mongoose`, `API`

## 예시
`MongoDB`, `Mongoose`, `API`가 등장하는 설정·코드 위치를 찾아 강의와 같은 순서로 확인한다.
