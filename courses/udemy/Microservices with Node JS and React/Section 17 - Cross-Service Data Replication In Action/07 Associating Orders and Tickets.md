# Associating Orders and Tickets

## 개요
- 둘째, 우린 기록을 몽고다브와 몽구스를 연관짓고 있어요 Mongoose 내부에 Ref나Pulation Feature라는 기능이 있는데요

## 내용
### 자막·본문 기반 핵심 내용
- 둘째, 우린 기록을 몽고다브와 몽구스를 연관짓고 있어요 Mongoose 내부에 Ref나Pulation Feature라는 기능이 있는데요
- 소득 신고 확인 중이에요 이 요청 처리자의 몸을 생각해 보세요 이 요청 처리기의 목적은 사용자가 구매하려는 티켓에 대한 정보를 취하는 것입니다. 그리고 주문 기록을 생성해서 MongoDB 데이터베이스에 주문을 저장하는 것이죠.
- 레코드와 MongoDB를 연결하는 것을 논의할 때 사용할 수 있는 두 가지 주요 표와 연관짓기 위해 사용할 수 있는 두 가지 주요 전략을 살펴볼 텐데요
- 이 기능에 익숙하지 않다면 어떻게 작동하는지 보여드릴게요 그렇지 않다면, 항상 Mongoose 문서를 보고 어떻게 작동하는지 조금 더 이해할 수 있어요.
