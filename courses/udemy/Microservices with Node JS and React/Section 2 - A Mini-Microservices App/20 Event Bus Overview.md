# Event Bus Overview

## 개요
- 이벤트 버스도 포함해서요 이 이벤트 버스를 우리가 직접 만들어야 해요 JavaScript를 이용해 빌드해 그걸 표현하는 거죠

## 내용
### 자막·본문 기반 핵심 내용
- 이벤트 버스도 포함해서요 이 이벤트 버스를 우리가 직접 만들어야 해요 JavaScript를 이용해 빌드해 그걸 표현하는 거죠
- 그것의 목적에 대해서는 잠시 후에 말씀드리죠 우리 응용 프로그램 내부에서 어떤 시점에 post service나 Common Service가 이벤트를 방출해야 한다고 결정하게 될 거예요
- JSON일 수도 있고 원시 바이트 데이터일 수도 있고 문자열일 수도 있고 어떤 서비스든 공유할 수 있어요
- 우체국일 거예요 이것은 localhost 4001/ 이벤트에 동일한 요청을 할 것입니다. 같은 것을 localhost 4002/ 이벤트에 요청할 수도 있고요.

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `JavaScript`, `JSON`, `service`
