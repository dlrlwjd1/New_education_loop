# Implementing a Comments Service

## 개요
- get request handler를 쓸게요 훨씬 쉽죠 레즈 전송을 할 거예요 게시 ID 개체로 주석 내부를 볼 거예요

## 내용
### 자막·본문 기반 핵심 내용
- get request handler를 쓸게요 훨씬 쉽죠 레즈 전송을 할 거예요 게시 ID 개체로 주석 내부를 볼 거예요
- 마지막으로 할 일은 패키지 JSON 파일을 여는 거예요 그 안에서 스크립트도 정의할 거예요 노드 모드로 프로젝트를 시작하려면요
- 제 패키지 JSON 파일이에요 시작 스크립트를 대체하거나 시작 스크립트를 생성할 거예요.
- 라우트 처리기는 하나예요 특정 게시물과 연관된 새 주석을 만들 수 있게 해주죠 여기 이 경로 안에서 Post Slash에 대한 요청을 만들 거예요 이 코멘트와 연결할 게시물의 ID도요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `request`, `JSON`
