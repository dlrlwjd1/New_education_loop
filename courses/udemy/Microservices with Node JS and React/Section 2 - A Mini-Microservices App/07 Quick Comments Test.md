## 내용
### 자막·본문 기반 핵심 내용
- 코멘트 딜러라고 하면 두 번째 코멘트가 뜨죠 get request 탭으로 가서 get request를 다시 할 수 있어요
- 드롭다운이 JSON에 맞춰져 있는지 확인할게요 여기 JSON을 입력할게요 코멘트는 콘텐츠 속성이 있어야 한다는 걸 기억하세요
- 터미널 창을 찾을게요 일반 프로젝트 디렉토리 내부에 있죠 그 안에서 NPM 시작을 실행할 두 개의 분리된 서비스가 있다는 걸 기억하세요 두 개의 분리된 익스프레스 응용 프로그램이 우리 컴퓨터에서 하나는 포트 4000에서 기울고 있어요
- 다음은 헤더예요 응용 프로그램/JSON의 콘텐츠 유형을 입력할게요 RAW를 선택하죠
