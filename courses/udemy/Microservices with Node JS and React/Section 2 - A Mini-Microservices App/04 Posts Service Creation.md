# Posts Service Creation

## 개요
- Express에 엑세스 권한을 갖고 새 Express 응용 프로그램을 만들 거예요

## 내용
### 자막·본문 기반 핵심 내용
- Express에 엑세스 권한을 갖고 새 Express 응용 프로그램을 만들 거예요
- 암호 패키지에서 랜덤 바이트요 여기서 무작위로 새 ID를 생성할 거예요 사용자가 생성하려는 게시물에 post request handler에서 Const ID를 입력하고 임의 ID를 생성해요 임의 바이트 함수를 사용해서요
- 공용 서비스의 게시 기능을 위한 아주 기본적인 기능을 함께 다룰 거예요 다른 말로 하면 아주 기본적인 Express JS 코드죠 아주 기본적인 리소스를 조작하거나 다루기 위해서요
- Express 응용 프로그램을 만든 직후에 작은 개체를 만들 거예요 생성된 모든 다른 포스트들을 저장하는 걸 책임지는 거죠

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `Express`, `request`, `JSON`
