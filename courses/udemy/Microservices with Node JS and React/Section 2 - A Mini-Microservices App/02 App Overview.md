# App Overview

## 개요
- 그렇게 하면 여기 Post counter가 보일 거예요 혹은 코멘트 카운터가 1로 증가했죠

## 내용
### 자막·본문 기반 핵심 내용
- 그렇게 하면 여기 Post counter가 보일 거예요 혹은 코멘트 카운터가 1로 증가했죠
- 미세 백신과 의사소통하는 방법에 대한 노트를 봤으니 이제 실제로 코드를 이 비디오에서는 응용 프로그램의 모형을 살펴볼 겁니다 비동기 통신 패턴을 더 잘 이해하기 위해서요
- 나중에 훨씬 더 크고 포괄적인 프로젝트를 할 거예요 첫 번째 프로젝트는 여러분의 경험을 토대로 중요한 문제들을 소개하는 이 프로젝트의 목표는 최대한 많은 것을 맨땅에서 만드는 거예요
- 모든 서비스를 수작업으로 구축할 거예요 이벤트 브로커를 수작업으로 빌드할 거예요 최대한 많은 부분을 수작업으로 만들 거예요 그래야 상황을 제대로 파악할 수 있으니까요
