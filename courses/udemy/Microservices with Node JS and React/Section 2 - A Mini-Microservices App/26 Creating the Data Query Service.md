# Creating the Data Query Service

## 개요
- 그런 다음 해당 디렉터리로 변경해 npm init을 이용한 패키지 json 파일을 생성할 거예요

## 내용
### 자막·본문 기반 핵심 내용
- 그런 다음 해당 디렉터리로 변경해 npm init을 이용한 패키지 json 파일을 생성할 거예요
- 파일을 생성하고 나면 두 개의 종속성을 설치해요 이 서비스에 필요한 건 Express와 물론 쿼리 서비스는 어떤 이벤트도 방출하지 않아요 그래서 액시오스를 설치하지 않는 거죠
- Express 보디 파서와 코스 모듈이 필요해요 급행으로 갈 거예요 보디 파서 부를게요
- 전선을 연결할게요 두 개의 루트 처리기를 합칠 거예요 기억하세요, 우리가 원하는 두 가지는 get 2/hash post와 Post to 슬래시 이벤트예요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `npm`, `json`, `Express`, `npm init`
