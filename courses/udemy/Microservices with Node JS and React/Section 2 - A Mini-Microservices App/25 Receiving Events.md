# Receiving Events

## 개요
- 이벤트 처리기를 함께 놓죠 post service와 Common Service를 위해서요

## 내용
### 자막·본문 기반 핵심 내용
- 이벤트 처리기를 함께 놓죠 post service와 Common Service를 위해서요
- 지난 몇 개의 영상에서 여러 번 말씀드린 것처럼 Post와 Common Service는 지금 나오는 어떤 이벤트도 신경 쓰지 않아요
- 먼저 제 우체국으로 가서 시작할게요 인덱스 케이스 파일을 찾아서 파일의 맨 밑에 있는 apt list 바로 위에 놓을게요.
- 게시 요청 처리기를 추가할게요 슬래시 이벤트를 위한 AP 포스트예요 녹음실과 레진도 가져가죠

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `service`
