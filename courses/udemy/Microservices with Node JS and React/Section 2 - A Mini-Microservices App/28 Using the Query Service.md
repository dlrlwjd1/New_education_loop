# Using the Query Service

## 개요
- React Application은 post service를 요청하고 공용 서비스를 요청합니다

## 내용
### 자막·본문 기반 핵심 내용
- React Application은 post service를 요청하고 공용 서비스를 요청합니다
- 쿼리 서비스는 모두 완성되었고 React Application에 변화가 필요합니다 필요한 데이터를 얻으려면 쿼리 서비스에 접근해야 하고요
- 게시물을 보여주거나 주석을 보여줘야 할 때마다요 더는 그런 걸 원하지 않아요 게시나 주석을 위한 요청을 하기 보다는 React Application이 쿼리 서비스에 하나의 요청을 만드는 겁니다 응용 프로그램에 관한 모든 정보와 관련된 모든 게시와 주석을 보여주는 거죠
- 사용자에게 게시물 리스트를 가져오는 것에 대해 얘기하고 있어요 포스트 서비스와 공용 서비스는 100% 책임져야 합니다 실제로 댓글을 남기고 게시물을 올리는 React Application이 게시물이나 코멘트를 만들어야 할 경우 이런 서비스에 직접 연락할 거예요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `React`, `service`
