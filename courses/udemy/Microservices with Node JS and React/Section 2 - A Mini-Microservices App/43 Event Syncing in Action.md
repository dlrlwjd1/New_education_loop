# Event Syncing in Action

## 개요
- 시동이 안 걸려요 게시물은 만들 수 있을 거예요 게시물을 만들게요 new post와 제출 같은 거요

## 내용
### 자막·본문 기반 핵심 내용
- 시동이 안 걸려요 게시물은 만들 수 있을 거예요 게시물을 만들게요 new post와 제출 같은 거요
- 마지막 비디오에선 이걸 테스트하기 전에 쿼리 안에 동기화 코드를 함께 넣었죠 여기서 액시오스를 사용하려고 했는데 불행히도 우리 쿼리 서비스는 아직 액시오스가 설치되지 이 인덱스 파일에 요구하지도 않았어요
- 이 파일의 맨 위로 올라갈게요 액시오스가 필요해요 이건 제가 보관할게요 제 터미널로 돌아갈게요
- 제 서비스를 실행하는 터미널 창을 찾을 거예요 내가 저걸 막을 거예요 액시오스 설치할게요

### 구현 요소
- 강의 흐름에 따라 Event Syncing in Action의 구현 목적과 적용 지점을 확인한다.
