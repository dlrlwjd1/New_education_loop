## 내용
### 자막·본문 기반 핵심 내용

- 이 안에는 특정 이벤트를 처리하고 처리할 방법을 아는 코드가 많아요 post request handler 안에서 직접 로컬화되는 이벤트요
- 그런 다음 post request handler로 돌아가죠 여기 있네요 콘솔 로그를 지우겠습니다 더 이상 필요 없는 거죠
