# Adding Comment Moderation

## 개요
- 댓글 서비스 찾아볼게요 그 안에 인덱스 파일이 있어요 그런 다음 내려가서 새 주석을 만드는 곳으로 갑니다 여기 post request handler 안에요

## 내용
### 자막·본문 기반 핵심 내용
- 댓글 서비스 찾아볼게요 그 안에 인덱스 파일이 있어요 그런 다음 내려가서 새 주석을 만드는 곳으로 갑니다 여기 post request handler 안에요
- 조정 서비스를 위해 스캐폴드가 만들어졌어요 이런 다양한 서비스 3개를 모두 살펴보고 각각에 몇 가지 변화를 어떤 경우엔 이미 존재하는 이벤트를 수정해야 하고 어떤 경우엔 새 이벤트를 추가해야 단계별로 살펴볼 겁니다 사용자가 코멘트를 보내는 실제 워크플로를 사용자가 코멘트를 제출하면 어떻게 되는지 생각해보죠
- 지금은 일반 서비스 안에 새 주석을 달아야 한다는 걸 기억하세요 지금은 코멘트, ID, 콘텐츠를 저장하고 있어요
- 코멘트 상태도 저장하고 싶을 겁니다 보류 중이든, 절제든 승인, 거부든 상관없이요
