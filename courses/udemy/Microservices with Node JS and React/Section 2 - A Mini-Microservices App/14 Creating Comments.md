# Creating Comments

## 개요
- 리액트 프로젝트의 에디터 안에서 컴 앤 크리에이티브로 시작할게요 CRC 디렉터리 안에 새 파일을 만들겠습니다 Comment Create Dogs라는 파일이죠

## 내용
### 자막·본문 기반 핵심 내용
- 리액트 프로젝트의 에디터 안에서 컴 앤 크리에이티브로 시작할게요 CRC 디렉터리 안에 새 파일을 만들겠습니다 Comment Create Dogs라는 파일이죠
- 이 안에 React를 넣을 거예요 그런 다음 새 구성 요소를 만들어 내보내는 거죠
- Comet Create에서 이게 프로펠러를 받는다고 가정할 거예요 여기 있는 소품을 받을 건데 post ID 같은 걸 포함하고 이 안에 다른 소품을 받지는 않을 것 같아요 그래서 post ID 값의 구조를 만들게요
- post request가 될 거예요 새 주석을 만들어야 하니까요 그런 다음 경로를 기억해야죠 해당 미세 감지에 사용하기로 한 경로요
