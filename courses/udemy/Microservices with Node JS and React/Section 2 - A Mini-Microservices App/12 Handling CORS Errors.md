# Handling CORS Errors

## 개요
- 강의 후반부에 다룰 큰 프로젝트는 이 핵심 이슈에 대해 너무 걱정하지 않아도 돼요 몇 가지 아키텍처 변화만 추가하면 되니까요 브라우저 내 하나의 URL에서 실제 API가 호스트된 다른 URL로 요청하는 일이 없도록요

## 내용
### 자막·본문 기반 핵심 내용
- 강의 후반부에 다룰 큰 프로젝트는 이 핵심 이슈에 대해 너무 걱정하지 않아도 돼요 몇 가지 아키텍처 변화만 추가하면 되니까요 브라우저 내 하나의 URL에서 실제 API가 호스트된 다른 URL로 요청하는 일이 없도록요
- 이 오류를 없애기 위해서는 브라우저 안에서 할 수 있는 게 없어요 이 오류를 없애기 위해 React app이나 그런 것에 추가할 수 있는 추가적인 서버 자체에 추가적인 구성을 해야 해요
- 저 서버와 코멘트 서버도 멈추죠 터미널 윈도우 두 개에도요 게시물과 댓글을 위해 npm 설치 대의명분을 실행할 거예요
- 포트나 하위 도메인이 있는 도메인을 살펴볼 때 URL이나 우리가 요청하려는 도메인과 다른 도메인을요
