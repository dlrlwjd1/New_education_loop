# Request Minimization Strategies

## 개요
- 저도 그러고 싶어요 돌기둥 같은 구조물을 만들려고 한다면 아주 쉽고 쉽게 지금 모노리스를 만든다면 get request를 해서 슬래시 포스트에 참과 같은 코멘트 = 쿼리 문자열을 추가한다고 할 수 있죠 그게 Monolith 서버의 기호예요 포스트에 모든 관련 코멘트가 삽입된 포스트 리스트를 얻기 돌기둥 형태의 접근은 아주 간단하고 쉬워요

## 내용
### 자막·본문 기반 핵심 내용
- 저도 그러고 싶어요 돌기둥 같은 구조물을 만들려고 한다면 아주 쉽고 쉽게 지금 모노리스를 만든다면 get request를 해서 슬래시 포스트에 참과 같은 코멘트 = 쿼리 문자열을 추가한다고 할 수 있죠 그게 Monolith 서버의 기호예요 포스트에 모든 관련 코멘트가 삽입된 포스트 리스트를 얻기 돌기둥 형태의 접근은 아주 간단하고 쉬워요
- React Application 전체를 건너뛰었다면 지난 강의의 완성된 코드를 다운받았을 거예요
- 이게 수수께끼처럼 사라지면 갑자기 게시물 서비스도 제대로 작동하지 POST 서비스에서 Common Service로 보낸 요청이 실패하면 전체 요청도 글도 안 올리고 댓글도 안 달게요
- 파일을 업데이트한 후에도 업데이트를 해야 합니다 게시 및 디렉터리에서 NPM 설치를 다시 실행하세요
