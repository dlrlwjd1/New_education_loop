# Parsing Incoming Events

## 개요
- 쿼리 서비스가 돌아가는 곳이기 때문이죠 React Application 안에서 쿼리 서비스를 아직 사용하진 않아요

## 내용
### 자막·본문 기반 핵심 내용
- 쿼리 서비스가 돌아가는 곳이기 때문이죠 React Application 안에서 쿼리 서비스를 아직 사용하진 않아요
- 이 정도면 괜찮네요 이론적으로 쿼리 서비스는 전체 게시물 리스트와 관련된 코멘트를 얻기 위해 필요한 모든 데이터를 마지막으로 해야 할 일은 React Application을 업데이트하는 겁니다
- React Application이 이 단말기에 요청을 보내 이 데이터 구조를 확보하고 전달하게 하세요 그 구조를 이용해 모든 게시와 주석을 나열하고요
- 오류가 없는지 확인하려는 거예요 React 응용 프로그램으로 돌아갈게요 새로운 게시물을 입력할 거예요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `React`
