# A Second Approach

## 개요
- 두 번째 옵션을 살펴보겠습니다 이 중재 서비스를 추가하는 것과 그걸 지원하는 이벤트를 추가하는 거죠

## 내용
### 자막·본문 기반 핵심 내용
- 두 번째 옵션을 살펴보겠습니다 이 중재 서비스를 추가하는 것과 그걸 지원하는 이벤트를 추가하는 거죠
- 두 번째 옵션이에요 두 번째 옵션은 첫 번째 옵션과 아주 비슷한데 한 가지 아주 작은 차이가 있어요
- 사실 2번 옵션은 1번 옵션이 될 거라고 생각하셨을 거예요 설명해 드릴게요 사용자가 현재 서비스에 코멘트를 보내도록 할 거예요
- 코멘트 서비스는 여전히 코멘트가 생성된 이벤트를 내보내죠 이벤트 플러스도 해당 이벤트를 조정 서비스로 보내죠

### 구현 요소
- 강의 흐름에 따라 A Second Approach의 구현 목적과 적용 지점을 확인한다.

## 예시
코멘트 서비스는 여전히 코멘트가 생성된 이벤트를 내보내죠 이벤트 플러스도 해당 이벤트를 조정 서비스로 보내죠
