## 내용
### 자막·본문 기반 핵심 내용
- RAW를 선택하겠습니다 여기 오른쪽에서 확인하겠습니다 이 드롭다운은 JSON에 그런 다음 API로 보내기 위해 JSON 데이터를 좀 쓸 거예요
- 아주 간단한 API 클라이언트를 사용할 거예요 Postman으로 가서 Postman API 클라이언트 테스터를 찾죠
- 중괄호 세트를 놓을게요 큰따옴표 안에 키를 넣을게요 이건 JSON 코드니까요 JavaScript 이렇게 첫 게시물 제목을 붙여 줄게요
- 이건 아주 작은 데스크톱 응용 프로그램으로 주어진 끝점에 임의의 API 요청을 할 때 사용할 Postman을 이용해 이 개인 서비스를 테스트할 겁니다 시간을 좀 절약하기 위해서요

### 구현 요소
