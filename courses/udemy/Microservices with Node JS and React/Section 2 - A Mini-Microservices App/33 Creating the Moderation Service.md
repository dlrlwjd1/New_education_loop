## 내용
### 자막·본문 기반 핵심 내용
- npm init이 있는 새로운 패키지 json 파일을 생성하는 경우에요 그런 다음 전에도 여러 번 했듯이 몇 가지 종속성을 설치할 거예요
- 그 안에 Moderation이라는 새 폴더를 만들게요 그 디렉터리로 바꿔요 이 단말 창을 아주 빨리 최대화할게요
- 4003층이에요 POST 이벤트나 POST 라우트 처리기에서 구현을 하기 전에 패키지 JSON 파일을 스크립트로 설정하고 터미널에서 성공적으로 실행되는지 확인하죠
- 그리고 새로운 익스프레스 애플리케이션을 생성하고 보디 파서 미들웨어에 연결하세요 JSON을 기능으로 호출하도록 할게요
