# Project Setup

## 개요
- React Application은 게시 서비스와 코멘트 서비스로 네트워크 요청을 통해 POST 서비스와 Common Service는 둘 다 Express 기반 응용 프로그램이 될 거예요

## 내용
### 자막·본문 기반 핵심 내용
- React Application은 게시 서비스와 코멘트 서비스로 네트워크 요청을 통해 POST 서비스와 Common Service는 둘 다 Express 기반 응용 프로그램이 될 거예요
- 먼저 React App Create를 이용해 새 프로젝트를 생성할 겁니다 우리 React 응용 프로그램을 다룰 수도 있고 스캐폴드를 할 수도 있죠 게시 서비스를 위한 Express 기반 프로젝트를 위한 코드를 함께 묶을 수도 있어요 코멘트 서비스도 마찬가지고요
- 프로젝트의 전체성을 생성할 것이죠 이 블로그 디렉터리 안에 새 React Application을 생성할 거예요 NPC의 Create React Application을 이용해서요 이걸 단순히 클라이언트라고 부를게요 이건 우리 웹 클라이언트예요
- 그 디렉터리로 바꿀게요 이 안에서 새 패키지 JSON 파일을 생성할 겁니다 종속성 두어 개를 NPM init을 해 볼게요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `React`, `Service`, `Express`, `JSON`, `NPM`, `NPM init`
