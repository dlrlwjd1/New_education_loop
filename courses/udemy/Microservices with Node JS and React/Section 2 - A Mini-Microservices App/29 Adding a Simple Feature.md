- 먼저, 이런 심플 필터링으로 코멘트에 오렌지가 있는지 없는지 확인하려 한다면 React Application에 구현하는 게 훨씬 말이 돼요
- 어떤 이유에선지 여과하고 있어요 시작부터 말씀드리고 싶은 건 아주 쉽게 한 가지 가정을 내릴 수 있다는 겁니다 여러분이 보시는 모형을 근거로요 React Application은 100% 알 수 있죠 주석이 중재를 기다리는지 거부되는지 승인되는지를요
- React Application은 주석 하나에 이런 구조가 있는 줄 알아요 바로 여기요
