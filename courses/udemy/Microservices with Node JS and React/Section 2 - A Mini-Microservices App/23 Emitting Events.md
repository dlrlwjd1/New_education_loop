# Emitting Events

## 개요
- 마지막으로 이건 비동기 연산으로 네트워크 요청을 만들죠 async를 추가하고 await하죠 이렇게요

## 내용
### 자막·본문 기반 핵심 내용
- 마지막으로 이건 비동기 연산으로 네트워크 요청을 만들죠 async를 추가하고 await하죠 이렇게요
- 사실 좋은 거예요 잠시 전에 언급한 것처럼 post service, 공용 서비스와 쿼리 서비스는 아직 존재하지만 post/Stash 이벤트의 끝점을 갖고 있지 않아요
- 이벤트 버스의 초기 구현이 이루어졌어요 이제 post service와 공용 서비스를 살펴볼게요
- 이때 이벤트를 내보내면 됩니다 누가 새 게시물을 올렸어요 게시물 컬렉션에 새 게시물을 추가한 직후 액시오스를 이용해 HTTP에 게시 요청을 콜론//Local host:: 2005요

### 구현 요소
