# Common Questions Around Async Events

## 개요
- 이런 스타일의 비동기 통신을 두 번 살펴봤죠 이쯤 되면 정말 궁금하실 거예요 이번 비디오에서는 여러분이 알고 있을 만한 질문과 가능한 답변을 살펴볼게요

## 내용
### 자막·본문 기반 핵심 내용
- 이런 스타일의 비동기 통신을 두 번 살펴봤죠 이쯤 되면 정말 궁금하실 거예요 이번 비디오에서는 여러분이 알고 있을 만한 질문과 가능한 답변을 살펴볼게요
- 아마 이런 생각부터 들 거예요 잠깐만요, 스티븐 두 가지 유형의 리소스가 있다면 우리 경우엔 둘 다 코멘트인데요 그 정보를 효과적으로 처리하려면 세 번째 서비스를 만들어야 한다는 거죠
- 아뇨, 그런 뜻이 아니에요 데이터 조인이라는 한 가지 목적으로만 추가 서비스를 만들지는 않아요
