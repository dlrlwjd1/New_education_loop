# A Basic Event Bus Implementation

## 개요
- 그런 다음 보디 파서 JSON 미들웨어를 이 앱과 연결해요 API로 보디 파서 JSON을 쓸 거예요

## 내용
### 자막·본문 기반 핵심 내용
- 그런 다음 보디 파서 JSON 미들웨어를 이 앱과 연결해요 API로 보디 파서 JSON을 쓸 거예요
- 단말기로 돌아왔죠 단말 창을 하나 더 열게요 4개가 됐어요 하나는 React app용이고 하나는 게시용, 하나는 코멘트용이죠
- 이 안에서 새 패키지 json 파일을 생성할게요 이건 NP init-t-y예요 그런 다음 설치할 거예요
- 여기에 제 콜백을 넣을게요 이벤트를 가져올 텐데 이것은 request body라고 가정해보죠

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `React`, `json`, `Express`, `API`, `request`, `HTTP`, `NPM`
