# Out-Of-Order Events

## 개요
- 이 경우엔 catch 안에선 아무것도 안 할 거예요 저 catch를 이용해 이 전체 테스트에서 공기를 내보내지 않도록 하고 있어요 그럼 동으로 전체 테스트가 실패하니까요

## 내용
### 자막·본문 기반 핵심 내용
- 이 경우엔 catch 안에선 아무것도 안 할 거예요 저 catch를 이용해 이 전체 테스트에서 공기를 내보내지 않도록 하고 있어요 그럼 동으로 전체 테스트가 실패하니까요
- 티켓 업데이트 리스너 테스트는 아주 잘 되고 있어요 두 테스트 모두 만족스러운 경로 테스트예요
- 모든 게 예상대로 되고 있다고 가정하고 있어요 적어도 한 가지 테스트를 추가하고 싶어요 나쁜 시나리오도 다룰 수 있는지 확인하기 다이어그램을 보여드리고 뭘 테스트할지 설명드리죠
- 이 다이어그램으로 돌아가죠 여러 번 봤잖아요 그리고 주문 데이터베이스에 Q라는 ID와 1의 버전이 있는 티켓이 있다고 여기 이 두 사건이 발산된다고 상상해 보세요
