## 내용
### 자막·본문 기반 핵심 내용
- 이것 전체를 weight ticket.bind by 이벤트로 만들 거예요. 데이터 개체를 이렇게 전달할게요
- 이런 동시성 문제 일부는 확실히 해결했지만 늘 그렇듯 여전히 우리 구현이 완전히 만족스럽진 않아요
- 개선할 점이 한두 가지 있는 것 같아요 티켓 업데이트 리스너에서 가장 먼저 살펴볼 것은 아주 흉한 이 복잡한 필터 세트를 추가해야 하는 곳을 찾아야 합니다 상상이 되시겠지만 이걸 나중에 많은 청취자에게 복사하면 아주 빨리 질리기 시작할 거예요
- 수수께끼의 밑줄 ID만 있는 게 아니라 ID 규칙을 따르려고 했던 곳이죠 데이터 버전도 1이 있어요 제 생각엔 다른 엔지니어들이 1을 보고 이럴 것 같아요 왜 1을 빼야 그렇게 하면 모든 게 부서지기 시작해요
