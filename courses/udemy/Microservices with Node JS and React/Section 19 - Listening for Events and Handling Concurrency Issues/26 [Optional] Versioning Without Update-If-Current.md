## 내용
### 자막·본문 기반 핵심 내용
- 이런 다른 종류의 정보 저장소에서 항상 같은 버전 관리 시맨틱을 사용할 필요는 없습니다 mongoose mongoose 업데이트처럼요
- 여기서 좀 서툴게 될 거예요 말하자면요 아시게 되면요 Mongoose 설명서를 보면 Model 클래스에 $ where 속성이라는 게 있어요
