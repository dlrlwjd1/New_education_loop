# Mongoose Update-If-Current

## 개요
- Mongoose Update if current라는 모듈을 살펴볼게요 원하신다면 문서를 살펴볼 수는 있어요

## 내용
### 자막·본문 기반 핵심 내용
- Mongoose Update if current라는 모듈을 살펴볼게요 원하신다면 문서를 살펴볼 수는 있어요
- 기본값으로 mongoose current update를 이용하는 모듈입니다. 밑줄을 이용해서 V 속성을 확인하려고 합니다. 밑줄을 이용해서 V는 큰 의미가 없어요.
- 티켓 서비스 먼저 살펴볼 모듈은 Mongoose와 함께 모든 버전 관리를 다룰 거예요
- derscore v을 이전에 보신 적이 있을 겁니다 mongoose를 우리가 쓰는 우체부요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `Mongoose`, `NPM`

## 예시
`Mongoose`, `NPM`가 등장하는 설정·코드 위치를 찾아 강의와 같은 순서로 확인한다.
