# A Quick Manual Test

## 개요
- 당신이 여전히 인증된 상태인지 확인하기 위해서요 API 사용자의 현재 사용자에게 get request를 할 수 있어요

## 내용
### 자막·본문 기반 핵심 내용
- 당신이 여전히 인증된 상태인지 확인하기 위해서요 API 사용자의 현재 사용자에게 get request를 할 수 있어요
- RAW와 JSON이 선택되었는지 확인하죠 티켓을 위한 속성을 입력할게요 작위와 가격이요
- 다시 로그인하는 대신 우체부 안에서 다른 탭을 열 수 있어요 API 사용자에게 게시 요청을 하고 싶을 거예요
- 보디로 JSON이 선택됐는지 확인하세요 그런 다음 이메일과 암호를 입력하세요 계좌를 개설하는 순간 인증된 것으로 간주되죠

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `API`, `request`, `JSON`

## 예시
`API`, `request`, `JSON`가 등장하는 설정·코드 위치를 찾아 강의와 같은 순서로 확인한다.
