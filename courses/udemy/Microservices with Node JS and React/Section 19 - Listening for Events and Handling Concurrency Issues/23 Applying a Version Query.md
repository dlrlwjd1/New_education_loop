# Applying a Version Query

## 개요
- 제가 인증되었는지도 아주 빨리 확인할게요 API 사용자와 현재 사용자죠 API 티켓에 요청을 게시하고 제목과 가격을 입력하죠

## 내용
### 자막·본문 기반 핵심 내용
- 제가 인증되었는지도 아주 빨리 확인할게요 API 사용자와 현재 사용자죠 API 티켓에 요청을 게시하고 제목과 가격을 입력하죠
- 버전 속성을 추가할게요 이건 그냥 여기죠 TypeScript의 불평 없이 티켓 버전 같은 코드를 쓸 수 있죠
- 하지만 예제를 보도록 하죠 그걸 고치는 방법에 대해서요 우체부 안이군요 먼저 탭으로 가서 API 티켓에 게시 요청을 할 거예요
- 입력 요청 탭으로 갈게요 여기 입력 요청 탭에요 API/표시에 요청을 넣도록 확실히 해둘게요

### 구현 요소
