# Strategies for Locking a Ticket

## 개요
- 주문 생성 리스너 안에 있어요 이 사건이 발생할 때마다 관련 티켓을 찾아서 어떻게든 봉쇄해야 이번 영상에서는 어떻게 티켓을 확보할 수 있는지 알아볼 거예요

## 내용
### 자막·본문 기반 핵심 내용
- 주문 생성 리스너 안에 있어요 이 사건이 발생할 때마다 관련 티켓을 찾아서 어떻게든 봉쇄해야 이번 영상에서는 어떻게 티켓을 확보할 수 있는지 알아볼 거예요
- 분명한 해결책이 있는 아주 분명한 문제처럼 보이겠죠 티켓 서비스 안에 있는 모든 다양한 티켓에 잠긴 속성이나 그 비슷한 걸 추가하자고 할 수도 있죠
- 불리언으로 하죠 로크가 참으로 설정되면 티켓이 잠긴 거니까 누구도 변경할 수 없게 해야 해요
- 주문 취소 이벤트가 보일 때마다 거짓으로 잠글 수 있어요 그럼 사람들이 이 티켓을 다시 편집할 수 있죠
