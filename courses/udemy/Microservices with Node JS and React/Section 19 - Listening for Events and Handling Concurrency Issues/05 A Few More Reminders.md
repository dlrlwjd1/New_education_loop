# A Few More Reminders

## 개요
- 대신에 Q그룹은 이 이벤트가 ORDER Services A나 ORDER Services BE로만 보내지도록 하죠

## 내용
### 자막·본문 기반 핵심 내용
- 대신에 Q그룹은 이 이벤트가 ORDER Services A나 ORDER Services BE로만 보내지도록 하죠
- 다이어그램을 잠깐 살펴보죠 이 다이어그램을 보면 왼쪽 상단에 게시자가 있죠 티켓 이벤트를 결국 게시하게 오른쪽은 네트 스트리밍 서버예요 주문 서비스 인스턴스 두 개를 듣고 있죠 티켓 생성이라는 채널로요
- 이 두 개의 주문 서비스가 이 채널에 연결되어 구독을 생성하면 그들은 주문 서비스라는 그룹을 가입했어요
- 이 그룹의 멤버가 되면 어떤 이벤트가 이 채널에 들어오든 해당 이벤트는 그룹 내의 한 멤버에게만 보내지게 되죠

### 구현 요소
- 강의 흐름에 따라 A Few More Reminders의 구현 목적과 적용 지점을 확인한다.
