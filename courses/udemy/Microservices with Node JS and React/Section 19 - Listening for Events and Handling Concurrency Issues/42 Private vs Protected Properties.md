# Private vs Protected Properties

## 개요
- 공통 모듈 CRC 이벤트로 가서 기본 리스너 TS를 찾죠 기억하실지 모르겠는데 리스너의 인스턴스를 만들 때나 리스너를 확장하는 어떤 것이요 그 점에선 나탈 클라이언트를 제공해야 하죠

## 내용
### 자막·본문 기반 핵심 내용
- 공통 모듈 CRC 이벤트로 가서 기본 리스너 TS를 찾죠 기억하실지 모르겠는데 리스너의 인스턴스를 만들 때나 리스너를 확장하는 어떤 것이요 그 점에선 나탈 클라이언트를 제공해야 하죠
- 이걸 사용하려면 인스턴스를 만들어야 해요 게시자의 Nets 클라이언트를 전달합니다 Nets 래퍼 클라이언트 같은 거죠 그리고 게시 기능을 부를게요
- 그런 다음 Nets 클라이언트를 여기 전달하고 싶어요 NAT 클라이언트를 제공하는 데는 두 가지 다른 방법이 있어요
- 순서대로 토론을 했으니 청취자를 만들어 주세요 티켓을 저장한 직후에 이벤트를 게시하고 싶어요 이 티켓이 방금 업데이트됐다고요
