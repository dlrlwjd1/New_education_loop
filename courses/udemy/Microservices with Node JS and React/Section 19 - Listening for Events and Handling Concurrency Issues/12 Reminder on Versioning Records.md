# Reminder on Versioning Records

## 내용
### 자막·본문 기반 핵심 내용
- 알고 보니 Mongoose와 MongoDB는 이 모든 버전을 자동으로 관리할 수 있어요
- 우리가 직접 할 필요는 없어요 MongoDB와 Mongoose는 버전 관리 문제를 스스로 해결할 수 있기 때문에 우리는 버전을 가지고 장난칠 필요가 전혀 없어요.
- 여기서 잠시 멈출게요 잠시 후, 다음 비디오에서는 버전 관리를 구현하기 위해 Mongoose와 MongoDB를 어떻게 사용하는지 볼게요.
- 작동하는 동시성 문제를 확인했어요 고칠 방법만 찾으면 돼요 오래전에 스트리밍 서버에 관해 처음 얘기할 때 이런 동시성 문제를 어떻게 해결할지에 관해 얘기했어요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `Mongoose`, `MongoDB`

## 예시
`Mongoose`, `MongoDB`가 등장하는 설정·코드 위치를 찾아 강의와 같은 순서로 확인한다.
