# Clear Concurrency Issues

## 개요
- 이 영상이 정말 기대돼요 이상한 동시성을 드디어 보게 됐으니까요 마지막 비디오 사이에 뭘 할지 말씀드리죠 테스트 스크립트를 이건 제가 만든 스크립트예요 아주 특정한 일련의 작업을 거치게 될 거죠

## 내용
### 자막·본문 기반 핵심 내용
- 이 영상이 정말 기대돼요 이상한 동시성을 드디어 보게 됐으니까요 마지막 비디오 사이에 뭘 할지 말씀드리죠 테스트 스크립트를 이건 제가 만든 스크립트예요 아주 특정한 일련의 작업을 거치게 될 거죠
- 스크립트를 실행하면 서버에 엄청나게 많은 요청이 쏟아질 거예요 스크립트가 실행되면 데이터의 일관성을 살펴볼 겁니다 두 데이터베이스 간에요 특정 사례에서 그걸 보게 될 거예요 이벤트가 순서대로 처리되지 않게 제가 준비한 이 테스트 스크립트에 대해 좀 더 말씀드리죠
- 이 테스트 스크립트를 실행할 필요는 없어요 아주 빨리 조립했어요 제대로 작동하게 하기 위해 몇 가지를 제 셋업을 살펴볼 거예요 당신 쪽에서 스크립트를 복제하는 대신에요
- 스크립트가 하는 일은 이거예요 이 스크립트는 5달러로 티켓을 만들려고 할 거예요 그런 다음 티켓을 10달러로 업데이트하고 마지막으로 티켓을 15달러로 전체 프로세스를 연속으로 200번 반복할 거예요

### 구현 요소
- 강의 흐름에 따라 Clear Concurrency Issues의 구현 목적과 적용 지점을 확인한다.
