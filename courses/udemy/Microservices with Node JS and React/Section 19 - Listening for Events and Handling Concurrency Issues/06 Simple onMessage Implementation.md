# Simple onMessage Implementation

## 개요
- 온 메시지 기능의 구현 작업을 시작할게요 먼저 주문 서비스 내부에 티켓이 생성된 이벤트로 우리가 해야 할 일을 잠시 상기시켜 드리죠

## 내용
### 자막·본문 기반 핵심 내용
- 온 메시지 기능의 구현 작업을 시작할게요 먼저 주문 서비스 내부에 티켓이 생성된 이벤트로 우리가 해야 할 일을 잠시 상기시켜 드리죠
- 여기 다이어그램을 보신 게 기억나실 거예요 주문 서비스로 오는 티켓 생성 이벤트가 있죠
- 주문 서비스에서 이 이벤트를 리스트하는 이유는 이 티켓에 대한 정보를 로컬 티켓 컬렉션에 저장하기 위해서예요
- 편집기 내부에서 on message 기능을 찾을 수 있어요 여기 있는 데이터 개체를 살펴볼 거예요

### 구현 요소
- 강의 흐름에 따라 Simple onMessage Implementation의 구현 목적과 적용 지점을 확인한다.
