# Did it Work?

## 개요
- 진실의 순간이 왔군요 이 모든 버전이 동시성 문제를 해결할 수 있을지 보죠 이 작은 테스트 스크립트를 다시 열었어요 상기시켜 드리자면 이 테스트 스크립트는 먼저 게시물을 생성하거나 게시물이 아니라 티켓을 5달러에 요청하려 할 거예요

## 내용
### 자막·본문 기반 핵심 내용
- 진실의 순간이 왔군요 이 모든 버전이 동시성 문제를 해결할 수 있을지 보죠 이 작은 테스트 스크립트를 다시 열었어요 상기시켜 드리자면 이 테스트 스크립트는 먼저 게시물을 생성하거나 게시물이 아니라 티켓을 5달러에 요청하려 할 거예요
- 10으로 업데이트하고 15로 업데이트할 거예요 결국 15달러로 모든 티켓을 볼 수 있을 거예요
- 동시에 진행되는 요청도 400건으로 늘렸고요 엄밀히 따지면 400 곱하기 3이니 실제로 1,200명가량의 요청이 법무부와 병렬적으로 이루어진 겁니다 엄밀히 따지면 병렬이 아니라 거의 동시에 실행된 거죠
- 그 너머로, 여기 두 개의 터미널 창이 열린 걸 기억하세요 둘 다 몽고DB와 직접 연결되어 있어요
