# Initializing the Listeners

## 개요

## 내용
### 자막·본문 기반 핵심 내용
- 아무것도 안 보이면 언제든 스캐폴드를 재시작할 수 있다는 걸 기억하세요 하지만 우리가 Nets, Connect, MongoDB에 연결됐다는 걸 보셨으면 좋겠네요
- NAT 스트리밍 서버 클라이언트의 인스턴스를 제공해야 한다는 걸 기억하세요 일단 인스턴스를 생성하면 그 인스턴스에서 Listen 메서드를 호출하죠
- 두 청취자 옆에서 마지막으로 할 일은 인시던트를 만들 때 인스턴스를 만드는 거예요
- 전혀 기억이 안 난다면요 듣는 사람이 적은 정의에서 명령 클릭을 할 수 있어요 생성자는 표준 클라이언트나 노드 스트리밍 서버 클라이언트의 인스턴스를 받길 기대해요 수신 기능은 특히 우리가 수신 트래픽을 듣는 걸 확실히 하죠
