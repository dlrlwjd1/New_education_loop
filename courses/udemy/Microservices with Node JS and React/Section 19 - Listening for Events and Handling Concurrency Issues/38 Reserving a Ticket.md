# Reserving a Ticket

## 개요
- 이 순서가 언급하는 티켓을 찾아보죠 이벤트가 언급하는 티켓은 중량 티켓이라고 치죠 ID data. ticket ID가 정의해요

## 내용
### 자막·본문 기반 핵심 내용
- 이 순서가 언급하는 티켓을 찾아보죠 이벤트가 언급하는 티켓은 중량 티켓이라고 치죠 ID data. ticket ID가 정의해요
- 티켓 문서 인터페이스로 돌아가세요 TypeScript가 티켓 문서나 티켓의 인스턴스도 주문 ID 속성이 있다는 걸 이해해야 해요
- 이게 선택적 속성이 될 거라는 걸 확실히 하기 위해 물음표를 TypeScript에 주문 ID가 문자열 아니면 정의되지 않은 게 된다고 하죠
- 실행을 시작하죠 먼저 티켓 서비스 안을 살펴보겠습니다 티켓 모델 파일로요 주문 ID를 티켓에 묶는다는 아이디어를 추가할 거예요
