# One More Test

## 개요
- 아니면 긍정적으로 테스트하고 통화 통제는 예상대로 잘 되고 있어요 지금 아주 작은 테스트를 하나 더 작성하고 싶어요 우리가 레코드를 저장하거나 업데이트할 때마다 버전 번호가 증가한다는 걸 증명할 게 아무것도 없는 테스트요

## 내용
### 자막·본문 기반 핵심 내용
- 아니면 긍정적으로 테스트하고 통화 통제는 예상대로 잘 되고 있어요 지금 아주 작은 테스트를 하나 더 작성하고 싶어요 우리가 레코드를 저장하거나 업데이트할 때마다 버전 번호가 증가한다는 걸 증명할 게 아무것도 없는 테스트요
- 아주 짧은 두 번째 테스트를 작성해 볼게요 레코드를 저장할 때마다 페치하면 버전 번호가 1로 증가하는 걸 볼 수 있도록요
- 파일의 맨 밑으로 내려갈게요 다른 구문을 작성하면 여러 개의 세이브에서 버전 넘버를 증가시키죠
- 이 안에서 다시 한 번 새 티켓을 생성할 거예요 우리가 구할 거예요 저장 티켓은 버전 수가 0이어야 해요

### 구현 요소
- 강의 흐름에 따라 One More Test의 구현 목적과 적용 지점을 확인한다.
