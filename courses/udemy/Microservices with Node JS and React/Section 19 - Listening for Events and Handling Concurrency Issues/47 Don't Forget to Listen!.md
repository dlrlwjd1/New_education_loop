# Don't Forget to Listen!

## 개요
- 나츠 연결 문제부터 해결하고요 새로운 주문 생성 리스너를 넣을게요 nets repr 클라이언트를 통과할 겁니다 인스턴스만 만드는 건 충분하지 않다는 걸 기억하세요

## 내용
### 자막·본문 기반 핵심 내용
- 나츠 연결 문제부터 해결하고요 새로운 주문 생성 리스너를 넣을게요 nets repr 클라이언트를 통과할 겁니다 인스턴스만 만드는 건 충분하지 않다는 걸 기억하세요
- 주문이 취소됐어요 청취자 상태가 좋아요 티켓 서비스를 마무리하기 위해 몇 가지만 더 할게요
- 먼저, 두 명의 리스너가 생겼으니 주문 취소와 주문 생성이죠 하지만 어떤 시점에서도 새 소식을 듣기 시작하진 않죠
- 둘 다의 인스턴스를 만들어 둘 다에 Nets 래퍼 클라이언트를 넘기죠 스크롤을 좀 내릴게요
