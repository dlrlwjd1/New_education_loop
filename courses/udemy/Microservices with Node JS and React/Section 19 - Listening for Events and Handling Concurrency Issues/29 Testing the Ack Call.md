# Testing the Ack Call

## 개요
- 청취자 테스트는 통과했지만 다른 결점도 있어요 우리가 모든 실패를 바로잡을 거예요

## 내용
### 자막·본문 기반 핵심 내용
- 청취자 테스트는 통과했지만 다른 결점도 있어요 우리가 모든 실패를 바로잡을 거예요
- 조금 전에 티켓 모델을 변경했거든요 하지만 먼저 티켓이 생성된 리스너를 둘러싼 테스트를 마무리하죠
- W와 P를 눌러서 테스트를 필터링하고 티켓 생성 리스너 파일 이름을 입력할게요 티켓 생성 리스너만 있으면 충분할 거예요
- 시험의 정점에서 시작해 보죠 데이터 리스너와 대기 셋업 메시지죠 그런 다음 on message 함수를 호출해 데이터 객체와 메시지 객체를 전달하고 리스너를 기다리죠

### 구현 요소
- 강의 흐름에 따라 Testing the Ack Call의 구현 목적과 적용 지점을 확인한다.
