# Missing Update Event

## 개요
- 이 이벤트는 for ticket ID라고 말할 거예요 예약하기 위해 생성한 게 바로 이거죠

## 내용
### 자막·본문 기반 핵심 내용
- 이 이벤트는 for ticket ID라고 말할 거예요 예약하기 위해 생성한 게 바로 이거죠
- 우리 질서가 만들어졌죠 청각은 양호하고 검사도 좀 했어요 청취자 인터뷰는 끝났어요
- 지금쯤은 그랬겠죠 청취자 얘기는 아직 안 끝났어요 알고 보니 이 안에 숨겨진 이슈가 있더군요 지금 이 상태로 코드를 배포하면 아주 쉽게 문제가 될 수 있어요
- 다이어그램을 살펴보고 작은 실수를 이해하도록 하죠 일련의 다이어그램을 살펴볼 거예요 우리 앱 내부의 잠재적 흐름에 관해 알려드릴 이 일련의 특정 작업의 내부를 보게 될 거예요

### 구현 요소
- 강의 흐름에 따라 Missing Update Event의 구현 목적과 적용 지점을 확인한다.

## 예시
다이어그램을 살펴보고 작은 실수를 이해하도록 하죠 일련의 다이어그램을 살펴볼 거예요 우리 앱 내부의 잠재적 흐름에 관해 알려드릴 이 일련의 특정 작업의 내부를 보게 될 거예요
