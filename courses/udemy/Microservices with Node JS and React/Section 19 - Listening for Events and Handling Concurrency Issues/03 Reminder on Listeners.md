# Reminder on Listeners

## 개요
- 리스너를 생성하는 방법에 대해 잠깐 상기시켜드리죠 CRC 디렉터리와 이벤트 폴더의 공통 모듈에서 기본 리스너 클래스를 생성했었죠

## 내용
### 자막·본문 기반 핵심 내용
- 리스너를 생성하는 방법에 대해 잠깐 상기시켜드리죠 CRC 디렉터리와 이벤트 폴더의 공통 모듈에서 기본 리스너 클래스를 생성했었죠
- 추상화 수업이었어요 우린 이걸 확장해 우리 서비스 내부에 다양한 클래스를 빌드할 겁니다 특정 이벤트에 반응하는 우리 서비스 내에요
- 이 수신기를 확장하면 이벤트 유형을 제네릭 유형으로 제공하는지 확인해요 그리고 하위 클래스 내에서도 피사체를 정의하는 것을 요구할 거예요.
- 스트리밍 서버에서 듣고 싶은 주제예요 그룹 이름 큐 그게 뭔지 빨리 알려드리죠 그리고 마지막으로 온 메시지 기능 온 메시지 기능은 실제로 이벤트를 수신하는 그게 우리가 구현할 비즈니스 로직의 양이죠

### 구현 요소
- 강의 흐름에 따라 Reminder on Listeners의 구현 목적과 적용 지점을 확인한다.
