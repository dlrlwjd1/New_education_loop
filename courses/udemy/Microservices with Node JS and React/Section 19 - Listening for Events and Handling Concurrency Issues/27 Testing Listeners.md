# Testing Listeners

## 개요
- 온메시지 함수가 적절한 일을 하도록 하는 거죠 이 경우에는 티켓 생성 리스너에 대해서 유효한 데이터 객체와 메시지를 전달하면 티켓을 생성하고 데이터베이스에 저장해야 합니다 그리고 message work, function 혹은 지식 기능을 호출해야 하죠
