# Success Case Testing

## 개요
- 첫 번째 테스트의 내부죠 셋업 함수를 호출하고 메시지 데이터 개체 티켓과 await에서 리스너를 청취자를 데려갈 수 있어요

## 내용
### 자막·본문 기반 핵심 내용
- 첫 번째 테스트의 내부죠 셋업 함수를 호출하고 메시지 데이터 개체 티켓과 await에서 리스너를 청취자를 데려갈 수 있어요
- 이 두 가지 테스트를 마무리하죠 이 두 테스트에서 셋업 함수를 호출해야 해요 기억하세요, 함수 집합은 동기화이고 이번엔 실제로 비동기화돼야 합니다 표를 생성해 데이터베이스에 저장할 거니까요
- 동 메시지 기능을 호출하겠습니다 데이터 객체와 메시지와 함께요 그리고 예상대로 작동되는지 확인하기 위해 몇 가지 기대 사항을 적을 수 있어요
- 새 또는 데이터 개체를 처리했는지 확인하세요 방금 다시 페치한 이 새 티켓에 업데이트된 타이틀과 가격이 있는지 확인해야 업데이트된 버전도 있는지 확인해야 할 수도 있어요
