# Time for Listeners!

## 개요
- 우리 주문 서비스에 출판업자들이 모였네요 이 시점에서 전 정말 흥분돼요 왜냐하면 주문 서비스와 티켓 서비스 안에서 게시자가 사용 가능하거든요

## 내용
### 자막·본문 기반 핵심 내용
- 우리 주문 서비스에 출판업자들이 모였네요 이 시점에서 전 정말 흥분돼요 왜냐하면 주문 서비스와 티켓 서비스 안에서 게시자가 사용 가능하거든요
- 지금부터 할 일은 이거예요 이 두 서비스에 많은 청취자를 모실 텐데요 리스너의 목표는 양쪽 서비스 내에서 수신 이벤트를 처리하는 겁니다
- 두 개의 다른 리스너를 만들어야 해요 이 다이어그램을 기억하실 겁니다 다양한 이벤트가 어디서 오고 어디로 가는지에 대한 다이어그램이죠
- 티켓 생성 이벤트에 대해 주문 서비스가 이 이벤트를 받거나 티켓 생성 이벤트를 듣는지 확인해야 해요

### 구현 요소
- 강의 흐름에 따라 Time for Listeners!의 구현 목적과 적용 지점을 확인한다.
