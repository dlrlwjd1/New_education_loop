# Client Health Checks

## 개요
- 큰 문자 덩어리만 보일 수도 있어요 멋지게 포맷된 게 보이네요 크롬 확장을 실행 중이거든요 브라우저 안에서 JSON을 자동으로 포맷하는 동일한 확장을 실행하고 싶다면 크롬 확장 스토어에 들어가 JSON을 비슷한 사람을 쉽게 찾을 수 있어요

## 내용
### 자막·본문 기반 핵심 내용
- 큰 문자 덩어리만 보일 수도 있어요 멋지게 포맷된 게 보이네요 크롬 확장을 실행 중이거든요 브라우저 안에서 JSON을 자동으로 포맷하는 동일한 확장을 실행하고 싶다면 크롬 확장 스토어에 들어가 JSON을 비슷한 사람을 쉽게 찾을 수 있어요
- 둘, 둘, 둘요 브라우저를 열고 로컬 호스트 8222로 탐색하면 실행 중인 NATS 서버에 관한 모니터링 정보가 출력될 거예요
- 이 탭 중 하나나 이 링크 중 하나를 클릭할 때마다 멋지게 형식화된 JSON 데이터가 보여요
- 하나는 2대 2 클라이언트를 연결하기 위한 거죠 8 2 to 2에 모니터링이란 포트가 하나 더 있어요 이 모니터링 포트에서 NAT 스트리밍 서버에 접근할 수 있죠
