# Manual Ack Mode

## 개요
- 옵션이라 불리는 새 변수를 생성하고 스탠 구독 옵션에서 이걸 JavaScript의 대부분의 라이브러리에서는 옵션을 설정할 수 있어요 개체를 여기로 넘기거나 그런 식으로요

## 내용
### 자막·본문 기반 핵심 내용
- 옵션이라 불리는 새 변수를 생성하고 스탠 구독 옵션에서 이걸 JavaScript의 대부분의 라이브러리에서는 옵션을 설정할 수 있어요 개체를 여기로 넘기거나 그런 식으로요
- 그걸 설정하려면 구독 옵션 호출로 바꿔야 해요 따라서 총 몇 가지 다른 옵션을 설정할 수 있습니다 Set Deliver 같은 걸 사용 가능한 세트 같은 것도 괜찮고요
- 지난 비디오에선 Q 그룹을 설정하기 위해 구독 호출에 두 번째 인수를 추가했죠 구독을 사용자 지정할 수 있는 많은 다른 방법이 있어요
- 여기 보이는 처음 두 개의 인수는 우리가 듣고자 하는 채널의 이름이에요 Q 그룹 이름은 간단한 문자열로 제공되죠
