# Client ID Generation

## 개요
- 주문 서비스를 수직으로 확장할 수도 있습니다 주문 서비스에 더 강력한 CPU와 RAM 등을 제공함으로써요

## 내용
### 자막·본문 기반 핵심 내용
- 주문 서비스를 수직으로 확장할 수도 있습니다 주문 서비스에 더 강력한 CPU와 RAM 등을 제공함으로써요
- 물론 두 서비스 모두 NAT 스트리밍 서버에 연결할 수 단말기 안에서 단말기를 한 번 더 열어 보죠
- 이 시점에서 저희 테스트 응용 프로그램은 게시자 하나와 리스너 하나가 안에 있죠 우리가 이 테스트 응용 프로그램을 쿠버네테스 클러스터에 배포한다고 가정해 보죠
- 실제 응용 프로그램에 사용할 수도 있어요 어떤 시점에서 주문 서비스가 트래픽을 많이 받는다는 걸 깨달을 수도 있어요 그럼 어떤 식으로든 주문 서비스를 확장하기로 하죠

### 구현 요소
