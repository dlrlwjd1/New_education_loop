# Three Important Items

## 개요
- 두 번째 브라우저 탭에서 Hub Docker를 탐색해 볼게요 그런 다음 여기 오면 상단에서 Nets를 검색하죠

## 내용
### 자막·본문 기반 핵심 내용
- 두 번째 브라우저 탭에서 Hub Docker를 탐색해 볼게요 그런 다음 여기 오면 상단에서 Nets를 검색하죠
- 3번 같아요 이 페이지는 계속 열어둘 겁니다 NAT 스트리밍 이미지에 관한 Docker Hub 문서요 사용 가능한 다양한 명령줄 옵션을 살펴볼 수 있도록요
- 응용 프로그램 등에 추가한 새 서비스를 동기화하는 방법도요 쿠버네츠 클러스터 내부에서 스트리밍 서버를 실행하겠습니다 공식 Docker 이미지인 Nets 스트리밍을 사용해서요
- 지금 Docker Hub에 있는 이미지 문서를 살펴보죠 이걸 어떻게 실행할지 더 나은 아이디어를 얻기 위해서요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `Docker`, `Docker Hub`

## 예시
`Docker`, `Docker Hub`가 등장하는 설정·코드 위치를 찾아 강의와 같은 순서로 확인한다.
