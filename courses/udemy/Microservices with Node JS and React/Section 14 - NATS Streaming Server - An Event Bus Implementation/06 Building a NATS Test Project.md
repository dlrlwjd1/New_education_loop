# Building a NATS Test Project

## 개요
- 새 하위 프로젝트를 생성하겠습니다 현재 프로젝트 디렉터리 안에요 TypeScript 지원을 받게 할 거예요 TypeScript를 쓰면서 노드 나탈 스트리밍하는 방법을 이해하고 싶으니까요

## 내용
### 자막·본문 기반 핵심 내용
- 새 하위 프로젝트를 생성하겠습니다 현재 프로젝트 디렉터리 안에요 TypeScript 지원을 받게 할 거예요 TypeScript를 쓰면서 노드 나탈 스트리밍하는 방법을 이해하고 싶으니까요
- 설치하는 데 1, 2분밖에 안 걸려요 실행되는 동안 편집기로 돌아가서 새로운 Nets-\ test directory를 찾아보죠
- Natt Stash 테스트 디렉터리 안에 TSE-Hash가 있어요 물론 이 명령은 여러분의 시스템에 TypeScript가 전면적으로 설치됐다고 가정하죠
- 거기서 오류가 발생하면 NPM을 해야 합니다 dmg typecript를 설치하고 tsk를 재실행하세요
