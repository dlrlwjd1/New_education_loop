## 내용
### 자막·본문 기반 핵심 내용
- 그 안에 오브젝트가 있어요 URL이 있을 거예요 지난번과 아주 비슷해요 2에서 2까지 http localhost 포트요
- 그 안에 RPM 실행 수신기를 실행할 거예요 RPM 작동해요 대본 이름을 약간 바꿨어요 ampm, run, listen 그런 것 같네요
- 핵심 키는 command DX예요 그래서 command를 누르면 화면이 나뉘죠 이벤트가 게시되고 들리는 걸 볼 수 있게 해주죠
- 대신 메시지로 통하죠 메시지 용어가 떠다니는 게 보이실 거예요 이것에 대한 인수가 실제 메시지가 될 겁니다 우리가 단순 MSG로 종종 줄이는 여기 있는 MSG는 단순한 원시 데이터가 아니에요
