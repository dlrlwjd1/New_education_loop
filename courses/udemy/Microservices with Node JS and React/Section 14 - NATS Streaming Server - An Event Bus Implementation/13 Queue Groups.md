# Queue Groups

## 개요
- 더 나은 형식은 Q그룹이라고 이름짓는 것이겠죠 합류하는 서비스 유형에 따라서요 우리는 여기에 Q 그룹이 있습니다. 오직 OrderService join의 복사본만 가지고 아마 더 나은 이름은 Orders Service Q 그룹 같은 것이겠죠

## 내용
### 자막·본문 기반 핵심 내용
- 더 나은 형식은 Q그룹이라고 이름짓는 것이겠죠 합류하는 서비스 유형에 따라서요 우리는 여기에 Q 그룹이 있습니다. 오직 OrderService join의 복사본만 가지고 아마 더 나은 이름은 Orders Service Q 그룹 같은 것이겠죠
- 잠시 메모리에 이 게시물들을 저장하지 않는다고 가정해보죠 이 게시물들을 어떤 종류의 MongoDB 데이터베이스나 다른 비슷한 종류의 데이터베이스에 저장한다고 가정해보죠
- 이 채널 안에 Ticket Colon이라는 채널이 생성됐어요 큐 그룹을 만들 거예요
- 출판사는 하나 청취자는 둘이죠 퍼블리셔를 재시작해 또 다른 이벤트를 내보내죠 RC에 엔터키를 입력하면 콘솔 로그 2개를 볼 수 있어요 각각에서 둘 다 똑같은 일을 겪은 것 같아요 배열 번호가 52인 사건요
