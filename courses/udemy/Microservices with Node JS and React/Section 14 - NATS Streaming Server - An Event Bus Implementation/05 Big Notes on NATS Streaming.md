# Big Notes on NATS Streaming

## 개요
- NPM에 관한 관련 문서를 지금 살펴보죠 새 브라우저 탭을 열고 NPM 체스로 이동할게요 컴이요

## 내용
### 자막·본문 기반 핵심 내용
- NPM에 관한 관련 문서를 지금 살펴보죠 새 브라우저 탭을 열고 NPM 체스로 이동할게요 컴이요
- 액시오나 익스프레스는 이벤트 처리에만 전념하지 않아요 여전히 일반적인 HTTP 요청에 액시오스나 Express를 쓸 거예요
- 이건 아주 단순한 방법이었어요 우린 액시오스나 익스프레스의 라이브러리에 의존했죠 지금은 스트리밍 서버를 사용하고 있지만 Express나 액시오스를 이용해 응용 프로그램 주변 이벤트를 공유하진 않을 거예요
- 이 설명서와 관련해 지적하고 싶은 게 하나 있어요 기본 사용 섹션을 보시면 이 라이브러리와 작업하려면 이벤트 기반의 아키텍처가 있는 게 보이실 다른 말로 하자면 노드의 이벤트 이미터에 익숙하시다면요 js나 다른 종류의 이벤트 라이브러리에서 이벤트를 방출하고 일반 JavaScript 코드로 듣는 거죠 이 라이브러리는 그렇게 작동해요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `Express`, `NPM`, `JavaScript`, `HTTP`
