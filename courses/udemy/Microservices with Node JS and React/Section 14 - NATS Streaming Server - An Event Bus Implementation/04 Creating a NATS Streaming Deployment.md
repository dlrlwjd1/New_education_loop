## 내용
### 자막·본문 기반 핵심 내용
- V1의 API 버전을 넣을 거예요 일종의 서비스죠 메타데이터와 이름은 Nets SRB예요
- 이 안에서 배포를 쓸 거예요 우리가 이미 생성한 것과 아주 유사하죠 맨 위엔 API 버전 앱/V1을 작성하고요
- 우리가 지금까지 배포한 것처럼 인프라 디렉터리의 코드 편집기로 갈 거예요 k 폴더 안에 netsd벨 html이라는 새 파일이 만들어져요
- 이 안에 넣은 각각의 개별 인수는 이 배열 안에서 개별 문자열로 분리될 예를 들어 여기 문서를 보면 우리가 rst 플래그를 사용할 때 문자열을 제공한다고 RST를 제공하고 문자열 인수를 주려면 EST를 입력하고 그런 다음 여기 다른 실제로 설정하진 않겠지만 우리가 설정하게 될 인수는 여기 다양한 인수가 목록에 있는데 아주 길어질 거예요
