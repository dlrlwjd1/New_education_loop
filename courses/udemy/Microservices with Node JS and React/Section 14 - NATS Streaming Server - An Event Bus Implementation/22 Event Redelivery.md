# Event Redelivery

## 개요
- 테스트, 세트, 배달 가능한 건 다 해 보죠 이 구독 옵션을 객체에 추가하면 구독이 생성될 때마다 NATS는 그 구독이 생성되기 전이나 다운될 동안 우리가 놓친 이벤트들을 모두 전송하려 할 거예요

## 내용
### 자막·본문 기반 핵심 내용
- 테스트, 세트, 배달 가능한 건 다 해 보죠 이 구독 옵션을 객체에 추가하면 구독이 생성될 때마다 NATS는 그 구독이 생성되기 전이나 다운될 동안 우리가 놓친 이벤트들을 모두 전송하려 할 거예요
- 저희가 제작한 커스텀 이벤트 버스와 현재 사용 중인 나탈 스트리밍을 통해서요 한 가지 정말 중요한 건 서비스가 오프라인인 동안 상당 기간 오프라인을 처리할 수 있어야 한다는 거죠
- 여기서 발산되는 어떤 사건도 처리하지 못할 거예요 이게 다시 작동하면 놓친 이벤트 목록을 줄 수 있어야 해요
- 방법을 찾아야 해요 이 비디오에서 제공하는 나탈 스트리밍을 통해 먼저 살펴볼 것은 순진한 방법입니다 그런 다음 몇 가지 다른 옵션을 결합해 이상적인 해결책을 스트리밍에 이벤트를 내보내거나 게시할 때마다 이 채널에 내부적으로 저장될 계좌 예금 70 같은 걸 내보낼 수도 있어요
