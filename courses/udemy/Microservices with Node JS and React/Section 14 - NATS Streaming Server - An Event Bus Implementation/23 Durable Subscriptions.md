# Durable Subscriptions

## 개요
- 이걸 처음 시작할 때 사용 가능한 모든 걸 배달하겠다고 했죠 그런 다음 Accounting Services 구독명을 설정합니다 재시작을 위해서요 Accounting Services 구독은 이미 모든 걸 사용 가능하게 했으니 다시 배달될 일이 없죠

## 내용
### 자막·본문 기반 핵심 내용
- 이걸 처음 시작할 때 사용 가능한 모든 걸 배달하겠다고 했죠 그런 다음 Accounting Services 구독명을 설정합니다 재시작을 위해서요 Accounting Services 구독은 이미 모든 걸 사용 가능하게 했으니 다시 배달될 일이 없죠
- ABC라는 이름이나 ID로 웰 구독을 만든다고 가정해보죠 하나, 둘, 셋 좋아요, 구독을 생성하면 내부적으로 우리가 구독하거나 듣는 채널 안에 있어요 우리가 가진 모든 다양한 구두 구독 목록의 레코드를 생성하죠
- 우리가 사건을 방출할 때마다 NASA가 그 사건을 수신하고 성공적으로 처리했는지 여기서 이벤트를 내보낸다고 칩시다 1번, 혹은 시퀀스 1번이 우리 서비스로 우리 서비스는 이 이벤트를 인식하고 이걸 성공적으로 처리했다고 말할 수 있죠
- 성공적으로 처리되자마자 이 구두 구독 옆에 작은 레코드를 저장할 ABC 1, 2, 3이 처리되었다고 나오죠
