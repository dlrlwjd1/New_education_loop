# Publishing Events

## 개요
- ID를 줄 거예요 콘서트 제목과 20달러 정도요 눈엣가시 같은 게 있는데요 문자열이나 원시 데이터만 공유할 여기 있는 건 우리가 공유하고 싶은 개체예요 일반 JavaScript 개체는 직접 공유할 이걸 공유하거나 스트리밍 서버로 보내려면 먼저 JSON으로 변환해야 합니다

## 내용
### 자막·본문 기반 핵심 내용
- ID를 줄 거예요 콘서트 제목과 20달러 정도요 눈엣가시 같은 게 있는데요 문자열이나 원시 데이터만 공유할 여기 있는 건 우리가 공유하고 싶은 개체예요 일반 JavaScript 개체는 직접 공유할 이걸 공유하거나 스트리밍 서버로 보내려면 먼저 JSON으로 변환해야 합니다
- 평면 문자열이죠 기본적으로 모든 데이터를 스트리밍 서버로 보내기 전에 JSON으로 JSON으로 마무리할 거예요
- 이벤트가 게시됐어요 이 파일을 저장하죠 패키지 JSON 스크립트에서 사용하는 노드 개발자 프로그램은 게시자 파일을 저장하자마자 자동으로 다시 실행해요
- 오른쪽에 NAT 스트리밍 서버가 있어요 그 안에 채널 목록이 있죠 기억하세요, 내셔널지오그래픽 세계에선 항상 특정 채널에 정보를 게시해요
