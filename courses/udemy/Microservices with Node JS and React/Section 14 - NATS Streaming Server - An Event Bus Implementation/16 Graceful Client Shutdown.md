# Graceful Client Shutdown

## 개요
- 그러기 위해서 리스너와 게시자에 코드를 추가하겠습니다 이 코드 안에 리스너나 게시자 프로그램이 종료될 시점을 감지하기 위해 코드를 서버가 닫히려는 걸 감지하는 순간 그걸 가로채서 스탠 클라이언트나 NAT 클라이언트에게 서버에 종료 요청을 보내라고 말할 겁니다 오프라인인 걸 알아두라고요

## 내용
### 자막·본문 기반 핵심 내용
- 그러기 위해서 리스너와 게시자에 코드를 추가하겠습니다 이 코드 안에 리스너나 게시자 프로그램이 종료될 시점을 감지하기 위해 코드를 서버가 닫히려는 걸 감지하는 순간 그걸 가로채서 스탠 클라이언트나 NAT 클라이언트에게 서버에 종료 요청을 보내라고 말할 겁니다 오프라인인 걸 알아두라고요
- 이 안이에요, 스탠 클로즈업이요 우리가 이 클라이언트를 닫거나 실행 중인 서버와의 연결을 끊으려고 할 때마다 우린 NAT의 콘솔 로그를 할 거예요
- 맨 밑에 파일도 있어요 처리기 2개를 추가할 거예요 누군가 이 프로세스를 종료하려 할 이걸 닫는 예는 이거예요 이 창을 선택하고 Ctrl C를 하면 되죠
- 윈도우를 이용한다면 윈도우는 항상 같은 종류의 Sig와 Sig 용어를 사용하지는 않아요

### 구현 요소
- 강의 흐름에 따라 Graceful Client Shutdown의 구현 목적과 적용 지점을 확인한다.
