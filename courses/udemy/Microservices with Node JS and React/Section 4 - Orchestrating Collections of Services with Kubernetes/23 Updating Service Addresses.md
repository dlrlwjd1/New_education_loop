# Updating Service Addresses

## 개요
- 대신 클러스터 IP 설문 조사를 게시하도록 요청합니다 그래야 게시 지점에 엑세스할 수 다시 터미널로 가서 CTL을 하고 Get Services를 하고 이름을 확인하죠

## 내용
### 자막·본문 기반 핵심 내용
- 대신 클러스터 IP 설문 조사를 게시하도록 요청합니다 그래야 게시 지점에 엑세스할 수 다시 터미널로 가서 CTL을 하고 Get Services를 하고 이름을 확인하죠
- Docker를 하고 Docker ID를 빌드합니다 슬래시 게시물과 점을 맨 끝에 붙이죠
- 이벤트 버스도 똑같이 해 줘요 이벤트 버스 코드를 열게요 POST 서비스나 POST 응용 프로그램에 요청을 할 때마다 해당 URL도 업데이트하도록 하죠
- 상기시켜 드리자면 다이어그램이 어디 있죠? 코드를 업데이트 했어요 그걸 배포하려면 이미지나 이벤트 버스를 다시 빌드해야 해요 그럼 4개의 게시물이 해당 이미지를 Docker Hub에 푸시하고 명령 큐, CTL 어쩌고저쩌고를 배포 이름으로 실행하죠

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `Docker`, `Docker Hub`, `Docker ID`

`Docker`, `Docker Hub`, `Docker ID`가 등장하는 설정·코드 위치를 찾아 강의와 같은 순서로 확인한다.
