# Building a Deployment for the Event Bus

## 개요
- 이벤트 버스 디렉터리 내부로 돌아가서 docker가 docker ID/ 이벤트 대시 버스를 푸시해요

## 내용
### 자막·본문 기반 핵심 내용
- 이벤트 버스 디렉터리 내부로 돌아가서 docker가 docker ID/ 이벤트 대시 버스를 푸시해요
- 먼저 이벤트 버스를 위한 이미지를 만들 거예요 Docker Hub에 그 이미지를 푸시하세요
- 그런 이미지는 아주 빨리 형성돼요 그게 1단계예요 두 번째 단계는 해당 이미지를 Docker Hub로 푸시하는 겁니다 포드를 만들 때 배포가 해당 이미지를 아주 쉽게 풀다운할 수 있도록요
- 우리가 방금 구축한 이미지를 Docker Hub에 전송하죠 이미지가 아주 작아서 1, 2분 정도 걸릴 거예요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `Docker`, `Docker Hub`, `docker ID/`
