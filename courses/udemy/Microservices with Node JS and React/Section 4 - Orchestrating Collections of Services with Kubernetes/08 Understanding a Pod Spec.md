# Understanding a Pod Spec

## 개요
- 이미지 속성도 제공하는데 일부 이미지에 정확히 적용되는 태그죠 한 가지 눈에 띄는 건 제가 여기 버전 번호를 맨 끝에 입력했다는 겁니다 Docker의 배경 지식을 통해 기억하실 텐데요 막판에 버전을 제공하지 않으면 Docker는 모든 시나리오에서 최신을 기본값으로 설치하게 됩니다 여러분이 최신이 저기 끝에 있거나 최신을 의미하는 게 아무것도 없는 포드를 적용하거나 만들려고 할 경우에요 그럼 쿠버네츠의 기본값 동작은 Docker Hub에 연락해 Docker Hub에 나열된 이 이미지를 찾는 거죠

## 내용
### 자막·본문 기반 핵심 내용
- 이미지 속성도 제공하는데 일부 이미지에 정확히 적용되는 태그죠 한 가지 눈에 띄는 건 제가 여기 버전 번호를 맨 끝에 입력했다는 겁니다 Docker의 배경 지식을 통해 기억하실 텐데요 막판에 버전을 제공하지 않으면 Docker는 모든 시나리오에서 최신을 기본값으로 설치하게 됩니다 여러분이 최신이 저기 끝에 있거나 최신을 의미하는 게 아무것도 없는 포드를 적용하거나 만들려고 할 경우에요 그럼 쿠버네츠의 기본값 동작은 Docker Hub에 연락해 Docker Hub에 나열된 이 이미지를 찾는 거죠
- 간단한 다이어그램을 보죠 왼쪽에는 구성 파일의 모든 라인이 있고 오른쪽에는 몇 가지 처음 작성한 게 API 버전 V1이었죠
- 쿠버네츠에게 생성하고자 하는 사용자 지정 개체도 말할 수 있어요 여기 이 API 버전의 목적은 쿠버네츠에게 우리가 그림 그릴 객체의 풀에 대해 알려주는 이 경우엔 쿠버네츠에게 명령하죠 우리가 만들 수 있는 기본값 V1 쿠버네츠 개체 목록을 오른쪽 다음 줄에서 그 다음 줄에서 해당 풀에서 생성하기 원하는 정확한 형식의 개체를 명시해요
- Docker Hub에 이 이미지를 푸시하지 않았어요 만약 그랬다면 오류가 발생했겠죠
