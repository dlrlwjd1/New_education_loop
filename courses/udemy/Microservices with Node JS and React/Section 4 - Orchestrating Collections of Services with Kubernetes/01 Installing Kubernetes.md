# Installing Kubernetes

## 개요
- 이 비디오의 설정을 살펴보죠 두 가지 가능성이 있어요 Windows에 대해 Docker를 실행하거나 Mac에 대해 Docker를 실행하거나 Docker Toolbox나 Linux를 실행하죠

## 내용
### 자막·본문 기반 핵심 내용
- 이 비디오의 설정을 살펴보죠 두 가지 가능성이 있어요 Windows에 대해 Docker를 실행하거나 Mac에 대해 Docker를 실행하거나 Docker Toolbox나 Linux를 실행하죠
- 솔직히 말씀 드릴게요 Docker Toolbox를 사용한다면 여기서 현실은 Docker Toolbox가 아주 안정적이지 않다는 잘못될 가능성은 무궁무진해요
- Mac이나 Windows를 위한 Docker를 실행 중이란 걸 알게 되죠 시스템 트레이 내부에 작은 아이콘이 있다면요
- 나쁜 소식이 있어요 불행히도 셋업은 Docker Toolbox나 Linux를 실행하면 좀 더 복잡해요
