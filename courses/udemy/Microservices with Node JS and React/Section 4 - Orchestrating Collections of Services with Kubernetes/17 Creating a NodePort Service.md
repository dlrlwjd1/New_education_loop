# Creating a NodePort Service

## 개요
- Post Dash CRV라는 새 파일을 만들어요 HTML CRV는 서비스란 뜻이죠

## 내용
### 자막·본문 기반 핵심 내용
- Post Dash CRV라는 새 파일을 만들어요 HTML CRV는 서비스란 뜻이죠
- 우리가 전에 작성한 배포 파일이나 포드 파일과 아주 흡사한 구성을 작성할 거예요 먼저 그것의 API 버전으로 시작할게요
- YAML에 배열 항목을 설정했다는 걸 기억하세요 저기 작은 대시를 넣어서요 대시하고 이름을 붙이죠
- 방금 네 가지 서비스에 관해 얘기했는데요 우리만의 서비스를 만들진 않을 거예요 먼저 노드 포트 생성에 초점을 맞출게요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `API`, `YAML`
