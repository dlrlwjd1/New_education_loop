# Skaffold Setup

## 개요
- 클라이언트 컨텍스트를 넣으세요 Docker에 중첩된 Docker 파일을 넣어 그 값은 대문자 D가 있는 Docker 파일이 동기화할 거예요

## 내용
### 자막·본문 기반 핵심 내용
- 클라이언트 컨텍스트를 넣으세요 Docker에 중첩된 Docker 파일을 넣어 그 값은 대문자 D가 있는 Docker 파일이 동기화할 거예요
- 이 시나리오는 한 번만 배우고 적절한 때 복사 붙여넣기를 Scaffold V2, 알파 3 API 버전을 쓸게요
- Docker ID 이미지를 입력할 테니 여러분한텐 dock ID/Client가 되겠죠
- 이 매니페스트 라인을 추가함으로써 모든 다른 YAML 파일을 보길 원한다고 스캐폴드에게 파일 중 하나를 변경할 때마다 스캐폴드는 자동으로 그 구성 파일을 쿠버네티스 클러스터에 다시 적용해요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `API`, `YAML`, `Docker`, `JavaScript`, `JSON`, `React`, `Docker

Hub`, `Docker ID`, `Docker ID/notash`
