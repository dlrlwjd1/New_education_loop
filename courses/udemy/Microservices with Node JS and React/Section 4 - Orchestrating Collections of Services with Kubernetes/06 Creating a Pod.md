## 내용
### 자막·본문 기반 핵심 내용
- Dashti를 입력하고 Docker ID/ posts를 입력합니다 그런 다음 호출해 버전 번호를 00을 쓸게요 1살요
- 한 디렉터리로 올라가죠 인프라로 갔다가 K로 갈게요 그 안에 yaml 파일을 게시하는 게 보일 겁니다 쿠버네츠에게 이 구성 파일을 사용하길 원한다고 말하는 cube를 쓰면 F를 적용하고 파일 이름을 적용합니다 이 경우엔 post HTML이죠
- 지난 두어 비디오에서 여러 번 빌드했지만 네, 다시 빌드할 게시물 내부에서 Docker Build를 실행할 거예요
- 시작하기에 앞서 먼저 터미널로 돌아가죠 게시 디렉터리로 바꾸고 Docker 이미지를 다시 빌드할 거예요
