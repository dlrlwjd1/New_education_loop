# Introducing Skaffold

## 개요
- 이미지를 재구축하고 Docker Hub에 밀어 명령을 실행해야 했죠 이건 악몽이에요

## 내용
### 자막·본문 기반 핵심 내용
- 이미지를 재구축하고 Docker Hub에 밀어 명령을 실행해야 했죠 이건 악몽이에요
- 일단 여길 보시면 왼쪽에 Git Scaffold란 링크가 있어요 그걸 클릭하면 Linux, Mac OS, Windows 설치 지침을 보실 수 있죠
- 그러니 적절한 운영 체제를 위한 지시를 따르세요 거의 모든 경우 아주 간단합니다 Mac OS에 대한 명령 하나 Windows에 대한 명령 하나 Linux에 있는 명령 하나면 되죠
- 스캐폴드의 홈페이지는 스캐폴드 개발자예요 새 브라우저 탭에서 Scffold dev로 갈게요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `Docker`, `Docker Hub`, `Git Scaffold`
