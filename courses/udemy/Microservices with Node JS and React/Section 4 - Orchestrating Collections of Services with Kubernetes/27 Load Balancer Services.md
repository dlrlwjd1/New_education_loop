# Load Balancer Services

## 개요
- HTML, CSS, JavaScript 같은 걸 보내면 React App이 사용자 브라우저 안에서 부팅되고 브라우저 안에서 React App이 쿼리 서비스에 접근해 HTML, CSS, JavaScript 같은 초기 작업을 한 후 게시판과 코멘트를 받아오죠

## 내용
### 자막·본문 기반 핵심 내용
- HTML, CSS, JavaScript 같은 걸 보내면 React App이 사용자 브라우저 안에서 부팅되고 브라우저 안에서 React App이 쿼리 서비스에 접근해 HTML, CSS, JavaScript 같은 초기 작업을 한 후 게시판과 코멘트를 받아오죠
- React App 개발자 서버에 연결을 시도할 거예요 개발 서버의 유일한 목표는 React 응용 프로그램 내부에 작성된 코드를 가져다가 HTML JavaScript와 CSS 파일을 생성하는 거예요
- 그걸 염두에 두고 반응 응용 프로그램을 여러분 내부에 어떻게 둘지 살펴보죠 React Application은 사실 Create React App Development 서버예요
- 포드 내부에 이걸 수용할 겁니다 새 Docker 이미지를 생성하거나 React Application이나 그런 다음 포드 안에 컨테이너를 만들어 클러스터 안에 둘 거예요
