- 먼저 API 버전으로 시작할게요 이 경우엔 APS/V1을 입력하죠 우리가 접근할 수 있는 다양한 유형의 개체가 있다는 걸 기억하세요
- YAML 파일 들여쓰기 내부는 중요하다는 걸 기억하세요 그러니 선택기에 들여쓰기 단계가 하나 있고 그다음이 둘, 그리고 셋이에요
- 컨테이너가 하나일 거예요 컨테이너는 배열이에요 YAML 내부는 배열 엔트리를 한 줄로 지정하죠
