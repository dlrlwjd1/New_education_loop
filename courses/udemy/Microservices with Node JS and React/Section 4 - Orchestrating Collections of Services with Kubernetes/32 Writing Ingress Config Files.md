# Writing Ingress Config Files

## 개요
- 편집기 안에 들어가서 에이즈 디렉터리를 찾아볼게요 그 안에 Ingress CRV HTML이라는 새 파일을 만들 거예요

## 내용
### 자막·본문 기반 핵심 내용
- 편집기 안에 들어가서 에이즈 디렉터리를 찾아볼게요 그 안에 Ingress CRV HTML이라는 새 파일을 만들 거예요
- 그런 다음 인그레스 같은 걸 넣죠 메타데이터가 나올 거예요 이것의 이름을 Ingress CRV로 할게요
- 그걸 다 구현하려면 슬래시 게시물의 경로를 쓸 거예요 서비스 이름은 post cluster IP service, 즉 CRV에요.
- 이 안에서 구성을 좀 더 쓸 거예요 우리가 이미 만든 구성과 성질이 비슷해요 먼저 API 버전으로 다시 한 번 시작할게요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `Ingress`, `API`, `YAML`, `HTTP`, `service`

## 예시
`Ingress`, `API`, `YAML`, `HTTP`, `service`가 등장하는 설정·코드 위치를 찾아 강의와 같은 순서로 확인한다.
