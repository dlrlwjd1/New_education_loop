# Load Balancers and Ingress

## 개요
- 한 가지 언급하고 싶은 게 있어요 React Application은 쿼리 구역과 게시 구역의 코멘트 구역의 차이를 이해하고 싶어 하지 않아요

## 내용
### 자막·본문 기반 핵심 내용
- 한 가지 언급하고 싶은 게 있어요 React Application은 쿼리 구역과 게시 구역의 코멘트 구역의 차이를 이해하고 싶어 하지 않아요
- React 앱 안에 해당 정보를 암호화할 필요는 없죠 대신에 이렇게 하면 좋을 거예요 이 경로에 요청을 해서 클러스터 주변에 뭔가 있다면 그 요청이 어떤 포드로 전달될지 알아내는 거죠
- AWS나 구글 클라우드 Azure에 직접 연락해서 부하 분산 장치라는 걸 프로비전하세요
- 이 부하 분산 장치는 클러스터 외부에 존재해요 구글 클라우드나 AWS Azure의 일부죠
