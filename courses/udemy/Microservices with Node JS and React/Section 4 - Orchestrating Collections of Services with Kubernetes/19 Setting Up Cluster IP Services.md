# Setting Up Cluster IP Services

## 개요
- 노드 포트 서비스를 살펴봤으니 클러스터 IP도 살펴보도록 클러스터 IP 서비스의 목표는 클러스터 내 다른 포드에 포드를 노출하는 거예요

## 내용
### 자막·본문 기반 핵심 내용
- 노드 포트 서비스를 살펴봤으니 클러스터 IP도 살펴보도록 클러스터 IP 서비스의 목표는 클러스터 내 다른 포드에 포드를 노출하는 거예요
- 클러스터 IP를 더 잘 탐색하기 위해서요 우리 응용 프로그램의 일부가 지금 어떻게 작동하는지 잠깐 알려드리자면 지금은 게시 프로젝트가 있죠
- 누군가 게시물을 만들려고 할 때마다 이벤트 버스에 요청을 보내는 거예요 이벤트 버스가 해당 이벤트를 내보내거나 우리 앱 내의 모든 것에 브로드캐스트하는 거죠
- 게시물까지 포함해서요 이벤트 버스를 실행하는 새 포드를 생성해보죠 그런 다음 게시물과 이벤트 버스가 서로 통신할 수 있도록 서비스를 설정하는 거예요

### 구현 요소
- 강의 흐름에 따라 Setting Up Cluster IP Services의 구현 목적과 적용 지점을 확인한다.

## 예시
게시물까지 포함해서요 이벤트 버스를 실행하는 새 포드를 생성해보죠 그런 다음 게시물과 이벤트 버스가 서로 통신할 수 있도록 서비스를 설정하는 거예요
