# Deploying the React App

## 개요
- React App Server 내부를 확인해야 합니다 실제 React 코드가 게시 요청을 할 거예요 이론적으로 쿠버네테스 클러스터가 위치하는 곳이니까요

## 내용
### 자막·본문 기반 핵심 내용
- React App Server 내부를 확인해야 합니다 실제 React 코드가 게시 요청을 할 거예요 이론적으로 쿠버네테스 클러스터가 위치하는 곳이니까요
- 업데이트를 5개 할게요 그런 다음 서비스로 내려가 업데이트를 3번 하죠 클라이언트에 코멘트한 다음 Create React Application은 포트 3000에서 호스팅되지만 이런 식으로 포트를 업데이트할 수 있죠
- React Application이 모두 업데이트됐으니 이걸로 이미지를 만들어야 해요
- 이쪽에도 요청이 들어온 것 같네요 그것도 게시물로 바꾸죠 다른 요구는 없어요 React 응용 프로그램 안의 모든 코드가 다시 게시될 거예요 로컬 컴퓨터에서 React 응용 프로그램을 실행할 때요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `React`, `JavaScript`, `Docker`, `Docker ID`, `Docker Hub`
