# How to Communicate Between Services

## 개요
- 정확한 이름은 Event 버스 CRV예요 이벤트 버스 서비스 서비스에 접근하고 싶다면 HTTP에 요청할 거예요 이벤트 버스, CRV에요

## 내용
### 자막·본문 기반 핵심 내용
- 정확한 이름은 Event 버스 CRV예요 이벤트 버스 서비스 서비스에 접근하고 싶다면 HTTP에 요청할 거예요 이벤트 버스, CRV에요
- 요청을 하기 위해 클러스터 IP 서비스를 생성하고 나면 HTTP의 URL을 작성할 겁니다 서비스 이름도요
- 한 포드에서 다른 서비스로 연결하는 방법이죠 HTTP를 입력했어요 그리고 우리가 연락하고자 하는 정확한 서비스 이름을요
- 저희가 저 안에 작성한 코드에 대해 잠깐 상기시켜 드리고 싶네요 다시 내부로 돌아가서 게시 프로젝트와 indexed JS 파일을 찾을 거예요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `Event`, `HTTP`
