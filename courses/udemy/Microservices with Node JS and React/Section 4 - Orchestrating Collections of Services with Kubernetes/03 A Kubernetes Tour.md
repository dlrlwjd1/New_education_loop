# A Kubernetes Tour

## 개요
- 모든 파일과 Docker 파일을 갖고 와 Docker에 입력했죠 거기서 우체국에 보낼 이미지가 나왔어요

## 내용
### 자막·본문 기반 핵심 내용
- 모든 파일과 Docker 파일을 갖고 와 Docker에 입력했죠 거기서 우체국에 보낼 이미지가 나왔어요
- 쿠버네츠는 세상을 뒤지며 이 사진의 복사본을 찾으려 하죠 먼저 여러분 개인 컴퓨터에서 실행되는 Docker 디먼, Docker 서버를 살펴보죠
- 의 컴퓨터에 이미 게시 이미지를 구축했어요 쿠버네츠는 여러분의 로컬 컴퓨터를 검토해 해당 이미지의 복사본이 이미 사용 가능한지 사용 불가능할 경우 Docker Hub를 기본값으로 살펴보고 대신 그 이미지의 복사본을 거기서 찾으려 하죠
- 이 새로운 윈도우에서는 Kube CTL 버전을 실행할 거예요 실행하면 클라이언트 버전과 서버 버전이 프린트되는 게 보일 거예요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `Docker`, `Docker Hub`

## 예시
`Docker`, `Docker Hub`가 등장하는 설정·코드 위치를 찾아 강의와 같은 순서로 확인한다.
