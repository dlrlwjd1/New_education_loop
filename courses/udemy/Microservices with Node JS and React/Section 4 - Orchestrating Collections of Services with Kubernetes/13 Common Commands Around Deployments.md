# Common Commands Around Deployments

## 개요
- 클러스터에 있는 모든 실행 중인 배포를 나열하게 되죠 배포를 좀 해볼게요 Post Dash Depot이라는 배포가 하나 있죠

## 내용
### 자막·본문 기반 핵심 내용
- 클러스터에 있는 모든 실행 중인 배포를 나열하게 되죠 배포를 좀 해볼게요 Post Dash Depot이라는 배포가 하나 있죠
- 그런 다음 ETL 적용 chef post-n-bal로 배포를 재생성할 수 있어요 또 파병 가겠죠
- 배포를 생성했어요 배포를 검사하고 조작하는 데 사용할 수 있는 명령 몇 가지를 첫 번째로 살펴볼 명령은 배포를 얻는 거죠
- 빨간색 숫자는 최신이고 준비된 포드는 저희가 만들려는 포드의 개수예요 작은 슬래시 오른쪽에 있는 숫자죠

### 구현 요소
- 강의 흐름에 따라 Common Commands Around Deployments의 구현 목적과 적용 지점을 확인한다.

## 예시
빨간색 숫자는 최신이고 준비된 포드는 저희가 만들려는 포드의 개수예요 작은 슬래시 오른쪽에 있는 숫자죠
