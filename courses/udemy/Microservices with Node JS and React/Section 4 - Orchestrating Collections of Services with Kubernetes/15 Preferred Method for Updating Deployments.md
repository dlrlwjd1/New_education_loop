# Preferred Method for Updating Deployments

## 개요
- 터미널로 돌아가서 OSS 디렉터리로 돌아갈게요 그 안에서 Docker 빌드 Dash TX로 이미지를 재구성합니다 Docker ID/포스팅 맨 끝에 점이 하나 있죠

## 내용
### 자막·본문 기반 핵심 내용
- 터미널로 돌아가서 OSS 디렉터리로 돌아갈게요 그 안에서 Docker 빌드 Dash TX로 이미지를 재구성합니다 Docker ID/포스팅 맨 끝에 점이 하나 있죠
- 또는 그 지정 전체를 삭제하면 Docker는 우리가 최신 정보를 사용하길 원한다고 추정하죠
- 두 번째 단계는 코드를 업데이트하는 거예요 포스트 코드 베이스를 업데이트하죠 그런 다음 이미지를 재구축해 해당 이미지를 Docker Hub에 푸시하는 거예요
- 까만 신분증 포스팅요 우리가 방금 구축한 이미지를 Docker Hub에 푸시하려 할 거예요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `Docker`, `Docker Hub`, `Docker ID/`, `Docker push`

## 예시
