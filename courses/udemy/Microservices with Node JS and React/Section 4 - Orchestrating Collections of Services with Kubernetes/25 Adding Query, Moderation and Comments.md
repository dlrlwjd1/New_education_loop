## 내용
### 자막·본문 기반 핵심 내용
- 마지막은 for query가 되겠죠 쿼리에 약간의 변화가 있어요 그 이미지를 만들 거예요
- Docker push를 할게요 URL을 업데이트했죠 이미지를 구축해 Docker Hub에 푸시했어요
- 먼저 댓글로 시작할게요 docker를 하고, 제 docker ID/comment를 빌드하고 점을 찍죠
- 왜냐하면 지금은 로컬 호스트 4005에 이벤트를 보내려고 하니까요 그런 다음 각각에 대해 이미지를 빌드해 Docker Hub에 푸시하죠

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `Docker`, `query`, `Docker Hub`, `docker ID/comment`, `Docker push`
