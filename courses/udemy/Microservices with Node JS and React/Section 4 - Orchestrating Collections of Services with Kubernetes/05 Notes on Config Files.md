# Notes on Config Files

## 개요
- 구성 파일은 전적으로 YAML 구문으로 작성될 겁니다 yaml에 익숙하지 않다면요

## 내용
### 자막·본문 기반 핵심 내용
- 구성 파일은 전적으로 YAML 구문으로 작성될 겁니다 yaml에 익숙하지 않다면요
- 정말 쉬운 구문이에요 특히 JSON에 익숙하시다면요 중괄호 같은 것만 좀 줄인 JSON이죠
- 이 구성 파일에 대해 좀 더 배우겠습니다 실제 포드와 서비스, 배포를 생성하기 위해 작성하는 거죠
- 이 구성 파일과 관련해 몇 가지 노트를 살펴보죠 먼저, 우리가 작성할 이 구성 파일은 쿠버네츠에게 클러스터 내부에 만들길 원하는 다양한 배포, 포드, 서비스에 대해 말해주죠

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `YAML`, `JSON`
