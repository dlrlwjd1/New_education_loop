# Updating Deployments

## 개요
- 그렇게 하려면 터미널로 돌아가야죠 게시 프로젝트 디렉터리로 다시 바꾸고 Docker를 실행해 해당 이미지를 재구축할 거예요

## 내용
### 자막·본문 기반 핵심 내용
- 그렇게 하려면 터미널로 돌아가야죠 게시 프로젝트 디렉터리로 다시 바꾸고 Docker를 실행해 해당 이미지를 재구축할 거예요
- 코드 편집기를 열고 게시된 프로젝트 디렉터리 안에서 indexed 파일을 찾을 수 이 프로젝트에 변화를 준다고 상상해 볼게요 여기 APT 바닥에요
- 콘솔 로그 바로 위를 들어보세요 listing on 4000에 약 20 버전의 콘솔 로그를 넣을게요
- 두어 번 비디오에서 배포를 사용하는 이유는 쉽게 버전 이미지를 업데이트할 수 있기 때문이라고 말씀드렸죠
