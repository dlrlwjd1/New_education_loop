# A Time-Saving Alias

## 개요
- K를 입력하면 자동으로 확장되죠 Docker PS를 위한 지름길도 있어요 DPS만 입력하면 실행 중인 모든 단말기나 실행 중인 콘솔 컨테이너를 모두 열거할 수 있죠

## 내용
### 자막·본문 기반 핵심 내용
- K를 입력하면 자동으로 확장되죠 Docker PS를 위한 지름길도 있어요 DPS만 입력하면 실행 중인 모든 단말기나 실행 중인 콘솔 컨테이너를 모두 열거할 수 있죠
- 도망갈 거면 멈춰요 지금 당장은 오류가 날 거라고 장담할 수 있어요 Unknown Command K 같은 거요
- Z 쉘에서 어떻게 하는지 보여드리죠 코드 에디터와 Z 쉘 RC 파일을 열겠습니다 bash를 실행 중이라면 bash RC라고 이 안에는 약간의 셸 구성과 다양한 앨리어스 목록이 있어요.
- 두 비디오 전에 제가 아주 빠르게 명령을 작성하는 걸 보셨을 겁니다 큐브와 대조되는 캡슐을 받을 꼬투리 잡히겠어요
