# Verifying Communication

## 개요
- 보통 세 번으로 시작하죠 3만 분의 1이에요 우리가 사용할 실제 URL은 여러분이 Docker를 Mac, Windows 또는 미니 큐브로 사용하느냐에 만약 여러분이 미니 큐브를 사용한다면 미니 큐브 IP를 실행할 것입니다 그러면 여러분은 요청을 할 IP 주소를 얻게 되겠죠

## 내용
### 자막·본문 기반 핵심 내용
- 보통 세 번으로 시작하죠 3만 분의 1이에요 우리가 사용할 실제 URL은 여러분이 Docker를 Mac, Windows 또는 미니 큐브로 사용하느냐에 만약 여러분이 미니 큐브를 사용한다면 미니 큐브 IP를 실행할 것입니다 그러면 여러분은 요청을 할 IP 주소를 얻게 되겠죠
- 콘솔 같은 게 나올 거예요 이 둘 사이에 통나무 같은 게 있어요 어떤 사건이 발현됐다거나 어떤 사건이 방금 접수됐다거나 그런 Postman이라는 API 클라이언트를 사용할 겁니다 코스 안에서 훨씬 초기에 사용했죠 포스트에 포스트를 보내기 위해서요
- 안 그러면 Mac이나 Windows를 위한 Docker에 있을 경우 로컬 호스트를 사용해 요청에 필요한 포트를 확보할 테니까요
- API 클라이언트 포스트맨을 이미 열었어요 새 탭을 열게요 게시물 요청을 해야 해요
