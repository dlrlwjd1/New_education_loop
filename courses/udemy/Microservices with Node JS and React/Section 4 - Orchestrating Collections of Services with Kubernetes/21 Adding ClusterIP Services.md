# Adding ClusterIP Services

## 개요
- 우리가 살펴볼 레이블이 바로 저거예요 선택기 필드에 그 라벨을 제공할 거예요 EP Event, Dash Plus죠

## 내용
### 자막·본문 기반 핵심 내용
- 우리가 살펴볼 레이블이 바로 저거예요 선택기 필드에 그 라벨을 제공할 거예요 EP Event, Dash Plus죠
- 단일 YAML 파일 안에 다중 개체를 만들기 위해서요 대시, 대시를 추가하고 다음 줄로 내려가죠
- 이 클러스터 IP 서비스를 만들려면 API 버전 B1이라고 하죠 힌드가 서빙할 거예요
- 하지만 쿠버네츠는 이 이벤트 버스가 새로운 것임을 깨닫고 만들어졌다고 발표했죠 CTL을 큐에 넣어 Get-Service를 하면 이벤트 버스 서비스를 바로 볼 수 있어요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `YAML`, `API`, `Event`, `Service`, `Deployment`
