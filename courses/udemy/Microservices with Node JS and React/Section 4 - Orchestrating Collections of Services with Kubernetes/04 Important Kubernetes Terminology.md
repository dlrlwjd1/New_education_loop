# Important Kubernetes Terminology

## 개요
- 쿠버네치스 지역을 간단히 둘러봤어요 말씀드린 것처럼 마지막 비디오 말미에 아주 중요한 용어 몇 가지를 강조하고 싶어요

## 내용
### 자막·본문 기반 핵심 내용
- 쿠버네치스 지역을 간단히 둘러봤어요 말씀드린 것처럼 마지막 비디오 말미에 아주 중요한 용어 몇 가지를 강조하고 싶어요
- 이 용어 중 일부는 남은 과정 내내 사용할 텐데요 이것들이 무슨 의미인지 확실히 하고 싶어요
- 쿠버네티스 서비스는 기억하기 쉬운 URL을 제공하는 겁니다 우리 클러스터 내부의 다른 실행 포드와 컨테이너가 다른 포드에 아주 쉽게 엑세스할 수 있도록요
- 하나의 클러스터에 할당된 노드가 많을 수도 있어요 노드가 하나일 수도 있어요 지금 로컬 컴퓨터에서 쿠버네테스 클러스터를 실행 중인데요 기본값으로 노드는 하지만 응용 프로그램을 배포할 때 310,000개의 서로 다른 노드를 여러 개 실행하는 걸 원할 수도 있어요
