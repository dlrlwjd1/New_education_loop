# Common Kubectl Commands

## 개요
- 대신, Kubernetes와 상호 작용하는 데 사용하는 명령줄 도구인 kubectl을 사용하겠습니다.

## 내용
### 자막·본문 기반 핵심 내용
- 대신, Kubernetes와 상호 작용하는 데 사용하는 명령줄 도구인 kubectl을 사용하겠습니다.
- 그러면 포드가 생성됩니다. 그런 다음 kubectl get pod를 사용하여 모든 다른 파드를 나열할 수 있습니다.
- 내 k8의 디렉토리 내에서 kubectl 적용 대시 f 포스트 포스트 도트 YAML을 실행합니다.
- 몇 가지만 더요. 어떤 이유로 인해 수동으로 파드를 삭제해야 하는 경우, 가장 일반적인 이유는 수동으로 파드를 재시작하려는 경우, kubectl 삭제 파드를 실행한 다음 그 이름을 삭제하는 것이다. 예를 들어 kubectl은 파드 게시물을 삭제한다. 삭제를 실행하면 실제로 삭제가 처리되기까지 몇 초에서 최대 10초까지 걸릴 따라서 약 10초 정도 멈춰도 괜찮습니다.

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `Docker`, `Kubernetes`, `kubectl`, `YAML`, `pod`, `kubectl apply f`, `kubectl get pod`
