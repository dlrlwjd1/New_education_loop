## 내용
### 자막·본문 기반 핵심 내용
- 그 요청은 공무원으로 가야 해요 get to 슬래시 post는 쿼리로 가서 Get to 슬래시 자체로 React 응용 프로그램을 로드해요
- 이 경로 중 하나의 이름을 바꿔야 한다는 거죠 여기 이건 슬래시 post 대신 O/슬래시 생성 같은 게 그걸 지금 넣으면 요청을 구별할 수 있어요 post 포드랑 쿼리 포드로 갈 이걸 현실로 만들려면 React Application만 업데이트하는 게 아니라 a를 만들어야 해요
- 이 다이어그램을 보면 React 응용 프로그램에서 다수의 요청이 들어오고 있어요 이건 우리가 기대하는 다양한 요청서예요
- 지금 처리하죠 이 두 코드 베이스를 편집해야 하니까요 그런 다음 이미지를 다시 빌드해 Docker Hub에 다시 게시해야 하니까요
