# Accessing NodePort Services

## 개요
- 고약한 물건인 거 알아요 게시판에 액세스하려면 Docker를 Mac이나 Windows 또는 Mini Cube로 사용하느냐가 미니 큐브를 써서 서비스에 접근하면 단말기에서 미니 큐브 IP를 실행하게 되고 IP 주소를 출력하게 되죠

## 내용
### 자막·본문 기반 핵심 내용
- 고약한 물건인 거 알아요 게시판에 액세스하려면 Docker를 Mac이나 Windows 또는 Mini Cube로 사용하느냐가 미니 큐브를 써서 서비스에 접근하면 단말기에서 미니 큐브 IP를 실행하게 되고 IP 주소를 출력하게 되죠
- Mac이나 Windows를 위한 Docker를 좀 더 쉽게 쓰신다면 그냥 로컬 호스트일 겁니다 그런 다음 콜론 그런 다음 노드 포트죠
- 새 브라우저 탭을 열게요 Mac을 위해 Docker를 실행 중이거든요 방금 노드 포트가 3402인 걸 봤어요
- 그리고 궁극적으로 다른 서비스를 위한 다른 포드도 만들어야 해요 제가 서비스라는 용어를 쓸 때는 Common Service와 이벤트 버스 등을 말하는 거예요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `Docker`, `Service`
