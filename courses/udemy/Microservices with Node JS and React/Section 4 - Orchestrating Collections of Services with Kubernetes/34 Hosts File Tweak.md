# Hosts File Tweak

## 개요
- 언제든 JPost로 갈 수 있어요 우리 로컬 컴퓨터에 연결하세요 Ingress 엔진 x가 우리가 post에서 온 줄 알도록 속임수를 쓸 거예요 이 섹션에서 보이는 라우팅 규칙을 적용할 거고요

## 내용
### 자막·본문 기반 핵심 내용
- 언제든 JPost로 갈 수 있어요 우리 로컬 컴퓨터에 연결하세요 Ingress 엔진 x가 우리가 post에서 온 줄 알도록 속임수를 쓸 거예요 이 섹션에서 보이는 라우팅 규칙을 적용할 거고요
- 하지만 문제가 생기면 코드를 봐야 한다는 걸 기억하세요 GitHub에서 먼저 코드를 테스트하세요
- 해당 입력 엔진 X 구성 파일에 라우팅 규칙을 추가해야 해요 또한 어떤 시점에 React 앱에 대한 배포도 생성하도록 해야 합니다
- Post Tracker에선 완전히 다른 앱이고 블로그에선 또 다른 앱이죠 컴이요 이런 다양한 도메인에 있는 다양한 응용 프로그램에 대한 인프라는 단일 쿠버네테스 클러스터 내에 호스트될 수 있어요
