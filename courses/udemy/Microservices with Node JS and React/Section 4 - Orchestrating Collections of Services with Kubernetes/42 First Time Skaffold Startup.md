# First Time Skaffold Startup

## 개요
- 완전히 조합된 스캐폴드 HTML 파일이 있어요 이제 스캐폴드 시작만 하면 되죠 다행히 스캐폴드를 시작하려면 명령 하나만 정확히 기억하면 돼요

## 내용
### 자막·본문 기반 핵심 내용

- 터미널로 돌아가죠 블로그의 루트 프로젝트 디렉터리 안이에요 스캐폴드 HTML 파일을 볼 수 있을 겁니다 스캐폴드를 시작하기 위해서요
- 비계를 작동할 거예요 이 명령을 실행하면 엄청난 양의 출력이 스크롤을 통해 나타나죠
