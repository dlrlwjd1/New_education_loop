# Publishing Order Cancellation

## 개요
- 주문 생성 이벤트를 게시하는 것보다 주문을 게시하는 거죠 행사를 취소해요 가장 위에 있는 delete로 가서 취소된 주문을 불러올게요.

## 내용
### 자막·본문 기반 핵심 내용
- 주문 생성 이벤트를 게시하는 것보다 주문을 게시하는 거죠 행사를 취소해요 가장 위에 있는 delete로 가서 취소된 주문을 불러올게요.
- 상단 디렉터리 이벤트 게시자 주문 취소 게시자 취소 상단 디렉터리에서 NAT 래퍼도 나츠 포장지예요
- 순서의 새 인스턴스를 생성하죠 nat 클라이언트를 전달할 건데 nat 리퍼 클라이언트를 통해 사용 가능하죠
- 그런 다음 출판사에 연락하죠 여기 이 개체에 이벤트 데이터를 위한 정보를 제공해야 해요

### 구현 요소
- 강의 흐름에 따라 Publishing Order Cancellation의 구현 목적과 적용 지점을 확인한다.
