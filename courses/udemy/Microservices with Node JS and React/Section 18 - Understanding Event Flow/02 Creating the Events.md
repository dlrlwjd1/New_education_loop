# Creating the Events

## 개요
- 사용자 ID도요 이 사람이 질서를 만들었군요 우린 유통기한이 중요해요 ORDER나 ORDER Model에 저장된 것은 날짜입니다 만료된 날짜를 저장하는 것입니다 데이터베이스 내에 날짜 객체입니다 JSON으로 변환될 무언가를 묘사하고 있는 이 명령 생성 이벤트가 속성에서 만료된다고 하는 대신 날짜 객체가 대신 문자열이라고 하죠 날짜 개체를 JSON이나 수동 문자열로 변환하고 싶으니까요 그래야 시간대가 설정되는 걸 제어할 수 있으니까요

- 그렇긴 하지만 저희 서비스는 이 상태를 신경 쓰지 않아요 그래도 이벤트와 함께 포함시키겠습니다 누가 알겠어요? 미래의 어느 시점에 다른 서비스가 온라인이 되면 이 주문의 기본 상태를 신경 쓸 어쨌든 여기 있는 데이터는 ID를 문자열로 포함한다고 말할 수 있습니다 status는 order status enum options 중 하나가 되겠죠
- 이 경우엔 최소한으로 할 거예요 마지막으로 할 것은 인덱스 파일로 돌아가죠 CRC 디렉터리 대신 방금 생성한 이벤트 두 개를 내보내도록 하단에 인덱스 TS가 있습니다 이벤트에서 내보내는 *를 추가하죠
