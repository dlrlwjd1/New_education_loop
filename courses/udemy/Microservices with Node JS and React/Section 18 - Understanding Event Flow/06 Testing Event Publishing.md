# Testing Event Publishing

## 개요
- 밑줄 MOX 디렉터리를 소스 파일 내에 만들었어요 그리고 자동으로 Nat 래퍼 파일로 임포트 문을 리다이렉트했죠 MOX NAT 래퍼 파일에 대한 테스트를 실행하는 동안에요

## 내용
### 자막·본문 기반 핵심 내용
- 밑줄 MOX 디렉터리를 소스 파일 내에 만들었어요 그리고 자동으로 Nat 래퍼 파일로 임포트 문을 리다이렉트했죠 MOX NAT 래퍼 파일에 대한 테스트를 실행하는 동안에요
- 다시 한 번 말씀드리죠 기억하실지 모르겠는데 Nets 래퍼 파일이 있죠 여기 대신에 몇 가지 코드가 있는데 테스트 환경 내에서 실행되는 걸 원치 않아요 실제 각기 다른 서버에 연결하려는 시도를 할 테니까요 그 문제를 피하기 위해서요
- 테스트를 작성할 시간입니다 이런 이벤트들이 실제로 게시되는지 확인하기 위해서요 이 테스트는 우리가 조금 전에 티켓 서비스 안에서 전에 작성했던 것과 아주 유사해 보일 거예요
- 우선 새 테스트 파일부터 시작하죠 주문 생성 요청이 들어올 때마다 주문이 생성되었다는 이벤트를 게시하는지 확인할 수 있어요.

### 구현 요소
- 강의 흐름에 따라 Testing Event Publishing의 구현 목적과 적용 지점을 확인한다.

## 예시
우선 새 테스트 파일부터 시작하죠 주문 생성 요청이 들어올 때마다 주문이 생성되었다는 이벤트를 게시하는지 확인할 수 있어요.
