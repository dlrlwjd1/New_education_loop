## 내용
### 자막·본문 기반 핵심 내용
- TypeScript가 그러더니 그 abstract 속성을 정의하래요 대상 속성을 갖는다고 할 수 있죠
- 속성 유형에 주석을 달게요. 그 가치는 질서가 아니라 주체가 되겠죠 순서대로 생성되었다는 것을 알리는 이벤트를 게시하고자 할 때마다 New Order Created Publaker 같은 것을 작성할 수 있어요.
- 주문 서비스로 돌아가서 우리가 생성한 이벤트를 위한 게시자 2개를 구축하죠 SRC 디렉터리 안에 이벤트 폴더를 만들게요
- 취소된 퍼블리셔에 대해서도 같은 과정을 반복하죠 OrderCanceed Publaker가 있네요.
