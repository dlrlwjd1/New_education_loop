# Void and Never

## 개요
- 이 안에 주석을 달 반환 문이 없어요 return type이 : void에 들어갈 여기 void란 함수가 있는데 기술적으로 아무것도 반환하지 않아요

## 내용
### 자막·본문 기반 핵심 내용
- 이 안에 주석을 달 반환 문이 없어요 return type이 : void에 들어갈 여기 void란 함수가 있는데 기술적으로 아무것도 반환하지 않아요
- void를 반환하는 함수는 null을 반환할 수 있어요 정의되지 않은 상태로 돌아올 수도 있죠
- 하지만 여기선 void를 써서 이 함수에선 반환 값이 없을 거라고 하죠 실수로 뭔가를 금세 오류 메시지가 떠요 아무것도 반환할 수 없다네요
- 오류를 발생시킬 때마다 기능은 기술적으로 아무것도 반환하지 않아요 여기에 콜론을 넣을 수 있어요 never라고 쓰여 있죠 이 함수의 끝까지 갈 수 없다는 뜻이에요

### 구현 요소
- 강의 흐름에 따라 Void and Never의 구현 목적과 적용 지점을 확인한다.
