# Class Method Modifiers

## 개요
- 하지만 자동차의 경우 공용 도로라고 표시돼 있죠 여기 보면 child class는 부모클래스와 다른 Modifier를 가지고 있어요.

## 내용
### 자막·본문 기반 핵심 내용
- 하지만 자동차의 경우 공용 도로라고 표시돼 있죠 여기 보면 child class는 부모클래스와 다른 Modifier를 가지고 있어요.
- TypeScript의 2015 클래스와 클래스 간의 차이점을 알아보도록 첫 번째로 다룰 것은 Modifier라는 것의 존재예요
- 다른 Modifier의 목적은 기본값으로 다른 함수나 다른 변수에 대한 액세스를 제한하는 클래스에 추가하는 모든 다양한 메서드와 속성은 항상 공용 Modifier를 기본값이라고 한 이유는 클래스 안에 공용, 사설, 보호로 보이는 것이 없다는 것을 알 수 있기 때문이죠.
- 여기 드라이브 메서드에 private으로 표시를 해 볼게요. 거기에 private Modifier를 추가할게요.

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `TypeScript`, `class`
