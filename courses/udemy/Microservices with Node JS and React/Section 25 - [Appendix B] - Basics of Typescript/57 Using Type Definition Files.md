# Using Type Definition Files

## 개요
- 안을 들여다보면 이걸 문서의 소스로 사용할 수 있어요 예를 들어, 방금 전에 봤던 공식 문서를 기억하세요 주소 모듈을 이게 TypeScript에게 말하는 거죠 이 라이브러리에 주소 개체가 있고 내부에 다양한 기능이 있다고요 우편번호, 도시, 도시 접두사 같은 거요

## 내용
### 자막·본문 기반 핵심 내용
- 안을 들여다보면 이걸 문서의 소스로 사용할 수 있어요 예를 들어, 방금 전에 봤던 공식 문서를 기억하세요 주소 모듈을 이게 TypeScript에게 말하는 거죠 이 라이브러리에 주소 개체가 있고 내부에 다양한 기능이 있다고요 우편번호, 도시, 도시 접두사 같은 거요
- 위도와 경도에도 똑같이 적용할 수 있어요 여기 아주 짧은 노트가 있어요 TypeScript를 처음 시작하는 사람들을 정말 당황하게 하는 거죠
- 지금은 TypeScript에게 우리 클래스 사용자가 형식적이거나 위치라는 속성을 가질 거라고 말하기 전까지요 위치에는 위도와 경도 속성이 있는 개체가 중요한 건 이거예요
- 저희가 한 건 TypeScript에게 위치 정보와 속성을 주는 게 다예요 이 두 가지 속성을 가진 객체가 될 텐데 아직 초기화 작업은 하지 않았어요
