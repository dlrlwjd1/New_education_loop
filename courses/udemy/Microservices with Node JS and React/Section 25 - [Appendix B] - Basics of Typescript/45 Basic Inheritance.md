# Basic Inheritance

## 개요
- TypeScript의 클래스에 관해 계속 논의할 거예요 상속 시스템을 보면서요 제 클래스 차량 바로 아래에 두 번째 클래스 정의를 만드는 것부터 시작할게요

## 내용
### 자막·본문 기반 핵심 내용
- TypeScript의 클래스에 관해 계속 논의할 거예요 상속 시스템을 보면서요 제 클래스 차량 바로 아래에 두 번째 클래스 정의를 만드는 것부터 시작할게요
- 여기서 클래스급 차를 찾고 그다음에 이렇게 확장된 차를 찾을 거예요 이 부분의 추가 구문을 작성함으로써 TypeScript에게 클래스 내의 모든 다양한 메서드를 가져다가 클래스 카에 복사 붙여넣기를 원한다고 실제 복사 붙여넣기는 없어요
- 그래야 차 안에서 운전하는 법을 재정립할 수 있으니까요 여기에 return type void와 안쪽에 주석을 달게요 칙칙폭폭 콘솔 로그 대신에요
- 차라고 부를 거예요 현실에서 차와 차의 관계를 생각해 보세요 동차는 자동차의 한 종류라고 할 수 있죠 자동차가 할 수 있는 건 뭐든 될 수 있어요
