# Type Definition Files

## 개요
- 타이프/Fasher가 될 거예요 NPM에 대한 모듈을 지금 찾아보죠 NPM 브라우저로 돌아가서 type/faker를 검색하면 TypeScript definition 파일이 라이브러리에 나타나요

## 내용
### 자막·본문 기반 핵심 내용
- 타이프/Fasher가 될 거예요 NPM에 대한 모듈을 지금 찾아보죠 NPM 브라우저로 돌아가서 type/faker를 검색하면 TypeScript definition 파일이 라이브러리에 나타나요
- 먼저 다이어그램을 보죠 확실히 해 두자면 우리가 TypeScript 코드를 쓸 때마다 JavaScript, 더 정확히 말하면 JavaScript 라이브러리를 마음껏 써도 돼요
- 일반 JavaScript 라이브러리를 NPM을 이용해 TypeScript 프로젝트에 설치할 수 있어요
- TypeScript는 유형 정의 파일을 알죠 형식 정의 파일을 일종의 어댑터로 생각할 수 있어요 우리가 쓰는 TypeScript 코드와 JavaScript 라이브러리 간의 어댑터요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `TypeScript`, `JavaScript`, `NPM`

## 예시
`TypeScript`, `JavaScript`, `NPM`가 등장하는 설정·코드 위치를 찾아 강의와 같은 순서로 확인한다.
