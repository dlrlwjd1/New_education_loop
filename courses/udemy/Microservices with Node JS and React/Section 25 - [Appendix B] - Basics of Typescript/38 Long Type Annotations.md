# Long Type Annotations

## 개요
- 이 형식은 annotation이 정말 길어요 이 개체에 속성이 더 있다면 저 형식 annotation은 더 읽기 힘들 게다가 기능을 더 추가하면 올드 시빅을 사용할 줄 알았어요

## 내용
### 자막·본문 기반 핵심 내용
- 이 형식은 annotation이 정말 길어요 이 개체에 속성이 더 있다면 저 형식 annotation은 더 읽기 힘들 게다가 기능을 더 추가하면 올드 시빅을 사용할 줄 알았어요
- 이 비디오에서는 코드를 써서 인터페이스 작동법을 더 잘 이해하도록 코드 에디터와 루트 프로젝트 디렉터리의 내부로 돌아왔어요
- 인터페이스라는 새 파일을 만들 거예요 이 안에선 아직 인터페이스를 작성하지 않을 거예요
- 그 대신 먼저 자동차를 대표하는 개체를 정의하고 싶어요 객체에서 작동하는 함수를 작성하고 인터페이스를 소개할게요.

### 구현 요소
- 강의 흐름에 따라 Long Type Annotations의 구현 목적과 적용 지점을 확인한다.
