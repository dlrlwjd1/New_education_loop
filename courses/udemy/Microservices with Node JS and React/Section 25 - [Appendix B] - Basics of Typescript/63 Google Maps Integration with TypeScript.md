## 내용
### 자막·본문 기반 핵심 내용
- 그게 우리가 찾는 거예요 여기 보시면 Google Maps, JavaScript API를 위한 형식의 definition 파일들이 있어요 우리가 사용하는 게 바로 그거죠 그러니 문서를 살펴볼 수 있어요
- TypeScript가 그걸 이해하도록 도와야 해요 TypeScript가 우리 프로젝트 내에 이용 가능한 전역 변수가 있다는 걸 이해하도록 도와야 해요 Google 개체에 이용 가능한 다양한 방법을 이해하도록 도와야죠
- 페이커를 위해 설치했죠 유형 정의 파일의 목적은 TypeScript가 타사 JavaScript 라이브러리를 이해하게 이 유형의 정의 파일을 NPM 모듈뿐 아니라 HTML 파일에 직접 추가된 스크립트 태그에도 사용할 수 있어요
- 터미널로 돌아가서 type/ Google Maps에 NPM을 설치할게요 그걸 추가하고 나면 편집기로 돌아갈 수 있어요 다시 한 번 인덱스 파일 안에 Google이라고 쓸게요
