# TypeScript Overview

## 개요
- 우리가 에디터 안에서 TypeScript 코드를 쓸 거예요 TypeScript를 그냥 JavaScript로 생각할 수도 있지만 이런 형식 annotation이 일단 코드를 실행하려면 TypeScript 컴파일러에 해당 코드를 피드해야죠
