# Understanding Inference

## 개요
- 지난 비디오에서 이런 다양한 형식의 주석을 모두 지울 수 있는 걸 봤죠 오류도 이 변수들을 가리켰으니 TypeScript는 각 변수에 어떤 유형의 값을 할당할지 알고 있어요

## 내용
### 자막·본문 기반 핵심 내용
- 지난 비디오에서 이런 다양한 형식의 주석을 모두 지울 수 있는 걸 봤죠 오류도 이 변수들을 가리켰으니 TypeScript는 각 변수에 어떤 유형의 값을 할당할지 알고 있어요
- 이렇게 미리 완료된 형식을 얻는 겁니다 annotation을 삭제해도 TypeScript는 여전히 진행 상황을 보죠
- 우리가 방금 만든 파일에는 annotation 형식의 예가 아주 많아요 기억하세요 여기서 개발자들은 TypeScript에게 값이나 변수가 참조할 타입을 알려줘야 하죠
- 타입 추정에 관한 규칙이 있어요 선언과 초기화를 같은 줄에서 하거나 근본적으로 단일 식에서 하면 TypeScript는 우리가 색깔에 할당할 값의 유형을 파악해요
