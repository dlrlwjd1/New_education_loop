# Adding Google Maps Support

## 개요
- 그 API 키를 이용해 Google Maps SDK를 HTML 파일에 추가하세요 NPM 모듈로 Google Maps를 설치하진 않을 거예요

## 내용
### 자막·본문 기반 핵심 내용
- 그 API 키를 이용해 Google Maps SDK를 HTML 파일에 추가하세요 NPM 모듈로 Google Maps를 설치하진 않을 거예요
- 두 단어로 Maps API를 찾죠 Maps JavaScript API를 여기 찾고 있어요
- 그게 우리 프로젝트에 JavaScript Maps API 지원을 추가할 거예요 그게 다 끝나면 콘솔 안에서 마지막으로 할 일은 API 키를 생성하는 겁니다 아주 쉽죠
- 이 프로젝트로 Google Maps API에 액세스할 수 있어요 화면에 지도를 보여주는 방법이죠

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `API`, `NPM`, `TypeScript`, `JavaScript`, `HTTPS`
