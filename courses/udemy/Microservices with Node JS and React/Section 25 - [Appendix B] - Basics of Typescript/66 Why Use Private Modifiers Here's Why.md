# Why Use Private Modifiers? Here's Why

## 개요
- 다른 엔지니어들이 여기 접근하는 걸 원치 않아요 그래서 private에 Modifier를 놓을게요.

## 내용
### 자막·본문 기반 핵심 내용
- 다른 엔지니어들이 여기 접근하는 걸 원치 않아요 그래서 private에 Modifier를 놓을게요.
- 우리 프로그램 내에서 할 수 있는 건 여기 다 있어요 현재 구글 맵의 API 표면을 완전히 없앴어요 앱의 복잡성을 확 줄이는 역할을 하죠
- 이걸 그냥 맵이라고 부르고 싶어요 사용자 지정이란 단어를 넣는 대신에요 하지만 우리가 만들 클래스는 Google Map 인스턴스에서 분리돼 있다는 걸 확실히 해두고 싶어요
- 대신 사용자 지정 맵이라고 부르죠 이 안에 Custom Map이라는 클래스를 생성하겠습니다 바로 내보낼 것입니다
