# More on Annotations Around Functions

## 개요
- 함수 자체에 annotations를 추가하는 방법과 input argument와 return value를 어떻게 추가하는지 볼게요.

## 내용
### 자막·본문 기반 핵심 내용
- 함수 자체에 annotations를 추가하는 방법과 input argument와 return value를 어떻게 추가하는지 볼게요.
- 함수와 관련해 형식 annotations에 관해 얘기할 땐 우리 프로젝트에 추가할 코드 얘길 하죠 TypeScript에 도움될 거예요
- 이런 annotations의 목표는 TypeScript에게 그 함수가 수신할 인수의 유형과 반환할 값의 유형을 알려주는 거죠
- 여기 있는 annotation은 변수에 대한 annotation이죠 TypeScript에게 이 변수에 값을 할당하겠다고 했죠 이 형식을 함수가 될 거예요
