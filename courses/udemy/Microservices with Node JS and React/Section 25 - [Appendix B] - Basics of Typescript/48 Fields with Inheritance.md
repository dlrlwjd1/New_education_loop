# Fields with Inheritance

## 개요
- 그 말은 우리가 차의 인스턴스를 만들려고 할 때마다 TypeScript가 상위 함수에서 생성자를 자동으로 호출한다는 거죠

## 내용
### 자막·본문 기반 핵심 내용
- 그 말은 우리가 차의 인스턴스를 만들려고 할 때마다 TypeScript가 상위 함수에서 생성자를 자동으로 호출한다는 거죠
- 클래스 안에서 필드가 어떻게 작동하는지 알았으니 유산을 다룰 때 필드가 어떻게 작동하는지 알아보죠 클래스 카를 살펴볼게요
- 이 파일 하단에 있는 모든 걸 주석 처리 해제할게요 새 차 호출과 관련해 오류가 있는 게 보이실 거예요
- 우리 클래스 차는 차를 확장해요 저희는 어떤 차량의 예시를 만들 때마다 그 차량에 사용할 색상을 여기서 이 오류가 보이는 이유는 색깔로 작용할 문자열을 전달해야 하기 이 오류를 수정할 수 있어요 이렇게 빨간색으로 문자열을 넣는 거죠
