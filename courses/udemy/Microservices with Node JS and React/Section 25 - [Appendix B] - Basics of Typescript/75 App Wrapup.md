# App Wrapup

## 개요
- 올바른 속성만 있다면 TypeScript는 안 보이는 곳에서 적절한 확인을 우리가 marker를 추가하기 위해 사용자나 회사를 통과시키려 하자마자 TypeScript가 동으로 사용자를 살펴보고 올바른 속성이 있는지 확인했어요

## 내용
### 자막·본문 기반 핵심 내용
- 올바른 속성만 있다면 TypeScript는 안 보이는 곳에서 적절한 확인을 우리가 marker를 추가하기 위해 사용자나 회사를 통과시키려 하자마자 TypeScript가 동으로 사용자를 살펴보고 올바른 속성이 있는지 확인했어요
- 지금 보시는 이 패턴은 저희가 여러 번 반복해서 반복하는 패턴이에요 여러 번 말했지만 TypeScript에서 우리가 배우고 싶은 가장 큰 점이자 TypeScript의 가장 멋진 특성은 클래스와 인터페이스 간의 상호 이 장면이 바로 그런 경우죠
- 그러기 위해 여기 선택적으로 구현 맵을 추가해요 그럼 TypeScript에 말하죠 우리가 사용자가 탭 가능한 인터페이스를 충족시키게 하려 한다고요 그걸 추가함으로써요 TypeScript는 사용자 정의를 살펴보고 올바른 속성을 구현하는지 확인하죠
- 저희가 다뤘던 첫 번째 중요한 것은 인덱스에 노출된 API 표면적의 양을 제한하고 싶다는 것이었죠

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `API`, `TypeScript`

## 예시
`API`, `TypeScript`가 등장하는 설정·코드 위치를 찾아 강의와 같은 순서로 확인한다.
