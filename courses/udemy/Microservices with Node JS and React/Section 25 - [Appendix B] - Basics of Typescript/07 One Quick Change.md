## 내용
### 자막·본문 기반 핵심 내용
- 여기에 typecript 파일을 넣는다는 걸 기억하세요 비행기 JavaScript 파일은 더 이상 사용하지 않아요
- 이 안에서 만든 오류를 피하기 위해 TypeScript를 어떻게 쉽게 쓰는지 얘기해 볼게요
- 지난 비디오에서 페치할 코드를 작성하고 단일 작업을 해서 단말기에서 프린트했죠 모든 게 잘 작동하지만 여기 이 콘솔 로그는 좀 흉하네요 이런 개체 형식에선 이해하기 어려워요
- 이 비디오에서 ID 타이틀과 완성된 플래그를 떼어내서 더 나은 포맷으로 프린트할게요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `JavaScript`, `TypeScript`
