# Bundling with Parcel

## 개요
- Parcel은 인덱스 소스와 함께 해당 스크립트 태그를 보게 됩니다. ts. 그리고 TS 확장자 소포가 '아, TypeScript 파일로 보이네요'라고 말하는 순간, 그 안에 있는 코드를 파싱하고 컴파일하여 JavaScript로 변환한 다음 인덱스가 아닌 브라우저에 로드해야 합니다. ts 파일을 요청했습니다.
