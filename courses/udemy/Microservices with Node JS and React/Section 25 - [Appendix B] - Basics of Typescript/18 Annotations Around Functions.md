## 내용
### 자막·본문 기반 핵심 내용
- 형식 annotations의 예제를 보았습니다 배열, 클래스, 개체 리터럴이 있었죠
- 방금 작성한 모든 것, 모든 새로운 구문요 annotation을 입력하죠 하지만 우리가 방금 만든 파일에는 실제로 요구되는 한 가지 형식의 주석이 이 파일 안에 이런 형식의 annotations는 하나도 추가할 필요가 없다는 거죠
- 그게 우리가 인코딩할 정보입니다 위생 안에서요 여기로 가는 annotation TypeScript에게 함수가 어떤 다른 인수를 취하고 어떤 다른 값을 반환할지 말할 거예요
- 그게 annotation으로 TypeScript에게 이 변수에 어떤 형식의 값을 할당할지 알려주는 거죠
