# Export Statements in TypeScript

## 개요
- 사용자의 초기 구현을 완료했어요 인덱스 파일 안에서 실제로 사용할 수 있어요 일반적으로 TypeScript에서 단일 클래스를 담은 파일을 만들 땐 그 클래스와 관련된 실제 코드는 없어요

## 내용
### 자막·본문 기반 핵심 내용
- 사용자의 초기 구현을 완료했어요 인덱스 파일 안에서 실제로 사용할 수 있어요 일반적으로 TypeScript에서 단일 클래스를 담은 파일을 만들 땐 그 클래스와 관련된 실제 코드는 없어요
- TypeScript에서도 기본 키워드 사용 가능하죠 기본 키워드 안 쓰셨어도 괜찮아요
- 그것의 콘솔 로그를 하면요 문자열만 읽을 수 있어요 TypeScript에선 보통 이런 기본 문을 사용하지 않아요 여기 보시는 것처럼요
- TypeScript 내부의 규칙은 절대 기본 내보내기 문을 사용하지 않는 거죠 물론 동의하지 않는 분들도 계시겠죠 여전히 기본 문을 사용하고 싶어하시는 이 이 경우와 같은 프로젝트에서 작업하고 기본 문을 사용하고 싶어도 괜찮아요
