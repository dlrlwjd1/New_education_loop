# Catching More Errors!

## 개요
- TypeScript에 관한 교훈이 또 나오네요 TypeScript를 올바르게 쓰지 않거나 일반 JavaScript를 쓸 경우 코드를 실행하기 전까진 오류를 못 찾는데 개발자 입장에선 아주 비효율적이죠

## 내용

- 이 영상에서는 우리 프로그램에 한 가지 변화를 주고 싶어요 이 콘솔을 가져가고 싶어요 로그 문을 열고 별도의 도우미 함수로 추출하면 promise 본체를 여기서 내보낼 수 있죠 현재보다 좀 더 작게요
