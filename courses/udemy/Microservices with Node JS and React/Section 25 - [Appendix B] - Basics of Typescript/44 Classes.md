# Classes

## 개요
- 코드 편집기로 넘어갈게요 프로젝트 디렉터리 안에 Classes라는 새 파일을 만들게요

## 내용
### 자막·본문 기반 핵심 내용
- 코드 편집기로 넘어갈게요 프로젝트 디렉터리 안에 Classes라는 새 파일을 만들게요
- 여기서 잠시 멈출게요 잠시 후 다음 비디오에선 TypeScript의 클래스가 2015 JavaScript의 전통적인 클래스와 어떻게 다른지 얘기할 거예요
- 흥미로운 응용 프로그램을 작업하기 전에 마지막으로 논의할 큰 주제예요 우선 정의부터 하죠
- 클래스는 일종의 청사진이죠 우린 지금 코드를 작성하고 있지만 이건 우리가 개체를 생성하는 데 사용할 청사진이나 모델이죠 거기에 다양한 필드와 메서드가 첨부돼 있어요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `TypeScript`, `JavaScript`

## 예시
`TypeScript`, `JavaScript`가 등장하는 설정·코드 위치를 찾아 강의와 같은 순서로 확인한다.
