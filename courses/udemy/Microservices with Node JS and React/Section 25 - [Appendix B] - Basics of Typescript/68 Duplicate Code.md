# Duplicate Code

## 개요
- 짐작하시겠지만 마커 코드는 우리가 방금 한 것과 아주 유사할 거예요 유일한 차이는 회사의 인스턴스에서 위도와 경도를 떼어낸다는 거죠 사용자와 새로운 Google Maps에 닷마커, 대문자를 추가할게요

## 내용
### 자막·본문 기반 핵심 내용
- 짐작하시겠지만 마커 코드는 우리가 방금 한 것과 아주 유사할 거예요 유일한 차이는 회사의 인스턴스에서 위도와 경도를 떼어낸다는 거죠 사용자와 새로운 Google Maps에 닷마커, 대문자를 추가할게요
- 광고 회사 마커 메서드를 구현하면서 계속할게요 아직 사용자 지정 앱 클래스 안에 있어요
- 바닥에 닿았어요 메서드 정의를 확장할게요 이 안쪽에 또 다른 마커 하나를 만들어 줄게요
- 옵션 개체를 줄 거예요 지도 속성을 가지게 되죠 이 지도에 마커를 추가할 거예요 구글 맵이 되겠죠

### 구현 요소
- 강의 흐름에 따라 Duplicate Code의 구현 목적과 적용 지점을 확인한다.

## 예시
옵션 개체를 줄 거예요 지도 속성을 가지게 되죠 이 지도에 마커를 추가할 거예요 구글 맵이 되겠죠
