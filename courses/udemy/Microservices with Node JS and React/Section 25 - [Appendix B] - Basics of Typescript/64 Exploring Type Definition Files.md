# Exploring Type Definition Files

## 개요
- 형식 정의 파일이 로드됐으니 TypeScript는 Google 라이브러리에서 일어나는 코드 첫 줄이 TypeScript에게 Google이란 전역 변수가 그 변수에는 maps라는 속성이 있어요

## 내용
### 자막·본문 기반 핵심 내용
- 형식 정의 파일이 로드됐으니 TypeScript는 Google 라이브러리에서 일어나는 코드 첫 줄이 TypeScript에게 Google이란 전역 변수가 그 변수에는 maps라는 속성이 있어요
- 또한 이 지도 객체에 많은 속성이 있는 것을 볼 수 있습니다. padding map options, map type ID, 제스처, 처리 옵션 등등. 리스트를 스크롤 하면 라이브러리 안에서 사용할 수 있는 모든 것들에 대한 개요를 볼 수 있어요.
- TypeScript의 반밖에 안 되는 힘이에요 이 다양한 형식들을 읽고 약간의 힌트를 써서 이런 라이브러리가 어떻게 작동하는지 이해하세요
- 저걸 입력하자마자 줌에 자동 완성이 되는 걸 보세요 TypeScript가 그걸 알기 때문에 자동완성이 보이는 거예요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `TypeScript`, `class`
