# Environment Setup

## 개요
- 여기서 단말기를 한 번 열어볼게요 NPM을 실행해 DAG를 설치하고 TypeScript와 TS 노드를 확보할 거예요

## 내용
### 자막·본문 기반 핵심 내용
- 여기서 단말기를 한 번 열어볼게요 NPM을 실행해 DAG를 설치하고 TypeScript와 TS 노드를 확보할 거예요
- NPM을 이용해 TypeScript를 글로벌 모듈로 설치할 거예요 TS 노드라는 두 번째 모듈도 설치할게요
- 가장 먼저 TypeScript 컴파일러를 설치할 거예요 설치는 NPM을 이용할 거예요
- 대시가 이렇게 도와요 TypeScript라는 패키지를 설치했어요 Tk라는 명령어에 엑세스 권한을 주는데 여러분이 짐작하시듯 TypeScript 컴파일러를 줄인 거죠

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `TypeScript`, `NPM`, `TS`, `JavaScript`
