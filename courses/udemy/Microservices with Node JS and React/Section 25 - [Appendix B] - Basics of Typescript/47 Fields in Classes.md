# Fields in Classes

## 개요
- 아까 말씀드린 Modifier는 변수에도 메서드와 같은 방식으로 적용되죠 다른 방법으로 private 키워드나 private Modifier를 사용할 수 있어요.

## 내용
### 자막·본문 기반 핵심 내용
- 아까 말씀드린 Modifier는 변수에도 메서드와 같은 방식으로 적용되죠 다른 방법으로 private 키워드나 private Modifier를 사용할 수 있어요.
- 하지만 초기 값을 부여하지 않았죠 클래스나 속성 정의 직후에 = 기호를 쓴 다음 some value를 쓸 수 있어요
- 클래스 안에서 속성을 지정하고 싶을 때마다 속성의 이름을 쓰면 돼요 그 속성에 대해 색과 형식 annotation이 있죠
- 클래스 안에서 메서드가 어떻게 작동하는지 봤으니 클래스 안에서 데이터를 어떻게 다루는지도 살펴볼게요
