# Annotations With Variables

## 개요
- 이것과 똑같이 생긴 구문을 보게 될 거예요 작업하는 TypeScript 코드의 대다수가 이 Type annotation은 TypeScript에게 사과의 변수에만 타입 번호 값을 할당한다고 말하는 거예요

## 내용
### 자막·본문 기반 핵심 내용
- 이것과 똑같이 생긴 구문을 보게 될 거예요 작업하는 TypeScript 코드의 대다수가 이 Type annotation은 TypeScript에게 사과의 변수에만 타입 번호 값을 할당한다고 말하는 거예요
- 침투형 시스템은 유형 추론과 좀 안 맞아요 먼저 형식 annotation에 초점을 맞추고 형식 추론이 어떻게 작용하는지 편집기로 가서 프로젝트 디렉터리 안에 Annotations라는 새 폴더를 만들게요
- TypeScript 내의 다양한 유형의 값에 관해 얘기했죠 문자열 부울, Null, 무효 Null, 정의되지 않은 함수 배열 이런 다양한 유형의 값은 모두 형식 annotation을 사용할 수 있어요
- 형식 annotation은 TypeScript를 돕기 위해 작성하는 약간의 코드가 될 거예요
