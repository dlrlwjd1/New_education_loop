## 내용
### 자막·본문 기반 핵심 내용
- 클래스 및 인터페이스 이해하기. 무슨 일이 일어나고 있는지 이해했으니 이 동영상에서 약간의 설정을 통해 브라우저 내에서 TypeScript 코드를 매우 쉽게 실행할 수 있도록 Parcel Bundler라는 도구를 사용하겠습니다.
- 이 과정의 나머지 부분에서는 디자인 패턴에만 집중할 것입니다. 애플리케이션 내에서 TypeScript를 효과적으로 사용하는 방법과 그 기능을 활용하여 재사용 가능한 코드를 작성하는 방법에 대해 알아보겠습니다.
- 이것은 TTS 노드 대신 사용할 명령줄 도구입니다. 소포 번들러는 브라우저 내에서 TypeScript를 매우 쉽게 실행할 수 있는 기능입니다.
- 따라서 많은 툴을 자동화할 수 있게 될 것입니다. 나중에 TypeScript 프로젝트를 수동으로 설정하는 방법을 배우겠지만 지금은 parcel을 사용하여 쉽고 간단하게 시작하겠습니다.
