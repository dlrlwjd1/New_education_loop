- 게이트키핑을 위해 인터페이스를 사용하는 이 메커니즘은 TypeScript 안에서 코드를 재사용할 수 있는 주된 방법 중 하나죠
- 이 코스에 있는 모든 응용 프로그램에서 반복해서 사용되는 이 전략을 보시게 될 TypeScript의 코드 재사용에 사용할 일반적인 전략은 인터페이스와 함께 입력된 인수를 받아들이는 함수를 만드는 거죠
- 앱 안에 오래된 시빅이나 음료 같은 어떤 값이 있는데 이 값들을 print 요약 함수와 함께 사용하고 싶다면 그런 값들이 보고 가능한 인터페이스를 구현하도록 해야 해요
