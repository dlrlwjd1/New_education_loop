# Where Do We Use Types?

## 개요
- 하지만 유형의 경우 어디에나 사용되죠 TypeScript를 사용할 때의 부작용이죠

## 내용
### 자막·본문 기반 핵심 내용
- 하지만 유형의 경우 어디에나 사용되죠 TypeScript를 사용할 때의 부작용이죠
- 이 원하든 원치 않든 앱 안에서 정의하는 모든 값은 관련된 형식을 갖게 되고 TypeScript는 최선을 다해 코드 품질을 확인하거나 이런 형식을 사용해 오류를 확인하죠
- 형식의 정의가 나왔네요 왜 신경 쓰는지 얘기했잖아요 몇 가지 예제를 봤는데요 마지막으로 언제 사용하느냐를 다루죠
- 이건 이 경우 좀 쉬운 거죠 우리가 살펴볼 다른 토픽들은 어디에 사용하느냐에 따라 훨씬 더 나은 답변이 될 거예요

### 구현 요소
