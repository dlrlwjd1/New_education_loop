- 여기 이 기능은 TypeScript로 더 많은 재사용 가능한 코드를 쓰도록 장려하죠
- 지난 비디오에서 인터페이스를 좀 더 일반적인 이름으로 리팩터링했죠 이 아래 함수에도 같은 작업을 했어요
- 이 파일 안에서 흥미로운 걸 해보려 해요 이건 올드 시빅이에요 그 아래에 또 다른 새 개체를 정의하고 싶어요
