# Fixing Annotations With Interfaces

## 개요
- 문에 추가하자마자 TypeScript가 우릴 위해 확인을 좀 해줬죠 뒤에서 작업을 좀 했죠

## 내용
### 자막·본문 기반 핵심 내용
- 문에 추가하자마자 TypeScript가 우릴 위해 확인을 좀 해줬죠 뒤에서 작업을 좀 했죠
- TypeScript는 우리가 제공한 인수를 보고 말했어요 저 오래된 공용 개체를 살펴보고 이 인터페이스를 만족시키도록 해야 해요
- 올드 시빅에 적절한 소유물 이름과 유형이 있는지 확인해야 해요 TypeScript는 모든 다양한 속성을 루프해서 올드 시빅에 각기 다른 속성 이름과 적절한 값을 부여했어요
- 그렇게 하자마자 이 아래에 오류 메시지가 뜨는 게 보이실 거예요 TypeScript는 올드 시빅을 통과하려면 망가진 속성이 있어야 한다고 해요 부울이죠
