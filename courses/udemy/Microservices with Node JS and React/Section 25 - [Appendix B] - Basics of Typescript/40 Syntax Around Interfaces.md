# Syntax Around Interfaces

## 개요
- 인터페이스 구문에 관해 몇 가지 추가하고 싶어요 다시 한 번, 인터페이스를 정의할 때, 우리가 기대하는 모든 속성 이름과 타입을 나열해 볼게요.

## 내용
### 자막·본문 기반 핵심 내용
- 인터페이스 구문에 관해 몇 가지 추가하고 싶어요 다시 한 번, 인터페이스를 정의할 때, 우리가 기대하는 모든 속성 이름과 타입을 나열해 볼게요.
- 이 안에서 원시적인 값만 표현하는 게 아니라 인터페이스 안에서 원하는 어떤 유형도 표현할 수 있어요
- 예를 들어, 연도 속성을 숫자로 설정하는 대신에 더 복잡한 객체로 설정해 볼게요. 날짜의 인스턴스처럼요.
- 이를 위해 숫자를 단순한 날짜로 바꿀게요 올드 시빅을 자동차로 인정받으려면 여기 오류가 있는 게 보이실 정의를 업데이트해야 해요

### 구현 요소
- 강의 흐름에 따라 Syntax Around Interfaces의 구현 목적과 적용 지점을 확인한다.
