# Executing Typescript Code

## 개요
- TypeScript 특정 구문을 많이 갖진 않을 거예요 이걸 기억하세요 첫 번째 응용 프로그램의 목표는 다양한 TypeScript 구문을 배우지 않는 대신 TypeScript가 왜 편리한지 보여드릴게요

## 내용
### 자막·본문 기반 핵심 내용
- TypeScript 특정 구문을 많이 갖진 않을 거예요 이걸 기억하세요 첫 번째 응용 프로그램의 목표는 다양한 TypeScript 구문을 배우지 않는 대신 TypeScript가 왜 편리한지 보여드릴게요
- 여기 파일 확장이 점인 걸 보세요 이 짐작하시듯 TypeScript로 시작해요 TypeScript 코드는 항상 Dot의 파일에 두죠
- 그러기 위해 액시오스 타깃을 적고 그 URL을 넘기죠 HTTP를 만들어 해당 URL에 get request하고 JSON 데이터를 페치하려 할 거예요
- JS는 TypeScript 코드의 컴파일된 버전이죠 파일을 열면 TypeScript가 코드 베이스에 한 일을 볼 수 있어요
