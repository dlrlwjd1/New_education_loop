# Object Literal Annotations

## 개요
- 그걸 표시하려면 문자열 anotation을 추가하고 대괄호를 이렇게 하죠 TypeScript에게 우리가 대괄호로 가리키는 배열을 할당한다는 걸 알려주죠 그 안에 문자열만 있을 거라고요

## 내용
### 자막·본문 기반 핵심 내용
- 그걸 표시하려면 문자열 anotation을 추가하고 대괄호를 이렇게 하죠 TypeScript에게 우리가 대괄호로 가리키는 배열을 할당한다는 걸 알려주죠 그 안에 문자열만 있을 거라고요
- TypeScript에서 좀 더 복잡한 것 중 하나는 새로운 형식 annotation과 구문을 분리해야 한다는 거예요 그리고 오른쪽에 있는 것처럼 배열을 만들 때 이해해야 하죠
- 진실, 거짓, 이렇게요 배열로 좀 더 자세히 설명할 테니 일단 여기 다음 예제에선 annotations 형식의 클래스를 어떻게 다루는지 살펴보죠
- 좀 더 복잡한 구문을 사용하는 예제를 두어 개 작성하진 않을게요 먼저 배열에 대한 annotation 형식을 추가하는 것부터 시작할게요
