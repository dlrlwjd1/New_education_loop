## 내용
### 자막·본문 기반 핵심 내용
- 이 type annotation을 사용함으로써 TypeScript는 우리가 type Boolean 값이나 type number 값을 이 변수에 할당할 수 있다는 걸 이해했어요
- TypeScript는 아주 정확히 이게 부울 형식이라고 생각해요 이 코드의 이 줄에서 그 변수에 숫자나 다름없는 뭔가를 할당하고 오류는 부울을 참조해야 하는 변수에 숫자를 할당하는 거예요
- 아주 큰 사건이 될 거예요 어쨌든, 언제 type annotations를 사용할지 이해해 주세요 이 예제를 빨리 살펴보죠
- 이 비디오에선 annotations 형식을 사용할 마지막 사례를 볼 거예요 선언과 초기화가 같은 라인에 있다고 해도 유형을 추론할 수 없는 변수가 있을 때마다요
