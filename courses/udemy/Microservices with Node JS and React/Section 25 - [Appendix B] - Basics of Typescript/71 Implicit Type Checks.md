# Implicit Type Checks

## 개요
- TypeScript가 자동으로 비교를 해주죠 암묵적인 체크라고 하죠 TypeScript는 암묵적으로 또는 이면에서 사용자가 올바른 속성을 자동으로 갖게 하고 그 안에 올바른 유형은 marker 추가를 위한 인수가 되게 하죠
