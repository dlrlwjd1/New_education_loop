# Showing Popup Windows

## 개요
- 클래스의 인스턴스를 생성하면 아무 때나 호출된다는 걸 기억하세요 여기 이런 게 있을 때마다 NewInfoWindows은 생성자를 호출하는 여기로 전달되는 이 개체는 생성자에 대한 인수가 될 거예요
