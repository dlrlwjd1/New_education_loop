# More on Types

## 개요
- 예를 들어, 다른 언어에서는 10진수를 가진 숫자를 나타내는 2형식이 있을 수도 있고 정수라서 10진수를 가지고 있지 않은 숫자를 나타내는 다른 형식이 있을 수도 JavaScript, 아니 TypeScript엔 그런 게 없죠

## 내용
### 자막·본문 기반 핵심 내용
- 예를 들어, 다른 언어에서는 10진수를 가진 숫자를 나타내는 2형식이 있을 수도 있고 정수라서 10진수를 가지고 있지 않은 숫자를 나타내는 다른 형식이 있을 수도 JavaScript, 아니 TypeScript엔 그런 게 없죠
- 존재하지 않는 변수를 작업하기 위해 거기에 일부 속성을 참조하면 TypeScript가 오류를 TypeScript는 이 변수가 이 속성만 가진 개체에 적용된다는 걸 알아요
- 여기 이 기본 형식만 제한된 게 아니란 걸 기억하세요 TypeScript의 모든 값은 예를 들어 새로운 날짜 객체를 만든다면 그 객체는 날짜 타입을 갖게 ID가 있는 개체가 있다면 완성된 깃발 타이틀 깃발이 있다면 그건 형식을 가진 개체라고 할 수 있죠
- TypeScript에는 두 가지 카테고리가 있어요 원시 유형과 개체 유형이 있죠 원시인은 모두 여러분이 짐작하는 아주 기본적인 종족이죠
