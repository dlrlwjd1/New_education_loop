# Examples of Types

## 개요
- 제 워크스페이스 폴더로 바꿔서 여기 둘게요 새 프로젝트 디렉터리를 만들어 다양한 코드 조각을 담을 거예요 TypeScript의 기본 기능을 살펴보며 함께 넣을 코드 조각들이죠

## 내용
### 자막·본문 기반 핵심 내용
- 제 워크스페이스 폴더로 바꿔서 여기 둘게요 새 프로젝트 디렉터리를 만들어 다양한 코드 조각을 담을 거예요 TypeScript의 기본 기능을 살펴보며 함께 넣을 코드 조각들이죠
- TypeScript는 이제 해당 정보를 이용해 그 변수로 정확히 뭘 할지 결정할 수 있죠
- 이건 날짜 객체가 가진 모든 함수와 속성을 나열하고 있어요 TypeScript는 이 정보만 바로 여기 표시해요 날짜가 정확히 뭔지에 대한 내부 정의가 있거든요
- TypeScript는 날짜의 속성과 메서드를 알기 때문에 이 목록에 프린트할 수 있어요

### 구현 요소
