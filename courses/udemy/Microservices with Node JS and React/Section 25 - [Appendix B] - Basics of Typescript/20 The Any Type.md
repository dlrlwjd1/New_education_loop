# The Any Type

## 개요
- 단축키로서 TypeScript는 대신 단순하게 이 다양한 유형을 추측할 수 없다고 JSON PARSE를 호출하면 any type라는 게 나올 거예요

## 내용
### 자막·본문 기반 핵심 내용
- 단축키로서 TypeScript는 대신 단순하게 이 다양한 유형을 추측할 수 없다고 JSON PARSE를 호출하면 any type라는 게 나올 거예요
- any type라는 건 JSON에서 어떤 유형의 값이 반환되는지 TypeScript가 모른다는 뜻이죠
- 여기서 문제는 TypeScript가 이 다양한 형식을 예측 못 한다는 거죠 TypeScript는 JSON PARSE에서 우리가 뭘 얻는지 몰라요 전적으로 해당 함수에 입력한 문자열에 달렸거든요
- 이런 타입 주석이 TypeScript에 도움이 된다는 걸 기억하세요 첫 번째 예제는 함수가 어떤 형식도 반환할 때마다 명확히 해야 아직 어떤 형식도 다루지 않았기 때문에 먼저 약간의 코드를 작성하도록 하겠습니다 그런 다음 any 형식이 정말 무슨 의미인지 살펴보고 왜 형식의 annotation을 사용해야 하는지 알아보도록 하죠
