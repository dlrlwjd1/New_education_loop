# A First App

## 개요
- 패키지 JSON 파일은 프로젝트에 설치한 모든 다양한 종속성을 기록하는 JavaScript 프로젝트는 보통 그렇지만 TypeScript도 마찬가지예요

## 내용
### 자막·본문 기반 핵심 내용
- 패키지 JSON 파일은 프로젝트에 설치한 모든 다양한 종속성을 기록하는 JavaScript 프로젝트는 보통 그렇지만 TypeScript도 마찬가지예요
- 그걸 염두에 두고 이 응용 프로그램을 실제로 구축하기 위한 흐름을 첫 번째 단계는 API를 살펴보는 겁니다 데이터를 가져오는 데 사용할 API죠
- 이 안에 새 프로젝트 폴더를 만들어 Fetch JSON이라고 부를게요 그런 다음 그 디렉터리로 바꾸고 이 안에서 새 패키지 JSON 파일을 생성할 거예요
- 여기 화면에 API 링크가 있어요 이건 가짜 API예요 즉, 테스트나 학습 목적으로 사용할 수 있는 가짜 데이터를 제공하는 거죠

### 구현 요소
