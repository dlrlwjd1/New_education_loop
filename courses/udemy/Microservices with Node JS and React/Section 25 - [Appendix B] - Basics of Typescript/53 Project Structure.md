## 내용

- 이 경우엔 대문자 U죠 사용자요, 이 파일에서 클래스를 내보낼 거니까요 하지만 indexed notes에선 수업을 안 할 거예요

- 이 비디오에선 우리가 일반적으로 사용할 전반적인 프로젝트 구조에 초점을 맞추고 싶어요
