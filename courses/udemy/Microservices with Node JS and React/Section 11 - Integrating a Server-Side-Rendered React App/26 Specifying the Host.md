# Specifying the Host

## 개요
- X세대에서의 인그레스죠 네임스페이스 내의 모든 서비스를 목록으로 만들 거예요 CTL get service N, Ingress 엔진 X 이게 제 서비스 이름이에요

## 내용
### 자막·본문 기반 핵심 내용
- X세대에서의 인그레스죠 네임스페이스 내의 모든 서비스를 목록으로 만들 거예요 CTL get service N, Ingress 엔진 X 이게 제 서비스 이름이에요
- API 사용자의 현재 사용자예요 브라우저가 자동으로 도메인에 있는 척할 거예요 그런 다음 응답 데이터를 반환할 수 있어요
- HTTP에 요청을 할 거예요 콜론, 슬래시, 인그레스 대시, X세대 .인그레스 대시, X세대 그리고 svc 클러스터 로컬에요
- 따라서 API 사용자의 현재 사용자의 마지막 단계에서도 경로를 지정할 거예요 여기 첫 번째 부분은 도메인이 인그레스 엔진 x에 접근하는 거죠 루트는 인그레스 엔진 x에 우리 요청이 전달되길 원하는 곳을 알려주는 거예요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `API`, `service`, `Ingress`, `HTTP`
