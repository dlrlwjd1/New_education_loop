# Reminder on Server Side Rendering

## 개요
- 브라우저가 다음 요청을 할 거예요 추가적인 JavaScript 파일을 요청하겠죠 React App 개발 서버 생성으로 만들어져서 브라우저가 요청하는 JavaScript 파일로 응답할 거예요
