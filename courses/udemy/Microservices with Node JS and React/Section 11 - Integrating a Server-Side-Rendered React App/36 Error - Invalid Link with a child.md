# Error: Invalid <Link> with <a> child

## 개요
- Error: Invalid <Link> with <a> child In the upcoming lecture, we will be adding a Link to our Header. In Next.js v13, using an <a> tag will cause an error: Error: Invalid <Link> with <a> child. Please remove <a> or use <Link legacyBehavior>. Learn more: https://nextjs.org/docs/messages/invalid-new-link-with-extra-anchor

## 내용
### 자막·본문 기반 핵심 내용

Please remove <a> or use <Link legacyBehavior>. Learn more: https://nextjs.org/docs/messages/invalid-new-link-with-extra-anchor
- To resolve this, we need to remove the <a> and move the className up to the Link component: <Link className="navbar-brand" href="/">
