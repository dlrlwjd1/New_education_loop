# On the Server or the Browser

## 개요
- HTTP나 빈 문자열의 기본 URL로 만들 수 있죠 기본 도메인이나 기본 URL은 브라우저에 의존할 거예요

## 내용
### 자막·본문 기반 핵심 내용
- HTTP나 빈 문자열의 기본 URL로 만들 수 있죠 기본 도메인이나 기본 URL은 브라우저에 의존할 거예요
- 초기 소품 요청은 HTTP에 기록되어야 하고요 그리고 저 긴 URL은 뭐였더라? 인그레스와 인그레스 점과 대시 엔진 x LS 케이스도 추가할 수 있어요
- 그걸 이해했으니 초기 프로펠러 내부의 전체 도메인 이슈를 걱정해야 해요 우리가 브라우저에 있는지 서버에 있는지 파악해야 해요 거기서 요청을 하면 그에 따라 도메인을 조정할 수 있도록요
- 하지만 그 기능이 최근에 제거됐기 때문에 그 대신 바보 같은 대비책에 보다시피 다음 JS에서 그 기능이 제거돼 좀 유감입니다 하지만 그게 인생이죠
