# Fetching Data During SSR

## 개요
- 액시오스에서 액시오스를 수입할 거예요 요청을 위해 액시오스를 만들 거예요 궁금하실 것 같은데 왜 아까 use request훅을 만들 때 액시오를 우리가 User Quest를 만든 건 일종의 요청을 아주 쉽게 만들고 발생할 수 있는 어떤 오류도 처리하기 위해서죠

## 내용
### 자막·본문 기반 핵심 내용
- 액시오스에서 액시오스를 수입할 거예요 요청을 위해 액시오스를 만들 거예요 궁금하실 것 같은데 왜 아까 use request훅을 만들 때 액시오를 우리가 User Quest를 만든 건 일종의 요청을 아주 쉽게 만들고 발생할 수 있는 어떤 오류도 처리하기 위해서죠
- 비동기 키워드를 여기 넣을게요 await 액시오스 대상 API 사용자의 현재 사용자로부터 응답이 올 거예요
- 잠시 상기시켜드리기 위해서요 잘 안 열리지만 열게요 사용자의 현재 사용자에게 get request를 할 거예요
- 사용자가 로그인했든 안 했든 HTML 문서의 초기 브라우저에 돌아온 초기 응답을 디스플레이할 수 있도록 하는 거죠

### 구현 요소
