# Basics of Next JS

## 개요
- React Router는 JavaScript 파일 내에 라우팅 구성을 설정하는 것에 관한 거예요 하지만 JSP는 아주 다른 방식으로 작동하죠

## 내용
### 자막·본문 기반 핵심 내용
- React Router는 JavaScript 파일 내에 라우팅 구성을 설정하는 것에 관한 거예요 하지만 JSP는 아주 다른 방식으로 작동하죠
- 이 디렉터리 안에 새 폴더를 만들게요 그런 다음 클라이언트로 바꿔 패키지 JSON 파일을 생성할 겁니다 90분 대시를 json 파일에 제 패키지가 있네요
- 프로젝트를 시작할 때마다 Next를 쓰면 페이지의 내용을 볼 수 있어요 인덱스라는 두 개의 파일이 있네요
- 클라이언트 디렉터리 안에요 먼저 새 폴더를 만들게요 이 페이지 디렉터리 안에서 여러 가지 다른 JavaScript 파일을 작성하게 될 거예요
