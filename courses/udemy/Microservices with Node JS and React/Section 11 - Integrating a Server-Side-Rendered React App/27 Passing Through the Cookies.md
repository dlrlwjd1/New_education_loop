# Passing Through the Cookies

## 개요
- 요청 객체를 구조화할 거예요. 여기 이 요청은 Express JS 응용 프로그램 안에서 우리가 받길 기대하는 요청 개체와 같은 종류죠

## 내용
### 자막·본문 기반 핵심 내용
- 요청 객체를 구조화할 거예요. 여기 이 요청은 Express JS 응용 프로그램 안에서 우리가 받길 기대하는 요청 개체와 같은 종류죠
- 이 전체 개체에 REC 속성으로 상주합니다 REST 자체로 구조를 해제해 수신 요청의 모든 헤더를 살펴볼 거예요 쿠키는 헤더로 전달되니까요
- 수신 요청에서 많은 특성을 가져다가 API 호출로 직접 그 전략을 써보죠 여기 헤더 개체를 삭제하고 REC.Header로 바꾸죠
- Next DJs의 요청을 In귄레스와 Gen X로 보내면 이 수신 요청과 관련된 모든 헤더와 쿠키들이 서비스로 직접 전달될 거예요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `Express`, `REST`, `API`
