# Building a Next Image

## 개요
- 다음 JS는 TypeScript를 지원해요 하지만 특정 애플리케이션에 사용한다면 얻는 것보다 잃는 게 더 많을 우리가 여기서 만들고 있는 React Application은 간단해서 TypeScript를 사용하는 이점은 별로 없지만 훨씬 더 많은 노력을 들여서 떠다니는 1톤의 타입에 주석을 달아야 특히 다음 JS를 위해 주석을 많이 추가해야 해요

## 내용
### 자막·본문 기반 핵심 내용
- 다음 JS는 TypeScript를 지원해요 하지만 특정 애플리케이션에 사용한다면 얻는 것보다 잃는 게 더 많을 우리가 여기서 만들고 있는 React Application은 간단해서 TypeScript를 사용하는 이점은 별로 없지만 훨씬 더 많은 노력을 들여서 떠다니는 1톤의 타입에 주석을 달아야 특히 다음 JS를 위해 주석을 많이 추가해야 해요
- 테스트 목적으로 아주 빨리 만들었죠 제가 잠깐 언급하고 싶은 또 한 가지는 두 개의 다른 구성 요소 파일을 만들어 TypeScript가 아닌 JavaScript로 작성했다는 거예요
- 솔직히 말해서 TypeScript를 여기서 쓴다면 상당한 시간을 들여 TypeScript에게 다음에 뭐가 나올지 알려줘야 해요
- 이미지를 빌드하고 싶을 땐 언제든 Docker 파일을 생성하세요 클라이언트 디렉토리 안에 Docker 파일이란 새 파일을 만들게요
