# When is GetInitialProps Called?

## 개요
- 예를 들어 서버 쪽 렌더링 프로세스 동안 바로 여기서 이 요청을 만든다면 HTTP나 인그레스 같은 걸 추가해야 합니다 조금 전에 얘기한 다른 모든 것도요

## 내용
### 자막·본문 기반 핵심 내용
- 예를 들어 서버 쪽 렌더링 프로세스 동안 바로 여기서 이 요청을 만든다면 HTTP나 인그레스 같은 걸 추가해야 합니다 조금 전에 얘기한 다른 모든 것도요
- 다른 말로 하면 빈 문자열 액시오스의 기본 URL을 이용하는 거죠 브라우저 안에서 요청을 실행하면서 URL을 가질 거예요
- 하지만 서버 쪽 렌더링 프로세스에서 요청을 할 경우 해당 요청에 기본 URL을 설정해야 합니다 인그레스 및 X 세대에게 직접 연락할 수 있도록요
- 하지만 초기 소품에 대한 요청을 할 때는 걱정해야 해요 우리가 어떤 요청을 구성 요소 내에서나 후크 내에서, 예를 들어 USEQUE 요청 같은 것으로부터 만든다면, 조금 전에 같이 만든 거죠 이 도메인 관련해서는 걱정할 필요가 없지만 Get 초기 소품 내에서 발생하는 어떤 요청이든, 그게 우리가 이 전체 도메인 문제에 대해 걱정해야 하는 점이죠

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `HTTP`
