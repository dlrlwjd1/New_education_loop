# The Sign In Form

## 개요
- API 사용자가 로그인하는 대신 API 사용자 로그인에 요청해야 해요 React JS에 초점을 맞추는 강의였다면 이 양식을 둘 다 디스플레이하기 위해 재사용 가능한 단일 구성 요소를 만드는 법을 보여드렸을 거예요

## 내용
### 자막·본문 기반 핵심 내용
- API 사용자가 로그인하는 대신 API 사용자 로그인에 요청해야 해요 React JS에 초점을 맞추는 강의였다면 이 양식을 둘 다 디스플레이하기 위해 재사용 가능한 단일 구성 요소를 만드는 법을 보여드렸을 거예요
- 로그인이라고 돼 있는지 확인해야 해요 그래야 할 것 같아요 다시 뒤집을게요 Off sign in으로 이동할 수 있을 거예요
- React에 초점을 맞추지 않기 때문에 복사, 붙여넣기, 등록만 하면 됩니다 그리고 요청한 라벨과 URL을 바꾸는 거죠
- 시험해본 거예요 그런 다음 Sign Up의 복사본을 만들게요 편집기에 그 옵션이 있다면 복제를 시도할 수도 있어요

### 구현 요소
