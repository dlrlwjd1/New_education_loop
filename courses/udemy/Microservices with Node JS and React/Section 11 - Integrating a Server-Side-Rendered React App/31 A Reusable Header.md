# A Reusable Header

## 개요
- 첫 번째 옵션은 다양한 페이지 구성 요소 모두로 가는 겁니다 Indexed Edge의 로그인 후 로그인하는 거죠

## 내용
### 자막·본문 기반 핵심 내용
- 첫 번째 옵션은 다양한 페이지 구성 요소 모두로 가는 겁니다 Indexed Edge의 로그인 후 로그인하는 거죠
- _AppJS 파일 안에요 원래 이렇게 한 이유는 글로벌 CSS를 포함시키기 위해서였죠
- 이 헤더를 만드는 데 집중할게요 모든 단일 페이지 상단에 디스플레이될 모든 페이지 상단에 표시된다는 점을 고려할 때 디자인과 스크린에 보여주는 방법은 두 가지예요
- 각각에 추가할 수 있어요 가장 윗부분의 로그인 내부에 해당 폼 바로 위에요 재사용 가능한 헤더 구성 요소 같은 거죠

### 구현 요소
- 강의 흐름에 따라 A Reusable Header의 구현 목적과 적용 지점을 확인한다.

## 예시
