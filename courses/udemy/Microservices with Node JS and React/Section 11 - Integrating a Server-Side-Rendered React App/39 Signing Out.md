# Signing Out

## 개요
- 효과를 사용할 거예요 React에서 Reacte 요청을 받을 수 있어요 위쪽 디렉터리 책에서 Reacte 요청이요

## 내용
### 자막·본문 기반 핵심 내용
- 효과를 사용할 거예요 React에서 Reacte 요청을 받을 수 있어요 위쪽 디렉터리 책에서 Reacte 요청이요
- API 사용자에게 게시 요청만 하면 돼요 그럼 우리 사용자가 로그아웃하죠 중요한 얘기가 하나 더 있어요
- USEquested를 호출할 때마다 do request 함수가 나오는 걸 기억하세요
- 디렉터리 내에 새 페이지를 생성하죠 안에 개가 있어요 사용자 요청 후크를 얻겠습니다 React에서 효과 사용 함수도 얻고요
