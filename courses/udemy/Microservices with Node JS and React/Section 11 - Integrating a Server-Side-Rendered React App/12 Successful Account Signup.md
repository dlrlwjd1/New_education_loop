# Successful Account Signup

## 개요
- 기억하세요, 처음에 서비스를 준비할 때 이미 이것에 대해 장시간 All Service에는 게시 요청 처리기가 있어 API 사용자가 등록한 수신 요청을 감시하죠

## 내용
### 자막·본문 기반 핵심 내용
- 기억하세요, 처음에 서비스를 준비할 때 이미 이것에 대해 장시간 All Service에는 게시 요청 처리기가 있어 API 사용자가 등록한 수신 요청을 감시하죠
- 브라우저 안에서 실행되는 React Application에서 할 일은 API 사용자 등록에 게시 요청을 하는 게 다죠 우리 서비스로 갈 거예요
- Ingress 엔진 X Service가 있죠 초기 라우팅을 처리할 거예요 인그레스 엔진 X 경로가 확보될 때마다 클러스터 내부에서 실행되는 클러스터 IP 서비스로 갑니다 그 클러스터 IP 서비스에서도요
- 그리고 마침내 컨테이너를 운행하는 구역으로 보내졌죠 그 컨테이너 안에는 Express 응용 프로그램이 있어요 요청 처리기로 라우트할 겁니다 거기서 사용자를 생성하죠
