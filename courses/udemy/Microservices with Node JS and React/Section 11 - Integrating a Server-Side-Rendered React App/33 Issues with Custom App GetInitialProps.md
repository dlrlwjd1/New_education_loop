## 내용
### 자막·본문 기반 핵심 내용
- 사용자 지정 앱 구성 요소를 위해 JIT 초기 기능을 정의할 때요 하지만 REST 객체는 첫 번째 인수 안에 있죠
- API 사용자는 사용자가 아니에요 여전히 데이터를 반환할 수 있어요 그 외장 함수를 sync로 표시하도록 할게요
- 그리고 단말기로 가서 키 콘솔을 볼 수 있어요 저기 통나무가 있어요 다시 한 번 앱 컨텍스트에서는 앱 3개 구성 요소 라우터와 Ctcs를 얻습니다 그리고 Ctcs는 우리가 정말 신경 쓰는 거죠 왜냐하면 거기 중첩돼 있어도 여전히 같으니까요
- 지난 비디오에서 앱 구성 요소를 위한 스캐폴딩을 작성했는데 갑자기 비디오를 끝냈어요 초기 소품이 있네요
