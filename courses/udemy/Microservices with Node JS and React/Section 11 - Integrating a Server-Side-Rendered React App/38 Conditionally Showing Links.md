# Conditionally Showing Links

## 개요
- 하지만 그걸 여기서 다 써서 엉망진창인 Gsx로 끝내는 것보다는 제가 갖고 있는 트릭을 보여드리고 싶어요 컬렉션이나 일종의 요소 리스트를 렌더링하고 조건부로 보여주거나 일부를 숨기기 위해서요

## 내용
### 자막·본문 기반 핵심 내용
- 하지만 그걸 여기서 다 써서 엉망진창인 Gsx로 끝내는 것보다는 제가 갖고 있는 트릭을 보여드리고 싶어요 컬렉션이나 일종의 요소 리스트를 렌더링하고 조건부로 보여주거나 일부를 숨기기 위해서요
- 현재 사용자가 null일 때만 로그인하는 걸 보여드리고 싶어요 사용자가 로그인하지 않으면 현재 사용자는 null이 되니까요
- 헤더 작업이 순조롭게 진행되고 있어요 우리가 할 일은 별로 좋지 않은 저 표현을 다양한 요소로 바꾸는 각각의 거짓말은 다른 링크를 보여주려고 하죠
- 결국 총 세 개의 거짓말이 될 거예요 하나는 로그아웃, 하나는 로그인 하나는 로그업이죠

### 구현 요소
- 강의 흐름에 따라 Conditionally Showing Links의 구현 목적과 적용 지점을 확인한다.

## 예시
