# An onSuccess Callback

## 개요
- 그런 다음 do request로 내려가죠 요청을 하고 성공적으로 답변을 받은 후에 온 성공 콜백이 제공됐는지 만약 그렇다면 전화를 걸어보죠

## 내용
### 자막·본문 기반 핵심 내용
- 그런 다음 do request로 내려가죠 요청을 하고 성공적으로 답변을 받은 후에 온 성공 콜백이 제공됐는지 만약 그렇다면 전화를 걸어보죠
- 그냥 보내기 내부에 호출을 추가하죠 성공적으로 등록했든 안 했든 사용자를 루트 경로로 다시 라우터 push를 호출해 사용자를 이동시키기 원하는 경로를 제공할 이걸 저장하고 다시 뒤집을게요
- 하지만 가장 중요한 건 여기서 발생한 오류를 잡았다는 거예요 어떤 오류도 summit 함수 안에서 나타나지 않습니다 즉, 예정된 요청을 호출한 후에는 오류가 발생하더라도 라우터 push로 진행할 수 있다는 이상적이진 않죠
- 예를 들어, 집합 에러를 호출한 직후에 throw Air를 입력할 수 있죠 공기를 내보낸다는 건 노출된다는 뜻이에요 본질적으로 이 줄을 내보낸다는 거죠
