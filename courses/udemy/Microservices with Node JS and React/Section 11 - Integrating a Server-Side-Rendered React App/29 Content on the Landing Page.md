# Content on the Landing Page

## 개요
- null과 같다면 출력해야 해요 로그인하지 않았고 그 안에 ID나 이메일로 된 개체와 같다면 프린트할 로그인 완료됐어요

## 내용
### 자막·본문 기반 핵심 내용
- null과 같다면 출력해야 해요 로그인하지 않았고 그 안에 ID나 이메일로 된 개체와 같다면 프린트할 로그인 완료됐어요
- 오랜 작업 끝에 드디어 정보를 얻었어요 착륙 페이지에 로그인했는지 아닌지에 마지막으로 현재 사용자 프로펠러를 살펴보는 거예요
- 다시 뒤집어서 한번 해 보죠 첫 페이지 내용이에요 그 안에 있는 건 지금 당장 다 지울 거예요 그리고 아주 간단하고 다양한 표현을 넣을 거예요
- 정의가 됐다면 보여드리죠 서명했다고 돼 있잖아요 아니면 H1이고요 서명을 안 했군요
