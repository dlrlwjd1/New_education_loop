## 개요
- 이 프로젝트에서 제일 위에 훅을 사용할 거예요 React에서 USEState훅을 가져올 거예요

## 내용
### 자막·본문 기반 핵심 내용
- 이 프로젝트에서 제일 위에 훅을 사용할 거예요 React에서 USEState훅을 가져올 거예요
- 비밀번호 값을 입력할 거예요 그런 다음 이게 바뀔 때마다 해당 이벤트를 갖고 암호를 호출해요 e. target. value와 그 두 개의 상태를 추적하는 거죠
- 기본 형태를 갖췄어요 이벤트 처리기를 입력에 추가할게요 양식을 위한 제출 처리기를 설치해 사용자가 뭔가를 입력하거나 저 버튼을 클릭하거나 양식을 제출하려 할 때 궁극적으로 우리 오프서비스에 요청하게 사용자가 이 2개의 입력 안에 입력한 걸 계속 추적하기 위해서는 어떤 상태 조각을 추적해야 해요
- 그런 다음 구성 요소 안에서 두 개의 새로운 상태를 만들 거예요 이메일 한 통이면 돼요
