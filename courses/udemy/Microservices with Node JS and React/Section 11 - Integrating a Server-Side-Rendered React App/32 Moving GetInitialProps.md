# Moving GetInitialProps

## 개요
- 디렉터리 하나 위로요 API 빌드 파이프라인이요 이니셜 프로펠러도 내렸고요 여기에 적을게요 컨텍스트 인수를 받으려고 해요

## 내용
### 자막·본문 기반 핵심 내용
- 디렉터리 하나 위로요 API 빌드 파이프라인이요 이니셜 프로펠러도 내렸고요 여기에 적을게요 컨텍스트 인수를 받으려고 해요
- 이 비디오에선 인덱스에서 사용자 지정 앱 구성 요소까지 초기 소품을 추출해 여기서 추출이란 건 복사 붙여넣기를 의미해요
- 양쪽에서 초기 소품을 확보하고 싶어요 여전히 데이터를 가져올 수 있는지 테스트하고 확인할 수 있도록요 표시하려는 페이지와 사용자 지정 앱 양쪽에서요
- 두 곳에서 동시에 데이터를 가져올 수 있으면 착륙 페이지에서 초기 소품을 결국 사라질 거예요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `API`
