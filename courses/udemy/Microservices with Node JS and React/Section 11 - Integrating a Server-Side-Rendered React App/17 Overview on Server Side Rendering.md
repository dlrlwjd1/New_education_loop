# Overview on Server Side Rendering

## 개요
- 우리가 원하는 건 이거예요 우리 서비스에 요청하는 걸 확실히 하고 싶어요 구체적으로 API 사용자의 우리가 로그인하면 돌아온 응답은 우리에 대한 정보를 갖게 되죠

## 내용
### 자막·본문 기반 핵심 내용
- 우리가 원하는 건 이거예요 우리 서비스에 요청하는 걸 확실히 하고 싶어요 구체적으로 API 사용자의 우리가 로그인하면 돌아온 응답은 우리에 대한 정보를 갖게 되죠
- 진짜 문제는 이 요청을 언제 하느냐는 거죠 사용자가 서버에 초기 요청을 할 때마다 그러니까 응용 프로그램을 얻기 위한 이 초기 요청은 일종의 HTML 파일을 그 안에 일부 관련 콘텐츠가 들어있는 채로 즉시 보내주길 우리가 즉시 보내는 이 HTML 파일은 사용자가 로그인했는지 아닌지 알려줘야 그 말은 응용 프로그램이 차세대 서버에서 빌드되거나 서비스되는 동안 요청하는 방법을 알아내야 한다는 거죠
- 그 둘 사이에 착륙 페이지를 쓰고 초기 소품을 얻죠 이 get 초기 장치는 next JRS에 특화돼 있어요
- 예를 들어 ID나 이메일 같은 거요 하지만 로그인이 안 되면 응답이 null이 되죠

### 구현 요소
