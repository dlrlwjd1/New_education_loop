## 내용
### 자막·본문 기반 핵심 내용
- bootstrap CSS를 가져올 거예요 import bootstrap dist CSS라고 쓸게요 bootstrap.CSS 아직 부트스트랩을 NP 모듈로 설치하지 않았어요 여기 이 라인은 설치했다고 가정하죠
- Bootstrap은 글로벌 CSS 파일이에요 전체 응용 프로그램에 적용돼야 할 CSS가 포함돼 있다는 거죠 그 안의 모든 페이지에도요
- bootstrap CSS를 이용해 이 프로젝트 스타일을 정할 거예요 이 비디오에선 부트스트랩을 설치하고 우리 프로젝트에 배선하는 걸 중점적으로 다룰 거예요
- 따라서 안에 불러온 CCIS는 최종 HTML 파일에 포함되지 않죠 따라서 모든 페이지에 포함돼야 하는 글로벌 CSS가 있다면 이 앱 파일로 불러와야 합니다 사용자가 우리 응용 프로그램에 올 때마다 로드될 수 있는 유일한 파일이니까요
