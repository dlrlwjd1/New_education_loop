# Handling Multiple GetInitialProps

## 개요
- 마지막 비디오에서 앱 구성 요소의 get 초기 프로펠러 기능을 정의하는 걸 봤죠 시작 페이지 내에 있던 걸 비활성화했어요

## 내용
### 자막·본문 기반 핵심 내용
- 마지막 비디오에서 앱 구성 요소의 get 초기 프로펠러 기능을 정의하는 걸 봤죠 시작 페이지 내에 있던 걸 비활성화했어요
- 이 비디오에서 이 문제를 빨리 해결하는 방법을 알아보죠 이게 무대 뒤에서 벌어지는 일이군요
- 앱 구성 요소도 있고요 데이터를 가져와서 앱에 소도구로 넣으려고 하죠 랜딩 페이지도 있죠 인덱스 도그를 호출하기보다는 랜딩 페이지라고 부를게요
- 그 자체로 초기 프로펠러 기능이 있어요 지금은 호출이 안 되고 있어요 하지만 이렇게 해결할 거예요

### 구현 요소
- 강의 흐름에 따라 Handling Multiple GetInitialProps의 구현 목적과 적용 지점을 확인한다.
