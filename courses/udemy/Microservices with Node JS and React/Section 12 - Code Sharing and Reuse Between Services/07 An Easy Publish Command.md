# An Easy Publish Command

## 개요
- 아니면 NPM 버전 패치 같은 기본 제공 명령을 실행해도 되고요 NPM 버전 패치를 실행하면 PM이 패키지 JSON 파일을 자동으로 열고 마지막 버전 번호를 업데이트해요

## 내용
### 자막·본문 기반 핵심 내용
- 아니면 NPM 버전 패치 같은 기본 제공 명령을 실행해도 되고요 NPM 버전 패치를 실행하면 PM이 패키지 JSON 파일을 자동으로 열고 마지막 버전 번호를 업데이트해요
- TypeScript가 사용하고 TypeScript에게 우리 프로젝트 내의 주요 형식 정의 파일이 을 위해 이건 indexed 파일입니다 빌드 디렉터리 내에서요
- 그런 다음 버전 패치를 하죠 NPM 런을 빌드할게요 그런 다음 MP가 게재하죠 게시하는 건 NPM이 게시하는 게 아니에요
- 이런 걸 쓸 거예요 미들웨어 불러오기 Srg 티케팅/공통으로부터의 저 패키지 내의 주요 깃발 JSON 파일은 이 임포트 문을 작성할 때 어떤 파일에 도달하려 했는지 알려주는 거죠
