# NPM Organizations

## 개요
- 지난 비디오에서 NPM 패키지를 통해 모든 코드를 공유하기로 했죠 공동 라이브러리를 NPM 패키지로 게시하는 것과 관련해 먼저 논의하고 싶은 건 코드의 보안이에요

## 내용
### 자막·본문 기반 핵심 내용
- 지난 비디오에서 NPM 패키지를 통해 모든 코드를 공유하기로 했죠 공동 라이브러리를 NPM 패키지로 게시하는 것과 관련해 먼저 논의하고 싶은 건 코드의 보안이에요
- 사설 단체를 이용하려면 NPM에 돈을 더 내야 해요 사설 레지스트리도 만들 수 있습니다 여기에 접근 권한은 직접 접근 권한을 준 사람에게만 NPM을 통해 직접 민간 레지스트리를 만들면 결국 돈을 내야 해요
- 이 패키지를 NPM에 공개할 수 있어요 어떤 조직 내의 공공 등기소에 게시할 수도 있고 개인 등기소에 게시할 수도 우리가 등기부에 소포를 올렸을 때요
- 따라서 이 패키지를 NPM에 바로 게시하면 모두가 볼 수 있죠 민간 단체에 출판하면 우리 단체의 일원만 접근할 그걸 개인 레지스트리에 게시하면 우리 레지스트리에 접속한 사람들만 조직 옵션으로 끝날 거예요
