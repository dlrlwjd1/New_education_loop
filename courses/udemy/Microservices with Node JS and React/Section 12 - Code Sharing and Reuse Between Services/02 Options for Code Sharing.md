# Options for Code Sharing

## 개요
- 이 공통 코드가 필요한 다른 서비스 내부에 NPM 종속성으로 설치할 겁니다 여러분이 익숙한 NPM 설치 명령을 사용해서요

## 내용
### 자막·본문 기반 핵심 내용
- 이 공통 코드가 필요한 다른 서비스 내부에 NPM 종속성으로 설치할 겁니다 여러분이 익숙한 NPM 설치 명령을 사용해서요
- NPM 레지스트리에 패키지로 게시할 거예요 이름을 Git틱스, 대시 공통 같은 걸로 할 수도 있죠
- Git을 잘 아신다면 서브 모듈을 들어보셨을 거예요 하위 모듈은 하나의 Git 리포지토리가 있을 때 어떻게든 다른 Git 리포지토리를 그 안에 포함하고 싶은 서비스에 대한 Git repo를 만들 수도 있고 티켓 서비스는 모든 공통 코드에 대한 세 번째 repo를 만들 수도 있죠
- 이건 확실히 유효한 옵션이지만 약간의 고통이 수반되죠 세 번째 옵션은 일반적인 코드를 NPM 패키지로 게시하는 거예요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `NPM`, `Git repo`, `Git Tick library`
