# Publishing NPM Modules

## 개요
- 여기서 서로 다른 서비스 사이에 접근하고자 하는 모든 공용 논리를 Common으로 바꾸겠습니다 그 안에 npm init 패키지 JSON 파일을 생성할 거예요

## 내용
### 자막·본문 기반 핵심 내용
- 여기서 서로 다른 서비스 사이에 접근하고자 하는 모든 공용 논리를 Common으로 바꾸겠습니다 그 안에 npm init 패키지 JSON 파일을 생성할 거예요
- 이름이 나왔으니 이 파일을 저장할게요 이 패키지를 즉시 제 조직 또는 NPM 레지스트리에 게시하고 싶어요
- NPM에서 사용하는 사용자 이름과 암호를 입력하세요 이걸 게시할 수 있으면 좋겠네요
- 이 모듈을 게시하면 이제 다른 서비스에 설치할 수 있어요 NPM 자체에 관한 게시된 패키지도 살펴볼 수 있어요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `npm`, `JSON`, `npm init`
