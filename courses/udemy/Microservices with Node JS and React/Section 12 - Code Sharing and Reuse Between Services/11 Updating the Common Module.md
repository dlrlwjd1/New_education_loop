# Updating the Common Module

## 개요
- 저 스크립트는 정말 필요 없지만 이 과정에선 상당한 시간을 절약할 NPM 런 펍을 하려고요

## 내용
### 자막·본문 기반 핵심 내용
- 저 스크립트는 정말 필요 없지만 이 과정에선 상당한 시간을 절약할 NPM 런 펍을 하려고요
- 인증으로 바꿀게요 NPM 업데이트만 하면 되죠 SG 티켓 슬래시 코멘트도요 물론 SG 티켓을 조직 이름으로 바꾸시겠죠
- 노드 모듈 폴더를 열어 볼게요. 그 안에서 공통 모듈을 찾고 싶어요 패키지 JSON 파일을 프린트하고 버전 1이 나왔다는 걸 확인하고 싶어요 9인용이에요
- 패키지 JSON 파일을 캣할 거예요 그 안의 모든 정보를 프린트하기 위해서요 스크롤을 조금 올리면 확인할 수 있을 거예요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `NPM`, `JSON`

## 예시
`NPM`, `JSON`가 등장하는 설정·코드 위치를 찾아 강의와 같은 순서로 확인한다.
