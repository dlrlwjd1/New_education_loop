# Project Setup

## 개요
- 선언문을 먼저 찾을 거예요 주석 처리하지 마세요 TypeScript를 JavaScript로 바꿀 때 유형 정의 파일도 생성되는 TypeScript를 사용하는 서비스에 이 모듈 설치를 중단해도 TypeScript가 공통 모듈 안에서 무슨 일이 벌어지는지 알아낼 수 있도록 형식 정의 파일이 여전히 존재하죠

## 내용
### 자막·본문 기반 핵심 내용
- 선언문을 먼저 찾을 거예요 주석 처리하지 마세요 TypeScript를 JavaScript로 바꿀 때 유형 정의 파일도 생성되는 TypeScript를 사용하는 서비스에 이 모듈 설치를 중단해도 TypeScript가 공통 모듈 안에서 무슨 일이 벌어지는지 알아낼 수 있도록 형식 정의 파일이 여전히 존재하죠
- 아주 특별한 버전의 TypeScript를 쓸 거예요 미래에는 TypeScript의 다른 버전을 사용하는 서비스에 이걸 설치할지도 TypeScript의 하나의 버전과 일부 서비스에서 사용되는 다른 버전 사이에 어떤 버전 이슈도 있어선 안 되니까요
- 그게 TypeScript 컴파일러를 실행하고 TypeScript 컴파일러를 설정해 indexed 파일을 찾고 예상하셨듯이 JavaScript 코드로 바꿀 거예요
- NPM, 런, 빌드요 우리가 쓴 TypeScript 파일을 JavaScript로 변환해 해당 빌드 디렉터리에 아니나 다를까 저기 있네요
