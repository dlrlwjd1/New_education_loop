# Updating Import Statements

## 개요
- 여기 있는 것과 같이 깨진 import 문을 찾을 수 있습니다. 그리고 이것들을 고쳐주세요.

## 내용
### 자막·본문 기반 핵심 내용
- 여기 있는 것과 같이 깨진 import 문을 찾을 수 있습니다. 그리고 이것들을 고쳐주세요.
- 두 가지 오류가 있네요 이거 꽤 괜찮네요 미들웨어와 Air를 개별적인 import 문장으로 불러오고 있었죠 요청 유효성 검사와 나쁜 요청 오류로요
- 이 안에 import 문에 에러가 없는 것 같네요. 뿌리로 들어가 보죠 테스트 디렉터리요
- 인증 모듈에는 미들웨어 디렉터리도 없어요 이 임포트 문을 업데이트해야 합니다 일반 모듈에서 현재 사용자의 미들웨어를 꺼내기 우리가 해야 할 일은 import 문을 업데이트 하는 거에요.

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `NPM`, `JSON`, `TS`

## 예시
`NPM`, `JSON`, `TS`가 등장하는 설정·코드 위치를 찾아 강의와 같은 순서로 확인한다.
