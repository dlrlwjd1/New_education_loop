# Relocating Shared Code

## 개요
- 예를 들어 현재 사용자 미들웨어 내부에서 Express와 JSON 웹 토큰을 불러오려고 이 모든 모듈을 내부에 설치했어요

## 내용
### 자막·본문 기반 핵심 내용
- 예를 들어 현재 사용자 미들웨어 내부에서 Express와 JSON 웹 토큰을 불러오려고 이 모든 모듈을 내부에 설치했어요
- 바로 시작하도록 하죠 NP 설치를 할 거예요 모듈 목록이 꽤 방대하네요 Express Express 유효성 검사기를 가져올 거예요
- 타입 쿠키 세션과 타입 익스프레스의 타입 JSON Web 토큰을 배울 거예요 그게 다인 것 같아요
- 예를 들어, off project 안에 나쁜 요청 오류를 불러오길 원하죠 특히 그런 indexed 파일을 열게요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `TypeScript`, `Express`, `JSON`
