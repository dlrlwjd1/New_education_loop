# Shared Logic Between Services

## 개요
- 인증 서비스를 위한 이벤트와 관련된 건 신경 쓰지 않을 거예요 사실 서비스가 실제로 하는 모든 일은 JSON 웹 토큰을 통해 소통을 서비스가 다른 서비스들과 통신하는 거죠

## 내용
### 자막·본문 기반 핵심 내용
- 인증 서비스를 위한 이벤트와 관련된 건 신경 쓰지 않을 거예요 사실 서비스가 실제로 하는 모든 일은 JSON 웹 토큰을 통해 소통을 서비스가 다른 서비스들과 통신하는 거죠
- 사용자의 쿠키 안에 JSON Web 토큰을 설정해야 해요 이 비디오에선 다음 대형 서비스에 대해 배워보죠
- 사용자가 인증되도록 하기 위해서요 쿠키를 검사하고 JSON 웹 토큰을 꺼내 토큰 유효성 검사 등을 하죠
- 클라이언트 쪽 응용 프로그램은 이제 꽤 괜찮아 보여요 이 안에서 온갖 종류의 인증 작업이 실행되고 있죠

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `JSON`
