# Auth Helper Function

## 개요
- 그러기 위해 파일 상단으로 갈게요 여기서 TypeScript 코드를 잠깐 써 볼게요 TypeScript에게 Sign Up라는 전역 속성이 있다고 알려 주려고요

## 내용
### 자막·본문 기반 핵심 내용
- 그러기 위해 파일 상단으로 갈게요 여기서 TypeScript 코드를 잠깐 써 볼게요 TypeScript에게 Sign Up라는 전역 속성이 있다고 알려 주려고요
- 쿠키가 정확히 뭔지 설명하자면 문자열의 배열이에요 그러니까 이 promise는 결국 스스로 해결된다고 하는 거죠 for 값으로 문자열 배열이죠
- 이 안에 이렇게 쓸게요 컨스트 응답은 웨이트예요 우리 앱에 요청할게요 API 사용자에게 게시 요청을 할 거예요
- 제 생각엔 이게 딱 맞는 것 같아요 셋업 파일로 돌아갈게요 TypeScript에게 전역 로그인 속성이 있다는 걸 알려줘야 해요

### 구현 요소
