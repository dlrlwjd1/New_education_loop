# Requiring Unique Emails

## 개요
- 저 새 블록 안에서 작업하고 대기할 거예요 앱에서 Request는 API 사용자에게 게시 요청을 하죠

## 내용
### 자막·본문 기반 핵심 내용
- 저 새 블록 안에서 작업하고 대기할 거예요 앱에서 Request는 API 사용자에게 게시 요청을 하죠
- 이 비디오에선 사용자가 같은 이메일을 연달아 두 번 로그인할 수 없다는 걸 확인하기 위해 테스트를 작성할 거예요
- 제 가입 테스트 파일로 돌아갈게요 바닥까지 내려왔어요 새로운 IT 블록을 작성하고 설명을 넣겠습니다 복제 이메일을 금지하는 것처럼요
- 이 안에서 같은 이메일과 암호 조합을 연달아 두 번 로그인하려 하죠 첫 번째 요청은 201표의 답변을 기대할 수 있어요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `Request`, `API`
