# Scope of Testing

## 개요
- 예를 들어, 우리 서비스가 MongoDB와 어떻게 상호작용하는지 혹은 서비스가 이벤트 버스와 어떻게 상호작용하는지 테스트하려고 할 때 말이죠

## 내용
### 자막·본문 기반 핵심 내용
- 예를 들어, 우리 서비스가 MongoDB와 어떻게 상호작용하는지 혹은 서비스가 이벤트 버스와 어떻게 상호작용하는지 테스트하려고 할 때 말이죠
- 우리 아트 서비스는 아주 좋아요 주문 제작 에어 핸들링 미들웨어 루트가 다 있어요
- 모든 게 맞아떨어져요 기억하실지 모르겠지만 처음 이 프로젝트를 시작했을 때 테스트에 집중할 것이라고 말씀드렸었죠
- 현재까지 자동 테스트는 전혀 하지 않았어요 포스트맨으로 테스트는 했지만 자동 테스트는 안 했어요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `MongoDB`
