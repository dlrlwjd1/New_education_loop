# Testing Goals

## 개요
- 작성할 첫 번째 테스트는 기본 요청 처리를 테스트하는 거예요 예를 들어 우리가 우리 서비스에 뭔가를 등록하기 위해 요청을 할 경우 그 안에 JSON Web 토큰이 있는 쿠키로 응답을 받아야 한다고 할 수 아니면 우리 MongoDB 데이터베이스에 데이터를 쓰겠다고 주장할 수도 있고요

## 내용
### 자막·본문 기반 핵심 내용
- 작성할 첫 번째 테스트는 기본 요청 처리를 테스트하는 거예요 예를 들어 우리가 우리 서비스에 뭔가를 등록하기 위해 요청을 할 경우 그 안에 JSON Web 토큰이 있는 쿠키로 응답을 받아야 한다고 할 수 아니면 우리 MongoDB 데이터베이스에 데이터를 쓰겠다고 주장할 수도 있고요
- Docker를 사용하지 않을 거예요 쿠버네츠 같은 건 안 쓸 거예요 테스트를 시작하자고 하면 터미널로 가서 NPM 같은 명령을 실행할 거예요 우리 로컬 컴퓨터나 개별 서비스에서 서버를 시작할 명령이죠 그런 다음 그에 대한 테스트를 실행해요
- 대신 각각의 서비스를 개별적으로 검토해 한 번에 하나씩 테스트해보죠 저희가 작성할 다양한 종류의 테스트를 보여드리고 싶어요 OTT 서비스 그 자체로요
- 이 비디오에선 다양한 테스트를 살펴볼 겁니다 티케팅 프로젝트 내의 다양한 서비스를 위해서요
