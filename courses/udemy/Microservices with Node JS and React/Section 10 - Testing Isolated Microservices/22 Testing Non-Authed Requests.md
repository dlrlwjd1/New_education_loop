# Testing Non-Authed Requests

## 개요
- 대기 요청 앱에서 응답이 올 거예요 API 사용자의 현재 사용자에게 get request를 할 거예요

## 내용
### 자막·본문 기반 핵심 내용
- 대기 요청 앱에서 응답이 올 거예요 API 사용자의 현재 사용자에게 get request를 할 거예요
- 현재 사용자 테스트 파일 내의 마지막 테스트예요 로그인을 안 했을 경우 현재 사용자가 NULL인 걸 확인해야죠
- 조립하기 정말 쉬울 거예요 여기에 블록을 하나 더 놓고 인증이 안 되면 NULL로 반응한다고 하죠
- 이번에는 어떤 쿠키도 설정하지 않을 거예요 문서가 없는 요청을 하고 싶으니까요 인증받은 건 아니지만 200점은 받아야죠

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `API`, `request`

## 예시
`API`, `request`가 등장하는 설정·코드 위치를 찾아 강의와 같은 순서로 확인한다.
