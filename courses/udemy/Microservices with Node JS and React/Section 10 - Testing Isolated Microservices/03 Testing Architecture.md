# Testing Architecture

## 개요
- 하드 코드 된 것도 있어요 특정 URL에 있는 MongoDB 데이터베이스에 연결하도록 MongoDB에게 말하라고 하기 위해서요

## 내용
### 자막·본문 기반 핵심 내용
- 하드 코드 된 것도 있어요 특정 URL에 있는 MongoDB 데이터베이스에 연결하도록 MongoDB에게 말하라고 하기 위해서요
- Express 응용 프로그램 변수에 엑세스해야 해요 인덱스 파일 내에서 정의되죠 이 Express 앱을 이 요청 함수에 전달할 겁니다 슈퍼 테스트 라이브러리에서 오는 거죠
- 패키지 JSON 파일에 새 스크립트를 추가할게요 명령과 테스트를 실행할 때마다 Gest라는 테스트 러너를 시작할 거예요
- 먼저, MongoDB의 인메모리 복사본을 시작할게요 이건 메모리에서 실행되는 Mongo의 복사본이 될 거예요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `MongoDB`, `JSON`, `Express`

## 예시
`MongoDB`, `JSON`, `Express`가 등장하는 설정·코드 위치를 찾아 강의와 같은 순서로 확인한다.
