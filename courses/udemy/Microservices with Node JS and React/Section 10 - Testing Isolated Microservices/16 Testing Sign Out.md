# Testing Sign Out

## 개요
- 이 경우엔 API 사용자에게 게시하죠 이 경우엔 서명하세요 빈 개체를 보낼 거예요 post request니까요

## 내용
### 자막·본문 기반 핵심 내용
- 이 경우엔 API 사용자에게 게시하죠 이 경우엔 서명하세요 빈 개체를 보낼 거예요 post request니까요
- API 사용자들에게 등록하라고 포스팅할게요 유효한 이메일을 보낼 거예요 그것도 타당해요
- 그 후에 요청할 거예요 API 사용자 로그아웃에 게시 요청이 될 거예요 응답에선 쿠키 헤더 설정을 검사해 정확히 뭐가 되돌아오는지 알아낼 수 퇴원할 때 위로해줘야 해요 그걸 기록해 해당 어설션을 어떻게 작성해야 할지 콘서트 응답은 대기 요청 앱이에요
- 그렇지 않다면 루트 처리기 주위의 단일 테스트를 작성하세요 다시 한 번 테스트 디렉터리 안에 로그아웃 테스트의 새 파일을 만들게요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `API`, `request`
