# Test Environment Setup

## 개요
- 맨 위에 몇 가지 다른 걸 불러올 거예요 MongoDB 혹은 MongoDB 메모리 서버에서 MongoDB 메모리 서버를 가져오죠

## 내용
### 자막·본문 기반 핵심 내용
- 맨 위에 몇 가지 다른 걸 불러올 거예요 MongoDB 혹은 MongoDB 메모리 서버에서 MongoDB 메모리 서버를 가져오죠
- 현금 금지 표시는 저희가 재밌는 TypeScript를 쓰려는 시도와 관련 있죠 TypeScript 지원이 없거든요 가끔 정말 헷갈릴 수 있어요
- 이것들을 사전 집합에 추가해서 TypeScript가 뭔지 이해 못 하게 할 거예요 TypeScript 지원을 추가할 종속성을 설치한 거죠
- Test라는 새 폴더를 만들고 그 안에 Set Updates라는 파일을 만들 거예요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `JSON`, `TypeScript`, `MongoDB`, `Mongoose`, `async`

## 예시
`JSON`, `TypeScript`, `MongoDB`, `Mongoose`, `async`가 등장하는 설정·코드 위치를 찾아 강의와 같은 순서로 확인한다.
