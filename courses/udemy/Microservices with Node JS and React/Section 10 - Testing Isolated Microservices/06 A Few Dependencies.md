# A Few Dependencies

## 개요
- 인증 디렉터리에서 Docker 파일을 찾아 NPM 설치 명령을 수정할 거예요 끝부분을 이런 사기꾼으로 바꿀 거예요

## 내용
### 자막·본문 기반 핵심 내용
- 인증 디렉터리에서 Docker 파일을 찾아 NPM 설치 명령을 수정할 거예요 끝부분을 이런 사기꾼으로 바꿀 거예요
- 이게 설치 프로세스를 시작하겠습니다 전 여기 화면 앞에 잠시 MongoDB Memory Server라는 아주 특별한 패키지를 설치할 때 그걸 보시게 될 겁니다 그에 따라 꽤 많은 양의 다운로드가 있어요
- 같은 테스트 Mongo 인스턴스에 연결된 이 모든 다른 서비스를 갖는 대신 대신에 MongoDB 메모리 서버나 메모리에 있는 Mongo 인스턴스를 생성하죠
- 제 서비스 디렉터리 안에 있습니다. NPM 설치를 할게요. 테스트 종속성이 아주 중요해요 설치는 개발 종속성으로 여기에 저장을 위한 플래그를 추가할게요.

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `NPM`, `MongoDB`, `Docker`
