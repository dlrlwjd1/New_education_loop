## 내용
### 자막·본문 기반 핵심 내용
- JavaScript는 고유의 sync와 비동기 정의가 있어요 미세 뇌의 동기화와 비동기는 완전히 다른 용어죠
- HTTP 요청이나 JSON을 교환하는 요청이 될 필요가 없어요 형식이 무엇이든 간에 직접 요청입니다 서비스 A에서 2 서비스 B로 정보를 가져오기 위한 직접 요청이죠
- 다음의 큰 문제는 enter service request가 실패하면 전체적인 요청도 실패한다는 서비스 실패에 관해 얘기한 것과 아주 흡사하죠
- 두 가지 일반적인 전략이 있습니다 동기나 동기 혹은 비동기와 비동기라고 하죠 바로 이해하시기 바랍니다 극세사 분야에서는 이런 용어들이 JavaScript 세계와는 다른 의미라는 것을요
