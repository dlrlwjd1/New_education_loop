# Quiz - Data in Microservices

## 개요
- 마이크로서비스의 데이터 소유권과 서비스 간 데이터 접근 원칙을 점검하는 퀴즈다.

## 내용
### 점검 범위
- 각 서비스가 자체 데이터베이스를 소유해야 하는 이유를 구분한다.
- 다른 서비스의 데이터가 필요할 때 동기 요청과 이벤트 기반 복제 중 어떤 방식을 선택할지 판단한다.
- 서비스 간 결합도와 데이터 일관성의 트레이드오프를 확인한다.

## 예시
퀴즈 답안은 기록하지 않았다. 먼저 직접 풀이한 뒤, 오답이 나온 개념을 앞뒤 강의 노트와 비교한다.

## 요약
- 데이터 소유권, 통신 방식, 결합도 사이의 관계를 스스로 설명할 수 있는지 확인한다.
