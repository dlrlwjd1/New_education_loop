# What Is a Microservice?

## 개요
- Monolithic 서버를 통해 사용자, 브라우저, 모바일 장치에서 온 요청이 우리 응용 프로그램으로 흘러들어와 사전 처리된 미들웨어를 거치는 거죠

## 내용
### 자막·본문 기반 핵심 내용
- Monolithic 서버를 통해 사용자, 브라우저, 모바일 장치에서 온 요청이 우리 응용 프로그램으로 흘러들어와 사전 처리된 미들웨어를 거치는 거죠
- 모놀리틱 서버에서 서버를 이런 식으로 빌드하겠죠 응용 프로그램을 구현하는 데 필요한 모든 코드가 하나의 코드 베이스 안에 있고 그 코드 베이스를 별개의 단위로 배포하죠
- 라우터로 갈 수도 있어요 그 라우터는 요청을 조사하고 특정 기능으로 보내기로 결정합니다 추가로 따라서 이 경우엔 A가 데이터베이스에서 데이터를 읽거나 쓰기로 결정해 응답을 구성하고 요청한 사람에게 응답을 보내는 거죠
- 일체형 서버의 특징을 설명하자면 다음과 같아요 이 문장으로 요약할 수 있겠네요 모노리스는 응용 프로그램의 모든 기능을 구현하기 위해 요구되는 모든 데이터베이스 액세스 코드의 모든 라우팅, 모든 미들웨어, 모든 비즈니스 로직을 포함한다고 할 수 있죠
