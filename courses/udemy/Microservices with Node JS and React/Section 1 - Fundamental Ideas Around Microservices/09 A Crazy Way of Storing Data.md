# A Crazy Way of Storing Data

## 개요
- 그걸 풀어야 해요 Get-Service A, B, C에게 사용자가 언제 상품을 등록하고 언제 주문을 할지 서비스 DX에게 알릴 방법을 생각해야 해요

## 내용
### 자막·본문 기반 핵심 내용
- 그걸 풀어야 해요 Get-Service A, B, C에게 사용자가 언제 상품을 등록하고 언제 주문을 할지 서비스 DX에게 알릴 방법을 생각해야 해요
- 데이터베이스를 도입할 수 있을 것 같아요 SQL이 아니거나 SQL 기반일 수도 있고요
- 동기화와 비동기화를 이용한 서로 다른 서비스 간의 통신 방법을 알아봤는데요 비동기 통신을 사용하는 두 번째 방법을 살펴보도록 하죠
- 저희가 살펴볼 두 번째 방법은 서비스 패턴을 위한 데이터베이스와 좀 비슷한데 이런 건 좀 이상하고 비효율적으로 보이겠죠
