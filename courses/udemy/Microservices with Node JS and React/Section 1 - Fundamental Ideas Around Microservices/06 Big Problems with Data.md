## 내용
### 자막·본문 기반 핵심 내용
- 데이터베이스에 우리 앱에 등록한 모든 사용자를 기록할 거예요 Service B는 Products고 서비스 C는 아래쪽에 제품을 구매하는 역할을 합니다
- 이건 획일적인 스타일이에요 Monolithic 서버가 있는데 사용 가능한 제품을 등록하고 구매하는 코드를 Monolithic 서버는 어딘가에 데이터를 저장해야 합니다 이런 다양한 기능 각각을 서비스할 데이터베이스를 생성하는 거죠
- 지난 비디오에서 우리가 만든 서비스 당 하나의 데이터베이스를 갖는 이유에 대해 얘기했죠
- 이 비디오에서 조금 전에 다뤘던 내용에 대해 다시 이야기해 보겠습니다. 서비스 간의 데이터 관리는 정말 어렵다고 했었죠.
