# Pros and Cons of Async Communication

## 개요
- 여기 있는 건 AWS나 아마존의 API 반응입니다 그들이 판매하는 제품에 관한 모든 아마존에서 실제로 판매하는 상품을 이렇게 정의했어요

## 내용
### 자막·본문 기반 핵심 내용
- 여기 있는 건 AWS나 아마존의 API 반응입니다 그들이 판매하는 제품에 관한 모든 아마존에서 실제로 판매하는 상품을 이렇게 정의했어요
- 서비스 DX는 사실 다른 종속성이 없어요 또 다른 큰 이점은 Service DX가 아주 빠르다는 겁니다 우리가 살펴본 다른 두 방법에 비해서요
- 그 이유는 Service DX는 사용자가 주문한 모든 제품을 즉시 사용 가능한 데이터베이스에 갖고 있기 때문이죠
- 수납공간을 늘리는 것에 대한 걱정은 접어두죠 잠시 다른 얘길 하죠 지금 이 비디오를 녹화하는 동안 약간의 조사를 했어요 Azure, 제 SQL 또는 구글 클라우드를 이용해 1기가바이트의 저장소를 확보하기 위해서요 제 SQL 또는 AWS 마이 SQL도요
