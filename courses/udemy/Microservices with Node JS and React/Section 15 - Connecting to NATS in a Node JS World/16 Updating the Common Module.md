# Updating the Common Module

## 내용
### 자막·본문 기반 핵심 내용
- 티켓으로 돌아가서 NPM 실행과 NPM 업데이트를 볼게요 SG 티켓이 오고 있어요
- 그냥 술집이었어요 일반 모듈 내부를 살펴보죠 그냥 술집이었어요 npm이 실행되는 퍼브를 이용해서 빌드를 하고 버전을 커밋하고 빌드를 삭제하죠
- 지난 비디오에서 언급했듯이 Nets 테스트 프로젝트 내의 많은 코드를 일반 모듈에 병합할 거예요
- 그런 다음 공통점을 재구축해 게시하고 티켓 프로젝트를 업데이트합니다 내부의 스트리밍 서버를 사용하기 이 공통 디렉토리 안에 CRC가 있습니다 이벤트라는 새 폴더를 만들 거예요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `npm`
