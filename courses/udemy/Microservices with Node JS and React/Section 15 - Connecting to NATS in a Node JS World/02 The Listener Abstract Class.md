# The Listener Abstract Class

## 개요
- 아래쪽에 Listener라는 추상 클래스를 생성할게요 모든 속성을 검토해 하나하나 추가할 겁니다 각각에 대한 구현과 우선 의뢰인 문제부터 해결하죠

## 내용
### 자막·본문 기반 핵심 내용
- 아래쪽에 Listener라는 추상 클래스를 생성할게요 모든 속성을 검토해 하나하나 추가할 겁니다 각각에 대한 구현과 우선 의뢰인 문제부터 해결하죠
- UTF8을 스트링하기 위해 JSON PARSE 데이터를 할 거예요 버퍼를 분석하고 JSON을 얻는 방법이죠
- 이 비디오에서는 클래스 리스너를 테스트 프로젝트에 구현해 볼게요 마지막 비디오와 이것 사이에 Q의 또 다른 abstract 속성을 추가한 즉 Q그룹 이름에 대한 실제 값을 정의해야 합니다 리스너의 하위 클래스 리스너 파일 내부의 편집기로 돌아가보죠
- abstract라고 하죠 이게 데이터를 받아들인다고 가정할 거예요 지금은 어떤 형식의 것이든 가능하죠

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `Listener`, `JSON`
