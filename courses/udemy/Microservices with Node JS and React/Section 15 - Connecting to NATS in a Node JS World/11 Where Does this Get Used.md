# Where Does this Get Used?

## 개요
- 이 시점에서는요 작은 테스트 프로젝트 안에 여러 개의 다른 파일이 있어요 여러 번 말씀드린 것처럼 결국엔 이 테스트 프로젝트에서 코드를 꺼내 일반 모듈로 병합할 거예요

## 내용
### 자막·본문 기반 핵심 내용
- 이 시점에서는요 작은 테스트 프로젝트 안에 여러 개의 다른 파일이 있어요 여러 번 말씀드린 것처럼 결국엔 이 테스트 프로젝트에서 코드를 꺼내 일반 모듈로 병합할 거예요
- 하지만 공통 모듈에 어떤 코드가 들어갈지 어떤 코드가 우리 서비스 안에서 최종적으로 작성될지 궁금하실 수도 있어요 티켓 서비스 같은 거요
- 그 질문에 답하기 위해 다이어그램을 살펴보죠 공통 모듈 안에서 주제 목록을 정의할 거예요
- 이건 이벤트를 방출할 수 있는 가능한 모든 채널이에요 우리 넷 스트리밍 서버 안에서요

### 구현 요소
- 강의 흐름에 따라 Where Does this Get Used?의 구현 목적과 적용 지점을 확인한다.
