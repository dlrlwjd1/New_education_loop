# Reusable NATS Listeners

## 개요
- 지금 보시는 것처럼 데이터를 추출해서 그 데이터가 문자열인지 버퍼인지 알아내고 그 데이터를 문자열이나 JSON의 실제 객체로 아주 의도적으로 지금 이 속성들을 아주 빨리 훑어보고 있는데요 왜냐하면 코드를 좀 쓰기 시작하면 훨씬 더 잘 이해될 테니까요
