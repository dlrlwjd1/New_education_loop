# Leveraging TypeScript for Listener Validation

## 개요
- 정말 멋진 건 이 티켓이 생성된 리스너를 합치는 거죠 TypeScript에게 Ticket Colon 생성을 주어로 지정하라고 할 방법이 있다면요 여기 이 데이터 속성을 지정했으니 문자열 타이틀 형식 ID가 되겠죠

## 내용
### 자막·본문 기반 핵심 내용
- 정말 멋진 건 이 티켓이 생성된 리스너를 합치는 거죠 TypeScript에게 Ticket Colon 생성을 주어로 지정하라고 할 방법이 있다면요 여기 이 데이터 속성을 지정했으니 문자열 타이틀 형식 ID가 되겠죠
- 여기에 뭔가를 쓰고 싶어요 티켓 같은 거요 그걸 작성함으로써 TypeScript가 유효성을 검사하고 올바른 유형의 데이터를 바로 여기서 on message의 첫 번째 인수로 받도록 해야죠
- 이 시점에서 TypeScript 같은 걸 사용할 방법을 찾아야 해요 우리가 여기서 쓰는 주제와 그 메시지 안에서 받는 데이터가 어느 정도 일치하도록요
- 도표 몇 개를 보여드릴 테니 TypeScript를 이용해 코드를 작성하는 방법을 이해하시면 메시지로 들어오는 주제와 데이터의 유효 유형을 확보할 수 있을 여기서 가장 먼저 아셔야 할 것은 애플리케이션 내의 모든 다른 주제에 대해서 아주 강력하게 형식화된 이벤트 데이터의 단일 구조가 있다는 점이에요
