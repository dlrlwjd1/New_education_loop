# Enforcing Data Types

## 개요
- 간단히 말해 티켓 생성 이벤트를 데이터에서 이렇게 대체하는 거죠 TypeScript를 시행할 거예요 아니, get TypeScript가 속성을 확인하도록요

## 내용
### 자막·본문 기반 핵심 내용
- 간단히 말해 티켓 생성 이벤트를 데이터에서 이렇게 대체하는 거죠 TypeScript를 시행할 거예요 아니, get TypeScript가 속성을 확인하도록요
- 따라서 TypeScript가 우리한테 불평하도록 해야죠 이름이 존재하지 않고 비용도 존재하지 그러기 위해서 여기 있는 데이터 유형을 바꿀 거예요
- 보다시피 멋진 자동 완성 타이틀이 생겼죠 우리가 존재하지 않는 속성에 액세스하려 하면 TypeScript가 소리칠 거예요 우리가 원하는 게 그거죠
- TypeScript는 이 티켓 생성된 이벤트 인터페이스의 데이터 부분을 보죠 온 메시지까지 첫 번째 인수를 해당 인터페이스 데이터 또는 데이터 부분으로 받도록 할 거예요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `TypeScript`
