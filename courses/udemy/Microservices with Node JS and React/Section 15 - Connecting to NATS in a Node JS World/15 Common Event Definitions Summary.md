# Common Event Definitions Summary

## 개요
- TypeScript 코드를 작성하고 이런 이벤트 정의들을 TypeScript 모듈 안에 넣을 거예요

## 내용
### 자막·본문 기반 핵심 내용
- TypeScript 코드를 작성하고 이런 이벤트 정의들을 TypeScript 모듈 안에 넣을 거예요
- 전부 TypeScript예요 몇 가지 방법이 있어요 모든 이벤트에 대한 공동의 정의를 원한다면 그 안의 정보를 원하고 일종의 다중글롯 아키텍처 안에서 그걸 공유하고 싶다면 JSON 스키마 같은 다른 대안도 살펴볼 수 있어요
- 일반 리포지토리 안에서 JSON 스키마를 작성할 수 있어요 GitHub 리포터 같은 거요
- 따라서 다중 언어 서비스를 여러분 응용 프로그램 안에 넣고 싶다면 TypeScript로 일반적인 모듈을 하고 이벤트 정의를 입력하는 대신 이런 접근법을 참고로 말씀드리자면 원래는 JSON 스키마를 이용해 이 응용 프로그램을 디자인하려 했어요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `TypeScript`, `JSON`, `GitHub`

## 예시
`TypeScript`, `JSON`, `GitHub`가 등장하는 설정·코드 위치를 찾아 강의와 같은 순서로 확인한다.
