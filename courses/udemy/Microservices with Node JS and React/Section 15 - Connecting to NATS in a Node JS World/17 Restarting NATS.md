# Restarting NATS

## 개요
- 지금 터미널로 돌아가서 Get 포드 작업을 해보면 보다시피 NAT 배포 또는 NAT 포드 실행 중이죠

## 내용
### 자막·본문 기반 핵심 내용
- 지금 터미널로 돌아가서 Get 포드 작업을 해보면 보다시피 NAT 배포 또는 NAT 포드 실행 중이죠
- 많은 테스트 코드를 실행해왔고 NAT 배포로 다량의 이벤트를 방출해왔습니다 아마 그 안에 많은 쓰레기 데이터가 있을 거예요
- 티켓 서비스에 대한 작업을 곧 다시 시작할 거예요 하지만 그 전에 알려드릴 게 있어요
- 이 NAT 포드를 재시작하는 게 이치에 맞을 수도 있어요 우리가 이미 방출한 이벤트가 전부 버려지게 하는 거죠

### 구현 요소
- 강의 흐름에 따라 Restarting NATS의 구현 목적과 적용 지점을 확인한다.
