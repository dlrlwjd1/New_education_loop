# Awaiting Event Publication

## 개요
- 실제로 뭔가를 작업하도록요 이걸 구현하려면 기본 게시자로 돌아갈게요 기본 문화 클래스 안에서 폴란드 기능을 찾을 거예요 async await 구문을 우리가 할 일은 promise를 리턴하는 겁니다 이 게시된 함수에서 수동으로 만들기로 한 것을요

## 내용
### 자막·본문 기반 핵심 내용
- 실제로 뭔가를 작업하도록요 이걸 구현하려면 기본 게시자로 돌아갈게요 기본 문화 클래스 안에서 폴란드 기능을 찾을 거예요 async await 구문을 우리가 할 일은 promise를 리턴하는 겁니다 이 게시된 함수에서 수동으로 만들기로 한 것을요
- 혼자서 promise를 만들어 본 적이 없다면 이게 그 방법이에요 promise에 함수를 전달할 거예요
- 오류가 있으면 일찍 리턴하고 방금 발생한 오류로 이 promise를 거부하는 그렇지 않다면 일반 콘솔 로그를 하는 대신 promise를 해결하죠
- 게시를 마우스로 가리키면 여기 annotation 형식이 promise인 게 보이시죠

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `async`, `await`, `promise`
