# Enforcing Listener Subjects

## 개요
- 그걸 삭제하면 다시 오류가 날 거예요 그 이유는 TypeScript가 우리가 주제의 값을 바꿀지도 모른다고 생각하기 본질적으로 TypeScript는 우리가 이런 걸 할까 봐 두려워하죠

## 내용
### 자막·본문 기반 핵심 내용
- 그걸 삭제하면 다시 오류가 날 거예요 그 이유는 TypeScript가 우리가 주제의 값을 바꿀지도 모른다고 생각하기 본질적으로 TypeScript는 우리가 이런 걸 할까 봐 두려워하죠
- 티켓 생성과 정확히 동일하도록 해야 해요 JavaScript가 아니라 일반 JavaScript에서 오셨다면 마지막 키워드를 사용하기에 좋은 장소가 되겠죠
- 구문은 좀 이상하겠지만 일단 전부 작동하는 걸 보면 이해가 우리의 목표는 어떻게든 TypeScript가 이해하게 하는 거죠 여기 나열된 주제가 우리가 제공하는 데이터 유형과 일치하도록요
- 클래스 정의 내에서 어디서든 T 형식을 참조할 수 있어요 페어링을 설정하고 TypeScript가 이해하도록 해야 해요 실제 수신기 내의 대상과 데이터 사이가 일치해야 하니까요
