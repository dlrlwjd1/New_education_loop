# Custom Publisher

## 개요
- 이 모든 것의 목표는 TypeScript가 우리 코드를 확인하게 해서 우리가 어떤 종류의 이벤트나 데이터를 내보내려고 할 때마다 올바른 구조, 올바른 속성 올바른 형식을 갖추게 하는 거죠 실제로 데이터를 게시할 때마다 이 안에 유효한 주제 그게 저희가 TypeScript를 구해 도움을 받으려는 모든 것의 목표죠 이 시점에서 이런 바보 같은 오타를 내지 않도록요

## 내용
### 자막·본문 기반 핵심 내용
- 이 모든 것의 목표는 TypeScript가 우리 코드를 확인하게 해서 우리가 어떤 종류의 이벤트나 데이터를 내보내려고 할 때마다 올바른 구조, 올바른 속성 올바른 형식을 갖추게 하는 거죠 실제로 데이터를 게시할 때마다 이 안에 유효한 주제 그게 저희가 TypeScript를 구해 도움을 받으려는 모든 것의 목표죠 이 시점에서 이런 바보 같은 오타를 내지 않도록요
- 이벤트 디렉터리 안에 티켓 관련 공개자 TS라는 새 파일을 만들게요 맨 위에 게시자를 불러올 거예요
- 간단히 말해서 코드를 작성할 건데 기본 수신자 클래스와 abstract 클래스가 될 거예요
- 발행인 파일에 들어왔어요 이 안에서 데이터 조각을 생성해 넷 서버에 게시하죠 이 게시된 코드를 보시면 확실히 지금 작동하네요
