# Custom Event Interface

## 개요
- 마지막으로 TypeScript에게 검증하는 법을 가르치고 여기 이것처럼 사용자 지정 수신기를 둘 때 TypeScript가 이해하도록 해야 해요 이 주제가 여기 있는 데이터 인수의 타입과 매치되도록요

## 내용
### 자막·본문 기반 핵심 내용
- 마지막으로 TypeScript에게 검증하는 법을 가르치고 여기 이것처럼 사용자 지정 수신기를 둘 때 TypeScript가 이해하도록 해야 해요 이 주제가 여기 있는 데이터 인수의 타입과 매치되도록요
- 응용 프로그램 안에 있을 거라 기대하는 모든 다양한 이벤트엔 다양한 인터페이스를 TypeScript가 개입해 우리가 만든 사용자 지정 리스너 중 하나에 일치하는 주제와 데이터가 있도록 하죠
- 피실험자의 게놈을 완성했으니 이제 인터페이스를 만들어서 이 피실험자와 그 피실험자가 접하게 될 이벤트 데이터를 고유하게 연결할 다시 에디터로 돌아가서 이벤트 디렉터리에서 티켓 생성 이벤트라는 새 파일을 만들게요
- 방금 생성한 열거를 불러오죠 실험 대상이군요 그런 다음 내보내기와 인터페이스를 만들어 티켓 생성 이벤트라고 부를 거예요
