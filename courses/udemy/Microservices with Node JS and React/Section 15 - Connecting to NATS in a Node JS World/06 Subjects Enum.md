## 내용
### 자막·본문 기반 핵심 내용
- 이벤트 디렉터리 안에 Simple Subjects라는 새 파일을 만들게요 각다귀 세계의 주제는 채널 이름이라는 걸 기억하세요
- 이렇게 생각해 보세요 이벤트 이름이나 그와 비슷한 걸로요 이 피사체의 파일 안에 Subjects라는 열원을 내보낼 거예요
- 이 비디오에선 여러 조각의 코드를 추가해 TypeScript가 리스너를 만들 때마다 온메시지 기능 내에 일치하는 주제와 데이터 유형 인수가 제공된다는 걸 확인하도록 하죠
- 이벤트 디렉터리에서 가장 먼저 할 것은 새 파일을 생성하는 거예요 그 안에 뭔가를 함께 놓습니다 우리가 받게 될 거라고 기대하는 모든 다양한 유효한 대상 이름을 나열하는 거죠
