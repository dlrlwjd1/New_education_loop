# Quick Refactor

## 개요
- 그 안에 베이스 리스너 TS라는 새 파일을 만들어요 리스너 클래스에서는 기본 리스너의 이름을 사용하지 않지만 프로젝트에 리스너라는 파일이 이미 있으니까요

## 내용
### 자막·본문 기반 핵심 내용
- 그 안에 베이스 리스너 TS라는 새 파일을 만들어요 리스너 클래스에서는 기본 리스너의 이름을 사용하지 않지만 프로젝트에 리스너라는 파일이 이미 있으니까요
- 새로운 티켓 리스너 주문 제작이 리스너의 기본 클래스와 함께 이루어졌어요 이 시점에서 빨리 확인하고 싶은 게 있어요
- 리스너의 기본 클래스와 티켓 생성 리스너가 있죠 공용 모듈에서 리스너 클래스를 정의할 건데요
- 이걸 나중에 생성하게 될 다양한 서비스에 불러오죠 우리 서비스 각각에 서브클래스 리스너가 있어요 사용자 지정 리스너를 만들어 특히 결제 서비스나 티켓 서비스나 우리가 만드는 어떤 서비스에든 사용할 수 있죠

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `TS`

## 예시
`TS`가 등장하는 설정·코드 위치를 찾아 강의와 같은 순서로 확인한다.
