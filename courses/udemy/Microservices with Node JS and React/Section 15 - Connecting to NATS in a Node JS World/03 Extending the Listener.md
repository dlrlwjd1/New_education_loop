## 개요
- abstract 클래스를 사용하는 건 정말 좋아요 TypeScript가 코드 일부를 구현하도록 도와주거든요

## 내용
### 자막·본문 기반 핵심 내용
- abstract 클래스를 사용하는 건 정말 좋아요 TypeScript가 코드 일부를 구현하도록 도와주거든요
- 귀가 좀 필요해요 TypeScript는 리스너를 연장하려면 메시지 큐, 그룹, 이름과 주제를 정의해야 한다고 말해요

- 다시 안쪽입니다 편집자가 맨 밑에 있어요 클래스를 정의해보죠 티켓 생성 리스너 이걸 쓰면 리스너 abstract 클래스가 확장되죠
