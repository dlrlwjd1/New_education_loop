# Emitting the Order Cancelled Event

## 개요
- 제 ID를 넣을게요. ORDERID에서 오는 ID요. 더 오래된 버전을 넣을게요 티켓이 될 거예요

## 내용
### 자막·본문 기반 핵심 내용
- 제 ID를 넣을게요. ORDERID에서 오는 ID요. 더 오래된 버전을 넣을게요 티켓이 될 거예요
- 지난 비디오 마지막에 이 주문의 티켓 속성을 비우거나 재설정하는 게 말이 되는지 여부였죠
- 이게 관련 있는 질문인 이유는 티켓이 예약되었는지 안 되었는지를 트래킹한다는 걸 기억하세요 티켓을 참조하는 주문이 있는지 살펴봐야 하니까요
- 주문서비스 안에서 티켓이 현재 예약된 상태인지 아닌지를 결정하는 모델 디렉터리 안에 티켓 파일에 적어뒀던 게 기억나실 거예요

### 구현 요소
- 강의 흐름에 따라 Emitting the Order Cancelled Event의 구현 목적과 적용 지점을 확인한다.

## 예시
주문서비스 안에서 티켓이 현재 예약된 상태인지 아닌지를 결정하는 모델 디렉터리 안에 티켓 파일에 적어뒀던 게 기억나실 거예요
