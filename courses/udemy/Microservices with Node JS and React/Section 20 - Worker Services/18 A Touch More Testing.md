# A Touch More Testing

## 개요
- TypeScript가 이해하도록 돕기 위해 .Mock이라고 적으면 돼요 typecript는 이게 모의 함수라는 걸 이해하죠 불평을 많이 하지 않고 적절한 속성들에 대한 엑세스 권한을 우리에게 줘요

## 내용
### 자막·본문 기반 핵심 내용
- TypeScript가 이해하도록 돕기 위해 .Mock이라고 적으면 돼요 typecript는 이게 모의 함수라는 걸 이해하죠 불평을 많이 하지 않고 적절한 속성들에 대한 엑세스 권한을 우리에게 줘요
- JSON으로 전체 데이터 개체를 돌려주죠 그걸 실제 개체로 바꿔야 해요 그런 다음 ID 속성을 끌어낼 수 있죠
- JSON 파싱을 할게요 괄호 세트로 전체를 감싸요 어바웃 이벤트 데이터에 이걸 서명하죠
- 함수 설정 완료했어요 검사지를 작성하죠 테스트는 본질적으로 꽤 간단할 거예요 메시지를 전달할 수 있어야 해요
