## 내용
### 자막·본문 기반 핵심 내용
- 그러려면 JavaScript 날짜 객체에 대한 약간의 지식이 필요해요 Add 문 바로 위에서 fonts 딜레이를 추가할 거예요
- 이 예상한 대로예요 밀리세컨드를 입력할 거예요 이 안에 어떤 밀리세컨드 값을 넣든 추가적인 지연이 생기게 됩니다 Redis로부터 이 작업을 받아오기 전까지요 이 프로세스 문에서 처리되고요
- 이런 값들이 무엇인지에 대한 콘솔 로그가 있어요 먼저 코드를 좀 더 작성하고 new date. get time에서 빼도록 하죠
- ADD 함수의 두 번째 인수로 시작하려면 이 안에 옵션 개체를 넣을 거예요 DeLay라는 속성을 제공할 거예요
