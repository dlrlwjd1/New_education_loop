# Testing Job Processing

## 개요
- HTTPS: 개발자 API 주문 티켓팅이요 콘텐츠 안에서요 애플리케이션/JSON 타입이죠

## 내용
### 자막·본문 기반 핵심 내용
- HTTPS: 개발자 API 주문 티켓팅이요 콘텐츠 안에서요 애플리케이션/JSON 타입이죠
- 우리가 로그인했는지 확인해야 해요 지금 로그인한 것 같네요 API 사용자의 현재 사용자에 대한 Get request죠
- 여기 JSON 개체를 티켓 ID로 입력할게요 그런 다음 방금 만든 티켓의 ID를 JSON에 들어가는 걸 기억하세요
- 인격체로 서명하는 거 잊지 마세요 그런 다음 새 티켓을 만드는 거죠 타이틀과 가격이 있는 API 티켓과는 반대죠

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `API`, `request`, `HTTPS`, `JSON`
