# Testing the Expiration Complete Listener

## 개요
- 엄청난 가격이죠 ID도 제공해야 한다는 걸 기억하세요 하드코딩된 ID를 줄 거예요 Mongoose에서 생성되는 거죠

## 내용
### 자막·본문 기반 핵심 내용
- 엄청난 가격이죠 ID도 제공해야 한다는 걸 기억하세요 하드코딩된 ID를 줄 거예요 Mongoose에서 생성되는 거죠
- TypeScript에 말할 거예요 변수가 너무 많아요 티켓을 돌려받으려면 꼭 필요한 건 아니지만 어쨌든 돌려받아야 해요
- 청취자 테스트요 이 리스너 테스트 파일은 우리가 리스너를 위해 만든 다른 모든 테스트 파일과 맨 위엔 수신기 Nets 래퍼를 위해 몇 가지 가져오기를 추가할게요
- 인스턴스를 만들어보죠 새로운 탐험이자 완전한 청취자가 될 거예요 거기에 Nets 클라이언트를 제공해야 하죠
