# A Touch of Kubernetes Setup

## 개요
- 정말 멋진 용어들이네요 이제 코드를 작성해보죠 다시 제 터미널로 돌아가 탐사에서 먼저 Docker 이미지와 Docker 빌드를 Docker ID/ 만료와 함께 그걸 태그할 거예요

## 내용
### 자막·본문 기반 핵심 내용
- 정말 멋진 용어들이네요 이제 코드를 작성해보죠 다시 제 터미널로 돌아가 탐사에서 먼저 Docker 이미지와 Docker 빌드를 Docker ID/ 만료와 함께 그걸 태그할 거예요
- 그게 다 끝나면 Docker push를 하죠 Docker ID 만료요 미는 데 1, 2분 걸려요
- K8s 안에서 만료 대시의 새 파일을 만들 거예요 redis 대시, 더블 HTML 그런 다음 다양한 MongoDB 배포 파일로 갈게요
- 만료된 배포 파일 안에 Redis 호스트라는 환경 변수에 대한 만료일을 Redis SRB라고 입력하죠

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `Docker`, `Redis`, `MongoDB`, `JSON`, `Docker Hub`, `Docker ID/`, `Docker push`, `Docker ID`
