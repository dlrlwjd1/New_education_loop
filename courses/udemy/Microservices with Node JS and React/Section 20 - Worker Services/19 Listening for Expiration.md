# Listening for Expiration

## 개요
- 여기 다른 탭으로 갈게요 API/Order에 게시 요청이요 티켓 ID를 붙여넣을 거예요

## 내용
### 자막·본문 기반 핵심 내용
- 여기 다른 탭으로 갈게요 API/Order에 게시 요청이요 티켓 ID를 붙여넣을 거예요
- 하지만 해야 할 일이 하나 더 있어요 CRC directies indexed 파일의 내부가 기억나실지도 모르겠네요. 서로 다른 모든 청취자들에게 입력하고 수신기의 새로운 인스턴스를 만들어 수신 이벤트를 들으라고 만료되는 완전한 리스너에도 같은 작업을 해야 하죠
- API 티켓을 게시할 거예요 티켓 ID를 얻을 수 있고 새 주문을 생성할 수 있습니다. 그러면 주문 만료나 취소된 이벤트가 공개되는 것을 볼 수 있겠죠.
- 만료 청취기에 관한 테스트를 좀 했는데 전 꽤 자신 있어요 예상대로 작동하는 것 같거든요
