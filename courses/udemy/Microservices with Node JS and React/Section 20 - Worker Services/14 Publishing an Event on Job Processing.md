# Publishing an Event on Job Processing

## 개요
- 주문 서비스로 돌아가면 SC Events Publchers 디렉터리를 찾을 수 있습니다 그리고 그 안에서 주문 생성된 공개자를 살펴볼 수 있죠

## 내용
### 자막·본문 기반 핵심 내용
- 주문 서비스로 돌아가면 SC Events Publchers 디렉터리를 찾을 수 있습니다 그리고 그 안에서 주문 생성된 공개자를 살펴볼 수 있죠
- 주문 ID에는 job data를 넣고요. 주문한 신분증요 자연스럽게 이걸 테스트해보죠 Postman을 이용해 수동으로 티켓을 생성하고 주문을 생성하고 1분을 기다릴 수도 있어요 최종적으로 만료 완료 이벤트가 게시되는 걸 보기 위해서요 그 대신 모든 걸 아주 빨리 하기 위해 주문 생성 리스너로 돌아가죠
- 매번 일시정지하는 겁니다 이름을 정확히 입력해야 하니까요 늘 그렇듯 TypeScript는 이걸 확장하려면 주체를 정의해야 한다고 하죠
