# Initial Setup

- 티켓 디렉터리에서 Docker를 다중 선택하겠습니다 Docker 파일 패키지 JSON은 무시하고요 구성 JSON 파일도요

## 내용
### 자막·본문 기반 핵심 내용
- 티켓 디렉터리에서 Docker를 다중 선택하겠습니다 Docker 파일 패키지 JSON은 무시하고요 구성 JSON 파일도요
- Mongoose Kinect 문과 MongoDB와 연결된 콘솔 로그를 삭제할게요 마지막으로 앱을 삭제할 거예요
- 그런 다음 일반 NPM 설치를 실행해 패키지 JSON 파일 안에 있는 모든 게 추가되는지 확인해야 해요
- 두 청취자를 위해 수입 기록을 삭제할게요 이 2/1 환경 변수들을 확인할게요 JSON Web 토큰 키나 mongo URI는 필요 없죠 다음 3개 정도는 남겨둘게요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `Docker`, `JSON`, `HTTP`, `MongoDB`, `NPM`, `Mongoose`, `TypeScript`, `Redis`
