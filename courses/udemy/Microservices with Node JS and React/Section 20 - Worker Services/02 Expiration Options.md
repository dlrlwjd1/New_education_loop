# Expiration Options

## 개요
- 즉 주문을 생성하고 타이머를 할당하는 것에서 주문 서비스로 돌아가서 경로와 new TS를 볼게요.

## 내용
### 자막·본문 기반 핵심 내용
- 즉 주문을 생성하고 타이머를 할당하는 것에서 주문 서비스로 돌아가서 경로와 new TS를 볼게요.
- 이 이벤트가 발생할 때마다 set time out 같은 걸 사용하면 됩니다 set time out 함수를 쓸 수 있게요
- 탐색 서비스의 내부에 불 JS라는 라이브러리를 이용할 거예요 이건 JavaScript 라이브러리로 본질적으로 장기간 시간을 설정하거나 스스로 알림을 줄 수 있게 해주죠
- 따라서 서비스 탐색에서 저희가 할 건 이 라이브러리에 관해 좀 더 배우는 겁니다 쿠버네테스 클러스터 내부에 Redis를 설정하는 방법도요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `TS`, `JavaScript`, `Redis`
