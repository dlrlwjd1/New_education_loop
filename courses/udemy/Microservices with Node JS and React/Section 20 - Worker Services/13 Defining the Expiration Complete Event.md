# Defining the Expiration Complete Event

## 개요
- 1분 정도 지났는데 콘솔이 보이네요 만료 완료 이벤트를 게시하고 싶다고 여기 로그인하세요

## 내용
### 자막·본문 기반 핵심 내용
- 1분 정도 지났는데 콘솔이 보이네요 만료 완료 이벤트를 게시하고 싶다고 여기 로그인하세요
- 아주 좋아 보여요 이벤트를 받는 전체 메커니즘이 생겼죠 작업을 게시하고, 작업을 수신하고 처리하는 메커니즘이요 잠재적으로는 아직 없지만 만료되는 형식의 이벤트를 게시하도록 이 비디오에서 그걸 연습할 거예요
- 먼저 공통 모듈에 만료된 완전한 유형 이벤트에 대한 정의가 있는지 확인해야 화면을 잘못 눌렀네요
- 일반 모듈로 돌아가 볼게요 새 이벤트를 어떻게 만드는지 기억하세요 이벤트 디렉터리를 찾고 이 안에서 이 이벤트 파일 중 하나를 새것으로 만들 모든 이벤트 파일은 우리가 만들려는 이벤트 다음에 이름 붙인 단일 인터페이스를 내보낼 거예요

### 구현 요소
- 강의 흐름에 따라 Defining the Expiration Complete Event의 구현 목적과 적용 지점을 확인한다.
