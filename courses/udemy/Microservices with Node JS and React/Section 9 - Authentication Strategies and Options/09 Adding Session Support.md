# Adding Session Support

## 개요
- HTTPS 연결은 신뢰하지 않아요 간단히 말해 여기 이 작은 단계를 추가하고 있어요 Express가 Ingress 엔진 X의 프록시 뒤에 있다는 걸 인식하도록요 여전히 트래픽이 안전하다고 신뢰하도록 하는 거죠

## 내용
### 자막·본문 기반 핵심 내용
- HTTPS 연결은 신뢰하지 않아요 간단히 말해 여기 이 작은 단계를 추가하고 있어요 Express가 Ingress 엔진 X의 프록시 뒤에 있다는 걸 인식하도록요 여전히 트래픽이 안전하다고 신뢰하도록 하는 거죠
- Express는 물건이 프록시라는 사실을 확인합니다 기본값으로 Express는 말합니다 잠깐, 여기 프록시가 있네요
- 기본값으로 쿠키 세션은 네이티브 typecript 지원이 없어요 TypeScript가 이 라이브러리 안에서 무슨 일이 벌어지는지 이해하도록 형식 정의 파일을 타입/쿠키 대시 세션에도 설치할 거예요
- 그런 다음 NPM 설치 쿠키 세션을 하죠 쿠키 세션 라이브러리만 설치하는 게 아니에요

### 구현 요소
