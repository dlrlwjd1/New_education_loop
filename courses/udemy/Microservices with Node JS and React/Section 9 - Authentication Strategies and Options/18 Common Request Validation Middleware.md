# Common Request Validation Middleware

## 개요
- 이 위쪽에 수입 기기를 몇 개 넣을 거예요 요청 응답을 불러오죠 Express의 다음 함수죠

## 내용
### 자막·본문 기반 핵심 내용
- 이 위쪽에 수입 기기를 몇 개 넣을 거예요 요청 응답을 불러오죠 Express의 다음 함수죠
- 이건 타입이란 걸 기억하세요 이걸 불러오는 유일한 이유는 TypeScript를 위한 형식 주석을 제공하기 위해서죠
- 요청과 응답을 불러오고 다음 기능은 미들웨어로 들어올 인수의 형식을 설명하죠 그런 다음 Express에서 유효성 검사 결과를 가져오죠
- 이 비디오에서는 유효성 검사를 할 건데요, 여기에서 헬퍼 미들웨어에서 추출하세요.

### 구현 요소
