# JWT Signing Keys

## 개요
- JSON Web 토큰만 가져갈게요 복사해서 JWT라는 다른 웹사이트로 갈게요 JSON 웹 토큰에 대한 인식을 높이기 위한 웹사이트예요

## 내용
### 자막·본문 기반 핵심 내용
- JSON Web 토큰만 가져갈게요 복사해서 JWT라는 다른 웹사이트로 갈게요 JSON 웹 토큰에 대한 인식을 높이기 위한 웹사이트예요
- 이 줄 전체를 붙여넣을게요 디코딩 누를게요 JSON 개체가 저기 있네요 JWT 속성이 있는 게 보이시죠 저 문자열 안에는 JSON 웹 그 스트링도 좀 바꿔보죠
- JWT, IO에서 스크롤을 내리면 작은 도구가 있는데 JSON Web 토큰을 제대로 인코딩됐는지 볼 수 있어요 내부 정보도 보이고요
- 서명 키를 JSON 웹 토큰 라이브러리로 던졌더니 실제 JSON 웹 토큰이 다른 서비스 내에서 JSON Web 토큰을 받을 때마다 유효한 토큰인지 확인해야 합니다 그래야 이 사용자가 로그인했는지 알 수 있죠

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `JSON`, `JWT`

## 예시
`JSON`, `JWT`가 등장하는 설정·코드 위치를 찾아 강의와 같은 순서로 확인한다.
