## 내용
### 자막·본문 기반 핵심 내용
- 그리고 다시 내려와요 빈 공간이 아니면 throw new request Validation Air를 해요
- React Application이나 지금 포스트맨이 우리 응용 프로그램에 로그인하기 위해 요청을 할 거예요
- 두 암호가 같다면 아주 좋은 거죠 이 사용자가 로그인한 걸로 간주하죠 그 쿠키에 JSON Web 토큰을 보내게 됩니다 로그인할 때 했던 것과 같은 종류의 전략을 사용해서요
- 유효성 검사 결과는 이 위의 Express Validator library에서 나오는 함수에요.
