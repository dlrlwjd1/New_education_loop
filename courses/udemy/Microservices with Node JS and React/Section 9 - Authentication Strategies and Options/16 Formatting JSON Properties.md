# Formatting JSON Properties

## 개요
- JSON 문자열을 one에서 호출할 때마다요 전체 개체를 문자열로 호출하는 대신 JavaScript는 이 2개의 JSON 메서드를 호출할 거예요

## 내용
### 자막·본문 기반 핵심 내용
- JSON 문자열을 one에서 호출할 때마다요 전체 개체를 문자열로 호출하는 대신 JavaScript는 이 2개의 JSON 메서드를 호출할 거예요
- 이 안에 Person이라는 새 개체를 만들 거예요 이름은 알렉스로 하고요 JSON 문자열로 PHI를 만들어 직접 전달하면 JSON으로 바뀌죠
- 1을 반환할 거예요 그러니까 1은 사람 2의 JSON 대표가 되겠죠 JSON string of PHI person to를 할게요
- 이걸 다루기 위해 JavaScript가 어떻게 개체를 JSON 데이터로 바꾸는지 간략히 알려드리고 싶어요 제 말은 그렇게 중요하지 않을 수도 있지만 절 믿으세요, 아주 중요해요
