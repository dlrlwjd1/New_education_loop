# Microservices Auth Requirements

## 개요
- 여기서 어떤 메커니즘을 사용하기로 결정하든 JSON, Web 토큰이나 그 외의 것으로요 Express, Ruby, Java와 함께 쉽게 구현되어야만 해요

## 내용
### 자막·본문 기반 핵심 내용
- 여기서 어떤 메커니즘을 사용하기로 결정하든 JSON, Web 토큰이나 그 외의 것으로요 Express, Ruby, Java와 함께 쉽게 구현되어야만 해요
- 하지만 JSON 웹 토큰은 만료 시간을 암호화하죠 JSON 웹 토큰이 만료되면 그걸로 끝이에요
- 이 비디오에서는 JSON Web 토큰을 사용할지 쿠키를 사용할지 결정하도록 하죠 이건 선택의 문제가 아니에요
- Cookies와 JSON 웹 토큰은 아주 달라요 여기서 암시하는 건 보통 쿠키 기반 인증을 사용한다고 할 때 그 안에 인코딩된 토큰을 저장할 쿠키가 있다는 의미입니다 그리고 그건 어떤 식으로든 암호화될 겁니다

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `JSON`, `Express`
