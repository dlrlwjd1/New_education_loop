# Generating a JWT

## 개요
- JSON 웹 토큰 생성을 위해 사용자 지정 JWT는 JWT 기호예요 첫 번째 인수는 페이로드예요 JSON 웹 토큰 안에 저장할 그 페이로드에 필요한 건 그것뿐이에요

## 내용
### 자막·본문 기반 핵심 내용
- JSON 웹 토큰 생성을 위해 사용자 지정 JWT는 JWT 기호예요 첫 번째 인수는 페이로드예요 JSON 웹 토큰 안에 저장할 그 페이로드에 필요한 건 그것뿐이에요
- NPM에서 JSON Web 토큰을 검색할 거예요 비슷한 이름을 가진 라이브러리가 많으니 JSON Web 토큰을 대시 없이 한 단어만 넣도록 하세요
- 새 개체를 만들고 JWT 속성을 줍니다 그리고 사용자 JSON Web 토큰을 넣죠
- 레크리에이션을 할 거예요 .JWT는 사용자 JWT죠 아직도 공기가 좀 통해요 쿠키 세션을 위해 설치한 정의 파일 유형은 개체가 레코드 세션으로 존재한다고 추정하지 않아요
