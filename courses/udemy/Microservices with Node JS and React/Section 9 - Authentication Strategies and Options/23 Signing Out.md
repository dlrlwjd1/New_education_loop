# Signing Out

## 개요
- 게시 요청을 할 거예요 폴란드/슬래시 https에요 티켓팅도 하고요 개발 API 사용자요

## 내용
### 자막·본문 기반 핵심 내용
- 게시 요청을 할 거예요 폴란드/슬래시 https에요 티켓팅도 하고요 개발 API 사용자요
- post request handler에서 로그아웃할 때 사각형 세션이 null인 걸 추가하면 동으로 응답을 보낼 수 있죠
- JSON 웹 토큰을 제거할 거예요 그 말은 사용자가 다음 요청을 할 때마다 쿠키에 포함된 토큰이 없다는 사용자 쿠키 안의 모든 정보를 비우기 위해서요
- 콘텐츠를 높게 헤더를 설정하도록 할게요 애플리케이션/JSON이죠 그걸 전송할 거예요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `JSON`, `request`, `https`, `API`
