## 내용
### 자막·본문 기반 핵심 내용
- 응답을 보내는 건 인증 서비스의 몫이에요 제가 지금 쓰는 용어는 sync request인데 JavaScript 세계에선 아니고 극세사 장비 세계에선 그렇죠
- 먼저 고지 사항으로 시작하겠습니다 사용자 인증을 처리하는 거죠 사용자에게 쿠키나 JSON Web 토큰 같은 걸 주고 우리 앱 내의 다른 서비스에 엑세스할 수 있게 하는 건 해결되지 않은 까다로운 문제죠
- 드디어 가입 절차의 마지막 단계예요 로그인할 사용자를 고려하고 있어요 쿠키나 JSON 웹 토큰 같은 걸 생성해서 사용자에게 보내야 한다는 뜻이죠
- 이 문제를 처리하는 데 완벽한 해결책은 없다는 거죠 이런 전략은 없어요 쿠키나 JSON 웹 토큰을 써서 존재하지 않는 걸 작동시키라고요
