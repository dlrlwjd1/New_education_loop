# So Which Option?

## 개요
- 기본적인 옵션 1과 함께 이 두 가지를 요약해 봅시다. 모든 개별 서비스는 중앙 OTT 서비스에 의존할 것입니다. 외부 서비스 혹은 중앙 게이트웨이로서요.

## 내용
### 자막·본문 기반 핵심 내용
- 기본적인 옵션 1과 함께 이 두 가지를 요약해 봅시다. 모든 개별 서비스는 중앙 OTT 서비스에 의존할 것입니다. 외부 서비스 혹은 중앙 게이트웨이로서요.
- 기본 옵션을 살펴봤습니다 첫 번째, 두 번째 사용자가 응용 프로그램 안에서 인증됐는지 아닌지를 처리하는 거죠
- 여기 녹색으로 반영된 이 접근 방식의 장점은 우리가 인증 상태나 사용자의 액세스를 변경할 때마다 클러스터의 나머지 전체나 우리 서비스의 나머지 전체에서 즉시 반영된다는 거죠
- 사용이 금지된 사용자로 설정하면 다음 서비스가 와서 사용자의 상태를 묻거나 로그인 여부를 묻자마자 사용자가 금지됐으니 접근을 허용하지 말라고 이 접근 방식의 큰 단점은 서비스가 다운되면 전체 앱이 망가진다는 기본 2번은 기본 옵션과는 정반대의 개념이에요
