# Creating and Accessing Secrets

## 내용
### 자막·본문 기반 핵심 내용
- 이 경우 JSON 웹 토큰 키값 쌍을 할당합니다 JWT=SDF라고도 하죠 한 가지 더 알려드릴 게 있어요
- 이 다이어그램에서 JWT는 a예요 훌륭한 키값 쌍은 아닐 겁니다 JWT의 값이 SDF라는 걸 암시하니까요
- 여기서 더 나은 건 JWT나 SDF와 같은 거죠 좀 더 선명할 거예요 JWT_e = pdf라고 입력할게요
- 쿠베르네테스에는 여러 가지 비밀이 있어요 우리가 만들 수 있는 다른 비밀의 예는 Docker 이미지 리포지토리에 엑세스하는 것과 관련된 정보예요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `Docker`, `JSON`, `JWT`
