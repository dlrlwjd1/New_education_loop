# Reminder on Cookies vs JWT's

## 개요
- 인증 메커니즘은 JSON 웹 토큰이나 쿠키 같은 게 될 거예요 이 비디오에선 다음 두어 개에선 사용자의 인증을 증명하는 정확한 방법을 JSON Web 토큰을 사용하느냐는 거죠

## 내용
### 자막·본문 기반 핵심 내용
- 인증 메커니즘은 JSON 웹 토큰이나 쿠키 같은 게 될 거예요 이 비디오에선 다음 두어 개에선 사용자의 인증을 증명하는 정확한 방법을 JSON Web 토큰을 사용하느냐는 거죠
- 쿠키에 관해 기억해야 할 중요한 사항이에요 JSON Web 토큰으로 가요 기억하세요 JSON Web 토큰으로 우리가 페이로드라고 부르는 임의의 정보 조각을 취할 거예요
- 그런 다음 그 페이로드를 JSON 웹 토큰 생성 알고리즘에 넣을 거예요 그런 다음 JSON 웹 토큰을 뱉어내요 인코딩된 스트링처럼 생겼죠 여기 이 안에 원래의 페이로드가 있어요
- JSON 웹 토큰은 브라우저에 의해 자동으로 관리되고 모든 후속 요청에 포함되죠 이 비디오에서 복구하거나 리콜한 걸 요약하자면 쿠키와 JSON 웹 토큰의 쿠키는 이동 장치예요
