# Returning the Current User

## 개요
- 먼저 rect session JWT 속성을 살펴보는 것으로 시작할게요 REQ session JWT가 아니라면요

## 내용
### 자막·본문 기반 핵심 내용
- 먼저 rect session JWT 속성을 살펴보는 것으로 시작할게요 REQ session JWT가 아니라면요
- 첫 번째 인수는 토큰 자체로 req session JWT가 될 거예요 두 번째 인수는 JWT quay가 될 거예요 전에 환경 변수로 설정했죠
- 이메일, ID, 그리고 토큰을 발행한 날짜가 적혀 있네요 React Application의 컨텍스트에서 React Application에서 이런 반응을 받으면 사용자가 로그인했다고 추정할 거예요
- 상단의 현재 사용자 파일 안에서 한두 가지를 불러올 거예요 아마도 필요하게 위쪽에 JSON 웹 토큰에서 JWT를 위한 불러오기를 추가할게요
