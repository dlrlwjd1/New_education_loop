# Common Response Properties

## 개요
- 현재 저희는 MongoDB를 사용하고 있지만 나중에 같은 프로젝트에서 MySQL이나 Postgres를 사용하는 다른 서비스를 작업하게 될 수도 있어요

## 내용
### 자막·본문 기반 핵심 내용
- 현재 저희는 MongoDB를 사용하고 있지만 나중에 같은 프로젝트에서 MySQL이나 Postgres를 사용하는 다른 서비스를 작업하게 될 수도 있어요
- 새 계정을 등록할 수 있어요 그렇게 하면 JSON 웹 토큰을 되찾을 수 있죠 모든 게 아주 좋다는 뜻이에요
- 가령, 응답에 암호가 포함돼선 안 되죠 그 외에, 또 다른 플래그나 속성인 밑줄 V가 있는데 mongoose와 연결되어 있어요 이 내용은 나중에 코스 내에서 실제로 관련이 있어요
- MongoDB는 ID를 밑줄 ID로 기록하죠 우체부 직원의 반응을 보면 알 수 있죠

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `JSON`, `mongoose`, `MongoDB`

## 예시
`JSON`, `mongoose`, `MongoDB`가 등장하는 설정·코드 위치를 찾아 강의와 같은 순서로 확인한다.
