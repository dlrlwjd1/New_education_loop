# Listing Running Containers

## 개요
- 예상하시겠지만 Docker를 다시 실행하면 해당 컨테이너가 더는 안 보일 거예요 Docker PS는 실행 중인 컨테이너를 구체적으로 보여주죠

## 내용
### 자막·본문 기반 핵심 내용
- 예상하시겠지만 Docker를 다시 실행하면 해당 컨테이너가 더는 안 보일 거예요 Docker PS는 실행 중인 컨테이너를 구체적으로 보여주죠
- Docker PS 명령을 약간 수정할 수 있어요 우리 컴퓨터에서 만들어진 모든 컨테이너를 보여주기 그러자면 Docker를 실행할 수 있죠
- 이 섹션에선 아주 흔하게 사용되는 명령을 또 한 번 살펴보죠 우리가 살펴볼 명령은 Docker죠
- 지금 당장 실행해서 어떻게 되는지 보죠 제 터미널로 가서 Docker를 실행하죠 PS, 이 명령을 실행하면 테이블 헤더가 보일 거예요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `Docker`, `Docker PS`

## 예시
`Docker`, `Docker PS`가 등장하는 설정·코드 위치를 찾아 강의와 같은 순서로 확인한다.
