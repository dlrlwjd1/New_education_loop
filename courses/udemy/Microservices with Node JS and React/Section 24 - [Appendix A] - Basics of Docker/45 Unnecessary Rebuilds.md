# Unnecessary Rebuilds

## 개요
- Docker를 다시 실행해 명령을 빌드하고 다시 빌드해야 합니다 새로 바뀐 파일로 복사해 실행하고 NPM을 설치한 다음 서버를 시작하는 거죠

## 내용
### 자막·본문 기반 핵심 내용
- Docker를 다시 실행해 명령을 빌드하고 다시 빌드해야 합니다 새로 바뀐 파일로 복사해 실행하고 NPM을 설치한 다음 서버를 시작하는 거죠
- 제 컨테이너를 Docker Run으로 아주 빨리 시작할게요 포트 매핑을 다시 하죠 88, 88, 80 스티븐 그리더/심플 웹으로요
- 서버 실행을 시작하겠습니다 그런 다음 Docker 빌드를 하죠 태그를 달 거예요 그리고 DOT을 눌러서 빌드 컨텍스트를 명시하도록 할게요
- 한 명도 빠짐없이요 방금 수정을 했는데 인덱스 파일과 Docker가 감지됐습니다 파일 하나를 변경한 거죠

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `Docker`, `NPM`, `Docker Run`
