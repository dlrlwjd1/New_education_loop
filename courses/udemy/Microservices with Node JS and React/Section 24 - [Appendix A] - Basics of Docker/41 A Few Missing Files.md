# A Few Missing Files

## 개요
- 이 문서의 목적은 프로젝트를 성공적으로 실행하는 데 필요한 다양한 종속성을 모두 나열하는 따라서 npm install을 실행하면 npm이 이 파일을 찾으려고 시도합니다.

## 내용
### 자막·본문 기반 핵심 내용
- 이 문서의 목적은 프로젝트를 성공적으로 실행하는 데 필요한 다양한 종속성을 모두 나열하는 따라서 npm install을 실행하면 npm이 이 파일을 찾으려고 시도합니다.
- 그러나 NPM 자체에서 패키지라는 파일이 없다는 오류 메시지가 바로 여기에 표시되었습니다. json을 사용할 수 있습니다.
- 짐작할 수 있겠지만, 이것이 바로 우리가 하려는 일입니다. Docker 파일에 한 줄의 구성을 추가하여 두 인덱스가 모두 포함되도록 하겠습니다. js 파일과 패키지. npm 설치 명령을 실행하려고 할 때 여기서 잠시 멈춰 보겠습니다.
- 패키지가 보이나요? json 파일입니다. 대답은 '아니요'입니다. 패키지가 없습니다. json 파일을 컨테이너 내부에서 사용할 수 있습니다.
