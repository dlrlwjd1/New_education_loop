# Creating Docker Images

## 개요
- Docker 파일을 만들고 나면 Docker 클라이언트에게 파일을 넘겨요 여러분이 떠올리게 될 Docker CLI는 우리가 터미널에서 사용해온 거죠

## 내용
### 자막·본문 기반 핵심 내용
- Docker 파일을 만들고 나면 Docker 클라이언트에게 파일을 넘겨요 여러분이 떠올리게 될 Docker CLI는 우리가 터미널에서 사용해온 거죠
- 차례로 Docker 클라이언트가 그 파일을 Docker 서버에 제공하죠 Docker 서버는 우릴 위해 힘든 작업을 하죠
- 새 명령 몇 개만 배우면 돼요 사실, 여러분과 제가 함께 만들게 될 거의 모든 Docker 파일은 거의 항상 모든 Docker 파일 안에서 우린 항상 기본 이미지를 명시할 겁니다 곧 그게 무슨 의미인지 얘기하도록 하죠
- Docker 파일이란 걸 만들 거예요 어두운 파일은 본질적으로 일반 텍스트 파일입니다 그 안에 두어 줄의 구성이 이 구성은 컨테이너가 어떻게 작동하는지 정의합니다 더 구체적으로 어떤 다양한 프로그램이 포함되는지 컨테이너로 시작할 때 뭘 하는지도요
