# Building a Dockerfile

## 개요
- 지난 섹션에선 사용자 지정 이미지를 만드는 법을 다뤘죠 Docker 파일을 만들어 Docker 서버에 입력하면 결국 유용한 이미지를 구축하게 됩니다

## 내용
### 자막·본문 기반 핵심 내용
- 지난 섹션에선 사용자 지정 이미지를 만드는 법을 다뤘죠 Docker 파일을 만들어 Docker 서버에 입력하면 결국 유용한 이미지를 구축하게 됩니다
- 이미지를 생성할 Docker 파일을 만들 겁니다 시작될 때마다 Redis 서버를 실행할 파일이죠
- JSON도 조개껍데기도 아무것도 없죠 간단히 Docker 파일이라 부르죠 이 안에 주석을 달겠습니다 사용자 지정 이미지 생성 과정을 안내하기 위해서요
- 이 ID를 복사해 Docker 실행을 실행합니다 해당 ID를 붙여넣어 이걸 그런 다음 재빨리 모든 종류의 출력을 여기서 보게 됩니다 전에 Docker를 실행했을 때 봤던 거죠 가장 붉은색 이미지를요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `Docker`, `Redis`, `JSON`
