# How's Docker Running on Your Computer?

## 개요
- 따라서 여러분은 지금 Docker를 어떻게 실행하는지 궁금할 수 있죠 Docker 클라이언트와 Docker 컨테이너를 실행 중이죠 Mac OS나 Windows 운영 체제에서요

## 내용
### 자막·본문 기반 핵심 내용
- 따라서 여러분은 지금 Docker를 어떻게 실행하는지 궁금할 수 있죠 Docker 클라이언트와 Docker 컨테이너를 실행 중이죠 Mac OS나 Windows 운영 체제에서요
- 조금 전에 Windows용 Docker나 Mac용 Docker를 설치했을 때 지난 두어 섹션에서 Linux 가상 컴퓨터를 설치했죠
- Docker가 실행되는 한 기술적으로 여러분 컴퓨터에 Linux 가상 컴퓨터가 이 가상 컴퓨터 내부는 이 모든 컨테이너가 생성되는 곳이죠
- 이 Linux 가상 컴퓨터를 실제로 볼 수 있습니다 지금 터미널을 열면요 Docker 버전 명령을 다시 실행해 서버를 살펴보면 여기 OS 엔트리가 있는 게 보이실 겁니다 보다시피 운영 체제 목록이 없죠

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `Docker`
