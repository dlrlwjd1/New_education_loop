# Dockerfile Teardown

## 개요
- 주석을 제외하고 Docker 파일에서 모든 줄을 빼서 이 다이어그램에 넣었어요 알프스 Run and Command를 보면 우리가 넣은 모든 구성 라인이 다른 것과 비슷한 걸 알 수 있어요

## 내용
### 자막·본문 기반 핵심 내용
- 주석을 제외하고 Docker 파일에서 모든 줄을 빼서 이 다이어그램에 넣었어요 알프스 Run and Command를 보면 우리가 넣은 모든 구성 라인이 다른 것과 비슷한 걸 알 수 있어요
- CMD는 이 아래에 있고요 짐작할 수 있죠? 그게 CMD의 논점이죠 Docker 파일의 전반적인 구조가 그렇게 됐는데 그걸로 많은 부분을 설명하진 않아요 또는 이 각각의 선들의 의도가 Docker 파일을 작성할 때 추가한 주석의 외부란 것도요
- 마지막 섹션에서 가장 첫 Docker 파일을 함께 입력해 터미널에서 새 이미지를 구축하는 데 재빠르게 사용했어요
- 하지만 이 안에서 무슨 일이 벌어지는지는 얘기 안 했죠 이 세션과 다음 세션에선 깊이 알아보겠습니다 Docker 파일에 추가한 모든 구성과 그 후 터미널에서 일어난 일에요
