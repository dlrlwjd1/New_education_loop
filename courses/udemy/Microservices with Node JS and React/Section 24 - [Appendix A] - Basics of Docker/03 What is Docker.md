# What is Docker?

## 개요
- 이 질문은 대답하기 훨씬 더 어렵네요 누군가 블로그 포스트나 기사, 포럼에서 Docker를 참조하는 걸 볼 때마다 그건 다양한 프로젝트, 도구, 소프트웨어의 전체 생태계를 참조하는 누군가 프로젝트에 Docker를 사용한다고 하면 Docker 클라이언트나 Docker 서버를 지칭하는 Docker Hub나 Docker Compose를 지칭할 수도 있죠

## 내용
### 자막·본문 기반 핵심 내용
- 이 질문은 대답하기 훨씬 더 어렵네요 누군가 블로그 포스트나 기사, 포럼에서 Docker를 참조하는 걸 볼 때마다 그건 다양한 프로젝트, 도구, 소프트웨어의 전체 생태계를 참조하는 누군가 프로젝트에 Docker를 사용한다고 하면 Docker 클라이언트나 Docker 서버를 지칭하는 Docker Hub나 Docker Compose를 지칭할 수도 있죠
- 지난 섹션에서 우린 왜 Docker를 사용하느냐는 질문에 답하려 했죠 결국 Docker를 사용하기로 했죠 컴퓨터에 새 소프트웨어를 설치하고 실행하는 게 여기서 또 다른 중요한 질문에 답하려 하진 않겠습니다 Docker가 무엇인가?죠
- 해당 명령을 실행했을 때 Docker CLI라는 것이 Docker Hub라는 것에 접촉해 이미지라는 단일 파일을 다운로드했어요
- Docker가 뭐냐는 질문에 대답하지 않았지만 Docker 참조가 다양한 프로젝트 및 도구 전체 컬렉션에 관해 얘기한다는 건 배웠죠
