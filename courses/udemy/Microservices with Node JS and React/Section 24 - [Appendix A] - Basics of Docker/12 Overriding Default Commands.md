# Overriding Default Commands

## 개요
- Docker 컨테이너에 따르면 파일과 폴더를 프린트할 때 etsi dev home proc 루트 시스템 사용자 및 var가 됐죠

## 내용
### 자막·본문 기반 핵심 내용
- Docker 컨테이너에 따르면 파일과 폴더를 프린트할 때 etsi dev home proc 루트 시스템 사용자 및 var가 됐죠
- Docker가 실행하는 명령을 계속 살펴볼 겁니다 그걸 약간 변형해서요 다음 변형된 명령어를 보여드리기 전에 한 가지 알려드릴 게 있어요
- Docker를 실행할 때마다 이미지와 함께 실행하면 파일 시스템 스냅샷만 얻는 게 아니라 이 기본 명령도 얻게 됩니다 컨테이너가 생성된 후에 실행되는 명령이죠
- Docker 실행을 변형해 살펴볼 텐데요 기본 시작 명령을 재정의할 이렇게 하면 돼요
