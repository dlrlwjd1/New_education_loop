# Executing Commands in Running Containers

## 개요
- 그러기 위해 다른 Docker 명령을 사용하죠 우리가 사용할 Docker 명령은 Docker EXEC이죠

## 내용
### 자막·본문 기반 핵심 내용
- 그러기 위해 다른 Docker 명령을 사용하죠 우리가 사용할 Docker 명령은 Docker EXEC이죠
- 컨테이너 ID를 확보해야 해요 Docker PS로요 ID가 저기 있네요 Docker EXECEC Dash를 하고 ID를 붙여넣습니다 그 안에서 실행하려는 명령은 Redis CLI예요
- 하지만 이번에는 IT 깃발은 안 뽑을 거예요 Docker EXEC ID를 한 다음 Redis CLI를 하면 이번엔 터미널로 직접 차인 게 보이실 거예요
- Exec은 실행의 약자로 컨테이너 내부의 추가 명령을 실행할 때 사용하죠 docker EXECer라고 쓸게요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `Docker`, `Redis`, `Docker EXEC`, `docker EXECer`, `Docker PS`, `Docker EXECEC Dash`, `Docker EXEC ID`
