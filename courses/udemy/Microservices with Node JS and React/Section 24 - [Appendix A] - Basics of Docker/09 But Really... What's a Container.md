## 내용
### 자막·본문 기반 핵심 내용
- 그중 하나는 크롬일 겁니다 웹 브라우저 같은 크롬이요 다른 건 노드죠 js, JavaScript 서버 요즘 세상에선 크롬이 제대로 작동하려면 파이썬 버전 2가 설치되고 노드가 있어야 하죠 js는 버전 3이 설치되어야 해요
- 따라서 사람들이 Docker 컨테이너가 있다고 해도 여러분 컴퓨터 안에 존재하는 물리적 구조물로 생각하면 안 돼요
- 하드디스크에서는 파이썬 버전 2에만 접근할 수 있죠 어떤 황당한 이유에서건 똑같은 Python을 동시에 두 개 설치할 수는 현재로서 크롬은 제대로 작동할 겁니다 버전 2에 액세스하니까요 하지만 노드죠 버전이나 Python 버전 3 복사본이 없기 때문이죠
- 마지막 부분에서요 이미지에 관해 계속 얘기하지만 컨테이너가 정확히 뭔지에 관한 몇몇 세부 사항은 놀라울 정도로 밝죠
