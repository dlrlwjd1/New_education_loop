# Manual Image Generation with Docker Commit

## 개요
- Docker 파일과 같은 작업을 수동으로 할 수 있다는 거죠 컨테이너를 생성하고 명령을 실행할 수 있어요 예를 들어 앱, 여기 Redis를 추가하고 이미지를 어떻게 보일지 빨리 보여드릴게요

## 내용
### 자막·본문 기반 핵심 내용
- Docker 파일과 같은 작업을 수동으로 할 수 있다는 거죠 컨테이너를 생성하고 명령을 실행할 수 있어요 예를 들어 앱, 여기 Redis를 추가하고 이미지를 어떻게 보일지 빨리 보여드릴게요
- 근본적으로 Docker 파일의 모든 것이 터미널에서 Docker 실행을 실행하겠습니다
- 그러기 위해 첫 번째 Docker PS를 입력해 실행 중인 컨테이너의 아이디어를 알아낸 다음 Docker 여기 대시 키를 추가하겠습니다 기본 명령을 지정할 수 있도록 해주는 거죠
- 방금 우리가 만든 Docker 파일을 에뮬레이트해 보죠 알프스 이미지에서 수동으로 새 컨테이너를 만들 거예요
