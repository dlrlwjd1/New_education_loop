# Retrieving Output Logs

## 개요
- Docker를 사용해 시작을 생성하고 다시 명령에 로그해 어떻게 되나 보죠 docker로 바쁜 상자를 만들고 에코를 넣죠

## 내용
### 자막·본문 기반 핵심 내용
- Docker를 사용해 시작을 생성하고 다시 명령에 로그해 어떻게 되나 보죠 docker로 바쁜 상자를 만들고 에코를 넣죠
- Docker start를 실행해 ID를 끼워넣으면요 하지만 작은 함정이 있어요 컨테이너에서 정보가 출력되는 걸 보려면 대시에 깃발을 추가해야 했어요
- 대시 플래그를 추가하지 않고 컨테이너에서 모든 결과물을 얻으려면 어떻게 예를 들어 Docker 실행 시작을 상상해 보세요 이 프로세스는 아주 비싸고 그 내부에서 시작하는 프로세스는 실행에 몇 분씩 걸리죠
- 결과 확인을 위해 대시 플래그를 추가하는 걸 잊었을 수도 있죠 우리 자신에게 좀 좌절할 수도 있어요 그럼 Docker를 다시 실행해 대시를 다시 시작하고 몇 분 더 기다려야 하니까요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `Docker`, `Docker start`
