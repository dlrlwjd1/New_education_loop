# A Brief Recap

## 개요
- 약간 다른 다이어그램으로 요약해보죠 모든 게 알파인 지시 사항에서 시작됐죠 Docker 서버나 Docker 디먼에 알파인 이미지를 다운로드하라고 명령했어요

## 내용
### 자막·본문 기반 핵심 내용
- 약간 다른 다이어그램으로 요약해보죠 모든 게 알파인 지시 사항에서 시작됐죠 Docker 서버나 Docker 디먼에 알파인 이미지를 다운로드하라고 명령했어요
- 전체 단계 시리즈의 결과물은 Docker 파일 안에서 마지막 지시 시간에 생성된 이미지가 말씀드린 대로 전체 프로세스를 한 번 더 간략히 요약하겠습니다 여기서 깊이 이해하는 게 그리 중요한 건 아니지만 Docker의 많은 부분을 훨씬 쉽게 만들어 주거든요 전체 흐름을 잘 이해한다면요
- 마지막 섹션에서 Docker 빌드 과정 동안 일어난 일의 뒷이야기를 살펴봤습니다 꽤 긴 섹션이 있었는데 세부 사항을 아주 자세히 살펴봤죠
- APK 프로그램이 실행됐어요 컨테이너 파일 시스템에 Redis를 다운로드해서 설치했어요
