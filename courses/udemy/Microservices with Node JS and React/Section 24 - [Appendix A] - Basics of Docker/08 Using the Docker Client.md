# Using the Docker Client

## 개요
- Docker 서버는 이미지 캐시란 걸 살펴봤죠 과 제가 방금 개인 컴퓨터에 Docker를 설치했기 때문에 이미지 캐시는 현재 비어 이미 다운로드된 이미지가 없기 때문에 이미지 캐시가 비었기 때문에 Docker 서버는 Docker Hub라는 무료 서비스에 연락하기로 했죠

## 내용
### 자막·본문 기반 핵심 내용
- Docker 서버는 이미지 캐시란 걸 살펴봤죠 과 제가 방금 개인 컴퓨터에 Docker를 설치했기 때문에 이미지 캐시는 현재 비어 이미 다운로드된 이미지가 없기 때문에 이미지 캐시가 비었기 때문에 Docker 서버는 Docker Hub라는 무료 서비스에 연락하기로 했죠
- 마지막 섹션에서 다운로드해 Windows 또는 Mac을 위한 Docker를 설치했죠 여러분의 개인 명령줄에서 명령 도커 버전을 실행하면 이런 텍스트가 가장 먼저 의미 있는 명령을 작성하고 싶어요 Docker 클라이언트 또는 Docker Clai로요
- Docker Hub는 무료 공용 이미지 리포지토리입니다 무료로 다운로드해 개인 컴퓨터에서 실행할 Docker 서버가 Docker Hub에 연락해 Hello World란 이미지를 찾고 있다고 했죠
- 무거운 걸 담당하는 Docker 서버죠 Hello World를 실행하는 명령 Docker를 실행하면 Hello World란 이름의 이미지를 이용해 새 컨테이너를 시작해야 한다는 뜻이죠
