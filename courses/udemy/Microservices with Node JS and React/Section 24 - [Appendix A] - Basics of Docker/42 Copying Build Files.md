# Copying Build Files

## 개요
- 지난 섹션에서 패키지로 인해 npm 설치 명령이 실행되지 않는 것을 확인했습니다. json 파일을 찾을 수 없었고, 그 이유에 대해 이야기했습니다.

## 내용
### 자막·본문 기반 핵심 내용
- 지난 섹션에서 패키지로 인해 npm 설치 명령이 실행되지 않는 것을 확인했습니다. json 파일을 찾을 수 없었고, 그 이유에 대해 이야기했습니다.
- 이 섹션에서는 패키지를 확인하는 방법을 알아보겠습니다. json 파일을 컨테이너 내부에서 npm 설치가 실행되기 전에 사용할 수 있습니다.
- 이를 위해 Docker 파일에 작은 명령어 하나를 추가하겠습니다. 이것은 이전에 사용하지 않았던 지침이 될 것입니다.
- 터미널에서 Docker 빌드를 실행할 때 빌드 컨텍스트가 바로 여기 점이라고 말씀드린 것을 기억하실 따라서 여기서 빌드는 간단한 웹 디렉토리 또는 현재 작업 디렉터리를 의미합니다.

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `npm`, `json`, `Docker`, `Docker ID`, `npm start`

## 예시
`npm`, `json`, `Docker`, `Docker ID`, `npm start`가 등장하는 설정·코드 위치를 찾아 강의와 같은 순서로 확인한다.
