# Docker Run in Detail

## 개요
- 이 섹션과 다음 두어 개에서 시작해 터미널 내의 Docker 클라이언트 또는 Docker CLI를 살펴보고 우리가 Docker 컨테이너 및 이미지와 상호 작용할 때 사용하는 아주 기본적인 명령 일부에 관해 배울 거예요

## 내용
### 자막·본문 기반 핵심 내용
- 이 섹션과 다음 두어 개에서 시작해 터미널 내의 Docker 클라이언트 또는 Docker CLI를 살펴보고 우리가 Docker 컨테이너 및 이미지와 상호 작용할 때 사용하는 아주 기본적인 명령 일부에 관해 배울 거예요
- 이 프로세스는 이미 한 번 거쳤죠 명령줄에서요 Docker Run Hello World를 실행해 해당 메시지가 화면에 나타나는 걸 봤죠
- 우리가 사용할 명령이죠 이미지를 이용해 컨테이너를 생성하고 실행하기 위해서요 명령줄에서 Docker 실행을 실행합니다 그런 다음 이 컨테이너를 위해 기본으로 사용하려는 이미지 이름을 입력하죠
- Docker 컨테이너가 실제로 뭔지 여러분이 아는 지식을 이용해 해당 명령을 실행했을 때 방금 발생한 일을 생각해 보세요
