# Node Server Setup

## 개요
- 이 섹션에서는 NodeJS 웹 애플리케이션에 대한 작업을 시작하겠습니다. NodeJS에 익숙하지 않거나 자바스크립트를 모르는 경우, 자바스크립트를 알고 싶지 않더라도 지금 동영상을 일시 중지할 수 있습니다.

## 내용
### 자막·본문 기반 핵심 내용
- 이 섹션에서는 NodeJS 웹 애플리케이션에 대한 작업을 시작하겠습니다. NodeJS에 익숙하지 않거나 자바스크립트를 모르는 경우, 자바스크립트를 알고 싶지 않더라도 지금 동영상을 일시 중지할 수 있습니다.
- 따라서 설정이 되어 있지 않더라도 괜찮습니다. 방금 만든 간단한 웹 디렉터리를 기반으로 코드 에디터를 열기만 하면 그런 다음 여기 내부에 패키지 도트 JSON이라는 파일을 먼저 생성합니다.
- 그런 다음 콜론을 표시한 다음 버전에 별표를 표시하여 모든 버전의 Express를 사용할 수 있음을 표시하겠습니다.
- 패키지 내부는 여기까지입니다. json 파일입니다. 종속성을 지정하고 단일 스크립트를 만들었습니다.
