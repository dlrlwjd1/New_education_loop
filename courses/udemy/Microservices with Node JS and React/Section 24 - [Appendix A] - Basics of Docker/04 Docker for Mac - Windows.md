# Docker for Mac / Windows

## 개요
- Docker 클라이언트는 컨테이너나 이미지로 아무것도 하지 않아요 Docker 클라이언트는 도구나 포털 같은 것으로 우리가 다른 소프트웨어와 상호 작용하도록 도와줍니다 이 Docker는 Windows나 Docker 서버라 불리는 Mac 패키지에 포함돼 있죠

## 내용
### 자막·본문 기반 핵심 내용
- Docker 클라이언트는 컨테이너나 이미지로 아무것도 하지 않아요 Docker 클라이언트는 도구나 포털 같은 것으로 우리가 다른 소프트웨어와 상호 작용하도록 도와줍니다 이 Docker는 Windows나 Docker 서버라 불리는 Mac 패키지에 포함돼 있죠
- 우리가 할 일은 이거예요 Windows용 Docker나 Mac용 Docker라는 소프트웨어를 설치할 겁니다
- Docker 클라이언트는 Docker CLI로도 알려져 있는데 여러분과 제가 터미널에서 상호 작용하게 될 프로그램이죠
- 흔히 Docker 데몬이라고도 하죠 여기 이 프로그램은 실제 도구나 소프트웨어로 컨테이너 생성, 이미지 관리 컨테이너 관리, 업로드 이미지를 책임지고 Docker의 세계에서 여러분이 상상할 수 있는 거의 모든 걸 작업하죠

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `Docker`, `Docker CLI`
