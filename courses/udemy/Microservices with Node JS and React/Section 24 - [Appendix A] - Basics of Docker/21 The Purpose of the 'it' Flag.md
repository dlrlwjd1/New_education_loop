## 내용
### 자막·본문 기반 핵심 내용
- Docker PS로 컨테이너 ID를 다시 확보할게요 그런 다음 Docker EXEC를 하고 대시 I만 하죠
- 가장 먼저 이해하셔야 할 것은 Linux 환경 안에서 프로세스가 어떻게 실행되느냐는 상기시켜드리자면 Docker를 여러분 컴퓨터에서 실행할 때 실행 중인 모든 단일 컨테이너는 Linux를 실행하는 가상 컴퓨터 안에서 실행되고 있죠
- 마지막 섹션에서 실행 중인 Docker 컨테이너 안에서 리타 실리와 연결할 수 있었습니다 두 번째 창에서 제 것이 여전히 실행 중인 걸 보세요 대시 잇 깃발을 그렇게 했더니 여기 프롬프트가 있네요 입력할 수 있어요
- 화면 이면에서 좀 더 많은 일을 하고 있어요 하지만 결국 영향은 미치는 법이죠 한 번 더 실행 중인 컨테이너에 Docker EXEC을 첨부하거나 실행해보죠 대시 t 깃발은 빼고 어떻게 되나 보죠
