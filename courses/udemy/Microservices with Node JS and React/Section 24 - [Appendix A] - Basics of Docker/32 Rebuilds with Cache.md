# Rebuilds with Cache

## 개요
- Docker를 실행해 어떤 변화도 주지 않고 세 번째 빌드하면 Docker는 우리가 Docker 파일에 어떤 변화도 주지 않은 걸 정확히 보게 되죠

## 내용
### 자막·본문 기반 핵심 내용
- Docker를 실행해 어떤 변화도 주지 않고 세 번째 빌드하면 Docker는 우리가 Docker 파일에 어떤 변화도 주지 않은 걸 정확히 보게 되죠
- Docker 빌드 프로세스에 관해 마지막으로 언급하고 싶은 게 있어요 이건 이해해야 할 중요한 겁니다 새 이미지를 만들 때마다 Docker에게 많은 성능을 주는 것이니까요
- 이미지를 재구축하고 싶어요 흥미로운 걸 발견하게 되실 텐데요 터미널로 돌아가서 아직 Redis 이미지 디렉터리 안에 있어요 Docker 빌드 닷을 실행해 두 번째로 제 이미지를 빌드할게요
- 이미 Docker 허브에서 다운로드해뒀기 때문에 두 번 다운로드할 필요가 께 보여드리고 싶은 흥미로운 건 여기서 Docker가 속도와 성능을 많이 얻는다는 겁니다 이미지를 빌드할 때요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `Docker`, `Redis`

## 예시
`Docker`, `Redis`가 등장하는 설정·코드 위치를 찾아 강의와 같은 순서로 확인한다.
