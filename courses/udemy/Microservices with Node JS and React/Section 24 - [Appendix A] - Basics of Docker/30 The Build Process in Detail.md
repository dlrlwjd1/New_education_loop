# The Build Process in Detail

## 개요
- Docker 빌드 아웃을 실행하면 Docker 파일을 Docker CLI에 넘기게 되죠

## 내용
### 자막·본문 기반 핵심 내용
- Docker 빌드 아웃을 실행하면 Docker 파일을 Docker CLI에 넘기게 되죠
- 우리 경우엔 아닐 거예요 가장 먼저 일어난 일은 Docker 서버가 Docker 허브에 도달한 겁니다 여러분이 상기하실 것은 무료로 사용 중인 기존 Docker 이미지 리포지토리란 거죠
- 조금 전에 한 얘기 기억해요? Docker 파일을 만들 때 그걸 Docker 클라이언트에 공급해 여러분의 파일을 Docker 서버에 넘깁니다 그렇게 사용 가능한 이미지를 빌드하죠
- 급한 일부터 처리하죠 Docker 빌드를 왜 사용하냐고요? Docker CLI에 연결된 새 명령어인데 전에 사용한 적이 없어요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `Docker`, `Redis`, `Docker CLI`, `Docker Hub`

## 예시
`Docker`, `Redis`, `Docker CLI`, `Docker Hub`가 등장하는 설정·코드 위치를 찾아 강의와 같은 순서로 확인한다.
