# A Few Planned Errors

## 개요
- 이 시점에서 아주 직접적인 유사점이 있는 것 같아요 노드 응용 프로그램은 Docker 파일을 작업하면 될 것 같아요 알파인을 기본 이미지로 지정하는 NPM 설치를 실행해 종속성을 모두 설치한 다음 NPM의 기본 명령을 설정합니다

## 내용
### 자막·본문 기반 핵심 내용
- 이 시점에서 아주 직접적인 유사점이 있는 것 같아요 노드 응용 프로그램은 Docker 파일을 작업하면 될 것 같아요 알파인을 기본 이미지로 지정하는 NPM 설치를 실행해 종속성을 모두 설치한 다음 NPM의 기본 명령을 설정합니다
- 다음은 종속성을 설치할 거예요 그러기 위해 명령 NPM 설치를 실행할 거예요 NPM 설치 명령은 노드에 종속성을 설치하는 방법이죠 js 프로젝트요
- 마지막 섹션에서 노드의 핵심을 합쳤어요 js 웹 응용 프로그램이요 지난 섹션에서 복사를 안 하셨다면 indexed JS 파일과 패키지 JSON 파일을 복사를 하세요
- 또한 프로젝트 디렉터리 내에 터미널이 열려있는지 확인해야 하죠 현재 파일과 폴더 목록을 보면 인덱스와 패키지 JSON 파일을 볼 수 있죠
