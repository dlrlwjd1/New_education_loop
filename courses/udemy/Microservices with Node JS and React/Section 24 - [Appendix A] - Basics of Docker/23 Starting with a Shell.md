# Starting with a Shell

## 개요
- 하지만 원하면 Docker를 실행할 수도 있어요 원조 Docker를 실행해 명령을 실행하는 거죠 깃발과 함께요 그럼 컨테이너가 처음 시작되면 즉시 셸을 시작할 수 있어요

## 내용
### 자막·본문 기반 핵심 내용
- 하지만 원하면 Docker를 실행할 수도 있어요 원조 Docker를 실행해 명령을 실행하는 거죠 깃발과 함께요 그럼 컨테이너가 처음 시작되면 즉시 셸을 시작할 수 있어요
- 지난 섹션에선 실행 중인 컨테이너 내 셸을 여는 방법에 관해 얘기했죠 Docker EXEC EXEC-H를 사용해서요 그런 다음 셸에 넘기거나 그냥 S-H를 통해 우리가 실행하려는 명령으로요
- 내가 원하는 대로 메시지를 전달할 수 있어요 다시 말씀드리지만 이건 여러분이 컨테이너를 찌르고 싶을 때 자주 사용하는 Docker를 함께 실행하는 단점은 S-H를 사용하면 다른 프로세스를 실행하지 않을 확률이 높다는 거죠
- 명령줄에서 그걸 시험해 보죠 제 단말기로 돌아갈게요 Docker 런에서 달릴 거예요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `Docker`, `Docker

EXEC EXEC-H`
