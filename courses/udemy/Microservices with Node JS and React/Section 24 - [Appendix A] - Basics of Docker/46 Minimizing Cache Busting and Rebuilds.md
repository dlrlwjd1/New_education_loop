## 내용
### 자막·본문 기반 핵심 내용
- 이 초기 복사 단계에서 제가 복사하고 싶은 유일한 건 패키지 JSON 파일이에요 여기 지시를 바꿨습니다 이제 보라고 하죠 현재 작업 디렉터리에서 또는 Docker 런이나 Docker 빌드 컨텍스트 인수에 의해 지정된 디렉터리를 살펴보라고요
- 인덱스 파일에 원하는 만큼 수정을 할 수 있고 캐시를 무효화하지 않습니다 두 단계 NPM 설치가 다시 실행되는 유일한 시간은 해당 단계를 변경하거나 그 이후의 단계를 다른 말로 하면 유일한 효과는 패키지 JSON 파일에 변화를 주는 것입니다 NPM 설치가 빌드 프로세스에서 다시 실행되는 유일한 다시 만들어 봅시다 컨테이너를 올리고 모든 게 잘 작동하는지 다시 뒤집을게요
- Docker는 우리가 파일 중 하나를 변경한 걸 감지했죠 NPM 설치 단계를 재실행했지만 NPM 설치 단계를 재실행하거나 모듈을 다시 설치할 필요는 없었습니다 실제 응용 프로그램에서는 몇 분밖에 걸리지 않았지만요
- 여기서 NPM 설치가 성공적으로 실행되려면 필요한 건 패키지 JSON 파일뿐이에요
