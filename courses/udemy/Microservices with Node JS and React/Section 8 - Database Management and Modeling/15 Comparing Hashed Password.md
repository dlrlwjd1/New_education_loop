# Comparing Hashed Password

## 개요
- 비밀번호 수업을 마칠게요 이 비디오에선 정적 비교 메서드를 구현할 거예요 저장된 암호를 데이터베이스에서 꺼내겠습니다 공급된 암호도요

## 내용
### 자막·본문 기반 핵심 내용
- 비밀번호 수업을 마칠게요 이 비디오에선 정적 비교 메서드를 구현할 거예요 저장된 암호를 데이터베이스에서 꺼내겠습니다 공급된 암호도요
- 다이어그램으로 돌아가서 아까 보던 건데요 공급된 암호를 해시하고 해시 버전을 얻은 다음 데이터베이스에 저장된 것과 비교할 거예요
- 그 숫자가 같다면 사용자가 올바른 암호를 줬다는 뜻이죠 일이 좀 복잡해지는 것 같아요
- 이 기능도 sync로 표시하도록 할게요 마지막으로 원래 해시 암호와 사용자가 방금 적용한 새 해시 암호가 포함된 버퍼도 버퍼를 문자열로 바꿔서 해시 1과 비교할 거예요

### 구현 요소
- 강의 흐름에 따라 Comparing Hashed Password의 구현 목적과 적용 지점을 확인한다.
