# Adding Static Properties to a Model

## 개요
- 사용자 빌드라고 하죠 아니나 다를까 결국 상속자를 얻었죠 이 시점에서 TypeScript와 Mongoose가 함께 작업하는 건 TypeScript는 정적 개체에 속성을 할당하는 게 무슨 뜻인지 몰라요

## 내용
### 자막·본문 기반 핵심 내용
- 사용자 빌드라고 하죠 아니나 다를까 결국 상속자를 얻었죠 이 시점에서 TypeScript와 Mongoose가 함께 작업하는 건 TypeScript는 정적 개체에 속성을 할당하는 게 무슨 뜻인지 몰라요
- 우리가 가진 전부요 몽구스 모델의 용도에 기능을 추가하는 방법인데요 하지만 TypeScript는 우리가 TypeScript에 정보를 더 줘야 한다는 걸 이해 못 해요
- 게다가 아직 첫 번째 문제만 해결했어요 두 번째 문제와 관련된 걸 해결하지 못했죠 TypeScript와 Mongoose에게 새 사용자를 만들 때 전달하는 속성 집합이 사용자의 속성 집합과 다르다고 아직 갈 길이 멀어요
- 역시 잘 됐어요 그런데 조금 더 혼란을 소개했고 불행히도 아까 언급한 대로 Typecript와 mongoose가 함께 작동하게 할 겁니다 좀 황당한 코드를 포함하죠
