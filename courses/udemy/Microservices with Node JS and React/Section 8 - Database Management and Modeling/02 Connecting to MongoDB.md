# Connecting to MongoDB

## 개요
- 명령 실행할게요 다시 뒤집으면 공기가 사라져요 이 파일 안에 Mongoose가 있어요 Mongoose를 이용해 MongoDB 인스턴스에 몽구스를 이용해서 다양한 방법으로 몽고 인스턴스와 연결할 수 있어요

## 내용
### 자막·본문 기반 핵심 내용

- 다른 말로 하자면 Mongoose Connect라고 쓰고 여전히 MongoDB::// 이렇게 쓰는 거죠 로컬 호스트 대신에 auth mongo crv라고 쓰는 거예요
- 그 안에 인덱스 파일이 있어요 MongoDB에 접근하기 위해 코드를 추가하겠습니다 Mongoose를 이용해 연결하기 지난 번 비디오에선 몽구스를 넣었어요
- 그런 다음 연결하고자 하는 실제 데이터베이스 이름을 입력할 수 있어요 여기서 이름을 만들면 MongoDB나 Mongoose가 자동으로 데이터베이스를 생성하죠
