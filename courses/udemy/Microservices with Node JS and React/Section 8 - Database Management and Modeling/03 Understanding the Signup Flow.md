# Understanding the Signup Flow

## 개요
- Mongoose와 TypeScript를 사용하고 있죠 TypeScript와 Mongoose는 서로 잘 협조하지 않아요

## 내용
### 자막·본문 기반 핵심 내용
- Mongoose와 TypeScript를 사용하고 있죠 TypeScript와 Mongoose는 서로 잘 협조하지 않아요
- 그걸 반영하기 위해 React Application으로 돌아가 JSON Web 토큰이나 그런 걸 보내겠습니다 이 사용자가 로그인하고 인증된 걸 나타내는 거죠
- 솔직히 말씀드릴게요 Mongoose와 TypeScript가 좀 더 함께 잘 작동하도록 하는 라이브러리가 있어요
- 하지만 이 프로젝트를 위해 사용할 라이브러리 수를 제한하고 싶어요 수동으로 Mongoose와 TypeScript를 상호 작용하게 할 거예요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `React`, `MongoDB`, `mongoose`, `JSON`, `TypeScript`
