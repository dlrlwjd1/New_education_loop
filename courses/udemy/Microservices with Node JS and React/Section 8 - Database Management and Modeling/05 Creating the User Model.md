# Creating the User Model

## 개요
- 제가 언급하고 싶은 또 한 가지는 여기에 문자열 형식을 넣을 때 이건 대문자 S 문자열이에요 문자열 생성자를 언급한 거니까요 JavaScript 언어에서 사용 가능한 TypeScript를 이용해 문자열을 쓸 때마다요

## 내용
### 자막·본문 기반 핵심 내용
- 제가 언급하고 싶은 또 한 가지는 여기에 문자열 형식을 넣을 때 이건 대문자 S 문자열이에요 문자열 생성자를 언급한 거니까요 JavaScript 언어에서 사용 가능한 TypeScript를 이용해 문자열을 쓸 때마다요
- TypeScript에선 문자열 형식을 표시하고 싶을 때마다 소문자에 mongoose를 쓰죠
- 이것도 형식 문자열이 될 거고 이것도 요구될 거예요 해당 스키마를 생성하고 나면 mongoose에게 스키마를 입력할 수 있습니다 mongoose는 거기서 새 모델을 생성하죠
- 예를 들어 새 사용자를 생성해 보죠 이 아래에 사용자 모델을 만든 후 new user를 누르죠
