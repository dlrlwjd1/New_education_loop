# Type Checking User Properties

## 개요
- 지난 비디오에선 TypeScript와 Mongoose가 협력하는 데 있어 두 가지 큰 이슈를 다뤘죠

## 내용
### 자막·본문 기반 핵심 내용
- 지난 비디오에선 TypeScript와 Mongoose가 협력하는 데 있어 두 가지 큰 이슈를 다뤘죠
- 이 모델을 작성했는데 모든 게 좋아 보여요 하지만 보셨듯이 사용자를 생성하려는 순간 몇 가지 문제에 부딪힐 수 있어요 TypeScript는 우리가 생성자에게 넘기는 인수의 유형을 확인하지 않기 때문이죠
- 그래, 새 문서를 만들려면 새것이라 불러야지 그런 다음 모델 이름을 알려주고 특성을 그걸 따르진 않을 거예요 TypeScript로는 효과적인 형식 확인을 할 수 없거든요
- 사용자 생성 프로세스에 TypeScript를 참여시키기 위해 추가 단계를 추가하고 우리 코드에 새 사용자를 직접 쓸 수는 없으니까요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `TypeScript`, `Mongoose`

## 예시
`TypeScript`, `Mongoose`가 등장하는 설정·코드 위치를 찾아 강의와 같은 순서로 확인한다.
