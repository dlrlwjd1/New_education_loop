# User Creation

## 개요
- 개발자 API 사용자 등록에 티켓팅 요청을 할게요 머리맡에 콘텐츠 형식 응용 프로그램 JSON이 있네요

## 내용
### 자막·본문 기반 핵심 내용
- 개발자 API 사용자 등록에 티켓팅 요청을 할게요 머리맡에 콘텐츠 형식 응용 프로그램 JSON이 있네요
- 사용자 컬렉션에 쿼리를 실행할 거예요 사용자 모델을 사용해서요 weight user를 선택해서 같은 이메일 주소를 사용할게요.
- 이 단계를 통과하면 사용자를 생성하고 데이터베이스에 저장해야 하죠 균형 잡힌 사용자를 만들어 볼게요. 새로운 사용자 문서를 어떻게 만드는지 기억하세요. user. build라고 불러요.
- 데이터베이스에 저장하려면 A weight user 저장을 해야 해요 몽고다브에서 벗어나지 못할 거예요
