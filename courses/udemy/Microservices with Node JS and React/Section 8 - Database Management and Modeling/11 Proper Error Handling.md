# Proper Error Handling

## 개요
- 로그인 라우트 처리기와 관련해 해야 할 일이 아직 두어 가지 있어요 암호 해싱을 쿠키나 JSON 웹 토큰을 생성하도록 해야 해요

## 내용
### 자막·본문 기반 핵심 내용
- 로그인 라우트 처리기와 관련해 해야 할 일이 아직 두어 가지 있어요 암호 해싱을 쿠키나 JSON 웹 토큰을 생성하도록 해야 해요
- 이미 이 사용자 지정 오류의 목표는 Express 유효성 검사기로부터의 출력을 처리하는 거였죠
- 커스텀 에어를 확장하면 TypeScript가 거기서부터 어떻게 진행할지 말해줄 어떻게 되는지 보여드리죠
- 공기가 있고 연장될 거예요 보다시피 TypeScript가 뛰어들어 이걸 실제로 구현하고 측정하기 위해 우리가 해야 할 모든 걸 말해주죠

### 구현 요소
