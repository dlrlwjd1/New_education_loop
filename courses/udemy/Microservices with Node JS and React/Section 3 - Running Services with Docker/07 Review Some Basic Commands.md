# Review Some Basic Commands

## 개요
- 예를 들어 POST 서비스로 돌아가죠 Docker로 T를 만들 수 있죠 그런 다음 대개 Docker ID를 입력합니다 스티븐 그리더 슬래시 우리 프로젝트 이름이죠

## 내용
### 자막·본문 기반 핵심 내용
- 예를 들어 POST 서비스로 돌아가죠 Docker로 T를 만들 수 있죠 그런 다음 대개 Docker ID를 입력합니다 스티븐 그리더 슬래시 우리 프로젝트 이름이죠
- 바로 마지막에 기본 명령을 제공하는 대신에요 가령, 방금 생성한 포스트 서비스 컨테이너를 시작할 수 있어요 그 안에서 셸을 시작하는 즉 컨테이너 내부의 터미널 윈도우가 NPM 시작이라는 기본 명령어를 실행하는 Docker 실행을 할 수 있어요
- Docker EXECEC-H를 할 수도 있지만 그 ID 안에서요 그런 다음 다시 S-H를 실행하면 실행 중인 컨테이너 안에서 셸이 시작되죠
- 이 비디오에선 아주 기본적인 Docker 명령 몇 가지를 간략히 개요해 여러분이 다시 기억하시는지 확인하죠

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `Docker`, `NPM`, `Docker ID`, `Docker EXEC`, `Docker EXECEC-H`

## 예시
