## 개요
- Docker에 관해 전혀 모르거나 재교육이 필요하다면 괜찮아요 비디오 섹션이군요 코스 막바지에 Docker 설치에 관해 설명드리고 Docker에 관한 기본 사항도 가르쳐드릴 거예요

## 내용
### 자막·본문 기반 핵심 내용

- 지난 두 영상에서 도케르와 쿠베르네테스를 언급했죠 이 시점에서 여러분이 Docker에 대한 배경 지식을 갖고 이 수업을 듣는지 모르겠네요
