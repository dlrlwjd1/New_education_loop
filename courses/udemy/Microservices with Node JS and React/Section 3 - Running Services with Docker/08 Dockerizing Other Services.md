# Dockerizing Other Services

## 개요
- 노드를 사용하고 NPM 스타트업 명령이 동일하다는 거죠 정확히 같은 Docker를 사용할 수 있죠 다른 모든 것과 함께 무시와 docker 파일도요

## 내용
### 자막·본문 기반 핵심 내용
- 노드를 사용하고 NPM 스타트업 명령이 동일하다는 거죠 정확히 같은 Docker를 사용할 수 있죠 다른 모든 것과 함께 무시와 docker 파일도요
- 이 두 개의 파일을 복사 붙여넣기를 하면 돼요 리액트 프로젝트도 마찬가지예요 React project는 기본 환경에서 노드를 사용합니다 NPM start도 함께 시작하고요
- 제 게시 디렉터리 안으로 들어가 보죠 Docker 무시와 Docker 파일을 찾을 수 있어요
- 이 Docker 파일을 만들거나 각각의 프로젝트를 작성하자고 했어요 각각에 동일한 Docker 파일을 가질 수 있도록요
