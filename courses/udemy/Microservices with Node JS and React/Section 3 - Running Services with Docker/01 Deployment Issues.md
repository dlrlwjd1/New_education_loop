# Deployment Issues

## 개요
- 다른 말로 하면 Common Service의 추가 복사본을 생성하자마자 이벤트 버스 코드를 열어야 해요

## 내용
### 자막·본문 기반 핵심 내용
- 다른 말로 하면 Common Service의 추가 복사본을 생성하자마자 이벤트 버스 코드를 열어야 해요
- 다양한 서비스들 사이의 아주 직접적이고 단순한 의사소통이죠 어떻게 하면 이런 종류의 구조를 가져다가 가능한 한 적게 수정해서 온라인에 배포할 수 아주 쉬운 방법은 디지털 오션이나 AWS, 마이크로소프트, Azure에 가서 가상 컴퓨터를 빌리는 거예요
- 애플리케이션은 이제 거의 완성된 상태예요 이 앱을 온라인으로 배포하는 방법을 생각해봐야 해요
- 먼저, 응용 프로그램이 로컬 컴퓨터에서 어떻게 실행되고 있는지 빠르게 이게 지금 여러분 컴퓨터에서 일어나는 일이에요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `Service`, `Docker`

## 예시
`Service`, `Docker`가 등장하는 설정·코드 위치를 찾아 강의와 같은 순서로 확인한다.
