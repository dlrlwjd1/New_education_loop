# Solution for Error Handling

## 개요
- 이 영역에서 프로세싱을 할 거예요 미들웨어 처리요 다른 중요한 건 뭐가 잘못되든 간에 어디서 오류가 발생하든 간에 어떻게든 그걸 캡처해 Express로 보내야 한다는 겁니다 미들웨어의 오류 처리로 전달될 수 모든 가능한 오류를 캡처하는 게 중요해요 우리의 다양한 요청 처리기 뭔가 잘못될 때마다 Express에 에러를 넘기죠

## 내용
### 자막·본문 기반 핵심 내용
- 이 영역에서 프로세싱을 할 거예요 미들웨어 처리요 다른 중요한 건 뭐가 잘못되든 간에 어디서 오류가 발생하든 간에 어떻게든 그걸 캡처해 Express로 보내야 한다는 겁니다 미들웨어의 오류 처리로 전달될 수 모든 가능한 오류를 캡처하는 게 중요해요 우리의 다양한 요청 처리기 뭔가 잘못될 때마다 Express에 에러를 넘기죠
- Express는 근본적으로 미들웨어에 들어갈 인수의 수를 알고 있어요 4개의 인수가 있는 미들웨어 함수가 있다면 Express는 이것이 다른 루트 처리기 중 하나에서 발생하는 오류를 처리하기 위한 함수라고 추정할 거예요
- 이걸 익스프레스로 연결할 거예요 애플리케이션 내에서 무언가 잘못될 때마다 Express는 공기의 종류를 잡아내서 에어 핸들링 미들웨어로 보내죠
- 이 안에 몇 개의 구역이 있어요 Express 내부의 에러를 처리하기 위한 두 단계 과정이죠
