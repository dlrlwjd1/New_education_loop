# Building an Error Handling Middleware

## 개요
- CRC 디렉터리를 찾아서 그 안에 미들웨어라는 새 폴더를 만들 거예요 그런 다음 Air Dash Hansler TS라는 새 파일을 디렉터리 안에 만들고요

## 내용
### 자막·본문 기반 핵심 내용
- CRC 디렉터리를 찾아서 그 안에 미들웨어라는 새 폴더를 만들 거예요 그런 다음 Air Dash Hansler TS라는 새 파일을 디렉터리 안에 만들고요
- Air, REC, rez 인수를 받게 될 거예요 그런 다음 TypeScript는 이 인수가 뭔지 전혀 모르기 때문에 주석을 적용해야 해요
- 다음은 요청, 객체, 응답 그리고 다음 함수예요 주석을 적용할 수 있어요 요청 유형 응답 유형을 Express에서 다음 함수 유형으로 불러오겠습니다 파일 상단에 있죠
- 요청을 불러오고 Express에서 응답하고 다음 함수 그런 형식들을 해당 인수에 다음 함수, 저장하죠

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `TS`, `TypeScript`, `Express`, `React`
