# Creating Route Handlers

## 개요
- 라우터라는 걸 생성할 거예요 고속 라우터라고 할게요 그런 다음 마지막으로 Router 도깃이라고 하죠 방금 만든 것과 같은 경로예요 API 사용자 부모 사용자요

## 내용
### 자막·본문 기반 핵심 내용
- 라우터라는 걸 생성할 거예요 고속 라우터라고 할게요 그런 다음 마지막으로 Router 도깃이라고 하죠 방금 만든 것과 같은 경로예요 API 사용자 부모 사용자요
- 이 라우트 처리기를 셋업하는 방법은 여러분이 익숙한 것과는 좀 다를 수도 있어요 Express를 보는 것에 익숙하고 Express로 작업하는 것에 익숙하시다면 저희가 하려는 건 아주 약간 다른 걸 할 거예요
- 현재 사용자를 위한 동등한 라우트 처리기를 만들어보죠 현재 사용자 파일로 돌아가겠습니다 맨 위에 Express에서 Express를 불러오기 할게요
- 다른 말로 하면, Express와 인증과 관련된 것들을 많이 쓰게 됩니다. 마이크로 백신과 관련이 없는 것들이죠.

### 구현 요소
