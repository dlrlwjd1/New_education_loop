# Final Error Related Code

## 개요
- 약간 다를 뿐이죠 추상적인 상태 코드 넘버를 작성할 거예요 이 말은 고객을 확장할 경우 status code 속성이 있어야 하고 반드시 숫자가 돼야 여기서 abstract를 쓰죠

## 내용
### 자막·본문 기반 핵심 내용
- 약간 다를 뿐이죠 추상적인 상태 코드 넘버를 작성할 거예요 이 말은 고객을 확장할 경우 status code 속성이 있어야 하고 반드시 숫자가 돼야 여기서 abstract를 쓰죠
- 상태 코드 속성을 구현해야 한다고 말하고 있어요 status code를 넣어 볼게요.
- 번 중 네 번이면 끝나요 인터페이스와 아주 유사하지만 대신 클래스를 사용하죠 그래야 JavaScript 세계로 실제 클래스 정의를 옮길 수 있으니까요
- 클래스를 빌드하고 고객을 확장해요 그럼 TypeScript가 거기서 그걸 인계받죠

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `JavaScript`, `TypeScript`
