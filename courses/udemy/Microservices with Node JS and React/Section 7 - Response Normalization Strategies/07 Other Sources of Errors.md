# Other Sources of Errors

## 개요
- 그건 이메일이 아니잖아요 어느 시점에서 Express Validator를 통해 이메일을 실행할 거예요

## 내용
### 자막·본문 기반 핵심 내용
- 그건 이메일이 아니잖아요 어느 시점에서 Express Validator를 통해 이메일을 실행할 거예요
- 하지만 Express Validator만 오류를 생성하는 건 아닙니다 사용자에게 다시 보내야 할 오류요
- Express 유효성 검사기든 뭐든 간에 모두 이 동일한 구조를 갖도록 해야죠 뭔가 잘못될 수 있는 다른 시나리오를 생각해보죠 응답을 되돌려 보내야 할 경우요 동일한 구조를 갖도록 해야 합니다 ReactApp이 공기를 아주 쉽게 분석할 수 있도록요
- 완전히 무관한 코드예요 Express Validator만이 여기 이 구조의 응답을 보내는 방법을 아는지 우리 코드 내의 다른 많은 곳에서도 동일한 구조를 전송할 수 있어야 목록이 더 있어요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `Express`, `React`

## 예시
`Express`, `React`가 등장하는 설정·코드 위치를 찾아 강의와 같은 순서로 확인한다.
