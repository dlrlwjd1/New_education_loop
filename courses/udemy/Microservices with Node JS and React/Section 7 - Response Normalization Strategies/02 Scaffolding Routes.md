# Scaffolding Routes

## 개요
- 마지막으로 등록하러 가죠 이건 API 사용자에게 게시 요청이 돼야 해요 API 사용자가 등록하는 게시물요

## 내용
### 자막·본문 기반 핵심 내용
- 마지막으로 등록하러 가죠 이건 API 사용자에게 게시 요청이 돼야 해요 API 사용자가 등록하는 게시물요
- API 사용자는 로그인하죠 방법을 바꿔서 반대할 거예요 아래쪽에 있는 라우터 이름도 바꿀게요
- 라우터로 로그인하도록 바꿀게요 이 파일을 저장하고 닫을게요 다음은 퇴실 서류예요 로그아웃 내부에서 이걸 API 사용자로 게시 요청으로 바꿀 거예요
- API 사용자는 로그아웃을 하고요 마지막으로 하단에 라우터 이름을 업데이트할게요 라우터를 로그인하세요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `API`, `Express`

## 예시
`API`, `Express`가 등장하는 설정·코드 위치를 찾아 강의와 같은 순서로 확인한다.
