# How to Define New Custom Errors

## 개요
- 묶인 게 아니에요 다 된 것 같네요 이 에어를 던질 때마다 다른 말로 하자면 라우트 처리기에 있는데 not found나 new를 던질 때죠

## 내용
### 자막·본문 기반 핵심 내용
- 묶인 게 아니에요 다 된 것 같네요 이 에어를 던질 때마다 다른 말로 하자면 라우트 처리기에 있는데 not found나 new를 던질 때죠
- Status code는 404죠 그런데 그걸 추가하지 않았다면 TypeScript가 추가하라고 할 거예요
- 저장하고 빠르게 테스트해보죠 골대로 돌아가요 존재하지 않는 루트로 가려고 해요 API 사용자로 가서 등록하고 슬래시 같은 걸 하죠 이걸 get 요청에만 설정했어요
- 파일 생성, 클래스 생성 내보내기, 고객 확장하기요 TypeScript는 여러분이 여기서 정의해야 할 것에 대한 가이드예요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `TypeScript`, `API`, `Express`
