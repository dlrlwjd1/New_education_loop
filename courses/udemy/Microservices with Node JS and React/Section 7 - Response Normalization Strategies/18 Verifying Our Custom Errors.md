# Verifying Our Custom Errors

## 개요
- 인터페이스를 JavaScript로 전환하면 모든 인터페이스는 사라지죠 JavaScript 세계에 실제로 존재하진 않지만 abstract 클래스는 있어요

## 내용
### 자막·본문 기반 핵심 내용
- 인터페이스를 JavaScript로 전환하면 모든 인터페이스는 사라지죠 JavaScript 세계에 실제로 존재하진 않지만 abstract 클래스는 있어요
- Custom Air라는 새로운 추상 클래스를 만들 거예요 abstract 클래스는 우리가 방금 본 인터페이스와 정확히 같은 목적을 수행할 거예요
- 그 안에 Custom Air라는 인터페이스를 정의하죠 이 사용자 지정 공기 인터페이스 안에서 사용자 지정 공기의 의미를 정의해보죠
- 간단히 말해서 인터페이스를 정의하고 클래스가 구현하게 하는 대신 Custom Air라는 클래스를 정의하고 요청 유효성 검사와 데이터베이스 연결 에러를 추상화 클래스를 확장하세요

### 구현 요소
- 강의에서 직접 언급하거나 사용하는 요소: `TypeScript`, `JavaScript`

## 예시
`TypeScript`, `JavaScript`가 등장하는 설정·코드 위치를 찾아 강의와 같은 순서로 확인한다.
