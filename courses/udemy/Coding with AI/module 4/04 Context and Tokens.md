# Context and Tokens

## 개요
- **컨텍스트(context)** 는 AI 코딩뿐 아니라 AI 전반에서 **가장 중요한 개념**.
- 이해 못 하면 "왜 5분 전 말을 잊었지?", "왜 내 코드 패턴을 안 따르지?" 하며 좌절하게 됨.
- 핵심: **컨텍스트 = AI의 단기 기억(short-term memory)**, **토큰(tokens) = 그 측정 단위(통화)**.

## 내용

### 컨텍스트란
- **AI가 특정 순간에 볼 수 있고 기억하는 모든 것** = 단기 기억.
- 비유(영화 *50 First Dates*): 매일 백지에서 시작하는 기억 — **컨텍스트가 클리어되면 사라진다.**
- **컨텍스트 윈도(context window)** 에 담기는 것:
  - 대화 메시지
  - 참조한 파일들
  - 시스템 지시(system instructions)
  - AI 자신의 응답
- 새 대화를 시작(예: ChatGPT의 New chat)하면 **백지** — 내가 누군지, 무슨 프로젝트인지, 어제 뭘 말했는지 모름(컨텍스트 윈도 안이 아니면).

### 왜 중요한가
- 실제 프로젝트엔 수많은 파일·설계 결정·의존성·코딩 패턴이 있는데, **명시하지 않으면 AI는 아무것도 모름**.
- 예: "이 컴포넌트에 삭제 버튼 추가"라 하면, 어떤 컴포넌트인지·무슨 프레임워크인지·기존 코드가 어떤지 몰라서 **추측** → 프로젝트에 안 맞을 수 있음.

### 컨텍스트 엔지니어링(Context Engineering)
- **필요한 정보를 전략적으로 AI에 공급**하는 실천 — 단순 프롬프팅을 넘어 **AI가 아는 것을 관리**.
- 프롬프팅(개별 프롬프트에 충분한 정보) vs 컨텍스트(진행 중 프로젝트 전체의 큰 그림) — 후자가 더 복잡.
- **좋은 소식: 상당 부분 자동화 가능** → `CLAUDE.md` 같은 파일의 역할 (곧 생성).
  - 도구별 컨텍스트 파일 이름이 다름:
    - **Claude Code**: `CLAUDE.md`
    - **Cursor**: rules 폴더
    - **Codex**: `AGENTS.md`
  - 모든 에이전틱 AI에 이 기능이 있고 이름만 다름 (모르면 챗봇에 물어보면 됨).
  - 코드 규칙·AI 상호작용 방식·기술 스택 등을 이 파일(또는 링크된 파일)에 넣으면, **시작 시 자동 인지** → 매번 반복 지시 불필요.

### 토큰(Tokens)
- 컨텍스트 윈도와 API 가격의 **측정 단위 = 컨텍스트의 통화**.
- 단어도 문자도 아닌 **그 중간** — 보내는 모든 것을 토큰으로 쪼갬.

### 가격(Pricing) — 구독 vs API
- **구독(subscription)**: Claude Code·Cursor·Codex 등. 일정 시간(예: 5시간)마다 할당량 배분 → **토큰 초과로 추가 과금 걱정 없음**. (이 코스가 이 방식.)
- **프로젝트에서 AI 사용(API)**: 사용량만큼 과금. 예: 강사의 VidPipe(유튜브 → SEO 글) 프로젝트는 글 1건당 5~10센트.
- **API 가격 예시(GPT-5.1, 100만 토큰당)**:
  - Input $1.25 / Cached input $0.125 / Output $10.
  - mini·nano 등 저렴한 모델도 있음 → **단순 작업엔 저렴한 모델**, 품질 필요하면 비싼 모델.
  - Claude는 GPT보다 대체로 조금 더 비쌈.
- 우리가 빌드할 SaaS에도 AI를 넣으므로 이 개념이 필요.

## 요약
- **컨텍스트 = AI의 단기 기억**: 대화·참조 파일·시스템 지시·AI 응답이 **컨텍스트 윈도**에 담기고, 클리어되면 사라짐.
- 명시 안 하면 AI는 프로젝트를 모르고 **추측**함 → **컨텍스트 엔지니어링**으로 필요한 정보를 전략적으로 공급.
- 자동화 수단 = **`CLAUDE.md`**(Cursor=rules, Codex=AGENTS.md) — 규칙·스택·상호작용 방식을 넣어 시작 시 자동 인지.
- **토큰 = 컨텍스트/가격의 단위**. 구독은 추가 과금 걱정 없음, 프로젝트 내 API 사용은 사용량 과금(모델별 가격 차이).
