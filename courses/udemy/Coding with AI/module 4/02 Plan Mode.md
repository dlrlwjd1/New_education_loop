# Plan Mode

## 개요
- **Plan mode**: 코드를 **편집·작성하지 않고** 계획만 세우는 모드. 계획은 **마크다운 파일**로 만들어짐.
- 특정 기능을 계획하거나, **추가할 새 기능을 발굴**할 때 유용.
- 강사의 사용 습관: 단일 기능 계획은 직접 + ChatGPT/claude.ai로 하고, plan mode는 주로 **프로젝트를 스캔해 새로운 걸 제안**받는 데 사용.

## 내용

### 진입 방법
- **Shift+Tab** 1회 → Accept Edits On, **2회 → Plan mode**.

### 동작 예시 (joke 스크립트 개선)
- 프롬프트: "이 joke 스크립트를 더 인터랙티브하고 흥미롭게 만들 제안을 해줘."
- Claude가 파일을 찾아 읽고(큰 코드베이스일수록 **시간·토큰↑** — 토큰은 곧 다룸), 일반 에이전트 모드와 **다른 포맷**으로 제안 작성.
- 계획 파일 저장 위치: **`.claude/` 폴더의 `Plans/`** 안에 마크다운 파일로 생성.
  - `.claude`는 홈 디렉토리의 **글로벌 폴더**일 수도, **프로젝트별 폴더**일 수도 있음.

### 제안 선택
- 제안 목록 예: Menu System, Joke Categories(API가 카테고리 지원), Colors & ASCII Art, Favorite System.
- 선택지: 전부 / 기본만 / 일부. 원하는 조합이 없으면 **직접 타이핑**해 지정 가능 (예: Colors + ASCII Art + Menu System).
- 토큰 사용량이 표시됨.

### 계획 → 실행
- Claude가 **계획(마크다운)** 을 갱신: Features to Add, Implementation Steps 등. (아직 코드 아님.)
- 하단에서 "진행할까요?" 물음 → **yes 하면 plan mode를 빠져나와 에이전트(일반) 모드로 전환**하고 변경을 구현.
- ⚠️ **주의**: yes 시 **Accept Edits가 켜짐**. 원치 않으면 이후 **다시 꺼야** 함 — 항상 켜짐 여부를 인지할 것.
- 구현 시 to-do 리스트를 만들고, diff(초록=추가)로 변경을 보여줌 (색상 상수, 카테고리 목록, 메뉴 시스템 등).

### 결과
- joke 스크립트가 헤더·컬러·카테고리 메뉴 등으로 훨씬 인터랙티브해짐.

## 요약
- **Plan mode**(Shift+Tab ×2) = 코드 안 건드리고 **마크다운 계획만** 생성 (`.claude/Plans/`).
- 프로젝트 스캔 → **새 기능 제안** 받기에 좋음. 제안은 조합 선택·직접 타이핑 가능.
- yes로 진행하면 **에이전트 모드로 전환되어 구현** — 이때 **Accept Edits가 켜지니** 필요 없으면 다시 끌 것.
- 계획 단계라도 파일 읽기에 **토큰이 소모**됨 (다음 주제).
