# Persistent Memory Update

## 개요
- 녹화 이후 **Claude Code 업데이트**로 지난 강의(컨텍스트 관리)의 동작이 달라진 것을 설명하는 보충 강의.
- 지난 강의에선 `/clear` 후 단어를 **잊었지만**, 최신 버전에선 **기억함** → 혼란 방지용 설명.
- 핵심: 이제 명시적으로 "기억해"라고 하면 **영구 메모리 파일(persistent memory file)** 에 저장됨.

## 내용

### 무엇이 바뀌었나
- 이전: "기억해" → `/clear` 하면 **깨끗이 지워짐**.
- 현재: **명시적으로 기억을 요청**하면 **영구 메모리 파일에 저장** → `/clear` 해도 유지.
- `/clear` 자체는 여전히 **컨텍스트/대화를 지우고 토큰을 확보**. 차이점은 이제 **특정 항목을 메모리에 영속화**할 수 있다는 것.

### 동작 데모
- "remember the word color" → 응답이 달라짐: "메모리에 저장합니다 (recalling one memory)" — 이전엔 없던 동작.
- `/clear` 후 "무슨 단어?" → 여전히 **color를 기억**.

### 메모리 파일 위치
- **홈 디렉토리의 `~/.claude/`** (프로젝트의 `.claude`가 아님).
- 경로: `~/.claude/projects/<프로젝트 폴더>/memory/`
  - Claude를 특정 폴더에서 쓰면 그 폴더에 대응하는 **project 폴더**가 생김 (예: `Test Project`).
  - 그 안에 **`memory/`** 폴더, 그리고 **`memory.md`** = 기억한 것들의 **인덱스**.
  - `memory.md`는 개별 파일(예: `user-remembered-word`)을 가리키고 설명("user asked to remember the word color")을 담음.
  - 개별 파일엔 프론트매터(description) + 내용이 있음.

### 삭제하면
- 메모리 폴더/프로젝트 폴더를 지우면 → Claude 재시작(exit 후 재진입) 후 "무슨 단어?" → **모름** (영구 메모리에서 사라짐).

### 모델 업데이트
- **Opus 4.6** 출시 → 4.5 대신 **4.6 사용 권장**.

## 요약
- 업데이트로 이제 **명시적 "기억해" 요청은 영구 메모리 파일에 저장**되어 `/clear` 후에도 유지.
- 저장 위치 = **`~/.claude/projects/<프로젝트>/memory/`** (인덱스 `memory.md` + 개별 파일).
- `/clear`는 여전히 컨텍스트/토큰을 비움 — 영구 메모리와는 별개.
- **Opus 4.6** 출시 → 사용 권장.
