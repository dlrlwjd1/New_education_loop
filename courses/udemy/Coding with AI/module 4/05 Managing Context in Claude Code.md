# Managing Context in Claude Code

## 개요
- 앞서 배운 컨텍스트·토큰을 **Claude Code에서 실제로 관리**하는 법.
- 핵심 도구: **`/context`**(사용량 확인), **`/clear`**(초기화), **`/compact`**(요약 압축).
- 강사의 전략: **기능 단위(feature by feature)로 작업 + 각 작업 전 컨텍스트 클리어**.

## 내용

### `/context` — 사용량 확인
- 현재 컨텍스트/토큰 사용을 시각화 (몇 초만 화면에 뜸 → 스크린샷 추천).
- 자주 실행하게 됨 (`/clear`와 함께). **항상 내 토큰 위치를 파악**하기 위함.
- Opus 4.5 = **200,000 토큰 할당**. (Sonnet 1M 옵션도 있으나 컨텍스트가 너무 커 혼란 + Opus보다 성능↓ → Opus 유지.)

### 시작하자마자 쓰이는 ~20,000 토큰 (baseline)
아무 코드도 안 썼는데 이미 소모됨:
- **System prompt** (~2,800) — Claude 행동 지침, Anthropic이 심어둠·제어 불가.
- **System tools** (~16,700) — 파일 읽기/쓰기, 명령 실행, 코드베이스 검색 등 내장 기능.
- **Messages** (~8) — 방금 실행한 명령 등.
- **Compact buffer** (~3,000) — auto compact용 버퍼.
- **Free space** — 나머지(예: 177,000 / 88.7%).

### 파일 참조로 컨텍스트 절약
- 예: "`@joke.py`의 colors·categories를 `config.py`로 옮겨라."
- **`@파일명`** 으로 파일을 컨텍스트에 넣으면, AI가 코드베이스 전체를 뒤지지 않아 **컨텍스트 절약**.
  - `@` 없어도 찾긴 하지만, 파일이 많으면 검색에 컨텍스트를 더 씀 → 명시가 유리.
- 작업 후 `/context` 확인 → 간단한 작업인데도 messages가 늘어남(예: 20K → 23K).
- 교훈: **200,000 토큰은 생각보다 빨리 소진** → 위치를 계속 추적할 것.

### 컨텍스트 초기화 — `/clear`
- 강사의 초기 실수: **컨텍스트를 안 지워서** AI가 방금 한 일도 잊는 좌절.
- 데모: "이 단어 기억해: read" → "무슨 단어?" → "read" → **`/clear`** → "무슨 단어?" → "모르겠음."
  - *50 First Dates*처럼 새 날 = 기억 리셋.
- `/clear` 후 `/context` → **baseline(~20,000)** 로 복귀.
- **전략**: 한 번에 한 작업만 집중, 각 **기능 전에 clear**, 기능 완료 후에도 clear → 200K 근처도 안 감.

### 압축 — `/compact`
- 컨텍스트를 다루는 두 방법: **clear**(강사 선호) 또는 **compact**.
- `/compact` = 대화 전체를 **요약해 컨텍스트에 넣음** → 전부가 아니라 요약본만 보유.
- baseline까지 내려가진 않지만 상당히 확보. auto compact 옵션도 있으나 강사는 수동 선호.
- **경고 구간**: 150,000 토큰에 가까워지면 **성능이 떨어지기 시작** → 그 전에 clear 또는 compact.
- 강사는 compact를 잘 안 쓰고 **기능 단위 진행 + 완료 후 clear** 선호.

### CLAUDE.md 예고
- **시작 시 로드되는 메모리/컨텍스트**.
- CLAUDE.md에 내용이 많을수록 **시작 시 토큰↑**.
- 프로젝트 정보 + AI와의 상호작용 방식·규칙을 담음 (곧 다룸).

## 요약
- **`/context`** 로 사용량 수시 확인 — Opus는 **200K 한도**, 시작만 해도 **~20K(system prompt + tools)** 소모.
- **`@파일명`** 으로 관련 파일을 명시해 컨텍스트 절약.
- **`/clear`** 로 초기화(baseline 복귀) — 강사 전략 = **기능 단위 + 작업 전후 clear**.
- **`/compact`** 는 요약 압축(baseline까진 아님). **150K 근처부터 성능 저하** → 그 전에 정리.
