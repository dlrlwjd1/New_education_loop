# Levels of AI Assistance

## 개요
- 소프트웨어 개발에서 AI 지원은 **binary(쓴다/안 쓴다)가 아니라 스펙트럼**이다.
- 강사가 경험에 기반해 만든 **레벨 1~5** — 위로 갈수록 AI 사용↑, **속도↑ 이해·통제↓**.
- 각 레벨의 위치를 알면 작업에 맞는 도구를 고를 수 있다. 이 코스는 주로 **레벨 3(대화형/에이전틱)** 에 위치.

## 내용

### 핵심 트레이드오프
- 사다리를 오를수록(AI 사용 증가) → **속도(speed) 증가**, **이해(understanding)·통제(control) 감소**.

### Level 1 — 자동완성 (Tab Completion / Autocomplete)
- 코드 대부분을 **직접** 작성, AI는 다음 줄 제안(탭으로 채움) — **수동적 AI(passive AI)**.
- 속도는 낮지만 **이해·통제는 완전(full)**. 아키텍처를 직접 결정.
- 도구: **GitHub Copilot**, Tabnine, VS Code IntelliSense, Codium.

### Level 2 — 인라인 AI (Inline AI)
- 코드를 하이라이트해서 변경 요청·설명 요청 — 채팅 인터페이스가 아니라 **코드에 통합**됨.
- 속도 조금 빠름, 이해·통제 양호. 방향은 **내가 안내(guide)**.
- 도구: **Cursor, Windsurf** (상위 레벨에도 사용 가능).

### Level 3 — 대화형 / 에이전틱 AI (Conversational / Agentic AI) ⭐ 이 코스의 중심
- **스위트 스팟(sweet spot)**: 속도를 얻으면서도, 제대로 하면 이해·통제 유지.
  - "제대로" = **리뷰·테스트·큰 의사결정을 내가 함**.
- 비유: **나는 아키텍트(architect), AI는 빌더(builder)**. 내가 계획·데이터 모델을 만들고 AI가 코드를 작성.
- 제대로 하려면: **컨텍스트 파일 + 커스텀 커맨드 + 서브에이전트** 등 (= 이 코스에서 하는 것).
- 도구: **Claude Code**, Codex, (CLI 계열), 그리고 에이전틱 기능을 가진 Cursor·Windsurf·Kiro.

### Level 4 — 목표 위임 (Autonomous Agents)
- 매우 빠름. 단, 과정에 거의 관여하지 않고 **결과만 사후 리뷰**.
- 알지만 하기 싫은 **반복적·지루한 작업 아웃소싱**에 유용.
- 목표만 설정 → AI가 다 하고 → 결과 리뷰(어느 정도 통제·이해 유지).
- 도구: **Devin, AutoGPT, Smol Developer** (강사는 사용 경험 거의 없음).

### Level 5 — 바이브 코딩 / 원샷 (Vibe Coding / One-shotting)
- "바이브"에 맡겨 **앱 전체를 한 번에 생성**. 속도 최고, **이해·통제는 사실상 0**.
- AI가 모든 메서드·데이터 모델을 선택, 파일조차 안 보는 경우 많음.
- ⚠️ **프로덕션 프로젝트엔 비추천**. **프로토타이핑(prototyping)** 에 유용:
  - 아이디어 검증용 빠른 UI, 팀 공유용, 머릿속 아이디어 시각화.
  - 코드는 형편없을 수 있으나 아이디어를 얻은 뒤 → 스크린샷을 Claude/Cursor에 넣어 레벨 1~3으로 다시 제대로 빌드.
- 도구: **Lovable, Bolt, V0**.

### 강사의 선호 도구
- 상위 픽: **Claude Code > Codex > Cursor**. **Gemini 3**도 매우 좋음.

## 요약
- AI 지원은 **스펙트럼(레벨 1~5)**, 위로 갈수록 속도↑·이해/통제↓.
- L1 자동완성(Copilot) → L2 인라인(Cursor/Windsurf) → **L3 에이전틱(Claude Code) = 코스 중심·스위트 스팟** → L4 자율 에이전트(Devin) → L5 바이브 코딩(Lovable/Bolt/V0).
- 레벨 3의 원칙: **나는 아키텍트, AI는 빌더** — 리뷰·테스트·큰 결정을 내가 쥐고 컨텍스트·커스텀 커맨드·서브에이전트를 활용.
- 바이브 코딩(L5)은 **프로토타이핑엔 OK, 프로덕션엔 부적합**.
