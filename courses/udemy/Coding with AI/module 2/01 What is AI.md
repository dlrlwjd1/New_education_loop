# What is AI

## 개요
- 본격적으로 AI 코딩을 시작하기 전, **AI란 무엇인가**에 대한 고수준 개요.
- 깊은 이론은 다루지 않고, 알아야 할 용어와 큰 그림 위주.
- 핵심: 우리가 쓰는 AI 도구는 **LLM(대규모 언어 모델)** 기반이고, 이는 본질적으로 **예측 기계(prediction machine)** 다.

## 내용

### AI의 3가지 주요 범주
**AI(Artificial Intelligence, 인공지능)** = 보통 인간 지능이 필요한 작업을 수행하는 기계에 대한 broad term. 요즘은 주로 아래 셋 중 하나를 의미.

1. **컴퓨터 비전(Computer Vision)** — 이미지·영상의 시각 정보를 해석·분석.
   - 예: 얼굴/이미지 인식, 자율주행 감지, 의료 영상(medical imaging).
2. **예측 AI(Predictive AI)** — 과거 데이터(historical data)를 분석해 예측.
   - 예: Netflix 추천, 사기 탐지(fraud detection), 주가 예측, 날씨 예측.
3. **생성 AI(Generative AI)** — 분석/예측을 넘어 **새로운 콘텐츠를 생성(creating)**. 요즘 "AI"라 하면 대개 이것 (ChatGPT가 대표).
   - 예: 텍스트, 이미지, **코드**(Cursor·Copilot 등 — 이 코스), 오디오/음성(ElevenLabs), 음악(Suno), 영상(Sora).

### LLM(Large Language Model)이란
- 우리가 쓰는 도구의 기반. 본질은 **패턴 매처(pattern matcher) · 예측 기계**.
- 방대한 텍스트(수십억 웹페이지, 책, 논문, 코드 저장소)로 학습해 **텍스트의 패턴**을 배움.
- 프롬프트를 주면, 학습한 모든 것을 바탕으로 **다음에 올 텍스트를 예측**할 뿐.
- ⚠️ 기계 안의 "의식 있는 존재"가 아니다 — 매우 정교한 패턴 매처일 뿐 (적어도 아직은).

### LLM 학습 과정 (단순화)
1. **사전학습(Pre-training)** — 인터넷·책·코드 등 방대한 텍스트를 흡수. 언어 패턴, 사실, 추론 구조, 코딩 문법을 학습. **가장 비싼 단계**(막대한 연산·컴퓨팅 파워).
2. **파인튜닝(Fine-tuning)** — 베이스 모델을 특정 작업에 맞게 다듬음. 지시 따르기, 응답 포맷팅 학습.
3. **RLHF(Reinforcement Learning from Human Feedback, 인간 피드백 기반 강화학습)** — 사람이 모델 응답을 평가(도움됨/안 됨) → 모델이 더 나은 출력을 학습. ChatGPT·Claude가 **랜덤 텍스트가 아니라 도움되는 느낌**을 주는 큰 이유.

### LLM이 잘하는 것
- 개념을 쉬운 말로 설명, 글쓰기·편집, **코드 생성**, 질문 답변, 브레인스토밍, 번역, 긴 문서 요약, 복잡한 지시 따르기.

### 단점 & 오해 (완벽하지 않음)
- **환각(Hallucinate)** — 그럴듯하지만 틀린 정보를 자신 있게 지어냄. 코딩에서는 **존재하지 않는 API 메서드**를 발명하거나, 없는 논문 인용, 겉보기 멀쩡하지만 미묘한 버그가 있는 코드 제공.
- **실제로 아무것도 "알지" 못함** — 확인할 사실 데이터베이스가 없음, 전부 패턴. 패턴이 대개 정확한 정보를 내지만 항상은 아님.
- **대화 중 학습 불가** — 대화에서 교정해주면 그 대화 내에서는 고칠 수 있지만, LLM의 **코어에 반영되지 않음** (학습은 사전학습 때만).
- **지식 컷오프(knowledge cutoff)** — 특정 날짜까지의 데이터로 학습, 그 이후는 모름 (웹 검색 접근 없으면).
- **인간처럼 추론하지 않음** — "생각"처럼 보여도 여전히 패턴 매칭. 인간의 논리와 다름 → 때로 훌륭하지만 때로 이상한 방식으로 실패.

### 주요 플레이어(Key Players)
- **OpenAI** — ChatGPT / GPT 시리즈
- **Anthropic** — Claude
- **Google** — Gemini
- **Meta** — Llama
- 이 코스의 메인 프로젝트는 **Claude Opus 4.5** 사용 (시청 시점엔 더 새 모델이 있을 수 있음 — 모델은 계속 좋아지는 중).

## 요약
- AI의 3대 범주: **컴퓨터 비전 / 예측 AI / 생성 AI** — 요즘 "AI"는 대개 **생성 AI**.
- 우리 도구의 기반 = **LLM = 다음 텍스트를 예측하는 정교한 패턴 매처** (의식 있는 존재 아님).
- 학습 3단계: **사전학습 → 파인튜닝 → RLHF**.
- 강점: 설명·글쓰기·코드 생성·요약·번역 등. 약점: **환각, 지식 없음, 대화 중 학습 불가, 지식 컷오프, 인간식 추론 아님**.
- 주요 플레이어: OpenAI(GPT) · Anthropic(Claude) · Google(Gemini) · Meta(Llama). 코스는 Claude Opus 4.5 사용.
