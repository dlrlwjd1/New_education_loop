# Prototyping with V0 — Markdown Notes App

## 개요
- 브라우저 claude.ai(고수준)에서 이제 **V0 / Bolt / Lovable** 같은 프로토타이핑 플랫폼으로 한 단계 이동. (이후 Claude Code로 더 깊이 들어감.)
- DevStash(메인 앱)는 아직 시작 안 함 — 간단한 **마크다운 노트 앱**을 프로토타입.
- 프로토타이핑에선 여러 기능을 한 프롬프트에 몰아넣지만, 실제 앱(Claude Code)에선 **기능당 하나의 프롬프트/문서 + 커맨드 워크플로**로 진행할 것.

## 내용

### 도구 & 준비
- 강사는 **V0** 사용 (Bolt·Lovable·Base44 등 아무거나 OK, **무료 티어면 충분**).
- 프롬프트는 앱에 바로 치지 않고 **마크다운 에디터**에 작성 후 붙여넣기 (Mac: MacDown, Windows: Typora — 둘 다 무료).
- 리소스 repo `prompts/`에 **프로토타입 예시 프롬프트 + 기본 템플릿** 제공 → 복사해 기능만 교체.

### 작성한 프롬프트 (마크다운 노트 앱)
> 💡 첫 줄에 **"프로토타입"임을 명시** — 프로덕션 앱으로 착각하지 않게.

**Features**
- 노트 생성/편집/삭제
- **라이브 마크다운 프리뷰** — split view (에디터 왼쪽, 프리뷰 오른쪽)
- 로컬 스토리지 **자동 저장 + 디바운싱(debouncing)** (저장 전 약간의 지연)
- 사이드바에 모든 노트 표시 (제목 + 날짜)
- 노트 필터링 **검색 기능**
- **다크/라이트 모드 토글**

**Technical**
- React, **함수형 컴포넌트 + 훅** (클래스 쓰지 않도록 명시)
- **react-markdown** 패키지 (프리뷰 렌더링)
- 반응형, 깔끔·모던 UI, **Tailwind v4**

**Structure**
- 💡 **UI를 별도 컴포넌트로 분리** — AI는 흔히 거대한 단일 파일(monolithic)에 다 몰아넣으므로, **파일 분리·컴포넌트 캡슐화**를 반드시 지시.

### 결과 검증
- 생성에 3~4분 소요. 요구사항과 대조:
  - 생성/편집/삭제 ✅, 다크/라이트 토글 ✅, split 에디터(프리뷰/에디터) ✅.
  - 새 노트 생성 시 타이핑하는 대로 **프리뷰 실시간 렌더링**, **Save 버튼 없이 자동 저장** ✅.
  - 노트 제목 변경 → 사이드바에도 반영 ✅.
  - 검색 필터 동작 ✅ (본문에 포함된 단어도 매칭).
- 반응형은 split view 특성상 다소 애매 (프리뷰 토글/탭 방식으로 개선 여지) — 어차피 **안 쓸 코드라 깊게 수정 안 함**.

### 프로토타입의 위치
- 이 코드는 **보관·사용하지 않음** — UI를 띄워 룩앤필을 확인하는 용도.
- 다음 강의: V0가 생성한 **코드를 살펴봄** (보관하진 않지만 이런 도구가 뭘 만드는지 확인).

## 요약
- claude.ai → **V0(또는 Bolt/Lovable)** 로 프로토타이핑 단계 이동, 간단한 마크다운 노트 앱 생성.
- 프롬프트는 **에디터에 따로 작성** + **"프로토타입"임을 명시** + **features / technical / structure** 구성.
- 꼭 넣을 지시: **함수형 컴포넌트**, **컴포넌트 파일 분리**(monolithic 방지).
- 생성 후 **요구사항 대조** 검증. 프로토타입 코드는 보관하지 않고 룩앤필 확인용.
