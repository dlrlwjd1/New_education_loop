# Dashboard UI Phase 3 Spec

> 원문 [dashboard-phase-3-spec.md](dashboard-phase-3-spec.md)의 한국어 번역본입니다.

## 개요 (Overview)

이 문서는 대시보드(dashboard) UI 레이아웃 3단계 중 3단계(phase 3)입니다. 어떻게 보여야 하는지는 아래에서 참조하는 스크린샷을 사용하세요. 데이터는 아래에서 참조하는 목업 데이터(mock data) 파일의 데이터를 사용하세요. 데이터베이스(database)를 구현하기 전까지는 지금은 그냥 직접 import 하세요.

## 3단계(phase 3) 요구사항

- 오른쪽 메인 영역
- 최근(recent) 컬렉션
- 고정된(pinned) 항목
- 최근 항목 10개
- 항목 수, 컬렉션 수, 즐겨찾는(favorite) 항목 수, 즐겨찾는 컬렉션 수를 나타내는 상단 통계(stats) 카드 4개 (스크린샷에는 없음)
