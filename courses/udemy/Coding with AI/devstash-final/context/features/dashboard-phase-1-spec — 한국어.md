# Dashboard UI Phase 1 Spec

> 원문 [dashboard-phase-1-spec.md](dashboard-phase-1-spec.md)의 한국어 번역본입니다.

## 개요 (Overview)

이 문서는 대시보드(dashboard) UI 레이아웃 3단계 중 1단계(phase 1)입니다. 어떻게 보여야 하는지는 아래에서 참조하는 스크린샷을 사용하세요.

## 1단계(phase 1) 요구사항

- ShadCN UI 초기화 및 컴포넌트(components)
- ShadCN 컴포넌트 설치
- /dashboard 경로(route)의 대시보드
- 메인 대시보드 레이아웃 및 전역 스타일(global styles)
- 기본값으로 다크 모드(dark mode)
- 검색(search)과 새 항목(new item) 버튼이 있는 상단 바(top bar) (표시 전용)
- 사이드바(sidebar)와 메인 영역용 자리표시자(placeholder). 지금은 "Sidebar"와 "Main"이라는 h2만 추가하세요.
