- 처리 상태: **대본 없음 — 사용자 요청으로 추가 정리 생략(2026-09-06).** 현재 화면 기반 부분 정리만 보관하며, 추가 작업 대상으로 세지 않는다.
- ROS 2가 다루려는 요구사항을 영상 슬라이드에서 확인했다.
- 자막·대본은 없지만 화면에서 읽을 수 있는 핵심 내용으로 보완했다.

## 내용

### ROS 2의 요구사항

1:08과 4:47의 슬라이드는 다섯 항목을 제시한다.

| 화면 원문 | 의미 |
|---|---|
| Unreliable Networks | 불안정한 네트워크 |
| Fleet of Robots | 다중 로봇 운용 |
| Embedded Platforms | 임베디드 플랫폼 |
| Secure Communication | 보안 통신 |
| Realtime Systems | 실시간 시스템 |

### 영상의 시각적 예시

2분대에는 컴퓨터와 여러 이동 로봇의 유·무선 연결을, 3:07에는 Arduino와 서보·모터 및 직렬 연결을 보여준다. 3:56에는 여러 로봇의 통신에 자물쇠 아이콘을 더해 보안 요구를 표현한다.

초반 연혁 슬라이드에는 Willow Garage, ROS 배포, OSRF, ROS 2, NASA의 ROS 2 적용 사례가 나온다. 화면의 연도 표기를 별도 검증한 기술사 사실로 일반화하지 않고 이 강의의 배경 소개로 읽는다.

## 예시

- 다중 이동 로봇과 중앙 컴퓨터의 통신 그림 → 다중 로봇·네트워크 요구.
- Arduino와 모터 그림 → 임베디드 장치 연동 요구.
- 무선 신호와 자물쇠 그림 → 보안 통신 요구.

확인한 주요 화면에는 실행 명령이나 코드가 나오지 않는다.
