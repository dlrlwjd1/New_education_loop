# ROS 2 Architecture

## 개요
ROS 2의 아키텍처는 기존의 ROS와 달리 개선되어 개발자들에게 더 강력하고 사용하기 쉬운 경험을 제공하도록 설계되었습니다.

- 원본: [Udemy 강의](https://www.udemy.com/course/computer-science-robotics-learn-by-doing-linux-to-ros-2/learn/lecture/49933251#overview)

## 내용
### DDS Middleware
ROS 2의 핵심은 DDS(Real-Time Data Distribution Service) 미들웨어입니다. 이 미들웨어는 노드와 로봇에서 실행되는 애플리케이션 간 메시지 교환이 주된 역할을 합니다.

#### DDS의 특징
- **노드 발견**: DDS는 노드를 자동으로 찾습니다.
- **메시지 직렬화**: 메시지를 효율적으로 직렬화하여 네트워크 전송이 가능합니다.
- **전송**: 다양한 환경에서 안정적이고 빠른 통신을 제공합니다.

#### DDS의 활용 분야
- 금융, 항공 우주, 기차 교통 등 다양한 분야에서 사용됩니다.

### ROS 2의 구조
ROS 2는 DDS 미들웨어를 기반으로 설계되었습니다. 이 미들웨어는 노드 간 메시지 교환이 주된 역할을 합니다.

#### Ros Client Library (RCL)
Ros 2의 핵심 로직과 기능은 Ros Client Library (RCL)이라는 레이어에 구현되어 있습니다. RCL은 C와 C++로 작성되며, 모든 ROS 기능을 포함하고 있으며 개발자들이 로봇 애플리케이션을 개발할 수 있도록 노출됩니다.
