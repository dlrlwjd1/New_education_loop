# [LAB] ros2 service CLI

## 개요
이 강의에서는 ROS 2 서비스를 관찰하고 실행하는 방법을 학습합니다. 주로 `ros2 service` 명령어를 사용하여 서비스 서버와 클라이언트를 시작하고, 서비스 정보를 확인하며, 서비스 호출을 수행하는 과정을 다룹니다.

- 원본: [Udemy 강의](https://www.udemy.com/course/computer-science-robotics-learn-by-doing-linux-to-ros-2/learn/lecture/53437671#overview)

## 내용
### 서비스 서버 시작하기
1. **서비스 서버 노드 실행**
   - 새로운 터미널을 열고 `ros2 run demo_nodes_cpp add_two_ints_server` 명령어를 사용하여 서비스 서버 노드를 실행합니다.
   - 이 노드는 두 숫자의 합을 계산하는 서비스 서버를 구현하고 있습니다.

### 서비스 목록 확인
1. **서비스 목록 조회**
   - 새로운 터미널을 열고 `ros2 service list` 명령어를 사용하여 현재 시스템에서 제공 가능한 모든 서비스를 확인합니다.
   - 기본적으로 실행한 노드는 단순한 서버 노드이지만, 많은 다른 서비스가 이미 시스템에 존재하고 있습니다.

### 서비스 정보 확인
1. **서비스 정보 조회**
   - `ros2 service info /add_two_ints` 명령어를 사용하여 `/add_two_ints` 서비스의 구체적인 정보를 확인합니다.
   - 이 서비스는 `Add2` 인터페이스를 사용하며, 요청 메시지에는 두 개의 정수가 포함되어 있으며, 응답 메시지는 두 숫자의 합을 나타냅니다.

### 서비스 호출하기
1. **서비스 호출**
   - 새로운 터미널을 열고 `ros2 service call /add_two_ints "a: 5 b: 3"` 명령어를 사용하여 `/add_two_ints` 서비스를 호출합니다.
   - 이 명령어는 요청 메시지에 `a: 5`와 `b: 3`을 포함하고 있으며, 서버가 이를 처리하여 두 숫자의 합인 8을 응답합니다.

### 서비스 클라이언트 시작하기
1. **서비스 클라이언트 노드 실행**
   - 새로운 터미널을 열고 `ros2 run demo_nodes_cpp add_two_ints_client` 명령어를 사용하여 서비스 클라이언트 노드를 실행합니다.
