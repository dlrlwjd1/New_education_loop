# Why a Robot Operating System?

## 개요

1. **로봇 운영 체제의 중요성**
   - 로봇 연구자와 최첨단 기업들이 선택하는 기본 프레임워크로 자리잡았습니다.
   - 강력하고 유연한 도구로서 고급 로봇을 구축하는데 필수적입니다.

2. **로봇 개발의 복잡성**
   - 로봇 자체는 다양한 분야를 요구하며, 기계학, 전자공학, 센서, 플라스틱 소프트웨어 등이 필요합니다.
   - 처음부터 로봇을 구축하는 것은 매우 어려운 도전입니다.

3. **로봇 개발의 효율성**
   - 각각의 모듈은 서로 호환되지 않았으며, 각 학교나 기업들은 자체 솔루션을 개발했습니다.
   - 이로 인해 다양한 소스에서 컴포넌트를 통합하는 것은 재구현하거나 전체 모듈을 다시 작성해야 했습니다.

4. **로봇 운영 체제의 발전**
   - 로봇 프로젝트는 이러한 분산된 모듈을 표준화하여 서로 원활하게 작동할 수 있도록 만들었습니다.
   - 이 통합은 연구 센터가 최첨단 혁신에 집중할 수 있게 했습니다.
