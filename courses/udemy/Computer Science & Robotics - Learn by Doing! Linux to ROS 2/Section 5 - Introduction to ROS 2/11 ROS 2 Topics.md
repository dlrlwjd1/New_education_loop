# ROS 2 Topics

## 개요
1. **노드와 주제의 개념**: 노드는 특정 기능을 수행하는 프로그램으로, 주제를 통해 메시지를 전송하고 수신합니다.
2. **주제의 역할**: 주제는 노드 간의 데이터 공유를 위한 채널로 작동하며, 여러 노드가 동시에 같은 주제에 구독할 수 있습니다.
3. **메시지 타입의 중요성**: 메시지는 노드가 특정 데이터를 전송할 때 선언해야 하며, 메시지 타입은 메시지의 종류를 나타냅니다.

## 내용
### 주제와 노드 이해
- **노드 (Node)**: ROS 2에서 메시지를 보내고 수신하는 프로그램입니다.
- **주제 (Topic)**: 노드 간에 데이터를 공유하기 위한 채널입니다. 하나의 주제에는 여러 노드가 구독할 수 있습니다.

### 주제의 동작 방식
1. **발행자 (Publisher)**: 특정 주제에 메시지를 보내는 노드입니다.
2. **구독자 (Subscriber)**: 같은 주제에서 메시지를 수신하는 노드입니다.
3. **다중 구독자**: 하나의 주제를 여러 노드가 동시에 구독할 수 있습니다.

### 메시지 타입
- **단순 메시지 타입**: 정수, 문자열, 불리언, 벡터 등 기본적인 데이터 유형입니다.
