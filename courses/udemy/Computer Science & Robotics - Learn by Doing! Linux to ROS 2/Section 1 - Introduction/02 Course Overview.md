# Course Overview

## 개요
1. 로봇공학 분야에서 중요한 개념과 도구를 배우게 됩니다.
2. 소프트웨어 개발, 하드웨어 통합 및 실제 환경에서의 문제 해결을 위한 지식을 습득할 수 있습니다.
3. Linux, Docker, Git, ROS 2 등에 대한 실무적인 기술을 배워보세요.

- 원본: [Udemy 강의](https://www.udemy.com/course/computer-science-robotics-learn-by-doing-linux-to-ros-2/learn/lecture/50106393#overview)

## 내용
### Linux
1. **Linux 설치와 구성**
   - Linux 배포판 설치 및 설정 방법
   - 파일 시스템 탐색 및 관리

2. **사용자 권한 관리**
   - 사용자와 그룹 관리
   - 파일 및 디렉토리의 권한 설정

3. **파일과 디렉토리 조작**
   - 파일 생성, 수정, 삭제
   - 디렉토리 생성, 이동, 복사

4. **명령줄 도구 활용**
   - 터미널에서의 명령어 사용
   - 파일 및 디렉토리 관리 명령어

5. **시리얼 포트 통신**
   - 로봇 하드웨어와의 인터페이스 설정

### Docker
1. **Docker 기본 개념**
   - 가볍고 재현 가능한 개발 환경 이해

2. **Docker 이미지 및 컨테이너 생성**
   - 사용자 정의 이미지 빌드
   - 컨테이너 실행 및 관리

3. **개발 흐름 단순화**
   - 일관성 유지와 개발 환경 간 충돌 방지

### Git
1. **Git 기본 개념**
   - 코드 변경 추적, 협업 도구 이해

2. **레파지토리 관리**
   - 새로운 레파지토리 생성
   - 브랜치 관리

3. **변경 사항 관리**
   - 코드 변경 사항 커밋 및 조직화
   - 풀 리퀘스트 이해 및 활용

### ROS 2
1. **ROS 2 기본 개념**
   - 오픈 소스 미들웨어 이해
   - 로봇 애플리케이션 구축 도구 제공

2. **ROS 2 아키텍처**
   - 통신 메커니즘 이해
   - 노드 생성 및 실행

3. **하드웨어 인터페이스**
   - 센서와 제동기와의 연결

## 예시
- 강의의 개념과 적용 맥락은 위 내용에 정리했으며, 구체적인 명령 실습은 관련 실습 강의에서 진행한다.
