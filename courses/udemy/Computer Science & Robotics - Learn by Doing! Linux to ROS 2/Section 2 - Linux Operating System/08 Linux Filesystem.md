## 내용
### 1. Linux 파일 시스템 이해
- Linux는 대부분의 것을 파일로 간주합니다.
- 파일 시스템은 프로그램, 설정 파일, 하드웨어 장치, 사용자 데이터 등 모든 것이 포함됩니다.

### 2. 파일 시스템의 구성
- **Root 디렉토리 (`/`)**: 모든 다른 파일과 디렉토리는 이 하위에 위치합니다.
- **Superuser (root)**: 전체 시스템을 통제하며, 모든 파일 및 디렉토리에 대한 제한 없는 접근 권한이 있습니다.
- **Standard User**: 개인 계정을 가진 사용자로, 일반적으로 `/home` 디렉토리 아래에 개인 디렉토리가 생성됩니다.

### 3. 유저 타입 이해
- **Superuser (root)**: 시스템 전체를 통제하며 모든 파일 및 디렉토리에 대한 접근 권한이 있습니다.
- **Standard User**: 개인 계정을 가진 사용자로, `/home` 디렉토리 아래에 개인 디렉토리가 생성됩니다.

### 4. 주요 디렉토리 소개
- **bin**: 시스템에서 기본적으로 필요한 프로그램과 명령어를 포함합니다.
- **dev**: 연결된 하드웨어 장치를 나타내는 특수 파일을 포함합니다.
- **etc**: 시스템 설정 파일이 저장됩니다.
- **opt**: 표준 Linux 설치에 포함되지 않는 추가 소프트웨어가 위치합니다.
- **home**: 사용자별 개인 디렉토리입니다.
- **var**: 로그, 데이터베이스, 메일 등 변수 파일을 포함합니다.
- **lib**: 시스템 프로그램 실행에 필요한 공유 라이브러리를 포함합니다.
