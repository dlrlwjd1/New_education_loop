# Beyond the Linux Terminal

## 개요
1. **Linux에서의 효율적인 프로그램 실행**
2. **터미널 창 관리의 어려움**
3. **tmux와 terminator: 터미널 관리 도구**

- 원본: [Udemy 강의](https://www.udemy.com/course/computer-science-robotics-learn-by-doing-linux-to-ros-2/learn/lecture/52221297#overview)

## 내용
### 1. 여러 프로그램 실행의 필요성
- 로봇 소프트웨어 개발자로서, 종종 여러 다른 프로그램을 동시에 실행해야 할 때가 많습니다.
- 예를 들어, 새로운 로봇 제어 프로그램을 개발할 때, 로봇 시뮬레이터 시작, 로봇 제어 프로그램 실행, 데이터 모니터링 등 다양한 터미널 창을 사용하게 됩니다.

### 2. 터미널 창 관리의 어려움
- 여러 터미널 창을 관리하면, 어떤 창이 어떤 작업에 해당하는지 파악하기가 어렵습니다.
- 이로 인해 효율성이 떨어지고, 필요한 터미널 창을 닫게 되는 등의 문제가 발생할 수 있습니다.

### 3. tmux와 terminator: 터미널 관리 도구
- **tmux**와 **terminator**는 Linux의 기본 터미널 대신 사용할 수 있는 강력한 대안입니다.
