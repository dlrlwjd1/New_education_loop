# Install Ubuntu

## 개요
1. **가상 머신(Virtual Machine) 설치**: Windows나 Mac OS에서 실행되는 메인 운영 체제 위에 가상 머신으로 Ubuntu를 설치하는 방법.
2. **다중 부트(Dual Boot) 설치**: 컴퓨터의 하드 드라이브를 분할하여 Ubuntu와 다른 운영 체제를 동시에 사용할 수 있는 방법.
3. **Windows Subsystem for Linux (WSL)**: Windows에서 직접적으로 Linux 환경을 실행할 수 있게 하는 Microsoft 기능.

## 내용
### 가상 머신(Virtual Machine) 설치
- 가장 간단한 방법으로, 메인 운영 체제 위에 가상 머신으로 Ubuntu를 설치할 수 있습니다.
- Windows나 Mac OS에서 실행되는 메인 운영 체제 위에 가상 머신을 설치하면, 현재 운영 체제 내부에서 Ubuntu를 실행할 수 있어 테스트, 학습, 새로운 기능 개발이 가능합니다.
- 단점은 성능이 제한적일 수 있으며, 리소스가 가상 머신과 호스트 운영 체제 사이에 공유됩니다.

### 다중 부트(Dual Boot) 설치
- 하드 드라이브를 분할하여 Ubuntu와 다른 운영 체제를 동시에 사용할 수 있는 방법입니다.
- 일반적으로 더 나은 성능을 제공하며, 로봇학과 같은 무거운 작업에 적합합니다.
- 단점은 하드 드라이브를 분할하고 운영 체제 전환 시마다 PC를 재시작해야 합니다.

### Windows Subsystem for Linux (WSL)
- Windows에서 직접적으로 Linux 환경을 실행할 수 있게 하는 Microsoft 기능입니다.
- 가상 머신이나 다중 부트보다 성능이 향상되고, 리소스가 분리되어 있습니다.
