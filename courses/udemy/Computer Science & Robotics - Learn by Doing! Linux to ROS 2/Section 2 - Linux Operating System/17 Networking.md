## 내용
### 1. 네트워크 인터페이스와 IP 주소 이해
네트워크 인터페이스는 컴퓨터가 다른 네트워크에 연결되는 포트입니다. 각 인터페이스에는 고유한 IP 주소가 할당되어 있습니다. 이 주소는 패킷이 올바른 장치로 전달되도록 하는 데 사용됩니다.

### 2. IPv4 주소 형식
IPv4 주소는 32비트 숫자로, 일반적으로 다음과 같은 형식으로 표기됩니다: `192.168.1.1`. 이 주소는 네트워크 부분과 호스트 부분으로 나뉩니다. 네트워크 부분은 공통의 IP 주소를 가진 모든 장치에 대해 사용되며, 호스트 부분은 특정 장치를 식별합니다.

### 3. 서브넷 마스크
서브넷 마스크는 IP 주소에서 네트워크 부분과 호스트 부분을 구분하는 데 사용됩니다. 예를 들어, `/24` 표기법은 첫 24비트가 네트워크 부분이고, 마지막 8비트가 호스트 부분임을 의미합니다.

### 4. 정적 IP와 동적 IP
- **정적 IP**: 수동으로 설정된 주소로, 변경되지 않습니다.
