# [LAB] Install Ubuntu on Dual Boot

## 개요
이 강의에서는 현재 운영체제와 함께 더블 부트로 Ubuntu를 설치하는 방법을 보여드리겠습니다. 이렇게 하면 컴퓨터가 시작될 때 Windows 또는 Ubuntu 중에서 선택할 수 있습니다.

만약 다른 방식으로 Ubuntu를 가상 머신에 설치하고 하드 디스크 파티션을 만들지 않으려는 경우, 이전 강의인 "Ubuntu를 가상 머신에 설치하는 방법"을 따르세요.

이미 Ubuntu 22.04 이상이 있는 컴퓨터가 있다면, 이번 강의를 건너뛰고 다음 강의로 바로 이동하세요.

- 원본: [Udemy 강의](https://www.udemy.com/course/computer-science-robotics-learn-by-doing-linux-to-ros-2/learn/lecture/50106469#overview)

## 내용
### Ubuntu 다운로드
먼저 Ubuntu ISO 파일을 다운로드해야 합니다. 아래 링크 중 하나를 사용하여 Ubuntu 24.04 또는 Ubuntu 22.04를 선택합니다.

다운로드가 완료되면 USB를 생성하여 PC에 Ubuntu를 설치할 수 있습니다.

### 부트 USB 생성
Ubuntu ISO 파일을 다운로드한 후, 컴퓨터가 시작될 때 부트를 위해 USB를 생성해야 합니다. 이를 위해 Rufus라는 다른 도구가 필요하며, 여기에서 다운로드할 수 있습니다. 다운로드 후 실행하면 됩니다.

USB를 컴퓨터에 연결하고 Rufus의 "부트 선택" 섹션에서 이전 단계에서 Ubuntu ISO 파일을 저장한 PC의 디렉토리를 입력합니다.

Rufus 설정이 완료되면 "시작"을 클릭하고 프로그램이 USB에 ISO 파일을 쓰는 과정을 기다립니다.

### Windows를 더블 부트 준비
Ubuntu를 설치하기 전에 하드 디스크에 Ubuntu가 사용할 공간을 미리 확보해야 합니다. 최소 30GB의 공간을 할당하는 것이 좋습니다.

Windows에서 파티션을 만들려면 Win + R을 눌러 diskmgmt.msc를 실행한 후 "OK"를 클릭합니다.

이렇게 하면 컴퓨터에 사용 가능한 저장공간이 표시되고, 다른 운영체제를 위한 디스크 파티션을 생성하고 공간을 할당할 수 있습니다.

그런 다음 Ubuntu에 할당할 공간의 크기를 지정하고 완료하면 "축소" 버튼을 클릭합니다.

이렇게 하면 지정된 크기의 하드 디스크 파티션이 생성됩니다.

이 시점에서 Ubuntu와 함께 필요한 모든 구성 요소를 설치할 준비가 되었습니다.

### Ubuntu 설치
Ubuntu 부트 USB를 연결한 컴퓨터에 USB를 연결하고, "고급 시작"으로 PC를 재시작합니다. Windows 설정 -> "업데이트 및 보안" -> "복구" -> "고급 시작" -> "재시작"을 통해 이동할 수 있습니다.

Windows가 고급 모드로 재시작되고, 다음 작업을 선택하라는 메시지가 표시됩니다. 여기서 "장치 사용"을 클릭하여 USB에 설치된 Ubuntu 부트를 사용해 PC를 재시작합니다.

다음번 컴퓨터 시작 시 USB에 있는 운영체제로 부트하고 Ubuntu 설치를 시작할 수 있습니다.

Ubuntu 환영 화면에서 "Ubuntu 설치"를 선택합니다.

그런 다음 키보드 설정을 선택하고 "계속"을 클릭합니다.
