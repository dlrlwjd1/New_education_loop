## 내용
### 1. GNU와 오픈 소스 모델의 역할
- GNU 프로젝트는 유닉스 운영 체제를 기반으로 한 오픈 소스 소프트웨어를 개발하는 데 초점을 맞추고 있습니다.
- 오픈 소스 모델은 다양한 Linux 배포판을 만들어냈습니다.

### 2. Ubuntu의 출시 배경과 특징
- **출시 배경**: 2004년 캐나다의 Canonical 회사에서 출시되었습니다.
- **목표**: 유닉스를 쉽게 설치, 사용, 유지 관리할 수 있는 배포판을 만들기 위해 간단하지만 강력한 목표를 세웠습니다.
- **특징**:
  - Debian 기반으로 개발되어 있으며, 가장 오래되고 안정적인 Linux 배포판 중 하나입니다.
  - 초보자들에게도 친화적인 사용자 인터페이스가 제공됩니다.
  - 정기적인 보안 업데이트와 강력한 커뮤니티 지원이 있습니다.

### 3. Ubuntu의 버전 및 사용 목적
- **버전**: 주요 버전으로 데스크톱 버전과 서버 버전이 있습니다.
  - **데스크톱 버전**: 그래픽 사용자 인터페이스를 포함하여 일상적인 사용과 소프트웨어 개발에 적합합니다.
    - 기본 도구로 웹 브라우저, 텍스트 에디터, 파일 관리자를 제공합니다.
  - **서버 버전**: 그래픽 사용자 인터페이스가 없으며, 가볍고 효율적이며 리모트 서버 관리를 최적화한 것입니다.
