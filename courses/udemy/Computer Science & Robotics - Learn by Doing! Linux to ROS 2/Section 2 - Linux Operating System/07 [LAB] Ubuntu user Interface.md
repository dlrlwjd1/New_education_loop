## 내용
### Ubuntu의 기본 사용자 인터페이스
Ubuntu 20.04는 Genome이라는 현대적인, 공유된 데스크톱 환경을 사용합니다. Genome은 "New Network Object Model Environment"를 의미하며, 기억할 필요가 없습니다. 중요한 것은 효율적으로 사용하는 방법입니다.

### Dock와 Activity 버튼
Dock은 우측 상단의 수직 바로, Windows의 어두운 바나 Mac OS의 도크와 유사합니다. 여기에는 파일 애플리케이션이나 Firefox 브라우저와 같은 자주 사용되는 애플리케이션의 단축키가 있습니다. 또한 Ubuntu 애플리케이션 센터도 포함됩니다. 원하는 아이콘 오른쪽 클릭하면 즐겨찾기에 추가하거나 제거할 수 있습니다.

### Activity 버튼
좌측 상단의 Activity 버튼을 클릭하면 열린 모든 창과 가상 데스크톱(Workspaces)이 표시됩니다. 이 뷰는 상단 중앙에 여러 작업이 실행될 때 매우 유용합니다. 현재 시간은 오른쪽에 표시되며, 시스템 메뉴에는 네트워크 설정, 소리, 배터리 또는 전원 제어, 로그아웃 및 종료 옵션이 포함됩니다.

### 새로운 프로그램 실행
우측 하단의 Ubuntu 로고를 클릭하면 Dock에 없는 새 애플리케이션을 열 수 있습니다. 예를 들어 텍스트 에디터를 열려면 검색 상자에 "editor"를 입력하고 첫 번째 아이콘을 클릭하면 시스템 설정이나 현재 구성 확인이 가능합니다.

### 시스템 메뉴
이 소절의 본문은 수집되지 않았다. Udemy 자막 원문을 확보한 뒤 보완해야 한다.

## 예시
1. **Dock 사용**
   ```bash
   # Dock에서 Firefox를 실행
   firefox &
   ```

2. **Activity 버튼 사용**
   ```bash
   # Activity 버튼을 클릭하여 열린 창 확인
   alt + tab
   ```

3. **시스템 메뉴 사용**
   ```bash
   # 시스템 메뉴에서 설정 열기
   gnome-control-center &
```
