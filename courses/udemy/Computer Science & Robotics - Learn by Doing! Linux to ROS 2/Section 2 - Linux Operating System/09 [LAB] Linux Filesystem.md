## 내용
### PWD (Print Working Directory)
- **개념**: 현재 위치한 디렉토리의 경로를 출력합니다.
- **이유**: 파일 시스템 내에서 위치를 파악하는 데 도움이 됩니다.
- **절차적 절차**:
  1. 터미널을 열고 `pwd` 명령어를 입력합니다.
  2. 현재 디렉토리의 경로가 출력됩니다.

### CD (Change Directory)
- **개념**: 파일 시스템 내에서 다른 디렉토리로 이동합니다.
- **이유**: 필요한 파일이나 폴더에 쉽게 접근할 수 있습니다.
- **절차적 절차**:
  1. `cd documents`를 입력하여 `documents` 폴더로 이동합니다.
  2. `cd ..`를 입력하여 한 단계 위의 디렉토리로 이동합니다.

### RLS (List)
- **개념**: 현재 디렉토리 내의 파일과 폴더를 나열합니다.
- **이유**: 필요한 파일이나 폴더를 찾는데 도움이 됩니다.
- **절차적 절차**:
  1. `ls` 명령어를 입력하여 현재 디렉토리의 내용을 나열합니다.
  2. `ls -l`을 입력하여 자세한 정보(파일 권한, 크기, 수정 날짜 등)가 출력됩니다.
  3. `ls -a`를 입력하여 숨겨진 파일도 포함하여 나열합니다.

### MKDIR (Make Directory)
- **개념**: 새로운 폴더를 생성합니다.
- **이유**: 필요한 구조를 만들기 위해 사용됩니다.
- **절차적 절차**:
  1. `mkdir new_folder`를 입력하여 `new_folder`라는 이름의 새 폴더를 생성합니다.
  2. `mkdir -p a/b/c`를 입력하여 중첩된 폴더 구조를 생성합니다.

### TOUCH (Create File)
- **개념**: 새로운 파일을 생성합니다.
- **이유**: 필요한 데이터를 저장하기 위해 사용됩니다.
- **절차적 절차**:
  1. `touch file_name`을 입력하여 `file_name`이라는 이름의 새 파일을 생성합니다.

### RM (Remove)
- **개념**: 파일이나 폴더를 삭제합니다.
- **이유**: 필요 없는 파일이나 폴더를 제거하기 위해 사용됩니다.
- **절차적 절차**:
  1. `rm file_name`을 입력하여 `file_name`이라는 이름의 파일을 삭제합니다.
  2. `rm -r folder_name`을 입력하여 `folder_name`이라는 이름의 폴더와 그 내용을 재귀적으로 삭제합니다.

### CP (Copy)
- **개념**: 파일이나 폴더를 복사합니다.
- **이유**: 필요한 데이터를 보존하거나 다른 위치로 이동하기 위해 사용됩니다.
