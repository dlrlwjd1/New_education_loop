# Environmental Variables

## 개요
1. **환경 변수의 개념**: Linux 시스템에서 중요한 구성 요소로, 시스템과 애플리케이션에 대한 정보를 저장하는 키-값 쌍입니다.
2. **환경 변수의 주요 용도**: 실행 가능한 프로그램 위치, 홈 디렉토리 위치, 애플리케이션 설정을 하드코딩하지 않고 구성하는 등 시스템과 애플리케이션에 대한 정보를 관리합니다.
3. **환경 변수의 활용**: 사용자 정의 환경 구성을 제공하여 프로그램 및 애플리케이션이 사용할 수 있습니다.
4. **예시 환경 변수**: PATH와 OAM 등이 있습니다.

- 원본: [Udemy 강의](https://www.udemy.com/course/computer-science-robotics-learn-by-doing-linux-to-ros-2/learn/lecture/50106509#overview)

## 내용
### PATH 환경 변수
- **설명**: PATH 환경 변수는 Linux가 특정 명령어를 실행하기 위해 찾을 프로그램의 위치를 지정합니다.
- **구체적 예시**:
  ```bash
  echo $PATH
  ```
  이 명령어를 실행하면 시스템이 현재 사용 가능한 모든 경로를 보여줍니다.

### OAM 환경 변수
- **설명**: OAM 환경 변수는 사용자의 개인 홈 디렉토리의 경로를 저장합니다.
- **구체적 예시**:
  ```bash
  echo $OAM
  ```
