## 내용
### 파일과 권한 이해
- **파일 확장자**: 다른 운영 체제에서 파일 확장자는 파일의 종류를 나타내지만, Linux에서는 중요하지 않습니다.
  - 예: `robot.txt`, `robot.png`
- **Linux의 관점**: 모든 파일은 바이트의 순서로 간주됩니다. 확장자는 사람이 이해하기 쉽게 하는 데 사용되는 규칙일 뿐입니다.

### 사용자와 그룹 관리
- **사용자 ID (UID)**: 각 사용자가 고유한 숫자를 가집니다.
  - 예: `user1`, `user2`
- **그룹**: 여러 사용자를 모아놓은 집합입니다. 협업 환경에서 효율적인 권한 관리를 위해 중요합니다.

### 권한 설정 및 변경
- **파일의 권한**: 읽기 (read), 쓰기 (write), 실행 (execute) 세 가지 모드가 있습니다.
  - 예: `rwxr-xr-x`
