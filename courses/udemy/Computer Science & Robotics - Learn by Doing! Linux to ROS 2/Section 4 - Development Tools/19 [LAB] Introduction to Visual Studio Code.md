## 내용
### 1. Visual Studio Code (VSCode) 소개
- **정의**: VSCode는 마이크로소프트가 개발한 가볍고 강력한 코드 에디터입니다.
- **특징**: 다양한 프로그래밍 언어 지원, 확장 기능으로 필요한 모든 기능 추가 가능

### 2. VSCode 설치 및 기본 설정
#### 2.1 VSCode 설치
- **Linux Ubuntu**:
  - 공식 웹사이트에서 deb dev 패키지 다운로드
  - 브라우저 열고 VSCode 공식 페이지 이동
  - deb 파일 다운로드 후 터미널에서 `sudo dpkg -i <패키지 이름>` 실행
- **시작 단계**:
  - Ubuntu 메뉴에서 VSCode 시작
  - 대시보드에 고정

#### 2.2 기본 인터페이스 익히기
- **활동 바 (Activity Bar)**: 주요 네비게이션 바
  - **탐색기 (Explorer)**: 파일 및 폴더 관리
  - **검색 (Search)**: 프로젝트 내 모든 파일에서 태그 검색
  - **소스 제어 (Source Control)**: GitHub 연동 기능
  - **디버깅 (Run and Debug)**: 디버깅 도구 접근
  - **확장 (Extensions)**: 확장 설치 및 관리

### 3. VSCode의 주요 기능 이해
- **프로젝트 로드**: 탐색기에서 프로젝트 폴더 열기
- **통합 터미널 (Integrated Terminal)**: 코드 작성 위치에서 바로 명령 실행 가능

### 4. 프로젝트 로드와 툴 사용 방법
#### 4.1 프로젝트 로드
- **프로젝트 폴더 열기**:
  - 메뉴에서 `File > Open Folder` 선택
  - 원하는 폴더 선택하여 프로젝트 파일 로드

#### 4.2 통합 터미널 사용
- **통합 터미널 열기**: `Terminal > New Terminal`
