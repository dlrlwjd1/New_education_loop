# [LAB] Getting started with Extensions

## 개요
1. Visual Studio Code (VSCode)의 확장 기능에 대해 계속 탐구합니다.
2. C/C++ 언어를 사용하여 코드를 개발하는 경우, Microsoft에서 제공하는 C/C++ 확장을 설치할 것입니다.
3. 확장의 기본적인 사용법과 설치 과정을 이해합니다.

- 원본: [Udemy 강의](https://www.udemy.com/course/computer-science-robotics-learn-by-doing-linux-to-ros-2/learn/lecture/51504515#overview)

## 내용
### C/C++ 확장 설치
1. **확장 아이콘 클릭**: VSCode 오른쪽 사이드의 활동 표시줄에서 확장 아이콘을 클릭합니다.
2. **C++ 검색**: 검색 창에 "C++"를 입력하여 Microsoft가 개발한 C++ 확장을 찾습니다.
3. **확장 설치**: 해당 확장의 설치 버튼을 클릭하여 설치합니다.

### 확장 사용 확인
1. **C++ 소스 파일 열기**: 로봇 명령어의 C++ 소스 파일을 VSCode에서 열고, 코드를 작성해봅니다.
2. **자동 완성 테스트**: 함수나 변수 이름을 입력하면 자동 완성 기능이 작동합니다.

## 예시
```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "Hello, World!" << endl;
    return 0;
}
```

### 확장 사용 결과
- **자동 완성**: `cout`를 입력하면 자동으로 `<< endl;`이 추가됩니다.
