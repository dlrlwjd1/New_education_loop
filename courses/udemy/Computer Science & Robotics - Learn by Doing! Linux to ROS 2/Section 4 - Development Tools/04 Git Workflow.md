# Git Workflow

## 개요
1. 로컬 폴더를 Git 저장소로 초기화하여 파일을 추적합니다.
2. 변경 사항을 추적하고 커밋하기 위해 스테이징 영역을 사용합니다.
3. 코드를 호스팅 서비스(GitHub, GitLab 등)에 업로드하여 공동 작업을 가능하게 합니다.

- 원본: [Udemy 강의](https://www.udemy.com/course/computer-science-robotics-learn-by-doing-linux-to-ros-2/learn/lecture/52443247#overview)

## 내용
### 1. 로컬 폴더 초기화
Git 저장소를 로컬 폴더로 초기화하는 방법입니다.
```bash
git init
```
이 명령어는 현재 디렉토리에 숨겨진 `.git` 폴더를 생성합니다. 이 폴더에는 Git의 모든 메타데이터가 포함되어 있습니다.

### 2. 파일 스테이징
변경 사항을 추적하기 전에 파일을 스테이징 영역으로 추가합니다.
```bash
git add <파일명>
```
또는 여러 파일을 한 번에 추가할 수 있습니다.
```bash
git add .
```

### 3. 커밋
스테이징 영역의 변경 사항을 커밋하여 저장소에 반영합니다.
```bash
git commit -m "커밋 메시지"
```
커밋 메시지는 코드 변경 내용이나 수정 사항을 간략하게 설명하는 것이 좋습니다.

### 4. 리모트 저장소 호스팅
로컬 저장소를 GitHub나 GitLab과 같은 호스팅 서비스에 업로드합니다.
```bash
git remote add origin <리모트 저장소 URL>
git push -u origin master
```
