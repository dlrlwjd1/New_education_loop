# [LAB] Create your first Repository

## 개요
이 강의에서는 Git 리포지토리를 생성하여 앞으로의 실습을 위한 기본 설정을 진행합니다. 이 과정에서 GitHub 계정과 Git 설치가 필요하며, 새로운 리포지토리를 생성하고 초기화하는 방법에 대해 배워보겠습니다.

- 원본: [Udemy 강의](https://www.udemy.com/course/computer-science-robotics-learn-by-doing-linux-to-ros-2/learn/lecture/51268673#overview)

## 내용

### 1. GitHub 리포지토리 생성
1. **로그인 및 리포지토리 생성**
   - GitHub에 로그인하여 새로운 리포지토리를 생성합니다.
   - 리포지토리 이름을 입력하고, 예를 들어 "Robo CMD"로 설정합니다.
   - 리포지토리의 공개 여부를 선택하며, 이 경우 비공개로 설정합니다.

2. **새로운 리포지토리 생성**
   - GitHub에서 새로운 리포지토리를 생성하는 방법을 설명합니다.
   - 리포지토리 이름이 유일해야 하며, 예시에서는 "Robo CMD"를 사용했습니다.

### 2. 로컬 디렉토리 및 파일 생성
1. **로컬 디렉토리 생성**
   - 개발 공간이나 홈 폴더에서 새로운 터미널을 열고, `mkdir robot_cmd` 명령어를 실행하여 "robot_cmd"라는 이름의 디렉토리를 생성합니다.

2. **C++ 프로그램 작성**
   - "robot_cmd" 디렉토리 내에 기본적인 C++ 프로그램을 작성합니다.
   - 예시 코드는 간단한 로봇 명령어를 포함하고 있으며, 각 명령어가 순차적으로 실행됩니다.

### 3. Git 초기화 및 파일 추가
1. **Git 초기화**
   - `git init` 명령어를 사용하여 로컬 디렉토리를 Git 리포지토리로 변환합니다.
   - 이 단계에서 디렉토리는 일반적인 폴더가 되고, Git의 버전 관리 기능이 활성화됩니다.

2. **파일 추가**
   - `git add .` 명령어를 사용하여 현재 디렉토리 내의 모든 파일을 스테이징 영역으로 이동합니다.
   - 스테이징 영역은 변경된 파일들을 저장하는 공간입니다.
