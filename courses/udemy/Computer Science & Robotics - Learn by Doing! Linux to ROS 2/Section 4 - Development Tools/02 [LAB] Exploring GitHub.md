## 내용
### 1. GitHub의 주요 기능 소개
- **이슈 (Issues)**: 저장소의 문제나 개선 사항을 추적하고 관리하는 도구
- **풀 리퀘스트 (Pull Requests)**: 코드 변경 사항을 제안하고 검토하는 과정
- **자동화**: CI/CD 파이프라인 등을 통한 자동화

### 2. GitHub의 기본 개념 이해
#### 저장소 (Repository)
- 저장소는 소스 코드를 보관하는 폴더로, 사용자 네임스페이스에 포함됨
- 예시: `https://github.com/username/repository`

#### 레포지토리 페이지
- 저장소의 내용을 확인하고 코드를 검사할 수 있는 페이지
- 공개 저장소는 모든 사용자가 접근 가능

### 3. 공개 저장소와 비공개 저장소의 차이점
- **공개 저장소**: 모든 사용자가 다운로드 및 사용 가능
- **비공개 저장소**: 등록된 사용자만 접근 가능

### 4. GitHub에 로그인 및 계정 생성 방법
1. 브라우저에서 `GitHub` 검색하여 접속
2. 공개 저장소의 내용 확인 (예: `https://github.com/username/repository`)
3. 계정이 없는 경우, `Sign up` 버튼 클릭 후 이메일, 비밀번호 입력
4. 사용자 이름, 지역 선택 및 계정 생성
