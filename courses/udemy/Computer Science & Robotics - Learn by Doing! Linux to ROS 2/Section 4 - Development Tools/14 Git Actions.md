## 내용
### 1. DevOps 소개
DevOps는 소프트웨어 개발과 IT 운영 사이의 협업과 자동화를 촉진하기 위한 문화적 사고와 기술적 연습의 집합입니다. CI/CD는 이 과정에서 중요한 역할을 합니다.

### 2. CI/CD 프레임워크
- **CI (Continuous Integration)**: 소프트웨어 리포지토리에 변경이 있을 때마다 자동으로 코드를 빌드하고 테스트하는 연습입니다.
- **CD (Continuous Deployment)**: 모든 테스트가 통과한 후 자동으로 코드를 배포하는 과정입니다.
