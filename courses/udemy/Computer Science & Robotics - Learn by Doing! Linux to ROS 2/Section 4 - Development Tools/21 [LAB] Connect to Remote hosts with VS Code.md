# [LAB] Connect to Remote hosts with VS Code

## 개요
1. Visual Studio Code를 사용하여 원격 호스트에 연결하는 방법을 배웁니다.
2. SSH 확장 프로그램을 설치하고 사용하여 로봇 컴퓨터와 같은 원격 시스템에서 작업할 수 있습니다.

- 원본: [Udemy 강의](https://www.udemy.com/course/computer-science-robotics-learn-by-doing-linux-to-ros-2/learn/lecture/51504533#overview)

## 내용
### 1. SSH 확장 프로그램 설치
Visual Studio Code의 확장 프로그램 탭으로 이동하여 "SSH"를 검색합니다. Microsoft가 출시한 SSH 확장 프로그램을 설치합니다.

### 2. 원격 서버 연결 설정
원격 서버에 연결하려면 Visual Studio Code의 SSH 리소스 탐색기에서 새로운 서버를 추가하고 SSH 명령어를 입력해야 합니다. 예를 들어, "ssh robot one"과 같은 명령어를 사용하여 로봇 컴퓨터에 연결할 수 있습니다.

### 3. 원격 파일 시스템 및 터미널 액세스
원격 서버에 연결하면 파일 시스템과 터미널에 액세스할 수 있습니다. 처음에는 새로운 서버를 추가해야 하며, SSH 명령어와 사용자 이름을 입력합니다.

### 4. 원격 컴퓨터에서 코드 작성 및 실행
이 소절의 본문은 수집되지 않았다. Udemy 자막 원문을 확보한 뒤 보완해야 한다.

## 예시
```bash
# SSH 명령어 예시
ssh robot one username@robot_one
```
## 요약
- Visual Studio Code를 사용하여 원격 호스트에 연결하는 방법을 배웁니다.
- SSH 확장 프로그램을 설치하고 사용하여 로봇 컴퓨터와 같은 원격 시스템에서 작업할 수 있습니다.
