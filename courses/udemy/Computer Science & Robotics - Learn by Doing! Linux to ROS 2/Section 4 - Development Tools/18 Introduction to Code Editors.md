# Introduction to Code Editors

## 개요
1. **텍스트 에디터의 중요성**: 텍스트 에디터는 로봇 소프트웨어 개발에 필수적입니다. 적절한 텍스트 에디터를 선택하면 로봇에 대한 다양한 기능을 개발할 수 있습니다.
2. **이전 강의 내용**: 이전 섹션에서는 vim, nano, gedit 등 여러 텍스트 에디터를 사용하여 Linux 파일을 터미널에서 빠르게 편집했습니다.
3. **텍스트 에디터의 종류**: 간단한 vim과 nano 외에도 gedit와 같은 더 완전한 텍스트 에디터도 있습니다. 이러한 텍스트 에디터는 코드 개발에 사용할 수 있지만, 실제로는 Integrated Development Environment (IDE)라고 불리는 고급 텍스트 에디터가 많습니다.
4. **IDE의 특징**: IDE는 코드 자동 완성, 오류 또는 경고 하이라이팅, Docker 통합, LLM과 같은 인터페이스 통합 등 다양한 기능을 제공합니다.
