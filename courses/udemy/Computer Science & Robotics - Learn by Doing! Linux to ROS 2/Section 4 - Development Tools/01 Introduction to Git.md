# Introduction to Git

## 개요
1. **개발 도구의 중요성**: 소프트웨어 개발에서 효율적인 작업과 팀 협업을 위해 사용되는 도구에 대해 설명합니다.
2. **Git 소개**: 가장 유명한 분산 버전 관리 시스템으로, 여러 개발자가 같은 프로젝트를 공동으로 개발하고 코드를 공유하고 관리할 수 있게 합니다.
3. **버전 관리 시스템의 역할**: 코드의 각 버전을 추적하고, 변경 사항을 확인하며, 과거 버전으로 돌아가서 안전하게 새로운 기능을 실험하거나 다른 사람과 협업할 수 있습니다.
4. **GitHub와 Git의 차이점**: GitHub는 오픈 소스 소프트웨어를 호스팅하는 인터넷 서비스로, Git은 로컬 컴퓨터에 설치할 수 있는 무료 오픈 소스 버전 관리 도구입니다.

## 내용
### Git 소개
- **버전 관리 시스템의 개념**: 코드의 각 버전을 추적하고 변경 사항을 확인하며, 과거 버전으로 돌아갈 수 있습니다.
- **Git의 주요 특징**: 여러 개발자가 같은 프로젝트를 공동으로 개발하고 코드를 공유하고 관리할 수 있게 합니다.

### GitHub 소개
- **GitHub의 개념**: 오픈 소스 소프트웨어를 호스팅하는 인터넷 서비스입니다.
- **Git과 GitHub의 차이점**: Git은 로컬 컴퓨터에 설치할 수 있는 버전 관리 도구로, GitHub는 Git을 클라우드에서 실행하기 위한 온라인 서비스입니다.

### GitHub와 Docker Hub의 비교
- **Docker Hub**: 공용 Docker 이미지를 저장하는 인터넷 저장소입니다.
- **GitHub**: 소프트웨어 리포지토리를 저장하는 인터넷 저장소입니다.
  - **공개 리포지토리**: 모든 사람이 접근할 수 있습니다.
