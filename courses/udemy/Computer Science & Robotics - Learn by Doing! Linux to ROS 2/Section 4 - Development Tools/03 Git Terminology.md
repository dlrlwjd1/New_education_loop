# Git Terminology

## 개요
1. **Commit**: 프로젝트의 현재 상태를 스냅샷으로 저장합니다.
2. **Branching**: 코드의 병렬 개발을 지원하는 중요한 기능입니다.

- 원본: [Udemy 강의](https://www.udemy.com/course/computer-science-robotics-learn-by-doing-linux-to-ros-2/learn/lecture/52473795#overview)

## 내용
### Commit
- **정의**: 프로젝트의 특정 시점에서 파일의 정확한 내용을 캡처하여 스냅샷을 만듭니다.
- **예시**:
  ```bash
  git commit -m "Add new navigation feature"
  ```
- **요약**: 커밋은 프로젝트의 현재 상태를 저장하고, 이전 버전으로 돌아갈 수 있게 합니다.

### Branching
- **정의**: 코드의 병렬 개발을 지원하는 중요한 기능입니다.
- **예시**:
  ```bash
  git branch develop_new_navigation
  ```

## 예시
- 강의의 개념과 적용 맥락은 위 내용에 정리했으며, 구체적인 명령 실습은 관련 실습 강의에서 진행한다.

## 요약
- **Commit**: 프로젝트의 현재 상태를 스냅샷으로 저장합니다.
- **Branching**: 코드의 병렬 개발을 지원하는 중요한 기능입니다.
