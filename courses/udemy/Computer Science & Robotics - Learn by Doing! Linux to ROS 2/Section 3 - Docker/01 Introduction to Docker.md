# Introduction to Docker

## 개요
1. **Docker의 개념과 목적**
   - Docker는 애플리케이션及其 의존성을 가볍고 이동성 있는 컨테이너로 패키징하는 플랫폼입니다.
   - 개발자가 동일한 환경에서 애플리케이션이 일관되게 실행될 수 있도록 합니다.

2. **Docker의 장점**
   - 개발자의 랜트оп에서 프로덕션 서버까지 일관된 환경에서 실행 가능합니다.
   - 복잡한 설치 지침이나 버전 충돌, 의존성 부족 문제를 해결할 수 있습니다.

3. **Docker의 역사**
   - 2013년에 처음 도입되었습니다.
   - 가볍고 이동성 있는 컨테이너를 사용하여 애플리케이션 배포를 더 쉽고 일관되게 만듭니다.

4. **Docker의 활용 분야**
   - 소프트웨어 개발, DevOps 커뮤니티에서 인기를 얻었습니다.
   - 마이크로서비스, 클라우드 컴퓨팅, CI/CD 파이프라인 등 다양한 분야에서 사용됩니다.

## 내용
### Docker의 기본 개념
- **컨테이너 (Container)**
  - 애플리케이션과 그 의존성을 포함한 가볍고 이동성 있는 실행 단위입니다.
  - 개발자의 랜트оп에서 프로덕션 서버까지 일관된 환경에서 실행 가능합니다.

- **Docker 이미지 (Docker Image)**
  - 컨테이너의 틀을 정의한 파일입니다.
  - 애플리케이션과 그 의존성을 포함하고 있습니다.

### Docker의 주요 기능
- **컨테이너 관리**
  - `docker run`: 새로운 컨테이너를 실행합니다.
    ```bash
    docker run -it ubuntu bash
    ```
  - `docker ps`: 현재 실행 중인 컨테이너 목록을 보여줍니다.
    ```bash
    docker ps
    ```

- **이미지 관리**
  - `docker pull`: 이미지를 다운로드합니다.
    ```bash
    docker pull ubuntu
```
