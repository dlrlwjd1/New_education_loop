## 내용
### Docker 이미지의 구성과 저장
Docker 이미지는 레이어로 구성되어 있으며, 각 레이어는 이전 레이어에서의 변경사항(델타)을 나타냅니다. 예를 들어, 한 레이어에서는 파일이나 패키지를 추가하거나 설치할 수 있습니다. 이러한 레이어들은 쌓여 최종 이미지를 만듭니다. 중요한 점은 각 레이어가 불변성(읽기 전용)이며, 고유한 해시를 통해 식별됩니다. 이 고유한 코드는 큰 이점을 제공하며, 여러 이미지가 동일한 레이어를 공유하면 디스크 공간을 절약할 수 있습니다.

### 컨테이너의 생성과 시작
컨테이너는 이미지를 기반으로 생성되며, 새로운 인스턴스가 생성됩니다. 이 때 컨테이너에는 고유한 ID와 사용자 친화적인 이름이 할당됩니다. 하지만 초기 상태에서는 아직 실행되지 않습니다. `start` 명령을 통해 컨테이너의 주요 프로세스가 시작되어 활성 상태로 전환됩니다. 컨테이너는 이 상태에서 지시된 모든 동작을 수행합니다.
