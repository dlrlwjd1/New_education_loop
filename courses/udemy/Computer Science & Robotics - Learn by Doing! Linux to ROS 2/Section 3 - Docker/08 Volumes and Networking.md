# Volumes and Networking

## 개요
1. 컨테이너의 격리된 환경: 호스트 머신과 분리된 독립적인 환경에서 실행됩니다.
2. 파일 시스템의 격리: 각 컨테이너는 임시적이고 제한된 파일 시스템 액세스를 가집니다.
3. 데이터 공유의 불가능성: 컨테이너와 호스트 컴퓨터 간에 데이터를 공유할 수 없습니다.
4. 볼륨(Volume)의 필요성: 컨테이너 삭제나 재시작에도 데이터를 유지하는 데 도움이 됩니다.

## 내용
### 1. 격리된 환경과 파일 시스템
- 각 컨테이너는 임시적이고 제한된 파일 시스템 액세스를 가집니다.
- 호스트 머신과 컨테이너 간에 데이터 공유가 불가능합니다.

### 2. 볼륨(Volume)의 개념
- Docker가 관리하는 지속적인 데이터 저장 공간입니다.
- 호스트 시스템과 하나 이상의 컨테이너 사이에서 공유할 수 있습니다.
- 컨테이너 삭제나 재시작에도 데이터를 유지합니다.

### 3. 네트워킹 기본
- Docker는 각 컨테이너에 자체적인 네트워크 스택을 제공하고, 브리지 네트워크와 연결합니다.
- 호스트 머신의 브리지 모드에서 설정된 격리된 가상 네트워크 내에서 각 컨테이너가 고유한 IP를 가지게 됩니다.

### 4. 네트워킹 모드
- **브리지 모드(Bridge Mode)**: 기본적인 네트워킹 모드로, 호스트 머신의 브리지 인터페이스와 연결됩니다.
