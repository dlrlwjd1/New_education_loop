## 내용
### Docker 이미지의 정의와 특징
Docker 이미지는 실행할 프로그램에 필요한 모든 파일, 바이너리, 라이브러리 및 종속성을 포함하는 읽기 전용 템플릿입니다. 이는 케이크를 만드는데 필요한 재료가 있는 쇼핑백이나 이미 모든 도구가 미리 설치된 전체 운영 체제와 비슷합니다.

### 컨테이너의 개념과 동작 방식
Docker 컨테이너는 이미지를 기반으로 실행되는 격리된 프로세스입니다. 이미지는 단순히 컨테이너를 생성하는 데 사용되는 틀 역할을 합니다. 컨테이너는 호스트 시스템과 분리되어 실행되며, 프로그램을 컴파일하고 실행하거나 미리 설치된 종속성을 사용할 수 있습니다.

### Docker 이미지를 가져오는 방법
Docker 이미지는 인터넷에서 원격 이미지 저장소를 통해 다운로드할 수 있습니다. 가장 유명한 공식 이미지 저장소는 Docker Hub입니다. 여기서 많은 유지 관리되고 사용 가능한 오픈 소스 이미지가 있으며, 이들을 어떻게 사용하는지 살펴보겠습니다.
