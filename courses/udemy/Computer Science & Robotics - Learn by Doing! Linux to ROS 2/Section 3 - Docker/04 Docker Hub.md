# Docker Hub

## 개요
1. Docker 이미지의 기본적인 Hello World 테스트를 넘어 실제 Docker의 강력함을 살펴보겠습니다.
2. Docker가 단순한 단계로 높은 품질의 소프트웨어를 개발할 수 있게 도와주는 방법에 대해 설명합니다.
3. Docker 이미지를 얻는 여러 가지 방법에 대해 논의하고, 이를 통해 공용 클라우드 기반 서비스인 Docker App을 소개합니다.
4. Docker App이 이미지 버전 관리를 단순화하는 방법과 태그의 의미를 설명합니다.

## 내용
### Docker Hub와 Docker App
Docker Hub는 공용 클라우드 기반 서비스로, 다양한 컨테이너 이미지를 저장하고 공유할 수 있는 플랫폼입니다. Docker App은 Docker Hub와 유사한 역할을 하지만, 개인적인 서버를 만들 수도 있습니다.

### 태그의 의미
Docker 이미지는 특정 버전이나 변형을 식별하기 위해 태그로 라벨이 붙습니다. 예를 들어, Python 3.11과 Python 2.7은 각각 다른 버전의 이미지를 나타냅니다. Docker Hub에서 이미지를 가져올 때 특정 태그를 지정하지 않으면 가장 최신 버전이 다운로드됩니다.
