# Docker Compose

## 개요
1. **Docker 이미지 생성**: Docker 파일을 사용하여 Docker 이미지를 만드는 방법에 대해 배웠습니다.
2. **복잡한 이미지 생성**: 여러 순차적인 명령어를 사용하여 복잡한 이미지를 만들 수 있습니다.
3. **컨테이너 실행**: Docker 이미지를 실행 가능한 인스턴스로 변환하는 과정을 이해했습니다.
4. **Docker Compose 소개**: 실무에서 많은 컨테이너가 필요한 경우, 각각의 컨테이너에 대한 별도의 툴을 사용해야 하는 문제를 해결하기 위해 Docker Compose가 소개되었습니다.

## 내용
### Docker Compose란?
Docker Compose는 단일 구성 파일과 단일 명령어로 다중 컨테이너 Docker 애플리케이션을 정의하고 실행할 수 있는 도구입니다. 이를 통해 복잡한 워크플로를 단순화할 수 있습니다.

### YAML 파일 사용
Docker Compose는 기본적으로 `docker-compose.yaml`이라는 특별한 YAML 파일을 사용합니다. 이 파일은 애플리케이션 서비스를 구성하는 데 사용됩니다.

### 서비스 정의
서비스는 애플리케이션의 하나의 구성 요소로, 실제로는 하나의 컨테이너 설정입니다. 예를 들어, 데이터베이스 컨테이너, 웹 서버 컨테이너, 로봇 자율 이동을 관리하는 컨테이너 등이 있을 수 있습니다.

### Docker Compose 엔진
Docker Compose 엔진은 YAML 파일을 파싱하여 전체 환경을 설정합니다. 기본 이미지를 찾고, 해당 이미지가 없는 경우 자동으로 Docker Hub에서 가져오거나, 제공된 경우 빌드를 시도합니다.
