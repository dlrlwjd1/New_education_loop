# Recap

## 개요
1. Linux, Docker, Git, ROS 2에 대한 기본 개념과 사용법을 배웠습니다.
2. 실습을 통해 각 도구의 활용 방법을 직접 경험했습니다.
3. 새로운 프로젝트를 시작할 준비가 되었습니다.

- 원본: [Udemy 강의](https://www.udemy.com/course/computer-science-robotics-learn-by-doing-linux-to-ros-2/learn/lecture/50147043#overview)

## 내용
### Linux 운영체제 이해
- Linux는 대부분의 로봇 시스템이 사용하는 운영체제입니다.
- 기본적인 명령어와 파일 시스템 탐색 기술을 배웠습니다.

### Docker 활용
- Docker는 개발, 테스트, 배포를 위한 가볍고 재현 가능한 환경을 제공합니다.
- 공용 이미지 사용과 커스텀 이미지 및 컨테이너 생성 방법을 배웠습니다.

### Git 버전 관리
- 코드 변경 추적, 협업, 여러 버전 관리를 가능하게 합니다.
- 새로운 저장소 생성, 브랜치 관리, 코드 변경 사항 정리 등 기능을 배웠습니다.

### ROS 2 활용
- 분산 및 확장 가능한 로봇 시스템 개발을 지원합니다.

## 예시
- 강의의 개념과 적용 맥락은 위 내용에 정리했으며, 구체적인 명령 실습은 관련 실습 강의에서 진행한다.

## 요약
- Linux, Docker, Git, ROS 2에 대한 기본 개념과 사용법을 배웠습니다.
- 실습을 통해 각 도구의 활용 방법을 직접 경험했습니다.
- 새로운 프로젝트를 시작할 준비가 되었습니다.
