# Getting Started with a Robot

## 개요
이 강의의 마지막 섹션은 매우 흥미롭습니다. 이 섹션에서는 이 강의에서 배운 이론적 개념을 실습하여 자율형 모바일 로봇을 만들 수 있습니다. 이 로봇은 Bumper Bot으로, ROS 2를 기반으로 한 오픈 소스로 제조된 3D 인쇄 자율형 로봇입니다. Bumper Bot의 단순한 디자인과 저렴한 가격이 학습 플랫폼으로 적합하며, 여러 다른 Udemy 강의에서도 사용되고 있습니다. 이 로봇은 문서화가 잘 되어 있고 시작하기도 쉽기 때문에 지식을 적용하는 이상적인 플랫폼이며, 특히 새로운 기능을 개발하고 테스트할 수 있는 추가 학습 도구로도 제공됩니다.

이 섹션에서는 ROS 2의 오픈 소스 로봇을 사용하여 설정 및 실행하는 과정을 안내합니다. 실제로 공개 저장소에서 소스 코드를 다운로드하는 방법, 필요한 의존성 설치 방법, 그리고 ROS 2의 협업적 특성을 고려한 예제 실행 방법에 대해 설명합니다. 이는 매우 중요한 기술입니다. 대부분의 경우, 새로운 로봇을 처음부터 만들기보다는 이미 존재하는 로봇을 사용하여 소프트웨어 알고리즘을 개발하고 테스트할 수 있습니다.

- 원본: [Udemy 강의](https://www.udemy.com/course/computer-science-robotics-learn-by-doing-linux-to-ros-2/learn/lecture/49902089#overview)

## 내용
### Bumper Bot 소개
Bumper Bot은 ROS 2를 기반으로 한 오픈 소스로 제조된 자율형 모바일 로봇입니다. 이 로봇의 단순한 디자인과 저렴한 가격이 학습 플랫폼으로 적합하며, 여러 다른 Udemy 강의에서도 사용되고 있습니다.

### 저장소 분석
이 섹션에서는 Bumper Bot의 저장소 내용과 조직을 분석합니다. 저장소에는 Bumper Robot이라는 이름으로 시작하는 여러 폴더가 포함되어 있습니다. 각 폴더는 ROS 2 패키지로, 노드와 애플리케이션 및 그 이름을 포함한 컨테이너입니다.

### 패키지 설명
- **Bumper Bot Description Package**: 로봇의 모델을 포함하며, 구조와 모든 기계 구성 요소를 설명합니다.
