## 내용
### 1. 실습 목적
이 강의에서는 학습한 Linux와 컴퓨터 과학 기술을 실제 로봇에 적용하는 방법을 다룹니다. 실제로 로봇을 만들거나 생성할 필요가 없습니다. 이 강의의 목적은 학습한 도구와 개념의 실용적 적용성을 보여주고, 이를 통해 우리의 실질적인 자율형 모바일 로봇 구현과 사용에 어떻게 적용할 수 있는지 설명하는 것입니다.

### 2. 필요한 장비
- Raspberry Pi 4 또는 최신 버전
- 최소 32GB 크기의 microSD 카드
- USB 어댑터 또는 microSD 어댑터
