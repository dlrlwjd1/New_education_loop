# 퀴즈 8: Working with Robots

## 개요
- 커리큘럼에 포함된 **5개 문항의 섹션 확인 퀴즈**다.
- 확인 범위: Section 6 전체 — 워크스페이스 생성과 활성화, rosdep, 런치 파일, Gazebo와 RViz, 그리고 Raspberry Pi 기반 실제 로봇 구성.

- 원본: [Udemy 퀴즈](https://www.udemy.com/course/computer-science-robotics-learn-by-doing-linux-to-ros-2/learn/quiz/7178069#overview)

### 확인 상태
**미응시.** 이 저장소는 평가 자료의 문항과 정답을 기록하지 않는다. 수강 진행 상태를 바꾸지 않기 위해 응시하지 않았고, 따라서 실제 문항을 임의로 만들어 적지 않는다. 실제 응시는 Udemy 수강 페이지에서 직접 진행한다.
