# [OPTIONAL] Work with a Real Robot

## 개요
1. 로봇의 모든 기능을 시작하는 방법.
2. tmux를 사용하여 로봇에 로그인하고 로그아웃하는 방법.
3. systemd를 사용하여 로봇의 시스템 서비스 자동화.

- 원본: [Udemy 강의](https://www.udemy.com/course/computer-science-robotics-learn-by-doing-linux-to-ros-2/learn/lecture/51267199#overview)

## 내용
### 로봇 기능 시작하기
- tmux를 사용하여 로봇에 로그인하고 로봇의 모든 기능을 시작하는 방법.
- 실제 로봇에서 시뮬레이션 로봇과 다른 launch 파일을 사용하여 로봇 기능을 시작.

### tmux로 로봇 제어
- tmux 세션을 생성하여 로봇의 모든 기능을 관리하는 방법.
- tmux를 사용하여 로봇을 조종하고 맵을 만들 수 있는 방법.

### systemd로 시스템 서비스 자동화
- systemd를 사용하여 로봇의 시스템 서비스를 자동으로 시작하는 방법.
