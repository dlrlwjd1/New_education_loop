# RViz

## 개요
1. **RViz의 필요성**: ROS 2에서 정보를 교환하는 토픽들이 많아서 명령행으로 하나씩 확인하는 것은 시간이 많이 걸린다.
2. **단순 메시지의 문제점**: 단순한 문자 메시지는 터미널에서 쉽게 읽고 시각화할 수 있지만, 복잡한 메시지는 터미널에서 이해하기 어렵다.
3. **RViz의 역할**: RViz는 ROS 2 메시지를 그래픽 인터페이스로 시각화하는 도구이다.

- 원본: [Udemy 강의](https://www.udemy.com/course/computer-science-robotics-learn-by-doing-linux-to-ros-2/learn/lecture/50660937#overview)

## 내용
### RViz 소개
- **RViz란**: Ros visualization의 약자로, ROS 2 메시지를 시각적으로 보여주는 그래픽 인터페이스다.
- **작동 방식**: Publisher-subscriber 통신 프로토콜을 기반으로 작동한다. 특정 토픽에서 오는 메시지를 수신하고, 메시지의 타입에 따라 해석하여 GUI에 표시한다.

### RViz 사용 예
1. **RViz 시작**:
   - `ros2 launch bumper_robot_simulation bringup_launch.py`
   - RViz가 자동으로 시작되어 여러 메시지가 시각화된다.

2. **메시지 시각화**:
   - 레이저 센서의 읽기 결과: 빨간 점으로 표시됨
   - 환경 맵: 흰색은 비어있는 영역, 검은색은 차단된 영역, 회색은 미지한 영역
   - 로봇 프레임과 발자국: 로봇의 현재 위치와 차지하는 영역 표시
