# Shipping Agent + Custom Tool

## 개요
- 배송 주문 도구에 사람의 승인 단계가 필요한 비즈니스 규칙을 구현한다.

## 내용
### 승인 임계값
배송 도구는 컨테이너 수, 목적지와 `ToolContext`를 받는다. 임계값 5개 이하 주문은 자동 승인하고, 초과 주문은 확인 요청 이벤트를 만든다.

첫 호출에서는 승인 대기 상태를 반환하고, 재개 호출에서는 `tool_confirmation`을 확인해 주문을 확정하거나 거절한다. 에이전트를 resumability가 활성화된 App으로 감싸 메시지, 도구 인자와 중단 지점을 저장한다.

## 예시
```text
소량 주문 → 즉시 처리
대량 주문 → 승인 요청 → 일시 중지
```

## 요약
- 승인 여부는 LLM이 아니라 도구의 비즈니스 규칙으로 결정한다.
- 중단과 재개를 위해 실행 상태를 저장해야 한다.
