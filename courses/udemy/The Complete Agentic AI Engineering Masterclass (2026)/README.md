## 개요
- AI 모델과 LLM의 작동 원리부터 RAG, 로컬 LLM, Google Agent Development Kit(ADK), 멀티 에이전트 패턴, 도구, MCP, Human-in-the-loop, 세션과 메모리까지 다룬다.
- 후반부에는 Agno와 DuckDuckGo 도구를 사용해 웹 자료를 조사하고 보고서를 작성하는 Deep Research Agent를 만든다.
- 이 저장소의 노트는 수강 페이지에서 실제로 제공된 영어 트랜스크립트를 기준으로 강의별로 정리했다. 각 섹션의 파일 번호는 `01`부터 다시 시작한다.

## 강의 상태
- 강의 1~29와 33~35는 트랜스크립트를 확인해 정리했다.
- 강의 30~32는 수강 페이지에 `Upcoming`으로 표시된 0~1분 자리표시자이며, 확인 시점에는 정리할 트랜스크립트가 없었다.
- 퀴즈 `Knowledge Check`는 응시하거나 진행 상태를 변경하지 않았다.

## 핵심 흐름
- **기초**: AI 모델 → 생성형 AI → 토큰·임베딩·셀프 어텐션 → RAG와 미세조정
- **개발 환경**: Ollama·LM Studio → Hugging Face → Google ADK
- **에이전트 설계**: LLM 오케스트레이터 → 순차·병렬·루프 패턴 → 커스텀 도구와 코드 실행
- **통합·운영**: MCP → Human-in-the-loop → 세션·영속 메모리
- **프로젝트**: 계획·검색·평가·보고서 생성을 수행하는 Deep Research Agent
