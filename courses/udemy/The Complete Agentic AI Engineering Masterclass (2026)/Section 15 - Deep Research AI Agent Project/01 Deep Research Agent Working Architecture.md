# Deep Research Agent Working Architecture

## 개요
- 연구 주제를 검색·평가·종합하는 Deep Research Agent의 전체 구조를 설계한다.

## 내용
### 연구 루프
사용자 주제에서 목표와 계획을 만들고 여러 검색 질의로 분해한다. 웹 검색 결과를 합친 뒤 정보가 충분한지 평가한다. 부족하면 새 질의를 만들어 검색을 반복하고, 충분하면 최종 보고서를 작성한다.

## 예시
```text
주제 → 계획 → 하위 질의 → 웹 검색 → 결과 통합
→ 충분성 평가 ─ 부족 → 재검색
              └ 충분 → 보고서
```

## 요약
- 한 번의 LLM 응답이 아니라 계획·검색·평가·반복·종합으로 구성된다.
- 검색 범위와 종료 조건이 보고서 품질을 결정한다.
