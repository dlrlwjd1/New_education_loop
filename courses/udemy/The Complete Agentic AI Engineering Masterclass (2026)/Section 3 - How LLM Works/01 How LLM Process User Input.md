# How LLM Process User Input

## 개요
- 자연어 입력이 토큰과 벡터로 바뀌고 Transformer를 거쳐 다음 토큰으로 생성되는 과정을 설명한다.

## 내용
### 토큰에서 출력까지
토크나이저(tokenizer)는 문장을 작은 토큰으로 나눈다. 모델마다 토큰 경계와 개수가 다르며 공백도 결과에 영향을 줄 수 있다. 각 토큰은 임베딩(embedding)을 통해 수치 벡터로 변환된다.

셀프 어텐션(self-attention)은 입력 요소 사이의 관계와 중요도를 계산한다. 여러 Transformer 층을 지난 모델은 다음 토큰의 확률 분포를 만들고 하나를 선택한다. 선택된 토큰을 입력에 붙여 종료 토큰(EOS)이 나올 때까지 반복한다.

## 예시
```text
문장 → 토큰화 → 임베딩 → 셀프 어텐션
→ 다음 토큰 확률 → 토큰 선택 → 반복
```

## 요약
- LLM은 문자열을 토큰과 벡터로 바꿔 처리한다.
- 응답은 다음 토큰 예측을 반복해 생성된다.
