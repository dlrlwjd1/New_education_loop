# Agent Patterns Overview

## 개요
- 작업의 의존성·동시성·반복성에 따라 에이전트 패턴을 선택한다.

## 내용
### 선택 기준
| 패턴 | 사용 조건 |
|---|---|
| LLM 오케스트레이터 | 동적 위임이 필요함 |
| Sequential | 순서와 단계 간 의존성이 있음 |
| Parallel | 작업이 독립적이고 속도가 중요함 |
| Loop | 평가와 반복 개선이 필요함 |

Human-in-the-loop는 LLM이 스스로 평가하는 Loop와 달리 사람의 승인을 기다린다. 실제 엔터프라이즈 시스템은 여러 패턴을 혼합한다.

## 예시
독립 조사를 병렬 실행하고, 결과를 순차적으로 집계한 뒤, 품질 기준을 충족할 때까지 루프로 개선할 수 있다.

## 요약
- 문제의 실행 제약을 먼저 분석한 뒤 패턴을 선택한다.
- 하나의 패턴만으로 전체 시스템을 구성할 필요는 없다.
