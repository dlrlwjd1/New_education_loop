# MCP As Agent Tool

## 개요
- MCP 클라이언트를 통해 외부 시스템의 표준화된 도구를 에이전트에 제공한다.

## 내용
### 연결 방식
Model Context Protocol(MCP)은 에이전트의 클라이언트와 외부 MCP 서버 사이의 인터페이스를 표준화한다. 같은 머신에서 로컬 프로세스로 실행할 때는 stdio, 원격 서버에는 HTTP 스트리밍/SSE 계열 연결을 사용한다.

강의는 GitHub MCP와 개인 액세스 토큰을 연결해 저장소·이슈·작업 관련 도구를 에이전트가 탐색하게 한다. 토큰에는 필요한 최소 권한만 부여해야 한다.

## 예시
```text
ADK Agent → MCP Client → 표준 MCP 연결 → GitHub MCP Server
```

## 요약
- MCP는 외부 시스템마다 커스텀 API 클라이언트를 반복 구현하는 비용을 줄인다.
- 연결 방식과 인증 권한을 배포 위치와 작업 범위에 맞춰 제한한다.
