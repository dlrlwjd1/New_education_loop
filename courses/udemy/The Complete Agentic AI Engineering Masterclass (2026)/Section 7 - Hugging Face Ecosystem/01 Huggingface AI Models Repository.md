# Huggingface AI Models Repository

## 개요
- Hugging Face Model Hub에서 모델 카드와 가중치 파일을 평가한다.

## 내용
### 모델 선택
작업 유형과 인기도로 모델을 찾은 뒤 모델 카드에서 용도, 학습 정보, 평가 결과와 실행 코드를 확인한다. `Files and versions`의 `safetensors`는 모델 가중치이므로 전체 크기를 보고 로컬 실행 가능성을 판단한다.

강의는 GPT-2와 Stable Diffusion 모델 페이지를 예로 살펴본다.

## 예시
1. 작업 유형으로 필터링한다.
2. 모델 카드와 평가 결과를 읽는다.
3. 라이선스와 파일 크기를 확인한다.
4. 제공된 코드로 작은 테스트를 수행한다.

## 요약
- 다운로드 수만으로 모델을 고르지 않는다.
- 모델 카드, 라이선스, 가중치 크기와 실제 실행 환경을 함께 확인한다.
