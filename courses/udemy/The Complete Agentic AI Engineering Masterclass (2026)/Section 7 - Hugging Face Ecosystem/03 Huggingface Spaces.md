# Huggingface Spaces (Image generation & Music Generation)

## 개요
- Hugging Face Spaces에서 이미지·음악·번역 모델 데모를 실행한다.

## 내용
### 호스팅된 모델 체험
Spaces는 모델 애플리케이션을 GPU에서 호스팅한다. 강의에서는 이미지 스타일 모델, 음악 생성과 UNESCO·Meta 번역 데모를 사용하고 어떤 기반 모델이 실행되는지 확인한다.

무료 GPU 환경은 대기열, 사용 한도와 런타임 오류가 발생할 수 있다. 따라서 Space는 모델 기능을 시험하는 데 유용하지만 제품용 서비스 수준을 보장하지 않는다.

## 예시
```text
Space 선택 → 프롬프트 입력 → GPU 대기
→ 결과 평가 → 연결된 모델 카드 확인
```

## 요약
- Space는 모델을 설치하기 전에 기능을 빠르게 시험하는 수단이다.
- 데모의 오류와 대기 시간은 호스팅 자원 제한에서 올 수 있다.
