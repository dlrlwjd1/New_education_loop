# Huggingface Opensource Finetuning Datasets

## 개요
- Hugging Face Datasets에서 미세조정용 텍스트·이미지 데이터를 탐색한다.

## 내용
### 데이터셋 검토
강의는 Data Studio에서 수백만 행의 데이터, 스키마, 샘플과 분할 파일을 확인한다. 텍스트 데이터뿐 아니라 이미지와 프롬프트·속성을 함께 가진 대규모 데이터셋도 살펴본다.

모델 학습에 쓰기 전 언어, 열의 의미, 데이터 크기, 라이선스와 품질을 검토해야 한다.

## 예시
```text
데이터셋 카드 → Data Studio 샘플 → 스키마
→ Files and versions → 크기·분할·라이선스 확인
```

## 요약
- 데이터 행 수보다 내용과 라이선스·품질 검증이 중요하다.
- 여러 공개 데이터셋을 조합해 미세조정 데이터를 구성할 수 있다.
