# When to use LLM Finetuning

## 개요
- 모델 가중치를 바꾸는 미세조정(fine-tuning)과 RAG의 사용 조건을 비교한다.

## 내용
### 지식 갱신과 행동 변경
미세조정은 추가 데이터로 모델을 재학습해 가중치와 편향을 변경한다. 특정 형식·어조·행동을 일관되게 만들 수 있지만 시간과 계산 비용이 크고, 지식을 갱신하려면 다시 학습해야 한다.

RAG는 문서를 교체하거나 다시 색인해 최신 정보를 빠르게 반영할 수 있지만 검색·저장·생성 파이프라인을 운영해야 한다.

## 예시
- 자주 바뀌는 고객 지원 정책: RAG
- 고정된 전문 응답 형식과 행동 학습: 미세조정

## 요약
- 새 지식을 제공하려면 RAG를 우선 검토한다.
- 모델의 행동 자체를 바꾸려면 미세조정을 검토한다.
