# How RAG Works

## 개요
- 외부 문서를 검색해 관련 문맥을 LLM 입력에 추가하는 RAG 파이프라인을 설명한다.

## 내용
### 검색 증강 생성
문서를 청크(chunk)로 나누고 임베딩으로 변환해 벡터 데이터베이스에 저장한다. 질문이 들어오면 질문 임베딩과 가까운 청크를 검색하고, 관련 문맥과 질문을 함께 LLM에 전달한다.

강의에서는 FAISS, pgvector, Pinecone, Qdrant 같은 저장소와 LangChain 계열 프레임워크를 예로 든다.

## 예시
```text
문서 → 청크 → 임베딩 → 벡터 DB
질문 → 임베딩 → 유사도 검색 → 문맥 + 질문 → LLM
```

## 요약
- RAG는 모델 가중치를 바꾸지 않고 외부 지식을 제공한다.
- 청킹, 임베딩, 검색 품질이 답변 품질에 직접 영향을 준다.
