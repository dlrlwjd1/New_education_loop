# What is Generative AI?

## 개요
- 학습한 패턴을 바탕으로 텍스트·이미지·음악·코드 같은 새 콘텐츠를 만드는 생성형 AI를 설명한다.

## 내용
### 확률적 콘텐츠 생성
분류 모델이 입력을 정해진 범주로 예측한다면, 생성형 AI는 입력 프롬프트를 조건으로 새로운 출력을 생성한다. 같은 프롬프트를 반복해도 표현이 달라질 수 있지만 핵심 의미는 유지될 수 있다.

강의에서는 GPT·Gemini 계열 텍스트 모델, Stable Diffusion·Midjourney 계열 이미지 모델, Whisper 음성 인식, 음악 생성과 과학 연구용 모델을 사례로 든다. 멀티모달 모델은 텍스트뿐 아니라 이미지·오디오 등 여러 입력 형식을 처리한다.

## 예시
```text
입력: Explain generative AI in a single line.
결과: 문장은 매번 달라도 "학습한 패턴으로 새 콘텐츠를 생성한다"는 의미는 유지된다.
```

## 요약
- 생성형 AI는 학습 데이터의 패턴을 사용해 새 결과를 만든다.
- 출력은 확률적이므로 같은 입력에도 표현이 달라질 수 있다.
