# Programming Tools I Will Use During this Course

## 개요

- 이 강의에서는 Ubuntu에서 ROS 2를 사용하기 위한 도구와 환경 설정에 대해 설명합니다.
- 유형: 동영상
- 길이: 5분
- 원문: [Udemy 강의](https://www.udemy.com/course/ros2-for-beginners/learn/lecture/21305238#overview)

## 내용

- 터미널 도구를 소개하고, Terminator를 설치하여 여러 터미널을 쉽게 나눌 수 있습니다.
- VS Code를 설치하여 ROS 2 프로그래밍에 적합한 IDE로 사용합니다.
- VS Code에서 ROS 확장 및 CMake 확장을 설치하여 코드 자동 완성과 문법 하이라이팅 기능을 제공합니다.
- Jedit 텍스트 에디터를 소개하고, 기본적인 텍스트 편집에 사용할 수 있습니다.

## 예시

- 터미널에서 'sudo apt install terminator' 명령어로 Terminator 설치
- VS Code에서 'sudo snap install code --classic' 명령어로 VS Code 설치
- VS Code 확장 패널에서 'Ross' 검색하여 Microsoft ROS 확장 설치

## 요약

- 터미널과 VS Code를 사용하여 ROS 2 프로그래밍을 시작합니다.
- VS Code의 확장 기능을 활용하여 코드 자동 완성과 문법 하이라이팅을 제공합니다.
- Jedit는 기본적인 텍스트 편집에 적합한 도구로 사용됩니다.
