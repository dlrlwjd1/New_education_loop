# Note - New extension for VS Code

## 개요

- VS Code에서 사용하는 ROS 확장 프로그램이 업데이트되었으므로, 새로운 'Robot Developer Extensions for ROS 2'를 설치해야 합니다.
- 유형: 문서/활동
- 길이: 1분
- 원문: [Udemy 강의](https://www.udemy.com/course/ros2-for-beginners/learn/lecture/51380955#overview)

## 내용

- 다음 강의 'Programming Tools I will use during this course'를 보면서 VS Code용 ROS 확장 프로그램이 더 이상 사용되지 않는 것을 확인합니다.
- ROS 확장 프로그램 대신 'Robot Developer Extensions for ROS 2' 확장을 설치해야 합니다.
- 'Robot Developer Extensions for ROS 2'는 기존의 ROS 확장 프로그램과 비슷한 기능을 제공하지만, 다른 이름으로 업데이트되었습니다.

## 예시

- VS Code에서 'Extensions' 탭을 열고 검색 창에 'ROS'를 입력합니다.
- 'Robot Developer Extensions for ROS 2' 확장을 찾고 설치 버튼을 클릭합니다.
- 확장 프로그램이 정상적으로 설치되었는지 확인하기 위해 VS Code를 재시작합니다.

## 요약

- VS Code용 ROS 확장 프로그램은 더 이상 사용되지 않으므로, 'Robot Developer Extensions for ROS 2'를 설치해야 합니다.
- 'Robot Developer Extensions for ROS 2'는 기존의 ROS 확장 프로그램과 비슷한 기능을 제공하지만, 다른 이름으로 업데이트되었습니다.
