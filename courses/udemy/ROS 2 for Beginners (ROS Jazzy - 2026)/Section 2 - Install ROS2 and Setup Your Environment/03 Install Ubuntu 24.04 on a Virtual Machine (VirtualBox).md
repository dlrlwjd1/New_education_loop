# Install Ubuntu 24.04 on a Virtual Machine (VirtualBox)

## 개요

- 이 강의에서는 Ubuntu 24.04를 가상 머신(VirtualBox)에 설치하여 ROS 2 개발 환경을 설정하는 방법을 설명합니다.
- 유형: 동영상
- 길이: 19분
- 원문: [Udemy 강의](https://www.udemy.com/course/ros2-for-beginners/learn/lecture/33147212#overview)

## 내용

- Ubuntu 24.04 ISO 파일 다운로드
- VirtualBox 설치
- 새 가상 머신 생성
- 가상 머신 설정 (RAM, CPU, 하드 디스크)
- Ubuntu 설치 프로세스 진행
- 네트워크 연결 및 인터페이스 설정

## 예시

- ubuntu 24.04 download 명령어 사용
- VirtualBox 설치 실행 파일 실행
- 새 가상 머신 이름: ubuntu 24.04 ROS 2 course 입력

## 요약

- Ubuntu 24.04를 가상 머신에 설치하여 ROS 2 개발 환경을 설정합니다.
- 네트워크 연결 및 인터페이스 설정이 중요합니다.
- 가상 머신의 RAM, CPU, 하드 디스크 크기를 적절히 설정해야 합니다.
