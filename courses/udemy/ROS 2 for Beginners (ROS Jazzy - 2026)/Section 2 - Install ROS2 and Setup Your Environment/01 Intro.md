# Intro

## 개요

- 이 강의에서는 ROS 2를 설치하고 환경을 설정하는 과정을 설명합니다.
- 유형: 문서/활동
- 길이: 1분
- 원문: [Udemy 강의](https://www.udemy.com/course/ros2-for-beginners/learn/lecture/21305184#overview)

## 내용

- ROS 2 버전 선택
- Ubuntu 가상 머신 설정 (필요시)
- 코스에서 사용할 프로그래밍 도구 소개
- ROS 2와 필요한 도구 설치

## 예시

- 설치할 배포판과 Ubuntu 버전의 호환성을 공식 ROS 2 문서에서 먼저 확인한다.
- Ubuntu 가상 머신 생성: `sudo apt-get install virtualbox`
- VSCode IDE 설치: 웹사이트에서 다운로드 후 설치

## 요약

- 이 강의를 통해 ROS 2 환경을 설정할 수 있습니다.
- 필요한 도구와 버전에 대해 알게 됩니다.
- 설치 과정은 간단하지만 시간이 걸릴 수 있으니 준비하시기 바랍니다.
