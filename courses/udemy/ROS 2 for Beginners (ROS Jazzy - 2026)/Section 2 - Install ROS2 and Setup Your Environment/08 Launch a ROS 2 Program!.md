# Launch a ROS 2 Program!

## 개요

- ROS 2 프로그램을 실행하여 ROS 2가 제대로 설치되었는지 확인합니다.
- 유형: 동영상
- 길이: 2분
- 원문: [Udemy 강의](https://www.udemy.com/course/ros2-for-beginners/learn/lecture/21305244#overview)

## 내용

- ROS 2 프로그램을 실행하기 위해 터미널을 두 개 열고 각각 다른 노드를 실행합니다.
- 첫 번째 터미널에서 'ros2 run demo_nodes_cpp talker' 명령어로 'talker' 노드를 실행합니다.
- 두 번째 터미널에서 'ros2 run demo_nodes_cpp listener' 명령어로 'listener' 노드를 실행합니다.
- 'talker' 노드는 메시지를 발행하고, 'listener' 노드는 해당 메시지를 수신하여 로그를 출력합니다.
- Ctrl+C 키를 눌러 프로그램을 중단할 수 있습니다.

## 예시

- ros2 run demo_nodes_cpp talker
- ros2 run demo_nodes_cpp listener

## 요약

- ROS 2 노드가 정상적으로 실행되면 설치 및 환경 설정이 올바르게 이루어졌습니다.
- Ctrl+C 키를 사용하여 프로그램을 중단할 수 있습니다.
