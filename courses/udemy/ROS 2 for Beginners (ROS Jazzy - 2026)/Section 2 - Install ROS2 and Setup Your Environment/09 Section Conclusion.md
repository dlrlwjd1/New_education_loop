# Section Conclusion

## 개요

- ROS 2를 Ubuntu에 설치하고 환경을 설정하는 과정을 마무리하며, 다음 단계로 이어갑니다.
- 유형: 문서/활동
- 길이: 1분
- 원문: [Udemy 강의](https://www.udemy.com/course/ros2-for-beginners/learn/lecture/21305204#overview)

## 내용

- ROS 2의 최신 LTS 버전인 ROS 2 Jazzy를 설치합니다.
- VS Code와 gedit를 사용하여 IDE 및 텍스트 에디터를 설정합니다.
- 다중 터미널을 화면에 표시하기 위해 Terminator를 사용합니다.
- 환경 변수를 항상 소스로드해야 하는 이유를 설명합니다.
- /opt/ros/jazzy/setup.bash 파일을 ~/.bashrc에 추가하여 환경 변수를 설정합니다.

## 예시

- source /opt/ros/jazzy/setup.bash
- VS Code와 gedit 사용
- Terminator로 다중 터미널 열기

## 요약

- ROS 2의 LTS 버전을 설치하고 환경을 설정하는 과정을 마무리했습니다.
- 다양한 IDE 중에서 자신이 편안하게 사용할 수 있는 것을 선택합니다.
- 터미널 관리를 위해 Terminator를 사용할 수 있습니다.
