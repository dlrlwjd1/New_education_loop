# Use Your Custom Msg in a Python Node

## 개요

- Python 노드에서 사용자 정의 메시지를 발행하는 방법을 배웁니다.
- 유형: 동영상
- 길이: 10분
- 원문: [Udemy 강의](https://www.udemy.com/course/ros2-for-beginners/learn/lecture/21306068#overview)

## 내용

- 사용자 정의 메시지 인터페이스를 Python 패키지에 추가합니다.
- VSCode에서 인터페이스를 인식하도록 VSCode를 재시작합니다.
- Python 노드를 생성하고 메시지를 발행하는 코드를 작성합니다.
- 메시지 객체를 생성하여 필드를 채우고 메시지를 발행합니다.
- 노드를 실행하여 메시지가 정상적으로 발행되는지 확인합니다.

## 예시

- VSCode에서 인터페이스를 인식하도록 재시작하는 방법
- Python 노드에서 메시지를 발행하는 코드 예시
- 메시지 객체 생성 및 필드 채우기 예시

## 요약

- VSCode를 재시작하여 인터페이스를 인식하도록 합니다.
- 메시지 객체를 생성하고 필드를 채워 메시지를 발행합니다.
- 노드를 실행하여 메시지가 정상적으로 발행되는지 확인합니다.
