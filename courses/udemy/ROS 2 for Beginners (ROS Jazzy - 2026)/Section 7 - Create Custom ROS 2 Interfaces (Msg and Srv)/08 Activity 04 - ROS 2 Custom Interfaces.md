# Activity 04 - ROS 2 Custom Interfaces

## 개요

- ROS 2에서 사용자 정의 메시지와 서비스를 만들어 배터리 상태에 따라 LED 패널 제어하는 예제를 구현합니다.
- 유형: 문서/활동
- 길이: 1분
- 원문: [Udemy 강의](https://www.udemy.com/course/ros2-for-beginners/learn/lecture/21306092#overview)

## 내용

- 배터리 노드와 LED 패널 노드를 각각 생성합니다.
- LED 패널 노드에서 사용자 정의 메시지를 이용해 LED 패널 상태를 발행합니다.
- LED 패널 노드에 사용자 정의 서비스 서버를 추가하여 LED 제어 요청을 처리합니다.
- 배터리 노드에서 배터리 상태를 시뮬레이션하고, 배터리가 비었을 때 LED 패널에 요청을 보내어 LED를 켜고, 다시 충전되었을 때 LED를 끄는 로직을 구현합니다.
- 서비스 클라이언트를 사용하여 배터리 노드에서 LED 패널 서비스를 호출하고, 배터리 상태가 변경될 때마다 LED 제어 요청을 반복적으로 전송합니다.

## 예시

- LED 패널 노드의 메시지 구조: `led_panel_state.msg`
- LED 패널 노드의 서비스 정의: `set_led.srv`
- 배터리 노드에서 LED 패널에 요청 보내는 코드 예시

## 요약

- 이 활동을 통해 ROS 2에서 사용자 정의 메시지와 서비스를 활용한 간단한 시스템 제어를 배웁니다.
- 배터리 상태에 따라 LED 패널 제어하는 로직을 구현하여 시뮬레이션합니다.
- 서비스 클라이언트와 서버를 통해 노드 간의 통신을 이해하고 실습합니다.
