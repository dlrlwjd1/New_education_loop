# Activity 04 - Solution [2/3]

## 개요

- 이 강의에서는 ROS 2에서 사용자 정의 메시지와 서비스 인터페이스를 생성하여 LED 패널 노드를 개선하는 방법을 배웁니다.
- 유형: 동영상
- 길이: 15분
- 원문: [Udemy 강의](https://www.udemy.com/course/ros2-for-beginners/learn/lecture/21306108#overview)

## 내용

- 서비스 서버를 추가하여 LED 패널 노드를 개선합니다.
- LED 번호와 상태를 전달할 수 있는 새로운 서비스 인터페이스를 만듭니다.
- 서비스 인터페이스 파일을 my_robot_interfaces 패키지의 service 폴더에 위치시킵니다.
- 서비스 서버 콜백 함수를 작성하여 LED 상태를 변경하고 검증합니다.
- 서비스 서버를 생성하여 콜백 함수와 연결합니다.
- 패키지를 빌드하고 새로운 인터페이스를 사용하도록 설정합니다.

## 예시

- set_led.srv 파일을 작성하여 LED 번호와 상태를 전달할 수 있는 서비스 인터페이스를 만듭니다.
- 서비스 서버 콜백 함수에서 LED 번호와 상태를 검증하고, 유효하지 않은 데이터에 대한 응답을 반환합니다.
- ros2 service call 명령어를 사용하여 서비스를 테스트합니다.

## 요약

- 새로운 서비스 인터페이스를 생성하여 LED 패널 노드의 기능을 확장합니다.
- 서비스 서버와 콜백 함수를 작성하여 데이터 검증과 상태 변경을 처리합니다.
- 패키지를 빌드하고 새로운 인터페이스를 사용하도록 설정하여 서비스를 실행합니다.
