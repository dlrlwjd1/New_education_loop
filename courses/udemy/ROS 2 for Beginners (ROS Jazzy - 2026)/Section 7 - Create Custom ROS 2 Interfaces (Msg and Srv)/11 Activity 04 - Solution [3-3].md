# Activity 04 - Solution [3/3]

## 개요

- 이 강의에서는 ROS 2에서 사용자 정의 메시지와 서비스를 생성하여 배터리 노드를 구현하는 방법을 학습합니다.
- 유형: 동영상
- 길이: 22분
- 원문: [Udemy 강의](https://www.udemy.com/course/ros2-for-beginners/learn/lecture/21306118#overview)

## 내용

- 배터리 노드를 만들고 배터리 상태를 모니터링하는 데 필요한 타이머를 설정합니다.
- 타이머 콜백 함수에서 배터리 상태가 변경되는 시간을 계산하고, 4초 후에 배터리가 비어지고, 6초 후에 다시 충전되는 로직을 구현합니다.
- 배터리 상태가 바뀔 때마다 LED 노드의 서비스를 호출하여 LED를 제어하는 메서드를 작성합니다.
- LED 노드에서 배터리 상태 변경을 감지하고, 배터리가 비어질 때 LED 3번을 켜고, 충전될 때 LED 3번을 끄는 로직을 구현합니다.
- 배터리 노드와 LED 노드를 실행하여 배터리 상태에 따라 LED가 제대로 작동하는지 확인합니다.

## 예시

- 타이머 콜백 함수에서 현재 시간을 가져오는 코드: `time_now = self.get_clock().now().to_msg()`
- LED 노드의 서비스를 호출하여 LED를 제어하는 메서드: `self.set_led_client.call_async(request)`
- 배터리 상태가 변경될 때마다 LED 노드의 서비스를 호출하는 로직: `if time_now - self.last_time_battery_state_changed > 4.0:`

## 요약

- 타이머와 콜백 함수를 사용하여 배터리 상태를 모니터링합니다.
- 배터리 상태가 변경될 때마다 LED 노드의 서비스를 호출하여 LED를 제어합니다.
- LED 노드에서 배터리 상태 변경을 감지하고, 배터리가 비어질 때 LED 3번을 켜고, 충전될 때 LED 3번을 끄는 로직을 구현합니다.
