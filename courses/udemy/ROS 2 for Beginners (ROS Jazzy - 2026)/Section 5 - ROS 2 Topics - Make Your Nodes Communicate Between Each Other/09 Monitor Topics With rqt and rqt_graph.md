# Monitor Topics With rqt and rqt_graph

## 개요

- ROS 2 토픽을 사용하여 노드 간 통신을 모니터링하는 방법을 배웁니다.
- 유형: 동영상
- 길이: 7분
- 원문: [Udemy 강의](https://www.udemy.com/course/ros2-for-beginners/learn/lecture/21305640#overview)

## 내용

- Actigraph를 사용하여 ROS 2 토픽을 모니터링합니다.
- 노드와 토픽을 생성하고, 발행자(Publisher)와 구독자(Subscriber)를 설정합니다.
- Activity Graph를 사용하여 노드와 토픽의 연결 상태를 확인합니다.
- 다양한 노드와 토픽을 추가하여 통신을 확장합니다.
- 노드 이름과 토픽 이름을 동적으로 변경하여 애플리케이션의 유연성을 높입니다.

## 예시

- ross run cpp_robot_news_station
- ross run python_smartphone
- ross run pi_pg_with_robot_news_station -r node station2

## 요약

- 노드와 토픽을 사용하여 ROS 2에서 통신을 구현할 수 있습니다.
- 노드 이름과 토픽 이름을 동적으로 변경하여 애플리케이션의 유연성을 높일 수 있습니다.
- Activity Graph를 사용하여 노드와 토픽의 연결 상태를 모니터링할 수 있습니다.
