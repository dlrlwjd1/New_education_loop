# What is a ROS 2 Topic?

## 개요

- ROS 2 토픽이 무엇인지 이해하고, 노드 간의 데이터 통신 방법을 배운다.
- 유형: 동영상
- 길이: 8분
- 원문: [Udemy 강의](https://www.udemy.com/course/ros2-for-beginners/learn/lecture/21305600#overview)

## 내용

- 토론 시작: 실생활의 라디오 발신기와 수신기를 사용하여 ROS 2 토픽 개념 설명
- 라디오 발신기는 특정 주파수(예: 98.7)에서 데이터를 전송하고, 이는 노드가 메시지를 받을 수 있도록 하는 이름으로 표현됨
- 라디오 수신기는 해당 주파수(98.7)에 연결하여 메시지를 수신함
- 발신기와 수신기는 동일한 데이터 구조를 사용해야 함
- 다른 장치나 차량에서도 같은 토픽을 통해 메시지를 전송하고 수신할 수 있음
- 노드는 발행자 또는 구독자로 작동하며, 각각 독립적이고 익명임

## 예시

- 라디오 발신기는 FM 신호를 주파수 98.7에서 전송
- 라디오 수신기는 AM 신호를 디코딩하려고 하면 데이터가 정상적으로 수신되지 않음
- 노드는 여러 토픽에 대해 발행자와 구독자를 가질 수 있음

## 요약

- ROS 2 토픽은 노드 간의 메시지 교환을 위한 이름이 있는 버스임
- 발신기와 수신기는 동일한 데이터 구조를 사용해야 함
- 노드는 발행자 또는 구독자로 작동하며, 각각 독립적이고 익명임
