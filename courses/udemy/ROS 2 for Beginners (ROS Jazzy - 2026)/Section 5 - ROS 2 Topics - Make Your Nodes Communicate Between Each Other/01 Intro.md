# Intro

## 개요

- 이 강의에서는 ROS 2 토픽을 사용하여 노드 간 통신을 구현하는 방법을 배운다.
- 유형: 문서/활동
- 길이: 1분
- 원문: [Udemy 강의](https://www.udemy.com/course/ros2-for-beginners/learn/lecture/21305596#overview)

## 내용

- ROS 2 토픽에 대한 개념을 실생활의 예를 통해 이해한다.
- Python과 C++로 직접 토픽(Publisher/Subscriber)을 작성한다.
- ROS 2 도구를 사용하여 토픽을 디버깅한다.
- Turtlesim에서 토픽을 실험한다.
- 이전에 배운 내용을 연습하기 위한 활동을 수행한다.

## 예시

- ROS 2 토픽의 개념 이해를 위해 실생활 예시 사용
- Python 코드로 Publisher와 Subscriber 작성
- C++ 코드로 Publisher와 Subscriber 작성

## 요약

- ROS 2 토픽을 통해 노드 간 통신이 가능하다는 것을 배운다.
- 실제 코드를 통해 토픽의 작동 방식을 이해한다.
- Turtlesim을 사용하여 토픽의 활용을 연습한다.
