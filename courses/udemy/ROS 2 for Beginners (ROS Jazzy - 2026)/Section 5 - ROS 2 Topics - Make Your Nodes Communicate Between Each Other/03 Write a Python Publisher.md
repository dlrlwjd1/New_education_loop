# Write a Python Publisher

## 개요

- Python에서 ROS 2 퍼블리셔를 작성하여 노드 간 통신을 구현하는 방법을 배웁니다.
- 유형: 동영상
- 길이: 20분
- 원문: [Udemy 강의](https://www.udemy.com/course/ros2-for-beginners/learn/lecture/21305606#overview)

## 내용

- ROS 2 퍼블리셔와 노드의 개념 이해
- 노드 생성 및 Python 패키지 설정
- 퍼블리셔 클래스 정의
- 메시지 타입과 이름 지정
- 퍼블리셔 생성 및 메시지 발행
- 타이머 사용하여 주기적인 메시지 발행

## 예시

- Robot News Station 노드 생성
- msg.data 필드 설정
- self.publisher.publish(msg) 호출

## 요약

- ROS 2 퍼블리셔를 사용하여 노드 간 통신을 구현할 수 있습니다.
- 메시지 타입과 이름은 명확하게 지정해야 합니다.
- 타이머를 사용하여 주기적인 메시지 발행이 가능합니다.
