# Section Conclusion

## 개요

- 이 강의에서는 ROS 2에서 사용할 중요한 도구인 ros2 cli와 rqt를 배우고, Turtlesim 패키지를 통해 학습 내용을 적용할 수 있는 간단한 2D 로봇을 소개했습니다.
- 유형: 문서/활동
- 길이: 1분
- 원문: [Udemy 강의](https://www.udemy.com/course/ros2-for-beginners/learn/lecture/21305562#overview)

## 내용

- ros2 cli와 rqt의 중요성 이해
- Turtlesim 패키지에 대한 소개
- 노드 생성, 컴파일 및 실행 방법 배우기
- 디버깅 도구 사용법 학습
- 다른 패키지에서의 노드 실행 방법 알아보기

## 예시

- ros2 run turtlesim turtlesim_node
- rqt_graph를 사용하여 노드 간 연결 확인
- Turtlesim 패키지를 통해 로봇 제어 명령 사용

## 요약

- ros2 cli와 rqt 도구를 활용해 ROS 2 애플리케이션 개발에 필요한 기초를 다졌습니다.
- Turtlesim 패키지를 통해 학습한 내용을 실제로 적용할 수 있는 실습 환경을 구축했습니다.
- 노드 생성, 컴파일, 실행, 디버깅 등 기본적인 노드 관리 능력을 배웠습니다.
