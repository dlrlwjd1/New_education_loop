# Introspect Your Nodes With ros2 cli

## 개요

- ROS 2의 ros2 cli를 사용하여 노드를 관찰하고 정보를 확인하는 방법을 학습합니다.
- 유형: 동영상
- 길이: 8분
- 원문: [Udemy 강의](https://www.udemy.com/course/ros2-for-beginners/learn/lecture/21305532#overview)

## 내용

- ros2 cli의 주요 기능들을 소개합니다.
- ros2 run 명령어로 노드를 시작하는 방법을 설명합니다.
- ros2 node list 명령어로 현재 실행 중인 노드 목록을 확인합니다.
- ros2 node info 명령어로 특정 노드에 대한 정보를 확인합니다.
- 노드 이름의 유일성을 유지하기 위한 주의사항을 강조합니다.

## 예시

- ros2 run demo_nodes_cpp talker
- ros2 node list
- ros2 node info /talker

## 요약

- ROS 2 cli를 사용하여 노드를 관찰하고 정보를 확인할 수 있습니다.
- 노드 이름의 유일성을 유지하는 것이 중요합니다.
- ros2 run, ros2 node list, ros2 node info 명령어는 필수적인 도구입니다.
