# Rqt and rqt_graph

## 개요

- ROS 2의 Rqt와 rqt_graph 도구를 소개하고, 노드 그래프를 통해 시스템의 구조와 통신을 확인하는 방법을 학습합니다.
- 유형: 동영상
- 길이: 4분
- 원문: [Udemy 강의](https://www.udemy.com/course/ros2-for-beginners/learn/lecture/21305546#overview)

## 내용

- Rqt와 rqt_graph 도구에 대해 설명합니다.
- RCT (ROS Configuration Tool)를 사용하여 노드 그래프를 시작합니다.
- 노드를 추가하고, RCT 그래프에서 노드의 통신 관계를 확인합니다.
- 디버그 모드를 활성화하여 데이터 흐름을 시각화합니다.
- RCT 그래프를 통해 시스템의 전반적인 구조를 파악할 수 있습니다.

## 예시

- rqt_graph 명령어로 RCT 그래프를 실행합니다.
- 노드를 시작하는 방법: ros2 run 패키지 이름 노드 이름
- 디버그 모드 활성화: 체크박스에서 'Debug'을 해제합니다.

## 요약

- RCT는 ROS 2 애플리케이션의 내부 구조와 통신을 시각적으로 확인할 수 있는 도구입니다.
- rqt_graph를 사용하여 노드 그래프를 쉽게 생성하고 관찰할 수 있습니다.
- 디버그 모드를 통해 데이터 흐름을 명확하게 파악할 수 있습니다.
