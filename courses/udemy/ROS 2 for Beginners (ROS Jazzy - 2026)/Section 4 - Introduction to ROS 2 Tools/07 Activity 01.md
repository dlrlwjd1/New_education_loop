# Activity 01

## 개요

- 이 강의에서는 ROS 2 노드와 도구를 사용하여 특정 그래프를 생성하는 실습을 수행합니다.
- 유형: 문서/활동
- 길이: 1분
- 원문: [Udemy 강의](https://www.udemy.com/course/ros2-for-beginners/learn/lecture/21305556#overview)

## 내용

- ROS 2 노드와 도구에 대해 이해합니다.
- rqt_graph를 사용하여 노드 간 연결 관계를 시각화합니다.
- 4개의 노드를 시작해야 합니다: Python과 Cpp 노드, 그리고 Turtlesim 패키지의 2개의 노드.
- 노드를 터미널에서 시작하는 방법을 배웁니다.
- 적절한 명령어를 사용하여 각 노드를 실행합니다.
- 다음 강의에서는 이 실습의 해결책을 제공합니다.

## 예시

- rqt_graph를 사용하여 그래프 시각화
- 터미널에서 'ros2 run 패키지 이름 노드 이름' 명령어 사용
- Turtlesim 패키지의 노드 시작: 'ros2 run turtlesim turtlesim_node'와 'ros2 run turtlesim turtle_teleop_key'

## 요약

- 이 실습을 통해 ROS 2 노드를 직접 실행하고 그래프를 생성하는 방법을 배웁니다.
- 터미널에서 적절한 명령어를 사용하여 노드를 시작할 수 있습니다.
- 다음 강의에서는 이 실습의 해결책을 제공합니다.
