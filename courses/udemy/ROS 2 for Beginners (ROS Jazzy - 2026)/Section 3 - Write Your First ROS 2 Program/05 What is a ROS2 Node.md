# What is a ROS 2 Node?

## 개요

- ROS 2 노드의 개념과 사용법을 이해하고, 실제 예제를 통해 노드가 어떻게 구성되고 통신하는지 배운다.
- 유형: 동영상
- 길이: 6분
- 원문: [Udemy 강의](https://www.udemy.com/course/ros2-for-beginners/learn/lecture/21305280#overview)

## 내용

- 노드는 애플리케이션의 하위 부분으로, Python이나 C++와 같은 언어로 작성된다.
- 노드는 단일 목적을 가져야 하며, 애플리케이션에는 여러 노드가 포함되어 있으며 패키지에 담겨 있다.
- 패키지는 비어있으면 아무것도 하지 않으며, 노드를 포함해야 한다.
- 예를 들어 카메라 패키지는 카메라를 독립적인 단위로 처리하며, 드라이버와 이미지 처리 프로그램이 필요하다.
- 노드는 별도로 실행될 수 있으며, 먼저 드라이버 노드를 시작한 후 이미지 처리 노드를 실행한다.
- 노드들은 ROS 2 통신 기능을 사용하여 서로 소통하며, 주제, 서비스, 매개변수 등으로 데이터를 교환한다.

## 예시

- 카메라 패키지는 드라이버와 이미지 처리 노드로 구성된다.
- 이미지 처리 노드는 카메라로부터의 프레임을 분석하고 환경에 대한 분석 결과를 전송한다.
- 모션 계획 패키지는 로봇의 모션 계획을 계산하는 모션 계획 노드와 외부 요인으로 인한 경로 수정을 담당하는 경로 수정 노드가 있다.

## 요약

- 노드는 애플리케이션의 하위 부분으로, 단일 목적을 가져야 한다.
- 노드들은 패키지에 포함되어 있으며, 별도로 실행될 수 있다.
- ROS 2 통신 기능을 사용하여 노드들이 서로 소통한다.
