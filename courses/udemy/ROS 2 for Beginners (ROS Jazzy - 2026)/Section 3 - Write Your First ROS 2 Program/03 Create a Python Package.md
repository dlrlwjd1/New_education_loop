# Create a Python Package

## 개요

- ROS 2 패키지를 생성하고 설정하는 방법을 배웁니다.
- 유형: 동영상
- 길이: 8분
- 원문: [Udemy 강의](https://www.udemy.com/course/ros2-for-beginners/learn/lecture/21305270#overview)

## 내용

- 패키지의 개념과 역할에 대해 설명합니다.
- ROS 2에서 Python 패키지를 생성하는 과정을 단계별로 설명합니다.
- 패키지 이름과 빌드 타입 설정 방법을 다룹니다.
- 패키지 의존성 추가 방법을 설명합니다.
- 패키지의 기본 구조와 파일 내용을 살펴봅니다.
- 패키지를 빌드하는 방법을 소개합니다.

## 예시

- ros2 pkg create my_py_pkg --build-type ament_python
- package.xml 파일에서 패키지 정보를 설정합니다.
- setup.cfg와 setup.py 파일의 역할에 대해 설명합니다.

## 요약

- ROS 2 패키지는 코드를 재사용 가능한 블록으로 분리하는 데 사용됩니다.
- 패키지를 생성하고 의존성을 추가하여 프로젝트를 구성할 수 있습니다.
- package.xml 파일을 통해 패키지의 메타데이터를 설정합니다.
