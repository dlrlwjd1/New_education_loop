# Write a C++ Node - With OOP

## 개요

- C++ 노드를 객체 지향 프로그래밍(OOP)을 사용하여 작성하는 방법을 배웁니다.
- 유형: 동영상
- 길이: 11분
- 원문: [Udemy 강의](https://www.udemy.com/course/ros2-for-beginners/learn/lecture/21305304#overview)

## 내용

- 기존 노드를 개선하여 C++ 템플릿으로 만듭니다.
- 새로운 클래스를 생성하고 ClcpNode로부터 상속받습니다.
- 클래스 내에서 다양한 기능을 추가할 수 있습니다.
- Logger와 문자열을 사용하여 메시지를 출력합니다.
- 노드 생성 시 공유 포인터를 사용하여 객체를 만듭니다.
- 타이머를 추가하여 노드가 특정 주기로 동작하도록 합니다.

## 예시

- ClcpNode 클래스로부터 상속받은 새로운 클래스 'MyNode'를 정의합니다.
- 노드 생성 시 공유 포인터를 사용하여 'MyNode' 객체를 만듭니다.
- 타이머 콜백 함수를 정의하고, 노드 생성 시 타이머를 설정합니다.

## 요약

- C++ 클래스를 사용하여 ROS 2 노드를 작성하는 방법을 배웠습니다.
- 상속과 공유 포인터를 활용하여 코드 재사용성을 높였습니다.
- 타이머를 사용하여 주기적인 작업을 수행할 수 있는 노드를 만들었습니다.
