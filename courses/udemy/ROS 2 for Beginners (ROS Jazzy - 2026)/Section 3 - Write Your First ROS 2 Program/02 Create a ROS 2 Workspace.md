# Create a ROS 2 Workspace

## 개요

- ROS 2 워크스페이스를 생성하고 설정하는 방법을 학습합니다.
- 유형: 동영상
- 길이: 5분
- 원문: [Udemy 강의](https://www.udemy.com/course/ros2-for-beginners/learn/lecture/21305260#overview)

## 내용

- 홈 디렉토리로 이동하여 새로운 디렉토리를 만듭니다.
- 새로운 디렉토리를 ros2_aws라고 이름 지정합니다.
- 워크스페이스 내부에 src 디렉토리를 생성합니다.
- 워크스페이스를 빌드하기 위해 ROS 2 workspace 디렉토리로 이동합니다.
- build 명령을 사용하여 워크스페이스를 빌드합니다.
- 빌드 후 build, install, log 디렉토리가 생성됩니다.

## 예시

- cd ~
- mkdir ros2_aws
- cd ros2_aws && mkdir src

## 요약

- 워크스페이스는 ROS 2와 관련된 모든 코드를 작성하고 컴파일하는 곳입니다.
- 워크스페이스 빌드는 노드 설치 시마다 필요합니다.
- setup.bash 스크립트를 사용하여 워크스페이스 기능에 접근할 수 있습니다.
