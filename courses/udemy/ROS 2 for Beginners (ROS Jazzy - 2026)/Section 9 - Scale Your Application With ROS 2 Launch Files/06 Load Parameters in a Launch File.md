# Load Parameters in a Launch File

## 개요

- ROS 2의 런치 파일에서 노드의 파라미터 값을 설정하고, YAML 파일로부터 파라미터를 로드하는 방법을 배웁니다.
- 유형: 동영상
- 길이: 10분
- 원문: [Udemy 강의](https://www.udemy.com/course/ros2-for-beginners/learn/lecture/48733897#overview)

## 내용

- 노드 내부에 파라미터 값을 설정하는 방법을 설명합니다.
- YAML 파일로 파라미터를 관리하는 방법을 소개합니다.
- 런치 파일에서 YAML 파일로부터 파라미터를 로드하는 방법을 설명합니다.
- Python launch 파일에서도 YAML 파일로부터 파라미터를 로드할 수 있는 방법을 다룹니다.

## 예시

- Ros args를 사용하여 노드의 파라미터 값을 설정하는 예시
- YAML 파일에 파라미터를 정의하는 예시 (number_params.yaml)
- 런치 파일에서 YAML 파일 로드하는 예시 (number_app.launch.xml)

## 요약

- 파라미터 관리는 노드의 동작을 쉽게 조정할 수 있습니다.
- YAML 파일로 파라미터를 관리하면 유지보수와 재사용성이 높아집니다.
- 런치 파일에서 YAML 파일 로드는 파라미터 설정을 간결하게 할 수 있습니다.
