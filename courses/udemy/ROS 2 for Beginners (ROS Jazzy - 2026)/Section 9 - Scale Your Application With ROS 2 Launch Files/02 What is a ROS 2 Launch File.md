# What is a ROS 2 Launch File?

## 개요

- ROS 2 Launch File에 대해 이해하고, 이를 사용하여 여러 노드를 자동으로 시작하는 방법을 배운다.
- 유형: 동영상
- 길이: 2분
- 원문: [Udemy 강의](https://www.udemy.com/course/ros2-for-beginners/learn/lecture/21306506#overview)

## 내용

- ROS 2 Launch File이 무엇인지 설명한다.
- 노드의 파라미터 설정과 이름 변경을 통해 복잡한 시나리오를 예시로 들린다.
- Launch File을 사용하여 모든 노드를 한 파일에서 시작할 수 있음을 보여준다.
- YAML 파일도 로드하고, 리맵핑을 적용하는 방법을 설명한다.
- 실제 애플리케이션에서 Launch File의 중요성을 강조한다.

## 예시

- camera_driver 노드를 시작하는 명령어 예시
- YAML 파일을 로드하는 코드 구조 예시
- Launch File에서 리맵핑 설정 방법 예시

## 요약

- Launch File은 여러 노드를 자동으로 시작할 수 있는 편리한 도구다.
- 노드의 파라미터와 이름을 설정하는 것은 Launch File에서 중요한 작업이다.
- YAML 파일을 사용하여 복잡한 설정을 관리할 수 있다.
