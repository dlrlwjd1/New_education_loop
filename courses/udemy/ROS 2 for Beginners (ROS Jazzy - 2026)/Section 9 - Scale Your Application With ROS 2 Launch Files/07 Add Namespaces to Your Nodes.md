# Add Namespaces to Your Nodes

## 개요

- ROS 2에서 노드에 네임스페이스를 추가하여 이름 충돌을 방지하고 애플리케이션을 동적으로 관리하는 방법을 배웁니다.
- 유형: 동영상
- 길이: 13분
- 원문: [Udemy 강의](https://www.udemy.com/course/ros2-for-beginners/learn/lecture/48733903#overview)

## 내용

- 네임스페이스의 개념을 이해합니다.
- 노드에 네임스페이스를 추가하는 방법을 설명합니다.
- 네임스페이스가 노드 이름, 주제 이름 등 모든 이름에 영향을 미치는 것을 확인합니다.
- 네임스페이스를 사용하여 여러 로봇의 애플리케이션을 분할하는 방법을 설명합니다.
- 런치 파일에서 네임스페이스를 추가하는 방법을 설명합니다.
- 네임스페이스가 주제 이름에 영향을 미치는 문제를 해결하는 방법을 설명합니다.

## 예시

- 노드 실행 명령: `ros2 run cbp number_publisher`
- 네임스페이스 추가 명령: `ros2 run cbp number_publisher --ros-args -r __ns:=test`
- 런치 파일 예시: `<node pkg=

## 요약

- 네임스페이스는 이름 충돌을 방지하고 애플리케이션의 동적 관리를 가능하게 합니다.
- 네임스페이스를 사용하여 여러 로봇의 애플리케이션을 분할할 수 있습니다.
- 런치 파일에서 네임스페이스를 추가하여 노드 이름과 주제 이름에 영향을 미칠 수 있습니다.
