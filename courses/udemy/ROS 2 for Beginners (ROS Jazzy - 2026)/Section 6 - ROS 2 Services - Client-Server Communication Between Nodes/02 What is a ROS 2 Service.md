# What is a ROS 2 Service?

## 개요

- ROS 2 서비스에 대해 이해하고, 클라이언트와 서버 간의 통신 방식을 배운다.
- 유형: 동영상
- 길이: 6분
- 원문: [Udemy 강의](https://www.udemy.com/course/ros2-for-beginners/learn/lecture/21305760#overview)

## 내용

- ROS 2 서비스는 Ros 토픽과 유사한 개념으로, 요청-응답 패턴을 사용한다.
- 실생활 예로 온라인 날씨 서비스를 들려주며, 클라이언트와 서버의 역할을 설명한다.
- 클라이언트는 HTTP 요청을 통해 서버에 위치 정보를 보내고, 서버는 해당 위치의 날씨를 응답으로 보낸다.
- 여러 클라이언트가 있을 경우에도 각각이 같은 URL을 통해 요청을 보낼 수 있으며, 서버는 각 클라이언트에게 응답한다.
- ROS 2 서비스는 동기식과 비동기식 두 가지 방식으로 작동할 수 있다.
- 비동기식에서는 클라이언트가 요청을 보내고 응답이 도착할 때까지 기다리지 않고, 콜백 함수를 등록하여 계속 실행한다.

## 예시

- 강의에서는 웹 요청의 URL처럼 클라이언트가 이름을 통해 특정 기능을 호출하는 비유로 서비스 이름을 설명한다.
- 클라이언트는 위치 정보를 포함한 요청을 보낸다.
- 서버는 요청을 처리하고 날씨 정보를 응답으로 보낸다.

## 요약

- ROS 2 서비스는 클라이언트와 서버 간의 통신을 위한 시스템이다.
- 서비스는 동기식과 비동기식 두 가지 방식으로 작동할 수 있다.
- 서비스는 이름과 요청/응답 메시지 쌍으로 정의된다.
