# Introspect Services with the ros2 Command Line

## 개요

- ROS 2 서비스를 인스펙트하는 ROS 2 명령어를 사용하여 서비스 정보를 확인하고, 터미널에서 서비스 호출 방법을 배웁니다.
- 유형: 동영상
- 길이: 7분
- 원문: [Udemy 강의](https://www.udemy.com/course/ros2-for-beginners/learn/lecture/21305820#overview)

## 내용

- ROS 2 명령어로 서비스 인스펙트하기
- 서비스 서버 시작 및 서비스 목록 확인
- 노드 정보와 서비스 찾기
- 서비스 타입 확인
- 서비스 인터페이스 내용 보기
- 터미널에서 서비스 호출 방법 이해

## 예시

- ros2 service list
- ros2 node info <node_name>
- ros2 service type <service_name>

## 요약

- ROS 2 명령어를 사용하여 서비스 정보를 쉽게 확인할 수 있습니다.
- 터미널에서 서비스 호출 시 자동 완성 기능을 활용하면 편리합니다.
- 서비스 인터페이스 내용을 보고 요청 필드를 정확하게 작성할 수 있습니다.
