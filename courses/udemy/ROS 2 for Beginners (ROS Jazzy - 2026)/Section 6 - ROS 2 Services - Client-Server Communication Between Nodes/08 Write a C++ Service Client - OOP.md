# Write a C++ Service Client - OOP

## 개요

- C++에서 OOP를 사용하여 ROS 2 서비스 클라이언트를 작성하는 방법을 배웁니다.
- 유형: 동영상
- 길이: 13분
- 원문: [Udemy 강의](https://www.udemy.com/course/ros2-for-beginners/learn/lecture/21305812#overview)

## 내용

- OOP 스타일의 노드에 직접 C++ 서비스 클라이언트를 작성합니다.
- 서비스 인터페이스와 클라이언트를 포함한 노드 구조를 만듭니다.
- 클라이언트를 생성하고 초기화합니다.
- 서비스가 준비될 때까지 기다립니다.
- 요청을 보내고 응답 처리를 위한 콜백 함수를 등록합니다.
- 노드를 실행하여 서비스 클라이언트와 서버 간 통신을 테스트합니다.

## 예시

- 클라이언트 노드에서 `add_to_int` 서비스 클라이언트를 생성합니다.
- 요청과 응답에 대한 콜백 함수를 정의합니다.
- 노드가 실행될 때까지 서비스가 준비될 때까지 기다립니다.

## 요약

- OOP를 사용하여 ROS 2 서비스 클라이언트를 작성하는 방법을 배웠습니다.
- 클라이언트와 서버 간의 통신을 테스트할 수 있습니다.
- 콜백 함수를 사용하여 응답을 처리할 수 있습니다.
