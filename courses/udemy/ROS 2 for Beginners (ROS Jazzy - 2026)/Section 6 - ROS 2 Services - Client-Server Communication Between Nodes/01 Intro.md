# Intro

## 개요

- ROS 2 서비스를 이해하고 사용하는 방법을 배운다.
- 유형: 문서/활동
- 길이: 1분
- 원문: [Udemy 강의](https://www.udemy.com/course/ros2-for-beginners/learn/lecture/21305756#overview)

## 내용

- ROS 2의 주요 통신 기능인 토픽과 서비스에 대해 설명한다.
- 서비스의 개념과 언제 사용해야 하는지 실생활의 예로 설명한다.
- Python과 C++로 자신의 서비스(클라이언트 + 서버)를 작성한다.
- 터미널에서 서비스를 탐색하는 방법을 배운다.
- Turtlesim에서 서비스를 실험해본다.
- 이전에 작성한 코드를 기반으로 활동을 수행한다.

## 예시

- 서비스의 클라이언트와 서버를 구현하는 예제 코드
- 터미널에서 'ros2 service list' 명령 사용법
- Turtlesim에서 서비스 호출 예시

## 요약

- ROS 2 서비스는 클라이언트-서버 패턴으로 데이터 교환을 지원한다.
- 서비스를 사용할 때 적절한 시점과 방법을 이해해야 한다.
- Python과 C++로 서비스를 구현하고 테스트할 수 있다.
