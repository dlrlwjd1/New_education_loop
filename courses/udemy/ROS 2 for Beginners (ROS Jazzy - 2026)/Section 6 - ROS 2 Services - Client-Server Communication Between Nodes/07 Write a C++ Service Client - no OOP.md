# Write a C++ Service Client - no OOP

## 개요

- C++ 서비스 클라이언트를 작성하여 ROS 2 서비스 서버와의 통신을 이해합니다.
- 유형: 동영상
- 길이: 12분
- 원문: [Udemy 강의](https://www.udemy.com/course/ros2-for-beginners/learn/lecture/21305798#overview)

## 내용

- C++로 서비스 클라이언트를 생성합니다.
- 클라이언트 노드를 초기화하고 ROS 2 통신을 설정합니다.
- 서비스 클라이언트를 생성하고 인터페이스를 제공합니다.
- 서버가 준비될 때까지 클라이언트가 대기합니다.
- 요청을 보내고 응답을 기다립니다.
- 응답을 처리하고 프로그램을 종료합니다.

## 예시

- client_no_oop.cpp 파일을 생성하여 클라이언트를 작성합니다.
- rclcpp::Node를 사용하여 노드를 초기화합니다.
- create_client 함수를 사용하여 서비스 클라이언트를 생성합니다. 인터페이스와 서비스 이름을 제공합니다.

## 요약

- C++로 서비스 클라이언트를 작성하는 방법을 배웁니다.
- 서버가 준비될 때까지 클라이언트가 대기하고 요청을 보내는 과정을 이해합니다.
- 응답을 처리하여 프로그램을 종료합니다.
