# Write a Python Service Client - OOP

## 개요

- ROS 2 서비스 클라이언트를 작성하는 과정에서 OOP를 사용하여 노드 내에 통합하는 방법을 배웁니다.
- 유형: 동영상
- 길이: 13분
- 원문: [Udemy 강의](https://www.udemy.com/course/ros2-for-beginners/learn/lecture/21305782#overview)

## 내용

- OOP를 사용한 노드 내 서비스 클라이언트 통합 방법 설명
- 서비스 클라이언트 생성 및 초기화
- 요청 메서드 구현
- 서비스 응답 대기 및 처리
- 비동기 요청 전송
- 콜백 함수 등록 및 호출

## 예시

- OOP를 사용한 노드 파일 생성 및 실행 권한 설정
- 서비스 인터페이스 임포트
- 서비스 클라이언트 생성 및 초기화 코드 예시 (self.client = self.create_client(AddTwoInts, 'add_two_ints'))

## 요약

- OOP를 사용하여 노드 내 서비스 클라이언트 통합은 가능합니다.
- 비동기 요청 전송과 콜백 함수 등록을 통해 응답 처리가 가능합니다.
- 요청 및 응답에 대한 로그 출력이 필요할 수 있습니다.
