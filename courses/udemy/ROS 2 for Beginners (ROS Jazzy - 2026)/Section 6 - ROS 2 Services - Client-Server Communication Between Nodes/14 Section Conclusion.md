# Section Conclusion

## 개요

- ROS 2 서비스를 사용하여 노드 간 클라이언트/서버 통신을 구현하는 방법에 대해 학습합니다.
- 유형: 문서/활동
- 길이: 1분
- 원문: [Udemy 강의](https://www.udemy.com/course/ros2-for-beginners/learn/lecture/21305856#overview)
- 첨부 자료: code_end_section6.zip

## 내용

- 서비스의 개념과 특징을 이해합니다: 동기적 또는 비동기적, 익명성
- 노드 내에서 서비스를 구현하는 단계를 설명합니다: 노드 생성, 서비스 서버 추가
- 클라이언트가 서비스 서버를 호출할 때 사용해야 하는 규칙을 설명합니다: 서비스 이름과 타입 일치
- 서비스와 토픽의 차이점을 이해하고 언제 사용하는지 결정하는 방법을 설명합니다
- 노드 간 통신을 추가하려면 데이터 전송인지 응답 기대 여부를 고려합니다

## 예시

- 서비스 서버를 생성하는 코드 예시
- 클라이언트가 서비스 서버를 호출하는 방법
- 서비스와 토픽의 차이점을 구분하는 질문 예시

## 요약

- 서비스는 클라이언트/서버 통신을 위한 도구입니다.
- 노드 내에서 서비스를 추가할 때는 이름과 타입 일치해야 합니다.
- 데이터 전송 여부에 따라 토픽 또는 서비스를 선택합니다.
