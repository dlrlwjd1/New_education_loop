# Write a Python Service Client - no OOP

## 개요

- Python 서비스 클라이언트를 작성하여 ROS 2 서비스와의 통신을 직접 테스트하는 방법을 배웁니다.
- 유형: 동영상
- 길이: 13분
- 원문: [Udemy 강의](https://www.udemy.com/course/ros2-for-beginners/learn/lecture/21305778#overview)

## 내용

- ROS 2 서비스 클라이언트를 생성하여 서비스 호출을 가능하게 합니다.
- 비 객체 지향적(non-OOP) 스크립트를 작성하여 간단한 서비스 테스트에 사용할 수 있습니다.
- 노드 초기화, 클라이언트 생성, 서비스 대기 및 요청 전송 과정을 설명합니다.
- 클라이언트가 서비스가 준비될 때까지 기다리는 방법을 배웁니다.
- 요청 객체를 생성하고 서비스 호출을 비동기적으로 수행하는 방법을 설명합니다.
- 노드가 응답을 받을 때까지 루프를 돌며 통신이 완료될 때까지 기다립니다.

## 예시

- no_oop.py 파일을 생성하고 실행 가능한 스크립트로 만듭니다.
- node.create_client() 메서드를 사용하여 서비스 클라이언트를 생성합니다.
- client.wait_for_service() 메서드를 사용하여 서비스가 준비될 때까지 기다립니다.

## 요약

- 비 객체 지향적 스크립트를 사용하여 ROS 2 서비스 클라이언트를 작성할 수 있습니다.
- 클라이언트가 서비스가 준비될 때까지 기다리는 것이 중요합니다.
- 요청을 비동기적으로 전송하고 응답을 받는 방법을 이해해야 합니다.
