# Write a C++ Service Server

## 개요

- C++ 서비스 서버를 작성하는 방법을 배웁니다.
- 유형: 동영상
- 길이: 14분
- 원문: [Udemy 강의](https://www.udemy.com/course/ros2-for-beginners/learn/lecture/21305788#overview)

## 내용

- ROS 2의 인터페이스 파일을 생성하고, 요청과 응답 메시지를 정의합니다.
- C++ 패키지의 소스 폴더에서 새로운 C++ 파일을 생성합니다.
- 서비스 서버 노드를 작성하고, 필요한 인터페이스를 포함합니다.
- 서비스 서버를 초기화하고, 요청과 응답 메시지를 처리하는 콜백 함수를 정의합니다.
- 노드가 회전할 때 콜백 함수가 호출되도록 설정합니다.
- 서비스 서버를 실행하고, 클라이언트로부터 요청을 받아 처리합니다.

## 예시

- interface 파일에서 request와 response 메시지를 정의하는 방법
- C++ 패키지의 소스 폴더에서 새로운 C++ 파일 생성
- 서비스 서버 노드를 작성하고 필요한 인터페이스 포함하는 예제 코드

## 요약

- ROS 2 서비스 서버는 요청과 응답 메시지를 처리하는 역할을 합니다.
- C++ 패키지의 소스 폴더에서 새로운 C++ 파일을 생성하여 서비스 서버를 작성합니다.
- 서비스 서버 노드를 초기화하고, 요청과 응답 메시지를 처리하는 콜백 함수를 정의합니다.
