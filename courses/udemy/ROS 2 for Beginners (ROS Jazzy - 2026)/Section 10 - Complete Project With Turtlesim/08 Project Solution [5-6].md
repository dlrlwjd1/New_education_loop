# Project Solution [5/6]

## 개요

- 최종 프로젝트의 마지막 단계에서 거북이가 가장 가까운 거북이를 추적하도록 프로그램을 수정합니다.
- 유형: 동영상
- 길이: 8분
- 원문: [Udemy 강의](https://www.udemy.com/course/ros2-for-beginners/learn/lecture/21306716#overview)

## 내용

- 거북이 생성기를 통해 거북이를 더 빠르게 생성합니다.
- 거북이 컨트롤러에서 가장 가까운 거북이를 추적하도록 코드를 수정합니다.
- self.catch_closest_turtle_first 변수를 추가하여 사용자가 가장 가까운 거북이를 추적할지 순서대로 따라갈지를 선택할 수 있도록 합니다.
- 거북이 목록을 받아 각 거북이와의 거리를 계산하고 가장 가까운 거북이를 찾습니다.
- 가장 가까운 거북이를 찾아 거북이 컨트롤러에서 추적하도록 설정합니다.
- 서비스 호출로 현재 추적 중인 거북이를 제거하고 새로운 목록을 전송합니다.

## 예시

- turtle spawner의 frequency를 0.5로 변경하여 거북이 생성 속도를 높입니다.
- self.catch_closest_turtle_first 변수를 True로 설정하여 가장 가까운 거북이를 추적하도록 합니다.
- 거북이 목록을 받아 각 거북이와의 거리를 계산하고 가장 가까운 거북이를 찾습니다.

## 요약

- 거북이가 가장 가까운 거북이를 추적하도록 프로그램을 수정했습니다.
- self.catch_closest_turtle_first 변수를 사용하여 사용자가 선택할 수 있도록 했습니다.
- 거북이 목록을 받아 각 거북이와의 거리를 계산하고 가장 가까운 거북이를 찾았습니다.
