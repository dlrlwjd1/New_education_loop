# Project Solution [3/6]

## 개요

- Turtlesim 프로젝트의 세 번째 단계에서 두 노드를 연결하여 터틀 위치 정보를 공유하고, 첫 번째 터틀로 이동하는 기능을 구현합니다.
- 유형: 동영상
- 길이: 19분
- 원문: [Udemy 강의](https://www.udemy.com/course/ros2-for-beginners/learn/lecture/21306710#overview)
- 첨부 자료: final_project_step3.zip

## 내용

- 터틀 스포너 노드가 생성한 터틀 목록과 좌표를 터틀 컨트롤러 노드에게 전달하도록 설정합니다.
- 새로운 인터페이스를 만들고, 터틀 정보와 위치 데이터를 포함하는 메시지를 정의합니다.
- 터틀 스포너 노드에서 생성된 터틀 목록을 발행하고, 터틀 컨트롤러 노드에서 이를 구독하여 첫 번째 터틀로 이동하도록 합니다.
- 터틀 스포너 노드의 콜백 함수에서 새 터틀이 생성될 때마다 목록에 추가하고, 해당 목록을 발행합니다.
- 터틀 컨트롤러 노드에서 받은 터틀 목록에서 첫 번째 터틀을 선택하여 이동하도록 합니다.
- 터틀 스포너와 컨트롤러 노드가 서로 통신하여 터틀 위치 정보를 공유하고, 첫 번째 터틀로 이동하는 기능을 구현합니다.

## 예시

- 터틀 스포너 노드에서 새 터틀이 생성될 때마다 `self.live_turtles.append(new_turtle)`를 사용하여 목록에 추가합니다.
- 터틀 컨트롤러 노드에서 받은 터틀 목록을 처리하는 콜백 함수는 다음과 같습니다:
```python
def callback_alive_turtles(self, turtle_list):
    if len(turtle_list.turtles) > 0:
        self.turtle_to_catch = turtle_list.turtles[0]
```
- 터틀 스포너 노드에서 터틀을 생성할 때마다 `self.publisher.publish(self.alive_turtles)`를 사용하여 목록을 발행합니다.

## 요약

- 터틀 스포너와 컨트롤러 노드가 서로 통신하여 터틀 위치 정보를 공유하고, 첫 번째 터틀로 이동하는 기능을 구현했습니다.
- 새로운 인터페이스를 만들고 메시지를 정의하여 터틀 정보와 위치 데이터를 전달합니다.
- 터틀 스포너 노드에서 생성된 터틀 목록을 발행하고, 터틀 컨트롤러 노드에서 이를 구독하여 첫 번째 터틀로 이동하도록 합니다.
