# Project Solution [2/6]

## 개요

- Turtlesim에서 터틀을 자동으로 생성하고 이들을 주도하는 노드를 작성합니다.
- 유형: 동영상
- 길이: 20분
- 원문: [Udemy 강의](https://www.udemy.com/course/ros2-for-beginners/learn/lecture/21306708#overview)
- 첨부 자료: final_project_step2.zip

## 내용

- 터틀 스포너 노드를 생성하여 새로운 터틀을 생성하는 서비스 클라이언트를 설정합니다.
- 서비스 타입 'spawn'을 사용하여 터틀을 생성하고, 이름과 위치를 지정할 수 있습니다.
- 터틀이 생성될 때마다 콜백 함수를 통해 생성된 터틀의 정보를 확인합니다.
- 타이머를 설정하여 주기적으로 새로운 터틀을 생성하는 로직을 구현합니다.
- 생성된 터틀의 이름과 위치는 랜덤으로 결정됩니다.
- 터틀 스포너 노드를 실행하여 터틀이 정상적으로 생성되는지 확인합니다.

## 요약

- 터틀 스포너 노드를 통해 터틀을 자동으로 생성하고 이들을 주도하는 기능을 구현합니다.
- 서비스 클라이언트와 타이머를 사용하여 터틀의 생성과 관리 로직을 작성합니다.
- 터틀 생성 시 이름과 위치를 랜덤하게 설정하여 다양한 터틀을 생성할 수 있습니다.
