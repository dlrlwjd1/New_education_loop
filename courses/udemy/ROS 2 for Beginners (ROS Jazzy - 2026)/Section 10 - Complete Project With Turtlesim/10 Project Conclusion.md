# Project Conclusion

## 개요

- Turtlesim 프로젝트를 완료했지만, 언제든지 개선할 수 있습니다.
- 유형: 문서/활동
- 길이: 1분
- 원문: [Udemy 강의](https://www.udemy.com/course/ros2-for-beginners/learn/lecture/21306724#overview)

## 내용

- 새로운 거북이가 무작위로 움직일 수 있도록 만들기
- 각 거북이의 자세를 실시간으로 모니터링하기 위해 동적으로 구독 생성
- 거북이 컨트롤러에게 언제든지 어디로 가야 하는지 알려주는 중간 노드 만들기
- 마스터 거북이가 다른 거북이를 잡을 때마다 펜 색상 변경
- 또한 마스터 거북이 노드 추가하여 더 빠르게 거북이 잡기

## 예시

- 거북이의 자세를 실시간으로 모니터링하기 위해 동적으로 구독 생성하는 방법
- 마스터 거북이가 다른 거북이를 잡을 때마다 펜 색상 변경하는 코드 예시
- 거북이 컨트롤러에게 언제든지 어디로 가야 하는지 알려주는 중간 노드 만들기

## 요약

- Turtlesim 프로젝트를 완료하면 ROS 2를 사용한 모든 로봇 프로젝트에서 학습한 지식을 적용할 수 있습니다.
- 거북이 컨트롤러와 중간 노드의 역할 이해
- 거북이의 자세를 실시간으로 모니터링하는 방법 배우기
