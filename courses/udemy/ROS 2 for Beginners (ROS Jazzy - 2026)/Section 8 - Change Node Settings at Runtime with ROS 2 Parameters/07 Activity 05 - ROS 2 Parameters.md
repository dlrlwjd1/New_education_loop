# Activity 05 - ROS 2 Parameters

## 개요

- ROS 2 파라미터를 사용하여 노드 설정을 런타임에 변경하는 방법을 연습합니다.
- 유형: 문서/활동
- 길이: 1분
- 원문: [Udemy 강의](https://www.udemy.com/course/ros2-for-beginners/learn/lecture/21306398#overview)

## 내용

- 1. 'robot_news_radio' 노드에서 'robot_name' 파라미터를 추가하고, 해당 파라미터의 값을 사용하여 'robot_news' 토픽에 문자열을 발행합니다.
- 2. 'led_panel_node'에서 LED 상태를 나타내는 int 배열을 파라미터로 설정합니다.
- 3. 'led_states'라는 이름의 파라미터를 사용하여 LED 상태를 저장하는 YAML 파일을 만듭니다.
- 4. 노드가 시작될 때 런타임에 이 파라미터를 로드합니다.

## 예시

- 1. 'robot_name' 파라미터를 추가하고, 해당 파라미터의 값을 사용하여 'robot_news' 토픽에 문자열을 발행하는 방법입니다.
- 2. YAML 파일을 생성하여 LED 상태를 저장하고, 노드가 시작될 때 이 파라미터를 로드하는 방법입니다.

## 요약

- 1. ROS 2 파라미터를 사용하여 노드 설정을 런타임에 변경할 수 있습니다.
- 2. 파라미터를 추가하고 해당 파라미터의 값을 사용하여 토픽에 문자열을 발행합니다.
- 3. YAML 파일을 생성하여 파라미터를 저장하고, 노드가 시작될 때 이 파라미터를 로드할 수 있습니다.
