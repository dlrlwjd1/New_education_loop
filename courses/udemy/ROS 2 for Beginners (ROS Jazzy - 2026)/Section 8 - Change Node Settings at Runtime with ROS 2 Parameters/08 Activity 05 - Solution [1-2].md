# Activity 05 - Solution [1/2]

## 개요

- ROS 2 파라미터를 사용하여 노드 설정을 런타임에 변경하는 방법을 배웁니다.
- 유형: 동영상
- 길이: 6분
- 원문: [Udemy 강의](https://www.udemy.com/course/ros2-for-beginners/learn/lecture/21306402#overview)

## 내용

- 노드의 로봇 이름을 런타임에 동적으로 변경할 수 있도록 파라미터를 사용합니다.
- 파라미터를 선언하고 기본값을 설정합니다.
- 코드에서 하드코딩된 로봇 이름을 파라미터로 대체합니다.
- 노드 시작 시 파라미터 값을 제공하여 동적으로 로봇 이름 변경이 가능합니다.
- 공간 문자열에 대한 처리 방법을 설명합니다.
- 노드의 리네임핑과 파라미터 설정 순서를 권장합니다.

## 예시

- ros2 param list 명령어로 파라미터 목록 확인
- ros2 param get station_one robot_name 명령어로 특정 노드의 파라미터 값 확인
- ros2 topic list 명령어로 토픽 목록 확인

## 요약

- 파라미터를 사용하여 노드 설정을 런타임에 변경할 수 있습니다.
- 노드 시작 시 파라미터 값을 제공하여 동적으로 로봇 이름 변경이 가능합니다.
- 공간 문자열에 대한 처리 방법을 이해하고 적용할 수 있습니다.
