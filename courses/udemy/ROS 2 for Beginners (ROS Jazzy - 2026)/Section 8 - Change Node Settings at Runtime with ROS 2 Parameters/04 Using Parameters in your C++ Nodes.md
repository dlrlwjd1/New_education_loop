# Using Parameters in your C++ Nodes

## 개요

- C++ 노드에서 파라미터를 사용하여 런타임에 값을 변경하는 방법을 배웁니다.
- 유형: 동영상
- 길이: 8분
- 원문: [Udemy 강의](https://www.udemy.com/course/ros2-for-beginners/learn/lecture/21306380#overview)

## 내용

- 파라미터의 선언과 기본값 설정 방법을 설명합니다.
- 파라미터 값 가져오기와 사용 방법을 설명합니다.
- C++ 코드에서 파라미터를 사용하여 숫자 발행자 노드를 수정합니다.
- 파라미터를 통해 런타임에 값을 변경하는 예시를 제공합니다.
- 파라미터가 존재하지 않을 때의 동작을 확인합니다.

## 예시

- declare_parameter 메서드로 파라미터 선언
- get_parameter 메서드로 파라미터 값 가져오기
- C++ 코드에서 파라미터 사용 예시 (number, timer period)

## 요약

- 파라미터는 노드 내부에 존재하지만 초기화되지 않습니다.
- 파라미터의 기본값은 선언 시 설정됩니다.
- 런타임에 파라미터 값을 변경할 수 있습니다.
