# Extra: Parameter Callbacks

## 개요

- ROS 2에서 노드 설정 변경에 대한 파라미터 콜백 기능에 대해 이해하고 사용법을 배웁니다.
- 유형: 동영상
- 길이: 11분
- 원문: [Udemy 강의](https://www.udemy.com/course/ros2-for-beginners/learn/lecture/48733849#overview)

## 내용

- 파라미터 콜백이란 노드가 실행 중인 동안 파라미터 값을 변경할 수 있게 하는 기능입니다.
- 파라미터 콜백을 사용하면 노드가 이미 실행 중일 때도 파라미터 값을 변경할 수 있습니다.
- 파라미터 콜백을 구현하려면 파라미터를 선언하고, 파라미터 값이 변경될 때마다 호출되는 콜백 함수를 등록합니다.
- 파라미터 콜백 함수는 파라미터의 이름, 타입 및 값을 받아 처리할 수 있습니다.
- 파라미터 콜백을 사용하면 노드가 실행 중인 동안에만 파라미터 값이 변경되므로, 노드 재시작 없이 설정 변경이 가능합니다.

## 예시

- ros2 param set number_publisher number 4
- ros2 topic echo /number
- 파라미터 콜백 함수를 정의하여 파라미터 값이 변경될 때마다 새로운 값을 사용하도록 합니다.

## 요약

- 파라미터 콜백은 노드가 실행 중인 동안 파라미터 값을 변경할 수 있게 해줍니다.
- 노드 재시작 없이 설정 변경이 가능하므로, 실시간으로 파라미터를 조정하는 데 유용합니다.
- 파라미터 콜백을 사용하면 노드가 실행 중인 동안에만 파라미터 값이 변경되므로, 효율적입니다.
