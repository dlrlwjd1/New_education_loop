# Intro

## 개요

- ROS 2 파라미터에 대해 이해하고, 노드의 런타임 설정을 제공하는 방법을 배운다.
- 유형: 문서/활동
- 길이: 1분
- 원문: [Udemy 강의](https://www.udemy.com/course/ros2-for-beginners/learn/lecture/21306350#overview)

## 내용

- ROS 2 파라미터의 개념과 언제 사용해야 하는지 설명한다.
- 노드에 대한 파라미터를 선언하고 가져오는 방법을 학습한다.
- 파라미터를 YAML 파일 내부에 저장하는 방법을 배운다.
- 옵션: 파라미터 콜백에 대해 소개한다.

## 예시

- ROS 2 파라미터의 기본 개념과 사용 예시를 설명한다.
- 노드에서 파라미터를 선언하고 가져오는 코드 예시를 제공한다.
- YAML 파일 내부에 파라미터를 저장하는 방법을 보여준다.

## 요약

- ROS 2 파라미터는 노드의 런타임 설정을 제공할 수 있다.
- 파라미터를 선언하고 가져오는 방법을 이해한다.
- YAML 파일 내부에 파라미터를 저장하는 것이 중요하다.
