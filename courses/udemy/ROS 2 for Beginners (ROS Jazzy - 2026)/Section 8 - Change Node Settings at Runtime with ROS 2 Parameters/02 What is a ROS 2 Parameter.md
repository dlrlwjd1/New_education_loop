# What is a ROS 2 Parameter?

## 개요

- ROS 2 파라미터에 대해 이해하고, 노드 설정을 런타임에 변경하는 방법을 배운다.
- 유형: 동영상
- 길이: 3분
- 원문: [Udemy 강의](https://www.udemy.com/course/ros2-for-beginners/learn/lecture/21306356#overview)

## 내용

- ROS 2 파라미터의 개념과 문제를 설명한다.
- 카메라 드라이버 노드에서 사용되는 설정 변수들을 살펴본다.
- 하드코딩된 설정 대신 런타임에 파라미터 값을 변경하는 방법을 소개한다.
- ROS 2 파라미터의 선언과 초기화 과정을 설명한다.
- 노드를 시작할 때 파라미터 값 설정 방법을 보여준다.
- 런타임에 파라미터 값을 변경하여 노드 재시작하는 방법을 설명한다.

## 예시

- ros2 run 명령어로 노드를 실행하고 파라미터 값을 설정한다.
- 노드의 파라미터 값 변경 후 다시 시작한다.
- 두 개 이상의 동일한 노드 인스턴스를 런타임에 다른 파라미터 값으로 실행한다.

## 요약

- ROS 2 파라미터는 노드 설정을 런타임에 변경할 수 있는 방법이다.
- 파라미터는 노드별로 독립적으로 존재하며, 노드가 종료되면 파라미터도 사라진다.
- 파라미터의 이름과 데이터 타입이 있으며, 보통 불리언, 정수, 실수, 문자열, 리스트 등이 사용된다.
