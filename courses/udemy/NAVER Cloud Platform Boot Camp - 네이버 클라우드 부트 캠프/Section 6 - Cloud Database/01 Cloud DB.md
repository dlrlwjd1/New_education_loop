# Cloud DB

## 개요

- 완전 관리형 데이터베이스(fully managed database)의 기능을 이해한다.
- VM 직접 설치 방식과 Cloud DB의 비용·운영 책임을 비교한다.
- 고가용성, 자동 백업, 읽기 복제와 모니터링 기능을 살펴본다.

## 내용

### 완전 관리형 데이터베이스

Cloud DB는 데이터베이스 설치, 최적화 설정, 이중화, 백업과 모니터링 등의 반복 운영 작업을 NAVER Cloud Platform이 관리하는 서비스다.

강의에서는 PostgreSQL, MySQL, Redis, MS SQL Server와 MongoDB를 지원 대상으로 소개한다.

### 관리 기능

- 클릭 중심의 빠른 설치와 권장 설정
- Multi Zone과 자동 Failover
- 최대 30일 자동 백업과 시점 복구
- 읽기 전용 복제본을 이용한 읽기 부하 분산
- 성능 모니터링과 이메일·SMS 알림
- 데이터 증가에 따른 스토리지 자동 확장

### 직접 설치와 비교

| 항목 | VM에 직접 설치 | Cloud DB |
|---|---|---|
| 초기 비용 | 상대적으로 낮음 | 관리 기능 비용 포함 |
| 설치·최적화 | 사용자가 수행 | 서비스가 제공 |
| 백업·Failover | 사용자가 구성 | 관리 기능 제공 |
| 세부 제어 | 높음 | 제공 범위 내 설정 |
| 필요한 전문성 | 높음 | 상대적으로 낮음 |

데이터베이스 전문가가 있고 비용·세부 설정이 중요하면 직접 설치를 고려할 수 있다. 반복 운영을 줄이고 안정성과 자동 Failover를 우선하면 Cloud DB가 적합하다.

## 예시

```text
운영팀에 DB 전문가가 있음
＋ 세부 파라미터 제어가 중요
→ VM 직접 설치 검토

운영 부담을 줄이고 싶음
＋ 자동 백업·Failover가 중요
→ Cloud DB 검토
```

## 요약

- Cloud DB는 설치·백업·장애 전환·모니터링을 관리형 기능으로 제공한다.
- Multi Zone과 읽기 복제본으로 가용성과 읽기 성능을 높일 수 있다.
- 직접 설치보다 비용은 높을 수 있지만 운영 업무가 줄어든다.
- 조직의 DB 전문성, 비용, 안정성 요구를 기준으로 방식을 선택한다.
