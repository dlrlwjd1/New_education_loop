# Compute - Linux VM Disk 추가하기

## 개요

- Linux VM에 데이터 스토리지를 추가한다.
- 새 디스크를 파티셔닝·포맷·마운트하는 흐름을 익힌다.
- 디스크 크기와 IOPS, 반납 보호와 과금의 관계를 확인한다.

## 내용

### 스토리지 생성

서버를 선택한 뒤 Server Management의 스토리지 생성 메뉴에서 데이터 볼륨을 추가한다. 용량, 스냅샷 사용 여부와 반납 보호를 지정할 수 있다.

강의에서는 단일 스토리지를 최대 2TB까지 생성할 수 있다고 설명한다. 디스크 크기에 따라 제공되는 IOPS가 달라질 수 있으므로 용량과 성능 요구를 함께 고려한다.

### Linux에서 사용하기

콘솔에서 스토리지를 생성·연결한 뒤 Linux 안에서 다음 작업을 수행한다.

```text
새 블록 장치 확인
→ 파티션 생성
→ 파일 시스템 포맷
→ 마운트 포인트 생성
→ 디스크 마운트
→ 재부팅 후에도 유지되도록 /etc/fstab 등록
```

스토리지는 서버 생성 화면에서 바로 추가하거나 Storage 메뉴에서 별도로 만든 후 원하는 서버에 연결할 수 있다.

### 2TB를 초과하는 용량

단일 디스크의 최대 크기를 초과하는 볼륨이 필요하면 여러 디스크를 묶어 논리 볼륨을 구성한다. 다음 강의는 Linux의 LVM(Logical Volume Manager)을 이용하는 방식을 다룰 예정이지만, 제공된 자동 트랜스크립트에서는 해당 내용이 정상적으로 확인되지 않았다.

## 예시

```text
Server > 스토리지 생성
→ 데이터 볼륨의 용량 지정
→ 대상 서버에 연결
→ Linux에서 장치 확인
→ 파티션·파일 시스템 생성
→ /data 등에 마운트
```

## 요약

- 추가 스토리지는 콘솔에서 생성한 뒤 서버에 연결한다.
- Linux에서는 파티셔닝, 포맷, 마운트 과정이 필요하다.
- 영구 마운트 정보는 `/etc/fstab`에 관리한다.
- 디스크 용량에 따라 IOPS가 달라질 수 있다.
- 사용하지 않는 스토리지는 반납해야 과금을 중지할 수 있다.
