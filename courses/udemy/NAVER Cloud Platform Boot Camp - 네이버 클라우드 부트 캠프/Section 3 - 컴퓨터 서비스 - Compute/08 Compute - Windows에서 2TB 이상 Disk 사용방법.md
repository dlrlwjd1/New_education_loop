# Compute - Windows에서 2TB 이상 Disk 사용방법

## 개요

- Windows Server에서 여러 디스크를 묶어 2TB를 초과하는 볼륨을 만든다.
- GPT 파티션 방식과 스트라이프 볼륨을 사용한다.
- 사용을 마친 스토리지의 안전한 제거와 반납을 확인한다.

## 내용

### GPT로 초기화

Windows에 새 디스크를 연결한 뒤 디스크 관리에서 초기화한다. 2TB를 초과하는 볼륨을 사용하려면 MBR(Master Boot Record)이 아니라 GPT(GUID Partition Table)를 선택한다.

### 스트라이프 볼륨

두 디스크를 하나의 논리 드라이브로 묶을 때 스트라이프 볼륨을 만든다. 각 디스크를 추가하고 드라이브 문자와 NTFS 파일 시스템을 선택해 포맷하면 하나의 큰 드라이브로 표시된다.

스트라이프 볼륨은 데이터를 여러 디스크에 나눠 기록하지만 장애 복제 기능은 없다. 디스크 하나에 문제가 생기면 전체 볼륨에 영향을 줄 수 있다.

디스크가 3개 이상이면 강의에서는 소프트웨어 RAID 5 구성도 선택지로 소개한다.

### 스토리지 제거

연결된 스토리지를 더 이상 사용하지 않으면 서버를 중지한 뒤 분리·반납한다. 운영 중인 VM에서 콘솔로 디스크를 강제로 제거하면 장애가 발생할 수 있다.

## 예시

```text
2TB 디스크 2개 연결
→ Windows 디스크 관리 실행
→ 각 디스크를 GPT로 초기화
→ 새 스트라이프 볼륨 생성
→ 두 디스크 추가
→ NTFS와 드라이브 문자 설정
→ 포맷 후 단일 드라이브로 사용
```

## 요약

- 2TB 초과 Windows 볼륨은 GPT로 초기화한다.
- 여러 디스크를 스트라이프 볼륨으로 묶어 하나의 큰 드라이브로 사용할 수 있다.
- 스트라이프 볼륨에는 자체 장애 복제 기능이 없다.
- 스토리지를 제거하기 전 VM을 중지한다.
- 사용하지 않는 디스크는 반납해야 과금이 끝난다.
