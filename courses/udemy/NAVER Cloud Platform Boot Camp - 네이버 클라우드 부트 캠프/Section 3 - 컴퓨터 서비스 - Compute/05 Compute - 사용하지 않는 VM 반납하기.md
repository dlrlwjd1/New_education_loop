# Compute - 사용하지 않는 VM 반납하기

## 개요

- 실습을 마친 VM을 중지하거나 반납해 불필요한 과금을 방지한다.
- 반납 보호가 설정된 서버를 안전하게 삭제하는 절차를 확인한다.

## 내용

### 중지와 반납

서버 중지는 나중에 다시 사용할 수 있도록 VM을 유지하는 작업이다. 시간제 서버의 CPU·메모리 과금을 줄일 수 있지만 디스크 등의 리소스 비용은 남을 수 있다.

반납은 서버를 더 이상 사용하지 않을 때 삭제하는 작업이다. 계속 사용할 계획이 없다면 중지 상태로 방치하지 말고 반납해야 추가 과금을 막을 수 있다.

### 반납 보호 해제

반납 보호가 켜진 서버는 바로 삭제되지 않는다. Server Management의 설정 변경 메뉴에서 반납 보호를 해제한 뒤 반납한다.

## 예시

```text
서버 사용 종료
→ 다시 사용할 예정이면 중지
→ 더 이상 필요 없으면 반납 보호 확인
→ 반납 보호 해제
→ 서버 반납
→ 콘솔에서 삭제 여부 확인
```

## 요약

- 중지와 반납은 서로 다른 작업이다.
- 중지된 VM에도 디스크 비용 등이 발생할 수 있다.
- 반납 보호는 실수로 서버를 삭제하는 사고를 막는다.
- 더 이상 필요 없는 실습 서버는 보호를 해제하고 반납한다.
