# Compute - 내 서버 이미지 만들기, 유사 서버 만들기

## 개요

- 기존 VM에서 사용자 서버 이미지를 생성한다.
- 유사 서버 생성과 사용자 이미지 기반 서버 생성을 비교한다.
- 동일한 환경을 복제해 배포·Auto Scaling에 활용한다.

## 내용

### 내 서버 이미지 생성

원본 서버를 선택하고 Server Management의 내 서버 이미지 생성 메뉴에서 이미지 이름과 설명을 입력한다. 이미지가 많아졌을 때 용도를 구분할 수 있도록 설명을 명확히 작성한다.

생성에는 시간이 걸리며 완료 후 사용자 서버 이미지 목록에서 확인할 수 있다.

### 유사 서버 생성

유사 서버 생성은 선택한 서버와 같은 이미지·사양·스토리지·인증 키·설정을 바탕으로 새 서버를 빠르게 만드는 기능이다. 강의에서는 원본 `red` 서버를 기준으로 `blue` 서버를 생성한다.

### 이미지 기반 서버 생성

서버 생성 화면의 사용자 서버 이미지에서 앞서 만든 이미지를 선택한다. VPC, 서버 수, 이름, 공인 IP, 반납 보호, 인증 키와 ACG 등을 지정해 새 서버를 만든다.

이미지에 웹 서버, 패키지와 설정을 미리 구성해 두면 동일한 서버를 여러 대 배포할 수 있다. Auto Scaling도 준비된 이미지를 기준으로 새 인스턴스를 복제할 수 있다.

## 예시

```text
원본 서버 red 구성
├─ 유사 서버 생성 → 같은 설정의 blue 생성
└─ 내 서버 이미지 생성
   └─ 사용자 이미지로 yellow 생성
```

## 요약

- 내 서버 이미지는 설치된 패키지와 설정을 재사용하는 기준 이미지다.
- 유사 서버 생성은 기존 서버와 같은 구성을 빠르게 복제한다.
- 사용자 이미지에서는 네트워크·이름 등 새 서버 설정을 다시 선택할 수 있다.
- 설명과 이름을 체계적으로 기록해야 이미지가 많아져도 관리하기 쉽다.
- 동일한 서버의 반복 배포와 Auto Scaling에 활용할 수 있다.
