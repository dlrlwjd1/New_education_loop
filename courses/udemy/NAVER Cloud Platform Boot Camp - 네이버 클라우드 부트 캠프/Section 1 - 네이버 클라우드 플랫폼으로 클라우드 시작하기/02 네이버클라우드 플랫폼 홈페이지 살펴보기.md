# 네이버클라우드 플랫폼 홈페이지 살펴보기

## 개요

- NAVER Cloud Platform 홈페이지에서 클라우드 환경과 서비스 카테고리를 살펴본다.
- 요금 계산기, 고객 지원, 교육 포털 등 운영·학습에 필요한 메뉴를 확인한다.

## 내용

### 클라우드 환경 구분

홈페이지에서는 기본 퍼블릭 클라우드와 함께 공공기관용·금융용 클라우드로 이동할 수 있다. 강의는 화면 테마로 각 환경을 구분하는 방법을 소개한다.

| 환경 | 화면 특징 |
|---|---|
| 퍼블릭 클라우드 | 흰색 배경 |
| 금융 클라우드 | 주황색 계열 |
| 공공기관용 클라우드 | 어두운 파란색 계열 |

### 서비스 카테고리

홈페이지의 서비스 목록은 컴퓨팅, 컨테이너, 스토리지, 네트워킹, 데이터베이스, 보안뿐 아니라 AI·애플리케이션·개발 도구까지 폭넓게 구성되어 있다.

- 컴퓨팅: 가상 머신, 디스크, Auto Scaling, Cloud Functions
- 컨테이너: Container Registry, Kubernetes Service
- 스토리지: Object Storage, Archive Storage, NAS, Backup
- 데이터베이스: PostgreSQL, MySQL, MS SQL, MongoDB 등
- 보안: 취약점 점검, 접근 제어, 로그 확인, 키 관리
- AI·애플리케이션: CLOVA Voice·OCR·Chatbot, Papago, 지도 연동
- 비즈니스: NAVER WORKS, WORKPLACE, WORKBOX, RPA
- 기타: 빅데이터, 블록체인, 디지털 트윈, 게임 운영, IoT, 미디어, 마이그레이션

강의에서는 Cloud Functions를 AWS Lambda와 비슷한 서비스로 설명한다. 일부 애플리케이션은 미리 만들어진 이미지 형태로 제공되므로 사용자가 직접 설치하는 작업을 줄일 수 있다.

### 데이터베이스와 라이선스

강의 시점의 관리형 데이터베이스 목록에는 Oracle이 포함되지 않는다. Oracle을 사용하려면 라이선스 정책을 확인한 후 Bare Metal 서버 등에 직접 구성하는 방안을 검토해야 한다. 라이선스 조건은 클라우드 사업자가 아니라 Oracle의 정책을 따른다는 점을 강조한다.

### 요금 계산기

요금 계산기에서 운영체제와 서버 사양을 선택하면 월 예상 비용을 계산할 수 있다. 여러 서비스를 추가해 전체 비용을 합산하고, 결과를 링크·출력·Excel·이메일 등의 형태로 공유할 수 있다.

### 고객 지원과 교육

고객 지원 메뉴에서는 서비스, 리소스, 회원 정보, 요금, 교육 관련 문의를 남길 수 있다. 교육 포털에는 온라인 교육과 NAVER Cloud 자격증 과정이 제공되며, 교육·세미나 행사 일정도 확인할 수 있다.

## 예시

```text
월 예상 비용 확인
→ 운영체제 선택
→ 서버 사양 선택
→ 스토리지·네트워크 등 추가 서비스 선택
→ 전체 월 비용 확인
→ 링크 또는 Excel로 결과 공유
```

## 요약

- 홈페이지는 퍼블릭·금융·공공기관용 클라우드로 구분된다.
- 컴퓨팅부터 AI·비즈니스 애플리케이션까지 다양한 서비스를 탐색할 수 있다.
- 관리형 서비스의 지원 범위뿐 아니라 외부 소프트웨어의 라이선스 정책도 확인해야 한다.
- 요금 계산기로 구축 전 예상 비용을 산정할 수 있다.
- 고객 지원과 교육 포털은 문의, 자격증 학습, 행사 확인에 활용한다.
