# Querying with boolean logic

## 개요

- `bool` 쿼리를 사용하여 여러 조건을 논리적으로 결합할 수 있습니다.

## 내용

- `must`, `must_not`, `should` 등의 occurrence type을 사용하여 복잡한 검색을 구성합니다.

## 예시

- "Alcohol" 태그가 있는 제품 중 "Wine" 태그가 없는 제품을 찾습니다.

## 요약

- `bool` 쿼리를 사용하여 여러 조건을 논리적으로 결합하는 방법입니다.
