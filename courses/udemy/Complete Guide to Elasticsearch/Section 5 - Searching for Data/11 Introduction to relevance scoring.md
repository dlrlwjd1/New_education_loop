# Introduction to relevance scoring

## 개요

- 풀 텍스트 검색 결과는 관련성 점수에 따라 정렬됩니다. `_score` 필드는 문서와 검색어의 일치도를 나타냅니다.

## 내용

- `match` 쿼리 외에도 풀 텍스트 검색에서는 관련성 점수가 중요합니다.

## 예시

- "pasta"와 "chicken"이라는 단어가 이름 필드에 있는 문서를 검색하고, 관련성 점수를 확인합니다.

## 요약

- 검색 결과의 정렬을 위해 `_score` 필드를 사용하는 방법입니다.
