# Introduction to searching

## 개요

- Elasticsearch에서 검색을 시작하기 전에 매핑과 분석기를 이해하는 것이 중요하다.

## 내용

- URI 검색과 Query DSL이 두 가지 검색 방법이다.

## 예시

- URI 검색은 Lucene의 쿼리 문자열 구문을 사용한다.

## 요약

- Query DSL은 더 많은 기능을 제공하고 JSON 형식으로 작성된다.
