# The match query

## 개요

- `match` 쿼리는 가장 널리 사용되는 풀 텍스트 검색 쿼리입니다. 지정된 단어가 필드에 포함된 문서를 반환합니다.

## 내용

- `match` 쿼리는 입력 텍스트를 분석하고, 분석된 결과를 역인덱스에서 찾습니다.

## 예시

- "pasta"라는 단어가 이름 필드에 있는 제품을 검색합니다.
