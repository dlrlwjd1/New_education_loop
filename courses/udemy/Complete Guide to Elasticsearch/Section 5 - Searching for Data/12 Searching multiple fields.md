# Searching multiple fields

## 개요

- `multi_match` 쿼리를 사용하여 여러 필드에서 텍스트를 검색할 수 있습니다.

## 내용

- 각 필드에 대한 중요도를 조절하여 관련성 점수를 높일 수 있습니다.

## 예시

- "vegetable"이라는 단어가 이름 또는 태그 필드에 있는 문서를 검색합니다.

## 요약

- 여러 필드에서 텍스트를 검색하고, 각 필드의 중요도를 조절하는 `multi_match` 쿼리의 사용법입니다.
