# Disjunction max (dis_max)

## 개요

- dis_max 쿼리는 여러 쿼리 중 하나라도 일치하면 문서를 반환합니다.

## 내용

- 최고의 관련성 점수를 사용하여 문서를 평가합니다.

## 예시

- "vegetable"이 name 또는 tags 필드에 있는 문서가 일치합니다.

## 요약

- dis_max 쿼리는 여러 쿼리 중 하나라도 일치하면 문서를 반환하고, 가장 높은 관련성 점수를 사용하여 평가합니다.
