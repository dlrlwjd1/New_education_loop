# Querying nested objects

## 개요

- nested 데이터 타입을 사용하여 개별적으로 객체를 쿼리할 수 있습니다.

## 내용

- 배열 내의 각 객체를 별도로 검색할 수 있습니다.

## 예시

- parmesan과 amount가 100 이상인 레시피를 찾습니다.
