# Boosting query

## 개요

- `boosting` 쿼리는 특정 문서의 관련성 점수를 높이는 동시에 다른 문서의 점수를 낮출 수 있습니다.

## 내용

- `positive`와 `negative` 쿼리를 사용하여 문서의 일치도를 조절합니다.

## 예시

- "juice"가 포함된 제품 중 "apple juice"의 관련성 점수를 낮춥니다.

## 요약

- 특정 문서의 관련성 점수를 조절하는 `boosting` 쿼리의 사용법입니다.
