# Adding synonyms from file

## 개요

- 많은 동의어를 파일로 관리하여 인덱스 크기를 줄입니다.

## 내용

- synonyms_path 파라미터를 사용해 외부 파일에서 동의어를 로드합니다.

## 예시

- synonyms.txt 파일을 사용해 동의어 매치됩니다.

## 요약

- 동의어를 파일로 관리하면 인덱스 크기를 줄일 수 있습니다.
