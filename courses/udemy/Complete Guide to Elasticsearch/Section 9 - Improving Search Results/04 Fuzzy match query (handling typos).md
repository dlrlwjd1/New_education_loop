# Fuzzy match query (handling typos)

## 개요

- 틀린 입력을 처리하여 관련 문서를 찾습니다.

## 내용

- fuzziness 파라미터를 사용해 틀린 입력도 매치됩니다.

## 예시

- lobster와 lobzer 모두 매치됩니다.

## 요약

- fuzziness 파라미터를 사용해 틀린 입력도 검색 결과에 포함할 수 있습니다.
