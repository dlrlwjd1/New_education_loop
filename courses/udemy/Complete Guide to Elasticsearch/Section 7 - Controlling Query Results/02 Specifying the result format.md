# Specifying the result format

## 개요

- 검색 결과 형식을 YAML 또는 JSON으로 변경하는 방법을 배웁니다.

## 내용

- `format` 파라미터를 사용하여 결과 형식을 설정합니다.

## 예시

- 쿼리 결과를 YAML로 반환하고, 터미널에서 읽기 쉬운 JSON 형식으로 변환합니다.
