# Source filtering

## 개요

- 검색 결과에서 `_source` 필드를 제어하여 필요한 데이터만 반환합니다.

## 내용

- `_source` 필드를 사용하여 특정 필드만 반환하거나, 전체 필드를 비활성화합니다.

## 예시

- 필요 없는 필드를 제외하고 검색 결과를 반환합니다.

## 요약

- 검색 결과에서 필요 없는 필드를 제거하여 데이터를 최적화하는 방법을 설명합니다.
