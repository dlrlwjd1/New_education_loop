# Sorting results

## 개요

- Elasticsearch에서 검색 결과를 정렬하는 방법을 설명합니다.

## 내용

- `sort` 파라미터를 사용하여 결과를 필드 기준으로 오름차순이나 내림차순으로 정렬할 수 있습니다.

## 예시

- `preparation_time_minutes` 필드로 오름차순 정렬하면 준비 시간이 짧은 레시피 순으로 결과가 나옵니다.

## 요약

- `sort` 파라미터를 사용하여 Elasticsearch에서 검색 결과를 정렬합니다.
