# Sorting by multi-value fields

## 개요

- 다중 값 필드에 대해 정렬하는 방법을 설명합니다.

## 내용

- `avg`, `max`, `min`, `sum` 등의 모드를 사용하여 다중 값 필드의 통계치를 기준으로 정렬할 수 있습니다.

## 예시

- `ratings` 필드의 평균값이 높은 레시피 순으로 결과가 나옵니다.

## 요약

- `avg`, `max`, `min`, `sum` 등의 모드를 사용하여 다중 값 필드에 대해 정렬합니다.
