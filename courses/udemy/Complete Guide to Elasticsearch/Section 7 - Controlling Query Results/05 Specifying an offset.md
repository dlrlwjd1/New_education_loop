# Specifying an offset

## 개요

- 검색 결과의 다음 페이지를 가져오기 위해 `from` 파라미터와 `size` 파라미터를 사용하는 방법을 설명합니다.

## 내용

- `from` 파라미터는 검색 결과에서 건너뛰어야 하는 매치 수를 지정하며, `size` 파라미터는 반환할 결과의 수를 지정합니다. 이 두 파라미터를 조합하여 페이지네이션을 구현할 수 있습니다.

## 예시

- `from=2`로 설정하면 첫 번째 페이지의 결과 다음 10개의 결과를 가져옵니다.

## 요약

- `from`과 `size` 파라미터를 사용하여 검색 결과를 페이지네이션합니다.
