# Add departments test data

## 개요

- 부모-자식 관계(join field) 실습에 사용할 부서 테스트 데이터를 준비하는 읽기 자료다.

## 내용

- 이후 강의에서 부서와 직원 문서의 관계를 매핑하고 조회하기 위한 선행 단계다.
- 수강 페이지에서 별도의 영상 트랜스크립트는 제공되지 않는다.
- 실제 데이터와 명령은 강의에 연결된 자료를 사용해야 하므로 임의로 만들지 않았다.

## 예시

- 테스트 데이터를 추가한 뒤 다음 강의의 관계 매핑 실습으로 진행한다.
