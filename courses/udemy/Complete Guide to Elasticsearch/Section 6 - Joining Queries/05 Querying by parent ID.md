# Querying by parent ID

## 개요

- 부모 문서의 ID를 기반으로 자식 문서를 쿼리하는 방법에 대해 설명합니다.

## 내용

- parent_id 쿼리를 사용하여 부모 문서와 일치하는 자식 문서를 반환합니다.

## 예시

- department ID 1을 기반으로 해당 department의 employee를 찾습니다.

## 요약

- parent_id 쿼리를 사용하여 부모 문서와 일치하는 자식 문서를 쉽게 검색할 수 있습니다.
