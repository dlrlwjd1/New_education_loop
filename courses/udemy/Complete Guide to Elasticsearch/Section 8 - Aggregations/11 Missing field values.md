# Missing field values

## 개요

- 결측 필드 값에 대처하여 집계를 수행합니다.

## 내용

- 결측 필드 값이나 존재하지 않는 필드 값을 포함하여 집계를 수행합니다.

## 예시

- 상태 필드가 결측되거나 null인 문서를 포함하여 총 금액의 합계를 계산하는 방법입니다.

## 요약

- 결측 필드 값에 대처하여 집계를 수행할 수 있습니다.
