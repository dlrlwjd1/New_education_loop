# Global aggregation

## 개요

- 전역 집계를 사용하여 모든 문서에 대해 집계를 수행합니다.

## 내용

- 전역 집계는 검색 쿼리가 적용되지 않은 상태로 모든 문서에 대한 집계를 수행합니다.

## 예시

- 총 금액이 100 이상인 문서만 포함하는 검색 쿼리를 사용하여 전체 문서의 통계를 계산하는 방법입니다.

## 요약

- 전역 집계는 검색 쿼리가 적용되지 않은 상태로 모든 문서에 대한 집계를 수행할 수 있습니다.
