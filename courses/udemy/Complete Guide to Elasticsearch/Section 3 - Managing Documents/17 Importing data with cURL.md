# Importing data with cURL

## 개요

- cURL을 사용하여 Elasticsearch에 테스트 데이터를 가져오는 방법을 배웁니다.

## 내용

- Bulk API를 사용하여 데이터를 명령줄에서 가져오기.

## 예시

- cURL을 사용하여 HTTP 요청을 보내고, Elasticsearch에 데이터를 인덱싱합니다.

## 요약
