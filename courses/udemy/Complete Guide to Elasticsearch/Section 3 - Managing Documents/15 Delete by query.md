# Delete by query

## 개요

- Elasticsearch에서 특정 조건에 맞는 여러 문서를 삭제하는 방법에 대해 설명한다.

## 내용

- Delete By Query API를 사용하여 특정 조건에 맞는 여러 문서를 한 번에 삭제할 수 있다.

## 예시

- "in_stock" 필드 값이 0인 모든 제품을 삭제한다.
