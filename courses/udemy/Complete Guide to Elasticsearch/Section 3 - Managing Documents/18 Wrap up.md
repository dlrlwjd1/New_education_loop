# Wrap up

## 개요

- 이 섹션에서는 문서 관리를 위한 기본적인 Elasticsearch 연산을 배웠습니다.

## 내용

- 라우팅, 문서 버전 관리, 흥미로운 API인 Bulk API에 대해 이해했습니다.

## 예시

- Bulk API를 사용하여 테스트 데이터를 가져왔습니다.
