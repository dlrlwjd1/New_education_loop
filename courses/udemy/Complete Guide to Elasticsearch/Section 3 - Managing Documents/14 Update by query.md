# Update by query

## 개요

- Elasticsearch에서 여러 문서를 한 번에 업데이트하는 방법에 대해 설명한다.

## 내용

- Update By Query API를 사용하여 특정 조건에 맞는 여러 문서를 한 번에 업데이트할 수 있다.

## 예시

- "in_stock" 필드 값을 감소시키기 위해 여러 제품을 한 번에 업데이트한다.

## 요약

- Update By Query API를 사용하여 여러 문서를 한 번에 업데이트할 수 있다.
