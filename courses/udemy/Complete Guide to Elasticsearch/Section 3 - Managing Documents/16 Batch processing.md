# Batch processing

## 개요

- Elasticsearch에서 일괄 처리를 위해 Bulk API를 사용하는 방법에 대해 설명한다.

## 내용

- Bulk API를 사용하여 여러 개의 인덱싱, 업데이트, 삭제 작업을 한 번에 수행할 수 있다.

## 예시

- 일괄적으로 여러 문서를 인덱싱하고, 일부 문서를 업데이트하고, 다른 문서를 삭제한다.

## 요약

- Bulk API를 사용하여 여러 개의 작업을 효율적으로 일괄 처리할 수 있다.
