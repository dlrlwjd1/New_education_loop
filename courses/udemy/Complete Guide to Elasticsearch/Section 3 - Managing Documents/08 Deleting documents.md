# Deleting documents

## 개요

- Elasticsearch에서 문서를 삭제하는 방법을 배웁니다.

## 내용

- DELETE HTTP 메서드를 사용하여 특정 ID의 문서를 삭제.

## 예시

- 특정 ID의 문서를 가져와서 해당 문서를 삭제하는 예제.

## 요약

- Elasticsearch에서 문서를 쉽게 삭제할 수 있습니다. 기본적인 delete 쿼리와 동작 원리에 대해 설명합니다.
