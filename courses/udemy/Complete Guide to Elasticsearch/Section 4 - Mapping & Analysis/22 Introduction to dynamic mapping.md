# Introduction to dynamic mapping

## 개요

- 동적 매핑이란 Elasticsearch가 문서를 인덱싱할 때 필드 매핑을 자동으로 생성하는 방법에 대해 설명합니다.

## 내용

- 처음 만났던 문서의 필드에 대해서는 자동으로 매핑이 생성됩니다.

## 예시

- 새로운 문서를 인덱싱할 때 "created_at", "in_stock", "tags" 필드가 자동으로 매핑되었습니다.

## 요약

- Elasticsearch는 처음 만났던 문서의 필드에 대해서는 자동으로 매핑을 생성합니다.
