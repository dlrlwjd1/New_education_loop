# Adding mappings to existing indices

## 개요

- 이미 있는 인덱스에 새로운 필드 매핑 추가 방법을 배웁니다.

## 내용

- Mapping API를 사용하여 기존 인덱스에 새 필드 매핑 추가.

## 예시

- "created_at" 필드의 매핑을 추가합니다.
