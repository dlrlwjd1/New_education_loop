# Using dot notation in field names

## 개요

- Elasticsearch에서 필드 이름에 점 표기법 사용 방법을 배웁니다.

## 내용

- 점 표기법을 사용하여 복잡한 객체 구조의 필드 매핑 정의.

## 예시

- "author.first_name"와 같은 형식으로 필드를 정의합니다.

## 요약

- 점 표기법을 사용하여 Elasticsearch에서 복잡한 객체 구조의 필드 매핑을 정의하는 방법을 설명합니다.
