# Adding explicit mappings

## 개요

- Elasticsearch의 필드 매핑을 추가하는 방법을 배웁니다.

## 내용

- 새 인덱스 생성 시 필드 매핑 정의.

## 예시

- "rating," "content," "product_id," "author" 등의 필드를 정의합니다.

## 요약

- 새 인덱스를 만들 때 명시적으로 필드 매핑을 추가하는 방법을 설명합니다.
