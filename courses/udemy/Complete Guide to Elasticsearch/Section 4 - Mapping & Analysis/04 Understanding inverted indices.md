# Understanding inverted indices

## 개요

- 인덱싱된 문서에서 검색이 어떻게 이루어지는지에 대해 설명합니다.

## 내용

- 인덱스는 특정 단어가 포함된 문서를 빠르게 찾을 수 있는 데이터 구조입니다.

## 예시

- "ducks"라는 단어를 검색하면 해당 단어를 포함하는 문서 ID를 반환합니다.

## 요약

- 인덱스는 특정 단어가 포함된 문서를 빠르게 찾을 수 있는 효율적인 데이터 구조입니다.
