# Analyzers and search queries

## 개요

- 인덱싱과 검색 시에 사용되는 애널라이저에 대해 설명합니다.

## 내용

- 인덱싱과 검색 시 동일한 분석기를 사용하여 값이 일치하도록 합니다.

## 예시

- "drinking"을 검색할 때, 인덱싱 시 "drink"으로 변환되어 일치합니다.
