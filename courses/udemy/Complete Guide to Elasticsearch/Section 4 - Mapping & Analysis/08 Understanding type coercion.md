# Understanding type coercion

## 개요

- Elasticsearch에서 잘못된 데이터 타입을 제공했을 때 어떻게 처리되는지 설명합니다.

## 내용

- 잘못된 데이터 타입이 제공되면 Elasticsearch는 해당 값을 적절한 데이터 타입으로 변환하려고 합니다.

## 예시

- 문자열로 입력된 숫자 값은 내부적으로 숫자로 변환됩니다.

## 요약

- Elasticsearch에서 잘못된 데이터 타입을 처리하는 방법에 대해 설명합니다.
