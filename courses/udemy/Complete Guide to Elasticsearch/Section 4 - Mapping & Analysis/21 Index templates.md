# Index templates

- 인덱스 템플릿을 사용하여 새로운 인덱스가 생성될 때 자동으로 설정과 매핑을 적용하는 방법에 대해 설명합니다.

## 내용

- 동적으로 생성되는 인덱스에 대한 일관된 설정과 매핑을 관리할 수 있습니다.

## 예시

- HTTP 액세스 로그를 저장하기 위한 인덱스 템플릿을 생성했습니다.
