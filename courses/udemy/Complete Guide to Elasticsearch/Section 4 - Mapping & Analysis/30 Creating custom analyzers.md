# Creating custom analyzers

## 개요

- 내장 애널라이저를 기반으로 사용자 정의 애널라이저를 만드는 방법을 설명합니다.

## 내용

- "html_strip"이라는 문자 필터와 "standard" 토큰화기를 사용하여 HTML 태그 및 엔티티 제거합니다.

## 예시

- "my_custom_analyzer"라는 이름의 사용자 정의 애널라이저를 생성하고, "açaí" 같은 특수 문자를 ASCII로 변환합니다.

## 요약

- 내장 애널라이저를 확장하여 사용자 정의 애널라이저를 만드는 방법을 설명합니다.
