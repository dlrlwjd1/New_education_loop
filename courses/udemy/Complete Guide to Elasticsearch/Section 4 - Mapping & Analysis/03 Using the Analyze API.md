# Using the Analyze API

## 개요

- Elasticsearch의 분석 API를 사용하여 텍스트가 어떻게 분석되는지 확인할 수 있습니다.

## 내용

- "standard" 분석기를 사용하여 텍스트를 분석하고 결과를 확인합니다.

## 예시

- "standard" 분석기는 공백 기준으로 텍스트를 단어로 분리하고 소문자로 변환합니다.

## 요약

- 분석 API를 사용하여 텍스트의 분석 과정을 시험하고 이해할 수 있습니다.
