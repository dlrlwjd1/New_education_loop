# Introduction to mapping

## 개요

- Elasticsearch에서 문서의 구조와 인덱싱 방식을 정의하는 맵핑에 대해 설명합니다.

## 내용

- 맵핑은 필드와 해당 필드의 데이터 타입을 정의하는 과정입니다.

## 예시

- "name"과 "description" 필드가 각각 다른 텍스트 데이터를 포함할 수 있습니다.

## 요약

- 맵핑은 문서의 구조와 인덱싱 방식을 정의하는 중요한 개념입니다.
