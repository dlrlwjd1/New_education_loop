# Updating existing mappings

## 개요

- 기존 인덱스의 필드 매핑을 업데이트하는 방법에 대해 설명합니다.

## 내용

- Elasticsearch에서는 필드 매핑을 변경할 수 없습니다. 일부 매핑 파라미터만 업데이트 가능합니다.

## 예시

- "product_id" 필드를 "keyword"로 변경하려고 시도했으나 실패했습니다.

## 요약

- Elasticsearch에서는 기존 필드 매핑을 변경할 수 없습니다. 일부 매핑 파라미터만 업데이트 가능합니다.
