# Adding analyzers to existing indices

## 개요

- 이미 생성된 인덱스에 새로운 애널라이저를 추가하는 방법을 설명합니다.

## 내용

- 인덱스가 열린 상태에서는 애널라이저를 수정할 수 없습니다. 따라서 인덱스를 닫고 다시 열어야 합니다.

## 예시

- "my_custom_analyzer"라는 이름의 새로운 애널라이저를 기존 인덱스에 추가합니다.
