# How the "keyword" data type works

## 개요

- "keyword" 데이터 타입이 어떻게 분석되고 저장되는지 설명합니다.

## 내용

- "keyword" 데이터 타입은 정확한 일치를 위해 분석되지 않습니다.

## 예시

- "email" 필드는 대소문자를 구분하지 않도록 설정할 수 있습니다.

## 요약

- "keyword" 데이터 타입은 정확한 일치, 필터링, 정렬 및 집계에 사용됩니다.
