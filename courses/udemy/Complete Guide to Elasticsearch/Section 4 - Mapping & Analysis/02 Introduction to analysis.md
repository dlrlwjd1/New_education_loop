# Introduction to analysis

## 개요

- 텍스트 분석의 기본 개념과 Elasticsearch에서의 적용 방법을 설명합니다.

## 내용

- 텍스트는 인덱싱 전에 처리되어 효율적인 검색을 위한 데이터 구조로 저장됩니다.

## 예시

- "standard" 분석기는 공백 기준으로 텍스트를 단어로 분리하고 소문자로 변환합니다.

## 요약

- 텍스트 분석은 인덱싱 전에 텍스트를 처리하여 검색 효율성을 높이는 과정입니다.
