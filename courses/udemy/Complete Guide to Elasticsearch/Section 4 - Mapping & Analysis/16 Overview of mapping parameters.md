# Overview of mapping parameters

## 개요

- Elasticsearch의 필드 매핑 파라미터 개요를 배웁니다.

## 내용

- "format," "properties," "coerce," "doc_values" 등 주요 파라미터 소개.

## 예시

- "format" 파라미터를 사용하여 날짜 형식 지정, "coerce" 파라미터를 사용하여 타입 강제 변환 설정.

## 요약

- Elasticsearch의 필드 매핑 파라미터 중 주요 파라미터에 대해 개요를 제공합니다.
