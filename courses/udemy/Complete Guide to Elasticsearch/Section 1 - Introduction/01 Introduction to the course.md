# Introduction to the course

## 개요

- 강사와 코스의 범위, 학습 방식과 제공 자료를 소개한다.

## 내용

### 코스의 출발점

- Elasticsearch를 처음 접하는 학습자도 따라올 수 있도록 핵심 개념을 단계적으로 소개한다.
- Elasticsearch 문서는 상세한 API 레퍼런스에 가깝기 때문에, 이 코스는 개념을 학습 순서에 맞춰 연결하는 데 초점을 둔다.

### 다루는 범위

- Elasticsearch 자체를 깊게 다루며 Kibana는 쿼리를 보내는 용도로 사용한다.
- Logstash와 Kibana의 상세 기능 등 Elastic Stack 전체는 별도 코스의 범위로 둔다.
- 검색, 집계(aggregation), 동의어, 형태소 처리(stemming), 자동 완성과 관련성 조정을 다룬다.

## 예시

- 강의에서 사용하는 쿼리와 명령은 연결된 GitHub 저장소에서 복사해 실습할 수 있다.

## 요약

- 이 코스는 개발자가 Elasticsearch의 핵심 기능과 내부 동작을 이해하도록 구성되어 있다.
- 전체 제품군보다 Elasticsearch와 실전 쿼리에 집중한다.
