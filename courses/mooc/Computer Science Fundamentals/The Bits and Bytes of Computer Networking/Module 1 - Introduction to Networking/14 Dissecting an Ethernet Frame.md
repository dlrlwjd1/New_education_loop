# Dissecting an Ethernet Frame

## 개요

- 이더넷 프레임을 필드 단위로 해부한다.
- 순서: **프리앰블(SFD 포함) → 목적지 MAC → 출발지 MAC → 이더타입(또는 VLAN 헤더) → 페이로드 → 프레임 체크 시퀀스(FCS)**.
- 핵심 개념: **CRC는 무결성을 알려 줄 뿐, 이더넷은 데이터 복구를 하지 않는다.**

## 내용

### 데이터 패킷과 이더넷 프레임

- **데이터 패킷(data packet)** 은 네트워크 링크로 전송되는 **이진 데이터 한 묶음**을 가리키는 포괄적 용어다. 특정 계층이나 기술에 묶이지 않은 **개념**이며, A에서 B로 보내지는 데이터 한 세트를 뜻한다.
- **이더넷 수준의 데이터 패킷을 이더넷 프레임(Ethernet frame)** 이라 한다.
- 이더넷 프레임은 **정해진 순서로 배열된 고도로 구조화된 정보 모음**이다. 그래야 물리 계층의 네트워크 인터페이스가 링크를 지나는 비트 스트림을 의미 있는 데이터로(또는 그 반대로) 변환할 수 있다.
- 거의 모든 구간이 **필수**이고 대부분 **크기가 고정**돼 있다.

### 프레임 구조

| 필드 | 크기 | 설명 |
|---|---|---|
| **프리앰블(Preamble)** | 8바이트(64비트) | 앞 7바이트는 **1과 0이 번갈아 나오는 열**. 프레임 사이의 버퍼 역할을 하고, 네트워크 인터페이스가 **전송 속도를 조절하는 내부 클럭을 동기화**하는 데도 쓰인다 |
| **SFD (Start Frame Delimiter)** | 프리앰블의 마지막 1바이트 | 프리앰블이 끝났고 **실제 프레임 내용이 이어진다**는 신호 |
| **목적지 MAC 주소** | 6바이트(48비트) | 의도된 수신자의 하드웨어 주소 |
| **출발지 MAC 주소** | 6바이트(48비트) | 프레임이 출발한 곳 |
| **이더타입(EtherType)** | 16비트 | **프레임 내용물의 프로토콜**을 설명 |
| *(대안)* **VLAN 헤더** | — | 있으면 이 프레임이 **VLAN 프레임**임을 나타내고, **이더타입 필드는 그 뒤에 온다** |
| **페이로드(Payload)** | 46~1500바이트 | **헤더가 아닌 실제 전송 데이터.** IP·전송·애플리케이션 계층의 모든 데이터가 여기 담긴다 |
| **FCS (Frame Check Sequence)** | 4바이트(32비트) | 프레임 전체에 대한 **체크섬 값** |

### VLAN

- **VLAN = virtual LAN.** **같은 물리 장비 위에서 여러 논리적 LAN을 운영**하게 해 주는 기법이다.
- VLAN 태그가 붙은 프레임은 **그 태그를 중계하도록 설정된 스위치 인터페이스로만** 나간다.
- 그래서 하나의 물리 네트워크를 **여러 LAN처럼** 동작시킬 수 있다.
- 보통 **서로 다른 종류의 트래픽을 분리**하는 데 쓴다. 예: 회사의 IP 전화기는 한 VLAN에, 데스크톱은 다른 VLAN에.

### CRC와 무결성 검사

- FCS의 체크섬 값은 프레임에 대해 **순환 중복 검사(CRC, Cyclical Redundancy Check)** 를 수행해 계산한다.
- CRC는 데이터 무결성에서 중요한 개념이며 **네트워크 전송뿐 아니라 컴퓨팅 전반에서** 쓰인다.
- CRC는 기본적으로 **다항식 나눗셈(polynomial division)을 이용해 더 큰 데이터 집합을 대표하는 수를 만드는 수학적 변환**이다.
- **같은 데이터에 CRC를 수행하면 항상 같은 체크섬이 나와야 한다.**

동작 순서:

1. 송신 장치가 목적지·출발지 MAC, 페이로드 등 모든 정보를 모은다.
2. 그 데이터에 대해 **CRC를 수행**하고, 결과 체크섬을 **프레임 끝의 FCS로 붙인다.**
3. 링크를 건너 수신 측에 도착한다.
4. 수신 측이 받은 필드들에 대해 **다시 CRC를 수행**한다.
5. **계산한 체크섬이 FCS 필드의 값과 다르면 데이터를 버린다.** 전송 중 데이터가 유실되거나 손상된 것이기 때문이다.
6. 그 데이터를 **재전송할지는 상위 계층 프로토콜이 결정**한다.

> **이더넷은 데이터 무결성을 보고할 뿐, 데이터 복구는 수행하지 않는다.**

## 예시

```
[프리앰블 7B][SFD 1B][목적지 MAC 6B][출발지 MAC 6B][이더타입 2B][페이로드 46~1500B][FCS 4B]
                                                    ↑
                                        VLAN 헤더가 있으면 그 뒤에 위치
```

## 요약

- 이더넷 프레임은 프리앰블/SFD → 목적지·출발지 MAC → 이더타입 → 페이로드 → FCS 순의 고정 구조다.
- 프리앰블은 버퍼 겸 클럭 동기화용이고 SFD가 본문 시작을 알린다.
- 페이로드는 46~1500바이트이며 상위 계층 데이터 전부가 여기 들어간다.
- FCS의 CRC로 손상 여부를 판별하되, 재전송 결정은 상위 계층 몫이다.
- VLAN 태그로 하나의 물리 네트워크를 여러 논리 LAN으로 쪼갤 수 있다.
