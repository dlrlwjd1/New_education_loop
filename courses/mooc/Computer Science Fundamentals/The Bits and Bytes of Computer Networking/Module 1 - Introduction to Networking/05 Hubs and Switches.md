# Hubs and Switches

## 개요

- 여러 대의 컴퓨터를 한 네트워크에 묶는 장치인 **허브(hub)** 와 **스위치(switch)** 를 비교한다.
- 핵심: **허브는 1계층(물리) 장치**, **스위치는 2계층(데이터 링크) 장치**다. 이 차이가 성능 차이를 만든다.

## 내용

### 점대점 연결의 한계

- 케이블만으로는 **점대점(point to point)** 연결밖에 만들 수 없다. 링크 양 끝에 장치가 하나씩만 존재하는 네트워크다.
- 컴퓨터가 수십억 대인 세상에서 이것만으로는 쓸모가 크지 않다.

### 허브 (Hub)

- **물리 계층(Layer 1) 장치**로, 여러 컴퓨터를 한꺼번에 연결할 수 있게 해 준다.
- 허브에 연결된 **모든 장치가 동시에 서로에게 말하는** 상태가 된다.
- 들어온 데이터가 자기 것인지 판단하고, 아니면 무시하는 일은 **연결된 각 시스템의 몫**이다.
- 이 때문에 네트워크에 **소음(noise)** 이 많아지고 **충돌 도메인(collision domain)** 이 만들어진다.

> **충돌 도메인(collision domain)** = 한 번에 **하나의 장치만** 통신할 수 있는 네트워크 구간.

- 여러 시스템이 동시에 데이터를 보내려 하면 케이블을 타는 전기 펄스가 서로 간섭한다.
- 그러면 시스템들은 **조용해질 때까지 기다렸다가 다시 보내야** 한다.
- 결과적으로 네트워크 통신이 크게 느려진다. **허브가 오늘날 드문 이유**이며, 대체로 과거의 유물이다.

### 스위치 (Switch)

- 원래 이름은 **switching hub**. 여러 장치를 연결해 통신하게 한다는 점은 허브와 같다.
- **차이는 계층이다.** 허브가 Layer 1 물리 계층 장치라면, **스위치는 Layer 2 데이터 링크 장치**다.
- 그래서 스위치는 네트워크를 오가는 **이더넷 프로토콜 데이터의 내용을 들여다볼 수 있고**, 그 데이터가 어느 시스템으로 가야 하는지 판단해 **그 시스템에게만** 보낸다.
- 결과: 네트워크의 **충돌 도메인 크기가 줄거나 완전히 사라진다.** 재전송이 줄고 전체 처리량(throughput)이 올라간다.

## 예시

| 구분 | 허브 | 스위치 |
|---|---|---|
| 계층 | Layer 1 (물리) | Layer 2 (데이터 링크) |
| 데이터 전달 | 연결된 **전부**에게 | 목적지 **하나**에게 |
| 목적지 판단 | 각 수신 시스템이 스스로 | 스위치가 이더넷 데이터를 검사해서 |
| 충돌 도메인 | 크게 만든다 | 줄이거나 없앤다 |
| 처리량 | 낮다 | 높다 |
| 현재 사용 | 거의 없음(역사적 유물) | 표준 |

## 요약

- 허브는 모든 포트로 데이터를 뿌리므로 충돌 도메인을 만들고 네트워크를 느리게 한다.
- 스위치는 이더넷 데이터를 검사해 목적지에만 보내므로 충돌 도메인을 줄이고 처리량을 높인다.
- 이 차이의 근원은 **동작하는 계층이 1계층이냐 2계층이냐**에 있다.
