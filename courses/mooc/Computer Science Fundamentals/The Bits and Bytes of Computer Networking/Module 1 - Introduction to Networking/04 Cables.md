# Cables

## 개요

- 유선 네트워크의 가장 기본 구성 요소인 **케이블**을 다룬다.
- 오늘날 쓰이는 네트워크 케이블은 크게 **구리(copper)** 와 **광섬유(fiber)** 두 종류로 나뉜다.
- 구리는 **전압 변화**로, 광섬유는 **빛의 펄스**로 1과 0을 표현한다.

## 내용

### 구리 케이블 (Copper)

- 가장 흔한 형태의 네트워킹 케이블이다. 플라스틱 절연체 안에 **여러 쌍의 구리선(pairs of copper wires)** 이 들어 있다.
- 컴퓨터는 이진수로 통신한다. 송신 장치는 **두 범위 사이에서 전압을 바꿔** 이진 데이터를 구리선으로 보낸다.
- 수신 장치는 그 전압 변화를 이진 1과 0으로 해석하고, 이를 다양한 형태의 데이터로 번역한다.

### 카테고리 케이블 — Cat 5 / Cat 5e / Cat 6

가장 흔한 구리 **트위스티드 페어(twisted pair)** 케이블이다. "Cat"은 category의 줄임말이다.

| 케이블 | 특징 |
|---|---|
| **Cat 5** | 오래된 규격. 대부분 Cat 5e·Cat 6로 대체됨 |
| **Cat 5e** | 내부 구조가 **크로스토크를 줄이도록** 개선되어 Cat 5를 대체함 |
| **Cat 6** | 크로스토크를 피하기 위한 **더 엄격한 규격**. 더 비싸다. 더 빠르고 더 신뢰성 있게 전송하지만, **내부 배열 때문에 고속에서는 최대 거리가 더 짧다** |

- 겉모습은 거의 같고 내부도 육안으로는 매우 비슷하다.
- 중요한 것은 **케이블 안에서 꼬임 쌍(twisted pair)이 어떻게 배열되었는지**에 따라 전송 속도와 외부 간섭에 대한 저항성이 크게 달라진다는 점이다.

### 크로스토크 (Crosstalk)

- **한 선의 전기 펄스가 다른 선에서 잘못 감지되는 현상**이다.
- 그러면 수신 측이 데이터를 이해하지 못해 **네트워크 오류**가 발생한다.
- 상위 계층 프로토콜에 누락 데이터를 감지하고 재요청하는 방법이 있지만, **당연히 시간이 더 걸린다.**
- Cat 5e의 더 높은 품질 규격은 재전송 필요성을 낮추고, 결과적으로 **같은 시간에 평균적으로 더 많은 데이터**를 보낼 수 있게 한다.

### 광섬유 케이블 (Fiber)

- fiber optic cable의 줄임말. 내부에 **개별 광섬유**가 들어 있는데, **사람 머리카락 굵기의 아주 가는 유리관**이다.
- 이 유리관은 **빛의 다발을 전송**한다. 구리가 전압을 쓰는 것과 달리, **빛의 펄스로 1과 0을 표현**한다.
- 장점
  - **외부 전자기 간섭이 심한 환경**에서 특히 유용하다. 그런 간섭은 구리선의 데이터 전송에 영향을 주기 때문이다.
  - 일반적으로 구리보다 **더 빠르게** 전송한다.
  - **훨씬 먼 거리**를 데이터 손실 위험 없이 전송할 수 있다.
- 단점: **훨씬 비싸고 부서지기 쉽다(fragile).**
- 실무 감각: 광섬유는 사무실이나 가정보다 **데이터센터에서 마주칠 가능성이 훨씬 높다.**

## 요약

- 네트워크 케이블은 구리와 광섬유 두 갈래다.
- 구리는 전압 변화로, 광섬유는 빛의 펄스로 이진 데이터를 나른다.
- Cat 5 → Cat 5e → Cat 6 순으로 크로스토크 저항이 좋아지고 비싸지며, Cat 6는 고속에서 최대 거리가 짧아진다.
- 크로스토크는 재전송을 유발해 실질 전송량을 떨어뜨린다.
- 광섬유는 빠르고 멀리 가며 전자기 간섭에 강하지만 비싸고 약하다. 주로 데이터센터에서 본다.
