# The TCP/IP Five-Layer Network Model

## 개요

- 이 코스의 뼈대인 **TCP/IP 5계층 모델**의 각 계층이 무엇이고 어떤 목적을 갖는지 정리한다.
- 아래에서 위로: **물리 계층 → 데이터 링크 계층 → 네트워크 계층 → 전송 계층 → 애플리케이션 계층**.
- 핵심 구분: **IP는 노드에서 노드로**, **TCP/UDP는 그 노드 안의 어느 프로그램으로**.

## 내용

### 1. 물리 계층 (Physical Layer)

- 이름 그대로 **컴퓨터를 물리적으로 연결하는 장치**를 나타낸다.
- 네트워킹 케이블과 커넥터의 규격, 그리고 그 연결 위로 **신호를 어떻게 보내는지**에 대한 명세를 포함한다.

### 2. 데이터 링크 계층 (Data Link Layer)

- 자료에 따라 **네트워크 인터페이스(network interface) 계층** 또는 **네트워크 액세스(network access) 계층**이라고도 부른다.
- **여기서 첫 프로토콜이 등장한다.** 물리 계층이 케이블·커넥터·신호 전송을 다룬다면, 데이터 링크 계층은 **그 신호를 해석하는 공통된 방법**을 정의해 네트워크 장치들이 서로 통신할 수 있게 한다.
- 이 계층에는 여러 프로토콜이 있지만 가장 흔한 것은 **이더넷(Ethernet)** 이다. 무선 기술도 점점 널리 쓰인다.
- 이더넷 표준은 물리 계층 속성을 규정하는 것을 넘어, **같은 네트워크(링크) 안의 노드에 데이터를 전달하는** 프로토콜도 정의한다.

### 3. 네트워크 계층 (Network Layer)

- **인터넷 계층(Internet layer)** 이라고도 한다.
- **서로 다른 네트워크끼리 통신하게 해 주는** 계층이며, 그 일을 하는 장치가 **라우터(router)** 다.
- 라우터로 연결된 네트워크들의 모음을 **인터네트워크(internetwork)** 라 하고, 그중 가장 유명한 것이 **인터넷**이다.
- 데이터 링크 계층이 **하나의 링크를 건너는** 책임이라면, 네트워크 계층은 **여러 네트워크를 가로질러 배달하는** 책임이다.
- 가장 흔한 프로토콜은 **IP(Internet Protocol)** 이며, 인터넷과 전 세계 소규모 네트워크의 심장이다.

### 4. 전송 계층 (Transport Layer)

- 네트워크 소프트웨어는 보통 **클라이언트(요청)** 와 **서버(응답)** 로 나뉜다. 한 노드가 여러 클라이언트·서버 프로그램을 동시에 돌릴 수 있다.
- 예: PC 한 대에서 메일 프로그램과 웹 브라우저(둘 다 클라이언트)를 동시에 쓰고, 메일 서버와 웹 서버가 같은 서버 장비에서 돌 수도 있다.
- 그런데도 메일은 메일 앱으로, 웹페이지는 브라우저로 정확히 들어간다. **그 일을 하는 것이 전송 계층이다.**
- 네트워크 계층이 **두 노드 사이**에 데이터를 배달한다면, 전송 계층은 **어느 클라이언트/서버 프로그램이 그 데이터를 받아야 하는지** 가려낸다.
- 대표 프로토콜은 **TCP(Transmission Control Protocol)** 이며, **UDP(User Datagram Protocol)** 도 IP 위에서 동작한다.
- **TCP와 UDP의 큰 차이: TCP는 데이터가 확실히 전달되도록 보장하는 메커니즘을 제공하고, UDP는 제공하지 않는다.**

> "TCP/IP"라고 붙여 부르는 일이 많지만, **둘은 목적이 완전히 다른 별개의 프로토콜**이다. 네트워크 문제를 이해하고 해결하려면 이 구분이 중요하다.

### 5. 애플리케이션 계층 (Application Layer)

- 이름대로 **애플리케이션에 특화된** 프로토콜이 아주 많이 존재하는 계층이다.
- 웹 브라우징, 메일 송수신을 가능하게 하는 프로토콜들이 여기에 있다.
- 사용자가 (의식하지 못했더라도) **직접 접해 본 프로토콜들**이라 가장 익숙하게 느껴지는 계층이다.

## 예시

강의가 제시한 **택배 배송 비유**:

| 계층 | 택배 비유 |
|---|---|
| 물리 계층 | 배송 트럭과 도로 |
| 데이터 링크 계층 | 트럭이 한 교차로에서 다음 교차로로 계속 이동하는 방식 |
| 네트워크 계층 | 주소 A에서 주소 B까지 가려면 **어떤 도로를 타야 하는지** 판단 |
| 전송 계층 | 기사가 **당신 집 문을 두드려** 물건이 도착했음을 알리는 것 |
| 애플리케이션 계층 | **소포 안의 내용물** 그 자체 |

## 요약

- 물리 = 케이블·커넥터·신호, 데이터 링크 = 신호 해석 규칙(이더넷)과 같은 링크 내 전달.
- 네트워크(IP) = 네트워크와 네트워크를 건너 노드까지, 라우터가 담당.
- 전송(TCP/UDP) = 그 노드 안에서 올바른 애플리케이션까지. TCP는 신뢰성 보장, UDP는 안 함.
- 애플리케이션 = 웹·메일 등 용도별 프로토콜.
- TCP/IP는 한 덩어리가 아니라 **서로 다른 층의 서로 다른 프로토콜 두 개**다.
