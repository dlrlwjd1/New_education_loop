# Routers

## 개요

- 허브·스위치가 **하나의 네트워크(LAN)** 안을 연결한다면, **라우터(router)** 는 **독립된 네트워크들 사이**로 데이터를 전달한다.
- 라우터는 **Layer 3(네트워크 계층)** 장치이며, **IP 데이터를 검사해** 어디로 보낼지 결정한다.
- 라우터끼리는 **BGP**로 경로 정보를 주고받는다.

## 내용

### 계층으로 본 세 장치

- 허브 = Layer 1 장치
- 스위치 = Layer 2 장치
- **라우터 = Layer 3 장치 (네트워크 계층)**

스위치가 이더넷 데이터를 검사해 목적지를 정하듯, **라우터는 IP 데이터를 검사해** 목적지를 정한다.

- LAN(local area network) = 허브·스위치로 묶인 하나의 네트워크.
- 다른 네트워크의 컴퓨터와 데이터를 주고받고 싶을 때 라우터가 등장한다.

### 라우팅 테이블

- 라우터는 **전 세계의 수많은 서로 다른 네트워크 사이에서 트래픽을 어떻게 라우팅할지에 대한 정보**를 담은 내부 테이블을 갖고 있다.

### 가정용·소규모 사무실 라우터

- 가장 흔히 보게 되는 라우터 종류다.
- 이런 장치는 **라우팅 테이블이 그리 상세하지 않다.**
- 주된 목적은 가정이나 사무실 LAN 내부에서 나온 트래픽을 받아 **ISP(Internet Service Provider)로 넘겨주는 것**이다.

### 코어 라우터 (Core Router)

- 트래픽이 ISP에 도달하면 **훨씬 정교한 종류의 라우터**가 넘겨받는다.
- 이 **코어 라우터들이 인터넷의 백본(backbone)** 을 이루며, 우리가 매일 인터넷으로 데이터를 주고받는 방식을 직접 책임진다.
- 코어 라우터는 가정용보다 트래픽이 훨씬 많을 뿐 아니라, **어디로 보낼지 결정하는 복잡도 자체가 훨씬 크다.**
- 코어 라우터는 보통 **다른 많은 라우터와 여러 연결**을 갖는다.

### BGP (Border Gateway Protocol)

- 라우터들이 서로 데이터를 공유하는 프로토콜이다.
- 이를 통해 **트래픽을 전달할 가장 최적인 경로**를 학습한다.

## 예시

웹 브라우저를 열고 웹페이지 하나를 불러올 때, 내 컴퓨터와 웹 서버 사이의 트래픽은 **수십 개의 서로 다른 라우터**를 거쳤을 수 있다.

## 요약

- 라우터는 Layer 3 장치로, 서로 다른 네트워크 사이에 데이터를 전달한다.
- 스위치는 이더넷(L2)을, 라우터는 IP(L3)를 검사해 목적지를 정한다.
- 가정용 라우터의 역할은 사실상 "내 LAN 트래픽을 ISP로 넘기기"다.
- ISP의 코어 라우터가 인터넷 백본을 이루며, BGP로 최적 경로를 학습한다.
