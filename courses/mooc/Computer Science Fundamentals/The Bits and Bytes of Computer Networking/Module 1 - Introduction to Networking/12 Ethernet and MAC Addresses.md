# Ethernet and MAC Addresses

## 개요

- 데이터 링크 계층의 대표 프로토콜인 **이더넷(Ethernet)** 과, 장치를 식별하는 **MAC 주소**를 다룬다.
- 데이터 링크 계층의 핵심 역할: **상위 계층이 물리 계층과 하드웨어를 신경 쓰지 않아도 되도록 추상화하는 것.**
- 이더넷이 충돌 문제를 푸는 방법이 **CSMA/CD**다.

## 내용

### 데이터 링크 계층이 하는 일 — 추상화

- 무선·셀룰러가 빠르게 늘고 있지만, **직장과 데이터센터에서는 전통적인 케이블 네트워크가 여전히 가장 흔하다.**
- 개별 링크로 데이터를 보내는 데 가장 널리 쓰이는 프로토콜이 **이더넷**이다.
- 이 계층의 주된 목적 중 하나는 **다른 계층들이 물리 계층과 어떤 하드웨어를 쓰는지 신경 쓸 필요를 없애는 것**이다.
- 덕분에 인터넷·전송·애플리케이션 계층은 **장치가 어떻게 연결됐든 똑같이 동작**한다. 웹 브라우저는 자신이 트위스티드 페어로 연결됐는지 무선으로 연결됐는지 알 필요가 없다.

### 이더넷의 역사와 충돌 문제

- 이더넷은 **1980년에 처음 등장**했고 **1983년에 첫 완전 표준화**가 발표됐다. 이후 대역폭 요구를 지원하기 위한 변경이 있었지만, **오늘날의 이더넷도 당시 표준과 대체로 비슷하다.**
- 1983년에는 **스위치(switching hub)가 아직 발명되지 않았다.** 그래서 네트워크의 많은/모든 장치가 **하나의 충돌 도메인(collision domain)** 을 공유하는 일이 잦았다.
- 충돌 도메인 안의 모든 데이터는 연결된 모든 노드에 전달된다. 두 컴퓨터가 동시에 데이터를 보내면 **1과 0을 나타내는 전류가 말 그대로 충돌**해 결과를 알아볼 수 없게 된다.

### CSMA/CD

> **CSMA/CD** = Carrier Sense Multiple Access with Collision Detection.
> 통신 채널이 비었는지, 장치가 전송해도 되는지를 판단하는 기법.

동작은 단순하다.

1. 해당 네트워크 구간에 **현재 전송 중인 데이터가 없으면** 노드는 자유롭게 데이터를 보낸다.
2. 둘 이상의 컴퓨터가 **동시에 보내게 되면**, 컴퓨터들이 **충돌을 감지하고 전송을 멈춘다.**
3. 충돌에 관여한 각 장치는 **무작위 시간 간격만큼 기다린 뒤** 다시 보낸다.
4. 이 **무작위 간격**이 다음 전송에서 또 충돌하는 것을 막아 준다.

### MAC 주소

- 충돌 도메인에서는 모든 장치가 전 구간의 통신을 다 받으므로, **이 전송이 실제로 어느 노드를 위한 것인지 식별할 방법**이 필요하다. 그것이 **MAC(Media Access Control) 주소**다.
- **개별 네트워크 인터페이스에 붙는 전 세계적으로 고유한 식별자**다.
- **48비트** 숫자이며, 보통 **16진수 두 자리씩 여섯 묶음**으로 표현한다.
- 16진수는 16개 숫자로 수를 표현하는 방식이다. 9보다 큰 한 자리를 나타낼 숫자가 없으므로 **A, B, C, D, E, F로 10, 11, 12, 13, 14, 15**를 표현한다.
- MAC 주소의 각 묶음을 **옥텟(octet)** 이라고도 한다. 네트워킹에서 옥텟은 **8비트로 표현할 수 있는 수**이며, 16진수 두 자리가 8비트와 같은 범위를 표현한다.

### 왜 전 세계적으로 고유한가

- 48비트 수의 총 가짓수는 **2^48 = 281,474,976,710,656** 가지다. 아주 많다.
- MAC 주소는 두 부분으로 나뉜다.

| 부분 | 이름 | 내용 |
|---|---|---|
| 앞 3옥텟 | **OUI (Organizationally Unique Identifier)** | **IEEE**가 개별 하드웨어 제조사에 할당 |
| 뒤 3옥텟 | — | 제조사가 원하는 대로 할당. 단 **각 주소를 한 번만** 할당해야 함 |

> 실무 팁: OUI 덕분에 **MAC 주소만 보고도 네트워크 인터페이스 제조사를 항상 알아낼 수 있다.**

- 이더넷은 MAC 주소를 사용해, 보내는 데이터에 **송신 장비의 주소와 수신 대상 장비의 주소**를 모두 담는다. 그래서 하나의 충돌 도메인으로 동작하는 네트워크 구간에서도 각 노드가 **언제 자기에게 온 트래픽인지** 알 수 있다.

## 예시

MAC 주소 표기: 16진수 2자리 × 6묶음 (총 48비트)

```
AA:BB:CC:DD:EE:FF
└──────┘ └──────┘
  OUI      제조사 할당분
(IEEE가 제조사에 배정)
```

## 요약

- 데이터 링크 계층은 상위 계층이 하드웨어를 몰라도 되게 추상화한다.
- 이더넷은 1980년 등장, 1983년 표준화됐고 지금도 큰 틀은 같다.
- 스위치 이전 시대의 충돌 문제를 CSMA/CD(채널 감지 → 충돌 감지 → 무작위 대기 후 재전송)로 해결했다.
- MAC 주소는 48비트 전역 고유 식별자이며, 앞 3옥텟 OUI로 제조사를 알 수 있다.
