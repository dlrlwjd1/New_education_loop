# The Application Layer and the OSI Model

## 개요

- 이 코스가 쓰는 5계층 모델과 **OSI(Open Systems Interconnection) 7계층 모델**의 관계를 정리한다.
- OSI가 추가로 두는 두 계층은 **세션 계층(session layer)** 과 **표현 계층(presentation layer)** 이며, 5계층 모델에서는 **이 둘의 기능을 애플리케이션 계층에 묶어 넣는다.**

## 내용

### 여러 모델이 존재한다

- 경쟁하는 네트워크 계층 모델이 여럿 있다. 이 코스는 **5계층 모델**을 쓰지만, IT 지원 담당자로 일하다 보면 다른 모델도 만나게 된다.
- 어떤 모델은 **물리 계층과 데이터 링크 계층을 하나로 합쳐 4계층**만 이야기하기도 한다.
- **OSI 모델**은 **가장 엄밀하게 정의된 모델**이라 중요하다. 그래서 **학계나 여러 네트워크 자격증 기관에서 자주 쓰인다.**

### OSI가 추가하는 두 계층

OSI는 7계층이며, **전송 계층과 애플리케이션 계층 사이에 두 계층을 더** 둔다.

| OSI 계층 | 책임 |
|---|---|
| **5. 세션 계층 (Session Layer)** | **실제 애플리케이션과 전송 계층 사이의 통신을 매개**한다. 하위 모든 계층에서 캡슐화가 벗겨진 애플리케이션 계층 데이터를 받아 **다음 계층(표현 계층)으로 넘기는 운영체제의 일부** |
| **6. 표현 계층 (Presentation Layer)** | 캡슐화가 벗겨진 애플리케이션 계층 데이터를 **해당 애플리케이션이 실제로 이해할 수 있도록** 만든다. **암호화나 압축을 처리하는 운영체제 부분** |

### 왜 5계층 모델은 이 둘을 합치는가

- 중요한 개념들이지만 **이 두 계층에서는 캡슐화(encapsulation)가 일어나지 않는다.**
- 그래서 5계층 모델에서는 **이 기능들을 모두 애플리케이션 계층에 묶는다.**
- 네트워킹을 이해하는 일상 업무에는 **5계층 모델이 가장 유용**하다고 보지만, **7계층 OSI 모델도 널리 쓰이므로 기초는 반드시 알아야** 한다.

## 예시

```
5계층 모델                    OSI 7계층 모델
─────────────                ─────────────
애플리케이션        ←──┬──   7. 애플리케이션
                       ├──   6. 표현 (암호화·압축)
                       └──   5. 세션
전송                   ───   4. 전송
네트워크               ───   3. 네트워크
데이터 링크            ───   2. 데이터 링크
물리                   ───   1. 물리
```

## 요약

- OSI는 가장 엄밀하게 정의된 7계층 모델로 학계와 자격증에서 많이 쓰인다.
- 세션 계층은 애플리케이션과 전송 계층을 잇고, 표현 계층은 암호화·압축을 담당한다.
- 이 두 계층에서는 캡슐화가 일어나지 않아 5계층 모델은 애플리케이션 계층에 통합한다.
