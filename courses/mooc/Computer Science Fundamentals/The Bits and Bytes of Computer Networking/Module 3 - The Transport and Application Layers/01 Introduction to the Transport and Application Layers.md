# Introduction to the Transport and Application Layers

## 개요

- 앞의 세 계층은 **노드와 노드**의 통신을 설명했다. 이 모듈은 **개별 컴퓨터 프로그램끼리의 통신**을 다룬다.
- **전송 계층** = 트래픽을 **특정 네트워크 애플리케이션으로** 보내는 것. **애플리케이션 계층** = 그 애플리케이션들이 **서로 이해하는 방식으로** 통신하는 것.

## 내용

### 네트워킹의 진짜 목적

- 컴퓨터를 네트워크로 묶는 이유는 단지 데이터를 주고받기 위해서가 아니라, **그 컴퓨터에서 돌아가는 프로그램들이 서로 데이터를 주고받게 하기 위해서**다.

### 이 모듈을 마치면

- **TCP 포트와 소켓**을 설명하고 **TCP 헤더의 각 구성 요소**를 식별할 수 있다.
- **연결 지향(connection-oriented) 프로토콜과 비연결(connectionless) 프로토콜의 차이**를 보일 수 있다.
- **TCP가 데이터 무결성을 보장하는 방법**을 설명할 수 있다.

## 요약

- 전송 계층은 "어느 프로그램에게"를, 애플리케이션 계층은 "무슨 말로"를 담당한다.
- 이 모듈의 키워드: 포트와 소켓, TCP 헤더, 연결 지향 vs 비연결, 데이터 무결성.
