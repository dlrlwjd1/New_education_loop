# IPv4 Address Classes

## 개요

- IP 주소는 **네트워크 ID**와 **호스트 ID**로 나뉜다.
- 전역 IP 주소 공간을 나누는 방식이 **주소 클래스 체계(address class system)** 이며, 주요 클래스는 **A·B·C**, 그 외에 **D·E**가 있다.
- 실무적으로는 **CIDR**로 대부분 대체됐지만, 여전히 여러 방식으로 남아 있어 이해할 필요가 있다.

## 내용

### 네트워크 ID와 호스트 ID

- 예: `9.100.100.100` (IBM이 첫 옥텟 9를 전부 소유)
  - **네트워크 ID = 첫 번째 옥텟**
  - **호스트 ID = 2, 3, 4번째 옥텟**

### 클래스 A · B · C

| 클래스 | 네트워크 ID | 호스트 ID | 호스트 주소 수 |
|---|---|---|---|
| **Class A** | 첫 1옥텟 | 나머지 3옥텟 | 24비트 → 2^24 = **16,777,216** |
| **Class B** | 첫 2옥텟 | 나머지 2옥텟 | 16비트 |
| **Class C** | 첫 3옥텟 | 마지막 1옥텟 | 8비트 → 2^8 = **256** |

### 첫 비트만 보면 클래스를 안다

| 클래스 | 첫 비트 패턴 | 첫 옥텟 십진 범위 |
|---|---|---|
| **A** | `0…` | **0 ~ 127** |
| **B** | `10…` | **128 ~ 191** |
| **C** | `110…` | **192 ~ 223** |
| **D** | `1110…` | **224 ~ 239** |
| **E** | 나머지 전부 | — |

- 사람은 이진수로 생각하는 데 능하지 않으므로, **점 십진 표기의 첫 옥텟 범위로 외우면 편하다.**
- 각 옥텟은 8비트라 0~255를 담을 수 있는데, **첫 비트가 0이어야 하는 클래스 A는 첫 옥텟이 0~127**이 된다.

### 클래스 D와 E

- **Class D**: 항상 `1110`으로 시작하며 **멀티캐스팅(multicasting)** 에 쓰인다. 하나의 IP 데이터그램을 **네트워크 전체에 한 번에** 보내는 방식이다. 십진 **224~239**.
- **Class E**: 남은 모든 IP 주소. **할당되지 않았고 테스트 목적으로만** 쓰인다.

### 지금은 CIDR

- 실무에서는 이 클래스 체계가 대체로 **CIDR(Classless Inter-Domain Routing)** 로 대체됐다.
- 그래도 클래스 체계는 여러 방식으로 여전히 남아 있어, 균형 잡힌 네트워킹 지식을 위해 이해해 둘 필요가 있다.

## 예시

```
9.100.100.100
└┬┘ └────┬────┘
 │        └─ 호스트 ID (2·3·4 옥텟)
 └─ 네트워크 ID (1 옥텟)  → 첫 옥텟 9 → 0~127 범위 → Class A
```

## 요약

- IP = 네트워크 ID + 호스트 ID. 어디서 끊느냐가 클래스다.
- A=1옥텟/3옥텟, B=2/2, C=3/1이며 각각 첫 비트 0, 10, 110으로 구분된다.
- 첫 옥텟 십진 범위: A 0~127, B 128~191, C 192~223, D(멀티캐스트) 224~239, E는 테스트용.
- 현재는 CIDR이 사실상 이 체계를 대체했다.
