# Stay motivated in the program

## 개요

- 학습 도중 막히거나 압도당할 때 어떻게 동기를 유지할지, 수료생들이 짧게 조언하는 영상이다.

## 내용

### 막히는 것은 나만이 아니다

- 어떤 부분에서 막히거나 벽에 부딪힌 느낌이 든다면, **똑같은 것을 겪고 있는 다른 누군가가 언제나 있다.**

### 자기 의심에 시간을 낭비하지 말 것

- 정보에 압도당하거나 이해가 안 된다고 느낄 때마다 **스스로를 의심하느라 너무 많은 시간을 낭비했다.**
- **"그냥 해 봐, 넌 할 수 있어"** 라는 친구와 가족의 말을 진작 들었어야 했다.

### 이동 중에도 학습하기

- 동기를 되찾는 데 가장 큰 도움이 된 것 중 하나는 **강좌를 휴대폰으로 볼 수 있다는 접근성**이었다.
- 앱에 들어가 영상 몇 개를 듣는 것만으로도 **이동 중 학습**이 가능했다.

### 나를 응원하는 네트워크를 만들 것

- **나에게 동기를 주는 사람들의 네트워크를 갖는 것이 정말 근본적**이다.
- 친구든 가족이든, **처음부터 함께하며 코치처럼 내 편에 서 줄 사람**이면 된다.
- **도움을 청하는 것을 두려워하지 말 것.** 동료, 코치, 친구, 가족 누구든. **언제나 나보다 더 잘 아는 사람이 있고, 그들에게서 배울 수 있다.**

## 요약

- 막히는 경험은 보편적이다. 혼자가 아니다.
- 자기 의심에 시간을 쓰기보다 일단 해 본다.
- 모바일 학습으로 짧은 시간을 활용한다.
- 응원해 줄 사람들을 곁에 두고, 도움을 청하는 데 주저하지 않는다.
