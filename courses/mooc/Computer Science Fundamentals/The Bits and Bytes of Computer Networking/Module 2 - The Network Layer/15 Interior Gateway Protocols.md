# Interior Gateway Protocols

## 개요

- 라우팅 테이블이 **어떻게 계속 최신 정보로 갱신되는지**가 라우팅의 진짜 핵심이며, 그 일을 하는 것이 **라우팅 프로토콜(routing protocol)** 이다.
- 라우팅 프로토콜은 **내부 게이트웨이 프로토콜(interior gateway protocol)** 과 **외부 게이트웨이 프로토콜(exterior gateway protocol)** 로 나뉜다.
- 내부 게이트웨이 프로토콜은 다시 **링크 상태(link state)** 와 **거리 벡터(distance vector)** 로 나뉜다.

## 내용

### 자율 시스템 (Autonomous System)

- **내부 게이트웨이 프로토콜**은 라우터들이 **하나의 자율 시스템 안에서** 정보를 공유할 때 쓴다.
- **자율 시스템(autonomous system)** = **하나의 네트워크 운영자의 통제 아래 있는 네트워크들의 모음**.
  - 예 1: 여러 사무실 각각이 자체 LAN을 갖고 그 사이로 데이터를 라우팅해야 하는 **대기업**.
  - 예 2: 보통 전국 규모인 **ISP가 운용하는 다수의 라우터**.
- 이와 대비되는 **외부 게이트웨이 프로토콜**은 **독립적인 자율 시스템들 사이의 정보 교환**에 쓰인다.

### 거리 벡터 프로토콜 (Distance Vector)

- **더 오래된 표준**이다.
- 동작: 라우터가 **자신의 라우팅 테이블**(자신이 아는 모든 네트워크와 그 홉 거리 목록)을 **직접 연결된 모든 이웃 라우터에게 보낸다.**
- 컴퓨터 과학에서 **리스트를 벡터(vector)** 라고 부른다. 그래서 **네트워크까지의 거리 목록을 보내는 프로토콜**을 거리 벡터 프로토콜이라 한다.
- 한계: 라우터가 **자율 시스템 전체 상태를 잘 모른다.** **직속 이웃에 대한 정보만** 갖는다. 그래서 **멀리 떨어진 곳의 변화에 반응이 느릴 수** 있다.

#### 동작 예시

- Router A의 라우팅 테이블에 **`10.1.1.0/24` (= 네트워크 X)** 항목이 있다.
- Router A는 네트워크 X로 가는 가장 빠른 길이 **자신의 Interface 2 → Router C**이고 **4홉**이라고 믿고 있다.
- 한편 **Router B는 네트워크 X에서 2홉** 거리이고, 그 사실이 B의 라우팅 테이블에 있다.
- Router B가 거리 벡터 프로토콜로 **자기 라우팅 테이블 내용을 Router A에게 보낸다.**
- Router A는 네트워크 X가 **B에서 2홉**임을 보고, **A→B로 가는 추가 1홉을 더해도 3홉**이라는 것을 계산한다.
- Router A는 라우팅 테이블을 갱신해, 네트워크 X로 갈 때 **자신의 Interface 1 → Router B**로 보내도록 바꾼다.

### 링크 상태 프로토콜 (Link State)

- 거리 벡터의 한계 때문에 나중에 발명됐다. **더 정교한 방식**으로 최적 경로를 결정한다.
- 이름의 유래: **각 라우터가 자기 인터페이스 각각의 링크 상태(state of the link)를 광고(advertise)** 하기 때문이다. 그 인터페이스는 다른 라우터에 연결될 수도, 네트워크에 직접 연결될 수도 있다.
- 각 라우터의 정보가 **자율 시스템의 다른 모든 라우터에게 전파**된다. 즉 **시스템의 모든 라우터가 다른 모든 라우터의 모든 세부를 안다.**
- 각 라우터는 이 **훨씬 큰 정보 집합**에 대해 **복잡한 알고리즘을 돌려** 최적 경로를 판단한다.

### 비교

| 항목 | 거리 벡터 | 링크 상태 |
|---|---|---|
| 공유하는 것 | 자기 라우팅 테이블(거리 목록) | 자기 인터페이스들의 링크 상태 |
| 공유 대상 | 직접 연결된 이웃 | 자율 시스템의 모든 라우터 |
| 아는 범위 | 이웃 정보만 | 시스템 전체 |
| 변화 반응 | 먼 곳 변화에 느림 | 빠름 |
| 자원 요구 | 적음 | **메모리·처리 능력 모두 훨씬 많이** 필요 |

- 하드웨어가 강력해지고 저렴해지면서 **링크 상태 프로토콜이 거리 벡터를 대체로 구식으로 만들었다.**

## 요약

- 라우팅 프로토콜은 라우터끼리 정보를 나눠 라우팅 테이블을 최신으로 유지한다.
- 자율 시스템 내부는 내부 게이트웨이 프로토콜, 시스템 간은 외부 게이트웨이 프로토콜.
- 거리 벡터는 이웃에게 거리 목록을 보내는 단순한 방식이지만 시야가 좁다.
- 링크 상태는 모든 라우터가 전체 지도를 갖고 알고리즘으로 최적 경로를 계산하며, 자원을 더 쓰는 대신 지금은 사실상 표준이다.
