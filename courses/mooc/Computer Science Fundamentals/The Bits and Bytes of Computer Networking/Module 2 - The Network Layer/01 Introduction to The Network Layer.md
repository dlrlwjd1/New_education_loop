# Introduction to The Network Layer

## 개요

- 모듈 1이 **짧은 거리, 단일 네트워크 구간(LAN)** 안의 통신이었다면, 이 모듈은 **여러 네트워크를 가로질러 먼 거리를 통신하게 하는 기술**을 다룬다.

## 내용

### 이 모듈을 마치면 할 수 있는 것

- **IP 주소 체계(IP addressing scheme)** 와 **서브넷팅(subnetting)** 이 어떻게 동작하는지 설명할 수 있다.
- 서브넷을 설명하기 위해 **이진법으로 기본적인 계산**을 할 수 있다.
- **캡슐화(encapsulation)** 가 어떻게 이루어지는지, 그리고 **ARP** 같은 프로토콜이 네트워크의 서로 다른 계층을 어떻게 소통시키는지 보여 줄 수 있다.
- **라우팅, 라우팅 프로토콜, 인터넷이 동작하는 방식**의 기초를 이해하게 된다.

## 요약

- 이 모듈의 주제는 "여러 네트워크를 건너는 통신"이다.
- 핵심 키워드: IP 주소 체계, 서브넷팅, 이진 계산, 캡슐화, ARP, 라우팅.
