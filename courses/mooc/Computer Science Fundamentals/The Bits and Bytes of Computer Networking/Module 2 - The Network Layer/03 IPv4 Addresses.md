# IPv4 Addresses

## 개요

- IPv4 주소는 **32비트, 4개 옥텟, 점 십진 표기(dotted decimal notation)** 다.
- 핵심 개념 두 가지: **IP 주소는 하드웨어가 아니라 조직·회사에 큰 덩어리로 배분된다**는 것, 그리고 **IP 주소는 장치가 아니라 네트워크에 속한다**는 것.

## 내용

### 형식

- IP 주소는 **32비트 길이의 수**이며 **4개의 옥텟**으로 이루어지고, 각 옥텟은 보통 **십진수**로 표기한다.
- 8비트(옥텟 하나)는 **0부터 255까지의 십진수 전부**를 표현할 수 있다.
- 예: `12.34.56.78`은 유효한 IP 주소다. 반면 `123.456.789.100`은 **8비트로 표현할 수 없는 수**가 들어 있으므로 유효하지 않다.
- 이 형식을 **점 십진 표기(dotted decimal notation)** 라 한다.

### 계층적으로 배분된다

- IP 주소는 **하드웨어 벤더가 정하는 것이 아니라**, 여러 조직과 회사에 **큰 구간 단위로 배분**된다.
- 그래서 IP 주소는 물리 주소보다 **계층적이고, 관련 데이터를 저장하기도 쉽다.**
- 예: **IBM은 첫 옥텟이 9인 모든 IP를 소유**한다. 인터넷 라우터가 `9.0.0.1`로 갈 패킷을 어디로 보낼지 판단할 때, **IBM의 라우터 중 하나로 보내기만 하면 된다.** 나머지 배달 과정은 그 라우터가 처리한다.

### IP 주소는 네트워크의 것이다

- **IP 주소는 네트워크에 속하지, 그 네트워크에 붙은 장치에 속하지 않는다.**
- 노트북의 **MAC 주소는 어디서 쓰든 항상 같다.** 하지만 **IP 주소는 인터넷 카페에서와 집에서 서로 다르게 할당**된다.
- 인터넷 카페의 LAN과 집의 LAN이 **각자 노트북에 IP 주소를 나눠 주는 책임**을 진다.

### 동적 IP와 정적 IP

| 구분 | 설명 |
|---|---|
| **동적 IP (dynamic IP address)** | **DHCP(Dynamic Host Configuration Protocol)** 기술로 **자동 할당**되는 주소. 최신 네트워크에서는 새 장치를 연결하면 자동으로 받는다 |
| **정적 IP (static IP address)** | 노드에 **수동으로 설정**해야 하는 주소 |

- 대부분의 경우 **정적 IP는 서버와 네트워크 장비에**, **동적 IP는 클라이언트에** 배정된다. 물론 그렇지 않은 상황도 분명히 존재한다.

## 예시

```
유효:    12.34.56.78
무효:    123.456.789.100   ← 456, 789는 8비트(0~255)로 표현 불가

IBM 소유: 9.x.x.x  → 라우터는 "9로 시작하면 IBM 라우터로" 만 알면 된다
```

## 요약

- IPv4 = 32비트, 4옥텟, 각 옥텟 0~255, 점 십진 표기.
- 조직 단위로 큰 블록이 배분되므로 라우팅이 계층적으로 단순해진다.
- IP는 네트워크에 속한다. 같은 노트북도 장소가 바뀌면 IP가 바뀐다.
- DHCP로 받는 것이 동적 IP, 수동 설정이 정적 IP. 보통 서버·장비는 정적, 클라이언트는 동적.
