# Basics of NAT

## 개요

- **NAT(Network Address Translation)** 는 **정의된 표준이 아니라 기법(technique)** 이다. 운영체제와 벤더마다 구현 세부가 다르지만 **개념은 일정**하다.
- 하는 일: **하나의 IP 주소를 다른 IP 주소로 번역**한다.
- 핵심 보안 개념: **IP 마스커레이딩(IP masquerading)**, 그리고 **일대다(one-to-many) NAT**.

## 내용

### NAT이란

- 이름 그대로 **IP 주소를 번역**한다. 이유는 **보안 보호 장치부터 제한된 IPv4 공간 보존까지** 다양하다.
- 가장 기본적인 수준에서 NAT은, **게이트웨이(보통 라우터나 방화벽)가 나가는 IP 데이터그램의 출발지 IP를 재작성하되, 응답에 다시 써넣기 위해 원래 IP를 보관하는** 기술이다.

### 동작 예시

| 구성 | 값 |
|---|---|
| Network A | 10.1.1.0/24 |
| Network B | 192.168.1.0/24 |
| 라우터 | Network A 인터페이스 / Network B 인터페이스 |
| Computer 1 | Network A, **10.1.1.100** |
| Computer 2 | Network B, **192.168.1.100** (웹 서버) |

1. Computer 1이 Computer 2의 웹 서버와 통신하려고 모든 계층의 패킷을 만들어 **주 게이트웨이(두 네트워크 사이의 라우터)** 로 보낸다.
2. 이 라우터는 **나가는 패킷에 NAT을 수행하도록 설정**돼 있다.
3. 보통 라우터는 IP 데이터그램의 내용을 검사하고 **TTL을 1 줄이고 체크섬을 재계산한 뒤 네트워크 계층 데이터는 건드리지 않고** 전달한다.
4. 그런데 **NAT이 있으면 라우터가 출발지 IP 주소도 재작성**한다. 이 경우 **라우터의 Network B 쪽 IP(192.168.1.1)** 가 된다.
5. 데이터그램이 Computer 2에 도착하면 **Computer 1이 아니라 라우터에서 온 것처럼 보인다.**
6. Computer 2가 응답을 만들어 라우터로 보낸다.
7. 라우터는 **이 트래픽이 실제로는 Computer 1을 위한 것임을 알고 있으므로, 전달하기 전에 목적지 IP 필드를 재작성**한다.

### IP 마스커레이딩

- 이 예시에서 NAT이 한 일은 **Computer 2로부터 Computer 1의 IP를 숨긴 것**이다. 이를 **IP 마스커레이딩(IP masquerading)** 이라 한다.
- **중요한 보안 개념**이다. 가장 기본적인 원리: **내 컴퓨터의 IP 주소를 모르면 아무도 내 컴퓨터에 연결을 수립할 수 없다.**

### 일대다 NAT

- 이 방식으로 **Network A에 컴퓨터가 수백 대 있어도 그 IP들이 전부 라우터의 IP로 번역**될 수 있다.
- **바깥 세상에서 보면 Network A의 주소 공간 전체가 보호되고 보이지 않는다.**
- 이것을 **일대다(one-to-many) NAT**이라 하며, **오늘날 많은 LAN에서 사용된다.**

## 요약

- NAT은 표준이 아니라 기법이며 구현은 벤더마다 다르다.
- 나갈 때 출발지 IP를 게이트웨이 IP로 바꾸고, 돌아올 때 목적지 IP를 원래 내부 IP로 되돌린다.
- 결과적으로 내부 호스트의 IP가 외부에 숨겨진다(IP 마스커레이딩).
- 수백 대의 내부 호스트가 하나의 외부 IP를 공유하는 것이 일대다 NAT이며 오늘날 LAN의 표준 구성이다.
