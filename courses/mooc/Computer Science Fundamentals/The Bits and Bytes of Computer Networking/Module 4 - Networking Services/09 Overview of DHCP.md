# Overview of DHCP

## 개요

- **DHCP(Dynamic Host Configuration Protocol)** = 네트워크 호스트의 **설정 과정을 자동화하는 애플리케이션 계층 프로토콜**.
- 할당 방식 세 가지: **동적(dynamic) / 자동(automatic) / 고정(fixed) 할당**.

## 내용

### 왜 필요한가

현대 TCP/IP 네트워크의 모든 컴퓨터는 최소 네 가지를 설정해야 한다.

1. **IP 주소**
2. **로컬 네트워크의 서브넷 마스크**
3. **주 게이트웨이(primary gateway)**
4. **네임서버**

- 각각은 별것 아니지만 **수백 대에 설정해야 한다면 극도로 지루한 일**이 된다.
- 이 중 **서브넷 마스크·주 게이트웨이·DNS 서버 세 가지는 거의 모든 노드에서 동일**하다.
- 하지만 **IP 주소는 모든 노드마다 달라야 한다.** 여기서 까다로운 설정 작업이 생기고, **DHCP가 등장한다.**

### DHCP가 하는 일

- 컴퓨터가 네트워크에 연결될 때 **DHCP 서버에 질의해 네트워킹 설정 전체를 한 번에 받는다.**
- 많은 네트워크 장치를 설정하는 **관리 부담을 줄일 뿐 아니라**, **어느 머신에 어느 IP를 줄지 정해야 하는 문제**도 해결한다.

### 정적 IP가 필요한 곳 vs 아닌 곳

- 네트워크의 모든 컴퓨터는 통신을 위해 IP가 필요하지만, **널리 알려진 IP가 필요한 것은 극소수**다.
- **서버나 게이트웨이 라우터 같은 네트워크 장비에는 정적이고 알려진 IP가 중요**하다.
  - 네트워크의 장치들은 **게이트웨이의 IP를 항상 알아야** 한다.
  - **로컬 DNS 서버가 오작동하면**, 관리자는 여전히 **IP를 통해 이런 장치에 접속할 방법**이 필요하다. **DNS 서버에 정적 IP가 설정돼 있지 않으면 그 서버가 고장 났을 때 접속해 진단하기가 어렵다.**
- 반면 **데스크톱·노트북·휴대폰 같은 클라이언트 장치**는 **올바른 네트워크의 IP를 갖는 것만 중요**하고, **정확히 어떤 IP인지는 훨씬 덜 중요**하다.
- 그래서 클라이언트용으로 **IP 주소 범위(range)를 따로 떼어 두면**, 필요할 때 IP를 받을 수 있으면서도 **모든 노드와 그 IP 목록을 유지해야 하는 문제가 사라진다.**

### 세 가지 할당 방식

| 방식 | 동작 |
|---|---|
| **동적 할당 (dynamic allocation)** | **가장 흔하다.** 클라이언트용 IP 범위를 떼어 두고 요청 시 그중 하나를 발급. **연결할 때마다 IP가 거의 매번 달라질 수 있다** |
| **자동 할당 (automatic allocation)** | 범위를 떼어 두는 것은 같지만, **DHCP 서버가 과거에 어느 장치에 어느 IP를 줬는지 추적**해 **가능하면 같은 머신에 같은 IP**를 배정 |
| **고정 할당 (fixed allocation)** | **MAC 주소와 대응 IP의 목록을 수동으로 지정.** 요청이 오면 테이블에서 MAC을 찾아 그에 대응하는 IP를 배정 |

**고정 할당에서 MAC이 목록에 없으면**: 자동·동적 할당으로 **폴백**하거나, **IP 배정을 아예 거부**할 수 있다. 후자는 **DHCP 서버에 MAC 주소가 명시적으로 설정된 장치만 IP를 얻어 네트워크에서 통신할 수 있게 하는 보안 수단**으로 쓸 수 있다.

### IP 말고도 배포할 수 있다

- DHCP 디스커버리는 여기서 다룬 것 이상을 설정하는 데 쓸 수 있다.
- IP 주소·주 게이트웨이와 함께 **NTP 서버** 같은 것도 배포할 수 있다.
- **NTP = Network Time Protocol**, 네트워크의 모든 컴퓨터의 **시간을 동기화**하는 데 쓰인다.

## 요약

- 호스트 4종 설정(IP, 서브넷 마스크, 게이트웨이, 네임서버) 중 IP만 노드마다 달라야 해서 자동화가 필요하다.
- DHCP는 연결 시 설정 전체를 한 번에 내려 준다.
- 서버·네트워크 장비는 정적 IP, 클라이언트는 DHCP가 원칙이다. DNS 서버가 죽었을 때 진단하려면 정적 IP가 필요하다.
- 동적/자동/고정 세 가지 할당 방식이 있으며, 고정 할당은 MAC 화이트리스트로 보안 수단이 될 수 있다.
- NTP 서버 등 다른 설정도 DHCP로 배포할 수 있다.
