# Anatomy of a Domain Name

## 개요

- 도메인 이름은 **세 부분**으로 나뉜다: **서브도메인 . 도메인 . TLD**.
- 전부 합친 것이 **FQDN(fully qualified domain name)** 이다.
- **길이 제한**: 각 구간 **63자**, FQDN 전체 **255자**, 이론상 **최대 127단계**.

## 내용

### 세 부분 — `www.google.com`

각 부분은 마침표로 구분된다: **`www`**, **`google`**, **`com`**.

### 1. TLD (Top-Level Domain) — `com`

- 도메인 이름의 **마지막 부분**.
- **정의된 TLD의 수는 제한**되어 있지만 **최근 몇 년 사이 많이 늘었다.**
- 가장 흔한 것: **`.com`, `.net`, `.edu`** 등.
- **국가별 TLD**도 있다: 독일은 **`.de`**, 중국은 **`.cn`**.
- 인터넷 성장으로 원래 정의된 TLD들이 매우 붐비게 되어, 오늘날에는 **`.museum`부터 `.pizza`까지 다양한 배니티(vanity) TLD**를 쓸 수 있다.
- **TLD의 관리와 정의는 ICANN**(Internet Corporation for Assigned Names and Numbers)이라는 비영리 조직이 담당한다.
- **ICANN은 IANA의 자매 조직**이며, 둘이 함께 **전역 IP 공간과 전역 DNS 시스템을 정의하고 통제**한다.

### 2. 도메인 (Domain) — `google`

- 도메인 이름의 **두 번째 부분**을 흔히 도메인이라 부른다.
- **TLD 네임서버에서 권한 네임서버로 통제가 넘어가는 지점을 구획**하는 데 쓰인다.
- 보통 **독립적인 조직, 즉 ICANN 외부의 누군가가 통제**한다.
- **개인이나 회사 누구나 등록하고 선택할 수 있지만, 반드시 미리 정의된 TLD 중 하나로 끝나야** 한다.

### 3. 서브도메인 (Subdomain) — `www`

- **서브도메인**이라 하며, **호스트 하나에만 배정된 경우 호스트 이름(host name)** 이라 부르기도 한다.

### FQDN과 등록

- 이 부분들을 모두 합치면 **FQDN(fully qualified domain name)** 이 된다.
- **도메인을 레지스트라(registrar)에 공식 등록하는 데는 돈이 들지만**, **서브도메인은 그 등록된 도메인을 통제하는 사람이 자유롭게 고르고 배정**할 수 있다.
- **레지스트라(registrar)** = **ICANN과 계약을 맺고 미등록 도메인 이름을 판매하는 회사**.

### 길이와 깊이 제한

- 기술적으로 **서브도메인은 여러 개** 둘 수 있다. 예: `host.subsubdomain.domain.com`도 완전히 유효하다. 다만 **그렇게 여러 단계인 FQDN은 드물게 보인다.**
- **DNS는 하나의 FQDN에 대해 기술적으로 최대 127단계의 도메인**을 지원한다.
- **각 개별 구간은 63자까지**, **완전한 FQDN은 총 255자까지**로 제한된다.

## 예시

```
www   .   google   .   com
└─┬─┘     └──┬──┘     └─┬┘
서브도메인   도메인      TLD
(호스트명)  (조직 통제)  (ICANN 관리)

└──────── FQDN ────────┘

제한: 각 구간 63자 · FQDN 전체 255자 · 최대 127단계
```

## 요약

- 도메인 이름 = 서브도메인 + 도메인 + TLD이며, 합치면 FQDN이다.
- TLD는 ICANN이 관리하고, 도메인은 레지스트라를 통해 누구나 등록할 수 있다.
- 도메인은 TLD 네임서버에서 권한 네임서버로 통제가 넘어가는 경계다.
- 서브도메인은 도메인 소유자가 무료로 마음대로 만들 수 있다.
- 구간당 63자, 전체 255자, 최대 127단계 제한이 있다.
