# Wireless Security

## 개요

- 유선에는 **어느 정도 본질적인 프라이버시**가 있지만, 무선은 **범위 안의 누구나 전송을 가로챌 수 있다.**
- 그래서 암호화가 필요하다: **WEP → WPA → WPA2** 순으로 키 길이가 늘어났다.
- 추가 장벽: **MAC 필터링**.

## 내용

### 무선의 근본 문제

- 유선 링크로 데이터를 보낼 때 **실제로 어떤 데이터가 오가는지 아는 것은 링크 양 끝의 두 노드뿐**이다. 가까이 있다고 해서 데이터를 그냥 읽을 수는 없다.
- **무선은 다르다.** 케이블 없이 **공중으로 방송되는 전파**뿐이므로, **범위 안의 누구든 자신을 향한 것이든 아니든 어떤 전송이라도 가로챌 수 있다.**

### WEP

- 이 문제를 풀기 위해 발명된 것이 **WEP(Wired Equivalent Privacy)** 이며, **아주 낮은 수준의 프라이버시만 제공하는 암호화 기술**이다.
- **이름에 이미 답이 있다.** WEP을 쓰면 데이터가 조금 보호되지만, **유선 연결로 암호화되지 않은 데이터를 보내는 것과 같은 정도로만 안전하다**고 봐야 한다.
- **매우 약한 암호화 알고리즘**이라 악의적 행위자가 **뚫고 데이터를 읽는 데 오래 걸리지 않는다.**
- **암호화 키의 비트 수가 안전성에 대응**한다. **비트가 많을수록 깨는 데 오래 걸린다.**
- **WEP은 40비트 키만** 사용하며, 현대 컴퓨터 속도로는 **보통 몇 분 만에 뚫린다.**

### WPA와 WPA2

| 방식 | 키 길이 | 비고 |
|---|---|---|
| **WEP** | **40비트** | 몇 분이면 깨진다 |
| **WPA** (Wi-Fi Protected Access) | **기본 128비트** | WEP보다 훨씬 깨기 어렵다. 대부분의 곳에서 WEP을 빠르게 대체 |
| **WPA2** | **256비트** | **오늘날 무선 네트워크에서 가장 흔히 쓰이는 암호화 알고리즘**. 원래 WPA의 업데이트 |

### MAC 필터링

- 무선 네트워크를 안전하게 하는 또 하나의 흔한 방법이다.
- **액세스 포인트가 신뢰하는 장치들의 특정 MAC 주소 집합에서 오는 연결만 허용**하도록 설정한다.
- **공중으로 오가는 무선 트래픽의 암호화에는 아무 기여도 하지 않지만**, **인가되지 않은 장치가 무선 네트워크 자체에 연결하는 것을 막는 추가 장벽**이 된다.

## 요약

- 무선은 전파를 방송하므로 범위 안의 누구나 도청할 수 있다.
- WEP은 40비트로 사실상 무방비이며, WPA는 128비트, WPA2는 256비트다.
- 오늘날 표준은 WPA2다.
- MAC 필터링은 암호화가 아니라 접속 허용 목록이며 보조 장벽으로 쓴다.
