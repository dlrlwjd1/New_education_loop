# Introduction to Wireless Networking Technologies

## 개요

- 무선 네트워킹은 **IEEE 802.11 표준군**으로 정의되며, 이것이 우리가 **Wi-Fi**라 부르는 기술 묶음이다.
- 802.11은 네트워킹 모델에서 **물리 계층과 데이터 링크 계층 양쪽을 정의**한다.
- 802.11 프레임에는 **주소 필드가 4개**나 있다.

## 내용

### 802.11과 주파수 대역

- 무선 네트워킹 장치는 **전파(radio wave)** 로 통신한다.
- 서로 다른 802.11 표준은 대체로 **같은 기본 프로토콜**을 쓰지만 **다른 주파수 대역(frequency band)** 에서 동작할 수 있다.

> **주파수 대역(frequency band)** = **특정 통신용으로 쓰기로 합의된 전파 스펙트럼의 한 구간**.

- 예: 북미의 FM 라디오는 **88~108 MHz**에서 동작하며 이 대역을 **FM broadcast band**라 한다.
- **Wi-Fi는 주로 2.4 GHz와 5 GHz 대역**에서 동작한다.

### 주요 802.11 규격

**802.11b → 802.11a → 802.11g → 802.11n → 802.11ac** (채택된 순서)

- 새 버전마다 대체로 개선이 있었다 — **더 높은 접속 속도**, 또는 **더 많은 장치가 동시에 네트워크를 쓸 수 있는 능력**.

### 802.11 프레임 구조

| 필드 | 크기 | 설명 |
|---|---|---|
| **Frame Control** | 16비트 | **프레임 자체를 어떻게 처리해야 하는지** 서술하는 여러 하위 필드. 어떤 802.11 버전이 쓰였는지 등을 포함 |
| **Duration** | — | **전체 프레임의 길이**를 지정. 수신 측이 **얼마나 오래 전송을 들어야 하는지** 알 수 있게 함 |
| **주소 필드 4개** | 각 6바이트 | 아래 참조 (모두 MAC 주소) |
| **Sequence Control** | 16비트 | 세 번째와 네 번째 주소 필드 사이에 위치. 주로 **프레임 순서를 추적하는 시퀀스 번호** |
| **Data Payload** | — | 스택 상위 프로토콜의 모든 데이터 |
| **Frame Check Sequence** | — | **CRC용 체크섬**. 이더넷과 동일한 방식 |

### 왜 주소 필드가 4개인가

- 가장 흔한 구성에는 **액세스 포인트(access point)** 라는 장치가 있다.

> **무선 액세스 포인트** = 네트워크의 **무선 부분과 유선 부분을 잇는(bridge)** 장치.

- 하나의 무선 네트워크가 **넓은 영역을 덮기 위해 여러 액세스 포인트**를 둘 수 있다.
- 무선 네트워크의 장치는 **특정 액세스 포인트와 연결(associate)** 된다. 보통 **물리적으로 가장 가까운 것**이지만, **전체 신호 강도나 무선 간섭** 같은 여러 요인으로 정해지기도 한다.
- 연결(association)은 무선 장치가 특정 AP와 대화하기 위해서만 중요한 것이 아니라, **무선 장치로 들어오는 전송을 올바른 AP가 보내도록** 하는 데도 중요하다.
- **그래서 어느 AP가 이 프레임을 처리해야 하는지 표시할 자리가 필요해 주소가 4개**다.

| 주소 | 의미 |
|---|---|
| **Source address** | 보내는 장치의 MAC 주소 |
| **Destination address** | 네트워크상의 의도된 목적지 |
| **Receiver address** | **프레임을 받아야 하는 액세스 포인트의 MAC 주소** |
| **Transmitter address** | **방금 프레임을 전송한 것의 MAC 주소** |

- 많은 경우 **destination과 receiver가 같고**, 보통 **source와 transmitter도 같다.**
- 다만 무선 네트워크를 어떻게 설계했느냐에 따라 **항상 그렇지는 않다.** **액세스 포인트들이 서로 프레임을 중계(relay)** 하기도 한다.

## 요약

- Wi-Fi = IEEE 802.11 표준군이며 물리·데이터 링크 두 계층을 정의한다.
- 주로 2.4GHz와 5GHz 대역을 쓰고, 규격은 b → a → g → n → ac 순으로 발전했다.
- 802.11 프레임은 Frame Control, Duration, 주소 4개, Sequence Control, 페이로드, FCS로 구성된다.
- AP를 거치는 구조 때문에 송신자/전송자, 목적지/수신자를 따로 적어야 해서 주소가 4개다.
