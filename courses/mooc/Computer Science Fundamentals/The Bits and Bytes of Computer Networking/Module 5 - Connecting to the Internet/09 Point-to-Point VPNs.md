# Point-to-Point VPNs

## 개요

- **점대점 VPN(point-to-point VPN)** = **사이트 간 VPN(site-to-site VPN)**. **두 사이트 사이에 VPN 터널을 수립**한다.
- WAN의 인기 있는 대안이며, **클라우드 이동** 덕분에 현실적인 선택지가 됐다.

## 내용

### WAN의 장단점

- WAN 기술은 **아주 빠르게 만들어졌기 때문에**, **많은 데이터를 여러 사이트에 걸쳐 옮겨야 할 때 훌륭하다.**
- **기업용 케이블이나 DSL 회선은 훨씬 저렴할 수 있지만**, 이런 상황에서 요구되는 부하를 감당하지 못한다.

### 클라우드가 바꾼 것

- 최근 몇 년간 기업들은 **내부 서비스를 점점 더 클라우드로 옮기고** 있다.
- **클라우드**는 기업이 **인프라의 전부 또는 일부를 다른 회사가 관리하도록 외주**할 수 있게 해 준다.

**이메일을 예로 보면:**

| 시대 | 방식 |
|---|---|
| 과거 | 이메일을 쓰려면 **자체 메일 서버를 직접 운영**해야 했다 |
| 지금 | **클라우드 호스팅 제공자가 메일 서버를 대신 호스팅**해 줄 수 있다 |
| 한 걸음 더 | **email-as-a-service 제공자**를 쓰면 **메일 서버 자체가 아예 없어진다.** 다른 회사에 비용을 내고 이메일 서비스의 모든 것을 맡긴다 |

- 이런 클라우드 솔루션이 자리 잡으면서 **많은 기업이 사이트 간 초고속 연결을 더 이상 필요로 하지 않게** 됐다. 그러면 **WAN 기술의 비용이 전혀 불필요**해진다.
- 대신 기업은 **점대점 VPN으로 서로 다른 사이트가 계속 통신**하게 할 수 있다.

### 동작

- **전통적인 VPN 설정이 개별 사용자가 접속 대상 네트워크에 있는 것처럼 동작하게 해 주는 것과 매우 비슷**하다.
- 다른 점은 **VPN 터널링 로직을 양쪽의 네트워크 장비가 처리**한다는 것이다. 그래서 **사용자들이 각자 연결을 수립할 필요가 없다.**

## 요약

- 점대점(사이트 간) VPN은 두 사이트의 네트워크 장비끼리 터널을 맺는다.
- WAN은 빠르지만 비싸고, 클라우드 이동으로 초고속 사이트 간 연결의 필요가 줄었다.
- 사용자는 아무것도 하지 않아도 되고 양쪽 장비가 터널을 유지한다.
