# Wide Area Network Technologies

## 개요

- **WAN(Wide Area Network)** = **하나의 네트워크처럼 동작하지만 여러 물리적 위치에 걸쳐 있는** 네트워크.
- 보통 **ISP와 계약해 인터넷을 가로지르는 링크**를 확보하며, **ISP가 사이트 간 데이터 전달을 처리**한다.
- 구성: **구획점(demarcation point) → 로컬 루프(local loop) → ISP 코어 네트워크**.

## 내용

### 이야기로 보는 배경

소기업의 유일한 IT 지원 담당자라고 하자.

1. 처음에는 **한 사무실에 직원 몇 명, 컴퓨터 몇 대**뿐이다.
   - 내부 IP로 **라우팅 불가 주소 공간**을 쓰기로 한다.
   - IP 주소는 희소하고 비싸므로 **라우터를 두고 NAT을 수행**하도록 설정한다.
   - 네트워크 설정을 쉽게 하려고 **로컬 DNS 서버와 DHCP 서버**를 둔다.
   - 사용자들이 웹에 접근하도록 **ISP와 계약해 사무실에 인터넷 링크**를 들인다.
2. 회사가 성장한다. 라우팅 불가 주소 공간을 쓰므로 **내부적으로 늘어날 여지는 충분**하다.
   - **출장 중인 영업 사원들**이 LAN의 자원에 접속해야 한다.
   - **VPN 서버**를 설정하고 **포트 포워딩으로 접근 가능**하게 만든다. 이제 전 세계 어디서든 직원이 사무실에 접속할 수 있다.
3. 사업이 잘돼 CEO가 **전국 반대편 도시에 새 사무실**을 열기로 한다.
   - 갑자기 원격 접속이 필요한 대상이 **영업 사원 몇 명이 아니라 두 번째 사무실 전체**가 된다.

**여기서 WAN 기술이 등장한다.**

### WAN이란

- **LAN(local area network)** 과 달리 **WAN은 wide area network**다.
- **하나의 네트워크처럼 동작하되 여러 물리적 위치에 걸쳐 있다.**
- WAN 기술은 보통 **ISP와 인터넷을 가로지르는 링크를 계약**해야 한다. **ISP가 한 사이트에서 다른 사이트로 데이터를 보내는 일을 처리**하므로, **모든 컴퓨터가 같은 물리적 위치에 있는 것처럼** 된다.

### 구성 요소

- 전국의 양쪽 끝에 각각 컴퓨터 네트워크가 있다고 하자.
- 각 네트워크는 **구획점(demarcation point)** 에서 끝나고, **거기서부터 ISP의 네트워크가 넘겨받는다.**
- **각 구획점과 ISP의 실제 코어 네트워크 사이 구간을 로컬 루프(local loop)** 라 한다.
- 로컬 루프는 **T-carrier 회선이나 제공자의 지역 사무소로 가는 고속 광 연결** 같은 것이다.
- 거기서 **ISP의 코어 네트워크와 인터넷 전반**으로 이어진다.

### 프로토콜

- WAN은 **데이터 링크 계층의 여러 프로토콜**을 사용해 한 사이트에서 다른 사이트로 데이터를 옮긴다.
- 사실 **이 프로토콜들이 인터넷의 코어에서 우리에게 익숙한 이더넷 대신 동작하기도** 한다.
- 이 프로토콜들의 세부는 **이 코스의 범위 밖**이다.

## 요약

- WAN은 여러 물리적 위치를 하나의 네트워크처럼 묶으며 ISP가 그 전달을 담당한다.
- 각 사이트는 구획점에서 끝나고, 구획점과 ISP 코어 사이가 로컬 루프다.
- 로컬 루프는 T-carrier나 고속 광 연결로 구성된다.
- WAN은 이더넷이 아닌 데이터 링크 계층 프로토콜들을 쓰며, 인터넷 코어에서도 쓰인다.
