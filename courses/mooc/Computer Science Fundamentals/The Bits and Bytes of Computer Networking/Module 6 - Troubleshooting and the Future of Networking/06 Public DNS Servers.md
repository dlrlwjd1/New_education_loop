# Public DNS Servers

## 개요

- **공개 DNS 서버(public DNS server)** = **누구나 무료로 쓸 수 있도록 설정된 네임서버**.
- 용도: **이름 해석 문제 진단**, **백업 DNS**, **아직 자체 네임서버가 준비되지 않은 신규 네트워크**.
- 대표: **Level 3의 `4.2.2.1`~`4.2.2.6`**, **Google의 `8.8.8.8`과 `8.8.4.4`**.

## 내용

### DNS 서비스 모델 세 가지

1. **ISP가 제공하는 재귀 네임서버** — 거의 항상 서비스의 일부로 제공되며, **대부분의 경우 인터넷의 다른 장치와 통신하는 데 이것만 있으면 충분**하다.
2. **자체 DNS 서버** — 대부분의 기업이 운영한다. **최소한 내부 호스트의 이름을 해석하기 위해** 필요하다. 컴퓨터를 `NAIS-laptop`이라 이름 짓거나 **프린터를 IP 대신 이름으로 부르려면 자체 네임서버가 필요**하다.
3. **DNS as a Service 제공자** — **점점 인기가 높아지고 있다.**

### 공개 DNS 서버가 유용한 경우

- 어떤 모델을 쓰든 **뭔가 잘못됐다고 의심될 때 DNS 기능을 테스트할 방법**이 있으면 유용하다.
- **자체 DNS에 문제가 생겼을 때의 백업 옵션**으로도 매우 유용하다.
- **새 네트워크를 구축하는 초기 단계**라, 결국 자체 네임서버를 둘 계획이더라도 **아직 준비되지 않았을 수** 있다.
- **어떤 사람들은 모든 해석을 그냥 이 네임서버들로 처리**하기도 한다.

### Level 3 — `4.2.2.1` ~ `4.2.2.6`

- 오랫동안 공개 DNS 서버는 **시스템 관리자들 사이에서 구전되던 지식**이었다.
- 여러 해 동안 **가장 흔히 쓰인 공개 DNS 서버는 세계 최대 ISP 중 하나인 Level 3 Communications**의 것이었다.
- Level 3는 워낙 커서 **최종 사용자를 직접 상대하기보다 다른 ISP에게 자기 네트워크 연결을 파는 방식**으로 주로 사업한다.
- 이 IP들은 **외우기 쉽지만 늘 약간의 미스터리에 싸여 있었다.** **거의 20년 동안 공개적으로 쓸 수 있었지만, Level 3가 공식적으로 인정하거나 광고한 적이 없는 서비스**다.

### Google — `8.8.8.8`, `8.8.4.4`

- **Level 3의 IP와 달리 Google이 공식적으로 인정하고 문서화**했으며 **누구나 무료로 쓸 수 있다.**

### 공통 특징과 주의

- **대부분의 공개 DNS 서버는 애니캐스트를 통해 전 세계에서 사용 가능**하다.
- 다른 많은 조직도 공개 DNS 서버를 제공하지만, **위 두 가지만큼 외우기 쉬운 것은 드물다.**

> **경고: 어떤 장치든 그런 네임서버를 쓰도록 설정하기 전에 반드시 조사할 것.**
> **나가는 DNS 요청을 가로채 잘못된 응답을 주는 것은 사용자를 악성 사이트로 리다이렉트하는 손쉬운 방법**이다.
> **네임서버가 평판 좋은 회사가 운영하는 것인지 반드시 확인**하고, **진단 상황이 아니라면 ISP가 제공하는 네임서버를 쓰려고** 해야 한다.

### 부수적 활용

- **대부분의 공개 DNS 서버는 ICMP echo request에도 응답**한다. 그래서 **ping으로 전반적인 인터넷 연결을 테스트하기에 좋은 대상**이다.

## 예시

```bash
# 인터넷 연결 자체를 확인
ping 8.8.8.8

# 이름 해석만 따로 확인 (다른 네임서버로 질의)
nslookup
> server 8.8.8.8
> twitter.com
```

| 제공자 | IP |
|---|---|
| Level 3 Communications | `4.2.2.1` ~ `4.2.2.6` (비공식) |
| Google | `8.8.8.8`, `8.8.4.4` (공식) |

## 요약

- 공개 DNS 서버는 누구나 무료로 쓸 수 있는 네임서버로, 진단·백업·초기 구축에 유용하다.
- Level 3의 4.2.2.x는 오래된 관행이지만 공식 인정된 적이 없고, Google의 8.8.8.8/8.8.4.4는 공식 문서화돼 있다.
- DNS 하이재킹 위험이 있으므로 평판을 확인해야 하고, 평소에는 ISP 네임서버를 쓴다.
- 대부분 ping에 응답하므로 인터넷 연결 확인 대상으로도 좋다.
