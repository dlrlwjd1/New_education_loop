# Using Big-O

## 개요
- 빅오(Big-O) 식을 다루는 실용적인 규칙, 실제 알고리즘의 실행 시간을 빅오로 계산하는 방법, 그리고 오메가(Ω)·세타(Θ)·리틀오(o) 같은 관련 표기법을 다룬다.

## 내용
### 빅오 식을 단순화하는 규칙
1. **곱셈 상수(multiplicative constant)는 생략 가능**: 7n³은 O(n³), n²/3은 O(n²).
2. **거듭제곱(power)이 클수록 더 빨리 증가**: n은 O(n²)보다 점근적으로 느리다. √n은 O(n)이다.
3. **다항식(polynomial)보다 지수함수(exponential)가 항상 더 빨리 증가**: n⁵ = O(√2^n), n^100 = O(1.1^n).
   - n^100이 끔찍한 실행 시간처럼 보이고 1.1^n이 온건해 보이지만, n이 충분히 커지면(대략 10만 이상) 결국 1.1^n이 n^100을 확실히 앞지른다.
4. **log n의 거듭제곱은 n의 거듭제곱보다 항상 느리게 증가**: (log n)³은 O(√n), n log n은 O(n²).
5. **합(sum)에서 더 작은 차수의 항은 생략 가능**: n²+n은 O(n²) (n이 더 느리게 증가), 2^n + n^9은 O(2^n) (n^9이 더 느리게 증가).

### 빅오로 실행 시간 계산하기 (피보나치 배열 알고리즘 예시)
- 배열 생성 후 모든 셀을 0으로 초기화: 셀마다 상수 시간 작업(쓰기, 비교, 증가)이 필요하고 셀이 n+1개이므로 O(n).
- 0번째, 1번째 원소 대입: 각각 O(1).
- for 루프 자체: n-1번 반복이므로 O(n)번 실행.
- 루프 내부의 덧셈: 배열 조회·저장은 O(1)이지만, 피보나치 수는 매우 커서(약 n/5자리) 기계어(machine word)에 들어가지 않으므로, 큰 수의 덧셈은 자릿수에 비례한 시간이 걸려 O(n).
- 반환(return): 포인터 연산, 배열 조회, 스택 팝 등으로 O(1).
- 전체 합산: O(n) + O(1) + O(1) + [루프 O(n)번 × 루프 내부 O(n)] + O(1) → 지배적인 항은 O(n)×O(n) = O(n²).
- 따라서 이 알고리즘의 실행 시간은 O(n²)이며, 대략 1초 안에 처리 가능한 입력 크기는(정확한 상수는 몰라도) 약 3만(30,000) 정도로 추정할 수 있다(컴퓨터·컴파일러에 따라 1000에서 100만 사이일 수 있음).

### 오메가, 세타, 리틀오 표기법
- **Big-Ω (오메가)**: f(n)이 g(n)의 상수 배 이상으로 아래에서 제한(bounded below)됨. 즉 어떤 상수 c에 대해 충분히 큰 모든 n에서 f(n) ≥ c·g(n).
- **Big-Θ (세타)**: f(n)이 O(g(n))이면서 동시에 Ω(g(n))인 경우. 상수 배까지 고려했을 때 f와 g가 같은 속도로 증가함을 의미.
- **little-o (리틀오)**: f(n)이 g(n)보다 엄격히 느리게 증가함. f(n)/g(n)의 비율이 n → ∞일 때 0으로 수렴한다는 의미이며, 상한 상수를 원하는 만큼 작게 만들 수 있다.
- 이 강의에서는 실행 시간의 상한을 보이는 것이 주된 목적이므로 빅오가 가장 많이 쓰이지만, 나머지 표기법도 유용하게 쓰일 수 있다.

## 예시
- 규칙 예시: 7n³ = O(n³), n = O(n²), √n = O(n), n⁵ = O(√2^n), n^100 = O(1.1^n), (log n)³ = O(√n), n log n = O(n²), n²+n = O(n²), 2^n+n⁹ = O(2^n)
- 피보나치 배열 알고리즘의 실행 시간: O(n²) (1초 내 처리 가능 입력 크기 추정치: 약 30,000)
- 표기법 요약: f=O(g) (위로 제한), f=Ω(g) (아래로 제한), f=Θ(g) (O이면서 Ω), f=o(g) (g보다 엄격히 느림, f(n)/g(n)→0)

## 요약
- 빅오 식은 상수 배 생략, 더 큰 차수/지수함수가 우세, log의 거듭제곱은 항상 다항식보다 느림, 합에서 더 작은 항 생략 등의 규칙으로 단순화할 수 있다.
- 실제 알고리즘의 실행 시간은 각 줄(연산)별로 빅오를 구한 뒤 더해서 지배적인 항만 남기는 방식으로 계산한다(예: 피보나치 배열 알고리즘 → O(n²)).
- Ω(하한), Θ(같은 크기), little-o(엄격한 하한/상한의 반대 개념) 등 관련 표기법도 존재하지만, 실행 시간의 상한을 다루는 빅오가 가장 널리 쓰인다.
