# Problem Overview and Naive Algorithm

## 개요
- 최대공약수(greatest common divisor, GCD) 문제를 정의하고, 모든 후보를 검사하는 비효율적인 나이브 알고리즘(naive algorithm)을 제시한다.

## 내용
### GCD의 정의와 동기
- 분수 a/b를 기약분수(simplest form)로 만들려면 분자와 분모를 같은 수 d로 나눠야 한다.
- 이때 d는 (1) a와 b를 모두 나누어야 하고, (2) 분수를 최대한 약분할 수 있도록 가능한 한 커야 한다.
- 정의: 두 정수 a, b의 최대공약수(GCD)는 a와 b를 모두 나누는 가장 큰 정수 d이다.

### GCD의 중요성
- GCD는 분수를 약분하는 데 쓰일 뿐 아니라, 소수(prime number)와 인수분해(factorization)를 다루는 정수론(number theory)에서 핵심 개념이다.
- 정수론이 암호학(cryptography)에서 중요하게 쓰이기 때문에, 온라인 뱅킹 등에서 안전한 암호화 알고리즘이 동작하는 것은 부분적으로 GCD를 효율적으로 계산할 수 있다는 사실에 기반한다.

### 풀어야 할 문제
- 0 이상인 두 정수 a, b가 주어졌을 때 GCD(a, b)를 계산하는 알고리즘이 필요하다.
- 5와 12, 11과 73처럼 작은 수뿐 아니라 3,918,848과 1,653,264 같은 큰 수, 나아가 20, 50, 100, 1000자리 숫자에 대해서도 GCD를 빠르게 계산할 수 있어야 한다.

### 나이브 알고리즘
- 변수 best를 0으로 초기화한다.
- d를 1부터 a+b까지 증가시키면서, d가 a와 b를 모두 나누면 best를 d로 갱신한다(d가 증가하는 순서이므로 항상 새로운 최댓값이 된다).
- 마지막에 best를 반환한다.
- 이 알고리즘은 정확하게 동작하지만, for 루프를 a+b번 반복해야 하므로 느리다.
- a와 b가 20자리 숫자 정도만 되어도 이미 실행에 수천 년이 걸릴 수 있어, 실용적으로 사용할 수 없다.

## 예시
- GCD 예시: 3,918,848과 1,653,264의 최대공약수를 구하는 문제(다음 강의에서 유클리드 알고리즘으로 해결)
- 나이브 알고리즘 의사코드:
  - best = 0
  - for d = 1 to a+b: if d divides a and d divides b: best = d
  - return best

## 요약
- GCD는 a, b를 모두 나누는 가장 큰 정수이며, 분수 약분과 암호학에서 중요하게 쓰인다.
- 모든 후보 d를 1부터 a+b까지 검사하는 나이브 알고리즘은 정확하지만 큰 수(20자리 이상)에서는 실용적으로 너무 느리다.
