# Queue of Patients

## 개요
- 병원 대기실에 동시에 도착한 환자들을 어떤 순서로 진료해야 전체 대기 시간(total waiting time)이 최소가 되는지를 구하는 문제(Queue of Patients)를 다룬다.
- 탐욕적 선택(greedy choice), 부분 문제(subproblem), 안전한 선택(safe choice) 개념을 정식으로 정의하고, "최소 진료 시간(minimum treatment time)을 가진 환자를 먼저 진료한다"는 선택이 안전한 선택임을 증명한다.

## 내용
### 문제 정의
- n명의 환자가 같은 시각(예: 오전 9시)에 병원에 도착했고, 어떤 순서로든 진료 가능하다.
- 환자 i의 진료 시간(treatment time)은 미리 알려진 값 tᵢ이다.
- 의사는 한 명이며 환자를 한 명씩 순서대로 진료한다. 지연 없이 계속 진료한다.
- 첫 번째 환자는 대기 시간이 없고, 두 번째 환자는 첫 번째 환자의 진료 시간만큼, 세 번째 환자는 첫 번째와 두 번째 환자의 진료 시간의 합만큼 대기한다.
- 목표: 모든 환자의 대기 시간의 총합(total waiting time)을 최소화하는 순서를 찾는 것.

### 수치 예시로 본 배열의 영향
- 환자 3명, 진료 시간: 환자1 = 15분, 환자2 = 20분, 환자3 = 10분
- 배열 1 (1, 2, 3 순서):
  - 환자1 대기 0분, 환자2 대기 15분, 환자3 대기 15+20=35분
  - 총 대기 시간 = 0 + 15 + 35 = **50분**
- 배열 2 (3, 1, 2 순서):
  - 환자3 대기 0분, 환자1 대기 10분(환자3의 진료 시간), 환자2 대기 10+15=25분
  - 총 대기 시간 = 0 + 10 + 25 = **35분**
- 35분 < 50분이므로 배열 2가 더 우수하다.

### 탐욕적 선택 후보와 안전한 선택
- 후보 전략:
  1. 진료 시간이 최대(maximum treatment time)인 환자를 먼저 진료
  2. 진료 시간이 최소(minimum treatment time)인 환자를 먼저 진료
  3. 평균 진료 시간(average treatment time)에 가장 가까운 환자를 먼저 진료
- 채택한 탐욕 전략: **진료 시간이 최소인 환자를 먼저 진료**한다. 이 환자를 대기열에서 제거한 뒤, 나머지 환자들을 같은 방식(탐욕적으로)으로 배열하는 부분 문제(subproblem)를 푼다.

### 부분 문제(subproblem)의 정의
- 예: 환자가 10명일 때 첫 번째로 진료할 환자를 정하고 나면, 남은 9명에 대해 총 대기 시간을 최소화하는 것은 크기만 작아진(9명) 동일한 종류의 문제다.
- Largest Number 문제와의 비교: 최댓값 숫자를 맨 앞에 놓고 나머지 숫자(1, 8, 9, 6)에 대해 같은 문제를 푸는 것과 동일한 구조다.
- 환자 대기열 문제에서는 최소 진료 시간 tmin을 가진 환자를 먼저 두면, 나머지 n-1명의 환자가 이 환자를 기다리는 시간 (n-1) × tmin이 확정되고, 이후 남은 환자들끼리의 대기 시간 최소화는 별도의 부분 문제가 된다.

### 안전한 선택(safe choice)의 정의
- 어떤 탐욕적 선택이 "안전한 선택(safe choice)"이라 불리려면, 그 선택과 일치하는(consistent with) 최적해(optimal solution)가 존재해야 한다.
- 즉, 최소 진료 시간 환자를 먼저 진료하는 것으로 시작하는 최적해가 존재함을 증명하면 그 선택은 안전한 선택이다.
- 반대로 최대 진료 시간 환자를 먼저 진료하는 선택은 그것으로 시작하는 최적해가 존재하지 않을 수 있으므로 안전한 선택이 아닐 수 있다.

### 안전한 선택 증명 (Lemma)
- **주장**: 최적의 배열(optimal arrangement)에는 연속한 두 환자의 진료 시간 t₁, t₂가 t₁ > t₂인 경우(큰 진료 시간을 가진 환자가 먼저, 작은 진료 시간을 가진 환자가 나중)가 존재할 수 없다.
- **증명 아이디어**: 만약 그런 최적 배열이 존재한다고 가정하고, 이 두 환자를 서로 교환(swap)했을 때 어떤 일이 벌어지는지 살펴본다.
  - 두 환자 이전의 환자들의 대기 시간은 변하지 않는다.
  - 두 환자 이후의 환자들의 대기 시간도 변하지 않는다.
  - 교환된 두 환자 자신의 대기 시간만 변한다: 원래 첫 번째였던 환자(이제 두 번째)는 t₂만큼 대기 시간이 늘어나고, 원래 두 번째였던 환자(이제 첫 번째)는 t₁만큼 대기 시간이 줄어든다.
  - 전체 대기 시간 변화량 = t₂ - t₁ < 0 (t₁ > t₂이므로 음수) → 전체 대기 시간이 감소한다.
  - 이는 원래 배열이 최적이라는 가정에 모순(contradiction)된다.
  - 따라서 최적 배열에서는 연속한 두 환자 중 앞선 환자의 진료 시간이 항상 더 작거나 같아야 한다.
- **결론**: 이 보조정리(lemma)를 이용해 "최소 진료 시간 환자가 최적 배열에서 반드시 첫 번째 위치에 온다"는 것을 증명한다.
  - 가정: 최적 배열에서 최소 진료 시간 tmin을 가진 환자가 첫 번째가 아니라고 하자.
  - i(> 1)를 tmin을 가진 환자가 처음 등장하는 위치라 하면, i-1 위치의 환자는 tmin보다 큰 진료 시간을 가진다(i가 tmin이 처음 나타나는 위치이므로).
  - 이는 앞서 증명한 보조정리(연속한 두 환자 중 앞이 항상 작거나 같아야 함)에 모순된다.
  - 따라서 가정이 틀렸으며, 최소 진료 시간 환자는 반드시 최적 배열의 첫 번째 위치에 있어야 한다.
- 결과적으로 "최소 진료 시간 환자를 먼저 진료한다"는 선택은 안전한 선택(safe choice)임이 증명된다.

### 최종 탐욕 알고리즘
1. 최소 진료 시간을 가진 환자를 먼저 진료한다.
2. 이 환자를 대기열에서 제거한다.
3. 남은 환자들에 대해 같은 방식(탐욕적으로)으로 총 대기 시간을 최소화하는 부분 문제를 푼다.

## 예시
- 3명 환자 예시(위 "수치 예시" 참고): 진료 시간이 [15, 20, 10]일 때 최소 진료 시간(10분, 환자3)을 먼저 배치하는 배열(3, 1, 2)의 총 대기 시간이 35분으로, (1, 2, 3) 순서의 50분보다 작다.

## 요약
- 환자 대기열 문제의 목표는 전체 대기 시간의 합을 최소화하는 진료 순서를 찾는 것이다.
- 안전한 선택(safe choice)은 "그 선택으로 시작하는 최적해가 존재함"을 의미한다.
- 이 문제의 안전한 선택은 **진료 시간이 가장 짧은 환자를 먼저 진료**하는 것이며, 교환 논증(exchange argument)을 통해 증명되었다.
- 안전한 선택 후에는 남은 환자들에 대한 동일한 형태의 부분 문제(subproblem)를 재귀적으로 풀면 된다.
