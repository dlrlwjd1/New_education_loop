# Celebration Party Problem

## 개요
- 파티에 모인 아이들을 나이 차이가 많이 나지 않도록 그룹으로 나누는 문제(Celebration Party Problem)를 소개한다.
- 이 문제를 모든 경우의 수를 시도하는 단순한 알고리즘(naive algorithm)으로 풀면 지수 시간(exponential time)이 걸려 비효율적임을 보인다.
- 다음 강의에서 탐욕 알고리즘으로 이를 크게 개선할 것을 예고한다.

## 내용
### 문제 정의
- 파티에 온 아이들을 그룹으로 나누되, **같은 그룹 안의 어떤 두 아이라도 나이 차이가 2살을 넘지 않도록(differ by at most two years of age)** 해야 한다.
- 목표: 그룹 수를 **최소화**하는 것(그룹마다 감독할 어른이 필요하므로 어른 수를 줄이기 위함).

### 단순 알고리즘(naive algorithm)
- 아이들을 하나 이상의 그룹으로 나누는 **모든 가능한 분배(distribution)**를 시도한다.
- 각 분배에 대해 모든 그룹에서 어떤 두 아이의 나이 차이도 2살을 넘지 않는지 확인(check)하고, 조건을 만족하면 유효한(valid) 분배로 간주한다.
- 유효한 분배들 중 그룹 수가 최소인 것을 반환한다.
- 이 알고리즘은 모든 가능한 분배를 고려하므로 정답은 찾아내지만, 실행 시간(running time)에 문제가 있다.

### 실행 시간 분석: 지수 시간
- **보조정리(lemma)**: 이 단순 알고리즘의 실행 시간은 최소 **2ⁿ**이다 (n은 아이의 수, Ω(2ⁿ)).
- 증명 아이디어: 이 알고리즘은 최소한 **아이들을 정확히 두 그룹으로 나누는 모든 경우**를 고려하게 된다.
  - 아이들을 두 그룹으로 나눌 때, 첫 번째 그룹은 아이들의 어떤 부분집합(subset)이든 될 수 있고 나머지는 두 번째 그룹이 된다.
  - n명의 아이들의 부분집합은 **2ⁿ**개 존재하므로, 두 그룹으로 나누는 분배 방법도 2ⁿ가지다.
  - 단순 알고리즘은 이 2ⁿ가지 분배를 모두 고려하므로 실행 시간은 최소 2ⁿ이며, 실제로는 이보다 더 많다(한 그룹, 세 그룹 이상으로 나누는 경우도 추가로 고려하므로).
- 결론: 단순 알고리즘의 실행 시간은 **Ω(2ⁿ)**, 즉 최소 지수 시간이다.

### 지수 시간의 비현실성
- 예를 들어 아이가 n = 50명이라면 최소 2⁵⁰번의 연산이 필요한데, 이는 매우 거대한 수치라 노트북으로는 결과를 기다릴 수 없는 수준이다.
- 이 때문에 더 나은(더 빠른) 방법이 필요하며, 다음 강의에서 탐욕 알고리즘으로 이를 크게 개선할 것이다.

## 요약
- Celebration Party Problem은 아이들을 나이 차이가 2살 이내인 그룹으로 최소 개수만큼 나누는 문제다.
- 모든 분배를 시도하는 단순 알고리즘은 정답을 찾지만, 실행 시간이 최소 **Ω(2ⁿ)**(지수 시간)로 매우 비효율적이다.
- n = 50 정도만 되어도 현실적으로 계산이 불가능하며, 이는 탐욕 알고리즘을 이용한 개선이 필요한 이유가 된다.
