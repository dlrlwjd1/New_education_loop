# Maximizing Loot

## 개요
- 도둑(burglar)이 용량이 제한된 배낭에 여러 향신료(spice)를 부분적으로(fraction) 담아 총 가치를 최대화하는 문제, 즉 **분수 배낭 문제(fractional knapsack problem)**를 다룬다.
- "무게당 가치(value per unit of weight)가 가장 큰 항목을 최대한 많이 담는다"는 선택이 안전한 선택(safe choice)임을 증명하고 탐욕 알고리즘을 제시한다.

## 내용
### 문제 정의
- 도둑이 침입한 상인의 집에는 여러 향신료가 있고, 배낭 용량은 15kg이다.
- 도둑은 각 향신료를 원하는 만큼(부분적으로도) 담을 수 있으며, 담은 향신료들의 총 무게가 배낭 용량을 넘지 않아야 한다.
- **형식적 정의(fractional knapsack)**: n개의 항목, 각각의 무게 W₁, …, Wₙ과 가치 V₁, …, Vₙ, 배낭 용량 W가 주어진다. 각 항목은 0에서 1 사이의 임의의 비율(fraction)로 담을 수 있으며(예: 1/3, 1/2, 0.4 등), 총 무게가 W를 넘지 않는 한도 내에서 총 가치를 최대화하는 것이 목표다.

### 수치 예시
- 항목 3개, 배낭 용량 9kg
  - 항목1: 가치 $30, 무게 5kg
  - 항목2: 가치 $28, 무게 4kg
  - 항목3: 가치 $24, 무게 3kg
- **방법 1**: 항목1 + 항목2 전체 → 무게 5+4=9kg(가득 참), 총 가치 = $30+$28 = **$58**
- **방법 2**: 항목1 + 항목3 전체 + 항목2의 1kg → 무게 5+3+1=9kg, 항목2는 4kg에 $28이므로 1kg당 $7 → 총 가치 = $30+$24+$7 = **$61**
- **방법 3(최적)**: 항목3 + 항목2 전체 + 항목1의 2kg → 항목1은 5kg에 $30이므로 1kg당 $6, 2kg이면 $12 → 총 가치 = $24+$28+$12 = **$64**

### 무게당 가치(value per unit of weight) 계산
- 항목1: $30 / 5kg = **$6/kg**
- 항목2: $28 / 4kg = **$7/kg**
- 항목3: $24 / 3kg = **$8/kg**
- 무게당 가치가 높은 항목부터 최대한 담는 것이 직관적으로 유리하다: 가장 무게당 가치가 높은 항목3을 전부, 그다음 항목2를 전부, 남은 용량은 무게당 가치가 가장 낮은 항목1로 채운다.

### 안전한 선택 증명(safe choice proof)
- **주장**: 무게당 가치가 최대인 항목을 최대한 많이 담는 것이 안전한 선택이다.
- **증명 방법**: 이 선택과 일치하는 최적해가 존재함을 보인다.
  - 어떤 최적해가 있다고 가정하되, 무게당 가치가 최대인 항목3을 최대한 담지 않았다고 가정한다(예: 항목1과 항목2를 전부 담은 해).
  - 항목1을 두 부분으로 나눈다: 항목3의 무게·가치에 해당하는 부분과 나머지.
  - 이 첫 부분(항목1의 일부)을 무게당 가치가 더 높은 항목3으로 대체(substitute)한다.
  - 대체 전: 이 3kg 분량에서 얻는 가치는 $6 × 3 = $18. 대체 후: 항목3의 가치인 $24를 얻는다. → 가치가 증가한다.
  - 나머지 6kg 분량은 그대로 유지한다.
  - 즉 항목1의 3/5을 제거하고 항목3(가장 무게당 가치가 높음) 3kg으로 교체함으로써 해를 개선(improve)했다.
  - 만약 최적해가 무게당 가치가 최대인 항목을 최대한 담지 않았다면, 이렇게 다른 항목의 일부를 그 항목으로 대체해 해를 개선할 수 있으므로 모순이다.
  - 따라서 무게당 가치가 최대인 항목을 최대한 담는 선택은 **안전한 선택**이다.

### 탐욕 알고리즘
- 배낭이 가득 찰 때까지 반복:
  1. 무게당 가치(Vᵢ / Wᵢ)가 최대인 항목 i를 선택한다.
  2. 이 항목 전체가 배낭에 들어갈 수 있으면 전부 담는다.
  3. 전부 들어가지 않으면, 배낭의 남은 용량을 채울 만큼만 담는다(이 시점에서 알고리즘 종료).
- 반복이 끝나면 담긴 항목들의 총 가치와 각 항목별로 담은 양(amount)을 반환한다.
- 이 알고리즘은 안전한 선택을 이용하므로 올바르게(correctly) 동작함이 보장된다.

## 예시
- 위 수치 예시에서: 무게당 가치 순위는 항목3($8/kg) > 항목2($7/kg) > 항목1($6/kg)이다.
- 탐욕 알고리즘 적용 결과: 항목3 전체(3kg, $24) + 항목2 전체(4kg, $28) + 항목1의 2kg($12) = 총 **$64**, 이것이 최적해다.

## 요약
- 분수 배낭 문제(fractional knapsack problem)의 목표는 무게 제한 내에서 항목들을 (부분적으로도) 담아 총 가치를 최대화하는 것이다.
- 안전한 선택은 **무게당 가치(value per unit of weight)가 가장 높은 항목을 최대한 담는 것**이며, 대체(substitution) 논증으로 증명되었다.
- 탐욕 알고리즘은 무게당 가치 순으로 항목을 하나씩 담다가, 항목이 다 들어가지 않으면 남은 용량만큼만 채우고 종료한다.
