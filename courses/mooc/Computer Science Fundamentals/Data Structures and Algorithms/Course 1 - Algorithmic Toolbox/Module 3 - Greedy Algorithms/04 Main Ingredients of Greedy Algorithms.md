# Main Ingredients of Greedy Algorithms

## 개요
- 지금까지 다룬 두 문제(Largest Number, Queue of Patients)를 바탕으로, 탐욕 알고리즘(greedy algorithm)을 구성하는 핵심 요소들을 정리한다.
- 탐욕 알고리즘의 일반적인 전략(general strategy)을 제시하고, 앞으로 이어질 강의들이 이 전략을 반복 적용해 다른 문제들을 풀 것임을 예고한다.

## 내용
### 핵심 아이디어: 부분 문제로의 축소(reduction)
- 탐욕 알고리즘을 적용하려면, 먼저 어떤 선택(choice)을 한 뒤 같은 종류이지만 더 작은 문제를 푼다.
- 예: 숫자가 하나 줄어들거나(Largest Number), 환자가 한 명 줄어드는(Queue of Patients) 식으로 문제 크기가 작아진다.
- 이렇게 작아진, 같은 종류의 문제를 **부분 문제(subproblem)**라고 부른다.

### 안전한 선택(safe choice)의 중요성
- 안전한 선택이란: 그 선택과 일치하는(consistent with) 최적해(optimal solution)가 존재하는 선택을 말한다.
- 모든 탐욕적 선택(greedy choice)이 안전한 것은 아니며, 오히려 안전하지 않은 경우가 흔하다.
- 따라서 탐욕 알고리즘으로 문제를 풀려면, 떠올린 탐욕적 선택이 실제로 안전한 선택임을 **증명**한 뒤에야 적용할 수 있다.

### 탐욕 알고리즘의 일반 전략(general strategy)
1. 어떤 탐욕적 선택(greedy choice)을 떠올린다.
2. 그 선택이 **안전한 선택(safe choice)**임을 증명한다.
3. 안전한 선택을 이용해 문제를 더 작은 **부분 문제(subproblem)**로 축소한다.
4. 부분 문제도 원래 문제와 같은 종류이므로, 같은 방식으로 다시 푼다.
- 이 과정(문제 → 안전한 선택 → 부분 문제 → 다시 문제)을 반복(loop)할 때마다 문제의 크기가 점점 줄어들고, 더 이상 풀 문제가 남지 않으면 종료된다.

## 요약
- 탐욕 알고리즘의 핵심 요소는 **부분 문제(subproblem)로의 축소**와 **안전한 선택(safe choice)**이다.
- 안전한 선택은 반드시 증명이 필요하며, 증명 없이 탐욕적 선택을 그대로 적용해서는 안 된다.
- 일반 전략: 탐욕적 선택 → 안전성 증명 → 부분 문제로 축소 → 반복.
