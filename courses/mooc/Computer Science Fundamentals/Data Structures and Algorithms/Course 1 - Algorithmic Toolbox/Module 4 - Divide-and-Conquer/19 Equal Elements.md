# Equal Elements

## 개요
- 앞선 실행 시간 분석은 배열의 모든 원소가 서로 다르다(pairwise different)는 가정 위에서 이루어졌는데, 이 강의에서는 같은 값(equal element)이 있을 때 발생하는 문제와 그 해법을 다룬다.
- 해법은 파티션을 두 부분이 아닌 세 부분으로 나누는 3-방향 파티션(three-way partition)이다.

## 내용

### 같은 원소가 있을 때 기존 분석이 깨지는 이유
- 기존 증명에서는 A′[i]와 A′[j] 사이에 있는 임의의 원소를 기준(pivot)으로 선택하면 두 원소가 서로 다른 파티션으로 갈라진다고 가정했다.
- 그러나 A′[i]와 A′[j]가 같은 값이라면, 그 사이의 모든 원소도 사실 같은 값이다. 이 경우 그 범위 안 어떤 원소를 기준으로 선택해도 모든 원소가 기준과 "같다"고 판정되어 한쪽(예: 왼쪽)으로 몰리게 되므로, i와 j가 갈라지지 않는다.
- 즉 같은 원소가 많은 배열에서는 기존의 확률 분석이 성립하지 않는다.

### 실제로 벌어지는 문제 — 시각화 관찰
- 원소의 종류가 몇 안 되는(few unique elements) 데이터셋에서 여러 정렬 알고리즘을 시각화로 비교하면, 다른 알고리즘들이 이미 정렬을 마쳤는데도 퀵 정렬은 가장 늦게 끝난다.
- 극단적인 예: 배열의 모든 원소가 서로 같다면, 파티션할 때마다 "기준보다 큰 원소" 부분은 항상 크기 0이고 "기준 이하" 부분은 항상 크기 n-1이 된다.
- 이 경우 점화식은 T(n) = T(n-1) + (선형 항) + T(0)이 되어, 이는 이미 앞서 본 "항상 불균형한 파티션" 사례에 해당하며 실행 시간이 이차(quadratic)가 된다.
- 즉 이미 정렬되어 있는(모든 원소가 같은) 배열을 정렬하는 데도 퀵 정렬이 이차 시간을 쓰게 되는 것이다.

### 해법: 3-방향 파티션(three-way partition)
- 배열을 "기준보다 작은 값", "기준과 같은 값", "기준보다 큰 값" 세 영역으로 나눈다.
- 형식적으로: 파티션 절차가 두 인덱스 m1, m2를 반환하며,
  - [l, m1-1] 영역: 기준 x보다 작은 원소들
  - [m1, m2] 영역: 기준 x와 같은 원소들
  - [m2+1, r] 영역: 기준 x보다 큰 원소들
- 이 절차는 기존 2-방향 파티션과 비슷하게, 하나의 스캔으로 여러 영역을 유지하며 구현하거나, 두 개의 카운터를 사용해 먼저 "≤x 대 >x"로 나눈 뒤 다시 그 안을 "<x 대 =x"로 나누는 방식으로 구현할 수 있다.

### 수정된 퀵 정렬(quick sort) 알고리즘
- 기존의 2-방향 `partition` 호출을 3-방향 파티션 호출로 대체한다.
- 가운데 영역(기준과 같은 값들)은 이미 최종 위치에 있으므로 이후 다시 건드리지 않는다.
- 왼쪽 영역과 오른쪽 영역에 대해서만 재귀 호출을 수행한다.
- 이렇게 수정한 결과, 원소 종류가 적은(few unique elements) 데이터셋에서도 시각화상 다른 알고리즘들과 비슷하게 빠르게 정렬이 끝나는 것을 확인할 수 있다.

## 예시
- 모든 원소가 같은 배열에서 기존 2-방향 파티션을 쓸 때의 점화식: T(n) = T(n-1) + O(n) + T(0) → Θ(n²)
- 3-방향 파티션의 결과 영역 구성:
  ```
  [l, m1-1]   : < x
  [m1, m2]    : = x   (이미 최종 위치, 재귀 호출 불필요)
  [m2+1, r]   : > x
  ```
- 수정된 퀵 정렬 의사코드(개념적):
  ```
  quickSort3Way(A, l, r):
      if l >= r: return
      (m1, m2) = partition3way(A, l, r)
      quickSort3Way(A, l, m1-1)
      quickSort3Way(A, m2+1, r)
  ```

## 요약
- 배열에 같은 값의 원소가 많으면, 두 원소 사이의 모든 원소가 기준으로 선택되어도 그 두 원소가 갈라지지 않으므로 기존의 O(n log n) 평균 분석이 깨지고, 최악의 경우 이차(quadratic) 시간이 걸릴 수 있다(예: 모든 원소가 같은 배열).
- 이를 해결하기 위해 배열을 "작음/같음/큼" 세 영역으로 나누는 3-방향 파티션(three-way partition)을 사용한다.
- 가운데(같음) 영역은 이미 최종 위치에 있으므로 재귀 호출에서 제외하며, 이렇게 수정한 퀵 정렬은 중복 원소가 많은 데이터셋에서도 효율적으로 동작한다.
