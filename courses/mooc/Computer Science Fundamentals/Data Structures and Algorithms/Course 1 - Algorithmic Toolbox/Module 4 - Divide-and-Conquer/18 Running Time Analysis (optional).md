# Running Time Analysis (optional)

## 개요
- 무작위(randomized) 퀵 정렬(quick sort)의 실행 시간에 대한 상한을 공식적으로(formally) 증명한다.
- 목표는 평균 실행 시간이 O(n log n)이고 최악의 경우 O(n²)임을 증명하는 것이며, 핵심은 "비교(comparison)의 총 횟수"를 추정하는 것이다.

## 내용

### 왜 비교 횟수를 세는가
- 퀵 정렬은 파티션(partition) 호출과 두 번의 재귀 호출로 구성되고, 각 재귀 호출은 다시 파티션 호출과 더 작은 재귀 호출들로 풀린다.
- 결국 퀵 정렬의 실질적인 작업은 여러 번의 파티션 호출이며, 파티션 절차 안에서 하는 일은 기준 원소(pivot)와 나머지 원소들을 비교하는 것이다.
- 따라서 비교 기반(comparison based) 알고리즘인 퀵 정렬의 실행 시간을 추정하려면 총 비교 횟수를 추정하면 된다.

### 균형 잡힌 파티션이 유리한 이유(직관)
- 크기 7인 배열에서 최솟값(1)을 기준으로 선택하면, 1이 최솟값이라는 사실만 알게 될 뿐 나머지 원소들 사이의 순서는 전혀 알 수 없다.
- 반대로 중간값 근처(4)를 기준으로 선택하면, 왼쪽 그룹(3,1,2)과 오른쪽 그룹(6,5,7) 사이의 비교는 전부 생략할 수 있다 — 이미 왼쪽은 모두 4 이하, 오른쪽은 모두 4보다 크다는 것을 알기 때문이다.
- 즉 균형 잡힌 파티션은 이후 단계에서 하지 않아도 되는 비교를 많이 만들어 낸다.

### 두 원소가 비교될 확률에 대한 직관
- 크기 9인 배열 (1~9)에서 원소 1과 9가 비교될 확률을 생각해 본다.
- 첫 기준 원소로 2,3,4,5,6,7,8 중 하나가 뽑히면 1과 9는 즉시 서로 다른 파티션으로 갈라져 다시는 비교되지 않는다(1<기준<9이면 1은 왼쪽, 9는 오른쪽으로 감).
- 반대로 첫 기준 원소로 1 또는 9 자신이 뽑히면, 기준 원소는 파티션 절차에서 배열의 모든 원소와 비교되므로 1과 9가 비교된다.
- 즉 9가지 선택 중 1과 9가 비교되는 경우는 2가지뿐이므로, 확률은 2/9이다.
- 반면 이웃한 원소인 3과 4의 경우, 이 둘 사이에 있는 다른 원소가 없으므로 둘 중 어느 것이 먼저 기준이 되든 상관없이 결국 두 원소는 반드시 비교된다 — 확률은 1이다.
- 결론: 두 원소가 비교될 확률은 정렬된 배열에서 그 둘이 얼마나 가까운지(close)에 따라 달라진다. 멀수록 확률이 낮고, 가까울수록(특히 이웃이면) 확률이 높다.

### 형식적 증명(formal proof)
- 정렬된 배열을 A′라 하고, 서로 다른 인덱스 i, j (1 ≤ i < j ≤ n)에 대해 확률 변수 Xᵢⱼ를 정의한다: A′[i]와 A′[j]가 비교되면 1, 아니면 0.
- 관찰 1: 두 원소는 많아야 한 번만 비교되거나 아예 비교되지 않는다. 두 원소가 비교되었다는 것은 그 시점에 둘 중 하나가 기준 원소였다는 뜻이고, 파티션 호출 직후 기준 원소는 최종 위치에 고정되어 이후 다시는 사용되지 않기 때문이다. (이로부터 최악의 경우 실행 시간이 이차임이 바로 도출된다: 가능한 쌍의 개수가 이차이고 각 쌍은 최대 한 번 비교되므로.)
- 관찰 2 (핵심): A′[i]와 A′[j]가 비교되는 것은, A′[i]부터 A′[j]까지의 부분 범위(subrange)에서 처음 선택되는 기준 원소가 정확히 A′[i] 또는 A′[j]일 때, 그리고 그때만이다.
  - 이 부분 범위 밖의 원소가 먼저 기준으로 선택되면, i와 j를 포함한 이 범위 전체는 함께 같은 쪽(왼쪽 또는 오른쪽)으로 이동하므로 아직 갈라지지 않는다.
  - 이 부분 범위 안에서 A′[i], A′[j]가 아닌 다른 원소가 먼저 기준으로 뽑히면, i와 j는 그 기준을 경계로 서로 다른 부분으로 갈라져 다시는 비교되지 않는다.
  - 이 부분 범위 안에서 처음 뽑히는 기준이 A′[i] 또는 A′[j] 자신이면, 그 기준은 파티션 과정에서 반드시 나머지 하나와 비교된다.
- 확률 계산: 부분 범위 [i, j] 안의 원소 개수는 (j - i + 1)개이고, 그중 원하는 원소(A′[i] 또는 A′[j])는 2개이므로, P(Xᵢⱼ = 1) = 2 / (j - i + 1).
  - 검증: j = i+1(이웃 원소)일 때 확률 = 2/2 = 1, 앞선 직관과 일치한다.
- 기댓값(expected value): 0/1 값만 갖는 확률 변수의 기댓값은 그 값이 1일 확률과 같으므로, E[Xᵢⱼ] = 2 / (j - i + 1).

### 총 비교 횟수의 기댓값 — 조화급수(harmonic series)
- 총 비교 횟수의 기댓값은 모든 (i, j) 쌍에 대한 E[Xᵢⱼ]의 합이다(기댓값의 선형성, linearity of expectation).
- E[총 비교 횟수] = Σᵢ Σⱼ>ᵢ 2 / (j - i + 1)
- 고정된 i에 대해 j를 i+1부터 n까지 움직이면, 안쪽 합은 1/2 + 1/3 + 1/4 + ... 형태의 조화급수(harmonic series)의 부분합이 되고, 이는 Θ(log n)으로 알려져 있다.
- 즉 고정된 i마다의 합이 최대 O(log n)이고, i는 1부터 n까지 n개이므로, 전체 기댓값은 O(n log n)이다.

## 예시
- P(Xᵢⱼ = 1) = 2 / (j - i + 1)
  - i, j가 이웃(j = i+1)이면 P = 1
  - 배열 크기 9에서 1과 9처럼 멀리 떨어진 경우(j - i + 1 = 9) P = 2/9
- 조화급수 부분합: 1/2 + 1/3 + ... + 1/n = Θ(log n)
- 전체 기댓값: E[비교 횟수] = Σᵢ O(log n) = O(n log n)

## 요약
- 퀵 정렬의 실행 시간은 총 비교 횟수로 환산해 분석할 수 있다.
- 두 원소 A′[i], A′[j]는 그 사이 부분 범위에서 처음 뽑히는 기준이 둘 중 하나일 때만 비교되며, 그 확률은 2/(j-i+1)이다.
- 기댓값의 선형성을 이용해 전체 비교 횟수의 기댓값을 구하면 조화급수의 합으로 귀결되어 O(n log n)이 된다.
- 임의의 두 원소는 최대 한 번만 비교되므로, 최악의 경우 실행 시간은 이차(quadratic), 즉 O(n²)이다.
