# Non-Comparison Based Sorting Algorithms

## 개요
- 원소들을 서로 비교(comparison)하지 않고도 정렬할 수 있는 경우가 있으며, 이런 경우 앞서 증명한 n log n 하한(lower bound)은 적용되지 않는다.
- 입력이 작은 정수(small integer)들로 이루어진 경우가 대표적이며, 이를 이용하는 계수 정렬(counting sort) 알고리즘을 다룬다.
- 계수 정렬의 실행 시간은 O(n + M)이며, M(정수의 최대 범위)이 n보다 빠르게 커지지 않으면 사실상 선형(linear) 시간이다.

## 내용

### 비교 없이 정렬한다는 것의 의미
- 입력 배열의 각 원소가 1부터 M까지의 정수라면, 각 정수가 몇 번 등장하는지 세는 것만으로 정렬된 결과를 만들 수 있다.
- 예: 크기 12인 배열이 1, 2, 3 세 종류의 숫자로만 이루어진 경우, 배열을 한 번 훑어(scanning) 각 숫자의 등장 횟수를 세면 그 정보만으로 정렬된 배열을 채울 수 있다.

### 계수 정렬(counting sort) 알고리즘
- 입력: 크기 n인 배열 A, 모든 원소는 1부터 M 사이의 정수.
- 1단계: 크기 M인 배열 `Count`를 0으로 초기화한다.
- 2단계: A를 왼쪽에서 오른쪽으로 한 번 훑으며, 원소 k를 만날 때마다 `Count[k]`를 1 증가시킨다. 이 루프가 끝나면 `Count[i]`는 값 i가 A에 등장한 총 횟수가 된다.
- 3단계: 결과 배열에서 각 값이 시작할 위치(starting point)를 계산하기 위해 배열 `Pos`를 만든다.
  - `Pos[1] = 1`
  - `Pos[j] = Pos[j-1] + Count[j-1]` (j ≥ 2)
- 4단계: 원본 배열 A를 다시 한 번 훑으며, 각 원소를 그에 해당하는 `Pos` 위치에 배치하고 배치할 때마다 해당 `Pos` 값을 1 증가시킨다.
- 참고: 단순히 1~M 정수를 채워 넣는 것이 아니라 원본 배열의 원소를 그대로 복사해 넣는 이유는, 실제로는 정수가 어떤 복잡한 객체(object)의 키(key)일 수 있어 원소들의 순열(permutation)을 구해야 하기 때문이다.

### 실행 시간(running time) 분석
- 세 개의 루프로 구성된다: 첫 번째(n번 반복), 두 번째(M번 반복), 세 번째(n번 반복).
- 따라서 전체 실행 시간은 O(n + M)이다.
- M이 n보다 빠르게 증가하지 않는다면(예: 원소가 1부터 n 사이의 정수이거나 상수로 상한이 정해진 경우), 실행 시간은 사실상 선형(linear in n)이 된다.

### 지금까지 배운 정렬 알고리즘 정리
- 병합 정렬(merge sort): 분할 정복(divide and conquer) 기반, 배열을 절반으로 나눠 재귀적으로 정렬한 뒤 병합. 실행 시간 O(n log n).
- 비교 기반(comparison based) 알고리즘의 하한: 어떤 비교 기반 알고리즘도 n log n보다 점근적으로 빠르게 정렬할 수 없다. 이는 n!개의 순열을 구분해야 하고, 최악의 경우 최소 Ω(n log n)번의 비교가 필요하기 때문이다.
- 계수 정렬(counting sort): 입력이 작은 정수라는 특별한 정보를 활용하면 n log n보다 빠르게, 경우에 따라 선형 시간에 정렬할 수 있다.

## 예시
- 배열 `[3, 2, 1, 2, 2, 2, 3, 2, 1, 2, 2, 2]`(크기 12, 값은 1~3)의 경우:
  - 1은 2번, 2는 7번, 3은 3번 등장한다.
  - 결과 배열 A'는 1을 2번, 2를 7번, 3을 3번 순서대로 채워 만든다.
- 계수 정렬 의사코드:
  ```
  countingSort(A[1..n], M):
      Count[1..M] = 0
      for i = 1 to n:
          Count[A[i]] += 1
      Pos[1] = 1
      for j = 2 to M:
          Pos[j] = Pos[j-1] + Count[j-1]
      for i = 1 to n:
          A'[Pos[A[i]]] = A[i]
          Pos[A[i]] += 1
      return A'
  ```

## 요약
- 입력이 작은 정수처럼 특별한 구조를 가지면 원소를 서로 비교하지 않고도 정렬할 수 있으며, 이 경우 n log n 하한이 적용되지 않는다.
- 계수 정렬(counting sort)은 각 값의 등장 횟수를 세고 그 누적 위치(Pos)를 계산해 정렬된 배열을 채우는 방식으로, 실행 시간은 O(n + M)이다.
- M이 n에 비례하거나 상수로 제한되면 계수 정렬은 선형 시간에 동작해, O(n log n)인 비교 기반 정렬보다 빠르다.
