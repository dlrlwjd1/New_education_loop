# Faster Divide and Conquer Algorithm

## 개요
- 1960년대 초 카라추바(Karatsuba)가 고안한, 다항식(및 큰 정수) 곱셈을 위한 더 빠른 분할 정복 알고리즘을 다룬다.
- 당시 콜모고로프(Kolmogorov, 카라추바의 지도교수)는 n²이 이론적 하한(lower bound)이라고 추측했으나, 대학원생이었던 카라추바가 일주일 만에 이를 깨는 방법을 찾아냈다.

## 내용

### 곱셈 횟수를 4번에서 3번으로 줄이는 아이디어
- 1차 다항식 A(x)=a₁x+a₀, B(x)=b₁x+b₀의 곱: C(x) = a₁b₁x² + (a₁b₀+a₀b₁)x + a₀b₀.
- 얼핏 보면 a₁b₁, a₁b₀, a₀b₁, a₀b₀ 4번의 곱셈이 필요해 보인다.
- 카라추바의 통찰: 중간 항 (a₁b₀+a₀b₁)을 (a₁+a₀)(b₁+b₀) − a₁b₁ − a₀b₀로 다시 쓸 수 있다.
  - (a₁+a₀)(b₁+b₀) = a₁b₁ + a₁b₀ + a₀b₁ + a₀b₀이므로, 여기서 a₁b₁과 a₀b₀을 빼면 정확히 a₁b₀+a₀b₁이 남는다.
- 결과적으로 필요한 곱셈은 a₁b₁, a₀b₀, (a₁+a₀)(b₁+b₀) 단 3번이며, 덧셈 몇 번이 추가로 필요할 뿐이다.

### 다항식 곱셈에의 적용과 실행 시간
- 이전과 같이 A, B를 상/하위 절반(D₁, D₀, E₁, E₀)으로 나눈다.
- D₁E₁, D₀E₀는 그대로 계산하되, D₁E₀ + D₀E₁ 대신 (D₁+D₀)(E₁+E₀) − D₁E₁ − D₀E₀를 계산한다. → 곱셈 3번(D₁E₁, D₀E₀, (D₁+D₀)(E₁+E₀)).
- 점화식: T(n) = 3T(n/2) + kn.
- 재귀 트리 분석:
  - 레벨 i에서 문제 개수는 3^i, 문제 크기는 n/2^i → 작업량 k·(3/2)^i·n.
  - 이는 등비수열(geometric series)이며 마지막 항이 지배적이므로, 합은 Θ(n^(log₂3)) = Θ(n^1.58...).
- 결론: n² → n^1.58로 실행 시간이 크게 개선된다. 하위 문제 수를 줄이는 것이 (레벨을 거듭할수록 문제 수가 지수적으로 곱해지므로) 최종 실행 시간에 큰 영향을 준다.

## 예시

A(x)=4x³+3x²+2x+1, B(x)=x³+2x²+3x+4인 경우:
- D₁=4x+3, D₀=2x+1, E₁=x+2, E₀=3x+4.
- D₁E₁ = 4x²+11x+6, D₀E₀ (별도 계산), (D₁+D₀)(E₁+E₀) = (6x+4)(4x+6) = 24x²+52x+24.
- 곱셈은 총 3번만 수행: D₁E₁, D₀E₀, (D₁+D₀)(E₁+E₀).
- 최종 결과 A(x)B(x) = D₁E₁·x⁴ + [(D₁+D₀)(E₁+E₀) − D₁E₁ − D₀E₀]·x² + D₀E₀ = 4x⁶+11x⁵+20x⁴+3x³+20x²+11x+4로, 순진한 방법과 동일한 결과를 얻는다.

실행 시간 비교:
- 4개 하위 문제 버전: T(n)=4T(n/2)+kn → Θ(n²)
- 3개 하위 문제 버전(카라추바): T(n)=3T(n/2)+kn → Θ(n^(log₂3)) ≈ Θ(n^1.58)

## 요약
- 카라추바 알고리즘은 (a₁+a₀)(b₁+b₀) 트릭으로 곱셈 횟수를 4번에서 3번으로 줄인다.
- 점화식 T(n) = 3T(n/2) + kn의 해는 Θ(n^(log₂3)) ≈ Θ(n^1.58)로, Θ(n²)보다 훨씬 빠르다.
- 하위 문제 개수를 줄이는 것이 분할 정복 알고리즘 성능 개선의 핵심 아이디어임을 보여주는 대표 사례다.
