# Problem Overview and Naïve Solution

## 개요
- 더 복잡한 분할 정복 문제인 다항식 곱셈(polynomial multiplication)을 다룬다. 이는 오류 정정 부호(error correcting code), 큰 정수 곱셈, 생성 함수(generating function), 합성곱(convolution) 등 컴퓨터 과학 여러 분야에서 쓰인다.
- 큰 자릿수의 정수를 곱할 때, 초등학교에서 배운 방식보다 다항식 곱셈 아이디어를 이용하면 더 빠르게 계산할 수 있다.

## 내용

### 다항식 곱셈이란
- 두 다항식을 곱해 새로운 다항식을 얻는 연산이다.
- 예: A(x) = 3x² + 2x + 5, B(x) = 5x² + x + 2를 곱하면 C(x) = 15x⁴ + 13x³ + 33x² + 9x + 10이 된다.

### 문제 정의
- 입력: 차수 n-1인 두 다항식 A, B. 계수는 A: a_(n-1), …, a_0 / B: b_(n-1), …, b_0.
- 두 다항식의 차수가 다르면, 낮은 차수 쪽의 앞쪽 계수를 0으로 채워(pad) 같은 길이로 맞춘다.
- 출력: 곱 다항식 C(x)로, 차수는 2n-2이다.
  - C의 각 계수 c_k는 인덱스 합이 k가 되는 (a_i, b_j) 쌍들의 곱을 모두 더한 값이다. 예: c_(2n-2) = a_(n-1)·b_(n-1) (한 쌍), c_(2n-3) = a_(n-1)·b_(n-2) + a_(n-2)·b_(n-1) (두 쌍) — 중간으로 갈수록 더해지는 쌍의 수가 늘었다가 다시 줄어든다.

### 순진한(naïve) 알고리즘
- 결과 배열(product)을 크기 2n-1(차수 0 ~ 2n-2)로 만들고 0으로 초기화한다.
- 이중 for문(i = 0..n-1, j = 0..n-1)을 돌며 A[i]·B[j]를 계산해 product[i+j]에 더한다.
- 예: i=0, j=0이면 A[0]·B[0]을 product[0]에 더함. i=n-1, j=n-1이면 A[n-1]·B[n-1]을 product[2n-2]에 저장.
- 실행 시간: 이중 루프가 각각 n번 도므로 O(n²).

## 예시

n=3인 경우 (A(x)=3x²+2x+5, B(x)=5x²+x+2):
- 계수만 표기: A=[3,2,5], B=[5,1,2] → 곱 결과 계수 [15, 13, 33, 9, 10] = 15x⁴+13x³+33x²+9x+10.

B가 차수 1(B(x)=x+2)일 경우, 앞쪽에 0을 채워 B=[0,1,2]로 맞춘 뒤 동일한 방식으로 계산한다.

## 요약
- 다항식 곱셈은 두 (n-1)차 다항식을 곱해 (2n-2)차 다항식을 만드는 문제다.
- 차수가 다른 두 다항식은 0으로 패딩(padding)해 길이를 맞춘다.
- 순진한 이중 루프 알고리즘의 실행 시간은 O(n²)이다.
- 다음 영상에서는 이를 분할 정복으로 접근하지만, 여전히 개선의 여지가 있는 "순진한" 분할 정복 버전을 먼저 살펴본다.
