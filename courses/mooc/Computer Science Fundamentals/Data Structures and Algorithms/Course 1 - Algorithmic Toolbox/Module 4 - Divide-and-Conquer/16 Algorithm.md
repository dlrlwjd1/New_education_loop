# Algorithm

## 개요
- 퀵 정렬(quick sort) 알고리즘의 전체 구조와, 그 핵심인 파티션(partition) 절차를 상세히 다룬다.
- 퀵 정렬은 재귀적(recursive)이며, 파티션 절차가 기준 원소(pivot)를 최종 위치에 놓고 배열을 두 부분으로 나눈 뒤, 양쪽에 재귀 호출을 적용하는 구조다.

## 내용

### 퀵 정렬(quick sort)의 전체 구조
- 배열 A와 인덱스 l(left), r(right)을 받아 부분 배열 A[l..r]을 정렬하는 재귀 절차다.
- l ≥ r이면 해당 부분 배열은 원소가 최대 1개이므로 아무 작업도 하지 않고 반환(return)한다.
- 그렇지 않으면 `partition(A, l, r)`을 호출해 인덱스 m을 얻는다. 이 호출 이후 A[m]은 최종 위치에 있으며, A[m]보다 왼쪽 원소들은 모두 A[m] 이하, 오른쪽 원소들은 모두 A[m]보다 크다.
- 이후 왼쪽 부분(A[l..m-1])과 오른쪽 부분(A[m+1..r])에 대해 각각 재귀 호출을 수행하면 배열 전체가 정렬된다.

### 파티션(partition) 절차의 아이디어
- 부분 배열의 첫 원소 A[l]을 x라 하고, 이를 기준(pivot)으로 삼는다. 목표는 x를 자신의 최종 위치에 놓고, x보다 왼쪽엔 x 이하, 오른쪽엔 x보다 큰 원소들만 남기는 것이다.
- 이를 위해 카운터 i를 l+1부터 r까지 증가시키며, 이미 살펴본 영역을 두 개의 하위 영역으로 유지하는 불변식(invariant)을 관리한다.
  - 영역 1 (l+1 ~ j): x 이하인 원소들
  - 영역 2 (j+1 ~ i): x보다 큰 원소들
- i를 한 칸씩 늘려가며 새로 발견한 원소 A[i]를 검사한다.
  - A[i]가 x보다 크면 아무 작업 없이 영역 2가 자연스럽게 확장된다.
  - A[i]가 x 이하이면 j를 1 증가시키고 A[j]와 A[i]를 교환(swap)하여 영역 1로 편입시킨다.
- i가 r에 도달하면 마지막으로 기준 원소(원래 A[l]에 있던 x)를 A[j]와 교환해 두 영역 사이 자신의 최종 위치에 놓고, j를 파티션 결과 인덱스로 반환한다.

## 예시
- 퀵 정렬 의사코드:
  ```
  quickSort(A, l, r):
      if l >= r: return
      m = partition(A, l, r)
      quickSort(A, l, m-1)
      quickSort(A, m+1, r)
  ```
- 파티션(partition) 의사코드:
  ```
  partition(A, l, r):
      x = A[l]
      j = l
      for i = l+1 to r:
          if A[i] <= x:
              j = j + 1
              swap(A[j], A[i])
      swap(A[l], A[j])
      return j
  ```
- 진행 예시: 기준 x = 6인 상태에서 진행 중 9(>6)를 만나면 영역 2만 확장, 4(≤6)를 만나면 j를 늘리고 4를 현재 영역 2의 첫 원소(9)와 교환, 7(>6)은 영역 2 확장, 6(=6, 이하 조건 포함)은 다시 교환해 영역 1로 편입. 마지막에 기준 6을 영역 1의 마지막 원소와 교환해 최종 위치를 확정한다.

## 요약
- 퀵 정렬(quick sort)은 파티션 절차로 기준 원소를 최종 위치에 놓고, 그보다 작은 부분과 큰 부분으로 나눈 뒤 양쪽에 재귀 호출을 적용하는 구조다.
- 파티션 절차는 카운터 i, j로 "x 이하 영역"과 "x보다 큰 영역"이라는 두 불변식을 유지하며 한 번의 스캔으로 배열을 재배열한다.
- 마지막에 기준 원소를 두 영역 경계로 교환함으로써 기준 원소가 자신의 최종 위치에 놓이게 된다.
