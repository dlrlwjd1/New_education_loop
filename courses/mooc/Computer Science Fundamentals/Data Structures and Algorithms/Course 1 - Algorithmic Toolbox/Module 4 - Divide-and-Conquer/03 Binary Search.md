# Binary Search

## 개요
- 정렬된 배열(sorted array)에서 값을 찾는 이진 탐색(binary search)을 다룬다. 사전(dictionary)처럼 정렬되어 있으면 훨씬 빠르게 탐색할 수 있다는 것이 핵심 동기다.
- 이진 탐색은 각 단계에서 절반의 원소를 버릴 수 있는, 하나의 하위 문제만 갖는 분할 정복 알고리즘이다.

## 내용

### 문제 정의
- 입력: 단조 비감소(monotonic non-decreasing) 순서로 정렬된 배열 A, 탐색 범위 low·high, 찾을 값 key.
  - "단조 비감소"라 부르는 이유는 중복 원소를 허용하기 위해 "증가"가 아니라 "감소하지 않음"이라고 표현하기 때문이다.
- 출력: A[i] = key인 어떤 인덱스 i.
  - key가 배열에 없을 경우, 단순히 NOT_FOUND를 반환하는 대신 더 유용한 정보를 반환한다: key보다 작은 원소 중 가장 큰 인덱스, 즉 "key를 삽입한다면 들어갈 위치의 바로 앞 인덱스".
  - 배열의 모든 원소가 key보다 크면 low - 1을 반환한다.

### 예시로 본 반환값
- 배열 (7개 원소, 20이 중복)에서 2를 찾으면 → 0 (모든 원소가 더 큼).
- 3을 찾으면 → 1, 4를 찾아도 → 1 (3과 5 사이를 의미).
- 20을 찾으면 → 4 또는 5 둘 다 유효 (20이 두 위치에 존재).
- 60을 찾으면 → 7, 70을 찾아도 → 7.

### 재귀적 이진 탐색 구현
- 기저 사례: high < low(빈 배열)이면 low - 1 반환.
- 중간점(mid) 계산: mid = low + floor((high - low) / 2).
- A[mid] = key이면 mid 반환.
- key < A[mid]이면 상위 절반은 버리고 low..mid-1 구간을 재귀 탐색.
- key > A[mid]이면 하위 절반은 버리고 mid+1..high 구간을 재귀 탐색.

### 분할 정복 관점에서의 정리
- 문제를 (거의) 절반 크기의 비겹침 하위 문제 하나로 나눈다.
- 그 하나의 하위 문제를 재귀적으로 해결한다.
- 결과를 결합하는 과정은 단순히 하위 문제의 결과를 그대로 반환하는 것이다.

## 예시

11개 원소의 배열에서 50을 찾는 과정:
1. low=1, high=11 → mid = 1 + floor((11-1)/2) = 6. A[6]=15 ≠ 50, 50 > 15이므로 low를 mid+1=7로 이동.
2. low=7, high=11 → mid = 7 + floor((11-7)/2) = 9. A[9]=20 ≠ 50, 50 > 20이므로 low를 mid+1=10로 이동.
3. low=10, high=11 → mid = 10 + floor((11-10)/2) = 10. A[10]=50 = 50 → 10 반환.

## 요약
- 이진 탐색은 정렬된 배열에서 중간 원소와 비교해 절반씩 탐색 범위를 줄여가는 분할 정복 알고리즘이다.
- 찾는 값이 없을 때는 NOT_FOUND 대신 "삽입 위치"에 해당하는 인덱스를 반환하도록 문제를 정의한다.
- 하나의 하위 문제(절반 크기)만 재귀적으로 풀고 그 결과를 그대로 반환하는 구조다.
