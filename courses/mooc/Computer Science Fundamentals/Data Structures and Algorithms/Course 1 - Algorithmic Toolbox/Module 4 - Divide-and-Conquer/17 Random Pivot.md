# Random Pivot

## 개요
- 퀵 정렬(quick sort)의 실행 시간(running time)을 분석하면서, 왜 기준 원소(pivot)를 무작위(random)로 선택해야 하는지를 설명한다.
- 파티션이 항상 균형 잡히면(balanced) O(n log n), 항상 매우 불균형(unbalanced)하면 O(n²)이 됨을 여러 병적인(pathological) 사례로 보인다.
- 결론적으로 무작위 기준 원소 선택은 평균적으로 O(n log n)의 실행 시간을 보장하는 실용적 해법이다.

## 내용

### 병적인 사례 1: 항상 최솟값을 기준으로 선택하는 경우
- 크기 n인 부분 배열에서 매번 최솟값을 기준(pivot)으로 선택하면, 파티션 후 왼쪽 부분은 비어 있고(크기 0) 오른쪽 부분은 크기 n-1이 된다.
- 이때 점화식은 T(n) = n + T(n-1) (n은 파티션 절차의 비용)이다.
- 이 점화식을 풀어 나가면 n + (n-1) + (n-2) + ... 형태의 등차수열(arithmetic series)이 되어 이차(quadratic) 시간이 걸린다.

### 병적인 사례 2: 항상 크게 불균형한 파티션(예: n-5 대 4)
- 한쪽이 항상 n-5, 다른 쪽이 4인 식으로 파티션되어도, 여전히 매우 불균형한 분할이다.
- T(n) = n + T(n-5)를 풀면 n + (n-5) + (n-10) + ... 형태가 되어, 공차만 다를 뿐 여전히 이차 시간이 걸린다(숨은 상수만 작아질 뿐 차수는 동일).

### 병적인 사례 3: 항상 균형 잡힌 파티션(예: n/2 대 n/2)
- T(n) = T(n/2) + O(n) 형태의 점화식이 되며, 이는 병합 정렬(merge sort)의 점화식과 동일하다.
- 재귀 트리(recursion tree)는 log n개의 레벨을 가지며 각 레벨에서 선형(linear) 시간이 소요되므로 전체 실행 시간은 O(n log n)이다.

### 병적인 사례 4: 적당히 불균형한 파티션(예: n/10 대 9n/10)
- T(n) = T(n/10) + T(9n/10) + O(n)
- 이 경우도 재귀 트리의 각 레벨에서 원소 크기의 합이 항상 n(또는 그 이하)이고, 트리의 높이는 log_{10} n(왼쪽 가지 기준)과 log_{10/9} n(오른쪽 가지 기준) 사이의 값으로 여전히 로그(logarithmic) 수준이다.
- 따라서 이 경우도 O(n log n)의 상한이 성립한다.

### 실행 시간이 파티션의 균형(balance)에 좌우된다는 결론
- 파티션이 항상 균형 잡히면 O(n log n), 항상 매우 불균형하면 O(n²)이라는 사실을 확인했다.
- 문제는 항상 균형 잡힌 파티션을 만들어 줄 기준 원소를 빠르게 미리 알아낼 방법이 없다는 것이다.

### 해법: 무작위(random) 기준 원소 선택
- 파티션 절차를 호출하기 전에, l과 r 사이의 임의의 인덱스를 무작위로 선택하고 A[l]과 그 원소를 교환한 뒤 평소처럼 파티션을 진행한다.
- 직관적 근거: 모든 원소가 서로 다르다고 가정할 때, 정렬된 버전의 배열에서 가운데 절반(n/2개)에 해당하는 원소들은 각각 자신보다 큰 원소가 최소 n/4개, 작은 원소가 최소 n/4개 존재한다.
- 즉 배열 내 어디에 있든, 이 n/2개 원소 중 하나를 기준으로 선택하면 파티션이 균형 잡히게(양쪽에 최소 n/4개씩) 된다.
- 무작위로 하나를 선택했을 때 이런 "좋은" 원소를 고를 확률은 최소 1/2이며, 이것으로 충분히 좋은 상한을 증명할 수 있다.

### 정리(theorem) — 다음 강의에서 증명 예정
- 배열의 모든 원소가 서로 다르다고 가정할 때, 무작위(randomized) 퀵 정렬의 평균 실행 시간은 O(n log n)이고, 최악의 경우(worst case) 실행 시간은 n²이다.
- "평균(average)"이란 임의의 고정된 배열에 대해서도 무작위 비트(random bits)들에 대한 평균을 취했을 때 실행 시간이 n log n이라는 뜻이며, 이는 모든 입력에 대해 성립한다.

## 예시
- 사례 1의 점화식: T(n) = n + T(n-1) → n + (n-1) + (n-2) + ... → 등차수열 합 → Θ(n²)
- 사례 2의 점화식: T(n) = n + T(n-5) → n + (n-5) + (n-10) + ... → Θ(n²) (공차만 다름)
- 사례 3의 점화식: T(n) = T(n/2) + O(n) → 재귀 트리 log n 레벨 × 레벨당 O(n) → O(n log n)
- 사례 4의 점화식: T(n) = T(n/10) + T(9n/10) + O(n) → 트리 높이가 로그 수준 → O(n log n)

## 요약
- 퀵 정렬의 실행 시간은 각 단계의 파티션이 얼마나 균형 잡혔는지(balance)에 크게 좌우된다: 항상 균형이면 O(n log n), 항상 불균형이면 O(n²).
- 항상 균형 잡힌 기준 원소를 결정적으로(deterministically) 빠르게 찾을 방법이 마땅치 않으므로, 기준 원소를 무작위로 선택하는 전략을 사용한다.
- 정렬된 배열의 가운데 절반에 해당하는 원소를 기준으로 뽑으면 파티션이 균형 잡히며, 무작위 선택이 이런 원소를 뽑을 확률은 최소 1/2이다.
- 이로부터 무작위 퀵 정렬의 평균 실행 시간이 O(n log n)임을(다음 강의에서 formal하게) 증명할 수 있으며, 최악의 경우는 여전히 O(n²)이다.
