# Problem Overview

## 개요
- 정렬(sorting) 문제를 소개하는 도입 강의로, 정렬이 왜 중요한 계산 문제인지, 특히 탐색(search) 문제를 얼마나 효율적으로 만들어주는지를 다룬다.

## 내용

### 정렬 문제의 정의
- 입력: 유한한 원소들의 수열(보통 A로 표기).
- 출력: 같은 원소들을 비내림차순(non-decreasing order)으로 나열한 수열.

### 정렬이 중요한 이유
- 일부 알고리즘은 입력 데이터를 작은 것부터 큰 것 순으로 처리해야 동작한다.
- 다른 경우에는, 데이터를 미리 정렬해두면 이후의 질의(query)를 훨씬 효율적으로 처리할 수 있다.

### 대표 사례: 탐색(search) 문제
- 문제: 주어진 수열에서 특정 원소가 존재하는지 확인한다.
- 정렬되지 않은 데이터: 왼쪽에서 오른쪽으로 훑는 선형 탐색 → 시간 복잡도 선형(linear).
- 정렬된 데이터: 중간 원소와 비교해 절반씩 좁혀가는 이진 탐색 → 시간 복잡도 로그(logarithmic).
- 같은 데이터에 대해 탐색 질의를 여러 번 수행할 것으로 예상된다면, 먼저 데이터를 정렬해두고 이후 질의들을 이진 탐색으로 처리하는 것이 전체적으로 훨씬 효율적이다.

### 앞으로의 학습 방향
- 이는 정렬이 유용한 여러 사례 중 하나일 뿐이며, 이후 레슨에서 정렬을 먼저 해두면 다른 질의들도 훨씬 효율적으로 처리할 수 있는 다양한 상황들을 살펴본다.
- 이어지는 영상들에서 여러 효율적인 정렬 알고리즘을 학습한다.

## 요약
- 정렬 문제는 주어진 원소 수열을 비내림차순으로 재배열하는 기본적인 계산 문제다.
- 탐색처럼, 데이터를 미리 정렬해두면 반복되는 질의를 로그 시간(logarithmic time)에 처리할 수 있어 전체 효율이 크게 향상된다.
- 다음 영상들에서 다양한 효율적 정렬 알고리즘을 다룰 예정이다.
