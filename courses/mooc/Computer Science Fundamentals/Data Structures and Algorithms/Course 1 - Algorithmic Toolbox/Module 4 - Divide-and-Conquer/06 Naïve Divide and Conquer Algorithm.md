# Naïve Divide and Conquer Algorithm

## 개요
- 다항식 곱셈 문제를 분할 정복으로 접근하는 첫 번째(순진한) 버전을 다룬다.
- 결론적으로 이 버전의 실행 시간은 이중 루프 방식과 동일한 O(n²)로, 분할 정복의 이점을 실제로 얻지 못한다는 것을 보여준다.

## 내용

### 분할 방식
- A(x)를 상위 절반과 하위 절반으로 나눈다: A(x) = D₁(x)·x^(n/2) + D₀(x). 여기서 D₁은 상위 계수들, D₀은 하위 계수들로 이루어진 다항식이다.
- B(x)도 마찬가지로 E₁(x)·x^(n/2) + E₀(x)로 나눈다.
- 두 다항식을 곱하면: A(x)B(x) = D₁E₁·x^n + (D₁E₀ + D₀E₁)·x^(n/2) + D₀E₀.
- 즉, D₁E₁, D₁E₀, D₀E₁, D₀E₀ 네 개의 곱을 구하면 되고, 각각은 차수 n/2 다항식 간의 곱셈이므로 재귀적으로 풀 수 있다.

### 점화식과 실행 시간
- 문제를 4개의 절반 크기 하위 문제로 나누고, 결과를 더하는 데 선형 시간이 필요하므로: T(n) = 4T(n/2) + kn.
- 재귀 트리 분석:
  - 레벨 i에서 문제 크기는 n/2^i, 문제 개수는 4^i.
  - 레벨 i에서의 총 작업량은 4^i · k·(n/2^i) = k·2^i·n.
  - 맨 아래 레벨(log₂n)에서는 문제 개수가 4^(log₂n) = n², 각 문제 크기 1이므로 작업량은 kn².
  - 전체 합 Σ(i=0..log₂n) k·2^i·n은 맨 아래 항(n²)이 지배적이므로 Θ(n²)이다.
- 결과적으로 분할 정복을 적용했음에도 실행 시간은 순진한 이중 루프 알고리즘과 같은 Θ(n²)이다. 다음 영상에서 하위 문제 수를 4개에서 3개로 줄여 이를 개선한다.

## 예시

n=4인 경우 (A(x)=x³+4x²+3, B(x)=x³+2x²+3x+4라고 가정한 예):
- 상위/하위 분할: A → D₁=4x+3, D₀=2x+1 / B → E₁=x+2, E₀=3x+4.
- D₁E₁ = (4x+3)(x+2) = 4x²+11x+6.
- 나머지 D₁E₀, D₀E₁, D₀E₀도 같은 방식으로 계산한 뒤, D₁E₁·x⁴ + (D₁E₀+D₀E₁)·x² + D₀E₀를 모두 더하면 최종 곱 다항식 4x⁶+11x⁵+20x⁴+30x³+20x²+11x+4를 얻는다.

재귀 트리 요약:
- 레벨 0: 문제 1개, 크기 n → 작업 kn
- 레벨 i: 문제 4^i개, 크기 n/2^i → 작업 k·2^i·n
- 맨 아래(레벨 log₂n): 문제 n²개, 크기 1 → 작업 kn²
- 총합: Θ(n²)

## 요약
- 다항식을 상/하위로 나눠 D₁E₁, D₁E₀, D₀E₁, D₀E₀ 네 개의 절반 크기 곱셈으로 재귀 분할하는 것이 첫 번째 분할 정복 버전이다.
- 점화식 T(n) = 4T(n/2) + kn을 풀면 Θ(n²)로, 순진한 이중 루프와 같은 성능이다.
- 하위 문제 수(이 경우 4개)를 줄이는 것이 분할 정복의 효율을 개선하는 핵심 열쇠이며, 다음 영상에서 이를 3개로 줄이는 방법(카라추바 알고리즘)을 다룬다.
