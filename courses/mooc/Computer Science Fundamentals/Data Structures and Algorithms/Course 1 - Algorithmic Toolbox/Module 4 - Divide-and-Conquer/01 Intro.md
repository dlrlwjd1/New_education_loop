# Intro

## 개요
- 이전 모듈에서 배운 탐욕 알고리즘(greedy algorithm)에 이어, 이번 모듈에서는 분할 정복(divide-and-conquer) 알고리즘을 다룬다.
- "분할 정복"이라는 용어는 원래 전쟁에서 유래했다. 하나의 큰 상대 집단을 무찌르는 것보다 여러 개의 작은 집단으로 나눠 각각 무찌르는 것이 더 쉽다는 발상이다.
- 모든 문제가 탐욕 알고리즘으로 풀리지 않듯, 모든 문제가 분할 정복으로 풀리는 것도 아니다. 두 기법 모두 문제 해결 도구 상자(toolbox) 안의 전략 중 하나일 뿐이다.

## 내용

### 분할 정복의 일반 구조
- 원래 문제를 서로 겹치지 않는(non-overlapping) 하위 문제(subproblem)들로 나눈다.
- 하위 문제는 반드시 원래 문제와 같은 유형(type)이어야 한다.
  - 예: 사각형 문제를 삼각형들로 쪼개는 것은 하위 문제 유형이 다르므로 분할 정복이 아니다.
  - 예: 사각형 문제를 서로 겹치는 사각형들로 쪼개는 것도, 비겹침 조건을 어기므로 분할 정복이 아니다.
  - 올바른 분할: 원래 문제와 같은 유형이면서 서로 겹치지 않는 하위 문제들로 나누는 것.
- 각 하위 문제를 독립적으로(independently) 해결한다.
- 하위 문제들의 해를 결합(combine)하여 원래 문제의 해를 만든다.

### 하위 문제는 어떻게 푸는가
- 각 하위 문제는 원래 문제와 같은 유형이므로, 동일한 분할 정복 전략을 재귀적으로(recursively) 적용해 풀 수 있다.
- 따라서 분할 정복 알고리즘은 자연스럽게 재귀적(recursive) 해법으로 이어진다.
- 실무에서는 재귀로 작성된 프로그램을 반복문(iterative) 형태로 다시 작성하는 경우가 흔하다.
  - 이유 1: 일부 프로그래머는 반복문에 더 익숙하다.
  - 이유 2: 재귀 구현은 추가적인 스택 공간(stack space)을 사용할 수 있는데, 이는 언어와 구현 방식에 따라 달라진다.

### 분할 정복의 3단계 요약
1. 문제를 같은 유형의, 겹치지 않는 하위 문제들로 나눈다(divide).
2. 하위 문제들을 재귀적으로 해결한다(conquer).
3. 결과들을 결합한다(combine).

## 요약
- 분할 정복(divide-and-conquer)은 문제를 같은 유형·비겹침 하위 문제로 나누고, 재귀적으로 풀고, 결과를 결합하는 3단계 전략이다.
- 탐욕 알고리즘과 마찬가지로 모든 문제에 적용되는 만능 해법은 아니며, 문제 특성에 따라 선택해야 한다.
- 다음 영상부터 매우 단순한 분할 정복 예시를 시작으로 점차 복잡한 사례를 다룬다.
