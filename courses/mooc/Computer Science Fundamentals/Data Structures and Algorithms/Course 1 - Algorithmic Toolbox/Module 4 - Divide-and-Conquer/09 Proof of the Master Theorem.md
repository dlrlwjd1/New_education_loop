# Proof of the Master Theorem

## 개요
- 마스터 정리(Master Theorem) T(n) = a·T(⌈n/b⌉) + O(n^d)의 세 경우가 왜 성립하는지, 재귀 트리와 등비수열(geometric series)을 이용해 증명한다.
- n이 b의 거듭제곱이라고 가정한다(그렇지 않아도 n을 b의 배수로 살짝 늘려 패딩하면 되므로 일반성을 잃지 않는다).

## 내용

### 재귀 트리 구조
- 레벨 0: 문제 1개, 크기 n.
- 레벨 i: 문제 a^i개, 각 크기 n/b^i.
- 맨 아래 레벨(log_b n): 문제 a^(log_b n)개, 각 크기 1.
- 레벨 i에서의 작업량: a^i개 문제 × O((n/b^i)^d) = O(n^d) × (a/b^d)^i.
- 전체 작업량 = Σ(i=0..log_b n) O(n^d)·(a/b^d)^i — 이는 O(n^d)를 첫 항으로, 공비(ratio) r = a/b^d인 등비수열이다.

### 등비수열(geometric series)의 성질
- 공비 r ≠ 1일 때, 합은 첫 항 × (1−r^n)/(1−r) 형태로 닫힌 형태(closed form)를 가진다.
- 빅오 표기에서는 가장 큰 항(첫 항 또는 마지막 항)이 전체 합을 지배한다.
  - r < 1이면 항이 점점 작아지므로 첫 항이 가장 크다 → 합은 O(첫 항).
  - r > 1이면 항이 점점 커지므로 마지막 항이 가장 크다 → 합은 O(마지막 항).

### 세 경우의 증명
- **경우 1 (d > log_b a, 즉 r = a/b^d < 1)**: 첫 항 O(n^d)이 지배적 → T(n) = O(n^d).
- **경우 2 (d = log_b a, 즉 r = 1)**: 등비수열 공식이 적용되지 않으므로 직접 합산한다. 모든 항이 O(n^d)로 동일하고 항의 개수는 log_b n + 1개이므로 합은 O(n^d)·(log_b n + 1) = O(n^d log n) (밑 변환은 상수 배수이므로 로그 표기에서 무시).
- **경우 3 (d < log_b a, 즉 r > 1)**: 마지막 항이 지배적. 마지막 항은 O(n^d)·(a/b^d)^(log_b n). 지수 법칙을 적용해 정리하면 b^(d·log_b n) = n^d이 분모에서 상쇄되고, 분자의 a^(log_b n)은 로그 항등식에 의해 n^(log_b a)와 같다. 따라서 T(n) = O(n^(log_b a)).

### 직관적으로 기억하는 방법(강사의 실전 팁)
- 마스터 정리를 암기하지 않고도, 재귀 트리의 첫 레벨과 두 번째 레벨의 작업량만 비교하면 어느 경우인지 알 수 있다.
  - 두 레벨의 작업량이 같다 → 모든 레벨이 같다 → 경우 2: O(n^d log n) (레벨 수만큼 log n배).
  - 첫 레벨이 두 번째보다 크다 → 위쪽이 지배적 → 경우 1: O(n^d).
  - 첫 레벨이 두 번째보다 작다 → 아래로 갈수록 커진다 → 경우 3: 맨 아래 레벨의 잎(leaf) 개수인 n^(log_b a)가 지배적.

## 예시

등비수열 예시:
- 증가하는 경우: 1+2+4+8+16+32+64 (공비 2 > 1) → 마지막 항이 지배적.
- 감소하는 경우: 10000+1000+100+10+1 (공비 1/10 < 1) → 첫 항이 지배적.

경우 3의 지수 정리: a^(log_b n) / b^(d·log_b n) = n^(log_b a) / n^d → O(n^d) × 이 비율 = O(n^(log_b a)).

## 요약
- 마스터 정리의 증명은 재귀 트리의 각 레벨 작업량이 공비 r = a/b^d인 등비수열을 이룬다는 점에서 출발한다.
- r < 1(경우 1)이면 최상위 레벨, r = 1(경우 2)이면 모든 레벨이 동일(×log n), r > 1(경우 3)이면 최하위 레벨(잎)이 전체 실행 시간을 지배한다.
- 실전에서는 정리를 암기하기보다, 재귀 트리의 첫 두 레벨 작업량을 비교해 어느 경우에 해당하는지 빠르게 판단할 수 있다.
