# Selection Sort

## 개요
- 정렬(sorting) 알고리즘 중 가장 단순한 축에 속하는 선택 정렬(selection sort)을 다룬다.
- 핵심 아이디어는 배열의 이미 정렬된 부분(sorted part)을 한 칸씩 늘려가는 것이다.
- 구현이 쉽고 분석도 쉬우며, 실행 시간(running time)은 이차(quadratic)인 O(n²)이다.

## 내용

### 알고리즘의 기본 아이디어
- 배열 전체에서 최솟값(minimum)을 찾아 배열의 첫 번째 원소와 교환(swap)한다.
- 교환 후 그 원소는 자신의 최종 위치(final position)에 고정되므로 더 이상 신경 쓰지 않는다.
- 남은 부분 배열에 대해 같은 절차 — 최솟값 찾기, 맨 앞과 교환, 잊어버리기 — 를 반복한다.
- 이 과정을 반복하면 정렬된 부분(sorted part)이 한 칸씩 자라나서 결국 배열 전체가 정렬된다.

### 의사코드(pseudocode) 구조
- 바깥 루프는 i를 1부터 n까지 순회한다.
- 각 반복에서 변수 `minIndex`를 i로 초기화한 뒤, i+1부터 n까지 순회하며 더 작은 원소를 발견할 때마다 `minIndex`를 갱신한다.
- 루프가 끝나면 `minIndex`는 부분 배열 [i, n] 중 최솟값의 위치이며, 이 위치의 원소를 A[i]와 교환한다.
- i가 1일 때 최솟값을 찾아 첫 번째 자리에 놓고, i가 2일 때 남은 부분에서 최솟값을 찾아 두 번째 자리에 놓는 식으로 진행한다.

### 실행 시간(running time) 분석
- 이중 루프(two nested loops) 구조이므로 대략 이차(quadratic) 시간이 걸린다.
- 바깥 루프에서 i가 1일 때 안쪽 루프 반복 횟수는 n-1, i가 2일 때는 n-2, ... 로 점점 줄어든다.
- 정확한 반복 횟수 합은 (n-1) + (n-2) + ... + 1 이며, 이는 등차수열(arithmetic series)의 합 공식 n(n+1)/2 에 의해 여전히 n² 에 비례(대략 n²/2)한다.
- 따라서 더 정밀하게 계산해도 점근적으로는 n²이라는 결론이 바뀌지 않는다.
- 이 알고리즘의 실행 시간은 입력 데이터의 특성(무작위, 거의 정렬됨, 역순 정렬, 중복이 많음 등)과 무관하며 오직 배열의 크기에만 의존한다.

### 등차수열(arithmetic series) 합 공식의 증명
- 1 + 2 + ... + n = n(n+1)/2 임을 두 가지 방식으로 보일 수 있다.
- 방법 1: 1부터 n까지를 한 줄로 쓰고, 그 아래 n부터 1까지 역순으로 한 줄을 쓰면 각 열(column)의 합이 항상 n+1이 되고 열이 n개이므로, 전체 합(원래 수열을 두 번 더한 것)은 n(n+1)이 되어 원래 합은 그 절반인 n(n+1)/2이다.
- 방법 2: 가로 n, 세로 n+1인 직사각형(넓이 n(n+1))을 절반으로 나누면 각 절반의 넓이가 1+2+...+n이 된다.

## 예시
- 배열 `[8, 4, 2, 5, 2]`를 정렬하는 과정:
  1. 전체에서 최솟값 2를 찾아 첫 원소 8과 교환 → `[2, 4, 8, 5, 2]` (첫 번째 2 확정)
  2. 남은 `[4, 8, 5, 2]`에서 최솟값 2를 찾아 맨 앞과 교환 → 두 번째 2 확정
  3. 남은 부분에서 다시 최솟값 4를 찾아 확정
  4. 이 과정을 반복하면 배열 전체가 정렬된다.
- 의사코드:
  ```
  for i = 1 to n:
      minIndex = i
      for j = i+1 to n:
          if A[j] < A[minIndex]:
              minIndex = j
      swap(A[i], A[minIndex])
  ```

## 요약
- 선택 정렬(selection sort)은 정렬된 부분을 한 칸씩 늘려가는 단순한 알고리즘이다.
- 구현과 분석이 쉽고, 배열을 제자리(in place)에서 정렬하므로 인덱스 변수 외에 추가 메모리가 거의 필요 없다.
- 실행 시간은 항상 O(n²)이며 입력 데이터의 특성에 영향을 받지 않는다.
- 삽입 정렬(insertion sort), 버블 정렬(bubble sort) 등 다른 이차 시간 정렬 알고리즘도 존재하지만 이 강의에서는 다루지 않고, 다음 강의에서 더 빠른 정렬 알고리즘으로 넘어간다.
