# Merge Sort

## 개요
- 분할 정복(divide and conquer) 기법을 기반으로 하는 병합 정렬(merge sort) 알고리즘을 다룬다.
- 분할 정복의 핵심 아이디어: 문제를 두 개 이상의 서로 겹치지 않는(disjoint) 부분 문제로 나누고, 각 부분 문제를 재귀적으로(recursively) 풀고, 그 결과를 결합(combine)하여 원래 문제의 답을 얻는다.
- 병합 정렬의 실행 시간은 O(n log n)으로, 이차 시간인 선택 정렬(selection sort)보다 훨씬 빠르다.

## 내용

### 병합 정렬의 동작 방식
- 크기 n인 배열을 절반 크기(n/2)의 두 배열로 나눈다.
- 두 부분에 대해 재귀적으로 정렬을 수행한다.
- 정렬된 두 배열을 하나의 정렬된 배열로 병합(merge)한다.
- n=1이면 이미 정렬된 것이므로 그대로 반환한다.

### 병합(merge) 절차
- 정렬된 두 배열 B(크기 p), C(크기 q)를 병합해 크기 p+q인 정렬된 배열 D를 만든다.
- B와 C의 첫 원소는 각각 그 배열에서 가장 작은 값이므로, 두 첫 원소 중 더 작은 쪽을 D로 옮기고 해당 배열에서 제거한다.
- 두 배열 중 하나가 빌 때까지 이 과정을 반복하고, 한쪽이 비면 남은 배열을 그대로 D 뒤에 복사한다.
- 이 절차는 두 배열을 왼쪽에서 오른쪽으로 한 번씩만 훑으므로 실행 시간은 p+q, 즉 선형(linear) 시간이다.

### 실행 시간(running time) 분석 — 점화식(recurrence)
- 크기 n/2인 두 부분을 병합하는 데 걸리는 시간은 선형, 즉 O(n)이다.
- 병합 정렬의 실행 시간을 T(n)이라 하면 다음 점화식이 성립한다: T(n) ≤ 2T(n/2) + O(n)
  - 2T(n/2)는 두 번의 재귀 호출(recursive call)에 해당한다.
  - O(n) 항은 재귀 호출 이전(배열을 절반으로 나누는 작업)과 이후(두 결과 배열을 병합하는 작업)에 드는 비용이다.

### 재귀 트리(recursion tree)를 이용한 상한 증명
- 트리 최상단에는 크기 n인 배열 하나가 있고, 그 아래로 크기 n/2인 배열 2개, 그 아래 n/4인 배열 4개, ... 순으로 내려가며 총 log n 개의 레벨(level)이 존재한다.
- 각 레벨에서 재귀 호출 전후에 하는 작업(분할과 병합)만 따로 계산하면, 크기 n인 배열 하나를 처리하는 데 걸리는 시간은 cn(c는 O 표기 속 상수)이다.
- 최상위 레벨: cn. 다음 레벨: 배열 2개 × c×(n/2) = cn. 그다음 레벨: 배열 4개 × c×(n/4) = cn. 즉 모든 레벨에서 동일하게 약 cn만큼의 작업이 발생한다.
- 레벨 수가 log n개이므로 전체 작업량은 cn·log n이 되어, T(n) = O(n log n)이 증명된다.
- 예: 100만(10⁶) 개의 원소를 정렬할 때 병합 정렬은 노트북에서도 충분히 실행 가능하지만, 이차 시간인 선택 정렬은 약 10¹²번의 연산이 필요해 현대 컴퓨터로도 비현실적이다.

## 예시
- 크기 8짜리 배열을 병합 정렬로 정렬하는 과정: 8 → 4,4 → 2,2,2,2 → 1×8 로 계속 절반씩 나눈 뒤, 크기 1인 배열들을 크기 2로, 다시 크기 4로, 마지막에 크기 8인 하나의 정렬된 배열로 합쳐 올라간다.
- 두 정렬된 배열의 병합 예: 왼쪽 배열의 최소값이 2, 오른쪽 배열의 최소값이 1이면 1을 먼저 꺼내 결과 배열에 넣고, 다음으로 남은 배열들 중 최소값(이 예시에서는 2)을 비교해 계속 옮기는 방식으로 진행한다.
- 병합 정렬 의사코드:
  ```
  mergeSort(A[1..n]):
      if n == 1: return A
      B = mergeSort(A[1..n/2])
      C = mergeSort(A[n/2+1..n])
      return merge(B, C)

  merge(B[1..p], C[1..q]):
      D = empty array of size p+q
      while B and C are both non-empty:
          move the smaller of B[1], C[1] into D
      copy remaining elements of B or C into D
      return D
  ```

## 요약
- 병합 정렬(merge sort)은 분할 정복(divide and conquer) 기법으로 배열을 절반씩 나눠 재귀적으로 정렬한 뒤 병합(merge)하는 알고리즘이다.
- 병합 절차는 선형 시간 O(p+q)에 동작하며, 이를 바탕으로 점화식 T(n) ≤ 2T(n/2) + O(n)이 성립한다.
- 재귀 트리 분석을 통해 병합 정렬의 실행 시간이 O(n log n)임을 증명할 수 있다.
- 다음 강의에서는 비교 기반(comparison based) 알고리즘이 n log n보다 점근적으로 빠를 수 없음을 보이며, 병합 정렬이 점근적으로 최적(optimal)임을 확인한다.
