# The Alignment Game

## 개요
- 낭포성 섬유증(cystic fibrosis) 유전자 탐색 사례를 통해 유전자 서열 유사성 비교의 실제 응용을 소개한다.
- "정렬 게임(alignment game)"이라는 놀이를 통해 두 문자열의 정렬(alignment)과 그 점수(score) 개념을 익힌다.
- 최장 공통 부분 수열(longest common subsequence)과 편집 거리(edit distance) 문제가 모두 정렬 문제(alignment problem)의 특수한 경우임을 보인다.

## 내용

### 배경: 낭포성 섬유증 유전자 탐색
- 낭포성 섬유증은 흔한 유전 질환으로, 약 25명 중 1명이 결함 유전자를 보유하며, 양쪽 부모 모두 보유자면 자녀가 발병할 확률이 25%다.
- 1980년대 초 생물학자들이 인간 게놈 프로젝트(human genome project)의 초기 작업으로 낭포성 섬유증 유전자를 찾기 시작했다.
- 30년 전, 탐색 범위를 7번 염색체(chromosome 7)의 100만 뉴클레오타이드(nucleotide) 길이 영역으로 좁혔지만, 이 영역에는 여러 유전자가 있어 어느 것이 원인인지 알 수 없었다.
- 힌트: 낭포성 섬유증은 나트륨 수치가 비정상적으로 높은 땀 분비(sweat secretion)를 동반한다. 당시 생물학자들은 분비(secretion)를 담당하는 것으로 알려진 유전자들의 서열(예: 수송 채널 역할을 하는 ATP 결합 단백질)을 이미 알고 있었다.
- 결국 생물학자들은 이 영역 내 유전자 중 하나가 분비를 담당하는 ATP 결합 단백질과 유사하다는 것을 발견해 낭포성 섬유증 유전자를 찾아냈다. 이는 서열 유사성 비교가 실제 문제 해결에 쓰인 사례다.

### 정렬 게임(alignment game) 규칙
- 1인용 게임으로, 두 개의 문자열이 주어지고 각 문자열에서 기호(symbol)를 제거해가며 점수를 최대화하는 것이 목표다.
- 점수 획득 방법:
  - 두 문자열 모두에서 첫 기호를 제거: 두 기호가 같으면 +1점, 다르면 0점.
  - 둘 중 한 문자열에서만 첫 기호를 제거: 항상 0점.
- 예시 진행: 첫 기호가 같은 쌍을 계속 제거해 +1, +1을 얻고, 기호가 다른 지점에서는 한쪽 문자열의 기호만 제거(0점)한 뒤, 다시 같은 기호(G, G)를 만나 점수를 추가하는 식으로 진행해 최종 점수 +4를 얻는다.

### 정렬(alignment)의 정의와 분류
- 정렬(alignment)은 두 행(row)으로 이루어진 행렬(matrix)이다.
  - 첫 번째 행: 첫 번째 문자열의 기호들을 순서대로, 필요하면 공백(space) 기호와 섞어서 배치.
  - 두 번째 행: 두 번째 문자열의 기호들을 순서대로, 마찬가지로 공백과 섞어서 배치.
- 정렬 행렬의 각 열(column)은 다음 중 하나로 분류된다.
  - 매치(match): 두 기호가 같음.
  - 미스매치(mismatch): 두 기호가 다름.
  - 삽입(insertion): 두 번째 문자열 쪽 기호를 선택한 경우.
  - 삭제(deletion): 첫 번째 문자열 쪽 기호를 선택한 경우.
- 점수 매기기: 매치마다 보상 +1, 미스매치마다 벌점 -μ(뮤), 인델(indel, 삽입 또는 삭제)마다 벌점 -σ(시그마)를 부여한다.
  - 정렬 점수(alignment score) = 매치 수 - μ × 미스매치 수 - σ × 인델 수.
  - 예: μ=0, σ=1일 때 특정 정렬의 점수는 1이 된다.

### 최적 정렬 문제(optimal alignment problem)
- 정의: 두 문자열과 미스매치 벌점 μ, 인델 벌점 σ가 주어졌을 때, 점수를 최대화하는 정렬을 찾는 문제다.

### 최장 공통 부분 수열(longest common subsequence, LCS)
- 공통 부분 수열(common subsequence)은 정렬에서의 매치들만 모은 것으로 정의한다. 예: 매치들이 A, T, G, T라면 공통 부분 수열은 ATGT다.
- 최장 공통 부분 수열 문제: 두 문자열에서 가장 긴 공통 부분 수열을 찾는 문제다.
- μ = 0, σ = 0으로 둔 최대 점수 정렬을 찾는 것이 곧 최장 공통 부분 수열을 찾는 것과 동일하다.

### 편집 거리(edit distance) 문제와 정렬 문제의 동치성
- 편집 거리 문제: 두 문자열이 주어졌을 때, 한 문자열을 다른 문자열로 바꾸는 데 필요한 기본 연산(삽입, 삭제, 치환)의 최소 횟수를 구한다.
- 두 문자열의 정렬에서 삽입, 삭제, 미스매치의 개수 합이 곧 편집 거리다.
- 증명 스케치: "editing"과 "distance" 두 문자열의 최적 정렬을 예로 들면, 두 문자열의 전체 기호 수 합은 (매치 수 × 2) + (미스매치 수 × 2) + 삽입 수 + 삭제 수와 같다.
- 이 식을 재배열(rewrite)하면 앞의 세 항은 정렬 점수(alignment score)에 대응하고, 뒤의 세 항(미스매치+삽입+삭제)은 편집 거리(edit distance)에 대응함을 알 수 있다.
- 결론: 편집 거리를 최소화하는 것은 정렬 점수를 최대화하는 것과 동일하다. 즉, 편집 거리 문제는 정렬 문제(alignment problem)의 한 특수한 버전이다.

## 예시
```text
정렬 게임 예시:
두 문자열에서 첫 기호가 같으면 +1, 한쪽만 제거하면 0점.
같은 기호(A,A), (T,T)를 순서대로 제거 → +1, +1
다른 기호는 한쪽만 제거(indel) → 0점
다시 같은 기호(G,G) 두 번 제거 → +1, +1
최종 점수: +4
공통 부분 수열(매치만 모음): A T G T
```

## 요약
- 정렬 게임은 두 문자열에서 기호를 매치/미스매치/삽입/삭제로 분류해 점수를 매기는 방식으로 정렬(alignment)과 그 점수(alignment score) 개념을 도입한다.
- 최장 공통 부분 수열(LCS) 문제는 μ=0, σ=0인 최대 점수 정렬 문제와 동일하다.
- 편집 거리(edit distance) 문제는 미스매치·삽입·삭제 벌점을 각각 1로 둔 정렬 문제와 동치이며, 편집 거리를 최소화하는 것은 정렬 점수를 최대화하는 것과 같은 문제다.
