# Reconstructing an Optimal Alignment

## 개요
- 편집 거리 값 자체를 계산하는 것을 넘어, 실제 최적 정렬(optimal alignment) 두 행을 복원하는 방법을 다룬다.
- 동적 계획법 표를 채우면서 기록해 둔 역추적 포인터(backtracking pointer)를 이용해 (0,0)에서 (n,m)으로의 경로를 되짚는 방식이다.
- OutputAlignment 의사코드와, 포인터를 별도로 저장하지 않고 표 값만으로 역추적하는 절약된 방식도 함께 소개한다.

## 내용

### 경로(path)와 정렬(alignment)의 관계
- 동적 계획법 행렬에서 (0,0)부터 (i,j)까지의 임의의 경로는 A의 i-prefix와 B의 j-prefix 사이의 하나의 정렬(alignment)을 나타낸다(반드시 최적일 필요는 없음).
- 예: (0,0)에서 (n,m)까지 그냥 순서대로(대각선 우선) 이동하며 만든 경로는 하나의 정렬이지만, 최적 정렬(그 예시에서 편집 거리는 5)과는 다를 수 있다.

### 역추적 포인터(backtracking pointer)를 이용한 복원
- 최적 정렬을 구성하려면, 표를 채울 때 각 노드에서 어떤 방향(수직/수평/대각선)으로 최솟값에 도달했는지 기록해 둔 역추적 포인터를 사용한다.
- 절차: 마지막 노드(편집 거리가 기록된 지점, 예시에서는 값 5)에서 시작해, 역추적 포인터를 따라 (0,0)까지 거슬러 올라간다.
- 한 노드에 도달하는 방법이 여러 개(예: 미스매치 경로와 삽입 경로 둘 다 최적)일 경우, 그중 하나를 임의로(arbitrarily) 선택해도 된다.
- 예시 진행: 마지막 노드에서 미스매치 경로를 선택 → 이전 노드에서는 유일한 경로인 인델(indel) → 이후 매치가 계속 이어지는 식으로 거슬러 올라가 결국 시작점(초기 노드)에 도달하며, 이 과정에서 최적 정렬이 구성된다.

### OutputAlignment 의사코드 로직
- 노드 (i, j)에 들어오는 역추적 포인터를 확인한다.
  - **수직 간선(vertical edge)**으로 도달했다면: 정렬의 한 열을 출력하되, 첫 번째 행에는 A의 i번째 기호를, 두 번째 행에는 공백(indel)을 출력한다.
  - **수평 간선(horizontal edge)**으로 도달했다면: 두 번째 행에 B의 j번째 기호를 출력한다(첫 번째 행은 공백).
  - **대각선 간선(diagonal edge)**으로 도달했다면: 첫 번째 행에 A의 i번째 기호, 두 번째 행에 B의 j번째 기호를 함께 출력한다(매치 또는 미스매치).
- 이 과정을 (n,m)에서 (0,0)까지 반대로 진행하며 각 열을 출력하면 전체 정렬이 복원된다.

### 공간을 절약하는 방법
- 언뜻 보면 정렬을 출력하기 위해 모든 역추적 포인터를 별도로 저장해야 할 것 같지만, 약간 수정된 의사코드를 사용하면 동적 계획법 행렬의 값(D(i,j) 값들)만 보고도 역추적 포인터를 즉석에서 계산할 수 있다.
- 즉, 어느 방향에서 왔는지는 인접한 세 값(D(i,j-1), D(i-1,j), D(i-1,j-1))과 현재 값 D(i,j)를 비교하는 것만으로 재구성할 수 있어, 포인터를 위한 별도 공간을 절약할 수 있다.

### 응용과 더 배울 거리
- 편집 거리는 문자열 비교(string comparison)의 여러 응용 중 하나일 뿐이며, 인터넷 페이지 비교부터 유사 유전자 찾기까지 다양한 분야에서 쓰인다.
- 이 강의는 낭포성 섬유증(cystic fibrosis) 유전자 탐색 사례(인간 게놈 프로젝트의 초기 성공 사례 중 하나)로 시작했다.
- 유전자·단백질·게놈 비교를 더 깊이 배우고 싶다면 MOOC의 Bioinformatics 전문과정이나 책 「Bioinformatics Algorithms: the Active Learning Approach」를 참고할 수 있다.

## 예시
```text
OutputAlignment(i, j):
    if 도달 방식이 수직 간선(vertical edge):
        출력 열: (A[i], "-")   # 삭제/indel
    elif 도달 방식이 수평 간선(horizontal edge):
        출력 열: ("-", B[j])   # 삽입/indel
    elif 도달 방식이 대각선 간선(diagonal edge):
        출력 열: (A[i], B[j])  # 매치 또는 미스매치

# (n,m)에서 (0,0) 방향으로 역추적하며 각 열을 출력하면
# 최적 정렬의 두 행(row)이 완성된다.
```

## 요약
- 동적 계획법 행렬에서 (0,0)~(i,j) 사이의 경로는 곧 하나의 정렬을 나타내며, 역추적 포인터를 따라가면 최적 정렬을 복원할 수 있다.
- 한 노드에 도달하는 최적 경로가 여러 개면 아무거나 하나를 선택해도 되며, 역추적은 마지막 노드에서 시작해 (0,0)까지 거슬러 올라간다.
- 역추적 포인터는 별도로 저장하지 않고 인접한 D(i,j) 값들만 비교해도 재구성할 수 있어 공간을 절약할 수 있다.
