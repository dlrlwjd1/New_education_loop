# Knapsack with Repetitions

## 개요
- 반복 허용 배낭 문제(knapsack with repetitions)에 대한 동적 계획법(dynamic programming) 알고리즘을 설계한다.
- 이 문제에서는 각 아이템을 무제한으로 가져갈 수 있다.

## 내용

### 문제의 형식적 정의
- 입력: n개의 아이템, 각각의 무게(weight) w1, w2, …, wn과 가치(value) v1, v2, …, vn.
- 배낭의 총 용량(capacity)은 W.
- 목표: 각 아이템을 몇 번이든 선택할 수 있는 상태에서, 총 무게가 W 이하이면서 총 가치가 최대가 되는 부분집합을 선택.

### 최적해의 구조 분석 — cut and paste trick
- 총 무게가 W 이하이고 총 가치가 최대인 어떤 최적해를 생각하고, 그 안의 아이템 i를 하나 꺼낸다고 하자.
- 남은 부분집합의 총 무게는 W - wi 이하가 되며, 이 남은 부분집합은 반드시 "총 무게가 W - wi 이하인 부분집합 중 최대 가치"를 가져야 한다.
- 만약 총 무게 W - wi 이하이면서 더 높은 가치를 가진 다른 부분집합이 있다면, 거기에 아이템 i를 다시 넣으면 원래보다 더 높은 가치의 해를 얻게 되어 최초 가정(최적해였다는 것)과 모순된다.
- 이러한 증명 기법을 cut and paste trick이라 부르며, 동적 계획법 알고리즘 설계에서 자주 사용된다.
- 즉, 총 무게 W인 배낭의 최적해에서 아이템 i를 제거하면, 남은 것은 더 작은 무게의 배낭에 대한 최적해가 되어야 한다.

### 하위 문제(subproblem) 정의와 점화식(recurrence relation)
- 0부터 W까지 가능한 모든 총 무게에 대해 각각 하위 문제를 정의한다.
- `value(w)`: 총 무게가 w 이하인 아이템들의 최적 총 가치.
- 점화식:
  ```
  value(w) = max over all items i such that wi ≤ w of [ value(w - wi) + vi ]
  ```
- 즉, 총 무게 w인 배낭의 최적해를 얻으려면, 더 작은 무게(w - wi)의 최적해에 아이템 i를 추가한다. 어떤 아이템을 추가해야 할지 모르므로 모든 n개의 아이템에 대해 시도하고 그중 최댓값을 선택한다.

### 알고리즘(의사코드)
- 하위 문제를 무게가 증가하는 순서로 풀어나간다.
- 초기화: `value(0) = 0` (무게 0인 배낭의 최대 가치는 0).
- `w = 1`부터 `W`까지 반복:
  - `wi ≤ w`인 모든 아이템 i에 대해, `value(w - wi) + vi`를 계산하고, 현재 `value(w)`보다 크면 갱신.
- 최종적으로 `value(W)`를 반환.
- 이 알고리즘은 점화식을 그대로 구현하므로 정확성(correctness)이 보장된다.

### 실행 시간(running time)
- 중첩 반복문(nested loop) 구조: 바깥 루프는 W번, 안쪽 루프는 n번 반복.
- 루프 내부는 상수 시간(constant time)이 걸리므로 전체 실행 시간은 **O(n × W)**.

## 예시
- 배낭 총 용량 10, 아이템 4개가 주어진 토이 예제. 무게 0부터 10까지 각 배낭의 최적값을 배열로 계산한다.
- 배열은 모두 0으로 초기화된 뒤 왼쪽부터 채워진다.
  - `value(2) = 9`: 무게 0인 배낭에 마지막 아이템(무게 2, 가치 9)을 추가한 것이 유일한 선택.
  - `value(3) = 14`: 두 가지 선택지 중 — (무게 1의 최적해 + 네 번째 아이템) vs (무게 0의 최적해 + 두 번째 아이템, 가치 14) — 후자가 더 큼.
  - `value(4) = 18`: 세 가지 선택지 — (무게 2 + 마지막 아이템 = +9), (무게 1 + 두 번째 아이템 = +14), (무게 0 + 세 번째 아이템 = +16) 중 최댓값 18.
- 이런 식으로 배열을 끝까지 채우면 `value(10) = 48`을 얻으며, 이는 첫 번째 아이템 1개와 마지막 아이템 2개를 선택한 결과와 일치한다.

## 요약
- 반복 허용 배낭 문제는 cut and paste trick으로 최적 부분 구조(optimal substructure)를 증명하고, `value(w) = max_i [value(w - wi) + vi]` 점화식으로 표현한다.
- 무게가 증가하는 순서로 하위 문제를 풀어나가는 상향식(bottom-up) 알고리즘의 실행 시간은 O(n × W)이다.
- 다음 영상에서는 반복이 허용되지 않는 경우(without repetitions)를 다룬다.
