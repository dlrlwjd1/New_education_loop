# Algorithm

## 개요
- 앞서 세운 점화식(recurrence relation)을 실제 동적 계획법(dynamic programming) 알고리즘으로 구현한다.

## 내용

### MinAndMax(i, j) 절차
- 부분식 (i, j)의 최솟값과 최댓값을, 더 작은 부분식들의 최적값을 이용해 계산하는 절차.
- `min`은 +∞(혹은 매우 큰 수), `max`는 -∞(혹은 매우 작은 수)로 초기화.
- k를 i부터 j-1까지 순회하며, 각 k에 대해 부분식 (i,j)를 (i,k)와 (k+1,j)로 분할.
- 분할이 정해지면, opk를 다음 네 가지 조합에 적용해 값을 계산: (최댓값, 최댓값), (최솟값, 최솟값), (최댓값, 최솟값), (최솟값, 최댓값).
- 계산된 값이 현재 `min` 또는 `max`를 갱신할 수 있으면 갱신.
- 최종적으로 `min`과 `max`를 반환.

### 하위 문제를 푸는 순서
- 부분식 (i,j)의 값을 계산하려면 그보다 짧은(shorter) 부분식들의 값이 먼저 계산되어 있어야 한다.
- 즉, **j - i 값이 증가하는 순서**로 모든 하위 문제를 풀어야 한다.
- 하위 문제는 i와 j로 파라미터화되며 둘 다 1부터 n까지의 범위를 가지므로, 대략 **2차(quadratic) 개수**의 하위 문제가 존재한다. 이를 저장하기 위해 n × n 크기의 2차원 테이블을 사용한다.
- j - i가 0인 대각선(주 대각선)부터 시작해, j - i = 1, 2, 3, … 순서로 대각선을 따라 채워 나간다.
- 최종 결과는 마지막 셀, 즉 (1, n)에 해당하는 값이다(전체 표현식에 해당).

### 전체 알고리즘(의사코드)
- 두 개의 테이블 m(최솟값용)과 M(최댓값용)을 유지한다.
- **초기화**: 부분식이 숫자 하나만 포함할 때(j = i)는 연산이 없으므로 최소/최대화할 것이 없다. 따라서 주 대각선은 `m(i,i) = M(i,i) = di`로 초기화한다.
- **채우기**: 파라미터 s(부분식 길이, s = j - i)를 1부터 n-1까지 증가시키며:
  - i를 1부터 n-s까지 순회하고, `j = i + s`로 계산.
  - i, j가 정해지면 `MinAndMax(i, j)` 절차를 호출해 m(i,j), M(i,j)를 계산.
- 최종적으로 `M(1, n)`을 반환한다(전체 표현식 1부터 n까지에 해당).

### 실행 시간(running time)
- 바깥 루프(n-1번 반복)와 안쪽 루프(최대 n번 반복)의 중첩으로 O(n²) 번 MinAndMax가 호출된다.
- MinAndMax 절차 자체의 실행 시간은 j - i에 비례하며 최대 n이다.
- 따라서 전체 실행 시간은 **O(n × n × n) = O(n³)** (세제곱, cubic).

## 예시
- 토이 예제: `5 - 8 + 7 × 4 - 8 + 9` (숫자 6개: 5, 8, 7, 4, 8, 9).
- **주 대각선** (숫자 하나짜리 부분식): m = M = 5, 8, 7, 4, 8, 9 그대로.
- **두 번째 대각선** (s=1, 연산 하나짜리 부분식): 예를 들어 (1,2) = `5-8` → 값은 -3 (연산이 하나뿐이라 최소/최대화할 필요 없음).
- **세 번째 대각선** (s=2): 예를 들어 (1,3) = `5-8+7`을 계산.
  - 분할 1: (1,1)과 (2,3), 즉 `5`와 `8+7`. (2,3)의 최솟값·최댓값은 모두 15. 뺄셈이므로 5(최댓값)에서 15(최솟값)를 빼는 조합을 고려 → 5 - 15 = -10.
  - 분할 2: (1,2)와 (3,3), 즉 `5-8`(최솟값·최댓값 모두 -3)과 `7`(최솟값·최댓값 모두 7). -3 + 7 = 4.
  - 따라서 M(1,3) = 4, m(1,3) = -10.
- 이런 식으로 표 전체를 채워 나가면 최종적으로 M(1,6) = **200**을 얻는다. 이는 초기 표현식의 최댓값이다.

## 요약
- 괄호 배치 문제는 부분식 길이(s = j - i)가 증가하는 순서로 n × n 테이블을 대각선 방향으로 채워 나가며 푼다.
- MinAndMax(i,j) 절차는 모든 분할 위치 k와 최댓값/최솟값의 네 가지 조합을 고려해 m(i,j), M(i,j)를 계산한다.
- 전체 알고리즘의 실행 시간은 O(n³)이며, 최종 답은 M(1,n)이다. 토이 예제에서는 최댓값 200을 얻었다.
