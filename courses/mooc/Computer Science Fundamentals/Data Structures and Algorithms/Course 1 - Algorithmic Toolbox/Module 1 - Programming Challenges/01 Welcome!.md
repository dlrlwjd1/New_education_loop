# Welcome!

## 개요
- 알고리즘(algorithm)은 소프트웨어 작성, 유전체 분석, 교통 예측, 영화 추천, 인터넷 검색 등 어디에나 존재하며, 컴퓨터 과학의 모든 분야에서 사용된다.
- 이 전문과정(specialization)은 알고리즘의 이론을 배우고, 원하는 프로그래밍 언어로 구현하며, 실제 문제 해결에 적용하는 것을 목표로 한다.
- 약 100개의 프로그래밍 과제를 통해 빠른 알고리즘을 구현·테스트·디버깅하는 실전 능력을 기른다.

## 내용

### 알고리즘의 효율성(efficiency)이 중요한 이유
- 사용자는 수조(trillions) 개의 웹 페이지를 검색하더라도 눈 깜짝할 사이에 결과를 보길 원한다.
- 잘못 설계된 알고리즘은 검색 엔진이 색인한 모든 웹페이지나 모든 Facebook 게시물을 처리하는 데 문자 그대로 수백 년이 걸릴 수 있다.
- 따라서 이런 시스템을 실용적으로 만들려면 알고리즘적 개선(algorithmic improvement)이 필수적이며, 이것이 기술 기업들이 면접에서 알고리즘 질문을 많이 하는 이유다.

### 데이터 과학(data science)에서의 알고리즘
- 검색 결과 순위 매기기, 도로 사고 예측, 영화 추천 같은 문제에서 고급 알고리즘이 검색 품질, 예측 정확도, 추천 관련성을 높이는 데 쓰인다.
- 선형 회귀(linear regression) 같은 단순한 머신러닝 알고리즘조차 빅데이터를 처리하는 것은 대개 도전 과제다.
- 심층 신경망(deep neural network) 같은 고급 알고리즘은 거대한 데이터셋에서 매우 정확한 예측을 하며, 시각·음성 인식 일부 영역에서는 인간을 능가하기 시작했다. 다만 이런 알고리즘을 대규모 데이터셋에서 수년이 아닌 수 시간 안에 동작시키는 것은 어렵고, 데이터 과학에서는 실험을 빠르게 수행하는 것이 중요하다.

### 생물의학(biomedical) 분야의 알고리즘
- 우리 몸의 수조 개 세포 각각이 복잡한, 아직도 잘 이해되지 못한 알고리즘을 실행한다.
- 알고리즘은 사람 간 차이를 만드는 돌연변이(mutation)가 무엇이고 그것이 질병과 어떻게 관련되는지 등 중요한 생물의학 문제를 푸는 열쇠다.
- 실제 응용 예로 수백만 개의 작은 조각으로부터 유전체(genome)를 조립하는 문제가 있으며, 이는 인류가 조립한 가장 큰 조각 맞추기(jigsaw puzzle)에 비유된다.

### 이 과정에서 배우는 것
- 알고리즘의 이론을 배우고, 직접 구현하며, 실제 문제에 적용한다.
- 제출한 해답은 자동으로 채점되며, 크고 어려운 문제를 몇 초 안에 푸는 빠른 알고리즘을 구현·테스트·디버깅하는 법을 배운다.
- 도입부에서 본 다섯 개의 정렬(sorting) 알고리즘은 모두 실행 시간(running time)이 서로 달랐다. 네 개가 거의 끝날 무렵 하나는 훨씬 오래 걸린다. 이 과정에서 이 알고리즘들을 모두 직접 구현하게 된다.

## 요약
- 알고리즘은 컴퓨터 과학 전반과 데이터 과학, 생물의학 등 실생활 곳곳에 존재한다.
- 대규모 데이터에서는 알고리즘의 효율성이 시스템의 실용성을 좌우한다.
- 이 전문과정은 이론 학습과 직접 구현, 실제 문제 적용, 그리고 테스트·디버깅 역량을 종합적으로 기르는 것을 목표로 한다.
