# For Python Learners: Getting Started with PyCharm Professional IDE

## 개요
- 파이썬(Python)으로 과제를 풀 경우 전문 IDE인 PyCharm 사용을 권장한다.
- PyCharm에서 작성·실행·테스트·디버깅의 실제 개발 워크플로(workflow)를 연습할 수 있다.
- 설치부터 학습 프로젝트 열기, IDE 탐색, 과제 수행까지의 절차를 안내한다.

## 내용

### 설치 및 설정 절차
- 이름을 입력하고 앱을 실행한다. 이때 매 과제(task)마다 코드 오브 아너(code of honor)를 반드시 수락해야 하며, 그렇지 않으면 진행 상황이 동기화되지 않을 수 있다.
- Download를 클릭해 JetBrains Toolbox를 받는다. JetBrains Toolbox는 PyCharm 같은 JetBrains 도구들을 설치·관리하는 중앙 허브 역할을 한다.
- Toolbox 준비가 끝나면 Start Coding을 클릭해 PyCharm 다운로드를 시작한다.
- Start Coding을 한 번 더 클릭하면 코스가 PyCharm 안에서 바로 열리고, 이후 PyCharm에서 파이썬 과제를 풀 수 있게 된다.

### PyCharm IDE 구성 요소
- **Course View 패널**: 코스의 모든 모듈과 과제 목록을 보여준다. 과제를 더블클릭하면 열린다. 버튼 클릭이나 `Command + 1`로 표시/숨김을 전환해 화면 공간을 넓힐 수 있다.
- **에디터(editor)**: 파이썬 프로그램을 작성하고 자유롭게 실험하는 공간이다.
- **실행(run)**: `Control + R`을 누르거나 메뉴에서 Run을 선택해 코드를 실행한다.
- **패널 전체 표시/숨김**: `Shift + Command + F12`로 모든 패널을 한 번에 켜고 끌 수 있어 화면을 최대로 활용할 수 있다.
- **Task Description 패널**: 이론, 퀴즈, 코딩 과제 등 각 과제에 대한 설명을 제공한다. 여기서 해답 확인, 과제 간 이동, 정답 미리보기 등이 가능하다. 이 패널은 계속 열어두거나 다른 모니터로 옮겨 사용하는 것을 권장한다.

### 과제 수행 워크플로
1. IDE에서 해당 과제를 연다.
2. 해답을 작성한다.
3. Check 버튼으로 코드가 올바르게 동작하는지 확인한다.
4. 과제가 모든 검사를 통과하면 원래의 MOOC 프로그래밍 과제 페이지로 돌아가 My Submission 탭에서 해답을 제출해 점수를 받는다.
- 이 과정은 코스 내 모든 파이썬 과제에 동일하게 적용된다.

## 요약
- 파이썬 학습자는 PyCharm Professional IDE로 실제 개발 워크플로를 연습하며 과제를 수행할 수 있다.
- JetBrains Toolbox → PyCharm 설치 → 코스 프로젝트 열기 순서로 환경을 구성한다.
- Course View, 에디터, Task Description 패널을 활용해 코딩 → Check → MOOC에서 Submit하는 흐름으로 과제를 완료한다.
