# Algorithmic Toolbox

- 전문과정: Data Structures and Algorithms (Course 1)
- 제공: University of California San Diego
- 구성: 6개 모듈, 영상 61개 — Transcript 기반 한국어 정리 완료
- 제외: 읽기 자료·퀴즈·프로그래밍 과제 채점

알고리즘 설계와 분석의 기초를 다지는 코스로, 프로그래밍 챌린지 진행 방식부터 시작해 점근적 표기법, 탐욕 알고리즘(greedy algorithm), 분할 정복(divide-and-conquer), 동적 계획법(dynamic programming)까지 핵심 알고리즘 패러다임을 다룬다.
