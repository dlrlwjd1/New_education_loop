# Data Structures and Algorithms Specialization

- 제공: University of California San Diego (MOOC)
- 구성: 6개 코스 — 각 코스 강의 영상을 Transcript 기반으로 한국어 정리
- 제외: 읽기 자료·퀴즈·프로그래밍 과제 채점

자료구조와 알고리즘의 기초 설계 기법(분할 정복, 그리디, 동적 계획법)부터 그래프, 문자열, 네트워크 유량, NP-완전성, 그리고 실전 게놈 조립(genome assembly) 프로젝트까지 이어지는 전문과정(specialization)이다.
