# Basic Estimate 1

## 개요
- ApproxPointQuery를 위한 매우 단순한 기초 추정량(basic estimate)을 설계한다. 이 자체로는 최종 문제를 풀기에 충분하지 않지만, 최종 알고리즘의 빌딩 블록(building block) 역할을 한다.
- 상수(constant) 크기의 공간만 사용하지만 정밀도(precision) 분석이 필요하다.

## 내용

### 가정과 용어: head와 tail
- 데이터 항목들은 스트림 내 빈도의 내림차순으로 정렬되어 있다고 가정한다(항목 1이 가장 빈번).
- 예를 들어 top 4개 최빈 항목을 찾고자 한다면, 이 항목들을 스트림의 head(머리, 초록색으로 표시)라 부르고, 나머지 덜 빈번한 항목들을 tail(꼬리, 빨간색으로 표시)이라 부른다. head가 스트림 질량(mass)의 대부분을 차지한다.

### 기초 추정량(basic estimate)의 구성
- 균등 무작위(uniformly random) 부호 해시 함수(sign hash function) s를 선택한다. s는 데이터 항목의 전체 유니버스(1부터 m까지의 정수)를 −1 또는 +1로 독립적으로(independently) 매핑한다.
- 데이터 구조는 카운터(counter) C 하나만 유지한다. 스트림 시작 시 C = 0으로 초기화한다.
- 갱신(update) 절차: 새 데이터 항목 i를 받으면 C에 s(i)를 더한다. 즉 s(i) = +1이면 C를 증가시키고, s(i) = −1이면 C를 감소시킨다.
- 스트림 처리: 각 위치 p(1 ≤ p ≤ N)마다 위 갱신 절차를 수행한다.
- 추정(estimation): 스트림이 끝난 뒤 항목 i의 빈도를 질의받으면, C × s(i)를 추정치로 반환한다.

### 정밀도 분석 방법론
- 이 추정량은 무작위 변수(random variable)이므로, "카운터 × s(i)"라는 확률 변수가 실제 값 fi에 높은 확률로 가깝다는 것을 증명해야 한다.
- 증명은 보통 두 단계로 진행된다.
  1. 이 확률 변수의 기댓값(expectation)이 실제 값 fi와 같음을 보인다(즉, 추정량이 편향되지 않음, unbiased).
  2. 추정량이 그 평균(mean)에 높은 확률로 가깝다는 것을 보인다. 이를 위해 분산(variance)을 적절히 작게 bound한다. 분산이 충분히 작으면 표준적인 집중 부등식(concentration inequality)으로 결론을 얻는다.

### 1단계: 기댓값 계산
- C × s(i)를 다음과 같이 다시 쓸 수 있다: 스트림의 모든 위치 p(1~N)에 대한 합 = Σ_j f(j) · s(j) · s(i) (모든 데이터 항목 j에 대해, j의 빈도 f(j)와 부호의 곱).
- 이 중 항목 i 자신의 기여만 따로 떼어내면: f(i) · s(i)² = f(i) (s(i)² = 1이므로) 더하기, i가 아닌 다른 항목 j에 대한 합 Σ_{j≠i} f(j) · s(j) · s(i).
- 즉, C × s(i) = fi + (다른 항목들로부터의 노이즈 항).
- 양변에 기댓값을 취하면, fi는 상수이므로 그대로 남고, 노이즈 항의 기댓값은 합 안으로 들어가 각 항이 E[s(j)] · E[s(i)]가 된다(j ≠ i일 때 s(j)와 s(i)는 독립).
- s(j), s(i)는 각각 −1, +1을 동일 확률로 가지므로 평균이 0이다. 따라서 노이즈 항의 기댓값은 0이 되어, 전체 추정량의 기댓값은 정확히 fi가 된다.

## 예시
- 항목을 1~10 사이의 숫자로 표현한 스트림 예시에서, 빈도 내림차순으로 정렬된 항목들 중 상위 4개가 head, 나머지가 tail이 된다.
- s: {1, …, m} → {−1, +1}인 균등 무작위 함수, C는 스트림을 지나며 증감을 반복하는 단일 카운터.

## 요약
- 기초 추정량은 무작위 부호 함수와 단일 카운터만으로 구성된 매우 단순하고 상수 공간을 쓰는 방법이다.
- 이 추정량의 기댓값은 정확히 실제 빈도 fi와 같음(unbiased)을 증명했다.
- 다음 영상에서는 이 추정량의 분산(variance)을 계산하여, 높은 확률로 fi에 가까움을 보인다.
