# Using SAT-solvers

## 개요
- 이론과 실무의 간극을 보여주는 마무리 강의: SAT 솔버(SAT-solver)를 실무에서 활용하는 방법을, 스도쿠(Sudoku) 퍼즐 풀이 예제를 통해 설명한다.
- 이론적으로는 `2ⁿ`보다 빠른 SAT 알고리즘이 알려져 있지 않지만, 실무의 최신 SAT 솔버는 수천~수백만 개 변수를 가진 논리식도 1초 이내에 풀어낸다. 어려운 조합 문제를 SAT로 환원한 뒤 기존 SAT 솔버를 활용하는 실무 전략을 제시한다.

## 내용

### 이론과 실무의 간극
- 이론적으로, 현재까지 SAT를 `2ⁿ`보다 빠른(예: 다항식 × `1.99ⁿ`) 시간에 푸는 알고리즘은 알려져 있지 않다.
- 반면 실무의 최신 SAT 솔버는 수천, 심지어 수백만 개의 변수를 가진 인스턴스도 1초 이내에 처리한다.
- 이로부터 실무적 전략이 도출된다: (1) 풀고자 하는 어려운 조합 문제를 충족가능성 문제로 환원한다, (2) 이미 구현된 효율적인 SAT 솔버 프로그램을 사용한다.

### 스도쿠(Sudoku) 문제를 SAT로 환원하기
- 스도쿠: `9×9` 격자에 일부 칸이 숫자 1~9로 채워져 있고, 각 행(row), 각 열(column), 그리고 9개의 `3×3` 블록(block)이 모두 1~9의 숫자를 정확히 하나씩 포함하도록 나머지 칸을 채우는 문제.
- **변수 설계**: `i, j, k`가 각각 1부터 9까지일 때, 변수 `x_ijk`를 정의한다. `x_ijk = 1(참)`이면 칸 `(i, j)`에 숫자 `k`가 들어있다는 뜻이다. 총 `9 × 9 × 9 ≈ 700`개의 불리언 변수가 필요하다.

### 기술적 도구: "정확히 하나만 참(exactly one true)" 인코딩
- 리터럴 `l1, l2, l3`(일반적으로는 `l1, …, lk`) 중 정확히 하나만 참임을 CNF로 표현하는 방법:
  1. **최소 하나는 참**: `(l1 ∨ l2 ∨ l3)` 절 하나를 추가한다.
  2. **최대 하나만 참**: 모든 서로 다른 두 리터럴 쌍에 대해 `(¬li ∨ ¬lj)` 형태의 절을 추가해, 두 리터럴이 동시에 참이 되는 것을 금지한다. 예: `(¬l1 ∨ ¬l2)`, `(¬l1 ∨ ¬l3)`, `(¬l2 ∨ ¬l3)`.
  - 일반적으로 `k`개의 리터럴이면, 긴 절 1개(모든 리터럴 포함)와 `k`개 중 2개를 고르는 조합 수인 `C(k, 2)`(약 `k²`)개의 절이 필요하다.
  - 이 절들을 모두 포함한 논리식의 임의의 만족 배정에서는, `l1, l2, l3` 중 정확히 하나만 참이 된다.

### 스도쿠 제약 조건의 인코딩
1. **각 칸(cell)에는 숫자가 정확히 하나**: 모든 `(i, j)`에 대해, `x_ij1, x_ij2, …, x_ij9` 중 정확히 하나가 참.
2. **각 행에서 숫자 k는 정확히 한 번 등장**: 모든 `(i, k)`에 대해, `x_i1k, x_i2k, …, x_i9k` 중 정확히 하나가 참.
3. **각 열에서 숫자 k는 정확히 한 번 등장**: 모든 `(j, k)`에 대해, 해당 열의 9개 변수 중 정확히 하나가 참.
4. **각 3×3 블록에서 숫자 k는 정확히 한 번 등장**: 9개 블록 각각에 대해, 블록 내 9개 변수 중 정확히 하나가 참.
5. **이미 채워진 칸**: 칸 `(i, j)`에 숫자 `k`가 이미 주어져 있다면, 변수 `x_ijk`가 반드시 참이어야 함을 나타내는 단항 절(unit clause) 하나를 추가한다.
- 결과 논리식은 약 700개(정확히는 `9³ = 729`개) 변수를 가지며, 가능한 후보 배정의 탐색 공간은 약 `2^700 ≈ 10^200`으로 거대하다. 현대 컴퓨터가 이 모든 경우를 전수 탐색하는 것은 불가능하지만, 최신 SAT 솔버는 이 논리식을 눈 깜짝할 사이에 풀어낸다.

### MiniSAT 입력 형식과 사용 예
- 형식: 첫 줄에 `p cnf <변수 개수> <절 개수>`, 이어지는 각 줄이 하나의 절(변수는 정수, 음수는 부정, 각 줄 끝에 `0`).
  - 예: 변수 2개, 절 3개인 경우 —
    ```
    p cnf 2 3
    1 2 0
    1 -2 0
    -1 -2 0
    ```
  - MiniSAT을 이 논리식에 실행하면 즉시 충족 가능(satisfiable)하다고 보고한다.
  - 여기에 거짓인 절 `-1 -2 0`을 하나 더 추가하면(이미 제시된 3개 절과 모순), MiniSAT은 즉시 충족 불가능(unsatisfiable)이라고 보고한다.

### 파이썬 구현 개요
- 스도쿠 퍼즐을 입력받아 절 목록(list of clauses)을 구성하는 파이썬 코드.
  - 변수 `digits`: 1~9의 숫자 목록.
  - 각 변수 `(i, j, k)`에 고유한 정수 인덱스를 반환하는 메서드(MiniSAT에 넘기기 위함).
  - 리터럴 목록을 받아 "정확히 하나만 참"을 표현하는 절들을 작성하는 메서드: 전체 리터럴을 포함하는 절 하나와, 모든 리터럴 쌍에 대해 negated 쌍 절을 추가.
  - 위 메서드를 이용해 (1) 각 칸에 숫자 하나, (2) 각 행에서 각 숫자가 한 번, (3) 각 열에서 각 숫자가 한 번, (4) 각 블록(시작 위치 1, 4, 7의 조합)에서 각 숫자가 한 번, 이라는 제약을 순서대로 작성.
  - 입력 퍼즐에서 이미 채워진 칸을 읽어 해당 변수에 대한 단항 절 추가.
  - 모든 절을 `tmp.cnf` 파일에 `p cnf <변수 수> <절 수>` 형식으로 기록(각 절 끝에 `0` 추가).
  - MiniSAT을 호출해 `tmp.cnf`를 입력으로, `tmp.sat`을 출력 파일로 지정해 실행.
  - `tmp.sat`의 첫 줄이 `UNSAT`이면 해가 없다고 보고하고, `SAT`이면 둘째 줄의 만족 배정을 파싱해 각 칸의 숫자를 출력.
- 이 스크립트를 실행하면 즉시 스도쿠 퍼즐의 해를 찾아낸다. 퍼즐을 의도적으로 모순되게 수정(예: 같은 행에 숫자 5를 두 번 넣음)하면, 스크립트는 즉시 해가 없음을 보고한다.

## 예시
- 2변수, 3절 CNF 예시 `p cnf 2 3` (`x1 ∨ x2`, `x1 ∨ ¬x2`, `¬x1 ∨ ¬x2`)는 MiniSAT으로 즉시 충족 가능함이 확인된다.
- 여기에 절 `¬x1 ∨ ¬x2`(중복이 아니라 새로운 모순 절, 원문 기준 `-1 -2 0` 추가)를 더하면 충족 불가능이 된다.
- 스도쿠 인스턴스: 약 729개 변수, 탐색 공간 `10^200`이지만 MiniSAT이 즉시 해를 찾아낸다.

## 요약
- SAT의 이론적 최선 알고리즘은 여전히 지수 시간(`2ⁿ` 근방)이지만, 실무의 SAT 솔버는 수천~수백만 변수 규모의 인스턴스도 매우 빠르게 처리한다.
- 실무 전략은 어려운 조합 문제를 SAT로 환원한 뒤 기존 SAT 솔버(예: MiniSAT)를 활용하는 것이며, 스도쿠는 `x_ijk`(칸에 숫자 배정) 변수와 "정확히 하나만 참" 인코딩을 이용해 자연스럽게 SAT로 환원된다.
- 약 729개 변수, `10^200` 크기의 탐색 공간을 가진 스도쿠 인스턴스도 MiniSAT은 즉시 해결한다.
