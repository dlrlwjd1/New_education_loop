# Reductions

## 개요
- 환원(reduction)은 하나의 탐색 문제가 다른 탐색 문제보다 "적어도 그만큼 어렵다"는 것을 형식화하는 도구다.
- 문제 A가 문제 B로 환원(reduce)된다는 것은, B에 대한 다항 시간 알고리즘을 블랙박스(black box)로 사용해 A를 다항 시간에 풀 수 있다는 뜻이다.
- 이 개념을 바탕으로 NP-완전(NP-complete) 문제를 정의한다: 모든 다른 탐색 문제가 환원되는(reduce to) 문제.

## 내용

### 환원의 직관과 파이프라인
- A가 B로 환원된다(`A ≤ B`로 표기)는 것은, B를 위한 다항 시간 알고리즘을 블랙박스로 사용해 A의 인스턴스를 다항 시간에 풀 수 있는 파이프라인이 존재한다는 뜻이다.
- 파이프라인 구조:
  1. A의 인스턴스 `I`를 다항 시간 알고리즘 `f`를 통해 B의 인스턴스 `f(I)`로 변환한다.
  2. B에 대한 (블랙박스) 다항 시간 알고리즘을 `f(I)`에 적용한다.
     - 만약 `f(I)`에 대한 해가 없다면, `I`에 대해서도 해가 없다고 보고한다.
     - 만약 `f(I)`에 대한 해 `S`가 있다면, 다항 시간 알고리즘 `h`를 사용해 `S`를 `I`의 해 `h(S)`로 되돌려 변환한다.

### 환원의 형식적 정의
- 두 탐색 문제 A, B에 대해, "A가 B로 환원된다(`A ≤ B`)"는 것은 다음을 만족하는 한 쌍의 다항 시간 알고리즘 `f`, `h`가 존재한다는 것이다.
  - `f`는 A의 임의의 인스턴스 `I`를 B의 인스턴스 `f(I)`로 변환한다.
  - `f(I)`에 대한 해가 없다면, `I`에 대한 해도 없다.
  - `f(I)`에 대한 해 `S`가 있다면, `h(S)`는 `I`에 대한 해가 된다.

### NP-완전(NP-complete)의 정의
- 모든 탐색 문제(NP 클래스)를 정점으로, "문제 A가 문제 B로 환원되면 A에서 B로 향하는 방향 간선(directed edge)을 긋는" 큰 그래프를 상상할 수 있다.
- **NP-완전(NP-complete)**: 다른 모든 탐색 문제가 이 문제로 환원되는 문제. 즉, 이 문제(정점)로 모든 다른 문제로부터 간선이 들어온다("이 문제가 다른 모든 문제를 끌어당긴다").
- NP-완전 문제에 대한 다항 시간 알고리즘이 있다면, 그것을 블랙박스로 사용해 다른 모든 탐색 문제도 다항 시간에 풀 수 있다.
- 이런 NP-완전 문제가 실제로 존재하는지는 자명하지 않지만, 이후 강의에서 실제로 존재함을 증명한다.
- 지금까지 다룬 문제들 — 충족가능성 문제(SAT), 외판원 문제(TSP), 최대 독립집합 문제, 최장 경로 문제, 정수 선형 계획법 문제 — 모두 NP-완전임을 보일 예정이다. 즉, 이들 중 어느 하나에 대해서라도 다항 시간 알고리즘을 만들면, 모든 탐색 문제를 다항 시간에 풀 수 있게 된다.

## 요약
- A가 B로 환원된다는 것은, B에 대한 다항 시간 알고리즘을 블랙박스로 써서 A를 다항 시간에 풀 수 있다는 뜻이며, 이는 변환 알고리즘 `f`(인스턴스 변환)와 `h`(해 역변환)의 쌍으로 형식화된다.
- NP-완전 문제는 NP에 속한 모든 문제가 환원되어 오는 문제로, 이 문제에 대한 효율적 알고리즘은 곧 모든 NP 문제에 대한 효율적 알고리즘을 의미한다.
- SAT, TSP, 독립집합, 최장 경로, ILP 등이 모두 NP-완전임이 이후 강의에서 증명된다.
