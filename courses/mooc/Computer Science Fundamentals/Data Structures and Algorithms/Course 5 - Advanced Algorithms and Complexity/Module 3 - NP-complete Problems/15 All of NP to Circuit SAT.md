# All of NP to Circuit SAT

## 개요
- NP-완전성 증명의 마지막 핵심 단계: 임의의 탐색 문제(NP 클래스의 모든 문제) A를 Circuit SAT로 환원한다.
- 핵심 통찰은 "컴퓨터 자체가 하나의 (불리언) 회로"라는 것이다. 이를 이용해, 어떤 탐색 문제의 검증 알고리즘이든 회로로 변환할 수 있다.
- 이로써 이번 모듈에서 다룬 전체 환원 체인이 완성되고, 독립집합, 정점 커버, 3-SAT, SAT, Circuit SAT가 모두 NP-완전임이 확립된다.

## 내용

### 임의의 탐색 문제를 회로로 표현하기
- 특정 탐색 문제 A를 생각하자. A의 인스턴스가 그래프인지, 불리언 논리식/회로인지, 숫자인지, 선형 부등식 시스템인지조차 몰라도 된다. 아는 것은 오직 "A가 탐색 문제(search problem)"라는 사실뿐이다.
- A가 탐색 문제라는 것은, 어떤 알고리즘 `C`가 존재해 인스턴스 `I`와 후보 해 `S`에 대해 `I`의 길이에 대해 다항 시간에 `S`가 `I`의 해인지 검증한다는 뜻이다(또한 후보 해 `S`의 길이는 `I`의 길이에 대해 다항식으로 제한된다).
- **핵심 관찰**: 컴퓨터 역시 하나의 회로다. 낮은 수준(low level)에서 비트(bit)와 불리언 값으로 동작하는 불리언 회로이며, 각 컴퓨터는 고정된 상수 크기의 회로다.
- 검증 알고리즘 `C`를 입력 `I`, `S`에 대해 실행하면, 컴퓨터는 `I`의 크기에 대해 다항식 개수의 단계(step)를 수행한다. 각 단계를 대응하는 회로로 치환하면, 여러 회로가 이어진 시퀀스(각 회로는 이전 회로들이 계산한 값을 이용해 새 값을 계산)를 얻는다.
- 이 시퀀스의 첫 회로는 인스턴스 `I`와 후보 해 `S`에 대응하는 비트들을 입력으로 사용하며, 전체 시퀀스는 `I`의 크기에 대해 다항식 개수의 회로로 구성된다.
- 결과적으로, `I`의 길이에 대해 다항 크기(다항 개수의 게이트)를 가지며, `S`가 `I`의 실제 해일 때에만 1을 출력하는 하나의 (거대한) 회로를 얻는다.

### 환원의 완성
- 이 회로는 입력 변수로 (1) 인스턴스 `I`를 인코딩하는 비트들과 (2) 후보 해를 인코딩하는 비트들을 갖는다.
- 특정 인스턴스 `I`에 대해, `I`를 인코딩하는 입력 비트들을 상수 값으로 고정(plug in)한다.
- 그러면 남는 것은, 입력 변수가 오직 해 후보를 인코딩하는 비트들뿐이고, 이 회로가 1을 출력하는 것과 그 후보가 인스턴스 `I`에 대한 실제 해인 것이 동치인 회로다.
- 이제 이 회로를 Circuit SAT에 대한 블랙박스 알고리즘의 입력으로 사용해, 그런 해가 존재하는지(그리고 존재한다면 무엇인지) 찾을 수 있다.
- 결론적으로, 임의의 탐색 문제 A는 Circuit SAT로 환원된다. Circuit SAT에 대해 임의의 회로의 만족 배정을 찾는 다항 시간 알고리즘이 있다면, 그것으로 임의의 탐색 문제 A도 다항 시간에 풀 수 있다는 뜻이다.

### 전체 환원 체인 요약
1. 독립집합 문제(Independent Set) → 정점 커버 문제(Vertex Cover)
2. 3-SAT → 독립집합 문제
3. 충족가능성 문제(SAT) → 3-SAT
4. 모든 탐색 문제(NP의 모든 문제) → Circuit SAT → SAT
- 이 체인 전체를 통해, 슬라이드에 등장한 네 문제(독립집합, 정점 커버, 3-SAT, SAT)가 모두 NP-완전(NP-complete)임이 증명된다. 즉, 임의의 탐색 문제가 이 네 문제로 환원된다.

## 요약
- 컴퓨터는 본질적으로 고정 크기의 불리언 회로이므로, 임의의 탐색 문제의 검증 알고리즘 실행 과정을 다항 개수의 회로 시퀀스로 치환할 수 있다.
- 인스턴스 `I`에 대응하는 입력 비트를 상수로 고정하면, 남은 회로는 "해 후보를 인코딩하는 입력에 대해 1을 출력하는 것 = 그 후보가 실제 해인 것"이 되고, 이를 Circuit SAT의 블랙박스 알고리즘으로 풀 수 있다.
- 이로써 임의의 탐색 문제(NP의 모든 문제)가 Circuit SAT로, 그리고 (이전 강의를 통해) SAT로 환원되며, 독립집합·정점 커버·3-SAT·SAT가 모두 NP-완전임이 확립된다.
