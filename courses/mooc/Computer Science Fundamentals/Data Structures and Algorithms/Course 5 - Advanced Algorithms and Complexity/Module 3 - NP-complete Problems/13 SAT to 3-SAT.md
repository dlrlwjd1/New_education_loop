# SAT to 3-SAT

## 개요
- 일반 충족가능성 문제(SAT, 절의 길이 제한 없음)를 그 특수 버전인 3-충족가능성 문제(3-SAT, 각 절이 최대 3개 리터럴)로 환원한다.
- 핵심 아이디어는 새로운 보조 변수(fresh variable)를 도입해, 긴 절(long clause)을 하나의 3-절과 원래보다 짧은 절로 나누는 것을 반복하는 것이다.

## 내용

### 목표: 동치 충족가능(equisatisfiable) 3-CNF 생성
- CNF 논리식 `F`를 입력받아, `F`와 **동치 충족가능(equisatisfiable)**한 3-CNF 논리식 `F'`(각 절이 리터럴 최대 3개)를 만드는 다항 시간 알고리즘을 설계해야 한다.
- 동치 충족가능이란: `F`가 충족 가능 ⟺ `F'`가 충족 가능(반드시 같은 만족 배정을 가진다는 뜻은 아님).

### 긴 절을 짧게 나누는 변환
- 리터럴이 3개를 초과하는 절 `C`를 생각하자. `C`에서 두 개의 리터럴 `l1`, `l2`를 뽑고, 나머지 리터럴 전체를 `A`라 하자.
- 새로운 변수 `y`를 도입하고, 절 `C`를 다음 두 절로 대체한다.
  1. `(l1 ∨ l2 ∨ y)` — 길이 3.
  2. `(¬y ∨ A)` — 원래 절보다 리터럴 하나가 적다(길이가 1 줄어듦).
- 이 절차를 긴 절이 하나도 남지 않을 때까지 반복한다. 매 단계마다 긴 절을 더 짧은 절로 바꾸므로 언젠가는 반드시 끝난다.

### 실행 시간(다항 시간) 분석
- 각 반복마다 절이 더 짧아지므로, 전체 반복 횟수는 입력 논리식의 모든 절에 있는 리터럴 총 개수로 상한이 잡힌다. 이는 입력 논리식 길이에 대해 명백히 다항식이다.

### 정확성(correctness) 증명
- `F`(긴 절 `C`를 포함)와 `F'`(`C`를 `(l1 ∨ l2 ∨ y)`와 `(¬y ∨ A)`로 대체한 논리식)가 동치 충족가능함을 보인다.
- **(⇒) F가 충족 가능하면 F'도 충족 가능**
  - `F`의 만족 배정을 하나 취한다. `F`와 `F'`의 변수 집합 차이는 `y` 하나뿐이므로, `y`의 값만 적절히 정하면 된다.
  - `F'`의 나머지 절들은 `F`를 만족시키는 배정 그대로 만족된다. 남은 것은 새로 생긴 두 절을 모두 만족시키도록 `y`를 정하는 것이다.
  - 만약 현재 배정이 `l1` 또는 `l2` 중 하나를 이미 만족시킨다면, `y = 0`으로 둔다. 그러면 첫 절은 `l1`/`l2`에 의해, 둘째 절은 `¬y`(=1)에 의해 만족된다.
  - 만약 `l1`과 `l2`가 모두 거짓이라면, `A`의 리터럴 중 적어도 하나는 (원래 `C`가 만족되었으므로) 참이어야 한다. 이때 `y = 1`로 둔다. 그러면 첫 절은 `y`에 의해, 둘째 절은 `A`의 참인 리터럴에 의해 만족된다.
- **(⇐) F'가 충족 가능하면 F도 충족 가능**
  - `F'`의 만족 배정에서 `y`의 값을 그냥 버리면 `F`의 만족 배정이 된다.
  - 이를 보이려면 원래 절 `C`가 만족됨을 보여야 한다. 귀류법(contradiction)으로, 만약 `l1 = 0`, `l2 = 0`이고 `A`의 모든 리터럴도 `0`이라고 가정하면, `y`를 어떤 값으로 두어도 두 새 절 중 적어도 하나가 만족되지 않는다(`y=0`이면 첫 절 위반, `y=1`이면 둘째 절 위반). 이는 `F'`가 만족되었다는 가정에 모순이므로, `C`의 리터럴 중 적어도 하나는 참이어야 하고, 따라서 `C`는 만족된다.

## 요약
- SAT를 3-SAT로 환원하려면, 리터럴이 4개 이상인 절마다 새 변수 `y`를 도입해 `(l1 ∨ l2 ∨ y)`와 `(¬y ∨ A)`(나머지 리터럴 `A`)의 두 절로 반복해서 쪼갠다.
- 이 과정은 절의 길이를 매번 줄이므로 다항 시간에 끝나며, 원래 논리식과 결과 논리식은 동치 충족가능(equisatisfiable)함이 증명된다.
