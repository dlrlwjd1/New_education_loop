# Integer Linear Programming Problem

## 개요
- 정수 선형 계획법 문제(Integer Linear Programming, ILP)는 선형 부등식(linear inequality) 시스템이 주어졌을 때, 모든 부등식을 만족시키는 정수(integer) 값을 변수들에 배정하는 문제다.
- 실수(real number) 해를 허용하는 일반 선형 계획법(Linear Programming)은 효율적으로 풀 수 있지만, 해가 정수여야 한다는 제약을 추가하면 다항 시간 알고리즘이 알려지지 않은 매우 어려운 문제가 된다.

## 내용

### 문제 정의
- 입력: 행렬(matrix) 형태로 표현된 선형 부등식들의 집합.
- 목표: 모든 부등식을 만족시키는 정수 값을 각 변수에 배정.
- 예시(2변수 `x1`, `x2`, 3개 부등식):
  1. `x1 ≥ 1/2`
  2. `-x1 + 8x2 ≥ 0`
  3. `-x1 - 8x2 ≥ -8`
- 각 부등식은 하나의 반평면(half-space)에 대응하며, 이 세 반평면의 교집합은 삼각형(convex polygon)으로 나타난다. 이 삼각형 안의 점들이 부등식들을 만족하는 실수 해(feasible point) 전체다.

### 정수 제약이 문제를 어렵게 만드는 이유
- 위 예시에서 삼각형 영역 안에는 정수 점(integer point)이 하나도 없을 수 있다. 즉, 실수 해는 존재하지만 정수 해는 존재하지 않는 경우가 생긴다.
- **선형 부등식 시스템의 해(실수 해)를 찾는 문제**는 심플렉스법(simplex method)으로 실무에서 잘 풀 수 있다. 다만 심플렉스법 자체의 실행 시간은 다항 시간으로 보장되지 않으며(병리적 사례에서는 지수 시간이 될 수 있음), 대신 타원체법(ellipsoid method)이나 내부점법(interior point method) 같은 방법은 다항 시간 상한이 증명되어 있다. 어느 쪽이든 실수 해는 효율적으로 구할 수 있다.
- 하지만 해가 반드시 **정수**여야 한다는 제약을 추가하면, 현재까지 다항 시간 알고리즘이 알려지지 않은 매우 어려운 문제(ILP)가 된다.

## 요약
- 정수 선형 계획법(ILP)은 선형 부등식을 만족하는 정수 해를 찾는 문제다.
- 실수 해만 요구하는 일반 선형 계획법은 심플렉스법, 타원체법, 내부점법 등으로 효율적으로 풀 수 있지만, 해가 정수여야 한다는 제약이 추가되면 다항 시간 알고리즘이 알려지지 않은 어려운 문제로 바뀐다.
