# Independent Set Problem

## 개요
- 독립집합 문제(Independent Set Problem)는 그래프와 예산(budget) `b`가 주어졌을 때, 서로 간선으로 연결되지 않은 정점을 `b`개 이상 선택할 수 있는지 판별하는 문제다.
- 일반 그래프에서는 다항 시간 알고리즘이 알려져 있지 않지만, 입력 그래프가 트리(tree)로 한정되면 간단한 그리디(greedy) 전략으로 선형 시간에 최적 해를 구할 수 있다.

## 내용

### 문제 정의
- 입력: 그래프, 예산 `b`.
- 목표: 어떤 두 선택된 정점 사이에도 간선이 없도록 최소 `b`개의 정점을 선택.
- 탐색 문제로서 검증은 쉽다 — 주어진 정점 집합의 크기가 `b` 이상이고, 그 안에 서로 연결된 두 정점이 없는지 확인하면 된다.

### 트리에서의 그리디 알고리즘
- 트리에서 최대 크기의 독립집합을 찾는 문제는 다음과 같은 간단한 그리디 전략으로 풀 수 있다.
  1. 트리의 모든 잎(leaf) 정점을 해(solution)에 포함시킨다.
  2. 포함된 잎들과 그 부모(parent)를 트리에서 제거한다.
  3. 남은 트리에 대해 이 과정을 반복한다.
- **최적성 증명(안전한 이동, safe move)**: "모든 잎을 선택하는 것이 최적해와 모순되지 않는다(safe)"는 것을 다음과 같이 보인다.
  - 모든 잎을 포함하지 않는 어떤 최적해가 있다고 가정한다(예: 특정 잎 몇 개가 빠진 부분최적 해).
  - 이 해를 변형해, 표시된 잎들을 전부 해에 포함시키고 그로 인해 필요하면 그 부모들을 해에서 제외한다.
  - 이렇게 변형해도 해의 크기는 줄어들지 않으며(이 예시에서는 크기가 그대로 유지됨), 결과적으로 모든 잎을 포함하는 또 다른 최적해를 얻는다.
  - 따라서 "모든 잎을 선택"하는 것이 항상 안전한(safe) 선택이며, 이를 반복해 최적해를 구성할 수 있다.
- 이 알고리즘은 트리에서 선형 시간(linear time)에 동작한다.

## 예시
- 8개 정점 그래프에서 크기 7의 독립집합이 존재하는 예: 선택된(빨간색) 정점들 사이에 어떤 간선도 없음을 확인할 수 있다.

## 요약
- 독립집합 문제는 서로 연결되지 않은 정점을 최대한 많이(또는 `b`개 이상) 선택하는 문제다.
- 트리에서는 "잎부터 그리디하게 선택하고 부모를 제거"하는 전략으로 선형 시간에 최적해를 구할 수 있다.
- 그러나 일반 그래프에서는 크기 `b` 이상의 독립집합이 존재하는지조차 판별하는 다항 시간 알고리즘이 알려져 있지 않다.
