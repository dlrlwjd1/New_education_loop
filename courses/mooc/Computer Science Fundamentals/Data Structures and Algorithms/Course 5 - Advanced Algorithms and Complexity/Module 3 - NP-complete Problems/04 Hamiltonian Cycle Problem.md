# Hamiltonian Cycle Problem

## 개요
- 해밀턴 사이클 문제(Hamiltonian Cycle Problem)는 방향 없는(가중치 없는) 그래프에서 모든 정점을 정확히 한 번씩 방문하는 사이클이 존재하는지 판별하는 문제로, 다항 시간 알고리즘이 알려져 있지 않다.
- 겉보기엔 비슷한 오일러 사이클 문제(Eulerian Cycle Problem, 모든 간선을 정확히 한 번씩 방문)는 반대로 매우 효율적으로(선형 시간에) 풀 수 있다. 두 문제를 대비시켜 "비슷해 보이는 문제도 난이도가 크게 다를 수 있음"을 보여준다.

## 내용

### 해밀턴 사이클 문제
- 입력: 방향 없는, 가중치 없는 그래프.
- 목표: 모든 정점을 정확히 한 번씩 방문하는 사이클이 있는지 판별.
- 탐색 문제로서 검증은 쉽다 — 주어진 정점 시퀀스가 각 정점을 정확히 한 번 포함하고, 연속한 두 정점 사이에 간선이 있는지 확인하면 된다.
- 그러나 이런 사이클을 실제로 찾는 다항 시간 알고리즘은 알려져 있지 않다.

### 오일러 사이클 문제와 비교
- 오일러 사이클 문제: 모든 간선을 정확히 한 번씩 방문하는 사이클을 찾는 문제(정점이 아니라 간선 기준).
- **정리(theorem)**: 무방향 그래프가 오일러 사이클을 가지려면, (1) 그래프가 연결(connected)되어 있고, (2) 모든 정점의 차수(degree)가 짝수(even)이어야 하고, 그럴 때만(if and only if) 오일러 사이클이 존재한다.
- **필요조건(차수가 짝수여야 함)에 대한 직관적 증명**: 어떤 정점 `v`의 차수가 3(홀수)이면 오일러 사이클이 존재할 수 없다.
  - 사이클이 `v`를 정확히 한 번 방문한다고 가정하면, `v`에 들어오는 간선 하나와 나가는 간선 하나, 총 2개의 간선만 사용되어 차수는 2여야 하는데 실제 차수는 3이므로 모순.
  - `v`를 두 번 이상 방문한다고 가정해도, 각 방문마다 들어오고 나가는 두 간선 쌍이 필요하므로 차수는 짝수(2, 4, 6, …)여야 하는데 3은 홀수이므로 모순.
  - 일반적으로, 오일러 사이클이 존재하면 각 정점에 들어올 때마다 나가는 데 쓸 짝을 이루는 간선이 필요하므로 모든 정점의 차수는 짝수여야 한다.

### 오일러 사이클을 구성하는 방법 (충분조건의 아이디어)
- 그래프가 연결되어 있고 모든 정점의 차수가 짝수라면, 다음과 같이 오일러 사이클을 구성할 수 있다.
  1. 임의의 정점에서 시작해 아직 사용하지 않은 간선을 따라 걷다가, 더 이상 사용 가능한 간선이 없는 정점(출발점)으로 돌아오면 하나의 사이클이 완성된다.
  2. 아직 사용되지 않은 간선이 남아 있다면, 그 간선들이 포함된 정점에서 새로 시작해 또 다른 사이클을 만든다.
  3. 이 과정을 모든 간선이 사용될 때까지 반복하면 여러 개의 작은 사이클들이 만들어진다.
  4. 그래프가 연결되어 있으므로 이 작은 사이클들은 서로 접점(공유 정점)을 가지며, 이를 이용해 여러 사이클을 하나의 큰 사이클로 이어 붙일(glue) 수 있다.
- 즉, 그래프의 연결성(connectedness)이 여러 사이클을 하나로 이어 붙이는 것을 보장한다.

## 예시
- 차수가 3인 정점을 포함한 그래프는 오일러 사이클을 가질 수 없다(위 증명 참고).
- 모든 정점의 차수가 짝수(2, 4, 4, 6, 2, 4)이고 연결된 그래프에서는, 임의의 정점에서 시작해 세 개의 부분 사이클을 만든 뒤 이를 이어 붙여 하나의 오일러 사이클을 완성할 수 있다.

## 요약
- 해밀턴 사이클 문제(모든 정점을 한 번씩 방문)는 다항 시간 알고리즘이 알려지지 않은 어려운 문제다.
- 오일러 사이클 문제(모든 간선을 한 번씩 방문)는 "연결되어 있고 모든 정점의 차수가 짝수"라는 조건으로 완전히 특징지어지며 선형 시간에 풀 수 있다.
- 겉보기엔 유사한 두 문제(정점 기준 vs 간선 기준)의 난이도가 극명하게 갈리는 대표적 사례다.
