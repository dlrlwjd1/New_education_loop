# Traveling Salesman Problem

## 개요
- 외판원 문제(Traveling Salesman Problem, TSP)는 가중치 그래프에서 모든 정점을 정확히 한 번씩 방문하고 총 길이가 예산(budget) `b` 이하인 사이클(cycle)을 찾는 문제다.
- 배송 회사의 최단 경로 문제, 회로 기판(circuit board) 드릴링처럼 실무 응용이 많지만, 최적화 버전이든 결정 버전(decision version)이든 알려진 다항 시간 알고리즘이 없는 대표적인 어려운 문제다.

## 내용

### 문제 정의
- 입력: 정점 간 거리를 알고 있는 그래프, 예산 `b`.
- 목표: 모든 정점을 정확히 한 번 방문하며 총 길이가 `b` 이하인 사이클을 찾는다.
- 원래 TSP는 최적화 문제(optimization problem, 최소 총 길이의 사이클을 찾는 것)이지만, 이를 탐색 문제(search problem)로 만들기 위해 예산 `b`를 두고 결정 버전(decision version)으로 서술한다.
  - 결정 버전에서는 주어진 해(사이클)가 실제로 해인지(모든 정점을 정확히 한 번 방문하고 길이가 `b` 이하인지) 쉽게 검증할 수 있다.
  - 반면 최적화 버전에서는 주어진 사이클이 최적인지 직접 검증하기 어렵다.
- 최적화 버전과 결정 버전은 알고리즘적으로 거의 차이가 없다.
  - 최적 사이클을 찾는 알고리즘이 있으면 결정 버전도 풀 수 있다(그 역도 가능).
  - 모든 `b`에 대해 길이 `b` 이하 사이클 존재 여부를 판정하는 알고리즘이 있으면, 이진 탐색(binary search)을 통해 로그(logarithmic) 횟수만 호출해 최적값을 찾을 수 있다.

### 알려진 알고리즘과 그 한계
- 순진한(naive) 방법: 모든 정점의 순열(permutation)을 탐색 — 실행 시간 약 `n!`. `n=15`일 때 `n!`은 약 10¹²로 완전히 비실용적이다.
- 더 나은 방법: 동적 계획법(dynamic programming)을 사용한 알고리즘으로 실행 시간이 `n² · 2ⁿ` — 여전히 지수 시간이지만 `n!`보다는 훨씬 낫다(이후 강좌에서 다룸).
- 현재까지 이보다 더 나은 알고리즘은 알려져 있지 않다. 예를 들어 `1.99ⁿ` 같은 실행 시간을 가진 알고리즘도 알려져 있지 않다.
- 실무에서는 다음과 같은 방식으로 다뤄진다.
  - **휴리스틱 알고리즘(heuristic algorithm)**: `n`이 수천 단위여도 실무 인스턴스를 잘 해결하지만, 실행 시간에 대한 이론적 보장은 없다.
  - **근사 알고리즘(approximation algorithm)**: 실행 시간에 대한 보장은 있지만, 반환하는 해가 최적은 아니고 최적보다 크게 나쁘지 않음이 보장된다(이후 강좌에서 다룰 알고리즘은 최적의 최대 2배 이내의 사이클을 다항 시간에 찾음).

### 최소 스패닝 트리(Minimum Spanning Tree)와의 비교
- 최소 스패닝 트리 문제(MST): 그래프(도시들의 집합)가 주어졌을 때, 모든 도시를 `n-1`개의 간선으로 연결하되 총 길이가 최소가 되도록 하는 문제. 이 문제는 거의 선형(almost linear) 시간에 풀 수 있다.
- TSP를 사이클이 아니라 경로(path)를 찾는 문제로 바꿔서 생각하면, 최적 경로 역시 모든 정점을 연결하는 트리(스패닝 트리)의 일종이다.
- 즉, TSP는 MST 문제에 "찾는 트리가 반드시 경로(path)여야 한다"는 추가 제약을 부과한 문제로 볼 수 있다.
- 이 작은 추가 제약 하나로 인해, 거의 선형 시간에 풀리던 문제(MST)가 다항 시간 알고리즘이 전혀 알려지지 않은 매우 어려운 문제(TSP)로 바뀐다.

## 예시
- 6개 도시 예시: MST는 5개 간선으로 모든 도시를 연결한다. 동일한 도시 집합에 대해 TSP(경로 버전)의 최적 경로 역시 5개 간선을 가진 트리이지만, 반드시 경로(path) 형태여야 한다는 제약이 추가된다.
- 독일의 15개 최대 도시를 방문하는 최적 사이클, 회로 기판에서 드릴로 뚫을 지점들을 최단 경로로 방문하는 문제가 실무 응용 예시다.

## 요약
- TSP는 모든 정점을 한 번씩 방문하는 최소(또는 예산 이하) 길이의 사이클을 찾는 문제로, 최적화 버전과 결정 버전은 실질적으로 동등하다.
- 순진한 알고리즘은 `n!` 시간, 동적 계획법 기반 알고리즘은 `n² · 2ⁿ` 시간이며, 더 나은 다항 시간 알고리즘은 알려져 있지 않다.
- 실무에서는 휴리스틱 알고리즘이나 근사 알고리즘(최적의 2배 이내 보장)으로 다룬다.
- TSP는 거의 선형 시간에 풀리는 MST 문제에 "스패닝 트리가 경로여야 한다"는 제약을 추가한 문제로 볼 수 있으며, 이 제약이 문제를 극도로 어렵게 만든다.
