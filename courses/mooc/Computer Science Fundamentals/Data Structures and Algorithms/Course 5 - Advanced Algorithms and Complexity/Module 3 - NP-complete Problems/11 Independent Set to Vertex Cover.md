# Independent Set to Vertex Cover

## 개요
- 독립집합 문제(Independent Set)를 정점 커버 문제(Vertex Cover Problem)로 환원(reduction)하는 방법을 다룬다.
- 두 문제는 "독립집합과 정점 커버는 서로 여집합(complement) 관계"라는 간단한 성질을 통해 매우 쉽게 서로 환원된다.

## 내용

### 정점 커버 문제의 정의
- 입력: 단순, 무가중치, 무방향 그래프와 예산 `b`.
- 목표: 그래프의 모든 간선을 커버(cover)하는 정점을 최대 `b`개 선택. 즉, 선택된 정점 집합의 크기가 `b` 이하이면서, 모든 간선이 적어도 하나의 끝점(endpoint)을 선택된 집합에 포함해야 한다.
- 독립집합 문제와 대비: 독립집합은 "최소 `b`개" 선택 + "선택된 정점 사이에 간선이 없어야" 하고, 정점 커버는 "최대 `b`개" 선택 + "모든 간선이 커버되어야" 한다.

### 핵심 성질: 독립집합과 정점 커버는 여집합 관계
- **명제**: 그래프 `G`에서 집합 `I`가 독립집합이다 ⟺ 여집합 `V \ I`가 정점 커버다.
- **증명**
  - (⇒) `I`가 독립집합이면, `I` 안의 어떤 두 정점도 간선으로 연결되지 않는다. 즉, 모든 간선은 적어도 한쪽 끝점이 `V \ I`에 있다. 따라서 `V \ I`는 정점 커버다.
  - (⇐) `V \ I`가 정점 커버이면, 모든 간선이 `V \ I`에 적어도 하나의 끝점을 가진다. 이는 어떤 간선도 두 끝점이 모두 `I`에 속하지 않는다는 뜻이므로, `I`는 독립집합이다.

### 환원의 구성
- 이 성질을 이용해, 그래프 `G`가 크기 `b` 이상의 독립집합을 가지는지 확인하려면, 같은 그래프 `G`가 크기 `|V| - b` 이하의 정점 커버를 가지는지 확인하면 된다.
- **알고리즘 f (인스턴스 변환)**: 독립집합 문제의 인스턴스 `(G, b)`를 받아, 그래프 `G`는 그대로 두고 예산을 `|V| - b`로 바꾼 정점 커버 문제의 인스턴스 `(G, |V| - b)`를 만든다.
- 정점 커버에 대한 블랙박스 알고리즘을 이 인스턴스에 대해 실행한다.
  - 크기 `|V| - b` 이하의 정점 커버가 없다고 나오면, 즉시 원래 그래프 `G`에 크기 `b` 이상의 독립집합이 없다고 보고한다.
  - 크기 `|V| - b` 이하의 정점 커버 `S`가 반환되면, **알고리즘 h (해 역변환)**: `S`의 여집합 `V \ S`를 취하면 이것이 크기 `b` 이상의 독립집합이 된다.
- 두 알고리즘 `f`, `h` 모두 명백히 다항 시간(사실상 상수/선형 시간)에 동작한다.

## 예시
- 8개 정점 그래프 예시:
  - `{E, C}`는 독립집합이지만 더 확장할 수 없다(다른 어떤 정점을 추가해도 기존 정점과 간선으로 연결됨).
  - `{A, C, F, H}`는 크기 4의 독립집합이다.
  - `V \ {E, C}`(즉, `{A, B, D, F, G, H}`, 크기 6)는 정점 커버다 — 모든 간선이 이 집합 안에 적어도 하나의 끝점을 가진다.
  - `{B, E, G, D}`는 더 작은 정점 커버(크기 4)의 예다.

## 요약
- 그래프 `G`에서 `I`가 독립집합인 것과 `V \ I`가 정점 커버인 것은 동치(if and only if)다.
- 이 성질을 이용해, 독립집합 문제의 인스턴스 `(G, b)`를 정점 커버 문제의 인스턴스 `(G, |V| - b)`로 변환하고, 반환된 정점 커버의 여집합을 취해 독립집합 문제의 해로 되돌리는 간단한 다항 시간 환원을 구성할 수 있다.
