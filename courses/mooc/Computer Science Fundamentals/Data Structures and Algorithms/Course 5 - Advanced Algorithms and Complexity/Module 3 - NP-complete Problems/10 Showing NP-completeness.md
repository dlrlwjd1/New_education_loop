# Showing NP-completeness

## 개요
- NP-완전성(NP-completeness)을 환원(reduction)을 통해 증명하는 일반적인 방법을 다룬다.
- 환원을 활용하는 두 가지 동치(equivalent) 방식, 환원의 합성(composition) 성질, 그리고 이를 이용해 NP-완전성을 연쇄적으로 전파하는 방법을 설명한다.
- 마지막으로 이번 모듈에서 증명할 환원들의 전체 계획(로드맵)을 제시한다.

## 내용

### 환원을 사용하는 두 가지 방식
1. **A ≤ B이고 B가 쉬우면(효율적 알고리즘 존재) → A도 쉽다.** 정의상 B에 대한 다항 시간 알고리즘을 블랙박스로 써서 A를 풀 수 있기 때문이다.
2. **(대우, contrapositive) A ≤ B이고 A가 어려우면(다항 시간 알고리즘 없음) → B도 어렵다.** 만약 B가 쉬웠다면 1번에 의해 A도 쉬웠을 것이므로 모순이다. 따라서 B에는 다항 시간 알고리즘이 있을 수 없다.

### 환원의 합성(composition) 성질
- **핵심 사실**: A가 B로 환원되고, B가 C로 환원되면, A는 C로 환원된다(추이성, transitivity).
- **증명**: A ≤ B는 다항 시간 알고리즘 쌍 `f_AB`, `h_AB`로, B ≤ C는 `f_BC`, `h_BC`로 주어진다.
  - A의 인스턴스 `I_A`를 C의 인스턴스로 변환하려면, 먼저 `f_AB`를 적용해 B의 인스턴스를 얻고, 여기에 `f_BC`를 적용해 C의 인스턴스를 얻는다(함수 합성, composition of functions).
  - **실행 시간이 여전히 다항 시간임**: 예를 들어 `f_AB`의 실행 시간이 `p(n) = n³`이고 `f_BC`의 실행 시간이 `q(n) = n⁵`라면, 합성 알고리즘의 실행 시간은 `p(q(n)) = (n⁵)³ = n¹⁵`이 된다. 즉, 두 다항 함수를 합성하면 여전히 다항 함수가 된다.
  - 해를 되돌리는 방향도 마찬가지로, C의 해 `S_C`에 `h_BC`를 적용해 B의 해를 얻고, 여기에 `h_AB`를 적용해 A의 해를 얻는다.
- 그래프로 표현하면: A→B, B→C 간선이 있으면 A→C 간선도 존재한다.

### NP-완전성의 전파
- A가 B로 환원되고 A가 NP-완전이면, B도 NP-완전이다.
- **증명(그래프 관점)**: A가 NP-완전이라는 것은 다른 모든 문제에서 A로 향하는 간선이 있다는 뜻이다. A에서 B로 향하는 간선도 있으므로, 환원의 합성 성질에 의해 다른 모든 문제에서 B로 향하는 간선도 존재한다. 따라서 B도 다른 모든 문제를 끌어당기므로 NP-완전이다.
- 이 성질 덕분에, NP-완전임이 이미 알려진 문제 하나에서 새로운 문제로 환원을 하나만 보이면 그 새로운 문제도 NP-완전임을 증명할 수 있다.

### 이번 모듈의 환원 계획
1. 독립집합 문제(Independent Set) → 정점 커버 문제(Vertex Cover)
2. 3-충족가능성 문제(3-SAT) → 독립집합 문제(Independent Set)
3. 충족가능성 문제(SAT, 일반 버전) → 3-충족가능성 문제(3-SAT, 특수 버전)
4. 그 밖의 모든 탐색 문제 → SAT (이를 통해 SAT를 비롯해 위 세 문제 모두가 NP-완전임을 확립)

## 요약
- 환원 A ≤ B는 "B가 쉬우면 A도 쉽다" 및 그 대우 "A가 어려우면 B도 어렵다"의 두 방식으로 활용된다.
- 환원은 합성(composition)이 가능하며, 두 다항 시간 환원을 합성해도 여전히 다항 시간 환원이 된다(추이성).
- A가 NP-완전이고 A ≤ B이면 B도 NP-완전이다. 이번 모듈은 독립집합 → 정점 커버, 3-SAT → 독립집합, SAT → 3-SAT, 모든 NP 문제 → SAT 순서로 환원을 구성해 이들 모두의 NP-완전성을 증명한다.
