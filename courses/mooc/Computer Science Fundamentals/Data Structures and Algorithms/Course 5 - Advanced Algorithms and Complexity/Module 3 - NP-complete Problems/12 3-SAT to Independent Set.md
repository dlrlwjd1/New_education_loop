# 3-SAT to Independent Set

## 개요
- 불리언 논리(Boolean logic)와 그래프를 연결하는 흥미로운 환원: 3-SAT 문제를 독립집합 문제(Independent Set)로 환원한다.
- 핵심 아이디어는 "각 절(clause)에서 만족시킬 리터럴(literal)을 하나씩 일관성(consistent) 있게 선택하는 것"을 그래프의 독립집합을 찾는 문제로 그대로 옮기는 것이다.

## 내용

### 3-SAT 문제
- 입력: 3-CNF 논리식(각 절이 리터럴 최대 3개의 논리합인 절들의 모음).
- 목표: 모든 절을 만족시키는 참/거짓 배정이 존재하는지 판별.
- 목표하는 환원: 3-CNF 논리식 `F`를 받아 그래프 `G`와 정수 `b`를 다항 시간에 만들어내되, `F`가 충족 가능(satisfiable) ⟺ `G`에 크기 `b` 이상의 독립집합이 존재하도록 한다.

### 충족가능성의 대안적 관점
- 논리식을 만족시킨다는 것은, 각 절에서 만족되는 리터럴을 최소 하나 갖도록 변수에 참/거짓을 배정하는 것이다.
- **대안적 정의**: 논리식을 만족시키려면, 각 절에서 리터럴을 하나씩 선택해 그 선택된 리터럴들의 집합이 **일관성(consistent)** 있어야 한다. 즉, 어떤 리터럴 `L`과 그 부정 `¬L`을 동시에 포함해서는 안 된다.
- 예: 절이 3개인 논리식에서 `{x, x, ¬z}` 같은 일관성 있는 리터럴 집합을 선택하면, 이를 만족시키는 배정(예: `x=1, z=0`)을 구성할 수 있다. `y`의 값은 이 경우 상관없다.
- 반대로 `{¬y, ¬y, ¬z}`처럼 리터럴 `y`와 `¬y`를 동시에 포함하는 집합은 일관성이 없으며, 이 경우 `y`에 어떤 값을 배정해도 어느 한쪽 절이 위반된다.

### 환원의 구성
1. **정점 생성**: 논리식의 각 절을 왼쪽부터 훑으며, 절의 길이(리터럴 개수: 1, 2, 또는 3)만큼 새 정점을 만들고 각 정점에 해당 리터럴로 레이블을 붙인다.
2. **블록 내부 완전 연결**: 같은 절(같은 "블록")에 속한 정점들끼리 모두 간선으로 연결한다. 길이 3인 절은 삼각형(triangle), 길이 2인 절은 하나의 간선이 된다.
   - 이렇게 하면 하나의 절 블록에서 최대 한 개의 정점만 독립집합에 포함될 수 있다(블록 내 어느 두 정점을 선택해도 간선으로 연결되어 있으므로).
3. **모순 리터럴 간 연결**: 서로 상반되는(complementary) 리터럴로 레이블된 모든 정점 쌍을 간선으로 연결한다. 즉, 정점이 리터럴 `L`로 레이블되어 있으면, `¬L`로 레이블된 모든 정점과 간선으로 연결한다.
   - 이렇게 하면 독립집합에 선택된 정점들의 레이블 집합이 일관성(consistent) 있게(모순 없이) 강제된다.
4. **결론**: 이렇게 구성된 그래프 `G`는, 절의 개수를 `b`라 할 때, `G`에 크기 `b`(정확히 절의 개수)의 독립집합이 존재하는 것과 원래 논리식 `F`가 충족 가능한 것이 동치다.

### 정확성(correctness) 증명
- **(⇒) 충족 가능하면 독립집합이 존재**: 각 절에서 만족시키는 리터럴을 하나씩 선택하면 일관성 있는 리터럴 집합을 얻는다. 각 블록에서 그 선택된 리터럴에 대응하는 정점을 고르면, 서로 다른 블록의 정점들은 오직 모순 관계일 때만 연결되는데, 선택된 리터럴 집합은 일관성이 있으므로 어떤 두 선택된 정점도 간선으로 연결되지 않는다. 따라서 크기 `b`(절의 개수)의 독립집합이 된다.
- **(⇐) 독립집합이 존재하면 충족 가능**: 크기 `b`의 독립집합은 (블록 내 완전 연결 제약으로 인해) 각 블록에서 정확히 하나의 정점을 가진다. 그 정점들의 레이블은 (모순 리터럴 간 연결 제약으로 인해) 일관성 있는 리터럴 집합을 이룬다. 이 리터럴 집합은 모든 절과 교차(intersect)하므로, 이에 대응하는 배정이 원래 논리식을 만족시킨다.

### 실행 시간(다항 시간) 분석
- 절의 개수를 `m`이라 하면:
  - 논리식을 스캔해 최대 `3m`개의 정점을 만드는 데 `O(m)` 시간.
  - 모든 정점 쌍을 검사해 모순 리터럴인 경우 간선을 추가하는 데 `O(m²)` 시간.
- 전체 변환은 다항 시간이다.

## 예시
- 5개 절, 3개 변수(`x, y, z`)로 이루어진 논리식 예시:
  - 각 절마다 2~3개의 정점을 만들고, 절 내부(블록)는 완전 그래프(삼각형 또는 간선)로 연결한다.
  - 예: 절 `{x, y, z}` → 삼각형 3개 정점, 절 `{x, ¬y}` → 간선으로 연결된 2개 정점.
  - `x`로 레이블된 정점과 `¬x`로 레이블된 정점들 사이에 모두 간선을 추가하고, `y`/`¬y`, `z`/`¬z`에 대해서도 마찬가지로 한다.
  - 이 그래프에 크기 5(절의 개수)의 독립집합이 존재하는 것과 원래 논리식이 충족 가능한 것이 동치다.

## 요약
- 3-SAT을 독립집합 문제로 환원하는 핵심 아이디어는 "논리식을 만족시키는 것 = 각 절에서 리터럴을 하나씩 일관성 있게 선택하는 것"이라는 관점을 그래프로 옮기는 것이다.
- 각 절을 정점 블록(내부는 완전 연결)으로, 모순되는 리터럴 쌍은 서로 간선으로 연결한 그래프 `G`를 구성하면, `G`의 크기 `b`(절의 개수) 독립집합 존재 여부와 논리식의 충족가능성이 동치가 된다.
- 이 변환은 `O(m²)` 시간(m = 절의 개수)에 수행되므로 다항 시간 환원이다.
