# Search Problems

## 개요
- 탐색 문제(search problem)를 형식적으로 정의하기 위해, 대표적 예시인 불리언 충족가능성 문제(Boolean Satisfiability Problem, SAT)를 소개한다.
- SAT는 논리곱 정규형(Conjunctive Normal Form, CNF) 형태의 논리식이 주어졌을 때 이를 만족시키는(satisfy) 참/거짓 배정이 존재하는지 판별하는 문제다.
- 탐색 문제의 일반적 정의: 인스턴스(instance) `I`와 후보 해(candidate solution) `S`가 주어졌을 때, `S`가 `I`의 해인지 다항 시간(polynomial time)에 검증할 수 있는 문제.

## 내용

### CNF와 SAT 문제
- CNF(논리곱 정규형) 논리식은 절(clause)들의 집합이다. 각 절은 리터럴(literal)들의 논리합(disjunction, OR)이다.
- 예: `x ∨ y ∨ z`, `x ∨ ¬y`, `y ∨ ¬z` 등의 절들로 이루어진 5개 절 논리식.
- 불리언 변수는 참(1) 또는 거짓(0) 값을 가진다.
- **SAT(Satisfiability Problem)**: CNF 논리식이 주어졌을 때, 모든 절을 만족시키는 참/거짓 배정(satisfying assignment)이 존재하는지 판별하고, 존재하면 그 배정을 출력하며, 존재하지 않으면(unsatisfiable) 그 사실을 보고한다.
- 하나의 논리식이 여러 개의 만족 배정(satisfying assignment)을 가질 수도 있다.
- 논리식이 충족 불가능(unsatisfiable)함을 보이는 방법
  1. 모든 가능한 참/거짓 배정(변수가 3개면 2³ = 8가지)을 나열해 각각이 적어도 하나의 절을 위반(falsify)함을 확인.
  2. 강제된 배정을 따라가며(예: `x=0`으로 두면 다른 절에 의해 `y=0`이 강제되고, 다시 다른 절에 의해 `z=0`이 강제되는데, 이때 마지막 절이 위반됨) 모순을 도출. `x=1`로 두어도 마찬가지로 모순에 도달함을 보이면 충족 불가능임이 증명된다.
- SAT는 계산 이론의 대표적인 어려운(canonical hard) 문제로, 컴퓨터 과학 여러 분야에 응용된다. 많은 어려운 조합 문제(combinatorial problem)가 SAT로 자연스럽게 환원(reduce)되며, 이후 SAT 솔버(SAT solver, 충족가능성 문제를 푸는 프로그램)를 사용해 해결할 수 있다.

### 탐색 문제(Search Problem)의 형식적 정의
- 탐색 문제에서는 인스턴스 크기 `I`가 주어지고, 목표는 이 인스턴스에 대한 해 `S`를 찾거나 해가 존재하지 않음을 보고하는 것이다.
- SAT의 경우: 인스턴스 `I`는 CNF 논리식, 해 `S`는 만족 배정.
- 탐색 문제가 갖춰야 할 자연스러운 성질 두 가지:
  1. **빠른 검증 가능성**: 주어진 해 `S`가 실제로 `I`의 해인지 빠르게(다항 시간에) 확인할 수 있어야 한다. SAT의 경우, 각 절을 왼쪽에서 오른쪽으로 훑으며 각 절에 만족되는 리터럴이 있는지 확인하면 된다.
  2. **해의 길이 제한**: 해 `S`의 길이는 인스턴스 `I`의 길이에 대해 다항식으로 제한(bounded by polynomial)되어야 한다. 그렇지 않으면 해를 적어 내려가는 데만 지수 시간이 걸릴 수 있다.
- 탐색 문제는 검증 알고리즘 `C`로 정의하는 것이 편리하다. `C`는 인스턴스 `I`와 후보 해 `S`를 입력으로 받아, `I`의 길이에 대해 다항 시간에 실행되며, `C(I, S)`가 참(true)을 반환하면 `S`는 `I`의 해라고 정의한다.
- SAT는 명백히 탐색 문제다: `I`는 CNF 논리식, `S`는 참/거짓 배정이고, 검증 알고리즘 `C`는 모든 절을 훑으며 각 절에 배정 `S`로 만족되는 리터럴이 있는지 확인하며, 이는 논리식 길이에 대해 다항 시간에 수행된다.

## 예시
- 논리식: `(x ∨ y) ∧ (x ∨ ¬y) ∧ (¬x)` 유형의 3개 절 예시에서, `x=1, y=0`은 만족 배정이다.
  - 첫 절: `x`가 만족.
  - 둘째 절: `¬y`가 만족.
  - 셋째 절: `x`가 만족(원문 예시의 마지막 절 확인 절차).

## 요약
- SAT는 CNF 논리식을 만족시키는 참/거짓 배정을 찾거나 존재하지 않음을 보이는 문제다.
- 탐색 문제는 인스턴스 `I`와 후보 해 `S`에 대해 다항 시간 검증 알고리즘 `C(I, S)`로 정의된다.
- 탐색 문제의 핵심 조건은 (1) 해의 검증이 다항 시간에 가능하고 (2) 해의 길이가 인스턴스 길이에 대해 다항식으로 제한된다는 것이다.
