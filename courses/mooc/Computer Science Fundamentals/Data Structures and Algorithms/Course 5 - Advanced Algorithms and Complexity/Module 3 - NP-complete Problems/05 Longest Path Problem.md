# Longest Path Problem

## 개요
- 최장 경로 문제(Longest Path Problem)는 가중치 그래프와 두 정점 `s`, `t`, 예산(budget) `b`가 주어졌을 때, 총 길이가 `b` 이상인 단순 경로(simple path)를 찾는 문제다.
- 겉보기에는 최단 경로 문제(Shortest Path Problem)와 매우 비슷하지만, 최단 경로 문제는 효율적으로 풀리는 반면 최장 경로 문제는 다항 시간 알고리즘이 알려져 있지 않다.

## 내용

### 문제 정의
- 입력: 가중치 그래프, 두 정점 `s`와 `t`, 예산 `b`.
- 목표: `s`에서 `t`까지 총 길이가 `b` 이상인 단순 경로(같은 정점을 두 번 지나지 않는 경로)를 찾는다.
- 예시로 든 그래프에서, 모든 간선의 길이가 1이라고 가정하면 `s`와 `t` 사이의 최단 경로는 간선 하나만 사용해 길이가 1이지만, 그래프의 다른 모든 정점을 거쳐 가는 매우 긴 단순 경로도 존재할 수 있다.

### 최단 경로 문제와의 대비
- 최단 경로 문제(결정 버전): 그래프와 예산 `b`가 주어졌을 때, 길이가 `b` 이하인 경로를 찾는 문제 — 매우 효율적으로 풀 수 있다.
  - 예: 모든 가중치가 1인(가중치 없는) 그래프라면 너비 우선 탐색(BFS)만으로 선형 시간에 풀 수 있다.
- 최장 경로 문제: 길이가 `b` 이상인 경로를 찾는 문제 — 이 문제에 대해서는 다항 시간 알고리즘이 알려져 있지 않다.
- 즉, "이하(at most)"를 "이상(at least)"으로 바꾸는 작은 차이가 문제의 난이도를 완전히 바꿔놓는다.

## 요약
- 최단 경로 문제는 효율적으로(가중치 없는 그래프의 경우 선형 시간에) 풀 수 있지만, 최장 경로 문제는 다항 시간 알고리즘이 알려지지 않은 어려운 문제다.
- 두 문제는 정의상 부등호 방향(`이하` vs `이상`)만 다를 뿐인데도 난이도가 극명하게 갈린다.
