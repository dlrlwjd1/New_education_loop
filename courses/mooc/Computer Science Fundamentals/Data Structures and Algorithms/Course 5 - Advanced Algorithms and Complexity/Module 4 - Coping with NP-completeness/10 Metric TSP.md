# Metric TSP

## 개요
- 삼각 부등식(triangle inequality)을 만족하는 거리 그래프에서의 TSP인 Metric TSP에 대한 2-근사 알고리즘을 소개한다.
- 최소 신장 트리(minimum spanning tree, MST)를 하한으로 사용하고, 간선을 두 배로 늘려 오일러 회로(Eulerian cycle)를 만든 뒤 지름길(shortcut)로 해밀턴 사이클(Hamiltonian cycle)을 얻는다.
- 더 나은 1.5-근사 알고리즘인 Christofides 알고리즘의 존재와, 삼각 부등식이 없는 일반 TSP는 P≠NP인 한 어떤 다항 시간 계산 가능 함수로도 근사할 수 없다는 한계도 언급한다.

## 내용

### Metric TSP 정의
- 입력: 무방향 그래프이며 간선 가중치가 음이 아니고 삼각 부등식(triangle inequality)을 만족한다 — 임의의 세 정점 u, v, w에 대해 d(u,v) + d(v,w) ≥ d(u,w).
- 목표: 모든 정점을 정확히 한 번 방문하는 최소 길이 사이클을 찾는다(일반 TSP와 동일하지만 거리 제약이 추가됨).

### 하한: 최소 신장 트리
- 임의의 음이 아닌 가중치 그래프(메트릭일 필요 없음)에서 최소 신장 트리(MST)의 총 가중치는 TSP 최적 사이클 길이 이하다.
- 근거: 최적 사이클에서 간선 하나를 제거하면 그래프의 스패닝 트리가 되고, 그 가중치는 MST 가중치 이상이며 동시에 (제거 전) 사이클 길이 이하다.

### 알고리즘
1. 그래프 G의 최소 신장 트리 T를 구성한다.
2. T의 모든 간선을 두 배로 늘려(double) 그래프 D를 만든다. D의 모든 정점 차수(degree)는 짝수가 되어 오일러 회로(Eulerian cycle)가 존재한다.
3. D에서 오일러 회로 C를 찾는다(트리를 두 배로 늘린 그래프에서는 각 서브트리를 재귀적으로 순회하고 돌아오는 방식으로 쉽게 구성할 수 있다).
4. C에서 이미 방문한 정점을 다시 방문하려는 지점은 건너뛰고(지름길, shortcut), 처음 등장하는 순서대로 정점을 나열해 해밀턴 사이클을 얻는다.

### 2-근사 증명
1. MST T의 총 길이 ≤ OPT (앞서 증명).
2. T의 각 간선을 두 배로 늘린 그래프 D의 총 가중치 = 2 × T의 길이 ≤ 2 × OPT.
3. 오일러 회로를 해밀턴 사이클로 바꿀 때(지름길 적용) 삼각 부등식 덕분에 총 길이가 늘어나지 않고 오히려 줄어들 수 있다.
- 결론: 알고리즘이 반환한 사이클의 길이 ≤ 2 × OPT.

### 한계와 발전
- 더 나은 근사 알고리즘으로 Christofides 알고리즘(1.5-근사)이 알려져 있으며, 현재까지 이 문제에 대한 최선의 근사 알고리즘이다.
- 삼각 부등식이 없는 일반 TSP는 P≠NP인 한 어떤 다항 시간 계산 가능한 근사 비율(예: 10, n^2, 2^n 근사)로도 근사할 수 없다 — 좋은 근사 알고리즘이 있다면 이를 이용해 해밀턴 사이클 문제(NP-완전)를 다항 시간에 풀 수 있게 되기 때문이다.

## 예시
- 4정점 예시: MST 구성 → 간선 두 배로 늘림(각 정점 차수 2 또는 6, 모두 짝수) → 오일러 회로(6개 간선 순회) → 중복 방문 지점을 건너뛰어 해밀턴 사이클로 변환.
- 평면 점(point) 예시에서 MST를 두 배로 늘린 그래프에서 오일러 회로(16개 이상의 간선)를 구성한 뒤, 이미 방문한 정점으로 가려는 간선(예: 5번째, 10~13번째 간선)을 건너뛰고 직접 다음 미방문 정점으로 이동.

## 요약
- Metric TSP는 최소 신장 트리를 두 배로 늘려 오일러 회로를 만들고 지름길로 해밀턴 사이클을 얻는 방식으로 2-근사할 수 있다.
- 증명은 MST ≤ OPT, 간선 두 배(2×MST), 삼각 부등식에 의한 지름길 단축이라는 세 단계로 이루어진다.
- 더 정교한 Christofides 알고리즘은 1.5-근사를 달성하며, 삼각 부등식이 없는 일반 TSP는 P≠NP 하에서 근사 자체가 불가능하다.
