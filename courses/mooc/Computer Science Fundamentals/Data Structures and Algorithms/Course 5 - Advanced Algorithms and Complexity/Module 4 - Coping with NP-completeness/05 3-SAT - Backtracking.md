# 3-SAT: Backtracking

## 개요
- 브루트 포스(brute force) 대신 백트래킹(backtracking) 기법으로 3-SAT를 푸는 완전 탐색(exact algorithm, "지능적 전수 탐색") 방법을 소개한다.
- 부분 할당이 막다른 길(dead end)에 다다르면 즉시 되돌아가는(backtrack) 방식으로 불필요한 탐색을 줄인다.
- 최악의 경우 여전히 지수 시간(exponential time)이지만 실무에서는 매우 효과적이며 현대 SAT 솔버(SAT-solver)의 기본 원리다.

## 내용

### 3-SAT 문제와 브루트 포스의 한계
- 입력: 각 절(clause)이 최대 세 개의 리터럴을 가진 3-CNF 논리식. 목표는 모든 절을 만족하는 변수 할당을 찾거나 불가능함을 판정.
- 브루트 포스 알고리즘은 변수 n개에 대해 가능한 2^n개의 할당을 모두 검사한다 — 시간 복잡도 O(|F| · 2^n)이며, 특히 불충족(unsatisfiable) 식이면 항상 모든 할당을 검사해야 한다.
- 목표는 2^n개의 모든 할당을 검사하지 않고도 충족 가능성을 판정하는 것이다.

### 백트래킹(backtracking) 기법
- 해를 조각조각(piece by piece) 구성하다가, 현재 부분 해가 더 이상 유효한 해로 확장될 수 없음을 알게 되면 즉시 되돌아가는(backtrack) 방식이다.
- 미로에서 막다른 방에 도달하면 이전 방으로 돌아가 다른 문을 시도하는 것에 비유된다.

### 알고리즘
- F가 비어 있으면(절이 없으면) 충족 가능(satisfiable)을 반환한다.
- F에 빈 절(empty clause, 모든 리터럴이 이미 거짓이 된 절)이 있으면 충족 불가능(unsatisfiable)을 반환한다.
- 그렇지 않으면 아직 값이 없는 변수 x를 골라 x=0으로 놓고 단순화한 식에 대해 재귀 호출한다. 만족 가능하면 즉시 그 결과를 반환한다.
- 실패하면 x=1로 놓고 다시 재귀 호출한다. 이것도 실패하면 충족 불가능을 반환한다.
- 변수에 값을 대입할 때는: 그 리터럴 때문에 이미 참이 된 절은 제거하고, 부정 리터럴만 남은 절에서는 해당 리터럴을 제거한다.

### 실무에서의 활용
- 이 알고리즘의 실행 시간에 대한 다항 시간 상한은 증명되지 않았다(증명하면 P=NP가 해결된다). 하지만 실무에서는 매우 유용하다.
- 실제 SAT 솔버는 식을 단순화하는 휴리스틱(heuristic), 다음 분기 변수(branching variable) 선택, 분기 값 선택 등의 정교한 기법을 추가로 사용해 수천 개 변수를 가진 식도 효율적으로 처리한다.
- 다음 강의에서 다룰 지역 탐색(local search) 역시 실무에서 널리 쓰이는 또 다른 기법이다.

## 예시
- 4변수 예시 논리식에서 x1=0, x2=0, x3=0, x4=0(또는 1) 순으로 대입하며 절을 단순화하다가 빈 절이 발생하면 즉시 백트래킹.
- 결국 x3=1, x2=1, x1=1까지 모두 시도해도 빈 절이 발생해, 16가지 전체 할당을 모두 확인하지 않고도 이 식이 충족 불가능함을 판정한다.

## 요약
- 백트래킹은 부분 해를 점진적으로 확장하다가 막히면 즉시 되돌아가는 방식으로, 브루트 포스보다 훨씬 적은 탐색으로 충족 가능성을 판정한다.
- 각 변수에 0과 1을 순서대로 시도하고 실패 시 되돌아가는 재귀 알고리즘으로 구현된다.
- 최악의 경우 지수 시간이지만, 휴리스틱과 결합하면 실무에서 매우 큰 규모의 식도 처리할 수 있어 현대 SAT 솔버의 핵심 기법이다.
