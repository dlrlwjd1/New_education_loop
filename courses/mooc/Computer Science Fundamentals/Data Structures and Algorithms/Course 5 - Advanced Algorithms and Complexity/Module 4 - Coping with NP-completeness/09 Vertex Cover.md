# Vertex Cover

## 개요
- 정점 커버(vertex cover) 문제에 대한 매우 단순한 2-근사 알고리즘(2-approximation algorithm)을 소개한다.
- 매칭(matching)을 이용해 알고리즘이 반환한 해와 최적해(OPT) 사이의 관계를 증명하는 방법을 다룬다.
- 이 알고리즘의 근사 비율(approximation ratio)이 타이트(tight)하다는 점과, 이보다 더 나은 근사 비율은 아직 알려져 있지 않다는 한계도 짚는다.

## 내용

### 문제 정의
- 입력: 무방향 그래프(undirected graph). 목표: 모든 간선의 양 끝점 중 적어도 하나를 포함하는 최소 크기의 정점 부분집합(vertex cover)을 찾는다.
- 예: 8개 정점 그래프에서 모든 정점을 커버로 삼을 수도 있고, 6개 정점만으로도 모든 간선을 커버할 수 있지만, 최적 정점 커버는 3개 정점으로 구성된다.

### 알고리즘
1. 커버 C를 빈 집합으로 초기화한다.
2. 그래프에 간선이 남아 있는 동안: 임의의 간선 (u, v)를 골라 u, v를 C에 추가하고, u 또는 v에 인접한 모든 간선을 그래프에서 제거한다.
3. 간선이 모두 사라지면 C를 반환한다.
- 실행 시간은 선형(linear)이며 다항 시간이다.

### 2-근사 증명
- 알고리즘이 선택한 간선들의 집합 M은 매칭(matching)을 이룬다 — 즉 M에 속한 간선들끼리는 끝점을 공유하지 않는다(간선을 선택하는 즉시 인접 간선을 모두 제거하기 때문).
- 매칭 M의 각 간선을 커버하려면 최소 한 개의 정점이 필요하고, M의 간선들은 끝점을 공유하지 않으므로 어떤 정점 커버도 최소 |M|개의 정점을 가져야 한다. 즉 OPT ≥ |M|.
- 반면 알고리즘이 반환한 C의 크기는 |C| = 2|M| (M의 각 간선마다 정점 2개를 추가하므로).
- 따라서 |C| = 2|M| ≤ 2 · OPT — 알고리즘의 해는 최적해의 최대 2배다.
- 핵심 통찰: OPT의 정확한 값을 몰라도, 계산 가능한 하한(|M|)을 이용해 |C| ≤ 2 · OPT라는 상한을 증명할 수 있다.

### 근사 비율의 타이트함과 한계
- 완전 이분 그래프(bipartite graph)에서 한쪽에 n개, 다른 쪽에 n개 정점이 있는 경우, 알고리즘은 매번 간선 하나에서 정점 2개씩 추가해 크기 2n인 커버를 반환하지만, 실제로는 한쪽 n개 정점만으로도 모든 간선을 커버할 수 있다. 즉 이 알고리즘의 근사 비율 2는 타이트(tight)하다.
- 놀랍게도 이 문제에 대해 근사 비율 1.99조차 달성하는 다항 시간 알고리즘은 알려져 있지 않다.

## 예시
- 8정점 그래프에서 최적 정점 커버 크기 3, 알고리즘 자체 결과 크기 6(= 2×3).
- 완전 이분 그래프(양쪽 n개씩): 최적해 n, 알고리즘 결과 2n → 근사 비율 2가 타이트함을 보이는 예.

## 요약
- 정점 커버의 2-근사 알고리즘은 임의의 간선을 골라 양 끝점을 커버에 추가하고 인접 간선을 제거하는 과정을 반복하는 매우 단순한 방법이다.
- 선택된 간선들이 매칭(matching)을 이루므로 |C| = 2|M| ≤ 2 · OPT가 성립해, 최적해를 몰라도 2-근사가 보장된다.
- 이 근사 비율은 타이트하며, 더 나은 상수 근사 알고리즘은 아직 알려져 있지 않다.
