# TSP: Dynamic Programming

## 개요
- 외판원 문제(Traveling Salesman Problem, TSP)를 동적 계획법(dynamic programming)으로 풀어 O(n^2 · 2^n) 시간 알고리즘을 얻는다.
- 방문한 정점 집합 S와 마지막 정점 i를 상태로 하는 점화식 C(S, i)를 정의하고, 비트마스크(bitmask)로 부분집합을 표현하는 구현 방법을 설명한다.
- 브루트 포스의 (n-1)!보다 훨씬 빠르며, n=100에서 약 10^120배 빠르다.

## 내용

### 문제 정의와 브루트 포스의 한계
- 입력: 음이 아닌 가중치를 가진 완전 그래프(complete graph)와 예산 b. 정점 1에서 출발해 모든 정점을 정확히 한 번씩 방문하고 다시 정점 1로 돌아오는 사이클 중 총 길이가 b 이하인 것을 찾는다.
- 브루트 포스는 (n-1)!개의 가능한 사이클을 모두 검사한다 — n=10만 되어도 실행이 사실상 불가능한 수준이다.
- 목표: O(n^2 · 2^n) 알고리즘. n=100에서 (n-1)! / (2^n · n^2) ≈ 10^120이므로 압도적으로 빠르다.

### 부분 문제 정의
- C(S, i): 정점 1에서 출발해 정점 i에서 끝나고, 집합 S(단, 1, i ∈ S)의 모든 정점을 정확히 한 번씩 방문하는 최단 경로의 길이.
- 초기값: C({1}, 1) = 0. |S| ≥ 2이면서 i=1인 경우 C(S, 1) = +∞ (경로가 정점 1에서 끝날 수 없으므로).

### 점화식
- C(S, i) = min over j ≠ i in S of [ C(S \ {i}, j) + weight(j, i) ]
- 즉, 정점 i로 끝나는 최적 경로는 "S에서 i를 뺀 집합을 방문하고 j에서 끝나는 최적 경로"에 간선 (j, i)를 이어붙인 것 중 최솟값이다.
- 계산 순서: 부분집합 크기가 작은 것부터 큰 순서로 처리해야, C(S, i)를 계산할 때 필요한 C(S \ {i}, j)가 이미 계산되어 있음이 보장된다.

### 알고리즘과 비트마스크 구현
- 부분집합 S를 정수 k (0 ≤ k ≤ 2^n − 1)로 표현한다: k의 이진 표현에서 1인 비트 위치가 S의 원소다.
- 집합 S에서 원소 j를 제외하는 연산은 k와 2^j의 비트 연산으로 계산한다: `k XOR (1 << j)`.
- 알고리즘: C({1}, 1) = 0으로 초기화 → 부분집합 크기를 2부터 n까지 늘려가며 각 크기의 모든 S에 대해 C(S, 1) = +∞로 초기화 → S에 속한 각 i에 대해 위 점화식으로 C(S, i)를 계산.
- 최종 답: min over i≠1 of [ C({1,...,n}, i) + weight(i, 1) ].

### 시간 복잡도
- 상태 수: O(2^n · n). 각 상태 계산에 O(n) — 전체 O(2^n · n^2).

## 예시
- 5개 정점 그래프에서 브루트 포스로 찾을 수 있는 사이클 예: 1→2→3→4→5→1(길이 15), 다른 사이클(길이 11), 최적 사이클(길이 9).
- 시간 복잡도 비교: 브루트 포스 (n-1)! vs 동적 계획법 O(n^2 · 2^n). n=100에서 약 10^120배 차이.
- 비트마스크 예시(n=3, 원소 0,1,2): 정수 0~7이 각각 부분집합 {}, {0}, {1}, {0,1}, {2}, ... 에 대응한다(예: 3 = 011₂ → {0,1}).

## 요약
- TSP는 상태를 (방문한 정점 집합 S, 마지막 정점 i)로 정의하는 동적 계획법으로 O(n^2 · 2^n) 시간에 풀 수 있다.
- 점화식 C(S, i) = min_j [C(S \ {i}, j) + w(j, i)]를 부분집합 크기 순으로 채워나간다.
- 비트마스크로 부분집합을 정수로 표현하면 구현이 간단해지며, 브루트 포스((n-1)!)보다 압도적으로 빠르다.
