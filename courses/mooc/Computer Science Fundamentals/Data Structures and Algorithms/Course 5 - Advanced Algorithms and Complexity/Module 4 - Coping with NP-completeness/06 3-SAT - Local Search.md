# 3-SAT: Local Search

## 개요
- 지역 탐색(local search)을 이용해 3-SAT의 충족 가능성을 판정하는 알고리즘을 소개한다.
- 해밍 거리(Hamming distance)와 해밍 볼(Hamming ball) 개념을 정의하고, 만족 할당이 볼 안에 있음을 알 때 이를 빠르게 찾는 재귀 절차를 설명한다.
- 최종적으로 O(|F| · 3^(n/2)) ≈ O(|F| · 1.733^n) 시간의 알고리즘을 얻어, 브루트 포스의 2^n보다 지수적으로 빠름을 보인다.

## 내용

### 지역 탐색(local search)의 일반 아이디어
- 초기 해에서 출발해, 현재 해가 충분히 좋지 않으면 조금씩 바꿔(small change) 더 나은 해로 이동하는 과정을 반복한다.

### 해밍 거리와 해밍 볼
- 후보 해(candidate solution)는 n개의 불리언 변수에 대한 {0,1}^n 벡터다.
- 두 할당 alpha, beta 사이의 거리(distance)는 서로 다른 비트의 개수로 정의한다.
- 반지름 r, 중심 alpha인 해밍 볼(Hamming ball)은 alpha로부터 거리 r 이하인 모든 할당의 집합이다. 예를 들어 n=4일 때 반지름 0인 볼은 원소 1개(중심 자신), 반지름 1인 볼은 원소 5개(중심 + 1비트씩 바꾼 4개), 반지름 2인 볼은 원소 11개다.

### 핵심 보조정리(lemma)와 재귀 알고리즘
- 논리식 F와 중심 alpha, 반지름 r인 해밍 볼이 만족 할당 beta를 포함한다고 알려져 있다면, 이 볼 안에서 만족 할당을 O(3^r · |F|) 시간에 찾을 수 있다.
- 절차: alpha가 F를 만족하면 즉시 반환한다. 아니면 만족되지 않은 절(리터럴 xi, not(xj), xk 등 최대 3개)을 골라, 각 변수의 비트를 하나씩 뒤집은 세 할당 alpha_i, alpha_j, alpha_k를 만든다.
- beta가 이 절을 만족하므로 세 할당 중 적어도 하나는 beta에 더 가까워진다(어느 것인지는 모르지만 보장된다).
- r=0이면 볼에는 alpha 자신만 있으므로, alpha가 F를 만족하지 않으면 "찾지 못함(not found)"을 반환한다.
- 이 재귀는 alpha_i, alpha_j, alpha_k 각각에 대해 반지름 r-1로 재귀 호출하며, 최대 3^r번의 호출로 alpha와 beta 사이 거리 r 이내에서 만족 할당을 찾는다.

### 전체 문제로의 확장
- F가 만족 가능하고 만족 할당 beta가 있다고 가정하면, beta에서 1이 0보다 많으면 all-1 할당과의 거리가 n/2 이하이고, 그렇지 않으면 all-0 할당과의 거리가 n/2 이하다.
- 따라서 반지름 n/2, 중심 all-1과 반지름 n/2, 중심 all-0인 두 개의 큰 해밍 볼만 검사하면 충족 가능성을 판정할 수 있다.
- 두 볼 모두에서 만족 할당을 찾지 못하면 F는 충족 불가능하다.

### 시간 복잡도 비교
- 전체 알고리즘 시간: O(|F| · 3^(n/2)) ≈ O(|F| · 1.733^n).
- 브루트 포스: O(|F| · 2^n).
- 1.733 ≈ 2^0.85 수준이므로, 이 알고리즘은 브루트 포스보다 지수적으로 빠르다. n=100일 때 약 100만 배 빠르다.
- 여전히 지수 시간이라 실무에서 그대로 쓰기엔 부족하지만, 실제 SAT 솔버는 지역 탐색 아이디어를 변형해 널리 사용한다.

## 예시
- n=4일 때 해밍 볼 크기: 반지름 0 → 1개, 반지름 1 → 5개, 반지름 2 → 11개.
- 재귀 호출 횟수 상한: 최대 3^r.
- 전체 알고리즘 시간 복잡도: O(|F| · 3^(n/2)) ≈ 1.733^n (브루트 포스 2^n 대비 지수적으로 빠름, n=100에서 약 100만 배 차이).

## 요약
- 지역 탐색은 해밍 거리 기준으로 정의한 볼(ball) 안에서 최대 3^r번의 재귀 호출로 만족 할당을 찾는 절차를 제공한다.
- all-1, all-0 두 개의 반지름 n/2 볼만 검사하면 전체 충족 가능성을 판정할 수 있어, O(|F| · 1.733^n) 시간에 3-SAT를 해결한다.
- 여전히 지수 시간이지만 브루트 포스(2^n)보다 지수적으로 빠르며, 현대 SAT 솔버의 지역 탐색 휴리스틱의 이론적 기반이 된다.
