# Independent Sets in Trees

## 개요
- 트리(tree)에서 최대 독립 집합(maximum independent set)을 찾는 문제를 균일 가중치 버전과 정점 가중치 버전 두 가지로 다룬다.
- 균일 가중치 버전은 잎(leaf)을 항상 포함하는 안전한 이동(safe move)만으로 간단히 풀린다.
- 가중치가 있는 버전은 서브트리 단위로 정의한 동적 계획법(dynamic programming)으로 해결한다.

## 내용

### 문제 정의: 독립 집합(independent set)
- 그래프에서 어떤 두 정점도 서로 인접하지 않는 정점 부분집합 중 최대 크기를 찾는 문제. 일반 그래프에서는 NP-완전이지만, 입력이 트리(tree)일 때는 선형 시간(linear time)에 풀 수 있다.
- 비유: 회사 파티에 최대한 많은 사람을 초대하되, 직속 상사와 부하 직원을 함께 초대할 수 없다는 제약이 있는 상황.

### 균일 가중치 버전: 잎을 모두 포함하는 안전한 이동
- 안전한 이동(safe move): 모든 잎(leaf)을 해에 포함시킨다.
- 증명 방식: 임의의(최적) 해를 변형해도 크기가 줄지 않으면서 모든 잎을 포함하는 해로 바꿀 수 있음을 보인다. 해에 없는 잎을 포함시키고 그 부모를 제외해도 해의 크기는 줄지 않는다.
- 알고리즘: 트리가 빌 때까지 (1) 모든 잎을 해에 넣고 (2) 그 잎과 부모를 트리에서 제거하는 과정을 반복한다.
- 구현: 각 정점의 남은 자식 수를 유지하다가 0이 되면 큐(queue)에 넣는 방식으로 관리하면 선형 시간에 구현할 수 있다.

### 가중치가 있는 버전: 동적 계획법
- 문제: 정점마다 음이 아닌 가중치(예: fun factor)가 있고, 총 가중치가 최대인 독립 집합을 찾는다. 이 경우 모든 잎을 포함하는 것이 항상 최적은 아니므로 새로운 알고리즘이 필요하다.
- 부분 문제 정의: D(v) = 정점 v를 루트로 하는 서브트리에서의 최대 독립 집합 가중치.
- 점화식:
  - v를 해에 포함하는 경우 — v의 가중치 + v의 모든 손자(grandchildren)에 대한 D 값의 합 (자식은 v와 인접하므로 제외).
  - v를 포함하지 않는 경우 — v의 모든 자식(children)에 대한 D 값의 합.
  - D(v) = max(포함하는 경우, 포함하지 않는 경우).
- 재귀 함수 FunParty(v): D(v)가 아직 계산되지 않았으면(무한대로 초기화되어 있으면) 계산한다. v가 잎이면 D(v) = v의 가중치. 아니면 위 점화식대로 m1(포함 시 값), m0(미포함 시 값)을 계산해 더 큰 값을 D(v)에 저장한다.
- 시간 복잡도: 각 정점당 실질적인 계산(serious call)은 한 번뿐이므로 전체 O(트리 크기), 즉 선형 시간이다.

## 예시
- 트리를 잎에서 루트 방향으로 채워나가는 계산 예: 어떤 서브트리에서 잎 값들의 합(1+2+1=4)과 그 부모 정점 자체의 가중치(7)를 비교해 더 큰 값인 7을 선택.
- 더 상위 단계에서는 "포함(부모 가중치 6 + 손자 값 합 1+2+1 = 10)" vs "미포함(자식 D값 합 7+2 = 9)"을 비교해 10을 선택.
- 최종적으로 예시 트리의 최대 독립 집합 가중치는 "루트 포함(3+2+3+7+2=17)" vs "루트 미포함(5+3+10=18)" 중 18로 결정된다.

## 요약
- 균일 가중치 트리 독립 집합은 잎을 모두 포함하는 탐욕적(greedy) 안전한 이동으로 선형 시간에 풀린다.
- 가중치가 있는 버전은 각 정점에서 "포함 vs 미포함"을 비교하는 동적 계획법 D(v) = max(w(v) + Σ손자, Σ자식)으로 선형 시간에 풀린다.
- NP-완전인 일반 독립 집합 문제도 입력이 트리라는 특수 구조를 가지면 효율적으로 풀 수 있음을 보여주는 사례다.
