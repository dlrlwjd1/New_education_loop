# Advanced Algorithms and Complexity

- 전문과정: Data Structures and Algorithms (Course 5)
- 제공: University of California San Diego
- 구성: 5개 모듈, 영상 56개 — Transcript 기반 한국어 정리 완료
- 제외: 읽기 자료·퀴즈·프로그래밍 과제 채점
