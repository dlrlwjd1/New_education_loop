# (Optional) The Ellipsoid Algorithm

## 개요
- 선형 계획을 항상 다항 시간(polynomial time)에 푸는 타원체 알고리즘(ellipsoid algorithm)을 다룬다. 단체법(simplex)과 달리 최악의 경우에도 다항 시간이 보장되지만, 실무에서는 대체로 단체법보다 느리다. 모듈의 마지막 강의다.

## 내용

### 문제 설정 - 충족가능성(satisfiability)
- 타원체 알고리즘은 완전 최적화가 아니라 충족가능성(satisfiability) 형태를 푼다: 주어진 제약 집합에 해가 있는지 여부만 판별한다.

### 알고리즘의 절차
1. **미세한 완화(relaxation)**: 모든 부등식을 아주 조금씩 더 느슨하게 만든다. 원래 해가 없었다면 여전히 없고, 원래 해가 있었다면(단 한 점뿐이었더라도) 이제 해집합이 작지만 양의 부피(positive volume)를 가지게 된다.
2. **큰 공(ball)으로 둘러싸기**: 해집합 전체(또는 최소한 해집합의 상당 부분)를 포함하는 아주 큰 공을 찾는다. 충분히 크게 잡으면 어렵지 않다.
3. **중심점 확인**: 현재 타원체(처음엔 공)의 중심이 제약을 만족하는지 확인한다.
   - 만족하면 해를 찾은 것이므로 충족 가능(satisfiable)하다고 답하고 종료한다.
   - 만족하지 않으면, 이 중심점은 볼록 영역(해집합) 밖의 점이므로 분리 초평면(separating hyperplane)을 찾을 수 있다.
4. **타원체 축소**: 분리 초평면에 의해 해집합 전체가 원래 타원체의 절반(half-ellipsoid) 안에 있음을 알 수 있다. 이 half-ellipsoid를 포함하면서 부피가 더 작은 새로운 타원체를 구성할 수 있다.
5. **반복**: 이 과정을 반복하며 해집합을 포함하는 타원체를 점점 더 작게 만들어간다.

### 종료 조건
- 두 가지 경우 중 하나로 종료한다.
  - 어느 시점에 타원체의 중심이 실제로 해집합에 속하면, 충족 가능(satisfiable)함을 확인하고 종료.
  - 타원체가 (1단계의 완화로 보장된) 최소 양의 부피보다 더 작아지면, 해집합이 존재할 수 없는 크기이므로 충족 불가능(unsatisfiable)함을 확인하고 종료.

### 실행 시간(runtime)
- 실행 시간은 대략 O((m + n²) · n⁵ · log(nU))이다. 여기서 n은 공간의 차원, m은 방정식(제약)의 개수, U는 계수들의 수치적 크기다.
- 다항 시간(polynomial time)이라는 점은 좋은 소식이지만, n⁷ 수준의 "나쁜 다항식(bad polynomial)"이어서 많은 경우 지수 시간이나 준지수 시간 알고리즘보다 오히려 느릴 수 있다.
- 실행 시간이 계수의 크기 U에 로그 의존(logarithmic dependence)하므로, 계수가 지나치게 복잡하고 큰 경우 성능이 나빠질 수 있다. 반면 단체법(simplex method)은 계수 크기와 무관하게 대수 연산의 횟수가 정해진다.

### 분리 오라클(separation oracle)만으로 동작 가능
- 타원체 알고리즘이 실제로 필요로 하는 것은 시스템의 명시적 방정식 목록이 아니라 분리 오라클(separation oracle)뿐이다: 어떤 점 x가 주어졌을 때, x가 해집합에 속하는지 판별하거나, 속하지 않으면 x를 해집합과 분리하는 초평면을 제시하는 기능.
- 명시적인 유한 개의 방정식이 없어도 분리 오라클만 제공할 수 있다면 타원체 알고리즘으로 선형 계획을 풀 수 있는 경우가 있으며, 이는 실무에서 유용하게 쓰이는 경우가 있다.

## 예시
- 실행 시간: O((m + n²) · n⁵ · log(nU))

## 요약
- 타원체 알고리즘(ellipsoid algorithm)은 제약을 미세하게 완화하고, 해집합을 감싸는 타원체를 계속 축소해가며 충족가능성을 판별하는 알고리즘이다.
- 단체법과 달리 최악의 경우에도 다항 시간이 보장되지만, 지수(n⁷ 등)가 커서 실무에서는 대체로 단체법보다 느리다.
- 명시적 방정식 없이 분리 오라클(separation oracle)만 있어도 동작할 수 있다는 점이 특징적인 장점이다.
- 이 강의로 선형 계획법(linear programming) 단원이 마무리되며, 다음 단원부터는 복잡도 이론(complexity theory)과 NP-완전(NP-complete) 문제를 다룬다.
