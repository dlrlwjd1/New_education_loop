# Introduction

## 개요
- 선형 계획법(linear programming) 단원의 도입 강의로, 위젯 공장 예시를 통해 "선형 함수를 선형 부등식 제약 아래에서 최적화한다"는 선형 계획 문제의 형태를 직관적으로 소개한다.

## 내용

### 위젯 공장 문제 설정
- 위젯을 기계(machine)와 노동자(worker)의 조합으로 생산한다.
- 기계는 최대 100대까지 보유 가능(재고 제한).
- 노동자는 무제한으로 고용 가능하지만, 기계 한 대를 가동하려면 노동자 2명이 필요하다.
- 기계 한 대는 하루 600개의 위젯을 생산하고, 기계를 조작하지 않는(비점유) 노동자는 한 명당 하루 200개의 위젯을 생산한다.
- 위젯에 대한 총수요는 하루 100,000개로 제한되어 있어, 이보다 많이 만들어도 팔리지 않는다.

### 제약식(constraints) 세우기
- 노동자 수를 W, 기계 수를 M이라 하면 다음과 같은 제약이 생긴다.
  - W ≥ 0 (노동자 수는 음수가 될 수 없음)
  - 0 ≤ M ≤ 100 (기계 수는 0~100 사이)
  - W ≥ 2M (노동자 수는 기계를 가동하는 데 필요한 인원의 최소 2배 이상)
  - 100,000 ≥ 200(W − 2M) + 600M (총 생산량이 수요를 넘지 않음, 여기서 W − 2M은 기계를 조작하지 않는 노동자 수)
- 이 제약들을 M, W 평면에 그리면 허용 가능한 영역이 사다리꼴(trapezoid) 형태로 나타난다.

### 목적 함수(objective function)와 이윤
- 위젯 하나당 $1의 수익이 나고, 노동자 한 명을 고용하는 데 하루 $100의 비용이 든다.
- 총이윤은 (총 위젯 수) − (총 노동자 임금) = [200(W − 2M) + 600M] − 100W = 200M + 100W 로 정리된다.
- 이 목적 함수를 그래프 위에 등이윤선(line of equal profit)으로 그리면, 좌하단에서 우상단으로 갈수록 이윤이 커진다.
- 허용 영역 안에서 이윤을 최대화하는 최적점은 영역의 한 꼭짓점(corner/vertex)에서 나타나며, 이 예시에서는 M=100, W=400일 때 최대 이윤 $60,000/일이 달성된다.

### 최적성 증명(듀얼 관점의 예고)
- 그래프만으로는 최적임을 "보이는" 것이지 "증명"한 것은 아니다.
- 증명 방법: 제약식 중 M ≤ 100 에 100을 곱하고, 200M + 200W ≤ 100,000 에 1/2를 곱한 뒤 더하면 200M + 100W ≤ 60,000 이라는 새로운 부등식이 유도된다.
- 이는 목적 함수(profit) 자체가 항상 60,000 이하임을 증명하므로, 그래프에서 찾은 60,000이 실제 최댓값임이 확인된다.
- 이 "제약식들의 양의 조합으로 상계를 증명하는 기법"은 이후 강의에서 다룰 쌍대성(duality)의 핵심 아이디어를 예고한다.

## 예시
- 변수: M(기계 수), W(노동자 수)
- 제약식:
  - W ≥ 0
  - 0 ≤ M ≤ 100
  - W ≥ 2M
  - 100,000 ≥ 200(W − 2M) + 600M
- 목적 함수: maximize 200M + 100W
- 최적해: M = 100, M = 400, 최댓값 = $60,000/일
- 최적성 증명: 100 × (M ≤ 100) + (1/2) × (200M + 200W ≤ 100,000) ⇒ 200M + 100W ≤ 60,000

## 요약
- 선형 계획(linear program)은 선형 목적 함수를 선형 부등식 제약 아래에서 최대화(또는 최소화)하는 문제다.
- 최적해는 허용 영역의 꼭짓점(corner)에서 나타난다.
- 제약식들을 적절한 양의 계수로 조합하면 목적 함수의 상계(또는 하계)를 증명할 수 있다 — 이는 다음에 다룰 쌍대성(duality)의 기초가 된다.
