# Linear Programming Formulations

## 개요
- 선형 계획법에는 여러 관련된 문제 형태(formulation)가 있으며, 이들이 사실상 서로 동등함을 보인다. 다음 강의들에서 다룰 알고리즘들은 각각 이 중 한 형태만을 풀도록 설계되어 있으므로, 서로 변환하는 방법을 아는 것이 중요하다.

## 내용

### 네 가지 문제 형태
1. **완전 최적화(full optimization)**: 선형 부등식 제약 시스템이 주어졌을 때, 선형 함수를 최소화 또는 최대화한다(해가 없으면 그렇다고 답함).
2. **시작점에서의 최적화(optimization from a starting point)**: 선형 부등식 시스템과 그 다면체의 한 꼭짓점(vertex)이 주어졌을 때, 그 지점에서 시작해 선형 함수를 최적화한다.
3. **해 찾기(solution finding)**: 목적 함수 없이, 선형 부등식 시스템의 해(존재한다고 가정) 하나를 찾는다.
4. **충족가능성(satisfiability)**: 선형 부등식 시스템에 해가 존재하는지 여부만 판별한다.

### 네 형태의 동등성
- 완전 최적화가 가장 강력한 형태이며, 이를 풀 수 있으면 나머지 세 가지도 모두 풀 수 있다.
  - 시작점에서의 최적화: 시작점을 무시하고 처음부터 풀면 된다.
  - 해 찾기: 최적해 자체가 하나의 해이므로 그대로 사용하면 된다.
  - 충족가능성: 완전 최적화를 돌려서 답이 나오면 해가 있는 것이다.
- 반대로, 더 약한 형태만으로도 완전 최적화를 구성할 수 있다.

### 시작점에서의 최적화 → 완전 최적화
- 문제는 "시작점을 어떻게 구할 것인가"이다. 방정식을 하나씩 추가해가며 해를 유지하는 방법을 사용한다.
- 예를 들어 첫 7개 제약을 만족하는 해가 있고, 8번째 제약을 추가하려 할 때: 현재 해가 8번째 부등식을 만족하지 않을 수 있으므로, "8번째 부등식을 최대한 만족시키는 방향으로" 선형 최적화를 수행한다(시작점에서의 최적화 알고리즘 사용). 그 결과로 얻는 꼭짓점이 커진 시스템의 해가 된다.
- 이 과정을 사각형(rectangle)에서 시작해 부등식을 하나씩 추가하며 잘라나가는 예시로 설명한다.
- 기술적 주의점: 중간 시스템이 unbounded(최댓값이 없는 경우)일 수 있으므로, 처음엔 n개의 제약으로 시작해 유일한 꼭짓점을 확보하고, 새 제약 v·x ≥ t를 추가할 때는 단순히 v·x를 최대화하는 대신 v·x ≤ t 라는 상한도 함께 추가해 최댓값이 t에서 확실히 존재하도록 만든다.

### 해 찾기 → 완전 최적화 (쌍대성 이용)
- 해 찾기만 가능할 때 최적해임을 어떻게 보장하는가에는 쌍대성(duality)을 이용한다: 쌍대 문제를 풀어 일치하는 상계를 제시하면 검증이 된다.
- minimize v·x subject to Ax ≥ b 를 풀려면, 다음의 더 큰 시스템의 해를 찾으면 된다:
  - Ax ≥ b
  - y ≥ 0
  - yᵀA = v
  - x·v = y·b
- 이 시스템의 해에서 x는 주 문제의 해이고 y는 쌍대 문제의 해이며, x·v = y·b라는 등식이 강쌍대성에 의해 x가 최적해임을 보장한다.

### 충족가능성 → 해 찾기 (Gaussian elimination 이용)
- 항상 다면체의 한 꼭짓점에서 해가 존재하므로, 해당 꼭짓점에서는 몇몇 부등식이 등식(tight)으로 성립한다. 어떤 부등식들이 등식인지만 알아내면, 가우스 소거법(Gaussian elimination)으로 교점을 구해 해를 얻을 수 있다.
- 방법: 각 부등식을 하나씩 골라, "이 부등식을 등식으로 고정했을 때도 여전히 시스템 전체에 해가 있는가"를 충족가능성(satisfiability) 알고리즘으로 확인한다.
  - 해가 없으면 그 등식은 버린다(그 등식은 최종 해에 필요하지 않음).
  - 해가 있으면 그 등식을 계속 유지한다.
- 모든 부등식에 대해 이 과정을 반복하면, 최종적으로 등식으로 남은 제약들의 교점이 원하는 해가 된다.
- m개의 방정식, n개의 변수를 가진 시스템이라면, 충족가능성 알고리즘을 정확히 m번 호출하면 된다(각 등식을 한 번씩만 테스트).

## 예시
- 시작점에서의 최적화를 이용한 점진적 제약 추가: 사각형 → 한 부등식씩 추가하며 매번 "새 부등식을 최대한 만족시키는" 최적화를 수행 → 마지막에 전체 목적 함수로 완전 최적화 수행.
- 해 찾기 → 완전 최적화 변환 시스템: Ax ≥ b, y ≥ 0, yᵀA = v, x·v = y·b
- 충족가능성 호출 횟수: 방정식 m개에 대해 총 m번.

## 요약
- 선형 계획에는 완전 최적화, 시작점에서의 최적화, 해 찾기, 충족가능성이라는 네 가지 형태가 있으며 서로 동등하다.
- 시작점에서의 최적화는 제약을 하나씩 추가하며 매번 최적화를 수행함으로써 완전 최적화로 확장할 수 있다.
- 해 찾기는 쌍대성을 이용한 더 큰 시스템을 구성함으로써 완전 최적화로 확장할 수 있다.
- 충족가능성은 각 부등식이 등식인지 여부를 하나씩 판별하고 가우스 소거법으로 교점을 구함으로써 해 찾기로 확장할 수 있다.
