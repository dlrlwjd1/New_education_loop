# Linear Algebra: Method of Substitution

## 개요
- 선형 부등식(linear inequality) 시스템을 다루기 전에, 더 단순한 특수 사례인 선형 등식(linear equality) 시스템을 대입법(method of substitution)으로 푸는 방법과 자유 변수(free variable)·해집합의 차원 개념을 다룬다.

## 내용

### 대입법(method of substitution)의 일반적 절차
1. 첫 번째 방정식을 이용해 한 변수를 다른 변수들로 표현한다.
2. 그 표현을 나머지 방정식들에 대입한다.
3. 이제 변수가 n−1개인 방정식들이 남으므로 이를 재귀적으로 푼다.
4. 나머지 변수들의 값을 구한 뒤, 첫 번째 방정식에 다시 대입해 처음 풀었던 변수의 값을 구한다.

### 예시 1 - 두 변수, 두 방정식 (유일해)
- 시스템: x + y = 5, 2x + 4y = 12.
- 첫 번째 식에서 x = 5 − y.
- 두 번째 식에 대입: 12 = 10 + 2y ⇒ y = 1.
- 첫 번째 식에 다시 대입: x = 5 − 1 = 4.
- 해: x = 4, y = 1.
- 연습 문제: x + 2y = 6, 3x − y = −3 ⇒ x = 0 (y = 3으로 계산됨).

### 예시 2 - 변수가 방정식보다 많은 경우 (자유 변수)
- 시스템: x + y + z = 5, 2x + y − z = 1 (변수 3개, 방정식 2개).
- 첫 번째 식에서 x = 5 − y − z.
- 두 번째 식에 대입해 y = 9 + 3z 를 얻는다.
- z를 풀 수 있는 방정식이 더 이상 남아 있지 않다 — 첫 번째 식은 x를, 두 번째 식은 y를 푸는 데 이미 사용했기 때문이다.
- 하지만 이는 문제가 되지 않는다. z에 어떤 값을 대입해도 y = 9 + 3z, x = 5 − y − z = −4 − 4z로 정의되는 해가 항상 성립한다.
- 이처럼 z는 자유 변수(free variable)가 되고, 해집합은 하나의 점이 아니라 부분공간(subspace)이 된다.

### 해집합의 차원(dimension)
- 해집합의 차원은 자유 변수의 개수, 즉 한 점을 표현하는 데 필요한 매개변수(parameter)의 개수와 같다.
- 일반적으로 방정식 하나는 변수 하나를 나머지로 표현해준다. 따라서 해집합의 차원 ≈ (전체 변수 개수) − (방정식 개수).
- n개의 방정식과 n개의 미지수: 자유 변수가 없어 유일해(unique solution)를 가진다.
- n+1개의 방정식과 n개의 미지수: 앞의 n개로 유일해를 구한 뒤, 남은 하나의 방정식이 그 해를 만족하지 못할 가능성이 크므로 일반적으로 해가 없다.
- n−1개의 방정식과 n개의 미지수: 자유 변수가 하나 남아, 일반적으로 차원 1의 부분공간(직선)이 해가 된다.

## 예시
- 유일해 시스템: x + y = 5, 2x + 4y = 12 → x = 4, y = 1
- 자유 변수가 있는 시스템: x + y + z = 5, 2x + y − z = 1 → y = 9 + 3z, x = −4 − 4z (z는 자유 변수)

## 요약
- 대입법(method of substitution)은 한 변수를 나머지로 표현해 방정식 개수를 하나씩 줄여가며 선형 등식 시스템을 푸는 일반적 방법이다.
- 방정식 개수가 변수 개수보다 적으면 자유 변수(free variable)가 남고, 해집합은 특정 차원을 가진 부분공간(subspace)이 된다.
- 다음 강의에서는 이 과정을 표기법 측면에서 체계화해 컴퓨터가 실행할 수 있는 알고리즘(가우스 소거법)으로 만든다.
