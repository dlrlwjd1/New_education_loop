# Linear Programming

## 개요
- 선형 계획법(linear programming)을 형식적으로 정의하고, 행렬 표기법으로 일반화한 뒤, 식단 문제(diet problem)와 최대 유량(max flow) 문제가 모두 선형 계획의 특수한 경우임을 보인다. 또한 해가 없는 경우와 최댓값이 없는(unbounded) 경우 같은 예외 상황도 다룬다.

## 내용

### 선형 계획의 일반적 정의
- 실수 x1, …, xn을 찾되, 다음과 같은 선형 부등식들을 만족해야 한다: a11x1 + a12x2 + … ≥ b1, 그리고 여러 개의 유사한 부등식.
- 이 제약을 만족하면서 선형 목적 함수 v1x1 + v2x2 + …를 최대(또는 최소)로 만들고자 한다.
- 행렬 표기: 계수를 행렬 A, 벡터 b, v로 저장한다. 출력은 벡터 x ∈ Rⁿ이며, Ax ≥ b를 만족해야 한다. 여기서 Ax ≥ b는 각 성분별 부등식을 뜻한다(성분별 비교).
- 이 제약 아래 v·x를 최대 또는 최소로 만드는 것이 목표다.

### 예시 1 - 식단 문제(diet problem)
- 1930~40년대 조지 스티글러(George Stigler)가 연구한 문제로, "건강한 식단을 얼마나 저렴하게 구성할 수 있는가"를 다룬다.
- 변수: 각 식품별 하루 섭취량(예: x_bread, x_milk, x_apple, …).
- 제약: 각 변수는 음수가 될 수 없고(비음수, non-negative), 각 영양소(칼로리, 비타민 C, 단백질 등)에 대해 하루 최소 섭취량을 만족해야 한다. 예를 들어 칼로리 제약은 (칼로리/서빙 × 빵) + (칼로리/서빙 × 우유) + … ≥ 2,000.
- 목적 함수: 총비용 = (빵 가격 × x_bread) + (우유 가격 × x_milk) + … 를 최소화.
- 실제로 이렇게 풀면 감자와 땅콩버터처럼 소수의 효율적인 식품과 비타민제 조합으로 수렴하는 경향이 있어, 실용적인 식단으로 삼기엔 부적합할 수 있다는 한계가 언급된다.

### 예시 2 - 최대 유량(max flow)
- 이전 강의에서 다룬 네트워크 유량 문제도 선형 계획의 특수한 경우다.
- 변수: 각 간선 e에 대한 유량 f_e.
- 제약:
  - 각 간선 e에 대해 0 ≤ f_e ≤ capacity(e).
  - source와 sink가 아닌 모든 정점에 대해 유량 보존(conservation of flow): 들어오는 유량 = 나가는 유량.
  - 등식(equality)은 부등식 두 개(≥, ≤)로 나눠서 표현할 수 있다(들어오는 유량 ≥ 나가는 유량, 그리고 들어오는 유량 ≤ 나가는 유량).
- 목적 함수: source에서 나가는 총유량 − source로 들어오는 총유량을 최대화.

### 해가 없는 경우와 unbounded인 경우
- 해가 없는 경우: 예를 들어 x ≥ 1, y ≥ 1, x + y ≤ 1이라는 제약은 서로 모순되어 해가 존재하지 않는다.
- 해는 있지만 최댓값이 없는(unbounded) 경우: x ≥ 0, y ≥ 0, x − y ≥ 1이라는 제약에서는 x를 원하는 만큼 크게 만들 수 있어 최댓값이 존재하지 않는다.
- 강의에서 세 가지 2변수 시스템(A, B, C)을 제시하고 분류하는 연습을 한다: A는 해가 없음, B는 x=1.5에서 유일한 최댓값을 가짐, C는 해는 있지만 x=y 직선을 따라 얼마든지 커질 수 있어 최댓값이 없음(unbounded).

## 예시
- 최대 유량의 목적 함수: maximize (source에서 나가는 총유량 − source로 들어오는 총유량)
- 해 없음 예시: x ≥ 1, y ≥ 1, x + y ≤ 1 → 모순(무해)
- Unbounded 예시: x ≥ 0, y ≥ 0, x − y ≥ 1 → x는 얼마든지 커질 수 있음

## 요약
- 선형 계획법(linear programming)은 Ax ≥ b 형태의 선형 부등식 제약 아래 선형 목적 함수 v·x를 최적화하는 문제로 일반화된다.
- 식단 문제(diet problem)와 최대 유량(max flow) 문제 모두 선형 계획의 특수 사례다.
- 선형 계획은 해가 아예 없거나(infeasible), 해는 있지만 최적값이 없는(unbounded) 경우가 있을 수 있다.
- 다음 강의부터는 부등식 대신 등식(선형 방정식)을 다루는 더 단순한 특수 사례부터 시작한다.
