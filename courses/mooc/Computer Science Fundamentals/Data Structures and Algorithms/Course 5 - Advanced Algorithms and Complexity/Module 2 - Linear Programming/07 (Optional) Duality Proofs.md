# (Optional) Duality Proofs

## 개요
- 선택(optional) 강의로, 앞서 다룬 선형 계획 쌍대성 정리(LP duality theorem)와 상보적 여유성(complementary slackness)을 실제로 증명한다. 물리적 비유(우물 속 공)로 직관을 먼저 제시한 뒤, 볼록성(convexity)과 분리 초평면(separating hyperplane)을 이용한 증명을 전개한다.

## 내용

### 물리적 직관 - 우물 속의 공
- 선형 제약이 정의하는 영역을 "벽으로 둘러싸인 우물"에 비유한다. 어떤 점의 높이(선형 목적 함수)를 최소화하는 것은, 중력에 의해 당겨지는 공을 우물에 떨어뜨려 가장 낮은 곳에 멈추게 하는 것과 같다.
- 공이 멈췄을 때는 힘의 균형이 이루어진다: 중력(아래로 당기는 힘)이 벽들이 밀어내는 수직 항력(normal force)들의 조합과 균형을 이룬다.
- 이 벽면의 법선 벡터(normal vector)들의 선형 결합이 중력 방향 벡터와 같아야 한다는 조건을, 방정식으로 풀어보면 정확히 쌍대 문제(dual)의 해가 된다.
- 이때 공이 실제로 닿아 있는 벽들만 사용된다는 사실이, 상보적 여유성(complementary slackness)의 직관을 보여준다 — 등식(tight)이 되는 제약만 사용된다는 것.

### 가해성(solvability) 문제로 재구성
- 목표: Ax ≥ b 이면서 x·v ≤ t 인 해가 언제 존재하는지를 판별.
- 주장: 이 시스템에 해가 존재하지 않는 것은, 제약들의 어떤 조합이 "0 > 1"이라는 모순을 낳을 때뿐이다(그리고 이것이 필요충분조건, if and only if).
- 이를 증명할 수 있으면, 원래 최적화 문제도 해결된다. 왜냐하면 (마지막 부등식을 제외한) 제약들의 조합이 x·v > t 라는 결론을 내는 경우에만 해가 존재하지 않기 때문이다.

### 볼록 집합과 분리 초평면을 이용한 증명
- 제약식 E1, …, Em에 음이 아닌 상수 c1, …, cm을 곱해 더한 모든 조합의 집합을 C라 하면, C는 볼록 집합(convex set)이다.
- "0 > 1"이 C에 속하지 않는다면, 이는 볼록 집합에 속하지 않는 하나의 점이므로 분리 초평면(separating hyperplane)이 존재한다.
- 이 분리 초평면은 "선형 부등식들의 집합" 공간에서의 초평면이라는 점에서 다소 추상적이지만, 이 초평면으로부터 원래 시스템의 실제 해를 추출할 수 있다.

### 구체적 예시로 살펴보기
- ax + by ≥ 1 형태의 부등식들로 이루어진 시스템을 생각하자. 이 부등식들의 (a, b) 계수를 평면에 그려보면, 이들의 음이 아닌 선형 조합으로 만들 수 있는 영역은 회색 영역으로 나타난다.
- "0 > 1"에 해당하는 원점은 이 회색 영역(볼록 영역)에 포함되지 않으므로 분리 초평면이 존재한다. 예: a + b ≥ 0.
- 이는 모든 원래 부등식이 a + b ≥ 0을 만족한다는 뜻이며, 이로부터 x = y = (충분히 큰 수)로 두면 ax + by = (a+b) × (그 큰 수) > 1이 항상 성립함을 알 수 있다 — 즉 x = y = 1이 실제 해가 된다.
- 이런 식으로 "0 > 1이 선형 조합에 없다 → 분리 초평면이 있다 → 그 초평면의 형태로부터 실제 해를 구성한다"는 절차로 일반적인 증명이 완성된다.

### 상보적 여유성(complementary slackness) 증명
- 주 문제의 해 x와 그에 대응하는 쌍대 해 y가 있다고 하자. 주 문제 최적값은 x·v = t이고, 쌍대성에 의해 쌍대에서도 같은 하계를 얻는다.
- 즉 제약식들의 조합 Σ yi·Ei 가 정확히 x·v ≥ t 라는(등식으로 성립하는, tight) 부등식을 만들어낸다.
- 각 부등식 Ei는 그 x값에 대해 참인 부등식이었는데, 이들의 합이 등식(tight)이 되려면, 사용된 개별 부등식들 자체도 등식(tight)이어야만 한다.
- 따라서 각 i에 대해 Ei가 등식(tight)이거나 yi = 0이어야 하며, 이것이 곧 상보적 여유성(complementary slackness)이다.

## 예시
- 가해성 문제: Ax ≥ b, x·v ≤ t 에 해가 있는가?
- 예시 시스템: ax + by ≥ 1 형태의 부등식들 → 분리 초평면 a + b ≥ 0 발견 → x = y = 1이 실제 해가 됨을 도출.

## 요약
- LP 쌍대성 정리는 "선형 부등식 조합이 모순(0 > 1)을 낳지 않으면 해가 존재한다"는 가해성 명제로 재구성해 증명할 수 있다.
- 증명의 핵심은 제약 조합들의 집합이 볼록 집합(convex set)이라는 점과, 그 집합에 속하지 않는 점은 분리 초평면(separating hyperplane)으로 분리할 수 있다는 점이다.
- 상보적 여유성(complementary slackness)은 "부등식들의 합이 등식이 되려면 사용된 개별 부등식도 모두 등식이어야 한다"는 사실로부터 직접 증명된다.
