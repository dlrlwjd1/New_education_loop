# Bipartite Matching

## 개요
- 네트워크 유량 알고리즘의 첫 응용으로 이분 매칭(bipartite matching) 문제를 다룬다.
- 기숙사 방 배정 문제를 예로 들어, 이분 그래프(bipartite graph)와 매칭(matching)을 정의하고, 최대 유량 문제로 환원해 푸는 방법을 보인다.
- 더 나아가 최대 유량-최소 컷 정리로부터 쾨니그 정리(Konig's theorem)를 유도한다.

## 내용

### 문제 설정: 기숙사 방 배정
- 학생 n명, 방 m개가 있고 각 학생은 자신이 받아들일 수 있는 방 목록을 제시한다.
- 목표: 한 방에 학생 한 명만 배정한다는 제약 하에 최대한 많은 학생을 방에 배정하는 것.

### 이분 그래프(bipartite graph)와 매칭(matching)
- 이분 그래프: 정점 집합이 U와 V 두 부분집합으로 나뉘고, 모든 간선이 U의 정점과 V의 정점 사이에만 존재하는 그래프(학생–방 관계를 표현).
- 매칭: 끝점을 공유하지 않는 간선들의 집합 — 각 학생은 최대 한 방에, 각 방은 최대 한 학생에게만 배정됨을 의미.
- 이분 매칭 문제: 주어진 이분 그래프에서 가능한 가장 많은 간선을 갖는 매칭(이상적으로는 양쪽 모든 정점을 짝지을 수 있는 매칭)을 찾는 것.

### 응용 사례
- 매치메이킹: 서로 호감이 있는 남녀를 짝짓는 문제(단, 동성 간 호감이 있으면 이분 그래프가 아니게 되어 문제가 더 복잡해짐).
- 스케줄링: 여러 이벤트를 서로 다른 시간대에 배정하는 문제.

### 최대 유량 문제로의 환원
- 이분 그래프 G의 모든 간선을 왼쪽(U)에서 오른쪽(V)으로 방향을 준다.
- 소스 s를 추가해 U의 모든 정점과 연결하고, V의 모든 정점을 싱크 t와 연결한다.
- 모든 간선(원래 간선, 소스→U, V→싱크)의 용량을 1로 둔다. 이렇게 만든 네트워크를 G'라 한다.
- 정리: G의 매칭과 G'의 정수 값 유량(integer-valued flow) 사이에는 일대일 대응이 존재한다.
  - 매칭 → 유량: 매칭에 쓰인 각 간선에 유량을 흘리고, 그 유량이 s에서부터 t까지 이어지도록 나머지 간선에도 흘린다.
  - 유량 → 매칭: U-V 사이 간선 중 유량이 흐르는 간선들을 매칭으로 채택한다. 각 정점에는 용량 1짜리 간선만 연결되어 있으므로 한 정점에서 두 개의 매칭 간선이 나올 수 없다.
- 앞서 증명한 정수 유량 보조정리(포드-풀커슨 알고리즘 강의)에 의해, 항상 정수 값의 최대 유량을 구할 수 있으므로 최대 유량 알고리즘을 그대로 이분 매칭에 적용할 수 있다.

### 이분 매칭 알고리즘
1. 이분 그래프 G에 대응하는 네트워크 G'를 구성한다.
2. G'의 최대 유량 f를 정수 값이 되도록 계산한다.
3. f로부터 대응하는 매칭을 찾아 반환한다.

### 컷과 쾨니그 정리(Konig's theorem)
- G'에서의 컷은 소스, U의 부분집합 X, V의 부분집합 Y를 포함한다.
- 컷을 최소화하려면 Y를 "X에서 도달 가능한 V의 정점들"로 고정하는 것이 유리하다.
- 이때 컷을 나가는 간선들은 (U \ X)에서 s로 나가는 간선과 Y에서 t로 나가는 간선들이며, 컷의 크기는 |U \ X| + |Y|이다.
- G의 모든 간선은 Y의 정점이나 (U \ X)의 정점 중 하나에 연결되므로, 이 두 집합의 합집합이 모든 간선을 커버하는 정점 집합(vertex cover)이 된다.
- **쾨니그 정리**: G가 이분 그래프이고 최대 매칭의 크기가 k이면, G의 모든 간선이 적어도 한 정점을 포함하도록 하는 크기 k의 정점 집합 S가 존재한다. 즉, 이분 그래프에서 최대 매칭의 크기 = 최소 정점 커버(minimum vertex cover)의 크기.

### 완전 매칭(perfect pairing)의 특수한 경우
- G가 양쪽 각각 n개의 정점을 가진 이분 그래프일 때, 완전 매칭(양쪽 모든 정점을 짝짓는 매칭)이 존재하지 않는 경우는, 왼쪽의 어떤 부분집합(크기 m)이 연결된 오른쪽 정점의 총수가 m보다 엄격히 적을 때뿐이다.
- 이는 "m명의 남자가 연결된 여자가 m명 미만이면 이들을 모두 서로 다른 상대와 짝지을 수 없다"는 직관과 일치한다.

## 예시
- 방 배정 퀴즈: 특정 이분 그래프에서 최대 매칭 크기는 3이며, 크기 4나 5는 불가능함을 확인.
- 정점 커버 예시: 어떤 그래프에서 4개의 정점이 모든 간선을 커버하므로 최대 매칭 크기는 최대 4이며, 이 경우 실제로 4가 달성 가능(tight)함을 확인.

## 요약
- 이분 매칭 문제는 소스·싱크와 용량 1짜리 간선을 추가한 네트워크의 최대 유량 문제로 환원해 풀 수 있다.
- 이분 그래프의 매칭과 대응 네트워크의 정수 값 유량은 일대일 대응 관계다.
- 최대 유량-최소 컷 정리를 이 구조에 적용하면 쾨니그 정리(최대 매칭 크기 = 최소 정점 커버 크기)가 도출된다.
- 완전 매칭이 존재하지 않는 조건도 최소 정점 커버 관점에서 설명할 수 있다.
