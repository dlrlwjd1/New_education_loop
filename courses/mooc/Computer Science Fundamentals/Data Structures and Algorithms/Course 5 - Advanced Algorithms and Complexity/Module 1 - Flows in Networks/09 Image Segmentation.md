# Image Segmentation

## 개요
- 네트워크 유량 알고리즘의 두 번째 응용으로 이미지 분할(image segmentation) 문제를 다룬다.
- 이미지의 전경(foreground)과 배경(background)을 분리하는 문제를, 인접 픽셀 간 페널티까지 고려한 최적화 문제로 정식화하고, 이를 최소 컷(min cut) 문제로 환원해 최대 유량 알고리즘으로 해결한다.

## 내용

### 문제 설정
- 이미지는 픽셀들의 격자이며, 각 픽셀을 전경 또는 배경으로 분류해야 한다.
- 별도의 사전 알고리즘이 각 픽셀 v에 대해 전경일 가능성 점수 a_v와 배경일 가능성 점수 b_v를 부여한다고 가정한다.

### 단순 버전(페널티 없음)
- 입력: a, b 값들. 출력: 픽셀을 전경/배경으로 나눈 분할.
- 목적함수: (전경에 속한 픽셀들의 a 값 합) + (배경에 속한 픽셀들의 b 값 합)을 최대화.
- 이 단순 버전은 각 픽셀을 독립적으로 판단하면 된다: a_v > b_v이면 전경, b_v > a_v이면 배경.

### 인접성 페널티를 포함한 전체 문제
- 인접한 픽셀들은 대체로 같은 쪽(전경 또는 배경)에 속하는 경향이 있으므로, 픽셀 쌍 (v, w)마다 "v는 전경, w는 배경"으로 나뉠 때 페널티 p_vw를 부여한다.
- 전체 목적함수: (전경 픽셀들의 a 합) + (배경 픽셀들의 b 합) − (v가 전경, w가 배경인 모든 쌍의 p_vw 합)을 최대화.

### 최소화 문제로의 변환(대수적 정리)
- 모든 픽셀 v에 대해 (a_v + b_v)의 합을 빼도 분할 결과의 최적성은 바뀌지 않는다(상수이므로).
- 이 변형을 거치면, "음수 목적함수를 최대화" 대신 "양수 목적함수를 최소화"하는 문제로 바뀐다: (배경에 속한 픽셀들의 a 합) + (전경에 속한 픽셀들의 b 합) + (전경-배경 경계를 넘는 페널티 p_vw 합)을 최소화.
- 이 형태는 두 집합으로 나누고 그 경계에서 비용을 지불하는 문제로, 최소 컷 문제와 매우 유사하다.

### 네트워크 구성과 최소 컷으로의 환원
- 소스 s와 싱크 t를 추가한다.
- s에서 각 픽셀 v로 용량 a_v짜리 간선을 추가한다.
- 각 픽셀 v에서 t로 용량 b_v짜리 간선을 추가한다.
- 픽셀 v에서 w로 용량 p_vw짜리 간선을 추가한다.
- 이 네트워크에서 s를 포함하고 t를 포함하지 않는 컷을 생각하면, 컷의 크기는 (컷 안에 있는 v의 b_v 합) + (컷 밖에 있는 v의 a_v 합) + (v는 컷 안, w는 컷 밖인 쌍의 p_vw 합)이 되며, 이는 정확히 앞서 최소화하려던 목적함수와 일치한다(컷 내부 = 전경, 컷 외부 = 배경으로 대응).
- 따라서 이미지 분할 문제는 그대로 이 네트워크의 최소 컷 문제로 환원된다.

### 알고리즘
1. 위와 같이 대응하는 네트워크 G를 구성한다.
2. 에드먼드-카프(Edmonds-Karp) 등의 알고리즘으로 G의 최대 유량 f를 계산한다.
3. f에 대응하는 잔여 네트워크(residual network)를 구성한다.
4. 잔여 네트워크에서 소스로부터 도달 가능한 정점 집합을 C라 하면, C가 전경, 나머지가 배경이 되는 것이 최적 해다(최대 유량-최소 컷 정리에 의해 C가 최소 컷을 이룸).

## 예시
- 단순 버전 수치 예시: 픽셀 3개에 대해 각각 a, b 값이 주어졌을 때, 픽셀 1은 배경(4점), 픽셀 2는 전경(5점), 픽셀 3은 전경(6점)으로 분류하면 총점 4+5+6=15로 최적이다.

## 요약
- 이미지 분할 문제는 픽셀별 전경/배경 점수와 인접 픽셀 간 페널티를 함께 고려하는 최적화 문제로 정식화된다.
- 대수적 변형을 거치면 이 문제는 정확히 최소 컷 문제와 동일한 형태가 된다.
- 소스·싱크와 픽셀 간 용량(a_v, b_v, p_vw)으로 구성한 네트워크를 만들어 최대 유량을 계산하고, 그 잔여 네트워크에서 소스로부터 도달 가능한 정점 집합을 전경으로 삼으면 최적 분할을 얻는다.
- 이는 최대 유량-최소 컷 정리가 이미지 처리 문제에도 응용될 수 있음을 보여주는 사례다.
