# The Ford–Fulkerson Algorithm

## 개요
- 최대 유량을 실제로 계산하는 첫 번째 알고리즘인 포드-풀커슨 알고리즘(Ford-Fulkerson algorithm)을 소개한다.
- 유량 0에서 시작해 잔여 네트워크에서 소스-싱크 경로를 찾아 조금씩 유량을 늘려가다가, 더 이상 경로가 없으면 종료한다.

## 내용

### 알고리즘의 핵심 아이디어
- 유량 f에서 시작(처음은 0)하여 잔여 네트워크 G_f를 계산한다.
- G_f에 소스-싱크 경로가 없으면, 소스에서 도달 가능한 정점 집합이 크기 0인 컷을 이루므로 f는 이미 최대 유량이다 → 종료.
- 경로가 있으면, 그 경로 위 잔여 간선들의 최소 용량만큼(x) 유량을 흘려 새 유량 g를 잔여 네트워크에서 만들고, f를 f+g로 갱신한다. 이렇게 하면 유량 크기가 반드시 커진다.

### 정수 유량 보조정리(integrality lemma)
- 원래 네트워크의 모든 용량이 정수이면, 포드-풀커슨 알고리즘이 만드는 모든 유량도 정수다. 매번 경로 위 최소 용량(항상 정수)만큼만 흘리기 때문이다.
- 따라서: 용량이 모두 정수인 네트워크 G에는 항상 정수 값을 갖는 최대 유량이 존재하며, 포드-풀커슨 알고리즘으로 얻을 수 있다. (이 보조정리는 이후 이분 매칭(bipartite matching) 강의에서 활용된다.)

### 실행 시간 분석
- 반복마다 잔여 네트워크 계산과 경로 탐색에 각각 O(간선 수) 시간이 걸린다.
- 반복마다 유량이 최소 1 이상 증가하므로, 반복 횟수는 최대 유량의 크기 이하다.
- 총 실행 시간: O(간선 수 × 최대 유량의 크기).
- 문제점: 이 실행 시간은 그래프의 구조뿐 아니라 용량의 수치 크기에도 의존한다. 용량이 매우 크면 매우 오래 걸릴 수 있다(다음 강의에서 실제 예시로 확인).
- 또한 이 알고리즘은 "어떤 경로를 선택할지"를 명시하지 않는 미완성 알고리즘이다. 깊이 우선 탐색(DFS)으로 아무 경로나 고를 수도 있지만, 경로 선택 방식이 실행 시간에 큰 영향을 준다(추후 강의에서 다룸).

## 예시
- 알고리즘 의사코드:
  1. f ← 자명한 유량(모든 간선 0)
  2. 반복:
     - G_f(잔여 네트워크)를 계산
     - G_f에서 s-t 경로 P를 탐색
     - P가 없으면 f를 반환하고 종료
     - x ← P 위 잔여 간선들의 최소 용량
     - g ← P의 각 간선에 x만큼 유량을 배정한 잔여 유량
     - f ← f + g
- 수치 예시: 어떤 네트워크에서 첫 반복에 찾은 s-t 경로 위 최소 용량 간선이 4이면, 해당 반복에서 4단위의 유량을 흘린다.
- 좀 더 큰 예시에서는 첫 경로에서 최소 용량 5로 5단위, 다음 경로에서 다시 최소 용량 5로 5단위, 마지막 경로에서 최소 용량 2로 2단위를 흘려 총 12단위의 유량을 만든 뒤, 더 이상 s-t 경로가 없는(컷이 존재하는) 상태에 도달해 최대 유량 12를 확인했다.

## 요약
- 포드-풀커슨 알고리즘: 유량 0에서 시작 → 잔여 네트워크의 s-t 경로를 따라 최소 용량만큼씩 유량을 증가 → 경로가 없어지면 종료.
- 용량이 정수이면 결과 유량도 항상 정수다.
- 실행 시간은 O(간선 수 × 최대 유량 크기)로, 용량이 매우 크면 비효율적일 수 있다는 한계가 있다.
- 경로 선택 방법이 명시되지 않아 완전한 알고리즘이 아니며, 선택 방식이 성능에 큰 영향을 준다.
