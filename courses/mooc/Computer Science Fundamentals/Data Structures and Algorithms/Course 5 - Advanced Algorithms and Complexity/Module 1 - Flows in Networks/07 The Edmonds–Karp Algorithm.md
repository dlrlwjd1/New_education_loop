# The Edmonds–Karp Algorithm

## 개요
- 포드-풀커슨 알고리즘(Ford-Fulkerson algorithm)에서 항상 최단 증가 경로(shortest augmenting path)를 선택하도록 한 에드먼드-카프 알고리즘(Edmonds-Karp algorithm)을 소개한다.
- 이 선택 규칙 덕분에 실행 시간이 용량의 크기와 무관한 다항 시간 O(V·E²)로 보장됨을 증명한다.

## 내용

### 알고리즘 아이디어
- 포드-풀커슨과 동일하지만, 증가 경로를 고를 때 항상 간선 수 기준으로 가장 짧은 경로를 사용한다.
- 이는 곧 잔여 네트워크에서 깊이 우선 탐색(DFS) 대신 너비 우선 탐색(BFS)으로 경로를 찾는 것을 의미한다.
- 이전 강의의 나쁜 예시에서, 지그재그(간선 3개) 경로 대신 간선 2개짜리 경로를 강제로 선택하게 되어 좋은 실행 결과를 얻는다.

### 포화 간선(saturated edge)과 분석 전략
- 증가 경로를 따라 유량을 흘릴 때는 항상 그 경로 위에서 잔여 용량이 가장 작은 간선을 완전히 소진(포화)시킨다.
- 유량을 추가한 뒤 잔여 네트워크는 갱신되며, 포화된 간선은 사라지고 반대 방향 간선이 생긴다.
- 분석 전략: 어떤 간선도 너무 여러 번 포화되지 않음을 보여서, 전체 증가 경로 수를 제한한다.
- 나쁜 예시에서는 중간 간선이 계속 반복적으로 포화되었던 것이 문제였는데, 에드먼드-카프에서는 이런 일이 제한된 횟수만 일어남을 보인다.

### 거리 단조 증가 보조정리
- 알고리즘이 진행되는 동안, 임의의 정점 v에 대해 소스에서 v까지의 거리, v에서 싱크까지의 거리, 소스에서 싱크까지의 거리는 모두 감소하지 않고 오직 증가만 한다.
- 증명 아이디어: 증가 경로는 항상 최단 경로이므로, 새로 생기는 역방향 간선은 소스에서 "더 먼" 정점에서 "더 가까운" 정점 쪽으로 향한다. 이런 간선은 소스에서 더 가까운 곳으로 가는 지름길이 될 수 없다(먼 도시에서 가까운 도시로만 가는 고속도로는 가까운 도시에서 출발할 때 도움이 안 되는 것과 같은 원리). 포화되어 사라지는 간선 때문에 거리가 늘어날 수는 있지만, 새로 생기는 간선이 거리를 줄이는 일은 없다.

### 간선 재포화 제한 보조정리
- 간선 e가 한 번 포화되면, 소스-싱크 사이의 거리가 증가하기 전까지는 e가 다시 증가 경로에 사용될 수 없다.
- 증명 스케치: 간선 e = (u→v)가 포함된 최단 경로의 길이가 x+y+1(s→u 거리 x, u→v 거리 1, v→t 거리 y)이라면, 소스-싱크 거리는 x+y+1이다. e가 다시 쓰이려면 역방향(v→u)을 사용해야 하는데, 이때 s→v 거리는 최소 x+1, u→t 거리는 최소 y+1이므로 새로운 s→t 거리는 최소 (x+1)+1+(y+1) = x+y+3으로, 반드시 이전보다 커야 한다.

### 실행 시간 분석
- 소스-싱크 거리는 정점 수(V) 이상 커질 수 없으므로, 최대 V번만 증가한다.
- 거리가 증가하는 사이에는 각 간선이 최대 한 번만 포화될 수 있으므로, 그 구간에는 최대 O(E)개의 증가 경로만 존재한다.
- 따라서 전체 증가 경로 수는 O(V·E), 각 경로 탐색(BFS)에 O(E) 시간이 걸리므로 총 실행 시간은 O(V·E²)이다.
- 이는 최대 유량의 크기에 의존하지 않는 다항 시간이라는 점에서 포드-풀커슨보다 우수하다.

### 확인 퀴즈 정리
- 참: 간선은 소스-싱크 거리가 증가한 뒤에만 다시 포화될 수 있으며, 거리는 최대 V번만 증가한다.
- 거짓: 증가 경로의 길이는 알고리즘이 진행될수록 "감소"하는 것이 아니라 오히려 증가(또는 유지)한다.
- 거짓: 용량을 바꿔도 실행 시간에 영향이 없다는 것은 사실이 아니다. 용량이 모두 0이면 증가 경로 자체가 필요 없는 등, 용량이 실행 시간에 (제한된 범위 내에서) 영향을 줄 수 있다.

### 참고: 더 나은 알고리즘
- 강의에서 다루지는 않지만, 최신 알고리즘들은 O(V·E) 수준까지 실행 시간을 개선한 것으로 알려져 있다.

## 예시
- 실행 시간 비교: 포드-풀커슨 O(E × 최대 유량 크기) vs 에드먼드-카프 O(V·E²).
- 이전 강의의 나쁜 예시 그래프에서 에드먼드-카프(BFS 기반 최단 경로)를 적용하면 지그재그 경로(간선 3개) 대신 간선 2개짜리 경로들을 순서대로 사용해 단 두 번의 반복으로 끝난다.

## 요약
- 에드먼드-카프 알고리즘은 포드-풀커슨에서 항상 최단(간선 수 기준) 증가 경로를 사용하도록 한 버전이다.
- 소스-싱크 거리가 단조 증가한다는 성질과, 한 간선이 재포화되려면 거리가 늘어나야 한다는 성질을 이용해 전체 증가 경로 수를 O(V·E)로 제한한다.
- 결과적으로 실행 시간은 O(V·E²)이며, 이는 용량의 수치 크기에 의존하지 않는 다항 시간이라는 점에서 포드-풀커슨의 약점을 해결한다.
