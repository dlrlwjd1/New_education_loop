# Introduction

## 개요
- 네트워크 유량(network flow) 단원의 도입 강의로, 도시 대피 문제를 예시로 앞으로 다룰 문제 유형을 소개한다.
- 아직 형식적 정의는 다루지 않고, "얼마나 빨리 도시를 대피시킬 수 있는가"라는 직관적 문제를 통해 병목(bottleneck)과 상한(upper bound) 개념을 맛보기로 보여준다.

## 내용

### 도시 대피 문제 설정
- 재난 관리자 입장에서, 도시를 빠져나가는 도로망을 이용해 비상시 얼마나 빨리 대피시킬 수 있는지 알고 싶다.
- 도로마다 시간당 처리 가능한 차량 수, 즉 용량(capacity)이 정해져 있다.
  - 메인 고속도로: 시간당 5000대
  - 보조 고속도로 두 개: 각각 시간당 2000대
  - 각 보조 고속도로는 다시 절반씩(각 1000대) 갈라지고, 그중 두 갈래가 다시 합쳐져 시간당 1000대짜리 도로가 된다.

### 대피 경로 배치와 총량 계산
- 메인 도로에 5000대, 북쪽 경로 두 갈래에 각 1000대씩, 세 번째 고속도로에 1000대를 배정하면 총 시간당 8000대를 대피시킬 수 있다.
- 관건은 "이보다 더 잘할 수 있는가"이다.

### 병목(bottleneck)을 이용한 상한 증명
- 지도 위에 강(river)이 흐른다고 가정하면, 그 강을 건너는 다리는 총 4개이며 이 다리들의 용량 합이 정확히 8000대다.
- 도시를 빠져나가려면 반드시 이 강을 건너야 하므로, 강을 건너는 총 용량이 곧 전체 대피 속도의 상한이 된다.
- 따라서 시간당 8000대가 이 문제의 최적해임이 증명된다. 이는 이후 강의에서 다룰 최소 컷(min cut) 개념의 직관적 선행 사례다.

## 요약
- 네트워크 유량 문제는 도로망처럼 용량이 있는 그래프에서 "얼마나 많은 것을 흘려보낼 수 있는가"를 다룬다.
- 특정 지점(다리들)의 총 용량이 전체 흐름의 상한을 결정한다는 아이디어가 핵심이며, 이는 이후 최대 유량-최소 컷(max flow-min cut) 정리의 토대가 된다.
- 다음 강의부터 이 문제를 형식적으로 정의하고, 실제 응용 사례들을 살펴본다.
