# Dijkstra Example

## 개요
- 특정 그래프에 다익스트라 알고리즘(Dijkstra's algorithm)을 직접 적용해보는 예시 영상이다.
- 노드를 하나씩 확정(검은색)하고 dist 값을 확정(초록색)하는 과정을 순서대로 보여준다.
- 이 영상에서는 노드를 별도 이름(A, B, C 등) 대신 "처리 순서"로 지칭하므로, 아래에서는 처리 순서에 따라 노드를 표기한다.

## 내용

### 초기 상태
- 출발 노드의 dist를 0으로 설정하고 검은색(확정)으로 칠한다. 나머지 모든 노드의 dist는 +무한대다.

### 진행 과정
- **출발 노드 처리**: 나가는 간선 두 개를 순서대로 완화한다.
  - 가중치 3인 간선 → 도착 노드 dist: ∞ → 3
  - 가중치 10인 간선 → 도착 노드 dist: ∞ → 10
- **다음 확정 노드 선택**: 미확정 노드 중 dist가 가장 작은 노드(dist=3)를 확정(검은색·초록색)한다.
  - 이 노드의 나가는 간선 처리: 가중치 8인 간선 → 3+8=11 > 10(기존 값)이라 완화 실패. 가중치 3인 간선 → 3+3=6 < ∞이므로 새 노드의 dist를 6으로 갱신. 가중치 5인 간선 → 3+5=8 < ∞이므로 새 노드의 dist를 8로 갱신.
- **다음 확정 노드 선택**: 미확정 노드 중 dist가 가장 작은 노드(dist=6)를 확정한다.
  - 나가는 간선 처리: 가중치 2인 간선 → 새 노드 dist: ∞ → 8. 가중치 1인 간선 → 기존 dist=8이던 노드를 6+1=7로 갱신. 가중치 3인 간선 → 기존 dist=10이던 노드를 6+3=9로 갱신.
- **다음 확정 노드 선택**: 미확정 노드 중 dist가 가장 작은 노드(dist=7)를 확정한다.
  - 나가는 간선(가중치 0) 하나만 존재: 7+0=7이 기존 dist=8보다 작으므로 해당 노드 dist를 7로 갱신.
- **다음 확정 노드 선택**: 미확정 노드 중 dist가 가장 작은 노드(dist=7, 7<9)를 확정한다. 나가는 간선이 없어 추가 처리 없음.
- **마지막 노드 확정**: 남은 노드(dist=9)를 확정한다.
  - 나가는 간선 처리: 가중치 5인 간선 → 9+5=14 > 7(대상 노드의 기존 dist)이므로 완화 실패. 가중치 2인 간선 → 9+2=11 > 3(대상 노드의 기존 dist)이므로 완화 실패.
- 모든 노드가 확정되고 더 이상 갱신이 없으므로 알고리즘을 종료한다.

## 예시
| 확정 순서 | 확정된 dist 값 | 비고 |
|---|---|---|
| 1 | 0 | 출발 노드 |
| 2 | 3 | 출발 노드에서 직접 연결 |
| 3 | 6 | 2번 노드에서 완화 |
| 4 | 7 | 3번 노드에서 완화(8→7) |
| 5 | 7 | 4번 노드에서 완화(8→7) |
| 6 | 9 | 3번 노드에서 완화(10→9), 마지막 확정 |

## 요약
- 다익스트라 알고리즘은 매 단계 미확정 노드 중 dist가 최소인 노드를 확정하고, 그 노드의 나가는 간선들을 완화하는 과정을 반복한다.
- 이미 확정된(초록색) dist 값은 이후 어떤 완화 시도로도 줄어들지 않는다.
- 이 그래프 예시에서 최종 확정된 dist 값은 처리 순서대로 0, 3, 6, 7, 7, 9다.
