# Bellman-Ford Algorithm

## 개요
- 음수 가중치(negative weight) 간선이 있어도 동작하는 벨만-포드 알고리즘(Bellman-Ford algorithm)을 소개한다. 단, **음의 사이클(negative cycle)이 없다는 전제** 아래에서 정확한 최단 거리를 구한다.
- 다익스트라 알고리즘(Dijkstra's algorithm)에 앞서 다룬 나이브 알고리즘(naive algorithm)의 아이디어를 그대로 활용한다.

## 내용

### 알고리즘 개요
- 나이브 알고리즘(모든 간선을 dist 값이 바뀌지 않을 때까지 반복 완화하는 방식)은 음수 가중치가 있어도, **음의 사이클만 없다면** 그대로 동작한다.
- 벨만-포드 알고리즘은 이를 구체화한 것으로, 완화 절차(relax)는 다익스트라 알고리즘과 동일하다: 간선 (u, v)에 대해 `dist[v] > dist[u] + weight(u, v)`이면 갱신한다.
- 그래프에 음의 사이클이 없다고 가정한 상태에서, 다음과 같이 동작한다.
  1. 모든 노드의 `dist`를 무한대로, `prev`를 "가리키는 곳 없음"으로 초기화하고, 출발 노드의 `dist`만 0으로 설정한다.
  2. 그래프의 노드 수를 V라 할 때, **모든 간선을 (어떤 순서로든) 완화하는 과정을 V-1번 반복**한다.

### 실행 시간
- 초기화는 O(V), 이후 V-1번의 반복에서 매번 모든 간선(E개)을 검사하므로 총 실행 시간은 **O(V·E)** 다.

### 예시로 보는 동작
- 그래프에 S, A, B, C, D 다섯 개 노드가 있고 일부 간선의 가중치가 음수라고 하자. (이 그래프에는 음의 사이클이 없다.)
- **1차 반복**: 모든 간선을 순서대로 완화한다.
  - S→A(4): `0+4 < ∞` → A=4
  - S→B(3): `0+3 < ∞` → B=3
  - A→B(-2): `4+(-2)=2 < 3` → B=2
  - A→C(4): `4+4 < ∞` → C=8
  - B→C(-3): `2+(-3)=-1 < 8` → C=-1
  - B→D(1): `2+1=3 < ∞` → D=3
  - C→D(2): `-1+2=1 < 3` → D=1
- **이후 반복**: 같은 순서로 모든 간선을 다시 검사하지만, 어떤 dist 값도 더 이상 줄어들지 않는다(예: `0+4=4`는 기존 A=4와 같아 갱신 없음 등). 노드가 5개이므로 총 4번의 반복이 필요하지만, 첫 반복 이후로는 변화가 없다.
- **최종 결과**: `dist[S]=0, dist[A]=4, dist[B]=2, dist[C]=-1, dist[D]=1`. 음수 가중치 간선이 있으므로 최단 거리 자체도 음수(C의 경우 -1)가 될 수 있다.
- 정확성 증명은 다음 영상에서 다룬다.

## 예시
```text
BellmanFord(G, S):
    for all u in V(G):
        dist[u] = ∞
        prev[u] = None
    dist[S] = 0

    repeat V-1 times:
        for all (u, v) in E(G):
            relax(u, v)   // dist[v] > dist[u] + weight(u,v) 이면 갱신

// 실행 시간: O(V · E)
```

## 요약
- 벨만-포드 알고리즘은 음의 사이클이 없는 그래프에서, 모든 간선을 V-1번 반복 완화해 정확한 최단 거리를 구한다.
- 실행 시간은 O(V·E)이며, 음수 가중치 덕분에 최단 거리 값 자체가 음수일 수 있다.
