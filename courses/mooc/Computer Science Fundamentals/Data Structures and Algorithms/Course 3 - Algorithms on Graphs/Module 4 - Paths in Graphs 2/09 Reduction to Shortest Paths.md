# Reduction to Shortest Paths

## 개요
- 통화 환전(currency exchange) 문제, 즉 "환율의 곱을 최대화"하는 문제를 표준적인 "가중치 합을 최소화"하는 최단 경로 문제로 환원(reduction)하는 방법을 다룬다.
- 또한 이렇게 변환된 그래프에는 음수 가중치(negative weight) 간선이 생기므로, 다익스트라 알고리즘(Dijkstra's algorithm)이 왜 더 이상 통하지 않는지, 그리고 음의 사이클(negative cycle)이라는 새로운 문제가 왜 발생하는지 설명한다.

## 내용

### 곱을 합으로, 최대화를 최소화로 바꾸기
- **로그(logarithm)를 취해 곱을 합으로 바꾼다**: `x·y = 2^(log₂x) · 2^(log₂y) = 2^(log₂x + log₂y)`이므로, x·y를 최대화하는 것은 `log₂x + log₂y`를 최대화하는 것과 동치다.
  - 예: `4 × 1 × 1/2 = 2`이고, `log₂4 + log₂1 + log₂(1/2) = 2 + 0 + (-1) = 1 = log₂2`.
- **부호를 반전해 최대화를 최소화로 바꾼다**: 로그의 합을 최대화하는 것은 로그에 음의 부호를 붙인 값(`-log`)의 합을 최소화하는 것과 동치다.
- 두 단계를 합치면: 원래 간선 가중치(환율) `r_i`를 `-log(r_i)`로 바꾼 뒤, 출발 통화에서 목표 통화까지 **가중치 합이 최소인 경로**를 찾으면 된다. 이것이 바로 표준 최단 경로 문제다.

### 다익스트라 알고리즘이 통하지 않는 이유
- 다익스트라 알고리즘은 "모든 간선 가중치가 음이 아니다"라는 전제에 강하게 의존한다. 구체적으로는 S에서 T까지의 최단 경로가 S보다 T에 더 가까운 노드들만 거친다는 전제다.
- 반례: 출발 노드 S에서 A로 가는 간선(가중치 5)과 B로 가는 간선(가중치 20)이 있다고 하자. 다익스트라 알고리즘은 A의 dist가 5로 가장 작으므로 A까지의 거리를 5로 확정한다.
- 그런데 만약 B에서 A로 가는 간선의 가중치가 -20이라면, S→B→A 경로의 총 가중치는 `20 + (-20) = 0`이 되어 5보다 짧다. 다익스트라 알고리즘은 이런 음수 간선 때문에 A까지의 거리를 잘못 계산하게 된다.
- 실제 예시: 루블→달러 환율 0.015, 루블→유로 환율 0.013, 유로→달러 환율 1.16이라 하자. `0.013 × 1.16`이 `0.015`보다 크므로 루블→유로→달러 경로가 더 유리하다.
  - 환율에 `-log`를 취하면 루블→달러 간선은 약 6.05, 루블→유로 간선은 약 6.26이 된다. 다익스트라 알고리즘은 첫 단계에서 더 작은 값(루블→달러, 6.05)을 최단 거리로 확정해버려, 실제로 더 짧은 유로를 거치는 경로를 놓친다.

### 음의 사이클(negative cycle) 문제
- 음수 가중치를 허용하면 더 심각한 문제인 음의 사이클(negative cycle)이 발생할 수 있다.
- 예: 사이클 A→B(-2)→C(-3)→A(4)의 합은 -1로 음수다. 이 사이클을 원하는 만큼 여러 번 돌면 총 가중치를 얼마든지 작게(음의 방향으로) 만들 수 있다.
- 이 경우 사이클에서 도달 가능한 모든 노드까지의 거리는 사실상 **음의 무한대(minus infinity)**가 된다.
- 통화 환전 맥락에서는, 음의 사이클이 존재한다는 것이 곧 **무한한 차익거래(arbitrage)** 가 가능하다는 뜻이므로 매우 흥미로운(그리고 다뤄야 할) 문제다.

## 예시
```text
곱 최대화 → 합 최대화 → 합 최소화로 변환:
  edge weight r_i  →  새 가중치 = -log(r_i)

  maximize Π r_i  ≡  maximize Σ log(r_i)  ≡  minimize Σ (-log(r_i))

반례 그래프 (다익스트라 실패):
  S -(5)-> A
  S -(20)-> B -(-20)-> A
  → 실제 distance(S, A) = 0 (S→B→A), 다익스트라는 5로 오판
```

## 요약
- 로그를 취하고 부호를 반전하면 "환율 곱 최대화" 문제를 "가중치 합 최소화"라는 표준 최단 경로 문제로 바꿀 수 있다.
- 그러나 이 변환은 음수 가중치 간선을 만들어내며, 다익스트라 알고리즘은 음수 간선이 있으면 정확한 결과를 보장하지 못한다.
- 음수 가중치는 음의 사이클(negative cycle) 문제로 이어지며, 사이클에 도달 가능한 노드들의 거리는 음의 무한대가 될 수 있다. 통화 환전에서는 이것이 무한한 차익거래 가능성을 의미한다.
