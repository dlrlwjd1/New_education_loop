# Currency Exchange

## 개요
- 벨만-포드 알고리즘(Bellman-Ford algorithm)을 소개하는 도입 강의로, 통화 환전(currency exchange) 문제를 통해 동기를 부여한다.
- 다익스트라 알고리즘(Dijkstra's algorithm)과 달리, 벨만-포드 알고리즘은 **간선 가중치에 음수(negative weight)가 있어도** 동작하는 일반적인 최단 경로 알고리즘이다.

## 내용

### 통화 환전 문제
- 여러 통화 사이에는 환전이 가능한 경우와 불가능한 경우가 있다(방향성이 있음: A→B는 가능해도 B→A는 불가능할 수 있다).
- $1,000에서 시작해 러시아 루블(ruble)을 최대한 많이 얻고 싶을 때, 다음 질문에 답하고자 한다.
  - 원하는 만큼 얼마든지 루블을 얻는 것이 가능한가(무한 차익거래)?
  - 원래 통화(달러)로 다시 얼마든지 많이 돌아올 수 있는가?
  - 가능하다면 얻을 수 있는 최대 금액은 얼마인가?

### 차익거래(arbitrage) 예시
- 세 통화(달러, 유로, 파운드)와 세 은행의 환율을 이용한 예시:
  - Dutch Bank: 달러 → 유로, 환율 0.8171
  - Credit Agricole: 유로 → 파운드, 환율 1.1910
  - Barclays: 파운드 → 달러, 환율 1.4650
- $5,000,000으로 시작해 위 순서로 환전하면 최종적으로 $5,025,406을 얻어 $25,406의 차익(arbitrage)이 발생한다.
- 실제로는 이런 차익거래 기회가 잘 발생하지 않지만, 발생한다면 이를 포착해 이익을 낼 수 있어야 한다. 차익거래가 없더라도 여러 단계를 거친 환전이 직접 환전보다 유리할 수 있으므로 최적 경로를 아는 것이 유용하다.

### 그래프로의 변환
- 통화를 노드로, 환전 가능한 방향을 간선으로, 환율을 간선의 가중치로 하는 방향 그래프(directed graph)를 만든다.
- 어떤 경로를 따라 순서대로 환전할 때 최종적으로 얻는 금액의 배수는, 그 경로 위의 **모든 환율(간선 가중치)의 곱**과 같다.
- 따라서 원하는 것은 출발 통화에서 목표 통화까지 가는 모든 경로 중 **환율의 곱이 최대가 되는 경로**를 찾는 것이다.

## 예시
```text
$5,000,000
  → (환율 0.8171, Dutch Bank)   → €4,085,500
  → (환율 1.1910, Credit Agricole) → £3,430,311... (원문 표기 기준)
  → (환율 1.4650, Barclays)     → $5,025,406

차익(arbitrage) = $5,025,406 - $5,000,000 = $25,406
```

## 요약
- 통화 환전 문제는 방향 그래프에서 환율을 가중치로 하는 경로들 중 가중치의 곱이 최대인 경로를 찾는 문제로 표현할 수 있다.
- 이 곱을 최대화하는 문제를 표준적인 최단 경로(합을 최소화하는) 문제로 바꾸는 방법은 다음 영상에서 다룬다.
