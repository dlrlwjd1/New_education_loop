# Proof of Correctness

## 개요
- 다익스트라 알고리즘(Dijkstra's algorithm)이 출발 노드로부터 모든 노드까지의 정확한 최단 거리를 반환함을 증명한다.
- 핵심은 `ExtractMin`으로 큐에서 꺼내지는 순간, 그 노드의 dist 값이 이미 정확한 최단 거리와 같다는 보조정리(lemma)다.

## 내용

### 핵심 보조정리
- **보조정리**: 우선순위 큐에서 `ExtractMin`으로 노드 u가 선택되는 시점에, `dist[u]`는 이미 출발 노드로부터 u까지의 실제 거리와 같다.
- dist 값은 항상 실제 거리의 상한(upper bound)이므로, 이 보조정리가 성립하면 알고리즘 종료 시 모든 dist 값이 정확한 거리와 일치하게 된다.

### 증명(귀류법)
- 어떤 그래프에서 어느 시점에 dist 값이 실제 거리와 다른 노드를 알려진 영역(known region) R에 추가한다고 가정하자.
- R 밖의 노드들 중 dist 값이 최소인 노드를 D라 하고, D의 dist 값(예: 6)이 실제 최단 거리와 다르다고 가정한다. dist 값은 상한이므로 실제 거리는 이보다 더 짧아야 한다.
- 출발 노드는 R 안에 있고 D는 R 밖에 있으므로, D로 가는 더 짧은 실제 경로는 어느 시점에 R에서 R 밖으로 나가는 간선을 지나야 한다. 이 간선을 (C, G)라 하자(C는 R 안, G는 R 밖).
- C는 이미 확정되어 있으므로 `dist[C]`는 실제 거리와 같다. 이 경로가 C를 거쳐 G로 나가면, G까지의 거리는 이미 알려진 `dist[G]`(예: 7) 이상이어야 한다. R에서 막 나온 경로이므로 이보다 짧을 수 없다.
- G에서 D까지 나머지 구간은 하나 이상의 간선을 거치며, 모든 간선의 가중치가 음이 아니므로 이 구간의 길이는 0 이상이다.
- 따라서 전체 경로의 길이는 `dist[G]` 이상이며, `dist[G]`는 R 밖 노드들 중 최솟값인 `dist[D]`보다 크거나 같다. 즉 이 "더 짧다고 가정한 경로"도 `dist[D]`보다 짧을 수 없다.
- 이는 D의 실제 거리가 `dist[D]`보다 짧다는 가정과 모순된다. 따라서 보조정리가 성립하며, 다익스트라 알고리즘은 항상 정확한 dist 값을 반환한다.

### 최단 경로 재구성
- BFS(breadth-first search)에서와 마찬가지로, `prev` 값은 언제나 "현재까지 알려진 최적 경로 상에서 바로 이전 노드"를 가리킨다.
- 알고리즘이 종료하면 dist 값이 실제 최단 거리와 같아지므로, `prev` 값도 실제 최단 경로 트리(shortest path tree)를 나타낸다.
- 목표 노드에서 `prev`를 따라 출발 노드까지 거슬러 올라간 뒤 뒤집으면, 출발 노드로부터의 최단 경로를 얻을 수 있다. 복원 절차는 BFS의 경우와 완전히 동일하다.

## 요약
- 다익스트라 알고리즘의 정확성은 "ExtractMin으로 선택되는 순간 그 노드의 dist가 이미 정확하다"는 보조정리로부터 증명된다.
- 증명의 핵심은 R 안에서 R 밖으로 나가는 간선을 반드시 거쳐야 하고, 이후 구간의 가중치가 음이 아니므로 더 짧은 경로가 존재할 수 없다는 점이다.
- prev 값을 따라가면 BFS와 동일한 방식으로 최단 경로를 복원할 수 있다.
