# Negative Cycles

## 개요
- 벨만-포드 알고리즘(Bellman-Ford algorithm)을 확장해, 그래프에 음의 사이클(negative cycle)이 존재하는지 판별하고, 존재한다면 그중 하나를 실제로 찾아내는 방법을 다룬다.

## 내용

### 판별 아이디어: V번째 추가 반복
- V-1번의 표준 반복 이후, **한 번 더(V번째) 모든 간선을 완화 시도**해 본다.
- **보조정리**: 이 V번째 반복에서 어떤 dist 값이든 갱신이 일어난다 ⟺ 그래프에 음의 사이클이 존재한다.

### 증명 — 음의 사이클이 없으면 V번째 반복에서 아무것도 바뀌지 않는다
- 음의 사이클이 없으면 모든 최단 경로는 최대 V-1개의 간선만 사용한다(사이클을 포함하는 경로는 사이클을 제거해도 길이가 줄거나 같기 때문).
- 따라서 V-1번째 반복까지 모든 dist 값은 이미 정확한 최단 거리이며, V번째 반복에서는 더 이상 갱신될 것이 없다.

### 증명 — 음의 사이클이 있으면 V번째 반복에서 반드시 뭔가 바뀐다
- 귀류법: 길이 3인 사이클 A→B→C→A가 음의 사이클이라 가정하고, 추가 반복에서 세 간선 모두 완화되지 않았다고 가정하자.
- 완화되지 않았다는 것은 세 부등식이 성립한다는 뜻이다: `dist[B] ≤ dist[A] + weight(A,B)`, `dist[C] ≤ dist[B] + weight(B,C)`, `dist[A] ≤ dist[C] + weight(C,A)`.
- 세 부등식을 양변끼리 더하면 양쪽에 `dist[A] + dist[B] + dist[C]`가 공통으로 나타나 상쇄되고, `weight(A,B) + weight(B,C) + weight(C,A) ≥ 0`이 남는다.
- 그런데 이는 이 사이클이 음의 사이클이라는 가정(합이 음수)과 모순된다. 사이클의 길이가 3보다 길어도 동일한 논리가 성립한다.
- 따라서 음의 사이클이 있다면 V번째 반복에서 반드시 어떤 완화가 일어난다.

### 음의 사이클 찾아내기
- V번째 반복에서 성공적으로 완화되어 dist 값이 바뀐 노드 v를 하나 저장해 둔다. 이 v는 반드시 음의 사이클로부터 도달 가능(reachable)하다.
  - 이유: v의 dist가 이 반복에서 갱신되었다는 것은 간선을 V개 이상 사용하는, 더 짧은 경로가 존재한다는 뜻이다. 이런 경로는 반드시 사이클을 포함하며, 사이클을 제거했을 때 경로가 더 길어져야만(즉 사이클이 음수여야만) V번째 반복에서 갱신이 일어날 수 있다.
- **사이클 복원 절차**:
  1. `x = v`로 시작해 `prev` 링크를 따라 V번 거슬러 올라간다. V번 이동하면 반드시 사이클 위의 어떤 노드에 도달하게 된다.
  2. 이 노드를 `y`로 저장한다.
  3. 다시 `prev` 링크를 따라가며 `y`로 돌아올 때까지 지나는 노드들을 순서대로 기록한다. 이 노드들이 곧 음의 사이클을 이룬다.

### 음의 사이클과 차익거래(arbitrage)의 관계 — 주의할 함정
- 음의 사이클을 찾았다고 해서 항상 $1,000를 원하는 만큼의 루블로 바꿀 수 있는 것은 아니다.
- 예: 달러→유로, 루블→유로 간선은 있지만, 유로-파운드-크로네 사이에 음의 사이클(즉 세 환율의 곱이 1보다 큰 사이클)이 있다고 하자. 달러에서 유로로 간 뒤 이 사이클을 이용해 유로를 무한히 늘릴 수는 있지만, **유로에서 루블로 가는 간선 자체가 없다면** 달러를 루블로 바꾸는 무한 차익거래는 불가능하다.
- 즉 "음의 사이클이 존재한다"는 사실만으로는 특정 두 통화 사이의 무한 차익거래 가능 여부를 판단하기에 충분하지 않다. 이 문제는 다음 영상에서 다룬다.

## 예시
```text
# 음의 사이클 판별
1. Bellman-Ford의 V-1번 표준 반복을 수행한다.
2. 모든 간선에 대해 V번째 완화를 한 번 더 시도한다.
3. 이때 dist 값이 하나라도 바뀌면 음의 사이클이 존재한다.

# 음의 사이클 복원
v = (V번째 반복에서 갱신된 임의의 노드)
x = v
V번 반복: x = prev[x]      # 이제 x는 사이클 위의 한 노드
y = x
cycle = [y]
반복: x = prev[x]; cycle.append(x)
until x == y
```

## 요약
- V-1번의 표준 반복 후 한 번 더(V번째) 완화를 시도해, 갱신이 일어나면 음의 사이클이 존재한다고 판별할 수 있다.
- V번째 반복에서 갱신된 노드로부터 prev 링크를 V번 거슬러 올라가면 사이클 위의 노드에 도달하며, 이를 이용해 실제 사이클을 복원할 수 있다.
- 음의 사이클이 존재한다는 사실만으로는 임의의 두 통화 사이의 무한 차익거래가 항상 가능한 것은 아니며, 사이클과 목표 노드 사이의 도달 가능성(reachability)까지 함께 확인해야 한다.
