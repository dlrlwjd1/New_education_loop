# Programming Project: Introduction

## 개요
- 이번 모듈은 고급 최단 경로(advanced shortest paths) 알고리즘을 다루는 프로그래밍 프로젝트로 구성된다.
- 실제 도로망(road network)과 소셜 네트워크(social network) 데이터를 다루며, 이전 모듈보다 자유도가 높은 창의적 최적화가 요구된다.

## 내용

### 프로젝트의 성격
- 이전 모듈들의 프로그래밍 과제와 비슷한 형식의 연속 과제(series of programming assignments)로 진행된다.
- 실제 도로망과 소셜 네트워크에 기반한 데이터를 다룬다.
- 알고리즘 개선에 대한 창의적인 아이디어를 자유롭게 시도할 수 있으며, 포럼(forum)에서 다른 학습자들과 알고리즘 속도를 경쟁할 수도 있다.

### 사전 지식
- 이전 모듈에서 배운 고전적인 최단 경로 알고리즘들, 즉 너비 우선 탐색(breadth-first search, BFS), 다익스트라 알고리즘(Dijkstra's algorithm), 벨만-포드 알고리즘(Bellman-Ford algorithm)을 이미 다뤘다.
- 이 모듈에서 배우는 고급 알고리즘들은 모두 고전적인 다익스트라 알고리즘을 기반으로 한 최적화이며, 실무에서는 수천 배에서 수백만 배까지 빨라질 수 있다. 다만 이러한 최적화는 특정 종류의 그래프에 특화되어 있다(예: 어떤 알고리즘은 도로망에 강하고, 다른 알고리즘은 소셜 네트워크에 강하다).
- 프로젝트를 시작하기 전, 다익스트라 알고리즘의 동작 원리를 복습하고 이전 모듈의 다익스트라 기반 문제들을 풀 수 있는지 확인할 것을 권장한다.

## 요약
- 이번 모듈은 실제 데이터 기반의 고급 최단 경로 프로그래밍 프로젝트다.
- 모든 고급 알고리즘은 다익스트라 알고리즘의 최적화이므로, 진행 전 다익스트라 알고리즘에 대한 이해를 복습해야 한다.
