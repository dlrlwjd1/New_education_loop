# Bidirectional Search

## 개요
- 양방향 탐색(bidirectional search)의 아이디어를 소개하고, 이를 다익스트라 알고리즘(Dijkstra's algorithm)에 적용하는 방향을 제시한다.
- 다익스트라 알고리즘의 조기 종료(early stopping) 최적화에서 출발해, 시작점과 목표점 양쪽에서 동시에 탐색을 진행하는 방식으로 발전시킨다.
- 실제 도로망(road network) 데이터에 적용했을 때의 성능 개선 정도를 측정한다.

## 내용

### 문제 정의와 동기
- 방향 그래프(directed graph) 또는 무방향 그래프(undirected graph) $G$가 있고, 간선 가중치(edge weight)는 모두 음이 아니다(nonnegative). 시작 정점 $s$와 목표 정점 $t$가 주어졌을 때 최단 경로를 구하는 문제다.
- 일반 다익스트라 알고리즘의 최악 시간 복잡도는 $O(E + V \log V)$로 이미 우수하지만, 실무에서는 이보다 훨씬 빠른 응답이 필요하다.
  - 무방향 그래프에서는 Mikkel Thorup이 1999년에 선형 시간(linear time) 알고리즘을 제시했으나, 방향 그래프에서는 아직 선형 시간 알고리즘이 알려져 있지 않다.
  - 미국 지도(정점 약 2천만 개, 간선 약 5천만 개) 규모에서 일반 다익스트라는 평균 몇 초가 걸리지만, 지도 서비스 등에서는 100밀리초 이하의 응답이 필요하다.

### 다익스트라 알고리즘의 진행 방식과 조기 종료
- 다익스트라 알고리즘은 거리가 증가하는 순서로 정점을 처리(process)한다. 정점 $u$가 `ExtractMin`으로 뽑힐 때, 그 거리 추정값(distance estimate)은 실제 거리와 같음이 보장되며, 그보다 가까운 모든 정점은 이미 처리되어 있다.
- 이 때문에 처리된 정점들의 집합은 시작 정점을 중심으로 한 "원(circle)"처럼 커진다.
- **조기 종료(early stopping)**: 목표 정점 $t$까지의 최단 경로만 필요하다면, $t$가 처리되는 순간 알고리즘을 멈출 수 있다. 그래프의 모든 정점까지 거리를 구할 필요가 없다.

### 양방향 탐색의 아이디어
- 시작 정점 $s$에서만 원을 키우는 대신, $s$에서 정방향으로, $t$에서 역방향으로 동시에(실제로는 교대로) 원을 키워 두 원이 만날 때까지 진행한다.
- 두 탐색이 만나면, $s$에서 만난 지점까지의 절반 경로와 만난 지점에서 $t$까지의 절반 경로를 이어 붙여 최단 경로를 구성한다.
- 구체적으로는 $s$에서 정방향 다익스트라 한 턴, $t$에서 역방향 다익스트라 한 턴을 번갈아 수행한다. 역방향 탐색을 위해서는 각 정점의 나가는 간선뿐 아니라 들어오는 간선(incoming edge) 정보도 필요하다.

### 원 넓이를 이용한 이론적 비교
- 일반 다익스트라가 처리하는 정점 수는 반지름이 $2r$인 큰 원 $C_1$의 넓이에 비례한다고 가정하면, $C_1$의 넓이는 $\pi (2r)^2 = 4\pi r^2$이다.
- 양방향 탐색은 반지름이 각각 $r$인 두 원 $C_2$, $C_3$의 넓이 합, 즉 $2 \times \pi r^2 = 2\pi r^2$에 비례한다.
- 따라서 양방향 탐색이 처리하는 정점 수는 일반 다익스트라의 약 절반 정도로 추정된다.

## 예시

### 실제 도로망에서의 성능
- 정점 약 160만 개, 간선 약 380만 개인 미국 지도 일부 구간에서 시작점(파란 사각형)과 목표점(초록 사각형) 사이 최단 경로를 구한 결과, 일반 다익스트라는 넓은 영역의 정점을 모두 탐색한 반면 양방향 탐색은 두 지점 주변에 각각 원 모양(지도 격자 특성상 45도 회전한 사각형에 가까움) 영역만 탐색했다.
- 도로망에서는 양방향 탐색이 대략 2배(2x) 정도의 속도 향상을 준다. 기대했던 수천 배 향상에는 못 미치지만, 다음 강의에서 다룰 소셜 네트워크(social network)에서는 이 양방향 탐색 아이디어가 훨씬 더 극적인 효과를 낸다.

## 요약
- 다익스트라 알고리즘은 목표 정점만 필요하면 그 정점이 처리되는 순간 멈추는 조기 종료로 최적화할 수 있다.
- 양방향 탐색은 시작점과 목표점에서 동시에(교대로) 다익스트라를 진행해 두 탐색이 만나는 순간 절반씩 경로를 합쳐 최단 경로를 구성하는 방식이다.
- 원의 넓이 비교를 통해 양방향 탐색이 이론적으로 정점 탐색 범위를 절반 정도로 줄이며, 실제 도로망에서도 약 2배의 속도 향상을 보인다.
