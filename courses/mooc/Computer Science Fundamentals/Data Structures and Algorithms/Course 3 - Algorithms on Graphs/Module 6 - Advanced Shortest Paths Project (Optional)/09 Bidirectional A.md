# Bidirectional A*

## 개요
- A* 알고리즘에 양방향 탐색(bidirectional search)을 결합해 양방향 A*(Bidirectional A*) 알고리즘을 만든다.
- 순방향 탐색과 역방향 탐색에 서로 다른 두 퍼텐셜 함수(potential function)가 필요하며, 두 방향의 간선 가중치를 일치시키기 위한 퍼텐셜 조합 방법을 다룬다.
- 두 퍼텐셜을 조합해도 여전히 실행 가능(feasible)함을 증명하는 보조정리(Lemma)를 다룬다.

## 내용

### 두 개의 퍼텐셜 함수가 필요한 이유
- 순방향 탐색에는 현재 지점에서 목표까지의 거리를 추정하는 퍼텐셜 πf(v)가 필요하다.
- 역방향 탐색(목표에서 시작하는 Dijkstra)에는 출발점(source)까지의 거리를 추정하는 퍼텐셜 πr(v)가 필요하다.
- 순방향 퍼텐셜 πf에 따른 새 간선 가중치는 l(u,v) − πf(u) + πf(v)이고, 역방향 퍼텐셜 πr에 따른 새 간선 가중치는 l(u,v) − πr(v) + πr(u)이다.
- 양방향 Dijkstra(Bidirectional Dijkstra)가 올바르게 동작하려면 같은 간선이 순방향과 역방향에서 동일한 가중치를 가져야 하는데, 위 두 식은 일반적으로 같지 않다.

### 가중치 일치 조건과 해법
- 두 식이 같으려면 lπf(u,v) = lπr(u,v), 즉 πf(u) + πr(u) = πf(v) + πr(v)가 간선으로 연결된 모든 u, v에 대해 성립해야 한다.
- 더 강한 조건으로 πf(u) + πr(u)가 모든 정점 u에 대해 상수(constant)이면, 임의의 두 정점 u, v에 대해서도 자동으로 성립한다.
- 해법: 순방향에 대해 실행 가능한 임의의 퍼텐셜 πf와 역방향에 대해 실행 가능한 임의의 퍼텐셜 πr을 각각 구한 뒤, 새로운 퍼텐셜을 다음과 같이 정의한다.
  - pf(u) = (πf(u) − πr(u)) / 2
  - pr(u) = −pf(u)
- 이렇게 정의하면 pf(u) + pr(u) = 0으로 모든 u에 대해 상수(0)가 되어 가중치 일치 조건을 만족한다.

### 보조정리 — 절반 차이 퍼텐셜의 실행 가능성
- πf가 순방향에 대해 실행 가능하고 πr이 역방향에 대해 실행 가능하면, 이 둘의 절반 차이 pf = (πf − πr)/2 는 순방향에 대해 실행 가능한 퍼텐셜이다(대칭적으로 pr도 역방향에 대해 실행 가능하다).
- 증명:
  - πf가 실행 가능: 임의의 간선 (u, v)에 대해 l(u,v) − πf(u) + πf(v) ≥ 0
  - πr이 역방향에 대해 실행 가능: l(u,v) − πr(v) + πr(u) ≥ 0
  - 두 부등식을 더하면: 2·l(u,v) − πf(u) + πr(u) + πf(v) − πr(v) ≥ 0
  - 양변을 2로 나누면: l(u,v) − (πf(u) − πr(u))/2 + (πf(v) − πr(v))/2 ≥ 0
  - 이는 정확히 pf가 실행 가능하다는 조건이다.

### 의의
- 이 보조정리 덕분에 좋은 퍼텐셜 함수를 가진 그래프가 있다면, 그래프를 뒤집어(reverse) 역방향 퍼텐셜도 구하고, 두 퍼텐셜을 조합해 순방향·역방향 가중치가 같은 새로운 퍼텐셜 쌍을 얻을 수 있다.
- 결과적으로 양방향 A*는 "퍼텐셜을 사용하는 양방향 Dijkstra"로 구현할 수 있으며, 양방향 탐색과 방향성 탐색(directed search)의 장점을 모두 취해 일반 양방향 Dijkstra나 일반 Dijkstra 기반 A*보다 더 빠르게 동작한다.
- 남은 문제는 "좋은 퍼텐셜을 어디서 얻는가"이며, 이후 강의(유클리드 거리, 랜드마크)에서 다룬다.

## 예시
- 순방향 새 간선 가중치: lπf(u, v) = l(u, v) − πf(u) + πf(v)
- 역방향 새 간선 가중치: lπr(u, v) = l(u, v) − πr(v) + πr(u)
- 조합 퍼텐셜: pf(u) = (πf(u) − πr(u)) / 2, pr(u) = −pf(u)
- 실행 가능성 증명의 핵심 부등식: 2·l(u,v) − πf(u) + πr(u) + πf(v) − πr(v) ≥ 0 ⇒ l(u,v) − pf(u) + pf(v) ≥ 0

## 요약
- 양방향 A*는 양방향 Dijkstra에 순방향·역방향 두 퍼텐셜을 함께 사용하는 방식이다.
- 두 방향의 간선 가중치를 일치시키려면 πf와 πr의 절반 차이로 새 퍼텐셜을 정의해야 하며, 이 퍼텐셜은 항상 실행 가능함이 증명된다.
- 이를 통해 양방향 A*는 "퍼텐셜을 사용하는 양방향 Dijkstra"로 구현되며, 양방향성과 방향성 탐색의 장점을 모두 얻는다.
