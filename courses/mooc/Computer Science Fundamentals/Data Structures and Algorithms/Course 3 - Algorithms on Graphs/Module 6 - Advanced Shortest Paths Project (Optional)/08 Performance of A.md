# Performance of A*

## 개요
- A* 알고리즘(A* algorithm)의 실제 성능은 잠재 함수(potential function)의 품질에 따라 크게 달라지는 경험적(empirical) 특성을 갖는다는 점을 다룬다.
- 최악의 경우와 최선의 경우를 비교해, 잠재 함수(하한 추정치)가 정확할수록 성능이 좋아짐을 설명한다.

## 내용

### 최악의 경우
- 잠재 함수 $\pi$가 모든 정점에서 항상 0이라면, 이는 항상 실현 가능한(feasible) 잠재 함수이지만 A* 알고리즘은 일반 다익스트라 알고리즘과 완전히 동일하게 동작한다. 즉 더 나빠지지는 않지만 개선도 없다.

### 최선의 경우
- 잠재 함수가 목표까지의 실제 거리와 정확히 일치하는 하한(lower bound)이라면, 최단 경로 위에 있는 간선의 새 가중치($l_\pi$)는 정확히 0이 되고, 그렇지 않은 간선은 0보다 크다.
- 이 경우 어느 간선으로 가야 할지(가중치 0인 간선만) 쉽게 구분할 수 있어, 시작점에서 목표점까지 최단 경로 위에 있는 간선들만 탐색하게 된다. 즉 반드시 필요한 최소한의 간선만 탐색하는 최선의 경우가 된다.

### 실제 성능
- 실무에서의 성능은 잠재 함수(하한 추정치)의 품질에 따라 최악과 최선 사이 어딘가에 위치한다.
- 하한이 실제 거리에 더 가까울수록(더 타이트할수록, tighter) A* 알고리즘의 성능이 더 좋아진다는 것이 알려져 있다.
- 다음 강의에서는 이 A* 알고리즘을 양방향(bidirectional)으로 확장해 성능을 더 개선하는 방법을 다룬다.

## 요약
- A* 알고리즘의 성능은 잠재 함수의 품질에 의존하는 경험적 알고리즘이다.
- 잠재 함수가 항상 0이면 일반 다익스트라와 동일하고(최악), 목표까지의 실제 거리와 정확히 같으면 최단 경로 위의 간선만 탐색하게 된다(최선).
- 하한 추정치가 정확할수록(타이트할수록) A*의 실제 성능이 향상된다.
