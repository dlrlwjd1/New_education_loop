# Potential Functions and Lower Bounds

## 개요
- A* 알고리즘을 실제로 구현하려면 실행 가능(feasible)하고 성능이 좋은 퍼텐셜 함수(potential function)가 필요하다.
- 퍼텐셜 함수가 실행 가능하고 목표 정점의 퍼텐셜이 0 이하이면, 그 퍼텐셜은 항상 실제 최단 거리(shortest distance)의 하한(lower bound)이 된다는 보조정리(Lemma)를 증명한다.
- 평면 지도(road network on a plane)에서 유클리드 거리(Euclidean distance)가 실제로 실행 가능하고 좋은(feasible and good) 퍼텐셜 함수임을 보인다.

## 내용

### 보조정리 — 실행 가능한 퍼텐셜은 하한이다
- 퍼텐셜 함수 π가 실행 가능(feasible)하면, 새 그래프에서의 간선 길이 lπ(x, y)는 어떤 x, y에 대해서도 음수가 아니다(non-negative).
- 따라서 새 그래프에서 임의의 경로 P의 길이 lπ(P)도 음수가 아니다.
- 정점 v에서 목표 t까지의 최단 경로를 P라 하면: 0 ≤ lπ(P) = l(P) − π(v) + π(t)
- 목표 정점의 퍼텐셜 π(t)가 0 이하(non-positive)라고 가정하면: 0 ≤ l(P) − π(v)
- 따라서 π(v) ≤ l(P) = d(v, t) (v에서 t까지의 실제 최단 거리)
- 즉, 실행 가능하고 π(t) ≤ 0인 퍼텐셜 함수는 항상 실제 거리의 하한이다.

### 유클리드 거리 퍼텐셜 (Euclidean distance potential)
- 평면 지도에서 각 정점은 좌표 (x, y)를 가진다.
- 퍼텐셜을 다음과 같이 정의한다: π(v) = v와 목표 t 사이의 유클리드 거리(직선 거리)
- 이 값은 두 점을 잇는 선분(line segment)의 길이이므로, 도로망(road network)에서 어떤 경로도 이 직선 거리보다 짧을 수 없다. 따라서 직관적으로도 항상 실제 최단 거리의 하한이 된다.
- 목표 정점 자신에 대한 퍼텐셜은 0이다(자기 자신까지의 거리는 0이므로).

### 유클리드 거리 퍼텐셜이 실행 가능함(feasible)을 증명
- 임의의 간선 (u, v)의 길이는 u와 v 사이의 유클리드 거리보다 크거나 같다. 선분이 두 점 사이의 최단 경로이기 때문이다.
- 삼각 부등식(triangle inequality)에 의해: 유클리드거리(u, t) ≤ 유클리드거리(u, v) + 유클리드거리(v, t)
- 여기서 유클리드거리(u, v) ≤ l(u, v)이고, 유클리드거리(v, t) = π(v)이므로: π(u) ≤ l(u, v) + π(v)
- 정리하면: l(u, v) − π(u) + π(v) ≥ 0
- 이는 정확히 새 그래프에서의 간선 길이(lπ)이므로, 새 그래프의 모든 간선 가중치가 음수가 아니다. 즉 π는 실행 가능하다.

### 실제 구현 방법
- 각 정점 v에 대해 π(v) = v와 목표 t 사이의 유클리드 거리를 미리 계산(precompute)하거나 그때그때 계산(on the fly)한다.
- v와 t의 좌표만 있으면 상수 시간(constant time)에 계산할 수 있다.
- 이 퍼텐셜 π(v)를 사용해 Dijkstra 알고리즘을 실행하면 그것이 곧 A* 알고리즘이다.
- 유클리드 거리 퍼텐셜만 사용해도 일반 Dijkstra보다 빠르게 동작한다.

## 예시
- 새 그래프의 간선 길이 정의: lπ(u, v) = l(u, v) − π(u) + π(v)
- 유클리드 거리: 유클리드거리(v, t) = √((v.x − t.x)² + (v.y − t.y)²)
- 하한 보조정리 핵심 부등식: π(v) ≤ l(P) − π(v) + π(t) ≥ 0 ⇒ π(v) ≤ d(v, t) (π(t) ≤ 0일 때)

## 요약
- 실행 가능하고 π(t) ≤ 0인 퍼텐셜 함수는 항상 실제 최단 거리의 하한이다.
- 평면 도로망에서 목표까지의 유클리드 거리를 퍼텐셜로 사용하면 실행 가능성 조건을 만족하며, 상수 시간에 계산 가능하다.
- 이 퍼텐셜로 Dijkstra를 실행하는 것이 곧 A* 알고리즘이며, 일반 Dijkstra보다 빠르다.
