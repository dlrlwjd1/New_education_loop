# Query

## 개요
- Contraction Hierarchies로 전처리된 증강 그래프(augmented graph)에서 두 정점 사이의 거리를 구하는 질의(query) 알고리즘을 다룬다.
- 전체 간선이 아니라 정점 축약 순서(node order)에 따른 상향 간선(upward edge)만 사용하는 변형된 양방향 Dijkstra(Bidirectional Dijkstra)를 사용한다.
- ComputeDistance 의사코드(pseudocode)를 통해 구체적인 절차를 설명한다.

## 내용

### 상향 간선만 사용하는 양방향 탐색
- 정점 축약 순서(노드가 나중에 축약될수록 더 중요함)를 아래에서 위로 갈수록 중요도가 높아지는 방향으로 그린다.
- 두 정점 사이의 최단 경로는 이 그림에서 먼저 위로 올라갔다가(increasing) 다시 아래로 내려오는(decreasing) 형태를 가진다는 성질을 이용한다.
- 순방향 탐색은 출발점에서 위로 향하는 간선만 사용하고, 역방향 탐색은 목표점에서 위로 향하는 간선만 사용해, 두 탐색이 만나는 지점(경로 상 가장 중요도가 높은 정점)에서 경로를 완성한다.
- 정점 A에서 B로 가는 간선이 있을 때, A가 B보다 먼저 축약되었다면(즉 A가 덜 중요하면) 이 간선은 위로 향하는 간선이므로 저장한다. 반대로 B가 먼저 축약되었다면 이 간선은 아래로 향하는 간선이므로 질의에서 전혀 쓰이지 않아 저장할 필요가 없다(삭제 가능).

### 일반 양방향 Dijkstra와의 차이 — 종료 조건
- 일반 양방향 Dijkstra는 어떤 정점이 순방향과 역방향 탐색 모두에서 처리(process)되는 순간 멈추고 최단 거리를 계산한다.
- 이 알고리즘은 그렇게 하지 않고, 추출된 정점의 거리가 이미 현재까지의 목표 거리 추정치(estimate)보다 커지는 순간에만 멈춘다.

### ComputeDistance 의사코드
- 입력: 출발점 s, 목표점 t (그래프와 역방향 그래프도 암묵적으로 필요).
- 상향 간선만 저장하면 되므로, 저장되는 그래프는 이미 축약 순서에 따라 걸러진 그래프다.
- estimate(현재까지의 s-t 거리 추정치)를 +무한대로 초기화한다(아직 경로를 모르므로).
- 순방향/역방향 각각의 거리 배열을 +무한대로 초기화하고, dist(s)=0, distR(t)=0으로 설정한다. 처리된 정점 목록(proc, procR)도 준비한다.
- 순방향 또는 역방향 큐에 처리할 정점이 남아있는 동안 메인 루프를 반복한다.
  - 순방향 큐에서 정점 v를 꺼낼 수 있으면, v까지의 거리(dist(v))가 이미 estimate보다 크면 그 정점은 더 이상 처리하지 않는다(큐에 넣지도, 이웃을 확장하지도 않는다).
  - 그렇지 않으면 일반 Dijkstra와 같은 방식으로 처리(relax)한다.
  - 만약 v가 이미 역방향 탐색에서도 처리된 정점(v ∈ procR)이라면, v는 양쪽 탐색 모두에서 처리된 것이므로 s에서 v를 거쳐 t로 가는 경로의 길이 dist(v) + distR(v)를 계산해, 이 값이 현재 estimate보다 작으면 estimate를 갱신한다.
  - 역방향 탐색도 순방향과 대칭적으로 동일하게 처리한다.
- 모든 큐가 빌 때까지 루프를 반복한 뒤, 최종 estimate 값을 s-t 거리로 반환한다.

### 남은 문제 — 정확성과 경로 복원
- ComputeDistance가 항상 초기 그래프에서의 정확한 s-t 거리와 같은 값을 반환하는지는 아직 증명되지 않았다(다음 강의에서 증명).
- ComputeDistance는 거리 추정치만 반환하며, 실제 최단 경로 자체는 반환하지 않는다.
- 경로 복원은 일반 양방향 Dijkstra처럼 각 정점에 "최단 경로 상의 이전 정점"을 기록해 해결할 수 있다.
- 다만 복원된 경로의 일부 간선은 지름길(shortcut)일 수 있으므로, 전처리 단계에서 각 지름길에 대해 "그 지름길이 어떤 두 간선을 대체했는지"도 함께 저장해 두어야 한다.
- 지름길을 재귀적으로(recursively) 원래의 두 간선으로 치환하는 과정을 반복하면, 결국 초기 그래프의 간선만으로 이루어진 최종 경로를 복원할 수 있다.

## 예시
- 상향 간선 저장 규칙: 간선 A→B에서 A가 B보다 먼저 축약되었으면 저장(상향), B가 먼저 축약되었으면 저장하지 않음(하향, 질의에 불필요)
- 경로 복원 시 거리 갱신 조건: v ∈ procR 이고 dist(v) + distR(v) < estimate 이면 estimate ← dist(v) + distR(v)
- 종료 조건: 순방향에서 추출한 정점 v의 dist(v) > estimate 이면 그 정점을 확장하지 않음(일반 양방향 Dijkstra의 "양쪽에서 처리된 순간 종료"와 다름)

## 요약
- 증강 그래프에서의 질의는 정점 축약 순서에 따른 상향 간선만 사용하는 변형된 양방향 Dijkstra(ComputeDistance)로 수행한다.
- 종료 조건이 일반 양방향 Dijkstra와 달리, 추출된 정점의 거리가 현재 추정치보다 커지는 순간까지 계속 처리한다.
- 실제 최단 경로는 지름길을 원래 두 간선으로 재귀적으로 치환하는 방식으로 복원할 수 있으며, 알고리즘의 정확성은 다음 강의에서 증명한다.
