# A* Algorithm

## 개요
- A* 알고리즘(A-star algorithm)은 시작점과 목표점이 고정되어 있고, 임의의 지점에서 목표점까지 남은 거리를 추정할 수 있을 때 다익스트라 알고리즘(Dijkstra's algorithm)을 최적화하는 방법이다.
- 이를 위해 잠재 함수(potential function)라는 개념을 도입하고, 잠재 함수로 간선 가중치를 바꿔도 최단 경로 자체는 변하지 않는다는 것을 증명한다.
- 이 성질을 이용해 "잠재 함수를 적용한 다익스트라(Dijkstra with potentials)"를 정의하고, 이것이 곧 A* 알고리즘임을 보인다.

## 내용

### 방향 탐색(directed search)과 잠재 함수(potential function)
- 잠재 함수 $\pi$는 정점을 실수로 대응시키는 임의의 함수이며, $\pi(v)$를 정점 $v$의 잠재값(potential)이라 한다.
- 원래 간선 가중치가 $l(u, v)$일 때, 새로운 간선 가중치를 다음과 같이 정의한다.

$$l_\pi(u, v) = l(u, v) - \pi(u) + \pi(v)$$

- GPS 좌표처럼 목표 지점까지의 직선 거리(및 속도)를 잠재값으로 쓸 수 있다. 실제 경로가 직선 거리보다 짧을 수 없으므로, 이런 잠재값은 목표까지 남은 거리의 하한(lower bound) 역할을 한다.

### 잠재 함수가 최단 경로를 바꾸지 않음을 증명
- **보조정리**: 임의의 잠재 함수 $\pi$, 고정된 두 정점 $s$, $t$, 그리고 $s$에서 $t$로 가는 임의의 경로 $P$에 대해, 새 가중치 기준 경로 길이는 다음과 같다.

$$l_\pi(P) = l(P) - \pi(s) + \pi(t)$$

- 경로 $P$를 $v_1(=s), v_2, \dots, v_k(=t)$라 하면, 새 가중치 경로 길이는 $\sum l_\pi(v_i, v_{i+1}) = \sum \big(l(v_i, v_{i+1}) - \pi(v_i) + \pi(v_{i+1})\big)$이다.
- 각 항을 나열하면 중간 정점들의 $\pi(v_2), \pi(v_3), \dots, \pi(v_{k-1})$ 항이 서로 부호가 반대로 상쇄(cancel out)되고, 남는 것은 원래 가중치의 합 $l(P)$에서 $\pi(v_1) = \pi(s)$를 빼고 $\pi(v_k) = \pi(t)$를 더한 값뿐이다.
- 즉 $s$, $t$를 고정하면 모든 경로의 새 가중치 길이는 원래 길이에서 항상 같은 상수 $-\pi(s) + \pi(t)$만큼만 차이가 난다. 따라서 원래 그래프에서 가장 짧았던 경로는 새 그래프에서도 가장 짧고, 그 역도 성립한다.

### 잠재 함수를 적용한 다익스트라(Dijkstra with potentials)
- 잠재 함수 $\pi$를 정하고, 원래 가중치 $l$ 대신 새 가중치 $l_\pi$로 다익스트라 알고리즘을 실행하면 결과 경로는 원래 그래프에서도 최단 경로다.
- 단, 모든 간선의 새 가중치 $l_\pi(u,v)$가 음수가 아니어야 다익스트라를 적용할 수 있다. 이 조건을 만족하는 잠재 함수를 실현 가능(feasible)하다고 한다.
- $\pi(v)$가 $v$에서 목표 $t$까지 거리의 하한(lower bound)인 경우가 많으며, 이런 추정값이 있으면 잘못된 방향으로 가는 탐색을 피할 수 있어 "방향 탐색(directed search)"이 가능해진다.

### A* 알고리즘의 정점 선택 기준
- 잠재 함수를 적용한 다익스트라는 매 반복마다 다음 식을 최소화하는 정점 $v$를 선택한다.

$$\text{dist}_\pi(v) = \text{dist}(v) - \pi(s) + \pi(v)$$

- $\pi(s)$는 모든 $v$에 대해 같은 상수이므로, 이 식을 최소화하는 것은 $\text{dist}(v) + \pi(v)$를 최소화하는 것과 같다.
- $\text{dist}(v)$는 $s$에서 $v$까지 알려진 최선의 경로 길이이고, $\pi(v)$는 $v$에서 $t$까지 남은 거리의 추정값이므로, 이 합은 "$v$를 거쳐 가는 $s$-$t$ 경로 길이의 추정값"이다.
- 즉 A* 알고리즘은 단순히 $s$에서 가장 가까운 정점이 아니라, $s$에서부터의 거리와 목표까지 남은 추정 거리의 합이 가장 작은(가장 유망한) 정점을 우선 처리하며, $t$가 이 기준으로 뽑히는 순간 알고리즘을 멈춘다.

## 예시

### 잠재 함수 적용 간선 가중치 공식
```
l_π(u, v) = l(u, v) - π(u) + π(v)
```

### A* 정점 선택 기준
```
select v minimizing:  dist[v] + π(v)
```

## 요약
- A* 알고리즘은 목표까지 남은 거리의 추정값을 잠재 함수 $\pi$로 표현해 간선 가중치를 $l_\pi(u,v) = l(u,v) - \pi(u) + \pi(v)$로 바꾼 뒤 다익스트라를 실행하는 것과 같다.
- 잠재 함수를 적용해도 $s$-$t$ 최단 경로 자체는 변하지 않으며, 모든 경로의 길이가 동일한 상수만큼만 달라진다는 사실이 증명의 핵심이다.
- 실현 가능(feasible)한 잠재 함수(모든 새 간선 가중치가 음이 아님)를 목표까지의 하한으로 사용하면, $\text{dist}[v] + \pi(v)$가 최소인 정점을 우선 탐색하는 방향 탐색이 가능해져 탐색 범위를 줄일 수 있다.
