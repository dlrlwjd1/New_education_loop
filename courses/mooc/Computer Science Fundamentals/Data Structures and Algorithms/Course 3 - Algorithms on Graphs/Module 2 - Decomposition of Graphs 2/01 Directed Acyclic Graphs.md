# Directed Acyclic Graphs

## 개요
- 간선에 방향이 있는 방향 그래프(directed graph)의 개념과, 무방향 그래프에서 배운 DFS가 방향 그래프에도 그대로 적용됨을 소개한다.
- 작업 간의 의존 관계(dependency)를 방향 그래프로 모델링하고, 이를 의존성을 지키는 순서로 선형 정렬(linear order)하는 문제를 제시한다.
- 그래프에 사이클(cycle)이 있으면 선형 정렬이 불가능함을 증명하고, 사이클이 없는 방향 그래프(directed acyclic graph, DAG)라는 개념을 정의한다.

## 내용
### 방향 그래프(Directed Graph)
- 방향 그래프는 각 간선이 시작점(start)과 끝점(end)을 갖는 그래프다. 두 대상의 관계가 대칭적이지 않을 때(한쪽이 다른 쪽보다 먼저이거나, 일방적인 관계일 때) 사용한다.
- 예시: 일방통행 도로가 있는 도시 지도, 웹페이지 간 링크(A가 B를 링크해도 B가 A를 링크하지 않을 수 있음), 소셜 네트워크의 팔로우 관계(페이스북의 친구 관계는 대칭적이라 무방향이지만, 팔로우는 방향성이 있음), 작업(task) 간의 의존 관계.

### 방향 그래프에서의 DFS
- 무방향 그래프에서 만든 탐색·DFS 이론이 대부분 방향 그래프에도 그대로 적용된다.
- 유일한 수정 사항: Explore(v)에서 "v의 모든 이웃 w"가 아니라 "v에서 w로 향하는 방향 간선이 있는 w"만 확인한다. 즉 일방통행 도로는 지정된 방향으로만 따라갈 수 있다.
- previsit/postvisit 순서도 그대로 계산할 수 있고, DFS의 실행 시간도 여전히 선형(linear time)이다.

### 작업 의존성과 선형 정렬 문제
- 예시: 아침 루틴(기상 → 샤워 → 옷 입기 → 아침 식사 → 출근) 같은 작업들 사이에는 순서 제약이 있다. A를 B보다 먼저 해야 한다면 A에서 B로 향하는 방향 간선을 그린다.
- 목표: 이런 의존 관계를 모두 만족하는 방식으로 작업(정점)들을 선형으로 나열하는 것. 예: 기상(7:00) → 샤워(7:05) → 옷 입기(7:15) → 아침 식사(7:20) → 출근(7:30) — 모든 의존 관계를 만족.
- 이런 의존 관계는 라이브러리 간 의존성처럼 복잡한 실제 시스템에서도 나타난다.

### 사이클이 있으면 선형 정렬이 불가능하다
- 반례: 닭과 달걀 문제 — 닭을 낳으려면 달걀이 필요하고, 달걀을 낳으려면 닭이 필요하다. 어느 쪽을 먼저 두어도 반대 방향을 가리키는 간선이 생겨 모순이 발생한다.
- **사이클(cycle)의 정의**: 정점들의 수열 v1, v2, …, vn이 각각 다음 정점으로 방향 간선을 통해 연결되고, 마지막이 다시 처음으로 연결되는 구조.
- **정리**: 그래프 G에 사이클이 존재하면 G는 선형으로 정렬될 수 없다.
- **증명**: G에 사이클 v1, …, vn이 있고 선형 정렬이 가능하다고 가정한다. 유한 개의 정점이므로 사이클 안의 어떤 vk가 정렬에서 가장 먼저 온다고 하자. 그런데 vk-1에서 vk로 향하는 간선이 있으므로, vk-1이 vk보다 먼저 와야 한다는 것과 모순된다.

### 방향 비순환 그래프(DAG)
- 사이클이 없는 방향 그래프를 **DAG(Directed Acyclic Graph)**라 부른다.
- 위 정리에 의해, 선형 정렬이 가능하려면 반드시 DAG여야 한다(필요조건).
- 자연스러운 질문: DAG이기만 하면 항상 선형 정렬이 가능한가(충분조건인가)? 이는 다음 강의에서 증명하며, 알고리즘도 함께 제시한다(정답은 "그렇다").

## 예시
- 4개의 방향 그래프 중 어느 것이 DAG인지 확인하는 문제: 간선의 연결 관계는 같지만 방향만 다른 그래프들 중, 사이클이 없는 그래프 하나만 DAG이고 나머지는 각각 다른 사이클을 포함해 DAG가 아니다.

## 요약
- 방향 그래프는 무방향 그래프의 DFS 이론을 대부분 그대로 물려받으며, Explore에서 방향 간선만 따라간다는 점만 다르다.
- 작업 의존성은 방향 그래프로 모델링되고, 의존성을 지키는 선형 정렬이 가능한지가 핵심 문제다.
- 그래프에 사이클이 있으면 선형 정렬이 불가능하며, 사이클이 없는 방향 그래프를 DAG라 부른다.
- 다음 강의에서는 모든 DAG가 실제로 선형 정렬 가능함을 증명하고, 그 정렬(위상 정렬, topological sort)을 구하는 알고리즘을 다룬다.
