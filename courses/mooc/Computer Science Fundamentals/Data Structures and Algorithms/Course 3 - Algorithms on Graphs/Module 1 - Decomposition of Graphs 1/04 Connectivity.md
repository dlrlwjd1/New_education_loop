# Connectivity

## 개요
- 무방향 그래프(undirected graph)에서 연결 요소(connected component)의 개념과, 이를 계산하는 알고리즘을 다룬다.
- 도달 가능성(reachability)이 동치 관계(equivalence relation)임을 증명하여, 그래프가 항상 연결 요소들로 분할될 수 있음을 보인다.
- 깊이 우선 탐색(DFS)을 약간 수정해 각 연결 요소에 번호를 매기는 알고리즘을 소개한다.

## 내용
### 연결 요소(Connected Component)
- 임의의 무방향 그래프 G는 항상 여러 개의 연결 요소로 분할될 수 있으며, 두 정점 v와 w가 서로 도달 가능(reachable)할 때에만 같은 연결 요소에 속한다.
- 즉 그래프를 여러 "섬(island)"으로 나눌 때, 서로 다른 섬 사이에는 어떤 연결도 없지만, 같은 섬 안에서는 어디서든 어디로든 이동할 수 있다.
- 예: 어떤 그래프가 4개의 서로 완전히 분리된 부분으로 이루어져 있다면 연결 요소는 4개다.

### 도달 가능성이 동치 관계임을 증명
- 동치 관계가 되려면 다음 세 조건을 만족해야 한다.
  1. **반사성**: v는 v로부터 도달 가능하다(자명함).
  2. **대칭성**: v가 w로부터 도달 가능하면, w도 v로부터 도달 가능하다(경로를 반대 방향으로 따라가면 됨).
  3. **추이성**: v가 u로부터 도달 가능하고 v가 w로부터도 도달 가능하면, w도 u로부터 도달 가능하다. u→v 경로와 v→w 경로를 v에서 이어 붙이면 u→w 경로가 만들어지므로 성립한다.
- 도달 가능성이 동치 관계이므로, 그래프의 정점들은 서로소(disjoint)인 연결 요소들로 자연스럽게 분할된다.

### 연결 요소를 계산하는 알고리즘
- 기본 아이디어: 어떤 정점 v에 대해 Explore(v)를 실행하면 v의 연결 요소 전체(= v로부터 도달 가능한 모든 정점)를 찾을 수 있다. 이를 모든 정점에 대해 반복하면 모든 연결 요소를 찾을 수 있다.
- 목표를 집합을 반환하는 대신 각 정점에 연결 요소 번호(CC number)를 라벨링하는 방식으로 바꾸면 DFS를 약간만 수정해서 구현할 수 있다.
- 수정된 Explore: 정점 v를 방문 표시하고, v에게 현재 연결 요소 번호(cc)를 부여한 뒤, 아직 방문하지 않은 이웃들을 재귀적으로 탐색한다. 같은 Explore 호출 안에서 발견된 정점들은 모두 같은 번호를 받는다.
- DFS의 외부 루프에서 새로운(아직 방문하지 않은) 정점을 찾아 새로운 Explore를 시작할 때마다 cc 값을 1씩 증가시킨다.

### 알고리즘의 정확성과 실행 시간
- 각 Explore 호출은 완전히 새로운 연결 요소 하나를 찾아낸다. 해당 정점이 아직 방문되지 않았다는 것은 이전에 발견된 어떤 연결 요소에도 속하지 않았다는 뜻이기 때문이다.
- DFS의 외부 루프 구조상 모든 정점은 결국 방문 여부가 확인되므로, 모든 정점이 언젠가 탐색되어 라벨을 받는다.
- 이 알고리즘은 DFS를 표면적(cosmetic)으로만 수정한 것이므로 실행 시간은 그대로 O(|V| + |E|)다.

## 예시
- **연결 요소 라벨링 의사코드**:
  ```
  cc = 1
  for all v in V:
      visited(v) = false
  for all v in V:
      if not visited(v):
          Explore(v)   # 이 Explore 안에서 발견된 모든 정점에 cc 번호를 부여
          cc = cc + 1

  Explore(v):
      visited(v) = true
      ccnum(v) = cc
      for each edge (v, w) in E:
          if not visited(w):
              Explore(w)
  ```
- 예시 그래프: 첫 번째 Explore 호출에서 발견된 4개의 정점 → 라벨 1, 두 번째 호출의 2개 정점 → 라벨 2, 세 번째 호출의 정점들 → 라벨 3. 결과적으로 3개의 연결 요소가 확인된다.

## 요약
- 무방향 그래프는 도달 가능성이라는 동치 관계에 의해 연결 요소들로 정확히 분할된다.
- DFS를 약간 수정해(Explore마다 같은 cc 번호를 부여하고, 새로운 Explore를 시작할 때마다 cc를 증가) 모든 연결 요소를 O(|V| + |E|) 시간에 계산할 수 있다.
- 다음 강의에서는 DFS의 또 다른 응용인 previsit/postvisit 순서(ordering)를 다룬다.
