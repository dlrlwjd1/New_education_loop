# Exploring Graphs

## 개요
- 그래프에서 어떤 정점(vertex)들이 특정 정점으로부터 도달 가능(reachable)한지 알아내는 탐색 알고리즘을 다룬다.
- 경로(path)와 도달 가능성(reachability)을 형식적으로 정의하고, 이를 계산하는 재귀 알고리즘 Explore(v)를 소개한다.
- Explore를 확장한 깊이 우선 탐색(depth first search, DFS) 알고리즘으로 그래프 전체의 모든 정점을 방문하는 방법과, 그 정확성(correctness) 증명 및 실행 시간을 다룬다.

## 내용
### 그래프 탐색의 응용 사례
- 비디오 게임에서 한 레벨의 모든 방을 탐험해 숨겨진 요소를 빠짐없이 찾는 문제.
- 지도에서 한 지점과 다른 지점 사이의 경로를 찾는 문제, 도로망 전체가 연결되어 있는지 확인하는 문제.
- 미로 찾기, 퍼즐(정점을 배치 상태, 간선을 가능한 이동으로 볼 때 원하는 배치에 도달할 수 있는지 확인하는 문제) 등에도 활용된다.

### 경로와 도달 가능성의 형식적 정의
- **경로(path)**: 그래프 G에서 정점들의 수열 v0, v1, v2, …로, 연속한 두 정점이 그래프의 간선으로 연결되어 있는 것.
- **도달 가능성(reachability) 문제**: 그래프 G와 시작 정점 s가 주어졌을 때, s에서 경로가 존재하는 모든 정점 v의 집합을 찾는 문제.

### 탐색 알고리즘의 기본 아이디어
- DiscoveredNodes 리스트를 시작 정점 하나로 초기화한다.
- 이미 발견한(discovered) 정점과 아직 발견하지 못한 정점을 잇는 간선 e가 있는 동안, 그 간선의 반대편 정점을 DiscoveredNodes에 추가한다.
- 더 이상 새로운 정점을 찾을 수 없을 때까지 반복한 뒤 DiscoveredNodes를 반환한다.
- 실제 구현을 위해서는 (1) 방문 여부를 기록하는 방법, (2) 아직 확인하지 않은 간선이 남은 정점을 추적하는 방법(재귀 호출 스택에 암묵적으로 반영됨), (3) 새 간선을 탐색하는 순서를 정하는 방법이 필요하다.

### 깊이 우선 순서(Depth First order)와 Explore(v)
- 깊이 우선 순서: 시작 정점에서 간선을 따라 최대한 멀리 나아가다가, 이미 방문한 정점을 만나거나 더 나아갈 간선이 없는 막다른 길(dead end)에 도달하면 한 단계만 되돌아가(backtrack) 다시 앞으로 나아간다.
- 이를 구현한 재귀 알고리즘이 Explore(v)이며, 인접 리스트(adjacency list) 표현을 사용해야 효율적으로 동작한다(이웃 순회가 빠르기 때문).

### Explore(v)의 정확성 증명
- **정리**: 모든 정점이 미방문(unvisited) 상태에서 Explore(v)를 실행하면, v로부터 도달 가능한 정점들만 정확히 방문(visited) 상태로 표시된다.
- 증명 개요:
  1. Explore는 시작 정점 또는 이미 탐색한 정점의 이웃만 탐색하므로, 탐색되는 모든 정점은 v로부터 도달 가능하다.
  2. 어떤 정점 w는 탐색(explore)되지 않으면 방문 표시가 되지 않는다.
  3. w가 탐색되면 w의 모든 이웃도 결국 탐색된다(이미 방문됐거나, 새로 탐색되거나).
  4. v로부터 도달 가능한 임의의 정점 u에 대해, v에서 u까지의 경로 상에서 탐색된 마지막 정점을 w라 하면, (3)에 의해 그 다음 정점도 탐색되어야 하므로 모순이 발생한다. 따라서 경로 상의 모든 정점이 탐색되며, 결국 u도 탐색된다.

### 깊이 우선 탐색(DFS)
- Explore(v)는 v로부터 도달 가능한 정점만 찾지만, 그래프 G의 모든 정점을 찾고 싶을 때는 DFS를 사용한다.
- 알고리즘: 모든 정점을 미방문으로 초기화한 뒤, 그래프의 각 정점에 대해 아직 방문하지 않았다면 Explore를 실행한다.

### DFS의 실행 시간 분석
- 각 정점은 탐색되기 전 반드시 방문 여부를 확인하므로, 정점마다 정확히 한 번씩만 탐색(explore)된다 → 정점당 O(1) 작업.
- 각 정점을 탐색할 때 그 정점의 모든 이웃을 확인하는 내부 루프가 있으며, 이 작업량의 총합은 간선 수에 비례한다(각 간선이 양 끝 정점에서 한 번씩, 총 두 번 계산되지만 여전히 O(간선 수)).
- 따라서 DFS의 전체 실행 시간은 O(|V| + |E|)로, 선형 시간(linear time) 알고리즘이다.

## 예시
- **재귀 알고리즘 Explore(v)**:
  ```
  Explore(v):
      visited(v) = true
      for each edge (v, w) in E:
          if not visited(w):
              Explore(w)
  ```
- **깊이 우선 탐색(DFS)**:
  ```
  for all v in V:
      visited(v) = false
  for all v in V:
      if not visited(v):
          Explore(v)
  ```

## 요약
- 경로(path)는 간선으로 연결된 정점들의 수열이며, 도달 가능성(reachability)은 시작 정점에서 경로가 존재하는 모든 정점을 찾는 문제로 정의된다.
- 재귀 알고리즘 Explore(v)는 인접 리스트를 이용해 v로부터 도달 가능한 모든 정점을 정확히 찾아내며, 이는 증명 가능하다.
- Explore를 모든 미방문 정점에 대해 반복 실행하는 깊이 우선 탐색(DFS)은 그래프의 모든 정점을 O(|V| + |E|) 시간에 방문한다.
- 다음 강의에서는 도달 가능성을 더 확장해 무방향 그래프의 연결 요소(connected component)를 다룬다.
