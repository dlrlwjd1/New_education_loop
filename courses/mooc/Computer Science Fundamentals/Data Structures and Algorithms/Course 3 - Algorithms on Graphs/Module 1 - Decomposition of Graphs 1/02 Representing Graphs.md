# Representing Graphs

## 개요
- 그래프(graph)를 컴퓨터 내부에 표현하는 세 가지 방법 — 간선 리스트(edge list), 인접 행렬(adjacency matrix), 인접 리스트(adjacency list) — 을 소개한다.
- 표현 방식에 따라 기본 연산들의 실행 시간(runtime)이 달라지며, 대부분의 그래프 알고리즘에서는 인접 리스트가 선호된다.
- 그래프 알고리즘의 실행 시간은 정점 수(|V|)와 간선 수(|E|) 두 매개변수에 동시에 의존하며, 이 때문에 밀집 그래프(dense graph)와 희소 그래프(sparse graph)의 구분이 중요하다.

## 내용
### 그래프를 표현하는 세 가지 방법
1. **간선 리스트(edge list)**: 각 간선을 정점 쌍으로 나열한 큰 리스트. 예: 정점 A, B, C, D에 대해 (A,B), (A,C), (A,D), (C,D)를 그대로 저장.
2. **인접 행렬(adjacency matrix)**: |V| × |V| 크기의 0/1 행렬. 정점 i, j 사이에 간선이 있으면 항목이 1, 없으면 0. 예: A-D 간선이 있으면 (A,D) 항목이 1, B-C 간선이 없으면 (B,C) 항목이 0.
3. **인접 리스트(adjacency list)**: 각 정점마다 자신과 인접한(이웃) 정점들의 리스트를 보관. 예: A는 B, C, D와 인접하고, B는 A와만 인접.

### 표현 방식별 연산 성능 비교
| 연산 | 간선 리스트 | 인접 행렬 | 인접 리스트 |
|---|---|---|---|
| 특정 두 정점 사이 간선 존재 여부 확인 | O(간선 수) — 전체 스캔 | O(1) — 상수 시간 | O(정점의 차수, degree) |
| 모든 간선 나열 | O(간선 수) — 매우 빠름 | O(정점 수²) — 느림 | O(간선 수) — 각 간선이 두 번 카운트되지만 여전히 선형 |
| 특정 정점의 모든 이웃 나열 | O(간선 수) — 전체 스캔 | O(정점 수) — 해당 행 스캔 | O(그 정점의 이웃 수) — 매우 빠름 |

- 이 강좌에서 다루는 대부분의 문제는 "주어진 정점의 이웃을 찾는" 연산을 자주 요구하므로, 인접 리스트 표현을 주로 사용한다.

### 그래프 알고리즘의 실행 시간
- 일반적인 알고리즘은 입력 크기를 하나의 매개변수 n으로 표현하지만(O(n²), O(n³) 등), 그래프는 정점 수와 간선 수라는 두 가지 크기 척도를 가진다.
- 그래프 알고리즘의 실행 시간은 O(|V| + |E|), O(|V| × |E|), O(|V|^(3/2)), O(|V| log |V| + |E|) 등 다양한 형태로 나타난다.
- 매개변수가 하나뿐이면 실행 시간 비교가 쉽지만(N log N vs N² vs N³), 두 매개변수가 있으면 어느 알고리즘이 더 빠른지는 그래프의 밀도(density)에 따라 달라진다.

### 밀집 그래프와 희소 그래프
- **밀집 그래프(dense graph)**: 간선 수가 정점 수의 제곱에 비례. 거의 모든 정점 쌍이 간선으로 연결됨. 예: 여러 도시를 여행할 때 모든 도시 간 이동 수단이 존재하는 경우, 도달 가능 여부보다 이동 난이도가 중요하므로 밀집 그래프로 모델링.
- **희소 그래프(sparse graph)**: 간선 수가 정점 수에 비례하거나 그 상수 배 정도로 작음. 각 정점의 차수가 적음. 예: 인터넷 — 웹페이지 수는 수십억 개지만 각 페이지의 링크 수는 수십 개에 불과. 지도, 소셜 네트워크 등 실세계의 많은 그래프가 희소 그래프에 해당.
- 그래프가 밀집인지 희소인지에 따라 알고리즘의 실행 시간뿐 아니라 어떤 알고리즘을 선택할지도 달라질 수 있다.

## 요약
- 그래프는 간선 리스트, 인접 행렬, 인접 리스트의 세 가지 방식으로 표현할 수 있으며, 각 방식은 기본 연산의 실행 시간이 서로 다르다.
- 이웃 탐색이 빈번한 대부분의 그래프 알고리즘에서는 인접 리스트 표현이 유리하다.
- 그래프 알고리즘의 실행 시간은 정점 수와 간선 수 두 가지에 의존하며, 그래프의 밀도(밀집/희소)에 따라 알고리즘 간 우열이 달라질 수 있다.
- 다음 강의에서는 그래프를 탐색(explore)하여 어떤 정점에서 어떤 정점에 도달할 수 있는지 알아내는 알고리즘을 다룬다.
