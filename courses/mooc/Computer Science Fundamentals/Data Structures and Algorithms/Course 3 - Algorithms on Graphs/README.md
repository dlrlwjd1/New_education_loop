# Algorithms on Graphs

- 전문과정: Data Structures and Algorithms (Course 3)
- 제공: University of California San Diego
- 구성: 6개 모듈, 영상 52개 — Transcript 기반 한국어 정리 완료
- 제외: 읽기 자료·퀴즈·프로그래밍 과제 채점

그래프의 표현과 분해(decomposition)부터 시작해 너비 우선 탐색(BFS)과 최단 경로 알고리즘(Dijkstra, Bellman-Ford), 최소 신장 트리(minimum spanning tree)까지 다루고, 마지막으로 대규모 그래프에서 최단 경로를 빠르게 계산하는 고급 기법(양방향 탐색, A*, 하이웨이 계층)을 선택적으로 소개한다.
