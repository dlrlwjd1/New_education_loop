# Greedy Algorithms

## 개요
- 최소 신장 트리(minimum spanning tree) 문제를 푸는 두 가지 탐욕 알고리즘(greedy algorithm), 크루스칼 알고리즘(Kruskal's algorithm)과 프림 알고리즘(Prim's algorithm)의 핵심 아이디어를 소개한다.
- 같은 예시 그래프에 두 알고리즘을 각각 적용하는 과정을 비교한다.

## 내용

### 두 알고리즘의 핵심 아이디어
- **크루스칼 알고리즘(Kruskal's algorithm)**: 모든 간선을 가중치가 증가하는 순서로 살펴보면서, 사이클(cycle)을 만들지 않는 한 가장 가벼운 간선을 반복적으로 추가한다.
- **프림 알고리즘(Prim's algorithm)**: 트리를 하나씩 키워나간다. 처음에는 정점 하나로 시작해서, 현재 트리에 새 정점을 하나씩 붙이는데, 항상 현재 트리와 연결되는 가장 가벼운 간선을 사용해 붙인다.

### 크루스칼 알고리즘 예시
- 해(solution)를 빈 집합에서 시작해 가장 가벼운 간선부터 순서대로 추가한다.
- 가중치 1인 간선 두 개를 먼저 추가하고, 그다음 가중치 2인 간선을 추가한다.
- 가중치 3인 간선은 추가하면 사이클이 생기므로 건너뛴다(skip).
- 가중치 4인 간선은 사이클을 만들지 않으므로 추가한다.
- 가중치 5인 간선은 사이클을 만들어 건너뛰고, 대신 가중치 6인 간선을 추가해 최종 해를 완성한다.

### 프림 알고리즘 예시
- 임의의 정점을 트리의 루트(root)로 선택한다.
- 루트에서 나가는 간선 중 가장 가벼운 것(가중치 4)을 선택해 새 정점을 트리에 붙인다.
- 이후 현재 트리에 정점 하나를 더 붙일 때마다, 트리 안 정점과 트리 밖 정점을 잇는 간선 중 가장 가벼운 것(가중치 1, 2, 6, 1 순서)을 선택해 트리를 키운다.

## 요약
- 크루스칼 알고리즘은 전체 간선을 가중치 순으로 정렬해 사이클을 만들지 않는 가장 가벼운 간선을 계속 추가하는 방식이다.
- 프림 알고리즘은 하나의 트리를 계속 키우면서 트리에 새 정점을 붙이는 가장 가벼운 간선을 매번 선택하는 방식이다.
- 다음 강의에서 두 알고리즘이 모두 최적해를 만든다는 사실을 증명한다.
