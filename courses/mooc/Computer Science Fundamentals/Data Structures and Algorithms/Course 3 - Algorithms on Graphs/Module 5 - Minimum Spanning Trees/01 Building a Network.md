# Building a Network

## 개요
- 최소 신장 트리(minimum spanning tree, MST) 문제를 네트워크 연결과 도로 건설이라는 두 가지 예시로 소개한다.
- 문제를 형식적으로 정의하고, 이름의 세 단어(minimum, spanning, tree)가 각각 어떤 의미를 갖는지 설명한다.
- 트리(tree)의 기본 성질을 정리하고, 최소 신장 트리 문제의 모든 최적해가 실제로 트리 형태임을 증명한다.

## 내용

### 도입 예시
- **네트워크 예시**: 사무실에 기계 6대가 있고, 일부 기계 쌍 사이에만 케이블(wire)을 연결할 수 있으며 각 연결에는 비용이 있다. 모든 기계가 서로 도달 가능하도록 연결하되 총 비용을 최소화해야 한다.
  - 예시 그래프에서 최적해의 총 비용은 12이며, 두 가지 서로 다른 간선 선택으로도 동일한 총 비용 12를 얻을 수 있다(즉 최적해가 유일하지 않을 수 있다).
- **도로 건설 예시**: 여러 도시 사이에 도로를 놓아 임의의 두 도시 사이에 경로가 존재하도록 하되, 건설하는 도로 길이의 총합을 최소화한다.

### 문제의 형식적 정의
- 연결 그래프(connected graph) $G = (V, E)$와 양의 간선 가중치(edge weight)가 주어진다.
- 목표는 간선의 부분집합 $E' \subseteq E$를 찾는 것이다. 단, $E'$만 남긴 그래프가 여전히 연결(connected)되어 있어야 하며, $E'$에 속한 간선들의 총 가중치가 최소가 되어야 한다.

### 이름의 의미
- **Minimum**: 선택한 간선 부분집합의 총 가중치가 최소여야 한다.
- **Spanning**: 부분집합만 남겨도 그래프의 모든 정점(vertex)이 연결되어야 한다(모든 정점을 "span"한다).
- **Tree**: 모든 최적해 $E'$는 실제로 트리(tree) 구조를 이룬다.

### 트리의 기본 성질
- 트리는 연결되어(connected) 있고 사이클(cycle)이 없는(acyclic) 무방향 그래프(undirected graph)다.
- 트리는 루트를 지정해 계층적으로(레벨별로) 그릴 수도 있고(rooted tree), 루트 없이 그릴 수도 있다. 루트 없는 트리라도 임의의 정점을 루트로 지정하면 계층적으로 다시 그릴 수 있다.
- **정점 수와 간선 수의 관계**: 정점이 $n$개인 트리는 정확히 $n-1$개의 간선을 가진다.
  - 정점 1개에서 시작해 정점을 하나씩 추가할 때마다 간선도 하나씩만 추가되므로, 정점 수가 늘어도 이 관계가 항상 유지된다.
  - 이미 존재하는 두 정점을 새 간선으로 연결하면(새 정점 없이) 반드시 사이클이 생기므로 트리가 아니게 된다.
- **역의 성립 조건**: 간선 수가 (정점 수 − 1)이라고 해서 항상 트리는 아니다. 그래프가 **연결되어 있어야** 한다는 조건이 반드시 필요하다.
  - 반례: 정점 4개, 간선 3개이지만 정점 3개짜리 삼각형과 고립된(isolated) 정점 1개로 이루어진 그래프는 간선 수 조건은 만족하지만 연결되어 있지 않으므로 트리가 아니다.
- **유일 경로 성질**: 무방향 그래프가 트리인 것은 임의의 두 정점 사이에 경로가 정확히 하나만 존재하는 것과 동치(if and only if)다. 두 정점 사이에 경로가 두 개 이상 있다면 그 경로들이 사이클을 이룬다.

### 최적해가 트리임을 증명
- 최소 신장 트리 문제의 임의의 최적해가 사이클을 포함한다고 가정하자.
- 사이클 위의 임의의 두 정점 사이에는 두 가지 경로(사이클의 양방향)가 존재하므로, 그중 한 간선을 제거해도 그래프는 여전히 연결된 상태를 유지한다.
- 간선을 제거하면 총 가중치가 감소하므로, 사이클이 있는 해는 더 나은 해로 개선될 수 있어 최적이 아니다.
- 따라서 모든 최적해는 사이클이 없어야(acyclic) 하며, 문제 정의상 연결(connected)도 되어 있어야 하므로 최적해는 반드시 트리다.

## 요약
- 최소 신장 트리 문제는 연결 그래프에서 모든 정점을 연결하면서 총 간선 가중치를 최소화하는 부분 그래프를 찾는 문제다.
- 정점 $n$개짜리 트리는 간선이 $n-1$개이며, 두 정점 사이에 경로가 유일하다는 성질을 갖는다. 단, 간선 수 조건만으로는 연결성이 보장되지 않는다.
- 사이클이 있는 해는 간선을 제거해 개선할 수 있으므로, 최소 신장 트리 문제의 모든 최적해는 사이클이 없는 연결 그래프, 즉 트리다.
