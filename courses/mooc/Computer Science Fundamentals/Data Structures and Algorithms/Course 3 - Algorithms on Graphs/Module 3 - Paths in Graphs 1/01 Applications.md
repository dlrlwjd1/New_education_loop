# Applications

## 개요
- 그래프에서 최적 경로(optimal path)를 찾는 알고리즘들의 실제 응용 사례를 소개한다.
- 이번 모듈에서는 그중 첫 번째 문제인 "최소 환승 횟수로 목적지에 도달하기" 문제에 집중한다.

## 내용

### 최적 경로 문제의 세 가지 응용 예시
1. **항공편 환승 최소화**: 먼 곳으로 여행할 때 직항이 없다면 최소한의 환승 횟수로 도착하고 싶다. 이는 그래프에서 간선(edge)의 개수가 가장 적은 경로, 즉 노드 A에서 노드 B까지 가장 적은 간선을 사용하는 경로를 찾는 문제에 해당한다.
2. **최단 시간 경로 찾기**: 자동차로 이동할 때(예: 집에서 회사까지) 가중치(weight)가 있는 간선으로 구성된 그래프에서 가장 짧은 경로를 찾는 문제다.
3. **환율 차익거래(currency arbitrage)**: 예를 들어 미국 달러(USD)를 러시아 루블(RUB)로 최적으로 환전하는 문제. 여러 번의 환전을 거쳐 원래 통화로 돌아왔을 때 처음보다 돈이 늘어나는 차익거래(arbitrage)가 가능한지, 가능하다면 어떻게 만드는지를 다룬다. 이 주제는 세 번째 강의에서 다룰 예정이다.

### 이번 강의의 초점: 최소 환승 문제
- 예시 문제: 런던(London)에서 퍼스(Perth)까지 가는 데 필요한 최소 환승 횟수는?
- 항공사가 제공하는 항공편 네트워크를 그래프로 표현하면, 도시는 노드(node), 운항 가능한 항공편은 방향이 있는 간선(directed edge)이 된다.
- 그래프 상에는 여러 경로가 존재할 수 있다.
  - 런던 → 파리 → 라스팔마스 → 루안다 → 요하네스버그 → 모리셔스 → 코코스 제도 → 퍼스: 매우 많은 환승이 필요한 경로.
  - 런던 → 요하네스버그 → 퍼스: 단 한 번의 환승만 필요한 경로.
  - 만약 런던에서 퍼스로 가는 직항 경로가 그래프에 존재한다면 그것이 최선이다.
- 일반화하면, 임의의 그래프에서 한 도시에서 다른 도시로 가는 데 필요한 최소 환승 횟수를 가지는 경로를 찾는 문제로 정리된다.

## 요약
- 그래프 최적 경로 알고리즘은 항공편 환승 최소화, 최단 시간 경로, 환율 차익거래 등 다양한 실제 문제에 적용된다.
- 이번 강의는 방향 그래프(directed graph)에서 최소 간선 수 경로(최소 환승 횟수)를 찾는 문제에 초점을 맞춘다.
- 다음 영상에서는 경로(path)와 거리(distance)의 형식적 정의를 도입해 이 문제를 알고리즘 관점에서 정식화한다.
