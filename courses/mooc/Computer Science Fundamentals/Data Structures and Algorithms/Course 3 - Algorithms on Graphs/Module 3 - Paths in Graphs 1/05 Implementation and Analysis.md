# Implementation and Analysis

## 개요
- 앞선 강의에서 설명한 너비 우선 탐색(breadth-first search, 줄여서 BFS) 알고리즘을 실제 의사코드로 구현한다.
- BFS 알고리즘의 실행 시간(running time)이 O(|E| + |V|)임을 증명한다.

## 내용

### BFS 절차의 입력과 초기화
- 입력: 그래프 G(노드 집합 V, 간선 집합 E)와 시작 노드 A.
- 목표: A로부터 그래프 내 다른 모든 노드까지의 거리를 구한다.
- 초기화
  - 모든 노드의 거리(dist)를 무한대(infinity)로 설정한다. 아직 A에서 어떤 노드로도 가는 경로를 찾지 못했기 때문이다. 끝내 경로를 찾지 못하는 노드는 거리가 무한대로 남아, 이는 A로부터 도달 불가능(unreachable)함을 의미한다.
  - 시작 노드 A 자신의 거리는 0으로 설정한다(레이어 0에 있으므로).
  - 큐(queue)를 초기화하고 시작 노드 A 하나만 넣는다.

### 메인 루프
- 큐가 비어 있지 않은 동안 다음을 반복한다.
  1. 큐의 맨 앞 노드를 꺼내 `u`에 저장하고 큐에서 제거한다.
  2. `u`에서 나가는 모든 간선 `(u, v)`(단, `(u, v)` ∈ E)에 대해 다음을 확인한다.
     - `v`가 아직 발견되지 않았는지는 `dist[v]`가 무한대인지로 판별한다(발견되면 즉시 유한한 값으로 갱신되기 때문).
     - `dist[v]`가 무한대이면(아직 흰색이면): `v`를 큐에 추가하고(회색으로 칠하는 것과 동일한 의미), `dist[v] = dist[u] + 1`로 설정한다.

### 실행 시간 분석
- **주장(lemma)**: BFS의 실행 시간은 O(|E| + |V|)이다.
- 증명의 핵심 관찰
  - **각 노드는 큐에 최대 한 번만 들어간다.** 노드가 큐에 들어가는 순간 거리가 무한대에서 유한한 값으로 바뀌고, 큐에 넣기 전에 거리가 무한대인지 확인하므로 이미 유한한 거리를 가진 노드는 다시 큐에 들어가지 않는다.
  - 각 노드가 최대 한 번만 큐에 들어가므로, 각 노드는 최대 한 번만 처리(process)된다.
  - **각 간선은 상수 번만 검사된다.**
    - 방향 그래프(directed graph): 간선 `(u, v)`는 `u`를 처리할 때만 확인되므로 정확히 한 번만 검사된다.
    - 무방향 그래프(undirected graph): 같은 간선이 `u`를 처리할 때와 `v`를 처리할 때 모두 확인될 수 있으므로 최대 두 번 검사된다.
  - 노드 처리와 간선 검사가 각각 상수 번(노드당 1회, 간선당 최대 2회)만 일어나므로, 전체 실행 시간은 노드 수와 간선 수의 합에 비례한다: O(|E| + |V|).

## 예시

```text
BFS(G, A):
    for each node u in V:
        dist[u] = infinity
    dist[A] = 0
    Queue = [A]
    while Queue is not empty:
        u = Queue.dequeue()
        for each edge (u, v) in E:
            if dist[v] == infinity:
                Queue.enqueue(v)
                dist[v] = dist[u] + 1
```

- 실행 시간: O(|E| + |V|)

## 요약
- BFS는 거리를 무한대로 초기화하고 시작 노드만 큐에 넣은 뒤, 큐가 빌 때까지 노드를 꺼내 나가는 간선을 확인하며 새 노드를 발견해 나가는 절차다.
- 각 노드는 최대 한 번만 큐에 들어가고 처리되며, 각 간선은 방향 그래프에서 최대 1번, 무방향 그래프에서 최대 2번 검사된다.
- 이 두 관찰로부터 BFS의 실행 시간이 O(|E| + |V|)임이 증명된다.
