# Shortest Path Tree

## 개요
- BFS는 최소 환승 횟수(거리) 자체는 알려주지만, 실제로 어떤 경로를 거쳐야 하는지는 알려주지 않는다는 한계를 지적한다.
- 이를 해결하기 위해 BFS를 확장해 최단 경로 트리(shortest-path tree)를 구성하는 방법과, 이를 이용해 실제 최단 경로를 복원(reconstruct)하는 방법을 설명한다.

## 내용

### 문제의식: 거리만으로는 부족하다
- BFS로 런던에서 퍼스까지 최소 환승 횟수가 2라는 것은 알 수 있지만, 구체적으로 어떤 두 항공편을 타야 하는지는 알 수 없다.
- 최소 환승 횟수뿐 아니라 실제 경로(정확한 항공편 목록)까지 알아야 한다.

### 최단 경로 트리의 구성 방법
- 그래프의 모든 노드를 A로부터의 거리 레이어에 따라 배치한다(A는 레이어 0, 그다음 레이어 1, 2, …).
- 각 노드 v에 대해 **이전 노드(previous node)** 개념을 정의한다: v가 발견될 때 처리 중이던 노드(즉 v를 발견시킨 노드)를 v의 이전 노드라 한다.
- 시작 노드 A를 제외한 모든 노드에는 이전 노드가 정확히 하나씩 존재한다(A는 가장 먼저 발견되므로 이전 노드가 없다).
- 각 노드에서 자신의 이전 노드로 향하는 간선만 그리면, 원래 그래프보다 간선 수가 적은 새로운 방향 그래프가 만들어진다. 이것이 최단 경로 트리다.

### 최단 경로 트리가 트리(연결되어 있고 사이클이 없음)임을 증명
- **연결성(connectedness)**: 모든 노드에서 이전 노드를 따라가면 결국 A에 도달한다. 즉 모든 노드에서 A로 가는 경로가 있으므로(방향을 무시하면) 그래프는 연결되어 있다.
- **사이클이 없음(트리임을 증명)**
  - 이 그래프에서 시작 노드 A를 제외한 모든 노드는 나가는 간선이 정확히 하나(자신의 이전 노드로 가는 간선)뿐이다.
  - 어떤 간선을 통해 이전 노드로 이동하면, A로부터의 거리가 정확히 1씩 감소한다(발견될 때 거리가 "이전 노드의 거리 + 1"로 정해졌기 때문).
  - 만약 사이클이 존재한다면(예: B → C → D → E → F → B), 사이클을 따라 한 바퀴 돌 때마다 거리가 계속 감소해야 한다. 그런데 사이클의 시작점으로 되돌아왔을 때 거리는 원래 값과 같아야 하므로, "거리가 감소하면서도 원래 값으로 돌아온다"는 모순이 발생한다.
  - 따라서 사이클은 존재할 수 없고, 이 그래프는 트리다.

### 왜 "최단 경로" 트리인가
- 어떤 노드에서 이전 노드를 따라 계속 거슬러 올라가면, 매 단계 거리가 1씩 줄어들며 결국 A(거리 0)에 도달한다.
- 거리가 d인 노드라면 정확히 d번의 단계를 거쳐 A에 도달하므로, 이 경로는 정확히 d개의 간선으로 이루어진 최단 경로(단, A→노드 방향이 아니라 노드→A 방향의 역순 경로)가 된다.
- 실제 A에서 해당 노드로 가는 최단 경로를 얻으려면 이 경로를 뒤집으면 된다.

### 구현: prev 배열과 경로 복원
- 배열 `prev`를 도입해 각 노드의 이전 노드를 저장한다. 초기값은 모든 노드에 대해 `nil`(가리키는 곳 없음)로 둔다.
- BFS에서 노드 v가 발견되는 시점(큐에 넣고 거리를 대입하는 시점)에 `prev[v] = u`도 함께 대입한다(u는 v를 발견시킨, 현재 처리 중인 노드).
- 노드 u까지의 최단 경로를 복원하는 절차 `reconstruct_path(u)`:
  1. 빈 리스트 `result`를 초기화한다.
  2. 현재 노드를 u로 시작해, 노드가 A가 될 때까지 다음을 반복한다: 현재 노드를 `result`에 추가하고, 현재 노드를 `prev`가 가리키는 노드로 옮긴다.
  3. 이렇게 얻은 `result`는 A에서 u까지 경로의 역순이므로, 이를 뒤집어 반환한다.

### 이 확장이 가능하게 하는 것
- 두 도시 사이의 최소 환승 횟수(거리)뿐 아니라, 그 최소 횟수를 만족하는 실제 경로도 구할 수 있다.
- 시작 노드 하나로부터 모든 다른 노드까지의 최단 경로 전체(트리 형태)를 한 번의 BFS 실행으로 얻을 수 있다.
- 전체 과정(거리 계산 + 최단 경로 트리 구성 + 경로 복원)의 실행 시간은 여전히 O(|E| + |V|)에 비례한다.

## 예시

```text
BFS(G, A):
    for each node u in V:
        dist[u] = infinity
        prev[u] = nil
    dist[A] = 0
    Queue = [A]
    while Queue is not empty:
        u = Queue.dequeue()
        for each edge (u, v) in E:
            if dist[v] == infinity:
                Queue.enqueue(v)
                dist[v] = dist[u] + 1
                prev[v] = u

reconstruct_path(u):
    result = []
    while u is not A:
        result.append(u)
        u = prev[u]
    result.append(A)
    return reverse(result)
```

## 요약
- BFS를 확장해 각 노드에 이전 노드(prev)를 기록하면 최단 경로 트리를 구성할 수 있다.
- 이 트리는 연결되어 있고 사이클이 없으므로(거리가 매 단계 1씩 감소하기 때문) 트리 구조를 이룬다.
- `prev` 배열을 거슬러 올라가고 결과를 뒤집으면 시작 노드 A로부터 임의의 노드까지의 실제 최단 경로를 O(|E| + |V|) 시간에 복원할 수 있다.
