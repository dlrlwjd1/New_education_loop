# Correct Distances

## 개요
- 이전 강의에서 증명한 BFS의 성질(순서 보존, 도달 가능성)을 바탕으로, BFS가 A로부터 모든 노드까지 실제로 올바른 거리(distance)를 계산함을 수학적 귀납법(mathematical induction)으로 증명한다.

## 내용

### 증명할 명제
- 노드 u가 발견되어 큐에 들어가는 순간, `dist[u]`에는 A에서 u까지의 정확한 거리가 대입된다.
- `dist[u]`가 변하는 시점은 오직 u가 발견되는 순간뿐이다(그 전에는 무한대로 유지된다).

### 귀납법에 의한 증명
- **기저 사례(base case)**: 시작 노드 A. A가 발견될 때 `dist[A]`는 정확히 0으로 설정되는데, 이는 A 자신까지의 거리와 정확히 일치한다.
- **귀납 가정**: A로부터 거리가 최대 k인 모든 노드에 대해 이미 올바른 거리가 대입되었다고 가정한다.
- **귀납 단계**: A로부터 거리가 정확히 k+1인 임의의 노드 v에 대해, v가 발견될 때 올바른 거리(k+1)가 대입됨을 보인다.
  1. 이전 강의(성질 1)에 의해 v는 도달 가능하므로 BFS 과정 중 반드시 발견된다.
  2. v가 발견될 때 처리 중이던 노드를 u라 하자(즉 u를 처리하다가 간선 u→v를 통해 v가 발견됨).
  3. A→u→v 경로가 존재하므로, `dist(A, v) ≤ dist(A, u) + 1`이다. v의 실제 거리가 k+1이므로 `dist(A, u) ≥ k`가 성립한다.
  4. 한편 v는 u가 큐에서 빠져나온(dequeue) 후에 발견되므로, 이전 강의의 순서 보존 성질(order lemma)에 의해 `dist(A, u) < dist(A, v) = k+1`이다.
  5. `dist(A, u)`는 정수이고 동시에 k 이상이면서 k+1 미만이어야 하므로, `dist(A, u) = k`인 경우만 가능하다.
  6. 귀납 가정에 의해 u가 발견될 때 이미 올바른 거리 k가 대입되어 있었으므로, v가 발견될 때 `dist[v] = dist[u] + 1 = k + 1`이 대입된다. 이는 정확히 v의 실제 거리와 같다.
- 이로써 모든 도달 가능한 노드에 대해 귀납적으로 올바른 거리가 대입됨이 증명된다.

### 도달 불가능한 노드에 대한 결론
- 도달 불가능한 노드는 (이전 강의의 성질에 의해) 아예 발견되지 않으므로, 초기화된 값인 무한대(infinity)로 거리가 남는다. 이는 정확히 원하는 결과다(실제로 경로가 없으므로 거리는 무한대여야 한다).

### 종합 결론
- 노드가 발견되는 순간에 이미 올바른 거리가 대입되고, 이후 그 노드는 다시 발견되거나 큐에 들어가지 않으므로 거리 값은 그대로 유지된다.
- 따라서 BFS 알고리즘은 A로부터 모든 노드까지의 거리를 정확하게 계산한다.

## 요약
- 수학적 귀납법을 통해, BFS에서 노드가 발견되는 순간 대입되는 거리 값이 항상 실제 최단 거리와 일치함을 증명했다.
- 핵심 근거는 이전 강의에서 증명한 순서 보존 성질(u가 v보다 먼저 처리됨을 이용해 `dist(A,u)`가 정확히 k로 결정됨)이다.
- 도달 불가능한 노드는 발견되지 않아 거리 무한대로 남으므로, BFS는 모든 경우에 대해 올바른 거리를 반환한다.
