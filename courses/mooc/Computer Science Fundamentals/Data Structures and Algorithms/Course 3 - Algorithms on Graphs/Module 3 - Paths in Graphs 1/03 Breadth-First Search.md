# Breadth-First Search

## 개요
- 그래프 알고리즘의 가장 기본적인 빌딩 블록 중 하나인 너비 우선 탐색(breadth-first search, BFS)을 소개한다.
- 시작 노드 A로부터 모든 노드까지의 거리 레이어(distance layer)를 레이어 순서대로 나열하는 아이디어를 방향 그래프와 무방향 그래프 예시로 설명한다.
- 노드를 동시에 여러 개 발견할 수 없다는 현실적 제약을 언급하며, 이를 해결하기 위한 자료구조로 큐(queue)를 예고한다.

## 내용

### 노드 색칠 규칙
- 흰색(아직 다루지 않은 상태, 명시적으로 색칠하지는 않지만 미발견 상태를 의미) → 회색(gray, 방금 발견됨) → 검은색(black, 처리 완료됨) 순으로 노드 상태가 바뀐다.
- **발견(discover)**: 어떤 노드에 처음 도달하면 회색으로 칠한다.
- **처리(process)**: 회색 노드에서 나가는 모든 간선을 살펴보고 나면 그 노드를 검은색으로 칠한다.

### 방향 그래프에서의 레이어별 진행 예시
- 시작 노드 A를 발견하고 회색으로 칠한 뒤, 거리 레이어 0에 놓고 A 자신과의 거리는 0으로 둔다.
- A를 처리(검은색으로 칠함)하면서 A에서 나가는 모든 간선을 따라간다.
  - A에서 직접 도달 가능한 노드 4개를 발견 → 이들이 거리 레이어 1의 전부가 된다(A와 직접 연결된 간선이 있으므로).
  - 이 4개 노드를 처리하면서 나가는 간선을 다시 살펴본다.
    - **검은색 간선**: 아직 발견되지 않은 새 노드로 이어지는 간선. 이런 간선을 따라가면 거리 레이어 2에 해당하는 노드 4개를 새로 발견한다.
    - **빨간색 간선**: 이미 검은색(처리 완료)인 노드로 이어지는 쓸모없는 간선. 새로운 정보를 주지 않지만, 사전에 알 수 없으므로 반드시 확인해야 한다.
  - 레이어 2의 노드 4개를 처리하면 나가는 간선이 모두 빨간색(쓸모없음)이라, 더 이상 새 노드를 발견하지 못하고 알고리즘이 멈춘다.
- 만약 어떤 노드가 다른 어떤 노드와도 연결되어 있지 않다면, 그 노드까지의 거리는 무한대(infinity)이며 별도의 레이어에 속한다.

### 무방향 그래프에서의 진행
- 시작 노드 A(레이어 0)에서 나가는 간선을 따라 노드 5개를 발견 → 거리 레이어 1.
- 레이어 1의 노드들을 처리하며 나가는 간선을 다시 확인한다.
  - 빨간색 간선: 이미 검은색인 노드로 향함(쓸모없음).
  - 검은색 간선: 아직 발견되지 않은 노드로 향함 → 노드 3개를 새로 발견해 거리 레이어 2가 됨.
- 레이어 2의 노드들을 처리하면 나가는 간선이 모두 빨간색이라 알고리즘이 종료된다.
- 방향 그래프와 마찬가지로, 어디에도 연결되지 않은 먼 노드는 거리 무한대의 별도 레이어에 속한다.

### 실제 알고리즘으로 가기 위한 제약
- 위에서 설명한 방식은 "레이어 안의 여러 노드를 동시에 발견"하는 방식이었지만, 실제 컴퓨터는 여러 작업을 동시에(병렬로) 수행할 수 없다.
- 따라서 노드를 하나씩 순서대로 발견하도록 알고리즘을 수정해야 한다.
  - 거리 0인 노드가 먼저, 그다음 거리 1인 노드 전체, 그다음 거리 2인 노드 전체 순으로 발견되어야 한다.
  - 같은 거리 레이어 안에서는 어떤 순서로 발견되든 상관없다.
- 이 순서를 보장하기 위해 큐(queue)라는 자료구조를 사용한다.

## 요약
- BFS는 시작 노드로부터 가까운 노드부터 차례로(레이어 단위로) 발견·처리하는 그래프 탐색 알고리즘이다.
- 노드는 흰색(미발견) → 회색(발견됨) → 검은색(처리 완료)의 상태를 거친다.
- 노드를 동시에 여러 개 발견할 수 없으므로, 발견 순서를 보장하기 위해 큐 자료구조가 필요하다.
