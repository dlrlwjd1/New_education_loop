# Breadth-First Search (continued)

## 개요
- 이전 강의에서 설명한 "레이어별로 노드를 한꺼번에 발견"하는 방식을, 노드를 하나씩 발견하는 실제 알고리즘으로 다듬는다.
- 큐(queue)를 이용해 노드를 발견한 순서대로 처리하면서도 거리 증가 순서가 자동으로 지켜지는 과정을 예시로 보여준다.
- 이 알고리즘이 왜 "너비 우선(breadth-first)"이라 불리는지 설명한다.

## 내용

### 큐를 이용한 노드 발견·처리 절차
- 큐는 처음에는 비어 있다.
- 시작 노드 A를 발견하면서 거리를 0으로 설정하고 큐에 A 하나만 넣는다.
- 이후 큐의 맨 앞(top)에 있는 노드를 꺼내어 처리하는 과정을 반복한다.
  - 큐에서 노드를 꺼낼 때는 그 노드를 큐에서 완전히 제거한다.
  - "큐에 들어있는 노드 = 현재 회색(gray)인 노드"라는 성질이 항상 유지된다.

### 노드 A 처리 과정
- A를 꺼내어 검은색으로 칠하고, A에서 나가는 간선들을 순서 상관없이 하나씩 확인한다.
- 흰색(미발견) 노드로 이어지는 간선을 만나면:
  - 그 노드를 회색으로 칠하고 큐의 끝에 넣는다.
  - 새 노드의 거리는 "현재 처리 중인 노드의 거리 + 1"로 설정한다(예: A의 거리가 0이므로, A를 처리하며 발견한 노드는 거리 1).
- A에서 나가는 간선 4개를 모두 확인해 노드 4개(거리 1)를 발견하고 큐에 넣는다.

### 거리 1 노드들 처리 과정
- 큐에서 순서대로 거리 1인 노드들을 하나씩 꺼내어 검은색으로 칠하고 나가는 간선을 확인한다.
  - 이미 회색인 노드로 향하는 간선은 무시한다(쓸모없음).
  - 흰색 노드로 향하는 간선을 만나면 그 노드를 회색으로 칠하고, 거리를 "현재 노드 거리 + 1 = 2"로 설정한 뒤 큐 끝에 넣는다.
- 이 과정을 거리 1인 노드 4개 모두에 대해 반복하면, 거리 2인 노드들이 차례로 발견되어 큐에 쌓인다.

### 거리 2 노드들 처리 과정
- 큐에서 거리 2인 노드들을 순서대로 꺼내어 처리한다.
- 이 시점에는 모든 노드가 이미 발견(회색 또는 검은색)된 상태이므로, 나가는 간선이 모두 쓸모없는 간선이 되어 더 이상 새 노드가 큐에 추가되지 않는다.
- 모든 노드에 정확한 거리가 표시되면 알고리즘이 종료된다.

### 알고리즘의 이름과 의미
- 이 알고리즘은 시작 노드 주변부터 점점 더 넓게(breadth) 탐색해 나간다고 해서 너비 우선 탐색(breadth-first search)이라 불린다.
- 먼 노드보다 가까운 노드를 항상 먼저 발견·처리하며, 탐색 범위(breadth)를 점진적으로 넓혀간다.

## 요약
- 큐를 사용해 노드를 하나씩 발견·처리하면 거리 순서(0, 1, 2, …)가 자연스럽게 지켜진다.
- 새로 발견한 노드의 거리는 항상 "현재 처리 중인 노드의 거리 + 1"이다.
- 이 성질 때문에 시작 노드 주변에서 점점 바깥으로 넓게 퍼지는 방식으로 탐색이 진행되어 breadth-first search라는 이름이 붙었다.
