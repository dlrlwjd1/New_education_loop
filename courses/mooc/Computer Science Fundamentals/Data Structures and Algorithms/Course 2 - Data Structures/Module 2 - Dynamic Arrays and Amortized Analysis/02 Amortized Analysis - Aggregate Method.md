# Amortized Analysis: Aggregate Method

## 개요
- 개별 연산의 최악의 경우(worst case)만 보고 그 값을 전체 횟수만큼 곱하면 실제 비용을 과대평가할 수 있다. 일부 연산만 비싸고 대부분은 저렴한 경우가 많기 때문이다.
- 분할상환 분석(amortized analysis)은 연산 하나하나가 아니라 "연산들의 시퀀스 전체"의 총 비용을 보고 평균적인 비용을 계산하는 방법이다.
- 집계 방법(aggregate method)은 분할상환 비용의 정의를 그대로 이용해 직접 계산하는 방식이다.

## 내용

### 분할상환 비용(amortized cost)의 정의
- n번의 연산으로 이루어진 시퀀스가 있을 때, 분할상환 비용은 그 n번 연산의 총 비용을 n으로 나눈 값이다.
- 비유: 5년(60개월) 뒤 6,000달러짜리 새 차가 필요하다고 할 때, 매달 100달러씩 저축해두면 실제로 돈을 쓰는 달은 59개월 동안 0달러, 마지막 달에 6,000달러이지만, 분할상환 비용 관점에서는 매달 100달러를 쓰는 것과 같다. 최악의 달 지출은 6,000달러지만, 평균적인 관점은 100달러가 더 합리적인 수치라는 것을 보여준다.

### 동적 배열 PushBack의 집계 방법 분석
- 빈 배열에서 시작해 PushBack을 n번 호출하는 상황을 분석한다.
- 최악의 경우 개별 PushBack의 비용은 O(n)이다.
- c_i를 i번째 삽입의 비용이라 하면, 원소를 배열에 쓰는 비용은 항상 1이다(리사이징 여부와 무관).
- 리사이징이 필요한 시점: i번째 삽입에서 리사이징이 필요하려면, (i-1)번째 삽입 직후 배열이 꽉 찬 상태여야 한다. 즉 용량을 매번 두 배로 늘리는 구조에서는 (i-1)이 2의 거듭제곱(power of 2)일 때 리사이징이 발생한다.
- 리사이징이 필요 없으면 추가 비용은 0이다.
- 전체 분할상환 비용은 `(sum_{i=1}^{n} c_i) / n`이다. 이 합은 다음과 같이 나눌 수 있다: 원소를 쓰는 기본 비용의 합(항상 1씩, n번 → 총 n) + 리사이징 시 원소를 복사하는 비용의 합(2의 거듭제곱들의 합, 즉 `sum_{j=1}^{floor(log2(n-1))} 2^j`).
- 예를 들어 n=100이면 2의 거듭제곱은 1, 2, 4, 8, 16, 32, 64이며, 이 합은 최대 2n을 넘지 않는다(등비수열의 성질).
- 따라서 총 비용은 `n + (2n 이하)`로 O(n)이 되고, 이를 n으로 나누면 분할상환 비용은 O(1)이 된다.

## 예시
- n=100일 때 리사이징이 일어나는 시점의 2의 거듭제곱들: 1, 2, 4, 8, 16, 32, 64 (합은 127로 2×100=200 이하).
- 결론적으로 PushBack의 최악의 경우 비용은 여전히 O(n)이지만(어떤 한 번의 호출이 리사이징을 유발하면 그 순간은 O(n)), n번 연속 호출했을 때의 분할상환 비용은 O(1)이다.

## 요약
- 분할상환 비용은 "n번 연산의 총 비용 / n"으로 정의되며, 최악의 경우만 보는 것보다 더 현실적인 평균 비용을 제공한다.
- 집계 방법(aggregate method)은 이 정의에 따라 총 비용을 직접 합산해 계산하는 방식이다.
- 동적 배열에서 용량을 두 배씩 늘리는 경우, PushBack을 n번 연속 수행했을 때 개별 최악 비용은 O(n)이지만 분할상환 비용은 O(1)이다.
- 다음 강의에서는 같은 결론을 다른 방식(뱅커 방법, banker's method)으로 유도한다.
