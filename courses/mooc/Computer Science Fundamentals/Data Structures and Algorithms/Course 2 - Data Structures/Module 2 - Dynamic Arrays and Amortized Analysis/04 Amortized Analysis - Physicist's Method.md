# Amortized Analysis: Physicist's Method

## 개요
- 물리학자 방법(Physicist's Method)은 분할상환 분석의 세 번째 방법으로, 자료구조의 상태를 정수로 매핑하는 퍼텐셜 함수(potential function)를 정의해 분석하는 방식이다.
- 고등학교 물리에서 배우는 위치 에너지(potential energy) 개념과 유사하다 — 공을 언덕 위로 올리면 위치 에너지가 증가하고, 굴러 내려가면 위치 에너지가 운동 에너지로 바뀌며 감소한다.

## 내용

### 퍼텐셜 함수의 조건
- Φ(h_0) = 0: 자료구조의 초기 상태(시간 0)의 퍼텐셜은 0이어야 한다.
- Φ(h_t) ≥ 0: 어느 시점에서도 퍼텐셜은 음수가 될 수 없다.
- 연산 t의 분할상환 비용은 `c_t + Φ(h_t) - Φ(h_{t-1})`로 정의한다. 즉 실제 비용에 "퍼텐셜의 변화량"을 더한 값이다.
- 좋은 퍼텐셜 함수는, 실제 비용(c_t)이 작을 때는 퍼텐셜이 증가(나중을 위해 저축)하고, 실제 비용이 클 때는 퍼텐셜이 감소(저축한 것을 사용)하도록 설계해야 한다.

### 왜 이 방법이 타당한가 (합의 상쇄)
- n번 연산의 분할상환 비용의 총합을 전개하면: `sum(c_i) + Φ(h_n) - Φ(h_0)`가 된다. 중간의 Φ(h_1), Φ(h_2), … 항들은 연속된 항끼리 부호가 반대로 나타나 서로 상쇄되기 때문이다.
- Φ(h_0)=0이고 Φ(h_n)≥0이므로, 분할상환 비용의 합은 항상 실제 비용의 합보다 크거나 같다. 즉 분할상환 비용의 합은 실제 총 비용의 하한(lower bound) 역할을 한다.

### 동적 배열 PushBack에 적용
- 퍼텐셜 함수를 `Φ(h) = 2 × size - capacity`로 정의한다.
- 조건 확인: 초기 상태(size=0, capacity=0)에서 Φ = 0으로 조건을 만족한다. size는 항상 capacity의 절반 이상이므로 `2 × size - capacity ≥ 0`이 항상 성립해 두 번째 조건도 만족한다.
- 리사이징이 필요 없는 경우: 원소 하나를 추가하는 실제 비용은 1이고, capacity는 변하지 않으므로 퍼텐셜 변화는 `2 × (size 변화량) = 2 × 1 = 2`. 따라서 분할상환 비용은 `1 + 2 = 3`.
- 리사이징이 필요한 경우: 리사이징 직전에는 size = capacity = k인 상태다. 실제 비용은 기존 k개의 원소를 옮기고 새 원소 1개를 추가하는 것이므로 k+1. 리사이징 후 capacity는 2k가 되고 size는 k+1이 되므로, Φ(이후) = 2(k+1) - 2k = 2, Φ(이전) = 2k - k = k. 따라서 분할상환 비용은 `(k+1) + 2 - k = 3`.

### 결과
- 리사이징이 있든 없든 PushBack의 분할상환 비용은 동일하게 3이며, 이는 O(1)이다.
- 이 값 3은 뱅커 방법(Banker's Method)에서 얻은 청구액 3과 정확히 동일하다 — 우연이 아니라 두 방법이 본질적으로 같은 회계를 다른 형태로 표현한 것이기 때문이다.

## 예시
- 리사이징 없는 경우의 분할상환 비용 계산: `c_i + Φ(h_i) - Φ(h_{i-1}) = 1 + 2×1 - 0 = 3` (capacity 불변이므로 상쇄, size 차이만 반영).
- 리사이징이 있는 경우(k=size=capacity 직전 상태)의 계산: `c_i + Φ(h_i) - Φ(h_{i-1}) = (k+1) + 2 - k = 3`.

## 요약
- 물리학자 방법(Physicist's Method)은 자료구조 상태를 정수로 매핑하는 퍼텐셜 함수 Φ를 정의하고, 분할상환 비용을 `c_t + Φ(h_t) - Φ(h_{t-1})`로 계산하는 기법이다.
- Φ(h_0)=0, Φ(h_t)≥0 조건을 만족하면 분할상환 비용의 합이 실제 비용 합의 하한이 됨을 보장한다.
- 동적 배열에 `Φ = 2 × size - capacity`를 적용하면, 리사이징 여부와 무관하게 PushBack의 분할상환 비용이 항상 3, 즉 O(1)임을 보일 수 있다.
- 이 결과는 뱅커 방법에서 얻은 결론(청구액 3)과 정확히 일치한다.
