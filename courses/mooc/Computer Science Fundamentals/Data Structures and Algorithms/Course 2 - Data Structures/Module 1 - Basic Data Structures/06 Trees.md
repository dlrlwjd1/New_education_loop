# Trees

## 개요
- 트리(tree)는 문장 구조(구문 트리, syntax tree), 수식, 계층 구조(지리, 생물 분류), 프로그램 코드(추상 구문 트리) 등 다양한 곳에서 사용되는 자료구조다.
- 트리는 재귀적(recursive)으로 정의된다: 트리는 비어있거나(empty), key와 자식 트리들의 목록을 가진 노드다.
- 컴퓨터 과학에서는 관례적으로 트리를 아래로 자라는 형태로 그린다. 즉 부모가 자식보다 위에 위치한다.

## 내용

### 트리 예시
- 구문 트리(syntax tree): 문장 "I ate the cake"를 명사구(noun phrase)와 동사구(verb phrase) 등으로 나누어 문장 구조를 표현한다.
- 수식 트리: `2sin(3z-7)` 같은 수식을 연산 순서에 따라 트리로 표현하면, 가장 나중에 계산되는 연산(곱셈)이 트리의 최상단에 온다.
- 계층 구조: 세계 지리(세계 → 국가 → 주/도 → 도시)나 동물 분류(동물 → 척추/무척추동물 → 하위 분류) 같은 포함 관계를 표현한다.
- 추상 구문 트리(abstract syntax tree): while 반복문 같은 코드를 조건과 실행문으로 나누어 트리로 표현한다.

### 이진 탐색 트리(binary search tree)
- 이진(binary) 트리이므로 각 노드는 최대 두 개의 자식을 가진다.
- 각 노드에서 루트(왼쪽 자식 서브트리의 모든 값) ≤ 루트 값 < (오른쪽 자식 서브트리의 모든 값)이라는 규칙이 트리 전체에 재귀적으로 적용된다(알파벳 순서 기준 예시 포함).
- 이 성질 덕분에 특정 값을 빠르게 탐색할 수 있다. 예를 들어 트리에서 "Tony"를 찾을 때 루트에서 시작해 크기 비교로 왼쪽 또는 오른쪽으로 이동하며, 정렬된 배열에서의 이진 탐색(binary search)과 유사하게 단 몇 번의 비교만으로 원하는 값을 찾을 수 있다.

### 트리 용어
- 루트(root): 트리의 최상단 노드.
- 자식(child)/부모(parent): 직접 연결된 아래/위 노드.
- 조상(ancestor): 부모, 부모의 부모 등.
- 자손(descendant): 자식, 자식의 자식 등.
- 형제(sibling): 같은 부모를 공유하는 노드들.
- 리프(leaf): 자식이 없는 노드.
- 내부 노드(interior node): 리프가 아닌(자식이 있는) 노드.
- 레벨(level): 루트와 해당 노드 사이의 간선(edge) 수 + 1. 루트 자신의 레벨은 1이다.
- 높이(height): 해당 노드에서 가장 먼 리프까지의 최대 깊이. 리프의 높이는 1이다.
- 포레스트(forest): 여러 트리의 집합.

### 트리의 표현
- 노드는 key, 자식 목록(children), 그리고 선택적으로 부모(parent) 포인터를 가질 수 있다.
- 가장 흔한 표현은 부모 포인터 없이 자식만 갖는 형태이지만, 부모 포인터를 두면 트리의 임의 위치에서 다른 위치로(위로 올라갔다 다시 아래로 내려가며) 이동할 수 있어 유용할 때가 있다.
- 이진 트리(binary tree)는 일반적인 자식 목록 대신 명시적인 left, right 자식 포인터를 가지며, 둘 중 하나 혹은 둘 다 nil일 수 있다.

### 재귀적 연산
- 트리는 재귀적으로 정의되므로, 트리를 다루는 함수도 재귀적으로 작성하는 것이 자연스럽다.
- 높이(height) 계산: nil 트리의 높이는 0. 그 외에는 `1 + max(왼쪽 자식의 높이, 오른쪽 자식의 높이)`.
- 크기(size, 노드 개수) 계산: nil 트리의 크기는 0. 그 외에는 `1 + 왼쪽 자식의 크기 + 오른쪽 자식의 크기`.

## 예시
- 리프 노드의 높이 계산: 왼쪽·오른쪽 자식이 모두 nil이므로 각각의 높이는 0, `1 + max(0, 0) = 1`.
- 이진 탐색 트리에서 "Tony" 탐색: 루트(Les)보다 크므로 오른쪽 → 다음 노드(Sam)보다 크므로 오른쪽 → 다음 노드(Violet)보다 작으므로 왼쪽 → Tony 발견. 총 4번의 비교로 탐색 완료.

## 요약
- 트리는 "비어있거나, key와 자식 트리 목록을 가진 노드"로 재귀적으로 정의되는 자료구조이며, 언어 구문·수식·계층 구조·코드 표현 등 다양한 곳에 쓰인다.
- 이진 탐색 트리(binary search tree)는 왼쪽 서브트리 ≤ 노드 < 오른쪽 서브트리 규칙을 통해 빠른 탐색을 지원한다.
- 루트, 자식, 부모, 조상, 자손, 형제, 리프, 내부 노드, 레벨, 높이 등의 용어로 트리 구조를 설명한다.
- 트리는 재귀적 구조이므로 높이나 크기 계산 같은 연산도 재귀적으로 구현하는 것이 자연스럽다.
