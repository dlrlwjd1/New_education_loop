# Overview

## 개요
- 새로운 주제인 서로소 집합(disjoint sets) 자료구조를 소개한다.
- 미로(maze) 예시를 통해 두 지점이 서로 연결되어 있는지 판별하는 문제를 동기로 제시하고, 이를 해결하는 세 가지 연산 `MakeSet`, `Find`, `Union`을 정의한다.

## 내용

### 동기 예시 — 미로(maze) 문제
- 격자(grid) 형태의 칸(cell)들과 일부 인접한 칸 사이의 벽(wall)으로 이루어진 미로가 주어졌을 때, 두 칸 사이에 경로(path)가 있는지 판단하는 문제.
- 한 칸 B에서 도달 가능한(reachable) 모든 칸의 집합을 구한 뒤, 다른 칸 A가 그 집합에 속하는지 확인하면 A가 B로부터 도달 가능한지 알 수 있다.

### 서로소 집합(disjoint set) 자료구조의 세 연산
- `MakeSet(x)`: 원소 x 하나만 포함하는 크기 1짜리 집합을 새로 만든다.
- `Find(x)`: 원소 x가 속한 집합의 ID를 반환한다.
  - x와 y가 같은 집합에 있으면 `Find(x) = Find(y)`.
  - x와 y가 다른 집합에 있으면 `Find(x) ≠ Find(y)`.
- `Union(x, y)`: x가 속한 집합과 y가 속한 집합을 하나로 합친다(merge). `Union(x, y)` 호출 직후에는 `Find(x) = Find(y)`가 성립해야 한다.

### 미로 문제 해결 절차
1. 미로의 모든 칸 c에 대해 `MakeSet(c)`를 호출한다 — 초기에는 칸 수만큼 별개의 영역(region)이 존재한다.
2. 모든 칸 c와 그 이웃(neighbor) n(인접하면서 사이에 벽이 없는 칸)에 대해 `Union(c, n)`을 호출해 영역을 합친다.
3. 전처리 후에는 각 영역(연결된 칸들의 묶음)이 고유한 ID를 갖게 되며, 두 칸이 `Find` 결과가 같은지만 확인하면 서로 도달 가능한지 알 수 있다.

### 또 다른 예시 — 네트워크 연결
- 기계(machine) 각각에 대해 `MakeSet`을 호출해 초기에는 모두 별도의 집합으로 둔다.
- 두 기계 사이에 와이어(wire)를 연결할 때마다 `Union`을 호출해 두 기계가 같은 네트워크(같은 집합)에 속함을 반영한다.
- 이렇게 관리하면 두 기계가 같은 네트워크에 있는지를 `Find` 결과 비교로 즉시 확인할 수 있다.
- 이 자료구조는 이후 강의에서 다룰 크루스칼(Kruskal) 알고리즘(최소 신장 트리를 구하는 알고리즘)에서 핵심적으로 사용된다.

## 예시
- 기계 1~5가 있다고 하자. `MakeSet(1)`, ..., `MakeSet(5)` 이후에는 `Find(1) ≠ Find(2)`이다.
- `Union(3,4)` 이후 3과 4는 같은 집합. `Union(3,2)` 이후 2, 3, 4가 같은 집합이지만, 여전히 `Find(1) ≠ Find(2)`.
- `Union(1,4)` 이후에는 1, 2, 3, 4가 모두 같은 집합이 되어 `Find(1) = Find(2)`가 성립한다.

## 요약
- 서로소 집합(disjoint sets) 자료구조는 `MakeSet`, `Find`, `Union` 세 연산을 지원하며, 원소들을 겹치지 않는 여러 집합으로 관리한다.
- 미로에서 두 칸의 연결 여부, 네트워크에서 두 기계의 연결 여부처럼 "같은 그룹에 속하는가"를 묻는 문제에 자연스럽게 응용된다.
- 다음 강의부터 이 자료구조를 효율적으로 구현하는 방법을 다룬다.
