# Introduction

## 개요
- 우선순위 큐(priority queue)라는 자료구조를 소개한다. C++, Java, Python 등 많은 언어에 내장 구현이 있으며, 이 강의에서는 그 내부 동작 원리를 다룬다.
- 우선순위 큐는 완전 이진 트리(complete binary tree)에 데이터를 저장하고, 이 트리를 다시 배열(array)로 저장하는 방식으로 구현할 수 있어 시간·공간 모두 효율적이다.

## 내용

### 큐(queue)와 우선순위 큐(priority queue)의 차이
- 표준 큐(queue)는 `PushBack(e)`로 뒤에 원소를 넣고, `PopFront()`로 앞에서 원소를 꺼내는 두 연산을 지원한다.
- 우선순위 큐에는 앞/뒤 개념이 없다. 그냥 원소들의 모음(bag)이며, 각 원소는 우선순위(priority)를 갖는다.
- 새 원소가 들어오면 `Insert`로 삽입하고, 다음에 처리할 원소를 꺼낼 때는 `ExtractMax`로 현재 가장 우선순위가 높은 원소를 찾아 꺼낸다.

### 활용 예시 상황
- 기계가 작업(job)들을 처리하는 상황을 가정하면, 새 작업이 도착했을 때 빠르게 `Insert`하고, 현재 작업이 끝났을 때 우선순위가 가장 높은 다음 작업을 빠르게 찾아야 한다.

### 형식적 정의(abstract data type)
- 우선순위 큐는 `Insert`와 `ExtractMax` 두 연산을 지원하는 추상 데이터 타입(abstract data type)이다.

### 추가로 기대할 수 있는 연산
- `Remove`: 최대값이 아니라 이터레이터(iterator)로 지정한 특정 원소를 제거.
- `GetMax`: 최대 우선순위를 추출하지 않고 확인만 함.
- `ChangePriority(it, p)`: 특정 원소의 우선순위를 증가 또는 감소시킴.

### 우선순위 큐를 사용하는 유명 알고리즘
- 다익스트라(Dijkstra) 알고리즘: 그래프에서 최단 경로를 찾는 데 사용.
- 프림(Prim) 알고리즘: 그래프에서 최소 신장 트리(minimum spanning tree)를 찾는 데 사용 (예: 컴퓨터들을 케이블 총 길이를 최소화하며 연결하는 문제).
- 허프만(Huffman) 알고리즘: 문자열/파일의 최적 접두어 자유 인코딩(prefix-free encoding)을 계산 (예: MP3 오디오 인코딩).
- 힙 정렬(heap sort): 우선순위 큐를 이용해 n개의 원소를 정렬하는 비교 기반(comparison based) 알고리즘. 최악의 경우에도 실행 시간이 O(n log n)이며, 추가 메모리 없이 제자리(in place)에서 동작한다.

## 예시
- 초기 빈 우선순위 큐에 5, 7, 1, 4를 차례로 삽입한 뒤 `ExtractMax()`를 호출하면 7이 추출된다.
- 이어서 3을 삽입하고 `ExtractMax()`를 호출하면 5가 추출되고, 다시 `ExtractMax()`를 호출하면 4가 추출된다.

## 요약
- 우선순위 큐(priority queue)는 `Insert`와 `ExtractMax`를 지원하는 추상 데이터 타입이며, 표준 큐와 달리 원소의 순서가 아니라 우선순위로 처리 대상을 결정한다.
- 다익스트라, 프림, 허프만 알고리즘과 힙 정렬 등 여러 유명 알고리즘이 우선순위 큐를 핵심적으로 사용한다.
- 이후 강의에서 이진 힙(binary heap)을 이용해 시간·공간 효율적인 구현을 다룬다.
