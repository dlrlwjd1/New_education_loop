# Binary Trees

## 개요
- 우선순위 큐를 구현하는 가장 대표적인 방법인 이진 힙(binary heap)을 정의한다.
- 이진 최대 힙(binary max heap)은 각 노드가 0, 1, 2개의 자식을 가지는 이진 트리(binary tree)이면서, 특정 힙 속성(heap property)을 만족해야 한다.

## 내용

### 이진 최대 힙(binary max heap)의 정의
- 이진 트리의 각 노드는 자식을 0개, 1개, 혹은 2개 가진다.
- 힙 속성: 모든 노드의 값은 그 자식 노드들의 값 이상이어야 한다.
- 달리 말하면, 트리의 어떤 간선(edge)을 봐도 위쪽(부모) 끝의 값이 아래쪽(자식) 끝의 값 이상이어야 한다.

### 예시로 본 힙 속성 위반
- 힙 속성을 만족하는 트리는 모든 간선에서 부모 값 ≥ 자식 값이 성립한다.
- 힙 속성을 위반한 트리의 예에서는 부모(10)보다 자식(25)이 더 큰 간선처럼, 속성이 깨진 간선이 여러 개(예시에서는 5개) 나타날 수 있다.

## 요약
- 이진 최대 힙(binary max heap)은 각 간선에서 부모 값이 자식 값 이상인 이진 트리다.
- 이 속성이 하나라도 위반되면 그 트리는 더 이상 이진 최대 힙이 아니다.
- 다음 강의부터 이 구조 위에서 `GetMax`, `Insert`, `ExtractMax` 같은 연산을 구현하는 방법을 다룬다.
