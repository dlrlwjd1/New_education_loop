# Final Remarks

## 개요
- 이진 힙(binary heap)에 관한 몇 가지 보충 내용을 다루고, 우선순위 큐(priority queue)와 이진 힙 강의 전체를 정리한다.

## 내용

### 0-기반 배열(zero-based array)에서의 인덱스 공식
- 배열을 0부터 인덱싱하는 경우, 부모/자식 인덱스 공식이 다음과 같이 바뀐다.
  - `Parent(i) = ⌊(i-1)/2⌋`
  - `LeftChild(i) = 2i + 1`
  - `RightChild(i) = 2i + 2`

### 이진 최소 힙(binary min-heap)
- 이진 최소 힙(binary min-heap)은 각 간선에서 부모 값이 자식 값 이하(부모 ≤ 자식)인 힙이다.
- 최대 우선순위가 아니라 최소 우선순위를 가진 원소를 추출해야 하는 경우에 사용하며, 구현 방식은 최대 힙과 동일하다(부등호 방향만 반대).

### d-항 힙(d-ary heap)으로의 일반화
- 각 노드가 최대 d개의 자식을 가질 수 있도록 일반화한 것이 d-항 힙이다.
- d-항 힙이 완전(complete)하려면 이진 힙과 마찬가지로 마지막 레벨을 제외한 모든 레벨이 가득 차 있고, 마지막 레벨은 왼쪽부터 채워져 있어야 한다.
- 트리 높이는 log_d(n)이 된다.
- `SiftUp`의 실행 시간은 O(log_d n)이다(높이만큼만 이동).
- `SiftDown`의 실행 시간은 O(d log_d n)이다. 아래로 내려갈 방향을 정하려면 d개의 자식 중 가장 큰 값을 찾아야 하므로 매 단계 d에 비례하는 비교가 추가로 필요하기 때문이다.

### 전체 정리
- 우선순위 큐(priority queue)는 `Insert`와 `ExtractMax`(최고 우선순위 원소 추출) 두 연산을 지원하는 추상 데이터 타입(abstract data type)이며 다양한 곳에 응용된다.
- 배열이나 리스트(정렬 여부와 무관)로 순진하게 구현하면 두 연산 중 하나는 항상 선형 시간이 걸린다.
- 이진 힙(binary heap)을 사용하면 모든 연산을 최악의 경우에도 O(log n)에 수행할 수 있다.
- 이진 힙은 공간 효율적이다. 트리이지만 부모·자식으로의 명시적 링크(link)를 저장할 필요 없이 배열 하나로 저장할 수 있어, 시간과 공간 모두 효율적인 자료구조다.

## 요약
- 0-기반 배열에서는 `Parent(i)=⌊(i-1)/2⌋`, `LeftChild(i)=2i+1`, `RightChild(i)=2i+2`를 사용한다.
- 최소 힙(min-heap)은 최대 힙과 구현이 동일하되 부등호 방향만 반대다.
- d-항 힙(d-ary heap)은 `SiftUp`이 O(log_d n), `SiftDown`이 O(d log_d n)이다.
- 이진 힙은 모든 연산을 O(log n)(`GetMax`는 O(1))에 처리하며 시간·공간 모두 효율적인 우선순위 큐 구현이다.
