# Basic Operations

## 개요
- 이진 탐색 트리(binary search tree)의 기본 연산인 Find, Next, Range Search, Insert, Delete를 어떻게 구현하는지 설명한다.

## 내용
### Find
- `Find(k, R)`: 키 `k`와 트리의 루트(root) `R`을 받아, `R`을 루트로 하는 서브트리(subtree)에서 키가 `k`와 같은 노드를 반환한다.
- 재귀적으로 구현한다.
  - `R.key == k`면 `R`을 반환한다.
  - `R.key > k`면 왼쪽 서브트리에서 재귀적으로 찾는다.
  - `R.key < k`면 오른쪽 서브트리에서 재귀적으로 찾는다.
- 찾는 키가 트리에 없을 경우: null 포인터에 도달하기 직전에 멈추면, 그 자리가 바로 `k`가 있어야 할 위치다. 그래서 `Find`를 약간 수정해 자식이 null이면 더 내려가지 않고 그 자리(현재 노드)를 반환하도록 한다. 이는 Insert에서 유용하게 쓰인다.

### Next (후속자 찾기)
- `Next(N)`: 노드 `N`을 받아 같은 트리에서 바로 다음으로 큰 키를 가진 노드를 반환한다.
- 경우 1: `N`이 오른쪽 자식(right child)을 가지면, 오른쪽으로 한 번 이동한 뒤 왼쪽 자식이 없을 때까지 계속 왼쪽으로 내려간다. 그 노드가 후속자(successor)다.
- 경우 2: `N`이 오른쪽 자식이 없으면, 부모(parent)를 따라 위로 올라가면서 `N`보다 키가 큰 첫 번째 조상(ancestor)을 찾는다. 그 조상이 후속자다.
- 구현은 두 하위 함수로 나뉜다.
  - `LeftDescendant`: 왼쪽 자식이 없으면 자기 자신을 반환, 있으면 왼쪽으로 한 칸 내려가 재귀 호출.
  - `RightAncestor`: 부모의 키가 자신보다 크면 부모를 반환, 아니면 한 단계 위로 올라가 재귀 호출.
- `Next(N)`: `N`이 오른쪽 자식이 없으면 `RightAncestor(N)`, 있으면 `LeftDescendant(N의 오른쪽 자식)`을 반환.

### Range Search
- `Find`와 `Next`를 조합해 쉽게 구현할 수 있다.
- 리스트 `L`을 만들고, `x` 이상인 첫 노드를 `Find`로 찾아 `N`에 저장한다.
- `N`의 키가 `y`보다 작은 동안(그리고 `x`보다 큰 동안) `N`을 `L`에 추가하고, `N`을 `Next(N)`으로 갱신하는 과정을 반복한다.
- 마지막에 `L`을 반환한다.

### Insert
- `Insert(k, R)`: 키 `k`를 트리에 새 노드로 추가한다.
- 배열과 달리 트리는 리프(leaf) 자리에 새 노드를 매달기만 하면 되므로 간단하다.
- 단, search tree property를 지키려면 올바른 위치에 매달아야 한다. `Find(k, R)`을 실행하면(트리에 없는 키이므로) 바로 그 위치인 부모 `P`를 얻을 수 있다.
- `k`와 `P.key`를 비교해 왼쪽 또는 오른쪽 자식으로 새 노드를 붙인다.

### Delete
- `Delete(N)`: 노드 `N`을 트리에서 제거한다.
- 단순히 노드를 지우면 그 부모와 자식들의 연결이 끊어지므로, 빈자리를 채울 방법이 필요하다.
- 자연스러운 방법: 정렬 순서상 가까운 원소, 즉 `Next(N)`인 `X`를 찾아 그 자리를 채운다.
- `X`는 `N`의 바로 다음 원소이므로 보통 왼쪽 자식은 없지만, 오른쪽 자식 `Y`를 가질 수 있다. `X`를 옮기면 `Y`가 고아가 되므로, `Y`를 `X`가 있던 자리로 올려야 한다.
- 구현
  - `N`이 오른쪽 자식이 없으면: `N`을 제거하고, `N`의 왼쪽 자식(있다면)을 `N`의 부모의 자식으로 승격(promote)시킨다.
  - `N`이 오른쪽 자식이 있으면: `X = Next(N)`을 구한다(이때 `X`는 왼쪽 자식이 없음). `N`을 `X`로 교체하고, `X`의 오른쪽 자식을 승격시켜 `X`가 있던 빈자리를 채운다.

## 예시
- Find(6): 7과 비교(작음) → 왼쪽으로 → 4와 비교(큼) → 4의 오른쪽으로 → 6과 비교(같음) → 종료.
- Find(5, 없는 키): 7보다 작음 → 왼쪽, 4보다 큼 → 오른쪽, 6보다 작음 → 왼쪽 자식이 null이므로 6에서 멈춤. 5가 있었어야 할 자리를 알려준다.
- Range Search(5, 12) on {1, 4, 6, 7, 10, 13, ...}: 5 이상인 첫 원소 6부터 시작해 `Next`를 반복 → 6, 7, 10을 리스트에 담고 13은 12보다 크므로 멈춘다.
- Delete 예시: 노드 1을 삭제할 때, `Next(1)`인 2로 1의 자리를 채우고, 2의 자식이었던 4를 2가 있던 자리(2의 원래 부모 쪽)로 승격시킨다.

## 요약
- Find는 트리를 따라 내려가며 키를 비교하는 재귀 탐색이며, 못 찾은 키에 대해서는 삽입 위치를 알려주도록 변형할 수 있다.
- Next는 오른쪽 자식이 있으면 그 서브트리의 최솟값으로, 없으면 자신보다 큰 첫 조상으로 이동해 구한다.
- Range Search는 Find로 시작점을 찾고 Next를 반복해 구현한다.
- Insert는 Find로 빈자리를 찾아 새 노드를 매달면 된다.
- Delete는 후속자(successor)로 자리를 채우고, 후속자의 오른쪽 자식을 다시 승격시키는 두 단계로 처리한다.
- 다음 강의에서는 이 연산들의 실행 시간과 트리의 균형(balance) 문제를 다룬다.
