# AVL Trees

## 개요
- 이진 탐색 트리의 균형을 유지하는 구체적인 방법인 AVL 트리를 소개한다. 균형을 측정하는 도구인 높이(height)와 AVL 성질(AVL property)을 정의하고, 이 성질이 성립하면 트리 높이가 O(log n)임을 증명한다.

## 내용
### 높이(Height)
- 노드의 높이(height)는 그 노드에서 리프(leaf)까지 내려가는 경로 중 가장 긴 경로의 길이다.
- 재귀적 정의
  - 리프의 높이는 1이다(더 내려갈 곳이 없으므로).
  - 그 외 노드의 높이는 왼쪽 자식의 높이와 오른쪽 자식의 높이 중 더 큰 값에 1을 더한 값이다.
- 노드는 key, parent, left child, right child 포인터 외에 높이(height) 필드를 새로 저장해야 한다.
- 트리를 재배열(회전 등)하면 높이가 바뀔 수 있으므로, 이 필드를 항상 최신 상태로 유지하는 작업이 별도로 필요하다.

### AVL 성질(AVL Property)
- 높이는 서브트리 크기를 대략적으로 나타내는 척도다. 균형을 위해서는 어떤 노드의 왼쪽·오른쪽 서브트리 높이가 거의 같기를 원한다.
- **AVL property**: 트리의 모든 노드 `N`에 대해, `N`의 왼쪽 자식의 높이와 오른쪽 자식의 높이 차이가 최대 1이다.
- 모든 노드에서 이 성질이 유지되면 트리가 충분히 균형 잡혀 있다고 볼 수 있다.

### AVL 성질과 트리 높이의 관계 (정리와 증명)
- 목표: AVL 트리의 높이가 O(log n)임을 보이는 것. 이를 직접 증명하기보다, "높이가 h인 AVL 트리는 노드 수가 적어도 얼마다"라는 방식(대우)으로 접근한다.
- **정리**: AVL 성질을 만족하는 트리에서, 높이가 `h`인 노드 `N`의 서브트리 크기는 최소한 `h`번째 피보나치 수(Fibonacci number) `F(h)` 이상이다.
- 피보나치 수: `F(0) = 0`, `F(1) = 1`, 이후 `F(n) = F(n-1) + F(n-2)`. `n ≥ 6`일 때 `F(n) ≥ 2^(n/2)`.
- 증명(높이에 대한 귀납법, induction on height)
  - 기본 단계: 높이가 1인 노드는 리프이며 서브트리 크기가 1이다. 이는 `F(1) = 1`과 일치한다.
  - 귀납 단계: 높이가 `h`인 노드는 정의상 두 자식 중 적어도 하나가 높이 `h-1`을 가진다. AVL property에 의해 다른 자식은 높이가 최소 `h-2`다. 귀납 가설(inductive hypothesis)에 의해 전체 노드 수는 최소 `F(h-1) + F(h-2) = F(h)` 이상이다.
- 결론: 노드가 `n`개인 트리에서 높이 `h`인 노드가 있다면 `2^(h/2) ≤ n`이 성립하므로, `h ≤ 2 log₂(n)`, 즉 `h = O(log n)`이다.
- 따라서 AVL property를 유지할 수 있다면 Find 등의 연산을 O(log n) 시간에 수행할 수 있다.

## 요약
- 노드의 높이(height)는 왼쪽·오른쪽 자식 높이의 최댓값 + 1로 재귀적으로 정의된다.
- AVL property: 모든 노드에서 왼쪽 자식과 오른쪽 자식의 높이 차이가 최대 1.
- 피보나치 수를 이용한 귀납 증명으로, AVL property를 만족하면 트리 높이가 O(log n)임을 보일 수 있다.
