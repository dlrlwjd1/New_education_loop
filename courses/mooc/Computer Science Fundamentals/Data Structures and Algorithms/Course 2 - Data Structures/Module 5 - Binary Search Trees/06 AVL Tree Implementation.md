# AVL Tree Implementation

## 개요
- AVL 트리에서 삽입(Insert)과 삭제(Delete) 시 AVL property가 깨지는 문제를 회전(rotation)을 이용한 재균형(rebalance) 연산으로 해결하는 구체적인 구현 방법을 설명한다.

## 내용
### 삽입이 AVL property를 깨는 이유
- 새 노드를 삽입하면 삽입 경로(insertion path)에 있는 조상 노드들의 높이가 바뀔 수 있고, 이로 인해 일부 노드에서 AVL property가 깨질 수 있다.
- 다행히 삽입 시 높이가 바뀌는 노드는 삽입 경로 위에 있는 노드들뿐이므로, 그 경로만 확인하면 된다.

### 삽입 알고리즘의 기본 흐름
1. 기존 방식대로 새 노드를 삽입한다.
2. 방금 삽입한 노드 `N`을 찾는다.
3. `N`에서 시작해 부모(parent) 포인터를 따라 루트까지 올라가며 재균형(rebalance) 연산을 수행한다.

### Rebalance 연산
- 어떤 노드에서 왼쪽 자식과 오른쪽 자식의 높이 차이가 1 이하면 이미 AVL property를 만족하므로 그대로 둔다.
- 차이가 1보다 크면(삽입 직후에는 최대 2까지만 벌어질 수 있음이 보장됨) 재조정이 필요하다. 왼쪽이 2 더 높으면 왼쪽 자식을 위로 올려 보정해야 한다.
- `Rebalance(N)` 절차
  1. `N`의 부모 `P`를 저장해 둔다(이후 `P`도 재귀적으로 고쳐야 하므로).
  2. `N`의 왼쪽 자식 높이가 오른쪽 자식보다 1 초과로 크면 오른쪽으로 재균형(rebalance right-wards)한다.
  3. `N`의 오른쪽 자식 높이가 왼쪽 자식보다 1 초과로 크면 왼쪽으로 재균형(rebalance left-wards)한다.
  4. 이후 `N`의 높이(height) 필드가 부정확할 수 있으므로 `AdjustHeight(N)`으로 다시 계산한다.
  5. `P`가 null이 아니면(즉 루트가 아니면) `P`에 대해 재귀적으로 `Rebalance`를 호출한다.
- `AdjustHeight(N)`: `N`의 높이를 "1 + max(왼쪽 자식 높이, 오른쪽 자식 높이)"로 재설정한다.

### 재균형(Rebalance Right)의 세부 구현과 이중 회전
- 왼쪽 자식이 2만큼 더 무거운(heavy) 경우, 단순히 오른쪽으로 한 번 회전하면 되는 경우가 많다.
- 하지만 문제가 되는 경우가 있다: 무거운 왼쪽 자식 `A`가 다시 자신의 오른쪽 자식 `X`(높이 n+1) 때문에 무거운 경우다. 이때 `B`를 그냥 오른쪽으로 한 번 회전하면 `X`가 `A`의 자식에서 `B`의 자식으로 옮겨가면서, 불균형이 `B`에서 `A` 쪽(반대 방향)으로 옮겨갈 뿐 해결되지 않는다.
- 해결책: 먼저 `A`를 왼쪽으로 한 번 회전해 `X`를 위로 올린 다음, `B`를 오른쪽으로 한 번 회전한다. 이 이중 회전(double rotation)으로 문제가 해결된다.
- `RebalanceRight(N)` 절차
  1. `M`을 `N`의 왼쪽 자식으로 둔다.
  2. `M`의 오른쪽 자식 높이가 `M`의 왼쪽 자식 높이보다 크면, `M`을 왼쪽으로 회전한다.
  3. (위 조건과 무관하게) `N`을 오른쪽으로 회전한다.
  4. 회전으로 위치가 바뀐 노드들의 높이를 다시 계산(adjust)한다.
- 이 과정으로 해당 노드의 AVL property가 복구되고 높이 필드도 올바르게 갱신된다.
- 이렇게 재균형까지 포함한 삽입은 트리의 각 레벨(level)마다 O(1) 작업만 필요하므로, 전체적으로 O(log n) 시간에 삽입을 완료할 수 있다.

### 삭제(Delete)와 재균형
- 기존 Delete에서는 노드 `N`을 후속자(successor)로 대체하고, 후속자의 자식을 승격(promote)시킨다.
- 이 과정에서 후속자가 있던 자리의 높이가 1 줄어드는 효과가 생기며, 원래 균형 잡혀 있던 트리도 이로 인해 불균형해질 수 있다.
- 해결: 기존 방식대로 `N`을 삭제한 뒤, `N`을 대체한 노드(즉, 균형을 깨뜨렸을 수 있는 지점) `M`의 위치에서부터 시작해 삽입 때와 동일한 `Rebalance` 연산을 트리 위쪽으로 실행한다.

## 예시
- 트리에 새 노드를 A, B, C, D 위치 중 하나에 삽입한다고 할 때, D 위치에 삽입하면 여러 조상의 높이가 바뀌어 AVL property가 깨지지만, A·B·C 위치에 삽입하면 문제가 없다.

## 요약
- 삽입은 "일반 삽입 → 삽입된 노드부터 루트까지 Rebalance" 두 단계로 구현한다.
- Rebalance는 왼쪽·오른쪽 자식 높이 차이가 1을 넘는 노드를 찾아 회전(단순 회전 또는 이중 회전)으로 바로잡고, 높이를 갱신하며 부모 쪽으로 재귀한다.
- 이중 회전이 필요한 경우는 무거운 자식의 반대쪽 자식이 더 무거울 때이며, 이때는 두 번 회전해야 문제가 해결된다.
- 삭제도 같은 Rebalance 로직을 재사용해 O(log n) 시간에 AVL property를 복구한다.
- 결과적으로 AVL 트리는 모든 기본 연산을 O(log n) 시간에 지원하는 실질적인 균형 이진 탐색 트리 구현이다.
