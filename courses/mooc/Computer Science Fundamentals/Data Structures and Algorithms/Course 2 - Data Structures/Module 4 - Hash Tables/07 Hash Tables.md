# Hash Tables

## 개요
- 맵(map)에 이어 또 다른 자연스러운 자료구조인 집합(set)을 체이닝(chaining)으로 구현하는 방법을 다룬다.
- 해시 테이블(hash table)이라는 용어의 정의와, 체이닝 방식의 전체 성능 요약(Θ(n+m) 메모리, Θ(c+1) 시간)을 정리한다.

## 내용

### 집합(set) 자료구조
- 집합(set)은 객체를 추가(add)하고, 제거(remove)하고, 특정 객체가 있는지 찾는(find) 메서드를 갖는 자료구조다.
- 예: 캠퍼스에 있는 학생들의 집합(특정 이름의 학생이 캠퍼스에 있는지), 전화번호부의 전화번호 집합(특정 번호가 있는지), 프로그래밍 언어의 키워드(keyword) 집합(입력한 토큰이 키워드인지 식별자인지).

### 맵을 이용한 집합 구현(비효율적인 방식)
- 집합 S는 사실 "S에서 값이 오직 `true` 하나뿐인 집합 V로의 맵"과 동등하다.
- 어떤 객체에 대응하는 값이 `true`이면 그 객체는 집합에 있는 것이고, 대응 값이 없으면 집합에 없는 것이다.
- 이 방식은 (object, true) 쌍을 저장해야 하므로 다소 번거롭고 낭비가 있다.

### 체이닝을 이용한 집합의 직접 구현
- 각 체인에 (object, value) 쌍 대신 object만 저장하면 된다.
- `chains`는 카디널리티만큼의 크기를 가진 배열이고, 각 원소는 object들의 이중 연결 리스트(체인)다.
- **Find(object)**: `hash(object)`로 체인을 찾고, 체인 안의 모든 key를 순회해 object와 같은 것이 있으면 `true`, 없으면(다른 체인에는 있을 수 없으므로) `false`를 반환한다.
- **Add(object)**: 먼저 해당 체인을 순회해 object가 이미 있는지 확인한다. 이미 있으면 아무 것도 하지 않고 반환한다(집합에 이미 있는 객체를 다시 추가하는 것은 아무 일도 하지 않는 것과 같다). 없으면 체인 끝에 object를 추가한다.
- **Remove(object)**: 먼저 object가 집합에 있는지 확인한다. 없으면 그냥 반환한다. 있으면 해당 체인에서 그 object를 이중 연결 리스트의 삭제 연산으로 제거한다. (`Find`가 `true`를 반환했다면 반드시 해당 체인에 있으므로 안전하게 지울 수 있다.)

### 해시 테이블(hash table)의 정의
- 해시 테이블은 해싱(hashing)을 이용해 집합(set) 또는 맵(map)을 구현한 것을 통칭한다. 체이닝뿐 아니라 direct addressing 등 다른 해싱 기반 기법으로 구현한 것도 모두 해시 테이블이라 부른다.
- 각 언어의 대표적인 해시 테이블 구현:
  - 집합: C++의 `unordered_set`, Java의 `HashSet`, Python의 `set`.
  - 맵: C++의 `unordered_map`, Java의 `HashMap`, Python의 `dict`.
- 이들은 모두 해싱에 기반하므로, 체이닝 등에서 논의한 것과 동일한 시간 복잡도·메모리 사용량 특성을 갖는다.

### 종합 정리
- 체이닝 기법의 파라미터: n(객체 수), m(해시 함수 카디널리티), c(해시 테이블 안 가장 긴 체인의 길이).
- 메모리 사용량: Θ(n + m).
- 연산 시간: Θ(c + 1).
- Θ(n)은 저장할 객체 자체를 위해 반드시 필요한 비용이므로 피할 수 없다. 반면 추가되는 Θ(m)은 오버헤드(overhead)이므로 최소화하고 싶다.
- 마찬가지로 연산이 거의 상수 시간(constant time)에 가깝게 동작하려면 Θ(c)라는 오버헤드도 최소화해야 한다.
- 즉 목표는 m과 c를 모두 가능한 한 작게 만드는 것이며, 이를 달성하는 방법은 다음 강의에서 다룬다.

## 요약
- 집합(set)은 (object, true) 형태의 맵으로도 구현할 수 있지만, 체인에 object만 저장하는 방식이 더 직접적이다.
- 해시 테이블(hash table): 해싱을 기반으로 구현된 집합/맵 자료구조를 통칭하는 이름(C++ unordered_set/map, Java HashSet/HashMap, Python set/dict 등).
- 체이닝의 성능: 메모리 Θ(n+m), 연산 시간 Θ(c+1). n에 대한 비용은 필수지만 m, c는 최소화해야 할 오버헤드다.
