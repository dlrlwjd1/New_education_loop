# Hashing Phone Numbers

## 개요
- 앞선 강의에서 정의한 보편적 해시 함수족(universal family)의 구체적인 예시를 정수 집합에 대해 제시한다.
- 이를 이용해 전화번호부 문제의 "전화번호 → 이름" 맵을 효율적으로 구현하는 방법을 완성한다.

## 내용

### 정수에 대한 보편적 해시 함수족
- 앞서 어떤 유한한 정수 집합에 대해서도 보편적 해시 함수족이 존재함을 보인다.
- 전화번호는 이미 정수로 변환할 수 있고, 변환 결과는 항상 10^15보다 작은 정수가 된다. 따라서 10^15까지의 정수에 대한 보편적 해시 함수족만 만들면 전화번호부 문제를 체이닝(chaining)으로 풀 수 있다.
- **정리(Lemma)**: 임의의 소수(prime number) p에 대해, 다음과 같이 정의되는 해시 함수 집합 H_p는 정수 0 ~ p−1에 대한 보편적 해시 함수족이다.
  - 두 파라미터 a(1 ≤ a ≤ p−1인 정수), b(0 ≤ b ≤ p−1인 정수)로 하나의 해시 함수가 정해진다.
  - 해시 함수: h(x) = ((a·x + b) mod p) mod m, 여기서 m은 해시 테이블의 카디널리티다.
- 이 함수는 선형 함수(ax+b)에 mod p, mod m을 적용하는 것뿐이므로 상수 시간(constant number of operations)에 계산할 수 있어 매우 빠르다.

### 구체적인 예시
- 최대 7자리인 지역 전화번호(1000만 미만)를 다룬다고 가정한다.
- 소수 p로 10,000,019(천만+19)를 선택한다. p는 다룰 전화번호의 최댓값보다 커야 하므로 1000만보다 약간 큰 소수를 골랐다.
- 파라미터를 a = 34, b = 2로 선택한다.
- 카디널리티(해시 테이블 크기)는 m = 1000으로 선택한다.
- 예시 키: 전화번호 1,482,567에 대응하는 정수 x = 1482567.
  - a·x + b를 계산한 뒤 mod p(=10,000,019)를 적용하면 결과는 407,185.
  - 여기에 다시 mod m(=1000)을 적용하면 마지막 세 자리인 185가 남는다.
  - 따라서 h(1482567) = 185.

### 보편성 증명의 개요
- 서로 다른 두 키 x, y와 H_p 안의 임의의 해시 함수(파라미터 a, b로 결정됨)를 생각한다.
- H_p에는 총 p·(p−1)개의 서로 다른 해시 함수가 있다(b는 p가지, a는 p−1가지이며 서로 독립적으로 선택되므로).
- x, y를 (ax+b) mod p, (ay+b) mod p로 보내면, a, b의 선택에 따라 이 두 값(서로 다른 나머지 쌍)은 p·(p−1)가지의 서로 다른 (나머지, 나머지) 쌍에 골고루, 같은 확률로 대응된다(첫 번째 나머지는 0~p−1 중 아무 값이나 가능하고, 두 번째 나머지는 첫 번째와 달라야 하므로 p−1가지).
- 즉 고정된 키 쌍 (x, y)는 H_p의 모든 함수에 의해 "서로 다른 나머지 쌍(mod p)" 전체에 걸쳐 균등하게 매핑된다.
- x, y가 충돌하는 경우는 이 서로 다른 나머지 쌍들 중 mod m을 취했을 때 같아지는 쌍들에 해당하며, 그러한 쌍의 비율이 1/m 미만임을 보일 수 있다.
- 이로써 H_p가 보편적 해시 함수족임이 (개략적으로) 증명된다.

### 전화번호부 문제 적용 절차
1. 전화번호의 최대 자릿수 L을 정한다(L = 15).
2. 모든 전화번호를 0 ~ 10^L − 1 범위의 정수로 자릿수 단위로 변환한다.
3. 10^L보다 큰 소수 p를 아무거나 선택한다(그러한 소수는 항상 존재한다).
4. 해시 테이블 크기(=카디널리티) m을 정한다.
5. 보편적 해시 함수족 H_p에서 무작위로 해시 함수를 고른다. 즉, a(1 ~ p−1)와 b(0 ~ p−1)를 각각 균등하게 무작위로 선택한다. 이 함수는 h(x) = ((a·x+b) mod p) mod m이다.
6. 이렇게 정해진 해시 함수와 테이블 크기로 체이닝(chaining)을 사용해 전화번호 → 이름 맵을 구현한다.
- H_p가 보편적 해시 함수족이므로, 연산은 빠르게 동작하고 메모리 사용량도 저장할 연락처 수에 선형(linear)으로 비례하는 좋은 성능을 얻는다.

## 예시
- p = 10,000,019, a = 34, b = 2, m = 1000, x = 1,482,567.
- h(x) = ((34 × 1,482,567 + 2) mod 10,000,019) mod 1000
  - (34x + 2) mod p = 407,185
  - 407,185 mod 1000 = 185
  - 따라서 h(1482567) = 185.

## 요약
- 임의의 소수 p에 대해 H_p = { h_{a,b}(x) = ((a·x+b) mod p) mod m : 1 ≤ a ≤ p−1, 0 ≤ b ≤ p−1 }는 0 ~ p−1 정수에 대한 보편적 해시 함수족이다.
- 이 함수는 선형 연산과 mod 연산만으로 이루어져 있어 계산이 매우 빠르다.
- 전화번호처럼 10^15 미만인 정수 키에 대해서는, 이보다 큰 소수 p를 골라 H_p에서 (a, b)를 무작위로 선택하는 방식으로 실용적인 해시 함수를 얻을 수 있다.
- 다음 강의에서는 반대 방향, 즉 "이름 → 전화번호" 맵을 구현하는 문제(문자열 해싱)를 다룬다.
