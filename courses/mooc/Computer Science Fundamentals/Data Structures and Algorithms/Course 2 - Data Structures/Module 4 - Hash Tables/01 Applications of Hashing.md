# Applications of Hashing

## 개요
- 해싱(hashing)은 가장 빠른 알고리즘들에서 널리 쓰이는 강력한 기법이며, 서로 매우 다른 방식으로 활용된다.
- 이 강의는 본격적인 해싱 학습에 앞서, 해싱이 실제로 어디에 쓰이는지를 개괄적으로 소개한다.

## 내용

### 블록체인(Blockchain)
- 비트코인(Bitcoin) 등 암호화폐(cryptocurrency)에 대한 관심으로 블록체인 자체에 대한 관심도 커지고 있다.
- 이 모듈 마지막에는 블록체인이 무엇에 기반하고 있으며 어떻게 동작하는지를 다룬다.

### 프로그래밍 언어(Programming Languages)
- 파이썬(Python)의 내장 자료구조인 `dict`는 해싱에 기반한다.
- 자바(Java) 컬렉션의 hash map, hash set도 마찬가지다.
- 프로그래밍 언어 구현(파서, 컴파일러, 인터프리터) 측면에서도, `for`, `if`, `while` 같은 키워드(keyword)를 프로그램에서 빠르게 찾아내고, 이것이 변수/함수 이름이 아니라 실제 키워드임을 판별하는 데 해싱이 사용된다.

### 파일 시스템(File Systems)
- 사람이 읽을 수 있는 파일 경로(path)를 디스크상의 실제 물리적 위치로 매핑(mapping)하는 데 해싱이 사용된다.

### 전자 서명(Digital Signature)
- 전자 문서가 실제 종이 문서(수표 등)를 대체하려면 다음 요건을 만족해야 한다.
  1. 다른 사람이 내 이름으로 서명하기 매우 어려워야 한다.
  2. 나중에 "내가 쓴 것이 아니다"라고 부인할 수 없어야 한다.
  3. 문서 내용(예: 지불 금액)을 위조하기 매우 어려워야 한다.
- 전자 서명은 이 세 가지 요건을 모두 해결하는 기법이며, 해싱에 기반한다.

## 요약
- 해싱의 대표적 응용 분야: 블록체인, 프로그래밍 언어(자료구조·키워드 판별), 파일 시스템, 전자 서명.
- 이후 강의에서 해싱의 원리와 이를 활용한 알고리즘·자료구조를 다루고, 선택적으로 블록체인 동작 원리도 다룬다.
