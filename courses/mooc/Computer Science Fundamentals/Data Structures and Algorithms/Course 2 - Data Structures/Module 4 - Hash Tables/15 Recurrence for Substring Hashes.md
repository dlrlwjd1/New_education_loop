# Recurrence for Substring Hashes

## 개요
- 같은 텍스트 안에서 연속한 두 부분 문자열의 다항식 해시(polynomial hash) 값 사이에 성립하는 점화식(recurrence)을 유도한다.
- 이 점화식을 이용하면 한 부분 문자열의 해시를 알 때 바로 다음(또는 이전) 부분 문자열의 해시를 상수 시간에 계산할 수 있어, Rabin-Karp's 알고리즘을 크게 최적화할 수 있는 토대가 된다.

## 내용

### 표기법
- 텍스트 T에서 위치 i부터 시작하고 길이가 패턴 P와 같은 부분 문자열의 해시 값을 H(i)로 표기한다.

### 구체적인 예시로 관찰하기
- 텍스트 T = "beach"를 a→0, b→1, c→2, ..., z→25로 인코딩하면 각 문자의 코드는 1, 4, 0, 2, 7이다.
- 패턴 길이를 3이라 하면, 확인할 부분 문자열은 "bea", "eac", "ach"다.
- "ach"(코드 0, 2, 7)의 해시: H(2) = 0 + 2x + 7x² (mod p, 이하 mod p는 생략).
- "eac"(코드 4, 0, 2)의 해시: H(1) = 4 + 0·x + 2x².
- 관찰: H(1)의 뒤 두 항(0x + 2x²)은 H(2)의 앞 두 항(0 + 2x)에 x를 곱한 것과 같다.
- 이는 우연이 아니라 다항식 해시 함수의 일반적인 성질이다.

### 점화식 유도
- H(2) = 0 + 2x + 7x²
- H(1) = 4 + 0·x + 2x² = 4 + x·(0 + 2x) = 4 + x·(H(2) − 7x²) = 4 + x·H(2) − 7x³
- 정리하면: H(1) = x·H(2) + 4 − 7x³
  - 즉, "다음 해시(H(2))에 x를 곱하고, 새로 앞에 붙는 문자의 항(4)을 더하고, 뒤로 빠지는 문자의 항(7x³)을 빼는" 형태다.

### 일반적인 점화식
- H(i+1)은 위치 i+1부터 시작하는 부분 문자열의 해시이며, 합의 형태로 쓰면 j = i+1부터 i+|P|까지에 대해 Σ T[j]·x^(j−i−1)이다(첫 항의 지수가 0이 되도록).
- H(i)는 위치 i부터 시작하는 부분 문자열의 해시로, j = i부터 i+|P|−1까지에 대해 Σ T[j]·x^(j−i)이다.
- H(i)의 합의 인덱스 범위를 H(i+1)과 맞추기 위해 조정하면(j를 i+1부터 i+|P|까지로), 원래 H(i)에서 빠졌던 항(j=i일 때의 T[i]·x⁰ = T[i])을 더하고, 새로 추가된 항(j = i+|P|일 때의 T[i+|P|]·x^(i+|P|−i) = T[i+|P|]·x^|P|)을 빼줘야 등식이 성립한다.
- 이렇게 정리한 식에서 공통되는 합 부분을 x로 묶어 지수를 하나씩 낮추면, 그 괄호 안의 식이 정확히 H(i+1)과 같아진다.
- 결과적으로 다음과 같은 점화식을 얻는다.
  - **H(i) = x·H(i+1) + T[i] − T[i+|P|]·x^|P| (mod p)**

### 점화식의 의미
- x^|P| (mod p)는 Rabin-Karp's 알고리즘 시작 시 딱 한 번만 계산해서 저장해 두면 된다.
- 이 값을 알고 있으면, H(i+1)로부터 H(i)를 계산하는 데는 곱셈 한 번, 덧셈 한 번, 뺄셈 한 번(모두 mod p 연산)만 필요하므로 **상수 시간 O(1)** 이다.
- 이 점화식을 이용하면 텍스트 T의 모든 부분 문자열(길이 |P|)의 해시 값을 처음부터 다시 계산하지 않고도 순차적으로 빠르게 구할 수 있으며, 이것이 다음 강의에서 다룰 Rabin-Karp's 알고리즘 최적화의 핵심이 된다.

## 예시
- T = "beach" (코드: b=1, e=4, a=0, c=2, h=7), |P| = 3.
- H(2)("ach") = 0 + 2x + 7x².
- H(1)("eac") = 4 + x·H(2) − 7x³ = x·H(2) + T[1] − T[1+3]·x³ (여기서 T[1]=4, T[4]=7).
- 일반식: H(i) = x·H(i+1) + T[i] − T[i+|P|]·x^|P| (mod p).

## 요약
- 텍스트의 연속된 두 부분 문자열(길이 |P|)의 다항식 해시 사이에는 점화식 H(i) = x·H(i+1) + T[i] − T[i+|P|]·x^|P| (mod p)가 성립한다.
- x^|P| (mod p)를 미리 한 번 계산해 두면, 이 점화식으로 H(i+1)에서 H(i)를 O(1)에 구할 수 있다.
- 다음 강의에서 이 점화식을 이용해 텍스트의 모든 부분 문자열 해시를 미리 계산(precomputation)함으로써 Rabin-Karp's 알고리즘의 실행 시간을 크게 개선한다.
