# Hashing Names

## 개요
- 앞선 강의들에서 "전화번호 → 이름" 맵을 완성했으니, 이번에는 반대 방향인 "이름 → 전화번호" 맵을 체이닝(chaining)으로 구현하기 위해 문자열(string)용 해시 함수를 만든다.
- 임의의 길이 제한이 있는 문자열을 해싱하는 다항식 해시 함수족(polynomial hash family)을 소개하고, 이것이 실제로 Java의 `String.hashCode()`가 구현된 방식과 매우 비슷함을 보인다.

## 내용

### 표기법
- 문자열 S의 길이는 |S|로 표기한다. 예: |edx| = 3, |ucsd| = 4, |chaining| = 8.
- S는 문자들의 배열로 볼 수 있으며, S[0], S[1], ..., S[|S|−1]이 각 개별 문자다.

### 왜 모든 문자를 사용해야 하는가
- 전화번호는 정수로 바로 변환할 수 있었지만, 문자열은 정수로 변환하는 자명한 방법이 없다.
- 해시 함수가 문자열의 일부 문자(예: 첫 글자)를 사용하지 않으면, 그 위치만 다른 문자열들(aa, ba, ..., za 등)이 전부 같은 해시 값을 갖게 되어 충돌(collision)이 대량으로 발생한다.
- 따라서 해시 함수는 문자열의 모든 문자를 사용해야 한다.

### 다항식 해시 함수족(polynomial family)
- 먼저 각 문자를 ASCII나 유니코드(Unicode) 같은 기존 인코딩을 이용해 정수로 변환한다.
- 큰 소수(prime number) p를 고르고, 결과를 이 p로 나눈 나머지(mod p)를 해시 값으로 삼는다.
- 다항식 해시 함수족 P는 파라미터 x(1 ≤ x ≤ p−1인 정수, mod p의 나머지)로 매개변수화된 해시 함수들의 집합이다.
- 문자열 S에 대한 해시 값은 다음 다항식을 p로 나눈 나머지로 계산한다.
  - hash(S) = (S[0] + S[1]·x + S[2]·x² + ... + S[|S|−1]·x^(|S|−1)) mod p

### PolyHash 계산 코드
- `PolyHash(S, p, x)`는 문자열 S, 소수 p, 정수 x를 입력받아 다항식 해시 함수족의 해시 값을 반환한다.
- 절차:
  1. hash ← 0으로 초기화한다.
  2. 인덱스 i를 |S|−1부터 0까지 거꾸로 순회한다.
  3. 매 단계마다 hash ← (hash × x + S[i]) mod p 로 갱신한다.
  4. 루프가 끝나면 hash를 반환한다.
- 문자열을 뒤에서부터 순회하며 매번 x를 곱하고 현재 문자를 더하는 방식(호너의 법칙과 유사한 누적 계산)으로, 최종적으로 앞서 소개한 다항식 값과 같은 결과를 얻는다.

### Java의 String.hashCode()와의 관계
- Java의 `String` 클래스에 내장된 `hashCode()` 메서드는 PolyHash와 매우 비슷하다.
- 다만 x를 항상 상수 31로 고정해서 쓰고, 기술적인 이유로 mod p 연산을 생략한다는 점만 다르다.
- 이 함수는 문자열과 해시 테이블이 워낙 널리 쓰이기 때문에 하루에 수조 번씩 실행되는 함수다.
- 다항식 해시 함수족이 문자열에 대해 왜 좋은 성질을 갖는지, 그리고 왜 Java가 이 방식을 채택했는지는 다음 강의에서 분석한다.

## 예시
- 길이가 3인 문자열 S에 대해 PolyHash를 손으로 계산해 보면 다음과 같이 전개된다.
  1. hash = 0에서 시작.
  2. i = 2(S[2]): hash = (0 × x + S[2]) mod p = S[2] mod p.
  3. i = 1(S[1]): hash = (S[2] × x + S[1]) mod p = (S[1] + S[2]·x) mod p.
  4. i = 0(S[0]): hash = ((S[1] + S[2]·x) × x + S[0]) mod p = (S[0] + S[1]·x + S[2]·x²) mod p.
- 길이가 4라면 마지막에 S[3]·x³ 항이 추가되는 식으로 일반화된다.

## 요약
- 문자열 해싱은 각 문자를 정수 인코딩으로 바꾼 뒤, 큰 소수 p와 파라미터 x로 정의되는 다항식 hash(S) = Σ S[i]·x^i mod p로 계산한다.
- `PolyHash` 알고리즘은 문자열을 뒤에서부터 순회하며 hash = hash·x + S[i] (mod p)를 반복해 O(|S|) 시간에 계산한다.
- 이 함수족은 반드시 문자열의 모든 문자를 사용해야 충돌을 피할 수 있다.
- Java의 `String.hashCode()`는 x = 31로 고정한 PolyHash의 변형이다.
- 다음 강의에서는 이 다항식 해시 함수족이 왜 좋은 해시 함수족인지 수학적으로 분석한다.
