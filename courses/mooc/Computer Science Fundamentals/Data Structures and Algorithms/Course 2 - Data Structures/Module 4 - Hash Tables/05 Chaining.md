# Chaining

## 개요
- 해시 함수에서 발생하는 충돌(collision)을 우회하면서 전화번호부(phone book) 문제를 해결하는 체이닝(chaining) 기법을 소개한다.
- 먼저 맵(map)이라는 자료구조를 정의하고, 이를 체이닝으로 구현하는 방법을 설명한다.

## 내용

### 맵(map)의 정의
- 한 종류의 객체를 다른 종류의 객체로 매핑해야 하는 경우가 많다. 예: 파일명 → 디스크상의 물리적 위치, 전화번호 → 이름(전화번호부), 이름 → 전화번호(스마트폰에서 이름으로 전화 걸기).
- 집합 S에서 집합 V로의 맵(map)은 다음 메서드를 갖는 자료구조다.
  - `HasKey`: 해당 객체에 대응하는 값이 맵에 있는지 여부를 반환.
  - `Get`: 해당 객체에 대응하는 값을 반환.
  - `Set`: 객체와 값 두 인자를 받아 해당 객체에 대응하는 값을 설정.
- 맵 S → V에서 S의 원소를 키(key), V의 원소를 값(value)이라 부른다.
- 전화번호부 문제는 "전화번호 → 이름" 맵을 구현하는 문제다.

### 체이닝(chaining)의 아이디어
- 카디널리티(cardinality) 8인 해시 함수(전화번호를 0~7로 매핑)를 사용한다고 가정한다.
- 크기 8인 배열을 만들어 각 셀(인덱스 0~7)을 사용해 연락처를 저장한다.
- 해시 값이 같은 두 번째 연락처가 들어오면(충돌), 기존 항목을 지우지 않고 같은 셀에 함께 저장해야 한다.
- 해결책: 배열의 각 셀을 이중 연결 리스트(doubly linked list)로 만들어, 같은 해시 값을 가진 여러 연락처(이름, 전화번호 쌍)를 그 리스트에 추가한다.
- 이 배열을 `chains`라 하고, 각 셀에 담긴 이중 연결 리스트를 체인(chain)이라 부른다. 이 기법의 이름이 여기서 유래한다.

### 체이닝을 이용한 연산
- **추가**: 전화번호의 해시 값을 계산해 해당 체인을 찾고, (이름, 전화번호) 쌍을 리스트 끝에 추가한다.
- **변경**: 전화번호의 해시 값으로 체인을 찾아, 리스트를 순회하며 해당 전화번호를 가진 항목을 찾아 이름을 바꾼다.
- **삭제**: 전화번호의 해시 값으로 체인을 찾아, 리스트에서 해당 전화번호가 있는 항목 하나만 제거한다.
- 일반화: 카디널리티 m인 해시 함수를 고르고, 크기 m인 배열 `chains`를 만든다. 각 원소는 (이름, 전화번호) 쌍의 이중 연결 리스트다. 실제로는 전화번호를 먼저 표준적인 방법으로 정수로 변환한 뒤, 그 정수에 해시 함수를 적용해 인덱스를 구하는 경우가 많다.

## 요약
- 맵(map)은 `HasKey`, `Get`, `Set`을 제공하는, 키에서 값으로의 매핑 자료구조다.
- 체이닝(chaining): 카디널리티 m인 해시 함수와 크기 m인 배열 `chains`를 사용하고, 각 셀을 이중 연결 리스트(체인)로 두어 같은 해시 값을 가진 여러 항목을 충돌 없이 함께 저장하는 기법.
- 다음 강의에서 체이닝을 의사코드로 구현하고, 시간 복잡도와 메모리 사용량을 분석한다.
