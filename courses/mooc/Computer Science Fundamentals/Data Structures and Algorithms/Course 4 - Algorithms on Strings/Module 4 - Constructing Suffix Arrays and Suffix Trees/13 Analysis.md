# Analysis

## 개요
- LCP 배열(LCP array) 계산 구현이 선형 시간(linear time)에 동작함을 증명한다.
- 증명은 Morris-Pratt 알고리즘에서 접두사 함수(prefix function)가 선형 시간에 동작함을 증명하는 방식과 매우 유사하다.
- 핵심은 변수 LCP의 증가·감소 총량을 추적하는 상환 분석(amortized analysis)이다.

## 내용

### 변수 LCP의 거동 관찰
- LCPOfSuffixes 함수 안의 각 문자 비교는 LCP를 1씩 증가시킨다.
- 계산의 어느 시점에서도 LCP 값은 문자열 길이 |S|를 넘지 못한다. LCP는 어떤 두 접미사의 최장 공통 접두사이고, 모든 접미사는 원래 문자열보다 길 수 없기 때문이다.
- 외부 for 루프의 각 반복마다 LCP 값은 최대 1만큼만 감소한다. 다음 접미사 쌍의 LCP가 최소 (현재 LCP - 1)이기 때문이다.

### 비교 횟수의 상한
- 각 비교는 LCP를 증가시키고, 각 반복은 LCP를 최대 1 감소시킨다.
- 0에서 시작하므로 최대 |S|번의 반복이 LCP를 최대 |S| 감소시킬 수 있고, LCP는 최대 |S|까지 오를 수 있다.
- 따라서 전체 비교 횟수는 2·|S|를 넘을 수 없다.

### 나머지 연산
- 비교 외의 나머지 작업은 모두 선형 시간이다.
  - InvertSuffixArray 함수 호출: 선형 시간.
  - 외부 for 루프 내부의 상수 시간 연산들: 반복 횟수 |S|만큼.
- 결과적으로 전체 알고리즘은 선형 시간에 동작한다.

## 요약
- 각 문자 비교는 LCP를 +1, 각 루프 반복은 LCP를 최대 -1 변화시킨다.
- LCP는 |S|를 넘지 않으므로 총 비교 횟수는 최대 2·|S|다.
- 나머지 연산(역배열 계산, 상수 연산)도 모두 선형이다.
- 따라서 LCP 배열 계산은 선형 시간 알고리즘이다.
