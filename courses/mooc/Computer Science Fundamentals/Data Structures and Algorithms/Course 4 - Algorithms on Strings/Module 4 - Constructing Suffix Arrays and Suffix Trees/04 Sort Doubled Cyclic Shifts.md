# Sort Doubled Cyclic Shifts

## 개요
- 길이 L의 부분 순환 이동이 이미 정렬되어 있고 클래스 번호를 알 때, 길이 2L의 부분 순환 이동(doubled partial cyclic shifts)을 빠르게 정렬하는 방법을 배운다.
- 핵심: 길이 2L 이동을 (길이 L, 길이 L) 쌍(pair)으로 보고 기수 정렬(radix sort) 방식으로 정렬한다.

## 내용

### 길이 2L 이동을 두 반쪽의 연결로 표현
- `C_i`가 위치 i에서 시작하는 길이 L 순환 이동, `C_i'`가 위치 i에서 시작하는 길이 2L 이동이면:
  - `C_i' = C_i + C_{i+L}` (두 길이 L 부분 순환 이동의 연결(concatenation)).
- 두 길이 2L 이동 `C_i'`와 `C_j'`의 비교:
  1. 먼저 첫 반쪽 `C_i`와 `C_j`를 비교. 다르면 작은 쪽이 전체적으로 작다.
  2. 같으면 둘째 반쪽 `C_{i+L}`과 `C_{j+L}`을 비교. 같으면 전체도 같고, 다르면 작은 쪽이 작다.
- 이 비교에는 오직 (a) 길이 L 이동의 순서와 (b) 동치 클래스(같은지 여부) 두 정보만 사용한다. 두 정보 모두 이미 가지고 있다.

### 정렬 방법 — 기수 정렬 (radix sort)
- 쌍(pair)을 정렬하려면:
  1. 먼저 쌍의 **둘째 원소**(second half)로 정렬한다.
  2. 그 다음 쌍의 **첫째 원소**(first half)로 **안정 정렬(stable sort)** 한다.
- 안정 정렬이므로 첫 반쪽이 같은 경우 둘째 반쪽의 (이미 올바른) 상대 순서가 유지된다.

### 둘째 반쪽 순서를 공짜로 얻기
- 길이 L 이동들이 이미 `C_{order[0]}, C_{order[1]}, ...` 순으로 정렬되어 있다.
- 이들을 **둘째 반쪽**으로 삼는다. 그러면 대응하는 길이 2L 이동의 **시작 위치**는 그 둘째 반쪽 위치에서 L만큼 반시계 방향(counterclockwise)으로 이동한 곳, 즉 `order[k] - L`이다.
  - 순환 문자열이므로 `(order[k] - L) mod len(S)`로 계산한다.
- 이렇게 하면 둘째 반쪽 기준으로 이미 정렬된 길이 2L 이동 목록을 얻는다.
- 이제 **첫째 반쪽** 기준으로 안정 정렬만 하면 된다. 계수 정렬(counting sort)은 안정 정렬이고, 클래스 번호(0 ~ 최대 클래스 번호, 개수 ≤ 문자열 길이)를 알므로 계수 정렬로 첫째 반쪽을 재정렬할 수 있다.

## 예시

`S = ababaa$`, 현재 L = 2. 위치 i = 2:
- `C_i = C_2 = ab`
- `C_{i+L} = C_4 = aa`
- `C_i' = C_2' = abaa` (길이 4) = `C_2 + C_4`의 연결.

이미 정렬된 길이 2 이동(둘째 반쪽으로 사용)과 그에 대응하는 길이 4 이동(둘째 반쪽 기준 정렬됨):

| 둘째 반쪽 (길이 2, 정렬됨) | 대응 길이 4 이동 |
|---------------------------|------------------|
| `$a` | `aa$a` |
| `a$` | `baa$` |
| `aa` | `abaa` |
| `ab` | `a$ab` |
| `ab` | `abab` |
| `ba` | `baba` |
| `ba` | `$aba` |

- 첫째 반쪽으로 안정 정렬 시, 첫 반쪽이 같은 `C_2'`와 `C_0'`(첫 반쪽 `ab`)는 상대 순서를 유지해야 하고, `C_3'`와 `C_1'`도 마찬가지다. 안정 정렬이 이를 보장한다.
- 결과로 길이 4 이동의 올바른 사전식 정렬 순서를 얻는다.

## 요약
- 길이 2L 이동 = (첫 반쪽 길이 L, 둘째 반쪽 길이 L) 쌍.
- 쌍 비교는 순서 정보와 동치 클래스 정보만으로 가능.
- 이미 정렬된 길이 L 순서를 둘째 반쪽으로 삼으면 대응 시작 위치는 `(order[k] - L) mod len(S)`이며, 이는 둘째 반쪽 기준 정렬 상태다.
- 그 뒤 첫째 반쪽 기준으로 계수 정렬(안정 정렬)만 하면 길이 2L 이동이 정렬된다.
