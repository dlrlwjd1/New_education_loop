# Initialization

## 개요
- 접미사 배열 구성 전략의 초기화(initialization) 단계를 다룬다.
- 두 가지를 수행한다.
  1. 초기 문자열의 단일 문자들을 정렬(길이 1의 부분 순환 이동으로 간주).
  2. 같은 길이의 부분 순환 이동에 대한 동치 클래스(equivalence classes)를 도입하고, 길이 1에 대해 계산.

## 내용

### 단일 문자 정렬 — 계수 정렬 (SortCharacters, counting sort)
- 알파벳 크기만큼의 문자 종류만 있으므로 계수 정렬(counting sort)을 사용한다.
- 절차:
  1. 결과를 저장할 `order` 배열(크기 = 문자열 길이)과 계수 정렬용 보조 배열 `count`(0으로 초기화)를 준비한다.
  2. 각 문자가 문자열에 나타나는 횟수를 센다(각 문자는 0 ~ 알파벳크기-1의 인덱스를 가짐).
  3. 같은 배열에 j번째 문자까지의 누적 개수를 저장한다.
  4. 가장 큰 문자부터 가장 작은 문자로 내려가며 각 문자가 나타나는 위치를 저장해 정렬 순서를 만든다.
  5. `order` 배열을 반환한다.
- **Lemma**: SortCharacters의 실행 시간은 문자열 길이 S와 알파벳 크기의 합에 비례한다. (N개 객체가 M가지 값을 가질 때 계수 정렬은 N + M에 비례.)

### 동치 클래스 (equivalence classes)
- 길이 L, 위치 i에서 시작하는 부분 순환 이동을 `C_i`로 표기한다.
- 두 부분 순환 이동 `C_i`와 `C_j`가 같으면 같은 동치 클래스에 속한다.
- **클래스 번호(class number)** 정의: `class[i]` = 위치 i에서 시작하는 부분 순환 이동 `C_i`보다 **엄격히 작은(strictly smaller)** 서로 다른 길이 L 부분 순환 이동의 개수.
- 핵심 성질: 두 부분 순환 이동이 같을 필요충분조건은 클래스 번호가 같은 것이다.
  - 같으면 각각보다 작은 것의 개수가 같으므로 클래스 번호가 같다.
  - 클래스 번호가 같으면, 만약 하나가 다른 것보다 작다면 작은 쪽이 큰 쪽의 카운트에 포함되어 클래스 번호가 달라졌을 것이므로 모순 → 둘은 같다.
- 이 클래스 번호로 두 부분 순환 이동이 같은지 **상수 시간**에 판별할 수 있다.

## 예시

`S = ababaa$`, 정렬된 단일 문자 순서 `order = 6, 0, 2, 4, 5, 1, 3`.

`class` 배열 채우기(가장 작은 부분 순환 이동부터):

| 순서상 부분 순환 이동 | 위치 | 이전과 비교 | class 값 |
|-----------------------|------|-------------|----------|
| `$` | 6 | (가장 작음) | 0 |
| `a` | 0 | 이전과 다름 (+1) | 1 |
| `a` | 2 | 이전과 같음 | 1 |
| `a` | 4 | 이전과 같음 | 1 |
| `a` | 5 | 이전과 같음 | 1 |
| `b` | 1 | 이전과 다름 (+1) | 2 |
| `b` | 3 | 이전과 같음 | 2 |

결과 `class`: 위치별로 `class[6]=0, class[0]=1, class[2]=1, class[4]=1, class[5]=1, class[1]=2, class[3]=2`.

### ComputeCharClasses 의사코드

```
ComputeCharClasses(S, order):
    class = new array of size len(S)
    class[order[0]] = 0          # 가장 작은 부분 순환 이동
    for i from 1 to len(S) - 1:
        if S[order[i]] != S[order[i-1]]:
            class[order[i]] = class[order[i-1]] + 1
        else:
            class[order[i]] = class[order[i-1]]
    return class
```

- **Lemma**: ComputeCharClasses의 실행 시간은 선형(linear)이다. for 루프가 len(S)번 돌고 내부는 상수 시간이기 때문이다.

## 요약
- SortCharacters: 계수 정렬로 단일 문자를 정렬, 시간 O(S + 알파벳 크기).
- 클래스 번호 = 해당 부분 순환 이동보다 엄격히 작은 서로 다른 부분 순환 이동의 개수.
- 두 부분 순환 이동이 같을 필요충분조건은 클래스 번호가 같은 것 → 상수 시간 판별 가능.
- ComputeCharClasses: 정렬된 순서를 훑으며 이전과 다르면 +1, 같으면 유지. 선형 시간.
