# General Construction Strategy

## 개요
- 접미사 배열을 효율적으로 구성하는 핵심 아이디어와 전체 전략(general construction strategy)을 배운다.
- 핵심 아이디어: 접미사 대신 **순환 이동(cyclic shift)** 을 정렬하고, 길이를 1 → 2 → 4 → ... 로 두 배씩 늘려가며(doubling) 정렬한다.

## 내용

### 아이디어 1 — 접미사 대신 순환 이동을 정렬
- 문자열을 원(circle) 위에 그린다. 예: `ababaa$`.
- 순환 이동(cyclic shift): 원 위의 어떤 문자에서 시작해 원 전체를 한 바퀴 도는 문자열.
  - 첫 번째 순환 이동은 문자열 자체 `ababaa$`.
  - 다음은 `babaa$a`, 그 다음 `abaa$ab`, ...
- 순환 이동의 개수는 문자열의 문자 개수와 같다(시작 문자가 순환 이동을 유일하게 결정).

### 핵심 Lemma (접미사 정렬 ≡ 순환 이동 정렬)
- 끝에 모든 문자보다 작은 특수 문자 `$`를 붙인 뒤 순환 이동들을 정렬하면:
- 정렬된 순환 이동들의 시작 위치 순서는 정렬된 접미사들의 시작 위치 순서(= 접미사 배열)와 **동일**하다.
- 이유: 정렬된 순환 이동에서 첫 `$` 오른쪽 부분을 잘라내면 그것이 바로 그 접미사이며, 이 순서가 접미사 배열과 같다.

### 아이디어 2 — 부분 순환 이동과 길이 두 배 늘리기 (doubling)
- 부분 순환 이동(partial cyclic shift): 순환 문자열 S의 부분 문자열. 원 위에서 시작해 원의 **일부**만 도는 문자열.
- 길이 4인 부분 순환 이동 예: 원 밖으로 나가면 원래 문자열의 부분 문자열이 아니라 순환 문자열의 부분 문자열이 되지만, 여전히 부분 순환 이동으로 취급한다.
- 길이 1의 부분 순환 이동은 각각의 단일 문자다.
- **전략**:
  1. 먼저 단일 문자(길이 1 부분 순환 이동)를 정렬한다. 문자 종류가 알파벳 크기로 한정되어 상대적으로 쉽다.
  2. 길이 L의 부분 순환 이동 순서를 알면 길이 2L의 부분 순환 이동을 정렬할 수 있다.
  3. 길이를 1 → 2 → 4 → 8 ... 로 두 배씩 늘려, 길이가 문자열 길이를 초과할 때까지 반복한다.
  4. 그 시점의 순서가 정렬된 접미사의 순서와 같다.

### 보조 자료 구조 — 동치 클래스 (equivalence classes)
- 어떤 부분 순환 이동들이 서로 같은지를 상수 시간(constant time)에 판별하기 위한 클래스(class) 자료 구조가 필요하다.
- 처음에는 문자에 대해 클래스를 만든다(문자 비교는 쉬움).
- 각 반복마다 어떤 부분 순환 이동들이 같은지 정보를 갱신한다.

## 예시

`S = ababaa$` 에 대한 doubling 과정 (각 단계의 순서):

- 단일 문자 정렬 (길이 1): `$`가 위치 6, `a`가 위치 0·2·4·5, `b`가 위치 1·3 →
  `6, 0, 2, 4, 5, 1, 3` (같은 문자끼리의 상대 순서는 중요하지 않음)
- 길이 2 부분 순환 이동 정렬: `$a`, `a$`, `aa`, ... →
  `6, 5, 4, 0, 2, 1, 3`
- 길이 4 부분 순환 이동 정렬 →
  `6, 5, 4, 2, 0, 3, 1`
- 길이 8 부분 순환 이동 정렬 →
  `6, 5, 4, 2, 0, 3, 1`

길이 8은 문자열 길이(7)를 초과하므로 이 순서가 접미사 배열과 같다. 총 4번의 반복으로 완성된다.

### 일반 구성 전략 템플릿 (의사코드)

```
order = SortCharacters(S)
class = ComputeCharClasses(S, order)
L = 1
while L < len(S):
    order = SortDoubled(S, L, order, class)
    class = UpdateClasses(order, class, L)
    L = 2 * L
return order
```

## 요약
- 접미사 정렬을 순환 이동 정렬로 치환한다(Lemma에 의해 결과 순서가 동일).
- 길이 1부터 시작해 부분 순환 이동의 길이를 두 배씩 늘리며 정렬한다(doubling).
- 길이 L의 순서와 동치 클래스를 알면 길이 2L을 정렬할 수 있다.
- 동치 클래스는 두 부분 순환 이동이 같은지 상수 시간에 판별하게 해준다.
- 로그 횟수(logarithmic)의 반복으로 접미사 배열이 완성된다.
