# Analysis

## 개요
- 이전 영상에서 구현한, 접미사 배열(suffix array)과 LCP 배열(LCP array)로부터 접미사 트리(suffix tree)를 만드는 알고리즘이 선형 시간(linear time)에 동작함을 증명한다.
- 증명의 핵심은 각 간선(edge)을 위로도 아래로도 최대 한 번씩만 지난다는 관찰이다.

## 내용

### 간선 개수는 선형이다
- 이전 강의들에서 배운 대로, 접미사 트리의 전체 간선 개수는 문자열 길이에 대해 선형(linear)이다.

### 각 간선은 위/아래로 최대 한 번씩만 지난다
- **위로 이동(가는 경우)**: 어떤 접미사에 대한 리프를 만들고 다음 접미사의 리프를 만들기 위해 위로 올라갈 때, 이는 현재 접미사가 다음 접미사와 갈라지는(diverge) 구간을 거슬러 올라가는 것이다. 갈라지는 지점 위로 올라가면 즉시 멈추므로, 같은 간선을 다시 올라가지 않는다.
- **아래로 이동(내려가는 경우)**: 아래로 내려갈 때는 직전 접미사와는 이미 갈라진 새로운 구간을 따라 내려가는 것이므로, 직전 접미사를 처리할 때 이미 지나간 간선을 다시 내려가지 않는다.
- 따라서 각 간선은 전체 알고리즘 동안 위로 최대 한 번, 아래로 최대 한 번만 지나간다.

### 전체 시간 복잡도
- 새 노드·새 간선 생성, 링크 설정 등 나머지 연산은 모두 상수 시간(constant time)이다.
- 바깥쪽 for 루프의 반복 횟수는 문자열 길이(|S|)이므로, 상수 시간 연산들의 총합은 선형이다.
- 유일하게 의심할 수 있는 부분은 위로 올라가는 while 루프인데, 이 루프의 전체 반복 횟수는 (간선 개수가 선형이고 각 간선을 위로 최대 한 번만 지나므로) 전체적으로 선형을 넘을 수 없다.
- 결론적으로 이 알고리즘은 선형 시간에 동작한다.

### 전체 파이프라인의 시간 복잡도
- 접미사 배열이 주어지면 LCP 배열은 선형 시간에 계산할 수 있다.
- LCP 배열까지 주어지면 접미사 트리는 선형 시간에 구성할 수 있다(이번 증명).
- 이전 강의에서 접미사 배열 자체도 선형 시간에 구성할 수 있음을 배웠다.
- 따라서 처음부터(문자열만 주어진 상태에서) 접미사 트리를 구성하는 전체 과정도 선형 시간이다.

## 요약
- 접미사 트리의 전체 간선 개수는 선형이고, 각 간선은 위/아래로 최대 한 번씩만 지나간다.
- 이 때문에 위로 올라가는 while 루프의 전체 반복 횟수도 선형이며, 나머지 연산도 모두 상수 시간이다.
- 따라서 접미사 배열 + LCP 배열 → 접미사 트리 구성 알고리즘은 선형 시간이다.
- 접미사 배열(선형) → LCP 배열(선형) → 접미사 트리(선형)로 이어지는 전체 파이프라인 역시 선형 시간이며, 이로써 접미사 트리·접미사 배열·KMP(Knuth-Morris-Pratt) 알고리즘 등 문자열을 다루는 핵심 자료구조를 모두 학습했다.
