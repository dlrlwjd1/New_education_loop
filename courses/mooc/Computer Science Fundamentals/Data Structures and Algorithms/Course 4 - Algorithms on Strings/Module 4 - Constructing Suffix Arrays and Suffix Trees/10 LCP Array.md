# LCP Array

## 개요
- LCP 배열(LCP array)은 접미사 배열에서 인접한(adjacent) 접미사 쌍들의 LCP 값을 모은 배열이다.
- 크기는 문자열 길이 - 1이다. (인접 쌍의 수 = 접미사 수 - 1)
- 접미사 배열이 이미 주어졌을 때 LCP 배열을 임의의 문자열에 대해 효율적으로 구하는 것이 목표다.
- 이를 위해 LCP 값들에 관한 중요한 단조성 성질(lemma)을 증명하고, 이 성질이 선형 시간 계산의 기반이 됨을 보인다.

## 내용

### LCP 배열의 정의
- 문자열의 모든 접미사를 오름차순으로 정렬한 뒤, 그 순서에서 인접한 모든 접미사 쌍의 LCP 값을 계산한 것이 LCP 배열이다.
- 크기 = |문자열| - 1. 접미사 수는 문자열 길이와 같고 인접 쌍은 그보다 하나 적기 때문이다.

### LCP 값의 단조성 성질 (Lemma)
- 두 서로 다른 인덱스 i < j에 대해, 정렬된 접미사 A[i]와 A[j]에 대하여:
  - lcp(A[i], A[j]) ≤ LCP값[i] (즉 i번째 인접 쌍의 LCP)
  - lcp(A[i], A[j]) ≤ LCP값[j-1]
- 의미: 접미사 배열에서 멀리 떨어진 두 접미사의 LCP는, 서로 가까이 인접한 두 접미사의 LCP보다 작거나 같다.

### Lemma 증명 (LCP값[i] 부분)
- 세 접미사 i, i+1, j를 두고 `lcp(A[i], A[j])`가 `LCP값[i](= lcp(A[i], A[i+1]))`보다 크다고 가정한다.
- 위치 k = LCP값[i]를 접미사 i와 i+1의 공통 접두사 바로 다음 문자로 둔다.
- 경우 1: k가 접미사 i+1의 범위 밖이면 접미사 i+1이 접미사 i의 접두사가 되어 i+1 < i가 되는데, 이는 정렬 순서(i가 i+1보다 작아야 함)에 모순이다. 따라서 k는 접미사 i+1 안에 있다.
- k < lcp(A[i], A[j])이므로 접미사 i와 j의 위치 k 문자는 같다. 하지만 k는 i와 i+1의 공통 접두사 바로 다음이므로 i와 i+1의 위치 k 문자는 다르다.
- 경우 (i+1의 문자가 더 큼): i+1의 위치 k 문자가 j의 것보다 커져 접미사 i+1 > 접미사 j가 되는데, 정렬상 i+1 ≤ j여야 하므로 모순.
- 경우 (i+1의 문자가 더 작음): 접미사 i+1이 접미사 i보다 사전순으로 작아져 i+1이 i 뒤에 온다는 사실에 모순.
- 두 경우 모두 모순이므로 가정이 틀렸고 lemma가 성립한다. (LCP값[j-1] 부분은 대칭적으로 증명됨.)

### 계산 방법과 그 한계
- 단순 방법: 각 i(0 ~ |S|-2)에 대해 접미사 i와 i+1을 문자 단위로 직접 비교해 LCP를 구한다.
- 각 쌍 비교가 최악의 경우 문자열 길이에 비례하고, 그런 위치가 문자열 길이만큼 있으므로 전체는 O(|S|²) (2차 시간)이다.
- 위에서 증명한 단조성 성질을 이용하면 이를 선형 시간(linear time)으로 줄일 수 있으며, 방법은 다음 강의에서 다룬다.

## 예시
- 예시 문자열(정렬된 접미사 기준)의 LCP 배열 계산:
  - 0번, 1번 접미사: 공통 접두사 없음 → LCP 0
  - 다음 쌍: 공통 접두사 `a` → LCP 1
  - 다음 쌍: → LCP 1
  - 다음 쌍: 공통 접두사 `aba`(길이 3) → LCP 3
  - 다음 쌍: 공통 접두사 없음 → LCP 0
  - 마지막 쌍: → LCP 2
  - 결과 LCP 배열: `[0, 1, 1, 3, 0, 2]`

## 요약
- LCP 배열은 접미사 배열의 인접 접미사 쌍들의 LCP 값 모음이며 크기는 |S|-1이다.
- 핵심 성질: 접미사 배열에서 멀리 떨어진 두 접미사의 LCP는 그 사이 인접 쌍들의 LCP보다 작거나 같다(단조성).
- 이 성질은 두 문자의 대소 비교로 인한 정렬 순서 모순을 통해 증명된다.
- 단순 계산은 O(|S|²)이지만 이 단조성 성질을 이용하면 선형 시간에 LCP 배열을 구할 수 있다.
