# Updating Classes

## 개요
- 현재 부분 순환 이동(partial cyclic shift)의 순서(order)와 클래스 번호(class number)를 이용해 정렬된 길이 2L의 doubled 부분 순환 이동에 대해 새로운 클래스 번호를 매기는 방법을 다룬다.
- doubled 부분 순환 이동은 길이 L 부분 순환 이동의 쌍(pair)이므로, 각 쌍의 클래스 번호만으로 두 쌍이 같은지 상수 시간에 비교할 수 있다.

## 내용

### 쌍 비교로 클래스 번호 매기기
- 정렬된 순서대로 doubled 부분 순환 이동(쌍)을 하나씩 훑으면서, 바로 이전 쌍과 비교해 새 클래스 번호를 매긴다.
- 두 doubled 부분 순환 이동이 같을 필요충분조건은 첫 반쪽(first half)끼리 같고 둘째 반쪽(second half)끼리도 같은 것이다.
- 이전 쌍과 같으면 같은 클래스 번호를 준다.
- 이전 쌍과 다르면(이미 오름차순 사전식으로 정렬돼 있으므로) 다음 쌍이 이전 쌍보다 크다는 뜻이고, 클래스 번호는 정확히 1 증가한다.
  - 클래스 번호는 자신보다 엄격히 작은 서로 다른 부분 순환 이동의 개수이므로, 새로운(다른) 값이 하나 나타날 때마다 정확히 1씩 증가한다.

### 쌍의 반쪽끼리 비교하는 법
- 두 쌍의 첫 반쪽 `T1`, `Q1`을 비교할 때는 원래 문자열이 아니라 **이미 알고 있는 길이 L 부분 순환 이동의 클래스 번호**를 비교한다.
  - 클래스 번호가 같으면 첫 반쪽이 같고, 다르면 다르다.
- 둘째 반쪽도 마찬가지로 각각의 클래스 번호를 비교해 같은지 판별한다.
- 따라서 문자열 자체를 다시 볼 필요 없이 이미 계산된 클래스 번호만으로 상수 시간에 쌍을 비교할 수 있다.

### 예시로 살펴보는 절차
- 문자열 `S = ababaa$`, 길이 1 부분 순환 이동의 클래스 번호를 이미 알고 있는 상태(`$`→0, `a`→1, `b`→2)에서 길이 2 doubled 부분 순환 이동을 정렬된 순서(`$a, a$, aa, ab, ab, ba, ba`)로 살펴본다.
- 각 doubled 이동을 (첫 반쪽 클래스, 둘째 반쪽 클래스) 쌍으로 표현:
  - `$a` → `(0, 1)`
  - `a$` → `(1, 0)`
  - `aa` → `(1, 1)`
  - `ab` → `(1, 2)`
  - `ab` → `(1, 2)`
  - `ba` → `(2, 1)`
  - `ba` → `(2, 1)`
- 가장 작은 것부터 시작해 새 클래스 번호(`newClass`)를 채운다.
  - `$a` = `(0,1)` → 첫 번째이므로 클래스 0.
  - `a$` = `(1,0)` → 이전 `(0,1)`과 다름 → 클래스 1.
  - `aa` = `(1,1)` → 이전 `(1,0)`과 다름 → 클래스 2.
  - `ab` = `(1,2)` → 이전 `(1,1)`과 다름 → 클래스 3.
  - `ab` = `(1,2)` → 이전과 같음 → 클래스 3(그대로).
  - `ba` = `(2,1)` → 이전 `(1,2)`와 다름 → 클래스 4.
  - `ba` = `(2,1)` → 이전과 같음 → 클래스 4(그대로).
- 결과적으로 각 doubled 부분 순환 이동이 시작하는 위치(position)에 해당 클래스 번호를 기록한 배열 `newClass`가 완성된다.

## 예시

`S = ababaa$`, doubled(길이 2) 이동의 정렬 순서와 위치, 클래스 쌍, 최종 `newClass`:

| 정렬 순위 | 시작 위치 | doubled 이동 | (첫 반쪽 클래스, 둘째 반쪽 클래스) | newClass |
|-----------|-----------|--------------|--------------------------------------|----------|
| 1 | 6 | `$a` | (0, 1) | 0 |
| 2 | 5 | `a$` | (1, 0) | 1 |
| 3 | 4 | `aa` | (1, 1) | 2 |
| 4 | 0 | `ab` | (1, 2) | 3 |
| 5 | 2 | `ab` | (1, 2) | 3 |
| 6 | 1 | `ba` | (2, 1) | 4 |
| 7 | 3 | `ba` | (2, 1) | 4 |

## 요약
- doubled 부분 순환 이동의 클래스 번호는 이전 쌍과 비교해 같으면 유지, 다르면 +1로 매긴다.
- 쌍의 반쪽끼리 비교는 원본 문자열이 아니라 이미 계산된 (길이 L 부분 순환 이동의) 클래스 번호로 수행해 상수 시간에 처리한다.
- 이렇게 얻은 `newClass`가 길이 2L 부분 순환 이동의 클래스 번호가 된다.
