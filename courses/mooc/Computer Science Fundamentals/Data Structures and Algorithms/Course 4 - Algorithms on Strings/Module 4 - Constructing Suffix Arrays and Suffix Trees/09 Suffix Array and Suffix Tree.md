# Suffix Array and Suffix Tree

## 개요
- 접미사 트리(suffix tree)는 유전체(genome)처럼 수십억 개의 문자로 이루어진 거대한 문자열에서 패턴 매칭(pattern matching)을 할 때 필수적인 자료구조다.
- 기존에 배운 접미사 트리 구성 알고리즘은 시간 복잡도가 O(|S|²)이라 약 10,000~100,000 문자 정도의 짧은 문자열까지만 실용적이다.
- 이 강의부터는 접미사 트리를 O(|S| log |S|) 시간에 구성하는 방법을 배워 매우 긴 텍스트도 처리할 수 있게 한다.
- 전체 전략: 접미사 배열(suffix array)을 O(|S| log |S|)에 구성 → 선형 시간에 추가 정보(LCP 배열) 계산 → 접미사 배열과 추가 정보로부터 접미사 트리를 선형 시간에 구성.

## 내용

### 전체 구성 전략
- 병목은 접미사 배열 구성뿐이고, 나머지는 모두 선형 시간(linear time)에 동작한다.
  1. 이전 강의의 알고리즘으로 접미사 배열을 O(|S| log |S|)에 구성한다.
  2. 선형 시간에 추가 정보(LCP array)를 계산한다.
  3. 접미사 배열과 이 추가 정보로부터 접미사 트리를 선형 시간에 구성한다.

### 접미사 배열과 접미사 트리의 대응 관계
- 예시 문자열 `ababaa$`에서 왼쪽에는 오름차순으로 정렬된 모든 접미사, 오른쪽에는 접미사 트리가 있다.
- 문자열의 모든 접미사에 대해 접미사 트리의 대응되는 리프(leaf)가 존재한다.
- 각 노드에서 나가는 간선(edge)들을 첫 문자 기준으로 왼쪽에서 오른쪽으로 오름차순 정렬하면, 접미사 배열을 오름차순으로 훑는 것과 접미사 트리의 리프를 왼쪽에서 오른쪽으로 훑는 것이 동일해진다.
- 즉, 접미사 배열의 접미사 순서는 접미사 트리 리프의 좌→우 순서와 일치한다.
- 그러나 이 대응만으로는 트리의 리프만 알 수 있을 뿐 내부 노드(internal node)를 복원할 수 없다.

### 최장 공통 접두사(LCP)
- 두 문자열 S, T의 최장 공통 접두사(longest common prefix, LCP)는 S와 T 모두의 접두사인 가장 긴 문자열 u다.
- 대문자 표기 LCP(S, T)는 그 문자열 자체를, 소문자 표기 lcp(S, T)는 그 길이를 나타낸다.
- 예: `ababc`와 `abc`의 LCP는 `ab`이고 길이는 2다. (다음 문자 a와 c가 다름)
- 예: `a`와 `b`의 lcp는 0이다. (비어 있지 않은 공통 접두사가 없음)

### LCP로 내부 노드 복원하기
- 접미사 배열을 순서대로 훑으면서, 인접한(adjacent) 두 접미사의 LCP 값을 함께 보면 내부 노드를 복원할 수 있다.
- 어떤 접미사가 직전 접미사와 LCP 값만큼 공통 경로(루트에서부터)를 지난 뒤 갈라진다(diverge).
- 내부 노드는 정확히 접미사들이 갈라지는 지점에 생기며, 갈라짐은 정확히 그들의 LCP를 지난 직후에 일어난다.
- 따라서 접미사 배열과 각 인접 접미사 쌍의 LCP 값을 모두 알면 리프뿐 아니라 모든 내부 노드까지 복원해 접미사 트리를 만들 수 있다.

## 예시
- 문자열 `ababaa$`의 정렬된 접미사와 직전 접미사와의 LCP:
  - `$` → (첫 접미사, LCP 없음): 루트에서 시작하는 가장 왼쪽 경로
  - `a$` → LCP 0: 루트에서 바로 갈라짐
  - `aa$` → LCP 1 (`a`): 루트→노드까지 `a` 공통 경로 후 갈라짐
  - `abaa$` → LCP 1 (`a`): 마찬가지로 `a` 공통 경로 후 갈라짐
  - `ababaa$` → LCP 3 (`aba`): 간선 두 개(`a`, `ba`)를 지난 공통 경로 후 갈라짐
  - `b...` → LCP 0: 루트에서 갈라짐
  - 마지막 접미사 → LCP 2 (`ba`): `ba` 끝에 노드가 생김

## 요약
- 접미사 트리는 거대 문자열 처리에 필수지만 기존 O(|S|²) 알고리즘은 긴 문자열에 부적합하다.
- 목표는 접미사 배열(O(|S| log |S|)) → LCP 배열(선형) → 접미사 트리(선형)로 O(|S| log |S|) 구성을 달성하는 것이다.
- 접미사 배열의 순서는 접미사 트리 리프의 좌→우 순서와 일치한다.
- LCP(최장 공통 접두사)는 인접 접미사가 갈라지는 지점을 알려주며, 이를 이용해 내부 노드까지 복원할 수 있다.
