# Knuth-Morris-Pratt Algorithm

## 개요
- 정확한 패턴 매칭(exact pattern matching)을 위한 커누스-모리스-프랫(Knuth–Morris–Pratt, KMP) 알고리즘을 최종적으로 기술·구현·분석한다.
- 접두 함수(prefix function)와 특수 구분 문자 트릭을 결합해 텍스트에서 패턴의 모든 출현을 선형 시간에 찾는다.

## 내용

### 특수 문자($) 트릭
- 문자열 문제에서 흔히 쓰는 표준 트릭을 적용한다.
- 새 문자열 S를 만든다: **패턴 P + 특수 문자 `$` + 텍스트 T**를 이어 붙인다(concatenate).
- `$`는 패턴에도 텍스트에도 **절대 나타나지 않는** 보장된 문자다.
- 이 문자열 S 전체에 대해 접두 함수 s를 계산한다.

### 패턴 탐지 원리
- 접두 함수를 계산한 뒤, `$` 오른쪽의 모든 위치 i를 살핀다.
- 어떤 위치 i에서 접두 함수 값이 **패턴 길이 |P|와 같으면**, 그 위치에서 끝나는 패턴의 출현이 있다는 뜻이다.
  - 접두 함수 값이 |P|라는 것은 위치 i에서 끝나는 길이 |P|의 접미사가 S의 길이 |P| 접두사(= 패턴 P 자체)와 같다는 의미다.
  - 이 접미사는 `$` 오른쪽에 있으므로 텍스트 T 안에 있고, 따라서 T에 패턴이 출현한다.

### 시작 위치 계산
- 위치 i가 패턴 출현의 **마지막** 위치다.
- 텍스트 T에서의 시작 위치를 구하려면 총 **2 × |P|**를 빼야 한다.
  - |P| − 1: 출현의 처음 위치(문자열 S 기준)로 가기 위해.
  - +1: `$` 한 글자.
  - + |P|: S 앞부분에 붙인 패턴 길이.
  - 합치면 (|P| − 1) + 1 + |P| = 2|P|.

### 접두 함수 값이 |P|를 넘지 않는 이유
- S의 모든 위치에서 접두 함수 값은 최대 |P|다.
- 만약 어떤 위치의 값이 |P|보다 크면, 해당 경계에 패턴뿐 아니라 그 뒤의 `$`까지 포함된다. 그런데 `$`는 S에 단 한 번만 존재하므로, 경계(접두사 부분과 접미사 부분)에 두 번 나타날 수 없다. 모순이다.
- 따라서 값이 |P|와 같으면 출현이 있고, |P|보다 엄격히 작으면 그 위치에서 끝나는 패턴의 완전한 출현은 없다(있었다면 경계 길이가 |P|가 되었을 것이므로). 이 방식으로 모든 출현을 빠짐없이 찾는다.

### 의사코드

```text
FindAllOccurrences(P, T):
    S = P + '$' + T
    s = ComputePrefixFunction(S)
    result = empty list
    for i from |P| + 1 to |S| - 1:      # '$' 오른쪽 위치들
        if s[i] == |P|:
            result.append(i - 2 * |P|)
    return result
```

- S를 만들고, 접두 함수 s를 계산하고, `$` 오른쪽(위치 |P|+1 ~ |S|−1)을 훑으며 s[i] == |P|인 곳마다 시작 위치 `i − 2|P|`를 결과에 추가한다.

### 실행 시간 분석
- 보조정리: KMP 알고리즘의 실행 시간은 **O(|P| + |T|)** 로, 브루트 포스의 |P| × |T|보다 훨씬 빠르다.
- 근거:
  - 문자열 S 생성: 두 문자열 길이의 합에 비례.
  - 접두 함수 계산: |S|에 비례 = |P| + |T|에 비례.
  - 마지막 for 루프: O(|S|) = O(|P| + |T|).
- 예: 텍스트 길이 10억(billion), 패턴 길이 1,000일 때 브루트 포스는 약 1조(trillion) 번 비교(약 1시간)가 필요하지만, KMP는 약 10억 번 비교(약 1~10초)로 끝난다.

## 예시

| 항목 | 값 |
|---|---|
| 문자열 S | `P + $ + T` |
| 출현 판정 조건 | `$` 오른쪽 위치 i에서 s[i] == |P| |
| 텍스트 내 시작 위치 | i − 2|P| |
| for 루프 범위 | i = |P|+1 … |S|−1 |
| 전체 복잡도 | O(|P| + |T|) |

## 요약
- KMP: S = P + `$` + T를 만들고 접두 함수를 계산해, `$` 오른쪽에서 s[i] == |P|인 위치를 모두 찾으면 그것이 패턴의 출현이다.
- 텍스트 내 시작 위치는 i − 2|P|.
- `$`가 유일하므로 접두 함수 값은 |P|를 넘지 못하며, 이 성질이 정확성을 보장한다.
- 전체 실행 시간은 O(|P| + |T|) 선형이며 브루트 포스(|P| × |T|)보다 훨씬 빠르다.
- 결론: 이제 패턴 탐색과 접두 함수 계산을 선형 시간에 수행하고, 접두 함수로 문자열의 모든 경계를 열거할 수 있다.
