# Implementation

## 개요
- 문자열 P 전체에 대한 접두 함수(prefix function) 값을 계산하는 알고리즘을 의사코드(pseudocode)로 구현한다.
- 반환값은 P와 같은 길이의 배열 s로, 각 위치의 접두 함수 값을 담는다.

## 내용

### 입력과 출력
- 입력: 문자열 P.
- 출력: 배열 s (길이 = |P|). s[i] = 위치 i에서 끝나는 접두사의 가장 긴 경계의 길이.

### 초기화
- s[0] = 0. (위치 0에서 끝나는 접두사는 길이 1이라 경계는 빈 문자열뿐.)
- 변수 `border` = 0. 이 변수는 **직전에 고려한 접두사의 현재 가장 긴 경계 길이**를 항상 유지한다.

### 메인 루프
- i를 1부터 마지막 위치까지 반복하며 각 위치의 접두 함수 값을 계산한다.
- 내부 while 루프: 새 접두사의 마지막 글자 `P[i]`와, 현재 아는 가장 긴 경계 바로 다음 글자 `P[border]`를 비교한다.
  - `P[border]`가 왜 "경계 다음 글자"인가: 위치를 0부터 세므로 길이 `border`인 접두사는 위치 0~border−1을 차지하고, `P[border]`가 그 다음 글자다.
  - **같으면**: 반복 종료. 이 위치의 접두 함수는 `border + 1`.
  - **다르면**: `border = s[border − 1]`로 갱신한다. 즉 길이 `border`인 경계에서 그 경계의 가장 긴 경계로 내려간다. 이 경계는 위치 `border − 1`에서 끝나고, s[border − 1]에 그 경계의 가장 긴 경계 길이가 이미 저장돼 있다. 이렇게 이전 접두사의 모든 경계를 긴 것부터 차례로 열거한다.
- while 루프를 빠져나온 뒤:
  - 다음 글자가 같아서 나온 경우: `border = border + 1`.
  - 모든 경계를 다 열거해도 맞는 것이 없으면(빈 경계까지 내려감): 이 위치의 가장 긴 경계 길이는 0.
- 마지막에 찾은 경계 길이를 `s[i]`에 저장한다.

### 의사코드

```text
ComputePrefixFunction(P):
    s = array of length |P|
    s[0] = 0
    border = 0
    for i from 1 to |P| - 1:
        while (border > 0) and (P[i] != P[border]):
            border = s[border - 1]
        if P[i] == P[border]:
            border = border + 1
        else:
            border = 0
        s[i] = border
    return s
```

- 위치 0은 미리 s[0] = 0으로 처리하고, 나머지 위치는 이전에 계산한 접두 함수 값들을 이용해 하나씩 구한다.

## 요약
- 접두 함수 계산은 배열 s와 변수 `border`(현재 가장 긴 경계 길이)를 유지하며 왼쪽에서 오른쪽으로 진행한다.
- 각 위치에서 `P[i]`와 `P[border]`를 비교: 같으면 `border+1`, 다르면 `border = s[border-1]`로 더 짧은 경계로 내려간다.
- 반환값은 모든 위치의 접두 함수 값을 담은 배열 s. 다음 영상에서 이 알고리즘의 실행 시간을 분석한다.
