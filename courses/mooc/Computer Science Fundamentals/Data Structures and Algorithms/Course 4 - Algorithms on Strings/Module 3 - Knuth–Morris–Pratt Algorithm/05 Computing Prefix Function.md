# Computing Prefix Function

## 개요
- 접두 함수(prefix function)의 성질을 이용해, 왼쪽에서 오른쪽으로 값을 하나씩 계산하는 과정을 구체적인 예시로 따라간다.
- 경계가 맞지 않을 때 더 짧은 경계로 내려가며 비교하는 절차를 자세히 보여준다.

## 내용

### 계산 원리 요약
- 위치 0의 접두 함수는 항상 0 (길이 1 문자열의 경계는 빈 문자열뿐).
- 새 위치 i의 값을 구할 때: **이전 접두사의 가장 긴 경계 바로 다음 글자**와 **새 마지막 글자**를 비교한다.
  - 같으면: 이전 위치의 접두 함수 값 + 1.
  - 다르면: 현재 경계의 (더 짧은) 경계로 내려가 다시 비교. 빈 경계까지 내려가서도 맞지 않으면 값은 0.

### 예시 계산 절차
- **위치 0**: 항상 0.
- **다음 위치 (글자 b로 가정된 진행)**: 빈 경계 다음 글자 `a`와 새 글자를 비교 → 다름(빨간색). 더 짧은 경계가 없으므로(이미 빈 경계) 경계 없음 → 0.
- **다음 위치 (글자 a)**: 이전 가장 긴 경계는 빈 문자열, 그 다음 글자는 첫 위치의 `a`. 새 마지막 글자 `a`와 같음 → 접두 함수 = 이전 값 + 1 = 1. 이제 처음으로 비어있지 않은 경계(노란색으로 표시) 생김.
- **다음 위치 (글자 b)**: 노란 경계 `a` 다음 글자 `b`와 새 글자 `b` 같음 → 값 = 이전 + 1 = 2. 가장 긴 경계는 `ab`.
- **다음 위치**: 노란 경계 `ab` 다음 글자 `a`와 같음 → 값 = 이전 + 1 = 3. 경계 `aba`.
- **다음 위치**: 노란 경계 다음 글자 `b`와 같음 → 값 = 이전 + 1 (증가).
- **다음 위치 (글자 c)**: 경계 `abab` 다음 글자 `a`와 `c` 다름. 아직 멈추지 않고, 현재 경계 `abab`의 **가장 긴 경계**로 내려간다. 그 길이는 해당 위치 아래 적힌 접두 함수 값 2 → 경계 `ab`. `ab` 다음 글자 `a`와 `c` 다시 다름. 다시 `ab`의 가장 긴 경계로 내려감 → 길이 0(빈 문자열). 빈 접두사 다음 글자 `a`와 `c` 다름 → 값 0.
- **다음 위치 (글자 a)**: 이전 가장 긴 경계 다음 첫 글자 `a`와 같음 → 값 = 이전 + 1 = 1. 경계 `a`.
- **다음 위치 (글자 a)**: 현재 경계 `a` 다음 글자 `b`와 `a` 다름. `a`의 가장 긴 경계는 길이 0(빈 문자열)로 내려감. 빈 경계 다음 첫 글자 `a`와 `a` 같음 → 값 1.
- **다음 위치 (글자 b)**: 현재 경계 다음 글자 `b`와 같음 → 값 = 이전 + 1 = 2. 계산 종료.

### 핵심 관찰
- 값이 증가할 때는 항상 "이전 값 + 1".
- 다음 글자가 맞지 않으면 **접두 함수 값을 따라가며 더 짧은 경계로 계속 내려간다**(빈 경계까지).
- 현재 경계의 마지막 글자 아래 적힌 접두 함수 값이 곧 "그 경계의 가장 긴 경계 길이"이므로, 다음 내려갈 경계 길이를 바로 알 수 있다.

## 요약
- 접두 함수를 왼쪽에서 오른쪽으로 하나씩 계산한다.
- 규칙: 현재 가장 긴 경계 다음 글자와 새 글자가 같으면 값 +1, 다르면 더 짧은 경계(그 경계의 접두 함수 값)로 내려가 반복하고, 끝내 맞지 않으면 0.
- 다음 영상에서 이 절차를 일반적인 경우의 알고리즘(의사코드)으로 구현한다.
