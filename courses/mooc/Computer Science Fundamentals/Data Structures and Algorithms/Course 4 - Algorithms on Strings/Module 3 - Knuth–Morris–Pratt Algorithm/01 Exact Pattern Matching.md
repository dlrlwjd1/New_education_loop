# Exact Pattern Matching

## 개요
- 정확한 패턴 매칭(exact pattern matching) 문제를 정의하고, 이를 선형 시간(linear time)에 푸는 커누스-모리스-프랫(Knuth–Morris–Pratt, KMP) 알고리즘을 소개한다.
- 먼저 단순한 브루트 포스(brute force) 알고리즘과 그 한계를 살펴보고, 비교 위치를 건너뛸(skip) 수 있다는 아이디어를 도출한다.

## 내용

### 정확한 패턴 매칭 문제
- 두 개의 문자열이 주어진다.
  - 텍스트(text) T: 보통 훨씬 긴 문자열.
  - 패턴(pattern) P: 보통 짧은 문자열.
- 목표: 텍스트 T 안에서 패턴 P가 나타나는 **모든** 위치를 찾는 것이다. 즉, 위치 i에서 시작하는 T의 부분 문자열(substring)이 패턴 P와 같아지는 모든 i를 찾는다.

### 브루트 포스 알고리즘
- 패턴을 텍스트의 가능한 모든 위치에 정렬(align)시켜 보고, 해당 부분 문자열이 패턴과 일치하는지 검사한다.
- 복잡도: 텍스트 길이 × 패턴 길이.
  - 외부 for 루프가 약 |T| 번 반복된다.
  - 각 위치에서 패턴과 부분 문자열을 비교하는 데 최악의 경우 패턴 길이에 비례하는 시간이 든다.

### 예시로 본 동작 (텍스트 abracadabra, 패턴 abra)
- 위치 0에 정렬 → 패턴이 일치한다. 결과에 위치 0 추가.
- 한 칸씩 오른쪽으로 이동하며 비교. 위치 1, 2에서는 첫 글자부터 불일치.
- 위치 3에서는 첫 글자는 맞지만 두 번째 글자(패턴의 b vs 텍스트의 c)가 불일치.
- 계속 이동하여 위치 7에서 패턴 전체가 다시 일치.
- 결과: 위치 0과 7에서 패턴이 나타난다.

### 위치 건너뛰기(skipping)의 착안
- 위치 0에서 패턴 전체가 일치했다고 가정하자.
- 패턴을 한 칸 오른쪽으로 옮겨 T의 위치 1과 비교하는 것은, 실제로는 패턴 자신을 위치 1부터 자기 자신과 비교하는 것과 같다.
  - 즉 패턴의 위치 0에서 시작하는 부분 문자열과 위치 1에서 시작하는 부분 문자열이 같아야만 새 위치에서 일치가 가능하다.
  - abracadabra 예에서 a ≠ b, a ≠ r이므로 위치 1, 2로 옮기는 것은 무의미하다.
- 잠재적 일치가 가능한 첫 위치는 위치 3이다(패턴 위치 0의 글자와 위치 3의 글자가 같기 때문). 따라서 위치 1, 2에서의 비교는 안전하게 건너뛸 수 있다.
- 패턴이 텍스트의 앞부분과 부분적으로만 일치하는 경우에도, 그 공통 부분 문자열을 이용해 몇 칸을 건너뛸 수 있는지 힌트를 얻을 수 있다. 패턴을 오른쪽으로 옮겨 일치가 일어나려면 패턴의 첫 글자가 (앞서 일치한) 패턴의 다른 위치와 맞아떨어져야 한다.

## 예시

텍스트 `abracadabra`, 패턴 `abra`:

| 정렬 시작 위치 | 결과 |
|---|---|
| 0 | 일치 (결과에 추가) |
| 1 | 첫 글자 불일치 |
| 2 | 첫 글자 불일치 |
| 3 | 두 번째 글자 불일치 |
| 4, 5, 6 | 불일치 |
| 7 | 일치 (결과에 추가) |

최종 결과: {0, 7}

## 요약
- 정확한 패턴 매칭: 텍스트 T에서 패턴 P가 나타나는 모든 위치를 찾는 문제.
- 브루트 포스 알고리즘의 복잡도는 |T| × |P|로, 긴 입력에서는 너무 느리다.
- 핵심 아이디어: 이미 일치한(또는 부분 일치한) 정보를 이용하면 여러 비교 위치를 안전하게 건너뛸 수 있으며, 이것이 KMP 알고리즘의 출발점이다.
