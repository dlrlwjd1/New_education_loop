# Analysis

## 개요
- 접두 함수(prefix function) 계산 알고리즘의 실행 시간(running time)을 분석한다.
- 보조정리(lemma): 이 알고리즘은 **선형 시간(linear time)**에 동작한다.

## 내용

### 선형인 부분들
- 초기화: 길이 |P| 배열을 초기화하므로 문자열 길이에 선형.
- 메인 for 루프: 내부 while 루프를 제외하면 각 반복에서 하는 일은 상수 시간(constant time)이고, 반복 횟수는 |P| − 1 번이므로 선형.

### 어려운 부분: 내부 while 루프
- while 루프는 for 루프의 각 반복마다 실행되며(총 |P| − 1 번 시작), 일부 반복에서는 여러 번 돌 수 있다.
- 증명해야 할 것: **모든 for 반복에 걸친 while 루프의 총 반복 횟수가 선형**임을 보이는 것.

### `border` 변수의 변화 추적
- 알고리즘에서 접두 함수 값(= 마지막으로 고려한 접두사의 가장 긴 경계 길이)은 변수 `border`로 관리된다.
- 위치 0에서 `border`는 0으로 시작한다.
- 오른쪽으로 진행하면서:
  - `border` 값은 for 루프의 각 반복에서 **최대 1 증가**한다(접두 함수의 성질).
  - `border` 값은 while 루프를 한 번 돌 때마다 **최소 1 감소**한다. while 루프에서는 현재 경계의 가장 긴 경계를 취하는데, 그 경계는 원래 것보다 엄격히(strictly) 짧기 때문이다.

### 총 while 반복 횟수의 상한
- `border`는 for 루프 반복당 최대 1씩만 증가하고, for 반복은 |P| − 1 번뿐이므로, **총 증가량은 최대 |P|**.
- while 루프 반복마다 `border`는 최소 1 감소하고, `border`는 항상 음수가 아니다(non-negative).
- 따라서 총 감소량도 최대 |P|이며, 이는 **while 루프의 총 반복 횟수가 최대 |P|**임을 의미한다.

### 결론
- 다른 모든 부분이 선형이고 while 루프의 총 반복 횟수도 선형이므로, 접두 함수 계산 알고리즘 전체는 **선형 시간**에 동작한다.

## 요약
- 접두 함수 계산은 O(|P|) 선형 시간.
- 핵심 논증(amortized argument): `border`는 for 반복당 최대 +1 증가, while 반복당 최소 −1 감소, 항상 ≥ 0이므로 while 루프 총 반복 횟수 ≤ |P|.
- 다음 영상에서 이 접두 함수를 이용해 텍스트에서 패턴을 효율적으로 찾는 방법(KMP)을 다룬다.
