# Approximate Pattern Matching

## 개요
- 지금까지는 정확한(exact) 매칭만 다뤘지만, 실제로는 참조 게놈(reference genome)과 개인 게놈이 다른 위치, 즉 변이(mutation)를 찾는 근사 패턴 매칭(approximate pattern matching)이 더 중요하다.
- BWT를 이용해 다중 근사 패턴 매칭을 어떻게 수행하는지, 그리고 이것이 실제 유전 질환 진단·치료와 어떻게 연결되는지를 다룬다.

## 내용

### 근사 패턴 매칭 문제 정의
- **근사 패턴 매칭(approximate pattern matching)**: 문자열 Pattern, 문자열 Text, 정수 d가 주어졌을 때, Text에서 Pattern이 최대 d개의 미스매치(mismatch)를 허용하며 부분 문자열로 등장하는 모든 위치를 찾는다.
- **다중 근사 패턴 매칭(multiple approximate pattern matching)**: 여러 패턴의 집합 Patterns, 문자열 Text, 정수 d가 주어졌을 때, Patterns의 어떤 문자열이 최대 d개의 미스매치로 등장하는 모든 위치를 찾는다.

### BWT를 이용한 근사 매칭 방법
- 기존 정확 매칭과 마찬가지로 `a`로 시작하는 모든 행을 찾는 데서 시작한다.
- 정확 매칭에서는 조건을 만족하지 않는 행을 즉시 버렸지만, 근사 매칭에서는 미스매치 허용 개수(d) 이내인 모든 행을 계속 유지해야 한다.
- 각 행마다 지금까지 발생한 미스매치 횟수를 기록해 두고, first-last property로 다음 글자를 확인하면서 미스매치 허용치를 넘는 행만 걸러낸다.
- 매칭된 위치는 (부분) 접미사 배열을 이용해 텍스트 상의 실제 위치로 변환한다.

### 근사 매칭과 실제 유전 질환
- 인간 집단의 약 10%가 희귀 유전 질환(rare genetic disease)을 가지고 있으며, 알려진 희귀 유전 질환은 7,000종이 넘는다.
- 패턴 매칭은 게놈에서 변이를 찾아 진단하는 데 쓰이지만, 진단이 되어도 치료법이 없는 경우(예: 조로증 progeria)도 많다.
- 더 복잡한 변이의 예로 필라델피아 염색체(Philadelphia chromosome)가 있다. 이는 두 정상 염색체의 조각이 서로 위치를 바꿔 형성되는 키메라(chimera) 염색체이며, 만성 골수성 백혈병(chronic myeloid leukemia)의 바이오마커(biomarker)로 알려져 있다.
- 이 변이에 대한 정확한 지식을 바탕으로 만성 골수성 백혈병 치료제인 글리벡(Gleevec)이 개발되었다.

## 예시
- `panamabananas`에서 최대 1개의 미스매치를 허용하며 `ana`를 검색:
  - `a`로 시작하는 6개 행 중 뒤 두 글자가 `na`로 정확히 매칭되는 행은 3개다. 나머지 3개 행도 미스매치 허용치 내에 있다면 계속 유지한다.
  - first-last property를 적용해 첫 열에서의 대응 위치를 찾고, 각 행의 미스매치 횟수를 다시 확인한다.
  - 6개의 후보 중 미스매치가 2개인 행 1개는 허용치(1개)를 초과해 제외되고, 나머지 5개가 최대 1개의 미스매치로 `ana`와 매칭되는 최종 결과가 된다.

## 요약
- 근사 패턴 매칭은 최대 d개의 미스매치를 허용하며 패턴이 등장하는 위치를 찾는 문제다.
- BWT 기반 방법은 정확 매칭과 같은 절차를 쓰되, 각 후보 행의 미스매치 횟수를 추적하며 허용치를 넘는 행만 제거한다.
- (부분) 접미사 배열로 매칭된 위치를 텍스트 상의 실제 위치로 변환한다.
- 이러한 패턴 매칭 기술은 실제 유전 질환의 변이 진단, 나아가 글리벡 같은 맞춤형 치료제 개발의 기반이 된다.
