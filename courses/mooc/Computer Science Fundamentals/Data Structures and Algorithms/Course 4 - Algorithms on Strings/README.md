# Algorithms on Strings

- 전문과정: Data Structures and Algorithms (Course 4)
- 제공: University of California San Diego
- 구성: 4개 모듈, 영상 35개 — Transcript 기반 한국어 정리 완료
- 제외: 읽기 자료·퀴즈·프로그래밍 과제 채점

문자열(string) 처리에 특화된 자료구조와 알고리즘을 다룬다. Trie와 suffix tree/array를 이용한 패턴 매칭, Burrows-Wheeler 변환을 이용한 텍스트 압축·검색, Knuth-Morris-Pratt(KMP) 알고리즘, 그리고 suffix array와 suffix tree를 선형에 가까운 시간에 구성하는 방법을 학습한다.
