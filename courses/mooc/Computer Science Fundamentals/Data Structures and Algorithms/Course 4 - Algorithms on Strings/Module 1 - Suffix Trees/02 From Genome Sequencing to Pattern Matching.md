# From Genome Sequencing to Pattern Matching

## 개요
- 유전체 서열분석(genome sequencing)이 어떻게 진행되는지 "신문 문제(newspaper problem)" 비유로 설명한다.
- 개인 유전체 서열분석과 참조 기반(reference-based) 접근을 통해 돌연변이를 찾는 문제가 어떻게 패턴 매칭(pattern matching) 문제로 이어지는지 보여준다.
- 정확 패턴 매칭, 근사 패턴 매칭, 다중 패턴 매칭 문제를 정의한다.

## 내용

### 진행성 노화 증후군(progeria)과 돌연변이
- Sam Berns는 프로게리아(progeria)라는 희귀 유전병을 앓았다. 이 병은 아이가 10세에 이미 노인처럼 보이게 하고 대개 10대에 사망하게 한다.
- 오랫동안 원인을 몰랐으나, 2003년에 프로게리아가 1번 염색체(chromosome one)의 단 하나의 돌연변이(single mutation)로 발생함이 밝혀졌다.

### 신문 문제(newspaper problem)와 유전체 조립
- 동일한 신문 여러 부를 폭발시켜 흩어진 조각들로부터 원래 내용을 복원하는 문제에 비유한다.
- 조각들을 겹치는(overlapping) 퍼즐로 보고 서로 맞춰 전체를 조립한다. 인간 유전체는 2000년에 이 방식으로 조립되었다(약 30억 달러 규모 프로젝트).
- 유전체(genome)는 A, C, G, T 알파벳으로 된 긴 가닥일 뿐이다.

### 유전체 서열분석 절차
1. 동일한 유전체 사본 수백만 개에서 시작한다.
2. 분자 가위(molecular scissors)로 무작위 위치에서 유전체를 자른다.
3. 시퀀싱 기계로 리드(read)라 불리는 짧은 부분문자열(substring)을 생성한다. 이 과정에서 일부 리드는 손실된다.
4. 수백만~수십억 개의 조각으로부터 유전체를 조립한다.
- 차세대 시퀀싱(next-generation sequencing) 혁명 이후 오늘날 생물학자들은 매년 수천 개의 유전체를 서열분석한다.

### 개인 유전체와 참조 기반 서열분석
- 사람 사이의 차이는 돌연변이에서 비롯되며, 대략 1,000 뉴클레오티드(nucleotide)당 1개꼴로 나타난다. 이 적은 돌연변이가 7,000종 이상의 알려진 유전병을 설명한다.
- 참조 기반 방식: Craig Venter의 유전체(참조 유전체, reference genome)에서 시작해 내 유전체의 리드를 생성한다. 일부는 참조에 완벽히 맞지만 일부는 맞지 않는다. 맞지 않는 리드로부터 내 유전체의 돌연변이(예: T→C 치환, T 결실(deletion))를 알아낼 수 있다.

### 계산 문제 정의
- **정확 패턴 매칭(Exact Pattern Matching)**: 문자열 Pattern과 Text가 주어질 때, Text에서 Pattern이 부분문자열로 나타나는 모든 위치를 찾는다.
- **근사 패턴 매칭(Approximate Pattern Matching)**: 입력은 문자열 Pattern, 문자열 Text, 정수 d. Text에서 Pattern이 최대 d개의 불일치(mismatch)를 허용하며 부분문자열로 나타나는 모든 위치를 찾는다.
- **다중 패턴 매칭(Multiple Pattern Matching)**: 문자열 집합 Patterns와 문자열 Text가 주어질 때, Text에서 Patterns의 어떤 문자열이 부분문자열로 나타나는 모든 위치를 찾는다. 수십억 개의 리드를 참조 유전체에 대조하는 문제에 해당한다.

## 요약
- 유전체 서열분석은 잘게 부순 조각(리드)으로부터 유전체를 복원하는 문제이며 신문 문제와 유사하다.
- 참조 유전체와 개인 리드를 대조해 돌연변이를 찾는 것이 실제 목표다.
- 이는 정확·근사·다중 패턴 매칭이라는 계산 문제로 귀결되며, 특히 수십억 리드를 다루는 다중 패턴 매칭이 핵심 과제다.
