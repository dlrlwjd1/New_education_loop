# Brute Force Approach to Pattern Matching

## 개요
- 패턴 매칭에 대한 첫 번째 무차별 대입(brute force) 접근법을 설명한다.
- 단일 패턴에서는 빠르지만, 수십억 개의 패턴을 다룰 때는 비현실적으로 느려짐을 보인다.

## 내용

### 무차별 대입 접근
- 패턴을 "차(car)"에 싣고 텍스트(text)를 따라 운전하는 비유로 설명한다.
- 텍스트의 각 위치에서 패턴과 텍스트를 문자 단위로 비교하고, 패턴이 나타나면 그 위치를 출현(occurrence)으로 보고한다.
- 예: `nana`를 `panamabananas`를 따라 운전하며 각 위치에서 대조한다.

### 복잡도 분석
- 각 위치에서 최대 |Pattern|번의 문자 비교가 필요하므로, 실행 시간은 **O(|Text| × |Pattern|)**이다.
- Knuth-Morris-Pratt(KMP) 알고리즘은 이 나이브(naive) 알고리즘을 개선해 패턴 길이와 무관하게 **O(|Text|)** 시간에 실행된다(이후 강의에서 Misha가 설명 예고).

### 다중 패턴에서의 한계
- 수십억 개의 패턴을 각각 따로 처리하면 실행 시간은 **O(|Text| × |Patterns|)**가 된다. 여기서 |Patterns|는 모든 패턴의 총 길이다.
- 인간 유전체에 적용하면 |Text|는 약 30억 뉴클레오티드, 패턴 총 길이는 최대 10^12에 이른다.
- 따라서 나이브 알고리즘은 물론 KMP 알고리즘조차 이 규모에서는 동작하지 못한다.

## 예시
- 단일 패턴 매칭 실행 시간: `O(|Text| × |Pattern|)`
- KMP 알고리즘 실행 시간: `O(|Text|)`
- 다중 패턴 무차별 대입 실행 시간: `O(|Text| × |Patterns|)`, |Patterns| = 모든 패턴의 총 길이

## 요약
- 무차별 대입 패턴 매칭은 패턴을 텍스트의 모든 위치에서 문자 비교하는 방식이다.
- 단일 패턴에는 O(|Text| × |Pattern|), KMP로는 O(|Text|)에 해결 가능하다.
- 그러나 수십억 패턴을 다루면 O(|Text| × |Patterns|)로 비현실적이라 새로운 접근이 필요하다.
