# Herding Text into Suffix Trie

## 개요
- 패턴 대신 텍스트를 트라이로 묶는 반대 아이디어, 즉 접미사 트라이(suffix trie)를 제시한다.
- 접미사 트라이로 패턴을 매칭하는 방법과, 리프에 위치 정보를 붙여 매칭 위치를 찾는 방법을 설명한다.
- 접미사 트라이의 메모리 한계를 분석한다.

## 내용

### 아이디어: 텍스트를 버스에 싣기
- 이전에는 패턴들을 트라이에 담았지만, 이번에는 텍스트의 모든 접미사(suffix)를 생성해 트라이로 만든다.
- 각 패턴에 대해, 그 패턴이 접미사 트라이에서 루트로부터 아래로 철자될 수 있는지(spelled out) 확인한다.

### 접미사 트라이 구성
- 텍스트 끝에 달러 기호 `$`를 붙인 뒤(`panamabananas$`) 시작한다.
- 가장 긴 접미사부터 시작해 각 접미사에 해당하는 경로를 트라이에 만든다. 공통 접두사에서 갈라지는 지점마다 가지(branch)가 생긴다.
- 완성된 것을 텍스트의 접미사 트라이(SuffixTrie of text)라 한다.

### 패턴 매칭
- 패턴을 "차"에 싣고 접미사 트라이의 가지들을 따라 운전한다.
- 패턴 기호를 하나씩 매칭하며 내려가다 텍스트의 어떤 접미사와 매칭되면 성공이다.
- 예: `banana`, `nab`은 매칭되지만, `b`에서 이어지는 경로가 없어 실패하거나, `antenna`는 `t`에서 매칭이 없어 멈춘다.

### 매칭 위치 찾기 — 리프에 위치 정보 붙이기
- 접미사 트라이만으로는 패턴이 텍스트의 어느 위치에서 나타나는지 알 수 없다.
- 각 리프(leaf)에 그 리프를 생성한 접미사의 시작 위치(starting position)를 기록한다. 예: `bananas`는 위치 6에서 시작하므로 6을 붙인다. `panamabananas$`는 위치 0.
- 이렇게 모든 접미사의 시작 위치로 리프를 장식(decorate)한 것이 완전한 접미사 트라이다.
- 매칭이 트라이 중간에서 끝나면, 리프(들)까지 계속 내려가 시작 위치를 얻는다.
  - 예: `banana`는 중간에서 끝나지만 계속 내려가면 위치 6을 찾는다.
  - 예: `ana`는 세 갈래로 이어져 세 개의 리프에 도달하므로, 텍스트에 3번 나타남을 알 수 있다.

### 메모리 분석
- 접미사 트라이는 텍스트의 접미사들로 구성된다.
- 접미사의 평균 길이는 약 |Text|/2 이다.
- 따라서 접미사 총 길이는 **|Text| × (|Text| − 1) / 2**이다.
- 인간 유전체에서는 비현실적으로 거대한 메모리를 차지한다.

## 예시
- 리프에 붙이는 값 = 해당 접미사의 텍스트 내 시작 위치 (예: `bananas` → 6, `panamabananas$` → 0)
- 접미사 총 길이: `|Text| × (|Text| − 1) / 2`

## 요약
- 접미사 트라이는 텍스트의 모든 접미사를 트라이로 만들어 패턴 매칭을 빠르게 한다.
- 리프에 접미사 시작 위치를 기록하면 패턴이 나타나는 텍스트 위치를 찾을 수 있다.
- 그러나 메모리가 |Text|²에 비례해 유전체 규모에서는 비현실적이다.
