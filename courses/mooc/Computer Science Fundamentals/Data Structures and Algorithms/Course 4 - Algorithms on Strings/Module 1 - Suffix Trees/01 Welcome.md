# Welcome

## 개요
- 문자열 알고리즘(string algorithms)이 일상 도구와 첨단 연구 양쪽에서 어떻게 쓰이는지 소개하는 도입 강의다.
- 특히 생물정보학(bioinformatics)에서 DNA와 유전자 분석에 문자열 알고리즘이 핵심적으로 사용된다.
- 코스 전체 구성과 캡스톤 프로젝트(genome assembly)를 예고한다.

## 내용

### 생물정보학과 DNA 문자열
- DNA는 두 가닥(strand)이 얽힌 3차원 구조다. 한 가닥의 분자 서열을 기록하면 DNA의 여러 성질을 추출할 수 있다.
- 아미노산(amino acid)이라 불리는 수십 종의 분자 각각을 라틴 문자 하나로 표기하면, 한 가닥을 라틴 문자로 이루어진 문자열(string)로 변환할 수 있다.
- 사람·침팬지·쥐의 DNA 문자열을 나란히 놓고 같은 부분과 다른 부분을 찾으면, 생명이 어떻게 진화했고 유전자에서 무엇이 바뀌었는지 관찰할 수 있다.
- 희귀 유전병(genetic disease) 환자의 유전체(genome)와 건강한 사람의 유전체를 비교해 차이를 찾고, 어떤 돌연변이(mutation)가 병을 일으키는지 가설을 세울 수 있다.

### 일상 속 문자열 알고리즘
- 검색 엔진(Google, Yandex, Baidu, Naver): 인터넷을 크롤링해 페타바이트(petabyte) 규모의 데이터를 내려받고, 검색어를 문서 텍스트와 대조(match)한다.
- 텍스트 편집기: 맞춤법 검사(spellchecking)나 텍스트 내 찾기 기능이 문자열 알고리즘으로 동작한다.
- 보안 소프트웨어: 안티바이러스는 프로그램 코드에서 의심스러운 패턴을, 네트워크 침입 탐지 시스템은 네트워크 트래픽에서 의심스러운 패턴을 찾는다. 즉 정확(exact) 및 근사(approximate) 패턴 매칭(pattern matching) 도구로 활용된다.
- 버전 관리 시스템(version control system)의 diff 도구: 코드나 위키백과 문서에서 무엇이 바뀌었는지 텍스트를 정렬(align)하고 대조해 추정한다.

### 코스 구성
- 1부: 생물정보학에 문자열 알고리즘을 적용하는 방법을 Pavel Pevzner가 설명한다.
- 2부: 이 알고리즘들을 수백만~수십억 문자 규모의 유전체나 인터넷 텍스트에도 충분히 빠르게 실행되도록 만드는 알고리즘적 도전을 다룬다.
- 마지막에는 캡스톤 프로젝트 Genome assembly를 통해 수백만 조각으로부터 유전체를 조립하며 문자열·그래프 알고리즘을 적용한다.

## 요약
- 문자열 알고리즘은 생물정보학 연구부터 검색, 편집기, 보안, 버전 관리까지 광범위하게 쓰인다.
- DNA 한 가닥은 문자 서열, 즉 문자열로 변환되어 알고리즘의 분석 대상이 된다.
- 이 코스는 패턴 매칭을 생물학 문제에 적용하고, 대규모 데이터에서도 빠르게 동작하도록 만드는 것을 목표로 한다.
