# 03 The Minimax Algorithm

## 개요
- 강좌: Intelligent Agents and Search Algorithms (University of Colorado Boulder)
- 모듈: Module 5 — Informed Adversarial Searches
- [MOOC 원본 강의](https://www.mooc.org/learn/intelligent-agents-and-search-algorithms/lecture/gyHeQ/the-minimax-algorithm)
- **미니맥스(minimax)** — 적대적 탐색의 기초 알고리즘. **상대가 최적으로 둔다고 가정하고** 내 결과를 최대화한다.

---

## 내용

### 기본 아이디어
- 적대적 게임에서 **에이전트의 모든 행동에는 상대가 그 이점을 무효화하려는 최선의 시도**가 돌아온다.
- 에이전트의 목표: **상대가 최소화하려 한다는 전제 아래 내 결과를 최대화한다.**

**전제 조건**
- **양쪽 모두 최적으로 둔다**고 가정한다
- **게임은 제로섬**이다 — 한 쪽의 이득이 다른 쪽의 손실
- 이 전제 아래 **max의 최선의 수는, 그 지점부터 양쪽이 완벽하게 둔다고 할 때 효용 값이 가장 높은 수**다

### 트리 구조
- **노드 = 게임 상태**, **간선 = 합법 행동**
- 층이 **max(내 차례)와 min(상대 차례)으로 번갈아** 나타난다. **각 층을 플라이(ply)** 라고 부른다
- 트리 맨 아래의 **잎 노드 = 종료 상태**(게임의 끝)

**틱택토의 효용 값**
| 결과 | 값 |
|---|---|
| 무승부 | **0** |
| max 승 | **+1** |
| max 패(= min 승) | **−1** |

### 동작 방식 ⭐
> **종료 노드까지 재귀적으로 내려가 그 경로의 값을 반환하고, 루트까지 거슬러 올라오며 값을 정한다.**
>
> - **min 노드에서는 자식 값 중 최솟값**을 고른다 — min은 max를 지게 만들려 하므로
> - **max 노드에서는 자식 값 중 최댓값**을 고른다
> - **루트는 max 노드**다 — 이 게임을 max의 관점에서 두고 있으므로

### 2-플라이 예제 (각 플레이어가 한 번씩) ⭐
종료 노드가 0/1/−1이 아니라 정수 값을 갖는 예다.

**1단계 — min 노드들이 먼저 고른다** (각자 자식 중 **최솟값**)

| min 노드 | 자식 값 | 선택 |
|---|---|---|
| **a** | 3, 12, 8 | **3** |
| **b** | 2, 4 | **2** |
| **c** | 14, 5, 2 | **2** |

**2단계 — max가 그중에서 고른다** (**최댓값**)

- max가 가진 선택지: **3, 2, 2** → **max는 3을 고른다. 즉 최적 선택은 가지 a.**

> ⭐ **핵심 관찰**: 트리 전체의 최댓값은 **14**(c의 자식)지만 **max는 그 선택지를 갖지 못한다.** min이 그 그룹에서 최솟값 **2**를 고르기 때문이다. **min의 선택이 max가 고를 수 있는 것을 결정한다.**

### 복잡도 문제
- 미니맥스는 실제로는 **게임 트리의 종료 상태까지 완전한 깊이 우선 탐색**을 수행한다. **실제 게임에서는 계산적으로 감당 불가능하다.**
- 분기 계수 **b**, 깊이 **m** 인 게임에서 **시간 복잡도는 O(b^m)**.

### 현실적 해법 — 휴리스틱 + 깊이 제한 탐색 ⭐
현대 적대적 탐색은 미니맥스의 기본 아이디어 위에 **휴리스틱 함수**와 **깊이 제한 탐색(depth-limited search)** 을 얹는다.

- 최단 경로 문제에서 휴리스틱은 **실제 비용을 모를 때 노드 비용을 추정**하는 수단이었다. **게임에서도 발상이 같다.**
- 게임의 휴리스틱은 **에이전트가 승리 경로 위에 있는지 알 수 없고 종료 노드까지 탐색할 수도 없을 때, 게임 상태의 품질을 평가**한다.
- **컷오프 상태(cutoff state)** — 깊이 제한 탐색에서 쓰는, **종료 상태가 아닌 상태** — 와 함께 쓰인다.
- 휴리스틱 함수는 **"이 위치가 max에게 얼마나 좋은가"의 빠른 근사**를 제공한다.

**좋은 게임 휴리스틱의 조건**
1. **실제 승리 확률과 상관이 높아야 한다** — 함수가 높게 평가한 위치가 **통계적으로 더 많은 승리로 이어져야** 한다
2. **계산이 빨라야 한다** — 수를 고르기 전에 **더 많은 선택지를 평가**할 수 있도록
3. 도메인 지식에 기반한 **전략적 가치**를 쓰거나, **데이터에서 패턴을 학습**할 수 있다

### 클로드 섀넌의 체스 모델 (1950) ⭐
섀넌은 **모든 수의 전수 탐색이 계산적으로 불가능함을 보이고**, 인간 체스 기사들이 승리와 관련 있다고 동의한 **게임 특징에 기반한 휴리스틱 평가**를 제시했다.

**전략적 가치를 갖는 범주들**
| 범주 | 내용 |
|---|---|
| **단순 계수(simple counts)** | 판 위에 각 기물이 몇 개 있고 그 가치는 얼마인가. 예: **비숍이 폰보다 점수가 높다** |
| **기동성(mobility)** | 개별 기물이 **의미 있는 수를 몇 개** 둘 수 있는가 |
| **킹 안전** | 킹이 다른 기물들에 의해 **보호되고 있는가** |
| **폰 구조(pawn structure)** | 판 위 폰의 배치 |
| **판 장악** | **중앙 칸 장악** 등 |

**선형 회귀 형태의 평가 함수**
```
Eval(s) = Σ wᵢ · fᵢ(s)

s  = 게임 상태
fᵢ = 특징 값 (기물 수, 합법 수의 개수 등)
wᵢ = 그 특징에 적용되는 가중치 (학습되거나 손으로 튜닝)
```

- 휴리스틱 평가에는 **게임에서 몇 수가 진행됐는지**도 포함될 수 있다. **플레이어의 전략은 게임이 진행되며 바뀌고, 어떤 수는 초반보다 후반에 더 전략적**이기 때문이다.

## 요약
- **미니맥스** = **min 노드는 최솟값, max 노드는 최댓값**을 고르며 종료 노드에서 루트로 값을 거슬러 올린다. **양쪽 모두 최적으로 둔다고 가정**한다.
- 층을 **플라이(ply)** 라 하고, **루트는 max 노드**다.
- 2-플라이 예제: min이 (3,12,8)→3, (2,4)→2, (14,5,2)→2를 고르면 **max는 3을 고른다.** 트리 최댓값 14는 **min 때문에 도달 불가**다.
- **시간 복잡도 O(b^m)** — 실제 게임에서는 불가능하다.
- 해법: **휴리스틱 평가 함수 + 깊이 제한 탐색(컷오프).** 좋은 휴리스틱은 **승률과 상관이 높고 계산이 빠르다.**
- **섀넌(1950)의 체스 평가 함수** = **기물 가치·기동성·킹 안전·폰 구조·중앙 장악**의 **가중 선형 결합**.
