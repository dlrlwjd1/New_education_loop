## 이 강좌의 특징

- **수식보다 개념과 애니메이션 중심**이다. 알고리즘 동작을 노드 확장 순서로 따라가게 한다.
- **8-퀸 퍼즐과 8-타일 퍼즐**이 강좌 전체를 관통하는 예제다.
- **프로그래밍 과제가 두 개**(A* 탐색, 유전 알고리즘) 있어 손으로 구현할 기회가 있다.
- 정리본은 **자막(영어) 전문을 근거로 작성**했다. 슬라이드 이미지·애니메이션은 원본 영상에서만 볼 수 있으므로, **막히면 각 노트 상단의 원본 강의 링크로 영상을 보는 편이 빠르다.**
