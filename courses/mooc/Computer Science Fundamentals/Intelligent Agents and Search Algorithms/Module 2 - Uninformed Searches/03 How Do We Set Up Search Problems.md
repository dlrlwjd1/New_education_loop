## 내용

### 알고리즘과 탐색 트리
- **알고리즘** = 문제를 풀거나 계산을 수행하는 정확한 단계별 절차. 입력을 받아 처리하고 출력을 낸다.
- AI에서 **탐색 알고리즘은 에이전트가 가능한 행동을 탐험하고, 진행을 평가하고, 최선의 경로를 고르는 방식**을 정의한다.
- 알고리즘마다 트레이드오프가 다르다 — **어떤 것은 최저 비용 해를 보장하고, 어떤 것은 빠르지만 그 보장을 못 한다.**

**탐색 트리(search tree)로 문제를 표현한다**
- **루트 노드** = 초기 상태
- **각 가지(branch)** = 하나의 행동
- **각 노드** = 새로운 상태
- **노드를 확장한다(expanding)** = 가능한 모든 행동을 적용해 **후계 노드(successors)** 를 생성하는 것

> **탐색 알고리즘은 "다음에 어느 노드를 확장할지" 고른다. 바로 이 결정이 탐색 전략들을 구분한다.**

### 세 가지 핵심 집합 ⭐
| 이름 | 뜻 |
|---|---|
| **프론티어(frontier)** | 확장을 기다리는 **모든 노드의 집합** |
| **확장 집합(expanded / explored)** | **이미 방문한** 모든 노드 |
| **해 비용(solution cost)** | 각 노드에 도달하는 데 드는 **누적 비용** |

### 모든 탐색 알고리즘의 공통 루프 ⭐
1. **프론티어에서 노드를 하나 고른다**
2. **목표인지 검사한다.** 맞으면 끝
3. 아니면 **노드를 확장한다** — 가능한 모든 행동을 적용해 후계 노드 생성
4. **새 노드들을 프론티어에 넣는다**
5. 목표를 찾거나 목표가 존재하지 않음이 확정될 때까지 반복

> **알고리즘마다 다른 것은 오직 1단계 — 다음에 어느 노드를 확장할지 정하는 규칙뿐이다.**

| 알고리즘 | 1단계의 규칙 |
|---|---|
| 너비 우선 탐색(BFS) | **가장 얕은** 노드를 먼저 확장 |
| 깊이 우선 탐색(DFS) | 한 가지를 **가능한 한 깊이** 따라간다 |
| 균일 비용 탐색(uniform cost) | **지금까지의 총 비용이 가장 낮은** 노드를 고른다 |
| A* 등 정보 이용 탐색 | **휴리스틱**을 더해 목표 쪽으로 탐색을 유도한다 |

### 예제 — 창고 로봇
충전소에서 출발해 특정 선반의 물건을 집고 충전소로 돌아온다.

| 요소 | 내용 |
|---|---|
| 상태 | 격자 위 로봇의 위치 |
| 행동 | 상·하·좌·우 이동 |
| 목표 | 선반에 도달 |
| 경로 비용 | 총 걸음 수 또는 소요 시간 |

현실을 더하면 — 통로가 **작업자나 임시 장애물로 막히거나 이동 제한 구역**이 생긴다. 그러면 **가능한 경로 수가 폭증한다.**

### 노드와 환경을 코드로 표현하기
**노드 하나를 표현하는 데 필요한 최소 정보**

| 저장할 것 | 왜 |
|---|---|
| 격자 위 위치 (행, 열) | 상태 그 자체 |
| **부모 노드(parent)** | 최종 해에서 **로봇의 경로를 재구성**하기 위해 |
| 그 노드에 도달한 **행동** | 〃 |
| 시작 노드까지의 **경로 비용** | 알고리즘에 따라 필요 |
| **목적 함수 값** | 탐색에서 노드에 우선순위를 매기는 값 |

**격자 환경을 표현하는 데 필요한 것**

- 격자 **크기** (행·열 수)
- **장애물 지도**
- **각 칸의 비용 지도** — 어떤 칸이 지나기 더 쉬울 때 유용하다. 예: 거친 지형은 통과 비용을 높게

**필요한 메서드**
- 단계 비용(step cost)을 부여하는 메서드
- **노드가 격자 안에 있고 통과 가능한지(inbounds and passable)** 판단하는 메서드
- 노드를 확장할 때 이 정보를 확인한다. **통과 불가한 노드는 프론티어에 넣을 필요가 없다.**

**후계 노드 생성 절차**
1. 모든 방향의 행동에 대해 결과 노드가 **격자 안이고 통과 가능한지** 확인
2. 여기서 **단계 비용도 확인**해 해 비용 계산에 쓴다
3. 각 후계 노드를 프론티어에 추가

### 프론티어의 자료구조 ⭐
**알고리즘이 곧 자료구조 선택이다.**

| 알고리즘 | 자료구조 | 꺼내는 순서 |
|---|---|---|
| **균일 비용 탐색 · A\*** | **우선순위 큐(priority queue)** | 최저 비용 해가 큐 맨 위 |
| **너비 우선 탐색(BFS)** | **일반 큐(queue)** | 넣은 순서대로 — **FIFO** |
| **깊이 우선 탐색(DFS)** | **스택(stack)**, 흔히 재귀로 | **LIFO** — 가장 최근에 넣은 노드를 먼저 확장 |

## 요약
- 탐색은 문제를 **탐색 트리**로 표현한다 — 루트=초기 상태, 가지=행동, 노드=상태. **확장**은 가능한 행동을 모두 적용해 후계를 만드는 것.
- 상태 셋: **프론티어(대기) · 확장 집합(방문 완료) · 해 비용(누적)**.
- 모든 탐색 알고리즘은 **고르기 → 목표 검사 → 확장 → 프론티어에 추가 → 반복**의 같은 루프를 돈다. **다른 것은 "무엇을 고르는가"뿐이다.**
- 노드에는 위치뿐 아니라 **부모와 행동**을 저장해야 경로를 재구성할 수 있다.
- **프론티어 자료구조가 알고리즘을 결정한다** — 큐=BFS, 스택=DFS, 우선순위 큐=균일 비용/A*.
