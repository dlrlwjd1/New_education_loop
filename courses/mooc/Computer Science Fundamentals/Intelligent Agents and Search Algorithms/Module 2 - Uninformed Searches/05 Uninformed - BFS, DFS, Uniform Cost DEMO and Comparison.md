## 내용

### 무정보 탐색이란
> **맹목 탐색(blind search)** 이라고도 한다. 에이전트가 **어떤 상태가 목표에 얼마나 가까운지, 어떤 행동이 다른 것보다 나은지에 대한 지식이 전혀 없다.**

- 에이전트가 아는 것은 **문제 정의뿐** — 시작 상태, 가능한 행동, 목표 검사.
- 그것만 가지고 상태 공간을 **체계적으로** 탐험한다.
- 세 알고리즘의 차이는 **탐색 트리를 탐험하는 방식, 즉 노드를 확장하는 순서**뿐이다.

### 1. 너비 우선 탐색 (BFS, breadth-first search)
- **가장 얕은 미확장 노드를 먼저** 확장한 뒤 더 깊은 노드로 간다.
- **레벨 단위로 탐험**한다. 시작 상태에서 물결이 퍼져 나가는 모습.
- 자료구조: **큐(queue)** — FIFO. 생성된 순서대로 탐험한다.
- **모든 단계 비용이 같으면 BFS는 항상 (단계 수 기준) 최단 경로를 찾는다.**

**동작 예시** (색: 활성 노드=빨강, 확장 완료=파랑, 프론티어 추가=주황)
1. 시작 노드 A에서 출발
2. 레벨 1의 **B와 C**가 프론티어에 추가 → 알파벳 순으로 B, 그다음 C 확장
3. B와 C의 자식들이 프론티어에 추가 → 레벨 2로 이동, **D·E·F·I·J** 추가
4. 레벨 2를 **왼쪽에서 오른쪽으로** 순서대로 확장, 그 자식들을 프론티어에 추가
5. 레벨 3에서 목표에 도달할 때까지 모든 노드를 확장

> 핵심: **각 레벨을 전부 훑고 나서야 다음 레벨로 넘어간다.** 목표를 찾긴 하지만 **매우 느리고 시간·공간을 많이 쓴다.**

### 2. 깊이 우선 탐색 (DFS, depth-first search)
- 한 가지를 **가능한 한 깊이** 따라가 끝에 도달한 뒤 **되돌아와(backtrack)** 다른 가지를 탐험한다.
- 자료구조: **스택(stack)** — LIFO.
- 비유: 미로에서 **막다른 길에 닿을 때까지 한 복도를 따라가고**, 그다음 돌아와 다른 복도를 시도한다.
- **메모리 면에서 BFS보다 효율적이다.** 한 번에 **경로 하나만** 저장하면 된다.
- 그러나 **최단 경로를 보장하지 않고, 무한 가지가 있으면 경로 자체를 못 찾을 수도 있다.**

**동작 예시** (BFS와 같은 트리)
1. 시작 노드에서 **B → D → K** 로 트리 바닥까지 확장
2. **B로 되돌아와(recurse back)** 다른 가지인 **E** 확장
3. 그다음 C의 가지 — **C → F → L**
4. 그다음 I 노드의 가지
5. 마지막으로 **J → M(목표)**

> 이 예제에서 DFS는 **BFS와 같은 수의 노드를 확장하지만, 메모리에는 한 번에 가지 하나만 담는다.**

### 3. 균일 비용 탐색 (uniform cost search)
- BFS를 일반화한 것으로 **깊이 대신 경로 비용**을 본다.
- **지금까지의 총 비용이 가장 낮은 노드**를 항상 확장한다. 자료구조는 **경로 비용으로 정렬된 우선순위 큐**.
- **단계 비용이 서로 달라도 최저 비용 경로를 찾는다** — 비용이 양수이기만 하면.

**동작 예시**
1. A에서 시작. **C까지의 비용이 B까지의 비용보다 낮아** C가 확장 순서에서 B보다 앞선다
2. C의 자식들이 **그 노드까지의 총 경로 비용**으로 프론티어에 추가된다. 예: F에 부여되는 비용 = (A→C 비용) + (C→F 비용)
3. 목표 노드가 확장될 때까지 비용 순으로 확장 → 확장된 시점이 **그 노드까지의 최저 비용 경로를 찾았다는 뜻**

> ⚠️ **중요**: 목표 노드에 이르는 경로가 여럿일 수 있다. **목표 노드가 프론티어에 추가되었다는 것만으로 그것이 해(최단 경로)라는 뜻은 아니다.** 예제에서 J를 지나는 경로가 먼저 발견되지만, 최종 최적 경로는 **G를 지나 목표에 도달하며 최적 비용 6.5**가 된다.

### 세 알고리즘 비교 ⭐
| | BFS | DFS | 균일 비용 탐색 |
|---|---|---|---|
| 확장 순서 | **레벨 단위** | **한 가지를 끝까지** | **총 비용이 낮은 순** |
| 자료구조 | 큐 (FIFO) | 스택 (LIFO) | 우선순위 큐 |
| 완전성 | ✓ | ✗ (무한 가지에서) | ✓ |
| 최적성 | **단계 비용이 모두 같을 때만** | ✗ | **✓ (비용이 양수면)** |
| 메모리 | 많음 (b^d) | **적음 (경로 하나)** | 많음 |

### 왜 여전히 배우는가
- 무정보 탐색은 AI 탐색을 넓게 이해하는 **기초**다. **체계적으로 탐험하는 법, 완전성·최적성·복잡도를 측정하는 법, 탐색 트리를 분석하는 법**을 가르쳐 준다.
- **A\* 같은 정보 이용 탐색은 여기에 휴리스틱(도메인 지식)을 더해 탐색 공간을 쳐내는 것**이다 — 곧바로 이 위에 쌓인다.
- 이 원리들은 현대 전략에도 깔려 있다 — 탐욕 최선 우선 탐색 같은 휴리스틱 유도 방법부터, **유전 알고리즘·몬테카를로 탐색 트리(MCTS)·RRT** 같은 메타휴리스틱·표본 기반 접근까지.

## 요약
- **무정보(맹목) 탐색** = 목표까지의 거리에 대한 지식 없이 문제 정의만으로 체계적으로 탐험.
- **BFS** — 레벨 단위, 큐(FIFO). 단계 비용이 같으면 최단 경로 보장. **느리고 메모리를 많이 쓴다.**
- **DFS** — 한 가지 끝까지, 스택(LIFO). **메모리 효율적**이지만 최단 경로도 해 자체도 보장 못 한다.
- **균일 비용 탐색** — 총 비용 최저 순, 우선순위 큐. **비용이 다를 때도 최적 비용을 보장한다.**
- 목표가 프론티어에 들어갔다고 해서 최단 경로를 찾은 것은 아니다. **확장될 때** 확정된다.
- 다음 단계는 여기에 **휴리스틱**을 더하는 것 — 정보 이용 탐색.
