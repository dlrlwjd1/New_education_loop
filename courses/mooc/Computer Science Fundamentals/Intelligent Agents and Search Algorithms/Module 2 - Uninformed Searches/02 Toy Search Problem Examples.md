## 내용

### 장난감 문제란 무엇이고 왜 쓰는가
> **연구·교육·알고리즘 테스트를 위해 단순화·추상화한 문제.**

- 현실의 지저분한 세부를 담지 않는다. 대신 **문제를 핵심만 남기고 벗겨내** 아이디어를 명확히 시험하게 한다.
- 쓰는 이유 셋:
  1. **탐색 문제를 형식화하는 연습** — 상태·행동·목표·비용 식별
  2. **알고리즘을 공정하게 비교** — 설정이 모두에게 알려져 있다
  3. **작고 안전한 환경에서 각 탐색 전략의 강점과 약점이 드러난다**
- 장난감 문제에서 알고리즘의 동작을 이해한 뒤, **로보틱스·스케줄링·경로 계획** 같은 실제 문제로 확장한다.

### 진공 세계(vacuum world) ⭐
**1×2 격자**가 방을 대신한다. 에이전트의 행동은 **세 가지** — 왼쪽 이동, 오른쪽 이동, 먼지 흡입.

완전 관측·모델 없는(model-free) 버전에서 에이전트는 **자기가 어느 칸에 있는지, 그 칸이 더러운지**를 항상 정확히 안다.

| 요소 | 내용 |
|---|---|
| 상태 | **에이전트의 위치 + 각 칸의 청결/오염 여부** |
| 초기 상태(예) | 에이전트 왼쪽 칸, 왼쪽 더러움, 오른쪽 깨끗함 |
| 목표 상태 | **두 칸 모두 깨끗함.** 에이전트가 어느 칸에 있든 상관없다 |
| 행동 | 왼쪽 이동 / 오른쪽 이동 / 흡입 |
| 전이 모델 | 행동 후의 진공 위치와 각 칸의 청결 상태 |
| 경로 비용 | **취한 행동의 수** |
| 상태 공간 | 위치와 각 칸 상태의 모든 조합 — **총 8가지** |

**행동 두 번의 예**
1. 초기 — 두 칸 다 더러움, 에이전트는 왼쪽 칸
2. 흡입 → 왼쪽 칸 깨끗, 에이전트 여전히 왼쪽 칸
3. 오른쪽 이동 → 왼쪽 깨끗, 에이전트 오른쪽 칸, **오른쪽은 아직 더러움**(치우려면 행동이 하나 더 필요)

> 상태 공간 전체를 **직접 그릴 수 있을 만큼 단순**해서, 상태·행동·목표를 정의하는 출발점으로 좋다.

**더 복잡한 AI로 확장되는 지점**
- **완전 관측**으로 모델링하면 A* 탐색으로 최단 행동 순서를 찾는 기본 실험이 된다
- **부분 관측**으로 만들 수도 있다 — 로봇이 자기 칸 상태만 안다. 그러면 **불확실성·기억·보상·감지** 개념이 들어온다
- **무작위성**을 넣을 수도 있다 — 먼지가 다시 생기거나 행동이 가끔 실패한다. **확률적 동역학과 강화학습 정책**의 시험대가 된다

### 슬라이딩 8-타일 퍼즐 ⭐
**3×3 격자**에 번호 붙은 타일 8개와 빈 칸 하나. 타일을 빈 칸으로 한 번에 하나씩 민다. 목표는 타일을 1~8 순서로 놓고 빈 칸을 퍼즐 처음에 두는 것.

| 요소 | 내용 |
|---|---|
| 초기 상태 | 타일의 임의 배치 |
| 목표 상태 | 순서대로 정렬 + 빈 칸이 구석 |
| 행동 | 이웃 타일을 빈 칸으로 밀기 |
| 전이 모델 | 밀기 후 보드가 어떻게 바뀌는가 |
| 경로 비용 | 보통 **이동 횟수** |

> 문제 서술은 단순한데 **상태 공간이 매우 크다 — 18만 가지가 넘는 배치**가 가능하다.

**여기서 얻는 교훈**
- 상태 공간 크기 때문에 **모든 배치를 시도하는 완전 탐색(brute force)으로는 해를 찾을 수 없다.** → **문제에 대한 휴리스틱 지식**을 쓰는 탐색 알고리즘을 개발하게 된다
- 상태 공간이 크므로 **휴리스틱이 분기 계수(branching factor)와 확장 노드에 미치는 효과를 평가**할 수 있다
- 여기서 휴리스틱을 시험하는 능력은 **경로 탐색·스케줄링·계획** 응용에 그대로 쓰인다

## 요약
- **장난감 문제**는 핵심만 남긴 단순 문제다. 형식화 연습·공정한 알고리즘 비교·전략의 강약점 노출에 쓴다.
- **진공 세계** — 1×2 격자, 행동 3개, 상태 8개. 상태 공간을 통째로 그릴 수 있다. 부분 관측·확률성을 넣어 확장 가능.
- **8-타일 퍼즐** — 3×3, 상태 18만+개. **완전 탐색이 불가능해 휴리스틱이 필요해지는 지점**이다.
- 두 문제 모두 이 강좌의 뒤 모듈([A*](../Module%203%20-%20Informed%20Searches/03%20A%20Star%20Search%20Including%20Conditions%20for%20Optimality.md), [휴리스틱 개발](../Module%203%20-%20Informed%20Searches/06%20Approaches%20to%20Developing%20Heuristics.md))에서 계속 예제로 돌아온다.
