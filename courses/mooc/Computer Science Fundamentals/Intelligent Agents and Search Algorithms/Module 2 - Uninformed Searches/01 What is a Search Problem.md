# 01 What is a Search Problem?

## 개요
- 강좌: Intelligent Agents and Search Algorithms (University of Colorado Boulder)
- 모듈: Module 2 — Uninformed Searches
- [MOOC 원본 강의](https://www.mooc.org/learn/intelligent-agents-and-search-algorithms/lecture/9teko/what-is-a-search-problem)
- **탐색 문제(search problem)** 를 정의하는 다섯 요소 — 초기 상태, 행동, 전이 모델, 목표 검사, 경로 비용 — 과 그것들이 만드는 **상태 공간**.

---

## 내용

### 왜 탐색인가 — 마트 예시
- 마트에서 살 물건 목록이 있다고 하자. 매장을 모르면 **통로를 하나씩 다 돌게 되고** 필요 이상으로 시간과 걸음을 쓴다.
- 더 효율적인 방법은 장보기를 **탐색 문제로 취급**하는 것이다 — 필요한 통로만 가장 효율적으로 지나는 경로를 찾고 갈 필요 없는 구역은 피한다.
- **지능적 에이전트도 똑같이 접근한다.**

> **AI에서 탐색이란 해를 찾기 위해 가능한 선택지를 탐험하는 과정이다.**

- 미로 풀기, Google Maps 경로 계획, 체스에서 다음 수 정하기 — 전부 탐색 문제다.
- **탐색은 에이전트가 다음에 무엇을 할지 알아내는 방식의 핵심**에 있다.

### 탐색 문제의 다섯 요소 ⭐
탐색 문제는 에이전트가 **시작 조건에서 목표까지 가능한 단계들을 탐험하며 이동하는 상황**을 형식적으로 기술한 것이다.

| 요소 | 뜻 | 미로 | 체스 | 경로 탐색 앱 |
|---|---|---|---|---|
| **초기 상태**<br>(initial state) | 탐색을 시작하는 곳 | 미로 입구 위치 | 게임 시작 시 보드 배치 | 현재 위치 |
| **행동**<br>(actions, 후계 함수 successor function) | 각 상태에서 가능한 수 | 상·하·좌·우 이동 | 합법 수 — 폰 이동, 기물 잡기, 캐슬링 | 교차로에서 좌/우회전, 도로 주행 |
| **전이 모델**<br>(transition model) | 행동 후의 상태를 결정 | A에서 "오른쪽"을 하면 새 위치 | 기물 이동 후의 새 보드 배치 | 행동 후 내 위치 |
| **목표 검사**<br>(goal test) | 언제 멈출지 판단 | 출구에 있는가? | 해답 패턴과 일치하는가? | 목적지에 도착했는가? |
| **경로 비용**<br>(path cost) | 각 경로에 숫자 비용 부여 | 출구까지 이동 거리 | 승리까지의 수 | 거리·소요 시간·연료/전기 |

- **목표 검사가 명확히 정의되지 않으면 탐색 에이전트는 언제 멈출지 절대 알 수 없다.**
- 경로 비용은 **해들을 비교해 최선을 고르는 데** 쓰인다.

### 상태 공간(state space)
> **초기 상태 + 행동 + 전이 모델이 암묵적으로 상태 공간을 정의한다** — 에이전트가 있을 수 있는 **모든 가능한 구성의 우주**.

상태 공간에 포함되는 특징은 문제에 따라 다르다.

- 미로 → 미로 안에서 에이전트가 있을 수 있는 **모든 위치**
- 체스 → **모든 가능한 보드 배치**
- 경로 탐색 앱 → 경로 상의 위치 + 목표 위치 + **지금까지 이동한 경로**

### 종합 예시 — 로드 트립 계획
| 요소 | 내용 |
|---|---|
| 초기 상태 | 현재 위치 |
| 행동 | 교차로에서 어느 도로를 탈지, 어느 방향으로 돌지 |
| 전이 모델 | 행동 후 내 위치 |
| 목표 검사 | 목록의 모든 마을을 방문했는가 |
| 경로 비용 | 이동 거리 / 소요 시간 / 사용한 자원 |

> **경로 비용은 비용 함수를 어떻게 설정하느냐로 결정된다.** 같은 문제라도 "최단 거리"와 "최소 연료"는 다른 답을 낸다.

---

## 요약
- 탐색 = **해를 찾기 위해 가능한 선택지를 탐험하는 과정.** 미로·경로 계획·체스가 모두 탐색 문제다.
- 탐색 문제의 다섯 요소: **초기 상태 · 행동(후계 함수) · 전이 모델 · 목표 검사 · 경로 비용**.
- **초기 상태 + 행동 + 전이 모델 = 상태 공간**(가능한 모든 구성).
- 목표 검사가 없으면 멈출 줄 모르고, 경로 비용이 없으면 해를 비교할 수 없다.
