# 05 The Types of Agent Environments

## 개요
- 강좌: Intelligent Agents and Search Algorithms (University of Colorado Boulder)
- 모듈: Module 1 — Search Problems & Intelligence
- [MOOC 원본 강의](https://www.mooc.org/learn/intelligent-agents-and-search-algorithms/lecture/MP1BF/the-types-of-agent-environments)
- **과업 환경(task environment)** 의 일곱 가지 성질과 **PEAS 프레임워크**. 에이전트를 설계하기 전에 반드시 정의해야 하는 것이다.

---

## 내용

### 과업 환경이란
> **에이전트가 지각하는 모든 것, 할 수 있는 모든 것, 이루어야 하는 것.**

과업 환경을 명시하는 것이 에이전트 설계의 필수 첫 단계다. 그 이유:

- **합리적 행동이 무엇인지 명확해진다**
- **알고리즘 선택을 결정한다** — 탐색 문제인가, 학습 문제인가, 계획 문제인가
- **필요한 시스템과 만들어진 시스템의 어긋남을 막는다**

> ⚠️ **성능 측도를 잘못 정의하면 에이전트는 엉뚱한 것에 성공한다.** 예 — 빠르게 가도록 설계했지만 **승객 안전을 고려하지 않은 자율주행차**는 아무도 타고 싶어 하지 않는다.

### 과업 환경의 일곱 가지 성질 ⭐
| 성질 | 묻는 것 |
|---|---|
| **완전 관측 vs 부분 관측**<br>(fully / partially observable) | 에이전트가 얼마나 아는가 |
| **결정적 vs 확률적**<br>(deterministic / stochastic) | 결과에 우연이 얼마나 개입하는가 |
| **에피소드적 vs 순차적**<br>(episodic / sequential) | 한 번의 행동인가, 행동의 **연쇄**인가 |
| **정적 vs 동적**<br>(static / dynamic) | 환경이 시간에 따라 변하는가 |
| **이산 vs 연속**<br>(discrete / continuous) | 상태와 행동을 어떻게 표현하는가 |
| **단일 에이전트 vs 다중 에이전트**<br>(single / multi-agent) | 에이전트가 하나인가, 서로 상호작용하는 여럿인가 |

### 세 가지 예제로 비교하기 ⭐
| 성질 | 크로스워드 퍼즐 | 포커 | 택시 운전 |
|---|---|---|---|
| 관측 | **완전 관측** — 판 전체가 보인다 | **부분 관측** — 딜러·다른 플레이어의 패를 모른다 | **부분 관측** |
| 결정성 | **결정적** | **확률적** — 무작위성이 있다 | **확률적** |
| 에피소드/순차 | **순차적** — 퍼즐을 푸는 단어들의 연쇄 | **순차적** — 이기기 위한 카드의 연쇄 | **순차적** — 운전 행동의 연쇄 |
| 정적/동적 | **정적** — 문제가 정해지면 변하지 않는다 | **정적** | **동적** — 시간에 따라 변한다 |
| 이산/연속 | **이산** | **이산** | **연속** — 택시와 다른 차의 위치가 연속적으로 변한다 |
| 에이전트 수 | **단일** — 다른 에이전트와 겨루지 않는다 | **다중** — 다른 플레이어가 있다 | **다중** — 다른 운전자와 장애물 |

> 택시가 가장 어려운 문제인 이유가 표에서 그대로 보인다 — **부분 관측 + 확률적 + 동적 + 연속 + 다중 에이전트**.

### PEAS 프레임워크 ⭐
환경을 더 정밀하게 기술하는 네 항목이다. **만들기 전에** 이것을 적는다.

| 글자 | 뜻 | 내용 |
|---|---|---|
| **P**erformance measure | 성능 측도 | 성공을 정의한다 — 정확도, 안전, 속도, 사용자 만족 |
| **E**nvironment | 환경 | 결과에 영향을 주지만 **에이전트가 통제할 수 없는 모든 것** |
| **A**ctuators | 작동기 | 에이전트가 행동하는 수단 — 모터, 디스플레이, 추천 |
| **S**ensors | 센서 | 세계를 지각하는 수단 — 카메라, 마이크, 데이터 스트림 |

#### 예 1 — 자율주행차
| | |
|---|---|
| **P** | **안전이 최우선**, 그다음 합법성 → 승차감 → 효율 |
| **E** | 도로, 다른 차량, 보행자, 기상 조건 |
| **A** | 핸들, 가속 페달, 브레이크 |
| **S** | 카메라, LiDAR, GPS, 내부 계기 |

#### 예 2 — 의료 진단 에이전트
| | |
|---|---|
| **P** | 정확도와 환자 건강 결과 |
| **E** | 환자의 생물학적 실제 상태 |
| **A** | 시스템의 권고 또는 경보 |
| **S** | 진료 기록, 검사 결과, 영상 데이터 |

> PEAS를 적고 나면 **에이전트의 임무가 정확히 무엇인지** 드러난다.

---

## 요약
- 과업 환경 = **에이전트가 지각하는 것 + 할 수 있는 것 + 이뤄야 하는 것.** 설계의 첫 단계다.
- 성질 여섯~일곱 가지로 환경을 분류한다 — 완전/부분 관측, 결정적/확률적, 에피소드적/순차적, 정적/동적, 이산/연속, 단일/다중 에이전트.
- **성능 측도를 잘못 잡으면 에이전트가 엉뚱한 것에 성공한다.**
- **PEAS** = Performance measure · Environment · Actuators · Sensors. 에이전트 설계의 청사진이다.
