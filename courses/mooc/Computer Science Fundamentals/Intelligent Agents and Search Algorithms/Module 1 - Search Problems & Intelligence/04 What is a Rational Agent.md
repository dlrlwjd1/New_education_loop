# 04 What is a Rational Agent?

## 개요
- 강좌: Intelligent Agents and Search Algorithms (University of Colorado Boulder)
- 모듈: Module 1 — Search Problems & Intelligence
- [MOOC 원본 강의](https://www.mooc.org/learn/intelligent-agents-and-search-algorithms/lecture/MgP3C/what-is-a-rational-agent)
- **합리적 에이전트(rational agent)** 의 정의와 세 구성 요소, 그리고 **에이전트 함수 vs 에이전트 프로그램**의 구분.

---

## 내용

### 정의
> **합리적 에이전트란 환경을 지각(perceive)하고, 지각한 정보를 처리하고, 목표 달성 가능성을 최대화하는 행동을 취하는 개체다.**

- 거의 모든 AI 시스템의 핵심에 이것이 있다.
- 핵심 개념은 **지각-행동 루프(perception-action loop)** — 에이전트가 환경을 지각하고 → 무엇을 할지 결정하고 → 행동하고 → **환경이 그에 반응해 바뀐다.**

### 세 가지 구성 요소 ⭐
| 구성 요소 | 뜻 |
|---|---|
| **지각(precepts)** | 에이전트가 환경으로부터 받는 정보 |
| **성능 측도(performance measure)** | 목표를 얼마나 잘 달성하고 있는지 평가하는 기준 |
| **행동 전략(action strategy)** | 다음에 무엇을 할지 고르는 방법 |

- 합리적 행동은 **목표·가진 정보·환경**에 달려 있다.
- **한 상황에서 좋은 행동이 다른 상황에서는 좋지 않을 수 있다. 합리성은 문맥 의존적(context-dependent)이다.**

### 예시 — 로봇 청소기
| 요소 | 로봇 청소기의 경우 |
|---|---|
| 지각(센서) | 바닥이 더러운지 깨끗한지 |
| 성능 측도 | 청소 품질 / 시간 효율 / 배터리 절약 중 무엇을 우선할지 |
| 행동 전략 | 이동, 회전, 청소, 충전 도크 복귀 |

- 먼지를 지각하면 → **빨아들이는 것이 합리적**이다.
- 칸이 이미 깨끗하면 → **다른 곳으로 이동하는 것이 합리적**이다.
- **배터리가 부족하면 → 먼지가 남아 있어도 충전 도크로 돌아가는 것이 합리적이다.**
- 이런 행동을 통해 에이전트는 **환경을 바꾼다** — 먼지를 제거하거나 자기 위치를 바꾼다.
- 환경이 불확실하거나 정보가 불완전해도, 에이전트는 **가진 정보로 행동해야 한다.** 많은 시스템에서 에이전트는 **시간·효율·완결성 사이에서 트레이드오프**를 한다.

### 합리적 ≠ 완벽 ⭐
- **합리적이라는 것은 완벽하다는 뜻이 아니다.** 지금 아는 것을 근거로 최선의 행동을 고른다는 뜻이다.
- 합리적 에이전트는 **지각 이력(precept history)과 세계에 대한 지식**을 근거로 **기대 성능 측도를 최대화하는** 행동을 고른다.
- 로봇 청소기는 감지할 수 있는 것, 프로그래밍된 이동 방식, 저장 가능한 이력에 **제한된다.**
- **합리성은 전지(omniscience)를 요구하지 않는다.** 지각이 불완전하거나 오해를 부르면 **합리적으로 선택하고도 틀릴 수 있다.** 중요한 것은 **가진 정보로 볼 때 그 선택이 타당했는가**다.

### 에이전트 함수 vs 에이전트 프로그램 ⭐
| | 에이전트 함수(agent function) | 에이전트 프로그램(agent program) |
|---|---|---|
| 무엇인가 | **모든 지각 이력 → 행동**의 추상적 대응 | 실제 구현 — 하드웨어 위에서 도는 코드와 알고리즘 |
| 비유 | 성능 측도를 최대화하기 위한 **이상적 청사진** | 그 청사진을 실현하려는 **현실의 시도** |
| 예 | "목표까지 가장 빠른 최단 경로를 찾는다" | 실제 로봇 위에서 도는 코드. 하드웨어·알고리즘 선택·계산 시간·버그에 제약된다 |

> **합리성은 프로그램이 아니라 함수를 기준으로 판단한다.** 합리적 행동이란 가진 정보로 최선의 결과를 고르는 것이기 때문이다. 다만 **실제로 이상에 얼마나 가까워지는지는 프로그램이 결정한다.**

### 예시 — 배달 드론이 실패하는 방식
- **함수**: 비행 금지 구역과 악천후를 피해 **가장 짧고 안전한 경로**로 배달한다.
- **프로그램**: GPS로 배달지를 찾고, **A\* 탐색**으로 최단 경로를 계산하고, 10분마다 경로를 갱신한다.

프로그램이 실패할 수 있는 지점 셋:

1. **센서 오독** — 강풍을 약한 바람으로 잘못 읽어 날씨가 안전하다고 지각한다
2. **알고리즘의 타협** — 계산 시간을 아끼려고 모든 경로를 유효하다고 받아들여 **고도 제한을 위반**하고 제한 공역으로 들어간다
3. **갱신 주기 부족** — 10분 주기가 **급변하는 날씨**를 따라가지 못한다

> 즉 AI는 아직 진화 중인 분야이고, 기여할 여지가 많다는 것이 강의의 마무리다.

---

## 요약
- 합리적 에이전트 = **지각 → 처리 → 목표 달성 가능성을 최대화하는 행동**. 핵심은 **지각-행동 루프**.
- 구성 요소 셋: **지각(precepts) · 성능 측도 · 행동 전략**.
- **합리성은 문맥 의존적**이다. 배터리가 낮으면 먼지를 남기고 복귀하는 것이 합리적이다.
- **합리적 ≠ 완벽 ≠ 전지.** 불완전한 지각 때문에 틀려도, 가진 정보로 타당했다면 합리적이다.
- **에이전트 함수**(이상적 대응)와 **에이전트 프로그램**(실제 구현)은 다르다. 합리성은 함수로 판단하고, 현실의 성능은 프로그램이 좌우한다.
