## 내용

### 합리성이란 곧 불확실성 아래의 좋은 결정
- AI의 본질은 **불확실성 아래에서 좋은 결정을 내리는 것**이다. 그것이 정확히 합리성(rationality)의 뜻이다 — **가진 지식과 자원 안에서 기대 성능(expected performance)을 최대화하는 행동을 고르는 것.**

| 시스템 | 합리적 행동의 모습 |
|---|---|
| 자율주행차 | 보행자를 보고 감속하기로 결정한다 |
| 금융 트레이딩 AI | 위험과 수익의 균형을 잡는다 |
| 언어 모델 | 학습한 문맥을 근거로 **다음에 올 확률이 가장 높은 단어**를 고른다 |

### 규칙으로 짠 합리성 → 학습한 합리성 ⭐
- **초기 AI**: 합리성을 명시적 규칙으로 **하드코딩**했다. `if this, then that`. **좁은 영역에서만** 작동했다.
- **현대 AI**: 합리적으로 행동하는 법을 **데이터에서 학습**한다.
  - **딥러닝** 시스템은 **지각(perceive)** 을 학습한다 — 음성·이미지·제스처 인식
  - **강화학습** 시스템은 **행동(act)** 을 학습한다 — 장기 보상을 최대화할 다음 행동 결정
- 핵심: **학습을 하더라도 여전히 최적화(optimizing)를 하고 있다.** 최선의 기대 결과를 향해 행동한다.
  - 즉 **합리성은 그대로 있고, 프로그래밍된 것에서 학습된 것으로 바뀌었을 뿐이다.**

### 합리적 에이전트라는 틀
지능적 시스템을 설계하려면 **합리적 에이전트(rational agent)** 로 형식화한다 — 환경을 지각하고 목표 달성을 위해 행동하는 개체. 이 틀이 던지는 질문 넷:

1. 세계의 **상태(state)** 는 무엇인가?
2. 어떤 **행동(action)** 이 가능한가?
3. **목표 또는 효용 함수(utility function)** 는 무엇인가?
4. 에이전트는 선택지 중 **어떻게 고르는가**?

- 방을 돌아다니는 로봇 = 경로를 최적화하는 에이전트
- 추천 시스템 = 사용자에게 최선의 선택지를 고르는 에이전트
- 언어 모델 비서도 **계획하고 행동을 실행하는 에이전트 프레임워크로 감쌀 수 있다**

### 그리고 탐색(search)이 등장한다 ⭐
- 목표와 행동을 정의했다면, 다음 과제는 **어떻게 최선의 행동을 고를 것인가**다. 여기서 **탐색**이 나온다.
- **탐색 = 가능한 행동과 결과를 탐험해 성공으로 가는 경로를 찾는 과정.**

| 고전 알고리즘 | 실제 쓰임 |
|---|---|
| 너비 우선 탐색(BFS) | 지도의 경로 계획 — 그래프 탐색 |
| A* 탐색 | 로봇 모션 플래닝 — 휴리스틱 탐색 |
| 탐욕 최선 우선 탐색 | 〃 |

- AlphaZero 같은 게임 AI는 **심층 신경망이 안내하는 탐색**을 쓴다.
- 한 문장: **탐색은 합리적 에이전트가 "무엇이 최선인지 아는 것"에서 "실제로 그것을 찾아내는 것"으로 넘어가는 방법이다.**

### 딥러닝·생성형 모델 안에도 합리성이 있다
- **강화학습 에이전트** — 명시적으로 합리적 행동을 하도록 설계된다. 경험을 통해 기대 누적 보상을 최대화한다.
- **심층 신경망** — 더 큰 합리적 에이전트 시스템 안에서 **지각 또는 예측 부품**으로 쓰인다(객체 탐지, 확률 추정 등).
- **대형 언어 모델(LLM)** — 그 자체로는 에이전트가 아니다. 하지만 **목표와 피드백이 있는 루프로 감싸면** 합리적 에이전트처럼 동작한다 — 문맥을 지각하고, 응답을 결정하고, 사용자 목표를 향해 행동한다.

> 합리성과 탐색이라는 틀이 답하게 해 주는 질문 — **이 AI 시스템은 무엇을 이루려 하는가 / 잘 되고 있는지 어떻게 측정하는가 / 그 행동을 어떻게 설명 가능하고 가치 체계에 정렬되게 만들 것인가.**

---

## 요약
- 현대 AI(자율주행·챗봇·의료 진단·게임 AI)는 전부 **지각 → 결정 → 행동**으로 성공을 최대화하는 **합리적 행동**의 사례다.
- 초기 AI는 합리성을 규칙으로 하드코딩했고 좁은 영역에서만 작동했다. **현대 AI는 합리성을 데이터에서 학습한다.** 그래도 **여전히 최적화**다.
- 합리적 에이전트 틀의 네 질문: 상태 / 가능한 행동 / 목표·효용 함수 / 선택 방법.
- **탐색은 "최선이 무엇인지"에서 "그것을 실제로 찾기"로 넘어가는 수단**이다. 이 강좌의 나머지가 탐색이다.
- LLM 자체는 에이전트가 아니지만 **목표와 피드백 루프로 감싸면** 합리적 에이전트가 된다.
