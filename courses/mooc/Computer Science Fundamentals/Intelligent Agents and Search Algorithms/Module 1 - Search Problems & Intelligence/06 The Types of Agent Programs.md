# 06 The Types of Agent Programs

## 개요
- 강좌: Intelligent Agents and Search Algorithms (University of Colorado Boulder)
- 모듈: Module 1 — Search Problems & Intelligence
- [MOOC 원본 강의](https://www.mooc.org/learn/intelligent-agents-and-search-algorithms/lecture/QQe9b/the-types-of-agent-programs)
- 에이전트 프로그램의 **네 가지 기본 유형**과 그 성질. 뒤로 갈수록 앞의 것 위에 하나씩 쌓인다.

---

## 내용

### 1. 반사 에이전트(reflex agent)
- **가장 단순한 형태.** 자극-반응 기계처럼 동작한다 — `if 조건 then 행동`.
- 예: **온도조절기(thermostat)**. 온도가 임계값 아래로 떨어지면 히터를 켠다. 지정 온도·지정 시각을 설정할 수 있어 똑똑해 보이지만, **여전히 조건에 프로그래밍된 행동으로 반응하는 것뿐**이다.
- 예: 플레이어가 보이면 항상 플레이어 쪽으로 움직이는 **비디오 게임의 단순한 적**.

| | |
|---|---|
| 강점 | **구현이 쉽고 빠르다** |
| 약점 | **본 적 없는 상황을 다루지 못하고, 과거 상태를 기억하지 못한다** |
| 한계 | **취약(brittle)하다.** 즉각적인 지각 너머의 세계를 추적하지 않기 때문에 복잡하거나 예측 불가한 환경에서 실패한다 |

### 2. 모델 기반 에이전트(model-based agent)
- **세계의 내부 모델(internal model)** 을 유지한다.
- 덕분에 **부분 관측(partial observability)** 을 다룰 수 있다 — 모든 것이 한 번에 보이지 않는 상황.
- 예: **로봇 청소기**가 이미 청소한 구역을 내부 모델로 기억한다. 2×2 격자 위에 있다면 어느 칸이 깨끗하고 어느 칸이 더러운지 알고 **더러운 칸만 지나는 경로**를 잡는다.
- 이 **내부 상태(internal state)** 가 직접 볼 수 없는 것에 대해 추론하게 해 준다.

### 3. 목표 기반 에이전트(goal-based agent) ⭐
- 그냥 반응하는 대신 **목표(goal)** 로 결정을 인도한다. 던지는 질문 — **"어떤 행동의 연쇄가 내 목표를 달성할까?"**
- 대표 예: **경로 탐색 앱.** 목적지까지 최선의 경로를 찾아야 한다. 가능한 경로들을 추론하고 "좌회전" "직진" 같은 행동을 고른다.
- **여기서 탐색 알고리즘이 등장한다** — 에이전트가 **가능한 미래 상태를 탐험해** 다음에 무엇을 할지 정한다.
- 만약 경로 전체를 미리 안다면 문제는 단순하다. **더 흥미로운 문제는 장애물이나 예기치 못한 상황을 우회하는 경로를 찾는 것**이다.

### 4. 효용 기반 에이전트(utility-based agent)
- 목표를 넘어선다. **목표를 달성하는 경로가 여럿이지만 다 똑같이 좋지는 않을 때** 필요하다.
- **효용 함수(utility function)** 로 결과에 순위를 매기고 트레이드오프를 한다. 각 결과에 **좋음의 수치**를 부여하고 **기대 효용이 가장 높은 행동**을 고른다.
- 예: 자율주행차는 **속도·안전·승차감·합법성**의 균형을 잡아야 한다. 전체 기대 효용이 최선인 행동을 고른다.
- 예: 가정용 **스마트 에너지 관리기**. 온도 선호·전기 요금·탄소 배출을 함께 고려해 언제 냉난방을 돌리고 언제 배터리를 충·방전할지 정한다.

### 학습 에이전트(learning agent) — 별도 범주가 아니다
- 위 네 유형 **모두** 학습 에이전트로 확장될 수 있다. **행동의 별도 범주가 아니라 덧씌우는 층(overlay)** 이고, 시간이 지나며 개선되게 해 준다.
- 구성:
  - **성능 요소(performance element)** — 실제 작업을 수행
  - **학습 요소(learning element)** — 어떻게 개선할지 알아냄
  - **비평자(critic)** — 피드백 제공
- 예: **이메일 스팸 필터.** 단순하게 시작하지만 사용자가 스팸으로 표시하는 것을 계속 학습한다.

### 네 유형 비교 ⭐
| 유형 | 기억 | 목표 | 효용 함수 | 예 |
|---|---|---|---|---|
| 반사 에이전트 | ✗ | ✗ | ✗ | 온도조절기 |
| 모델 기반 에이전트 | **✓** | ✗ | ✗ | 로봇 청소기 |
| 목표 기반 에이전트 | ✓ | **✓** | ✗ | 경로 탐색 앱 |
| 효용 기반 에이전트 | ✓ | ✓ | **✓** | 자율주행차, 스마트 에너지 관리기 |

> **각 단계가 앞 단계 위에 쌓인다.** 복잡한 환경에서 더 유연하고 더 합리적이 된다.

---

## 요약
- 네 유형: **반사 → 모델 기반 → 목표 기반 → 효용 기반.** 순서대로 기억 → 목표 → 효용이 더해진다.
- **반사 에이전트**는 빠르고 쉽지만 기억이 없어 취약하다.
- **모델 기반**은 내부 모델로 부분 관측을 다룬다.
- **목표 기반**에서 **탐색 알고리즘이 필요해진다.** 이 강좌의 나머지가 여기서 출발한다.
- **효용 기반**은 여러 목표 사이의 트레이드오프를 수치로 다룬다.
- **학습 에이전트**는 별도 유형이 아니라 네 유형 모두에 덧씌울 수 있는 층이다(성능 요소 + 학습 요소 + 비평자).
