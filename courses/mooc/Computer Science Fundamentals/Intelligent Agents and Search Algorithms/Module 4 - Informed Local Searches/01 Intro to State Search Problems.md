# 01 Intro to State Search Problems

## 개요
- 강좌: Intelligent Agents and Search Algorithms (University of Colorado Boulder)
- 모듈: Module 4 — Informed Local Searches
- [MOOC 원본 강의](https://www.mooc.org/learn/intelligent-agents-and-search-algorithms/lecture/fSo4E/intro-to-state-search-problems)
- 지금까지와 **다른 종류의 탐색 문제** — 해가 **경로가 아니라 상태 하나**인 **배치 문제(configuration problem)**.

---

## 내용

### 두 번째 종류의 탐색 문제 ⭐
- 지금까지 다룬 문제: 해가 **행동의 연쇄(sequence)**, 즉 시작 상태에서 목표 상태까지의 **경로**였다.
- 이 모듈에서 다루는 문제: **해가 연쇄가 아니라 상태 하나**다. 제약 집합을 만족하거나 목적을 충족하는 **어떤 상태**를 찾는 것이 목표이고, **거기까지 간 경로는 상관없다.**

| | 경로 문제 | **배치 문제** |
|---|---|---|
| 해 | 시작→목표의 **행동 연쇄** | **최종 상태 하나** |
| 필요한 것 | 상태, 행동, 전이 모델, 목표 검사, **경로 비용** | **상태**(모든 가능한 배치의 인코딩) + **목표 검사** |
| 경로 비용 | 있음 (비교·최소화 대상) | **없음** — 도달 경로의 비용을 비교하지 않는다 |
| 묻는 것 | **배치에 어떻게 도달하는가** | **좋은 배치란 어떤 모습인가** |

### 예제 셋
| 문제 | 상태 | 목표 |
|---|---|---|
| **8-퀸(8 queens)** | 퀸 8개의 특정 배치 | **어떤 두 퀸도 서로 공격하지 않는** 배치. 퀸을 하나씩 놓은 순서는 무의미하고 **최종 배치만** 중요하다 |
| **그래프 색칠(graph coloring)** | 노드 → 색의 매핑 | **인접한 노드가 같은 색을 갖지 않는** 배치 |
| **스케줄링** | 대학이 강의를 강의실·시간에 배정 | 큰 수업 둘이 같은 강의실에 겹치지 않고, **교수가 이중 예약되지 않고**, 같은 학년 필수 과목이 겹치지 않는 배치 |

> 세 문제 모두 **고려할 의미 있는 경로가 없다. 최종 배정만이 중요하다.**

### 상태를 어떻게 표현하는가 — 8-퀸 예시 ⭐
- 상태 = 8×8 체스판 위 퀸 8개의 배치.
- **간결한 표현**: 길이 8의 배열. **i번째 원소 = i열에 있는 퀸의 행 위치.**
  - 첫 원소가 2 → 1열의 퀸은 2행
  - 두 번째 원소가 4 → 2열의 퀸은 4행
- 이 표현은 **열마다 퀸이 정확히 하나**임을 보장한다. **한 열 안의 불법 상태나 중복을 아예 고려하지 않는다.**

**그런데도 상태 수가 엄청나다**
```
퀸 하나당 가능한 행 위치 8개 × 퀸 8개 = 8^8 = 1,600만 가지 이상
```
> **이미 같은 열에 여러 퀸이 오는 불법 배치를 제거한 뒤의 수**다.
>
> **교훈: 배치 문제의 상태 공간은 중복을 줄이도록 표현을 구조화해도 여전히 조합적(combinatorial)이다.**

### 그래서 지역 탐색(local search)을 쓴다
이런 문제의 탐색 알고리즘은 **지역 탐색 방법**을 쓴다.

- **상태 공간에서 직접 작업한다**
- **휴리스틱 함수 또는 목적 함수로 상태를 평가한다**
- **현재 상태에서 더 나은 이웃 상태로 이동을 시도한다**

> 이렇게 하면 **탐색 트리 전체를 열거하지 않고**, 계산을 **후보 배치 하나를 개선하는 데** 집중할 수 있다.

### 현실의 배치 문제들
| 응용 | 내용 |
|---|---|
| **클라우드 스케줄링·자원 배분** | 가상 머신을 실행할 서버 집합이 주어지고, 작업을 CPU·GPU 클러스터에 배정한다. 해는 **작업↔자원 매핑 배치**로, 서버 과부하를 피하고 지연·코로케이션 제약을 최소화하며 에너지 사용을 줄인다 |
| **차량 경로(vehicle routing)** | 배송 회사의 경로 계획. 어느 기사가 어느 배송을 맡는가, 트럭에 어떤 순서로 싣는가, 어느 물류센터가 어느 경로를 준비하는가. 제약: **시간창, 적재 용량, 기사 근무 제한, 연료·거리 효율** |
| **무선 네트워크 주파수 배정** | 기지국과 Wi-Fi가 **인접 송신기끼리 간섭하지 않도록** 채널 주파수를 배정하고 대역폭을 공평하게 나눈다. **구조적으로 그래프 색칠 문제와 같다** — 색 대신 무선 주파수일 뿐 |

### 지역 탐색 방법들 (이 모듈에서 다룰 것) ⭐
| 방법 | 핵심 아이디어 |
|---|---|
| **언덕 오르기(hill climbing)** | 가장 단순한 형태. **완전한 후보 해에서 시작**해 평가 점수를 개선하는 **작은 수정**을 가한다. 개선하는 이웃이 없으면 멈춘다 |
| **무작위 재시작(random restarts)** | 언덕 오르기를 **여러 무작위 시작점에서 여러 번** 돌리고 **최선을 택한다** |
| **시뮬레이티드 어닐링(simulated annealing)** | **가끔 더 나쁜 상태도 받아들여** 지역 최적에서 빠져나온다. 나쁜 상태를 받아들일 확률은 **시간이 갈수록 줄어든다** |
| **유전 알고리즘(genetic algorithms)** | **후보 상태의 집단(population)** 을 유지하고, 집단의 조각들을 **조합해** 더 높은 적합도의 새 집단을 만든다 |
| **메타휴리스틱(metaheuristics)** | 크고 울퉁불퉁한(rugged) 최적화 공간에서 탐색을 안내하는 **일반적 탐색 프레임워크** |

---

## 요약
- **배치 문제**는 해가 **경로가 아니라 상태 하나**다. 제약을 만족하는 배치를 찾고 **경로 비용은 없다.**
- 예: **8-퀸 · 그래프 색칠 · 스케줄링.** 현실 응용: 클라우드 자원 배분, 차량 경로, **무선 주파수 배정(= 그래프 색칠)**.
- 8-퀸을 열별 행 배열로 간결히 표현해도 **상태가 1,600만 개 이상** — 배치 문제의 상태 공간은 **조합적**이다.
- 그래서 **지역 탐색**을 쓴다 — 탐색 트리를 열거하지 않고 **후보 배치 하나를 반복 개선**한다.
