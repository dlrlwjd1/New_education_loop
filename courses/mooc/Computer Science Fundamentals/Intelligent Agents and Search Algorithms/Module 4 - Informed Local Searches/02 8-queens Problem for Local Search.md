# 02 8-queens Problem for Local Search

## 개요
- 강좌: Intelligent Agents and Search Algorithms (University of Colorado Boulder)
- 모듈: Module 4 — Informed Local Searches
- [MOOC 원본 강의](https://www.mooc.org/learn/intelligent-agents-and-search-algorithms/lecture/30e5N/8-queens-problem-for-local-search)
- **지역 탐색**의 개념과 가장 단순한 알고리즘 **언덕 오르기(hill climbing)**.

---

## 내용

### 지역 탐색이란
> **상태 공간을 관통하는 완전한 경로를 탐험하는 대신, 현재 상태 하나를 개선하는 데 집중하는 최적화 전략.**

- BFS나 A*처럼 초기 상태에서 시작해 목표까지 경로를 쌓는 것이 아니라, **완전한 후보 해(들)에서 시작**해 **목적 함수에 따라 더 나은 해가 되도록 반복 수정**한다.

### 언덕 오르기(hill climbing)
- **한 번에 상태 하나만 메모리에 유지**한다.
- **이웃 상태**(현재 상태에 작은 변화를 가해 도달할 수 있는 상태)를 평가한다.
- **목적 함수 기준으로 더 나으면 그 이웃으로 이동**한다. 그것이 메모리에 저장되는 새 상태다.
- **목적 함수가 더 개선되지 않을 때까지** 반복한다.

**주요 한계**
> **지역 지형(local landscape)만 볼 수 있어 상태 공간 전체를 볼 수 없다.**

지형이 단순하면 잘 작동하지만, 많은 최적화 지형은 **울퉁불퉁(rugged)** 하다.

| 지형 특징 | 뜻 |
|---|---|
| **지역 최대(local maxima)** | 가장 높지 않은데 주변보다 높은 지점 |
| **고원(plateaus)** | 위로 향하는 방향이 없는 **평평한 영역** |
| **능선(ridges)** | 개선하려면 **먼저 내려갔다가** 다시 올라가야 하는 지형 |

> **언덕 오르기는 탐욕적이다.** 해를 개선하는 걸음만 딛기 때문에 **쉽게 갇힌다.**

### 8-퀸에 적용하기 ⭐
| 항목 | 내용 |
|---|---|
| **목적 함수** | **서로 공격하는 쌍(attacking pairs)의 수.** 이 값을 **최소화**한다 |
| **이웃 해** | **퀸 하나를 자기 열 안에서 다른 행으로 옮긴** 판 배치 |

**절차**
1. **무작위 판 배치**에서 시작
2. 그 배치의 **공격 쌍 수를 계산**
3. **각 퀸을 자기 열의 다른 행으로 옮기는 경우를 모두 고려**하고, **충돌이 가장 적어지는 수**를 고른다
4. 개선이 없을 때까지(충돌 쌍이 더 줄지 않을 때까지) 반복

> 놀랍게도 꽤 잘 작동하지만 **항상은 아니다.** 많은 무작위 시작 상태에서 언덕 오르기는 **어떤 단일 이동도 충돌을 줄이지 못하는 지점**에 도달하는데, **더 나은 해는 아직 찾지 못한 상태**다. 이것이 **지역 최적**이다.
>
> **언덕 오르기는 해가 맞아서 멈추는 것이 아니라, 더 나은 이웃을 찾지 못해서 멈춘다.**
>
> 많은 탐색 문제에서 **순수 언덕 오르기는 무작위성이나 재시작으로 보강하지 않으면 자주 실패한다.**

### 다른 예 — 배송 경로 문제
배송 회사가 매일 도시의 여러 지점에 물건을 배달한다. 기사는 **창고에서 출발해 모든 배송지를 들르고 창고로 돌아온다.** **외판원 문제(TSP)의 변형**에 현실 제약이 붙은 형태다.

**현실 제약**
- 시간대별로 다른 **교통 상황**
- **배송 시간창** (예: 정오까지 배달)
- **일방통행·공사 중인 도로**
- **차량 제약** — 냉장 트럭은 신선식품을 먼저 배달해야 한다

> 8-퀸과 달리 **해마다 품질이 다르다.** 어떤 해는 유효하지만 다른 해보다 비싸다. 목표는 **총 경로 비용 최소화**다.

| 항목 | 내용 |
|---|---|
| **목적 함수** | **이동 시간 + 지연 배송 + 교통 지체**의 비용. 제약은 **모든 물건이 배달되어야 함** |
| **이웃 해** | 현재 경로에 **작은 변화**를 준 것 — 배송지 **두 개 교환(swap)**, 경로 **한 구간 뒤집기(reverse)**, 한 지점을 **다른 위치에 삽입(insert)** |

**예시**: 현재 경로가 창고 → A, B, C, D → 창고이고 비용이 있다. **B와 C를 교환한 이웃 경로**를 생성해 목적 함수를 계산한다. 그 비용이 **개선인지, 제약을 여전히 만족하는지** 보고 새 현재 경로로 저장할지 정한다.

### 언덕 오르기를 개선하는 전략들
기본 언덕 오르기는 **지역 최적에 취약하다.** 이웃 해가 비용을 개선하지 못하는 지점에 도달하지만 **전역 최적은 아닌** 상황이다.

| 전략 | 내용 |
|---|---|
| **무작위 재시작 언덕 오르기** | 여러 무작위 시작점에서 여러 번 돌리고 **최선의 결과를 보관** |
| **개선하지 않는 해도 일부 수용** | 가끔 **내리막(downhill)이나 옆걸음(sideways)** 이동을 허용해 지역 최적을 탈출. → **시뮬레이티드 어닐링** |
| **확률적 언덕 오르기(stochastic hill climbing)** | 개선하는 이웃 해 중 **하나를 무작위로** 고른다 |
| **집단 기반 알고리즘** | **해의 집단**을 조합해 새 해를 만들고 좋은 것을 보존 → **유전 알고리즘** |

> 어느 방식이든 **언덕 오르기의 핵심 아이디어는 그대로다 — 지역적 조정으로 상태 하나를 개선한다.**

## 요약
- **지역 탐색** = 완전한 후보 해에서 시작해 **목적 함수에 따라 반복 개선**. 경로가 아니라 상태를 다룬다.
- **언덕 오르기** = 상태 하나만 유지하고 **더 나은 이웃으로 이동**, 개선이 없으면 정지. 빠르고 메모리 효율적.
- 한계: **지역 지형만 본다.** 지역 최대·고원·능선에서 갇힌다. **해가 맞아서가 아니라 더 나은 이웃이 없어서 멈춘다.**
- **8-퀸**: 목적 함수=공격 쌍 수(최소화), 이웃=퀸 하나를 같은 열 다른 행으로.
- **배송 경로**: 목적 함수=시간·지연·지체 비용, 이웃=교환·구간 뒤집기·삽입.
- 개선 전략: **무작위 재시작 · 옆걸음/내리막 허용 · 확률적 선택 · 집단 기반**.
