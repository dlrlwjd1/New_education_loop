## 내용

### 지역 탐색과 무엇이 다른가 ⭐
| | 언덕 오르기 등 전통 지역 탐색 | **유전 알고리즘** |
|---|---|---|
| 다루는 것 | **한 번에 해 하나** | **후보 해의 집단(population)** |
| 방식 | 점진적 변화를 가하고 개선을 수락 | **적합도 높은 해들을 조합**해 새 해 생성 |

> 집단 기반 알고리즘의 전제: **나쁜 해라도 쓸모 있는 부분 해(partial solution)를 담고 있을 수 있다.**
>
> 그래서 **탐색 공간의 여러 영역을 동시에 탐험하고, 좋은 조각들을 병합해 더 나은 해를 만든다.**

### 생물학에서 가져온 세 개념
| 개념 | GA에서의 뜻 |
|---|---|
| **돌연변이(mutation)** | 개별 후보 해에 **작은 무작위 변화**를 가한다. **집단에 다양성(diversity)을 도입**하는 것이 목적 |
| **교차(crossover)** | 기존 해 **두 개의 조각을 결합**해 새 후보 해를 만든다. 기존 해 = **부모(parents)**, 새 해 = **자식(child)** |
| **자연선택(natural selection)** | **더 적합한 개체가 다음 세대를 만들 확률이 높다.** 적합도가 높은 해가 선택될 확률이 높고, **시간이 지나며 집단 전체의 적합도가 올라간다** |

### 해를 어떻게 인코딩하는가
- **초기 집단** = 무작위 생성된 상태 **k개**의 집합.
- 각 해는 **염색체(chromosome)** 를 흉내 낸다. 인코딩은 **유한한 알파벳에서 뽑은 문자열**이다.

**8-퀸의 인코딩 두 가지**

| 방식 | 내용 |
|---|---|
| **순열(permutation) 인코딩** | 8개 숫자의 순열. **인덱스 = 체스판의 열(0~7), 값 = 그 열에서 퀸이 있는 행.** 순열이므로 **각 행이 최대 한 번만 등장** → **구조적으로 두 퀸이 같은 행을 공유하지 않는다** |
| **이진(binary) 인코딩** | 8×8 체스판을 만들고 **1 = 그 위치에 퀸, 0 = 빈 칸.** 염색체는 판을 펼친 **64자리 1/0 문자열** |

### 적합도 함수(fitness function)
- 집단의 각 염색체를 **적합도 함수**로 평가한다. **GA에서 목적 함수를 부르는 말**이며, **적자생존** 개념에 기반한다.
- **더 적합한 개체가 낮은 적합도 개체보다 번식할 확률이 높다.**

**8-퀸 예시**
- 적합도 함수 = **서로 공격하지 않는 쌍(non-attacking pairs)의 수.** **최적값은 28.**
- 후보 4개의 적합도가 각각 **23, 23, 20, 11**이라면,
- **흔한 방식은 번식 확률을 적합도 점수에 정비례**시키는 것이다.

### 교차(crossover) — 가장 중요한 연산자 ⭐
**재조합(recombination)** 이라고도 한다. **두 부모 해의 정보를 섞어 새 후보 해**를 만들며, **각 부모의 좋은 특징을 물려받도록** 설계된다.

> 계산적 근거: **두 해가 각각 좋은 부분 구조를 담고 있다면, 결합했을 때 어느 한쪽 부모보다 나은 해가 나올 수 있다.**

| 방식 | 내용 | 장점 | 단점 |
|---|---|---|---|
| **단일점 교차<br>(single-point)** | 염색체를 따라 **무작위 위치(교차점)** 를 하나 골라 두 부모를 그 지점에서 자른다. **부모1의 앞부분 + 부모2의 뒷부분**으로 자식 하나, 반대로 자식 하나 (총 2개) | **연속된 구간에 좋은 부분 해가 있는 문제**에서 올바른 교차점을 고르면 그것을 보존한다 | **교차점을 잘못 고르면** 좋은 구간을 **파괴**한다 |
| **다중점 교차<br>(multi-point)** | **두 개 이상의 교차점**을 골라 부모의 구간을 번갈아 취한다. 예: 2·3번째 사이와 6·7번째 사이 | **좋은 빌딩 블록이 여러 곳에 있을 때** 유용. 단일점보다 **섞임이 많다** | 단일점보다 **기존 해를 더 많이 교란**할 수 있다 |
| **균등 교차<br>(uniform, 위치별 독립)** | 교차점을 고르지 않고 **각 위치를 독립적으로 결정**한다. 흔한 방법: **확률 0.5로 부모1의 유전자를, 아니면 부모2의 것을** 취한다 | **위치 간 연관(positional linkage)이 없는 문제**에 효과적. 각 위치를 독립으로 다룰 수 있을 때 | 좋은 구간이 **여러 위치에 걸쳐 있으면 파괴**한다. 확률이 잘못 조정되면 **무작위 섞기처럼** 행동한다 |
| **순서 교차<br>(order crossover)** | **부모1에서 부분 해를 선택**해 그대로 자식에 복사하고, **나머지 위치는 부모2에서 미사용 원소들의 상대 순서**대로 채운다. 예: 부모1의 `4-8-5` 시퀀스를 보존하고 나머지를 부모2에서 채운다. **모든 숫자는 한 번씩만** 사용 | **부모1의 절대 위치**와 **부모2의 상대 순서**를 함께 보존 | — |

### 돌연변이(mutation)
- **해에 작은 무작위 변화**를 가한다.
- **교차의 위험**: 문제가 부분 해로 잘 분해되지 않을 때 **교차가 해를 파괴할 수 있다.** 이런 경우 **돌연변이가 해 품질에 극적인 영향**을 준다.
- 8-퀸에서의 예: **일부 해에서 퀸 하나의 위치를 바꾼다.**
- 예시 흐름: 부모 두 개 → **단일점 교차**로 자식 생성 → 자식 하나에 **돌연변이 적용**(5번째 열의 퀸을 8행에서 1행으로) → 다음 세대 집단에 추가.

### 한 라운드 실행 예 (8-퀸, 집단 4개)
- 각 염색체는 퀸이 놓인 행·열의 순열이고, **왼쪽 숫자가 적합도 점수**다(예: 첫 염색체 24).
- **단일점 교차** 사용. **한 염색체가 서로 다른 교차점으로 두 번 쓰일 수 있다** — 두 번째 염색체가 `327` 뒤와 `32752` 뒤에서 각각 한 번씩.
- **적합도 11인 마지막 염색체는 번식에서 제외**되었다. ⚠️ **다만 실제 시스템에서는 낮은 적합도 해도 선택될 기회가 있다.**
- 교차 결과 **쌍마다 새 염색체 2개**가 생긴다. 마지막으로 **돌연변이 적용** —
  - 첫 염색체: 돌연변이가 **교차 과정에서 생긴 중복을 제거**했다
  - 세 번째 염색체: 돌연변이가 **중복을 만들어** 그 해의 적합도를 **떨어뜨렸다**

### 세대 진행 예 (집단 7개)
- 각 염색체에 적합도 점수가 있고, **번식 선택 확률은 적합도에 정비례**한다.
  - 적합도 **10**인 염색체 둘 → 확률 각 **약 7%**
  - 적합도 **25**인 염색체 → 확률 **약 18%**
- **선택된 염색체가 가장 높은 점수들만은 아니다.** 낮은 적합도 염색체 하나도 선택됐다.
- 다음 세대에서 인덱스 4·5·6에 새 염색체 3개가 생긴다. 4·5는 이전 세대 **5와 0의 자식**, 6은 **3과 2의 자식**이다.
- ⭐ **0과 5에서 나온 두 자식의 적합도가 25와 13으로 크게 갈렸다** — **교차가 매우 다른 결과를 만들 수 있음**을 보여 준다.
- 다음 세대에도 높고 낮은 적합도의 자식이 섞여 생기지만, **집단의 평균 적합도는 상승**했고 **최고 기록도 25 → 26으로 올랐다.**

### GA를 튜닝하는 어려움 ⚠️
| 어려움 | 내용 |
|---|---|
| **탐험 vs 활용(exploration vs exploitation)** | **탐험 과다**(높은 돌연변이율, 큰 다양성) → **무작위 탐색처럼** 행동하고 좋은 해를 다듬을 만큼 안정되지 않는다. **활용 과다**(낮은 돌연변이율, 지나치게 공격적인 고성능 해 선택) → **조기 수렴**해 지역 최적에 갇히고, **낮은 적합도 염색체의 부분 해를 포함할 방법이 없어진다** |
| **표현과 연산자 선택** | 표현이 **유용한 빌딩 블록을 보존하지 못하거나** 교차가 좋은 하위 구조를 교란하면 GA는 진전을 못 낸다. **도메인도 중요하다** — 한 도메인에서 훌륭한 것이 다른 도메인에서 완전히 실패할 수 있다 |
| **집단 크기** | **작은 집단**은 빨리 진화하지만 **다양성을 잃는다.** **큰 집단**은 다양성을 보존하지만 **느리고 계산이 비싸다** |
| **파라미터는 독립적이지 않다** | **돌연변이율은 표현과 상호작용**하고, **교차 효과는 집단 다양성에 달려 있고**, **선택 압력은 집단 크기와 상호작용**한다 |

> GA는 강력한 탐색 방법이지만 **효과적으로 쓰려면 실험과 도메인 지식이 필요하다.**

### 실무 튜닝 전략 ⭐
| 전략 | 내용 |
|---|---|
| **표준 기준값에서 시작** | **집단 크기 50~수백**, **돌연변이율 1~5%**, **교차율 70~90%** 가 흔한 출발점이다 |
| **최종 적합도만이 아니라 집단의 행동을 관찰** | **너무 빨리 수렴**(모든 염색체가 비슷해짐) → **다양성이 붕괴 중.** 처방: **돌연변이 증가 · 선택 압력 감소 · 집단 크기 증가.** **진전이 느리거나 불규칙**하면 반대로 조정 |
| **한 번에 파라미터 하나만 조정** | 작은 조정이 **비선형으로 상호작용**한다. 여러 개를 동시에 바꾸면 **어느 변화가 무슨 영향을 줬는지 알 수 없다** |
| **파라미터 스위핑(parameter sweeping)** | 돌연변이율의 효과를 보려면 **다른 파라미터를 모두 고정**하고 돌연변이율만 조금씩 바꿔 여러 번 돌려 결과를 관찰한다 |
| **문제 도메인 이해** | **표현과 교차 연산자가 그 문제에서 중요한 빌딩 블록을 반영**해야 한다. 예: 8-퀸에서는 **해를 보존하는 교차 전략**이 **같은 행에 퀸을 여러 개 만드는 교차**보다 효과적이다 |
| **여러 번 돌려 안정성 확인** | 올바른 파라미터는 **여러 실행에 걸쳐 안정적인 결과**를 낸다. GA를 여러 번 돌려 **일관되게 고품질 해에 수렴**해야 한다 |

## 요약
- **GA = 집단 기반 알고리즘.** 한 해가 아니라 **후보 해의 집단**을 유지하며, **적합도 높은 해들을 조합**해 세대를 거듭한다. 전제는 **나쁜 해도 쓸모 있는 부분 해를 담는다**는 것.
- 세 연산: **돌연변이**(다양성) · **교차**(부모 조각 결합) · **자연선택**(적합도 비례 번식 확률).
- 8-퀸 인코딩: **순열**(열=인덱스, 행=값 — 같은 행 중복이 구조적으로 방지) 또는 **64자리 이진 문자열**. 적합도 = **비공격 쌍 수, 최적 28**.
- 교차 방식: **단일점 · 다중점 · 균등 · 순서 교차.** 각각 **좋은 구간을 보존하는 능력과 파괴 위험**이 다르다.
- **교차가 해를 파괴할 수 있는 문제에서는 돌연변이가 결정적**이다.
- 튜닝의 핵심은 **탐험과 활용의 균형**. 기준값: **집단 50~수백, 돌연변이 1~5%, 교차 70~90%**. **한 번에 하나씩** 조정하고 **여러 번 돌려 안정성**을 본다.
