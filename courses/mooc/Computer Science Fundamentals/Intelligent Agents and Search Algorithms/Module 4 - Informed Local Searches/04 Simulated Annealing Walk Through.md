# 04 Simulated Annealing Walk Through

## 개요
- 강좌: Intelligent Agents and Search Algorithms (University of Colorado Boulder)
- 모듈: Module 4 — Informed Local Searches
- [MOOC 원본 강의](https://www.mooc.org/learn/intelligent-agents-and-search-algorithms/lecture/qPBeu/simulated-annealing-walk-through)
- **시뮬레이티드 어닐링(simulated annealing)** — 금속 풀림(annealing)에서 착안한 알고리즘. **온도**로 탐험과 수렴을 조절한다.

---

## 내용

### 착안한 물리 현상 — 금속 풀림
- 금속을 **높은 온도로 가열**하면 원자가 자유롭게 움직인다. 그다음 **천천히 냉각**하면 원자가 **더 낮은 에너지 상태로 자리 잡는다.**
- **아주 천천히 조심스럽게 냉각**하면 원자들이 재배열할 시간이 충분해 **가능한 가장 낮은 에너지 배열 — 잘 정렬된 결정 구조**가 된다.
- **너무 빨리 냉각하면** 원자들이 **무작위하거나 불완전한 배열에 갇힌다.** → **전역 최소가 아니라 지역 최소**에 해당한다.

### 알고리즘이 이를 흉내 낸다
| 단계 | 알고리즘의 상태 |
|---|---|
| **높은 온도로 시작** | **들뜬(excited) 상태.** 넓게 탐험하며 **오르막·내리막 전이를 많이 받아들인다** |
| **점진적으로 냉각** | 시간이 갈수록 **보수적**이 된다 |
| **낮은 온도로 종료** | 탐색 공간의 **정제된 영역에서 언덕 오르기처럼** 행동한다 |

### 핵심 루프 ⭐
1. **무작위 초기 상태**에서 시작하고 **초기 온도 T**를 설정
2. 종료 조건이 만족될 때까지 반복:
   - **무작위 이웃 상태**를 하나 고른다
   - **목적 값의 변화(ΔE)를 계산**한다
   - **변화가 양(개선)이면 → 받아들인다**
   - **변화가 음(악화)이어도 → 확률적으로 받아들인다.** 그 확률은 **변화량의 크기와 현재 온도**로 계산한다
   - **냉각 스케줄**에 따라 **온도 T를 점진적으로 낮춘다**

> **이 확률 함수가 시뮬레이티드 어닐링의 심장이다.**
> **T가 크면 나쁜 해도 받아들여질 수 있다. T가 줄면 내리막 이동은 점점 드물어진다.**

### 냉각 스케줄 네 가지
| 방식 | 내용 | 강점 | 약점 |
|---|---|---|---|
| **지수 감쇠(exponential decay)** | T에 **1에 가까운 조정 가능한 계수**를 곱한다 | 단순·매끄럽고 **널리 쓰인다.** 예측 가능하게 식는다 | **민감하다.** 계수를 잘못 고르면 **너무 빨리 얼거나 너무 오래 헤맨다** |
| **선형 감쇠(linear decay)** | 매 반복마다 **일정량을 뺀다** | 균일해서 **추론하기 쉽다** | **경직됐다.** 지형이 복잡하면 **초반엔 너무 빠르고 후반엔 너무 느릴** 수 있다 |
| **로그 감쇠(logarithmic decay)** | — | **이론적으로 최적.** 충분히 천천히 식히면 **전역 최적 수렴을 보장** | **대부분의 실제 문제에는 너무 느리고 계산적으로 매우 비싸다** |
| **적응형 스케줄(custom adaptive)** | **탐색이 겪는 상황에 따라** 온도를 조정(예: 최근 ΔE 값 사용) | **반응적이다.** 진전이 좋으면 빨리 식히고, **정체되면 늦춘다** | **복잡하다.** 더 많은 튜닝과 세심한 모니터링이 필요 |

> 각 방식은 **탐험과 효율의 균형을 다르게** 잡는다. 최선의 선택은 **문제 구조에 달려 있다.**

### 실행 예시 — 배송 경로 (5개 지점)
- 창고 = A, 나머지 지점 = B, C, D, E. 경로는 **창고에서 시작해 모두 방문하고 창고로 복귀**.
- **초기 온도 50, 지수 냉각 스케줄.** 예: B와 C 사이 거리는 35.
- **이웃 해 생성 방법**: 경로 중간의 **두 도시를 교환(swap)**.

| 단계 | 경로 | 비용 | 판정 | 온도 |
|---|---|---|---|---|
| 초기 | A→B→C→D→E→A | **$116** | — | 50 |
| 1 | A→C→E→D→B→A | **$94** | **개선 → 수락** | 50 → **40** |
| 2 | A→C→D→E→B→A | **$88** | **개선 → 수락** | 40 → **32** |
| 3 | (새 경로) | **$105** | **악화** (현재 88보다 높음) — 그런데 **확률 약 59%로 수락 가능** | — |

> **3단계가 핵심이다.** 표준 언덕 오르기라면 이 해를 버린다. 시뮬레이티드 어닐링은 **비용 차이와 현재 온도로 계산한 확률(≈59%)로 여전히 받아들일 수 있다.**
>
> **코드로 구현하는 법**: 1~100 사이의 난수를 생성해 **59 이하면 수락**하고 새 현재 해로 삼는다. **60~100이면 버리고** 현재 해를 유지한다.

- 이 장난감 문제의 **최적 비용은 88**이었다. 노드가 5개뿐이라 알고리즘이 빠르게 찾았다.

### 종료 조건 네 가지
| 조건 | 내용 |
|---|---|
| **온도가 최소 임계값 도달** | **가장 고전적인 정지 규칙** (T < T_min). 온도가 충분히 낮아지면 알고리즘은 사실상 탐욕적 언덕 오르기처럼 행동하므로 더 탐험할 이유가 없다 |
| **최대 반복 횟수** | **예측 가능한 실행 시간**을 보장한다 |
| **개선 정체** | x회 반복 동안 **개선이 없거나** 온도가 변하지 않으면 정지. 해가 사실상 **정체(stagnate)** 될 때까지 돌린다 |
| **목표 품질 도달** | **목표 해 비용**을 정해 두고 도달하면 종료 |

## 요약
- **금속 풀림 비유**: 고온 → 원자 자유 이동, 서서히 냉각 → 최저 에너지 결정 구조. **급랭하면 지역 최소에 갇힌다.**
- 핵심 루프: 무작위 이웃 선택 → ΔE 계산 → **개선이면 수락, 악화여도 확률적으로 수락** → 온도 감소.
- **수락 확률은 변화량과 현재 온도의 함수다.** T가 크면 나쁜 해도 잘 받아들이고, T가 줄면 내리막 이동이 드물어진다.
- 냉각 스케줄: **지수(널리 쓰임·민감) · 선형(단순·경직) · 로그(이론상 최적·너무 느림) · 적응형(반응적·복잡)**.
- 종료 조건: **최소 온도 · 최대 반복 · 개선 정체 · 목표 품질 도달.**
