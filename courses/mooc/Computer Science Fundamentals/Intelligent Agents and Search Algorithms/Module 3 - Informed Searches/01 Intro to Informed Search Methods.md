# 01 Intro to Informed Search Methods

## 개요
- 강좌: Intelligent Agents and Search Algorithms (University of Colorado Boulder)
- 모듈: Module 3 — Informed Searches
- [MOOC 원본 강의](https://www.mooc.org/learn/intelligent-agents-and-search-algorithms/lecture/OutXY/intro-to-informed-search-methods)
- **휴리스틱(heuristic)** 으로 탐색을 유도하는 **정보 이용 탐색**의 개념과, 최적성을 위해 휴리스틱이 만족해야 할 **세 가지 조건**.

---

## 내용

### 왜 정보를 더하는가
- 탐색 문제가 크면 **맹목적으로 노드를 확장하는 것은 비싸다.**
- 정보 이용 탐색은 **휴리스틱** 형태로 문제에 대한 지식을 더한다.

> **휴리스틱 = 어떤 상태에서 목표까지 남은 비용의 빠른 추정치.**

- 모든 것을 균일하게 탐험하는 대신 **유망해 보이는 쪽에 우선순위를 준다.**
- **좋은 휴리스틱의 조건 둘: 계산이 빠르고, 실제 남은 비용과 상관이 높다.**

| 문제 | 좋은 휴리스틱 |
|---|---|
| 지도 기반 경로 탐색 | 노드에서 목표까지의 **유클리드 거리** 또는 **맨해튼 거리**. 목표에 가까운 노드를 우선한다 |
| 체스 | **중앙 칸 장악(control of the center)**. 중앙을 잡는 수를 그렇지 않은 수보다 우선한다 |
| 8-타일 퍼즐 | **제자리에 없는 타일의 개수**로 수의 품질을 추정 |

### 목적 함수 (objective / evaluation function) ⭐
노드의 **좋음(goodness)** 을 재는 척도다. 두 부품으로 이루어진다.

| 기호 | 뜻 |
|---|---|
| **g(n)** | **시작 노드에서 n까지 이미 든 비용.** 균일 비용 탐색이 쓰는 값. 이미 이동한 거리 |
| **h(n)** | **휴리스틱.** n에서 목표까지의 **추정** 비용. 근거 있는 추측 |

| 알고리즘 | 목적 함수 |
|---|---|
| 균일 비용 탐색 | **g(n)만** |
| **탐욕 최선 우선 탐색** | **h(n)만** — 이미 이동한 비용을 고려하지 않는다 |
| **A\*** | **g(n) + h(n)** — 둘 다 쓴다 |

> 균일 비용 탐색과 비교하면 — 그쪽은 **최적성이 보장되지만 지수적 비용**이 든다. 정보 이용 탐색의 목적은 **목표에 도달하기까지 확장해야 하는 노드 수를 줄이는 것**이다.

### 휴리스틱이 만족해야 할 조건 ⭐
탐색 알고리즘이 최적이려면 휴리스틱이 아래를 만족해야 한다.

**1. 목표에서 0**
- 에이전트가 목표에 가까워질수록 거리가 줄어야 하므로 **목표는 0으로 평가**한다.
- 따라서 **음수 값을 가져서는 안 된다.**

**2. 허용 가능성 (admissibility)**
> **휴리스틱이 노드에서 목표까지의 비용을 절대 과대평가하지 않는다.**
>
> `h(n) ≤ (n에서 목표까지의 실제 비용)`

**3. 일관성 (consistency, 단조성 monotonicity)**
> **삼각 부등식(triangle inequality)** 을 따른다. 시작에서 목표까지의 경로 비용이 **비감소(non-decreasing)** 다.
>
> 임의의 노드 n에 대해: `h(n) ≤ cost(n → n') + h(n')`

- 뜻: **한 노드까지의 최단 경로가 확정되면, 이전 노드들을 거쳐 돌아가서 더 짧은 경로를 찾는 일은 없다.**

### 핵심 정리
- 정보 이용 탐색은 **효율을 위해 휴리스틱을 활용**한다. **좋은 휴리스틱은 무정보 탐색 대비 확장 노드 수를 몇 자릿수(orders of magnitude)나 줄일 수 있다.**
- 반대로 **나쁜 휴리스틱을 쓰면 정보 이용 탐색이 무정보 탐색보다 나을 게 없어진다.**
- 노드의 품질은 **목적 함수**가 결정하며, 여기에 **h(n)(목표까지 추정 비용)과 g(n)(시작까지의 실제 비용)** 이 들어갈 수 있다.

---

## 요약
- **휴리스틱 h(n)** = 상태에서 목표까지 남은 비용의 **빠른 추정치**. 좋은 휴리스틱은 **계산이 싸고 실제 비용과 상관이 높다.**
- 목적 함수는 **g(n)**(이미 든 비용)과 **h(n)**(남은 추정 비용)으로 구성된다. 균일 비용=g만, 탐욕 최선 우선=h만, **A\*=g+h**.
- 최적성을 위한 휴리스틱 조건 셋: **목표에서 0(음수 불가) · 허용 가능성(과대평가 금지) · 일관성(삼각 부등식)**.
- 좋은 휴리스틱은 확장 노드를 몇 자릿수 줄이지만, **나쁜 휴리스틱은 무정보 탐색 수준으로 떨어뜨린다.**
