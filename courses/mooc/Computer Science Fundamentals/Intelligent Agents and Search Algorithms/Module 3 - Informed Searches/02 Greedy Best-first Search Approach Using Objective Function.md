# 02 Greedy Best-first Search Approach Using Objective Function

## 개요
- 강좌: Intelligent Agents and Search Algorithms (University of Colorado Boulder)
- 모듈: Module 3 — Informed Searches
- [MOOC 원본 강의](https://www.mooc.org/learn/intelligent-agents-and-search-algorithms/lecture/mwapk/greedy-best-first-search-approach-using-objective-function)
- **탐욕 최선 우선 탐색(greedy best-first search)** — 휴리스틱만 보고 목표에 가장 가까워 보이는 노드를 확장한다. **빠르지만 최적을 보장하지 않는다.**

---

## 내용

### 목적 함수는 휴리스틱뿐
> 탐욕 최선 우선 탐색의 목적 함수는 **오직 h(n)** 에만 의존한다. 즉 **에이전트를 목표에 가장 가깝게 만드는 행동**을 취한다.

| 알고리즘 | 목적 함수 |
|---|---|
| 균일 비용 탐색 | g(n) — **경로 비용만** |
| **탐욕 최선 우선 탐색** | **h(n) — 휴리스틱만** |
| A* | g(n) + h(n) — **둘 다** |

### 잘 되는 경우
- A가 시작, J가 목표인 단순한 그래프. 각 노드에 목표까지의 **유클리드 거리**가 휴리스틱 값으로 붙어 있다.
- **C의 휴리스틱 값이 B보다 낮으므로** 알고리즘은 B보다 C를 먼저 고른다(목표에 더 가깝다는 뜻).
- B·F·I 노드가 프론티어에 들어가지만, 경로가 단순해서 **탐욕 알고리즘이 쉽게 목표를 찾는다.**

### 실패하는 경우 ⭐
- A에서 두 선택지: **X1(비용 0.72)** 과 **B(비용 0.84)**.
- 탐욕 에이전트는 **더 낮아 보이는 X1**을 고르고, 값이 계속 감소하는 경로를 따라간다 — **X1 → X2 → X3 → X4 → 목표**.
- 그런데 **이것은 최단 경로가 아니다.** 처음에 더 길어 보였던 **B를 지나는 더 짧은 경로를 놓쳤다.**
- 목표에 도달했을 때 **B는 여전히 프론티어에 남아 있고, 최종 해에 포함되지 않는다.**

> **탐욕 최선 우선 탐색이 최적해를 놓치는 고전적 사례다. 항상 목표에 가장 가까워 보이는 수를 택하다가, 처음엔 나빠 보였던 수를 놓친다.**

### 성질
| 항목 | 값 |
|---|---|
| 완전성 | **유한 그래프에서는 완전하다.** 해가 있으면 찾는다 |
| 최적성 | **아니다.** 목적 함수에 **누적 비용을 절대 반영하지 않으므로** 쉽게 준최적 경로를 낸다 |
| 최악의 시간·공간 | **탐색 트리 깊이에 대해 지수적.** 휴리스틱이 정보가 없거나 오도할 때 이렇게 되며, **무정보 탐색과 비슷한 성능**이 된다 |
| 최선의 경우 | 좋은 휴리스틱이면 **탐색 공간의 일부만 탐험** — 목표까지 거리에 대략 **선형** |

### 한계
- **휴리스틱 품질에 민감하다.** 나쁜 휴리스틱 → 나쁜 해.
- **비슷한 목적 함수 값을 가진 노드가 많은 탐색 공간**에서는 헤매다가 목표를 빨리 못 찾을 수 있다.
- **지역 최적(local optima)에 빠지기 쉽다** — 휴리스틱 값이 줄다가 다시 늘어나는 상황. 위 실패 예시가 정확히 이것이다.
- **되돌아갈(backtrack) 능력이 없어 갇힌다.** 예시에서 B 노드로 되돌아가 확장해 더 짧은 경로를 찾을 방법이 없었다. 시작 노드에서의 첫 수에 묶여 그대로 진행할 수밖에 없었다.

### 잘 쓰는 경우
- **휴리스틱이 매우 유익할 때(정보를 많이 줄 때)** 잘 작동한다. 이때는 **괜찮은 경로를 빠르게** 낸다. 최적은 아닐 수 있지만 쓸 만한 경로다.

### 관련 알고리즘
- **A\*** — 허용 가능하고 일관적인 휴리스틱이면 **속도와 최적성의 균형**을 잡는다.
- **빔 탐색(beam search)** — 각 레벨에서 **상위 노드만 유지해 확장**하는 탐욕 알고리즘.

---

## 요약
- 탐욕 최선 우선 탐색 = **h(n)만 보고** 목표에 가장 가까워 보이는 노드를 확장. g(n)은 무시한다.
- **유한 그래프에서 완전하지만 최적이 아니다.** 누적 비용을 안 보기 때문이다.
- **지역 최적에 빠지고 되돌아갈 수 없다** — 처음에 나빠 보인 경로가 실제로 더 짧아도 놓친다.
- 성능이 **휴리스틱 품질에 전적으로 달려 있다.** 좋으면 선형에 가깝고, 나쁘면 무정보 탐색 수준.
- 해결책은 **g와 h를 함께 쓰는 A\***.
