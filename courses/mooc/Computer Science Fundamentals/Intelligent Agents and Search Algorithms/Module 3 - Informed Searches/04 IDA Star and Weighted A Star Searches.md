# 04 IDA* and Weighted A* Searches

## 개요
- 강좌: Intelligent Agents and Search Algorithms (University of Colorado Boulder)
- 모듈: Module 3 — Informed Searches
- [MOOC 원본 강의](https://www.mooc.org/learn/intelligent-agents-and-search-algorithms/lecture/wOdqm/ida-and-weighted-a-searches)
- A*의 두 한계(**메모리**와 **속도**)를 각각 겨냥한 두 변형 — **IDA\*** 와 **가중 A\***.

---

## 내용

### A*의 두 가지 한계
| 한계 | 내용 |
|---|---|
| **메모리 사용** | 생성한 **모든 노드를 메모리에 유지**한다. 100×100 격자 경로 계획이나 3D 공간 로봇 내비게이션 같은 큰 문제에서는 **해를 찾기 훨씬 전에 메모리가 바닥난다** |
| **속도** | 최적해를 내지만 **매우 느릴 수 있다.** 조심스럽게 탐험하며 **최적 프론티어 근처의 많은 노드를 확장**한다. 실제 AI 문제에서는 **약간 준최적이어도 빠른 해**가 더 바람직한 경우가 많다 |

> **IDA\*는 메모리 요구를 줄이고, 가중 A\*는 시간 복잡도를 줄인다.** 둘 다 트레이드오프가 따른다.

### IDA* (Iterative Deepening A*) ⭐

**핵심 아이디어**
> 큰 우선순위 큐를 유지하는 대신, **비용 임계값(threshold)으로 제한된 깊이 우선 탐색을 여러 번** 수행한다. 임계값은 **A\*의 f = g + h 공식**으로 계산한다.

**절차**
1. 임계값을 **시작 노드의 f 값**(시작에서는 곧 휴리스틱 값)으로 설정
2. **DFS를 수행**하되, **목적 함수 비용이 임계값을 넘는 가지는 잘라낸다**
3. 목표를 못 찾으면, **임계값을 넘었던 f 값 중 가장 작은 값**으로 임계값을 올린다
4. **시작 노드부터 다시** 반복

> 이렇게 하면 **한 번에 경로 하나만 메모리에 유지**한다. open/closed 리스트 전체를 담지 않는다. 상태 공간을 반복해서 탐험하므로 **시간은 더 들지만 메모리는 제한된다.**

**동작 예시** (색: 현재 노드=노랑, 프론티어=주황, 확장 완료=파랑, 잘린 가지=빨간 X)

휴리스틱은 **남은 단계 수**다.

1. **1회차 (임계값 = 4, 시작 노드의 h 값)**
   - B 노드의 f 값이 **6**으로 임계값 초과 → 가지 잘림
   - A의 다른 자식 C1, X1도 f 값이 임계값 초과 → 잘림
   - A에서 더 탐험할 가지가 없으므로 **초기화**하고, 임계값을 **이전 회차에서 임계값을 넘은 값 중 최소인 5**로 올린다
2. **2회차 (임계값 = 5)**
   - 시작 노드부터 **앞선 작업을 반복**하되 더 높은 임계값으로
   - X2까지 확장했다가 컷오프에 걸림 → X1으로 되돌아가 다른 가지 시도, Y1을 프론티어에 추가
   - 다시 임계값에 걸림 → **임계값을 7로 올려 재시작**
3. **3회차 (임계값 = 7)** — 해를 찾고 종료

**복잡도 비교**
| 항목 | IDA* vs A* |
|---|---|
| 시간 | **약간 더 높다** — DFS 패스를 반복하기 때문 |
| 공간 | **DFS와 비슷 — 재귀 스택 크기에 선형.** A*의 지수적 요구보다 **극적으로 낫다** |
| 최적성 | **휴리스틱이 허용 가능하면 최적 유지** |

> 요약: **IDA\*는 메모리가 병목인 큰 문제로 A\*를 확장 가능하게 만든다.**

### 가중 A* (Weighted A*) ⭐

**핵심 아이디어**
> 메모리가 아니라 **최적성을 속도와 맞바꾼다.** 휴리스틱에 **가중치 w > 1** 을 붙인다.

```
f(n) = g(n) + w · h(n)      (w > 1)
```

- 휴리스틱의 영향력이 커져 **목표에 가까워 보이는 노드를 더 선호**하게 된다 — 최종 경로가 더 길어지더라도.
- **탐욕 최선 우선 탐색에 더 가깝게 행동하되, 더 통제된 방식**이다.
- **가중치가 클수록 빠르지만 해는 덜 최적**이 된다.

**가중치를 바꿔 가며 관찰**
- w = **1** → **일반 A\***
- w = 2, 2.5 → 중간
- w = **3** → 확장 노드가 **눈에 띄게 적다**

> 일반 A*(w=1)가 확장한 파란 노드 수와 w=3일 때를 비교하면 **A\*가 훨씬 많은 노드를 확장했음이 분명하다.** 작은 그래프에서의 예지만, **노드가 훨씬 많은 큰 그래프에서는 이 차이가 상당한 계산 시간 차이**가 된다.

**성질**
| 항목 | 값 |
|---|---|
| 완전성 | **✓** 모든 단계 비용이 양수면 |
| 최적성 | **w = 1일 때만 보장.** 그 외에는 **유계 준최적(bounded suboptimal)** — 해 비용이 **최적 비용의 w배를 넘지 않음이 보장**된다 |
| 성능 | 큰 그래프에서 일반 A*보다 **몇 자릿수 빠를 수 있다** |

### 두 변형 비교
| | IDA* | 가중 A* |
|---|---|---|
| 얻는 것 | **메모리 효율** | **속도와 유연성** |
| 치르는 대가 | **추가 시간** (반복 탐색) | **준최적 경로** |

> 실제 AI 시스템에는 실제 제약이 있다 — **메모리·시간·연산 자원.** 이 변형들은 알고리즘을 복잡한 문제에서 **확장 가능하게 만드는 방법**이다.

---

## 요약
- A*의 두 한계: **메모리(모든 노드 저장)** 와 **속도(조심스러운 확장)**.
- **IDA\*** — f 임계값으로 제한한 **DFS를 임계값을 올려 가며 반복**한다. **메모리는 재귀 스택에 선형**, 시간은 약간 증가, **허용 가능 휴리스틱이면 최적 유지.**
- **가중 A\*** — `f = g + w·h` (w>1). **빠르지만 유계 준최적** — 해 비용 ≤ w × 최적 비용.
- w=1이면 일반 A*. **w가 커질수록 확장 노드가 줄고 빨라지며 최적성에서 멀어진다.**
