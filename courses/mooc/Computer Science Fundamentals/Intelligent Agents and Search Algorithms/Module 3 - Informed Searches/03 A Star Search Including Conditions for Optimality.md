# 03 A* Search, Including Conditions for Optimality

## 개요
- 강좌: Intelligent Agents and Search Algorithms (University of Colorado Boulder)
- 모듈: Module 3 — Informed Searches
- [MOOC 원본 강의](https://www.mooc.org/learn/intelligent-agents-and-search-algorithms/lecture/iehNY/a-search-including-conditions-for-optimality)
- **A\* 탐색** — 경로 비용과 휴리스틱을 **둘 다** 쓴다. 이 강좌에서 가장 중요한 알고리즘이다.

---

## 내용

### 핵심 아이디어 ⭐
모든 노드 n에 값 **f(n)** 을 부여한다.

```
f(n) = g(n) + h(n)

g(n) = 시작 노드에서 n까지 도달하는 데 든 비용
h(n) = n에서 목표까지의 휴리스틱 추정 비용
```

| 알고리즘 | 쓰는 값 |
|---|---|
| 균일 비용 탐색 | **g(n)만** |
| 탐욕 최선 우선 탐색 | **h(n)만** |
| **A\*** | **둘 다** — 그 노드를 지나는 **전체 경로 비용**을 계산한다 |

### 동작 절차
1. 초기 노드에서 시작한다. **g(n)=0**이므로 함수 값은 휴리스틱 비용뿐이다
2. 그 노드를 **f(n)으로 정렬된 우선순위 큐**에 넣는다
3. **f(n)이 가장 작은 노드를 꺼내** 확장하고 후계 노드를 생성한다
4. 각 후계에 대해 **새로운 g, h, f 값을 계산**한다
5. 목표에 도달하면 **최저 비용 경로를 찾은 것**이다

**두 개의 집합을 유지한다**

| 집합 | 뜻 |
|---|---|
| **open list** | 프론티어 — 생성됐지만 아직 탐험되지 않은 노드 |
| **closed list** | 이미 탐험된 노드 |

> **노드가 closed list에 들어가면 그 노드까지의 최단 경로가 확정된 것**이고, 더 짧은 경로를 찾으려고 다시 방문할 이유가 없다.

### 최적성의 조건 ⭐
A*는 휴리스틱이 아래 **둘 다** 만족할 때 최적해를 찾는다.

| 조건 | 뜻 |
|---|---|
| **허용 가능성(admissibility)** | `h(n)`이 목표까지의 실제 비용을 **절대 과대평가하지 않는다** |
| **일관성(consistency)** | 모든 후계 n'에 대해 `h(n) ≤ cost(n → n') + h(n')`. 경로가 **비감소**다 |

> 두 조건이 모두 참이면 A*는 **최적이면서 효율적**이다 — **노드를 다시 열(reopen) 필요가 없다는 의미**에서. 한 노드까지의 최단 경로를 찾으면 더 짧은 경로는 존재하지 않는다.

### 평가
| 항목 | 값 |
|---|---|
| 완전성 | **✓** 해가 있으면 찾는다 |
| 최적성 | **✓** 단, 휴리스틱이 허용 가능하고 일관적일 때 |
| **주요 한계** | **메모리.** 생성한 **모든 노드를 메모리에 저장**하므로 요구량이 **지수적**이다 |

> 15-퍼즐 배치나 고해상도 지도 같은 큰 상태 공간에서는 **최종 해에 포함되지도 않는 수백만 노드가 프론티어에 쌓여 메모리를 잡아먹는다.** 이 때문에 A*는 일부 실제 시스템에서 비현실적이다.

### 실행 예시 — 20×20 격자 히트맵
- 시작 = 왼쪽 위 X, 목표 = 오른쪽 아래 X. 장애물은 작은 X들.
- **맨해튼 거리 휴리스틱**으로 A* 실행.
- 색상은 확장 순서 — **어두울수록 먼저, 밝을수록 나중**. 왼쪽 위가 어둡고 목표 근처가 밝다.
- 최종 경로는 흰 점 — 왼쪽을 따라 수직으로 내려가다 수평으로 가로지르고 다시 수직으로 목표에 닿는다.

| 측정 | 값 |
|---|---|
| **프론티어에 추가된 노드** | **213개** (각각 메모리를 소비) |
| **최종 해 경로의 노드** | **39개** |

> 확장된 노드 중 상당수가 **최종 해 근처가 아니었다.** 격자를 수평으로 넓게 가로지르며 가능한 선택지를 탐험했다.

### A* vs 탐욕 최선 우선 탐색 비교 (다른 격자)
| | A* | 탐욕 최선 우선 |
|---|---|---|
| 해 경로 길이 | **39** | **57 (준최적)** |
| 확장 노드 수 | **151** | **158** |

> 이 문제에서는 **A\*가 더 짧은 경로를 더 적은 확장으로** 찾았다.
>
> 탐욕 알고리즘이 A*보다 빠르고 메모리를 덜 쓰면서 괜찮은 해를 내는 문제도 물론 있다. **하지만 더 복잡한 문제에서는 탐욕 알고리즘이 현실의 장애물을 다루는 데 대체로 실패한다.**

### 그래도 남는 문제 — 메모리
- 20×20 격자에서 약 200개 노드를 확장했다.
- **50×50 격자라면** 확장 노드 수를 줄이도록 **알고리즘을 수정해야** 쓸 만해진다.

**두 가지 수정 방향** (다음 강의)

| 변형 | 고치는 것 | 방법 |
|---|---|---|
| **IDA\*** (반복 심화 A*) | **메모리** | 비용 임계값을 늘려 가며 **DFS를 반복**한다. 허용 가능 휴리스틱이면 **최적성은 유지**하면서 메모리를 크게 줄인다 |
| **가중 A\*** (weighted A*) | **속도** | 휴리스틱에 **1보다 큰 가중치**를 곱해 목표 쪽으로 더 강하게 유도한다. 확장 노드가 줄고 빨라지지만 **최적성을 일부 포기**한다 |

---

## 요약
- **f(n) = g(n) + h(n).** 이미 든 비용과 남은 추정 비용을 **함께** 본다.
- 우선순위 큐에서 **f가 가장 작은 노드**를 꺼내 확장. **open list**(프론티어)와 **closed list**(탐험 완료)를 유지한다.
- **허용 가능 + 일관적 휴리스틱이면 A\*는 완전하고 최적이며 노드를 재방문할 필요가 없다.**
- **최대 약점은 메모리** — 생성한 모든 노드를 저장하므로 지수적. 예시에서 해는 39노드인데 **213노드를 프론티어에 담았다.**
- 해결책: **IDA\***(메모리) 와 **가중 A\***(속도).
