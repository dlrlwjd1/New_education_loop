# Software Architecture

- 전문과정: Software Design and Architecture (Course 3)
- 제공: University of Alberta
- 구성: 3개 모듈, 영상 19개 — Transcript 기반 한국어 정리 완료
- 제외: 읽기 자료·퀴즈·Capstone 채점 과제

아키텍처 설계 과정과 Kruchten의 4+1 뷰 모델, UML 컴포넌트·패키지·배포·액티비티 다이어그램을 다룬 뒤, 추상 데이터 타입·메인 프로그램/서브루틴·계층형 시스템·클라이언트-서버 n-tier·인터프리터·파이프-필터·이벤트 기반·프로세스 제어 등 주요 아키텍처 스타일을 살펴본다. 마지막으로 품질 속성, 아키텍처 평가, 조직 구조와의 관계, 제품 라인까지 실무 적용을 다룬다.
