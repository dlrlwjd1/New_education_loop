# 1.2.5 – Decomposition

## 개요

- 분해(decomposition)는 전체(whole)를 여러 부분(part)으로 나누거나, 반대로 서로 다른 기능을 가진 부분들을 결합해 전체를 만드는 설계 원리다.
- 부분과 전체의 관계에서 고정(fixed)/동적(dynamic) 개수, 수명(lifetime) 관계, 공유(sharing) 여부가 중요한 이슈다.
- 자동차·냉장고 같은 일상 사물의 예로 분해를 연습한다.

## 내용

### 분해란

- 분해는 전체를 서로 다른 부분들로 나누는 것, 또는 반대로 서로 다른 기능을 가진 별개의 부분들을 결합해 전체를 만드는 것이다.
- 분해는 문제를 더 이해하고 해결하기 쉬운 조각으로 쪼갤 수 있게 한다. 설계 원리들은 서로 잘 어우러져 작동한다는 점도 기억하자.
- 일반 규칙: 어떤 전체의 서로 다른 책임(responsibilities)을 보고, 각자 고유한 책임을 가진 서로 다른 부분들로 어떻게 분리할 수 있는지 평가한다. 이는 하나의 전체를 여러 부분에 관련짓는다.

### 예시: 자동차와 냉장고의 부분들

- 자동차의 구성 부분: 변속기(transmission), 모터, 바퀴, 타이어, 문, 창문, 좌석, 연료 등.
- 냉장고의 부분: 캐비닛과 문, 압축기(compressor)와 코일, 냉동실(freezer), 제빙기(ice-maker), 선반, 서랍, 그리고 채워져 있다면 음식.
- 각 부분은 전체의 책임을 달성하도록 돕는 매우 구체적인 목적을 가진다. 냉장고의 부분들은 음식을 차게 보관·보존한다는 전체 목적을 위해 함께 작동한다.
- 전체가 특정 책임을 부분에 위임(delegate)하기도 한다. 냉장고는 음식의 냉동과 그 보관을 냉동실에 위임한다.

### 부분 개수: 고정 vs 동적

- 전체는 특정 종류의 부분을 고정된(fixed) 개수 또는 동적인(dynamic) 개수로 가질 수 있다.
- 고정이면 전체 객체의 수명 동안 정확히 그만큼의 부분 객체를 가진다. 예: 냉장고의 냉동실은 하나로 고정이며 시간이 지나도 변하지 않는다.
- 동적이면 전체 객체가 수명 동안 그 부분 객체의 새 인스턴스를 얻을 수 있다. 예: 냉장고의 선반이나 음식 개수는 시간에 따라 변할 수 있다.
- 자동차 연습: 일반적인 자동차는 어느 시점에나 핸들(steering wheel) 1개, 타이어 4개, 엔진 1개를 가지며 이 수는 변동하지 않는다(고정). 반면 승객 수는 변할 수 있으므로 동적이다.

### 부분이 다시 전체가 될 수 있다

- 부분 자체가 또 다른 구성 부분들을 담는 전체 역할을 할 수 있다. 냉장고 예시에서 서랍은 과일을 담을 수 있다.
- 자동차 예시: 계기판(instrument panel)은 연료 게이지(fuel gauge), 주행계(odometer), 속도계(speedometer) 등을 담는 부분이다.
- 또한 캡슐화(encapsulation) 덕분에 계기판은 각 계기를 블랙박스처럼 다루며, 그것들이 어떻게 구현되었는지 신경 쓰지 않는다.

### 수명(lifetime) 관계

- 분해에서 전체 객체와 부분 객체의 수명이 어떻게 관련되는지가 하나의 이슈다.
- 수명이 밀접하게 관련된 경우: 냉장고와 냉동실은 같은 수명을 가진다. 하나는 다른 것 없이 스스로 존재할 수 없다. 냉장고를 버리면 냉동실도 버려진다.
- 수명이 그다지 관련 없는 경우: 냉장고와 음식은 서로 다른 수명을 가지며 각자 독립적으로 존재할 수 있다.
- 자동차 연습: 수명이 밀접하게 관련된 부분은 차체 프레임(frame), 그렇지 않은 부분은 타이어.

### 공유(sharing)

- 여러 전체가 같은 부분을 동시에 공유할 수도 있다. 예: 어떤 사람이 한 가족에서는 딸이고 다른 가족에서는 배우자다. 두 가족은 별개의 전체로 여겨지지만 동시에 같은 부분을 공유한다.
- 그러나 공유가 불가능하거나 의도되지 않는 경우도 있다. 예: 냉장고 안의 음식이 동시에 오븐 안에 있을 수는 없다.

## 요약

- 분해는 문제를 더 작은 조각으로 나누는 것을 돕는다. 복잡한 전체는 별개의 더 단순한 구성 부분들로 조립될 수 있다.
- 부분 개수는 고정(냉동실 1개)일 수도, 동적(선반·음식·승객)일 수도 있다.
- 부분은 다시 다른 부분들을 담는 전체가 될 수 있다(계기판 예시).
- 전체와 부분의 수명은 밀접할 수도(냉장고–냉동실), 독립적일 수도(냉장고–음식) 있다.
- 부분은 여러 전체에 공유될 수도 있고(두 가족의 한 사람), 공유가 불가능할 수도 있다(냉장고 속 음식).
