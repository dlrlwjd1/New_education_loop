# Service-Oriented Architecture

- 전문과정: Software Design and Architecture (Course 4)
- 제공: University of Alberta
- 구성: 3개 모듈, 영상 17개 — Transcript 기반 한국어 정리 완료
- 제외: 읽기 자료·퀴즈·Capstone 채점 과제

서비스 지향 아키텍처(SOA)의 원칙과 웹 시스템의 진화·아키텍처, HTML/XML/JSON·HTTP·JavaScript·RPC·오브젝트 브로커 같은 웹 기술 기초를 다진 뒤, SOAP 기반 서비스 호출(WSDL·UDDI·BPEL)로 대표되는 전통적 웹 서비스 스택을 살펴본다. 마지막으로 REST 아키텍처 스타일과 REST 서비스 설계, 마이크로서비스 입문까지 이어지는 전문과정의 마지막 코스.
