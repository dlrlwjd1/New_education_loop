# 4.1.5 – HTML / XML / JSON

## 개요

- 웹 시스템에서 콘텐츠를 저장·표현하는 데 쓰이는 세 가지 일반적인 형식을 다룬다.
- HTML과 XML은 콘텐츠를 표현·구조화하는 마크업 언어(markup language)이고, JSON은 많은 웹 애플리케이션에서 쓰이는 경량 데이터 교환 형식(data interchange format)이다.
- 세 형식 모두 기계와 사람이 모두 읽을 수 있도록(machine and human-readable) 설계되었다.

## 내용

### 마크업 언어란

마크업 언어는 텍스트를 기계와 사람이 읽을 수 있는 방식으로 꾸며(adorn) 보통 의미나 구조를 더하기 위해 설계되었다.

- 특정 텍스트가 어떻게 해석되는지를 **태그(tag)** 로 표시한다. 태그는 어떤 의미나 목적을 위해 정의할 수 있는 표준 단어인 경우가 많다.
- 강의 예시: "service-oriented architecture"라는 텍스트에서 service-oriented는 형용사(adjective), architecture는 명사(noun)로 마킹.
- 마크업 언어에는 일반적으로 프로그래밍 문법이 없다. 태그만으로 단순 텍스트 파일을 컴퓨터가 다룰 수 있거나 사람이 이해할 수 있는 것으로 만든다.

### HTML (HyperText Markup Language)

웹 페이지의 텍스트는 HTML이라는 마크업 언어로 구조화된다.

- HTML은 텍스트의 **스타일링이 아니라 구조화**에 집중한다. 페이지 텍스트의 어느 부분이 제목(title), 헤딩(heading), 문단(paragraph)인지 표시하고, 웹 브라우저가 이를 적절히 렌더링한다.
- HTML에는 목적별로 미리 정의된 태그 집합이 있다.
- `DOCTYPE`은 모든 HTML 파일의 첫 줄에 필요하며, 콘텐츠가 HTML임을 브라우저에 알린다.
- 문서의 나머지는 `html` 태그 안에 담기고, 보통 **head**와 **body** 두 섹션으로 나뉜다.
  - head: 페이지가 사용하는 메타데이터(metadata)를 담는다.
  - body: 웹 페이지의 주요 콘텐츠와 정보 — 텍스트, 링크, 이미지, 목록 등 — 를 각각 적절히 태깅해 담는다.
- HTML 문서에는 스타일링 정보가 없다. 글꼴·색상 같은 미적 요소는 **CSS(Cascading Style Sheet)** 로 적용한다. CSS는 표준 HTML 태그를 참조해 해당 태그 안의 텍스트에 스타일을 적용하며, 별도의 CSS 파일 또는 HTML 문서 내부에 둘 수 있다.

### XML (Extensible Markup Language)

XML은 데이터를 저장하고 전송하기 위한 마크업 언어다.

- 다른 마크업 언어처럼 기계와 사람이 모두 읽을 수 있다.
- 일반적으로 웹 기반 시스템 안에서 구조화된 데이터를 보내는 데 쓰인다.
- 강의 예시: Jane이 John에게 보내는 쪽지(note)로, 제목(heading)은 "Reminder", 본문은 "Don't forget the dogs"인 XML 문서.
- XML 문서에 유효한 태그와 그 구조를 정의하는 **XML 스키마(schema)** 를 정의할 수 있다.

### JSON (JavaScript Object Notation)

JSON도 데이터를 저장·전송하는 형식이며, 역시 기계와 사람이 모두 읽을 수 있게 설계되었다.

- 큰 장점: JSON을 JavaScript 객체로, 또 그 반대로 쉽게 변환할 수 있다. JavaScript는 현대 웹 브라우저가 일반적으로 지원하는 인터프리터 언어(interpreted programming language)다.
- 그래서 JSON은 웹 브라우저와 서버 간 데이터 전송, 웹 애플리케이션 내 데이터 전달에 인기 있는 형식이다.
- JSON 데이터는 **이름-값 쌍(name-value pairs)** 으로 작성되고, JSON 객체는 중괄호(`{}`) 안에 쓴다.
- JSON 객체의 배열(array)도 가능하며, 배열은 대괄호(`[]`) 안에 쓴다.

## 예시

HTML 문서의 기본 구조(강의에서 설명한 요소들):

```html
<!DOCTYPE html>
<html>
  <head>
    <!-- 페이지가 사용하는 메타데이터 -->
  </head>
  <body>
    <!-- 텍스트, 링크, 이미지, 목록 등 주요 콘텐츠 -->
  </body>
</html>
```

모든 `p`(문단) 태그 안의 텍스트를 파란색으로 스타일링하는 CSS:

```css
p {
  color: blue;
}
```

Jane이 John에게 보내는 쪽지를 담은 XML 문서:

```xml
<note>
  <to>John</to>
  <from>Jane</from>
  <heading>Reminder</heading>
  <body>Don't forget the dogs</body>
</note>
```

이름-값 쌍으로 이루어진 person JSON 객체(John Doe, 15세, 좋아하는 색 red):

```json
{
  "name": "John Doe",
  "age": 15,
  "favoriteColor": "red"
}
```

JSON 객체 배열(여러 사람과 그 속성들):

```json
[
  { "name": "John Doe", "age": 15, "favoriteColor": "red" },
  { "name": "Jane Doe", "age": 17, "favoriteColor": "blue" },
  { "name": "Joe Doe", "age": 21, "favoriteColor": "green" }
]
```

## 요약

- 웹 기반 시스템의 일반적인 콘텐츠 형식은 HTML, XML, JSON이며 모두 기계와 사람이 읽을 수 있다.
- HTML과 XML은 텍스트를 태깅하는 마크업 언어다.
- HTML은 웹 페이지 텍스트를 구조화해 브라우저가 적절히 렌더링하게 하고, 스타일링은 CSS가 담당한다.
- XML은 일반적으로 데이터나 메시지를 구조화하는 데 쓰인다.
- JSON은 데이터를 키-값 쌍으로 표현하며 JavaScript 객체와 쉽게 상호 변환된다.
