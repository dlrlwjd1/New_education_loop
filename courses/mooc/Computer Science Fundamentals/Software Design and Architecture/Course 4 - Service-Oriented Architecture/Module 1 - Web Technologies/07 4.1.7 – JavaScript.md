# 4.1.7 – JavaScript

## 개요

- JavaScript는 다양한 목적에 쓰이는 언어지만, 이 강의는 HTML 문서에 임베드(embed)되어 웹 페이지를 인터랙티브하게 만드는 용도에 집중한다.
- JavaScript는 인터프리터 언어(interpreted language)로, 웹 브라우저가 런타임에 코드를 해석해 실행한다.
- 클라이언트 측(client side) 처리로 서버의 부담을 덜고, 사용자에게 더 효율적이고 사용성 높은 상호작용을 제공한다.

## 내용

### HTML에 임베드되는 JavaScript

- JavaScript는 HTML 문서 안의 `script` 태그 사이에 삽입할 수 있다. 강의 예시에서는 페이지의 버튼을 클릭하면 알림 상자(alert box) 팝업이 나타난다.
- 임베드된 JavaScript는 HTML 문서 내의 요소(element), 속성(attribute), 스타일(style), 콘텐츠를 수정할 수 있다.
- 임베드된 JavaScript는 브라우저가 HTML 문서를 로드할 때 실행하는 일련의 명령이라고 생각할 수 있다.

### 서버 왕복 없는 상호작용

- JavaScript가 없는 단순한 웹 페이지와 상호작용하려면 HTML 폼(form)으로 POST나 GET 요청을 제출해야 하고, 웹 서버가 새 HTML 문서로 응답한다. 브라우저가 새 문서를 받아 로드한 뒤에야 상호작용의 결과를 볼 수 있다.
- JavaScript가 임베드된 페이지의 상호작용은 훨씬 효율적이고 사용성도 좋다. 폼을 클라이언트 측에서 부분적으로 검사·처리할 수 있어, 브라우저가 서버의 새 페이지를 기다릴 필요가 없다. 임베드된 JavaScript가 이미 브라우저에 로드된 HTML 페이지를 동적으로 변경한다.
- 물론 일부 상호작용은 웹 서버와의 접촉이 필요하지만, 항상 필요한 것은 아니라는 점이 핵심이다.
- 임베드된 JavaScript는 브라우저에서 클라이언트 측으로 실행되기 때문에 웹 애플리케이션에 매력적이다. 모든 처리를 서버 측에서 하는 대신 일부를 클라이언트 측에서 수행해 처리 부담을 덜어낸다(offload).

### DOM을 활용한 예시 — 고양이 썸네일

조금 더 복잡한 예시: 보호소에서 입양 가능한 고양이들의 썸네일 이미지를 보여주는 페이지에서, 썸네일을 클릭하면 커지고 다시 클릭하면 썸네일 크기로 줄어들게 만든다.

- 이를 위해 **HTML 문서 객체 모델(Document Object Model, DOM)** 을 사용한다. 브라우저가 웹 페이지를 로드하면 HTML 문서는 문서 객체(document object)가 되고, JavaScript는 이 객체로 페이지의 요소와 콘텐츠를 얻고 수정할 수 있다. 문서 객체를 처리한 결과로 HTML 문서의 콘텐츠, 구조, 스타일이 변경될 수 있다.
- CSS 파일은 이미지의 기본 높이·너비를 설정한다.
- 동작 흐름(강의 설명):
  1. 페이지 로드 시 모든 이미지는 썸네일 크기이며, 이때 문서에 임베드된 JavaScript가 실행된다.
  2. 스크립트 첫 줄이 문서의 모든 이미지 요소를 얻어 리스트에 저장한다.
  3. `for` 루프가 리스트의 각 이미지 요소에 클릭 리스너(OnClickListener)를 추가한다. 이미지가 클릭되면 process element 함수가 호출된다.
  4. process element 함수는 이미지 크기 조절을 담당하는 **익명 함수(anonymous function)** 를 반환한다.
  5. 익명 함수는 이미지 요소의 현재 높이·너비를 확인한다. 클릭 시 이미지가 원래 크기의 25%면 높이·너비를 100%로 바꾸고, 100%면 다시 25%로 되돌린다.

### 기성 스크립트 활용

JavaScript를 잘 몰라도 활용할 수 있다. 신뢰할 수 있는 출처의 기성 스크립트를 찾아 그대로 쓰거나 사이트에 맞게 조금 수정하면 된다. 예를 들어 Disqus 같은 댓글 관리 서비스를 쓰면 사용자가 페이지에 댓글을 달고 운영자가 이를 관리(moderate)할 수 있는데, 가입 후 해당 페이지의 HTML 문서에 JavaScript를 복사해 붙여 넣기만 하면 된다.

## 예시

버튼 클릭 시 알림 상자를 띄우는 임베디드 JavaScript:

```html
<button onclick="alert('Hello!')">Click me</button>

<script>
  // script 태그 사이에 JavaScript를 임베드할 수 있다
</script>
```

클릭할 때마다 이미지가 25% ↔ 100% 크기로 토글되는 스크립트(강의에서 설명한 로직):

```html
<script>
  var images = document.getElementsByTagName("img");
  for (var i = 0; i < images.length; i++) {
    images[i].onclick = processElement(images[i]);
  }

  function processElement(img) {
    return function () {
      if (img.style.height === "25%") {
        img.style.height = "100%";
        img.style.width = "100%";
      } else {
        img.style.height = "25%";
        img.style.width = "25%";
      }
    };
  }
</script>
```

## 요약

- JavaScript는 HTML 문서에 임베드되어 브라우저에서 웹 페이지를 조작할 수 있다.
- 브라우저가 런타임에 해석하는 인터프리터 언어이며, DOM을 통해 문서의 콘텐츠·구조·스타일을 얻고 수정한다.
- 처리를 웹 서버에서 웹 브라우저로 덜어내(offload) 페이지 효율을 높이고, 서버 왕복 없이 더 인터랙티브한 경험을 제공한다.
- 신뢰할 수 있는 기성 스크립트(예: Disqus)를 복사해 붙여 넣는 것만으로도 기능을 추가할 수 있다.
- JavaScript와 HTML을 사용해 웹 페이지에서 서비스 접근을 삽입할 수 있다.
