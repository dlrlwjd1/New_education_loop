# Software Design and Architecture Specialization

- 플랫폼: MOOC
- 제공: University of Alberta
- 구성: 4개 코스, 12개 모듈, 영상 83개 — Transcript 기반 한국어 정리 완료
- 제외: 읽기 자료·퀴즈·Capstone 채점 과제

객체지향 설계의 기초 개념(추상화·캡슐화·분해·일반화)과 설계 원칙에서 시작해, 생성·구조·행위 디자인 패턴과 안티패턴, UML 기반 소프트웨어 아키텍처 표현과 주요 아키텍처 스타일, 마지막으로 웹 기술과 SOAP/REST 기반 서비스 지향 아키텍처(SOA)까지 이어지는 4개 코스 전문과정.

## 코스 구성

### Course 1 - Object-Oriented Design (영상 25개)

소프트웨어 아키텍트/설계자의 역할, 요구사항과 품질 속성 트레이드오프, 추상화·캡슐화·분해·일반화 등 객체지향 모델링 개념을 Java·UML로 구현하고, 결합도·응집도·정보 은닉 같은 설계 원칙을 다룬다.

- [Course 1 README](Course%201%20-%20Object-Oriented%20Design/README.md)
  - Module 1 - Object-Oriented Analysis and Design (6)
  - Module 2 - Object-Oriented Modeling (11)
  - Module 3 - Design Principles (8)

### Course 2 - Design Patterns (영상 22개)

디자인 패턴의 개념과 분류(생성·구조·행위), Singleton·Factory Method·Facade·Adapter·Composite·Proxy·Decorator 등 생성/구조 패턴, Template Method·State·Command·Observer 등 행위 패턴, MVC 패턴과 SOLID 원칙, 코드 스멜을 다룬다.

- [Course 2 README](Course%202%20-%20Design%20Patterns/README.md)
  - Module 1 - Introduction to Design Patterns - Creational & Structural Patterns (9)
  - Module 2 - Behavioural Design Patterns (5)
  - Module 3 - Working with Design Patterns & Anti-patterns (8)

### Course 3 - Software Architecture (영상 19개)

Kruchten의 4+1 뷰 모델과 UML 컴포넌트·패키지·배포·액티비티 다이어그램, 계층형 시스템·클라이언트-서버 n-tier·이벤트 기반 등 아키텍처 스타일, 품질 속성과 아키텍처 평가·제품 라인을 다룬다.

- [Course 3 README](Course%203%20-%20Software%20Architecture/README.md)
  - Module 1 - UML Architecture Diagrams (6)
  - Module 2 - Architectural Styles (9)
  - Module 3 - Architecture in Practice (4)

### Course 4 - Service-Oriented Architecture (영상 17개)

서비스 지향 아키텍처(SOA) 원칙과 HTML/XML/JSON·HTTP·JavaScript·RPC 등 웹 기술 기초, SOAP·WSDL·UDDI·BPEL 기반 전통적 웹 서비스, REST 아키텍처 스타일과 마이크로서비스 입문을 다룬다.

- [Course 4 README](Course%204%20-%20Service-Oriented%20Architecture/README.md)
  - Module 1 - Web Technologies (9)
  - Module 2 - Web Services (5)
  - Module 3 - REST Architecture for SOA (3)
