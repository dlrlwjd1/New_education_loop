# Deploy ML Models to Production

**Course URL:** [mooc.org/learn/model-deployment-production-operations-for-mlops](https://www.mooc.org/learn/model-deployment-production-operations-for-mlops)

MOOC / KodeKloud. "Hands-On MLOps Fundamentals for ML Engineers" 스페셜라이제이션의 세 번째이자 마지막 코스(Course 3 of 3). 실험적인 노트북과 견고한 프로덕션 환경 사이의 간극을 메우는 것을 목표로, 모델 서빙(온라인/오프라인, 모델 드리프트), 데이터 보안·거버넌스(GDPR 등 규제 준수), AWS SageMaker를 활용한 클라우드 기반 ML 운영을 다루는 3개 모듈로 구성. 강사는 Mumshad Mannambeth(실제 영상 내레이터는 Raghunandan Asano로 자기소개).

## 모듈 구성
- [Module 1 - Model Serving](Module%201%20-%20Model%20Serving/) — 모델 서빙·배포 개요, 모델 드리프트, 온라인/오프라인 서빙 비교, TensorFlow Serving/TorchServe/BentoML 비교, BentoML 실습(모델 서빙, v1→v2 업그레이드, 멀티 버전 라우팅)
- [Module 2 - Data Security and Governance](Module%202%20-%20Data%20Security%20and%20Governance/) — 모니터링 도구(Prometheus/Grafana/Evidently), 데이터 프라이버시·보안, 데이터 접근 관리, 데이터 보존, GDPR/HIPAA/PCI 컴플라이언스와 실제 벌금 사례, Pre-Launch Audit 롤플레이
- [Module 3 - Sneak Peek into AWS SageMaker](Module%203%20-%20Sneak%20Peek%20into%20AWS%20SageMaker/) — SageMaker 개요(MLOps 생애주기 재정리, 공통 문제와 해결책), 10대 핵심 구성 요소, IoT 예측 모델 파이프라인 실전 예시
