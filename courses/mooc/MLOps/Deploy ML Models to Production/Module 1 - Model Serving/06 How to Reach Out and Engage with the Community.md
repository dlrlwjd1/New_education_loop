# How to Reach Out and Engage with the Community

## 개요
- KodeKloud가 제공하는 커뮤니티 지원 채널(포럼, Discord) 안내 리딩(10분). 기술 내용이 아닌 학습 커뮤니티 참여 방법 안내.

## 내용
- **KodeKloud 커뮤니티 포럼**: 기술적 질문, 토론, 다른 학습자·전문가의 인사이트를 얻는 용도. 가입/로그인 → 적절한 카테고리(Cloud, DevOps, 특정 자격증 등) 선택 → 관련 태그(AWS, Kubernetes, Terraform 등) 사용 → "New Topic"으로 질문 게시.
- **Discord 채널**: 실시간 협업, 네트워킹, DevOps/Cloud 최신 동향 파악 용도. 스터디 그룹, 네트워킹, 성과 공유, 커리어 가이드, 기술 토론 등에 활용.
- **채널 선택 가이드**: 기술/개념 질문 → 커뮤니티 포럼 이용, 협업/네트워킹 목적 → Discord 이용.

## 요약
- 이 리딩은 강의 내용이 아니라 KodeKloud 커뮤니티 포럼과 Discord 채널을 목적에 맞게 활용하는 방법을 안내하는 공통 안내문이다.
