# Need of Compliance and GDPR

## 개요
- 데이터 컴플라이언스가 왜 필요한지, 그리고 세계에서 가장 견고한 개인정보 보호법 중 하나인 **GDPR(General Data Protection Regulation)**의 핵심 원칙과 위반 시 처벌을 다루는 5분 영상.

## 내용

### 왜 컴플라이언스가 필요한가
- 앱 설치·업데이트나 웹사이트 양식에서 흔히 마주치는 "동의" 옵션 — 대부분 그냥 수락하고 넘어가지만, 실제로 제공한 정보가 어떻게 사용되는지, 앱이 미래에 내 정보를 삭제할 권리가 있는지, 필요 이상으로 정보를 수집하는지, 내 기기의 다른 콘텐츠를 확인할 권한이 있는지 등은 거의 의문을 갖지 않음.
- 이런 데이터 오용으로부터 사용자를 보호하는 법률의 필요성이 바로 **컴플라이언스**의 핵심 — 데이터 주체(data subject)의 권리에 관한 것:
  - 데이터 처리에 반대할 권리(right to object)
  - 개인 데이터에 접근할 권리(right to access)
  - 처리를 제한할 권리(right to restrict processing)
  - 데이터 이동성(data portability, 한 조직에서 다른 조직으로 데이터를 옮기거나 판매하는 것)
  - 정정권(right to rectification)과 완전 삭제권(right to erasure)

### GDPR이란
- **GDPR(General Data Protection Regulation)**: 2018년 5월 제정, 세계에서 가장 견고한 개인정보 보호법 중 하나로 EU 내 조직의 개인 데이터 취급 방식을 혁신함.
- 실제 사례: Facebook이 사용자 데이터 오용 의혹으로 GDPR에 따라 거액의 벌금을 부과받음 — GDPR은 기업이 사용자 프라이버시와 데이터 권리를 존중하도록 강제하며, 단순히 처벌을 피하는 것이 아니라 사용자와의 **신뢰 구축**이 핵심.

### GDPR의 핵심 원칙
1. **합법성, 공정성, 투명성(Lawfulness, Fairness, Transparency)**: 개인 데이터는 합법적으로 처리되어야 하며, 사용자는 항상 자신의 데이터가 어떻게 사용되는지 알아야 함 — 예: 웹사이트에서 쿠키 동의를 받는 것도 GDPR 준수의 일부.
2. **데이터 최소화(Data Minimization)**: 기업은 정말 필요한 데이터만 수집해야 함 — 예: 전자상거래 사이트가 계정 등록에 여권 번호를 요구하는 것은 불필요함.
3. **정확성(Accuracy)**: 데이터는 항상 정확하고 최신 상태여야 함 — 예: 은행이 이미 상환된 대출을 실수로 미상환으로 표시하는 것은 심각한 GDPR 위반.
4. **목적 제한(Purpose Limitation)**: 하나의 목적으로 수집된 데이터는 다른 목적에 사용되어서는 안 됨 — 예: 인보이스 수령을 위해 공유한 이메일 주소를 동의 없이 마케팅에 사용할 수 없음.
5. **무결성과 기밀성(Integrity and Confidentiality)**: 데이터 보안에 초점 — 예: 은행·병원 같은 기업이 무단 접근을 막기 위해 암호화와 데이터 보호에 크게 투자.
6. **저장 제한(Storage Limitation)**: 데이터를 필요 이상으로 오래 보관하지 않도록 보장 — 예: 온라인 소매업체가 거래 완료 후 신용카드 정보를 계속 보관해서는 안 됨.

### 미준수 시 처벌
- GDPR 준수는 선택이 아니라 **의무** — 민감한 개인 데이터를 다루는 조직은 **데이터 보호 책임자(Data Protection Officer, DPO)**를 지정해야 함.
- 미준수 시 처벌은 매우 심각함: 벌금이 **최대 2,000만 유로 또는 전 세계 매출의 4%(둘 중 더 큰 금액)**에 달할 수 있음.
- 실제 사례: Google이 광고 관련 동의 부족으로 GDPR 위반에 대해 약 5,000만 유로의 벌금을 부과받음.
- 결론: 컴플라이언스는 이제 단순한 법적 의무를 넘어 **전략적 필수 요소**.

## 예시
```text
[GDPR 6대 핵심 원칙]
1. 합법성·공정성·투명성 — 사용자가 데이터 사용 방식을 알아야 함
2. 데이터 최소화 — 필요한 데이터만 수집
3. 정확성 — 데이터는 항상 최신·정확해야 함
4. 목적 제한 — 수집 목적 외 사용 금지
5. 무결성·기밀성 — 암호화 등 보안 투자
6. 저장 제한 — 필요 이상 장기 보관 금지

[미준수 처벌]
최대 2,000만 유로 또는 전 세계 매출의 4% 중 더 큰 금액
```

## 요약
- 컴플라이언스는 데이터 주체의 접근·정정·삭제·이동성 등의 권리를 보호하기 위해 존재하며, 그 대표격인 GDPR은 합법성·투명성, 데이터 최소화, 정확성, 목적 제한, 무결성·기밀성, 저장 제한이라는 6대 원칙을 통해 EU 내 개인 데이터 취급을 규율하고, 위반 시 최대 2,000만 유로 또는 전 세계 매출 4%의 벌금(Google, Facebook 실제 사례)이 부과될 수 있는 만큼 이제는 법적 의무를 넘어선 전략적 필수 요소가 되었다.
