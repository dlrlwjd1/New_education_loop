# Compliance Consequences and Penalties

## 개요
- GDPR 위반에 대한 실제 대형 벌금 사례(Meta, Uber, WhatsApp)를 통해 컴플라이언스가 단순한 서류상의 정책이 아니라 실제로 집행되는 규정임을 보여주는 3분 영상.

## 내용

### Meta — 역대 최대 규모 GDPR 벌금 (2023년)
- 아일랜드 데이터보호위원회(Irish Data Protection Commission)가 Instagram·WhatsApp의 모회사 **Meta**에 기록적인 **12억 유로** 벌금 부과.
- 사유: 유럽 사용자의 개인 데이터를 적절한 안전장치 없이 미국으로 이전.
- 이 사건은 데이터 보호 규제 역사의 이정표 — 국경 간(cross-border) 데이터 이전 시 견고한 보호 메커니즘의 중요성을 부각. Meta는 항소 중이지만, 결과에 따라 기업들의 국제 데이터 이전 방식이 재편될 수 있음.

### Uber — 2억 9,000만 유로 벌금
- 네덜란드 데이터보호청(Dutch DPA)이 유럽 택시 기사들의 개인 데이터를 미국으로 부적절하게 이전한 혐의로 **Uber**에 벌금 부과.
- 프랑스 Uber 기사 170명의 불만 제기로 조사가 시작됨 → DPA는 **Privacy Shield 협정**이 무효화된 이후에도 Uber가 민감 데이터를 미국 서버에 적절한 보호 조치 없이 저장했음을 확인.
- 데이터 이전 규정 미준수의 위험성과, 모든 단계에서 사용자 데이터를 보호하는 것의 중요성을 보여줌.

### WhatsApp — 2억 2,500만 유로 벌금 (2021년)
- 아일랜드 데이터보호위원회가 3년간의 조사 끝에 **WhatsApp Ireland**에 벌금 부과.
- 사유: WhatsApp이 사용자 데이터를 다른 Facebook 계열사와 공유하는 방식에 대한 **투명성 문제**.
- 유럽 데이터보호위원회(European Data Protection Board)가 개입해 벌금과 준수 일정 재평가를 요구.
- 사용자에게 데이터 사용 방식을 투명하게 알리고 조직의 모든 프로세스에서 컴플라이언스를 보장하는 것의 중요성을 보여줌.

### 핵심 시사점
- 이 사례들을 보여주는 이유는 이런 정책들이 단순히 서류상의 형식이 아니라 **실제로 집행되고 있음**을 설명하기 위함.
- 따라서 스타트업이든 대기업이든 적절한 컴플라이언스를 따르는 것이 매우 중요함.

## 예시
| 기업 | 연도 | 벌금 규모 | 위반 사유 |
|---|---|---|---|
| Meta | 2023 | 12억 유로 | EU 사용자 데이터를 안전장치 없이 미국으로 이전 |
| Uber | (조사 개시: 프랑스 기사 불만) | 2억 9,000만 유로 | Privacy Shield 무효화 이후에도 미국 서버에 부적절한 데이터 저장 |
| WhatsApp | 2021 | 2억 2,500만 유로 | 다른 Facebook 계열사와의 데이터 공유 투명성 부족 |

## 요약
- Meta(12억 유로), Uber(2억 9,000만 유로), WhatsApp(2억 2,500만 유로)의 실제 GDPR 벌금 사례는 국경 간 데이터 이전과 데이터 공유 투명성에 대한 규정 위반이 실제로 막대한 재정적 처벌로 이어짐을 보여주며, 컴플라이언스가 단순한 서류 작업이 아니라 기업 규모와 무관하게 반드시 실천해야 할 실질적 의무임을 강조한다.
