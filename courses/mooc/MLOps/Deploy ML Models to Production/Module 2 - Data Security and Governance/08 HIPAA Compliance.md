# HIPAA Compliance

## 개요
- 미국의 의료 정보 보호법 **HIPAA(Health Insurance Portability and Accountability Act)**의 3대 규칙과 준수 요건, 그리고 이것이 헬스케어 관련 ML 모델 개발에 왜 중요한지를 설명하는 3분 영상.

## 내용

### HIPAA란
- **HIPAA(Health Insurance Portability and Accountability Act)**: 1996년 제정된 미국 법으로, 민감한 환자 건강 정보가 동의나 인지 없이 공개되지 않도록 보호.
- 예: 병원 방문 시 건강 기록이 본인 허락 없이 제3자와 공유되지 않도록 보장.
- 2003년 개정을 통해 디지털 시대에 맞춰 보호 조치가 강화됨.

### HIPAA의 3대 핵심 규칙
1. **프라이버시 규칙(Privacy Rule)**: 건강 정보를 보호하기 위한 국가 표준 수립 — 예: 병원에서의 진료 기록이 이 규칙으로 보호됨.
2. **보안 규칙(Security Rule)**: 전자 건강 정보(electronic health information) 보호에 초점 — 예: 의료 시스템에서 유출을 방지하기 위한 암호화와 다요소 인증 사용.
3. **유출 통지 규칙(Breach Notification Rule)**: 데이터가 침해되었을 경우 신속하게 통지받도록 보장 — 예: 데이터 유출을 겪은 병원은 영향을 받은 환자에게 반드시 통지해 투명성을 확보해야 함.

### 준수 요건
- **행정적, 물리적, 기술적 안전장치(Administrative, Physical, and Technical Safeguards)** 구현 필요 — 예: 병원은 안전한 로그인, 접근 통제, 암호화된 데이터베이스를 사용해야 함.
- **직원 교육 필수** — 프라이버시 교육으로 직원이 민감한 데이터를 책임감 있게 다루는 법을 알도록 함.
- **미준수 시 처벌**: 민사 벌금, 형사 고발, 심지어 징역형까지 가능 — 컴플라이언스가 단순 의무를 넘어 환자 신뢰와 조직 신뢰도 보호에 필수적임을 보여줌.

### MLOps 생애주기와의 관련성
- 헬스케어 관련 데이터로 ML 모델을 구축하는 조직이라면 반드시 HIPAA를 준수해야 함.
- 준수하지 않으면 향후 "모델이 어떻게 학습되었는가", "어떤 데이터로 학습되었는가", "그 데이터를 어떻게 확보했는가"와 같은 질문에 답할 수 없게 됨.
- 따라서 헬스케어 관련 ML 모델이나 ML 모델 배포 생애주기에서 일하는 사람이라면 HIPAA를 반드시 숙지해야 함.

## 예시
```text
[HIPAA 3대 규칙]
1. Privacy Rule — 건강 정보 보호 국가 표준
2. Security Rule — 전자 건강 정보 보안(암호화, MFA)
3. Breach Notification Rule — 유출 시 신속한 통지 의무

[준수 요건]
행정적·물리적·기술적 안전장치 + 직원 프라이버시 교육
미준수 시: 민사 벌금 / 형사 고발 / 징역형
```

## 요약
- HIPAA는 프라이버시 규칙, 보안 규칙, 유출 통지 규칙이라는 3대 축으로 미국 내 환자 건강 정보를 보호하며, 행정적·물리적·기술적 안전장치와 직원 교육을 요구하고 미준수 시 민사·형사 처벌까지 가능하므로, 헬스케어 데이터로 ML 모델을 학습·배포하는 모든 MLOps 관계자는 데이터 출처와 학습 과정을 설명할 수 있도록 HIPAA를 반드시 숙지해야 한다.
