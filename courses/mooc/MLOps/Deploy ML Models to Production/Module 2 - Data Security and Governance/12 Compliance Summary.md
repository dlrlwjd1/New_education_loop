# Compliance Summary

## 개요
- GDPR, HIPAA, PCI 세 가지 컴플라이언스를 위반 유형·처벌 관점에서 간단히 정리하며 Module 2 데이터 거버넌스 주제를 마무리하는 1분 영상.

## 내용

### GDPR
- 미준수 시 조직의 **총 매출과 연동된 벌금**이 부과될 수 있음 — 앞서 다룬 Meta, WhatsApp 사례가 대표적.

### HIPAA
- HIPAA에는 두 종류의 위반이 있음:
  - **민사 위반(Civic/Civil Violation)**: 지침을 따르지 않은 조직에 금전적 벌금 부과.
  - **형사 위반(Criminal Violation)**: 심각한 경우 **징역형(imprisonment)**까지 이어질 수 있음.

### PCI
- PCI 규정을 미준수하면 조직이 자사 애플리케이션에서 **어떤 형태의 결제 처리도 할 수 없게 되는 단계**에 이를 수 있음.

### MLOps 엔지니어를 위한 핵심 시사점
- 세 가지 컴플라이언스(GDPR, HIPAA, PCI)의 위반 유형과 처벌을 정리한 전체적인 취지는, MLOps 엔지니어가 항상 "우리가 데이터를 어떻게 학습시키고 있는가", "이 데이터가 어떻게 보안되었는가"를 스스로 질문해야 한다는 것.
- 이것으로 데이터 거버넌스(data governance) 주제를 마무리.

## 예시
| 규정 | 위반 유형 | 처벌 |
|---|---|---|
| GDPR | 데이터 이전·처리 위반 | 총 매출 연동 벌금 (예: Meta, WhatsApp) |
| HIPAA | 민사 위반 / 형사 위반 | 금전적 벌금 / 징역형 |
| PCI | 결제 데이터 보안 미준수 | 결제 처리 자격 상실까지 가능 |

## 요약
- GDPR은 매출 연동 벌금, HIPAA는 민사(벌금)·형사(징역형) 두 갈래의 위반 처벌, PCI는 결제 처리 자격 상실이라는 각기 다른 처벌 체계를 가지고 있으며, MLOps 엔지니어는 항상 데이터 학습·보안 방식이 이런 규정에 부합하는지 스스로 점검해야 한다.
