# Data Security and Governance (Graded Assignment)

## 개요
- Module 2 채점 대상 그레이디드 퀴즈(30분).

## 내용
- 학업 정직성 모니터링 대상 콘텐츠이므로 문제·보기·정답은 기록하지 않음.
- Module 2에서 다룬 데이터 보안·거버넌스 개념(모니터링 도구, 데이터 프라이버시·보안, 데이터 접근 관리, 데이터 보존, GDPR/HIPAA/PCI 컴플라이언스와 처벌) 내용을 기반으로 출제된 것으로 추정.

## 요약
- 채점 대상 평가 항목으로 실제 문항 내용은 기록하지 않는다.
