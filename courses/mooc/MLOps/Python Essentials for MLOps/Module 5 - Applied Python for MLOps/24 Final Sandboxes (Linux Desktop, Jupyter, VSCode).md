# Final Sandboxes — Linux Desktop / Jupyter / VSCode

## 개요
- 코스 전체(Module 1~5)에서 배운 내용을 자유롭게 복습·실험할 수 있는 3개의 최종 오픈 샌드박스(ungraded lab). 정해진 커리큘럼 없이 각자 원하는 환경(Linux 데스크톱, Jupyter, VSCode)에서 자유 실습.

## 내용
- Linux Desktop Sandbox: 리눅스 데스크톱 환경에서 커맨드라인·CLI 도구 등을 자유롭게 복습.
- Jupyter Final Sandbox: Jupyter Notebook 환경에서 Pandas/NumPy/함수/클래스 등을 자유롭게 복습.
- VSCode Final Sandbox: VSCode 환경에서 스크립트/API 코드를 자유롭게 복습.
- 셋 다 채점 대상이 아니며(ungraded), 정해진 지침 없이 "이 코스에서 배운 것을 탐구해보라"는 안내만 제공됨.

## 요약
- 실제 실습은 MOOC 클라우드 환경에서 각자 원하는 도구로 직접 진행 (`Launch lab`). 이 노트에는 세 샌드박스의 목적만 기록.
