# Testing Conventions Lab

## 개요
- MOOC 클라우드 기반 Jupyter/터미널 환경에서 진행하는 실습(ungraded lab). pytest 설치와 이름 규칙에 따른 테스트 자동 탐색을 직접 실행해보는 실습.

## 내용
- 제공된 예제 프로젝트에서 `pytest` 명령을 직접 실행하며 파일/함수 이름 규칙에 따라 테스트가 수집되는지 확인하는 구성. 채점 대상이 아니며(ungraded), 직접 실행해보는 경험 자체가 목적.

## 요약
- 실제 실습은 MOOC 클라우드 환경에서 직접 진행 (`Launch lab`). 이 노트에는 랩의 목적만 기록.
