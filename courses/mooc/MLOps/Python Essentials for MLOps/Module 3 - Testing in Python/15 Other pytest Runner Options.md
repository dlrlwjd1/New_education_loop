# Other pytest Runner Options

## 개요
- pytest 커맨드라인의 유용한 추가 옵션 3가지 — **`--collect-only`(수집만 확인)**, **`-x`(첫 실패에서 즉시 중단)**, **`pytest-xdist` 플러그인으로 테스트 병렬 실행** — 을 다룬다.

## 내용

### `--collect-only` — 수집 확인 전용
- `pytest --collect-only`를 실행하면 **테스트를 실행하지 않고, 어떤 테스트들이 수집(collect)되는지만 보여준다.**
- 테스트 수집에 문제가 있는지(파일/함수 이름 규칙 등) 확인할 때 유용.

### `-x` — 첫 실패에서 즉시 중단
- 큰 테스트 스위트를 실행할 때, **첫 실패가 발생하면 그 즉시 실행을 멈추고 싶다면 `-x` 플래그**를 쓴다.
- 예: 6개 테스트 중 첫 번째가 실패하면, 나머지 5개는 아예 실행되지 않고 멈춘다 — 출력이 그 실패 지점에만 집중되어 훨씬 보기 편해진다.

### `pytest-xdist` — 병렬 실행 플러그인
- pytest는 **플러그인을 설치해서 기능을 확장**할 수 있는데, 그중 `pytest-xdist`는 테스트가 많을 때 매우 유용하다.
- 설치: `pip install pytest-xdist`.
- 사용: `pytest -n 4`처럼 실행하면 **4개의 테스트 러너 인스턴스를 동시에 띄워 병렬로 테스트를 실행**한다.
- 테스트가 몇 개 안 될 때는 차이가 잘 안 느껴지지만, **수백~수천 개의 테스트**가 있다면 병렬 실행으로 전체 실행 시간이 훨씬 단축된다.

## 예시
```bash
pytest --collect-only        # 실행 없이 수집된 테스트 목록만 확인

pytest -x                    # 첫 실패에서 즉시 중단

pip install pytest-xdist
pytest -n 4                  # 4개의 러너로 병렬 실행
```

## 요약
- `--collect-only`로 테스트 수집 여부만 빠르게 점검하고, `-x`로 큰 스위트에서 첫 실패에 집중할 수 있다.
- 테스트가 많은 프로젝트라면 `pytest-xdist` 플러그인을 설치해 `-n` 옵션으로 병렬 실행하는 것을 강력히 추천.
