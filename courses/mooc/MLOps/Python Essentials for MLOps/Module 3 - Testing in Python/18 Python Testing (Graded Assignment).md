# Python Testing (Graded Assignment)

## 개요
- Module 3을 마무리하는 채점용 과제(Graded Assignment). 학업 정직성(academic integrity) 모니터링 대상이라, 이 노트에는 실제 문항 내용을 기록하지 않는다 (직접 응시해서 본인 실력으로 풀 것).

## 내용
- Module 3에서 다룬 핵심 개념 — 테스트가 필요한 이유, `unittest` vs `pytest`, 파일/함수/클래스 이름 규칙, plain assert의 리포팅, 테스트 클래스의 setup/teardown, parametrize, 테스트 실패 출력 읽는 법, PDB 디버깅, `-x`/`--collect-only`/`pytest-xdist`, pytest fixture(`tmpdir`) — 에 대한 이해를 종합적으로 점검하는 것으로 보인다.
- 복습이 필요하면 이 폴더의 다른 노트를 참고:
  - [03~04 pytest 기본과 규칙](03%20Testing%20Conventions.md), [07~10 유용한 테스트 작성](07%20Using%20Plain%20Asserts%20in%20pytest.md)
  - [13~16 실패 분석과 디버깅](13%20Test%20Failure%20Output.md)
