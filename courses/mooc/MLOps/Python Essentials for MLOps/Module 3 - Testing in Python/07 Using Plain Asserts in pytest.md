# Using Plain Asserts in pytest

## 개요
- 큰 딕셔너리·리스트·문자열처럼 조밀한(dense) 자료구조를 비교할 때 pytest의 plain assert가 얼마나 자세한 실패 리포팅(diff)을 제공하는지 실습으로 보여준다. `-v` 플래그로 더 상세한 출력을 얻는 법도 함께 다룬다.

## 내용

### 왜 plain assert가 유용한가 — 조밀한 자료구조 비교
- 큰 딕셔너리 두 개를 비교할 때, 어디가 다른지 눈으로 찾기 어렵다. pytest는 실패 시 **정확히 어느 키가 다른지**를 리포트해준다.
  - 예: "left contains one more item: {'last_name': ...}", "right contains one more item: {'last name': ...}" — 키 이름의 언더스코어 유무 차이까지 짚어줌.

### `-v` (verbose) 플래그
- 기본 출력은 다른 부분을 요약해서 보여주지만, **`-v`를 추가하면 두 자료구조를 나란히 놓고 전체 diff를 보여준다** (한쪽에만 있는 항목은 `+`로 표시).

### 리스트 비교
- 리스트도 마찬가지로 **정확히 몇 번째 인덱스(예: Index 2)가 다른지** 짚어준다 — 인덱스는 0부터 시작하므로 Index 2는 세 번째 항목.
- `-v`를 추가하면 이전에 생략됐던 항목까지 포함해 더 자세한 diff를 볼 수 있다.

### 문자열 비교
- 아주 긴 문자열도 어디서 다른지(예: 대소문자 차이) 찾기 어려운데, pytest는 **비교 중인 두 문자열의 관련 부분(subset)만 잘라서 보여줘서** 엔지니어가 빠르게 문제를 고칠 수 있게 해준다.

### 한계
- 이런 자동 diff 리포팅은 **Python의 표준 자료구조(딕셔너리/리스트/문자열 등)에는 잘 동작**하지만, **커스텀 자료구조**를 비교할 때는 추가 작업이 필요할 수 있다.

## 예시
```bash
pytest test_long_dictionaries.py       # 딕셔너리 비교 실패 시 다른 키를 정확히 짚어줌
pytest test_long_dictionaries.py -v    # 전체 diff를 나란히 보여줌 (+/- 표시)

pytest test_long_lists.py              # 다른 인덱스(Index 2 등)를 정확히 짚어줌
pytest test_long_strings.py            # 긴 문자열에서 다른 부분(대소문자 등)만 잘라서 보여줌
```

## 요약
- pytest의 plain assert는 딕셔너리/리스트/문자열처럼 표준 자료구조를 비교할 때, 실패 지점(다른 키/인덱스/부분 문자열)을 정확히 짚어주는 리포팅을 자동으로 제공한다.
- `-v` 플래그로 더 상세한 diff를 볼 수 있으며, 커스텀 자료구조는 표준 자료구조만큼 자동으로 리포팅되지 않을 수 있다.
