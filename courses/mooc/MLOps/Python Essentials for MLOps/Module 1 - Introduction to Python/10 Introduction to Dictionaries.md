# Introduction to Dictionaries

## 개요
- 딕셔너리(dictionary)는 리스트와 달리 **항목들의 컨테이너가 아니라 값들의 매핑(mapping)**이다. "전화번호부(phonebook)" 비유로 키-값 개념을 소개하고, 생성 방법과 키의 유일성(uniqueness) 제약, 해시 불가능한(unhashable) 타입을 키로 쓸 때의 에러를 다룬다.

## 내용

### 딕셔너리 = 매핑
- 리스트는 "항목의 컨테이너"지만, 딕셔너리는 **"값들의 매핑"**으로 이해해야 한다.
- 비유: **전화번호부** — 이름이 전화번호에 매핑되는 것처럼, 딕셔너리는 항상 **키(key)와 값(value)** 쌍으로 구성된다.

### 생성 문법
- 중괄호 `{}`가 딕셔너리를 만드는 데 필요하다 (다른 생성 방법은 다음 영상에서 다룸).
- `{"key": "value"}` — 키와 값은 콜론(`:`)으로 구분.
- 값은 문자열뿐 아니라 불리언 등 다른 타입도 가능.
- 여러 키-값 쌍을 넣을 때는 콤마로 구분 (리스트에서 여러 항목을 나열하는 것과 동일한 방식).

### 키의 유일성(uniqueness) 제약
- **키는 반드시 유일(unique)해야 한다.** 같은 키를 두 번 쓰면(예: `"name": "Alfredo"`를 두 번), Python은 하나만 남기고 **나중에 온 것이 이긴다(마지막 값으로 덮어씀)**.

### 값으로 다른 자료구조 사용하기
- 값(value)에는 리스트 같은 다른 자료구조도 넣을 수 있다 (예: `"items": ["lumber", "concrete", "nails"]`).
- 하지만 **키(key)로는 리스트처럼 해시 불가능한(unhashable) 타입을 쓸 수 없다** — 시도하면 `TypeError: unhashable type: 'list'` 발생.
- 이는 딕셔너리가 내부적으로 "키의 유일성을 빠르게 찾는" 구조(거의 메모리 안의 미니 데이터베이스처럼 동작)이기 때문 — 키는 반드시 해시 가능한(hashable) 타입이어야 한다.

## 예시
```python
contact = {"name": "Alfredo", "active": True}   # 키-값, 값은 어떤 타입도 가능

duplicate = {"name": "Alfredo", "name": "Alfredo"}  # 키 중복 → 하나만 남음

data = {"items": ["lumber", "concrete", "nails"]}   # 값으로 리스트 사용 OK

bad = {["a", "b"]: "value"}   # TypeError: unhashable type: 'list' (키로 리스트 사용 불가)
```

## 요약
- 딕셔너리는 리스트와 달리 키-값 매핑(mapping)이며, 중괄호 `{}`로 만든다.
- 키는 반드시 유일해야 하며, 중복 키는 마지막 값으로 덮어써진다.
- 값에는 리스트 등 다른 자료구조를 자유롭게 쓸 수 있지만, 키에는 해시 불가능한 타입(리스트 등)을 쓸 수 없다 — 시도하면 TypeError.
