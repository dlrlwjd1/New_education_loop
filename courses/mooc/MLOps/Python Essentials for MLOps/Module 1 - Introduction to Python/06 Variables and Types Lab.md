# Variables and Types Lab

## 개요
- MOOC 클라우드 기반 Jupyter 환경에서 진행하는 실습(ungraded lab). 이 레슨(변수/타입/조건문/예외 처리)에서 배운 내용을 직접 코드로 실행해보는 실습 노트북.

## 내용
- 제공된 Jupyter Notebook 셀들을 순서대로 실행하며 Python 변수와 타입을 직접 다뤄보는 구성.
- 채점 대상은 아니며(ungraded), IDE 환경에서 직접 코드를 실행해보는 경험 자체가 목적 — 자유롭게 값을 바꿔보고 실험하는 것을 권장.

## 요약
- 실제 랩 실습은 MOOC 클라우드 환경에서 직접 진행 (`Launch lab`). 이 노트에는 랩의 목적만 기록하고, 실습 코드/결과는 본인이 직접 실행하며 익힐 것.
