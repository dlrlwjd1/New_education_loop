# Minimal Python book: Storing Data (외부 읽기 자료)

## 개요
- *Minimal Python* 책의 2장을 참고하는 보충 읽기 자료. 이번 주에 다룬 자료구조(리스트/튜플/딕셔너리/세트)를 복습하는 성격으로, 전체 챕터는 온라인 원문에서 확인하도록 안내됨.

## 내용

**요약**: 리스트, 튜플, 딕셔너리, 세트 같은 기본 자료구조와 각각의 흔한 연산·사용 사례를 다룬다. 핵심은 리스트는 순서 있고 값이 저장되며, 튜플은 불변 리스트, 딕셔너리는 키를 값에 매핑, 세트는 유일한 원소만 담는다는 것. 적절한 자료구조 선택과 조작이 대부분의 Python 프로그램의 핵심이다.

**핵심 포인트 3가지**
- 리스트는 순서 있고 변경 가능한(mutable) 항목들을 저장한다.
- 딕셔너리는 유일한 키를 값에 매핑한다.
- 세트는 유일한 원소만 담는다.

**생각해볼 질문(Reflection Questions)**
- 리스트 대신 튜플을 언제 쓰고 싶을까?
- 딕셔너리로 모델링할 수 있는 실제 사례는?
- 세트가 프로그램의 효율을 어떻게 개선할 수 있을까?
- 중첩된 자료구조에서 어떤 문제가 발생할 수 있을까?
- 코딩할 때 적절한 자료구조 선택이 왜 중요한가?

**도전 과제(Challenge Exercises, 참고용 — 직접 풀어볼 것)**
- 전화번호부를 딕셔너리로 구현하기
- 세트를 이용해 텍스트 파일에서 가장 빈번한 단어 찾기
- 리스트에 저장된 사용자 댓글에서 비속어 필터링하기
- 딕셔너리로 단어 빈도 히스토그램 만들기
- 깊게 중첩된 리스트를 평평한(flat) 리스트로 변환하기

## 요약
- 원문 전체는 온라인에서 확인 가능하며, 이 노트는 이 레슨과 겹치는 핵심 요약만 기록.
- 도전 과제는 직접 코드로 풀어보는 것을 권장 (본 노트에는 문제만 기록, 풀이는 기록하지 않음).
