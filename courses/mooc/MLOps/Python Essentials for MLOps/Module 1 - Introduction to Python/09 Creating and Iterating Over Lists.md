# Creating and Iterating Over Lists

## 개요
- 리스트를 만드는 또 다른 방법(`list()` 내장 함수)과, 리스트를 순회(iterate)하는 가장 흔한 패턴인 `for ... in` 루프, 그리고 리스트 컴프리헨션(list comprehension)의 기초와 주의점을 다룬다.

## 내용

### 리스트 생성 — 두 가지 방법
- 대괄호 `[]`로 만드는 것 외에, **내장 함수 `list()`**로도 리스트를 만들 수 있다 — 결과는 동일하다.

### 순회(iteration) — `for ... in`
- 리스트를 순회하는(=반복적으로 하나씩 처리하는) 것은 Python에서 가장 흔한 연산 중 하나.
- `for color in colors:` 형태 — `color`라는 변수가 매 반복마다 리스트의 다음 항목 값으로 바뀐다.
- **순서가 항상 보존**되므로 인덱스 접근과도 일맥상통한다.
- 변수 이름은 의미가 통하게 짓는 것이 좋다 (예: `colors` 리스트를 순회할 때는 단수형인 `color`를 루프 변수로 사용).

### 리스트 컴프리헨션 (List Comprehension)
- 대괄호 안에 루프를 넣는 형태 — **"리스트 안의 루프"**.
- 문법: `[n for n in numbers if n < 6]` — `numbers`를 순회하면서 조건(`n < 6`)을 만족하는 값만 동적으로 새 리스트에 추가한다.
- 조건은 자유롭게 바꿀 수 있다 (예: `> 6`으로 바꾸면 다른 결과가 나옴).
- **주의**: 리스트 컴프리헨션은 간결하고 자체적으로 완결된(self-contained) 경우에는 유용하지만, **너무 길어지면 가독성이 떨어지고 유지보수가 어려워진다** — 프로그램의 가독성과 견고함(robustness)은 매우 중요하므로 남용하지 말 것.

## 예시
```python
colors = list(("red", "blue", "brown"))  # list() 내장 함수로 생성

for color in colors:
    print(color)   # red, blue, brown 순서대로 출력

numbers = [1, 3, 6, 8, 12]
low_numbers = [n for n in numbers if n < 6]   # 리스트 컴프리헨션
print(low_numbers)   # [1, 3]
```

## 요약
- 리스트는 `[]` 리터럴 또는 `list()` 함수로 생성 가능 — 결과는 같다.
- `for 변수 in 리스트:` 로 순회하며, 순서는 항상 보존된다.
- 리스트 컴프리헨션(`[표현식 for 항목 in 리스트 if 조건]`)은 조건부로 새 리스트를 만드는 간결한 문법이지만, 길어지면 가독성이 떨어지므로 간단한 경우에만 사용하는 것이 좋다.
