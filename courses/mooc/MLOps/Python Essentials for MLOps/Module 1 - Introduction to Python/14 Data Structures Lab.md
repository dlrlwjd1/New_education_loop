# Data Structures Lab

## 개요
- MOOC 클라우드 기반 Jupyter 환경에서 진행하는 실습(ungraded lab). 리스트/딕셔너리/튜플/세트를 직접 코드로 다뤄보는 실습 노트북.

## 내용
- 제공된 Jupyter Notebook 셀을 순서대로 실행하며 자료구조를 직접 다뤄보는 구성.
- 채점 대상이 아니며(ungraded), IDE 환경에서 직접 실행해보는 경험 자체가 목적.

## 요약
- 실제 실습은 MOOC 클라우드 환경에서 직접 진행 (`Launch lab`). 이 노트에는 랩의 목적만 기록.
