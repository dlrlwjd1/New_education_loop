# Week 1-Final Graded Quiz-Python Basics (Graded Assignment)

## 개요
- Module 1을 마무리하는 채점용 과제(Graded Assignment). 학업 정직성(academic integrity) 모니터링 대상이라, 이 노트에는 실제 문항 내용을 기록하지 않는다 (직접 응시해서 본인 실력으로 풀 것).
