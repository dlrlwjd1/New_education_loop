# Introduction to Lists

## 개요
- 리스트(list)는 Python에서 가장 흔한 자료구조 중 하나로, 대괄호(`[]`)로 정의하는 "항목들의 컨테이너". 어떤 타입이든 담을 수 있고, `len()`으로 길이를 확인하며, 인덱스(0부터 시작)로 항목에 접근하는 법을 다룬다.

## 내용

### 리스트의 본질
- 리스트는 그냥 **항목들의 컨테이너**다. 대괄호 안에 숫자든 문자열이든 어떤 타입이든 제약 없이 섞어서 담을 수 있다 (정수, 문자열, 불리언, 실수 등).
- 담을 수 있는 타입에 제약이 없다는 것이 리스트의 큰 장점.

### 길이 확인 — `len()`
- 내장 함수 `len()`으로 리스트(또는 다른 컬렉션)에 몇 개의 항목이 있는지 확인할 수 있다.

### 인덱스로 접근하기
- 리스트는 변수에 할당해서 만든다: `items = ["carrots", "peas", "celery"]`.
- **각 항목은 인덱스(위치)를 가지며, Python은 0부터 시작한다** — 첫 번째 항목의 인덱스는 0.
- `items[0]`처럼 대괄호와 정수 인덱스로 항목을 꺼낸다. 순서가 보존되기 때문에 인덱스가 의미를 가진다.
- **음수 인덱스**도 가능 — `items[-1]`은 마지막 항목, `items[-2]`는 뒤에서 두 번째 항목을 가져온다.
- 인덱스가 0부터 시작한다는 점은 처음 배울 때 혼란스러울 수 있다(1부터라고 착각하기 쉬움) — 이 점만 기억하면 리스트에서 항목을 꺼낼 때 어려움이 없다.

## 예시
```python
items = ["carrots", "peas", "celery"]
print(items[0])    # carrots (첫 항목, 인덱스 0)
print(items[1])    # peas
print(items[-1])   # celery (마지막 항목)
print(items[-2])   # peas (뒤에서 두 번째)

print(len(items))  # 3
```

## 요약
- 리스트 = 순서가 있는, 타입 제약 없는 항목들의 컨테이너. 대괄호로 정의.
- 인덱스는 0부터 시작하며, 음수 인덱스로 뒤에서부터 접근할 수 있다(`-1`이 마지막 항목).
- `len()`으로 리스트의 항목 개수를 확인한다.
