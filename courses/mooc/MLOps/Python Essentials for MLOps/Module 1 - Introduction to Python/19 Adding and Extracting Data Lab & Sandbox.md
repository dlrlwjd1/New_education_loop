# Adding and Extracting Data Lab & Sandbox Week One

## 개요
- Module 1의 마지막 두 실습(ungraded lab). "Adding and Extracting Data"는 이번 레슨(append/insert/extend/slicing/pop/get)을 직접 코드로 연습하는 실습이고, "Sandbox Week One"은 Week 1 전체 내용을 자유롭게 실험해볼 수 있는 오픈 Jupyter 환경이다.

## 내용
- 둘 다 MOOC 클라우드 기반 Jupyter 환경에서 진행되며 채점 대상이 아니다(ungraded).
- Adding and Extracting Data Lab: 리스트/딕셔너리에 데이터를 추가·삭제·조회하는 코드를 직접 실행.
- Sandbox Week One: 정해진 커리큘럼 없이 Week 1(변수/타입/자료구조/데이터 추가·추출)에서 배운 내용을 자유롭게 실험하는 공간.

## 요약
- 실제 실습은 MOOC 클라우드 환경에서 직접 진행 (`Launch lab`). 이 노트에는 랩의 목적만 기록.
