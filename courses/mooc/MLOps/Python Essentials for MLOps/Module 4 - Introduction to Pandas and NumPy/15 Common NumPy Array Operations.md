# Common NumPy Array Operations

## 개요
- 배열 전체에 한 번에 산술 연산을 적용하는 법(브로드캐스팅), 배열을 다른 형태로 **재구성(reshape)**할 때의 제약(원소 개수 보존), 그리고 다차원 배열을 1차원으로 **평탄화(flatten)**하는 법을 다룬다.

## 내용

### 배열 전체에 연산 적용 — 브로드캐스팅
- `weights_lbs = np.array([140, 174, 166, 192])`처럼 몸무게(파운드) 배열을 만든 뒤, **`weights_lbs / 2.2`처럼 배열 전체를 한 번에 나눌 수 있다.**
- 언뜻 이상해 보일 수 있지만(배열에 스칼라를 나누는 것), NumPy는 내부적으로 **그 나눗셈을 배열의 모든 원소에 각각 적용**한다 — 파운드를 킬로그램으로 변환하는 예시(1kg ≈ 2.2lbs).

### 재구성(Reshape) — 원소 개수는 항상 보존되어야 한다
- `np.ones((3, 4))`(3행 4열, 총 12개 원소)를 `.reshape(4, 3)`으로 바꾸면 4행 3열(역시 12개)이 되어 문제없이 동작한다.
- **핵심 제약: reshape 전후 원소 개수가 반드시 같아야 한다.** `(3,4)`(12개)를 `(4,4)`(16개)로 바꾸려 하면 에러가 난다 — "cannot reshape array of size 12 into shape (4,4)".
- 개수만 맞으면 어떤 형태로도 바꿀 수 있다: `(2, 6)`, `(12, 1)`, `(1, 12)` 모두 12개 원소를 유지하므로 가능. 반면 `(5, 1)`처럼 원소 수가 안 맞으면(5개) 불가능.

### 평탄화(Flatten)
- 3행 4열처럼 다차원인 배열을 **1차원으로 펼치고 싶을 때**는 `.flatten()` 함수를 쓴다 — 매우 직관적으로 동작.

## 예시
```python
import numpy as np

weights_lbs = np.array([140, 174, 166, 192])
weights_kg = weights_lbs / 2.2          # 배열 전체에 나눗셈이 자동 적용됨 (브로드캐스팅)
print(weights_kg)                        # [63.6 79.1 75.5 87.3] 근사

arr = np.ones((3, 4))                     # 3행 4열, 원소 12개
reshaped = arr.reshape(4, 3)               # 4행 3열, 원소 12개 (OK)
# arr.reshape(4, 4)                        # ValueError: 원소 개수(12 ≠ 16) 불일치

flattened = arr.flatten()                  # 1차원으로 평탄화
```

## 요약
- NumPy는 배열 전체에 산술 연산을 자동으로 적용(브로드캐스팅)해, 매 원소마다 반복문을 돌 필요가 없다.
- reshape은 원소 개수가 정확히 일치하는 형태로만 가능하며, flatten으로 다차원 배열을 1차원으로 펼칠 수 있다.
