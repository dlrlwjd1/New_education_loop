# Applying Functions with Pandas

## 개요
- 일반 Python에서는 데이터를 다룰 때 보통 **반복문(loop)**을 쓰지만, Pandas에서는 **함수를 컬럼에 적용(apply)**하는 방식이 자연스럽다는 것을 실습으로 보여준다. `.apply()`로 커스텀 로직을 컬럼 전체에 한 번에 적용하는 법을 다룬다.

## 내용

### Python 반복문 vs. Pandas의 `apply`
- 순수 Python에서 리스트/딕셔너리를 다룰 때는 보통 **루프를 돌며** 새 자료구조를 만들거나 값을 추출한다.
- Pandas는 다르다 — 데이터를 조작하고 싶을 때 **함수를 "적용(apply)"**하는 방식을 쓴다. 어느 쪽이 더 낫다는 게 아니라, **접근 방식 자체가 다르다**는 점을 알아두는 것이 중요 (익숙하지 않으면 낯설게 느껴질 수 있음).

### 예시 — "좋은 와인" 판별 컬럼 만들기
- 비즈니스 요구사항: 평점이 특정 기준(예: 95점) 이상이면 "좋은 와인"으로 표시하고 싶다.
- 이를 위해 **평범한 함수**를 하나 작성한다 — 값을 받아서 조건에 따라 `True`/`False`를 반환하는 3~4줄짜리 함수.
- `df["good"] = df["rating"].apply(good_wine)`처럼, **특정 컬럼(`rating`)의 모든 값에 대해 그 함수를 적용**해서 새 컬럼(`good`)을 만든다.
- Pandas가 내부적으로 그 컬럼의 **각 값을 함수에 하나씩 전달**하면서 결과를 모아 새 컬럼으로 만들어준다 — 개발자가 직접 루프를 짤 필요가 없다.

### 결과값을 통계 분석에 맞게 조정하기
- `True`/`False`로 반환해도 되지만, **통계·수치 분석을 하려면 `1`/`0`처럼 숫자형이 더 적합**할 수 있다.
- 함수 내부에서 반환값을 `True`/`False` 대신 `1`/`0`으로 바꾸기만 하면, 같은 로직으로 숫자형 결과를 얻을 수 있다.

## 예시
```python
def good_wine(value):
    if value > 94:
        return True   # 또는 통계 분석용으로 1
    return False        # 또는 0

df["good"] = df["rating"].apply(good_wine)

df.query("rating > 94").head()   # good 컬럼이 True/1로 표시된 행들 확인
```

## 요약
- Pandas는 순수 Python의 반복문 대신, 커스텀 함수를 컬럼 전체에 `.apply()`로 적용하는 방식을 쓴다.
- 함수는 값 하나를 받아 원하는 로직(조건 판별 등)을 수행해 반환하면 되며, 반환 타입(True/False vs 1/0)은 이후 분석 목적에 맞게 선택하면 된다.
