# Minimal Python book: Create functions (외부 읽기 자료)

## 개요
- *Minimal Python* 책의 관련 챕터를 참고하는 보충 읽기 자료. 입력/반환이 없는 함수, 입력 없이 값만 반환하는 함수, 입력은 받지만 반환하지 않는 함수 등 함수의 기본 패턴을 복습한다.

## 내용

**요약**: 함수는 재사용 가능한 로직 블록을 만들어주며, 선택적으로 입력을 받고 출력을 반환할 수 있다. 대부분의 Python 프로그램에서 핵심 연산을 담당한다.

**핵심 포인트 3가지**
- 함수는 코드에서 재사용 가능한 로직 블록을 만들어준다.
- 함수는 선택적으로 입력을 받고 출력을 반환할 수 있다.
- 함수는 대부분의 Python 프로그램의 핵심 연산을 구성한다.

**생각해볼 질문(Reflection Questions)**
- Python 함수로 구현할 수 있는 실제 사례는?
- 입력도 반환도 없는 함수가 필요한 경우는 언제일까?
- 함수에서 값을 반환하는 것이 왜 유용할까?
- 부작용(side-effect)이 있는 함수에서 어떤 문제가 생길 수 있을까?
- 함수가 Python 프로그램의 유지보수성을 어떻게 개선할 수 있을까?

**도전 과제(Challenge Exercises, 참고용 — 직접 풀어볼 것)**
- 화씨를 섭씨로 변환하는 함수 작성
- 입력에 따라 출력을 출력하는 함수 만들기
- 임의의 숫자를 반환하는 함수 정의
- 인자에 따라 다양한 도형의 넓이를 계산하는 함수 구현
- 이름을 입력받는 재사용 가능한 인사 함수 작성
