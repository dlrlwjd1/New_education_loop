# Inheritance (외부 읽기 자료)

## 개요
- 상속과 객체지향 프로그래밍(OOP)의 핵심 개념을 다루는 보충 읽기 자료. 앞선 영상에서 다룬 단일 상속 외에, **메서드 오버라이딩**, **다중 상속**, **네임 맹글링(name mangling)** 등 심화 주제를 소개한다.

## 내용

**핵심 포인트**
- 파생 클래스(derived class)는 부모 베이스 클래스로부터 속성과 동작(behavior)을 상속받는다.
- 상속받은 메서드를 오버라이딩(overriding)하면 자식 클래스에서 기능을 수정할 수 있다.
- 다중 상속(multiple inheritance)을 이용하면 파생 클래스가 여러 부모 클래스로부터 상속받을 수 있다.
- 더블 언더스코어를 이용한 네임 맹글링(name mangling)으로 일종의 비공개(private) 클래스 변수를 만들 수 있다.

**생각해볼 질문(Reflection Questions)**
- 상속은 OOP에서 코드 재사용을 어떻게 촉진할까?
- 상속받은 메서드를 오버라이딩하고 싶은 예시는?
- 다중 상속에서 다이아몬드 상속 문제(diamond inheritance problem)는 왜 생길까?
- 비공개 네임 맹글링은 어떤 용례가 있을까?
- 내가 만드는 프로그램에서 상속을 어떻게 활용할 수 있을까?

**도전 과제(참고용 — 직접 풀어볼 것)**
- 단일 상속을 보여주는 클래스 3개 만들기
- 부모 클래스에서 상속받은 메서드를 오버라이딩하기
- 2개의 부모 클래스로부터 상속받는 클래스 만들기
- 네임 맹글링으로 비공개 클래스 변수 만들기
- 다중 상속 예시에서 메서드 결정 순서(MRO) 분석하기

## 요약
- 원문 전체는 온라인에서 확인 가능하며, 이 노트는 이 레슨과 겹치는 핵심 요약만 기록.
- 다중 상속, 오버라이딩, 네임 맹글링은 이 코스 영상에서 직접 다루지 않은 심화 주제로, 도전 과제를 통해 직접 탐구해볼 것을 권장.
