# Python Classes Sandbox

## 개요
- 정해진 커리큘럼 없이 클래스/생성자/메서드/상속을 자유롭게 실험해볼 수 있는 MOOC 클라우드 Jupyter 샌드박스(ungraded lab).

## 내용
- 채점 대상이 아니며, 자유 실습 공간. 뒤따르는 "Quiz-Ungraded Lab Python Classes Sandbox"는 연습용 Practice Assignment로 학업 정직성 정책에 따라 문항을 기록하지 않음.

## 요약
- 실제 실습은 MOOC 클라우드 환경에서 직접 진행 (`Launch lab`).
