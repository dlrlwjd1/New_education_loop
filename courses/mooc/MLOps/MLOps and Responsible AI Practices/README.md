# MLOps and Responsible AI Practices

**Course URL:** [mooc.org/learn/microsoft-mlops-and-responsible-ai-practices](https://www.mooc.org/learn/microsoft-mlops-and-responsible-ai-practices)

MOOC / Microsoft. "Microsoft Generative AI Engineering" 전문 자격증(Professional Certificate)의 일부. 생성형 AI 모델을 개발에서 프로덕션까지 이끄는 데 필요한 핵심 역량을 다루는 코스로, 4개 모듈로 구성. Azure에서의 견고한 MLOps 실천(자동화된 CI/CD 파이프라인, 버전 관리, 모델 전체 생애주기 관리)과 Microsoft의 책임감 있는 AI(Responsible AI) 프레임워크를 함께 다룸. 강사는 Microsoft.

## 모듈 구성
- **Module 1 - Introduction to MLOps and Model Lifecycle Management** — MLOps 기초, Azure ML 툴킷, 모델 생애주기 관리(요구사항 수집, Azure ML Model Registry)
- **Module 2 - Version Control and CI-CD Pipelines** — Azure Repos·Git 버전 관리 전략, Azure DevOps CI/CD 파이프라인 설계·구현
- **Module 3 - Monitoring, Logging, and Cost Optimization** — Azure Monitor·Application Insights 모니터링, 커스텀 로깅과 KQL 분석, Azure ML/OpenAI 비용 최적화
- [Module 4 - Ethical AI and Responsible AI Practices](Module%204%20-%20Ethical%20AI%20and%20Responsible%20AI%20Practices/) — 책임감 있는 AI 원칙, Azure Responsible AI Dashboard, Microsoft AETHER 가이드라인, MLOps 파이프라인의 윤리적 Quality Gate
