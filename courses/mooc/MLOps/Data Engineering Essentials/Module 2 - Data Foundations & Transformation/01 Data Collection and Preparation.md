# Data Collection and Preparation

## 개요
- 식료품 배달 앱의 개인화 추천 사례로, 데이터 수집·준비가 왜 모든 ML 모델 구축의 근간이 되는지 설명하는 4분 영상.

## 내용

### 사례 — 식료품 배달 앱의 개인화
- 목표: 앱 내 모든 사용자에게 개인화된 경험 제공.
- 구매 이력, 탐색 패턴, 선호 아이템 같은 사용자 데이터로 다음에 필요한 것을 예측 → 사용자 참여·만족도 향상.
- 고객 행동 기반으로 개인화된 프로모션·할인 발송 → 전환율 증가. ML 모델이 매출 기회로 이어지는 패턴을 식별.
- 개인화 경험과 가치 기반 오퍼 제공은 고객 유지, 재구매, 매출 성장 같은 비즈니스 지표를 개선.

### 모든 것의 중심은 데이터
- ML 모델이 이런 예측(패턴 이해, 개인화된 선택 생성 등)을 하려면 무엇이 필요한가? 그 중심에는 **데이터**가 있음.
- 필요한 모든 관련 데이터를 확보하는 것이 중요 — 데이터가 정확하고 포괄적일수록 예측이 좋아짐.
- 실제 환경에서는 데이터가 SQL 데이터베이스, 스프레드시트, NoSQL 데이터베이스 등 여러 곳에 흩어져 있음 — ML 모델에 사용하기 전에 이를 **중앙화(centralize)**하고 **정제(clean)**해야 함.

### 여러 데이터 소스에서 수집
- 앱의 백엔드는 여러 데이터 소스(API, 데이터베이스, 구글 스프레드시트 등)에 의존할 수 있음 — 효과적인 데이터 수집을 위해서는 이 각각의 소스에서 데이터를 추출해 하나의 응집된(cohesive) 데이터셋으로 만들어야 함.
- 결국 관련성 높은 데이터가 방대한 백엔드 시스템 전반에서 응집력 있게 수집·저장되는 것이 ML 모델 구축의 첫걸음.

### 이 섹션에서 다룰 내용
- 데이터 수집·준비 과정에서 **ETL, 데이터 수집(ingestion), 데이터 레이크, 피처 스토어, Spark/Pandas를 활용한 데이터 준비** 등을 다룰 예정.

## 요약
- 데이터 수집과 준비는 ML 모델 구축의 근간이며, 목표는 여러 데이터 소스(SQL/NoSQL DB, 스프레드시트, API)에 흩어진 데이터를 중앙화·정제해 모델 학습에 필요한 응집된 데이터셋으로 통합하는 것이다.
