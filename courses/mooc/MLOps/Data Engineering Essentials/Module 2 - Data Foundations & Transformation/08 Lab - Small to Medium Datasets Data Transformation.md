# Lab: Small to Medium Datasets Data Transformation

## 개요
- Demo 1~3에서 다룬 Pandas 기반 데이터 정제·변환(결측치 처리, JSON 펼치기, 피처 생성, 집계)을 KodeKloud 플랫폼에서 직접 실습해보는 랩.

## 내용
- KodeKloud 랩 접근 방법: 코스의 KodeKloud 링크로 이동 → 로그인/계정 생성 → 등록 후 모든 랩·레슨에 접근.
- 이 레슨(소규모~중간 규모 데이터셋 변환)에 대한 실습 랩 링크가 제공됨.

## 요약
- 이 랩은 앞선 3개의 Pandas 데모(결측치 처리, JSON 펼치기, 피처 엔지니어링·집계)를 KodeKloud 환경에서 직접 실습해볼 수 있도록 연결하는 자료다.
