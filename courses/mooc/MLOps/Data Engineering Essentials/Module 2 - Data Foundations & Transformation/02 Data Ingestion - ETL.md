# Data Ingestion - ETL

## 개요
- 조직 내 데이터가 저장되는 다양한 위치를 개괄한 뒤, 이를 하나로 통합하는 **ETL(Extract, Transform, Load)** 프로세스를 설명하는 3분 영상.

## 내용

### 조직 내 데이터가 저장되는 곳들
- **CRM 시스템**: 고객 데이터, 상호작용, 영업 리드 저장 — 영업·마케팅 담당자가 주로 사용.
- **마케팅 도구**: 이메일 마케팅 캠페인 발송, 웹 분석 데이터 제공(예: 이메일 오픈율, 완독률).
- **소셜 미디어 플랫폼**: 조직을 대신해 콘텐츠를 게시 → 고객의 콘텐츠 시청에 대한 감성 분석 제공.
- **웹 분석 데이터**: 모바일·웹 분석 데이터 — 사용자 행동, 트래픽 소스 등 정보 제공. 조직이 가장 많이 다루게 될 데이터 소스 중 하나.
- **전통적인 데이터베이스**: 모든 마이크로서비스·애플리케이션이 데이터를 저장하는 방식.
- **IoT 기기**: 공장이나 기계에 설치된 장비가 실시간 데이터를 전송.
- 그 외: 구글 시트, 문서, 이미지 등.

### ETL — Extract, Transform, Load
- 이 모든 정보를 하나로 통합·저장하는 과정이 바로 **ETL(추출·변환·적재)**.
- **추출(Extract)**: 데이터베이스, API 등에서 데이터를 가져오고 일부 집계 수행 — Talend, DLT 같은 도구 활용.
- **변환(Transform)**: 필요한 데이터를 확보했지만 형식이 제각각이므로, 이 단계에서 집계·필터링 등을 수행.
- **적재(Load)**: 정제된 데이터를 소스로 다시 보낼 수는 없으므로, 이를 소비할 수 있는 장소에 저장.

### 핵심 통찰
- ETL은 매우 유명한 용어이며, 실제로 MLOps 여정에서 모델링 목적의 필요한 데이터를 모으는 **첫 단계**.
- 다음 영상에서는 "적재(Load)" 부분을 더 자세히 다룰 예정.

## 요약
- 조직의 데이터는 CRM, 마케팅 도구, 소셜 미디어, 웹 분석, 데이터베이스, IoT 기기 등 여러 곳에 흩어져 있으며, ETL(추출·변환·적재)이 이를 하나의 응집된 데이터셋으로 통합하는 MLOps의 첫 단계다.
