# Course Introduction

## 개요
- 강사 Raghunandan Asano가 MLOps 코스 전체의 구성과 학습 목표를 소개하는 2분짜리 오리엔테이션 영상.

## 내용

### 강사 소개와 학습 방식
- 강사 Raghunandan Asano — 이 MLOps 여정의 가이드 역할.
- 코스 전반에 걸쳐 여러 **실습 랩(hands-on labs)**에 참여하게 되며, 실제와 유사한 환경에서 실험하고 실수하며 배우는(learn by doing) 방식으로 실전 DevOps 과제에 대비.

### 코스 구성 개요
1. **MLOps란 무엇이고 MLOps 엔지니어의 역할은 무엇인가**로 시작.
2. **MLOps 생애주기(lifecycle)** 안내, MLOps 요구에 맞는 올바른 도구 선택법, MLOps 아키텍처 개괄 익히기.
3. 데이터는 모든 머신러닝 프로젝트의 근간 — **데이터 수집(ingestion), 데이터 정제(cleaning), 데이터 변환(transformation), 데이터 레이크(data lakes)** 개념 학습.
4. 실전 데모와 최종 실습 랩으로 마무리.

### 커뮤니티
- KodeKloud는 커뮤니티를 중요하게 여김 — 활발한 포럼에서 질문을 올리거나, 인사이트를 공유하거나, 동료 학습자를 도울 수 있음.

## 요약
- 이 코스는 MLOps 개념·생애주기·아키텍처 소개에서 시작해 데이터 수집·정제·변환·데이터 레이크까지 다루며, 실습 랩 중심의 학습으로 구성된다.
