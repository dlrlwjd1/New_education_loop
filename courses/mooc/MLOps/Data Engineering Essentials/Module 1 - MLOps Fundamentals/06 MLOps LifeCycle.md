# MLOps LifeCycle

## 개요
- 데이터 탐색 → 모델 구축 → 테스트 → 평가 → 배포·운영으로 이어지는 MLOps 생애주기의 4대 핵심 단계를 설명하는 3분 영상.

## 내용

### MLOps 생애주기의 4대 섹션

1. **데이터 탐색(Data Exploration)**
   - 데이터를 큐레이션(curating), 수집(collecting), 변환(transforming), 검증(validating)하는 초기 단계.
   - 예: 이커머스 회사가 과거 판매 데이터를 수집·탐색해 미래 판매 추세를 예측하는 ML 모델에 활용.
   - **가장 많은 시간이 소요되는 단계** — 전체 시간의 약 **30~40%**를 차지.

2. **머신러닝 모델 구축(Building the ML Model)**
   - 데이터가 준비되면 알고리즘 선택, 모델 학습, 최적화를 진행.
   - 데이터 과학자가 가장 많은 시간을 쏟는 부분은 사실상 **모델 평가** — 주어진 사용 사례에 어떤 알고리즘이 적합한지 판단하는 것은 매우 시간이 많이 드는 작업.

3. **테스트와 개발(Testing and Development)**
   - 배포 전, 교차 검증(cross-validation)이나 홀드아웃 검증(holdout validation) 같은 기법으로 모델 성능을 철저히 테스트.
   - 예: 사기 탐지 모델을 미지의 데이터(unseen data)로 테스트해 실제 사기 사례를 잘 탐지하는지 확인.
   - 프로덕션에 배포되기 전 반드시 엄격한 테스트·개발 단계를 거쳐야 함 — 프로덕션에 배포된 후 문제가 생기면 원래 해결하려던 문제에 악영향을 주거나 새로운 문제를 만들 수 있기 때문.
   - 이후 **모델 평가(evaluate)** — 정확도, 재현율(recall), 정밀도(precision) 등 주요 지표로 평가.

4. **배포·운영(Deployment/Operation)**
   - 모델을 프로덕션에 릴리스 → ML 서비스 모니터링 → 새로운 ML 서비스 추가.

### 핵심 통찰
- MLOps는 **데이터 탐색, 머신러닝(모델 구축), 테스트와 개발, 운영**이라는 4가지 핵심 섹션으로 나눌 수 있으며, MLOps 엔지니어는 이 네 가지 모두를 숙달해야 함.
- 이 코스도 이 4가지 섹션(데이터 탐색 → 테스트·개발 → 배포·서빙)을 따라 구성됨.

## 요약
- MLOps 생애주기는 데이터 탐색(가장 큰 시간 비중, 30~40%) → 모델 구축(알고리즘 선택·평가) → 테스트·개발(교차 검증) → 배포·운영(모니터링)의 4단계로 구성되며, 이 코스도 이 구조를 따라 진행된다.
