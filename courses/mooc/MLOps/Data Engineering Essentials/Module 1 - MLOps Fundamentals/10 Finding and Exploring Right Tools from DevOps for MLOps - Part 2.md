# Finding and Exploring Right Tools from DevOps for MLOps - Part 2

## 개요
- Part 1에 이어 컨테이너화·오케스트레이션, 모니터링·로깅, 보안·컴플라이언스, 워크플로 오케스트레이션, 하이퍼파라미터 튜닝 도구를 소개하는 3분 영상(Part 2).

## 내용

### 컨테이너화와 오케스트레이션 도구
- **Docker**: 애플리케이션을 컨테이너화하는 사실상의 표준 — ML 모델과 의존성을 컨테이너에 패키징해 여러 환경에서 일관성을 보장.
- **Kubernetes**: 컨테이너화된 애플리케이션을 관리하는 대표적 오케스트레이션 플랫폼 — MLOps에서 ML 모델의 배포·확장을 자동화해 대규모 프로덕션 환경 관리를 용이하게 함.

### 모니터링과 로깅 도구
- **Prometheus**: 메트릭을 수집·저장하는 오픈소스 모니터링·알림 툴킷 — DevOps에서 널리 쓰이며 MLOps에서도 사용 가능.
- **Grafana**: Prometheus의 메트릭을 시각화하는 애드온.
- **Elastic Stack(ELK)**: 로깅 서비스로 ELK를 선택한 조직이라면 Prometheus·Grafana를 대체할 수 있는 옵션.

### 보안·컴플라이언스 도구
- **HashiCorp Vault**: 시크릿과 민감 데이터를 관리하는 도구 — Vault를 쓰지 않으려면 AWS나 GCP의 클라우드 환경에 맞는 시크릿 서비스를 사용 가능.
- **SonarCloud**: 코드 품질·보안을 평가 — 리포지토리를 스캔해 코드베이스가 안전한지, 시크릿이 노출되지 않았는지 등을 확인.

### 워크플로 오케스트레이션 도구
- **Airflow**: 워크플로를 작성·스케줄링·모니터링하는 오픈소스 플랫폼 — 데이터 수집부터 모델 학습·배포까지 ML 파이프라인 자동화에 흔히 사용됨.
- **Luigi**: 또 다른 오케스트레이션 도구지만 Airflow만큼 널리 쓰이지는 않음.

### 하이퍼파라미터 튜닝·최적화 도구
- **Optuna**, **Hyperopt**: ML 모델의 하이퍼파라미터 튜닝과 최적화를 돕는 도구.

### 핵심 통찰
- 이런 도구들을 MLOps 파이프라인에 통합하면 더 매끄러운 운영, 더 나은 협업, 확장 가능한 배포를 보장할 수 있음 — 오늘 살펴본 도구들이 모든 MLOps 엔지니어링의 근간.
- 주목할 점: 이 도구들의 **약 60%는 이미 DevOps와 관련**이 있으며, 따라서 MLOps 엔지니어가 되기 위해 새로 집중해야 할 부분은 **약 40%의 새로운 도구**들.
- 다음 섹션들에서는 이 각 주제를 더 깊이 파고들어, 이 도구들 중 하나를 선택해 MLOps 워크플로에 어떻게 적용되는지 살펴볼 예정.

## 요약
| 카테고리 | 도구 |
|---|---|
| 컨테이너화·오케스트레이션 | Docker, Kubernetes |
| 모니터링·로깅 | Prometheus, Grafana, Elastic Stack(ELK) |
| 보안·컴플라이언스 | HashiCorp Vault, SonarCloud |
| 워크플로 오케스트레이션 | Airflow, Luigi |
| 하이퍼파라미터 튜닝 | Optuna, Hyperopt |

- 전체 MLOps 도구 스택 중 약 60%는 기존 DevOps 도구를 그대로 재사용하며, MLOps 엔지니어로 성장하려면 나머지 약 40%(DVC, MLflow, Kubeflow, Great Expectations 등 ML 특화 도구)에 집중하면 된다.
