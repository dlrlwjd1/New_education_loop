# How to Reach Out and Engage with the Community

## 개요
- KodeKloud가 제공하는 두 가지 커뮤니티 채널(Community Forum, Discord)의 용도와 사용법을 안내하는 자료(오디오 요약 1분 42초).

## 내용

### 1. KodeKloud Community Forum
- 기술적 질문, 토론 참여, 동료 학습자·전문가로부터의 인사이트를 얻는 용도.
- 사용법: 포럼에 가입/로그인 → 적절한 카테고리(Cloud, DevOps, 특정 자격증 등) 이동 → 관련 태그(AWS, Kubernetes, Terraform 등) 사용 → New Topic 버튼으로 질문·아이디어·인사이트 게시.

### 2. Discord 채널
- 실시간 협업, 네트워킹, DevOps·클라우드 최신 동향 파악 용도.
- Discord 서버 참여 후 가능한 활동: 스터디 그룹, 네트워킹, 성취(자격증·프로젝트·마일스톤) 공유, 커리어 조언(채용 프로세스·자격증·프로젝트 아이디어 팁), 기술 토론.

### 어디에 게시할지 판단하는 기준
- 기술적/개념적 질문 → **Community Forum** 사용.
- 협업이나 네트워킹 목적 → **Discord**로 이동.

## 요약
- 기술 질문은 Community Forum에, 협업·네트워킹은 Discord에 게시하는 것이 KodeKloud 커뮤니티를 효과적으로 활용하는 방법이다.
