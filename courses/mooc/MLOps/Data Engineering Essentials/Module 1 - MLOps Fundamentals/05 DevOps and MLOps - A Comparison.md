# DevOps and MLOps - A Comparison

## 개요
- DevOps와 MLOps를 목적, 협업, 역할, 도구, 생애주기 관리, 초점, 성능 모니터링, 확장성 등 여러 기준으로 심층 비교하는 7분 영상.

## 내용

### 개요
- **DevOps**: 소프트웨어 개발과 IT 운영의 작업을 자동화·통합하는 데 초점 — 시스템 배포 생애주기를 단축하는 것이 목표.
- **MLOps**: DevOps 관행을 머신러닝으로 확장한 것 — 모델뿐 아니라 **데이터와 재학습(retraining)**까지 포함해 머신러닝 생애주기 전체를 자동화·관리하는 것이 목표.

### 기준별 비교

| 기준 | DevOps | MLOps |
|---|---|---|
| **전반적 목적** | 일반 소프트웨어 개발·IT 운영, CI/CD/배포 지속. 예: 이커머스 회사의 웹사이트 업데이트 자동화 | ML 모델 개발·배포·모니터링에 특화. 예: 금융 서비스 회사의 사기 탐지 모델 개발·지속적 모니터링·재학습 |
| **협업** | 개발자, IT 운영, 보안팀 간 협업 | 데이터 과학자, ML 엔지니어, DevOps 엔지니어, 분석가까지 참여. 예: 헬스케어 테크 기업의 환자 결과 예측 모델 |
| **역할** | 시스템 관리자·소프트웨어 개발자와 협업해 배포 관리(예: 마이크로서비스 배포 자동화) | 데이터 과학자·ML 엔지니어와 협업해 ML 모델의 배포·생애주기 관리 |
| **핵심 도구** | Jenkins, Docker, Kubernetes, Ansible, Terraform | MLflow, DVC, Kubeflow, Airflow(예: Airflow로 프로덕션 모델의 재학습 자동화) |
| **생애주기 관리** | 앱 코드 생애주기와 인프라 — CI/CD/배포 지속 | 데이터 생애주기, 모델 생애주기, 지속적 재학습(예: 자율주행 회사의 데이터 수집→학습→배포→지속 업데이트) |
| **주요 초점** | 코드 전달, 시스템 자동화, 신뢰성 | 데이터 버전 관리, 모델 재현성, 성능(예: IoT 농업 기업 — DevOps는 앱 신뢰성, MLOps는 작물 수확량 모델 생산성) |
| **성능 모니터링** | 시스템·애플리케이션 성능, 가동 시간(uptime) | 모델 드리프트, 정확도, 실제 영향(예: 이커머스 사이트 — DevOps는 가동 시간, MLOps는 신규 고객 데이터에서의 사기 탐지 모델 성능) |
| **확장성** | 애플리케이션 수요에 맞춘 인프라 확장(예: 트래픽 급증 시 웹 서버 확장) | ML 파이프라인과 모델 배포 확장(예: 수백만 사용자를 처리하는 추천 엔진 확장) |

### 핵심 통찰
- DevOps와 MLOps는 유사점을 공유하지만 서로 다른 필요를 충족함 — DevOps는 애플리케이션 개발과 IT 인프라의 자동화·모니터링에 초점을 맞추고, MLOps는 여기에 머신러닝 모델 개발·배포·지속적 재학습이라는 복잡성을 더해 확장한 것.

## 요약
- DevOps는 코드·인프라·시스템 성능에 초점을 맞춘 소프트웨어 배포 자동화이고, MLOps는 여기에 데이터·모델 버전 관리·재학습·모델 드리프트 모니터링이라는 ML 고유의 복잡성을 더한 확장 개념이다.
