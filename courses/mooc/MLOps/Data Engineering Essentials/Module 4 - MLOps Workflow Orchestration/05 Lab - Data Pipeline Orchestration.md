# Lab: Data Pipeline Orchestration

## 개요
- Demo 1~2에서 다룬 Airflow 환경 구축과 커스텀 DAG 작성을 KodeKloud 플랫폼에서 직접 실습해보는 랩.

## 내용
- KodeKloud 랩 접근 방법: 코스의 KodeKloud 링크로 이동 → 로그인/계정 생성 → 등록 후 모든 랩·레슨에 접근.
- 이 레슨(Airflow를 활용한 데이터 파이프라인 오케스트레이션)에 대한 실습 랩 링크가 제공됨.

## 요약
- 이 랩은 앞선 Airflow 데모(Docker Compose 환경 구축, IoT 데이터 DAG 작성)를 KodeKloud 환경에서 직접 실습해볼 수 있도록 연결하는 자료다.
