# Large Datasets: Apache Spark (PySpark), Dask

## 개요
- 왜 Apache Spark 같은 분산 처리 도구가 필요한지, 그리고 Spark의 4가지 핵심 특징(분산 처리, 장애 허용성, 인메모리 연산, 통합 API)을 설명하는 3분 영상.

## 내용

### Apache Spark가 등장한 배경
- 이전 영상에서는 Pandas로 작은 파일(약 50MB)의 데이터 정제·변환을 다뤘음.
- 실제 사용 사례에서는 파일이 하나가 아니라 수천 개일 수 있고, 크기도 약 500GB에 달할 수 있음 — 이는 서버 하나의 메모리에 담길 수 없음.
- 이때 필요한 것이 **분산 데이터 처리(distributed data processing)**이며, 여기서 Apache Spark가 강점을 발휘함.

### Apache Spark란
- 클러스터 내 여러 노드에 걸쳐 대규모 데이터셋을 처리하는 분산 컴퓨팅을 활용 — 작업이 병렬로 실행되어 전체 처리 시간을 크게 단축.
- 데이터 변환 능력 덕분에 이커머스, 헬스케어 같은 산업에서 즐겨 사용 — 예: 고객 클릭스트림 데이터를 분석해 실시간 상품 추천을 생성. Spark는 초당 수백만 건의 이벤트를 처리해 실행 가능한 인사이트를 제공.

### Spark의 4가지 핵심 강점

1. **분산 처리와 속도**: 대규모 데이터셋을 클러스터 전반에 나눠 병렬 처리. 예: 제조업의 예지 정비(predictive maintenance)를 위한 IoT 센서 데이터 처리.
2. **장애 허용성(Fault Tolerance)**: **RDD(Resilient Distributed Datasets)** 방식으로 노드 장애로부터 자동 복구. 예: 금융 기관의 거래 처리 — 클러스터 노드가 다운되어도 데이터 무결성과 처리 연속성을 보장.
3. **인메모리 연산으로 효율성 확보**: 디스크가 아닌 메모리에서 데이터를 처리해 지연시간(latency)을 줄임 — 실시간 인사이트가 수백만 달러를 절약할 수 있는 사기 탐지(fraud detection)에 특히 유용.
4. **통합 API로 다양성 확보**: Python, Java, Scala 등 여러 프로그래밍 언어를 지원해 다양한 전문성을 가진 팀이 효과적으로 협업 가능. (참고: Apache Spark 자체는 **Scala**로 작성됨.)

### MLOps에서의 활용
- MLOps 엔지니어링에서 Apache Spark는 **온라인 서빙(online serving)** 시점에 ML 모델에 실시간 데이터를 공급하기 위한 처리에 활용될 수 있음 — ML 모델에 투입하기 위해서는 실시간으로 많은 집계(aggregation) 작업이 필요하기 때문에 중요.

## 요약
- Apache Spark는 분산 처리·장애 허용성(RDD)·인메모리 연산·다중 언어 API 지원을 통해 대규모 데이터셋을 고성능으로 처리하는 프레임워크이며, MLOps에서는 온라인 서빙을 위한 실시간 데이터 집계에 특히 유용하다.
