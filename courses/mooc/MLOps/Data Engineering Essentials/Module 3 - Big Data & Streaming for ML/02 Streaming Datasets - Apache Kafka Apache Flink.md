# Streaming Datasets: Apache Kafka, Apache Flink

## 개요
- IoT 공장 모니터링 사례로 Apache Kafka(실시간 데이터 수집·메시징)와 Apache Flink(실시간 처리·분석)의 역할 분담을 설명하는 6분 영상.

## 내용

### 실제 사례 — 공장 모니터링
- 24/7 가동되는 대규모 공장의 여러 기계 — 성능을 파악해 문제를 사전에 예측·수리하면 생산성이 개선됨.
- IoT 기기가 유휴 온도, 과거 지표, 생산량 등의 정보를 각 기계 센서로부터 캡처 → 이 데이터가 실시간으로 수집·처리되어 운영 엔지니어가 볼 수 있는 대시보드로 표시되어야 함.
- 흐름: 데이터를 **Apache Kafka**로 전송 → Kafka로부터 **Apache Flink**가 실시간 집계 수행 → 집계된 데이터를 데이터베이스의 다른 데이터와 결합 가능 → 최종적으로 공장 기계의 상태·지표를 보여주는 대시보드 구성.
- 이는 실시간 스트리밍, 실시간 모니터링, 이벤트 기반 아키텍처 문제를 해결하는 실제 사례이며, 머신러닝 모델의 **온라인 추론(online inference)**에도 유용.

### Apache Kafka
- 실시간 데이터 스트림 관리에 탁월 — 낮은 지연시간 처리와 높은 처리량(throughput) 제공. 데이터 일관성과 속도가 중요한 애플리케이션의 대표적 선택.
- **4가지 핵심 특징**:
  1. **처리량과 데이터 스트리밍**: 최소한의 지연시간으로 실시간 데이터 스트림 관리 — 예: 금융 서비스의 사기 탐지 같은 이벤트 기반 시스템에 이상적.
  2. **대규모 워크로드를 위한 확장성**: 브로커(broker, Kafka 인프라에 추가되는 컴퓨트·스토리지)를 추가해 수평적으로 확장 — 증가하는 데이터셋을 매끄럽게 처리.
  3. **메시징 시스템의 장애 허용성**: 복제(replication)와 내구성(durability)으로 신뢰할 수 있는 메시지 전달 보장 — 미션 크리티컬한 애플리케이션에 적합.
  4. **분산 아키텍처에 따른 유연성**: 다양한 사용 사례에 다재다능함. 실시간 응답 시스템을 갖춘 많은 조직이 배경에서 Kafka를 활용 중.

### Apache Flink
- Kafka가 데이터 수집·스트리밍을 담당한다면, **Flink**는 강력한 실시간 처리 도구 역할.
- 실시간/이벤트 기반 애플리케이션과 배치 처리 모두를 위해 만들어진 스트림 처리 프레임워크 — 밀리초 단위 지연시간의 복잡한 데이터 흐름 처리에 특화.
- **상태 유지형(stateful) 스트림 처리 시스템**으로 고급 분석을 가능하게 하며, 배치·스트림 처리 모두 지원.
- 예: Kafka에 서로 다른 두 종류의 데이터가 서로 다른 토픽(topic)에 저장되고 있을 때, 이 두 토픽의 정보를 실시간으로 결합·집계하는 것이 바로 Flink가 할 수 있는 일.
- **4가지 핵심 특징**:
  1. **이벤트 기반 처리**: 이벤트가 발생하는 즉시 데이터를 처리 — 예: 라이드셰어링 앱의 실시간 수요·공급 기반 동적 가격 책정.
  2. **상태 유지형 스트림 처리**: 복잡한 데이터 흐름 동안 상태를 유지 — 예: 스마트홈의 온도 센서를 모니터링해 이상 징후 탐지.
  3. **정확히 한 번(Exactly-Once) 시맨틱스**: 각 이벤트가 정확히 한 번만 처리됨을 보장 — 금융 거래 처리 같은 시나리오에서 정확성 보장.
  4. **다른 빅데이터 도구와의 매끄러운 통합**: Kafka, Hadoop, NoSQL 같은 데이터 소스와 원활하게 작동해 대규모 시스템의 실시간 분석 가능.

### 핵심 통찰
- Kafka는 실시간 데이터 수집·메시징을 담당하고, Flink는 이 데이터를 실시간으로 처리·분석 — 둘이 함께 확장 가능하고 신뢰할 수 있는 이벤트 기반 애플리케이션 생태계를 구성.
- MLOps 엔지니어로서 Flink나 Kafka를 직접 다루는 방법을 알거나, 최소한 이 도구들이 존재하며 실시간으로 필요한 데이터를 이들과 통합하는 방법을 아는 것이 중요.

## 요약
- Apache Kafka는 낮은 지연시간·고처리량·확장성·장애 허용성을 갖춘 실시간 메시징 시스템이고, Apache Flink는 이벤트 기반·상태 유지형·정확히 한 번 처리를 보장하는 실시간 스트림 처리 프레임워크이며, 이 둘의 조합이 ML 모델의 온라인 추론에 필요한 실시간 데이터 파이프라인의 핵심을 이룬다.
