# Lab: Stream Data using Apache Kafka

## 개요
- Demo 1~3에서 다룬 Kafka 클러스터 구축, 토픽 생성, 프로듀서·컨슈머 스크립트 작성을 KodeKloud 플랫폼에서 직접 실습해보는 랩.

## 내용
- KodeKloud 랩 접근 방법: 코스의 KodeKloud 링크로 이동 → 로그인/계정 생성 → 등록 후 모든 랩·레슨에 접근.
- 이 레슨(Apache Kafka를 활용한 데이터 스트리밍)에 대한 실습 랩 링크가 제공됨.

## 요약
- 이 랩은 앞선 3개의 Kafka 데모(환경 구축, 프로듀서, 컨슈머)를 KodeKloud 환경에서 직접 실습해볼 수 있도록 연결하는 자료다.
