# Lesson Reflection — Selecting the Appropriate Model(s) for a Given Machine Learning Problem

## 개요
- Lesson 1 전체를 요약하는 공식 회고 자료: Amazon SageMaker로 비즈니스 문제를 해결하는 머신러닝 파이프라인 구현의 핵심 단계를 다뤘다.

## 내용

### 핵심 포인트
- 문제를 정량적인 비즈니스 용어로 프레이밍한다.
- 모델링 전에 지저분한 데이터를 정제한다.
- 확장 가능한 학습을 위해 SageMaker를 사용한다.
- 배포 전에 모델을 검증한다.
- 하이퍼파라미터를 최적화한다.

### 회고 질문
1. 지저분한 데이터셋 변수를 인코딩·정제하는 데 가장 유용했던 기법은 무엇이었는가?
2. SageMaker Autopilot과 커스텀 모델링 중 언제 무엇을 사용할지 어떻게 판단하겠는가?
3. 자신의 비즈니스 문제에 가장 의미 있는 평가 지표는 무엇인가?
4. 모델을 프로덕션에 배포할 때 준비가 되었음을 나타내는 요인은 무엇인가?
5. 자신의 사용 사례에서 어떤 하이퍼파라미터가 모델 정확도에 가장 큰 영향을 미치는 것으로 보이는가?

### 도전 과제
1. 모호한 비즈니스 이슈를 정량적으로 머신러닝 문제로 정형화해보기.
2. 테이블형 데이터셋을 불러와 Pandas로 정제·탐색해보기.
3. SageMaker에서 최소 두 개의 모델을 학습해 평가 지표를 비교해보기.
4. 가장 성능이 좋은 모델을 배포하기 위한 SageMaker 엔드포인트를 만들어보기.
5. SageMaker Hyperparameter Tuning으로 모델의 하이퍼파라미터를 튜닝해보기.

## 요약
- Lesson 1은 지도학습 vs 비지도학습 개념 → 휴리스틱 vs ML 선택 기준 → 비즈니스 문제 프레이밍(분류/회귀/예측/클러스터링/추천)까지, 적절한 모델을 선택하는 사고 과정을 다뤘다.
