# Introducing Computer Vision

## 개요
- AWS Academy Machine Learning Foundations Module 5 자료(오디오 요약 1분 37초) — **Amazon Rekognition**을 활용한 이미지·영상 분석을 소개하는 읽기 자료.

## 내용

### 요약
- 컴퓨터 비전 개념과 이미지·영상 분석을 위한 Amazon Rekognition 사용법 개괄. 얼굴 인식, 객체 탐지 같은 흔한 사용 사례를 다룸.
- **Amazon SageMaker Ground Truth**로 커스텀 레이블 데이터셋을 준비하고 모델 정확도를 평가하는 세부 내용 포함.

### 핵심 포인트
- 컴퓨터 비전은 디지털 이미지에서 정보를 추출한다.
- Amazon Rekognition은 객체, 장면, 얼굴 등을 탐지한다.
- 커스텀 모델은 레이블이 있는 학습 데이터가 필요하다.
- SageMaker Ground Truth는 데이터셋 레이블링을 돕는다.
- 정밀도(precision)와 재현율(recall) 같은 지표로 모델을 평가한다.

### 성찰 질문
1. 자신의 비즈니스 도메인에 유용할 수 있는 컴퓨터 비전 기법은 무엇인가?
2. 이미지·영상 데이터를 다루면서 어떤 어려움을 겪었는가?
3. 커스텀 레이블 데이터셋이 일반 이미지 분류기보다 어떻게 개선될 수 있는가?
4. 전체 정확도 대신 정밀도와 재현율을 평가하는 이유는 무엇인가?
5. 얼굴 분석 사용 사례에서 어떤 윤리적 고려사항이 발생하는가?

### 도전 과제
1. 관심 있는 5개 카테고리에 대해 Rekognition으로 이미지 분류기를 만들어보기.
2. SageMaker Ground Truth로 제품 이미지 데이터셋에 레이블을 붙여보기.
3. 커스텀 모델을 학습해 정밀도/재현율 지표를 비교해보기.
4. 샘플 유명인 이미지에서 얼굴 속성과 감정을 분석해보기.
5. Rekognition의 이미지/프레임 분석으로 영상 검색 파이프라인을 프로토타이핑해보기.

## 요약
- Amazon Rekognition은 얼굴 인식·객체 탐지 같은 컴퓨터 비전 작업을 지원하며, SageMaker Ground Truth로 커스텀 레이블 데이터셋을 만들고 정밀도·재현율로 모델을 평가하는 흐름을 다룬다. 얼굴 분석에는 윤리적 고려사항도 함께 따른다.
