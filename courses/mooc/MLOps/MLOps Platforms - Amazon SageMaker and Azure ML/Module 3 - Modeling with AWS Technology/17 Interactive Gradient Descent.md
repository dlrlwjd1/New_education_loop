# Interactive Gradient Descent

## 개요
- 간단한 이차함수 f(x)=x²에 대해 경사하강법(gradient descent) 최적화를 직접 코드로 구현해보는 인터랙티브 실습 자료(오디오 요약 1분 1초).

## 내용

### 랩 목표
- 간단한 이차함수에 대한 경사하강법 최적화를 구현하기.

### 랩 설명
- f(x)=x²의 최솟값을 찾는 경사하강법을 코딩.
- 도함수(derivative)를 계산하고 매 단계마다 x를 업데이트하며 알고리즘을 반복.
- 플롯으로 최적화 경로를 확인.

### 성찰 질문
1. 학습률이 수렴에 어떤 영향을 미치는가?
2. 전역 최솟값 vs 지역 최솟값을 찾는 데 어떤 어려움이 있는가?
3. 경사하강법을 위해 함수의 도함수를 계산해야 하는 이유는 무엇인가?
4. 무엇이 경사하강법을 발산(diverge)하게 만드는가?
5. 경사하강법이 아닌 다른 최적화 방법을 사용해야 하는 경우는 언제인가?

### 도전 과제
1. 랩 코드에서 다양한 학습률을 실험해보기.
2. 다른 초기 x값으로 시도해보기.
3. x³ 같은 다른 간단한 함수를 최소화하도록 코드를 수정해보기.
4. 매 반복마다 f(x)를 출력해 최소화 과정을 보여주기.
5. 작은 임계값 아래로 완전히 수렴할 때까지 반복을 확장해보기.

## 예시
```python
import numpy as np

# 최소화할 예시 함수
def f(x):
    return x**2

# 함수의 도함수
def df(x):
    return 2*x

learning_rate = 0.1

# 경사하강법 알고리즘
x = 5  # 초기값
for i in range(10):
    x -= learning_rate * df(x)
    print(f"Iteration {i+1}: x = {x}")

print(f"Final value of x: {x}")
```

## 요약
- 이 실습은 앞서 Key Terms와 "Solving Optimization Problems"에서 다룬 경사하강법·학습률·전역/지역 최솟값 개념을 f(x)=x²라는 가장 단순한 함수에 직접 코드로 적용해보며 확인하는 인터랙티브 자료다.
