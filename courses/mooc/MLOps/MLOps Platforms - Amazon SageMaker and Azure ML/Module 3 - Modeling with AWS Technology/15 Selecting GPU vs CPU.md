# Selecting GPU vs. CPU

## 개요
- 학습(training) 또는 추론(inference) 작업에서 CPU와 GPU 중 무엇을 선택할지에 대한 트레이드오프를 설명하는 1분 영상.

## 내용

### CPU
- 저렴하고 **단일 목적(single purpose)**으로 만들어진 칩.
- 스프레드시트를 여는 것 같은 작업에는 훌륭하지만, **병렬 처리**용으로 설계되지 않았기 때문에 병렬 처리에는 덜 적합함.

### GPU
- **고밀도(high density)**로 설계되어 있어 병렬 처리에 특화됨. 다만 비용이 더 높음 — 그 높은 비용이 병렬로 작업을 수행할 수 있게 해줌.

### 선택 기준
- CPU와 GPU 사이의 트레이드오프는 결국 **어떤 문제를 얼마나 빠르게 풀고 싶은가**에 달려 있음.
- 시간이 중요하지 않거나, 배치(batch)로 처리해도 되고 긴급하지 않다면 → **CPU**가 좋은 선택일 수 있음.
- 매우 높은 성능이 필요하고 대규모 병렬 연산을 수행해야 한다면 → **GPU**가 좋은 선택 — 학습 시간이나 추론 시간을 크게 단축시킬 수 있음.

## 요약
- CPU는 저렴하지만 병렬 처리에 약하고, GPU는 비싸지만 병렬 처리에 강하므로, 시간 제약이 없는 배치 작업에는 CPU를, 대규모 병렬 연산이 필요한 고성능 작업에는 GPU를 선택하는 것이 합리적이다.
