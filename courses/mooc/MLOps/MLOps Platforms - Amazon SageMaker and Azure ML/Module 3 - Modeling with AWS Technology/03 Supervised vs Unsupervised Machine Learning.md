# Supervised vs. Unsupervised Machine Learning

## 개요
- NBA 데이터 사례로 지도학습(예측)과 비지도학습(패턴 발견)의 핵심 차이, 그리고 둘이 어떻게 연계될 수 있는지 설명하는 2분 영상.

## 내용

### 지도학습(Supervised Machine Learning)
- 레이블이 있는 과거 데이터를 사용해 예측을 수행.
- 예: 경기당 득점(points per game)을 사용해 연봉(salary)을 예측 — 득점이라는 레이블 기반의 지도학습 예측으로 salary라는 타깃을 예측.
- 레이블이 있는 데이터, 특히 숫자 형태의 테이블형 데이터가 있다면 지도학습으로 문제를 풀 수 있음.

### 비지도학습(Unsupervised Machine Learning)
- 핵심 아이디어: **숨겨진 패턴을 발견**하고, 그 패턴이 이후 레이블이 될 수 있음.
- 예: 득점, 어시스트, 리바운드로 클러스터링 — NBA에서 누가 최고 득점자인지, 누가 포인트 가드인지, 누가 센터인지를 발견할 수 있음.
- 클러스터링하면 다차원 공간에서 이 값들이 서로 가장 가까운 위치로 자연스럽게 그룹화됨.
- 이후 **도메인 전문가**가 이 숨겨진 패턴에 이름(notation)을 붙여 데이터셋에 레이블로 적용하는 것이 일반적.

### 핵심 차이와 연계
- 핵심 차이: 비지도학습은 **발견(discovery)**, 지도학습은 **이미 레이블된 데이터로 예측을 수행하는 것**.
- 둘은 함께 작동할 수 있음 — 비지도학습이 첫 단계로 데이터의 레이블을 찾아내고, 그다음 단계로 그 데이터를 사용해 지도학습 예측을 수행하는 흐름이 가능.

## 요약
- 지도학습은 레이블이 있는 데이터로 예측하는 것이고, 비지도학습은 숨겨진 패턴을 발견해 레이블을 만들어내는 것이며, 실제로는 비지도학습으로 레이블을 발견한 뒤 그 레이블로 지도학습 예측을 수행하는 파이프라인으로 연계되는 경우가 많다.
