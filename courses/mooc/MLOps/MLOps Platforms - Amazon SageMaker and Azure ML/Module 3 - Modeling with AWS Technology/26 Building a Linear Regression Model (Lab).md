# Building a Linear Regression Model (Lab)

## 개요
- 키(height)로 몸무게(weight)를 예측하는 선형 회귀 모델을 만들고, 피처를 추가했을 때 예측 정확도가 개선되는지 확인해보는 1시간짜리 실습 랩(ungraded lab).

## 내용

### 과제
1. 노트북을 실행해 키로 몸무게를 예측하는 정확도를 확인하기.
2. 모델에 피처를 더 추가하면 예측 정확도가 더 높아지는지 확인하기.
3. 노트북을 결론(conclusion)과 함께 GitHub 리포지토리에 포트폴리오 프로젝트로 게시하기.

## 요약
- 이 랩은 단순 선형 회귀(키 → 몸무게)에서 시작해 피처 추가에 따른 정확도 변화를 실험하고, 최종적으로 GitHub에 포트폴리오로 게시하는 실습이다.
