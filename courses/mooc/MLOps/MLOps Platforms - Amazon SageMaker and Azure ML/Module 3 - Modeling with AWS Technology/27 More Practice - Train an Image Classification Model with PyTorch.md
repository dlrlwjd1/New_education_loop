# More Practice: Train an Image Classification Model with PyTorch

## 개요
- 이미지 분류(컴퓨터 비전의 하위 분야)의 개념을 소개하고, SageMaker Studio Lab에서 PyTorch로 이미지 분류 모델을 학습해볼 수 있는 실습 노트북 링크를 안내하는 자료(오디오 요약 46초).

## 내용

### 소개
- **이미지 분류(Image Classification/Recognition)**는 컴퓨터 비전의 하위 분야로, 알고리즘이 이미지를 보고 사전에 학습된 태그·카테고리 목록 중 하나를 할당하는 작업.
- 시각(vision)은 인간이 세상을 인식하는 데 있어 80~85%를 차지하며, 인간은 일상적으로 마주치는 데이터를 자연스럽게 분류함.
- 그래서 신경망으로 분류 작업을 모방하는 것은 연구자들이 컴퓨터 비전에서 가장 먼저 떠올린 활용 사례 중 하나.

### 직접 해보기
