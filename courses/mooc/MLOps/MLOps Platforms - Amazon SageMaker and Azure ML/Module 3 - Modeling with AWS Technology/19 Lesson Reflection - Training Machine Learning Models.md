# Lesson Reflection — Training Machine Learning Models

## 개요
- Lesson 2 전체를 요약하는 공식 회고 자료: 머신러닝 모델을 학습시키는 기법들을 다뤘다. 알고리즘 선택으로 시작해 모델링을 최적화 문제로 프레이밍했고, 지역 최솟값·학습률·경사하강법의 역할을 논의했다. 교차 검증을 포함한 학습/테스트 분할 전략으로 과적합을 방지하는 방법과, 신경망 같은 아키텍처, 직관을 쌓는 도구들도 소개했다.

## 내용

### 핵심 포인트
- 문제를 프레이밍하고 적합한 알고리즘을 선택한다.
- 경사하강법 같은 최적화 방법을 사용한다.
- 학습/테스트 분할로 과적합을 줄인다.
- 하이퍼파라미터와 아키텍처를 튜닝한다.
- 실험을 통해 직관을 쌓는다.

### 회고 질문
1. 회귀 알고리즘과 분류 알고리즘은 각각 어떤 문제에 가장 적합한가?
2. 학습률은 경사하강법의 수렴과 정확도에 어떤 영향을 미치는가?
3. 모델 학습 중 과적합을 줄이는 데 어떤 전략이 도움이 되는가?
4. 신경망 등 ML 모델이 지역 최솟값에 갇히는 원인은 무엇인가?
5. 정규 교육 외에 ML 개념에 대한 직관을 기르는 데 어떤 기법이 도움이 되는가?

### 도전 과제
1. TensorFlow Playground를 사용해 배치 크기, 학습률 같은 하이퍼파라미터를 조정하며 최적화를 실험해보기.
2. 데이터를 분할할 때 교차 검증을 활용해 과적합을 줄여보기.
3. 샘플 과제에서 다양한 활성화 함수와 네트워크 아키텍처를 시도해보기.
4. 다양한 학습률로 경사하강법을 구현해 f(x)=x² 같은 함수를 최소화해보기.
5. 온라인 코스, Kaggle 대회, 연구 논문 읽기를 통해 시야를 넓혀보기.

## 요약
- Lesson 2는 AutoML/SageMaker Canvas를 통한 모델 선택 → 학습/테스트 분할과 교차 검증 → 최적화(경사하강법, 학습률, 지역/전역 최솟값) → GPU/CPU 선택 → 신경망 아키텍처(TensorFlow Playground)까지 모델 학습의 전체 파이프라인을 다뤘다.
