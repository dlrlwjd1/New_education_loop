# Introduction to Implementing a Machine Learning Pipeline with Amazon SageMaker

## 개요
- AWS Academy Machine Learning Foundations 코스 Module 3 자료(오디오 요약 1분 40초) — 문제 정의부터 배포까지 완전한 머신러닝 파이프라인 구현 개요를 소개하는 읽기 자료.

## 내용

### 머신러닝 파이프라인 개요
- 완전한 머신러닝 파이프라인을 구현하는 데는 문제 정의(problem formulation), 데이터 수집, 데이터 준비, 모델 학습, 평가, 배포 등 여러 단계가 포함됨.
- **Amazon SageMaker**는 파이프라인의 많은 부분을 지원하는 도구를 제공.

### 핵심 포인트
- 비즈니스 문제를 **정량적으로 프레이밍**한다.
- 모델링 전에 데이터를 정제·전처리한다.
- SageMaker 내장 알고리즘으로 학습한다.
- 배포 전에 모델 정확도를 검증한다.
- 성능 최적화를 위해 하이퍼파라미터를 튜닝한다.

### 성찰 질문
1. 모호한 비즈니스 문제를 머신러닝에 적합한 정량적 용어로 어떻게 프레이밍할 수 있는가?
2. 모델 학습 전에 고쳐야 할 흔한 데이터 문제는 무엇인가?
3. 커스텀 모델링 대신 SageMaker Autopilot을 선택할 시점은 언제인가?
4. 분류 모델과 회귀 모델을 평가하는 데 어떤 지표를 사용하겠는가?
5. 모델이 프로덕션 배포 준비가 되었는지 어떻게 판단하겠는가?

### 도전 과제
1. 관심 있는 비즈니스 문제를 머신러닝 문제로 정형화해보기.
2. 데이터셋을 Pandas로 프로그래밍 방식으로 탐색해 정제·시각화해보기.
3. SageMaker 내장 알고리즘 중 하나로 모델을 학습해보기.
4. 학습된 모델의 테스트 데이터에 대한 평가 지표를 계산해보기.
5. SageMaker Hyperparameter Tuning으로 모델의 하이퍼파라미터를 최소 1개 튜닝해보기.

## 요약
- 이 자료는 "문제 정의 → 데이터 준비 → SageMaker 내장 알고리즘 학습 → 평가 → 하이퍼파라미터 튜닝 → 배포"로 이어지는 완전한 머신러닝 파이프라인을 SageMaker 도구와 함께 개괄한다.
