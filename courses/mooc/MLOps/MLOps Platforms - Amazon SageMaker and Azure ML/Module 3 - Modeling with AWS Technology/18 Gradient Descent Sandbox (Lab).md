# Gradient Descent Sandbox (Lab)

## 개요
- 살아있는(live) Jupyter 노트북에서 셀을 반복 실행하며 경사하강법 최적화를 직접 실험해보는 1시간짜리 실습 랩(ungraded lab) — "Interactive Gradient Descent" 자료의 실습 버전.

## 내용

### 랩 목표
- Jupyter 노트북에서 셀을 반복 실행하며 경사하강법 최적화를 실험하기.

### 랩 설명
- 라이브 Jupyter 노트북에서 경사하강법을 구현해 f(x)=x²를 최소화.
- 코드 셀을 실행해 문제를 정의하고, 경사하강법을 실행하고, 최적화 경로를 시각화.
- 파라미터를 조정하고 셀을 다시 실행하며 학습률·수렴 임계값 등 다양한 하이퍼파라미터가 성능에 미치는 영향을 직관적으로 파악.

### 랩 단계
1. 라이브러리(matplotlib, numpy) 임포트.
2. 목적 함수 f(x)=x² 정의.
3. 도함수 df(x)/dx 계산.
4. 경사하강법 설정 초기화.
5. 경사하강법 셀 실행.
6. 시각화 플롯.
7. 학습률, 반복 횟수 등 파라미터 조정.
8. 셀을 다시 실행하며 효과 실험.

### 성찰 질문
1. 학습률이 수렴 속도와 정확도에 어떤 영향을 미치는가?
2. 무엇이 경사하강법을 발산하게 만드는가?
3. 손실을 최소화해야 하는가, 아니면 df(x)의 절댓값을 최소화해야 하는가?
4. 시각화를 개선하기 위해 코드를 어떻게 조정할 수 있는가?
5. 어떤 다른 목적 함수로 실험해볼 수 있는가?

### 도전 과제
1. 다양한 학습률과 반복 횟수를 시도해보기.
2. 함수를 f(x) = x³으로 수정해보기.
3. 반복마다 f(x)를 출력해 최소화 과정을 보여주기.
4. 수렴 임계값을 설정해 도달 시 조기 종료하도록 만들기.
5. 경사하강법을 다른 SciPy 최적화 함수와 비교해보기.

## 요약
- 이 랩은 "Interactive Gradient Descent"의 f(x)=x² 최소화 코드를 실제 Jupyter 노트북 환경에서 반복 실행하며, 학습률·초기값·목적 함수를 바꿔가며 경사하강법의 동작을 체득하는 실습이다.
