# Modeling Demo with SageMaker Canvas

## 개요
- **Amazon SageMaker Canvas**(로우코드/노코드 ML 도구)로 메이저리그 야구(MLB) 데이터를 가져와 선수 포지션을 예측하는 모델을 만들고, 정확도·정밀도·재현율 등 다양한 평가 지표를 살펴보는 5분 데모.

## 내용

### 데이터 수집(Ingestion)
- SageMaker Canvas의 **Import**에서 로컬 파일을 드래그하거나 S3에서 데이터를 가져올 수 있음 — 이번 데모는 메이저리그 야구 데이터를 S3에서 가져와 분석.

### 데이터 탐색 — Excel과 유사한 ML 특화 기능
- "New Baseball Model" 생성 → MLB 데이터셋 선택.
- 각 컬럼의 데이터 타입, 결측 데이터 유무, 값 불일치 여부, 고유값 개수, 평균·최빈값(mode)까지 자동으로 보여줌.
- **Visualize**로 키(height)와 몸무게(weight) 사이의 관계 같은 것을 시각적으로 즉시 확인 가능.
- Excel과 유사한 폼(form) 함수 기능도 지원 — 머신러닝에 특화된 형태.

### 모델 생성과 예측 대상 선택
- 예측하고자 하는 컬럼 선택 — 키, 몸무게, 나이, 팀, **포지션(position)** 중 포지션을 선택.
- 포지션에는 구원투수(relief pitcher), 선발투수(starting pitcher) 등 총 7개 카테고리 존재.
- **Validate**로 데이터가 올바른지 확인 → **Quick Build**로 빠르게 모델 생성.

### 모델 정확도와 평가 지표
- 완성된 모델은 전체 포지션 예측에서 **37%의 정확도**를 보임.
- 포지션별 예측력을 세부적으로 확인 가능 — 예: **구원투수**는 상대적으로 예측이 잘 되는 포지션 중 하나 — 키·몸무게만으로 41% 확률로 정확히 예측, 실제 구원투수인 경우의 73%를 정확히 식별.
- **F1, 평균 정확도(accuracy), 평균 정밀도(precision), 평균 재현율(recall), 평균 AUC** 등 고급 지표 확인 가능.
  - **정밀도(precision)** 예: 포수(catcher)로 예측된 모든 경우 중 실제로 맞은 비율이 28%.
  - **재현율(recall)** 예: 실제 포지션이 포수인 경우 중 모델이 정확히 포수로 예측한 비율이 13%.
  - **정확도(accuracy)**: 전체 예측 중 맞은 비율.
  - **F1**: 클래스 불균형(class balance)을 고려한 균형 잡힌 정확도 지표.
- **혼동 행렬(confusion matrix)**로 True Positive/False Positive 등을 구원투수·포수 사례로 확인 가능.
- 완성된 모델이나 시각화를 다운로드해 대시보드에 활용 가능.

## 요약
- SageMaker Canvas는 데이터 임포트부터 자동 데이터 프로파일링, Quick Build 모델 생성, 그리고 정확도·F1·정밀도·재현율·혼동 행렬까지 상세한 평가 지표를 코드 없이 제공하는 도구이며, 각 지표의 의미를 툴팁으로 직접 설명해줘 데이터 과학 개념을 배우는 데도 유용하다.
