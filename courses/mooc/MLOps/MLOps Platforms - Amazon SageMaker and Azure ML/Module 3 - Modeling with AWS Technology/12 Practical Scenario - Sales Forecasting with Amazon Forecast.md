# Practical Scenario — Sales Forecasting with Amazon Forecast

## 개요
- Amazon Forecast와 SageMaker Canvas 지식을 적용해보는 5분짜리 AI 생성 인터랙티브 성찰 활동.

## 내용

### 시나리오
- 소매 회사의 데이터 과학자로서, 신제품 라인의 다음 달 매출을 예측해야 함. 과거 매출 데이터를 확보했고 **Amazon Forecast** 사용을 고려 중.
- 질문: Amazon Forecast에 대해 배운 내용을 바탕으로, 특히 시계열 데이터의 어려움을 고려할 때 이 매출 예측 과제에 Amazon Forecast가 제공하는 핵심 이점은 무엇인가?

### 종합 답변 (강의 개념 기반)
- **예측기 모델 구축 자동화**: Amazon Forecast는 예측기(predictor) 모델 구축 과정을 자동화해, 여러 알고리즘을 직접 일일이 구현하지 않고도 다양한 시계열 예측 모델을 시도해볼 수 있음.
- **시계열 데이터 특유의 어려움 처리**: 결측 타임스탬프, 이상치, 불규칙한 시간 간격 같은 시계열 데이터 고유의 문제를 다루도록 설계되어 있어, 신제품처럼 과거 데이터가 제한적이거나 불완전할 수 있는 상황에도 적합.
- **다각도 정확도 평가**: 단순 RMSE뿐 아니라 **분위수 손실(quantile loss, wQuantileLoss)**로 예측을 평가할 수 있어, "평균적으로 얼마나 팔릴까"뿐 아니라 "최악의 경우/최선의 경우 얼마나 팔릴까"까지 분위수별로 파악 가능 — 재고 계획처럼 리스크 관리가 중요한 소매 매출 예측에 특히 유용.
- **관련 데이터 통합**: 프로모션 등 관련된 다른 시계열 데이터를 병합해 예측 정확도를 높일 수 있음 — 신제품 출시 시점의 프로모션 계획을 함께 반영하면 더 정교한 예측이 가능.
- **백테스팅**: 과거 데이터로 모델을 백테스트해 실제 배포 전에 정확도를 검증할 수 있음.

## 요약
- Amazon Forecast는 예측 모델 구축 자동화, 시계열 특유의 데이터 문제 처리, 분위수 기반의 리스크 인식 정확도 평가, 관련 데이터(프로모션 등) 통합을 통해 신제품 매출 예측처럼 불확실성이 큰 시계열 문제에 특히 유용한 이점을 제공한다.
