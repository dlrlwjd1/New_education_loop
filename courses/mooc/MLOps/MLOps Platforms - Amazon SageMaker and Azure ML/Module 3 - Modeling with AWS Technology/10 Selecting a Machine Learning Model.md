# Selecting a Machine Learning Model

## 개요
- **AutoML**을 탐색 도구로 활용해 적합한 모델과 하이퍼파라미터를 찾는 방법과, 이미 경험이 있는 경우 직접 모델을 선택하는 방법을 비교하는 1분 영상.

## 내용

### AutoML을 활용한 모델 선택
- 문제에 완벽한 정답은 없으며 다양한 기법이 존재. 흥미로운 기법 중 하나는 **AutoML 도구를 먼저 사용**하는 것.
- 단, AutoML을 아무 문제에나 바로 던질 수는 없음 — 먼저 **문제 유형**(회귀 또는 분류 등)을 선택해야 함.
- 예: 분류 문제를 선택했다면, AutoML 시스템이 XGBoost, 로지스틱 회귀 등 다양한 분류 모델과 다양한 하이퍼파라미터 조합(예: 그리드 서치)으로 여러 실험을 수행하도록 설정 가능.
- 이 모든 실험은 **SageMaker 실험 추적**이나 **MLflow 실험 추적** 같은 도구에 기록됨.
- 실험 추적 결과를 확인한 뒤, 풀고자 하는 문제의 정확도·설명 가능성(explainability) 목표에 맞는 모델을 선택.

### 이미 경험이 있는 경우
- 특정 문제에 XGBoost가 잘 맞는다는 것을 이미 알고 있다면, 바로 그 모델로 뛰어들어도 됨.

### 핵심 통찰
- AutoML이 적합한 모델을 선택하는 유일한 방법은 아니지만, 어떤 모델과 하이퍼파라미터가 주어진 문제에 효과적일지 **탐색(discovery)**하는 데 매우 유용한 도구.

## 요약
- 적합한 모델을 선택하는 두 가지 방법은 AutoML로 다양한 모델·하이퍼파라미터 실험을 자동 탐색한 뒤 실험 추적 결과로 최적 모델을 고르는 것과, 이미 특정 문제에 대한 경험이 있다면 곧바로 해당 모델(예: XGBoost)로 진행하는 것이다.
