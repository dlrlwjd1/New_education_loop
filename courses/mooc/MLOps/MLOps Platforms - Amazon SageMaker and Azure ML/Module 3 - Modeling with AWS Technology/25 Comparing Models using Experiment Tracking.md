# Comparing Models using Experiment Tracking

## 개요
- SageMaker 대시보드의 **Training Jobs** 화면에서 완료된 학습 작업들을 필터링·조회하며 실험 추적(experiment tracking)의 핵심 가치를 보여주는 1분 데모.

## 내용

### SageMaker Training Jobs 대시보드
- 완료된 모든 학습 작업(training jobs)을 살펴볼 수 있음.
- 실험 추적의 핵심 아이디어: **상태(status)로 필터링** 가능 — 예: 완료된 작업만 확인하거나 실패한 작업만 확인해, 다음 날 아침 바로 어떤 작업이 성공/실패했는지 파악 가능.
- **작업 이름으로 필터링**도 가능 — 예: "주성분 분석(PCA)"이 포함된 작업만 필터링.
- 세부 사항으로 들어가 다음과 같은 메트릭 확인 가능: 실행 소요 시간, 사용된 학습 이미지(training image), 인스턴스 유형(CPU vs GPU).

### 핵심 통찰
- 이것이 실험 추적과 학습 이력 창(training window)의 핵심 아이디어 — 방대한 작업 이력을 쿼리하고 조회할 수 있게 해줌.
- 100명, 1,000명 규모의 팀이라면, 이런 기능을 통해 원하는 속성으로 필터링해 대규모 학습 환경을 관리할 수 있음.

## 요약
- SageMaker의 실험 추적 대시보드는 상태·이름 등으로 학습 작업을 필터링하고 소요 시간·이미지·인스턴스 유형 같은 세부 메트릭을 조회할 수 있게 해주며, 이는 대규모 팀이 방대한 학습 작업 이력을 관리하는 데 핵심적인 기능이다.
