# When to Use Machine Learning?

## 개요
- 머신러닝과 휴리스틱(heuristic) 중 어느 것을 사용해야 하는지 판단하는 기준을 외판원 문제와 NBA 연봉 예측 사례로 설명하는 1분 영상.

## 내용

### 휴리스틱을 먼저 고려해야 하는 경우
- 문제가 휴리스틱으로 풀릴 수 있다면 **휴리스틱을 먼저** 사용해야 함.
- 예: 배송 회사가 여러 도시를 최단 거리로 방문해야 하는 문제 — 컴퓨터과학의 고전 문제인 **외판원 문제(Traveling Salesman Problem)**.
- 이런 문제는 휴리스틱으로 훨씬 잘 해결됨 — 이미 알려진 해법이 많고 디버깅도 쉬움. 예: 무작위 그리디 시작(random greedy start) → 여러 시뮬레이션 실행 → 최단 경로로 최소화.

### 머신러닝이 적합한 경우
- **레이블이 있는 과거 데이터**가 있는 경우 — 예: 경기당 득점(points per game)과 연봉(salary) 레이블이 있는 노트북 데이터로, 향후 NBA 선수에게 지불할 연봉을 득점 기록 기반으로 예측하고 싶은 경우 — 이것은 머신러닝에 훌륭한 사용 사례.

### 핵심 통찰
- 일반적으로 휴리스틱으로 풀 수 있는 문제라면, 복잡한 머신러닝 접근으로 바로 뛰어들기보다 **먼저 휴리스틱을 시도**해보는 것이 좋음.
- 반대로 **레이블이 있는 테이블형(tabular) 데이터**가 있고, 한 컬럼의 결과를 바탕으로 다른 것을 예측하고 싶다면, 이는 비즈니스 시나리오에서 머신러닝을 적용하기에 좋은 사례.

## 요약
- 문제가 휴리스틱(예: 외판원 문제)으로 풀 수 있다면 먼저 휴리스틱을 시도하고, 레이블이 있는 데이터로 미래 값을 예측해야 하는 경우(예: NBA 연봉 예측)에는 머신러닝을 사용하는 것이 적절하다.
