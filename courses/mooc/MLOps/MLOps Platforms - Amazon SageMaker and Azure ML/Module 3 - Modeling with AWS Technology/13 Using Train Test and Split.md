# Using Train, Test and Split

## 개요
- 머신러닝의 핵심 역량인 **학습/테스트 분할(train/test split)**과, 선택 편향(selection bias)으로 인한 과적합 문제를 완화하는 **교차 검증(cross-validation)**을 설명하는 1분 영상.

## 내용

### 80/20 학습/테스트 분할
- 데이터를 무작위로 **80%(학습용) / 20%(테스트용)**로 나누는 것이 일반적.
- 80%의 학습 데이터로 하이퍼파라미터를 조정하고 적절한 모델을 선택해 최고의 정확도를 찾음.
- 나머지 20%는 학습에 전혀 사용하지 않고 **보류(hold out)**했다가, 모델 성능을 테스트하는 데 사용.
- 이를 통해 모델이 실제 세계에서 어떻게 동작할지 더 현실적으로 이해할 수 있음.

### 남아있는 과적합 위험 — 선택 편향
- 이렇게 해도 여전히 과적합 문제가 발생할 수 있음 — 무작위로 선택된 데이터가 **선택 편향(selection bias)**의 영향을 받을 수 있기 때문(예: 우연히 서로 너무 유사한 데이터가 선택되는 경우).

### 해결책 — 교차 검증(Cross-Validation)
- 데이터를 여러 개의 폴드(fold)로 나눠 각각 80/20으로 분할한 뒤, 이 폴드들을 다시 리샘플링(re-sample)해 함께 사용하는 방법.
- 이것이 과적합 문제를 반드시 해결해준다는 보장은 없고, 애초에 과적합 문제가 있는지 여부도 확정해주지 않음 — 하지만 **선택 편향** 문제가 있다면 교차 검증이 해결책 중 하나가 될 수 있음.
- 과적합 문제가 의심된다면 교차 검증을 시도해볼 가치가 있음.

### 핵심 통찰
- 핵심 직관은, 데이터 선택이 잘못되었을 경우 과적합이 발생할 수 있고, 교차 검증이 이를 해결하는 데 도움이 될 수 있다는 것.

## 요약
- 80/20 학습/테스트 분할은 모델의 실제 성능을 현실적으로 가늠하게 해주지만, 무작위 분할이 선택 편향을 낳아 과적합으로 이어질 수 있어, 이런 경우 여러 폴드를 리샘플링하는 교차 검증이 해결책이 될 수 있다.
