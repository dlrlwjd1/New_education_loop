# Selecting a Machine Learning Solution

## 개요
- AWS 플랫폼에서 올바른 머신러닝 솔루션을 선택하는 두 가지 방법 — 문서 읽기와 비즈니스 문제 프레이밍 — 을 설명하는 1분 영상.

## 내용

### 방법 1 — SageMaker 알고리즘 문서 읽기
- AWS는 SageMaker에 포함된 알고리즘들이 어떻게 동작하는지에 대한 훌륭한 문서를 제공 — 분류, 회귀, 예측(forecasting) 알고리즘 등을 살펴보는 것이 좋은 출발점.

### 방법 2 — 비즈니스 문제를 올바르게 프레이밍하기
- 문제를 어떻게 프레이밍하느냐에 따라 적합한 ML 솔루션이 결정됨:
  - "책 vs 음식"을 구분하고 싶다면 → **분류(classification)** 문제.
  - "경기당 득점"처럼 수치를 예측하고 싶다면 → **회귀(regression)** 문제.
  - 미래의 시계열 이벤트(예: 재고 예측)를 예측하고 싶다면 → **예측(forecasting)** 문제 — SageMaker의 내장 예측 도구나 다른 AWS 예측 도구 활용.
  - 숨겨진 고객 관계를 찾고 싶다면 → **K-평균 클러스터링(K-means clustering)** 문제 — SageMaker K-means 활용.
  - 고객 수를 늘리고 싶다면 → 더 나은 추천을 제공하는 **추천(recommendation)** 문제로 프레이밍 가능.

### 핵심 통찰
- 올바른 머신러닝 솔루션을 찾는 것은 대부분 **프레이밍(framing)의 문제** — 문제를 올바르게 프레이밍하면 어떤 ML 솔루션이 필요한지 훨씬 쉽게 식별할 수 있음.

## 요약
| 비즈니스 문제 | ML 문제 유형 | 예시 SageMaker 도구 |
|---|---|---|
| 카테고리 구분(책 vs 음식) | 분류 | 분류 알고리즘 |
| 수치 예측(득점 등) | 회귀 | 회귀 알고리즘 |
| 미래 시계열 예측(재고 등) | 예측 | SageMaker Forecasting |
| 숨겨진 고객 관계 발견 | 클러스터링 | SageMaker K-means |
| 고객 수 증대(추천) | 추천 | 추천 시스템 |
