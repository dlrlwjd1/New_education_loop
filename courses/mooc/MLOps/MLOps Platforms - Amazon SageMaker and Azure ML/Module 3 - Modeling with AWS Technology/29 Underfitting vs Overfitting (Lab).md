# Underfitting vs Overfitting (Lab)

## 개요
- 합성 데이터에 선형·다항 회귀 모델을 학습시켜 모델 복잡도가 언더피팅과 오버피팅에 미치는 영향을 시각적으로 체험하는 1시간짜리 실습 랩(ungraded lab).

## 내용

### 랩 목표
- 모델 복잡도를 실험해 언더피팅과 오버피팅을 인식하기.

### 랩 설명
- 합성 데이터(synthetic data)에 선형 및 다항(polynomial) 회귀 모델을 학습.
- 모델 복잡도를 조정하고 적합(fit)을 시각화하며 언더피팅, 적절한 적합, 오버피팅에 대한 직관을 기른다.

### 랩 단계
1. 비선형 합성 1차원 데이터 생성.
2. 단순 선형 모델 학습.
3. 모델 예측을 플롯해 언더피팅 여부 평가.
4. 복잡한 7차 다항 모델 학습.
5. 모델 예측을 플롯해 오버피팅 여부 평가.
6. 선형과 7차 다항 사이의 복잡도를 가진 모델들도 시도.

### 성찰 질문
1. 모델이 언더피팅 또는 오버피팅되었음을 나타내는 시각적 단서는 무엇인가?
2. 프로덕션에서 심각하게 오버피팅된 모델은 어떤 위험을 초래하는가?
3. 학습 성능과 검증 성능을 모두 평가하는 이유는 무엇인가?
4. 모델 적합을 평가할 때 합성 데이터가 실제 데이터를 어떻게 보완할 수 있는가?
5. 실제 어떤 시나리오에서 오버피팅이나 언더피팅이 나타날 수 있는가?

### 도전 과제
1. 다항식, 사인함수 등 다양한 피처 변환을 시도해보기.
2. LASSO 같은 정규화 기법으로 오버피팅을 줄이는 방법을 탐구해보기.
3. 더 높은 차원의 합성 데이터를 생성해보기.
4. K-폴드 교차 검증 평가를 구현해보기.
5. 오버피팅을 방지하는 조기 종료(early stopping) 같은 기법을 조사해보기.

## 요약
- 이 랩은 "Overfitting vs. Underfitting" 데모의 개념을 직접 코드로 구현해, 선형 모델(언더피팅)과 7차 다항 모델(오버피팅)의 시각적 차이를 비교하며 적절한 모델 복잡도를 찾는 실습이다.
