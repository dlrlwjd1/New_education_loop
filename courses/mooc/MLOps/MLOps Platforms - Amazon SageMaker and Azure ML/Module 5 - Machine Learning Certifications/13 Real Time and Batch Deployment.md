# Real Time and Batch Deployment

## 개요
- Azure ML Studio에서 모델을 배포하는 두 가지 핵심 방식(배치, 실시간)과 프레임워크 기반 서비스 배포 옵션을 설명하는 2분 영상.

## 내용

### 배치(Batch) vs 실시간(Real-time) 배포
- Azure는 모델 패키징의 복잡함을 추상화해주는 **Azure 웹 서비스**로 직접 배포하는 기능을 제공.
- **배치(Batch)**: 주기적으로 실행 — 예: 매일 밤 한 번씩 신용카드 스코어링을 실행.
- **실시간(Real-time)**: 24/7 가능성을 전제로 동작 — 엔드포인트를 배포해두고 지속적으로 요청을 실시간 엔드포인트에 전달.
- 이 외에도 전체 서비스를 패키징하는 **주변적(peripheral) 옵션**이 존재.

### Azure ML Studio에서 실제로 확인하기
- 모델 예측 인터페이스에서 **"Deploy to real-time"**, **"Deploy to batch"**, **"Deploy to service"** 옵션 확인 가능 — 단, scikit-learn이나 PyTorch 같은 프레임워크 기반 모델에만 해당.
- "Deploy to batch" 선택 시 옵션을 설정하고 구성하면 서비스가 생성됨.
- **기존 엔드포인트(existing endpoint)** 화면에서 등록된 실시간/배치 엔드포인트를 확인 가능 — 배치 엔드포인트는 예약된 시점에 실행되도록 설계되고, 실시간 엔드포인트는 클라이언트로부터 API 요청을 지속적으로 수신하도록 설정.

### 핵심 통찰
- Azure ML Studio에는 몇 가지 핵심 배포 방식이 있으며, 프레임워크를 곧바로 가져와 프로덕션에 배포할 수 있는 고급 옵션도 존재.

## 요약
| 배포 방식 | 실행 패턴 | 사용 사례 |
|---|---|---|
| 배치(Batch) | 주기적(예: 매일 밤) | 신용카드 스코어링 등 예약 작업 |
| 실시간(Real-time) | 24/7 지속 | API 요청에 즉시 응답하는 엔드포인트 |
| 서비스 배포 | 프레임워크(scikit-learn, PyTorch 등) 직접 패키징 | 전체 서비스로 프로덕션 배포 |
