# Lesson Reflection — Introductory Azure ML and MLOps Concepts

## 개요
- Lesson 2 전체를 요약하는 공식 회고 자료: Azure ML Studio 인터페이스, 워크스페이스, 데이터셋 관리, 배포 옵션의 핵심 개념을 다뤘다.

## 내용

### 핵심 포인트
- Azure ML Studio는 Automated ML 실험, 데이터셋 관리, 모델 배포 옵션 같은 Azure ML 기능에 접근하는 인터페이스다.
- 워크스페이스는 데이터셋, 모델, 컴퓨트 클러스터 같은 Azure ML 리소스를 중앙화한다.
- 견고한 데이터셋 도구는 다양한 소스로부터의 수집·프로파일링을 가능하게 한다.
- 유연한 배포 옵션(실시간/배치)은 통합 요구에 따라 서로 다른 애플리케이션을 타깃으로 한다.

### 회고 질문
1. Azure ML Studio 인터페이스는 어떤 문제를 해결하는 데 도움이 되는가?
2. 여러 ML 프로젝트를 어떻게 더 잘 조직할 수 있는가?
3. 어떤 데이터셋 분석이 이해에 도움이 되었는가?
4. 자신의 애플리케이션에 어떤 배포 방식이 적합한가?
5. 자신의 역할에 가장 가치 있어 보이는 기능은 무엇인가?

### 도전 과제
1. Azure ML Studio 인터페이스를 탐색해보기.
2. Azure ML 워크스페이스를 만들어보기.
3. 데이터셋을 수집하고 프로파일링해보기.
4. Automated ML 실험을 실행해보기.
5. 실시간 배포 엔드포인트를 구성해보기.
