# Exploring Open Datasets SDK

## 개요
- Azure ML Studio에 등록된 데이터셋을 GUI에서 살펴본 뒤, **Consume** 탭에서 제공되는 코드 예시를 복사해 노트북에서 Python SDK로 그대로 불러오는 흐름을 보여주는 1분 데모.

## 내용

### GUI에서 데이터셋 살펴보기
- 등록된 Azure Open Dataset을 GUI에서 확인 가능한 것들: 전체 파일 크기, 프로파일링, 기본 탐색(미리보기 제공).

### Consume 탭 — 코드로 가져오기
- **Consume** 탭을 선택하면 이 데이터셋을 코드로 가져오는 **예시 코드**를 제공 — 그대로 복사해 노트북에 붙여넣기만 하면 됨.
- Notebooks로 이동해 복사한 코드 셀을 붙여넣고 실행 → 데이터가 로드되고, 코드 셀 안에서 바로 시각화 확인 가능.
- 이후 기술 통계(descriptive statistics)를 계산하거나 seaborn·matplotlib 같은 라이브러리로 플로팅하는 등 원하는 작업을 이어갈 수 있음.

### 핵심 통찰
- 등록된 데이터셋에서 코드를 그대로 복사해 붙여넣는 것만으로 노트북에 데이터를 통합할 수 있는, 매우 간편한 방법.

## 요약
- Azure ML Studio의 등록된 데이터셋은 Consume 탭에서 제공하는 코드 스니펫을 복사해 노트북에 붙여넣는 것만으로 즉시 Python SDK를 통한 탐색·시각화·통계 분석으로 이어질 수 있다.
