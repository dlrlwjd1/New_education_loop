# Prerequisite Technology

## 개요
- **Azure Associate Data Scientist(DP-100)** 시험을 준비하기 위한 두 가지 기본 준비물 — Azure 프리티어 계정과 GitHub Codespaces — 를 소개하는 1분 영상.

## 내용

### Azure 프리티어(Free Tier) 계정
- DP-100 시험 공부를 시작하기에 좋은 출발점.
- 프리티어 계정을 받으면, 필요한 대부분의 서비스를 **12개월 동안 무료**로 사용 가능하며 이후에는 사용한 만큼 지불(pay-as-you-go).

### GitHub 계정과 Codespaces
- 또 다른 강력한 인터페이스는 GitHub 계정 — **Codespaces**를 사용하면 Azure API를 대상으로 개발할 수 있어 시험 공부에 매우 강력한 방법이 됨.
- Codespaces를 생성해 클라우드 기반 환경에서 개발을 시작하고 Azure와 깊이 통합할 수 있음 — 코드 샘플을 보관하기에도 좋은 장소.

## 요약
- DP-100 시험을 준비하려면 Azure 프리티어 계정(12개월 무료)과 GitHub Codespaces(클라우드 기반 개발 환경 + Azure API 연동)라는 두 가지 준비물로 충분히 시작할 수 있다.
