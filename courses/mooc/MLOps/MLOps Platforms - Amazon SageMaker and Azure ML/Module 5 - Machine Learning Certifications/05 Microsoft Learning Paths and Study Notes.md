# Microsoft Learning Paths and Study Notes

## 개요
- Microsoft Learn의 "컬렉션 → 학습 경로(Learning Path) → 학습 모듈(Learning Module) → 유닛(Unit)" 계층 구조를 살펴보고, 강사가 직접 GitHub에 정리한 자신만의 스터디 노트(Markdown) 작성법을 공유하는 6분 데모.

## 내용

### 학습 콘텐츠의 계층 구조
- **컬렉션(Collection)**이 가장 상위 — 여러 **학습 경로(Learning Path)**의 묶음.
- **학습 경로**는 여러 **학습 모듈(Learning Module)**의 묶음.
- 각 **학습 모듈**은 여러 **유닛(Unit)**(한 페이지 = 한 유닛)으로 구성됨.
- 예시로 살펴본 "AI Fundamentals" 학습 경로는 "Get started with AI on Azure" 모듈을 포함하며, 이 모듈은 10개 유닛으로 구성됨.

### 콘텐츠의 성격
- 콘텐츠 중 상당수는 Azure에 국한되지 않고 **머신러닝 일반 개념**(머신러닝 이해, 이상 탐지 등)을 다룸 — 머신러닝에 이미 능숙하다면 건너뛰어도 되지만, 훑어볼 가치가 있음.
- 각 유닛은 소화하기 쉬운 짧은 분량(대부분 3분, 일부 10분)으로 나뉘어 있고, 로그인하면 진행 상황을 추적하며 이어서 학습 가능.
- 각 유닛에는 비디오와 몇 가지 정의(예: 컴퓨터 비전, 이상 탐지가 무엇인지)가 담겨 있어 매우 소화하기 쉬운 형태로 압축되어 있음.

### 강사의 스터디 노트 작성 전략
- 강사는 AI Fundamentals를 공부하며 학습 경로의 각 섹션을 **개별 Markdown 파일**로 정리해 GitHub 리포지토리에 링크로 구성.
- Markdown 파일이나 리포지토리를 꼭 만들 필요는 없지만, 이 방식은 콘텐츠를 자신의 언어로 다시 써보고, 나중에 한 페이지에서 전체를 쉽게 복습할 수 있게 해주는 좋은 방법.
- 노트는 항상 학습 경로 링크와 학습 모듈 링크를 먼저 기록한 뒤, 자신의 언어로 요약 — 예: "머신러닝이 어떻게 작동하는가", "Azure Machine Learning Studio의 구성 요소" 등, 인증 시험에 중요하다고 생각되는 세부사항을 포착.

### 핵심 통찰
- 이렇게 스터디 가이드를 요약해두는 것은 학습 방법을 강화하고 Azure 인증 시험 합격 준비를 탄탄히 하는 견고한 방법.

## 요약
- Microsoft Learn은 컬렉션 → 학습 경로 → 학습 모듈 → 유닛의 계층으로 학습 콘텐츠를 조직하며, 각 유닛의 핵심 내용을 자신의 언어로 Markdown에 정리해 GitHub에 보관하는 것이 인증 학습을 효과적으로 복습·강화하는 방법이다.
