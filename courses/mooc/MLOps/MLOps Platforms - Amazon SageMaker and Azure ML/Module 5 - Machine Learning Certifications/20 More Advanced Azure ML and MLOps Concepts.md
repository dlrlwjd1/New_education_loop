# More Advanced Azure ML and MLOps Concepts

## 개요
- Lesson 3에서 다룰 더 심화된 Azure ML 구성 요소(CPU/GPU 컴퓨트, 리소스·사용량)를 짧게 소개하는 1분 인트로 영상.

## 내용
- 지금까지 AI Fundamentals 같은 인증이 MLOps와 어떻게 (직접적이진 않지만) 연관되는지, 그리고 오픈 데이터셋으로 어떻게 작업하는지 살펴봤음.
- 이제 Azure의 더 흥미로운 구성 요소들을 조금 더 깊이 파고들 예정 — Azure Machine Learning Studio의 컴퓨트 시스템에서 **리소스·사용량, CPU 컴포넌트 vs GPU 컴포넌트**를 다룰 예정.
- 이 내용들은 **Azure AI Fundamentals 인증**에도 등장하는 내용이므로, 인증을 통해 지식을 확장하고 싶다면 함께 유용함.
- 이 구성 요소·서비스들 중 상당수는 Azure에만 국한되지 않고 다른 곳에도 적용 가능한 개념.

## 요약
- 이 짧은 인트로는 이어질 CPU/GPU 컴퓨트, 커맨드라인, 하이퍼파라미터, Python SDK 학습 콘텐츠가 AI Fundamentals 인증과도 연결되는 심화 Azure ML 주제임을 안내한다.
