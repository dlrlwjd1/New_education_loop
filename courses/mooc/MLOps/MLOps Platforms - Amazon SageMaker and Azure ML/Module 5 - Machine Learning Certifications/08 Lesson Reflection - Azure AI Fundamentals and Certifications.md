# Lesson Reflection — Azure AI Fundamentals and other Azure Certifications

## 개요
- Lesson 1 전체를 요약하는 공식 회고 자료: Azure Machine Learning Studio와 Automated ML 사용법을 소개했다.

## 내용

### 핵심 포인트
- Azure Machine Learning Studio는 Azure ML 모델을 구축하는 웹 인터페이스이며, Automated ML·파이프라인·컴퓨트 클러스터 같은 기능에 쉽게 접근할 수 있게 해준다.
- Automated ML은 모델과 하이퍼파라미터를 자동으로 반복 탐색해 데이터에 가장 적합한 모델을 찾아주어, 수동 시행착오 노력을 절약해준다.
- Microsoft Learn의 학습 경로와 모듈은 인증 콘텐츠를 특정 학습 목표에 초점을 맞춘 논리적 그룹으로 조직한다.

### 회고 질문
1. Automated ML이 자신의 모델 구축 프로세스를 어떻게 개선할 수 있는가?
2. 자신의 역할에 가장 관련 있어 보이는 Azure 서비스는 무엇인가?
3. Microsoft 인증 콘텐츠는 다른 클라우드 제공업체와 비교해 어떠한가?
4. Azure ML Studio 인터페이스의 어떤 부분이 인상적이었는가?
5. 학습 경로/모듈을 자신의 학습에 어떻게 적용할 수 있는가?

### 도전 과제
1. 트랜스크립트를 따라 Azure ML Studio 워크스페이스를 설정해보기.
2. 샘플 데이터셋으로 Azure에서 Automated ML 실험을 실행해보기.
3. Azure 인증의 학습 경로와 모듈 하나를 검토해보기.
4. Azure AI Fundamentals 인증에서 소개된 핵심 용어 5개를 나열해보기.
5. 인증 스터디 노트를 저장할 GitHub 리포지토리를 설정해보기.
