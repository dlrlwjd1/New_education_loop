# Practical Scenario — AutoML for a Tight Deadline

## 개요
- Azure ML Studio의 Automated ML 기능 지식을 적용해보는 5분짜리 AI 생성 인터랙티브 성찰 활동.

## 내용

### 시나리오
- 스타트업의 데이터 과학자로서, 팀 리더가 고객 이탈(customer churn) 예측 프로젝트에 Azure ML Studio의 Automated ML 기능을 사용하는 핵심 이점을 설명해달라고 요청. 팀은 빠듯한 마감 기한 아래 있음.
- 질문: 이 시나리오에서 Automated ML을 사용하는 주된 이점을 어떻게 설명하겠으며, 왜 시간에 민감한 프로젝트에 잘 맞는지 초점을 맞춰 답변하라.

### 종합 답변 (강의 개념 기반)
- Automated ML의 핵심 이점은 **다양한 모델과 하이퍼파라미터를 자동으로 반복 시도**해 주어진 데이터셋에 대해 최고 성능의 모델을 찾아준다는 것 — 이는 수동 시행착오(manual trial-and-error) 대비 상당한 시간을 절약해준다.
- 고객 이탈 예측처럼 분류 문제의 경우, 데이터 과학자가 로지스틱 회귀, 랜덤 포레스트, 그래디언트 부스팅 등 여러 알고리즘을 하나하나 직접 구현·튜닝·비교할 필요 없이, AutoML이 이 과정을 자동으로 수행해 짧은 시간 안에 준수한 베이스라인 모델을 확보할 수 있게 해준다.
- 빠듯한 마감 아래서는 이 시간 절약이 결정적 — 팀은 모델 아키텍처 탐색에 시간을 쓰는 대신, 비즈니스 요구사항 정의, 피처 엔지니어링, 결과 해석과 배포 준비에 시간을 집중할 수 있다.
- 또한 AutoML은 실험 추적과 함께 사용되어, 시도된 모든 모델·하이퍼파라미터 조합을 기록해두므로, 나중에 더 시간이 생겼을 때 어떤 모델이 가장 유망했는지 쉽게 되짚어볼 수 있다.

## 요약
- Automated ML의 핵심 가치는 "모델 선택·튜닝의 자동화를 통한 시간 절약"이며, 이는 마감이 빠듯한 고객 이탈 예측 같은 프로젝트에서 팀이 더 중요한 작업(비즈니스 요구사항, 배포)에 집중할 수 있게 해준다.
