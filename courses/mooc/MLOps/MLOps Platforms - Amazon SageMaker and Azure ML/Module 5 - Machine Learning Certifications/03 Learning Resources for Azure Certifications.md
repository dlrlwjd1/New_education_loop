# Learning Resources for Azure Certifications

## 개요
- **learn.microsoft.com**을 통해 Azure 인증(특히 **AI Fundamentals**와 **Azure Fundamentals**)을 탐색·준비하는 방법을 상세히 안내하는 8분 데모.

## 내용

### Microsoft Learn — 원스톱 학습 허브
- learn.microsoft.com은 Azure 플랫폼의 모든 API 문서와 교육 자료를 한곳에서 제공하는 단일 참조 지점.
- 검색창에서 "Azure Fundamentals" 같은 인증명을 직접 검색하거나, 상단의 **Certifications** 링크를 통해 역할별(데이터 과학자, 개발자, DevOps 엔지니어, AI 관심자 등)로 탐색 가능.
- MLOps 전용 인증은 없지만, 지식 확장에 도움이 되는 몇 가지 인증을 추천.
- 인기 인증(popular certifications) 목록에서도 Azure Fundamentals가 상위에 있음을 확인 가능.

### AI Fundamentals 인증 살펴보기
- "AI Fundamentals" 검색 시 두 가지 결과: **시험(exam)**과 **인증(certification)** — 학습을 위해서는 **인증** 쪽에 집중.
- "Microsoft Certified Azure AI Fundamentals" 상세 페이지에서 **Skills Measured**(측정되는 역량) 목록 확인 가능 — 예: Azure의 AI 워크로드 설명 원칙 및 머신러닝(20~25%), 컴퓨터 비전 워크로드(25~30%), NLP 등 — MLOps와 직접적 관련은 없지만 알아두면 유용한 내용이 많음.

### 준비 방법 — Self-paced vs Instructor-led
- 두 가지 준비 방식: **자기주도(self-paced)**(무료, Microsoft Learn에서 학습) 또는 **강사 주도(instructor-led)**.
- 이런 학습 경로들은 **컬렉션(collection)**이라 불리며, 여러 학습 경로(learning path)와 학습 모듈(learning module)의 묶음.
- 자기주도 학습으로 진행 상황을 추적할 수 있음.

### 학생 무료 인증 혜택
- 학생이라면 인증 시험을 **무료로** 응시 가능(일반적으로 시험 비용은 지역에 따라 약 100~150달러) — 원격으로도 응시 가능(강사도 실제로 원격 응시 경험 있음).
- 학생 프로필 생성 및 학생 신분 인증 절차를 거치면 무료 응시 가능하며, 경우에 따라 **대학 학점(college credits)**으로도 인정될 수 있음.

### Azure Fundamentals 인증도 함께 추천
- MLOps에 관심이 있더라도 Azure Fundamentals를 추천하는 이유: Azure 전용 서비스뿐 아니라 **범용 클라우드 컴퓨팅 개념**(컴퓨트 서비스, 관리·비용, PaaS vs SaaS, 보안 관리·거버넌스 등)을 폭넓게 다루기 때문에 매우 가치 있음.

## 요약
- learn.microsoft.com에서 AI Fundamentals(20~30%가 ML/컴퓨터 비전/NLP 관련 역량 측정)와 Azure Fundamentals(범용 클라우드 개념) 인증을 자기주도 또는 강사 주도로 무료 학습할 수 있으며, 학생은 시험 응시료까지 무료로 지원받을 수 있다.
