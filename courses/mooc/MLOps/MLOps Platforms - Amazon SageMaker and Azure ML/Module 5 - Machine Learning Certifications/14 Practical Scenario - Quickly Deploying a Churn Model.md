# Practical Scenario — Quickly Deploying a Churn Model

## 개요
- Azure ML Studio의 핵심 기능(Automated ML, Workspace, Dataset, Deployment) 지식을 적용해보는 5분짜리 AI 생성 인터랙티브 성찰 활동.

## 내용

### 시나리오
- 스타트업의 데이터 과학자로서, 고객 이탈을 예측하는 머신러닝 모델을 빠르게 구축·배포해야 함. 데이터셋은 준비되어 있지만, 모델 개발에 쓸 시간과 자원이 제한적.
- 질문: 이런 상황에서 모델을 빠르게 배포하기 위해 Azure ML Studio의 어떤 핵심 기능을 우선시하겠으며, 그 이유는?

### 종합 답변 (강의 개념 기반)
- 가장 우선시할 기능은 **Automated ML**이다.
  - **시간 절약**: 여러 모델과 하이퍼파라미터를 자동으로 반복 탐색해 최적 모델을 찾아주므로, 제한된 시간 안에 직접 알고리즘을 하나씩 구현·튜닝할 필요가 없다.
  - **데이터셋 등록과의 연계**: 이미 준비된 데이터셋을 Azure ML **Dataset**으로 등록한 뒤 곧바로 AutoML 작업의 입력으로 사용할 수 있어, 데이터 파이프라인 구축에 드는 시간도 최소화된다.
- 모델이 나오면, 배포 단계에서는 상황에 맞게 선택:
  - 고객 이탈 예측이 실시간 대시보드나 CRM 시스템에 즉시 반영되어야 한다면 **실시간(real-time) 배포**.
  - 매일/매주 배치로 고객 목록을 스코어링하는 정도로 충분하다면 **배치(batch) 배포**로 비용과 복잡도를 낮출 수 있다.
- 결론적으로, 제한된 시간과 자원 아래서는 **Automated ML로 모델 개발 단계를 자동화**하는 것이 가장 큰 효율을 가져다주며, 이후 배포 방식은 비즈니스 요구사항(실시간 vs 배치)에 맞춰 결정한다.

## 요약
- 시간·자원이 제한된 상황에서는 Automated ML로 모델 탐색·튜닝을 자동화하는 것이 가장 큰 효율을 제공하며, 배포 방식(실시간/배치)은 이후 비즈니스 요구사항에 맞춰 선택하는 것이 합리적이다.
