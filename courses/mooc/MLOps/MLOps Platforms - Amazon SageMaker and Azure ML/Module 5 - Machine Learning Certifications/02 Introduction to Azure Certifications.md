# Introduction to Azure Certifications

## 개요
- Azure(Microsoft의 클라우드) 인증이 MLOps 지식을 보완하는 방법과, Microsoft가 학습 자료를 조직하는 방식(Learning Module/Path)을 소개하는 2분 영상.

## 내용

### Azure 인증과 MLOps의 관계
- 인증은 지식을 더 확장하는 훌륭한 방법이 될 수 있음.
- **MLOps 전용 인증은 없지만**, 예를 들어 **Azure AI Fundamentals**는 Azure 자체뿐 아니라 머신러닝의 여러 측면을 폭넓게 다루는 매우 포괄적인 인증.
- 이 개념들은 다른 곳에도 적용 가능 — 회귀(regression), 분류(classification) 같은 머신러닝 기법을 더 배우게 됨.
- 비록 머신러닝 운영(MLOps)에 특화된 것은 아니지만, 이 지식은 MLOps 엔지니어나 MLOps 관련 업무를 하는 사람의 일상 업무 대부분과 상호보완적(complementary)임.

### Microsoft의 학습 자료 조직 방식
- **학습 모듈(learning modules)**과 **학습 경로(learning paths)**, 그리고 Microsoft가 이 정보를 어떻게 조직하는지 이해하면 학습 자료를 어떻게 진행해야 하는지 알 수 있음.
- 결국 인증을 따지 않기로 결정하더라도, 관심 있는 요소나 머신러닝을 더 편하게 다루기 위해 지식을 확장해야 할 부분을 골라서 선택할 수 있고, 이를 머신러닝 운영에도 적용해볼 수 있음.

## 요약
- Azure AI Fundamentals 같은 인증은 MLOps 전용은 아니지만 회귀·분류 등 머신러닝 개념 전반을 다뤄 MLOps 업무와 상호보완적이며, Microsoft의 Learning Module/Learning Path 구조를 이해하면 관심 있는 부분만 골라 학습할 수도 있다.
