# Azure Open Datasets

## 개요
- Azure ML Studio의 **Data** 탭에서 로컬 파일(MLB 선수 키·몸무게 데이터)을 새 데이터 자산으로 업로드하고, 자동 **데이터 프로파일(profile)**을 생성해 탐색적 데이터 분석을 수행하는 3분 데모.

## 내용

### 새 데이터 자산 생성
- **Data** 탭 → **New asset**으로 새 데이터셋 생성 — 이름(예: `test asset`)과 설명(예: "This is a test with MLB data") 입력.
- 자산 유형 선택: 파일(File), 폴더, 테이블 중 **File** 선택.
- 데이터 소스 옵션 3가지:
  1. **URI**(웹 URL) — 데이터를 수집하는 좋은 방법.
  2. **기존 스토리지(Existing storage)** — Azure Storage에 페타바이트급 데이터가 있는 경우.
  3. **로컬 파일(Local file)** — 워크플로를 빠르게 테스트하고 싶을 때.
- 로컬 파일 선택 → 저장 위치로 **Workspace blob** 선택 → 메이저리그 야구 선수의 키·몸무게 데이터 파일을 업로드.
- 생성된 데이터셋을 탐색·스크롤하며 컬럼을 확인 가능 — 컬럼 헤더(column headers) 토글을 켜면 데이터가 훨씬 더 명확하게 보임.

### 데이터 프로파일 생성
- Data 화면에서 **"Generate profile"** 기능 — 실행 중인 컴퓨트 인스턴스를 선택해 프로파일을 생성.
- 생성된 프로파일을 **"View profile"**로 확인 — 컬럼별 데이터 타입, 개수(count), 포지션 등의 값, 그리고 키·몸무게의 분포를 보여주는 히스토그램 등 유용한 시각화 제공.

### 핵심 통찰
- Azure Machine Learning을 시작할 때, 먼저 데이터셋을 수집(ingest)하고 프로파일링(profile)하는 것이 매우 귀중한 자원 — 이를 통해 머신러닝 모델을 만들기 전에 데이터에 대한 더 나은 이해를 얻을 수 있음.

## 요약
- Azure ML Studio의 데이터 자산 생성(URI/스토리지/로컬 파일)과 자동 프로파일 생성 기능은, 모델링 이전에 데이터를 수집하고 컬럼 타입·분포를 탐색적으로 파악하는 정교한 워크플로를 제공한다.
