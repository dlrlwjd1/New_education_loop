# MLOps Platforms: Amazon SageMaker and Azure ML

**Course URL:** [mooc.org/learn/mlops-aws-azure-duke](https://www.mooc.org/learn/mlops-aws-azure-duke)

MOOC / Duke University. "MLOps | Machine Learning Operations" 스페셜라이제이션의 네 번째이자 마지막 코스(Course 4 of 4). AWS와 Azure 두 클라우드 플랫폼을 활용해 프로덕션 환경에서 머신러닝 솔루션을 구축·학습·배포하는 방법을 다루는 심화(Advanced) 코스로, 5개 모듈로 구성. AWS/Azure 머신러닝 자격증 준비에도 도움이 되는 내용. 주 강사는 Noah Gift, 보조 강사는 Alfredo Deza.

## 모듈 구성
- [Module 1 - Data Engineering with AWS Technology](Module%201%20-%20Data%20Engineering%20with%20AWS%20Technology/) — AWS 머신러닝 기술 시작하기(SageMaker Studio Lab, CloudShell, Cloud9+CodeWhisperer), 데이터 저장소 구축(S3, 데이터 레이크), 데이터 수집·변환(AWS Batch, Step Functions, EMR Serverless)
- [Module 2 - Exploratory Data Analysis with AWS Technology](Module%202%20-%20Exploratory%20Data%20Analysis%20with%20AWS%20Technology/) — 데이터 정제·준비(결측치·스케일링·레이블링·NLP 전처리), 피처 엔지니어링(공개 데이터셋, MLflow 실험 추적, 하이퍼파라미터 튜닝, NBA 승리 시즌 실습), 데이터 분석·시각화(COVID EDA, K-평균 클러스터링, 주택 가격 시장 비교)
- [Module 3 - Modeling with AWS Technology](Module%203%20-%20Modeling%20with%20AWS%20Technology/) — 적합한 모델 선택(지도/비지도학습, 휴리스틱 vs ML, SageMaker Canvas), 모델 학습(경사하강법, 학습률, 학습/테스트 분할, 교차 검증, GPU vs CPU, 신경망), 모델 평가(과적합/과소적합, AUC·RMSE·R² 지표, 컴퓨터 비전, 실험 추적, 선형 회귀 실습)
- [Module 4 - MLOps with AWS Technology](Module%204%20-%20MLOps%20with%20AWS%20Technology/) — 성능·회복탄력성(Infrastructure as Code, 로깅, 다중 리전/AZ, AWS 스타일 컨테이너화 DevOps), 적합한 서비스 추천(EC2/EBS 프로비저닝, AWS AI/ML 서비스), 보안 배포·운영화(최소 권한 원칙, SageMaker Studio 워크플로, 데이터 드리프트 모니터링, PyTorch+App Runner 배포)
- [Module 5 - Machine Learning Certifications](Module%205%20-%20Machine%20Learning%20Certifications/) — Azure AI Fundamentals·Azure 인증(Azure ML Studio, AutoML, Microsoft Learning Path), Azure ML/MLOps 기초 개념(워크스페이스, 데이터셋, 실시간/배치 배포, Open Datasets), Azure ML 심화 개념(CLI, GitHub Actions 연동, 하이퍼파라미터 튜닝, Python SDK v2 재현 가능한 학습·배포)
