# Data Lakes with Amazon S3

## 개요
- AWS 공식 백서 "Building Data Lakes"(오디오 요약 1분 15초) — S3를 핵심 스토리지 계층으로 하는 안전하고 확장 가능한 데이터 레이크 구축의 모범 사례를 다루는 읽기 자료.

## 내용

### 핵심 포인트
- **S3**를 무제한에 가깝고 내구성 있는 중앙 스토리지로 사용.
- **수집(ingest)**: Kinesis, Snowball, Glue, DataSync로 데이터 수집.
- **변환(transform)**: Glue, EMR, Lambda, S3 Object Lambda로 데이터 변환.
- **보안**: IAM, 암호화, 접근 제어, 감사(auditing)로 데이터 보호.
- **비용 최적화**: 라이프사이클 규칙, 분석, 계층화된 스토리지(tiered storage)로 비용 절감.

### 성찰 질문
1. 분석용 데이터 레이크에 어떤 데이터 소스를 수집하겠는가?
2. 데이터 레이크 스토리지의 쿼리 성능을 어떻게 최적화할 수 있는가?
3. 멀티테넌트 데이터 레이크에는 어떤 보안 통제가 필요한가?
4. 컴플라이언스 데이터를 원본 데이터와 어떻게 다르게 관리하겠는가?
5. 여러 데이터 사일로를 하나의 중앙 플랫폼으로 마이그레이션할 때 어떤 리스크가 보이는가?

### 도전 과제
1. AWS에 소규모 S3 기반 데이터 레이크를 구축해보기.
2. 서버리스 데이터 변환 워크플로를 구현해보기.
3. 샘플 데이터셋에 대한 IAM 역할과 Glacier 정책을 만들어보기.
4. 스토리지 접근 패턴을 분석해 라이프사이클 규칙을 개발해보기.
5. 중앙화된 스토리지에서 어떤 분석 서비스가 동작할 수 있는지 평가해보기.

## 요약
- 이 백서는 S3를 중심으로 수집(Kinesis/Snowball/Glue/DataSync) → 변환(Glue/EMR/Lambda) → 보안(IAM/암호화) → 비용 최적화(라이프사이클 규칙)로 이어지는 데이터 레이크 구축의 전체 파이프라인을 모범 사례로 제시한다.
