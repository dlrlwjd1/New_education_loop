# Lesson Reflection — Creating Data Repositories for Machine Learning

## 개요
- Lesson 3 전체를 요약하는 공식 회고 자료: AWS에서 머신러닝 데이터를 저장하는 옵션들(S3, EFS, EBS, Storage Gateway, DataSync)을 다뤘다.

## 내용

### 핵심 포인트
- **S3**는 내구성 있고 무한에 가깝게 확장 가능한 객체 스토리지를 제공한다.
- **EFS**는 디스크 I/O를 확장할 수 있는 공유 파일 시스템을 제공한다.
- **EBS**는 각 볼륨마다 커스텀 디스크 성능을 설정할 수 있게 해준다.
- **Storage Gateway**는 온프레미스 데이터를 클라우드와 연결한다.
- **DataSync**는 시스템 간 데이터 이동을 돕는다.
- 데모에서는 콘솔·CLI에서 S3에 업로드, S3 Select로 데이터 쿼리, EC2 인스턴스 간 EFS 공유 등의 기능을 시연했다.

### 회고 질문
1. 자신의 머신러닝 데이터에 가장 적합한 AWS 스토리지 서비스는 무엇이며 그 이유는?
2. 팀원들이 공유 학습 데이터셋에 접근하도록 어떻게 구성할 수 있는가?
3. 민감한 모델 아티팩트를 위해 어떤 데이터 보호 조치를 구현하겠는가?
4. 아카이브된 모델·백업의 스토리지 비용을 어떻게 줄일 수 있는가?
5. 레거시 스토리지 시스템을 클라우드로 마이그레이션할 때 어떤 어려움이 예상되는가?

### 도전 과제
1. S3 버킷을 설정하고 샘플 학습 데이터를 업로드해보기.
2. EC2 학습 클러스터를 위한 EFS 공유를 만들어보기.
3. EBS 볼륨 유형별로 처리량(throughput)과 IOPS를 벤치마킹해보기.
4. 랩 환경에 Storage Gateway를 설치해보기.
5. 온프레미스 시스템과 S3 사이의 DataSync 워크플로를 구축해보기.

## 요약
- Lesson 3는 S3(객체 스토리지) → EFS(공유 파일 시스템) → EBS(블록 스토리지) → Storage Gateway/DataSync(온프레미스 연동)까지, 머신러닝 데이터를 저장하는 AWS의 스토리지 스펙트럼 전체와 실습(콘솔/CLI 업로드, S3 Select 쿼리)을 다뤘다.
