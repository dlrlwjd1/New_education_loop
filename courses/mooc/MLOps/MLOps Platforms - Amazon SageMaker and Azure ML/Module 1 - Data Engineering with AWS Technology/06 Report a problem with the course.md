# Report a Problem with the Course

## 개요
- 코스 콘텐츠(오류, 깨진 링크, 접근 불가 콘텐츠 등)에 문제가 있을 때 MOOC 문제 해결 가이드와 신고 양식을 안내하는 표준 보일러플레이트 자료.

## 내용
- 먼저 MOOC의 문제 해결 가이드(troubleshooting guide)로 일반적인 문제 해결 시도.
- 여전히 기술적 문제나 콘텐츠 오류가 있다면 신고 양식을 통해 Duke에 전달됨.
- 문제가 없다면 그냥 "Mark as completed"로 다음으로 진행.

## 요약
- 순수 안내성 보일러플레이트 자료로, 실제 학습 콘텐츠는 없다.
