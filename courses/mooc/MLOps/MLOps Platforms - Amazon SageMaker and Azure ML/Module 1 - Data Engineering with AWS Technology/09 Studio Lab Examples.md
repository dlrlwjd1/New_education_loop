# Studio Lab Examples

## 개요
- **Amazon SageMaker Studio Lab**을 활용해 AI/ML 학습 환경을 구축하는 예제 Jupyter 노트북들을 소개하고, 온보딩 절차를 안내하는 자료.

## 내용

### SageMaker Studio Lab이란?
- 개인 데이터 과학자가 AI/ML 실무자로 커리어를 발전시키고 싶을 때 사용하는 서비스.
- **무료로** ML 여정을 시작할 수 있음.
- 컴퓨터 비전, 자연어 처리 등 관심 분야에 맞게 Studio Lab을 설정하는 방법을 제공하는 리포지토리가 존재하며, 이후 프로젝트를 **Amazon SageMaker**에 배포해 AI/ML 실무자로 성장하는 흐름을 보여줌.

### 시작 방법
1. Studio Lab 계정 신청(Request).
2. Studio Lab 계정 생성(Create).
3. Studio Lab 로그인(Sign in).

## 요약
- SageMaker Studio Lab은 무료로 시작할 수 있는 개인용 AI/ML 학습 환경이며, 이후 실전 프로젝트를 SageMaker 본 서비스로 배포하는 경로로 이어진다.
