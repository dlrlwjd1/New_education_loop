# Developing AWS Storage Solutions

## 개요
- AWS Academy Cloud Developing 코스 Module 3 자료(오디오 요약 1분 9초) — 클라우드 애플리케이션 개발 시 **Amazon S3**를 스토리지로 활용하는 방법을 소개하는 읽기 자료.

## 내용

### 핵심 포인트
- S3는 버킷(bucket)과 객체(object)로 구성된 내구성 있고 확장 가능한 객체 스토리지를 제공.
- 버킷에 저장된 객체는 SDK를 통해 관리 가능.
- 데이터 보호를 위해 **버저닝(versioning)**과 **암호화(encryption)**를 활성화할 수 있음.
- **정책(policy)**과 **서명된 URL(signed URL)**로 접근을 제어.
- SDK로 객체 업로드, 조회, 쿼리 가능.

### 성찰 질문
1. 애플리케이션의 자산(assets)을 저장하는 데 S3를 어떻게 활용할 수 있는가?
2. 민감한 데이터 업로드를 보호하려면 어떤 단계가 필요한가?
3. 데이터가 늘어남에 따라 비용을 어떻게 최적화할 수 있는가?
4. 멀티테넌트 버킷에는 어떤 접근 제어가 필요한가?
5. 실수로 인한 데이터 삭제로부터 어떻게 중단을 피할 수 있는가?

### 도전 과제
1. S3 버킷을 만들고 CORS 권한을 설정해보기.
2. KMS 키로 암호화된 샘플 객체를 업로드해보기.
3. 복제 상태(replication status)에 대한 S3 인벤토리 리포트를 만들어보기.
4. 객체를 공유하기 위한 사전 서명 URL(pre-signed URL)을 생성해보기.
5. 버저닝을 활성화하고 객체 삭제를 시도해보기.
