# Getting Started with AWS CloudShell

## 개요
- **AWS CloudShell**의 기본 기능(파일 업로드/다운로드, 셸 커스터마이징, S3 버킷 생성·동기화)을 실습하는 12분 데모.

## 내용

### AWS CloudShell이란
- 브라우저에서 커맨드라인으로 AWS 리소스·도구에 접근하는 서비스 — 도서관이나 카페 어디서든 셸에 접속해 작업을 시작할 수 있고, AWS 생태계 내부에 있으므로 매우 빠름.
- 장점: 추가 자격 증명 관리 불필요(역할 기반 권한), 최신 Amazon OS로 자동 업데이트, 도구가 미리 설치되어 있음, **비용 없음**, **1GB 저장 공간** 제공, 커스터마이징 가능.

### 기본 조작
- 어느 리전에서든 실행 가능. 기존 작업을 완전히 삭제하고 재시작하는 것도 가능(실험하다 꼬였을 때 유용).
- **Actions 메뉴**: 새 셸 열기, 화면을 행(row)으로 분할, 열(column)로 분할해 대시보드처럼 구성 가능(예: Flask/FastAPI 같은 포그라운드 마이크로서비스를 아래쪽 셸에서 바로 호출).
- **파일 업로드/다운로드**: 홈 디렉토리는 1GB로 제한됨. 로컬의 zip 파일(예: `cats-dogs-small`)을 업로드 → `unzip`으로 압축 해제 → 특정 파일 경로를 지정해 다운로드도 가능.
- `df -h`로 파일 시스템 사용량 확인 가능 (예: 10MB 사용 중, 899MB 여유).

### 셸 커스터마이징
- `echo $SHELL`로 현재 셸 확인(기본값 `/bin/bash`).
- **bash**, **zsh**(개발자들이 선호하는 추가 명령 제공, `.zshrc`에서 `auto cd` 같은 설정 가능), **PowerShell**(.NET 개발자용, C# 활용 가능) 등 여러 셸 환경을 자유롭게 전환·커스터마이징 가능.

### S3 버킷 생성과 동기화 실습
1. 버킷 생성: `aws s3api create-bucket --bucket cats-dogs-11-21-2021` — 콘솔 없이 커맨드라인만으로 버킷 생성.
2. 버킷 개수 확인: `aws s3 ls | wc -l` — 파이프로 출력 개수 카운트(예: 99개 버킷).
3. 디렉토리 전체를 S3에 동기화: `aws s3 sync . s3://cats-dogs-11-21-2021` — 현재 디렉토리의 모든 파일을 원격 버킷에 동기화. 이후 파일이 바뀌면 동기화 명령이 최신 상태로 유지해줌 — 데이터 파이프라인/데이터 엔지니어링/ML 엔지니어링에 매우 유용.
4. 압축 후 다운로드: `zip -r cat.zip <path>` → `pwd`로 정확한 경로 확인 후 Download file 메뉴로 다운로드.

## 예시
```bash
# 파일 시스템 사용량 확인
df -h

# 현재 셸 확인
echo $SHELL

# S3 버킷 생성
aws s3api create-bucket --bucket cats-dogs-11-21-2021

# 버킷 개수 확인
aws s3 ls | wc -l

# 현재 디렉토리를 S3 버킷에 동기화
aws s3 sync . s3://cats-dogs-11-21-2021

# 디렉토리를 zip으로 압축
zip -r cat.zip cats-dogs-small/
```

## 요약
- AWS CloudShell은 자격 증명 관리 없이 브라우저에서 바로 AWS를 다룰 수 있는 무료 커맨드라인 환경으로, 파일 업로드/다운로드, bash/zsh/PowerShell 커스터마이징, S3 버킷 생성·동기화까지 데이터 엔지니어링 워크플로에 즉시 활용할 수 있다.
