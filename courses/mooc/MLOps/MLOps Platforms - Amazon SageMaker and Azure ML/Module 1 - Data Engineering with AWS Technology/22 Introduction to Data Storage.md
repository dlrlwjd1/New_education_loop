# Introduction to Data Storage

## 개요
- 데이터 엔지니어링 전략의 첫 단계인 **데이터 소스 카탈로그화(cataloging)**를 소개하는 1분 영상.

## 내용

### 데이터 소스 카탈로그화
- 조직이 데이터 엔지니어링 전략을 구현할 때 중요한 첫 단계는 회사의 모든 데이터 소스를 **카탈로그화**하는 것.
- 예1) 모바일 애플리케이션의 사용자 데이터 — 어디에 저장되는지 분석. 예를 들어 **DynamoDB** 같은 키-값 저장소에 흔히 저장되며, 사용자 프로필 레코드는 이후 데이터 엔지니어가 작업할 카탈로그 대상 중 하나가 됨.
- 예2) 로그 데이터 — 스프레드시트 등에 다른 모든 데이터 소스와 함께 콘텐츠 유형(예: HTTP 요청 — 200/400 응답 개수, 참조 URL 등)을 식별하고 카탈로그화. 위치까지 함께 기록.
- **S3**는 원본(raw) 로그 데이터를 저장하기에 좋은 위치이며, 이는 객체 기반 스토리지(object-based storage)에 해당.

### 핵심 통찰
- 데이터 소스 마스터 목록에 이렇게 카탈로그화가 완료되면, 이후 데이터 엔지니어링 파이프라인에서 그 데이터를 어떻게 처리할지에 대한 전략을 수립할 수 있게 됨.

## 요약
- 데이터 엔지니어링의 출발점은 모든 데이터 소스(모바일 앱 사용자 데이터, 로그 데이터 등)의 저장 위치와 콘텐츠 유형을 카탈로그화하는 것이며, S3 같은 객체 스토리지는 원본 로그 데이터를 저장하기에 적합한 위치다.
