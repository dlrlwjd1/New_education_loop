# Course Structure and Discussion Etiquette

## 개요
- 코스 진행 방식(비디오·읽기 자료 → 실습 랩 → 채점 퀴즈)과 토론 게시판·소셜미디어 활용 시 에티켓을 안내하는 자료.

## 내용

### 코스 구조 개요
- 각 모듈에서 다음을 수행:
  1. 비디오와 읽기 자료를 통해 콘텐츠 학습.
  2. MOOC Labs에서 채점되지 않는 실습(hands-on exercises) 수행 — 각 레슨에서 배운 개념·기술을 연습하는 기회.
  3. 매주 마지막에 **채점 퀴즈** 응시 — 모든 비디오·읽기·실습 랩의 개념을 다루는 객관식 10문항. **80% 이상**을 받아야 다음 주 자료로 넘어갈 수 있으며, 원하는 만큼 재응시 가능.
- 각 레슨에서 강사들이 GitHub를 실제 데이터 엔지니어링 커리어에서 프로젝트 공유에 어떻게 활용했는지 사례가 등장 — 선택사항이지만, 학습자도 자신의 GitHub 리포지토리를 토론 게시판이나 `#duke-mlops-python` 해시태그로 공유하는 것을 권장.

### 토론 에티켓
- 예의를 지킬 것 — 의견 차이는 자연스러운 것이지만 항상 존중하는 태도 유지, 전체 대문자 사용은 "소리 지르는 것"으로 받아들여질 수 있음, 부적절한 게시물은 'report' 버튼으로 신고.
- 사려 깊게 기여할 것 — 답글을 달기 전에 스레드 전체를 읽어 이미 논의된 내용을 반복하지 않기.
- 다른 사람을 도울 것 — 데이터 엔지니어링이나 온라인 토론 경험이 더 많다면, 적절한 시점에 동료 학습자에게 친절한 피드백 제공.

## 요약
- 이 코스는 콘텐츠 학습 → 실습 랩 → 80% 이상을 요구하는 채점 퀴즈의 흐름으로 진행되며, GitHub 프로젝트 공유와 존중을 바탕으로 한 토론 참여가 권장된다.
