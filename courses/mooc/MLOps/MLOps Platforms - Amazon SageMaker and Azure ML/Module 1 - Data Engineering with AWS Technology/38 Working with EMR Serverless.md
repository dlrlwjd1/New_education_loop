# Working with EMR Serverless

## 개요
- **EMR Studio** 인터페이스에서 서버리스 Spark 애플리케이션을 생성하고 작업(job)을 제출하는 방법을 보여주는 1분 데모.

## 내용

### EMR — AWS에서 맵리듀스를 수행하는 곳
- **EMR**은 AWS 플랫폼에서 맵리듀스를 수행할 수 있는 대표적인 장소.
- **EMR Studio** 인터페이스에서 서버리스 애플리케이션을 실행하고 작업을 제출할 수 있음.
- 완전관리형 **Jupyter 노트북**을 클러스터에 연결해 사용할 수 있고, 이를 통해 작업의 문제를 진단(diagnose)할 수도 있음.

### 애플리케이션 생성과 작업 제출
- "Create application"으로 **Spark 애플리케이션**을 생성 — 기본 설정(default settings)을 그대로 사용해도 됨.
- 애플리케이션 생성 후, 특정 구성과 인자(arguments)를 받는 작업(job)을 제출 가능.
- 추가적인 JSON 페이로드로 작업을 세부 구성할 수도 있음.

## 요약
- EMR Studio는 완전관리형 Jupyter 노트북과 서버리스 Spark 애플리케이션을 결합해, 별도의 클러스터 관리 없이 맵리듀스 작업을 생성·제출·진단할 수 있는 인터페이스를 제공한다.
