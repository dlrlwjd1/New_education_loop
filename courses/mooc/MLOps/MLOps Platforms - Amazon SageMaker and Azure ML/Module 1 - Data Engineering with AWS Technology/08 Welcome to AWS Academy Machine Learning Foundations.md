# Welcome to AWS Academy Machine Learning Foundations

## 개요
- AWS Academy Machine Learning Foundations 코스의 Module 1 PDF 자료(오디오 요약 1분 24초)를 통해, AWS에서 머신러닝을 다루는 데 필요한 배경지식과 직무 역할을 소개하는 읽기 자료.

## 내용

### 핵심 포인트
- 이 코스는 AWS를 활용해 **ML 파이프라인 구현, 예측(forecasting), 컴퓨터 비전, NLP**를 다룸.
- 사전에 필요한 역량: Python, 통계학, 네트워킹, 분산 시스템.
- 데이터 과학자, ML 엔지니어, 개발자 등의 역할이 머신러닝을 적용.
- 직무 역할은 통계·프로그래밍·도메인 전문성의 조합을 요구함.
- 추가 학습을 위한 자료: AWS ML 블로그, 솔루션 마켓플레이스, 공식 문서 등.

### 성찰 질문
1. 어떤 머신러닝 직무 역할이 가장 흥미롭고, 그 이유는 무엇인가?
2. 코스의 어떤 부분이 자신의 목표와 가장 관련이 있는가?
3. 코스 개념에 도움이 될 기존 보유 역량은 무엇인가?
4. 어떤 선행 요건이 학습하기에 가장 도전적인가?
5. 학습 과정에서 추가 읽기 자료를 어떻게 활용할 것인가?

### 도전 과제
1. 머신러닝 직무 기술서(job description)를 검토하고 현재 역량과 비교해보기.
2. AWS 머신러닝 서비스 하나를 선택해 문서를 읽어보기.
3. Amazon SageMaker로 샘플 데이터를 활용해 기본 ML 모델 만들어보기.
4. 오픈 데이터셋을 분석해 ML 비즈니스 솔루션을 구상해보기.
5. AWS 머신러닝 커뮤니티에 참여해 멘토를 찾아보기.

## 요약
- 이 자료는 AWS에서 머신러닝을 다루기 위한 필요 역량(Python, 통계, 분산 시스템)과 관련 직무 역할을 소개하며, 실제 서비스 문서 탐색·SageMaker 실습·커뮤니티 참여 등 실천적 도전 과제를 제시한다.
