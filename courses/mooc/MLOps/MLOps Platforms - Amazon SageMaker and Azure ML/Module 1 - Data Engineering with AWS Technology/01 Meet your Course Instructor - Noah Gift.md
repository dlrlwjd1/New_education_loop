# Meet your Course Instructor: Noah Gift

## 개요
- Noah Gift(Duke 겸임교수, Executive in Residence)가 코스 전체 5개 모듈의 구성과 목표를 소개하는 4분짜리 오리엔테이션 영상.

## 내용

### 강사 소개
- Noah Gift는 Duke의 MIDS(Master of Interdisciplinary Data Science) 프로그램과 AIPI(AI for Product Innovation) 프로그램에서 강의하는 Executive in Residence 겸임교수.
- 이 코스는 클라우드 플랫폼을 활용해 실제로 무언가를 프로덕션에 배포하는 데 필요한 기초 역량들을 다룸.

### 주차별(모듈별) 구성 개요
1. **Week 1 — Data Engineering with AWS Technology**: AWS 머신러닝 기술 시작하기, 머신러닝을 위한 데이터 저장소 구축, 데이터 수집·변환 솔루션 식별 및 구현.
2. **Week 2 — Exploratory Data Analysis(AWS 기술 활용)**: 데이터 정제·준비(sanitizing), 피처 엔지니어링, 머신러닝을 위한 데이터 분석·시각화. AWS의 서버리스 솔루션들이 이 인프라 구축을 돕는데, MLOps의 목표 중 하나가 "최대한 적은 작업으로 효율을 추구하는 것"이므로 전처리에 서버리스 기술을 활용하는 것이 중요.
3. **Week 3 — Modeling with AWS Technology**: 과제에 적합한 모델 선택(딥러닝 vs 단순 선형회귀), 하이퍼파라미터 선택, SageMaker Autopilot 같은 완전관리형(full solution) 옵션 선택 시의 트레이드오프, 모델 학습과 평가 방법.
4. **Week 4 — MLOps with AWS**: 프로덕션 배포의 마지막 단계 — 모델을 효율적으로 운영화(operationalize)하는 방법. 언어 선택, 배포 대상(CPU/GPU), ONNX 같은 기술을 활용한 추론 효율화 등 다양한 설계 고려사항. 배포 후 유지·트래픽 처리까지 포함.
5. **Week 5 — Machine Learning Certifications**: AWS 머신러닝 자격증 준비에도 직접 도움이 되는 내용.

### 핵심 통찰
- 이 코스는 AWS 플랫폼에서 머신러닝을 실제로 다뤄보고 싶은 사람들에게 실습 중심으로 설계되었으며, 동시에 AWS Machine Learning 자격증 취득 준비에도 도움이 된다.

## 요약
- 이 코스는 데이터 엔지니어링 → 탐색적 데이터 분석 → 모델링 → MLOps(운영화) → 자격증 준비의 5단계로 구성되며, AWS 플랫폼에서 머신러닝을 프로덕션에 배포하는 전체 파이프라인을 실습으로 다룬다.
