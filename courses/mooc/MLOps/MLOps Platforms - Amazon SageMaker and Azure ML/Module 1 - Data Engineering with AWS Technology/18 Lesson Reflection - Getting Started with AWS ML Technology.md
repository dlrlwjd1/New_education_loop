# Lesson Reflection — Getting Started with AWS Machine Learning Technology

## 개요
- Lesson 2 전체를 요약하는 공식 회고 자료: SageMaker Studio Lab, CloudShell, Cloud9, Comprehend, Lynx 등 AWS 머신러닝 핵심 서비스·도구를 소개했다.

## 내용

### 핵심 포인트
- **SageMaker Studio Lab**은 무료 GPU 지원 노트북 환경을 제공한다.
- **CloudShell**은 브라우저 기반 터미널로 AWS 리소스에 접근할 수 있게 해준다.
- **Cloud9**은 AWS 툴킷이 통합된 브라우저 기반 IDE다.
- **Comprehend**는 감성 분석 등 NLP 기능을 제공한다.
- **Lynx**는 웹사이트의 텍스트를 터미널로 스크래핑할 수 있게 해준다.

### 회고 질문
1. 어떤 AWS 도구가 자신의 개발 요구에 가장 유용해 보이는가?
2. Comprehend나 Lynx를 어떻게 ML 비즈니스 문제에 적용할 수 있는가?
3. 클라우드 기반 환경이 로컬 도구 대비 어떤 이점을 제공하는가?
4. SageMaker Studio와 Cloud9 중 언제 무엇을 사용할지 어떻게 결정할 것인가?
5. 이러한 새 플랫폼들을 학습하는 데 어떤 어려움이 예상되는가?

### 도전 과제
1. Lynx로 웹페이지 스크래퍼를 만들어 텍스트 데이터 수집해보기.
2. Comprehend로 리뷰에 대한 감성 분석 수행해보기.
3. 간단한 SageMaker 노트북을 개발·배포해보기.
4. CloudFormation 스택으로 Cloud9 환경을 관리해보기.
5. CloudShell 그룹에 대한 사용자 역할과 권한을 구성해보기.

## 요약
- Lesson 2는 SageMaker Studio Lab(GPU 노트북) → CloudShell(브라우저 터미널) → Cloud9(브라우저 IDE + CodeWhisperer) → Comprehend(NLP API) → Lynx(터미널 웹 스크래핑)까지, AWS에서 머신러닝을 프로토타이핑하기 위한 개발 환경과 AI 서비스들을 실습 중심으로 다뤘다.
