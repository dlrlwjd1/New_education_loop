# Handling Map Reduce for Machine Learning

## 개요
- **Spark**와 **Hadoop 분산 파일 시스템(HDFS)**이 S3 위에서 어떻게 맵리듀스(Map Reduce) 방식의 분산 컴퓨팅을 가능하게 하는지 설명하는 1분 영상.

## 내용

### Spark와 HDFS
- AWS는 Spark를 실행해 머신러닝을 위한 맵리듀스를 처리하는 훌륭한 메커니즘을 제공. Spark는 Databricks 같은 서드파티 플랫폼에서 실행되거나 **EMR** 생태계 안에서 실행될 수 있음.
- Spark의 핵심 기능은 **Hadoop 분산 파일 시스템(HDFS)**과 상호작용하는 것 — HDFS는 **S3 위에 위치**하며, 파일 시스템을 분산·병렬 컴퓨팅 및 스토리지 메커니즘으로 취급함.
- 즉, 노트북이 점점 더 많은 디스크 I/O를 필요로 하면, S3의 객체 스토리지 시스템이 가상 머신을 여러 대 띄워 모든 입출력 연산을 처리하고, 클러스터 내 각 노드에 걸쳐 컴퓨트와 스토리지를 분산시킴.

### 맵(Map)과 리듀스(Reduce)
- 프로그래머는 예를 들어 상관관계(correlation) 계산 같은 연산을 적용하는 함수를 작성(맵 단계).
- 리듀스 단계에서는 이 모든 결과를 하나로 합쳐(combine) 시각화 등을 생성.

### 핵심 통찰
- Spark 생태계의 진짜 장점은, 노트북을 통해 이 파일 시스템 전반에 걸친 작업 분산이 **뒤에서 매끄럽게(seamlessly)** 처리된다는 것 — 프로그래머는 함수만 작성하면 되고, 명시적인 병렬 코딩을 직접 할 필요가 없음.

## 요약
- Spark(EMR 또는 Databricks에서 실행)는 S3 위의 HDFS를 분산·병렬 컴퓨팅/스토리지로 취급해, 프로그래머가 명시적 병렬 코딩 없이도 맵(함수 적용) → 리듀스(결과 결합) 방식의 대규모 데이터 처리를 노트북에서 매끄럽게 수행할 수 있게 해준다.
