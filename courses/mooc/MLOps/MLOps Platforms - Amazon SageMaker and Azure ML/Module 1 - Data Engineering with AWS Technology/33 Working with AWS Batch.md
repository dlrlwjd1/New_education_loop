# Working with AWS Batch

## 개요
- AWS Batch의 "Get Started" 마법사(wizard)를 따라 컴퓨트 환경 → 작업 큐 → 작업 정의 → 작업 실행까지 첫 배치 작업을 만들어보는 3분 데모.

## 내용

### AWS Batch 개요
- 애플리케이션 이미지 설정, 작업 큐(job queue), 스케줄러, 실제 작업 실행으로 구성된 단순하고 유용한 서비스 — 시작하기 쉬움.

### Get Started 마법사 4단계

1. **컴퓨트 환경(Compute Environment) 생성**
   - 실행 위치 선택: **Fargate**(서버 관리 불필요, 컨테이너 안에서 실행되며 백엔드를 AWS가 전부 처리) 추천.
   - **Fargate Spot**: 최대 **70% 할인**을 받을 수 있어 다수의 작업을 실행할 때 유리.
   - 그 외 가상 머신 방식(온디맨드 또는 스팟)도 선택 가능하며, 사용할 vCPU 개수와 VPC(네트워크)도 설정.

2. **작업 큐(Job Queue) 생성**
   - 처리할 모든 작업을 담아두는 큐.

3. **일반 설정(General Configuration)**
   - 타임아웃 시간, 실행 역할(execution role) 등을 설정 — 다른 API나 AWS 서비스와 통신해야 한다면 별도의 역할을 부여 가능.

4. **작업 정의(Job Definition/Configuration)**
   - 컨테이너를 시작할 **이미지**를 지정 — 다른 이미지로 바꾸거나, Hugging Face 라이브러리 등이 포함된 **커스텀 이미지**를 직접 빌드해 사용하는 것을 권장.
   - 실행할 **명령어** 지정(예: `HelloWorld` 출력 + 실행 시각을 보여주는 `date` 명령).
   - 컨테이너에 예약할 **vCPU 개수**, **메모리**도 설정 가능.
   - 고급 옵션으로 볼륨 마운트, 로깅 등 컨테이너 세부 설정도 가능.

### 실행
- 위 설정을 마치면 전체 정보 요약을 확인한 뒤 **작업을 실행(Run job)**할 수 있음.

## 요약
- AWS Batch는 "컴퓨트 환경 생성 → 작업 큐 생성 → 일반 설정 → 작업 정의"라는 4단계 마법사만으로 컨테이너 기반 배치 작업을 손쉽게 구성할 수 있으며, Fargate/Fargate Spot을 활용하면 서버 관리 없이 최대 70% 비용을 절감하며 대규모 작업(GPU 파인튜닝 등)을 처리할 수 있다.
