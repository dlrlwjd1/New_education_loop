# Getting Started and Course Gotchas

## 개요
- 코스 수강 전 필요한 선행 지식과, 흔히 놓치기 쉬운 "함정(gotchas)"을 피하기 위한 모범 사례를 안내하는 자료.

## 내용

### 선행 지식(Prerequisites)
- 클라우드 컴퓨팅 기초에 익숙해야 코스를 최대한 활용 가능. 기초가 부족하다면 **Cloud Computing Foundations**(Duke) 코스를 먼저 수강 권장 — Hugo/AWS CodePipeline/S3/GitHub로 정적 사이트 호스팅 구축, Linux, 중급 Python 등을 다룸.

### 있으면 좋은 기술(Nice to Have Skills)
- 필수는 아니지만 도움이 되는 Python 역량: 로직·변수 할당·자료구조 사용, Pytest로 테스트 작성·실행·디버깅, API/SDK를 활용해 CLI 도구나 HTTP API 구축.
- 기초·중급 Python이 필요하다면 **Python for Machine Learning Operations**(Duke) 코스 권장.

### 코스의 함정과 모범 사례
1. 각 레슨의 **Key Terms**를 반드시 읽어 용어에 익숙해질 것.
2. AWS, Azure, GCP에 **무료 클라우드 계정**을 생성할 것.
3. 각 레슨의 **Reflection** 읽기 자료로 학습 내용을 정리할 것.
4. 각 레슨의 연습 퀴즈를 응시해 이해도를 점검할 것.
5. 코스를 듣는 동안 **포트폴리오를 함께 구축**할 것 — 직접 실습하는 것을 대체할 수 있는 것은 없음.

## 요약
- 클라우드 컴퓨팅 기초와 기본 Python 역량이 있으면 이 코스를 가장 잘 활용할 수 있으며, Key Terms 숙지·3대 클라우드 무료 계정 생성·Reflection과 퀴즈 활용·포트폴리오 구축이 핵심 모범 사례로 제시된다.
