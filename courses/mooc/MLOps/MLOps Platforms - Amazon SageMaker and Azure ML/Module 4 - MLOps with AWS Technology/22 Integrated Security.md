# Integrated Security

## 개요
- 방화벽, 역할 기반 권한, 암호화, VPC, 모니터링(CloudTrail, IAM)이 여러 계층으로 결합된 AWS 통합 보안 아키텍처를 설명하는 1분 영상.

## 내용

### 보안 계층들
- **AWS 보안 방화벽**: 들어오는 포트를 차단해 공격 벡터(attack vector)를 제한.
- **역할 기반 권한(role-based privileges)**: EC2 등에서 공격 벡터를 제한.
- **암호화**: 저장 데이터(at rest)와 전송 중 데이터(in transit, 예: EBS → S3 이동 시) 모두 암호화.
- **가상 사설 클라우드(VPC)**: 전체 시스템이 VPC 안에 격리됨.
- **자동화된 배포/Infrastructure as Code**: 사용하므로 수동 실수를 걱정할 필요가 없음.

### 모니터링 시스템과의 통합
- **AWS CloudTrail**: API 호출을 확인해 네트워크에서 일어나는 모든 단일 행동을 들여다볼 수 있음(introspect).
- 콘솔 계정 로그인 시 **2단계 인증(two-factor authentication)**을 활성화 → 누가 실제로 계정에 로그인하는지 감사·모니터링 가능.
- **AWS IAM 정책**으로 최소 권한을 구현 — 빌드 시스템은 배포에 필요한 정확한 권한만 사용 가능. 서비스 자체도 역할 기반 권한으로 필요한 정확한 권한만 사용.

### 핵심 통찰
- 이 **통합 보안(integrated security)** 개념은 안전한 네트워크를 설계하는 핵심 기본 원칙 중 하나.

## 요약
- AWS의 통합 보안은 방화벽·역할 기반 권한·암호화(저장/전송)·VPC 격리·IaC 자동화라는 예방적 계층과, CloudTrail·2단계 인증·IAM 최소 권한이라는 감사·모니터링 계층이 결합되어 안전한 네트워크를 구성하는 원칙이다.
