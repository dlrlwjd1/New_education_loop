# Model Predictions with SageMaker Canvas

## 개요
- SageMaker Canvas에서 병원 입원 기간을 예측하는 모델의 피처 영향력을 확인하고, 배치/단일 예측과 모델 버전 관리를 살펴보는 1분 데모.

## 내용

### 모델 정확도와 피처 영향력
- 병원 입원 기간(time in hospital)을 22% 확률로 정확히 예측하는 모델 — 개선의 여지가 있음.
- 각 컬럼의 영향력(impact)을 확인 가능 — **투약 횟수(number of medications)**와 **검사 절차 수(number of lab procedures)**가 이 모델을 이끄는 가장 강력한 피처 중 두 가지로 나타남.

### 프로덕션 배포 — Predict
- **배치 예측(batch-based prediction)**: 데이터셋을 입력하면 그 데이터셋 전체에 대해 여러 예측을 수행.
- **단일 예측(single prediction)**: 이 모델에 대해 개별적으로 예측을 수행할 수 있음.
- 값을 실시간으로 조정하며 예측 시스템에 변화를 주는 것도 가능.

### 모델 버전 관리
- 여러 버전의 모델 사이를 오가며 빌드·전환 가능 — 예: 새로 만든 피처를 시도해보고 그것으로 모델을 재학습한 뒤, 여러 버전을 유지하며 배치 예측을 수행해 결과를 비교.

### 핵심 통찰
- Canvas는 머신러닝 솔루션에 대한 아이디어를 고수준(high level)에서 빠르게 얻는 좋은 방법이며, 이후 SageMaker로 직접 시스템을 구축하거나 Cloud9 같은 도구로 외부에서 자체 시스템을 구축하는 방식으로 이어갈 수 있음.

## 요약
- SageMaker Canvas는 피처 영향력 확인, 배치/단일 예측, 여러 모델 버전 간 전환을 코드 없이 지원하며, 이는 머신러닝 문제를 고수준에서 빠르게 탐색한 뒤 본격적인 개발(SageMaker/Cloud9)로 넘어가기 위한 좋은 출발점이 된다.
