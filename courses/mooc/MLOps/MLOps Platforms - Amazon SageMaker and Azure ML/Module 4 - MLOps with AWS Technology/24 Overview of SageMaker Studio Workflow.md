# Overview of SageMaker Studio Workflow

## 개요
- SageMaker의 전체 MLOps 워크플로(데이터 준비 → 학습·튜닝 → 배포·관리)와, SageMaker Studio의 런처(launcher)·Canvas·실험 추적 기능을 개괄하는 2분 영상.

## 내용

### SageMaker MLOps 워크플로 단계
1. **데이터 준비(Prepare data)**.
2. **데이터 구축(Build)**.
3. **학습과 튜닝(Training and Tuning)** — 모델이 올바른지 확인.
4. **배포(Deploy)**.
5. **프로덕션에서 관리(Manage in production)** — 특정 모델 버전 관리, A/B 테스트, 해당 모델에 대한 예측 수행, 데이터 드리프트 여부에 따른 재학습 시점 판단 등.

### 도구 카테고리
- MLOps 관점에서 **파이프라인, 프로젝트, 모델 레지스트리(Model Registry)** 등으로 나뉘는 도구 모음이 있음.
- **SageMaker Studio**(일반) 외에 스튜디오 통합 기능도 존재.
- **SageMaker Canvas**: 데이터를 업로드하고 타깃 컬럼을 선택한 뒤 예측을 수행하는, 노코드/로우코드의 상위 수준 비즈니스 인텔리전스형 도구.

### SageMaker Studio — 개발자 친화적 환경
- **런처(Launcher)**에서 시작하는 것이 좋음: 모델·알고리즘 솔루션을 바로 시작(jump start)하거나, **Autopilot 실험**을 만들어 실험 이름과 데이터 위치만 입력해 모델을 자동으로 구축 가능.
- **데이터 임포트 및 탐색**: 환경에 있는 데이터로 바로 시작해 클릭 몇 번으로 시각화와 솔루션을 구축 가능.
- 런치 메뉴에서 데이터 플로우 구축, 신규 컴파일 작업, 신규 프로젝트 등 다양한 작업·구성 요소를 확인 가능. 필요하다면 노트북을 바로 실행해 처음부터 솔루션을 만들 수도 있음.

### 실험 추적
- SageMaker Studio는 런치 메뉴 외에도 이전 실험(experiment)과 시도(trial)를 살펴볼 수 있음 — 프로젝트마다 메트릭, 파라미터, 아티팩트를 관리하는 데 유용한 자원.

## 요약
- SageMaker Studio는 데이터 준비부터 프로덕션 관리까지 이어지는 MLOps 워크플로 전체를 지원하며, 런처를 통한 빠른 시작(Autopilot, 데이터 임포트), Canvas를 통한 노코드 예측, 그리고 실험 추적을 통한 프로젝트 간 메트릭·파라미터 관리를 하나의 개발자 친화적 환경에서 제공한다.
