# Python Logging Lab

## 개요
- Python 내장 `logging` 모듈로 기존 애플리케이션에 구성 가능한 로그 문을 추가해보는 1시간짜리 실습 랩(ungraded lab).

## 내용

### 랩 설명
- Python의 내장 `logging` 모듈을 사용해 기존 애플리케이션에 구성 가능한 로그 문을 추가.
- 로그 형식을 정의하고, 심각도 임계값(severity threshold)을 설정하고, 로그를 콘솔과 파일 양쪽으로 보냄.

### 랩 단계
1. `logging`을 임포트하고 로거 인스턴스 생성.
2. 로그 레벨, 형식, 핸들러를 설정해 로거 구성.
3. debug, info, warning, error 등의 레벨로 로그 문 추가.
4. 애플리케이션을 실행해 로그 파일 생성.
5. 파일 크기, 로테이션(rotation) 등을 변경하도록 설정 수정.
6. 사용자 로그인 같은 이벤트를 추적하도록 로그 문 업데이트.

### 성찰 질문
1. print문 대비 구조화된 로깅의 이점은 무엇인가?
2. 어떤 로그 레벨이 있고 각각 언제 사용하겠는가?
3. 여러 위치로 출력하도록 로깅을 어떻게 구성할 수 있는가?
4. 어떤 유형의 정보는 로깅을 피해야 하는가?
5. 로깅이 프로덕션 시스템의 문제를 디버깅하는 데 어떻게 도움이 되는가?

### 도전 과제
1. 추가 로그 문으로 새 모듈을 계측해보기.
2. 애플리케이션의 특정 부분을 위한 커스텀 로거를 만들어보기.
3. 타임스탬프, 함수 이름, 줄 번호를 추적하도록 형식을 업데이트해보기.
4. 로그 크기를 제한하도록 파일 로테이션을 구성해보기.
5. 콘솔과 파일에 각각 다른 상세도(verbosity) 임계값을 설정해보기.

## 요약
- 이 랩은 "Interactive Python Logging"에서 다룬 로깅 개념을 실제 애플리케이션에 적용해, 로거 구성·다중 출력(콘솔+파일)·로그 로테이션·이벤트 추적까지 실전 로깅 워크플로를 실습한다.
