# Data Drift and Model Monitoring

## 개요
- COVID-19 백신 예측 모델을 예시로, 새로운 데이터가 들어올 때 데이터 드리프트를 감지하고 모델을 재학습·재배포하는 순환 과정을 설명하는 1분 영상.

## 내용

### 데이터 드리프트와 모델 모니터링의 흐름
1. 데이터로 모델을 만듦 — 이 모델은 프로덕션에 배포되어, 예를 들어 COVID-19를 예측(백신 관련 엔드포인트)하는 데 사용될 수 있음.
2. 이후 새로운 데이터(예: 질병의 새로운 변이)가 들어오면 **데이터 드리프트 알림(data drift alert)**이 발생 — "새 모델을 학습해야 한다"는 신호.
3. 새 모델은 **원본 데이터 + 이전 모델이 배포된 이후 발생한 새 데이터**를 결합해 만들어짐.
4. 새 모델이 등록(registered)되고, 학습(trained)되고, 배포(deployed)되어 프로덕션에 투입됨.
5. 이후 같은 과정이 다시 반복되며 세 번째 모델이 만들어짐.

### 핵심 통찰
- 데이터 드리프트와 모델 모니터링은 비교적 단순한 프로세스로 생각할 수 있음 — 핵심은 새로운 데이터가 들어올 때마다 새 모델을 만들어 프로덕션에 투입한다는 것.

## 요약
- 데이터 드리프트 감지 → (원본 데이터 + 신규 데이터로) 재학습 → 새 모델 등록·배포라는 순환 과정이 프로덕션 ML 모델을 최신 상태로 유지하는 핵심 메커니즘이다.
