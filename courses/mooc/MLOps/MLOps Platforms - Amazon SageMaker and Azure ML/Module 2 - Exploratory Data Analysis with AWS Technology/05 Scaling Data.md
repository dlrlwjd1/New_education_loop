# Scaling Data

## 개요
- 머신러닝에서 데이터 **스케일링(scaling)**이 필요한 이유를 단위(unit) 불일치 비유로 직관적으로 설명하는 1분 영상.

## 내용

### 스케일링이 필요한 이유
- 대부분(전부는 아니지만)의 머신러닝 문제는 데이터 스케일링을 필요로 함.
- 직관적 비유: 데이터셋에 여러 컬럼이 있고, 누군가 "5를 뛰었다(ran 5)"라고 말했다고 하자 — 5마일인지, 5킬로미터인지, 5피트인지에 따라 의미가 완전히 달라짐.
- 마찬가지로 한 컬럼은 마일 단위, 다른 컬럼은 피트 단위일 수 있는데, 이를 그대로 비교하면 머신러닝 문제에 적합하지 않은 결과가 나옴.
- 예를 들어 **클러스터링(clustering)**을 수행한다면, 단위가 다른 값들을 그대로 비교할 경우 클러스터링 결과가 올바르게 나오지 않음.

### 해결책 — 스케일링
- 값을 **0과 1 사이**로 스케일링하면, 잘못된 단위 간 절대 비교(absolute comparison) 대신 **상대적 비교(relative comparison)**를 할 수 있게 됨.
- 대부분의 머신러닝 알고리즘이 데이터 스케일링을 요구하며, 이 직관은 비교적 단순함.
- 스케일링을 마치면 예를 들어 **K-평균(K-means) 클러스터링** 같은 솔루션에 데이터를 투입할 수 있게 됨.

## 요약
- 서로 다른 단위(마일 vs 피트 등)를 가진 컬럼을 그대로 비교하면 클러스터링 등의 머신러닝 결과가 왜곡되므로, 데이터를 0~1 범위로 스케일링해 상대적 비교가 가능하도록 만드는 것이 대부분의 머신러닝 알고리즘에 필수적이다.
