# Practical Scenario — Cleaning Customer Review Data

## 개요
- 결측치 처리, NLP, 데이터 스케일링 지식을 적용해보는 5분짜리 AI 생성 인터랙티브 성찰 활동.

## 내용

### 시나리오
- 신제품에 대한 고객 리뷰 데이터셋 작업 중 — 일부 리뷰는 텍스트가 누락되어 있고, 다른 리뷰들은 감성 분석에 큰 의미를 더하지 않는 "the", "a", "is" 같은 흔한 단어들을 포함.
- 질문: 고객 감성을 예측하는 머신러닝 모델을 위해 이 데이터를 어떻게 정제할 것이며, 구체적으로 어떤 기법을 사용하고 그 이유는?

### 종합 답변 (강의 개념 기반)
1. **결측치가 있는 리뷰 처리**: 텍스트가 아예 없는 리뷰는 감성 분석에 사용할 수 없으므로, 데이터 양이 충분하다면 해당 행을 **제거(drop)**하는 것이 합리적이다. 만약 리뷰 자체는 없지만 평점(rating) 등 다른 유용한 필드가 남아있다면, 텍스트 없이도 활용 가능한 방식으로 별도 처리하거나 대체(imputation) 여부를 신중히 판단한다.
2. **불용어 제거**: "the", "a", "is" 같은 단어는 감성을 전달하지 않으므로 **NLP 전처리(토큰화 + 불용어 제거)**로 걸러낸다. `nltk`의 `word_tokenize`와 `stopwords`를 사용해 각 리뷰를 토큰화한 뒤 불용어 목록에 있는 토큰을 제거한다.
3. **정제 순서**: 결측치 제거 → 토큰화 → 불용어 제거 순으로 진행해, 감성 분석 모델이 실제로 의미 있는 단어(형용사, 감성 표현 등)에 집중하도록 만든다.
4. **스케일링과의 관계**: 텍스트 자체는 스케일링 대상이 아니지만, 이후 감성 점수나 평점 같은 수치형 피처를 함께 모델에 사용한다면 `MinMaxScaler` 등으로 스케일을 맞추는 것이 필요할 수 있다.

## 요약
- 고객 리뷰 데이터 정제는 "결측 리뷰 제거 → 토큰화 → 불용어 제거"의 순서로 이뤄지며, 이는 감성 분석 모델이 노이즈 없이 실제 감성 신호에 집중할 수 있도록 하기 위함이다.
