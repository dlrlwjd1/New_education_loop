# Lesson Reflection — Sanitizing and Preparing Data for Modeling

## 개요
- Lesson 1 전체를 요약하는 공식 회고 자료: EDA·모델링 전에 결측치, 형식 오류, 이상치 같은 문제를 처리하는 핵심 데이터 준비·정제 기법을 다뤘다.

## 내용

### 핵심 포인트
- 결측 데이터는 행 제거, 값 대체(imputing), 또는 결측치에 강건한 모델링 방법으로 처리할 수 있다.
- 스케일링은 모든 피처를 0~1 같은 표준 범위에 놓아 동등한 영향력을 갖게 한다.
- 레이블링은 피처를 타깃 변수에 매핑해 지도학습을 가능하게 한다.
- NLP 전처리는 토큰화와 불용어 제거를 포함한다.
- 효과적인 EDA나 모델링 이전에 데이터 문제들이 반드시 해결되어야 한다.

### 회고 질문
1. 결측치가 있는 행을 제거할 때와 값을 대체(impute)할 때는 각각 언제인가?
2. 스케일이 다른 데이터가 분석과 모델에 어떤 영향을 미칠 수 있는가?
3. 기존 데이터셋 외에 레이블을 확보하는 흔한 방법들은 무엇인가?
4. NLP 전처리에서 불용어를 제거하는 이유는 무엇인가?
5. 어떤 유형의 데이터 문제에 대해 EDA가 문제 처리 전 필수적인 첫 단계인가?

### 도전 과제
1. 데이터셋에서 결측 데이터가 있는 컬럼을 찾아 제거 vs 채우기를 연습해보기.
2. 이질적인(heterogeneous) 피처를 가진 데이터셋에 스케일링을 적용해 영향을 실험해보기.
3. Amazon Mechanical Turk를 통한 크라우드소싱 데이터 레이블링 방법을 조사해보기.
4. NLP 데이터셋을 찾아 토큰화/표제어 추출(lemmatizing)과 불용어 제거를 연습해보기.
5. 시각화와 통계 분석으로 이상치를 식별하고 처리를 연습해보기.

## 요약
- Lesson 1은 결측치 처리(dropna/imputing) → 스케일링 → 레이블링 → NLP 전처리(토큰화/불용어 제거)까지, 모델링 이전 데이터 정제의 핵심 4단계를 다뤘다.
