# Covid19 Exploratory Data Analysis (Lab)

## 개요
- "Graphing Data" 데모에서 다룬 COVID-19 데이터셋을 활용해 직접 EDA를 확장하고, 모델링과 결론까지 작성해보는 1시간짜리 실습 랩(ungraded lab).

## 내용

### 과제
1. **Task 1**: COVID-19 데이터셋으로 자신만의 EDA를 만들어보기 — 이 분석에 어떤 새로운 것을 추가할 수 있는가?
2. **Task 2**: 모델링(modeling) 섹션에서 모델을 만들어보기.
3. **Task 3**: 무엇을 배웠는지에 대한 결론(conclusion) 작성.
4. **Task 4**: 자신의 GitHub 계정에 게시(publish)하기.

## 요약
- 이 랩은 "Graphing Data" 데모의 수집 → EDA → 모델링 → 결론 4단계 구조를 그대로 따라, COVID-19 데이터로 직접 분석을 확장하고 GitHub에 게시까지 완료하는 실습이다.
