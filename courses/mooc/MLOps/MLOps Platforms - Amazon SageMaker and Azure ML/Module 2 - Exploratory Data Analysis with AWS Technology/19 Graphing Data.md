# Graphing Data

## 개요
- 뉴욕타임즈의 주(state)별 COVID-19 데이터를 예시로, 데이터 과학 프로젝트의 "수집 → EDA → 모델링 → 결론" 구조와 실제 기술 통계·시각화 작업을 시연하는 3분 데모.

## 내용

### 데이터 과학 프로젝트의 4단계 구조
- 데이터 과학 프로젝트를 다룰 때 권장하는 구조: **수집(ingestion) → 탐색적 데이터 분석(EDA) → 모델링(modeling) → 결론(conclusion)**. 각 단계는 필요한 핵심 요소를 포함하며, 단계 간 자유롭게 오갈 수 있음.

### 수집과 초기 탐색
- 뉴욕타임즈의 주별 COVID 데이터를 직접 가져와, 최신 레코드를 확인(현재 데이터 상태 파악) → 컬럼과 shape 확인 — 데이터의 기본 상태를 "발로 차보는(kicking the tires)" 과정.

### 기술 통계
- `df.describe()`로 확진자(cases), 사망자(deaths) 등의 수치 요약 확인 — 예: 사망자 수의 중앙값(50%)은 4,345이지만 최댓값은 96,960으로 큰 편차 존재.

### 시각화
- 확진자(cases) vs 사망자(deaths)를 산점도로 플로팅하고 **hue**를 추가해 추가 정보 확인 → 확진자 수와 사망자 수 사이에 뚜렷한 **선형 상관관계** 확인.
- 날짜 범위로 데이터를 필터링해 일자별 패턴 확인.
- 정렬(sorting)로 값 기준 데이터 확인, 주(state)별 분석으로 확진자 수 상위 주(캘리포니아, 플로리다, 뉴욕, 펜실베이니아, 텍사스 — 대체로 인구가 많은 주) 확인 후 플로팅.

### 핵심 통찰
- 캘리포니아·뉴욕 등의 데이터에서 **로그(logarithmic)** 패턴이 나타나기 시작 — 이는 지수적 성장(exponential growth)이 결국 완만해지는(taper off) 현상과 관련되며, 사망자 수가 결국 **정체기(plateau)**에 도달할 수 있음을 시사.

## 요약
- 데이터 과학 프로젝트는 수집 → EDA(기술 통계 + 시각화) → 모델링 → 결론의 구조로 진행되며, COVID 데이터 예시에서는 확진자-사망자 간 선형 상관관계와 지수 성장이 로그 형태로 완만해지는 패턴을 `describe()`와 산점도/라인 그래프로 확인할 수 있었다.
