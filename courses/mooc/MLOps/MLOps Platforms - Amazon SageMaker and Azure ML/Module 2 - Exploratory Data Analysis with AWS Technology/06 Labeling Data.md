# Labeling Data

## 개요
- NBA 선수 데이터 예시로 **피처(feature)**, **레이블(label)**, **타깃(target)** 개념의 관계를 설명하는 1분 영상.

## 내용

### 피처와 레이블, 타깃의 관계
- 예시: NBA 선수 데이터에서 "경기당 득점(point-per-game)" 컬럼은 **레이블(label)**이자 동시에 **피처(feature)**이기도 함 — 같은 컬럼을 가리키는 두 가지 다른 용어.
- 이 피처를 사용해 **타깃(target)**, 예를 들어 NBA 선수의 연봉을 예측할 수 있음.
- 만약 NBA 팀 구단주라면, 경기당 득점을 바탕으로 해당 선수에게 적합한 연봉을 산정하려 할 수 있음 — 타깃을 예측하는 데 사용하는 것이 피처이며, 그 피처는 특정 레이블을 가져야 함.

### 레이블이 없는 경우
- 레이블이 없다면 다른 방법으로 레이블을 얻어야 함:
  - **사람 작업자(human workers)** 활용 — 예: Amazon Mechanical Turk.
  - **비지도 머신러닝(unsupervised machine learning)**으로 자연스러운 그룹(natural groupings)을 만든 뒤, 이를 레이블로 활용.

### 핵심 통찰
- 지도 머신러닝(supervised machine learning) 문제를 풀려면, 일반적으로 레이블이 있는 피처가 반드시 필요함.

## 요약
- 피처는 예측에 사용되는 입력값, 레이블은 그 피처(또는 타깃)에 부여된 값이며, 지도학습을 위해 레이블이 없다면 사람 작업자(Mechanical Turk)나 비지도 학습으로 레이블을 확보해야 한다.
