# Feature Engineering with scikit-learn on Databricks

## 개요
- Databricks에서 scikit-learn을 활용한 엔드투엔드 ML 예제(오디오 요약 1분 29초) — 데이터 시각화부터 하이퍼파라미터 튜닝, MLflow 실험 추적, 모델 등록·배포·서빙까지 전체 파이프라인을 다루는 읽기 자료.

## 내용

### 요약
- 이 엔드투엔드 ML 예제는 데이터 시각화, SparkTrials를 활용한 하이퍼파라미터 튜닝, MLflow에서의 실험 추적, 모델 등록, 배포, AWS 기술을 활용한 서빙까지 다룸.
- 핵심 단계: 탐색적 데이터 분석 → 베이스라인 모델과 XGBoost 모델 학습 → 비교를 위한 메트릭 로깅 → 최적 모델 탐색 → 저지연(low-latency) 예측 환경 구성.

### 핵심 포인트
- 시각화와 통계 분석은 데이터 이해와 모델 디버깅을 가능하게 한다.
- 하이퍼파라미터 스윕(sweep)은 최적 설정 탐색을 자동화한다.
- MLflow는 여러 실행(run)에 걸친 실험을 추적해 쉬운 비교를 가능하게 한다.
- Model Registry는 버전을 관리하고 모델을 프로덕션으로 전환한다.
- 서빙(Serving)은 배포된 모델로부터 실시간 추론을 가능하게 한다.

### 성찰 질문
1. 어떤 문제에 머신러닝이 적절한 해결책인지 어떻게 판단할 수 있는가?
2. 모델링 전에 데이터를 스케일링/정규화하는 것이 왜 중요한가?
3. 아키텍처와 하이퍼파라미터를 선택하는 데 어떤 전략이 도움이 되는가?
4. 실험 추적은 모델 개선을 어떻게 가능하게 하는가?
5. 배포와 서빙 결정에 어떤 요인들이 영향을 미치는가?

### 도전 과제
1. 데이터셋을 찾아 Seaborn으로 초기 분석을 위한 시각화를 생성해보기.
2. 정규화(normalization)를 구현하고 샘플 데이터셋에서 그 차이를 확인해보기.
3. 그리드 서치(grid search), 랜덤 서치(random search) 같은 하이퍼파라미터 선택 방법을 조사해보기.
4. MLflow Tracking API로 샘플 학습 실행의 메트릭을 로깅해보기.
5. Flask나 FastAPI로 작은 모델을 로컬에 배포하고 요청을 테스트해보기.

## 요약
- 이 읽기 자료는 EDA → 하이퍼파라미터 튜닝(SparkTrials) → MLflow 실험 추적 → Model Registry → 실시간 서빙까지 이어지는 엔드투엔드 ML 파이프라인을 개괄하며, 앞선 Key Terms에서 다룬 MLflow·SageMaker 튜닝 개념들이 실제로 어떻게 하나의 워크플로로 연결되는지 보여준다.
