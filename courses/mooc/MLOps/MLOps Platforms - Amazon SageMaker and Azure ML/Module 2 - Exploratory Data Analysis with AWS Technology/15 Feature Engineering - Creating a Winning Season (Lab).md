# Feature Engineering — Creating a Winning Season (Lab)

## 개요
- 앞선 "Feature Engineering Concepts" 데모의 NBA 승리 시즌 피처 아이디어를 실제 NBA 선수 데이터셋으로 직접 구현해보는 1시간짜리 실습 랩(ungraded lab).

## 내용

### 랩 목표
- 선수 통계를 활용해 NBA 팀 시즌을 승리/패배 시즌으로 분류하는 데 피처 엔지니어링 기법을 적용해보기.

### 랩 설명
- NBA 선수 데이터셋을 사용해, 팀 시즌 기록이 승리 시즌일지 패배 시즌일지 예측하는 모델 학습에 도움이 되는 피처를 엔지니어링.

### 랩 단계
1. NBA 선수 데이터셋 가져오기.
2. 시각화로 데이터 분포 탐색.
3. 총 승수 임계값을 기준으로 `winning_season` 피처 생성.
4. 나이, 득점, 연봉 등 핵심 피처 선택.
5. 결측 데이터 처리 및 피처 전처리.
6. 엔지니어링된 데이터셋으로 분류 모델 학습.
7. 테스트셋에서 모델 정확도 평가.

### 성찰 질문
1. 어떤 피처가 가장 예측력 있는 신호를 제공했는가?
2. 피처 스케일링이 모델 성능에 어떤 영향을 미치는가?
3. 예측을 개선하려면 어떤 데이터를 추가로 수집하겠는가?
4. 승리/패배 시즌의 불균형을 어떻게 처리하겠는가?
5. 실제 예측을 위해 이것을 어디에 배포하겠는가?

### 도전 과제
1. 선수 통계를 활용해 새로운 피처를 엔지니어링해보기.
2. 행을 제거하지 않고 결측 데이터를 처리해보기.
3. Random Forest와 SVM 같은 모델을 비교해보기.
4. 튜닝과 교차 검증으로 모델을 개선해보기.
5. 사용자가 피처를 입력할 수 있는 웹 인터페이스를 구성해보기.

## 요약
- 이 랩은 "Feature Engineering Concepts"에서 개념적으로 다룬 승수 임계값 기반 `winning_season` 피처 생성을 실제 NBA 선수 데이터셋에 적용해, 결측치 처리·피처 선택·분류 모델 학습·평가까지 이어지는 전체 피처 엔지니어링 워크플로를 실습한다.
