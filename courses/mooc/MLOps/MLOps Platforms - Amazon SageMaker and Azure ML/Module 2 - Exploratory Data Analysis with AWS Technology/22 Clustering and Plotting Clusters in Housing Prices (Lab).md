# Clustering and Plotting Clusters in Housing Prices (Lab)

## 개요
- 미국 지역별 주택 중위 판매가(median home sale price) 데이터에 K-평균 클러스터링을 적용해, 시장별 주택 가격 상승률(appreciation)을 비교하는 1시간짜리 실습 랩(ungraded lab).

## 내용

### 랩 목표
- 주택 가격 데이터를 탐색해 클러스터를 식별하고, 서로 다른 시장 간 주택 가격 상승률을 비교하기.

### 랩 설명
- 미국 여러 지역의 시간 경과에 따른 주택 중위 판매가 데이터셋을 사용.
- 데이터를 정제·준비한 뒤 **K-평균 클러스터링**을 적용해 주택 시장을 그룹화.
- 식별된 클러스터와 시장별로 주택 가격 상승률을 분석·비교.

### 랩 단계
1. **패키지 임포트**: pandas, numpy, sklearn, seaborn 등.
2. **데이터 수집**: CSV 데이터 파일 읽기.
3. **데이터 정제**: 컬럼명 변경, 데이터 타입 변환, 선택한 도시들의 비교용 데이터프레임 생성.
4. **스케일링과 클러스터링**: 수치 데이터 스케일링 → K-평균으로 클러스터 식별.
5. **클러스터 분석**: 원본 데이터프레임에 클러스터 할당값 추가 → 시장별 상승 비율(appreciation ratio) 계산 → 클러스터와 상승률을 보여주는 플롯 생성.
6. **시장 비교**: 여러 시장/도시의 상승률 통계를 추출해 비교 — 예: 샌프란시스코 vs 마린 카운티 vs 팔로알토 vs 전체 중위값.

## 요약
