# Clustering Data

## 개요
- NBA 시즌 통계(득점, 리바운드, 어시스트)를 예시로 클러스터링의 핵심 수학적 원리와 다차원 공간에서 나타나는 자연스러운 그룹핑을 설명하는 2분 영상.

## 내용

### 클러스터링의 핵심 직관
- NBA 시즌 통계: 득점(points), 리바운드(rebounds), 어시스트(assists).
- 한 경기에서 세 지표 모두 10을 넘기면 "트리플 더블(triple double)"이라 불릴 만큼 드문 기록.
- 이 세 값을 다차원 공간에 플롯하면(각 축이 득점/어시스트/리바운드), 값들이 서로 가까운 **자연스러운 그룹(natural groupings)**이 클러스터로 나타남.

### 나타나는 클러스터의 의미
- 득점을 많이 하면서도 어시스트가 상당한 선수들 — 바스켓에서 멀리 떨어져 있어 리바운드는 적은 편 → 하나의 그룹으로 묶임.
- **포인트 가드(Point Guards)**: 어시스트에서 두각을 나타내며 함께 그룹화됨, 리바운드도 어느 정도 있지만 센터만큼은 아님.
- **센터(Centers)**: 바스켓 근처에서 리바운드에 집중 — 리바운드가 많은 별도의 그룹으로 나타남.

### 핵심 통찰
- 다차원 공간에서 클러스터링을 수행하면, 데이터셋에 따라 득점왕·포인트 가드·센터 같은 **자연스럽게 창발하는(emergent) 레이블**이 나타남.
- 실제로 NBA 데이터셋에 K-평균(K-means) 클러스터링을 직접 적용해보면, 일반적으로 생각하는 포지션(포인트 가드, 포워드 등)에 부합하는 자연스러운 그룹을 쉽게 발견할 수 있음.

## 요약
- 클러스터링은 다차원 공간에서 값이 서로 가까운 데이터 포인트들을 자연스러운 그룹으로 묶어주며, NBA 선수 통계(득점/리바운드/어시스트)에 K-평균을 적용하면 포인트 가드·센터 같은 포지션에 대응하는 창발적 레이블을 발견할 수 있다.
