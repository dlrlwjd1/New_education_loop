# Lesson Reflection — Analyzing and Visualizing Data for Machine Learning

## 개요
- Lesson 3 전체를 요약하는 공식 회고 자료: 기술 통계와 유의미한 시각화를 통해 데이터를 이해하고 인사이트를 얻는 핵심 기법을 다뤘다. 요약 지표·그래프·필터링·클러스터링 계산을 통해 숨겨진 패턴과 추세가 드러나 모델링에 정보를 제공한다.

## 내용

### 핵심 포인트
- 통계는 데이터 분포의 특성을 드러낸다.
- 시각화는 변수 간 관계를 보여준다.
- 정렬과 필터링은 부분집합을 분리해낸다.
- 로그 패턴은 지수적 성장을 나타낸다.
- 클러스터링은 유사한 데이터를 자동으로 그룹화한다.

### 회고 질문
1. 요약 통계는 이상치와 문제를 어떻게 드러낼 수 있는가?
2. 추세와 상관관계 분석에 가장 유용한 그래프는 무엇인가?
3. 필터링은 어떤 방식으로 분석을 관련 데이터에 집중시키는가?
4. 성장 패턴은 예측 모델링에 어떤 영향을 미칠 수 있는가?
5. 클러스터링이 인사이트를 얻기에 적절한 경우는 언제인가?

### 도전 과제
1. 기존 데이터로부터 부가가치 있는 피처를 엔지니어링해보기.
2. Matplotlib으로 애니메이션 플롯과 대시보드를 만들어보기.
3. 샘플 데이터셋에 K-평균 클러스터링을 구현해보기.
4. PCA 같은 차원에서 클러스터를 비교해보기.
5. 새로운 통계 플롯으로 업데이트 가능한 데이터 대시보드를 구성해보기.

## 요약
