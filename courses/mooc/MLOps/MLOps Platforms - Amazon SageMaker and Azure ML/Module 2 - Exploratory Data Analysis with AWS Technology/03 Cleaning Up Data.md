# Cleaning Up Data

## 개요
- 지저분한(dirty) 데이터를 유용하게 사용하기 전 반드시 거쳐야 하는 전처리(preprocessing) 과정 — 결측치 처리와 NLP 텍스트 전처리 — 를 설명하는 1분 영상.

## 내용

### 결측치 처리
- 탐색적 데이터 분석(EDA)을 시작하기 전, pandas에서 `df.isna()` 같은 방법으로 결측치(missing values)를 확인.
- 결측치를 발견했을 때 데이터 과학자가 내려야 할 결정:
  - **행을 제거(drop)**할 것인가 — 예: 데이터가 충분히 많다면 해당 행을 버리는 것이 더 나을 수 있음.
  - **값을 대체(impute)**할 것인가 — 예: 데이터가 적다면 데이터셋의 중앙값(median)을 결측치 자리에 채워 넣는 방식.

### NLP 전처리
- 자연어 처리(NLP)에서는 **토큰화(tokenization)**, **불용어(stop words) 제거** 같은 전처리가 매우 흔함.
- 예: 감성 분석(sentiment analysis)을 수행하기 전, "the", "and" 같은 단어를 제거 — 이런 단어들이 NLP 작업의 효과를 떨어뜨리기 때문.

## 요약
- 데이터 전처리의 핵심은 결측치를 행 제거 또는 대체(imputation)로 처리하는 것과, NLP 작업 전 불용어를 제거하는 토큰화 과정이며, 두 경우 모두 데이터 과학자의 판단(데이터 양, 분석 목적)에 따라 적절한 방법을 선택해야 한다.
