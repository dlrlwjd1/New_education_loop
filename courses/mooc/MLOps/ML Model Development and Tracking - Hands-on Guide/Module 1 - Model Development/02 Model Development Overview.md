# Model Development Overview

## 개요
- 약국 재고 예측 사례로 데이터 과학자가 모델 개발 과정에서 마주하는 4가지 핵심 질문과, 이 과정에서 MLOps 엔지니어가 어떻게 도울 수 있는지 설명하는 5분 영상.

## 내용

### 사례 — 약국 재고 예측
- 조직 산하 약국들이 수집한 데이터를 학습에 활용 — 이 데이터를 처리해 각 약국에 향후 필요한 재고량을 예측하는 ML 모델(재고 예측 모델)을 만들고자 함.
- 데이터셋과 사용 사례는 있지만, 데이터 과학자가 이 ML 모델을 어떻게 구축하기 시작할지가 관건.

### 데이터 과학자가 마주하는 4가지 핵심 질문
1. **어디서, 어떻게 모델 개발을 하는가?**: 올바른 환경과 도구 선택에 관한 질문.
2. **어디서, 어떻게 대용량 데이터셋으로 모델을 학습시키는가?**: 효과적인 학습은 모든 데이터 과학자에게 도전 과제.
3. **서로 다른 모델 평가 버전을 어떻게 관리하는가?**: 평가를 추적해야 개선을 측정 가능 — 예: 모델 A를 만들어 학습·테스트한 뒤, 모델 B로 더 나은지 비교하려면 두 모델의 결과를 비교할 수 있는 플랫폼이 필요.
4. **모든 모델 버전을 어디에 추적·보관하는가?**: 모델 버전의 중앙 저장소를 유지하는 것은 과거 변경 이력과 그에 따른 모델 동작을 되짚어보는 데 필수적.
5. (추가로) **실험을 어떻게 수행하고 결과를 추적하는가?**: 이 모든 것을 하나로 묶어, 연구 과정이 반복적이고 데이터 기반이 되도록 함.

### 실제로 어떻게 해결되는가
- 첫 단계: 어떤 모델 컴퓨팅 환경을 선택할지 결정 → 이후 모델 학습에 집중.
- 데이터 과학자들이 선호하는 개발 도구·환경: **Jupyter Notebook**, **Colab Notebook**, **AWS SageMaker**, **GCP Vertex AI** — 필요한 패키지를 노트북에 설치하고, 데이터셋에 연결한 뒤 모델 구축 시작.

### MLOps 엔지니어의 역할
- 데이터 과학자가 SageMaker나 Vertex AI를 어떻게 설정할 것인가? Jupyter Notebook을 로컬에서 사용하기도 하지만, **Kubernetes 위에서 필요할 때마다(ad-hoc) Jupyter Notebook을 띄우는 것**도 가능 — 이런 자동화·인프라 요구가 바로 MLOps 엔지니어가 강점을 발휘해 모델 개발 과정에서 데이터 과학자의 병목을 풀어주는 영역.
- 예시 흐름: 데이터 과학자가 Jupyter Notebook에 데이터를 로드 → 전처리 → 여러 ML 알고리즘 실험 → 대용량 데이터 처리를 위해 컴퓨팅을 **Google Colab**이나 **SageMaker**로 옮겨 **GPU 가속**으로 모델 학습 → 학습된 모델의 모든 버전을 **Vertex AI**에 저장해 향후 참조.

## 요약
- 모델 개발과 학습은 올바른 알고리즘 선택, 적절한 클라우드 도구(Jupyter/Colab/SageMaker/Vertex AI) 활용, 그리고 이 모든 과정에서 인프라 자동화를 통해 데이터 과학자를 지원하는 MLOps 엔지니어의 역할이 결합된 다단계 과정이다.
