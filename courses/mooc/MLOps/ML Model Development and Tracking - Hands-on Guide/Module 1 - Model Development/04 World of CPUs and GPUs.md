# World of CPUs and GPUs

## 개요
- 현대 컴퓨팅의 4가지 과제를 짚은 뒤, CPU와 GPU를 6가지 측면에서 비교하고 MLOps 엔지니어가 이 차이를 알아야 하는 이유(GPU 프로비저닝 판단)를 설명하는 4분 영상.

## 내용

### 현대 컴퓨팅의 4가지 핵심 과제
1. **모델 연산**: 반복적인 계산을 처리할 고성능 프로세서 필요.
2. **대용량 데이터셋**: 처리해야 할 데이터 양의 지속적 증가.
3. **긴 학습 시간**: ML 모델 학습은 며칠, 심지어 몇 주가 걸리기도 함.
4. **복잡한 딥러닝 모델**: 속도와 효율성 모두 요구.
- 이 과제들 때문에 전통적인 CPU 기반 시스템은 최첨단 컴퓨팅 작업에 덜 실용적 — 여기서 **GPU**가 등장.

### CPU vs GPU — 6가지 핵심 비교

| 측면 | CPU | GPU |
|---|---|---|
| **아키텍처** | 순차 처리에 최적화된 적은 수의 강력한 코어 | 병렬 처리를 위한 수천 개의 더 작은 코어 |
| **처리 방식** | 로직·의사결정이 필요한 범용 작업에 강점 | 여러 데이터 포인트에 동일 연산을 동시에 수행 — ML·이미지 처리에 핵심적 |
| **코어 수** | 적지만 강력한 코어 | 덜 강력하지만 병렬로 작동하는 수많은 코어 — 대용량 데이터셋 처리에 필수 |
| **대역폭(Bandwidth)** | 낮은 대역폭, 범용 컴퓨팅에 적합 | 더 높은 메모리 대역폭, ML의 대규모 연산에 이상적 |
| **연산 특화** | 다양한 작업을 효과적으로 처리 | 행렬·벡터 연산 같은 수학 연산에 특화 — 대부분 ML 알고리즘의 기반 |
| **효율성** | 대규모 병렬 작업에는 비효율적, 학습 시간이 느림(제한된 병렬성 때문) | 대규모 병렬 처리로 학습 시간을 크게 단축, 전력은 더 소모하지만 병렬 연산에서는 훨씬 효율적 |

### MLOps 엔지니어가 이 차이를 알아야 하는 이유
- 데이터 과학자가 새로운 GPU 요청을 가지고 올 때, **왜** 이를 요청하는지, GPU가 실제로 도움이 되는지 이해해야 함 — GPU는 비용이 많이 들고, 허용되더라도 일반적으로 쉽게 구할 수 없어 프로비저닝이 어려운 경우가 많음.

### 핵심 통찰
- CPU와 GPU는 서로 다른 작업에 맞춰져 있음 — CPU는 다양한 로직 집약적 프로세스를, GPU는 고도로 병렬적인 작업을 처리하는 데 강점.
- MLOps 생애주기의 어느 시점에서든 ML 모델 학습을 위해 CPU와 GPU 중 하나를 선택해야 하는 상황을 마주하게 됨.

## 요약
- CPU는 적고 강력한 코어로 순차적·로직 중심 작업에, GPU는 수천 개의 작은 코어로 병렬적·행렬 연산 중심 작업(ML 학습)에 강점을 가지며, MLOps 엔지니어는 데이터 과학자의 GPU 요청이 실제로 정당한지 판단하기 위해 이 차이를 이해해야 한다.
