# Course Introduction

## 개요
- 강사 Raghunandan Asano가 이 코스(모델 개발·실험 추적)의 구성과 학습 목표를 소개하는 1분 31초짜리 오리엔테이션 영상.

## 내용

### 강사 소개와 학습 방식
- 강사 Raghunandan Asano — 이전 "Data Engineering Essentials" 코스와 동일한 강사.
- MLOps는 오늘날의 빠르게 변화하는 기술 환경에서 단순한 유행어가 아니라 **필수 요소**.
- 코스 전반에 걸쳐 실습 랩(hands-on labs)에 참여하며 실제와 유사한 환경에서 실험하고 실수하며 배우는(learn by doing) 방식으로 실전 DevOps 과제에 대비.

### 코스 구성 개요
- **모델 개발, 모델 학습, 하이퍼파라미터 튜닝**을 다루고, **CPU와 GPU의 세계**를 탐구.
- **MLflow**를 사용해 서버를 설정하는 방법을 실습 데모와 최종 핸즈온 랩을 통해 경험.

### 커뮤니티
- KodeKloud는 커뮤니티를 중요하게 여김 — 활발한 포럼에서 질문을 올리거나, 인사이트를 공유하거나, 동료 학습자를 도울 수 있음.

## 요약
- 이 코스는 모델 개발·학습·하이퍼파라미터 튜닝, CPU/GPU 이해, MLflow를 활용한 실험 추적·서버 설정까지 실습 중심으로 구성된다.
