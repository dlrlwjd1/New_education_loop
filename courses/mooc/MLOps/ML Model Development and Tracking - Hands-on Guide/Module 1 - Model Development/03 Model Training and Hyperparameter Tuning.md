# Model Training and Hyperparameter Tuning

## 개요
- 모델 평가 지표(정밀도·재현율), 모델 학습의 3단계 핵심 과정, 하이퍼파라미터 튜닝(그리드 서치, 교차 검증) 개념을 설명하는 3분 영상.

## 내용

### 모델 평가 — 정밀도(Precision)와 재현율(Recall)
- 모델을 구축한 뒤 첫 단계는 성능 평가 — 핵심 지표는 **정밀도(precision)**와 **재현율(recall)**.
- **정밀도**: 모델이 양성(positive)이라고 예측한 것들 중 실제로 올바르게 예측된 비율.
- **재현율**: 실제 양성인 것들 중 모델이 올바르게 예측한 비율.
- 세부 이론까지 깊이 파고들 필요는 없지만, 이 두 용어(정밀도·재현율)는 데이터 과학자가 항상 사용하는 중요한 개념이므로 기억해둘 것.

### 모델 학습의 3가지 핵심 단계
1. **대용량 데이터셋으로 학습**: 모델이 더 잘 일반화(generalize)되고 다양한 시나리오를 다룰 수 있도록 보장.
2. **각 단계마다 정밀도·재현율 평가**: 학습 과정 전반에서 모델의 강점·약점을 지속적으로 파악.
3. **데이터 분할(partitioning)**: 데이터셋을 학습/검증/테스트로 분할 — 모델이 학습 데이터에 과적합되지 않도록 보장하는 핵심 요소.
   - *(영상에서 언급된 비율은 "학습 70%, 검증 50%, 테스트 15%"였으나 합이 100%를 넘어 실제로는 구술 오류로 보임 — 일반적으로 흔히 쓰이는 비율은 학습 70%, 검증 15%, 테스트 15% 방식이다.)*

### 하이퍼파라미터 튜닝
- **그리드 서치(Grid Search)**: 하이퍼파라미터 조합을 체계적으로 테스트해 최적의 조합을 찾는 대표적 기법.
- **교차 검증(Cross-Validation)**: 예를 들어 **5-폴드 교차 검증**으로 여러 데이터셋에 걸쳐 모델 성능을 검증.
- **평가 지표**: 튜닝 후 **정확도(accuracy)**와 **F1 점수** 같은 지표로 모델 성능을 명확히 파악 — 예: 정확도 85%, F1 점수 0.80이면 비교적 균형 잡힌 모델임을 시사.

### MLOps 엔지니어의 역할
- 모델 학습과 하이퍼파라미터 튜닝은 정제·평가·최적화를 반복하는 과정이며, MLOps 엔지니어는 이 단계들 여러 곳에서 데이터 과학자와 함께 관여하게 됨.
- 예: 추가 하이퍼파라미터 튜닝을 위해 클라우드에 추가 리소스를 프로비저닝해야 할 수 있고, 더 나은 성능 평가를 위해 외부 데이터를 가져오거나 기존 데이터를 정제해달라는 요청을 받을 수 있음.
- 이런 개념을 알고 있으면 데이터 과학자와 훨씬 더 원활하게 소통할 수 있음.

## 요약
- 모델 학습은 대용량 데이터 학습 → 정밀도·재현율 평가 → 데이터 분할(학습/검증/테스트)의 3단계로 이뤄지며, 그리드 서치와 교차 검증을 통한 하이퍼파라미터 튜닝으로 정확도·F1 점수를 개선하는 반복적 최적화 과정이다.
