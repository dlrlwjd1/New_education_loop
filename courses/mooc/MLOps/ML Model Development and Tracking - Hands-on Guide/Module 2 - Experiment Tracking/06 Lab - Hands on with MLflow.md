# Lab: Hands on with MLflow

## 개요
- 앞선 데모들(MLflow 설치·설정, 실험 실행·비교, 모델 아티팩트·버전 관리)을 KodeKloud 플랫폼에서 직접 실습해보는 랩.

## 내용
- KodeKloud 랩 접근 방법: 코스의 KodeKloud 링크로 이동 → 로그인/계정 생성 → 등록 후 모든 랩·레슨에 접근.
- 이 레슨(MLflow를 활용한 실험 추적)에 대한 실습 랩 링크가 제공됨.

## 요약
- 이 랩은 앞선 MLflow 데모(설치, 실험 실행·비교, 모델 레지스트리 등록)를 KodeKloud 환경에서 직접 실습해볼 수 있도록 연결하는 자료다.
