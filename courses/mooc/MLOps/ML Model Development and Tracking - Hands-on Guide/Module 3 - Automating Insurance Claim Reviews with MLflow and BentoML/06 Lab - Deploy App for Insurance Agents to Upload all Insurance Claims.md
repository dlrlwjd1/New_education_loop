# Lab: Deploy App for Insurance Agents to Upload all Insurance Claims

## 개요
- 실습(Reading, 10분) — 본문은 실제 실습 문제가 아니라 **KodeKloud 플랫폼에 접속해 실습을 진행하는 방법**을 안내하는 일반 안내문.

## 내용
- KodeKloud 코스 링크로 이동 → 계정 로그인/가입 → 등록 후 코스의 모든 랩·레슨에 접근 가능하다는 접속 절차만 안내됨.
- 실습 주제는 앞선 데모들(더미 데이터 생성 → MLflow 실험 → BentoML 등록/서빙 → Flask 앱 연동)을 학습자가 직접 KodeKloud 환경에서 재현해보는 것으로 추정.
- 실제 실습 콘텐츠(단계별 지시문, 정답)는 KodeKloud 외부 플랫폼에 있으며 이 페이지에는 포함되어 있지 않음.

## 요약
- 이 항목은 실습 내용 자체가 아니라 KodeKloud 랩 플랫폼 접속 안내문이다.
