# Unsupervised Learning

## 개요
- 형식: 영상 (약 6분)
- 핵심: **시뮬레이션한 4개 데이터셋**에 군집 알고리즘 5종을 걸어 비교한다. 결론은 **모든 것을 이기는 군집 방법은 없다**는 것과 **평가 지표를 믿을 때 주의해야 한다**는 것.

## 내용

### 왜 데이터를 시뮬레이션하는가
> **모든 군집 알고리즘이 동등하게 만들어지지 않았기 때문**이다. 그 강점과 약점을 이해하는 데 있어 **군집 할당을 시각화하는 것이 큰 도움이 된다.**

4개 데이터셋(A·B·C·D)을 만들고, 알고리즘 계보와의 대응을 이렇게 설명한다.

| 데이터셋 | 어떤 알고리즘을 염두에 두고 개발된 형태인가 |
|---|---|
| A, B (앞의 두 개) | **스펙트럼 군집화** 같은 방법 |
| C, D (뒤의 두 개) | **가우시안 혼합 모델(GMM)** 과 그 변형 |

### 평가 지표 — 실루엣 점수
군집 할당을 평가하는 데 **실루엣 점수(silhouette score)** 를 쓴다. 다른 방법과 유사한 결과를 내지만 **−1에서 1로 스케일되어 매우 직관적**이다.

> 다만 미리 경고한다 — 실루엣 점수와 유사 방법들은 유용하지만, **전통적으로 "군집"이라 생각되는 형태를 벗어난 데이터셋에는 최적화되어 있지 않다.**

### 알고리즘별 결과

**k-평균 (k-means)**
- 표본을 **분산이 같은 k개 그룹으로 분리**하려 시도하며, **관성(inertia, 군집 내 제곱합)** 이라는 기준을 최소화한다
- 관성은 k-평균에는 의미가 있지만 몇 가지 단점이 있다. **가장 중요한 단점은 유효한 척도(metric)의 기준을 충족하지 못한다**는 것 → 일반적인 모델 선택에는 최선이 아니다
- **매우 빠르고 사용 사례가 많다**. 모든 데이터셋에서 잘 작동하지는 않지만, **알고리즘이 얼마나 단순한지를 고려하면 오히려 꽤 잘한다**

**계층적 군집화 (hierarchical clustering)**
- **결과를 얻기 전에 군집 개수를 고를 필요가 없다** — 상향식(bottom-up)으로 군집을 연속적으로 융합해 모든 데이터가 하나로 합쳐질 때까지 진행하기 때문
- k-평균처럼 흔히 **유클리드 거리**를 쓴다 (다른 척도도 가능)
- 절차: ① 가장 가까운 두 점을 찾아 군집으로 묶는다 → ② 그 쌍을 하나의 단위로 취급 → ③ 관측치를 계층에 추가해 구조를 세운다
- 결과: **A·B에는 잘하고 C·D에는 어려움을 겪는다**
- **덴드로그램(dendrogram)** 으로 직관적 시각화가 가능하며 **EDA에 유용**하다

**스펙트럼 군집화 (spectral clustering)**
- 여러 방법이 있으나 정본(canonical) 버전은 **라플라시안 행렬(Laplacian matrix)로 데이터를 다른 공간에 투영한 뒤 k-평균을 적용**하는 것
- 첫 단계에서 데이터를 **연결된 점들의 무향 그래프(undirected graph)로 취급**하고 이를 **인접 행렬(adjacency matrix)** 로 표현한다 → 따라서 **그래프에 바로 적용할 수 있다**
- 결과: 오른쪽 플롯(C·D)에 잘한다. 그리고 **군집 개수를 직접 알려주면 4개 플롯 모두에서 꽤 잘한다**
- 평가: **예외적으로 유연한 알고리즘**

**가우시안 혼합 모델 (GMM)** — 여기서는 베이지안 버전
- **확률적 할당**으로 군집을 만든다
- **매우 유연하다** — *"가우시안을 충분히 많이 더하면 어떤 분포든 적합시킬 수 있다"* 는 말이 자주 인용된다
- 군집 알고리즘과 달리 **`predict` 함수를 사용**한다
- **GMM에서는 데이터를 스케일링할 필요가 없다**
- 결과: 예상대로 오른쪽(C·D)에 잘한다
- **k를 명시적으로 설정할 필요가 없는 변형**도 있다 — **디리클레 프로세스 사전분포(Dirichlet process prior)** 를 써서 데이터로부터 k를 결정한다

### 결론 — 두 가지 경고

**k를 추정하게 했을 때의 결과**
- **계층적 군집화가 A에서 완벽하게 수행했는데도 점수는 더 낮았다**
- C·D의 숫자는 예상대로 나왔다
- 하지만 앞의 두 플롯(A·B)에서는 **군집의 모양이 실루엣 값 지표가 기대하는 방식으로 작동하지 않는다**
- **시도한 다른 지표들도 결과가 같았다**

**k를 알고 있다고 가정했을 때**
- **스펙트럼과 계층적 군집화가 A·B 데이터셋에서 완벽했지만, 실루엣 값은 이를 반영하지 못했다**
- C·D에서는 평가 지표가 예상대로 작동했다

> **이 실험이 보여주는 것은, 나머지 전부를 능가하는 단 하나의 군집 방법은 없다는 것, 그리고 평가 지표의 사용에 의존할 때는 주의가 필요하다는 것이다.**

## 요약
- 군집 알고리즘 비교의 방법론은 **형태가 다른 데이터를 시뮬레이션해 시각화하는 것**이다.
- 데이터 형태와 알고리즘 계보가 대응한다 — A·B는 스펙트럼, C·D는 GMM이 유리하다.
- 알고리즘별 요점:
  - **k-평균**: 빠르고 단순하지만 관성은 유효한 척도가 아니다
  - **계층적**: k를 미리 안 정해도 되고 덴드로그램으로 EDA에 좋다
  - **스펙트럼**: 가장 유연하고 **그래프에 바로 적용 가능**
  - **GMM**: 확률적 할당, **스케일링 불필요**, `predict` 사용, 디리클레 사전으로 k 자동 결정 가능
- **두 가지 결론**: ① 모든 것을 이기는 군집 방법은 없다 ② **실루엣 점수가 완벽한 군집화를 낮게 평가하는 경우가 있다** — 지표를 맹신하면 안 된다.
