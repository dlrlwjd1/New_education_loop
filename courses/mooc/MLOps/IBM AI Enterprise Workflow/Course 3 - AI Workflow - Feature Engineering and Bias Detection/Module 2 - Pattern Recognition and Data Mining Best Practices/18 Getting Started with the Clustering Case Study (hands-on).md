# Getting Started with the Clustering Case Study (hands-on)

## 개요
- 형식: 읽기 자료 + 실습 (약 2시간 10분)
- 핵심: AAVAIL 고객 데이터로 군집화를 수행하고, **군집을 새 특징으로 만들어** 예측 성능에 기여하는지 본다.

## 내용

### 준비물
| 파일 | 용도 |
|---|---|
| `Clustering-Case-Study-Local.zip` | 로컬 Jupyter 서버용 데이터와 노트북 |
| `Clustering-Case-Study-WS.zip` | **Watson Studio**용 |

> **중요** — Watson Studio용 zip을 받을 때 파일명이 정확히 `Clustering-Case-Study-WS.zip`인지 확인한다. 브라우저가 자동 생성한 토큰 문자열이 이름 앞에 붙으면 **업로드가 차단된다.** 필요하면 이름을 고친다. Watson Studio용은 **압축을 풀지 않고 그대로 업로드**한다.

필요한 파일:
- `clustering-case-study.ipynb`
- `aavail-target.db`

사례 연구를 마치면 **짧은 퀴즈**가 있다 (→ [20번](20%20CASE%20STUDY%20-%20Clustering%20-%20Check%20for%20Understanding.md)).

> 내용을 노트북의 일부로 검토할 수 있지만, 시작할 준비가 되면 **Watson Studio나 로컬에서 살아 있는 버전으로 작업**하고 있는지 확인하라.

### 참고 — 선행 영상
이 자료는 앞선 영상 *Getting started with Watson Studio*를 언급하며 zip 업로드 방법을 설명한다. 해당 영상은 이 강좌(Course 3)의 커리큘럼에는 포함되어 있지 않고, **전문과정의 앞 강좌에 있는 내용**이다.

## 요약
- 데이터는 `aavail-target.db`, 노트북은 `clustering-case-study.ipynb`.
- Watson Studio용 zip은 **파일명 앞 토큰 문자열을 지워야** 업로드된다.
- 노트북을 읽는 것으로 끝내지 말고 **실행 환경에서 직접 돌려야** 한다.
- 끝나면 짧은 퀴즈가 이어진다.
