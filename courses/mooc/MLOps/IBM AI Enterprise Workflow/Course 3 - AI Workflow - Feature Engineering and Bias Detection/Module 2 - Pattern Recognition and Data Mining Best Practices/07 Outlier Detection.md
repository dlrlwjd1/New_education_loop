# Outlier Detection

## 개요
- 형식: 영상 (약 3분)
- 핵심: 이상치를 **인공적으로 주입해** 탐지 알고리즘의 동작을 확인한다. 그리고 PCA와 t-SNE를 역할별로 나눠 쓴다.

## 내용

### 이 강의의 두 목표
1. 워크플로에서 **여러 이상치 탐지 알고리즘을 편하게 쓸 수 있게** 된다
2. 그렇게 하는 것의 **잠재적 결과를 인지**한다

### 전략 — 이상치를 일부러 넣는다
이상치 탐지의 거동을 이해하기 위해 **데이터셋에 인공적으로 이상치를 추가**해 시연한다. 작업 데이터는 **AAVAIL 고객 유지 데이터 + 시뮬레이션된 이상치**다.

> 정답을 아는 상태를 만들어 놓고 알고리즘이 그것을 찾아내는지 보는 방식이다. 라벨이 없는 이상치 탐지에서 알고리즘을 검증할 수 있는 실용적인 방법이다.

### 이상치 탐지 vs 신규성 탐지 — 정확한 구분

| 알고리즘 범주 | 학습 데이터에 이상치가 | 관심사 |
|---|---|---|
| **신규성 탐지** (novelty detection) | **없다고 가정** | **새 데이터**에서의 이상치 탐지 |
| **이상치 탐지** (outlier detection) | **있다고 가정** | 이미 가진 데이터의 이상치. **학습 후 신규성 탐지에도 쓸 수 있다** |

이 알고리즘들이 자주 등장하는 상황:
- **극단적으로 불균형한 데이터**를 지도 학습 맥락에서 다룰 때
- 모델이 **배포되어 품질 보증(QA) 메커니즘이 구현되어 있을 때**

### 알고리즘별 주의점
| 알고리즘 | 주의점 |
|---|---|
| **Elliptic Envelope** | **고차원에서 깨지거나 성능이 나쁠 수 있다.** 예컨대 N < P (P는 차원 수)인 경우. → **PCA 등으로 먼저 차원을 줄여** 쓸 수 있다 |
| **One Class SVM** | 보통 **RBF(radial basis function) 커널**을 고르지만 **수동 튜닝이 필요하다** |

> 모든 방법은 자기 데이터에 맞게 조정·튜닝해야 한다. **이 때문에 시각화가 기대대로 작동하는지 확인하는 필수적인 방법이 된다.**

### 실습 절차
1. 학습(train)·테스트(test)·이상치(outlier) X 데이터를 담은 데이터프레임을 만든다
2. 그것으로 **PCA 투영과 t-SNE 투영을 각각** 만든다
3. **주의**: train/test를 따로 투영하지 않고 **모든 데이터를 한 번에 투영**한다

또 언급된 실무 팁: **`ColumnTransformer`에서 특징 이름을 얻어내는 것이 까다로울 수 있다** — 강의에서 이 경우의 방법을 보여준다.

### 결과 해석
- **PCA와 t-SNE 임베딩 모두 이상치를 뚜렷하게 다른 것으로 분해**한다
- **t-SNE가 데이터 구조를 더 많이 분해**한 것으로 보인다 (그룹 수가 더 많다)
- 더 구체적으로 라벨링된 플롯으로 조사하면 두 플롯의 여러 그룹의 본질을 이해하는 데 도움이 된다

### PCA와 t-SNE의 역할 분담 — 이 강의의 핵심 실무 지침
이 예제에서는 **PCA 공간에서** 탐지 알고리즘을 학습·평가했다. 다만 **원본 특징 공간이 최선인 경우도 있다.**

> **t-SNE는 시각화에 훌륭하지만, PCA가 더 안정적인(stable) 투영이며 이것이 일관된 임계값(consistent threshold)을 위해 중요하다.**

즉 역할이 갈린다.

| 목적 | 도구 | 이유 |
|---|---|---|
| 사람이 보는 시각화 | **t-SNE** | 구조를 더 잘 드러낸다 |
| 탐지 알고리즘의 입력 | **PCA** | 투영이 안정적이라 임계값이 일관된다 |

t-SNE가 왜 임계값에 부적합한지는 [Module 1의 Dimension Reduction](../Module%201%20-%20Data%20Transforms%20and%20Feature%20Engineering/17%20Dimension%20Reduction.md)에서 나온 성질로 설명된다 — **비용 함수가 비볼록이라 매번 같은 결과가 나오지 않는다.**

### 마무리
> 새 데이터를 예상해 이 알고리즘들을 잘 작동하도록 튜닝하는 일은 **당분간 어려운 데이터 과학 과제로 남을 것**이다. 하지만 여기 제시한 것 같은 워크플로가 **반복 속도를 높여줄 수 있다.**

## 요약
- 이상치를 **일부러 주입**해 알고리즘을 검증하는 것이 이 강의의 방법론이다.
- **신규성 탐지는 학습 데이터가 깨끗하다고 가정**하고, 이상치 탐지는 그렇지 않다고 가정한다.
- Elliptic Envelope은 고차원(N<P)에서 취약하므로 **PCA를 먼저 통과**시킨다. One Class SVM은 RBF 커널을 수동 튜닝해야 한다.
- 투영은 **train/test를 나누지 않고 한 번에** 한다.
- **역할 분담이 핵심**: 시각화는 t-SNE, 탐지 알고리즘 입력은 PCA(안정적 투영 → 일관된 임계값).
