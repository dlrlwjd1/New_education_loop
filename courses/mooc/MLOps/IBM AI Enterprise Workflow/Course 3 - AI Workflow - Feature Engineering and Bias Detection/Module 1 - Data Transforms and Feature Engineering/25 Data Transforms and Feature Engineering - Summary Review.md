# Data Transforms and Feature Engineering - Summary Review

## 개요
- 형식: 읽기 자료 (약 5분)
- 핵심: Module 1 전체 요약. **정확도 식과 정밀도·재현율 식을 나란히 보여주며 왜 정확도가 무용한지 다시 못박는다.**

## 내용

### 시작하기 — 이 단계의 성격
> 데이터 변환 부분은 전체 프로세스에서 **명시적으로 반복(iteration)을 권장하는 첫 지점**이다.

이 단계는 데이터의 가능한 모든 변환을 포함한다 — 차원 축소, 이상치 탐지, 클러스터링, 기타 비지도 학습.

**이 활동들을 하나의 과정으로 묶는 이유**: 적합한 변환을 선택하거나 주어진 변환을 튜닝하는 일이 **모두 같은 형태를 취하기 때문**이다. 그 형태는 scikit-learn의 세 인터페이스와 컨테이너 클래스인 파이프라인 위에 세워진다.

| 인터페이스 | 하는 일 |
|---|---|
| Transformer | 데이터를 한 형식에서 다른 형식으로 변환 |
| Estimator | 모델을 구축하고 적합(fit) |
| Predictor | 예측 수행 |

이 조합의 영향력이 커서 **Apache Spark도 유사한 ML 파이프라인을 갖게 되었다.**

### 클래스 불균형, 데이터 편향
불균형은 흔하다. 특히 **사기 탐지와 고객 유지(customer retention)** 같은 응용에서.

**첫 번째 지침**: 정확도를 지표로 쓰지 마라. 결과가 오해를 낳는다.

```
accuracy = (tp + tn) / (tp + fp + tn + fn)
```

양성 클래스가 전체의 작은 비율이면 **모델이 음성 클래스에 최적화된다.** 진양성을 잡아내는 모델의 능력이 지표에 잘 반영되지 않는다 — 다수 클래스의 영향에 압도되기 때문이다.

정밀도·재현율 기반 지표가 이 문제에 더 특화된다. **TN이 분자에 들어가지 않기 때문**이다.

```
precision = tp / (tp + fp)
recall    = tp / (tp + fn)
```

**샘플링 접근**

| 방향 | 내용 | 대가 |
|---|---|---|
| 언더샘플링 | 다수 클래스에서 무작위로 관측치를 뺀다. 개념적으로 더 단순 | **데이터를 전부 쓰지 않는다** |
| 오버샘플링 | 무작위/단순부터 **SMOTE**, **ADASYN** 등 알고리즘 계열까지 | 변형이 많아 비교가 필요 |

논의한 모든 샘플링 기법은 **`imbalanced-learn`** 파이썬 패키지에 구현되어 있다. 이 패키지의 편리한 점:
- 여러 샘플링 기법을 **파이프라인으로** 구현할 수 있다
- **TensorFlow와 Keras와도 편하게 연동**된다 — 신경망이 일반적으로 불균형에 민감하기 때문에 중요하다

**SVM**은 불균형에 덜 민감한 알고리즘의 예다. 불균형 비율 상황에 맞게 튜닝할 수 있어 **이상치 탐지 도구로도 합리적**이다. (→ Module 2의 OneClassSVM)

### 차원 축소
차원 축소가 필요한 응용 분야: **이미지 분석, 텍스트 분석, 신호 처리, 천문학, 의학.**

세 범주로 논의했다.

| 범주 | 예 |
|---|---|
| 행렬 분해 | **PCA, NMF, SVD** |
| 매니폴드 학습 | **t-SNE 계열** |
| 토픽 모델 | NMF, **LDA** |

토픽 모델 기법은 일반적으로 앞의 두 범주 중 하나에 속하지만, **응용이 NLP**라는 점이 다르다.

PCA의 주된 단점: **비선형·곡면은 잘 설명되지 않는다.** 그 대안이 매니폴드 학습이다.

t-SNE는 토픽 모델 표현을 저차원에서 시각화하는 데 자주 쓰이며, 목적은 **모델 튜닝 + 데이터 통찰**이다. `pyLDAvis`가 그 용도의 패키지다.

### 사례 연구 — 토픽 모델링
> 토픽 모델링은 흔히 쓰이는 차원 축소의 한 형태다. 시각화 도구로 결과를 탐색하는 것은 **도메인과 관련된 특징을 식별하기 위해서**다. 이 통찰은 새 특징으로 변환되어 직접 쓰이거나 특징 행렬에 덧붙여진다.

## 요약
- Module 1의 모든 활동(변환·불균형·차원 축소·이상치·클러스터링)이 한 묶음인 이유는 **선택과 튜닝의 형태가 동일**하기 때문이다. 그 형태가 파이프라인이다.
- 정확도가 실패하는 이유는 식에 **TN이 들어 있어서**다. 정밀도·재현율에는 없다.
- 언더샘플링의 대가는 데이터 손실, 오버샘플링의 대표는 SMOTE·ADASYN, 구현체는 `imbalanced-learn`.
- **신경망은 불균형에 민감하고 SVM은 강하다.** 그래서 SVM은 이상치 탐지로도 쓰인다.
- 차원 축소는 행렬 분해 / 매니폴드 학습 / 토픽 모델. PCA의 약점은 비선형이다.
