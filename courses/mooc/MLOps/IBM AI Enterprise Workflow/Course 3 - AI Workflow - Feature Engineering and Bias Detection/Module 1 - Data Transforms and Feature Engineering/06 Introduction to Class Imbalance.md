# Introduction to Class Imbalance

## 개요
- 형식: 영상 (약 2분)
- 핵심: 클래스 불균형은 단순한 성능 문제가 아니라 **데이터 편향(data bias), 즉 윤리 문제와 직결된다.**

## 내용

### EDA에서 드러나는 문제들
탐색적 데이터 분석(EDA) 과정에서 데이터의 문제가 드러난다. 앞서 결측(missingness)을 다뤘고, 이제 **클래스 불균형**을 다룬다.

### 불균형과 편향은 같은 뿌리
> 불균형 클래스 같은 데이터 문제는 AI의 또 다른 활발한 연구 영역인 **데이터 편향**과 직접 연결된다.

편향된 데이터로 학습된 알고리즘은 매우 현실적인 문제다. 데이터에 **인종·성별 등의 편향**이 있으면 문제는 윤리 문제가 된다.

핵심 문장:

> **머신러닝 알고리즘은 편향에 신경 쓰지 않는다.** 언제나 학습 데이터에서 가장 강한 패턴을 사용해 최선의 판단을 내린다.

따라서 이 알고리즘이 윤리적으로 쓰이도록 보장할 책임은 사람에게 있고, 그것은 **데이터 자체에서 시작한다.**

### 이 레슨이 다루는 것
1. 불균형 클래스를 다루는 가장 흔한 전략 — 오버샘플링(over-sampling)과 언더샘플링(under-sampling)
2. **어떤 알고리즘이 불균형에 영향을 받고, 어떤 알고리즘은 자체적으로 대응하는지**
3. 데이터의 편향을 줄이는 방법

IBM은 이 과제를 겨냥해 설계한 제품(오픈소스 포함)을 여러 개 갖고 있다. 이 레슨에서 시연되는 도구가 그것이다 (→ Module 2의 AI Fairness 360).

## 요약
- 클래스 불균형과 데이터 편향은 "과소 대표된(underrepresented) 부분이 있다"는 같은 구조의 문제다.
- 알고리즘은 편향을 판단하지 않고 가장 강한 패턴을 쓴다. 그래서 책임은 데이터를 만지는 사람에게 있다.
- 대응 수단은 샘플링 전략 + 불균형에 강한 알고리즘 선택 + 편향 완화 도구다.
