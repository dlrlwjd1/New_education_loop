# Sampling Techniques

## 개요
- 형식: 읽기 자료 (약 2분)
- 핵심: 불균형 대응의 가장 흔한 접근은 **재샘플링(re-sampling)** 이다. 업샘플링과 다운샘플링의 알고리즘 계보를 정리한다.

## 내용

### 다운샘플링 (down-sampling / under-sampling)
개념적으로 더 단순하다. 다수 클래스에서 **무작위로 일부를 학습 데이터에서 빼서** 클래스 비율을 맞춘다.

순수 무작위 선택보다 개선된 방법도 있다. 그중 하나는 **K-최근접 이웃(KNN)에서 착안한** 방식이다.

> **중대한 단서(caveat)**: 다운샘플링은 **데이터를 전부 쓰지 않는다.**

### 업샘플링 (up-sampling / over-sampling)
여러 종류가 있고, 무작위·단순 버전부터 알고리즘 계열까지 폭이 넓다.

| 알고리즘 | 설명 |
|---|---|
| 무작위/단순(naive) 오버샘플링 | 소수 클래스를 반복 복제 |
| **SMOTE** (Synthetic Minority Oversampling Technique) | 소수 클래스의 **합성 샘플**을 생성 |
| **ADASYN** (Adaptive Synthetic) | 적응적 합성 샘플링 |
| **SMOTENC** (for Nominal and Continuous) | SMOTE의 확장. **범주형과 연속형 특징이 섞인** 경우를 다루도록 설계 |

SMOTE에는 다른 변형도 여럿 있다. 합성 샘플의 품질을 높이기 위해 **서포트 벡터 머신(SVM)** 이나 **K-평균 군집화(k-means)** 를 활용하는 변형이 있다.

## 요약
- 두 방향이 있다 — 다수를 줄이는 다운샘플링, 소수를 늘리는 업샘플링.
- 다운샘플링은 단순하지만 **데이터를 버린다**는 대가가 있다.
- 업샘플링의 대표는 SMOTE이고, 범주형이 섞였으면 SMOTENC를 본다.
- 어느 쪽이 나은지는 정해져 있지 않다. 다음 강의에서 파이프라인으로 비교한다.
