## 전문과정을 관통하는 요소

- **AAVAiL** — 오디오/비디오 서비스 회사라는 가상 사례. 모든 강좌의 "Through the eyes of our Working Example" 자료가 이 회사 이야기다.
- **디자인 사고(design thinking)** — 공감(Empathize) → 정의(Define) → 아이디어 도출(Ideate) → 프로토타입(Prototype) → 테스트(Test). 각 자료가 해당 작업이 어느 단계에 속하는지 명시한다.
- **플레이백(playback) 회의** — 여러 부서가 모여 진행 상황을 공유하는 자리. 데이터 과학자가 결과를 전달하고 편향 논의를 제기하는 장소로 반복 등장한다.
- **IBM Watson Studio** — 사례 연구 실습 환경.
