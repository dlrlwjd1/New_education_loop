# "Help me reduce the latency and cost of my LLM pipeline." (Graded Assignment)

## 개요
- Module 2 전체(3개 레슨: Managing Context Windows & Prompt Structure, Inference Optimization, Prompt Versioning & Experiment Tracking)를 아우르는 채점 대상 그레이디드 과제(Graded Assignment, 1시간). 학업 정직성 및 AI 사용 모니터링 대상으로 명시됨.

## 내용
- 학업 정직성 모니터링 대상 콘텐츠이므로 문제·보기·정답은 기록하지 않음.
- Module 2에서 다룬 컨텍스트 윈도우 설계, 구조화된 프롬프트, 환각 감소, 지연시간·토큰 비용, 배칭/캐싱/스트리밍, API vs 로컬 모델, 프롬프트 버저닝·델타 추적·통계적 평가 내용을 기반으로 LLM 파이프라인의 지연시간·비용을 줄이는 과제로 추정.

## 요약
- 채점 대상 평가 항목으로 실제 문항 내용은 기록하지 않는다.
