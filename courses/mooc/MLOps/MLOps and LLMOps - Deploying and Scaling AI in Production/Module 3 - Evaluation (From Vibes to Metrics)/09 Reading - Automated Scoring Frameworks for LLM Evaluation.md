# "Automated Scoring Frameworks for LLM Evaluation"

## 개요
- 앞선 3개 영상([06 평가자 프롬프트 설계](06%20Designing%20Evaluator%20Prompts.md), [07 다차원 채점](07%20Scoring%20for%20Consistency%2C%20Relevance%2C%20Correctness.md), [08 자동 채점의 한계](08%20Limits%20of%20Automated%20Scoring.md))를 요약하며 **DAG 구조 평가, 토큰 확률 가중 채점, 쌍대 비교(pairwise) 평가, 포지션 편향**이라는 새로운 개념을 보충하는 리딩(30분).

## 내용

### LLM-as-a-Judge 개요
- 하나의 LLM이 다른 LLM 애플리케이션이 생성한 출력의 품질을 평가하는 방법론 — 대규모 자동 채점을 가능하게 함.
- 명확한 채점 루브릭을 가진 평가 프롬프트를 정의하고, 판정 모델에게 원본 질의·생성된 응답·참조 컨텍스트를 제공한 뒤, 관련성·정확성·충실성(faithfulness)·유용성 같은 차원에 걸쳐 구조화된 점수를 수집.
- 이는 사람 평가의 수동 병목(bottleneck)을 대체하면서, 소규모 샘플이 아니라 **트래픽의 100%**를 커버할 수 있게 함.

### 채점 설계 고급 기법 (새로운 내용)
- **DAG(방향성 비순환 그래프)로 구조화된 평가**: 각 노드가 특정한 원자적(atomic) 판단을 담당하도록 평가를 구조화.
- **토큰 확률 가중 채점(Token Probability-weighted Scoring)**: 거친 이산 척도(coarse discrete scale) 대신 연속적인 지표를 생성.
- **여러 판정 모델을 사용한 교차 검증**.
- **쌍대 평가(Pairwise Evaluation)**: 판정자가 두 응답을 나란히 비교하는 방식 — 절대 채점(absolute scoring)보다 종종 더 신뢰할 수 있는 순위를 만들어냄.

### 알려진 편향 (앞선 영상 내용 보충)
- **포지션 편향(Position Bias)**: 쌍대 비교에서 **첫 번째로 제시된 응답을 선호**하는 경향 — 앞선 영상에서 다루지 않은 새로운 편향 유형.
- **장황함 편향(Verbosity Bias)**: 더 긴 답변을 선호 — 앞선 영상의 "길이 편향"과 동일한 개념.
- **자기 강화 편향(Self-enhancement Bias)**: 동일한 모델 계열의 출력에 더 높은 점수를 주는 경향 — 앞선 영상의 "자기 편향"과 동일한 개념.
- **완화 방법**: 응답 순서를 무작위화, 검증 슬라이스(validation slice)에서 사람 판단에 대해 캘리브레이션, 평가 대상 시스템과 **다른 모델 계열**의 판정자 사용. 신뢰도가 낮거나 플래그된 사례에 대한 인간 참여 검토(human-in-the-loop)는 평가의 무결성을 유지하는 데 여전히 필수적임.

## 예시
```text
[쌍대 평가(Pairwise) vs 절대 채점(Absolute)]
절대 채점: 응답 A → 점수 4/5 (단독 평가, 기준 모호할 수 있음)
쌍대 평가: 응답 A vs 응답 B → "A가 더 낫다" (상대 비교로 더 신뢰할 수 있는 순위)

→ 포지션 편향 방지: A/B 순서를 무작위화하여 반복 비교
```

```text
[새롭게 보충된 편향 3종]
포지션 편향       — 쌍대 비교에서 첫 번째 응답 선호
장황함 편향       — 긴 답변 선호 (= 길이 편향)
자기 강화 편향     — 같은 모델 계열 출력 선호 (= 자기 편향)
```

## 요약
- 이 리딩은 LLM-as-a-Judge가 사람 평가의 병목을 대체해 트래픽 100%를 커버할 수 있게 한다는 점, DAG 구조화·토큰 확률 가중 채점·쌍대 평가 같은 고급 채점 기법이 절대 채점보다 더 신뢰할 수 있는 순위를 만들어낸다는 점, 그리고 포지션 편향(쌍대 비교에서 첫 응답 선호)이라는 새로운 편향 유형과 장황함·자기 강화 편향에 대한 완화책(순서 무작위화, 사람 판단 캘리브레이션, 다른 모델 계열 판정자 사용)을 보충한다.
