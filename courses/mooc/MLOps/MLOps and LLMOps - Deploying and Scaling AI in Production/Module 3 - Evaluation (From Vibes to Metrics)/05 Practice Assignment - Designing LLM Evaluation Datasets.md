# Designing LLM Evaluation Datasets (Practice Assignment)

## 개요
- "Designing LLM Evaluation Datasets" 레슨에 대한 연습 과제(Practice Assignment, 15분).

## 내용
- 학업 정직성 모니터링 대상 콘텐츠이므로 문제·보기·정답은 기록하지 않음.
- 앞선 3개 영상(현실적 평가 데이터 구축, 엣지 케이스 샘플링, 테스트 데이터 편향 방지)과 리딩(평가 데이터셋 블루프린트) 내용을 기반으로 출제된 것으로 추정.

## 요약
- 채점 대상 평가 항목으로 실제 문항 내용은 기록하지 않는다.
