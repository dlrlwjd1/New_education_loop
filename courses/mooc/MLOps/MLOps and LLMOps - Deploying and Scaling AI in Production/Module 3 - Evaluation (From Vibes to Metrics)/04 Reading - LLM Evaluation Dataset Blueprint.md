# "LLM Evaluation Dataset Blueprint"

## 개요
- 앞선 3개 영상([01 현실적 평가 데이터](01%20Constructing%20Realistic%20Evaluation%20Data.md), [02 엣지 케이스 샘플링](02%20Sampling%20Edge%20Cases%20and%20Failure%20Modes.md), [03 테스트 데이터 편향 방지](03%20Avoiding%20Bias%20in%20Test%20Data.md))를 요약하며 **살아있는 평가셋(living evaluation set), 인구통계학적 계층화(demographic stratification), 홀드아웃 코호트** 같은 새로운 개념을 보충하는 리딩(30분).

## 내용

### 현실적인 평가 데이터셋 구축 — 살아있는 평가셋
- 실제 프로덕션 트래픽에서 샘플링해 사용자 질의, 의도 유형, 복잡도 수준의 진짜 분포를 포착해야 함.
- 합성 데이터나 큐레이션된 데이터셋에만 의존하면 사각지대가 생김 — 모델이 깨끗한 테스트 케이스에서는 잘 작동해도 프로덕션에서 마주치는 지저분하고 모호하고 적대적인 입력에서는 실패할 수 있음.
- 모범 사례: 새로운 실패 모드가 발견됨에 따라 계속 성장하는 **살아있는(living) 평가셋**을 유지하고, 일관된 사람 주석을 위해 명확한 루브릭(rubric)으로 정답(ground-truth) 답변을 라벨링할 것.

### 엣지 케이스·실패 모드 샘플링 — 불균형적 커버리지
- 엣지 케이스에는 여러 타당한 해석이 가능한 모호한 질의, 모델이 갖고 있지 않은 정보를 요구하는 질의, 유해한 출력을 유도하도록 설계된 적대적 프롬프트, 예상치 못한 형식이나 언어의 입력이 포함됨.
- 잘 설계된 평가셋은 프로덕션 분포를 그대로 반영하는 대신 이런 **고위험 시나리오에 불균형적으로(disproportionate) 더 많은 커버리지**를 할당함 — 프로덕션 분포를 그대로 반영하면 희귀하지만 중대한 실패가 과소 대표되기 때문. (앞선 영상에서 다룬 "20% 할당"보다 한 걸음 더 나아가, 리스크가 클수록 비율을 더 높일 수 있다는 뉘앙스를 보충.)

### 테스트 데이터 편향 방지 — 인구통계학적 계층화와 홀드아웃 코호트
- 편향을 피하려면 **인구통계학적 계층화(demographic stratification)**, 프로덕션 다양성을 반영하는 **홀드아웃 코호트(holdout cohorts)**, 그리고 LLM이 판정한 라벨을 사람의 스팟 감사(spot audit)로 교차 검증하는 등의 의도적인 전략이 필요.
- 합성 데이터만 사용한 데이터셋은 그룹 간 커버리지를 왜곡시킴 — 실제 사용자 트레이스를 인구통계학적 분할과 함께 섞고 드리프트를 확인하는 것이 필수적.
- 평가 데이터셋을 대표성 격차(representation gap)에 대해 정기적으로 감사하고, 사용자 인구가 진화함에 따라 업데이트하는 것이 평가 파이프라인이 거짓된 확신의 원천이 되는 것을 방지함.

## 예시
```text
[살아있는 평가셋의 순환]
새로운 실패 모드 발견 → 평가셋에 추가 → 루브릭 기반 라벨링
        │
        ▼
평가셋이 계속 성장·갱신 (한 번 만들고 끝이 아님)
```

```text
[편향 방지 보충 전략]
인구통계학적 계층화 + 홀드아웃 코호트
        │
        ▼
LLM 판정 라벨 ←→ 사람의 스팟 감사로 교차 검증
        │
        ▼
정기적인 대표성 격차 감사 → 사용자 인구 변화에 맞춰 갱신
```

## 요약
- 이 리딩은 평가 데이터셋이 한 번 만들고 마는 것이 아니라 새로운 실패 모드를 계속 흡수하는 "살아있는" 것이어야 한다는 점, 고위험 엣지 케이스에는 프로덕션 분포보다 불균형적으로 더 많은 커버리지를 할당해야 한다는 점, 그리고 인구통계학적 계층화와 홀드아웃 코호트, LLM 판정 라벨의 사람 교차 검증을 통해 대표성 격차를 정기적으로 감사해야 평가 파이프라인이 거짓 확신의 원천이 되지 않는다는 점을 보충한다.
