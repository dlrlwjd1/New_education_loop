# "Evaluation Automation Templates Using MLflow/W&B"

## 개요
- 앞선 3개 영상([11 배포 중 평가 트리거](11%20Evaluation%20Triggers%20During%20Deployment.md), [12 품질 게이트](12%20Quality%20Gates%20and%20Release%20Thresholds.md), [13 릴리스 준비 대시보드](13%20Reading%20Evaluation%20Dashboards%20for%20Release%20Readiness.md))를 요약하며 **적대적 테스트 스위트 통과율, 신뢰구간, 슬라이스별 분해**라는 개념을 보충하는 리딩(30분).

## 내용

### 배포 중 평가 트리거 요약
- 배포 중 평가 트리거는 모델 업데이트, 프롬프트 변경, 설정 수정이 프로덕션에 도달하기 전에 자동으로 평가되도록 보장함.
- 트리거는 풀 리퀘스트(병합 전 문제 포착), 스테이징 배포(프로덕션과 유사한 환경에서 검증), 정기 스케줄(시간에 따른 드리프트 탐지)에서 실행되도록 설정 가능.
- 자동화된 평가는 품질 보증을 사후 고려사항에서 코드 통합과 나란히 실행되는 **지속적이고 내장된 프로세스**로 전환함.

### 품질 게이트와 릴리스 임계값 요약 — 적대적 테스트 스위트
- 품질 게이트는 모델이 다음 환경으로 승격되기 전 충족해야 하는 최소 성능 기준을 정의.
- 일반적인 게이트: 평가 지표의 최소 점수(예: 충실성(faithfulness) > 0.85, 관련성 > 0.90), 현재 프로덕션 모델 대비 최대 회귀 한도(예: 어떤 지표도 5% 초과 하락 금지), 그리고 **적대적 테스트 스위트(adversarial test suite)의 통과율** — 앞선 영상에서 명시적으로 다루지 않은 게이트 유형.
- 어떤 게이트든 실패하면 파이프라인이 배포를 차단하고 어떤 테스트가 왜 실패했는지 식별하는 상세 리포트를 생성.

### 릴리스 준비 대시보드 요약 — 신뢰구간과 슬라이스별 분해
- 릴리스 준비를 위한 대시보드 읽기는 개별 임계값 충족 여부만 확인하는 것이 아니라 여러 지표를 맥락 속에서 해석해 전반적인 품질 프로파일을 이해하는 것을 요구함.
- 대시보드는 시간에 따른 지표 트렌드, 서로 다른 질의 유형에 걸친 성능을 보여주는 **슬라이스별 분해(slice-level breakdown)**, 후보 모델과 프로덕션 모델 간의 비교 뷰, 그리고 통계적 유의성을 나타내는 **신뢰구간(confidence interval)**을 표시해야 함 — 이 두 가지는 앞선 영상에서 다루지 않은 새로운 요소.
- 포괄적인 평가 대시보드에 투자하는 팀은 더 빠르고 자신 있는 배포 결정을 내림.

## 예시
```text
[품질 게이트 보충 — 적대적 테스트 스위트]
평가 지표 최소 점수 (충실성 > 0.85, 관련성 > 0.90)
+ 프로덕션 대비 최대 회귀 한도 (어떤 지표도 -5% 초과 금지)
+ 적대적 테스트 스위트 통과율  ← 새로운 게이트 유형
→ 하나라도 실패 시 배포 차단 + 상세 실패 리포트 생성
```

```text
[대시보드 보충 요소]
슬라이스별 분해 — 질의 유형별 성능 차이 확인
신뢰구간       — 관측된 차이가 통계적으로 유의미한지 표시
```

## 요약
- 이 리딩은 배포 중 평가 트리거가 품질 보증을 지속적인 내장 프로세스로 만든다는 점, 품질 게이트에 최소 점수와 회귀 한도뿐 아니라 적대적 테스트 스위트 통과율까지 포함될 수 있다는 점, 그리고 릴리스 준비 대시보드가 단순 임계값 확인을 넘어 슬라이스별 분해와 신뢰구간까지 포함해 전반적인 품질 프로파일을 보여줘야 한다는 점을 보충하며 앞선 3개 영상의 핵심을 재확인한다.
