# "Telemetry Best Practices for Production AI"

## 개요
- 앞선 3개 영상([01 프롬프트·응답·메타데이터 로깅](01%20Logging%20Prompts%2C%20Responses%2C%20and%20Metadata.md), [02 버전 간 실험 비교](02%20Comparing%20Experiments%20Across%20Versions.md), [03 추론 지표 추적](03%20Tracking%20Inference%20Metrics.md))을 요약하는 리딩(30분). 로깅 범위에 대해 앞선 영상과 다소 다른 관점을 제시하는 부분이 있어 주의가 필요함.

## 내용

### 프롬프트·응답·메타데이터 로깅 — 앞선 영상과의 관점 차이
- 모든 LLM 호출에 대해 프롬프트, 응답, 메타데이터를 로깅하는 것이 디버깅·최적화·컴플라이언스에 필요한 텔레메트리 기반을 만듦.
- 이 리딩은 프로덕션 시스템이 **전체 프롬프트(시스템+사용자+컨텍스트), 완전한 모델 응답, 토큰 수, 지연시간, 모델 버전, 프롬프트 버전, 실행 중 이루어진 도구 호출**을 포착해야 한다고 언급 — **주의**: 이는 [01번 영상](01%20Logging%20Prompts%2C%20Responses%2C%20and%20Metadata.md)에서 강조한 "원본 질의 텍스트를 절대 로깅하지 말라"는 프라이버시 우선 원칙과 다소 긴장 관계에 있음. 실제 구현에서는 01번 영상의 PII 마스킹/해싱 원칙을 적용한 뒤에 이런 상세 로깅을 하거나, 조직의 컴플라이언스 정책에 따라 절충해야 함.
- 이런 구조화된 로깅은 개별 상호작용에 대한 사후 분석을 가능하게 하고, 시스템 전체 패턴을 드러내는 집계 대시보드에 힘을 실어줌.

### 버전 간 실험 비교 보충
- 응답 품질 점수, 지연시간 분포, 토큰 사용량, 질의당 비용 같은 지표의 나란한 시각화가 필요.
- MLflow의 실험 추적 UI는 실행을 파라미터별로 그룹화하고 지표 비교를 표시하며, W&B는 인터랙티브 차트, 테이블 비교, 협업 주석을 제공.
- 프롬프트 버전, 모델 버전, 날짜 범위로 실험을 필터링하는 능력이 팀으로 하여금 특정 변경의 영향을 격리하고 어떤 설정을 승격할지 데이터 기반으로 결정하게 함.

### 추론 지표 추적 보충 — LLM 특화 지표
- 프로덕션 추론 지표 추적은 기본적인 지연시간·처리량을 넘어 LLM 특화 지표를 포함해야 함: **초당 토큰 수(tokens per second), 첫 토큰까지의 시간(TTFT), 캐시 히트율, 도구 호출 성공률(tool call success rate), 질의당 비용** — 도구 호출 성공률은 앞선 영상에서 다루지 않은 새로운 지표.
- 이런 지표들은 추론 경로에 최소한의 오버헤드만 추가하는 **경량 계측(lightweight instrumentation)**을 통해 수집되어야 함.
- 이런 지표에 알림 임계값을 설정하면 성능이 저하될 때 팀이 즉시 통보받아 사용자가 크게 영향받기 전에 선제적으로 개입할 수 있음.

## 예시
```text
[LLM 특화 추론 지표 — 보충]
tokens per second     — 초당 토큰 생성 속도
TTFT                   — 첫 토큰까지의 시간
cache hit rate         — 캐시 히트율
tool call success rate — 도구 호출 성공률 (신규)
per-query cost         — 질의당 비용

→ 경량 계측(lightweight instrumentation)으로 수집, 추론 경로에 최소 오버헤드
```

## 요약
- 이 리딩은 전체 프롬프트·응답을 포함한 상세 로깅이 사후 분석과 집계 대시보드를 가능하게 한다고 설명하지만 이는 원본 텍스트를 로깅하지 말라는 [01번 영상](01%20Logging%20Prompts%2C%20Responses%2C%20and%20Metadata.md)의 프라이버시 우선 원칙과 균형을 맞춰 적용해야 하며, MLflow/W&B를 통한 실험 비교와 초당 토큰 수·도구 호출 성공률 같은 LLM 특화 지표를 경량 계측으로 수집해 알림 임계값을 설정하는 것이 프로덕션 AI 텔레메트리의 핵심임을 재확인한다.
