# "Drift Detection Techniques for LLM Applications"

## 개요
- 앞선 3개 영상([11 데이터 드리프트 vs 행동 드리프트](11%20Data%20Drift%20vs%20Behavioral%20Drift.md), [12 드리프트 대시보드·알림](12%20Drift%20Dashboards%20and%20Alerting.md), [13 재학습·파이프라인 업데이트 시점](13%20When%20to%20Retrain%20or%20Update%20the%20Pipeline.md))을 요약하며 **AWS의 3단계 드리프트 대응 프로세스, KS 검정, 개념 드리프트(concept drift), 업스트림 API 모델 업데이트로 인한 행동 드리프트**라는 새로운 개념을 보충하는 리딩(30분).

## 내용

### 데이터 드리프트와 행동 드리프트 — 원인 보충
- 데이터 드리프트는 입력 데이터의 통계적 분포가 변할 때 발생 — 사용자가 모델이 평가받았던 것과 다른 유형의 질문을 하거나 다른 용어를 사용하기 시작할 때.
- 행동 드리프트는 입력이 안정적으로 유지되어도 모델 출력이 변하는 것을 의미하며, 종종 **업스트림 API 모델 업데이트**(예: 사용 중인 외부 LLM 제공업체가 모델을 조용히 업데이트)나 검색 파이프라인 구성 요소의 저하로 인해 발생함 — 앞선 영상에서 명시적으로 다루지 않은 원인.
- 두 유형 모두 사용자 경험에 크게 영향을 미치기 전에 탐지하기 위한 지속적인 모니터링이 필요.

### 드리프트 대시보드·알림 — AWS의 3단계 프로세스
- AWS는 다음 3단계 프로세스를 권장:
  1. 통계적 알림이 트리거되면 **드리프트된 데이터를 샘플링**.
  2. **판정 LLM(judge LLM)**을 사용해 드리프트의 성격을 분류(새로운 주제, 이동된 의도, 증가된 복잡도, 또는 변화된 언어 스타일).
  3. 발견 사항을 조치를 위해 **적절한 팀으로 라우팅**.
- 탐지 기법: 요약 통계 모니터링, 통계적 가설 검정(**KS 검정**, PSI), 그리고 표면적 통계로는 보이지 않는 의미론적 변화(semantic shift)를 포착하는 **임베딩 공간 거리 지표**.

### 재학습·업데이트 시점 결정 — 개념 드리프트와 에스컬레이션 정책
- 재학습이나 파이프라인 업데이트 시점은 탐지된 드리프트의 심각도와 유형에 따라 달라짐.
- **경미한 분포 이동**은 검색 지식 베이스를 업데이트하거나 프롬프트 템플릿을 조정하는 것으로 해결될 수 있음.
- **중대한 개념 드리프트(Concept Drift)** — 입력과 원하는 출력 사이의 관계가 근본적으로 변한 경우 — 는 모델 재학습이나 파인튜닝이 필요함. (새로운 용어: 개념 드리프트는 단순한 분포 이동보다 더 근본적인 변화를 의미.)
- 각 개입 수준에 대한 임계값을 정의하는 명확한 **에스컬레이션 정책**을 수립하면 과잉 반응(불필요한 재학습)과 과소 반응(저하된 성능을 너무 오래 용인하는 것) 모두를 방지함.

## 예시
```text
[AWS 3단계 드리프트 대응 프로세스]
통계적 알림 트리거 → 드리프트된 데이터 샘플링
        │
        ▼
판정 LLM로 드리프트 성격 분류 (새 주제/의도 이동/복잡도 증가/언어 스타일 변화)
        │
        ▼
적절한 팀으로 라우팅하여 조치
```

```text
[드리프트 심각도별 대응]
경미한 분포 이동  → 검색 지식 베이스 업데이트, 프롬프트 템플릿 조정
중대한 개념 드리프트 → 모델 재학습 또는 파인튜닝
(입력-출력 관계 자체가 근본적으로 변한 경우)

→ 명확한 에스컬레이션 정책으로 과잉/과소 반응 방지
```

## 요약
- 이 리딩은 행동 드리프트가 업스트림 API 모델의 조용한 업데이트나 검색 파이프라인 저하에서 비롯될 수 있다는 점, AWS가 권장하는 샘플링→판정 LLM 분류→팀 라우팅이라는 3단계 드리프트 대응 프로세스, KS 검정 같은 통계적 가설 검정과 임베딩 공간 거리 지표라는 탐지 기법, 그리고 경미한 분포 이동과 근본적인 관계 변화인 개념 드리프트를 구분해 각각 다른 개입 수준(업데이트 vs 재학습)과 명확한 에스컬레이션 임계값을 적용해야 한다는 점을 보충한다.
