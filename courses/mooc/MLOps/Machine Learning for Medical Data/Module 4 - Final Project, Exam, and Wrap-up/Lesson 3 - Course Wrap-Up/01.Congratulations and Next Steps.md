# Congratulations and Next Steps (수료 축하 및 다음 단계)

## 개요
- "Machine Learning for Medical Data" 코스 수료를 축하하며 배운 내용을 요약하고 다음 학습 단계를 안내하는 1분 43초 분량 영상/읽기자료 — Module 4 "Lesson 3 - Course Wrap-Up"의 첫 항목

## 내용

### 코스에서 배운 것
- 복잡한 의료 데이터를 분석하고, 숨겨진 패턴을 발견하며, 정확하고 윤리적이며 데이터 기반의 임상적 통찰을 지원하는 머신러닝 방법을 적용하는 법을 배움
- 지도학습 기법으로 질병 결과를 예측하고, 클래스 불균형을 관리하며, 정밀도·재현율·ROC-AUC로 모델을 평가하는 법을 탐구함
- 환자 세분화와 위험 계층화를 위한 비지도 학습, 그리고 신경망이 영상·시계열 데이터에서 예측을 어떻게 향상시키는지도 다룸
- 랩과 응용 사례 연구를 통해 결측값·피처 선택·모델 해석 가능성 같은 실제 데이터 문제를 다루는 법을 연습함 — 각 모듈은 기술적 정확성뿐 아니라 임상적 관련성과 책임감을 강조해, 설계한 모델이 실제 헬스케어 현장의 현실과 부합하도록 함

### 다음 단계
- 이 코스는 전문가들이 AI 도구를 임상 환경에 책임감 있고 효과적으로 통합하도록 돕는 "AI in Healthcare" 스페셜라이제이션의 일부
- 다음 단계로 같은 스페셜라이제이션의 다음 코스인 "AI Technologies in Healthcare"로 학습을 이어갈 것을 권장함
