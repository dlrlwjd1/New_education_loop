# Reading: Course Glossary (코스 용어집)

## 개요
- 코스 전체에서 사용된 핵심 용어를 알파벳순으로 정리한 10분 분량 용어집 — 업계에서 일하거나 사용자 그룹·다른 자격증 프로그램에 참여할 때 이 용어들을 이해하는 것이 중요함

## 내용

### A
- **Accuracy(정확도)**: 전체 예측 중 올바른 예측의 비율을 측정하는 지표 — 데이터가 불균형할 때는 오해를 부를 수 있음
- **Activation function(활성화 함수)**: 뉴런의 출력에 비선형성을 도입해 신경망이 복잡한 패턴을 학습하게 하는 수학 함수
- **Adversarial image(적대적 이미지)**: AI 시스템을 속이도록 조작된 의료 영상 — 오진이나 안전하지 않은 임상 결정으로 이어질 수 있음
- **AI model poisoning(AI 모델 오염)**: 훈련 데이터셋이나 모델 업데이트에 악의적인 데이터를 삽입해 손상된 출력이나 위험한 예측을 유발하는 사이버 공격
- **AI-powered monitoring(AI 기반 모니터링)**: 시계열 모델로 활력징후·검사 결과·바이오마커를 실시간 분석해 패혈증이나 심장 위험 같은 상태에 경고를 발생시키는 환자 진료 시스템
- **Anomaly score(이상 점수)**: 환자나 사건이 동료 집단에 비해 얼마나 특이한지 측정하는 값 — 워크플로에서 잠재적 위험을 표시하는 데 사용
- **Area under the curve, AUC(곡선 아래 면적)**: 모든 임계값에 걸쳐 클래스를 구분하는 모델의 능력을 요약하는 지표 — 값이 높을수록 구분력이 강함
- **Artificial neuron(인공 뉴런)**: 입력을 받아 가중치와 활성화 함수를 적용하고 네트워크 내 다른 뉴런이 사용할 출력을 만드는 계산 단위

### B
- **Backpropagation(역전파)**: 오차 기울기를 계산해 레이어를 거슬러 전파함으로써 네트워크 가중치를 업데이트하는 학습 알고리즘
- **Balanced accuracy(균형 정확도)**: 민감도와 특이도를 평균해 불균형 데이터셋에서 훈련된 모델을 더 공정하게 평가하는 척도
- **Batch normalization(배치 정규화)**: 중간 레이어 출력을 정규화해 훈련을 안정시키고 수렴을 가속하는 기법
- **Bias term(편향 항)**: 각 뉴런에서 활성화 함수를 이동시켜 0을 중심으로 하지 않는 데이터에 모델이 맞도록 돕는 파라미터
- **Brier score(브라이어 점수)**: 예측된 확률의 정확도를 관측된 결과와 비교해 평가하는 지표 — 값이 낮을수록 보정이 좋음

### C
- **Calibration(보정)**: 예측된 확률이 실제 사건 빈도와 일치하는지 평가해 신뢰할 수 있는 임상 예측을 보장하는 과정
- **CDS hooks(임상 의사결정 지원 훅)**: 특정 워크플로 이벤트가 발생할 때 임상 소프트웨어에서 의사결정 지원 조치를 트리거하는 표준
- **Class activation map, CAM(클래스 활성화 지도)**: 모델 예측에 가장 크게 책임 있는 이미지 영역을 강조하는 시각화
- **Class imbalance(클래스 불균형)**: 한 클래스(예: 질병 사례)가 다른 클래스보다 훨씬 드물게 발생하는 상태 — 흔히 편향된 모델로 이어짐
- **Class weighting(클래스 가중치)**: 소수 클래스의 오류에 더 높은 페널티를 부여해 모델이 드물지만 중요한 결과를 효과적으로 학습하게 하는 기법
- **Clinical validation(임상 검증)**: 데이터 기반 패턴이나 클러스터가 임상의에게 실제로 의학적 의미가 있는지 확인하는 과정
- **Clustering(클러스터링)**: 데이터의 자연스러운 그룹을 밝혀내 맞춤 치료와 계획을 지원하는 비지도 학습의 한 종류
- **CNN(합성곱 신경망)**: 합성곱 레이어를 사용해 이미지의 공간적 피처를 탐지하는 딥러닝 모델 — 영상의학과 의료 영상에서 널리 쓰임
- **Confusion matrix(혼동 행렬)**: 진양성·위양성·진음성·위음성을 표로 보여줘 성능 지표를 계산하게 하는 도구
- **Cost-sensitive learning(비용 민감 학습)**: 다양한 오분류에 서로 다른 비용을 부여해 모델의 우선순위를 임상적 위험과 정렬시키는 학습 접근법
- **Counterfactual explanation(반사실적 설명)**: 입력 피처의 작은 변화가 모델 예측을 어떻게 바꿀 수 있는지 보여줘 임상의가 결정 경계를 이해하도록 돕는 기법
- **Cross-validation(교차 검증)**: 데이터를 여러 폴드로 나누어 모델 성능의 일관성을 테스트하고 과적합을 방지하는 검증 절차

### D
- **Data cleaning(데이터 정제)**: 원시 의료 데이터에서 오류·불일치·중복을 제거해 데이터 품질을 높이는 과정
- **Data harmonization(데이터 조화)**: ICD-9를 ICD-10에 매핑하는 것처럼 코드·단위·형식을 표준화해 일관된 데이터 분석을 가능하게 하는 과정
- **Data leakage(데이터 누수)**: 테스트 세트의 정보가 의도치 않게 훈련에 영향을 미쳐 성능 추정치를 부풀리는 모델링 오류
- **Decision curve analysis(의사결정 곡선 분석)**: 다양한 임계값에서 이익과 손해를 저울질해 예측 모델의 임상적 유용성을 측정하는 방법
- **Deep learning(딥러닝)**: 다층 신경망을 사용해 대규모 데이터셋에서 자동으로 표현을 추출하는 머신러닝의 하위 분야
- **DeepLIFT**: 모델의 예측을 네트워크를 거슬러 추적해 각 입력 피처에 기여 점수를 배정하는 방법
- **Dense layer(밀집층)**: 각 뉴런이 이전 레이어의 모든 뉴런과 연결되어 포괄적인 피처 통합을 가능하게 하는 레이어
- **DenseNet(밀집 연결 네트워크)**: 각 레이어를 다른 모든 레이어에 연결해 피처 재사용과 효율적인 기울기 흐름을 촉진하는 CNN 아키텍처
- **Dimensionality reduction(차원 축소)**: 많은 변수를 구조를 보존하면서 더 적은 수의 유의미한 피처나 임베딩으로 변환하는 과정
- **Dropout(드롭아웃)**: 훈련 중 뉴런을 무작위로 비활성화해 과적합을 방지하는 정규화 기법

### E
- **EfficientNet**: 깊이·너비·해상도를 최적으로 확장해 적은 파라미터로 높은 정확도를 달성하는 CNN 아키텍처 계열
- **Electronic health record, EHR(전자의무기록)**: 환자의 종단적 임상 정보를 저장하고 워크플로에 통합된 AI 통찰을 담는 디지털 시스템
- **Encoding(인코딩)**: 범주형 데이터를 숫자 형태로 변환해 알고리즘이 효과적으로 해석·분석하게 하는 과정
- **Epoch(에폭)**: 모델 훈련 중 전체 훈련 데이터셋을 한 번 통과하는 것
- **Explainable artificial intelligence(설명 가능한 AI)**: AI 모델의 추론을 사람이 이해할 수 있도록 투명하게 만드는 방법들 — 임상적 신뢰에 필수적
- **Explained variance ratio(설명된 분산 비율)**: PCA에서 각 주성분이 전체 변동성 중 얼마를 포착하는지 나타내는 척도

### F
- **F1 score(F1 점수)**: 정밀도와 재현율의 조화평균으로, 둘의 균형을 맞춰 전반적인 모델 품질을 평가하는 지표
- **Fairness audit(공정성 감사)**: 모델 성능이 인구통계·임상 하위 그룹에 걸쳐 일관되는지 확인하는 평가 과정
- **Feature attribution(피처 기여도)**: 각 입력 변수가 모델 예측에 얼마나 기여하는지 정량화하는 과정
- **Feature engineering(피처 엔지니어링)**: 원시 데이터를 예측 과제에 임상적 의미를 담은 변수로 변환하는 과정
- **FHIR(Fast Healthcare Interoperability Resources)**: 관찰(observation)과 그룹 같은 임상 데이터를 여러 시스템에 걸쳐 구조화·교환하는 표준
- **Focal loss(포컬 손실)**: 불균형 데이터셋에서 분류하기 어려운 예시를 강조하는 손실 함수 변형

### G
- **Gated recurrent unit, GRU(게이트 순환 유닛)**: 게이트로 정보 흐름을 제어하는 RNN의 변형으로 LSTM을 단순화한 형태
- **Gradient(기울기)**: 훈련 중 가중치 업데이트의 방향과 크기를 나타내는 편미분 벡터
- **Grad-CAM(gradient-weighted class activation mapping)**: CNN 레이어로 흐르는 기울기를 사용해 이미지에서 중요한 영역을 강조하는 히트맵을 만드는 시각적 설명 방법
- **Grad-CAM++**: 한 스캔에서 여러 개의 작은 피처를 더 잘 포착하는 Grad-CAM의 향상된 버전

### H
- **Handling missing data(결측 데이터 처리)**: 대체(imputation)나 제외 기법을 사용해 불완전한 임상 기록을 유효성을 유지하며 관리하는 과정
- **HIPAA(Health Insurance Portability and Accountability Act)**: 환자 건강 정보를 보호하고 의료 데이터 취급의 프라이버시를 보장하는 미국 법률
- **Hidden layer(은닉층)**: 입력층과 출력층 사이에서 중간 표현을 학습하는 뉴런 레이어
- **Hierarchical clustering(계층적 클러스터링)**: 관계의 트리를 구축해 넓거나 세밀한 그룹을 만드는 클러스터링 방법

### I
- **Imputation(대체)**: 다른 피처에서 유도한 통계적 또는 모델 기반 추정치로 결측 데이터 값을 채우는 방법
- **Integrated gradients(적분 기울기)**: 베이스라인 입력에서 실제 입력까지 중요도 점수를 누적해 안정적인 설명을 만드는 기여도 방법

### K
- **K-means clustering(K-평균 클러스터링)**: 중심점(centroid)까지의 거리를 기준으로 사용자가 정한 수의 클러스터에 레코드를 배정하는 클러스터링 방법

### L
- **Layer-wise relevance propagation, LRP(레이어별 관련성 전파)**: 모델 출력을 네트워크를 거슬러 추적해 각 입력이 결과에 미친 영향을 판단하는 방법
- **Learning rate(학습률)**: 훈련 중 각 반복 후 가중치가 얼마나 업데이트되는지 제어하는 하이퍼파라미터
- **LOINC(Logical Observation Identifiers Names and Codes)**: 검사와 임상 관찰을 식별하는 표준화된 코딩 시스템
- **LSTM(Long Short-Term Memory)**: 메모리 셀과 게이트를 사용해 순차 데이터의 장기 의존성을 유지하는 RNN의 한 종류
- **Loss function(손실 함수)**: 예측값과 실제값의 차이를 정량화해 모델 최적화를 이끄는 수학 함수

### M
- **MCAR/MAR/MNAR**: 결측 데이터의 유형 — 완전 무작위 결측, 무작위 결측, 비무작위 결측 — 각각 다른 처리 전략이 필요함
- **Minimum distance(최소 거리)**: UMAP 임베딩 내에서 점들이 얼마나 촘촘히 모이는지 제어해 클러스터 조밀도를 형성하는 설정

### O
- **One-hot encoding(원-핫 인코딩)**: 범주형 변수를 이진 벡터로 표현해 기계가 읽을 수 있게 만드는 기법
- **Outlier detection(이상치 탐지)**: 분석이나 모델 훈련을 왜곡할 수 있는, 표준과 크게 다른 데이터 포인트를 식별하는 과정
- **Overfitting(과적합)**: 모델이 훈련 데이터를 너무 구체적으로 학습해 새 데이터에서 성능이 떨어지는 상황

### P
- **Patient cohort(환자 코호트)**: 추적·대시보드·표적 조치에 사용되는(흔히 클러스터 기반의) 정의된 환자 그룹
- **Pooling layer(풀링층)**: 피처를 집계해 공간 차원을 줄임으로써 효율성과 불변성을 개선하는 CNN 레이어
- **Precision(정밀도)**: 양성으로 예측된 사례 중 실제로 양성인 비율을 측정하는 지표 — 경고의 정확성을 반영
- **Precision-recall curve(정밀도-재현율 곡선)**: 다양한 분류 임계값에 걸친 정밀도와 재현율의 트레이드오프를 보여주는 시각화
- **Preprocessing(전처리)**: 정제·정규화·인코딩·검증을 포함해 원시 데이터를 모델링용으로 준비하는 포괄적 과정
- **PCA(주성분분석)**: 상관된 변수를 최대 분산을 포착하는 주성분으로 변환해 데이터셋 차원을 줄이는 통계 기법
- **Privacy protection(프라이버시 보호)**: 비식별화와 안전한 데이터 취급 관행을 통해 프라이버시 법규 준수를 보장하는 원칙

### R
- **Recall/Sensitivity(재현율/민감도)**: 모델이 실제 양성 사례를 얼마나 올바르게 식별하는지 측정하는 지표
- **ROC(Receiver operating characteristic)**: 재현율(진양성률)을 위양성률에 대해 그려 모델의 구분 능력을 보여주는 곡선
- **ReLU(Rectified Linear Unit)**: 음수 입력에는 0을, 양수 입력에는 입력값 자체를 출력하는 활성화 함수 — 속도와 단순성으로 널리 사용됨
- **RNN(순환 신경망)**: 시간 단계에 걸쳐 정보를 전달함으로써 순차 데이터를 처리하도록 설계된 신경망
- **Regularization(정규화)**: 드롭아웃·가중치 감쇠 같이 모델 복잡도를 제한해 과적합을 방지하는 기법들의 집합
- **ResNet(잔차 네트워크)**: 레이어를 건너뛰는 단축 연결(shortcut connection)을 추가해 매우 깊은 네트워크를 효율적으로 훈련시키는 CNN 아키텍처

### S
- **Saliency map(현저성 지도)**: 입력 이미지의 어느 부분이 모델 예측에 가장 큰 영향을 미치는지 보여주는 시각화
- **Sampling(샘플링)**: 소수 예시를 늘리거나 다수 예시를 줄여 데이터셋 균형을 재조정하는 기법들
- **Self-supervised learning(자기지도 학습)**: 라벨 없는 데이터로 유사 라벨이나 사전학습 과제를 만들어 유용한 표현을 학습하는 훈련 접근법
- **SHAP(SHapley Additive exPlanations)**: 게임 이론에 기반해 각 입력 피처에 예측 기여값을 배정하는 피처 기여도 방법
- **Sigmoid function(시그모이드 함수)**: 입력을 0과 1 사이 범위로 매핑하는 활성화 함수 — 흔히 이진 분류에 사용
- **Silhouette score(실루엣 점수)**: 한 항목이 다른 클러스터에 비해 자신의 클러스터와 얼마나 유사한지 평가하는 지표
- **SmoothGrad**: 약간 교란된 입력들로부터 기울기를 평균화해 현저성 지도의 노이즈를 줄이는 방법
- **SMOTE(Synthetic Minority Oversampling Technique)**: 기존 예시들 사이를 보간해 합성 소수 클래스 샘플을 생성하는 방법
- **SNOMED CT**: 의무기록에서 질환·시술·소견을 인코딩하는 표준화된 의학 용어 체계
- **Softmax function(소프트맥스 함수)**: 원시 점수를 여러 클래스에 걸친 확률로 변환하는 활성화 함수
- **Spiculation(간유리음영/침상 패턴)**: 병변의 가장자리가 뾰족한 방사선학적 패턴 — 흔히 악성과 연관됨
- **Stability test(안정성 테스트)**: 입력이 약간 수정되었을 때 모델 설명이 일관되게 유지되는지 확인하는 검증 절차
- **Stratified sampling(층화 추출)**: 각 클래스의 비례 대표성을 유지하면서 데이터를 훈련·테스트 세트로 나누는 과정
- **Streaming pipeline(스트리밍 파이프라인)**: 현장 진료 의사결정을 위해 거의 실시간으로 통찰을 갱신하는 데이터 파이프라인
- **Supervised learning(지도 학습)**: 라벨링된 데이터로 모델을 훈련해 알려진 결과를 예측하는 머신러닝 접근법
- **Synthetic data(합성 데이터)**: 실제 환자 기록을 모방해 프라이버시를 침해하지 않고 연구를 지원하는 인위적으로 생성된 데이터

### T
- **Temporal validation(시간적 검증)**: 이후 시점 데이터로 모델 성능을 테스트해 실제 배포를 시뮬레이션하는 검증 방법
- **TCAV(Testing with Concept Activation Vectors)**: 사람이 정의한 개념이 모델의 결정에 얼마나 영향을 미치는지 측정하는 개념 기반 방법
- **Threshold selection(임계값 선택)**: 임상 목표에 따라 민감도와 특이도의 균형을 맞추는 컷오프 확률을 결정하는 과정
- **Tomek links(토멕 링크)**: 겹치는 클래스에서 경계에 있는 샘플을 제거해 결정 경계를 명확히 하는 데이터 정제 방법
- **Transfer learning(전이 학습)**: 한 과제에서 사전학습된 모델의 지식을 제한된 데이터를 가진 새 과제의 성능 개선에 적용하는 과정

### U
- **U-Net**: 의료 과제에서 정밀한 이미지 분할을 위해 U자형 인코더-디코더 구조를 사용하는 CNN 아키텍처
- **UMAP(Uniform Manifold Approximation and Projection)**: 지역적·전역적 구조의 균형을 맞춰 확장 가능한 시각화와 임베딩을 만드는 기법

### V
- **Validation set(검증 세트)**: 훈련 중 모델 파라미터를 조정하고 성능을 평가하는 데 사용되는 데이터의 일부

### W
- **Weight decay(가중치 감쇠)**: 큰 가중치에 페널티를 더해 더 단순한 모델을 유도하는 정규화 방법
- **Workflow placement(워크플로 배치)**: 경고 대 문제 목록처럼 통찰을 EHR의 올바른 위치와 시점에 배치하는 설계 원칙

### Z
- **Z-score standardization(Z-점수 표준화)**: PCA나 클러스터링 이전에 피처를 비교 가능한 범위로 조정하는 전처리 단계
