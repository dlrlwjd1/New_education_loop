# Course Wrap-up (코스 마무리)

## 개요
- 코스 전체(Module 1~3)를 되돌아보며 배운 내용을 정리하는 3분 49초 분량 영상 — Module 4 "Lesson 2 - Glossary and Final Exam"의 첫 영상

## 내용

### Module 1 되짚기 — Supervised Learning in Healthcare
- 머신러닝이 환자 데이터를 알려진 결과와 연결해 질병 위험이나 치료 반응을 예측하는 모델을 만드는 법을 다룸
- 헬스케어 데이터를 정제·전처리하고, 결측값을 처리하고, 실제 임상 패턴을 나타내는 의미 있는 피처를 설계하는 법을 배움
- 정밀도·재현율·ROC 곡선 같은 평가 지표가 헬스케어 환경에서 모델의 정확도와 안전성 균형을 어떻게 반영하는지 탐구함 — 지도학습 모델이 조기 질병 탐지를 지원하고, 진단을 개선하며, 임상의가 더 정보에 기반한 결정을 내리도록 돕는 사례들을 살펴봄

### Module 2 되짚기 — Unsupervised Learning for Medical Data
- 클러스터링 알고리즘이 공유된 증상·검사 결과·위험 프로필에 따라 환자를 그룹화해 맞춤 치료와 연구를 이끄는 패턴을 식별하는 법을 배움
- PCA를 이용한 차원 축소가 노이즈를 줄이고, 지배적인 요인을 강조하며, 시각적 패턴을 더 쉽게 해석하게 돕는 법을 살펴봄
- 이런 통찰을 실제 임상 의사결정과 연결해, 비지도 모델이 복잡한 데이터를 조직하고 숨겨진 트렌드를 드러내며 데이터 기반 발견으로 의사의 직관을 보완하는 방식을 확인함
- 비지도 학습 결과를 EHR 시스템에 통합해 모델을 실제 임상 워크플로와 연결하는 법도 배움 — 이런 통합 덕분에 클러스터링 통찰이 대시보드에 직접 나타나 임상의가 새로 떠오르는 트렌드에 더 빠르게 대응할 수 있음

### Module 3 되짚기 — Neural Networks for Healthcare Applications
- CNN이 스캔에서 이상 소견을 탐지해 영상의학을 향상시키는 방법과, 순환 모델이 환자 타임라인과 활력징후를 시간에 따라 해석하는 방법을 배움
- Grad-CAM, 현저성 지도, 피처 기여도(feature attribution) 같은 설명 가능한 AI 기법을 탐구해 모델이 무엇에 집중하는지 드러냄 — 이런 도구들은 계산과 임상적 신뢰 사이의 간극을 메워, AI 결정이 투명하고 검증 가능하며 헬스케어에서 안전하게 사용될 수 있도록 보장함

### 지금까지의 여정
- 이제 기말 프로젝트에서 이 기법들을 적용해 실제 헬스케어 데이터로 예측 모델을 구축·테스트해봄 — 전체 ML 워크플로를 연습하고 결과를 임상적 관련성 측면에서 검증하는 법을 익힘
- 동료 프로젝트도 검토하며 새로운 관점과 통찰을 얻음
- 헬스케어 데이터를 책임감 있게 준비·모델링·해석해 알고리즘을 임상적 동반자로 전환하는 법을 배웠으며, 이제 AI 기반 헬스케어의 다음 물결을 혁신하고 협업하고 이끌어갈 차례임
