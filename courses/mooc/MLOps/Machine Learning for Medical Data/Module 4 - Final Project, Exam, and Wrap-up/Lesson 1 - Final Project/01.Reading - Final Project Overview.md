# Reading: Final Project Overview (기말 프로젝트 개요)

## 개요
- 학습 목표: 산모 건강 위험(maternal health risk) 예측을 위한 머신러닝 모델을 구축·평가해 조기 개입을 지원하는 3분 분량 읽기자료 — Module 4 "Lesson 1 - Final Project"의 첫 항목

## 내용

### 프로젝트 시나리오 — AI로 산모 건강 위험 예측하기
- 준도시·농촌 지역사회를 대상으로 하는 지역 의료 네트워크의 임상 데이터 과학자라고 가정함 — 산부인과가 고위험 임신을 충분히 일찍 발견하지 못해 합병증이 발생하기 전까지 많은 사례가 감지되지 않는 문제를 겪고 있음
- 병원 경영진은 AI 기반 산모 건강 위험 예측 시스템을 시범 운영하기로 결정함 — 목표는 혈압·심박수·체온·혈당 같은 일상적으로 수집되는 임상 지표를 사용해 산모 건강 위험 수준을 예측·평가하는 머신러닝 모델을 개발하는 것

### 데이터셋 소개
- Maternal Health Risk Dataset — 방글라데시 농촌 클리닉·병원에서 IoT 기반 모니터링 시스템을 통해 수집된 실제 데이터셋, UCI Machine Learning Repository에 공개되어 저자원 의료 환경에서의 산모 위험 분류 연구에 흔히 사용됨
- **피처**: Age(나이), SystolicBP(수축기 혈압), DiastolicBP(이완기 혈압), BS(혈당 수치), BodyTemp(체온, °F), HeartRate(분당 심박수)
- **타깃**: RiskLevel — 이진 분류(1=고위험, 0=저위험)
- 이 프로젝트에서는 수정된 버전인 `Maternal_Health_Risk_Data_Set_Modified.csv`를 사용함

### 수행할 작업
Python·Jupyter Notebook(Google Colab)·Gradio를 사용해 데이터 처리부터 모델 배포까지 전체 워크플로를 완성함:
1. **데이터셋 준비 및 정제**: 데이터를 로드·정제하고 결측값을 처리한 뒤 모델링을 위해 정규화
2. **지도학습 기반 환자 위험 점수 모델 구축·평가**: 지도학습 모델을 훈련해 환자 위험을 예측하고, 성능을 평가하고, 훈련된 모델을 저장
3. **밀집 신경망 모델 개발·평가**: 같은 예측 과제를 위한 밀집 신경망을 구축·훈련하고 모델을 저장
4. **Gradio 기반 웹 애플리케이션 제작·테스트**: 의사가 환자 데이터를 입력해 즉각적인 위험 예측을 받을 수 있는 웹 앱 제작

### 제출물과 동료 평가 절차
- 코드 출력 스크린샷을 담은 문서를 작성해 제출함(템플릿 제공)
- 이후 동료 제출물 2건을 간단한 루브릭으로 검토하고, 자신의 제출물에 대한 건설적 피드백을 받으며, 참고 해답(reference solution)과 자신의 문서를 비교해 추가 통찰을 얻음
- 예상 소요 시간: 45~60분
