# Reading: Module Summary: Neural Networks for Healthcare Applications (모듈 요약: 헬스케어 응용을 위한 신경망)

## 개요
- Module 3 전체를 정리하는 2분 분량의 요약 읽기자료 — 딥러닝이 임상 결과 예측부터 복잡한 의료 영상 해석까지 현대 헬스케어 AI를 어떻게 구동하는지 되짚음

## 내용

### 신경 지능의 토대 세우기
- 신경망이 원시 의료 데이터를 예측으로 전환하는 방식을 배움 — 각 뉴런은 가중치가 부여된 입력을 처리하고 ReLU나 시그모이드 같은 활성화 함수를 적용하며, 레이어를 거치면서 점점 더 복잡한 관계를 학습함
- 밀집층(dense layer)은 구조화된 EHR 데이터를, 합성곱층(convolutional layer)은 의료 영상을, 순환 유닛(recurrent unit)은 시간 기반 시퀀스를 처리함
- 학습률 조정이나 드롭아웃·가중치 감쇠 같은 정규화 기법 같은 최적화 기법이 과적합을 방지해 모델이 실제 환자에게 잘 일반화되도록 도움

### 합성곱 신경망의 시선으로 보기
- CNN이 픽셀 데이터로부터 직접 학습해 영상의학을 어떻게 혁신하는지 탐구함 — 합성곱과 풀링 레이어를 거치며 CNN은 단순한 가장자리부터 완전한 질병 패턴까지 피처를 탐지함
- CNN은 X-ray·MRI·CT 전반에서 진단 정확도를 높여 더 빠른 중증도 분류와 종양·병변의 정밀한 분할을 가능하게 함
- ResNet·DenseNet·EfficientNet 같은 고급 아키텍처는 여러 영상 양식에 걸쳐 미묘한 진단 단서를 포착하고, U-Net과 3D CNN은 분할과 볼륨 영상에 특화되어 실제 병원 환경에 적응 가능한 확장 가능하고 고성능인 모델을 보장함

### 불투명함에서 통찰로 — 설명 가능하고 신뢰할 수 있는 AI
- 의료 영상에서 딥러닝 모델은 높은 정확도를 제공하지만 임상의의 신뢰도 얻어야 함
- 현저성 지도(saliency map), Grad-CAM(Gradient-Weighted Class Activation Mapping), SHAP(SHapley Additive exPlanations), TCAV(Testing with Concept Activation Vectors) 같은 설명 가능한 AI 기법이 모델의 결정에 무엇이 영향을 미치는지 드러냄 — 예를 들어 흉부 X-ray에서 폐렴 예측을 이끄는 영역을 강조 표시함
- 보정(calibration), 공정성 점검, 지속적 모니터링과 결합되면 이런 도구들은 딥러닝을 블랙박스에서 신뢰할 수 있는 임상 파트너로 전환함

### 이 모듈에서 얻은 핵심 역량
- 신경망이 의료·임상 데이터를 처리하는 방식에 대한 탄탄한 이해
- CNN·RNN, 그리고 LSTM·GRU 같은 고급 아키텍처를 다양한 헬스케어 문제에 적용하는 능력
- 견고하고 일반화 가능한 모델을 만들기 위한 최적화·정규화 기법에 대한 지식
- AI 시스템의 신뢰와 투명성을 높이는 설명 가능성 도구(Grad-CAM, SHAP, TCAV)에 대한 인식
- 딥러닝 모델을 실제 임상 워크플로에서 평가·검증·통합할 자신감
