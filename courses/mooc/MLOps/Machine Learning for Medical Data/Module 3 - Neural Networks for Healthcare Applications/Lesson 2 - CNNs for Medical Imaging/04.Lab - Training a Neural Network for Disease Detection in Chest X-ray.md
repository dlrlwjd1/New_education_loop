# Lab: Training a Neural Network for Disease Detection in Chest X-ray (흉부 X-ray 질병 탐지 신경망 훈련 실습)

## 개요
- MedMNIST의 ChestMNIST 데이터셋으로 흉부 X-ray 이미지를 분석하는 30분 분량 핸즈온 랩 — 완전 연결 신경망을 구축·훈련해 이미지 한 장에서 여러 흉부 질환을 동시에 탐지함
- 다중 라벨 분류(multi-label classification)가 공존하는 질환을 식별하는 데 어떻게 도움이 되는지 탐구하고, 임상적으로 의미 있는 지표로 모델 성능을 평가함

### 랩 접근 방법
