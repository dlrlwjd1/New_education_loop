# Advanced CNN Architectures for Medical Tasks (의료 과제를 위한 고급 CNN 아키텍처)

## 개요
- 헬스케어에서 사용되는 현대적 CNN 아키텍처들을 식별하고, 아키텍처 설계가 진단 성능에 미치는 영향을 설명하며, 사용 사례와 계산 효율성에 따라 CNN 변형들을 구분하는 5분 47초 분량 영상 — Module 3 "Lesson 2 - CNNs for Medical Imaging"의 두 번째 영상
- 현대 임상 영상은 사람 눈으로는 놓치기 쉬운 미묘하고 복잡한 패턴을 탐지해야 하는 과제에 직면해 있으며, 영상 장비 간 높은 변동성·클래스 불균형·진단 정밀도 요구가 이를 더 어렵게 만듦 — 고급 CNN은 효율성과 설명 가능성을 유지하면서 풍부한 다중 스케일 피처를 추출할 수 있는 강력한 도구로 부상함

## 내용

### 왜 아키텍처 선택이 중요한가
- 의료 데이터셋은 흔히 미세한 진단 단서, 상당한 클래스 불균형, 영상 장비 간 변동성을 포함함 — 현대 CNN은 깊은 표현력, 효율적인 파라미터 사용, 견고한 일반화를 통해 이런 복잡성을 다루어, 여러 병원·스캐너에 걸쳐 미묘한 병리를 신뢰성 있게 탐지하고 다중 클래스 분류를 정확히 수행함

### 깊은 아키텍처 — ResNet과 DenseNet
- **ResNet**: 레이어 간 정보를 전달하는 스킵 연결(skip connection)을 도입해 깊은 네트워크를 안정시키고, 기울기 소실(vanishing gradient)을 방지하며, 미세한 세부사항에 대한 피처 학습을 강화함 — 예: ResNet-50은 얕은 모델이 놓치기 쉬운 가장자리·질감 단서를 보존해 흉부 X-ray에서 희미한 폐결절을 식별할 수 있음
- **DenseNet**: 모든 레이어를 이후의 모든 레이어에 연결해 피처 재사용과 효율적인 기울기 흐름을 촉진함 — 이 구조는 파라미터를 줄이고 라벨링된 데이터가 제한적일 때 학습을 개선함. 흉부 X-ray 분류에서는 여러 진단 범주에 걸쳐 중간 피처를 재사용함으로써 흉막 삼출과 무기폐(atelectasis) 같은 동시 발생 소견을 포착함

### 스케일에 대응하는 아키텍처 — Inception과 EfficientNet
- **Inception**: 여러 커널 크기를 결합해 미세석회화(microcalcification)와 큰 종괴를 모두 탐지함
- **EfficientNet**: 깊이·너비·해상도를 균형 있게 확장해 계산 제약 하에서도 강력한 성능을 달성함 — 소형 클리닉이나 휴대용 기기의 초음파 중증도 분류 시스템 배포에 이상적임

### 픽셀 단위 정밀도 — U-Net 계열
- 픽셀 수준의 정밀도가 중요할 때는 U-Net과 그 변형(Attention U-Net, U-Net++)이 분할(segmentation)에서 탁월함 — 인코더-디코더 구조와 스킵 연결을 통해 종양·장기·혈관을 정확하게 구획화함
- 예: 3D U-Net이 CT 볼륨에서 간 병변을 분할해 치료 계획을 지원할 수 있음

### 볼륨·시간 데이터 처리
- 3D CNN은 MRI·CT의 여러 슬라이스에 걸친 공간 패턴을 학습하고, 2.5D CNN은 맥락과 메모리 효율성의 균형을 맞춤
- 심장초음파 같은 시계열 데이터에는 시공간(spatiotemporal) CNN이 움직임 패턴을 포착해 박출률(ejection fraction)을 추정하거나 내시경 영상에서 출혈을 탐지함

### 컴퓨팅 자원이 제한적일 때 — MobileNet과 ShuffleNet
- MobileNet과 ShuffleNet은 깊이별 분리 합성곱(depth-wise separable convolution)을 사용해 계산·메모리 비용을 크게 줄임 — 휴대용 초음파 기기에서 실시간 추론을 가능하게 해 프라이버시를 유지하고 응급 진료의 지연을 줄임

### 주의 메커니즘과 설명 가능성
- 스퀴즈-앤-익사이테이션(squeeze-and-excitation), 합성곱 블록 주의(convolutional block attention) 같은 주의(attention) 메커니즘은 임상적으로 관련 있는 영역을 강조함 — ResNet이나 DenseNet에 추가하면 당뇨병성 망막병증 같은 질환의 조기 발견에서 희미한 병변에 대한 민감도를 높임
- 효과적인 아키텍처 선택은 적절한 훈련 전략과 짝을 이뤄야 함: 전이 학습(transfer learning)은 대규모 자연 이미지 데이터셋에서 네트워크 가중치를 초기화하고, 라벨 없는 의료 스캔에 대한 자기지도 사전훈련(self-supervised pre-training)은 도메인 특화 피처를 추출하며, 생성형 AI 기법은 희귀 진단 범주를 합성 변형으로 증강함 — 이런 전략들이 함께 작동해 CNN이 서로 다른 스캐너에 걸쳐 일반화하고, 주석 작업 부담을 줄이며, 임상 정확도를 보존하도록 함
- Grad-CAM(gradient-weighted class activation mapping) 같은 해석 가능성 도구는 어떤 이미지 영역이 예측에 영향을 미쳤는지 시각화함 — 예: 폐렴 탐지 시 Grad-CAM은 음영 구역을 강조해 모델의 추론을 방사선 전문의의 기대와 정렬시킴

## 요약
- 현대 CNN 아키텍처는 의료 데이터의 요구에 맞춰 발전함 — ResNet은 세부사항에 대한 깊은 학습을 안정시키고, DenseNet은 데이터 효율성과 다중 라벨 작업을 위한 피처 재사용을 촉진하며, Inception·EfficientNet은 스케일과 자원 제약을 다루고, U-Net 계열은 해부학적 구조를 분할함
- 3D 및 주의 메커니즘이 강화된 CNN은 임상 워크플로에서 볼륨·시간적·미묘한 병리 문제를 지원하며, 전이 학습·자기지도 학습·Grad-CAM 같은 해석 가능성 도구가 실제 배포를 뒷받침함
