# Convolutional Neural Networks for Radiology (영상의학을 위한 합성곱 신경망)

## 개요
- CNN(convolutional neural network)이 X-ray·MRI·CT 같은 방사선 영상에 어떻게 적용되는지, 질병 분류와 진단 정확도를 어떻게 향상시키는지 다루는 5분 11초 분량 영상 — Module 3 "Lesson 2 - CNNs for Medical Imaging"의 첫 영상
- 영상의학은 숙련된 방사선 전문의도 놓칠 수 있는 미묘한 패턴으로 가득한 방대한 영상 데이터를 생성하는데, CNN은 이런 숨겨진 패턴을 드러내 유용한 임상적 통찰로 바꿔줌

## 내용

### CNN이 의료 영상을 해석하는 방식
- 큰 포스터를 작은 돋보기로 구역별로 살펴보는 것을 상상해보면 — CNN이 하는 일이 정확히 이것으로, 필터(filter)를 이미지 위에 슬라이딩시켜 한 번에 작은 구역씩 살펴봄
- 이미지는 여러 레이어를 통과하며, 레이어마다 CNN은 더 복잡한 것을 인식하도록 학습함 — 초기 레이어는 단순한 가장자리와 선을 탐지하고, 중간 레이어는 선들이 모여 형태와 질감을 이루며, 깊은 레이어는 갈비뼈·신장·폐야(lung field) 같은 해부학적 구조를 식별하기 시작하고, 가장 깊은 레이어는 종양이나 골절 같은 완전한 질병 패턴을 인식함
- 각 레이어 안에서는 처리 효율을 유지하기 위해 풀링(pooling)이 일어남 — 합성곱이 세부사항을 포착한 뒤, 풀링은 핵심 피처를 유지하고 나머지를 버리며 이미지 표현의 크기를 줄임. 즉 CNN은 이미지를 단순 암기하는 게 아니라 진단에 무엇이 중요한지를 학습함

### 질병 분류와 진단 정확도 향상 사례
- **흉부 X-ray**: 폐렴이나 흉막 삼출(pleural effusion) 같은 질환을 표시하는 데 CNN을 사용할 수 있음 — 일부 연구에서 CNN 모델이 높은 특이도를 유지하면서 민감도를 약 75%에서 88%로 개선했으며, 이는 응급 상황에서 놓치는 중대 사례를 줄이고 검토 시간을 몇 시간에서 몇 분으로 단축시켜 더 빠른 중증도 분류(triage)를 가능하게 함
- **뇌 MRI**: T1·T2·FLAIR(fluid-attenuated inversion recovery, 유체감쇠역전회복법) 등 서로 다른 조직 특성을 강조하는 시퀀스에 걸쳐 CNN이 종양 영역을 분할(segment)할 수 있음 — 이 분할을 통해 임상의는 종양 부피를 정확히 계산하고 시간에 따른 변화를 추적할 수 있음
- **CT 스캔**: 수동 검토로는 놓칠 수 있는 미묘한 출혈처럼 생명을 위협하는 소견을 탐지하는 데 CNN을 사용할 수 있음 — 고급 CNN은 전체 스캔 볼륨을 처리해 진단 정확도를 높이고 진단 시간을 단축함

### 임상 워크플로에 CNN을 안전하게 구현하는 법
- **1단계 — 의료 영상 전처리**: 이미지는 이미지와 환자 정보를 함께 저장하는 표준인 DICOM(Digital Imaging and Communications in Medicine) 형식으로 도착함 — 프라이버시 보호와 일관성을 위해 스캔을 비식별화(de-identify)하고 정규화함. CT 스캔의 경우 윈도잉(windowing) 기법으로 대비를 조정해 폐나 뇌 조직 같은 관련 조직을 강조함
- **2단계 — 작업에 맞는 모델 아키텍처 선택**: 분류 작업에는 ResNet 같은 모델이 잘 작동하고, 분할(segmentation)에는 U-Net이 최선의 선택임
- **3단계 — 모델 훈련**: 회전·반전·밝기 조정 같은 데이터 증강(data augmentation) 기법으로 실제 임상 환경의 변동성을 시뮬레이션할 수 있음 — 희귀 질환에는 포컬 손실(focal loss)이나 가중 샘플링(weighted sampling) 같은 방법을 적용해 모델이 드물지만 중요한 사례에 더 집중하도록 도울 수 있음
- **4단계 — 기존 시스템에 안전하게 통합**: CNN은 종종 PACS(picture archiving and communication system)에 연결되어 긴급한 사례의 우선순위를 정하고 구조화된 리포트를 생성하는 데 도움을 줌

## 요약
- CNN은 단순한 가장자리부터 완전한 질병 패턴까지 계층적 피처를 추출하며 레이어별로 의료 영상을 분석해, X-ray·MRI·CT 전반의 진단 정확도를 높임
- CNN의 성능은 신중한 전처리(DICOM 비식별화·정규화·윈도잉), 적절한 모델 아키텍처(ResNet·U-Net) 선택, 훈련 전략(데이터 증강·포컬 손실)에 달려 있으며, PACS 같은 시스템과 제대로 통합되면 방사선 전문의가 더 빠르고 신뢰할 수 있는 결정을 내리도록 도움
