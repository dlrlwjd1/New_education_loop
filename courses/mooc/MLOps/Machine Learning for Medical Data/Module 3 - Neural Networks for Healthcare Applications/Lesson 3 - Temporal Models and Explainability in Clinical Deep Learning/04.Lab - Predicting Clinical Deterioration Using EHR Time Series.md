# Lab: Predicting Clinical Deterioration Using EHR Time Series (EHR 시계열로 임상 악화 예측하기 실습)

## 개요
- 시간에 걸쳐 기록된 환자 활력징후 데이터를 분석하는 20분 분량 핸즈온 랩 — 시뮬레이션된 시계열 EHR 데이터셋으로 LSTM(Long Short-Term Memory) 신경망을 구축·훈련해 환자의 ICU 입원 위험 여부를 예측함
- 심박수·혈압·산소포화도의 순차적 패턴이 어떻게 임상 악화를 예고하는지 탐구하고, 혼동 행렬·ROC 곡선 같은 표준 분류 지표와 시각화로 모델 성능을 평가함
