# Activity: Interpreting Model Explanations in Clinical Time-Series Prediction (임상 시계열 예측의 모델 설명 해석하기)

## 개요
- 15분 분량의 시나리오 기반 인터랙티브 액티비티 — 병원 데이터 과학팀 소속으로서 ICU 환자 악화를 조기에 예측하는 LSTM 기반 AI 시스템을 실전 배포 전에 검증하는 상황을 체험함

## 내용

### 설정 — LSTM 기반 ICU 악화 예측 모델 검증
- 심박수·산소포화도·혈압 등 시간에 따라 수집된 EHR 활력징후 데이터를 처리하는 LSTM 모델의 설명 가능성 결과를 실시간 모니터링에 사용하기 전에 검토하는 임무
- 해석 가능성·신뢰성·임상 워크플로 우선순위 사이의 균형을 요구하는 네 가지 짧은 시나리오를 마주함

### 시나리오 1 — 모델이 잘못된 시점에 집중할 때
- 시간적 현저성 지도(temporal saliency map)가 임상 사건 6시간 전 측정치를 가장 중요하다고 표시하는데, 간호사들은 실제 핵심 변화가 2시간 전에야 나타났다고 보고함 — 임상의는 모델이 오래된 신호에 집중하는 것이 아닌지 의문을 제기함
- **올바른 다음 단계**: 특징 기여도(feature attribution) 방법을 조사하고, 초기 신호가 이후의 악화와 실제로 상관관계가 있는지 검증할 것 — 현저성 방법이 중요도를 배정하는 방식을 검토하면 모델이 임상적으로 타당한 시간적 패턴을 학습했는지 판단하는 데 도움이 됨

### 시나리오 2 — 경고 빈도의 딜레마
- ICU는 위험도가 0.6을 넘을 때마다 경고를 발생시키길 원하지만, 임상의들은 경고 피로(alert fatigue)를 우려함 — 활력징후가 분 단위로 변함에 따라 모델의 예측도 빠르게 요동침
- **균형점**: 원시 확률(raw probability) 대신 예측을 시간에 걸쳐 평활화(smoothing)하고 신뢰도 트렌드(confidence trend)로 보여줄 것 — 시간적 평활화와 신뢰도 시각화는 경고 과부하를 억제하면서 사용성과 해석 가능성을 향상시킴

### 시나리오 3 — 투명성 대 성능의 트레이드오프
- 병원이 두 모델 중 하나를 선택해야 하는 상황: Model A(AUROC는 다소 낮지만 주의 메커니즘 기반 시간 단계별 설명 제공) vs Model B(AUROC는 높지만 블랙박스로 작동)
- **우선 배포 대상**: Model A — 임상적으로 투명하고 감사(audit) 가능한 모델 — 해석 가능성은 작은 정확도 손실을 감수하더라도 임상적 책임성(accountability)을 뒷받침함

### 반성 및 마무리 — 핵심 요점
- 시간적 현저성(temporal saliency)은 모델의 초점이 임상적 추론과 일치하는지(또는 어긋나는지) 드러냄
- 경고 설계는 해석 가능성과 실용성 사이의 균형을 맞춰야 함
- 투명한 모델은 작은 성능 비용을 치르더라도 신뢰를 구축함
- 설명 가능성은 복잡한 신경망 모델을 지속적인 환자 진료의 신뢰할 수 있는 파트너로 전환함
