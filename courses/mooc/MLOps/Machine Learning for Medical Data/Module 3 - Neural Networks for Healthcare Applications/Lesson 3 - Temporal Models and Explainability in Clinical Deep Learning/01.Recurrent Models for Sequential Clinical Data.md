# Recurrent Models for Sequential Clinical Data (순차적 임상 데이터를 위한 순환 모델)

## 개요
- 순환 모델이 시간 순서 임상 데이터로부터 어떻게 학습하는지, RNN·GRU·LSTM이 환자 이력을 포착하는 방식을 어떻게 비교하는지, 실제 헬스케어에서 불규칙하고 결측된 데이터를 다루는 전략을 다루는 5분 22초 분량 영상 — Module 3 "Lesson 3 - Temporal Models and Explainability in Clinical Deep Learning"의 첫 영상
- 투약은 시작되고 중단되며, 검사 수치는 불규칙하게 변하고, 활력징후는 분 단위로 바뀜 — 순환 모델은 이런 흩어진 점들을 의미 있는 타임라인으로 연결하는 데 도움을 줌

## 내용

### 순차적 임상 데이터란
- 진료·투약·활력징후·검사 결과처럼 시간에 걸쳐 수집되는 데이터 포인트로, 모두 불규칙한 간격으로 발생함 — 과제는 AI 모델이 이전에 일어난 일을 기억하고 그것이 미래 결과에 어떻게 영향을 미치는지 판단하도록 하는 것

### RNN — 가장 단순한 시간 모델링
- RNN(Recurrent Neural Network)은 데이터를 단계별로 처리하며, 은닉 상태(hidden state)를 한 지점에서 다음 지점으로 전달함 — 최근 24~72시간 ICU 활력징후 모니터링처럼 최근 맥락이 가장 중요한 단기 패턴에 잘 작동함
- 타임라인이 길어지면 RNN은 오래된 정보를 유지하는 데 어려움을 겪음 — 이를 기울기 소실(vanishing gradient) 문제라 함

### LSTM — 장기 기억을 위한 게이트 구조
- LSTM(Long Short-Term Memory)은 어떤 정보를 유지하고 어떤 정보를 잊을지 결정하는 특수한 게이트를 포함함 — 몇 달 전의 화학요법 주기가 오늘의 혈구 수치에 미치는 영향처럼 장기 패턴을 보존함
- 트레이드오프는 LSTM이 더 많은 파라미터를 사용해 훈련 시간이 더 오래 걸리고 배포 시 더 많은 메모리를 요구한다는 것

### GRU — 더 가벼운 대안
- GRU(Gated Recurrent Unit)는 LSTM의 경량 버전으로, 게이트를 더 단순한 구조로 통합해 중기 트렌드를 포착하면서도 훈련 속도를 높임 — 예: 최근 활력징후·검사 결과·투약 정보로 90일 심부전 재입원을 예측할 수 있음

### 어떤 것을 선택해야 할까
- 짧고 조밀한 시퀀스에는 RNN으로 충분할 수 있고, 길고 복잡한 타임라인에는 LSTM이 최선의 성능을 내며, 좋은 정확도와 함께 효율성이 필요할 때는 GRU가 적절한 균형을 이룸 — 선택은 시퀀스 길이, 데이터 희소성, 사용 가능한 컴퓨팅 자원에 달려 있음

### 불규칙하고 결측된 데이터 다루기
- 임상 타임라인은 거의 균일하지 않음 — 데이터 포인트가 서로 다른 시점에 들어오거나 아예 누락될 수 있음
- 이를 다루기 위해 모델은 마지막 사건 이후 경과 시간, 결측값을 위한 마스킹(masking), 오래된 기록의 영향을 줄이는 감쇠 함수(decay function) 같은 추가 피처를 사용함 — 예: 마지막 크레아티닌 검사 이후 경과 시간을 추가하면 모델이 최근 정보에 더 강한 가중치를 두도록 도움

### 구현 시 유용한 실무 사례
- 시퀀스 패딩(padding)과 패킹(packing)을 사용해 가변 길이를 처리할 것
- 인코운터(encounter)가 아닌 환자(patient) 단위로 데이터를 분할해 데이터 누수를 방지할 것
- 재가중치(reweighting)나 포컬 손실(focal loss)로 클래스 불균형을 해결할 것
- AUROC(area under the receiver operating characteristic curve)와 보정(calibration) 같은 지표로 모델을 평가해 신뢰할 수 있는 임상 예측을 보장할 것

### 분류를 넘어선 활용 — 예측과 결합 모델
- 순환 모델은 분류를 넘어 미래 트렌드를 예측할 수 있음 — GRU로 다음 주 일일 혈당 수치를 예측하거나, LSTM으로 몇 달에 걸친 장기 A1C 변화를 모델링하는 식 — 훈련 중 교사 강제(teacher forcing)를 추가하면 이런 시퀀스-투-시퀀스 예측의 단기 정확도가 향상됨
- 고급 파이프라인에서는 CNN과 RNN이 함께 작동하는 경우가 많음 — 예: CNN이 먼저 흉부 X-ray에서 피처를 추출하고 LSTM이 여러 입원에 걸쳐 그 피처가 어떻게 변화하는지 모델링하거나, 1D CNN이 ECG 파형을 포착하고 GRU가 그 패턴들을 결합해 부정맥 위험을 예측함

### 신뢰성과 설명 가능성
- 임상 응용에는 신뢰성과 설명 가능성이 모두 필요함 — GRU는 종종 병상 곁의 지연 시간 요구사항을 충족하고, LSTM은 더 긴 트렌드를 다룸
- 주의 메커니즘(attention mechanism)이나 피처 기여도 히트맵(feature attribution heatmap)을 추가하면 어떤 시점이 예측에 영향을 미쳤는지 보여줌 — 이런 투명성이 임상의의 신뢰를 쌓고 더 안전한 배포를 가능하게 함

## 요약
- 순환 모델은 시간 기반 임상 데이터를 해석해 환자 트렌드와 결과를 드러냄 — RNN은 단기 패턴을 포착하고, GRU는 효율성과 정확도의 균형을 맞추며, LSTM은 장기 맥락을 보존함
- 이런 모델들이 불규칙한 데이터를 관리하고, 건강 이벤트를 예측하며, 해석 가능한 임상 결정을 지원하는 방식을 살펴봄
