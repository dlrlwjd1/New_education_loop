# Lab: Building a Dense Neural Network for Heart Disease Prediction (심장질환 예측을 위한 밀집 신경망 구축 실습)

## 개요
- Cleveland Heart Disease 데이터셋(실제 환자 데이터)을 사용해 심장질환을 예측하는 밀집(dense) 신경망을 만들고 훈련하는 30분 분량 핸즈온 랩
- 결측값 처리·정규화·변수 인코딩 등 임상 피처를 전처리한 뒤, 완전 연결(fully connected) 신경망을 설계해 주요 지표로부터 패턴을 학습하고, 정확도·재현율 같은 지표와 학습 곡선(learning curve) 시각화로 모델 성능을 평가함

## 내용
