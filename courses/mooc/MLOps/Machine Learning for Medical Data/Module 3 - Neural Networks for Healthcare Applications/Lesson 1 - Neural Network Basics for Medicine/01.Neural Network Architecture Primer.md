# Neural Network Architecture Primer (신경망 구조 입문)

## 개요
- 신경망의 기본 구성 요소, 가중치·활성화 함수가 학습에 미치는 영향, 의료 영상·순차 데이터를 다루는 다양한 레이어 종류를 다루는 4분 23초 분량 영상 — Module 3 "Lesson 1 - Neural Network Basics for Medicine"의 첫 영상
- 신경망은 오늘날 많은 임상 예측·영상 시스템의 핵심이며, 작동 원리를 이해하면 x-ray, 검사 수치, 활력징후 같은 의료 데이터를 다룰 때 자신감을 가질 수 있음

## 내용

### 신경망의 기본 구조
- 신경망은 뉴런(neuron)이라는 연결된 단위를 통해 입력을 출력으로 매핑함 — 각 뉴런은 입력에 가중치(weight)를 곱하고 편향(bias)을 더한 뒤 활성화 함수(activation function)를 적용함
- 뉴런들은 레이어(layer)로 조직됨: 입력층(input layer)은 검사 수치나 이미지 픽셀 같은 환자 피처를 나타내고, 은닉층(hidden layer)은 중간 패턴을 학습하며, 출력층(output layer)은 패혈증 확률이나 질병 유형 같은 예측을 만들어냄

### 가중치와 편향, 활성화 함수
- 가중치는 각 입력이 출력에 얼마나 강하게 영향을 미치는지를 결정하고, 편향은 입력이 0일 때의 기본 베이스라인을 설정함 — 예를 들어 젖산(lactate) 수치에 높은 가중치가 걸리면 패혈증 위험이 높아지고, 편향은 검사 결과를 고려하기 전의 기본 위험도를 더함. 훈련 중에는 정확도를 높이기 위해 가중치와 편향이 계속 조정됨
- 활성화 함수는 신경망이 복잡한 관계를 학습할 수 있게 해줌 — ReLU(rectified linear unit)는 양수는 그대로 통과시키고 음수는 0으로 만들어 훈련을 안정시키고, 시그모이드(sigmoid)는 출력을 0~1 사이 확률로 매핑하며, 소프트맥스(softmax)는 여러 진단 범주에 걸쳐 확률을 분배함 — 각각 의료 AI에서 고유한 역할을 함

### 순전파와 손실 함수
- 순전파(forward pass) 동안 데이터는 레이어별로 이동함 — 입력에 가중치를 곱하고 편향을 더한 뒤 활성화를 거쳐 예측을 만들어냄
- 손실 함수(loss function)는 예측과 실제 값 사이의 차이를 측정함 — 패혈증 탐지 같은 분류 작업에서는 교차 엔트로피 손실(cross-entropy loss)이 확신에 찬 오류에 더 큰 페널티를 줌. 손실이 작을수록 모델이 좋다는 뜻이며, 이 손실값이 역전파(backpropagation)를 통해 학습을 이끔

### 레이어 종류별 용도
- **밀집층(Dense layer)**: 모든 입력을 모든 뉴런에 연결하며, 검사 결과·투약 정보 같은 구조화된 EHR 데이터에 이상적임 — 변수 간 관계를 포착해 위험 점수나 확률을 생성함. 파라미터가 많기 때문에 정규화(regularization)로 과적합을 방지하고 일반화를 유지해야 함
- **합성곱층(convolutional layer)**: 의료 영상 모델이 의존하는 레이어로, 작은 필터를 사용해 x-ray나 CT 스캔에서 가장자리·질감·음영(opacity) 같은 지역적 패턴을 탐지함
- **풀링층(pooling layer)**: 핵심 신호를 보존하면서 데이터 크기를 줄임 — 맥스 풀링(max pooling)은 가장 강한 활성화를 유지하고, 평균 풀링(average pooling)은 세부사항을 매끄럽게 만들어 더 넓은 요약을 제공함
- **순환 유닛(recurrent unit, LSTM·GRU)**: 시간에 따라 변화하는 의료 데이터를 다룸 — 활력징후나 투약 변경 같은 시간 순서 기록을 처리하며, 이전 사건에 대한 기억을 유지한 채 새 데이터를 처리함. 예: 심박수 상승과 혈압 하강이 동시에 나타나면 순환 신경망이 이를 악화 신호로 감지할 수 있음

### 견고한 모델을 위한 훈련 기법
- 드롭아웃(dropout)은 뉴런을 무작위로 비활성화해 과적합을 줄이고, 배치 정규화(batch normalization)는 활성화를 안정시키고 학습을 가속함
- 훈련이 끝나면 출력층은 시그모이드나 소프트맥스 함수를 사용해 점수를 확률로 변환함 — 보정(calibration)은 예측된 확률을 실제 임상 결과와 정렬시켜 신뢰할 수 있는 결과를 보장함

## 요약
- 신경망은 뉴런 레이어를 통해 의료 데이터를 예측으로 전환하며, 가중치·편향·활성화 함수가 학습을 이끌고, 밀집층·합성곱층·풀링층·순환층이 각기 다른 데이터 유형(구조화 EHR 데이터, 영상, 시계열)을 처리함
- 드롭아웃과 보정 같은 기법이 임상 AI 응용에서 신뢰성을 높임
