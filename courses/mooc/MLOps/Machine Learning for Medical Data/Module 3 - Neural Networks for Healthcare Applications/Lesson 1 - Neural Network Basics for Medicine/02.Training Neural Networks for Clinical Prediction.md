# Training Neural Networks for Clinical Prediction (임상 예측을 위한 신경망 훈련)

## 개요
- 헬스케어용 신경망 훈련에서 핵심적인 최적화 선택(학습률·정규화 기법)을 식별하고, 이런 선택이 모델의 견고성과 임상적 신뢰성에 어떤 영향을 미치는지 다루는 4분 51초 분량 영상 — Module 3 "Lesson 1 - Neural Network Basics for Medicine"의 두 번째 영상

## 내용

### 훈련의 비유 — 속도와 다양성의 균형
- 누군가에게 과제를 숙달하도록 훈련시키는 상황을 생각해보면 — 너무 빨리 진행시키면 기본 원리를 놓치고 실수를 하고, 너무 느리면 추진력을 잃음. 익숙한 예시 몇 개만 반복하면 학습자가 단순 암기에 갇히므로 다양한 상황에 노출시켜야 함
- 신경망을 훈련할 때도 마찬가지로 정확도와 임상적 사용성 사이의 균형을 맞추는 최적화 선택을 하게 되며, 여기에는 학습률(learning rate)과 정규화(regularization) 기법이 포함됨

### 학습률 — 너무 빠르지도 느리지도 않게
- 학습률은 각 훈련 단계에서 모델이 가중치를 얼마나 조정할지 제어하는 하이퍼파라미터임 — 가중치는 모델이 각 입력 피처에 부여하는 중요도를 결정함
- 학습률이 너무 높으면 모델이 이리저리 튀며 안정적인 해에 정착하지 못하고, 너무 낮으면 학습이 느려짐 — 속도보다 안정성과 신뢰성이 중요한 헬스케어에서는 점진적인 접근이 가장 효과적
- 작은 학습률로 시작해 초기 훈련 중 점차 늘렸다가 시간이 지나며 다시 줄이는 방식이 모델을 불안정 없이 매끄럽게 수렴시킴 — 학습률을 적절한 배치 크기(batch size, 가중치를 업데이트하기 전에 처리하는 데이터 샘플 수)와 짝짓는 것도 중요함. 작은 배치는 노이즈가 많지만 다양한 해를 탐색하도록 돕고, 큰 배치는 안정적이지만 차선의 패턴에 갇힐 수 있음 — 둘의 균형이 꾸준한 진전을 만듦

### 정규화 — 불필요한 복잡성 방지
- 정규화는 모델이 불필요하게 복잡해지는 것을 막는 최적화 기법들의 집합으로, 드롭아웃(dropout)·가중치 감쇠(weight decay)·데이터 증강(data augmentation)을 포함함
- 정규화가 없으면 신경망은 수백만 개의 파라미터를 발전시켜 실제 환자에게는 나타나지 않는 의미 없는 노이즈와 데이터 변동까지 완벽하게 맞춰버릴 수 있음 — 이를 과적합(overfitting)이라 하며, 모델이 새 환자에게 일반화하지 못하는 현상을 말함

### 드롭아웃과 몬테카를로 드롭아웃
- 드롭아웃은 각 훈련 단계마다 일정 비율의 뉴런을 무작위로 꺼버리는 정규화 기법 — 이는 네트워크가 여러 독립적인 경로를 학습하도록 강제해, 모델이 단일 뉴런이나 피처에 의존하지 않고 네트워크 일부가 사용 불가능해도 예측을 계속할 수 있게 함
- ECG 신호 같은 순차 데이터에서는 시간 단계 전반에 드롭아웃을 적용해 모델이 누락되거나 손상된 구간을 처리하도록 강제할 수 있음
- 몬테카를로 드롭아웃(Monte Carlo dropout)이라는 관련 기법은 훈련 시뿐 아니라 예측 시에도 드롭아웃을 적용함 — 이는 임상적으로 매우 유용한 불확실성 추정치를 제공함. 단일 예측 대신 모델이 "이것이 부정맥일 확률을 85% 확신한다"라고 말할 수 있어, 임상의가 언제 결과를 신뢰해야 할지 아는 데 도움을 줌

### 가중치 감쇠와 데이터 증강
- 가중치 감쇠는 과도하게 큰 가중치를 억제해 과적합을 방지하는 정규화 기법 — 훈련 중 가중치를 0 쪽으로 살짝 줄여, 모델이 훈련 데이터의 노이즈를 암기하기보다 더 단순하고 일반화 가능한 패턴을 학습하도록 유도함. 이는 모델의 연결이 너무 강해지지 않도록 작은 페널티를 가하는 것과 같음
- 데이터 증강은 훈련 예시의 인위적인 변형을 만들어 다양성을 높이는 정규화 기법 — 예를 들어 ECG 데이터라면 파형을 시간축에서 살짝 이동시키거나, 현실적인 센서 노이즈를 추가하거나, 다른 심박수를 시뮬레이션할 수 있음. 이런 변형은 새로운 환자 데이터를 수집하지 않고도 훈련 예시의 다양성을 확장함

## 요약
- 헬스케어를 위한 견고한 신경망 훈련은 학습률(너무 높으면 불안정, 너무 낮으면 느림)과 정규화 기법(드롭아웃·가중치 감쇠·데이터 증강)이라는 최적화 선택에 달려 있음
- 드롭아웃은 뉴런을 무작위로 비활성화해 과적합을 방지하고(몬테카를로 드롭아웃은 임상적으로 유용한 불확실성 추정치까지 제공), 가중치 감쇠는 가중치를 부드럽게 줄이며, 데이터 증강은 다양한 훈련 예시를 만들어 암기를 줄임
