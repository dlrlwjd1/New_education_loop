# Machine Learning for Medical Data

**Course URL:** [mooc.org/learn/machine-learning-for-medical-data](https://www.mooc.org/learn/machine-learning-for-medical-data)

SkillUp · "AI for Healthcare" 스페셜라이제이션의 한 코스. 지도 학습부터 비지도 학습, 신경망, 최종 프로젝트까지 헬스케어 데이터에 머신러닝을 적용하는 4개 모듈 구성. 각 레슨은 영상·읽기자료·랩(Jupyter/Colab 노트북)·AI 대화형 활동(Dialogue)으로 구성되며, Practice Quiz/Graded Quiz는 학업 정직성 정책에 따라 건너뜀.

## 모듈 구성
- [Module 1 - Introduction to Supervised Learning in Healthcare](Module%201%20-%20Introduction%20to%20Supervised%20Learning%20in%20Healthcare/) — 지도 학습 기초(당뇨병 위험 예측 사례), 피처 엔지니어링·데이터 전처리(EHR 데이터 정제, BMI 등 피처 엔지니어링), 불균형 데이터 처리(SMOTE, 정밀도-재현율/ROC 평가)
- [Module 2 - Unsupervised Learning for Medical Data](Module%202%20-%20Unsupervised%20Learning%20for%20Medical%20Data/) — 환자 세분화를 위한 클러스터링(K-평균), 차원 축소(PCA·t-SNE·UMAP), 클러스터를 임상적 결정으로 번역하기, 비지도 학습 결과의 EHR 시스템 통합, Gradio를 이용한 모델 배포 랩
- [Module 3 - Neural Networks for Healthcare Applications](Module%203%20-%20Neural%20Networks%20for%20Healthcare%20Applications/) — 신경망 기초와 훈련 최적화(심장질환 예측 밀집 신경망 랩), CNN을 이용한 의료 영상 분석(흉부 X-ray 다중 라벨 질병 탐지 랩), 순환 모델(LSTM/GRU)과 설명 가능한 AI 기법(Grad-CAM·SHAP·TCAV), EHR 시계열 기반 임상 악화 예측 랩
- [Module 4 - Final Project, Exam, and Wrap-up](Module%204%20-%20Final%20Project%2C%20Exam%2C%20and%20Wrap-up/) — 기말 프로젝트 개요(산모 건강 위험 예측 AI, Peer-graded Assignment는 학업 정직성 정책상 건너뜀), 코스 전체 용어집, 코스 마무리 및 다음 단계(스페셜라이제이션의 다음 코스 "AI Technologies in Healthcare"로 연결)
