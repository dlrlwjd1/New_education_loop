# Course Overview (코스 개요)

## 개요
- 머신러닝(machine learning)이 의료 데이터를 **분석·해석·이해**하는 데 어떻게 활용되는지 학습
- 다양한 헬스케어 데이터셋, 알고리즘 작동 방식, 데이터 기반 통찰(data-driven insights)이 진단·치료·환자 케어에 미치는 영향 탐구
- 실무 예시 출처: 전자건강기록(EHR, electronic health records), 의료 영상(medical imaging), 유전체 데이터(genomic data)

## 내용

### 학습 목표 (Learning Outcomes)
코스 완료 시 다음을 수행할 수 있음:
1. 분류(classification)·회귀(regression) 등 임상 예측을 위한 **지도 학습(supervised learning)** 알고리즘 구현
2. 헬스케어 데이터 패턴 발견 및 환자 계층화(patient stratification)를 위한 **비지도 학습(unsupervised learning)** 적용
3. 의료 데이터 분석용 **신경망(neural networks)** 설계·훈련 (딥러닝 아키텍처 포함)
4. 헬스케어 맥락에 맞는 지표(metrics)와 임상 검증(clinical validation) 기법으로 **모델 평가**

### 코스 구성 (4개 모듈)
- **Module 1 — Supervised Learning in Healthcare**: 질병 예측·결과 분석을 위한 지도 학습. 분류/회귀 모델, 데이터 정제(cleaning), 클래스 불균형(class imbalance) 해결, 피처 엔지니어링(feature engineering)으로 정확도 향상
- **Module 2 — Unsupervised Learning for Medical Data**: 레이블 없이 숨은 패턴 발견. 군집화(clustering)·차원 축소(dimensionality reduction)로 환자 그룹화 및 복잡한 데이터 단순화, 개인 맞춤 케어(personalized care) 지원
- **Module 3 — Neural Networks for Healthcare Applications**: 복잡한 데이터 처리. CNN(convolutional)·RNN(recurrent)을 의료 영상·환자 모니터링에 적용, 설명 가능성(explainability) 도구로 투명하고 신뢰 가능한 모델 확보
- **Module 4 — Final Project, Exam, and Wrap-Up**: 실제 시나리오 기반 최종 프로젝트 — **산모 건강 위험 예측(maternal health risk prediction)** 모델 구축·평가로 조기 개입(early intervention) 지원. 최종 시험 포함

### 수강 대상 (Who is this for)
- 기술(technical)·헬스케어·연구(research) 배경의 학습자
- 학생, 주니어 전문가(early-career), 의료 종사자(healthcare practitioner) 중 의료 AI에 관심 있는 사람

### 선수 지식 (Prerequisites)
- 통계 및 프로그래밍 개념의 기본 이해
- 기초 머신러닝 개념에 대한 친숙함
- 헬스케어 데이터·용어에 대한 일반적 이해 (필수 아님, 있으면 도움)

### 사용 도구 (Tools & Software)
- **Jupyter Notebook** (.ipynb) — **Google Colab** 환경에서 실습
- **Gradio** — 앱 기반(app-based) 실습
- Colab 사용 조건: Google 계정(Gmail/Workspace), 웹 브라우저(Chrome/Firefox/Edge), 안정적인 인터넷 연결

## 요약
- 4개 모듈: 지도 학습 → 비지도 학습 → 신경망 → 최종 프로젝트/시험 순으로 구성
- 최종 프로젝트 주제는 **산모 건강 위험 예측(maternal health risk prediction)**
- 실습 환경은 **Google Colab + Jupyter Notebook**, 앱 데모는 **Gradio**
- 완료 시 진단·치료·의사결정을 지원하는 ML 적용에 대한 탄탄한 이해와 실무 지식 확보
