# Welcome to the Course (코스 소개)

## 개요
- 의료 데이터에 머신러닝(machine learning)을 적용해 임상 의사결정을 지원하는 과정
- 모든 의료 기록·영상(scan)·데이터 포인트에는 의미가 있으며, 핵심은 **중요한 패턴을 찾아 실행 가능한 지식(actionable knowledge)으로 전환**하는 것
- 이론을 넘어 알고리즘을 **훈련(train)·테스트(test)·적용(apply)** 하는 실무 중심 과정

## 내용

### 대상 학습자
- 헬스케어 분야에 기술 역량을 적용하려는 기술자(technologist)
- AI 기반 도구의 가능성을 이해하려는 의료 전문가(medical professional)

### 학습 내용 (4가지 핵심 주제)
1. **지도 학습(supervised learning)** — 진단(diagnosis) 및 위험 평가(risk assessment)를 위한 예측 모델 구축
2. **비지도 학습(unsupervised learning)** — 의료 데이터의 패턴 발견, 공통 특성 기반 환자 그룹화(grouping)
3. **신경망과 딥러닝(neural networks & deep learning)** — 의료 영상(medical imaging)·유전체학(genomics) 분야의 돌파구를 견인, 복잡한 데이터 처리 및 미세 신호(subtle signal) 탐지
4. **모델 평가 및 검증(model evaluation & validation)** — 적절한 지표(metrics) 사용, 정확하면서도 임상적으로 유의미한(clinically relevant) 모델 보장

### 학습 활동
- 비디오(videos), 읽기 자료(readings), 활동(activities), 토론(discussions), 퀴즈(quizzes)
- 실제 헬스케어 데이터를 다루는 **핸즈온 최종 프로젝트(hands-on final project)**

### 수강 방식
- 주당 2시간 투자 시 약 **5주(5 weeks)** 완료, 또는 자율 속도(self-paced)로 진행 가능

## 요약
- 이 코스는 **데이터 사이언스와 헬스케어의 결합**을 이해하는 것이 목표
- 지도학습 → 비지도학습 → 신경망/딥러닝 → 모델 평가/검증 순으로 진행
- 최종적으로 **기술적 정밀성(technical precision)과 임상적 통찰(clinical insight)을 결합**해 실제 의료 문제를 해결하는 ML 모델을 설계·평가할 수 있게 됨
