# How to Make the Most of This Course (코스 활용법)

## 개요
- 이 코스는 단순히 강의를 완료하는 것이 아니라, 각 학습 요소를 활용해 **직접 해보며 배우는 것(learn by doing)** 이 중요함
- 비디오, 읽기 자료, 활동, 퀴즈, 토론, 최종 프로젝트는 서로 연결되어 학습을 강화하도록 설계됨
- 꾸준한 학습 일정과 작은 목표 설정이 코스 완주에 도움이 됨

## 내용

### 코스 구성 요소 활용법
- **Video**: 핵심 개념을 소개하는 자료. 필요하면 멈추거나 다시 보면서 노트 작성
- **Reading**: 주제를 더 깊게 설명하는 자료. 나중에 참고할 수 있도록 저장하고 제공된 템플릿 활용
- **Lab**: 실습 경험 제공. 환경을 준비하고 안내문을 확인한 뒤 연습 문제 수행
- **Activity**: 상호작용형 학습 경험 제공. 속도보다 깊이에 집중하며 비판적으로 사고
- **Discussion prompt**: 동료 학습자와 생각을 공유하고 다른 경험에서 배우는 공간
- **Dialogue**: AI coach와의 대화를 통해 학습 내용을 되돌아보고 아이디어를 발전시키는 활동
- **Practice quiz**: 이해도를 점검하는 연습 퀴즈. 피드백을 검토하고 필요한 경우 관련 내용을 다시 학습
- **Graded quiz**: 학습 성과를 확인하는 평가. 핵심 개념과 요약을 복습한 뒤 조용한 환경에서 집중해 응시
- **Final project**: 실제 문제 해결 상황을 모의하는 핸즈온 과제. 지시사항과 템플릿을 확인하고, 해결 과정에 몰입하며 동료 피드백을 제공
- **Glossary**: 낯선 용어를 확인하는 참고 자료

### 학습 지속 전략
- 주간 학습 시간을 정하고 리마인더 앱을 사용해 학습 습관 형성
- 코스를 작은 목표로 나누어 한 번에 하나의 모듈 또는 활동에 집중
- 노트를 작성하고 필요할 때 다시 보며 기억 유지
- 배운 내용을 개인적·전문적 상황에 바로 적용해 이해 강화
- 집중력이 떨어지기 전에 짧은 휴식을 취하고 다시 학습
- 친구, 동료, 학습자 등 accountability partner와 목표와 진행 상황 공유
- 작은 성취를 인식하며 학습 흐름 유지

## 예시
학습 루틴 예시:

1. 비디오를 보며 핵심 개념을 간단히 메모
2. 읽기 자료로 세부 내용을 보완
3. Lab 또는 Activity를 통해 직접 적용
4. Practice quiz 피드백으로 부족한 부분 확인
5. Graded quiz 전 요약 노트와 용어집 복습

## 요약
- 코스의 각 요소는 독립적인 과제가 아니라 **개념 이해 → 적용 → 점검 → 프로젝트 경험**으로 이어지는 학습 흐름의 일부
- 활동과 퀴즈는 학습을 강화하는 도구이며, 피드백을 적극적으로 활용해야 함
- 꾸준한 일정, 작은 목표, 노트 작성, 실제 적용이 코스 완주와 개념 정착에 핵심
