# AI for Healthcare Specialization Overview (전문 과정 소개)

> 강사: Ramesh Sanareddy — **Artificial Intelligence for Healthcare** 전문 과정(specialization) 소개

## 개요
- AI는 강력하지만 복잡하며, **실제 환자의 삶에 직접 영향**을 미침
- 책임감 있게 적용하면 진단 개선·결과 예측·의료 효율성 향상 가능
- 헬스케어에서는 모든 예측이 생사를 가르는 결정에 영향을 줄 수 있어 **기술적 우수성(technical excellence)만으로는 부족**
- 의료 윤리(medical ethics)·규제 요건(regulatory requirements)·임상 현실을 무시한 모델은 서류상 인상적이어도 임상적으로 무용하거나 해로울 수 있음

## 내용

### 전문 과정 구성 (3개 코스)
세 개 코스로 구성되며, 안전하고(safe) 윤리적이며(ethical) 효과적인(effective) AI 솔루션 구축 역량을 기름

- **Course 1 — 기초부터 실습 코딩까지**
  - 핵심 AI 개념 → 실제 헬스케어 데이터로 핸즈온 코딩
  - 프라이버시(privacy) 유지하며 데이터 전처리(pre-process), 진단 모델 구축
  - 실전 프로젝트: **간 질환 탐지(liver disease detection)** — 데이터에서 임상 평가까지 전체 ML 워크플로 경험

- **Course 2 — 본 코스 (심화)**
  - 진단을 위한 지도 학습(supervised learning), 패턴 발견을 위한 비지도 학습(unsupervised learning), 복잡한 의료 데이터를 위한 신경망(neural networks)
  - 임상 활용을 위한 사용자 인터페이스(UI) 개발 경험
  - 임상 검증(clinical validation) — 임상의가 실제로 신뢰하는 지표(metrics) 이해
  - 실전 프로젝트: **산모 건강 위험 예측(maternal health risk prediction)**

- **Course 3 — 변혁적 기술 3가지**
  - 자연어 처리(NLP) — 임상 노트에서 통찰 추출
  - 컴퓨터 비전(computer vision) — 의료 영상 해석
  - 생성형 AI(generative AI) — 문서화·챗봇·환자 커뮤니케이션
  - 프로젝트: 경량 생성형 **LLM** 기반 의료 챗봇 구축, **Gradio** UI 연결, 프롬프트 설계(prompt design) 원칙 적용

### 사용 도구
- Python, Jupyter Notebook, Google Colab, Gradio
- 헬스케어 AI에 쓰이는 주요 머신러닝 라이브러리

### 수강 정보
- 난이도: 중급(intermediate-level), 약 **25시간** 소요
- 대상: AI를 업무에 통합하려는 의료 전문가, 헬스케어에 집중하는 데이터 사이언티스트/IT 전문가

## 요약
- 본 코스(ML for Medical Data)는 **3개 코스 전문 과정 중 Course 2**에 해당
- Course 1(간 질환 탐지) → Course 2(산모 건강 위험 예측) → Course 3(NLP·CV·생성형 AI 챗봇)로 이어짐
- 핵심 메시지: 강력함뿐 아니라 **안전·윤리·효과**를 갖춘 책임감 있는(responsible) 의료 AI 구축
