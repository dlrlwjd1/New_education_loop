# Reading: Module Summary: Supervised Learning in Healthcare (모듈 요약)

## 개요
- Module 1 전체(지도 학습 기초, 피처 엔지니어링·전처리, 불균형 데이터 처리)를 마무리하며 학습 내용을 정리하는 2분 분량 요약 읽기자료

## 내용

### 헬스케어에서의 지도 학습 이해
- 레이블이 있는 데이터로부터 알고리즘이 어떻게 예측을 학습하는지를 포함한 지도 학습의 기초를 다룸 — 당뇨병 위험 예측 같은 사례 연구를 통해 분류·회귀 모델이 건강 위험 식별, 진단 개선, 치료 계획 향상에 어떻게 도움을 주는지 살펴봄

### 피처 엔지니어링과 데이터 전처리
- 데이터 정제·변환·피처 추출을 통해 헬스케어 데이터를 머신러닝에 맞게 준비하는 법을 학습 — 결측값 처리, 변수 정규화, 임상적으로 의미 있는 피처 엔지니어링에 중점을 둠

### 불균형 임상 데이터 관리
- 희귀 질환이나 이상 반응 예측처럼 헬스케어에서 흔히 발생하는 불균형 데이터셋을 다루는 전략(리샘플링·가중치 부여·임계값 조정)과, 정밀도-재현율·ROC 곡선 같은 평가 지표를 살펴봄

### 핵심 학습 성과
- 임상 예측 과제에서의 지도 학습 원리 이해
- 의료 데이터셋의 피처 엔지니어링·전처리 실무 능력
- 불균형 데이터 처리법과 적절한 헬스케어 지표를 사용한 모델 성능 평가 지식
- 환자 위험 점수화 등 기본적인 지도 학습 모델 구현 능력

## 요약
