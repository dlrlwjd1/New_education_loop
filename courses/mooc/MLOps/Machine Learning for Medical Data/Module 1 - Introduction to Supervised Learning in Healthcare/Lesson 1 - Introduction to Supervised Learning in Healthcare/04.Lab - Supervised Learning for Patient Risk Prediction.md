# Lab: Supervised Learning for Patient Risk Prediction (환자 위험 예측 실습)

## 개요
- 실제 임상 문제에 **지도 학습(supervised learning)**을 적용하는 핸즈온 랩(hands-on lab)
- 데이터셋: **위스콘신 유방암 데이터(Wisconsin Breast Cancer data)** 기반 임상 데이터셋
- 목표: 환자 위험 예측(patient risk prediction)을 위한 기본 지도 모델 구축·평가
- 핵심 작업:
  - **랜덤 포레스트 분류기(Random Forest classifier)** 훈련
  - **민감도(sensitivity)·특이도(specificity)** 등 주요 지표로 성능 분석
  - 모델 출력이 임상 의사결정(clinical decision-making)을 어떻게 지원하는지 해석
