# Supervised Learning Basics in Healthcare (헬스케어 지도 학습 기초)

## 개요
- **지도 학습(supervised learning)**을 헬스케어 맥락에서 정의
- **분류(classification)**와 **회귀(regression)** 적용 사례 구분
- 신뢰할 수 있는 모델 개발에서 **레이블링(labeling)·평가(evaluation)·거버넌스(governance)**의 역할 설명
- 핵심 흐름: 임상 입력 → 레이블된 결과 → 예측 → 임상 의사결정

## 내용

### 지도 학습이란 (What is Supervised Learning)
- **레이블된 임상 데이터(labeled clinical data)**로 AI 모델을 훈련하는 과정
- 각 환자 기록은 **입력(input)**과 **알려진 결과(known outcome)**를 쌍으로 가짐
- **입력 예시**: 활력징후(vital signs), 검사 결과(laboratory results), 약물(medications), 임상 노트(clinical notes)에서 추출한 정보
- **결과 예시**: 진단 유무(presence of a diagnosis), 미래 건강 위험 점수(risk score), 예상 재원 기간(predicted length of stay)

### 분류 vs 회귀 (Classification vs Regression)
- **분류(classification)** — 범주형(categorical) 결과 예측
  - 예: 패혈증 경보(sepsis alert) 유/무, 재입원(readmission) 여부, 영상에서 골절(fracture) 검출 유/무
  - 헬스케어는 고위험(high-stakes) 의사결정 → **거짓 음성(false negative)**의 결과가 심각할 수 있음
  - 따라서 **민감도(sensitivity)**가 매우 중요
- **회귀(regression)** — 연속 값(value) 추정
  - 예: 30일 내 재입원 확률, 질병 위험 점수(disease risk score), 예상 재원 기간
  - 임상의는 예측값에 **임계값(threshold)**이나 **케어 경로(care pathway)**를 적용해 실행 가능한 조치로 전환

### 레이블링 (Labeling)
- 분류·회귀 모두에서 **적절한 레이블링이 필수**
- 레이블의 역할:
  - 작업 유형(task type)을 명확히 정의
  - 질환 발생 시점(when conditions begin) 식별
  - 어떤 환자가 각 코호트(cohort)에 속하는지 결정
- 불명확한 지도(unclear supervision)를 피하고 효과적인 훈련 보장
- **생성형 AI(generative AI)**가 레이블링 가이드라인 작성·노트 인사이트 추출을 도울 수 있으나, **임상의의 지속적 검토·확인** 필수

### 피처 엔지니어링 (Feature Engineering)
- 데이터에는 결측값(missing values), 단위 불일치(inconsistent units), 타임스탬프 정렬 오류(misaligned timestamps)가 흔함
- **전처리(preprocessing)**로 의미를 유지하면서 문제 해결
- 유용한 피처: 활력징후 추세(vital sign trends), 검사 결과 변화, 약물 노출 기간(medication exposure windows), 동반질환 지수(comorbidity indices)
- 임상적으로 안정적인(clinically stable) 패턴 학습에 기여

### 평가 (Evaluation)
- **분류 모델 지표**: 민감도(sensitivity), 특이도(specificity), ROC-AUC, 적정 임계값에서의 정밀도(precision)
- **회귀 모델 지표**: 평균 절대 오차(MAE, mean absolute error), 보정(calibration)
- 예: 패혈증 모델은 선별검사(screening) 단계에서 **높은 민감도** 우선 → 치료 가능한 케이스를 놓치지 않도록 설계
- 평가가 중요한 이유:
  - 강력한 지표 → 임상의 신뢰(clinician trust) 구축
  - 해석 가능한 신호: 피처 중요도(feature importance), 기여도 플롯(contribution plots)
  - 잘 보정된 확률(well-calibrated probabilities) → 명확한 위험 소통
  - 인구집단 간 **형평성 점검(equity checks)** → 모든 환자에게 공정한 모델

### 거버넌스 (Governance)
- 예측 도구의 책임 있는 사용을 보장하는 핵심 요소
- 규제 준수(regulatory compliance), 환자 프라이버시 법(privacy laws), 기관 심의(institutional review), 규제 가이드라인 준수
- 윤리적·법적·운영적 무결성(integrity) 보호
- 효과적 위험 관리(risk management):
  - 명확한 문서화(documentation)와 감사 추적(audit trails) 유지
  - 모든 단계에서 **인간 감독(human oversight)**
  - 예측 도구를 임상 워크플로(clinical workflows)에 통합하되 제공자(provider)를 과부하시키지 않도록 경보·점수 설계

## 예시 (Examples in Practice)
- **심혈관 위험 점수(cardiovascular risk score)**: 회귀로 10년 위험 추정 → 스타틴(statin) 치료 결정 지원
- **수술 후 합병증 플래그(post-operative complication flag)**: 분류로 고위험 환자 조기 식별
- 두 사례 모두 레이블·피처·보정된 출력(calibrated outputs)을 실행 가능한 권고로 전환

## 실제 배포 (Real-World Deployment)
- 지속적 모니터링(ongoing monitoring) 필요
- **데이터 드리프트(data drift)**, 새로운 진료 패턴, 장비 변경 → 성능 저하 가능
- 대응: 보정 추적(track calibration), 임계값 조정, 필요 시 재훈련(retrain)
- 예: 호흡기 질환의 계절적 변동(seasonal variation) → 재보정(recalibration) 필요

## 요약
- 지도 학습은 임상 입력을 레이블된 결과에 매핑하여 AI 모델로 예측을 수행
- **분류**(범주형)와 **회귀**(연속값)의 차이와 각각의 적합한 사용 시점 이해
- 정밀한 레이블, 강력한 피처, 보정된 지표, 해석 가능성(interpretability), 거버넌스가 모두 안전하고 신뢰할 수 있는 예측의 조건
- 궁극 목표: **환자를 중심에 둔(patient at the center)** 케어
