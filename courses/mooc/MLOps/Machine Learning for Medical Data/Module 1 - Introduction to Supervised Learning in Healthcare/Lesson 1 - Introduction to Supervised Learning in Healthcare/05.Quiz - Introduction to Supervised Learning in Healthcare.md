# Quiz: Introduction to Supervised Learning in Healthcare (퀴즈 복습)

## 개요
- Lesson 1의 주요 개념을 점검하는 퀴즈
- 범위:
  - 헬스케어 데이터 분석에서 군집화(clustering)의 목적
  - 당뇨병 위험 예측 사례에서 시간에 따른 변화 추적의 의미
  - 임상 AI에서 지도 학습(supervised learning) 응용 범주
- 이 노트는 정답표가 아니라, 퀴즈 전후에 개념을 복습하기 위한 정리임

## 내용

### 핵심 개념 1: 군집화의 목적
군집화(clustering)는 비지도 학습(unsupervised learning)의 대표적 방법이다. 헬스케어 데이터 분석에서는 환자 데이터를 미리 정해진 진단명이나 레이블에 맞추는 것이 아니라, 비슷한 특성을 가진 환자들이 자연스럽게 어떤 그룹으로 나뉘는지 탐색하는 데 사용된다.

복습 포인트:
- 군집화는 레이블이 없는 데이터에서 패턴을 찾는다
- 환자 계층화(patient stratification), 유사 환자 그룹 탐색, 숨은 하위 집단 발견에 활용된다
- 지도 학습처럼 사전에 정의된 결과를 예측하는 방식과 구분해야 한다

### 핵심 개념 2: 시간 기반 변화 추적
당뇨병 위험 예측 사례에서는 단일 혈당 수치나 단일 체중 값만 사용하는 대신, 혈당과 체중이 시간에 따라 어떻게 변하는지 추적한다.

복습 포인트:
- 한 번의 측정값은 환자의 전체 위험 변화를 충분히 보여주지 못할 수 있다
- 혈당 상승 추세, 체중 증가 추세처럼 시간에 따른 패턴은 조기 경고 신호가 될 수 있다
- 의료 AI 모델은 원시 데이터를 그대로 쓰기보다, 임상적으로 의미 있는 신호(signal)로 변환해 학습한다

### 핵심 개념 3: 지도 학습 응용 범주
임상 AI에서 지도 학습은 레이블된 임상 데이터를 기반으로 새로운 사례의 결과나 상태를 예측한다.

주요 응용 범주:
- **Screening**: 증상 발생 전 위험 환자 식별
- **Diagnostic support**: 검사 소견이나 질환 분류를 통한 진단 보조
- **Prognosis**: 재입원, 합병증, 질병 진행 등 미래 결과 예측
- **Treatment recommendations**: 치료법, 약물, 용량 선택 지원
- **Operations**: 병상 수요, 인력 배치, 예약 불참 등 운영 최적화

### 퀴즈 전 확인 질문
- 군집화는 지도 학습인가, 비지도 학습인가?
- 군집화는 알려진 정답 레이블을 예측하는가, 자연스러운 그룹을 찾는가?
- 당뇨병 위험 예측에서 단일 측정값보다 추세가 중요한 이유는 무엇인가?
- 증상 발생 전에 위험 환자를 식별하는 지도 학습 응용은 어떤 범주에 해당하는가?
- 예후 예측(prognosis)과 선별(screening)은 어떻게 다른가?

## 예시
개념 구분 예시:

| 개념 | 목적 | 헬스케어 예시 |
|---|---|---|
| Clustering | 비슷한 환자끼리 자연스러운 그룹 찾기 | 유사한 임상 특성을 가진 환자군 발견 |
| Screening | 증상 전 위험 환자 식별 | 당뇨병, 망막병증, 심방세동 위험 선별 |
| Prognosis | 미래 임상 결과 예측 | 재입원, 합병증, 질병 진행 가능성 예측 |
| Diagnostic support | 현재 소견 또는 질환 분류 | CT, X-ray, 병리 슬라이드 판독 보조 |

## 요약
- 군집화는 레이블 없이 유사한 환자 그룹을 찾는 비지도 학습 방법이다
- 당뇨병 위험 예측에서는 단일 수치보다 시간에 따른 변화 추세가 조기 위험 신호를 더 잘 드러낼 수 있다
- 지도 학습의 임상 AI 응용은 선별, 진단 지원, 예후 예측, 치료 추천, 운영 최적화로 구분된다
- 퀴즈는 각 개념의 정의보다, 서로 다른 적용 목적을 구분할 수 있는지 확인하는 데 초점이 있다
