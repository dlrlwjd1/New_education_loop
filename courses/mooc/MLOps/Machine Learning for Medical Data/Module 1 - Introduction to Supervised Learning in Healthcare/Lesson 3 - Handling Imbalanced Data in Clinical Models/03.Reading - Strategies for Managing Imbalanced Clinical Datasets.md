# Reading: Strategies for Managing Imbalanced Clinical Datasets (불균형 임상 데이터셋 관리 전략)

## 개요
- 심부전 재입원 예측 사례(30일 내 재입원율 3%인 데이터에서 "재입원 없음"만 예측해도 97% 정확도가 나오지만 실제 사례를 하나도 못 잡는 "정확도 함정")로 시작해, 임상 유틸리티를 우선시하는 불균형 데이터 관리 전략을 개괄하는 4분 분량 읽기자료

## 내용

### 임상 데이터의 불균형 이해
- 한 결과가 다른 결과보다 훨씬 드물 때 불균형이 발생 — 패혈증이 환자의 2%에게만 나타나는 데이터셋에서 "패혈증 없음"만 예측해도 98% 정확도가 나오지만 실제 사례는 거의 다 놓치는 것이 그 예
- 이는 이런 맥락에서 정확도가 왜 오해를 부르는지, 그리고 임상 AI가 실제 결과를 반영하는 지표를 필요로 하는 이유를 보여줌

### 적절한 평가 지표 선택
- 정확도만으로는 임상적 관련성을 포착하지 못함 — 대안 지표: 정밀도(precision), 재현율(recall), F1 점수, 정밀도-재현율 AUC(희귀 사건에 이상적), 균형 정확도(balanced accuracy, 민감도·특이도 평균), 캘리브레이션(calibration, 예측 확률과 실제 발생 빈도의 일치도)

### 임상적 결정 임계값 설정
- 임계값은 통계적 최적화가 아니라 임상적 비용을 반영해야 함 — 패혈증 사례를 놓치는 것은 거짓 경보를 내는 것보다 훨씬 큰 해를 끼침
- 캘리브레이션 방법은 여러 인구집단에 걸쳐 확률이 신뢰할 수 있게 유지되도록 함 — 브라이어 점수(Brier score)는 확률의 정확도를 측정하고, 의사결정 곡선 분석(decision curve analysis)은 여러 임계값에서의 순이익(net benefit)을 평가해 모델 출력을 실행 가능한 결정으로 변환하는 데 도움을 줌

### 샘플링 기반 리밸런싱 기법
- 무작위 언더샘플링(다수 사례 일부 제거, 데이터 크기 감소하지만 정보 손실 위험)과 무작위 오버샘플링(소수 사례 복제, 다양성은 보존하지만 과적합 위험 증가)이 있음
- 모든 샘플링은 같은 사람이 훈련·테스트 양쪽에 나타나지 않도록 환자 단위 그룹화(patient-level grouping)를 존중해야 하며, 시간 기반 데이터에는 시간 순서를 보존하는 시간적 분할(temporal split)을 적용해야 함

### 합성 샘플 생성
- SMOTE(Synthetic Minority Oversampling Technique)는 유사한 사례들 사이를 보간(interpolate)해 새로운 소수 클래스 샘플을 만듦 — Borderline-SMOTE(어려운 결정 영역용), SMOTE-NC와 Tomek links(겹치는 다수 클래스 샘플 정리용) 등의 변형이 있음
- 합성 조합은 비현실적인 의료 패턴을 만들어낼 수 있으므로, 모델 배포 전 타당성을 확인하는 임상적 검증(clinical validation)이 필수

### 희귀 질환을 위한 생성형 AI
- 생성 모델은 비식별화(de-identified)된 데이터를 사용해 희귀 질환의 현실적인 환자 프로필이나 임상 노트를 시뮬레이션할 수 있음 — 예를 들어 심장 전문의가 AI가 생성한 비전형적 흉통 사례들을 검토해 의학적 사실성을 확인하는 식
- 이 접근법은 오도하는 경향을 방지하기 위해 엄격한 프라이버시 안전장치, 분포 테스트, 검증을 요구함

### 모델 측 전략
- 데이터를 바꾸는 대신 학습 우선순위를 조정하는 기법들 — 클래스 가중치(class weighting)는 소수 클래스 오류에 대한 페널티를 늘리고, Focal loss는 어려운 사례를 자동으로 강조하며, 임계값 조정은 훈련 후 비용 민감도에 적용됨
- 이 방법들은 캘리브레이션 도구와 잘 어울리고 합성 데이터 생성과 관련된 위험을 피함

### 검증과 공정성 점검
- 검증은 편향과 데이터 누수를 방지해야 함 — 계층화 그룹화(stratified grouping)로 환자 기록을 함께 유지하고, 종단(longitudinal) 데이터에는 배포를 모방하는 롤링 오리진 분할(rolling-origin split)을 적용하며, 여러 병원에 걸친 외부 검증(external validation)으로 일반화 가능성을 테스트할 것
- 배포 전 인구통계학적 그룹 전반에 걸쳐 정밀도·재현율·특이도·캘리브레이션을 평가해 공평한 성능을 확인할 것

### 임상 목표에 맞는 전략 선택
- 조기 발견(예: 패혈증)은 재현율·클래스 가중치·캘리브레이션을 우선시하고, 고위험 개입(예: 수술)은 언더샘플링과 신중한 임계값 설정으로 높은 정밀도를 선호함
- 지속적인 모니터링과 문서화는 데이터와 실무가 변화함에 따라 모델이 안전하게 적응하도록 보장함

### 핵심 요점
- 클래스 불균형은 정확도를 왜곡하며 임상적 관련성에 맞춘 지표를 필요로 함
- 샘플링·합성 데이터·모델 측 가중치 부여는 각각 트레이드오프를 지님
- 캘리브레이션과 외부 검증은 신뢰성과 공정성을 지켜줌
- 임상 목표가 전략 선택과 성능 평가를 이끌어야 함
- 지속적인 모니터링과 투명한 문서화가 신뢰와 규정 준수를 유지시킴
