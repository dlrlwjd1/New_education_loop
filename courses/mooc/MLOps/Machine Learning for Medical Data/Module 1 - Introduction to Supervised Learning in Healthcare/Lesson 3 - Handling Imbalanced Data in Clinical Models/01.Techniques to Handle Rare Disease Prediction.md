# Techniques to Handle Rare Disease Prediction (희귀 질환 예측 기법)

## 개요
- 극도로 불균형(imbalanced)한 임상 데이터셋에서 희귀 질환을 예측할 때의 어려움과, 언더샘플링(undersampling)·SMOTE·비용 민감 학습(cost-sensitive learning) 같은 데이터 리밸런싱(rebalancing) 기법을 다루는 5분 23초 분량 영상 — Module 1 "Lesson 3 - Handling Imbalanced Data in Clinical Models"의 첫 영상

## 내용

### 정확도(accuracy)의 함정
- 환자의 0.5%에게만 나타나는 희귀 심장 질환을 탐지하는 AI 모델을 만든다고 가정해보면, 모든 환자에게 "질환 없음"이라고 예측해도 99.5%의 정확도를 달성할 수 있지만 실제 사례는 모두 놓치게 됨
- 이는 희귀 질환 예측이 데이터를 리밸런싱하면서도 임상적 타당성(clinical validity)과 안전성을 유지하는 특화된 기법을 필요로 하는 이유를 보여줌 — 임상 데이터셋은 흔히 양성(positive) 사례가 1% 이하이므로, 전체 정확도만으로는 오해의 소지가 있음

### 언더샘플링(undersampling)
- 다수 클래스(음성 사례)를 줄여 빠르게 균형을 맞추는 방법
- 무작위 언더샘플링(random undersampling)은 단순히 음성 사례를 제거하는 반면, 더 정교한 방법들도 있음
  - **Tomek links**: 양성 사례 근처의 경계선상 음성 사례를 제거
  - **Edited nearest neighbors**: 노이즈가 있는 음성 사례를 제거
  - **Cluster centroids**: 중복되는 레코드를 압축
- 이 방법들은 훈련 시간을 줄이고 결정 경계(decision boundary)를 드러낼 수 있지만, 잠재적으로 유용한 정보를 버릴 수도 있음

### SMOTE 계열 — 소수 클래스 신호 강화
- SMOTE(Synthetic Minority Over-sampling Technique)는 기존 사례를 바탕으로 합성 양성 샘플을 만들어 소수 클래스 신호를 강화함
- **SMOTE-NC**: 혼합 데이터 타입(범주형 변수 포함)을 적절히 처리
- **Borderline SMOTE**: 결정 경계 근처의 사례에 집중
- **ADASYN**: 더 어려운 사례 쪽으로 샘플링을 적응시킴
- 이 방법들은 원본 데이터를 모두 보존하면서 희귀 사례에 대한 학습을 강화함

### 생성형 AI를 활용한 데이터 증강
- 생성형 AI는 현실적인 합성 환자 프로필이나 의역된(paraphrased) 임상 노트를 만들어 희귀 사례 문서를 보강할 수 있음
- 다만 안전장치가 매우 중요 — 프라이버시 점검, 통계적 검증, 테스트를 통해 합성 데이터가 모델을 오도하는 비현실적인 패턴을 도입하지 않도록 확인해야 함

### 비용 민감 학습(cost-sensitive learning)
- 불균형 처리를 훈련 과정 자체에 직접 내장하는 방식
- **클래스 가중치(class weights)**: 예를 들어 패혈증(sepsis) 사례를 놓치는 경우처럼, 거짓 음성(false negative)에 더 무거운 페널티를 부여
- **Focal loss**와 커스텀 손실 함수는 분류하기 어려운 사례에 학습을 집중시키고 임상적 우선순위를 인코딩하며, 유병률(prevalence)이 매우 낮을 때도 데이터 충실도를 보존함

### 평가 지표와 임상적 임계값
- **정밀도-재현율 곡선 아래 면적(PR-AUC)**은 낮은 유병률 상황에서 표준 ROC 곡선보다 성능을 더 잘 보여줌
- 고정 정밀도에서의 특이도(specificity-at-fixed-precision)는 중증도 분류(triage)에, 고정 민감도에서의 특이도(specificity-at-fixed-sensitivity)는 배제 검사(rule-out testing)에 적합
- 캘리브레이션(calibration)은 예측 확률이 실제 위험과 일치하도록 보장함 — 이런 지표들은 균형 잡힌 훈련이 실제 임상적 의사결정의 질을 개선하는지 판단하는 데 도움을 줌
- 결정 임계값(decision threshold)은 검증 점수 최적화가 아니라 임상적 필요를 충족해야 함 — 예를 들어 그 업무량을 감당할 수 있는 전원(referral) 경로를 위해 90% 민감도와 최소 30% 정밀도를 달성하는 임계값을 선택하는 식
- 비용 곡선(cost curve)과 의사결정 곡선 분석(decision curve analysis)은 트레이드오프를 명시적으로 드러내, 모델 출력을 실행 가능한 임상적 결정으로 변환함

### 데이터 누수(data leakage) 방지와 실무 조합 전략
- 데이터 리밸런싱 전략 전체를 훼손할 수 있는 데이터 누수를 막기 위해, 방문(encounter) 단위가 아닌 환자(patient) 단위로 데이터를 분할하고 시간적 검증(temporal validation)을 사용할 것
- 계층화 교차 검증(stratified cross-validation)을 적용해 각 폴드(fold)에서 양성 사례의 균형 잡힌 분포를 유지
- 합성 샘플과 실제 샘플이 훈련·테스트 사이에 섞이지 않도록 데이터 출처를 추적할 것
- 유병률 0.3%인 질환의 경우, 실용적인 접근법은 언더샘플링·SMOTE·클래스 가중치를 결합한 뒤 캘리브레이션과 임상적으로 적절한 임계값 설정을 뒤따르는 것
- 배포 후에는 성능 드리프트(drift)와 하위 그룹 차이를 모니터링하고, 합성 데이터를 사용했다면 실제 환자로만 구성된 별도의 검증 세트를 정의하며, 모든 방법을 문서화하고 감사 로그(audit log)를 유지해 장기적 신뢰성을 확보할 것

## 요약
- 언더샘플링은 속도를 제공하지만 유용한 정보를 버릴 수 있는 반면, SMOTE는 실제 사례를 잃지 않으면서 소수 클래스 신호를 강화함 — 생성형 AI는 적절히 검증되면 희귀 사례를 증강할 수 있고, 비용 민감 학습은 불균형을 훈련 자체에서 다룸
- 성공을 위해서는 리밸런싱 전략을 적절한 평가 지표, 임상적 임계값, 그리고 데이터 누수를 방지하고 신뢰할 수 있는 성능을 보장하는 엄격한 검증과 정렬시켜야 함
