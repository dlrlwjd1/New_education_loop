# Activity: Building Responsible AI for Rare Disease Prediction (책임 있는 AI 구축 실전 활동)

## 개요
- 희귀 질환 예측 모델을 설계할 때 책임 있는 AI(responsible AI) 원칙을 적용해보는 15분 분량의 SCORM 기반 인터랙티브 활동 — Module 1 "Lesson 3 - Handling Imbalanced Data in Clinical Models"의 활동 항목

## 내용

### 활동 형식
- 이 활동은 외부 SCORM 패키지(인터랙티브 슬라이드/시나리오형 콘텐츠)로 임베드되어 있어, 이 노트를 작성하는 시점에는 브라우저 자동화로 내부 콘텐츠를 직접 추출할 수 없었음
- 앞선 [01.Techniques to Handle Rare Disease Prediction.md](01.Techniques%20to%20Handle%20Rare%20Disease%20Prediction.md)과 [03.Reading - Strategies for Managing Imbalanced Clinical Datasets.md](03.Reading%20-%20Strategies%20for%20Managing%20Imbalanced%20Clinical%20Datasets.md)에서 다룬 리밸런싱 기법(언더샘플링·SMOTE·비용 민감 학습)과 평가 지표를 바탕으로, 희귀 질환 예측 시나리오에서 공정성·프라이버시·임상적 안전성을 고려한 의사결정을 내려보는 실전 시나리오형 활동으로 추정됨

### 처리 방침
- 개인별 상호작용에 따라 내용이 달라지는 인터랙티브 활동이며 채점 대상이 아니므로(Ungraded Plugin), 실제 참여는 진행하지 않고 항목의 존재와 맥락만 기록함

## 요약
- 이 활동은 리밸런싱 기법과 평가 지표에 대한 지식을 희귀 질환 예측이라는 구체적 시나리오에서 "책임 있는 AI" 관점(공정성·프라이버시·임상적 안전)으로 적용해보는 실습으로 보임
- 다음 [05.Lab - Detecting Rare Medical Conditions with Machine Learning.md](05.Lab%20-%20Detecting%20Rare%20Medical%20Conditions%20with%20Machine%20Learning.md)에서 희귀 질환 탐지 랩을 다룸
