# Lab: Detecting Rare Medical Conditions with Machine Learning (희귀 질환 탐지 실습)

## 개요
- 불균형 데이터셋으로 희귀 질환을 탐지하는 방법을 배우는 핸즈온 랩 — SMOTE(Synthetic Minority Oversampling Technique)를 적용해 모델 성능을 개선하고, 정밀도·재현율·정밀도-재현율 곡선으로 결과를 평가함
- 헬스케어에서 정확도만으로는 충분하지 않은 이유와, 적절한 평가가 희귀하지만 중대한 상태를 신뢰성 있게 식별하는 모델을 만드는 데 어떻게 도움이 되는지 확인함

## 내용

### 랩 접근 방법
1. 랩 링크를 우클릭 → "Save link as…"로 `.ipynb` 파일을 로컬에 다운로드
2. Google Colab에서 열어 코드 주석을 먼저 읽고, 각 셀을 순서대로 실행
3. 파일 끝의 연습 문제에서 직접 코드를 작성·실행하며 이해도 점검
4. Colab이 처음이라면 "Lab Instructions for Google Colab" 가이드 참고
