# Evaluating Models with Precision-Recall and ROC (정밀도-재현율과 ROC를 통한 모델 평가)

## 개요
- 정밀도(precision)·재현율(recall)·F1 점수·ROC-AUC의 정의와, 희귀하고 위험도가 높은(high-stakes) 결과를 평가할 때 정밀도-재현율 곡선과 ROC 곡선을 사용하는 방법을 다루는 5분 33초 분량 영상

## 내용

### 정확도가 오도할 수 있는 이유
- 패혈증(sepsis) 예측 모델에서 환자의 5%만 패혈증을 앓고 있다고 가정하면, 모든 환자에게 "패혈증 없음"이라 예측해도 95%의 정확도가 나오지만 실제 사례는 모두 놓치게 됨 — 이는 헬스케어에서 흔한 데이터 불균형 상황에서 정확도가 얼마나 오해를 줄 수 있는지 보여줌

### 정밀도(precision)
- 예측된 양성 사례 중 실제 양성을 식별하는 정확도를 측정 — 모델이 경보를 울렸을 때 얼마나 자주 옳은지를 말해줌
- 예: AI 모델이 100건의 암 사례를 표시했는데 그중 60건이 맞았다면 정밀도는 0.60
- 높은 정밀도는 불필요한 후속 검사를 줄이고, 환자 불안을 최소화하며, 임상 자원을 절약함

### 재현율(recall, 민감도)
- 모델이 놓치는 환자는 어떻게 될까 — 이때 재현율(민감도, sensitivity라고도 함)이 필요함
- 재현율은 실제 양성 사례 중 모델이 성공적으로 식별한 비율을 측정 — 예를 들어 실제로 암에 걸린 환자가 80명이고 모델이 그중 60명을 탐지했다면 재현율은 0.75
- 높은 재현율은 놓치는 진단을 줄이는 반면, 낮은 재현율은 중요한 치료를 지연시키거나 막을 수 있음

### F1 점수 — 균형 잡기
- F1 점수는 정밀도와 재현율의 조화 평균(harmonic mean)으로, 둘을 동등하게 반영하는 단일 지표를 제공
- 예: 정밀도 0.60, 재현율 0.75일 때 F1 점수는 약 0.67
- 클래스가 불균형해 정확도만으로는 모델 품질을 반영하지 못할 때 특히 유용함

### 임계값(threshold) 선택의 영향
- 양성/음성 예측을 나누는 임계값을 바꾸면 정밀도와 재현율 사이의 균형이 이동함
- 임계값을 낮추면 재현율이 높아져 선별검사(screening)나 중증도 분류(triage) 작업에 도움이 됨
- 임계값을 높이면 정밀도가 높아져, 거짓 양성(false positive)의 비용이 큰 확진 검사(confirmatory testing)에 더 적합함
- 정밀도-재현율 곡선(precision-recall curve)은 이런 트레이드오프를 시각화하고 서로 다른 임계값에서 성능이 어떻게 변하는지 보여줌

### ROC 곡선과 ROC-AUC
- 모델이 양성과 음성 사례를 전반적으로 얼마나 잘 구분하는지 이해하기 위해 ROC 곡선을 사용 — 실제 양성률(재현율)을 거짓 양성률(1 − 특이도) 대비 도표로 그림
- ROC-AUC 값은 이 성능을 종합적으로 나타냄 — 값이 높을수록 모델이 실제 음성보다 실제 양성을 일관되게 더 높게 순위 매긴다는 뜻으로, 더 강한 구분 능력을 보여줌
- 두 폐렴 예측 모델을 비교한 예: 모델 A는 ROC-AUC 0.86, 모델 B는 0.78 — 모델 A가 환자를 위험도로 순위 매기는 데 더 나아 보임
- 하지만 질병 유병률이 2%처럼 매우 낮을 때는 정밀도-재현율 곡선이 더 명확한 그림을 줄 수 있음 — 모델 A가 평균 정밀도 0.25, 모델 B가 0.12를 기록한다면, 희귀 질환에서 모델 A가 더 나은 성능을 보이는 것

### 실제 평가 워크플로에 적용하기
- 견고한 평가는 교차 검증(cross-validation)과 정밀도·재현율·F1 점수·ROC-AUC·PR-AUC의 보고를 포함함
- 팀은 임상적으로 선택한 임계값에서의 혼동 행렬(confusion matrix)을 제시하고 그 트레이드오프를 설명함
- 예를 들어 패혈증 선별 모델은 놓치는 사례를 최소화하기 위해 재현율 0.90 이상을 우선시할 수 있고, 진단 모델은 오탐(false alarm)을 줄이기 위해 정밀도 0.90 이상을 목표로 할 수 있음

## 요약
- 정확도만으로는 결과가 불균형할 때 오해를 줄 수 있으며, 정밀도는 양성 경보의 정확성을, 재현율은 모델이 실제 사례를 얼마나 잘 식별하는지를, ROC 분석은 여러 임계값에 걸친 구분 능력을 각각 포착함
- 이 지표들을 함께 사용하면 헬스케어 환경에서 안전하고 신뢰성 있게 작동해야 하는 예측 모델을 평가하는 실용적이고 임상적으로 근거 있는 프레임워크가 됨
