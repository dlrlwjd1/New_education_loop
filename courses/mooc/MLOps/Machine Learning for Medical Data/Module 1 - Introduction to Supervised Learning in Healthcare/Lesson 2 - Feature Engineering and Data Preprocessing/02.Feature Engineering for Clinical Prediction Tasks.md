# Feature Engineering for Clinical Prediction Tasks (임상 예측을 위한 피처 엔지니어링)

## 개요
- 의료 데이터에서 **피처 엔지니어링(feature engineering)** 정의
- 데이터 유형별 핵심 전처리(preprocessing) 단계 식별
- **공정성(fairness)·신뢰성(reliability)**이 모델 설계에 미치는 영향 설명
- 핵심 통찰: 원시 데이터(raw data)는 전체 이야기를 거의 담지 못함 → 단순 측정값을 **임상적 의미를 가진 패턴**으로 전환
  - 예: 혈압 단일 측정값보다 "시간에 따른 혈압 변화"가 심장마비 예측에 더 정확

## 내용

### 피처 엔지니어링이란
- 원시 환자 데이터를 **임상적으로 관련된 예측 인자(clinically relevant predictors)**로 변환
- 예: 단일 크레아티닌(creatinine) 값 대신 → 24시간 내 최고치, 변화율(rate of change), 마지막 정상 수치 이후 경과 시간
- 의사들이 실제로 사고·추론하는 방식을 반영

### 의료 데이터의 3가지 유형
- **시계열(temporal)**: 시간에 따른 변화 — 활력징후, 검사 결과
- **범주형(categorical)**: 진단(diagnoses), 시술(procedures), 약물(medications)
- **연속형(continuous)**: 수치 측정값 — BMI, 혈압
- 각 유형은 임상 신호(clinical signal)를 유지하고 노이즈(noise)를 최소화하기 위해 **서로 다른 전처리** 필요

### 1. 시계열 피처 (Temporal Features)
- 환자 상태가 어떻게 변하는지 포착 → 단일 측정값보다 중요한 경우 많음
- 종류: 마지막 비정상 결과 이후 경과 시간, 변화율, 이동 평균(rolling averages), 변동성(variability)
- 예 (패혈증 예측): 6시간 심박수 추세, 12시간 락테이트(lactate) 피크, 마지막 항생제 투여 이후 경과 시간 → 질병 진행·치료 반응 반영
- **불규칙 도착 데이터 대응**: 병원 데이터는 정해진 일정에 도착하지 않음
  - 마지막 측정 이후 경과 시간(time since last measurement)과 **결측 플래그(missing data flag)** 활용
  - 결측 자체가 임상적으로 중요한 신호일 수 있음 → ICU 예측 성능 향상

### 2. 범주형 데이터 (Categorical Data)
- 작은 집합 (예: 성별): 단순 **원-핫 인코딩(one-hot encoding)**으로 충분
- 큰 집합 (예: ICD-10 코드): 유사 질환을 **임상 카테고리로 그룹화** → 단순하면서도 의미 있는 데이터 유지

### 3. 연속형 데이터 (Continuous Data)
- 극단값(extreme)이나 치우친 값(skewed)이 예측을 왜곡
- 관리 방법:
  - **임상 임계값(clinical thresholds)**에서 이상치(outlier) 캡핑(capping)
  - 스케일 표준화(standardize scales)
  - 심하게 치우친 값에 **로그 변환(log transformation)**
- → 모든 변수가 모델 학습에 공정하게 기여

### 복합 피처 (Composite Features)
- 임상 전문성(clinical expertise)을 활용해 결합 피처 생성
- 예: **쇼크 지수(shock index)**, **호중구-림프구 비율(neutrophil-to-lymphocyte ratio)**
- 재입원 예측: 활력징후 변동성 + 약물 변경(medication changes) 결합 → 임상의가 직관적으로 인식하는 환자 안정성 패턴 포착

### 데이터 누수 방지 (Data Leakage Prevention)
- **데이터 누수(data leakage)**: 예측 시점에 사용 불가능한 정보를 피처에 포함하는 문제 → "미래를 엿보게 하는 것"
- 방지법:
  - **예측 시점 이전에 기록된 데이터만** 사용
  - 중복·과잉(redundant) 변수 제거
  - **정규화(regularization)**로 진짜 예측 신호에 집중

### 신뢰성·공정성 확보 (Reliability & Fairness)
- 변환(transformation)은 **훈련 데이터에만** 적용 → 동일 단계를 검증/테스트 세트에 복제
- 각 변환을 문서화 → 투명성(transparency) 지원
- 모델 평가 기준:
  - **보정(calibration)** — 확률의 정확성
  - **판별력(discrimination)** — 고위험 vs 저위험 순위
  - **공정성(fairness)** — 환자 그룹 간 성능

## 요약
- 피처 엔지니어링은 원시 환자 데이터를 의미 있는 임상 신호로 변환해 예측을 개선
- **시계열·범주형·연속형** 데이터는 각각 고유한 전처리 단계 필요
- 추세·결측·변동성이 조기 위험 패턴을 드러내고, 임상 전문성이 쇼크 지수 같은 복합 피처를 생성
- **데이터 누수 방지**와 모델 설계의 **공정성·신뢰성** 확보가 핵심
