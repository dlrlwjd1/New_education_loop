### Step 3: 통계적 이상치 탐지 — IQR vs Z-Score
- **IQR 방법**: IQR = Q3 − Q1, 이상치는 Q1 − 1.5×IQR 미만 또는 Q3 + 1.5×IQR 초과 — 정규분포가 아닌 데이터에 강건함(비대칭성에도 안정적)
- **Z-Score 방법**: Z = (값 − 평균) / 표준편차, |Z| > 3이면 이상치 — 정규분포 데이터에 적합

```python
def iqr_outliers(series):
    q1 = series.quantile(0.25)
    q3 = series.quantile(0.75)
    iqr = q3 - q1
    lower_bound = q1 - 1.5 * iqr
    upper_bound = q3 + 1.5 * iqr
    return series[(series < lower_bound) | (series > upper_bound)]

age_outliers = iqr_outliers(df['Age'].dropna())
glucose_outliers = iqr_outliers(df['Glucose_mg_dL'].dropna())
```

df_clean['Gender'] = df_clean['Gender'].astype(str).str.strip().str.lower()

### Step 7: 단위 정규화 및 BMI 피처 엔지니어링
- BMI = 체중(kg) / 신장(m)² — 저체중 <18.5 / 정상 18.5~24.9 / 과체중 25~29.9 / 비만 ≥30
```python
def weight_to_kg(x):
    """숫자(kg으로 가정) 또는 'lbs' 접미사가 붙은 문자열을 kg으로 변환"""
    if pd.isna(x):
        return np.nan
    if isinstance(x, (int, float, np.integer, np.floating)):
        return float(x)
    s = str(x).strip().lower()
    match = re.match(r'^\s*([0-9]+(?:\.[0-9]+)?)\s*lbs?\s*$', s)
    if match:
        return round(float(match.group(1)) * 0.45359237, 2)
    try:
        return float(s)
    except:
        return np.nan

df_clean['Weight_kg'] = df_clean['Weight'].apply(weight_to_kg)
df_clean['Height_cm'] = pd.to_numeric(df_clean['Height_cm'], errors='coerce')
df_clean['Height_m'] = df_clean['Height_cm'] / 100.0

df_clean['BMI'] = df_clean.apply(
    lambda row: round(row['Weight_kg'] / (row['Height_m'] ** 2), 2)
    if pd.notna(row['Weight_kg']) and pd.notna(row['Height_m']) and row['Height_m'] > 0
    else np.nan, axis=1)
```

### Step 8: 결측값 대체(imputation) — 왜 중앙값(median)인가
- **이상치에 강건함**: 헬스케어 데이터엔 극단값(매우 높은 혈당, 비정상 나이)이 흔함
- **평균은 민감함**: 소수의 극단값이 평균을 크게 왜곡할 수 있음
- **중앙값은 중심을 대표**: 정렬된 데이터의 가운데 값으로 극단값의 영향을 받지 않음
- **분포 보존**: 비대칭 분포의 형태를 더 잘 유지함
```python
numeric_cols = ['Age', 'Weight_kg', 'Height_cm', 'BMI', 'Glucose_mg_dL']
for col in numeric_cols:
    median_val = df_clean[col].median()
    df_clean[col] = df_clean[col].fillna(median_val)
```

### Step 10: 범주형 변수 인코딩 — 원-핫 인코딩(one-hot encoding)
- 각 범주마다 이진(0/1) 컬럼을 생성 — 예: Diagnosis_Code가 ['DEP','OCD','ANX']라면 `Diagnosis_Code_DEP`, `Diagnosis_Code_OCD`, `Diagnosis_Code_ANX` 컬럼 생성, 'OCD' 환자는 [0,1,0]
- 모든 범주를 동등하게 취급(암묵적 순서 없음), 모든 ML 알고리즘에서 작동, 범주 간 수치적 관계를 가정하지 않도록 방지
- 대안: 순서(ordinal)가 있는 데이터에는 레이블 인코딩(1,2,3…) 사용
```python
df_final = pd.get_dummies(
    df_clean, columns=['Diagnosis_Code', 'Gender', 'Ethnicity'], drop_first=False)
```

### Step 11: 수치형 피처 스케일링
- 스케일링이 필요한 이유: 예) Age(0~100)와 Glucose(70~500) — 스케일링 없이는 값이 큰 피처에 더 큰 가중치가 실릴 수 있음
- 영향받는 알고리즘: 로지스틱 회귀, SVM, KNN, 신경망, K-평균 / 영향받지 않는 알고리즘: 트리 기반 모델(결정 트리, 랜덤 포레스트, XGBoost)
- **StandardScaler(Z-score 정규화)**: z = (x − μ) / σ, 평균=0·표준편차=1로 변환 — 정규분포를 가정하는 알고리즘(선형/로지스틱 회귀, SVM)에 적합
```python
numeric_cols_to_scale = ['Age', 'Weight_kg', 'Height_cm', 'BMI', 'Glucose_mg_dL', 'Days_Since_Diagnosis']
numeric_cols_existing = [c for c in numeric_cols_to_scale if c in df_final.columns]

df_final[numeric_cols_existing] = df_final[numeric_cols_existing].fillna(
    df_final[numeric_cols_existing].median())

scaler = StandardScaler()
scaled_columns = [col + '_scaled' for col in numeric_cols_existing]
df_final[scaled_columns] = scaler.fit_transform(df_final[numeric_cols_existing])
```

## 요약
- PII 제거 → 중복 제거 → 범주형 표준화 → 단위 정규화·BMI 엔지니어링 → 중앙값 대체(median imputation) → 날짜 파싱·시간 피처 → 원-핫 인코딩 → 표준화(StandardScaler) → 저장, 순서로 이어지는 헬스케어 데이터 전처리 파이프라인의 표준 흐름을 실습
- 헬스케어 데이터에서는 극단값에 강건한 **중앙값 대체**가 평균 대체보다 선호되며, PII 제거는 HIPAA·GDPR 준수의 첫 단계
