# Preprocessing Medical Data Best Practices (의료 데이터 전처리 모범 사례)

## 개요
- 임상 데이터의 **프로파일링(profiling)·정제(cleaning)·표준화(standardization)** 핵심 단계 정의
- **결측 데이터(missing data)** 처리 및 데이터 유효성(validity) 확보 기법 식별
- **프라이버시 보호(privacy protection)**와 **문서화(documentation)**가 신뢰할 수 있는 전처리를 어떻게 지원하는지 설명
- 핵심: 전자건강기록(EHR)은 구조화 필드 + 자유 텍스트(free text) + 여러 코딩 체계 + 일관성 없는 타임스탬프 → 전처리로 정돈

## 내용

### 1. 데이터 프로파일링 (Data Profiling)
- 첫 번째 단계 — 데이터셋 전반의 **완전성(completeness)·분포(distributions)·단위(units)·코딩 체계** 점검
- 간단한 감사(audit)만으로도 비현실적 나이, 중복 방문(duplicate encounters), 혼재된 측정 단위 등 문제 발견
- 베이스라인(baseline) 파악 → 정제 우선순위 설정 및 자원 배분에 활용

### 2. 결측 데이터 처리 (Handling Missing Data)
- 임상 데이터의 세 가지 결측 유형(missingness):
  - **MCAR (Missing Completely At Random)** — 완전 무작위 결측
  - **MAR (Missing At Random)** — 무작위 결측 (다른 관측 변수에 의존)
  - **MNAR (Missing Not At Random)** — 비무작위 결측 → **실제 데이터에서 가장 흔함**
- MNAR 예시: 환자 조기 퇴원으로 활력징후 누락, 임상의가 불필요하다고 판단해 검사 미실시
- 결측 패턴 인식이 중요 → **대체(imputation) 전략**을 안내하고, **결측 자체가 임상적 신호(clinical signal)**인지 판단

### 3. 대체 (Imputation)
- **안정적 필드(stable fields)**: 중앙값 대체(median replacement) 같은 단순 방법으로 충분 (예: 크레아티닌 creatinine)
- **변동성 큰 신호**: **모델 기반 대체(model-based imputation)**가 효과적
  - 예: 나이·성별·약물 계열(medication class)·최근 활력징후로 수축기 혈압(systolic BP) 추정
- 대체한 항목은 **이진 지시자(binary indicator)**로 플래그 → 모델이 적절히 반영하도록

### 4. 표준화 (Standardization)
- 단위·코드 불일치에서 오류 발생 → 일관성(consistency) 유지가 핵심
- **검증된 변환 계수(validated conversion factors)**로 모든 측정값 변환
- 타임스탬프는 **UTC + 명시적 시간대(time zone)**로 저장
- 기관 코드를 표준에 매핑:
  - **LOINC** (Logical Observation Identifiers Names and Codes) — 검사(lab tests)
  - **SNOMED-CT** (Systematized Nomenclature of Medicine, Clinical Terms) — 진단(diagnoses)
- **원본 값과 표준화 값 모두 보존** → 감사 가능성(auditable) 유지

### 5. 자동 검증 (Automated Validation)
- 타입 검사(type checks), 임상 범위 검증(clinical range validation), 필드 간 논리 규칙(logical rules) 적용
- 예: 퇴원 시각은 항상 입원 시각 이후, 임신 코드는 남성 성별 지시자와 함께 나타나면 안 됨
- 방문(encounters)·약물(medications)·검사(labs) 간 **참조 무결성(referential integrity)**으로 데이터 일관성 확보

### 6. 프라이버시 보호 (Privacy Protection)
- **HIPAA** 등 규제가 강력한 보호 장치 요구
- 비식별화(de-identification): **Safe Harbor** 또는 **전문가 결정(expert determination)** 방법
- 가명화된 환자 식별자(pseudonymized identifiers), 역할 기반 접근 제어(role-based access control), 전체 감사 로그(audit logs)
- 협업 프로젝트: **차등 프라이버시(differential privacy)** 기법 또는 데이터 사용 협약(data use agreement) 하의 제한된 데이터셋(limited datasets)

### 7. 문서화 (Documentation)
- 재현성(reproducibility)과 책임성(accountability) 보장
- 단위·범위·코드 매핑을 포함한 상세 **데이터 사전(data dictionary)** 설계
- 데이터 정제 파이프라인 **버전 관리(versioning)**
- 원본 입력 → 최종 피처까지 **데이터 계보(data lineage)** 추적
- 조기 문제 탐지를 위한 자동 테스트(automated tests) 구비 → 회귀(regression) 방지

### 모델링용 데이터 준비 (Preparing Data for Modeling)
- 범주형 변수(categorical variables) 일관 인코딩
- 수치형 피처(numerical features) 적절한 스케일링(scaling)
- 시간 윈도(temporal windows)를 예측 시점(prediction time points)에 정렬
- 처리된 피처는 **거버넌스된 저장소(governed repository)**에 보관 → 전통 ML과 최신 AI 모두에 표준화·신뢰 가능한 입력 제공

## 요약
- 효과적 전처리는 **프로파일링**으로 시작 → 체계적 **결측 데이터 처리**로 확장
- **표준화**는 숨은 오류를 방지하고, **검증·중복 제거(deduplication)·문서화**는 신뢰성을 강화
- 무엇보다 **프라이버시·공정성(fairness)·누수 방지(leakage prevention)**가 신뢰받는 임상 모델 구축의 핵심
