# Data Preparation Guidelines for Healthcare ML (헬스케어 ML 데이터 준비 가이드라인)

> Reading 자료 — 원문: https://advanced-machine-learning-for-medical-data-8e1579.gitlab.io/readings/Data-Preparation-Guidelines-for-Healthcare-ML.md.html

## 개요
- 헬스케어 조직이 의료 데이터를 머신러닝(machine learning)용으로 준비하는 방법을 다룸
- 체계적인 **감사(auditing)·정제(cleaning)·검증(validation)** 프로세스 중심

## 내용

### 헬스케어 데이터의 주요 과제 (Key Challenges)
- 정보가 여러 시스템에 흩어져 있고(scattered), 각 시스템이 서로 다른 코딩 표준(coding standards)·타임스탬프·포맷 사용
- 검사값(laboratory values)의 단위가 일관되지 않음
- 활력징후(vital signs)가 불규칙하게 기록됨
- 임상 문서(clinical documentation)에 표준화 부재

### 핵심 준비 단계 (Core Preparation Steps)

**1. 감사 (Auditing)**
- 모든 데이터 출처 식별: EHR(전자건강기록), 검사(labs), 청구 데이터(claims)
- 환자 기록 간 연결 매핑
- 프라이버시 준수(privacy compliance) 보장

**2. 조화 (Harmonization)**
- 서로 다른 코딩 체계 통합
- 예: 버전 간 진단 코드(diagnosis codes) 변환
- 검사 측정값을 **생물학적으로 타당한 범위(biologically reasonable ranges)**로 표준화

**3. 결측 데이터 전략 (Missing Data Strategy)**
- 결측값은 종종 **임상적 의미(clinical meaning)**를 내포
- 적절한 처리 방법 선택 전에 **결측 유형 분류** 필요

**4. 이상치·중복 관리 (Outlier and Duplicate Management)**
- 인체의 타당한 한계를 벗어난 값 → 전문가 검토(expert review)를 위해 플래그
- 중복 항목 → 여러 식별자(multiple identifiers)를 사용해 해소

**5. 데이터 분할 (Data Splitting)**
- 방문(encounter)이 아닌 **환자(patient) 단위로 분할** → 데이터 누수(data leakage) 방지
- **시간적 접근(temporal approaches)** 사용 → 현실적인 성능 추정치 산출

**6. 변수 인코딩 (Encoding Variables)**
- 범주형 피처(categorical features)를 **더 넓은 임상 카테고리(broader clinical categories)**로 그룹화 → 해석 가능성(interpretability) 유지

### 필수 감독 (Essential Oversight)
- 품질 보증(quality assurance): 자동 검증(automated validation) + **임상 전문가의 모든 정의·변환 검토**
- 재현성(reproducibility)과 규제 투명성(regulatory transparency)을 가능케 하는 **문서화(documentation)**로 프로세스 완성

## 요약
- 헬스케어 데이터는 분산·비표준화된 특성 때문에 고유한 준비 과제를 가짐
- 핵심 흐름: **감사 → 조화 → 결측 처리 → 이상치/중복 관리 → 데이터 분할 → 인코딩**
- 데이터 누수 방지를 위해 **환자 단위 + 시간적 분할** 사용
- 자동 검증과 **임상 전문가 검토**, 그리고 문서화가 신뢰할 수 있는 데이터 준비를 완성
