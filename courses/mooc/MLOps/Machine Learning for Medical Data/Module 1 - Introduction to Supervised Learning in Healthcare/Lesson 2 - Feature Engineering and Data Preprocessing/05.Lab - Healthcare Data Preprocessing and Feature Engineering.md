# Lab: Healthcare Data Preprocessing and Feature Engineering (헬스케어 데이터 전처리·피처 엔지니어링 실습)

## 개요
- 실제와 유사한 전자의무기록(EHR, electronic health record) 시뮬레이션 데이터를 정제·표준화해 머신러닝에 사용할 수 있게 준비하는 핸즈온 랩
- 결측값(missing values)·중복(duplicates)·형식 불일치를 처리하고, 개인식별정보(PII)를 제거해 프라이버시를 준수하며, BMI·시간 기반 지표 같은 의미 있는 피처를 엔지니어링함
