# Lab: Using Gradio to Deploy Machine Learning Models (Gradio를 이용한 모델 배포 실습)

## 개요
- Gradio를 사용해 머신러닝 모델을 배포하는 법을 배우는 핸즈온 랩 — 합성 키·몸무게 데이터로 BMI 분류 모델을 훈련하고, 사용자가 값을 입력해 즉각적인 예측을 받을 수 있는 인터랙티브 웹 인터페이스를 구축함
- 모델 배포의 핵심을 소개하며, AI 도구가 실제 헬스케어 환경에서 어떻게 접근 가능하고 유용하게 만들어질 수 있는지 보여줌

## 내용

### 랩 접근 방법
1. 랩 링크를 우클릭 → "Save link as…"로 `.ipynb` 파일을 로컬에 다운로드
2. Google Colab에서 열어 코드 주석을 먼저 읽고, 각 셀을 순서대로 실행
3. 파일 끝의 연습 문제에서 직접 코드를 작성·실행하며 이해도 점검
4. Colab이 처음이라면 "Lab Instructions for Google Colab" 가이드 참고
