df = pd.read_csv("https://advanced-machine-learning-for-medical-data-8e1579.gitlab.io/labs/lab4/patient_dataset.csv")
df.head()

### Step 3: 전처리 — 왜 필요한가
- **결측값 처리**: ML 알고리즘은 결측 데이터를 처리할 수 없음 — 수치형은 평균 대체, 범주형은 최빈값(mode) 대체
- **범주형 인코딩**: K-평균은 유클리드 거리를 사용하므로 모든 피처가 수치형이어야 함 — 원-핫 인코딩으로 "Urban"/"Rural" 같은 범주를 이진 컬럼으로 변환
- **표준화**: 범위가 큰 피처(예: 콜레스테롤 120~300)가 범위가 작은 피처(예: 성별 0~1)보다 거리 계산을 지배하는 것을 방지 — 표준화로 모든 피처가 동등하게 기여하도록 보장
```python
# 3.1 수치형/범주형 컬럼 분리
numeric_cols = df.select_dtypes(include=['int64', 'float64']).columns
categorical_cols = df.select_dtypes(include=['object', 'category']).columns

# 3.2 결측값 대체 (수치형=평균, 범주형=최빈값)
df[numeric_cols] = df[numeric_cols].fillna(df[numeric_cols].mean())
df[categorical_cols] = df[categorical_cols].fillna(df[categorical_cols].mode().iloc[0])

# 3.3 원-핫 인코딩 (drop_first=True로 다중공선성 방지)
df_encoded = pd.get_dummies(df, columns=categorical_cols, drop_first=True)

# 3.4 StandardScaler로 수치형 피처 표준화 (평균=0, 표준편차=1)
scaler = StandardScaler()
df_scaled = scaler.fit_transform(df_encoded)
df_scaled = pd.DataFrame(df_scaled, columns=df_encoded.columns)
```

### Step 4: K-평균 클러스터링 적용
- K-평균 작동 원리: (1) K개의 중심점(centroid)을 무작위(혹은 k-means++로 스마트하게) 초기화 → (2) 각 데이터 포인트를 가장 가까운 중심점에 할당 → (3) 각 클러스터 내 포인트의 평균으로 중심점을 갱신 → (4) 중심점이 더 이상 이동하지 않을 때까지(수렴할 때까지) 2~3단계 반복
- 주요 파라미터: `n_clusters`(클러스터 수 K, 이 랩에서는 3), `init='k-means++'`(스마트 초기화로 수렴 개선), `max_iter`(최대 반복, 보통 300이면 충분), `n_init`(서로 다른 초기 중심점으로 실행하는 횟수, 기본 10), `random_state`(재현성)
```python
optimal_k = 3
kmeans = KMeans(n_clusters=optimal_k, init='k-means++', max_iter=300, n_init=10, random_state=42)
df_scaled['Cluster'] = kmeans.fit_predict(df_scaled)
print(df_scaled['Cluster'].value_counts().sort_index())
```

### Step 5: 클러스터 특성 분석
- 각 클러스터의 피처 평균값을 확인해 "어느 클러스터가 더 고령인가", "어느 클러스터가 콜레스테롤이 높은가", "어느 클러스터가 더 많은 위험 요인과 연관되는가" 같은 질문에 답할 수 있음 — 이 통찰은 맞춤형 헬스케어 개입을 설계하는 데 활용됨
```python
cluster_summary = df_scaled.groupby('Cluster').mean()  # 표준화된 값(양수=평균 이상, 음수=평균 이하)

df['Cluster'] = df_scaled['Cluster']         # 원본 데이터프레임에 클러스터 정보 복사
df.groupby('Cluster').mean(numeric_only=True)  # 원본 스케일 기준 클러스터 요약
```

### Step 6: PCA로 클러스터 시각화
- 인코딩 후 16개 이상의 피처를 가진 고차원 공간은 시각화가 불가능함 — PCA는 데이터에서 분산이 가장 큰 방향(주성분)을 찾아 차원을 축소하면서도 가장 중요한 패턴을 보존함
- 첫 두 주성분(PC1, PC2)이 가장 중요한 패턴을 포착해 2D 시각화를 가능하게 함
```python
pca = PCA(n_components=2)
principal_components = pca.fit_transform(df_scaled.drop('Cluster', axis=1))

df_pca = pd.DataFrame(data=principal_components, columns=['PC1', 'PC2'])
df_pca['Cluster'] = df_scaled['Cluster'].values

plt.figure(figsize=(8, 6))
sns.scatterplot(x='PC1', y='PC2', hue='Cluster', data=df_pca, palette='viridis', s=50, alpha=0.7)
plt.title("PCA Visualization of K-means Clusters")

print(f"PC1 설명 분산: {pca.explained_variance_ratio_[0]:.2%}")
print(f"PC2 설명 분산: {pca.explained_variance_ratio_[1]:.2%}")
```

## 요약
- 결측값 대체·원-핫 인코딩·표준화라는 전처리 3단계 → K-평균(K=3)으로 클러스터링 → 클러스터별 평균값으로 특성 분석 → PCA로 2D 시각화, 순서로 이어지는 표준적인 환자 세분화 파이프라인을 실습
- 표준화는 큰 범위의 피처가 거리 계산을 지배하는 것을 막고, PCA는 고차원 클러스터링 결과를 해석 가능한 2D 산점도로 압축함
- 연습 문제는 동일 파이프라인을 뇌졸중 위험 데이터셋(age, avg_glucose_level, bmi 3개 피처, K=2)에 적용
