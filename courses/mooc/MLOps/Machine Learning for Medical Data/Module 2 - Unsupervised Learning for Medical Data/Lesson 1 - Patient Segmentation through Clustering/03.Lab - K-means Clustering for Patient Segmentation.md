# Lab: K-means Clustering for Patient Segmentation (K-평균 클러스터링 실습)

## 개요
- 시뮬레이션 헬스케어 데이터셋으로 K-평균 클러스터링을 수행해 환자를 건강 프로필에 따라 뚜렷한 하위 집단으로 그룹화하는 핸즈온 랩
- 데이터를 전처리하고, 엘보우 기법(elbow method)으로 최적의 클러스터 개수를 결정하며, 주성분분석(PCA)으로 결과를 시각화해 의미 있는 패턴을 드러냄
