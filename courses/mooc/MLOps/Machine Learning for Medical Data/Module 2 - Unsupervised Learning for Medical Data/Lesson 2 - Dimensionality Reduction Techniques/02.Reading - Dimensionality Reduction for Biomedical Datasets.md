# Reading: Dimensionality Reduction for Biomedical Datasets (생의학 데이터셋을 위한 차원 축소)

## 개요
- PCA·t-SNE·UMAP 세 가지 핵심 차원 축소 기법이 고차원 생의학 데이터를 시각화·해석·활용하는 데 어떻게 도움을 주는지 다루는 4분 분량 읽기자료

## 내용

### 차원 축소가 중요한 이유
- 생의학 데이터셋은 흔히 수만 개의 측정값(검사 결과, 유전자 발현, 영상 피처, 활력징후)을 포함함 — 이런 데이터는 고차원(high-dimensional)이며, 각 기록마다 변수는 많지만 변수당 관측치는 상대적으로 적음
- 희소성(sparsity, 대부분의 데이터 포인트가 0이거나 결측인 상태)도 흔함 — 예를 들어 유전자 발현 데이터셋은 5만 개 세포에 걸쳐 3만 개 유전자를 측정하지만, 어느 특정 세포에서 활성화된 유전자는 극히 일부에 불과함. 희소성은 대부분의 전통적 알고리즘이 텅 비거나 거의 비어 있는 수많은 차원 사이에서 의미 있는 관계를 찾기 어렵게 만듦
- 차원 축소는 정보를 더 적은 수의 성분이나 임베딩으로 요약해 노이즈를 걸러내면서도 데이터의 본질을 보존함으로써 이 문제를 해결함

### PCA — 빠르고 해석 가능함
- PCA는 차원 축소의 고전적인 출발점 — 상관된 변수들을 데이터에서 최대 분산의 방향을 포착하는 더 적은 수의 새롭고 독립적인 주성분으로 변환함
- 헬스케어에서는 혈당·콜레스테롤·혈압 같은 여러 검사 결과를 하나의 "대사 건강" 성분으로 압축할 수 있음 — 주요 경향을 보존하면서 분석을 단순화함
- PCA는 속도·안정성·해석 가능성으로 가치를 인정받음 — 대규모 데이터셋에서도 빠르게 실행되고 일관되고 재현 가능한 결과를 만들어냄. 각 성분에는 어떤 원본 피처가 가장 많이 기여하는지 보여주는 로딩이 딸려 있어 연구자가 생물학적 의미를 이해하는 데 도움을 줌
- 다만 PCA는 선형 관계를 가정하므로 데이터의 곡선형이나 복잡한 구조를 간과할 수 있음 — 이때 t-SNE나 UMAP 같은 비선형 방법이 더 유용해짐

### t-SNE — 지역적 구조를 드러냄
- t-SNE는 질환 내 하위 유형을 식별하는 것처럼 세밀한 관계를 탐구할 때 빛을 발함 — 지역적 이웃 관계를 보존해, 가까이 있던 데이터 포인트가 축소된 공간에서도 가까이 남도록 하여 미묘한 생물학적 구분을 시각화하는 데 이상적임
- 예: 단일세포 RNA 시퀀싱에서 t-SNE는 전통적 방법이 뭉뚱그려버리는 면역세포 하위 집단을 분리할 수 있음 — 연구자는 이후 서로 다른 세포 유형이나 질병 상태를 나타내는 클러스터에 라벨을 붙일 수 있음
- 트레이드오프는 t-SNE가 종종 전역적 구조를 잃는다는 것 — 멀리 떨어진 클러스터 사이의 거리가 항상 실제 관계를 반영하지는 않고, 실행할 때마다 결과가 약간씩 달라질 수 있음. 그럼에도 유전체학과 영상에서 패턴 발견을 위한 강력한 탐색 도구로 남아 있음

### UMAP — 지역적 패턴과 전역적 패턴의 균형
- UMAP은 PCA와 t-SNE의 강점을 결합함 — t-SNE처럼 지역적 관계를 보존하면서도, 클러스터들이 어떻게 연결되는지 보여줄 만큼 충분한 전역적 구조도 유지함
- 더 빠르고, 수백만 개의 샘플로도 잘 확장되며, t-SNE에는 없는 새 데이터에 대한 일관된 변환을 허용함 — UMAP은 인접한 데이터 포인트들의 그래프를 만들고 그 레이아웃을 최적화해 의미 있는 관계를 유지하는 방식으로 작동함
- 예: 방사선 영상을 분석할 때 UMAP은 정상 스캔부터 진행된 병리까지 질병 중증도의 연속체를 따라 사례를 정리해, t-SNE라면 조각내버릴 수도 있는 점진적 전환을 드러낼 수 있음
- UMAP을 조정하는 데는 이웃 수(뷰가 얼마나 지역적인지)와 최소 거리(클러스터가 얼마나 촘촘히 형성되는지) 같은 파라미터가 관여함 — 이 값들을 조정하면 세부사항과 가독성 사이의 균형을 맞추는 데 도움이 됨

### 적절한 기법 선택하기
- PCA·t-SNE·UMAP 중 선택하는 것은 목표와 데이터 유형에 따라 다름
  - **PCA**는 검사·EHR 데이터처럼 선형적이고 해석 가능한 관계에 가장 적합함
  - **t-SNE**는 연구 탐색에서 작고 의미 있는 클러스터를 발견하는 데 뛰어남
  - **UMAP**은 지역적 세부사항과 전역적 연속성을 모두 갖춘 확장 가능한 시각화를 제공함
- 대부분의 생의학 워크플로는 먼저 PCA로 노이즈를 줄인 뒤, 시각화와 하위 그룹 발견을 위해 UMAP이나 t-SNE를 적용함 — 이 조합은 계산 효율성과 과학적 통찰 사이의 균형을 맞추는 데 도움을 줌

### 생의학 데이터를 위한 모범 사례
- 어떤 방법을 적용하든 데이터를 신중히 준비해야 함 — 연속값(검사 단위 등) 정규화, 진단·투약 같은 범주형 변수의 숫자 인코딩, 결측값의 대체 또는 플래그 처리, 희소한 데이터셋의 로그 변환(낮은 카운트를 비교 가능하게 만듦)
- 모든 전처리 단계를 문서화해 재현성을 확보하고 환자 데이터의 윤리적 처리를 보장할 것 — 차원 축소는 임상적으로 의미 있는 발견을 흐리게 하는 것이 아니라 뒷받침해야 함

### 핵심 요점
- 차원 축소를 활용해 고차원 생의학 데이터를 해석 가능하고 실행 가능하게 만들 것
- PCA를 빠르고 선형적인 요약과 초기 노이즈 감소에 적용할 것
- t-SNE나 UMAP을 지역적 패턴, 희귀 하위 그룹, 질병 진행 경로를 발견하는 데 사용할 것
- 로그 변환과 변수 선택 같은 전처리 단계로 희소성을 다뤄 모델 안정성을 개선할 것
- 통계적 검증과 임상적 해석을 결합해 축소된 피처가 실제 생물학적 의미를 반영하도록 확인할 것
