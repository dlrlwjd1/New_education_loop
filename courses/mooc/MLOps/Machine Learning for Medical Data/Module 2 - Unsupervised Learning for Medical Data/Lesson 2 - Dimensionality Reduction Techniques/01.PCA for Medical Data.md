# PCA for Medical Data (의료 데이터를 위한 PCA)

## 개요
- 주성분분석(PCA)이 어떻게 데이터를 단순화하는지, 다양한 머신러닝 모델을 어떻게 지원하는지, 헬스케어 분석에서 PCA를 효과적으로 사용하는 핵심 단계를 다루는 5분 5초 분량 영상 — Module 2 "Lesson 2 - Dimensionality Reduction Techniques"의 첫 영상

## 내용

### PCA란 — 압도적인 데이터를 다루는 법
- 유전학 연구자가 500명의 암 환자로부터 얻은 2만 개의 유전자 발현 값이 담긴 스프레드시트를 보고 있다면, 이렇게 압도적인 데이터에서 어떻게 패턴을 찾을 수 있을까
- 주성분분석(PCA)은 변수를 가장 의미 있는 변동을 포착하는 소수의 성분(component)으로 축소함 — 이 변환은 데이터를 탐색·시각화·모델링하기 훨씬 쉽게 만듦
- PCA는 상관된 변수들을 데이터에서 최대 분산을 포착하는 새롭고 독립적인 성분으로 변환함 — 예를 들어 여러 혈압·콜레스테롤 측정치가 하나의 심혈관 위험 성분으로 결합될 수 있음. 이 성분들은 데이터셋의 변동을 가장 잘 요약하는 방향을 나타냄

### PCA 적용 전 데이터 준비
- 의료 데이터는 흔히 서로 다른 척도가 뒤섞여 있음 — 혈압(mmHg), 콜레스테롤(mg/dL), 나이(년) 등. PCA는 모든 피처가 비슷한 척도에 있을 때 가장 잘 작동함
- Z-점수를 사용한 표준화는 모든 피처를 같은 수준으로 맞춰, 큰 척도의 측정값이 작은 척도의 측정값을 압도하는 것을 방지함
- 데이터를 표준화한 뒤에는 몇 개의 성분을 유지할지 선택하고, 설명된 분산 비율(explained variance ratio)을 확인해 전체 분산의 90~95%를 목표로 함 — 교차 검증을 사용하고 환자 표본 전반에서 성분의 안정성을 테스트할 것

### 성분이 나타내는 것 이해하기
- PCA를 실행한 뒤에는 각 성분이 무엇을 나타내는지 이해하는 것이 신뢰를 쌓음 — 성분 로딩(component loadings)은 각 원본 변수가 얼마나 기여하는지 보여줌
- 예를 들어 한 성분이 헤모글로빈·헤마토크릿·적혈구 수를 결합해 산소 운반 능력을 나타낼 수 있음 — 성분에 익숙한 임상 용어로 라벨을 붙이면 의사가 결과를 해석하고 측정 문제를 발견하는 데 도움이 됨

### PCA가 모델 학습을 돕는 방식
- PCA는 중복된 정보를 제거해 모델이 효율적으로 학습하도록 도움 — 선형 모델은 PCA가 다중공선성(multicollinearity)을 줄여주기 때문에 이득을 얻음
- K-평균 클러스터링이나 K-최근접 이웃(KNN) 같은 거리 기반 알고리즘도 PCA가 노이즈를 걸러내고 데이터를 의미 있는 차원으로 정렬해주기 때문에 더 나은 성능을 보임
- 예: 패혈증 위험을 예측하는 병원이 수백 개의 원시 검사 값 대신 20개의 PCA 유래 성분으로 모델을 훈련할 수 있음

### PCA가 잘 작동했는지 확인하기
- 처음 두세 개 성분의 산점도는 환자 하위 그룹, 데이터 입력 오류, 측정 아티팩트 같은 패턴을 드러냄 — 질병 라벨을 겹쳐 그룹이 어떻게 다른지 볼 수 있지만, 처음 몇 개 성분이 모든 것을 포착하지 못할 수도 있다는 점을 기억할 것 — 중요한 변동이 그 상위 차원들 너머에 존재할 수도 있음

### PCA를 신뢰성 있게 구현하기
- 항상 데이터셋을 먼저 분할한 뒤, 표준화와 PCA 모두를 훈련 데이터에만 적합(fit)시킬 것 — 같은 적합된 변환을 재적합 없이 검증·테스트 데이터에 적용할 것
- 성분이 병원·장비·인구통계와 관련된 차이를 의도치 않게 포착하지 않는지도 확인할 것 — 만약 그렇다면 조화(harmonization)를 적용하거나 이후 모델에서 그 변수들을 보정할 것

### PCA가 빛을 발하는 영역
- PCA는 복잡하고 고차원적인 헬스케어 데이터에서 빛을 발함 — 유전체학(genomics), 영상, 지속적인 환자 모니터링 모두 수천 개의 변수를 생성함
- PCA는 이를 주요 생물학적·임상적 신호를 여전히 반영하는 관리 가능한 피처 집합으로 압축해, 모델링과 해석을 훨씬 효율적으로 만듦
- PCA는 예측 모델의 입력을 압축하고, 환자 클러스터 시각화를 돕고, 후속 연구를 위한 피처를 생성하는 등 다양한 워크플로를 지원함 — 어떤 용도로 쓰든, 효율성과 임상적 관련성 사이의 균형을 맞춰 축소 과정에서 희귀하지만 중요한 패턴이 사라지지 않도록 할 것

## 요약
- PCA는 크고 상관된 데이터셋을 의료 데이터의 주요 변동을 포착하는 더 작은 독립 성분 집합으로 변환하며, 적절한 전처리와 데이터 분할이 신뢰할 수 있는 결과를 보장하고 설명된 분산과 임상적 추론이 몇 개의 성분을 유지할지 안내함
- PCA는 선형·거리 기반 모델을 개선하고, 패턴 시각화를 지원하며, 복잡한 데이터를 분석하기 쉽게 단순화함 — 공정성 점검과 재현 가능한 절차와 함께, PCA는 방대한 헬스케어 데이터를 임상의가 더 명확하고 데이터 기반의 결정을 내리도록 돕는 의미 있고 신뢰할 수 있는 통찰로 전환함
