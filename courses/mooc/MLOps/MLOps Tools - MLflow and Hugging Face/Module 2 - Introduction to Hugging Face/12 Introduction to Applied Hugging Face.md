# Introduction to Applied Hugging Face

## 개요
- 이 부분부터는 **Noah Gift**(보조 강사)가 직접 진행하며, 앞으로 다룰 "Applied Hugging Face" 흐름을 1분 안에 개괄하는 도입 영상.

## 내용

### 3단계 구성 예고
1. **데이터/모델을 Hugging Face에 넣고 다시 꺼내오기** — 데이터를 Hugging Face에 올리는 법, 모델을 올리는 법, 그리고 그것을 **GPU 지원 GitHub Codespaces** 같은 개발 환경으로 다시 받아오는 법.
2. **파인튜닝(fine-tuning)** — 세계 최고의 AI/ML 기업들이 만든 최신 모델(예: 요약 모델)을 가져와 커스텀 데이터로 살짝 파인튜닝한 뒤, 그 결과를 다시 Hugging Face 모델 리포지토리에 올려 나중에 재사용하는 법. GitHub Codespaces나 다른 GPU 지원 환경으로 이 전이학습(transfer learning) 과정을 가속화하는 법도 포함.
3. **Spaces** — Streamlit과 Gradio로 머신러닝 포트폴리오를 시연하는 좋은 방법.

## 요약
- 이번 레슨은 **데이터/모델 업로드·다운로드 → 파인튜닝(+ GPU 가속) → Spaces로 포트폴리오 시연**이라는 3단계 흐름으로 "Applied Hugging Face"를 다룰 예정임을 미리 보여주는 짧은 도입부.
