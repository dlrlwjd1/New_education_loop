# Key Terms — Introduction to Hugging Face

## 개요
- Module 2의 첫 레슨 핵심 용어 정리. Hugging Face 생태계의 4대 축(Model Hub, Datasets, Spaces, CLI)을 정의한다.

## 내용

| 용어 | 설명 |
|---|---|
| **Model Hub** | 재사용 가능한 학습된 ML 모델 수천 개를 담은 저장소. |
| **Datasets** | 모델 튜닝을 위해 정제된(curated) 데이터셋 모음. |
| **Spaces** | ML 프로젝트를 시연하기 위해 호스팅되는 앱. |
| **CLI** | Hugging Face 기능에 접근하는 커맨드라인 도구. |

## 요약
- 이번 레슨은 Hugging Face의 핵심 4대 축(Model Hub, Datasets, Spaces, CLI)을 개괄한 뒤, 실제로 리포지토리와 Spaces를 사용해보는 실습으로 이어진다.
