# Key Terms — Introduction to Applied Hugging Face

## 개요
- Lesson 2의 핵심 용어 정리. GPU 개발 환경, CLI, 추론 API를 다룬다.

## 내용

| 용어 | 설명 |
|---|---|
| **Codespaces** | GPU 접근이 가능한 브라우저 기반 개발 환경. |
| **CLI** | 인증(authentication), 캐싱(caching) 같은 작업을 위한 커맨드라인 도구. |
| **Inference API** | 최신 모델로부터 예측 결과를 얻을 수 있는 호스팅된 API. |

## 요약
- 이번 레슨은 GPU가 활성화된 Codespaces 환경에서 Hugging Face CLI(인증·캐싱)를 실전으로 다루는 짧은 레슨임을 용어로 보여준다.
