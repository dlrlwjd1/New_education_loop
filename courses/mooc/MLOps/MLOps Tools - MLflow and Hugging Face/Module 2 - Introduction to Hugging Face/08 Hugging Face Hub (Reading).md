# Hugging Face Hub (Reading)

## 개요
- Hugging Face Hub의 규모와 목적을 정리하는 공식 읽기 자료. 오픈소스 협업을 통한 ML 연구 발전이라는 플랫폼의 미션을 강조한다.

## 내용

### Hub의 규모 (당시 기준)
- **12만 개 이상의 ML 모델**(NLP, 비전, 오디오 등 다양한 태스크).
- **2만 개 이상의 데이터셋**, 100개 이상의 언어 지원.
- **5만 개 이상의 Spaces**(모델을 인터랙티브하게 시연하는 앱).
- 사용자/조직 계정으로 콘텐츠 조직화 지원.
- **접근 제어, 멀웨어 스캐닝** 같은 보안 기능.

### Hub가 쉽게 만들어주는 것
- 최신(state-of-the-art) 모델·데이터셋 발견.
- 라이브러리 지원으로 프로젝트에 손쉽게 통합.
- **Gradio, Streamlit** 같은 SDK로 인터랙티브 데모 앱 구축.
- 조직(organizations)을 통한 공개/비공개 콘텐츠 관리.

### 회고 질문
1. GitHub이나 개인 웹사이트에 모델을 공유하는 것 대비 Hugging Face Hub는 어떤 이점을 제공하는가?
2. ML 모델을 공개적으로 공유하는 것에서 어떤 윤리적 우려가 생길 수 있으며, Hugging Face는 이를 어떻게 다루려고 하는가?
3. Hugging Face가 제공하는 서비스/콘텐츠와 다른 AI 제공자들과의 핵심 차이점은?
4. 개인 연구자나 소규모 팀이 Hugging Face에 자신의 작업을 공유하는 것이 얼마나 실현 가능한가? 무엇이 어려울 수 있는가?
5. Hugging Face Hub가 ML 연구 커뮤니티의 중복 노력을 줄여줄 수 있을까? 어떤 방식으로?

### 도전 과제
- Hugging Face Hub를 탐색해 흥미로운 ML 모델을 찾고, 리포지토리를 포크한 뒤 간단한 Python 스크립트에서 그 모델로 작은 데이터셋에 대한 예측을 수행해보기.

## 요약
- Hugging Face Hub는 12만+ 모델, 2만+ 데이터셋, 5만+ Spaces를 아우르는 대규모 오픈소스 ML 협업 플랫폼이며, 이번 레슨에서 실제로 다룬 리포지토리 생성·업로드·Spaces 데모가 바로 이 생태계의 핵심 활동임을 재확인한다.
