# Introduction to Hugging Face Lab

## 개요
- **GitHub Codespaces**에서 `alfredodeza/try-huggingface` 리포지토리를 이용해 Transformers와 Datasets 라이브러리를 직접 실습하는 종합 실습(ungraded lab).

## 내용

### 중요 안내
- 이 랩은 **반드시 GitHub Codespaces에서 진행해야 함** — 다른 환경에서는 해결 불가능한 **SSL 관련 오류**가 발생한다고 명시.

### 실습 단계
1. 리포지토리 `alfredodeza/try-huggingface`(GitHub)에 접속.
2. Codespaces에 직접 접근하거나, 자신의 계정으로 **포크한 뒤 그곳에서 Codespace 시작**.
3. Codespaces 사용법이 필요하면 관련 비디오 시리즈 참고.
4. 준비되면 `README.md`를 따라 진행:
   - **Model Hub**에서 기존 모델 검색.
   - `requirements.txt`에서 **Datasets**와 **Transformers** 라이브러리 설치.
   - `notebooks` 디렉터리의 모든 Jupyter Notebook을 순서대로 실행하며 Hugging Face를 실험.

## 요약
- 이 랩은 Module 2에서 다룬 이론(Model Hub 탐색, Transformers/Datasets 라이브러리 사용)을 GitHub Codespaces 환경에서 실제 Jupyter Notebook들을 통해 손으로 익히는 종합 실습이며, SSL 문제 때문에 반드시 Codespaces에서 진행해야 한다는 점이 특히 중요하다.
