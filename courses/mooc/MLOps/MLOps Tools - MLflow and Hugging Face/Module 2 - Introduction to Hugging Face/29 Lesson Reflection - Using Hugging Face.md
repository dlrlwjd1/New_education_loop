# Lesson Reflection — Using Hugging Face

## 개요
- Lesson 3(및 Module 2 전체)를 요약하는 공식 회고 자료: Hugging Face 모델과 데이터셋을 탐색·다운로드·프로그래매틱하게 다루는 핵심 기능을 다뤘다.

## 내용

### 회고 질문
- 자신의 사용 사례에 가장 적용 가능해 보이는 모델은?
- 파인튜닝이 자신의 문제에 대한 모델 성능을 어떻게 개선할 수 있는가?
- 자신의 모델을 향상시키는 데 가치 있을 데이터셋은 무엇인가?

### 도전 과제
1. 서로 다른 모델 3개를 로컬로 다운로드해 예측을 테스트해보기.
2. 작은 커스텀 데이터셋으로 텍스트 분류 모델 파인튜닝해보기.
3. Pandas로 데이터셋의 통계와 시각화 분석해보기.

## 요약
- Lesson 3은 Model Hub 필터링(Using the Model Hub), 모델 다운로드 3가지 방법(Downloading Models), 위키피디아 요약 CLI와 모델 업로드(Working with Models), 데이터셋 업로드·분할·커스텀 로더(Adding/Using/Working with Datasets)까지 Hugging Face의 실전 활용을 폭넓게 다뤘다.
- 이것으로 **Module 2 "Introduction to Hugging Face" 전체(Hub 소개 → Applied 기초 → 실전 활용)가 완료**되었다. 다음은 Module 3 "Deploying Hugging Face"로 이어진다.
