# Datasets (Reading)

## 개요
- Hugging Face **Datasets 라이브러리**의 기능을 정리하는 공식 읽기 자료. Apache Arrow 기반의 효율적인 대용량 데이터 처리가 핵심 차별점으로 강조된다.

## 내용

### 핵심 기능
- NLP, 비전, 오디오 태스크를 위한 데이터셋에 편리하게 접근.
- **한 줄 코드**로 데이터셋 로드가 가능한 단순한 API.
- Hugging Face Hub와 직접 통합되어 공유된 데이터셋에 접근.
- **Apache Arrow**를 이용한 효율적인 데이터 처리 — 대용량 데이터셋도 효율적으로 다룸.
- 토큰화(tokenization), 패딩(padding) 같은 일반적인 데이터 작업을 위한 메서드 제공.
- 오디오, 표(tabular), 이미지, 텍스트 데이터 작업 지원.
- 자신만의 데이터셋을 만들고 버전 관리해 공유 가능.

### 핵심 메시지
- 데이터셋 준비에 드는 시간을 절약해 모델 구축에 집중할 수 있게 하는 것이 목표이며, 표준화된 포맷 덕분에 데이터셋을 쉽게 공유·재사용할 수 있음.

### 회고 질문
1. 데이터 처리를 별도로 다루는 것 대비 Hugging Face Datasets를 쓰는 이점은? 이 라이브러리가 특히 유용한 상황은?
2. Hub와의 통합이 데이터셋 재사용·공유를 어떻게 더 편리하게 만드는가? 어떤 이점을 제공하는가?
3. 대용량 데이터셋 작업에서 Hugging Face Datasets는 어떤 효율성 이득을 제공하는가? Apache Arrow 포맷이 이를 어떻게 달성하는가?
4. 텍스트/오디오/표 형식 등 다양한 데이터 양식(modality)을 다루기 위한 라이브러리 내 전문 기능은 무엇인가?
5. 새로운 데이터 타입이나 태스크 템플릿을 Hugging Face Datasets에 통합하는 것이 얼마나 확장 가능한가?

### 도전 과제
1. Hub에서 데이터셋을 로드해 모델용으로 정제·준비하는 처리 파이프라인 적용해보기.
2. 라이브러리를 활용해 데이터를 처리·버전 관리하는 커스텀 데이터셋 생성 스크립트 만들어보기.
3. Hugging Face Datasets로 이미지를 로드해 PyTorch 모델에 넣는 컴퓨터 비전 파이프라인을 Colab으로 시연해보기.
4. 라이브러리의 오디오 지원 기능으로 음성 인식 데이터셋을 만들고 정규화 등 오디오 전처리 적용해보기.
5. 현재 다루지 않는 특화된 NLP 태스크를 위한 새 템플릿을 태스크 템플릿 기능에 추가해보기.

## 요약
- Hugging Face Datasets는 Apache Arrow 기반의 효율적인 대용량 데이터 처리와 Hub 통합을 핵심으로 하며, 텍스트/오디오/이미지/표 데이터를 아우르는 통합 인터페이스로 데이터 준비 시간을 절약해준다는 것이 이 자료의 핵심 메시지다.
