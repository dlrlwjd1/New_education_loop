# Key Terms — Using Hugging Face

## 개요
- Lesson 3의 핵심 용어 정리. 모델 탐색·다운로드, 파인튜닝, 데이터셋 활용이라는 이번 레슨의 핵심 활동을 정의한다.

## 내용

| 용어 | 설명 |
|---|---|
| **Model Hub** | 저장소에서 모델을 탐색하고 다운로드. |
| **Fine-tuning** | 새 데이터로 재학습해 모델 정확도를 커스터마이징. |
| **Dataset Hub** | 텍스트, 이미지, 오디오, 표(tabular) 데이터셋에 접근. |

## 요약
- 이번 레슨은 Model Hub에서 모델을 다운로드·조작하고, Dataset Hub에서 데이터셋을 추가·활용하는 실전 코드 작성으로 이어진다.
