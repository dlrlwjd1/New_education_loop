# Lesson Reflection — Introduction to Applied Hugging Face

## 개요
- Lesson 2 전체를 요약하는 공식 회고 자료: GPU 지원 Codespaces와 Hugging Face CLI로 모델·데이터셋을 생산적으로 다루는 법을 다뤘다.

## 내용

### 회고 질문
- Codespaces가 모델 개발 워크플로를 어떻게 가속화할 수 있는가?
- 모델과 데이터셋을 다루는 데 가장 유용해 보이는 CLI 명령은?
- 실시간 추론 API(Inference API)는 어디에 적용될 수 있는가?

### 도전 과제
1. Codespace를 설정하고 GPU 모델 학습을 테스트해보기.
2. CLI 명령으로 데이터셋을 다운로드하는 스크립트 작성하기.
3. Python 애플리케이션에서 추론 API에 쿼리를 보내보기.

## 요약
- Lesson 2는 GPU 지원 GitHub Codespaces 템플릿(`mlops-template`)에서 Whisper로 GPU 활용을 실시간 확인하고, `huggingface-cli`의 login/whoami/repo/scan-cache 명령을 다루는 짧지만 실용적인 레슨이었다.
- 다음 레슨("Using Hugging Face")에서는 Model Hub 사용법, 모델 다운로드·조작, 데이터셋 추가·활용을 더 깊이 다룬다.
