# Key Terms — Hugging Face Automation

## 개요
- Lesson 3의 핵심 용어 정리. CI/CD 자동화와 컨테이너 레지스트리를 통한 예측 가능한 배포를 다룬다.

## 내용

| 용어 | 설명 |
|---|---|
| **GitHub Actions** | CI/CD 워크플로를 자동화. |
| **Container Registry** | 클라우드에 컨테이너를 저장. |
| **Deployment** | 프로덕션으로의 예측 가능한 릴리즈. |

## 요약
- 이번 레슨은 GitHub Actions로 모델 배포를 자동화하고, Azure Container Registry와 Docker Hub 양쪽에 패키징을 자동화하는 실습으로 이어진다.
