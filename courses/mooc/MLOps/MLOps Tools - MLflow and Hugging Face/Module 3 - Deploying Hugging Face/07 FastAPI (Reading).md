# FastAPI (Reading)

## 개요
- FastAPI 공식 튜토리얼의 전체 커버리지를 정리하는 읽기 자료. 기초부터 프로덕션급 기능까지 아우르는 학습 경로를 제시한다.

## 내용

### FastAPI 핵심 기능
- Python 타입 어노테이션을 이용한 **선언적 라우팅(declarative routing)**.
- **자동 JSON 입출력 검증과 직렬화**.
- Path, Query, Body, Cookie, Header 파라미터 지원.
- 응답 모델(Response models)과 상태 코드.
- 폼(Forms)과 파일 업로드.
- 보안과 인증.
- 관계형/NoSQL 데이터베이스 연동.
- 메타데이터와 문서화(자동 Swagger/OpenAPI docs).
- 디버깅.

### 핵심 포인트
- 튜토리얼은 각 개념을 점진적으로 쌓아가며 주제 간 명확한 구분을 유지 — 모든 예제는 **로컬에서 바로 실행 가능한 테스트 가능한 Python 코드**.
- 초보자를 위한 실전 입문서이자, 나중에 다시 참고할 수 있는 레퍼런스 가이드 역할도 겸함.
- 보완 자료인 **Advanced User Guide**가 같은 빌딩 블록으로 추가 기능을 다룸.

### 회고 질문
1. FastAPI 튜토리얼의 구조가 처음 배울 때와 나중에 참고할 때 모두 효과적인 이유는?
2. Python 코드 예제를 직접 빌드·테스트해보는 것이 FastAPI 학습에 어떻게 도움이 되는가? 개념만 읽는 것 대비 어떤 이점이 있는가?
3. 튜토리얼은 단계별 학습과 관심 주제로 바로 건너뛰는 것 사이의 균형을 어떻게 맞추는가?
4. FastAPI 기초의 어떤 측면이 후속 가이드의 고급 기능으로 이어지는가?
5. FastAPI 튜토리얼은 기초부터 프로덕션 준비까지 얼마나 포괄적인 API 개발 워크플로를 가능하게 하는가?

### 도전 과제
1. 튜토리얼의 초기 단계를 따라 경로(path) 엔드포인트가 있는 간단한 FastAPI 앱 만들기.
2. Query/Body/Cookie 파라미터와 응답 모델을 처리하도록 확장하기.
3. 인증을 설정하고 API를 데이터베이스에 연결하기.
4. Docker로 API를 컨테이너화하고 자동 인터랙티브 문서를 생성하기.
5. 백그라운드 태스크 같은 고급 기능을 검토하고 앱에 통합해보기.

## 요약
- FastAPI는 타입 어노테이션 기반의 선언적 라우팅과 자동 검증·문서화를 핵심으로 하며, 이번 모듈에서 실습한 Hugging Face 서빙은 FastAPI의 방대한 기능(인증, DB 연동, 백그라운드 태스크 등) 중 가장 기초적인 부분만 활용한 것임을 이 자료를 통해 확인할 수 있다.
