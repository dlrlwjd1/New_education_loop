# Docker Overview (Reading)

## 개요
- Docker의 핵심 개념(컨테이너, 이미지, 레지스트리, 클라이언트-서버 아키텍처)을 정리하는 공식 읽기 자료.

## 내용

### 핵심 요약
- Docker는 애플리케이션을 컨테이너(가볍고 이식 가능하며 서로와 호스트로부터 격리된 작업공간)에서 개발·배포·실행하는 플랫폼.
- 핵심 구성요소: **Docker 데몬(daemon), 클라이언트(client), 레지스트리(registries), 이미지(images), 컨테이너(containers)**.
- 이점: 더 빠른 배포, 확장 가능한 배포, 더 높은 밀도의 워크로드.

### 핵심 포인트
1. 컨테이너는 앱을 의존성과 함께 패키징해 호스트 및 서로로부터 격리된 가볍고 이식 가능한 작업공간에서 실행.
2. **클라이언트-서버 아키텍처** — 데몬이 빌드·실행·컨테이너 배포의 핵심 작업을 수행.
3. **이미지**는 컨테이너를 만들기 위한 읽기 전용 템플릿 — Dockerfile로부터 빌드되어 레지스트리에 저장.

### 회고 질문
1. Docker가 팀의 소프트웨어 개발 워크플로를 어떻게 개선할 수 있는가?
2. 여러 환경에서 협업할 때 Docker가 해결해줄 수 있는 어려움은 무엇인가?
3. 컨테이너가 VM 대비 컴퓨트 자원 활용을 어떻게 개선할 수 있는가?
4. 레지스트리는 Docker의 이점을 실현하는 데 어떤 역할을 하는가?
5. 개발과 프로덕션 배포 양쪽에 Docker를 어떻게 활용할 수 있는가?
