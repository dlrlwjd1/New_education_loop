# Key Terms — Packaging Hugging Face

## 개요
- Module 3의 첫 레슨 핵심 용어 정리. Hugging Face 모델을 API로 서빙하고 컨테이너화·자동화하는 데 필요한 용어들을 다룬다.

## 내용

| 용어 | 설명 |
|---|---|
| **FastAPI** | API를 구축하기 위한 Python 웹 프레임워크. |
| **Container Registry** | DockerHub나 Azure Container Registry 같은 Docker 이미지 저장소. |
| **CI/CD Pipeline** | 빌드·테스트·배포 프로세스를 자동화. |

## 요약
- 이번 레슨은 Hugging Face 모델을 FastAPI로 서빙하고, 컨테이너화한 뒤, GitHub Actions로 CI/CD 파이프라인을 구성하는 실습으로 이어진다.
