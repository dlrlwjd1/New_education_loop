# Key Terms — Hugging Face and Azure ML Studio

## 개요
- Lesson 2의 핵심 용어 정리. Azure ML Studio에서 모델과 데이터셋을 관리·배포하는 핵심 개념을 다룬다.

## 내용

| 용어 | 설명 |
|---|---|
| **Model Registry** | 모델을 관리하고 계보(lineage)를 추적하는 중앙 저장소. |
| **Datasets** | 모델 개발을 위한 정제된(curated) 데이터와 커스텀 데이터. |
| **Deployment** | 실시간(real-time) 또는 배치(batch) 엔드포인트로 모델을 서빙. |

## 요약
- 이번 레슨은 Hugging Face의 데이터셋과 모델을 Azure ML Studio에 등록하고, Azure ML Python SDK로 이를 프로그래매틱하게 다루는 실습으로 이어진다.
