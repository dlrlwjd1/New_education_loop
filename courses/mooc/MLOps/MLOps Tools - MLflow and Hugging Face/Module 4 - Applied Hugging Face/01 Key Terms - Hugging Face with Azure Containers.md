# Key Terms — Hugging Face with Azure Containers

## 개요
- Module 4의 첫 레슨 핵심 용어 정리. Azure Container Apps로 배포하고 문제 발생 시 되돌리는 핵심 개념을 다룬다.

## 내용

| 용어 | 설명 |
|---|---|
| **Container Apps** | 서버리스 컨테이너 호스팅 서비스. |
| **Automation** | GitHub Actions를 사용해 빌드하고 릴리즈. |
| **Rollback** | 문제가 있으면 마지막으로 정상 동작한 버전으로 되돌리기. |

## 요약
- 이번 레슨은 Azure Container App을 생성·구성하고, Hugging Face 컨테이너를 실제로 배포한 뒤 문제가 생겼을 때 트러블슈팅하는 실습으로 이어진다.
