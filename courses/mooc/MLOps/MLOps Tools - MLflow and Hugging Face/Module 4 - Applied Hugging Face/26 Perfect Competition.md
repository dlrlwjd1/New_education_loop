# Perfect Competition

## 개요
- "완전 경쟁에서는 모든 이윤이 0으로 수렴한다"는 경제학 개념을 레스토랑의 셰프 비유로 설명한 뒤, 이를 폐쇄형(closed) vs 개방형(open) GenAI 모델 전략에 적용하는 2분 영상.

## 내용

### 레스토랑 셰프 비유
- 작은 마을에 레스토랑 4곳이 있고, 서로 경쟁할 뾰족한 방법이 없다가 **재능 있는 셰프**가 마을에 등장.
- 이 셰프는 희소 자원(scarce resource)이므로, 모든 레스토랑이 이 셰프를 영입하려고 경쟁 → 셰프의 몸값이 계속 오름.
- 결국 셰프가 **모든 경제적 이윤(economic profit)**을 가져가게 됨.

### 경제적 이윤의 정의
- **경제적 이윤 = 총수익 − 총경제비용**.
- **정상 이윤(normal profit)**: 투자를 유치하는 데 드는 비용 수준의 이윤.
- **경제적 이윤(economic profit)**: 정상 이윤을 초과하는 부분.
- 완전 경쟁 상황에서는 희소 자원(셰프)을 가진 쪽이 이 초과 이윤을 전부 흡수 → 나머지는 결국 파산 위험에 처할 수 있음.

### GenAI 사례에 적용
- **폐쇄형(closed) 모델 시나리오**: 성능이 압도적으로 우수한 폐쇄형 모델이 하나 있어 모두가 그것만 사용해야 한다면 → 셰프 사례처럼 아무도 경쟁 우위를 가질 수 없고, 모든 이윤이 API 호출 비용(즉 그 모델 제공사)으로 흘러감.
- **개방형(open) 모델 시나리오**: 반대로 모든 모델이 오픈소스라면 누구나 동일하게 사용할 수 있어 차별화가 불가능 → 모델을 학습시키는 회사들이 이윤을 낼 방법이 없어져 결국 사업을 접게 될 수 있음.

### 핵심 통찰
- 이는 가설적 상황이지만, AI 전략을 평가할 때 경제학적 관점에서 반드시 고려해야 할 질문: "폐쇄형 모델에 올인하는 것이 경쟁 우위를 줄 것인가, 아니면 미래에는 모델이 무한히 많아져 리눅스(Linux)처럼 하나의 **상품(commodity)**이 되어 무료로 제공되고, 결국 다른 형태의 기술로 경쟁해야 하는 시대가 올 것인가?"

## 요약
- 완전 경쟁 하에서는 희소 자원을 가진 쪽(레스토랑의 셰프, GenAI의 독점 폐쇄형 모델)이 모든 경제적 이윤을 흡수하거나, 반대로 자원이 완전히 상품화(오픈소스화)되면 그 자원을 만드는 쪽이 이윤을 낼 수 없게 된다.
- AI 전략 수립 시 "폐쇄형 모델 올인" vs "모델의 상품화(commoditization)에 대비한 차별화 전략"이라는 경제학적 트레이드오프를 고려해야 한다.
