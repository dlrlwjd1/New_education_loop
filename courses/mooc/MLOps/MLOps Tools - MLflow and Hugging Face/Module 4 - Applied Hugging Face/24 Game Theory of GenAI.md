# Game Theory of GenAI

## 개요
- **게임 이론(Game Theory)**과 **죄수의 딜레마(Prisoner's Dilemma)**를 소개한 뒤, 이를 GenAI 콘텐츠 조정(content moderation)·지적재산권·창작 품질 경쟁에 적용해 "바닥을 향한 경주(race to the bottom)"가 어떻게 발생하는지 설명하는 4분 영상.

## 내용

### 게임 이론과 죄수의 딜레마
- **게임 이론**: 참가자(players), 전략(strategies), 보상(payoffs)이 있는 상호작용을 게임으로 연구해 **최적 전략** 또는 (준최적 결과로 이어지는) **지배 전략(dominant strategy)**을 찾아내는 수학적 프레임워크.
- **죄수의 딜레마**: 검사가 Sam과 Helen 둘 다 유죄로 만들 증거가 부족한 상황 → 각자에게 "자백하면 석방, 상대는 20년형"이라고 제안 → 결국 모두가 자백하도록 유도.
  - 둘 다 침묵하면 각 1년형 (최적, 하지만 서로 신뢰가 없어 도달 불가).
  - 둘 다 자백하면 각 5년형 (지배 전략이지만 준최적 결과).
  - 한쪽만 자백하면 자백자는 석방, 침묵자는 20년형 → 침묵의 리스크가 너무 커서 결국 모두 자백을 선택.
- 핵심: 서로 소통·신뢰할 수 없는 시스템에서는, 개별적으로 합리적인 선택이 모여 **모두에게 나쁜 준최적 결과**를 낳을 수 있음.

### GenAI에 적용한 게임 이론적 시나리오

1. **콘텐츠 조정(Content Moderation)의 경주**
   - 모든 콘텐츠 조정이 AI 시스템으로 이뤄지는 세상 가정 → 참여(engagement)를 높여야 한다는 강한 유인이 존재.
   - 참여가 부족하면 회사가 손해를 봄 → 나쁜 GenAI 콘텐츠가 많아져도 조정을 완화(수익에 영향을 주므로).
   - 경쟁사도 손해를 보기 시작하면 마찬가지로 조정 기준을 낮춤 → 결국 플랫폼 전체가 저품질·독성 콘텐츠로 가득 찬 "바닥을 향한 경주"에 도달할 수 있음.

2. **지적재산권 도용의 경주**
   - 다른 경쟁사·국가·정부가 지적재산권을 도용(pirate)할 것이라고 예상 → 자신도 동일하게 도용하게 됨.
   - 지적재산권을 존중하는 대신 모두가 도용하게 되면, 결국 지적재산권이라는 개념 자체가 사라지는 지점에 도달 — 상대가 나쁜 행동을 할 것이라는 예상이 만든 바닥을 향한 경주.

3. **저품질 창작물 사용의 경주**
   - 경쟁사가 프롬프트로 생성한 열등한 AI 창작물을 사용하기 시작할 것이라 예상 → 자신도 동일하게 대응.
   - 결국 모두가 점점 더 조악한 예술을 만들게 됨 → 고객도 손해, 예술가도 일자리를 잃음 → 좋은 예술이 다시는 나오지 않는 결과.

### 핵심 통찰
- 지배 전략만 생각하고 **반복(iteration)** 없이 단 한 번의 턴만 고려하면, 모든 참가자에게 준최적인 결과로 귀결될 수 있음.
- 새로운 기술(GenAI 등)을 고려할 때는 그 영향을 살펴보고, **반복적 전략(iterative strategy)**을 통해 서로 협력함으로써 바닥을 향한 경주에 빠지지 않는 방법을 고민하는 것이 중요.

## 예시
| 시나리오 | 개별 최적 선택 | 집단적 결과 |
|---|---|---|
| 죄수의 딜레마 | 자백(배신) | 둘 다 5년형 (침묵 시 각 1년형보다 나쁨) |
| 콘텐츠 조정 | 조정 완화(경쟁 대응) | 플랫폼 전체가 저품질·독성 콘텐츠화 |
| 지적재산권 | 도용(상대도 할 것이므로) | 지적재산권 개념 붕괴 |
| 창작 품질 | 저품질 AI 창작물 사용 | 예술 전반의 질적 저하, 예술가 실업 |

## 요약
- 죄수의 딜레마처럼, GenAI를 둘러싼 경쟁(콘텐츠 조정, 지적재산권, 창작 품질)에서도 상대의 나쁜 행동을 예상해 스스로도 나쁜 선택을 하는 "바닥을 향한 경주"가 발생할 수 있다.
- 단발성 지배 전략이 아닌 반복적·협력적 전략을 통해 이러한 준최적 결과를 피하는 것이 GenAI 생태계 설계에서 중요한 과제다.
