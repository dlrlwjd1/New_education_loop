# Final Sandboxes

## 개요
- 코스에서 배운 내용을 자유롭게 실습해볼 수 있는 3개의 최종 샌드박스 랩(각 1시간) — 별도의 채점 없이 자유 탐색용.

## 내용
- **Final Jupyter TensorFlow Sandbox** — Jupyter + TensorFlow 환경에서 자유 실습.
- **VSCode Final Sandbox** — VSCode 기반 환경에서 자유 실습.
- **Linux Desktop Final Desktop** — 리눅스 데스크톱 환경에서 자유 실습.
- 세 랩 모두 공통 안내문("This is a final sandbox for you to explore what you learned in the course. Enjoy!")만 제공되며, 구체적인 과제나 채점 기준은 없음.

## 요약
- 코스 전체(MLflow, Hugging Face, Azure 배포, 파인튜닝, ONNX 등)에서 학습한 내용을 원하는 환경(Jupyter/TensorFlow, VSCode, Linux Desktop)에서 자유롭게 복습·실험해볼 수 있는 선택적 실습 공간이다.
