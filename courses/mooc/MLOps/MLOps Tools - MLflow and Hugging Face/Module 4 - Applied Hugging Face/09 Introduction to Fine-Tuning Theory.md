# Introduction to Fine-Tuning Theory

## 개요
- 전통적 지도학습 대비 **전이학습(transfer learning)**의 장점을 개념적으로 정리하는 2분 도입 영상. Module 5의 "Rust for MLOps"에서 다룬 전이학습 개념을 Hugging Face 맥락에서 다시 확인한다.

## 내용

### 전통적 지도학습의 한계
- 고전적 지도학습: 과거 데이터로 모델을 학습해 예측(예: 선수의 득점 기록으로 미래 연봉 예측).
- NLP 예시: 뉴스 데이터로 요약 모델을 학습 — 대형 언어 모델(수십억 파라미터)을 처음부터 학습하는 것은 매우 비용이 많이 드는 과정.
- 다른 도메인(예: 문학 데이터셋)에 대해 같은 작업을 하려면 **또다시 처음부터** 비슷한 규모의 값비싼 학습 과정을 반복해야 함.
- **문제**: 많은 조직은 이런 대규모 지도학습을 할 만한 **원본 데이터도, 리소스도 충분하지 않음**.

### 전이학습의 해법 — "몸통은 유지, 머리만 교체"
- Hugging Face 플랫폼의 핵심 장점: 특정 도메인(예: 뉴스)에서 학습된 모델의 **본체(body, 수십억 파라미터, 최고의 연구자들이 학습)는 그대로 유지**하고, **헤드(head)만 교체**해 더 적은 데이터로 파인튜닝.
- 완전히 다른 도메인(예: 문학 데이터셋)에도 동일한 방식 적용 가능 — 새 데이터로 평가 지표를 만들고, 그 데이터로 헤드를 파인튜닝해 예측 서빙.
- 핵심 이점: **고품질 모델을 극도로 효율적으로, 그것도 원래와 다른 도메인에서** 만들어낼 수 있다는 것.

## 요약
- 전이학습은 "누군가 이미 값비싸게 학습해둔 모델의 본체를 재사용하고, 헤드만 자신의 도메인 데이터로 파인튜닝한다"는 아이디어이며, 이것이 Hugging Face 플랫폼이 제공하는 핵심 가치 중 하나임을 재확인하는 개념적 도입부다.
