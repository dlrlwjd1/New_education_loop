# Key Terms — Beyond Hugging Face Spaces

## 개요
- Module 4의 마지막 레슨 핵심 용어 정리. Hugging Face Spaces 배포 실습뿐 아니라, **GenAI를 둘러싼 경제학·게임이론·윤리·규제 이슈**까지 아우르는 이번 레슨의 폭넓은 범위를 보여준다.

## 내용

| 용어 | 설명 |
|---|---|
| **Regulatory Entrepreneurship** | 업계 참여자들이 자율 규제(self-regulation)를 통해 윤리적 AI 이슈에 선제적으로 대응하는 것. |
| **Negative Externalities** | 타인의 이윤 추구 행위로 인해 제3자가 부담하게 되는 비용. |
| **Tragedy of the Commons** | 거버넌스 없이 공유 자원이 고갈되는 현상. |
| **Game Theory** | 전략적 의사결정을 수학적으로 모델링하는 것. |
| **Perfect Competition** | 경쟁이 가격 인하를 통해 이윤을 0으로 몰아가는 시장 역학. |
| **Algorithmic Bias** | 특정 집단을 체계적이고 불공정하게 차별하는 것. |
| **Data Sourcing Ethics** | 잠재적 해악을 신중하게 평가하며 데이터셋을 검토하는 것. |
| **Attribution** | 인간 창작자의 기여를 적절히 인정하는 것. |
| **Informed Consent** | 개인의 데이터를 사용하기 위해 명시적 동의를 구하는 것. |
| **Symbiotic Creation** | 인간과 AI가 협력적으로 파트너십을 이뤄 새로운 작품을 만드는 것. |

## 요약
- 이번 레슨은 Hugging Face Spaces 배포라는 기술적 실습으로 시작하지만, 이후 **GenAI 생태계의 경제학(수익 공유, 공유지의 비극, 게임이론, 완전경쟁)과 윤리·규제(부정적 외부효과, 데이터 소싱 윤리, 저작자 표시, 동의, 규제 기업가정신)**까지 다루며 코스 전체를 마무리하는 폭넓은 성찰형 레슨이다.
