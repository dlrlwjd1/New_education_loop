# Key Terms — Fine-Tuning and ONNX Exporting

## 개요
- Lesson 2의 핵심 용어 정리. 모델을 특화시키는 파인튜닝과, 프레임워크 간 이식성을 위한 ONNX·양자화 개념을 다룬다.

## 내용

| 용어 | 설명 |
|---|---|
| **Fine-tuning** | 새 데이터로 재학습해 모델을 특화(specialize)시키는 것. |
| **ONNX** | 프레임워크 간 상호운용성(interoperability)을 위한 개방형 표준. |
| **Quantization** | 속도를 최적화하기 위한 모델 압축 기법. |

## 요약
- 이번 레슨은 사전학습 모델을 커스텀 데이터로 파인튜닝하는 이론과 실습, 그리고 Hugging Face 모델을 ONNX 포맷으로 내보내는 실습으로 이어진다.
