# Welcome! Let Us Set Your Production ML Goals

## 개요
- 강좌: Engineer Features and Evaluate Models for Production (MOOC)
- 모듈: Module 1 — Build Feature Engineering Pipelines
- 형식: **Dialogue** (MOOC Coach · AI 대화형 · 약 15분)
- 핵심: 강좌 시작 전에 **내 학습 목표를 강좌 내용에 정렬**하는 대화.

## 내용

안내문에 따르면 이 대화는 세 가지를 다룬다.

1. **현재 역량 되돌아보기** — 지금까지의 머신러닝 경험을 이야기한다
2. **학습 목표 정의하기** — 이 강좌로 무엇을 이루고 싶은지 정한다
3. **목표를 강좌 내용에 연결하기** — 강좌가 내 실제 업무 과제를 어떻게 다루는지 확인한다

막히면 우측 상단의 **"I'm stuck"** 을 눌러 힌트를 받을 수 있다.

> **주의 (MOOC 안내)** — Dialogue는 AI로 동작하므로 **오류를 확인해야 하고, 개인·민감 정보를 넣지 말아야 한다.**

## 상태

**대화 내용 미기록.** AI와의 실시간 대화이므로 고정된 본문이 없다. 위 내용은 시작 전 안내문에 근거한 것이다.

실제로 대화를 진행하면 여기에 남긴다.

- 내가 설정한 목표
- 그 목표가 이 강좌의 어느 모듈에 대응하는지

## 요약
- 강좌 본문이 아니라 **목표 설정용 AI 대화**다.
- 다루는 것: 현재 역량 → 학습 목표 → 강좌 내용과의 연결.
- AI 생성물이므로 검증이 필요하고 개인정보를 넣으면 안 된다.
