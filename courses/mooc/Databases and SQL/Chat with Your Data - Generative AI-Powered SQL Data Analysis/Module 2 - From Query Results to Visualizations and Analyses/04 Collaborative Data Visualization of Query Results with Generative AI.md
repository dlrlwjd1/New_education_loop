# Collaborative Data Visualization of Query Results with Generative AI

## 개요
- 텍스트 기반 분석을 넘어, **쿼리 결과를 생성형 AI로 시각화(visualization)**하는 방법을 다루는 강의. 비싼 BI 도구 없이도 ChatGPT만으로 다양한 시각화를 얻는 법을 보여준다.

## 내용
### 문제의식 — 기존 DB 도구는 시각화에 약하다
- 데이터베이스 조회 도구들은 데이터를 뽑아내는 데는 능하지만, **표(table) 이상의 시각화**는 대개 형편없다.
- 전통적 해결책은 비싼 데이터 시각화 도구를 따로 사서 데이터를 옮기는 것이었지만, 생성형 AI로 이제 그럴 필요가 없다.

### 방법 1 — "시각화를 먼저 상상하고, 그에 맞는 쿼리를 설계하기"
- 프롬프트: "장르별·월별 연체 반납(late returns)을 시각화할 수 있는 데이터를 가져오는 쿼리를 만들어줘. 내가 쿼리를 실행해서 결과를 시각화용으로 줄게."
- (이미 데이터베이스 컨텍스트가 확립된 대화에서 진행.)
- AI가 접근 방식 설명: "연체 건 식별 → 대여월 추출 → 영화 카테고리와 조인해 장르 확보 → 장르·월별 연체 건수 집계"가 필요하다고 판단 후 쿼리 생성.
- 쿼리 실행 → **CSV로 결과 내보내기** (엑셀 대신 CSV를 강력 추천 — 수식이 들어간 엑셀은 이 작업에 적합하지 않음).
- CSV를 업로드하며 "결과를 첨부했어"라고 하면, AI가 **곧바로 원하는 시각화를 생성**.

### 방법 2 — "원하는 시각화의 이미지를 보여주고 그에 맞는 쿼리 설계 요청"
- 마음에 드는 시각화의 **스크린샷이나 이미지를 업로드**하고: "내 데이터베이스를 기준으로, 이런 모습의 시각화를 만들 수 있는 쿼리를 설계해줘."
- 말로 설명하기 어려운 시각화 스타일도 **이미지로 보여주는 게 더 쉬울 때가 많다.**
- 이후 "이렇게 필터링해줘", "선 색깔을 바꿔줘" 등으로 계속 대화하며 다듬을 수 있다.

### 방법 3 — "여러 가지 완전히 다른 시각화를 한꺼번에 요청하기" (탐색적 시각화)
- 이번엔 시각화를 미리 계획하지 않고, **먼저 질문/데이터부터 확보한 뒤** 시각화 단계로 넘어가는 경우.
- 기존 값비싼 도구였다면 시각화 하나 만들기도 번거로워서 딱 하나만 만들고 끝냈을 상황.
- 프롬프트: "이 쿼리 결과의 완전히 다른 여러 시각화를 보여줘."
- 결과: 장르별 총 반납 건수 막대그래프, 장르별·시간별 연체 히트맵(heat map), 시간에 따른 연체 추이 선 그래프, 파이 차트 등 **서로 다른 관점의 여러 시각화**를 한 번에 받음.
- 효과: 예상치 못한 패턴 발견 가능 — 예: "왜 스포츠 장르가 특정 날짜에 짙은 빨간색(연체 급증)을 보이지?"라는 궁금증이 생겨 추가 조사로 이어질 수 있음.
- 핵심 철학: **이 도구의 목적은 AI가 대신 결정을 내려주는 것이 아니라, 사람이 더 나은 결정을 내리도록 영감을 주는 것(augmenting)**이다.

### 내부 동작 원리 — 역시 "코드 생성 + 실행"
- 시각화도 앞선 분석과 동일한 원리로 동작한다 — AI가 **Python 코드(예: matplotlib 등 사용)를 작성하고 실행**해 결과를 이미지로 보여준다.
- 원한다면 이 코드도 직접 열어볼 수 있다.

### 재현/자동화와의 연결
- 마음에 든 시각화들을 **파일로 저장하는 스크립트**로 만들어달라고 요청할 수 있다 — 예: 매일 아침 실행해 CSV를 다시 분석하고 이미지를 재생성하는 자동화 스크립트.
- 이는 앞선 강의(재현·자동화)에서 다룬 기법을 시각화에도 그대로 적용한 것.

## 예시
```
1) 목표 시각화 우선 설계:
"Let's create a query to give you the data you need to visualize late returns by genre by month.
I will run the query and give you the results to visualize."

2) 이미지 기반 요청:
"(원하는 스타일의 시각화 이미지 첨부) Based on what you know about my database,
design the query to help me create a visualization that looks like this."

3) 다양한 시각화 탐색:
"(쿼리 결과 첨부) Show me several very different visualizations of these query results."
```

## 요약
- 생성형 AI(특히 ChatGPT)로 데이터 시각화를 만들 때는 **(1) 원하는 시각화를 먼저 그리고 그에 맞는 쿼리를 설계**하거나, **(2) 원하는 시각화의 이미지를 보여주고 쿼리를 역설계**하거나, **(3) 완전히 다른 여러 시각화를 한꺼번에 요청**해 탐색적으로 패턴을 찾는 세 가지 방식을 쓸 수 있다.
- CSV로 쿼리 결과를 내보내는 것이 이 모든 협업적 분석/시각화의 전제 조건이다.
- 여러 시각화를 한꺼번에 보는 것은 예상치 못한 패턴을 발견하게 해주며, 궁극적으로 **AI가 결정을 내려주는 게 아니라 사람의 판단을 증강(augment)**하는 데 목적이 있다.
- 시각화도 내부적으로는 Python 코드 생성·실행으로 이루어지며, 마음에 든 시각화는 스크립트로 재현·자동화할 수 있다.
