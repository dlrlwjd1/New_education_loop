# Collaborative Data Analysis with Generative AI

## 개요
- "데이터와 채팅하기(chat with your data)"는 쿼리 생성에서 끝나지 않는다는 것을 강조하며, **쿼리 결과 데이터를 다시 AI에 넣어 협업적으로 분석(collaborative analysis)**하는 방법을 다루는 Module 2의 첫 강의.
- ChatGPT의 **코드 인터프리터(code interpreter)** 기능이 데이터 분석에서 얼마나 강력한지 구체적으로 보여준다.

## 내용
### "데이터와 채팅하기"의 두 축
- 지금까지(Module 1)는 그림에서 **"질문 → 쿼리 → 데이터 추출"**이라는 윗부분에 집중했다.
- 이제부터는 나머지 절반, **"추출한 데이터를 어떻게 분석할 것인가"**를 다룬다.
- 즉, 데이터를 뽑아내는 것과 그것을 분석하는 것, 둘 다 AI와의 대화로 처리할 수 있다.

### 실전 워크플로 — 쿼리 결과를 CSV로 저장해 ChatGPT에 업로드
1. 데이터베이스 클라이언트에서 쿼리 결과를 **CSV(comma-separated values)**로 저장 (엑셀 등에서 열 수 있는 표 형태 — 업로드하기 좋은 형식).
2. ChatGPT에 업로드하며 프롬프트: "첨부한 것은 연체 반납(late returns) 쿼리 결과입니다. 분석을 도와주세요. 먼저 모든 컬럼을 설명하고, 결과에서 보이는 고수준 트렌드를 알려주세요."
3. (기존 쿼리 생성 대화를 이어가도 되고, 새 대화를 시작해도 됨.)

### 왜 "먼저 컬럼을 설명해달라"고 요청하는가 — 두 가지 이유
1. **AI를 위한 그라운딩(grounding)**: AI가 실제로 파일에 접근했는지, 컬럼명을 정확히 파악했는지 확인. (가끔 파일에 접근하지 못했는데도 데이터를 지어내는 경우가 있으므로 이를 방지.)
2. **사람을 위한 확인**: 혹시 **잘못된 파일을 업로드했을 가능성**을 점검. 엉뚱한 파일을 올리고 한참 분석을 시킨 뒤에야 잘못을 깨닫는 경우가 실제로 자주 발생한다.

### 핵심 기능 — ChatGPT의 코드 인터프리터(code interpreter)
- 저자가 "인류 역사상 가장 중요한 혁신 중 하나"라고 극찬하는 기능: 사용자가 "고수준 관찰(observation)을 알려줘"라고만 요청해도, ChatGPT는 **내부적으로 Python 코드를 작성하고, 그 코드를 실제로 실행해서, 결과를 설명**해준다.
- 이는 마치 **개인 소프트웨어 엔지니어를 고용한 것**과 같다 — 사용자의 목표/아이디어를 컴퓨테이션(코드)으로 번역해 실행하고 결과를 다시 설명해주는 것.
- 화면의 작은 버튼(코드 보기)을 클릭하면 실제로 어떤 Python 코드가 작성·실행되었는지 확인할 수 있다.

### 실습 예시 1 — 이상치(outlier) 탐지
- 프롬프트: "이 데이터셋에 알아둬야 할 이상치가 있나요?"
- 결과: "IQR(사분위범위) 방법 기준으로 통계적 이상치는 발견되지 않았습니다. 장르별 월간 연체 건수가 비교적 일관적입니다."
- 코드를 열어 실제로 IQR 방식을 올바르게 사용했는지 검토 가능 (저자는 소프트웨어 엔지니어라 직접 검토).

### 코드를 검증하는 방법 — 다른 LLM에게 "이 코드 설명해줘"
- 코드를 완전히 이해하지 못하겠다면, **그 코드를 복사해서 다른 대화(또는 다른 LLM, 예: Anthropic Claude)에 붙여넣고 "이 코드가 뭘 하는지 쉬운 말로 설명해줘"**라고 요청할 수 있다.
- 확신을 더 얻고 싶다면 **여러 개의 새 대화(다른 LLM 포함)를 시작해서 각각에게 같은 코드를 검토시키고, 이상한 점이 있는지 물어볼 수도 있다.**
- 저자 본인은 이렇게까지는 하지 않지만(다른 방식으로 오류를 점검), 확신이 필요하다면 이 방법이 유효하다고 언급.

### 실습 예시 2 — "학교 방학 기간 중 연체가 많은 장르 3개는?" (더 어려운 분석)
- 왜 어려운가: "학교 방학 기간"이라는 개념을 데이터에서 어떻게 정의할지, 그리고 실제 데이터에는 **개별 날짜가 아니라 "월(month)" 단위만 있다**는 제약이 있음.
- 결과: "스포츠, 애니메이션, 공상과학(sci-fi)이 학교 방학 기간에 연체가 많은 상위 3개 장르입니다."
- 후속 프롬프트: **"코드 없이, 어떻게 그렇게 판단했는지 설명해줘."**
  - 설명받은 내용: "미국 기준으로 통상적인 학교 방학월(1월, 3월, 6월, 7월, 8월, 11월, 12월)을 식별했다"는 식으로 **가정(assumption)을 명시**함.
  - 이 가정이 사용자의 실제 맥락(어느 나라, 어느 학사일정)과 맞는지 검토할 기회를 얻음 — 예: 미국이 아닌 다른 나라라면 다른 방학월 가정이 필요할 수 있음.
- 코드를 봤을 때도 실제로 1월/3월(봄방학)/6~8월(여름방학)/11월(추수감사절)/12월(크리스마스) 등이 반영되어 있음을 확인 가능.

### 핵심 통찰 — "고수준 아이디어를 계산으로 번역하는 개인 데이터 과학자"
- 이 전체 과정은 마치 **훌륭한 Python 기반 데이터 과학자를 고용한 것**과 같다.
- "이렇게 필터링해줘", "이런 식으로 봐줘", "이런 고수준 질문에 답해줘" 같은 요청을 하면, AI가 그 아이디어를 실제 계산(코드)으로 옮기고 실행한 뒤 결과를 설명해준다.

## 예시
```
1) 초기 분석 요청: "Attached are the results of the query on late returns.
   Help me analyze the results. Start by explaining all the columns and any high-level trends."

2) 이상치 탐지: "Are there any outliers that I should know about in this dataset?"

3) 복잡한 분석: "What are the top three genres associated with late returns during school holidays?"
   후속: "Explain how you did it without code."
```

## 요약
- "데이터와 채팅하기"는 쿼리 생성뿐 아니라, **쿼리 결과를 다시 AI에 넣어 분석하는 것**까지 포함한다.
- ChatGPT의 코드 인터프리터는 고수준 요청을 **실제 Python 코드로 번역·실행·설명**해주는, 저자가 "인류사적 혁신"이라 표현할 만큼 강력한 기능이다.
- 데이터 업로드 시 "컬럼을 먼저 설명해달라"고 요청해 그라운딩(파일이 맞는지, AI가 실제로 읽었는지)을 확인하고, 복잡한 분석은 "코드 없이 어떻게 했는지 설명해줘"라고 요청해 숨은 가정(assumption)을 검토하는 것이 중요하다.
