# Introduction to Chatting with Your Data Using Generative AI

## 개요
- 생성형 AI를 활용해 데이터베이스와 **대화하듯(conversational) 데이터를 탐색**하는 방법을 다루는 강좌의 도입 강의.
- 생성형 AI, SQL, 고급 데이터 분석 기법을 결합해, 누구나 자신의 비즈니스/조직에 대해 더 깊이 이해할 수 있게 만드는 것이 목표.

## 내용
### 기존 도구의 문제
- 기존 데이터 분석 도구들은 서로 데이터를 공유하기 어렵고, 쿼리 작성과 데이터 이해가 어려워 진입 장벽이 높았다.
- 생성형 AI는 이런 장벽을 허물고, **더 유동적이고 대화 중심적인 방식**으로 데이터를 탐색할 수 있게 해준다.

### 핵심 아이디어 — AI는 "쿼리 생성기" 그 이상이다
- 생성형 AI를 단순히 SQL 쿼리를 생성하는 도구로만 쓰는 게 아니라, **"애초에 어떤 질문을 물어야 하는지"를 함께 찾아주는 협업자(collaborator)**로 활용한다.
- 예: "이 데이터로 물어볼 만한 흥미로운 질문이 뭐가 있을까?" → "지출 기준 상위 10명의 고객은 누구인가?", "연체된 대여가 가장 많은 고객은 누구인가?"(비디오 대여점 예시) 같은 질문을 AI와 함께 발굴.
- 이것이 바로 **증강 지능(augmented intelligence)**으로서의 AI 활용 — AI가 사람을 대체하는 게 아니라, 사람이 올바른 질문을 찾고 답을 얻도록 보조한다.

### 전체 흐름 — 질문 → 쿼리 → 시각화까지 하나의 대화로
1. 흥미로운 질문 찾기 (AI와 협업)
2. 질문을 **시각화를 염두에 둔 쿼리**로 변환
   - 예: "장르별·월별 연체 반납(late returns) 데이터를 시각화할 수 있도록 쿼리를 만들어줘."
3. ChatGPT가 쿼리를 생성 → 사용자가 실제로 쿼리를 실행 → 결과 데이터를 다시 ChatGPT에 넣어 시각화.
4. 시각화가 마음에 들지 않으면 "이런 식으로 바꿔줘"라고 대화로 계속 개선.

### 이 강좌가 추구하는 방향
- 비싸고 배우기 어려운 BI 툴을 새로 익힐 필요 없이, **대화만으로** 질문 → 쿼리 → 결과 → 시각화 → 인사이트 → 커뮤니케이션까지 전 과정을 처리한다.
- 목표: 데이터베이스에 갇혀 있어 조회하기도, 해석하기도, 실행 가능한 시각화·인사이트로 바꾸기도 어려웠던 정보를, **생성형 AI로 사람의 지능을 증강시켜(augment)** 다른 사람에게 전달할 수 있는 스토리로 바꾸는 것.

## 예시
```
프롬프트: "Create a query to give you the data you need to visualize late returns by genre and month.
I will run the query and give you the results to visualize."
```

## 요약
- 이 강좌는 생성형 AI를 **SQL 쿼리 생성기를 넘어, 올바른 질문을 찾고 데이터를 해석·시각화·전달하는 전 과정의 협업자**로 활용하는 법을 다룬다.
- 핵심은 "질문 발굴 → 쿼리 생성 → 실행 → 결과를 AI에 다시 넣어 시각화 → 대화로 개선"까지 모든 과정을 하나의 유동적인 대화로 처리하는 것.
- 값비싼 BI 도구 없이도, 대화를 통해 데이터베이스에 잠긴 정보를 실행 가능한 인사이트와 스토리로 바꿀 수 있다.
