# Lesson Summary (레슨 요약)

> 강좌: Database Design: A Modern Approach (Logical Operations, MOOC) · 모듈 3: Defining the Database Logical Model

## 개요
- 모듈 3에서 정의한 논리 모델 — 열·데이터 타입 식별, 기본 키 선택, 기본 키·외래 키를 이용한 테이블 관계 수립을 정리한다.

## 내용
- **데이터 타입을 어떻게 정하나** — 이 레슨과 유사한 과정. 단 SQL 표준 타입 대신 **사용하는 DBMS의 타입**을 사용. 각 열에 저장할 값을 고려하고, 옵션이 여러 개면 저장 효율·애플리케이션 용도 등 추가 요인을 고려해 선택.
- **논리 모델을 어떻게 테스트하나** — 다음 레슨의 **정규화(normalization)**가 한 방법. 또한 팀원(특히 이 DB에 접근할 클라이언트 앱을 만들 개발자)에게 논리 모델을 검토받아 앱과 잘 맞는지 확인.

## 요약
- 모듈 3 정리: **열·데이터 타입 식별 → 기본 키 선택 → 기본 키/외래 키로 관계 수립**으로 논리 모델을 정의했다.
- 논리 모델은 **정규화**와 **팀 검토**로 테스트한다.
