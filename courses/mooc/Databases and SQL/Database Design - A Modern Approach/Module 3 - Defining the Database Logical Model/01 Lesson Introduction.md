# Lesson Introduction (레슨 도입)

> 강좌: Database Design: A Modern Approach (Logical Operations, MOOC) · 모듈 3: Defining the Database Logical Model

## 개요
- 요구사항을 수집하고 개념을 식별한 뒤, **데이터베이스 로직(logic)을 모델링**하기 시작한다.

## 내용
- 이 레슨의 목표:
  - 각 테이블에 포함될 **열(columns)을 식별**한다.
  - 테이블의 적절한 **기본 키(primary key)를 선택**한다.
  - 테이블 관계에 적절한 **선택성(optionality)과 카디널리티(cardinality) 규칙**을 적용한다.

## 요약
- 모듈 3(논리 모델)은 **열 식별 → 기본 키 선택 → 관계의 선택성·카디널리티 규칙 적용** 순으로 진행된다.
