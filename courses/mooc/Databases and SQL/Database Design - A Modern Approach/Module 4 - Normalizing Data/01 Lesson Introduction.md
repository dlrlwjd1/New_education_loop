# Lesson Introduction (레슨 도입)

> 강좌: Database Design: A Modern Approach (Logical Operations, MOOC) · 모듈 4: Normalizing Data

## 개요
- 표현할 개념·테이블·열·관계를 모두 설계에 반영한 뒤, 설계에 대한 **품질 관리(quality control)**를 수행하는 단계.

## 내용
- 이 레슨의 목표:
  - **데이터 정규화(data normalization)** 원리를 사용해 초기 설계를 개선한다.
  - 초기 설계를 **보이스-코드 정규형(Boyce-Codd normal form, BCNF)**, **제4정규형(4NF)**, **제5정규형(5NF)**에 부합하도록 개정한다.

## 요약
- 모듈 4(정규화)는 정규화 원리로 설계 품질을 점검하고, 흔한 오류를 피하며 **고차 정규형(BCNF·4NF·5NF)**까지 준수하도록 개선한다.
