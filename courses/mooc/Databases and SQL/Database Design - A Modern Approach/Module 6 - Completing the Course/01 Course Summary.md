# Course Summary (강좌 마무리)

> 강좌: Database Design: A Modern Approach (Logical Operations, MOOC) · 모듈 6: Completing the Course

## 개요
- 강좌를 마무리하며, 관계형 데이터베이스 설계 전 과정을 학습했음을 정리한다.

## 내용
- 이 강좌를 통해 **관계형 데이터베이스를 설계하는 방법**을 성공적으로 학습했다.
- 전체 흐름 복습:
  1. **요구사항 수집·목적 식별** (모듈 1) — 구성 요소·설계 문제·프로세스·요구사항.
  2. **개념 모델** (모듈 2) — 엔티티 식별과 관계.
  3. **논리 모델** (모듈 3) — 열·데이터 타입·기본 키·외래 키·카디널리티/선택성.
  4. **정규화** (모듈 4) — 1NF~5NF로 이상 제거·품질 개선.
  5. **설계 완성** (모듈 5) — 물리 모델·참조/데이터 무결성·클라우드 설계.

## 요약
- 관계형 DB 설계의 전체 생애주기 — **요구사항 → 개념 → 논리 → 정규화 → 물리/무결성** — 를 완료했다. 강좌 수료 후에는 필요 시 SQL 및 특정 RDBMS 플랫폼 학습으로 이어갈 수 있다.
