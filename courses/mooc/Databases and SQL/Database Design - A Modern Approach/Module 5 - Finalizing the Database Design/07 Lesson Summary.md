# Lesson Summary (레슨 요약)

> 강좌: Database Design: A Modern Approach (Logical Operations, MOOC) · 모듈 5: Finalizing the Database Design

## 개요
- 모듈 5에서 다룬 설계 완성 — 데이터 무결성 보장, DBMS 간 차이, 전통적 vs 클라우드 설계의 차이를 정리한다.

## 내용
- **조직/개발팀의 식별자 명명 규칙** — 조직마다 다름.
- **검증 통제를 어떻게 정하나** — 검증은 개발 막바지로 미뤄지기 쉽지만 **설계 초기에 고려**해야 한다. 가능한 한 **DB 내에서 직접** 무결성을 보장하되, 통제하지 못하는 부분은 **클라이언트 애플리케이션**이 자체 통제를 둘 수 있음을 유념.

## 요약
- 모듈 5 정리: **물리 모델화·데이터 무결성(참조/열/테이블)·클라우드 설계**로 설계를 완성했다.
- 검증 통제는 설계 초기부터 고려하고, 무결성은 우선 DB 내에서 보장하되 앱 수준 통제로 보완한다.
