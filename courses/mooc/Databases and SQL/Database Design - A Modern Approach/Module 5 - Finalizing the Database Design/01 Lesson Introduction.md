# Lesson Introduction (레슨 도입)

> 강좌: Database Design: A Modern Approach (Logical Operations, MOOC) · 모듈 5: Finalizing the Database Design

## 개요
- 논리 모델을 대체로 완성한 뒤, DB를 생성·적재하기 전에 수행할 **마무리 작업**을 다룬다.

## 내용
- 이 레슨의 목표:
  - 논리 모델을 정교화해 **물리 모델(physical model)**을 만든다.
  - **참조 무결성(referential integrity)**을 보장하는 통제를 식별한다.
  - **열 수준(column level)**의 데이터 무결성 통제를 식별한다.
  - **테이블 수준(table level)**의 데이터 무결성 통제를 식별한다.
  - 전통적 아키텍처와 **클라우드**를 위한 설계의 차이를 식별한다.

## 요약
- 모듈 5(설계 완성)는 **물리 모델화 → 참조 무결성 → 열/테이블 수준 데이터 무결성 → 클라우드 설계**로 진행된다.
