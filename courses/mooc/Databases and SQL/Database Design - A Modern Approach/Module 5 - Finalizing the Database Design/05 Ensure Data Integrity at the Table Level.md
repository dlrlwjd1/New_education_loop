# Ensure Data Integrity at the Table Level (테이블 수준 데이터 무결성 보장)

> 강좌: Database Design: A Modern Approach (Logical Operations, MOOC) · 모듈 5: Finalizing the Database Design · 토픽 5D

## 개요
- **테이블 수준(table level)**의 무결성 통제 — 열 간 비교 규칙, 검증 테이블(validation table), 설계 검토·마무리, 가져온 데이터의 정제(cleansing)를 다룬다.

## 내용

### 열 비교 (column comparisons)
- 테이블 속성으로 **같은 행의 한 열 값을 다른 열 값과 비교**하는 검증 규칙 설정(행 저장 전 실행). 예: `ship_date`는 `order_date` +3일 이내 → `ship_date <= order_date + 3`. 위반 시 오류 메시지.

### 검증 테이블 (validation table)
- 보통 두 열(기본 키 + 값)로 구성되며 **정적인 값 집합**을 보관. 마스터 값을 한 곳에 두고 참조해 **일관된 값** 사용을 보장.
- 예: `Orders.ship_via`가 승인된 배송 방법만 갖도록 **`Shippers` 테이블** 추가 → `ship_via`를 외래 키로, `Shippers`↔`Orders` 1:N 관계. 앱에서는 사용자가 `shipper_name`을 보게 설정.

### 검토·마무리 (review and finalize)
- 테이블·열 생성 전, 설계를 검토: **검증 테이블 필요 여부**, 데이터 타입·열 제약, 비즈니스 규칙 구현 방법.
- **문서화가 매우 중요** — 무엇을 했는지뿐 아니라 **왜** 했는지도. 본인조차 세부를 잊고, 타인이 변경하려면 문서가 필요. 이유가 사라지면 DB가 빠르게 노후화됨.

### 가져온 데이터 정제 (cleansing imported data)
사용자 입력엔 제약을 걸지만, 외부 전자 소스의 데이터는 가져오기 전 조정이 필요할 수 있음:
- **입력 오류** — 오타·잘못된 행/열·앞뒤 공백·대소문자 불일치(검색·정렬·그룹에 영향).
- **잘못된 데이터 타입** — 숫자가 텍스트로 저장되면 계산 불가·정렬 오류("14"가 "4"보다 앞에 정렬).
- **잘못된 코드** — 유효 옵션 중 틀린 값 선택(기본값이 그대로 남는 경우 등).
- **비논리적 데이터** — 업무 로직상 말이 안 되는 값(카탈로그 등장 전 배송일, 음수 재고).
- **누락 데이터** — 가져올 때 올바르게 (누락 상태로) 표현되어야.
- **중복 데이터** — "Beatles" vs "The Beatles"처럼 같은 항목이 다르게 입력되어 중복.
- **허용되지 않는 문자** — 제어 문자(탭·CR·LF)·미지원 문자셋.
- **검열/절단 데이터** — 열에 안 맞아 잘리거나 행이 통째 누락 → 불완전·부정확.
- **일관성 없는 표현** — 단위 없는 통화(유로·달러·루블·위안 혼재) 등으로 비교·계산 곤란.
- **비원자적 데이터** — 한 열에 여러 값이 결합(atomic = 더 쪼갤 수 없는 단일 값).
- **깨진 참조** — 더 이상 없는 항목을 참조(예: 삭제된 `product_id 3425`를 `Orders`가 여전히 참조).

## 예시 — 활동들
- **5-5**: 직원이 주 35시간 초과 근무해야 건강보험 자격 → **열 비교(field comparison)**로 `hours > 35` 검증.
- **5-6 (마무리)**: 유한한 옵션 목록을 참조하는 열을 검증 테이블 후보로 스캔. `product_type`(hardcover·paperback·vinyl·CD 등)에 대해 **코드+설명 테이블** 추가(리포트에서 두 글자 코드보다 설명이 읽기 좋음).

## 요약
- 테이블 수준 통제: **열 간 비교 규칙**(`ship_date <= order_date + 3`), **검증 테이블**(유한 도메인을 외래 키로 참조).
- 구현 전 설계를 **검토**하고 반드시 **왜 그렇게 했는지 문서화**.
- 외부 데이터는 입력 오류·잘못된 타입/코드·비논리·누락·중복·불량 문자·절단·비일관·비원자·깨진 참조를 **정제(cleansing)**한 뒤 가져온다.
