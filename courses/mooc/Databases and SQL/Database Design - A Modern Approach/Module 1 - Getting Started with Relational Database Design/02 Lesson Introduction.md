# Lesson Introduction (레슨 도입)

> 강좌: Database Design: A Modern Approach (Logical Operations, MOOC) · 모듈 1: Getting Started with Relational Database Design

## 개요
- 데이터를 DB에 저장해야 하는 상황에서, **DB를 사용하는 것과 만드는 것은 다르다**는 점을 짚으며 DB 계획을 위한 정보 수집의 필요성을 소개한다.

## 내용
- 정보 수집·계획에 시간을 들이지 않으면, 필요한 정보를 제공하지 못하거나 유지보수가 번거로운 DB가 된다. **계획**은 불완전한 데이터·낮은 성능 같은 미래 문제를 예방한다.
- 이 레슨의 목표:
  - DBMS를 구성하는 **여러 구성 요소를 식별·설명**한다.
  - 낮은 성능이나 예기치 않은 동작을 유발하는 **흔한 데이터베이스 설계 문제**를 식별한다.
  - **잘 설계된 DB의 특성**과 그 특성을 설계에 반영하는 **프로세스**를 설명한다.
  - DB 설계를 시작하는 데 필요한 **정보를 수집**한다.

## 요약
- 모듈 1은 **구성 요소 식별 → 흔한 설계 문제 → 설계 프로세스 → 요구사항 수집**으로 이어지며, 계획의 중요성을 강조한다.
