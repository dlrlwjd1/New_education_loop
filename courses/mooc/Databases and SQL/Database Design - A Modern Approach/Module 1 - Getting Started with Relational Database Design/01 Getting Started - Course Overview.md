# Getting Started - Course Overview (강좌 개요)

> 강좌: Database Design: A Modern Approach (Logical Operations, MOOC) · 모듈 1: Getting Started with Relational Database Design

## 개요
- 이 강좌는 **기능적이고 효율적인 관계형 데이터베이스(relational database)를 계획·설계하는 과정(process)**을 소개한다.
- "설계는 만들면서 자연스레 잡히겠지"라는 흔한 오해를 경계하고, **사전 계획(planning)**의 중요성을 강조한다. 계획 없이는 데이터베이스가 무엇을 해야 하는지, 어떤 정보를 담아야 하는지 알 수 없으며, 나중에 데이터 유지보수 문제를 고치는 추가 작업을 낳는다.
- 개념은 특정 소프트웨어에 종속되지 않고 **모든 관계형 DBMS에 적용** 가능하다.

## 내용

### 대상 학습자 (target student)
- 데이터베이스 설계 기초를 배우려는 학습자. 보통 SQL 강좌(예: SQL Querying: Fundamentals)나 특정 RDBMS 플랫폼 강좌의 **선수·보완 과정**으로 수강.

### 강좌 목표 (course objectives)
관계형 데이터베이스를 설계하는 단계를 수행한다 — 요구사항 수집(gathering requirements), 데이터 모델링(data modeling), 구현 계획(planning implementation). 구체적으로:
1. 관계형 데이터베이스 설계를 위한 **효율적 프로세스**를 따른다.
2. 데이터베이스 **개념 모델(conceptual model)**을 정의한다.
3. 데이터베이스 **논리 모델(logical model)**을 정의한다.
4. **정규화(normalization)** 기법을 적용해 초기 설계를 개선한다.
5. **참조 무결성(referential integrity)·데이터 무결성(data integrity)** 통제를 포함해 설계를 완성한다.

### 강좌 구성 메모
- 각 레슨은 여러 페이지로 구성되며, 상단 내비게이션(Previous / Next)으로 이동한다.
- 별도의 기술 요구사항이나 데이터 파일은 없으며, 모든 활동은 워크시트·토론 기반이다.

## 요약
- 목표: **요구사항 수집 → 개념 모델 → 논리 모델 → 정규화 → 무결성 통제**의 순서로 관계형 DB를 설계.
- 특정 제품에 종속되지 않는 **범용 관계형 DB 설계 원리**를 다룬다. (Logical Operations, Course 094020)
