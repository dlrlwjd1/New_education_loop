# Lesson Summary (레슨 요약)

> 강좌: Database Design: A Modern Approach (Logical Operations, MOOC) · 모듈 1: Getting Started with Relational Database Design

## 개요
- 모듈 1에서 다룬 흔한 데이터베이스 설계 문제와, 견고한 설계 프로세스가 그런 문제를 예방하는 방법을 정리한다.

## 내용
- **체계적 설계 프로세스를 쓰는 이유** — 데이터베이스가 ① 고객의 요구를 충족하고 ② 성능이 좋도록 보장하기 위해서.
- **요구사항 수집의 핵심 첫 단계** — 어떤 고객을 위해 설계하든, **데이터베이스가 무엇을 달성해야 하는지 명확히 이해**하는 것이 결정적이다.

## 요약
- 모듈 1 정리: 나쁜 설계는 **데이터 이상**을 낳고, **방법론적 설계 프로세스**(구성 요소 이해 → 문제 인식 → 프로세스 → 요구사항 수집)로 이를 예방한다. 설계의 출발점은 언제나 **DB가 무엇을 해야 하는지 명확히 파악**하는 것.
