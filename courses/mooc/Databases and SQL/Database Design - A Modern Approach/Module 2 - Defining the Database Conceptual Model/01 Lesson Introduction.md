# Lesson Introduction (레슨 도입)

> 강좌: Database Design: A Modern Approach (Logical Operations, MOOC) · 모듈 2: Defining the Database Conceptual Model

## 개요
- 요구사항과 정보 소스를 수집한 뒤, 설계를 스케치하기 시작하는 단계. **개념 모델(conceptual model)**에 포함할 개념을 식별하는 것부터 시작한다.

## 내용
- 이 레슨의 목표:
  - DB의 **개념 모델에 포함할 개념(concepts)을 선택**한다.
  - 데이터베이스 스키마에서 **주요 엔티티(entity) 간의 관계를 식별**한다.

## 요약
- 모듈 2는 요구사항으로부터 **개념 선택 → 엔티티 간 관계 식별**로 개념 모델을 정의한다.
