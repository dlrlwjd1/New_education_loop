# Lesson Summary (레슨 요약)

> 강좌: Database Design: A Modern Approach (Logical Operations, MOOC) · 모듈 2: Defining the Database Conceptual Model

## 개요
- 모듈 2에서 다룬 개념 모델링 — 엔티티 타입 식별과 엔티티 간 관계의 첫 패스를 정리한다.

## 내용
- **개념 모델링에 누구를 참여시키나** — DB가 지원할 업무를 잘 이해하는 사람들, 그리고 개발팀의 프로그래머·테스터(기술적 관점에서 설계를 보고 개념적으로 검증하도록 도움).
- **어떤 문서를 사용하나** — **ER 다이어그램(entity relationship diagram)**이 인기 있는 도구. 그리기 쉽고 DB 모델을 명확히 표현한다.

## 요약
- 모듈 2 정리: 요구사항으로부터 **엔티티 타입(개념)을 식별**하고 **관계의 첫 패스**를 잡아 개념 모델을 스케치했다. 업무 이해관계자·개발팀을 참여시키고, **ER 다이어그램**으로 문서화한다.
