### 한국어 Transcript

데이터 과학자가 되기 위한 다음 단계를 밟게 된 것을 축하합니다. Python은 데이터 과학을 위한 최고의 언어입니다. 이제 Python으로 프로그래밍하는 방법을 알았으니 Python을 사용하여 데이터를 분석해 보겠습니다. 이 강좌에서는 NumPy, Pandas, Klearn을 포함하여 파이썬에서 데이터를 분석하는 데 가장 중요한 라이브러리를 사용하는 방법을 배웁니다. 이러한 Python 라이브러리는 데이터 사이언티스트가 되기 위한 필수 요소이며 의료, 금융, 보험, 인터넷 등 다양한 산업에서 사용됩니다.

데이터 분석 외에도 데이터 파이프라인을 구축하고 실제 데이터 세트를 기반으로 예측하기 위한 자체 기계 학습 모델을 구축하는 방법을 배우게 됩니다. 모듈 1에서는 데이터 세트 특성을 이해하는 방법, 데이터 분석을 위한 Python 패키지의 개요를 살펴보고, 데이터를 가져와서 분석을 시작하는 방법을 알아봅니다. 모듈 2에서는 데이터 랭글링 전처리, 누락된 값 처리, 데이터 형식 지정 및 데이터 정규화에 대해 설명합니다. 모듈 3에서는 탐색적 데이터 분석, 기술 통계 GroupBy, 상관 관계 및 기타 중요한 통계를 소개합니다. 모듈 4에서는 선형 회귀, 모델 평가, 다항식 회귀, 표본 내 평가, 예측 및 의사 결정을 위한 파이프라인 측정에 대해 알아봅니다.

모듈 5에서는 모델 평가 및 미세 조정, 오버피팅, 언더피팅, 모델 선택, 능선 회귀, 그리드 검색을 살펴봅니다. 마지막으로, 실제 데이터 세트를 사용하는 실습 프로젝트를 통해 새로 습득한 기술을 연습해 봅니다. 이 교육 과정의 유일한 전제 조건은 Python을 사용한 프로그래밍과 고등학교 수학입니다.
