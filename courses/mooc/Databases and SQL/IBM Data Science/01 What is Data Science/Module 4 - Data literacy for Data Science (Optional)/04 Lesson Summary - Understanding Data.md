- 재생 시간: 4분

- 성공적인 데이터 과학자가 되려면 정형, 반정형, 비정형 등 다양한 형태의 데이터를 이해해야 합니다.
- 이 강의에서 제공하는 동영상과 자료를 통해 데이터를 생성, 저장 및 액세스하는 방법을 살펴보았습니다.

## 내용
### 핵심 내용
- 성공적인 데이터 과학자가 되려면 정형, 반정형, 비정형 등 다양한 형태의 데이터를 이해해야 합니다.
- 이 강의에서 제공하는 동영상과 자료를 통해 데이터를 생성, 저장 및 액세스하는 방법을 살펴보았습니다.
- 데이터를 유용하게 사용하려면 데이터를 해석하여 의미를 도출해야 합니다.
- 데이터베이스 및 데이터 웨어하우스에 저장된 데이터를 분석 소스로 사용할 수 있습니다.
- 일반적으로 애플리케이션 프로그래밍 인터페이스 또는 API를 통해 최신 클라우드 기반 소프트웨어 애플리케이션의 데이터에 액세스할 수 있습니다.
- 당신은 데이터를 전문으로 하므로 데이터를 자세히 이해해야 합니다.

### 한국어 Transcript

데이터 이해 강의 요약 비디오에 오신 것을 환영합니다. 성공적인 데이터 과학자가 되려면 정형, 반정형, 비정형 등 다양한 형태의 데이터를 이해해야 합니다. 이 강의에서 제공하는 동영상과 자료를 통해 데이터를 생성, 저장 및 액세스하는 방법을 살펴보았습니다. 데이터를 유용하게 사용하려면 데이터를 해석하여 의미를 도출해야 합니다. 구조화된 데이터는 구조가 잘 정의되어 있거나 지정된 데이터 모델을 따르며, 데이터베이스와 같이 잘 정의된 스키마에 저장할 수 있으며, 대부분의 경우 행과 열이 있는 여러 테이블에 표시할 수 있습니다.

스키마는 테이블 간의 관계를 정의합니다. 반구조화에는 몇 가지 조직적 속성이 있지만 고정되거나 엄격한 스키마가 없습니다. 여기에는 데이터를 계층 구조로 구성하는 데 사용되는 태그와 요소 또는 메타데이터가 포함됩니다. 메타데이터는 이 데이터에 대한 유용한 정보를 제공합니다. 메타데이터는 기술, 프로세스 또는 비즈니스로 분류할 수 있습니다.

또한 다양한 소스의 정보 액세스 및 통합을 보장하고 일반적으로 데이터 카탈로그를 통해 조직 전체에 적절하게 공유되도록 메타데이터를 관리해야 합니다. 잘 구현된 데이터 카탈로그는 데이터 검색, 반복성, 거버넌스 및 액세스를 향상시킵니다. 광범위한 소스에서 제공되며 다양한 비즈니스 인텔리전스 및 분석 애플리케이션을 갖추고 있습니다. 비정형 데이터를 분석하려면 해당 데이터에서 통찰력을 얻을 수 있는 인공 지능이 필요한 경우가 많습니다. 분석용 데이터는 자동으로 생성되고 저장되든 수동 작업을 통해 생성되고 저장되든 상관없이 전자 풋프린트가 있는 모든 것에서 얻을 수 있다는 점을 아는 것이 중요합니다.

오래된 레코드는 종이와 같은 아날로그 형식으로 존재할 수 있지만 효과적인 채굴 및 처리를 위해서는 일반적으로 전자 형식으로 변환해야 합니다. 일반적으로 조직에서는 내부 애플리케이션을 사용하여 비즈니스 활동 및 워크플로의 일상적인 관리를 지원합니다. 데이터베이스 및 데이터 웨어하우스에 저장된 데이터를 분석 소스로 사용할 수 있습니다. 또한 분석을 위해 공개 및 비상장 데이터 세트를 찾을 수 있습니다. 전용 데이터 세트를 구입할 수도 있습니다.

이러한 데이터 세트는 일반적으로 CSV 형식 또는 스프레드시트와 같은 단일 플랫 파일로 제공됩니다. 수년 동안 플랫 파일은 구조에 대한 정보를 XML이라는 형식으로 저장했습니다. 최근에는 사람과 기계가 읽을 수 있는 간단한 형식인 JSON 형식으로 텍스트 데이터가 교환되는 것을 볼 수 있습니다. JSON 데이터에는 미리 정의된 스키마가 없으므로 데이터 구조가 발전함에 따라 데이터 구조 간에 쉽게 전송할 수 있습니다. 일반적으로 애플리케이션 프로그래밍 인터페이스 또는 API를 통해 최신 클라우드 기반 소프트웨어 애플리케이션의 데이터에 액세스할 수 있습니다.

JSON 데이터를 처리할 때 애플리케이션은 소위 “RESTful API”를 데이터 전송에 사용합니다. 많은 데이터 공급자와 웹 사이트에서 데이터에 액세스하기 위한 API를 제공합니다. Twitter와 Facebook은 모두 오피니언 마이닝과 같은 작업을 수행하기 위해 게시물에서 데이터를 소싱할 수 있는 API를 제공합니다. 이를 통해 고객 만족도와 같은 특정 주제에 대한 감정을 분석할 수 있습니다. 일반적으로 데이터 수집 및 관리는 데이터 엔지니어에게 할당되지만, 데이터 과학자는 분석을 위해 데이터를 전송해야 하는 경우가 가장 많습니다.

이 프로세스에는 유연성이 필요합니다. 데이터 사이언티스트는 광범위한 데이터 세트를 자주 다루며 때로는 크기가 테라바이트에 달하기도 합니다. 지속적으로 업데이트되는 이러한 대규모 데이터 세트는 IoT 애플리케이션, 센서 데이터, 수백만 사용자로부터 수집한 소셜 미디어 데이터의 지속적인 유입과 같은 출처에서 비롯됩니다. 데이터 사이언티스트는 데이터와 독특한 관계를 맺고 있습니다. 당신은 데이터를 전문으로 하므로 데이터를 자세히 이해해야 합니다.

하지만 데이터를 분석하려면 먼저 데이터의 구성, 저장, 조작 및 검색을 위한 현대의 생태계를 알아야 합니다. 이 강의에서는 이러한 아이디어 중 일부를 소개했습니다.

Welcome to the understanding data lesson summary video. Data is the foundation of data science. To be a successful data scientist, you must understand data in different forms, whether structured, semi-structured, or unstructured. In the videos and reading in this lesson, you explored how data can be generated, stored, and accessed. For data to be useful, it must be interpreted to derive meaning.

Structured data has a well-defined structure or adheres to a specified data model, can be stored in well-defined schemas such as databases, and in many cases, can be represented in multiple tables with rows and columns. The schema defines the relationships between tables. Semi-structured has some organizational properties, but lacks a fixed or rigid schema. It cannot be stored in rows and columns. It contains tags and elements, or metadata, which is used to organize data in a hierarchy.

The metadata provides useful information about this data. Metadata can be categorized as technical, process, or business. Metadata also needs managing to ensure information access and integration from various sources and appropriately shared across an organization, usually in a data catalog. A well-implemented data catalog enhances data discovery, repeatability, governance, and access. Unstructured data is heterogenous.

It comes from a broad range of sources and has a variety of business intelligence and analytics applications. Analyzing unstructured data often requires artificial intelligence to gain insights from it. It is important to know that the data for analysis can be sourced from anything with an electronic footprint, whether it’s generated and stored automatically or through manual efforts. While older records may exist in analog formats like paper, they typically require conversion to electronic formats for effective mining and processing. Typically, organizations use internal applications to support their day-to-day management of business activities and workflows.

You can use data stored in databases and data warehouses as a source for analysis. You can also find publicly and privately held data sets for analysis. You can even purchase proprietary data sets. These data sets are usually made available as a single flat file such as CSV format or spreadsheets. For a number of years, flat files stored information about their structure in a format called XML.

More recently, you see text data exchanged in JSON format, a straightforward format readable by humans and machines. JSON data does not have a predefined schema, so you can easily transfer it between data structures as they evolve. You can usually access the data in modern cloud-based software applications through an application programming interface or API. When dealing with JSON data, applications use what is called a “RESTful API” for data transfer. Many data providers and websites provide APIs for accessing their data.

Twitter and Facebook both provide APIs to source data from posts for performing tasks such as opinion mining. This allows you to analyze sentiments on a given subject, such as customer satisfaction. Usually data gathering and management are typically assigned to data engineers, although as a data scientist, you most often need to transfer data for analysis. This process demands flexibility. As a data scientist, you will frequently work with extensive data sets, sometimes reaching terabytes in size.

These continually updating massive data sets stem from sources like IoT applications, sensor data, and the constant influx of social media data collected from millions of users. Data scientists have a unique relationship with data. You specialize in data, so you must understand it intimately. But before you can analyze it, you’ll need to know the modern-day ecosystem for organizing, storing, manipulating, and retrieving data. This lesson introduced you to some of these ideas.
