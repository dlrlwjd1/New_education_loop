### 핵심 내용

- 비정형 데이터는 수동 분석을 위해 파일 및 문서 (예: Word 문서) 에 저장하거나 이러한 유형의 데이터를 검사하기 위한 자체 분석 도구가 있는 NoSQL 데이터베이스에 저장할 수 있습니다.
- 요약하자면 정형 데이터는 데이터베이스에 저장할 수 있는 형식으로 잘 구성되어 있고 표준 데이터 분석 방법 및 도구에 적합한 데이터이고, 반정형 데이터는 다소 정돈된 데이터로 그룹화 및 계층 구조에 메타 태그에 의존하는 데이터이며 , 비정형 데이터는 일반적으로 특정 형식의 행과 열 형태로 구성되지 않는 데이터입니다.

### 한국어 Transcript

데이터는 의미 있게 처리되는 비정형 정보입니다. 일반적으로 데이터는 의미를 도출하기 위해 해석할 수 있는 사실, 관찰, 인식, 숫자, 문자, 기호 및 이미지로 구성됩니다. 데이터를 분류할 수 있는 방법 중 하나는 구조입니다. 데이터는 정형 , 반정형 또는 비정형 데이터일 수 있습니다. 구조화된 데이터는 구조가 잘 정의되어 있거나 지정된 데이터 모델을 따르며, 데이터베이스와 같이 잘 정의된 스키마에 저장할 수 있으며, 대부분의 경우 행과 열을 사용하여 표 형식으로 표현할 수 있습니다.

구조화된 데이터는 일반적인 데이터베이스에서 수집, 내보내기, 저장 및 구성할 수 있는 객관적인 사실이자 수치입니다. 구조화된 데이터의 출처로는 비즈니스 트랜잭션에 초점을 맞춘 SQL 데이터베이스 및 온라인 트랜잭션 처리 (OLTP) 시스템, Excel 및 Google 스프레드시트와 같은 스프레드시트, 온라인 양식, 글로벌 포지셔닝 시스템 (또는 GPS), 무선 주파수 식별 (또는 RFID) 태그와 같은 센서, 네트워크 및 웹 서버 로그 등이 있습니다. 구조화된 데이터는 일반적으로 관계형 또는 SQL 데이터베이스에 저장할 수 있습니다. 또한 표준 데이터 분석 방법 및 도구를 사용하여 구조화된 데이터를 쉽게 검사할 수 있습니다. 반정형 데이터는 일부 조직적 속성은 있지만 고정되거나 엄격한 스키마가 없는 데이터입니다.

반정형 데이터는 데이터베이스에서처럼 행과 열의 형태로 저장할 수 없습니다. 여기에는 데이터를 그룹화하고 계층 구조로 구성하는 데 사용되는 태그와 요소 또는 메타데이터가 포함됩니다. 반정형 데이터의 일부 소스에는 이메일, XML 및 기타 마크업 언어, 바이너리 실행 파일, TCP/IP 패킷, 압축 파일, 다양한 소스의 데이터 통합 등이 포함될 수 있습니다. XML 및 JSON을 사용하면 태그와 속성을 정의하여 데이터를 계층적 형태로 저장할 수 있으며 반정형 데이터를 저장하고 교환하는 데 널리 사용됩니다. 비정형 데이터는 쉽게 식별할 수 있는 구조를 갖지 않아 주류 관계형 데이터베이스에서 행과 열의 형태로 구성할 수 없는 데이터입니다.

특정 형식, 순서, 의미 또는 규칙을 따르지 않습니다. 비정형 데이터는 소스의 이질성을 처리할 수 있으며 다양한 비즈니스 인텔리전스 및 분석 애플리케이션을 갖추고 있습니다. 비정형 데이터의 출처로는 웹 페이지, 소셜 미디어 피드, 다양한 파일 형식 (예: JPEG, GIF, PNG) 의 이미지, 비디오 및 오디오 파일, 문서 및 PDF 파일, PowerPoint 프레젠테이션, 미디어 로그, 설문조사 등이 있습니다. 비정형 데이터는 수동 분석을 위해 파일 및 문서 (예: Word 문서) 에 저장하거나 이러한 유형의 데이터를 검사하기 위한 자체 분석 도구가 있는 NoSQL 데이터베이스에 저장할 수 있습니다. 요약하자면 정형 데이터는 데이터베이스에 저장할 수 있는 형식으로 잘 구성되어 있고 표준 데이터 분석 방법 및 도구에 적합한 데이터이고, 반정형 데이터는 다소 정돈된 데이터로 그룹화 및 계층 구조에 메타 태그에 의존하는 데이터이며 , 비정형 데이터는 일반적으로 특정 형식의 행과 열 형태로 구성되지 않는 데이터입니다.

Data is unorganized information that is processed to make it meaningful. Generally, data comprises of facts, observations, perceptions, numbers, characters, symbols, and images that can be interpreted to derive meaning. One of the ways in which data can be categorized is by its structure. Data can be: Structured; Semi-structured, or Unstructured. Structured data has a well-defined structure or adheres to a specified data model, can be stored in well-defined schemas such as databases, and in many cases can be represented in a tabular manner with rows and columns.

Structured data is objective facts and numbers that can be collected, exported, stored, and organized in typical databases. Some of the sources of structured data could include: SQL Databases and Online Transaction Processing (or OLTP) Systems that focus on business transactions, Spreadsheets such as Excel and Google Spreadsheets, Online forms, Sensors such as Global Positioning Systems (or GPS) and Radio Frequency Identification (or RFID) tags; and Network and Web server logs. You can typically store structured data in relational or SQL databases. You can also easily examine structured data with standard data analysis methods and tools. Semi-structured data is data that has some organizational properties but lacks a fixed or rigid schema.

Semi-structured data cannot be stored in the form of rows and columns as in databases. It contains tags and elements, or metadata, which is used to group data and organize it in a hierarchy. Some of the sources of semi-structured data could include: E-mails, XML, and other markup languages, Binary executables, TCP/IP packets, Zipped files, Integration of data from different sources. XML and JSON allow users to define tags and attributes to store data in a hierarchical form and are used widely to store and exchange semi-structured data. Unstructured data is data that does not have an easily identifiable structure and, therefore, cannot be organized in a mainstream relational database in the form of rows and columns.

It does not follow any particular format, sequence, semantics, or rules. Unstructured data can deal with the heterogeneity of sources and has a variety of business intelligence and analytics applications. Some of the sources of unstructured data could include: Web pages, Social media feeds, Images in varied file formats (such as JPEG, GIF, and PNG), video and audio files, documents and PDF files, PowerPoint presentations, media logs; and surveys. Unstructured data can be stored in files and documents (such as a Word doc) for manual analysis or in NoSQL databases that have their own analysis tools for examining this type of data. To summarize, structured data is data that is well organized in formats that can be stored in databases and lends itself to standard data analysis methods and tools; Semi-structured data is data that is somewhat organized and relies on meta tags for grouping and hierarchy; and Unstructured data is data that is not conventionally organized in the form of rows and columns in a particular format In the next video, we will learn about the different types of file structures.
