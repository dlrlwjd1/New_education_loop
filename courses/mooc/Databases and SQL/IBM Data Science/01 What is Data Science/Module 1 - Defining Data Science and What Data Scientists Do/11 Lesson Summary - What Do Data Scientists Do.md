## 내용
### 핵심 내용
- 혁신과 발견, 그리고 앞으로 펼쳐질 무한한 가능성으로 향하는 관문입니다.
- 데이터 사이언티스트는 많은 문제를 조사하고 그에 대한 설명을 찾아냅니다.
- 데이터 사이언티스트는 물 독성을 방지하기 위해 조류 번식을 예측하는 것과 같은 환경 문제를 해결할 수도 있습니다.
- 데이터 사이언티스트는 인공 신경망의 강력한 데이터를 활용하여 수처리 회사가 생태계를 보호하도록 도울 수 있습니다.
- 또한 데이터 사이언티스트는 Nearst Neighbor와 같은 머신 러닝 알고리즘을 활용하여 미디어에서 흔히 빅 데이터라고 부르는 데이터를 처리합니다.
- 텍스트 기반 데이터는 행과 열이 있는 표와 같이 구조화될 수도 있고 이메일이나 로그와 같이 구조화되지 않은 데이터일 수도 있습니다.

### 한국어 Transcript

데이터가 단순한 숫자가 아닌 세상에 오신 것을 환영합니다. 혁신과 발견, 그리고 앞으로 펼쳐질 무한한 가능성으로 향하는 관문입니다. 데이터 사이언티스트 세계의 핵심을 이해하기 위해 이 강의의 자료와 비디오에서 논의한 대로 데이터 과학자가 하는 일을 살펴보겠습니다. 데이터 사이언티스트는 많은 문제를 조사하고 그에 대한 설명을 찾아냅니다. 예를 들어, Murtaza Haider 박사는 50만 명의 고객이 토론토의 대중 교통에 대해 불만을 제기하는 이유에 대한 설명을 찾았습니다.

많은 조사 끝에 그는 예상치 못한 악천후와 해당 날짜의 불만 건수 사이의 관계를 발견했습니다. 데이터 사이언티스트는 물 독성을 방지하기 위해 조류 번식을 예측하는 것과 같은 환경 문제를 해결할 수도 있습니다. 데이터 사이언티스트는 인공 신경망의 강력한 데이터를 활용하여 수처리 회사가 생태계를 보호하도록 도울 수 있습니다. 스턴 경영대학원의 임상 교수인 Norman White도 부서 간의 복잡한 문제를 단순화하는 추천 엔진을 구축하게 된 여정에 대해 설명했습니다. 이는 혁신적인 솔루션으로 실제 문제를 해결하는 데이터 과학의 본질을 잘 보여줍니다.

교육은 미래의 데이터 과학자가 필수 기술을 갖추도록 하는 초석 역할을 합니다. White의 강의실에는 Python 노트북이 있어 유닉스, 리눅스, 관계형 데이터베이스, Pandas와 같은 강력한 도구의 비밀을 밝혀 줍니다. 데이터 과학의 저자인 빈센트 그랜빌 박사는 데이터 과학자가 되기 위해 필요한 교육 배경으로 대수, 미적분, 훈련, 확률 및 통계를 꼽습니다. 그는 통계학자와 데이터 과학자를 구분합니다. 데이터 과학자는 통계를 사용하지만 통계학자일 뿐만이 아닙니다.

하지만 데이터 사이언티스트는 통계적 회귀와 같은 통계 모델을 많이 사용합니다. 회귀 분석은 두 변수 간의 가능한 관계 ( 예: 운전 거리, 가스 사용량) 를 보여줍니다. 또한 데이터 사이언티스트는 Nearst Neighbor와 같은 머신 러닝 알고리즘을 활용하여 미디어에서 흔히 빅 데이터라고 부르는 데이터를 처리합니다. 이 용어는 주의해서 사용해야 합니다. 한때 빅 데이터로 여겨졌던 것이 혁신을 통해 계속해서 재편되고 있습니다.

Hadoop과 같은 도구와 소프트웨어 발전은 기존의 한계를 깨고 가능성의 새로운 시대를 열었습니다. 파텔 박사는 데이터 과학자가 임의 크기의 데이터 세트를 다루도록 제한하거나 특정 도구를 사용하도록 제한하지도 않습니다. 그의 정의에는 다양한 학문적 배경과 교육을 받은 사람들이 포함됩니다. 데이터 과학자는 데이터세트 내에서 통찰력을 발굴할 뿐만 아니라 이해관계자에게 설득력 있는 이야기를 전달합니다. 이러한 기술적 통찰력과 커뮤니케이션 기교가 이들을 차별화하는 것은 바로 이러한 기술적 통찰력과 커뮤니케이션 기교의 조화입니다.

데이터 과학자가 사용하는 데이터는 다양한 출처에서 나옵니다. 비디오도 있고 오디오도 있고 형식이 지정되지 않은 텍스트도 있습니다. 텍스트 기반 데이터는 행과 열이 있는 표와 같이 구조화될 수도 있고 이메일이나 로그와 같이 구조화되지 않은 데이터일 수도 있습니다. 사용하는 데이터는 구분된 텍스트 파일, 스프레드시트, XML, PDF, Javascript 객체 표기법 (JSON) 등 다양한 형식으로 제공됩니다. 데이터 사이언티스트가 정말 뛰어난 이유는 무엇일까요?

News Corp의 수석 데이터 과학자인 레이첼 슈트 (Rachel Schutt) 에 따르면 그 해답은 호기심에 있습니다. 성공적인 데이터 사이언티스트는 컴퓨터 과학자, 소프트웨어 엔지니어, 통계학자를 모두 아우르는 사람입니다. 비정형 솔루션을 구조화된 인사이트로 전환하는 능력이 기업의 능력을 결정합니다. 데이터 과학자의 하루에서 얻은 통찰력을 되돌아보면서 우리는 데이터 과학이 단순한 직업이 아니라는 것을 깨닫게 됩니다. 탐구, 혁신, 스토리텔링의 여정입니다.

기술, 호기심, 결단력을 갖춘 데이터 과학자는 데이터를 탐색하여 놀라운 사실을 밝혀냅니다.
