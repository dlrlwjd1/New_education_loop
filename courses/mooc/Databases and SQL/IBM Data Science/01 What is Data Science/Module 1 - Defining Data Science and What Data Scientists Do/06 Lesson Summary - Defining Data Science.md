### 한국어 Transcript

데이터 과학의 정의, 강의 요약에 오신 것을 환영합니다. 이 비디오에서는 이 강의의 비디오와 독서에서 배운 중요한 포인트를 복습하고, 이 강의의 리소스에서 얻은 아이디어도 함께 연결해 보겠습니다. 데이터 과학이란 무엇인지, 조직에서 데이터 과학자의 역할, 숙련된 데이터를 과학자로 만드는 요인, 이러한 기술을 습득하는 방법에 대한 전문가의 조언을 빠르게 요약해 보겠습니다. 간단히 말해, 데이터 과학은 데이터에 대한 연구이고, 데이터 과학은 데이터를 사용하여 주변 세계를 이해하며, 일부는 데이터 과학을 데이터 뒤에 숨어 있는 통찰력과 추세를 발견하는 기술이라고 생각합니다. 데이터 분석은 새로운 것이 아닙니다.

최근의 데이터 액세스와 향상된 컴퓨팅 성능은 분석을 통해 새로운 통찰력과 지식을 제공합니다. 또한 우리는 이 데이터를 분석하여 새로운 지식을 발견하는 데 필요한 컴퓨팅 파워를 갖추고 있습니다. 컴퓨터의 힘으로 이 정보를 파헤쳐 가치 있는 통찰력을 얻을 수 있습니다. 탐정이 비밀을 밝혀내는 것처럼 데이터 과학자는 데이터를 이야기로 변환하여 통찰력을 창출합니다. 이러한 통찰력은 기업이나 기관의 전략적 의사 결정에 도움이 됩니다.

생물학 또는 물리과학과 마찬가지로 데이터 과학은 정형 데이터와 비정형 데이터를 다룹니다. 데이터에서 통찰력을 얻는 프로세스에는 문제 명확화, 데이터 수집, 분석, 패턴 인식, 스토리텔링 및 시각화가 포함됩니다. 테드 로저스 경영대학원의 Murtez Aheter 교수에 따르면 데이터 사이언티스트에게는 호기심, 논증, 판단력이 매우 중요하다고 합니다. 호기심은 데이터를 탐색하고 의미 있는 질문을 떠올리는 데 도움이 됩니다. 훌륭하고 타당하며 합리적인 주장은 데이터에서 학습한 후 발견한 내용을 설명하는 데 도움이 되며, 청취자가 새로운 정보를 기반으로 아이디어를 조정하도록 유도할 수 있습니다.

올바른 판단을 통해 올바른 방향으로 출발할 수 있습니다. 숙련된 데이터 사이언티스트는 단순히 통계학자나 컴퓨터 전문가가 되는 데 그치지 않습니다. 기업들은 특정 주제에 대해 잘 알고 있고, 데이터 프로그래밍 및 분석 경험이 있고, 의사소통을 잘할 수 있는 다재다능한 인재를 찾고 있습니다. 일반적으로 데이터 사이언티스트는 수학에 익숙하고 호기심이 많으며 이야기를 잘 풀어냅니다. 이들의 배경은 경제, 공학, 의학 등 다양한 분야에서 나올 수 있습니다.

자신의 강점과 관심사를 이해했다면 해당 분야의 데이터 분석을 마스터하는 데 집중하고 업계에 적합한 도구를 선택하십시오. 능숙해지면 단서를 해독하여 미스터리를 푸는 것과 마찬가지로 데이터를 사용하여 실제 문제를 해결하는 데 전문 지식을 적용하십시오. 그렇다면 숙련된 데이터 과학자인 당신에게 미래는 어떤 모습일까요? 기술이 변화하고 데이터 역할이 발전함에 따라 데이터 과학자 직업도 바뀔 것입니다. 직원이 자격을 갖추도록 하려면 회사에서 인증을 요구합니다.

데이터 사이언티스트는 항상 논리적으로 사고하고, 알고리즘을 사용하고, 체계적인 접근 방식을 따라야 합니다. 가장 중요한 것은 성공적인 비즈니스 성과를 달성하기 위해 데이터를 정확하게 수집하고 사용 중인 모델을 주의 깊게 분석해야 한다는 것입니다.
