### 한국어 Transcript

딥 러닝 및 머신 러닝 강의 요약에 오신 것을 환영합니다. 이 비디오에서는 비디오와 이 강의에서 읽은 내용을 통해 딥러닝과 머신 러닝에 대해 배운 내용을 살펴보겠습니다. 인공 지능에서 일반적으로 사용되는 많은 용어와 이를 구별하는 방법, 데이터 과학자가 인공 지능 OR AI를 사용하는 방법, 기계 학습과 데이터 과학 간의 관계, 사물 간의 관계를 나타내는 데 사용되는 회귀 모델을 요약해 보겠습니다. 인공 지능 (AI) 은 급성장하여 거의 모든 사람이 이용할 수 있게 되었습니다. 데이터 과학자는 데이터를 분석할 때 정기적으로 AI를 사용합니다.

머신 러닝, 딥 러닝, 신경망, 제너레이티브 AI 등 AI와 관련된 이 단원에서 사용된 몇 가지 용어에 대해 알아보겠습니다. AI는 인간 지능과 관련된 많은 작업을 모방할 수 있는 시스템 개발을 포함하는 컴퓨터 과학의 한 분야입니다. 머신 러닝은 분석 방법을 시스템에 명시적으로 프로그래밍할 필요 없이 컴퓨터 알고리즘을 사용하여 데이터를 학습하고 데이터를 기반으로 예측을 수행하는 AI의 하위 집합입니다. 딥러닝은 계층화된 신경망을 사용하여 인간의 의사 결정을 시뮬레이션하는 머신 러닝의 하위 집합입니다. 신경망은 뉴런이라고 하는 작은 컴퓨팅 장치의 모음으로, 수신되는 데이터를 가져와 시간이 지남에 따라 개와 고양이의 차이와 같은 결정을 내리는 방법을 학습합니다.

딥러닝 알고리즘은 정체되는 경향이 있는 다른 머신러닝 알고리즘과 달리 데이터의 양이 늘어날수록 효율성이 높아집니다. AI의 또 다른 하위 집합인 제너레이티브 AI는 기존 데이터를 분석하는 데 그치지 않고 새로운 데이터를 생성하는 데 초점을 맞춥니다. 이를 통해 기계는 인간의 창조물을 모방하여 이미지, 음악, 언어 및 컴퓨터 코드를 포함한 콘텐츠를 만들 수 있습니다. 또한 제너레이티브 AI는 원시 데이터 세트와 유사한 특성을 가진 데이터 세트를 만들 수 있습니다. 때때로 데이터 과학자는 데이터가 충분하지 않을 때 합성 데이터를 생성하여 모델을 훈련하고 테스트하는 데 사용할 수 있습니다.

데이터 과학자는 머신러닝 알고리즘을 사용하여 데이터에서 인사이트를 도출하게 됩니다. 예측 분석을 위한 머신러닝 알고리즘을 자주 적용하거나 권장사항을 제시하게 됩니다. 예를 들어, 사기 탐지에 이러한 알고리즘을 사용하여 이전 구매 습관을 기반으로 사기 신용 카드 구매를 식별할 수도 있습니다. 머신러닝 알고리즘은 회귀라는 통계 기법에 크게 의존합니다. 회귀는 하나 이상의 입력과 출력 간의 상관 관계의 강도와 양을 식별합니다.

예를 들어, 면적과 침실 수를 기준으로 주택 가격이 얼마나 인상되며, 이러한 관계에 대해 얼마나 확신할 수 있습니까? 요약하면, 제너레이티브 AI는 원시 데이터 세트와 같은 새로운 데이터를 생성합니다. 딥 러닝은 머신 러닝의 하위 집합이고 머신 러닝은 인공 지능의 하위 집합입니다. 딥러닝은 신경망을 활용하여 입력과 출력의 패턴을 스스로 학습합니다. 데이터 과학자는 빅 데이터를 사용하여 이러한 AI 영역을 모두 사용하여 예측합니다.
