- 데이터 과학에서는 혼용되어 사용되는 용어들이 많습니다 그럼 가장 일반적인 것들을 살펴봅시다 '빅 데이터'라는 용어는 여러분이 관계형 데이터베이스로 수행했을 법한 전통적인 분석 방법에 도전할 만큼 엄청 방대하고, 아주 빠르게 구축되고 너무 다양한 데이터 세트를 의미하죠 데이터 과학을 위한 새로운 도구, 기술들과 분산망에서의 엄청난 컴퓨터 성능의 동시 개발은 이제 조직들이 이러한 방대한 데이터 세트들을 분석할 수 있는 능력이 있다는 걸 의미하죠 새로운 지식과 통찰력은 이제 누구나 사용할 수 있게 됐습니다 빅 데이터는 종종 다섯 개의 V로 설명됩니다 속도(velocity), 양(volume), 다양성(variety), 진실성(veracity), 가치(value)가 그 요소들이죠 데이터 마이닝은 자동으로 데이터를 검색하고, 분석하며 이전에 공개되지 않은 패턴을 찾아내는 과정입니다 데이터를 준비하기 위해 전처리를 수행하고, 이를 적합한 형태로 변형하는 것들도 데이터 마이닝의 한 과정이죠 이 작업이 완료되면 간단한 데이터 시각화 도구들에서부터 머신 러닝과 통계모델들에 이르는 다양한 도구들과 기술들을 이용하여 통찰력과 패턴들을 발굴하고 추출하죠 머신 러닝은 인공지능의 한 종류인데, 컴퓨터 알고리즘을 사용하여 데이터를 분석하고, 지능적인 결정을 내리죠 명확히 프로그래밍되지 않은 상태로 학습했던 것들을 바탕으로 말이죠 머신 러닝 알고리즘은 방대한 데이터 세트들을 통해 학습되며, 예시들로부터 배우죠 머신 러닝은 규칙 기반 알고리즘을 따르지 않습니다 머신 러닝은 주어진 데이터를 바탕으로 기계가 정확한 예측을 만들어서, 그걸 기반으로 문제를 풀 수 있도록 해주는 겁니다 딥 러닝은 머신 러닝의 전문화된 한 종류이며, 계층화된 신경망을 이용하여, 인간의 의사 결정을 시뮬레이션합니다 딥 러닝 알고리즘은 정보를 분류하고, 패턴들을 식별할 수 있습니다 이 덕분에 인공지능 시스템은 결정들이 정확했는지 확인하면서, 지속적으로 결과의 정확성과 품질을 향상시키고, 그 일을 통해 학습할 수 있죠 인공 신경망은 종종 간단히 신경망이라고도 불리는데요 인공 신경망은 생체 신경망과 꽤 많이 다르게 작동하지만, 생체 신경망에서 영감을 얻은 것이죠 인공 지능의 신경망은 뉴런이라고 불리는 작은 컴퓨팅 단위의 집합인데, 뉴런은 시간이 흐르면서 의사 결정을 할 수 있도록 전송되는 데이터를 받아서 학습합니다 신경망은 종종 층이 깊으며, 신경망으로 인해 딥 러닝 알고리즘은 데이터 세트의 양이 증가함에 따라 더 효율적이게 되죠 데이터가 증가하면 정체될 수 있는 다른 머신 러닝 알고리즘과는 반대로 말이죠 이제 여러분은 몇몇 주요 인공지능 개념들의 차이점에 대해 폭넓게 이해하고 있습니다 인공지능과 데이터 과학 간의 차이가 하나 더 있는데, 이 차이점을 이해하는 것은 중요하죠 데이터 과학이란 종류가 다른 대량의 데이터로부터 지식과 통찰력을 얻는 과정이자 방법입니다 이는 수학, 통계 분석과 데이터 시각화, 머신 러닝 등을 포함하는 통합 학문 영역입니다 데이터 과학 덕분에, 우리는 대용량의 데이터로부터 의미를 발견하고, 패턴을 찾아내며, 정보를 이용하고, 이를 통해 사업을 추진하는 의사 결정을 할 수 있죠 데이터 과학은 데이터로부터 통찰력을 끌어내기 위해 많은 인공지능 기술들을 사용할 수 있습니다 예를 들면, 데이터로부터 의미를 도출하고 결론을 끌어내기 위해서 머신러닝 알고리즘과 심지어 딥 러닝 모델도 사용할 수 있죠 인공지능과 데이터 과학 간 약간의 상호작용이 있지만 하나가 다른 하나의 하위 집합이지는 않습니다 오히려 데이터 과학은 전체 데이터 처리 방법을 아우르는 광범위한 용어인 반면에, 인공지능은 컴퓨터가 문제 해결 방법을 학습하고, 지능적인 판단을 할 수 있도록 해주는 모든 것들을 포함하죠 인공지능과 데이터 과학 모두 빅 데이터를 사용합니다 아주 많은 양의 데이터 말이죠
