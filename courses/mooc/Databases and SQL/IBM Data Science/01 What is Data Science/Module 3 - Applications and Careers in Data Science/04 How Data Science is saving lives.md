# How Data Science is saving lives

## 개요
- 강좌: What is Data Science?
- 모듈: Applications and Careers in Data Science
- 재생 시간: 5분
- [MOOC 원본 강의](https://www.mooc.org/learn/what-is-datascience/lecture/RvMe9/how-data-science-is-saving-lives)
- (음악) 오늘날 사용 가능한 대량의 데이터 집합을 이해하고 분석하는 데이터 과학 기술을 사용하는 것은 인간의 삶에 엄청난 영향을 미칩니다 이는 표적 인포메이션을 제공하는데, 전문 의료진이 환자에게 최선의 치료를 하고, 자연 재해를 예측하도록 도와줍니다 이로 인해 사람들은 미리 준비할 수 있고, 훨씬 더 많은 일들도 할 수 있죠 의료 부문에서, 데이터 과학자들은 환자에게 가장 적합한 옵션을 찾기 위해 데이터 마이닝, 데이터 모델링, 통계와 기계 학습을 이용한 예측 분석을 합니다 이러한 종류의 예측 분석은 질병에 관해 알려진 요소를 모두 조사합니다 유전적 형질, 관련 조건과 환경적 요인들도 검토하죠 그런 다음 적합한 검사, 적절한 시도 및 권장되는 치료법들을 추천합니다 모든 의사들은 그들의 연구, 흥미와 경험에서 얻은 그들만의 지식을 갖고 있습니다 예측 분석을 사용하는 데이터 과학 시스템은 모든 의사들이 그들의 특정 환자에 맞춘 질병, 검사, 치료 계획에 관한 최신 정보를 얻을 수 있도록 해주죠 이런 시스템을 이용해, 모든 의사들은 동일한 지식을 얻을 수 있고, 환자의 상태를 개선시키는 최고의 옵션들을 지속적으로 제공받을 수 있습니다 예를 들면, 보스턴 컨설팅 그룹과 의료 진단 회사 협회인 AdvaMedDX는 연구를 통해, 특정 암에 걸렸거나 특정 유전적 형질을 가진 환자들의 생명을 잠재적으로 구할 수 있는 진단 검사 채택에 장벽이 있는지 조사했습니다 이 연구는 이 특정한 검사를 받은 환자들의 가장 큰 요소를 발견했는데, 이는 환자의 암 전문의가 이 검사에 대해 알았는지 몰랐는지와 유전적 형질과의 관계입니다 데이터 과학 도구를 통해 추가 정보를 제공함으로써 의사는 특정 환자를 위한 가장 유용한 검사와 치료를 알 수 있죠 다양한 종류의 의학 연구를 위해 전자 의무 기록 등으로부터 데이터를 찾아낼 다른 방법들을 탐구할 기회가 많습니다 시카고 교외의 노스쇼어 대학교 보건 시스템과 같은 학교에서는 전자 의료 기록 시스템을 시행하는 지도자가 이제는 데이터 마이닝에 관해 지침을 제공합니다 이는 입원 및 외래진료를 위한 전자 의료 기록 배포에서 미국 최초로 최고 수준을 받은 의료 기관이죠 이 놀라운 노력을 통해, 혁신적인 분석 연구를 위한 익명으로 된 데이터를 만들어냈죠 보다 정교한 빅 데이터 분석 기능을 개발하는 것은 의료 기관들이 기본적인 기술 분석에서 벗어나 예측력이 높은 통찰을 하도록 도왔죠 데이터 과학 덕분에요 재난 대비 분야에서, 데이터 과학 도구를 이용해생명을 살리는 기술은 수년 동안 개발되어왔습니다 예측 분석 도구의 사용은 다양한 방법으로 새로운 데이터 분석을 개선하고 만들어냈죠 그 어느 때보다 더 빠르게 경보를 발했습니다 규모가 크고 고품질인 데이터 집합은 다양한 종류의 자연 재해가 발생하는 것을 예측할 때 사용되죠 수천명의 삶과 죽음을 가를수 있습니다 홍수, 지진, 토네이도, 허리케인과 화산 분출은 데이터 과학의 도움으로 예측될 수 있습니다 영국의 워릭대학교는 최근 연구에서 소셜 미디어 콘텐츠를 사용했습니다 여러 기후 변화가 일어나는 것을 추적할 때 사진이나 키워드를 이용하는 것처럼요 과학자나 기상 관측소에 의해 기록된 정보가 추가될 때, 이런 종류의 데이터는 지역의 기후 변화 예측을 개선하는 데 사용됩니다 이러한 지식의 실질적인 이점이 굉장히 중요하기 때문에, 학교들은 그들의 교과 과정에 이러한 종류의 데이터 과학 교육을 포함시키기 시작했죠 예를 들어, 시카고 대학의 그레이엄 스쿨은 위협 및 대응 관리에 관한 이학 석사 학위를 제공합니다 데이터 과학 도구는 기관들이 각양각색의 자료로부터 얻은 방대한 양의 데이터를 분석하도록 하고, 그 정보를 제시해 데이터 과학자들이 새로운 지식을 얻도록 하죠.
