회귀 분석에서 가장 중요한 네 가지 메트릭이 있습니다. MAE (평균 절대 오차) 는 모형에 적합된 값과 관측된 과거 데이터 간의 평균 절대 차이입니다. MSC 또는 평균 제곱 오차는 모형이 피팅한 값과 관측값 간의 차이 제곱의 합을 과거 점의 수에서 모형의 매개변수 수를 뺀 값입니다. RMSE 또는 제곱근 평균 오차는 MSC의 제곱근입니다. 이는 목표 변수와 단위가 동일하여 MSC보다 해석하기 쉽기 때문에 널리 사용되는 평가 지표입니다.

R-제곱은 독립 변수가 설명할 수 있는 종속 변수의 분산량입니다. 결정 계수라고도 하며 모델의 적합도를 측정합니다. 값의 범위는 0에서 1까지이며, 0은 적합하지 않은 모델이고 1은 완벽한 모델입니다. 실생활에서는 완벽한 모델이 없기 때문에 0과 1 사이의 값은 실제 시나리오에서 기대할 수 있는 값입니다. 모델의 예측값 y i-hat을 실제 값 y-l과 비교하는 다음과 같은 평가 메트릭을 고려해 보십시오.

어떤 단일 평가 지표도 적합도를 보편적으로 잘 측정할 수는 없습니다. 모형의 실제값과 예측값을 플로팅하여 회귀 모형이 레이블에 얼마나 잘 맞는지 확인하십시오. 설명 분산은 예측과 실제 대상 데이터의 평균값 간의 차이 제곱의 합입니다. 완벽한 예측 변수의 경우 설명된 분산은 목표값의 총 분산과 동일합니다. 여기서 일반적으로 시그마 제곱으로 표시되는 총 분산은 평균값을 기준으로 목표값의 전체 변수를 측정합니다.

R 제곱은 입력 변수에서 예측 가능한 목표 변수의 분산 비율을 측정하는 인기 평가 지표입니다. R 제곱은 모델 성능을 설명하기 위한 간단한 척도로, 모델이 결과 변동의 85% 를 설명한다고 주장하며 기술 전문가가 아닌 사람도 쉽게 이해할 수 있습니다. R squared는 목표값이 입력 특징과 선형적으로 관련되어 있다고 가정한다는 점을 기억해야 합니다. 비선형 모델의 경우 오해의 소지가 있을 수 있습니다. 모형이 모든 데이터 점을 완벽하게 예측하는 경우, 이 경우 y i-hat은 모든 i에 대해 y i와 같으며, 설명된 분산은 전체 분산과 동일하며 설명할 수 없는 분산은 0입니다.

따라서 R 제곱은 완벽한 모델을 위한 것입니다. 모델의 예측이 매우 단순하여 모든 데이터 포인트에 대한 데이터의 평균을 지속적으로 예측한다고 가정해 보겠습니다. 이 경우 설명된 분산이 0이고 전체 분산이 정확히 설명할 수 없는 분산이기 때문에 분산을 설명하지 않습니다. 따라서 단순 평균값 모델의 경우 R 제곱은 0입니다. R 제곱 값이 음수이면 모형의 성능이 너무 낮아 설명할 수 없는 분산이 전체 분산을 초과한다는 의미입니다.

여기서는 일반적으로 로그 정규 분포라고 하는 지수 분포를 사용하여 시뮬레이션된 목표 변수를 기반으로 하는 세 가지 선형 회귀 결과를 보여줍니다. 선형 모델은 목표 변수의 세 가지 버전, 즉 원래 목표값, 목표값의 Box-Cox 변환 버전, 로그 변환 버전에 적합합니다. 시각적으로 볼 때 모델이 대상 데이터에 점점 더 적합하다는 것을 알 수 있습니다. 변환할 때마다 데이터가 가장 적합한 선을 중심으로 집중되기 때문입니다. 변환된 대상에 맞는 세 가지 모델 각각에 대해 표시되는 다양한 평가 지표는 결과에 대한 시각적 직관과 모두 일치합니다.

Box-Cox 및 로그 변환의 경우 R 제곱이 크게 증가했으며 오류 메트릭 MAE, MSE 및 RMSE가 모두 크게 개선되었습니다. 이 비디오에서는 회귀 모델을 평가하려면 모형이 연속형 수치값을 얼마나 정확하게 예측할 수 있는지를 결정해야 한다는 것을 배웠습니다. 모델의 오차는 알고리즘에 의해 생성된 추세선과 데이터 요소 간의 차이를 측정한 값입니다. 필수 회귀 측정 지표는 AME, MSE, RMSE 및 R 제곱입니다. 설명 분산은 예측과 실제 대상 데이터의 평균값 간의 차이 제곱의 합입니다.

R 제곱은 입력 변수에서 예측 가능한 목표 변수의 분산 비율을 측정합니다.
