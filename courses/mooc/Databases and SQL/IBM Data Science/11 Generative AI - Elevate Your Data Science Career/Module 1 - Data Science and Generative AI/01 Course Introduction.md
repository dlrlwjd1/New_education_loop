- 재생 시간: 3분
- [MOOC 원본 강의](https://www.mooc.org/learn/generative-ai-elevate-your-data-science-career/lecture/SAR2d/course-introduction)
- 데이터 과학자가 사실적인 이미지를 생성하여 부족한 데이터 세트를 보강하거나, 매력적인 내러티브가 포함된 맞춤형 보고서를 작성하거나, 강력한 AI 모델의 개발을 가속화하기 위해 방대한 양의 교육 데이터를 합성할 수 있는 세상을 상상해 보십시오.
- 이 능력은 제너레이티브 AI가 제공하는 혁신적인 잠재력입니다.

## 내용
### 핵심 내용
- 데이터 과학자가 사실적인 이미지를 생성하여 부족한 데이터 세트를 보강하거나, 매력적인 내러티브가 포함된 맞춤형 보고서를 작성하거나, 강력한 AI 모델의 개발을 가속화하기 위해 방대한 양의 교육 데이터를 합성할 수 있는 세상을 상상해 보십시오.
- 이 능력은 제너레이티브 AI가 제공하는 혁신적인 잠재력입니다.
- 데이터 과학자, 데이터 분석가 또는 데이터 엔지니어로서 다양한 영역에서 혁신적인 솔루션을 활용하면서 AI 기술의 윤리적 배포를 보장하면서 제너레이티브 AI 물결을 타고자 한다면 이 과정이 적합합니다.
- 첫 번째 모듈에서는 데이터 과학에 사용할 수 있는 다양한 제너레이티브 AI 툴과 다양한 산업의 데이터 전문가를 위한 제너레이티브 AI의 응용에 대해 알아봅니다.
- 다음 모듈에서는 다양한 생성 AI 도구를 사용하여 데이터 세트에서 인사이트를 도출하고 데이터 시각화에 생성 AI를 사용하는 방법을 알아봅니다.
- 또한 제너레이티브 AI를 사용하여 효율적인 예측 모델을 개발하는 방법과 제너레이티브 AI를 사용하는 동안 데이터 과학자가 직면하는 고려 사항 및 문제를 이해하는 방법을 배우게 됩니다.
