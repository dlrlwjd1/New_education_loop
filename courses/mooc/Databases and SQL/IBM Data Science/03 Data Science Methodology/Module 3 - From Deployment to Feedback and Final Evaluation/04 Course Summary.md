# Course Summary

## 개요
- 강좌: Data Science Methodology
- 모듈: From Deployment to Feedback and Final Evaluation
- 재생 시간: 3분
- [MOOC 원본 강의](https://www.mooc.org/learn/data-science-methodology/lecture/9T8nq/course-summary)
- 데이터 과학 문제를 해결하고 흥미로운 실제 사례에 적용하는 단계를 포함하여 데이터 과학자처럼 생각하는 법을 배웠습니다.
- 이러한 단계에는 구체적인 비즈니스 또는 연구 문제 형성, 데이터 수집 및 분석, 모델 구축, 모델 배포 후 피드백 이해 등이 포함됩니다.

## 내용
### 핵심 내용
- 데이터 과학 문제를 해결하고 흥미로운 실제 사례에 적용하는 단계를 포함하여 데이터 과학자처럼 생각하는 법을 배웠습니다.
- 이러한 단계에는 구체적인 비즈니스 또는 연구 문제 형성, 데이터 수집 및 분석, 모델 구축, 모델 배포 후 피드백 이해 등이 포함됩니다.
- 이 과정에서는 질문을 이해하는 것의 중요성, 비즈니스 목표 및 목적, 질문에 답하고 문제를 해결하기 위한 가장 효과적인 분석 접근 방식을 선택하는 등 문제에서 접근 방식으로 전환하는 체계적인 방법도 배웠습니다.
- 또한 데이터를 사용하는 체계적인 방법, 특히 데이터 요구 사항을 결정하고, 적절한 데이터를 수집하고, 데이터를 이해한 다음 모델링을 위한 데이터를 준비하는 방법도 배웠습니다!
- 또한 데이터 요구 사항과 해결하려는 문제를 기반으로 적절한 분석 접근 방식을 사용하여 데이터를 모델링하는 방법도 배웠습니다.
- 10개의 간단한 질문에 체계적으로 답함으로써 방법론이 데이터 과학 문제뿐만 아니라 다른 문제도 해결하는 데 도움이 될 수 있다는 것을 배웠습니다.
