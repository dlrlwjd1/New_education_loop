### 한국어 Transcript

데이터 과학과 AI를 위해 제가 배워야 할 프로그래밍 언어가 딱 하나 있다면 의심할 여지 없이 Python일 것입니다. 가장 좋은 점은 Python은 배우기가 매우 쉽고 사람들이 코딩을 배우려고 할 때 가장 먼저 사용하는 언어 중 하나라는 것입니다. 거대한 라이브러리 에코시스템을 갖추고 있어 코드 몇 줄만으로 가장 복잡한 작업을 수행할 수 있습니다. Python은 데이터 분석, 웹 스크래핑부터 빅 데이터 작업, 재무, 컴퓨터 비전, 자연어 처리, 기계 학습, 딥 러닝 등에 이르기까지 모든 것에 훌륭합니다. 파이썬은 당신이 할 수 있는 모든 것을 할 수 있습니다.

이 과정은 초보자를 위해 설계되었지만 프로그래밍 방법을 알고 있다면 이 과정을 수강하여 파이썬을 빠르게 배울 수도 있습니다. 모듈 1에서는 유형, 표현식, 변수, 문자열 연산 등 파이썬 기본 사항을 배우게 됩니다. 모듈 2에서는 목록, 튜플, 사전 및 집합을 비롯한 Python 데이터 구조를 다룹니다. 모듈 3에서는 조건, 분기, 루프, 함수, 객체 및 클래스와 같은 파이썬 프로그래밍의 기초를 가르칠 것입니다. 모듈 4에서는 Python의 내장 함수로 데이터를 로드하고, NumPy와 Pandas와 같은 인기 라이브러리, 그리고 애플리케이션 프로그래밍 인터페이스, 줄여서 API를 사용하는 등 데이터를 다루는 방법을 가르칠 것입니다.

실제 데이터세트를 사용하여 프로젝트를 수행하면서 배운 내용을 적용할 수 있습니다. 질문이 있거나 설명이 필요한 경우 언제든지 코스 토론 포럼에 게시하세요.
