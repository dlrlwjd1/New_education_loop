### 한국어 Transcript

데이터 과학용 도구에 관한 이 교육 과정에 오신 것을 환영합니다. 이 과정은 데이터 과학자가 되고자 하는 모든 학습자를 대상으로 합니다. 데이터 과학자는 데이터를 다루게 되며, 이 과정을 통해 분석하고 결론을 도출하는 데 사용할 수 있는 다양한 도구에 대한 지식을 얻을 수 있습니다. 프로그래밍 지식이 있든 없든 이 과정을 수강할 수 있습니다. 이제 데이터 과학자의 도구 키트는 많은 도구로 구성되어 있습니다.

이 과정에서는 다음 모듈에서 다양한 도구를 살펴보겠습니다. 모듈 1, 데이터 과학 도구 개요 모듈 2, 데이터 과학의 언어 모듈 3, 라이브러리, API, 데이터세트, 모델 모듈 4, 주피터 프로젝트. 모듈 5, RStudio 및 GitHub 모듈 6, 최종 프로젝트, Jupyter Notebook 만들기 모듈 1에서는 다양한 범주의 데이터 과학 도구와 각 범주의 오픈 소스 및 상용 제품의 예에 대해 알아봅니다. 또한 도구가 기능면에서 어떻게 겹치는지, 장단점이 무엇인지 배우게 됩니다. 모듈 2에서는 Python, R, Scala, Java, Julia 및 SQL과 같은 데이터 과학에서 사용할 수 있는 일반적으로 사용되는 언어와 그 용도에 대한 개요를 제공합니다.

세 번째 모듈에서는 다양한 기능을 제공하는 내장 모듈을 포함하는 라이브러리에 대해 배웁니다. 또한 응용 프로그래밍 인터페이스 또는 API를 통해 두 소프트웨어 간의 통신이 가능하다는 것도 알게 됩니다. 마지막으로 머신러닝 또는 ML이 모델이라고도 하는 알고리즘을 사용하여 데이터의 패턴을 식별하는 방법을 알아봅니다. 모듈 4에서는 데이터 과학자들 사이에서 가장 일반적으로 사용되는 환경 중 하나인 Project Jupyter에 대해 알아봅니다. 프로젝트 주피터 (Jupyter Notebook) 의 세 가지 주요 애플리케이션인 주피터 노트북 (Jupyter Notebook), 주피터 랩 (JupyterLab), 주피터 라이트를 살펴보겠습니다.

또한 IBM Watson Studio 및 Google Colab과 같은 상용 Jupyter 기반 애플리케이션을 소개합니다. 이 모듈에서는 Anaconda와 같은 자체 시스템에 설치할 수 있는 Jupyter 배포판에 대한 개요도 제공합니다. 모듈 5는 R 및 RStudio에 대한 소개로 시작합니다. 다양한 R 시각화 패키지와 plot 함수를 사용하여 시각적 차트를 만드는 방법에 대해 알아봅니다. 또한 데이터 과학자가 프로젝트를 공유하고 포트폴리오를 소개하는 데 사용할 수 있는 인기 있는 버전 제어 플랫폼인 GitHub에 대해서도 알아봅니다.

모듈 6에서는 Jupyter Notebook을 만들고 공유하는 최종 프로젝트를 진행하게 됩니다. 여기서 다루어야 할 내용이 많습니다. 이 과정을 최대한 활용하려면 각 비디오 시청을 완료하고 모든 실습을 완료한 다음 각 퀴즈에서 학습 내용을 확인하십시오. 데이터 과학 여정을 위한 도구를 시작할 때 저희와 함께하게 되어 매우 기쁩니다. 과정 자료에 문제가 있는 경우 언제든지 토론 포럼을 통해 문의하시기 바랍니다.

Now, a data scientist's tool kit consists of many tools, and in this course, you will explore a variety of them in the following modules.

Module 1, overview of data science tools. Module 2, languages of data science. Module 3, libraries, APIs, datasets, and models. Module 4, Jupyter Project. Module 5, RStudio and GitHub.

Module 6, final project, create a Jupyter Notebook. In Module 1, you will learn about the different categories of data science tools and examples of open source and commercial offerings in each category. Module 2 will give you an overview of the commonly used languages that are available in data science like Python, R, Scala, Java, Julia, and SQL, and what they are used for. In the third module, you will learn about libraries that contain built in modules providing different functionalities.

You will also learn that an application programming interface or API allows communication between two pieces of software. Finally, you will learn how machine learning or ML uses algorithms, also known as models, to identify patterns in the data. In Module 4, you will learn about Project Jupyter, one of the most commonly used environments among data scientists. You will explore the three main applications of Project Jupyter: Jupyter Notebook, JupyterLab, and JupyterLite. In addition, you will be introduced to commercial Jupyter based applications such as IBM Watson Studio and Google Colab; and this module also gives an overview of Jupyter distributions that can be installed on your own system like Anaconda.

Module 5 will start with an introduction to R and RStudio. You will learn about the different R visualization packages and how to create visual charts using the plot function. In addition, you will learn about GitHub, a popular version control platform that data scientists can use for sharing their projects and showcasing their portfolios. In Module 6, you will work on your final project in which you will create and share your Jupyter Notebook. There's a lot to cover here.
