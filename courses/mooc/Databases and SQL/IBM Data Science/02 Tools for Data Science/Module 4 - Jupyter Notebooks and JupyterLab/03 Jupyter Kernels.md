# Jupyter Kernels

## 개요
- 강좌: Tools for Data Science
- 모듈:  Jupyter Notebooks and JupyterLab
- 재생 시간: 2분
- [MOOC 원본 강의](https://www.mooc.org/learn/open-source-tools-for-data-science/lecture/Vlf3Y/jupyter-kernels)
- 노트북 커널은 Notebook 파일에 포함된 코드를 실행하는 계산 엔진입니다.

### 한국어 Transcript

“주피터 커널”에 오신 것을 환영합니다. 이 비디오를 보고 나면 커널을 정의하고 커널을 사용하는 방법을 설명할 수 있을 것입니다. 노트북 커널은 Notebook 파일에 포함된 코드를 실행하는 계산 엔진입니다. 여러 언어를 위한 Jupyter 커널이 존재하며, 데이터 과학과 관련된 몇 가지를 살펴보겠습니다. Notebook 문서가 열리면 관련 커널이 자동으로 실행됩니다.

노트북이 실행되면 커널이 계산을 수행하고 결과를 생성합니다. 설정에 따라 Jupyter 환경에 다른 노트북 언어를 설치해야 할 수도 있습니다. 스킬 네트워크 랩 환경에는 몇 가지 언어가 사전 설치되어 있습니다. 노트북을 실행할 때 데이터 과학 프로젝트에 관심이 있는 언어를 선택하세요. Python 커널을 사용하면 파이썬 셀을 실행할 수 있습니다.

셀에서 Python 스크립트를 실행하여 출력을 생성할 수 있습니다. 노트북의 오른쪽 상단에는 커널 이름이 표시됩니다. 여기서는 Python 커널을 보여줍니다. 다른 커널을 실행할 수 있는 옵션이 있습니다. 스킬 네트워크 가상 주피터 환경에는 아파치, 줄리아, R, 스위프트가 있습니다.

시작 페이지에서 커널을 선택하거나 오른쪽 상단 아이콘을 클릭하고 드롭다운 메뉴에서 커널을 선택하면 원하는 언어를 사용하여 코드를 실행할 수 있습니다. 로컬 컴퓨터에서 커널을 실행하는 경우 명령줄 인터페이스 (CLI) 를 통해 언어를 수동으로 설치해야 합니다. 이 비디오에서는 커널이 계산 엔진처럼 작동하며 Notebook 파일에서 코드를 실행한다는 것을 배웠습니다. Jupyter Notebook은 다양한 언어를 지원하며 요구 사항에 따라 다른 커널로 전환할 수 있습니다.

Welcome to “Jupyter Kernels.” After watching this video, you will be able to define a kernel, and describe how to work with kernels. A notebook kernel is a computational engine that executes the code contained in a Notebook file. Jupyter Kernels for many languages exist, and we will explore some that are relevant in Data Science. When a Notebook document opens, the related kernel launches automatically. When the Notebook is executed, the kernel performs the computation and produces the results.

Depending on your settings, you may need to install other notebook languages in your Jupyter environment. In the Skills Network lab environment, a few languages have been pre-installed for you. The first one is the Python kernel. When you launch a notebook, pick the language you are interested in for your Data Science project. The Python kernel allows you to run python cells.

You can run the Python script in the cells to produce an output. The top right corner of the Notebook shows the name of the kernel. Here it shows the Python kernel. You have the option to run other kernels. The Skills Network virtual Jupyter environment has Apache, Julia, R, and Swift.

You can use any language to execute your code, either by selecting the kernel on the launch page or clicking the top right icon and selecting the kernel from the drop-down menu. If running the kernel on your local machine, you will need to manually install the languages through your command line interface (CLI). In this video, you learned that The kernel acts like a computational engine and executes the code in a Notebook file. Jupyter Notebook supports different languages, and you can switch to a different kernel as per your requirement.
