“Jupyter 노트북 소개”에 오신 것을 환영합니다. 이 비디오를 시청한 후에는 Jupyter 노트북을 정의하고, JupyterLab을 사용하는 방법을 설명하고, JupyterLab에서 노트북을 사용하는 방법을 설명할 수 있습니다. Jupyter 노트북은 원래 파이썬 프로그래밍을 위해 개발된 “IPython”이라는 이름으로 시작되었습니다. 이후 추가 언어를 지원하기 시작하면서 Julia, Python, R의 약자인 Jupyter로 이름이 변경되었지만 지금은 다른 많은 언어를 지원합니다. Jupyter Notebook은 코드, 방정식, 시각화, 설명 텍스트 링크 등이 포함된 문서를 만들고 공유할 수 있는 브라우저 기반 애플리케이션입니다.

마치 과학자가 실험을 수행하는 모든 단계를 기록하고 재현할 수 있는 결과를 기록하는 과학자의 실험 공책과 같습니다. 마찬가지로 Jupyter Notebook을 사용하면 데이터 과학자가 데이터 실험과 결과를 기록하여 다른 사람들이 재사용할 수 있습니다. 이제 Jupyter Notebook 파일을 사용하여 설명 텍스트, 코드 블록 및 코드 출력을 단일 파일에 결합할 수 있습니다. 코드를 실행하면 노트북 파일 내에 플롯과 테이블을 포함한 출력이 생성됩니다. 그런 다음 노트북을 PDF 또는 HTML 파일 형식으로 내보낸 다음 다른 사람과 공유할 수 있습니다.
