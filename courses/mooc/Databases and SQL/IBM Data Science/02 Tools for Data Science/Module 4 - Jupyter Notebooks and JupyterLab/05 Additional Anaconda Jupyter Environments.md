### 한국어 Transcript

추가 아나콘다 목성 환경에 오신 것을 환영합니다. 이 비디오를 시청한 후에는 아나콘다와 그 데이터 과학 기능에 대해 설명하고 아나콘다 목성 환경을 설명하고 아나콘다 목성 환경의 도구를 식별할 수 있습니다. 컴퓨팅 노트북은 코드, 연산 출력, 설명 텍스트, 멀티미디어 리소스를 하나의 문서로 결합합니다. Jupyter Notebook은 수십 개의 프로그래밍 언어를 지원하기 때문에 널리 사용되는 컴퓨팅 노트북 유형입니다. JupyterLab과 VS Code는 로컬 장치에서 주피터 노트북을 만들고 수정하는 데 널리 사용되는 환경입니다.

JupyterLab은 주피터 노트북을 기반으로 하는 오픈 소스 웹 기반 애플리케이션입니다. Jupyter Notebook과 마찬가지로 코드, 대화형 시각화 , 텍스트 및 방정식을 만들 수 있습니다. JupyterLab에는 NumPy, Pandas, Matplotlib 등 아나콘다에서 가장 광범위하게 사전 설치된 파이썬 라이브러리와 함께 확장된 기능이 포함되어 있습니다. Anaconda는 데이터 과학 및 기계 학습에 가장 많이 사용되는 언어인 Python과 R의 무료 오픈 소스 배포자입니다. 아나콘다에는 1,500개 이상의 라이브러리가 있습니다.

설치는 무료이며 Python에 대한 도움이 필요한 모든 사용자를 위한 무료 커뮤니티 지원을 제공합니다. 다운로드 가능한 Anaconda Navigator 그래픽 사용자 인터페이스를 통해 사용자는 명령줄 인터페이스나 'CLI'를 사용하지 않고도 로컬 장치에 새 패키지를 설치할 수 있습니다. 주어진 URL에서 아나콘다 내비게이터를 다운로드할 수 있습니다. 아나콘다 내비게이터 홈페이지는 다음과 같습니다. JupyterLab을 실행하려면 JupyterLab 상자에서 실행을 클릭하십시오.

시작 버튼이 없는 경우 먼저 설치를 클릭한 다음 실행을 클릭합니다. 주피터 노트북으로 시작하려면 검색 창에 주피터 노트북 (anaconda3) 을 입력하고 엔터를 누르세요. 로컬 호스트의 브라우저에서 JupyterLab 대시보드가 열립니다. Jupyter 노트북을 관리하도록 특별히 설계되었습니다. 새 Jupyter 노트북을 만들려면 새로 만들기를 클릭하고 Python 3을 선택합니다.

그러면 새 탭에 새 노트북이 열립니다. 파일 이름과 커널을 보여주는 URL이 표시됩니다. 또한 마지막 체크포인트도 표시됩니다. Untitled를 클릭하여 노트북 이름을 변경해 보겠습니다. 노트북의 이름을 입력하고 이름 바꾸기를 클릭합니다.

이제 코드와 마크다운이라는 두 가지 주요 셀 유형을 살펴보겠습니다. 드롭다운 메뉴에서 코드를 선택합니다. 코드 셀에는 커널에서 실행할 코드가 들어 있으며 해당 결과가 표시됩니다. 또는 드롭다운 메뉴에서 마크다운을 선택합니다. 마크다운 셀에는 리치 텍스트가 포함되어 있으며 실행 시 출력이 제자리에 표시됩니다.

노트북을 다운로드하려면 파일로 이동하여 다른 이름으로 다운로드를 클릭합니다. VS Code는 디버깅 및 작업 실행 작업을 위한 무료 오픈 소스 코드 편집기입니다. VS 코드는 리눅스, 윈도우, 맥OS에서 작동합니다. 다국어, 구문 강조, 자동 들여쓰기 등을 지원합니다. VS Code는 가장 널리 사용되는 개발 환경 도구 중 하나입니다.

Anaconda Navigator를 사용하지 않고 VS 코드를 별도로 설치하려는 경우 code. com으로 이동하여 장치에 해당하는 다운로드 옵션을 클릭한 다음 설치 지침을 따르세요. VS Code를 별도로 설치하면 아나콘다 내비게이터와 동일하게 작동하지만 아나콘다, 파이썬 또는 주피터 노트북용으로 구성되지는 않습니다. 아나콘다 내비게이터를 사용하여 VS Code를 열려면 아나콘다 내비게이터를 열고 VS Code 애플리케이션을 찾아 실행을 클릭하십시오. 설치가 완료되면 시작하기 화면이 나타납니다.

VS Code에서 Python 코드를 실행하려면 몇 가지 확장 프로그램을 설치해야 합니다. 먼저 확장 프로그램을 클릭하거나 Ctrl + Shift + X 키를 사용하여 확장 프로그램을 엽니다. 그런 다음 “Python”을 검색하면 Python과 관련된 모든 확장 프로그램이 나타납니다. 확장 프로그램을 설치한 후 파일을 클릭합니다. 새 파일에서 Jupyter Notebook을 선택합니다.

노트북은 다음과 같이 보일 것입니다. 커널이 Python이라는 점을 주목하세요. 코드를 작성한 다음 RUN 아이콘을 사용하여 실행합니다. 코드가 성공적으로 실행되었다는 확인 메시지가 나타납니다. 마지막으로 파일로 이동하여 저장을 선택합니다.

이 비디오에서는 Jupyter가 수십 개의 프로그래밍 언어를 지원하기 때문에 널리 사용되는 컴퓨터 노트북 도구라는 것을 알게 되었습니다. Anaconda Navigator GUI는 로컬 장치에서 여러 애플리케이션을 실행할 수 있습니다. 아나콘다 내비게이터의 주피터 환경에는 JupyterLab 및 VS Code가 포함됩니다. 또한 아나콘다 내비게이터와 별도로 Jupyter 환경을 다운로드할 수 있지만 제대로 구성되지 않을 수 있습니다.
