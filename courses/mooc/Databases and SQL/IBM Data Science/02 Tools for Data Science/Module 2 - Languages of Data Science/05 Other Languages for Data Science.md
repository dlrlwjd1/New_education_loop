하지만 자바스크립트, PHP, Go, Ruby, Visual Basic 및 기타 많은 분야가 데이터 과학 커뮤니티에서 제자리를 찾았습니다. 그 중 몇 가지에 대한 몇 가지 주목할 만한 하이라이트를 살펴보겠습니다. Java는 검증된 범용 객체 지향 프로그래밍 언어입니다. 기업 공간에서 널리 사용되고 있으며 빠르고 확장 가능하도록 설계되었습니다. Java 애플리케이션은 바이트코드로 컴파일되고 Java 가상 머신 또는 JVM에서 실행됩니다.

Java로 구축된 주목할만한 데이터 과학 도구로는 데이터 마이닝을 위한 Weka, 기계 학습을 위한 Java-ML, 기계 학습을 확장 가능하게 하는 Apache Mllib, 딥 러닝을 위한 Deeplearning4 등이 있습니다. 하둡은 클러스터 시스템에서 실행되는 빅데이터 애플리케이션의 데이터 처리 및 스토리지를 관리하는 Java의 또 다른 애플리케이션입니다. Scala는 함수형 프로그래밍을 지원하는 범용 프로그래밍 언어이며 강력한 정적 형식 시스템입니다. Scala 언어는 Java의 단점을 해결하기 위해 만들어졌습니다. 또한 JVM에서 실행되므로 Java와 상호 운용이 가능합니다.

Scala라는 이름은 확장성과 언어의 조합입니다. 이 언어는 사용자의 요구 사항에 따라 발전하도록 설계되었습니다. 데이터 사이언스의 경우 Scala로 빌드된 가장 인기 있는 프로그램은 Apache Spark입니다. Spark는 병렬 작업을 쉽게 작성할 수 있는 API를 제공하는 빠른 범용 클러스터 컴퓨팅 시스템입니다. 일반 계산 그래프를 지원하는 최적화된 엔진을 갖추고 있습니다.

Spark에는 쿼리 엔진인 Shark, 머신 러닝을 위한 Mllib, 그래프 처리를 위한 GraphX, Spark 스트리밍이 포함됩니다. C++는 범용 프로그래밍 언어입니다. 이 언어는 C 프로그래밍 언어 또는 “클래스가 있는 C”의 확장입니다. C++는 처리 속도를 향상시키고 시스템 프로그래밍을 가능하게 하며 소프트웨어 응용 프로그램을 더 광범위하게 제어할 수 있도록 합니다. 데이터 분석 및 탐색 작업에 Python이나 기타 고급 언어를 사용하는 많은 조직에서는 고객에게 실시간으로 데이터를 제공하는 프로그램을 개발하기 위해 C++를 사용합니다.

데이터 과학의 경우 TensorFlow는 C++로 구축된 인기 있는 데이터 흐름용 딥 러닝 라이브러리입니다. C++는 TensorFlow의 기반이지만 Python 인터페이스에서 실행되므로 사용자는 C++에 대한 지식이 없어도 실행할 수 있습니다. MongoDB는 C++로 구축된 빅데이터 관리를 위한 NoSQL 데이터베이스입니다. Caffe는 Python 및 Matlab 바인딩이 포함된 C++로 구축된 딥 러닝 알고리즘 리포지토리입니다. 월드 와이드 웹의 핵심 기술인 JavaScript는 Node.

js 및 기타 서버 측 접근 방식을 만들면서 브라우저를 넘어 확장된 범용 언어입니다. 자바스크립트는 자바 언어와 관련이 없습니다. 데이터 사이언스의 경우 의심할 여지 없이 TensorFlow. js 가 가장 인기 있는 구현입니다. js 뿐만 아니라 브라우저에서도 기계 학습과 딥 러닝이 가능합니다.

js 및 ks를 포함한 다른 오픈 소스 라이브러리에서도 채택되었습니다. js 데이터 과학을 위한 자바스크립트의 또 다른 구현은 R-JS입니다. R-JS 프로젝트는 R 언어의 선형 대수 사양을 타이프스크립트로 다시 작성했습니다. 이는 Python의 Numpy 및 SciPy와 같은 더 강력한 수학 기반 프레임워크를 구현하는 향후 프로젝트의 토대를 마련합니다. 타이프스크립트는 자바스크립트의 상위 집합입니다.

마지막으로 Julia는 MIT에서 고성능 수치 분석 및 계산 과학을 위해 설계되었습니다. Julia는 Python이나 R과 같은 빠른 개발을 제공하는 동시에 C 또는 Fortran 프로그램만큼 빠르게 실행되는 프로그램을 제작합니다. Julia 코드가 컴파일되었으므로 Julia 코드가 프로세서에서 실행 코드로 직접 실행됩니다. C, Go, Java, MATLAB, R, 포트란, Python 라이브러리를 호출하며 병렬 처리 기능이 개선되었습니다. Julia라는 언어는 2012년에 작성된 지 겨우 8년이 지났지만, 향후 데이터 과학 산업에 미칠 영향은 무궁무진합니다.

데이터 과학에 Julia를 잘 응용한 것 중 하나는 JuliaDB입니다. JuliaDB는 대규모 영구 데이터 세트를 처리하기 위한 패키지입니다. 이 비디오에서는 Java로 빌드된 데이터 과학 도구에는 Weka, Java-ML, Apache MLib 및 딥러닝4가 포함된다는 것을 배웠습니다. 데이터 사이언스의 경우 Scala로 빌드한 인기 있는 프로그램은 아파치 스파크입니다. 이 프로그램에는 샤크, MLib, GraphX, Spark Streaming이 포함됩니다.

데이터 사이언스의 경우 텐서플로우, 몽고DB, 카페는 C++로 구축되었습니다. 자바스크립트로 데이터 과학을 위해 구축한 프로그램에는 TensorFlow. 데이터 과학을 위한 Julia의 훌륭한 애플리케이션 중 하나는 JuliaDB입니다.
