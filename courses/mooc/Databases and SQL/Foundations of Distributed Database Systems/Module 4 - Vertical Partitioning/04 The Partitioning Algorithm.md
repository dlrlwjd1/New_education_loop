# The Partitioning Algorithm

## 개요

- clustered affinity matrix에서 실제 수직 fragment의 절단점 `Z`를 선택하는 알고리즘을 설명한다.
- 한쪽 fragment 질의는 많이 담고 양쪽을 가로지르는 질의는 적게 만드는 경계를 찾는다.

## 내용

### 질의 집합 분류

후보 절단점마다 질의를 세 집합으로 나눈다.

- `TQ`: 위쪽 속성 집합만 사용하는 질의
- `BQ`: 아래쪽 속성 집합만 사용하는 질의
- `OQ`: 양쪽 fragment를 모두 사용하는 질의

각 질의의 전체 사이트 접근 빈도를 합산해 `CTQ`, `CBQ`, `COQ`를 구한다.

### 절단점 점수

강의의 점수는 `CTQ × CBQ − COQ²`이다. fragment 내부 질의 빈도는 보상하고, 두 fragment를 join해야 하는 질의 빈도는 제곱으로 크게 벌점 준다. 모든 경계에서 계산해 가장 큰 값을 선택한다.

### 알고리즘 한계

행·열의 시작 순서에 따라 cluster가 행렬 경계에 걸칠 수 있어 순환 이동 후 다시 평가해야 한다. 절단점이 여러 개일 가능성까지 모두 탐색하면 다시 지수적 문제가 되므로 재귀와 중단 조건 같은 개선이 필요하다.

## 예시

```text
후보 Z:
CTQ = 45
CBQ = 75
COQ = 8

Z score = 45 × 75 − 8² = 3311
```

## 요약

- 좋은 절단점은 각 fragment 내부 질의가 많고 교차 질의가 적다.
- 접근 횟수를 사용해 실제 workload를 점수에 반영한다.
- 여러 절단점과 열 순서 문제 때문에 결과를 검증하고 반복 개선해야 한다.
