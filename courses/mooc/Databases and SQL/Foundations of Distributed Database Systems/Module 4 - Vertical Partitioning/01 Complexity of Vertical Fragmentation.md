# Complexity of Vertical Fragmentation

## 개요

- 수직 fragmentation의 가능한 속성 그룹 수가 Bell 수(Bell number)로 빠르게 증가함을 설명한다.
- 전수 탐색 대신 휴리스틱이 필요한 이유를 정량적으로 보여 준다.

## 내용

### 가능한 분할 수

비-key 열을 여러 비어 있지 않은 그룹으로 나누는 모든 경우가 후보다. 열 2개는 2가지, 3개는 5가지, 4개는 15가지, 5개는 52가지다. 열 10개만 되어도 115,975개의 분할 후보가 생긴다.

### 설계 의미

각 후보마다 사이트별 질의 비용을 계산해 최적해를 고르는 것은 현실적이지 않다. 같은 질의에서 함께 사용되는 속성을 먼저 인접하게 만드는 affinity 기반 휴리스틱으로 탐색 공간을 줄인다.

## 예시

```text
속성 {A, B, C}의 일부 후보:
{A,B,C}
{A,B} | {C}
{A,C} | {B}
{A} | {B,C}
{A} | {B} | {C}
```

각 fragment에는 원본을 재구성할 primary key가 추가로 포함된다.

## 요약

- 열 그룹 후보 수는 Bell 수에 따라 폭발적으로 증가한다.
- 열이 조금만 많아져도 완전 탐색은 비현실적이다.
- query workload 기반 친화도와 휴리스틱으로 좋은 분할을 찾는다.
