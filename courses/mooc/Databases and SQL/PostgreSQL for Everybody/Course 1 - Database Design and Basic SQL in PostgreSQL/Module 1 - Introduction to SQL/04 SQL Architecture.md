# SQL Architecture

## 개요
- 클라이언트-서버(client-server) 구조로 SQL 명령을 주고받는 방식을 설명하고, 실제로 psql 명령줄 클라이언트로 PostgreSQL에 접속해 사용자·데이터베이스·테이블을 처음 만들어보는 실습 강의

## 내용
### 클라이언트-서버 아키텍처
- 실습 환경이 로컬이든 원격 서버든, SQL은 항상 "클라이언트"가 "서버"에게 SQL 명령을 보내고 결과를 돌려받는 구조로 이해하는 것이 좋다. 클라이언트와 서버가 물리적으로 같은 컴퓨터에 있어도 이 둘은 완전히 다른 소프트웨어다.
- 서버 쪽은 디스크 I/O, 캐싱 등 수십 년간 축적된 최적화 기술이 집약된 "마법 같은" 소프트웨어이며, 사용자는 그 내부를 몰라도 SQL 명령만 보내면 된다.
- 클라이언트는 명령줄(psql), 데스크톱 GUI(pgAdmin, DBeaver) 등 다양하게 있을 수 있으나, 이 강좌는 문서화와 접근성이 좋은 명령줄(psql) 위주로 진행한다.

### 리눅스 기초와 슈퍼유저(superuser) 개념
- 서버는 보통 리눅스(Linux)에서 운영되므로, 강좌에서는 리눅스 명령어를 함께 다룬다. (Mac 터미널이나 Windows의 Bash 셸에서도 유사하게 동작한다.)
- PostgreSQL 서버를 처음 설정하면 `postgres`라는 슈퍼유저(superuser) 계정이 생기며, 이 계정은 다른 사용자를 생성하는 등 모든 권한을 가진다. 명령줄 프롬프트가 `#`(파운드 기호)이면 슈퍼유저 세션이라는 뜻이다.
- 리눅스의 `sudo` 명령(xkcd 만화의 "sudo make me a sandwich" 농담으로 설명)처럼, 슈퍼유저 권한으로는 일반 사용자가 할 수 없는 작업(예: 다른 계정 생성)을 할 수 있다.
- 원칙: 슈퍼유저 권한은 최소한으로만 사용하고, 가능한 한 빨리 권한이 낮은 일반 계정을 만들어 그 계정으로 작업해야 한다.

### 실습: 데이터베이스·사용자·테이블 만들기
- `\l` : 현재 서버의 데이터베이스 목록을 보여주는 psql 메타 명령. 초기 상태의 기본 데이터베이스들은 PostgreSQL 자체 운영에 쓰이므로 건드리면 안 된다.
- `CREATE USER` : 새 사용자(계정)를 만드는 SQL 명령.
- `CREATE DATABASE ... OWNER ...` : 새 데이터베이스를 만들고 소유자를 지정하는 SQL 명령.
- `psql <데이터베이스명> <사용자명>` : 지정한 계정으로 데이터베이스에 접속.
- `\dt` : 현재 데이터베이스의 테이블(관계, relation) 목록 확인.
- `CREATE TABLE 테이블명 (열이름 타입, 열이름 타입, ...);` : 테이블 생성. 괄호 안 내용이 스키마(schema)이며, PostgreSQL과 맺는 "계약"이다. 예를 들어 열 길이를 128자로 지정하면 129번째 문자를 저장하려 할 때 오류가 나는데, 이는 PostgreSQL이 지정된 크기에 맞춰 저장 구조를 효율적으로 최적화하기 때문이다.
- `\d+ 테이블명` : 특정 테이블의 스키마(구조)를 다시 확인.
- `\q` : psql 세션 종료.

## 예시
```sql
-- 슈퍼유저로 새 계정과 데이터베이스 생성
CREATE USER pg4e WITH PASSWORD 'secret';
CREATE DATABASE people OWNER pg4e;
```

```bash
# 새로 만든 계정으로 접속
psql people pg4e
```

```sql
-- 접속 후 테이블 생성
CREATE TABLE users (
    name VARCHAR(128),
    email VARCHAR(128)
);
```

```
\l      -- 데이터베이스 목록
\dt     -- 테이블 목록
\d+ users  -- users 테이블 스키마 확인
\q      -- 종료
```

## 요약
- SQL은 클라이언트가 서버에 명령을 보내고 결과를 받는 클라이언트-서버 구조로 동작한다.
- PostgreSQL 서버는 리눅스에서 운영되는 경우가 많으며, 슈퍼유저 권한은 최소한으로만 사용하고 이후 일반 계정으로 작업해야 한다.
- `CREATE USER`, `CREATE DATABASE`, `CREATE TABLE`이 이번 실습의 핵심 SQL 명령이며, 테이블 생성 시 지정하는 스키마는 PostgreSQL과의 "계약"으로서 저장 효율성을 위해 엄격히 지켜진다.
