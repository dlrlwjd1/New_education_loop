# Using PythonAnywhere to Run SQL

## 개요
- 무료 리눅스 셸을 제공하는 PythonAnywhere를 이용해 psql 명령으로 실습 과제를 수행하는 방법을 보여주는 실습 강의

## 내용
### PythonAnywhere 계정과 접속 정보
- PythonAnywhere 무료 계정은 사용하지 않으면 3개월 후 만료되지만, 계속 사용하면 무료로 유지된다.
- 강좌의 "Initial Database Setup" 같은 과제에 들어가면 pg4e.com에서 발급한 데이터베이스 접속 정보(호스트, 포트, 데이터베이스명, 사용자명, 비밀번호)와, 명령줄 클라이언트용 psql 접속 명령이 함께 제공된다.

### 리눅스 콘솔 기본 조작
- Bash 콘솔을 새 탭에서 열어 사용하며, 아래와 같은 기본 명령을 다룬다.
  - `ls` : 파일 목록 확인
  - `cat 파일명` : 텍스트 파일 내용 출력 (탭 키로 파일명 자동완성 가능)
  - `cd 폴더명` : 폴더 이동, `cd ..`은 상위 폴더, `cd ~`(틸드)는 홈 폴더로 이동
  - 위쪽 화살표로 이전 명령 재호출
- 파일 탭에서 제공하는 텍스트 편집기로 `.sql` 파일을 직접 열어 SQL 구문을 작성·저장할 수 있고, `nano`나 `vi` 같은 터미널 편집기도 사용 가능하다.

### psql로 접속해 SQL 실행하기
- `psql <데이터베이스명> <사용자명>` 형태로 접속 후 비밀번호를 입력(제공된 복사 버튼으로 붙여넣기 가능)하면 로그인된다.
- `\dt` : 슬래시로 시작하는 명령은 psql 전용 메타 명령이며, 테이블 목록을 보여준다.
- `SELECT * FROM 테이블명;` : 세미콜론으로 끝나는 표준 SQL 명령. psql뿐 아니라 어떤 클라이언트에서도 동일하게 동작한다.
- `\i lesson1.sql` : 지정한 파일에 저장된 SQL 명령들을 일괄 실행.
- `\q` : psql 세션을 종료하고 리눅스 셸로 복귀.
- 무료 계정에서는 콘솔을 최대 2개까지만 동시에 열 수 있으며, 콘솔 내에서 `exit`나 `Ctrl+D`를 입력하면 완전히 로그아웃(콘솔 종료)된다.

## 예시
```bash
psql <데이터베이스명> <사용자명>
```
```sql
\dt
SELECT * FROM pg4e_debug;
```
```
\i lesson1.sql
\q
```

## 요약
- PythonAnywhere는 무료로 리눅스 셸을 제공하며, psql로 원격 PostgreSQL 서버에 접속해 과제를 수행할 수 있다.
- `\`로 시작하는 명령은 psql 전용 메타 명령(예: `\dt`, `\i`, `\q`)이고, 세미콜론으로 끝나는 명령이 표준 SQL이다.
- 파일 탭의 편집기나 `nano`/`vi`로 `.sql` 파일을 작성해 `\i` 명령으로 한 번에 실행할 수 있다.
