# Up Next - Beyond CRUD (Create, Read, Update, Delete) and JOIN

## 개요
- 이 강좌(1강좌)에서 다룬 내용을 정리하고, 스페셜라이제이션의 다음 강좌에서 배우게 될 심화 주제를 미리 안내하는 마무리 강의

## 내용
### 이 강좌에서 배운 것
- 강사는 이번 강좌에서 CRUD(Create, Read, Update, Delete), JOIN, 데이터 모델링(정규화, 기본 키·논리적 키·외래 키, 일대다·다대다 관계)까지 다뤘으며, 이를 "SQL에서 가장 중요한 60%"라고 요약한다.

### 다음 강좌(Intermediate PostgreSQL)에서 다룰 주제
- 날짜(date) 처리, GROUP BY(그룹화)와 MAX·MIN·COUNT 같은 집계 함수(aggregate function)
- 트랜잭션(transaction)
- 서브쿼리(subquery)
- 저장 프로시저(stored procedure)
- 텍스트 처리와 정규 표현식(regular expression)
- 텍스트·데이터에 대한 고급 인덱싱(advanced indexing)
