# Welcome to Intermediate SQL!

## 개요
- Course 1(Database Design and Basic SQL in PostgreSQL)의 CRUD 기초를 넘어, 이 강좌에서 다룰 심화 SQL 기법들을 미리 안내하는 오리엔테이션 강의

## 내용
### 이 강좌에서 다룰 주제
- GROUP BY, 저장 프로시저(stored procedure), 서브쿼리(subquery), 집계(aggregation), 트랜잭션(transaction) 등 CRUD를 넘어서는 기법들을 다룬다.
- 강사는 이 기법들을 하나씩 배운 뒤, 이후 과제에서는 여러 기법을 조합해서 사용하게 될 것이라고 안내한다 — 예를 들어 서브쿼리 과제라도 실제로는 SELECT DISTINCT 같은 이전에 배운 기법과 함께 사용해야 하는 경우가 많다.
- 즉 한 가지 기법만 사용하는 과제를 내기 어려운 이유는, 실전 SQL에서는 여러 기법이 결합되어 쓰이기 때문이라고 설명한다.
