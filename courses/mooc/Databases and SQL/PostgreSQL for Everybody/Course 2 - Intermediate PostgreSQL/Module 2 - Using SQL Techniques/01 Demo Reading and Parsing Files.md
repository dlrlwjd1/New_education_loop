# Demo Reading and Parsing Files

## 개요
- 이어질 실습 데모(CSV 적재 및 자동 정규화)가 무엇을 자동화하려는 것인지 미리 설명하는 도입 강의

## 내용
### 이번 데모의 목표
- Course 1에서는 수직 복제된 문자열 열을 손으로 직접 여러 테이블(조회 테이블 + 외래 키)로 나누는 작업을 했다. 이번 데모에서는 그 과정을 SQL로 자동화한다 — 테이블 두 개가 아니라 임의의 개수로 확장 가능한 방식이다.
- 이를 위해 `SELECT DISTINCT`, 서브쿼리(subselect) 등 이 모듈에서 배운 기법들을 조합해서 사용할 것이라고 미리 안내한다.
- 이 방식은 온라인 서비스에 최적화된 기법은 아니지만(하위 쿼리는 온라인에서는 지양됨), 정규화되지 않은 CSV 파일을 한 번에 적절히 정규화된 데이터베이스로 변환하는 일괄 작업(batch job)에는 매우 편리한 접근이다.

### SELECT의 중요성 재확인
- CREATE, INSERT, UPDATE, DELETE는 어느 정도 익숙해졌지만, SELECT는 관계형 데이터베이스의 힘이 실제로 발휘되는 지점이며 아직 배울 것이 훨씬 많다고 강조한다. 다음 강의들에서 텍스트 데이터 처리를 통해 SELECT의 활용 폭을 더 넓힌다.
