# PostgreSQL for Everybody Specialization

- 플랫폼: MOOC
- 제공: University of Michigan
- 강사: Charles Russell Severance (Dr. Chuck)
- 링크: <https://www.mooc.org/specializations/postgresql-for-everybody>
- 수집일: 2026-07-24

PostgreSQL을 중심으로 SQL 기초 CRUD와 데이터 모델링부터 심화 SQL, JSON·자연어 처리, 대규모 아키텍처까지 다루는 4개 코스 전문과정.

## 코스 구성

### Course 1 - Database Design and Basic SQL in PostgreSQL (영상 20개)

CRUD(Create, Read, Update, Delete), psql/DBeaver 클라이언트 사용법, 데이터 타입, 키(기본 키·논리적 키·외래 키)와 인덱스, 정규화, JOIN, 일대다·다대다 데이터 모델링.

- [Course 1 README](Course%201%20-%20Database%20Design%20and%20Basic%20SQL%20in%20PostgreSQL/README.md)
  - Module 1 - Introduction to SQL (6)
  - Module 2 - Single Table SQL (4)
  - Module 3 - One-To-Many Data Models (7)
  - Module 4 - Many-To-Many Data Models (3)

### Course 2 - Intermediate PostgreSQL (영상 28개)

ALTER TABLE, 날짜/시간, DISTINCT·GROUP BY, 서브쿼리, 동시성과 트랜잭션, 저장 프로시저, CSV 자동 정규화, 텍스트·문자 집합·해시·인덱스 전략, 정규 표현식.

- [Course 2 README](Course%202%20-%20Intermediate%20PostgreSQL/README.md)
  - Module 1 - SQL Techniques (12)
  - Module 2 - Using SQL Techniques (3)
  - Module 3 - Text in PostgreSQL (8)
  - Module 4 - Regular Expressions (5)

### Course 3 - JSON and Natural Language Processing in PostgreSQL (영상 29개)

블록·인덱스 내부 구조(B-트리, BRIN, GIN, GiST), 손수 구현한 역방향 인덱스, PostgreSQL 내장 자연어 검색(tsvector/tsquery), Python-PostgreSQL 연동(psycopg2), JSON/JSONB 모델링·인덱싱.

- [Course 3 README](Course%203%20-%20JSON%20and%20Natural%20Language%20Processing%20in%20PostgreSQL/README.md)
  - Module 1 - Natural Language (7)
  - Module 2 - Inverted Indexes with PostgreSQL (5)
  - Module 3 - Python and PostgreSQL (8)
  - Module 4 - JSON and PostgreSQL (9)

### Course 4 - Database Architecture and NoSQL at Scale with Deno (영상 16개)

관계형 데이터베이스 확장의 역사, 1·2세대 클라우드 애플리케이션(Google·Gmail·Facebook), ACID vs BASE, NoSQL의 등장과 PostgreSQL의 대응, Deno KV(분산 키-값 데이터베이스) 실습.

- [Course 4 README](Course%204%20-%20Database%20Architecture%20and%20NoSQL%20at%20Scale%20with%20Deno/README.md)
  - Module 1 - Scaling Databases (3)
  - Module 2 - Cloud Scale Applications (5)
  - Module 3 - DenoKV (7)
  - Module 4 - Wrap Up (1)
