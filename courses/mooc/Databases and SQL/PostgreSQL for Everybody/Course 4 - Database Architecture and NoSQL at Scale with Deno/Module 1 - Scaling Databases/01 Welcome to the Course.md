## 내용
### 이 강좌에서 다룰 것
- 지금까지는 SQL 문법과 사용법을 배웠다면, 이 강좌는 "데이터베이스가 왜, 어떻게 그렇게 동작하는가"라는 메타 질문을 다룬다.
- 관계형 데이터베이스가 어떻게 동작하는지부터 시작해, 그 강점과 약점, 배포·확장 방법(수백 명 → 수백만 명 → 수십억 사용자로 커지는 과정)을 살펴본다.
- NoSQL 운동은 관계형 데이터베이스와 대립하는 것이 아니라 상호 보완적인 흐름으로 소개된다 — 관계형 데이터베이스가 감당하기 어려운 지점을 NoSQL이 보여준 사례로 다뤄진다.
- 마스터-마스터(multi-master), 마스터-슬레이브(master-slave) 복제 같은 배포·확장 개념과 그것이 성능에 미치는 영향도 다룬다.

### 실습 NoSQL 데이터베이스 예고
- 강사는 실습으로 JSON 기반 NoSQL 데이터베이스인 Elasticsearch를 사용할 것이라고 언급한다 — 검색 기능은 Elasticsearch로, 나머지 애플리케이션 로직은 MySQL/Postgres 같은 관계형 데이터베이스로 처리하는 하이브리드 구조가 실무에서 흔하다는 점을 이유로 든다.
- (참고: 실제 Module 3 실습은 이후 커리큘럼 개편으로 Elasticsearch 대신 Deno KV를 사용한다 — 이 강의는 개편 이전 녹화분일 수 있음.)
