# Welcome to the Course!

## 개요
- 이 강좌(3강좌)에서 다룰 두 축 — 텍스트/자연어와 JSON — 을 소개하고, JSON이 관계형 데이터베이스에 가져온 유연성의 의미를 설명하는 오리엔테이션 강의

## 내용
### 왜 텍스트/자연어가 중요한가
- 컴퓨터는 숫자(특히 64비트 정수 같은 외래 키)를 저장·비교·이동하는 데 매우 효율적이지만, 실제 데이터의 대부분은 이름·댓글·블로그 게시물 같은 문자열이다. 우편번호·전화번호처럼 숫자처럼 보여도 실제로는 문자열로 다뤄야 하는 데이터도 많다.

### JSON이 관계형 데이터베이스에 가져온 변화
- 강사는 JSON을 "관계형 데이터베이스에서 지난 20~25년간 일어난 가장 큰 사건"이라고 표현한다.
- 지금까지 배운 데이터 모델링은 각 열의 크기·타입을 미리 정확히 계약(스키마)해 저장 효율을 극대화하는 방식이었다. 하지만 일부 상황에서는 이런 사전 계약이 너무 경직될 수 있다 — 정렬이나 WHERE 절 조건으로 쓰지 않을 소량의 부가 데이터를 유연하게 저장하고 싶을 때가 있다.
- JSON 열을 쓰면 이런 유연성을 얻을 수 있고, 심지어 JSON 내부 값에 인덱스를 걸어 WHERE 절에서도 활용할 수 있다. 즉 JSON은 비정형 데이터를 정형 데이터처럼 다룰 수 있게 해주는 개선이다.
- 다만 신중하게 설계된 고정 스키마가 주는 성능 이점을 포기하고 싶지는 않으므로, 이 강좌에서는 "비정형 데이터를 정형 데이터처럼 다루는" 절충 기법들을 중점적으로 다룬다.
