# Ethical Data Use

## 개요
- 책임 있는 데이터 분석을 위한 투명성, 동의, 익명화, 공정성, 편향 방지 원칙을 살펴본다.

## 내용

### 다섯 가지 원칙
- **투명성**: 무엇을 왜 수집하고 어디에 저장하며 어떻게 사용하는지 명확히 알린다.
- **동의**: 데이터를 사용하기 전에 적절한 권한과 데이터 주체의 허락을 확보한다.
- **익명화**: 개인을 추적할 수 있는 식별 정보를 제거하거나 변환한다.
- **공정성**: 분석 결과가 특정 집단에 부당하거나 차별적인 영향을 주지 않게 한다.
- **편향 방지**: 데이터 수집·표본·모델링 방법 자체가 불공정성을 만들지 않도록 점검한다.

### 실무 적용
- 익명화와 마스킹으로 PII와 민감 데이터를 보호한다.
- 정확성을 관리해 잘못된 정보가 의사결정을 왜곡하지 않게 한다.
- 데이터 생애주기 전체에서 일관성과 신뢰성을 유지해 무결성을 보장한다.
- 결과의 공정성과 과정의 편향을 별도로 검토한다.

## 예시
- 고객 행동 분석에서 이름·이메일을 제거하더라도 희귀한 지역·연령 조합으로 개인을 다시 식별할 수 있는지 확인하고, 필요한 경우 범주를 집계한다.

## 요약
- 윤리적 데이터 사용은 법률 준수보다 넓으며 수집 과정과 분석 결과 모두를 평가한다.
- 투명성·동의·익명화·공정성·편향 방지를 지속적인 검토 기준으로 사용한다.
