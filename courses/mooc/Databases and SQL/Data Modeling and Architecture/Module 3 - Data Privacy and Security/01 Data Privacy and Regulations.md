# Data Privacy and Regulations

## 개요
- 개인·민감 정보를 무단 접근, 오용, 노출로부터 보호하는 데이터 프라이버시와 주요 규제의 초점을 이해한다.

## 내용

### 데이터 프라이버시
- 데이터 프라이버시는 개인을 식별하거나 민감한 사실을 드러내는 정보의 수집·저장·사용·공유를 통제하는 것이다.
- 분석 가능성만큼 데이터 주체의 권리, 접근 통제, 목적 제한, 보존 기간을 고려해야 한다.

### 주요 규제
- **GDPR**: 개인의 정보 접근·정정·삭제 권리와 처리의 적법성·투명성을 강조한다.
- **HIPAA**: 미국 의료 환경에서 보호 대상 건강 정보의 프라이버시와 보안을 다룬다.
- **CCPA**: 캘리포니아 소비자에게 수집 정보 확인과 판매 거부 등의 권리를 제공한다.
- 적용 법률은 지역·산업·데이터 유형에 따라 달라지므로 실제 업무에서는 조직의 법무·보안 정책을 확인해야 한다.

### Power BI 모델의 책임
- 필요한 데이터만 모델에 포함하고 민감 열은 제거·마스킹·익명화한다.
- 보고서 공유 대상과 작업 영역 접근 권한을 최소 권한 원칙으로 관리한다.
- 원본에서 보고서까지 데이터가 이동하는 경로와 사용 목적을 문서화한다.

## 예시
- 영업 보고서에 직원 전체 이름이 필요 없다면 이니셜과 마스킹 문자만 제공하고, 원본 이름 열은 최종 모델에서 제거한다.

## 요약
- 데이터 프라이버시는 데이터 주체의 권리와 민감 정보 보호를 분석 전 과정에 반영하는 것이다.
- 규제 준수와 최소 수집·접근 통제·마스킹을 모델 설계 단계부터 고려한다.
