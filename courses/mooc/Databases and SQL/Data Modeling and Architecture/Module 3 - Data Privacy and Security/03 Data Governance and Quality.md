# Data Governance and Quality

## 개요
- 데이터를 정확하고 안전하며 접근 가능하게 유지하는 거버넌스 체계와 지속적인 데이터 품질 관리를 이해한다.

## 내용

### 데이터 거버넌스
- 데이터 거버넌스는 데이터 품질·무결성·보안·접근성을 위한 전략, 정책, 표준, 책임 구조다.
- 잠재적 위험인 데이터를 통제 가능한 조직 자산으로 바꾸는 운영 체계다.

### 네 가지 구성 요소
- **데이터 스튜어드십**: 데이터 관리·보호 책임과 역할을 명확히 배정한다.
- **데이터 품질 관리**: 조직 데이터의 정확성, 완전성, 신뢰성을 측정하고 개선한다.
- **데이터 생애주기 관리**: 생성·수집부터 사용·보관·폐기까지 각 단계를 통제한다.
- **정책과 절차**: 접근, 사용, 공유, 보존 규칙을 문서화하고 집행한다.

### 품질 차원
- **정확성**: 값이 실제 대상을 올바르게 표현하는가.
- **완전성**: 필요한 값과 레코드가 빠지지 않았는가.
- **일관성**: 시스템·보고서 사이에서 정의와 값이 충돌하지 않는가.
- **적시성**: 의사결정에 필요한 시점에 최신 데이터가 제공되는가.
- **신뢰성**: 반복해서 사용해도 안정적인 결과를 제공하는가.

## 예시
- Power BI 작업 영역별 소유자와 접근 정책을 정하고, 새로 고침 실패·결측률·중복률·최종 갱신 시간을 품질 지표로 추적한다.

## 요약
- 거버넌스는 사람·정책·생애주기·품질 관리를 하나의 책임 체계로 묶는다.
- 품질은 일회성 정제가 아니라 정확성·완전성·일관성·적시성·신뢰성을 지속적으로 관찰하는 활동이다.
