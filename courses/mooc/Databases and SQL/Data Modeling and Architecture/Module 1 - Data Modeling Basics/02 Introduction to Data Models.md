# Introduction to Data Models

## 개요
- 데이터 모델을 시각화보다 먼저 설계해야 하는 이유와 Power BI에서 모델을 구축하는 기본 흐름을 학습한다.

## 내용

### 데이터 모델의 의미
- 데이터 모델은 데이터 요소와 그 관계를 구조적으로 표현한 **청사진**이다.
- 흩어진 데이터가 하나의 일관된 이야기를 만들도록 연결하며, 보고서와 시각화가 신뢰할 수 있는 구조 위에서 계산되게 한다.
- 따라서 시각화를 만들기 전에 데이터 모델을 먼저 구성해야 한다.

### Power BI 모델 구축 흐름
1. 데이터 원본에 연결한다.
2. Power Query에서 데이터를 정제·변환한다.
3. 처리 결과를 Power BI 모델의 테이블로 불러온다.
4. 테이블·열 속성을 구성하고 공통 키를 이용해 관계를 만든다.
5. DAX로 측정값과 계산 열을 작성한다.

### 잘 설계된 모델의 효과
- 관계와 데이터 구조를 최적화해 조회·쿼리 성능을 높인다.
- 관계와 계층을 바탕으로 합계·평균 같은 집계를 단순화한다.
- 복잡한 측정값과 비즈니스 로직을 재사용할 수 있다.
- 필터와 계산이 일관되게 적용되어 보고서 정확도가 향상된다.

## 예시
- Adventure Works는 고객·마케팅·판매 데이터를 각각 정제한 뒤 `Customer ID`로 고객과 판매 테이블을 연결한다. 이후 DAX로 총매출과 전년 대비 매출을 계산해 캠페인 효과와 고객별 거래를 분석한다.

## 요약
- 데이터 모델은 분석과 시각화의 기반이다.
- Power Query 변환 → 테이블 적재 → 관계 설정 → DAX 계산 순서로 모델을 구축한다.
- 좋은 모델은 성능, 계산 재사용성, 분석 깊이, 보고서 정확도를 함께 높인다.
