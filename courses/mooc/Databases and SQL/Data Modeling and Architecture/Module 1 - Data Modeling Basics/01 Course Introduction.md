# Course Introduction

## 개요
- Power BI에서 데이터 모델과 데이터 아키텍처가 맡는 역할을 구분하고, 강좌 전체의 학습 범위를 살펴본다.

## 내용

### 데이터 분석가와 데이터 모델링
- 데이터 분석가는 원시 데이터를 실행 가능한 인사이트로 바꾸며, 보고서 작성뿐 아니라 데이터 모델 설계·유지, 데이터 품질 확보, 의사결정 지원을 담당한다.
- **데이터 아키텍처**는 조직 전체에서 데이터를 수집·저장·관리하는 큰 틀이다.
- **데이터 모델링**은 원시 데이터를 조직하고 테이블 사이의 관계를 구체적으로 설계하는 작업이다.
- 두 영역이 함께 작동해야 Power BI 분석·보고·의사결정이 일관되고 효율적으로 수행된다.

### 강좌 범위
- Module 1: 카디널리티, 데이터 스키마, 고급 스키마
- Module 2: DAX 측정값, 필터·교차 필터 컨텍스트, 테이블 관계
- Module 3: 데이터 프라이버시, 윤리, 거버넌스
- Module 4: 실제 시나리오 기반 최종 프로젝트와 평가

### 선수 지식과 환경
- 여러 데이터 원본 연결, Power Query를 이용한 정제·변환, 데이터 무결성과 품질에 대한 기본 이해가 필요하다.
- 실습에는 Power BI Desktop과 Microsoft Excel을 실행할 수 있는 데스크톱 환경이 필요하다.

## 예시
- 조직의 판매·고객·마케팅 데이터를 아키텍처 수준에서 수집·관리하고, Power BI 모델에서는 테이블 관계와 계산을 구성해 하나의 분석 체계로 연결한다.

## 요약
- 데이터 아키텍처는 전체 데이터 흐름의 틀이고 데이터 모델링은 분석을 위한 세부 구조다.
- 이 강좌는 관계·스키마·DAX에서 프라이버시와 거버넌스까지 Power BI 모델링의 전 과정을 다룬다.
