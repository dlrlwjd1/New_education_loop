# Data Modeling and Architecture

**Course URL:** [mooc.org/learn/data-modeling-and-architecture](https://www.mooc.org/learn/data-modeling-and-architecture)

MOOC에서 Microsoft가 제공하는 Power BI 데이터 모델링 강좌다. 데이터 아키텍처와 데이터 모델의 차이부터 카디널리티, 스타·스노우플레이크 스키마, DAX, 데이터 프라이버시·보안·거버넌스까지 다루며 총 4개 모듈로 구성된다.

## 모듈 구성

- [Module 1 - Data Modeling Basics](Module%201%20-%20Data%20Modeling%20Basics/) — 데이터 모델, 카디널리티와 세분성, 팩트·디멘션 테이블, 정규화·비정규화, 스타·스노우플레이크 스키마
- [Module 2 - Data Analysis Expressions](Module%202%20-%20Data%20Analysis%20Expressions/) — DAX 구문·컨텍스트·측정값, `CALCULATE`, 교차 필터, 역할 수행 디멘션, Copilot
- [Module 3 - Data Privacy and Security](Module%203%20-%20Data%20Privacy%20and%20Security/) — 데이터 프라이버시와 규제, 윤리적 사용, 데이터 거버넌스와 품질
- [Module 4 - Final Project and Assessment](Module%204%20-%20Final%20Project%20and%20Assessment/) — 스타·스노우플레이크 모델, DAX, 역할 수행 디멘션, 개인정보 마스킹을 통합한 최종 프로젝트
