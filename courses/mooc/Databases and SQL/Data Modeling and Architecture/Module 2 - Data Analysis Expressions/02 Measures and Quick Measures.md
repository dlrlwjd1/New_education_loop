# Measures and Quick Measures

## 개요
- 원시 데이터를 동적 인사이트로 바꾸는 DAX 측정값과 Power BI 빠른 측정값의 종류와 용도를 살펴본다.

## 내용

### 측정값
- 측정값은 현재 필터 컨텍스트에서 계산되며 보고서의 선택과 상호작용에 따라 값이 바뀐다.
- 모델에 저장해 여러 시각화에서 재사용할 수 있으므로 계산 로직을 중앙화한다.

### 집계 특성에 따른 분류
- **가산(additive)**: 모든 차원에서 합산 가능. 예: 매출액, 판매 수량.
- **비가산(non-additive)**: 단순 합산이 의미 없음. 예: 비율, 평균, 고유 개수.
- **반가산(semi-additive)**: 일부 차원에서는 합산 가능하지만 시간 같은 특정 차원에서는 불가. 예: 월말 재고 잔액.

### 기본 통계 함수
- `AVERAGE`, `MEDIAN`, `COUNT`, `DISTINCTCOUNT`, `MIN`, `MAX`는 분포·추세·이상치를 파악하는 기본 도구다.
- `SUMX`처럼 `X`가 붙은 반복 함수는 테이블의 각 행에서 식을 평가한 뒤 결과를 집계한다.

### 빠른 측정값
- Power BI가 일반적인 DAX 패턴을 자동 생성하는 기능으로 직접 수식을 작성하지 않고도 계산을 만들 수 있다.
- 범주별 집계, 필터, 시간 인텔리전스, 합계, 수학 연산, 텍스트 계산 등을 지원한다.
- 생성된 DAX를 검토하면 패턴 학습과 오류 감소에도 도움이 된다.

## 예시
```DAX
Total Sales = SUM(Sales[SalesAmount])
Average Order = AVERAGE(Sales[SalesAmount])
Customers = DISTINCTCOUNT(Sales[CustomerKey])
```

## 요약
- 측정값은 필터 컨텍스트에 반응하는 재사용 가능한 계산이다.
- 계산의 가산성을 확인해야 합계가 올바른 의미를 가지며, 빠른 측정값은 일반 패턴을 신속하게 생성한다.
