# Cross-filter Direction

## 개요
- 테이블 관계에서 필터가 전파되는 방향과 DAX `CROSSFILTER`로 특정 계산의 관계 동작을 바꾸는 방법을 다룬다.

## 내용

### 필터 방향
- 단방향 관계에서는 일반적으로 디멘션의 필터가 팩트로 전달된다.
- 양방향 관계는 양쪽 테이블에서 필터가 전파되지만, 여러 경로가 생기면 모호성이나 예상치 못한 결과를 만들 수 있다.
- 모델의 기본 관계는 단순하고 예측 가능하게 유지하고, 예외적인 분석 요구는 측정값 안에서 제한적으로 처리하는 편이 안전하다.

### CROSSFILTER
- `CROSSFILTER`는 모델의 관계 설정을 영구 변경하지 않고 현재 `CALCULATE` 평가 동안 필터 방향을 바꾸거나 관계를 비활성화한다.
- 방향 인수로 단방향, 양방향, 관계 사용 안 함 등을 지정할 수 있다.

## 예시
```DAX
Products by Year =
CALCULATE(
    DISTINCTCOUNT(Products[ProductKey]),
    CROSSFILTER(Sales[ProductKey], Products[ProductKey], BOTH)
)
```
- 기본 모델에서는 날짜가 판매를 거쳐 제품까지 필터링하지 못하는 경우, 이 측정값 안에서만 양방향 전파를 허용해 연도별 판매 제품 수를 계산한다.

## 요약
- 교차 필터 방향은 관계를 따라 필터가 이동하는 규칙이다.
- 양방향 관계를 모델 전체에 남용하기보다 `CROSSFILTER`로 필요한 계산에만 적용할 수 있다.
