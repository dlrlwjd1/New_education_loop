# Course wrap up

## 개요

- 강좌 수료를 축하하며 획득 역량과 다음 단계를 안내하는 마무리 강의

## 내용

### 이 강좌로 갖춘 역량

- 데이터 필터링·조인·그룹화
- 제약조건·서브쿼리·뷰를 활용한 데이터 삽입·갱신
- MySQL 함수와 저장 프로시저 배포
- 채점 평가 측정 항목: 필터링·조인·그룹화 지식, 가상 테이블·데이터 무결성·서브쿼리 개념 설명, 함수·저장 프로시저 경험

### 다음 단계

- 전문과정의 다음 강좌로 계속 진행 — 최종 랩에서 배운 것을 총동원해 완전히 동작하는 데이터베이스 시스템(포트폴리오용)을 만든다.
- 전 과정을 수료하면 Meta Database Engineering 인증을 받으며 다른 Meta 역할 기반 인증으로 이어갈 수 있다.

## 요약

- MySQL 구조·관리(필터링·조인·그룹화·제약·서브쿼리·뷰·함수·프로시저) 역량을 갖추고 강좌를 마쳤다.
