# Course Recap

## 개요

- Database Structures and Management with MySQL 강좌 전체(3개 학습 모듈)를 되짚는 총정리 강의

## 내용

### Module 1 — MySQL 입문

- 데이터베이스와 Meta의 MySQL 활용 소개
- 논리 연산자(AND·OR·NOT·IN·BETWEEN·LIKE)와 와일드카드로 데이터 필터링
- 별칭(alias)과 테이블 조인(INNER·LEFT·RIGHT·SELF), UNION 연산자
- GROUP BY와 집계 함수, HAVING 필터, ANY·ALL 연산자

### Module 2 — 데이터베이스 갱신과 뷰

- REPLACE 명령으로 삽입·갱신
- 제약조건 유형(키·도메인·참조 무결성)과 동작
- ALTER TABLE로 컬럼 추가·삭제·수정, 서브쿼리 활용
- 뷰의 개념·생성·이름 변경·삭제와 이점

### Module 3 — 함수와 저장 프로시저

- 숫자(집계·수학)·문자열·날짜·비교·제어 흐름 함수
- 저장 프로시저의 개념과 생성·삭제

## 요약

- 필터링·조인·그룹화 → REPLACE·제약·ALTER·서브쿼리·뷰 → 함수·저장 프로시저까지 MySQL 구조·관리의 전 과정을 복습했으며, 다음은 채점 평가다.
