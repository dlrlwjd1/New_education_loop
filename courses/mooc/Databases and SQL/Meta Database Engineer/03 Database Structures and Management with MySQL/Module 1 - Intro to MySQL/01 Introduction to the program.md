# Introduction to the program

## 개요

- Meta Database Engineer 전문 자격증 전체를 소개하는 공통 오리엔테이션 영상 (Course 1의 프로그램 소개와 동일한 내용)

## 내용

- 기술 배경이 없어도 1년 안에 취업 준비를 목표로 하는 자기 주도형 프로그램.
- Meta 엔지니어들의 고성능 데이터베이스 협업 방식 학습, 동료 수강생과의 토론, 코딩 실습.
- 로드맵: 모범 사례 기반 데이터베이스 모델링·구조화 → SQL로 데이터 생성·관리·조작 → Django로 웹 프론트엔드와 데이터베이스 연결 → Git/GitHub 버전 관리 → 캡스톤(포트폴리오용 관계형 데이터베이스) → 코딩 인터뷰 준비.
- 각 강좌가 이전 강좌 위에 쌓이므로 순서대로 수강해야 하며, 수료 시 200개 이상 고용주와 연결되는 Meta career programs job board 접근 권한 제공.

## 요약

- 전문 자격증의 구조와 목표를 안내하는 프로그램 공통 소개 영상이다.
