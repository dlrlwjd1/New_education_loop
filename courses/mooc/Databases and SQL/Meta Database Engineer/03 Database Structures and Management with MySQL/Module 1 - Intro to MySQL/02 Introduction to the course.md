# Introduction to the course

## 개요

- 전문과정의 세 번째 강좌(Database Structures and Management with MySQL)에서 배울 내용을 모듈별로 안내하는 강의

## 내용

### Module 1 — MySQL 입문

- 논리 연산자로 데이터 필터링
- 테이블 조인(join)과 별칭(alias) 사용
- GROUP BY·HAVING 절로 데이터 그룹화
- ANY·ALL 연산자 활용

### Module 2 — 데이터베이스 갱신과 뷰

- MySQL REPLACE 문으로 데이터 삽입·갱신
- MySQL 제약조건(constraint) 활용
- ALTER TABLE·COPY TABLE 문으로 테이블 구조 변경
- 서브쿼리(subquery)와 비교 연산자의 결합
- CREATE VIEW 문으로 가상 테이블 생성

### Module 3 — 함수와 저장 프로시저

- 숫자·문자열·날짜 함수 등 공통 MySQL 함수
- 비교 함수와 제어 흐름(control flow) 함수
- 저장 프로시저(stored procedure) 작업

### 평가

- 모듈별 지식·기술 점검 활동, 랩 프로젝트, 채점 평가로 실력을 확인한다.

## 요약

- 이 강좌는 필터링·조인·그룹화 → REPLACE·제약·ALTER·서브쿼리·뷰 → 함수·저장 프로시저 순으로 MySQL 데이터베이스 구조와 관리를 다룬다.
