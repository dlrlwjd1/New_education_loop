# Module summary: Intro to MySQL

## 개요

- Module 1(MySQL 입문)에서 배운 내용을 되짚는 요약 강의

## 내용

### 레슨 1 — 강좌 소개

- MySQL이 데이터베이스 엔지니어의 핵심 언어인 이유와 Meta의 MySQL 활용 방식

### 레슨 2 — 데이터 필터링

- 데이터 필터링과 논리 연산자(AND·OR·NOT, IN·BETWEEN·LIKE) 개념과 사용법, 실사례 읽기 자료

### 레슨 3 — 테이블 조인

- 별칭(alias)의 개념과 활용
- JOIN 유형(INNER·LEFT·RIGHT·SELF) 식별과 사용, 랩 실습
- UNION 연산자의 개념과 활용

### 레슨 4 — 데이터 그룹화

- GROUP BY 절 활용, HAVING 절 사용법
- 읽기 자료로 ANY·ALL 연산자 학습, 랩에서 그룹화 기술 시연

## 요약

- 이 모듈로 MySQL에서 데이터 필터링, 테이블 조인, 데이터 그룹화 능력을 갖췄다. 다음 모듈은 데이터베이스 갱신과 뷰(views)다.
