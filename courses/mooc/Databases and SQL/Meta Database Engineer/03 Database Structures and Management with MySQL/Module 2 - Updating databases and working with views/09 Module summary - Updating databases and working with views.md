# Module summary: Updating databases and working with views

## 개요

- Module 2(데이터베이스 갱신과 뷰)에서 배운 내용을 되짚는 요약 강의

## 내용

### 레슨별 성취

1. **데이터 삽입·갱신** — REPLACE 문의 개념과 삽입/갱신 활용, 랩 실습
2. **값과 제약조건** — 제약 유형(키·도메인·참조 무결성) 식별, 동작 원리, ON DELETE/UPDATE CASCADE 옵션, 랩 실습
3. **테이블 구조 변경** — 기존 테이블의 컬럼·제약 추가/삭제/수정(ALTER), COPY TABLE 구문으로 테이블·데이터베이스 내/간 데이터 복사
4. **서브쿼리** — 서브쿼리 인식과 구문, 사용 시나리오, 데이터 검색 활용
5. **뷰(가상 테이블)** — 뷰 개념, 생성·이름 변경·삭제, 뷰의 이점

## 요약

- 이 모듈로 REPLACE 갱신, 제약조건 관리, ALTER/COPY 테이블 구조 변경, 서브쿼리, 뷰 활용 능력을 갖췄다. 다음 모듈은 함수와 저장 프로시저다.
