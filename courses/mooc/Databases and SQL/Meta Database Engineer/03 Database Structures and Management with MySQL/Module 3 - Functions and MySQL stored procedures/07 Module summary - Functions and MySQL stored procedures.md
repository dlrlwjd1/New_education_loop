# Module summary: Functions and MySQL stored procedures

## 개요

- Module 3(함수와 저장 프로시저)에서 배운 내용을 되짚는 요약 강의

## 내용

### 레슨 1 — MySQL 함수

- 함수의 개념 설명, 공통 함수 유형 구분, 기본 함수 활용:
  - **숫자 함수** — 집계 또는 수학 연산 (SUM·AVG·ROUND·MOD)
  - **문자열 함수** — 문자열 값 처리 (CONCAT·SUBSTRING·UCASE·LCASE)
  - **날짜 함수** — 시간·날짜 정보 반환 (CURRENT_DATE·DATE_FORMAT·DATEDIFF)
  - **비교 함수** — 값 비교 (GREATEST·LEAST·ISNULL)
  - **제어 흐름 함수** — 조건 평가와 실행 경로 결정 (CASE)

### 레슨 2 — 저장 프로시저

- 저장 프로시저 개념 설명, 간단한 프로시저 생성·삭제(CREATE/CALL/DROP PROCEDURE), 랩 실습

## 요약

- 숫자·문자열·날짜·비교·제어 흐름 함수와 저장 프로시저까지 MySQL의 데이터 처리·재사용 도구를 갖췄다.
