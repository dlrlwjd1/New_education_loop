# Programming in Python

Meta Database Engineer 전문 자격증의 다섯 번째 강좌. Python 기초(문법·변수·타입·연산자·제어 흐름)부터 함수·자료 구조·예외·파일 처리, 프로그래밍 패러다임(절차적·함수형·OOP), 모듈·패키지·웹 프레임워크·테스팅(Pytest·TDD)까지 다룬다.

- 강좌: https://www.mooc.org/learn/programming-in-python
- 구성: 학습 모듈 4개 + 평가 모듈 1개, 강의 영상 67개
- 노트: 강의별 Transcript 기반 한국어 정리 (형식: 개요/내용/예시/요약, 기술 용어 영어 병기)
- 제외: 읽기 자료·퀴즈·채점 평가 (학업 정직성 정책)

## 모듈 구성

### Module 1 - Getting started with Python (19강)

강좌·프로그램 소개, 실세계의 Python, 프로그래밍 역사와 이진 코드, Python의 장점, 환경 설정(Windows/Mac), 커맨드라인 vs IDE, 문법·공백·들여쓰기, 변수, 데이터 타입, 문자열, 타입 캐스팅, 입력·출력, 수학·논리 연산자, if/elif/else, match 문, 루프, 중첩 루프와 복잡도.

### Module 2 - Basic Programming with Python (13강)

함수(def·return), 스코프(LEGB), 리스트, 튜플, 집합, 딕셔너리, args/kwargs, 예외 개념과 try/except, 파일 처리(open·모드), 파일 생성(w/a), 파일 읽기(read/readline/readlines).

### Module 3 - Programming paradigms (16강)

절차적 프로그래밍과 DRY, 알고리즘(팰린드롬), 복잡도(Big O), 함수형 프로그래밍, 순수 함수, 재귀, 문자열 뒤집기, map·filter, OOP 입문(4대 개념), 클래스와 인스턴스, 커스텀 객체(__init__), 인스턴스 메서드, 상속(부모·자식), 추상 클래스(ABC), MRO.

### Module 4 - Modules, packages, libraries and tools (17강)

모듈 개념·접근·임포트(import/from/as/*), 네임스페이스·스코프(global·nonlocal), reload(), 인기 패키지, 데이터 분석 패키지(NumPy·pandas·Matplotlib·scikit-learn), ML/AI 라이브러리, 웹 프레임워크(Django·Flask), 테스팅 개념·유형(4수준), 자동화 패키지(Pytest·Robot·Selenium), Pytest 실습, TDD 개념·적용.

### Module 5 - End-of-Course Graded Assessment (2강)

강좌 총정리와 수료 마무리. 채점 평가는 정리 제외.
