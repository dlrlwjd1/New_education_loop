# What is functional programming?

## 개요

- 함수형 프로그래밍(functional programming)의 개념과 전통 함수 vs 순수 함수의 차이
- 일급 시민(first-class citizen)으로서의 Python 함수와 내장 함수(sorted, map) 활용

## 내용

### 함수형 프로그래밍이란

- 깨끗하고 일관되며 유지보수 가능한 코드를 위해 **함수를 활용하는 패러다임.** 대량 데이터의 고속 처리에 특히 능하다.
- 핵심 설계 원칙: **함수 스코프 밖의 데이터를 바꾸지 않는다** — 입력 데이터·인자를 수정하지 말고 **완성된 결과만 반환**한다. 함수는 독립적(standalone)이며 이것이 코드의 우아함을 만든다.
- 강타입 객체지향 언어들도 함수형 프로그래밍을 구조에 통합해 왔다.

### 전통 함수 vs 순수 함수(pure function)

| | 전통 함수 | 순수 함수 |
|---|---|---|
| 전역 상태 접근·수정 | 가능 | **불가** |
| 지역 상태 접근 | 가능 | 가능 |
| 인자(args) 변경 | 가능 | **불가** |
| 출력의 입력 의존 | 의존하지 않을 수 있음 | **입력에 의존** — 몇 번을 호출해도 같은 입력이면 같은 결과 |

### Python 함수는 일급 시민

- 함수형 프로그래밍을 지원하려면 언어가 **함수를 인자로 전달하고 함수를 반환**할 수 있어야 한다.
- Python 함수는 문자열·숫자와 같은 지위 — **변수에 할당, 인자로 전달, 호출자에 반환**이 모두 가능하다.

### 내장 함수 예

- **sorted(리스트)** — 정렬된 리스트 반환 (예: 커피 이름들의 알파벳 정렬). 로직이 이미 내장되어 재사용으로 개발 시간을 아낀다.
- **map(함수, 반복가능객체)** — 첫 인자로 함수를, 둘째로 iterable을 받아 **각 항목에 함수를 자동 적용**한다.

## 예시

```python
coffees = ["Latte", "Americano", "Espresso"]
print(sorted(coffees))                # 알파벳순 정렬

def reverse(str):
    return str[::-1]                  # 슬라이스로 뒤집기

result = map(reverse, coffees)        # 각 커피 이름을 뒤집어 적용
print(list(result))
```

## 요약

- 함수형 프로그래밍은 함수 밖 데이터를 바꾸지 않고 결과만 반환하는 독립 함수 중심의 패러다임이다.
- 순수 함수는 전역 접근·인자 변경이 없고 같은 입력에 항상 같은 출력을 낸다.
- Python 함수는 일급 시민이라 map처럼 함수를 인자로 넘기는 패턴이 자연스럽다.
