# Introduction to Object Oriented Programming

## 개요

- 객체지향 프로그래밍(OOP) 패러다임의 구성요소(클래스·객체·메서드)와 4대 개념(상속·다형성·캡슐화·추상화)

## 내용

### 패러다임과 OOP

- 패러다임은 **코드 복잡성을 줄이고 실행 흐름을 결정하는 전략** — 프로그램 작성 스타일. 선언형·절차적·객체지향·함수형·이벤트 기반 등 여러 가지가 있고 **상호 배타적이지 않다** (Python은 주로 객체지향이지만 절차적·함수형이기도 하다).
- OOP가 성공한 가장 큰 요인은 **실세계 문제를 코드로 옮기는 능력**. 높은 모듈성 덕에 코드가 이해하기 쉽고 재사용 가능하며, 추상화 계층을 더하고 코드 블록을 프로젝트 간에 옮길 수 있다.

### 구성요소

- **클래스(class)** — 속성(변수)과 행동(함수)을 담는 논리적 코드 블록. `class` 키워드로 정의. **객체 생성의 청사진(blueprint)**. 예: Little Lemon 직원의 직위·고용 상태를 담는 Employee 클래스.
- **객체(object)** — 클래스의 **인스턴스**. 몇 개든 만들 수 있고, 각각 고유 식별자로 구별된다. 객체의 상태는 속성과 행동으로 정의된다. 예: `emp1 = Employee("Shift Lead", "FT")` — 인스턴스화(instantiation).
- **메서드(method)** — 클래스 안에 정의되어 **객체 인스턴스의 행동을 결정하는 함수.** 예: 직위 문자열을 출력하는 introduction 함수를 클래스에 선언하고 객체에서 호출.

### OOP의 4대 개념

1. **상속(inheritance)** — 기존 클래스에서 새 클래스를 파생. 원본은 부모/슈퍼클래스, 파생은 자식/서브클래스.
2. **다형성(polymorphism)** — "여러 형태" — 하나의 함수가 대상에 따라 다르게 동작. 예: `+` 연산자는 정수에는 덧셈(3+5=8), 문자열에는 연결로 동작한다.
3. **캡슐화(encapsulation)** — 메서드·변수를 클래스 같은 **하나의 스코프 단위로 감싸 직접 접근을 제한** — 원치 않는 수정과 에러를 줄인다.
4. **추상화(abstraction)** — 구현 상세를 숨겨 데이터를 더 안전하게 만드는 능력. **Python은 추상화를 직접 지원하지 않고 상속으로 달성**한다.

## 요약

- OOP는 클래스(청사진)·객체(인스턴스)·메서드(행동)로 실세계 문제를 코드로 모델링하는 패러다임이다.
- 4대 개념은 상속, 다형성, 캡슐화, 추상화이며 Python의 추상화는 상속을 통해 구현된다.
- 메서드 오버로딩·오버라이딩·생성자 등의 개념은 이후 강의에서 다룬다.
