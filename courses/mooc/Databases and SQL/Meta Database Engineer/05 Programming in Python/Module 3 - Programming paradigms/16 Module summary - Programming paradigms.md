# Module summary: Programming paradigms

## 개요

- Module 3(프로그래밍 패러다임)에서 배운 내용을 되짚는 요약 강의

## 내용

### 세 패러다임 요약

- **절차적 프로그래밍** — 가장 쉬운, 객체지향으로 가는 디딤돌이자 신규 개발자의 첫 선택
- **함수형 프로그래밍** — 깨끗하고 일관되며 유지보수 가능한 코드를 위해 함수를 만드는 패러다임
- **객체지향 프로그래밍** — 데이터와 메서드를 모두 담는 객체를 만드는 패러다임

### 익힌 능력

- 절차적 프로그래밍 개념, 알고리즘과 문제 해결, 알고리즘 복잡도 계산과 성능 개선, Big O 표기법
- 함수형 프로그래밍, 순수 함수, 재귀와 문제 해결
- 문자열 뒤집기(슬라이스·재귀), map vs filter의 차이
- OOP와 4대 개념(상속·다형성·캡슐화·추상화), 클래스와 인스턴스의 관계
- 클래스 생성·인스턴스화·변수/메서드 접근, 인스턴스 변수·메서드로 객체 상태 변경

## 요약

- 절차적 → 함수형(순수 함수·재귀·map/filter) → 객체지향(클래스·상속·MRO)까지 Python의 주요 패러다임을 모두 다뤘다.
