# Recursion

## 개요

- 재귀(recursion) — 자기 자신을 호출하는 함수 — 의 개념과 팩토리얼 예제(루프 vs 재귀 비교), 장단점

## 내용

### 재귀란

- **자기 자신을 호출하는 함수** — 계속 반복되는 패턴을 만든다. return 문이 같은 함수를 반환하는 것이 핵심.
- 작은 반복 문제로 쪼갤 수 있는 문제, **분기가 많아 반복(iterative) 접근이 버거운 복잡한 문제**(예: 파일 시스템 탐색)에 적합.
- **경고**: 종료 조건을 고려하지 않으면 **무한 루프**가 되어 메모리를 소진하고 프로그램이 죽는다.

### 팩토리얼 — 루프 vs 재귀

- **루프 버전**: n<0이면 0 반환, 아니면 factorial=1로 시작해 range를 돌며 1×2×3×4×5 = 120 계산.
- **재귀 버전**: 더 단순·간결 — for 루프가 필요 없다.
  - 종료 조건: n이 1이면 1 반환
  - 아니면 `n * find_factorial(n - 1)` — **매 호출마다 n이 1씩 줄어** 1이 되면 재귀가 멈춘다
  - return이 곱해지는 값의 참조를 유지해 최종적으로 120이 완성된다.

### 장단점

- **장점**: 코드가 깔끔하고 덜 비대해짐 / 복잡한 과업을 읽기 쉬운 하위 문제로 분해 / 수열 생성이 중첩 루프보다 이해 쉬움
- **단점**: 로직 따라가기 어려울 수 있음 / **메모리 비용이 크고** 때로 비효율적 / 디버그·단계 실행이 어려움

## 예시

```python
def find_factorial(n):
    if n == 1:
        return 1
    else:
        return n * find_factorial(n - 1)

print(find_factorial(5))   # 120  (5×4×3×2×1)
```

## 요약

- 재귀는 자기 호출 함수로, 종료 조건(base case)이 반드시 있어야 무한 루프를 피한다.
- 팩토리얼처럼 반복 문제를 루프 없이 간결하게 표현할 수 있다.
- 가독성 이점과 메모리·디버깅 비용을 저울질해 사용한다.
