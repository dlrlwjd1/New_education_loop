# Pure functions

## 개요

- 순수 함수(pure function)의 정의와 이점, 그리고 일반 함수를 단계적으로 순수 함수로 바꾸는 실습

## 내용

### 순수 함수란

- **자신의 스코프 밖의 변수·데이터·리스트·집합을 바꾸거나 영향을 주지 않는 함수.**
- 예: 전역 리스트에 항목을 추가하거나 변경하면 순수 함수가 아니다.
- 순수 함수로 만드는 요령: 원본 리스트를 수정하지 말고 **복사본을 만들고, 새 항목을 복사본에 더해, 새 리스트를 반환**한다.

### 이점 4가지

1. 결과를 항상 **예측**할 수 있다
2. 의도한 일을 정확히 하는 **일관된** 코드 조각이다
3. 반환이 늘 같으므로 **캐싱(cache)** 이 가능하다
4. **멀티스레드 프로그램**에 적합 — 전역 스코프의 변경을 방지해 동시 실행 중에도 데이터가 신뢰성 있게 유지된다

### 단계별 변환 실습 (핵심 흐름)

1. `my_list.append(item)`을 함수 안에서 직접 호출 → 전역 리스트가 바뀜 → **순수 아님**
2. 반환값을 new_list에 받아도 여전히 my_list를 참조 → **순수 아님**
3. 리스트를 매개변수(lst)로 받아도 그 리스트를 append로 갱신 → **순수 아님** (인자로 받은 원본이 바뀜)
4. **`nl = lst.copy()`로 복사**한 뒤 복사본에 append하고 nl을 반환 → 원본(1,2,3)은 그대로, 새 리스트(1,2,3,4)만 생성 → **순수 함수 완성**

## 예시

```python
my_list = [1, 2, 3]

def add_to_list(lst, item):
    nl = lst.copy()      # 원본 복사
    nl.append(item)      # 복사본에만 추가
    return nl            # 새 리스트 반환

new_list = add_to_list(my_list, 4)
print(my_list)   # [1, 2, 3]      — 원본 불변
print(new_list)  # [1, 2, 3, 4]
```

## 요약

- 순수 함수는 스코프 밖 데이터에 영향을 주지 않고 입력에만 의존해 결과를 반환한다.
- 복사 → 복사본 수정 → 반환 패턴이 핵심 변환 기법이다.
- 예측 가능성·일관성·캐싱·멀티스레드 안전성 덕분에 코드가 깨끗해지고 디버그·확장이 쉬워진다.
