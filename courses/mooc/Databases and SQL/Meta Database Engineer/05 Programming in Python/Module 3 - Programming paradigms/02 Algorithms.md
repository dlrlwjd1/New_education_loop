# Algorithms

## 개요

- 알고리즘의 정의(과업 완수·문제 해결을 위한 일련의 단계)와 문제를 작은 부분으로 나누는 접근
- 팰린드롬(palindrome) 판별 알고리즘을 코드로 구현하는 실습

## 내용

### 알고리즘이란

- **주어진 과업을 완수하거나 문제를 풀기 위한 단계들의 연속.** 오믈렛 레시피에 비유: 재료(입력) → 조리 단계(방법) → 완성 요리(출력) — 단계는 매번 동일하게 실행된다.
- 핵심은 **문제를 더 작은 부분으로 쪼개는 것** — 그렇게 단계를 쌓아 전체 문제를 푼다.

### 팰린드롬 판별 문제 분해

- 팰린드롬 = 앞뒤 어느 쪽으로 읽어도 같은 단어 (racecar).
- 분해: 인덱스 0의 문자와 마지막 인덱스의 문자를 비교 → 다음 문자(1)와 끝에서 두 번째(5) 비교 → ... 반복.
- 참을 확인하는 것보다 **거짓을 먼저 확인하는 편이 빠르다** — 불일치가 나오는 순간 팰린드롬이 아님을 알 수 있다.

## 예시

```python
def is_palindrome(str):
    start_index = 0                 # 문자열은 항상 0에서 시작
    end_index = len(str) - 1        # 마지막 인덱스

    for x in str:
        if str[start_index] != str[end_index]:
            return False            # 불일치 발견 → 즉시 False
        start_index += 1
        end_index -= 1
    return True                     # 끝까지 불일치 없으면 팰린드롬

print(is_palindrome("racecar"))   # True
print(is_palindrome("racecars"))  # False
```

## 요약

- 알고리즘은 같은 방식으로 매번 실행되는 문제 해결 단계의 집합이다.
- 문제를 작은 비교 단계로 분해하고, 실패 조건을 먼저 검사하면 효율적이다.
- 단순한 문제든 복잡한 문제든 같은 원리로 접근한다.
