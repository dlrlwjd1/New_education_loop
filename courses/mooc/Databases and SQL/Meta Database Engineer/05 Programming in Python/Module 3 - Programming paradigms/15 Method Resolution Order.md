# Method Resolution Order

## 개요

- 상속의 유형 5가지와 메서드 해석 순서(MRO) — 상속 계층에서 메서드·속성을 어디서 찾을지 결정하는 규칙
- 선형화(linearization), C3 알고리즘, mro()·help() 함수

## 내용

### 상속의 유형

1. **단순(simple) 상속** — 자식이 부모 하나에서 상속
2. **다중(multiple) 상속** — 자식이 **부모 여러 명**에서 상속
3. **다단계(multi-level) 상속** — 여러 수준에 걸친 상속
4. **계층적(hierarchical) 상속** — 여러 서브클래스가 공통 부모에서 상속
5. **하이브리드(hybrid)** — 위 특성들의 혼합

### MRO란

- **메서드·속성을 클래스 계층에서 검색하는 순서**를 결정한다. 그 해석 순서를 클래스의 **선형화(linearization)**라 하며, MRO는 그것이 따르는 규칙이다.
- 기본 순서: 상속 트리를 그렸을 때 **아래에서 위로, 왼쪽에서 오른쪽으로**.
  - 단일 상속: 객체의 클래스 → 슈퍼클래스 순으로 검색
  - Z가 X, Y에서 상속하면 MRO는 **Z → Y → X**
- 계층이 복잡해지면 알고리즘에 의존한다: 구식 클래스는 **깊이 우선 탐색(DFS)**, Python 3 이후 신식 클래스는 **C3 선형화 알고리즘** 사용.
  - C3의 규칙: **단조성(monotonicity)** — 상속 속성이 직계 부모를 건너뛸 수 없음 / 클래스의 상속 그래프를 따름 / 로컬 클래스의 메서드를 방문한 뒤에만 슈퍼클래스 방문.

### MRO 확인 도구

- **클래스.mro()** — 해석 순서 출력. 예: A(num=5) ← B(num=9) ← C 구조에서 C.mro()는 C→B→A — C가 **B의 9를 상속**함을 바로 알 수 있다.
- **help(클래스)** — MRO 정보에 더해 데이터 디스크립터·타입 정보까지 상세 출력.

## 예시

```python
class A:
    num = 5
class B(A):
    num = 9
class C(B):
    pass

print(C.mro())    # [C, B, A, object]
print(C.num)      # 9 — B에서 상속
help(C)           # 상세 정보
```

## 요약

- 상속은 단순·다중·다단계·계층적·하이브리드로 나뉘고, 복잡할수록 MRO가 중요해진다.
- MRO는 아래→위, 왼쪽→오른쪽 원칙과 C3 선형화 알고리즘으로 결정된다.
- mro()와 help()로 어느 클래스의 값이 상속되는지 빠르게 확인한다.
