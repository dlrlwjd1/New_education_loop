# Variables

## 개요

- 변수 선언·재할당·다중 할당·삭제와 이름 규칙(camelCase, snake_case)

## 내용

### 변수란

- **값의 참조를 유지하는** 프로그래밍의 초석. 데이터는 프로그램 생애 동안 계속 바뀌며, 변수는 그 데이터를 다루고 조작하게 해 준다.
- 선언은 이름을 정하고 값을 할당하는 것 — Python이 데이터 타입을 **자동으로 지정**한다.
- 변경하려면 **재할당(재선언)**하면 된다 (x = 10 → x = 20).

### 이름 규칙

- **camelCase** — 첫 단어는 소문자로 시작, 이후 단어의 첫 글자는 대문자, 공백 없음: `myName`
- **snake_case** — 전부 소문자, 단어 사이 언더스코어: `my_name`
- 어떤 방식이든 **프로그램 전체에서 일관성**이 중요하다.
- x·y 같은 일반적 이름 대신 **맥락에 맞는 의미 있는 이름**을 써야 몇 달 뒤의 자신과 동료가 코드를 이해할 수 있다.

### 다양한 할당

```python
x = 5              # 기본 선언
x = 'hello'        # 문자열도 가능 (타입 자동 지정)

a = b = c = 10     # 여러 변수에 하나의 값
a, b, c = 1, 2, 3  # 다중 할당 (각각 대응)

a = 10
a = 5              # 재할당 — 이후 print(a)는 5

del a              # 변수 삭제
print(a)           # NameError: name 'a' is not defined
```

## 요약

- 변수는 이름 = 값으로 선언하고 재할당으로 바꾸며 del로 삭제한다.
- 하나의 값에 여러 변수, 여러 값에 여러 변수(다중 할당)가 모두 가능하다.
- camelCase/snake_case 중 하나로 일관되게, 의미 있는 이름을 짓는다.
