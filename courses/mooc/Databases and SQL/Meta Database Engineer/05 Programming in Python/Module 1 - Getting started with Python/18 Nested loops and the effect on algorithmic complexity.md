# Nested loops and the effect on algorithmic complexity

## 개요

- 중첩 루프(nested loop)의 실행 흐름과 반복 횟수 계산
- 시간 복잡도(time complexity) — 범위가 커질수록 실행 시간이 늘어나는 것을 time 모듈로 실측

## 내용

### 중첩 루프의 흐름

- 안쪽 루프는 바깥 루프 내부에 **들여쓰기**로 작성한다.
- 실행 순서: 바깥 루프 시작 → 안쪽 루프 진입 → **안쪽 루프가 자기 범위를 다 돌아야** 바깥 루프의 다음 반복으로 → 바깥 루프 한계까지 반복.
- 반복 횟수 예: 각각 1~9를 도는 두 리스트 — 바깥 9회 + 안쪽 9×9=81회 → 합계 90회. **루프 실행 횟수는 리스트 크기에 좌우**된다.
- 시각화: 바깥 range를 1로 줄이면 0이 한 줄만(안쪽 10회), 2로 하면 두 줄 — 바깥 반복마다 안쪽이 전부 실행됨을 보여준다.

### 시간 복잡도 실측

- time 모듈로 실행 시간을 잰다: 시작 시각 기록 → 루프 실행 → (종료 시각 − 시작 시각)을 round()로 반올림해 출력.
- 실측 결과 (바깥×안쪽):
  - 10×10 → 0.0초
  - 100×100 → 0.01초
  - 100×1,000 → 0.04초
  - 100×10,000 → 0.45초
- **배열(범위)이 클수록 완료 시간이 급증** — 대규모 데이터셋에서는 실행 시간에 큰 영향을 주므로 코드 최적화와 소요 시간을 항상 고려해야 한다.

## 예시

```python
import time

start = time.time()

for i in range(100):          # outer loop
    for j in range(10000):    # inner loop
        print(0, end=" ")
    print()                    # 줄바꿈

print(round(time.time() - start, 2))   # 실행 시간(초, 소수 2자리)
```

## 요약

- 중첩 루프는 바깥 1회마다 안쪽이 전 범위를 돌므로 반복 횟수가 곱으로 늘어난다.
- 범위가 커질수록 실행 시간이 크게 증가한다 — 시간 복잡도를 의식한 최적화가 필요하다.
- time 모듈 + round로 실행 시간을 간단히 측정할 수 있다.
