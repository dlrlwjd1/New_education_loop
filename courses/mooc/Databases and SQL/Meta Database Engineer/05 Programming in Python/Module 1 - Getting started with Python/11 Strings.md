# Strings

## 개요

- 문자열(string)의 선언 방법(작은/큰따옴표, 여러 줄), 재할당, 연결(concatenation), 인덱스 접근과 len()

## 내용

### 문자열이란

- **작은따옴표 또는 큰따옴표로 감싼 문자들의 시퀀스.**
- 컴퓨터는 이진 코드만 이해하므로 문자는 **인코딩(encoding)**을 거쳐야 하며, Python은 **유니코드(Unicode)**를 사용한다.

### 선언 방법

- 작은따옴표와 큰따옴표는 **동등하게 유효** — 개인 취향이지만 코드 전체에서 하나로 일관되게 쓰는 것이 좋다.
- **여러 줄 선언**: 줄이 길면 각 줄 끝에 백슬래시(\\)를 붙여 나눈다 — 출력하면 하나의 줄로 합쳐진다.
- **재할당**: `name = 'John'` → `name = 'Paul'`처럼 단순 재할당으로 값 변경.

### 문자열은 문자 배열이다

- 문자열은 문자들의 컬렉션이므로 배열처럼 **인덱스로 개별 문자에 접근**한다.
- **0 기반 인덱싱(zero-indexing)** — 첫 문자는 [0], 세 번째는 [2].
- **len() 함수**로 문자열의 문자 수를 확인한다.

### 연결(Concatenation)

- `+` 기호는 산술 연산자지만 **문자열에 적용하면 문자열을 이어 붙인다.**

## 예시

```python
a = 'hello'       # 작은따옴표
b = "hello"       # 큰따옴표 — 동등

b = "this is a multi \
line string example"   # 백슬래시로 여러 줄

a = 'hello '
b = 'there'
print(a + b)      # hello there (연결)

name = 'John'
print(name[0])    # J  (0 기반)
print(name[3])    # n  (네 번째 문자)
print(len(name))  # 4
```

## 요약

- 문자열은 따옴표로 감싼 문자 시퀀스이고 유니코드로 인코딩된다.
- 백슬래시로 여러 줄 선언, +로 연결, [인덱스]로 개별 문자 접근(0 기반), len()으로 길이 확인.
