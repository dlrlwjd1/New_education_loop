# Why Python?

## 개요

- Python을 배우는 이유 — 배경, 강점, 활용 분야, 커리어 관점

## 내용

### Python의 배경

- **Guido van Rossum**이 만들어 **1991년** 공개. 영어와 수학의 유사성을 바탕으로 **읽기 쉽게 설계**되었다.
- 공개 이후 인기가 크게 늘어 풍부한 프레임워크·라이브러리를 지원하며, 현재 가장 인기 있는 학습 언어 중 하나다.

### 강점

- Windows·Mac·Linux 등 **다중 플랫폼**에서 동작하는 고수준 언어
- 영어를 닮은 문법이라 읽고 해석하기 쉬움
- **C나 Java보다 적은 코드**로 같은 일을 수행
- 복잡성을 추상화해 개발자가 과제에 집중하게 함 → **생산성 향상, 프로젝트 완료 시간 단축**
- 학습 곡선이 완만해 신규 프로그래머가 짧은 시간에 결과물을 낼 수 있음 — "적게 쓰고 많이 한다(write less, do more)" 철학

### 활용 분야와 커리어

- 웹 개발, 인공지능, 머신러닝, 데이터 분석 등 비즈니스 전 영역에서 사용
- Python 개발자는 수요가 높아 좋은 커리어 선택이 된다.

## 요약

- Python은 1991년 Guido van Rossum이 만든 읽기 쉬운 다중 플랫폼 언어다.
- 적은 코드·완만한 학습 곡선·높은 생산성이 강점이고, 웹·AI·ML·데이터 분석 등에서 널리 쓰이며 개발자 수요도 높다.
