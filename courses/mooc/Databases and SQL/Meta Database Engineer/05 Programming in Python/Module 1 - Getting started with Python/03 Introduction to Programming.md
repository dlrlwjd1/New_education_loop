# Introduction to Programming

## 개요

- 프로그래밍의 역사(Babbage와 Lovelace)와 컴퓨터의 근본 동작(이진 코드), 그리고 프로그래밍의 정의

## 내용

### 프로그래밍의 역사

- **Charles Babbage(1822, 케임브리지)** — 항해 차트·천문표 같은 계산 장치의 인간 오류를 해결하려고 **차분 기관(difference engine)**을 고안: 0~9 숫자가 새겨진 기계 기어를 손 크랭크로 움직여 하나의 연산을 수행.
- 이후 개선을 거듭해 **해석 기관(analytical engine)** 개념을 만들었고, 이것이 **현대 컴퓨팅의 기초**로 널리 인정받는다.
- 친구 **Ada Lovelace**는 해석 기관이 일련의 계산을 수행하는 방법을 기술한 문서를 발표했다 — 본질적으로 오늘날의 컴퓨터 프로그램이 하는 일이다.
- (해석 기관은 완성되지 못했고, Babbage는 여느 개발자처럼 문서화에 소홀했다는 농담도.)

### 컴퓨터의 근본 — 이진 코드

- 컴퓨터는 **0과 1의 이진 코드(binary code)**만 이해한다 — 전기 상태(0=꺼짐, 1=켜짐)에 대응, 전등 스위치와 유사.
- 십진수는 이진수로 변환된다: 십진 1 = 이진 1, 십진 2 = 이진 10, 십진 3 = 이진 11 ...
- 이진 코드는 **CPU(컴퓨터의 두뇌)** 안의 작은 전기 전도체인 **트랜지스터**로 표현된다.
- 사람이 이진 코드를 읽고 쓰는 것은 극히 어렵고 오류가 잦으므로, 프로그래밍 언어로 쓴 코드를 **컴파일 또는 인터프리트**해서 컴퓨터가 읽는 코드로 바꾼다.

### 프로그래밍이란

- **컴퓨터가 이해하는 언어로 명령의 집합을 제공해 작업을 수행하게 하는 능력.**
- 연습할수록 느는 **기술(skill)**이며, 같은 문제를 여러 방식으로 풀 수 있는 **창의적 기술**이기도 하다.

## 요약

- 프로그래밍의 뿌리는 Babbage의 차분·해석 기관과 Lovelace의 계산 시퀀스 문서에 있다.
- 컴퓨터는 트랜지스터로 표현되는 0/1만 이해하므로 사람이 쓴 코드는 컴파일/인터프리트를 거친다.
- 프로그래밍은 컴퓨터에게 이해 가능한 형식으로 지시를 내리는 창의적 기술이다.
