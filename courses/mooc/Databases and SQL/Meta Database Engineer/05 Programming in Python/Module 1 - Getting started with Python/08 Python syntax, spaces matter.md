# Python syntax, spaces matter

## 개요

- Python 문법에서 공백(whitespace)·줄바꿈·들여쓰기(indentation)가 프로그램에 미치는 영향

## 내용

### 한 줄에 두 문장 — 문장 구분

- `print('Hello') print('World')`처럼 한 줄에 두 문장을 쓰면 **SyntaxError: invalid syntax** — 인터프리터가 새 문장이 어디서 시작되는지 모르기 때문.
- 해결책 2가지:
  1. 둘째 문장을 **다른 줄로** 옮긴다
  2. 두 문장을 **세미콜론**으로 구분한다 (`print('Hello'); print('World')`)

### 공백과 줄 연속

- 한 줄 안의 공백은 얼마든지 괜찮다: `x = 1     +     2`도 문제없다.
- 그러나 식을 여러 줄로 나누면 문제: `x = 1 + 2` 다음 줄에 `+ 3`을 쓰면 첫 줄만 실행되어 3이 나온다.
- 해결: 첫 줄 끝에 **백슬래시(\\)** 로 줄 연속(force line)을 표시 → 6이 나온다.
- 요약: 한 줄 내 공백·들여쓰기는 자유지만, 여러 줄로 나눌 때는 새 줄임을 분명히 표시해야 한다.

### 들여쓰기

- if 블록 등에는 **들여쓰기가 필수**다:

```python
name = 'John'
if name == 'John':
    print(name)   # 들여쓰기 필요 (VS Code가 자동 추가)
```

- 들여쓰기를 지우고 실행하면 **IndentationError: expected an indented block** — 에러 메시지가 문제가 난 줄을 알려준다.
- 에러를 만나면 **출력을 읽는 습관**을 들이자 — 무엇이 어디서 잘못됐는지 구체적으로 알려준다.

## 요약

- 한 줄 다중 문장은 줄 분리나 세미콜론으로 해결한다.
- 줄 내 공백은 자유지만 식을 줄로 나눌 땐 백슬래시로 연속을 표시한다.
- 블록에는 들여쓰기가 필수이며, 에러 메시지가 위치를 정확히 알려주므로 항상 읽는다.
