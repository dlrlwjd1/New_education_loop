# Introduction to the Course

## 개요

- Programming in Python 강좌의 5개 모듈 로드맵을 안내하는 오리엔테이션 강의

## 내용

### Python이라는 언어

- 다중 플랫폼에서 쓰는 **다재다능한 고수준 언어** — 웹 개발, 데이터 분석, 비즈니스 예측 등 대소 기업의 다양한 애플리케이션에 사용된다.
- 문법이 영어와 비슷해 직관적이라 초보자가 빨리 이해하고, 숙련 개발자에게는 강력함과 적응력이 매력이다.

### 모듈 로드맵

- **Module 1 — Python 시작**: 일반적 활용 사례, 소프트웨어 공학 기초 개념, 연산자로 출력 프로그래밍, 제어 흐름·루프로 문제 해결
- **Module 2 — 기본 프로그래밍**: 변수와 데이터 타입, 조건 실행, 함수와 자료 구조, 에러 인식·원인 파악·처리, 파일 생성·읽기·쓰기
- **Module 3 — 프로그래밍 패러다임**: 함수형·객체지향 패러다임, 함수로 알고리즘적 사고 탐구, 객체·클래스·메서드
- **Module 4 — 모듈·패키지·라이브러리·도구**: 인기 모듈·패키지 탐색·임포트·사용, 워크플로 최적화 도구, 테스트 유형과 테스트 작성
- **Module 5 — 채점 평가**: 코딩 능력 시연과 학습 경로 회고

## 요약

- 이 강좌는 Python 기초 → 자료 구조·예외·파일 → 패러다임(함수형·OOP) → 모듈·패키지·테스트 → 평가 순으로 Python 코딩 기반을 다진다.
