# Type casting

## 개요

- 타입 캐스팅(type casting) — 한 데이터 타입을 다른 타입으로 변환하는 두 방식: 암시적(implicit)과 명시적(explicit)

## 내용

### 왜 필요한가

- 예: 웹 폼에서 정수여야 할 값이 문자열로 넘어오면 계산할 수 없다 — 정수 타입으로 변환해야 한다.

### 암시적(implicit) 변환

- **Python 컴파일러가 데이터 손실을 막기 위해 자동으로 수행.** 예: 소수 값이 감지되면 int를 float로 변환.
- **호환되는 타입끼리만** 가능하다 — int↔float는 호환, 문자열↔int는 비호환. 비호환이면 **TypeError**.

### 명시적(explicit) 변환 — 제공 함수 사용

- **str(값)** — 어떤 타입이든 문자열로
- **int(값)** — 정수로
- **float(값)** — 실수로
- 기타 함수:
  - **ord()** — 문자에 해당하는 유니코드 정수 반환
  - **hex()** — 정수를 16진수 문자열로
  - **oct()** — 정수를 8진수 문자열로
  - **tuple(), set(), list(), dict()** — 컬렉션 타입 변환 (이후 레슨에서 상세)

## 예시

```python
age_str = "25"          # 폼에서 문자열로 도착
age = int(age_str)      # 명시적 변환 → 계산 가능
price = float("9.99")
label = str(100)

x = 10
y = x + 2.5             # 암시적: int가 float로 자동 변환 → 12.5
```

## 요약

- 타입 캐스팅은 데이터 타입 간 변환이며, 암시적(자동, 호환 타입만)과 명시적(str/int/float 등 함수) 두 방식이 있다.
- 비호환 타입의 암시적 변환은 TypeError를 일으키므로 명시적 함수로 처리한다.
