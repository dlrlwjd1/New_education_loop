# Math and logical operators

## 개요

- 수학 연산자(+, -, /, *)와 논리 연산자(and, or, not)의 동작
- 논리 연산자가 조건문과 결합해 프로그램 흐름을 제어하는 방식

## 내용

### 연산자란

- **Python에게 특정 연산을 수행하라고 알리는 기호** — 도로 표지판에 비유. 대부분 두 값에 대해 동작하며, 수학·논리·비교 연산이 있다.

### 수학 연산자

| 연산 | 기호 | 예 |
|---|---|---|
| 덧셈 | `+` | 2 + 2 → 4 |
| 뺄셈 | `-` | 2 - 2 → 0 |
| 나눗셈 | `/` | 35 / 5 → **7.0 (float 반환)** |
| 곱셈 | `*` | 35 * 5 → 175 |

- 나눗셈 결과는 정수가 아닌 **float**로 반환된다는 점에 주의.

### 논리 연산자

- **and** — **모든 조건이 참**이어야 참. 예: `a > 5 and a < 10`
- **or** — **하나 이상이 참**이면 참. 예: `a > 5 or b > 10`
- **not** — 결과를 **부정**. 참이면 거짓 반환. 예: `not a`
- 활용: 조건문과 결합해 특정 기준을 만족할 때만 코드 실행 — 예: 로열티 프로그램 회원이면서 $100 이상 구매한 고객에게 할인.

## 예시

```python
a = True
b = True
if a and b:
    print("all true")     # 둘 다 참일 때만 출력 (b=False면 출력 없음)

if a or b:
    print("all true")     # 하나만 참이어도 출력 (둘 다 False면 없음)

a = False; b = False
if (not a) or (not b):
    print("all true")     # not False = True → 출력됨
```

## 요약

- 수학 연산자는 +, -, /, *이며 나눗셈은 float를 반환한다.
- and는 전부 참, or는 하나 이상 참, not은 부정이다.
- 논리 연산자는 조건문과 결합해 프로그램 흐름 제어의 근간이 된다.
