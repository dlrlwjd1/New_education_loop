# How is Python used in the real world?

## 개요

- Meta 엔지니어 Laila Rizvi가 들려주는 실세계에서의 Python 활용 — Instagram 백엔드부터 머신러닝까지

## 내용

### Python이라는 이름

- 창시자는 뱀이 아니라 TV 쇼 **Monty Python's Flying Circus**의 팬이었고, 짧고 수수께끼 같은 어감의 Python을 언어 이름으로 삼았다.

### 실세계에서의 Python

- Instagram, Facebook, Google, Spotify 등 — 인지하지 못해도 일상적으로 Python이 만든 서비스를 쓰고 있을 만큼 **어디에나 있는(ubiquitous) 언어**.
- **TensorFlow**(머신러닝 프레임워크)에도 쓰인다 — Airbnb의 이미지 분류, 헬스케어 기업의 MRI 데이터 분류 등.
- Meta에서의 활용: **Instagram 백엔드**, 광고 머신러닝 알고리즘, 서비스 가동을 유지하는 프로덕션 엔지니어링.

### 배우는 사람에게

- 화자의 경험: 첫 언어가 Python이었고 첫 애플리케이션은 계산기 — 들여쓰기·공백·문법·루프 같은 핵심 개념이 처음엔 어려웠지만 꾸준히 하니 됐다.
- Python을 배워야 하는 이유: 배우기 쉽고 단순하며, **지원 라이브러리가 풍부**하고 사용하는 엔지니어가 많아 기능을 빠르게 개발하고 결과를 빨리 볼 수 있다.

## 요약

- Python은 Instagram·Facebook 등 대형 서비스와 TensorFlow 기반 머신러닝을 지탱하는 보편적 언어다.
- 단순한 문법과 풍부한 라이브러리·커뮤니티 덕분에 빠른 개발과 학습이 가능하다.
