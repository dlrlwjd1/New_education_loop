# Module summary: Getting started with Python

## 개요

- Module 1(Python 시작)에서 배운 내용을 되짚는 요약 강의

## 내용

### 이 모듈에서 익힌 능력

- 프로그래밍의 역사와 일반적 동작 원리 설명
- Python의 이점과 활용처 설명, 개발 환경 설정 점검(Windows/Mac)
- 커맨드라인 vs IDE 실행 방식의 차이
- 문법과 공백·들여쓰기의 중요성
- 변수의 개념과 사용, 데이터 타입 식별
- 문자열 선언·사용, 타입 캐스팅 두 방식(암시적/명시적)
- 사용자 입력(input)과 콘솔 출력(print)의 기초
- 수학·논리 연산자 인식
- 조건문(if/elif/else)으로 흐름 제어, match-case 문 활용
- 루프 구조(for/while)와 중첩 루프의 동작

## 요약

- Python의 구조와 규칙(문법·변수·타입·연산자·조건문·루프)을 갖췄으니 이제 프로그램을 만들 준비가 되었다.
