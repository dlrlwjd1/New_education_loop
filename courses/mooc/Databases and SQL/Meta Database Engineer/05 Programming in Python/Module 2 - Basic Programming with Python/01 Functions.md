# Functions

## 개요

- 함수의 개념(입력을 받아 출력을 반환하는 명령 집합)과 def 선언, 인자 전달, return

## 내용

### 함수란

- **입력을 받아 출력을 반환하는 명령의 집합** — print(값 출력), input(사용자 입력 수용)도 함수다.
- **재사용 가능한 모듈식 코드 조각**으로, 특정 과업을 수행한다.

### 선언과 호출

- `def 함수명(매개변수):` — def 키워드 + 이름 + (선택적) 괄호 속 매개변수 + 수행할 작업.
- **함수는 호출될 때만 실행**된다 — 정의만 하고 실행하면 아무 일도 안 일어난다.
- `return`으로 값을 되돌린다.
- 함수의 장점: **한 번 수정하면 그 함수를 호출하는 모든 코드에 반영**된다.

## 예시

세금 계산 — 변수를 매번 갱신하는 비효율을 함수로 해결:

```python
# 비효율: 고객마다 변수 수정 필요
bill = 175.00
tax_rate = 15
total_tax = bill * tax_rate / 100

# 재사용 함수
def calculate_tax(bill, tax_rate):
    return bill * tax_rate / 100

print(calculate_tax(175, 15))              # 26.25
print(calculate_tax(164.33, 22))           # 36.1526
print(round(calculate_tax(164.33, 22), 2)) # 36.15 — round로 소수 자리 정리
```

## 요약

- 함수는 def로 선언하고 매개변수로 입력을 받아 return으로 출력을 반환하며, 호출해야 실행된다.
- 인자를 받으면 동적으로 재사용할 수 있고, 수정도 한 곳에서 끝난다.
- round() 같은 함수와 결합해 출력을 다듬을 수 있다.
