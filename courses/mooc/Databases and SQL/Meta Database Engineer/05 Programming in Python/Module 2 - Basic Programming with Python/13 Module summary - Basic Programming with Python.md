# Module summary: Basic Programming with Python

## 개요

- Module 2(기본 프로그래밍)에서 배운 내용을 되짚는 요약 강의

## 내용

### 레슨 1 — 함수와 스코프

- 함수 선언(def), 데이터 전달(매개변수), 반환(return)
- 4가지 스코프(LEGB) 식별과 함수가 수준별로 스코프를 통제하는 방식
- 자료 구조의 개념과 리스트 소개

### 레슨 2 — 자료 구조

- 리스트 메서드, 리스트에 저장 가능한 타입, 순회 방법
- 튜플·집합·딕셔너리·kwargs의 주요 용도

### 레슨 3 — 파일 처리와 예외

- open 함수로 파일 생성·조작, 파일 읽기(read/readline/readlines)
- 다양한 형식으로 출력하고 파일 내용을 자료 구조에 저장하기
- 에러·예외 처리 (try/except)

## 요약

- 함수·스코프, 자료 구조(리스트·튜플·집합·딕셔너리·kwargs), 예외 처리·파일 입출력까지 Python 기본 프로그래밍의 골격을 갖췄다.
