# Lists

## 개요

- 리스트(list) — 어떤 데이터 타입이든 담는 동적 배열 — 의 선언, 인덱스 접근, 추가(insert/append/extend), 제거(pop/del), 순회

## 내용

### 리스트란

- **같거나 다른 데이터 타입 하나 이상의 시퀀스** — 사실상 어떤 타입도 담을 수 있는 동적 배열.
- 대괄호 + 쉼표로 선언한다. 문자열·정수·불리언·실수 혼합도, **중첩 리스트**도 유효하다.
- **0 기반 인덱스**: list1의 세 번째 항목은 `list1[2]`.

### 항목 추가 — 3가지

- **insert(인덱스, 값)** — 지정 위치에 삽입. 끝에 넣으려면 `list1.insert(len(list1), 6)`
- **append(값)** — 인덱스 지정 없이 끝에 추가
- **extend([값들])** — **리스트를 받아 여러 항목을 한 번에** 덧붙임

### 항목 제거 — 2가지

- **pop(인덱스)** — 해당 위치 항목 제거 (pop(4) = 다섯 번째 항목)
- **del list1[인덱스]** — del 키워드로 해당 인덱스 삭제

### 출력과 순회

- `print(*list1, sep=", ")` — 별표로 전체 항목 언패킹 출력, sep로 구분자 지정
- for 루프로 순회: 리스트를 쓰는 주된 이유는 **대량 데이터에 반복 접근**하기 위해서다.

## 예시

```python
list1 = [1, 2, 3, 4, 5]
list2 = ['a', 'b', 'c']
list3 = ['text', 10, True, 2.5]     # 혼합 타입
list4 = [1, [2, 3, 4], 5, 6]        # 중첩 리스트

print(list1[2])                 # 3 (0 기반)
list1.insert(len(list1), 6)     # 끝에 6 삽입
list1.append(6)                 # 끝에 추가
list1.extend([6, 7, 8, 9])      # 다중 추가
list1.pop(4)                    # 5번째 항목 제거
del list1[2]                    # 인덱스 2 제거

for x in list1:
    print("value", x)
```

## 요약

- 리스트는 혼합 타입·중첩까지 담는 0 기반 동적 배열이다.
- 추가는 insert(위치 지정)/append(끝)/extend(다중), 제거는 pop(인덱스)/del이다.
- for 루프 순회가 리스트 활용의 핵심이다.
