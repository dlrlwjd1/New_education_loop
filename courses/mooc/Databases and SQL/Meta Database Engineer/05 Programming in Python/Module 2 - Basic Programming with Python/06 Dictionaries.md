# Dictionaries

## 개요

- 딕셔너리(dictionary) — 키-값 쌍으로 값을 검색하는 자료 구조 — 의 성능 이점과 CRUD 조작, 순회 방법

## 내용

### 딕셔너리란

- 실제 사전처럼 **키로 값을 바로 찾도록 최적화**된 구조. 리스트는 항목을 찾을 때까지 계속 훑어야 하지만, 딕셔너리는 **키로 곧장 접근**하므로 더 빠르고 유연하다.
- 값은 **변경 가능(mutable)** — 갱신·삭제 가능.
- 빈 중괄호 `{}`는 기본적으로 **빈 딕셔너리**로 분류된다 (type()으로 확인 가능).

### 조작

- **선언**: `{키: 값, ...}` — 키는 숫자·문자열 모두 가능, 콜론으로 할당, 쌍은 쉼표로 구분
- **접근**: `d[키]`
- **추가/갱신**: `d[키] = 값` — 있으면 갱신, 없으면 추가
- **중복 키 불허** — 같은 키를 다시 넣으면 **최신 값으로 덮어쓴다**
- **삭제**: `del d[키]`

### 순회 3가지

1. `for x in d:` — **키만** 순회
2. `d.items()` — **키와 값 모두** 접근 (키·값 동시 할당)
3. `d.values()` — 값 순회
- 정수 키를 문자열과 연결(concatenation)할 때는 str() 변환이 필요하다.

## 예시

```python
my_d = {}                      # 빈 딕셔너리
my_d[1] = "test"
my_d["name"] = "Jim"

print(my_d[1], my_d["name"])   # test Jim
my_d[1] = "not a test"         # 갱신 (중복 키는 덮어씀)
del my_d[1]                    # 삭제

for key, value in my_d.items():
    print(str(key) + " " + str(value))
```

## 요약

- 딕셔너리는 키-값 쌍으로 리스트보다 빠르게 값을 찾는 가변 구조다.
- d[키]로 접근·추가·갱신하고 del로 지우며, 중복 키는 최신 값으로 덮어써진다.
- 순회는 기본(키만)·items()(키+값)·values()(값만) 세 방법이 있다.
