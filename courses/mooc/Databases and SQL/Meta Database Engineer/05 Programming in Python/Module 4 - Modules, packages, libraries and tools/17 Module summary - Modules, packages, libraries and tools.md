# Module summary: Modules, packages, libraries and tools

## 개요

- Module 4(모듈·패키지·라이브러리·도구)에서 배운 내용을 되짚는 요약 강의

## 내용

### 익힌 능력

- **모듈**: 개념과 용도, 유형과 위치, 내장·사용자 정의 모듈 접근, 다른 디렉터리의 모듈 임포트, import 문 작성, reload() 함수
- **패키지**: pip로 PyPI 패키지 설치, 모듈 사용 사례, 내장 vs 사용자 정의 구분, 인기 패키지 나열
- **데이터 분석·과학 라이브러리**: NumPy, pandas, Matplotlib, scikit-learn 등
- **ML·AI 라이브러리**와 Python 빅데이터 분석, **웹 프레임워크** 정의와 유형(풀스택·마이크로·비동기)
- **테스팅**: 개념과 유형, 4대 수준(단위·통합·시스템·인수), 테스트 패키지(Pytest·Selenium·Robot), 자동화 테스트의 중요성
- **TDD**: 방법론 설명과 특징

## 요약

- 모듈·패키지 임포트부터 데이터/ML 라이브러리, 웹 프레임워크, 테스팅과 TDD까지 코드의 능력을 확장하는 생태계 전반을 다뤘다.
