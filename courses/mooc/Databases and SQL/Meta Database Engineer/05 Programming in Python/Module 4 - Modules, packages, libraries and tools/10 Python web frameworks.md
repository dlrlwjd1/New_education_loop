# Python web frameworks

## 개요

- 웹 프레임워크의 역할과 Python 웹 프레임워크의 3유형: 풀스택, 마이크로, 비동기
- 대표 프레임워크 Django(풀스택)와 Flask(마이크로) 비교

## 내용

### 웹 프레임워크란

- **웹 애플리케이션을 만들고 배포·지원하는 표준 방식을 제공하는 소프트웨어.**
- 반복 작업을 자동화해 개발자가 애플리케이션 로직에 집중하게 하고, 기본 구조·모델을 제공해 신뢰성·안정성·유지보수성을 높인다.
- 고수준 코드로 작성되어 소켓·스레딩·프로토콜 같은 개념 이해의 부담을 제거한다.
- Python 프레임워크의 강점: 좋은 문서, 풍부한 라이브러리, 구현 용이성, 재사용성, 보안, 쉬운 통합. 폼 처리, 요청 라우팅, 데이터베이스 연결, 사용자 인증을 쉽게 다루며 디버깅·테스트(프로파일링, 커버리지, 자동화) 도구를 제공한다.

### 3유형

1. **풀스택(full-stack)** — 필요한 기능이 다 있는 원스톱: 폼 생성·검증, 템플릿 레이아웃, HTTP 요청 처리, 웹 서버 연결용 WSGI 인터페이스, DB 연결 처리. 대표: **Django, Web2py, Pyramid**
2. **마이크로(micro)** — 풀스택의 경량판, 패턴·기능이 적다. 작은 프로젝트와 **API 구축**에 적합. 대표: **Flask, Bottle, Dash, CherryPy**
3. **비동기(asynchronous)** — **대량의 동시 연결** 처리용, 주로 asyncio 네트워킹 라이브러리 기반. 대표: **Growler, AIOHTTP, Sanic**

### Django vs Flask

- **Django** — 깔끔한 설계와 빠른 개발을 장려하는 고수준 풀스택. 기능·라이브러리가 풍부하고 보안·템플릿·서드파티 지원이 좋다. **저수준 지식 없이 확장 가능한 앱을 빠르게 배포**할 수 있어 인기.
- **Flask** — 작은 프로젝트에 적합한 마이크로 프레임워크. 배우기 쉽고 단순하며 애드온 라이브러리가 많다.

### 선택 기준

- 문서화 수준, 확장성, 유연성, 통합 — 프레임워크마다 고유 기능이 있어 프로젝트에 따라 적합성이 다르다.

## 요약

- 웹 프레임워크는 반복 작업을 자동화해 로직에 집중하게 하는 표준 구조다.
- Python은 풀스택(Django)·마이크로(Flask)·비동기(AIOHTTP 등) 3유형을 제공한다.
- 프로젝트 규모와 요구(문서·확장성·통합)에 따라 프레임워크를 고른다.
