# Machine learning, deep learning and AI: PyTorch, TensorFlow

## 개요

- AI·데이터 과학·머신러닝의 관계와 Python이 이 분야에서 인기 있는 이유
- 패키지 vs 라이브러리 vs 프레임워크 용어 구분, ML 라이브러리의 활용 영역

## 내용

### 세 분야의 관계

- **AI** — 넓게는 기계가 인간처럼 생각하게 만드는 것
- **데이터 과학** — 텍스트·오디오·이미지·비디오를 포함한 데이터의 관리·탐구
- **머신러닝(ML)** — AI의 하위 분야로, 데이터를 학습해 통찰을 만드는 알고리즘
- ML의 대표 활용 영역: 자연어 처리, 딥러닝, 감성 분석, 추천 엔진, 컴퓨터 비전, 음성 인식

### Python이 인기인 이유

- 문법의 효율성과 가독성 / 언어·프레임워크·운영체제 간 유연성 / 크고 환영하는 개발자 커뮤니티
- 내부 구조를 다 이해하지 않아도 ML 모델을 만들 수 있음 / 친화적 디버그·테스트 도구 / 모듈식 구조
- 이 특성들이 수많은 오픈소스 라이브러리·프레임워크의 탄생을 이끌었다.

### 용어 정리

- **패키지** = 모듈의 모음
- **라이브러리** = 패키지와 혼용되지만, 특정 목적을 가진 패키지들의 모음일 수 있음
- **프레임워크** = **일정한 흐름과 아키텍처**가 있을 때 쓰는 용어
- 셋 다 import 문으로 사용한다.

### ML 라이브러리의 영역

- 딥러닝·신경망(PyTorch, TensorFlow 등), 컴퓨터 비전·이미지 인식, 자연어 처리, 데이터 시각화, 웹 스크레이핑
- 이 분류는 대략적일 뿐 — 대부분의 라이브러리는 한 분야에 국한되지 않는다. **프로젝트마다 알맞은 라이브러리 선택이 코딩 시간을 절약**한다.

## 요약

- ML은 AI의 하위 분야이고, Python은 가독성·커뮤니티·모듈 구조 덕에 이 영역의 사실상 표준 언어다.
- 패키지(모듈 모음)·라이브러리(목적성 모음)·프레임워크(흐름·아키텍처)를 구분하되 모두 import로 쓴다.
- 딥러닝·비전·NLP 등 영역별 라이브러리에서 프로젝트에 맞는 것을 신중히 고른다.
