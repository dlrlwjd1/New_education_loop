# What is a module in Python?

## 개요

- 모듈(module) — 문장과 정의를 담은 코드 블록 — 의 개념과 3대 이점: 스코프·재사용성·단순성
- 내장 모듈과 임포트 실행의 성질

## 내용

### 모듈이란

- **문장과 정의를 담는 파일** — sample.py 파일이 sample이라는 모듈이 되어 임포트할 수 있다. 실행문과 함수 모두 담을 수 있다.
- 파이 굽는 레시피처럼, 매번 다시 만들지 않도록 **기능을 추가하는 빌딩 블록** 역할을 한다.

### 모듈러 프로그래밍의 3대 이점

1. **스코프(scoping)** — 모듈은 **별도의 네임스페이스**를 만든다. 서로 다른 두 모듈이 같은 이름의 함수를 가질 수 있고, 임포트하면 실행 코드의 전역 공간에 포함된다.
2. **재사용성(reusability)** — 가장 중요한 이점. 코드·노력의 중복은 메모리를 더 쓰고 비효율적이다. 예: math 패키지를 임포트하면 factorial, GCD(최대공약수) 등 정의 없이 재사용할 기능을 바로 얻는다.
3. **단순성(simplicity)** — 각 모듈은 단순한 목적 하나로 만들어지고, 모듈 간 의존이 적을수록 단순함이 유지된다. 예: 정규 표현식은 re 모듈, 데이터 시각화는 Matplotlib 하나로 충분.

### 임포트와 실행의 성질

- **내장(built-in) 모듈** — 표준 Python 라이브러리에 이미 포함. `import math` 시 인터프리터가 먼저 내장 모듈에서 찾는다.
- **모듈은 실행 중 한 번만 임포트**된다 — print 문이 든 모듈을 여러 번 임포트해도 첫 임포트 때만 실행된다.
- 독립 모듈은 함수들을 담되 호출 없이 실행되는 함수는 거의 없다 — 사용자가 함수를 실행할 때 효용이 나타난다.
- 임포트는 보통 코드 첫머리에 두지만 어느 지점에서도 가능하다. 단, Python 실행은 순차적이므로 **함수를 쓰기 전에 임포트**해야 하며, 함수 안에서 임포트하면 그 함수가 실행될 때부터 쓸 수 있다.

## 요약

- 모듈은 기능을 담아 재사용하는 파일 단위 빌딩 블록으로, 스코프·재사용성·단순성을 제공한다.
- 내장 모듈은 import 문으로 즉시 쓸 수 있고, 모듈은 실행당 한 번만 임포트된다.
- 사용 전에 임포트해야 한다는 순서 규칙만 지키면 어디서든 임포트할 수 있다.
