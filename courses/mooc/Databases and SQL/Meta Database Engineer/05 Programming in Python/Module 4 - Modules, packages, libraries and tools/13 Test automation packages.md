# Test automation packages

## 개요

- 테스트 자동화의 대상 조건과 Python 자동화 프레임워크: unittest, Pytest, Robot, Selenium

## 내용

### 무엇을 자동화하는가

- 자동화에 적합한 테스트: **반복성·볼륨이 높고, 환경·데이터가 예측 가능하며, 결과가 결정적**인 것 — 단위·회귀·통합 테스트가 자동화 가능하다.
- 자동화의 이상적 단계: 테스트 환경 준비 → 테스트 스크립트 실행 → 결과 분석.

### 주요 프레임워크

- **unittest** — Python 내장 테스트 패키지. 테스트 자동화, 독립 테스트 모듈, 테스트의 컬렉션 집계를 지원.
- **Pytest** — 단순·사용 용이·상당한 확장성의 네이티브 라이브러리. 단위·통합·엔드투엔드 등 기능 테스트를 다루고, **매개변수화 테스트**(같은 단위 테스트를 다른 인자로 여러 번 실행), 병렬 실행, HTML/XML/텍스트 리포트를 지원한다. Pyunit·nose2, Flask·Django와 통합 가능. API 테스트가 주 무대지만 UI·DB 연결·웹 앱에도 널리 쓰인다. **쉬운 작성과 빠른 버그 수정 덕에 가장 인기 있는 자동화 프레임워크.**
- **Robot** — **키워드 주도 개발**이 특징(사전 정의/사용자 정의 키워드를 테스트 케이스에 사용). 인수 테스트, RPA(robotic process automation), TDD에 활용. Android·API·메인프레임 등 다양한 도메인 지원.
- **Selenium** — **웹 애플리케이션** 지향 오픈소스. 대다수 브라우저·OS 지원, 브라우저별 웹 드라이버로 로그인·버튼 클릭·폼 작성 등을 테스트. 실행 속도 선택, 특정 테스트/스위트 실행 옵션 제공.

### 도구 생태계와 한계

- 프레임워크들은 플러그인·위젯·확장·테스트 러너·드라이버와 함께 쓰이며, 한 코드에 여러 프레임워크를 함께 적용하기도 한다.
- **수동 테스트는 아직 대체 불가** — 미묘함과 복잡한 문제를 더 정교하게 다룬다. 완전 자동화까지는 시간이 필요하다.

## 요약

- 반복적·예측 가능·결정적 테스트가 자동화 대상이며 단위·회귀·통합 테스트가 대표적이다.
- unittest(내장), Pytest(최고 인기, 매개변수화·병렬·리포트), Robot(키워드 주도·RPA), Selenium(웹·브라우저)이 주요 프레임워크다.
- 자동화가 산업을 가속하지만 수동 테스트의 역할은 여전히 남아 있다.
