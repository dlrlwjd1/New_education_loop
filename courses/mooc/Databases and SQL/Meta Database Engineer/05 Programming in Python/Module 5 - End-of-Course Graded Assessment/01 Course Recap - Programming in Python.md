# Course Recap: Programming in Python

## 개요

- Programming in Python 강좌 전체(4개 학습 모듈)를 되짚는 총정리 강의

## 내용

### Module 1 — Python 시작

- 실세계의 Python 활용과 존재 이유, VS Code 실행과 운영체제 환경 점검(의존성 확인)
- 변수·데이터 타입, 문자열·캐스팅, 연산자와 루프·흐름 제어

### Module 2 — 핵심 프로그래밍 스킬

- 함수와 자료 구조: 스코프, 리스트, 튜플, 집합, 딕셔너리, kwargs
- 에러·예외·파일 처리와 에러 처리 접근법

### Module 3 — 프로그래밍 패러다임

- 함수형·객체지향 패러다임과 논리 개념
- 알고리즘 입문, 클래스와 인스턴스

### Module 4 — 모듈·라이브러리·도구

- 모듈·라이브러리·도구로 코딩 환경 강화
- 테스트 유형과 테스트 작성법

## 요약

- Python 기초 → 자료 구조·예외·파일 → 패러다임 → 생태계·테스팅 순으로 개발 기반을 완성했으며, 다음은 채점 평가다.
