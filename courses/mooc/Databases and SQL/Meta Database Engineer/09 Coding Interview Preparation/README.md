> 2026-09-06: 이 폴더에는 Meta iOS Developer 쪽과 **바이트 단위로 동일한** 노트 27개가 복사돼 있었다. 저장소는 공유 강좌를 포인터 README 하나로 처리하며 Meta Android Developer·Meta Front-End Developer도 이 강좌를 Meta iOS 쪽으로 가리키고 있어, 같은 방식에 맞춰 중복 사본을 제거하고 이 문서로 대체했다.
