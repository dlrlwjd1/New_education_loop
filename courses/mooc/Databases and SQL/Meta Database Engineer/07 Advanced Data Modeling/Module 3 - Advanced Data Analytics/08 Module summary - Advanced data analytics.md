# Module summary: Advanced data analytics

## 개요

- Module 3(고급 데이터 분석)에서 배운 내용을 되짚는 요약 강의

## 내용

### 데이터 분석 기초

- 데이터 분석 = 집계된 데이터를 유용하고 의미 있는 정보로 변환·처리
- 분석 유형: 기술적(서술), 탐색적(변수 관계), 추론적(표본 추론), 예측적(패턴→미래 예측), 인과적(원인·결과)
- 데이터 유형: 정량(수치) vs 정성(비수치)
- 측정 척도 4종: 명목(라벨만, 값·순서 없음), 서열(순위), 구간(명확한 차이, 음수 가능), 비율(식별+순서+등간격, 음수 불가)

### 데이터 마이닝과 머신러닝

- 데이터 마이닝 = 패턴 탐지, 머신러닝 = 컴퓨터에 학습을 가르침(지도/비지도)
- 마이닝 모델: 분류 분석, 연관 규칙, 이상치 탐지, 군집 분석, 회귀 분석

### 데이터 시각화

- 의사결정자가 빠르고 쉽게 해석하도록 표현
- 고려 질문: 청중은 누구인가, 어떤 정보가 필요한가, 검토 시간은, 요구 정확도는
- 차트: 막대, 선, 버블, 맵, 산점도 — 각자 목적이 다르므로 청중에게 가장 잘 전달되는 것 선택

### Tableau

- 다양한 데이터 타입 저장, 광범위한 소스·파일 연동, 인터랙티브 대시보드, 다중 언어 스크립팅, 드래그 앤 드롭
- 워크플로: 다운로드·실행·탐색 → 데이터 임포트·준비(라이브 연결/임포트, 필터링·분할·계산 필드·타입 수정) → 필터·분석·시각화(소스 페이지/워크시트, 조건 필터, 서브카테고리) → 인터랙티브 대시보드 생성 → 분석 실습

## 요약
