# Data mining versus machine learning

## 개요

- 데이터 마이닝(data mining)과 머신러닝(machine learning)의 차이, 그리고 머신러닝이 활용하는 5가지 데이터 마이닝 모델

## 내용

### 데이터 마이닝 vs 머신러닝

- 두 용어는 자주 혼용되지만 작동 방식이 다르다.
- **데이터 마이닝** — 데이터에서 **패턴을 탐지**하는 프로세스. 패턴 기반으로 인사이트·판단·예측 도출. 예: 테이블 구매 고객이 의자도 구매 → 함께 광고·판매
- **머신러닝** — 컴퓨터가 **학습하도록 가르치는** 프로세스. 확률 판단과 예측을 학습
  - **지도 학습(supervised)** — 주어진 **라벨** 기반 분류. 예: 의자·테이블 이미지 CH, 책상 DK로 라벨링 → 라벨 기반 인식·분류·그룹화 학습
  - **비지도 학습(unsupervised)** — 라벨 없이 **공유 특성** 기반 분류. 예: 이미지 속 형태로 의자·테이블·책상 분류

### 머신러닝이 쓰는 데이터 마이닝 모델

1. **분류 분석(classification analysis)** — 데이터를 카테고리/클래스에 배정, 대상 클래스 예측. 예: 저가 사무용품 구매 고객 → "저예산 고객"으로 분류해 저가 상품 광고 타깃팅
2. **연관 규칙(association rule)** — 데이터 요소 간 관계를 식별, 기준에 따른 상관 판단. 예: 휴대폰 구매 고객이 충전기·배터리팩도 구매 → 함께 광고·판매
3. **이상치 탐지(outlier detection)** — 기대 패턴에 맞지 않는 이상 데이터(anomaly) 발견. 예: 저가 상품만 사던 고객군이 갑자기 고가 상품 구매 → 재분류 후 고가 상품 광고
4. **군집 분석(clustering analysis)** — 데이터 내 유사성을 찾아 공통 특성 기반 **부분집합(cluster)** 으로 분리. 분류 분석과 비슷하지만 분류 분석은 **사전 정의된** 그룹, 군집은 **새로 발견한** 그룹. 예: 온라인 스토어 탐색 행동 유사성으로 저/고예산 고객 구분
5. **회귀 분석(regression analysis)** — 데이터에 영향을 주는 요인들 간 관계 결정. 예: 특정 상품 할인 → 매출 증가 → 할인이 매출에 영향을 준다고 결론

## 요약

- 데이터 마이닝은 패턴 탐지, 머신러닝은 기계에 학습(지도=라벨, 비지도=특성)을 가르치는 것이다.
- 머신러닝은 분류·연관 규칙·이상치 탐지·군집·회귀 등 마이닝 모델을 활용해 데이터를 처리한다.
