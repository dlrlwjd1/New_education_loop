# Using advanced analytic tools for data analysis

## 개요

- 데이터 분석 도구(Tableau, SAS BI, Power BI)의 공통 특징과 Tableau 작업 환경 소개

## 내용

### 데이터 분석 도구의 역할

- 분석은 전통적 DBMS의 능력을 넘는 복잡한 작업 — 전용 분석 도구가 필요.
- AI·머신러닝·데이터 마이닝을 활용하고, 결과 이해·전달을 돕는 시각화 도구를 제공.
- 대표 도구: **Tableau**, **SAS Business Intelligence**, **Microsoft Power BI**

### 공통 핵심 기능

- 대량의 데이터 처리
- 다양한 형식의 데이터 및 다양한 데이터 소스·데이터베이스 시스템과 연동
- 고급 분석 기법으로 인사이트 생성
- 고급 데이터 시각화 도구 제공

### Tableau 특징

- 널리 쓰이는 시각화 도구 — 14일 무료 체험, 공인 교육기관 교수·학생 1년 라이선스
- string, date, time 등 다양한 데이터 타입 저장
- 데이터 소스 연결: MySQL, Microsoft SQL, MongoDB, Oracle DB 등
- 파일 연동: Excel, JSON, PDF 등
- 실시간 데이터 **인터랙티브 대시보드** 생성
- **Python·R 스크립팅** 지원, 드래그 앤 드롭 UI
- 데스크톱·클라우드 버전 (이 과정은 Tableau Desktop 사용, tableau.com에서 다운로드)

### Tableau 작업 환경

- **시작 페이지** — 워크북 열기(Open a workbook), 샘플 워크북(Accelerator), 학습 자료(Discover), 데이터 소스 연결(Connect 패널 — 예: Excel 문서 로드)
- Tableau 아이콘으로 **저작 워크스페이스(authoring workspace)** 전환 — 연결된 소스와 필드가 데이터 패널에 표시
- **Marks 카드**와 **행/열 선반(shelves)** 으로 뷰에 데이터 추가 — 측정값·차원을 드래그해 비교
- **툴바** — 명령·내비게이션(정렬 아이콘으로 오름/내림차순 등)
- **대시보드** — 여러 소스를 한 번에 보고, 여러 시트를 결합한 인터랙티브 대시보드 구성
- **스토리(Story)** — 워크시트·대시보드 시퀀스로 데이터 이야기 전달

## 요약

- 분석 도구는 대량·다형식 데이터를 다루며 AI 기반 분석과 시각화를 제공한다 (Tableau, SAS BI, Power BI).
- Tableau는 다양한 소스 연결, 인터랙티브 대시보드, Python/R 지원, 드래그 앤 드롭이 강점이며 이 과정의 실습 도구다.
