# Overview of data visualization

## 개요

- 데이터 시각화(data visualization)의 정의, 시각화 결정에 고려할 4요소, 주요 차트 유형 5가지

## 내용

### 데이터 시각화란

- 의사결정자가 정보를 **빠르고 쉽게 해석**하도록 데이터를 표현하는 것.
- 데이터의 노이즈를 제거하고 추세·패러다임·이상치 같은 중요한 요소를 사용자 친화적으로 제시 — "데이터로 유익하고 몰입감 있는 이야기 전하기".

### 시각화 결정 4요소

1. **대상 청중** — 누구에게 보여주는가, 배경과 주제 이해 수준은?
2. **포함할 정보** — 어떤 정보가 청중의 질문에 답하는가, 무엇이 불필요한가?
3. **시간** — 차트 하나를 이해하는 데 몇 분이면 되게 할 것인가?
4. **정확도 수준** — 개략적 이해면 충분한가, 세부까지 드릴다운해야 하는가?

### 주요 차트 유형

| 차트 | 용도 | Global Superstore 예 |
| --- | --- | --- |
| **막대 차트(bar chart)** | 비교형 — 값들의 차이·유사성, 카테고리 간 수치 비교(가로/세로) | 상품 판매 vs 이익률 — 카테고리별 이익 |
| **선 그래프(line graph)** | 연속 구간·기간의 정량 데이터, 좌표계 위 데이터 점 연결 | 최근 수년간 이익 추세 |
| **버블 차트(bubble chart)** | 수치 변수 간 관계 — 버블의 크기·위치·색으로 비교 | 큰 버블 = 더 수익성 높은 부서 |
| **맵 차트(map chart)** | 지리 영역별 데이터 — 색·라벨 등으로 표현 | 글로벌 지역별 매출 |
| **산점도(scatter plot)** | 좌표 격자에 변수를 점으로 표시, 상관 탐색, 카테고리별 추세선 추가 가능 | 카테고리/부서별 매출·이익 |

## 요약

- 시각화는 노이즈를 걷어내고 데이터의 이야기를 전달하는 일이다.
- 청중·정보·시간·정확도 4요소를 먼저 정한 뒤, 메시지에 맞는 차트(막대=비교, 선=추세, 버블=관계, 맵=지리, 산점도=상관)를 고른다.
