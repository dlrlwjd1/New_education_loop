# Overview of data analytics

## 개요

- 데이터 분석(data analytics)의 유형 복습과 데이터 종류(정량/정성), 4가지 측정 척도(명목·서열·구간·비율)

## 내용

### 데이터 분석 유형 복습

- **기술적(descriptive)** — 데이터를 서술 형식으로 제시
- **탐색적(exploratory)** — 변수 간 관계 규명
- **추론적(inferential)** — 작은 표본으로 추론
- **예측적(predictive)** — 패턴을 찾아 미래 성과 예측
- **인과적(causal)** — 변수 간 원인과 결과 탐구

### 정량 vs 정성 데이터

- **정량(quantitative)** — 셀 수 있는 수치 데이터. 예: 일평균 구매 고객 수, 평균 구매 금액
- **정성(qualitative)** — 비수치·서술 데이터. 예: 상품 카테고리 이름·설명(가구, 사무용품)

### 4가지 측정 척도

| 척도 | 성격 | 특징 | 예 |
| --- | --- | --- | --- |
| **명목(nominal)** | 정성 | 순수 서술 — 데이터의 식별만 | 재고 상품 식별(의자, 책상) |
| **서열(ordinal)** | 정성 | 순위 부여, 단 값 사이 차이의 명확한 기준 없음 | 품질 등급 1(최고)·2(우수)·3(양호) |
| **구간(interval)** | 정량 | 데이터 간 차이를 명확한 기준으로 식별, 음수 가능, **0이 절대값 아님** | 상품 피드백 −10 ~ +10 |
| **비율(ratio)** | 정량 | 명목·서열·구간 속성 포함 + **절대 0 존재** | 상품 무게 20kg·40kg·60kg (등간격, 정확한 측정) |

## 요약

- 분석 유형(기술·탐색·추론·예측·인과)에 앞서 데이터가 정량인지 정성인지 파악해야 한다.
- 측정 척도는 명목(식별) → 서열(순위) → 구간(등간격, 0 비절대) → 비율(절대 0)로 정보량이 늘어난다.
