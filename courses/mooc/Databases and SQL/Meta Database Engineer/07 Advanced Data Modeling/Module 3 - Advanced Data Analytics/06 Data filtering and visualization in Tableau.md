# Data filtering and visualization in Tableau

## 개요

- Tableau의 데이터 필터링(데이터 소스 vs 워크시트)과 막대 차트 시각화 실습 — 캐나다 마케팅 캠페인용 매출 분석 사례

## 내용

### 필터 위치의 차이

- **데이터 소스 페이지 필터** — 모든 워크시트가 필터 기준에 묶임 (예: 카테고리를 사무 가구로 필터하면 다른 카테고리는 어느 워크시트에서도 분석 불가)
- **워크시트 필터** — 해당 시트에서만 적용

### 데이터 소스 페이지 필터링

- Filters의 **Add** → 대화상자에서 다시 Add → **Region** 선택 → OK → General 탭 Select from list → **Canada** 체크 → OK → 데이터 패널이 캐나다 레코드만 표시.
- 제거: **Edit Filter** → Canada 선택 → Remove → OK.

### 워크시트 필터링과 차트 만들기

- 시트 탭을 열면 소스 컬럼이 왼쪽 데이터 패널의 필드로 표시:
  - 회색 선 위 = **차원 필드(dimension)** — 범주형 데이터 (카테고리, 유형, 날짜)
  - 회색 선 아래 = **측정값 필드(measure)** — 수치 데이터 (매출, 이익, 수량)
- Category 차원을 **행 선반**에, Sales 측정값을 **열 선반**에 드래그 → 가로 막대 차트 생성.
- Region 차원을 **필터 카드**로 드래그 → General 탭에서 Canada → Apply → OK.

### 차트 다듬기

- **스왑 아이콘** — 가로 ↔ 세로 차트 전환
- **내림차순 아이콘** — 매출 최대→최소 정렬
- Sales를 Marks의 **Color**에 드래그 — 매출 기준 막대 색상
- Profit을 **Label** 마크에 드래그 — 카테고리별 이익 표시
- 시트 제목 지정 (예: "Sales in Canada")
- Sub-Category를 열 선반에 추가해 상세도 향상

### 고급 필터 기법

- **범주 필터** — Category를 필터 카드로 드래그, furniture만 남기고 technology·office supplies 해제
- **Top 필터** — Sub-Category를 필터 카드로 → Top 탭 → By field → 값 2 → 상위 2개 카테고리
- **와일드카드(wildcard)** — 텍스트 "chair" 입력 → 해당 텍스트를 포함하는 서브카테고리 반환
- **조건 필터(condition)** — Sales 필드 선택, sum > 500,000 규칙 지정 → 조건 초과 값만 반환
- 필터 제거: 우클릭 → Remove

## 요약

- 소스 페이지 필터는 전역, 워크시트 필터는 시트 한정 — 분석 유연성이 필요하면 워크시트에서 필터링한다.
- 차원(범주)·측정값(수치) 필드를 선반에 드래그해 차트를 만들고 색·라벨·정렬로 가독성을 높인다.
- 목록·Top N·와일드카드·조건 필터로 분석 대상을 정밀하게 좁힌다.
