# Module summary: Data modeling and management

## 개요

- Module 1(데이터 모델링과 관리)에서 배운 내용을 되짚는 요약 강의

## 내용

### 레슨 1 — 데이터 모델링

- 데이터 모델 = 데이터베이스 시스템 구조의 표현
- 3수준: 개념적(엔터티·관계의 추상 개요) → 논리적(속성·PK·FK 정의) → 물리적(내부 스키마 구현 상세)
- 모델 유형: 관계형, ER, 계층적, 객체지향, 차원 — 장단점 비교로 선택
- 정규화 복습: 삽입·갱신·삭제 이상과 1NF(원자성)·2NF(함수/부분 종속)·3NF(이행 종속)

### 레슨 2 — MySQL Workbench

- 통합 시각 모델링·관리 도구: 다운로드·설치, 사용자 생성, 연결 수립
- 스키마 생성·탐색, 테이블·뷰 생성과 데이터 질의
- **Forward Engineer** — 모델 다이어그램 → SQL 스키마 구현
- **Reverse Engineer** — 기존 데이터베이스 → 모델 다이어그램 (인쇄·공유·수정 후 재반영)

## 요약

- 모델 3수준·유형·정규화의 이론과 Workbench의 모델링·관리·양방향 엔지니어링 실무를 갖췄다. 다음 모듈은 데이터 웨어하우징이다.
