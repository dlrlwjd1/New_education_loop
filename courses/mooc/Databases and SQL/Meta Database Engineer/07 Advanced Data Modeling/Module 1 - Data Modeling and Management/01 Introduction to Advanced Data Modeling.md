# Introduction to Advanced Data Modeling

## 개요

- Advanced Data Modeling 강좌에서 배울 내용을 모듈별로 안내하는 오리엔테이션 강의

## 내용

### Module 1 — 데이터 모델링과 관리

- 데이터 모델 = 데이터 요소들과 그 관계의 시각적 표현, Meta의 활용
- 3수준 모델: 개념적(conceptual)·논리적(logical)·물리적(physical)
- 정규화로 이상(삽입·갱신·삭제) 제거
- **MySQL Workbench** — 모델링·관리 통합 시각 도구: 데이터 모델 다이어그램 작성, **forward engineer**(모델→스키마), **reverse engineer**(기존 데이터베이스→ER 다이어그램)

### Module 2 — 데이터 웨어하우징

- 데이터 웨어하우스 = 다중 소스의 대량 데이터를 적재·통합·저장·처리하는 **중앙 저장소**
- 4대 특성: 주제 지향(subject-oriented), 통합(integrated), 비휘발(non-volatile), 시간 가변(time-variant)
- 데이터 형태: 정형·반정형·비정형
- 아키텍처: 데이터 소스 → 스테이징 영역(ETL) → 웨어하우스 → 데이터 마트
- **차원 데이터 모델링** — 차원(dimension)과 사실(fact), 스타·스노우플레이크 스키마, 4단계(비즈니스 프로세스 → 그레인 → 차원 → 사실 → 스키마 작성)

### Module 3 — 고급 데이터 분석

- 정량(quantitative)/정성(qualitative) 데이터, 4가지 측정 척도(명목·서열·구간·비율)
- 데이터 마이닝(패턴 감지) vs 머신러닝(컴퓨터에게 학습을 가르침) — 분류·연관 규칙·클러스터링·회귀 분석 모델
- 데이터 시각화 — 청중과 정보에 맞는 차트 선택
- **Tableau** — 다운로드·탐색, 데이터 적재·준비, 필터·시각화, 인터랙티브 대시보드

### Module 4 — 모델링·분석 실전

- 총정리와 평가

## 요약

- 이 강좌는 데이터 모델 3수준과 Workbench → 데이터 웨어하우스와 차원 모델링 → 분석·시각화(Tableau) 순으로 고급 데이터 모델링을 다룬다.
