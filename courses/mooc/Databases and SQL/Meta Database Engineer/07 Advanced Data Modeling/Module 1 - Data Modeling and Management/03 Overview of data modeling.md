# Overview of data modeling

## 개요

- 데이터 모델링의 정의와 3수준 모델(개념적·논리적·물리적)의 역할 (M&G 보석상 예제)

## 내용

### 데이터 모델이란

- **데이터 요소들의 시각적 표현이자 서로의 관계를 보여주는 것** — 데이터베이스 시스템의 구조를 드러낸다.
- 이 구조는 데이터가 어떻게 저장·접근·갱신·질의되는지 이해하게 하고, 일관된 구조와 고품질 데이터를 보장한다.
- 특히 엔터티 관계형 데이터베이스는 ER 다이어그램으로 계획된다.

### 3수준 데이터 모델

1. **개념적(conceptual) 모델** — 엔터티라 부르는 **고추상 수준의 데이터 요소**로 구성. 엔터티와 그 관계의 시각적 표현으로 시스템의 고수준 개요 제공. 예: 고객·상품·주문을 엔터티로 놓고 관계를 문서화. **논리 모델의 기초**가 된다.
2. **논리적(logical) 모델** — 개념 모델을 발전시켜 더 상세한 개요 제공: **각 엔터티의 속성 식별, 기본 키 정의, 외래 키 지정.** 예: 클라이언트 테이블의 client ID가 기본 키, 주문 테이블과는 client ID 외래 키로 연결.
3. **물리적(physical) 모델** — DBMS에 구현되는 **내부 SQL 스키마**를 만든다: **데이터 타입, 제약조건, 속성**을 명세. 예: full name은 VARCHAR, contact number는 INT, 각 컬럼에 NOT NULL 제약. 내부 스키마 생성·실행 도구들은 이후 레슨에서 다룬다.

## 요약

- 데이터 모델은 시스템 구축 전에 저장·접근 구조를 계획하는 시각적 설계도다.
- 개념(엔터티·관계 개요) → 논리(속성·PK·FK) → 물리(타입·제약·스키마)의 3수준으로 구체화된다.
