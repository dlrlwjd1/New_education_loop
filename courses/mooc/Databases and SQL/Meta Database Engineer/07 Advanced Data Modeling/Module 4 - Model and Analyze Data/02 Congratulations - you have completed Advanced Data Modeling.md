# Congratulations, you have completed Advanced Data Modeling

## 개요

- 코스 수료 축하와 획득 역량 정리, 다음 단계(캡스톤·수료증) 안내

## 내용

### 획득한 역량

- MySQL Workbench로 데이터베이스 모델 설계
- 데이터 웨어하우스의 역할과 데이터 분석 프로세스 이해
- 웨어하우스에서 차원 데이터 모델 생성
- Tableau로 데이터 분석 수행, 시각화 기법으로 결과 발표

### 다음 단계

- 이후 데이터베이스 엔지니어 코스에서 역량을 계속 발전
- **최종 프로젝트**(캡스톤): 배운 모든 것을 적용해 완전히 동작하는 데이터베이스 시스템 구축 — 포트폴리오에 참조할 수 있는 운영 데이터베이스가 되어 고용주에게 역량 증명
- 전문 과정 전체 수료 시 데이터베이스 엔지니어링 수료증 취득 — 다른 역할 기반 자격으로 진행 가능

## 요약

- Workbench 모델링, 웨어하우스·차원 모델, Tableau 분석·시각화 역량을 갖추고 코스를 마쳤다. 다음은 캡스톤 프로젝트다.
