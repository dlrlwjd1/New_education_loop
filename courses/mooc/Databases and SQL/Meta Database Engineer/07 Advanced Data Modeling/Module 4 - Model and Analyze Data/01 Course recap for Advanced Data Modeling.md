# Course recap for Advanced Data Modeling

## 개요

- Advanced Data Modeling 코스 전체(모델링·웨어하우징·분석)를 되짚는 총정리 강의

## 내용

### Module 1 — 데이터 모델링과 관리

- 데이터 모델 = 데이터 요소들과 상호 관계의 시각적 표현
- 3수준: 개념적·논리적·물리적 / 유형: ER, 객체지향 등
- 정규화로 삽입·갱신·삭제 이상 해결
- MySQL Workbench: 통합 시각 모델링·관리 도구 — **Forward Engineer**(모델→스키마), **Reverse Engineer**(기존 스키마→모델, 인쇄·공유·수정 후 재반영)

### Module 2 — 데이터 웨어하우징

- 웨어하우스 = 다중 소스 대량 데이터를 집계·통합·저장·처리하는 중앙 저장소
- 4대 특성: 주제 지향, 통합, 비휘발성, 시간 변이
- 데이터 형태: 정형·반정형·비정형
- 아키텍처: 데이터 소스 → 스테이징(ETL) → 웨어하우스 → 데이터 마트 → 분석·보고
- 차원 모델링: 차원·팩트 기반, 스타/스노플레이크 스키마, 4단계(프로세스 → 그레인 → 차원 → 팩트)

### Module 3 — 고급 데이터 분석

- 정량(수치)·정성(비수치) 데이터와 4가지 측정 척도(명목·서열·구간·비율)
- 데이터 마이닝(패턴 탐지) vs 머신러닝(학습 교육) — 분류·연관 규칙·군집·회귀 등 모델 활용
- 시각화: 청중과 필요한 정보를 고려해 적절한 차트 선택
- Tableau: 다운로드·실행·탐색 → 데이터 로드·준비 → 필터·시각화 → 인터랙티브 대시보드 → 분석 실습

## 요약

- 모델링(3수준·정규화·Workbench), 웨어하우징(4대 특성·아키텍처·차원 모델), 분석(척도·마이닝/ML·시각화·Tableau)을 마쳤다. 남은 것은 종합 평가(graded assessment)다.
