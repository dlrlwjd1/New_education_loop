## 핵심 주제

- 데이터 모델 3수준(개념·논리·물리)과 유형, 정규화 복습
- MySQL Workbench: Forward/Reverse Engineering
- 데이터 웨어하우스 4대 특성과 아키텍처(소스 → ETL 스테이징 → 저장 → 데이터 마트)
- 차원 데이터 모델링: 팩트·차원, 스타/스노플레이크 스키마, 킴볼 4단계
- 데이터 분석: 측정 척도, 데이터 마이닝 vs 머신러닝, 시각화
- Tableau: 데이터 준비, 필터링, 차트, 인터랙티브 대시보드
