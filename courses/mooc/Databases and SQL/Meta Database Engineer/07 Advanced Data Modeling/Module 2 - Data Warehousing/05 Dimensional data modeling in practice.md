# Dimensional data modeling in practice

## 개요

- 킴볼(Kimball)의 4단계 차원 모델링 접근법: 비즈니스 프로세스 → 그레인 → 차원 → 팩트 선택 (Global Superstore 매출 분석 사례)

## 내용

### 4단계 접근법

- 차원 모델은 특정 문제를 다루기 위해 비즈니스의 특정 측면에 집중해야 한다.
- 각 단계는 모두 **선택(choice)** 이다: 조사할 프로세스를 고르고, 답을 줄 팩트와 차원을 고른다.

### 1단계 — 비즈니스 프로세스 선택

- 모델이 다룰 구체적인 비즈니스 프로세스를 식별한다. 예: Global Superstore는 **판매 활동(sales activity)** 을 선택.

### 2단계 — 그레인(grain) 결정

- 필요한 **상세 수준(granularity)** 과 문제 해결에 필요한 **최저 상세 수준**을 정한다.
- 예: 매출을 연도·일 단위 모두에서, 그리고 글로벌·로컬 수준 모두에서 분석해야 함.

### 3단계 — 차원 선택

- 어떤 맥락에서 비즈니스 활동을 탐색할지 결정. 예: 상품, 고객, 시간, 위치.

### 4단계 — 팩트 확정

- "무엇을 측정할 것인가"에 답한다 — 수치 데이터를 담은 측정값을 골라 팩트 테이블을 채운다.
- 각 차원이 매출에 어떤 영향을 주는지 보여주고, 차원마다 유용한 정보를 주는 속성을 포함한다.

### 스키마 작성

- 4가지 선택이 끝나면 스키마를 만든다. Global Superstore는 **스타 스키마**로 customers·products·locations·time 4개 차원의 맥락에서 판매 성과를 검토하고, 각 차원에 필요한 데이터를 겨냥한 속성 집합을 둔다.

## 요약

- 킴볼 4단계: ① 비즈니스 프로세스 ② 그레인 ③ 차원 ④ 팩트 — 모두 비즈니스 요구 기반의 선택이다.
- 선택이 끝나면 스타 스키마 등으로 차원·측정값을 배치해 분석을 수행한다.
