# Overview of data warehousing

## 개요

- 데이터 웨어하우스(data warehouse)의 정의, 4대 특성, 데이터 유형(정형·반정형·비정형) 소개 (Global Superstore 매출 하락 분석 사례)

## 내용

### 데이터 웨어하우스란

- 여러 소스(온라인 거래, 소셜 미디어, 웹사이트 데이터 등)의 대량 데이터를 **집계·저장·처리하는 중앙 저장소**
- 분석 워크로드를 일반 트랜잭션 워크로드에서 분리
- **OLAP**(Online Analytical Processing) — 분석용 질의 처리
- 일반 데이터베이스는 실시간 수집·저장·처리 중심의 **OLTP**(Online Transactional Processing)

### 4대 특성

| 특성 | 의미 |
| --- | --- |
| **주제 지향(subject-oriented)** | 탐구할 주제 영역을 선택해 구축 (예: 매출 — 최고/최저 판매 상품 분석) |
| **통합(integrated)** | 여러 소스 데이터를 일관된 형식으로 통합, 명명 충돌·데이터 타입 문제 해소 |
| **비휘발성(non-volatile)** | 적재된 데이터는 삭제하지 않음 — 데이터가 많을수록 분석 결과가 좋아짐 |
| **시간 변이(time-variant)** | 장기간 데이터를 집계해 시간에 따른 변화·추세·패턴·관계 발견 |

### 데이터 유형

- **정형(structured)** — 잘 정의된 데이터 모델(주로 관계형) 안의 구조화된 데이터. SQL로 접근·관리·검색. 웨어하우스가 주로 사용하며 인사이트 도출이 쉬움
- **반정형(semi-structured)** — 부분적으로만 구조화. 예: 이메일(발신자·제목은 정형, 본문은 텍스트·이미지·영상 혼합)
- **비정형(unstructured)** — 사전 정의 모델이 없는 데이터(텍스트·비디오·오디오). 분석에는 머신러닝·데이터 마이닝 같은 고급 기법 필요
- 반정형·비정형 데이터는 **데이터 레이크(data lake)** 에 더 적합 — 데이터 과학자가 주로 사용. 기업은 정확성 때문에 정형 데이터 + 웨어하우스를 선호

## 요약

- 웨어하우스는 다중 소스 데이터를 집계·분석하는 OLAP 중앙 저장소로, OLTP 데이터베이스와 역할이 다르다.
- 주제 지향·통합·비휘발성·시간 변이가 4대 특성이다.
- 정형 데이터는 웨어하우스, 반정형·비정형은 데이터 레이크가 담당한다.
