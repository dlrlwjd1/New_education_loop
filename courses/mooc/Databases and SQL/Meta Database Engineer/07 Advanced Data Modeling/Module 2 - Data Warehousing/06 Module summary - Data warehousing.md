# Module summary: Data warehousing

## 개요

- Module 2(데이터 웨어하우징)에서 배운 내용을 되짚는 요약 강의

## 내용

### 데이터 웨어하우스 기초

- 여러 소스의 대량 데이터를 집계·저장·처리하는 중앙 저장소 — 사용자는 질의로 분석 수행
- 4대 특성: **주제 지향**(선택한 주제 정보 제공), **통합**(다양한 소스의 데이터 통합), **비휘발성**(적재 상태 그대로 유지), **시간 변이**(장기간 집계로 변화 측정)
- 데이터 유형: **정형**(접근·관리·검색 쉬움), **반정형**(유연하지만 분석에 노력 필요), **비정형**(모델 없음, 분석이 가장 어려움)

### 아키텍처

- 데이터 흐름: **데이터 소스** → **스테이징 영역**(ETL로 분석 준비) → **웨어하우스 저장** → **데이터 마트**(특정 사용자용 주제 지향 데이터베이스) → 분석·발표
- 모범 사례 준수와 개발 **문서화**(새 기능 통합 대비)가 중요
- 실무 사례 연구(Meta ETL)와 퀴즈로 확인

### 차원 데이터 모델링

- **팩트** = 정량화 가능한 측정값, **차원** = 측정값을 탐색하는 맥락
- 저장 측정값(집계 저장) vs 계산 측정값(다른 측정값에서 계산)
- 차원 테이블의 **계층 구조**로 드릴다운/롤업 분석
- 설계 스키마: **스타 스키마**, **스노플레이크 스키마**
- 구축 4단계: ① 비즈니스 프로세스 식별 ② 그레인 선택 ③ 차원 선택 ④ 팩트 테이블 측정값 결정

## 요약

- 웨어하우스의 정의·4대 특성·데이터 유형·아키텍처와 차원 모델링(팩트·차원·스키마·킴볼 4단계)을 정리했다. 다음 모듈은 고급 데이터 분석이다.
