# Module summary

## 개요

- Module 3(클라이언트와 시각화)에서 수행한 Tableau 분석과 Python 데이터베이스 클라이언트 작업을 되짚는 요약 강의

## 내용

### Tableau 데이터 분석

- 다양한 소스 연결, 대량·다형식 데이터 처리, 시각화 차트, 실시간 인터랙티브 대시보드, Python·R 스크립팅, 인터랙티브 UI
- Connect 패널로 소스 연결 → 저작 워크스페이스에서 워크시트·대시보드·스토리로 시각화 → Marks 카드·행/열 선반 활용
- 데이터 준비: 분할, 계산 필드, 타입 수정, 필터링
- 드릴다운·롤업·필터로 다양한 관점·상세 수준 분석
- 잘 조직된 대시보드로 비즈니스 질문에 명확한 답 제공

### Python 데이터베이스 클라이언트

- 명령 프롬프트에서 Python 버전 확인 — Python 3 최신 여부 점검
- Jupyter IDE 설치 → `jupyter notebook`으로 브라우저에서 실행
- **MySQL Connector** 라이브러리를 pip로 설치, 임포트 성공 확인
- Python으로 Little Lemon 데이터베이스 질의 함수 구현 실습 후 Git 커밋

## 요약

- Tableau로 인사이트 생성(연결 → 준비 → 시각화 → 대시보드), Python/Jupyter/MySQL Connector로 데이터베이스 클라이언트를 구축하고 Git으로 관리했다.
