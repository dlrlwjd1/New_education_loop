# Data analytics and visualization

## 개요

- Little Lemon 비즈니스 인사이트 생성을 위한 Tableau 핵심 기능·워크플로 복습

## 내용

### Tableau 핵심 기능

- 광범위한 데이터 소스 연결, 대량·다양한 데이터 타입 처리, 시각화 차트 생성
- 인터랙티브 실시간 대시보드, Python·R 스크립팅, 인터랙티브 UI 도구

### 작업 흐름

1. **연결** — 시작 페이지 Connect 패널로 데이터 소스 연결 → 관련 필드가 데이터 패널에 표시
2. **저작 워크스페이스** — 워크시트·대시보드·스토리로 시각화. Marks 카드로 뷰에 데이터 추가, 행/열 선반으로 분석·시각화. 툴바의 명령·도구, 정렬 아이콘(오름/내림차순), 대시보드 뷰에서 다중 소스 작업, 스토리로 발표
3. **데이터 준비** — 분할(접근성 향상), 계산 필드 생성, 데이터 타입 수정, 필터링
4. **필터링** — 필요한 데이터에만 집중, 드릴다운·롤업으로 다양한 관점·상세 수준 표시
   - 워크시트 또는 데이터 소스 페이지에서 필터 가능 — 단, 소스 페이지 필터는 모든 워크시트가 그 기준에 묶임
5. **대시보드** — 여러 소스 데이터 결합, 필터·드릴다운·롤업 추가 — 잘 조직된 대시보드가 비즈니스 질문에 명확한 답을 제공

## 요약

- Tableau로 소스 연결 → 데이터 준비 → 워크시트 분석 → 인터랙티브 대시보드 발표의 흐름을 수행한다.
- 소스 페이지 필터는 전역 제약이 되므로 유연한 분석에는 워크시트 필터를 쓴다.
