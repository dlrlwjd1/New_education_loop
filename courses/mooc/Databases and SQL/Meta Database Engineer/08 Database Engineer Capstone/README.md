# Database Engineer Capstone

Meta Database Engineer 전문 과정의 8번째 강좌. Little Lemon 레스토랑의 완전한 데이터베이스 시스템을 구축하는 캡스톤 프로젝트 — ER 모델링·Workbench 구현·Git, 보고서 질의, 예약 시스템, Tableau 분석, Python 클라이언트를 다룬다.

- 강좌 링크: <https://www.mooc.org/learn/database-engineer-capstone>

## 핵심 주제

- 3대 정규형 준수 ER 다이어그램 설계와 MySQL Workbench 구현, Git/GitHub 버전 관리
- 판매 보고서: 가상 테이블(뷰), JOIN, 저장 프로시저, 프리페어드 스테이트먼트
- 테이블 예약 시스템: CRUD 트랜잭션과 트리거
- Tableau 데이터 분석·인터랙티브 대시보드
- Python 데이터베이스 클라이언트: Jupyter + MySQL Connector
