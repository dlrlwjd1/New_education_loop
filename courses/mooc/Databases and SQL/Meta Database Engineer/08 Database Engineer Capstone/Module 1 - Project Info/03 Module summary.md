# Module summary

## 개요

- Module 1(프로젝트 정보)에서 수행한 프로젝트 설정 작업을 되짚는 요약 강의

## 내용

### 수행한 3단계

1. MySQL Server 인스턴스로 Workbench에 데이터베이스 설정
2. ER 다이어그램 생성·Workbench에서 구현
3. 프로젝트 커밋

### 핵심 복습

- **ER 모델** — 3대 정규형을 준수해 설계 → 무결성 확보, 삽입·갱신·삭제 이상 방지
- **MySQL Workbench** — 오픈소스·크로스 플랫폼·시각적 SQL 에디터, 모델을 물리 스키마로 변환. dev.mysql.com/downloads에서 MySQL Server·Workbench·Shell 설치
- **Git** — 무료 오픈소스 분산 버전 관리: 이력 관리, 커밋 이력, 이전 버전 복원, 협업 (git-scm.com/downloads)
- **GitHub** — Git 소스 관리 + 프로젝트 관리·지원 티켓·버그 추적, 저장소 공유·보관·백업

## 요약

- 정규형 준수 ER 설계 → Workbench 구현 → Git/GitHub 커밋으로 프로젝트 기반을 마련했다. 다음은 모듈 퀴즈와 추가 자료다.
