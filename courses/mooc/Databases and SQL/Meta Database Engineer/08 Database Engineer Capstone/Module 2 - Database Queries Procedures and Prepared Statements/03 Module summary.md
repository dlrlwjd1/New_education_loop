# Module summary

## 개요

- Module 2(질의·프로시저·프리페어드 스테이트먼트)에서 수행한 판매 보고서·예약 시스템 작업을 되짚는 요약 강의

## 내용

### 판매 보고서 작성

- **가상 테이블** — 다른 테이블의 데이터 활용: 접근·질의 단순화, 가상+베이스 테이블 조인, 효율적 조작·필터링, 보안 지원
- **JOIN** — 공통 컬럼 기반 레코드 연결: inner, left, right, self, full outer
- **저장 프로시저** — 재사용 코드: 일관성·유지보수성 향상, 다중 매개변수, SQL 문·변수·제어 구조 포함 가능, 고유 이름 필수
- **프리페어드 스테이트먼트** — 1회 컴파일·파싱 후 반복 사용, MySQL 자원 절약

### 테이블 예약 시스템

- **INSERT INTO** — 테이블·컬럼·값을 명시해 새 예약 생성
- **UPDATE / DELETE** — 예약 변경·취소 (핵심 정보 명시)
- **SELECT** — 실행 성공 여부 테스트 (테이블·컬럼·값·조건 명시)
- **트리거** — CREATE TRIGGER → 유형(INSERT/UPDATE/DELETE, 전/후) → 로직·대상 테이블·적용 방식 정의
- 완료 후 Git 커밋으로 버전 관리

## 요약

- 뷰·조인·프로시저·프리페어드 스테이트먼트로 판매 보고서를, CRUD와 트리거로 예약 시스템을 완성하고 Git으로 관리했다.
