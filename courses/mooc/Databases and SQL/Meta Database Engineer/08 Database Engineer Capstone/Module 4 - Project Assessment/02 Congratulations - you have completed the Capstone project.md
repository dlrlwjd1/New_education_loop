# Congratulations, you have completed the Capstone project!

## 개요

- 캡스톤 수료 축하 — 전문 과정 전체에서 쌓은 역량 정리와 수료증·포트폴리오 활용 안내

## 내용

### 프로그램 전체에서 쌓은 역량

- 데이터베이스 엔지니어링 기초와 MySQL 문법
- 데이터베이스 구조·관리의 탄탄한 기반과 고급 MySQL
- Python 기초
- 고급 데이터 모델링 기법 이해·구현
- 최종 코스에서 데이터베이스 프로젝트 설계로 역량 입증 — Little Lemon의 완전히 동작하는 데이터베이스 시스템 구축 실습

### 회고 포인트

- 이 코스와 이전 코스들의 연결, 프로젝트 수행 과정
- 가장 어려웠던/쉬웠던 부분, 얻은 경험, 이전 코스 복습 필요 여부

### 수료증과 포트폴리오

- 완성된 운영 데이터베이스는 포트폴리오 자료 — 고용주에게 자기주도성·혁신성과 지식 증명
- 전문 과정 수료로 데이터베이스 엔지니어링 수료증 취득 — 다른 역할 기반 자격으로 진행하거나 심화/기초 과정 선택 가능
- 자격증은 기술 숙달의 글로벌 공인·업계 인증 증거

## 요약

- Meta Database Engineer 전문 과정을 완주했다 — MySQL·구조·고급 모델링·Python·캡스톤 프로젝트로 역량을 입증했고, 수료증과 포트폴리오용 데이터베이스를 얻었다.
