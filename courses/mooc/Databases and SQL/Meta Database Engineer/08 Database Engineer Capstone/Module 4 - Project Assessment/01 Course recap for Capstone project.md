# Course recap for Capstone project

## 개요

- 캡스톤에서 완료한 Little Lemon 과제 전체를 되짚는 총정리 강의 — 이후 동료 평가(peer review)와 종합 평가 진행

## 내용

### 완료한 과제

1. **데이터베이스 구축** — 3대 정규형을 준수하는 ER 모델을 Workbench로 설계, 모델을 MySQL 서버의 물리 스키마로 변환, Git 커밋·GitHub 보관
2. **판매 보고서** — 가상 테이블(데이터 접근 단순화), JOIN(공통 컬럼 기반 연결), 저장 프로시저(재사용 코드), 프리페어드 스테이트먼트(1회 컴파일 후 반복 사용)
3. **테이블 예약 시스템** — INSERT INTO(생성), UPDATE(변경), DELETE(삭제), SELECT(조회) + 트리거(이벤트 시 자동 호출되는 저장 프로그램), 완료 후 Git 커밋
4. **비즈니스 인사이트** — Tableau: 소스 연결 → 데이터 준비 → UI 요소로 시각화 → 인터랙티브 실시간 대시보드
5. **데이터베이스 클라이언트** — Python 버전 확인 → Jupyter IDE 설치 → 노트북에서 MySQL Connector(pip)로 데이터베이스 연결

### 다음 단계

- 동료 평가 프로젝트와 종합 평가(graded assessment)로 지식 검증

## 요약

- 모델링·구현·버전 관리, 보고서 질의, 예약 시스템 트랜잭션, Tableau 분석, Python 클라이언트까지 데이터베이스 엔지니어링 전 과정을 실습했다. 남은 것은 동료 평가다.
