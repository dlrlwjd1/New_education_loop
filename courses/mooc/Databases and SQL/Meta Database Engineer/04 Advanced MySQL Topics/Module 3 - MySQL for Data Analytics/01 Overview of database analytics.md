# Overview of database analytics

## 개요

- 데이터 분석(data analysis)과 데이터 분석학(data analytics)의 관계, 데이터 분석의 5가지 유형

## 내용

### 데이터 분석학이란

- 데이터 분석을 한 단계 더 발전시켜 **수집한 데이터를 유용하고 의미 있는 정보로 변환·가공**하는 것.
- 그 정보로 **미래 사건에 대한 예측**을 하고 의사결정을 뒷받침한다. 특수 도구를 사용한다.
- 활용 예(Lucky Shrub): 어떤 제품이 잘 팔려 재고를 유지해야 하는지, 어떤 특가가 고객을 끄는지, 온라인 판매를 어떻게 관리할지 예측.
- 전제: 분석학 이전에 **데이터 분석과 SQL 쿼리**로 데이터를 수집·분석해 통찰을 만들어야 한다.

### 데이터 분석의 5가지 유형

1. **기술적(descriptive) 분석** — "무슨 일이 있었는가"를 서술. 예: 특정 기간의 판매를 베스트셀러·수익으로 설명.
2. **탐색적(exploratory) 분석** — 변수들 사이의 **관계 성립 여부** 탐색. 예: 특정 제품 판매 증가와 계절(홀리데이 시즌 트리 판매)의 상관.
3. **추론적(inferential) 분석** — **작은 표본으로 더 큰 모집단에 대해 추론**·일반 결론 도출. 예: 여름철 바비큐 용품 판매 증가 → 그 시기가 최적 판매기라고 추론.
4. **예측적(predictive) 분석** — 기존(레거시) 데이터에서 패턴을 찾아 **미래 성과 예측**. 예: 할인 시 원예 도구 판매 증가 → 추가 할인이 판매를 늘릴 것으로 예측.
5. **인과적(causal) 분석** — 변수 간 **원인-결과 관계** 탐구. 예: 원예 도구 구매 고객이 야외 조명도 사는 관계의 원인 규명.

### 용어 주의

- 실무에서 data analysis와 data analytics는 **혼용**되지만 별개 개념이며, 분석 없이 분석학은 성립하지 않는다.

## 요약

- 데이터 분석학은 분석으로 모은 데이터를 미래 예측용 정보로 바꾸는 과정이다.
- 분석 유형은 기술적·탐색적·추론적·예측적·인과적 5가지로, 각각 서술·관계·일반화·예측·인과를 다룬다.
