# Module summary: MySQL for data analytics

## 개요

- Module 3(데이터 분석용 MySQL)에서 배운 내용을 되짚는 요약 강의

## 내용

### 레슨 1 — 데이터 분석 도구로서의 MySQL 평가

- 데이터 분석학 = 수집한 데이터를 의미 있는 정보로 변환해 미래 예측에 활용
- 분석 유형 5가지: 기술적(서술), 탐색적(변수 간 관계), 추론적(모집단 추론), 예측적(패턴→예측), 인과적(원인-결과)
- MySQL의 이점: 무료 오픈소스, 관계형 대용량 저장, 광범위한 채택, 분석 도구 제공 / 한계: 전문 도구 대비 분석력·시각화 부재

### 레슨 2 — MySQL에서 데이터 분석 수행

- SQL 쿼리로 데이터 추출 → 결과 서술 → 분석학으로 추가 통찰
- **FULL OUTER JOIN 에뮬레이션**: MySQL 미지원이므로 LEFT+RIGHT JOIN에 UNION ALL(중복 포함)/UNION(유일)을 결합
- 함수·연산자·서브쿼리·뷰 등 다양한 쿼리 도구 활용

## 요약

- 분석 유형과 MySQL의 장단점을 평가하고, 조인(FULL JOIN 에뮬레이션 포함)·서브쿼리·뷰로 실전 데이터 분석을 수행할 수 있다.
