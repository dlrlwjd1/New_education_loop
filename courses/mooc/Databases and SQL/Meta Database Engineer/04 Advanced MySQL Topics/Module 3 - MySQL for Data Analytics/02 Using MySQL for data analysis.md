# Using MySQL for data analysis

## 개요

- 데이터 분석 도구로서 MySQL의 강점 3가지와 한계 2가지

## 내용

### MySQL의 강점

1. **관계형 모델** — 관련 테이블 구조 덕분에 관련 정보의 접근·검색·분석이 쉽다. 외래 키로 테이블을 연결해 한 테이블로 다른 테이블의 정보를 찾는다 (예: orders와 products가 product ID로 연결되어 고객별 주문 상품 파악).
2. **무료 오픈소스** — 비용·지식재산권 부담 없이 데이터베이스를 관리할 수 있어 사업 비용을 줄인다.
3. **광범위한 사용** — 수많은 기업·정부·조직이 MySQL로 데이터를 수집·저장·처리하므로 조직 간 데이터 소통과 분석 개선이 쉽다 (예: 공급업체도 MySQL을 쓰면 products 테이블 데이터로 재고 현황을 바로 공유).

### MySQL의 한계

1. **분석 능력의 제한** — 고급 데이터 분석 도구 대비 복잡한 분석 수행 능력이 제한적이며, AI 기반 분석 같은 기능이 없다.
2. **데이터 시각화 부재** — 막대 차트·그래프·지도 같은 시각화 기능이 없다. 시각화는 테이블 형태보다 정보를 훨씬 효과적으로 전달하고 트렌드·이슈 포착에 유리하다.

## 요약

- MySQL은 관계형 구조, 무료 오픈소스, 광범위한 채택이라는 강점으로 데이터 분석의 기반이 된다.
- 다만 고급 분석·시각화는 전문 분석 도구 대비 제한적이다.
