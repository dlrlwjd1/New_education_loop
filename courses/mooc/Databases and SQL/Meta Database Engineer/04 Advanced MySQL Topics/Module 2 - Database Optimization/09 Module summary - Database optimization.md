# Module summary: Database optimization

## 개요

- Module 2(데이터베이스 최적화)에서 배운 내용을 되짚는 요약 강의

## 내용

### 레슨 1 — 쿼리 최적화와 인덱스

- 최적화 = 쿼리 실행 시 성능·속도·효율의 최대화. 대상은 데이터 검색(SELECT) 문과 데이터 변경 문.
- SELECT 최적화 기법: 필요한 컬럼만 지정, 서술어 함수 회피, 선행 와일드카드 회피, INNER JOIN 우선, DISTINCT·UNION 최소화
- 인덱스: 정렬 데이터로 이어지는 포인터. 기본(클러스터드)·2차(비클러스터드) 인덱스, CREATE INDEX + 커스텀 이름 + ON 테이블(컬럼) 구문

### 레슨 2 — 추가 최적화 기법

- **트랜잭션**: START TRANSACTION(BEGIN/BEGIN WORK)·COMMIT·ROLLBACK으로 쿼리 관리, 실패 시 시작점으로 복원
- **CTE**: WITH 절로 복잡한 쿼리를 명명된 블록으로 컴파일, UNION으로 다중 CTE 실행
- **준비된 문**: 컴파일·파싱 횟수 절감
- **JSON 데이터 타입**: 데이터베이스와의 효율적 상호작용

## 요약

- SELECT 최적화 원칙, 인덱스, 트랜잭션, CTE, 준비된 문, JSON까지 문장이 빠르게 컴파일·파싱·실행되도록 하는 폭넓은 최적화 기법을 갖췄다.
