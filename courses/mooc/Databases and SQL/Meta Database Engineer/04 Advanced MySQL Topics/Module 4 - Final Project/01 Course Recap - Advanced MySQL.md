# Course Recap: Advanced MySQL

## 개요

- Advanced MySQL Topics 강좌 전체(3개 학습 모듈)를 되짚는 총정리 강의

## 내용

### Module 1 — 함수와 트리거

- 함수·기본/복합 저장 프로시저로 코드 블록 재사용
- 변수·매개변수(IN/OUT/INOUT)로 복잡한 함수·프로시저 구성, 사용자 정의 함수 개발
- 트리거(INSERT/UPDATE/DELETE 유형, CREATE TRIGGER + BEGIN...END)와 예약 이벤트로 작업 자동화

### Module 2 — 데이터베이스 최적화

- 최적화 개념과 SELECT 문 최적화(필요 컬럼 지정, 복잡한 함수 회피 등), 인덱스로 검색 성능 향상
- 트랜잭션 문으로 트랜잭션 관리, CTE로 복잡한 쿼리 블록화, 준비된 문으로 컴파일 절감, JSON 데이터 타입 활용

### Module 3 — 데이터 분석용 MySQL

- 데이터 분석학과 MySQL의 관계, 분석 유형, 분석 도구로서의 장단점
- 조인·서브쿼리·뷰를 이용한 분석, FULL OUTER JOIN 에뮬레이션, 다중 테이블 JOIN 추출

## 요약

- 함수·프로시저·트리거·이벤트 → 최적화(인덱스·트랜잭션·CTE·준비된 문·JSON) → 데이터 분석까지 고급 MySQL 역량을 복습했으며, 다음은 채점 평가다.
