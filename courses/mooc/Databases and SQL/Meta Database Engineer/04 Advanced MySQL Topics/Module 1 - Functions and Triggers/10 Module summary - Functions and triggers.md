# Module summary: Functions and triggers

## 개요

- Module 1(함수와 트리거)에서 배운 내용을 되짚는 요약 강의

## 내용

### 레슨 1 — 강좌 소개

- Meta의 고급 데이터베이스 엔지니어 역할과 강좌 주제 개관

### 레슨 2 — 고급 함수와 저장 프로시저

- 함수·프로시저의 목적은 코드의 캡슐화 — 일관성·조직화·재사용성 확보
- 핵심 차이: 함수는 입력 매개변수만, 프로시저는 입력·출력 모두 가능
- **변수** — SQL 문 간, 프로시저-SQL 문 간 값 전달. 프로시저·SELECT 안팎 어디서든 생성 가능
- **매개변수** — 외부에서 값을 전달. 프로시저에는 IN·OUT·INOUT 3종
- **사용자 정의 함수** — 내장 함수가 부족할 때 직접 코드 작성 → 특정 기능 수행 → 결과 반환

### 레슨 3 — 트리거와 이벤트

- 트리거 = 특정 이벤트(삽입·갱신·삭제) 발생 시 자동 호출되는 저장 프로그램
- 행 수준·문장 수준 트리거 구분, CREATE/DROP TRIGGER 문법, BEGIN...END 로직
- 예약 이벤트(scheduled event)의 문법과 생성 절차

## 요약

- 함수·프로시저(변수·매개변수·사용자 정의 포함)와 트리거·예약 이벤트로 MySQL 자동화·재사용 도구를 갖췄다. 다음 모듈은 데이터베이스 최적화다.
