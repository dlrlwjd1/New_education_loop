# Advantages of SQL

## 개요

- 개발자들이 데이터베이스와의 상호작용에 SQL을 선택하는 이유 — SQL의 6가지 장점

## 내용

### SQL의 장점

1. **적은 코딩 기술로 사용 가능** — 키워드의 집합일 뿐이라 기본 CRUD 연산에 많은 코드가 필요 없다. 개발자/사용자 친화적 언어.
2. **상호작용성(interactivity)** — 짧은 시간 안에 복잡한 쿼리를 작성할 수 있다. 어떤 키워드를 언제 쓰는지만 알면 된다.
3. **표준 언어** — MySQL 등 모든 관계형 데이터베이스에서 쓸 수 있고, 그만큼 지원과 정보가 풍부하다. 데이터베이스 소프트웨어만 설치돼 있으면 어떤 컴퓨터에서든 실행된다.
4. **이식성(portability)** — 한 번 작성한 코드는 어떤 하드웨어·운영체제·플랫폼에서도 사용 가능. 데스크톱에서 작성한 SQL을 프로덕션 서버로 옮겨도 동일하게 동작한다.
5. **포괄성(comprehensive)** — 데이터베이스 관리·운영의 전 영역을 커버: 데이터베이스 생성, 데이터 삽입·갱신·삭제, 다중 사용자 간 데이터 검색·공유, 보안 관리. 이는 DDL·DML·DQL·DCL 하위 언어들로 가능해진다.
6. **효율성** — 대량의 데이터를 빠르고 효율적으로 처리할 수 있다.

## 요약

- SQL은 관계형 데이터베이스와 사용자를 잇는 인터페이스(다리)다.
- 간단하고(simple), 표준이며(standard), 이식 가능하고(portable), 포괄적이며(comprehensive), 효율적(efficient)이라는 장점 때문에 널리 쓰인다.
