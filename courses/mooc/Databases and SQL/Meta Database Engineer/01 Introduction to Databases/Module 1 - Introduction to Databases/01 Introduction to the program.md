# Introduction to the program

## 개요

- Meta Database Engineer 전문 자격증(Professional Certificate) 전체 프로그램을 소개하는 오리엔테이션 강의
- 기술 배경이 없어도 1년 안에 취업 준비를 마칠 수 있도록 설계된 자기 주도(self-paced) 과정

## 내용

### 프로그램이 제공하는 것

- 데이터베이스 엔지니어링 직무에 필요한 실무 역량(job-ready skills)과 Meta 발급 자격 증명(credential)
- Meta 엔지니어들이 고성능 데이터베이스를 협업으로 만들고 테스트하는 방식 학습
- 다른 데이터베이스 엔지니어 지망생들과의 토론, 코딩 실습 문제 풀이

### 학습 내용 로드맵

- 모범 사례(best practice)에 따른 데이터베이스 **모델링과 구조화**
- **SQL**로 데이터 생성·관리·조작 — 데이터베이스 작업에 가장 널리 쓰이는 언어
- **Django 웹 프레임워크**로 웹 애플리케이션 프론트엔드를 데이터베이스에 연결
- **Git·GitHub 버전 관리**로 다른 개발자와 협업하는 방법
- 최종 프로젝트: 모범 사례 아키텍처로 설계·개발한 **동작하는 관계형 데이터베이스**를 만들어 구직용 포트폴리오로 활용
- 마지막 강좌에서 **코딩 인터뷰 준비**: 면접 연습, 이력서 다듬기, 기술 면접 단골 코딩 과제 풀이

### 수강 방식

- 각 강좌가 이전 강좌 위에 쌓이므로 **순서대로 수강**해야 한다.
- 권장 일정은 있지만 전적으로 자기 주도형이다.
- 수료 후에는 Meta 자격증 프로그램 출신 인재 채용을 약속한 **200개 이상 고용주**와 연결되는 Meta career programs job board 접근 권한을 얻는다.

## 요약

- Meta Database Engineer 자격증은 데이터베이스 모델링, SQL, Django 연동, Git/GitHub, 캡스톤 프로젝트, 코딩 인터뷰 준비로 이어지는 순차 과정이다.
- 무경험자도 1년 내 취업 준비 완료를 목표로 하며, 수료 시 Meta 채용 파트너 잡보드에 접근할 수 있다.
