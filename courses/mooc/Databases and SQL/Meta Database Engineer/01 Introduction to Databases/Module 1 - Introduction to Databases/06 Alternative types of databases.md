# Alternative types of databases

## 개요

- 인터넷 성장으로 비정형 데이터가 폭증하면서 데이터베이스가 어떻게 진화했는지
- NoSQL 데이터베이스, 빅데이터(big data), 클라우드 데이터베이스, 비즈니스 인텔리전스(BI) 트렌드

## 내용

### NoSQL 데이터베이스

- 관계형 데이터베이스는 주로 **정형(structured) 데이터**를 저장하기에, 늘어나는 **비정형(unstructured) 데이터** 저장에는 한계가 있다.
- **NoSQL 데이터베이스**는 다양한 형식으로 데이터를 저장하는 유형으로, **유연한 구조**를 제공한다 — 복잡한 데이터 모델 없이 구조 자체를 바꿀 수 있어 **확장(scaling)이 쉽다**.
- 소셜 미디어, IoT, 인공지능처럼 방대한 비정형 데이터를 만드는 애플리케이션이 사용한다.
- 종류: **문서(document) 데이터베이스, 키-값(key-value) 데이터베이스, 그래프(graph) 데이터베이스**

### 빅데이터(Big Data)

- **시간이 지날수록 기하급수적으로 늘어날 수 있는 복잡한 데이터**.
- 출처: 소셜 미디어·온라인 쇼핑 등은 전 세계 수십억 사용자의 행동을 매초 기록하고, IoT 기기 증가로 데이터는 더 늘어난다.
- 성격: **정형 + 반정형(semi-structured) + 비정형** 데이터의 조합. 전통적 데이터베이스는 테이블·레코드·관계로 정형 데이터만 다뤘기에 빅데이터는 새로운 도전이다.
- 가치: 정형 데이터만으로 다룰 수 없는 **복잡한 비즈니스 문제**를 해결하고, 의사결정을 개선하는 고유한 통찰을 제공한다.

**산업별 활용 예:**

- **제조**: 기계 상태 평가로 장비 고장 예측, 생산 라인 모니터링으로 공정 평가, 고객 피드백에 선제 대응, 현재 판매를 관찰해 미래 수요 예측
- **소매(retail)**: 고객 수요 예측, 고객 경험 개선, 행동·소비 패턴 분석, 가격 개선 기회 식별
- **통신(telecommunications)**: 네트워크 사용 분석으로 인프라 투자 계획, 수요에 맞는 신규 서비스 설계, 서비스 품질 데이터로 고객 만족 예측·이탈 방지 계획

### 클라우드 데이터베이스

- 물리 서버 인프라의 유지보수·저장 비용 부담에서 벗어나기 위해 조직들이 클라우드로 이동한다.
- 예: Dropbox, iCloud 같은 클라우드 스토리지 서비스 — 문서·데이터를 클라우드에 훨씬 저렴하게 저장.

### 비즈니스 인텔리전스(BI)

- 전통적으로 데이터베이스는 저장 수단이었지만, 이제 조직은 BI 기술·전략으로 **데이터를 분석해 가치 있는 정보를 추출**하고 정보에 기반한 의사결정을 내린다.

## 요약

- 비정형 데이터의 폭증으로 유연한 구조의 NoSQL(문서·키-값·그래프)이 부상했다.
- 빅데이터는 정형·반정형·비정형이 섞인 지수적으로 증가하는 데이터로, 제조·소매·통신 등에서 예측과 의사결정에 활용된다.
- 인프라 부담을 줄이는 클라우드 데이터베이스와, 데이터에서 통찰을 뽑는 BI가 주요 트렌드다.
