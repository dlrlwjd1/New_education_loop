# Module summary: Introduction to Databases

## 개요

- Module 1(데이터베이스 입문)에서 배운 내용을 되짚는 요약 강의
- 세 개의 레슨: 데이터베이스와 데이터 기초 → SQL 입문 → 기본 데이터베이스 구조

## 내용

### 레슨 1 — 데이터베이스와 데이터

- 데이터베이스가 무엇인지 개념 수준에서 설명하고, 실세계 사용 예를 제시하며, 데이터가 어떻게 조직되는지 설명할 수 있다.
- 관련 데이터(related data)의 중요성과 그 사례를 식별할 수 있다.
- 데이터베이스 응용의 새 트렌드(빅데이터·클라우드 등)와 데이터베이스의 진화, 다양한 데이터베이스 유형을 개괄할 수 있다.

### 레슨 2 — SQL 입문

- SQL의 목적과 데이터베이스에서의 역할을 설명할 수 있다.
- SQL의 장점 — 낮은 진입 장벽, 넓은 활용 범위, 운영체제 간 이식성 — 과 이것이 데이터베이스 작업에 어떻게 도움 되는지 설명할 수 있다.
- DDL·DML·DQL 구문의 쓰임을 개괄하고 주요 SQL 명령어를 식별할 수 있다.

### 레슨 3 — 기본 데이터베이스 구조

- 테이블의 개념과 용도를 설명할 수 있다.
- 테이블의 핵심 구성요소 — 컬럼, 행, 데이터 타입, 키 — 를 식별할 수 있다.

## 요약

- 이 모듈로 데이터베이스의 저장 방식, SQL을 통한 상호작용 방법, 기본 구조를 갖췄다 — 데이터베이스 여정의 출발점 완료.
