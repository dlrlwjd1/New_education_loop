# Introduction to databases

## 개요

- 데이터베이스가 무엇인지, 실세계에서 어떻게 쓰이는지 소개하는 강좌 첫 개념 강의
- 이 강좌(Introduction to Databases)에서 배울 내용과 학습 방법 안내

## 내용

### 데이터베이스란

- 가장 단순한 정의: **데이터를 담아두는 전자적 저장소(electronic storage)**.
- 실제 영향력은 그 이상 — 산업·정부·조직 전반의 핵심 기술이다.

### 실세계 사용 사례

- **은행**: 고객, 계좌, 거래 데이터 저장
- **병원**: 환자, 직원, 검사(laboratory) 데이터
- **온라인 상점**: 프로필, 쇼핑 이력, 회계 거래
- 온라인 서비스·소셜 미디어는 위치, 체류 시간, 친구 관계 등 다양한 데이터를 추가로 수집하며, 방대한 사용자와 상시 활동으로 **엄청난 양의 데이터**를 생성한다.
- IoT(Internet of Things)로 연결 기기가 늘면서 지속적 데이터 스트림이 생겼고, 이 **빅데이터(big data)**의 양(volume)·다양성(variety)·복잡성을 감당하기 위해 데이터베이스 기술의 혁명이 일어났다.

### 데이터베이스가 수행하는 기본 동작 (데이터베이스 엔지니어의 필수 지식)

1. 데이터 **저장(store)**
2. 분할된 데이터 영역 간 **연결/관계(relationship) 형성**
3. 관련 레코드만 보여주는 **필터링(filter)**
4. 일치하는 레코드를 반환하는 **검색(search)**
5. 데이터의 **갱신·변경·삭제** 기능

### 이 강좌에서 배우는 것

- 데이터와 데이터베이스의 개념, 데이터가 데이터베이스 안에서 관계 맺는 방식
- 다양한 데이터베이스 구조와 용도
- CRUD(create, read, update, delete) 연산 수행
- SQL 연산자로 데이터 정렬·필터링
- 정규화(normalization)의 개념과 방법
- 완전히 동작하는 데이터베이스 구축, 로컬·원격 학습을 위한 **XAMPP** 설치·설정

### 학습 방법 안내

- 영상을 보고, 멈추고, 되감아 반복 시청하며 확신이 들 때까지 익힌다.
- 읽기 자료로 지식을 다지고, 실습으로 적용하며, 지식 퀴즈로 자가 점검한다.
- 토론 프롬프트로 동료 수강생과 교류한다.
- 자기 주도형이지만 **정기적·규율 있는 학습 일정**(날짜·시간을 정한 출석 개념)을 권장한다.

## 요약

- 데이터베이스는 데이터를 저장하고 관계를 형성하며 필터·검색·갱신·삭제를 지원하는 전자 저장소다.
- 은행·병원·온라인 상점 등 어디에나 쓰이며, 빅데이터와 IoT가 기술 혁신을 이끌었다.
- 이 강좌는 데이터베이스 개념부터 CRUD, SQL 연산자, 정규화, XAMPP 기반 실습까지 다루는 입문 과정이다.
