# Module summary: SQL operators and sorting and filtering data

## 개요

- Module 3(SQL 연산자·정렬·필터링)에서 배운 내용을 되짚는 요약 강의

## 내용

### 이 모듈에서 익힌 능력

- **산술 연산자**를 테이블에 적용해 계산을 수행할 수 있다.
- **비교 연산자**를 데이터베이스에서 사용할 수 있다.
- **ORDER BY 절**의 목적을 설명하고, 단일·다중 컬럼 기준의 오름차순/내림차순 정렬을 시연할 수 있다.
- **WHERE 절**의 목적을 설명하고, 비교 연산자와 함께 데이터를 필터링할 수 있다.
- **SELECT DISTINCT**로 중복 값을 제거하는 방법과 단일·다중 컬럼, NULL 값에 대한 동작을 설명할 수 있다.

### 의미

- 데이터를 저장하는 것보다 그 데이터를 이해하는 것이 더 가치 있다 — SQL 조작 능력이 있으면 데이터베이스는 단순한 저장소가 아니라 **조사하고 결론을 끌어낼 수 있는 대상**이 된다.

## 요약

- 산술·비교 연산자, ORDER BY 정렬, WHERE 필터링, SELECT DISTINCT 중복 제거까지 데이터에 실제 가치를 부여하는 기본 조작을 갖췄다.
