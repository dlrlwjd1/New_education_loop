# SQL Arithmetic Operators

## 개요

- SQL 연산자(operator)의 개념과 산술 연산자(arithmetic operator) 5종의 사용법
- SELECT 문으로 산술 연산을 수행하는 기본 패턴

## 내용

### 연산자란

- **데이터베이스에서 다양한 작업을 수행하게 해 주는 특정 단어나 문자**. 문장의 접속사, 계산기의 연산 키에 비유된다.
- 데이터 질의·조작에 필요하다 — 예: 직원의 남은 휴가 일수 계산(산술), 직원이 회사 목표를 달성했는지 비교(비교).

### 산술 연산자 5종

| 연산자 | 기호 | 의미 |
|---|---|---|
| 덧셈 | `+` | 더하기 |
| 뺄셈 | `-` | 빼기 |
| 곱셈 | `*` | 곱하기 |
| 나눗셈 | `/` | 나누기 |
| 모듈러스 | `%` | 나눗셈의 **나머지** 반환 |

### 동작 방식

- 연산자는 **두 개의 피연산자(operand)**를 받아 결과를 반환한다.
- SQL에서는 `SELECT 피연산자 연산자 피연산자;` 형태로 수행한다.
- 5를 양쪽 피연산자로: `5+5=10`, `5-5=0`, `5*5=25`, `5/5=1`, `5%5=0`(나머지 없음)

## 예시

```sql
SELECT 10 + 15;   -- 25
SELECT 100 % 10;  -- 0 (100 ÷ 10 = 10, 나머지 0)
```

- 세미콜론은 이 경우 선택 사항이지만 문장의 끝을 나타내기 위해 붙이는 것이 좋다.

## 요약

- 연산자는 데이터 조작을 가능하게 하는 SQL의 기본 도구다.
- 산술 연산자는 +, -, *, /, %(나머지) 5종이며 두 피연산자를 받아 결과를 반환한다.
- `SELECT 식;` 패턴으로 산술 결과를 바로 확인할 수 있다.
