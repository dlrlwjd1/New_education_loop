# Operators in use

## 개요

- 산술 연산자를 실제 테이블 데이터(직원 급여)에 적용하는 실습 강의
- 컬럼 값에 연산자를 결합한 SELECT 질의 패턴

## 내용

### 시나리오 — employee 테이블 (ID, 이름, 연봉)

1. **보너스 시뮬레이션(+)**: 전 직원에게 $500 보너스를 주면 급여가 어떻게 되는지 — SELECT가 각 직원의 salary를 가져와 500을 더해 보여준다.
2. **공제(−)**: 각 직원 급여에서 $500 차감한 결과 조회.
3. **연봉 2배(*)**: 각 직원의 현재 연봉을 두 배로 늘린 결과 조회.
4. **월급 계산(/)**: 연봉을 12개월로 나눠 월 급여 산출.
5. **짝수/홀수 판별(%)**: 각 직원 ID를 2로 나눈 나머지를 구한다 — **나머지 0이면 짝수 ID**(짝수는 2로 나눠떨어지므로). 결과: 홀수 ID 3개, 짝수 ID 2개.

## 예시

```sql
-- 1. $500 보너스 반영 급여
SELECT salary + 500 FROM employee;

-- 2. $500 공제
SELECT salary - 500 FROM employee;

-- 3. 연봉 2배
SELECT salary * 2 FROM employee;

-- 4. 월급 (연봉 ÷ 12)
SELECT salary / 12 FROM employee;

-- 5. ID 짝홀 판별 (0 = 짝수)
SELECT ID % 2 FROM employee;
```

## 요약

- 산술 연산자는 컬럼 값에 직접 적용해 `SELECT 컬럼 연산자 값 FROM 테이블` 형태로 쓴다.
- 급여 인상/공제(+·−), 배수 계산(*), 월급 환산(/), 짝홀 판별(%)처럼 실무 계산을 질의 안에서 바로 수행할 수 있다.
