# CREATE and DROP database

## 개요

- SQL로 데이터베이스를 생성(CREATE DATABASE)하고 제거(DROP DATABASE)하는 방법
- 데이터베이스 이름 규칙과 생성 전 목적 정의의 중요성

## 내용

### 생성 전에 — 목적을 명확히

- 데이터베이스를 만들기 전에 **용도를 분명히** 해야 한다.
- 예: 온라인 서점 데이터베이스라면 책 제목, 저자, 고객, 판매 데이터를 기록해야 하고, 이 주제들의 데이터가 적절한 테이블에 저장·조직되어야 사용자가 접근·검색·갱신할 수 있다.

### CREATE DATABASE

- 구문: `CREATE DATABASE 데이터베이스명;`
- 이름 규칙:
  - **의미 있고 관련성 있는 이름**을 쓴다 — 작업 문서화가 쉬워진다.
  - 이름은 **유일**해야 하며 **최대 63자**까지 가능하다. 요건을 어기면 에러 메시지가 나타난다.
- 문장 끝에 세미콜론을 붙이고 실행하면 사이드바에 새 데이터베이스가 나타난다.

### DROP DATABASE

- 구문: `DROP DATABASE 데이터베이스명;`
- SQL 탭에서 쿼리를 입력하고 실행하면 해당 데이터베이스가 삭제된다.

## 예시

```sql
-- 서점 데이터베이스 생성
CREATE DATABASE bookstore2_db;

-- 기존 데이터베이스 삭제
DROP DATABASE bookstore_db;
```

## 요약

- `CREATE DATABASE 이름;`으로 생성, `DROP DATABASE 이름;`으로 삭제한다.
- 이름은 의미 있게, 유일하게, 63자 이내로 짓는다.
- 생성 전에 데이터베이스의 목적과 저장할 데이터 주제를 먼저 정의한다.
