# Module summary: Create, Read, Update and Delete (CRUD) Operations

## 개요

- Module 2(CRUD 연산)에서 배운 내용을 되짚는 요약 강의
- 세 개의 레슨: SQL 데이터 타입 → 데이터 생성·읽기 → 데이터 갱신·삭제

## 내용

### 레슨 1 — SQL 데이터 타입

- **숫자 타입**: 데이터를 숫자로 저장하고, 크기·부호가 다른 값을 위해 정수(integer)와 소수(decimal)를 구분해 사용할 수 있다.
- **문자열 타입**: 사용법을 시연하고 CHAR와 VARCHAR의 핵심 차이를 설명할 수 있다.
- **기본값(default values)**: 제약조건(constraint) 개념과 DEFAULT 제약으로 기본값을 설정하는 법을 이해했다.
- 실습으로 데이터에 맞는 올바른 타입 선택 능력을 확인했다.

### 레슨 2 — 데이터 생성과 읽기

- 데이터베이스 생성, 테이블 생성(CREATE TABLE), 테이블 구조 변경(ALTER TABLE), 데이터베이스 삭제(DROP)를 수행할 수 있다.
- INSERT 문으로 데이터 삽입, SELECT 문으로 데이터 검색, INSERT INTO SELECT로 원본→대상 테이블 데이터 이전이 가능하다.

### 레슨 3 — 데이터 갱신과 삭제

- UPDATE 문으로 한 레코드 또는 여러 레코드의 단일·다중 필드 값을 갱신할 수 있다.
- DELETE 실습으로 테이블 레코드 삭제 능력을 확인했다.

## 요약

- 이 모듈로 CRUD 연산 전체(생성·읽기·갱신·삭제)와 SQL 데이터 타입 활용 능력을 갖췄다.
