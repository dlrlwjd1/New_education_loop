# Numeric data types

## 개요

- 데이터 타입의 역할 — 각 필드가 받아들일 데이터 종류를 결정해 올바른 형식을 유지
- 숫자(numeric) 데이터 타입의 두 대표: 정수(integer)와 소수(decimal)

## 내용

### 데이터 타입이란

- 테이블을 만들 때 컬럼 이름과 함께 **그 컬럼에 담길 내용의 데이터 타입을 정의**해야 한다.
- 데이터 타입은 MySQL 같은 DBMS에 **컬럼 값을 어떻게 해석할지** 알려주고, 데이터를 올바른 형식으로 유지해 각 컬럼 값이 기대대로 되도록 보장한다.
- 가장 많이 쓰는 타입: **숫자(numeric), 문자열(string), 날짜·시간(date and time)**
- 온라인 상점 예: 고객명 컬럼 = 문자열, 주문일 = 날짜, 상품 수량·총액 = 숫자 타입.

### 숫자 데이터 타입

- 컬럼이 데이터를 **숫자로 저장**하게 하는 모든 구체적 타입의 총칭.
- 대표 2종:
  - **정수(integer)** — 정수 값 저장. 소수를 넣으면 데이터베이스가 가장 가까운 정수로 자동 반올림/내림한다. 예: 상품 수량 컬럼.
  - **소수(decimal)** — 분수 값을 가진 수 저장. 예: 총액 컬럼($80.90 — 80은 정수부, 90은 소수부). 정수를 넣으면 소수점과 0인 소수부가 자동으로 붙는다.

### 크기별 타입 구분

- 대부분의 DBMS는 최소·최대 저장 값에 따라 여러 정수·소수 타입을 제공한다.
- MySQL 예:
  - **TINYINT** — 아주 작은 정수용, 최대 255
  - **INT** — 큰 수용, 최대 40억 이상
- 두 타입 모두 음수·양수를 받을 수 있고, 일부 DBMS에서는 컬럼을 **양수 전용**으로 강제해 저장 가능한 최대값을 늘릴 수 있다.

## 예시

```sql
CREATE TABLE customer_order (
  customer_name  VARCHAR(100),   -- 문자열
  order_date     DATE,           -- 날짜
  product_qty    INT,            -- 정수 (수량)
  total_price    DECIMAL(10, 2)  -- 소수 (금액)
);
```

## 요약

- 데이터 타입은 DBMS가 컬럼 값을 해석하는 방법이자 형식 보증 장치다.
- 정수 타입은 정수만(소수는 반올림), 소수 타입은 분수 값을 저장한다.
- TINYINT(최대 255)와 INT(40억+)처럼 저장 범위별 타입이 있고, 양수 전용 설정으로 범위를 넓힐 수 있다.
