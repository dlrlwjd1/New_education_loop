# Introduction to Databases

Meta Database Engineer 전문 자격증의 첫 번째 강좌. 데이터베이스·데이터 개념부터 SQL 기초(CRUD), 연산자·정렬·필터링, 스키마·관계·정규화(1NF~3NF)까지 다룬다.

- 강좌: https://www.mooc.org/learn/introduction-to-databases
- 구성: 학습 모듈 4개 + 평가 모듈 1개, 강의 영상 46개
- 노트: 강의별 Transcript 기반 한국어 정리 (형식: 개요/내용/예시/요약, 기술 용어 영어 병기)
- 제외: 읽기 자료·퀴즈·채점 평가 (학업 정직성 정책)

## 모듈 구성

### Module 1 - Introduction to Databases (13강)

프로그램·강좌 소개, 데이터베이스 엔지니어의 일상, 데이터베이스 개념, 데이터 관계, NoSQL·빅데이터·클라우드 트렌드, SQL의 역할·하위 언어(DDL/DML/DQL/DCL)·장점·기본 문법, 테이블 구조, 키의 종류.

### Module 2 - Create, Read, Update and Delete (CRUD) Operations (12강)

숫자·문자열 데이터 타입, NOT NULL·DEFAULT 제약, CREATE/DROP DATABASE, CREATE/ALTER TABLE, INSERT, SELECT, INSERT INTO SELECT, UPDATE, DELETE.

### Module 3 - SQL Operators and sorting and filtering data (7강)

산술 연산자(+, -, *, /, %)와 실전 적용, 비교 연산자, ORDER BY 정렬, WHERE 필터링(BETWEEN·LIKE·IN), SELECT DISTINCT.

### Module 4 - Database design (12강)

스키마 개념과 시스템별 차이, 스키마 구축 실습, 논리적/물리적 스키마, 테이블 관계(1:1/1:N/M:N), 기본 키·외래 키, 엔터티와 속성 유형, 정규화 개념(이상 3종)과 1NF·2NF·3NF.

### Module 5 - Graded assessment (2강)

강좌 총정리(Course Recap)와 수료 축하·다음 단계 안내. 채점 평가는 정리 제외.
