# Congratulations, you have completed Introduction to databases

## 개요

- Meta Database Engineer 전문과정의 첫 강좌 수료를 축하하며, 획득한 역량과 다음 단계를 안내하는 마무리 강의

## 내용

### 이 강좌로 갖춘 역량 (채점 평가에서 측정하는 핵심 능력)

- 다양한 데이터베이스 스키마에 대한 지식 시연
- 관계형 데이터베이스 설계와 테이블 정규화 설명
- CRUD(생성·읽기·갱신·삭제) 데이터베이스 연산 수행
- 정렬·필터링 SQL 명령 시연
- 프로젝트 랩에서 데이터베이스를 생성·질의하며 실무 능력을 증명

### 다음 단계

- 이 강좌는 전문과정의 첫 코스 — 이어서 2번째 강좌 수강을 권장한다.
- 마지막 랩에서는 배운 것을 총동원해 **완전히 동작하는 데이터베이스 시스템**을 직접 만든다.
  - 이 결과물은 **포트폴리오에 넣을 수 있는 운영 가능한 데이터베이스**가 되어 잠재 고용주에게 기술과 자기주도성을 보여준다.
- 전 과정을 수료하면 Meta Database Engineering 인증을 받으며, 이는 다른 Meta 역할 기반(role-based) 인증으로 진행하는 발판이 된다.
- Meta 인증은 전 세계적으로 인정되고 업계가 보증하는 기술 역량의 증거다.

## 요약

- 첫 강좌 수료로 스키마·설계·정규화·CRUD·정렬/필터링 역량을 갖췄다.
- 전문과정을 이어가면 포트폴리오용 실전 데이터베이스와 Meta 인증을 얻게 된다.
