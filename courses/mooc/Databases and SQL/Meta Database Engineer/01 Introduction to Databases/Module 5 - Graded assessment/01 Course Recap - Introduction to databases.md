# Course Recap: Introduction to databases

## 개요

- Introduction to Databases 강좌 전체(4개 학습 모듈)를 되짚는 총정리 강의

## 내용

### Module 1 — 데이터베이스 입문

- 강좌 소개와 데이터베이스 엔지니어 커리어, 수강 성공 팁
- SQL(데이터베이스와 상호작용하는 코딩 문법) 입문
- 데이터베이스의 기본 구조와 키의 종류

### Module 2 — 데이터 타입과 CRUD 연산

- 숫자 데이터·문자열 데이터·기본값(default values) 구분과 활용 실습
- CRUD(create, read, update, delete): 데이터베이스·테이블 생성과 데이터 삽입, 갱신·삭제

### Module 3 — SQL 연산자와 정렬·필터링

- 산술·비교 연산자의 구문과 적용 절차
- ORDER BY(정렬), WHERE(필터링), SELECT DISTINCT(중복 제거) 절의 사용법과 데모·실습

### Module 4 — 데이터베이스 설계

- 스키마 개념과 스키마 유형
- 키(기본·2차·후보·외래)로 테이블 간 관계 설정하는 관계형 설계
- 정규화의 핵심 개념과 1NF·2NF·3NF

## 요약

- 데이터베이스 개념 → SQL 기초와 CRUD → 연산자·정렬·필터링 → 스키마·관계·정규화 순으로 데이터베이스 엔지니어링의 기초를 완주했으며, 다음은 채점 평가(graded assessment)다.
