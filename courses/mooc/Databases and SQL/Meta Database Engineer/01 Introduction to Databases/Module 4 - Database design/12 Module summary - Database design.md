# Module summary: Database design

## 개요

- Module 4(데이터베이스 설계)에서 배운 내용을 되짚는 요약 강의
- 세 개의 레슨: 스키마 설계 → 관계형 데이터베이스 설계 → 정규화

## 내용

### 레슨 1 — 데이터베이스 스키마 설계

- 올바르게 설계된 데이터베이스가 이후 모든 저장·분석의 기반이다. 잘못 설계되면 정확한 정보 산출이 어렵거나 불가능하다.
- 스키마 정의, 시스템별 스키마 차이, SQL로 기본 스키마 생성, 스키마의 두 유형(논리적·물리적)을 다룰 수 있다.

### 레슨 2 — 관계형 데이터베이스 설계

- 관계형 모델 설명, 관계 유형(1:1, 1:N, M:N) 나열, ERD 평가가 가능하다.
- 기본 키의 목적 설명, 단일/복합 기본 키 선택, 외래 키의 목적과 테이블 연결, 엔터티의 의미 요약을 할 수 있다.
- 속성 유형 나열, 엔터티·속성 식별, 엔터티 간 링크 생성이 가능하다.

### 레슨 3 — 정규화

- 정규화 = 큰 테이블을 여러 테이블로 나눠 중복을 줄이는 프로세스.
- 삽입·갱신·삭제 이상 인식, 원자성(atomicity)·반복 그룹 문제 설명이 가능하다.
- 1NF·2NF·3NF 설계와 함수·부분·이행 종속 개념을 설명할 수 있다.

## 요약

- 이 모듈로 스키마, 관계·키·엔터티, 1~3NF 정규화까지 정규화된 관계형 데이터베이스 구조를 만들 수 있는 설계 역량을 갖췄다.
