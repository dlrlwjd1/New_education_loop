# Cursors and MySQL

## 개요

- 커서(cursor) — 쿼리 결과의 위치를 가리키는 포인터 — 의 3가지 특성과 선언→열기→가져오기→닫기 4단계

## 내용

### 커서란

- **SQL 쿼리 결과가 MySQL 데이터베이스 안 어디에 있는지 Python 클라이언트에 알려주는 포인터.** 특정 행(레코드)을 식별해 위치를 가리키며, 결과 안의 개별 레코드를 읽고·가져오고·이동할 수 있다.

### 3가지 핵심 특성

1. **읽기 전용(read-only)** — 커서가 연결된 데이터를 갱신할 수 없다. 결과는 보존된다.
2. **비스크롤(non-scrollable)** — 레코드를 **순서대로만** 가져온다. 건너뛰기·역순 불가 — 개별 레코드 처리 시 위치 추적에 유리.
3. **asensitive** — 복사본이 아니라 **원본 데이터를 가리킨다** — 복사본만 가리키는 insensitive 커서보다 빠르다.

### 커서 사용 4단계 (SQL 문법)

1. **선언**: `DECLARE 커서이름 CURSOR FOR SELECT ...` — 커서의 목적을 SELECT로 정의
2. **열기**: `OPEN 커서이름` — 결과 집합 확보
3. **가져오기**: `FETCH 커서이름 INTO 대상` — 결과를 지역 변수 등으로 이전 (Python 앱에서 사용)
4. **닫기**: `CLOSE 커서이름` — **메모리 해제를 위한 좋은 습관.** 비스크롤이라 마지막 결과에 도달하면 더 열어 둘 이유가 없다.

### 활용 예 (Little Lemon)

- guest_booking_details 커서 선언 → 손님 데이터를 겨냥한 SELECT → OPEN → FETCH로 Python 클라이언트의 booking_data 변수에 저장.

## 요약

- 커서는 쿼리 결과를 가리키는 포인터로, 읽기 전용·순차 접근·원본 참조(asensitive)의 특성을 가진다.
- DECLARE → OPEN → FETCH INTO → CLOSE 순서로 쓰고, 닫아서 메모리를 해제한다.
