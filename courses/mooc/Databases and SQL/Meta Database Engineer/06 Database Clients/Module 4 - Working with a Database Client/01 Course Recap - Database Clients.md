# Course Recap: Database Clients

## 개요

- Database Clients 강좌 전체(3개 학습 모듈)를 되짚는 총정리 강의

## 내용

### Module 1 — Python으로 MySQL 상호작용

- MySQL Connector/Python API와 pip, 클라이언트 설치와 연결
- CRUD를 위한 통신 수립, 커서 객체 접근, 데이터베이스·테이블 생성, 커밋
- 커서 특성(읽기 전용·비스크롤·asensitive), 커서 클래스와 서브클래스, 인터리빙 요청

### Module 2 — Python으로 CRUD와 고급 쿼리

- 레코드 생성·읽기, 갱신·삭제와 커밋
- 필터링·정렬 기법의 Python 적용, 다양한 JOIN으로 다중 테이블 결합

### Module 3 — 고급 데이터베이스 클라이언트

- MySQL 함수의 중요성·유형과 Python 접근, datetime 함수 활용
- 저장 프로시저(함수와의 차이, callproc, 구분자)
- 연결 풀링 개념·이점과 연결 풀 구현 절차

## 요약

- 연결·커서 → CRUD·고급 쿼리 → 함수·프로시저·연결 풀 순으로 Python 데이터베이스 클라이언트 개발의 전 과정을 복습했으며, 다음은 채점 평가다.
