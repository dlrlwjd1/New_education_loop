# Database connection pooling

## 개요

- 연결 풀링(connection pooling) — 연결의 풀을 만들어 관리함으로써 빠르고 효율적인 클라이언트-데이터베이스 연결을 제공하는 기법

## 내용

### 왜 필요한가

- 데이터베이스는 다수 사용자에게 동시에 **안전하고 안정적인 연결**을 제공해야 하는데, 연결 관리에는 자원이 많이 드는 동작들이 필요하다 — 이를 효율화하는 답이 연결 풀링이다.

### 동작 원리 (시각적 예)

- 4개의 열린 연결로 이뤄진 풀: 2개는 사용 중, 2개는 대기.
- 새 사용자가 오면 풀이 **열린 연결 하나를 배정**한다.
- 사용을 마친 사용자가 떠나도 **연결은 닫히지 않고 풀로 반환**되어 다음 사용자를 위해 대기한다.
- 4개가 모두 사용 중일 때 5번째 사용자가 오면? → **연결 수를 지정한 풀을 여러 개** 만들어 사용자를 분산 배정하고, 다른 풀에도 가용 연결이 없으면 **풀 안에 새 연결을 생성하도록 프로그래밍**할 수 있다.

### 이점

1. 가용 자원의 효율적 사용
2. 연결 수립에 드는 시간·노력 절감
3. 프로그래밍 모델 단순화
4. MySQL 연결 시 Python 애플리케이션의 성능 향상

## 요약

- 연결 풀링은 연결을 닫지 않고 풀로 재사용해 연결 비용을 없애는 관리 기법이다.
- 풀이 가득 차는 상황은 다중 풀 구성과 동적 연결 생성으로 대비한다.
- 자원 효율·속도·단순성·성능이 핵심 이점이다.
