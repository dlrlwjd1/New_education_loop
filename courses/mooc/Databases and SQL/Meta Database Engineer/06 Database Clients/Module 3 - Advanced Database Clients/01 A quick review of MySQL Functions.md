# A quick review of MySQL Functions

## 개요

- MySQL 함수의 5개 범주(문자열·숫자·날짜/시간·비교·제어 흐름) 복습과 Python에서의 기본 활용

## 내용

### 함수 복습

- **특정 연산을 수행하고 결과를 반환하는 코드 조각** — 지시들의 집합을 결합해 출력 산출.
- 이점: 일부는 매개변수를 받고, 데이터 조작에 탁월하며, 여러 작업을 묶은 **커스텀 함수**를 만들어 데이터베이스에 저장·호출할 수 있고, 재사용 가능하다.

### 5개 범주 (Little Lemon 활용 예)

1. **문자열 함수** — 문자열 결합·부분 추출. 예: **CONCAT**으로 두 테이블 데이터를 한 문자열로 — 고객별 지출 정보 추출.
2. **숫자 함수** — 집계·수학 함수. 예: **AVG**로 고객별 평균 지출액 산출.
3. **날짜·시간 함수** — 다양한 형식의 일시 값 추출. 예: 손님 체류 시간, 가장 붐비는 요일 분석.
4. **비교 함수** — 숫자·문자열·문자 값 비교. 예: **GREATEST·LEAST**로 최고/최저 판매 메뉴 식별.
5. **제어 흐름 함수** — 조건 평가로 실행 경로 결정. 예: **CASE**로 메뉴별 손익 판정.

### Python에서의 사용

- 함수가 든 SELECT 쿼리를 Python 문자열로 만들어 실행하는 방식은 동일 — 예: AVG 함수 쿼리를 데이터베이스에 전달·실행 후 결과 접근.

## 예시

```python
avg_query = """SELECT AVG(bill_amount) FROM orders;"""
cursor.execute(avg_query)
print(cursor.fetchall())
```

## 요약

- MySQL 함수는 문자열·숫자·날짜/시간·비교·제어 흐름의 5범주로 재사용 가능한 연산 블록이다.
- Python에서는 함수가 포함된 쿼리를 문자열로 작성해 같은 execute 흐름으로 사용한다.
