# Normal Forms and Normalization Process

## 개요
- 비정규형에서 1NF, 2NF, 3NF로 단계적으로 릴레이션을 분해하는 절차를 다룬다.

## 내용

### 1NF
- 비정규형은 한 셀에 여러 값이나 반복 그룹을 허용한다.
- 1NF에서는 행과 열의 교차점마다 원자값 하나만 존재해야 한다. 반복 값은 별도 행이나 적절한 릴레이션으로 분리한다.

### 2NF
- 1NF이면서 모든 비키 속성이 기본키 전체에 완전 함수 종속돼야 한다.
- 복합키 일부에만 종속되는 속성은 결정자와 함께 새 릴레이션으로 옮긴다. 결정자는 새 릴레이션의 기본키이자 원래 릴레이션과 연결하는 외래키가 된다.

### 3NF
- 2NF이면서 비키 속성이 기본키에 이행 종속되지 않아야 한다.
- `기본키 → 비키 결정자 → 다른 비키 속성` 구조에서 뒤쪽 종속을 새 릴레이션으로 옮긴다.
- 분해 과정에서 새로 생긴 모든 릴레이션도 각각 정규형 조건을 다시 확인한다.

## 예시
```text
R(A,B,C,D,E,F,G), PK=(A,B,C)
A -> D, (B,C) -> E, F -> G

2NF: R(A,B,C,F,G), R1(A,D), R2(B,C,E)
3NF: R(A,B,C,F), R1(A,D), R2(B,C,E), R3(F,G)
```

## 요약
- 1NF는 원자값, 2NF는 부분 종속 제거, 3NF는 이행 종속 제거가 핵심이다.
- 문제 종속성을 삭제하는 데서 끝내지 않고 별도 릴레이션으로 보존해 조인 가능한 구조를 만든다.
