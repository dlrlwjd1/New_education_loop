# Full, Partial, and Transitive Functional Dependencies

## 개요
- 2NF와 3NF 판단에 필요한 완전·부분·이행 함수 종속성을 구분한다.

## 내용

### 완전 함수 종속과 부분 함수 종속
- `A → B`에서 A의 어떤 진부분집합도 B를 결정하지 못하면 B는 A에 완전 함수 종속된다.
- A의 일부만으로도 B를 결정할 수 있다면 부분 함수 종속이다. 결정자에 불필요한 속성이 포함된 셈이다.
- 결정자가 단일 속성이면 더 작은 비어 있지 않은 부분집합이 없으므로 일반적으로 완전 함수 종속이다.

### 이행 함수 종속
- `A → B`이고 `B → C`이면 B를 거쳐 `A → C`가 성립한다. 비키 속성이 다른 비키 속성을 결정하는 이 구조가 3NF에서 제거할 대상이다.

## 예시
```text
R(A, B, C, D, E, F, G), PK=(A,B,C)
(A,B,C) -> D,E,F,G
A -> D
(B,C) -> E
F -> G
```
- `D`와 `E`는 복합키 일부에 의해 결정되므로 부분 종속이다.
- `(B,C) → E` 자체는 B나 C만으로 E를 결정하지 못한다면 완전 종속이다.
- `(A,B,C) → F → G`는 G의 이행 종속이다.

## 요약
- 복합 결정자의 일부가 결과를 결정하면 부분 종속, 중간 속성을 거쳐 결정되면 이행 종속이다.
- 2NF는 부분 종속을, 3NF는 이행 종속을 제거한다.
