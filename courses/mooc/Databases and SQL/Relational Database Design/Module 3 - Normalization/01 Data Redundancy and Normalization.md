# Data Redundancy and Normalization

## 개요
- 중복 데이터가 만드는 이상 현상을 이해하고 정규화가 필요한 이유를 설명한다.

## 내용

### 중복과 이상 현상
- 같은 사실을 여러 행에 저장하면 값이 서로 달라질 수 있고 저장 공간과 유지보수 비용이 늘어난다.
- 삽입 이상은 다른 사실이 없어 새 사실을 넣지 못하는 문제, 갱신 이상은 같은 사실을 여러 곳에서 고쳐야 하는 문제, 삭제 이상은 한 행을 지우며 필요한 사실까지 사라지는 문제다.

### 정규화의 목표
- 정규화는 큰 릴레이션을 의미 있는 작은 릴레이션으로 분해해 중복과 이상 현상을 줄이는 과정이다.
- 분해 후에도 원래 정보를 조인으로 복원할 수 있어야 하며, 속성 간 의미는 함수 종속성으로 분석한다.

## 예시
```text
Enrollment(StudentID, StudentName, CourseID, CourseName)
```
- 학생 이름과 강좌 이름이 수강 건마다 반복된다. `Student`, `Course`, `Enrollment`로 분리하면 각 사실을 한 곳에서 관리할 수 있다.

## 요약
- 데이터 중복은 삽입·갱신·삭제 이상을 만든다.
- 정규화는 함수 종속성을 근거로 릴레이션을 손실 없이 분해해 데이터 일관성을 높인다.
