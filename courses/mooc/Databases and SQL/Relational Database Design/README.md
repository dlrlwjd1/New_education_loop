# Relational Database Design

MOOC의 Di Wu 강좌로, DBMS와 ER 모델의 기초부터 관계형 모델 변환, 함수 종속성과 3NF 정규화, PetsCare 사례연구까지 이어진다.

- 강좌: https://www.mooc.org/learn/relational-database-design
- 구성: 4개 모듈, 학습 노트 24개
- 제외: 채점 퀴즈·과제, 잠금된 해답지

## 모듈

1. **Introduction to DBMS, and Entity Relational Models** — 데이터 관리, 엔티티·속성·관계, Crow's Foot ERD
2. **Relational Models** — 릴레이션·키·스키마와 ERD 변환
3. **Normalization** — 함수 종속성, 1NF·2NF·3NF와 분해
4. **Case Study** — PetsCare 요구사항에서 구현 가능한 3NF 스키마까지

## 학습 흐름

```text
업무 요구사항 -> ER 모델/ERD -> 관계형 모델 -> 함수 종속성 분석 -> 3NF -> 구현 명세
```
