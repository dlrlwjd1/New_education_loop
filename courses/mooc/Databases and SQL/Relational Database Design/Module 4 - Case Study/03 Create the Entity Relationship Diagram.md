# Create the Entity Relationship Diagram

## 개요
- PetsCare의 엔티티, 속성, 식별자와 관계를 ERD로 표현한다.

## 내용

### 엔티티와 식별자
- `Customers`는 `CustomerID`, `Staff`는 `EmployeeID`, `Visit`는 `VisitID`를 식별자로 사용한다.
- `Pets`는 `CustomerID + Pet#`을 복합 식별자로 사용한다.
- 고객에는 연락·결제·가입 정보, 직원에는 신원·연락 정보, 방문에는 일시·서비스·담당자·청구·결제 정보를 둔다.

### 관계
- 고객 1명은 0개 이상의 반려동물을 가질 수 있고 반려동물은 정확히 고객 1명에게 속한다.
- 직원과 반려동물은 선택적 N:M 관계다.
- 고객은 여러 방문을 가질 수 있고 각 방문은 고객 1명에게 속한다. 방문에는 반려동물 0~1마리가 관련될 수 있다.
- 방문은 직원 1명이 담당하고, 고객 추천과 직원 감독은 각각 자기참조 관계다.

## 예시
```text
Customers 1 ----- 0..* Pets
Staff     0..* -- 0..* Pets
Customers 1 ----- 0..* Visit
Staff     1 ----- 1..* Visit
```

## 요약
- ERD에는 엔티티와 속성뿐 아니라 식별자, 선택성, 최소·최대 카디널리티를 함께 표시한다.
- 고객 추천과 직원 감독처럼 동일 엔티티 사이의 관계는 역할명을 분명히 한다.
