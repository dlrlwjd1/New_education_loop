# Course Overview (강좌 개요)

> 강좌: Relational Database Design (MOOC, 강사 Di Wu) · 모듈 1: Introduction to DBMS and Entity Relational Models

## 개요
- 관계형 데이터베이스 시스템(relational database system)을 설계하는 데 필요한 도구를 준비하는 강좌 1.

## 내용
- 배우게 될 핵심 개념: **엔티티(entities), 관계(relationships), 릴레이션(relations), 키(keys), 함수 종속(functional dependencies), 정규화(normalization)**.
- 이 도구들로 "어떤 데이터를 연결할지"라는 아이디어를 **구현 가능한 관계형 DB**로 표현할 수 있게 된다.

### 학습 목표
- 엔티티와 그들 간의 관계를 이해·설명한다.
- **개체-관계 다이어그램(Entity Relationship Diagram, ERD)**을 그린다.
- 릴레이션과 그 속성을 이해·설명한다.
- ERD를 **관계형 모델(relational model)**로 변환한다.
- 정규형(normal forms)을 이해·설명하고, 비정규 관계형 모델을 **제3정규형(3NF)**까지 정규화한다.

### 강좌 구성 (4개 모듈)
1. **개체-관계 모델(ER Models)** — 순수 개념 모델(conceptual model).
2. **관계형 모델(Relational Models)** — 개념 모델에서 구현 가능한 모델로 가는 중간 단계.
3. **정규화(Normalization)** — 데이터 중복(data redundancy)과 그로 인한 문제를 제거해 유지·추가·삭제·갱신을 쉽게 하는 과정.
4. **사례 연구(Case Study)** — 고객 요청(아이디어) → 개념 모델 → 관계형 모델 → 3NF 구현 가능 모델까지의 전 과정.

## 예시
- 온라인 교육 회사의 요구사항을 엔티티·관계로 정리하고 ERD, 관계 스키마, 3NF 스키마 순으로 구체화한다.

## 요약
- 이 강좌는 **엔티티/관계 → ERD → 관계형 모델 → 정규화(3NF)**로 이어지는 관계형 DB 설계 전 과정을 다룬다.
