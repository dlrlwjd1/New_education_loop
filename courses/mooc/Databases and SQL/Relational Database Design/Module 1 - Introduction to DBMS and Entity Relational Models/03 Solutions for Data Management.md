# Solutions for Data Management (데이터 관리 솔루션)

> 강좌: Relational Database Design (MOOC, 강사 Di Wu) · 모듈 1: Introduction to DBMS and Entity Relational Models

## 개요
- 고전적 **파일 시스템(file system)**의 한계와, 그 대안인 **데이터베이스(DBMS) 솔루션**의 구성·장단점, 그리고 DBMS가 부적절한 경우를 다룬다.

## 내용

### 파일 시스템의 한계
- 파일들이 **분리·고립**되어 데이터의 연결된 뷰를 만들기 어려움.
- **데이터 중복(duplication)** — 같은 정보(사용자명·생일 등)를 여러 파일에 저장.
- **애플리케이션 의존성** — 특정 앱으로만 열림, 앱 업데이트·단종 시 호환성 문제.
- **데이터 공유 곤란** — 공통 포맷 부재. → 대규모 데이터 관리에는 부적합.

### 데이터베이스 솔루션
- 데이터를 담는 **구조(structure)** — 데이터의 표현·의미·관계, 그리고 입력·갱신·삭제·질의·리포트를 빠르게 하는 방법을 정의.
- 관계형 DB의 조직 요소:
  - **엔티티(entity)** — 관리하려는 사물의 종류/클래스.
  - **속성(attribute)** — 엔티티의 특성·속성·기록할 값.
  - **관계(relationship)** — 엔티티들이 어떻게 연결되는지(예: 거래에 고객·제품·매장·계산원이 연결).
- **DBMS** — 사용자가 DB와 상호작용하게 해주는 프로그램. GUI 또는 간결한 코드로 조작, 폼·쿼리·리포트 제공.
- 대표 DBMS: **Microsoft Access**, **MySQL·PostgreSQL**(관계형, Course 2에서 학습), **MongoDB 등 NoSQL**(비관계형 — 테이블·릴레이션에 의존 안 함).

### DBMS의 장점
- 같은 양의 데이터에서 **더 많은 정보** 추출(연도별·매장별·지역별·판매원별 매출 등 질의).
- **데이터 공유 용이**(공통 형식, 시스템·앱 호환).
- **중복 통제(정규화)** → DB 최소화, **일관성(consistency)** 확보(한 곳만 갱신).
- **참조 무결성(referential integrity)** — 관계의 참여(participation) 속성으로 강제.
- **보안** — 다층 권한, 사용자-DB 분리.
- **생산성 향상** — 사용자는 설계를 몰라도 사용 가능(설계·구현·유지보수는 설계자/관리자의 책임).
- **데이터 독립성(data independence)** — 앱·소프트웨어·하드웨어 의존 최소화.

### DBMS의 단점
- **복잡성** — 설계·구현 학습 필요(파일 시스템보다 훨씬 복잡).
- 설계 실수 시 **영향이 큼**, 유지 부실 시 데이터 손실·손상 위험 → **복구(recovery)가 더 어려움**.
- **더 큰 파일 크기** — 실제 데이터 외에 구조·사용자·앱 데이터도 저장.

### DBMS가 부적절한 경우
장점이 단점을 능가하지 못할 때. 구체적으로:
- DB가 작고 구조가 매우 단순할 때(일일 지출 기록 등 → 노트로 충분).
- 앱이 단순·특정 목적·정적(자주 변하지 않음)일 때(지인 생일 목록 등).
- **실시간(real-time) 응답**이 필요할 때(신호등 제어, 환자 모니터링 — 갱신에 시간이 걸림).
- **동시·다중 사용자 접근**이 필요 없을 때.
- → 하지만 오늘날 대부분의 비즈니스·온라인 쇼핑·분석에는 DBMS가 필요.

## 예시
- 부서별 고객 파일을 따로 두면 주소 변경을 여러 파일에 반영해야 한다. 중앙 DBMS와 고객 키를 사용하면 한 번의 갱신으로 일관성을 유지한다.

## 요약
- 파일 시스템은 **고립·중복·앱 의존·공유 곤란**으로 한계 → **DBMS**(엔티티·속성·관계로 조직된 구조)로 전환.
- DBMS 장점: 정보 추출력·공유·중복 통제·일관성·참조 무결성·보안·생산성·데이터 독립성. 단점: 복잡성·큰 영향·복구 어려움·큰 크기.
- **장점이 단점을 능가할 때만** 사용 — 소규모·정적·실시간·단일 사용자면 부적절할 수 있다.
