# Summary and Highlights

> MOOC 읽기 자료(Reading, 1분) · [원본 자료](https://www.mooc.org/learn/sql-data-science/supplement/KJsso/summary-and-highlights)

## 개요

이 레슨을 마친 시점에서 알게 된 내용을 정리한 자료입니다.

## 내용

이 레슨을 완료하면서 다음을 익혔습니다.

- **실제 데이터셋(real-world dataset)을 다루는 방법** — 데이터를 처리하고 분석하는 실전 경험을 쌓았습니다.
- **데이터베이스에서 테이블·컬럼 상세 정보를 얻는 과정** — 데이터베이스 구조를 이해하고 효과적인 쿼리를 설계하는 데 필수적인 작업입니다.

## 요약

- 실제 데이터셋 처리·분석 경험
- 테이블/컬럼 메타데이터 조회를 통한 데이터베이스 구조 파악과 쿼리 설계
