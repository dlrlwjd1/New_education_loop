# Congratulations & Next Steps

> MOOC 읽기 자료(Reading, 2분) · [원본 자료](https://www.mooc.org/learn/sql-data-science/supplement/FXe2I/congratulations-next-steps)

## 개요

`Databases and SQL for Data Science with Python` 코스를 완료한 것을 축하하며, 이 코스가 어떤 프로그램의 일부인지와 다음에 들을 코스를 안내하는 자료다.

## 내용

### 이 코스가 속한 프로그램

이 코스는 다음 전문과정(specialization)·전문 자격증(professional certificate)의 일부다.

- Introduction to Data Science Specialization
- IBM Data Engineering Foundations Specialization
- IBM Data Analyst Professional Certificate
- IBM Data Science Professional Certificate
- IBM Data Engineering Professional Certificate
- BI Foundations with SQL, ETL and Data Warehousing Specialization
- IBM Relational Database Administrator Professional Certificate
- Data Science Fundamentals with Python and SQL Specialization

### Data Engineering 트랙 수강생 주의사항

Data Engineering 트랙을 따르는 경우 이 코스의 **보너스 모듈(Module 6: Bonus Module - Advanced SQL for Data Engineers)** 도 반드시 완료해야 한다. 데이터 엔지니어에게 유용한 고급 SQL 기법을 담고 있다.

> 이 저장소에서는 `Module 6 - Bonus - Advanced SQL for Data Engineers/`에 정리되어 있다.

### 다음 단계 — 트랙별 추천 코스

| 트랙 | 다음 코스 |
|---|---|
| Data Science / Data Analytics | Data Analysis with Python |
| Data Engineering | Hands-on Introduction to Linux Commands and Shell Scripting |
| BI Foundations with SQL, ETL and Data Warehousing | ETL and Data Pipelines with Shell, Airflow and Kafka |
| IBM Relational Database Administrator | Hands-on Introduction to Linux Commands and Shell Scripting |

코스 팀은 피드백을 남기고 코스를 평가해 줄 것을 권장한다.

## 요약

- 이 코스는 8개 이상의 IBM 전문과정·전문 자격증에 포함된다.
- Data Engineering 트랙이라면 Module 6(보너스, 고급 SQL)까지 완료해야 한다.
- 다음 코스는 트랙에 따라 다르다 — Data Analysis with Python, Linux Commands and Shell Scripting, ETL and Data Pipelines 등.
