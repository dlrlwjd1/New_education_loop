# Module 6 Introduction: Advanced SQL for Data Engineers

## 모듈 개요

이 모듈은 **데이터 엔지니어**에게 유용한 고급 SQL 기법을 다룹니다.

---

## 학습 내용

이 모듈에서는 아래의 고급 SQL 기법을 활용해 더 강력한 쿼리를 작성하는 방법을 배웁니다.

| 주제 | 설명 |
|------|------|
| Views | 쿼리 결과를 가상 테이블로 저장해 재사용 |
| Transactions | 여러 SQL 작업을 하나의 논리적 단위로 처리 |
| Stored Procedures | 데이터베이스에 저장해두고 반복 실행하는 SQL 블록 |
| Joins | 여러 테이블을 결합해 데이터를 조회 |
