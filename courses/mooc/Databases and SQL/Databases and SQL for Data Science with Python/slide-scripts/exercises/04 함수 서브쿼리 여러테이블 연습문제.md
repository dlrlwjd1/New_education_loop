# 04강 연습문제 — SQL 함수, 서브쿼리, 여러 테이블

## 학습 목표

- 집계 함수(`SUM`, `AVG`, `MIN`, `MAX`)와 스칼라 함수(`ROUND`, `LENGTH`, `UCASE`)를 사용한다.
- 날짜 함수로 날짜 데이터를 다룬다.
- `WHERE`, `SELECT`, `FROM` 절에 서브쿼리(subquery)를 사용한다.
- 두 테이블을 서브쿼리 또는 암시적 조인으로 연결한다.

## 사전 준비

```sql
-- data/04_functions_data.sql 실행
-- 테이블: PETRESCUE, SALES, DEPARTMENTS, EMPLOYEES
```

## 테이블 구조

**PETRESCUE:** ID, ANIMAL, QUANTITY, COST, RESCUEDATE

**SALES:** ID, PRODUCT, AMOUNT, SALEDATE

**DEPARTMENTS:** DEPT_ID_DEP, DEP_NAME, MANAGER_ID, LOCATION

**EMPLOYEES:** EMP_ID, F_NAME, L_NAME, DEP_ID, SALARY, JOB_TITLE

## 연습 문제

### 문제 1 — 집계 함수

**과제:** SALES 테이블에서 아래 값을 한 쿼리로 모두 구하세요.
- 총 매출액 합계
- 평균 거래 금액
- 최소 거래 금액
- 최대 거래 금액

<details>
<summary>풀이 보기</summary>

**정답:**
```sql
SELECT
    SUM(AMOUNT)          AS total_sales,
    ROUND(AVG(AMOUNT), 2) AS avg_sale,
    MIN(AMOUNT)          AS min_sale,
    MAX(AMOUNT)          AS max_sale
FROM SALES;
```

**설명:**
집계 함수는 여러 행의 값을 하나의 요약 값으로 줄입니다. 한 `SELECT`에 여러 집계 함수를 동시에 사용할 수 있습니다. `ROUND(값, 소수점자리)`로 반올림합니다.

**예상 결과:**
| total_sales | avg_sale | min_sale | max_sale |
|-------------|----------|----------|----------|
| 6600.00 | 660.00 | 80.00 | 1350.00 |

</details>

### 문제 2 — GROUP BY + 집계 함수

**과제:** SALES 테이블에서 상품(PRODUCT)별로 총 매출액과 거래 횟수를 구하세요.
총 매출액 내림차순으로 정렬합니다.

<details>
<summary>풀이 보기</summary>

**정답:**
```sql
SELECT
    PRODUCT,
    COUNT(*)       AS sale_count,
    SUM(AMOUNT)    AS total_amount
FROM SALES
GROUP BY PRODUCT
ORDER BY total_amount DESC;
```

**예상 결과:**
| PRODUCT | sale_count | total_amount |
|---------|------------|--------------|
| Laptop | 3 | 3650.00 |
| Tablet | 2 | 1570.00 |
| Monitor | 2 | 950.00 |
| Keyboard | 2 | 350.00 |
| Mouse | 1 | 80.00 |

</details>

### 문제 3 — ROUND + LENGTH: 스칼라 함수

**과제:** PETRESCUE 테이블에서 아래 정보를 조회하세요.
- ANIMAL 이름
- COST 값 (소수점 없이 반올림)
- ANIMAL 이름의 글자 수 (LENGTH)
- ANIMAL 이름 대문자 변환 (UCASE)

<details>
<summary>풀이 보기</summary>

**정답:**
```sql
SELECT
    ANIMAL,
    ROUND(COST, 0)    AS cost_rounded,
    LENGTH(ANIMAL)    AS name_length,
    UCASE(ANIMAL)     AS animal_upper
FROM PETRESCUE;
```

> **SQLite 참고:** SQLite에서는 `UCASE()` 대신 `UPPER()`, `LCASE()` 대신 `LOWER()`를 사용합니다.
> MySQL/Db2에서는 `UCASE()`도 지원됩니다.

**설명:**
스칼라 함수는 각 행에 개별적으로 적용됩니다. 집계 함수와 달리 행 수가 줄어들지 않습니다.

</details>

### 문제 4 — 날짜 함수

**과제:** PETRESCUE 테이블에서 구조 날짜(RESCUEDATE)에서 월(MONTH)만 뽑아 조회하세요.
또한 2021년에 구조된 기록만 필터링하세요.

> **힌트:** DBMS별 날짜 함수 문법이 다릅니다. MySQL 기준으로 작성하고, SQLite 버전도 함께 제시합니다.

<details>
<summary>풀이 보기</summary>

**MySQL / Db2:**
```sql
SELECT
    ID,
    ANIMAL,
    RESCUEDATE,
    MONTH(RESCUEDATE) AS rescue_month
FROM PETRESCUE
WHERE YEAR(RESCUEDATE) = 2021;
```

**SQLite (strftime 함수 사용):**
```sql
SELECT
    ID,
    ANIMAL,
    RESCUEDATE,
    CAST(strftime('%m', RESCUEDATE) AS INTEGER) AS rescue_month
FROM PETRESCUE
WHERE strftime('%Y', RESCUEDATE) = '2021';
```

**설명:**
날짜 함수는 DBMS별로 문법 차이가 큽니다.
- MySQL: `YEAR()`, `MONTH()`, `DAY()`
- SQLite: `strftime('%Y', col)`, `strftime('%m', col)`, `strftime('%d', col)`
- Db2: `YEAR()`, `MONTH()`, `DAY()`

**예상 결과:** 2021년 구조 기록 8건 (ID 1~8)

</details>

### 문제 5 — 서브쿼리 (WHERE): 평균보다 낮은 급여

**과제:** EMPLOYEES 테이블에서 전체 평균 급여보다 낮은 급여를 받는 직원의
이름(F_NAME, L_NAME)과 급여를 조회하세요.

> **핵심:** `WHERE SALARY < AVG(SALARY)`처럼 직접 집계 함수를 WHERE에 쓸 수 없습니다.

<details>
<summary>풀이 보기</summary>

**정답:**
```sql
SELECT F_NAME, L_NAME, SALARY
FROM EMPLOYEES
WHERE SALARY < (
    SELECT AVG(SALARY)
    FROM EMPLOYEES
);
```

**설명:**
`WHERE` 안의 서브쿼리는 먼저 실행되어 단일 값(평균 급여)을 반환합니다. 바깥 쿼리는 그 값을 기준으로 행을 필터링합니다.

전체 평균: `(75000+52000+48000+82000+61000+45000+70000+88000+92000+47000) / 10 = 66000`

**예상 결과:** Soyeon Lee(52000), Jinho Park(48000), Maria Garcia(61000), James Brown(45000), Priya Sharma(70000) 중 66000 미만 → Lee(52000), Park(48000), Garcia(61000), Brown(45000), Wilson(47000)

</details>

### 문제 6 — 서브쿼리 (SELECT): 개인 급여 vs 전체 평균

**과제:** EMPLOYEES 테이블에서 각 직원의 이름, 급여, 전체 평균 급여, 그리고 개인 급여와 평균의 차이를 함께 조회하세요.

<details>
<summary>풀이 보기</summary>

**정답:**
```sql
SELECT
    F_NAME,
    L_NAME,
    SALARY,
    (SELECT ROUND(AVG(SALARY), 0) FROM EMPLOYEES) AS avg_salary,
    SALARY - (SELECT ROUND(AVG(SALARY), 0) FROM EMPLOYEES) AS diff_from_avg
FROM EMPLOYEES
ORDER BY diff_from_avg DESC;
```

**설명:**
`SELECT` 절의 서브쿼리는 각 행에 대해 실행되어 추가 컬럼처럼 결과에 붙습니다. 모든 행에 동일한 평균 값이 붙게 됩니다. 개인 급여와 평균의 차이를 계산해 상대적 위치를 파악할 수 있습니다.

</details>

### 문제 7 — 서브쿼리 (FROM): 파생 테이블

**과제:** EMPLOYEES 테이블에서 부서별 평균 급여를 먼저 계산한 뒤,
그 결과에서 평균 급여가 65000 이상인 부서만 조회하세요.

> **힌트:** `FROM` 절의 서브쿼리 결과에 반드시 별칭(alias)을 붙여야 합니다.

<details>
<summary>풀이 보기</summary>

**정답:**
```sql
SELECT *
FROM (
    SELECT DEP_ID,
           ROUND(AVG(SALARY), 0) AS avg_salary,
           COUNT(*)              AS emp_count
    FROM EMPLOYEES
    GROUP BY DEP_ID
) AS dept_summary
WHERE avg_salary >= 65000;
```

**설명:**
`FROM` 절의 서브쿼리는 임시 테이블(파생 테이블, derived table)처럼 동작합니다. 이 임시 결과에 `AS dept_summary`로 별칭을 붙여야 바깥 쿼리에서 참조할 수 있습니다.

**예상 결과:**
| DEP_ID | avg_salary | emp_count |
|--------|------------|-----------|
| D01 | 75667 | 3 |
| D04 | 90000 | 2 |

</details>

### 문제 8 — 여러 테이블: 서브쿼리로 연결

**과제:** DEPARTMENTS 테이블에 존재하는 부서 ID(DEPT_ID_DEP)에 해당하는 직원만 조회하세요.
(서브쿼리와 `IN`을 사용합니다.)

<details>
<summary>풀이 보기</summary>

**정답:**
```sql
SELECT EMP_ID, F_NAME, L_NAME, DEP_ID
FROM EMPLOYEES
WHERE DEP_ID IN (
    SELECT DEPT_ID_DEP
    FROM DEPARTMENTS
);
```

**설명:**
서브쿼리가 여러 값의 목록을 반환할 때는 `IN`을 사용합니다. DEPARTMENTS에 없는 부서 ID를 가진 직원은 결과에서 제외됩니다.

이 방식은 이해하기 쉽지만, 두 테이블의 컬럼을 함께 보려면 JOIN이 더 적합합니다.

</details>

### 문제 9 — 암시적 조인

**과제:** EMPLOYEES와 DEPARTMENTS 테이블을 연결하여
직원 이름(F_NAME, L_NAME), 부서명(DEP_NAME), 위치(LOCATION)를 함께 조회하세요.

> **힌트:** `FROM` 절에 두 테이블을 나열하고, `WHERE`로 연결 조건을 지정합니다.
> 연결 조건을 빠뜨리면 모든 조합이 만들어집니다 (cross join 주의).

<details>
<summary>풀이 보기</summary>

**정답:**
```sql
SELECT E.F_NAME, E.L_NAME, D.DEP_NAME, D.LOCATION
FROM EMPLOYEES E, DEPARTMENTS D
WHERE E.DEP_ID = D.DEPT_ID_DEP
ORDER BY D.DEP_NAME, E.L_NAME;
```

**설명:**
- `FROM EMPLOYEES E, DEPARTMENTS D`: 두 테이블을 나열하고 각각 E, D라는 별칭을 붙입니다.
- `WHERE E.DEP_ID = D.DEPT_ID_DEP`: 직원의 부서 ID와 부서 테이블의 ID를 연결합니다.
- `E.F_NAME`, `D.DEP_NAME`처럼 테이블 별칭을 붙이면 어느 테이블의 컬럼인지 명확합니다.

**예상 결과:** 10명의 직원 각각에 부서명과 위치가 붙음

</details>

### 문제 10 — 통합 분석 쿼리

**과제:** 아래 분석 질문에 답하는 SQL을 작성하세요.

**질문:** "Engineering 또는 Data Science 부서에 속한 직원 중,
자신의 부서 평균 급여보다 높은 급여를 받는 직원의 이름과 급여, 부서명을 조회하세요."

<details>
<summary>풀이 보기</summary>

**정답:**
```sql
SELECT E.F_NAME, E.L_NAME, E.SALARY, D.DEP_NAME
FROM EMPLOYEES E, DEPARTMENTS D
WHERE E.DEP_ID = D.DEPT_ID_DEP
  AND D.DEP_NAME IN ('Engineering', 'Data Science')
  AND E.SALARY > (
      SELECT AVG(E2.SALARY)
      FROM EMPLOYEES E2
      WHERE E2.DEP_ID = E.DEP_ID
  )
ORDER BY D.DEP_NAME, E.SALARY DESC;
```

**설명:**
이 쿼리는 **상관 서브쿼리(correlated subquery)**를 사용합니다. 안쪽 서브쿼리가 바깥 쿼리의 `E.DEP_ID`를 참조합니다. 즉, 각 직원의 행을 검사할 때마다 해당 직원의 부서 평균을 계산합니다.

- Engineering 평균: (75000 + 82000 + 70000) / 3 = 75666.67
  - 75000 미만 → Priya Sharma(70000) 제외, John Smith(82000) 포함
- Data Science 평균: (88000 + 92000) / 2 = 90000
  - 90000 초과 → Ana Silva(92000)만 포함

</details>

## 핵심 정리

| 항목 | 설명 |
|------|------|
| 집계 함수 | SUM, AVG, MIN, MAX, COUNT — 여러 행을 하나의 값으로 |
| 스칼라 함수 | ROUND, LENGTH, UCASE/UPPER — 각 행에 개별 적용 |
| 날짜 함수 | YEAR/MONTH/DAY (MySQL) vs strftime (SQLite) |
| 서브쿼리 WHERE | 집계 기준값 계산 → `SALARY < (SELECT AVG(...))` |
| 서브쿼리 SELECT | 추가 계산 컬럼 → `(SELECT AVG(...)) AS avg` |
| 서브쿼리 FROM | 임시 테이블(파생 테이블) → 반드시 별칭 필요 |
| 암시적 조인 | FROM에 여러 테이블 + WHERE 연결 조건 |
