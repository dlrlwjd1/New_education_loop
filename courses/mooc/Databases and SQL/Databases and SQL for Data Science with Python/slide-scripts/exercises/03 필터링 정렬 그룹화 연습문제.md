# 03강 연습문제 — 필터링, 정렬, 그룹화

## 학습 목표

- `LIKE`, `BETWEEN`, `IN`으로 다양한 조건식을 작성한다.
- `ORDER BY`로 결과를 원하는 순서로 정렬한다.
- `GROUP BY`와 집계 함수(`COUNT`, `SUM`, `AVG`, `MIN`, `MAX`)로 그룹별 분석을 수행한다.
- `HAVING`과 `WHERE`의 차이를 이해하고 올바르게 사용한다.

## 연습 문제

### 문제 1 — LIKE: 이름 패턴 검색

**과제:** AUTHOR 테이블에서 성(LASTNAME)이 'S'로 시작하는 저자를 모두 조회하세요.

> **힌트:** `LIKE 'S%'` — `%`는 0개 이상의 임의 문자를 의미합니다.

<details>
<summary>풀이 보기</summary>

**정답:**
```sql
SELECT *
FROM AUTHOR
WHERE LASTNAME LIKE 'S%';
```

**설명:**
`LIKE`는 패턴 매칭에 사용됩니다. `S%`는 S로 시작하면 뒤에 어떤 문자가 와도 매칭됩니다.

- `'S%'` → S로 시작하는 모든 값
- `'%a'` → a로 끝나는 모든 값
- `'%il%'` → il이 포함된 모든 값

**예상 결과:** Santos(A5), Smith(A4), Sharma(A7), Silva(A3) → 4명

</details>

---

### 문제 2 — LIKE: 제목 내 특정 단어 포함

**과제:** BOOK 테이블에서 제목(TITLE)에 'Wood' 또는 'Light'가 포함된 책을 조회하세요.

> **힌트:** `LIKE '%단어%'` 패턴을 사용하거나 `OR`로 두 조건을 결합합니다.

<details>
<summary>풀이 보기</summary>

**정답:**
```sql
SELECT BOOK_ID, TITLE, PRICE
FROM BOOK
WHERE TITLE LIKE '%Wood%'
   OR TITLE LIKE '%Light%';
```

**설명:**
`%단어%`는 해당 단어가 어디에 있든 매칭됩니다. 두 조건은 `OR`로 연결해 둘 중 하나라도 해당하면 결과에 포함됩니다.

**예상 결과:** Norwegian Wood, Morning Light

</details>

---

### 문제 3 — BETWEEN: 범위 조건

**과제:** BOOK 테이블에서 가격(PRICE)이 15.00 이상 20.00 이하인 책의 제목과 가격을 조회하세요.

> **힌트:** `BETWEEN a AND b`는 a ≤ 값 ≤ b 범위입니다 (양 끝 포함).

<details>
<summary>풀이 보기</summary>

**정답:**
```sql
SELECT TITLE, PRICE
FROM BOOK
WHERE PRICE BETWEEN 15.00 AND 20.00;
```

**설명:**
`BETWEEN`은 양 끝 값을 포함합니다. `15.00 <= PRICE <= 20.00`과 동일합니다.
동일 표현: `WHERE PRICE >= 15.00 AND PRICE <= 20.00`

**예상 결과:** The Night Watch(15.99), Norwegian Wood(18.50), Dark Wind(19.99), Silver Thread(16.75)

</details>

### 문제 4 — IN: 집합 조건

**과제:** AUTHOR 테이블에서 국가(COUNTRY)가 France, Japan, India 중 하나인 저자를 조회하세요.

<details>
<summary>풀이 보기</summary>

**정답:**
```sql
SELECT AUTHOR_ID, FIRSTNAME, LASTNAME, COUNTRY
FROM AUTHOR
WHERE COUNTRY IN ('France', 'Japan', 'India');
```

**설명:**
`IN`은 여러 `OR` 조건을 간결하게 표현합니다.
동일 표현: `WHERE COUNTRY = 'France' OR COUNTRY = 'Japan' OR COUNTRY = 'India'`

**예상 결과:** Modiano(France), Murakami(Japan), Martin(France), Sharma(India) → 4명

</details>

### 문제 5 — ORDER BY: 오름차순 정렬

**과제:** BOOK 테이블에서 모든 책을 가격(PRICE) 오름차순으로 정렬해 조회하세요.

<details>
<summary>풀이 보기</summary>

**정답:**
```sql
SELECT TITLE, PRICE
FROM BOOK
ORDER BY PRICE ASC;
```

**설명:**
`ORDER BY 컬럼 ASC`는 오름차순(낮은 값 → 높은 값)으로 정렬합니다. `ASC`는 기본값이므로 생략해도 됩니다.

**예상 결과:** Mountain Road(11.00) → Ocean Echoes(12.00) → ... → Tokyo Dreams(24.99)

</details>

### 문제 6 — ORDER BY: 내림차순 다중 정렬

**과제:** BOOK 테이블에서 출판연도(YEAR_PUBLISHED) 내림차순으로 정렬하되, 같은 연도 내에서는 가격(PRICE) 오름차순으로 정렬하세요.

<details>
<summary>풀이 보기</summary>

**정답:**
```sql
SELECT TITLE, YEAR_PUBLISHED, PRICE
FROM BOOK
ORDER BY YEAR_PUBLISHED DESC, PRICE ASC;
```

**설명:**
`ORDER BY`에 여러 기준을 나열하면 앞에서부터 순서대로 적용됩니다. 먼저 출판연도 내림차순으로 정렬한 뒤, 같은 연도 안에서는 가격 오름차순으로 정렬합니다.

</details>

### 문제 7 — GROUP BY + COUNT

**과제:** AUTHOR 테이블에서 국가(COUNTRY)별 저자 수를 구하세요.
결과 컬럼명은 `author_count`로 지정하고, 저자 수 내림차순으로 정렬하세요.

<details>
<summary>풀이 보기</summary>

**정답:**
```sql
SELECT COUNTRY, COUNT(*) AS author_count
FROM AUTHOR
GROUP BY COUNTRY
ORDER BY author_count DESC;
```

**설명:**
`GROUP BY COUNTRY`는 같은 국가를 가진 행들을 하나의 그룹으로 묶습니다. `COUNT(*)`는 각 그룹의 행 수를 셉니다. `AS author_count`로 결과 컬럼에 의미 있는 이름을 붙입니다.

**예상 결과:**
| COUNTRY | author_count |
|---------|--------------|
| France | 2 |
| Australia | 2 |
| Japan | 1 |
| Brazil | 1 |
| Spain | 1 |
| Canada | 1 |
| India | 1 |

</details>

### 문제 8 — GROUP BY + AVG

**과제:** BOOK 테이블에서 저자(AUTHOR_ID)별 책의 평균 가격을 구하세요.
결과는 평균 가격 내림차순으로 정렬하고, 평균 가격을 소수점 둘째 자리까지 표시하세요.

> **힌트:** `AVG()`, `ROUND()`, `ORDER BY`를 함께 사용합니다.

<details>
<summary>풀이 보기</summary>

**정답:**
```sql
SELECT AUTHOR_ID,
       COUNT(*)                    AS book_count,
       ROUND(AVG(PRICE), 2)        AS avg_price
FROM BOOK
GROUP BY AUTHOR_ID
ORDER BY avg_price DESC;
```

**설명:**
`AVG(PRICE)`는 그룹 내 PRICE의 평균을 계산합니다. `ROUND(값, 2)`로 소수점 둘째 자리까지 반올림합니다. 여러 집계 함수를 동시에 사용할 수 있습니다.

**예상 결과:**
| AUTHOR_ID | book_count | avg_price |
|-----------|------------|-----------|
| A2 | 2 | 21.75 |
| A1 | 2 | 18.50 |
| A4 | 2 | 16.50 |
| ... | ... | ... |

</details>

### 문제 9 — HAVING: 그룹 결과 필터링

**과제:** AUTHOR 테이블에서 저자가 2명 이상인 국가만 조회하세요.

> **핵심:** `WHERE COUNT(*) >= 2`처럼 쓸 수 없습니다. 집계 함수 조건은 `HAVING`을 사용합니다.

<details>
<summary>풀이 보기</summary>

**정답:**
```sql
SELECT COUNTRY, COUNT(*) AS author_count
FROM AUTHOR
GROUP BY COUNTRY
HAVING COUNT(*) >= 2;
```

**왜 WHERE가 아닌 HAVING인가?**

| 구문 | 실행 시점 | 사용 가능한 조건 |
|------|-----------|-----------------|
| `WHERE` | GROUP BY 이전 (개별 행 대상) | 집계 함수 사용 불가 |
| `HAVING` | GROUP BY 이후 (그룹 대상) | 집계 함수 사용 가능 |

`WHERE COUNT(*) >= 2`를 쓰면 오류가 발생합니다. 아직 그룹화가 되기 전이라 COUNT를 계산할 수 없기 때문입니다.

**예상 결과:** France(2), Australia(2)

</details>

### 문제 10 — 복합 쿼리: WHERE + GROUP BY + HAVING + ORDER BY

**과제:** BOOK 테이블에서 아래 조건을 모두 만족하는 쿼리를 작성하세요.

1. 2000년 이후에 출판된 책만 대상으로 (WHERE)
2. 저자별로 그룹화하여 책 수와 평균 가격을 계산 (GROUP BY)
3. 책이 1권 이상인 저자만 포함 (HAVING)
4. 평균 가격 내림차순으로 정렬 (ORDER BY)

<details>
<summary>풀이 보기</summary>

**정답:**
```sql
SELECT AUTHOR_ID,
       COUNT(*)             AS book_count,
       ROUND(AVG(PRICE), 2) AS avg_price
FROM BOOK
WHERE YEAR_PUBLISHED >= 2000
GROUP BY AUTHOR_ID
HAVING COUNT(*) >= 1
ORDER BY avg_price DESC;
```

**SQL 논리적 실행 순서:**
1. `FROM BOOK` — 테이블 선택
2. `WHERE YEAR_PUBLISHED >= 2000` — 2000년 이후 행만 남김
3. `GROUP BY AUTHOR_ID` — 저자별 그룹화
4. `COUNT(*)`, `AVG(PRICE)` — 그룹별 집계
5. `HAVING COUNT(*) >= 1` — 책 1권 이상인 그룹만 남김
6. `SELECT` — 결과 컬럼 선택
7. `ORDER BY avg_price DESC` — 정렬

이 순서를 이해하면 `WHERE`와 `HAVING`의 위치가 왜 다른지 자연스럽게 이해됩니다.

</details>

## 통합 문제 — 분석 쿼리

**과제:** 다음 분석 질문에 답하는 SQL을 작성하세요.

**질문:** "AUTHOR와 BOOK 데이터를 바탕으로, S 또는 M으로 시작하는 성(LASTNAME)을 가진 저자들의 국가별 평균 책 가격을 구하되, 평균 가격이 15 이상인 국가만 내림차순으로 보여주세요."

> 이 문제는 두 테이블을 연결하는 암시적 조인을 포함합니다. 04강 내용을 먼저 봐도 됩니다.

<details>
<summary>풀이 보기</summary>

**정답:**
```sql
SELECT A.COUNTRY,
       COUNT(B.BOOK_ID)        AS book_count,
       ROUND(AVG(B.PRICE), 2)  AS avg_price
FROM AUTHOR A, BOOK B
WHERE A.AUTHOR_ID = B.AUTHOR_ID
  AND (A.LASTNAME LIKE 'S%' OR A.LASTNAME LIKE 'M%')
GROUP BY A.COUNTRY
HAVING AVG(B.PRICE) >= 15
ORDER BY avg_price DESC;
```

**설명:**
- `FROM AUTHOR A, BOOK B` + `WHERE A.AUTHOR_ID = B.AUTHOR_ID`: 두 테이블을 저자 ID로 연결 (암시적 조인)
- `(LASTNAME LIKE 'S%' OR LASTNAME LIKE 'M%')`: S 또는 M으로 시작하는 성
- `GROUP BY A.COUNTRY`: 국가별 집계
- `HAVING AVG(B.PRICE) >= 15`: 평균 가격 15 이상인 국가만

</details>

## 핵심 정리

| 구문 | 사용 상황 | 예시 |
|------|----------|------|
| `LIKE 'S%'` | S로 시작하는 값 | `WHERE LASTNAME LIKE 'S%'` |
| `LIKE '%ile%'` | 중간에 포함된 값 | `WHERE TITLE LIKE '%ile%'` |
| `BETWEEN a AND b` | 범위 조건 (양 끝 포함) | `WHERE PRICE BETWEEN 10 AND 25` |
| `IN (a, b, c)` | 여러 값 중 하나 | `WHERE COUNTRY IN ('France', 'Japan')` |
| `ORDER BY col ASC` | 오름차순 정렬 | 기본값 |
| `ORDER BY col DESC` | 내림차순 정렬 | |
| `GROUP BY col` | 그룹별 집계 | `SELECT DEPT, COUNT(*) FROM EMP GROUP BY DEPT` |
| `HAVING 조건` | 그룹 결과 필터링 | 집계 함수 조건에 사용 |
