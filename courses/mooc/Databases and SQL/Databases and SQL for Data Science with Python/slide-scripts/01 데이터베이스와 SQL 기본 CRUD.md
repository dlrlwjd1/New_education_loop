## Slide 2. 데이터 과학에서 SQL이 필요한 이유

### 슬라이드 문구

데이터 분석의 출발점

- 데이터는 보통 데이터베이스에 저장된다
- 분석 전에 필요한 데이터를 가져와야 한다
- SQL은 데이터베이스에 질문하는 언어다

### 스크립트

데이터 과학에서 Python과 Pandas를 많이 사용하지만, 실제 업무 데이터는 처음부터 CSV 파일로 예쁘게 주어지는 경우가 많지 않습니다.

많은 데이터는 관계형 데이터베이스에 저장되어 있습니다. 고객, 주문, 상품, 결제, 로그 같은 데이터가 여러 테이블로 나뉘어 관리됩니다.

SQL은 이런 데이터베이스에서 필요한 데이터를 조회하고, 필터링하고, 집계하고, 분석 가능한 형태로 가져오는 언어입니다.

## Slide 3. 데이터, 데이터베이스, DBMS

### 슬라이드 문구

기본 용어

- Data: 관찰하거나 기록한 값
- Database: 데이터를 체계적으로 저장한 공간
- DBMS: 데이터베이스를 관리하는 소프트웨어
- RDBMS: 관계형 모델 기반 DBMS

### 스크립트

먼저 용어를 정리하겠습니다.

데이터는 숫자, 문자열, 날짜처럼 관찰하거나 기록한 값입니다. 데이터베이스는 이런 데이터를 체계적으로 저장한 공간입니다.

DBMS는 데이터베이스를 생성하고 조회하고 관리하는 소프트웨어입니다. MySQL, PostgreSQL, IBM Db2, SQLite 같은 것들이 여기에 해당합니다.

RDBMS는 관계형 데이터베이스 관리 시스템입니다. 데이터를 행과 열로 구성된 테이블에 저장하고, 테이블 사이의 관계를 기반으로 관리합니다.

## Slide 4. SQL이란?

### 슬라이드 문구

SQL

Structured Query Language

주요 작업:
- 데이터 조회
- 데이터 삽입
- 데이터 수정
- 데이터 삭제
- 테이블 구조 생성/변경

### 스크립트

SQL은 Structured Query Language의 약자입니다.

이름에는 Query가 들어가지만, SQL은 조회만 하는 언어가 아닙니다. 데이터를 조회하고, 새 데이터를 넣고, 기존 데이터를 수정하고, 삭제할 수 있습니다.

또한 테이블을 만들거나 구조를 바꾸는 작업도 SQL로 수행합니다.

이번 영상에서는 먼저 데이터를 다루는 기본 명령어를 보고, 다음 영상에서 테이블 구조를 다루는 DDL로 넘어가겠습니다.

## Slide 5. SQL 기본 명령어

### 슬라이드 문구

5가지 기본 SQL 명령어

- `SELECT`: 조회
- `INSERT`: 삽입
- `UPDATE`: 수정
- `DELETE`: 삭제
- `CREATE`: 생성

### 스크립트

처음 SQL을 배울 때는 다섯 가지 명령어를 중심으로 잡으면 됩니다.

`SELECT`는 데이터를 조회합니다. 데이터 분석에서 가장 자주 쓰는 명령어입니다.

`INSERT`는 새 행을 추가하고, `UPDATE`는 기존 행의 값을 수정하고, `DELETE`는 행을 삭제합니다.

`CREATE`는 테이블 같은 데이터베이스 객체를 생성합니다. 이 중 `CREATE`는 다음 강의에서 더 자세히 다루겠습니다.

## Slide 6. SELECT 기본 문법

### 슬라이드 문구

기본 조회

```sql
SELECT column1, column2
FROM table_name;
```

모든 열 조회

```sql
SELECT *
FROM table_name;
```

### 스크립트

SQL에서 가장 기본이 되는 구문은 `SELECT`입니다.

특정 열만 보고 싶으면 `SELECT` 뒤에 열 이름을 적고, `FROM` 뒤에 테이블 이름을 적습니다.

모든 열을 보고 싶으면 별표를 사용할 수 있습니다. 다만 실제 업무에서는 필요한 열만 명시하는 습관이 좋습니다. 테이블이 크면 모든 열을 가져오는 것이 비효율적일 수 있기 때문입니다.

---

## Slide 7. WHERE로 행 필터링

### 슬라이드 문구

조건에 맞는 행만 조회

```sql
SELECT *
FROM EMPLOYEE
WHERE DEPT = 'HR';
```

비교 연산자:
- `=`
- `<>`
- `>`
- `<`
- `>=`
- `<=`

### 스크립트

`WHERE` 절은 행을 필터링할 때 사용합니다.

예를 들어 직원 테이블에서 부서가 HR인 직원만 보고 싶다면 `WHERE DEPT = 'HR'` 조건을 붙입니다.

숫자에는 크다, 작다 같은 비교 연산자를 사용할 수 있고, 문자열 값은 보통 작은따옴표로 감쌉니다.

SQL에서 `WHERE`를 정확히 쓰는 능력은 매우 중요합니다. 조회뿐 아니라 수정과 삭제에서도 어떤 행을 대상으로 할지 결정하기 때문입니다.

## Slide 8. 실습 데모: 기본 SELECT

### 슬라이드 문구

데모 쿼리

```sql
SELECT *
FROM EMPLOYEE;

SELECT NAME, DEPT
FROM EMPLOYEE;

SELECT NAME, SALARY
FROM EMPLOYEE
WHERE SALARY >= 60000;
```

### 스크립트

여기서는 EMPLOYEE 테이블을 기준으로 세 가지 쿼리를 실행합니다.

첫 번째는 전체 테이블을 확인하는 쿼리입니다. 두 번째는 이름과 부서만 가져옵니다. 세 번째는 급여가 60000 이상인 직원만 필터링합니다.

실행 결과를 볼 때는 항상 두 가지를 확인하면 됩니다. 어떤 열을 가져왔는가, 그리고 어떤 행이 남았는가입니다.

## Slide 9. COUNT, DISTINCT, LIMIT

### 슬라이드 문구

조회에 자주 붙는 표현

```sql
SELECT COUNT(*)
FROM MEDALS;

SELECT DISTINCT COUNTRY
FROM MEDALS;

SELECT *
FROM MEDALS
LIMIT 5;
```

### 스크립트

`COUNT`, `DISTINCT`, `LIMIT`는 기본 조회에서 아주 자주 사용합니다.

`COUNT`는 행 수를 셉니다. `DISTINCT`는 중복을 제거합니다. `LIMIT`는 결과 행 수를 제한합니다.

분석에서는 전체 데이터를 다 보기보다 먼저 몇 행만 확인하거나, 고유한 값의 목록을 확인하는 경우가 많습니다. 이때 이 세 가지 표현이 유용합니다.

## Slide 10. INSERT

### 슬라이드 문구

새 행 추가

```sql
INSERT INTO INSTRUCTOR (ID, NAME, DEPT)
VALUES ('A1', 'John', 'Data Science');
```

여러 행 삽입

```sql
INSERT INTO INSTRUCTOR
VALUES
  ('A2', 'Jane', 'SQL'),
  ('A3', 'Kim', 'Python');
```

### 스크립트

`INSERT`는 테이블에 새 행을 추가합니다.

열 이름을 명시하고 값을 넣는 방식이 가장 안전합니다. 테이블의 열 순서에 의존하지 않기 때문입니다.

여러 행을 한 번에 넣을 수도 있습니다. 다만 실제 업무에서는 데이터 타입과 필수 값, 기본 키 중복 여부를 확인해야 합니다.

## Slide 11. UPDATE

### 슬라이드 문구

기존 행 수정

```sql
UPDATE INSTRUCTOR
SET NAME = 'Alice'
WHERE ID = 'A2';
```

주의:
`WHERE` 없이 실행하면 모든 행이 수정될 수 있다

### 스크립트

`UPDATE`는 기존 행의 값을 수정합니다.

가장 중요한 것은 `WHERE` 절입니다. 어떤 행을 수정할지 지정하지 않으면 테이블의 모든 행이 바뀔 수 있습니다.

그래서 실무에서는 `UPDATE`를 실행하기 전에 같은 조건으로 `SELECT`를 먼저 실행해 대상 행을 확인하는 습관이 좋습니다.

---

## Slide 12. DELETE

### 슬라이드 문구

행 삭제

```sql
DELETE FROM INSTRUCTOR
WHERE ID = 'A3';
```

주의:
`WHERE` 없이 실행하면 모든 행이 삭제될 수 있다

### 스크립트

`DELETE`는 조건에 맞는 행을 삭제합니다.

`UPDATE`와 마찬가지로 `WHERE`가 매우 중요합니다. `DELETE FROM table_name`만 실행하면 테이블의 모든 행이 삭제될 수 있습니다.

처음 SQL을 배울 때는 `DELETE`를 무서워할 필요는 없지만, 반드시 조건 확인과 백업, 트랜잭션 개념을 함께 생각해야 합니다.

## Slide 13. CRUD 관점으로 정리

### 슬라이드 문구

CRUD와 SQL

| 작업 | SQL |
|------|-----|
| Create | `INSERT` |
| Read | `SELECT` |
| Update | `UPDATE` |
| Delete | `DELETE` |

### 스크립트

애플리케이션과 데이터베이스에서 자주 쓰는 표현으로 CRUD가 있습니다.

Create, Read, Update, Delete의 약자입니다.

SQL에서는 새 데이터를 추가하는 작업이 `INSERT`, 읽는 작업이 `SELECT`, 수정이 `UPDATE`, 삭제가 `DELETE`에 해당합니다.

이 네 가지를 이해하면 데이터 조작의 기본 뼈대는 잡힌 것입니다.

### 슬라이드 문구

직접 작성해보기

마지막은 `UPDATE` 문제인데, 수정 전에 반드시 같은 조건으로 `SELECT`를 먼저 작성해보는 방식으로 진행하겠습니다.
