# Course Introduction

## 데이터 과학의 중요성

데이터 중심의 시대에서 데이터의 역할과 그 사용을 지원하는 구조는 인류와 전 세계에 점점 더 중요해지고 있습니다. 데이터 과학은 수십억 달러 규모의 산업이며, 과학, 정치, 비즈니스 및 우리 삶의 거의 모든 분야에서 그 응용 분야를 계속 발굴해 냄에 따라 더욱 성장할 준비가 되어 있습니다.

- 분석가들은 이 산업이 이번 10년이 끝날 때까지 **5,000억 달러 이상** 규모로 성장할 것으로 예상
- 데이터 과학자의 평균 연봉: **연간 124,000달러**
- 매일 수조 기가바이트의 데이터가 생성·저장되며, 이를 분석·조작·관리하는 일이 핵심 과제로 부상

## SQL과 Python의 역할

빠르게 진화하는 디지털 환경에서 **데이터베이스**는 방대한 데이터의 저장소입니다. **SQL(Structured Query Language)**은 이 데이터를 효율적으로 쿼리, 업데이트 및 조작할 수 있게 해주는 핵심 도구입니다.

- SQL은 강력하고, 산업 및 학계 전반에서 전 세계적으로 통용되며, 오늘날 대부분의 데이터 과학자가 널리 사용
- **Python**은 다양한 데이터베이스에 연결하고, SQL 쿼리를 실행하며, 결과를 분석에 적합한 형식으로 검색하는 데 활용
- Python은 연결 과정을 단순화하는 다양한 라이브러리를 제공

## 과정 목표

이 과정은 데이터 과학을 수행함에 있어 **데이터베이스와 SQL의 힘을 효과적으로 활용**할 수 있는 지식과 기술을 갖추도록 하는 것을 목표로 합니다.
