# Course Structure

## 주차별 구성

| 주차 | 주제 | 학습 내용 |
|------|------|-----------|
| Week 1 | Getting Started with SQL | SQL과 데이터베이스 기초, 데이터베이스 테이블 쿼리 방법 |
| Week 2 | Introduction to Relational Databases and Tables | 관계형 데이터베이스, 테이블 생성 및 데이터 수정 |
| Week 3 | Intermediate SQL | 다양한 SQL 쿼리 유형, 함수, 문자열 패턴, 그룹화 및 정렬 |
| Week 4 | Accessing Databases with Python | Python 라이브러리와 Jupyter Notebook의 SQL Magic을 활용한 데이터베이스 접근 |
| Week 5 | Course Assignment | 실제 데이터셋을 다루는 방법 이해 및 과정 전반의 기술을 테스트하는 과제 수행 |
| Week 6 *(보너스)* | Advanced SQL for Data Engineers | Views, Stored Procedures, ACID 트랜잭션 등 고급 SQL 쿼리 적용 |
