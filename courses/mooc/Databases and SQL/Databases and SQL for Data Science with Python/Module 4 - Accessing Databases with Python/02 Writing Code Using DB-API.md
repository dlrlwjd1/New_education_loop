# Writing Code Using DB-API

## 학습 목표

- Python DB-API의 기본 개념 설명
- 데이터베이스 커서(Cursor)의 역할 이해
- DB-API를 사용해 데이터베이스에 연결하고 쿼리를 실행하는 코드 작성

---

## Python DB-API란?

**DB-API**는 Python에서 관계형 데이터베이스에 접근하기 위한 표준 API입니다.

DB-API의 핵심 장점은 **하나의 프로그램으로 여러 종류의 데이터베이스를 다룰 수 있다**는 점입니다. 데이터베이스마다 별도의 프로그램을 작성할 필요가 없습니다.

DB-API 함수를 한 번 익혀두면, 어떤 데이터베이스를 사용하든 동일하게 적용할 수 있습니다.

---

## DB-API의 장점

| 장점 | 설명 |
|------|------|
| 쉬운 구현 및 이해 | 간결하고 일관된 인터페이스 |
| 모듈 간 유사성 장려 | 데이터베이스 접근 모듈들이 일관된 방식으로 설계됨 |
| 높은 이식성 | 데이터베이스가 달라도 동일한 코드 구조 사용 가능 |
| 광범위한 연결 지원 | Python에서 다양한 데이터베이스에 연결 가능 |

---

## 데이터베이스별 DB-API 라이브러리

각 데이터베이스 시스템은 Python 연결을 위한 자체 라이브러리를 제공합니다.

| 데이터베이스 | Python 라이브러리 |
|--------------|------------------|
| IBM Db2 | `ibm_db` |
| MySQL | `mysql-connector-python` |
| PostgreSQL | `psycopg2` |
| MongoDB | `PyMongo` |

## DB-API의 두 가지 핵심 개념

### 1. Connection Object (연결 객체)

- 데이터베이스에 연결하고 트랜잭션을 관리하는 데 사용
- `connect()` 생성자로 만들며, 반환된 연결 객체로 아래 메서드 사용 가능

| 메서드 | 설명 |
|--------|------|
| `cursor()` | 새로운 커서 객체 반환 |
| `commit()` | 대기 중인 트랜잭션을 데이터베이스에 반영 |
| `rollback()` | 대기 중인 트랜잭션을 취소하고 이전 상태로 되돌림 |
| `close()` | 데이터베이스 연결 종료 |

### 2. Cursor Object (커서 객체)

- 쿼리를 실행하고 결과를 가져오는 데 사용
- 텍스트 편집기의 커서처럼 결과 집합을 순회하며 데이터에 접근

---

## 커서(Cursor)란?

커서는 데이터베이스의 레코드를 순회할 수 있게 해주는 제어 구조입니다.

프로그래밍 언어에서 파일 핸들(file handle)과 유사하게 동작합니다.

| 파일 핸들 동작 | 커서 동작 |
|----------------|-----------|
| 파일을 열어 내용에 접근 | 커서를 열어 쿼리 결과에 접근 |
| 파일을 닫아 접근 종료 | 커서를 닫아 쿼리 결과 접근 종료 |
| 파일 내 현재 위치를 추적 | 쿼리 결과 내 현재 위치를 추적 |

### 커서 격리(Isolation) 규칙

- **같은 연결**에서 만들어진 커서끼리는 격리되지 않음 → 한 커서의 변경사항이 다른 커서에 즉시 반영됨
- **다른 연결**에서 만들어진 커서는 트랜잭션 지원 방식에 따라 격리될 수도, 되지 않을 수도 있음

---

## Python DB-API 코드 작성 흐름

```python
# 1. 데이터베이스 모듈 가져오기
import ibm_db  # 사용하는 DB에 맞는 라이브러리

# 2. 데이터베이스에 연결 (DB명, 사용자명, 비밀번호 전달)
connection = ibm_db.connect("database", "username", "password")

# 3. 커서 객체 생성
cursor = connection.cursor()

# 4. 쿼리 실행
cursor.execute("SELECT * FROM tablename")

# 5. 결과 가져오기
results = cursor.fetchall()

# 6. 연결 종료
connection.close()
```

> 연결을 닫지 않으면 사용하지 않는 연결이 자원을 계속 점유합니다. 작업이 끝나면 반드시 연결을 종료해야 합니다.

---

## 핵심 요약

- DB-API는 Python에서 관계형 데이터베이스에 접근하기 위한 표준으로, 하나의 코드 구조로 여러 DB를 다룰 수 있습니다.
- 주요 개념은 **연결 객체(Connection Object)** 와 **커서 객체(Cursor Object)** 두 가지입니다.
- 커서는 파일 핸들처럼 쿼리 결과를 순회하며 데이터에 접근합니다.
- DB-API 코드의 기본 흐름은 **연결 → 커서 생성 → 쿼리 실행 → 결과 처리 → 연결 종료** 입니다.
- 사용이 끝난 데이터베이스 연결은 반드시 닫아 자원 낭비를 방지해야 합니다.
