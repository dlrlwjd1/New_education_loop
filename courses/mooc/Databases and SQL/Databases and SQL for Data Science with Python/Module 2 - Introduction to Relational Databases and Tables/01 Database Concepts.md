# Database Concepts

## 학습 목표

- 관계형 모델(Relational Model)의 장점 설명
- 엔티티 이름과 속성이 관계형 데이터베이스 테이블에 매핑되는 방식 설명
- 엔티티(Entity)와 속성(Attribute)의 차이 구분

## 관계형 모델 (Relational Model)

데이터베이스에서 가장 많이 사용되는 데이터 모델로, **데이터 독립성**을 제공합니다.

| 독립성 종류 | 설명 |
|------------|------|
| 논리적 데이터 독립성 | 논리 구조 변경이 응용 프로그램에 영향을 주지 않음 |
| 물리적 데이터 독립성 | 물리 구조 변경이 논리 구조에 영향을 주지 않음 |
| 물리적 저장 독립성 | 저장 방식이 변경되어도 데이터 접근 방식은 그대로 |

---

## ER 모델 (Entity-Relationship Model)

관계형 데이터베이스를 **설계하기 위한 도구**로 사용됩니다.

### 도서관 예시 ERD

```
BOOK ──────── AUTHOR
 │
 └──── COPY ──── BORROWER
           │
          LOAN
```

- 책(Book)은 한 명 또는 여러 저자(Author)가 쓸 수 있다.
- 도서관은 책의 한 권 또는 여러 권(Copy)을 보유할 수 있다.
- 각 권(Copy)은 한 번에 한 명의 대출자(Borrower)만 빌릴 수 있다.

## 엔티티(Entity)와 속성(Attribute)

| 구분 | 설명 | ERD 표현 |
|------|------|----------|
| 엔티티(Entity) | 데이터베이스에서 독립적으로 존재하는 객체 (사람, 장소, 사물) | **사각형** |
| 속성(Attribute) | 엔티티의 특성 또는 데이터 요소 | **타원** |

### Book 엔티티 예시

```
        [Book]
       /   |   \
[Title] [Edition] [Year] [ISBN]
```

- 엔티티 `Book` → 데이터베이스의 **테이블**이 됨
- 속성 `Title`, `Edition`, `Year`, `ISBN` → 테이블의 **열(Column)**이 됨

---

## 데이터 타입

| 데이터 타입 | 설명 | 예시 |
|------------|------|------|
| `CHAR(n)` | 고정 길이 문자 | ISBN (항상 같은 길이) |
| `VARCHAR(n)` | 가변 길이 문자 | Book Title (길이가 다양함) |
| `INTEGER` | 정수 | Edition, Year |
| `DECIMAL` | 소수점 숫자 | 가격 |
| `DATE` | 날짜 | 출판일 |
| `TIME` | 시간 | 대출 시간 |

> ISBN은 숫자뿐 아니라 `-`(대시)도 포함하므로 `CHAR` 타입을 사용합니다.

## 기본 키(Primary Key)와 외래 키(Foreign Key)

### 기본 키 (Primary Key)
- 테이블에서 각 행(Row/Tuple)을 **유일하게 식별**하는 열
- 데이터 중복 방지
- 테이블 간 관계 정의의 기준

### 외래 키 (Foreign Key)
- 다른 테이블의 기본 키를 참조하는 열
- 테이블 간 **연결(Link)** 역할
