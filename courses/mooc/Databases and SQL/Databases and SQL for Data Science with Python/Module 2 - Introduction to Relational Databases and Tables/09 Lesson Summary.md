## 핵심 개념 정리

| 개념 | 설명 |
|------|------|
| 데이터베이스(Database) | 데이터를 저장하는 저장소이며, 데이터 추가, 수정, 조회 기능을 제공합니다. |
| SQL | 관계형 데이터베이스에서 데이터를 조회하거나 검색하기 위해 사용하는 언어입니다. |
| 관계형 모델(Relational Model) | 데이터 독립성을 제공하기 때문에 데이터베이스에서 가장 많이 사용되는 데이터 모델입니다. |
| 기본 키(Primary Key) | 관계형 테이블의 각 튜플 또는 행을 고유하게 식별합니다. |
| SQL 문 유형 | SQL 문은 DDL과 DML 두 가지 범주로 나뉩니다. |

---

## 데이터베이스

데이터베이스는 데이터를 체계적으로 저장하는 저장소입니다.

데이터베이스는 단순히 데이터를 보관하는 것뿐 아니라 다음 기능을 제공합니다.

- 데이터 추가
- 데이터 수정
- 데이터 조회

---

## SQL

SQL은 관계형 데이터베이스에서 데이터를 다루기 위해 사용하는 언어입니다.

특히 데이터를 **조회(query)** 하거나 **검색(retrieve)** 할 때 사용됩니다.

```sql
SELECT * FROM table_name;
```

---

## 관계형 모델

관계형 모델은 데이터베이스에서 가장 널리 사용되는 데이터 모델입니다.

가장 큰 장점은 **데이터 독립성(data independence)** 입니다.

데이터 독립성이란 데이터의 저장 방식이나 구조가 일부 변경되어도, 데이터를 사용하는 애플리케이션에 미치는 영향을 줄일 수 있다는 의미입니다.

---

## 기본 키

기본 키는 관계형 테이블에서 각 행을 고유하게 식별하는 컬럼입니다.

기본 키의 역할은 다음과 같습니다.

| 역할 | 설명 |
|------|------|
| 행 식별 | 각 튜플 또는 행을 고유하게 구분 |
| 중복 방지 | 같은 기본 키 값을 가진 행이 중복되지 않도록 함 |
| 관계 정의 | 테이블 간 관계를 정의하는 기준으로 사용 |

---

## SQL 문 유형

SQL 문은 크게 두 가지 범주로 나뉩니다.

| 유형 | 전체 이름 | 목적 | 대표 명령어 |
|------|-----------|------|-------------|
| DDL | Data Definition Language | 데이터베이스 객체 정의 및 변경 | `CREATE`, `ALTER`, `DROP`, `TRUNCATE` |
| DML | Data Manipulation Language | 테이블 안의 데이터 조작 | `INSERT`, `SELECT`, `UPDATE`, `DELETE` |

---

## 핵심 요약

- 데이터베이스는 데이터를 저장하고 추가, 수정, 조회할 수 있게 해주는 저장소입니다.
- SQL은 관계형 데이터베이스에서 데이터를 조회하거나 검색하는 데 사용하는 언어입니다.
- 관계형 모델은 데이터 독립성을 제공하기 때문에 가장 널리 사용됩니다.
- 기본 키는 각 행을 고유하게 식별하고 중복을 방지하며 테이블 간 관계를 정의하는 데 사용됩니다.
- SQL 문은 DDL과 DML로 나뉩니다.
