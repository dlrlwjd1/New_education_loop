# Instructor Welcome and Course Introduction

- 강좌 전체 구조(3개 모듈)와 학습 목표를 소개하는 1분짜리 오리엔테이션 강의

## 내용

### 강좌 구성 (3개 모듈)

1. **ER 모델링(ER Modeling)** — 비즈니스 환경의 규칙을 ER 다이어그램(ER diagram)으로 시각적으로 표현하는 법
2. **함수 종속성(Functional Dependency)** — 중복 관계·중복 데이터를 점검하는 이론적 도구
3. **데이터베이스 정규화(Database Normalization)** — 잘 형성된 관계(well-formed relations)를 만들기 위한 절차

### 강좌의 목표

- 데이터가 "새로운 석유(data is the new oil)"인 시대에, 데이터의 저장·관리를 이해하는 조직이 큰 이익을 얻는다는 문제의식에서 출발
- ER 모델링 지식으로 비즈니스 규칙을 다이어그램으로 표현
- 함수 종속성과 정규화 지식으로 **중복 관계(redundant relationships)와 중복 데이터(redundant data)를 제거**
- 모든 데이터가 한 곳에만 저장되도록 보장 — 같은 데이터가 두 곳 이상에 저장되지 않게 설계
- 구현할 설계가 좋은 형태(good shape)를 갖추도록 하는 것이 최종 목표

## 요약

- 이 강좌는 ER 모델링 → 함수 종속성 → 정규화 순서의 3개 모듈로 구성된다.
- 핵심 목표는 중복 없는 잘 형성된 관계(well-formed relations)를 설계하는 것이다.
