# Canonical (Minimal) Cover of FDs

## 개요

- 정준 커버(canonical cover, Fc) = 최소 커버(minimal cover)의 정의와 조건
- 외적 속성(extraneous attribute)의 정의와 좌변·우변에서의 검사 방법
- Armstrong 공리의 추가 규칙: 합집합(union)·분해(decomposition)·의사이행(pseudo-transitivity)
- 정준 커버 계산 5단계와 전체 예제 풀이, 함수 종속성 다이어그램(FD diagram)

## 내용

### 정준 커버(Canonical Cover, Fc)

원래 FD 집합 F와 **같은 폐포를 갖는, 축소 불가능한(irreducible) 최소 FD 집합**. 조건:

1. F는 Fc의 모든 FD를 함의(imply)하고, Fc도 F의 모든 FD를 함의한다 (F ≡ Fc)
2. Fc의 어떤 FD에도 **외적(중복) 속성이 없다**
3. Fc의 모든 FD의 **좌변(결정자)은 유일**하다

### 외적 속성(Extraneous Attribute)

- 제거해도 원래 집합의 폐포가 변하지 않는 속성.
- 예: F = {AB → C, B → C}라면 B만으로 C를 결정하므로 AB → C의 **A는 외적** — 제약을 바꾸지 않고 안전하게 제거 가능.

**검사 방법** (FD `α → β`에 대해):

- **좌변(α)의 속성 A 검사**: A를 뺀 나머지 좌변의 폐포를 **원래 집합 F로** 계산한다. 그 폐포에 **A가 포함되면 A는 외적**이다.
  - (실전 요령: AD에서 A를 검사하려면 "형제" D의 폐포 D⁺를 구해, 지금 검사 중인 FD 없이도 같은 결정이 가능한지 본다)
- **우변(β)의 속성 A 검사**: 수정된 집합 `(F − {α → β}) ∪ {α → (β − A)}`로 α⁺를 계산한다. 그 폐포에 **A가 포함되면 A는 β에서 외적**이다.

### Armstrong 공리의 추가 규칙

- **합집합(union)**: α → β이고 α → γ이면 α → βγ (결정자가 같으면 종속자를 합칠 수 있다)
- **분해(decomposition)**: α → βγ이면 α → β이고 α → γ (합집합의 반대 — 각 구성요소를 개별적으로 결정)
- **의사이행(pseudo-transitivity)**: α → β이고 βγ → δ이면 αγ → δ (β ⊆ α 상황에서 α가 β를 대신할 수 있다)

### 정준 커버 계산 5단계

1. 모든 FD의 **우변에 분해 규칙 적용** — 우변을 단일(singleton) 속성으로 만든다
2. **좌변의 외적 속성 제거**
3. **중복(redundant) FD 제거** — FD를 하나씩 검사: 해당 FD를 제외한 나머지로 결정자의 폐포를 계산해, 종속자가 폐포에 포함되면 그 FD 전체가 중복이므로 제거
4. 최소 FD 집합 반환
5. 필요하면 **합집합 규칙 적용** — 같은 결정자를 가진 FD들을 합침

## 예시

R(A, B, C, D, E, F, G), 원래 집합 F = {AD → BF, CD → EGC, BD → F, E → D, F → C, D → F}

**1단계 — 우변 분해:**

AD → B, AD → F, CD → E, CD → G, CD → C, BD → F, E → D, F → C, D → F

**2단계 — 좌변 외적 속성 제거:**

- `AD → B`: A 검사 → D⁺ = {D, F, C, E, G} 계산(D → F, F → C, CD → E/G 경유). A가 폐포에 없음 → A 필요. D 검사 → A⁺ = {A} (A는 어디로도 못 감) → D 필요. **둘 다 유지**
- `AD → F`: 같은 방식으로 A, D 모두 외적 아님
- `CD → E`: C 검사 → D⁺를 구하면 D → F → C로 **C가 폐포에 포함** → **C는 외적** → `D → E`로 축소
- `CD → G` → 같은 논리로 `D → G`
- `CD → C` → `D → C`
- `BD → F`: B 검사 → D⁺ = {D, F, C, E, G}에 B 없음 → B 필요. D 검사 → B⁺ = {B}에 D 없음 → D 필요. **유지**
- 나머지(E → D, F → C, D → F)는 좌변이 단일 속성이라 검사 불필요

결과: {AD → B, AD → F, D → E, D → G, D → C, BD → F, E → D, F → C, D → F}

**3단계 — 중복 FD 제거** (검사 대상 FD는 제외하고 폐포 계산):

- `AD → B`: AD⁺ = {A, D, F, C, E, G} — B 없음 → **유지**
- `AD → F`: AD⁺ = {A, D, B, E, G, C, F} — F 포함 → **중복, 제거**
- `D → E`: D⁺ = {D, G, C, F} — E 없음 → 유지
- `D → G`: D⁺ = {D, E, C, F} — G 없음 → 유지
- `D → C`: D⁺ = {D, E, G, F} → F → C로 **C 포함** → **중복, 제거**
- `BD → F`: BD⁺ = {B, D, E, G, F} — **F 포함** → **중복, 제거**
- `E → D`: E⁺ = {E} — D 없음 → 유지
- `F → C`: F⁺ = {F} — C 없음 → 유지
- `D → F`: D⁺ = {D, E, G} — F 없음 → 유지

**4단계 — 반환:** {AD → B, D → E, D → G, E → D, F → C, D → F}

**5단계 — 합집합 규칙:** D를 결정자로 갖는 세 FD를 합침

> **Fc = {AD → B, D → EGF, E → D, F → C}**

이 최소 집합은 원래 집합 F와 논리적으로 완전히 동일한 제약을 함의한다.

### 함수 종속성 다이어그램(FD Diagram)

FD를 시각적으로 표현한 다이어그램. 예: R(A, B, C, D, E), FD = {AB → CDE, B → CD, D → E}

- **AB → CDE**: AB가 나머지 전 속성을 결정 → **기본 키**(밑줄 표시). 이것이 **바람직한(desired) 종속성**.
- **B → CD**: 키(AB)의 **일부**인 B가 C, D를 결정 → **부분 함수 종속(partial dependency)**
- **D → E**: 비프라임(non-prime) 속성 D(자신도 종속자)가 E를 결정 → **이행 종속(transitive dependency)**. 간접적으로 B → E가 성립한다.
- 화살표는 종속자를 가리킬 때만 그린다.

## 요약

- 정준 커버는 원래 FD 집합과 동치이면서 외적 속성과 중복 FD가 없는 최소 집합이다.
- 좌변 외적 속성은 "나머지 좌변의 폐포에 그 속성이 포함되는지"로, 중복 FD는 "그 FD를 뺀 집합으로 구한 결정자 폐포에 종속자가 포함되는지"로 검사한다.
- 계산 순서: 우변 분해 → 좌변 외적 속성 제거 → 중복 FD 제거 → 반환 → 합집합 적용.
- FD 다이어그램에서 부분 종속(키 일부가 결정자)과 이행 종속(비프라임이 결정자)을 시각적으로 식별할 수 있으며, 이것이 다음 주제인 정규화의 기반이 된다.
