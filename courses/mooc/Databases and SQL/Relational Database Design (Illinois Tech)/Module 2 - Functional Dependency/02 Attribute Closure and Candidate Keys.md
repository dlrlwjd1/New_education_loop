# Attribute Closure and Candidate Keys

## 개요

- 속성 폐포(attribute closure, X⁺)의 정의와 용도 — 키 판별, FD 유효성 검사
- Armstrong 공리(Armstrong's axioms)와 폐포 계산 알고리즘
- 폐포를 이용해 후보 키(candidate key)를 찾는 절차와 예제 풀이

## 내용

### 속성 폐포(Closure of Attributes)

- 표기: **X⁺** — X가 함수적으로 결정하는 **모든 속성의 집합** (X로부터 따라 나오는 모든 값 포함)
- 용도:
  1. **키 찾기** — "X는 관계 R의 키인가?"를 폐포로 확인
  2. **종속성 검증** — "X가 Y를 결정할 수 있는가?"(FD의 참/거짓)를 폐포로 확인

### 폐포 알고리즘 (Armstrong Axiom Closure Algorithm)

1. **초기화**: 폐포 집합을 주어진 속성 집합으로 초기화한다. (X⁺를 구한다면 첫 답은 X)
2. **반복**: 더 이상 추가할 속성이 없을 때까지, 모든 FD에 대해 반복한다 —
   - FD `Y → Z`의 **결정자 Y가 현재 폐포 집합의 부분집합이면**, 그 종속자 Z를 폐포 집합에 추가한다.
3. **반환**: 변화가 없으면 최종 폐포 집합을 반환한다.

### Armstrong 공리 (FD의 추론 규칙)

- **재귀성(reflexivity)**: Y ⊆ X이면 X → Y. (큰 집합이 결정자, 부분집합이 종속자)
- **증강(augmentation)**: X → Y이면 XZ → YZ. (결정자에 어떤 속성 집합을 덧붙이면 종속자에도 덧붙일 수 있다)
- **이행성(transitivity)**: X → Y이고 Y → Z이면 X → Z. (Y를 경유한 간접 결정)

## 예시

### 예제 1 — 폐포 계산

관계 R(A, B, C, D, E), FD 집합: `CE → D`, `D → B`, `C → A`

**CE⁺ 구하기:**

| 반복 | 폐포 | 근거 |
|---|---|---|
| 1 | CE | 초기화 (재귀성) |
| 2 | CED | `CE → D`: CE ⊆ {C,E} ✓ → D 추가 |
| 3 | CEDB | `D → B`: D ⊆ {C,E,D} ✓ → B 추가 |
| 4 | CEDBA | `C → A`: C ⊆ 폐포 ✓ → A 추가 |

→ **CE⁺ = {A, B, C, D, E}** (더 추가할 속성 없음)

**D⁺ 구하기:** 초기값 D → `CE → D`는 CE ⊄ {D}라 통과 → `D → B`로 B 추가 → `C → A`는 C ⊄ {D,B}라 통과 → **D⁺ = {B, D}**

**C⁺ 구하기:** 초기값 C → `C → A`만 적용 → **C⁺ = {A, C}**

### 예제 2 — 후보 키 판별

질문: "CE는 R의 키인가?" — 키란 R의 **모든 속성(A~E)을 유일하게 식별**하는 속성 집합이다.

1. 결정자들의 폐포를 모두 계산한다: CE⁺ = ABCDE, C⁺ = AC, D⁺ = BD
2. **폐포가 R의 모든 속성을 포함하는 것**이 키다 → CE⁺만 해당.
3. 후보 키 정의 확인 — **부분집합도 키가 되면 안 된다**:
   - C 단독: C⁺ = {A, C}로 전체를 결정하지 못함 → 키 아님
   - E는 결정자가 아니므로 검사할 필요 없음
   - D도 D⁺ = {B, D}로 키 아님
4. 결론: **CE는 유일한 후보 키**이며, 경쟁하는 키가 없으므로 설계자가 기본 키로 선택할 수 있다. (키는 슈퍼 키이기도 하다.)

추가 질문: "CE → DB는 성립하는가?" → CE⁺에 D, B가 모두 포함되므로 **성립**. 또는 CE가 유일한 후보 키(=기본 키)이므로 R의 어떤 속성 조합도 유일하게 결정한다고 답할 수 있다.

## 요약

- X⁺는 X가 결정하는 모든 속성의 집합으로, 키 판별과 FD 검증에 쓴다.
- 폐포 알고리즘: 주어진 집합으로 초기화 → 결정자가 폐포의 부분집합인 FD의 종속자를 계속 추가 → 변화 없으면 반환.
- Armstrong 공리는 재귀성·증강·이행성 세 규칙이다.
- 폐포가 관계의 전 속성을 포함하면 키이고, 어떤 진부분집합도 키가 아니면 후보 키다. 유일한 후보 키는 기본 키가 된다.
- 다음 강의는 최소 커버(minimal cover) = 정준 커버(canonical cover)다.
