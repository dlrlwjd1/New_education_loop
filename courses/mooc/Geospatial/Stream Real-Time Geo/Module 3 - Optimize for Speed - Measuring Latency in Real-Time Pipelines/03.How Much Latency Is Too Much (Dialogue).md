# Dialogue: How Much Latency Is Too Much? (지연시간은 어느 정도까지 허용될 수 있는가)

## 개요
- 지연시간을 단순히 측정하는 것을 넘어, 사용자의 필요와 운영상의 위험(operational risk)에 근거한 판단을 내리는 방법을 탐구하는 10분 분량 AI 대화형 실습 — Module 3 "Optimize for Speed: Measuring Latency in Real-Time Pipelines"의 세 번째 항목
- 이 항목은 학습자가 직접 답하며 진행하는 개인 실습형 대화이므로, 다루는 주제와 목적만 정리함

## 내용

### 다루는 주제
- **지연시간의 영향 이해하기(Understanding Latency's Impact)**: 지연시간이 사용자 경험과 의사결정에 어떻게 영향을 미치는지 논의함
- **필요와 가능성 구분하기(Distinguishing Needs from Possibilities)**: 기술적으로 달성 가능한 것과 운영상 반드시 필요한 것을 구분하는 법을 배움
- **데이터 기반 의사결정 내리기(Making Data-Driven Decisions)**: 데이터로 뒷받침되는 "충분히 좋은(good enough)" 결정을 내리는 연습을 함
- **트레이드오프 정당화하기(Justifying Trade-offs)**: 실제 프로덕션 시스템에서 트레이드오프를 설명하고 정당화하는 능력을 강화함

## 요약
- 이 Dialogue는 지연시간을 측정하는 것에서 그치지 않고, 사용자의 필요와 운영상의 위험을 근거로 "충분히 좋은" 수준을 판단하고 트레이드오프를 정당화하는 법을, 학습자가 직접 답하며 되짚어보게 함
