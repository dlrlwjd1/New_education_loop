# Landsat and Sentinel Basics

## 개요
- 유형: MOOC 읽기
- 원본: [Landsat and Sentinel Basics](https://www.mooc.org/learn/raster-processing-and-remote-sensing/supplement/Tw4vn/landsat-and-sentinel-basics)
- Landsat과 Sentinel-2를 공간 해상도, 재방문 주기, 밴드 구성과 시간 연속성으로 비교한다.

## 내용
- Landsat은 약 30m 해상도와 약 16일 주기로 장기간 일관된 기록에 강하다.
- Sentinel-2는 약 10~20m 해상도와 두 위성 기준 약 5일 주기로 더 세밀하고 잦은 관측에 유리하다.
- 센서 선택은 우열이 아니라 필요한 세부 수준과 갱신 빈도, 장기 비교 가능성으로 결정한다.

## 예시
수십 년 산림 변화는 Landsat, 생육기 농경지의 잦은 상태 갱신은 Sentinel-2를 우선 검토한다.

## 요약
- 도구를 실행하기 전에 입력 데이터와 분석 가정을 검증한다.
- 결과가 그럴듯하게 보이는 것보다 공간적·분석적 의미를 설명할 수 있는지가 중요하다.
