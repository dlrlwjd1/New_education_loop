# Why This Project Matters

## 개요
- 유형: MOOC 읽기
- 원본: [Why This Project Matters](https://www.mooc.org/learn/raster-processing-and-remote-sensing/supplement/pLSGN/why-this-project-matters)
- 두 시점 위성 영상에서 NDVI를 계산해 식생 변화를 탐지하는 최종 프로젝트의 업무 맥락을 설명한다.

## 내용
- 원시 영상의 NoData, 반사도 차이와 정렬 문제를 처리해 신뢰 가능한 지표로 바꾼다.
- 센서·밴드·공간 정렬·촬영 조건과 전처리의 비교 가능성을 확인한다.
- Rasterio, NumPy, NDVI, 변화 분류와 품질 보증을 하나의 Python 워크플로로 결합한다.

## 예시
산림 훼손·가뭄·토지 황폐화 후보를 찾되 가정과 한계를 의사결정자에게 함께 전달한다.

## 요약
- 도구를 실행하기 전에 입력 데이터와 분석 가정을 검증한다.
- 결과가 그럴듯하게 보이는 것보다 공간적·분석적 의미를 설명할 수 있는지가 중요하다.
