# Would You Send This to the Response Team?

## 개요
- 유형: MOOC 대화형 활동
- 원본: [Would You Send This to the Response Team?](https://www.mooc.org/learn/raster-processing-and-remote-sensing/coach/Q1xnv/would-you-send-this-to-the-response-team)
- 수집 상태: 학습자 응답에 따라 내용이 달라지는 대화형 활동이므로 임의의 답변을 만들지 않고 항목과 링크만 기록했다.

## 내용
- 실제 수강 시 MOOC 페이지에서 직접 수행한다.
- 완료 여부는 GIS 로드맵의 체크리스트에서 관리한다.

## 예시
- 해당 없음

## 요약
- 커리큘럼 순서와 원본 링크를 보존한 상태 문서다.
