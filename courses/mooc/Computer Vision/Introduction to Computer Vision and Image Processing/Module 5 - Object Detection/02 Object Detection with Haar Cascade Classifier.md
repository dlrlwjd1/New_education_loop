# 02 Object Detection with Haar Cascade Classifier

## 개요
- 강좌: Introduction to Computer Vision and Image Processing (IBM)
- 모듈: Module 5 — Object Detection
- ⭐⭐ **Viola-Jones(2001) Haar cascade** — ⭐ **적분 이미지 · AdaBoost · 캐스케이드** 세 가지 아이디어. **딥러닝 이전의 고전적 객체 탐지**.

---

## 내용

### 방법의 배경 ⭐
> **P. Viola와 M. Jones가 2001년에 제안한 방법이다.**
>
> ⭐ **머신러닝 방법으로, 캐스케이드 함수가 다수의 양성 이미지(positive images, 탐지하려는 객체를 포함)와 음성 이미지(negative images, 즉 배경)로 훈련된다.**
>
> **이 이미지에서 자동차·신호등·보행자·정지 표지판 등을 탐지하는 데 쓴다.**

### Haar 웨이블릿(wavelets) ⭐
> **Viola와 Jones는 Haar 특징 분류기에 Haar 웨이블릿의 아이디어를 썼다.**
>
> **수백만 장의 훈련 이미지가 시스템에 입력되면 분류기는 각 이미지에서 특징을 추출하기 시작한다.**
>
> ⭐ **Haar 웨이블릿은 특징을 추출하는 데 쓰는 합성곱 커널이다. 에지·선·대각선 에지에 대한 정보를 추출한다.**

### ① ⭐⭐ 적분 이미지(integral image)
> ⭐⭐ **각 픽셀은 그 픽셀의 위쪽과 왼쪽에 있는 대응 입력 픽셀들의 누적 합을 나타낸다.**

**계산 예시**
| 대상 | 계산 | 결과 |
|---|---|---|
| **첫 픽셀** | **왼쪽과 위에 아무것도 없으므로 자기 자신만** | **1** |
| **두 번째 픽셀** | **왼쪽의 1 + 자기 자신 2** | **3** |
| **다른 픽셀** | **2, 4, 1, 3, 2 그리고 자기 자신 3** | **15** |

> ⚠️ **Viola-Jones 논문은 24×24 기본 창 크기를 예로 썼는데, 그것만으로 적분 이미지에서 18만 개가 넘는 특징이 계산된다.**

### ② ⭐⭐ AdaBoost — 특징을 추린다
> ⭐ **알고리즘은 AdaBoost를 사용해 큰 집합에서 소수의 중요한 특징만 골라 매우 효율적인 분류기를 만든다.**
>
> ⭐⭐ **아이디어는 분류기와 표본 양쪽에 가중치를 설정해, 분류기가 올바르게 분류하기 어려운 관측에 집중하도록 강제하는 것이다. 따라서 분류기 정확도를 개선하는 데 도움이 되는 특징만을 선택해, 약한 분류기(weak classifiers)의 선형 결합인 강한 분류기(strong classifier)를 구성한다.**

**고양이·개 예시**
```
각 약한 분류기는 적어도 50% 정확도로 예시를 나눈다
  ↓ ⭐ 오분류된 예시가 다음 라운드에서 강조된다
분류기와 표본에 가중치를 두어 오분류된 관측에 집중하게 만든다
  ↓ 오차 수가 최소화될 때까지 반복
강한 분류기 = 약한 분류기들의 선형 결합
```

> ⭐⭐ **24×24 창 예시에서 18만 개가 넘는 특징이 생성됐는데, AdaBoost를 쓰면 약 6,000개로 줄어든다.**

### ③ ⭐⭐ 분류기의 캐스케이드(cascade)
> ⭐⭐ **이 분류기는 입력 이미지의 하위 이미지들을 단계(stage)별로 묶고, 탐지하려는 객체와 맞지 않는 영역은 무시한다.**

```
이미지의 자동차를 탐지하려면:
  ① 분류기가 특징을 여러 하위 이미지로 묶는다
  ② 각 단계의 분류기가 그 하위 이미지가 우리가 찾는 객체인지 판정한다
  ③ ⭐ 아니면 그 하위 창은 그 안의 특징들과 함께 버려진다
  ④ 하위 창이 분류기를 통과하면 다음 단계로 가서 두 번째 단계 특징이 적용된다
  ⑤ 자동차임이 확실해질 때까지 계속된다
```

> ⭐ **이 "빨리 버리는" 구조가 Haar cascade를 빠르게 만든다.**

## 요약
- **Viola-Jones(2001)** — ⭐ **양성 이미지(객체 포함)와 음성 이미지(배경)** 로 캐스케이드 함수를 훈련하는 머신러닝 방법.
- **Haar 웨이블릿 = 에지·선·대각 에지 정보를 뽑는 합성곱 커널.**
- ⭐⭐ **① 적분 이미지 — 각 픽셀이 왼쪽·위쪽 픽셀들의 누적 합.** 24×24 창에서 **18만 개 이상의 특징**이 나온다.
- ⭐⭐ **② AdaBoost — 오분류된 관측에 집중하도록 가중치를 두고, 약한 분류기들의 선형 결합으로 강한 분류기를 만든다.** **18만 → 약 6,000개로 특징을 줄인다.**
- ⭐⭐ **③ 캐스케이드 — 단계별로 판정해 아니면 즉시 버린다.** 이것이 속도의 비결이다.
