## 내용

### ⭐⭐ 세 과제의 구분
| 과제 | 하는 일 |
|---|---|
| **이미지 분류(classification)** | **이미지 속 객체의 클래스를 예측**한다 |
| **분류 + 위치 파악(localization)** | **객체의 존재를 찾아내고 바운딩 박스로 위치를 표시**한다 |
| ⭐⭐ **객체 탐지(object detection)** | **여러 객체를 바운딩 박스와 그 클래스로 찾아낸다** |

### 슬라이딩 윈도우(sliding window) ⭐⭐
> **객체 탐지 문제에서는 일반적으로 이미지 안의 가능한 모든 객체를 찾아야 한다. 이를 위해 슬라이딩 윈도우 탐지라는 알고리즘을 쓴다.**
>
> **개를 탐지하려면 고정된 창 크기를 정한다. 잘 고르면 개가 창의 대부분을 차지한다. 이것이 본질적으로 우리가 개로 분류하고 싶은 하위 이미지다.** ⭐ **개를 포함하지 않는 다른 하위 이미지들은 배경(background) 클래스로 분류된다.**

**알고리즘** ⭐
```
① 이미지의 한 영역에서 시작해 그 하위 이미지를 분류한다
② 창을 옆으로 옮겨 다음 하위 이미지를 분류한다
③ 반복한다
④ 수평 경계에 닿으면 수직 방향으로 몇 픽셀 내려가 반복한다
⑤ 객체가 창의 대부분을 차지하면 개로 분류된다
```

### ⚠️⚠️ 객체 탐지 고유의 문제들
분류의 문제([Module 3 01](../Module%203%20-%20Machine%20Learning%20Image%20Classification/01%20Introduction%20to%20Image%20Classification.md)의 다섯 가지)에 더해:

| 문제 | 설명 | 해법 |
|---|---|---|
| ⚠️ **겹치는 탐지** | **객체 탐지기가 겹치는 탐지를 여럿 출력하는 경우가 많다** | 아래의 점수 임계 |
| ⚠️ **객체 크기** | **같은 객체가 다른 크기로 나타난다** | ⭐ **이미지를 reshape** |
| ⚠️ **객체 형태** | **같은 객체가 다른 형태를 가질 수 있다** | ⭐ **reshape 또는 resize** |
| ⚠️ **겹치는 객체** | **사진 속 객체들이 서로 겹친다** | 슬라이딩 윈도우에 문제가 될 수 있다 |

### 바운딩 박스(bounding box) ⭐⭐
> ⭐ **바운딩 박스는 또 다른 객체 탐지 방법이다. 독립적으로 쓸 수도, 슬라이딩 윈도우나 더 고급 방법과 함께 쓸 수도 있다.**

**두 가지 표현 방식**
```
① 사각형의 우하단 좌표 (y₀, x₀) + 너비 + 높이
② ⭐ 좌상단 (y_min, x_min) + 우하단 (y_max, x_max)
```
> ⚠️ **여기서의 `y`와 `x`는 분류 레이블 `y`, 이미지 `x`와 다르다.** 강의에서는 구분을 위해 파란색으로 칠했다. **이것들은 우리가 `box`라 부르는 바운딩 박스의 좌표일 뿐이다.**
>
> 예: **좌상단 (0, 1), 우하단 (7, 8).** ⭐ **객체 탐지의 목표는 이 점들을 예측하는 것이므로 예측임을 나타내려고 모자(hat)를 붙인다.**

### 바운딩 박스 파이프라인 ⭐
```
분류처럼 클래스 y와 이미지 x가 있고, 여기에 바운딩 박스가 추가된다
  ↓
클래스와 바운딩 박스로 이루어진 데이터셋
  ↓
데이터셋으로 모델을 훈련한다 (박스 좌표를 포함해서)
  ↓
학습 파라미터가 갱신된 객체 탐지기
  ↓
탐지하려는 객체가 있는 이미지를 입력
  ↓
예측 클래스 + 박스 좌표
  (개 + 좌표 / 고양이 + 좌표 / 새 + 좌표 / 새 + 좌표 …)
```

### ⭐⭐ 점수(score) — 신뢰도
> ⭐ **많은 객체 탐지 알고리즘이 점수를 제공해 모델 예측이 얼마나 확신하는지 알려 준다.** 점수 범위는 **0에서 1**이다.

| 예측 | 점수 | 해석 |
|---|---|---|
| **개라고 예측했지만 이미지가 개처럼 안 보임** | ⚠️ **0.5** | **모델이 자기 예측을 확신하지 못한다** |
| **개라고 예측했고 이미지가 개처럼 보임** | ⭐ **0.99** | **모델이 확신한다** |

**점수 임계의 실제 효과** ⭐⭐
> **개 한 마리와 고양이 두 마리를 탐지했다고 하자. 개의 위치에서 고양이와 개를 둘 다 탐지한 것처럼 보인다. 점수를 살펴보니 고양이 예측 중 하나가 0.5로 낮다.**
>
> ⭐⭐ **0.9 이상의 점수만 받아들이면 고양이와 개를 올바르게 탐지한다.**
>
> **보통 모델은 특정 임계 이상의 객체만 출력한다.**

## 요약
- ⭐⭐ **분류 → 분류+위치 파악 → 객체 탐지(여러 객체 + 박스 + 클래스).**
- **슬라이딩 윈도우** — 고정 크기 창을 옮기며 각 하위 이미지를 분류. **객체가 없으면 배경 클래스.**
- ⚠️⚠️ **탐지 고유의 문제: 겹치는 탐지 · 객체 크기 · 객체 형태 · 겹치는 객체.** 크기·형태는 **reshape/resize**로 다룬다.
- **바운딩 박스**: `(좌상단, 우하단)` 또는 `(우하단, 너비, 높이)`. 예측이므로 `hat`을 붙인다.
- **파이프라인 = 클래스+박스 데이터셋 → 훈련 → 탐지기 → 이미지 입력 → 클래스+박스 출력.**
- ⭐⭐ **점수(0~1)가 신뢰도다.** **임계(예: 0.9)를 걸어 겹치는 오탐을 걸러 낸다.**
