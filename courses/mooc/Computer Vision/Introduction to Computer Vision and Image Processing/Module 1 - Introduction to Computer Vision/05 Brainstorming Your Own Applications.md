# 05 Brainstorming Your Own Applications

## 개요
- 강좌: Introduction to Computer Vision and Image Processing (IBM)
- 모듈: Module 1 — Introduction to Computer Vision
- ⭐⭐ **컴퓨터비전 응용을 발상하는 방법** — 해법이 아니라 **문제에서 출발한다.**

---

## 내용

### ⭐⭐ 발상의 원칙 — 해법이 아니라 문제에서 시작한다
> **해법이 아니라 이미 존재하는 문제에서 시작하는 것이 가장 도움이 된다.**

| ❌ 해법에서 출발 | ✅ 문제에서 출발 |
|---|---|
| **"컴퓨터비전으로 여러 음식을 인식하고 싶다"** | ⭐ **"시각장애인은 식료품점에서 음식을 식별하기 어렵다. 컴퓨터비전으로 그 문제를 어떻게 다룰 수 있을까?"** |

### 산업별로 좁혀 문제 찾기 ⭐
> **산업별로 좁혀 보면 도움이 된다. 우리가 공감하기 쉬운 것부터 시작하자.**

| 산업 | 문제 |
|---|---|
| **의학** | **가장 어렵고 시간이 오래 걸리는 일 하나 — 암을 정확히 탐지하도록 의사를 훈련시키는 것.** 그 전문성을 훈련하고 개발하는 것 |
| **운전** | **모든 것을 동시에 볼 수는 없다. 운전은 지속적으로 집중된 시각적 주의를 요구하고 실수의 결과가 꽤 심각하다.** 게다가 **장거리 운전자는 운전대에서 잠들기 쉽다** |
| **보안·감시** | **수 시간 분량의 영상에서 용의자를 찾는 데 많은 시간이 든다.** 또 **공항 X선에서 위험물을 탐지하는 것은 어렵고, 실수의 결과가 상당한 보안 위험**이다 |
| **제조** | **어떤 공급망에서는 수천~수만 개 제품이 조립된다. 각 품목이 고품질인지 확인하는 것은 매우 어렵고 노동집약적**이다 |
| **보험·산업안전** | **건설 근로자가 중장비를 다룰 때 적절한 안전모·장비·조끼를 착용하지 않는 경우가 자주 발견된다.** 컴퓨터비전으로 준수 여부를 어떻게 보장할까? |
| **보험(자동차)** | **사고는 늘 일어나지만 각 차량의 손상을 평가하는 데 시간과 전문성이 든다.** 게다가 **교체 비용을 정하려면 차의 제조사·모델·연식 등에 따라 달라진다** |

### ⭐ 더 쉽게 시작하는 법 — 내 주변의 문제
> **직장에서, 집에서, 친구들과 겪는 문제를 생각해 보라.**
>
> - **반품·교환하려는 물건의 영수증을 못 찾는 문제가 있는가?**
> - **뒷마당에 어떤 식물이 있는지 궁금하거나, 집에서 키우는 식물의 성장을 어떻게 추적할지 궁금한 적이 있는가?**
> - **쥐 문제가 있는가? 혹은 (캐나다 토론토처럼) 쓰레기통에 뛰어드는 너구리 문제가 있는가?**

> ⭐ **컴퓨터비전의 가능성은 무궁무진하다. 내 삶, 친구의 삶, 내 일을 더 낫거나 편하게 만들 수 있는지 주변에 물어보기 시작하라.**

---

## 요약
- ⭐⭐ **해법("X를 인식하고 싶다")이 아니라 문제("누가 X 때문에 곤란을 겪는다")에서 시작한다.**
- **산업별로 좁히면 문제가 보인다** — 의학(암 진단 훈련), 운전(지속적 주의·졸음), 보안(영상 수색·X선 위험물), 제조(품질 검사), 보험(안전장비 착용·차량 손상 사정).
- **거창할 필요 없다** — 영수증 찾기, 식물 종류·성장 추적, 너구리 쓰레기통 습격 같은 일상 문제도 좋은 출발점이다.
