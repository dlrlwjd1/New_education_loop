# 01 Course Introduction

## 개요
- 강좌: Introduction to Computer Vision and Image Processing (IBM)
- 모듈: Module 1 — Introduction to Computer Vision
- 강좌 전체가 무엇을 다루고, 무엇을 준비해야 하는지 안내한다.

---

## 내용

### 이 강좌가 다루는 것 ⭐
> **의료 스캔, 공장 제품, 실시간 보안 위협 같은 시각 데이터를 컴퓨터가 분석하는 분야를 상상해 보라. 어려움은 이미지를 찍는 데 있는 것이 아니라 그것을 빠르고 정확하게 해석하는 데 있다.**

| 단계 | 내용 |
|---|---|
| **① 핵심 개념** | 컴퓨터비전의 실세계 응용. **스마트폰 사진 개선부터 의료 진단 보조까지, 영상처리가 비전 과제의 토대**임을 본다 |
| **② 영상처리 실습** | ⭐ **OpenCV와 Pillow**로 이미지를 처리·분석하고 분류를 위해 준비한다 |
| **③ 머신러닝 분류** | **k-최근접이웃(KNN) · 로지스틱 회귀 · Softmax · 서포트 벡터 머신(SVM)** 으로 이미지 분류기를 만든다 |
| **④ 딥러닝** | **신경망과 CNN** — 층과 활성 함수 같은 핵심 구성요소, **LeNet과 ResNet** 같은 아키텍처 |
| **⑤ 객체 탐지** | ⭐ **Haar cascade**로 객체를 탐지하고 그 효과를 평가한다 |

### 선수 지식 ⭐
> **시작하는 데 필요한 것은 파이썬 기초 이해와 고등학교 수준 수학뿐이다. 머신러닝이나 컴퓨터비전의 사전 경험은 필요 없다.**

### 최종 프로젝트
> ⭐ **자율주행차를 위한 정지 표지판 탐지기 설계** — 실세계 과제를 시뮬레이션한다. 강좌는 **클라우드에 커스텀 컴퓨터비전 앱을 만들어 배포하는 것**으로 마무리된다.

### 대상 학습자
**컴퓨터비전 진로를 탐색하는 학생·졸업생**, **영상처리 전문성을 쌓는 초기 경력자**, **시각 컴퓨팅으로 확장하는 개발자·데이터 분석가**, **실습 경험을 찾는 연구자**, **시각 데이터 분석으로 전향하는 사람**.

### 학습 방법 안내
> **각 영상을 보고, 읽기 자료를 훑고, 모든 실습 랩(hands-on lab)을 완료하고, 연습·채점 퀴즈로 학습을 점검하라.**

---

## 요약
- 강좌 흐름: **컴퓨터비전 개념 → OpenCV·Pillow 영상처리 → ML 이미지 분류(KNN·로지스틱·Softmax·SVM) → 신경망·CNN(LeNet·ResNet) → Haar cascade 객체 탐지 → 최종 프로젝트.**
- ⭐ **선수 지식은 파이썬 기초 + 고등학교 수학**뿐이다.
- **최종 프로젝트는 자율주행차용 정지 표지판 탐지기.**
- ⚠️ **강좌의 상당 부분이 영상이 아니라 실습 랩**이다.
