---

## 내용

### 사례 ① 영상 검색 ⭐
> **영화의 특정 장면을 찾으려고 빨리 감기로 이리저리 건너뛴 적이 있는가? 내 영상들이 검색 가능해진다면?**
>
> **IBM은 각 장면에 등장하는 객체를 기준으로 영상에 키워드를 태깅하는 예시를 만들었다.**
>
> ⭐ **수 시간 분량의 영상에서 파란 밴을 탄 용의자를 찾아야 하는 보안 회사를 생각해 보라. 컴퓨터비전과 객체 인식으로 영상을 뒤지는 일은 과거의 것이 됐다.**

### 사례 ② 송전탑 녹 점검 — ⭐⭐ 분류기 두 개를 잇는 설계
⚠️ **문제**: **탑에 직접 올라 구석구석 살피는 것은 극도로 시간과 비용이 많이 든다. 전선 주변에 드론을 띄우는 것도 특별히 안전해 보이지 않는다.**

⭐⭐ **해법 — 단계별 파이프라인**
```
① 지상에서 여러 각도의 고해상도 이미지를 찍는다
② 이미지를 더 작은 이미지들의 격자(grid)로 자른다
③ 커스텀 분류기 A — 금속 구조물 / 다른 구조물 / 비금속 객체를 구분
   → 이미지의 어느 영역이 금속인지 판정
④ ⚠️ 금속을 탐지하는 것만으로는 부족하다
   커스텀 분류기 B — 구조 기준에 따라 녹의 등급 판정
   (예: 등급 1 = 아주 미미한 녹 … 등급 6 = 심각한 녹)
⑤ 금속으로 판정된 영역의 이미지를 두 번째 분류기에 통과시켜 녹 등급을 정한다
```
> ⭐ **금속 분류기와 녹 분류기를 수천~수백만 장의 이미지에 확장 적용하면 보험사가 수백만 달러를 아낄 수 있다.**
>
> **또 다른 활용법은 관심 영역을 이미지 위에 직접 매핑하는 것이다** — 녹슨 다리 사진처럼 **격자 형태의 히트맵**으로 어느 영역이 녹으로 분류되는지 표시한다.

### 사례 ③ 보험 손해 사정 ⭐
> ⚠️ **보험사는 청구의 심각도를 등급 매기는 문제를 자주 겪는데, 사람이 분류하기 다소 어렵다.** 예컨대 왼쪽 이미지는 폭풍 중 우박과 얼음 알갱이로 생긴 작은 손상 영역을 담고 있다.
>
> ⭐ **컴퓨터비전을 쓰면 손상을 훨씬 쉽게 분류할 수 있고, 각 보험 청구를 처리하는 데 드는 시간과 비용을 크게 아낄 수 있다.**

---

## 요약
- **영상 검색** — 장면의 객체로 키워드 태깅. 보안 영상에서 용의자 찾기가 쉬워진다.
- ⭐⭐ **송전탑 녹 점검이 이 강의의 핵심 설계 교훈**이다 — **이미지를 격자로 자르고 → 금속 분류기 → 녹 등급 분류기** 로 **분류기를 이어 붙인다.** 한 개의 만능 모델이 아니다.
- **보험 손해 사정** — 손상 심각도 등급을 자동 분류해 처리 시간·비용을 줄인다.
