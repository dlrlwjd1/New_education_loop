> 이 강의는 **1채널 표현**으로 보여 주지만, 별도 언급이 없으면 **각 채널에 동시에 적용**할 수 있다.

---

## 내용

### 좌표계 ⭐
> **이미지를 `Y`와 `X`의 함수로 다룬다. `Y`는 수직 방향, `X`는 수평 방향이다. X와 Y는 실수지만 정수 점만 표본으로 삼는다(예: 점 (0,0), (1,1)).**
>
> ⭐ **기하 변환에서는 이미지의 좌표 X와 Y를 바꾼다.** 새 이미지 `G`는 `X'`와 `Y'`의 함수이고, **`G(X', Y')`는 X, Y에서 매핑된 값에 대응하는 `F`의 값을 가진다.**
>
> **여기서 다루는 것은 기하 변환의 부분집합인 아핀 변환(affine transformations)이다.**

### ① 스케일링(scaling) ⭐⭐
> **스케일링은 이미지를 재구성하는 것이다. 수평·수직 방향으로 축소하거나 확대할 수 있다.**

**X축 스케일링** — 스케일 인자를 `A`라 하자. `A = 2`면:
```
G(Y, 2X) = F(Y, X)
```
> **이미지 G의 값들은 이미지 F에 비해 늘어난 것처럼 보인다.**

| 원본 점 | 변환 후 |
|---|---|
| (0, 0) | **변화 없음** |
| (0, 5) | **X 좌표가 5 → 10** |
| (5, 0) | **변화 없음** |
| (5, 5) | **(5, 10)** |

**Y축(수직) 스케일링** — 수직 스케일 인자를 `D`라 하자. `D = 2`면 (5,0) → (10,0), (5,5) → (10,5). **이미지가 수직 방향으로 늘어난다.**

> ⚠️ **A나 D가 1보다 작으면 이미지가 축소된다.** (강의 자막은 "0보다 작으면"이라 말하지만 문맥상 축소는 1 미만일 때다.)

### ⭐⭐ 보간(interpolation) — 늘리면 빈칸이 생긴다
> **F의 첫 열이 G의 첫 열로, F의 두 번째 열이 G의 세 번째 열로 매핑된다. 그러면 G의 여러 열이 F에 대응하는 값이 없다.**
>
> ⭐⭐ **알 수 없는 픽셀 값을 정하기 위해 보간을 쓴다. 보간은 이웃 픽셀을 이용해 미지 픽셀의 값을 정하는 것이다.**
>
> **여기서는 최근접 이웃(nearest neighbors)을 썼다 — 가장 가까운 픽셀을 기준으로 값을 배정한다. PIL과 OpenCV가 쓰는 다른 방법들도 있다.**

### ② 평행이동(translation) ⭐
> **평행이동은 이미지를 옮기는 것이다.**
```
X' = X + Tx      (수평 이동)
Y' = Y + Ty      (수직 이동)
```
> ⚠️ **가장자리에 있던 픽셀은 0 값으로 대체된다. 이동된 픽셀을 포함하려면 이미지 크기를 키울 수 있다.**

### ③ 아핀 변환 행렬 ⭐⭐
> **기하 변환을 방정식의 집합으로 표현할 수 있고, 그 방정식을 행렬 형태로 놓으면 아핀 변환 행렬을 얻는다. OpenCV에서는 이 행렬을 배열로 입력한다.**

```
M = [[A,  0, Tx],
     [0,  D, Ty]]          # 스케일 A·D, 이동 Tx·Ty
```

### ④ 회전(rotation) ⭐
> **각도 `θ`만큼 이미지를 회전할 수 있다(빨간 선이 원래의 수평·수직 축). 비슷한 행렬을 쓴다. 이 회전 행렬은 반시계 방향 회전을 수행한다.**
>
> ⚠️ **행렬의 식은 꽤 복잡하다.** 그래서 단순화한다 — ⭐ **등방 스케일 인자 `R`을 1로 두고, 이미지 중심을 기준으로 회전한다고 가정한다. 이 가정을 하면 PIL과 OpenCV 같은 라이브러리는 파라미터 `θ`만 요구한다.**

## 예시

### PIL
```python
# 스케일링 — ⚠️ 정수 픽셀 수로 지정한다
new_image = image.resize((width * 2, height))    # 너비를 두 배로
# 축소도 되지만 입력은 정수여야 한다

# 회전 — 입력은 회전시킬 각도
new_image = image.rotate(45)
```

### OpenCV ⭐
```python
import cv2

# 스케일링 — ⭐ 스케일 인자가 정수일 필요가 없다. 1보다 작아도 된다
new_image = cv2.resize(image, None, fx=2, fy=1,
                       interpolation=cv2.INTER_NEAREST)   # 보간법 지정 가능
# fx=2, fy=1 → 수평축만 2배, 수직축은 그대로

# 평행이동 — 아핀 변환 행렬 M이 필요하다
tx, ty = 100, 0
M = np.float32([[1, 0, tx],
                [0, 1, ty]])          # 스케일 인자는 1로 둔다
new_image = cv2.warpAffine(image, M, (cols, rows))   # 세 번째 인자는 출력 이미지의 shape

# 회전 — 회전 행렬을 얻는다
M = cv2.getRotationMatrix2D(center=(cols//2, rows//2), angle=theta, scale=1)
new_image = cv2.warpAffine(image, M, (cols, rows))
#   center = 원본에서 회전의 중심
#   scale  = 1
```

## 요약
- ⭐ **아핀 변환 = 스케일링 · 평행이동 · 회전.** 이미지 좌표 `(X, Y)`를 `(X', Y')`로 바꾼다.
- **스케일링**: `A`(수평)·`D`(수직) 인자. **1보다 작으면 축소.**
- ⭐⭐ **늘리면 대응 값이 없는 칸이 생긴다 → 보간이 필요하다.** 강의는 **최근접 이웃**을 쓴다.
- **평행이동**: `X+Tx`, `Y+Ty`. ⚠️ **가장자리 픽셀은 0으로 채워지고**, 잘리는 것을 막으려면 출력 크기를 키운다.
- ⭐⭐ **아핀 변환 행렬 `M = [[A,0,Tx],[0,D,Ty]]`** 를 `cv2.warpAffine`에 넣는다.
- **회전**은 식이 복잡하지만 **스케일 1 + 중심 기준**으로 가정하면 **`θ`만 주면 된다.** `cv2.getRotationMatrix2D(center, angle, scale)`.
- ⚠️ **PIL `resize`는 정수 픽셀 수, OpenCV `resize`는 실수 스케일 인자**를 받는다.
