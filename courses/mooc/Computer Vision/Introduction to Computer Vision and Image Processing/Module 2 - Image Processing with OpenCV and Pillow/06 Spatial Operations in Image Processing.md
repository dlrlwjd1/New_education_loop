## 내용

### 공간 연산이란 ⭐⭐
> ⭐ **공간 연산은 이웃(neighborhood)으로 이루어진다.** 예컨대 **2×2 픽셀 이웃**을 잡고, **그 이웃의 각 픽셀을 포함하는 함수를 적용해 결과를 출력**한다. 그다음 **이웃을 옮겨 이미지의 각 픽셀에 대해 이 과정을 반복**한다.
>
> **결과는 특성이 강화된 새 이미지다. 이 공간 연산들은 이미지의 공간적 패턴을 활용한다.**

### ① 합성곱(convolution) = 선형 필터링 ⭐⭐
> **합성곱 또는 선형 필터링은 이미지를 필터링하는 표준적인 방법이다.** ⭐ **필터를 커널(kernel)이라 부른다. 커널이 다르면 다른 작업을 수행한다.**
>
> **합성곱은 이 선형 방정식과 유사하다** — **입력은 이미지 `x`, 출력은 또 다른 이미지 `z`, 파라미터 `w`가 커널(필터)이다.**

```
z = w * x        (*는 합성곱)
```

**동작 방식** ⭐⭐
```
① 이미지의 모서리에서 시작해 커널을 그 영역에 겹친다
② 이미지의 모든 원소를 커널의 대응 원소와 곱한다
③ 행마다 곱하고 더한 결과를 전부 합친다 → 출력 이미지 z의 첫 원소
④ 커널을 한 열 옆으로 옮겨 같은 연산 → z의 두 번째 원소
⑤ 열 끝까지 가면 커널을 아래로 내려 반복 → 새 이미지 완성
```

**⚠️ 크기 문제와 패딩(padding)** ⭐
> ⚠️ **문제 하나는 두 이미지의 크기가 달라진다는 것이다. 이미지 `x`의 크기를 바꿔 이를 고칠 수 있다 — 패딩으로 크기를 바꾼다.**
>
> - **제로 패딩(zero padding)**: **0으로 된 행 2개와 열 2개를 추가**한다.
> - **경계 값 복제(replicate)**: 테두리의 값을 그대로 복제한다.

### ② 저역 통과 필터(low pass filter) — 잡음 제거 ⭐
> ⭐ **저역 통과 필터는 이미지를 부드럽게(smooth) 만들어 잡음을 없애는 데 쓴다.**
>
> **평활 필터는 이웃 안의 픽셀들을 평균 낸다. 그래서 저역 통과 필터라고도 부른다. 평균 필터링(mean filtering)에서는 커널이 단순히 이웃의 값을 평균한다.**

**커널이 영역마다 하는 일** ⭐
| 영역 | 결과 |
|---|---|
| **평탄한 영역** | **강도값이 그대로 유지된다** |
| **상자의 가장자리 주변** | ⚠️ **255가 0들과 평균되어 값이 바뀐다** |
| **잡음 픽셀이 있는 영역** | ⭐ **잡음 값이 작아진다** |

> ⚠️⚠️ **원본과 출력을 비교하면 잡음의 강도는 줄었지만 에지가 덜 선명해졌다. 일반적으로 선명함(sharpness)과 부드러움(smoothness) 사이에 트레이드오프가 있다.**

### ③ 에지 검출(edge detection) ⭐⭐
> ⭐⭐ **에지 검출은 많은 컴퓨터비전 알고리즘에서 중요한 첫 단계다. 디지털 이미지에서 에지는 이미지 밝기가 급격히 변하는 곳이다. 에지 검출은 도함수와 그래디언트를 근사하는 방법으로 이런 영역을 식별한다.**

**직관** ⭐
> **한 행의 강도값을 그려 보자. 가로축은 열 인덱스, 세로축은 강도값이다.**
> - **픽셀 1에서 2로 오른쪽으로 움직일 때 강도값이 증가하면** → **벡터로 표현**한다.
> - **픽셀 2에서 3으로 갈 때 강도값이 감소하면** → **반대 방향을 가리키는 벡터**.
> - ⭐ **벡터의 방향이 이웃 픽셀이 증가하는지를 나타낸다.**

**차분 방정식**
```
같은 행 i에서 인접한 열 j와 j+1의 강도값을 뺀다
→ x 방향 그래디언트의 근사
```

**⭐⭐ Sobel 연산자**
> **합성곱으로 비슷한 수평 도함수 근사를 수행할 수 있다. 수평 변화(그래디언트)는 이미지를 커널과 합성곱해 계산한다.** ⭐ **이 커널들을 Sobel 연산자(Sobel operators)라 한다.**
>
> **출력을 강도 배열 `g_x`로 표현하면, 수평 에지에 해당하는 원소를 제외한 모든 값이 0이다. 이 이미지에서 회색 값은 범위가 다르다 — 검정은 음수, 회색은 0, 흰색은 양수.** 이것이 앞서 논의한 벡터를 나타낸다.
>
> **같은 과정으로 수직 변화를 찾으면 `g_y`를 얻고, 이번에는 벡터가 수직 방향을 가리킨다.**

**⭐ 두 필터의 출력을 합치기**
> **각 필터의 출력을 하나의 벡터로 결합할 수 있다. 미적분에 익숙하다면 이것이 그래디언트를 근사한다는 것을 알 것이다.**
>
> - **벡터의 크기(magnitude)를 취하면 강도값을 얻고, 이를 에지를 나타내는 이미지로 그릴 수 있다.**
> - **방향을 나타내는 각도도 계산할 수 있다.**

### ④ 중간값 필터(median filter) ⭐
> **중간값 필터는 또 다른 인기 있는 필터다.** ⭐ **어떤 종류의 잡음을 제거하는 데 더 낫지만 이미지를 왜곡할 수 있다.**
>
> **중간값 필터는 이웃의 중간값을 출력한다.** 3×3 이웃이면 **9개 픽셀의 중간값**이 출력 이미지의 값이 된다.

| | 결과 |
|---|---|
| **대부분의 영역** | **중간값이 원본 이미지와 동일하다** |
| ⭐ **잡음 표본이 있는 영역** | **잡음이 완전히 사라지고 에지가 곧게 유지된다** |
| ⚠️ **단점** | **정사각형이 픽셀 하나를 잃어 왜곡된다** |

#   ddepth = 출력 이미지 깊이

## 요약
- ⭐⭐ **공간 연산 = 이웃에 함수를 적용하며 이미지를 훑는 것.** 공간적 패턴을 활용한다.
- ⭐⭐ **합성곱(선형 필터링)** — **커널(필터) `w`를 겹쳐 곱하고 더한다.** 커널이 바뀌면 하는 일이 바뀐다. **크기가 줄어드는 문제는 제로 패딩이나 경계 복제로 해결.**
- **저역 통과(평균) 필터 = 잡음 제거.** ⚠️⚠️ **선명함 ↔ 부드러움 트레이드오프**가 항상 있다.
- ⭐⭐ **에지 = 밝기가 급격히 변하는 곳.** **인접 픽셀의 차분 → 그래디언트 근사 → Sobel 연산자.** `g_x`와 `g_y`를 합쳐 **크기(에지 강도)와 각도(방향)** 를 얻는다.
- ⭐ **에지 검출 전에 가우시안 블러**를 건다 — 잡음이 그래디언트를 흔들지 않도록.
- **중간값 필터** — 이웃의 중간값. ⭐ **잡음을 완전히 없애고 에지를 곧게 유지**하지만 ⚠️ **형태를 왜곡**할 수 있다.
- 핵심 함수: **`cv2.filter2D` · `cv2.GaussianBlur` · `cv2.Sobel` · `cv2.convertScaleAbs` · `cv2.addWeighted`.**
