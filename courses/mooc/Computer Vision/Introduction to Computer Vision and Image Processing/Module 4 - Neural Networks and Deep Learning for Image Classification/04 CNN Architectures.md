## 내용

### LeNet-5 (1989) ⭐
> **최초의 CNN 중 하나는 1989년 Yann LeCun 등이 제안했다. LeNet-5의 가장 성공적인 사용 사례는 손글씨 숫자 MNIST 데이터셋이다.**

```
입력(보통 회색조 이미지)
  → 5×5 필터, 스트라이드 1 → 28×28 출력 볼륨
  → 풀링층 → 14×14 출력
  → 필터·풀링 반복
  → 완전 연결층: 평탄화 → 뉴런 120개 → 뉴런 84개
  → ⭐ 시그모이드 활성 함수로 출력 생성
```

### ⚠️ 암흑기와 ImageNet ⭐⭐
> ⚠️ **한동안 CNN은 이미지 분류에서 인기를 잃었고 서포트 벡터 머신이 기본 표준이 됐다.**
>
> ⭐ **이미지 분류 방법을 비교하려면 데이터셋에서의 분류 정확도를 비교한다. ImageNet이 벤치마크 데이터셋이다** — 누가 최고의 이미지 분류 방법을 가졌는지 보려고 모두가 쓰는 것.

| 시기 | 최고 성능 |
|---|---|
| **2012년 이전** | ⭐ **SIFT(HOG 같은 특징)를 쓴 방법이 정확도 51%로 1위** |
| **2012년 이후** | ⭐⭐ **AlexNet이 정확도 63.3%로 기록을 박살냈다** |

> ⭐⭐ **이 도약이 너무 커서 모두가 이미지 분류에 CNN을 쓰기 시작했다.**

### AlexNet ⚠️
> **블록 다이어그램을 보면 신경망에 파라미터가 아주 많다. 합성곱 커널의 크기가 제각각이다.**
>
> ⚠️ **파라미터가 많다는 것은 더 많은 데이터가 필요하다는 뜻이다. 첫 합성곱 커널층은 25채널의 11×11 형태로 파라미터 수가 상당히 많다.**

### ⭐⭐ VGGNet — 3×3 커널을 쌓는다
> **VGG는 합성곱층의 파라미터 수를 줄이고 훈련 시간을 개선할 필요에서 개발된 아주 깊은 합성곱 신경망이다. 또 일반적으로 더 깊은 신경망이 더 잘 수행됨을 보였다.**
>
> **VGG19, VGG16 같은 변형이 있고 숫자는 신경망의 층 수다. VGG16을 AlexNet 옆에 놓으면 훨씬 깊다.**
>
> ⭐⭐ **VGG의 핵심 통찰: 합성곱층의 큰 커널을 3×3 커널의 합성곱층을 쌓는 것으로 대체할 수 있다 — 같은 수용 영역을 유지하면서 파라미터 수를 줄인다.**
>
> ⭐ **이것은 합성곱층의 연산 수를 줄이고 특징 맵 크기를 줄여 계산량도 감소시켰다.**

### ⭐⭐ ResNet — 스킵 연결
> ⚠️ **CNN이 깊어지면서 기울기 소실이 다시 문제가 되기 시작했다.**
>
> ⭐⭐ **ResNet은 잔차 학습(residual learning)을 도입해 이 문제를 해결했다. 잔차층 또는 스킵 연결(skip connections)이 그래디언트가 여러 층을 우회하도록 허용해 성능을 개선한다. 이제 훨씬 더 깊은 신경망을 만들 수 있다.**
>
> **논문 `Deep Residual Learning for Image Recognition`의 32층 신경망이 예시다.**

### ⭐⭐ 전이 학습(transfer learning)
> ⭐ **전이 학습은 사전 훈련된(pre-trained) CNN을 써서 이미지를 분류하는 것이다. 직접 신경망을 만드는 대신 앞서 논의한 CNN 아키텍처를 쓸 수 있다. 사전 훈련된 CNN은 방대한 양의 데이터로 훈련되어 있다.**

**가장 단순한 방법** ⭐⭐
```
① softmax 층을 우리 것으로 교체한다
   ⭐ 뉴런 수 = 우리 클래스 수
② 분류하려는 데이터셋으로 softmax 층만 훈련한다
   softmax 층 각 뉴런의 입력 차원 = 마지막 완전 연결층의 뉴런 수
```
> ⭐⭐ **사전 훈련된 모델을 특징 생성기(feature generator)로 생각할 수 있다.**
>
> ⭐ **데이터셋 크기에 따라 softmax 층 대신 SVM을 써도 된다.**

---

## 요약
- **LeNet-5(1989, LeCun)** — MNIST. **5×5 필터 → 풀링 반복 → FC 120 → 84 → 시그모이드.**
- ⚠️ **한때 SVM이 표준이 됐다.** **ImageNet이 벤치마크.** ⭐⭐ **2012년 AlexNet(63.3%)이 SIFT 기반(51%)을 크게 넘어서며 CNN 시대를 열었다.**
- ⚠️ **AlexNet은 파라미터가 많다** (11×11 커널 등) → **더 많은 데이터가 필요.**
- ⭐⭐ **VGGNet: 큰 커널을 3×3 커널 스택으로 대체.** **같은 수용 영역, 더 적은 파라미터와 연산.** 깊은 신경망이 더 낫다는 것도 보였다.
- ⭐⭐ **ResNet: 잔차 학습 / 스킵 연결로 그래디언트가 층을 우회** → 기울기 소실 해결, 훨씬 깊은 신경망 가능.
- ⭐⭐ **전이 학습: 사전 훈련 CNN을 특징 생성기로 쓰고 softmax 층만 갈아 끼워 훈련.** SVM으로 대체해도 된다.
