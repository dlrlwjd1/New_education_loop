# 02 Fully Connected Neural Network Architecture

## 개요
- 강좌: Introduction to Computer Vision and Image Processing (IBM)
- 모듈: Module 4 — Neural Networks and Deep Learning for Image Classification
- ⭐⭐ **은닉층과 뉴런을 어떻게 배치하는가**, ⚠️⚠️ **기울기 소실(vanishing gradient)** 과 **ReLU**.

---

## 내용

### 다중 클래스 출력 ⭐
> **신경망은 보통 학습 가능한 파라미터를 표기하지 않고 그린다.**
>
> ⭐ **다중 클래스 예측은 출력층에 뉴런을 더 추가하면 된다. 출력층을 softmax 함수로 바꾸는 것으로 생각할 수 있다.**
>
> **클래스가 셋이면 출력층에 뉴런 3개. 주어진 입력에 대해 뉴런마다 출력을 얻고, ⭐ 가장 큰 값을 가진 뉴런의 인덱스에 따라 클래스를 고른다.** (뉴런 2가 가장 크면 출력은 2.)
>
> **클래스마다 하나씩, 출력층에 뉴런 5개를 둘 수도 있다** — 개, 고양이, 등등.

### 심층 신경망 ⭐
> ⭐ **은닉층을 추가할 수 있다. 은닉층이 하나보다 많으면 그 신경망을 심층 신경망(deep neural network)이라 한다.**
>
> ⚠️ **뉴런이 더 많거나 층이 더 많으면 과적합으로 이어질 수 있다.**

### 차원 규칙 ⭐⭐
> ⭐ **각 층의 출력(활성)은 그 층의 뉴런 수와 같은 차원을 가진다.** 뉴런이 3개면 활성도 3차원.
>
> ⭐⭐ **각 뉴런은 선형 분류기와 같다. 따라서 각 뉴런은 이전 층과 같은 수의 입력을 가져야 한다.** 이전 층에 뉴런이 3개면 이 뉴런의 입력은 3개다.

**예시**
```
입력 벡터 4차원
  → 첫 층의 각 뉴런은 입력 4개. 뉴런이 3개 → 활성 차원 3
    → 다음 층의 각 뉴런은 입력 차원 3. 뉴런이 2개 → 출력 활성 차원 2
```

### 아키텍처 선택 ⭐
> ⭐ **완전 연결 신경망 아키텍처를 고르는 한 방법은 검증 데이터를 쓰는 것이다.** 아키텍처 A, B, C 중 **검증 데이터에서 성능이 가장 좋은 것**(이 경우 C)을 고른다.

### ⚠️⚠️ 기울기 소실(vanishing gradient)
> ⭐ **알고 보면 깊은 신경망이 더 잘 작동하지만 훈련하기 어렵다.**
>
> **경사하강으로 학습 파라미터를 얻으려면 그래디언트를 계산해야 하는데,** ⚠️⚠️ **신경망이 깊을수록 그래디언트가 작아진다. 이것을 기울기 소실이라 한다. 그 결과 신경망의 깊은 층을 훈련하기가 더 어려워진다.**
>
> ⚠️ **시그모이드 활성 함수를 쓸 때의 주된 단점 하나가 기울기 소실이다.**

### ⭐⭐ ReLU
> **활성 함수 하나가 정류 선형 유닛(rectified linear unit) 함수, 줄여서 ReLU다.**
```
ReLU(z) = 0   if z < 0
ReLU(z) = z   if z > 0        (z=5면 출력 5, z=10이면 출력 10)
```
> ⚠️ **ReLU는 은닉층에서만 쓴다.**

### 훈련을 돕는 층들 ⭐
> **신경망에는 훈련에 도움이 되는 층들이 있다.** (세부는 건너뛴다.)

| 기법 | 역할 |
|---|---|
| ⭐ **드롭아웃(dropout)** | **과적합을 방지한다** |
| **배치 정규화(batch normalization)** | **훈련을 돕는다** |
| ⭐ **스킵 연결(skip connections)** | **훈련 중 더 깊은 층들을 연결해 더 깊은 신경망을 훈련할 수 있게 한다** |

### ⭐⭐ 신경망 vs SVM
> ⭐⭐ **신경망의 은닉층이 SVM의 커널을 대체한다.**
>
> **입력으로는 원본 이미지를 쓸 수도 있고 HOG 같은 특징을 쓸 수도 있다.**
>
> ⚠️ **신경망 훈련은 과학이라기보다 예술에 가깝다.** 그래서 랩에서 여러 방법을 시도해 본다. **일반적으로 신경망은 로지스틱 회귀·softmax와 비슷한 방식으로 훈련되지만,** ⚠️ **손실(비용) 곡면이 복잡해 훈련이 어렵다.**

---

## 요약
- **다중 클래스는 출력층 뉴런을 늘리고 softmax를 쓴다.** 가장 큰 값의 인덱스가 클래스.
- **은닉층이 둘 이상이면 심층 신경망.** ⚠️ **뉴런·층이 많으면 과적합 위험.**
- ⭐⭐ **차원 규칙: 층의 활성 차원 = 그 층의 뉴런 수. 각 뉴런의 입력 수 = 이전 층의 뉴런 수.**
- **아키텍처는 검증 데이터로 고른다.**
- ⚠️⚠️ **기울기 소실 — 깊을수록 그래디언트가 작아져 깊은 층 훈련이 어렵다. 시그모이드의 주된 단점.**
- ⭐⭐ **ReLU: `z<0 → 0`, `z>0 → z`.** ⚠️ **은닉층에서만 쓴다.**
- **드롭아웃(과적합 방지) · 배치 정규화(훈련 보조) · 스킵 연결(더 깊은 신경망).**
- ⭐⭐ **신경망의 은닉층이 SVM의 커널을 대체한다.**
