# 01 Course Wrap-Up

## 개요
- 강좌: Introduction to Computer Vision and Image Processing (IBM)
- 모듈: Module 6 — Project Case: Not Quite a Self-Driving Car - Traffic Sign Classification
- ⭐ **강좌 전체 정리**와 **최종 프로젝트** 안내.

> ⚠️ 이 모듈은 **영상이 이 한 편뿐**이고 나머지는 프로젝트 안내 읽기 자료, 팟캐스트, 동료 평가 과제다.

---

## 내용

### 강좌가 지나온 길 ⭐⭐
| 단계 | 배운 것 |
|---|---|
| **① 컴퓨터비전 소개** | **시각 데이터 해석에 의존하는 산업**(증강현실·리테일·제조)에서의 역할. **Python, Pillow, OpenCV** 같은 핵심 도구 |
| **② 영상처리** | ⭐ **모든 컴퓨터비전 파이프라인의 기초 단계.** 이미지 데이터를 조작하며 **의미 있는 특징을 추출하고 이미지 품질을 개선**하는 법. **크기 조정·필터링·임계화** 실습 |
| **③ 머신러닝 이미지 분류** | **KNN · 로지스틱 회귀 · SVM.** 이 모델들이 **이미지 특징에 기반해 객체를 식별·분류**하는 방식 |
| **④ 딥러닝** | **신경망과 CNN의 구조와 기능.** **층 · 활성 함수(ReLU) · LeNet과 ResNet 같은 아키텍처.** ⭐ **PyTorch로 첫 CNN 기반 이미지 분류기 구현** |
| **⑤ 객체 탐지** | **전통적 방법과 딥러닝 기반 방법 모두.** **Haar cascade 분류기**부터 시작 |

### 랩에서 실제로 해 본 것 ⭐
> **이 강좌는 실습 랩과 최종 프로젝트를 포함한다. 이를 통해 다음 실무 기술을 얻었다.**

- **OpenCV·Pillow로 이미지 파일 다루기**
- **기본 이미지 연산 — 표시 · 자르기 · 뒤집기 · 회전**
- ⭐ **클라우드를 통한 이미지 저장·전송·검색**
- **히스토그램 생성과 강도 변환 적용**
- **임계화로 이미지 개선과 객체 분할**
- **KNN·SVM 모델로 이미지 분류**
- ⭐ **HOG로 특징 추출**
- **신경망 구축과 ReLU vs 시그모이드 비교**
- ⭐ **ResNet 같은 사전 훈련 CNN으로 전이 학습**
- **모델 미세 조정(fine-tuning)과 하이퍼파라미터 튜닝**
- ⭐ **Haar cascade로 차량 탐지**
- ⭐ **Faster R-CNN으로 다중 객체 탐지와 신뢰도 점수**

> ⚠️ **Faster R-CNN은 랩에서만 다룬다** — 영상 강의에는 나오지 않는다.

### ⭐ 최종 프로젝트 — 정지 표지판 탐지기
> **최종 프로젝트는 전이 학습으로 커스텀 정지 표지판 탐지기를 만들며 이미지 분류 기술을 적용하는 기회였다.**
>
> ⭐ **사전 훈련된 합성곱 신경망으로 특징을 추출하고, 출력층을 미세 조정하고, 하이퍼파라미터를 실험해 성능을 최적화한다.**

> 💡 **강좌의 용어집(glossary)** 을 다시 보며 핵심 용어와 정의를 복습하라고 안내한다.

---

## 요약
- 강좌 흐름: **컴퓨터비전 소개 → 영상처리(OpenCV·Pillow) → ML 분류(KNN·로지스틱·SVM) → 딥러닝(신경망·CNN·PyTorch) → 객체 탐지(Haar cascade).**
- ⭐ **랩에서 클라우드 이미지 저장, HOG 특징 추출, ResNet 전이 학습, Haar cascade 차량 탐지, Faster R-CNN 다중 객체 탐지까지 다룬다.**
- **최종 프로젝트 = 전이 학습으로 만드는 정지 표지판 탐지기** — 사전 훈련 CNN으로 특징 추출 → 출력층 미세 조정 → 하이퍼파라미터 실험.
