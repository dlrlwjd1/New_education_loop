# 06 SoftMax and Multi-Class Classification

## 개요
- 강좌: Introduction to Computer Vision and Image Processing (IBM)
- 모듈: Module 3 — Machine Learning Image Classification
- ⭐⭐ **클래스가 셋 이상일 때** — **클래스마다 평면을 하나씩** 두고 **argmax**로 고른다.

---

## 내용

### argmax 복습 ⭐
> ⭐ **argmax 함수는 수열에서 가장 큰 값에 대응하는 인덱스를 반환한다.**

| Z | 최댓값 | argmax |
|---|---|---|
| 최댓값 100이 인덱스 0에 | 100 | **0** |
| 최댓값 10이 인덱스 7에 | 10 | **7** |

### 3클래스 문제 ⭐⭐
> **로지스틱 회귀는 두 클래스에 쓸 수 있는데, 세 클래스 문제는 어떻게 풀까?**
>
> **Y=0 고양이, Y=1 개, Y=2 물고기.**
>
> ⭐⭐ **하나의 평면으로 데이터를 분류하는 대신, 클래스마다 평면을 하나씩 쓴다.** 이 경우 **세 클래스를 나타내는 세 개의 방정식**이 있고, **임의의 클래스 수로 일반화**할 수 있다.

**그래프 표현**
> **노드가 X의 서로 다른 성분을 나타내고, 각 출력 Z마다 노드를 추가한다. 엣지는 서로 다른 학습 가능한 파라미터를 나타내며 아래첨자가 차원을 가리킨다.**

### 영역과 argmax ⭐⭐
| 영역 | 어느 Z가 최대인가 | 클래스 |
|---|---|---|
| **파란 영역** | **Z₀** (방정식 0) | **클래스 0** |
| **빨간 영역** | **Z₁** | **클래스 1** |
| **노란 영역** | **Z₂** | **클래스 2** |

> ⚠️ **참고: 노란 선은 그 평면이 0보다 큰 곳이고, 노란 영역은 노란 평면이 파랑·빨강 영역보다 큰 곳이다.**
>
> ⭐ **미지의 점을 분류하려면 평면들의 출력을 계산하고 argmax를 적용한다.** 결과가 클래스 1이면 클래스 1이다.

### 왜 "softmax"인가 ⭐⭐
> ⭐⭐ **이 함수를 softmax라 부르는 이유는, 각 입력 벡터와 파라미터의 실제 거리(즉 내적)를 확률 함수로 확률로 변환하기 때문이다.**
>
> **로지스틱 회귀와 마찬가지로 분류 과정은 비슷하지만 확률의 출력을 쓴다.**
>
> ⭐ **softmax의 훈련은 로지스틱 회귀와 거의 동일하다.**

### 다른 다중 클래스 방법 ⭐
> ⚠️ **때로는 softmax가 다중 클래스 분류에 최선의 선택이 아니다.**
>
> **2클래스 분류기를 다중 클래스 분류기로 바꾸는 다른 방법이 여럿 있다** — ⭐ **1 대 나머지(one versus rest)**, **1 대 1(one versus one)**. **이 방법들은 서포트 벡터 머신에 쓰인다.**

---

## 요약
- ⭐ **argmax = 가장 큰 값의 인덱스를 반환.**
- ⭐⭐ **다중 클래스는 클래스마다 평면 하나.** 각 평면의 Z를 계산하고 **argmax로 클래스를 고른다.**
- ⭐⭐ **softmax는 내적(거리)을 확률로 변환**하기 때문에 그렇게 불린다. **훈련은 로지스틱 회귀와 거의 같다.**
- ⚠️ **softmax가 늘 최선은 아니다.** **one-vs-rest**, **one-vs-one** 같은 방법도 있고 **SVM에서 쓰인다.**
