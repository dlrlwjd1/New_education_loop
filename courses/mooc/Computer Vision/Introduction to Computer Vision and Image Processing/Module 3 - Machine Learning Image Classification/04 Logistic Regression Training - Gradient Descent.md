# 04 Logistic Regression Training: Gradient Descent

## 개요
- 강좌: Introduction to Computer Vision and Image Processing (IBM)
- 모듈: Module 3 — Machine Learning Image Classification
- ⭐⭐ **손실(loss)과 비용(cost)**, **교차 엔트로피**, **경사하강법(gradient descent)** 과 **학습률**.

---

## 내용

### 훈련이란 ⭐
> ⭐ **훈련은 결정 경계의 최선의 학습 가능한 파라미터를 찾는 것이다.**
>
> 파라미터 `W`, `B`를 무작위로 고른다(위첨자는 몇 번째 추측인지). **첫 결정 경계는 모든 이미지를 고양이로 분류해 형편없고, 두 번째는 더 낫고, 마지막이 가장 좋다.**
>
> **먼저 결정 경계가 얼마나 좋은지 판단할 방법이 필요하다.**

### 손실과 비용 ⭐⭐
> ⭐ **손실 함수(loss function)는 예측이 얼마나 좋은지 알려 준다.**

**분류 손실(classification loss)**
```
예측이 맞으면 → 0
예측이 틀리면 → 1
```
> ⭐ **비용(cost)은 손실의 합이다. 비용은 학습 가능한 파라미터가 데이터셋에서 얼마나 잘하고 있는지 알려 준다.**
>
> **오분류된 표본마다 손실이 1이라 비용이 올라간다. 올바르게 분류된 표본은 비용을 바꾸지 않는다.**

| 결정 경계 | 비용 |
|---|---|
| 3개 오분류 | **3** |
| 1개 오분류 | **1** |
| 완벽 | **0** |

> ⭐ **비용은 학습 가능한 파라미터의 함수다.** 단순화를 위해 **편향 `b`만의 함수로 보면** 비용을 `b`에 대해 그릴 수 있다.
>
> ⚠️ **현실에서 비용은 여러 파라미터 `w`와 `b`의 함수다. 아주 단순한 2D 예제조차 그리기에는 파라미터가 너무 많다.**

### ⭐⭐ 교차 엔트로피 손실(cross-entropy loss)
> ⚠️ **실무에서 분류 오차(classification error)는 다루기 어렵다.**
>
> ⭐⭐ **대신 교차 엔트로피 손실을 쓴다. 이것은 예측 `ŷ`이 아니라 로지스틱 함수의 출력을 사용한다.** 비용은 여전히 손실의 합이다.
>
> **교차 엔트로피는 이미지가 특정 클래스에 속할 가능성(likelihood)을 다룬다.**
> - **틀린 클래스에 속할 가능성이 크면 교차 엔트로피 손실도 커진다.**
> - **맞는 클래스에 속할 가능성이 맞으면 교차 엔트로피는 작지만 0은 아니다.**

> ⭐⭐ **교차 엔트로피로 그린 비용 곡선은 분류 비용 곡선에 비해 매끄럽다(smooth).** 이것이 경사하강법을 쓸 수 있게 해 준다.

### ⭐⭐ 경사하강법(gradient descent)
> **비용의 최소를 찾으면 최선의 파라미터를 찾을 수 있다. 그래디언트(gradient)는 함수의 기울기를 준다. 어느 점에서든 경사하강법을 비용 함수의 최소를 찾는 방법으로 쓸 수 있다.**

**작동 원리** ⭐⭐
```
편향 파라미터를 무작위로 추측한다 (위첨자 = 추측 번호)

최소의 왼쪽에 있다면 → 양의 방향으로 움직여야 한다
  그래디언트의 부호를 보면 그 수와 반대 부호다
  ⭐ 따라서 그래디언트의 음수에 비례하는 값을 더하면 된다

최소의 오른쪽에 있다면 → 음의 방향으로 움직여야 한다
  역시 그래디언트의 부호는 반대다
  ⭐ 따라서 같은 규칙이 적용된다
```

**최종 식**
```
b^(i+1) = b^(i) − η · ∂cost/∂b
```
> ⭐ **η(에타)는 그래디언트 방향으로 얼마나 멀리 움직일지를 결정한다. 보통 작은 수다.**
>
> **각 반복마다 새 편향 값이 비용을 줄인다. 최소에 도달하면 그래디언트가 0이 되고 파라미터 갱신이 멈춘다.**

### ⚠️⚠️ 학습률(learning rate)
| 학습률 | 결과 |
|---|---|
| **너무 낮으면** | ⚠️ **최소에 영영 도달하지 못할 수 있다** |
| **너무 크면** | ⚠️ **진동하며 최소에 도달하지 못할 수 있다** |
| **적절하면** | ⭐ **비용의 최소에 도달한다** |

> ⭐ **학습률은 하이퍼파라미터다. 검증 데이터에서 최고 정확도를 내는 값을 찾아 선택한다.**

### ⚠️ 임계 함수로는 경사하강을 하기 어렵다
> ⚠️⚠️ **임계 함수에서 경사하강을 수행하는 것은 어렵다. 많은 영역에서 기울기가 0이기 때문이다. 그런 영역에 갇히면 그래디언트가 0이라 갱신되지 않는다.**

이것이 **[03 Linear Classifiers](03%20Linear%20Classifiers.md)** 에서 말한 **"시그모이드가 임계 함수보다 성능이 좋은 이유"** 다.

### 다차원과 학습 곡선 ⭐
> **결정 평면은 파라미터가 여럿이므로 그래디언트는 벡터다. 2차원의 경우 곡면(surface)으로 그릴 수 있는데 그릇(bowl) 모양이고, 파라미터를 갱신하면 최소를 찾아간다.**
>
> ⭐ **보통 비용을 반복 횟수 `i`에 대해 그린다. 이것을 학습 곡선(learning curve)이라 한다.**
>
> ⚠️ **일반적으로 파라미터가 많을수록 모델이 작동하려면 더 많은 이미지와 반복이 필요하다.**

---

## 요약
- **훈련 = 최선의 학습 가능한 파라미터 찾기.** **손실 = 예측의 좋음, 비용 = 손실의 합.**
- ⚠️ **분류 오차는 다루기 어렵다** → ⭐⭐ **교차 엔트로피 손실**을 쓴다. **로지스틱 출력(확률)을 쓰므로 비용 곡선이 매끄럽다.**
- ⭐⭐ **경사하강법 `b ← b − η·∂cost/∂b`.** **그래디언트의 음수 방향으로 움직인다.** 최소에서 그래디언트가 0이라 멈춘다.
- ⚠️⚠️ **학습률 η: 너무 작으면 도달 못 하고, 너무 크면 진동한다.** 하이퍼파라미터이므로 **검증 데이터로 고른다.**
- ⚠️ **임계 함수는 기울기가 0인 영역이 많아 경사하강이 안 된다** — 그래서 시그모이드를 쓴다.
- **학습 곡선 = 반복 횟수 대비 비용 그래프.** ⚠️ **파라미터가 많을수록 더 많은 데이터와 반복이 필요하다.**
