# 07 Support Vector Machines (SVM)

## 개요
- 강좌: Introduction to Computer Vision and Image Processing (IBM)
- 모듈: Module 3 — Machine Learning Image Classification
- ⭐⭐ **커널(kernel)** 로 선형 분리 불가능한 데이터를 다루고, **최대 마진(maximum margin)** 으로 최선의 평면을 고른다. ⚠️ **과적합**이 여기서 구체적으로 등장한다.

---

## 내용

### ⭐⭐ 커널 — 차원을 올려 분리 가능하게 만든다
> ⚠️ **모든 데이터셋이 선형 분리 가능한 것은 아니다.** 두 색이 서로 겹쳐 있는 데이터를 생각해 보라.
>
> ⭐ **선형 분리 가능한 공간을 만들도록 데이터를 변환할 수 있다.**

**1차원 예시**
```
특징이 x 하나뿐 → 선형 분리 불가능
함수로 새 공간에 매핑: x → (x, x²)
⭐ 2차원이 되면 선형 분리 가능해진다
```
> **2차원 공간에 있으므로 초평면은 평면을 두 부분으로 나누는 직선이고, 각 클래스가 양쪽에 놓인다. 이제 이 선으로 데이터셋을 분류할 수 있다.**

**커널 트릭** ⭐
> ⚠️ **때로는 그 매핑을 계산하기 어렵다. 그래서 커널(kernel)이라는 지름길을 쓴다.**

| 커널 종류 | 비고 |
|---|---|
| **선형(linear)** | |
| **다항(polynomial)** | |
| ⭐ **RBF(radial basis function)** | **가장 널리 쓰인다** |

> **각 함수마다 고유한 특성과 장단점이 있다.**
>
> ⭐ **RBF 커널은 두 입력 `x`와 `x'`의 차이를 찾는다. 그것을 서포트 벡터(support vector)라 한다. RBF 커널에는 파라미터 감마(gamma)가 있다.**

### ⚠️⚠️ 감마와 과적합
**고양이·개 데이터 실험**

| γ | 결과 |
|---|---|
| **0.01** | **분류기의 유연성이 커진다** |
| **0.1** | ⭐ **더 많은 점을 분류하는 것으로 보인다** |
| **0.5** | ⚠️⚠️ **거의 모든 점을 정확히 분류했지만 원래 슬라이드의 영역과 맞지 않는다** |

> ⚠️⚠️ **이것이 과적합(overfitting)이다 — 분류기가 실제 패턴이 아니라 데이터 점들에 맞춰지는 것. 감마가 클수록 과적합할 가능성이 높다.**

**왜 그런가 — 구체적인 예** ⭐
> **개처럼 보이는 고양이 이미지들이 있다. 잘못 레이블링됐거나, 나쁜 각도에서 찍혔거나, 그냥 고양이가 개처럼 생겼을 수 있다. 그 결과 이미지 점들이 잘못된 영역에 나타난다.**
>
> **높은 감마로 모델을 맞추면 훈련 점들에서는 거의 완벽하지만, 결정 영역이 우리가 의도한 영역과 맞지 않는다.**
>
> ⚠️⚠️ **이것이 과적합이다 — 훈련 표본에서는 잘하지만 새 데이터를 만나면 못할 수 있다.**

**해결: 검증 데이터로 감마를 고른다** ⭐
```
데이터를 훈련 세트와 검증 세트로 나눈다
γ = 0.5 → 오분류 표본 발생
γ = 0.1 → 더 낫다
⭐ 따라서 0.1을 쓴다
```
> **실무에서는 여러 감마 값을 시도해 검증 데이터에서 가장 잘하는 값을 고른다.**

### ⭐⭐ 최대 마진(maximum margin)
> **세 개의 평면 중 어느 것이 데이터를 더 잘 분류할까? 직관적으로 초록 선이라 답할 것이고, 그것이 옳다.** ⭐ **잡음으로 인한 데이터셋의 변화가 초록 선의 분류 정확도에는 영향을 주지 않기 때문이다.**
>
> ⭐⭐ **SVM은 데이터셋을 두 클래스로 가장 잘 나누는 평면을 찾는다는 아이디어에 기반한다. 최선의 초평면에 대한 합리적 선택 하나는 두 클래스 사이의 분리, 즉 마진(margin)이 가장 큰 것이다. 그래서 목표는 가능한 한 큰 마진을 가진 초평면을 고르는 것이다.**

**서포트 벡터** ⭐⭐
> ⭐⭐ **초평면에 가장 가까운 예시들이 서포트 벡터다. 우리 목표를 달성하는 데는 오직 서포트 벡터만 중요하고, 따라서 다른 훈련 예시들은 무시할 수 있다는 것이 직관적이다.**
>
> **서포트 벡터까지의 거리가 최대가 되도록 초평면을 찾는다.**
>
> ⚠️ **최적화된 초평면을 찾는 것은 수학이 꽤 더 들어가므로 여기서 자세히 다루지 않는다.** 다만 **초평면은 마진을 최대화하는 최적화 절차로 훈련 데이터에서 학습되며, 이 최적화 문제 역시 경사하강법으로 풀 수 있다.**

### 소프트 마진(soft margin) SVM ⭐
> ⚠️ **클래스가 분리 가능하지 않을 때는 소프트 마진 SVM을 쓸 수 있다. 보통 정규화 파라미터(regularization parameter)로 제어된다. 이는 일부 표본이 오분류되는 것을 허용한다.**
>
> ⭐ **감마와 정규화 파라미터 `C`는 검증 데이터에서 가장 잘하는 값으로 고른다.**

---

## 요약
- ⭐⭐ **커널 = 데이터를 선형 분리 가능한 공간으로 매핑하는 지름길.** `x → (x, x²)` 처럼 차원을 올린다.
- **커널 종류: 선형 · 다항 · RBF.** ⭐ **RBF가 가장 널리 쓰이고 파라미터 γ를 가진다.**
- ⚠️⚠️ **γ가 클수록 과적합하기 쉽다** — 훈련 점에는 거의 완벽하지만 **실제 패턴이 아니라 점들에 맞춰진다.** 원인은 **잘못 레이블링됐거나 이상한 각도로 찍힌 이미지**.
- ⭐ **γ와 정규화 파라미터 `C`는 검증 데이터로 고른다.**
- ⭐⭐ **최대 마진** — 마진이 클수록 **잡음에 강하다.** ⭐⭐ **초평면에 가장 가까운 예시 = 서포트 벡터**이며, **그것만 중요하고 나머지 훈련 예시는 무시할 수 있다.**
- **분리 불가능하면 소프트 마진 SVM**으로 일부 오분류를 허용한다.
