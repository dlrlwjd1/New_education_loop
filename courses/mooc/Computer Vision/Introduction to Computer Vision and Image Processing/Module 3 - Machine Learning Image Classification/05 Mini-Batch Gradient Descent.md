# 05 Mini-Batch Gradient Descent

## 개요
- 강좌: Introduction to Computer Vision and Image Processing (IBM)
- 모듈: Module 3 — Machine Learning Image Classification
- ⭐ **미니배치 경사하강법** — *"더 많은 데이터로 모델을 훈련할 수 있게 해 준다."* **epoch · batch size · iteration**의 관계.

---

## 내용

### 배치 vs 미니배치 ⭐⭐
> **지금까지는 경사하강에 모든 표본을 썼다.** ⭐ **미니배치 경사하강법에서는 각 반복마다 몇 개의 표본만 쓴다.**
>
> **미니 비용 함수 또는 총 손실(total loss)을 최소화한다고 생각하면 도움이 된다.**

| 용어 | 뜻 |
|---|---|
| ⭐ **에폭(epoch)** | **데이터셋의 모든 표본을 한 번 다 쓰는 것** |
| **배치 경사하강(batch gradient descent)** | **모든 표본을 쓸 때. 1 반복 = 1 에폭** |
| **미니배치** | **몇 개의 표본으로 비용(총 손실)을 계산한다** |

### 반복 횟수 계산 ⭐⭐
```
반복 횟수 = 훈련 예제 수 ÷ 배치 크기
```

**훈련 예제 6개일 때**

| 배치 크기 | 한 에폭당 반복 |
|---|---|
| **1** | **6회** — 매 반복에 표본 1개 |
| **2** | **3회** — 매 반복에 표본 2개 |
| **3** | **2회** — 매 반복에 표본 3개 |

> **배치 크기 2면 첫 반복에 처음 두 표본, 두 번째 반복에 다음 두 표본, 세 번째 반복에 마지막 두 표본을 쓴다. 두 번째 에폭도 마찬가지로 3회가 걸린다.**

### 총 손실과 과적합 ⭐
> **각 반복 전에 총 손실을 계산한다.** ⭐ **이것은 비용의 잡음 섞인(noisy) 버전이다.**
>
> ⭐ **각 에폭이 끝날 때 검증 데이터에서 정확도를 계산한다.** 그리고 다음 반복을 위해 과정을 반복한다.
>
> ⚠️⚠️ **정확도가 떨어지면 너무 많이 훈련한 것이다. 이것을 과적합(overfitting)이라 한다.**

---

## 요약
- ⭐ **미니배치 경사하강 = 반복마다 몇 개의 표본만 쓴다.** 더 많은 데이터로 훈련할 수 있게 해 준다.
- **에폭 = 전체 데이터를 한 번 도는 것.** **배치 경사하강은 1 반복 = 1 에폭.**
- ⭐⭐ **반복 횟수 = 훈련 예제 수 ÷ 배치 크기.**
- **각 반복 전 총 손실은 비용의 잡음 섞인 버전**이다.
- ⚠️⚠️ **에폭마다 검증 정확도를 재고, 정확도가 떨어지기 시작하면 과적합**이다.
