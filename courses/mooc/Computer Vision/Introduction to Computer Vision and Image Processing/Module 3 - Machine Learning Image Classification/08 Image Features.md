---

## 내용

### ⚠️⚠️ 픽셀 강도를 그대로 쓰면 안 되는 이유
> ⚠️⚠️ **실무에서 이미지 강도를 분류에 그대로 쓰면 잘 작동하지 않는다.**
>
> **이미지를 벡터로 변환한다고 하자. (설명을 위해 개별 픽셀 값 대신 큰 패치를 쓴다.)**
>
> ⭐ **이미지를 분류하는 것은 픽셀들 사이의 관계와 관련이 있다. 이미지의 약간의 변화가 이 관계에 영향을 준다.**
>
> ⚠️ **작은 이동(shift)이 특징 벡터를 어떻게 바꾸는지 보라. 두 벡터를 비교하면 이미지의 작은 이동이 벡터를 다르게 만든다.**

### 특징(features)이란 ⭐
> ⭐ **특징은 분류에 도움이 되도록 이미지에서 취한 측정값이다.**

### ① 색 히스토그램 — 그리고 그 한계 ⭐
> **이동한 이미지의 히스토그램을 구하고 0을 제거하면 히스토그램들이 비슷하다.** (이동에 강하다.)
>
> ⚠️⚠️ **그러나 히스토그램은 강도를 세기만 할 뿐 픽셀들 사이의 관계를 고려하지 않는다.**
>
> **원과 정사각형이 있을 때 히스토그램은 둘이 검은 픽셀 수가 같다는 사실만 정량화한다.**

**부분적 해결** ⭐
> **이 문제를 극복하는 한 방법은 이미지를 하위 이미지(sub-image)로 나누고 각 하위 이미지의 히스토그램을 계산하는 것이다.** 첫 다섯 하위 이미지의 히스토그램, 다음 다섯 개의 히스토그램, 이런 식으로.

### ⚠️ 색이 늘 최선의 도구는 아니다
> **원을 분류하는 과제를 생각해 보자. 빨간 원이면 빨강 채널의 많은 원소가 큰 값을 가지고, 파란 원이면 파랑이나 초록 채널의 원소만 큰 크기를 가진다. 두 히스토그램은 (구조상) 같을 수밖에 없다.**
>
> ⚠️ **인간은 색으로 이미지를 분류하지만, 색을 쓰는 특징을 사람이 고안하기는 어렵다.**
>
> ⭐⭐ **비슷한 원들을 회색조로 바꾸면 비슷해 보인다. 놀랍게도 그래디언트는 동일하게 보인다. 그 결과 우리는 그래디언트에 기반한 특징을 쓴다.**

### ⭐⭐ HOG (Histogram of Oriented Gradients)
> ⭐ **HOG는 우리가 쓸 수 있는 많은 이미지 특징 중 하나이며 이해하기 상대적으로 쉽다.**
>
> ⭐⭐ **이 기법은 이미지의 국소 영역에서 그래디언트 방향(orientation)의 발생 횟수를 센다. HOG는 각 영역마다 히스토그램을 따로 생성한다. 히스토그램은 픽셀 값들의 그래디언트와 방향으로 만들어진다. 그래서 이름이 "방향 그래디언트 히스토그램"이다.**

**기본 아이디어** ⭐
| 도형 | 그래디언트 | 히스토그램 |
|---|---|---|
| **단위원** | **크기가 모두 같다** | **각 빈의 인덱스는 그래디언트의 각도, 값은 크기(magnitude)** |
| **정사각형** | 다르다 | ⭐ **정사각형은 다른 히스토그램을 가진다** |

**HOG 계산 절차** ⭐⭐
```
① 이미지를 회색조로 변환한다
② ⭐ Sobel로 그래디언트의 크기와 각도를 계산한다   ← Module 2에서 배운 것
③ 이미지를 격자 형태의 셀(cell)로 나눈다
④ 각 셀 안의 픽셀들에 대해 그래디언트 방향의 히스토그램을 만든다
⑤ ⭐ 이미지의 하이라이트·그림자에 대한 불균형을 개선하기 위해 셀들을 블록 정규화(block normalize)한다
⑥ HOG 특징 벡터 = 모든 픽셀 수준 히스토그램의 조합
⑦ ⭐ 이것을 SVM과 함께 써서 이미지를 분류한다
```
> ⚠️ **이 예는 단순화한 것이다. 이미지 셀의 개수나 히스토그램의 각도 빈 개수 같은 다른 자유 파라미터도 고려해야 한다.**
>
> **SURF와 SIFT 같은 다른 종류의 이미지 특징도 있다.**

### ⭐⭐ 전통적 머신러닝 파이프라인 요약
> **전체 머신러닝 과정을 다음과 같이 요약할 수 있다.**
```
특징 추출(Feature Extraction)
  → 커널(Kernel, 즉 비선형 매핑)
    → 선형 분류(Linear Classification)
```

---

## 요약
- ⚠️⚠️ **픽셀 강도를 그대로 쓰면 안 된다** — **작은 이동만으로도 특징 벡터가 완전히 달라진다.** 분류는 **픽셀들 사이의 관계**에 달려 있다.
- **색 히스토그램은 이동에 강하지만** ⚠️ **픽셀 간 관계를 무시한다** (원과 정사각형을 구분 못 함). **하위 이미지로 나눠 히스토그램을 구하면 부분적으로 개선**된다.
- ⚠️ **색은 늘 최선이 아니다.** ⭐⭐ **회색조로 바꾸면 그래디언트가 동일해 보인다 → 그래디언트 기반 특징을 쓴다.**
- ⭐⭐ **HOG = 국소 영역에서 그래디언트 방향의 히스토그램.** **빈 인덱스 = 각도, 값 = 크기.**
- **HOG 절차: 회색조 → Sobel로 크기·각도 → 셀 격자 → 셀별 방향 히스토그램 → 블록 정규화 → 특징 벡터 → SVM.**
- 다른 특징: **SURF, SIFT.**
- ⭐⭐ **전통적 파이프라인 = 특징 추출 → 커널 → 선형 분류.**
