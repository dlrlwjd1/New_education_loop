# 02 Image Classification with KNN

## 개요
- 강좌: Introduction to Computer Vision and Image Processing (IBM)
- 모듈: Module 3 — Machine Learning Image Classification
- ⭐⭐ **KNN(K-Nearest Neighbor)** — 가장 단순한 분류 알고리즘. 그리고 **훈련/검증/테스트 분할**과 **하이퍼파라미터** 개념이 여기서 나온다.

---

## 내용

### KNN의 원리 ⭐⭐
> ⭐ **KNN은 K개의 가장 가까운 예시에서 가장 흔한 클래스를 찾아 미지의 데이터 점을 분류한다. 가장 가까운 짝을 찾는 것이다.**
>
> **3채널 이미지를 하나의 벡터로 이어 붙인다(회색조도 마찬가지). 강의에서는 시각화를 위해 2차원을 쓴다.**

**거리 계산**
```
유클리드 거리 = 두 점을 잇는 벡터의 길이
```
> **훈련 표본(training samples)들이 있고, 미지 표본이 오면 각 이미지와의 거리를 계산한다.** 표를 만들면 **행이 표본, 두 번째 열이 클래스, 마지막 열이 미지 점까지의 거리**다.
>
> ⭐ **거리를 이용해 미지 클래스의 레이블을 예측한다. 추측·예측이므로 `ŷ`(y-hat)로 쓴다. 모자(hat)는 추정값이라는 뜻이다.**

**절차**: **미지 표본에서의 거리 계산 → 가장 가까운 점(최근접 이웃)을 찾음 → 그 레이블을 미지 표본에 배정.** 이것을 **모델**이라 부르기도 한다.

> **KNN은 직접 코딩하기도 쉽고 sklearn 같은 패키지를 써도 된다.**

### 훈련/테스트 분할과 정확도 ⭐⭐
> ⭐ **데이터를 훈련 세트와 테스트 세트로 나누는 것은 모델 평가의 중요한 부분이다. 테스트 데이터로 우리 모델이 실세계에서 어떻게 동작할지 감을 잡는다.**
>
> **보통 더 큰 쪽이 훈련용, 작은 쪽이 테스트용이다.** 예: **훈련 70% / 테스트 30%.**
>
> ⭐ **테스트를 마치면 모든 데이터를 써서 모델을 훈련해야 한다.**

**정확도(accuracy)**
> **정확도는 우리 방법이 얼마나 좋은지, 즉 모델이 맞힌 평균 횟수를 보여 준다.**

| 행 | 내용 |
|---|---|
| 1행 | 표본 번호 |
| 2행 | **실제 클래스 레이블** |
| 3행 | **예측값** |
| 4행 | **맞으면 1, 틀리면 0** |

> **맞힌 횟수를 세고 평균을 내면 정확도다.**

### ⭐⭐ K를 왜 1보다 크게 하는가
> ⚠️ **가장 가까운 표본을 찾는 것이 늘 최선은 아니다.** 예컨대 **고양이가 고양이처럼 생긴 개 옆에 있고, 그 주변의 다른 표본은 전부 고양이인 경우.**
>
> ⭐ **이를 다루기 위해 K개의 가장 가까운 표본을 찾고 다수결(majority vote)을 한다** — 그 부분집합 안에서 표본 수가 가장 많은 클래스를 찾아 미지 표본에 그 레이블을 배정한다.

### ⭐⭐ 하이퍼파라미터와 검증 데이터
> ⭐⭐ **최적의 K를 정하기 위해 검증 데이터(validation data)라는 부분집합을 쓴다. 이런 것을 하이퍼파라미터(hyperparameter)라 한다.**

```
데이터셋을 세 부분으로 나눈다:
  훈련 세트(training set)    ← 서로 다른 하이퍼파라미터로 학습
  검증 세트(validation set)  ← ⭐ 정확도를 최대화하는 K를 선택
  테스트 세트(test set)      ← 실세계 성능을 가늠
```
> ⚠️ **이 강좌에서는 단순화를 위해 검증 세트와 테스트 세트를 합친다.**
>
> 예: **K=1의 정확도와 K=3의 정확도를 계산해 K=3이 더 나으므로 K=3을 고른다.** ⭐ **데이터셋에 표본이 충분하면 실세계에서도 이 정확도를 기대할 수 있다.**

### 실제 앱에서 ⭐
> **고양이·개 인식 앱을 만들고 K=3으로 뒀다고 하자. 사진을 찍으면 내부적으로 앱이 거리들을 계산하고, 최근접 이웃들을 찾고, 클래스를 문자열로 출력한다.**
>
> ⭐ **클래스를 추가하는 것도 간단하다** — 예컨대 물고기를 추가하면 2D 공간에서 그렇게 보일 것이다.

### ⚠️⚠️ KNN의 한계
> ⚠️⚠️ **KNN은 실무에서 잘 쓰이지 않는다. 극도로 느리고, 이미지 분류의 여러 어려움을 다룰 수 없다.** 그래서 다른 분류기를 배운다.

---

## 요약
- ⭐⭐ **KNN = K개의 최근접 이웃에서 다수결.** 거리 척도는 **유클리드 거리**.
- **이미지를 벡터로 이어 붙여** 공간 상의 점으로 다룬다.
- **훈련/테스트 분할(예: 70/30)** — 테스트로 실세계 성능을 가늠하고, 끝나면 **전체 데이터로 다시 훈련**한다.
- ⭐ **정확도 = 맞힌 비율.**
- ⭐⭐ **K는 하이퍼파라미터**다. **검증 세트에서 정확도를 최대화하는 K**를 고른다. (이 강좌는 단순화를 위해 검증=테스트로 합친다.)
- ⚠️⚠️ **KNN은 실무용이 아니다** — **극도로 느리고** 이미지 분류의 어려움에 대처하지 못한다.
