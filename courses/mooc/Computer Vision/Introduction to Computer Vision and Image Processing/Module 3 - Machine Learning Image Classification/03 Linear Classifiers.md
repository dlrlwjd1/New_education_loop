---

## 내용

### 결정 평면(decision plane) ⭐⭐
> **1차원에서 직선의 방정식은 다음과 같다.**
```
z = w·x + b
```
| 항 | 뜻 |
|---|---|
| **w** | **가중치(weight) 항** |
| **b** | **편향(bias) 항** |
| 둘 다 | ⭐ **학습 가능한 파라미터(learnable parameters)** — 이것으로 이미지를 분류한다 |

> **임의의 차원에서 이 식은 초평면(hyperplane)으로 일반화된다. 행 벡터 `w`와 이미지 `x`의 내적으로 표현할 수 있다. 이것을 결정 평면이라 한다.**
>
> ⚠️ **`x`가 굵은 글씨가 아니면 표본이 아니라 그냥 대수 변수다.**

**2차원 예시** — `w₁=1, w₂=−1, b=1`로 두면:
- **평면 `z = 0`을 그릴 수 있고, 결정 평면이 `z=0` 평면과 만나는 선이 보인다.**
- ⭐⭐ **이 선을 결정 경계(decision boundary)라 한다.**
- **선의 왼쪽은 개, 오른쪽은 고양이다.**

### z의 부호로 분류하기 ⭐
| 위치 | z |
|---|---|
| **선의 왼쪽 모든 점** | ⭐ **양수** (예: z=2) |
| **선의 오른쪽 모든 점** | ⭐ **음수** (예: z=−2) |

### 임계 함수(threshold function) ⭐
> ⚠️ **z로 클래스를 계산하면 항상 실수가 나온다(−1, 3, −2 등). 그런데 우리에게는 0과 1 사이의 클래스가 필요하다. 어떻게 변환할까?**

```
ŷ = 1  if z > 0    (개)
ŷ = 0  if z < 0    (고양이)
```
> ⚠️ **평면이 데이터를 항상 분리할 수 있는 것은 아니다.** 어떤 표본은 오분류된다. 이런 경우 **데이터가 선형 분리 가능(linearly separable)하지 않다**고 한다.

### ⭐⭐ 로지스틱(시그모이드) 함수
> **로지스틱 함수는 임계 함수를 닮았고 시그모이드 함수로 알려진 식으로 주어진다. 우리 추정이 얼마나 그럴듯한지 확률을 준다. 게다가 임계 함수보다 성능이 좋다(이유는 나중에 논의).**

```
σ(z) = 1 / (1 + e^(−z))
```
| z | σ(z) |
|---|---|
| **아주 큰 음수** | **≈ 0** |
| **아주 큰 양수** | **≈ 1** |
| 중간 | **0과 1 사이** |

**이산 클래스로 바꾸기**
```
ŷ = 1  if σ(z) > 0.5
ŷ = 0  if σ(z) ≤ 0.5
```

**예시**
| 입력 | z | σ(z) | ŷ |
|---|---|---|---|
| x = (0, 3)·... | **2** | **> 0.5** | **1 (개)** |
| x = (−2, −3) | **−2** | **< 0.5** | **0 (고양이)** |

### 확률로 해석하기 ⭐
> ⭐ **로지스틱 함수를 확률로 표현할 수도 있다.**
```
P(ŷ = 1)  → 이미지가 개일 확률
P(ŷ = 0)  → 이미지가 고양이일 확률   (= 1 − P(ŷ=1))
```
> **어떤 이미지에는 개일 확률이 더 크고, 다른 이미지에는 고양이일 확률이 더 크다.** 강의 도입부의 **"92% 확률로 개"** 가 이것이다.

### 실제 앱에서
> **학습 가능한 파라미터가 있으면 선형 분류기를 쓸 수 있다. 사진을 찍으면 앱이 내부적으로 선형 분류기로 예측하고 클래스를 문자열로 출력한다.**

## 요약
- ⭐⭐ **선형 분류기 `z = w·x + b`.** `w`(가중치)와 `b`(편향)가 **학습 가능한 파라미터**다.
- **결정 경계 = 결정 평면이 `z=0` 평면과 만나는 선.** **z의 부호가 클래스를 가른다.**
- **임계 함수**: `z>0 → 1`, `z<0 → 0`. ⚠️ **선형 분리 가능하지 않은 데이터도 있다.**
- ⭐⭐ **시그모이드 `σ(z) = 1/(1+e^(−z))`** — 임계 함수를 닮았지만 **확률을 주고 성능이 더 낫다.** **0.5를 기준으로 클래스를 정한다.**
- **선형 분류기는 더 고급 방법들의 구성 요소다.**
