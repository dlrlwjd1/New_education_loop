# Price Decoy

## 개요
- 마지막 정신적 지름길인 **가격 미끼(price decoy)** 를 다룬다.
- **팔 생각이 없는 세 번째 선택지**를 넣어 소비자의 기존 선호를 이동시키는 기법이다.
- **가격 기반 미끼**와 **속성 기반 미끼(지배된 선택지, dominated option)** 두 가지를 본다.

## 내용

### 시나리오 A — 두 선택지의 트레이드오프
제빵기를 사려는 상황이다.
- **기계 A: $59**
- **기계 B: $129**

이런 상황에서 소비자는 **가격과 지각된 품질 사이에서 트레이드오프**를 한다.
- **가격을 의식하는 소비자**는 **A**를 선호한다.
- **더 높은 품질을 선호하는 소비자**는 **B**를 선호한다.

### 시나리오 B — 세 번째 선택지를 넣는다
같은 두 기계에 **하나를 더한다.**
- **기계 C: $199**

**선호가 안정적이라면** 세 번째 항목을 넣는다고 해서 두 기계 사이의 선호가 바뀌어서는 안 된다. **그런데 바뀐다.**

- **더 높은 가격에 매겨진 기계 C가 미끼(decoy)** 로 작동한다.
- **기계 C가 등장하는 순간 $129 기계는 더 이상 시장에서 비싼 것이 아니게 된다.** $129를 $199와 비교하면 **상대적으로 싸기 때문**이다. 정당화 가능해진다.
- 결과: **결코 팔 생각이 없는 더 비싼 품목을 넣음으로써, 더 많은 소비자가 가운데 선택지를 선호하게 된다.** 고려 집합에 미끼가 있기 때문이다.

### 속성 기반 미끼 — 지배된 선택지(dominated option)
가격 미끼는 가격만이 아니라 **속성 수준의 정보**로도 만들 수 있다.

**시나리오 A (속성 포함)**
- **기계 A**: 저렴하지만 **자동 타이머가 없고 용량도 작다** — 기능이 열등하다
- **기계 B**: 더 비싸지만 **기능이 훨씬 낫다**
- 소비자는 **기능이 열등한 저가**와 **기능이 훨씬 나은 고가** 사이에서 **비교적 어려운 트레이드오프**를 해야 한다.

**시나리오 B — 기계 B를 밀고 싶다면**
세 번째 선택지 **기계 C**를 넣되, **가격만이 아니라 속성도 설계**한다. C를 **지배된(dominated) 선택지**로 만들어야 한다.

- **기계 C의 기능이 기계 B보다 최소 두 개의 속성 차원에서 열등**하도록 만든다.
  - 기계 B가 **타이머 기능과 용량 모두에서 C보다 훨씬 낫다.**
  - 게다가 **기계 B가 더 싸다.** → **기계 B가 세 개 차원에서 이긴다.**
- 기계 A와 기계 C를 비교할 때는 **비교를 쉽게 하도록 C의 속성 수준을 A와 동일하게** 의도적으로 배치한다. 더 낫지 않게 만드는 것이다.
  - 그러면 **$59 대 $199**의 비교에서 **기계 A가 가격에서 압도적으로 우월**하다.

**"더 비싸고 기능도 나쁜 기계 C를 대체 누가 사겠는가?"**
- **요점은 소매업체가 기계 C를 팔 의도가 없다는 것**이다.
- **지배된 선택지** — 열등하면서 동시에 더 비싼 선택지 — 를 넣는 목적은 **소비자가 트레이드오프 결정을 더 쉽게 하도록 만드는 것**이다.
- 비교를 하면 **기계 B가 명백한 승자**로 보이고, 소비자는 더 이상 **더 나은 품질 대 더 높은 가격이라는 단일한 트레이드오프**에 직면하지 않게 된다.

### 결론
- **가격 미끼는 추가 선택지를 도입해 소비자의 기존 가격 선호를 이동시키는 것**이다.
- 지금까지 여러 정신적 지름길을 살펴봤다. 핵심은 **이 모든 지름길이 소비자가 가격에 대한 인상을 형성할 때 영향을 준다**는 것이다.
- 다음번에 제품 가격을 정할 때, **이런 작은 장치들이 당신의 가격을 소비자에게 더 매력적으로 또는 덜 매력적으로 만들 수 있다는 점**을 유념하라.

## 예시

```text
[가격 미끼]

시나리오 A            시나리오 B
기계 A  $59          기계 A  $59
기계 B  $129         기계 B  $129   ← 선호가 여기로 이동
                     기계 C  $199   ← 미끼 (팔 생각 없음)

$129는 $199 옆에서 "비싸지 않은 것"이 된다
```

```text
[지배된 선택지 (속성 미끼) — 기계 B를 밀고 싶을 때]

           가격    자동 타이머   용량
기계 A     $59        없음       작음
기계 B     $129       있음       큼      ← 밀고 싶은 것
기계 C     $199       없음       작음    ← 지배된 선택지

B vs C : 가격 · 타이머 · 용량 세 차원 모두 B가 승 → B가 명백한 승자
A vs C : 속성이 동일한데 A가 훨씬 싸다 → C는 살 이유가 없다
결과   : 소비자가 어려운 트레이드오프에서 벗어나 B를 고른다
```

## 요약
- **가격 미끼**는 **팔 생각이 없는 세 번째 선택지**를 넣어 선호를 이동시키는 기법이다.
- **가격 기반**: $59와 $129 사이에 $199를 넣으면, **$129가 더 이상 비싸 보이지 않아** 가운데 선택지의 선택이 늘어난다.
- **속성 기반(지배된 선택지)**: 밀고 싶은 기계 B보다 **최소 두 개 속성에서 열등하면서 더 비싼** 기계 C를 넣는다. B가 **가격·타이머·용량 세 차원에서 이기므로 명백한 승자**가 된다.
- 미끼의 목적은 **판매가 아니라, 소비자가 어려운 트레이드오프에서 벗어나 결정을 쉽게 하도록 만드는 것**이다.
