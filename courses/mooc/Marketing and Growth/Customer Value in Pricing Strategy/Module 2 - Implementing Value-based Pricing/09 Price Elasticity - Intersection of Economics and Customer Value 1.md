# Price Elasticity: Intersection of Economics and Customer Value 1

## 개요
- Ron(다든)과 Thomas(BCG)가 함께 **하나의 세그먼트에 대해 최적 가격을 수학적·그래프적으로 구하는** 실습이다.
- 핵심 원리는 **한계수입(marginal revenue) = 한계비용(marginal cost)** 이 되는 지점을 찾는 것이다.
- 이 강의는 **세그먼트 1**을 풀고, 다음 강의에서 **더 매력적인 세그먼트 2**와 비교한다.

## 내용

### 문제 설정 — 세그먼트 1
- **수요 함수**: **Q = 10 − 2P**
  - 선형 수요 함수이고, 가격과 수량이 **음의 관계**다. 가격이 오르면 수량이 내려간다.
- **비용 조건**: **한계비용 MC = 2** (일정)
  - 얼마를 팔든 **한 단위를 더 만드는 데 $2**가 든다.

### 왜 한계비용이 중요한가
- 최적 가격을 얻으려면 **한계비용 = 한계수입**이 되는 지점을 풀어야 하기 때문이다.
- 직관: **한계수입이 한계비용 위에 있지 않으면 그것을 팔고 싶지 않다.** 팔면 손해다.
- 그래서 **한계수입이 한계비용과 정확히 같아지는 지점까지는 팔 의사가 있지만 그 너머로는 아니다.**

### 그래프로 보기
- **수요 곡선**: P = 0이면 Q = 10. P = 5면 Q = 10 − 10 = 0.
  - 즉 (0, 10)과 (5, 0)을 잇는 선이다. **기울기가 완만한 편**이다.
- **한계비용**: MC = 2인 **수평선**.
- 두 선이 교차한다. 그런데 우리가 찾을 것은 **한계수입 = 한계비용**인 지점이다.

### 풀이

**1. 역수요 함수(inverse demand function)를 구한다**
계산을 쉽게 하기 위해 Q에 대한 P가 아니라 **P를 Q의 함수로** 바꾼다.

```
Q = 10 − 2P
2P = 10 − Q
P = 5 − ½Q          ← 역수요 함수
```

**2. 수입(revenue)을 구한다**
수입 = P × Q 이므로, P를 대입해 **Q 하나의 변수로** 만든다.

```
R = (5 − ½Q) × Q = 5Q − ½Q²
```

**3. 한계수입(marginal revenue)을 구한다**
총수입이 아니라 **한계수입**이 필요하므로 **Q에 대해 미분**한다.
(미분이 기억나지 않으면 이 코스의 자료 섹션에 미분 복습 파일이 있다.)

```
MR = dR/dQ = 5 − Q
```

**4. 그래프로도 확인**
- MR도 선형 함수다. **Q = 0이면 MR = 5**, **MR = 0이면 Q = 5**.
- 수요 곡선과 **같은 지점(5)에서 출발하지만 더 가파르게 내려간다.**
- MC = 2 수평선과 만나는 지점이 **우리가 찾는 점**이다.

**5. MR = MC를 푼다**

```
5 − Q = 2
Q = 3               ← 최적 가격에서 팔리는 수량
```

**6. 최적 가격을 구한다** — Q를 역수요 함수에 다시 넣는다.

```
P = 5 − ½(3) = 5 − 1.5 = 3.5
```

**7. 이익을 구한다**
이익 = 마진(P − MC) × 수량

```
이익 = (3.5 − 2) × 3 = 1.5 × 3 = 4.5
```

### 반응
- Thomas: **"조금 실망스럽다. 더 잘할 수 있을 줄 알았다."**
- **지불 의사가 더 높고 가격에 덜 민감한 세그먼트를 찾을 수 있을까?** 그러면 수요 함수가 달라진다.
- 다만 **그런 고객을 응대하는 비용은 아마 더 비쌀 것**이다. 더 많이 내려면 더 많은 가치를 받아야 하기 때문이다. **비용 구조도 함께 바뀐다.**

## 예시

```text
[세그먼트 1 풀이 전체]

수요:        Q = 10 − 2P
한계비용:    MC = 2

역수요:      P = 5 − ½Q
수입:        R = 5Q − ½Q²
한계수입:    MR = 5 − Q

MR = MC  →  5 − Q = 2  →  Q = 3
가격:        P = 5 − 1.5 = 3.5
이익:        (3.5 − 2) × 3 = 4.5
```

```text
       3   5
```

## 요약
- 최적 가격의 원리는 **한계수입 = 한계비용**이다. 한계수입이 한계비용보다 낮은 단위는 팔 이유가 없다.
- 절차: **역수요 함수 → 수입(P×Q) → 미분해 한계수입 → MR=MC로 Q → 역수요에 대입해 P → 이익 계산.**
- 세그먼트 1 (Q = 10 − 2P, MC = 2): **Q = 3, P = 3.5, 이익 = 4.5.**
- 지불 의사가 높고 **가격에 덜 민감한** 세그먼트가 있다면 결과가 크게 달라질 수 있다. 다만 **응대 비용도 함께 올라간다.**
