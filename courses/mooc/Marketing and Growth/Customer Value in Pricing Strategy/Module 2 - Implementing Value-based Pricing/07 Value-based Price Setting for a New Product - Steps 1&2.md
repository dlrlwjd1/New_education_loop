# Value-based Price Setting for a New Product: Steps 1&2

## 개요
- 가격을 정하는 근본적 세 가지 방법 — **원가 가산(cost plus), 가치 기반(value based), 시장 기반(market based)** — 중 **가치 기반**을 실제 컨설팅에서 어떻게 적용하는지 5단계로 보여 준다.
- 이 강의는 **1단계(타깃 세그먼트 정의)와 2단계(차선의 대안 식별)** 를 다룬다.

## 내용

### 가치 기반 가격 결정의 5단계
| 단계 | 내용 |
|---|---|
| **1** | **타깃 세그먼트를 정의한다** |
| **2** | 그 세그먼트의 **차선의 대안(next best alternative)을 식별한다** |
| **3** | 고객의 **가치 동인을 식별한다** |
| **4** | 그 가치 동인을 **정량화한다** → **무차별 가격(indifference price point)** 이 나온다 |
| **5** | 그것으로 **가격을 설정한다** |

이 강의는 1~2단계를, 다음 강의가 3~5단계를 다룬다.

### 1단계 — 타깃 세그먼트 정의
가격을 성공적으로 매기려면 **고객에서 시작한다.**

**Jane (B2C 페르소나)**
- **3D로 영화를 보고 싶어 하고**
- 그것을 편안히 보려면 **충분히 큰 화면 크기**가 필요하고
- **매력적인 브랜드**를 원한다
- → 전체적으로 그의 사용은 **기술적 편익을 덜 요구한다.**

**Raj (B2B 페르소나, IT 디렉터)**
- **보안** — **256비트 하드웨어 암호화**를 뜻한다
- **내구성** — 현장에서 **최소 3년**은 버텨야 한다
- 충분한 성능을 위한 **듀얼코어 프로세서**
- 저장 용량으로 **최소 500GB SSD**
- → **훨씬 많은 기술적 요구**를 **매우 정밀하게 명시**한다.

두 사람의 언어만 비교해도 차이가 명확하다. **Jane은 영화를 보고 싶어 하고, Raj는 이 모든 기술 사양을 원한다.**

### 고객 프로파일은 어떻게 얻는가
- **매장 방문(store visit)** — 고객이 구매 결정을 생각하는 과정에서 직접 대화한다.
- **경쟁 매핑(competitive mapping)** — 시장에 무엇이 나와 있는가.
- 더 구조화된 **고객 인터뷰**나 **정량 설문(quantitative survey)**.

**고객만이 아니라 경쟁자도 알아야 한다.** Jane의 경우 우리와 경쟁하는 여러 브랜드가 있고, 특히 **브랜드 1이 점유율 40%의 시장 선도자**다.

### 2단계 — 차선의 대안(next best alternative)
- **Jane이 노트북 구매를 생각할 때 아마 머릿속에 떠올리는 제품**이다.
- 중요한 이유: **Jane이 대략 어느 정도를 쓸 의사가 있는지에 대한 첫 감**을 준다. 이것이 **기준 가격(reference price)** 이 된다.
- 기준 가격을 **가치 방정식의 출발점**으로 삼는다. 여기에 **가치 동인을 더하거나(양수) 빼서(음수) 무차별 가격**에 도달한다.

### Jane의 차선의 대안 찾기
- 시장을 훑고 Jane 세그먼트를 대표하는 고객들과 이야기하며 **시장 선도자의 제품**을 찾는다. **소비자가 실제로 머릿속에 떠올릴 가능성이 가장 높은 제품**이기 때문이다.

**공통 사양 (그래서 좋은 비교 대상이 된다)**
- 둘 다 **듀얼코어 2.5GHz 프로세서**
- 둘 다 **500GB 하드드라이브**, **4GB RAM**
- 둘 다 **90분 영화를 1시간에 변환**
- 둘 다 **꽤 좋은 HD 비디오 편집** 능력

이 공통 기능들 때문에 **아주 적합한 차선의 대안**이 되고, 그 컴퓨터의 시장 가격인 **$600이 기준 가격**이 된다.

**차이점**
- **점유율**: 우리 20% vs 브랜드 1의 40% — Jane에게 **잘 알려지고 매력적인 브랜드**가 중요했다는 점을 기억하라 (우리에게 불리)
- **화면 크기**: 우리가 더 크다 (유리)
- **3D 블루레이 재생**: 우리는 되고 브랜드 1은 안 된다 (유리)

### 직접 비교 대상이 없는 신제품이라면
이 방법은 **카테고리에 이미 존재하는 제품의 가격을 매길 때** 잘 작동한다. 그러나 **직접 비교 대상이 없는 신제품**, 즉 **시장을 선도하는 새 기능**을 갖고 있다면?

기준 가격이 없으므로 **직접 구성해야 한다.** 제품을 뜯어 **기능을 따로따로 더하고 각각에 가격을 붙여 같은 결과에 도달**하게 만든다.

**예시 — 2TB 하드드라이브**
- 우리 노트북에 **2TB** 하드드라이브가 있다.
- 시장에서 가장 가까운 경쟁 제품은 **1TB**이고 **기준 가격은 $700**이다.
- 소비자가 2TB를 정말 원한다면 어떻게 할까? **1TB 외장 하드를 사서 꽂고 "이제 2TB짜리 컴퓨터를 가졌다"고 말할 것이다.**
- 그래서 이렇게 구성한다:
  - 경쟁 제품 시작가 **$700**
  - **1TB USB 외장 하드 $75**
  - → **구성된 차선의 대안 $775**

## 예시

```text
[5단계 개요]
1. 타깃 세그먼트 정의
2. 차선의 대안 식별  → 기준 가격(reference price)
3. 가치 동인 식별
4. 가치 동인 정량화  → 무차별 가격(indifference price)
5. 가격 설정
```

```text
[Jane의 차선의 대안]

               우리 제품          브랜드 1 (시장 선도자)
프로세서       듀얼코어 2.5GHz    듀얼코어 2.5GHz      ← 동일
하드드라이브   500GB              500GB                ← 동일
RAM            4GB                4GB                  ← 동일
영화 변환      90분 → 1시간       90분 → 1시간         ← 동일
점유율         20%                40%                  ← 불리
화면 크기      더 큼              —                    ← 유리
3D 블루레이    가능               불가                 ← 유리

기준 가격 = $600 (브랜드 1의 시장 가격)
```

```text
[비교 대상이 없을 때 — 기준 가격 구성하기]
우리 제품: 2TB 하드드라이브
경쟁 제품: 1TB, $700
        + 1TB USB 외장 하드 $75
──────────────────────────────
구성된 차선의 대안 = $775
```

## 요약
- 가치 기반 가격 결정은 **5단계**다: 세그먼트 정의 → 차선의 대안 → 가치 동인 식별 → 정량화 → 가격 설정.
- **1단계**는 페르소나로 세그먼트를 정의하는 것이다. B2C의 Jane은 3D 영화·화면 크기·브랜드를, B2B의 Raj는 암호화·내구성·프로세서·SSD를 정밀하게 요구한다.
- 프로파일은 **매장 방문, 경쟁 매핑, 고객 인터뷰, 정량 설문**으로 얻는다.
- **2단계**의 **차선의 대안**은 고객이 머릿속에 떠올리는 제품이며, 그 가격이 **기준 가격**이 된다. Jane의 경우 시장 선도자의 $600 제품이다.
- **비교 대상이 없는 신제품**이라면 경쟁 제품에 부품을 더해 **기준 가격을 구성**한다($700 + $75 = $775).
