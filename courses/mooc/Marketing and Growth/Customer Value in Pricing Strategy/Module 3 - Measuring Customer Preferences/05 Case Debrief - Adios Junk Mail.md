# Case Debrief: Adios Junk Mail

## 상태

**이 강의는 정리하지 못했다.**

MOOC에서 이 영상은 앞선 항목을 완료해야 열리는 **잠금 상태**다. 해당 페이지는 "Complete previous item to unlock"만 표시하며, 바로 앞에 **채점 과제(Adios Junk Mail: Case Quiz)** 가 있다.

```text
Module 3 - Measuring Customer Preferences
  ...
  Case Intro: Adios Junk Mail        Video    58 sec   ← 정리 완료 (04)
  Case: Adios Junk Mail              Reading  1h 30m
  Adios Junk Mail: Case Quiz         Graded Assignment 15 min  ← 이 항목이 잠금 해제 조건
  Case Debrief: Adios Junk Mail      Video    1 min    ← 잠김
```

채점 과제를 대신 푸는 것은 하지 않았으므로 **자막(transcript)을 확보하지 못했고, 내용을 임의로 채우지 않는다.**

## 이 강의를 여는 방법

1. MOOC에서 **Case: Adios Junk Mail** 읽기 자료를 읽는다.
2. **Adios Junk Mail: Case Quiz** 를 직접 푼다.
3. 그러면 이 Case Debrief 영상이 열린다.

영상을 본 뒤 이 파일을 다른 노트와 같은 형식(개요 / 내용 / 예시 / 요약)으로 채우면 된다.
