# Case Intro: Adios Junk Mail

## 개요
- 3주 차의 첫 번째 케이스인 **Adios Junk Mail** 을 소개하는 짧은 영상이다.
- **설문 데이터로 가격을 정하는 실습**이며, 앞의 두 강의(설문으로 WTP 얻기, 결합 데이터 해석)의 응용이다.

## 내용

### 도입 — 다든 우편실
- 다든 스쿨의 활동 중심지인 **우편실(mail room)** 에서 시작한다.
- 우편 담당자 **Gary**가 등장한다.
  - **"광고 우편(junk mail)이 얼마나 오나요?"** → **"아주 많이 옵니다."**
  - **"그걸 어떻게 하시나요?"** → **"대부분은 재활용통으로 갑니다."**
  - 그 통은 금방 가득 찬다.

### 케이스 설정
- **Adios Junk Mail** 은 **광고 우편 문제**를 다루는 회사다. 많은 사람이 겪는 문제다.
- **광고 우편을 없애 주는 구독 서비스(subscription service)** 다.
- 우리가 할 일: **가격 결정을 도와야 한다.**
- 조건:
  - **작은 회사**이고 **자원이 많지 않다.**
  - 그러나 **설문 데이터는 갖고 있다.**
- 따라서 **그 설문 데이터를 가지고, 이 코스에서 배운 기법을 적용해, Adios Junk Mail의 최선의 가격을 도출**해야 한다.

## 예시

```text
[케이스 조건]
회사    : Adios Junk Mail (광고 우편 제거 구독 서비스)
규모    : 작다. 자원 부족 → 컨조인트 분석을 할 여력이 없다
보유 자료: 설문 데이터
과제    : 설문 데이터 → 스위트 스팟 → 비용 반영 → 최적 가격

→ 앞 강의(02·03)에서 배운 절차를 그대로 적용하는 사례
```

## 요약
- **Adios Junk Mail** 은 광고 우편을 없애 주는 **구독 서비스**다.
- 작은 회사라 자원이 부족하지만 **설문 데이터는 있다.** 바로 설문 방법이 유용한 전형적 상황이다.
- 과제는 그 설문 데이터에 **이 코스에서 배운 기법(두 질문 → 스위트 스팟 → 비용 반영)** 을 적용해 **최선의 가격**을 찾는 것이다.
