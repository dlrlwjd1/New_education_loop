# Attribute Importances

## 개요
- 컨조인트 분석의 세 번째 활용법 — **각 속성이 전체 의사결정 과정에서 얼마나 중요한지 판단하는 것** — 을 다룬다.
- 핵심 직관: **가장 선호되는 수준과 가장 덜 선호되는 수준의 차이(spread)가 클수록 그 속성이 중요하다.**
- 결과는 **의사결정 가중치(decision weight)** 라는 백분율로 나온다.

## 내용

### 직관 — 폭(spread)이 곧 중요도다
- 효용 값의 **차이**는 어떤 수준을 얼마나 더/덜 선호하는지를 알려 준다.
- 나아가 **한 속성의 가장 선호되는 수준과 가장 덜 선호되는 수준 사이의 폭**을 보면, **그 속성이 선택 과정에서 얼마나 중요한지** 알 수 있다.

**예 — 브랜드**
- 가장 선호되는 수준: **High-Flyer Pro, 0.56**
- 가장 덜 선호되는 수준: **Long Shot, −0.60**

만약 이 숫자들이 전부 **0에 가까웠다면** 무슨 뜻일까?
- **어떤 브랜드를 고르든 큰 차이가 없다**는 뜻이다. 사람들이 별로 신경 쓰지 않는다.
- 효용을 크게 더하지도, 크게 빼지도 않는다.

→ **가장 선호되는 수준과 가장 덜 선호되는 수준의 폭이 클수록 그 속성이 중요하다.**

### 수식
속성 k의 중요도는:

```
                (속성 k의 최선호 수준 효용) − (속성 k의 최비선호 수준 효용)
중요도(k) = ────────────────────────────────────────────────────────
              모든 속성의 폭(spread)의 합 (속성 k 자신 포함)
```

- **분자**: 최비선호 수준은 (효용의 합이 0이므로) 보통 **음수**다. 따라서 **음수를 빼는 것**이 되어 분자는 **양수**가 된다.
- **분모**: 컨조인트에 포함된 **모든 속성의 폭을 더한 것**이다. 분자에 들어간 속성도 포함한다. 이 출력이라면 **브랜드의 폭 + 거리의 폭 + 가격의 폭**이다.

### 골프공 예시 — 거리(distance)의 중요도
- 거리의 **최비선호 수준은 −0.48**, **최선호 수준은 0.36**.
- 분자 = 0.36 − (−0.48) = **0.84** (음수를 빼므로 덧셈이 된다)
- 분모 = 거리의 폭 + 브랜드의 폭 + 가격의 폭
- 결과 = **0.24**

### 왜 0과 1 사이인가
- **분자에 들어간 것은 분모에도 항상 포함**되므로, 이 값은 수학적으로 **항상 0과 1 사이**가 된다.
- 그래서 이 값을 **그 속성의 의사결정 가중치 백분율(percent decision weight)** 로 해석한다.

### 해석
- 이 예시에서 **거리는 의사결정 가중치의 24%** 를 차지한다.
- **아주 높지도 아주 낮지도 않다.** 속성 중요도로 보면 **중간 어디쯤**이다.

## 예시

```text
[중요도 = 폭 / 폭의 총합]

브랜드   최선호 High-Flyer Pro  0.56
         최비선호 Long Shot    −0.60      폭 = 1.16
거리     최선호 15야드 더       0.36
         최비선호 5야드 더     −0.48      폭 = 0.84
가격     (최선호 − 최비선호)              폭 = ...

거리의 중요도 = 0.84 / (1.16 + 0.84 + 가격의 폭) = 0.24
             → 의사결정 가중치의 24%
```

```text
[직관 확인]
모든 효용이 0 근처 → 폭이 작다 → 사람들이 신경 쓰지 않는다 → 중요도 낮음
효용이 크게 벌어짐 → 폭이 크다 → 선택을 좌우한다      → 중요도 높음
```

## 요약
- 속성의 중요도는 **최선호 수준과 최비선호 수준의 폭(spread)** 으로 잰다. 폭이 클수록 중요하다.
- 수식은 **(그 속성의 폭) ÷ (모든 속성의 폭의 합)** 이며, 분자가 분모에 포함되므로 **항상 0~1 사이**다.
- 그래서 이 값을 **의사결정 가중치 백분율**로 읽는다.
- 골프공 예시에서 **거리는 24%** 로, 아주 높지도 낮지도 않은 중간 수준의 중요도였다.
