# Conjoint Analysis Applications

## 개요
- 지불 의사를 파악하는 또 하나의 방법인 **컨조인트 분석(conjoint analysis)** 을 소개한다.
- 무엇인지, 어디서 왔는지(1970년대 운영과학), 어떻게 대중화되었는지, 그리고 **얼마나 넓은 범위의 실제 사례에 쓰였는지**를 다룬다.

## 내용

### 컨조인트 분석이란
- **사람들이 서로 다른 제품 속성(attribute)에 어떤 가치를 두는지 판단하는 통계 기법**이다.
- 여러 속성을 가진 제품이 있고 그중 하나가 **가격**일 수 있다. 우리는 사람들이 **한 속성을 다른 속성과, 또는 가격을 특정 업그레이드와 어떻게 맞바꾸는지(trade off)** 를 이해하고자 한다.
- **엑셀로 하는 일이 아니다.** 이 작업을 위한 **전용 소프트웨어**가 있다.
- 널리 쓰이는 기법이다. 어느 정도 규모 있는 마케팅 리서치 회사라면 **컨조인트 분석을 할 줄 아는 사람이 반드시 있다.**

### 역사
| 시기 | 내용 |
|---|---|
| **1970년대** | 기본 형태가 등장. **운영과학(operations research)** 기법에서 나왔다. 운영과학은 생산 공정 같은 것을 수학적으로 모델링하는 분야다. **조립 라인 공정을 보는 데 쓰던 수학과 같은 수학**에서 선호를 다루는 통계 기법이 나왔다 |
| **1980년대** | **노트 카드(note card)** 와, 기본적인 회귀분석을 도와주는 소프트웨어 접근성이 생기며 조금 더 대중화 |
| **1990년대** | 컨조인트 분석 **전용 소프트웨어**가 등장 |
| **2005년경** | **웹 기반 인터뷰** 기법 등장. 사람들이 웹 앱으로 데이터를 제공할 수 있게 됨 |

### 왜 지금 인기가 많은가
- **온라인 패널** 덕분에 **매우 빠른 결과**를 얻을 수 있다.
- 예: **Amazon Mechanical Turk** — 컨조인트 인터뷰·실험을 온라인에 올려놓고 자러 갔다가 다음 날 아침에 일어나면 **수천 명이 응답을 마쳐 놓았다.** (많은 서비스 중 하나일 뿐이다.)

### 응용 사례
컨조인트 분석이 **얼마나 넓은 범위에서 쓰이는지** 보여 주는 목록이다.

| 사례 | 내용 |
|---|---|
| **AT&T 최초의 휴대전화** | 초기 형태의 컨조인트 분석으로 설계 |
| **볼티모어 레이븐스(Baltimore Ravens)** | NFL 팀. 보라색 까마귀 **로고**를 컨조인트 분석으로 설계 (색상·디자인 등의 속성) |
| **코트야드 바이 메리어트(Courtyard by Marriott)** | **호텔 전체**를 비즈니스 여행객 응답자로 한 대규모 컨조인트 연구로 설계 |
| **FedEx** | 새로운 **지상 특송 서비스** 출시 시 선호 측정 |
| **IBM** | **마이크로칩** 하나를 설계. 사람들이 칩에서 원하는 속성이 무엇인가 |
| **다이너스 클럽(Diners Club)** | **신용카드**. 카드는 속성이 많다 |
| **의약품** | 심장 관련 **고혈압 치료제** 설계 |
| **리츠칼튼(Ritz-Carlton)** | 일부 **서비스** 설계 |
| **UPS** | 새로운 **배송 서비스** 설계 |
| **미 해군(US Navy)** | 병사들의 **재입대(re-enlist)** 를 늘리기 위해 **복리후생 패키지**를 설계. 재입대를 고민하는 병사들이 정확히 무엇을 원하는지를 컨조인트로 파악 |

## 예시

```text
[컨조인트가 하는 일]
제품 = 속성들의 묶음 (그중 하나가 가격)
   ↓
"사람들은 속성 A와 속성 B를, 또는 가격과 업그레이드를
 어떻게 맞바꾸는가"를 통계적으로 알아낸다
   ↓
전용 소프트웨어로 수행 (엑셀이 아니다)
```

```text
[적용 범위의 넓이]
소비재     휴대전화 · 신용카드 · 골프공
서비스     호텔(Courtyard) · 특송(FedEx, UPS) · 리츠칼튼 서비스
B2B/기술   IBM 마이크로칩
디자인     볼티모어 레이븐스 로고
의약품     고혈압 치료제
공공       미 해군 재입대 복리후생 패키지
```

## 요약
- **컨조인트 분석**은 사람들이 제품 속성에 어떤 가치를 두는지, 그리고 **속성 간·속성과 가격 간의 트레이드오프**를 어떻게 하는지 알아내는 통계 기법이다.
- **1970년대 운영과학**에서 나왔고, 1990년대 전용 소프트웨어, **2005년경 웹 기반 인터뷰**를 거쳐 대중화되었다.
- **온라인 패널**(예: Amazon Mechanical Turk) 덕분에 **하룻밤이면 수천 명의 응답**을 얻을 수 있게 되었다.
- 휴대전화, 호텔, 로고, 마이크로칩, 신용카드, 의약품, 배송 서비스, 심지어 **미 해군의 재입대 복리후생 패키지**까지 적용 범위가 매우 넓다.
