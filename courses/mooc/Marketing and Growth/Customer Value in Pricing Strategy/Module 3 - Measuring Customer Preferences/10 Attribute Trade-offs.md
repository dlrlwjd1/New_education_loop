# Attribute Trade-offs

## 개요
- 컨조인트 분석의 두 번째 활용법 — **사람들이 속성 사이에서 어떤 트레이드오프를 기꺼이 하는지 분석하는 것** — 을 다룬다.
- 골프공 예시로 **"5야드 더 나가는 것 vs 팩당 $2 인하"** 중 무엇을 더 선호하는지 계산한다.

## 내용

### 출발점 — 현재 제품의 총효용
| 속성 수준 | 효용 |
|---|---|
| **Magnum Force** | **0.43** (출력의 0.429를 반올림) |
| **평균보다 10야드 더** | **0.12** |
| **팩당 $6.99** | **0.22** (출력의 0.216) |
| **총효용** | **0.77** |

### 질문
> **평균적인 골퍼는 공이 5야드 더 나가는 것(10야드 → 15야드)을 선호할까, 아니면 팩당 $4.99로 가격이 내려가는 것을 선호할까?**

### 계산 방법 — 두 차이(spread)를 비교한다

**(1) 거리 개선으로 얻는 효용 증가**
```
15야드 더 (0.36) − 10야드 더 (0.12) = 0.24
```

**(2) $2 인하로 얻는 효용 증가**
```
팩당 $4.99 (0.696 ≈ 0.70) − 팩당 $6.99 (0.22) = 0.48
```

**(3) 어느 차이가 더 큰가**
- **가격 쪽 차이(0.70 − 0.22 = 0.48)** 가 더 크다.
- 실제로 **거리 쪽 차이(0.24)의 두 배**다.

### 결론
> **대부분의 골퍼는 공이 조금 더 멀리 나가는 것보다 $2 가격 인하를 선호한다.**

이 첫 번째 차이(0.70 − 0.22)는 **가격 속성의 효용들이 벌어진 폭(spread)** 에서 나온 것임을 다시 강조한다.

### 세그먼트별로도 가능하다
이 예시들 각각은 **모집단 수준**에서 계산할 수도 있고, **관심 있는 세그먼트별로** 계산할 수도 있다.

## 예시

```text
[트레이드오프 비교 — 골프공]

현재 제품: Magnum Force(0.43) + 10야드 더(0.12) + $6.99(0.22) = 0.77

선택지 A: 거리 개선 (10야드 → 15야드)
   효용 증가 = 0.36 − 0.12 = 0.24

선택지 B: 가격 인하 ($6.99 → $4.99)
   효용 증가 = 0.70 − 0.22 = 0.48   ← 두 배

→ 골퍼들은 5야드보다 $2 인하를 더 원한다
```

## 요약
- 속성 트레이드오프 분석은 **두 변경안이 각각 만들어 내는 효용 증가(차이)를 비교**하는 것이다.
- 골프공 예시: 거리 5야드 개선은 **+0.24**, 가격 $2 인하는 **+0.48**.
- 따라서 **대부분의 골퍼는 5야드보다 $2 인하를 선호한다.** 가격 인하가 두 배의 효용을 준다.
- 이 계산은 **모집단 전체는 물론 세그먼트별로도** 할 수 있다.
