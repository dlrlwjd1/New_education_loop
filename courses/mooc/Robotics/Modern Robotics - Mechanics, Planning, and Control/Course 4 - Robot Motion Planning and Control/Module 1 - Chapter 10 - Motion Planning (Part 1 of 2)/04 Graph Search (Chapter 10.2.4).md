# Graph Search (Chapter 10.2.4)

## 개요

- 자유 C-space를 그래프로 표현했으면, **시작 구성에서 목표 구성까지의 경로를 찾기 위해 그래프를 탐색**해야 한다.
- **A\* (A-star) 탐색**은 가장 유용한 그래프 탐색 알고리즘 중 하나로, **간선 비용의 합이 경로 비용인 그래프에서 최저 비용 경로**를 찾는다.
- 낙관적 비용 추정(optimistic cost-to-go)을 0으로 두면 **다익스트라(Dijkstra) 알고리즘**이 된다.

## 내용

### 예제 그래프

- 노드 6개. 간선을 도로라고 생각하자. 도로는 직선일 수도 굽어 있을 수도 있다.
- 도로는 직선 간선으로 그리되, **각 간선에 길이(비용)를 나타내는 가중치**를 부여한다. 예: 노드 1 → 노드 3의 비용은 18.
- **가중 무방향 그래프**다. (방향 그래프로의 일반화는 쉽다.)
- 이 그래프의 **최단 경로는 비용 30이고 노드 1 → 4 → 5 → 6** 이다.

### A\*가 필요한 것 — 낙관적 비용 추정 함수

- 그래프 외에, **임의의 노드에서 목표 노드까지의 낙관적 비용(optimistic cost-to-go)** 을 계산하는 함수가 필요하다.
- **낙관적이라는 것: 실제 남은 비용이 그 추정값보다 작을 수 없다는 뜻이다.**

**좋은 추정 함수의 두 기준**

| 기준 | 설명 |
| --- | --- |
| 1. **평가가 빠르다** | |
| 2. **추정값이 실제 값에 합리적으로 가깝다** | |

**나쁜 예 두 가지**

```text
항상 0 을 반환하는 함수      → 빠르지만 추정이 나쁘다
그래프를 탐색해 정확히 계산   → 추정은 정확하지만 느리다
```

**예제에서의 좋은 선택**

- **목표까지의 직선 거리(새가 날아가는 거리, as the bird flies)**. **빠르고 낙관적임이 보장된다.**

```text
노드 1의 낙관적 비용 = 20
노드 2~5의 낙관적 비용 = 10
노드 6(목표)의 낙관적 비용 = 0
```

### 표에서 추적하는 4가지 값

| 항목 | 정의 |
| --- | --- |
| **과거 비용(past cost)** | **이 노드까지 알려진 최선 경로의 비용.** 시작 노드는 0, 나머지는 처음에 **무한(∞)** |
| **낙관적 비용(optimistic cost-to-go)** | 위에서 정의한 추정값 |
| **추정 총비용(estimated total cost)** | **그 노드를 지나는 최선 해 경로의 추정 비용 = 과거 비용 + 낙관적 비용** |
| **부모 노드(parent node)** | **노드 i까지의 알려진 최선 경로에서 직전 노드** |

### 두 리스트

```text
OPEN   : 탐색해 나갈 노드 목록.  추정 총비용 기준 정렬 유지
CLOSED : 이미 탐색을 마친 노드 목록.  다시 방문하지 않는다

초기화: OPEN = [노드 1 (추정 총비용 20)]
```

### 탐색 과정 (예제 추적)

**노드 1에서 탐색**

```text
1 → 3:  부모 = 1,  과거 비용 = 18,  추정 총비용 = 28   → OPEN 에 정렬 삽입
1 → 4:  부모 = 1,  과거 비용 = 12,  추정 총비용 = 22   → 28 보다 앞에 삽입
1 → 5:  부모 = 1,  과거 비용 = 30,  추정 총비용 = 40   → 정렬 삽입

노드 1 → CLOSED  (다시 방문하지 않음)
```

**노드 4에서 탐색** (OPEN의 첫 노드 = 추정 총비용이 가장 낮은 노드)

```text
노드 4는 1, 5, 6 과 연결. 노드 1은 CLOSED 이므로 고려하지 않는다.

4 → 5:  현재 노드 5의 과거 비용은 30 (부모 1).
        노드 4를 경유한 비용 = 12 + 8 = 20 < 30
        → 갱신: 과거 비용 20, 추정 총비용 30, 부모 4.  OPEN 도 갱신

4 → 6:  부모 = 4, 과거 비용·추정 총비용 = 32  → OPEN 에 추가

  ※ 노드 6이 목표지만 탐색은 끝나지 않는다.
     앞으로 더 저렴한 경로를 찾을 수 있기 때문이다.

노드 4 → CLOSED
```

**노드 3에서 탐색**

```text
3 → 2:  노드 2 정보 갱신, OPEN 에 정렬 삽입
3 → 6:  18 + 15 = 33 > 32 (이미 알려진 경로의 과거 비용)
        → 이 간선은 무시한다

노드 3 → CLOSED
```

**노드 5에서 탐색**

```text
CLOSED 가 아닌 연결 노드는 6 뿐.

5 → 6:  20 + 10 = 30 < 32
        → 갱신: 과거 비용·추정 총비용 30, 부모 5.  OPEN 도 갱신

노드 5 → CLOSED
```

**종료**

- 이제 **OPEN의 첫 노드가 목표 노드 6**이다.
- **비용의 가산적(additive) 성질 때문에, 앞으로 더 낮은 비용으로 이 목표에 도달할 수 없다.** 따라서 탐색 완료.

**경로 복원**

```text
노드 6 → 부모 5 → 부모 4 → 부모 1
⇒ 최적 경로: 1 → 4 → 5 → 6  (비용 30)
```

### 의사코드 요약

```text
초기화

while OPEN 이 비어 있지 않은 동안:
    OPEN 의 첫 노드를 탐색 대상으로 표시

    if 그 노드가 목표 영역 안이면:
        최적 해를 찾았으므로 성공 종료

    for CLOSED 에 없는 각 이웃 노드:
        그 노드로 가는 새 최선 경로를 찾았는지 확인
        찾았으면 과거 비용, 추정 총비용, 부모, OPEN 내 위치를 갱신

    현재 노드를 CLOSED 로 이동

OPEN 이 비었다면 → 모션 계획 문제에 해가 없다
```

### 다익스트라 알고리즘과의 관계

```text
낙관적 비용을 항상 0 으로 선택하면
→ 과거 비용 = 추정 총비용
→ 이것이 다익스트라(Dijkstra) 알고리즘 (역사적으로 A* 보다 먼저)
```

| | A\* | 다익스트라 |
| --- | --- | --- |
| 최적 경로 | 찾는다 | 찾는다 |
| 속도 | 빠르다 | **일반적으로 훨씬 느리다** — **탐색을 안내하는 휴리스틱 비용을 쓰지 않기 때문** |

### 중요한 주의 — 낙관성이 깨지면

- **낙관적 비용 함수가 실수로 실제 비용보다 큰 추정값을 반환하면, A\*가 최적이 아닌 해로 종료할 수 있다.**

## 예시

```text
# 세 값의 관계
추정 총비용 = 과거 비용 + 낙관적 비용

# 간선 갱신 조건
if (현재 노드의 과거 비용 + 간선 비용) < (이웃 노드의 기존 과거 비용):
    이웃 노드 갱신

# 종료 조건
OPEN 의 첫 노드가 목표 → 최적 해
OPEN 이 비었다 → 해가 없다
```

## 요약

- **A\***는 간선 비용이 양수이고 경로 비용이 그 합인 그래프에서 **최저 비용 경로**를 찾는다.
- 필요한 것은 그래프 + **낙관적 비용 추정 함수**(실제 남은 비용보다 작거나 같아야 한다). 좋은 함수는 **빠르고 실제 값에 가깝다.** 흔한 선택은 **목표까지의 직선 거리**다.
- 노드마다 **과거 비용 / 낙관적 비용 / 추정 총비용(= 두 값의 합) / 부모 노드**를 관리하고, **OPEN(추정 총비용 정렬)** 과 **CLOSED** 리스트로 진행한다.
- 매 반복에서 **OPEN의 첫 노드(추정 총비용 최소)를 확장**하고, 이웃에 대해 **더 나은 경로를 찾았으면 갱신**한다. 목표 노드를 처음 발견해도 **바로 끝나지 않는다** — 더 저렴한 경로가 나올 수 있다.
- **OPEN의 첫 노드가 목표가 되는 순간 종료**하고, **부모 포인터를 거슬러 경로를 복원**한다. **OPEN이 비면 해가 없다.**
- **낙관적 비용을 0으로 두면 다익스트라**가 된다. 최적성은 같지만 휴리스틱이 없어 **보통 훨씬 느리다.** 반대로 **추정이 실제보다 크면(낙관성 위반) A\*가 비최적 해를 낼 수 있다.**
