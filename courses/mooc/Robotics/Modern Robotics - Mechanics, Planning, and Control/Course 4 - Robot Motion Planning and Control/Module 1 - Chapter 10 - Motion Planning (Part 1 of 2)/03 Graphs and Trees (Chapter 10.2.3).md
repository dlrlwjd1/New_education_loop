# Graphs and Trees (Chapter 10.2.3)

## 개요

- 로봇의 C-space는 연속 공간이지만, **모션 계획에서는 보통 어떤 방식으로든 이산화(discretize)** 한다.
- 이산화된 자유 공간 표현으로 **그래프(graph)** 와 **트리(tree)** 를 사용한다.

## 내용

### 자유 공간의 그래프 표현

- 예: 미로(maze) 안의 이동 로봇.
- **자유 구성 몇 개를 표본(sample)** 하고, **직선 경로로 서로 도달할 수 있는 구성들 사이에 선을 그린다.**
- 이 그래프가 곧 **자유 공간의 이산화된 표현**이다.

### 그래프의 종류

그래프는 **노드(nodes) 집합**과 그들 사이의 **간선(edges) 집합**으로 구성된다. 노드 5개(a~e) 예제를 사용한다.

| 종류 | 정의 |
| --- | --- |
| **무방향(undirected)** | 각 간선을 **양방향으로 따라갈 수 있다** |
| **방향(directed)** | 간선에 방향이 있다. 줄여서 **digraph** 라고도 한다 |
| **비가중(unweighted)** | **어떤 간선을 통과하는 비용이 모두 같다** |
| **가중(weighted)** | **간선마다 비용이 다르다** |

**가중치의 의미**

- 간선에 붙은 비용은 **그 간선에 대응하는 경로의 길이**, 또는 **통과에 드는 에너지나 시간**일 수 있다.
- 예: 노드 b에서 노드 a로 가는 것이 노드 b에서 노드 c로 가는 것보다 훨씬 저렴하다.

**가중 방향 그래프의 예**

- 노드 a와 b 사이는 **양방향 이동이 가능하지만 a로 가는 것이 b로 가는 것보다 비용이 적다.**
- 노드 c에서 노드 e로는 갈 수 있지만 **노드 e에서 노드 c로는 갈 수 없다.**

### 트리 (tree)

**트리는 특정 종류의 방향 그래프**다.

| 성질 | 설명 |
| --- | --- |
| **루트 노드(root node)가 하나** 있다 | |
| **다른 모든 노드는 부모(parent)가 하나** | 즉 **오직 한 노드로부터 단일 간선으로 도달할 수 있다** |
| **순환(cycle)이 없다** | |
| **잎(leaf)** | **자식이 없는 노드** |
| 가중·비가중 모두 가능 | |

## 예시

```text
# 그래프 분류
무방향 + 비가중 : 모든 간선 양방향, 비용 동일
무방향 + 가중   : 양방향이지만 간선마다 비용 다름
방향 + 가중     : 방향마다 비용이 다를 수 있고, 한 방향만 가능할 수도 있음

# 트리
루트 1개, 각 노드의 부모 1개, 순환 없음, 자식 없는 노드 = 잎
```

## 요약

- 연속 C-space를 **표본 구성 + 직선으로 연결 가능한 쌍 사이의 간선**으로 이산화하면 그래프가 된다.
- 그래프는 **방향/무방향**, **가중/비가중**으로 분류된다. 가중치는 **경로 길이, 에너지, 시간** 등을 뜻할 수 있다. 방향 그래프에서는 **한 방향만 통과 가능**하거나 **방향별 비용이 다를** 수 있다.
- **트리는 방향 그래프의 특수한 경우**로, **루트가 하나이고 나머지 노드는 부모가 하나이며 순환이 없다.** 자식 없는 노드가 **잎**이다.
