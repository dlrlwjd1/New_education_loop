# Overview of Motion Planning (Chapter 10.1)

## 개요

- Chapter 10은 **환경에 장애물이 있는 경우의 로봇 모션 계획(motion planning)** 을 다룬다.
- 문제의 형식적 정의와, 문제의 여러 **변형(variations)**, 그리고 플래너의 **성질(properties)** — 완전성(completeness), 계산 복잡도 — 을 정리한다.

## 내용

### 문제의 별칭

- 경로 계획 문제의 일부 버전은 **"피아노 운반자 문제(piano-mover's problem)"** 라고 불린다. 좁은 공간으로 피아노를 조작해 통과시키는 문제에 비유된다.

### 기호와 정의

| 기호 | 정의 |
| --- | --- |
| `q` | 로봇 구성을 나타내는 n개 좌표 벡터 |
| `C ⊂ Rⁿ` | 로봇의 C-space. 일반적으로는 SE(3) 같은 임의의 다양체(manifold)일 수 있지만, **여기서는 최소 좌표로 명시적으로 매개화된 구성에 집중**한다 |
| `C_free` | 로봇이 어떤 장애물에도 접촉하지 않는 구성들의 집합 |
| `C_obs` | 로봇이 장애물과 충돌하는 구성들의 집합 |
| `x ∈ X` | 로봇의 **상태(state)** 와 상태 공간 |
| `u ∈ U` | 제어(control)와 실현 가능 제어 집합 |

**상태 `x`의 두 가지 형태**

```text
제어 입력이 속도(velocity)라면       →  x = q          (구성만)
제어 입력이 가속도 또는 힘이라면     →  x = (q, q̇)     (구성 + 속도)
```

**운동 방정식**

```text
ẋ = f(x, u),        u ∈ U
(적분 형태로도 쓸 수 있다)
```

### 모션 계획 문제의 일반적 서술

```text
초기 상태 x_start 와 원하는 최종 상태 x_goal 이 주어졌을 때,

시간 T 와 제어들의 집합을 찾아
  x(T) = x_goal 을 만족하고
  충돌이 없는(collision free) 운동이 되게 하라.
```

- **가정: 로봇과 환경에 대한 완벽한 모델을 가지고 있다.**

### 문제의 변형들

| 축 | 선택지 |
| --- | --- |
| 결과물 | **타이밍 정보를 포함한 완전한 궤적** vs **충돌 없는 기하 경로만** |
| 구동기 수 | **모든 자유도에 구동기**(대부분의 로봇 팔) vs **자유도보다 적은 구동기**(전진·후진 속도와 조향 속도 2개만 있는 자동차) |
| 실시간성 | **장애물이 움직여서 실시간으로 변경**해야 하는가 vs **로봇 운동 전에 미리** 계산해도 되는가 |
| 최적성 | **최소 시간·최소 길이·최소 비용** 운동 vs **목표에 도달하는 충돌 없는 운동이면 아무것이나** |
| 목표 | **정확히 목표 상태**에 도달 vs **목표 영역(goal region) 안 어디든** |

### 플래너의 성질 — 질의(query) 방식

| 방식 | 설명 |
| --- | --- |
| **다중 질의(multiple-query)** | **C-space의 좋은 표현을 만드는 데 시간을 투자**해, 그 공간의 향후 모션 계획 문제를 빠르게 풀 수 있게 한다 |
| **단일 질의(single-query)** | **C-space가 자주 변하는 경우**에 적합. 하나의 모션 계획 문제의 해를 가능한 빨리 찾으려 한다 |

### 플래너의 성질 — 완전성(completeness)

| 종류 | 정의 |
| --- | --- |
| **완전(complete)** | **해가 존재하면 항상 찾는다** |
| **해상도 완전(resolution complete)** | 문제 표현에 쓰인 **이산화 수준(level of discretization)에서** 해가 존재하면 항상 찾는다 |
| **확률적 완전(probabilistically complete)** | **계획 시간이 무한으로 갈 때 해를 찾을 확률이 100%로 간다** (해가 존재한다면) |

### 플래너의 성질 — 계산 복잡도

- 플래너가 **얼마나 많은 메모리를 쓰는지**, 또는 **실행에 얼마나 오래 걸리는지**를 뜻한다.
- **평균(average) 또는 최악(worst) 경우**로, **계획 문제의 기술(description)의 함수**로 표현한다.
  - 예: **로봇의 자유도 개수**, **장애물을 표현하는 데 쓰인 정점(vertex)의 개수**

## 예시

```text
# 문제 설정 요약
C = C_free ∪ C_obs
x = q  또는  (q, q̇)
ẋ = f(x, u),  u ∈ U

찾는 것: T 와 u(t) 로서  x(T) = x_goal 이고 경로가 C_free 안에 있는 것
```

## 요약

- 모션 계획은 **장애물이 있는 환경에서 시작 상태에서 목표 상태로 가는 충돌 없는 운동(시간 `T`와 제어 입력)을 찾는 문제**다. **로봇과 환경의 완벽한 모델을 가정**한다.
- `C = C_free ∪ C_obs`. 상태 `x`는 제어 입력이 **속도면 `q`**, **가속도·힘이면 `(q, q̇)`** 다. 운동 방정식은 `ẋ = f(x,u)`.
- 문제 변형 축: **궤적 vs 경로**, **완전 구동 vs 부족 구동**, **실시간 vs 사전 계산**, **최적 vs 임의 해**, **정확한 목표 상태 vs 목표 영역**.
- 플래너는 **다중 질의**(C-space 표현에 선투자)와 **단일 질의**(C-space가 자주 변할 때)로 나뉜다.
- 완전성 3단계: **완전** > **해상도 완전**(이산화 수준에서) > **확률적 완전**(시간 → ∞에서 확률 → 100%).
- 계산 복잡도는 **자유도 개수, 장애물 정점 개수** 등 문제 기술의 함수로 표현한다.
- 다음 몇 강의에서 기초 개념 — **C-space 장애물, 그래프와 트리, 그래프 탐색** — 을 소개한다.
