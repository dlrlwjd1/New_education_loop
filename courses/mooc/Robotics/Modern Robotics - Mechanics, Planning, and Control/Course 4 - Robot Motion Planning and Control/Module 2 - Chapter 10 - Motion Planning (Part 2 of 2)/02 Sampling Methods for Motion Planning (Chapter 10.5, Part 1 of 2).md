# Sampling Methods for Motion Planning (Chapter 10.5, Part 1 of 2)

## 개요

- 진짜 로드맵은 해석적으로 계산하기 어렵다. 그래서 **로드맵을 근사적으로 구성**하는 방법을 찾는다.
- **확률적 로드맵(probabilistic roadmap, PRM)** — C-space에서 표본추출한 구성들로 만든 근사 로드맵. **다중 질의(multiple-query) 플래너**로 쓰인다.

## 내용

### PRM이란

- **C-space에서 표본추출한 구성 집합으로 구성**된다.
- **"확률적" 로드맵이라 불리는 이유: 표본 수가 무한으로 갈 때 그 그래프가 진짜 로드맵일 확률이 100%로 간다.**
- 격자 기반 그래프에 대한 장점: **자유 C-space의 구조를 격자 그래프보다 훨씬 적은 노드로 포착한다.**
- **PRM은 고차원 C-space의 복잡한 모션 계획 문제를 푸는 데 사용되어 왔다.**

### PRM 구성 알고리즘 — 1단계: 표본추출

```text
자유 C-space의 표본 N 개를 생성한다.

기본 방법: C-space를 균일 무작위(uniformly randomly)로 표본추출하고
           충돌이 없는(collision-free) 표본만 유지한다.

비균일(non-uniform) 표본추출 전략도 쓸 수 있다.
목적: 더 적은 표본으로도 PRM이 C-space의 좁은 통로(narrow passageways)를
      표현할 가능성을 높인다.
```

- 이 N개 자유 구성이 **그래프의 노드**가 된다.

### PRM 구성 알고리즘 — 2단계: 간선 연결

```text
for 각 노드:
    가까운 노드 k 개의 집합을 찾는다

    for 각 이웃 노드:
        아주 단순하고 빠른 국소 경로 플래너(local path planner)로
        원래 노드에서 이웃까지의 경로를 찾는다.
        이 플래너는 장애물 회피를 시도하지 않는다.
        (예: 두 노드 사이의 직선)

        그 경로가 충돌 없는지 확인하고,
        충돌이 없으면 두 노드 사이에 간선을 추가한다
```

### PRM을 결정하는 4가지 선택

| 선택 | 설명 |
| --- | --- |
| **표본 수 `N`** | |
| **이웃 수 `k`** | |
| **표본추출 알고리즘** | 균일 무작위 / 비균일 / 결정적 |
| **국소 경로 플래너** | 직선 등 |

- **표본추출 알고리즘과 국소 경로 플래너의 선택이 기본 알고리즘을 맞춤화할 큰 유연성을 준다.**

### 사용 방식 — 다중 질의 플래너

```text
PRM 생성 = C-space 전처리(preprocessing)

이후 서로 다른 경로 계획 문제를
  다른 시작·목표 구성을 PRM 에 연결하고
  A* 탐색으로 PRM 위의 좋은 경로를 찾아서 푼다
```

- 따라서 **PRM 플래너는 보통 다중 질의 플래너로 여겨진다**: **자유 C-space의 좋은 표현을 만드는 데 시간을 투자해, 이후 여러 모션 계획 문제를 효율적으로 풀 수 있게 한다.**

## 예시

```text
# PRM 구성
1단계: 자유 구성 N 개 표본추출 (충돌 없는 것만 유지)
2단계: 각 노드마다 가까운 k 개 이웃에 대해
       국소 플래너(예: 직선)로 경로 생성 → 충돌 없으면 간선 추가

# PRM 사용 (다중 질의)
start, goal 을 PRM 에 연결  →  A* 로 PRM 위 경로 탐색
```

## 요약

- **PRM은 표본추출로 만든 근사 로드맵**이다. **표본 수 → ∞ 일 때 진짜 로드맵일 확률 → 100%** 라서 "확률적"이다.
- 격자 그래프보다 **훨씬 적은 노드로 자유 C-space 구조를 포착**하며, **고차원 문제에 성공적으로 쓰였다.**
- 구성은 2단계다: **(1) 충돌 없는 자유 구성 N개 표본추출**, **(2) 각 노드의 가까운 이웃 k개에 대해 빠른 국소 플래너(예: 직선)로 경로를 시도하고 충돌이 없으면 간선 추가.**
- **국소 플래너는 장애물 회피를 하지 않는다** — 회피는 별도의 충돌 검사가 담당한다.
- **비균일 표본추출**을 쓰면 적은 표본으로도 **좁은 통로**를 표현할 가능성이 높아진다.
- 결과 품질은 **`N`, `k`, 표본추출 알고리즘, 국소 플래너** 네 선택에 달려 있다.
- PRM은 **다중 질의 플래너**다. 한 번 전처리해 두면 여러 시작·목표 쌍을 A\*로 빠르게 풀 수 있다.
- 다음 강의에서 **단일 질의**에 주로 쓰이는 표본 기반 플래너(RRT)를 다룬다.
