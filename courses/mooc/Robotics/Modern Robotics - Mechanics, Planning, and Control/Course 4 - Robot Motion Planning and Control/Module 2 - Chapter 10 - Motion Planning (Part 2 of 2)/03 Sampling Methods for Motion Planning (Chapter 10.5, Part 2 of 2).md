# Sampling Methods for Motion Planning (Chapter 10.5, Part 2 of 2)

## 개요

- **RRT (rapidly exploring random tree, 빠르게 탐색하는 무작위 트리)** — **임의의 동역학 `ẋ = f(x,u)`** 를 갖는 로봇에 적용되는 인기 있는 표본 기반 플래너.
- 무작위 표본이 트리를 **끌어당겨(pull)** 상태 공간을 탐색하게 한다. 무작위 걷기(random walk)보다 훨씬 효율적이다.
- **RRT\*** 는 트리를 계속 재배선(rewiring)해 노드 수 → ∞ 에서 최적해에 수렴한다.

## 내용

### 기본 아이디어

```text
T       : 부분적으로 형성된 탐색 트리
x_start : 초기 상태
X       : 상태 공간
X_goal  : 허용되는 최종 상태들의 집합

반복:
  1. 무작위 상태 x_samp 를 선택
  2. 트리에 이미 있는 가장 가까운 노드 x_nearest 를 찾는다
  3. x_nearest 에서 x_new 로 가는 충돌 없는 운동을 찾는다
     (x_new 는 x_samp 와 같을 수도 있고 아닐 수도 있지만,
      최소한 x_samp 방향(direction)이다)
  4. 탐색 트리를 갱신한다

목표 영역 X_goal 안에 노드가 생기면 종료.

※ 때때로 x_samp 를 X_goal 안에서 선택해 계획 문제를 완결하려 시도해야 한다.
```

### RRT vs 무작위 걷기 (random walk)

| | RRT | 무작위 걷기 |
| --- | --- | --- |
| 성장 방식 | **무작위 표본이 트리를 끌어당겨** 탐색 | 매 스텝 **무작위로 고른 노드**에서 **무작위 방향**으로 최대 스텝만큼 성장 |
| 같은 노드 수에서 | 상태 공간을 널리 탐색 | **거의 탐색하지 못했다** |

### 의사코드

```text
1  T ← {x_start}
2  while 반복:
3      x_samp ← 상태 공간에서 표본추출
4      x_nearest ← 트리에서 x_samp 에 가장 가까운 노드
5      x_new ← 국소 플래너로 x_nearest 에서 x_samp 에 더 가까운 상태로
6      if 그 운동이 충돌 없으면:
7          트리에 새 간선(x_nearest → x_new) 추가
8      if x_new ∈ X_goal:
9          성공 — 목표 영역의 노드에서 부모 노드를 거꾸로 따라가 계획 복원
```

### 3번 줄 — 표본추출기(sampler)

- 상태 공간 `X`에서 **균일 무작위**로 고를 수 있지만, **결정적(deterministic) 표본추출 방식**도 가능하다.

| 방식 | 설명 |
| --- | --- |
| **판데르코르푸트(Van der Corput) 수열** | **1차원 상태 공간**에 사용. **구간을 뛰어다니며 점점 더 촘촘하고 거의 균일한 표본추출**을 제공하는 결정적 수열. **해를 찾을 때까지 해상도가 올라가는 다해상도 표본추출**처럼 동작해서 매력적이다 |
| **핼턴(Halton) 수열** | 판데르코르푸트 수열의 **고차원 일반화** |

- **알고리즘 설계자가 작업에 가장 적합한 표본추출 알고리즘을 고를 수 있다.**
- 표본추출기는 **때때로 목표 영역의 상태도 표본추출**해서 계획을 완결하려 해야 한다.

### 4번 줄 — 가장 가까운 노드 찾기와 "거리"의 정의

- 이 연산을 효율화하는 다양한 자료구조·알고리즘이 있지만, 먼저 **두 상태 사이 거리의 합리적인 정의**가 있어야 한다.
- 문제: **구성이 선형 좌표와 각 좌표로 이루어져 있으면, 1 라디안과 1 미터의 거리를 어떻게 비교하는가?**
- 자동차 예제: 표본 구성(파란 자동차)에 대해 트리 안의 여러 구성(흰 자동차) 중 어느 것이 가장 가까운가?
  - 강의자의 답: **자동차의 운동 제약을 고려할 때, 표본까지 가는 경로에 시간이 가장 적게 드는 구성**이 가장 가깝다고 보는 것이 맞다.

### 5번 줄 — 국소 플래너 (local planner)

- 트리의 노드에서 표본 상태에 더 가까운 새 상태로 가는 운동을 찾는다. **빠르게 실행되어야 한다.**
- **충돌 검사는 6번 줄이 담당하므로 국소 플래너는 충돌을 걱정하지 않아도 된다.**

| 국소 플래너 | 적용 대상 | 설명 |
| --- | --- | --- |
| **직선(straight-line)** | **완전 구동 운동학 로봇, 속도 입력** | 가장 단순 |
| **제어 이산화 + 전방 적분** | **일반 동역학 `ẋ = f(x,u)`** | **제어 집합을 이산화하고, 각각을 일정 시간 전방 적분해, 표본 상태에 가장 가까워지는 것을 `x_new`로 선택.** 단순하고 **어떤 로봇에도 적용 가능해서 매력적** |
| **로봇에 특화된 플래너** | 특정 로봇 | 예: 자동차형 로봇의 **리즈-셰프(Reeds-Shepp) 곡선** — **장애물을 고려하지 않고 두 구성 사이 경로 길이를 최소화하는 경로.** 국소 계획의 좋은 후보 |

**자동차형 로봇의 제어 이산화 예**

```text
제어 2개: 선속도 v, 각속도 ω

선속도와 최소 회전 반경이 유계(bounded)이면
제어 집합의 경계가 나비넥타이(bowtie) 모양이 된다

이 제어 집합을 6개 속도로 이산화:
  전진, 후진, 그리고 가장 급한 회전 반경의 회전들

각 제어를 적분한 궤적들 중, 표본 상태에 가장 가까운 것을 선택
그 경로가 충돌 없으면 x_new 를 RRT 에 추가
```

### RRT의 특성과 개선

- **RRT는 코딩이 간단하고 맞춤화가 쉬우며, 다양한 응용에 변형이 사용되어 왔다.**
- **일반적으로 복잡한 모션 계획 문제를 빠르게 풀도록 설계되었으나, 해의 품질(quality)은 고려하지 않는다.**

**해 품질 개선 방법 1 — 계속 성장시키기**

- 초기 해를 찾은 뒤에도 **RRT를 계속 성장시키고 최선의 해를 유지**한다.
- 예시: 트리에 노드 5000개를 생성한 뒤 녹색 목표 영역까지 찾은 최선 경로.
- **단점: 이 과정은 최적해로 수렴하지 않는다.**

**해 품질 개선 방법 2 — RRT\***

- 기본 알고리즘의 수정판인 **RRT\*** 는 **탐색 트리를 계속 재배선(rewire)** 해서, **노드 수가 무한으로 갈 때 해가 최적해로 수렴**한다.
- **단점: RRT\*는 임의의 로봇 동역학에는 적용할 수 없다.**

### 표본 기반 방법의 위치

- RRT, PRM 및 관련 알고리즘은 **단순성**과 **일부 복잡한 모션 계획 문제에서의 성능** 때문에 인기가 있다.
- 구현이 계속 빨라지고 있지만, **전통적으로는 오프라인 플래너로 사용되어 왔다.**

## 예시

```text
# RRT 한 반복
x_samp   ← Sample(X)                     (때때로 X_goal 에서)
x_nearest ← NearestNode(T, x_samp)
x_new    ← LocalPlanner(x_nearest, x_samp)
if CollisionFree(x_nearest → x_new): T ← T ∪ {edge}
if x_new ∈ X_goal: 부모 포인터 역추적으로 계획 복원

# 표본추출기 선택
균일 무작위 / 판데르코르푸트(1D) / 핼턴(고차원)

# 국소 플래너 선택
직선 (완전 구동·속도 입력)
제어 이산화 + 전방 적분 (임의 동역학)
리즈-셰프 곡선 (자동차형 로봇)
```

## 요약

- **RRT는 `ẋ = f(x,u)` 형태의 임의 동역학에 적용되는 단일 질의 플래너**다. 매 반복에서 **표본추출 → 최근접 노드 찾기 → 국소 플래너로 표본 방향으로 전진 → 충돌 없으면 트리에 추가**를 반복하고, **목표 영역에 노드가 생기면 부모 포인터를 역추적**해 계획을 복원한다.
- **무작위 표본이 트리를 끌어당겨 상태 공간을 빠르게 탐색**한다. 무작위 걷기는 같은 노드 수로 훨씬 적게 탐색한다.
- **표본추출기**는 균일 무작위 외에 **판데르코르푸트(1D)·핼턴(고차원)** 같은 결정적 수열도 가능하고, 이는 **점진적 다해상도** 효과를 준다. **때때로 목표 영역을 표본추출**해야 한다.
- **최근접 노드 찾기에는 "거리"의 정의가 필요**하다. 라디안과 미터를 어떻게 비교할지가 문제이며, **로봇의 운동 제약을 고려한 도달 시간**이 합리적 기준이다.
- **국소 플래너는 빠르면 되고 충돌은 신경 쓰지 않아도 된다**(별도 검사). 선택지는 **직선**(완전 구동·속도 입력), **제어 이산화 + 전방 적분**(임의 동역학, 범용), **리즈-셰프 곡선**(자동차형) 등이다.
- RRT는 **빠른 해를 목표로 하고 해의 품질은 보장하지 않는다.** 계속 성장시켜 최선 해를 유지해도 **최적으로 수렴하지 않는다.** **RRT\*** 는 재배선으로 **노드 수 → ∞ 에서 최적 수렴**하지만 **임의 동역학에는 적용할 수 없다.**
- 다음 강의에서 **인공 포텐셜 필드 기반 실시간 궤적 생성**을 다룬다.
