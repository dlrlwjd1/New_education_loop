# Grid Methods for Motion Planning (Chapter 10.4)

## 개요

- C-space를 **격자(grid)** 로 이산화해 그래프를 만들고 A\*로 탐색한다.
- 성질: **완전하지는 않지만 해상도 완전(resolution complete)** 하고, **격자 그래프에 대해서는 최적**이다.
- 치명적 단점: **고차원 공간에 실용적이지 않다.** 완화책으로 **다해상도 격자(쿼드트리/옥트리)** 를 쓴다.

## 내용

### 격자 만들기

```text
C-space가 n차원이고 각 차원을 k개 구간으로 분할하면
→ 총 kⁿ 개의 격자 셀(grid cell)

각 셀은 그래프에서 노드 하나로 표현되며,
그 노드는 셀 중심(center)의 구성을 나타낸다.

예: 2R 로봇, k = 32  →  32² = 1024 개 셀
```

### 장애물의 보수적 표현

- 장애물이 **닿는 모든 C-space 격자 셀을 장애물로 표시**하면 C-space 장애물이 **보수적(conservative)** 으로 만들어진다. (안전 쪽으로 치우친다)

### 격자를 그래프로 — 4-연결 vs 8-연결

| 방식 | 간선 조건 |
| --- | --- |
| **4-연결(4-connected)** | 두 자유 셀이 서로 **북·남·동·서 바로 옆**이면 간선이 존재 |
| **8-연결(8-connected)** | 위에 더해 **대각선으로 인접한 자유 셀도 연결** |

- 자유 셀의 중심이 그래프의 노드이고, 간선은 4-연결 또는 8-연결 자유 셀 사이에 놓인다.

### A\* 탐색

- **그래프 전체를 미리 명시적으로 구성할 필요가 없다.** 4-연결/8-연결 규칙을 써서 **탐색하면서 구성**할 수 있다.
- **낙관적 비용**은 **조인트 공간의 최단 직선 경로**다. 단 **각 조인트의 0과 2π에서의 되감김(wraparound)을 고려**해야 한다.
- 셀이 4-연결이면 이 경로가 **최적**이다.
- **최적 경로는 유일하지 않다.** 같은 경로 길이를 갖는 다른 경로들도 존재한다.

### 시작·목표가 셀 중심이 아닐 때

```text
시작 구성 → 그 셀의 중심          (첫 경로 구간)
… 격자 그래프 경로 …
셀 중심 → 목표 구성               (마지막 경로 구간)
```

### 적용 범위와 한계

- **제약이 있는 경우**(예: 옆으로 움직일 수 없는 자동차) 또는 **로봇이 동역학적이고 제어 입력이 속도가 아니라 힘인 경우**에는 격자 기반 방법을 **수정해야 한다**(교재 참조).
- 위에서 설명한 단순 격자 기반 플래너는 **제어 입력이 속도인 모든 완전 구동(fully actuated) 운동학 시스템**에 적용할 수 있다.

### 성질

| 성질 | 설명 |
| --- | --- |
| **완전(complete)** | ❌ **C-space 이산화 때문에 완전하지 않다** |
| **해상도 완전(resolution complete)** | ✅ **선택한 이산화 수준에서 경로가 존재하면 찾는다** |
| **최적(optimal)** | ✅ **A\* 탐색을 쓰는 기반 그래프에 대해서는 최적** |
| 고차원 실용성 | ❌ **주요 단점.** 격자를 표현하는 메모리와 탐색 시간이 **자유도 개수에 따라 빠르게 증가**한다 |

### 완화책 — 다해상도 격자 (multi-resolution grid)

- 핵심 아이디어: **이산화 수준 `k`를 미리 정하지 않고**, **넓게 열린 영역은 거칠게, 복잡한 영역은 세밀하게** 표현한다.
- 목표: **C-space 표현을 비교적 작게 유지하면서도 자유 공간의 좁은 통로를 표현할 수 있게** 한다.

**예제 — 세분(subdivision) 과정**

```text
진한 회색 상자 = C-space 셀 하나,  밝은 상자 = C-space 장애물

고정 해상도로 표현하면 → 이 셀 전체가 충돌로 표시된다

셀을 4개로 세분  → 그중 1개만 충돌
다시 세분        → …
다시 세분        → …

결과: 원래 C-space 셀이 트리로 표현된다.
      트리의 잎(leaf) 10개가 최종 셀이고, 그중 2개(회색)만 충돌이다.

고정 해상도 격자로 같은 해상도를 얻으려면 64개 셀이 필요했다.
```

| 이름 | 차원 | 세분 수 |
| --- | --- | --- |
| **쿼드트리(quadtree)** | 2차원 | 셀이 **4개**로 세분 |
| **옥트리(octree)** | 3차원 | 셀이 **8개**로 세분 |

## 예시

```text
# 격자 크기
n차원 C-space, 각 차원 k구간  →  kⁿ 셀
2R 로봇, k = 32  →  1024 셀

# 연결성
4-연결: 북·남·동·서
8-연결: + 대각선

# 낙관적 비용
조인트 공간 직선 거리 (0 ↔ 2π wraparound 고려)

# 다해상도
쿼드트리(2D, 4분할) / 옥트리(3D, 8분할)
예제: 잎 10개(충돌 2개) vs 고정 해상도 64셀
```

## 요약

- C-space의 각 차원을 `k`구간으로 나누면 **`kⁿ` 셀**이 되고, 각 셀 중심이 그래프 노드가 된다. 장애물이 닿는 셀을 모두 장애물로 표시해 **보수적**으로 만든다.
- 간선은 **4-연결**(상하좌우) 또는 **8-연결**(대각 포함) 규칙으로 정하며, **그래프를 미리 만들지 않고 탐색하면서 생성**할 수 있다.
- 낙관적 비용은 **조인트 공간 직선 거리**이고, **0/2π 되감김을 반영**해야 한다. 4-연결에서는 결과가 최적이다(단 **유일하지 않다**).
- **해상도 완전하고 격자 그래프에 대해 최적이지만 완전하지는 않다.** **고차원에서 메모리·시간이 급격히 늘어나는 것이 치명적 단점**이다.
- **제어 입력이 속도인 완전 구동 운동학 시스템**에 그대로 적용된다. 자동차처럼 제약이 있거나 힘 입력인 동역학 시스템에는 수정이 필요하다.
- **다해상도 격자(쿼드트리/옥트리)** 로 완화한다. **빈 곳은 거칠게, 복잡한 곳은 세밀하게** 나눠 표현 크기를 줄이면서 좁은 통로를 유지한다.
- 다음 강의에서 **무작위 표본추출(random sampling)** 로 C-space 그래프를 만드는 방법을 다룬다.
