# Nonlinear Optimization (Chapter 10.7)

## 개요

- 모션 계획을 **비선형 최적화(nonlinear optimization)** 문제로 정식화한다.
- 두 가지 접근: **슈팅(shooting)** 과 **콜로케이션(collocation)**. 문제를 유한 매개변수 최적화로 바꾸는 과정을 **전사(transcription)** 라 한다.
- 본질적으로 **국소 방법**이므로 **좋은 초기 추측이 있을 때 좋은 선택**이다. 예: **RRT 해를 매끄럽게 다듬기**.

## 내용

### 문제 정식화

```text
설계 대상:
  제어 이력(control history) u(t)
  궤적 q(t)
  궤적 지속 시간 T

목적: 어떤 비용 함수(cost functional) J 를 최소화
      (예: 구동기가 소비한 총 에너지, 또는 운동 시간)

제약(constraints):
  동역학 방정식이 모든 시각에 만족된다
  제어가 실현 가능하다(feasible)
  운동이 충돌 없다
  궤적이 시작 상태를 목표 상태로 가져간다
```

- `J`를 **비용(cost)** 이라 하고, 나머지 조건들이 **제약**이다.

### 유한 매개변수 표현이 필요하다

- **비선형 최적화는 해에 대한 초기 추측(initial guess)을 요구한다.**
- 모션 계획 문제를 비선형 최적화로 바꾸려면 **제어의 유한 매개변수 표현**이 필요하다. 여러 방법이 있다.

| 표현 방법 |
| --- |
| **매듭점(knot points)을 다항식이나 스플라인으로 보간** |
| **구간별 상수(piecewise constant) 제어** |
| **구간별 선형(piecewise linear) 제어** |

- 예제에서는 **구간별 선형 제어**를 가정한다.

### 반복 과정

```text
1. 초기 추측 제어 이력을 정한다

2. 운동 방정식을 적분해 로봇의 궤적을 얻는다
   → 이 궤적이 장애물과 교차하고 목표 구성에서 끝나지 않으면, 해가 아니다

3. 장애물로 인한 제약을 평가한다:
   궤적 위의 유한 개 시험점(test points)을 골라 충돌 없는지 평가
   충돌 제약 = 시험점과 장애물 사이의 거리에 대한 제약
     거리 > 0  → 충돌 없음
     거리 < 0  → 충돌

4. 제약의 궤적에 대한 기울기(gradient)를 계산한다
   → 제약을 만족하려면 시험점들이 어떻게 움직여야 하는지를 알려준다

5. 그 기울기를 "궤적의 제어에 대한 기울기"를 통해 사상해,
   제어 이력 추측을 수정할 방향을 얻는다
   (비용의 제어에 대한 기울기 정보도 함께 사용한다)

6. 제어 이력을 갱신하고 새 제어를 적분해 갱신된 궤적을 얻는다

7. 제약을 만족하고 비용을 국소적으로 최소화하는 궤적을 찾을 때까지 반복
```

### 두 가지 접근법

| 접근법 | 설계 변수 | 궤적을 얻는 방법 | 비유 |
| --- | --- | --- | --- |
| **슈팅(shooting)** | **총 시간 `T`와 제어 이력을 기술하는 매개변수들** | **운동 방정식을 시뮬레이션**해서 얻는다. 이렇게 하면 **동역학 제약이 자동으로 만족된다** | **대포를 조준하는 것과 같다.** 발사해 보고 결과를 보고 다음 시도에서 목표에 더 가까워지도록 조준을 수정한다 |
| **콜로케이션(collocation)** | **제어 이력과 궤적을 동시에** 설계 | 둘을 모두 설계하므로 **제어와 궤적이 동역학에 따라 일관적(consistent)임을 강제해야 한다.** 보통 **유한 개 시험점에서 운동 방정식이 만족되게** 한다 | |

### 전사(transcription)

- 문제 서술을 **표준적인 유한 매개변수 비선형 최적화 문제로 바꾸는 과정**을 **전사(transcription)** 라 한다.
- 그 결과는 **순차 이차 계획법(sequential quadratic programming, SQP)** 같은 기법으로 풀 수 있다.

### 결정적으로 중요한 것 — 기울기

- **제어, 궤적, 비용, 제약을 표현하는 방법은 여러 가지이고, 그 선택이 최적화 성능에 영향을 준다.**
- 그러나 **결정적으로 중요한 것은 설계 변수에 대한 비용과 제약의 기울기를 계산할 수 있어야 한다는 점**이다. **이 기울기가 설계 변수 공간의 탐색을 안내한다.**
- **이상적으로는 해석적으로 계산**할 수 있어야 하고, 그렇지 못하면 **효율적이고 정확하게 수치적으로 평가**할 수 있어야 한다.

### 한계 — 국소 방법

- 기울기 계산이 좋아도, **기울기 기반 비선형 최적화는 본질적으로 국소(local) 방법**이다.
- **국소 최소점에 갇히기 쉽고**, 그 결과 해가 **비용을 전역적으로 최소화하지 못하거나 제약을 만족하지 못할 수 있다.**

### 좋은 사용법 — 다른 방법과의 결합

- **다른 방법으로 합리적인 초기 추측을 제공할 수 있을 때 좋은 선택이다.**
- 예: **RRT가 찾은 덜컹거리는(jerky) 운동을 비선형 최적화로 매끄럽게 만든다.**
  - **RRT가 어수선한 환경에서의 전역 탐색을 담당하고, 비선형 최적화가 그 해를 변형해 비용을 국소적으로 최소화한다.**

## 예시

```text
# 문제
min_{u(t), q(t), T}  J
s.t.  q̇ = f(q, u)          (동역학)
      u ∈ U                 (제어 실현 가능)
      d(q(t), obstacles) > 0  (충돌 없음)
      q(0) = q_start,  q(T) = q_goal

# 슈팅 vs 콜로케이션
슈팅:      설계 = (T, 제어 매개변수),  궤적 = 시뮬레이션 결과 (동역학 자동 만족)
콜로케이션: 설계 = (제어, 궤적) 동시,  동역학은 시험점에서 강제

# 결합 사용
RRT (전역 탐색) → 비선형 최적화 (국소 매끄럽게 하기)
```

## 요약

- 모션 계획을 **비용 `J`를 최소화하면서 동역학·제어 실현 가능성·충돌 없음·종단 조건을 제약으로 갖는 비선형 최적화**로 정식화한다.
- 풀려면 **제어의 유한 매개변수 표현**(매듭점+스플라인, 구간별 상수/선형)과 **초기 추측**이 필요하다.
- 반복 과정: **제어 적분 → 궤적 → 시험점에서 충돌 거리 평가 → 제약의 기울기 → 궤적→제어 감도로 사상 → 제어 갱신 → 재적분.**
- **슈팅**은 `T`와 제어만 설계하고 궤적을 시뮬레이션으로 얻는다(동역학 자동 만족). **대포 조준** 비유. **콜로케이션**은 제어와 궤적을 동시에 설계하고 **시험점에서 동역학 일관성을 강제**한다.
- 문제를 표준 유한 매개변수 최적화로 바꾸는 것이 **전사**이고, SQP 등으로 푼다.
- **가장 중요한 요구사항은 비용·제약의 기울기 계산 능력**이다. 해석적이 최선이고, 아니면 효율적·정확한 수치 평가가 필요하다.
- **본질적으로 국소 방법이라 국소 최소점에 갇히기 쉽다.** 그래서 **좋은 초기 추측을 다른 방법에서 얻을 때 유용**하다 — **RRT로 전역 탐색, 비선형 최적화로 국소 다듬기** 조합이 대표적이다.
- 이로써 Chapter 10이 끝난다. Chapter 11에서는 **모션 플래너가 만든 궤적을 따라 로봇을 구동하는 피드백 컨트롤러 설계**를 다룬다.
