# Introduction to the Capstone Project: Mobile Manipulation

## 개요

- 캡스톤 프로젝트의 목표: **지금까지 배운 것들을 하나의 프로젝트로 통합**하는 것.
- 하는 일: **시뮬레이션된 모바일 매니퓰레이터의 궤적을 계획하고, 계획된 궤적을 따르도록 운동을 제어**한다.

## 내용

### 프로젝트가 통합하는 것

```text
궤적 계획(trajectory planning)
주행 거리 측정(odometry)
피드백 제어(feedback control)
```

### 사용 도구

- 개발한 소프트웨어를 시연하기 위해 **로봇 시뮬레이터**를 사용한다. (강의 음성에서는 시뮬레이터 이름이 "virape"로 전사되었는데, 이 강좌가 안내하는 시뮬레이터는 **CoppeliaSim**이다 — 스페셜라이제이션 Course 1 Module 1의 CoppeliaSim 보충 자료 참조.)

### 참고

- 더 자세한 내용은 **이어지는 영상들과 서면 프로젝트 설명(written project description)** 에 있다.

## 요약

- 캡스톤은 **궤적 계획 + 주행 거리 측정 + 피드백 제어**를 하나로 묶는 프로젝트다.
- 대상은 **시뮬레이션된 모바일 매니퓰레이터**이며, 계획한 궤적을 추종하도록 제어한다.
- 구체적인 요구사항은 **다음 영상들과 서면 프로젝트 설명**에서 제시된다.
