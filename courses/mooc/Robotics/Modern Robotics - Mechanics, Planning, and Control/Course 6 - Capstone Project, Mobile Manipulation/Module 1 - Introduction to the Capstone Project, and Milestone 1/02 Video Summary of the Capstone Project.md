# Video Summary of the Capstone Project

## 개요

- 과제: **모바일 매니퓰레이터가 블록(block)을 초기 구성에서 목표 구성으로 운반**하도록 제어하는 소프트웨어를 작성한다.
- 작성할 세 가지 소프트웨어: **기준 궤적 계획기**, **피드백 컨트롤러**, **시뮬레이터(주행 거리 측정 기반)**.
- 그리퍼 기준 궤적은 **8개 궤적 구간의 연결(concatenation)** 이다.

## 내용

### 작성해야 할 소프트웨어 세 가지

| 순서 | 소프트웨어 | 역할 |
| --- | --- | --- |
| 1 | **궤적 계획기** | **엔드 이펙터의 공칭(nominal) 궤적을 계획**한다 |
| 2 | **피드백 컨트롤러** | **초기 오차와 외란을 고려해** 엔드 이펙터를 궤적을 따라 몰아간다 |
| 3 | **시뮬레이터** | **컨트롤러가 명령한 바퀴 속도로부터 섀시의 운동을 계산**하기 위해 **주행 거리 측정(odometry)** 을 사용한다 |

- **주행 거리 측정 추정치는 피드백 컨트롤러도 사용할 수 있다고 가정한다.**

### 그리퍼 기준 궤적 — 8개 구간

```text
구간 1 : 블록 위의 스탠드오프(standoff) 구성으로 그리퍼를 가져간다
구간 2 : 그리퍼를 블록까지 내린다
구간 3 : 그리퍼를 닫는다 (파지)
구간 4 : 블록을 들어 올린다
구간 5 : 블록을 목표 구성 위의 지점으로 옮긴다
구간 6 : 블록을 내려놓는다
구간 7 : 블록을 놓는다 (그리퍼를 연다)
구간 8 : 그리퍼를 멀리 치운다
```

### 애니메이션에서 관찰할 것

```text
구간 1 : 그리퍼가 기준 궤적에서 벗어난 구성에서 시작하고,
         피드백 컨트롤러가 그리퍼를 기준 궤적으로 되돌린다
구간 2 : 그리퍼를 아래로 이동
구간 3 : 블록을 파지
구간 4 : 그리퍼를 위로 이동
구간 5 : 블록의 목표 구성 쪽으로 이동
구간 6 : 블록을 내려놓기
구간 7 : 블록을 놓기
구간 8 : 그리퍼를 멀리 이동
```

### 최종 산출물

- **소프트웨어의 출력은 피드백 컨트롤러가 결정한 모바일 매니퓰레이터의 시뮬레이션된 운동**이다.
- 상세는 **서면 프로젝트 설명(written project description)** 에 있다.

## 요약

- 캡스톤 과제는 **모바일 매니퓰레이터로 블록을 집어서 목표 위치로 옮기는 것**이다.
- 세 가지를 직접 작성한다: **공칭 궤적 계획기**, **초기 오차·외란을 잡아 주는 피드백 컨트롤러**, **주행 거리 측정으로 섀시 운동을 계산하는 시뮬레이터**. **주행 거리 측정 추정치는 컨트롤러도 사용할 수 있다고 가정**한다.
- 기준 궤적은 **8개 구간**이다: **스탠드오프 접근 → 하강 → 그리퍼 닫기 → 들어올리기 → 목표 위로 이동 → 내려놓기 → 놓기 → 치우기.**
- **구간 1에서 그리퍼가 기준 궤적을 벗어난 상태로 시작**하므로 피드백 컨트롤러의 수렴을 확인할 수 있다.
- 최종 출력은 **컨트롤러가 만든 시뮬레이션 운동**이다.
