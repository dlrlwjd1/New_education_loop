# Introduction to the Course

## 개요
- 강좌 전체 구성을 소개하는 도입 강의. **NestJS**로 효율적이고 확장 가능한(scalable) Node.js 애플리케이션을 만드는 방법을 다루는 강좌라는 것을 안내한다.

## 내용
### 강좌 구성 — 2개 모듈
- **Module 1 (Getting Started with NestJS)**: NestJS의 의의를 소개하고, 개발 환경 설정, NestJS 아키텍처 이해, 첫 NestJS 애플리케이션 생성까지 기초를 다진다.
- **Module 2 (Services, Middleware, and Exception Filters)**: Services, Middleware, Exception Filters 등 견고하고 확장 가능한 애플리케이션을 만드는 데 필수적인 구성 요소를 다룬다. 비즈니스 로직 처리, 요청 관리, 에러 처리를 효과적으로 수행하는 법을 배운다.

### 학습 목표
- 강좌를 마치면 NestJS의 핵심 개념부터 더 심화된 주제까지 포괄적으로 이해하게 되어, 효율적이고 확장 가능한 Node.js 애플리케이션을 개발할 수 있게 된다.
- NestJS를 처음 접하는 사람이든, 기존 Node.js 개발 역량을 강화하려는 사람이든 모두를 대상으로 한다.
