# What You Will Learn in This Lesson

## 개요
- "Introduction to NestJS" 레슨에서 다룰 세 가지 핵심 주제(NestJS 개요, 개발 환경 설정, 프로젝트 구조)를 미리 안내하는 짧은 도입 강의.

## 내용
### NestJS 소개
- **NestJS**는 효율적이고 확장 가능한(scalable) 웹 애플리케이션을 구축하기 위해 설계된, 진보적이고(progressive) 다재다능한(versatile) Node.js 프레임워크다.

### 이 레슨에서 다룰 세 가지 주제
- **NestJS 개요(overview)**: 현대 웹 개발에서 NestJS가 가지는 의미와 중요성을 살펴본다.
- **개발 환경 설정(setting up the development environment)**: NestJS 애플리케이션 개발에 필요한 도구와 설정 과정을 안내한다.
- **프로젝트 구조(project structure)**: NestJS 애플리케이션이 코드를 어떻게 조직하고 관리하는지에 대한 기초적인 이해를 제공한다.

### 학습 목표
- 이 레슨을 마치면 자신감과 숙련도를 가지고 NestJS 개발을 시작하는 데 필요한 지식과 리소스를 갖추게 된다.
