# What You Will Learn in This Lesson

## 개요
- "Middleware and Exception Filters" 레슨에서 다룰 세 가지 핵심 주제(미들웨어 이해, 예외 필터, 통합 실습)를 미리 안내하는 도입 강의.

## 내용
### 이 레슨에서 다룰 세 가지 주제
- **미들웨어 이해(understanding middleware)**: 애플리케이션 제어를 최적화하기 위해 요청(requests)을 가로채고(intercept) 수정하는(modify) 방법을 살펴본다.
- **예외 필터(exception filters)**: 오류 처리(error handling)에 초점을 맞추어, 예외(exceptions)에 세련되게 대응하고 응답하는 전략을 다룬다.
- **통합 실습(putting it all together)**: 미들웨어와 예외 필터를 하나로 통합해, 견고한(robust) NestJS 애플리케이션을 만드는 과정을 보여준다.

### 학습 목표
- 이 레슨은 NestJS가 트래픽을 처리하고(directing traffic) 오류를 관리하는(managing errors) 메커니즘을 간결하게 탐구한다.
- 레슨을 마치면 요청 처리(request handling)와 오류 관리(error management)를 자신 있게 다룰 수 있는 도구를 갖추게 된다.
