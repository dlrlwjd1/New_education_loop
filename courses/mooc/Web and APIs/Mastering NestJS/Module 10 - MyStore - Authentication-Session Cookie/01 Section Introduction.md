# Section Introduction

## 개요
- MyStore 애플리케이션에 인증(authentication) 기능을 구현하는 이번 섹션의 전체 목표와 흐름을 소개하는 강의.

## 내용
### 인증(authentication)이 필요한 이유
- 이메일 서비스나 은행, 이커머스 사이트처럼 회원가입(sign up)을 한 사용자만 로그인(log in)해서 사용할 수 있는 기능이 있는 것처럼, MyStore 앱에도 동일한 개념의 인증 기능을 구현할 예정이다.
- 사용자는 먼저 회원가입(sign up)을 하고, 이후 아이디(username)와 비밀번호(password) 같은 유효한 자격 증명(credentials)으로 로그인(log in)한다.
- 이렇게 애플리케이션에 의해 승인(approved)된 상태, 즉 인증된(authenticated) 상태가 되어야만 특정 링크나 기능에 접근할 수 있다.

### 이번 섹션에서 구현할 내용
- 현재는 애플리케이션이 시작되면 모든 링크와 기능이 제한 없이 노출되어 있지만, 이제 특정 기능은 로그인한 사용자에게만 보이도록 제한할 예정이다.
- 먼저 회원가입 링크(sign up link)와 회원가입 폼(sign up form)을 추가해 사용자를 등록(register)할 수 있게 한다.
- 그다음 로그인 링크(login link)와 로그인 폼(login form)을 추가한다.
- 사용자가 로그인하지 않은 상태에서는 홈 화면에 로그인(login)과 회원가입(sign up) 링크가 보이고 모든 상품(product) 목록도 보이지만, 수정(edit)·삭제(delete) 버튼은 보이지 않는다. 또한 상품 추가(add product) 링크도 숨겨서, 인증되지 않은 사용자가 상품을 추가하지 못하도록 한다.
- 회원가입(sign up) 링크를 클릭하면 회원가입 폼이 열리고, 로그인(login) 링크를 클릭하면 로그인 페이지로 이동한다.
- 사용자가 로그인하면 상품 추가(add product) 링크, 수정(edit)·삭제(delete) 버튼이 모두 보이게 되며, 회원가입 링크는 사라지고 로그인 링크 대신 로그아웃(logout) 옵션이 표시된다.
