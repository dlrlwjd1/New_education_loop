# Introduction to Pipes

## 개요
- NestJS에서 **파이프(pipes)**가 데이터 변환(transformation)과 검증(validation)을 담당하는 핵심 도구임을 소개하고, 파이프의 두 가지 종류(내장 파이프, 커스텀 파이프)를 개괄하는 강의.

## 내용
### 파이프란 무엇인가
- NestJS에서 **파이프(pipes)**는 데이터 변환과 검증을 돕는 기본적인 도구(fundamental tools) 중 하나로 손꼽힌다.
- 파이프는 들어오는 데이터(incoming data)에 대해 원활한 변환과 검증을 수행한다. 예를 들어 폼(form)에서 들어오는 입력 데이터를 문자열(string) 값에서 정수(integer)로 변환하거나, 입력 데이터가 유효한지(valid) 아닌지를 평가하는 작업을 데이터가 애플리케이션의 여러 부분을 거치기 전에 수행한다.
- 이러한 모든 처리는 데이터가 컨트롤러(controllers)에서 사용되거나 응답(response)으로 되돌아가기 전에 특정 요구사항을 충족하도록 보장하기 위해 파이프에 의해 수행된다.
- 즉 파이프는 변형되었든(modified) 원본이든(original) 데이터를 반환할 수 있으며, 그 데이터는 라우트 핸들러(route handlers)로 전달된다.
- 파이프는 비동기적(asynchronous) 성격을 가진다. 그래서 외부 소스에서 데이터를 가져오거나(fetching), 데이터베이스 쿼리를 수행하거나, 기타 IO 작업을 수행하는 등의 비동기 동작을 손쉽게 구현할 수 있다.

### 파이프의 두 가지 종류
- Nest는 바로 사용할 수 있는 여러 **내장 파이프(built-in pipes)**를 제공한다.
- 또한 직접 **커스텀 파이프(custom pipes)**를 만들 수도 있다.
- 즉 파이프에는 내장 파이프와 커스텀 파이프라는 두 가지 종류가 있다.
- 이번 섹션(section)에서는 내장 파이프와 커스텀 파이프를 만들고 사용하는 방법을 모두 살펴보고, 이러한 파이프들을 다양한 라우트 핸들러(route handlers)에 붙여 데이터 변환과 검증을 수행하는 방법을 확인한다.

## 요약
- 파이프는 들어오는 데이터를 변환하고 검증해 컨트롤러에 전달되기 전에 요구사항을 충족시키는 역할을 한다.
- 파이프는 비동기 동작(asynchronous behavior)을 지원해 외부 데이터 fetch, DB 쿼리 등도 처리할 수 있다.
- 파이프는 내장 파이프(built-in pipes)와 커스텀 파이프(custom pipes) 두 종류로 나뉘며, 이후 강의에서 각각을 다룬다.
