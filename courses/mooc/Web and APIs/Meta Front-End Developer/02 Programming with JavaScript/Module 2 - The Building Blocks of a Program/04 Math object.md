# Math object

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/programming-with-javascript/lecture/Qub3z/math-object)

## 개요
- 이 비디오에서는 JavaScript에서 Math 개체의 Random 및 Ceil 메서드를 사용하는 방법을 배웁니다.

## 내용
- 이 비디오에서는 JavaScript에서 Math 개체의 Random 및 Ceil 메서드를 사용하는 방법을 배웁니다.
- Math 개체는 기본 제공 메서드 중 일부를 사용할 때 매우 유용하며 그 중 하나는 Random 메서드입니다.
- Math Dot Random 메서드로 작업할 수 있는 한 가지 방법은 결과를 변수에 저장하는 것입니다.
- Decimal이라는 변수를 만들고 그 값을 Math Dot Random 메서드에 할당합니다.
- 첫 번째 단계는 변수를 만들고 수학 도트 무작위 메서드의 값을 10을 곱한 값을 할당하는 것입니다.
- 그래서 나는 반올림 된 변수를 선언하고 괄호 안에 십진 변수를 포함하는 수학 점 ceil 메서드의 값을 할당합니다.
- 이 비디오에서는 JavaScript에서 Math 개체의 Random 및 Ceil 메서드를 사용하는 방법을 배웠습니다.

## 예시
- 예를 들어, 이 방법을 사용하면 0에서 0.99 사이의 10진수를 생성할 수 있습니다.

## 요약
- 그래서 나는 반올림 된 변수를 선언하고 괄호 안에 십진 변수를 포함하는 수학 점 ceil 메서드의 값을 할당합니다. 이 비디오에서는 JavaScript에서 Math 개체의 Random 및 Ceil 메서드를 사용하는 방법을 배웠습니다.
