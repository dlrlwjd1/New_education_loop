# Storing data in arrays

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/programming-with-javascript/lecture/k1nBb/storing-data-in-arrays)

## 개요
- 캐리지는 일반적으로 특정 순서로 설정되며 각 캐리지는 다른 품목이나 재료를 운반할 수 있습니다.

## 내용
- 캐리지는 일반적으로 특정 순서로 설정되며 각 캐리지는 다른 품목이나 재료를 운반할 수 있습니다.
- 화물 열차와 마찬가지로 JavaScript에는 일련의 항목을 저장하고 재배열할 수 있는 기능이 있습니다.
- JavaScript를 사용하여 장난감 화물 열차를 에뮬레이트하고 싶다고 가정해 보겠습니다.
- train2carriage0 및 train2carriage1과 같은 더 설명적인 이름을 사용할 수 있지만 약간 장황한 느낌이 듭니다.
- 예를 들어, train1과 0을 입력하면 괄호로 묶인 경우 이 경우 밀인 캐리지 0 내부의 값에 액세스할 수 있습니다.
- 이러한 값은 순서대로 정렬되며 각 값은 해당 시퀀스의 인덱스 번호를 통해 액세스할 수 있습니다.
- 또한 JavaScript가 인덱스 값을 사용하여 배열 항목을 배열하는 방법을 배웠습니다.

## 예시
- 예를 들어, train1과 0을 입력하면 괄호로 묶인 경우 이 경우 밀인 캐리지 0 내부의 값에 액세스할 수 있습니다.

## 요약
- 이러한 값은 순서대로 정렬되며 각 값은 해당 시퀀스의 인덱스 번호를 통해 액세스할 수 있습니다. 또한 JavaScript가 인덱스 값을 사용하여 배열 항목을 배열하는 방법을 배웠습니다.
