# Module summary: The building blocks of a program

## 개요
- 이 모듈에서는 배열, 객체 및 함수로 작업하는 방법을 발견했습니다.

## 내용
- 이 모듈에서는 배열, 객체 및 함수로 작업하는 방법을 발견했습니다.
- 이제 이 단원을 완료했으므로 기능의 목적을 설명하고 이점을 설명할 수 있습니다.
- 함수를 만들고 호출하고, 사용자 정의 개체를 만들고, 수학 개체가 작동하는 방식을 설명하고, 배열 및 개체와 상호 작용하는 방법을 설명할 수도 있습니다.
- 이 모듈에서는 간단한 문제를 해결하고, 배열에 문자열을 추가하고, 객체에 속성을 추가하는 기능을 활용하는 능력을 시연하는 일련의 연습도 수행했습니다.
- 그런 다음 오류 방지의 개념을 탐구한 다음 수업으로 넘어갔습니다.
- 또한 구문, 논리 및 런타임을 포함하여 JavaScript에서 일반적인 유형의 오류를 인식하고 방어 프로그래밍에 참여하는 방법을 배웠습니다.
- 이제 배열, 객체 및 함수에 익숙해야 하며 오류 방지 기술도 개발해야 합니다.
