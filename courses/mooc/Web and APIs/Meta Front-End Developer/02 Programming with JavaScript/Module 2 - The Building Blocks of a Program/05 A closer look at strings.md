# A closer look at strings

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/programming-with-javascript/lecture/saM83/a-closer-look-at-strings)

## 개요
- 두 명의 JavaScript 개발자가 작업과 관련된 주제에 대해 논의할 때 때때로 iterable이라는 단어가 언급되는 것을 들을 수 있습니다.

## 내용
- 두 명의 JavaScript 개발자가 작업과 관련된 주제에 대해 논의할 때 때때로 iterable이라는 단어가 언급되는 것을 들을 수 있습니다.
- 이 비디오에서는 문자열의 배열 특성에 대해 배우고 연결 연산자를 사용하여 추가 문자열 조작을 탐구합니다.
- 예를 들어, 문자 배열에 대해 for 루프를 실행하고 console.log 메서드를 사용하여 결과를 출력할 수 있습니다.
- 인덱스 0의 양파, 인덱스 1의 파슬리, 그리고 마지막으로 배열의 모든 항목을 출력하는 for 루프의 결과로 양파, 파슬리 및 당근.
- 이 파일에는 문자열 길이에 대한 콘솔 로그와 인덱스 0 및 1의 문자와 함께 문자열 값이 Howdy인 Greeting이라는 변수가 있습니다.
- 이 코드를 실행하면 0과 1 인덱스에 대해 문자열 길이 h와 o에 대해 5를 제공한 다음 루프의 출력으로 전체 문자열의 각 문자를 순서대로 순서대로 지정합니다.
- 또한 concat 메서드가 실행 중인 문자열에 값을 추가하는 데 사용할 수 있는 concat이라는 메서드가 있습니다.

## 예시
- 예를 들어, 문자 배열에 대해 for 루프를 실행하고 console.log 메서드를 사용하여 결과를 출력할 수 있습니다.

## 요약
- 이 코드를 실행하면 0과 1 인덱스에 대해 문자열 길이 h와 o에 대해 5를 제공한 다음 루프의 출력으로 전체 문자열의 각 문자를 순서대로 순서대로 지정합니다. 또한 concat 메서드가 실행 중인 문자열에 값을 추가하는 데 사용할 수 있는 concat이라는 메서드가 있습니다.
