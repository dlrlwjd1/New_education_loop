# Functions

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/programming-with-javascript/lecture/ScS8u/functions)

## 개요
- Sports Wash를 선택하면 기계가 매번 같은 온도에서 세척 주기를 실행하거나 다이얼을 합성 물질로 돌리면 기계가 정확히 같은 시간 동안 세척을 실행합니다.

## 내용
- Sports Wash를 선택하면 기계가 매번 같은 온도에서 세척 주기를 실행하거나 다이얼을 합성 물질로 돌리면 기계가 정확히 같은 시간 동안 세척을 실행합니다.
- 다음 몇 분 동안 JavaScript에서 함수를 사용하는 것의 장점에 대해 배우고, 함수가 어떻게 구성되어 있는지, 매개변수를 사용하여 코드에서 함수를 선언하는 방법을 배우게 됩니다.
- 함수를 사용하면 일련의 관련 작업을 수행하는 여러 줄의 코드를 취한 다음 단일 레이블로 그룹화할 수 있습니다.
- 그런 다음 저장한 코드를 실행해야 할 때 함수를 호출하거나 호출하기만 하면 됩니다.
- 함수가 실행되면 함수 코드를 실행하려면 함수를 호출하거나 호출해야 하며, 이와 같은 함수를 입력하고 괄호를 열고 닫는 괄호를 입력하면 됩니다.
- 수락된 함수, 인수 없음 다른 단어, 매개변수가 정의되지 않은 반면 변수를 사용하여 결과를 생성할 수 있습니다.
- 이제 함수를 매개 변수로 선언하고 함수를 인수로 호출하는 함수를 사용하는 장점에 익숙해졌습니다.

## 예시
- 예를 들어 우리의 함수인 addTwonums에 인수로 값을 전달합니다.

## 요약
- 수락된 함수, 인수 없음 다른 단어, 매개변수가 정의되지 않은 반면 변수를 사용하여 결과를 생성할 수 있습니다. 이제 함수를 매개 변수로 선언하고 함수를 인수로 호출하는 함수를 사용하는 장점에 익숙해졌습니다.
