# Try catch blocks

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/programming-with-javascript/lecture/L7vNy/try-catch-blocks)

## 개요
- 이 비디오에서는 throw, 시도 및 catch라는 문에 대해 배우고 JavaScript의 오류를 처리하고 코드가 중지되지 않도록 하는 방법에 대해 알아봅니다.

## 내용
- 이 비디오에서는 throw, 시도 및 catch라는 문에 대해 배우고 JavaScript의 오류를 처리하고 코드가 중지되지 않도록 하는 방법에 대해 알아봅니다.
- throw 키워드를 사용하면 try 블록에서 catch 블록으로 오류를 throw할 수 있습니다.
- try 블록 밖에서 throw 키워드를 사용할 수 있다는 것을 기억하는 것이 중요하지만 그것을 잡을 수는 없습니다.
- catch 블록에는 두 개의 문자열을 출력하기 위한 콘솔 로그가 포함되어 있습니다.
- 마지막으로 catch 블록 이후에 다른 콘솔 로그가 문자열을 출력하고 내 프로그램이 중지되지 않습니다.
- 이 예제에서 try 블록에는 새 참조 오류를 throw하는 throw 문이 포함되어 있습니다.
- try catch 블록 외부에서 프로그램은 문자열을 출력하기 위해 콘솔 로그로 끝나고 내 프로그램은 중지되지 않습니다.

## 예시
- try catch 블록 외부에서 프로그램은 문자열을 출력하기 위해 콘솔 로그로 끝나고 내 프로그램은 중지되지 않습니다.

## 요약
- 이 예제에서 try 블록에는 새 참조 오류를 throw하는 throw 문이 포함되어 있습니다. try catch 블록 외부에서 프로그램은 문자열을 출력하기 위해 콘솔 로그로 끝나고 내 프로그램은 중지되지 않습니다.
