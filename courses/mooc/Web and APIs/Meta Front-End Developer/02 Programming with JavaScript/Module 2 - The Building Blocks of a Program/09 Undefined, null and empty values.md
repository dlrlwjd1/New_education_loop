# Undefined, null and empty values

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/programming-with-javascript/lecture/Gkrkl/undefined-null-and-empty-values)

## 개요
- 이 비디오에서는 세 가지 유형의 빈 값(null 데이터 유형, 정의되지 않은 데이터 유형 및 빈 문자열)에 대해 알아봅니다.

## 내용
- 이 비디오에서는 세 가지 유형의 빈 값(null 데이터 유형, 정의되지 않은 데이터 유형 및 빈 문자열)에 대해 알아봅니다.
- Match 메서드의 반환 값은 JavaScript의 객체인 배열이어야 하지만 D 문자를 찾을 수 없으므로 결과가 있는 배열을 만들 수 없으므로 대신 NULL이 나타나 객체가 없음을 나타냅니다.
- JavaScript에서는 아직 명확하게 정의되지 않은 것을 빌드하여 값을 할당할 수 없는 경우도 있을 수 있습니다.
- JavaScript의 일부 데이터 유형은 가능한 많은 값을 보유할 수 있지만 다른 데이터 유형은 몇 가지로 제한됩니다.
- 예를 들어, 문자열 데이터 유형은 거의 무한한 문자 조합을 보유하는 반면 부울 데이터 유형은 true 또는 false 값으로 제한됩니다.
- 예를 들어, 전체 코드에서 선언되지 않은 변수를 console.log로 시도하면 프로그램 실행이 중지되고 정의되지 않은 대신 참조 오류가 출력됩니다.
- 그것에 대해 생각하는 한 가지 방법은 정의되지 않은 데이터 유형이 JavaScript 엔진이 존재한다고 알고 있는 값에 대한 자리 표시자처럼 작동한다는 것입니다.
