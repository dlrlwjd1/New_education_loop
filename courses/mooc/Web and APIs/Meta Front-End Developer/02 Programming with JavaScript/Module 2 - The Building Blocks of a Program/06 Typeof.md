# Typeof

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/programming-with-javascript/lecture/pxAXd/typeof)

## 개요
- 이 비디오에서는 typeof 연산자를 사용하여 JavaScript의 데이터 유형을 식별하는 방법을 배웁니다.

## 내용
- 이 비디오에서는 typeof 연산자를 사용하여 JavaScript의 데이터 유형을 식별하는 방법을 배웁니다.
- typeof 연산자는 매개변수를 수락 및 평가하고 문자열로 표시된 데이터 유형의 이름을 반환합니다.
- 이를 사용하려면 typeof 다음에 괄호 안에 묶인 매개변수를 입력하면 됩니다.
- 결과를 확인하기 위해 console log 메서드를 사용하여 변수 test 값을 출력하고 있습니다.
- 먼저, typeof 연산자를 포함하는 uncomment 행 3은 문자열의 매개변수를 전달합니다.
- 코드를 다시 실행하고 Number라는 데이터 유형이 출력되는 것을 확인합니다.
- 이제 typeof 연산자와 JavaScript에서 데이터 유형을 확인하는 방법에 대해 알게 되었습니다.

## 예시
- 예를 들어, 여기에 숫자 1, 2 및 3을 포함하는 배열이 있습니다.

## 요약
- 코드를 다시 실행하고 Number라는 데이터 유형이 출력되는 것을 확인합니다. 이제 typeof 연산자와 JavaScript에서 데이터 유형을 확인하는 방법에 대해 알게 되었습니다.
