# Introduction to objects

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/programming-with-javascript/lecture/fRSJ9/introduction-to-objects)

## 개요
- 또한 점 표기법을 사용하고 쉼표로 구분된 키-값 쌍을 지정하여 개체를 만드는 방법을 보여줍니다.

## 내용
- 또한 점 표기법을 사용하고 쉼표로 구분된 키-값 쌍을 지정하여 개체를 만드는 방법을 보여줍니다.
- 객체를 사용하여 변수 이름을 줄이고 JavaScript를 얻도록 하여 이러한 모든 변수가 관련되어 있음을 이해함으로써 이러한 문제점을 해결할 수 있습니다.
- 다음으로 특성에 대한 개별 변수를 선언하는 대신 스토어 관리자라는 단어 바로 뒤에 각각에 점 연산자를 추가할 수 있습니다.
- 이것은 일반적으로 변수 이름이 속성 키가 되고 일반적으로 변수의 값이 객체의 속성 값이 됨을 의미합니다.
- 스토어 관리자 개체의 경우 점 표기법을 사용하여 Next Achievement라는 다른 속성을 추가할 수 있습니다.
- 그런 다음 어시스턴트 매니저 개체의 경우 점 표기법을 사용하여 동일한 이름의 속성을 추가할 수 있습니다.
- 이 비디오에서는 객체가 자바스크립트 코딩에서 유용한 도구인 이유와 DOT 표기법을 사용하고 쉼표로 구분된 키 값 쌍을 지정하여 객체를 빌드하는 방법을 배웠습니다.

## 예시
- 먼저 var를 사용하여 객체 이름을 선언한 다음 객체를 예를 들어 어시스턴트 관리자로 선언합니다.

## 요약
- 그런 다음 어시스턴트 매니저 개체의 경우 점 표기법을 사용하여 동일한 이름의 속성을 추가할 수 있습니다. 이 비디오에서는 객체가 자바스크립트 코딩에서 유용한 도구인 이유와 DOT 표기법을 사용하고 쉼표로 구분된 키 값 쌍을 지정하여 객체를 빌드하는 방법을 배웠습니다.
