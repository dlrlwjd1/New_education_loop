# Recap Programming with JavaScript

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/programming-with-javascript/lecture/EPPdU/recap-programming-with-javascript)

## 개요
- 이러한 개념을 탐색하는 동안 다양한 형태의 JavaScript 조건문을 스크립팅하고 for, while 및 중첩과 같은 다양한 유형의 루프로 작업하는 방법을 배웠습니다.

## 내용
- 이러한 개념을 탐색하는 동안 다양한 형태의 JavaScript 조건문을 스크립팅하고 for, while 및 중첩과 같은 다양한 유형의 루프로 작업하는 방법을 배웠습니다.
- 이 단원에서 함수의 목적을 설명하고 그 이점을 설명하는 방법, 배열을 만들고 그 내용에 접근하는 과정을 설명하는 방법을 배웠고, 이제 배열 특성과 문자열의 연결 연산자를 이해하고 함수를 만들고, 사용자 정의 객체를 만들고, 수학 객체가 작동하는 방식을 설명하고, 상호 작용할 수도 있습니다.
- 프로그래밍 패러다임의 다음 모듈은 함수 패러다임이 어떻게 작동하는지 설명하고, 재귀의 개념을 설명하고, 범위가 작동하는 방식을 설명하고, let, const 및 var와 같은 다양한 형태의 범위를 설명하는 방법을 배웠습니다.
- 다음 단원에서는 객체 지향 프로그래밍을 탐구하고 객체 지향 프로그래밍의 원리, JavaScript에서 클래스를 배포하고, 생성자를 빌드 및 활용하고, 상속을 사용하는 방법을 배웠습니다.
- 그런 다음 배열과 객체를 파괴하는 방법을 배웠고, for-of 루프와 객체를 사용하고, 템플릿 리터럴과 데이터 구조의 개념을 설명하고, spread 및 REST 연산자의 사용을 시연하는 고급 JavaScript 기능을 탐색했습니다.
- 이 수업은 테스트의 개념과 다양한 유형의 테스트를 연습하는 방법, 단위 테스트를 작성하는 방법, Jest로 테스트를 작성하는 프로세스, 테스트 기반 개발을 적용하는 방법에 대해 배웠던 테스트에 대한 소개로 시작되었습니다.
- 그런 다음 Node 및 NPM과 같은 다른 JS 환경을 탐색하는 방법, Webpack 및 Transpiring, React에서 Arrow 함수 및 클래스 작업 프로세스를 학습하는 방법을 배웠고, DOM이 테스트 과제에서 수행하는 역할을 발견하고 마지막으로 테스트를 작성하는 방법을 알게 된 JavaScript 테스트 과제를 검토했습니다.

## 예시
- 그런 다음 Node 및 NPM과 같은 다른 JS 환경을 탐색하는 방법, Webpack 및 Transpiring, React에서 Arrow 함수 및 클래스 작업 프로세스를 학습하는 방법을 배웠고, DOM이 테스트 과제에서 수행하는 역할을 발견하고 마지막으로 테스트를 작성하는 방법을 알게 된 JavaScript 테스트 과제를 검토했습니다.
