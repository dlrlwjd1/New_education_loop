# Congratulations on completing the course Programming with JavaScript

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/programming-with-javascript/lecture/uqExJ/congratulations-on-completing-the-course-programming-with-javascript)

## 개요
- 당신은 여기에 오기 위해 열심히 일했고 그 과정에서 많은 새로운 기술을 개발했습니다.

## 내용
- 당신은 여기에 오기 위해 열심히 일했고 그 과정에서 많은 새로운 기술을 개발했습니다.
- 프로그래밍에 대한 소개로 시작하여 이제 JavaScript의 기능과 사용을 설명하고 JavaScript의 배경과 역사를 설명하고 ECMA와 ECMAScript의 중요성을 설명하고 JavaScript 라이브러리와 그 사용을 설명할 수 있어야 합니다.
- 자바스크립트 코딩의 핵심 개념에 대한 소개를 받았고 이제 세미콜론 구문으로 단일 라인 및 다중 라인 주석을 코딩하고 변수, 데이터 유형, 연산자, 숫자, 부울 및 문자열을 사용하는 방법을 알아야 합니다.
- 조건문과 루프를 사용하여 명령문을 작성하고, 배열, 객체 및 함수를 사용하고, 코드에서 오류 방지를 활성화하여 코딩 능력을 더욱 확장했습니다.
- 프로그래밍 패러다임에서는 함수형 프로그래밍 및 객체 지향 프로그래밍, 고급 JavaScript 기능 및 브라우저에서 JavaScript 작동을 소개했습니다.
- 마지막으로 테스트 및 호환성을 통해 테스트의 목적을 발견하고 테스트 유형을 탐색하고 Jest로 JavaScript 테스트 문제와 테스트를 연구했습니다.
- JavaScript 프로그래밍 과정이 종료된 것을 다시 한 번 축하드립니다.

## 예시
- JavaScript 프로그래밍 과정이 종료된 것을 다시 한 번 축하드립니다.

## 요약
- 마지막으로 테스트 및 호환성을 통해 테스트의 목적을 발견하고 테스트 유형을 탐색하고 Jest로 JavaScript 테스트 문제와 테스트를 연구했습니다. JavaScript 프로그래밍 과정이 종료된 것을 다시 한 번 축하드립니다.
