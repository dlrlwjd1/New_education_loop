# Types of testing

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/programming-with-javascript/lecture/aUVyM/types-of-testing)

## 개요
- 높은 수준의 소프트웨어를 테스트한다는 것은 최신 소프트웨어 개발 프로젝트에서 예상대로 작동하는지 확인하는 것을 의미한다고 말할 수 있습니다.

## 내용
- 높은 수준의 소프트웨어를 테스트한다는 것은 최신 소프트웨어 개발 프로젝트에서 예상대로 작동하는지 확인하는 것을 의미한다고 말할 수 있습니다.
- 소프트웨어 프로젝트 테스트의 프로젝트 관리자의 경우 특정 소프트웨어가 소프트웨어 엔지니어를 위해 시스템의 다른 부분과 잘 작동한다는 것을 의미할 수 있습니다.
- 테스트는 기존 기능을 손상시키지 않는 코드를 작성하는 것이 버그가 없으며 동기를 기반으로 주어진 작업에 명시된 요구 사항을 충족한다는 것을 의미할 수 있습니다.
- 이제 종단 간 테스트 또는 E2E, 통합 테스트 및 단위 테스트의 세 가지 유형의 테스트에 대해 논의하겠습니다.
- E2E 테스트의 예는 랩톱 제조업체가 랩톱 제조업체에서 일부 오프 어셈블리 라인 랩톱을 열고 일반 사용자가 전체 최종 제품이 정상적으로 작동하는지 확인하는 것처럼 사용하도록 합니다.
- 웹 개발 종단 간 테스트에 대한 보다 구체적인 내용은 사용자가 앱과 상호 작용하는 방식을 모방하려고 합니다.
- 통합 테스트는 시스템의 일부가 시스템의 다른 부분과 상호 작용하는 방식을 테스트하는 것입니다.

## 예시
- 예를 들어, 로그인 버튼을 클릭하면 장바구니에 항목을 추가하는 과정이 진행됩니다.

## 요약
- 웹 개발 종단 간 테스트에 대한 보다 구체적인 내용은 사용자가 앱과 상호 작용하는 방식을 모방하려고 합니다. 통합 테스트는 시스템의 일부가 시스템의 다른 부분과 상호 작용하는 방식을 테스트하는 것입니다.
