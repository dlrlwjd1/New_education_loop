# Introduction to Jest

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/programming-with-javascript/lecture/GyWer/introduction-to-jest)

## 개요
- 이 단계에서는 코드가 의도한 대로 작동하는지 확인하기 위해 코드를 테스트하는 개념에 익숙할 것입니다.

## 내용
- 이 단계에서는 코드가 의도한 대로 작동하는지 확인하기 위해 코드를 테스트하는 개념에 익숙할 것입니다.
- JavaScript의 경우 Jest와 같은 테스트 프레임워크를 사용할 수 있습니다.
- 앞으로 몇 분 동안 Jest 프레임워크, 코드 적용 범위, 조롱 및 스냅샷 테스트의 기능을 소개하겠습니다.
- 일반 JavaScript 및 React 코드 외에도 Babel, TypeScript, Node, Angular, Vue 및 기타 다양한 프레임워크를 테스트할 수 있습니다.
- 예를 들어, 실제로 클라이언트에서 온 데이터가 서버에서 돌아온 것처럼 데이터를 조롱하여 웹 앱의 프런트 엔드 기능을 테스트할 수 있습니다.
- 그러면 프런트 엔드 개발자는 프런트 엔드 코드가 빌드되기 전에 백엔드 개발자가 작업을 완료하기를 기다리는 데 갇힐 것입니다.
- 이제 Jest 테스트 프레임워크를 사용하여 JavaScript 코드를 테스트하는 개념에 익숙해졌습니다.

## 예시
- 예를 들어, 실제로 클라이언트에서 온 데이터가 서버에서 돌아온 것처럼 데이터를 조롱하여 웹 앱의 프런트 엔드 기능을 테스트할 수 있습니다.

## 요약
- 그러면 프런트 엔드 개발자는 프런트 엔드 코드가 빌드되기 전에 백엔드 개발자가 작업을 완료하기를 기다리는 데 갇힐 것입니다. 이제 Jest 테스트 프레임워크를 사용하여 JavaScript 코드를 테스트하는 개념에 익숙해졌습니다.
