# What is testing?

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/programming-with-javascript/lecture/UV81A/what-is-testing)

## 개요
- 예를 들어, 내가 제공하는 두 문자열을 결합하기 위해 concatstrings 함수를 만들 수 있습니다.

## 내용
- 예를 들어, 내가 제공하는 두 문자열을 결합하기 위해 concatstrings 함수를 만들 수 있습니다.
- 내가 테스트를 작성할 때 이러한 테스트는 내 소스 코드가 충족하려는 기대치를 지정하기 때문에 내 소스 코드의 주석에 대한 더 나은 대안입니다.
- 앞서 설명했듯이 첫 번째 인수는 문자열 abc, 두 번째 인수는 string def를 사용하여 concatstrings 함수를 실행할 수 있습니다.
- 예를 들어, ConcatStrings 123과 456을 인수로 예상한 다음 함수가 인수 123456과 함께 있어야 하며, 각 인스턴스에서 기대치가 정확하고 코드가 예상대로 작동합니다.
- 예를 들어, expect 메서드를 실행하고 숫자 1과 2를 인수로 사용하는 concatstrings 함수의 호출을 전달하면 결과가 12에 대한 기대가 실패합니다.
- 숫자 유형의 두 값이 있는 plus 연산자를 사용할 때 두 숫자를 함께 결합하여 abcdef를 형성하는 것처럼 숫자 12를 형성하는 대신 수학 연산을 수행하기 때문입니다.
- 테스트가 통과되면 앱 코드와 테스트 코드를 모두 개선해야 하지만 동작을 변경하거나 테스트 코드를 변경하지 않고 개선해야 합니다.
