# Writing tests with Jest

## 개요
- 이 비디오에서는 JavaScript 코드와 Jest Framework를 테스트하는 데 필요한 패키지를 설치하는 방법과 테스트를 설정하는 방법을 살펴봅니다.

## 내용
- 이 비디오에서는 JavaScript 코드와 Jest Framework를 테스트하는 데 필요한 패키지를 설치하는 방법과 테스트를 설정하는 방법을 살펴봅니다.

- 이제 이 함수가 어떻게 작동해야 하는지에 대한 몇 가지 기대치를 작성하기 위해 Jest Testing 프레임워크를 사용하는 것으로 전환하겠습니다.
- 이 파일을 설정하려면 먼저 const, addfive equals require를 입력하여 내보낸 addFive 함수를 가져온 다음 괄호, backtick dot, forward slash, addfive, backtick을 입력합니다.
- 앞으로 슬래시의 이유는 함수가 테스트 파일과 같은 폴더에 있음을 나타내기 위함이며, Node가 사용하지 않더라도 내가 의미하는 바를 이해하기 때문에 점 JS를 생략했습니다.
- 이 문자열은 pass 또는 fail이라는 단어와 함께 테스트를 실행할 때 명령줄에 출력되고 npm run test 명령을 실행할 때 실행할 함수입니다.
