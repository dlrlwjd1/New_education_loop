## 내용
- 그런 다음 2009년 Ryan Dahl이라는 개발자가 Google의 JavaScript V8 엔진을 사용하여 서버에서 작동하도록 하기로 결정했습니다.
- 글쎄, 이것은 당신이 JavaScript 파일을 실행하거나 JavaScript 코드를 직접 실행하기 위해 node 명령을 사용하기 때문입니다.
- 이러한 프로젝트는 모양과 크기가 다를 수 있지만 모두 npm 명령을 실행한 후 생성되는 package.json 파일이라는 공통점이 하나 이상 있습니다.
- package.json 파일에는 오픈 소스 모듈의 npm 저장소에서 가져온 모든 노드 모듈에 대한 모든 지침이 들어 있습니다.
- 이는 npm install 명령을 실행하고 패키지 이름을 추가하여 수천 시간의 다른 개발자 코딩을 얻을 수 있음을 의미합니다.
- 예를 들어, 특정 수의 다른 노드 패키지로 프로젝트를 빌드한 경우 package.json 파일에 모두 나열됩니다.
- npm install 명령을 실행할 때 100MB 상당의 노드 패키지가 노드 모듈 폴더 아래의 프로젝트에 설치되는 경우가 많습니다.

## 예시
- 예를 들어, 명령줄, 데스크톱 응용 프로그램 또는 웹 앱의 백엔드에서.
