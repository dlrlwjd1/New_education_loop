# Module summary: Testing

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/programming-with-javascript/lecture/KECir/module-summary-testing)

## 개요
- 이제 이 모듈에 포함된 자료를 요약하고 핵심 학습 포인트에 초점을 맞춰 내용을 요약해 보겠습니다.

## 내용
- 이제 이 모듈에 포함된 자료를 요약하고 핵심 학습 포인트에 초점을 맞춰 내용을 요약해 보겠습니다.
- JavaScript 언어 개발의 역사가 설명되었으며 오늘날 JavaScript로 전체 스택 프로그램을 작성하는 것이 가능하다는 것을 배웠습니다.
- 이제 node.js 및 npm을 설명하고 node.js 및 npm을 설치 및 설정하는 방법을 알아야 합니다.
- Contact Strings 함수를 사용하여 제공된 두 문자열을 결합하여 코멘트가 코드 의도된 동작을 나타내는 데 어떻게 도움이 되는지, JavaScript에서 테스트가 함수가 의도한 방식으로 작동하는지 확인하는 방법을 보여줍니다.
- 수동 테스트와 자동 테스트를 구분하고, 세 가지 다른 유형의 테스트를 식별 및 설명하고, Jest 프레임워크 내에서 웹 개발자가 사용할 수 있는 기능을 탐색합니다.
- 또한 모의 및 스냅샷 테스트의 개념을 이해하고 Jest로 JavaScript 파일을 테스트하는 방법을 설명하고 단위 테스트를 작성하는 방법을 시연할 수 있어야 합니다.
- 당신은 코드 테스트의 필요성에 대해 배우면서 여기까지 오기 위해 엄청난 노력을 기울이고 몇 가지 중요한 기술을 습득했습니다.

## 예시
- 당신은 코드 테스트의 필요성에 대해 배우면서 여기까지 오기 위해 엄청난 노력을 기울이고 몇 가지 중요한 기술을 습득했습니다.
