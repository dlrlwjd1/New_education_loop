# Writing statements

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/programming-with-javascript/lecture/KwHPY/writing-statements)

## 개요
- 이 비디오에서는 if 및 else 문을 사용하여 JavaScript의 조건문에 대해 알아봅니다.

## 내용
- 이 비디오에서는 if 및 else 문을 사용하여 JavaScript의 조건문에 대해 알아봅니다.
- JavaScript에는 조건문이라는 코드 조각이 있으며 개발자는 코드를 사용하여 무언가가 true인지 false인지에 따라 조건부로 코드를 실행할 수 있습니다.
- if 문은 조건을 확인하고 조건이 충족되거나 true인 경우 코드 블록을 실행합니다.
- 여러 유형의 비교 연산자를 사용하여 조건을 평가할 수 있습니다.
- 지금까지 사물이 true 또는 false일 수 있는 바이너리 조건으로 조건문을 사용하는 방법에 대해 배웠습니다.
- 이 경우 true 블록이 실행되고 학습자에게 전달되었다는 메시지를 콘솔에 출력합니다.
- 이 경우 false 블록이 실행되고 학습자에게 전달되지 않았다는 메시지를 콘솔에 출력합니다.

## 예시
- 더 복잡한 조건이나 시나리오에 대해 프로그래밍해야 하는 경우가 많이 있습니다.

## 요약
- 이 경우 true 블록이 실행되고 학습자에게 전달되었다는 메시지를 콘솔에 출력합니다. 이 경우 false 블록이 실행되고 학습자에게 전달되지 않았다는 메시지를 콘솔에 출력합니다.
