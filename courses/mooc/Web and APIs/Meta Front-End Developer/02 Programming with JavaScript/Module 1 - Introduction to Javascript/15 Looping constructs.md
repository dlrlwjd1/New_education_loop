# Looping constructs

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/programming-with-javascript/lecture/wde0G/looping-constructs)

## 개요
- 예를 들어, 셔츠를 입거나, 접시 더미를 하나씩 씻거나, 10에서 1로 카운트다운할 때 각 버튼을 닫는 것은 새해 복 많이 받으세요.

## 내용
- 예를 들어, 셔츠를 입거나, 접시 더미를 하나씩 씻거나, 10에서 1로 카운트다운할 때 각 버튼을 닫는 것은 새해 복 많이 받으세요.
- 특정 조건이 충족되면 코드 블록을 실행하는 조건부 if 문을 불러옵니다.
- JavaScript에서 개발자는 루프를 사용하여 특정 조건이 충족될 때까지 반복되는 코드 블록을 계속 실행합니다.
- JavaScript에서 카운터는 변수 또는 숫자가 될 수 있지만 프로그래밍에서는 문자 I을 사용하는 것이 일반적입니다.
- 루프를 사용하면 더 적은 코드 줄을 사용하여 동일한 작업을 더 효율적으로 수행할 수 있습니다.
- for 루프, while 루프 및 중첩 루프와 같은 많은 유형의 루프가 있습니다.
- Afor 또는 While 루프를 신진 개발자로 사용하여 동일한 결과를 얻을 수 있지만 for-loop로 작업하는 것이 더 쉬울 수 있습니다.

## 예시
- 예를 들어, 셔츠를 입거나, 접시 더미를 하나씩 씻거나, 10에서 1로 카운트다운할 때 각 버튼을 닫는 것은 새해 복 많이 받으세요.

## 요약
- for 루프, while 루프 및 중첩 루프와 같은 많은 유형의 루프가 있습니다. Afor 또는 While 루프를 신진 개발자로 사용하여 동일한 결과를 얻을 수 있지만 for-loop로 작업하는 것이 더 쉬울 수 있습니다.
