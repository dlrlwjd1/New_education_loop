# While loop

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/programming-with-javascript/lecture/T0L00/while-loop)

## 개요
- 해당 표현식이 True JavaScript를 반환하면 while 루프 내에서 코드를 실행합니다.

## 내용
- 해당 표현식이 True JavaScript를 반환하면 while 루프 내에서 코드를 실행합니다.
- 그래서 while 루프를 구성하려면 while이라는 단어를 입력한 다음 괄호 안에 조건을 입력했습니다.
- 이것은 JavaScript가 처음으로 코드 줄을 실행하기 시작하면 카운터 변수의 값을 확인합니다.
- 카운터 값이 0보다 크면 와일드 루프 내에서 코드를 실행한 다음 카운터 변수의 현재 값을 콘솔에 출력합니다.
- 그렇기 때문에 while 루프 코드 블록으로 다시 이동하여 카운터의 현재 값인 2를 출력합니다.
- 이제 블록의 끝에 도달했으므로 JavaScript가 백업하여 1이 0보다 큰 사실임을 확인한 다음 while 루프 본문 내부로 다시 이동하여 1의 값을 출력하고 카운터를 1-1로 업데이트합니다.
- 루프의 끝에 도달했기 때문에 body, 그것은 다시 돌아가서 0이 0보다 큰지 확인하고 그렇지 않기 때문에 while 루프 내에서 코드를 다시 실행하지 않습니다.

## 예시
- 루프의 끝에 도달했기 때문에 body, 그것은 다시 돌아가서 0이 0보다 큰지 확인하고 그렇지 않기 때문에 while 루프 내에서 코드를 다시 실행하지 않습니다.
