# Introduction to programming

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/programming-with-javascript/lecture/qUwaB/introduction-to-programming)

## 개요
- 프로그래밍은 단순히 프로그래밍 언어를 사용하여 완료할 수 있는 일련의 지침을 컴퓨터에 제공한다는 것을 인식합니다.

## 내용
- 프로그래밍은 단순히 프로그래밍 언어를 사용하여 완료할 수 있는 일련의 지침을 컴퓨터에 제공한다는 것을 인식합니다.
- 그리고 JavaScript와 같은 프로그래밍 언어가 컴퓨터에 무엇을 해야 하는지 알려주는 방법을 설명하십시오.
- 식료품을 사고, 운동하는 동안 그녀의 심장 박동수를 추적하고, 그녀의 친구를 위해 꽃을 사십시오.
- 식료품점에서 계산원은 Jane이 사고 싶어하는 각 제품에 대한 정보와 가격을 얻기 위해 바코드 판독기를 사용해야 합니다.
- Jane과 같은 많은 사람들에게 우리의 일상 활동은 컴퓨터 및 컴퓨터 프로그램과 얽혀 있습니다.
- 마지막으로 Jane이 친구를 위해 꽃을 주문할 수 있도록 다양한 기계의 다른 많은 프로그램이 참여했습니다.
- 마지막으로 컴퓨터의 중앙 처리 장치 또는 CPU는 이러한 이진 전기 신호를 이해하고 그에 따라 자체적으로 업데이트할 수 있습니다.

## 예시
- 예를 들어, Jane이 식료품을 구입할 때 바코드 스캐너에서 받은 입력을 받아 각 항목의 가격으로 변환할 수 있는 프로그램이 있었습니다.

## 요약
- 마지막으로 Jane이 친구를 위해 꽃을 주문할 수 있도록 다양한 기계의 다른 많은 프로그램이 참여했습니다. 마지막으로 컴퓨터의 중앙 처리 장치 또는 CPU는 이러한 이진 전기 신호를 이해하고 그에 따라 자체적으로 업데이트할 수 있습니다.
