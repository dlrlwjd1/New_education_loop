# Introduction to programming with JavaScript

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/programming-with-javascript/lecture/lJUVf/introduction-to-programming-with-javascript)

## 개요
- 이제는 프런트 엔드 개발뿐만 아니라 백엔드 개발에도 사용되며 JavaScript와 React를 사용하여 모바일 앱을 만들 수도 있습니다.

## 내용
- 이제는 프런트 엔드 개발뿐만 아니라 백엔드 개발에도 사용되며 JavaScript와 React를 사용하여 모바일 앱을 만들 수도 있습니다.
- 그것은 매우 강력한 도구이고 소프트웨어 개발에 필수적이기 때문에 새로운 개발자로서 그것이 작동하는 방법과 사용 방법을 아는 것이 중요합니다.
- 이 과정에서는 모듈 1부터 시작하여 JavaScript에 대한 소개를 다루며 실제 세계에서 JavaScript가 어떻게 사용되는지 이해하는 데 도움이 됩니다.
- 또한 이 모듈은 변수, 데이터 유형, 연산자, 문자열, 부울 및 숫자에 대한 학습을 포함하는 JavaScript 프로그래밍을 소개합니다.
- 모듈 3에서는 함수 호출, 재귀 및 범위를 포함하는 함수형 프로그래밍 및 객체 지향 프로그래밍 패러다임에 대해 배웁니다.
- 또한 4개의 루프 및 템플릿 리터럴을 사용하여 배열 및 객체를 구조화하는 것과 같은 고급 JavaScript 기능에 대해서도 배울 수 있습니다.
- 또한 웹팩에 대한 학습, 트랜스파일링 및 React에서 화살표 함수 작업을 포함하는 JavaScript 테스트 문제에 대해서도 배우게 됩니다.

## 예시
- 또한 웹팩에 대한 학습, 트랜스파일링 및 React에서 화살표 함수 작업을 포함하는 JavaScript 테스트 문제에 대해서도 배우게 됩니다.

## 요약
- 또한 4개의 루프 및 템플릿 리터럴을 사용하여 배열 및 객체를 구조화하는 것과 같은 고급 JavaScript 기능에 대해서도 배울 수 있습니다. 또한 웹팩에 대한 학습, 트랜스파일링 및 React에서 화살표 함수 작업을 포함하는 JavaScript 테스트 문제에 대해서도 배우게 됩니다.
