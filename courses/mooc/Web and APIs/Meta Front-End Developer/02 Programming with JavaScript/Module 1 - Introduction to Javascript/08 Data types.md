# Data types

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/programming-with-javascript/lecture/3faAu/data-types)

## 개요
- 글쎄, 당신은 아마도 품목을 분류하고 상자에 포장한 다음 상자에 레이블을 붙여 각 상자에 무엇이 들어 있는지 알 수 있도록 하는 것으로 시작할 것입니다.

## 내용
- 글쎄, 당신은 아마도 품목을 분류하고 상자에 포장한 다음 상자에 레이블을 붙여 각 상자에 무엇이 들어 있는지 알 수 있도록 하는 것으로 시작할 것입니다.
- 자바스크립트에서 텍스트 값은 문자열 데이터 유형으로 알려져 있고 숫자 값은 숫자 데이터 유형이라고 합니다.
- 예를 들어, 숫자를 작성하려면 숫자 값을 입력하기만 하면 되지만 JavaScript로 문자열을 빌드하려면 문자를 작은 따옴표 또는 큰 따옴표로 묶어야 합니다.
- 이제 문자열 데이터 유형이 제목 및 설명과 같은 값을 저장하는 데 적합하고 숫자 데이터 유형이 가격이나 계산하려는 값에 더 적합하다는 것을 알았습니다.
- 또한 정의되지 않은 값만 보유할 수 있는 정의되지 않은 데이터 유형이 있으며 일반적으로 아직 값이 할당되지 않은 변수를 나타냅니다.
- 하나는 숫자 데이터 유형보다 훨씬 더 많은 숫자 범위를 수용할 수 있는 초대형 상자와 같은 Bigint 데이터 유형입니다.
- 모든 데이터 유형에는 특정 사용 사례가 있으며 각 데이터 유형을 적용할 시기를 알면 더 나은 코더가 될 수 있습니다.

## 예시
- 특정 사용 사례와 각 데이터 유형을 사용하는 시기에 대해 알아봅니다.

## 요약
- 하나는 숫자 데이터 유형보다 훨씬 더 많은 숫자 범위를 수용할 수 있는 초대형 상자와 같은 Bigint 데이터 유형입니다. 모든 데이터 유형에는 특정 사용 사례가 있으며 각 데이터 유형을 적용할 시기를 알면 더 나은 코더가 될 수 있습니다.
