# Working with conditional statements

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/programming-with-javascript/lecture/RBpdU/working-with-conditional-statements)

## 개요
- 조건문은 조건이 true인지 false인지에 따라 코드 조각을 실행하는 데 사용된다는 것을 기억하십시오.

## 내용
- 조건문은 조건이 true인지 false인지에 따라 코드 조각을 실행하는 데 사용된다는 것을 기억하십시오.
- 자, 이제 변수와 if else 문을 사용하여 간단한 예제로 이것을 설명하겠습니다.
- 예를 들어 if else 문은 true 또는 false인 특정 조건을 기반으로 코드를 실행하려는 경우에 사용할 수 있습니다.
- 자, 이제 else if를 사용할 때와 switch 문을 사용할 때의 예를 통해 이것을 설명하겠습니다.
- 그래서 여기에서 VS 코드가 열려 있고 if else 문의 예를 붙여 넣었다는 것을 알았습니다.
- 좋아, 그래서 나는 place라는 변수가 있고 첫 번째 값을 가진 문자열에 할당됩니다.
- 첫 번째, 두 번째 또는 세 번째 값에 대한 조건부 검사가 충족되지 않으면 else 블록이 실행되고 텍스트를 출력하고 메달이 없기 때문에 이것은 중요합니다.

## 예시
- 예를 들어 if else 문은 true 또는 false인 특정 조건을 기반으로 코드를 실행하려는 경우에 사용할 수 있습니다.

## 요약
- 좋아, 그래서 나는 place라는 변수가 있고 첫 번째 값을 가진 문자열에 할당됩니다. 첫 번째, 두 번째 또는 세 번째 값에 대한 조건부 검사가 충족되지 않으면 else 블록이 실행되고 텍스트를 출력하고 메달이 없기 때문에 이것은 중요합니다.
