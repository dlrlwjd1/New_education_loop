# Module summary: Introduction to JavaScript

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/programming-with-javascript/lecture/gqXeM/module-summary-introduction-to-javascript)

## 개요
- 조건문과 루프에 대한 이 단원의 최종 비디오와 JavaScript 소개 모듈의 끝 부분에 도달했습니다.

## 내용
- 조건문과 루프에 대한 이 단원의 최종 비디오와 JavaScript 소개 모듈의 끝 부분에 도달했습니다.
- 이 모듈에서는 프로그래밍이 무엇인지와 현대 세계에서 그것이 수행하는 역할을 설명하고, JavaScript가 무엇이며 웹 개발 도구로서의 가치를 설명하고, 개발자가 JavaScript 엔진과 상호 작용하여 웹 경험을 만들고, 변수를 만들고, 변수를 생성하고, 포함하는 값을 할당하거나 재할당하는 방법을 설명하고, 7개의 기본 데이터를 식별하는 방법을 배웠습니다.
- 문자열이 무엇인지와 문자열을 작성하는 구문을 설명하고, 부울 데이터 유형의 값을 식별하고, 숫자 데이터 유형으로 할 수 있는 것과 할 수 없는 것을 설명합니다.
- 조건부 결과를 생성하고 반복 작업을 반복하는 루프를 빌드하는 if else 문을 빌드합니다.

## 예시
- 조건부 결과를 생성하고 반복 작업을 반복하는 루프를 빌드하는 if else 문을 빌드합니다.

## 요약
- 문자열이 무엇인지와 문자열을 작성하는 구문을 설명하고, 부울 데이터 유형의 값을 식별하고, 숫자 데이터 유형으로 할 수 있는 것과 할 수 없는 것을 설명합니다. 조건부 결과를 생성하고 반복 작업을 반복하는 루프를 빌드하는 if else 문을 빌드합니다.
