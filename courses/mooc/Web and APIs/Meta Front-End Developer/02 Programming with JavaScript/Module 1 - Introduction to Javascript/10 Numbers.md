# Numbers

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/programming-with-javascript/lecture/TIzJ6/numbers)

## 개요
- JavaScript에는 다른 프로그래밍 언어와 마찬가지로 다양한 데이터 유형이 있습니다.

## 내용
- JavaScript에는 다른 프로그래밍 언어와 마찬가지로 다양한 데이터 유형이 있습니다.
- 데이터 유형의 수는 정수와 소수점 숫자를 모두 나타내기 때문에 프로그래밍 언어로서의 JavaScript의 기본 부분입니다.
- JavaScript에서는 숫자를 사용하여 수학 연산을 수행할 수 있습니다.
- 예를 들어, 2 더하기 2를 코딩하고 4의 값을 반환할 수 있습니다.
- 이렇게 하면 한 숫자를 다른 숫자에 넣을 수 있는 횟수를 확인한 다음 나머지를 반환할 수 있습니다.
- 예를 들어, 2 곱하기 4 더하기 8은 계산에 사용된 순서에 따라 다른 답변을 반환할 수 있습니다.
- 예를 들어, 2를 4로 곱한 다음 8의 값을 더하면 16을 반환하지만 4 더하기 8의 값의 2배는 24를 반환합니다.

## 예시
- 예를 들어, 2 더하기 2를 코딩하고 4의 값을 반환할 수 있습니다.

## 요약
- 예를 들어, 2 곱하기 4 더하기 8은 계산에 사용된 순서에 따라 다른 답변을 반환할 수 있습니다. 예를 들어, 2를 4로 곱한 다음 8의 값을 더하면 16을 반환하지만 4 더하기 8의 값의 2배는 24를 반환합니다.
