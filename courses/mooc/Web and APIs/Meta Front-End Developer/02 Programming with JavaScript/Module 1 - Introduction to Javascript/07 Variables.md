# Variables

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/programming-with-javascript/lecture/A0YPr/variables)

## 개요
- 이 비디오에서는 변수가 무엇이며 왜 필요한지 식별하고 변수 선언과 변수 할당을 구분하고 변수 값을 가져오고 다시 할당하는 방법을 설명합니다.

## 내용
- 이 비디오에서는 변수가 무엇이며 왜 필요한지 식별하고 변수 선언과 변수 할당을 구분하고 변수 값을 가져오고 다시 할당하는 방법을 설명합니다.
- 이 이름을 변수에 저장하기 위해, var 키워드로 시작하여 다시 사용하고 싶은 값을 제공한다는 것을 자바스크립트에 알리는 데 사용합니다.
- 내가 다시 사용하고 싶은 값이 있고 이 값에 person이라는 단어를 사용하여 액세스할 수 있다는 사실입니다.
- 즉, 사람 변수가 John의 값을 보유하려면 사람 변수에 John의 값을 할당해야 합니다.
- 내장 console.log 메서드를 사용하여 JavaScript가 "hello john"이라는 텍스트를 콘솔에 출력하도록 할 수 있습니다.
- 이제 console.log 메소드를 두 변수, 인사말과 사람 모두와 함께 사용할 때 이러한 변수의 단어 또는 값인 'hello john''이 콘솔에 기록됩니다.
- 예를 들어, 인사말을 따옴표로 묶어 인사말을 입력하여 변수 값을 Hello에서 Hi로 변경할 수 있습니다.

## 예시
- 예를 들어, 인사말을 따옴표로 묶어 인사말을 입력하여 변수 값을 Hello에서 Hi로 변경할 수 있습니다.

## 요약
- 이제 console.log 메소드를 두 변수, 인사말과 사람 모두와 함께 사용할 때 이러한 변수의 단어 또는 값인 'hello john''이 콘솔에 기록됩니다. 예를 들어, 인사말을 따옴표로 묶어 인사말을 입력하여 변수 값을 Hello에서 Hi로 변경할 수 있습니다.
