# Strings

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/programming-with-javascript/lecture/s9Wiq/strings)

## 개요
- 그러나 문자열이 비어 있을 필요는 없으므로 일부 문자와 느낌표가 있는 비어 있지 않은 문자열을 만들겠습니다.

## 내용
- 그러나 문자열이 비어 있을 필요는 없으므로 일부 문자와 느낌표가 있는 비어 있지 않은 문자열을 만들겠습니다.
- 나는 거기에 Hello라는 단어와 작은 따옴표 한 쌍에 느낌표를 입력하여이 작업을 수행합니다.
- 문자열 값을 둘러싸기 위해 작은 따옴표 또는 큰 따옴표를 사용하는 경우 이러한 문자를 구분 기호라고 합니다.
- JavaScript에서 문자열을 처음 사용하기 시작할 때 문제를 일으킬 수 있는 몇 가지 비정상적인 상황이 있습니다.
- 이는 자바스크립트가 문자열을 형성하는 것으로 처음 두 글자라는 단어를 읽고 그 다음에는 아포스트로피 때문에 코드의 나머지 부분을 이해하지 못하기 때문입니다.
- 나는 구의 양쪽에 있는 원래 작은 따옴표를 큰따옴표로 대체함으로써 이 작업을 수행합니다.
- JavaScript에서 문자열 데이터 유형이 무엇인지 설명할 수도 있습니다.

## 예시
- JavaScript에서 문자열 데이터 유형이 무엇인지 설명할 수도 있습니다.

## 요약
- 나는 구의 양쪽에 있는 원래 작은 따옴표를 큰따옴표로 대체함으로써 이 작업을 수행합니다. JavaScript에서 문자열 데이터 유형이 무엇인지 설명할 수도 있습니다.
