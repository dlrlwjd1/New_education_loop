# For loop

## 개요
- 운 좋게도 for-loop라는 것을 사용하여 더 효율적인 방법이 있습니다.

## 내용
- 운 좋게도 for-loop라는 것을 사용하여 더 효율적인 방법이 있습니다.
- 카운터는 일반적으로 iterator에 대해 i라는 이름의 변수이지만 원하는 변수 이름을 사용할 수 있습니다.
- 이 예에서 조건은 i의 값이 실행할 루프에 대해 3보다 작거나 같아야 한다는 것입니다.
- i 플러스 1과 같은 기술을 배웠을 수도 있지만 i의 값을 1만큼 증가시키는 또 다른 방법으로 i plus plus 구문을 사용할 수도 있습니다.
- 각 루프 후에 i 값을 증가시키는 방법을 지정하지 않으면 for 루프는 항상 3보다 작기 때문에 영원히 실행됩니다.
- 4가 3보다 작거나 큰 값이 false를 반환하므로 for-loop가 종료되고 JavaScript가 그 아래에 코드를 계속 읽고 실행합니다.
- 이제 플러스 플러스를 사용하여 i의 값을 증가시키는 대신 빼기 마이너스로 감소시킬 수 있습니다.

## 예시
- 예를 들어, 10에서 카운트를 시작하고 i 값을 0보다 크게 설정할 수 있습니다.

## 요약
- 4가 3보다 작거나 큰 값이 false를 반환하므로 for-loop가 종료되고 JavaScript가 그 아래에 코드를 계속 읽고 실행합니다. 이제 플러스 플러스를 사용하여 i의 값을 증가시키는 대신 빼기 마이너스로 감소시킬 수 있습니다.
