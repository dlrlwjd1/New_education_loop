# Nested loops

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/programming-with-javascript/lecture/Dvzu4/nested-loops)

## 개요
- 그러나 JavaScript를 사용하면 여러 작업을 한 번에 수행할 수 있도록 다른 루프 내에서 루프를 중첩할 수 있습니다.

## 내용
- 그러나 JavaScript를 사용하면 여러 작업을 한 번에 수행할 수 있도록 다른 루프 내에서 루프를 중첩할 수 있습니다.
- 이제 중첩 루프를 시연하고 싶고 그렇게 하려면 첫 번째 for 루프의 본문 안에 다른 루프를 추가해야 합니다.
- 이것이 중첩되어 있음을 확인하기 위해 여러 대시 문자를 추가 한 다음 월 변수를 추가 할 것입니다.
- 내부 루프의 코드 안에 들어가면 코드가 세 번 실행되고 대시 6, 대시 7 및 대시 8을 출력할 것으로 예상할 수 있습니다.
- 그러면 내부 루프가 종료되고 코드는 다음 루프 주기를 시작하기 위해 외부 루프로 다시 이동합니다.
- 이 긴 변수 이름을 사용하는 대신 연도 대신 i를 사용할 수 있고 월 대신 j를 사용할 수 있습니다.
- 중첩 루프는 코드를 자동으로 반복해야 하는 경우(예: 가장 높은 것에서 가장 낮은 곳까지의 숫자 정렬)에서 사용할 수 있습니다.

## 예시
- 그러나 이러한 변수 이름은 개발 커뮤니티에서 표준 관행이며 사용하기에 모범 사례로 간주됩니다.

## 요약
- 이 긴 변수 이름을 사용하는 대신 연도 대신 i를 사용할 수 있고 월 대신 j를 사용할 수 있습니다. 중첩 루프는 코드를 자동으로 반복해야 하는 경우(예: 가장 높은 것에서 가장 낮은 곳까지의 숫자 정렬)에서 사용할 수 있습니다.
