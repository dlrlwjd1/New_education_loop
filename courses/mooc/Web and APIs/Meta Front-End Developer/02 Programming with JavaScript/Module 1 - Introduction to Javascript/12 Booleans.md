# Booleans

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/programming-with-javascript/lecture/PMHdF/booleans)

## 개요
- 부울 데이터 유형은 명령문이 true인지 false인지 확인하는 데 사용되므로 JavaScript를 사용하는 방법을 아는 기본 부분이 됩니다.

## 내용
- 부울 데이터 유형은 명령문이 true인지 false인지 확인하는 데 사용되므로 JavaScript를 사용하는 방법을 아는 기본 부분이 됩니다.
- 이 질문에 대한 답을 이해하기 위해 숫자 1이 숫자 2보다 작은지 확인하는 것과 같이 숫자를 비교하는 실제 시나리오에 대해 생각해 봅시다.
- 그러나 JavaScript에서는 할당 연산자로 단일 등호를 사용하여 할당 연산자의 오른쪽에서 할당 연산자의 왼쪽에 있는 변수에 값을 할당합니다.
- 예를 들어, Equality 연산자를 사용하면 100 이중 등호, 큰따옴표, 숫자 100 및 닫기 큰따옴표를 입력하면 콘솔이 true의 부울 값을 반환합니다.
- 큰따옴표가 없는 평등 연산자의 왼쪽에 있는 100이 숫자이고 큰따옴표가 있는 등호 연산자의 오른쪽에 있는 100이 문자열이라는 사실을 무시합니다.
- JavaScript에는 다른 연산자가 있으며 연산자 우선 순위 및 연산자 연관성과 같은 몇 가지 추가 개념이 있지만 지금은 건너뛸 것입니다.
- 숫자와 문자열을 비교하는 것 외에 코드에서 사용할 수있는 다른 중요한 방법이 있기 때문에 부울 값을 다시 만날 것입니다.

## 예시
- 이 질문에 대한 답을 이해하기 위해 숫자 1이 숫자 2보다 작은지 확인하는 것과 같이 숫자를 비교하는 실제 시나리오에 대해 생각해 봅시다.

## 요약
- JavaScript에는 다른 연산자가 있으며 연산자 우선 순위 및 연산자 연관성과 같은 몇 가지 추가 개념이 있지만 지금은 건너뛸 것입니다. 숫자와 문자열을 비교하는 것 외에 코드에서 사용할 수있는 다른 중요한 방법이 있기 때문에 부울 값을 다시 만날 것입니다.
