# Operators

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/programming-with-javascript/lecture/jh2es/operators)

## 개요
- 예를 들어, 값을 변수에 할당하는 할당 연산자에 이미 익숙할 수 있습니다.

## 내용
- 예를 들어, 값을 변수에 할당하는 할당 연산자에 이미 익숙할 수 있습니다.
- 이 비디오에서는 할당 및 논리 연산자와 JavaScript에서 사용하는 방법에 대해 알아봅니다.
- 예를 들어 두 개의 숫자를 추가하려면 더하기 기호로 표시되는 덧셈 연산자를 사용할 수 있습니다.
- 논리 연산자는 JavaScript에서 무언가가 true인지 false인지 확인하는 데 사용됩니다.
- 예를 들어, 두 개 이상의 조건을 확인하는 데 사용할 수 있는 AND라는 논리 연산자가 true입니다.
- 마지막으로 결과가 true인 경우 거짓 값을 반환하는 논리 연산자가 아닌 논리 연산자를 사용할 수 있습니다.
- 이제 JavaScript에서 산술 및 비교 연산자를 사용하는 방법을 보여 드리겠습니다.

## 예시
- 예를 들어, 값을 변수에 할당하는 할당 연산자에 이미 익숙할 수 있습니다.
