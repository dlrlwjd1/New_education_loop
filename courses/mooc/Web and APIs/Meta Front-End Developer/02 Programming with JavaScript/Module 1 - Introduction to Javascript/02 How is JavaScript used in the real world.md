# How is JavaScript used in the real world?

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/programming-with-javascript/lecture/ODbC8/how-is-javascript-used-in-the-real-world)

## 개요
- 오늘날 우리는 JavaScript가 너무 일반적이고 많은 기술과 많은 장치에서 너무 많이 사용되어 대체할 수 없는 언어가 되는 세상에 있습니다.

## 내용
- 오늘날 우리는 JavaScript가 너무 일반적이고 많은 기술과 많은 장치에서 너무 많이 사용되어 대체할 수 없는 언어가 되는 세상에 있습니다.
- 그러나 이제 우리는 세계가 JavaScript를 사용하여 실행되는 것을 보고 있으며 오늘날 우리가 상호 작용하는 거의 모든 응용 프로그램에는 아마도 어떤 식으로든 JavaScript가 있을 것입니다.
- C Plus Plus를 사용하거나 Java를 사용할 수 있거나 다른 것을 사용할 수 있는 것과 같은 다른 언어를 사용하는 선택권이 있습니다.
- 그러나 웹 개발과 관련하여 사용 가능한 유일한 언어는 JavaScript이며, 이것이 바로 웹 응용 프로그램을 개발할 때 배우는 것이 인기 있고 일반적이며 중요하게 만드는 이유입니다.
- 다른 언어가 없는 JavaScript의 독특한 점 중 하나는 프론트 엔드와 백엔드를 작성하는 데 사용할 수 있는 언어이기 때문에 많은 응용 프로그램이 Python, PHP 또는 Java 또는 다른 것으로 백엔드를 가지고 있다는 것입니다.
- 그러나 응용 프로그램을 디자인하는 경우 백엔드에서도 사용할 수 있기 때문에 전체 스택에서 JavaScript를 일관되게 만들기로 선택하면 응용 프로그램을 단순화하고 여러 언어를 배우거나 다른 언어로 작성된 코드 기반을 유지할 필요가 없습니다.
- C Plus Plus 및 Java 및 특정 동작을 따르는 다른 언어와 같은 다른 프로그래밍 언어와 비교할 때 약간의 일치하지 않는 JavaScript가 있습니다.

## 예시
- C Plus Plus 및 Java 및 특정 동작을 따르는 다른 언어와 같은 다른 프로그래밍 언어와 비교할 때 약간의 일치하지 않는 JavaScript가 있습니다.

- 그러나 응용 프로그램을 디자인하는 경우 백엔드에서도 사용할 수 있기 때문에 전체 스택에서 JavaScript를 일관되게 만들기로 선택하면 응용 프로그램을 단순화하고 여러 언어를 배우거나 다른 언어로 작성된 코드 기반을 유지할 필요가 없습니다. C Plus Plus 및 Java 및 특정 동작을 따르는 다른 언어와 같은 다른 프로그래밍 언어와 비교할 때 약간의 일치하지 않는 JavaScript가 있습니다.
