# Event handling

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/programming-with-javascript/lecture/T8YWw/event-handling)

## 개요
- 예를 들어 장바구니 아이콘 옆에 1이라는 숫자가 있는 원을 추가하여 이제 장바구니에 하나의 항목이 있음을 나타냅니다.

## 내용
- 예를 들어 장바구니 아이콘 옆에 1이라는 숫자가 있는 원을 추가하여 이제 장바구니에 하나의 항목이 있음을 나타냅니다.
- 동일한 이벤트가 다시 트리거되거나 실행되면 이벤트 처리 코드가 장바구니 아이콘 옆에 있는 원의 개수를 업데이트하여 이벤트를 처리합니다.
- 이벤트 리스너 추가 메서드를 사용하여 이벤트를 수신하는 방법을 보여 드리겠습니다.
- 자, 여기 콘솔로 돌아가서 웹 페이지에서 HTML 요소에 대한 이벤트 리스너를 설정하는 두 가지 방법을 보여 드리겠습니다.
- AddEventListener 메서드 외에도 이벤트를 수신하는 다른 방법은 HTML 이벤트 속성을 사용하는 것입니다.
- 그런 다음 h1 다음에 onclick equals를 입력하고 마지막에 괄호 쌍을 사용하여 함수 이름 handleclick2를 입력하여 속성을 만듭니다.
- 이 비디오에서는 AddEventListener 메서드를 사용하여 이벤트 리스너를 작성하는 방법과 함수를 HTML 이벤트 속성으로 직접 작성하는 방법을 배웠습니다.

## 예시
- 예를 들어 장바구니 아이콘 옆에 1이라는 숫자가 있는 원을 추가하여 이제 장바구니에 하나의 항목이 있음을 나타냅니다.

## 요약
- 그런 다음 h1 다음에 onclick equals를 입력하고 마지막에 괄호 쌍을 사용하여 함수 이름 handleclick2를 입력하여 속성을 만듭니다. 이 비디오에서는 AddEventListener 메서드를 사용하여 이벤트 리스너를 작성하는 방법과 함수를 HTML 이벤트 속성으로 직접 작성하는 방법을 배웠습니다.
