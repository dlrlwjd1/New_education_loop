# Scoping with var, let and const

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/programming-with-javascript/lecture/EzMYv/scoping-with-var-let-and-const)

## 개요
- 함수 외부의 모든 코드를 전역 범위라고 하며 함수 내부의 모든 코드를 로컬 범위라고 합니다.

## 내용
- 함수 외부의 모든 코드를 전역 범위라고 하며 함수 내부의 모든 코드를 로컬 범위라고 합니다.
- 블록 범위는 코드 블록에 선언된 변수가 해당 블록 내에서만 액세스할 수 있음을 나타냅니다.
- 블록 범위는 let 또는 const를 사용하여 변수를 선언할 때 작성됩니다.
- 즉, let 또는 const를 사용하여 변수를 만들 때 변수가 생성된 코드 블록으로 즉시 범위가 지정됩니다.
- 중괄호 안에 하나가 선언되고 다른 하나가 선언되지 않은 경우 해당 범위 내에서 이러한 변수에만 액세스할 수 있습니다.
- 변수의 범위는 함수 R로 범위가 지정되어 있으며, 해당 범위가 전역인 함수 외부에서 선언된 경우.
- 이 비디오에서는 ES5 JavaScript에서 var 키워드를 사용할 때 변수의 범위가 어떻게 변경되는지, ES6 JavaScript에서 let 및 const 키워드를 사용할 때 어떻게 변하는지 배웠습니다.

## 예시
- 예를 들어 동일한 이름으로 두 개의 개별 변수를 선언할 수 있습니다.

## 요약
- 변수의 범위는 함수 R로 범위가 지정되어 있으며, 해당 범위가 전역인 함수 외부에서 선언된 경우. 이 비디오에서는 ES5 JavaScript에서 var 키워드를 사용할 때 변수의 범위가 어떻게 변경되는지, ES6 JavaScript에서 let 및 const 키워드를 사용할 때 어떻게 변하는지 배웠습니다.
