# For- of loops and objects

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/programming-with-javascript/lecture/erm9R/for-of-loops-and-objects)

## 개요
- 나는 또한 문자열, 스포츠카 개체, 스포츠카 개체의 속성을 표시하는 콘솔 로그를 추가했습니다.

## 내용
- 나는 또한 문자열, 스포츠카 개체, 스포츠카 개체의 속성을 표시하는 콘솔 로그를 추가했습니다.
- 속도 속성 대신 스포츠카 개체 자체가 아닌 스포츠카 개체의 프로토타입에 존재하는 엔진 및 스티어링 속성도 루프했습니다.
- 마지막으로, 나는 콘솔에 스포츠카 물체를 기록하고 소품과 스포츠카, 물체 키와 스포츠카의 소품을 반복하고 있습니다.
- 나는 생각 이모티콘과 첫 번째 루프인 외래 루프에 대한 소품 값을 콘솔로 기록하고 있습니다.
- 그런 다음 엔진은 스포츠카 개체의 프로토타입이 아니라 스포츠카 개체의 프로토타입에 속하기 때문에 속도와 엔진을 표시합니다.
- 요약하자면, 속도와 엔진 속성은 스포츠카 개체의 프로토타입과 개체 자체에서 가져오기 때문에 외부 루프에서 나온 것입니다.
- 그러나 속도 빠른 속성은 스포츠카 개체 속성만 반복하기 때문에 for 루프에서 나옵니다.

## 예시
- 사실, 공통 상태로, for 루프는 지정된 객체뿐만 아니라 프로토타입도 반복하기 때문에 이 시나리오에서 신뢰할 수 없습니다.

## 요약
- 요약하자면, 속도와 엔진 속성은 스포츠카 개체의 프로토타입과 개체 자체에서 가져오기 때문에 외부 루프에서 나온 것입니다. 그러나 속도 빠른 속성은 스포츠카 개체 속성만 반복하기 때문에 for 루프에서 나옵니다.
