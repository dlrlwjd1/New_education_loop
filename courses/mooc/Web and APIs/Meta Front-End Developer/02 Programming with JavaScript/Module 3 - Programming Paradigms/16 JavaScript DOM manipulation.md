# JavaScript DOM manipulation

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/programming-with-javascript/lecture/0yDbS/javascript-dom-manipulation)

## 개요
- 또한 이미지나 제목 또는 둘 다와 같은 페이지의 특정 부분만 교체할 수 있습니다.

## 내용
- 또한 이미지나 제목 또는 둘 다와 같은 페이지의 특정 부분만 교체할 수 있습니다.
- 예를 들어, 영화가 재생되는 동안 몇 가지 간단한 명령으로 TV 영화의 캐릭터가 어떻게 생겼는지 변경할 수 있다고 상상해 보십시오.
- 이러한 개체는 전체 HTML 파일이 트리 구조처럼 보이는 것으로 매핑될 때까지 자체적으로 중첩된 개체를 가지고 있습니다.
- 브라우저가 서버에 연결하고 브라우저가 페이지를 다운로드하도록 허용하면 모든 HTML 코드를 수신하고 메모리에 저장합니다.
- 요소 탭을 사용하면 GUI라고도 하는 그래픽 사용자 인터페이스를 사용하여 현재 활성 웹 페이지의 DOM과 상호 작용할 수 있습니다.
- 그런 다음 열기 및 닫기 괄호 안에 내가 만들려는 HTML 요소의 이름을 입력하고 작은 따옴표로 묶습니다.
- 문서에 H2 요소를 추가한 후에도 DOM의 일부이므로 내부에 텍스트가 없기 때문에 추가된 H2 요소가 내부에 텍스트가 없기 때문에 페이지에 눈에 띄는 변경 사항이 없습니다.

## 예시
- 예를 들어, 영화가 재생되는 동안 몇 가지 간단한 명령으로 TV 영화의 캐릭터가 어떻게 생겼는지 변경할 수 있다고 상상해 보십시오.

## 요약
- 그런 다음 열기 및 닫기 괄호 안에 내가 만들려는 HTML 요소의 이름을 입력하고 작은 따옴표로 묶습니다. 문서에 H2 요소를 추가한 후에도 DOM의 일부이므로 내부에 텍스트가 없기 때문에 추가된 H2 요소가 내부에 텍스트가 없기 때문에 페이지에 눈에 띄는 변경 사항이 없습니다.
