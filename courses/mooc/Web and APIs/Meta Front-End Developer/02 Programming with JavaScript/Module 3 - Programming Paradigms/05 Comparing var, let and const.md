# Comparing var, let and const

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/programming-with-javascript/lecture/pgpIa/comparing-var-let-and-const)

## 개요
- 변수가 결국 코드의 어딘가에 초기화되는 한 초기화 전에 var 키워드로 선언된 변수에 액세스할 수 있습니다.

## 내용
- 변수가 결국 코드의 어딘가에 초기화되는 한 초기화 전에 var 키워드로 선언된 변수에 액세스할 수 있습니다.
- 그러나 var 키워드를 사용하여 변수 사용자를 마지막 코드 줄로 선언하고 코드를 다시 실행한다고 가정합니다.
- 그리고 var 키워드에 대해 알아야 할 또 다른 점은 오류 없이 동일한 var 변수를 선언하고 다시 선언할 수 있다는 것입니다.
- 각 행은 var 키워드를 사용하여 사용자 변수를 반복적으로 선언하고 다른 문자열 값 mary, joanna 및 마지막으로 mark에 할당합니다.
- 예를 들어, 4행과 5행에서 사용자 변수에 대한 콘솔 로그를 첫 번째 줄로 실행한다고 가정합니다.
- 8행과 9행의 주석 처리를 해제하여 콘솔 로그를 실행하면 문제 없이 작동하며 정의되지 않은 반환값을 반환합니다.
- const 변수는 상수 변수에 유형 오류 할당을 throw하므로 const 변수를 다시 선언할 수 없습니다.

## 예시
- 예를 들어, 4행과 5행에서 사용자 변수에 대한 콘솔 로그를 첫 번째 줄로 실행한다고 가정합니다.

## 요약
- 8행과 9행의 주석 처리를 해제하여 콘솔 로그를 실행하면 문제 없이 작동하며 정의되지 않은 반환값을 반환합니다. const 변수는 상수 변수에 유형 오류 할당을 throw하므로 const 변수를 다시 선언할 수 없습니다.
