# Rest operator

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/programming-with-javascript/lecture/aiIrt/rest-operator)

## 개요
- JavaScript의 Spread 연산자는 예를 들어 배열의 압축을 풀기 위해 상자의 압축을 풀기 위해 사용된다는 것을 이미 알고 있을 것입니다.

## 내용
- JavaScript의 Spread 연산자는 예를 들어 배열의 압축을 풀기 위해 상자의 압축을 풀기 위해 사용된다는 것을 이미 알고 있을 것입니다.
- 문제를 해결하기 위해 목록을 정리하여 상위 3개 명소를 보유하고 두 번째 방문을 위해 또 다른 목록을 준비하기로 결정했습니다.
- 그런 다음 SEcondVisit라는 목록의 나머지 부분을 유지하기 위해 먼저, 두 번째, 세 번째 변수와 다른 변수를 만듭니다.
- 이렇게 하려면 const First, Second, Third, 그리고 3개의 점을 입력하고 대괄호 안에 새 변수인 secondVisit를 입력한 다음 Top7, Semi Colon과 같습니다.
- 나는 가격에 세율을 추가하기 위해 함수를 만들고, 이름을 AddTaxToPrices로 지정하고, 구매한 항목과 함께 세율과 나머지 연산자라는 두 가지 매개변수를 제공합니다.
- addToTaXPrices, Parameters에서 REST 매개 변수는 배열을 제공하므로 Map 메서드를 사용하여 구입한 항목에 대해 배열 메서드를 사용할 수 있습니다.
- 이 비디오에서는 REST 연산자에 대해 이 비디오를 완성한 표준 JavaScript 배열 내에서 목록의 나머지 매개변수를 그룹화하는 REST 연산자를 사용하는 방법을 배웠습니다.

## 예시
