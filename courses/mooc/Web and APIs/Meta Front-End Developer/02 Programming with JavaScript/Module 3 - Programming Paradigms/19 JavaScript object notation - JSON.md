# JavaScript object notation - JSON

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/programming-with-javascript/lecture/BUYbY/javascript-object-notation-json)

## 개요
- 이 비디오에서는 JSON 문자열을 일반 JavaScript 개체로 또는 그 반대로 변환하는 방법을 배우는 데 도움이 됩니다.

## 내용
- 이 비디오에서는 JSON 문자열을 일반 JavaScript 개체로 또는 그 반대로 변환하는 방법을 배우는 데 도움이 됩니다.
- 따라서 JSON으로 작업하려면 속성 및 메서드를 사용하여 JavaScript 객체로 다시 변환하는 것이 일반적입니다.
- 먼저 const 키워드를 사용하여 jsonstr이라는 변수에 json 문자열을 할당합니다.
- 다음으로 json.parse를 입력한 다음 괄호 안에 jsonstr을 입력하여 이 변수에 대해 JSON 구문 분석 메서드를 실행합니다.
- 이 비디오에서는 parse 메서드를 사용하여 json 문자열을 JavaScript 객체로 변환하는 방법을 배웠습니다.
- 및 stringify 메서드를 사용하여 JavaScript 객체를 JSON 문자열로 변환하는 방법.
- API에서 데이터를 검색하는 작업을 수행하는 경우 JSON 문자열을 JavaScript 객체로 변환하는 것이 표준 워크플로입니다.

## 예시
- 예를 들어, Hello 문자열의 값을 포함하는 Greating이라는 속성이 하나 있는 JSON 문자열입니다.

## 요약
- 및 stringify 메서드를 사용하여 JavaScript 객체를 JSON 문자열로 변환하는 방법. API에서 데이터를 검색하는 작업을 수행하는 경우 JSON 문자열을 JavaScript 객체로 변환하는 것이 표준 워크플로입니다.
