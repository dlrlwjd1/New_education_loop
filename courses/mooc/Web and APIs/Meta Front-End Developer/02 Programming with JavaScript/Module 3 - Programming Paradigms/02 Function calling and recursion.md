# Function calling and recursion

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/programming-with-javascript/lecture/tb3kZ/function-calling-and-recursion)

## 개요
- 이 비디오에서는 재귀 기능이 무엇인지 보여주고 무한 루프에 갇히지 않도록 올바르게 작성하는 방법을 이해하는 데 도움이됩니다.

## 내용
- 이 비디오에서는 재귀 기능이 무엇인지 보여주고 무한 루프에 갇히지 않도록 올바르게 작성하는 방법을 이해하는 데 도움이됩니다.
- 함수를 호출, 호출 또는 실행하는 것은 한 번에 한 줄의 코드를 따르도록 지시하는 것을 의미합니다.
- Enter 키를 눌러 다음 줄로 이동하고 콘솔 도트 로그를 입력합니다.
- 괄호 안에서 따옴표 1 줄을 입력하고 따옴표를 붙인 다음 세미 콜론으로 닫습니다.
- 첫 번째 줄의 경우 콘솔 점 로그를 입력한 다음 괄호 안의 카운터를 입력합니다.
- 두 번째 줄에는 counter equal sign, counter - 1 semi colon을 입력합니다.
- 그리고 마지막으로 세 번째 줄의 경우 if를 입력한 다음 괄호 안에 입력하는 것으로 시작합니다.

## 예시
- 그리고 마지막으로 세 번째 줄의 경우 if를 입력한 다음 괄호 안에 입력하는 것으로 시작합니다.

## 요약
- 두 번째 줄에는 counter equal sign, counter - 1 semi colon을 입력합니다. 그리고 마지막으로 세 번째 줄의 경우 if를 입력한 다음 괄호 안에 입력하는 것으로 시작합니다.
