# Introduction to object-oriented programming

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/programming-with-javascript/lecture/n3oeh/introduction-to-object-oriented-programming)

## 개요
- 이는 앱에서 사용되는 데이터를 해당 데이터에서 작동하는 기능과 별도로 유지해야 하는 함수형 프로그래밍 접근 방식과 대조적입니다.

## 내용
- 이는 앱에서 사용되는 데이터를 해당 데이터에서 작동하는 기능과 별도로 유지해야 하는 함수형 프로그래밍 접근 방식과 대조적입니다.
- OOP 접근 방식을 사용하면 객체를 만들고 변수, 함수 및 출력 문을 포함하여 해당 객체와 관련된 모든 데이터를 저장합니다.
- 글쎄, 여기서 장점은 내가 액세스하려는 신발 가격 속성을 가진 개체의 이름에 대해 생각하지 않고 현재 개체 이름의 별칭, 즉이 키워드를 사용했다는 것입니다.
- 이제 총 가격 함수를 호출하고 SHOES 변수 값과 주세 변수 값을 전달하는 변수를 선언합니다.
- 그런 다음 Purchase1의 총 가격 방법을 복사하여 이제 동일하므로 Purchase 2 개체에 붙여넣을 수 있습니다.
- 이 접근 방식을 사용하면 모든 개체에 대해 사용자 정의 메서드를 작성하는 대신 기존 코드를 재사용할 수 있습니다.
- 그러나 기존 코드를 재사용하고 있지만 이제 빌드되는 각 새 개체에 대해 동일한 방법을 반복하고 있습니다.

## 예시
- 예를 들어 점 표기법을 사용하면 신발 가격 데이터와 주 세금 데이터에 액세스할 수 있습니다.

## 요약
- 이 접근 방식을 사용하면 모든 개체에 대해 사용자 정의 메서드를 작성하는 대신 기존 코드를 재사용할 수 있습니다. 그러나 기존 코드를 재사용하고 있지만 이제 빌드되는 각 새 개체에 대해 동일한 방법을 반복하고 있습니다.
