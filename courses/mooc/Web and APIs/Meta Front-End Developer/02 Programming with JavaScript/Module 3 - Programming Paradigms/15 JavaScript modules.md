# JavaScript modules

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/programming-with-javascript/lecture/Vb0IW/javascript-modules)

## 개요
- 독립 실행형이라는 것은 프로그램에 추가하고 제거하고 다른 모듈로 교체할 수 있으며 모든 것이 계속 작동한다는 것을 의미합니다.

## 내용
- 독립 실행형이라는 것은 프로그램에 추가하고 제거하고 다른 모듈로 교체할 수 있으며 모든 것이 계속 작동한다는 것을 의미합니다.
- 추가 읽기에서 다른 모듈 시스템에 대해 자세히 알아볼 수 있지만 이제 약간의 역사를 알았으므로 ES6 모듈이 작동하는 방식을 이해하기 위해 작동 중인 ES6 모듈을 보여 드리겠습니다.
- JavaScript의 경우 다음 줄의 브라우저에 텍스트를 표시하기 위해 큰 따옴표로 텍스트 슬래시 JavaScript가 뒤에 오는 스크립트 유형이 같음으로 작성됩니다.
- console.log를 입력한 다음 괄호 안의 스크립트 태그에서 hello 문자열을 입력한 다음 스크립트 닫기 태그를 입력했습니다.
- 개발자 도구에서 요소 탭을 열었을 때 이 코드에 연결된 내 브라우저에서 로컬 HTML 파일을 열면 콘솔 탭이 콘솔 로그 출력을 표시하는 동안 스크립트 태그가 표시됩니다.
- 이 파일을 로컬로 실행하고 있기 때문에 Cross Origin Resource Sharing이라는 내장 브라우저 보안 기능에 의해 내 스크립트에 대한 액세스가 차단되고 콘솔 탭 아래에 오류 메시지가 나타납니다.
- 이제 사용과 제한 사항에 대해 더 잘 알고 있어야 하며 브라우저에서 기본 ES6 모듈을 사용하는 방법을 알아야 합니다.

## 예시
- 예를 들어, 한 스크립트의 전역 함수는 동일한 변수 이름을 사용하여 다른 함수의 함수를 재정의할 수 있습니다.

## 요약
- 이 파일을 로컬로 실행하고 있기 때문에 Cross Origin Resource Sharing이라는 내장 브라우저 보안 기능에 의해 내 스크립트에 대한 액세스가 차단되고 콘솔 탭 아래에 오류 메시지가 나타납니다. 이제 사용과 제한 사항에 대해 더 잘 알고 있어야 하며 브라우저에서 기본 ES6 모듈을 사용하는 방법을 알아야 합니다.
