# Data Structures

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/programming-with-javascript/lecture/rCfuP/data-structures)

## 개요
- 학생 시험 결과에 대한 일부 데이터를 수신하고 원시 데이터를 기반으로 모든 시험에서 평균 성적을 출력하는 프로그램을 작성하는 것이 과제라고 가정합니다.

## 내용
- 학생 시험 결과에 대한 일부 데이터를 수신하고 원시 데이터를 기반으로 모든 시험에서 평균 성적을 출력하는 프로그램을 작성하는 것이 과제라고 가정합니다.
- 이 비디오에서는 객체, 배열, 지도 및 세트와 같은 JavaScript의 가장 일반적인 데이터 구조에 대해 알아봅니다.
- 그러나 여기서 중요한 것은 주어진 작업에 대한 솔루션을 코딩하는 방법을 이해한다는 것입니다.
- JavaScript는 Java 또는 Python과 같은 다른 프로그래밍 언어와 비교하여 사용 가능한 데이터 구조 유형이 다소 제한적입니다.
- 개체가 순서가 지정되지 않고 키 값 쌍의 반복할 수 없는 컬렉션이며 키 아래의 값을 저장하고 나중에 액세스해야 할 때 개체를 사용한다는 것을 기억할 수 있습니다.
- 예를 들어, 작업의 평균 등급을 더 일찍 찾으려면 배열을 반복하고 총합을 계산할 수 있습니다.
- 이 비디오에서는 객체, 배열, 지도 및 세트와 같은 JavaScript의 가장 일반적인 데이터 구조에 대해 배웠습니다.
