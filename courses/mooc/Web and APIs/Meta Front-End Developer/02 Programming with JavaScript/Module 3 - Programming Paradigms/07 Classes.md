# Classes

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/programming-with-javascript/lecture/ZNsNX/classes)

## 개요
- 프로그래밍에서는 특정 속성 및 메서드 집합이 있는 많은 개체를 빌드해야 하는 상황이 있습니다.

## 내용
- 프로그래밍에서는 특정 속성 및 메서드 집합이 있는 많은 개체를 빌드해야 하는 상황이 있습니다.
- 예를 들어, 자동차 레이싱 게임을 위해 수백 개의 자동차 개체를 만들어야 할 수도 있습니다.
- 그것들은 본질적으로 당신이 원하는 만큼 특정 종류의 새로운 객체를 만드는 데 반복적으로 사용할 수 있는 청사진입니다.
- 자바 스크립트에서 클래스는 class 키워드를 사용하여 빌드된 다음 대문자로 시작하는 클래스 이름과 곱슬 괄호 쌍을 사용하여 빌드됩니다.
- 예를 들어 Turbo on 메서드에 액세스하려면 CAR ONE 개체의 이름을 입력한 다음 점을 입력한 다음 해당 개체에 존재하는 메서드의 이름을 입력합니다.
- 일반 함수와 마찬가지로 클래스 메서드에 매개 변수를 전달한 다음 일반 함수와 동일하게 사용할 수도 있습니다.
- 이 비디오에서는 클래스와 클래스를 사용하여 특정 속성을 사용하여 여러 개체 인스턴스를 구축하는 방법에 대해 배웠습니다.

## 예시
- 예를 들어, 자동차 레이싱 게임을 위해 수백 개의 자동차 개체를 만들어야 할 수도 있습니다.

## 요약
- 일반 함수와 마찬가지로 클래스 메서드에 매개 변수를 전달한 다음 일반 함수와 동일하게 사용할 수도 있습니다. 이 비디오에서는 클래스와 클래스를 사용하여 특정 속성을 사용하여 여러 개체 인스턴스를 구축하는 방법에 대해 배웠습니다.
