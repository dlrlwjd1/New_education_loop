# De-structuring arrays and objects

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/programming-with-javascript/lecture/RP3yM/de-structuring-arrays-and-objects)

## 개요
- 이 비디오에서는 객체와 배열을 해체하고 객체와 배열을 해체하는 방법과 객체와 배열에서 새로운 변수를 추출하기 위해 destructuring 구문을 사용하는 방법을 배웁니다.

## 내용
- 이 비디오에서는 객체와 배열을 해체하고 객체와 배열을 해체하는 방법과 객체와 배열에서 새로운 변수를 추출하기 위해 destructuring 구문을 사용하는 방법을 배웁니다.
- 객체 또는 배열에서 무언가를 파괴하는 이 경우 프로젝트 폴더는 폴더에서 다른 위치로 해당 항목을 복사하는 것과 같습니다.
- 나는 소문자가 작동하지 않고 let open curly bracket small case pi close curly bracket이 정의되지 않은 수학 PI 반환과 같음을 입력하면 정의되지 않은 값을 반환합니다.
- 다음 단계는 Triple Equal Strict Comparison 연산자를 사용하여 모든 CAPS PI 변수가 Math Dot PI와 동일한 값과 데이터 유형을 가지고 있는지 확인하는 것입니다.
- 이렇게 하면 해체된 속성과 원래 속성이 연결되어 있지 않음을 증명하기 위해 true 값을 반환합니다.
- 이제 pi, triple equal sign, math dot pi를 입력하여 모든 caps pi와 math dot pi를 다시 비교할 수 있으므로 false의 부울 값을 다시 얻을 수 있습니다.
- 이 비디오에서는 객체를 구조화하고 지우는 방법과 객체와 배열에서 새로운 변수를 추출하기 위해 파괴 구문을 사용하는 방법을 다루었습니다.

## 예시
- 이 비디오에서는 객체를 구조화하고 지우는 방법과 객체와 배열에서 새로운 변수를 추출하기 위해 파괴 구문을 사용하는 방법을 다루었습니다.
