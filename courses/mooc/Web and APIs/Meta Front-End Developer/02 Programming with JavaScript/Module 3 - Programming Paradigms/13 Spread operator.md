# Spread operator

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/programming-with-javascript/lecture/2qgy8/spread-operator)

## 개요
- 스프레드 연산자를 배열 항목을 분산시키고 개체를 함께 결합할 수 있는 마법의 다목적 도구로 생각하십시오.

## 내용
- 스프레드 연산자를 배열 항목을 분산시키고 개체를 함께 결합할 수 있는 마법의 다목적 도구로 생각하십시오.
- 스프레드 연산자가 유용한 위치를 설명하기 위해 먼저 배열을 만든 다음 기본 함수를 사용하여 항목을 호출해 보겠습니다.
- 간단하게 유지하기 위해 콘솔에 로그인하고 함수를 만들고 place1, place2, place3의 세 가지 인수로 showiterary라는 이름을 지정합니다.
- 이제 console.log를 입력한 다음 문자열 방문과 첫 번째 인수인 place1을 입력하여 방문할 세 곳을 로깅합니다.
- 나는 함수 이름, showItIterary, 그리고 Top3으로 시작하는 각 배열 요소, 배열의 첫 번째 요소인 zero를 열고 대괄호를 닫습니다.
- 이제 showiterary 함수를 호출하고 이 함수를 전달하면 7개의 인수가 Top7에서와 같이 다시 0으로 시작하고 대괄호 내에서 0으로 다시 시작합니다.
- showiterary 함수를 입력한 다음 괄호, 3개의 점, top7, 닫기 괄호, 세미콜론을 엽니다.

## 예시
- showiterary 함수를 입력한 다음 괄호, 3개의 점, top7, 닫기 괄호, 세미콜론을 엽니다.

## 요약
- 이제 showiterary 함수를 호출하고 이 함수를 전달하면 7개의 인수가 Top7에서와 같이 다시 0으로 시작하고 대괄호 내에서 0으로 다시 시작합니다. showiterary 함수를 입력한 다음 괄호, 3개의 점, top7, 닫기 괄호, 세미콜론을 엽니다.
