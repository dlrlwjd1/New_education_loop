# Module summary: Programming Paradigms

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/programming-with-javascript/lecture/2kdEY/module-summary-programming-paradigms)

## 개요
- 이 모듈에서 함수형 프로그래밍과 객체 지향 프로그래밍의 핵심 기능을 살펴보았습니다.

## 내용
- 이 모듈에서 함수형 프로그래밍과 객체 지향 프로그래밍의 핵심 기능을 살펴보았습니다.
- 이 모듈에서 프로그래밍 패러다임을 공부한 후 함수형 프로그래밍과 함수에서 데이터를 분리하여 문제를 해결하는 방법을 설명할 수 있어야 합니다.
- 프로그래밍에서 범위는 코드의 어떤 부분에 액세스할 수 있고 어떤 부분에 액세스할 수 없는지를 결정합니다.
- ES5 JavaScript에서 var 키워드를 사용할 때 변수의 범위가 어떻게 변경되는지, 키워드를 사용할 때 ES6 JavaScript에서 let 및 const를 사용하는 방법을 배웠습니다.
- 이제 JavaScript에서 범위 체인이 작동하는 방식에 익숙할 것입니다.
- 또한 이제 전역 및 로컬을 포함하여 다양한 유형의 범위가 작동하는 방식을 식별할 수 있어야 합니다.
- 또한 JavaScript Code에서 Spread, REST, Template Strings 및 Modules와 같은 최신 기능을 사용하는 방법을 살펴보았습니다.

## 예시
- 또한 JavaScript Code에서 Spread, REST, Template Strings 및 Modules와 같은 최신 기능을 사용하는 방법을 살펴보았습니다.

## 요약
- 또한 이제 전역 및 로컬을 포함하여 다양한 유형의 범위가 작동하는 방식을 식별할 수 있어야 합니다. 또한 JavaScript Code에서 Spread, REST, Template Strings 및 Modules와 같은 최신 기능을 사용하는 방법을 살펴보았습니다.
