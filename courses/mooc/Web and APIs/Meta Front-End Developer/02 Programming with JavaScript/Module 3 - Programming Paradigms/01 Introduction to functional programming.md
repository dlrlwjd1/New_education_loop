# Introduction to functional programming

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/programming-with-javascript/lecture/KTOth/introduction-to-functional-programming)

## 개요
- 함수의 외부에 데이터가 존재할 수 있으므로 함수형 프로그래밍에서 데이터와 함수 사이에는 분명한 차이가 있습니다.

## 내용
- 함수의 외부에 데이터가 존재할 수 있으므로 함수형 프로그래밍에서 데이터와 함수 사이에는 분명한 차이가 있습니다.
- 예를 들어, 함수에 일부 데이터가 필요할 때 인수 형식의 값을 전달한다는 것을 기억할 수 있습니다.
- 그런 다음 함수는 주어진 데이터에 대해 약간의 작업을 수행하고 프로그램의 다른 곳에서 사용할 수 있는 몇 가지 값을 반환합니다.
- 이제 통화 변환을 계산하기 위해 코딩 예제를 사용하여 함수형 프로그래밍 스타일의 실제 구현을 살펴보겠습니다.
- 여기서 첫 번째 단어의 첫 글자는 소문자이고 다음 단어의 첫 번째 글자는 공백이 없고 대문자로 표시됩니다.
- 다음으로, 이러한 변수로 작동하고 이 데이터에 대해 작동하는 함수를 만들 수 있습니다.
- 이렇게 하기 위해 방금 만든 함수의 결과에 CurrencyTwo 값을 할당합니다.
