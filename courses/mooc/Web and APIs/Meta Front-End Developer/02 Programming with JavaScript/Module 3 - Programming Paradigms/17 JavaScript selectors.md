# JavaScript selectors

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/programming-with-javascript/lecture/GjOua/javascript-selectors)

## 개요
- 이 비디오에서는 JavaScript에서 선택기를 사용하여 문서에서 특정 개체를 빠르게 찾는 방법을 안내합니다.

## 내용
- 이 비디오에서는 JavaScript에서 선택기를 사용하여 문서에서 특정 개체를 빠르게 찾는 방법을 안내합니다.
- JavaScript 선택기는 키워드 document를 입력하여 액세스할 수 있는 Document 객체와 함께 작동합니다.
- 또는 document 키워드에 대해 콘솔 로그를 실행하여 동일한 결과를 얻을 수 있습니다.
- 예를 들어, 이 페이지에 두 개의 HTML 단락 요소가 포함되어 있다는 것을 알고 있습니다.
- 또 다른 유용한 JavaScript 선택기는 지정된 HTML ID 속성과 일치하는 Dawn에서 개체를 찾을 수 있는 ID로 요소를 가져옵니다.
- 그런 다음 괄호 안의 문자열 제목을 누르면 Enter 키를 누르면 H1, 요소가 Heading의 HTML id 속성 값으로 할당 된 것을 알 수 있습니다.
- 이 비디오에서는 JavaScript 선택기를 사용하여 문서에서 특정 개체를 찾는 프로세스의 속도를 높이는 방법을 배웠습니다.

## 예시
- 예를 들어, 버튼을 클릭하고 일부 텍스트의 색상을 변경하거나 팝업 메시지를 표시할 수도 있습니다.
