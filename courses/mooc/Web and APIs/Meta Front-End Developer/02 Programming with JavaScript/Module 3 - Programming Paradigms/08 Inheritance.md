# Inheritance

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/programming-with-javascript/lecture/bFDJq/inheritance)

## 개요
- 이 비디오에서는 상속이 JavaScript에도 존재하며 상속 모델이 프로토타입이라는 것을 중심으로 전개된다는 것을 알게 될 것입니다.

## 내용
- 이 비디오에서는 상속이 JavaScript에도 존재하며 상속 모델이 프로토타입이라는 것을 중심으로 전개된다는 것을 알게 될 것입니다.
- JavaScript에서 프로토타입은 여러 다른 객체와 공유할 속성을 보유할 수 있는 객체입니다.
- 상속과 프로토타입을 구축하는 방법을 설명하는 몇 가지 코드 예제를 사용하여 이제 이에 대해 자세히 살펴보겠습니다.
- 예를 들어, Eagle1 변수를 Bird 객체를 가져와 객체 .create 메서드에 전달하는 호출로 설정했습니다.
- Eagle2 개체는 Bird 개체에 저장된 속성에 프로토타입으로도 액세스할 수 있다는 것을 이해하는 것이 중요합니다.
- 따라서 깃털이 있고 펭귄1의 속성을 날 수 있는 액세스는 내가 코드를 실행할 때 프로토타입에 저장된 값을 반환합니다.
- 이 비디오에서는 Object Create 메서드를 사용하여 상속을 구축할 수 있지만 JavaScript의 상속에 대해 배웠습니다.

## 예시
- 예를 들어, Eagle1 변수를 Bird 객체를 가져와 객체 .create 메서드에 전달하는 호출로 설정했습니다.

## 요약
- 따라서 깃털이 있고 펭귄1의 속성을 날 수 있는 액세스는 내가 코드를 실행할 때 프로토타입에 저장된 값을 반환합니다. 이 비디오에서는 Object Create 메서드를 사용하여 상속을 구축할 수 있지만 JavaScript의 상속에 대해 배웠습니다.
