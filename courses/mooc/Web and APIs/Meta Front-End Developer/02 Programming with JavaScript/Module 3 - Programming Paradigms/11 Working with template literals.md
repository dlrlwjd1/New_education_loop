# Working with template literals

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/programming-with-javascript/lecture/Td4w8/working-with-template-literals)

## 개요
- 이 비디오에서는 JavaScript ES6에서 템플릿 리터럴을 만들고 사용하여 이점을 이해하는 방법을 안내합니다.

## 내용
- 이 비디오에서는 JavaScript ES6에서 템플릿 리터럴을 만들고 사용하여 이점을 이해하는 방법을 안내합니다.
- 먼저 작은 따옴표 또는 큰 따옴표를 사용하여 작성된 JavaScript ES5의 문자열을 다시 살펴보겠습니다.
- 문자열 값을 보유하는 let 키워드와 여러 줄이 없고 ES5에는 여러 줄 문자열이 없습니다.
- ES5 방법을 사용하면 작은 따옴표 또는 큰 따옴표를 사용하여 문자열만 만들 수 있으며 이 방법을 사용하면 여러 줄 문자열을 사용할 수 없습니다.
- 이제 템플릿 리터럴을 다시 사용하여 다른 줄에서 먼저 변수를 보간할 수 있습니다.
- 템플릿 리터럴을 사용하면 작은 따옴표와 큰 따옴표 사용의 한계에 대해 걱정할 필요가 없습니다.
- 자바스크립트에서 여러 줄 문자열을 만들고 변수를 보간하기 위해 템플릿 리터럴을 빌드한 다음 적용하는 방법을 배웠습니다.

## 예시
- 자바스크립트에서 여러 줄 문자열을 만들고 변수를 보간하기 위해 템플릿 리터럴을 빌드한 다음 적용하는 방법을 배웠습니다.

## 요약
- 템플릿 리터럴을 사용하면 작은 따옴표와 큰 따옴표 사용의 한계에 대해 걱정할 필요가 없습니다. 자바스크립트에서 여러 줄 문자열을 만들고 변수를 보간하기 위해 템플릿 리터럴을 빌드한 다음 적용하는 방법을 배웠습니다.
