# Introduction to scope

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/programming-with-javascript/lecture/o7wWi/introduction-to-scope)

## 개요
- 예를 들어, 코드 내에서 함수가 액세스할 수 있는 변수는 무엇입니까?

## 내용
- 예를 들어, 코드 내에서 함수가 액세스할 수 있는 변수는 무엇입니까?
- 앞으로 몇 분 동안 범위의 개념을 탐구하고 JavaScript 내에서 범위 체인이 작동하는 방식에 대해 배우게 됩니다.
- JavaScript에서 범위가 작동하는 방식에 대해 생각하는 좋은 방법은 양방향 미러 유리입니다.
- 예를 들어, 레스토랑이 양방향 유리를 사용하는 경우 레스토랑 외부의 사람들은 내부에서 일어나는 일을 볼 수 없지만 내부 사람들은 외부에서 일어나는 일을 볼 수 있습니다.
- 예를 들어, 함수 외부에 존재하는 코드를 전역 범위라고 하며 함수 내부의 모든 코드를 로컬 범위 또는 함수 범위라고 합니다.
- 변수가 함수 내에서 정의된 경우 해당 함수의 범위가 지정된다고 말할 수 있습니다.
- 또한 함수 범위라고도 하는 전역 및 로컬을 포함하여 다양한 유형의 범위가 작동하는 방식을 식별할 수도 있습니다.
