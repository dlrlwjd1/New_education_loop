# Programming with JavaScript

Meta Front-End Developer 전문과정의 두 번째 강좌. JavaScript 문법, 자료구조, 함수형·객체지향 프로그래밍, 브라우저 DOM과 Jest 테스트를 다룬다.

- 강좌 링크: <https://www.mooc.org/learn/programming-with-javascript>
- 구성: 5개 모듈, 영상 58개
- 노트: 영어 Transcript를 온디바이스 번역한 한국어 정리
- 제외: 읽기 자료·퀴즈·채점 평가의 정답 및 제출

## 모듈 구성

### Module 1 - Introduction to Javascript

- 영상 19개
- 변수, 자료형, 연산자, 문자열, 숫자와 불리언
- 조건문과 반복문

### Module 2 - The Building Blocks of a Program

- 영상 10개
- 배열, 객체와 함수
- 버그, 오류와 예외 처리

### Module 3 - Programming Paradigms

- 영상 20개
- 함수형 프로그래밍과 재귀
- 객체지향 프로그래밍
- 스코프와 `var`, `let`, `const`
- 구조 분해, 템플릿 리터럴, spread·rest
- JavaScript와 브라우저 DOM

### Module 4 - Testing

- 영상 7개
- 단위 테스트와 테스트 주도 개발
- Jest
- Webpack, 트랜스파일링, Node.js와 NPM

### Module 5 - End-of-Course Graded Assessment

- 영상 2개
- 강좌 복습과 다음 단계 안내
- 채점 평가는 정리에서 제외
