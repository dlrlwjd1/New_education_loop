# Webpages, Websites and Web Apps

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/introduction-to-front-end-development/lecture/EnR5Z/webpages-websites-and-web-apps)

## 개요
- 웹 페이지가 단일 페이지인 경우 웹 사이트는 하나의 도메인 이름 아래 서로 연결되는 웹 페이지 모음입니다.

## 내용
- 웹 페이지가 단일 페이지인 경우 웹 사이트는 하나의 도메인 이름 아래 서로 연결되는 웹 페이지 모음입니다.
- 즐겨 찾는 백과사전 웹사이트를 방문했는데 홈페이지에 여러 기사로 연결되는 링크가 많을 때 해당 링크 중 하나를 클릭하면 새 웹 페이지의 기사가 표시되고 해당 문서는 더 많은 기사 및 다른 웹 페이지로 연결됩니다.
- 예를 들어 즐겨 찾는 검색 엔진으로 이동하여 구문을 검색하면 다른 웹 사이트로 연결되는 링크 목록이 검색 결과에 표시됩니다.
- 여기서 정의가 좀 더 흐려집니다.웹 사이트와 웹 애플리케이션이라는 용어는 종종 같은 의미로 사용됩니다.웹 사이트와 웹 애플리케이션 간의 주요 차이점은 상호 작용 수준과 동적 콘텐츠입니다.
- 음식을 주문하고 싶은데 즐겨 찾는 사이트로 이동하면 브라우저에 웹 페이지가 표시되고 메뉴에서 음식을 선택하여 주문을 제출한다고 가정해 보겠습니다.
- 예를 들어 회사 웹 사이트와 회사가 제공하는 서비스에 대한 정보를 표시하는 회사 웹 사이트와 비교해 보십시오.
- 특정 도메인의 웹 페이지가 웹 사이트를 구성하고 있으며 웹 사이트와 웹 응용 프로그램 간의 주요 차이점은 상호 작용 수준과 동적 콘텐츠라는 것을 알고 있습니다.

## 예시
- 예를 들어 즐겨 찾는 검색 엔진으로 이동하여 구문을 검색하면 다른 웹 사이트로 연결되는 링크 목록이 검색 결과에 표시됩니다.

## 요약
- 예를 들어 회사 웹 사이트와 회사가 제공하는 서비스에 대한 정보를 표시하는 회사 웹 사이트와 비교해 보십시오. 특정 도메인의 웹 페이지가 웹 사이트를 구성하고 있으며 웹 사이트와 웹 응용 프로그램 간의 주요 차이점은 상호 작용 수준과 동적 콘텐츠라는 것을 알고 있습니다.
