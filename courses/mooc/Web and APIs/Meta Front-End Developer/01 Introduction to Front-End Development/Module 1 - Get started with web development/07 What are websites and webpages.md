# What are websites and webpages?

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/introduction-to-front-end-development/lecture/7kj2y/what-are-websites-and-webpages)

## 개요
- 웹 페이지는 웹 브라우저에 이미지, 텍스트, 동영상 및 기타 콘텐츠를 표시하는 문서입니다 웹 브라우저에 표시되는 문서인 반면, 웹사이트는 서로 연결된 웹페이지의 모음입니다.

## 내용
- 웹 페이지는 웹 브라우저에 이미지, 텍스트, 동영상 및 기타 콘텐츠를 표시하는 문서입니다 웹 브라우저에 표시되는 문서인 반면, 웹사이트는 서로 연결된 웹페이지의 모음입니다.
- 이번 주에 많은 웹사이트를 방문하셨을 것입니다, 실제로 지금 이 순간에도 한 웹사이트에서 동영상을 시청하고 있을 것입니다, 즐겨 찾는 백과사전 웹사이트를 방문하는 경우를 예로 들어 보겠습니다.
- 홈페이지에 도착하면 다양한 기사로 연결되는 많은 링크가 있습니다 그 링크 중 하나를 클릭하면 새 웹페이지 기사로 이동하고 그 기사는 더 많은 기사 및 다른 웹 페이지로 연결됩니다.
- 그러나 페이지의 링크가 모두 같은 웹사이트로 연결될 필요는 없습니다, 다른 웹사이트로 연결될 수도 있습니다.
- 현재 인터넷 속도로 인터넷에 있는 모든 웹 페이지를 다운로드하려면 인터넷에 있는 웹페이지와 이 수십억 개의 다양한 웹페이지들은 모두 동일한 핵심 기술에 의존합니다.
- 이러한 태그는 브라우저 창에 표시되는 콘텐츠를 설명합니다, 이 콘텐츠는 제목, 단락, 이미지, 심지어는 오디오 및 비디오와 같은 멀티미디어 요소도 포함할 수 있습니다, hTML이 콘텐츠를 설명하는 방식을 마크업이라고 합니다.
- 이 생성 프로세스를 페이지 렌더링이라고 하며, 웹 서버의 응답은 요청을 이행하기 위해 완전한 웹 페이지여야 합니다, 브라우저에 페이지를 표시하려면 웹 서버의 응답이 완전한 웹 페이지여야 합니다.

## 예시
- 예를 들어 즐겨찾는 검색 엔진을 방문해서 문구를 검색하면 검색 결과에 다른 웹사이트로 연결되는 링크 목록이 표시됩니다.

## 요약
- 이러한 태그는 브라우저 창에 표시되는 콘텐츠를 설명합니다, 이 콘텐츠는 제목, 단락, 이미지, 심지어는 오디오 및 비디오와 같은 멀티미디어 요소도 포함할 수 있습니다, hTML이 콘텐츠를 설명하는 방식을 마크업이라고 합니다. 이 생성 프로세스를 페이지 렌더링이라고 하며, 웹 서버의 응답은 요청을 이행하기 위해 완전한 웹 페이지여야 합니다, 브라우저에 페이지를 표시하려면 웹 서버의 응답이 완전한 웹 페이지여야 합니다.
