# Front-end, back-end and full-stack developer roles

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/introduction-to-front-end-development/lecture/lYajY/front-end-back-end-and-full-stack-developer-roles)

## 개요
- 개발자들이 아키텍트를 만들고 우리가 디바이스에서 매일 사용하는 기술을 유지 관리하지 않았다면 우리 모두가 살고 있는 디지털 세상은 불가능했을 것입니다.

## 내용
- 개발자들이 아키텍트를 만들고 우리가 디바이스에서 매일 사용하는 기술을 유지 관리하지 않았다면 우리 모두가 살고 있는 디지털 세상은 불가능했을 것입니다.
- 프런트 엔드 개발자는 사용자가 상호 작용하는 웹 사이트 또는 웹 앱의 모든 부분에서 일하는 사람입니다.
- 이 경우 html을 사용하여 사용자가 이메일 주소를 입력할 수 있는 입력 영역과 전자 메일 주소를 클릭하여 보낼 수 있는 버튼과 같은 표시 요소를 만들 수 있습니다.
- 마지막으로 자바스크립트를 사용하여 사용자가 버튼을 클릭할 때 액티비티를 처리할 수 있습니다.이메일 주소가 유효한지 확인한 다음 해당 이메일 주소를 웹사이트로 전송하여 뉴스레터 회원에 보관하는 것과 같을 수 있습니다.
- 처리 (예: 계정 수행, 로그인 또는 신용 카드를 사용한 온라인 구매 완료) 백엔드 개발자는 웹 사이트와 데이터베이스에 저장된 콘텐츠의 상호 작용을 촉진할 것입니다.
- 이는 다양할 수 있지만 일반적으로 백엔드 프로그래밍 언어, 데이터베이스 관리 시스템, API 및 웹 서버와 관련된 지식으로 구성되며 급여는 프런트 엔드 개발자와 비슷하며 경험에 따라 달라집니다.
- 예를 들어 웹 사이트 또는 웹의 계획, 아키텍처, 디자인, 개발, 배포 및 유지 관리에 대한 관련 전문 지식을 보유하고 있습니다.

## 예시
- 예를 들어 시각적인 사람이라면 최종 사용자에게 탁월한 경험을 제공하는 멋진 웹 사이트를 디자인하고 싶을 수 있습니다.

## 요약
- 이는 다양할 수 있지만 일반적으로 백엔드 프로그래밍 언어, 데이터베이스 관리 시스템, API 및 웹 서버와 관련된 지식으로 구성되며 급여는 프런트 엔드 개발자와 비슷하며 경험에 따라 달라집니다. 예를 들어 웹 사이트 또는 웹의 계획, 아키텍처, 디자인, 개발, 배포 및 유지 관리에 대한 관련 전문 지식을 보유하고 있습니다.
