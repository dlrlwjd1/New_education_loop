# APIs and services

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/introduction-to-front-end-development/lecture/G30rT/apis-and-services)

## 개요
- API는 운영 체제, 애플리케이션 또는 기타 서비스의 기능이나 데이터에 액세스하는 애플리케이션을 만들기 위한 일련의 함수 및 프로시저입니다.

## 내용
- API는 운영 체제, 애플리케이션 또는 기타 서비스의 기능이나 데이터에 액세스하는 애플리케이션을 만들기 위한 일련의 함수 및 프로시저입니다.
- 웹 개발자가 사용하는 일반적인 API로는 브라우저, API, REST API, 센서 기반 API 등이 있습니다.
- 소프트웨어 개발에서 API는 종종 여러 구성 요소 또는 시스템을 연결하는 다리 역할을 합니다.
- 새 서비스를 추가하여 브라우저의 기능을 확장하고 복잡한 기능을 단순화하고 고급 기능을 빌드하기 위한 쉬운 구문을 제공하도록 설계되었습니다.
- 이러한 API 웹 서버는 웹 페이지 또는 모바일 앱과 같은 웹 클라이언트에 데이터 백본을 제공하도록 설계되었습니다.
- 즉, 이러한 API는 데이터 가져오기나 데이터 가져오기, 생성과 같은 작업을 수행할 수 있어야 합니다.데이터 사후 업데이트 또는 데이터 추가 및 삭제 또는 삭제라고도 합니다.
- API 문제, REST 원칙 및 검색 가능한 인터페이스를 만들기 위한 우수 설계 사례 이를 통해 예상한 정확한 응답을 얻을 수 있습니다.

## 예시
- 여전히 모호하게 들리더라도 API라는 용어는 의도적으로 너무 많은 애플리케이션과 사용 사례를 공개한다는 점을 기억하세요.

## 요약
- 즉, 이러한 API는 데이터 가져오기나 데이터 가져오기, 생성과 같은 작업을 수행할 수 있어야 합니다.데이터 사후 업데이트 또는 데이터 추가 및 삭제 또는 삭제라고도 합니다. API 문제, REST 원칙 및 검색 가능한 인터페이스를 만들기 위한 우수 설계 사례 이를 통해 예상한 정확한 응답을 얻을 수 있습니다.
