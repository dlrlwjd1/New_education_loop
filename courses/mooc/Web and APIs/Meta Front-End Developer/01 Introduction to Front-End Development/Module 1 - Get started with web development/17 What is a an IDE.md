# What is a an IDE?

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/introduction-to-front-end-development/lecture/a6AVm/what-is-a-an-ide)

## 개요
- 다양한 IDE를 사용할 수 있으며, 특정 프로그래밍 언어에만 적용되는 IDE도 있고 하나의 IDE에서 여러 언어를 지원하는 IDE도 있습니다.

## 내용
- 다양한 IDE를 사용할 수 있으며, 특정 프로그래밍 언어에만 적용되는 IDE도 있고 하나의 IDE에서 여러 언어를 지원하는 IDE도 있습니다.
- 즉, 프로그래밍 언어의 특수 키워드가 다양한 색상으로 강조 표시되어 개발자가 이러한 키워드를 다른 텍스트와 빠르게 구분할 수 있습니다.
- 예를 들어 구문 강조 표시 없이 JavaScript 코드를 작성하는 경우 다른 텍스트에서 키워드를 식별하기가 더 어려울 수 있습니다.
- 프로그래밍 언어에는 특수 키워드가 있으므로 IDE는 단어를 입력하기 시작하면 자동으로 완성되도록 제안 기능을 제공할 수 있습니다.
- 예를 들어 JavaScript 파일 상단에 MyFunction이라는 자바스크립트 함수가 정의되어 있는 경우 m을 입력하기 시작하자마자 IDE에서 이 함수를 자동 완성 기능으로 제안합니다.
- IDE는 코드를 이해하므로 리팩토링을 지원하고 모든 파일에서 함수 이름을 자동으로 업데이트할 수 있습니다.
- IDE에는 버그를 조사하고 다른 개발자와 협업하는 데 도움이 되는 많은 다른 기능이 포함되어 있습니다.

## 예시
- 예를 들어 구문 강조 표시 없이 JavaScript 코드를 작성하는 경우 다른 텍스트에서 키워드를 식별하기가 더 어려울 수 있습니다.

## 요약
- IDE는 코드를 이해하므로 리팩토링을 지원하고 모든 파일에서 함수 이름을 자동으로 업데이트할 수 있습니다. IDE에는 버그를 조사하고 다른 개발자와 협업하는 데 도움이 되는 많은 다른 기능이 포함되어 있습니다.
