# Introduction to the course

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/introduction-to-front-end-development/lecture/taH5Z/introduction-to-the-course)

## 개요
- 휴대폰, 컴퓨터, 태블릿 또는 기타 장치의 애플리케이션을 사용하여 웹에 액세스하고 쇼핑, 호텔 예약, 친구 및 직장 동료와의 채팅과 같은 작업을 수행할 수 있습니다.

## 내용
- 휴대폰, 컴퓨터, 태블릿 또는 기타 장치의 애플리케이션을 사용하여 웹에 액세스하고 쇼핑, 호텔 예약, 친구 및 직장 동료와의 채팅과 같은 작업을 수행할 수 있습니다.
- 집에서 편안하게 일하고, 동료와 소통하고, 생산성을 높일 수 있습니다.이 모든 것은 인터넷, 인프라, 기술의 조합과 사용하는 앱을 개발하는 숙련된 전문가들이 함께라면 가능합니다.
- 간단히 말씀드리자면, 앱이라는 용어는 휴대폰에 있는 앱을 가리킬 수도 있고 웹 사이트에서 실행되는 웹 앱을 가리킬 수도 있고 다른 온라인 방식으로 실행되는 웹 앱을 가리킬 수도 있습니다.
- 개발자가 이러한 기술을 결합하여 기능적이고 인터랙티브한 웹 사이트 및 웹 애플리케이션을 구축하는 방법을 배우게 됩니다.
- 진행하면서 전문 개발자가 사용하는 몇 가지 도구를 살펴보고 모범 사례 및 표준을 사용하여 코딩의 기초를 배우게 됩니다.
- 예를 들어 통합 개발 환경 또는 IDE라고 하는 업계 표준 소프트웨어를 사용하여 웹 브라우저에 내장된 개발자 도구 및 코드를 사용하는 방법을 배우게 됩니다.
- 또한 사용자 인터페이스 또는 UI 디자인에 대해 알아보고 일반적인 UI 구성 요소를 사용하여 작업하고 유연한 Bootstrap 그리드를 사용하여 해당 구성 요소를 배치하는 방법도 배우게 됩니다.

## 예시
- 또한 HTML, CSS, JavaScript와 같은 핵심 인터넷 기술을 사용하여 실습을 할 수 있습니다.

## 요약
- 예를 들어 통합 개발 환경 또는 IDE라고 하는 업계 표준 소프트웨어를 사용하여 웹 브라우저에 내장된 개발자 도구 및 코드를 사용하는 방법을 배우게 됩니다. 또한 사용자 인터페이스 또는 UI 디자인에 대해 알아보고 일반적인 UI 구성 요소를 사용하여 작업하고 유연한 Bootstrap 그리드를 사용하여 해당 구성 요소를 배치하는 방법도 배우게 됩니다.
