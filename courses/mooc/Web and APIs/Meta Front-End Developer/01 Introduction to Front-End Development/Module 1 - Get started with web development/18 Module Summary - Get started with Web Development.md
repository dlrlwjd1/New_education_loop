# Module Summary - Get started with Web Development

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/introduction-to-front-end-development/lecture/g84rB/module-summary-get-started-with-web-development)

## 개요
- 이 모듈을 통해 웹 작동 방식의 기본 사항을 살펴보고 핵심 인터넷 기술의 주요 개념을 익혔습니다.그 과정에서 습득한 주요 기술을 요약해 보겠습니다.

## 내용
- 이 모듈을 통해 웹 작동 방식의 기본 사항을 살펴보고 핵심 인터넷 기술의 주요 개념을 익혔습니다.그 과정에서 습득한 주요 기술을 요약해 보겠습니다.
- 이제 웹 페이지 측면에서 각 웹 사이트의 주요 요소를 간략하게 설명하여 웹 사이트와 웹 페이지를 구분할 수 있을 것입니다.
- 또한 웹 서버의 기본 사항도 살펴보았으므로 데이터 센터가 웹 서버에 스토리지와 전력을 제공하는 방법을 설명할 수 있을 것입니다.
- 웹 서버 하드웨어와 소프트웨어의 주요 기능을 구분하고 웹 서버가 HTTP 또는 하이퍼텍스트 전송 프로토콜을 통해 요청을 처리하는 방법을 간략하게 설명하십시오.
- 이 탐색을 마치면 이제 웹 브라우저가 무엇인지 설명하고, 웹 브라우저가 웹 서버로부터 콘텐츠를 수신하여 사용자에게 표시하는 방법을 설명하고, 요청 응답 주기를 간략하게 설명할 수 있을 것입니다.
- 이제 IP 주소의 개념과 IP 주소가 인터넷을 통한 데이터 전송을 촉진하는 방법을 설명하고, HTTP 기능에 대한 이해를 입증하고, 일반적인 HTTP 방법을 식별하고, HTML, CSS 및 Javascript가 서로 상호 작용하는 방식을 개괄적으로 설명할 수 있어야 합니다.
- 마지막으로 라이브러리와 프레임워크의 장점과 단점을 이해하고, 애플리케이션 프로그래밍 인터페이스 또는 API를 식별하고, 애플리케이션 개발에 어떻게 활용되는지 설명하고, IDE 또는 통합 개발 환경의 목적과 이점을 설명할 수 있어야 합니다.

## 예시
- 마지막으로 라이브러리와 프레임워크의 장점과 단점을 이해하고, 애플리케이션 프로그래밍 인터페이스 또는 API를 식별하고, 애플리케이션 개발에 어떻게 활용되는지 설명하고, IDE 또는 통합 개발 환경의 목적과 이점을 설명할 수 있어야 합니다.

## 요약
- 이제 IP 주소의 개념과 IP 주소가 인터넷을 통한 데이터 전송을 촉진하는 방법을 설명하고, HTTP 기능에 대한 이해를 입증하고, 일반적인 HTTP 방법을 식별하고, HTML, CSS 및 Javascript가 서로 상호 작용하는 방식을 개괄적으로 설명할 수 있어야 합니다. 마지막으로 라이브러리와 프레임워크의 장점과 단점을 이해하고, 애플리케이션 프로그래밍 인터페이스 또는 API를 식별하고, 애플리케이션 개발에 어떻게 활용되는지 설명하고, IDE 또는 통합 개발 환경의 목적과 이점을 설명할 수 있어야 합니다.
