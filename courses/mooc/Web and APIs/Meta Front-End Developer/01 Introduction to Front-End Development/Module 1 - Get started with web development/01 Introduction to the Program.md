# Introduction to the Program

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/introduction-to-front-end-development/lecture/WFNYK/introduction-to-the-program)

## 개요
- 프론트엔드 개발자 전문 수료증은 는 프론트엔드 개발 직무를 위한 취업 준비 기술을 쌓는 데 도움이 됩니다 자격증을 취득할 수 있습니다.

## 내용
- 프론트엔드 개발자 전문 수료증은 는 프론트엔드 개발 직무를 위한 취업 준비 기술을 쌓는 데 도움이 됩니다 자격증을 취득할 수 있습니다.
- Meta 개발자로부터 협업하는 방법을 배울 수 있습니다 반응형 고성능 웹사이트와 애플리케이션을 만들고 테스트하는 방법을 배우게 됩니다.
- 또한 부트스트랩 프레임워크 사용 방법도 배우게 됩니다 사용법을 배우게 됩니다, 널리 사용되는 자바스크립트 라이브러리로, Meta에서 만들어졌습니다.
- 최종 프로젝트에서는 포트폴리오를 위한 아름다운 전문 웹사이트를 완성할 수 있습니다 인터랙티브한 포트폴리오를 완성하게 됩니다, 구직 활동 중에 선보일 수 있습니다.
- 또한 다른 개발자와 협업할 준비가 되어 있습니다 버전 관리를 위해 Git과 GitHub를 사용하는 방법을 배우게 되므로 다른 개발자와 협업할 준비가 된 것입니다.
- 사용자의 요구 사항을 조사하는 방법을 배우게 됩니다, figma와 같은 업계에서 널리 사용되는 도구를 사용하여 와이어프레임을 만들고, 인터랙티비티를 디자인하는 방법을 배우게 됩니다.
- 프로그램을 완료하면 meta 커리어 프로그램 구인 게시판에 액세스할 수 있습니다, 200개 이상의 고용주와 연결해주는 구직 플랫폼으로 200개 이상의 고용주와 연결되는 구직 플랫폼인 Meta 커리어 프로그램 구인 게시판에 액세스할 수 있습니다.
