# Intro to HTML, CSS and Javascript

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/introduction-to-front-end-development/lecture/RBCdA/intro-to-html-css-and-javascript)

## 개요
- 매일 방문하는 웹 페이지는 HTML, CSS, JavaScript라는 세 가지 핵심 기술을 기반으로 합니다.이 두 가지를 함께 사용하면 웹 페이지와 애플리케이션을 만들어 온라인에서 본 모든 콘텐츠를 제공할 수 있습니다.

## 내용
- 매일 방문하는 웹 페이지는 HTML, CSS, JavaScript라는 세 가지 핵심 기술을 기반으로 합니다.이 두 가지를 함께 사용하면 웹 페이지와 애플리케이션을 만들어 온라인에서 본 모든 콘텐츠를 제공할 수 있습니다.
- 시계 요소를 만들기 위해 먼저 clock.html 파일에 HTML 코드를 정의해 보겠습니다.
- 확인 결과, 동영상이 현재 중지된 경우 동영상 재생이 시작되고 버튼 아이콘이 중지 아이콘으로 변경됩니다.
- 또는 동영상이 현재 재생 중이면 동영상 재생을 중단하고 버튼 아이콘을 재생 아이콘으로 변경합니다.
- 사용자가 재생 버튼을 클릭하면 버튼이 중지 아이콘으로 변경되고 동영상 재생이 시작됩니다.
- 사용자가 버튼을 다시 클릭하면 재생 버튼으로 다시 변경되고 동영상 재생이 중지됩니다.
- CSS 파일은 응용 프로그램의 형식을 지정하고 스타일을 지정하기 위해 호출되며 JavaScript 파일의 코드는 앱의 핵심 기능과 사용자 상호 작용을 구현합니다.

## 예시
- CSS 파일은 응용 프로그램의 형식을 지정하고 스타일을 지정하기 위해 호출되며 JavaScript 파일의 코드는 앱의 핵심 기능과 사용자 상호 작용을 구현합니다.
