# Developer tools

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/introduction-to-front-end-development/lecture/HbGZj/developer-tools)

## 개요
- 개발자는 프런트 엔드가 예상대로 작동하지 않는 경우 후드를 열어 무엇이 잘못되었는지 확인할 수도 있습니다.

## 내용
- 개발자는 프런트 엔드가 예상대로 작동하지 않는 경우 후드를 열어 무엇이 잘못되었는지 확인할 수도 있습니다.
- 대부분의 웹 브라우저에는 개발자가 HTML, CSS 및 Javascript 코드를 검사할 수 있는 개발자 도구 세트가 있습니다.
- 크롬에서 개발자 도구를 열려면 PC의 경우 키보드에서 F12 키를 누르거나 Mac의 경우 명령 옵션 J를 누릅니다.
- 네트워크 탭을 사용하면 웹 페이지에 대한 http 요청 및 응답의 타임라인과 세부 정보를 검사할 수 있습니다.
- 시간이 가장 많이 걸리는 함수를 찾아낼 수 있기 때문에 웹 응용 프로그램이 느리게 실행되는 경우 유용합니다.
- 예를 들어 요소 탭에서 요소를 마우스로 가리키면 브라우저 창에서 해당 요소가 강조 표시됩니다.
- 웹 브라우저 개발자 도구는 문제를 조사하고 진단하는 데 도움이 되는 개발 툴킷의 중요한 부분이며, 이제 이러한 도구에 액세스하고 사용하는 방법을 알게 되었습니다.

## 예시
- 예를 들어 요소 탭에서 요소를 마우스로 가리키면 브라우저 창에서 해당 요소가 강조 표시됩니다.

## 요약
- 예를 들어 요소 탭에서 요소를 마우스로 가리키면 브라우저 창에서 해당 요소가 강조 표시됩니다. 웹 브라우저 개발자 도구는 문제를 조사하고 진단하는 데 도움이 되는 개발 툴킷의 중요한 부분이며, 이제 이러한 도구에 액세스하고 사용하는 방법을 알게 되었습니다.
