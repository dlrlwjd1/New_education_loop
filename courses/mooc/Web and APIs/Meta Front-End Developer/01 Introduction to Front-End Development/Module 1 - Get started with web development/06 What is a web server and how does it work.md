# What is a web server and how does it work?

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/introduction-to-front-end-development/lecture/YbnPy/what-is-a-web-server-and-how-does-it-work)

## 개요
- 서버는 웹 사이트에서 인스턴트 메시징에 이르는 다양한 응용 프로그램과 서비스를 실행하는 컴퓨터입니다.

## 내용
- 서버는 웹 사이트에서 인스턴트 메시징에 이르는 다양한 응용 프로그램과 서비스를 실행하는 컴퓨터입니다.
- 다른 컴퓨터와 클라이언트라고도 하는 해당 사용자에게 서비스를 제공하기 때문에 서버라고 합니다.
- 일반적으로 인터넷에 연결된 서로 다른 서비스를 실행하는 수백 또는 수천 대의 다른 서버가 있는 데이터 센터라는 곳에 저장됩니다.
- 데이터 센터에는 서버에 지속적인 전력과 지속적인 인터넷 연결을 보장하고 하루 24시간 통화 상태를 유지하기 위한 다양한 시스템이 있습니다.
- 많은 웹 사이트에서 이를 사용하여 가장 가까운 데이터 센터에서 콘텐츠에 빠르게 액세스할 수 있습니다.
- 이 점을 기억하기 좋은 한 가지 방법은 하드웨어를 물리적으로 만질 수 있지만 구성 요소를 물리적으로 교체해야 하기 때문에 변경하기 어려운 것으로 생각하는 것입니다.
- 웹 서버에는 웹 사이트 저장 및 관리, 데이터 저장, 보안, 이메일 관리 등 다양한 기능이 있습니다.

## 예시
- 예를 들어 서버를 이미지 저장용으로만 사용하는 경우 하드 드라이브 공간이 많을 수 있습니다.

## 요약
- 이 점을 기억하기 좋은 한 가지 방법은 하드웨어를 물리적으로 만질 수 있지만 구성 요소를 물리적으로 교체해야 하기 때문에 변경하기 어려운 것으로 생각하는 것입니다. 웹 서버에는 웹 사이트 저장 및 관리, 데이터 저장, 보안, 이메일 관리 등 다양한 기능이 있습니다.
