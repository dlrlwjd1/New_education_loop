# Introduction to Internet Protocols

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/introduction-to-front-end-development/lecture/NGJ4k/introduction-to-internet-protocols)

## 개요
- 우편 시스템과 컴퓨터가 매일 인터넷을 통해 데이터를 보내고 받는 방식 사이에는 놀라운 유사점이 있습니다.

## 내용
- 우편 시스템과 컴퓨터가 매일 인터넷을 통해 데이터를 보내고 받는 방식 사이에는 놀라운 유사점이 있습니다.
- 인터넷을 통해 전송되는 데이터는 일상 생활에서 매우 중요한 부분이며 인터넷 프로토콜 주소나 IP 주소 없이는 불가능합니다.
- 이 비디오에서는 IP 주소가 무엇인지 알아보고 컴퓨터가 인터넷을 통해 데이터를 보내는 방법을 살펴보겠습니다.
- 이전에 컴퓨터가 서로 연결되어 네트워크를 형성하는 방법과 이러한 네트워크가 서로 연결되어 인터넷을 구성하는 방법을 배웠습니다.
- 인터넷을 통해 컴퓨터 간에 데이터를 전송할 때 일반적으로 컴퓨터는 데이터를 요청하고 받는 대상이고 네트워크는 데이터가 이동하는 경로라는 것입니다.
- 이 프로토콜은 음성 통화 또는 라이브 비디오 스트리밍과 같은 일부 데이터 손실을 견딜 수 있는 데이터를 전송하는 데 사용됩니다.
- 이러한 프로토콜은 데이터가 정상적으로 도착하고 전송 중에 손상되거나 손실되거나 손실되지 않도록 하는 데 도움이 될 수 있습니다.

## 예시
- 이러한 프로토콜은 데이터가 정상적으로 도착하고 전송 중에 손상되거나 손실되거나 손실되지 않도록 하는 데 도움이 될 수 있습니다.

## 요약
- 이 프로토콜은 음성 통화 또는 라이브 비디오 스트리밍과 같은 일부 데이터 손실을 견딜 수 있는 데이터를 전송하는 데 사용됩니다. 이러한 프로토콜은 데이터가 정상적으로 도착하고 전송 중에 손상되거나 손실되거나 손실되지 않도록 하는 데 도움이 될 수 있습니다.
