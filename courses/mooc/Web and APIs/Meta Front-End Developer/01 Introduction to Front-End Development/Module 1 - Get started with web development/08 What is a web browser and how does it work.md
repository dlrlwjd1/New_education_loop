# What is a web browser and how does it work?

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/introduction-to-front-end-development/lecture/ofA9j/what-is-a-web-browser-and-how-does-it-work)

## 개요
- 웹 서버에 요청을 보낸 다음 장치 화면에 표시될 콘텐츠가 포함된 응답을 받는 방식으로 작동합니다.

## 내용
- 웹 서버에 요청을 보낸 다음 장치 화면에 표시될 콘텐츠가 포함된 응답을 받는 방식으로 작동합니다.
- URL에는 프로토콜 또는 HTTP, 도메인 이름 ( 일반적으로 웹 사이트 이름), 파일 경로 또는 표시되는 페이지 경로가 포함됩니다.
- 그런 다음 Enter 키를 누르면 웹 브라우저가 네트워크를 통해 요청을 보내고 인터넷상의 다른 컴퓨터 (웹 서버) 에 연결합니다.
- 이제 검색 엔진 웹 페이지가 브라우저에 로드되었으므로 해당 페이지와 상호 작용하여 찾으려는 내용을 검색할 수 있습니다.
- 다시 한 번 브라우저가 요청을 준비하여 동일한 검색 엔진 웹 서버로 보냅니다.
- 검색 엔진 웹 서버는 키워드를 가져와 요청된 데이터를 찾는 데 사용하는 방식으로 요청을 처리합니다.
- 웹 브라우저가 웹 서버로부터 전체 응답을 받으면 일부 레스토랑으로 연결되는 링크, 주변 위치, 리뷰, 목록, 예약과 같은 추가 관련 정보가 표시된 지도가 있는 가시적인 웹 페이지를 다시 렌더링합니다.

## 예시
- 예를 들어 검색 창에 주변 레스토랑을 입력하고 검색 버튼을 누릅니다.

## 요약
- 검색 엔진 웹 서버는 키워드를 가져와 요청된 데이터를 찾는 데 사용하는 방식으로 요청을 처리합니다. 웹 브라우저가 웹 서버로부터 전체 응답을 받으면 일부 레스토랑으로 연결되는 링크, 주변 위치, 리뷰, 목록, 예약과 같은 추가 관련 정보가 표시된 지도가 있는 가시적인 웹 페이지를 다시 렌더링합니다.
