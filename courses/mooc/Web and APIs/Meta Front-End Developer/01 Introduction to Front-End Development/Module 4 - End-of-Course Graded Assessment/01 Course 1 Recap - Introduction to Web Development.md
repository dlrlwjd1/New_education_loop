# Course 1 Recap: Introduction to Web Development

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/introduction-to-front-end-development/lecture/F7iPe/course-1-recap-introduction-to-web-development)

## 개요
- 다음으로 웹 페이지, 웹 서버, 웹 브라우저에 대해 더 알아보고, 이 모든 것이 어떻게 함께 작동하여 우리가 인터넷이라고 부르는 것을 만드는지에 대해 배웠습니다.

## 내용
- 다음으로 웹 페이지, 웹 서버, 웹 브라우저에 대해 더 알아보고, 이 모든 것이 어떻게 함께 작동하여 우리가 인터넷이라고 부르는 것을 만드는지에 대해 배웠습니다.
- 온라인에서 무언가를 검색해 달라는 요청을 보내면 어떤 일이 벌어지는지, 그리고 그 정보가 어떻게 돌아오는지에 대해 다루었습니다.
- HTML에서 HTML 문서를 만들고, 간단한 HTML 태그와 연결된 문서를 사용하여 웹 사이트를 만드는 방법을 배웠습니다.
- 그런 다음 문서 객체 모델 또는 DOM에 대해 알아보고, DOM을 사용하여 디바이스에 표시되는 내용을 표시하는 방법을 배웠습니다.
- 요소를 선택하고 스타일을 지정하고 텍스트, 색상 및 정렬을 사용하여 만든 웹 페이지를 멋지게 만들고 뛰어난 사용자 경험을 제공하는 방법을 살펴보았습니다.
- 모듈 3에서는 Bootstrap 프레임워크를 사용하여 반응형 인터페이스를 구축하는 방법을 배우고 UI 프레임워크를 사용하여 얻을 수 있는 이점에 대해 알아보았습니다.
- 그런 다음 Bootstrap 라이브러리를 시작하는 방법과 Bootstrap 스타일을 사용하는 방법을 배우고 몇 가지 대체 UI 프레임워크 및 라이브러리를 살펴보았습니다.

## 예시
- 그런 다음 Bootstrap 라이브러리를 시작하는 방법과 Bootstrap 스타일을 사용하는 방법을 배우고 몇 가지 대체 UI 프레임워크 및 라이브러리를 살펴보았습니다.

## 요약
- 모듈 3에서는 Bootstrap 프레임워크를 사용하여 반응형 인터페이스를 구축하는 방법을 배우고 UI 프레임워크를 사용하여 얻을 수 있는 이점에 대해 알아보았습니다. 그런 다음 Bootstrap 라이브러리를 시작하는 방법과 Bootstrap 스타일을 사용하는 방법을 배우고 몇 가지 대체 UI 프레임워크 및 라이브러리를 살펴보았습니다.
