# Congratulations, you have completed Introduction to Web Development

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/introduction-to-front-end-development/lecture/eI6P3/congratulations-you-have-completed-introduction-to-web-development)

## 개요
- 이제 기반이 되는 프론트엔드 웹 개발 기술에 대한 훌륭한 기반을 갖추게 될 것입니다.

## 내용
- 이제 기반이 되는 프론트엔드 웹 개발 기술에 대한 훌륭한 기반을 갖추게 될 것입니다.
- 첫 번째 과정을 마치면 이제 웹 개발자의 직무 역할을 설명하고, 프론트엔드 개발자와 백엔드 개발자와 풀스택 개발자를 구분하고, 인터넷을 통해 데이터가 이동하는 방식을 설명하고, 인터넷을 뒷받침하는 기술을 설명할 수 있습니다.
- 실습에서 측정한 주요 기술은 HTML을 사용하여 간단한 웹 페이지를 만들고, CSS를 사용하여 간단한 웹 페이지의 스타일을 정의하고, Bootstrap을 예로 들어 대부분의 UI 프레임워크에 존재하는 개념을 간략하게 설명하여 일반적인 관행을 직접 참조하는 능력을 보여주었습니다.
- 또한 이제 Bootstrap 설명서를 사용하여 CSS 구성 요소를 재생산 및 수정하고, Bootstrap 테마를 사용하여 워크플로 속도를 높이고, 다른 프레임워크 및 웹 기술과 관련된 React의 기본 사항을 설명할 수 있습니다.
- 최종 평가에서는 지금까지 배운 모든 기술을 한데 모아 완전한 기능을 갖춘 자신만의 웹사이트를 만들게 됩니다.
- 포트폴리오에 포함시켜 잠재적 고용주에게 여러분의 기술을 보여줄 수 있는 기능적인 웹사이트를 갖게 될 것입니다.
- 이 전문가 자격증의 모든 과정을 완료하면 Meta 프론트엔드 개발자를 위한 MOOC 인증을 받게 됩니다.

## 예시
