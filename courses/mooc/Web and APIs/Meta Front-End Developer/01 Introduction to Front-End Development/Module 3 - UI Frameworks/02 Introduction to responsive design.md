# Introduction to responsive design

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/introduction-to-front-end-development/lecture/sXqzv/introduction-to-responsive-design)

## 개요
- CSS 미디어 쿼리와 화면 해상도를 설명하고, 유동 이미지를 분류하고, 고정 그리드와 유동 그리드를 구분하세요.

## 내용
- CSS 미디어 쿼리와 화면 해상도를 설명하고, 유동 이미지를 분류하고, 고정 그리드와 유동 그리드를 구분하세요.
- 휴대폰, 태블릿, 컴퓨터 화면 등 여러분이 지금 사용하고 있는 화면도 포함되며 픽셀이라고 하는 수천 개의 작은 조명으로 이루어져 있습니다.
- 화면 해상도는 화면에 포함된 픽셀 수를 말하며, 대부분 가로 픽셀 수에 세로 픽셀 수를 곱한 값으로 표현됩니다.
- 유연한 그리드는 픽셀을 기반으로 웹 사이트 요소 크기를 정의하는 대신 백분율 값으로 정의되므로 화면 크기에 따라 조정할 수 있습니다.
- 이러한 요소를 함께 사용하면 기기에 따라 레이아웃이 자동으로 조정되어 반응형 그리드를 제공하는 웹 사이트를 만들 수 있습니다.
- 플루이드 그리드는 화면 크기에 따라 가장자리에서 끝까지 이어지는 유연한 콘텐츠를 제공합니다 유동 그리드에서는 사용 가능한 공간에 맞게 기둥이 늘어나거나 줄어듭니다.
- 많은 반응형 디자인 프레임워크는 최상의 시각적 경험을 제공하기 위해 다양한 장치 크기를 기반으로 여러 CSS 규칙을 제공합니다.

## 예시
- 예를 들어 일반적인 컴퓨터 화면 해상도는 너비 1920픽셀, 높이 1080픽셀입니다.

## 요약
- 플루이드 그리드는 화면 크기에 따라 가장자리에서 끝까지 이어지는 유연한 콘텐츠를 제공합니다 유동 그리드에서는 사용 가능한 공간에 맞게 기둥이 늘어나거나 줄어듭니다. 많은 반응형 디자인 프레임워크는 최상의 시각적 경험을 제공하기 위해 다양한 장치 크기를 기반으로 여러 CSS 규칙을 제공합니다.
