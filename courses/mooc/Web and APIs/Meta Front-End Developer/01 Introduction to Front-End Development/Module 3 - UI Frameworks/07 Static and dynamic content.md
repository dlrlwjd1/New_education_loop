# Static and dynamic content

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/introduction-to-front-end-development/lecture/FOtll/static-and-dynamic-content)

## 개요
- 이제 웹 사이트를 열면 웹 서버가 웹 사이트의 콘텐츠를 브라우저로 전송한다는 것을 알고 계실 것입니다.

## 내용
- 이제 웹 사이트를 열면 웹 서버가 웹 사이트의 콘텐츠를 브라우저로 전송한다는 것을 알고 계실 것입니다.
- 예를 들어 콘텐츠는 사용자의 입력을 기반으로 생성되거나 뉴스 웹 사이트를 방문할 때 현재 날짜를 기반으로 생성될 수 있습니다.
- 애플리케이션 서버는 웹 서버가 사용자의 브라우저로 다시 보내는 동적 콘텐츠를 생성합니다.
- 동적 콘텐츠는 웹 사이트를 사용하는 동안 생성되므로 일반적으로 정적 콘텐츠를 다시 보내는 데 걸리는 시간보다 생성하는 데 더 오래 걸립니다.
- 예를 들어, 이 강좌에 로그인하면 웹 서버가 애플리케이션 서버와 통신하여 사용자가 실제로 등록되었는지 확인합니다.
- 콘텐츠가 다시 요청되는 경우 웹 서버는 요청을 애플리케이션 서버에 다시 전달하는 대신 이 캐시된 버전을 즉시 보낼 수 있습니다.
- 이제 정적 콘텐츠와 동적 콘텐츠의 차이점과 웹 서버와 애플리케이션 서버 간의 차이를 알게 되었습니다.

## 예시
- 예를 들어 콘텐츠는 사용자의 입력을 기반으로 생성되거나 뉴스 웹 사이트를 방문할 때 현재 날짜를 기반으로 생성될 수 있습니다.

## 요약
- 콘텐츠가 다시 요청되는 경우 웹 서버는 요청을 애플리케이션 서버에 다시 전달하는 대신 이 캐시된 버전을 즉시 보낼 수 있습니다. 이제 정적 콘텐츠와 동적 콘텐츠의 차이점과 웹 서버와 애플리케이션 서버 간의 차이를 알게 되었습니다.
