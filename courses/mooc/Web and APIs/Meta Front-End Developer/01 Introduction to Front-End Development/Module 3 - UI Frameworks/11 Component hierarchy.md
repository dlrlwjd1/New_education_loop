# Component hierarchy

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/introduction-to-front-end-development/lecture/Z2fLi/component-hierarchy)

## 개요
- 우리는 이미 핵심 인터넷 기술에 대해 배웠고 이제 React의 JavaScript 라이브러리를 사용하면 사용자 인터페이스를 훨씬 빠르게 개발할 수 있다는 것을 알게 되었습니다.

## 내용
- 우리는 이미 핵심 인터넷 기술에 대해 배웠고 이제 React의 JavaScript 라이브러리를 사용하면 사용자 인터페이스를 훨씬 빠르게 개발할 수 있다는 것을 알게 되었습니다.
- 쇼핑 목록 구성 요소에는 쇼핑 목록의 각 항목에 대한 하위 구성 요소인 쇼핑 품목이 포함됩니다.
- 사용자가 품목을 제거하면 목록이 업데이트되어 쇼핑 목록 구성 요소에서 해당 쇼핑 품목 하위 구성 요소가 제거됩니다.
- 앱 구성 요소에는 두 개의 하위 구성 요소, 즉 탐색 막대용 Navbar 구성 요소와 페이지 구성 요소가 있습니다.
- 기본 기능 구성 요소와 작은 기능 구성 요소의 두 인스턴스 주요 기능 구성 요소에는 특정 블로그 게시물에 대한 블로그 요약이 표시됩니다.
- 작은 기능 구성 요소에는 블로그 요약과 블로그 게시물과 관련된 이미지를 표시하는 썸네일 구성 요소가 있습니다.
- 일련의 컴포넌트를 사용하여 애플리케이션을 빌드하는 것은 처음에는 까다로울 수 있지만, 몇 번 해보면 얼마나 편리한지 알게 될 것입니다.React에서 컴포넌트 계층 구조를 계획하는 데 행운을 빕니다.

## 예시
- 일련의 컴포넌트를 사용하여 애플리케이션을 빌드하는 것은 처음에는 까다로울 수 있지만, 몇 번 해보면 얼마나 편리한지 알게 될 것입니다.React에서 컴포넌트 계층 구조를 계획하는 데 행운을 빕니다.

## 요약
- 작은 기능 구성 요소에는 블로그 요약과 블로그 게시물과 관련된 이미지를 표시하는 썸네일 구성 요소가 있습니다. 일련의 컴포넌트를 사용하여 애플리케이션을 빌드하는 것은 처음에는 까다로울 수 있지만, 몇 번 해보면 얼마나 편리한지 알게 될 것입니다.React에서 컴포넌트 계층 구조를 계획하는 데 행운을 빕니다.
