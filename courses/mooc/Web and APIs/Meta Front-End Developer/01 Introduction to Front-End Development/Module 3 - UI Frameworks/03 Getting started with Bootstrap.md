# Getting started with Bootstrap

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/introduction-to-front-end-development/lecture/ov6pv/getting-started-with-bootstrap)

## 개요
- 먼저 메뉴 H1 태그 아래에 제목 2 태그를 추가하고 그 안에 요리 이름인 팔라펠을 추가합니다.

## 내용
- 먼저 메뉴 H1 태그 아래에 제목 2 태그를 추가하고 그 안에 요리 이름인 팔라펠을 추가합니다.
- 이제 팔라펠 이미지를 추가하기 위해 IMG 또는 이미지 태그를 추가하고 그 안에 알려진 대로 SRC 또는 소스 속성을 추가합니다.
- IMG-Fluid 클래스를 사용하면 이미지 크기를 수동으로 설정하는 대신 이미지 크기를 상위 열의 너비로 조정할 수 있습니다.
- 제목 2 또는 H2 태그를 하나 더 추가하고 그 안에 요리 파스타 샐러드의 이름을 추가합니다.
- 파스타 샐러드 H2 태그 아래에 단락 태그 또는 p 태그를 추가하고 재료, 양상추, 야채, 모짜렐라 치즈를 나열합니다.
- 이제 Control 키와 S 키를 눌러 파일을 저장하거나 Mac Command 및 S 키를 사용하는 경우 파일을 저장합니다.
- HTML 테이블 태그 안에 두 개의 테이블 행 태그 또는 tr 태그를 추가합니다.

## 예시
- HTML 테이블 태그 안에 두 개의 테이블 행 태그 또는 tr 태그를 추가합니다.

## 요약
- 이제 Control 키와 S 키를 눌러 파일을 저장하거나 Mac Command 및 S 키를 사용하는 경우 파일을 저장합니다. HTML 테이블 태그 안에 두 개의 테이블 행 태그 또는 tr 태그를 추가합니다.
