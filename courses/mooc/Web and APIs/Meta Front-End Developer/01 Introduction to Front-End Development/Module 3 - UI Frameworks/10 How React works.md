# How React works

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/introduction-to-front-end-development/lecture/YqQH9/how-react-works)

## 개요
- 지금까지 React에서 컴포넌트를 빌드하여 사용자 인터페이스를 개발할 수 있다는 것을 배웠습니다.

## 내용
- 지금까지 React에서 컴포넌트를 빌드하여 사용자 인터페이스를 개발할 수 있다는 것을 배웠습니다.
- 웹 브라우저가 HTML 페이지를 수신하면 해당 페이지를 나타내는 DOM을 구성한다는 점을 기억하세요.
- 브라우저 DOM이 업데이트될 때마다 브라우저가 페이지를 다시 계산하게 됩니다.
- 이 비디오에서는 React가 자체 가상 DOM을 계산하여 문제를 해결하는 방법을 설명하겠습니다.먼저 React 컴포넌트가 브라우저에 표시된 웹 사이트와 어떤 관련이 있는지부터 살펴보겠습니다.
- React는 가상 DOM의 HTML 구성 요소가 브라우저 DOM과 일치하는지 확인합니다.
- 그런 다음 React는 가상 DOM을 이전 버전의 가상 DOM과 비교하고 어떤 요소가 변경되었는지 확인합니다.
- 브라우저가 전체 페이지를 다시 만드는 대신 특정 HTML 요소만 업데이트하도록 하기 위해서입니다.

## 예시
- 브라우저가 전체 페이지를 다시 만드는 대신 특정 HTML 요소만 업데이트하도록 하기 위해서입니다.

## 요약
- 그런 다음 React는 가상 DOM을 이전 버전의 가상 DOM과 비교하고 어떤 요소가 변경되었는지 확인합니다. 브라우저가 전체 페이지를 다시 만드는 대신 특정 HTML 요소만 업데이트하도록 하기 위해서입니다.
