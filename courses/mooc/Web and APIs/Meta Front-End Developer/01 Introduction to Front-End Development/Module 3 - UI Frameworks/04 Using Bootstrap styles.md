# Using Bootstrap styles

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/introduction-to-front-end-development/lecture/ETatJ/using-bootstrap-styles)

## 개요
- 이제 수정 사항이 어떻게 사용되는지 살펴보도록 하겠습니다.장치 또는 뷰포인트 크기에 따라 레이아웃이 변경되는 방식을 결정하는 부트스트랩의 트리거가 중단점이라는 것을 이미 알고 계실 것입니다.

## 내용
- 이제 수정 사항이 어떻게 사용되는지 살펴보도록 하겠습니다.장치 또는 뷰포인트 크기에 따라 레이아웃이 변경되는 방식을 결정하는 부트스트랩의 트리거가 중단점이라는 것을 이미 알고 계실 것입니다.
- 기본, 보조, 성공, 정보, 경고, 위험, 밝음, 어두움 경고는 경고, 오류 또는 확인 메시지와 같이 사용자의 즉각적인 주의가 필요한 정보를 표시하는 데 주로 사용됩니다.
- Bootstrap을 사용하면 미리 정의된 경고 메시지를 쉽게 만들 수 있으며 다양한 유형의 경고도 있습니다.
- 예를 들어 기본 알림은 부트스트랩의 기본 색상인 파란색을 사용하여 경고를 표시합니다.
- 알림 CSS 클래스를 추가하고 컨텍스트 클래스인 alert dash primary 클래스를 추가하면 이 작업을 수행할 수 있습니다.
- 이를 위해 컨텍스트 클래스 바로 뒤에 roll CSS 클래스를 추가하고 경고 대시 프라이머리와 타이핑 얼러트를 추가합니다.
- 컨텍스트 클래스인 alert primary 클래스는 Bootstrap 기본 색상인 파란색을 사용하여 경고를 표시합니다.

## 예시
- Bootstrap에는 Bootstrap 개발자가 수천 개의 사용 사례를 사용하여 구축한 상당히 큰 CSS 라이브러리가 있습니다.

## 요약
- 이를 위해 컨텍스트 클래스 바로 뒤에 roll CSS 클래스를 추가하고 경고 대시 프라이머리와 타이핑 얼러트를 추가합니다. 컨텍스트 클래스인 alert primary 클래스는 Bootstrap 기본 색상인 파란색을 사용하여 경고를 표시합니다.
