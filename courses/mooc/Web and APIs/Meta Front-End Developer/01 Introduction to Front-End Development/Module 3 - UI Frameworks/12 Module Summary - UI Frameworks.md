# Module Summary: UI Frameworks

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/introduction-to-front-end-development/lecture/KTvyj/module-summary-ui-frameworks)

## 개요
- 이 모듈을 통해 UI 프레임워크와 라이브러리의 개념을 살펴보고 React에 대한 소개를 다뤘습니다.지금까지 배운 핵심 포인트와 습득한 기술을 다시 정리해 보겠습니다.

## 내용
- 이 모듈을 통해 UI 프레임워크와 라이브러리의 개념을 살펴보고 React에 대한 소개를 다뤘습니다.지금까지 배운 핵심 포인트와 습득한 기술을 다시 정리해 보겠습니다.
- 이 첫 번째 강의를 마치면 이제 CSS 및 JavaScript 라이브러리를 활용하고 종속성, 패키지 관리자 및 JavaScript 번들러에 대한 높은 수준의 이해를 입증하고 화면 해상도, 고정 및 유동 그리드와 같은 반응형 웹 디자인의 주요 기법 및 개념을 설명할 수 있을 것입니다.
- Bootstrap 그리드를 사용하여 웹 페이지를 구축함으로써 반응형 중단점 및 클래스 수정자를 수정하여 CSS 코드를 변경하고 Bootstrap의 그리드 시스템에 대한 이해를 입증하는 등 Bootstrap CSS 라이브러리를 활용하십시오.
- UI 프레임워크와 라이브러리를 살펴본 다음에는 사용자 인터페이스 구축을 위한 React와 JavaScript 라이브러리를 소개했습니다.
- 이제 react에 대한 소개를 마쳤으니, 정적 웹 페이지 콘텐츠와 동적 웹 페이지 콘텐츠를 구분할 수 있을 것입니다.
- 또한 JavaScript 라이브러리로서 React의 용도를 간략하게 설명하고, React 구성 요소 모델의 개념을 설명하고, 일반적인 구성 요소의 예를 식별할 수 있어야 합니다.
- React 컴포넌트에 대한 높은 수준의 이해를 보여주고, 가상 DOM을 통해 웹 페이지를 생성하기 위해 React 컴포넌트가 계층 구조로 작동하는 방식을 설명하세요.

## 예시
