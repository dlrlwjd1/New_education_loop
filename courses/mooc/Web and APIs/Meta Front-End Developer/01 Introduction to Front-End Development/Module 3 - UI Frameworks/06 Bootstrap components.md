# Bootstrap components

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/introduction-to-front-end-development/lecture/xIhP5/bootstrap-components)

## 개요
- 이를 위해 메뉴 열에 새 h2 태그를 추가하고 그 안에 Fried Calamari라는 요리 이름을 추가합니다.

## 내용
- 이를 위해 메뉴 열에 새 h2 태그를 추가하고 그 안에 Fried Calamari라는 요리 이름을 추가합니다.
- 그래서 소스 속성과 함께 이미지 파일 이름이 calamari.jpeg 인 이미지 태그를 사용했습니다.
- Bootstrap에는 이 요리가 새롭다는 것을 강조하기 위해 사용할 수 있는 배지 구성 요소가 포함되어 있습니다 .이제 추가해 보겠습니다.
- 카드 요소를 사용하여 제목의 자막, 본문, 카드 이미지 등 다양한 유형의 콘텐츠를 스타일링하고 수용할 수 있습니다.
- 그런 다음 각 요리의 이미지 태그가 있는 코드를 카드 클래스로 옮기세요.
- 다시 한 번 비주얼 스타일을 개선하기 위해 각 요리의 헤더에 카드 제목 css 클래스를 추가합니다.
- Bootstrap에는 많은 구성 요소가 있습니다.웹 사이트를 개선하는 데 사용할 수 있는 몇 가지 방법이 더 있을 수도 있습니다.

## 예시
- Bootstrap에는 많은 구성 요소가 있습니다.웹 사이트를 개선하는 데 사용할 수 있는 몇 가지 방법이 더 있을 수도 있습니다.

## 요약
- 다시 한 번 비주얼 스타일을 개선하기 위해 각 요리의 헤더에 카드 제목 css 클래스를 추가합니다. Bootstrap에는 많은 구성 요소가 있습니다.웹 사이트를 개선하는 데 사용할 수 있는 몇 가지 방법이 더 있을 수도 있습니다.
