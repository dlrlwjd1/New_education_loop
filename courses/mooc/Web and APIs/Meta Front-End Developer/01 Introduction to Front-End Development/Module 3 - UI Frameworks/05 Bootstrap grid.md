# Bootstrap grid

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/introduction-to-front-end-development/lecture/JcTk4/bootstrap-grid)

## 개요
- 앞서 배웠듯이 반응형 디자인을 사용하여 웹 사이트를 구축하려면 반응형 그리드와 반응형 중단점이 필요합니다.

## 내용
- 앞서 배웠듯이 반응형 디자인을 사용하여 웹 사이트를 구축하려면 반응형 그리드와 반응형 중단점이 필요합니다.
- 부트스트랩 그리드 시스템을 사용하면 콘텐츠가 들어 있는 일련의 행과 열을 통해 웹 페이지 레이아웃을 만들 수 있습니다.
- 가격 열을 네 칸으로 줄이고 메뉴 열을 여덟 칸으로 확장해 보겠습니다.
- 중단점별 CSS 규칙을 사용하여 디바이스에 따라 다른 레이아웃을 사용하도록 콘텐츠를 구성할 수 있습니다.
- 모바일 디바이스의 경우 두 열의 석탄 규칙에 접미사로 12를 추가하여 각 열에 12개의 공백을 사용하도록 설정하겠습니다.
- 그런 다음 데스크톱의 경우 cold- LG 규칙을 사용하고 열 sizes-6을 접미사로 추가하여 각 열을 6개 열로 설정하겠습니다.
- 이렇게 하면 장치별로 다른 콘텐츠 레이아웃을 개발할 필요가 없으므로 개발 시간을 크게 절약할 수 있습니다.

## 예시
- 이렇게 하면 장치별로 다른 콘텐츠 레이아웃을 개발할 필요가 없으므로 개발 시간을 크게 절약할 수 있습니다.

## 요약
