# Working with libraries

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/introduction-to-front-end-development/lecture/a9U1t/working-with-libraries)

## 개요
- 다양한 재료, 다른 조리 시간을 시도해 볼 수도 있고 인터넷에서 찾은 레시피를 사용할 수도 있습니다.

## 내용
- 다양한 재료, 다른 조리 시간을 시도해 볼 수도 있고 인터넷에서 찾은 레시피를 사용할 수도 있습니다.
- 이 비디오에서는 HTML 파일에 CSS 및 JavaScript 라이브러리를 포함하는 방법을 설명하겠습니다.
- 또한 종속성이 무엇인지, 패키지 관리자와 JavaScript 핸들러의 용도에 대해서도 설명하겠습니다.시작해 봅시다.
- 하지만 지금은 Bootstrap과 같은 라이브러리를 웹 페이지에 포함할 수 있는 방법을 보여 드리겠습니다.
- 또한 부트스트랩은 드롭다운 및 툴팁과 같은 향상된 기능을 사용할 수 있는 JavaScript 라이브러리를 제공합니다.개발 중에 이러한 기능이 필요할 수 있습니다.
- 또한 btn 대시 프라이머리라는 수정자와 설명을 추가합니다.이 버튼을 클릭하세요.그러면 웹 페이지에 Bootstrap의 기본 색상인 파란색을 사용하는 버튼이 추가됩니다.
- 종속성이 무엇인지, 패키지 관리자의 용도가 무엇인지, JavaScript 번들이 무엇인지도 알 수 있습니다.

## 예시
- 예를 들어 종속성이 다른 라이브러리와 프레임워크에도 의존한다면 어떻게 될까요?
