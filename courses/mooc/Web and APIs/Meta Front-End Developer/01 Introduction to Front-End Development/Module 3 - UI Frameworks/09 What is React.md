# What is React?

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/introduction-to-front-end-development/lecture/TgGHl/what-is-react)

## 개요
- 그리고 React는 가장 인기 있는 JavaScript 라이브러리 중 하나이기 때문에, React의 용도를 설명하고 컴포넌트가 함께 작동하는 방식을 설명하는 것이 중요합니다.

## 내용
- 그리고 React는 가장 인기 있는 JavaScript 라이브러리 중 하나이기 때문에, React의 용도를 설명하고 컴포넌트가 함께 작동하는 방식을 설명하는 것이 중요합니다.
- 개발자는 React를 사용하여 단일 페이지 애플리케이션을 개발하고, React 네이티브로 모바일 애플리케이션을 개발할 수도 있습니다.
- 이 구성 요소 모델을 사용하면 응용 프로그램의 일부를 개별적으로 개발하고 테스트하는 등 여러 작업을 수행할 수 있으며 응용 프로그램의 여러 섹션에서 구성 요소를 재사용할 수도 있습니다.
- 일반적으로 응용 프로그램의 여러 부분에서 이 프로필 사진의 버전을 사용합니다 ( 예: 사용자 이름 옆의 탐색 표시줄).
- 또한 다른 여러 사용자 사진과 함께 사용자 검색 결과에 표시될 수 있으며 사용자 사진에 인스턴트 메시지 알림이 표시될 수도 있습니다.
- 사용자 프로필 사진의 모든 인스턴스에 대한 로직을 프로그래밍하는 대신 React를 사용하면 프로필 사진을 사용할 때마다 프로필 사진 버전을 표시하는 사용자 아이콘 컴포넌트를 만들 수 있습니다.
- 가까운 장래에 여러분이 적극적인 회원으로 React 커뮤니티에 가입하고 미래의 React 커뮤니티 구성원이 되어 React 라이브러리의 목적과 컴포넌트가 어떻게 함께 작동하여 프론트엔드 개발자의 삶을 더 쉽게 만드는지 알게 되었으면 좋겠습니다.

## 예시
- 예를 들어, 웹사이트에 비디오 플레이어를 추가하려는 경우 이를 위한 React 컴포넌트 라이브러리가 있습니다.

## 요약
- 사용자 프로필 사진의 모든 인스턴스에 대한 로직을 프로그래밍하는 대신 React를 사용하면 프로필 사진을 사용할 때마다 프로필 사진 버전을 표시하는 사용자 아이콘 컴포넌트를 만들 수 있습니다. 가까운 장래에 여러분이 적극적인 회원으로 React 커뮤니티에 가입하고 미래의 React 커뮤니티 구성원이 되어 React 라이브러리의 목적과 컴포넌트가 어떻게 함께 작동하여 프론트엔드 개발자의 삶을 더 쉽게 만드는지 알게 되었으면 좋겠습니다.
