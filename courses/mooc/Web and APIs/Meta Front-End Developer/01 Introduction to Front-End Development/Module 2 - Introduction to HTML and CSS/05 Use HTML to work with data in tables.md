# Use HTML to work with data in tables

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/introduction-to-front-end-development/lecture/OpD7S/use-html-to-work-with-data-in-tables)

## 개요
- 가격표와 같은 정보를 추가하는 가장 좋은 방법은 HTML 표를 사용하는 것입니다.

## 내용
- 가격표와 같은 정보를 추가하는 가장 좋은 방법은 HTML 표를 사용하는 것입니다.
- 이 비디오에서는 리틀 레몬 가격을 나타내는 심볼 테이블을 만드는 방법을 보여 드리겠습니다.
- 이제 가격을 포함할 수 있도록 테이블 데이터 태그 또는 td 태그를 추가해야 합니다.
- 첫 번째 행에서는 첫 번째 테이블 데이터 태그 안에 Falafel을 입력합니다.
- 첫 번째 테이블 데이터 태그에는 파스타 샐러드를 입력하고 두 번째 테이블 데이터 태그에는 12달러의 가격을 입력합니다.
- 이를 위해 테이블 행 태그를 사용하여 테이블 상단에 새 행을 추가합니다.
- 첫 번째 열 제목에는 요리를 입력하고 두 번째 제목에는 가격을 입력합니다.

## 예시
- 나중에 CSS 모범 사례를 사용하여 이 작업을 수행하는 방법을 배우게 됩니다.

## 요약
- 이를 위해 테이블 행 태그를 사용하여 테이블 상단에 새 행을 추가합니다. 첫 번째 열 제목에는 요리를 입력하고 두 번째 제목에는 가격을 입력합니다.
