# What are forms?

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/introduction-to-front-end-development/lecture/HzSRF/what-are-forms)

## 개요
- 하지만 온라인 쇼핑을 가능하게 하는 기능 중 하나가 HTML 양식이라는 사실을 알고 계셨나요?이 기능이 없으면 결제 시 신용 카드 세부 정보를 입력할 수 없습니다.

## 내용
- 하지만 온라인 쇼핑을 가능하게 하는 기능 중 하나가 HTML 양식이라는 사실을 알고 계셨나요?이 기능이 없으면 결제 시 신용 카드 세부 정보를 입력할 수 없습니다.
- 간단히 말해서 사용자가 웹 사이트에 데이터를 입력할 때 HTML 양식은 데이터가 포함된 HTTP 요청을 서버에 제출합니다.
- FORM 메서드도 있으며, FORM 메서드를 사용하여 HTTP 요청에 사용할 HTTP 메서드를 지정할 수 있습니다.
- 하지만 텍스트 상자 자체는 그다지 사용자 친화적이지 않으므로 이제 텍스트 상자 위에 레이블을 추가하겠습니다.
- 레이블 태그를 사용하여 입력 유형의 레이블을 만들 수 있으며, 텍스트 입력에는 사용자 이름과 같은 텍스트 입력 유형을 사용할 수 있습니다.
- 사용자가 여러 줄의 텍스트를 입력할 수 있게 하려면 텍스트 입력 유형 대신 텍스트 영역 태그를 사용해야 합니다.
- 입력 태그를 사용하지 않는 또 다른 입력 유형은 사용자가 선택할 수 있는 항목이 포함된 드롭다운 목록입니다.

## 예시
- 입력 태그를 사용하지 않는 또 다른 입력 유형은 사용자가 선택할 수 있는 항목이 포함된 드롭다운 목록입니다.

## 요약
