# Document flow - Block vs. In-line

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/introduction-to-front-end-development/lecture/mX2z2/document-flow-block-vs-in-line)

## 개요
- 이제 CSS가 개별 html 요소의 스타일을 지정하는 방법을 배웠지만 웹 브라우저가 화면에 요소를 배치하지 않는 이유는 무엇입니까?

## 내용
- 이제 CSS가 개별 html 요소의 스타일을 지정하는 방법을 배웠지만 웹 브라우저가 화면에 요소를 배치하지 않는 이유는 무엇입니까?
- 웹 브라우저가 화면에서 html 요소의 위치를 계산하는 일반적인 방법을 문서 흐름이라고 합니다.
- 기본적으로 거의 모든 html 요소는 블록 및 라인 요소의 두 범주 중 하나로 구성됩니다.
- 블록 레벨 요소는 상위 요소의 전체 가로 너비와 콘텐츠의 세로 높이를 차지합니다.
- html로 코딩할 때는 블록 요소를 인식하고 사용할 수 있어야 합니다.
- 이제 div와 span 요소를 포함하는 html 파일의 예를 사용하여 블록과 인라인의 차이점을 보여 드리겠습니다.
- 다른 비디오에서는 요소의 레이아웃 동작을 변경하기 위해 display 속성에 설정할 수 있는 다른 값이 있다는 것을 보여 드리겠습니다.

## 예시
- 다른 비디오에서는 요소의 레이아웃 동작을 변경하기 위해 display 속성에 설정할 수 있는 다른 값이 있다는 것을 보여 드리겠습니다.

## 요약
- 이제 div와 span 요소를 포함하는 html 파일의 예를 사용하여 블록과 인라인의 차이점을 보여 드리겠습니다. 다른 비디오에서는 요소의 레이아웃 동작을 변경하기 위해 display 속성에 설정할 수 있는 다른 값이 있다는 것을 보여 드리겠습니다.
