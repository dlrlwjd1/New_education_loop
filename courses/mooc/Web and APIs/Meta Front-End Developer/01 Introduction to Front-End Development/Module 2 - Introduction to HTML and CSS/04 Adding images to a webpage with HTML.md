# Adding images to a webpage with HTML

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/introduction-to-front-end-development/lecture/UG9gR/adding-images-to-a-webpage-with-html)

## 개요
- 이 비디오에서는 일반적으로 알려진 이미지 또는 IMG 태그를 사용하여 HTML 문서에 이미지를 추가하는 방법을 알아봅니다.

## 내용
- 이 비디오에서는 일반적으로 알려진 이미지 또는 IMG 태그를 사용하여 HTML 문서에 이미지를 추가하는 방법을 알아봅니다.
- 프로젝트 폴더에 있는 파일을 이미지로 만들어야 하는데, 한 이름은 falafel.jpeg, 다른 이름은 salad.jpeg 입니다.
- 문서 링크를 사용할 때와 마찬가지로 이미지 태그를 사용하여 이미지 파일에 대한 링크를 지정해야 합니다.
- 대신 HTML의 이미지 태그를 사용하여 이미지 파일에 연결합니다.
- 이미지 태그를 추가하려면 img를 입력하고 그 안에 src 속성 또는 소스 속성을 알려진 대로 추가합니다.
- 한 이미지의 소스로 falafel.jpeg 를 입력하고 다른 이미지의 소스로 salad.jpeg 를 입력합니다.
- 보조 기술을 사용하는 사람들의 접근성을 개선하는 데 도움이 되며 검색 엔진 순위도 높일 수 있습니다.제단 헌정이라고도 하는 대체 텍스트 속성을 사용하여 이미지 설명을 추가할 수 있습니다.

## 예시
- Little Lemon에 대한 제 예시 웹사이트는 분명 이미지 몇 개를 사용할 수 있을 거예요.

## 요약
- 한 이미지의 소스로 falafel.jpeg 를 입력하고 다른 이미지의 소스로 salad.jpeg 를 입력합니다. 보조 기술을 사용하는 사람들의 접근성을 개선하는 데 도움이 되며 검색 엔진 순위도 높일 수 있습니다.제단 헌정이라고도 하는 대체 텍스트 속성을 사용하여 이미지 설명을 추가할 수 있습니다.
