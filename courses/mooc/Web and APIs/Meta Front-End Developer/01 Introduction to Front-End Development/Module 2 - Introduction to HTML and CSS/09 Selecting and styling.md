# Selecting and styling

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/introduction-to-front-end-development/lecture/BFM6m/selecting-and-styling)

## 개요
- 비슷한 방식으로 웹사이트와 웹 앱의 경우 HTML을 다음과 같이 생각할 수 있습니다 프레임과 구조라고 생각할 수 있습니다.

## 내용
- 비슷한 방식으로 웹사이트와 웹 앱의 경우 HTML을 다음과 같이 생각할 수 있습니다 프레임과 구조라고 생각할 수 있습니다.
- 예를 들어 h1 선택기를 사용하여 웹 페이지의 모든 머리글 1 태그의 색상을 변경하는 규칙을 만들 수 있습니다 제목 1 태그의 색상을 회색으로 변경하는 규칙을 만들 수 있습니다.
- 선언 블록에는 선택기에 적용할 속성 및 값에 대한 정보가 들어 있습니다 속성과 값에 대한 정보를 담고 있습니다.
- 예를 들어, 이 경우 변경하려는 속성은 색상과 헤더 또는 헤더 또는 선택기의 배경색입니다.
- 이제 CSS가 웹 브라우저에 HTML 요소를 화면에 표시하는 방법을 알려준다는 것을 배웠을 것입니다 를 화면에 표시하는 방법을 배웠을 것입니다.
- 이제 style.css 파일에 작성할 스타일 규칙을 사용하여 index.html 파일에 CSS를 적용할 준비가 되었습니다 를 작성합니다.
- 선언 블록의 속성을 사용하면 선택한 요소의 방식을 변경할 수 있습니다 예를 들어 모든 H1 요소의 색상 속성을 설정하여 텍스트를 보라색으로 표시하고 있습니다 보라색으로 표시하도록 설정합니다.
