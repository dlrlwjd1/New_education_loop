# HTML documents

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/introduction-to-front-end-development/lecture/B6PB6/html-documents)

## 개요
- 이 비디오를 마치면 HTML 문서의 구조를 파악하고 기본적인 웹 페이지를 만들 수 있을 것입니다.

## 내용
- 이 비디오를 마치면 HTML 문서의 구조를 파악하고 기본적인 웹 페이지를 만들 수 있을 것입니다.
- HTML 파일과 비주얼 스튜디오 코드를 만들려면 탐색기 패널을 마우스 오른쪽 버튼으로 클릭하고 새 파일을 선택합니다.
- 하지만 요소나 태그를 추가하기 전에 먼저 DOCTYPE 선언으로 시작하는 표준 HTML 구조를 만들어야 합니다.
- 모든 것이 올바른지 확인하기 위해 브라우저에서 index.html 파일을 열어 웹 페이지를 확인합니다.
- 이제 탐색기 패널에서 index.html 파일을 마우스 오른쪽 버튼으로 클릭하고 파일 탐색기에 표시를 선택합니다.
- 브라우저 탭에 표시되는 제목이 헤드 섹션에 추가한 제목과 일치하고 내용이 브라우저 창에 표시되지만 여전히 약간 비어 있습니다.
- 이제 몇 가지 기본 HTML 태그를 알았으니 해당 태그가 해당 웹사이트를 어디에 사용하고 있었는지 확인해 보세요.

## 예시
- 예를 들어, 메타 태그는 웹 페이지 설명, 검색 엔진 키워드, 웹 페이지 순서 등을 지정할 수 있습니다.

## 요약
- 브라우저 탭에 표시되는 제목이 헤드 섹션에 추가한 제목과 일치하고 내용이 브라우저 창에 표시되지만 여전히 약간 비어 있습니다. 이제 몇 가지 기본 HTML 태그를 알았으니 해당 태그가 해당 웹사이트를 어디에 사용하고 있었는지 확인해 보세요.
