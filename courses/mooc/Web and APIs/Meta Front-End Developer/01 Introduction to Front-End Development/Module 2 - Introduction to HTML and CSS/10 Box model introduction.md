# Box model introduction

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/introduction-to-front-end-development/lecture/CxRUc/box-model-introduction)

## 개요
- 이를 위해서는 콘텐츠에 너비, 최소 너비, 최대 너비 최소 너비, 최대 너비 높이, 최소 높이, 최대 높이와 같은 CSS 규칙을 콘텐츠에 적용하면 됩니다.

## 내용
- 이를 위해서는 콘텐츠에 너비, 최소 너비, 최대 너비 최소 너비, 최대 너비 높이, 최소 높이, 최대 높이와 같은 CSS 규칙을 콘텐츠에 적용하면 됩니다.
- 패딩 상자 너비는 다음과 같이 계산할 수 있습니다 콘텐츠 너비에 패딩을 더한 값 왼쪽에 오른쪽 패딩을 더한 값으로 계산할 수 있습니다.
- 패딩 상자 높이는 콘텐츠 높이 콘텐츠 높이를 더하면 됩니다, 패딩 위쪽과 패딩 아래쪽을 더하면 패딩 상자 높이를 계산할 수 있습니다.
- 다양한 유형의 테두리를 설정할 수 있습니다, 실선 테두리 또는 점선 테두리 등 다양한 유형의 테두리를 설정할 수 있습니다.
- 테두리 상자 높이는 다음을 더하여 계산할 수 있습니다 패딩 상자 높이와 테두리 윗면, 테두리 아래쪽을 더하면 테두리 상자 높이를 계산할 수 있습니다.
- 여백 상자 너비 는 테두리 상자 너비를 더하여 계산할 수 있습니다, 왼쪽 여백과 오른쪽 여백을 더하면 됩니다.
- 여백 상자 높이는 테두리 상자 높이로 구할 수 있습니다, 여백 위쪽과 여백 아래쪽을 더하면 됩니다.

## 예시
- 여백 상자 높이는 테두리 상자 높이로 구할 수 있습니다, 여백 위쪽과 여백 아래쪽을 더하면 됩니다.

## 요약
- 여백 상자 너비 는 테두리 상자 너비를 더하여 계산할 수 있습니다, 왼쪽 여백과 오른쪽 여백을 더하면 됩니다. 여백 상자 높이는 테두리 상자 높이로 구할 수 있습니다, 여백 위쪽과 여백 아래쪽을 더하면 됩니다.
