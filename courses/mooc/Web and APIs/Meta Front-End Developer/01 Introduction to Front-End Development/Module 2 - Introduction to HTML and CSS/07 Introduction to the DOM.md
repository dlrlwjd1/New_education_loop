# Introduction to the DOM

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/introduction-to-front-end-development/lecture/mcBAE/introduction-to-the-dom)

## 개요
- 단순한 HTML 문서라면 사용자가 페이지를 스크롤하고 사진을 보고 텍스트를 읽을 수는 있지만 게시물처럼 로그인하거나 새 메시지에 대한 알림을 받을 수는 없을 것입니다.

## 내용
- 단순한 HTML 문서라면 사용자가 페이지를 스크롤하고 사진을 보고 텍스트를 읽을 수는 있지만 게시물처럼 로그인하거나 새 메시지에 대한 알림을 받을 수는 없을 것입니다.
- 사용자가 이러한 작업을 수행할 수 있게 하려면 반응 아이콘이나 댓글 버튼과 같이 페이지에 있는 개체와 상호 작용할 수 있어야 합니다.
- 이 비디오에서는 DOM이 무엇인지, 어떻게 생성되는지, JavaScript가 DOM과 상호 작용하여 사이트를 동적으로 만드는 방법을 살펴보겠습니다.
- body 오브젝트는 두 개의 div 오브젝트를 포함하며, 첫 번째 div에는 해당 텍스트 오브젝트가 들어 있는 h1 오브젝트가 있습니다.
- 예를 들어, 사용자가 잘못된 데이터를 삽입한 경우 양식에 오류 메시지를 추가할 수 있으며, DOM 객체를 삭제하면 브라우저에 표시된 해당 HTML이 제거될 수도 있습니다.
- 예를 들어 페이지를 처음 로드할 때 페이지 내용이 희미하게 표시되거나 사용자가 인스턴트 메시지를 받으면 웹 브라우저에 알림이 팝업될 수 있습니다.
- 지금쯤이면 DOM이 무엇인지, 어떻게 구성되는지, 웹 개발자가 이를 사용하여 현대적인 대화형 웹 사이트를 만들 수 있는 놀라운 일들이 무엇인지 알게 될 것입니다.

## 예시
- 예를 들어 웹 사이트에 있는 디지털 시계의 초, 분, 시간을 업데이트하는 JavaScript를 작성할 수 있습니다.

## 요약
- 예를 들어 페이지를 처음 로드할 때 페이지 내용이 희미하게 표시되거나 사용자가 인스턴트 메시지를 받으면 웹 브라우저에 알림이 팝업될 수 있습니다. 지금쯤이면 DOM이 무엇인지, 어떻게 구성되는지, 웹 개발자가 이를 사용하여 현대적인 대화형 웹 사이트를 만들 수 있는 놀라운 일들이 무엇인지 알게 될 것입니다.
