# Module Summary - Introduction to HTML and CSS

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/introduction-to-front-end-development/lecture/rpDQk/module-summary-introduction-to-html-and-css)

## 개요
- 웹 브라우저에서 HTML의 용도를 설명하고 올바른 구문을 사용하는 방법, 웹 문서에서 HTML 요소가 사용되는 방식을 식별하는 방법 등 HTML 태그 사용을 시연하는 방법을 배웠습니다.

## 내용
- 웹 브라우저에서 HTML의 용도를 설명하고 올바른 구문을 사용하는 방법, 웹 문서에서 HTML 요소가 사용되는 방식을 식별하는 방법 등 HTML 태그 사용을 시연하는 방법을 배웠습니다.
- 또한 HTML 문서를 살펴보았으므로 이제 루트, 헤드, 본문 및 기타 요소를 포함하여 HTML 페이지의 구조를 개괄적으로 설명하고, 공통 키 요소와 태그를 결합하여 구조를 만드는 방법을 보여주고, H 참조 또는 하이퍼텍스트 참조 속성을 사용하여 HTML 문서 간에 링크를 만들어 문서 간에 사용자를 리디렉션하는 방법을 설명할 수 있을 것입니다.
- 또한 HTML 코드로 웹 페이지에 이미지를 추가하고, HTML을 활용하여 표의 데이터를 조작하고, 다양한 입력 유형으로 HTML 양식을 작성할 수 있어야 합니다.
- 그런 다음 HTML 페이지에 있는 개체의 트리 구조 또는 모델인 DOM (문서 개체 모델) 을 연구하기 시작했습니다.DOM을 조사하면서 DOM이 무엇인지, HTML 문서에서 DOM이 어떤 역할을 하는지 설명하고, DOM을 생성하는 요소를 탐색하고 다이어그램 형식으로 시각화하여 HTML 페이지에서 DOM을 생성하는 방법을 설명하고, 웹 개발자가 JavaScript를 통해 DOM과 상호 작용하는 일반적인 인스턴스에 대한 높은 수준의 설명을 제공하는 방법을 배웠습니다.
- 또한 장애가 있는 사용자가 웹 사이트를 이해하고 탐색하고 상호 작용할 수 있는 방법을 탐색하여 웹 접근성의 개념을 탐구했습니다.
- 이 주제를 살펴본 다음에는 이제 화면 읽기 및 음성 인식 소프트웨어와 같이 웹을 탐색하는 데 사용되는 보조 기술에 대한 수준 높은 지식을 입증하고 올바른 HTML 구조와 같은 웹 프로젝트의 접근성을 개선하기 위한 기본 기술을 사용할 수 있게 될 것입니다.
- 이 수업은 선택 및 스타일 지정에 대한 개요로 시작하여 HTML 문서 내의 요소에 스타일을 지정하기 위해 CSS 규칙을 작성하는 방법을 배우고, 상자 모델과 주요 기능을 보여주고 이해하며, 문서 흐름의 개념을 설명합니다.
