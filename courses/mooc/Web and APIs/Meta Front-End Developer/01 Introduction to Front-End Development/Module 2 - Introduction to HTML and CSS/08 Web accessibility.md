# Web accessibility

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/introduction-to-front-end-development/lecture/UEYQ0/web-accessibility)

## 개요
- 웹 개발자로서 모든 사람이 인터넷에 접속하고 즐길 수 있도록 모든 사람이 인터넷에 접속하고 즐길 수 있도록 노력해야 합니다.

## 내용
- 웹 개발자로서 모든 사람이 인터넷에 접속하고 즐길 수 있도록 모든 사람이 인터넷에 접속하고 즐길 수 있도록 노력해야 합니다.
- 흔히 시각 장애를 가리키는 것으로 오해하고 있지만, 사실 여기에는 시청각 장애, 인지 및 신경 장애, 신체 및 언어 장애 등 웹 사이트와의 상호 작용에 영향을 미치는 모든 장애가 포함됩니다.
- 스크린 리더는 맹인 및 시각 장애가 있는 사용자뿐만 아니라 읽기 또는 학습에 장애가 있는 사용자도 사용합니다.
- 이는 신체적 또는 신경계 장애로 인해 마우스나 키보드를 사용할 수 없는 사람들에게 유용하며, 자막과 비디오 스크립트 및 비디오는 시청각 장애가 있는 사람들에게 도움이 됩니다.
- 예를 들어 단락 또는 제목 태그와 같은 적절한 태그 내에 텍스트가 포함되지 않으면 보조 기술이 콘텐츠와 상호 작용하기가 더 어려워집니다.
- 하지만 미래에는 아마도 매우 복잡한 사용자 인터페이스를 개발하게 될 것이며 이러한 인터페이스에 액세스할 수 있게 만드는 것이 단지 html을 올바르게 사용하는 것만큼 간단하지 않을 수도 있습니다.
- 이제 다양한 보조 기술에 대해 알고 있으며 올바른 html 구조와 적절한 요소를 사용하여 접근성을 개선해야 한다는 사실을 알게 되었습니다.

## 예시
- 이 과정에서는 html을 올바르게 구성하는 방법을 배우고 모범 사례를 따라 보조 기술을 지원하는 방법을 배우게 됩니다.

## 요약
- 하지만 미래에는 아마도 매우 복잡한 사용자 인터페이스를 개발하게 될 것이며 이러한 인터페이스에 액세스할 수 있게 만드는 것이 단지 html을 올바르게 사용하는 것만큼 간단하지 않을 수도 있습니다. 이제 다양한 보조 기술에 대해 알고 있으며 올바른 html 구조와 적절한 요소를 사용하여 접근성을 개선해야 한다는 사실을 알게 되었습니다.
