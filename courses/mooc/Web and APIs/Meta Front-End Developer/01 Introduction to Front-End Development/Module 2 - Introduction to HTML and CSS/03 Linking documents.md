# Linking documents

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/introduction-to-front-end-development/lecture/fCYCp/linking-documents)

## 개요
- 앵커 태그 앵커 태그를 사용하면 일반적으로 알려진 하이퍼링크나 링크를 만들 수 있습니다.

## 내용
- 앵커 태그 앵커 태그를 사용하면 일반적으로 알려진 하이퍼링크나 링크를 만들 수 있습니다.
- 탐색기 패널을 마우스 오른쪽 버튼으로 클릭하여 새 파일을 만들고 이름을 location.html 로 지정합니다.
- 마지막 단락 태그 아래에 앵커 또는 태그를 추가하고 그 뒤에 href 트리뷰트 또는 하이퍼텍스트 참조를 추가합니다.
- index.html 파일을 링크하기 위해 location.html 라는 파일 이름을 입력했습니다.
- 변경 내용을 업데이트하기 위해 파일을 저장한 다음 index.html 파일을 마우스 오른쪽 버튼으로 클릭하고 파일 탐색기에서 공개를 선택하여 웹 브라우저에서 엽니다.
- Windows를 사용하지 않는 경우, 이를 파인더 공개 또는 공개 파일 탐색기라고 할 수 있습니다.
- 이제 여러 HTML 파일을 연결하여 웹사이트를 만들 수 있습니다.
