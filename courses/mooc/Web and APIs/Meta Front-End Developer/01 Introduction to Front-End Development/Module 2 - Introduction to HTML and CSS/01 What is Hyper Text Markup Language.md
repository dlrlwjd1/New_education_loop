# What is Hyper Text Markup Language?

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/introduction-to-front-end-development/lecture/bvbzK/what-is-hyper-text-markup-language)

## 개요
- 예를 들어 단락을 만들려면 왼쪽 꺾쇠 괄호, 단락에는 문자 p, 오른쪽 꺾쇠 괄호를 차례로 입력합니다.

## 내용
- 예를 들어 단락을 만들려면 왼쪽 꺾쇠 괄호, 단락에는 문자 p, 오른쪽 꺾쇠 괄호를 차례로 입력합니다.
- 대부분의 요소는 왼쪽 꺾쇠 괄호 앞에 슬래시가 있는 닫기 태그와 쌍을 이룹니다.
- 예를 들어 왼쪽 꺾쇠 괄호, 앞쪽 슬래시, 문자 p, 오른쪽 꺾쇠 괄호를 사용하여 단락 요소를 닫습니다.
- 왼쪽 꺾쇠 괄호, br, 오른쪽 꺾쇠 괄호를 차례로 입력하여 단락 태그에 줄 바꿈 태그를 추가하여 내용을 다음 줄로 이동할 수 있습니다.
- 자동으로 닫히는 태그의 끝에 오른쪽 꺾쇠 괄호를 추가하기만 하면 됩니다.오른쪽 꺾쇠 괄호 바로 앞에 슬래시를 입력하여 오른쪽 꺾쇠 괄호를 닫을 수도 있습니다.
- 요약하자면 여는 태그와 닫는 태그가 있는 HTML 요소와 꺾쇠 괄호가 있는 HTML 요소가 HTML 문서를 구성합니다.
- 예를 들어 브라우저는 이미지 태그가 있는 HTML 페이지를 읽고 icon.png 라는 이미지 파일을 표시합니다.

## 예시
- 예를 들어, 웹 사이트를 방문할 때 브라우저로 반환되는 첫 페이지를 index.html 라고 하는 경우가 많습니다.

## 요약
- 요약하자면 여는 태그와 닫는 태그가 있는 HTML 요소와 꺾쇠 괄호가 있는 HTML 요소가 HTML 문서를 구성합니다. 예를 들어 브라우저는 이미지 태그가 있는 HTML 페이지를 읽고 icon.png 라는 이미지 파일을 표시합니다.
