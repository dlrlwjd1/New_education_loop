# Introduction to Front-End Development

Meta Front-End Developer 전문과정의 첫 번째 강좌. 웹의 동작 방식, HTML·CSS 기초, 반응형 UI 프레임워크와 React의 기본 구조를 다룬다.

- 강좌 링크: <https://www.mooc.org/learn/introduction-to-front-end-development>
- 구성: 4개 모듈, 영상 44개
- 노트: 영상 Transcript 기반 한국어 정리
- 제외: 읽기 자료·퀴즈·채점 평가의 정답 및 제출

- 채점 평가는 정리에서 제외

## 핵심 요약

- 프론트엔드는 브라우저에서 사용자가 보는 인터페이스를 담당하고, 백엔드는 서버·데이터베이스와 비즈니스 처리를 담당한다.
- 브라우저와 서버는 HTTP 요청·응답으로 통신하며 HTML, CSS, JavaScript를 이용해 웹페이지를 구성한다.
- HTML은 구조, CSS는 표현, JavaScript는 상호작용을 담당한다.
- 반응형 디자인은 다양한 화면 크기에 맞춰 레이아웃과 콘텐츠를 조정한다.
- Bootstrap은 반복적인 UI 구성을 단순화하고, React는 재사용 가능한 컴포넌트와 가상 DOM을 통해 동적 UI를 구성한다.
