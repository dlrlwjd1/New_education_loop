# Advanced React

Meta Front-End Developer 전문과정의 여섯 번째 강좌. 고급 컴포넌트 패턴, React Hooks, JSX 변환과 테스트를 다룬다.

- 강좌 링크: <https://www.mooc.org/learn/advanced-react>
- 구성: 4개 모듈, 영상 41개
- 수집 상태: 접근 가능한 영상 40개 Transcript 정리 완료
- 잠금 항목: `Solution walk-through: Portfolio` 1개 — 선행 채점 과제 완료 필요
- 제외: 읽기 자료·퀴즈·채점 평가의 정답 및 제출

## 모듈 구성

- Module 1 - Components: 영상 14개
- Module 2 - React Hooks and Custom Hooks: 영상 12개
- Module 3 - JSX and testing: 영상 12개
- Module 4 - Final project: 영상 3개 중 2개 수집, 잠금 1개

## 핵심 주제

- 고차 컴포넌트와 Render Props
- 합성과 특수화
- Context
- `useReducer`, `useRef`, `useEffect`와 커스텀 훅
- JSX 변환과 React 테스트
