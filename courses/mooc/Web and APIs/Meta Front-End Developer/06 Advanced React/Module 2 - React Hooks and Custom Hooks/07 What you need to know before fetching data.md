# What you need to know before fetching data

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/advanced-react/lecture/1oxvs/what-you-need-to-know-before-fetching-data)

## 개요
- 처음에는 Fetch 함수가 이 프로세스에 어떻게 기여하는지 파악할 수 있도록 JavaScript에서 작업을 위임하는 방법을 개괄적으로 살펴보는 것이 좋습니다.

## 내용
- 처음에는 Fetch 함수가 이 프로세스에 어떻게 기여하는지 파악할 수 있도록 JavaScript에서 작업을 위임하는 방법을 개괄적으로 살펴보는 것이 좋습니다.
- 이 비디오에서는 Fetch 함수를 사용하여 웹에서 데이터를 검색하는 방법과 프로세스의 예제를 일반 JavaScript로 제공하는 방법을 알아봅니다.
- 고객 세부 정보를 얻고, 패키지의 무게를 측정하고, 패키지에 스탬프를 붙이고, 서비스 비용을 청구하고, 백오피스로 가서 패키지를 그곳으로 운반하는 과정을 거칩니다.
- JavaScript는 서비스 요금을 청구하기 위해 또 다른 점원에게 전화를 걸고, 또 다른 직원이 패키지를 백오피스로 운반하여 JavaScript가 다음 고객을 돌볼 수 있도록 합니다.
- JavaScript 우체국 직원이 우체국 기록 부서에 전화를 걸어 고객에 대한 데이터를 얻는 것으로 생각할 수 있습니다.
- 다른 직원이 정보를 가지고 와서 우체국 직원에게 넘겨주면 JSON 정보를 받게 되고 마지막으로 해당 데이터를 콘솔에 기록합니다.
- 이 비디오에서는 Fetch 함수를 사용하여 웹에서 데이터를 검색하는 방법과 프로세스의 예제를 일반 JavaScript로 제공하는 방법을 배웠습니다.
