# Fetching data – Putting it all together

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/advanced-react/lecture/3NT5T/fetching-data-putting-it-all-together)

## 개요
- 이 비디오에서는 웹 사이트에서 임의의 사용자 데이터를 가져오는 방법을 보여 드리겠습니다.이 데모에서는 random.me 웹 사이트를 사용하여 임의의 사용자 데이터에 액세스할 것입니다.

## 내용
- 이 비디오에서는 웹 사이트에서 임의의 사용자 데이터를 가져오는 방법을 보여 드리겠습니다.이 데모에서는 random.me 웹 사이트를 사용하여 임의의 사용자 데이터에 액세스할 것입니다.
- 동시에 백그라운드에서 임의의 사용자 웹 사이트에서 사용자 정보를 검색하는 데이터 가져오기 기능을 수행합니다.
- 이는 웹에서 데이터를 가져오기 전에 제목의 데이터 보류 텍스트를 관찰할 수 있도록 하기 위한 것입니다.
- 먼저 object.keys 코드 스니펫을 사용하여 사용자 개체의 모든 키를 배열에 넣습니다.
- object.keys는 배열을 반환하므로 이 배열의 length 속성에 액세스하여 이 배열의 길이가 0보다 큰지 확인할 수 있습니다.
- 따라서 작은 레몬 레스토랑은 고객 목록 API에 동일한 논리를 적용하여 경쟁사의 무작위 우승자를 선택할 수 있습니다.
- 이 비디오에서는 상태 및 효과 후크를 사용하여 데이터를 가져오는 방법을 배웠습니다.
