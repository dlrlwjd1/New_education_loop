# Working with React hooks

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/advanced-react/lecture/7Fb8U/working-with-react-hooks)

## 개요
- React 훅은 React 컨퍼런스에서 처음 소개되었으며, 새로운 것에 대해 열광하는 커뮤니티 및 React 애호가 커뮤니티와 공유되었습니다.

## 내용
- React 훅은 React 컨퍼런스에서 처음 소개되었으며, 새로운 것에 대해 열광하는 커뮤니티 및 React 애호가 커뮤니티와 공유되었습니다.
- 그들은 우리에게 피드백을 제공하고 우리가 생각하고 있는 것들을 테스트할 수 있는 신뢰할 수 있는 사람들입니다.
- 실제로 후크는 애플리케이션을 크게 단순화하고 성능 향상을 가져와 코드를 더 읽기 쉽고 관리하기 쉽게 만들 수 있을 뿐만 아니라 코드의 공유 및 재사용성을 높일 수 있습니다.
- 후크가 도입되기 전에는 클래스 컴포넌트를 사용하고 있었는데, 클래스 컴포넌트가 제 역할을 하는 것 같았습니다.
- Meta에서 새로운 기술을 개발할 때 우리는 이러한 것들이 실제로 작동하는지 확인하는 첫 번째 사용자가 되려고 노력했고 엔지니어로부터 직접 피드백을 받을 수 있도록 했습니다.
- 그래서 후크가 React 애플리케이션 개발 과정에서 큰 차이를 만들고 더 광범위하게 출시할 수 있었다는 것이 정당화되었습니다.
- 처음에는 어렵고 혼란스러워 보일 수 있지만 시간이 지남에 따라 코드가 개선되고 이전 React 코드 작성 방법을 사용하고 싶을 수도 있지만 실제로 후크를 사용하면 후크를 사용하는 것이 더 쉬울 것입니다.
