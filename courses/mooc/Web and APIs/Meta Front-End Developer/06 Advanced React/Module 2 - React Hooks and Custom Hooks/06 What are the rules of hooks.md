# What are the rules of hooks?

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/advanced-react/lecture/RHByK/what-are-the-rules-of-hooks)

## 개요
- 지금쯤이면 React에서 후크의 목적과 기능에 대해 꽤 잘 알고 있을 것입니다.또한 일부 솔루션에서 후크를 사용하기 시작했을 수도 있습니다.

## 내용
- 지금쯤이면 React에서 후크의 목적과 기능에 대해 꽤 잘 알고 있을 것입니다.또한 일부 솔루션에서 후크를 사용하기 시작했을 수도 있습니다.
- 이 비디오에서는 React의 후크 규칙과 후크 규칙이 왜 그렇게 중요한지, 왜 최상위 레벨과 React 함수에서만 후크를 호출하는지에 대해 알아봅니다.
- 셋째, 컴포넌트 내에서 여러 상태 후크 또는 이펙트 후크를 호출할 수 있습니다.
- 첫 번째 규칙은 일반 Javascript 함수에서 후크를 호출하지 말고 React 컴포넌트 함수 내에서만 호출해야 한다는 것입니다.
- 내장 후크 호출 (예: useEffect 후크 또는 사용자 지정 후크) 에서 이 예제의 코드는 클릭하여 애완동물의 새 이름을 선택할 수 있는 버튼을 설명합니다.
- 여기서는 NameLooper 함수 내에서 PetName이라는 상태 설정 함수를 사용하는 대신 useState 후크를 대신 사용했습니다.
- 이 비디오에서는 React에서 후크를 사용하는 주요 규칙과 React 함수의 최상위 수준에서만 후크를 호출하는 이유에 대해 알아봅니다.

## 예시
- 예를 들어, 여기서는 if 조건문 내에 useEffect 후크가 사용되었으므로 이 코드에서 후크를 사용할 수 없게 됩니다.

## 요약
- 여기서는 NameLooper 함수 내에서 PetName이라는 상태 설정 함수를 사용하는 대신 useState 후크를 대신 사용했습니다. 이 비디오에서는 React에서 후크를 사용하는 주요 규칙과 React 함수의 최상위 수준에서만 후크를 호출하는 이유에 대해 알아봅니다.
