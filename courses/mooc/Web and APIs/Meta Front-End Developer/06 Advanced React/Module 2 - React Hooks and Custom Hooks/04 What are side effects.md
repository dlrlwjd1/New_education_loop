# What are side effects?

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/advanced-react/lecture/bziSe/what-are-side-effects)

## 개요
- 이 비디오에서는 순수 함수와 불순한 함수의 정의, 부작용과의 관계, 함수 구성 요소 내에서 부작용을 수행하는 데 useEffect를 사용하는 방법을 포함하여 반응 구성 요소 내의 부작용이 무엇인지 알아봅니다.

## 내용
- 이 비디오에서는 순수 함수와 불순한 함수의 정의, 부작용과의 관계, 함수 구성 요소 내에서 부작용을 수행하는 데 useEffect를 사용하는 방법을 포함하여 반응 구성 요소 내의 부작용이 무엇인지 알아봅니다.
- 함수는 순수하고 불순한 것으로 분류될 수 있다는 것을 알고 계셨습니까?간단히 말해서 순수 함수에는 부작용이 없으며 불순한 함수에는 부작용이 있습니다.
- 또한 '설정된 연도'라는 단어 뒤에 콜론, 공백, 연도 소품 값을 출력하는 표제 값도 반환합니다.year prop의 값이 2003이면 설정된 year 함수를 호출하거나 앱 구성 요소에서 렌더링한 횟수에 관계없이 출력은 변경되지 않습니다.
- 즉, '콘솔 로그' 호출, '가져오기' 호출 또는 브라우저 지오로케이션 기능 호출과 같은 작업을 수행합니다.
- 이 배열은 비워 둘 수 있으며 이는 완전히 유효합니다.구문은 유효하지만 useEffect 후크 호출의 첫 번째 인수로 화살표 함수를 사용하는 것이 일반적입니다.
- 일반적으로 몇 줄의 코드를 소비합니다.이는 일반적으로 구성 요소 변수의 값을 콘솔에 기록하는 것보다 더 의미 있는 작업을 수행해야 하기 때문입니다.
- 이 비디오에서는 순수 함수와 불순한 함수와 부작용과의 관계에 대해 알아보고, 반응 컴포넌트 내에서 어떤 부작용이 있는지 알아보고, useEffect를 사용하여 이를 수행하는 방법에 대해 간략하게 알아보았습니다.
