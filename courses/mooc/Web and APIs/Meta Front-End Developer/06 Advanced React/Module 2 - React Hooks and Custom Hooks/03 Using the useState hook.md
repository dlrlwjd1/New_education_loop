# Using the useState hook

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/advanced-react/lecture/0bmk8/using-the-usestate-hook)

## 개요
- 첫 번째 입력 필드는 소유자가 목표를 입력할 수 있도록 하기 위한 것이고, 두 번째 입력 필드는 소유자가 주어진 목표를 달성하고자 하는 기간을 입력할 수 있도록 하기 위한 것입니다.

## 내용
- 첫 번째 입력 필드는 소유자가 목표를 입력할 수 있도록 하기 위한 것이고, 두 번째 입력 필드는 소유자가 주어진 목표를 달성하고자 하는 기간을 입력할 수 있도록 하기 위한 것입니다.
- 변경 핸들러 함수의 본문에서는 use State 후크 호출을 통해 D 구조화된 집합 양식 데이터의 이전 D 구조화된 상태 설정 변수를 호출하여 양식 데이터 변수의 상태를 업데이트합니다.
- 즉, 사용자가 이름 속성을 목표로 설정한 상태에서 입력에 입력한 경우 목표로 설정하거나, 사용자가 이름 속성을 By로 설정한 상태에서 입력에 입력한 경우 목표로 설정할 수 있습니다.
- 모든 것이 제대로 작동하도록 하려면 목표 추가 함수 정의를 앱 구성 요소의 return 문에 있는 목표 포럼 JSX 요소에 전달해야 합니다.
- 이것이 목표 양식 함수 내에서 Add 라는 이름의 prop으로 목표 추가 함수를 사용할 수 있는 이유이기도 합니다.
- 이 문제를 해결하려면 양식 데이터 상태 개체의 목표 속성과 양식 데이터 상태 개체의 buy 속성 모두에서 양식 데이터 상태 변수를 빈 문자열로 재설정해야 합니다.
- 이제 React에서 목표 앱을 코딩하는 과정을 마쳤으니, 상태를 선언하고, 읽고, 업데이트하는 방법을 포함하여 컴포넌트 내에서 use State 훅을 사용하는 방법을 더 잘 이해할 수 있을 것입니다.
