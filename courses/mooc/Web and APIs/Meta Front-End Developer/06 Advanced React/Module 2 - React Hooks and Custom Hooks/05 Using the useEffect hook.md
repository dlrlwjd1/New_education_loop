# Using the useEffect hook

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/advanced-react/lecture/1F5cP/using-the-useeffect-hook)

## 개요
- 구성 요소 내에서 useEffect 후크를 사용하는 방법을 보여주기 위해 Little Lemon 앱에서 계속 작업해 보겠습니다.

## 내용
- 구성 요소 내에서 useEffect 후크를 사용하는 방법을 보여주기 위해 Little Lemon 앱에서 계속 작업해 보겠습니다.
- 이 비디오에서는 useEffect 후크를 사용하여 React에서 부작용을 수행하는 방법과 종속성 배열을 사용하여 useEffect 함수가 실행되는 시기를 제어하는 방법을 보여줍니다.
- 이전에 Create React App을 사용하여 만든 앱을 사용하여 useEffect 후크를 사용하는 방법을 보여 드리겠습니다.
- 파라미터가 없는 화살표 함수를 추가하고 화살표 함수 본문에 토글 변수의 값이 true인지 false인지 확인하는 이 삼항을 여기에 추가하겠습니다.
- 종속성 배열은 특정 변수의 변경 사항을 감시하고 이를 기반으로 useEffect 함수 호출의 첫 번째 인수로 전달된 함수를 실행하기 위한 것입니다.
- 즉 , 토글 변수에 저장된 값이 업데이트될 때마다 useEffect 후크를 실행하려면 토글 변수를 종속성 배열에 추가해야 합니다.
- 이제 useEffect 함수를 사용하여 부작용을 처리하는 방법과 종속성 배열을 사용하여 호출 시기를 결정하는 방법을 더 잘 이해할 수 있을 것입니다.

## 예시
- 이제 useEffect 함수를 사용하여 부작용을 처리하는 방법과 종속성 배열을 사용하여 호출 시기를 결정하는 방법을 더 잘 이해할 수 있을 것입니다.
