# Revising useState hook

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/advanced-react/lecture/fYbiz/revising-usestate-hook)

## 개요
- Little Lemon용으로 빌드된 앱을 사용하여 몇 가지 실용적인 예제를 통해 사용된 상태 후크를 수정하고 useState 후크가 호출되는 방식을 알아보고 useState 후크의 반환 값과 상태를 업데이트하는 데 어떻게 사용되는지 살펴보겠습니다.

## 내용
- Little Lemon용으로 빌드된 앱을 사용하여 몇 가지 실용적인 예제를 통해 사용된 상태 후크를 수정하고 useState 후크가 호출되는 방식을 알아보고 useState 후크의 반환 값과 상태를 업데이트하는 데 어떻게 사용되는지 살펴보겠습니다.
- 실제로 어떻게 작동하는지 살펴보겠습니다.use state 후크를 사용하여 레스토랑 이름의 초기 값을 Lemon으로 설정한 다음 use state update 함수만 사용하여 little Lemon으로 업데이트하여 상태 및 반응 앱을 업데이트하는 방법을 보여 드리겠습니다.
- 또 다른 규칙은 D 구조화된 상태 변수에 사용되는 변수 이름에 설정된 단어를 미리 보류하여 이름을 지정하는 것입니다.
- 즉, 상태를 올바르게 다루는 방법은 코드 예제를 시작하여 useState 후크 호출에서 반환된 배열을 D로 구조화해야 한다는 것을 의미합니다.
- 일부 개발자는 다양한 방법으로 상태 변수를 업데이트하려고 하지만 use state를 사용할 때 상태를 업데이트하는 올바른 방법은 하나뿐입니다.
- 즉, 레스토랑 이름 변수의 상태를 업데이트하는 유일한 방법은 반응 앱에서 set restaurant name 함수를 호출하는 것입니다.
- 업데이트 레스토랑 이름 함수를 호출하면 set 레스토랑 이름 상태 설정 함수에 대한 호출이 트리거되었기 때문입니다.

## 예시
- 업데이트 레스토랑 이름 함수를 호출하면 set 레스토랑 이름 상태 설정 함수에 대한 호출이 트리거되었기 때문입니다.

## 요약
- 즉, 레스토랑 이름 변수의 상태를 업데이트하는 유일한 방법은 반응 앱에서 set restaurant name 함수를 호출하는 것입니다. 업데이트 레스토랑 이름 함수를 호출하면 set 레스토랑 이름 상태 설정 함수에 대한 호출이 트리거되었기 때문입니다.
