# What is useReducer and how it differs from useState

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/advanced-react/lecture/gSMJb/what-is-usereducer-and-how-it-differs-from-usestate)

## 개요
- 예를 들어 여러 하위 값을 포함하는 복잡한 상태 논리가 있거나 다음 상태가 이전 상태에 종속되는 경우 useState 후크가 복잡해질 수 있습니다.

## 내용
- 예를 들어 여러 하위 값을 포함하는 복잡한 상태 논리가 있거나 다음 상태가 이전 상태에 종속되는 경우 useState 후크가 복잡해질 수 있습니다.
- useState 후크는 초기 상태로 시작하지만 useReducer 후크는 초기 상태 외에 리듀서 함수를 가져옵니다.
- 이 객체에는 여러 유형 값이 있으며 이러한 각 유형 값을 기반으로 디스패치 함수를 호출하여 특정 작업을 수행할 수 있습니다.
- 이는 재료 구매 비용과 완제품을 고객에게 판매하여 발생하는 수입을 간단히 추적하기 위해 useReducer 후크를 구현할 수 있는 완벽한 기회입니다.
- 이 앱을 사용하면 두 가지 작업을 추적할 수 있습니다.식사를 준비하기 위한 재료 구입 비용 및 완성된 식사를 고객과 레스토랑에 판매하여 얻은 수입인 리틀 레몬 레스토랑.
- 이 작업을 수행하기 위해 reducer 함수에 다른 작업 유형을 추가한 다음 이를 트리거하는 버튼을 하나 더 추가했습니다.
- 이 비디오에서는 useReducer 후크가 useState 후크와 어떻게 다른지, 그리고 특정 상황에서 유용하고 더 효율적인 솔루션이 될 수 있는 이유에 대해 알아보았습니다.
