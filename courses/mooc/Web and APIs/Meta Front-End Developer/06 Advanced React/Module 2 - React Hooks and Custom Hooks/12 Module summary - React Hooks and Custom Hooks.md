# Module summary: React Hooks and Custom Hooks

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/advanced-react/lecture/Ef2I2/module-summary-react-hooks-and-custom-hooks)

## 개요
- useState 후크를 사용하여 배열 구조 분해를 수행하고 상태 업데이트 함수를 통해 새 상태를 사용할 때 상태를 업데이트하는 방법, 버튼 클릭과 같은 사용자 생성 이벤트에 대한 상태 및 응답을 변경하는 방법까지 살펴보았습니다.

## 내용
- useState 후크를 사용하여 배열 구조 분해를 수행하고 상태 업데이트 함수를 통해 새 상태를 사용할 때 상태를 업데이트하는 방법, 버튼 클릭과 같은 사용자 생성 이벤트에 대한 상태 및 응답을 변경하는 방법까지 살펴보았습니다.
- 그런 다음 자세한 데모를 통해 상태를 선언 , 읽기 및 업데이트하는 방법을 포함하여 구성 요소 내에서 useState 후크를 사용하는 방법을 배웠습니다.
- 이론적으로 useEffect 후크에 대해 배우는 것 외에도 UseEffect 후크를 사용하여 함수 구성 요소 내에서 부작용을 수행하고 종속성 배열을 사용하여 useEffect 함수가 실행되는 시기를 제어하는 방법을 실습 데모를 통해 배웠습니다.
- 이러한 규칙은 React 컴포넌트 함수와 React 컴포넌트 함수의 최상위 레벨에서만 후크를 호출하거나 컴포넌트 내에서 여러 상태 후크 또는 효과 후크를 호출할 수 있고 동일한 순서로 여러 후크 호출을 수행해야 한다는 것입니다.
- 이 모듈의 세 번째 단원에서는 useReducer 후크에 대해 배웠고 초기 상태 외에 리듀서 함수를 가져오기 때문에 useState 후크와 다르다는 것을 배웠습니다.
- UseReducer 후크는 복잡한 상태 로직이 있거나 코드에서 useReducer 후크를 구현하는 방법과 같이 useState 후크가 비효율적인 경우에 사용될 수 있다는 것을 배웠습니다.
- 또한 refs의 개념과 이를 사용하여 가상 DOM을 넘어 기본 DOM 요소 및 기타 응용 프로그램에 액세스하는 방법을 소개하고 사용자 지정 후크를 코딩하는 방법을 살펴보았습니다.

## 예시
- 그런 다음 자세한 데모를 통해 상태를 선언 , 읽기 및 업데이트하는 방법을 포함하여 구성 요소 내에서 useState 후크를 사용하는 방법을 배웠습니다.

## 요약
- UseReducer 후크는 복잡한 상태 로직이 있거나 코드에서 useReducer 후크를 구현하는 방법과 같이 useState 후크가 비효율적인 경우에 사용될 수 있다는 것을 배웠습니다. 또한 refs의 개념과 이를 사용하여 가상 DOM을 넘어 기본 DOM 요소 및 기타 응용 프로그램에 액세스하는 방법을 소개하고 사용자 지정 후크를 코딩하는 방법을 살펴보았습니다.
