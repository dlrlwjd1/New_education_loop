# Course recap: Advanced React

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/advanced-react/lecture/ktSG7/course-recap-advanced-react)

## 개요
- VS Code에서 프로젝트를 설정하는 방법을 알게 되었고 목표를 달성할 수 있도록 이 과정에서 콘텐츠를 최대한 활용하는 방법을 배웠습니다.

## 내용
- VS Code에서 프로젝트를 설정하는 방법을 알게 되었고 목표를 달성할 수 있도록 이 과정에서 콘텐츠를 최대한 활용하는 방법을 배웠습니다.
- 이 단원에서는 목록 구성 요소를 변환하고 렌더링하는 방법, 기본 목록 구성 요소를 만들고 목록 구성 요소 및 React 내에서 키에 대해 배웠습니다.
- 다음으로 React에서 제어된 양식 구성 요소를 만드는 방법을 발견하고 자신의 등록 양식을 만들어 기술을 테스트할 기회를 얻었습니다.
- 또한 후크를 사용하여 데이터를 가져오는 방법에 대한 심층적인 설명을 얻었고 실제 연습에서 데이터를 가져오는 기술을 테스트했습니다.
- 다음으로 격리 및 전문화라는 두 가지 주요 기능과 JSX에서 자식을 동적으로 조작하는 방법을 사용하여 구성 요소 구성을 탐색했습니다.
- 새로운 기술을 적용하고 라디오 그룹 구성 요소를 구축할 기회가 있었고 JSX에서 속성을 확산하는 방법을 소개합니다.
- 당신은 크로스 커팅 문제에 대해 배웠고 반응하고 고차 구성 요소와 그것들이 어떻게 사용되어 큰 효과를 얻었는지 탐구했습니다.

## 예시
- 양식에 대한 테스트 시나리오를 작성했으며 지속적인 통합을 소개합니다.

## 요약
- 새로운 기술을 적용하고 라디오 그룹 구성 요소를 구축할 기회가 있었고 JSX에서 속성을 확산하는 방법을 소개합니다. 당신은 크로스 커팅 문제에 대해 배웠고 반응하고 고차 구성 요소와 그것들이 어떻게 사용되어 큰 효과를 얻었는지 탐구했습니다.
