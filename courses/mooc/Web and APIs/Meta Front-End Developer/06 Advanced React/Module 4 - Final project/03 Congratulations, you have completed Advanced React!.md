# Congratulations, you have completed Advanced React!

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/advanced-react/lecture/7xe0u/congratulations-you-have-completed-advanced-react)

## 개요
- 프론트 엔드 개발자 여정에서 큰 발전을 이루고 있으며 이제 고급 React 기능을 사용하고 React 애플리케이션을 테스트하고 JSX를 더 능숙하게 사용하는 방법을 이해해야 합니다.

## 내용
- 프론트 엔드 개발자 여정에서 큰 발전을 이루고 있으며 이제 고급 React 기능을 사용하고 React 애플리케이션을 테스트하고 JSX를 더 능숙하게 사용하는 방법을 이해해야 합니다.
- 이 과정과 Advanced React를 마친 후에는 이제 React에서 목록과 구성 요소를 효율적으로 렌더링할 수 있습니다.
- Context가 정의된 API와 잠재적 애플리케이션을 사용하여 구성 요소 간에 전역 값을 공유하는 방법을 제공하는 방법을 보여줍니다.
- React에서 모든 공통 후크를 사용하고 응용 프로그램 내에서 사용하고 자신만의 사용자 지정 후크를 구축하십시오.
- 마지막 실습에서는 React를 사용하여 자신만의 완전한 기능을 갖춘 웹사이트를 구축하기 위해 배운 모든 것을 적용합니다.
- 기술 전문가, 학생 또는 비즈니스 사용자로 막 시작하는 경우 이 과정과 프로젝트는 프론트 엔드 개발의 가치와 기능에 대한 지식을 증명합니다.
- 이것은 잠재적인 고용주에게 당신의 기술을 보여주는 역할을 하며, 고용주에게 당신이 자기 주도적이고 혁신적이라는 것을 보여줄 뿐만 아니라 개인으로서 당신에 대해 많은 것을 말해줍니다.

## 예시
- 마지막 실습에서는 React를 사용하여 자신만의 완전한 기능을 갖춘 웹사이트를 구축하기 위해 배운 모든 것을 적용합니다.

## 요약
- 기술 전문가, 학생 또는 비즈니스 사용자로 막 시작하는 경우 이 과정과 프로젝트는 프론트 엔드 개발의 가치와 기능에 대한 지식을 증명합니다. 이것은 잠재적인 고용주에게 당신의 기술을 보여주는 역할을 하며, 고용주에게 당신이 자기 주도적이고 혁신적이라는 것을 보여줄 뿐만 아니라 개인으로서 당신에 대해 많은 것을 말해줍니다.
