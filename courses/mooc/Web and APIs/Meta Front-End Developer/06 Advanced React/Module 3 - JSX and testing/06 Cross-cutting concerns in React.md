# Cross-cutting concerns in React

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/advanced-react/lecture/RFFSC/cross-cutting-concerns-in-react)

## 개요
- React 애플리케이션을 만들 때 애플리케이션의 비즈니스 로직과 관련이 없고 여러 곳에서 필요한 몇 가지 일반적인 기능을 만들게 될 것입니다.

## 내용
- React 애플리케이션을 만들 때 애플리케이션의 비즈니스 로직과 관련이 없고 여러 곳에서 필요한 몇 가지 일반적인 기능을 만들게 될 것입니다.
- 여기서 로컬 상태는 현재 주문 목록을 저장하는 데 사용되고 사용 효과는 구독과 라이브 데이터 구독을 모두 처리하여 새 주문이 도착하자마자 주문 값을 업데이트합니다.
- 검사 시 둘 다 마운트 시 데이터 소스에 변경 리스너를 추가하고, 데이터 소스가 변경될 때마다 새 상태를 설정하고, 마운트 해제 시 변경 리스너를 제거합니다.
- 구성 요소가 소품을 UI로 변환하는 반면, 상위 구성 요소는 구성 요소를 다른 구성 요소로 변환합니다.
- 구독은 구독 기능을 통해 향상시키려는 래프트 구성 요소와 SelectData 함수를 사용하여 데이터 소스에서 가져오는 데이터 유형을 결정하는 고차 구성 요소입니다.
- 구독을 사용하면 제공된 구성 요소를 렌더링하는 새 구성 요소가 반환되고 해당 구성 요소에 관심 데이터 소스의 최신 항목 목록이 포함된 데이터라는 새 소품을 제공합니다.
- 이 경우 실시간 주문과 사용자 목록에서 구독 구현을 반복하지 않고도 실시간 주문과 뉴스레터 구독자를 위한 구성 요소 두 개를 사용자 지정 매개변수로 구성하여 정의하면 훨씬 더 효율적인 솔루션이 됩니다.

## 예시
- 예를 들어 다양한 권한 역할을 관리하거나 오류를 처리하거나 로깅하는 것을 생각해 보세요.

## 요약
- 구독을 사용하면 제공된 구성 요소를 렌더링하는 새 구성 요소가 반환되고 해당 구성 요소에 관심 데이터 소스의 최신 항목 목록이 포함된 데이터라는 새 소품을 제공합니다. 이 경우 실시간 주문과 사용자 목록에서 구독 구현을 반복하지 않고도 실시간 주문과 뉴스레터 구독자를 위한 구성 요소 두 개를 사용자 지정 매개변수로 구성하여 정의하면 훨씬 더 효율적인 솔루션이 됩니다.
