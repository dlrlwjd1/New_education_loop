# Component composition with children

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/advanced-react/lecture/wmsiA/component-composition-with-children)

## 개요
- 이 비디오에서는 구성 요소 구성이 왜 중요한지, 그리고 어린이 소품을 효과적으로 사용하고 감상하는 방법을 배우게 됩니다.

## 내용
- 이 비디오에서는 구성 요소 구성이 왜 중요한지, 그리고 어린이 소품을 효과적으로 사용하고 감상하는 방법을 배우게 됩니다.
- 또한 구성의 두 가지 주요 기능에 대해 알아보고 구성 요소를 더 강력하고 재사용할 수 있도록 이를 활용하는 방법을 이해하는 데 도움이 되는 몇 가지 실제 예제를 살펴보겠습니다.
- 구성 요소 구성을 가능하게 하는 두 가지 주요 기능, 즉 격리 및 전문 과정이 있습니다.
- 이를 설명하기 위해 대화 구성 요소를 사용하고 제목과 설명을 하위 항목으로 렌더링하는 확인 대화 상자 구성 요소가 정의되었습니다.
- 목표는 제목, 설명 및 경고 버튼을 포함하는 일반 대화 구성 요소를 만들어 사용자가 구성 요소 구성을 사용하는 모든 작업의 결과를 알 수 있도록 하는 것입니다.
- 첫 번째 단계는 구성 요소 구성의 전문 과정 기능을 사용하여 경고 버튼을 만드는 것입니다.
- 특수 children 소품을 사용하여 더 강력하고 재사용이 가능한 구성 요소를 만드는 데 도움이 되는 몇 가지 실용적인 예제를 살펴보았습니다.

## 예시
- 특수 children 소품을 사용하여 더 강력하고 재사용이 가능한 구성 요소를 만드는 데 도움이 되는 몇 가지 실용적인 예제를 살펴보았습니다.

## 요약
- 첫 번째 단계는 구성 요소 구성의 전문 과정 기능을 사용하여 경고 버튼을 만드는 것입니다. 특수 children 소품을 사용하여 더 강력하고 재사용이 가능한 구성 요소를 만드는 데 도움이 되는 몇 가지 실용적인 예제를 살펴보았습니다.
