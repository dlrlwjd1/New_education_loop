# Style guides

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/advanced-react/lecture/4UP3V/style-guides)

## 개요
- 그래서 사람들은 스타일 가이드가 어리석거나 쓸모가 없다고 생각하는 경우가 많으며, 실제로 스타일 가이드에 큰 가치를 부여하지 못할 수도 있습니다.

## 내용
- 그래서 사람들은 스타일 가이드가 어리석거나 쓸모가 없다고 생각하는 경우가 많으며, 실제로 스타일 가이드에 큰 가치를 부여하지 못할 수도 있습니다.
- 제 댓글의 상당수가 사실 스타일링에 관한 것인데, 제가 거슬리는 것 같거나 중요하지 않은 것에 대해 조잡하게 굴고 있는 것 같기도 합니다.
- 왜냐하면 코드를 작성할 때 우리 자신을 위해 작성하는 것이 아니라 다른 사람들을 위해 작성하는 경우가 많기 때문입니다.
- 새로운 사람이 코드를 보고 여러 번 코드를 작성했는데 코드를 계속 작성하거나 개선하거나 유지하지 않으면 다른 사람이 옵니다.
- Meta에는 회사가 다양한 코드베이스에서 유사하거나 일관된 가이드를 따르고 있는지 확인하기 위해 스타일 가이드 설정의 소유자인 팀이 있거나 여러 개 있습니다.
- 그래서 저는 엔지니어 개발자이고 코드를 작성하는 회사의 다른 모든 사람들처럼 매일 이 스타일 가이드를 따르고 사용하고 있습니다.
- 이러한 스타일 가이드를 따르고 준수하고 좋은 스타일 가이드를 배우면 응용 프로그램과 안정성, 유용성, 가독성에 큰 차이를 만들 수 있습니다.

## 예시
- 이러한 스타일 가이드를 따르고 준수하고 좋은 스타일 가이드를 배우면 응용 프로그램과 안정성, 유용성, 가독성에 큰 차이를 만들 수 있습니다.

## 요약
- 그래서 저는 엔지니어 개발자이고 코드를 작성하는 회사의 다른 모든 사람들처럼 매일 이 스타일 가이드를 따르고 사용하고 있습니다. 이러한 스타일 가이드를 따르고 준수하고 좋은 스타일 가이드를 배우면 응용 프로그램과 안정성, 유용성, 가독성에 큰 차이를 만들 수 있습니다.
