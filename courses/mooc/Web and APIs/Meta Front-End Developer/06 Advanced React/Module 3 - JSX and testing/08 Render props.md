# Render props

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/advanced-react/lecture/pkY18/render-props)

## 개요
- 지금까지 일반적인 기능을 캡슐화하는 데 사용되는 고차 구성 요소라는 기술에 대해 배웠지만 사용할 수 있는 유일한 방법은 아닙니다.

## 내용
- 지금까지 일반적인 기능을 캡슐화하는 데 사용되는 고차 구성 요소라는 기술에 대해 배웠지만 사용할 수 있는 유일한 방법은 아닙니다.
- 좀 더 정확히 말하자면, render prop이 있는 컴포넌트는 반응 요소를 반환하는 함수를 사용하고 렌더링 로직 내에서 해당 함수를 호출합니다.
- 예를 들어 상위 구성 요소가 렌더링 소품으로 새 소품을 제공하여 구성 요소를 향상시킨 것을 기억한다면 식사 제공자 구성 요소에서 이 패턴을 사용할 수 있습니다.
- 여러 구성 요소가 다른 곳에 있는 데이터에 의존할 수 있지만, 이를 필요로 하는 모든 구성 요소에서 동일한 가져오기 로직을 반복해서 구현하고 싶지는 않습니다.
- 데이터 페처는 데이터를 가져오는 한 가지 용도로만 사용되며 데이터를 받는 방법은 디저트 또는 음료 목록을 저장하는 데 사용되는 로컬 상태인 렌더링 함수의 인수를 사용하는 것입니다.
- 디저트 개수 구성요소는 특정 엔드포인트를 사용하여 디저트를 가져오고 단락 요소를 렌더링 소품으로 사용하여 디저트 수를 단일 텍스트로 표시합니다.
- 음료 수 구성 요소에도 동일하게 적용되지만 다른 U.R.L을 사용하고 대신 음료 수를 반영하는 헤더 요소를 표시한다는 차이점이 있습니다.

## 예시
- 예를 들어, 먹는 음식의 종류에 따라 다양한 식사 도구 중에서 선택할 수 있습니다.

## 요약
- 디저트 개수 구성요소는 특정 엔드포인트를 사용하여 디저트를 가져오고 단락 요소를 렌더링 소품으로 사용하여 디저트 수를 단일 텍스트로 표시합니다. 음료 수 구성 요소에도 동일하게 적용되지만 다른 U.R.L을 사용하고 대신 음료 수를 반영하는 헤더 요소를 표시한다는 차이점이 있습니다.
