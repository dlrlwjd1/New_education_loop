# Create a HOC for cursor position

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/advanced-react/lecture/g9SZk/create-a-hoc-for-cursor-position)

## 개요
- 그래서 그들은 어떤 피자가 베스트셀러이고 어떤 피자가 자주 주문되지 않는지 더 잘 이해하기 위해 몇 가지 기본 애널리틱스를 구현하기로 결정했습니다.이를 위해 방문자가 피자 섹션에 있을 때 마우스 위치를 추적하여 어떤 사진이 사람들의 관심을 끌고 어떤 사진이 간과되는지 정확히 알 수 있도록 하고자 합니다.

## 내용
- 그래서 그들은 어떤 피자가 베스트셀러이고 어떤 피자가 자주 주문되지 않는지 더 잘 이해하기 위해 몇 가지 기본 애널리틱스를 구현하기로 결정했습니다.이를 위해 방문자가 피자 섹션에 있을 때 마우스 위치를 추적하여 어떤 사진이 사람들의 관심을 끌고 어떤 사진이 간과되는지 정확히 알 수 있도록 하고자 합니다.
- 그런 다음 해당 데이터를 사용하고 다른 방식으로 표시하는 두 가지 다른 프레젠테이션 또는 구성 요소를 보여 드리겠습니다.
- 지금까지 앱 컴포넌트의 렌더링 부분에는 레스토랑의 제목을 표시하는 헤더와 패널 모스트 로거와 포인트 마우스 로거라는 두 개의 컴포넌트가 있습니다.
- 각 구성 요소에 마우스 트래킹 로직을 구현할 수도 있지만, 이렇게 하면 코드가 반복되고 서로 다른 두 곳에서 동일한 로직이 중복될 수 있다는 점을 기억하세요.
- 로직을 완성하고 현재 마우스 위치로 상태를 설정하려면 콜백에 인수로 전달되는 브라우저 이벤트 객체에서 해당 정보를 읽어야 합니다.
- 마지막으로 구현을 완료하기 위한 마지막 단계는 rapt 구성 요소에 마우스 위치라는 새 소품을 설정하여 해당 데이터에 관심이 있는 모든 구성 요소에 해당 정보를 전달하는 것입니다.
- 이전에 정의한 패널 마우스 로거와 포인트 마우스 로거의 두 구성 요소를 향상시키기 위해 HOC를 사용하여 마우스 위치 데이터를 인식하는 두 개의 새 구성 요소 버전을 만들고 각각 패널 마우스 트래커와 포인트 마우스 트래커라고 부르겠습니다.

## 예시
- 이전에 정의한 패널 마우스 로거와 포인트 마우스 로거의 두 구성 요소를 향상시키기 위해 HOC를 사용하여 마우스 위치 데이터를 인식하는 두 개의 새 구성 요소 버전을 만들고 각각 패널 마우스 트래커와 포인트 마우스 트래커라고 부르겠습니다.
