# JSX, Components and Elements

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/advanced-react/lecture/LcYik/jsx-components-and-elements)

## 개요
- 그리고 React가 JSX와 어떻게 작동하여 UI를 설명하고 사용자 친화적이고 효과적인 앱을 만드는지 완전히 명확하지 않을 수 있습니다.

## 내용
- 그리고 React가 JSX와 어떻게 작동하여 UI를 설명하고 사용자 친화적이고 효과적인 앱을 만드는지 완전히 명확하지 않을 수 있습니다.
- 이 비디오에서는 React가 JSX를 사용하여 UI를 설명하는 방법, 구성 요소와 요소 간의 차이점, React 선언적 모델의 기본 개념에 대해 알아봅니다.
- Type은 버튼과 같은 노드 유형을 정의하며, props는 구성 요소가 단일 객체에서 받는 모든 속성을 포함합니다.
- 예를 들어 Little Lemon 레스토랑 앱을 위한 로그아웃 프로세스를 만드는 경우 JSX의 로그아웃 구성 요소를 사용하여 이 작업을 수행할 수 있습니다.
- 이를 통해 Submit 버튼이 버튼으로 렌더링되는지, diff 또는 다른 것으로 렌더링되는지에 대해 걱정하지 않고 구성 요소와 dom 요소를 유형 속성으로 혼합하고 일치시킬 수 있습니다.
- react는 submit 버튼과 같은 함수 유형의 요소를 발견하면 해당 구성 요소에 주어진 props로 어떤 요소를 렌더링하는지 묻는 것을 알게 됩니다.
- 이 비디오에서는 React가 JSX를 사용하여 UI를 설명하는 방법, 구성 요소와 요소 간의 차이점, React 선언적 모델의 기본 개념을 배웠습니다.

## 예시
- 예를 들어 Little Lemon 레스토랑 앱을 위한 로그아웃 프로세스를 만드는 경우 JSX의 로그아웃 구성 요소를 사용하여 이 작업을 수행할 수 있습니다.

- react는 submit 버튼과 같은 함수 유형의 요소를 발견하면 해당 구성 요소에 주어진 props로 어떤 요소를 렌더링하는지 묻는 것을 알게 됩니다. 이 비디오에서는 React가 JSX를 사용하여 UI를 설명하는 방법, 구성 요소와 요소 간의 차이점, React 선언적 모델의 기본 개념을 배웠습니다.
