# Why React Testing Library

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/advanced-react/lecture/hEwy6/why-react-testing-library)

## 개요
- 공장에서 제품이 예상대로 작동하는지 확인하기 위해 제품을 테스트하는 것처럼 개발자도 코드를 사용하여 동일한 작업을 수행해야 합니다.

## 내용
- 공장에서 제품이 예상대로 작동하는지 확인하기 위해 제품을 테스트하는 것처럼 개발자도 코드를 사용하여 동일한 작업을 수행해야 합니다.
- 두 번째 툴은 React Testing Library로, 구현 세부 사항에 의존하지 않고 React 컴포넌트를 테스트할 수 있는 유틸리티 세트입니다.
- Create React 앱으로 새 프로젝트를 시작하면 기본적으로 Jest와 React 테스트 라이브러리가 모두 사전 설치되어 있습니다.
- 전체 document.body를 쿼리하는 것은 매우 흔한 일이기 때문에 React Testing Library는 해당 객체에 대한 참조인 스크린 객체도 내보냅니다.
- 이제 테스트 시나리오를 마무리하기 위해 텍스트 설명을 첫 번째 인수로 취하는 글로벌 테스트 함수와 두 번째 인수로 테스트에 필요한 모든 단계를 구성하는 함수를 제공합니다.
- 이 경우 GetByText 유틸리티를 사용하여 문서의 body 태그에 Little Lemon Restaurant이라는 문자열이 있는 요소를 찾을 수 있는지 묻고 해당 검색 결과를 링크 요소 개체에 저장합니다.
- 테스트 및 테스트 모범 사례의 중요성 외에도 이제 Jest와 React 테스트 라이브러리를 사용하여 React 구성 요소를 테스트하는 방법을 배웠습니다.

## 예시
- 테스트가 중요한 이유와 테스트를 만들 때의 모범 사례를 살펴봄으로써 이를 달성할 수 있습니다.

## 요약
- 이 경우 GetByText 유틸리티를 사용하여 문서의 body 태그에 Little Lemon Restaurant이라는 문자열이 있는 요소를 찾을 수 있는지 묻고 해당 검색 결과를 링크 요소 개체에 저장합니다. 테스트 및 테스트 모범 사례의 중요성 외에도 이제 Jest와 React 테스트 라이브러리를 사용하여 React 구성 요소를 테스트하는 방법을 배웠습니다.
