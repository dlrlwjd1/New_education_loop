# Module summary: JSX and Testing

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/advanced-react/lecture/EymXG/module-summary-jsx-and-testing)

## 개요
- 또한 대화를 기반으로 확인 대화 상자를 만드는 것과 같이 다른 구성 요소의 특수한 경우의 구성 요소를 정의할 수 있는 기술인 전문 과정도 소개되었습니다.

## 내용
- 또한 대화를 기반으로 확인 대화 상자를 만드는 것과 같이 다른 구성 요소의 특수한 경우의 구성 요소를 정의할 수 있는 기술인 전문 과정도 소개되었습니다.
- 또한 반응 도트 자식 도트 맵이 어린이 조작에 유용하며 반응 도트 클론 요소와 함께 사용하면 유연한 구성 요소를 만들 수 있는 강력한 구성 모델을 사용할 수 있다는 것도 배웠습니다.
- 마지막으로 react에서 스프레드 연산자를 소개하면서 스프레드 연산자를 사용하면 복사와 병합이라는 두 가지 주요 작업과 객체가 가능하다는 것을 알게 되었습니다.
- 마지막으로 스프레드 연산자를 사용하여 유연한 구성 요소를 만들 수 있는 방법을 보여주는 몇 가지 실제 예제를 살펴보았습니다.
- 첫 번째로 소개한 기법은 고차 컴포넌트 기법이었는데, 이를 통해 크로스 커팅 문제를 만들 수 있는 강력한 추상화가 가능하다는 것을 알게 되었습니다.
- 그런 다음 텍스트별 쿼리 또는 역할별 쿼리와 같은 다양한 쿼리 유형의 글로벌 문서에 대한 screen to Query와 같은 반응 테스트 라이브러리의 여러 API가 제공되었습니다.
- 마지막으로 모의 함수에 대해 호출하는 것과 요소에 속성에 대한 속성을 갖는 것과 같은 기대와 주장에 대한 다양한 문제에 대해 배웠습니다.

## 예시
- 리액트 테스팅 라이브러리가 이 모든 것을 염두에 두고 어떻게 설계되었는지 확인하면서 테스트에 관한 모범 사례를 제시받았습니다.

## 요약
- 그런 다음 텍스트별 쿼리 또는 역할별 쿼리와 같은 다양한 쿼리 유형의 글로벌 문서에 대한 screen to Query와 같은 반응 테스트 라이브러리의 여러 API가 제공되었습니다. 마지막으로 모의 함수에 대해 호출하는 것과 요소에 속성에 대한 속성을 갖는 것과 같은 기대와 주장에 대한 다양한 문제에 대해 배웠습니다.
