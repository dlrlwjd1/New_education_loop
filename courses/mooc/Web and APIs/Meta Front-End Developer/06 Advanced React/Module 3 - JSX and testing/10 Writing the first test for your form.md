# Writing the first test for your form

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/advanced-react/lecture/IUGpz/writing-the-first-test-for-your-form)

## 개요
- 또한 변경 사항이 수행될 때마다 테스트 스위트가 실행되어 잘못된 업데이트로 인해 발생할 수 있는 잠재적 오류를 찾아낼 수 있도록 이 새로운 로직을 자동화된 테스트로 보호하고자 합니다.

## 내용
- 또한 변경 사항이 수행될 때마다 테스트 스위트가 실행되어 잘못된 업데이트로 인해 발생할 수 있는 잠재적 오류를 찾아낼 수 있도록 이 새로운 로직을 자동화된 테스트로 보호하고자 합니다.
- Little Lemon이 원하는 요구 사항을 충족하기 위해 점수가 5점 미만이면 제출 버튼이 비활성화되므로 사용자는 최소 10자 이상의 댓글을 추가해야 합니다.
- 피드백 양식은 HTML 양식을 나타내며 로컬 상태, 정렬된 입력 및 텍스트 영역을 통해 제어되는 두 개의 구성 요소를 포함합니다.
- 첫 번째는 “버튼 비활성화” 로직은 해당 상태를 제어하는 변수이며, 점수가 5보다 낮고 댓글이 10자 미만인 경우 true로 설정된다는 것입니다.
- 테스트 시나리오는 점수가 5점 미만이고 추가 피드백이 없거나 너무 짧은 경우 사용자가 양식을 즉시 제출하지 못하도록 하는 것을 확인하는 것입니다.
- Screen은 전체 페이지를 나타내는 반응 테스트 라이브러리의 유틸리티 객체로, 기본적으로 루트 문서에 단어 점수가 포함된 텍스트의 레이블 태그를 찾은 다음 해당 레이블과 관련된 입력 요소를 반환하도록 요청하는 것으로 해석됩니다.
- 양식, 제출을 시뮬레이션하려면 버튼 요소를 찾고 다른 쿼리 방법을 어떻게 사용하고 있는지 관찰해야 합니다.

## 예시
- 테스트 시나리오를 이미 작성했으므로 이제 테스트가 어떻게 구성되어 있는지 단계별로 이해할 수 있도록 각 코드 줄을 안내해 드리겠습니다.

## 요약
- Screen은 전체 페이지를 나타내는 반응 테스트 라이브러리의 유틸리티 객체로, 기본적으로 루트 문서에 단어 점수가 포함된 텍스트의 레이블 태그를 찾은 다음 해당 레이블과 관련된 입력 요소를 반환하도록 요청하는 것으로 해석됩니다. 양식, 제출을 시뮬레이션하려면 버튼 요소를 찾고 다른 쿼리 방법을 어떻게 사용하고 있는지 관찰해야 합니다.
