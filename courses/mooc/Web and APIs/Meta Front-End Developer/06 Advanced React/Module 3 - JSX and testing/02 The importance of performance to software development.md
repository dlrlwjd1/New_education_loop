# The importance of performance to software development

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/advanced-react/lecture/5fVsN/the-importance-of-performance-to-software-development)

## 개요
- 물론 때로는 성능을 향상시키기 위해 전체 응용 프로그램을 다시 작성하고 다시 시작해야 할 수도 있습니다.

## 내용
- 물론 때로는 성능을 향상시키기 위해 전체 응용 프로그램을 다시 작성하고 다시 시작해야 할 수도 있습니다.
- Meta에서는 사용자의 다양한 다양성과 다양한 배경, 그리고 사용자가 우리 제품에 액세스하는 데 사용할 수 있는 기술에 대해 생각하려고 노력했습니다.
- 바로 알아차리지 못할 수도 있고, 보여주고 자랑할 수 없을 수도 있는 보이지 않는 것이 바로 성능이죠.
- 하지만 사실 정말 중요하죠.응용 프로그램의 기본 부분으로, 그것 없이는 응용 프로그램을 실제로 사용할 수 없습니다.
- React가 정말 잘하는 것은 변경 사항을 현지화하여 작은 텍스트를 변경해야 할 경우 전체 페이지를 다시 작성할 필요 없이 작은 텍스트를 학습시키는 작업만 할 수 있다는 것입니다.
- 엔지니어와 제품 관리자, 디자이너들은 모두 응용 프로그램을 개발하는 동안 사용자의 입장에서 생각하고 응용 프로그램을 사용할 때 겪게 되는 경험을 실제로 느끼기 위해 응용 프로그램을 최대한 많이 사용합니다.
- 메모이제이션을 사용하거나 처리의 일부를 백엔드에 위임하는 것과 같습니다.이러한 디자인 패턴을 찾아 응용 프로그램에 이러한 디자인 패턴을 도입할 수 있는 방법을 찾는 것이 좋습니다.

## 예시
- 메모이제이션을 사용하거나 처리의 일부를 백엔드에 위임하는 것과 같습니다.이러한 디자인 패턴을 찾아 응용 프로그램에 이러한 디자인 패턴을 도입할 수 있는 방법을 찾는 것이 좋습니다.
