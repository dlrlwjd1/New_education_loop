# Spread Attributes

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/advanced-react/lecture/bCIpF/spread-attributes)

## 개요
- 유연한 구성 요소를 설계하는 방법 및 스프레드 연산자를 사용할 때의 주의 사항 작은 레몬 레스토랑에서 사용자가 계정 유무에 따라 가입하거나 로그인할 수 있는 간단한 환영 화면을 원한다고 상상해 보십시오.

## 내용
- 유연한 구성 요소를 설계하는 방법 및 스프레드 연산자를 사용할 때의 주의 사항 작은 레몬 레스토랑에서 사용자가 계정 유무에 따라 가입하거나 로그인할 수 있는 간단한 환영 화면을 원한다고 상상해 보십시오.
- 이 구현을 위해 기본 HTML 버튼 요소를 캡슐화하고 기본 요소와 동일한 소품을 사용하는 버튼 구성 요소를 정의할 수 있습니다.
- 다음은 스프레드 연산자를 사용하여 네이티브 버튼에 속하는 모든 소품을 그룹화하고 이 구성 요소에 대해 정의한 사용자 지정 소품과 반응별, 유형 및 Children을 명시적으로 추출하는 명확한 예입니다.
- 두 번째 예는 제가 직접 만든 사용자 지정 버튼 구성 요소를 렌더링하는 로그인 버튼 구성 요소입니다.
- 이 로그인 버튼은 버튼 구성 요소 ( 이 경우 유형 및 클릭 시 버튼 구성 요소) 의 일부 소품을 고정하는 동시에 스프레드 연산자를 사용하여 기본 버튼 소품을 전달하여 사전 구성을 수행합니다.
- 이제 앱 구성 요소가 두 버튼을 렌더링하고 가입에 버튼 구성 요소를 사용하고 로그인에 로그인 버튼 구성 요소를 사용합니다.
- 스프레드 오퍼레이터는 특히 소품을 필요로 하는 다른 구성 요소에 자동으로 전달하고 소비자에게 멋진 구성 요소를 제공할 때 보다 유연한 구성 요소를 만들 수 있는 훌륭한 도구입니다.

## 예시
- 스프레드 오퍼레이터는 특히 소품을 필요로 하는 다른 구성 요소에 자동으로 전달하고 소비자에게 멋진 구성 요소를 제공할 때 보다 유연한 구성 요소를 만들 수 있는 훌륭한 도구입니다.
