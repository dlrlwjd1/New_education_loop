# Render a simple list component

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/advanced-react/lecture/mXrn5/render-a-simple-list-component)

## 개요
- React를 사용하면 모든 항목 목록을 React 컴포넌트 컬렉션으로 변환할 수 있다는 사실을 알고 계셨나요?

## 내용
- React를 사용하면 모든 항목 목록을 React 컴포넌트 컬렉션으로 변환할 수 있다는 사실을 알고 계셨나요?
- 앞서 소개한 작은 레몬의 디저트 목록을 참고하여, 온라인 방문자에게 전용 섹션에서 최고의 디저트를 살짝 엿볼 수 있는 기회를 제공하여 주문을 유도하고자 하는 레스토랑을 상상해 보십시오.
- 이 비디오에서는 JSX 구문의 map 함수를 사용하여 React에서 이와 같은 요소 컬렉션을 표시하는 방법을 배웁니다.
- JSX는 React가 사용자 인터페이스 또는 UI를 설명하는 데 사용하는 JavaScript의 특수 구문 확장이며 컴포넌트는 JSX를 반환하는 함수라는 점을 기억하세요.
- 목록 항목의 경우 목록 항목 또는 LI 시맨틱 태그를 선택하는 것이 가장 좋습니다.
- 이것은 이 컴포넌트의 렌더링 메서드에 포함될 JSX 변환이므로 데이터 (이 경우 변수 항목 텍스트의 값인 각 목록 항목의 텍스트) 를 줄 바꿈할 때는 중괄호를 사용해야 합니다.
- 마지막 단계는 render 메서드로 이동하여 목록 항목을 HTML 목록 래퍼 구성 요소, 정렬되지 않은 목록 또는 UL에 포함시키는 것입니다.

## 예시
- 이 데모에서는 리틀 레몬 베스트 디저트 목록을 다시 사용하겠습니다.

## 요약
- 이것은 이 컴포넌트의 렌더링 메서드에 포함될 JSX 변환이므로 데이터 (이 경우 변수 항목 텍스트의 값인 각 목록 항목의 텍스트) 를 줄 바꿈할 때는 중괄호를 사용해야 합니다. 마지막 단계는 render 메서드로 이동하여 목록 항목을 HTML 목록 래퍼 구성 요소, 정렬되지 않은 목록 또는 UL에 포함시키는 것입니다.
