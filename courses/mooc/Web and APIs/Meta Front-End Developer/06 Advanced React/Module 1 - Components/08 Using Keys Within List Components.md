# Using Keys Within List Components

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/advanced-react/lecture/qZtMh/using-keys-within-list-components)

## 개요
- 이 비디오에서는 목록 구성 요소 내에서 키를 올바르게 사용하고 실제 예제를 통해 반응하는 방법을 배웁니다.

## 내용
- 이 비디오에서는 목록 구성 요소 내에서 키를 올바르게 사용하고 실제 예제를 통해 반응하는 방법을 배웁니다.
- 이를 위해 저는 텍스트 입력으로 표시되는 편집 가능한 두 개의 할 일과 할 일의 순서를 반대로 바꾸는 버튼이 있는 아주 간단한 할 일 목록 앱을 만들었습니다.
- todo 컴포넌트는 기본적으로 id, 값을 입력하기 위한 텍스트 입력, 생성 날짜가 있는 테이블 행입니다.
- 마지막으로, 사용자 인터페이스용 jsx에는 래핑 div, todos의 순서를 반대로 바꾸는 버튼, 각 테이블 행이 todo 작업인 테이블이 있습니다.
- 개발 모드에서 애플리케이션을 실행할 때 React는 콘솔 오류와 같은 컨텍스트 경고를 통해 애플리케이션의 잠재적 문제에 대한 솔루션을 제공하는 역할을 훌륭하게 수행합니다.
- 그럼 정확히 무슨 일이 벌어지고 있는 걸까요?다시 코드로 돌아가서 각 todo의 jsx를 살펴보면 todos의 순서를 반대로 바꾸면 id와 createdAt prop이 변경되었습니다.
- 이제 어떻게 고칠 수 있을까요?다시 핵심 요구 사항으로 돌아와서 말씀드리자면, 목록에서 어떤 위치에 있든 상관없이 각 할 일을 정확하게 식별할 수 있는 고유해야 합니다.
