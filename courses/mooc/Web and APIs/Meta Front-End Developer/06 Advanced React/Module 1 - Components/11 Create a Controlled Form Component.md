# Create a Controlled Form Component

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/advanced-react/lecture/JjN0j/create-a-controlled-form-component)

## 개요
- 그렇다면 나중에 체험에 대한 피드백을 제공할 수 있는 특정 페이지로 연결되는 링크를 제공하는 친절한 이메일을 받았을 수도 있습니다.

## 내용
- 그렇다면 나중에 체험에 대한 피드백을 제공할 수 있는 특정 페이지로 연결되는 링크를 제공하는 친절한 이메일을 받았을 수도 있습니다.
- 이 예제의 요구 사항은 사용자가 0-10의 점수를 제공한 다음 며칠 전에 즐겼던 음식이 얼마나 맛있었는지 셰프에게 알려주는 추가 설명을 제공할 수 있는 인터페이스입니다.
- 이 작업을 수행할 수 있는 방법은 여러 가지가 있지만 이 사용 사례에서는 사용자에게 간단한 슬라이더를 제공하는 범위 입력을 선택해 보겠습니다.
- 셰프의 레시피가 일반적으로 타의 추종을 불허한다는 것을 알고 있기 때문에 사용자가 원할 경우 슬라이더를 조작할 때 점수를 10에서 낮출 수 있기 때문입니다.
- 이제 범위 입력에서 value prop을 사용하여 상태를 연결하고 onchange를 사용하여 변경 사항을 수신하고 그에 따라 상태를 업데이트해야 합니다.
- 이제 제대로 렌더링되었으니 상태를 value prop에 연결하고 onchange를 통해 변경 사항을 업데이트해야 합니다.
- 제어된 컴포넌트와 사용자 지정 검증을 사용하여 사용자가 원활한 경험을 할 수 있도록 React로 피드백 양식을 작성하는 방법을 배웠습니다.

## 예시
- 이 작업을 수행할 수 있는 방법은 여러 가지가 있지만 이 사용 사례에서는 사용자에게 간단한 슬라이더를 제공하는 범위 입력을 선택해 보겠습니다.

## 요약
- 이제 제대로 렌더링되었으니 상태를 value prop에 연결하고 onchange를 통해 변경 사항을 업데이트해야 합니다. 제어된 컴포넌트와 사용자 지정 검증을 사용하여 사용자가 원활한 경험을 할 수 있도록 React로 피드백 양식을 작성하는 방법을 배웠습니다.
