# Introduction to the course

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/advanced-react/lecture/9sOxn/introduction-to-the-course)

## 개요
- 첫 번째 모듈에서는 React에서 목록을 렌더링 및 변환하고 양식을 사용하는 방법을 배우는 것으로 시작합니다.

## 내용
- 첫 번째 모듈에서는 React에서 목록을 렌더링 및 변환하고 양식을 사용하는 방법을 배우는 것으로 시작합니다.
- 그런 다음 React에서 변환을 유도하는 필수 구성 요소인 키라는 식별자에 대해 배우게 됩니다.
- React에서 제어 양식 구성 요소를 만들고 자체 피드백 양식을 구현하는 데 중점을 두고 제어 구성 요소에 대해 자세히 알아보겠습니다.
- 여기에는 React 후크의 사용과 목적, React에서의 후크 사용 규칙, React에서 커스텀 후크를 빌드하는 방법을 배우는 것이 포함됩니다.
- 또한 포럼의 동작을 테스트하고 테스트의 실제 응용 프로그램을 탐색하는 데 중점을 두고 React 테스트 라이브러리를 사용하여 통합 테스트를 작성하는 방법을 배우게 됩니다.
- 이 모듈에서는 리틀 레몬 (Little lemon) 이라는 레스토랑을 기반으로 한 이론적 개념의 실제 사례를 살펴보고 지식과 기술을 테스트하기 위한 활동을 경험하게 됩니다.
- 마지막 모듈에서는 자체 포트폴리오 앱을 코딩하는 랩 프로젝트에서 학습한 내용과 실제 고급 React 기술을 시연할 수 있습니다.

## 예시
- 예를 들어 useState, UseEffect 및 UseReducer 후크의 용도와 사용 방법에 대해 배우게 됩니다.

## 요약
- 이 모듈에서는 리틀 레몬 (Little lemon) 이라는 레스토랑을 기반으로 한 이론적 개념의 실제 사례를 살펴보고 지식과 기술을 테스트하기 위한 활동을 경험하게 됩니다. 마지막 모듈에서는 자체 포트폴리오 앱을 코딩하는 랩 프로젝트에서 학습한 내용과 실제 고급 React 기술을 시연할 수 있습니다.
