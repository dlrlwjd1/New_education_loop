# What is Context, and why is it used?

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/advanced-react/lecture/8q0SY/what-is-context-and-why-is-it-used)

## 개요
- 이러한 시나리오에서는 React가 데이터를 전달하기 위해 제공하는 props를 사용하는 것이 항상 효과적인 것은 아닙니다.

## 내용
- 이러한 시나리오에서는 React가 데이터를 전달하기 위해 제공하는 props를 사용하는 것이 항상 효과적인 것은 아닙니다.
- Little Lemon의 음식 주문 앱이 모든 요소의 배경과 텍스트 색상을 변경하는 밝거나 어두운 테마를 제공하거나 여러 구성 요소가 알아야 하는 방문자의 지리적 위치에 따라 특정 지역과 같은 일반적인 기본 설정을 제공한다고 가정해 보겠습니다.
- 하지만 이 시나리오에서는 데이터를 실제로 필요로 하지 않고 프록시 역할만 하는 중간 구성 요소를 사용하여 트리의 모든 수준에 데이터를 명시적으로 전달해야 하기 때문에 번거로울 수 있습니다.
- 컨텍스트는 모든 수준에서 props를 수동으로 전달하지 않고도 구성 요소 트리를 통해 데이터를 전달할 수 있는 대체 방법을 제공합니다.
- 인증된 사용자는 여러 구성 요소 간에 공유해야 하는 글로벌 데이터의 특성에 속하기 때문에 컨텍스트가 작업을 위한 완벽한 도구라는 분명한 예입니다.
- UserContext.Provider 구성 요소는 소비 구성 요소가 컨텍스트 변경을 구독할 수 있도록 하는 구성 요소입니다.
- 마지막 단계는 사용자 이름을 표시해야 하는 위치 ( 로그인한 사용자 구성 요소 및 페이지 구성 요소) 에서 사용자 컨텍스트를 사용하는 것입니다.

## 예시
- 이러한 시나리오에서는 React가 데이터를 전달하기 위해 제공하는 props를 사용하는 것이 항상 효과적인 것은 아닙니다.

## 요약
- UserContext.Provider 구성 요소는 소비 구성 요소가 컨텍스트 변경을 구독할 수 있도록 하는 구성 요소입니다. 마지막 단계는 사용자 이름을 표시해야 하는 위치 ( 로그인한 사용자 구성 요소 및 페이지 구성 요소) 에서 사용자 컨텍스트를 사용하는 것입니다.
