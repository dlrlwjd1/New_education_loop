# What are Keys in React?

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/advanced-react/lecture/8xcxd/what-are-keys-in-react)

## 개요
- React를 사용할 때 얻을 수 있는 중요한 이점 중 하나는 사용자 인터페이스 또는 UI의 업데이트를 자동으로 최적화할 수 있다는 것입니다.

## 내용
- React를 사용할 때 얻을 수 있는 중요한 이점 중 하나는 사용자 인터페이스 또는 UI의 업데이트를 자동으로 최적화할 수 있다는 것입니다.
- 개발자로서 UI가 변경될 때 React가 어떻게 동작할지 지정하기 위해 추가 단계를 거쳐야 하는 시나리오가 있기 때문에 React도 마찬가지입니다.
- 이 동영상에서는 요소 목록을 처리할 때 키를 사용하는 방법을 알아보고, 키를 사용하여 목록의 요소를 식별하고 구분하는 방법, 목록 항목에 적합한 키를 결정하는 방법, 키를 잘못 사용하는 것이 앱 성능에 미치는 영향을 알아봅니다.
- 이 알고리즘은 대부분 완벽하게 작동하지만 앞서 언급한 것처럼 React가 업데이트에 가장 적합한 경로를 찾기 위해 중요한 가정을 하지 못하는 경우가 있습니다.
- 그러나 리스트의 시작 부분에 새 요소를 삽입하면 React가 맥주와 와인 하위 트리를 그대로 유지할 수 있다는 사실을 깨닫지 못하고 모든 어린이를 변경하기 때문에 알고리즘의 성능이 저하됩니다.
- 최후의 수단으로 항목 색인을 사용할 수 있습니다.목록에서 각 요소의 위치를 결정하므로 중복이 발생하지 않도록 보장하지만 목록에 정렬 기능이 있거나 사용자가 항목을 추가 또는 제거할 수 있는 경우와 같이 항목 순서가 변경될 수 있는 경우에는 키에 인덱스를 사용하지 않는 것이 좋습니다.
- 이제 React의 키와 항목 목록을 처리할 때 키를 사용하는 방법 ( 예: 키를 사용하여 목록 요소를 구분하는 방법, 올바른 키 선택, 잘못된 키 사용이 앱 성능에 미치는 영향) 에 대해 알아보았습니다.가장 중요한 교훈은 항상 형제 자매들 사이에서 고유하다는 것이 보장되는 키를 사용하는 것입니다.

## 예시
- 개발자로서 UI가 변경될 때 React가 어떻게 동작할지 지정하기 위해 추가 단계를 거쳐야 하는 시나리오가 있기 때문에 React도 마찬가지입니다.
