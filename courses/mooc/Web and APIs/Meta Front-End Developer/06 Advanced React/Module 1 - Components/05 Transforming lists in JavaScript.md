# Transforming lists in JavaScript

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/advanced-react/lecture/ATGhd/transforming-lists-in-javascript)

## 개요
- 앱을 사용하여 음식을 주문하고 원하는 메뉴를 찾기 위해 다양한 메뉴를 스크롤해 본 적이 있을 수 있습니다.

## 내용
- 앱을 사용하여 음식을 주문하고 원하는 메뉴를 찾기 위해 다양한 메뉴를 스크롤해 본 적이 있을 수 있습니다.
- 이 비디오에서는 JavaScript에서 map 메서드를 사용하여 데이터 목록을 변환하는 방법을 배웁니다.
- 리틀 레몬 (Little Lemon) 이라는 레스토랑이 인기 있는 디저트 목록을 표시하고 싶다고 가정해 봅시다.
- 이제 Little Lemon이 외부 서비스를 사용하여 사용자들이 가장 많이 요청한 디저트 목록을 쿼리한다고 가정해 보겠습니다.
- JavaScript의 map 메서드를 사용하여 이 디저트 항목 목록을 변환하는 방법을 살펴보겠습니다.
- JavaScript는 배열과 함께 사용하여 다양한 작업을 수행할 수 있는 다양한 메서드를 제공합니다.
- 맵 메서드를 사용하여 JavaScript에서 데이터를 변환하는 방법을 방금 배웠습니다.

## 예시
- 맵 메서드를 사용하여 JavaScript에서 데이터를 변환하는 방법을 방금 배웠습니다.

## 요약
- JavaScript는 배열과 함께 사용하여 다양한 작업을 수행할 수 있는 다양한 메서드를 제공합니다. 맵 메서드를 사용하여 JavaScript에서 데이터를 변환하는 방법을 방금 배웠습니다.
