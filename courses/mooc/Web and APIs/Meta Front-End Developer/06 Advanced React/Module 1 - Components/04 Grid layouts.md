# Grid layouts

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/advanced-react/lecture/7Pkfw/grid-layouts)

## 개요
- 버튼의 스타일을 지정하거나 행에 스타일을 지정하거나 그리드에 스타일을 지정할 때 일반적으로 필요한 프리미티브가 많이 있습니다.

## 내용
- 버튼의 스타일을 지정하거나 행에 스타일을 지정하거나 그리드에 스타일을 지정할 때 일반적으로 필요한 프리미티브가 많이 있습니다.
- 그리고 그리드가 있는데, 이는 이전에 매우 복잡한 작업이었던 그리드에 항목을 배치할 수 있게 해주는 CSS 레이아웃 사양입니다.
- 간단하게 들리겠지만 이 항목이 그리드의 이 부분, 이 행, 이 행에 있어야 반응성이 더 뛰어난 앱을 만들 수 있게 해주고 싶다고 말씀하실 수 있습니다.
- 그런 다음 이전 레이아웃 접근 방식을 사용하면 JavaScript에서 많은 계산을 수행하여 이미지의 너비와 높이, 이미지를 배치할 위치, 화면에 이미지를 배치하는 방법을 알아야 합니다.
- 하지만 CSS 그리드가 있다면 단 한 줄의 코드로 반응성과 안정성이 뛰어난 고성능 레이아웃을 만들 수 있습니다.
- 하나의 레이아웃과 하나의 레이아웃이 어떻게 작동하는지 자세히 알면 그 지식을 바탕으로 나중에 만들고 싶은 레이아웃을 쉽게 배울 수 있습니다.
- 더 중요한 것은 여기서 여러분이 그리드 경력을 쌓고 다른 레이아웃 사양과 차세대 앱을 구축하는 방법을 배울 수 있는 탄탄한 기반을 다지기를 바랍니다.

## 예시
- 예를 들어 반응형을 원하는 테이블 기반 레이아웃에서 그리드 사양을 한 곳에서 사용할 수 있습니다.

## 요약
- 하나의 레이아웃과 하나의 레이아웃이 어떻게 작동하는지 자세히 알면 그 지식을 바탕으로 나중에 만들고 싶은 레이아웃을 쉽게 배울 수 있습니다. 더 중요한 것은 여기서 여러분이 그리드 경력을 쌓고 다른 레이아웃 사양과 차세대 앱을 구축하는 방법을 배울 수 있는 탄탄한 기반을 다지기를 바랍니다.
