# What are controlled components?

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/advanced-react/lecture/sAx7F/what-are-controlled-components)

## 개요
- 이 비디오에서는 React의 제어 컴포넌트의 개념과 외부 프로세스에서 제어되는 컴포넌트가 어떻게 사용되는지 알아봅니다.

## 내용
- 이 비디오에서는 React의 제어 컴포넌트의 개념과 외부 프로세스에서 제어되는 컴포넌트가 어떻게 사용되는지 알아봅니다.
- HTML 폼의 기본 개념과 포럼을 React 컴포넌트로 만드는 방법 React 애플리케이션에서 HTML 양식은 다른 DOM 요소와 다르게 작동합니다.
- 제어 컴포넌트는 React state를 사용하여 언제든지 폼 요소의 상태를 완전히 제어할 수 있는 선언적 애플리케이션 프로그래밍 인터페이스 또는 API를 제공하는 컴포넌트 세트입니다.
- DOM 요소의 기본 상태에 의존하는 대신 React 상태를 단일 정보 소스로 삼아 양식 요소의 표시된 값을 항상 제어합니다.
- 마지막으로, 양식이 제출될 때마다 양식 값을 제어하려면 양식 HTML 요소에 OnSubmit 소품을 사용할 수 있습니다.
- React는 대부분의 입력 유형의 제어 버전을 제공하며 포럼 구현을 위해 제어된 컴포넌트를 사용할 것을 권장합니다.
- 또한 HTML 폼의 기본 개념과 양식을 React 컴포넌트로 만드는 방법을 살펴보았습니다.

## 예시
- 예를 들어, 리틀 레몬 레스토랑의 고객은 양식을 사용하여 웹 사이트에서 테이블을 예약할 수 있습니다.

## 요약
- React는 대부분의 입력 유형의 제어 버전을 제공하며 포럼 구현을 위해 제어된 컴포넌트를 사용할 것을 권장합니다. 또한 HTML 폼의 기본 개념과 양식을 React 컴포넌트로 만드는 방법을 살펴보았습니다.
