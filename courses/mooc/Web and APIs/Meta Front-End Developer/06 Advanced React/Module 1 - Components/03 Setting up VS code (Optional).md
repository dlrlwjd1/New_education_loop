# Setting up VS code (Optional)

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/advanced-react/lecture/krRHe/setting-up-vs-code-optional)

## 개요
- 이 비디오가 끝나면 Windows 운영 체제에 VS Code, Node.js 및 코드 러너 확장 프로그램을 설치할 수 있습니다.

## 내용
- 이 비디오가 끝나면 Windows 운영 체제에 VS Code, Node.js 및 코드 러너 확장 프로그램을 설치할 수 있습니다.
- Node.js VS Code에서 새 JavaScript 파일을 시작하고 코드 러너 확장을 사용하여 파일을 실행하고 JavaScript에서 console.log 가 수행하는 작업을 설명합니다.
- 먼저 브라우저에서 검색 엔진을 열고 VS 코드 또는 Visual Studio Code라는 용어를 검색합니다.
- 바탕 화면 아이콘 만들기, Windows 탐색기 파일 컨텍스트 메뉴에 코드로 열기 작업 추가, Windows 탐색기 디렉터리 컨텍스트 메뉴에 코드로 열기 작업 추가 추가 작업을 선택하고 나면 “다음”을 클릭합니다.
- 그런 다음 “언어 선택”을 클릭하고 언어 목록에서 JavaScript를 선택합니다.검색 창에 JS를 입력하여 검색 결과를 좁힐 수도 있습니다.
- 이제 Windows 운영 체제에 Visual Studio 또는 VS Code, Node.js 및 코드 러너 확장을 설치하는 방법을 알게 되었습니다.
- Node.js VS Code에서 새 JavaScript 파일을 시작하고 코드 러너 확장을 사용하여 파일을 실행할 수도 있습니다.

## 예시
- Node.js VS Code에서 새 JavaScript 파일을 시작하고 코드 러너 확장을 사용하여 파일을 실행할 수도 있습니다.

## 요약
- 이제 Windows 운영 체제에 Visual Studio 또는 VS Code, Node.js 및 코드 러너 확장을 설치하는 방법을 알게 되었습니다. Node.js VS Code에서 새 JavaScript 파일을 시작하고 코드 러너 확장을 사용하여 파일을 실행할 수도 있습니다.
