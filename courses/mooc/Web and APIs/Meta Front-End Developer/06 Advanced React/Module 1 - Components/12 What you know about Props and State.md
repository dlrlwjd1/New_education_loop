# What you know about Props and State

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/advanced-react/lecture/74u77/what-you-know-about-props-and-state)

## 개요
- 이 비유에서 새 로케이션의 블루프린트는 리액트 컴포넌트인 반면, 각 로케이션의 구체적인 구성 또는 리액트 프롭과 스테이트가 나타내는 내용은 다음과 같습니다.

## 내용
- 이 비유에서 새 로케이션의 블루프린트는 리액트 컴포넌트인 반면, 각 로케이션의 구체적인 구성 또는 리액트 프롭과 스테이트가 나타내는 내용은 다음과 같습니다.
- 따라서 props란 무엇이며 state props와 state는 모두 일반 자바스크립트 또는 Js 객체입니다.
- 또한 어떤 것이 props 또는 state에 속하는지, 언제 상태가 필요한지 식별하는 방법과 props와 state를 기반으로 다양한 반응 컴포넌트를 구별하는 방법도 배우게 됩니다.
- props와 state는 모두 렌더링 출력에 영향을 주지만, 컴포넌트 내에서 선언된 변수처럼 컴포넌트 내에서 상태가 관리되는 함수의 매개변수처럼 props가 컴포넌트에 전달된다는 점에서 한 가지 중요한 차이점이 있습니다.
- props와 state는 함께 html 출력이 props에서 파생되는 원시 데이터를 구성하며 상태는 일반 Js 객체이며 결정적입니다.
- 경험상 구성 요소가 특정 시점에 속성 중 하나를 변경해야 하는 경우 해당 속성은 해당 상태의 일부여야 합니다.
- 따라서 매우 쉽게 따라하고 테스트할 수 있는 반면, 스테이트풀 컴포넌트에는 props와 state가 모두 있습니다.

## 예시
- 따라서 매우 쉽게 따라하고 테스트할 수 있는 반면, 스테이트풀 컴포넌트에는 props와 state가 모두 있습니다.

## 요약
- 경험상 구성 요소가 특정 시점에 속성 중 하나를 변경해야 하는 경우 해당 속성은 해당 상태의 일부여야 합니다. 따라서 매우 쉽게 따라하고 테스트할 수 있는 반면, 스테이트풀 컴포넌트에는 props와 state가 모두 있습니다.
