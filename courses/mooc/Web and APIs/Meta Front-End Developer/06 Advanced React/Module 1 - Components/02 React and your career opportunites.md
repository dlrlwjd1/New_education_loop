# React and your career opportunites

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/advanced-react/lecture/TFsIp/react-and-your-career-opportunites)

## 개요
- Meta에서 경력을 쌓으면서 쌓은 거의 모든 것이 React에서 구축되었습니다.

## 내용
- Meta에서 경력을 쌓으면서 쌓은 거의 모든 것이 React에서 구축되었습니다.
- Facebook을 사용하든 Instagram을 사용하든 상관없이 Meta 제품을 사용하는 경우 메뉴의 버튼과 클릭은 모두 React 프레임워크를 통해 처리되는 모든 이벤트와 구성 요소일 가능성이 큽니다.
- 2018년의 트렌드를 살펴보면 React는 실제로 성장하여 이전에 가장 인기 있었던 jQuery라는 웹 프레임워크를 넘어섰고, React는 가장 많은 검색 키워드가 되었습니다.
- 웹에서 React 컴포넌트를 사용하는 다양한 방법 외에도 실제로 React를 사용하여 Android와 iOS에서 모바일 컴포넌트를 개발할 수 있습니다.
- 가장 최근에 React는 사람들이 웹과 모바일에서 가상 현실 애플리케이션을 개발하는 데 사용되는 것과 동일한 프레임워크를 일관되게 사용할 수 있는 가상 현실과 같은 VR 컴포넌트를 개발하는 방법을 출시하고 있습니다.
- 이러한 지식을 갖추면 경력을 쌓는 데 정말 도움이 될 것이며 그러한 프레임워크를 사용하는 방법을 배우기가 더 쉬워질 것입니다.
- 처음에는 조금 복잡하거나 벅차게 느껴질 수도 있고 , 이해가 안 되는 것들이 있을 수도 있지만, 그것을 통해 힘을 얻기만 하면 이러한 원리를 배우기가 훨씬 쉬워질 것입니다.
