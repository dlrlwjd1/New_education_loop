# Module summary: Components

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/advanced-react/lecture/okeXQ/module-summary-components)

## 개요
- 다음으로 맵 메서드 함수를 JSX와 함께 사용하여 컴포넌트 목록을 렌더링하고 react로 요소 컬렉션을 변환하는 방법을 배웠습니다.

## 내용
- 다음으로 맵 메서드 함수를 JSX와 함께 사용하여 컴포넌트 목록을 렌더링하고 react로 요소 컬렉션을 변환하는 방법을 배웠습니다.
- 키는 어떤 항목이 변경, 추가 또는 제거되었는지 판단하기 위해 반응하는 데 도움이 될 뿐만 아니라 업데이트가 발생할 때 특정 요소를 처리하는 방법과 내부 상태를 보존해야 하는지 여부를 반응에 지시하는 식별자라는 것을 배웠습니다.
- 또한 항목 목록을 처리할 때 UI가 변경될 때 반응에 어떻게 행동해야 하는지 알려주는 명시적인 정보를 제공해야 할 때 키를 사용할 수 있다는 것도 알게 되었습니다.
- 그런 다음 최후의 수단으로 인덱스를 키로 사용할 수 있지만 목록 항목의 순서가 변경될 경우 성능에 부정적인 영향을 미칠 수 있다는 사실을 알게 되었습니다.
- React state를 사용하여 언제든지 양식 요소의 상태를 완전히 제어할 수 있는 선언적 API를 제공하는 구성 요소 집합인 제어 구성 요소를 처음 접했습니다.
- 또한 제어된 구성 요소가 제어되지 않은 구성 요소와 비교할 때 어떤 이점이 있는지도 알게 되었습니다.
- 이 문제에 대한 해결책으로 Context API를 알게 되었고, 이를 사용하여 글로벌 상태를 캡슐화하고 구성 요소 간에 소품을 수동으로 전달하지 않는 방법을 알게 되었습니다.

## 예시
- 마지막으로, 키의 개념을 이해한 후 사용 사례에 따라 올바른 키를 선택하는 데 도움이 되는 실용적인 가이드라인도 알게 되었습니다.

## 요약
- 또한 제어된 구성 요소가 제어되지 않은 구성 요소와 비교할 때 어떤 이점이 있는지도 알게 되었습니다. 이 문제에 대한 해결책으로 Context API를 알게 되었고, 이를 사용하여 글로벌 상태를 캡슐화하고 구성 요소 간에 소품을 수동으로 전달하지 않는 방법을 알게 되었습니다.
