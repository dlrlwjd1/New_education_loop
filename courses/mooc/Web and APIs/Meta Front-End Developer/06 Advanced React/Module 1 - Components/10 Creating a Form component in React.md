# Creating a Form component in React

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/advanced-react/lecture/VpQWd/creating-a-form-component-in-react)

## 개요
- React를 사용하여 제어되는 구성 요소 및 양식의 다양성과 효과를 진정으로 활용하기 위해 배워야 할 몇 가지 주요 개념과 기능이 있습니다.

## 내용
- React를 사용하여 제어되는 구성 요소 및 양식의 다양성과 효과를 진정으로 활용하기 위해 배워야 할 몇 가지 주요 개념과 기능이 있습니다.
- 몇 가지 조언을 받은 후 그들은 다시 빌드해야 한다는 결론을 내렸고 양식에서 요구하는 특징, 기능 및 제어를 쉽게 적용할 수 있는 능력 때문에 React를 작업에 가장 적합한 프레임워크로 선택했습니다.
- 이 비디오에서는 React에서 로컬 상태와 onChange 이벤트를 사용하여 양식 입력을 업데이트하는 제어 컴포넌트를 만들고, 양식 제출 이벤트의 기본 동작을 피하고, 양식이 유효하지 않을 때 Submit 버튼을 비활성화하는 방법을 배웁니다.
- 이전에 만든 앱을 사용하여 React에서 양식 구성 요소를 만드는 방법을 보여 드리겠습니다.
- 제어된 구성 요소의 더 많은 이점을 보여주기 위해 텍스트 입력이 비어 있지 않을 때만 사용자가 양식을 제출할 수 있도록 하여 추가로 개선해 보겠습니다.
- 로컬 상태, onChange 이벤트, onSubmit prop을 사용하여 제어되지 않은 양식을 제어 버전으로 변환하는 방법과 이를 통해 얻을 수 있는 몇 가지 이점을 배웠습니다.
- 양식 제출과 관련하여 기본 동작을 피하고 양식이 유효하지 않을 때 제출 버튼을 비활성화하는 방법도 배웠습니다.

## 예시
- 마지막으로 접근성 모범 사례를 위해 레이블을 입력과 연결해 보겠습니다.

## 요약
- 로컬 상태, onChange 이벤트, onSubmit prop을 사용하여 제어되지 않은 양식을 제어 버전으로 변환하는 방법과 이를 통해 얻을 수 있는 몇 가지 이점을 배웠습니다. 양식 제출과 관련하여 기본 동작을 피하고 양식이 유효하지 않을 때 제출 버튼을 비활성화하는 방법도 배웠습니다.
