# Positioning the elements, creating placeholders

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/html-and-css-in-depth/lecture/xzPKH/positioning-the-elements-creating-placeholders)

## 개요
- Visual Studio Code를 열고 1주차부터 Bare-Bones 레이아웃을 기반으로 한 semantic HTML 문서 구조로 index.html 파일을 만들었습니다.

## 내용
- Visual Studio Code를 열고 1주차부터 Bare-Bones 레이아웃을 기반으로 한 semantic HTML 문서 구조로 index.html 파일을 만들었습니다.
- 내 의미 구조에서 로고의 헤더 요소, 탐색 모음의 nav 요소, 기본 요소의 기본 요소를 사용합니다.
- 요소 선택기를 사용하여 헤더 요소의 하위 항목인 이미지 요소를 선택합니다.
- 이렇게 하려면 요소 선택기를 추가하여 탐색 요소의 하위 항목인 정렬되지 않은 목록 요소를 선택합니다.
- 이번에는 선택자가 탐색 요소의 하위 항목인 목록 항목 요소를 선택합니다.
- 요소 선택기를 사용하여 다른 CSS 규칙을 추가하여 섹션 요소를 선택합니다.
- 먼저 요소 선택기를 사용하여 CSS 규칙을 추가하여 바닥글 요소를 선택합니다.

## 예시
- 먼저 요소 선택기를 사용하여 CSS 규칙을 추가하여 바닥글 요소를 선택합니다.

## 요약
- 요소 선택기를 사용하여 다른 CSS 규칙을 추가하여 섹션 요소를 선택합니다. 먼저 요소 선택기를 사용하여 CSS 규칙을 추가하여 바닥글 요소를 선택합니다.
