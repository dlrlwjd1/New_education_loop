# Congratulations, you have completed HTMLS and CSS in depth!

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/html-and-css-in-depth/lecture/euBuM/congratulations-you-have-completed-htmls-and-css-in-depth)

## 개요
- 이 HTML 및 CSS의 프런트 엔드 개발자 프로그램의 끝에 도달한 것을 축하합니다.

## 내용
- 이 HTML 및 CSS의 프런트 엔드 개발자 프로그램의 끝에 도달한 것을 축하합니다.
- 당신은 이곳에 오기 위해 열심히 일했고, 많은 것을 배웠고, 코스에서 많은 새로운 기술을 개발했습니다.
- 당신은 클라이언트 페르소나를 위해 홈페이지에서 미디어를 평가할 수 있는 비디오 및 오디오 플레이어를 만들어 이 학습과 실용적인 HTML 및 CSS 개발 기술을 시연할 수 있습니다.
- 이 외에도 HTML 및 CSS 개발 과정을 마친 후 이제 일반적인 의미 및 메타 태그는 물론 HTML을 사용하는 웹 페이지 레이아웃 및 구성 요소를 사용할 수 있습니다.
- HTML을 사용하여 클라이언트 측 유효성 검사를 사용하여 포럼을 만들고, CSS를 사용하여 레이아웃, 차트, 효과 및 애니메이션을 생성하고, 기본 프런트 엔드 테스트, 디버깅 및 오류 처리를 수행합니다.
- 음, 이것은 프론트 엔드 개발자 프로그램의 네 번째 과정이며 중요한 개념과 실용적인 기술에 대한 귀중한 이해를 얻었습니다.
- 프로그램의 각 과정에서 계속해서 기술을 확장하고 최종 평가에서 자신의 프로젝트를 관리하기 위해 배운 모든 기술을 통합합니다.

## 예시
- 프로그램의 각 과정에서 계속해서 기술을 확장하고 최종 평가에서 자신의 프로젝트를 관리하기 위해 배운 모든 기술을 통합합니다.

## 요약
- 음, 이것은 프론트 엔드 개발자 프로그램의 네 번째 과정이며 중요한 개념과 실용적인 기술에 대한 귀중한 이해를 얻었습니다. 프로그램의 각 과정에서 계속해서 기술을 확장하고 최종 평가에서 자신의 프로젝트를 관리하기 위해 배운 모든 기술을 통합합니다.
