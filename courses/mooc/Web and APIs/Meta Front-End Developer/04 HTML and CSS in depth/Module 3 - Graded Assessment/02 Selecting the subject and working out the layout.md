# Selecting the subject and working out the layout

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/html-and-css-in-depth/lecture/m1ReD/selecting-the-subject-and-working-out-the-layout)

## 개요
- 과정 초반에 클라이언트 페르소나에 대해 배운 것을 기억할 수 있습니다.

## 내용
- 과정 초반에 클라이언트 페르소나에 대해 배운 것을 기억할 수 있습니다.
- 웹 페이지는 페이지 상단에 회사 로고가 있어야 하며 아래에 탐색 메뉴가 있어야 합니다.
- 다른 링크는 제품 페이지, 연락처 양식 또는 회사 정보 페이지에 대한 것일 수 있습니다.
- 주요 콘텐츠에는 프로모션 배너 아래에 있는 고객의 현재 프로모션 제안에 대한 링크가 있는 큰 배너가 있어야 합니다.
- 로고에는 머리글 요소, 탐색을 위한 탐색 요소, 기본 콘텐츠의 기본 요소 및 페이지 바닥글의 바닥글 요소를 사용해야 합니다.
- 시맨틱 HTML 구조를 설정했으면 다음 단계는 웹 페이지의 이러한 부분에 대한 기본 콘텐츠 및 바닥글에 대한 그리드 레이아웃을 계획하는 것입니다.
- 먼저 시각적 레이아웃을 고려한 다음 레이아웃에 대한 HTML 및 CSS 구조를 고려한 다음 의미 구조와 그리드 레이아웃을 고려합니다.

## 예시
- 먼저 시각적 레이아웃을 고려한 다음 레이아웃에 대한 HTML 및 CSS 구조를 고려한 다음 의미 구조와 그리드 레이아웃을 고려합니다.

## 요약
- 시맨틱 HTML 구조를 설정했으면 다음 단계는 웹 페이지의 이러한 부분에 대한 기본 콘텐츠 및 바닥글에 대한 그리드 레이아웃을 계획하는 것입니다. 먼저 시각적 레이아웃을 고려한 다음 레이아웃에 대한 HTML 및 CSS 구조를 고려한 다음 의미 구조와 그리드 레이아웃을 고려합니다.
