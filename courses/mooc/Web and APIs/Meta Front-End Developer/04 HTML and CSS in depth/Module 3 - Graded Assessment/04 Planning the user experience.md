# Planning the user experience

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/html-and-css-in-depth/lecture/KLjcI/planning-the-user-experience)

## 개요
- 웹사이트 구축의 핵심 부분은 좋은 사용자 인터페이스와 좋은 사용자 경험을 모두 보장하는 것입니다.

## 내용
- 웹사이트 구축의 핵심 부분은 좋은 사용자 인터페이스와 좋은 사용자 경험을 모두 보장하는 것입니다.
- 이 비디오는 사용자 인터페이스 UI와 사용자 경험 UX의 차이점과 의도적 참여의 개념을 설명하여 웹 페이지 방문자에게 좋은 사용자 경험을 설계하는 데 도움이 됩니다.
- 이해관계자 인터뷰, 사용자 조사, UX 감사 및 시나리오 매핑, 클라이언트 페르소나와 같이 기업에서 사용하는 다양한 UX 디자인 프로세스가 있습니다.
- 그러나 이 프로젝트의 경우 사용자 경험을 개선하는 데 사용할 수 있는 또 다른 프로세스인 의도적 참여에 집중해 보겠습니다.
- 참여의 목표는 사용자가 귀하의 웹사이트와 상호 작용하고 비즈니스에 따라 유지하거나 구매를 통해 수익을 창출하거나 광고와의 상호 작용을 유지하는 것입니다.
- 귀하의 건물은 고객 페르소나에 맞는 고객을 대상으로 하는 웹 페이지이기 때문에 사용자 경험은 고객이 웹사이트에 참여하는 방식에 따라 결정되어야 합니다.
- 고객이 웹사이트를 방문할 때 무엇을 찾고 있는지 나열하고 사용자가 해당 정보를 얻을 수 있도록 가능한 한 쉽게 만들도록 노력하는 것은 좋은 연습입니다.

## 예시
- 이해관계자 인터뷰, 사용자 조사, UX 감사 및 시나리오 매핑, 클라이언트 페르소나와 같이 기업에서 사용하는 다양한 UX 디자인 프로세스가 있습니다.

## 요약
- 귀하의 건물은 고객 페르소나에 맞는 고객을 대상으로 하는 웹 페이지이기 때문에 사용자 경험은 고객이 웹사이트에 참여하는 방식에 따라 결정되어야 합니다. 고객이 웹사이트를 방문할 때 무엇을 찾고 있는지 나열하고 사용자가 해당 정보를 얻을 수 있도록 가능한 한 쉽게 만들도록 노력하는 것은 좋은 연습입니다.
