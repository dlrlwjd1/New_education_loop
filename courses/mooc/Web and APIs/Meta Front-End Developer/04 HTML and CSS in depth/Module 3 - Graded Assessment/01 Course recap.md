# Course recap

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/html-and-css-in-depth/lecture/qJl7p/course-recap)

## 개요
- 메타데이터와 태그에 대해, 그리고 이를 사용하여 검색 엔진 최적화 또는 SEO를 통해 웹페이지 순위에 영향을 미치는 방법에 대해 배웠습니다.

## 내용
- 메타데이터와 태그에 대해, 그리고 이를 사용하여 검색 엔진 최적화 또는 SEO를 통해 웹페이지 순위에 영향을 미치는 방법에 대해 배웠습니다.
- 이 모듈의 마지막 부분은 미디어 요소에 관한 것이었고 웹 페이지에 비디오와 오디오를 포함하는 방법을 배우면서 높은 메모로 끝났습니다.
- 이 섹션에서 사용자에게 항상 좋은 뷰포트가 표시되도록 하는 방법에 대해 많은 것을 배웠을 것입니다.
- 궁극적으로, 이제 속성 선택기와 같은 CSS 선택기를 사용하여 다양한 정도의 특수성을 가진 다른 HTML 요소에 규칙을 적용하는 방법을 알아야 합니다.
- 이 모듈의 두 번째 마지막 부분에서는 CSS의 키프레임, 애니메이션 및 효과, 프런트 엔드 개발자를 위한 필수 지식 및 기술에 대해 배웠습니다.
- 두 번째 모듈의 마지막 부분은 HTML 및 CSS 문제를 디버깅하는 데 도움이 되는 브라우저 개발자 도구를 사용하는 방법에 관한 것이었습니다.
- 이것은 HTML 및 CSS 개발자가 되기 위한 여정의 시작일 수 있지만 이미 배우고 성취한 것에 대해 자신을 매우 자랑스럽게 생각할 수 있습니다.

## 예시
- 이것은 HTML 및 CSS 개발자가 되기 위한 여정의 시작일 수 있지만 이미 배우고 성취한 것에 대해 자신을 매우 자랑스럽게 생각할 수 있습니다.

## 요약
- 두 번째 모듈의 마지막 부분은 HTML 및 CSS 문제를 디버깅하는 데 도움이 되는 브라우저 개발자 도구를 사용하는 방법에 관한 것이었습니다. 이것은 HTML 및 CSS 개발자가 되기 위한 여정의 시작일 수 있지만 이미 배우고 성취한 것에 대해 자신을 매우 자랑스럽게 생각할 수 있습니다.
