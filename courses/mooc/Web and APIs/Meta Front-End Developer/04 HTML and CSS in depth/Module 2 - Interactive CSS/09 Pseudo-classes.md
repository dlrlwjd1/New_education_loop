# Pseudo-classes

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/html-and-css-in-depth/lecture/CMwle/pseudo-classes)

## 개요
- 가상 클래스 선택기를 사용하면 사용자 입력에 따라 요소에 스타일을 지정하여 웹 페이지의 상호 작용을 개선할 수 있습니다.

## 내용
- 가상 클래스 선택기를 사용하면 사용자 입력에 따라 요소에 스타일을 지정하여 웹 페이지의 상호 작용을 개선할 수 있습니다.
- 가상 클래스는 목록의 다섯 번째 항목, 굵게 표시된 항목, 빈 요소 등과 같은 특정 요소를 대상으로 하는 데에도 매우 효과적입니다.
- 가장 먼저 알아야 할 그룹은 사용자 작업 상태이며, 여기에는 커서가 요소 위에 커서를 놓으면 요소의 스타일을 변경하는 호버 가상 클래스가 포함됩니다.
- 활성 가상 클래스는 사용자가 마우스 버튼을 계속 누르고 있는 동안에만 요소에 스타일을 지정하는 반면, 포커스 가상 클래스는 해당 요소를 사용하는 요소에 스타일을 지정하는 데 초점을 맞춥니다.
- 이 예제에서 가상 클래스 선택기는 HTML 요소를 대상으로 하지만 HTML 클래스 특성을 대상으로 하는 데에도 사용할 수 있습니다.
- 양식 상태 가상 클래스에는 일반적으로 단추에 사용되는 비활성화됨 및 활성화됨, 확인란에 사용되는 확인됨 및 확인되지 않음, 이메일이나 전화번호와 같은 필드에 사용되는 유효/유효하지 않은 클래스가 포함됩니다.
- 이러한 유형의 예로는 첫 번째 유형, 유형 마지막, n번째 유형 및 n번째 유형 마지막 유형이 있습니다.

- 양식 상태 가상 클래스에는 일반적으로 단추에 사용되는 비활성화됨 및 활성화됨, 확인란에 사용되는 확인됨 및 확인되지 않음, 이메일이나 전화번호와 같은 필드에 사용되는 유효/유효하지 않은 클래스가 포함됩니다. 이러한 유형의 예로는 첫 번째 유형, 유형 마지막, n번째 유형 및 n번째 유형 마지막 유형이 있습니다.
