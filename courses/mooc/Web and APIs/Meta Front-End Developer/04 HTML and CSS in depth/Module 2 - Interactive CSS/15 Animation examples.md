# Animation examples

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/html-and-css-in-depth/lecture/16pez/animation-examples)

## 개요
- 이전에는 HTML 캔버스 요소와 JavaScript를 사용하여 튀는 공에 애니메이션을 적용하는 방법을 배웠습니다.

## 내용
- 이전에는 HTML 캔버스 요소와 JavaScript를 사용하여 튀는 공에 애니메이션을 적용하는 방법을 배웠습니다.
- 비주얼 스튜디오 코드를 열고 index.html 라는 파일에 기본 HTML 구조를 만들었습니다.
- 시작 위치는 요소의 기본 위치여야 하므로 transform 속성을 추가하고 해당 값을 좌표 000으로 3D를 변환하도록 설정합니다.
- 이를 위해 transform 속성을 추가하고 그 값을 좌표가 640픽셀 00인 3D를 변환하도록 설정합니다.
- 볼 요소에 대한 CSS 규칙에서 애니메이션 속성을 추가하고 그 값을 bounce 2s로 설정했습니다.
- HTML과 JavaScript로 만든 애니메이션을 일치시키기 위해 애니메이션 타이밍 함수를 선형으로 설정했습니다.
- 볼 요소에 대한 CSS 규칙에서 애니메이션 속성을 업데이트하고 값을 바운스 2s 리니어로 설정합니다.

## 예시
- 볼 요소에 대한 CSS 규칙에서 애니메이션 속성을 업데이트하고 값을 바운스 2s 리니어로 설정합니다.

## 요약
- HTML과 JavaScript로 만든 애니메이션을 일치시키기 위해 애니메이션 타이밍 함수를 선형으로 설정했습니다. 볼 요소에 대한 CSS 규칙에서 애니메이션 속성을 업데이트하고 값을 바운스 2s 리니어로 설정합니다.
