# Widely used selectors

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/html-and-css-in-depth/lecture/mafHz/widely-used-selectors)

## 개요
- 개발자는 요소 선택기를 사용하여 요소 유형에 따라 html 요소를 선택할 수 있습니다.

## 내용
- 개발자는 요소 선택기를 사용하여 요소 유형에 따라 html 요소를 선택할 수 있습니다.
- 클래스 선택기를 사용하면 지정된 클래스 이름을 가진 모든 요소에 규칙을 적용할 수 있습니다.이 CSS 셀렉터들은 여러분이 이전에 배웠던 것들입니다.
- 첫 번째 클래스에는 클래스가 없는 반면, 두 번째 클래스에는 홈이라는 클래스가 있고 세 번째 클래스에는 Call out이라는 클래스가 있습니다.
- 또는 href 속성, 별표 및 대상으로 지정하려는 모든 링크의 일부인 공통 값을 삽입하여 세 요소를 모두 대상으로 지정할 수 있습니다.
- 또는 대괄호 안에 대상으로 지정하려는 특정 링크를 href 속성의 값으로 추가하여 첫 번째 요소만 대상으로 지정할 수 있습니다.
- 제목 요소 및 단락 요소와 같이 둘 이상의 요소 유형에 동일한 스타일을 적용하려는 경우 그룹 선택기를 사용할 수 있습니다.
- 제목 1과 P와 같이 모든 요소에 규칙을 사용하는 요소 선택기를 사용하는 대신 h1, p를 입력한 다음 CSS 속성을 추가할 수 있습니다.

## 예시
- 예를 들어 대괄호 안에 클래스를 추가하여 정의된 클래스가 있는 모든 요소에 스타일을 지정할 수 있습니다.

## 요약
- 제목 요소 및 단락 요소와 같이 둘 이상의 요소 유형에 동일한 스타일을 적용하려는 경우 그룹 선택기를 사용할 수 있습니다. 제목 1과 P와 같이 모든 요소에 규칙을 사용하는 요소 선택기를 사용하는 대신 h1, p를 입력한 다음 CSS 속성을 추가할 수 있습니다.
