# Handling errors

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/html-and-css-in-depth/lecture/b255Y/handling-errors)

## 개요
- 이제 CSS 코드를 수정하여 실수를 만들어 보겠습니다.상자의 배경색 속성 뒤에 있는 세미콜론을 제거해 보겠습니다.

## 내용
- 이제 CSS 코드를 수정하여 실수를 만들어 보겠습니다.상자의 배경색 속성 뒤에 있는 세미콜론을 제거해 보겠습니다.
- 그 이후에도 테두리 속성 및 hover 가상 클래스 속성과 같은 나머지 스타일링이 계속 적용됩니다.세미콜론을 되돌리고 배경 뒤에 세미콜론을 제거했을 때 또 다른 오류를 만들어 보겠습니다.
- 코드를 수정하기 위해 세미콜론을 다시 넣었지만 때로는 구문 오류뿐만 아니라 코드의 유효성을 검사해야 할 때도 있습니다.예를 들어 특정 코딩 규칙 및 모범 사례를 기준으로 이러한 종류의 문제를 해결합니다.
- 이러한 온라인 도구 및 겨울 확장 프로그램 설치 방법에 대한 자세한 내용은 강의 마지막 부분에 있는 추가 리소스에서 확인할 수 있습니다.
- 색상: 16진수 린트 없음 규칙에는 8번째 줄에서 예상치 못한 16진수 색상이 발견되었다고 나와 있습니다.
- HS L과 같은 유효한 표기법으로 16진수 코드를 업데이트하려면 CSS 코드의 색상 상자를 클릭하면 색상 패널이 나타납니다.
- L 스타일링은 Lint 오류를 찾는 데 사용할 수 있는 Visual Studio 코드의 여러 개발자 도구 중 하나에 불과합니다.

## 예시
- 코드를 수정하기 위해 세미콜론을 다시 넣었지만 때로는 구문 오류뿐만 아니라 코드의 유효성을 검사해야 할 때도 있습니다.예를 들어 특정 코딩 규칙 및 모범 사례를 기준으로 이러한 종류의 문제를 해결합니다.
