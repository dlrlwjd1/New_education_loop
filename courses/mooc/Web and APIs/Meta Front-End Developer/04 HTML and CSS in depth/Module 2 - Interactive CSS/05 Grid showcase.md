# Grid showcase

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/html-and-css-in-depth/lecture/b91pE/grid-showcase)

## 개요
- 이제 그리드 행의 크기 조정 함수를 추적할 그리드 템플릿 행 속성을 추가합니다.

## 내용
- 이제 그리드 행의 크기 조정 함수를 추적할 그리드 템플릿 행 속성을 추가합니다.
- 먼저 부모 클래스의 CSS 속성을 추가한 다음 개별 세그먼트에 대해 정의합니다.
- 부모 클래스의 경우 display grid를 작성한 다음 grid 템플릿 columns 속성을 추가합니다.
- 이 두 세그먼트는 이제 첫 번째 컬럼에서 시작하여 12번째 컬럼까지 더 나은 모습을 보이고 있습니다.
- 이제 색상을 통해 요소가 다섯 번째 열에서 시작하여 8개 열에 걸쳐 있음을 알 수 있습니다.
- 모서리에 있는 버튼을 선택하여 페이지에서 검사할 요소를 선택한 다음 그리드를 스캔할 수 있습니다.
- 이와 같은 그리드는 잡지, 신문 또는 페이지 레이아웃과 같은 모델을 복제할 수 있는 디자인을 할 때 매우 유용합니다.

## 예시
- 이와 같은 그리드는 잡지, 신문 또는 페이지 레이아웃과 같은 모델을 복제할 수 있는 디자인을 할 때 매우 유용합니다.

## 요약
- 모서리에 있는 버튼을 선택하여 페이지에서 검사할 요소를 선택한 다음 그리드를 스캔할 수 있습니다. 이와 같은 그리드는 잡지, 신문 또는 페이지 레이아웃과 같은 모델을 복제할 수 있는 디자인을 할 때 매우 유용합니다.
