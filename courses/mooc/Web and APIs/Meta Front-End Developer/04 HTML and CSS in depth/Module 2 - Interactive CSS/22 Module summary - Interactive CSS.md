# Module summary: Interactive CSS

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/html-and-css-in-depth/lecture/MjkqE/module-summary-interactive-css)

## 개요
- 다양한 요소에 점점 더 구체적인 스타일을 적용하여 CSS에 대해 더 깊이 있게 다룰 수 있는 대화형 CSS에 대한 이 단원을 마쳤습니다.

## 내용
- 다양한 요소에 점점 더 구체적인 스타일을 적용하여 CSS에 대해 더 깊이 있게 다룰 수 있는 대화형 CSS에 대한 이 단원을 마쳤습니다.
- 레이아웃 생성에 대한 강의로 이 모듈을 시작했습니다.그리드와 플렉스 박스 모듈, 일반적인 플렉스 레이아웃, 열 그리드 및 스택 CSS 측정 단위와 같은 일반적인 페이지 레이아웃의 예를 설명하는 CSS 웹 레이아웃에 대해 배웠습니다.
- 포함된 요소의 세분화된 선택을 보여주는 모든 선택자와 그 특이성 조합 선택자는 세분화된 선택과 유사 클래스 및 요소의 개념과 실제 사용을 사용하여 CSS 스타일 지정 요소를 대상으로 합니다.
- 이 단원에서는 세밀한 선택을 사용하여 주어진 요소의 스타일을 지정하는 능력을 테스트하는 배은망덕스러운 실습도 완료했습니다.
- Effects에 관한 것이었으며, 모듈의 이 부분에서는 효과의 정의, 효과를 사용하여 웹 프레젠테이션을 향상시키는 방법, 그림자 및 글로우 CSS 애니메이션과 같은 텍스트 효과를 사용하는 방법, 기본 애니메이션 원리에 대해 배웠습니다.
- 네 번째이자 마지막 강의는 디버깅에 관한 것으로, 이 주제를 탐구하면서 CSS 및 html 문제를 검사, 진단 및 해결하는 방법을 배웠고, 일반적인 오류, 오류 처리, 프런트 엔드 디버깅, 브라우저 개발자 도구가 html 및 CSS 문제 디버깅을 지원하는 방법, 조건부 주석 및 UI 테스트에 대해 배웠습니다.
- 이제 대화형 CSS의 기본 사항과 CSS 및 html 문제를 진단하고 해결하는 데 사용할 수 있는 디버깅 도구에 익숙해질 것입니다.

## 예시
- 등급이 매겨지지 않은 실습 2과에서는 CSS 선택기에 초점을 맞춥니다.

## 요약
- 네 번째이자 마지막 강의는 디버깅에 관한 것으로, 이 주제를 탐구하면서 CSS 및 html 문제를 검사, 진단 및 해결하는 방법을 배웠고, 일반적인 오류, 오류 처리, 프런트 엔드 디버깅, 브라우저 개발자 도구가 html 및 CSS 문제 디버깅을 지원하는 방법, 조건부 주석 및 UI 테스트에 대해 배웠습니다. 이제 대화형 CSS의 기본 사항과 CSS 및 html 문제를 진단하고 해결하는 데 사용할 수 있는 디버깅 도구에 익숙해질 것입니다.
