# CSS animation

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/html-and-css-in-depth/lecture/9U7tU/css-animation)

## 개요
- 이 비디오에서는 애니메이션 속성을 @keyframes 규칙과 함께 사용하여 고급 애니메이션을 만드는 방법을 알아봅니다.

## 내용
- 이 비디오에서는 애니메이션 속성을 @keyframes 규칙과 함께 사용하여 고급 애니메이션을 만드는 방법을 알아봅니다.
- 애니메이션 속성에는 애니메이션 이름, 애니메이션 지연 등과 같은 여러 하위 속성이 있습니다.
- 알아야 할 것은 시계와 바늘이라는 두 개의 클래스를 만들고 시계와 바늘의 기본 레이아웃과 모양을 지정하는 스타일 규칙을 삽입하는 것뿐입니다.
- 분 클래스의 경우 6초, 무한 선형 값을 사용하여 애니메이션 속성을 추가합니다.
- 시간 클래스의 경우 주기 60초 무한 선형 값을 사용하여 애니메이션 속성을 추가합니다.
- from 키워드의 경우 0도 회전 값을 사용하여 변환 속성을 추가합니다.
- 이 비디오에서는 애니메이션 프로퍼티와 @keyframe 규칙을 함께 사용하여 특정 효과를 내는 방법을 배웠습니다.

## 예시
- 예를 들어 이미지와 같은 다른 요소와 결합하여 순수한 CSS를 사용하여 놀라운 애니메이션을 만들 수 있습니다.

## 요약
- from 키워드의 경우 0도 회전 값을 사용하여 변환 속성을 추가합니다. 이 비디오에서는 애니메이션 프로퍼티와 @keyframe 규칙을 함께 사용하여 특정 효과를 내는 방법을 배웠습니다.
