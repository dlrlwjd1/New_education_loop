# Practical use of pseudo

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/html-and-css-in-depth/lecture/fovk0/practical-use-of-pseudo)

## 개요
- 이 비디오에서는 웹 페이지의 링크 스타일을 지정하는 데 사용할 수 있는 가상 클래스, 즉 웹 링크 상태를 살펴보겠습니다.

## 내용
- 이 비디오에서는 웹 페이지의 링크 스타일을 지정하는 데 사용할 수 있는 가상 클래스, 즉 웹 링크 상태를 살펴보겠습니다.
- 예를 들어 HTML 파일에는 웹 사이트의 다른 페이지로 연결되는 고유한 href가 있는 두 개의 a 태그가 있을 수 있습니다.
- 링크에 초기 색상을 지정하려면 링크 가상 클래스 선택기를 사용하고, 링크 색상을 변경하도록 하려면 사용자가 이러한 페이지를 방문한 후 방문한 가상 클래스 선택기를 사용할 수 있습니다.
- 이제 웹 링크 상태에 대해 자세히 알아보았으니 링크, 방문, 호버 및 활성 가상 클래스를 사용하는 방법을 살펴보겠습니다.
- pseudo_links.html 파일에 제목 태그, 단락 태그, 단락 태그 등 세 개의 태그를 추가했습니다.
- 예상대로 링크 위로 마우스를 가져가면 호버 가상 클래스의 색상 속성 값으로 녹색을 추가했기 때문에 색상이 녹색으로 바뀝니다.
- 모든 텍스트 블록이 동일한 텍스트 클래스에 속하므로 다른 텍스트 블록 위로 마우스를 가져가면 동일한 효과가 나타납니다.

## 예시
- 예를 들어 HTML 파일에는 웹 사이트의 다른 페이지로 연결되는 고유한 href가 있는 두 개의 a 태그가 있을 수 있습니다.

## 요약
- 예상대로 링크 위로 마우스를 가져가면 호버 가상 클래스의 색상 속성 값으로 녹색을 추가했기 때문에 색상이 녹색으로 바뀝니다. 모든 텍스트 블록이 동일한 텍스트 클래스에 속하므로 다른 텍스트 블록 위로 마우스를 가져가면 동일한 효과가 나타납니다.
