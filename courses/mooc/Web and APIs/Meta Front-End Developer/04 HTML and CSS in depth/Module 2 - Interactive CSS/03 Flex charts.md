# Flex charts

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/html-and-css-in-depth/lecture/bHZ1S/flex-charts)

## 개요
- 이 비디오에서는 막대형 차트를 만드는 데 플렉스 박스를 사용하여 플렉스 박스의 다양성에 대해 더 자세히 살펴보겠습니다.

## 내용
- 이 비디오에서는 막대형 차트를 만드는 데 플렉스 박스를 사용하여 플렉스 박스의 다양성에 대해 더 자세히 살펴보겠습니다.
- 막대 차트는 통계에 사용되는 데이터를 시각화하는 일반적인 방법입니다.데이터가 나타내는 값에 비례하는 높이를 갖는 직사각형 막대 형태로 데이터를 볼 때 데이터를 비교하고 이해하기가 더 쉽습니다.
- 플렉스 그로우 (Flex grow) 는 아이템이 다른 유연 아이템에 비해 얼마나 커질지를 지정하고 플렉스 슈링크는 아이템이 다른 유연 아이템에 비해 얼마나 줄어들 것인지를 지정합니다.
- 레이블을 추가하려면 새 줄에 도트 레이블을 입력하고 Enter 키를 누른 다음 원하는 요리 레이블 이름을 추가합니다.
- 다음으로 도트 컨테이너를 입력하여 컨테이너라는 또 다른 클래스를 만든 다음 Enter 키를 누릅니다.
- 요리를 구별하기 위해 저는 각 항목의 클래스 이름을 디쉬 ( dish) 라는 단어 뒤에 항목 1, 파스타, 항목 2, 피자, 항목 3 부리또로 지정합니다.
- 이제 코드를 만들었으니 화면 상단에 있는 플렉스 차트 도트 CSS 파일을 클릭하고 올바른 파일을 참조하고 있는지 확인하여 CSS로 이동합니다.

## 예시
