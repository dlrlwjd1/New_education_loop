# Debugging tools

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/html-and-css-in-depth/lecture/iPju2/debugging-tools)

## 개요
- 여기에는 오류 로그 보기, JavaScript 코드 디버깅, HTTP 요청 및 응답 검사, JavaScript 코드의 성능 및 메모리 사용 검사, CSS 그리드 및 플렉스박스 레이아웃 검사, HTML 및 CSS 렌더링 검사, 실시간 편집이 포함됩니다.

## 내용
- 여기에는 오류 로그 보기, JavaScript 코드 디버깅, HTTP 요청 및 응답 검사, JavaScript 코드의 성능 및 메모리 사용 검사, CSS 그리드 및 플렉스박스 레이아웃 검사, HTML 및 CSS 렌더링 검사, 실시간 편집이 포함됩니다.
- 이렇게 하면 렌더링된 페이지에 표시된 특정 요소 ( 예: 로고) 를 강조 표시하고 개발자 도구에서 강조 표시된 해당 HTML을 확인할 수 있습니다.
- 또한 웹 페이지의 요소가 강조 표시되면 개발자 도구에서 해당 요소에 적용된 CSS 규칙을 검사할 수 있습니다.
- HTML과 CSS 렌더링을 검사할 수 있다는 것은 의심할 여지 없이 유용하지만, 라이브 편집, HTML 및 CSS와 함께 사용하면 더 강력할 수 있습니다.
- 이를 통해 CSS 규칙 변경을 테스트하고 HTML 요소를 조정하여 수정 사항을 확인한 후 코드에 영구적으로 추가할 수 있으며, 웹 페이지를 편집하고 다시 로드하는 데 소요되는 시간이 줄어들기 때문에 많은 시간을 절약할 수 있습니다.
- 멋지지 않나요?이 비디오에서는 브라우저 개발자 도구를 사용하여 HTML 및 CSS 코드를 디버깅하는 데 어떻게 도움이 되는지 살펴보았습니다.
- 전기 기술자와 마찬가지로 개발자도 문제를 검사하고 진단할 수 있는 많은 도구를 사용할 수 있으며 개발자 도구를 사용하면 웹 페이지와 웹 응용 프로그램을 쉽게 만들고 유지 관리할 수 있습니다.

## 예시
- 전기 기술자와 마찬가지로 개발자도 문제를 검사하고 진단할 수 있는 많은 도구를 사용할 수 있으며 개발자 도구를 사용하면 웹 페이지와 웹 응용 프로그램을 쉽게 만들고 유지 관리할 수 있습니다.
