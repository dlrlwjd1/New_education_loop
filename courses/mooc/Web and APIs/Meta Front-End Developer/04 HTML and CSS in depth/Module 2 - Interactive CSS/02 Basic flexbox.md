# Basic flexbox

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/html-and-css-in-depth/lecture/2Ur82/basic-flexbox)

## 개요
- 플렉스박스를 활용하여 요소를 서로 바인딩하거나 쉬운 레이아웃을 만들 수 있는 간단한 방법을 알게 될 것입니다.

## 내용
- 플렉스박스를 활용하여 요소를 서로 바인딩하거나 쉬운 레이아웃을 만들 수 있는 간단한 방법을 알게 될 것입니다.
- flex는 작은 검색 아이콘, 검색 입력 영역 및 제출 버튼과 같은 모든 요소를 연결하므로 검색 창에서 플렉스를 사용할 수 있습니다.
- 다음 몇 분 안에 간단한 레이아웃을 보장하기 위해 이러한 플렉스박스를 만드는 방법을 알게 될 것입니다.
- 이 컨테이너 안에는 검색 아이콘, 검색을 입력한 검색 상자, 마지막으로 제출 버튼이라는 세 가지 요소가 있습니다.
- CSS 코드에서 먼저 컨테이너에 대한 규칙을 작성한 다음 검색 아이콘, 검색 상자, 마지막으로 버튼에 대한 규칙을 작성합니다.
- 이는 플렉스박스를 사용하여 웹 사이트에 대한 반응성을 제공하고 웹 페이지의 다양한 요소를 서로 바인딩하는 몇 가지 방법에 불과합니다.
- 이제 플렉스박스를 사용하여 요소를 서로 바인딩하여 웹 페이지에 쉽게 반응하는 레이아웃을 만들 수 있는 몇 가지 간단한 방법에 더 익숙해질 것입니다.잘했어.

## 예시
- 마지막으로 보여드릴 플렉스박스의 예시는 반응형 이미지 갤러리입니다.

## 요약
- 이는 플렉스박스를 사용하여 웹 사이트에 대한 반응성을 제공하고 웹 페이지의 다양한 요소를 서로 바인딩하는 몇 가지 방법에 불과합니다. 이제 플렉스박스를 사용하여 요소를 서로 바인딩하여 웹 페이지에 쉽게 반응하는 레이아웃을 만들 수 있는 몇 가지 간단한 방법에 더 익숙해질 것입니다.잘했어.
