# Case study: How Meta creates responsive builds

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/html-and-css-in-depth/lecture/eoB8p/case-study-how-meta-creates-responsive-builds)

## 개요
- 휴대폰, 데스크톱 앱, 태블릿 반응형 웹 디자인의 기본 개념은 다양한 뷰포트에서 작동하는 제품을 만드는 것입니다.

## 내용
- 휴대폰, 데스크톱 앱, 태블릿 반응형 웹 디자인의 기본 개념은 다양한 뷰포트에서 작동하는 제품을 만드는 것입니다.
- 이 작업을 수행하는 데에는 많은 기술이 필요하지만 핵심 문제는 제품이 있고 어디서나 작동해야 한다는 것입니다.어떻게 할 수 있죠?
- 해결해야 할 문제는 앱이 다양한 뷰포트에서 작동하도록 하는 것입니다.
- 모바일 디바이스에서 작동하도록 앱을 빌드하는 경우 화면 하단에 액션 버튼을 배치하여 오른쪽 상단의 드롭다운을 검지 손가락으로 누를 필요 없이 엄지손가락으로 누를 수 있습니다.
- 왜냐하면 그건 개인적인 일이기 때문이죠.그런 사진을 찍으면 마치 그곳에 있는 것 같은 느낌이 들고 그들과 이야기를 나누는 것 같은 느낌이 듭니다.
- 사람들은 가능한 한 제대로 작동하는지 확인하기 위해 엔드 투 엔드 테스트를 작성할 수 있습니다.
- 디바이스가 제대로 작동하도록 만드는 데 초점을 맞추는 대신 인터페이스를 앞뒤로 움직여 다양한 차원을 가로질러 움직이게 만드세요.

## 예시
- 디바이스가 제대로 작동하도록 만드는 데 초점을 맞추는 대신 인터페이스를 앞뒤로 움직여 다양한 차원을 가로질러 움직이게 만드세요.

## 요약
- 사람들은 가능한 한 제대로 작동하는지 확인하기 위해 엔드 투 엔드 테스트를 작성할 수 있습니다. 디바이스가 제대로 작동하도록 만드는 데 초점을 맞추는 대신 인터페이스를 앞뒤로 움직여 다양한 차원을 가로질러 움직이게 만드세요.
