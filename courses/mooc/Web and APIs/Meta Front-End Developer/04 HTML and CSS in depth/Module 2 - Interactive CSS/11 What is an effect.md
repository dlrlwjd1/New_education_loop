# What is an effect

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/html-and-css-in-depth/lecture/jRGY0/what-is-an-effect)

## 개요
- 애니메이션은 웹 페이지에 생기를 불어넣는 효과의 일종으로 오늘날 웹 개발의 일부분으로 널리 사용되고 있습니다.

## 내용
- 애니메이션은 웹 페이지에 생기를 불어넣는 효과의 일종으로 오늘날 웹 개발의 일부분으로 널리 사용되고 있습니다.
- 오늘날 프런트 엔드 개발자가 웹 사이트에 애니메이션을 추가하는 데 사용할 수 있는 프로그램과 라이브러리는 많습니다.
- 예를 들어 요소를 밝게 하거나 어둡게 하거나 커서 위치를 강조 표시하는 기타 효과가 있습니다.
- 또 다른 인기 있는 효과는 일반적인 화살표 대신 커서 모양을 변경하는 것입니다.
- 일반적으로 이미지 모음이나 텍스트 상자를 표시하는 데 사용되며 움직임을 설명하기 위해 화면 상단에 일반적으로 추가되는 비디오 배경이 나타납니다.
- 사용자가 웹 페이지를 스크롤할 때 전체 화면 스냅은 사용자가 스크롤하는 동안 자동으로 한 페이지에서 다른 페이지로 빠르게 전환하는 것입니다.
- 이제 몇 가지 인기 있는 효과에 익숙해졌으니 웹 페이지에 효과를 추가할 때의 장단점을 간단히 살펴보겠습니다.

## 예시
- 예를 들어 요소를 밝게 하거나 어둡게 하거나 커서 위치를 강조 표시하는 기타 효과가 있습니다.

## 요약
- 사용자가 웹 페이지를 스크롤할 때 전체 화면 스냅은 사용자가 스크롤하는 동안 자동으로 한 페이지에서 다른 페이지로 빠르게 전환하는 것입니다. 이제 몇 가지 인기 있는 효과에 익숙해졌으니 웹 페이지에 효과를 추가할 때의 장단점을 간단히 살펴보겠습니다.
