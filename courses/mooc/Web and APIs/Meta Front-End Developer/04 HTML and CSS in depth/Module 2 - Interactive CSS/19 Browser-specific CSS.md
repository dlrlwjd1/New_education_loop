# Browser-specific CSS

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/html-and-css-in-depth/lecture/daKNG/browser-specific-css)

## 개요
- 다음 몇 분 동안 CSS와 다른 브라우저의 상호 작용에 대해 알아보고 이러한 브라우저와의 호환성을 보장하기 위해 CSS 파일에 코드를 추가하는 방법을 배우게 됩니다.

## 내용
- 다음 몇 분 동안 CSS와 다른 브라우저의 상호 작용에 대해 알아보고 이러한 브라우저와의 호환성을 보장하기 위해 CSS 파일에 코드를 추가하는 방법을 배우게 됩니다.
- 모든 주요 브라우저는 대부분 CSS 구현 방식에 맞춰져 있지만, 여전히 브라우저별 차이점이 존재하며, 이로 인해 때때로 CSS와 관련된 레이아웃, 스타일 및 기타 반응형 구성 요소에 방해가 될 수 있습니다.
- 예를 들어 개발자는 이러한 사이트 중 하나를 사용하여 CSS 규칙의 테두리 반경 규칙이 다른 모든 브라우저와 호환되는지 확인할 수 있습니다.
- 이러한 웹킷 규칙은 화면 해상도, 뷰포트, 브라우저 높이 등과 같은 측면에 대한 매개 변수를 설정하는 비표준 방법으로 사용되는 미디어 쿼리 규칙의 일부입니다.
- CSS 및 HTML 코드에 추가할 수 있는 이러한 조건부 주석 및 기타 브라우저별 설정에 대한 미디어 쿼리와 변형이 많이 있습니다.
- 브라우저와의 호환성을 설정하기 위해 이러한 미디어 쿼리와 기타 CSS 코드를 추가하는 것은 그 자체만으로도 방대한 주제이며, 기존 CSS 규칙의 범위를 넘어서 탐구할 수 있습니다.
- 이 비디오에서는 CSS 호환성과 CSS를 렌더링할 때 여러 브라우저 간에 발생할 수 있는 문제에 대해 알아보고, 각 브라우저마다 고유한 렌더링 엔진이 있는 방법, 개발자가 특수 웹 사이트를 사용하여 CSS 코드가 여러 브라우저에서 유효한지 확인할 수 있다는 것을 배웠습니다.

## 예시
- 예를 들어 색상과 글꼴이 원래 스타일과 약간 다르게 보일 수 있으며, 이는 사용자 경험에 영향을 미칠 수 있습니다.

## 요약
- 브라우저와의 호환성을 설정하기 위해 이러한 미디어 쿼리와 기타 CSS 코드를 추가하는 것은 그 자체만으로도 방대한 주제이며, 기존 CSS 규칙의 범위를 넘어서 탐구할 수 있습니다. 이 비디오에서는 CSS 호환성과 CSS를 렌더링할 때 여러 브라우저 간에 발생할 수 있는 문제에 대해 알아보고, 각 브라우저마다 고유한 렌더링 엔진이 있는 방법, 개발자가 특수 웹 사이트를 사용하여 CSS 코드가 여러 브라우저에서 유효한지 확인할 수 있다는 것을 배웠습니다.
