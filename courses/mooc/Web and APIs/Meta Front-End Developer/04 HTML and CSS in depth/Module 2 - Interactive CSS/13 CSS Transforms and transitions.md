# CSS Transforms and transitions

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/html-and-css-in-depth/lecture/zLk5a/css-transforms-and-transitions)

## 개요
- 예를 들어 스케일과 각도를 변경할 수 있지만 이러한 변경은 즉각적으로 움직이는 것처럼 보이기 때문에 그다지 효과적이거나 사용자 친화적이지 않습니다.

## 내용
- 예를 들어 스케일과 각도를 변경할 수 있지만 이러한 변경은 즉각적으로 움직이는 것처럼 보이기 때문에 그다지 효과적이거나 사용자 친화적이지 않습니다.
- 예를 들어 H one 요소가 기본적으로 0도 회전하도록 설정할 수 있지만 hover 유사 클래스와 transform 속성을 사용하면 마우스를 요소 위로 가져가면 요소가 20도까지 회전하도록 할 수 있습니다.
- 첫 번째 div 태그에는 A라는 클래스가 있는 문자 A가 들어 있고, 두 번째 div 태그에는 B라는 클래스가 있는 문자 B가 들어 있습니다.
- div 태그 요소 내부 먼저 상자에 대한 규칙을 작성한 다음 호버 가상 클래스와 그룹 선택기를 사용하여 상자에서 변환을 수행하는 규칙을 추가하겠습니다.
- 테두리 반경을 추가하고 약식 표기법을 사용하여 12픽셀의 값을 지정하고 테두리를 단색으로 지정하고 16진수 형식의 RGB 값을 추가합니다.
- 변환 및 전환 속성을 함께 사용하여 기본 애니메이션을 만드는 방법을 배웠습니다.
- 트랜스폼과 트랜지션, 호버 액티브와 같은 유사 클래스 (예: 호버, 액티브, 기타) 와 결합하여 이러한 효과를 다양하게 구현할 수 있습니다.

## 예시
- 예를 들어 스케일과 각도를 변경할 수 있지만 이러한 변경은 즉각적으로 움직이는 것처럼 보이기 때문에 그다지 효과적이거나 사용자 친화적이지 않습니다.

## 요약
- 변환 및 전환 속성을 함께 사용하여 기본 애니메이션을 만드는 방법을 배웠습니다. 트랜스폼과 트랜지션, 호버 액티브와 같은 유사 클래스 (예: 호버, 액티브, 기타) 와 결합하여 이러한 효과를 다양하게 구현할 수 있습니다.
