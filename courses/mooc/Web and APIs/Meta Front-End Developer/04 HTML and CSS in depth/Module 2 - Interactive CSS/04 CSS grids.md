# CSS grids

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/html-and-css-in-depth/lecture/VQIRo/css-grids)

## 개요
- 레이아웃은 이해하기 쉽도록 관련 콘텐츠를 구성하여 사용자에게 시각적 단서를 제공하는 방법이기 때문입니다.

## 내용
- 레이아웃은 이해하기 쉽도록 관련 콘텐츠를 구성하여 사용자에게 시각적 단서를 제공하는 방법이기 때문입니다.
- 그리드는 페이지를 행과 열로 나누며, 이러한 트랙 사이의 공간을 거터 또는 간격이라고 합니다.
- 가장 먼저 할 일은 컨테이너 객체 내에 있는 다양한 상자 클래스의 속성 값을 설정하여 레이아웃을 더 보기 좋게 만드는 것입니다.
- 업데이트된 컨테이너의 디스플레이 속성 값은 그리드로 설정되고 속성 값은 열 3개와 행 2개에 대해 구성되어 있습니다.
- 이제 그리드 간격 , 거터 및 배경색과 같은 몇 가지 속성을 추가하여 그리드를 정의하면 업데이트된 뷰에 그리드를 나타내는 빨간색 상자가 표시됩니다.
- 그리드는 기본적으로 페이지의 전체 너비로 확장되며 그리드 트랙 또는 여백의 크기가 10픽셀로 조정되어 그리드 셀 사이에 더 많은 공간이 남습니다.
- 또한 그리드, 자동 행 및 그리드 자동 열과 같은 자동 속성을 통칭하여 암시적 그리드라고 부르는 것을 선택할 수도 있습니다.

## 예시
- 또한 그리드, 자동 행 및 그리드 자동 열과 같은 자동 속성을 통칭하여 암시적 그리드라고 부르는 것을 선택할 수도 있습니다.

## 요약
- 그리드는 기본적으로 페이지의 전체 너비로 확장되며 그리드 트랙 또는 여백의 크기가 10픽셀로 조정되어 그리드 셀 사이에 더 많은 공간이 남습니다. 또한 그리드, 자동 행 및 그리드 자동 열과 같은 자동 속성을 통칭하여 암시적 그리드라고 부르는 것을 선택할 수도 있습니다.
