# Combination selectors

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/html-and-css-in-depth/lecture/xVmgq/combination-selectors)

## 개요
- 다음으로, 첫 번째 유형 다음에 오는 동일한 유형의 모든 선택자에 규칙을 적용하는 일반 형제 선택자에 초점을 맞추어 보겠습니다.

## 내용
- 다음으로, 첫 번째 유형 다음에 오는 동일한 유형의 모든 선택자에 규칙을 적용하는 일반 형제 선택자에 초점을 맞추어 보겠습니다.
- 가족 비유를 다시 설명하자면, 일반 형제 선택기를 사용하면 사람을 선택한 다음 검은 머리를 가진 남동생을 모두 선택할 수 있습니다.
- 첫 번째 단락 요소는 파란색으로 바뀌지 않았는데, 이는 일반 형제 선택기가 선택자와 일치하는 후속 요소만 선택하기 때문입니다.형제 선택자와 비교하여 인접 형제 선택기를 사용하여 다른 요소 다음에 오는 첫 번째 요소 또는 인접 요소만 대상으로 지정할 수 있습니다.
- 일반 형제 선택자는 첫 번째 유형 다음에 오는 두 번째 유형의 일치하는 요소를 모두 선택한다는 점을 기억하십시오.
- 형제 선택자는 첫 번째 유형 다음에 오는 동일한 유형의 모든 선택자에 규칙을 적용한다는 점을 기억하십시오.
- 즉, 이미지 뒤에 오는 모든 단락에 스타일을 적용하고 싶지만 다른 단락이나 div 태그와 같은 다른 요소에는 영향을 미치지 않습니다.
- 인접한 셀렉터로 이 작업을 수행할 수 있습니다.인접 선택자와 형제 선택자의 차이점은 인접 선택자는 참조 요소 다음의 첫 번째 요소만 대상으로 한다는 점을 기억하십시오.

## 예시
- 예를 들어 div 태그가 있고 해당 ID 속성이 blog로 설정된 HTML 파일을 만들 수 있습니다.

## 요약
- 즉, 이미지 뒤에 오는 모든 단락에 스타일을 적용하고 싶지만 다른 단락이나 div 태그와 같은 다른 요소에는 영향을 미치지 않습니다. 인접한 셀렉터로 이 작업을 수행할 수 있습니다.인접 선택자와 형제 선택자의 차이점은 인접 선택자는 참조 요소 다음의 첫 번째 요소만 대상으로 한다는 점을 기억하십시오.
