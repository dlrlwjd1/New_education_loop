# Case study: How Meta performs front-end testing

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/html-and-css-in-depth/lecture/UsSnr/case-study-how-meta-performs-front-end-testing)

## 개요
- 테스트를 거친 응용 프로그램을 통해 원래 구축된 것이 의도한 대로 작동하고 있다는 확신을 가질 수 있습니다.

## 내용
- 테스트를 거친 응용 프로그램을 통해 원래 구축된 것이 의도한 대로 작동하고 있다는 확신을 가질 수 있습니다.
- 시간이 지남에 따라 많은 코드를 작성하고 하나의 하위 시스템에서 하나의 작은 문제가 발생하여 결국 앱에서 수많은 오류가 발생할 수 있습니다.예를 들어 메시징 앱을 만들 때 메시지가 한 시간 동안 중단되면 사람들이 친구나 가족에게 연락할 수 없게 됩니다.
- 프론트엔드 테스트를 처음 배웠을 때 툴을 제대로 작동시킨 다음 직접 빌드하거나 자동으로 실행하거나 어딘가에서 지속적인 통합을 통해 실행할 수 있는 자체 앱을 갖는 것이 실제로 매우 만족스러웠습니다.
- 소비자 고객이 사용하는 제품을 만드는 제품 팀이 있고, 제품이 안정적인지 확인하기 위한 테스트를 작성해야 하는 팀은 바로 이들입니다.
- 회사에서 각자의 부품에 대한 테스트를 작성하는 것은 모든 사람의 책임이라고 생각합니다.제품이 어떻게 작동하는지 모르기 때문에 들어와 제품을 테스트하는 슈퍼 팀은 하나도 없을 것입니다.
- 일반적으로 우리가 하는 일은 테스트 기준을 설정하는 것이므로 모든 새로운 기능에 대해 최소한 몇 가지 테스트를 거쳐야 합니다.이렇게 하면 이미 테스트를 마칠 때까지 제품을 출시할 준비가 되지 않았으므로 다른 방법보다 훨씬 더 많은 확신을 가질 수 있습니다.
- 도전적인 활동, 좋은 테스트를 작성하는 것은 어렵고 테스트를 작성하는 데 자부심을 느끼는 것과 마찬가지로 만들고 싶은 제품을 만드는 데 자부심을 가질 것입니다.

## 예시
- 시간이 지남에 따라 많은 코드를 작성하고 하나의 하위 시스템에서 하나의 작은 문제가 발생하여 결국 앱에서 수많은 오류가 발생할 수 있습니다.예를 들어 메시징 앱을 만들 때 메시지가 한 시간 동안 중단되면 사람들이 친구나 가족에게 연락할 수 없게 됩니다.

- 일반적으로 우리가 하는 일은 테스트 기준을 설정하는 것이므로 모든 새로운 기능에 대해 최소한 몇 가지 테스트를 거쳐야 합니다.이렇게 하면 이미 테스트를 마칠 때까지 제품을 출시할 준비가 되지 않았으므로 다른 방법보다 훨씬 더 많은 확신을 가질 수 있습니다. 도전적인 활동, 좋은 테스트를 작성하는 것은 어렵고 테스트를 작성하는 데 자부심을 느끼는 것과 마찬가지로 만들고 싶은 제품을 만드는 데 자부심을 가질 것입니다.
