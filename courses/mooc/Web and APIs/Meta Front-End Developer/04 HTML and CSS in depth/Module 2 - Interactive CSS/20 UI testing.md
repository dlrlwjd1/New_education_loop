# UI testing

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/html-and-css-in-depth/lecture/ZmvKV/ui-testing)

## 개요
- 이와 같은 시나리오에 대응하기 위해 개발자는 엄격한 사용자 인터페이스 또는 UI 테스트 전략을 사용하여 최적의 고객 만족을 보장합니다.

## 내용
- 이와 같은 시나리오에 대응하기 위해 개발자는 엄격한 사용자 인터페이스 또는 UI 테스트 전략을 사용하여 최적의 고객 만족을 보장합니다.
- 또한 브라우저에서 크로스 디바이스 테스트를 수행하는 방법에 대한 실제 예제도 확인할 수 있습니다.
- 다양한 유형의 UI 테스트에 대해 배웠으니, 이제 웹 개발자 도구를 사용하여 크로스 디바이스 테스트를 수동으로 수행하는 방법을 배울 준비가 되었습니다.
- 개발자 도구의 성능 탭에서 네트워크 옵션을 사용하여 다양한 모바일 네트워크 속도를 시뮬레이션할 수 있습니다.
- 가상 모바일 소프트웨어 및 언리얼 모바일 하드웨어에서 테스트를 수행하는 데 사용할 수 있는 도구가 많이 있습니다.
- 많은 기업에는 실제 환경 테스트를 수행하기 위해 많은 모바일 장치를 갖춘 사내 실험실이 있습니다.
- 또한 크로스 디바이스 테스트를 수행하는 데 사용할 수 있는 웹 개발자 도구에 대해서도 배웠습니다.

## 예시
- 이와 같은 시나리오에 대응하기 위해 개발자는 엄격한 사용자 인터페이스 또는 UI 테스트 전략을 사용하여 최적의 고객 만족을 보장합니다.

## 요약
- 많은 기업에는 실제 환경 테스트를 수행하기 위해 많은 모바일 장치를 갖춘 사내 실험실이 있습니다. 또한 크로스 디바이스 테스트를 수행하는 데 사용할 수 있는 웹 개발자 도구에 대해서도 배웠습니다.
