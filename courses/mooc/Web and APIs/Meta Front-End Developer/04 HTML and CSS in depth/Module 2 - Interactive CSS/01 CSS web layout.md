# CSS web layout

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/html-and-css-in-depth/lecture/qsWww/css-web-layout)

## 개요
- 이 개발에는 CSS의 반응형 디자인 도입이 포함되며 플렉스 박스, 그리드 및 박스와 같은 레이아웃 옵션을 통해 더욱 성장했습니다.

## 내용
- 이 개발에는 CSS의 반응형 디자인 도입이 포함되며 플렉스 박스, 그리드 및 박스와 같은 레이아웃 옵션을 통해 더욱 성장했습니다.
- CSS는 웹 페이지를 더 보기 좋게 만드는 글꼴, 색상, 레이아웃, 크기 및 기타 스타일 서식 옵션을 수정하여 웹 페이지를 향상시키는 데 사용할 수 있습니다.
- 이전 강좌에서 디스플레이 속성이 라인 상자 또는 블록 상자 모델에서 렌더링된 상자가 html 요소에 사각형이나 상자를 할당하는지 여부를 결정한다는 것을 기억했을 것입니다.
- 예를 들어 ID가 있는 html 요소에 대한 상대 CSS 규칙에는 블록 값이 있는 display 속성이 포함됩니다.
- 표시 상자의 속성을 블록 유형으로 변경하는 코드는 블록 유형을 사용하여 만든 레이아웃도 좋지만 요구 사항이 진화하면서 플렉스 박스 및 그리드와 같은 CSS 웹 레이아웃이 개발되어 여러 요소에 대한 규칙을 만드는 데 도움이 되었습니다.
- 웹 페이지의 특정 섹션을 미세 조정할 수 있는 더 나은 옵션을 통해 유연성과 차원성을 높였습니다.이 둘의 주요 차이점은 단어에서 알 수 있듯이 플렉스 박스는 1 차원이고 그리드는 2 차원이라는 것입니다.
- 예를 들어 I.D가 있는 flex box 속성에는 flex를 값으로 사용하는 display 속성이 포함되어 있고, flex box는 float 요소를 사용하여 CSS에 대한 응답성을 높이고, 1차원으로 배치하는 것은 주어진 플렉스 상자 컨테이너가 축을 따라 열 또는 행에 항목을 정렬한다는 것을 의미합니다.

## 예시
