# Common errors

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/html-and-css-in-depth/lecture/cvrV3/common-errors)

## 개요
- 앞으로 몇 분 동안 프로그래밍에서 흔히 발생하는 오류와 이러한 오류를 방지하기 위해 구현할 수 있는 모범 사례에 대해 알아보겠습니다.

## 내용
- 앞으로 몇 분 동안 프로그래밍에서 흔히 발생하는 오류와 이러한 오류를 방지하기 위해 구현할 수 있는 모범 사례에 대해 알아보겠습니다.
- 예를 들어 다음은 색상 값을 허용하고 색상, 배경, 색상, 글꼴, 색상, 테두리 색상을 혼합할 수 있는 다양한 속성 중 일부에 대한 간략한 목록입니다.
- 또는 플렉스 박스, 그리드 등과 같이 각각 고유한 속성 세트를 사용하여 동일한 페이지를 디자인할 수 있는 방법이 여러 개 있는 경우가 많습니다.
- 일반적인 오류를 방지하기 위해 적용할 수 있는 모범 사례 중 하나는 속기를 사용하는 것입니다.속성 하나를 대신 사용하여 속성이 4개 있는 코드를 작성할 수 있습니다.
- 앞서 언급한 오류와 방법이 완전하지는 않지만, 학습에 가장 좋은 방법은 더 많은 웹 페이지를 디자인하고 코드에 모범 사례를 통합하는 것입니다.
- 예를 들어 레이아웃 내부에 규칙을 적용할 수 있는 앵커 태그가 있는 클래스가 포함된 분할 태그가 있는 경우, 이는 규칙의 대상 요소를 지정하는 것과 관련이 있습니다.
- 범용 또는 별표 선택기를 사용하여 브라우저별 구성을 제거하면 웹 페이지에 잘못 구성된 레이아웃이 나타날 가능성을 방지하고 나중에 많은 노력을 절약할 수 있습니다.

## 예시
- 앞으로 몇 분 동안 프로그래밍에서 흔히 발생하는 오류와 이러한 오류를 방지하기 위해 구현할 수 있는 모범 사례에 대해 알아보겠습니다.

## 요약
- 예를 들어 레이아웃 내부에 규칙을 적용할 수 있는 앵커 태그가 있는 클래스가 포함된 분할 태그가 있는 경우, 이는 규칙의 대상 요소를 지정하는 것과 관련이 있습니다. 범용 또는 별표 선택기를 사용하여 브라우저별 구성을 제거하면 웹 페이지에 잘못 구성된 레이아웃이 나타날 가능성을 방지하고 나중에 많은 노력을 절약할 수 있습니다.
