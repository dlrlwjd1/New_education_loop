# Semantic tags in action

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/html-and-css-in-depth/lecture/AoFb0/semantic-tags-in-action)

## 개요
- 그들은 페이지에 여러 블로그 게시물이 포함될 것이며 검색 엔진과 접근성 소프트웨어가 페이지의 의미를 이해할 수 있도록 시맨틱 html을 사용해야 한다고 말했습니다.

## 내용
- 그들은 페이지에 여러 블로그 게시물이 포함될 것이며 검색 엔진과 접근성 소프트웨어가 페이지의 의미를 이해할 수 있도록 시맨틱 html을 사용해야 한다고 말했습니다.
- 구체적으로 헤더 요소는 Little Lemon 로고를 표시하는 데 사용되고 탐색 요소는 웹사이트의 탐색 구조를 설명하는 데 사용됩니다.
- 검색 엔진 또는 접근성 소프트웨어가 이 문서를 읽을 때 시맨틱 태그는 소프트웨어가 문서의 여러 섹션의 목적과 의미를 이해하는 데 도움이 됩니다.
- 헤더 요소 안에 이미지 태그를 사용하여 Little Lemon 로고를 추가합니다.
- 목록 항목 안에 앵커 태그를 사용하여 index.html, location.html 및 blog.html 용 하이퍼링크를 추가합니다.
- 그런 다음 제목 아래에 블로그 게시물 텍스트가 포함된 단락 요소를 추가합니다.
- Little Lemon Restaurant은 블로그를 통해 많은 비즈니스를 얻을 수 있을 것이며 장애가 있는 고객들도 문제 없이 블로그에 접속할 수 있을 것이라고 확신합니다.

## 예시
- Little Lemon Restaurant은 블로그를 통해 많은 비즈니스를 얻을 수 있을 것이며 장애가 있는 고객들도 문제 없이 블로그에 접속할 수 있을 것이라고 확신합니다.
