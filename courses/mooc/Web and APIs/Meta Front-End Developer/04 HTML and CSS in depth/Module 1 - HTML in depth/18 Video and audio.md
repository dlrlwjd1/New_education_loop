# Video and audio

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/html-and-css-in-depth/lecture/NHaRT/video-and-audio)

## 개요
- HTML 비디오 및 오디오 태그는 웹 페이지에 미디어를 삽입하는 데 사용되며 두 태그 모두 웹 브라우저에서 재생할 수 있는 다양한 파일 형식을 지원합니다.

## 내용
- HTML 비디오 및 오디오 태그는 웹 페이지에 미디어를 삽입하는 데 사용되며 두 태그 모두 웹 브라우저에서 재생할 수 있는 다양한 파일 형식을 지원합니다.
- 비디오의 경우 대부분의 웹 브라우저, MP4, WebM 및 OGG에서 지원되는 파일 형식은 다음과 같습니다.
- 파일 형식이 지원되지 않는 경우 비디오 태그를 사용하여 여러 소스를 지정할 수 있습니다.
- 웹 브라우저에서 한 형식을 다른 형식보다 사용하는 것을 선호하는 경우 원하는 순서로 형식을 지정해야 합니다.
- 비디오 태그 자체에 사용할 수 있는 속성도 있으므로 비디오 플레이어를 사용자 지정할 수 있습니다.
- 비디오 플레이어를 사용자 지정하는 데 사용할 수 있는 다른 속성도 있습니다.
- 비디오 플레이어와 마찬가지로 오디오 플레이어를 사용자 지정할 수도 있습니다.

## 예시
- 예를 들어 width 및 height 속성을 사용하여 플레이어의 너비와 높이를 지정할 수 있습니다.

## 요약
- 비디오 플레이어를 사용자 지정하는 데 사용할 수 있는 다른 속성도 있습니다. 비디오 플레이어와 마찬가지로 오디오 플레이어를 사용자 지정할 수도 있습니다.
