# Module summary: HTML deep dive

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/html-and-css-in-depth/lecture/xWsIF/module-summary-html-deep-dive)

## 개요
- 어떤 초급 직업과 진로를 선택할 수 있는지, 개발자의 하루가 어떤 모습인지, HTML 및 CSS 개발자로서 누구와 함께 일할지 등을 알아보세요.

## 내용
- 어떤 초급 직업과 진로를 선택할 수 있는지, 개발자의 하루가 어떤 모습인지, HTML 및 CSS 개발자로서 누구와 함께 일할지 등을 알아보세요.
- HTML과 CSS가 어떻게 지속적으로 개선되고 있는지, HTML과 CSS 사용이 데스크톱 PC를 넘어선 방법 다음으로 시맨틱 태그와 메타태그에 대해 알아보았습니다.
- 이러한 주제를 살펴본 후에는 HTML 문서의 기본 Open Graph Protocol Meta 태그에서 메타데이터 및 메타데이터 태그가 사용되는 이유를 설명하고 소셜 미디어 카드를 설정할 때 OG 프로토콜을 적용하는 방법을 시연할 수 있을 것입니다.
- 이 주제에는 양식 및 유효성 검사, 클라이언트 측 유효성 검사, 양식 제출, 라디오 버튼 및 브라우저 차이점에 대한 학습이 포함되었습니다.
- 기본 양식을 작성 및 테스트하고, HTML 유효성 검사 유형의 가능성을 식별하고, 양식에서 웹 서버로 데이터를 보내는 방법을 설명했습니다.
- 또한 이제 라디오 버튼 사용을 시연하고 양식이 브라우저 간에 일관되게 표시되도록 하는 방법을 설명할 수 있을 것입니다.
- 재생되는 미디어를 평가할 수 있는 비디오 및 오디오 플레이어를 만드세요.iframe 태그의 용도를 파악하고 iframe 태그를 사용할 때 보안 위험을 식별 및 완화하고 캔버스 요소의 용도를 식별하는 방법을 알아봅니다.
