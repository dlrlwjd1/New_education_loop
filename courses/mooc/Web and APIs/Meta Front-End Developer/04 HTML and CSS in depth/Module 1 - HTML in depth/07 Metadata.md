# Metadata

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/html-and-css-in-depth/lecture/EeFw9/metadata)

## 개요
- 검색 엔진이 웹 페이지를 분석하는 방법과 메타 태그가 검색 엔진에 정보를 제공하는 데 어떻게 도움이 되는지 알아봅니다.

## 내용
- 검색 엔진이 웹 페이지를 분석하는 방법과 메타 태그가 검색 엔진에 정보를 제공하는 데 어떻게 도움이 되는지 알아봅니다.
- 검색 엔진이 웹 페이지를 분석할 때 정확히 어떤 역할을 하는지 궁금하실 수도 있습니다.
- 다른 html 문서로 연결되는 링크를 찾으면 해당 문서에 대한 링크를 따라가며 전체 웹 사이트 분석을 마칠 때까지 링크를 계속 따라갑니다.
- 순위가 어떻게 결정되는지는 공개되지 않았지만 검색 엔진이 웹사이트를 분석하고 순위를 매기는 방식에 영향을 미치기 위해 따를 수 있는 모범 사례가 많이 있습니다.
- 주요 검색 엔진 중 하나는 이제 이 메타데이터를 무시하고 다른 하나는 키워드 메타데이터를 스팸 지표로 사용하므로 최신 웹 페이지에는 이 메타데이터를 포함하지 않는 것이 좋습니다.
- 일부 봇은 이를 무시하므로 봇이 페이지를 분석하는 것을 막기 위해 이에 의존하지 않는 것이 가장 좋으며, 어떤 팔로우도 봇에게 웹 페이지의 링크를 방문하지 말라고 지시하지 않습니다.
- 현재로서는 작성자 설명, 키워드, 로봇 및 뷰 포트 메타데이터가 모두 웹 페이지의 검색 엔진 최적화에 중요한 역할을 한다는 사실을 아는 것이 중요합니다.

## 예시
- 순위가 어떻게 결정되는지는 공개되지 않았지만 검색 엔진이 웹사이트를 분석하고 순위를 매기는 방식에 영향을 미치기 위해 따를 수 있는 모범 사례가 많이 있습니다.

## 요약
- 일부 봇은 이를 무시하므로 봇이 페이지를 분석하는 것을 막기 위해 이에 의존하지 않는 것이 가장 좋으며, 어떤 팔로우도 봇에게 웹 페이지의 링크를 방문하지 말라고 지시하지 않습니다. 현재로서는 작성자 설명, 키워드, 로봇 및 뷰 포트 메타데이터가 모두 웹 페이지의 검색 엔진 최적화에 중요한 역할을 한다는 사실을 아는 것이 중요합니다.
