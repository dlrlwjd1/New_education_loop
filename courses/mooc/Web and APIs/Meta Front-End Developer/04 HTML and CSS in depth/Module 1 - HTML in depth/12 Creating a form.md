# Creating a form

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/html-and-css-in-depth/lecture/NDMJL/creating-a-form)

## 개요
- Little Lemon 레스토랑은 온라인 주문을 받아 집에 있는 고객에게 음식을 배달하는 방식으로 서비스를 확장하고자 합니다.

## 내용
- Little Lemon 레스토랑은 온라인 주문을 받아 집에 있는 고객에게 음식을 배달하는 방식으로 서비스를 확장하고자 합니다.
- 이 비디오에서는 Little Lemon 웹 사이트에서 사용자 계정에 대한 간단한 가입 양식을 만드는 방법을 배웁니다.
- 첫 번째 이름 요소와 마찬가지로 유형 속성을 텍스트로 설정하고 이름 및 ID 속성을 user_last_name으로 설정합니다.
- 사용자가 이 필드에 유효한 이메일 주소를 입력하도록 하기 위해 type 속성을 email로 설정했습니다.
- 사용자가 암호를 입력할 때 화면에서 암호를 숨기고 싶어서 유형 속성을 암호로 설정했습니다.
- 그런 다음 레이블을 입력 필드에 연결하기 위해 네 개의 속성을 추가하고 해당 값을 입력 요소의 ID 속성 값과 일치하도록 설정합니다.
- 이 비디오에서는 각각 고유한 CSS 블록에 여러 개의 서로 다른 입력 필드가 있는 기본 양식을 만드는 방법을 배웠고, 안전한 방식으로 양식을 제출하도록 메서드 속성을 설정하는 방법을 살펴보았으며, 이제 사용자 경험을 개선하기 위해 레이블을 입력 필드와 연결하는 방법도 알게 되었습니다.
