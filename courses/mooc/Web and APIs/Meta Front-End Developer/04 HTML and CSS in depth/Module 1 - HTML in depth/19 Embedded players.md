# Embedded players

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/html-and-css-in-depth/lecture/VMsB2/embedded-players)

## 개요
- 오디오 요소 안에 소스 요소를 추가하고 src 속성을 music.ogg 로 설정했습니다.

## 내용
- 오디오 요소 안에 소스 요소를 추가하고 src 속성을 music.ogg 로 설정했습니다.
- 또한 오디오 플레이어가 오디오의 끝에 도달하면 자동으로 돌아가서 처음부터 다시 재생하도록 오디오를 반복 재생하도록 요청했습니다.
- 또한 사용자가 오디오를 재생하고 일시 중지할 수 있도록 컨트롤을 추가해야 합니다.
- 재생 버튼을 누르면 오디오가 시작되고 일시 중지를 누르면 오디오가 일시 중지됩니다.
- 비디오 요소 안에 소스 요소를 추가하고 src 속성을 video.mp4 로 설정했습니다.
- 그래서 비디오 요소로 돌아가서 너비 속성을 320으로 설정하고, 높은 속성을 240으로 설정했습니다.
- 이러한 오디오 및 비디오 플레이어는 정보 페이지를 탐색할 때 고객의 관심을 끌 것입니다.

## 예시
- 이러한 오디오 및 비디오 플레이어는 정보 페이지를 탐색할 때 고객의 관심을 끌 것입니다.

## 요약
- 그래서 비디오 요소로 돌아가서 너비 속성을 320으로 설정하고, 높은 속성을 240으로 설정했습니다. 이러한 오디오 및 비디오 플레이어는 정보 페이지를 탐색할 때 고객의 관심을 끌 것입니다.
