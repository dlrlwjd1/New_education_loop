## 내용
- 이를 추가하기 위해 첫 번째 div 요소에 입력 요소를 추가하고 type 속성을 date로 설정합니다.
- 다시 한 번 말씀드리지만, 좋은 사용자 경험을 제공하기 위해 요소 앞에 레이블을 추가하고 콘텐츠를 인원수로 설정합니다.
- 데이터 목록 입력 유형을 사용하면 드롭다운 목록에 표시될 사용 가능한 옵션 목록을 지정할 수 있습니다.
- 그런 다음 데이터 목록 요소를 추가하고 입력 요소의 목록 속성 값과 일치하도록 ID 속성을 설정합니다.
- 다시 말하지만, 좋은 사용자 경험을 제공하기 위해 입력 요소 앞에 레이블을 추가하고 해당 콘텐츠를 location으로 설정합니다.
- 마지막으로, 데이터 목록 입력을 통해 위치에 대한 옵션을 선택하거나 입력을 시작하여 사용 가능한 옵션의 범위를 좁힐 수 있습니다.
- 이제 캘린더를 추가하고, 값이 포함된 슬라이더를 만들고, 사용자가 드롭다운 목록에서 옵션을 선택하거나 옵션을 입력할 수 있는 데이터 목록을 추가할 수 있습니다.
