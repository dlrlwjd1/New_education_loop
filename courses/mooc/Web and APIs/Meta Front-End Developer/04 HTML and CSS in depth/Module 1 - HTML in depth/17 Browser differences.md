# Browser differences

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/html-and-css-in-depth/lecture/gQorv/browser-differences)

## 개요
- 이 비디오에서는 양식 요소가 다양한 웹 브라우저에서 어떻게 다르게 표시되는지와 이 문제를 해결하는 방법을 살펴봅니다.

## 내용
- 이 비디오에서는 양식 요소가 다양한 웹 브라우저에서 어떻게 다르게 표시되는지와 이 문제를 해결하는 방법을 살펴봅니다.
- 동일한 입력 유형의 HTML 코드는 파이어폭스, 마이크로소프트 엣지, 크롬, 사파리와 같은 웹 브라우저에서 다르게 표시됩니다.
- 다시 말하지만, 정확히 동일한 입력 유형의 HTML 코드를 사용하면 브라우저마다 확인란이 선택된 상태와 선택되지 않은 상태로 다르게 표시됩니다.
- 다양한 웹 브라우저에서 HTML 양식 요소가 어떻게 일관되지 않게 표시되는지 살펴보았으니 이제 이 문제를 해결하는 방법을 중점적으로 살펴보겠습니다.
- 다양한 HTML 양식 요소에 대한 CSS 규칙을 정의하면 웹 브라우저에서 요소의 스타일을 일관되게 유지할 수 있습니다.
- 입력 HTML 요소를 선택하려면 입력 요소 선택기를 사용하고 대괄호 한 쌍을 추가하여 개별 스타일을 지정한 다음 equals (이 경우 text 또는 email) 를 입력합니다.
- 이제 웹 브라우저에서 다양한 HTML 요소의 모양에 주의를 기울이는 것이 왜 중요한지, 그리고 CSS 규칙과의 일관성을 유지하는 방법을 알게 될 것입니다.

## 예시
- 예를 들어 입력 상자의 높이와 모서리에 미묘한 차이가 있습니다.

## 요약
- 입력 HTML 요소를 선택하려면 입력 요소 선택기를 사용하고 대괄호 한 쌍을 추가하여 개별 스타일을 지정한 다음 equals (이 경우 text 또는 email) 를 입력합니다. 이제 웹 브라우저에서 다양한 HTML 요소의 모양에 주의를 기울이는 것이 왜 중요한지, 그리고 CSS 규칙과의 일관성을 유지하는 방법을 알게 될 것입니다.
