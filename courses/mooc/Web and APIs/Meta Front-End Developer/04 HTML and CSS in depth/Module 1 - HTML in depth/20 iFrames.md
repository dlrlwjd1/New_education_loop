# iFrames

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/html-and-css-in-depth/lecture/8nTJT/iframes)

## 개요
- iframe은 다른 웹 사이트의 콘텐츠를 웹 페이지에 배치하거나 포함할 수 있는 HTML 요소입니다.

## 내용
- iframe은 다른 웹 사이트의 콘텐츠를 웹 페이지에 배치하거나 포함할 수 있는 HTML 요소입니다.
- iframe은 광고를 표시하는 데 자주 사용되지만 소셜 미디어 게시물과 같은 다른 웹 사이트의 콘텐츠를 삽입하는 데에도 사용할 수 있습니다.
- 너비 및 높이 속성을 사용하여 iframe의 너비와 높이를 설정할 수도 있습니다.
- iframe 요소에 allow 속성을 추가하고 값을 카메라 없음 및 마이크 없음으로 설정합니다.이제 그건 쉬웠어요.
- 현재 주목해야 할 중요한 점은 샌드박스 속성을 빈 값과 함께 사용하면 모든 샌드박스 제한이 iframe에 적용된다는 것입니다.
- 이러한 제한은 사용자의 보안을 유지하는 데 도움이 되지만 내장된 웹 페이지가 악용할 수 있는 웹 브라우저의 보안 취약성이 여전히 있을 수 있습니다.
- 따라서 iframe을 사용할 때는 항상 주의를 기울이고 삽입하려는 웹 사이트를 신뢰할 수 있는지 확인하는 것이 가장 좋습니다.

## 예시
- 예를 들어 iframe에서 파일 다운로드를 허용하려면 다운로드 허용 값을 허용하면 됩니다.

## 요약
- 이러한 제한은 사용자의 보안을 유지하는 데 도움이 되지만 내장된 웹 페이지가 악용할 수 있는 웹 브라우저의 보안 취약성이 여전히 있을 수 있습니다. 따라서 iframe을 사용할 때는 항상 주의를 기울이고 삽입하려는 웹 사이트를 신뢰할 수 있는지 확인하는 것이 가장 좋습니다.
