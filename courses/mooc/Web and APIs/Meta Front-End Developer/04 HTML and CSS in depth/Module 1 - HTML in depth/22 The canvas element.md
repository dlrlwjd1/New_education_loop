# The canvas element

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/html-and-css-in-depth/lecture/h4Las/the-canvas-element)

## 개요
- 웹 브라우저용 애니메이션 및 비디오 게임 콘텐츠를 제작하는 데 사용할 수 있는 저작 도구가 많이 있습니다.

## 내용
- 웹 브라우저용 애니메이션 및 비디오 게임 콘텐츠를 제작하는 데 사용할 수 있는 저작 도구가 많이 있습니다.
- 이 형식을 사용하는 이미지는 상호 작용이 없지만 애니메이션 콘텐츠를 삽입하거나 2D 비디오 게임 및 애니메이션을 제작하는 데 널리 사용됩니다.
- 비주얼 스튜디오 코드를 열고 인덱스 도트 html 안에 인덱스 도트 html과 애니메이션 도트 Js 두 파일을 설정했습니다.
- 캔버스 html 요소를 추가했습니다.너비 속성을 640으로 설정했고 높이 속성을 480으로 설정했습니다.
- 다음으로 캔버스 도트 get을 사용하여 두 개의 D 캔버스 컨텍스트를 찾아 매개 변수를 D에 전달합니다.
- 이 함수는 컨텍스트 도트 클리어 렉을 사용하여 캔버스 영역을 지운 다음 컨텍스트 도트 시작 경로, 컨텍스트 도트 아크 및 컨텍스트 도트 필 함수를 사용하여 현재 위치에 공을 그립니다.
- 애니메이션과 비디오 게임을 개발할 수 있는 가능성은 훨씬 더 많으며 개발을 단순화하는 데 사용할 수 있는 라이브러리도 많이 있습니다.

## 예시
- 애니메이션과 비디오 게임을 개발할 수 있는 가능성은 훨씬 더 많으며 개발을 단순화하는 데 사용할 수 있는 라이브러리도 많이 있습니다.

## 요약
