# Semantic tags and why we need them

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/html-and-css-in-depth/lecture/M4OoX/semantic-tags-and-why-we-need-them)

## 개요
- 이를 통해 검색 엔진과 스크린 리더와 같은 접근성 소프트웨어가 페이지의 내용을 이해할 수 있습니다.

## 내용
- 이를 통해 검색 엔진과 스크린 리더와 같은 접근성 소프트웨어가 페이지의 내용을 이해할 수 있습니다.
- 일반적인 HTML 페이지의 경우 머리글, 기본 및 바닥글 시맨틱 HTML 태그를 사용하여 구조를 의미론적으로 설명할 수 있습니다.
- Nav 태그를 사용하여 웹 페이지의 기본 탐색 섹션을 의미적으로 설명할 수도 있습니다.
- 또는 독립적으로 배포할 수 있는 문서 페이지 애플리케이션 또는 사이트에 포함된 자체 컴포지션일 수도 있습니다.
- 이러한 예로는 포럼 게시물, 잡지 또는 신문 기사, 블로그 게시물, 사용자가 제출한 의견, 대화형 위젯 또는 가젯 또는 기타 독립적인 콘텐츠 항목이 있습니다.
- 블로그 제목과 블로그 게시물의 날짜 및 작성자를 설명하는 단락 요소와 함께 기사 요소에 헤더 요소를 추가합니다.
- 섹션 요소를 추가하여 문서의 개별 섹션을 의미적으로 정의할 수 있습니다 섹션에는 섹션을 의미적으로 설명하는 제목 요소가 포함되어야 한다는 점에 유의해야 합니다.

## 예시
- 예를 들어 H1과 같은 제목 태그를 사용하면 콘텐츠가 제목임을 알 수 있습니다.

## 요약
- 블로그 제목과 블로그 게시물의 날짜 및 작성자를 설명하는 단락 요소와 함께 기사 요소에 헤더 요소를 추가합니다. 섹션 요소를 추가하여 문서의 개별 섹션을 의미적으로 정의할 수 있습니다 섹션에는 섹션을 의미적으로 설명하는 제목 요소가 포함되어야 한다는 점에 유의해야 합니다.
