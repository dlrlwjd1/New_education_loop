# UX with meta tags

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/html-and-css-in-depth/lecture/AAmO5/ux-with-meta-tags)

## 개요
- 소셜 네트워크는 친구, 가족, 동료 및 비즈니스 파트너와도 콘텐츠를 공유할 수 있는 훌륭한 도구입니다.링크를 공유하면 대부분의 소셜 네트워크에서는 링크 미리보기를 생성하여 사용자에게 연결된 웹페이지의 내용을 알려줍니다.

## 내용
- 소셜 네트워크는 친구, 가족, 동료 및 비즈니스 파트너와도 콘텐츠를 공유할 수 있는 훌륭한 도구입니다.링크를 공유하면 대부분의 소셜 네트워크에서는 링크 미리보기를 생성하여 사용자에게 연결된 웹페이지의 내용을 알려줍니다.
- Meta 태그를 사용하여 사용자에게 표시할 정보를 제어하면 웹 사이트를 공유할 때 더 많은 클릭을 얻을 수 있습니다.
- 프로토콜에는 많은 메타데이터 옵션을 사용할 수 있지만, 이에 대해 알아보기 전에 먼저 오픈 그래프 프로토콜 메타데이터를 정의하는 방법에 대해 알아보겠습니다.
- 오픈 그래프 프로토콜은 name 속성 대신 속성 속성을 사용하여 메타데이터 이름을 정의합니다.
- 이러한 오픈 그래프 프로토콜 속성을 함께 사용하면 소셜 미디어 플랫폼에서 공유 웹 링크의 미리보기를 만들 수 있습니다.
- 이제 소셜 네트워크에서 공유 콘텐츠를 미리 보면서 사용자 경험을 개선할 수 있도록 메타데이터를 사용하여 웹 페이지를 설명하는 방법을 배웠습니다.
- 다음에 소셜 네트워크에서 웹사이트를 공유할 때 Open Graph Protocol 속성에 대해 배운 내용을 활용하여 더 많은 클릭을 발생시킬 수 있습니다.

## 예시
- 예를 들어 en_US는 페이지가 영어이고 로케일이 미국임을 지정합니다.

## 요약
- 이제 소셜 네트워크에서 공유 콘텐츠를 미리 보면서 사용자 경험을 개선할 수 있도록 메타데이터를 사용하여 웹 페이지를 설명하는 방법을 배웠습니다. 다음에 소셜 네트워크에서 웹사이트를 공유할 때 Open Graph Protocol 속성에 대해 배운 내용을 활용하여 더 많은 클릭을 발생시킬 수 있습니다.
