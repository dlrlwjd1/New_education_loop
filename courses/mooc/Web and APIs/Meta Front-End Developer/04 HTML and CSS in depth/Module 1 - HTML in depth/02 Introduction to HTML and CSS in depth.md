# Introduction to HTML and CSS in depth

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/html-and-css-in-depth/lecture/awn0s/introduction-to-html-and-css-in-depth)

## 개요
- 이 소개 바로 뒤에 HTML과 CSS에 대한 간략한 개요가 있을 것입니다.

## 내용
- 이 소개 바로 뒤에 HTML과 CSS에 대한 간략한 개요가 있을 것입니다.
- 먼저 HTML이 실제 세계에서 어떻게 사용되는지 배우게 됩니다.
- 여기에는 시맨틱 태그와 메타 태그에 대한 학습과 잘 구성된 웹 페이지를 만들 수 있도록 구조화된 접근 방식의 중요성에 대한 학습이 포함됩니다.
- 고급 입력 유형, 입력의 유효성을 검사하는 방법, 양식의 사용자 경험을 개선하기 위한 피드백을 제공하는 방법에 대해 알아봅니다.
- 다음 HTML 섹션에서는 미디어 요소를 사용하여 웹 사이트에 활기를 불어넣는 데 초점을 맞출 것입니다.
- 뿐만 아니라 가상 클래스 선택기를 사용하여 웹 페이지의 상호 작용을 개선하는 방법도 배우게 됩니다.
- 순수 CSS를 사용하여 웹 페이지에 효과를 추가하는 방법을 배우고 기본 변환 및 전환 애니메이션과 키 프레임을 사용하는 고급 애니메이션을 다룹니다.

## 예시
- 그런 다음 교육 과정에서 읽은 내용을 참조하고 교육 과정 연습 중에 기술을 실습하여 지식을 통합하십시오.

## 요약
- 뿐만 아니라 가상 클래스 선택기를 사용하여 웹 페이지의 상호 작용을 개선하는 방법도 배우게 됩니다. 순수 CSS를 사용하여 웹 페이지에 효과를 추가하는 방법을 배우고 기본 변환 및 전환 애니메이션과 키 프레임을 사용하는 고급 애니메이션을 다룹니다.
