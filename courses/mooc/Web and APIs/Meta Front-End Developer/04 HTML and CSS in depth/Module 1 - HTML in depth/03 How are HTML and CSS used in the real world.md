# How are HTML and CSS used in the real world?

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/html-and-css-in-depth/lecture/IsFWS/how-are-html-and-css-used-in-the-real-world)

## 개요
- 이제 HTML이 웹 페이지를 만드는 데 사용되는 마크업 언어라는 것을 알고 계실 것입니다.

## 내용
- 이제 HTML이 웹 페이지를 만드는 데 사용되는 마크업 언어라는 것을 알고 계실 것입니다.
- HTML은 1990년부터 사용되어 왔으며, 원래는 사람들이 인터넷을 통해 정보를 공유할 수 있는 방법을 제공하기 위해 설계되었습니다.
- 이를 통해 오디오 및 비디오와 같은 멀티미디어 콘텐츠에 대한 지원이 향상되고, 웹 페이지를 보는 장치에 따라 웹 페이지 레이아웃 적용 등 반응형 디자인에 대한 지원이 향상되었으며, 슬라이더 및 범위 입력과 같은 새로운 양식 입력 유형, 날짜 및 색상 선택기, 새로운 양식 유효성 검사 기능, 맞춤법 검사 및 텍스트 편집과 같은 새로운 텍스트 작업 방법이 있습니다.
- 2011년에 CSS용으로 출시된 주요 기능 중 일부는 페이지를 보는 데 사용되는 미디어 콘텐츠나 장치에 관계없이 CSS가 웹 사이트를 스타일링하고 제어할 수 있도록 합니다.
- 현재 버전에 추가된 기능으로는 사용 중인 장치에 따라 다양한 스타일을 적용할 수 있는 미디어 쿼리, 개발자가 콘텐츠의 크기 조정 및 패딩 방식을 지정할 수 있는 상자 크기 조정 , 요소에 대해 여러 배경 이미지를 지정할 수 있는 다중 배경 , 개발자가 단색이나 스타일 대신 테두리로 이미지를 지정할 수 있는 텍스트 그림자 등이 있습니다.
- 기본적으로 HTML과 CSS를 함께 사용하면 웹사이트가 보는 기기에 따라 디자인과 레이아웃을 조정할 수 있습니다.
- 이 기능은 처음에는 휴대폰 및 태블릿과 같은 모바일 장치를 지원하는 데 사용되었지만 HTML과 CSS의 사용은 기존 웹 브라우저 및 웹 페이지를 넘어섰습니다.
