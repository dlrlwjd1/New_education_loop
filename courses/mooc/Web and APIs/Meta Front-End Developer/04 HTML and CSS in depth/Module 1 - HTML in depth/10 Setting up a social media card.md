# Setting up a social media card

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/html-and-css-in-depth/lecture/2mf5G/setting-up-a-social-media-card)

## 개요
- 첫 번째 메타 태그에서 속성 속성을 추가하고 그 값을 og:title로 설정했습니다.

## 내용
- 첫 번째 메타 태그에서 속성 속성을 추가하고 그 값을 og:title로 설정했습니다.
- 그런 다음 content 속성을 추가하고 해당 값을 메뉴에 설정합니다.
- 두 번째 메타 태그에서 속성 속성을 추가하고 값을 og:type으로 설정했습니다.
- 그런 다음 콘텐츠 속성을 추가하고 해당 값을 웹 사이트에 설정합니다.
- 세 번째 메타 태그에서 속성 속성을 추가하고 그 값을 og:image로 설정했습니다.
- 그런 다음 콘텐츠 속성을 추가하고 그 값을 Little Lemon 웹 사이트의 URL에 설정합니다.
- 그런 다음 콘텐츠 속성을 추가하고 그 가치를 가족 소유의 지중해식 레스토랑인 Little Lemon으로 설정합니다.

## 예시
- 그런 다음 콘텐츠 속성을 추가하고 그 가치를 가족 소유의 지중해식 레스토랑인 Little Lemon으로 설정합니다.

## 요약
- 그런 다음 콘텐츠 속성을 추가하고 그 값을 Little Lemon 웹 사이트의 URL에 설정합니다. 그런 다음 콘텐츠 속성을 추가하고 그 가치를 가족 소유의 지중해식 레스토랑인 Little Lemon으로 설정합니다.
