# Making the most of client-side validation

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/html-and-css-in-depth/lecture/R7n6S/making-the-most-of-client-side-validation)

## 개요
- 이 비디오에서는 HTML의 클라이언트 측 유효성 검사 기능과 CSS를 사용하여 데이터가 올바르지 않을 때 사용자에게 효과적으로 경고하는 방법에 대해 자세히 알아봅니다.

## 내용
- 이 비디오에서는 HTML의 클라이언트 측 유효성 검사 기능과 CSS를 사용하여 데이터가 올바르지 않을 때 사용자에게 효과적으로 경고하는 방법에 대해 자세히 알아봅니다.
- 지금까지 다양한 HTML 입력 유형과 이러한 입력 유형이 데이터 형식을 검증하는 방법에 대해 배웠지만 추가 검증을 위해 요소에 적용할 수 있는 추가 속성이 있습니다.
- 사용자가 사용자 이름이나 암호를 추가하지 않고 “제출” 버튼을 클릭하면 브라우저에서 양식을 웹 서버에 제출할 수 있습니다.
- 이제 필수 속성이 코드에 포함되었으므로 필드 중 하나가 비어 있는 상태에서 사용자가 제출 버튼을 클릭하면 요청이 웹 서버에 제출되지 않습니다.
- 사용자 이름을 최소 3자 , 최대 12자로 설정하려는 경우 또는 최소 암호 길이를 5자로 설정하여 더 안전한 암호를 만들고 싶다고 가정해 보겠습니다.
- 이제 데이터가 유효하지 않을 때 빨간색으로 바뀌는 양식 필드와 같이 브라우저가 사용자에게 오류를 전달하는 방식을 중점적으로 살펴보겠습니다.
- 이제 페이지가 처음 로드될 때 양식이 정상적으로 표시되고 사용자가 데이터 입력을 시작할 때 데이터가 유효하지 않은 경우 필드가 빨간색으로 바뀝니다.

## 예시
- 이제 페이지가 처음 로드될 때 양식이 정상적으로 표시되고 사용자가 데이터 입력을 시작할 때 데이터가 유효하지 않은 경우 필드가 빨간색으로 바뀝니다.

## 요약
- 이제 데이터가 유효하지 않을 때 빨간색으로 바뀌는 양식 필드와 같이 브라우저가 사용자에게 오류를 전달하는 방식을 중점적으로 살펴보겠습니다. 이제 페이지가 처음 로드될 때 양식이 정상적으로 표시되고 사용자가 데이터 입력을 시작할 때 데이터가 유효하지 않은 경우 필드가 빨간색으로 바뀝니다.
