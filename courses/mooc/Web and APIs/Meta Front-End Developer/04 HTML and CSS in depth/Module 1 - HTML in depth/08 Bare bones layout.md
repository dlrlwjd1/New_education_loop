# Bare bones layout

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/html-and-css-in-depth/lecture/b4o99/bare-bones-layout)

## 개요
- 개발자가 되는 데 있어 중요한 부분은 통합 개발 환경과 같이 사용하는 도구뿐만 아니라 시간이 지남에 따라 구축한 지식 및 코드 템플릿의 저장소이기도 합니다.

## 내용
- 개발자가 되는 데 있어 중요한 부분은 통합 개발 환경과 같이 사용하는 도구뿐만 아니라 시간이 지남에 따라 구축한 지식 및 코드 템플릿의 저장소이기도 합니다.
- 다시 말하지만, 이 파일에는 내용이 없지만 웹 페이지에 CSS 규칙을 쉽게 추가할 수 있도록 여기에 있습니다.
- 다시 말하지만, 이 폴더에 다른 CSS 파일도 추가하는 것이 가장 좋습니다.
- 현재 알아두어야 할 주요 사항은 소셜 미디어에서 웹 페이지를 공유할 계획이라면 이 HTML 섹션의 주석 처리를 제거하고 콘텐츠 속성을 업데이트해야 한다는 것입니다.
- 주석 처리된 코드의 다음 블록은 아이콘용입니다.웹 사이트의 웹 브라우저 탭에 아이콘을 표시하려면 여기에서 아이콘을 가리키도록 href 속성을 업데이트할 수 있습니다.
- 여기에는 웹사이트 제목 또는 로고의 헤더 요소, 웹사이트 탐색을 위한 탐색 요소, 기본 콘텐츠의 기본 요소, 저작권 고지 또는 보조 웹페이지 링크의 바닥글 요소가 포함됩니다.
- 쉽게 사용할 수 있도록 JS 폴더의 script.js 파일을 참조하도록 스크립트 요소가 이미 설정되어 있습니다.

## 예시
- 쉽게 사용할 수 있도록 JS 폴더의 script.js 파일을 참조하도록 스크립트 요소가 이미 설정되어 있습니다.

## 요약
- 여기에는 웹사이트 제목 또는 로고의 헤더 요소, 웹사이트 탐색을 위한 탐색 요소, 기본 콘텐츠의 기본 요소, 저작권 고지 또는 보조 웹페이지 링크의 바닥글 요소가 포함됩니다. 쉽게 사용할 수 있도록 JS 폴더의 script.js 파일을 참조하도록 스크립트 요소가 이미 설정되어 있습니다.
