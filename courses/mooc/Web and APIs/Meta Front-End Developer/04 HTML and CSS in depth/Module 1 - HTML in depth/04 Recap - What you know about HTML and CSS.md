# Recap: What you know about HTML and CSS

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/html-and-css-in-depth/lecture/Hocqi/recap-what-you-know-about-html-and-css)

## 개요
- 아마도 다른 강좌에서 HTML과 CSS에 대해 조금 알고 있거나 전혀 알지 못할 수도 있습니다.

## 내용
- 아마도 다른 강좌에서 HTML과 CSS에 대해 조금 알고 있거나 전혀 알지 못할 수도 있습니다.
- 각괄호 안에 여는 태그와 닫는 태그가 있는 HTML 요소가 HTML 문서를 구성합니다.
- HTML 태그와 올바른 구문 사용, 웹 문서에서 HTML 요소가 사용되는 방식 하지만 HTML로 무엇을 할 수 있을까요?
- 또한 올바른 HTML 구조와 적절한 요소를 기반으로 사용하는 것은 접근성 있는 웹 사이트를 구축하는 데 필수적인 부분입니다.
- HTML은 장애가 있는 사용자가 웹 사이트와 상호 작용하고 웹 사이트를 이해하는 데 사용하는 기술을 지원하여 웹 접근성을 보장하는 데 도움이 될 수 있습니다.
- HTML에 대해 이야기할 때 알아야 할 또 다른 중요한 개념은 문서 객체 모델 또는 DOM입니다.
- CSS를 사용하여 HTML 문서 내의 요소에 스타일을 지정하고, 상자 모델을 사용하여 매력적인 웹 페이지 레이아웃을 만들고, 일반 문서 흐름을 사용하여 페이지 요소를 정렬합니다.

## 예시
- 이제 몇 가지 기본 HTML 및 CSS 원칙과 사례를 살펴보겠습니다.

## 요약
- HTML에 대해 이야기할 때 알아야 할 또 다른 중요한 개념은 문서 객체 모델 또는 DOM입니다. CSS를 사용하여 HTML 문서 내의 요소에 스타일을 지정하고, 상자 모델을 사용하여 매력적인 웹 페이지 레이아웃을 만들고, 일반 문서 흐름을 사용하여 페이지 요소를 정렬합니다.
