# Form submission

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/html-and-css-in-depth/lecture/59ItJ/form-submission)

## 개요
- 프론트엔드 개발에 대해 더 많이 배우고 있기 때문에 해당 주문 버튼을 클릭하면 정확히 어떤 일이 발생하는지 궁금할 수 있습니다.

## 내용
- 프론트엔드 개발에 대해 더 많이 배우고 있기 때문에 해당 주문 버튼을 클릭하면 정확히 어떤 일이 발생하는지 궁금할 수 있습니다.
- 이제 웹 브라우저가 HTTP 요청 응답 주기를 사용하여 웹 서버와 통신한다는 것을 알 수 있습니다.
- 실제로 양식에서 HTTP GET 메서드 또는 HTTP POST 메서드를 사용하여 웹 서버에 데이터를 보낼 수 있는 두 가지 방법이 있습니다.
- 양식 요소의 method 속성을 사용하여 양식에서 사용할 메서드를 지정할 수 있습니다.
- 따라서 양식이 큰 경우 GET Method를 통해 웹 서버로 보낼 때 일부 데이터가 손실될 수 있습니다.
- 주소 또는 신용 카드 번호와 같은 개인 정보를 전송하는 경우 이는 중대한 개인 정보 보호 및 보안 위험입니다.
- post 메서드를 사용하여 양식을 제출하면 양식 데이터가 HTTP 요청의 내용에 삽입됩니다.

## 예시
- post 메서드를 사용하여 양식을 제출하면 양식 데이터가 HTTP 요청의 내용에 삽입됩니다.

## 요약
- 주소 또는 신용 카드 번호와 같은 개인 정보를 전송하는 경우 이는 중대한 개인 정보 보호 및 보안 위험입니다. post 메서드를 사용하여 양식을 제출하면 양식 데이터가 HTTP 요청의 내용에 삽입됩니다.
