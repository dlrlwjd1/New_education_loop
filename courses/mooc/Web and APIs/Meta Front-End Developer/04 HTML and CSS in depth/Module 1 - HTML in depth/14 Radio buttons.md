# Radio buttons

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/html-and-css-in-depth/lecture/Bynvf/radio-buttons)

## 개요
- 따라서 HTML 양식을 통해 고객은 사용 가능한 테이블 크기를 선택할 수 있을 뿐만 아니라 실내 또는 실외에 앉을지 결정할 수 있어야 합니다.

## 내용
- 따라서 HTML 양식을 통해 고객은 사용 가능한 테이블 크기를 선택할 수 있을 뿐만 아니라 실내 또는 실외에 앉을지 결정할 수 있어야 합니다.
- 첫 번째 필드 집합 요소 안에 세 가지 다른 테이블 크기를 나타내는 세 개의 입력 요소를 추가합니다.
- 두 번째 입력 요소에서는 type 속성을 radio로 설정하고 value 속성을 4로 설정했습니다.
- 세 번째 입력 요소에서는 type 속성을 radio로 설정하고 value 속성을 6으로 설정했습니다.
- 첫 번째 입력 요소에서 type 속성을 radio로 설정하고 value 속성을 실내로 설정했습니다.
- 두 번째 입력 요소에서는 type 속성을 radio로 설정하고 value 속성을 Outdoors로 설정했습니다.
- 이 동영상에서는 라디오 버튼을 사용하여 간단한 온라인 예약 양식을 만드는 방법을 살펴보았습니다.이제 리틀 레몬에서 더 많은 테이블 예약을 받을 수 있기를 바랍니다.

## 예시
- 이 동영상에서는 라디오 버튼을 사용하여 간단한 온라인 예약 양식을 만드는 방법을 살펴보았습니다.이제 리틀 레몬에서 더 많은 테이블 예약을 받을 수 있기를 바랍니다.
