# Introduction to the Program

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/html-and-css-in-depth/lecture/6j2oH/introduction-to-the-program)

## 개요
- 웹을 통해 메타에 있는 개발자들의 개인적인 이야기를 통해 배울 수 있는 이 프로그램에 등록할 수 있습니다.

## 내용
- 웹을 통해 메타에 있는 개발자들의 개인적인 이야기를 통해 배울 수 있는 이 프로그램에 등록할 수 있습니다.
- 그렇다면 이 전문가 자격증을 통해 메타와 같은 조직에 취직하기 위해 어떻게 준비할 수 있을까요?
- 프론트엔드 개발자 전문가 자격증은 메타에서 자격증을 취득하는 동시에 프론트엔드 개발 역할을 위한 취업 준비 기술을 쌓는 데 도움이 됩니다.
- 또한 다른 프론트 엔드 개발자 지망생들과 흥미로운 주제에 대해 토론하고 다양한 코딩 연습을 완료하여 기술을 향상시킬 수 있습니다.
- 메타에서 만든 널리 사용되는 JavaScript 라이브러리인 React의 세계로 들어가기 전에 부트스트랩 프레임워크를 사용하는 방법도 배우게 됩니다.
- 사용자의 요구 사항을 조사하고, Figma와 같은 인기 있는 산업 도구를 사용하여 와이어 프레임을 만들고, 상호 작용을 설계하는 방법을 배우게 됩니다.
- 면접 기술을 연습하고, 이력서를 다듬고, 일반적으로 기술 면접의 일부인 몇 가지 일반적인 코딩 문제를 해결하게 됩니다.프로그램을 완료하면 메타 커리어 프로그램 구인 게시판에 접속할 수 있습니다.

## 예시
- 면접 기술을 연습하고, 이력서를 다듬고, 일반적으로 기술 면접의 일부인 몇 가지 일반적인 코딩 문제를 해결하게 됩니다.프로그램을 완료하면 메타 커리어 프로그램 구인 게시판에 접속할 수 있습니다.
