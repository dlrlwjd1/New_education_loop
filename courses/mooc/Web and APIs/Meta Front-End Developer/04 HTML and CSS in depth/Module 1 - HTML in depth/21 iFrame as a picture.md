# iFrame as a picture

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/html-and-css-in-depth/lecture/U6idM/iframe-as-a-picture)

## 개요
- iFrame을 사용하면 먼저 연락하지 않고도 Little Lemon 웹 사이트에서 프로모션 이미지를 업데이트할 수 있기 때문입니다.

## 내용
- iFrame을 사용하면 먼저 연락하지 않고도 Little Lemon 웹 사이트에서 프로모션 이미지를 업데이트할 수 있기 때문입니다.
- 이를 위해 iFrame 요소에 SRC 속성을 추가하고 해당 값을 placeholder.png 로 설정합니다.
- 이렇게 하면 IFrame 내에서 JavaScript 파일이 실행되는 것을 방지할 수 있고 양식 제출 및 팝업 창 허용과 같은 IFrame 컨텍스트 내의 많은 브라우저 기능이 제한됩니다.
- allow 속성에 먼저 지불이라는 단어를 추가하고, 그 뒤에 공백 문자를 추가하고, 작은따옴표, 없음이라는 단어를 추가하고, 비활성화된 결제에 대해 다른 작은 따옴표를 추가합니다.
- 다음으로 카메라라는 단어를 추가하고 공백 뒤에 작은따옴표 안에 none이라는 단어를 추가합니다.
- 마지막으로 마이크라는 단어를 추가하고 다시 공백 뒤에 작은따옴표 안에 없음이라는 단어를 추가합니다.
- 먼저 샌드박스 속성을 추가하여 특정 브라우저 기능을 제한한 다음 allow 속성을 사용하여 잠재적으로 보안이 취약한 일부 브라우저 기능을 비활성화했습니다.

## 예시
- 먼저 샌드박스 속성을 추가하여 특정 브라우저 기능을 제한한 다음 allow 속성을 사용하여 잠재적으로 보안이 취약한 일부 브라우저 기능을 비활성화했습니다.

## 요약
- 마지막으로 마이크라는 단어를 추가하고 다시 공백 뒤에 작은따옴표 안에 없음이라는 단어를 추가합니다. 먼저 샌드박스 속성을 추가하여 특정 브라우저 기능을 제한한 다음 allow 속성을 사용하여 잠재적으로 보안이 취약한 일부 브라우저 기능을 비활성화했습니다.
