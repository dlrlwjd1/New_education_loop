# HTML and CSS in depth

Meta Front-End Developer 전문과정의 네 번째 강좌. 시맨틱 HTML, 폼과 미디어, CSS 레이아웃·효과·애니메이션을 심화 학습한다.

- 강좌 링크: <https://www.mooc.org/learn/html-and-css-in-depth>
- 구성: 3개 모듈, 영상 51개
- 수집 상태: 접근 가능한 영상 50개 Transcript 정리 완료
- 잠금 항목: `Exemplar: So far so good` 1개 — 선행 채점 과제 완료 필요
- 제외: 읽기 자료·퀴즈·채점 평가의 정답 및 제출

## 모듈 구성

- Module 1 - HTML in depth: 영상 23개
- Module 2 - Interactive CSS: 영상 22개
- Module 3 - Graded Assessment: 영상 6개 중 5개 수집, 잠금 1개

## 핵심 주제

- 시맨틱 HTML과 메타데이터
- 폼, 입력 검증과 멀티미디어
- Flexbox와 Grid
- 선택자, 의사 클래스와 의사 요소
- 전환, 변형과 애니메이션
