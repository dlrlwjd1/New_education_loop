# Module summary: Project functionality

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/meta-front-end-developer-capstone/lecture/vn11T/module-summary-project-functionality)

## 개요
- 이 모듈에서는 테이블 예약 시스템, API와 상호 작용, 경험 개선 등 각 수업에 대해 서로 다른 초점으로 다양한 개념, 기술 및 기술을 다루었습니다.

## 내용
- 이 모듈에서는 테이블 예약 시스템, API와 상호 작용, 경험 개선 등 각 수업에 대해 서로 다른 초점으로 다양한 개념, 기술 및 기술을 다루었습니다.
- 궁극적으로 이러한 수업을 완료하면 테이블 예약 시스템의 프런트 엔드를 설정하고 HTML 5 유효성 검사 및 라이브 데이터를 사용하여 UX를 개선하는 방법을 알게 될 것입니다.
- 첫 번째 단원에서는 테이블 예약 시스템을 구축하여 이를 수행하기 위해 다음 개념, React의 구성 요소, React의 상태 작업 및 여러 구성 요소의 상태 공유를 다시 검토해야 했습니다.
- Fetch FaceDE 함수를 사용하여 테이블 예약 API를 지운 다음 함수 호출을 시작했습니다.
- 그런 다음 예약 기능에서 앱의 예약 양식에 양식 유효성 검사를 추가하거나 사용자 경험을 개선하고 향상시키기 위해 개선했습니다.
- 접근성을 해결하고 통합함으로써 이제 모든 사용 사례에서 모든 잠재 사용자가 Little Lemon Reserve A Table 웹 앱에 액세스할 수 있습니다.
- 그 후 휴리스틱 평가를 완료하여 UI 디자인의 사용성 문제를 식별하고 이것이 얼마나 중요한지, 얼마나 시급한지 식별하여 즉시 또는 반복적인 디자인 프로세스의 일부로 수정할 수 있도록 합니다.

## 예시
- 접근성을 해결하고 통합함으로써 이제 모든 사용 사례에서 모든 잠재 사용자가 Little Lemon Reserve A Table 웹 앱에 액세스할 수 있습니다.
