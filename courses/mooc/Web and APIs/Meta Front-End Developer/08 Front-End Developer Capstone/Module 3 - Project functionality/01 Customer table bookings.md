# Customer table bookings

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/meta-front-end-developer-capstone/lecture/rAFf1/customer-table-bookings)

## 개요
- 상태가 없는 바로 그 정의에 따르면, 당신이 끝내게 될 것은 다수의 정적 구성 요소이며, React는 단순히 큰 HTML 조각을 추론하기 쉬운 작은 섹션으로 나누는 방법일 것입니다.

## 내용
- 상태가 없는 바로 그 정의에 따르면, 당신이 끝내게 될 것은 다수의 정적 구성 요소이며, React는 단순히 큰 HTML 조각을 추론하기 쉬운 작은 섹션으로 나누는 방법일 것입니다.
- 이 경우 구성 요소의 유일한 이점은 전체 웹 페이지를 더 작은 청크로 묘사하는 긴 코드를 분할할 수 있다는 것입니다.
- 이것은 React에서 구성 요소와 상태가 떼려야 뗄 수 없이 연결되어 있음을 보여줍니다.
- React에서 상태에 대해 배울 때 초보자에게 제공되는 가장 간단한 예 중 하나는 카운터 앱 또는 카운터 구성 요소의 예입니다.
- 이와 같은 간단한 예제를 직접 코딩하려면 React에서 렌더링에 대해 알아야 합니다.
- 물론 이것은 매우 기본적인 예이지만 React에서 상태를 처리하기 위해 알아야 하고 사용할 수 있는 다양한 것을 잘 보여주기 때문에 자주 사용됩니다.
- 제어된 구성 요소를 사용하면 React의 상태를 사용하여 주어진 양식을 제어할 수 있습니다.

## 예시
- 카운터는 예를 들어 특정 숫자 값으로 시작하는 단락으로 구성되며, 해당 단락 아래에는 클릭하면 단락에 표시된 값의 수가 업데이트되는 버튼이 됩니다.

## 요약
- 물론 이것은 매우 기본적인 예이지만 React에서 상태를 처리하기 위해 알아야 하고 사용할 수 있는 다양한 것을 잘 보여주기 때문에 자주 사용됩니다. 제어된 구성 요소를 사용하면 React의 상태를 사용하여 주어진 양식을 제어할 수 있습니다.
