# The importance of UX

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/meta-front-end-developer-capstone/lecture/DiQJ5/the-importance-of-ux)

## 개요
- 제품을 만들 때 기억해야 할 가장 중요한 것은 제품을 디자인했더라도 사용자가 아닐 수도 있다는 것입니다.

## 내용
- 제품을 만들 때 기억해야 할 가장 중요한 것은 제품을 디자인했더라도 사용자가 아닐 수도 있다는 것입니다.
- 그런 다음 사용자에게 다가가서 사용자와 상호 작용하고 제품을 어떻게 사용하는지 관찰하고 왜 특정 선택을 했는지 스스로에게 물어봐야 합니다.
- Little Lemon Web App에서 테이블을 예약하는 사용자에게 멋진 경험을 제공할 수 있도록 소비자와 고객으로부터 많은 것을 배울 수 있으므로 주의를 기울이고 질문하십시오.
- 양식 유효성 검사는 사용자가 웹 양식에 제출한 데이터가 정확한지 여부를 확인하기 위해 인터넷에서 사용되는 기술적 문구입니다.
- 포괄성을 보장하기 위해 마련된 접근성 법률을 준수하는 것 외에도 디자이너는 모든 사용 사례에 모든 잠재 사용자를 포함시키기 위해 모든 노력을 기울여야 합니다.
- 모든 사용자가 Little Lemon Reserve A Table Web 앱에 액세스할 수 있도록 연습을 완료하면 이 원칙을 실행에 옮길 것입니다.
- 그런 다음 인터페이스 사용성을 허용된 사용성 원칙과 비교하기 위해 경험적 평가를 수행하여 Little Lemon Reserve 테이블 인터페이스가 얼마나 사용 가능한지 결정합니다.

## 예시
- 포괄성을 보장하기 위해 마련된 접근성 법률을 준수하는 것 외에도 디자이너는 모든 사용 사례에 모든 잠재 사용자를 포함시키기 위해 모든 노력을 기울여야 합니다.

## 요약
- 모든 사용자가 Little Lemon Reserve A Table Web 앱에 액세스할 수 있도록 연습을 완료하면 이 원칙을 실행에 옮길 것입니다. 그런 다음 인터페이스 사용성을 허용된 사용성 원칙과 비교하기 위해 경험적 평가를 수행하여 Little Lemon Reserve 테이블 인터페이스가 얼마나 사용 가능한지 결정합니다.
