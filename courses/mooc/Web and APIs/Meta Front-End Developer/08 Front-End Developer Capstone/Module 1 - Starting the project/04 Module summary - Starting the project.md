# Module summary: Starting the project

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/meta-front-end-developer-capstone/lecture/1Qz7c/module-summary-starting-the-project)

## 개요
- 이 모듈에서는 테이블을 예약하려고 할 때 Little Lemon 웹사이트의 사용자가 직면한 문제를 해결하는 데 먼 길을 왔습니다.

## 내용
- 이 모듈에서는 테이블을 예약하려고 할 때 Little Lemon 웹사이트의 사용자가 직면한 문제를 해결하는 데 먼 길을 왔습니다.
- 그런 다음 효과적이고 효율적인 코드를 개발하고 궁극적으로 웹 앱을 성공적으로 개발하기 위해 올바른 도구를 사용하도록 프로젝트 설정으로 넘어갔습니다.
- 이제 컴퓨터에 Node.js 및 npm의 올바른 버전이 설치되어 있으며 이제 node.js와 상호 작용하고 create-react-app npm 패키지를 사용하여 Little Lemon 프로젝트를 자유롭게 구축할 수 있는 운영 체제에서 작업할 수 있습니다.
- Little Lemon 웹사이트에서 테이블 예약 기능을 명확히 하는 Figma를 사용하여 프로젝트 와이어프레임을 설계합니다.
- 웹사이트의 기능과 레이아웃, 창의적이고 브랜딩 측면이 한 번에 하나씩 해결되어 소유자와 Little Lemon 웹사이트 사용자가 조기 피드백을 제공할 수 있으므로 장기적으로 시간을 절약할 수 있습니다.
- 구성 요소는 Figma에서 만들어졌으며 디자인 전반에 걸쳐 재사용할 수 있는 요소를 사용하여 Little Lemon 웹사이트에서 테이블을 예약하기 위해 제안된 솔루션의 일관성을 만들고 관리하는 데 도움이 됩니다.
- 코딩 환경과 생성된 프로젝트에 대한 일련의 디자인을 설정하면 프로젝트 코딩을 시작할 수 있는 환상적인 위치에 있습니다.

## 예시
- 코딩 환경과 생성된 프로젝트에 대한 일련의 디자인을 설정하면 프로젝트 코딩을 시작할 수 있는 환상적인 위치에 있습니다.

## 요약
- 구성 요소는 Figma에서 만들어졌으며 디자인 전반에 걸쳐 재사용할 수 있는 요소를 사용하여 Little Lemon 웹사이트에서 테이블을 예약하기 위해 제안된 솔루션의 일관성을 만들고 관리하는 데 도움이 됩니다. 코딩 환경과 생성된 프로젝트에 대한 일련의 디자인을 설정하면 프로젝트 코딩을 시작할 수 있는 환상적인 위치에 있습니다.
