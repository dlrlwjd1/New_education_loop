# Introduction to the course

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/meta-front-end-developer-capstone/lecture/QiAVc/introduction-to-the-course)

## 개요
- 특히, Little Lemon의 소유자는 Little Lemon 웹사이트에서 예약 A 테이블 기능에 대해 부정적인 피드백을 받았습니다.

## 내용
- 특히, Little Lemon의 소유자는 Little Lemon 웹사이트에서 예약 A 테이블 기능에 대해 부정적인 피드백을 받았습니다.
- 이 과정에서는 사용자가 Little Lemon 레스토랑을 위한 테이블을 예약할 수 있도록 하는 최신 프런트 엔드 애플리케이션을 코딩하여 반응형 웹 앱을 구축하고 여러 기술을 시연하는 방법을 배우게 됩니다.
- 당면한 문제를 해결하기 위해 이 프로그램을 통해 배운 모든 기술과 기술을 결합하여 앱을 구축하는 과정을 안내합니다.
- 이 과정은 프로젝트 시작, 프로젝트 기초, 프로젝트 기능 및 프로젝트 평가의 4가지 모듈로 구성됩니다.
- 여기에는 이미 완료한 React 과정의 콘텐츠에 대한 간략한 요약과 링크가 포함되며, GitHub에서 프로젝트에 대한 코딩 환경, React 프로젝트 및 Git 리포지토리를 설정하여 프로젝트의 개발 단계를 진행할 준비가 됩니다.
- 프로젝트 기반을 다루는 모듈 2에서는 시맨틱 HTML, 메타 태그 및 오픈 그래프 프로토콜을 사용하여 웹 앱을 위한 최신 HTML 구조를 만듭니다.
- 보다 구체적으로, 당신은 당신의 프로젝트에 대한 자체 검토와 다른 학습자 솔루션에 대한 피어 리뷰를 수행할 수 있는 기회를 갖게 될 것입니다.

## 예시
- 이 과정의 중심에 있는 캡스톤 프로젝트는 레스토랑 Little Lemon과 관련된 시나리오를 기반으로 합니다.

## 요약
- 프로젝트 기반을 다루는 모듈 2에서는 시맨틱 HTML, 메타 태그 및 오픈 그래프 프로토콜을 사용하여 웹 앱을 위한 최신 HTML 구조를 만듭니다. 보다 구체적으로, 당신은 당신의 프로젝트에 대한 자체 검토와 다른 학습자 솔루션에 대한 피어 리뷰를 수행할 수 있는 기회를 갖게 될 것입니다.
