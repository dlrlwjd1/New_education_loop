# Setting up the project

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/meta-front-end-developer-capstone/lecture/DC7Ui/setting-up-the-project)

## 개요
- 그렇기 때문에 이 수업을 통해 해당 프로젝트의 설정과 관련된 몇 가지 개념을 다시 살펴보겠습니다.

## 내용
- 그렇기 때문에 이 수업을 통해 해당 프로젝트의 설정과 관련된 몇 가지 개념을 다시 살펴보겠습니다.
- 특히, 이는 시스템에 올바른 버전의 Node.js 및 npm이 설치되어 있고 Node.js와 자유롭게 상호 작용하고 프로젝트를 빌드할 수 있는 OS에서 작동하고 있음을 의미합니다.
- 컴퓨터에 git이 설치되어 있고 github 계정이 있으므로 코드에 대한 원격 저장소를 추가할 수 있습니다.
- 이와 같은 React 프로젝트를 설정하면 Node.js와 npm이 무엇인지, node.js가 높은 수준에서 React와 함께 작동하는 방식, package.json이 작동하는 방식과 그 목적이 무엇인지 이해해야 합니다.
- 또한 React 앱의 코드가 브라우저가 이해하지 못하는 JSX에서 브라우저가 이해하고 로컬로 번들로 묶고 다음과 같은 모듈 번들러의 도움으로 로컬로 제공되는 JS로 컴파일되는 방법을 포함하여 React 앱의 코드와 관련된 다양한 개념을 이해해야 합니다.
- 아마 아시다시피, create-react-app npm 패키지를 사용하여 React 프로젝트를 빌드할 때 해당 프로젝트는 로컬 git 설정과 초기 커밋을 추가합니다.
- 이 git 설정으로 제대로 작동하려면 다음 개념을 다시 방문하고 최소한 다음 개념을 이해해야 합니다.

## 예시
- 이 git 설정으로 제대로 작동하려면 다음 개념을 다시 방문하고 최소한 다음 개념을 이해해야 합니다.

## 요약
- 아마 아시다시피, create-react-app npm 패키지를 사용하여 React 프로젝트를 빌드할 때 해당 프로젝트는 로컬 git 설정과 초기 커밋을 추가합니다. 이 git 설정으로 제대로 작동하려면 다음 개념을 다시 방문하고 최소한 다음 개념을 이해해야 합니다.
