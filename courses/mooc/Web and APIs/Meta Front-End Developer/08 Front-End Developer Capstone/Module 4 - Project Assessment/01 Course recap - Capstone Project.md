# Course recap: Capstone Project

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/meta-front-end-developer-capstone/lecture/w62I6/course-recap-capstone-project)

## 개요
- 시작 React 앱을 만들고 Git을 사용하여 변경 사항을 추적하고 프로젝트의 UX 및 UI를 계획하는 것을 포함하여 프로젝트를 설정했습니다.

## 내용
- 시작 React 앱을 만들고 Git을 사용하여 변경 사항을 추적하고 프로젝트의 UX 및 UI를 계획하는 것을 포함하여 프로젝트를 설정했습니다.
- 또한 앱에 대한 메타 태그 및 개방형 그래프 프로토콜 설정을 작업하고 CSS 그리드를 다시 방문하여 반응형 레이아웃을 만들었습니다.
- 세 번째 모듈 프로젝트 기능은 테이블 예약 시스템을 코딩하고 Little Lemon Web 앱의 예약 페이지를 정의하는 것과 관련이 있습니다.
- 이 모듈은 동료들과 협력하고 완성된 Little Lemon 프로젝트를 조사하여 다른 프로젝트와 인코딩된 디자인을 비교할 수 있도록 하는 것입니다.
- 이 접근 방식은 학습을 더욱 강화하고 지식을 향상시키며 다른 사람들이 이 과정에서 완료해야 하는 동일한 문제와 연습 문제를 해결하는 방법에 대한 통찰력을 얻을 수 있는 기회를 제공합니다.
- 앞서 언급했듯이 동일한 작업을 완료하는 몇 가지 방법을 검토할 기회를 갖는 것은 학습에 추가되고 다양한 솔루션에 대한 더 넓은 범위의 이해를 제공하며 궁극적으로 React 개발자로서의 기량을 향상시켜야 합니다.
- 두 번째 수업은 과정 마무리의 형태를 취하며 프로젝트를 완료하기 위해 따라온 여정을 반성할 기회를 갖게 됩니다.

## 예시
- 두 번째 수업은 과정 마무리의 형태를 취하며 프로젝트를 완료하기 위해 따라온 여정을 반성할 기회를 갖게 됩니다.

## 요약
