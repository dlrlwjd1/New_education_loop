# Setting up a semantic HTML document

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/meta-front-end-developer-capstone/lecture/rm9LM/setting-up-a-semantic-html-document)

## 개요
- Semantic Structure라는 제목의 이 단원에서는 캡스톤 프로젝트의 구조를 적절하게 구성하는 것과 관련된 기술과 기술을 수정하고 리틀 레몬을 위한 예약 웹 앱에 대한 작업을 계속합니다.

## 내용
- Semantic Structure라는 제목의 이 단원에서는 캡스톤 프로젝트의 구조를 적절하게 구성하는 것과 관련된 기술과 기술을 수정하고 리틀 레몬을 위한 예약 웹 앱에 대한 작업을 계속합니다.
- 특히, 웹페이지가 더 많은 의미를 전달하여 사람, 스크린 리더 및 검색 엔진이 사이트의 마크업을 더 잘 이해할 수 있도록 하는 보다 현대적인 HTML5 구문인 시맨틱 HTML에 초점을 맞출 것입니다.
- Div 요소를 어디서나 사용하는 것이 모범 사례가 아니며, 대신 오늘날 사용 가능한 많은 의미의 HTML5 태그를 사용하는 데 집중해야 한다는 점을 상기시켜 드리겠습니다.
- 다양한 웹 페이지 섹션을 찾는 데 사용할 수 있는 이러한 태그는 탐색 요소, 머리글 요소, 바닥글 요소, 주 요소, 옆 요소 및 기사 요소를 포함하지만 이에 국한되지 않습니다.
- 또한 HTML의 역사, HTML4와 HTML5의 차이점, 그리고 HTML5 사양이 시맨틱 태그에 초점을 맞추는 이유를 다시 알게 될 것입니다.
- 하나는 Open Graph 프로토콜 설정에서 메타 태그를 완료하기 위한 것이고 다른 하나는 Git으로 진행 상황을 추적하는 것과 관련된 것입니다.
- 시맨틱 HTML, 메타 태그 및 오픈 그래프 태그와 관련된 지식을 더욱 강화하기 위해 추가 관련 리소스 및 유용한 읽기 자료로 연결하는 퀴즈와 읽기로 이 수업을 완료합니다.

## 예시
- Div 요소를 어디서나 사용하는 것이 모범 사례가 아니며, 대신 오늘날 사용 가능한 많은 의미의 HTML5 태그를 사용하는 데 집중해야 한다는 점을 상기시켜 드리겠습니다.

## 요약
- 하나는 Open Graph 프로토콜 설정에서 메타 태그를 완료하기 위한 것이고 다른 하나는 Git으로 진행 상황을 추적하는 것과 관련된 것입니다. 시맨틱 HTML, 메타 태그 및 오픈 그래프 태그와 관련된 지식을 더욱 강화하기 위해 추가 관련 리소스 및 유용한 읽기 자료로 연결하는 퀴즈와 읽기로 이 수업을 완료합니다.
