# Project components

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/meta-front-end-developer-capstone/lecture/9SzMB/project-components)

## 개요
- 전후크 시대에는 클래스 기반 구문을 사용하여 상태 저장 구성 요소라고 하는 상태 또는 상태가 없는 구성 요소를 상태 비저장 구성 요소라고 하는 구성 요소로 구성할 수 있습니다.

## 내용
- 전후크 시대에는 클래스 기반 구문을 사용하여 상태 저장 구성 요소라고 하는 상태 또는 상태가 없는 구성 요소를 상태 비저장 구성 요소라고 하는 구성 요소로 구성할 수 있습니다.
- Core React 팀이 클래스 기반 구성 요소를 사용하지 않도록 했지만, 여전히 클래스 기반 구문을 사용하여 앱을 코딩할 수 있지만, 단점으로 인해 클래스 기반 구문을 사용하지 않고 대신 기능 구성 요소를 수용하는 경향이 있습니다.
- 사실, 이러한 추세는 너무 강해서 사람들이 클래스 대 기능 구분을 사용하지 않고 현대 반응을 논의할 때 구성 요소를 언급하는 것을 자주 듣게 될 것입니다.
- 따라서 어떤 면에서는 Modern React의 경우 구성 요소를 작성하는 유일한 방법이 함수 기반 구문을 사용하는 것임을 암시합니다.
- 이러한 기능적 구성 요소를 코딩할 때 ES5 함수 선언 또는 화살표 함수가 할당된 ES6 const 변수로 React 구성 요소를 코딩하도록 선택할 수 있다는 점에 유의해야 합니다.
- React Basics 과정으로 돌아가서 구성 요소를 이해하고 React에서 구성 요소를 사용하는 방법을 이해하는 것 외에도 데이터, 상태 및 이벤트에 대해서도 배웠습니다.
- 따라서 이 수업을 완료하기 위해 이해하고 작업할 수 있어야 하는 많은 것들이 있지만 목표는 React에서 구성 요소의 기본 사항을 다시 검토하고 Little Lemons Reserve-a-Table Apps 구성 요소를 설정하는 것입니다.

## 예시
- 따라서 이 수업을 완료하기 위해 이해하고 작업할 수 있어야 하는 많은 것들이 있지만 목표는 React에서 구성 요소의 기본 사항을 다시 검토하고 Little Lemons Reserve-a-Table Apps 구성 요소를 설정하는 것입니다.

## 요약
- React Basics 과정으로 돌아가서 구성 요소를 이해하고 React에서 구성 요소를 사용하는 방법을 이해하는 것 외에도 데이터, 상태 및 이벤트에 대해서도 배웠습니다. 따라서 이 수업을 완료하기 위해 이해하고 작업할 수 있어야 하는 많은 것들이 있지만 목표는 React에서 구성 요소의 기본 사항을 다시 검토하고 Little Lemons Reserve-a-Table Apps 구성 요소를 설정하는 것입니다.
