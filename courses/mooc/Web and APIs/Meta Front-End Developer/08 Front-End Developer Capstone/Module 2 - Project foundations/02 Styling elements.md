# Styling elements

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/meta-front-end-developer-capstone/lecture/VIlKH/styling-elements)

## 개요
- Floats는 웹 레이아웃을 구축하기 위한 것이 아니었기 때문에 CSS에서 여전히 적절한 레이아웃 구문이 필요했기 때문에 꽤 오랫동안 인기가 있었습니다.

## 내용
- Floats는 웹 레이아웃을 구축하기 위한 것이 아니었기 때문에 CSS에서 여전히 적절한 레이아웃 구문이 필요했기 때문에 꽤 오랫동안 인기가 있었습니다.
- 2010년대 초에 더 나은 것이 필요하다는 합의와 함께 CSS 유연한 레이아웃 모듈 사양 또는 Flex Box 레이아웃을 도입하려는 몇 가지 시도가 있었습니다.
- 그러나 CSS 사양의 플렉스 박스 레이아웃에 대한 이러한 초기 시도가 브라우저 간에 지속적으로 사양을 변경하고 일관되지 않고 불규칙한 지원으로 인해 완전히 성공적이지 못했다는 점은 주목할 가치가 있습니다.
- CSS 그리드 레이아웃 기술은 CSS 그리드 레이아웃 모듈이 웹 레이아웃을 구축하는 것을 목적으로 하는 CSS 사양의 일부인 2018년경에 실제로 시작되었습니다.
- 다양한 레이아웃 기술을 알고 있어야 하는 또 다른 이유는 레이아웃 선택에 대해 정보에 입각한 결정을 내릴 수 있기 때문입니다.
- 실제로, 이 주제에 대한 지식이 많을수록 올바른 접근 방식을 선택하고 작업 중인 프로젝트의 기존 코드가 최신 표준에 부합하는지 여부를 결정하는 데 더 능숙할 것입니다.
- 그렇긴 하지만, 이 단원의 초점은 현대 CSS 레이아웃 도구 상자에서 가장 포괄적이고 다목적 도구인 CSS 그리드를 사용하여 CSS 레이아웃을 구축하는 데 주로 있습니다.
