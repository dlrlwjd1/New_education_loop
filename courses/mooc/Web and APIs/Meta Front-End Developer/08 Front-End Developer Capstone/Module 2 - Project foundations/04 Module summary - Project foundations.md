# Module summary: Project foundations

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/meta-front-end-developer-capstone/lecture/9yrvr/module-summary-project-foundations)

## 개요
- 이 모듈에서는 의미 구조, 스타일링 및 응답성 및 구성 요소 추가와 관련된 몇 가지 개념을 다시 살펴보았습니다.

## 내용
- 이 모듈에서는 의미 구조, 스타일링 및 응답성 및 구성 요소 추가와 관련된 몇 가지 개념을 다시 살펴보았습니다.
- 궁극적으로 반응형 웹사이트를 설정하고 React 구성 요소를 사용하여 여러 보기를 만들고 반응형 UI를 디자인하고 스타일을 지정할 수 있었습니다.
- 메타 태그와 오픈 그래프 프로토콜 태그가 제대로 설정되어 있지 않으면 공유 링크가 다양한 소셜 미디어 사이트 채팅 창에 사진을 표시하지 않을 수 있습니다.
- 웹 개발과 관련된 다른 기술과 마찬가지로 때때로 까다로운 구문과 함께 제공되지만 CSS 그리드와 같은 것을 더 많이 연습할수록 더 잘 얻을 수 있습니다.
- 이 모듈의 세 번째 단원에서는 Little Lemon Restaurants 웹 앱의 구성 요소를 추가하기 시작했습니다.
- 그렇기 때문에 이 기술에 전적으로 전념하는 수업을 완료하고 React의 구성 요소의 기본 사항을 다시 살펴보고 지식을 실천합니다.
- 다음 모듈에서는 Little Lemon 웹사이트 방문자가 게스트 및 기타 관련 사용자 요구 사항에 따라 테이블을 예약할 수 있도록 특정 상호 작용을 코딩합니다.

## 예시
- 다음 모듈에서는 Little Lemon 웹사이트 방문자가 게스트 및 기타 관련 사용자 요구 사항에 따라 테이블을 예약할 수 있도록 특정 상호 작용을 코딩합니다.

## 요약
- 그렇기 때문에 이 기술에 전적으로 전념하는 수업을 완료하고 React의 구성 요소의 기본 사항을 다시 살펴보고 지식을 실천합니다. 다음 모듈에서는 Little Lemon 웹사이트 방문자가 게스트 및 기타 관련 사용자 요구 사항에 따라 테이블을 예약할 수 있도록 특정 상호 작용을 코딩합니다.
