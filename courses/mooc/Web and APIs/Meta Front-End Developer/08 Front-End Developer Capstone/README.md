# Front-End Developer Capstone

Meta Front-End Developer 전문과정의 여덟 번째 강좌. Little Lemon 예약 웹 애플리케이션을 설계하고 React로 구현·평가한다.

- 강좌 링크: <https://www.mooc.org/learn/meta-front-end-developer-capstone>
- 구성: 4개 모듈, 영상 14개
- 수집 상태: 영상 14개 Transcript 정리 완료
- 제외: 읽기 자료·퀴즈·채점 평가의 정답 및 제출

## 모듈 구성

- Module 1 - Starting the project: 영상 4개
- Module 2 - Project foundations: 영상 4개
- Module 3 - Project functionality: 영상 4개
- Module 4 - Project Assessment: 영상 2개

## 핵심 주제

- 사용자 페르소나와 사용자 여정
- 와이어프레임과 프로토타입
- 시맨틱 HTML과 반응형 UI
- 예약 폼, 상태와 데이터 검증
- 접근성, 단위 테스트와 동료 평가
