# React Basics

Meta Front-End Developer 전문과정의 다섯 번째 강좌. React 컴포넌트, props·state, 이벤트, 라우팅과 자산 사용을 다룬다.

- 강좌 링크: <https://www.mooc.org/learn/react-basics>
- 구성: 4개 모듈, 영상 40개
- 수집 상태: 접근 가능한 영상 39개 Transcript 정리 완료
- 잠금 항목: `Exemplar: Build a calculator app` 1개 — 선행 채점 과제 완료 필요
- 제외: 읽기 자료·퀴즈·채점 평가의 정답 및 제출

## 모듈 구성

- Module 1 - React Components: 영상 15개
- Module 2 - Data and State: 영상 13개
- Module 3 - Navigation, Updating and Assets in React.js: 영상 9개
- Module 4 - Your first React app: 영상 3개 중 2개 수집, 잠금 1개

## 핵심 주제

- JSX와 재사용 가능한 컴포넌트
- props, state와 단방향 데이터 흐름
- 이벤트 처리와 동적 UI
- React Router
- 이미지·오디오 등 정적 자산
