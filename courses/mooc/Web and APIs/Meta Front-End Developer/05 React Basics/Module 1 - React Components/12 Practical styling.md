# Practical styling

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/react-basics/lecture/3b3tR/practical-styling)

## 개요
- 이 비디오에서는 index.CSS 라는 외부 파일에서 CSS 스타일 규칙을 가져와 구성 요소 내부에 내부 스타일로 추가하는 방법을 알아봅니다.

## 내용
- 이 비디오에서는 index.CSS 라는 외부 파일에서 CSS 스타일 규칙을 가져와 구성 요소 내부에 내부 스타일로 추가하는 방법을 알아봅니다.
- 그러면 구성 요소의 return 문 내에서 코드에서 스타일 규칙을 참조할 수 있습니다.
- 구성 요소의 스타일은 외부 스타일 시트인 인덱스 도트 CSS로 지정됩니다.
- 이번에는 사이드바 구성 요소 내부의 스타일을 사용하는 데 초점을 맞출 것입니다.
- 이렇게 하려면 사이트 스타일을 const 변수로 선언한 다음 세미콜론과 코드를 쉼표로 바꿔야 합니다.
- 마지막으로 구성 요소의 사이트 태그와 반환 명령문 안에 style equals side style을 JSX 표현식으로 입력하여 스타일 속성을 추가해야 합니다.
- 이 비디오에서는 index.CSS 라는 외부 파일에서 CSS 스타일 규칙을 가져와 구성 요소 내부에 내부 스타일로 추가하는 방법을 배웠습니다.

## 예시
- 예를 들어 사이트의 CSS 코드를 선택하고 Mac에서 Ctrl X 또는 Command X를 눌러 잘라냅니다.

## 요약
- 마지막으로 구성 요소의 사이트 태그와 반환 명령문 안에 style equals side style을 JSX 표현식으로 입력하여 스타일 속성을 추가해야 합니다. 이 비디오에서는 index.CSS 라는 외부 파일에서 CSS 스타일 규칙을 가져와 구성 요소 내부에 내부 스타일로 추가하는 방법을 배웠습니다.
