# Principles of components: Props

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/react-basics/lecture/TV084/principles-of-components-props)

## 개요
- JavaScript에서는 함수를 호출할 때 값을 인수로 전달할 수 있는 매개 변수로 함수를 선언하여 함수를 보다 유연하게 만들 수 있다는 점을 기억하세요.

## 내용
- JavaScript에서는 함수를 호출할 때 값을 인수로 전달할 수 있는 매개 변수로 함수를 선언하여 함수를 보다 유연하게 만들 수 있다는 점을 기억하세요.
- 이 비디오에서는 props 객체와 개발자가 이 객체를 사용하여 한 구성 요소에서 다른 구성 요소로 데이터를 전달하는 방법에 대해 알아봅니다.
- React에서는 유사한 기법을 사용하여 properties 객체 또는 단순히 props를 사용하여 한 구성 요소에서 다른 구성 요소로 데이터를 전달할 수 있습니다.
- props는 기본적으로 JavaScript 객체이므로 문자열 및 정수와 같은 간단한 유형부터 함수, 배열 및 객체와 같은 보다 복잡한 유형까지 다양한 데이터 유형을 수용할 수 있습니다.
- 두 구성 요소가 서로 통신할 때 props 데이터를 보내는 구성 요소를 상위 구성 요소라고 하고 props 데이터를 받는 구성 요소를 하위 구성 요소라고 합니다.
- 예를 들어 프롬프트를 사용하여 하위 구성 요소의 데이터를 상위 구성 요소로 다시 보낼 수 없는 방법에 대해 방금 배웠습니다.
- 마지막으로 props를 사용하여 데이터를 부모 구성요소로 다시 보낼 수 없고 props를 사용하는 함수가 자체 props를 수정해서는 안 된다는 점에서 props를 사용할 때의 몇 가지 제한 사항을 살펴보았습니다.

## 예시
- 예를 들어 유형, 수량 및 색상에 대한 속성이 포함된 과일이라는 객체를 만든다고 가정해 보겠습니다.

## 요약
- 예를 들어 프롬프트를 사용하여 하위 구성 요소의 데이터를 상위 구성 요소로 다시 보낼 수 없는 방법에 대해 방금 배웠습니다. 마지막으로 props를 사용하여 데이터를 부모 구성요소로 다시 보낼 수 없고 props를 사용하는 함수가 자체 props를 수정해서는 안 된다는 점에서 props를 사용할 때의 몇 가지 제한 사항을 살펴보았습니다.
