# Embedding in attributes

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/react-basics/lecture/TCcTA/embedding-in-attributes)

## 개요
- 속성, 특히 html 이미지 태그의 SRC 속성에 JS 표현식을 삽입하여 이 작업을 수행할 수 있습니다.

## 내용
- 속성, 특히 html 이미지 태그의 SRC 속성에 JS 표현식을 삽입하여 이 작업을 수행할 수 있습니다.
- 이 비디오가 끝날 무렵에는 스타일 추가, 자산 가져오기 등 속성에 JS 표현식을 삽입하는 방법과 구성 요소를 가져와서 앱 내에서 추가 자산을 활용하는 방법을 시연할 수 있습니다.
- 저는 이전에 get up API를 통해 공개적으로 사용할 수 있는 MOOC GitHub 계정에서 아바타 프로필 이미지를 복사한 적이 있습니다.
- SRC 폴더의 루트에 이미지를 붙여넣고 이름을 avatar.png 로 지정했습니다.이미지를 사용하려면 앱 구성 요소로 이미지를 가져와야 합니다.
- 이것은 이미지 요소이고 가져온 아바타 PNG 이미지를 이 이미지 요소 내의 SRC 속성 값으로 전달하고 있습니다.
- 앱 구성 요소 안으로 돌아가서 이제 앱 구성 요소 반환 명령문 안에 로고 요소를 추가하여 로고 구성 요소를 렌더링하겠습니다.
- 더 많은 구성 요소로 이 앱을 계속 빌드하려면 로고 구성 요소를 자체 파일로 추출한 다음 필요에 따라 가져와서 렌더링하는 것이 가장 좋습니다.

## 예시
- 이것은 속성에 JSX 표현식을 삽입하는 방법에 대한 데모입니다.

## 요약
- 앱 구성 요소 안으로 돌아가서 이제 앱 구성 요소 반환 명령문 안에 로고 요소를 추가하여 로고 구성 요소를 렌더링하겠습니다. 더 많은 구성 요소로 이 앱을 계속 빌드하려면 로고 구성 요소를 자체 파일로 추출한 다음 필요에 따라 가져와서 렌더링하는 것이 가장 좋습니다.
