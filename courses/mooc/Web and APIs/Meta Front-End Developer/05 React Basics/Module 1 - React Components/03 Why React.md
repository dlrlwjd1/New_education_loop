# Why React?

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/react-basics/lecture/M2wtj/why-react)

## 개요
- React로 이런 경험을 할 수 있어서 좋았고, 제가 React로 작업하는 것을 정말 좋아한다는 것을 깨닫고 일상 업무에서 이 경험을 할 수 있게 되었습니다.

## 내용
- React로 이런 경험을 할 수 있어서 좋았고, 제가 React로 작업하는 것을 정말 좋아한다는 것을 깨닫고 일상 업무에서 이 경험을 할 수 있게 되었습니다.
- YouTube로 가서 비디오를 보거나 문서를 읽거나 React를 사용하는 다른 오픈 소스 프로젝트를 볼 수 있습니다.활용할 수 있는 리소스가 너무 많습니다.
- Meta 외부의 개발자들도 Meta에서 사용하는 것과 같은 이유로 React를 사용한다고 생각합니다.
- 우리는 facebook.com에서 매일 많은 사용자 지정 구성 요소와 UI가 필요한 다양한 기능을 만들고 있습니다.
- UI가 정말 멋지고 앱이나 웹 사이트에 통합할 수 있는 다른 라이브러리와의 유연성이 필요하다면 React가 최고의 앱이라고 말하고 싶습니다.
- React는 여러 페이지에서 코드를 재사용하려는 복잡한 UI가 있는 경우에도 유용합니다.수많은 페이지에 걸쳐 수많은 기능을 갖춘 복잡한 웹 사이트를 구축하려는 경우 훌륭한 선택이라고 생각합니다.
- 버그와 핵심 UI 구성 요소를 발견하고 수정하면 한 가지 사용 사례에서만 수정하는 것이 아니라 사이트 전체의 사용 사례에 맞게 수정하기 때문입니다.

## 예시
- 버그와 핵심 UI 구성 요소를 발견하고 수정하면 한 가지 사용 사례에서만 수정하는 것이 아니라 사이트 전체의 사용 사례에 맞게 수정하기 때문입니다.

## 요약
- React는 여러 페이지에서 코드를 재사용하려는 복잡한 UI가 있는 경우에도 유용합니다.수많은 페이지에 걸쳐 수많은 기능을 갖춘 복잡한 웹 사이트를 구축하려는 경우 훌륭한 선택이라고 생각합니다. 버그와 핵심 UI 구성 요소를 발견하고 수정하면 한 가지 사용 사례에서만 수정하는 것이 아니라 사이트 전체의 사용 사례에 맞게 수정하기 때문입니다.
