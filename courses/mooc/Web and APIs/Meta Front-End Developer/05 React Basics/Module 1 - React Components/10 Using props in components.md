# Using props in components

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/react-basics/lecture/Bj28Z/using-props-in-components)

## 개요
- 그리고 소품을 통해 한 구성 요소에서 다른 구성 요소로 데이터를 전달할 수 있다는 것도 잘 알고 계실 것입니다.

## 내용
- 그리고 소품을 통해 한 구성 요소에서 다른 구성 요소로 데이터를 전달할 수 있다는 것도 잘 알고 계실 것입니다.
- 또한 함수를 사용하여 구성 요소 내부 및 구성 요소 내에서 props를 전달하는 방법도 살펴봅니다.
- 이 경우 앱 구성 요소를 상위 구성 요소라고 하고 헤더 기본 및 측면 볼 구성 요소를 앱 구성 요소의 하위 구성요소라고 합니다.
- 이제 props 도트 이름과 props 도트 칼라를 사용하여 헤더 구성 요소 내에 있는 두 속성의 값에 액세스할 수 있습니다.
- 앱 구성 요소 렌더링 명령문으로 돌아가서 기본 JXS 요소에 howdy 값을, 사이드바 JXS 요소에 high 값을 사용하여 greet prop을 추가합니다.
- 이제 모든 구성 요소가 해당 props 개체를 사용하여 상위 구성 요소에서 받은 데이터를 사용하고 있습니다.
- 이제 클래스와 함수를 사용하여 구성 요소 내부 및 구성 요소 내에서 props를 전달하는 방법을 효과적으로 시연할 수 있을 것입니다.

## 예시
- 예를 들어, return 문에는 U L 및 L I 태그와 같은 HTLM과 같은 여러 요소가 포함될 수 있습니다.

## 요약
- 이제 모든 구성 요소가 해당 props 개체를 사용하여 상위 구성 요소에서 받은 데이터를 사용하고 있습니다. 이제 클래스와 함수를 사용하여 구성 요소 내부 및 구성 요소 내에서 props를 전달하는 방법을 효과적으로 시연할 수 있을 것입니다.
