# Importing components

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/react-basics/lecture/Ba9nx/importing-components)

## 개요
- 이미 배웠듯이 이러한 구성 요소는 코드의 재사용 가능한 구성 요소를 기반으로 강력한 UI를 구축하는 데 사용할 수 있습니다.

## 내용
- 이미 배웠듯이 이러한 구성 요소는 코드의 재사용 가능한 구성 요소를 기반으로 강력한 UI를 구축하는 데 사용할 수 있습니다.
- 그러나 앱이 여러 다른 구성 요소로 나뉘어지면 모든 것을 앱에 어떻게 찾고 통합하는지 궁금할 것입니다.
- 이 비디오에서는 모듈의 개념과 React 구성 요소를 구성 요소 폴더에 배치하여 관리하는 방법에 대해 알아봅니다.
- 음, React에서는 이 JavaScript 기능을 사용하여 구성 요소를 자체 파일에 배치하여 구성 요소를 분리할 수 있습니다.
- 그런 다음 다른 파일에서 함수와 변수를 사용할 수 있도록 하려면 import 문을 통해 사용할 수 있도록 내보내야 합니다.
- 현재 React를 사용하여 애플리케이션을 구축하는 과정에 있는 개발자이고 앱에 포함해야 하는 몇 가지 구성 요소가 있다고 가정해 보겠습니다.
- 먼저 header라는 구성 요소를 사용하는 헤더 섹션, main이라는 구성 요소를 사용하는 지불 섹션, 마지막으로 사이드바라는 구성 요소를 사용하는 사이드바입니다.
