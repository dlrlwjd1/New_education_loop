# The React project structure

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/react-basics/lecture/v572a/the-react-project-structure)

## 개요
- 이 비디오가 끝날 무렵에는 React 프로젝트의 기본 폴더 구조를 설명하고, 폴더 구조의 이점을 간략하게 설명하고, 컴포넌트와 에셋을 보관할 폴더 구조를 사용자 지정하고, 앱 개발을 위한 폴더 사용 계획의 이점을 설명하는 방법을 배웠을 것입니다.

## 내용
- 이 비디오가 끝날 무렵에는 React 프로젝트의 기본 폴더 구조를 설명하고, 폴더 구조의 이점을 간략하게 설명하고, 컴포넌트와 에셋을 보관할 폴더 구조를 사용자 지정하고, 앱 개발을 위한 폴더 사용 계획의 이점을 설명하는 방법을 배웠을 것입니다.
- npm init React app 명령을 사용하여 React 앱을 빌드하면 프로젝트는 특정 파일 및 폴더 구조로 구성됩니다.
- 이 폴더에는 React 앱이 제대로 작동하는지 확인하는 데 필요한 모든 필수 구성 요소 파일이 들어 있습니다.
- 루트 파일은 프로젝트 폴더 자체의 루트에 있는 추가 파일이며 gitignore 파일, 두 개의 json 파일 및 README 파일을 포함합니다.
- 또는 프로젝트를 실행하는 데 필요한 모든 파일이 들어 있는 node modules 폴더를 삭제하면 package-loc.json 파일에는 npm이 해당 파일을 안정적으로 다시 빌드할 수 있는 모든 정보가 들어 있습니다.
- 이제 React 프로젝트의 기본 폴더 구조를 설명하고 폴더 구조의 이점을 간략하게 설명할 수 있을 것입니다.
- 또한 구성 요소 및 자산을 보관하도록 폴더 구조를 사용자 지정하는 방법을 알고 앱 개발을 위한 폴더 사용 계획의 이점을 설명할 수 있어야 합니다.잘했어.

## 예시
- 또한 구성 요소 및 자산을 보관하도록 폴더 구조를 사용자 지정하는 방법을 알고 앱 개발을 위한 폴더 사용 계획의 이점을 설명할 수 있어야 합니다.잘했어.

## 요약
- 이제 React 프로젝트의 기본 폴더 구조를 설명하고 폴더 구조의 이점을 간략하게 설명할 수 있을 것입니다. 또한 구성 요소 및 자산을 보관하도록 폴더 구조를 사용자 지정하는 방법을 알고 앱 개발을 위한 폴더 사용 계획의 이점을 설명할 수 있어야 합니다.잘했어.
