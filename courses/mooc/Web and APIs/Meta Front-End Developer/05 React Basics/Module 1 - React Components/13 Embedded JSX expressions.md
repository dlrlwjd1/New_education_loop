# Embedded JSX expressions

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/react-basics/lecture/vHVug/embedded-jsx-expressions)

## 개요
- 이를 통해 개발자는 HTML을 컴포넌트 코드의 일부로 작성할 수 있으며 유연성이 뛰어나 React에서 자주 사용됩니다.

## 내용
- 이를 통해 개발자는 HTML을 컴포넌트 코드의 일부로 작성할 수 있으며 유연성이 뛰어나 React에서 자주 사용됩니다.
- 이 비디오에서는 JSX의 사용 방법과 주요 기능인 임베디드 표현식을 사용하는 방법을 알아봅니다.
- 참고로 이 JSX 코드가 실행되면 결과 변수에는 웹 페이지에 삽입할 수 있는 반응 요소가 포함됩니다.
- 임베디드 표현식을 통해 개발자는 JavaScript 변수 값을 결과 React 요소의 HTML에 삽입할 수 있습니다.
- 이를 위해 먼저 format name이라는 함수를 생성하면 이름과 성 사이에 공백이 있는 이름이 반환됩니다.
- 이것은 JSX가 JavaScript 변수 내용을 포함하는 HTML 요소를 출력하는 효율적인 방법이라는 것을 보여주는 한 가지 예일 뿐이며, 진행하면서 더 많은 것을 알게 될 것입니다.
- 이 비디오에서는 임베디드 표현식을 사용하여 React 요소 내의 HTML에 JavaScript 변수 값을 삽입하는 예제를 포함하여 여러 JSX 예제를 살펴보았습니다.

## 예시
- 이 비디오에서는 임베디드 표현식을 사용하여 React 요소 내의 HTML에 JavaScript 변수 값을 삽입하는 예제를 포함하여 여러 JSX 예제를 살펴보았습니다.

## 요약
- 이것은 JSX가 JavaScript 변수 내용을 포함하는 HTML 요소를 출력하는 효율적인 방법이라는 것을 보여주는 한 가지 예일 뿐이며, 진행하면서 더 많은 것을 알게 될 것입니다. 이 비디오에서는 임베디드 표현식을 사용하여 React 요소 내의 HTML에 JavaScript 변수 값을 삽입하는 예제를 포함하여 여러 JSX 예제를 살펴보았습니다.
