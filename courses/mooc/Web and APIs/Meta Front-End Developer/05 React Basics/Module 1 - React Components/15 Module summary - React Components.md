# Module summary: React Components

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/react-basics/lecture/Wbbac/module-summary-react-components)

## 개요
- 그런 다음 VS Code에서 프로젝트를 설정하는 방법과 JavaScript 모듈을 사용하는 방법을 배웁니다.

## 내용
- 그런 다음 VS Code에서 프로젝트를 설정하는 방법과 JavaScript 모듈을 사용하는 방법을 배웁니다.
- 이 단원에서는 리액터 라이브러리와 같은 코드의 재사용 가능한 구성 요소를 기반으로 소프트웨어를 구축하기 위한 설계 철학인 구성 요소 기반 아키텍처를 소개했습니다.
- 가상 DOM을 사용하는 구성 요소 유형과 구성 요소 스타일 레이아웃에 대해 배웠습니다.
- 그리고 젊은 등급의 실습에서는 앱 구성 요소 내에 새 구성 요소를 만들고 화면에 렌더링하는 방법을 배웠습니다.구성 요소를 자체 파일에 저장하고 부모 구성 요소로 가져와 화면에서 렌더링할 수 있도록 하는 방법도 있습니다.
- 속성을 사용하여 한 구성 요소에서 다른 구성 요소로 데이터를 전달하는 방법을 배웠고 채점되지 않은 실험실에서 해당 기능을 테스트했습니다.
- 업그레이드된 다른 실습에서는 다양한 소품을 사용하여 한 구성 요소를 여러 번 렌더링하는 방법을 배웠습니다.
- 또한 JSX의 임베디드 표현식을 사용하는 방법과 기능적이고 보기 좋은 방식으로 JSX 요소의 스타일을 지정하는 방법에 대해서도 자세히 배웠습니다.

## 예시
- 그런 다음 실습의 기초를 다지기 위해 html, CSS, JavaScript의 기초를 간단히 요약했습니다.

## 요약
- 업그레이드된 다른 실습에서는 다양한 소품을 사용하여 한 구성 요소를 여러 번 렌더링하는 방법을 배웠습니다. 또한 JSX의 임베디드 표현식을 사용하는 방법과 기능적이고 보기 좋은 방식으로 JSX 요소의 스타일을 지정하는 방법에 대해서도 자세히 배웠습니다.
