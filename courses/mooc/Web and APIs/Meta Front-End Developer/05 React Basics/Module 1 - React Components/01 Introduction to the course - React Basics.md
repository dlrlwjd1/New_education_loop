# Introduction to the course: React Basics

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/react-basics/lecture/AStT3/introduction-to-the-course-react-basics)

## 개요
- 이 단원에서는 React.js 라이브러리의 기본 구조와 사용에 익숙해지는 방법을 배우게 됩니다.

## 내용
- 이 단원에서는 React.js 라이브러리의 기본 구조와 사용에 익숙해지는 방법을 배우게 됩니다.
- 상태 및 단계 관리의 개념과 실제 사용을 살펴보고 React 앱에서 탐색을 설정하고 에셋을 사용하는 방법을 알아보세요.
- 먼저 React를 사용하여 웹 사이트 프런트 엔드에 현대적인 사용자 인터페이스 또는 UI를 구축하는 방법을 배우게 됩니다.
- 현재로서는 모든 웹 사이트의 UI가 구성 요소 및 구성 가능성을 기반으로 구축되었다는 사실만 알면 충분합니다.
- 단순한 구성 요소가 더 복잡한 구성 요소로 결합되어 결국 병합되어 웹 사이트를 형성합니다.
- 이 강좌를 진행하면서 일반적인 스타일의 재사용을 포함하여 React 앱의 스타일을 지정하는 방법에 대해서도 배우게 됩니다.
- 클릭, 사용자가 제출한 데이터 등의 이벤트에 반응하도록 앱을 설정하고, 탐색 경로를 만들고, 자산을 사용하면 새로운 지식을 적용할 프로젝트 포트폴리오로 과정을 마칠 수 있습니다.

## 예시
- 클릭, 사용자가 제출한 데이터 등의 이벤트에 반응하도록 앱을 설정하고, 탐색 경로를 만들고, 자산을 사용하면 새로운 지식을 적용할 프로젝트 포트폴리오로 과정을 마칠 수 있습니다.
