# Introduction to functional components

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/react-basics/lecture/gQa3l/introduction-to-functional-components)

## 개요
- 이 비디오에서는 기능 구성 요소, 구성 요소 유형, JSX 및 트랜스파일링에 대해 학습하여 React 아키텍처의 구조에 대한 탐색을 계속합니다.

## 내용
- 이 비디오에서는 기능 구성 요소, 구성 요소 유형, JSX 및 트랜스파일링에 대해 학습하여 React 아키텍처의 구조에 대한 탐색을 계속합니다.
- 기본 React 응용 프로그램에서는 하나의 구성 요소만 렌더링되며 소스 폴더 안에 있는 index.js 파일 안에 있는 앱 구성 요소입니다.
- 루트 구성 요소는 이전에 학습한 전자 상거래 예제와 같이 응용 프로그램의 다양한 UI 부분을 나타내기 위해 개발자가 만든 다른 구성 요소를 포함할 수 있습니다.
- 앱 구성 요소를 분석하면 내부에 일부 HTML 코드가 있는 JavaScript 함수와 매우 유사하게 보입니다.
- 자, 이제 기능적 구성 요소의 개념에 익숙해졌으므로 웹 개발자가 React에서 구성 요소를 만드는 방법을 살펴보겠습니다.
- 웹 페이지에 일부 텍스트를 표시하기 위해 제목 하나의 HTML 요소 내에 일부 JSX 코드가 포함되는 React 구성 요소를 만드는 것과 관련된 단계를 살펴보겠습니다.
- 기능 구성 요소 내에서 동적 콘텐츠를 생성하는 데 사용할 수 있는 HTML과 JavaScript의 조합과 같은 역할을 하는 JSX에 대해서도 배웠습니다.

## 예시
- 기능 구성 요소 내에서 동적 콘텐츠를 생성하는 데 사용할 수 있는 HTML과 JavaScript의 조합과 같은 역할을 하는 JSX에 대해서도 배웠습니다.

## 요약
- 웹 페이지에 일부 텍스트를 표시하기 위해 제목 하나의 HTML 요소 내에 일부 JSX 코드가 포함되는 React 구성 요소를 만드는 것과 관련된 단계를 살펴보겠습니다. 기능 구성 요소 내에서 동적 콘텐츠를 생성하는 데 사용할 수 있는 HTML과 JavaScript의 조합과 같은 역할을 하는 JSX에 대해서도 배웠습니다.
