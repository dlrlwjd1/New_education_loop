# Introducing JSX

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/react-basics/lecture/AoQUi/introducing-jsx)

## 개요
- 참고로 일반 JavaScript 함수는 React가 nav JSX 요소를 사용하여 참조되는 모든 위치에서 컴포넌트를 렌더링하는 방법을 정의하는 데 사용된다는 점입니다.

## 내용
- 참고로 일반 JavaScript 함수는 React가 nav JSX 요소를 사용하여 참조되는 모든 위치에서 컴포넌트를 렌더링하는 방법을 정의하는 데 사용된다는 점입니다.
- 즉, 중괄호를 원하는 모든 종류의 JavaScript 코드를 작성할 수 있는 특수 영역이라고 생각할 수 있습니다.
- return 문은 렌더링된 앱에서 원하는 대로 일반 HTML 코드를 작성할 수 있는 표현식 구문 영역이라고 생각할 수 있습니다.
- 이를 통해 개발자는 일반 HTML 태그와 중괄호 안의 JSX 표현식으로 표시되는 동적 값을 번갈아 사용할 수 있습니다.
- return 문 안의 코드는 일반 HTML이라고 생각할 수 있지만, JavaScript 파일에 있다는 점을 기억해야 합니다.
- ClassName을 사용하여 CSS 클래스를 원하는 수만큼 나열하여 구성 요소 내의 특정 JSX 요소의 스타일을 지정할 수 있습니다.
- 이제 JSX를 사용하여 구성 요소 내에서 JavaScript, HTML 및 CSS를 혼합하는 방법에 대한 이해를 넓혔습니다.수고하셨습니다.

## 예시
- 예를 들어 탐색 구성 요소를 만들어 웹 사이트에 탐색 기능을 추가할 수 있습니다.

## 요약
- ClassName을 사용하여 CSS 클래스를 원하는 수만큼 나열하여 구성 요소 내의 특정 JSX 요소의 스타일을 지정할 수 있습니다. 이제 JSX를 사용하여 구성 요소 내에서 JavaScript, HTML 및 CSS를 혼합하는 방법에 대한 이해를 넓혔습니다.수고하셨습니다.
