# How is React used in the real world?

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/react-basics/lecture/zvXcc/how-is-react-used-in-the-real-world)

## 개요
- 우리 팀은 React를 사용하며 React 팀이 만들고 있는 새롭고 실험적인 기능을 많이 사용합니다.

## 내용
- 우리 팀은 React를 사용하며 React 팀이 만들고 있는 새롭고 실험적인 기능을 많이 사용합니다.
- 웹사이트를 다시 작성했을 때, 우리는 실제로 출시되지 않은 많은 기능을 사용하고 있었고 React 팀이 만들고 있는 많은 새로운 것들을 실험하고 있었습니다.
- 그래서 Meta에서 Facebook.com을 위해 글을 쓰는 모든 엔지니어들은 거의 React를 사용하고 있습니다.
- 이야기를 나눈 모든 팀이 Facebook.com의 새 버전을 출시할 수 있다고 생각한 것은 아니었기 때문에 속도가 더 빠르다는 것을 증명해야 했습니다.
- 분명히 더 현대적으로 보였지만, 제품 팀이 웹에서 할 수 있는 최고의 제품 버전을 제공하는 데 정말 도움이 될 것이라는 것을 증명해야 했습니다.
- 궁금한 점이 있거나 특정 기능이나 최적화 또는 개선에 대한 아이디어가 있다면 React 라이브러리 자체에 실제로 기여할 수 있는 좋은 기회가 있습니다.
- 실제로 매년 React 컨퍼런스에서 React의 새로운 기능에 대해 이야기하고 많은 React 개발자들과 교류할 수 있습니다.

## 예시
- 실제로 매년 React 컨퍼런스에서 React의 새로운 기능에 대해 이야기하고 많은 React 개발자들과 교류할 수 있습니다.

## 요약
- 궁금한 점이 있거나 특정 기능이나 최적화 또는 개선에 대한 아이디어가 있다면 React 라이브러리 자체에 실제로 기여할 수 있는 좋은 기회가 있습니다. 실제로 매년 React 컨퍼런스에서 React의 새로운 기능에 대해 이야기하고 많은 React 개발자들과 교류할 수 있습니다.
