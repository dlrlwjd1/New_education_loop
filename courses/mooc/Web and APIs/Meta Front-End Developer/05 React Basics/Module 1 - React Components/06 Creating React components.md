# Creating React components

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/react-basics/lecture/iIQHY/creating-react-components)

## 개요
- 내보내기 명령문의 개념과 구성 요소를 사용하여 재사용 가능한 코드 블록을 만드는 방법을 소개합니다.

## 내용
- 내보내기 명령문의 개념과 구성 요소를 사용하여 재사용 가능한 코드 블록을 만드는 방법을 소개합니다.
- 다시 말해, 저는 Create React 앱을 사용하여 이 폴더 안에 새 앱을 빌드하고 있습니다.
- 이제 VS Code의 왼쪽 창에 노드 모듈, 공용 SRC 및 package.json과 같은 파일과 폴더가 모두 있습니다.이에 대해서는 나중에 자세히 알아보겠습니다.
- 이를 위해 header라는 또 다른 함수를 만들고 함수 본문에 H1 JSX 요소 내부의 인사말 텍스트를 반환하겠습니다.
- 앱 함수 본문에서 return 문을 만들고 왼쪽 및 오른쪽 꺾쇠 괄호 안에 header의 함수 이름을 입력합니다.
- 헤더 구성 요소를 분리하고 재사용할 수 있게 하려면 헤더 구성 요소를 자체 파일에 배치해야 합니다.
- 이 비디오에서는 React에서 함수형 컴포넌트를 만들고 이를 app.js 라는 루트 컴포넌트로 렌더링하는 방법을 알아봅니다.

## 예시
- 이 비디오에서는 React에서 함수형 컴포넌트를 만들고 이를 app.js 라는 루트 컴포넌트로 렌더링하는 방법을 알아봅니다.
