# Basic types of navigation

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/react-basics/lecture/vN7FD/basic-types-of-navigation)

## 개요
- 이 비디오에서는 웹사이트의 기본 탐색 유형과 React에서 탐색 프로세스가 작동하는 방식에 대해 알아봅니다.

## 내용
- 이 비디오에서는 웹사이트의 기본 탐색 유형과 React에서 탐색 프로세스가 작동하는 방식에 대해 알아봅니다.
- 웹사이트 탐색은 단일 구성 요소에서 해당 웹사이트의 다양한 페이지 또는 링크를 탐색할 수 있는 웹사이트의 일부입니다.
- 가장 일반적인 탐색 구성 요소는 수평 탐색 모음, 수직 탐색 메뉴, 버튼 뒤에 숨어 있는 메뉴 및 바닥글 탐색 메뉴입니다.
- 이 메뉴는 일반적으로 버튼 뒤에 숨어 있으며 일반적으로 전자 상거래 사이트 및 많은 링크가 필요한 기타 사이트에서 하위 또는 대형 메뉴로 사용됩니다.
- 예를 들어 드롭다운 메뉴 항목이 있는 수평 탐색 모음 또는 탐색 모음이 있을 수 있습니다.
- 각 목록 항목에는 HTML 파일에 대한 하이퍼링크가 포함되어 있으며 목록을 수평으로 표시하는 디스플레이 인라인 속성과 같은 메뉴 스타일을 지정하는 일부 CSS가 포함되어 있습니다.
- 이 비디오에서는 웹사이트의 기본 탐색 유형과 React에서 탐색 프로세스가 작동하는 방식에 대해 배웠습니다.

## 예시
- 다양한 디자인과 실험이 있었지만 궁극적으로 웹 개발 커뮤니티는 몇 가지 모범 사례를 정착시켰습니다.

## 요약
- 각 목록 항목에는 HTML 파일에 대한 하이퍼링크가 포함되어 있으며 목록을 수평으로 표시하는 디스플레이 인라인 속성과 같은 메뉴 스타일을 지정하는 일부 CSS가 포함되어 있습니다. 이 비디오에서는 웹사이트의 기본 탐색 유형과 React에서 탐색 프로세스가 작동하는 방식에 대해 배웠습니다.
