# Single view conditional updates

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/react-basics/lecture/AKEcz/single-view-conditional-updates)

## 개요
- 이 비디오를 마치면 조건부 렌더링 및 반응에 대한 다양한 접근 방식을 설명할 수 있을 것입니다.

## 내용
- 이 비디오를 마치면 조건부 렌더링 및 반응에 대한 다양한 접근 방식을 설명할 수 있을 것입니다.
- 또한 if-else 문과 삼항 연산자를 사용하여 구성 요소를 조건부로 렌더링할 수 있습니다.
- 내 앱의 목표는 로컬 컴퓨터의 시간을 사용하고 반환 값을 기반으로 동일한 반환 명령문 내에 다양한 메시지를 출력하는 것입니다.
- 시간 변수를 선언하고 날짜 생성자에 대한 호출을 할당하여 앱 구성 요소 코드를 시작합니다.
- 다음으로, 현재 시간이 6보다 크거나 같고 12보다 작거나 같은지 여부에 따라 부울 값을 저장하는 아침 변수를 선언합니다.
- 이것이 반환 문에서 다양한 종류의 문자열을 조건부로 렌더링하는 상당히 동적인 구성 요소를 만드는 데 필요한 전부입니다.
- 이 비디오에서는 if-else 문을 사용하여 조건부 렌더링 및 반응에 대한 다양한 접근 방식에 대해 배웠습니다.

## 예시
- 이 맞춤형 스타터 앱의 코드를 살펴보면서 몇 가지 조건부 렌더링과 실습을 보여드리겠습니다.

## 요약
- 이것이 반환 문에서 다양한 종류의 문자열을 조건부로 렌더링하는 상당히 동적인 구성 요소를 만드는 데 필요한 전부입니다. 이 비디오에서는 if-else 문을 사용하여 조건부 렌더링 및 반응에 대한 다양한 접근 방식에 대해 배웠습니다.
