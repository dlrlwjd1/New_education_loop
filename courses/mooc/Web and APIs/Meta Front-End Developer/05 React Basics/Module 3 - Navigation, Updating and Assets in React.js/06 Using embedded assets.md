# Using embedded assets

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/react-basics/lecture/WBFFo/using-embedded-assets)

## 개요
- 특히 import 문을 사용하거나 require 함수를 사용하여 파일 경로를 설정하거나 이미지 URL을 제공하여 이미지를 표시하고 앱을 반응시키는 세 가지 방법을 배우게 됩니다.

## 내용
- 특히 import 문을 사용하거나 require 함수를 사용하여 파일 경로를 설정하거나 이미지 URL을 제공하여 이미지를 표시하고 앱을 반응시키는 세 가지 방법을 배우게 됩니다.
- 참고로 저는 Central Park라는 이름의 이미지 폴더에 Jpeg 이미지를 하나 추가했습니다.
- Central Park 이미지 파일을 가져오려면 import rooftops를 입력한 다음 큰 따옴표로 묶은 파일의 상대 경로를 제공하기 위해 도트 슬래시를 입력합니다.
- 제 코드에서는 height 속성을 사용하여 이미지 높이를 정확히 200픽셀로 설정하여 이미지 크기를 제한합니다.
- 다시 한 번 이미지 코드를 완성하기 위해 L to 속성에 이미지 설명을 추가하고 코드를 저장했는데 이제 두 번째 이미지가 나타납니다.
- 이제 인터넷에서 호스팅되는 이미지 파일을 로드하여 이미지 자산을 임포트하는 세 번째 방법을 보여 드리겠습니다.
- 이 작업을 수행하려면 등호 연산자를 사용하는 변수 이름 임의 이미지 URL 대신 const를 입력하고 그 뒤에 임의 이미지의 URL을 입력하여 변수를 만듭니다.

## 예시
- 마지막으로 , 모범 사례를 위해 이미지에 대한 기본 설명과 함께 외부 속성을 추가합니다.

## 요약
- 이제 인터넷에서 호스팅되는 이미지 파일을 로드하여 이미지 자산을 임포트하는 세 번째 방법을 보여 드리겠습니다. 이 작업을 수행하려면 등호 연산자를 사용하는 변수 이름 임의 이미지 URL 대신 const를 입력하고 그 뒤에 임의 이미지의 URL을 입력하여 변수를 만듭니다.
