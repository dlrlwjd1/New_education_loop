# Create an audio / video component

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/react-basics/lecture/0JGLo/create-an-audio-video-component)

## 개요
- 이 비디오를 마치면 리액트 플레이어 패키지를 설치하고 이를 사용하여 리액트 앱에서 미디어 플레이어를 렌더링하는 방법을 알게 될 것입니다.

## 내용
- 이 비디오를 마치면 리액트 플레이어 패키지를 설치하고 이를 사용하여 리액트 앱에서 미디어 플레이어를 렌더링하는 방법을 알게 될 것입니다.
- 또한 자동 재생 및 시작 볼륨과 같은 몇 가지 일반적인 설정과 리액트 플레이어를 적용하는 방법도 알게 될 것입니다.
- 이 프로세스의 첫 번째 단계는 리액트 플레이어 모듈을 설치하는 것이고, 두 번째 단계는 제 앱 컴포넌트로 임포트하는 것입니다.
- 이를 위해 리액트 플레이어 태그에 equals를 재생하는 속성을 추가한 다음 중괄호와 볼륨 이퀄에 false를 추가한 다음 중괄호에 0.5를 추가합니다.
- 마지막으로 대문자 C와 대문자 P 슬래시 리액트 대시 플레이어로 닷컴 슬래시 쿡 피트와 함께 프로젝트가 행복해지는 것을 볼 수 있습니다.
- 여러 비디오 소스 중에서 선택하고 재생 속도, 조명 모드, 루프 등과 같은 비디오 설정을 변경할 수 있습니다.
- 리액트 플레이어 패키지를 설치하고 사용하는 방법과 리액트 플레이어의 공통 설정을 변경하는 방법을 배웁니다.

## 예시
- 이 페이지에는 오른쪽에 정보 섹션이 있으며 링크 페이지에서 라이브 데모 링크를 찾을 수 있습니다.

## 요약
- 여러 비디오 소스 중에서 선택하고 재생 속도, 조명 모드, 루프 등과 같은 비디오 설정을 변경할 수 있습니다. 리액트 플레이어 패키지를 설치하고 사용하는 방법과 리액트 플레이어의 공통 설정을 변경하는 방법을 배웁니다.
