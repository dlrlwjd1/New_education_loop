# Audio and video

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/react-basics/lecture/tSLxo/audio-and-video)

## 개요
- 이 비디오를 마치면 React 개발자가 앱 내에서 오디오 및 비디오 자산을 사용하는 방법을 배우게 될 것입니다.

## 내용
- 이 비디오를 마치면 React 개발자가 앱 내에서 오디오 및 비디오 자산을 사용하는 방법을 배우게 될 것입니다.
- 쉽게 사용할 수 있는 HTML5 비디오 태그를 사용하여 로컬 비디오 자산을 React 앱에 로드할 수 있습니다.
- 그러나 이러한 접근 방식은 여러 소셜 미디어 및 소셜 비디오 공유 플랫폼 중 하나와 같은 일부 주요 비디오 콘텐츠 제공업체에서는 쉽게 작동하지 않을 수 있습니다.
- 특정 소셜 미디어 플랫폼에서 비디오 및 오디오 자산을 웹 사이트에 임베드하도록 권장하는 방법에 대한 구체적인 지침에 따라 달라질 수 있습니다.
- 첫 번째 방법은 비디오 요소를 사용하여 로컬 비디오를 제공하는 것이고, 두 번째 방법은 임베디드 타사 비디오를 사용하는 것입니다.
- 따라서 React에서 비디오 요구 사항에 맞는 맞춤형 오픈 소스 솔루션을 원한다면 이 패키지 또는 유사한 패키지를 선택할 수 있습니다.수고하셨습니다.
- 이제 React 앱에서 오디오 및 비디오 에셋을 사용하는 방법과 npmjs.org와 github.com을 사용하여 패키지를 찾는 방법에 대한 일반적인 아이디어를 얻었습니다.

## 예시
- 하지만 특정 구현은 예를 들어 별도의 React 컴포넌트로 추가하고 싶기 때문에 약간 다를 수 있습니다.

## 요약
- 따라서 React에서 비디오 요구 사항에 맞는 맞춤형 오픈 소스 솔루션을 원한다면 이 패키지 또는 유사한 패키지를 선택할 수 있습니다.수고하셨습니다. 이제 React 앱에서 오디오 및 비디오 에셋을 사용하는 방법과 npmjs.org와 github.com을 사용하여 패키지를 찾는 방법에 대한 일반적인 아이디어를 얻었습니다.
