# The navbar

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/react-basics/lecture/epk9z/the-navbar)

## 개요
- 또한 이 라이브러리를 사용하여 웹 페이지의 기본 탐색을 만드는 연습도 해볼 수 있습니다.

## 내용
- 또한 이 라이브러리를 사용하여 웹 페이지의 기본 탐색을 만드는 연습도 해볼 수 있습니다.
- 홈페이지와 Aboutme는 모두 앱 구성 요소로 가져오고 앵커 태그를 사용하여 참조됩니다.
- 하지만 React Router라는 또 다른 라이브러리를 사용하여 이 작업을 가능하게 할 수 있습니다.
- 일단 가져온 후에는 브라우저 라우터 태그 사이에 앱 jsx 요소를 배치하여 브라우저 라우터 내부에 래핑해야 합니다.
- 브라우저로 가서 경로 중 하나에 정확한 링크 ( 예: /Aboutme) 를 입력하면 탐색 아래에 Aboutme 구성 요소만 표시됩니다.
- 그러나 URL에서 Aboutme를 제거하면, 즉 슬래시로 표시된 루트 경로를 열면 탐색 모음 아래에 홈페이지 구성 요소의 텍스트가 표시됩니다.
- 앱 구성 요소에서 홈페이지의 앵커 태그는 equals에 대한 링크가 되고 큰 따옴표 사이의 슬래시가 됩니다.그 다음에는 클래스 이름이 같고 그 다음에는 nav-item (nav-item) 이 큰따옴표로 묶입니다.

## 예시
- 앱 구성 요소에서 홈페이지의 앵커 태그는 equals에 대한 링크가 되고 큰 따옴표 사이의 슬래시가 됩니다.그 다음에는 클래스 이름이 같고 그 다음에는 nav-item (nav-item) 이 큰따옴표로 묶입니다.
