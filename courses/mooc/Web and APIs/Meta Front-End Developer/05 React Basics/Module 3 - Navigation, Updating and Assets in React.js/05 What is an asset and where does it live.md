# What is an asset and where does it live?

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/react-basics/lecture/SEzb6/what-is-an-asset-and-where-does-it-live)

## 개요
- 또한 React 앱에서 사용할 에셋 파일을 임포트하는 몇 가지 일반적인 방법도 배우게 됩니다.

## 내용
- 또한 React 앱에서 사용할 에셋 파일을 임포트하는 몇 가지 일반적인 방법도 배우게 됩니다.
- React에서 에셋은 이미지, 스타일 시트, 글꼴, 미디어 파일 또는 기본적으로 런타임에 앱에 필요한 모든 파일일 수 있습니다.
- 하지만 이러한 기능을 사용할 수 없는 상태에서 앱을 실행하면 기본 글꼴을 사용할 때 자리 표시자가 표시되는 등 예상치 못한 동작이 발생할 수 있습니다.
- 이를 수행하는 일반적인 방법은 소스 폴더 내에 자산 폴더를 추가하고 모든 앱 자산을 거기에 보관하는 것입니다.
- 애셋 스토리지의 일반적인 규칙은 애셋 스토리지 없이도 앱을 컴파일할 수 있는 경우 공용 폴더에 보관할 수 있다는 것입니다.
- 예를 들어 파비콘은 어떤 구성 요소도 종속되지 않기 때문에 공용 폴더에 있습니다.
- 하지만 앱 구성 요소 중 하나로 이미지를 가져와야 하는 경우 자산 폴더에 저장하는 것이 가장 좋습니다.

## 예시
- 예를 들어 특정 이미지를 표시하거나 특정 글꼴을 사용하도록 앱을 코딩할 수 있습니다.

## 요약
- 예를 들어 파비콘은 어떤 구성 요소도 종속되지 않기 때문에 공용 폴더에 있습니다. 하지만 앱 구성 요소 중 하나로 이미지를 가져와야 하는 경우 자산 폴더에 저장하는 것이 가장 좋습니다.
