# Module summary: navigation, updating and assets in React.js

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/react-basics/lecture/PpSRQ/module-summary-navigation-updating-and-assets-in-react-js)

## 개요
- 가로 탐색 막대 또는 탐색 모음과 같은 가장 일반적인 탐색 구성 요소에 대해 배웠습니다.

## 내용
- 가로 탐색 막대 또는 탐색 모음과 같은 가장 일반적인 탐색 구성 요소에 대해 배웠습니다.
- 물론 대부분의 웹 사이트에는 가로 탐색 표시줄과 드롭다운 메뉴 항목을 결합하는 것과 같이 단일 구성 요소에 여러 탐색 접근 방식이 포함된 더 복잡한 탐색 UI가 있습니다.
- 단일 페이지 애플리케이션 또는 SPA라고 하는 React 기반 웹 페이지를 사용하면 전체 앱이 단일 div 내에 로드되므로 HTML 파일의 하이퍼링크를 사용할 때처럼 실제로 다른 페이지를 방문할 필요가 없습니다.
- 여러 페이지로 구성된 웹사이트의 솔루션을 구현하려면 React 프로젝트에 React Router 라이브러리를 추가해야 한다는 것을 배우고, 이를 사용하여 웹 페이지의 기본 탐색 경로를 만들고 구현하는 연습을 합니다.
- 앱에 비디오를 추가하는 세 가지 방법, 즉 비디오 요소를 사용하여 로컬 비디오를 제공하고, 내장된 타사 비디오를 사용하는 방법을 배웠습니다.
- 이러한 패키지 사용에 익숙해지도록 돕기 위해 React 플레이어 패키지를 설치하고 이를 사용하여 React 앱에서 미디어 플레이어를 렌더링하는 방법을 배웠습니다.
- 이제 모듈을 완료했으니 단일 및 다중 페이지 탐색을 중심으로 React에서의 탐색 디자인을 설명하고, navbar 형태의 루트를 만들어 구현하고, 여러 컴포넌트의 조건부 구현과 렌더링을 시연하고, React 프로젝트의 폴더 구조를 임베디드 또는 레퍼런스 에셋으로 설명하고, 참조 경로를 사용하여 이미지 자산을 조작하는 방법을 시연하고, React에서 오디오 및 비디오와 같은 미디어 자산을 사용할 수 있을 것입니다.

## 예시
- 이 단원의 채점되지 않은 실습에서는 수업 항목 제목의 코드를 탐색 모음에 사용했으며 기존 코드에 다른 링크를 추가해야 했습니다.

## 요약
- 이러한 패키지 사용에 익숙해지도록 돕기 위해 React 플레이어 패키지를 설치하고 이를 사용하여 React 앱에서 미디어 플레이어를 렌더링하는 방법을 배웠습니다. 이제 모듈을 완료했으니 단일 및 다중 페이지 탐색을 중심으로 React에서의 탐색 디자인을 설명하고, navbar 형태의 루트를 만들어 구현하고, 여러 컴포넌트의 조건부 구현과 렌더링을 시연하고, React 프로젝트의 폴더 구조를 임베디드 또는 레퍼런스 에셋으로 설명하고, 참조 경로를 사용하여 이미지 자산을 조작하는 방법을 시연하고, React에서 오디오 및 비디오와 같은 미디어 자산을 사용할 수 있을 것입니다.
