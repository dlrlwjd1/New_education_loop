# Conditional rendering

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/react-basics/lecture/MiC3F/conditional-rendering)

## 개요
- 예를 들어, 고객이 홈페이지 텍스트에서 내 정보 텍스트로 웹 사이트 변경에 반응할 때 새 페이지로 이동하는 것이 아니라 한 구성 요소가 다른 구성 요소 대신 렌더링된다는 것을 알게 됩니다.

## 내용
- 예를 들어, 고객이 홈페이지 텍스트에서 내 정보 텍스트로 웹 사이트 변경에 반응할 때 새 페이지로 이동하는 것이 아니라 한 구성 요소가 다른 구성 요소 대신 렌더링된다는 것을 알게 됩니다.
- 유용하긴 하지만, 무엇을 렌더링하고 무엇을 렌더링하지 않을 것인지에 대한 매우 구체적인 지침을 react에 제공해야 합니다.또한 클릭과 같은 이벤트에 반응하는 구성 요소가 있으면 복잡성이 가중될 수 있습니다.
- 이 비디오를 마치면 조건부 렌더링에 대한 높은 수준의 이해와 삼항 연산자를 사용하여 조건부 렌더링을 설정하는 방법을 알게 될 것입니다.
- 즉, 기본 앱 구성 요소에 렌더링 로직을 작성할 때 다른 구성 요소의 상태를 참조해야 합니다.
- 예를 들어 사이드바를 표시하는 버튼에 대한 코드가 포함된 구성요소가 있는 경우 버튼은 false로 설정된 토글 사이드바 변수의 상태를 제어합니다.
- 현재 메시지 구성 요소는 GetDay 함수 호출에서 반환된 값을 기반으로 적절한 구성 요소를 렌더링해야 합니다.
- 이 비디오에서는 조건부 렌더링에 대해 알아보고 삼항 연산자를 사용하여 동적 앱 내에서 조건부 렌더링을 구현하는 방법을 배웠습니다.

## 예시
- 예를 들어, 고객이 홈페이지 텍스트에서 내 정보 텍스트로 웹 사이트 변경에 반응할 때 새 페이지로 이동하는 것이 아니라 한 구성 요소가 다른 구성 요소 대신 렌더링된다는 것을 알게 됩니다.

## 요약
- 현재 메시지 구성 요소는 GetDay 함수 호출에서 반환된 값을 기반으로 적절한 구성 요소를 렌더링해야 합니다. 이 비디오에서는 조건부 렌더링에 대해 알아보고 삼항 연산자를 사용하여 동적 앱 내에서 조건부 렌더링을 구현하는 방법을 배웠습니다.
