# Module summary: Data and state

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/react-basics/lecture/LBM6i/module-summary-data-and-state)

## 개요
- 이벤트 유형을 식별하는 방법과 구성 요소를 사용하여 이벤트를 처리하는 방법을 배웠습니다.

## 내용
- 이벤트 유형을 식별하는 방법과 구성 요소를 사용하여 이벤트를 처리하는 방법을 배웠습니다.
- 또한 다양한 유형의 구문을 사용하여 이벤트 처리 코드를 작성할 수 있도록 HTML 및 React에서 이벤트 핸들러를 사용하는 구문의 차이점에 대해서도 배웠습니다.
- 이러한 방법에는 인라인 익명 ES5 함수 사용, 인라인 익명 ES6 함수 사용, 별도의 함수 선언 사용, 별도의 함수 표현식 사용이 포함됩니다.
- 루트에서 시작하여 루트 구성 요소에서 하위 구성 요소, 하위 하위 구성 요소로, 그리고 하위 하위 구성 요소로, 계층 아래로 여러 단계의 중첩으로 흐를 수 있습니다.
- 그 후, 상태 저장 및 상태 비저장 구성 요소를 소개받았고, 주어진 요구에 맞는 최상의 유형을 선택하는 방법을 배웠습니다.
- 구성 요소가 상태 비저장 또는 상태 저장 여부를 결정하기 위해 따라야 하는 몇 가지 규칙을 배웠습니다.
- 구성 요소가 작동하기 위해 자체 상태를 유지할 필요가 없을 때 상태 비저장 구성 요소를 사용합니다.

## 예시
- 예를 들어 UseState 후크를 사용하여 모든 유형의 데이터를 추적할 수 있습니다.

## 요약
- 구성 요소가 상태 비저장 또는 상태 저장 여부를 결정하기 위해 따라야 하는 몇 가지 규칙을 배웠습니다. 구성 요소가 작동하기 위해 자체 상태를 유지할 필요가 없을 때 상태 비저장 구성 요소를 사용합니다.
