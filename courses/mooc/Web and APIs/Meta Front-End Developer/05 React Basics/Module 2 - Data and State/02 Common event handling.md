# Common event handling

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/react-basics/lecture/mAn3k/common-event-handling)

## 개요
- 이제 컴포넌트를 사용하여 React에서 여러 이벤트를 처리하는 방법을 보여 드리겠습니다.

## 내용
- 이제 컴포넌트를 사용하여 React에서 여러 이벤트를 처리하는 방법을 보여 드리겠습니다.
- Return 문에 버튼을 추가하면 버튼이 읽고 나를 클릭하고 Mac에서 Control S 또는 Command S를 눌러 저장하고 버튼을 화면에 렌더링합니다.
- 사용자가 ClickHandler라는 표현식을 평가하는 버튼을 클릭할 때마다 이제 이 ClickHandler를 정의해야 하며 함수 표현식으로 설정합니다.
- 누른 상태에서 K 버튼을 눌렀다 놓은 다음 C 버튼을 눌렀다 놓고 마지막으로 컨트롤 키를 놓습니다.
- 이 주석 처리 된 코드 바로 아래에서 강조 표시된 모든 코드를 주석 처리하는 것을 제어하십시오.
- OnClick JSX 이벤트 처리 속성을 다른 속성으로 바꾸어 다른 이벤트를 처리하겠습니다.
- 예를 들어 onclick 속성을 on mouse over 속성으로 바꾸고 그에 따라 이벤트 처리 기능을 업데이트하여 마우스 오버를 읽을 수 있습니다.

## 예시
- 예를 들어 onclick 속성을 on mouse over 속성으로 바꾸고 그에 따라 이벤트 처리 기능을 업데이트하여 마우스 오버를 읽을 수 있습니다.

## 요약
- OnClick JSX 이벤트 처리 속성을 다른 속성으로 바꾸어 다른 이벤트를 처리하겠습니다. 예를 들어 onclick 속성을 on mouse over 속성으로 바꾸고 그에 따라 이벤트 처리 기능을 업데이트하여 마우스 오버를 읽을 수 있습니다.
