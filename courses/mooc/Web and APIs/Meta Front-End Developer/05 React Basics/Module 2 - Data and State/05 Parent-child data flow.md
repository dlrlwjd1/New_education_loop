# Parent-child data flow

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/react-basics/lecture/jBgei/parent-child-data-flow)

## 개요
- 이 예에서 프로모션 구성 요소는 부모 구성 요소로 알려져 있으며 구성 요소는 렌더링하는 구성 요소인 Promoheading을 하위 구성 요소라고 합니다.

## 내용
- 이 예에서 프로모션 구성 요소는 부모 구성 요소로 알려져 있으며 구성 요소는 렌더링하는 구성 요소인 Promoheading을 하위 구성 요소라고 합니다.
- 이번에는 관리자가 프로모션 구성 요소 외에 웹 앱의 사이드바 및 바닥글 구성 요소에서 프로모션 구성 요소를 호출하도록 요청합니다.
- 필요한 모든 데이터를 props를 사용하여 자식 구성 요소에 전달할 수 있도록 상위 구성 요소 내에 포함됩니다.
- 다음으로, 데이터 개체의 제목과 클릭 유도문안 값을 프로모션 제목 구성 요소에 전달하도록 프로모션 구성 요소를 업데이트합니다.
- 이를 알고 있으면 이제 프로모션 제목 구성 요소와 유사한 방식으로 사이드바 구성 요소와 바닥글 구성 요소를 코딩할 수 있습니다.
- React에서 props 데이터는 항상 부모에서 자식 구성 요소로 흐르며 props를 사용하면 여러 위치에서 데이터를 변경할 필요가 없습니다.
- 부모 구성 요소에 데이터를 저장하면 하위 구성 요소를 개별적으로 업데이트할 필요 없이 동적으로 하위 구성 요소에 전달할 수 있습니다.

## 예시
- 예를 들어 항목을 개별적으로 업데이트하는 것은 지루하고 시간이 많이 걸립니다.

## 요약
- React에서 props 데이터는 항상 부모에서 자식 구성 요소로 흐르며 props를 사용하면 여러 위치에서 데이터를 변경할 필요가 없습니다. 부모 구성 요소에 데이터를 저장하면 하위 구성 요소를 개별적으로 업데이트할 필요 없이 동적으로 하위 구성 요소에 전달할 수 있습니다.
