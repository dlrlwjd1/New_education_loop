# Types of events

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/react-basics/lecture/L71Z2/types-of-events)

## 개요
- 이벤트는 일반적으로 일부 상호 작용에 의존하기 때문에 트리거되기 전에 해당 상호 작용이 발생할 때까지 기다렸다가 백그라운드에서 들어야 합니다.

## 내용
- 이벤트는 일반적으로 일부 상호 작용에 의존하기 때문에 트리거되기 전에 해당 상호 작용이 발생할 때까지 기다렸다가 백그라운드에서 들어야 합니다.
- 모든 HTML 요소에는 일반적으로 이벤트 리스너라고 하는 HTML 속성을 사용하여 개발자가 액세스할 수 있는 일련의 이벤트가 포함되어 있습니다.
- 개발자는 버튼 클릭과 같은 사용자 상호 작용을 기반으로 한 작업에 응답하여 JavaScript의 코드를 실행하기 위해 이벤트를 사용할 수 있습니다.
- HTML 버튼이 일부 코드를 실행하고 이벤트 작업에 응답하기 위해 JavaScript 이벤트 핸들러와 통신하는 이 프로세스를 트리거링이라고 합니다.
- 동일한 이벤트가 다시 트리거되거나 다시 실행되면 장바구니 아이콘 옆에 있는 원의 개수를 업데이트하여 이벤트를 처리하는 이벤트 처리 코드입니다.
- 이 비디오가 끝나면 React에서 사용할 수 있는 광범위한 이벤트 유형을 식별하고 가장 일반적으로 사용되는 이벤트를 설명할 수 있습니다.
- 그러나 실제로 이러한 기능과 함께 제공되는 브라우저는 사건에 액세스하는 데 사용하는 다양한 장치가 사용자가 웹사이트와 상호 작용할 수 있는 다양한 방법을 제공했기 때문입니다.

## 예시
- 예를 들어, 클릭하면 어떤 일이 발생하는 버튼이 있는 웹사이트나 앱의 일반적인 기능입니다.

## 요약
- 이 비디오가 끝나면 React에서 사용할 수 있는 광범위한 이벤트 유형을 식별하고 가장 일반적으로 사용되는 이벤트를 설명할 수 있습니다. 그러나 실제로 이러한 기능과 함께 제공되는 브라우저는 사건에 액세스하는 데 사용하는 다양한 장치가 사용자가 웹사이트와 상호 작용할 수 있는 다양한 방법을 제공했기 때문입니다.
