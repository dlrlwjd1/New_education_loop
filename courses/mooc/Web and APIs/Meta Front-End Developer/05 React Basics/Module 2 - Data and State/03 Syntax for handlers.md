# Syntax for handlers

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/react-basics/lecture/U1gy6/syntax-for-handlers)

## 개요
- 이 비디오가 끝나면 HTML 및 React에서 이벤트 핸들러를 사용하는 구문의 차이점을 설명할 수 있습니다.

## 내용
- 이 비디오가 끝나면 HTML 및 React에서 이벤트 핸들러를 사용하는 구문의 차이점을 설명할 수 있습니다.
- 또한 HTML 함수 호출과 구성 요소 포함을 설명하는 방법을 알고 구성 요소 수준의 제어 수준의 이점에 대해 논의합니다.
- 둘째, JavaScript를 사용하여 HTML 요소에 액세스할 수 있게 되면 Document 객체에 내장된 AddEventListener 메서드를 사용하여 특정 이벤트 리스너를 연결할 수 있습니다.
- 즉, 일반 HTML에서는 onclick 이벤트에 값으로 이벤트 처리 함수에 호출을 전달해야 합니다.
- HTML에서는 ON으로 시작하는 이벤트 처리 속성을 제공하고 이벤트 이름을 추가합니다.
- React에서 ON으로 시작하는 이벤트 처리 속성을 제공하고 각 단어의 첫 글자를 대문자로 추가하여 이벤트 이름을 추가합니다.
- 다음에 웹 페이지에서 버튼을 클릭하거나 알림을 닫거나 단순히 탐색할 때 이러한 이벤트가 어떤 형태의 이벤트 처리에 의해 지원된다는 것을 알게 될 것입니다.

## 예시
- 예를 들어, 버튼을 사용하여 메뉴를 여는 경우를 가정해 보겠습니다.

## 요약
- React에서 ON으로 시작하는 이벤트 처리 속성을 제공하고 각 단어의 첫 글자를 대문자로 추가하여 이벤트 이름을 추가합니다. 다음에 웹 페이지에서 버튼을 클릭하거나 알림을 닫거나 단순히 탐색할 때 이러한 이벤트가 어떤 형태의 이벤트 처리에 의해 지원된다는 것을 알게 될 것입니다.
