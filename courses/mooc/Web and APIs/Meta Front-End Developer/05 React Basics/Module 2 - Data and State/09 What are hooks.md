# What are hooks?

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/react-basics/lecture/mu8sO/what-are-hooks)

## 개요
- 이 시점에서 상호 작용을 추가하고 React 구성 요소 내에서 상태를 유지하고 후크를 탐색하는 방법을 배울 준비가 되었습니다.

## 내용
- 이 시점에서 상호 작용을 추가하고 React 구성 요소 내에서 상태를 유지하고 후크를 탐색하는 방법을 배울 준비가 되었습니다.
- React 개발자로 진행하면서 곧 Stateful Logic을 사용하여 복잡한 구성 요소를 사용할 것입니다.
- 구성 요소에서 상태를 추적하는 것은 상당한 작업이 될 수 있으며 여기에서 React의 후크가 도움이 될 수 있습니다.
- 후크의 한 가지 주요 이점은 구성 요소 간에 불필요한 코드 재사용 문제를 해결한다는 것입니다.
- 이 후크는 구성 요소 내의 상태를 관리하고 이를 추적하는 데 사용되며 React에 직접 내장되어 있습니다.
- 이 예에서는 UseState Hook이 부울 상태 값을 추적하는 데 사용되었음을 알 수 있습니다.
- React를 사용하여 상자에서 나오는 후크 외에도 사용자 정의 구성 요소 논리를 재사용 가능한 기능으로 추출할 수 있는 고유한 후크를 만들 수도 있습니다.

## 예시
- React를 사용하여 상자에서 나오는 후크 외에도 사용자 정의 구성 요소 논리를 재사용 가능한 기능으로 추출할 수 있는 고유한 후크를 만들 수도 있습니다.

## 요약
- 이 예에서는 UseState Hook이 부울 상태 값을 추적하는 데 사용되었음을 알 수 있습니다. React를 사용하여 상자에서 나오는 후크 외에도 사용자 정의 구성 요소 논리를 재사용 가능한 기능으로 추출할 수 있는 고유한 후크를 만들 수도 있습니다.
