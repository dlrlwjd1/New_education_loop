# Children and data

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/react-basics/lecture/TtjoP/children-and-data)

## 개요
- 이러한 유형의 데이터 흐름은 구성 요소 계층을 통해 데이터가 위에서 아래로 이동하도록 합니다.

## 내용
- 이러한 유형의 데이터 흐름은 구성 요소 계층을 통해 데이터가 위에서 아래로 이동하도록 합니다.
- 지금은 이 비디오에서 데이터 흐름에 초점을 맞춰 무국적 및 상태 저장 예제를 사용하는 방법도 배우게 됩니다.
- React에서 데이터는 props를 통해 부모 구성 요소에서 하위 구성 요소로 전달됩니다.
- 그러나 항상 그랬다면 React 앱에서 가질 수 있는 것은 그들이 수신한 데이터로 채워질 구성 요소 템플릿으로 작동하는 DOM의 별도 조각입니다.
- 하위 구성 요소에는 정의된 메시지가 정의되어 있으며 해당 값은 날짜의 시, 분 및 초를 포함하는 문자열 형식으로 변환된 구성 요소 상태의 현재 날짜로 설정됩니다.
- 이제 앱을 실행할 때 앱 구성 요소의 상태가 데이터를 하위 구성 요소 소품으로 흐르고 h1 요소에 현재 날짜와 시간이 표시됩니다.
- 이제 React.js에서 자식과 데이터가 어떻게 흐르는지 배웠고, 데이터 흐름에 초점을 맞춰 무국적 및 상태 저장 예제를 사용할 수 있어야 합니다.
