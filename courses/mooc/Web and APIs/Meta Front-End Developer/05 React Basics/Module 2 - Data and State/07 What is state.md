# What is state?

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/react-basics/lecture/Z0oi5/what-is-state)

## 개요
- 일반적으로 기상 시간을 설정하기 위해 알람이 켜져 있고, 이 기능이 필요하지 않을 때는 알람을 끄고, 몇 분 더 잠을 자면 잠을 자는 것에 대해 알람이 켜져 있습니다.

## 내용
- 일반적으로 기상 시간을 설정하기 위해 알람이 켜져 있고, 이 기능이 필요하지 않을 때는 알람을 끄고, 몇 분 더 잠을 자면 잠을 자는 것에 대해 알람이 켜져 있습니다.
- React 앱에서 이 기능을 생성하면 Clock이라는 구성 요소를 만든 다음 props를 통해 상태 값을 구문 분석할 수 있습니다.
- 이를 통해 주어진 요구에 맞게 구성 요소가 작동하는 방식을 쉽게 변경할 수도 있습니다.
- 상태를 구성 요소의 현재 동작을 결정하는 구성 요소의 내부 데이터로 생각하는 데 도움이 됩니다.
- 자식 구성 요소에 고유한 손자식 구성 요소가 있는 경우 하위 구성 요소에 해당 손자 구성 요소에 소품을 보내는 일부 상태가 있을 수 있습니다.
- 텍스트를 상태 비저장 구성 요소로 렌더링한 다음 상태 저장 기능 구성 요소를 갖는 단일 작업을 수행합니다.
- 이 비디오에서는 React의 상태, 특히 앱의 상태 저장 및 상태 비저장 구성 요소의 특성에 대해 배웠습니다.

## 예시
- 이 코드 라인은 이미 이해가 되었지만 명확하게 하기 위해 사과, 배, 자두의 세 가지 문자열을 포함하는 Fruits라는 예를 들어 살펴보십시오.

## 요약
- 텍스트를 상태 비저장 구성 요소로 렌더링한 다음 상태 저장 기능 구성 요소를 갖는 단일 작업을 수행합니다. 이 비디오에서는 React의 상태, 특히 앱의 상태 저장 및 상태 비저장 구성 요소의 특성에 대해 배웠습니다.
