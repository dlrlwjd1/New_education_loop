# User events

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/react-basics/lecture/8mIir/user-events)

## 개요
- 상태를 사용하여 다크 모드의 부울 값을 계속 유지하는 구성 요소가 있다고 가정해 보겠습니다.

## 내용
- 상태를 사용하여 다크 모드의 부울 값을 계속 유지하는 구성 요소가 있다고 가정해 보겠습니다.
- 이 변수의 값이 true인지 false인지에 따라 컴포넌트는 일부 텍스트가 있는 H1 제목을 렌더링합니다.
- 앱에 추가 기능을 제공하기 위해 이벤트 사용에 대한 실용적인 통찰력을 얻을 수 있도록 예제를 사용하여 이벤트 처리를 시연할 것입니다.
- true에서 false까지의 변수인 다크 모드 값의 이 토글을 처리하기 위해 on Click 이벤트가 있는 버튼을 추가합니다.
- 이것을 조금 더 설명하기 위해, 다크 모드 ON의 값이 예를 들어 true이면, 다크 아님 모드 켜기는 TRUE가 아닌 것으로 평가됩니다.
- 라이트 모드의 이전 제목이 켜져 있기 때문에 이제 다크 모드가 켜져 있는 제목이 되었습니다.
- 이제 사용자 트리거 이벤트를 사용하여 부울 변수의 값을 토글하는 방법을 보여줄 수 있습니다.

## 예시
- 이것을 조금 더 설명하기 위해, 다크 모드 ON의 값이 예를 들어 true이면, 다크 아님 모드 켜기는 TRUE가 아닌 것으로 평가됩니다.

## 요약
- 라이트 모드의 이전 제목이 켜져 있기 때문에 이제 다크 모드가 켜져 있는 제목이 되었습니다. 이제 사용자 트리거 이벤트를 사용하여 부울 변수의 값을 토글하는 방법을 보여줄 수 있습니다.
