# Observing state

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/react-basics/lecture/1XZnE/observing-state)

## 개요
- 이를 통해 구성 요소는 상태 데이터의 변경 사항을 기반으로 다시 렌더링하고 최신 업데이트를 사용자에게 제공할 수 있습니다.

## 내용
- 이를 통해 구성 요소는 상태 데이터의 변경 사항을 기반으로 다시 렌더링하고 최신 업데이트를 사용자에게 제공할 수 있습니다.
- 이를 염두에 두고 이전에 발견한 UseState 후크로 두 구성 요소를 업데이트하는 방법을 살펴보겠습니다.
- UseState Hook을 사용하는 것이 얼마나 유용한지 이해하는 데 도움이 되도록 이제 이를 사용하여 구성 요소의 상태를 관찰하고 조작하는 방법을 보여주는 예제를 탐색합니다.
- 부모의 app.js 구성 요소에서 제목 구성 요소를 가져와서 단어를 상태 변수로 설정하고 EAT 문자열로 설정합니다.
- 단어 상태 변수의 값을 음료와 같은 다른 값으로 업데이트하고 싶다면 설정된 단어 함수를 직접 사용하여 이를 달성하는 데 도움이 될 수 있습니다.
- 상태를 관찰하고 업데이트하려면 상태 후크를 사용하여 상태의 설정 함수와 상태 변수를 사용할 수 있습니다.
- 이 비디오에서는 상태 구문 사용을 적용하고 상태 및 구성 요소를 관찰하고 조작하는 방법을 포함하여 React의 상태 변경 기본에 대해 배웠습니다.

## 예시
- 예를 들어 날짜 변수를 사용하여 날짜 상태에 액세스할 수 있습니다.

## 요약
- 상태를 관찰하고 업데이트하려면 상태 후크를 사용하여 상태의 설정 함수와 상태 변수를 사용할 수 있습니다. 이 비디오에서는 상태 구문 사용을 적용하고 상태 및 구성 요소를 관찰하고 조작하는 방법을 포함하여 React의 상태 변경 기본에 대해 배웠습니다.
