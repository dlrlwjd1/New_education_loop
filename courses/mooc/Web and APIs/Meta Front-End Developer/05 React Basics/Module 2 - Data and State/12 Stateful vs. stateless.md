# Stateful vs. stateless

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/react-basics/lecture/c8Tpl/stateful-vs-stateless)

## 개요
- 이 비디오가 끝나면 상태 유형 간의 차이점을 설명하고 주어진 요구에 맞는 최상의 유형을 선택하고 React의 동적 특성이 복잡성에 영향을 미치기 위해 구조화된 결정을 호출하는 방법을 설명할 수 있습니다.

## 내용
- 이 비디오가 끝나면 상태 유형 간의 차이점을 설명하고 주어진 요구에 맞는 최상의 유형을 선택하고 React의 동적 특성이 복잡성에 영향을 미치기 위해 구조화된 결정을 호출하는 방법을 설명할 수 있습니다.
- 상태 저장 구성 요소와 무국적 구성 요소의 차이점은 상태 저장 구성 요소가 상태를 내부 데이터로 유지하고 앱이 빌드되는 방식에 따라 상태가 변경된다는 것입니다.
- 그러나 상태 비저장 구성 요소는 상태를 저장하지 않으며 모든 변경 사항은 props를 통해 상속되어야 합니다.
- 구성 요소가 작동하기 위해 자체 상태를 유지할 필요가 없을 때 상태 비저장 구성 요소를 사용합니다.
- React에서 구성 요소를 구성하는 일반적인 접근 방식은 상태가 저장된 구성 요소를 부모로 사용하여 상태를 여러 상태 비저장 구성 요소로 보내고 상태를 수신하고 화면에서 렌더링하는 것입니다.
- 이 비디오에서는 특정 요구 사항에 따라 React 앱에서 상태 저장 또는 상태 비저장 구성 요소를 활용하는 이유와 시기를 배웠습니다.
- 또한 상태 비저장 구성 요소가 상태를 직접 전달할 수는 없지만 다른 구성 요소의 상태를 업데이트하는 작업을 계속 트리거할 수 있음을 관찰했습니다.

## 예시
- 또한 상태 비저장 구성 요소가 상태를 직접 전달할 수는 없지만 다른 구성 요소의 상태를 업데이트하는 작업을 계속 트리거할 수 있음을 관찰했습니다.

## 요약
- 이 비디오에서는 특정 요구 사항에 따라 React 앱에서 상태 저장 또는 상태 비저장 구성 요소를 활용하는 이유와 시기를 배웠습니다. 또한 상태 비저장 구성 요소가 상태를 직접 전달할 수는 없지만 다른 구성 요소의 상태를 업데이트하는 작업을 계속 트리거할 수 있음을 관찰했습니다.
