# Managing state

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/react-basics/lecture/JJv8p/managing-state)

## 개요
- 이 비디오에서는 상태 관리의 개념을 설명하고 React 응용 프로그램에서 상태를 관리하기 위한 몇 가지 솔루션을 탐색하는 방법을 배웁니다.

## 내용
- 이 비디오에서는 상태 관리의 개념을 설명하고 React 응용 프로그램에서 상태를 관리하기 위한 몇 가지 솔루션을 탐색하는 방법을 배웁니다.
- 앱은 App.js라는 루트 구성 요소와 두 개의 하위 구성 요소인 MealsList 및 Counter라는 세 가지 구성 요소로 구성됩니다.
- 카운터 구성 요소는 MealsList 구성 요소에서 상태 정보를 가져와야 하지만 두 구성 요소 모두 App 구성 요소에서 렌더링됩니다.
- 카운터 구성 요소가 MealsList 구성 요소의 하위가 아닌 경우 MealsList 구성 요소의 상태 정보를 카운터 구성 요소로 전달하는 방법은 무엇입니까?
- 그런 다음 MealsList 구성 요소를 MealItem 구성 요소에 대한 일종의 브리지로 사용하여 소품을 통과할 수 있습니다.
- 상태는 이제 앱 구성 요소로 이동했으며 내 MealsList 구성 요소는 상태 데이터가 대상인 MealItem 구성 요소로 전달되는 도관이 됩니다.
- 소품 드릴링은 부모에서 자식, 그 아이의 자식 등의 구성 요소에서 여러 계층의 구성 요소에 있는 소품을 통해 상태를 전달해야 하는 것을 설명하는 데 일반적으로 사용되는 용어입니다.

## 예시
- 국가를 관리해야 하는 시나리오를 설명하려면 사용자가 음식 섭취를 모니터링할 수 있도록 하여 더 건강한 생활 방식을 촉진하는 데 도움이 되는 소규모 React 앱을 고려하십시오.

## 요약
- 상태는 이제 앱 구성 요소로 이동했으며 내 MealsList 구성 요소는 상태 데이터가 대상인 MealItem 구성 요소로 전달되는 도관이 됩니다. 소품 드릴링은 부모에서 자식, 그 아이의 자식 등의 구성 요소에서 여러 계층의 구성 요소에 있는 소품을 통해 상태를 전달해야 하는 것을 설명하는 데 일반적으로 사용되는 용어입니다.
