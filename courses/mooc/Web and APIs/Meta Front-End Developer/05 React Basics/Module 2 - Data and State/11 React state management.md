# React state management

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/react-basics/lecture/hyeST/react-state-management)

## 개요
- 이 과정에서 상위 구성 요소와 하위 구성 요소 사이의 상태를 관리하는 몇 가지 접근 방식을 배웠을 것입니다.

## 내용
- 이 과정에서 상위 구성 요소와 하위 구성 요소 사이의 상태를 관리하는 몇 가지 접근 방식을 배웠을 것입니다.
- 이 비디오가 끝나면 컨텍스트 API를 사용하여 여러 수준의 구성 요소에서 상태를 보다 효율적으로 관리하는 방법을 이해할 수 있습니다.
- 또한 Context API에 있는 UseContext 및 UserEducer 후크를 사용하여 기본 상태 관리를 수행할 수 있습니다.
- 이 시점에서 소품을 사용하여 한 구성 요소에서 다른 구성 요소로 상태를 전달하는 관행에 익숙할 것입니다.
- MealsProvider는 컨텍스트 상태 데이터를 제공하고 앱 구성 요소 내에서 래핑하는 모든 구성 요소에 제공합니다.
- 파일 하단에서 MealsProvider 구성 요소를 내보내기 전에 UseMealsListContext 변수를 React.UseContext 호출로 설정하고 MealsContext에 단일 인수로 전달합니다.
- 이 비디오에서는 UseContext 및 UserEducer 후크를 사용하여 여러 수준의 구성 요소에서 상태를 보다 효율적으로 관리하는 방법을 배웠습니다.

## 예시
- 이 비디오에서는 UseContext 및 UserEducer 후크를 사용하여 여러 수준의 구성 요소에서 상태를 보다 효율적으로 관리하는 방법을 배웠습니다.

## 요약
- 파일 하단에서 MealsProvider 구성 요소를 내보내기 전에 UseMealsListContext 변수를 React.UseContext 호출로 설정하고 MealsContext에 단일 인수로 전달합니다. 이 비디오에서는 UseContext 및 UserEducer 후크를 사용하여 여러 수준의 구성 요소에서 상태를 보다 효율적으로 관리하는 방법을 배웠습니다.
