# Course recap: React Basics

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/react-basics/lecture/Cr55y/course-recap-react-basics)

## 개요
- 이 소개에서 당신은 React에 대해 배웠고 React가 실제 세계에서 어떻게 사용되는지에 대해 배웠습니다.

## 내용
- 이 소개에서 당신은 React에 대해 배웠고 React가 실제 세계에서 어떻게 사용되는지에 대해 배웠습니다.
- 그런 다음 React 구성 요소에 대해 배운 다음 수업으로 넘어갔습니다.
- 이 단원에서는 구성 요소, 해당 아키텍처 및 렌더링 방법을 설명하는 방법을 배웠습니다.
- 그런 다음 구성 요소를 가져오는 방법에 대한 지식을 보여주었습니다.
- 즉, 이제 props로 기능 구성 요소를 선언하고 다른 구성 요소에 전달할 수 있습니다.
- 결과적으로 이제 부모와 자식 구성 요소 간의 데이터 흐름을 설명하고 React의 상태 개념과 관리 방법을 설명할 수 있습니다.
- 또한 후크를 소개했고 이제 후크를 사용하여 상태의 기능을 확장할 수 있으며 상태 저장 및 상태 비저장 구성 요소에 대한 몇 가지 일반적인 사용 사례를 식별할 수 있습니다.

## 예시
- 또한 후크를 소개했고 이제 후크를 사용하여 상태의 기능을 확장할 수 있으며 상태 저장 및 상태 비저장 구성 요소에 대한 몇 가지 일반적인 사용 사례를 식별할 수 있습니다.
