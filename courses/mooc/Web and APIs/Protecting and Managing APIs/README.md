# Protecting and Managing APIs

**Course URL:** [mooc.org/learn/protecting-and-managing-apis](https://www.mooc.org/learn/protecting-and-managing-apis)

Edureka · "API Development and Architecture" 스페셜라이제이션의 한 코스. API 보안 기초(인증·인가·암호화·위협 방어)부터 API 관리·모니터링·제품화까지 3개 모듈로 구성. 각 레슨은 영상·읽기자료·실습 데모(Demonstration)·AI 대화형 활동(Dialogue)으로 구성되며, Practice Quiz/Graded Assignment/Discussion Prompt는 학업 정직성 정책에 따라 건너뜀.

## 모듈 구성
- [Module 1 - API Security Fundamentals](Module%201%20-%20API%20Security%20Fundamentals/) — 인증 방법(Basic Auth·API 키·OAuth 2.0·JWT, OAuth 구현 실습), 인가와 접근 제어(RBAC·ABAC·OAuth 스코프, RBAC 구축 실습), 흔한 API 공격(인젝션·중간자·DoS)과 보안 테스트 실습(취약한 서버 vs. 강화된 서버 비교), 암호화와 컴플라이언스(HTTPS/TLS 구현 실습, GDPR·HIPAA·PCI DSS), Module 요약과 헬스케어 API 보안 실습 프로젝트(MediServe 시나리오)
- [Module 2 - API Management and Monitoring](Module%202%20-%20API%20Management%20and%20Monitoring/) — API 게이트웨이(개념·Kong/Apigee/NGINX 등 도구·라우팅과 프록시, Kong+Python 실습), 모니터링과 분석(로깅 모범 사례·Prometheus/Grafana 모니터링 실습·API 사용량 지표·대시보드/A-B 테스트·SQLite 기반 분석 실습), API 제품화(제품으로의 전환·수익화·개발자 포털/마켓플레이스·거버넌스, FastAPI 개발자 포털 실습), Module 요약과 FinBank API 관리 실습 프로젝트
- [Module 3 - Course Wrap-Up and Assessment](Module%203%20-%20Course%20Wrap-Up%20and%20Assessment/) — ApexFin 종합 실습 프로젝트 개요(인증·게이트웨이·모니터링·제품화·거버넌스 통합), API 키 침해 사고 대응 시나리오(Dialogue), 코스 전체 요약 영상
