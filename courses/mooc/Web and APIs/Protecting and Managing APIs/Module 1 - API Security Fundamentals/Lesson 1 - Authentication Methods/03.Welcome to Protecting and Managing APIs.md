# Welcome to Protecting and Managing APIs (환영 읽기자료)

## 개요
- 코스 전체 구조·목표·평가 방식·대상 수강생을 안내하는 30분 분량 읽기자료 — Module 1 "Lesson 1: Authentication Methods"의 세 번째 항목

## 내용

### 코스 개요
- API 개발자·아키텍트·DevOps 전문가를 대상으로, 안전하고 잘 거버넌스되며 고성능인 API를 구축하도록 돕는 종합 실습 코스
- API Security Fundamentals(핵심 인증·인가 방법, 암호화 구현, 흔한 공격 벡터 방어)로 시작해, API Management and Monitoring(게이트웨이 설정, 모니터링·분석 적용, API를 완전한 제품으로 전환하는 전략)으로 이어짐

### 학습 목표
- OAuth 2.0·JWT·RBAC·ABAC 같은 안전한 인증·인가 메커니즘 구현
- 인젝션·DoS·중간자 공격 같은 흔한 API 위협을 식별·테스트·완화
- 암호화 기법을 적용하고 민감 데이터 보호를 위한 컴플라이언스 표준 충족
- 트래픽 라우팅·프록시·정책 적용을 위한 API 게이트웨이 구성·운영
- API 성능 모니터링, 분석 대시보드 구축, 지표와 A/B 테스트를 통한 채택률 개선
- 개발자 포털 제작, 수익화 전략 탐구, 거버넌스 모델 적용을 통한 API 제품화

### 코스 구조 — 3개 모듈
- **Module 1: API Security Fundamentals** — Lesson 1.1 Authentication Methods, Lesson 1.2 Authorization and Access Control, Lesson 1.3 Securing APIs Against Threats, Lesson 1.4 Encryption and Compliance
- **Module 2: API Management and Monitoring** — Lesson 2.1 API Gateways, Lesson 2.2 Monitoring and Analytics, Lesson 2.3 API Productization
- **Module 3: Course Wrap-Up and Assessment** — Course Summary 영상, End Course Knowledge Check(Graded Assignment)

### 평가·학습 방식
- 각 모듈은 지식 점검(knowledge check)과 실습 데모를 포함하며, 코스는 최종 채점 평가로 마무리됨
- 영상·데모와 더불어 인증·인가·모니터링·거버넌스 모범 사례를 다루는 읽기자료·참고 가이드가 제공됨
- OAuth 구현, RBAC 설정, API 게이트웨이 구성, 모니터링·분석 활성화 등 핸즈온 데모를 통해 이론과 실전을 연결함
- 디스커션 프롬프트 등 협업 학습 요소로 동료 학습자와 통찰을 공유하고 다양한 API 보호·관리 전략에 노출됨

### 수강 대상
- API 보안 태세를 강화하고 API 관리·분석 전문성을 기르려는 API 개발자, 백엔드 엔지니어, DevOps 전문가, 솔루션 아키텍트에게 적합
- 웹 서비스·API에 대한 기본적인 이해가 권장되지만, API 보안이나 관리에 대한 사전 경험은 필요하지 않음
