# Specialization Introduction (스페셜라이제이션 소개)

## 개요
- "API Development and Architecture" 스페셜라이제이션 전체(4개 코스)의 구성과 학습 목표를 소개하는 3분 16초 분량 영상 — Module 1 "Lesson 1: Authentication Methods"의 첫 항목이자 이 코스("Protecting and Managing APIs")가 속한 스페셜라이제이션 전체의 오리엔테이션

## 내용

### 스페셜라이제이션 구성 — 4개 코스
- **Course 1: Getting Started with APIs** — API 기초, 핵심 개념과 아키텍처, HTTP 메서드·헤더·상태 코드, REST·SOAP·GraphQL·WebSocket 비교, 간단하고 문서화가 잘 된 API를 직접 설계·구축
- **Course 2: Modern API Development** — Django·Node.js·Spring Boot 전반에 걸쳐 API를 구축하고, 데이터 처리·검증, 명확한 에러 응답 설계, API 버전 관리 전략, 장시간 작업을 위한 비동기 패턴을 익힌 뒤 프로파일링과 캐싱으로 성능을 튜닝
- **Course 3: Protecting and Managing APIs** (현재 코스) — 인증·인가(OAuth2, JWT, RBAC) 구현, 흔한 위협·악용에 대한 방어, 암호화·컴플라이언스 적용, API 게이트웨이를 통한 정책·트래픽 제어, 모니터링·분석·제품화로 규모 있게 운영하기
- **Course 4: Advanced API Technologies** — GraphQL 기초(스키마·쿼리·뮤테이션·리졸버)부터 GraphQL API 구축·배포, 마이크로서비스(동기/비동기 통신, 오케스트레이션), 데이터 관리, CI/CD, 쿠버네티스 배포까지 엔드투엔드로 다룸

### 이 스페셜라이제이션을 통해 얻는 것
- API 개념과 REST 설계에 대한 탄탄한 기초
- Django·Node.js·Spring Boot로 실습 경험
- 게이트웨이·모니터링·컴플라이언스로 API를 보안·관리하는 능력
- GraphQL과 마이크로서비스 탐구, 확장성과 성능에 초점을 맞춘 엔터프라이즈급 API 설계 역량
