# Protecting and Managing APIs: Self Check-In (자기 점검 대화형 활동)

## 개요
- 10분 분량의 AI 기반 대화형(Dialogue) 자기 점검 활동 — Module 1 "Lesson 1: Authentication Methods"의 네 번째 항목
- 새로운 개념을 가르치는 콘텐츠가 아니라, 코스를 시작하기 전에 학습자의 현재 이해도를 파악해 학습 경험을 개인화하기 위한 진단용 대화

## 내용

### 다루는 주제 범위(사전 진단 목적)
- API가 인증·인가되는 방식(API 키, OAuth, RBAC/ABAC)
- 인젝션 공격, DoS, 중간자 공격 등 API에 대한 위협
- 암호화·HTTPS·컴플라이언스 표준 같은 API 보호 조치
- 게이트웨이·모니터링·분석·제품화 같은 API 관리 개념

### 활동의 성격
- 이 대화는 AI(MOOC Coach)가 학습자에게 질문을 던져 현재 지식 수준을 스스로 점검하게 하는 형식으로, 정답이 채점되는 평가가 아니라 이후 학습 내용을 개인화하기 위한 오리엔테이션 성격의 활동임
- 실제 강의 개념(인증, 위협, 암호화, 관리)은 이후 Lesson 1의 영상들(05~08)과 Lesson 2~4에서 본격적으로 다뤄짐

## 요약
- 이 항목 자체는 새로운 학습 콘텐츠를 전달하지 않으며, 앞으로 배울 Module 1의 전체 주제 지도를 미리 훑어보는 셀프 체크인 역할을 함
- 다음 [05.API Authentication Methods.md](05.API%20Authentication%20Methods.md)에서 API 인증 방법에 대한 본격적인 학습이 시작됨
