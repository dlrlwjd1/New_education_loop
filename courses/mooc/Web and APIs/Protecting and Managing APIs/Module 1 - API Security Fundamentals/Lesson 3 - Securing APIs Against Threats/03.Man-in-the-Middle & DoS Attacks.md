# Man-in-the-Middle & DoS Attacks (중간자 공격과 DoS 공격)

## 개요
- 중간자(man-in-the-middle) 공격과 서비스 거부(denial-of-service, DoS) 공격이 각각 어떻게 작동하고 어떤 피해를 일으키며 왜 이해가 중요한지 다루는 3분 46초 분량 영상 — Module 1 "Lesson 3: Securing APIs Against Threats"의 세 번째 영상

## 내용

### 두 공격의 정의
- **중간자 공격(Man-in-the-middle attack)**: 악의적인 행위자가 두 당사자 사이에 몰래 자리 잡아 통신을 가로챔 — 대화를 엿듣는 스파이와 같음. 이는 어느 쪽도 모르는 사이에 데이터가 실시간으로 도난·감시·심지어 변조될 수 있음을 의미함
- **서비스 거부 공격(DoS)**: 가짜 트래픽으로 시스템을 압도해 사용할 수 없게 만듦 — 진짜 쇼핑객이 들어올 수 없도록 수천 명의 가짜 손님이 매장으로 몰려드는 것과 같음

### 공격이 시스템을 방해하는 방식
- **중간자 공격**: 공격자가 사용자와 서버 사이에 조용히 끼어들어 전송 중인 데이터를 포착함 — 은행 송금 세부사항을 바꾸는 것처럼 탐지되지 않고 민감한 데이터를 읽거나 훔치거나 변조할 수 있음
- **DoS 공격**: 공격자가 과도한 요청으로 서버를 폭격해 과부하시킴 — 결과적으로 정당한 사용자는 속도 저하·오류·완전한 서비스 중단을 겪음. 세일 날 온라인 쇼핑몰이 자동화된 가짜 방문에 잠겨 갑자기 멈추는 상황을 상상하면 됨

### 결과와 영향
- 성공적인 중간자 공격은 민감한 데이터를 노출시켜 사기와 신원 도용을 가능하게 함 — 예를 들어 가로챈 로그인 자격증명이 범죄자에게 금융 계좌나 기밀 회사 이메일 접근권을 줄 수 있음
- DoS 공격은 상당한 다운타임, 매출 손실, 조직 평판 손상으로 이어질 수 있음 — 서비스가 자주 이용 불가능해지면 고객은 신뢰를 잃음
- 이런 결과를 인식하는 것이 왜 이 공격들이 모든 조직의 위험 평가에서 높은 순위를 차지하는지 이해하는 데 도움을 줌

### 오늘날의 위협 환경
- 오늘날 연결된 세상에서 중간자 공격은 특히 공용 Wi-Fi 네트워크, 취약한 암호화 설정, 피싱 시나리오에서 주요 위협임 — 신뢰·안전한 통신·온라인 거래를 훼손함
- 마찬가지로 DoS 공격은 핵티비즘(hacktivism)과 사이버 전쟁의 도구로, 뱅킹이나 헬스케어 시스템 같은 핵심 서비스를 방해하는 데 사용됨
- 이런 위험에 대응하기 위해 조직은 로드 밸런싱, 침입 탐지, 강력한 암호화 같은 복원력과 가동 시간 보호에 많은 투자를 함 — 이런 방어책은 디지털 세계의 자물쇠와 경보 시스템과 같음

## 요약
- 중간자 공격은 통신을 가로채 데이터를 훔치거나 변조하고, DoS 공격은 가짜 트래픽으로 시스템을 압도해 서비스를 마비시킴 — 둘 다 사기·신원 도용·다운타임·평판 손상 같은 심각한 결과를 초래함
- 공용 Wi-Fi·약한 암호화·피싱은 중간자 공격의 온상이며, 로드 밸런싱·침입 탐지·강력한 암호화가 두 위협 모두에 대한 핵심 방어책임
