# Security Best Practices & Preventive Measures (보안 모범 사례와 예방 조치)

## 개요
- 보안 모범 사례가 왜 중요하며 조직이 예방 조치를 어떻게 실천에 옮길 수 있는지 다루는 3분 41초 분량 영상 — Module 1 "Lesson 3: Securing APIs Against Threats"의 네 번째 영상
- 사이버 보안은 더 이상 방화벽과 백신 소프트�어에 관한 것만이 아니라, 공격자를 한 걸음 떨어뜨려 놓는 강력한 습관과 예방 조치를 만드는 것에 관한 것임

### 보안 모범 사례가 중요한 이유
1. 사이버 공격이 증가하고 있으며 대기업만이 아니라 중소기업도 똑같이 취약함
2. 기본 비밀번호를 그대로 두는 것 같은 취약한 설정이 공격자에게 가장 큰 문을 열어주는 경우가 많음
3. 사람의 실수가 침해의 가장 큰 원인으로 남아 있음 — 피싱 링크 클릭이든 시스템 잘못 설정이든
4. 사전 예방적 방어는 비용을 절약할 뿐 아니라 시간·신뢰·평판도 보호함
- 요약하면 모범 사례는 선택이 아니라 디지털 시대의 생존에 필수적임

## 내용

### 모든 조직이 따라야 할 핵심 관행
1. **강력한 인증 방법 사용**: 다중 인증(MFA)과 복잡하고 정기적으로 갱신되는 비밀번호
2. **최소 권한 원칙 적용**: 사용자가 업무에 필요한 것보다 더 많은 접근 권한을 주지 않음 — 계정이 침해되었을 때 피해를 최소화함
3. **시스템을 항상 패치·업데이트된 상태로 유지**: 공격자는 오래된 소프트웨어를 악용함 — 마치 현관문을 잠그지 않은 것과 같음
- 이 세 가지는 기본적으로 들리지만 함께 강력한 방어 체계의 근간을 이룸

### 실제 적용되는 예방 조치
- **모든 곳에 암호화**: 데이터가 도난당하더라도 읽을 수 없게 만듦
- **정기 감사**: 공격자보다 먼저 취약점을 발견하도록 도움
- **모니터링과 알림**: 24시간 시스템을 지켜보는 경비원처럼 작동해 이상 활동을 빠르게 표시함
- **직원 교육**: 아마도 가장 강력한 도구 — 아무리 뛰어난 기술도 인식 없이는 사람의 실수를 막을 수 없음
- 이 조치들이 결합되면 계층화된 방어를 이루어 공격자가 성공하기 훨씬 어려워짐

### 장기적 회복탄력성
- 보안은 일회성 수정이 아니라 장기적인 회복탄력성(resilience)에 관한 것임
- **제로 트러스트 모델**: 로그인 시 한 번만이 아니라 모든 단계에서 엄격한 검증을 보장함
- **사고 대응 계획**: 문제가 발생했을 때 팀이 빠르게 복구하도록 도움
- **지속적인 위험 평가**: 진화하는 위협을 계속 점검함
- **보안 우선 문화**: IT 부서만이 아니라 모든 직원을 보호의 이해관계자로 만듦
- 이런 관행들을 내재화함으로써 조직은 위협에 그저 대응하는 것을 넘어 예측하고 견뎌낼 수 있게 됨

## 요약
- 강력한 인증·최소 권한·패치 관리라는 핵심 관행과, 암호화·정기 감사·모니터링·직원 교육이라는 예방 조치가 결합되면 계층화된 방어를 형성함
- 제로 트러스트·사고 대응 계획·지속적 위험 평가·보안 우선 문화가 일회성 대응을 넘어선 장기적 회복탄력성을 만듦
