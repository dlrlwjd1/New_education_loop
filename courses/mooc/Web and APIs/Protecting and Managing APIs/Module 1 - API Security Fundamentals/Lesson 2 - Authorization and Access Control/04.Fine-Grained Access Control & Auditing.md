# Fine-Grained Access Control & Auditing (세밀한 접근 제어와 감사)

## 개요
- 세밀한 접근 제어(Fine-Grained Access Control, FGAC)와 감사(auditing)가 무엇이고 어떻게 함께 작동하는지, 왜 중요하며 어떻게 실무에 적용되는지 다루는 4분 4초 분량 영상 — Module 1 "Lesson 2: Authorization and Access Control"의 네 번째 영상

## 내용

### 두 핵심 용어 정의
- **세밀한 접근 제어(FGAC)**: 테이블·행·열, 심지어 특정 속성 단위까지 상세한 수준에서 접근을 제한함 — 예를 들어 병원 데이터베이스에서 간호사는 환자의 알레르기 정보는 볼 수 있지만 청구 세부사항은 절대 볼 수 없게 할 수 있음
- **감사(Auditing)**: 누가 무엇을, 언제, 어떻게 접근했는지 추적함 — 단순한 호기심 차원이 아니라 책임성(accountability)을 보장하고 HIPAA나 GDPR 같은 법률 준수를 지원함
- 통제(control)와 책임성(accountability)이 결합되면 더 강력한 보안 프레임워크가 됨 — 데이터를 보호할 뿐 아니라 모든 접근이 정당하고 기록되었음을 증명함(문에 자물쇠를 달고 모든 출입을 녹화하는 카메라를 더한 것과 같음)

### FGAC와 감사가 중요한 이유
1. **데이터 노출 방지**: 급여나 건강 기록 같은 민감 데이터가 필요한 사람에게만 보이도록 유지함
2. **최소 권한 강제**: 사람들이 자신의 역할에 필요한 최소한의 정보에만 접근하게 함
3. **컴플라이언스 지원**: GDPR·SOX 같은 많은 규제가 엄격한 통제와 감사 추적을 요구함
4. **포렌식 통찰**: 의심스러운 일이 발생하면 감사가 조사자에게 명확한 타임라인을 제공함
5. **적응성**: 팀이나 프로젝트가 진화함에 따라 권한을 쉽게 조정할 수 있음
6. **신뢰 향상**: 파트너와 고객이 접근이 모니터링·통제되고 있음을 알게 됨

### 작동 방식 — 4단계 워크플로
1. **사용자 요청**: 누군가 특정 데이터에 접근하려 시도함
2. **정책 확인**: 시스템이 사용자의 역할, 요청된 정확한 행/열 같은 요소를 고려해 세밀한 규칙을 평가함
3. **접근 허가**: 모든 조건이 충족되면 데이터 접근이 허용됨
4. **감사 기록**: 접근이 허용되든 거부되든 모든 행동이 감사 로그에 기록되어 향후 검토를 위한 영구 기록이 만들어짐
- 이 4단계 워크플로는 올바른 사람만 올바른 시점에 올바른 데이터를 보게 하고, 모든 단계가 문서화되도록 보장함

### 실무 적용 사례
- **엔터프라이즈**: 역할 기반 대시보드와 상세한 감사 추적으로 재무·전략 데이터를 볼 수 있는 사람을 통제함
- **교육 시스템**: 학생은 자신의 성적만 볼 수 있고, 관리자는 전체 학사 기록에 접근할 수 있음
- **미디어 플랫폼**: 편집자는 콘텐츠를 게시·수정할 수 있지만 일반 시청자는 읽기만 가능함
- 이런 사례들은 FGAC가 산업마다 다르게 적응하며 항상 접근성과 책임성 사이의 균형을 맞춘다는 것을 보여줌 — 각 사람에게 자신의 영역에만 맞는 맞춤형 열쇠를 주는 것과 같음

## 요약
- FGAC는 테이블·행·열 수준까지 접근을 세밀하게 제한하고, 감사는 모든 접근 시도(허용·거부 모두)를 기록해 책임성과 컴플라이언스를 보장함 — 정책 확인 → 접근 허가/거부 → 감사 로그 기록의 4단계 워크플로로 작동함
- 헬스케어·엔터프라이즈·교육·미디어 등 다양한 산업에서 최소 권한 원칙과 규제 준수를 동시에 충족하는 핵심 메커니즘임
