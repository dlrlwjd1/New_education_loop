# Demonstration: Creating a Developer Portal for an API (API 개발자 포털 만들기 실습 데모)

## 개요
- 개발자가 엔드포인트를 탐색하고, 요청을 대화형으로 테스트하며, API 키로 인증할 수 있는 간단한 개발자 포털을 구축하는 4분 50초 분량 실습 데모 영상 — Module 2 "Lesson 3: API Productization"의 다섯 번째이자 마지막 영상
- 완료 시점에는 공개 엔드포인트와 보호된 엔드포인트가 모두 작동하는 것을 확인하게 됨

## 내용

### Step 1 — 의존성 설치 및 앱 메타데이터 설정
- 프로젝트 폴더 안에서 FastAPI, uvicorn, python-multipart를 pip install로 설치함
- `main.py` 파일을 만들고 FastAPI와 HTTP 예외·요청 헤더 처리를 위한 모듈을 임포트함
- FastAPI 앱을 만들면서 제목·설명·버전을 제공함 — 이 메타데이터는 개발자 포털에 자동으로 표시되어 개발자가 API를 즉시 파악할 수 있게 함

### Step 2 — API 키 저장소와 검증 의존성
- 간단한 API 키 저장소를 정의함 — 이 데모에서는 단일 키를 가진 Python set일 뿐이며, 프로덕션 환경에서는 데이터베이스나 ID 제공자가 키를 관리할 수 있음
- `verifyAPIKey`라는 의존성 함수를 만듦 — 이 함수는 요청 헤더에서 API 키를 추출하고, 키가 없거나 유효하지 않으면 "invalid or missing API key" 메시지와 함께 403 Forbidden 오류를 발생시키며, 키가 유효하면 그대로 반환해 요청이 진행되도록 함

### Step 3 — 공개 엔드포인트와 보호된 엔드포인트 정의
- **공개(public) 엔드포인트**: 누구나 접근 가능하며 API 키가 필요 없음 — 열려 있음을 확인하는 메시지를 반환함
- **보호된(protected) 엔드포인트**: 유효한 API 키가 필요함 — `verifyAPIKey` 의존성을 붙여 유효한 키가 없는 요청은 자동으로 차단됨. 키가 올바르면 사용된 API 키와 함께 성공 메시지로 응답함

### Step 4 — 서버 실행 및 대화형 문서 확인
```bash
uvicorn main:app --reload --port 8002
```
- Swagger UI(`http://localhost:8002/docs`)를 열면 브라우저에서 직접 엔드포인트를 탐색하고 테스트할 수 있는 대화형 포털을 확인할 수 있음
- ReDoc(`http://localhost:8002/redoc`)을 열면 깔끔한 참조 스타일의 문서 인터페이스를 확인할 수 있음
- 두 포털 모두 자동 생성된 요청·응답 예시와 보호된 엔드포인트를 위한 인증 헤더를 제공해, 개발자가 추가 코드 작성 없이 API를 쉽게 탐색·테스트할 수 있게 함

### Step 5 — curl로 엔드포인트 테스트
- **공개 엔드포인트 테스트**: 요청을 보내면 API 키 없이도 누구나 접근 가능하다는 확인 메시지로 응답함
- **API 키 없이 보호된 엔드포인트 테스트**: API가 즉시 요청을 거부하고 `X-API-Key` 헤더가 누락되어 인증이 필요하다는 오류 메시지를 반환함
- **유효한 API 키로 보호된 엔드포인트 테스트**: API가 요청을 수락하고 사용된 정확한 키와 함께 성공 메시지로 응답함
- API가 유효한 키 없는 요청은 차단하고 올바른 키가 제공되면 접근을 허용하는 방식으로 인증을 강제하는 것을 확인함 — 키 기반 인증이 의도한 대로 정확히 작동함을 확인시켜줌

## 요약
- FastAPI로 공개 엔드포인트와 `verifyAPIKey` 의존성을 사용하는 API 키 기반 보호 엔드포인트를 구현하고, Swagger UI/ReDoc이 자동 생성한 대화형 문서를 개발자 포털로 활용하는 전체 과정을 실습함
- curl로 공개/보호 엔드포인트를 각각 테스트해 키가 없을 때는 403 오류가, 유효한 키가 있을 때는 성공 응답이 반환되는 것을 검증함
