# Demonstration: Setting Up Analytics for an API (API 분석 설정하기 실습 데모)

## 개요
- 요청·엔드포인트·상태 코드·응답 시간 같은 사용량 데이터를 SQLite 데이터베이스에 기록하고 시각화해 API 활동에 대한 통찰을 얻는 5분 15초 분량 실습 데모 영상 — Module 2 "Lesson 2: Monitoring and Analytics"의 일곱 번째 영상

## 내용

### Step 1 — 의존성 설치 및 프로젝트 준비
- 프로젝트 폴더 안에서 FastAPI, uvicorn, sqlite-utils(분석 저장용)를 pip install로 설치함
- `main.py` 파일을 새로 만들고 time, sqlite3, FastAPI를 임포트함

### Step 2 — SQLite 데이터베이스와 로깅 미들웨어 구성
- FastAPI 앱을 만들고 `analytics.db`라는 SQLite 데이터베이스에 연결함
- HTTP 메서드, 경로(path), 상태 코드, 클라이언트 IP, 응답 시간, 타임스탬프 같은 세부 정보를 저장할 `apilogs` 테이블을 생성하고 커밋함 — 로깅을 시작하기 전에 테이블이 준비되도록 함
- 모든 요청에서 실행되는 미들웨어(middleware)를 추가함 — 이 미들웨어는 타이머를 시작하고, 요청을 처리하고, 지연 시간을 계산한 뒤 관련 세부 정보를 담아 `apilogs`에 새 행을 삽입함
- 이 방식 덕분에 개별 엔드포인트를 수정하지 않아도 모든 API 호출이 자동으로 로깅됨

### Step 3 — 엔드포인트 정의
- 간단한 `/items/{item_id}` 엔드포인트를 정의함 — 아이템 ID와 메시지를 반환하며, 이 엔드포인트에 대한 각 호출도 미들웨어에 의해 로깅됨
- `/analytics` 엔드포인트를 만듦 — 이 엔드포인트는 `apilogs` 테이블을 조회해 경로별 히트 수를 세고 평균 응답 시간을 계산함 — 원본 로그를 JSON 형식의 유용한 지표로 변환하는 것

### Step 4 — 서버 실행 및 테스트
```bash
uvicorn main:app --reload --port 8001
```
- 브라우저에서 `http://localhost:8001/items/42`를 열면 `{"item_id": 42, "message": "analytics captured"}` 같은 JSON 응답이 보임
- `http://localhost:8001/analytics`로 이동하면 아직 트래픽이 없으므로 헤더만 보이고 나머지는 비어 있음

### Step 5 — 트래픽 생성 및 분석 확인
```bash
curl http://localhost:8001/items/1
curl http://localhost:8001/items/2
curl http://localhost:8001/items/3
```
- 각 요청이 자동으로 SQLite 데이터베이스에 로깅됨
```bash
curl http://localhost:8001/analytics
```
- 방금 만든 세 개의 아이템 요청이 반영된 것을 확인할 수 있음 — 브라우저의 analytics 페이지를 새로고침해도 동일한 세 엔드포인트가 표시되며, API 경로·총 히트 수·평균 응답 시간을 보여줌 — 엔드포인트 자체에 추가 작업 없이 자동으로 수집된 기본 API 사용량 지표임

### Step 6 — DB Browser for SQLite로 원본 데이터 탐색
```bash
sqlitebrowser analytics.db
```
- 모든 로깅된 요청이 구조화된 테이블에 깔끔하게 저장된 것을 확인할 수 있음
- 최근 요청을 확인하는 쿼리를 실행하면 메서드·경로·상태 코드·지연 시간·타임스탬프 같은 세부 정보와 함께 앞서 보낸 모든 요청을 볼 수 있음
- 트래픽 패턴·응답 시간·오류율을 분석하기 위한 추가 쿼리도 실행할 수 있으며, 필요하면 이 데이터를 CSV 파일로 내보내 Excel·Python·BI 도구에서 추가 분석할 수 있음
- 이를 통해 어떤 엔드포인트가 가장 많이 사용되는지 빠르게 파악하고, 지연 시간 추세를 모니터링하며, 실시간 API 사용량에 대한 실행 가능한 통찰을 얻을 수 있음

## 요약
- FastAPI 미들웨어로 모든 요청을 자동으로 SQLite(`analytics.db`)에 로깅하고, `/analytics` 엔드포인트로 경로별 히트 수·평균 응답 시간을 집계하는 전체 분석 파이프라인을 실습함
- curl로 트래픽을 생성해 분석 결과가 누적되는 것을 확인하고, DB Browser for SQLite로 원본 로그 데이터를 직접 탐색·쿼리하는 방법을 다룸
