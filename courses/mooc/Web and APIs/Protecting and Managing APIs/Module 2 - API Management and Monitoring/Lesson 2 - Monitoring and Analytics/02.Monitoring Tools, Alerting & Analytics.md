# Monitoring Tools, Alerting & Analytics (모니터링 도구, 알림, 분석)

## 개요
- 조직이 API와 시스템을 신뢰할 수 있고 안전하며 고성능으로 유지하는 방법 — 모니터링 도구, 알림 시스템, 분석을 다루는 4분 6초 분량 영상 — Module 2 "Lesson 2: Monitoring and Analytics"의 두 번째 영상

## 내용

### 세 가지 핵심 요소
1. **모니터링 도구(Monitoring tools)**: API와 인프라의 상태를 실시간으로 추적함 — 지속적인 시스템 검진과 같음
2. **알림(Alerting)**: 시스템을 위한 화재 경보와 같음 — 지연 시간 급증이나 요청 실패 같은 문제가 발생하면 즉시 팀에 알림
3. **분석(Analytics)**: 실시간 모니터링을 넘어서 원시 데이터를 실행 가능한 통찰로 바꿔 팀이 성능을 최적화하고 비용을 줄이며 미래의 문제를 예측하도록 도움
- 이 세 가지 능력이 합쳐져 조직이 빠르고 똑똑하게 대응할 수 있게 함

### 왜 필요한가 — 네 가지 이유
1. **신뢰성(Reliability)**: 모니터링은 시스템이 계속 가동되도록 보장해 다운타임을 최소화함
2. **성능(Performance)**: 팀이 속도·효율성·처리량을 측정해 API가 규모에 맞게 제공되도록 보장함
3. **보안(Security)**: 모니터링은 더 큰 위협으로 확대되기 전에 의심스러운 행동이나 비정상적인 패턴을 드러낼 수 있음
4. **의사결정(Decision-making)**: 분석이 데이터 기반 통찰을 제공해 리더들이 확장·비용·개선에 대해 더 현명한 선택을 할 수 있게 함

### 현대 모니터링·알림 시스템의 핵심 기능
1. **실시간 대시보드**: 시스템 전반에서 일어나는 일을 명확한 시각 스냅샷으로 제공함
2. **커스텀 알림**: 임계값을 정의해 팀이 필요할 때만 알림을 받도록 해 알림 피로(alert fatigue)를 방지함
3. **로그·트레이스 통합**: 모니터링을 상세 로그와 연결해 문제를 더 빠르게 해결할 수 있게 함
4. **분석과 리포팅**: 추세·예측·요약을 생성해 운영 데이터를 유용한 비즈니스 인텔리전스로 전환함
- 이 기능들이 함께 작동해 엔지니어와 의사결정자 모두에게 필요한 명확성을 제공함

### 대표적인 도구
- **Prometheus**: 모니터링과 메트릭을 위한 대표적인 오픈소스 솔루션
- **Grafana**: 흔히 Prometheus와 함께 쓰이며 풍부한 시각적 대시보드를 제공함
- **Datadog**: 다양한 환경에 매끄럽게 통합되는 클라우드 네이티브 모니터링·분석 플랫폼
- **New Relic**: 애플리케이션 성능 모니터링(APM)에 널리 사용됨
- **ELK 스택(Elasticsearch, Logstash, Kibana)**: 중앙화된 로깅·분석에 매우 인기 있음
- **Splunk**: 로그 관리와 보안 통찰을 위한 엔터프라이즈급 솔루션
- 각 도구마다 강점이 다르지만, 모두 시스템을 가시적이고 신뢰할 수 있으며 안전하게 유지한다는 같은 목적을 수행함

## 요약
- 모니터링 도구·알림·분석이라는 세 요소가 결합해 신뢰성·성능·보안·의사결정이라는 네 가지 이유로 API 관리에 필수적이며, 실시간 대시보드·커스텀 알림·로그 통합·분석 리포팅이 핵심 기능임
- Prometheus, Grafana, Datadog, New Relic, ELK 스택, Splunk 등 대표적인 도구들을 소개함
