# Reading: Kong API Gateway with Python (Python으로 Kong API 게이트웨이 실습)

## 개요
- Flask로 간단한 Python API를 만들고 Docker로 실행한 Kong 게이트웨이에 등록해 프록시를 거쳐 접근해보는 15분 분량 실습 읽기자료 — Module 2 "Lesson 1: API Gateways"의 다섯 번째이자 마지막 항목

## 내용

### Step 1 — Python API 만들기
- Flask 설치:
```bash
pip install flask
```
- `app.py` 작성:
```python
from flask import Flask, jsonify

app = Flask(__name__)

@app.route("/users")
def users():
    return jsonify({"users": ["Alice", "Bob"]})

if __name__ == "__main__":
    app.run(host="0.0.0.0", port=5000)
```
- API 실행:
```bash
python app.py
```
- `http://localhost:5000/users`로 접근 가능함

### Step 2 — Docker로 Kong 실행
- 간단한 Docker 명령으로 Kong을 시작함:
```bash
docker run -d --name kong \
  -e "KONG_DATABASE=off" \
  -e "KONG_PROXY_ACCESS_LOG=/dev/stdout" \
  -e "KONG_ADMIN_ACCESS_LOG=/dev/stdout" \
  -p 8000:8000 \
  -p 8001:8001 \
  kong:3.4
```
- **Kong Admin API**: `http://localhost:8001`
- **Kong Proxy**: `http://localhost:8000`

### Step 3 — Python API를 Kong에 등록하기
- 서비스(service) 추가:
```bash
curl -i -X POST http://localhost:8001/services/ \
  --data name=python-api \
  --data url=http://host.docker.internal:5000
```
- 라우트(route) 추가:
```bash
curl -i -X POST http://localhost:8001/services/python-api/routes \
  --data 'paths[]=/users'
```

### Step 4 — Kong을 통해 테스트하기
```bash
curl http://localhost:8000/users
```
- 다음과 같이 반환되어야 함:
```json
{"users": ["Alice", "Bob"]}
```
- 이는 클라이언트가 Kong 프록시(포트 8000)를 거쳐 실제 Python API(포트 5000)에 도달했음을 확인해줌 — Kong이 라우트 규칙에 따라 요청을 올바른 백엔드 서비스로 전달한 것임

## 요약
- Flask로 만든 간단한 Python API를 Docker 기반 Kong 게이트웨이의 서비스·라우트로 등록해, 클라이언트가 Kong 프록시를 통해 백엔드 API에 접근하는 전체 흐름을 실습함
- Kong Admin API(8001)로 서비스·라우트를 설정하고, Kong Proxy(8000)로 실제 요청이 라우팅되는 것을 curl로 검증함
