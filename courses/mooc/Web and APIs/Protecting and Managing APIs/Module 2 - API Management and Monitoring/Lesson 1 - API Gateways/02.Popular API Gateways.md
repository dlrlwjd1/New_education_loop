# Popular API Gateways (널리 쓰이는 API 게이트웨이)

## 개요
- 오늘날 널리 사용되는 API 게이트웨이 도구들과 게이트웨이 선택 시 고려할 요소·모범 사례를 다루는 2분 41초 분량 영상 — Module 2 "Lesson 1: API Gateways"의 두 번째 영상

## 내용

### 대표적인 API 게이트웨이 도구
- API 게이트웨이는 어디에나 존재하며, 그중 몇몇이 시장을 주도함
- **Kong**: 유연성과 오픈소스 지원으로 잘 알려짐
- **APIGEE(Google)**: 엔터프라이즈급 관리와 강력한 분석 기능을 제공함
- **NGINX**: 고성능 라우팅과 로드 밸런싱에 널리 사용됨
- **Tyk**: 경량 설계와 손쉬운 통합이 강점임
- 각 게이트웨이는 저마다 고유하지만, 확장성·보안·개발자 친화적 기능을 제공해 API를 신뢰할 수 있게 유지한다는 공통 목적을 공유함

### 게이트웨이 비교 시 고려할 핵심 요소
1. **배포 모델(Deployment model)**: 온프레미스, 클라우드, 하이브리드 여부
2. **성능(Performance)**: 트래픽이 많을 때 속도와 응답성에 영향을 미침
3. **보안 기능(Security features)**: 내장 인증, 속도 제한, 모니터링 등
4. **에코시스템과 통합(Ecosystem and integrations)**: 다른 도구·플랫폼과의 연동성
5. **가격(Pricing)**: 기업 규모별 비용 효율성에 영향을 미침
- 이 요소들을 염두에 두면 필요에 맞는 게이트웨이를 더 쉽게 선택할 수 있음

### 선택 시 과제와 모범 사례
- **단점**: 일부 게이트웨이는 종속성을 만들어 나중에 전환하기 어렵게 하고, 다른 게이트웨이는 시스템 복잡성을 높이거나 최적화되지 않으면 성능 지연을 유발할 수 있음
- **모범 사례**: 항상 클라우드 전략과 정렬시키고, 향후 성장을 처리할 수 있는지 확장성 점검을 수행하며, 과도한 지출을 피하기 위한 비용 유연성을 확보함
- 이러한 단점과 모범 사례를 균형 있게 고려하면 조직이 더 현명한 게이트웨이 결정을 내리는 데 도움이 됨

## 요약
- Kong, APIGEE, NGINX, Tyk 등 대표적인 API 게이트웨이 도구를 소개하고, 배포 모델·성능·보안·에코시스템·가격이라는 비교 기준과 종속성·복잡성 같은 단점, 클라우드 전략 정렬·확장성 점검·비용 유연성 같은 모범 사례를 정리함
