# Dialogue: The Case of the Compromised API Key: Can You Contain It? (침해된 API 키 사건: 봉쇄할 수 있는가?)

## 개요
- 핀테크 스타트업(FinServ Tech)에서 발생한 API 보안 사고에 대응하는 시나리오 기반 대화형 실습(AI 코치와의 롤플레이) — Module 3 "Course Wrap-Up and Assessment"의 두 번째 항목, 10분 분량
- 이 항목은 학습자가 API 보안 엔지니어 역할을 맡아 실시간으로 의사결정을 내리며 진행하는 개인 실습형 대화이므로, AI가 학습자를 대신해 진행하지 않고 다루는 주제와 목적만 정리함

## 내용

### 다루는 주제
- 시나리오 설정: API 보안 엔지니어로서 비정상적인 트래픽 급증과 수천 건의 무단 요청을 발견한 상황에서 시작함
- 대화를 통해 다음을 단계적으로 다룸:
  1. 즉각적인 위협과 취약점 식별하기
  2. 진행 중인 공격을 완화하기 위한 보안 조치 구현하기
  3. 장기적 보호를 위한 인증·인가 강화하기
  4. 컴플라이언스 확보와 이해관계자와의 효과적인 소통

### 활용 방식
- "Start Dialogue"를 누르면 AI 코치가 시나리오를 제시하고, 학습자가 각 단계에서 어떤 조치를 취할지 직접 입력하며 대화를 이어가는 방식임 — 막히면 "I'm stuck" 버튼으로 힌트를 받을 수 있음
- 정답이 정해진 퀴즈가 아니라 Module 1~2에서 배운 인증/인가·모니터링/알림·거버넌스 개념을 실제 사고 대응 맥락에 적용해보는 판단력 훈련에 가까움

## 요약
- 이 Dialogue는 API 키 침해 사고에 대응하는 과정을 롤플레이로 연습하는 개인 실습 도구로, 즉각 대응 → 보안 조치 → 인증/인가 강화 → 컴플라이언스/소통이라는 단계를 다룸
- 실제 대화 진행은 학습자 본인의 판단이 필요한 개인 실습이므로 AI가 대신 완료하지 않음
