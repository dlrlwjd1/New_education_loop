# Audio Data Capture

## 개요

키워드 스팟팅(음성 인식) 데이터셋을 만드는 실습. **Google Speech Commands** 공개 데이터셋을 기반으로, 나만의 커스텀 키워드를 추가하고, 배경 소음을 섞어 데이터를 증강(augmentation)한 뒤, Google Colab 큐레이션 스크립트로 자동 가공해 Edge Impulse에 업로드한다.

## 내용

### 시작점 — Google Speech Commands 데이터셋

- 수십 개의 단어, 각각 수천 개의 샘플이 있는 공개 데이터셋. **서드파티 데이터셋으로 시작**하면 학습 자체를 익히거나, 내 데이터셋을 보강하는 데 유용하다.
- 여기에 배경 소음 샘플 6개도 함께 제공된다(원하면 직접 녹음한 소음 — 교통 소음, 붐비는 사무실 등 — 을 써도 된다).

### 3가지 클래스로 큐레이션

마이크로컨트롤러에는 모든 단어를 분류할 신경망을 담을 공간이 없다 — 그래서 3개 카테고리로 단순화한다.

1. **noise(소음)** — 배경 소음 클립.
2. **unknown(미상)** — 목표 키워드가 아닌 모든 단어.
3. **키워드(들)** — 실제로 감지하고 싶은 단어(들). 보통 1개지만 이 강의는 **2개**로 시연(3~4개까지도 Nano 33 BLE Sense에서 동작 확인했다고 언급).

> Alexa급 신뢰도는 기대하지 말라고 미리 안내 — 데모 수준의 정확도.

### 데이터 증강(Data Augmentation) — 배경 소음 섞기

- 한 단어 샘플에 **서로 다른 배경 소음을 무작위로 섞으면**, 배경 소음 6개가 있으면 **원본 샘플 1개에서 최대 6개의 새로운 샘플**을 만들어낼 수 있다 — 실제 환경에서 수집한 것만큼 좋지는 않지만 데이터가 부족할 때 유용.
- 다른 증강 방법도 가능: 단어가 프레임 안에서 등장하는 위치를 바꾸기, 음량 바꾸기, 피치 바꾸기 등.
- Edge Impulse에도 배경 소음을 자동으로 섞어주는 도구가 있지만, 이 강의는 **어떤 소음을 어떻게 섞을지 더 세밀하게 제어**하기 위해 수동(스크립트) 방식을 보여준다.

### 샘플 규격 통일 — 샘플레이트·비트깊이·길이

- 모든 샘플은 **정확히 같은 샘플링 레이트·비트 깊이·길이**여야 한다. 예: 16kHz·16비트·1초 = 정확히 16,000개의 16비트 샘플. 이게 안 맞으면 특징 차원이 달라져 신경망에 제대로 안 들어간다.
- 큐레이션 스크립트가 자동으로 맞춰준다: **너무 길면 1초 이후를 잘라내고, 너무 짧으면 0으로 패딩**, 샘플레이트·비트 깊이도 자동 변환. (스크립트가 못 잡아도 Edge Impulse가 업로드 시 다시 한번 맞춰준다.)

### Google Colab에서 큐레이션 스크립트 실행

- 강사의 GitHub(`github.com/ShawnHymel/ei-keyword-spotting`)에서 스크립트를 Colab으로 연다(무료 Gmail 계정 필요). **Colab은 단순 Jupyter가 아니라 백그라운드에서 리눅스 VM이 돈다** — 사실상 완전한 컴퓨터처럼 쓸 수 있다.
- Shift+Enter로 셀을 순서대로 실행:
  1. npm 설치.
  2. `soundfile` 패키지 + Edge Impulse CLI 도구 설치.
  3. 설정: Google Speech Commands **v0.02** 다운로드, 클래스당 목표 샘플 수(예: 1,500개), 샘플 규격(1초·16kHz·16비트), 음성/소음 상대 음량 조절 가능.
  4. 데이터셋 다운로드(수 분 소요) → 배경 소음 폴더를 별도로 분리.
  5. (선택) 자신의 GitHub 저장소에서 커스텀 데이터셋을 추가로 가져올 수도 있음.

### 커스텀 키워드 직접 녹음하기

1. 녹음 앱으로 원하는 단어(예: "Hello")를 **최소 50번**, 발화 사이 간격을 충분히 두고 녹음. 강사는 다양한 목소리·억양·나이·성별을 섞어야 편향이 적다고 강조하지만, 처음엔 본인 목소리만으로도 충분(다만 다른 사람 목소리엔 잘 안 맞을 수 있다는 한계는 인지).
2. Audacity 같은 편집기로 **발화 하나씩 정확히 1초 근처로 선택**해 개별 WAV 파일(**16비트 PCM**)로 내보내기. 단어가 프레임 내 다른 위치(예: 항상 0.5초가 아니라 다양한 위치)에 오도록 다양하게 자르면 더 강건한 모델이 된다.
3. Colab에서 `content` 디렉터리에 `custom_keywords/{라벨명}` 폴더 생성(**폴더명이 곧 클래스 라벨**이며, 나중에 지정할 target 이름과 일치해야 함) → WAV 파일들을 업로드.
4. 커스텀 데이터셋 경로를 스크립트의 `CUSTOM_DATASET_PATH` 변수에 붙여넣기.

### Edge Impulse 연결과 실행

1. Edge Impulse에서 새 프로젝트 생성 → Keys 탭에서 **API 키** 복사 → Colab의 `EI_API_KEY` 변수에 붙여넣기.
2. `TARGETS` 변수에 원하는 키워드를 쉼표로 구분해 입력(Google 데이터셋 또는 커스텀 데이터셋에 실제로 존재하는 단어만 가능). 예: `Hello, stop`.
   - **키워드 수가 늘수록 신경망 출력 노드도 늘어나야 하고, 비슷한 발음을 구분하려면 모델 크기·형태도 조정이 필요할 수 있다** — 너무 커지면 타깃 보드에서 못 돌 수 있으니 키워드 수를 늘릴 땐 이 점을 염두에 둔다.
3. 큐레이션 스크립트 셀 실행(20~30분 소요) — 배경 소음 믹싱, 규격 통일 등을 전부 수행.
4. 완료 후 `content/keywords_curated` 폴더에 실제 업로드용 WAV 파일들이 생성된다 — 다운로드해서 재생해 확인 가능.
5. 마지막 셀이 **Edge Impulse CLI**로 이 폴더 전체를 업로드 — 이 과정에서 **학습/테스트 세트로 자동 분할**되고, **각 샘플의 라벨은 소속 폴더명에서 자동으로 추론**된다.
6. Data Acquisition에서 확인: 4개 클래스 기준 학습 세트에 약 **4,800개**, 테스트 세트에 약 **1,200개** 샘플이 클래스별로 고르게 분포되어 있어야 한다.

## 예시

`custom_keywords/Hello/`라는 폴더에 50개의 "Hello" WAV 파일을 넣고, `TARGETS = "Hello, stop"`으로 스크립트를 돌리면 → noise / unknown / Hello / stop 4개 클래스로 자동 구성된 균형 잡힌 데이터셋이 Edge Impulse 프로젝트에 업로드된다.

## 요약

- 키워드 스팟팅 데이터셋은 **noise / unknown / 키워드(들)** 3(+)개 클래스로 구성하며, 마이크로컨트롤러의 한계 때문에 "모든 단어"가 아니라 소수의 목표 단어만 다룬다.
- **배경 소음 믹싱**은 적은 원본 샘플을 여러 배로 늘리는 실용적인 데이터 증강 기법이다.
- 모든 샘플은 **샘플레이트·비트깊이·길이가 통일**되어야 하며, 큐레이션 스크립트와 Edge Impulse가 이를 자동으로 맞춰준다.
- Google Colab + 커스텀 녹음 + 큐레이션 스크립트 + Edge Impulse CLI 업로드로 이어지는 이 파이프라인은, 직접 마이크를 붙잡고 하나하나 Edge Impulse UI로 녹음하는 것보다 훨씬 빠르게 대량의 균형 잡힌 데이터셋을 만드는 방법이다.
