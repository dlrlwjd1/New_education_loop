# Conclusion

## 개요

코스 전체를 마무리하며 다음 학습 경로와 커뮤니티 자원을 안내한다.

## 내용

### 더 깊이 배우고 싶다면

- **머신러닝 기초를 처음부터**: MOOC의 Andrew Ng 머신러닝 강좌 추천 — 행렬대수 복습부터 시작해, 코스 끝에서는 신경망 학습·추론 알고리즘을 직접 처음부터(from scratch) 작성하게 된다. 같은 강사의 **CNN 등 딥러닝 심화 강좌**도 추천.
- **신경망을 다룰 고수준 프레임워크**: **Keras**를 배울 것을 권장. Edge Impulse 자체가 신경망을 만드는 인터페이스로 Keras를 쓰기 때문에(전문가 뷰에서 Keras 코드로 직접 신경망을 수정 가능, Module 3 "Modifying the Neural Network" 강의에서 잠깐 언급됨), Keras를 알면 Edge Impulse를 더 깊이 활용할 수 있다.

### 커뮤니티 자원

- **Edge Impulse 포럼**(`forum.edgeimpulse.com`) — 도구 사용 중 막히면 참고.
- **tinyml.org** — 임베디드 머신러닝 실무자·연구자 커뮤니티이자 재단(Foundation) 이름. **한 달에 약 2번 온라인 세미나**를 열고, 온/오프라인 컨퍼런스에서 연구·제품 발표도 진행 — 임베디드 ML의 최신 동향을 따라가기 좋은 곳.

### 이 코스에서 다루지 않은 것 — AutoML

- Edge Impulse는 데이터 수집·특징 추출·모델 학습·배포 **전체 과정을 스크립트로 자동화할 수 있는 API**를 제공한다.
- 수백 개의 센서에서 데이터를 모아 모델을 계속 업데이트하고 재배포해야 하는 상황이라면, 이런 API(AutoML)가 매우 중요해진다 — 이 코스는 다루지 않았지만 실제 제품화 단계에서는 필수적으로 고려할 부분.

## 요약

- 임베디드 머신러닝은 아직 비교적 새로운 분야이며, 이제 막 흥미로운 응용들이 나오기 시작하는 단계다.
- 다음 학습 경로 제안: **머신러닝 수학 기초(Andrew Ng 강좌) → Keras 학습 → tinyml.org 커뮤니티 참여**, 그리고 스케일이 커지면 **Edge Impulse API를 이용한 AutoML**까지 고려.
