# Introduction to Convolutional Neural Networks

## 개요

MFCC가 사실상 이미지(2D 행렬)이므로, 이미지 분류의 표준 도구인 **CNN(합성곱 신경망)** 을 키워드 스팟팅에 적용한다. 합성곱(convolution)·맥스풀링(max pooling)·드롭아웃(dropout) 개념과, Edge Impulse 기본 CNN 구조(1D convolution 버전)를 실습으로 확인한다.

## 내용

### CNN이란

- **CNN(Convolutional Neural Network)**: 입력 데이터에서 **특징/패턴을 자동으로 찾아내는** 일련의 연산으로 구성된 신경망. 이미지 분석·분류에 특히 강하다.
- 핵심은 **합성곱 층(convolution layer)** — 안에 있는 **필터(filter/kernel)** 의 파라미터도 일반 신경망 노드처럼 **역전파로 학습**된다.
- 필터는 이미지에서 다양한 특징을 자동으로 뽑아낸다: 뚜렷한 원형 같은 **넓은 형태**, 털·잔디·나무결 같은 **반복 패턴**, 두 물체의 경계 같은 **엣지(edge detection)**.
- **층을 쌓을수록 더 복잡한 특징을 잡아낸다** — 앞쪽 층은 단순한 모양, 뒤쪽 층은 귀·눈·코 같은 복합 형태, 충분히 쌓이면 얼굴·사람·동물·자동차 전체를 식별할 수도 있다.

### 2D 합성곱(Convolution)의 동작 원리

- 흑백 이미지의 각 픽셀은 숫자 하나(보통 0~1로 정규화된 부동소수점).
- **필터(커널)**: 픽셀 값과 곱해질 파라미터로 이루어진 작은 행렬(예: 3×3). 커널을 이미지 위에 올려 **대응하는 픽셀끼리 곱한 뒤 다 더하는(내적, dot product)** 연산으로 출력 이미지의 픽셀 하나를 만든다. 커널을 옆으로 밀며(슬라이딩) 전체 이미지에 반복 — 이 과정 전체를 **합성곱**이라 부른다.
- **커널 크기는 하이퍼파라미터**로, 바꿔가며 성능을 실험해볼 수 있다.
- 합성곱 출력에는 보통 **비선형 활성화 함수**(주로 ReLU — 음수를 전부 0으로 깎아버림)를 적용해 특징을 더 두드러지게 만든다.

### 1D 합성곱 — MFCC에 적합한 이유

- 2D 합성곱은 이미지 전체를 작은 커널로 훑어야 해서 시간이 오래 걸린다. **한 차원의 크기를 이미지와 같게 만들면** 1차원 합성곱이 된다.
- MFCC는 **13(계수) × 49(시간 프레임)** 크기의 2D 행렬이지만, **시간축을 따라 정보가 어떻게 변하는지가 중요**하므로 필터를 **가로 방향(옆으로)** 으로만 슬라이딩시킨다 — 세로(13픽셀 전체)는 필터 폭과 같게 고정.
- 즉 필터 폭 = 13(고정), 길이(Edge Impulse 기본값) = 3. 이 필터가 시간축을 따라 슬라이딩하며 내적을 계산 → **1×49 배열**을 출력.

### 맥스 풀링(Max Pooling) — 크기 줄이기

- 합성곱 출력(필터링된 이미지)에 **윈도우**를 씌워, 그 안의 값 중 **최댓값 하나만 남기고** 나머지는 버린다(평균을 쓰면 average pooling).
- 윈도우를 옆으로 밀며(hop) 반복 — **겹치는 정도, hop 크기**도 조정 가능한 하이퍼파라미터. hop이 클수록 압축은 많이 되지만 정보 손실도 커진다 — 실험이 필요하다.
- MFCC의 1D 출력이라 **1D 맥스풀링**을 쓴다. Edge Impulse 기본값은 **윈도우 1×2, hop 2** — 배열 크기를 절반으로 줄인다. 홀수 길이 배열은 **0으로 패딩**해서 짝수로 맞춘 뒤 처리(예: 49 → 25).
- 보통 **합성곱 층마다 그 뒤에 맥스풀링 층**을 붙여 크기를 계속 줄여나간다.

### 전체 구조 예시 (Edge Impulse 기본값)

- **1층 합성곱**: 필터 8개 → 출력 8개의 1×49 배열 → 맥스풀링 → 8개의 1×25.
- **2층 합성곱**: 필터 16개(이전 8개 출력이 각 16개 필터에 모두 복사되어 들어감) → 맥스풀링 → 16개의 **1×13** 배열.
- 이미지가 크고 층이 많을수록 저장·연산량이 급격히 늘어난다는 점(8장 → 128장 등)을 강사가 명시적으로 경고 — 필터링+맥스풀링이 이 부담을 줄여주는 이유.

### 분류기(Classifier) — Flatten + Dense + Softmax

- CNN의 마지막 부분은 거의 항상 **단순한 완전연결(dense) 신경망**이다.
- 분류기는 1차원 입력을 기대하므로, 16개의 1×13 배열을 **일렬로 이어 붙여(flatten)** **1×208**(16×13) 배열로 만든다.
- Edge Impulse 기본 분류기는 **노드 4개**(클래스 수만큼) — 208개 입력을 각 노드가 가중치 곱+편향 합산 → **소프트맥스**로 클래스 확률 변환.
- 학습(역전파)은 **합성곱 필터 파라미터와 분류기의 가중치·편향을 동시에** 갱신한다.

### 드롭아웃(Dropout) — 처음 소개

- 층과 층 사이에 넣어 **과적합을 줄이는** 기법. 학습 중 이전 층 출력의 **일정 비율(예: 25%)을 무작위로 완전히 무시**한다.
- 남은 노드들이 더 많은 책임을 떠안게 되고, 매 샘플의 순전파마다 드롭되는 노드가 무작위로 바뀌어 학습 과정에 "노이즈"가 섞인다 — 이게 오히려 과적합 방지에 도움이 된다.
- **학습 중에만 적용되고, 배포(추론) 시에는 적용되지 않는다.** 과적합 징후가 보이면 정규화와 마찬가지로 시도해볼 수 있는 기법.

### Edge Impulse 실습

1. **Neural Network Classifier** 페이지에서 구조 확인(위에서 설명한 대로) — 필요하면 Edit로 층 형태·크기 변경 가능하나 기본값으로 충분.
2. **Start Training** 클릭.
3. 학습 후 **손실/정확도, 혼동 행렬**로 과소·과대적합 여부 확인(이전 강의에서 배운 방법 그대로).
4. **Model Testing**에서 테스트 세트 전체를 채점 — **90~95% 정도면 좋은 편**, 이 데모 수준이면 **85% 정도도 쓸 만하지만, 실제 제품화 전엔 추가 튜닝이 필요**할 수 있다고 언급.

## 예시

MFCC(13×49) → 합성곱+맥스풀링 2회 반복(8개→16개 필터, 크기는 49→25→13으로 축소) → flatten(16×13=208) → 4노드 분류기 → 소프트맥스 → 클래스 확률. 이 전체가 하나의 CNN이며, Edge Impulse가 기본값으로 이미 이렇게 구성해준다.

## 요약

- CNN은 **합성곱(특징 자동 추출) + 맥스풀링(크기 축소) 반복 후, 마지막에 완전연결 분류기**로 마무리되는 구조다.
- MFCC처럼 "시간축을 따라 의미가 있는" 2D 데이터에는 **1D 합성곱**(한쪽 축을 필터 폭과 맞춤)이 자연스럽다.
- **드롭아웃**은 학습 중 일부 출력을 무작위로 끄는 과적합 방지 기법으로, 추론 시에는 작동하지 않는다.
- 이 모든 게 Edge Impulse UI에서 기본값만으로도 합리적인 성능(85% 이상)을 내도록 세팅되어 있고, 필요하면 필터 수·커널 크기·풀링 파라미터·드롭아웃 비율을 직접 조정해 실험할 수 있다.
