# Audio Feature Extraction

## 개요

오디오 raw 데이터를 그대로 쓰면 안 되는 이유(음량·발화 위치 같은 무의미한 특징을 학습해버림)부터 시작해, **스펙트로그램 → 나이퀴스트 정리·에일리어싱 → MFCC(Mel 주파수 켑스트럼 계수)** 로 이어지는 오디오 특징 추출의 전체 이론과, Edge Impulse에서의 실제 설정을 다룬다. 이 코스에서 수학적으로 가장 깊은 강의 중 하나다.

## 내용

### 왜 raw 오디오를 그대로 쓰면 안 되는가

가속도계 예제와 같은 이유 — 모델이 **음량이나 발화가 프레임 내 어디서 시작하는지** 같은, 실제로 중요하지 않은 특징에 꽂힐 수 있다. **사람이 소리를 인지하는 방식을 흉내 낸 특징**을 뽑아야 한다.

### 푸리에 변환 → 스펙트로그램

- 1800년대 프랑스 수학자 **조제프 푸리에**: 반복되는 신호는 서로 다른 주파수의 사인·코사인파의 무한합으로 표현될 수 있다 — 이것이 푸리에 변환의 시작.
- 샘플 전체를 한 번에 FFT하면 전체적인 주파수 경향은 보이지만 **시간에 따른 변화 정보를 잃는다.**
- 그래서 **작은 시간 윈도우로 잘라 FFT**를 하고, 윈도우를 조금씩(겹치게) 밀면서 반복 → 각 윈도우의 FFT 결과를 열(column)로 쌓으면 **스펙트로그램**(주파수=y축, 시간=x축, 진폭=z축/색상)이 만들어진다.
- 사람 목소리는 대략 **300~3400Hz**(보통 300~3000Hz로 일반화) 범위.
- 스펙트로그램은 사실상 **이미지**이므로, 고양이/개 이미지를 구분하는 것과 같은 이미지 분류 기법을 소리 구분에 그대로 쓸 수 있다. **유리 파손·노크·교통 소음** 같은 비음성 소리나 동물 소리엔 스펙트로그램 자체로도 충분히 좋은 특징이 되지만, **사람 음성에는 한 단계 더 필요하다**(→ MFCC).

### 나이퀴스트-섀넌 표본화 정리와 에일리어싱

- **정리**: 원래 연속 신호를 완전히 복원하려면, **신호에 포함된 최고 주파수의 2배보다 높은 주파수로 샘플링**해야 한다.
- FFT/DFT는 **샘플링 레이트의 절반(나이퀴스트 주파수)까지만** 정확히 보여준다. 샘플링 레이트가 16kHz라면 나이퀴스트 주파수는 **8kHz**.
- 그 이상의 주파수 성분(예: 배경의 10kHz 새소리, 목소리의 배음)이 있으면, **그 성분이 접혀서(mirror) 원래 FFT에 잘못 섞여 들어간다** — 이것이 **에일리어싱(aliasing)**. 예: 10kHz 성분이 6kHz 자리에 나타나는 식으로 왜곡된다.
- **해결책 — 저역통과 필터(anti-aliasing filter)**: 나이퀴스트 주파수 근처를 차단 주파수로 잡아, 그 이상 주파수를 미리 걸러낸다. 이상적인 필터는 차단 주파수 아래는 1을 곱하고 위는 0을 곱하는 셈.
- **아날로그-디지털 변환(ADC) 이전에** 아날로그 필터로 거르는 것이 정석(일부 마이크는 이 필터가 내장돼 있음). **샘플링 후에** 디지털 필터를 걸면, 이미 에일리어싱이 필터의 통과대역(passband) 안에 들어와 있을 경우 소용이 없을 수 있다.
- 핵심 실무 원칙: **녹음하려는 소리의 주파수가 항상 샘플링 레이트의 절반보다 낮아야 한다.**

### MFCC(Mel Frequency Cepstral Coefficients) — 사람 청각을 흉내 낸 특징

사람의 음성 인식을 위해 귀가 소리를 인지하는 방식을 흉내 낸 특징. 계산 순서:

1. 윈도우 슬라이스에 **FFT** 적용(스펙트로그램과 동일한 시작점). Edge Impulse는 음성 인식에 불필요한 **300Hz 이하는 미리 필터링**.
2. **Mel 스케일의 삼각형 필터 뱅크**를 여러 개(보통 20개 이상, 강의 예시는 8개) 만든다. 1kHz 이하는 균등한 간격·너비, **1kHz 이상은 점점 넓어지고 로그 스케일로 배치** — 달팽이관(cochlea)이 주파수를 비선형적으로 나누는 방식을 흉내 낸 것.
3. 각 필터와 FFT를 곱한 뒤 **곡선 아래 면적(에너지)** 을 계산해 배열로 저장.
4. 각 에너지 값에 **로그**를 취한다 — 사람은 소리 크기를 **선형이 아니라 로그 스케일**로 인지하기 때문.
5. 이 로그 에너지 값들에 **DCT(이산 코사인 변환)** 를 적용 — 필터들이 서로 겹쳐 있어 생기는 상관관계를 없애고(decorrelate) 정보를 압축한다. 이 DCT 출력이 바로 **MFCC**.
   - 입력 필터 개수만큼 MFCC가 나온다(예: 32개 필터 → 32개 MFCC).
   - **낮은 차수의 MFCC = 신호의 전체적인 형태**, **높은 차수 = 빠르게 변하는 세부 형태**. 음성 인식에서는 **전체적인 형태만 중요**해서, 보통 20~30개 중 **앞의 12~13개만 쓰고 나머지는 버린다.**

### 전체 특징 세트 구성 — MFCC를 여러 번 반복

- 한 윈도우(=Edge Impulse에서 "프레임"이라고도 부름)에서 MFCC를 계산 → 윈도우를 겹치게 밀며 반복 → 이 프로젝트 기준 **13개 MFCC × 49개 윈도우 = 637차원**. 이것도 스펙트로그램처럼 이미지 형태라, 이미지 분류용 신경망을 그대로 응용할 수 있다.
- "hello"와 "stop"의 MFCC를 나란히 놓고 보면 사람 눈에도 미세한 차이가 보이고, 컴퓨터는 이런 차이를 훨씬 쉽게 잡아낸다.

### Edge Impulse 설정 실습

1. **Impulse Design**: 윈도우 크기는 샘플 길이와 같은 **1,000ms** 유지. Processing block으로 **MFCC**(스펙트로그램 블록도 추천되지만 음성이라 MFCC 선택) 추가, Learning block으로 **Neural Network** 추가(참고: MFCC가 이미지처럼 보여도 **전이학습은 쓰지 않는다**) → Save Impulse.
2. **MFCC 페이지 설정**(기본값): 계수 개수 **13개**, 프레임(윈도우) 크기 **20ms**, 기본은 겹침 없음(조정 가능), **300Hz 이하 필터링**, high frequency는 0으로 설정되어 있지만 이는 곧 **나이퀴스트 주파수(8kHz)** 를 의미. **프리엠퍼시스(pre-emphasis) 필터**로 고주파를 미리 증폭해 음성 인식 성능을 돕는다. 지금은 기본값 유지, 나중에 바꿔가며 실험해볼 것을 권장.
3. **Generate Features** 클릭 → 몇 분 대기.
4. **Feature Explorer**: 637차원은 시각화가 불가능하므로, Edge Impulse가 **UMAP** 알고리즘(비슷한 걸 가까이 모으는 군집화 유사 기법)으로 3차원으로 축소해 보여준다. 비슷한 MFCC 스펙트로그램은 가까이, 다른 것은 멀리 찍힌다 — **여기서 군집이 잘 분리되어 보이면 모델도 잘 구분할 가능성이 높다**는 신호.

## 예시

10kHz의 배경 새소리가 16kHz로 샘플링된 신호에 섞여 있으면 FFT에서 6kHz 성분처럼 잘못 나타난다 — 저역통과 필터가 없으면 이 에일리어싱이 그대로 특징에 섞여 모델을 혼란스럽게 만들 수 있다.

## 요약

- 오디오 특징 추출의 계보: **FFT(주파수 분해) → 스펙트로그램(시간+주파수) → MFCC(사람 청각 모사, Mel 필터+로그+DCT)**.
- **나이퀴스트 주파수(샘플링 레이트의 절반)를 넘는 성분은 에일리어싱을 일으킨다** — 녹음 전에 저역통과 필터로 미리 걸러야 사후에 고칠 수 없는 문제를 막는다.
- MFCC는 낮은 차수만 남기고 높은 차수는 버려 "전체적인 소리 형태"만 압축해서 담는다.
- Edge Impulse의 MFCC 블록이 이 모든 계산을 자동화해주고, UMAP으로 고차원 특징을 3D로 시각화해 클래스 분리 여부를 미리 눈으로 확인할 수 있게 해준다.
