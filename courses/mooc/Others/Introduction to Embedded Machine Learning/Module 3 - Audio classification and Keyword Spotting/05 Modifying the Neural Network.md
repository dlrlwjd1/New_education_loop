# Modifying the Neural Network

## 개요

지금까지는 Edge Impulse 기본값으로만 학습했다. 이 강의는 **에폭 수·학습률·데이터 증강·모델 구조**를 실제로 조정하며 성능을 튜닝하는 방법과, 그 과정에서 만나는 실전 함정들(지역 최소점, 손실 0의 함정, 학습률 문제)을 다룬다.

## 내용

### 학습 사이클(에폭) 조정

- 일반적으로 **에폭이 많을수록 모델이 데이터에 맞출 시간이 늘어난다.** 복잡한 모델(예: 이미지 객체 탐지)은 손실이 떨어지기 시작하는 데만 수천 에폭이 걸리기도 한다.
- **좋은 학습 곡선의 모습**: 손실이 떨어지다가 **일정 구간 동안 평평하게 수렴**한다. 강사는 개인적으로 전체 에폭의 **10~20% 구간 정도는 손실이 비슷한 값에 머물러야** "학습이 끝났다"고 판단한다.
- **주의**: "학습이 끝났다"가 "좋은 모델이다"를 의미하진 않는다.

### 지역 최소점(Local Minimum)의 함정

- 손실이 수렴한 것처럼 보여도, 정확도가 형편없다면 **전역 최소점(global minimum)이 아니라 지역 최소점에 갇혔을 가능성**이 있다.
- 대부분의 모델은 무작위 초기값에서 시작해 반복적으로 손실을 줄여가므로, 차원이 많고 모델이 복잡할수록 전역 최소점을 보장하기 어렵다.
- 해결책: **다른 무작위 초기값으로 재학습**해보거나, **더 오래 학습**시켜서 빠져나오는지 확인. 그래도 안 되면 데이터가 부족하거나 모델이 과소적합인 것일 수 있다 — 데이터를 더 모으거나 모델을 조정해야 한다.

### "손실 0"을 오히려 의심해야 하는 이유

- 학습 손실이 완벽(0)에 가깝다면 **나이브 분류기이거나 과적합**일 수 있다 — 반드시 **혼동 행렬**로 확인하고, **학습 손실 vs 검증/테스트 손실**을 비교한다.
- 검증 손실이 학습 손실을 잘 따라가다가 어느 순간부터 나빠지기 시작하면 과적합 신호 — 데이터 보강·정규화 등을 다 시도해봤다면 **조기 종료(early stopping)** 로 검증 손실이 가장 낮았던 시점의 모델을 채택한다. **Edge Impulse는 이걸 자동으로 해준다.**
- 임베디드 응용에서는 보통 **100 에폭 정도가 무난한 시작점**(단순한 모델 기준).

### 학습률(Learning Rate)

- 매 스텝마다 파라미터가 얼마나 크게 바뀌는지를 결정.
- **너무 낮으면**: 파라미터가 충분히 빠르게 갱신되지 않아 손실 수렴에 오래 걸리고, 시간을 낭비한다. (역설적으로 너무 낮은 학습률도 과적합을 유발할 수 있다고 언급.)
- **적절하면**: 손실이 적당한 시간 안에 떨어지고 수렴한다.
- **너무 높으면**: 파라미터가 목표를 지나쳐(overshoot) 갱신되어, **손실 그래프가 들쭉날쭉해지거나 발산(증가)** 한다 — 이런 그래프가 보이면 학습률을 낮춰야 한다.
- **모멘텀(momentum)·어닐링(annealing)** 같은 기법으로 처음엔 높은 학습률로 빠르게 학습하다가 최적점에 가까워질수록 학습률을 낮추는 방식도 있다(이 데모는 고정 학습률 **0.005** 사용).

### Minimum Confidence Rating

검증/테스트 시 **이 임계값보다 낮은 확신도의 예측은 카운트하지 않는** 용도 — 모델이 확신을 가지고 예측할 때 실제로 맞히는지를 검증하는 데 도움.

### 데이터 증강(Edge Impulse 내장 기능)

- 일부 모델에서 사용 가능 — 사운드 샘플에 **컴퓨터가 생성한 노이즈**를 추가(무작위 노이즈, 특정 시간/주파수 구간 마스킹, 시간 구간 스트레칭 등).
- 과적합을 줄이고 더 강건한 모델을 만드는 데 도움이 될 수 있다. 이 데모는 이미 직접 배경 소음을 섞어놨으므로 꺼둔 채 진행하지만, 자유롭게 켜서 실험해보라고 권장.

### 모델 아키텍처 수정 — "예술과 약간의 마법"

- 무한한 설계 가능성이 있어 어렵게 느껴질 수 있다 — **현실적인 접근은 이미 검증된 아키텍처에서 시작해 조금씩 바꿔보는 것.**
- 자기 응용 분야를 검색해 논문·사례를 찾아보고, 비슷한 문제를 푼 아키텍처를 출발점으로 삼는다.
- **예시 아키텍처(Keras, 2D CNN, 숫자 이미지 분류 가정)**: Conv(25 필터, 5×5, ReLU) → MaxPool(2×2) → Conv(50 필터, 5×5) → MaxPool → **배치 정규화(batch normalization, 출력 평균을 0·표준편차를 1에 가깝게 유지)** → Conv(70 필터, 3×3) → MaxPool → 정규화 → Flatten → Dense(100, ReLU) ×2 → Dense(10, 클래스 수) → Softmax. (참고: Edge Impulse는 현재 배치 정규화 레이어를 직접 추가하는 옵션은 없다고 언급.)
- Edge Impulse는 오디오 데이터임을 인식해 **이미 음성에 잘 맞는 기본 CNN**을 제공하지만, 필요하면 다음을 직접 조정할 수 있다:
  - 합성곱 층의 **필터 수·커널 크기** 수정.
  - 맥스풀링 앞에 **합성곱 층을 더 추가**.
  - **드롭아웃 비율** 조정(과적합 완화 실험).
  - 층 순서 재배치, **Dense 층 추가**(새 층의 노드 수는 대개 "정답에 가까운 값보다 많이" 시작 — 예: 최종 4개 클래스보다 많은 8개로 시작해보는 식).

### Wide vs Deep — 구조 선택의 트레이드오프

| 구조 | 특징 | 장단점 |
|---|---|---|
| **넓고 얕은(wide, shallow)** — 노드 많고 층 적음 | 세부 사항을 잘 암기 | 과적합되기 쉬움 |
| **깊은(deep)** — 층 많음 | 중간 단계의 특징을 잘 잡아내고 일반화에 유리 | 연산 비용이 크고, 역시 과적합 가능 |

- 목표는 **과적합 없이 임무를 해낼 수 있는 한도 내에서 최대한 작은 모델**을 찾는 것 — 크기·형태를 실험하며 튜닝하는 과정 자체가 이 작업의 핵심이다.

### 고급 옵션 — Keras 뷰

- 우측 상단 점 3개(⋮) 메뉴에서 **Keras 뷰**로 전환하면, Keras에 익숙한 사람은 아키텍처를 **코드로 직접 수정**할 수 있다. (이 강의는 다시 기본 시각적(visual) 모드로 돌아가 학습을 재확인)

## 예시

학습률을 실수로 너무 크게 잡으면 손실 그래프가 지그재그로 튀다가 점점 커지는 것을 볼 수 있는데, 이때는 값을 낮춰서 다시 학습해야 정상적인 수렴 곡선을 얻을 수 있다.

## 요약

- 에폭·학습률은 가장 먼저 만지게 되는 하이퍼파라미터이며, 각각의 "너무 적음/너무 많음" 증상을 손실 그래프로 구분할 수 있다.
- **지역 최소점, 손실 0의 함정(나이브 분류기·과적합)** 은 학습이 "끝났다"는 착시를 준다 — 항상 혼동 행렬과 검증/테스트 손실로 재확인한다.
- 모델 아키텍처 수정은 "이미 검증된 구조에서 시작해 조금씩 바꿔가며 재학습·재검증하는" 시행착오 과정이며, **넓고 얕은 모델**과 **깊은 모델** 사이의 트레이드오프를 이해하고 있으면 방향을 잡기 쉽다.
- 임베디드 목표는 결국 **과적합 없이 일을 해낼 수 있는 가장 작은 모델**을 찾는 것이다.
