# What is Machine Learning?

## 개요

게스트 강사(Alex Fred-Ojala)가 AI/머신러닝/딥러닝 용어를 정리하고, AI의 역사(3번의 "하이프 물결")와 지금의 딥러닝 붐을 만든 4가지 요인, 그리고 머신러닝의 3가지 카테고리를 개괄한다.

## 내용

### 인간 지능 vs 인공지능

- **인간 지능**의 특징(강사 정리): 문제 해결·목표 설정과 달성, 추론(과거·현재·미래를 분석), 소통·협업·타인에게 영향을 주는 능력(사회·문명 형성), 그리고 **의식**(자기 인식, 감정, 직관, 상상력, 창의성).
- **인공지능**에 대한 합의된 정의는 없지만, 강사가 선호하는 정의: "기계·시스템·모델·컴퓨터가 인간 지능의 여러 측면을 흉내내거나 강화하는 능력." 오늘날 AI는 **잘 정의된 특정 문제**는 매우 잘 풀지만, **의식이나 감정은 갖고 있지 않다.**
- 학술적 정의(Russell & Norvig, *Artificial Intelligence: A Modern Approach*): "환경으로부터 지각(precept)을 받아, 그 환경에 영향을 미치는 행동을 취하는 지능형 에이전트를 설계하고 만드는 것."

### 포함 관계 — 데이터 사이언스 ⊃ AI ⊃ 머신러닝 ⊃ 딥러닝

| 용어 | 정의 |
|---|---|
| **데이터 사이언스** | 데이터에서 지식·통찰을 뽑아 더 나은 의사결정/예측을 하는, 가장 넓은 범주. 엑셀만 써봤어도 넓은 의미에선 데이터 사이언스를 한 것 |
| **AI** | 위에서 정의한 것 |
| **머신러닝** | 학습 데이터로부터 표현(representation)을 학습하는 수학·통계 모델의 집합. 입력 데이터에서 패턴을 뽑아 규칙·파라미터를 만들어 예측/판단한다 |
| **딥러닝** | 머신러닝의 부분집합. 표현을 여러 층(layer)에 걸쳐 순차적으로 학습하는 복잡한 모델. 2010년대 이후 가장 주목받은 AI 분야 |

### AI는 새로운 게 아니다 — 3번의 하이프 물결과 2번의 겨울

1. **1950년대**: 다트머스 회의에서 "인공지능"이라는 용어 탄생, 퍼셉트론(신경망의 기본 구성 요소) 등장 → 기대에 못 미쳐 **1970년대 초 첫 번째 AI 겨울**.
2. **1980년대 중반**: 머신러닝·기호주의 AI·전문가 시스템 붐. 스팸 메일 분류, 우편물 손글씨 숫자 인식(CNN) 등 실용 사례 등장 → 다시 기대에 못 미쳐 **2000년대 초 두 번째 AI 겨울**.
3. **2010년대~현재**: **딥러닝 혁명(deep-learning revolution)**. 강사는 이번을 AI의 진짜 르네상스로 본다.
   - (참고로 가우스가 1700년대 후반에 선형 회귀·최소제곱법을 풀 때도 넓게 보면 이미 "머신러닝"의 영역이었다고 언급 — AI는 생각보다 오래된 개념.)

### 지금의 딥러닝 붐을 만든 4가지 요인

1. **데이터 양의 폭증** — 인류는 이틀마다 2003년까지 인류 전체가 만든 데이터보다 많은 데이터를 생산한다.
2. **연산력** — 무어의 법칙(CPU 처리력이 약 18개월마다 2배)이 1960년대부터 꾸준히 유지됨.
3. **알고리즘의 지속적 발전** — 매주 새로운 논문·기법이 쏟아짐.
4. **대중적 관심** — 각국 정부의 R&D 투자, 대학의 관련 학위 신설, 그리고 이 코스가 만들어졌다는 사실 자체가 그 방증.

### 머신러닝의 3가지 카테고리

- **지도학습(Supervised Learning)** — 입력과 정답(레이블)이 짝을 이룬 데이터로 학습. 연속값을 예측하는 **회귀(regression)**, 범주를 예측하는 **분류(classification)**로 나뉜다.
- **비지도학습(Unsupervised Learning)** — 정답 레이블 없이 데이터에서 패턴을 뽑는다. 군집화(clustering), 차원 축소, 이상치 탐지 등.
- (이 강의에서 3번째 카테고리는 명시적으로 이름이 언급되지 않았지만 강화학습이 일반적으로 세 번째 축으로 다뤄진다.)

### 전통 알고리즘과 머신러닝의 결정적 차이

- **전통 알고리즘**(기호주의 AI·전문가 시스템 등): **사람이** 규칙과 파라미터를 정하고, 데이터는 그 규칙에 따라 처리되어 결과가 나온다.
- **머신러닝**: **학습 과정에서** 규칙(파라미터)이 정해진다. 지도학습이라면 (입력, 정답) 쌍을 주기만 하면 규칙이 도출되고, 그 규칙으로 처음 보는 데이터에 대해서도 예측한다 — 처음 보는 데이터에서도 잘 맞으면 "일반화(generalize)를 잘한다"고 말한다.

## 요약

- 데이터 사이언스 ⊃ AI ⊃ 머신러닝 ⊃ 딥러닝의 포함 관계를 기억한다.
- AI는 2번의 겨울을 거쳐 지금 3번째 붐(딥러닝 혁명) 중이며, 그 동력은 **데이터·연산력·알고리즘·대중 관심** 네 가지다.
- 머신러닝의 핵심은 "규칙을 사람이 짜는 게 아니라 데이터로부터 학습한다"는 것 — 이 관점이 이후 강의(특징 추출, 모델 학습, 임베디드 배포)를 이해하는 기준이 된다.
