# Welcome to the Course

## 개요

이 코스 전체의 방향을 소개하는 도입부. Amazon Echo의 "Alexa" 키워드 인식을 예로 들어 **엣지 AI(Edge AI)/임베디드 머신러닝(TinyML)** 이 무엇이고 왜 필요한지 설명한다.

## 내용

### 왜 클라우드가 아니라 엣지인가

- 일반적으로 머신러닝은 스팸 필터링·영화 추천·교통 예측처럼 **강력한 서버가 대량의 데이터를 처리**하는 것을 떠올리게 한다.
- 하지만 모든 머신러닝을 클라우드에서 할 수는 없다. 예: **자율주행차가 인터넷 연결을 잃으면?** 그래도 교통 법규를 지키고 충돌을 피해야 한다 — 로컬(차량 내부)에서 즉시 판단해야 한다.
- 최근 몇 년간 연구자들이 **아주 작은 마이크로컨트롤러에서도 머신러닝 알고리즘을 돌릴 수 있는 효율화**를 이뤄냈다. 이것이 **임베디드 머신러닝(embedded machine learning) = TinyML**이다.
- 마이크로컨트롤러는 저렴하고 전력 효율이 좋아서, TinyML은 AI가 들어간 완전히 새로운 세대의 전자기기를 가능하게 한다.

### Amazon Echo 사례로 보는 하이브리드 구조

Echo는 **"Alexa"라는 키워드만 임베디드 머신러닝으로 로컬에서 감지**하고, 그 이후의 실제 요청 처리는 서버로 스트리밍해서 더 복잡한 모델로 처리한다 — **작은 모델(엣지)과 큰 모델(클라우드)을 나눠 쓰는 전형적인 패턴**이다.

### 이 코스에서 배우는 것

1. AI·머신러닝이란 무엇인가
2. 데이터 수집 방법
3. 데이터에서 특징(feature) 추출
4. 머신러닝 모델 학습
5. 학습된 모델을 임베디드 시스템에 배포

### 실습 프로젝트 2개

- **제스처 인식(gesture recognition)** 디바이스 — 스마트폰 또는 Arduino로 실습.
- **음성 인식(speech recognition)** 시스템.
- 두 프로젝트 모두 자신의 용도에 맞게 변형해보는 과제가 주어진다.

### 도구와 전제 조건

- 데이터 수집·모델 학습에 **Edge Impulse**라는 도구를 사용한다.
- **사전 머신러닝 지식은 필요 없다** — 이 코스는 머신러닝 시스템을 만드는 전체 과정을 몇 시간 안에 훑어보는 개관(overview)이 목표다. 더 깊이 알고 싶으면 별도의 책·강좌를 참고하라고 안내한다.
- **Arduino 또는 C 프로그래밍 경험이 있으면 좋다.** 시연은 Arduino 기준으로 진행되지만, 배운 내용은 다른 개발 환경에도 그대로 적용할 수 있다.

## 요약

- 이 코스의 핵심 축: **클라우드 머신러닝과 다른, 마이크로컨트롤러에서 직접 도는 TinyML**.
- Amazon Echo처럼 "작은 모델(로컬)+큰 모델(클라우드)"을 나누는 하이브리드 구조가 실전 패턴이다.
- Edge Impulse 도구로 데이터 수집 → 특징 추출 → 학습 → 배포까지의 전체 파이프라인을 실습하며, 제스처 인식과 음성 인식 두 프로젝트로 마무리한다.
