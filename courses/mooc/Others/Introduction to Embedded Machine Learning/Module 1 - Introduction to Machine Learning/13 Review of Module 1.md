# Review of Module 1

## 개요

Module 1 전체를 요약하는 짧은 정리 영상. 새로운 내용은 없고, 각 강의를 순서대로 되짚으며 Module 2에서 무엇을 할지 예고한다.

## 내용

### 지금까지 배운 것 순서대로

1. **AI·머신러닝·딥러닝의 차이**, 머신러닝의 역사와 용도 (Alex).
2. **윤리** — 데이터가 균형 잡히고 편향이 없어야 공정한 모델을 만들 수 있다는 것 (Alex + 강사).
3. **싱글보드 컴퓨터 vs 마이크로컨트롤러**의 차이와 각각에서 머신러닝이 어떻게 다르게 쓰이는지, 그 한계.
4. **하드웨어 발전**이 마이크로컨트롤러의 ML 연산을 어떻게 더 효율적으로 만들었는지 (Tomas, 게스트).
5. **소프트웨어 프레임워크**들이 어떻게 함께 작동해 마이크로컨트롤러에서 ML을 최적화하는지 (Felix, 게스트).
6. Edge Impulse 계정 생성, 스마트폰/Arduino로 **데이터 수집**.
7. **학습/검증/테스트 분할**의 필요성.
8. **편향된 데이터로 학습하면 편향된 모델이 나온다**는 실제 예시(윤리 강의와 연결).
9. **특징 추출**이 왜 필요한지, 모션 데이터에서 RMS·FFT를 어떻게 계산하는지.
10. **머신러닝 파이프라인**의 구조, 그리고 **학습 파이프라인과 추론 파이프라인이 어떻게 다른지.**

### 강사의 실전 팁

- 모델을 학습시킬 때는 **완벽한 하이퍼파라미터를 찾으려 오래 고민하기보다, 일단 뭐라도 빨리 돌려보는 것**이 낫다 — 그래야 애초에 방향이 맞는지 빨리 확인할 수 있다. 방향이 틀렸는데 난해한 알고리즘을 몇 달씩 연구하는 것을 피하기 위함.
- **학습(training)** 은 하이퍼파라미터를 계속 조정해야 해서 복잡한 반면, **추론(inference)** 은 상대적으로 단순하다 — 데이터 수집 → 즉시 특징으로 변환 → 모델에 한 번 순전파(forward pass) → 예측(분류 문제라면 어느 클래스인지) 출력, 이 흐름뿐이다.

## 요약

Module 1은 "왜"(AI/ML이란 무엇이고 왜 임베디드에서 중요한가, 윤리)와 "어떻게 시작하는가"(Edge Impulse로 데이터 수집·특징 추출)를 다뤘다. **Module 2에서는 실제로 모델을 학습시키고, 임베디드 시스템에 배포하는 단계로 들어간다.**
