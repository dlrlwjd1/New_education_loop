# Getting Started with Edge Impulse

## 개요

이 코스 전체에서 쓸 도구 **Edge Impulse**를 소개하고, 계정 생성부터 스마트폰·Arduino Nano 33 BLE Sense를 데이터 수집 디바이스로 연결하는 과정을 안내한다.

## 내용

### Edge Impulse란

- TensorFlow·scikit-learn 같은 프레임워크를 파이썬으로 직접 다루는 대신, **모델 학습을 훨씬 쉽게 만들고 과정을 그래픽으로 보여주는 온라인 도구**.
- 2019년 **Zach Shelby**와 **Jan Jongboom**이 창업. 목표는 임베디드 엔지니어가 머신러닝 프레임워크를 따로 공부하지 않고도, 도구가 무거운 작업을 대신 해주게 해서 **본래 풀어야 할 문제에 집중**하게 하는 것.
- 여전히 TensorFlow 같은 프레임워크를 직접 배우는 것도 가치가 있다고 언급하지만, 이 코스는 Edge Impulse로 진행한다.

### 프로젝트 생성과 대시보드

- 계정 생성 → 새 프로젝트 생성(이름 지정) → 프로젝트 열기.
- 왼쪽 패널이 전체 흐름을 보여준다: **데이터 수집 → 임펄스(Impulse, ML 파이프라인) 구성 → 모델 학습 → 디바이스에 배포**.
- 대시보드 상단의 **Keys** 탭에 두 종류의 키가 있다:
  - **API 키** — 스마트폰·마이크로컨트롤러 같은 디바이스를 연결해 데이터를 수집하거나 라이브 테스트할 때 사용.
  - **HMAC 키** — 데이터를 프로그래밍 방식으로 밀어넣는 **ingestion 서비스** 연결용. 스크립트로 데이터 수집·학습을 자동화할 때 쓴다(이 코스에서 깊게 다루진 않음).

### 데이터를 보내는 방법 4가지

1. **파일 직접 업로드** — 오디오·이미지·CBOR/JSON 형식의 raw 데이터를 지원.
2. **커맨드라인 도구로 스크립트 자동 업로드**.
3. **지원되는 개발보드**(예: Arduino Nano) — 전용 펌웨어 + 컴퓨터의 CLI 도구로 센서 데이터를 전송.
4. **스마트폰** — 보드가 없어도 데모를 체험하기 좋은 방법.
5. (참고) 엔터프라이즈 계정에서는 다른 클라우드 서비스와 직접 연결도 지원.

이 코스는 **마이크로컨트롤러 보드↔컴퓤터** 방식과 **스마트폰** 방식 위주로 진행한다.

### 스마트폰 연결

Devices → Connect a new device → Show QR code → 폰의 QR 코드 리더로 스캔 → 웹페이지 접속 → 연결 알림 확인 → Devices 목록에 폰이 표시된다.

### Arduino Nano 33 BLE Sense 연결 (Windows 기준 절차)

1. Arduino를 컴퓨터에 연결 → **리셋 버튼을 빠르게 두 번** 눌러 부트로더 모드 진입(노란 LED가 깜빡이면 성공).
2. **Node.js** 설치(nodejs.org).
3. **Arduino CLI** 설치 — macOS는 Homebrew, Linux는 curl 설치 스크립트, Windows는 zip을 `C:\` 드라이브에 압축 해제 후 **환경 변수 PATH**에 실행 파일 경로 추가.
4. `npm install -g edge-impulse-cli`로 Edge Impulse CLI 설치.
5. Edge Impulse의 Nano 안내 페이지에서 **최신 Edge Impulse 전용 펌웨어**를 다운로드 → 압축 해제 → OS에 맞는 스크립트(Windows는 배치 파일) 실행 → 부트로더 모드인 보드를 자동으로 찾아 펌웨어 업로드.
6. 완료 후 **리셋 버튼을 한 번** 눌러 보드를 재시작.
7. 커맨드 프롬프트에서 `edge-impulse-daemon` 실행 → Edge Impulse 계정 로그인 → 보드가 연결된 **시리얼 포트 선택**(Windows는 장치 관리자에서 COM 포트 확인 필요할 수 있음) → 사용할 **프로젝트 선택**(예: 모션 감지 프로젝트) → 보드 이름 지정(기본은 MAC 주소).
8. Edge Impulse 프로젝트의 Devices 페이지에서 Arduino 보드가 폰과 함께 목록에 뜨는 것을 확인.

## 예시

같은 프로젝트에 스마트폰과 Arduino를 **동시에 디바이스로 등록**해두면, 두 소스에서 각각 다른 종류의 데이터(예: 폰의 가속도계 vs Arduino의 센서)를 모아 하나의 데이터셋으로 합칠 수 있다.

## 요약

- Edge Impulse는 데이터 수집부터 배포까지 GUI로 안내하는 TinyML 전용 플랫폼이다.
- 디바이스 연결은 **스마트폰(QR 코드)** 또는 **Arduino(부트로더 모드 → 전용 펌웨어 업로드 → `edge-impulse-daemon`)** 두 경로로 진행하며, 다음 강의(Data Collection)에서 이 연결된 디바이스로 실제 데이터를 모은다.
