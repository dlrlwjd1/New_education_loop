# Module Review

## 개요

Module 2 전체(신경망 이론 → 학습 → 평가 → 배포 → 이상 탐지)를 요약하는 정리 영상. Module 3(음성 키워드 감지) 예고로 마무리한다.

## 내용

### 이 모듈에서 다룬 것 정리

1. **신경망 개요**(Alex) — 3층 신경망으로 가속도계 제스처를 분류. 핵심 요점: **출력 개수 = 클래스 개수**이고, 각 출력은 "그 클래스일 확률"이다.
2. **학습 원리(역전파)** — 샘플을 넣어 예측 → 손실 함수로 정답과의 차이 계산 → 역전파로 그 손실을 모델에 되먹임 → 파라미터가 점점 데이터의 경향을 반영하도록 갱신. 학습이 진행될수록 **손실은 감소, 정확도는 증가**가 기대되는 패턴이며, **검증 세트**로 처음 보는 데이터에 대한 성능을 확인한다.
3. **모델 평가** — 혼동 행렬로 정확도·특이도(specificity)·정밀도(precision)·재현율(recall)을 계산하고, 이를 조합한 **F1 점수**가 단순 정확도보다 나은 평가 기준이 되는 경우가 많다는 것.
4. **과소적합 vs 과대적합** — 각각이 성능을 어떻게 해치는지, 어떻게 발견하는지, 어떻게 줄이거나 막는지.
5. **배포** — Edge Impulse가 학습된 모델을 라이브러리로 감싸주어, 임베디드 시스템(폰·마이크로컨트롤러)에서 **raw 가속도계 데이터 읽기 → 지정된 특징 추출 → 추론 → 클래스별 확률**의 흐름으로 바로 쓸 수 있다. 스마트폰 브라우저 실시간 추론과 Arduino 실제 배포를 모두 시연.
6. **이상 탐지** — 머신러닝 맥락에서 어떻게 이뤄지는지, 특히 임베디드 시스템에서 어떤 문제를 풀어주는지.

## 요약

이 모듈로 **데이터 수집 → 특징 추출 → 모델 학습 → 마이크로컨트롤러 배포**로 이어지는 머신러닝 프로젝트 전체 사이클을 한 바퀴 완주했다. **다음 모듈(Module 3)에서는 Amazon Echo와 비슷한 방식의 음성 키워드 감지(keyword spotting)** 를 주제로, 조금 더 발전된 모델로 이 과정을 다시 한번 반복한다.
