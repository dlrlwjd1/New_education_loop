# Introduction to Neural Networks

## 개요

게스트 강사 Alex가 **밀집 신경망(dense neural network)** 의 동작 원리를 손글씨 숫자 인식 예제로 직관적으로 설명한다. 퍼셉트론 → 활성화 함수 → 순전파 → 손실 함수 → 역전파(경사하강법)까지 신경망 학습의 전체 흐름을 다룬다.

## 내용

### 퍼셉트론(Perceptron) — 신경망의 기본 단위

- 1950년대 Rosenblatt가 제안, 생물학적 뉴런에서 영감을 받음.
- 손글씨 숫자(28×28 픽셀) 이미지를 **1차원 배열(784개 값)로 펼쳐서(flatten)** 입력으로 쓴다.
- 각 입력값에 **가중치(weight, w)** 를 곱하고 다 더한 뒤 **편향(bias)** 을 더한다 — 이것이 **가중합(weighted sum)**.
  - 가중치: 각 특징(픽셀)이 결과에 얼마나 중요한지를 나타냄.
  - 편향: 결정 경계를 위/아래로 이동시키는 역할.
- 가중합에 **활성화 함수(activation function)** 를 적용해 최종 출력을 낸다. 고전 퍼셉트론은 임계값을 넘으면 1, 아니면 0을 내는 **헤비사이드 계단 함수**를 썼다.

### 활성화 함수 — 왜 비선형이어야 하는가

- 활성화 함수가 없으면 신경망은 그냥 큰 **선형 회귀 모델**에 불과하다 — **비선형성**을 넣는 것이 핵심 역할.
- 초창기엔 시그모이드·tanh를 많이 썼지만, 경험적으로 **ReLU(Rectified Linear Unit)** 같은 더 단순한 함수가 학습 시 더 효율적이고 안정적이어서 지금은 딥러닝의 사실상 표준이 됐다.

### 신경망 구조 — 입력층·은닉층·출력층

- 가장 단순한 형태(1개 은닉층)를 **얕은 신경망(shallow neural network)** 이라 부른다: **입력층 → 은닉층 → 출력층**.
- 은닉층의 각 노드는 입력층 모든 노드와 연결(밀집 연결)되어 가중합을 계산하고 활성화 함수를 적용해 다음 층으로 넘긴다. 층 사이의 각 연결(화살표)이 하나의 **모델 파라미터(가중치)** 다.
- 손글씨 숫자 예제라면 **출력 노드가 10개**(0~9) — 각 노드는 "이 이미지가 이 숫자일 확률"을 나타내고, 전체 합은 1이 되며 **가장 높은 확률을 예측값으로 채택**한다.

### 학습 절차 — 순전파·손실·역전파

1. 모델을 **랜덤 가중치**(또는 최선의 사전 추정치)로 초기화.
2. 입력 샘플 하나를 넣고 **순전파(forward pass)** 로 전체 네트워크를 통과시켜 출력(예측)을 계산.
3. 예측값을 **정답(true value)** 과 비교해 **손실 함수(loss function)** 값을 계산.
4. **역전파(backpropagation)** 로 손실을 전체 층에 거꾸로 전파해 **손실의 그래디언트(기울기)** 를 계산.
5. 그래디언트를 이용해 모든 모델 파라미터(가중치)를 갱신.
6. 원하는 성능이 나올 때까지 2~5를 반복.

### 손실 최소화의 직관 — 선형회귀로 보는 경사하강법

- 가장 단순한 예: 기울기 `a`와 절편 `b`를 갖는 선형회귀 모델. 데이터 산점도에 가장 잘 맞는 직선을 찾는 문제.
- **손실**: 예측값(직선 위의 점)과 실제값(산점도의 점) 사이의 **제곱 오차** 합.
- **최적화**: 초기값에서 시작 → 손실의 **그래디언트를 계산** → **그래디언트의 반대 방향으로 한 걸음** 이동(그래디언트 방향으로 가면 손실이 커지므로 반대로 간다) → 전역 최소점에 가까워질 때까지 반복.

### 역전파와 연쇄 법칙(Chain Rule)

- 신경망에서는 이 그래디언트 계산을 **역전파**로 한다 — 미적분의 **연쇄 법칙(chain rule)** 을 이용해 네트워크 출력의 손실로부터 각 층의 가중치까지 거슬러 올라가며 미분을 계산한다.
- 벡터 값 함수의 연쇄 법칙은 **야코비안(Jacobian) 행렬의 곱셈**으로 표현할 수 있다 — 여러 층이 중첩된 함수라도 이 행렬곱으로 전체 그래디언트를 계산할 수 있다.
- (강사는 세부 수식을 다 이해하지 못해도 괜찮다고 강조 — 핵심은 "역전파가 손실로부터 각 가중치까지의 기여도를 계산해서 가중치를 조정한다"는 상위 개념을 이해하는 것.)

### 핵심 요약 절차 (반복)

**순전파(샘플 입력→예측) → 손실 계산(예측 vs 정답) → 역전파(그래디언트 계산) → 가중치 갱신** — 이 사이클을 만족스러운 성능이 나올 때까지 반복한다.

### 용어 정리

| 용어 | 뜻 |
|---|---|
| **이터레이션(iteration)** | 순전파+역전파 한 번 |
| **미니배치(mini-batch)** | 한 이터레이션에 사용하는 데이터의 부분집합 |
| **배치(batch)** | 한 번에 전체 데이터를 다 통과시키는 것 |
| **에폭(epoch)** | 전체 데이터셋을 한 번 다 통과하는 것 |

## 예시

28×28 손글씨 숫자 이미지 → 784차원으로 펼침 → 은닉층을 거쳐 → 출력층 10개 노드가 각각 "이 숫자가 0~9일 확률"을 냄 → 가장 높은 확률의 숫자를 예측으로 채택. 이 과정을 학습 데이터 전체(라벨 포함)로 반복하며 가중치를 조정하는 것이 곧 "학습"이다.

## 요약

- 퍼셉트론(가중합 + 활성화 함수)이 신경망의 기본 단위이고, 비선형 활성화 함수(요즘은 주로 ReLU)가 신경망을 단순 선형모델 이상으로 만든다.
- 학습은 **순전파 → 손실 계산 → 역전파(그래디언트) → 가중치 갱신**의 반복이며, 직관적으로는 손실 함수의 그래디언트 반대 방향으로 조금씩 내려가는 경사하강법이다.
- 역전파는 연쇄 법칙(야코비안 행렬곱)으로 손실을 각 층의 가중치까지 거슬러 전파한다.
- 이터레이션·미니배치·배치·에폭 용어를 구분해두면 다음 강의(모델 학습 실습)에서 설정값을 이해하기 쉽다.
