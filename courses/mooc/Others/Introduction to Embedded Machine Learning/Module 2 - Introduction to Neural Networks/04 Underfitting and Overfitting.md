# Underfitting and Overfitting

## 개요

머신러닝에서 가장 흔한 두 가지 실패 유형, **과소적합(underfitting)** 과 **과대적합(overfitting)** 을 정의하고, 학습/검증 곡선으로 어떻게 구분하는지, 그리고 각각의 해결책을 다룬다.

## 내용

### 과소적합(Underfitting)

- 2차원(특징 2개)짜리 아주 단순한 예시: 한 축에 대한 **단순 임계값(threshold)** 하나로만 원/삼각형을 나누는 모델.
- 빠르지만 **데이터의 군집·경향을 전혀 잡아내지 못한다** — 이게 과소적합이다. 모델이 너무 단순해서 데이터의 패턴을 못 담아낸다.

### 과대적합(Overfitting)

- 더 복잡한 모델을 오래 학습시키면 처음엔 잘 분리되다가, **너무 오래 학습시키면 학습 데이터의 세세한 잡음(nuance)까지 통째로 외워버린다.**
- 결과: **학습 데이터에서는 정확도가 훌륭**하지만, **처음 보는 데이터(검증/테스트)에서는 성능이 뚝 떨어진다.**

### 구분하는 법 — 학습 곡선 vs 검증 곡선

**반드시 검증 세트로 확인한다.** (테스트 세트로 문제를 발견하고 모델을 고치면, 그 순간부터 테스트 세트가 오염되어 더 이상 "한 번도 안 본 데이터"가 아니게 된다 — 그래서 튜닝은 검증 세트로, 최종 확인만 테스트 세트로.)

| 상황 | 정확도(accuracy) 패턴 | 손실(loss) 패턴 |
|---|---|---|
| **좋은 적합(good fit)** | 학습·검증 모두 높음 (100%는 보통 아니어도 됨, 80~90%면 충분한 경우도 많음) | 학습·검증 모두 함께 떨어짐. 보통 학습이 검증보다 살짝 낫다 |
| **과소적합** | 학습·검증 모두 낮음 | 학습을 계속해도 손실이 유의미하게 안 떨어짐 |
| **과대적합** | **학습은 높은데 검증은 훨씬 낮음** | **학습 손실은 거의 0인데 검증 손실은 여전히 큼** |

## 해결책 — 과소적합

과소적합은 보통 "모델이 부족하거나, 데이터가 부족하다"는 신호라 상대적으로 다루기 쉽다.

1. **데이터를 더 모은다** — 대부분의 경우 손해가 없다. 단, 편향 없이 목표를 대표하는 데이터여야 한다.
2. **특징을 바꾸거나 추가한다** — 지금 쓰는 특징이 클래스를 충분히 분리하지 못할 수 있다.
3. **더 오래 학습시킨다** — 강사는 복잡한 객체 탐지 모델이 손실이 떨어지기 시작하는 데 **2만 에폭**까지 걸린 경험을 언급 — 일단 더 오래 돌려보는 게 쉬운 첫 시도.
4. **모델을 더 복잡하게 만든다** — 신경망이라면 층·노드 수를 늘려본다.
5. **접근 자체를 바꾼다** — 신경망이 이 문제에 안 맞는 방법일 수도 있다. 문제에 맞는 다른 머신러닝 기법을 조사해본다.

## 해결책 — 과대적합 (더 다루기 까다로움)

1. **데이터를 더 모은다** — 여기서도 거의 항상 도움이 된다.
2. **조기 종료(Early Stopping)** — 검증 정확도가 오르다가 다시 떨어지기 시작하는 지점을 찾아, **가장 검증 성능이 좋았던 에폭에서 학습을 멈춘다.** 근본 원인(결국 과적합되는 경향)을 고치는 건 아니지만 빠르게 쓸만한 모델을 얻는 방법. **Edge Impulse는 이 조기 종료를 자동으로 해준다** — 매 에폭마다 모델을 저장해두고 검증 결과가 가장 좋은 버전을 골라준다.
3. **모델을 덜 복잡하게 만든다** — 복잡할수록 과적합되기 쉬우므로, 층·노드 수를 줄여본다.
4. **정규화(Regularization)** — 모델이 복잡할수록 손실 함수에 페널티를 줘서, **가능한 한 단순한 형태로 데이터에 맞추도록 유도**하는 기법. **Edge Impulse는 기본 신경망에 L1 정규화 항을 기본으로 넣어준다** — 직접 추가할 필요는 없지만 값을 조정해볼 수는 있다.
5. **드롭아웃(Dropout)** — 학습 중 **일부 노드의 출력을 무작위로 무시**해서, 나머지 노드들이 데이터에 맞추는 책임을 더 나눠 지게 만드는 기법. 모델 전체의 과적합을 줄이는 데 자주 쓰인다.

## 예시

검증 정확도 곡선이 어느 에폭까지는 학습 정확도와 함께 올라가다가, 그 이후로는 학습 정확도만 계속 오르고 검증 정확도는 떨어지기 시작한다면 — **바로 그 꺾이는 지점**이 조기 종료로 멈춰야 할 지점이다.

## 요약

- **과소적합** = 모델이 데이터의 패턴을 못 잡음(학습·검증 둘 다 나쁨). **과대적합** = 모델이 학습 데이터를 통째로 외움(학습은 좋은데 검증이 나쁨).
- 판단은 항상 **검증 세트**로 하고, 테스트 세트는 최종 확인용으로 아껴둔다.
- 과소적합엔 데이터 추가·특징 개선·더 긴 학습·더 복잡한 모델이, 과대적합엔 데이터 추가·조기 종료·더 단순한 모델·정규화·드롭아웃이 각각의 처방이다.
- 머신러닝 실무의 상당 부분은 **데이터/특징/모델을 바꿔가며 재학습하고, 처음 보는 데이터에서 어떻게 되는지 확인하는 시행착오**다.
