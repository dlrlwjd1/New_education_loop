# Testing Inference with a Smartphone

## 개요

배포 전 마지막 검증 단계. Edge Impulse의 **테스트 세트 자동 채점**과 **스마트폰 라이브 분류**로 모델이 실제로 잘 작동하는지 확인한다.

## 내용

### 1. 테스트 세트로 최종 채점 — Model Testing 페이지

- 프로젝트의 **Model Testing** 페이지 → 전체 샘플 체크 → **Classify Selected** 클릭.
- 예측이 실제 라벨과 다르면 **빨간색으로 표시**된다.
- 동작을 매번 일관되게 수행했다면 거의 100%에 가까운 정확도가 나올 것.
- **테스트 세트 정확도가 학습/검증보다 훨씬 낮다면 → 과적합 신호**(앞 강의에서 다룬 문제) — 재학습하거나 과적합 감소 기법(정규화·드롭아웃·조기 종료 등)을 적용해야 한다.

### 2. 실시간 분류(Live Classification) — 웹 기반

1. `smartphone.edgeimpulse.com`에서 폰을 다시 연결하고 **Live Classification** 페이지로 이동.
2. **Start Sampling** → 10초 동안 좌우 → 상하 → 원 → 정지 순으로 동작을 이어서 수행.
3. 완료되면 10초 전체 가속도계 그래프가 나오고, **원하는 구간으로 창(윈도우)을 드래그**하면 그 구간에 대한 예측 확률을 확인할 수 있다.
4. 각 구간(좌우/상하/원/정지)에서 해당 라벨의 확률이 가장 높게 나오는지 확인.
5. **동작이 전환되는 경계 구간**(예: 좌우 → 상하로 바뀌는 순간)에 윈도우를 겹치면, 모델이 확신하지 못해 **빨간색으로 표시된 불확실한 예측**이 나오는 것도 볼 수 있다 — 실제 사용 시 발생할 수 있는 자연스러운 한계.

### 3. 실시간 분류 — 연속 모드(Live Classification Mode)

- Arduino를 연결해 데이터 캡처했던 것과 같은 방식으로, **폰에서도 daemon 없이** 데이터 캡처 화면에서 **"switch to live classification mode"** 버튼을 누르면 된다.
- 이 모드는 **2초마다 자동으로 샘플링 → 분류 → 반복**하며 각 클래스의 확률을 실시간 리스트로 보여준다.
- 좌우 동작 시 `left-right` 확률이 1에 가깝게, 다른 동작도 마찬가지로 확인. 가만히 두거나 테이블에 올려두면 `idle` 확률이 높게 나오는지 확인.
- **이 실시간 분류는 Edge Impulse 서버로 데이터를 보내지 않고, JavaScript + WebAssembly로 폰(브라우저) 안에서 로컬로 돈다.**

### 참고 — 브라우저/모바일 앱에 직접 통합하고 싶다면

- Edge Impulse는 학습된 모델+라이브러리를 **WebAssembly 파일**로 다운로드할 수 있게 해준다. Node.js에서 테스트하거나, 웹서버로 브라우저에 전달하는 방법이 공식 문서에 안내되어 있다(브라우저마다 사용법이 달라 이 코스에서는 다루지 않음).
- **TensorFlow Lite** 모델 자체만 따로 받아서 `tensorflow.org/lite` 안내에 따라 네이티브 모바일 앱에 직접 통합할 수도 있다. 단, **이 파일에는 특징 추출 코드가 들어있지 않으므로 직접 구현해야 한다.**
- 이 코스는 모바일 앱 개발에 시간을 쏟기보다, **폰은 데모용으로만 쓰고 다음 강의부터 마이크로컨트롤러 코드로 들어간다.**

## 예시

폰을 손에 쥔 채 좌우로 흔들면 실시간 리스트에 `left-right: 0.97` 같은 값이 즉시 뜨는 것을 눈으로 확인 — 학습된 모델이 실제로 동작한다는 걸 가장 직관적으로 체감하는 순간이다.

## 요약

- 배포 전 검증은 **테스트 세트 자동 채점(정량적) + 스마트폰 라이브 분류(정성적, 실감 나는 확인)** 두 가지로 한다.
- 라이브 분류는 브라우저 안에서 로컬로(WebAssembly) 돌기 때문에 서버 왕복 지연이 없다.
- 폰 앱에 직접 통합하는 방법(WebAssembly, TFLite 단독)도 있지만 이 코스는 다루지 않고, 다음 강의부터 **마이크로컨트롤러(Arduino) 배포**로 넘어간다.
