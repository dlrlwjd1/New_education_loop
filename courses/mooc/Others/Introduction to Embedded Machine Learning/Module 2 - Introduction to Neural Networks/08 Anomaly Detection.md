# Anomaly Detection

## 개요

지도학습 분류기는 **학습한 클래스 중 하나로만** 답을 낸다 — 전혀 새로운(학습하지 않은) 동작이 들어와도 억지로 그중 하나로 분류해버린다. 이 강의는 **비지도학습(K-means 클러스터링) 기반 이상 탐지(anomaly detection)** 로 "이건 내가 아는 어떤 클래스도 아니다"를 감지하는 법을 다룬다.

## 내용

### 이상 탐지란

- 지도학습으로도 비지도학습으로도 할 수 있으며, **정확한 라벨이 없거나 무엇을 찾아야 할지 모를 때 특히 유용**하다.
- 대표 사례 — **신용카드 사기 탐지**: 카드사가 고객의 구매 패턴을 특징(2차원으로 단순화해 시각화)으로 모델링해두면, 새 구매가 그 군집에서 벗어나 있는지로 이상 여부를 판단한다.
- 핵심 포인트: **한 축(차원)씩 따로 보면 정상 범위 안에 있어 보여도, 여러 차원을 함께(경계, boundary) 보면 명백히 벗어나 있을 수 있다.** 그래서 단순 임계값이 아니라 **다차원 경계**를 그리는 방식이 필요하다.

### 임베디드 시스템에서의 응용 — 예지보전(Predictive Maintenance)

- 2005년 NASA 연구: 베어링을 며칠간 계속 회전시켜 마모·파손시키며 진동 데이터를 기록(현재 NASA 사이트에 공개, 여러 연구 경진대회에 쓰임).
- 목표: **베어링이 실제로 고장 나기 훨씬 전에** 진동 데이터의 이상 징후를 예측하는 것.
- 공장 대형 모터·베어링·압축기, 인공위성 등에 적용하면, 고장 전 미리 감지해 수천~수백만 달러의 피해를 막을 수 있다 — 이것이 임베디드 머신러닝에서 이상 탐지가 특히 중요한 이유.

### 실습 — 스마트폰에서 "학습 안 한 동작" 흔들어보기

1. `smartphone.edgeimpulse.com` 연결 → Live Classification → 알고 있는 동작(좌우)을 하다가, **학습한 적 없는 새로운 동작**(예: 앞뒤로 흔들기)을 시도.
2. 결과: 좌우 동작은 잘 분류되지만, **앞뒤 동작은 (관련 없는 x·z축이 안 움직였다는 이유로) `idle`로 잘못 분류**된다 — 분류기는 "모르겠다"는 답을 낼 수 없고 4개 중 하나를 억지로 고르기 때문.
3. 하지만 **Spectral Features 플롯**을 보면, 앞뒤 동작의 X/Y/Z RMS 값들이 **기존 4개 클래스 군집과 별개로 자기들만의 군집**을 이루고 있다 — 데이터 자체에는 "이건 다르다"는 정보가 이미 있다는 뜻.

### Edge Impulse에서 이상 탐지 블록 추가하기

1. **Impulse Design**에서 기존 Spectral Analysis(특징 추출) 블록은 그대로 두고, **Anomaly Detection(K-means)** 을 두 번째 Learning block으로 추가 → Save Impulse.
2. Edge Impulse는 **K-means 클러스터링**(비지도학습 — 특징 군집의 경계를 찾는 기법)을 사용한다.
3. **Cluster count(군집 수)**: 최소한 클래스 수만큼은 필요하지만, **실전에서는 그보다 더 많이 잡는 것이 좋다** — 같은 클래스 안에서도 변형(예: 폰을 아래로 향하게 쥐는 경우 등)이 있으면 그 안에서 여러 군집이 생길 수 있기 때문. 숫자를 바꿔가며 결과 플롯을 보고 조정.
4. 학습 후 새 샘플마다 **이상 점수(anomaly score)** 가 매겨진다 — 군집 경계에서 얼마나 벗어났는지를 나타내는 값. **0을 넘으면 군집 밖**으로 간주하고, **기본 임계값은 0.3**.
5. 어떤 축을 K-means에 쓸지 선택 가능 — 이 예제는 **X/Y/Z RMS 값**이 분리가 가장 잘 되어 이 셋을 사용.
6. Start Training 후 **Live Classification**에서 같은 테스트(좌우 → 앞뒤)를 반복하면, 결과에 **anomaly 컬럼**이 새로 생긴다. 음수는 정상 범위 안, **0.3 초과는 이상으로 플래그**. Spectral Features 플롯에서도 처음엔 `left-right` 군집에 있다가 점점 자기만의 군집으로 이동하는 것을 시각적으로 확인할 수 있다.

### Arduino(마이크로컨트롤러)에 배포

1. Arduino 프로젝트의 Impulse Design에도 동일하게 **K-means Anomaly Detection 블록** 추가(RMS 3축 선택) → Save Impulse → Anomaly Detection 페이지에서 학습.
2. Deployment 페이지에서 Arduino 라이브러리 다운로드(기존 라이브러리와 충돌하지 않도록 이전 것 삭제 권장) → Arduino IDE에 zip 설치 → **일반(비연속) accelerometer 예제**를 그대로 사용.
3. 코드 자체는 이전과 동일하고, **`EI_CLASSIFIER_HAS_ANOMALY`가 1로 설정**되어 있어 결과에 **이상 점수가 함께 출력**된다는 점만 다르다 — 애플리케이션 코드에서는 `result.anomaly` 값을 보고 판단하면 된다(임계값 0.3 기준).
4. 실제 업로드 후 시리얼 모니터에서: 학습된 동작(좌우 등)을 하면 **분류 결과 + 음수의 이상 점수**(정상 범위 확신)가 나오고, 학습하지 않은 동작(앞뒤)이나 동작을 과격하게 하면 **높은 이상 점수**가 나오는 것을 확인.

## 예시

앞뒤로 흔드는 동작을 모델이 `idle`로 잘못 분류하더라도, **이상 점수가 0.3을 넘으면 애플리케이션 코드가 "이 예측은 못 믿겠다"고 판단**할 수 있다 — 분류 결과와 이상 탐지 결과를 함께 보는 것이 신뢰할 수 있는 시스템을 만드는 핵심이다.

## 요약

- 이상 탐지는 **"학습한 클래스 중 하나가 아니라, 아예 다른 무언가"** 를 감지하는 데 쓰이며, 사기 탐지·예지보전 같은 데 실전 가치가 크다.
- Edge Impulse는 **K-means 클러스터링**(비지도학습)으로 특징 공간에서의 군집 경계를 학습하고, 새 샘플이 그 경계를 얼마나 벗어났는지를 **이상 점수**로 알려준다.
- 분류(Classification) 블록과 이상 탐지(Anomaly Detection) 블록을 **같은 임펄스 안에 함께 둘 수 있다** — 같은 특징(RMS 등)을 재사용.
- 배포된 코드는 분류 결과에 더해 `result.anomaly` 값을 함께 확인해, 예측을 신뢰할 수 있는지 추가로 판단할 수 있다.
