# Model Training in Edge Impulse

## 개요

앞 강의의 신경망 이론을 Edge Impulse의 **Neural Network Classifier** 페이지에서 실제로 학습시켜본다. 하이퍼파라미터 설정, 기본 신경망 구조(33→20→...→4), 학습 곡선(loss/accuracy) 해석까지 다룬다.

## 내용

### 학습 설정(하이퍼파라미터)

- **Epoch 수** — 학습 데이터 전체를 한 번 통과하는 것이 1 에폭. 기본값 유지.
- **Learning rate(학습률)** — 매 스텝마다 파라미터를 얼마나 크게 업데이트할지 조절. 기본값 유지.
- **Minimum confidence rating** — 학습 자체에는 쓰이지 않고, 학습 후 검증 세트로 테스트할 때 **이 값보다 낮은 확신도의 예측은 "불확실(uncertain)"로 표시**하는 데 쓰인다.

### 기본 신경망 구조 — 33 → 20 → ... → 4

- 3개 층으로 구성된 단순한 신경망. 각 층은 **완전연결(fully connected) = 밀집(dense)** 노드로 구성.
- **입력**: 앞서 추출한 33개 특징(정확히 같은 33개여야 함).
- **1층**: 노드 20개. 각 노드가 33개 입력 전체를 받아 **가중치 곱 + 편향 → 합산 → ReLU(비선형 활성화)** 를 거쳐 다음 층으로 전달.
- **2층**: 같은 방식 반복(노드 수는 다를 수 있음).
- **출력층**: 클래스 개수만큼 노드(이 예제는 4개 — 좌우/상하/원/정지). 합산 결과를 ReLU 대신 **소프트맥스(softmax)** 함수에 통과시켜, **0~1 사이 값이면서 전체 합이 1인 확률 분포**로 변환한다. 가장 높은 확률을 가진 클래스가 예측값.
- **Edit** 버튼으로 층 수·노드 수를 자유롭게 바꿀 수 있다 — 나중에 직접 바꿔보며 정확도 변화를 실험해보라고 권장. 지금은 기본값으로 진행.

### 학습 과정 (Start Training 클릭 시 내부 동작)

1. 파라미터(가중치·편향)를 **무작위로 초기화**.
2. 학습 샘플 하나의 특징을 넣어 **순전파** → (초기엔 무작위라) 예측이 크게 틀림.
3. **손실 함수(loss/cost function)** 로 얼마나 틀렸는지 수치화.
4. **역전파**로 그 손실을 이용해 파라미터 갱신.
5. 학습 세트의 모든 샘플에 대해 반복 → 1 에폭.
6. 에폭을 반복할수록 **손실은 떨어지고 정확도는 올라가는** 것이 정상 패턴 — 보통 초반 몇 에폭에서 급격히 좋아지다가 이후 완만해진다(수렴).

### 검증(Validation) 세트의 역할

- 이전 강의에서 배운 대로, Edge Impulse는 **Start Training을 누르는 시점에 학습 데이터의 20%를 자동으로 검증용으로 떼어놓는다**(테스트 세트는 이미 데이터 수집 때 별도로 분리해둔 상태).
- 매 에폭 후 검증 샘플에 대해서도 순전파로 예측 → 같은 손실 함수로 **검증 손실(validation loss)** 계산 — 단, **이 값으로는 파라미터를 갱신하지 않는다**(그러면 더 이상 검증이 아니게 되므로).
- **학습 손실보다 검증 손실이 눈에 띄게 나쁘면 과적합(overfitting) 신호**다(다음 강의에서 더 자세히). 이 예제에서는 오히려 검증 세트 성능이 학습 세트보다 살짝 나은 경우가 나왔는데, 표본이 작아 우연일 수 있어 **좋은 데이터를 최대한 많이 쓰는 것이 여전히 중요**하다고 강조.
- 진짜 최종 테스트는 **테스트 세트**로 하는 것 — 검증은 학습 중 튜닝용, 테스트는 맨 마지막 1회용이라는 원칙이 여기서도 재확인된다.

### 결과 확인 — Confusion Matrix

- 학습이 끝나면 **혼동 행렬(confusion matrix)** 로 검증 세트에서 예측 클래스 vs 실제 클래스를 비교할 수 있다(자세한 해석은 다음 강의). 이 예제에서는 모션 분류가 매우 잘 되는 것으로 확인됐다.

## 예시

4개 클래스(좌우/상하/원/정지)처럼 통제된 단순한 문제에서는 신경망이 거의 완벽에 가까운 정확도를 낼 것으로 기대할 수 있다 — 실제로 이 강의의 학습 결과도 그렇게 나왔다.

## 요약

- Edge Impulse의 Neural Network Classifier 페이지에서 **에폭 수·학습률·최소 확신도** 같은 하이퍼파라미터를 설정하고 Start Training 한 번으로 전체 학습 사이클(순전파→손실→역전파→갱신, 에폭 반복)이 자동으로 돈다.
- 출력층은 **소프트맥스**로 확률 분포를 만들고, 그중 최댓값이 예측 클래스가 된다.
- **학습 손실/정확도**와 **검증 손실/정확도**를 나란히 살펴보는 것이 과적합을 조기에 알아채는 방법이며, 최종 판단은 항상 테스트 세트에서 내려야 한다.
