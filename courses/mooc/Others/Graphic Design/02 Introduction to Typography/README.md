# Introduction to Typography

**Course URL:** [mooc.org/learn/typography](https://www.mooc.org/learn/typography)

California Institute of the Arts (CalArts) · Anther Kiley. **Graphic Design** 특화 과정의 Course 2(24시간). 타입의 해부학·측정 체계부터 서체의 역사와 함의, 그리드·위계를 활용한 조판, 표현적 타이포그래피, 최종 타이포그래피 포스터 프로젝트까지 4주 로드맵으로 타이포그래피를 깊이 있게 다룬다.

## 모듈 구성

- **Module 1 - Anatomy and Metrics** — Font vs Typeface, 획·비례·글자 해부학 용어, 포인트/파이카 측정 체계, 타입페이스 선택·조합 기준
- **Module 2 - Historical Context and Classification** — Bembo(올드스타일)·Baskerville/Didot(트랜지셔널/모던)·Clarendon(슬랩)·Futura(지오메트릭 산세리프)·Helvetica(네오그로테스크)·Scala Sans(휴머니스트 산세리프)라는 6개 사례 연구로 보는 서구 타입 역사
- [Module 3 - Grid Systems and Typographic Hierarchy](Module%203%20-%20Grid%20Systems%20and%20Typographic%20Hierarchy/) — 트래킹·커닝·리딩 등 타이포그래피 공간, 근접성의 원칙, 그리드 시스템(여백·칼럼·거터·베이스라인), 위계 만들기, 조판의 규칙·관습(줄바꿈·대시·숫자체 등), 웹 타이포그래피
- **Module 4 - Expressive Typography and Poster Design** — 표현적 타이포그래피, 조판을 넘어선 실험(안야 카이저·Polymode Studio·냇 파이퍼 프로필), CalArts 포스터 아카이브 사례 분석

각 모듈의 필수 Graded Assignment(퀴즈/최종 포스터 프로젝트)와 Practice Assignment는 학업 정직성 정책에 따라 건너뛰었으며, 모듈별 노트 마지막에 존재 여부만 기록함. AI 생성 "Practical Scenario" 활동은 랜딩 시점의 시나리오·질문을 기반으로 설명적 노트로 정리함.
