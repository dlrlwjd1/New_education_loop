# 13 Creating Hierarchy (영상)

## 개요
- 공간을 통한 구조화에 이어, 시각적 위계(visual hierarchy)로 타입을 더 명료하게 구조화하는 법을 다루는 3분 16초 분량 영상 — "Typographic Hierarchy" 섹션의 첫 영상

## 내용

### 100년 전과 오늘의 신문 1면
- 지금까지는 공간을 사용해 타이포그래피를 조직·구조화하는 법을 살펴봤음 — 이번에는 시각적 위계가 타입을 어떻게 더 명료하게 만들고 구조화하는지 살펴봄
- 100년 전 신문 1면과 오늘날 신문 1면을 비교 — 둘 다 빽빽하지만, 오늘날 신문이 훨씬 읽기 쉽고 매력적인데, 이는 주로 오늘날 신문이 **타이포그래피 위계**를 더 잘 확립하기 때문
- 옛날 신문에서는 페이지의 모든 정보가 비슷하게 보임 — 이 신문을 읽는 유일한 방법은 맨 위에서 시작해 아래로 내려가는 것뿐이라, 그날 사건을 빠르게 파악하고 싶을 때는 별로 편리하지 않음

### 오늘날 신문의 위계
- 대조적으로 오늘날 신문에서는 서로 다른 종류의 정보가 서로 다르게 보임 — 어떤 종류의 정보는 다른 것보다 시각적으로 더 두드러짐
- 그래서 이 신문을 훑어보며 헤드라인만 읽을 수도 있고, 기사를 훑어보며 페이지 번호 참조를 빠르게 찾을 수도 있음
- **타이포그래피 위계**란 서로 다른 종류의 콘텐츠가 서로 다르게 보이도록 만드는 전략이며, 스타일링을 통해 여러 콘텐츠의 상대적 중요도를 반영하는 것

### 효과적인 위계의 핵심 — 스타일 변수
- 효과적인 타이포그래피 위계의 핵심은, 제한된 타입페이스 팔레트로 작업하더라도 각 타입 스타일이 이전 스타일과 명확히 구별되어 보이도록 만드는 것
- 이를 위해 사용할 수 있는 스타일적 변수: **타입페이스, 스타일(이탤릭 등), 크기, 굵기, 색, 세팅(리딩 등)**

### 실습 예시 — 두 문단 스타일링하기
- 왼쪽은 중요한 텍스트, 오른쪽은 덜 중요한 텍스트인 두 문단을 스타일링하는 예시
  1. **크기**부터 변경 — 왼쪽 타입을 더 크게, 오른쪽 타입을 더 작게
  2. **스타일** 변경 — 오른쪽 문단을 이탤릭으로
  3. **색** 변경 — 덜 중요한 문단을 더 밝게
  4. **굵기** 변경 — 오른쪽 타입을 볼드로 만들어 조금 더 눈에 띄게
  5. 두 스타일을 더 구별하기 위해 **리딩** 변경 — 왼쪽 문단은 더 느슨하게, 오른쪽 문단은 더 타이트하게
  6. 마지막으로 **타입페이스 자체**를 구별 — 오른쪽 타입을 산세리프로 변경
- 이제 서로 뚜렷이 구별되면서도 서로 다른 중요도 수준을 읽어낼 수 있는 두 스타일이 만들어졌고, 타이트한 페어링 덕분에 여전히 어느 정도 응집력 있게 보임

### 앞선 예시(타입페이스 연표)에 적용하기
- 몇 개 영상 앞서 다룬 타입페이스 연표 예시에 이 전략을 적용하면 명료함을 한 단계 더 높일 수 있음 — 예를 들어 모든 디자이너 이름을 뚜렷이 구별되는 스타일로 처리하면, 그 정보 카테고리를 다른 콘텐츠로부터 빠르게 골라낼 수 있음

### 마무리
- 공간과 마찬가지로, 잘 실행된 위계가 독자에게 매력적이고 쉽게 접근·파악할 수 있는 타이포그래피를 만드는 데 얼마나 중요한지는 아무리 강조해도 지나치지 않음

## 요약
- 타이포그래피 위계는 콘텐츠의 상대적 중요도를 시각적 차이로 반영하는 전략이며, 타입페이스·스타일·크기·굵기·색·세팅(리딩 등)이라는 6가지 변수를 조합해 만듦
- 100년 전과 오늘날 신문 1면의 비교가 보여주듯, 위계가 없으면 콘텐츠를 처음부터 끝까지 순서대로 읽어야 하지만, 위계가 있으면 독자가 원하는 정보를 빠르게 훑어 찾을 수 있음
- 여러 변수를 동시에(그러나 일관되게) 조합하면 스타일 간 명확한 구별과 전체적인 응집력을 동시에 달성할 수 있음
