# 20 Reading: Optional Project — Typeset an Article for Screen (읽기자료, 선택 프로젝트 안내)

## 개요
- Module 2의 타입페이스 리서치를 웹 아티클 형식으로 레이아웃·조판해보는 선택 프로젝트를 안내하는 2분 59초 분량 읽기자료(비디오 형식) — 예상 소요 시간 2~3시간

## 내용

### 프로젝트 개요
- 중요: 이 프로젝트는 'Typeset an Article for Print'와 짝을 이루는 두 번째 선택 프로젝트 — 둘 다 완료해도, 하나만 해도, 둘 다 건너뛰어도 됨
- 지난 프로젝트와 마찬가지로 Module 2의 타입페이스 리서치를 이번에는 웹 아티클 형식으로 레이아웃·조판해봄 — 화면 타이포그래피의 가능성과 한계를 경험하는 동시에, 위계·타이포그래피 공간의 원리와 조판의 규칙·관습을 복습할 기회

### 프로젝트 지침
1. 'Research a Typeface' 프로젝트의 이미지와 텍스트를 웹 프로토타이핑 애플리케이션이나 페이지 레이아웃 프로그램으로 가져올 것. 반응형 디자인을 만들려면 최소 두 가지 다른 브라우저 너비에서 작업해야 함 — 데스크톱 범위(예: 흔한 표준인 1440px) 하나와 폰 화면 범위(예: 360px) 하나. 사용 중인 소프트웨어가 다른 화면 크기에서 미리보기 도구를 제공하지 않는다면, 다른 너비의 아트보드나 페이지를 만들어 각각에 디자인을 수동으로 맞출 수 있음. 공간과 상호작용이 제한된 폰 화면부터 디자인을 시작한 다음, 데스크톱 브라우저에서도 작동하도록 적응시키는 것이 항상 좋은 방법
2. 본문 텍스트 스타일부터 개발할 것 — 타입 크기(font-size), 리딩(line-height), 트래킹(letter-spacing), 행 길이(width), 정렬(align)을 가지고 놀아볼 것. 지금까지 논의한 조판 원리와 관습을 염두에 두고 화면에서 읽기 쉽고 매력적인 세팅을 만드는 것이 목표
3. 텍스트의 각 요소(제목·부제·본문·출처 등)에 타입 스타일·크기·굵기·색·리딩이라는 변수를 사용해 서로 다른 스타일과 시각적 중요도 수준을 부여해 타이포그래피 위계를 도입할 것
4. 이미지를 조합에 가져와 텍스트와 함께 순서를 정하고 배치하는 방법을 탐색할 것 — 여기서의 선택지는 인쇄보다 더 제한적임. 폰 화면은 일반적으로 여러 칼럼의 텍스트, 극적인 타입 크기 변화, 복잡한 레이아웃을 수용하기에는 너무 작음
5. 디자인이 작은 화면과 큰 화면에서 어떻게 작동하는지 탐색할 것 — 더 큰 화면 크기에서만 활성화되는 레이아웃 기능(예: 두 번째 텍스트 칼럼, 다른 이미지 배치)을 도입하는 것도 고려
6. 마지막으로 여백과 다른 타이포그래피 공간을 픽셀 단위 거리로 다듬고 표준화하며, 적절한 대시·피겨·줄바꿈 규칙을 구현해 타입에 완성도를 더할 것

### 작업물 공유
- 디자인을 JPEG 이미지로, 혹은 온라인 프로토타입 링크를 제공해 그룹과 공유할 것 — 언제나처럼 동료들에게 피드백을 요청하거나, 작업 과정을 공유하거나, 다른 사람의 작업에 댓글을 다는 것도 환영
