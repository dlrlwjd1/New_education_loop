# 19 Reading: Resources for Web Typography (읽기자료)

## 개요
- 웹·앱 타이포그래피를 실제로 구현하는 데 사용할 소프트웨어와 학습 자료를 안내하는 1분 1초 분량 읽기자료(비디오 형식)

## 내용

### 웹 타이포그래피 레이아웃을 위한 소프트웨어
- 웹이나 앱에 구현할 타이포그래피 레이아웃을 디자인하는 가장 좋은 방법은 웹 프로토타이핑이나 웹 디자인 애플리케이션을 사용하는 것 — 이런 소프트웨어는 브라우저가 지원하는 타이포그래피 컨트롤로 범위를 제한해주고 반응형 디자인을 만들 수 있게 해줌
  - **Figma**(선도적인 협업 웹 프로토타이핑 애플리케이션)
  - **Webflow**(선도적인 웹사이트 빌딩 애플리케이션)
- 혹은 최소한의 소프트웨어만으로 직접 HTML·CSS 파일을 만들고 브라우저에서 미리 볼 수도 있음 — 이를 배우는 데 도움이 되는 온라인 강좌·자료가 많음
  - **W3 Schools**(CSS·HTML 학습을 위한 대표적인 무료 자료)
  - **Code Academy**(코드 학습을 위한 더 구조화된 플랫폼)

### 웹에서 타입 설정하기 — 추천 가이드
- 온라인에서 타입을 설정하는 법을 다루는 훌륭한 가이드도 있음 — 다음 두 가지로 시작할 것을 권장
  - **The Elements of Typographic Style Applied to the Web** — 로버트 브링허스트의 유명한 타이포그래피 책을 웹이라는 맥락에 문단 단위로 포괄적으로 각색한 자료
  - **Pro Web Type** — 접근하기 쉬운 입문 자료

## 요약
- 웹 타이포그래피를 실제로 구현하려면 Figma·Webflow 같은 프로토타이핑 도구나, W3 Schools·Code Academy로 배운 직접 HTML/CSS 작성 중 하나를 선택할 수 있음
