# 15 Typographic Conventions (영상)

## 개요
- 조판의 관습적 규칙(줄바꿈, 래그, 대시류, 인용부호, 숫자체, 스몰캡스, 리게처)을 다루는 5분 32초 분량 영상 — "Rules and Conventions" 섹션의 첫 영상

## 내용

### 관습으로의 전환 — 형식과 문법 사이
- 지금까지 조판과 타이포그래피 구성을 지배하는 시각적 원리를 살펴봤다면, 이제 올바른 조판의 규칙, 즉 **관습(convention)**으로 주의를 돌림
- 지금까지 다룬 공간적·조직적 원리와 마찬가지로, 이 관습들은 미학과 구문(syntax) 사이에 걸쳐 있음 — 일부는 형식(form), 일부는 문법(grammar)

### 줄바꿈(Line Breaks)
- 이상적으로 각 줄은 리듬을 방해하지 않는 지점에서 끊겨야 함
- 단어를 하이픈으로 나눠야 한다면 음절 사이에서 나눠야 하고, 3글자보다 작은 조각으로 나눠서는 안 됨
- 1~2글자짜리 단어는 줄 끝에 매달려 있어서는 안 됨 — 시각적으로 눈이 나머지 텍스트와 분리해서 인식하는 경향이 있기 때문에 다음 줄로 내려야 함
- 마찬가지로 단어 하나나 단어 일부가 문단 맨 아래에 혼자 남아서도 안 됨 — 앞줄들의 줄바꿈을 조정해 해결 가능
- 문단의 한 줄이 혼자 남겨져서도 안 됨 — 페이지 맨 아래에 혼자 남은 문단의 첫 줄은 **오펀(orphan)**, 페이지 맨 위에 혼자 남은 문단의 마지막 줄은 **위도우(widow)**라 부름

### 래그(Rag) 다듬기
- 왼쪽 정렬 텍스트 블록의 고르지 않은 오른쪽 가장자리를 **래그(rag)**라 부름 — 본질적으로 고르지 않은 것이 정상이지만, 원뿔(cone) 모양처럼 균일하게 고르지 않을 때 시각적으로 가장 보기 좋음
- 너무 고른 래그는 거의 일직선인데 완전히 일직선은 아니어서 오히려 산만하고, 너무 고르지 않은 래그는 뚜렷한 형태를 만들어 산만함
- 디자인에서는 하이픈네이션 설정과 행 길이를 조정해 좋은 래그를 얻으려 하지만, 보통은 디자이너들이 말하는 "두 더 래그(doing the rag)" — 소프트 리턴과 하이픈으로 줄바꿈을 수동으로 만드는 작업을 하게 됨
- 양쪽 정렬(justified) 텍스트를 조판할 때도 같은 줄바꿈 규칙이 적용됨 — 사실 흰 공간이 세로로 이어지는 "리버(river)"가 생길 위험 때문에 양쪽 정렬 텍스트의 줄바꿈은 오히려 더 까다로움

### 하이픈과 대시의 종류
- 단어를 나눠 줄바꿈을 만드는 것 외에, 하이픈은 left-wing이나 pre-owned 같은 복합어에도 사용됨
- **엔 대시(en dash)**는 하이픈보다 길며(M의 절반 길이), 범위를 나타낼 때 사용 — "to"라는 단어를 쓸 법한 곳(예: July to August, six to seven feet)에 사용
- **엠 대시(em dash)**는 더 길며(1엠 길이), 쉼표처럼 텍스트 안에서 구절을 구분하는 데 사용됨 — 인용문을 화자에게 귀속시키는 데도 사용
- 대시를 잘못 사용하는 것은 디자이너들이 즐겨 지적하는 흔한 타이포그래피 오류 중 하나

### 인용부호 vs 피트/인치 기호
- 또 다른 흔한 오류는 피트·인치 기호와 인용부호를 혼동하는 것 — 실제로는 상당히 다름
- 피트·인치 기호는 쐐기 모양(직선)이고, 작은따옴표·큰따옴표는 곡선이며 좌우 쌍으로 이루어짐
- 디자인 소프트웨어에는 인용문 주위에 자동으로 올바른 부호를 넣어주는 "스마트 따옴표(smart quotes)" 옵션이 있음

### 숫자체(Figures)의 네 가지 종류
- 대부분의 동시대 텍스트 타입페이스는 네 가지 다른 종류의 숫자(피겨)를 가짐
- 우리에게 익숙한 피겨는 **라이닝 피겨(lining figures)** — 대문자처럼 베이스라인에서 시작해 캡-높이에서 끝남
- 더 전통적인 형태는 **올드스타일 피겨(old style figures)** — 소문자처럼 어센더와 디센더를 가짐
- 어느 것을 쓸지는 쉽게 기억할 수 있음: 대문자가 쓰이는 곳(제목 등)에는 라이닝 피겨를, 소문자가 쓰이는 곳(본문 등)에는 올드스타일 피겨를 사용
- 피겨는 또한 **프로포셔널(proportional)**과 **테뷸러(tabular)** 버전으로도 나뉨 — 프로포셔널 피겨는 다른 문자처럼 간격이 배정되어 어떤 숫자는 더 넓고 어떤 숫자는 더 좁은 공간을 차지하고, 테뷸러 피겨는 모노스페이스라 모든 숫자가 같은 수평 공간을 차지함. 테뷸러 피겨는 차트나 수학 방정식처럼 숫자를 수직으로 맞춰야 할 때 유용

### 스몰캡스(Small Caps)와 리게처(Ligature)
- 텍스트용 버전과 타이틀용 버전이 있는 것은 피겨뿐 아니라 대문자도 마찬가지 — 텍스트에 조판하기 위한 대문자를 **스몰캡스(small caps)**라 부름
- 스몰캡스는 일반 대문자의 형태를 가지지만 높이는 소문자의 x-높이에 가까움 — 약어(acronym)처럼 텍스트 안에서 전부 대문자로 나타나는 곳 어디에나 스몰캡스를 사용 — 예외는 사람 이니셜로, 이는 항상 일반 대문자로 표기
- 텍스트에 매끄러운 외양을 주기 위해 디자인된 또 다른 문자 세트는 **리게처(ligature)** — 하나의 문자처럼 연결된 두 글자 형태. 대부분의 타입페이스는 기본적인 리게처를 포함하며, 일부는 더 많은 리게처를 포함하기도 함

### 마무리
- 이 모든 관습은 다소 난해해 보일 수 있지만, 지난 몇 영상에서 다룬 공간적·조직적 원리와 결합되면 타이포그래피에 최종적인 전문적 완성도를 더해줌

## 요약
- 줄바꿈 관습: 하이픈은 음절 사이 3글자 이상, 1~2글자 단어는 줄 끝에 남기지 않기, 오펀·위도우 방지, 래그는 원뿔형으로 고르게
- 문장부호 관습: 엔 대시(범위), 엠 대시(구절 구분), 피트/인치 기호와 인용부호의 구별(스마트 따옴표 활용)
- 숫자·대문자 관습: 라이닝 피겨(제목)/올드스타일 피겨(본문), 프로포셔널/테뷸러 피겨, 스몰캡스(텍스트 내 약어), 리게처(매끄러운 문자 연결)
- 이런 관습들은 공간적·조직적 원리와 결합되어 타이포그래피에 전문적 완성도를 더함
