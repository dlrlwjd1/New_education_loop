# 17 Reading: Optional Project — Typeset an Article for Print (읽기자료, 선택 프로젝트 안내)

## 개요
- Module 2의 타입페이스 리서치를 매거진 스프레드 형식으로 레이아웃·조판해보는 선택 프로젝트를 안내하는 2분 29초 분량 읽기자료(비디오 형식) — 예상 소요 시간 2~3시간

## 내용

### 프로젝트 개요
- 중요: 이 프로젝트는 매우 유사한 두 선택 프로젝트("Typeset an Article for Print"와 "Typeset an Article for Screen") 중 첫 번째 — 둘 다 완료해도 되고, 하나만 해도 되고, 둘 다 건너뛰어도 됨
- 이 프로젝트는 Module 2의 'Get to Know a Typeface' 프로젝트에서 만든 타입페이스 리서치를 매거진 스프레드 형식으로 레이아웃·조판해보도록 초대함 — 타이포그래피 공간 조작, 위계 만들기, 그리드 구축, 조판의 규칙·관습 적용을 인쇄 디자인 맥락에서 직접 경험해볼 수 있음

### 프로젝트 지침
1. 선택한 레이아웃 소프트웨어에서 마주보는 페이지(facing pages)가 있는 8.5×11인치(레터 사이즈) 문서를 만들 것. 'Get to Know a Typeface' 프로젝트에서 만든 이미지와 텍스트를 이 문서의 한 스프레드(마주보는 두 페이지)에 배치
2. 작성한 글의 텍스트부터 시작해 타입 크기·리딩·트래킹·행 길이·정렬을 가지고 놀아볼 것 — 타입 크기는 9~11포인트 범위로 유지. 지난 몇 영상에서 소개한 조판 원리와 관습을 염두에 두고, 읽기 쉽고 매력적인 조판을 만드는 것을 목표로 할 것
3. 텍스트 세팅을 다듬었다면, 텍스트의 각 요소(제목·부제·본문·출처 등)에 타입 스타일·크기·굵기·색·리딩이라는 변수를 사용해 서로 다른 스타일과 시각적 중요도 수준을 부여함으로써 위계를 만들 것
4. 이미지를 조합에 가져와 스프레드를 구성하는 방법을 탐색할 것 — 순서·위계·근접성/그룹핑을 사용해 콘텐츠에 맞게 텍스트와 이미지를 조직할 것. 시각적으로 역동적인 구성을 만들기 위해 음의 공간과 정렬도 고려할 것
5. 요소들을 서로 깔끔하게 정렬하는 데 도움이 될 페이지 그리드를 만들 것 — 최소 0.5인치의 여백부터 시작한 다음 칼럼을 만들 것. 텍스트가 단일 칼럼이더라도 칼럼 그리드는 요소를 구조적으로 배치하는 데 도움이 됨
6. 타이포그래피의 세부를 다듬을 것 — 줄바꿈을 정돈하고, 인용부호·대시·리게처·피겨·대문자를 올바르게 사용하고 있는지 다시 확인할 것

### 작업물 공유
- 최종 스프레드 디자인을 JPEG 이미지로 내보내 그룹과 공유할 것 — 언제나처럼 동료들에게 피드백을 요청하거나, 작업 과정을 공유하거나, 다른 사람의 작업에 댓글을 다는 것도 환영

## 요약
- 이 선택 프로젝트는 Module 2의 타입페이스 리서치 콘텐츠를 활용해, Module 3에서 배운 타이포그래피 공간·위계·그리드·관습을 모두 종합해 실제 매거진 스프레드로 완성해보는 실습
- 'Typeset an Article for Screen'과 짝을 이루는 프로젝트로, 같은 콘텐츠를 인쇄 vs 화면이라는 다른 맥락에 조판해보는 비교 학습이 가능
