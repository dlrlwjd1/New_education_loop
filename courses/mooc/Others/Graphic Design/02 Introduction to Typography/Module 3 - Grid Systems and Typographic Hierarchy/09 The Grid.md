# 09 The Grid (영상)

## 개요
- 페이지·화면 공간에 구조를 정의하고 요소를 그 구조에 정렬시키는 그리드의 역사와 구성 요소를 다루는 4분 6초 분량 영상

## 내용

### 그리드란
- 타이포그래피 구성을 정제되어 보이게 만드는 한 가지 방법은 페이지나 화면 공간에 구조를 정의하고, 구성의 요소들을 그 구조에 정렬시키는 것 — 타이포그래피에서 이 구조를 **그리드(grid)**라 부름
- 사람들은 인쇄의 초창기부터, 그리고 그 이전부터 다양한 형태의 그리드를 사용해왔음

### 역사 — 중국 필사본에서 황금비까지
- 전통 중국 필사본에서는 텍스트가 동일한 너비의 칼럼에 배열되고, 각 글자는 칼럼 안에서 완벽한 정사각형 공간을 차지
- 중세 유럽에서는 책의 페이지가 **황금비(golden ratio)**라는 특별한 수학적 비례로 정의된 여백으로 레이아웃되기도 함 — 필경사와 이후의 식자공들은 이 여백을 측정하기 위해 선(line) 시스템을 자주 사용
- 이 시스템은 페이지 상·하·좌·우에서 서로 다른 너비의 여백을 만들어냄으로써, 정적이기보다 역동적인 느낌의 구성을 만들어냄

### 20세기의 계승 — 치홀트와 스위스 학파
- 약 1.618의 비율인 황금비는 20세기에도 타이포그래피 구성에 계속 영향을 미침
- 1920년대 산세리프 타입을 옹호했던 독일 타이포그래퍼 얀 치홀트는 중세 필사본을 연구했고, 자신의 구성에 황금비를 자주 적용 — 예: 1938년 포스터에서 치홀트는 이 비율에 기반한 구조와의 관계 속에서 요소들을 배치
- 20세기 중반 스위스 Neue Grafik 운동의 디자이너들은 그리드 사용을 정제해 고도로 조직화된 시각적 구조를 만듦 — 요제프 뮐러브로크만의 1955년 포스터와 저널 Neue Grafik의 스프레드가 그 예시
- 그리드를 정의하고 사용하는 것은 시각적으로 정제된 느낌의 구성을 만드는 데 도움을 줌

### 출판물에서 그리드의 유용성
- 그리드는 특히 출판물에서 유용 — 각 스프레드가 다음 스프레드와 하나로 이어지는 느낌을 만드는 데 도움을 줌
- 고전적인 페이지 그리드의 구성 요소들:
  - **여백(margin)**: 페이지의 주 인쇄 영역 경계를 정의. 책의 여백을 설정할 때는 안쪽 여백이 책등(spine)에 해당한다는 점을 기억해야 함 — 제본 방식에 따라 이 여백을 넉넉하게 잡는 것이 좋음
  - **행 라인(hang line)**: 텍스트나 새 챕터가 시작될 수 있는 페이지 위의 특정 지점
  - **칼럼(column)**: 큰 판형의 출판물은 행 길이를 적절하게 유지하기 위해 여러 칼럼을 사용하는 경우가 많음. 이 칼럼들은 다시 세분되어, 디자이너가 여러 칼럼에 걸치는 등 다양한 너비의 텍스트 블록을 만들 수 있는 유연성을 갖게 됨
  - **거터(gutter)**: 칼럼 사이의 공간 — 흔히 거터의 너비는 타입 리딩의 크기로 설정됨
  - **베이스라인 그리드(baseline grid)**: 인접한 칼럼과 이어지는 페이지의 텍스트 줄들이 서로 정렬되도록 보장하는 데 사용 — 이 선들의 간격은 타입의 리딩으로 정의됨

### 오늘날의 그리드 — 웹과 실용적 조언
- 오늘날 그리드는 타이포그래피가 있는 거의 모든 곳에 존재 — 웹에서는 흔히 CSS 안에 실제로 내장되어 있음
- 그리드 시스템을 다루는 이 사이트에서 사용하는 것 같은 인기 있는 웹사이트 그리드는 960픽셀 너비에 6, 12, 혹은 16개 칼럼으로 구성됨
- 그리드는 매우 유용한 도구이지만, 잘못 사용되거나 지나치게 많이 사용되면 구성을 제한하고 제약할 수 있음
- 그래서 항상 그리드 없이 구성을 시작한 뒤, 무엇을 하고 싶은지 파악한 다음, 다시 돌아가 정렬을 정제하고 거리를 일관되게 만들어줄 그리드를 역설계할 것을 권장
- 그리고 그리드가 필요하지 않거나 심지어 적절하지도 않은 경우가 많다는 것을 항상 기억할 것

## 요약
- 그리드는 페이지/화면 공간에 구조를 부여해 정제된 구성을 만드는 도구이며, 중국 필사본의 등폭 칼럼부터 중세 유럽의 황금비 여백, 치홀트와 스위스 Neue Grafik 학파를 거쳐 오늘날 웹 CSS 그리드(예: 960px, 6/12/16 칼럼)까지 이어지는 긴 역사를 가짐
- 고전적 페이지 그리드는 여백·행 라인·칼럼·거터·베이스라인 그리드로 구성되며, 거터와 베이스라인 간격은 흔히 리딩 크기로 설정됨
- 실용적 조언: 그리드 없이 구성을 시작한 뒤 나중에 역설계하는 편이 낫고, 그리드가 항상 필요하거나 적절한 것은 아님을 기억할 것
