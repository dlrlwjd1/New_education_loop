# 14 Reading: Optional Activity — Analyze a Newspaper (읽기자료, 선택 실습 안내)

## 개요
- 실제 신문의 타이포그래피 위계를 직접 분석해보는 선택 실습을 안내하는 2분 8초 분량 읽기자료(비디오 형식) — 예상 소요 시간 1.5시간

## 내용

### 왜 신문인가
- 신문은 다양한 종류의 정보를 조직하고 접근 가능하게 만들도록 디자인되었기 때문에 훌륭한 타이포그래피 사례 연구가 됨 — 이는 신중한 타이포그래피 위계 사용을 통해 달성됨
- 이 선택 실습은 인쇄물이든 온라인이든 실제 신문의 타이포그래피 위계를 연구·분석해보도록 초대함 — 타이포그래피 위계가 실제로 어떻게 작동하는지에 대해 훨씬 풍부한 이해를 줄 고전적인 타이포그래피 연습이며, 발견하는 내용에 놀랄 수도 있음

### 실습 지침
1. 분석하고 싶은 신문을 찾을 것 — 어떤 언어의 어떤 주류 신문이든 사용 가능. 온라인 신문이라면 랜딩(메인) 페이지를 스크린샷하거나 내보내고, 인쇄 신문이라면 1면을 뜯어 분석에 사용
2. 1면에서 보이는 모든 타이포그래피 스타일을 글로 하나하나 나열할 것 — 예시로 든 USA Today 1면에는 약 35개의 스타일이 있었음. 여러 개의 '헤딩' 스타일, 여러 개의 '서브헤딩' 스타일 등이 있을 수 있는데, 이런 스타일은 위계상 위치 순서로 번호를 매기는 것이 관례 — 즉 "Heading 1"은 가장 중요한 헤드라인, "Heading 2"는 두 번째로 중요한 헤드라인 순
3. 페이지의 모든 스타일을 나열했다면, 지금까지 배운 타이포그래피 용어를 사용해 각 스타일에 대한 언어적 설명을 추가할 것 — 예를 들어 위 예시의 'Heading 1'을 "72pt 볼드 산세리프"로 기술할 수 있음(포인트 크기는 추정하거나 Module 1에서 만든 스페시먼을 참고)
4. 발견한 내용을 성찰할 것: 몇 가지 다른 타입 스타일을 식별했는가? 한 스타일을 다음 스타일과 구별하는 데 어떤 스타일적 변수가 사용되었는가? 전체적으로 응집력 있는 느낌을 유지하는 스타일적 상수는 무엇이었는가?

### 관찰 결과 공유
- 놀랍거나 인상적이었던 점을 발견했다면 포럼에 생각을 공유할 것 — 분석한 페이지의 이미지를 함께 올려도 좋고, 다른 사람들의 발견에 자유롭게 응답할 것
