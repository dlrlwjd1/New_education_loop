# 05 Reading: A Kerning Challenge! (읽기자료)

## 개요
- 레터스페이싱을 "구슬(marble)" 비유로 직관적으로 이해하고, 온라인 게임으로 직접 연습해보도록 안내하는 1분 15초 분량 읽기자료(비디오 형식)

## 내용

### 공간 관계를 연습하는 출발점 — 레터스페이싱
- 지난 영상에서 설명했듯, 타이포그래피의 많은 부분은 트래킹·리딩·행 길이를 통해 글자와 단어의 안팎 공간을 조작하는 것에 관한 것
- 타이포그래피를 연습하다 보면 이런 공간적 관계에 점점 더 민감해지게 되며, 연습을 시작하기 가장 좋은 곳은 한 단어 안에서 글자들 사이의 관계, 즉 **레터스페이싱**을 탐구하는 것

### 구슬(Marble) 비유
- 레터스페이싱은 타입 디자이너가 폰트 파일에 프로그래밍해두는 것이라 수동으로 조정(커닝)할 필요가 있는 경우는 드묾 — 그래도 레터스페이싱을 자세히 들여다보는 것은 유익함
- 타입 디자이너가 글자 간격을 정할 때는 글자 형태 안쪽 공간과 글자 사이 공간의 균형을 맞추려 함
- 타입 디자인에서 흔한 연습법: 글자 사이와 안쪽 공간에 구슬을 떨어뜨린다고 상상하는 것 — 대략 각 공간에 비슷한 개수의 구슬이 들어가야 함
- 예시 이미지: 단어 "hot"의 글자 안팎 공간이 주황색 구슬로 채워진 일러스트레이션 — 이 비유가 다소 느슨하게 적용되긴 하지만, 균형 잡힌 레터스페이싱이 어떤 모습인지 이해하는 데 도움이 됨

### 직접 연습해보기 — Kerntype
- 레터스페이싱을 직접 연습해보고 싶다면 타이포그래퍼를 위한 재미있는 온라인 게임 **Kerntype**으로 연습할 수 있음
- 즐기되 너무 진지하게 받아들이지 말 것 — 공간적 관계는 언제나 다소 주관적이기 때문

## 요약
- 균형 잡힌 레터스페이싱은 "글자 사이·안쪽 공간에 비슷한 수의 구슬이 들어간다"는 비유로 직관적으로 이해할 수 있음
- 레터스페이싱은 보통 폰트에 이미 프로그래밍되어 있어 수동 조정(커닝)이 필요한 경우는 드물지만, Kerntype 같은 게임으로 감각을 직접 연습해볼 수 있음
