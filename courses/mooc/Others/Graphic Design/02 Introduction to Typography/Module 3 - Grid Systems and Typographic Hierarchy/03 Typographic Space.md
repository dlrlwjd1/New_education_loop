# 03 Typographic Space (영상)

## 개요
- 타이포그래피 공간을 구성하는 핵심 용어(레터스페이싱·트래킹·커닝·리딩·행 길이·정렬)를 다루는 5분 56초 분량 영상

## 내용

### 타이포그래피는 타입만큼이나 공간의 문제
- 타이포그래피는 타입 자체를 만드는 것만큼이나 글자·단어·텍스트 블록 사이·주변의 공간을 만드는 것에 관한 것
- 타이포그래피에는 다양한 종류의 공간을 가리키는 용어와, 이 공간들이 서로 어떻게 관계 맺어야 하는지를 규정하는 원칙이 있음

### 레터스페이싱(Letter Spacing)과 트래킹(Tracking)
- 타입페이스 안에서 글자들 사이의 간격은 **레터스페이싱(letter spacing)**이라 부름 — 타입 디자이너가 폰트 파일에 직접 프로그래밍하며, 일반적으로 글자 사이의 공간과 글자 안쪽 공간(카운터)의 균형을 맞추려 함
- 조판에서 단어·문장·문단의 글자 사이 공간을 더하거나 빼는 것은 **트래킹(tracking)**
- 9포인트 이하 작은 크기로 조판할 때는 약간의 트래킹(10~20유닛)을 더하면 더 명확하게 판독 가능해질 수 있음
- 반대로 큰 크기에서 트래킹을 너무 많이 주면 글자들이 단어로서 뭉치지 않아 시각적으로 흩어짐 — 큰 제목을 조판할 때는 오히려 원래 레터스페이싱보다 글자를 더 가깝게 붙이는 **음의 트래킹(negative tracking)**을 원할 수 있음
- 추가 트래킹이 항상 적절한 곳이 하나 있는데, 바로 **전체 대문자(all uppercase)** 조판 — 대문자는 보통 소문자와 나란히 나타나므로 소문자의 더 좁은 간격에 맞춰 디자인되어 있음. 따라서 대문자끼리만 조판할 때는 20~50유닛 정도의 트래킹을 추가해야 함

### 커닝(Kerning)
- 전체 트래킹과 무관하게 특정 두 글자 사이의 간격을 조정하는 것은 **커닝(kerning)**
- 두 글자가 어색하게 맞물릴 때 커닝이 필요한 경우가 있음 — 예를 들어 대문자 A와 v의 형태 때문에 이 둘 사이에 거슬리는 여분의 공간이 생기면 더 가깝게 커닝
- 요즘 타입페이스는 문제가 되는 글자 조합에 대해 커닝이 미리 프로그래밍되어 있어, 수동 커닝이 필요한 경우는 드묾

### 리딩(Leading)
- 문단 안에서 줄과 줄 사이, 즉 한 베이스라인과 다음 베이스라인 사이의 공간은 **리딩(leading)**이라 부름 — 활판 인쇄 시절 줄 사이에 끼워 넣던 납(lead) 조각 스트립에서 유래한 이름
- 특정 조판 설정은 타입 크기와 리딩의 조합으로 기술됨 — 예를 들어 책 본문의 일반적인 설정은 9포인트 타입에 12포인트 리딩이며, 이를 "9/12"로 표기
- 적절한 리딩을 정하는 쉬운 규칙은 없지만, 원칙은 줄들을 눈이 명확히 구분할 수 있을 만큼 충분히 떨어뜨리되, 문단을 하나의 덩어리로 볼 수 있을 만큼은 충분히 가깝게 유지하는 것
- 리딩이 너무 적으면 눈이 줄을 따라가다 위아래 줄과 헷갈리기 쉽고, 너무 많으면 줄은 뚜렷이 구분되지만 문단이 하나의 시각적으로 응집된 덩어리로 유지되지 못함
- 타입페이스의 x-높이도 리딩에 영향을 미침 — x-높이가 큰 타입페이스는 시각적으로 더 커 보이므로 더 많은 리딩이 필요함. 같은 9/12로 설정해도 x-높이가 작은 타입페이스는 상대적으로 리딩이 더 많아 보이는 느낌을 줌

### 행 길이(Line Length)
- 이 공간적 관계의 매트릭스에서 또 다른 요인은 **행 길이** — 한 줄에 들어가는 평균 글자 수로 측정
- 좋은 행 길이는 몇 단어마다 새 줄을 시작할 필요가 없을 만큼 충분히 길되, 한 줄 끝에서 다음 줄 시작을 쉽게 찾을 수 있을 만큼은 충분히 짧아야 함
- 한 줄당 66자가 흔히 행 길이의 스위트 스폿으로 여겨지지만, 최대 80자까지도 괜찮고, 더 좁은 칼럼이라면 40자까지 내려가도 괜찮음
- 행 길이는 리딩에도 영향을 미침 — 줄이 길수록 독자의 눈이 줄을 따라가도록 돕기 위해 줄 사이에 더 많은 공간이 필요할 수 있음

### 정렬(Text Alignment)
- 마지막 변수는 텍스트 정렬 — 텍스트가 왼쪽에는 정렬되고 오른쪽에는 정렬되지 않은 것을 **왼쪽 정렬(left aligned)**이라 함
- 이 방식의 장점은 타입페이스 고유의 레터스페이싱과 단어 간격을 그대로 보존할 수 있다는 것 — 단점은 텍스트 한쪽 가장자리를 고르지 못하게 만드는 **래그(rag)**가 생긴다는 것(래그를 시각적으로 보기 좋게 다듬는 법은 다음 영상에서 다룸)
- 왼쪽 정렬의 대안은 좌우 양쪽 모두 정렬되는 **양쪽 정렬(justified text)** — 장점은 양쪽 가장자리가 고르게 맞춰진다는 것, 단점은 긴 줄은 짧게, 짧은 줄은 길게 만들기 위해 단어 간격이나 트래킹을 조정해야 한다는 것 — 이는 줄을 깨뜨려 문단을 관통하는 수직 통로(채널)를 만들 수 있고, 이를 보정하려면 리딩을 늘려야 함

### 서로 영향을 주고받는 변수들
- 타이포그래피 공간을 정의하는 변수들 — 트래킹, 리딩, 행 길이, 정렬 — 은 모두 서로 영향을 미침
- 타이포그래퍼로서 타입을 다룰 때 이 모든 공간적 관계를 충분히 의식하는 것이 중요함

## 요약
- 타이포그래피 공간의 핵심 용어: 레터스페이싱(폰트에 내장) → 트래킹(전체 글자 간격 조정) → 커닝(특정 글자쌍 조정) → 리딩(줄 간격, x-높이에 영향받음) → 행 길이(66자가 표준) → 정렬(왼쪽 정렬의 래그 vs 양쪽 정렬의 공간 조정)
- 모든 변수는 서로 상호작용하므로(예: 행 길이가 길어지면 리딩도 늘려야 함), 개별 변수가 아니라 전체 매트릭스로 이해해야 함
