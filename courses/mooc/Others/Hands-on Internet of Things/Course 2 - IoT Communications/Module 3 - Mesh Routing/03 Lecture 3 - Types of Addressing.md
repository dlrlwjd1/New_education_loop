# Lecture 3 -  Types of Addressing

> MOOC video · [원본 학습 항목](https://www.mooc.org/learn/iot-communications/lecture/uM75d/lecture-3-types-of-addressing)

## 개요
- 단일 장치의 다른 인터페이스로 라우팅하고 싶을 수도 있고 그렇지 않을 수도 있습니다.

## 내용
- 단일 장치의 다른 인터페이스로 라우팅하고 싶을 수도 있고 그렇지 않을 수도 있습니다.
- 아마도 우리는 여러 장치나 다른 논리적 노드를 통해 네트워크에 접속할 수 있는 사람에게 라우팅하거나 그 이상의 응용 프로그램별 이벤트로 구성하려는 것일 수도 있습니다.
- 고유하지 않다는 개념도 있습니다.서비스로 라우팅하고 싶은데 서비스가 어떤 특정 노드에 있는지 신경 쓰지 않을 수도 있습니다.
- 하드웨어 주소 지정, 지리적, 계층적 주소 지정, 확률적 주소 지정, 그리고 먼저 하드웨어 주소 지정에 대해 이야기하겠습니다.
- 그래서 제가 하드웨어 어드레싱이라고 부르는 것은 이러한 장치나 인터페이스 등 원하는 모든 것을 갖추고 있고 여기에 주소를 할당하면 하드웨어에 영향을 준다는 개념입니다.
- 예를 들어 노트북이나 컴퓨터 또는 2.11 Wi-Fi를 사용하는 거의 모든 장치를 사용하는 경우 해당 네트워크 인터페이스 카드에는 출하 시 입력된 MAC 주소가 있습니다.
- MAC 주소의 경우 상위 비트 청크는 공급업체를 나타내는 데 사용되고 그 공급업체는 하위 비트를 모두 지정하면 해당 비트를 생산 라인의 노드에 할당하려는 모든 사람에게 사용할 수 있습니다.

## 예시
- 예를 들어 노트북이나 컴퓨터 또는 2.11 Wi-Fi를 사용하는 거의 모든 장치를 사용하는 경우 해당 네트워크 인터페이스 카드에는 출하 시 입력된 MAC 주소가 있습니다.

## 요약
- 예를 들어 노트북이나 컴퓨터 또는 2.11 Wi-Fi를 사용하는 거의 모든 장치를 사용하는 경우 해당 네트워크 인터페이스 카드에는 출하 시 입력된 MAC 주소가 있습니다. MAC 주소의 경우 상위 비트 청크는 공급업체를 나타내는 데 사용되고 그 공급업체는 하위 비트를 모두 지정하면 해당 비트를 생산 라인의 노드에 할당하려는 모든 사람에게 사용할 수 있습니다.
