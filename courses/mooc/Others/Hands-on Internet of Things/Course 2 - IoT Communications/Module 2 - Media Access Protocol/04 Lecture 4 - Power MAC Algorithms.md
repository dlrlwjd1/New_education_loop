# Lecture 4 -  Power MAC Algorithms

> MOOC video · [원본 학습 항목](https://www.mooc.org/learn/iot-communications/lecture/rtAUB/lecture-4-power-mac-algorithms)

## 개요
- 그렇다면 문제가 생겼습니다.절전 모드인 경우 데이터를 수신할 수 없고, 절전 모드의 라디오인 경우 데이터를 수신할 수 없습니다.

## 내용
- 그렇다면 문제가 생겼습니다.절전 모드인 경우 데이터를 수신할 수 없고, 절전 모드의 라디오인 경우 데이터를 수신할 수 없습니다.
- 따라서 노드가 언제 휴면 모드로 전환되고 어떻게 휴면 모드로 전환되는지를 조정할 방법이 필요합니다.
- 예를 들어 휴면 모드에서는 알고리즘이 모든 노드가 항상 깨어 있고 항상 수신 중이라고 가정하기 때문에 충돌 감지와 충돌 회피 기능이 작동하지 않습니다.
- 우리가 할 수 있는 한 가지는 노드가 깨어날 때와 휴면 모드로 전환될 때를 동기화하는 것입니다.
- 왜냐하면 모든 노드가 동의했기 때문에 다른 노드가 언제 깨어날지 알 수 있기 때문입니다.
- 그래서 여기서 중요한 것은 이런 모든 종류의 사람들이 잠에서 깨고 동시에 잠에 들어간다는 것입니다.취침 시간에 데이터를 주고받을 수 있는 활동 시간으로, 잘 수 있는 시간이라는 점에는 모두 동의합니다.
- 이런 종류의 비콘이 울리게 할 수는 있지만 비콘이 울리기 전에 노드를 깨울 수 있는 일종의 조정 방법이 필요하죠.이에 대해서는 다음에 설명하도록 하겠습니다.

## 예시
- 예를 들어, 사용자가 노드이고 다른 노드로 데이터를 전송하려고 하는데 해당 노드가 휴면 상태라고 가정해 보겠습니다.
