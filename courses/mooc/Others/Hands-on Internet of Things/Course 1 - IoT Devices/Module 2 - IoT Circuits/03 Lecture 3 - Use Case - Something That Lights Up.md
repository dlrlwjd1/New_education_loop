# Lecture 3 -  Use Case -  Something That Lights Up

> MOOC video · [원본 학습 항목](https://www.mooc.org/learn/iot-devices-il/lecture/CTLUc/lecture-3-use-case-something-that-lights-up)

## 개요
- 지금까지 전기 흐름을 측정하는 데 사용할 수 있는 다양한 측정 기준, 구성 요소, 구성 요소, 구성 요소 연결 방법 등에 대해 이야기했습니다.

## 내용
- 지금까지 전기 흐름을 측정하는 데 사용할 수 있는 다양한 측정 기준, 구성 요소, 구성 요소, 구성 요소 연결 방법 등에 대해 이야기했습니다.
- 따라서 IoT 장치를 구축할 때 흔히 볼 수 있는 일련의 실제 사용 사례에 대해 이야기한 다음, 이러한 제품 및 시스템의 설계 방식에 대한 직관적인 이해를 돕기 위해 이러한 사용 사례를 해결하는 데 사용할 수 있는 구성 요소 집합에 대해 설명하겠습니다.
- 예를 들어, 빛을 발하는 무언가를 만들고 싶다고 가정해 봅시다.기기의 상태를 나타내는 무언가를 만들거나, 사용자의 체온을 표시하는 스마트 스웨터를 만들거나, 기기에 대한 정보를 표시하는 디스플레이가 있는 기기를 만들고 싶습니다.
- 또한 아주 작은 광점이 있는 다양한 디스플레이가 있는데, 이를 다양한 방식으로 제어하여 이미지를 표시할 수 있습니다.
- 따라서 빛을 사용하여 정보를 전달하거나 조명을 생성하는 다양한 구성 요소가 있습니다.
- 따라서 이러한 다양한 구성 요소에 대해 생각해 볼 때, 두 구성 요소 중에서 선택할 때 서로 다르기 때문에 여기서 중요한 특정 지표가 있습니다.
- 따라서 구성 요소를 선택할 때 어떤 메트릭이 중요한지 생각하고 이러한 메트릭에 대해 어떤 값을 중요하게 생각하는지 생각해 본 다음 해당 값을 포함하는 구성 요소를 선택할 수 있습니다.

## 예시
- 이러한 것들이 어떻게 적용되는지 이해할 수 있도록 좀 더 적용하기 위해 일련의 사용 사례의 맥락에서 이에 대해 이야기하고자 합니다.

## 요약
- 따라서 이러한 다양한 구성 요소에 대해 생각해 볼 때, 두 구성 요소 중에서 선택할 때 서로 다르기 때문에 여기서 중요한 특정 지표가 있습니다. 따라서 구성 요소를 선택할 때 어떤 메트릭이 중요한지 생각하고 이러한 메트릭에 대해 어떤 값을 중요하게 생각하는지 생각해 본 다음 해당 값을 포함하는 구성 요소를 선택할 수 있습니다.
