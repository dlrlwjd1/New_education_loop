# Lecture 5 -  Programmable Circuits

> MOOC video · [원본 학습 항목](https://www.mooc.org/learn/iot-devices-il/lecture/FKxlx/lecture-5-programmable-circuits)

## 개요
- 로직 게이트뿐만 아니라 기본 로직 외에도 ROM과 RAM, 전기적으로 지울 수 있는 ROM, 플래시 메모리, 기타 구성 요소 등을 포함할 수 있습니다.

## 내용
- 로직 게이트뿐만 아니라 기본 로직 외에도 ROM과 RAM, 전기적으로 지울 수 있는 ROM, 플래시 메모리, 기타 구성 요소 등을 포함할 수 있습니다.
- 따라서 일반적인 설계는 ASIC를 사용하고 CPU용 IP 코어를 장착하고 디지털 신호 프로세서, 통신 인터페이스, 메모리 등을 장착하는 것과 같은 작업을 수행하는 것입니다.
- 따라서 대부분의 GPU는 고도로 병렬화된 CPU와 같이 많은 스레드를 사용하여 구축됩니다.또한 500개 또는 1,000개 정도의 스레드 또는 스트림 프로세서가 있을 수 있으며 모두 이미지 상에서 병렬로 작동할 수 있습니다.
- 그래서 시스템과 칩, FPGA, GPU 같은 것들은 현재 시중에 나와 있는 여러 가지 기술들인데 IoT와 관련하여 매우 널리 사용되고 있습니다.
- 신경망은 많은 응용 분야에서 유용하지만 기계 학습에는 다른 알고리즘이 있고 때로는 기계 학습 처리를 위해 일반 플랫폼이 필요하다는 것을 알고 있습니다.
- 따라서 ALU나 오디오 처리 장치 같은 것을 원한다면 셀 라이브러리를 다운로드해서 이런 다양한 것들을 다운로드할 수 있고 IDE를 이용해서 서로 연결해서 사용할 수 있습니다.
- 따라서 일반적으로 IoT 장치 또는 일반 계산을 구축하는 방법은 SRAM을 계산 단위 근처에 두고 더 큰 백업 저장소가 필요한 경우 DRAM을 더 멀리 배치하는 것입니다.

## 예시
- 애플리케이션별 집적 회로는 집적 회로를 구축할 여유가 있을 때, 특정 애플리케이션별 시나리오가 발생할 때 만드는 IC입니다.

## 요약
- 따라서 ALU나 오디오 처리 장치 같은 것을 원한다면 셀 라이브러리를 다운로드해서 이런 다양한 것들을 다운로드할 수 있고 IDE를 이용해서 서로 연결해서 사용할 수 있습니다. 따라서 일반적으로 IoT 장치 또는 일반 계산을 구축하는 방법은 SRAM을 계산 단위 근처에 두고 더 큰 백업 저장소가 필요한 경우 DRAM을 더 멀리 배치하는 것입니다.
