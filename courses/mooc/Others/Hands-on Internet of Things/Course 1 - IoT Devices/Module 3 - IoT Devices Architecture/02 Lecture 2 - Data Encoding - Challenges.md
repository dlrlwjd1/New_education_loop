# Lecture 2 -  Data Encoding -  Challenges

> MOOC video · [원본 학습 항목](https://www.mooc.org/learn/iot-devices-il/lecture/lDAm4/lecture-2-data-encoding-challenges)

## 개요
- 그래서 한 가지 아이디어는 기기와 구성 요소를 와이어로 연결하고 다른 쪽에서 읽을 수 있는 와이어의 속성을 변경할 수 있다는 것입니다.이 작업을 직관적으로 수행할 수 있는 방법인 것 같습니다.

## 내용
- 그래서 한 가지 아이디어는 기기와 구성 요소를 와이어로 연결하고 다른 쪽에서 읽을 수 있는 와이어의 속성을 변경할 수 있다는 것입니다.이 작업을 직관적으로 수행할 수 있는 방법인 것 같습니다.
- 유선으로 연결되어 있는 상태에서 다른 장치나 다른 구성 요소로 데이터를 전송하려는 경우 다른 방식으로 전기를 보내고 정보를 보낼 수 있습니다.
- 그래서 인코딩 방식과 통신 메커니즘을 설계할 때는 둘 중 하나를 사용할 수 있지만, 정보를 보내는 데 전압이 훨씬 더 효율적이기 때문에 모든 사람이 전압을 사용합니다.
- 전선을 통해 전류를 보낼 수 있지만 전선의 길이가 길수록 전선의 성능이 저하되고 전선을 통한 저항이 생기기 때문에 전류가 감소하고 많은 전류를 보낼 경우 더 많은 전기가 필요하고 정보를 보내는 데 더 많은 전기가 필요하기 때문입니다.
- 펄스와 클럭 라인의 잡음을 구분하기 위해 펄스를 높게 두는 시간을 두고 싶을 수도 있지만, 일반적으로 데이터 라인이 있고, 비트를 전송하고, 클럭 라인이 펄스를 사용하는데, 이렇게 계속 진행하게 됩니다.
- 송신자가 개별 클럭 신호를 전송하여 각 비트가 정확히 언제 발생하는지 알려주기 때문에 비트 전환이 정확히 언제 발생하는지 알 수 있기 때문에 모호성을 유발하는 긴 0 문자열에 대해 걱정할 필요가 없습니다.
- 그래서 그게 문제죠.또 다른 문제는 전압을 보내는 것보다 더 많은 전기를 보내서 다른 사람이나 회로에 전기를 보내는 경우 회로를 전기적으로 분리하기가 어렵다는 것입니다.

## 예시
- 그래서 사람들은 오래 전에 이 점을 생각해 보았고, 목표와 사용 사례에 따라 다른 전압 레벨을 선택했습니다.

## 요약
- 송신자가 개별 클럭 신호를 전송하여 각 비트가 정확히 언제 발생하는지 알려주기 때문에 비트 전환이 정확히 언제 발생하는지 알 수 있기 때문에 모호성을 유발하는 긴 0 문자열에 대해 걱정할 필요가 없습니다. 그래서 그게 문제죠.또 다른 문제는 전압을 보내는 것보다 더 많은 전기를 보내서 다른 사람이나 회로에 전기를 보내는 경우 회로를 전기적으로 분리하기가 어렵다는 것입니다.
