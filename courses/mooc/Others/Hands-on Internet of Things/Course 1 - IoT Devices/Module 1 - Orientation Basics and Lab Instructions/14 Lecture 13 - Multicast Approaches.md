# Lecture 13 -  Multicast Approaches

> MOOC video · [원본 학습 항목](https://www.mooc.org/learn/iot-devices-il/lecture/j8ecp/lecture-13-multicast-approaches)

## 개요
- 하지만 이러한 접근 방식은 배포 트리가 있거나 네트워크 전체에 백본을 구성해야 하는 다른 경우에도 적용됩니다.

## 내용
- 하지만 이러한 접근 방식은 배포 트리가 있거나 네트워크 전체에 백본을 구성해야 하는 다른 경우에도 적용됩니다.
- 예를 들어 멀티캐스트 그룹에 보내는 송신 역할을 하는 노드 F가 있는 경우 F에 뿌리를 둔 트리를 생성합니다.
- 그래서 멀티캐스트 그룹의 모든 노드에 도달하는 J를 기반으로 하는 또 다른 트리를 만들 것입니다.
- 따라서 이러한 트리를 구성하는 방법은 예를 들어 각 수신기에 대한 최단 경로 세트를 사용하는 것입니다.
- 이 방법의 장점은 멀티캐스트 그룹에서 해당 소스에 도달하는 가장 효율적인 방법으로 트리를 설계할 수 있기 때문에 매우 효율적인 트리를 얻을 수 있다는 것입니다.
- 단일 소스 트리를 사용하는 경우 해당 노드 꼭대기에 도달할 가능성이 더 높으며 노드는 깨어 있는 상태로 배터리를 사용해야 합니다.
- 따라서 여러 노드가 있는 환경에서 노드가 모두 연결되어 백본에 정보를 전달하는 스패닝 트리를 구성해야 합니다.

## 예시
- 예를 들어 멀티캐스트 그룹에 보내는 송신 역할을 하는 노드 F가 있는 경우 F에 뿌리를 둔 트리를 생성합니다.

## 요약
- 단일 소스 트리를 사용하는 경우 해당 노드 꼭대기에 도달할 가능성이 더 높으며 노드는 깨어 있는 상태로 배터리를 사용해야 합니다. 따라서 여러 노드가 있는 환경에서 노드가 모두 연결되어 백본에 정보를 전달하는 스패닝 트리를 구성해야 합니다.
