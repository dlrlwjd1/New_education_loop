# Lecture 4 -  Protocol Stacks

> MOOC video · [원본 학습 항목](https://www.mooc.org/learn/iot-devices-il/lecture/AhkwV/lecture-4-protocol-stacks)

## 개요
- 이메일, 웹과 같은 시스템이 있는데, 이러한 시스템에서는 HTTP와 같은 다양한 프로토콜을 사용하여 웹 페이지 정보를 전송하고 IMAP을 사용하여 이메일 정보를 인코딩하는 등의 다양한 프로토콜을 사용합니다.

## 내용
- 이메일, 웹과 같은 시스템이 있는데, 이러한 시스템에서는 HTTP와 같은 다양한 프로토콜을 사용하여 웹 페이지 정보를 전송하고 IMAP을 사용하여 이메일 정보를 인코딩하는 등의 다양한 프로토콜을 사용합니다.
- 이러한 프로토콜은 상위 계층인 애플리케이션 계층에서 데이터를 가져와 인코딩하고 캡슐화하여 네트워크를 통해 전송할 수 있도록 하는 프로토콜입니다.
- 따라서 네트워크를 설정하는 제어 프로토콜이 있지만 유용한 데이터를 실제로 보내는 것과는 관련이 없고 네트워크를 통해 데이터를 보내는 것과 관련된 데이터 프로토콜이 있습니다.
- 그래서 우리가 하는 일은 데이터를 전송할 때 프로토콜 스택을 구현하는 다양한 소프트웨어 계층을 통해 데이터를 전송하는 것입니다.
- 그런 다음 패킷은 데이터 링크와 물리적 계층으로 전송되며, 물리적 계층은 MAC 레벨 정보를 추가하여 추가로 캡슐화한 다음 패킷이 네트워크로 전송됩니다.
- 사람들은 일반적으로 레이어 2에서 포워딩을 수행하는 디바이스를 가리킬 때 스위치라는 용어를 사용하고, 레이어 3에서 포워딩을 수행하는 디바이스를 지칭할 때는 라우터라는 용어를 사용합니다.
- 따라서 네트워크를 구축할 때 네트워크에 필요한 다양한 기능과 이러한 기능이 작동해야 하는 여러 계층을 생각해 본 다음 이를 기반으로 결정을 내릴 수 있습니다.

## 예시
- 예를 들어 네트워크 중립성에 대해 들어 보셨다면 ISP가 데이터를 받아들이고 선택적으로 데이터를 걸러낼 수 있는지에 대한 논쟁이 벌어지고 있습니다.

## 요약
- 사람들은 일반적으로 레이어 2에서 포워딩을 수행하는 디바이스를 가리킬 때 스위치라는 용어를 사용하고, 레이어 3에서 포워딩을 수행하는 디바이스를 지칭할 때는 라우터라는 용어를 사용합니다. 따라서 네트워크를 구축할 때 네트워크에 필요한 다양한 기능과 이러한 기능이 작동해야 하는 여러 계층을 생각해 본 다음 이를 기반으로 결정을 내릴 수 있습니다.
