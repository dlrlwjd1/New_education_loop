# Lecture 8 -  Address Resolution Protocol

> MOOC video · [원본 학습 항목](https://www.mooc.org/learn/iot-networking/lecture/QiLMV/lecture-8-address-resolution-protocol)

## 개요
- 다음 LAN 홉에 대한 정보와 필요한 기타 모든 중간 주소에 대한 정보를 제공할 수 있다면 좋지 않을까요?

## 내용
- 다음 LAN 홉에 대한 정보와 필요한 기타 모든 중간 주소에 대한 정보를 제공할 수 있다면 좋지 않을까요?
- 여기에 네트워크가 있고 호스트가 여러 개 있고 각 호스트에 IP 주소와 MAC 주소가 있고 중간 스위치가 몇 개 있다고 가정해 보겠습니다.
- 따라서 4444로 향하는 패킷을 받으면 현재 LAN 홉을 통해 전송할 수 있도록 대상의 MAC 주소를 파악하는 작업을 수행해야 합니다.
- 모든 호스트가 로컬 검사를 수행합니다.그러면 제가 그 IP 주소를 소유하고 있는지 확인하겠죠.
- 따라서 이 프로세스는 작동하며 해당 서브넷의 모든 IP 주소에 적용됩니다.로컬 LAN의 로컬 서브넷에 있는 대상으로 전송하는 경우 해당 목적지를 발견하게 됩니다.
- 이 검사를 수행하는 방법은 각 호스트가 DHCP 또는 일부 수동 메커니즘을 통해 기본 게이트웨이의 IP 주소를 사용하여 구성되며 로컬 서브넷도 아는 것입니다.
- 호스트가 로컬 서브넷에 있는지 아니면 인터넷 외부의 원격 서브넷에 있는지 여부를 결정적으로 알 수 있습니다.

## 예시
- 호스트가 로컬 서브넷에 있는지 아니면 인터넷 외부의 원격 서브넷에 있는지 여부를 결정적으로 알 수 있습니다.

## 요약
- 이 검사를 수행하는 방법은 각 호스트가 DHCP 또는 일부 수동 메커니즘을 통해 기본 게이트웨이의 IP 주소를 사용하여 구성되며 로컬 서브넷도 아는 것입니다. 호스트가 로컬 서브넷에 있는지 아니면 인터넷 외부의 원격 서브넷에 있는지 여부를 결정적으로 알 수 있습니다.
