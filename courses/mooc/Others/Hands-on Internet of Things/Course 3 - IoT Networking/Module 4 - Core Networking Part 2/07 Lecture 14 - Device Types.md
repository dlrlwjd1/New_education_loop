# Lecture 14 -  Device Types

> MOOC video · [원본 학습 항목](https://www.mooc.org/learn/iot-networking/lecture/QBH7P/lecture-14-device-types)

## 개요
- 따라서 네트워크를 구축하는 방법을 제대로 이해하려면 네트워크에 적용할 수 있는 다양한 유형의 장치 또는 다양한 유형의 기능을 이해하는 것이 도움이 됩니다.

## 내용
- 따라서 네트워크를 구축하는 방법을 제대로 이해하려면 네트워크에 적용할 수 있는 다양한 유형의 장치 또는 다양한 유형의 기능을 이해하는 것이 도움이 됩니다.
- 또 다른 범주의 장치는 처리 장치입니다.이 장치들은 여러분이 패킷을 받아 가지고 뭔가를 하는 장치들입니다.이 작업을 수행하려는 이유에는 여러 가지 예가 있습니다.
- 예를 들어 넷플릭스가 하고 있는 일 중 하나는 서버가 많고, 거대한 데이터 센터에서 영화를 퍼뜨리고, 많은 사람들이 동시에 영화를 보는 이런 문제를 안고 있다는 것입니다.
- 따라서 집에 있고 집에서 인터넷을 사용하는 경우 AT&T나 DSL 네트워크를 통해 데이터를 라우팅하는 회사를 사용하고 있을 수 있습니다.디지털 가입자 회선 액세스 멀티플렉서를 사용할 수도 있습니다.
- 계층 3 규칙을 사용할 수 있고 해당 IP 주소에서 들어오는 패킷을 원하지 않는다고 말할 수 있으며 계층 7 규칙을 적용할 수 있습니다.
- 따라서 서비스 거부 공격은 누군가가 특정 리소스에 대한 서비스를 거부하려는 공격입니다.예를 들어 제가 네트워크 관계자인데 인터넷에 접속해야 할 업스트림 문제가 있는데 누군가 저를 좋아하지 않거나 협박을 하려는 경우 봇을 많이 확보하여 제 라우터의 입력 포트에 트래픽을 보내기 시작해서 과부하가 걸리고 제가 데이터를 보낼 수 없게 될 수도 있습니다.
- 이들은 정보나 데이터 또는 패킷이 이동하지 말아야 할 특정 위치로 이동하는 것을 방지하는 데 초점을 맞추고 있습니다.이러한 데이터를 처리하는 방법은 해당 위치에 정책을 구성하는 것입니다.

## 예시
- 예를 들어 Amazon에 있고 쇼핑을 처리할 수 있는 서버가 여러 대 있을 수 있습니다.

## 요약
- 따라서 서비스 거부 공격은 누군가가 특정 리소스에 대한 서비스를 거부하려는 공격입니다.예를 들어 제가 네트워크 관계자인데 인터넷에 접속해야 할 업스트림 문제가 있는데 누군가 저를 좋아하지 않거나 협박을 하려는 경우 봇을 많이 확보하여 제 라우터의 입력 포트에 트래픽을 보내기 시작해서 과부하가 걸리고 제가 데이터를 보낼 수 없게 될 수도 있습니다. 이들은 정보나 데이터 또는 패킷이 이동하지 말아야 할 특정 위치로 이동하는 것을 방지하는 데 초점을 맞추고 있습니다.이러한 데이터를 처리하는 방법은 해당 위치에 정책을 구성하는 것입니다.
