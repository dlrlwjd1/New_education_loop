# Lecture 3 -  Encapsulation Examples -  TCP Header

> MOOC video · [원본 학습 항목](https://www.mooc.org/learn/iot-networking/lecture/sUfry/lecture-3-encapsulation-examples-tcp-header)

## 개요
- 따라서 TCP 헤더는 TCP용 헤더이고 IP 패킷 내부에 포함되며 이더넷 프레임 내부에 포함됩니다.

## 내용
- 따라서 TCP 헤더는 TCP용 헤더이고 IP 패킷 내부에 포함되며 이더넷 프레임 내부에 포함됩니다.
- 그런데 포트라는 용어가 약간 헷갈리는데 , 물리적인 라우터가 있고 케이블을 꽂는 구멍에 대해 얘기하는 경우 이를 포트라고도 부르기 때문입니다.
- 이는 프레임을 전송하거나 세그먼트를 보내는 애플리케이션 ID와 세그먼트를 수신할 대상 애플리케이션을 정의합니다.
- 상대방이 데이터를 수신할 때 상대방은 당신이 말하는 데이터의 어떤 인덱스를 사용하는지, 어떤 바이트 번호를 보내고 있는지 알아야 합니다.
- 따라서 매우 제약이 심하고 많은 데이터를 지원할 수 없고 내부에 작은 버퍼가 있는 작은 IoT 장치로 전송하는 경우에도 TCP를 처리할 수 있고 작은 창 크기로 TCP를 실행할 수 있습니다.
- 최신 커널에서는 효율성을 이유로 세그먼트를 애플리케이션으로 전송하기 전에 이러한 세그먼트를 잠시 저장하기도 합니다.
- 한 가지 명심해야 할 점은 이것이 스택 캡슐화를 위한 한 가지 방법일 뿐이라는 것입니다.다양한 방법으로 캡슐화를 수행할 수 있습니다.
