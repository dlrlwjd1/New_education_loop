# Lecture 4 -  Internet Addressing

> MOOC video · [원본 학습 항목](https://www.mooc.org/learn/iot-networking/lecture/41SG3/lecture-4-internet-addressing)

## 개요
- 데이터를 보내려면 단순히 특정 파일이나 특정 응용 프로그램으로 데이터를 보내는 것이 아니라 인터넷을 사용할 수 있도록 먼저 몇 가지 작업을 해야 합니다.

## 내용
- 데이터를 보내려면 단순히 특정 파일이나 특정 응용 프로그램으로 데이터를 보내는 것이 아니라 인터넷을 사용할 수 있도록 먼저 몇 가지 작업을 해야 합니다.
- 인터넷이 패킷을 실제 목적지로 전달하는 데 사용되는 중간 색인 또는 중간 주소를 찾아야 합니다.
- 패킷을 전송할 때 이러한 주소 목록을 입력해야 하고 캡슐화를 통해 이 작업을 수행하면 패킷 내의 여러 레이어가 있습니다.
- 따라서 이미 실내에서는 다소 복잡하지만 최종 사용자에게는 파일을 원할 경우 파일 위치를 알아야 한다는 압박을 가하고 있습니다.
- 따라서 Denley 웹 페이지용 HTTP라는 프로토콜 등을 사용하여 웹과 같은 프로토콜을 실행하는 경우 HTTP 서버는 포트 80에 위치합니다.
- 따라서 특정 URL로 연결되는 경로를 찾고 싶거나 특정 URL로 파일을 가져오려는 경우 그냥 할 수 있는 것이 아니라 그 아래에 있는 모든 것을 식별해야 합니다.
- 먼저 전송 엔드포인트로 라우팅해야 하고, 데이터를 전송하려는 지점의 특정 애플리케이션 레이어로 라우팅해야 합니다.

## 예시
- 먼저 전송 엔드포인트로 라우팅해야 하고, 데이터를 전송하려는 지점의 특정 애플리케이션 레이어로 라우팅해야 합니다.

## 요약
- 따라서 특정 URL로 연결되는 경로를 찾고 싶거나 특정 URL로 파일을 가져오려는 경우 그냥 할 수 있는 것이 아니라 그 아래에 있는 모든 것을 식별해야 합니다. 먼저 전송 엔드포인트로 라우팅해야 하고, 데이터를 전송하려는 지점의 특정 애플리케이션 레이어로 라우팅해야 합니다.
