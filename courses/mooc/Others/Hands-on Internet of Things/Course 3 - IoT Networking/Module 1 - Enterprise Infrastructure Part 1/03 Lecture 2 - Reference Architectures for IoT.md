# Lecture 2 -  Reference Architectures for IoT

> MOOC video · [원본 학습 항목](https://www.mooc.org/learn/iot-networking/lecture/A61Qm/lecture-2-reference-architectures-for-iot)

## 개요
- 따라서 건물의 각 층이나 각 지역에 스위치 세트를 설치한 다음 이를 코어 스위치 세트로 더 많이 통합하게 될 것입니다.

## 내용
- 따라서 건물의 각 층이나 각 지역에 스위치 세트를 설치한 다음 이를 코어 스위치 세트로 더 많이 통합하게 될 것입니다.
- 따라서 한 지점에서 다른 지점으로 트래픽을 라우팅하려면 위로 올라가서 액세스 스위치와 재배포 스위치를 누른 다음 건물 내부 스위치로 이동한 다음 다시 배전 스위치로 내려가야 합니다.
- 그러면 이러한 구성 요소와 인터페이스하고 실행 등을 할 수 있는 빌딩 운영 센터가 있을 수 있습니다.
- 이제 규모가 좀 더 커지면 스마트 시티에 대해 이야기할 수 있고, 그 다음에는 대형 네트워크를 설계하는 것입니다.
- 액세스를 제어하고 잘못된 트래픽을 차단하는 등의 작업을 수행할 수 있습니다.침입 탐지 서비스와 침입 방지 서비스를 갖게 될 것입니다.
- 클라우드에 데이터 센터가 있고 운영 센터가 있을 수 있으며 이러한 운영 센터가 IP 코어에도 연결될 수 있습니다.
- 일반적으로 네트워크 설계에서는 IP 코어 이더넷이 여기에 걸려 있고 우리가 경계를 설정하는 서비스가 있을 것입니다.

## 예시
- 일반적으로 네트워크 설계에서는 IP 코어 이더넷이 여기에 걸려 있고 우리가 경계를 설정하는 서비스가 있을 것입니다.

## 요약
- 클라우드에 데이터 센터가 있고 운영 센터가 있을 수 있으며 이러한 운영 센터가 IP 코어에도 연결될 수 있습니다. 일반적으로 네트워크 설계에서는 IP 코어 이더넷이 여기에 걸려 있고 우리가 경계를 설정하는 서비스가 있을 것입니다.
