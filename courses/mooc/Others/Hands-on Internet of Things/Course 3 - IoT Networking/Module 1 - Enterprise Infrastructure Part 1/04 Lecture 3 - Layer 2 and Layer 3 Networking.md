# Lecture 3 -  Layer 2 and Layer 3 Networking

> MOOC video · [원본 학습 항목](https://www.mooc.org/learn/iot-networking/lecture/LsDoD/lecture-3-layer-2-and-layer-3-networking)

## 개요
- 계층 1 물리 계층, 계층 2 MAC 계층, 계층 3 네트워킹, 계층 4 전송 등이 있습니다.

## 내용
- 계층 1 물리 계층, 계층 2 MAC 계층, 계층 3 네트워킹, 계층 4 전송 등이 있습니다.
- IP, 인터넷 프로토콜, IP 기반 네트워킹 등을 다루기 시작하면서부터요.결과적으로 레이어 2와 레이어 3의 설계 방식이 네트워크를 설계하는 방식에 많은 영향을 미친다는 것이 밝혀졌습니다.
- 이 IP 백본은 사용자가 직접 실행하는 것일 수도 있고, 고유한 라우팅 프로토콜을 실행하고 IP 라우터 등을 실행할 수도 있습니다.이를 ISP와 계약할 수도 있습니다.
- 따라서 ISP는 마치 자체 IP 네트워크를 제공하는 것처럼 가장하는데 실제로는 가상화되어 있기 때문에 자체 IP 백본 위에서 IP 네트워크를 운영하고 있는 것과 같습니다.
- 따라서 이더넷에 대해 이야기할 때는 네트워크 가장자리에 있는 계층 2에 대해 이야기하고 있습니다.
- 이더넷을 설계하려는 경우 액세스 제어 목록을 설정하거나 무선 네트워크용 SSID와 같은 네트워크 이름을 변경하려는 경우 등을 선택적으로 구성할 수 있습니다.
- 따라서 원하는 경우 이더넷을 구성할 수 있지만 기본적으로 포인트 투 포인트 연결만 제공하는 것은 플러그 앤 플레이 방식이므로 아무 것도 할 필요가 없습니다.

## 예시
- 따라서 원하는 경우 이더넷을 구성할 수 있지만 기본적으로 포인트 투 포인트 연결만 제공하는 것은 플러그 앤 플레이 방식이므로 아무 것도 할 필요가 없습니다.
