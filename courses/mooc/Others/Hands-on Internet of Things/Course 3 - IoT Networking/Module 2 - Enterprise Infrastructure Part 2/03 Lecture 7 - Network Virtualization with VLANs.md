# Lecture 7 -  Network Virtualization with VLANs

> MOOC video · [원본 학습 항목](https://www.mooc.org/learn/iot-networking/lecture/U1LuC/lecture-7-network-virtualization-with-vlans)

## 개요
- 컴퓨터를 가상화하려는 경우 컴퓨터를 하나 가져와서 물리적 시스템을 가져와서 그 위에 여러 가상 시스템을 실행하는 것과 같은 기능이 있습니다.이 컴퓨터로 모든 종류의 강력한 일을 할 수 있습니다.

## 내용
- 컴퓨터를 가상화하려는 경우 컴퓨터를 하나 가져와서 물리적 시스템을 가져와서 그 위에 여러 가상 시스템을 실행하는 것과 같은 기능이 있습니다.이 컴퓨터로 모든 종류의 강력한 일을 할 수 있습니다.
- 그래서 우리는 네트워크를 만들고, 물리적 네트워크를 만든 다음, 그 위에 여러 개의 가상 네트워크를 실행할 수 있습니다.
- PCI 서버, 즉 사용자의 신용 카드 정보를 저장하는 결제 카드 인프라 서버가 있습니다.이 모든 것을 가지고 있고 그건 별개의 문제라고 가정해 봅시다.
- 따라서 VLAN을 사용하는 경우 이러한 네트워크를 구축할 때 가장 현명한 방법 중 하나는 이러한 요소를 분리하는 것입니다.
- 그리고 이것이 구현되는 방식은 스위치에 이러한 포트가 있고 어떤 포트가 어떤 VLAN에 있는지 스위치에 알려주는 것입니다.또한 단일 포트가 여러 VLAN에 있을 수 있습니다.
- 데이터 센터가 있고 여러 VM, 가상 머신이 서로 다른 VLAN에 있는데 VLAN 간에 이동하려는 경우 번호를 다시 매겨야 합니다.
- 이는 매우 동질적인 인프라, 많은 서버, 매우 유사한 네트워크를 여러 곳에 배포한 다음 필요한 것을 설정할 수 있는 데이터 센터에 적합합니다.

## 예시
- 예를 들어, 네트워크가 있고 스위치가 여러 개 있고 링크와 작은 서브넷으로 연결되어 있다고 가정해 보겠습니다.스마트 빌딩을 짓는다고 가정해 봅시다.

## 요약
- 데이터 센터가 있고 여러 VM, 가상 머신이 서로 다른 VLAN에 있는데 VLAN 간에 이동하려는 경우 번호를 다시 매겨야 합니다. 이는 매우 동질적인 인프라, 많은 서버, 매우 유사한 네트워크를 여러 곳에 배포한 다음 필요한 것을 설정할 수 있는 데이터 센터에 적합합니다.
