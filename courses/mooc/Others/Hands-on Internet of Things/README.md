# Hands-on Internet of Things

University of Illinois Urbana-Champaign의 4강좌 전문과정으로, IoT 장치·회로와 Arduino에서 RF·MAC·mesh 통신, enterprise network, router·switch와 물리 배선 인프라까지 순서대로 다룬다.

- 전문과정: https://www.mooc.org/specializations/uiuc-iot
- 구성: 4개 하위 강좌 · 16개 주차 · 강의별 학습 노트 102개
- 수준: Intermediate
- 선택 실습: 네트워크·센서 기반 소형 자율주행 차량을 단계적으로 확장하는 Honors lab
- 하드웨어: Honors 실습을 수행할 때만 별도 구입 필요(과정 안내 기준 지역에 따라 약 USD 100~200)
- 제외: 채점 퀴즈·과제와 잠금된 해답

## 강좌

1. **[IoT Devices](Course%201%20-%20IoT%20Devices/README.md)** — 28개 강의, Internet·protocol stack 기초, 회로·센서·actuator, microcontroller와 Arduino
2. **[IoT Communications](Course%202%20-%20IoT%20Communications/README.md)** — 31개 강의, RF·antenna·modulation, MAC·저전력 통신, mesh routing과 service discovery
3. **[IoT Networking](Course%203%20-%20IoT%20Networking/README.md)** — 24개 강의, enterprise IoT, Ethernet·VLAN, IP addressing·DHCP·ARP, socket과 forwarding
4. **[IoT Cloud](Course%204%20-%20IoT%20Cloud/README.md)** — 19개 강의, router·switch 내부, control/data plane, 물리 배선·EMI·cable security

## 학습 흐름

```text
Device/Circuit -> Wireless Communication -> Enterprise/IP Network -> Network & Physical Infrastructure
```
