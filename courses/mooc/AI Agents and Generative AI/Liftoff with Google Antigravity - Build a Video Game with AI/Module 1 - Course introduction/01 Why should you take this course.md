# Why should you take this course?

## 개요

- Voyager 게임을 직접 만들며 Antigravity와 Firebase를 함께 익히는 실습형 강의다.
- 일반적인 클라우드 실습 환경 대신 Antigravity를 로컬 컴퓨터에서 실행한다.

## 내용

### 네 가지 학습 목표

- Antigravity 개발 환경 설정
- Firebase 서비스 활성화
- 여러 AI 에이전트의 오케스트레이션
- 코드 생성을 위한 효과적인 프롬프트 작성

### 학습 방식

강의는 단순 시청보다 따라 만들기에 초점을 둔다. 학습자는 Voyager의 개발자가 되어 설치, 서비스 구성, 병렬 개발, 테스트, 배포까지 전 과정을 수행한다.

Antigravity는 출간 시점에 로컬 실행이 필요하므로, 강좌 전체가 하나의 긴 실습처럼 구성된다. 영상의 화면과 최신 제품 UI가 달라질 수 있다는 점도 고려해야 한다.

## 예시

전체 프로젝트의 흐름은 다음과 같다.

```text
Antigravity 설정
  → Firebase 서비스 활성화
  → 에이전트 A/B 병렬 개발
  → 에이전트 C 통합 검증
  → 로컬 테스트 및 배포
```

## 요약

- 목표는 Voyager 완성뿐 아니라 에이전트 기반 개발 절차를 체득하는 것이다.
- 학습자는 인간 검토자이자 프로젝트 관리자로 계속 개입한다.
- 실제 로컬 환경에서 강의를 따라가는 것이 핵심이다.
