# Using AI Memory to Build Skills

## 개요
- "어떤 스킬을 만들어야 할지"를 정하는 실용적인 방법을 다루는 강의.
- ChatGPT/Claude 같은 도구에 쌓인 **메모리(memory)**, 즉 과거 대화 기록을 활용해 스킬 후보를 발굴하는 방법을 소개한다.

## 내용
### 어떤 작업을 스킬로 만들어야 하는가
- 일반 원칙: **반복적으로 하는 일(over and over again)**이면서 **내가 정확히 무엇을 원하는지 이미 잘 알고 있는 일**을 스킬로 만들어야 한다.
- 반대로, 한 번도 해본 적 없어서 원하는 결과가 아직 명확하지 않은 작업은 스킬로 만들기에 적합하지 않다.
- 판단 기준(신호): **AI에게 매번 똑같은 말을 반복해서 설명하고 있다면**, 그것이 바로 스킬을 만들어야 한다는 신호다.

### AI 메모리를 활용해 스킬 아이디어 찾기
- 방법: 대화 기록(memory)이 충분히 쌓인 ChatGPT/Claude 세션에서 다음과 같이 요청한다.
  > "우리가 나눈 대화들과 내가 자주 시키는 작업들을 되짚어보고, 이런 작업들을 위한 AI 에이전트 스킬을 제안해줘."
- 조건: memory 기능이 켜져 있고, 대화 이력이 충분히 쌓여 있어야 함. 대화가 적다면 아직 이 방법을 쓸 준비가 안 된 것.

### 실습 예시 (강사의 실제 결과)
AI가 대화 기록을 바탕으로 제안한 스킬 후보들:
1. **Course Architect** — 러프한 코스 아이디어, 모듈 주제, 대상, 학습 목표, 강의 스타일 예시를 받아서 코스 개요, 학습 목표, 과제 아이디어, 랜딩 페이지 카피, 전문 과정(specialization) 구조까지 만들어주는 스킬.
   - 실제로 강사가 자주 시키는 "랜딩 페이지 카피 작성" 같은 작업을 AI가 기억하고 이를 반영해 제안함.
2. **Workshop Designer** — AI 에이전트/프롬프트 엔지니어링 워크숍 설계.
3. **Thought Partner** — 강사가 AI와 자주 하는 "생각 파트너링(thought partnering)" 작업.
4. **Agent Product Spec Writer** — AI 에이전트용 소프트웨어 제품 개발 작업을 자주 하는 것을 반영한 스킬.

### 스킬 생성의 트레이드오프 (주의사항)
- 스킬을 만든다는 것은 **"이 작업은 이런 방식으로 한다"고 못박는(lock in)** 것을 의미한다.
- 생성형 AI의 매력 중 하나는 매번 다른 방식으로 시도해보고 다양한 결과를 발견하는 데 있는데, 스킬로 고정하면 이런 "발견의 마법"을 일부 잃게 된다.
- 따라서 아이디어가 많더라도, **정말 원하는 방식이 확실한 것만** 스킬로 만들어야 한다.

## 예시
- 프롬프트: "Reflect on our conversations and common tasks I have you perform. Then propose AI agent skills that we could create for these tasks."
- 결과: Course Architect, Workshop Designer, Thought Partner, Agent Product Spec Writer 등 개인화된 스킬 후보 목록.

## 요약
- 스킬 후보를 고르는 기준: **반복적이고 + 원하는 방식이 명확한 작업**.
- AI에게 같은 설명을 반복하고 있다면 그것이 스킬화의 신호.
- 충분히 쌓인 AI 메모리(대화 기록)에 "우리가 자주 하는 작업 기반으로 스킬을 제안해줘"라고 요청하면 개인 맞춤 스킬 아이디어를 얻을 수 있다.
- 단, 스킬은 방식을 고정시키므로, 아직 방법이 확실하지 않은 작업은 스킬화를 미루는 것이 좋다.
