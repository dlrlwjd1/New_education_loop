# Assets: Data, Templates, and More for the AI Agent to Work With

## 개요
- 스킬 폴더의 마지막 구성 요소인 **assets 폴더**를 다루는 강의.
- assets는 스킬에서 가장 저평가되지만 강력한 요소라고 강조하며, 템플릿(template)과 데이터(data)를 중심으로 활용법을 설명한다.

## 내용
### assets란
- 에이전트가 작업에 필요한 것 — **템플릿부터 조회용 데이터까지 무엇이든** 담을 수 있는 폴더.
- 강사는 이를 "스킬에서 가장 저활용되는(underutilized) 부분"이라고 표현할 만큼 강력하다고 강조.

### 핵심 활용 1 — 템플릿(template)으로 형식을 고정하기
- 문제: AI에게 매번 같은 작업을 시켜도, 매번 형식이 조금씩 다르게 출력되는 경우가 많다(예: CSV 컬럼 순서가 다름, 포맷이 미묘하게 달라짐).
- 해결책: **완성되지 않은 절반짜리 결과물(semi-complete work)을 assets에 넣어두고**, AI에게 "이 템플릿을 사용해서 채워 넣어라"고 지시.
  - 예: 헤더만 있고 데이터 행은 비어 있는 CSV 파일을 넣어두고, 거기에 값만 채우게 함.
- 왜 효과적인가: AI가 문제를 겪는 대부분의 경우는 **"처음부터(from scratch)" 시작할 때**다. 템플릿을 주면 AI는 이미 헤더와 주요 섹션이 갖춰진 상태에서 시작하므로, 매번 같은 포맷을 안정적으로 재현할 수 있다.

### 핵심 활용 2 — 조회용 데이터(lookup data)
- 예: 지역별 세율(tax rates)을 조회해야 하는 작업 → 세율이 담긴 CSV 파일과 "이 파일에서 적절한 값을 찾는 방법"에 대한 지침을 함께 assets에 넣어둔다.
- 데이터베이스나 그 데이터베이스에 접근하는 도구도 assets에 포함 가능.

### 실전 사례 — 여행 경비 대시보드를 assets로 고정하기
- 앞서 보여준 "매번 동일한 스타일의 대시보드"가 나오는 비결:
  1. 대화에서 AI와 반복적으로 주고받으며("이 부분 추가해줘", "이 색을 바꿔줘") 대시보드를 원하는 형태로 완성.
  2. 완성된 대시보드의 다운로드 링크를 받아 파일로 저장.
  3. 이 **거의 완성된(almost complete) 대시보드 파일을 스킬의 assets에 포함**.
  4. SKILL.md의 지시문에는 단지 "이번 여행의 데이터를 assets에 있는 이 대시보드에 추가하라"고만 적으면 됨.
- 즉, 어려운 디자인 작업은 미리 사람이 대화로 완성해두고, 스킬 실행 시에는 **데이터만 갈아 끼우는 방식**으로 매번 동일한 품질의 결과물을 재현.

## 예시
```
expense-reports/
└── assets/
    ├── dashboard_template.html   ← 완성된 대시보드, 데이터만 채우면 됨
    └── tax_rates.csv             ← 지역별 세율 조회용 데이터
```
- 지시문 예: "Add this trip's expense data to the dashboard template already provided in assets."

## 요약
- assets는 **템플릿(형식 고정)**과 **조회용 데이터/도구**를 담아, AI가 매번 처음부터 시작하지 않고 이미 검증된 출발점에서 작업하도록 돕는다.
- 좋은 산출물(예: 대시보드)을 대화로 미리 완성해두고, 데이터만 교체하는 방식으로 assets에 넣으면 **일관되고 안정적인 품질**을 재현할 수 있다.
- assets는 스킬에서 가장 저평가되지만, 형식 안정성과 재사용성을 크게 높이는 핵심 요소다.
