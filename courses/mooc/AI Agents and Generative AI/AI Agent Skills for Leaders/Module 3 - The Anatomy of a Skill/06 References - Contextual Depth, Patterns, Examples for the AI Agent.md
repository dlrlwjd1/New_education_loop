# References: Contextual Depth + Patterns / Examples for the AI Agent

## 개요
- 스킬 폴더의 **references 폴더**를 다루는 강의.
- "왜 SKILL.md 하나에 모든 걸 다 넣지 않고 별도 폴더로 분리하는가?"라는 질문에서 출발한다.

## 내용
### 왜 SKILL.md에 모든 걸 다 담으면 안 되는가
- 비유: 사람에게 매뉴얼을 줄 때도 **장(chapter)별로 나눈다.**
  - 서론(introduction)에는 누구나 읽어야 할 기본 규칙만 담는다.
  - "국제 출장 경비 처리에 대해 더 알고 싶으면 이 챕터로", "국내 출장은 이 챕터로" 하는 식으로 **필요할 때만 참조하는 별도 챕터**로 분리한다.
- SKILL.md = 항상 읽히는 "서론(introduction)" 역할.
- references = 특정 상황에서만 필요한, **온디맨드로 조회하는 추가 정보**.

### references에 넣을 것 1 — 상세하고 특수한 케이스 정보
- 예: 여행 경비 보고서 스킬에서, 항목별로 세부 규정이 다를 때
  - 라이드셰어(ride sharing) 정책
  - 항공권(airfare) 예약 및 처리 정책
- 마일리지 환급을 요청하는 출장이라면 항공권 정책을 읽을 필요가 없듯, **필요한 경우에만 해당 참조 문서를 읽도록** 구성.

### references에 넣을 것 2 — 예시(examples), 가장 강력한 활용법
- 통찰: **모든 규칙을 말로 다 풀어쓰는 것보다, "정답 예시"를 보여주는 것이 더 효과적일 때가 있다.**
- 비유: 톨스토이(Tolstoy)처럼 글을 쓰라고 가르치려면? 모든 문체 규칙을 나열하는 지시문은 극도로 어렵다. 하지만 **톨스토이의 실제 글 일부를 보여주고 "이렇게 써라"**고 하면 훨씬 쉽고 효과적이다.
- 스킬에서도 마찬가지: "이 영수증들에 대한 올바른 경비 보고서 예시", "이 주제에 대한 올바른 코스 공지문 예시" 등 **정답 예시 자체를 references에 넣어두면**, 모든 규칙을 명시적으로 적지 않아도 AI가 패턴을 학습해 따라 할 수 있다.

## 예시
```
expense-reports/
└── references/
    ├── international-expense-policy.md   ← 국제 출장 시에만 참조
    ├── ridesharing-policy.md             ← 라이드셰어 비용 처리 시에만 참조
    └── example-expense-report.md         ← 올바르게 작성된 경비 보고서 예시
```

## 요약
- SKILL.md는 항상 읽히는 "서론"이고, references는 **필요할 때만 온디맨드로 조회하는 심화 정보**다.
- references는 (1) 특정 상황/변형 케이스에 대한 상세 규칙, (2) 올바른 결과물의 실제 예시, 두 가지 용도로 특히 강력하다.
- 특히 "예시로 가르치기"는 모든 규칙을 말로 나열하기 어려운 경우(예: 특정 문체 모방) 매우 효과적인 방법이다.
