# Creating a Skill in Chat with a Skill Creator

## 개요
- "스킬을 만드는 것 자체도 스킬이다"라는 재미있는 개념 소개.
- ChatGPT 등에 내장된 **Skill Creator**라는 스킬을 이용해, 대화(chat)를 통해 스킬을 자동으로 만드는 방법을 다룬다.
- 앞선 강의(수동 생성)와 비교해 각각의 장단점을 짚는다.

## 내용
### Skill Creator란
- ChatGPT 같은 도구에는 **"Skill Creator"**라는 이름의 특수한 스킬이 내장되어 있다.
- 이 스킬은 "AI 에이전트에게 스킬을 만드는 방법 자체를 알려주는 스킬"이다. 즉 스킬로 스킬을 만드는 메타(meta) 구조.

### 사용 방법 (Create with Chat)
1. ChatGPT 메뉴 → Skills로 이동.
2. 스킬 생성 시 **"Create with Chat"**을 선택 (수동 생성 시의 "Create with editor"와 대비됨).
3. 대화에서 "스킬을 만들고 싶어. 이런 걸 하는 스킬이야" 라고 원하는 동작을 설명(또는 기존에 Word 문서에 적어둔 내용을 그대로 복사/붙여넣기).
4. 화면에 "using Skill Creator skill" 혹은 "used Skill Creator skill"이라는 표시가 뜨면, AI가 "이건 스킬을 만들어달라는 요청이구나"를 인식하고 Skill Creator 스킬(스킬 만드는 법을 알려주는 스킬)을 참고해 작업을 진행 중이라는 뜻이다.
5. 작업이 끝나면 AI가 스킬을 패키징해서 "설치할 수 있다"는 안내와 함께 완성된 스킬을 제공한다.

### 수동 작성 vs. Skill Creator 자동 생성 비교
- Skill Creator가 만든 결과물은 사용자가 준 원래 지시문에 **AI가 살을 붙이고(embellish)**, 적절한 구조/포맷/폴더 형태로 정리해준다는 장점이 있다.
  - 장점: 수동으로 에디터에 값을 복사/붙여넣는 수고를 덜어준다.
- 하지만 강사는 다음과 같이 강조한다:
  - **직접 통제하며 세밀하게 조정하는 방식(수동 작성 후 직접 edit)이 더 나은 경우가 많다.**
  - 스킬의 품질을 좌우하는 것은 "Skill Creator라는 도구"가 아니라 **"내가 무엇을 원하는지에 대한 깊은 사고(thought process)"**다.
  - 스킬을 잘 만드는 것은 결국 사람의 지식과 고민(knowledge)에 달려 있지, 자동 생성 도구 자체에 달려 있지 않다.

### 핵심 통찰
- 스킬을 실제로 "만드는 메커니즘"(파일/폴더 구조에 맞춰 패키징, 이름 붙이기, 에디터에 붙여넣기 등)은 사실 쉬운 부분이다.
- **진짜 어려운 부분은 "무엇을 스킬에 담을지, 어떻게 하면 이 스킬이 항상 가치를 만들어낼지"를 고민하는 것**이다.

## 예시
- 이전 강의(수동 작성)에서 쓴 것과 동일한 Word 문서 내용(name/description/process)을 그대로 채팅에 붙여넣고 "이 내용으로 스킬을 만들어줘"라고 요청 → Skill Creator 스킬이 작동해 자동으로 패키징된 스킬을 생성.

## 요약
- ChatGPT 등에는 스킬 생성 자체를 도와주는 **Skill Creator 스킬**이 내장되어 있어, 대화만으로도 스킬을 만들 수 있다("Create with Chat").
- 자동 생성은 편리하지만, **스킬의 진짜 가치는 도구가 아니라 사람이 원하는 바를 얼마나 깊이 고민해서 텍스트로 표현했는가**에서 나온다.
- 스킬 제작의 메커니즘(포맷팅, 패키징)은 쉬운 부분이고, 무엇을 담을지 고민하는 것이 진짜 어려운 부분이다.
