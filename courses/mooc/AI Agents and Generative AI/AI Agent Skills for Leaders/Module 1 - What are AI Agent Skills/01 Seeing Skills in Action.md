# Seeing Skills in Action

## 개요
- AI 에이전트 스킬(Skill)이 없을 때와 있을 때의 대화를 비교하며, 스킬(skill)이 왜 필요한지 직관적으로 보여주는 강의.
- 예시로 "여행 경비 보고서(travel expense report) 작성"이라는 동일한 작업을 스킬 없이/있이 각각 수행해본다.

## 내용
### 스킬이 없을 때의 문제
- 영수증 여러 장을 ChatGPT에 업로드하고 "여행 경비 보고서를 만들어줘"라고 요청하면, AI는 표 형태로 결과를 주지만 사용자가 원하는 포맷(엑셀에서 열리는 CSV, 특정 컬럼 구성 등)과는 다르다.
- 결국 대화를 이어가며 "이 컬럼으로", "이 카테고리로 나눠줘" 등 세부사항을 하나하나 설명해야 한다. 즉, **매번 대화로 AI를 다시 가르쳐야 하는(teaching it how to perform the task)** 비효율이 발생한다.
- AI는 사용자가 "여행 경비 보고서"라는 말에 담긴 구체적인 의미(포맷, 컬럼, 스타일)를 모르기 때문에 매번 반복 설명이 필요하다.

### 스킬이 있을 때
- 미리 만들어둔 "travel expense reporting skill"을 사용해 동일한 영수증들을 업로드하고 "이 스킬로 여행 경비 보고서를 만들어줘"라고 요청.
- AI가 스킬을 참고해 사용자가 원하는 방식을 그대로 재현:
  - 엑셀에서 열 수 있는 CSV 파일(원하는 컬럼 구조 포함)을 자동 생성
  - 지출 항목을 날짜/카테고리별로 보기 좋게 정리한 대시보드(dashboard) 생성
  - 영수증 파일명을 날짜·거래처·카테고리 기준의 일관된 명명 규칙으로 자동 변경 후 zip으로 정리
- 대화를 통해 매번 설명할 필요 없이, 스킬 하나로 원하는 결과를 반복 재현(repeatably) 가능.

### 도구를 넘나드는 재사용성
- 오늘날 ChatGPT, Claude, Magic 등 다양한 도구는 결국 **모두 AI 에이전트(AI agent)** 기반으로 동작한다.
- 같은 스킬을 Claude에 가져가서 동일한 영수증을 주고 요청하면, Claude도 별도 질문 없이 동일한 색상·폰트·시각화 스타일의 대시보드와 동일한 컬럼의 CSV, 동일한 파일 정리 방식을 그대로 재현한다.
- 즉, 스킬은 특정 챗봇에 종속되지 않고 **"AI 에이전트에게 일하는 방식을 가르치는 재사용 가능한 훈련 자료"**로 기능한다.

## 예시
- 입력: 여행 영수증 PDF 여러 장 + "travel expense skill로 경비 보고서 만들어줘"
- 출력 3종:
  1. CSV 파일 (엑셀 호환, 지정된 컬럼 구조)
  2. 지출 breakdown 대시보드 (날짜/카테고리별 시각화)
  3. 명명 규칙에 맞게 이름이 바뀐 영수증 파일들의 zip

## 요약
- 스킬(skill) 없이는 매번 대화로 AI에게 "어떻게 할지"를 새로 알려줘야 한다.
- 스킬은 AI 에이전트에게 **작업 수행 방식을 온디맨드(on-demand)로 훈련시키는 장치**이며, ChatGPT·Claude 등 도구가 달라도 동일하게 재사용된다.
- 이 강좌의 목표: 이런 AI 에이전트 스킬을 직접 만들고, 에이전트를 지능적으로 훈련시켜 강력한 가치를 만들어내는 방법을 배우는 것.
