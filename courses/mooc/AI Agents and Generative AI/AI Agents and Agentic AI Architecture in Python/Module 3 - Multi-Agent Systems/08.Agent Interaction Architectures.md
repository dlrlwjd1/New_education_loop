# 에이전트 상호작용 아키텍처

## 실습 문제

**1. ChatGPT 또는 Claude를 활용하여, 에이전트 상호작용의 핵심 패턴과 각 패턴을 언제 사용하면 좋은지를 2~3문단으로 작성하라.**

---

## 모범 답안 예시

에이전트 상호작용의 가장 기본적인 패턴은 **메시지 전달(Message Passing)** 이다. 이 방식에서는 한 에이전트가 처리한 결과를 텍스트 메시지 형태로 다른 에이전트에게 전달하며, 각 에이전트는 독립적인 컨텍스트를 유지한다. 구조가 단순하고 에이전트 간 결합도가 낮아 유지보수가 쉽다는 장점이 있다. 작업이 명확하게 분리될 수 있고, 두 번째 에이전트가 최소한의 배경 지식만으로 작업을 수행할 수 있을 때 가장 적합하다. 예를 들어, 요약 에이전트가 처리한 결과를 번역 에이전트에게 넘기는 파이프라인 구조가 이에 해당한다.

작업의 연속성이나 과정 공유가 필요할 경우에는 **메모리 인계(Memory Handoff)** 또는 **메모리 반영(Memory Reflection)** 패턴이 유용하다. 메모리 인계는 첫 번째 에이전트의 전체 대화 히스토리를 두 번째 에이전트에게 그대로 넘겨주어, 마치 한 사람이 계속 대화를 이어가는 것처럼 작동하게 한다. 복잡한 멀티스텝 작업에서 중간 상태나 의사결정 맥락을 잃지 않아야 할 때 적합하다. 메모리 반영은 두 번째 에이전트의 작업이 끝난 후 그 과정을 첫 번째 에이전트가 학습하고 메모리에 통합하는 방식으로, 에이전트 간 상호 학습이 필요한 시나리오에서 효과적이다.

마지막으로, 관련성 높은 정보만 선별적으로 공유해야 할 때는 **선택적 메모리 공유(Selective Memory Sharing)** 패턴이 적합하다. 이 방식은 LLM이 전체 메모리 중 현재 작업에 필요한 항목만 추려 두 번째 에이전트에게 전달한다. 메모리 양이 많거나, 민감한 정보가 포함되어 있거나, 두 번째 에이전트의 집중력을 유지해야 할 때 특히 유용하다. 예를 들어, 프로젝트 전반을 다루는 에이전트가 예산 검토만을 담당하는 전문 에이전트에게 비용 관련 메모리만 선별해 전달하는 경우가 이에 해당한다. 네 가지 패턴은 상호 배타적이지 않으며, 복잡한 멀티 에이전트 시스템에서는 상황에 따라 조합하여 사용하는 것이 일반적이다.

## 패턴 선택 가이드

| 상황 | 권장 패턴 |
|------|-----------|
| 작업이 명확히 분리되고 독립적 | 메시지 전달 |
| 전체 대화 흐름을 이어받아야 할 때 | 메모리 인계 |
| 에이전트 간 서로의 프로세스를 배워야 할 때 | 메모리 반영 |
| 관련 정보만 골라 전달해야 할 때 | 선택적 메모리 공유 |
| 대용량 메모리 + 집중된 하위 작업 | 선택적 메모리 공유 |
