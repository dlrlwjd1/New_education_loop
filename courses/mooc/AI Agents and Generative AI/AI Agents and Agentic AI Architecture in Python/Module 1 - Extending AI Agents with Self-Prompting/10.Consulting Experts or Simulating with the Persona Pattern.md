# 페르소나 패턴을 활용한 전문가 상담 및 시뮬레이션

전문적인 지식을 활용하는 에이전트를 구축할 때, LLM이 다양한 **전문가 페르소나**를 채택하여 통찰력을 제공하게 하는 페르소나 패턴은 매우 강력한 도구입니다. `prompt_expert` 도구를 기본 바탕으로 하여, 특정 배경과 전문성을 가진 전문가와의 상호작용을 만들 수 있습니다.

---

## 1. 기본 전문가 상담 도구 (`prompt_expert`)

전문가의 배경 설명과 질문(프롬프트)을 받아 답변을 생성하는 기본 구조입니다.

- **역할**: 시스템 메시지에 전문가의 상세 설명을 넣고, 사용자의 질문에 답하게 함
- **핵심**: 전문가의 배경과 전문 분야를 상세히 기술할수록 답변의 품질이 정교해짐

---

## 2. 동적 전문가 생성

미리 정의된 전문가 외에도, 에이전트가 직면한 상황에 맞춰 **실시간으로 새로운 전문가를 생성**할 수 있습니다.

> 예: 일반적인 아키텍트 대신 "특정 하드웨어 기반의 ML 파이프라인 최적화 10년 경력자"를 즉석에서 생성

---

## 3. 사전 구축된 전문가 도구 예시 (Prebuilt Experts)

소프트웨어 개발 프로세스의 각 단계를 담당하는 네 가지 전문가 도구 예시입니다.

| 도구 이름 | 전문가 페르소나 | 주요 역할 |
|---|---|---|
| 기술 문서 생성 | 15년 경력의 시니어 기술 작가 | 복잡한 개념을 개발자가 이해하기 쉽게 설명하고, API 및 사용 예시 작성 |
| 테스트 스위트 설계 | 12년 경력의 시니어 QA 엔지니어 | 단위/통합/E2E 테스트 설계 및 놓치기 쉬운 엣지 케이스 식별 |
| 코드 리뷰 수행 | 20년 경력의 시니어 소프트웨어 아키텍트 | 코드 품질, 디자인 패턴, 성능 최적화 및 유지보수성 검토 |
| 기능 발표문 작성 | 12년 경력의 제품 마케팅 매니저 | 기술적 특징을 대상 청중(기술적/비즈니스적)에 맞는 가치 제안으로 변환 |

---

## 4. 이 방식의 장점

- **명확한 정의**: 각 도구 내에 전문가의 배경과 전문성이 명확히 정의됨
- **정교한 프롬프트**: 특정 작업에 최적화된 프롬프트를 미리 구성 가능
- **유지보수 용이성**: 각 전문가의 구현이 독립적이므로 관리가 쉬움
- **관심사 분리**: 에이전트가 복잡한 작업을 수행할 때 각 분야의 전문가에게 역할을 나누어 맡길 수 있음

---

## 성공을 위한 핵심 팁

이 패턴의 핵심은 훌륭한 **전문가 설명(Description)**과 **집중된 프롬프트(Focused Prompt)**를 작성하는 것입니다.

- **설명**: 전문가의 관점과 접근 방식을 확립할 수 있을 만큼 충분히 구체적으로 작성
- **프롬프트**: 해당 분야 내에서 실행 가능한 구체적인 입력을 제공하도록 유도
