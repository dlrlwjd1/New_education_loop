# 프롬프트로 도구와 비정형 데이터 연결하기 — AI Shim

## 핵심 문제: 실세계 vs. 전통적 컴퓨팅 시스템의 간극

프롬프트가 연산으로서 수행할 수 있는 가장 중요한 역할 중 하나는 **에이전트에게 결정적인 간극을 메워주는 것**이다.

우리가 컴퓨터 시스템을 다룰 때 항상 마주치는 근본적인 문제가 있다:

| 실세계 (비정형) | 전통적 컴퓨팅 (정형) |
|----------------|----------------------|
| 사람이 쓴 자유로운 텍스트 | 정확한 형식의 API 입력 |
| 뉴스, 회의록, 대화 | 구조화된 JSON, XML 등 |
| 예외와 모호함이 넘침 | 형식이 완벽해야 동작 |
| 아날로그, 유동적 | 엄격한 스키마 요구 |

이 간극을 어떻게 메울 것인가? 바로 **프롬프트 기반 연산**이 이 문제에 탁월하게 효과적이다.

---

## AI Shim이란?

비정형 정보를 가져와 프롬프트를 통해 **기존 컴퓨팅 시스템과 연결할 수 있는 구조**로 변환하는 것이다. 에이전트가 도구를 호출하고 정보를 구조화할 때 이미 암묵적으로 이 작업을 수행하고 있다.

하지만 이 변환 작업을 **별도의 독립적인 도구로 분리**하면 더욱 강력해진다.

---

## 예시 1: 자연어 계획 → JSON 변환

**Step 1** — 자연어로 계획 생성:
> *"케이크를 굽는 단계별 계획을 만들어줘."*

LLM은 읽기 쉬운 자연어 계획을 반환한다. 하지만 이 결과물은 사람과 에이전트 눈에는 구조가 있어 보여도, 컴퓨팅 시스템은 이해할 수 없다. `for` 루프를 돌릴 수 없고, API로 보낼 수도 없다.

**Step 2** — 프롬프트로 구조화:
> *"이 단계들을 다음 형식의 JSON으로 변환해줘."*

```json
[
  { "step": 1, "action": "오븐을 180°C로 예열한다" },
  { "step": 2, "action": "밀가루, 설탕, 버터를 계량한다" },
  ...
]
```

이제 `for` 루프로 순회할 수 있고, 다른 API로 전송하거나, 분석할 수 있다.

> **포인트**: 자연어로 먼저 생각하고, 그 다음 JSON으로 변환하는 2단계 방식이 처음부터 JSON으로 작성하는 것보다 인지적으로 더 유연하고 품질이 높다.

---

## 예시 2: 웹페이지 콘텐츠 → JSON 변환

홈페이지의 텍스트를 복사해 프롬프트에 붙여넣고 이렇게 요청한다:

> *"이 콘텐츠를 다음 형식의 JSON으로 변환해줘."*

지저분한 복사-붙여넣기 형식의 텍스트도 깔끔하게 구조화된 데이터로 변환된다. 이를 활용하면:
- RSS 피드 생성
- 앱에서 뉴스 헤드라인 표시
- 다른 API로 전송

등 원하는 모든 작업이 가능해진다.

---

## 예시 3: 이미지 → 구조화 데이터 변환

프롬프트 기반 변환은 텍스트에만 국한되지 않는다. **이미지, 스크린샷, 영수증** 등 다양한 형태의 비정형 데이터에도 적용된다.

예시:
- 병실 사진 → "환자 있음", "간호사 있음", "가족 있음" 여부를 JSON으로 추출
- 홈페이지 스크린샷 → 헤드라인 목록을 JSON으로 추출

```json
[
  { "headline": "Amplify 오픈소스 플랫폼 출시", "url": "..." },
  { "headline": "새 연구 프로그램 발표", "url": "..." }
]
```

이미지 속 정보를 구조화된 데이터로 변환함으로써 기존 컴퓨팅 시스템과 바로 연결할 수 있다.

---

## 정리: AI Shim의 역할

```
실세계 비정형 데이터
(텍스트, 이미지, 문서, 영수증)
          ↓
    [프롬프트 기반 변환]
    = AI Shim
          ↓
구조화 데이터 (JSON 등)
          ↓
전통적 컴퓨팅 시스템 / API
(for 루프, 데이터베이스, 외부 서비스 등)
```

프롬프트는 단순한 연산을 넘어, 비정형의 실세계 정보와 엄격한 구조를 요구하는 기존 시스템 사이를 잇는 **강력한 브릿지**다. 에이전트에게 이 변환 능력을 도구로 부여하면, 현실 세계의 지저분한 정보를 받아 기존 인프라와 매끄럽게 연동되는 강력한 에이전트를 만들 수 있다.
