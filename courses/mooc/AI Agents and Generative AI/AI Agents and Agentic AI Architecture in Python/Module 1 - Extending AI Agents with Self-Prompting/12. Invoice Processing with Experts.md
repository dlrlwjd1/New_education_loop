# 전문가를 활용한 송장(Invoice) 처리

이전에 제작한 '송장 처리 에이전트'를 확장하여, 두 가지 핵심 작업을 수행하는 **전문가 상담(Expert Consultations)** 기능을 도입합니다.

| 기능 | 설명 |
|---|---|
| **지출 분류** | 한 문장 설명을 바탕으로 20개의 사전 정의된 범주 중 하나로 분류 |
| **구매 규칙 확인** | 송장이 회사의 구매 정책을 준수하는지 검증 |

> 전문가 도구를 사용하면 모든 규칙을 하드코딩하지 않고도 전문 지식을 동적으로 호출할 수 있어 아키텍처를 깔끔하고 유연하게 유지할 수 있습니다.

---

## 1단계: 지출 분류 전문가 생성

지출 분류를 전문으로 하는 전문가를 정의합니다. 송장 설명을 입력받아 최적의 카테고리를 반환합니다.

```python
@register_tool(tags=["invoice_processing", "categorization"])
def categorize_expenditure(action_context: ActionContext, description: str) -> str:
    categories = ["사무용품", "IT 장비", "소프트웨어 라이선스", "컨설팅 서비스", ...]
    return prompt_expert(
        action_context=action_context,
        description_of_expert="기업 지출 분류에 깊은 전문 지식을 가진 시니어 재무 분석가",
        prompt=f"다음 설명('{description}')을 바탕으로 비용을 다음 카테고리 중 하나로 분류하세요: {categories}"
    )
```

---

## 2단계: 구매 규칙 전문가 생성

최신 정책 가이드라인을 사용하기 위해, **디스크의 파일에서 구매 규칙을 읽어와** 송장을 검증합니다. 정책이 바뀌어도 코드를 수정할 필요가 없는 동적 시스템입니다.

```python
@register_tool(tags=["invoice_processing", "validation"])
def check_purchasing_rules(action_context: ActionContext, invoice_data: dict) -> dict:
    rules_path = "config/purchasing_rules.txt"
    # 파일에서 규칙을 읽어옴 (휴먼 리더블 정책이 곧 로직이 됨)
    # ...
    return prompt_expert(
        action_context=action_context,
        description_of_expert="구매 정책에 정통한 기업 조달 준수 담당자",
        prompt=f"송장 데이터: {invoice_data}가 다음 구매 규칙을 준수하는지 확인하세요: {purchasing_rules}"
    )
```

### 작동 원리

1. **디스크에서 규칙 읽기**: 도구가 실행될 때마다 최신 정책 파일을 로드
2. **프롬프트에 규칙 삽입**: LLM 전문가는 프롬프트 내의 전체 정책 텍스트를 전달받아 판단
3. **검증 보고서 반환**: 준수 여부(`true`/`false`)와 문제점에 대한 간략한 설명 출력

### 코드 변경 없는 규칙 업데이트 예시

정책 파일에 `"5,000달러 이상의 모든 구매는 사전 승인이 필요함"` 이 명시된 경우, 6,000달러짜리 송장 수신 시 에이전트가 자동으로 위반 사항을 감지합니다.

```json
{"compliant": false, "issues": "이 구매는 5,000달러를 초과하지만 필요한 사전 승인이 누락되었습니다."}
```

---

## 구조화된 응답 생성 (JSON)

단순 텍스트 응답은 시스템 자동화에 한계가 있으므로, `prompt_llm_for_json`을 사용하여 결과를 **정형화된 JSON 포맷**으로 받습니다. 이를 통해 데이터베이스 기록이나 워크플로우 자동 트리거가 용이해집니다.

---

## 3단계 & 4단계: 에이전트 업데이트 및 테스트

에이전트에게 아래 순서로 작업을 수행하도록 목표(Goals)를 설정합니다.

```
송장 추출 → 요약 생성 → 전문가 분류 → 정책 검증 → 저장
```

**결과 예시:**

```
Invoice #4567 - 분류: IT 장비 - 준수 여부: 통과 - 저장 완료
```
