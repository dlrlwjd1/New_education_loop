# Popular Community Agent Skill Examples

## 개요

- 커뮤니티 저장소의 다양한 Agent Skill 사용 사례를 살펴본다.
- 코드 리뷰, frontend, testing, security, performance 자동화에 활용한다.

## 내용

강의는 많은 공개 skill 중 실제 개발에 유용한 예제를 골라 소개한다. 여러 agent가 같은 표준을 지원하므로 Antigravity뿐 아니라 다른 AI coding tool에도 응용할 수 있다.

외부 skill은 지시문과 script를 읽어 안전성, 프로젝트 적합성, 중복 여부를 확인한 뒤 설치한다.

## 예시

```text
Code review checklist
Frontend development guidelines
Web app testing
Security review
Performance optimization
```

## 요약

- 커뮤니티 skill은 작업 자동화의 좋은 출발점이다.
- 신뢰하지 않은 skill을 검토 없이 실행하지 않는다.
