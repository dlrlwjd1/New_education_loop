# Agent Skill Templates for Developers

## 개요

- 개발자가 참고할 실제 Agent Skill template을 제공한다.
- 코드 리뷰, frontend, 테스트, 성능 최적화 등의 예제가 포함된다.

## 내용

Code Review Checklist는 기능, 코드 품질, 보안, 성능, 테스트를 체계적으로 확인한다. Frontend Development Guidelines는 React·TypeScript 구조, strict typing, 성능 기준을 제공한다.

웹 테스트와 성능 최적화 skill도 반복 가능한 점검 절차로 활용할 수 있다. 원본은 [예제 저장소](https://github.com/dvasyliev/ai-dev-tools-getting-started/tree/main/antigravity/skills)에서 확인한다.

## 예시

```text
code-review-checklist/SKILL.md
frontend-development-guidelines/SKILL.md
web-performance-optimization/SKILL.md
```

## 요약

- template의 범위와 trigger를 프로젝트에 맞게 수정한다.
- 여러 skill의 책임이 겹치지 않도록 구성한다.
