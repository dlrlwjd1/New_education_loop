# Quick Start with Google Antigravity

## 개요

- 편집기, Explorer, Terminal, Agent 패널의 기본 사용법을 익힌다.
- 간단한 프로젝트를 통해 AI 코드 생성 흐름을 경험한다.

## 내용

왼쪽 메뉴에서 파일 탐색, 검색, 확장 기능을 사용하고 중앙 편집기에서 코드를 확인한다. 오른쪽 Agent 패널에서는 모델과 모드를 선택해 질문하거나 코드 변경을 요청할 수 있다.

AI는 숙련 개발자라기보다 구체적인 지시와 검토가 필요한 주니어 개발자처럼 다룬다. 작은 요청으로 시작하고 결과가 부족하면 컨텍스트와 세부 조건을 추가한다.

## 예시

```text
요청 → AI 변경안 확인 → diff 검토 → 실행·테스트 → 추가 지시
```

## 요약

- 편집기와 Agent 패널을 함께 사용한다.
- 세부 정보가 많을수록 결과가 정확해지지만 항상 사람이 검토한다.
