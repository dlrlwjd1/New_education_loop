# Install & Setup Google Antigravity

## 개요

- 운영체제에 맞는 Antigravity를 설치하고 초기 설정을 완료한다.
- 기존 VS Code 설정을 가져오거나 새 환경으로 시작할 수 있다.

## 내용

공식 사이트에서 macOS, Windows, Linux용 설치 파일을 내려받는다. 첫 실행 시 기존 코드 편집기의 설정과 테마를 가져오거나 **Start fresh**를 선택한다.

에이전트 설정은 처음에는 기본값을 유지하고, 동작 방식을 이해한 뒤 변경하는 편이 안전하다. Google 계정으로 로그인하고 약관을 확인하면 편집기와 확장 설치가 준비된다.

## 예시

```text
Download → Install → Import VS Code settings 또는 Start fresh
→ 기본 Agent 설정 → Google 로그인 → 약관 확인
```

## 요약

- 기존 개발 환경을 가져오면 전환 비용을 줄일 수 있다.
- 에이전트 권한과 설정은 이해한 뒤 조정한다.
