# Course Requirements

## 개요

- Antigravity나 AI IDE 경험 없이도 수강할 수 있는 입문 강의다.
- JavaScript 기초는 도움이 되지만 필수는 아니다.

## 내용

강의는 설치부터 실제 프로젝트까지 처음부터 단계적으로 진행한다. 프로그래밍 입문자도 화면을 따라가며 AI 기반 개발 과정을 이해할 수 있도록 구성됐다.

## 예시

```text
필수: 실습을 따라갈 컴퓨터
선택: JavaScript 기초 지식
```

## 요약

- 별도의 AI 도구 경험은 필요하지 않다.
- 강의를 따라 직접 기능을 실행하는 방식으로 학습한다.
