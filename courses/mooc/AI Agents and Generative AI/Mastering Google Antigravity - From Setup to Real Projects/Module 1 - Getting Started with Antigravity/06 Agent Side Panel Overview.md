# Agent Side Panel Overview

## 개요

- 긴 대화와 여러 파일 변경에는 Agent Side Panel을 사용한다.
- 작업별 대화를 분리하고 파일·이미지·코드를 컨텍스트로 첨부한다.

## 내용

Agent 패널은 코드 설명, 복수 파일 변경, 디버깅처럼 대화가 필요한 작업을 담당한다. 새 대화를 만들면 이전 작업과 컨텍스트가 섞이지 않는다.

대화에는 관련 파일과 이미지 등을 첨부할 수 있으며, 모델과 실행 모드를 선택할 수 있다. 에이전트가 제안한 변경은 파일별 diff로 검토한다.

## 예시

```text
기능 A → Conversation A
버그 수정 → New Conversation
관련 파일 첨부 → 요청 → 변경 검토
```

## 요약

- 작업이나 주제가 달라지면 새 대화를 만든다.
- 장기 작업은 충분한 컨텍스트와 변경 검토가 필요하다.
