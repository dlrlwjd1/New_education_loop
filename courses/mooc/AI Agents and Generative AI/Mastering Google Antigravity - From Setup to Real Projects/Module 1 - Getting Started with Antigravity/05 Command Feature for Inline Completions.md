# Command Feature for Inline Completions

## 개요

- 현재 커서 위치에서 자연어로 코드를 생성하거나 수정한다.
- 편집기뿐 아니라 터미널 명령 작성에도 AI를 활용한다.

## 내용

macOS에서는 `Cmd + I`, Windows에서는 `Ctrl + I`로 inline command를 연다. 빈 위치에서는 새 코드를, 선택 영역에서는 기존 코드를 수정하도록 요청할 수 있다.

명령 결과는 diff 형태로 확인하고 수락하거나 거절한다. 터미널에서 모르는 명령이 필요할 때도 자연어로 설명해 제안을 받을 수 있지만 실행 전 내용을 검토한다.

## 예시

```text
커서 위치 → Cmd/Ctrl + I
→ "오늘 날짜를 반환하는 함수를 추가해줘"
→ 생성 코드 검토 → Accept
```

## 요약

- 작은 국소 변경은 별도 채팅보다 inline command가 빠르다.
- 생성 코드와 터미널 명령은 실행 전에 확인한다.
