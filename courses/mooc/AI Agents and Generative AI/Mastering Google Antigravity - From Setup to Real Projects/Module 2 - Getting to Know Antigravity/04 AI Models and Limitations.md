# Antigravity AI Models & Limitations

## 개요

- 추론 모델과 백그라운드 모델이 역할을 나눠 동작한다.
- 작업의 복잡도, 속도, 출력 특성에 맞춰 모델을 선택한다.

## 내용

강의는 복잡한 설계와 추론에는 상위 모델, 문서화와 구조화된 출력에는 읽기 쉬운 응답을 주는 모델, 빠른 수정에는 경량·고속 모델을 선택하는 전략을 소개한다.

선택한 reasoning model은 에이전트의 계획과 실행 품질에 직접 영향을 준다. 오픈 모델은 실험에 유연하지만 큰 프로젝트에서는 성능 차이가 날 수 있다. 백그라운드 모델은 탐색, 기억, 시각화처럼 보조 작업을 처리한다.

## 예시

```text
복잡한 아키텍처 → 강한 추론 모델
빠른 국소 수정 → 고속 모델
문서·리팩터링 → 구조화 출력에 강한 모델
```

## 요약

- 하나의 모델이 모든 작업에 최적인 것은 아니다.
- 모델을 바꾸면 같은 프롬프트의 결과도 달라질 수 있다.
