# Overview of Google Antigravity

## 개요

- Antigravity는 AI가 편집기 안에서 개발을 지원하는 AI-powered code editor다.
- 코드 생성, 설명, 개선, 문제 해결을 한 작업공간에서 수행한다.

## 내용

이 도구는 현대 개발의 복잡성, 반복 작업, 학습 장벽을 줄이는 것을 목표로 한다. 문서 검색과 도구 전환을 줄이고, 현재 코드의 맥락에서 제안과 설명을 제공한다.

AI는 협업 파트너이며 최종 결정권자는 사용자다. 생성된 코드를 수락·수정·거절하고 요구사항 충족 여부를 직접 확인해야 한다.

## 예시

```text
반복 코드 생성 + 낯선 문법 설명 + 개선 제안
→ 사용자가 검토하고 최종 선택
```

## 요약

- Antigravity는 코드 편집기와 AI 협업을 결합한다.
- 자동화는 개발자의 이해와 소유권을 대신하지 않는다.
