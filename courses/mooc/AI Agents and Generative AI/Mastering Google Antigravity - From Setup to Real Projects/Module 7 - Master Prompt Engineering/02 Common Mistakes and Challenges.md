# Common Mistakes and Challenges

## 개요

- bias, ambiguity, hallucination, context 한계가 주요 위험이다.
- 모델과 사용 환경 변화에 따라 prompt도 계속 조정해야 한다.

## 내용

학습 데이터의 편향이 출력에 재현될 수 있고, 다의적인 표현은 AI가 다른 의미로 해석할 수 있다. AI는 확신 있게 잘못된 사실을 만들거나 대화 중 스타일과 논리를 일관되게 유지하지 못할 수 있다.

지나치게 적은 정보와 과도한 제약 사이의 균형도 필요하다. 결과를 검증하고 중요한 사실은 출처로 확인한다.

## 예시

```text
"Java를 설명해줘"
→ programming language인지 island인지 명확히 지정
```

## 요약

- 모호한 용어, 편향, 사실 오류를 적극 점검한다.
- AI 사용 교육과 사람의 검증이 위험을 줄인다.
