# What Is Prompt Engineering?

## 개요

- Prompt engineering은 AI가 원하는 결과를 내도록 지시를 작성·개선하는 과정이다.
- 첫 응답이 부족하면 세부 정보와 표현을 반복 조정한다.

## 내용

Prompt는 간단한 질문부터 역할, 맥락, 스타일, 형식이 포함된 복잡한 지시까지 다양하다. 요청이 명확할수록 관련성과 정확도가 높아진다.

좋은 prompt는 작업 목적, 필요한 컨텍스트, 제약, 기대 출력 형식을 전달한다. 연습과 피드백을 통해 개선하는 기술이다.

## 예시

```text
모호함: "React에 대해 써줘"
구체적: "초급 개발자를 위해 React가 인기 있는 이유를
친근한 톤의 500자 블로그 글로 작성해줘."
```

## 요약

- 좋은 결과는 좋은 지시와 반복 개선에서 나온다.
- prompt engineering은 개발, 글쓰기, 학습 등 여러 분야에 적용된다.
