# Mastering Google Antigravity: From Setup to Real Projects

**Course URL:** [mooc.org/learn/mastering-google-antigravity-from-setup-to-real-projects](https://www.mooc.org/learn/mastering-google-antigravity-from-setup-to-real-projects)

SkillsBooster Academy가 제공하는 Google Antigravity 실습 강좌. 편집기 설치와 AI coding 기능부터 Calendar App 구현, workspace context, Rules, Workflows, Agent Skills, prompt engineering까지 다룬다.

## 개요

- 제공 기관: SkillsBooster Academy
- 강사: Anton Voroniuk, Dmytro Vasyliev
- 난이도: 초급
- 예상 학습 시간: 약 6시간
- 구성: 7개 모듈, 영상 40개, 읽기 자료 4개, 평가 4개
- 강의 페이지 기준 최근 업데이트: 2026년 4월
- 전문 과정: Master AI Coding Agents for Advanced Software Development Specialization

## 학습 목표

- Google Antigravity를 설치하고 Tab, Navigation, inline command, Agent 패널을 사용한다.
- Fast Mode, Planning Mode와 chat context를 작업에 맞게 선택한다.
- React·TypeScript Calendar App을 계획, 구현, 개선, 리팩터링, 테스트한다.
- workspace boundary와 ignored files로 Agent context를 관리한다.
- Rules, Workflows, Agent Skills로 반복 가능한 AI 개발 방식을 만든다.
- 명확하고 검증 가능한 prompt를 설계한다.
