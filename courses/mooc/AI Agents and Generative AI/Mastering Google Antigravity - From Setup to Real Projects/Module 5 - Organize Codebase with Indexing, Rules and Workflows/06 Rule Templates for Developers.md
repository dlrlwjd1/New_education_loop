# Rule Templates for Developers

## 개요

- 개발자가 재사용할 수 있는 실제 Rule template 링크를 제공한다.
- frontend, accessibility, form, HTML/CSS, React 기준을 포함한다.

## 내용

Frontend template은 functional component, TypeScript, reusable UI, typed props, naming, styling과 코드 품질을 다룬다. Accessibility Guard는 keyboard, label, focus, modal과 오류 메시지를 점검한다.

그 밖에 form validation, HTML/CSS 구조, React 개발 규칙을 프로젝트의 시작점으로 사용할 수 있다. 원본은 강의가 연결한 [예제 저장소](https://github.com/dvasyliev/ai-dev-tools-getting-started/tree/main/antigravity/rules)에서 확인한다.

## 예시

```text
template 선택 → 프로젝트 규칙과 비교
→ 불필요 항목 제거 → 팀 기준 추가 → 적용 테스트
```

## 요약

- template은 복사 후 반드시 프로젝트에 맞게 수정한다.
- 접근성·타입·폼 규칙을 초기 기준으로 활용한다.
