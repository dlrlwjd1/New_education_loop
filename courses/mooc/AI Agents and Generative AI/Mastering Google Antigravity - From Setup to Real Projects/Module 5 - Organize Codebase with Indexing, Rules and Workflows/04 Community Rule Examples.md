# Popular Community Rule Examples

## 개요

- React·frontend 프로젝트에 활용할 커뮤니티 규칙을 살펴본다.
- accessibility, form, HTML/CSS, React 품질 기준을 조합한다.

## 내용

Accessibility Guard는 icon button, keyboard support, image alt, label, focus, modal, error message를 다룬다. Frontend·React 규칙은 functional component, TypeScript, typed props, 재사용 UI, naming과 코드 품질을 규정한다.

커뮤니티 규칙을 그대로 복사하기보다 팀과 프로젝트에 필요한 항목을 선택해 자체 규칙으로 다듬는다.

## 예시

```text
Accessibility Guard + React standards + Form rules
→ 프로젝트 특성에 맞게 충돌 제거
→ 하나의 rule set으로 통합
```

## 요약

- 예제는 규칙 설계의 출발점이다.
- 중복과 충돌을 제거한 뒤 프로젝트에 적용한다.
