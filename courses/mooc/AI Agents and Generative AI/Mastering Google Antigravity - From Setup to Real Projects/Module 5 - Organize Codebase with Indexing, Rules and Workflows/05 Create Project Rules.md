# Create Your Own Project Rules

## 개요

- UI 또는 파일 시스템에서 workspace·global rule을 만든다.
- 팀의 coding convention을 Agent의 반복 지침으로 변환한다.

## 내용

프로젝트에만 적용할 규칙과 모든 프로젝트에 적용할 개인 규칙을 구분한다. React component 구조, TypeScript 사용, naming, test 작성처럼 자주 반복하는 기준을 Markdown으로 기록한다.

규칙에는 목적, 적용 조건, 구체적인 해야 할 일과 하지 말아야 할 일을 포함한다. 지나치게 긴 규칙은 관련 파일로 나눈다.

## 예시

```text
Project rule: 이 저장소의 React·TypeScript 기준
Global rule: 개인의 공통 코드 리뷰 선호
```

## 요약

- 팀 규칙은 workspace에 두어 저장소와 함께 공유한다.
- 구체적이고 충돌 없는 규칙이 잘 적용된다.
