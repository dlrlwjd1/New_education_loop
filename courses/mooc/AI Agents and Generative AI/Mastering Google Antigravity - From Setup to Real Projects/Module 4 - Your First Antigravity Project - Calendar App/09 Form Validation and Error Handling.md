# Enhance Form Validation and Error Handling

## 개요

- AI에게 UX·frontend 전문가 관점의 form review를 맡긴다.
- validation rule, edge case, 오류 메시지, 날짜·시간 논리를 개선한다.

## 내용

구체적인 해결책을 모두 지시하기보다 현재 form의 문제를 분석하고 개선 계획을 제안하도록 요청한다. title과 description의 길이, 필수 입력, 시간 범위, 잘못된 날짜 조합, 사용자가 이해할 수 있는 메시지 등을 검토한다.

계획을 확인한 뒤 구현과 브라우저 검증을 허용한다. 에이전트의 자동 verification 영상도 참고할 수 있지만 사람이 직접 form을 테스트해야 한다.

## 예시

```text
Review this form as a UX and frontend expert.
Find missing validation, edge cases, unclear errors,
date/time issues, and character-limit problems.
```

## 요약

- AI에게 문제 발견과 개선안 제안을 맡길 수 있다.
- 자동 검증 결과만 믿지 말고 직접 잘못된 입력을 시험한다.
