# Create Implementation Plan

## 개요

- 코드를 만들기 전에 단계별 구현 계획을 생성하고 검토한다.
- 스크린샷과 기능 요구사항을 구체적인 컴포넌트 구조로 변환한다.

## 내용

Vite CLI, React, TypeScript를 기술 스택으로 지정하고 두 스크린샷에서 사용할 UI 요소를 구분해 설명한다. AI는 프로젝트 초기화, 라이브러리, 폴더 구조, header, sidebar, calendar, day panel 등의 구현 순서를 제안한다.

사용자는 계획에서 잘못된 라이브러리나 누락된 데이터 모델, 과도한 범위를 확인하고 댓글로 수정한다. 계획이 확정된 뒤에만 실행한다.

## 예시

```text
요구사항 + screenshots
→ component/data model 계획
→ 계획 검토와 댓글
→ Proceed
```

## 요약

- 계획 단계는 AI가 코드를 만들기 전에 방향을 교정할 기회다.
- 화면 요소, 기술 스택, 데이터와 동작을 모두 명시한다.
