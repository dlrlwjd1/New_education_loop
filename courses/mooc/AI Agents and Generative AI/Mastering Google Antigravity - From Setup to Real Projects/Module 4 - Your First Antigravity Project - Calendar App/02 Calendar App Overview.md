# Calendar App Overview

## 개요

- 완성할 앱의 화면 구조와 이벤트 관리 흐름을 확인한다.
- 월·연도 탐색, 날짜별 일정, CRUD가 핵심 기능이다.

## 내용

중앙에는 월간 calendar grid, 왼쪽에는 월·연도 sidebar, 오른쪽에는 선택한 날짜의 day panel이 배치된다. 일정이 있는 날짜에는 이벤트 수에 따라 색상 점이 표시된다.

날짜를 클릭하면 해당 일정을 보고, 추가 버튼으로 이벤트를 만든다. 각 이벤트의 action menu에서 수정하거나 삭제하며 삭제 전 확인 dialog를 표시한다.

## 예시

```text
Months Sidebar | Calendar Grid | Day Agenda
                 날짜 선택       이벤트 목록·추가·수정·삭제
```

## 요약

- 앱은 탐색 영역, 월간 보기, 일간 일정의 세 영역으로 구성된다.
- UI 상태와 이벤트 데이터가 일관되게 갱신돼야 한다.
