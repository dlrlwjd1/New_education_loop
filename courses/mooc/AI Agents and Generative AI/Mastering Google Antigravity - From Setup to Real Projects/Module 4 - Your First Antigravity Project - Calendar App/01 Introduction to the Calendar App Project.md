# Introduction to Your First Antigravity Project

## 개요

- Antigravity와 AI를 사용해 실제 Calendar App을 단계적으로 만든다.
- AI를 블랙박스로 사용하지 않고 결과를 검토하며 개발한다.

## 내용

이 프로젝트에서는 이벤트 생성·수정·삭제, validation, 오류 메시지, empty state, UI 개선을 구현한다. 이후 큰 컴포넌트를 분리하고 기본 테스트와 문서를 추가한다.

작업마다 적절한 Agent mode와 모델을 선택하고, 프롬프트를 반복 개선하며 AI의 실수를 직접 확인한다.

## 예시

```text
기능 계획 → AI 구현 → 결과 검증 → 피드백
→ 리팩터링 → 테스트 → 문서화
```

## 요약

- 기능 단위로 작게 구현하고 계속 검증한다.
- AI는 조력자이며 설계와 품질 판단은 개발자가 맡는다.
