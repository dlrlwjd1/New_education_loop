# Build the Calendar App in the Editor by a Plan

## 개요

- 승인한 계획을 따라 React·TypeScript 앱을 생성한다.
- 에이전트가 실행하려는 명령과 결과물을 감독한다.

## 내용

에이전트는 Vite로 프로젝트를 만들고 의존성을 설치한 뒤 계획의 컴포넌트 구조를 구현한다. 명령 실행 권한을 항상 허용할 수도 있지만, 내용을 이해하지 못하는 단계에서는 매번 확인하도록 두는 것이 안전하다.

완료 후 연·월 탐색, 날짜 선택, 일정 표시, 반응형 배치가 요구사항대로 동작하는지 확인한다. 아직 구현하지 않은 추가 버튼 등은 다음 단계의 작업으로 남긴다.

## 예시

```text
Implementation Plan 승인
→ Vite React TypeScript 초기화
→ 의존성 설치 승인
→ 컴포넌트 생성
→ 브라우저에서 요구사항 검증
```

## 요약

- 계획대로 생성됐는지 기능 단위로 확인한다.
- 터미널 명령은 자동 승인보다 검토 후 승인이 안전하다.
