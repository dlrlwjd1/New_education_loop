# Popular Approaches to Build a Calendar App

## 개요

- Step-by-step, design-first, plan-first, mixed의 네 접근법을 비교한다.
- 프로젝트 상황에 맞춰 통제력과 속도의 균형을 선택한다.

## 내용

- **Step-by-step**: 작은 변경마다 검토해 안전하지만 프롬프트가 많다.
- **Design-first**: 스크린샷이나 Figma를 빠르게 UI로 옮기지만 로직과 구조를 나중에 보완해야 한다.
- **Plan-first**: 복잡한 기능을 계획 후 구현해 예측 가능성이 높다.
- **Mixed**: UI는 시각 자료로 시작하고 기능은 계획·단계별 구현으로 보완한다.

## 예시

| 상황 | 접근법 |
|---|---|
| 기존 서비스의 조심스러운 수정 | Step-by-step |
| 디자인 시안 구현 | Design-first |
| 복잡한 신규 기능 | Plan-first |
| 일반적인 실제 프로젝트 | Mixed |

## 요약

- 하나의 방식만 고집하지 않는다.
- 실제 프로젝트에는 mixed approach가 균형 잡힌 선택이다.
