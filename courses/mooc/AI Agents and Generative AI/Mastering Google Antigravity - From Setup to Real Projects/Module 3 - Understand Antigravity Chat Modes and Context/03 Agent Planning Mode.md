# Plan Your Work with Agent Planning Mode

## 개요

- Planning Mode는 복잡한 작업을 조사하고 단계별 계획을 만든 뒤 실행한다.
- 여러 파일, 구조 변경, 복잡한 로직에 적합하다.

## 내용

새 기능, 코드베이스 리팩터링, 아키텍처 변경처럼 실패 비용이 큰 작업은 계획을 먼저 검토한다. 에이전트는 저장소를 조사하고 구현 순서와 변경 파일을 제안한다.

사용자는 계획에 댓글을 달아 누락과 잘못된 가정을 수정한 뒤 실행을 승인한다. Fast Mode보다 느리지만 재작업을 줄이고 결과를 예측하기 쉽다.

## 예시

```text
복잡한 요청 → 코드베이스 조사 → Implementation Plan
→ 사용자 댓글·수정 → 실행 → 테스트·검토
```

## 요약

- 큰 변경은 계획 검토 단계에서 방향을 바로잡는다.
- 실행 후에도 코드 리뷰와 테스트는 생략하지 않는다.
