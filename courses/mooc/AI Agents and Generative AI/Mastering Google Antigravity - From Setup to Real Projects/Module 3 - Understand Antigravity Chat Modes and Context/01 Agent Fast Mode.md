# Execute Tasks with Agent Fast Mode

## 개요

- Fast Mode는 계획과 검증 단계를 줄여 단순 작업을 빠르게 실행한다.
- 사람이 쉽게 확인할 수 있는 국소 변경에 적합하다.

## 내용

변수·메서드 이름 변경, 몇 개의 명령 실행, 작은 코드 수정처럼 범위가 분명한 작업에 사용한다. 복잡한 구현을 Fast Mode에 맡기면 구조적 실수나 누락 가능성이 커진다.

속도를 얻는 대신 품질 검토 책임이 사용자에게 더 많이 남는다. 여러 파일이나 비즈니스 로직을 건드리면 Planning Mode로 전환한다.

## 예시

```text
적합: 변수 rename, 작은 CSS 수정, 단순 명령
부적합: 새 기능 전체, 대규모 refactoring, 복잡한 class
```

## 요약

- 빠르고 쉽게 검증 가능한 작업에만 사용한다.
- 복잡성이 올라가면 Planning Mode를 선택한다.
