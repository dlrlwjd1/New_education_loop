# Use Chat Context for Better Responses

## 개요

- 관련 파일, 메서드, 오류 출력 등을 제공하면 응답 정확도가 높아진다.
- 너무 많은 컨텍스트는 오히려 에이전트의 초점을 흐릴 수 있다.

## 내용

`fix the bug`처럼 모호한 요청보다 문제가 있는 파일, 함수, 오류 메시지, 기대 동작을 함께 전달한다. Agent는 실제 프로젝트 구조와 이름을 확인한 뒤 기존 코드에 맞는 답을 낼 수 있다.

파일, 선택 코드, terminal output, 이전 대화 등을 컨텍스트로 추가할 수 있다. 최소한의 관련 자료로 시작하고 필요할 때 확장한다.

## 예시

```text
나쁜 요청: "버그를 고쳐줘"
좋은 요청: "EventForm.tsx의 saveEvent에서 이 오류가 난다.
첨부한 terminal output을 보고 기존 타입을 유지하며 수정해줘."
```

## 요약

- 요청에는 위치, 문제, 기대 결과를 포함한다.
- 관련 없는 대량의 파일을 무조건 첨부하지 않는다.
