# 10 Reading: Generative AI Risks

## 개요
- 생성형 AI(generative AI)와 관련된 잠재적 리스크(기회와 위협 양쪽)를 체계적으로 정리한 5분 분량 읽기 자료

## 내용
- **리스크(risk)**는 이니셔티브에 긍정적 또는 부정적 영향을 미칠 수 있는 모든 사건 — 제품 관리자는 생성형 AI 사용에서 비롯되는 잠재적 리스크를 인지하고 이를 식별·대응해야 함
- 리스크 관리 활동에는 **부정적 리스크(위협) 식별·완화**와 **긍정적 리스크(기회) 식별·활용** 양쪽이 모두 포함됨

### 기회 (긍정적 리스크)
| 리스크 | 대응 |
|---|---|
| 다수 아이디어 생성 | 실현 가능성·관련성 기반으로 아이디어 우선순위화·정제할 필터링 시스템 구현 |
| 모델 속도·효율성 | 조기의 엄격한 테스트·검증으로 이슈를 신속히 식별·해결 |
| 품질 향상 | AI와 인간 전문성을 결합해 창의성과 효율성의 균형 확보 |
| 커스터마이징 | 효과적인 모델 확장성을 위한 커스터마이징 경계 정의 |
| 경쟁 우위 | 자사 제품 역량을 경쟁사와 비교·차별화, 효과적인 가치 제안·포지셔닝 문구 개발 |

### 위협 (부정적 리스크)
| 리스크 | 대응 |
|---|---|
| 사용자 경험·수용성 | 설계 초기부터 사용자를 참여시키고, 사용성 테스트 실시, 피드백 수집·반영 |
| 직원 저항 | 훈련 제공·이점 소통, 고용 안정성 우려 해소, 검증된 변화 관리 기법 활용 |
| 법률·컴플라이언스 | 프라이버시 법률·데이터 보호 규제·업계 표준 식별·준수 |
| 비즈니스 모델 붕괴 | 전략적으로 전환 계획 수립, 매출원 다각화, 이해관계자와 효과적으로 소통 |
| 공급업체·파트너 리스크 | 공급업체 다각화, 엄격한 소싱 기준 개발, 벤더 관리 구현 |
| 윤리·사회적 리스크 | AI 결정이 특정 집단에 해를 끼치거나 편향을 지속시키지 않는지 윤리 평가 실시, 이슈를 사전에 다루기 |
| AI 생성 코드의 가독성·유지보수성 | 코드를 정기적으로 검토·리팩터링, 모델 알파 테스트, 코딩 표준 수립 및 인간 개발자 참여 |
| 보안 결함 | 취약점 모니터링, 정기적 보안 감사 실시, 보안 코딩 관행 사용 |
| 지식재산권 유출 | IP 실사(due diligence) 수행, 모델 학습 데이터 추적, 법적 준수 |
| 편향과 차별 | 모델의 편향을 정기적으로 감사, 학습 데이터 다각화 |
| 낮은 투명성 | 불투명한 AI 결정을 식별하고 이해관계자에게 투명성 제공 |
| 기술 부채(technical debt) | 클린 코드 유지, 기술 부채 감소를 위한 자원 배정 |
| 투자·투자수익률(ROI) | 명확한 재무 목표 설정, 모든 직간접 비용 식별, 비용-편익 분석 검증 |

## 요약
- 효과적인 리스크 관리는 제품 관리자의 핵심 역할이며, 생성형 AI 활용에 영향을 미치는 기회와 위협을 모두 식별해 위협은 완화하고 기회는 활용하는 대응책을 개발해야 함
- [10 Challenges with Generative AI](../Module%201%20-%20Product%20Management%20and%20Generative%20AI/10%20Challenges%20with%20Generative%20AI.md)에서 다룬 4대 과제 범주(데이터·기술·인간-AI 균형·조직)가 이 자료에서 13개의 구체적 위협과 5개의 구체적 기회로 세분화됨
- 표 형태로 정리되어 실무에서 리스크 등록부(risk register)로 바로 활용 가능한 참고 자료
