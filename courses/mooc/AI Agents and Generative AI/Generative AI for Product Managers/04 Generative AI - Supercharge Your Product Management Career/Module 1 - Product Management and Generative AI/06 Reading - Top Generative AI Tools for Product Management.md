# 06 Reading: Top Generative AI Tools for Product Management

## 개요
- 제품 관리자가 널리 사용하는 생성형 AI(generative AI) 도구들을 용도별로 요약한 2분 분량 읽기 자료

## 내용
- 생성형 AI 도구는 시장 조사(market research), 고객 세분화(customer segmentation), 피드백 분석(feedback analysis) 등 다양한 제품 관리 활동을 지원
- 아래 목록은 **포괄적이지도, 우선순위 순도 아니며**, 최신 가격은 각 웹사이트에서 확인 필요

### 주요 생성형 AI 도구와 용도
| 도구 | 용도 |
|---|---|
| **Canva** | 시각 콘텐츠 제작 간소화 — 드래그 앤 드롭(drag-and-drop) 인터페이스와 템플릿 라이브러리 제공 |
| **ChatGPT** | 텍스트 요약·편집·생성, 제품 관련 데이터 접근, 제품 아이디어 도출(ideation)·분석 등 다양한 제품 관리 작업 수행 |
| **ClickUp** | AI로 텍스트/카피 생성, 문서 요약 및 액션 아이템 생성 |
| **Copilot** | 제품 콘셉트 개발(기능·특징 제안), 제품 비교·경쟁 분석, 마케팅 캠페인·가치 제안·포지셔닝 문구 제안 |
| **DALL-E** | 텍스트 설명으로 이미지 생성 — 제품 아이디어를 설명하면 시각 자료로 변환, 아이디어 도출·마케팅에 유용 |
| **Gemini** | 사람처럼 자연스러운 텍스트 생성 — 브레인스토밍, 콘텐츠 제작, 제품 설명 초안 작성 |
| **Gencraft** | 단어를 AI 생성 아트/사진으로 변환 — 콘셉트·아이디어·제품 디자인 시각화, 창의적 정체(creative block) 극복 |
| **Google Notebook LM** | 긴 문서에서 요약 생성, 여러 문서에서 인사이트 추출, 온라인 리서치 정보 통합 |
| **LogicBalls** | 제품 로드맵(roadmap) 개발, 개요 작성, 보고서 수정 등 혁신 기능 제공 |
| **Midjourney** | 아이디어를 AI 생성 비주얼로 변환 — 제품 콘셉트·디자인·마케팅 자료 시각화 |
| **Picsart** | 이미지·영상 표준 편집 도구 — 제품 비주얼 강화, 마케팅 자료·프레젠테이션·세일즈 데모 제작 |
