# 03 Reading: How to Make the Most of this Course

## 개요
- 코스에서 최대의 학습 효과와 자격증/취업 인터뷰에 필요한 지식을 얻기 위한 5가지 학습 전략 팁

## 내용

### Tip 1 — 코스 콘텐츠에 익숙해지기
- 모듈 구조를 훑어보며 주제와 관련 자료(assets)에 대한 감각을 잡을 것 — 코스 탐색이 쉬워지고 필수/선택 주제를 구분하는 데 도움
- 주제의 순서에 익숙해지면 아이디어들을 서로 연결해 하나의 응집된 전체로 이해하는 데 도움

### Tip 2 — 코스 완료 일정 세우기
- 코스를 마칠 목표일을 정하고 매일 학습 시간을 배정할 것 — 각 모듈을 완료할 합리적인 목표 설정

### Tip 3 — 능동적인 학습자 되기
- 학습 시간을 따로 확보하고 방해 요소를 피할 것
- 강의 영상을 볼 때 **노트 필기** — 트랜스크립트를 다운로드해 중요한 부분을 하이라이트하거나 별도로 필기
- 학습에 몰입하는 것이 더 많이 배우고 이해도를 스스로 측정하는 데 중요
- 읽기 자료를 꼼꼼히 살펴볼 것 — 강의 영상과 실제 시나리오를 연결해줌
- **Expert Viewpoints**(전문가 관점) 자료가 제품 관리 관련 질문에 대한 전문가 답변을 담고 있음 — 강의 영상·읽기 자료에서 배운 내용과 비교해볼 것
- 데모 영상을 검토하고 랩(labs)을 시도할 것 — 제품 관리자로서 필요한 다양한 활동에 익숙해지는 데 도움
- Practice Quiz를 모두 풀어보고 정답/오답 피드백을 읽을 것 — 모든 답이 맞을 때까지 재시도
- Graded Quiz를 모두 완료할 것 — 틀린 문항이 있으면 해당 주제를 다시 검토하고 정답과 그 이유를 이해할 것. 최소 합격 점수가 있지만 더 높은 점수를 위해 재시도 가능
- Discussion Forum은 선택사항이지만 적극적인 참여를 권장 — 사려 깊은 응답을 작성하고 다른 사람의 게시물에도 반응할 것

### Tip 4 — 가족·친구에게 학습 목표 알리기
- 코스 등록은 첫걸음일 뿐 — 스스로에게 책임을 지우고 코스에 전념할 것을 다짐. 가족·친구에게 이 약속을 알리고, 다른 관점이 필요한 주제가 있다면 그들을 참여시킬 것

### Tip 5 — 계획을 끝까지 실행하기
- Tip 2에서 세운 일정을 유지하고 동기를 잃지 않을 것. 목표를 달성하기 위해 전념하고 실행할 것

## 요약
- 이 코스의 학습 전략: **구조 파악 → 일정 수립 → 능동적 학습(노트·읽기·랩·퀴즈·포럼 활용) → 주변에 목표 공유 → 끝까지 실행**
- 특히 이 코스에는 **Expert Viewpoints**(전문가 인터뷰)와 **hands-on labs**가 포함되어 있어, 이론과 실무를 비교·연결하는 것이 권장됨
