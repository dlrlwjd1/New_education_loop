# 04 Hands-on Lab: Text Generation in Action (실습 — 텍스트 생성)

## 개요
- 실습 랩 (소요 시간 약 30분)
- 대표 텍스트 생성 도구 **ChatGPT**(OpenAI)와 **Gemini**(Google)를 직접 사용
- 텍스트 생성(text generation)과 텍스트 요약(text summarization)을 체험

### 학습 목표
- 생성형 AI의 텍스트 생성 역량 탐색
- ChatGPT로 이메일 작성
- ChatGPT로 단위 변환(unit conversion) 수행
- Gemini로 텍스트 요약

## 내용

### 텍스트 생성이란
- 생성형 AI의 최대 잠재력 중 하나는 **문맥 기반의 매력적인 콘텐츠 생성**
- 생성 가능한 형식: 기사, 블로그, 소셜 포스트, 제품 설명, 마케팅 카피, 언어 번역, 대화형 상호작용, 이미지 설명 등

### 실습 1 — ChatGPT로 이메일 작성
1. ChatGPT(https://chat.openai.com/) 로그인 (무료 계정 가능)
2. 상황(context)을 담은 프롬프트 입력 — 예:
   > "You are a customer support representative at XYZ Inc. ... Write a feedback request email for this scenario."
3. 생성된 이메일을 검증·복사·수정하여 활용
- **팁**: 주제·맥락을 구체적으로 넣을수록 결과가 좋음
- 연습 예시: 교수에게 미팅 요청, 지원한 직무 팔로업, 사내 행사 초대, 프로젝트 지연 리마인더, 신제품 출시 안내

### 실습 2 — ChatGPT로 단위 변환
1. 로그인 상태에서 계산이 필요한 상황을 프롬프트로 입력 — 예:
   > "Convert 500 grams to ounces and provide the result based on the appropriate conversion factor."
2. 응답을 검증·활용
- ChatGPT의 **계산 능력(computational abilities)** 확인이 목적 (수학·단위 변환·문제 해결)
- 연습 예시: 삼각형 넓이, 다섯 숫자 평균, 단리(simple interest) 계산

### (선택) 실습 — Gemini로 텍스트 요약
> Gemini는 일부 국가에서 사용 불가하여 선택 실습
1. Gemini(https://gemini.google.com/) Gmail 계정으로 로그인
2. 요약 프롬프트 입력 — 예: 특정 기사/블로그 URL을 짧은 문단으로 요약
3. 결과가 불만족스러우면 **redo**로 재생성, 결과 복사/공유(Share Conversation) 가능
- 요약은 긴 텍스트에서 핵심을 뽑아 관련 없는 부분을 제거 → 시간 절약
- 연습: 기사, 블로그, 연구 논문·보고서 요약

## 요약
- **ChatGPT** — 이메일 작성(생성), 단위 변환(계산)
- **Gemini** — 긴 텍스트 요약
- 공통 주의사항: 생성 결과의 **사실 정확성(factual accuracy)을 반드시 검증**하고, 기술을 **윤리적·책임 있게** 사용
