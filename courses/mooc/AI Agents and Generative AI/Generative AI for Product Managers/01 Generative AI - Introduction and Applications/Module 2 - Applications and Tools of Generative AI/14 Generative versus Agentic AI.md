# 14 Generative versus Agentic AI (생성형 AI vs 에이전틱 AI)

## 개요
- 생성형 AI(Generative AI)와 에이전틱 AI(Agentic AI)의 근본적 차이를 다루는 영상 — **반응형(reactive) vs 능동형(proactive)** 시스템의 구분이 핵심
- 관련 심화 자료: [AI Agents and Agentic AI with Python & Generative AI](../../../AI%20Agents%20and%20Agentic%20AI%20with%20Python%20%26%20Generative%20AI/README.md) 강좌 전체가 이 주제(에이전틱 AI)를 깊이 다룸

## 내용

### 생성형 AI = 반응형(Reactive) 시스템
- 챗봇, 이미지 생성기 등 우리가 익히 아는 것들
- **사용자의 프롬프트를 기다렸다가**, 프롬프트가 오면 훈련 중 학습한 패턴에 기반해 콘텐츠(텍스트·이미지·코드·오디오)를 생성
- 본질은 **정교한 패턴 매칭 기계** — 단어·픽셀·음파 사이의 통계적 관계를 방대한 데이터셋에서 학습, 프롬프트가 주어지면 "다음에 무엇이 와야 하는지"를 예측
- **생성으로 작업이 끝남** — 사용자의 추가 입력 없이는 스스로 다음 단계로 나아가지 않음

### 에이전틱 AI = 능동형(Proactive) 시스템
- 생성형 AI처럼 사용자 프롬프트로 시작하지만, 그 프롬프트는 **여러 단계의 행동(actions)을 거쳐 목표(goal)를 추구**하는 데 쓰임
- 에이전틱 시스템의 **라이프사이클**: 환경을 **지각(perceive)** → 취할 행동을 **결정(decide)** → 행동을 **실행(execute)** → 결과로부터 **학습(learn)** → 다시 반복 — 이 모든 과정이 **최소한의 인간 개입**으로 이뤄짐
  - (이 4단계 루프는 [AI Agents 강좌 Module 1의 Agent Loop(6단계)](../../../AI%20Agents%20and%20Agentic%20AI%20with%20Python%20%26%20Generative%20AI/Module%201%20-%20Agentic%20AI%20Concepts/README.md) 개념과 본질적으로 같은 아이디어)

### 공통 기반: LLM
- 생성형·에이전틱 AI 모두 종종 **LLM(대규모 언어 모델)**을 공통 기반으로 함
- 챗봇 등은 LLM이 백본(backbone), 이미지·오디오 생성에는 주로 **디퓨전 모델(diffusion model)**이 쓰임
- LLM은 에이전틱 시스템에 **추론(reasoning) 능력**도 제공 — 이것이 에이전트의 "생각하는 엔진(cognitive engine)" 역할을 함

### 실제 사례로 보는 차이
- **생성형 AI 사용 예**: 유튜버가 스크립트를 검토하고 썸네일 아이디어·배경음악을 생성 → 각 단계마다 **사람이 결과를 확인·수정·주도** (AI는 가능성을 생성하고, 사람이 큐레이션)
- **에이전틱 AI 사용 예**: **개인 쇼핑 에이전트** — 구매할 상품만 입력하면, 여러 플랫폼에서 재고를 찾고, 가격 변동을 모니터링하고, 결제를 처리하고, 배송까지 조율 — **필요할 때만 사용자에게 묻고** 대부분 스스로 진행
- 에이전틱 AI는 **지속적인 관리가 필요한 다단계(multi-step) 프로세스**에서 특히 강점을 보임

### Chain-of-Thought 추론
- LLM 기반 추론을 활용해 에이전트가 복잡한 작업을 더 작은 논리적 단계로 쪼개는 과정 = **Chain-of-Thought(사고의 연쇄) 추론**
- 예시: 컨퍼런스 기획 에이전트의 내적 대화 — "먼저 규모·기간·예산 등 요구사항을 파악해야 해" → "그 조건에 맞는 장소를 조사해야 해" → "가능한 장소들의 예약 가능 여부를 확인해야 해" ... 처럼 스스로 문제 공간을 탐색한 뒤 행동에 나섬

### 전망
- 미래의 가장 강력한 AI 시스템은 순수 생성형도, 순수 에이전틱도 아닌 **지능형 협업자(intelligent collaborator)**가 될 것
- 생성(탐색)과 에이전틱 행동(실행 커밋) 중 **언제 어느 쪽을 써야 하는지 아는 시스템**으로 발전할 전망

## 요약
- 핵심 구분: **생성형 AI = 반응형, 프롬프트 → 생성으로 종료** vs **에이전틱 AI = 능동형, 지각→결정→실행→학습의 루프로 목표를 추구**
- 둘 다 LLM(및 디퓨전 모델)을 공통 기반으로 하지만, 에이전틱 AI는 여기에 **Chain-of-Thought 추론 + 다단계 자율 실행**을 더한 것
