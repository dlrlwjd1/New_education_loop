# 06 Tools for Image Generation (이미지 생성 도구)

## 개요
- 이미지 생성형 AI 모델의 기본 역량과, 대표적인 이미지 생성 모델·도구의 핵심 기능을 다루는 영상

## 내용

### 이미지 생성·수정의 기본 역량
- 새로운 이미지 생성 + 실사/생성 이미지를 원하는 형태로 커스터마이즈(예: 아이가 책을 든 이미지를 만든 뒤 책 표지 색상만 변경)
- **FreePic** 같은 무료 AI 이미지 생성기 예시: 텍스트 프롬프트(예: "석양 아래 잔잔한 호수를 항해하는 배, 무성한 초록과 고요한 하늘")를 입력 → 스타일 선택 → 여러 이미지 생성 → 선택/다운로드 또는 프롬프트 수정으로 재생성
- 프롬프트에 담는 단어와 묘사의 구체성이 생성 이미지의 **정확도와 품질**을 좌우함

### 이미지 생성 모델의 4가지 응용 방식
- **이미지-투-이미지 변환(Image-to-image translation)**: 원본 내용·스타일을 유지하며 한 도메인에서 다른 도메인으로 변환 — 예: 스케치→사실적 이미지, 위성 사진→지도, 보안 카메라 화질 개선, 의료 영상 디테일 강화
- **스타일 전이·융합(Style transfer and fusion)**: 한 이미지의 스타일을 추출해 다른 이미지에 적용 → 하이브리드/퓨전 이미지 생성 (예: 그림→사진 변환)
- **인페인팅(Inpainting)**: 이미지의 손상되거나 없는 부분을 복원 — 미술품 복원, 포렌식(forensics), 원치 않는 객체 제거, AR에서 가상 객체를 실제 장면에 자연스럽게 합성
- **아웃페인팅(Outpainting)**: 원본 이미지를 자연스러운 확장으로 넓힘 — 더 큰 이미지 생성, 해상도 향상, 파노라마 뷰 제작

### 대표 이미지 생성 모델
- **DALL-E**(OpenAI) — GPT 기반, 이미지·텍스트 설명 대규모 데이터로 훈련되어 사실적 이미지·회화 등 다양한 스타일의 고해상도 이미지 생성. 최신 버전은 여러 변형 이미지 생성 + 인페인팅/아웃페인팅 지원
- **Stable Diffusion** — 오픈소스 텍스트-투-이미지 디퓨전 모델(diffusion model). 주로 텍스트 프롬프트 기반 이미지 생성에 쓰이지만 이미지-투-이미지, 인페인팅, 아웃페인팅도 가능
- **StyleGAN**(NVIDIA) — 이미지의 **내용(content)과 스타일(style)을 분리**해 모델링 → 포즈·표정 같은 특정 특징을 정밀하게 제어 가능. 이후 버전에서 더 고해상도·사실적인 디테일로 발전

### 대표 이미지 생성 도구·플랫폼
- **Crayon, FreePic, Pixar(원문 표기)** — 무료 텍스트-투-이미지 생성 도구, 다양한 사전 훈련 스타일 제공 또는 커스텀 스타일 제작 지원
- **Midjourney** — 아티스트·디자이너가 AI로 이미지를 만들고 서로의 창작물을 탐색할 수 있는 커뮤니티형 플랫폼
- 많은 이미지 생성기가 **API로 통합 가능** — 대표적으로 DALL-E, Midjourney, Crayon
- **Microsoft Bing Image Creator** — DALL-E 기반, bing.com/create 또는 Microsoft Edge에서 접근 가능. Edge는 **AI 이미지 생성기를 내장한 최초의 브라우저**
- **Adobe Firefly** — Adobe Creative Cloud(Photoshop, Illustrator 등)와 통합되는 생성형 AI 도구 모음. Adobe Stock의 공개 라이선스·퍼블릭 도메인 콘텐츠로 훈련. 100개 이상 언어의 텍스트 프롬프트를 받아 색상·톤·조명·구도·생성형 채우기(generative fill)·텍스트 효과·생성형 색상·3D→이미지·이미지 확장 등을 조작 가능

## 요약
- 이미지 생성형 AI는 **생성뿐 아니라 변환·스타일 전이·복원·확장**까지 폭넓게 지원 — 이미지-투-이미지 / 스타일 전이·융합 / 인페인팅 / 아웃페인팅의 4가지 응용 패턴이 핵심
