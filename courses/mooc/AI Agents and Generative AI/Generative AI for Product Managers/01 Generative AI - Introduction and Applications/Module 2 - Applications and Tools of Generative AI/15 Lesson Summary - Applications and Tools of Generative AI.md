# 15 Reading: Lesson Summary — Applications and Tools of Generative AI (레슨 요약)

## 개요
- Module 2 전체를 마무리하는 공식 요약 읽기 자료 (오디오 버전 포함)

## 내용
Module 2에서 배운 핵심 사항:
- 생성형 AI는 IT·DevOps, 엔터테인먼트, 금융, 의료, 인사(HR) 등 **수많은 분야**에 적용되고 있음
- 직장에서 생성형 AI의 적용은 일하는 방식 자체를 바꾸며, 더 효율적이고 성공적으로 일할 수 있게 함
- **텍스트 생성**: 다양한 형태의 텍스트 생성, 언어 번역, 질의응답 가능
  - **OpenAI ChatGPT**: 텍스트·이미지·음성을 아우르는 멀티모달 상호작용 지원. 자연스러운 대화 흐름 유지, 단계별 설명, 리서치·창작 작업에 강함
  - **Google Gemini**: 텍스트·이미지·음성 처리 가능. 매우 긴 문서 처리, 텍스트·이미지·비디오 등 다양한 창작 옵션 탐색, Google 앱과의 긴밀한 연동(작업·계획·리서치 지원)에 특히 강함
- **이미지 생성**: 텍스트/이미지 프롬프트로 새 이미지 생성. 이미지-투-이미지 변환, 스타일 전이, 인페인팅, 아웃페인팅 등으로 이미지 변형 가능
  - 대표 모델: **DALL-E, Stable Diffusion, StyleGAN**
  - 대표 제품: **Microsoft Bing Image Creator**, **Adobe Firefly**(Creative Cloud용 생성형 AI 도구 모음)
- **코드 생성**: 새 코드 생성, 기존 코드 최적화, 언어 간 코드 변환 가능
  - 대표 도구: **GPT, GitHub Copilot, PolyCoder, IBM Watson**
  - ChatGPT·Gemini는 기본적인 코드 생성에 유용하지만 훈련 데이터의 한계로 제약이 있음
- **생성형 AI vs 에이전틱 AI**: 생성형 AI는 **반응형(reactive)**으로 프롬프트에 응답하는 반면, AI 에이전트는 **능동형(proactive)**으로 최소한의 인간 개입만으로 일련의 행동을 통해 목표를 추구
- 에이전틱 AI는 LLM의 추론 능력을 활용해 복잡한 작업을 더 작고 논리적인 단계로 쪼개는데, 이 과정을 **"Chain of Thought reasoning"(사고의 연쇄 추론)**이라 부름
