# 12 Expert Viewpoints: Leveraging Generative AI Tools (전문가 관점 — 도구 활용)

## 개요
- AI 전문가가 텍스트·이미지·코드 생성 도구를 직접 써본 **개인적 경험**을 공유하는 영상
- 지금까지 배운 도구 목록([09](09%20Tools%20for%20Audio%20and%20Video%20Generation.md), [10](10%20Tools%20for%20Code%20Generation.md))을 실무자 관점에서 "무엇이 실제로 더 잘 되는지" 정리

## 내용

### 실무 경험상 가장 결과가 좋은 영역
- 텍스트 생성, 코드 생성 → 비디오·음악·3D 파일 등 **다른 영역보다 첫 시도에 원하는 결과를 얻기 가장 쉬움**
  - 이유: 모델이 더 많이 다듬어졌고, 프롬프트를 잘 짜는 노하우도 세상에 더 많이 축적되어 있음

### 하나의 LLM이 모든 것을 해결하지 않는다
- 모든 생성형 AI 유스케이스를 다 처리하는 단일 LLM은 없음 — 작업마다 오픈소스 커뮤니티나 각 기업이 훈련한 **여러 후보 모델** 중 선택
- **파인튜닝(fine-tuning)** 개념: 막대한 연산 자원이나 대량의 데이터 없이도, 기존 LLM을 자신의(또는 고객의) 데이터셋에 맞게 미세조정할 수 있음

### 영역별 대표 도구 정리 (전문가가 실무에서 실제로 쓰는 것들)
- **텍스트 생성**: ChatGPT(GPT-3 기반), Google Gemini가 가장 대중적. 그 외 **Copy.ai, Jasper, Frase.io, MS Copilot**
- **코드 생성**: ChatGPT/Gemini도 가능하지만, **GitHub Copilot이 코드 생성에 있어 조금 더 낫다**는 것이 실무 체감. 그 외 **Microsoft Copilot, IBM Watson Code Assistant, Polycoder, OpenAI Codex**
- **이미지 생성**: **DALL-E**가 가장 대중적, **Stable Diffusion**도 많이 사용. 플랫폼 관점에서는 **Midjourney**가 인기
  - DALL-E는 ChatGPT와 함께 쓸 수 있음 — 최신 ChatGPT 버전은 DALL-E가 통합되어 나오는 경우가 많음

### 이점과 과제(도전 과제)
- **이점**: 콘텐츠 제작을 위한 좋은 **베이스라인(baseline)**을 빠르게 만들어줌
- **한계**: 생성된 콘텐츠에 전적으로 의존할 수는 없음 — 모든 생성 콘텐츠에는 한계가 있음
- 음악, 3D 파일/모델 같은 **더 니치(niche)한 영역**은 원하는 결과를 얻기가 상대적으로 어렵고, 생성 시간도 오래 걸리며, 더 많은 시행착오(trial and error)가 필요 — 현재 시점 기준
- 전망: 앞으로 더 쉬워지고, 좋아지고, 특히 **멀티모달(multimodal)**해질 것 — 하나의 인터페이스로 여러 유형의 생성을 매끄럽게 통합하는 방향으로 발전 예상
- 실무 조언: **관심이 없는 영역이라도 일단 다 써보라** — 지금은 안 쓸 것 같아도 나중에 유용해질 수 있음

## 요약
- 실무 체감상 **텍스트·코드 생성이 가장 성숙**하고, 음악·3D 등은 아직 상대적으로 어려움
- 모든 유스케이스를 커버하는 만능 LLM은 없다 — 작업별로 적합한 모델을 고르거나 **파인튜닝**하는 것이 현실적 전략
- 앞으로의 방향: **멀티모달 통합 인터페이스** — 지금 배우는 개별 도구들(ChatGPT, DALL-E, Copilot 등)이 점차 하나의 매끄러운 경험으로 수렴할 것으로 전망
