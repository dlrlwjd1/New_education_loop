# 09 Tools for Audio and Video Generation (오디오·비디오 생성 도구)

## 개요
- 생성형 AI 오디오·비디오 도구가 어떻게 임팩트 있는 미디어 콘텐츠를 만드는지, 대표 도구와 핵심 역량, 그리고 가상 세계 재구성 역량까지 다루는 영상
- 시장 규모: 생성형 AI 음악 시장은 2022년 2억 2,900만 달러 → 2032년 26억 6,000만 달러로 **연평균 28.6% 성장(CAGR)** 전망 (Market.us)

## 내용

### 오디오 생성 도구 — 3가지 범주
1. **음성 생성(Speech generation)** — 주로 TTS(Text-to-Speech) 도구
   - 딥러닝 알고리즘이 방대한 인간 음성 데이터셋으로 반복 훈련되어, 발음·속도·감정·억양(intonation) 등 음성 특성을 정교하게 복제
   - 시각장애, 언어 장벽, 읽기 장애가 있는 사람들에게 특히 유용
   - 대표 도구: **LOVO, Synthesia, Murf.ai, Listenr** — 다양한 AI 음성·언어·감정 라이브러리 제공, 목소리 복제(clone) 및 편집(발음/톤/속도) 가능
2. **음악 창작(Music creation)**
   - **Meta AudioCraft** — Meta 소유·라이선스 음악 2만 시간으로 사전훈련된 생성형 AI 도구
   - **Shutterstock Amper Music, AIVA, Soundful, Google Magenta, GPT-4 기반 WavTool**
   - 텍스트 프롬프트만 입력하면 짧은 멜로디·리프 작곡, 악기 제안·추가, 신곡 작곡, 유튜브/인스타그램용 사운드트랙 제작까지 가능. 믹싱·마스터링·스트리밍 플랫폼 발행까지 지원
3. **오디오 품질 향상(Audio enhancement)**
   - 특정 소리를 식별하도록 사전훈련되어 원치 않는 소리 제거 또는 원하는 효과음 추가
   - **Descript** — 배경 소음 제거, 저품질 녹음 개선, 원하는 효과음 추가
   - **Audo AI** — 파일의 원치 않는 노이즈 정리

### 비디오 생성 도구
- **2022년 Runway AI**의 생성형 AI 기술로 제작된 영화 **《Everything Everywhere All at Once》**가 오스카를 수상 — 생성형 AI가 실제 상업 영화 제작에도 쓰인 사례
- **Runway Gen-1** — 기존 영상 클립을 다른 스타일로 변환
- **Runway Gen-2** — 텍스트·이미지·비디오 입력으로 새 영상 생성
- **EaseUS Video Toolkit, Synthesia** — 사진 업로드(또는 텍스트 프롬프트로 이미지 생성) → 내레이션 녹음 → 오디오 향상 → 파일 형식 변환 → 발행까지 지원
- **Synthesia**는 브랜드 회상(brand recall)을 높이는 **커스텀 아바타** 제작도 가능

### 가상 세계(Virtual World) 역량
- 하이브리드 특성과 이색적인 풍경을 가진 상상 속 가상 세계를 만들 수 있음
- 생성형 모델은 **실시간으로 반응**할 수 있어 시뮬레이션의 정확도를 높임
- **메타버스 플랫폼**은 생성형 AI로 더 개인화되고 몰입감 있는 사용자 경험 제공
- 게이밍 메타버스에서는 3D 객체를 빠르게 생성하고, 특정 성격 특성을 가진 아바타(표정·행동·대화·의사결정에 반영)까지 제작 가능
- **The Sandbox** — 사용자가 직접 게임을 만들고 소유하고 전 세계에 마케팅할 수 있는 메타버스
- **Scenario AI** — 맞춤형 모바일 게임 에셋을 생성·연결하는 데 도움

## 요약
- 오디오 도구는 **음성 생성(TTS) · 음악 창작 · 오디오 향상**의 3범주, 비디오 도구는 **스타일 변환·텍스트/이미지 기반 생성**이 핵심
- 대표 오디오 도구: **LOVO·Synthesia·Murf.ai** (음성), **AudioCraft·AIVA·WavTool** (음악), **Descript·Audo AI** (향상)
- 대표 비디오 도구: **Runway Gen-1/Gen-2, EaseUS, Synthesia**
- [10 Capabilities of Generative AI](../Module%201%20-%20Introduction%20and%20Capabilities%20of%20Generative%20AI/10%20Capabilities%20of%20Generative%20AI.md)에서 다룬 오디오·비디오·가상세계 생성 역량이 실제 상용 도구로 어떻게 구현되는지 보여주는 영상 — 오스카 수상작 제작 사례가 생성형 AI의 실무 파급력을 상징적으로 보여줌
