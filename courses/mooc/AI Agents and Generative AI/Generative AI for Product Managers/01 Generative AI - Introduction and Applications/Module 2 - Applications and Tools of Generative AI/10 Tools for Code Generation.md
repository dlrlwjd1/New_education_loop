# 10 Tools for Code Generation (코드 생성 도구)

## 개요
- 코드 생성형 AI의 기본 역량, 텍스트 생성 도구를 코드 생성에 쓸 때의 강점·한계, 그리고 코드 전용 도구들의 핵심 기능을 다루는 영상

## 내용

### 코드 생성의 기본 역량
- 딥러닝과 **NLP(자연어 처리)** 기반으로 맥락을 이해해 적절한 코드를 생성
- 텍스트 프롬프트로 새 코드 스니펫/프로그램 생성, 부분 코드 완성(자동완성), 기존 코드 최적화, **언어 간 코드 변환(translation)**, 코드 요약·주석 생성(문서화), 문제 설명만으로 알고리즘·자료구조·접근법 추천

### 범용 텍스트 생성 도구(GPT 계열)의 코드 생성
- **ChatGPT(GPT 기반)**: 프롬프트로 파이썬 코드 생성 + 실행 방법 안내까지 제공. 좋은 결과를 위해 **명확한 프롬프트 + 프로그래밍 언어 명시 + 제약조건 명시**가 중요
- **디버깅**: 잘못된 코드를 프롬프트로 주면 올바른 코드와 수정 설명을 제공
- 언어 간 코드 번역, 문서화/주석 생성도 가능. 최신 GPT는 **이미지에서 코드 생성**도 가능(예: 강좌 개요 이미지 → 앱 코드)
- **Google Gemini**: 20개 이상 프로그래밍 언어의 코드 생성·디버깅 지원
- **한계**: ChatGPT/Gemini는 기본 로직·개념 수준 코드에 강하지만, 크고 복잡한 코드를 처음부터 만드는 데는 약함. 문법(syntax)은 이해해도 **의미(semantics)를 완전히 이해하지 못해** 기술적으로는 맞아도 의도대로 동작하지 않을 수 있음. 또한 **훈련 데이터 시점 이후의 최신 프레임워크/라이브러리는 모름**(예: GPT-3.5는 2021년 9월까지의 지식으로 한정)

### 코드 생성 전용 도구
- **GitHub Copilot** — OpenAI **Codex**(생성형 사전훈련 언어 모델) 기반. GitHub 등 공개 저장소의 자연어·소스코드로 훈련. VS Code 등 코드 에디터에 확장 프로그램으로 통합, 베스트 프랙티스에 맞는 코드 스니펫 생성
- **Polycoder** — GPT-2 기반 **오픈소스** 코드 생성기. 12개 언어의 GitHub 저장소로 훈련, 특히 **C 코드**에 강함. 사전 정의된 템플릿 라이브러리로 요구사항에 맞춘 코드 생성·검토·정제
- **IBM Watson Code Assistant** — IBM watsonx.ai 파운데이션 모델 기반, 모든 숙련도의 개발자 대상. 코드 에디터 통합, 실시간 추천·자동완성·코드 재구조화(restructuring) 지원. 코드/프로젝트 파일을 분석해 패턴 식별·개선 제안·코드 스니펫/템플릿 생성
- **기타 도구**: **Amazon CodeWhisperer**(실시간 코드 추천), **Tabnine**(정확한 코드 완성), **Repl.it**(코딩·학습·협업을 위한 인터랙티브 플랫폼)

### 코드 생성 도구의 가치와 위험
- 생산성·코드 품질 향상, 빠른 프로토타이핑(rapid prototyping) 지원
- 다국어 코드 번역으로 **크로스플랫폼 호환성·마이그레이션** 지원
- 일관된 코딩 표준과 리팩터링 패턴 제안
- **주의사항**: AI 생성 코드가 **윤리적 문제**(보안 취약점, 악성 데이터 생성, 훈련 데이터에 내재된 편향)로 이어지지 않도록 신중히 사용해야 함

## 요약
- 범용 도구(**ChatGPT, Gemini**)는 간단한 코드 생성·디버깅·학습에 유용하지만, 복잡한 코드나 최신 프레임워크에는 한계
- 전용 도구(**GitHub Copilot, Polycoder, IBM Watson Code Assistant**)는 실시간 추천·코드 재구조화·솔루션 템플릿 등 더 정교한 기능 제공
- [10 Capabilities of Generative AI](../Module%201%20-%20Introduction%20and%20Capabilities%20of%20Generative%20AI/10%20Capabilities%20of%20Generative%20AI.md)의 "코드 생성" 역량이 실제 도구 생태계에서 어떻게 구현·활용되는지 구체화 — 다만 **의미(semantics) 이해의 한계**와 **보안/윤리적 위험**은 실무 적용 시 반드시 고려해야 할 요소
