# 16 Podcast: Recap: Applications and Tools for Generative AI (Module 2 팟캐스트 마무리)

## 개요
- Jeff와 Cathy가 Module 2 전체를 대화 형식으로 마무리하는 팟캐스트 — [15 Lesson Summary](15%20Lesson%20Summary%20-%20Applications%20and%20Tools%20of%20Generative%20AI.md)와 동일한 내용을 구어체로 복습

## 내용
- 생성형 AI는 IT, 금융, 엔터테인먼트, 의료, HR 등 거의 모든 곳에 등장하며 업무 방식을 바꾸고 효율성을 높이고 있음
- **텍스트 생성**: ChatGPT(자연스러운 대화, 단계별 설명, 리서치·창작에 강함, 텍스트·이미지·음성 처리) vs Gemini(긴 문서 처리, 텍스트·이미지·비디오 창작, Google 앱 연동)
- **이미지 생성**: DALL-E, Stable Diffusion, StyleGAN — 프롬프트로 새 이미지 생성 또는 스타일 전이·인페인팅 등으로 변형. Microsoft Bing Image Creator, Adobe Firefly도 언급
- **코드 생성**: GPT, GitHub Copilot, PolyCoder, IBM Watson — 새 코드 작성·기존 코드 최적화·언어 간 변환. ChatGPT/Gemini는 기본 코드에 유용하지만 훈련 데이터 수준의 한계 있음
- **생성형 vs 에이전틱 AI**: 생성형 AI는 프롬프트에 반응하는 **반응형**, 에이전틱 AI는 거의 독립적으로 목표를 추구하는 **능동형**. 에이전틱 AI는 LLM으로 복잡한 작업을 작은 논리적 단계로 쪼개는 **"Chain of Thought reasoning"**을 사용
- 마무리 메시지: "이 도구들을 아직 안 쓰고 있다면, 확실히 뒤처지고 있는 것" — 계속 새로운 발전이 나오고 있으니 계속 탐구할 것을 권장
