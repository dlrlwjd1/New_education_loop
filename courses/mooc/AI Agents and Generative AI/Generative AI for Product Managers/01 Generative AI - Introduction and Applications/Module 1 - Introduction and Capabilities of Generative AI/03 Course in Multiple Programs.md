# 03 Course in Multiple Programs (여러 프로그램에 포함된 이 코스)

## 개요
- 이 코스(*Generative AI: Introduction and Applications*)는 IBM의 여러 프로그램에 **공통 입문 코스**로 들어감
- 즉, 이 코스를 들으면 여러 특화 과정(Specialization)·전문 자격증(Professional Certificate)의 첫걸음을 함께 밟는 셈
- (읽기 자료 / supporting reading)

### 주요 프로그램 요약

**1. Generative AI Fundamentals Specialization**
생성형 AI의 기본 개념·모델·도구·응용을 종합적으로 다룸. 빌딩 블록과 파운데이션 모델(foundation models), 프롬프트 엔지니어링(prompt engineering), 그리고 데이터 프라이버시·보안·노동·환경 관련 **윤리적 함의(ethical implications)**까지 학습. 전문가·기술 애호가·관리자·학생 대상.
- 구성(5개 코스): Introduction and Applications / Prompt Engineering Basics / Foundation Models and Platforms / Impact, Considerations, and Ethical Issues / Business Transformation and Career Growth

**2. IBM Applied AI Professional Certificate**
AI 기술·응용·활용 사례에 대한 탄탄한 이해 제공. 머신러닝, 데이터 사이언스, 자연어 처리(NLP), 이미지 분류·처리, IBM Watson AI, OpenCV, API 등을 다루며, **프로그래밍 배경이 없어도** 파이썬으로 웹 AI 앱을 설계·구축·배포하는 실무 역량을 익힘.
- 구성: Introduction to AI / Introduction and Applications / Prompt Engineering Basics / Building AI Powered Chatbots Without Programming / Python for Data Science, AI & Development / Developing AI Applications with Python and Flask / Building AI Applications with Watson APIs

**3. Generative AI for Data Scientists Specialization**
데이터 사이언스에 생성형 AI를 적용하는 여정. 프롬프트 엔지니어링 개념과 도구(IBM Watsonx, Prompt Lab, Spellbook, Dust)를 익히고, 데이터 증강(data augmentation)·데이터 생성·피처 엔지니어링·모델 개발/정제·시각화·인사이트 등 데이터 사이언스 방법론 전반에 적용.
- 구성: Introduction and Applications / Prompt Engineering Basics / Elevate your Data Science Career

**4. Generative AI for Software Developers Specialization**
소프트웨어 개발에 생성형 AI 활용. 텍스트·코드·이미지·오디오·비디오 생성 모델과 프롬프트 엔지니어링 도구를 익히고, GitHub Copilot·OpenAI ChatGPT·Google Gemini 등으로 코드 설계·개발·번역·테스트·문서화·배포를 실습.
- 구성: Introduction and Applications / Prompt Engineering Basics / Elevate your Software Development Career

## 요약
- *Generative AI: Introduction and Applications*는 **IBM의 다수 프로그램 공통 입문 코스**
- 거의 모든 트랙이 `Introduction and Applications` → `Prompt Engineering Basics`로 시작하고, 마지막에 직군별 심화 코스가 붙는 구조
- 내가 듣는 트랙: **Generative AI for Product Managers Specialization**
