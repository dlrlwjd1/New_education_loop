# 05 Course Overview (코스 개요)

## 개요
- 생성형 AI(Generative AI)는 우리의 일과 일상 전반을 바꿀 기술
- 이 코스는 LLM(large language models) 등 다양한 모델이 구동하는 생성형 AI의 **역량을 이해하는 첫걸음**
- 애호가·학생·전문가 누구나, **사전 지식 없이** 시작 가능 (읽기 자료 / reading)

## 내용

### 학습 목표 (수료 후 할 수 있는 것)
- 생성형 AI를 설명하고 **판별형 AI(discriminative AI)와 구분**
- 생성형 AI의 역량과 실제 세계 활용 사례(use cases) 설명
- 다양한 부문·산업에서의 응용 식별
- 텍스트·코드·이미지·오디오·비디오 생성을 위한 공통 모델·도구 탐색

### 코스 구성 (3개 모듈, 주 1모듈 권장)

- **Week 1 / Module 1 — Introduction and Capabilities**
  생성형 AI의 기초와 판별형 AI와의 차이. 텍스트·이미지·코드·음성·비디오 생성 역량 탐색. (인터랙티브 체크포인트·요약 자료 포함)

- **Week 2 / Module 2 — Applications and Tools**
  IT·DevOps·엔터테인먼트·교육·금융·헬스케어·인사(HR) 등 산업별 응용과 영향. 텍스트·이미지·코드·오디오·비디오·가상세계 생성 도구의 핵심 역량·활용 사례

- **Week 3 / Module 3 — Quiz, Project, and Wrap-Up**
  채점 퀴즈(graded quiz), 용어집(glossary), 선택 프로젝트(텍스트·이미지·코드 생성 실습), 다음 학습 단계 안내, 최종 실습 활동

### 학습 자원
- 영상, 읽기 자료, 실습 랩(hands-on labs), 전문가 관점(Expert Viewpoints), 토론, 퀴즈
- 생성형 AI로 제작된 콘텐츠(인터랙티브 오디오 팟캐스트, 역할극, 대화)도 포함
- 실습 랩은 프로그래밍 경험이 필요 없는 도구(IBM Generative AI Classroom, ChatGPT 등) 기반

### 수강 대상 / 권장 배경
- 생성형 AI 입문자, 업무 개선을 원하는 전문가, 조직 도입을 검토하는 관리자·임원, 실무 역량을 원하는 학생
- **특별한 선수 지식·학위 불필요** — 기술 전문 용어 없이 쉬운 언어로 설명

## 요약
- 이 코스의 핵심 구분: **생성형 AI(Generative) vs 판별형 AI(Discriminative)**
- 3개 모듈 흐름: **역량 → 응용/도구 → 퀴즈·프로젝트·마무리**
- 선수 지식 불필요, 프로그래밍 없이 실습 가능 → 진입 장벽이 낮음
