# 10 Capabilities of Generative AI (생성형 AI의 역량)

## 개요
- 생성형 AI의 7가지 핵심 역량(capability)을 개괄하고, 각 역량의 대표 모델·실제 활용 사례를 살펴보는 영상
- 핵심 메시지: **인간이 상상할 수 있는 것이라면 무엇이든 생성형 AI의 잠재적 활용 사례가 될 수 있다**

## 내용

### 7가지 역량 개괄
1. **텍스트 생성(Text Generation)** — 명확하고 문맥에 맞는(contextually relevant) 텍스트 응답 생성
2. **이미지 생성(Image Generation)** — 실제와 유사한 예술적·사실적 이미지 합성
3. **오디오 생성(Audio Generation)** — 음악 작곡, 합성 오디오 생성
4. **비디오 생성(Video Generation)** — 텍스트 설명·이미지를 바탕으로 동적인 영상 생성
5. **코드 생성(Code Generation)** — 코드 함수·프로그램 생성
6. **데이터 생성·증강(Data Generation and Augmentation)** — 합성 데이터로 데이터셋 보강
7. **가상 세계 생성(Virtual World Generation)** — 사실적이고 몰입감 있는 가상 세계 창조

### 1. 텍스트 생성
- 핵심 기술: **LLM(Large Language Model)** — 대규모 데이터셋으로 훈련되어 다양한 맥락에서 인간 같은 텍스트 생성
- 데이터 내 패턴·구조를 학습해 일관되고 맥락에 맞는 응답을 만듦
- 대표 모델: OpenAI **GPT**, Google **PaLM**
- 활용: 텍스트 완성(text completion), 요약(summarization), 질의응답, 번역, 코드 생성, 이미지·텍스트 페어링, 챗봇·가상 비서의 대화형 상호작용

### 2. 이미지 생성
- 핵심 기술: **GAN**, **VAE** 등 딥러닝 기법 기반
- 생성된 이미지는 사실적인 질감·자연스러운 색상·정교한 디테일을 가져 실제 카메라로 찍은 듯한 인상을 줌
- 대표 모델: **StyleGAN**(고해상도 가상 얼굴/동물/자연 이미지), **DeepArt**(간단한 스케치→작품), **DALL-E**(사용자가 설명한 새로운 이미지 생성)
- 활용: 예술·디자인·엔터테인먼트·게임·연구, 훈련 데이터 증강, 의료 영상(medical imaging), 과학적 시각화

### 3. 오디오 생성
- 새로운 음악 작곡, **TTS(Text-to-Speech)**로 텍스트→오디오 변환, 합성 음성·자연스러운 발화 생성
- 목소리 변환·수정·노이즈 감소·오디오 품질 향상, 인간 목소리를 상당히 유사하게 모방 가능
- 대표 모델: **WaveGAN**(사실적인 원시 오디오 파형 — 음성·음악·자연음), **MuseNet**(OpenAI, 여러 악기·스타일·장르를 조합한 새 작곡), Google **Tacotron 2**, **Mozilla TTS**(어조·피치·리듬 등을 반영한 합성 음성)
- 활용: 미디어, 창작, 엔터테인먼트, 교육·훈련, 게임, VR

### 4. 비디오 생성
- 기본 애니메이션부터 복잡한 장면까지 동적인 영상 생성
- 핵심 개념: **시간적 일관성(temporal coherence)** — 시간에 따른 의미·맥락의 일관성과 연속성 → 부드러운 움직임과 자연스러운 전환을 가능하게 함
- 대표 모델: **VideoGPT** — 텍스트 프롬프트를 따라 영상 생성(완성·편집·합성·예측·스타일 전이 등 지정 가능)
- 활용: 예술, 엔터테인먼트, 교육, 게임, 의학, 연구

### 5. 코드 생성
- 원하는 기능(functionality)에 따라 새로운 코드 스니펫·함수·전체 프로그램 생성
- 기존 코드 저장소로 훈련되어 코드 완성/생성, 리팩터링, 버그 식별·수정, 테스트, 문서화(주석·함수 설명·사용 예시)까지 수행
- 대표 모델: **GitHub Copilot**, **IBM Watson Code Assistant** — 자동완성, 어려운 작업 가속화
- 활용: 소프트웨어/웹 개발, ML·NLP, 데이터 사이언스·분석, 로보틱스·자동화, 가상 게임·AR/VR 개발, 오디오/비디오/음성 처리

### 6. 데이터 생성·증강
- 새로운 데이터를 생성하거나 기존 데이터셋을 증강 → 데이터의 다양성·변동성 확대 → 더 견고하고 효과적인 모델 성능
- 이미지·텍스트·음성·표 형태 데이터·통계 분포·시계열·금융 데이터 등에 적용
- 활용: 의학·헬스케어, 게임, 교육·훈련, 예술·창작, 자율주행차 등

### 7. 가상 세계 생성
- 사실적이고 복잡한 가상 세계 창조 — 사실적 행동·표정·대화·의사결정을 시뮬레이션하는 아바타 생성 가능
- 물리 법칙을 따르는 사실적 텍스처·소리·객체를 가진 복잡한 가상 환경 구현
- **메타버스(Metaverse) 플랫폼**은 생성형 모델로 사용자별 맞춤 경험을 제공
- 고유한 성격을 가진 **가상 정체성(virtual identity)**·아바타 생성 가능 (행동·대화에 반영)
- 활용: 게임, 엔터테인먼트, 교육, AR/VR, 메타버스 플랫폼, 가상 인플루언서(virtual influencer)·디지털 퍼스낼리티

## 요약
- 생성형 AI의 7대 역량: **텍스트 · 이미지 · 오디오 · 비디오 · 코드 · 데이터 · 가상 세계** 생성
- 각 역량은 GAN/VAE/트랜스포머 등 공통 딥러닝 기반 위에 서 있으며, 대표 모델(GPT, DALL-E, WaveGAN, VideoGPT, Copilot 등)이 실제 산업 전반(의료·게임·교육·엔터테인먼트·소프트웨어 개발 등)에 적용되고 있음
- [08 Introduction to Generative AI](08%20Introduction%20to%20Generative%20AI.md)에서 배운 판별형 vs 생성형 AI 구분, 빌딩 블록(GAN/VAE/트랜스포머/디퓨전)이 이 7가지 역량의 기술적 토대가 됨
