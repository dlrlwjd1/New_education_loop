# 16 Role Play: Prompt Engineering in Action (역할극 실습)

## 개요
- Module 2에서 배운 프롬프트 엔지니어링 기법을 실무 상황에 적용해보는 음성 대화 기반 역할극 (15분, 음성 채팅 필수)

## 내용
- 이 항목은 **실시간 음성 AI 역할극**(고정된 스크립트 없음)이라, 실제 대화 내용 대신 랜딩 페이지에 제시된 시나리오와 목표를 정리함

### 시나리오
- 중견 기술 솔루션 회사의 **프롬프트 엔지니어** 역할을 맡음
- 제품 관리자 Joseph Clark가 생성형 AI로 팀의 효율을 높이고 싶어 하며, 다양한 비즈니스 콘텐츠 제작에 AI 활용을 원함
- Joseph가 제시하는 3가지 콘텐츠 유형 중 하나를 선택해 집중 작업: **회사 웹사이트용 고객 FAQ / 신제품 출시 마케팅 카피 / 신입사원 온보딩 교육 자료**
- 목표: Joseph의 비전을 이해하고, 정밀한 프롬프트를 설계하며, 출력이 완벽해질 때까지 반복 정제하는 것

### 목표(Your Goal)
1. AI 생성 콘텐츠에 대한 **비즈니스 요구사항과 타깃 독자**에 관해 제품 관리자에게 명확화 질문(clarifying questions) 던지기
2. 제품 관리자의 요청을 바탕으로 **초기 프롬프트를 작성**하고 AI 도구로 테스트
3. AI의 출력이 **정확하고 전문적이며 비즈니스 맥락에 맞도록** 프롬프트를 정제

## 요약
- [02 Interview Pattern Approach](02%20Interview%20Pattern%20Approach.md)에서 배운 **명확화 질문을 통한 정보 수집**과, Module 2 전반에서 다룬 **프롬프트 초안 작성 → 테스트 → 반복 정제**의 워크플로를 실제 비즈니스 시나리오(고객 FAQ/마케팅 카피/온보딩 자료)에 적용해보는 종합 실습
- Module 2를 마무리하는 활동으로, 그동안 배운 기법(인터뷰 패턴, Chain-of-Thought, Tree-of-Thought, 멀티모달, Playoff Method)을 실무 맥락에서 종합적으로 활용하는 감각을 기르는 데 목적이 있음
