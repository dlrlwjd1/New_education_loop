# 01 Text-to-Text Prompt Techniques (텍스트-투-텍스트 프롬프트 기법)

## 개요
- LLM의 신뢰성·품질을 높이는 텍스트 프롬프트 기법들과, 이를 효과적으로 쓸 때의 이점을 다루는 영상
- LLM이 커지고 복잡해질수록 신뢰성·보안·편향에 대한 우려가 커지는데, **효과적인 텍스트 프롬프트 사용이 유망한 해결책**

## 내용

### 신뢰성을 높이는 6가지 기법
1. **작업 명시(Task Specification)** — LLM에게 목표를 명시적으로 지정. 예: "이 영어 문장을 프랑스어로 번역해줘"
2. **맥락적 안내(Contextual Guidance)** — 구체적 지시로 관련성 있는 출력 유도. 예: "뉴욕에 대한 짧은 글을 써줘"(일반적) → "뉴욕의 상징적인 랜드마크를 강조하며 짧은 글을 써줘"(구체적)
3. **도메인 전문성(Domain Expertise)** — 의료·법률·공학처럼 정확성이 중요한 분야에서 **도메인 특화 용어**를 사용. 예: "갑상선 기능 저하증의 원인·증상·치료법을, 최신 연구와 의료 가이드라인을 포함해 설명해줘"
4. **편향 완화(Bias Mitigation)** — 중립적 응답을 명시적으로 요청. 예: "특정 성별에 치우치지 않고 리더십 특성에 대한 100단어 글을 써줘. 모든 성별의 특성 예시를 균등하게 제공해줘"
5. **프레이밍(Framing)** — 원하는 범위 내에서 응답이 나오도록 경계를 설정. 예: "기후 변화 기사의 핵심 발견과 권고사항에 초점을 맞춰 100단어로 요약해줘"
6. **사용자 피드백 루프(User Feedback Loop)** — 응답에 대해 반복적으로 피드백을 주며 프롬프트를 정제. 예: 시를 써달라고 요청 → "더 유머러스하게 해줘" → 모델이 조정 → 승인

### Zero-shot과 Few-shot (재확인 + 심화)
- **Zero-shot**: 사전 훈련 없이도 프롬프트만으로 의미 있는 응답 생성. 예: "이 문장에서 형용사를 골라줘: 'Anita bakes the best cakes in the neighborhood.'" → 답: "best"
- **Few-shot**: 프롬프트 안에 **시연(demonstration) 예시**를 제공해 인컨텍스트 학습(in-context learning)을 유도. 예: "여름 휴가지로 해변이 아름다운 곳을 추천해줘" + "가을 휴가지로 단풍이 아름다운 곳을 추천해줘" 같은 예시 2개를 준 뒤 → "도시 여행지를 추천해줘"라고 하면 모델이 같은 패턴으로 "파리" 등을 추천

### 텍스트 프롬프트를 효과적으로 쓸 때의 이점
- **설명가능성(Explainability) 향상** — 사용자·개발자·이해관계자가 모델의 의사결정 과정과 출력 이유를 이해하고, 다양한 응용에서 신뢰할 수 있는지 판단하는 데 도움. AI 관련 윤리적 우려 해소에 중요 — 도메인별 윤리 가이드라인·법적 요구사항과의 일치 여부를 평가하는 데 기여
- **사용자 신뢰 구축** — 사용자가 모델의 작동 방식과 자신의 지시가 미치는 영향을 이해할수록, **투명하고 의미 있는 상호작용**으로 이어짐

## 요약
- 신뢰성 향상 6대 기법: **작업 명시 · 맥락적 안내 · 도메인 전문성 · 편향 완화 · 프레이밍 · 사용자 피드백 루프**
- Zero-shot(예시 없음) vs Few-shot(예시로 인컨텍스트 학습) — [Module 1의 14 Expert Viewpoints](../Module%201%20-%20Prompt%20Engineering%20for%20Generative%20AI/14%20Expert%20Viewpoints%20-%20Exploring%20Prompt%20Engineering%20in%20Generative%20AI.md)에서 예고됐던 개념이 여기서 구체화됨
- 효과적인 텍스트 프롬프트는 **설명가능성과 사용자 신뢰**라는 실무적으로 중요한 두 가지 이점을 가져옴
