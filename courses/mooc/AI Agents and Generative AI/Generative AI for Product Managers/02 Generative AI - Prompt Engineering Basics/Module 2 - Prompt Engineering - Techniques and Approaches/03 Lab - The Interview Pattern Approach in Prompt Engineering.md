# 03 Lab: The Interview Pattern Approach in Prompt Engineering (실습)

## 개요
- 인터뷰 패턴을 페르소나 패턴과 결합해 더 정밀하고 개인화된 결과를 얻는 20분 실습 (GPT-5 Nano 사용)

### 학습 목표
- 다중 턴(multi-turn) 대화를 시뮬레이션하는 프롬프트를 설계해 더 깊이 있는 인사이트 얻기
- 페르소나 패턴 + 인터뷰 패턴을 결합해 더 상세하고 개인화된 결과 얻기

## 내용

### 예시 1 — 헬스 프로그램
- Prompt Instructions: `당신은 최신 연구에 정통한 피트니스 전문가 역할을 할 것이다. 내 질문에 아주 상세한 단계별 지침으로 답하되, 최선의 답을 주기 위해 필요한 모든 관련 질문으로 나를 인터뷰해라.`
- 질문: `체중 감량과 근력 강화를 위한 헬스장 운동 프로그램을 만들어줘.`
- → 모델이 나이·성별·키·체중·부상 이력·운동 가능 요일·장비·목표·수면·영양 등 **상세한 설문(interview questionnaire)**을 먼저 던짐 → 답변 후 맞춤형 4~12주 프로그램 제공

### 예시 2 — 블로그 포스트 작성 (나이브 vs 인터뷰 패턴)
- **나이브 접근**: `"Prompt Engineering for Everyone"라는 새 코스를 알리는 블로그 포스트를 써줘` → 무난하지만 매우 일반적인 글 (모델이 코스에 대해 아는 게 제목뿐이라서)
- **인터뷰 패턴 적용**: Prompt Instructions에 `당신은 SEO와 콘텐츠 마케팅 전문가 역할을 할 것이다. 최선의 답을 주기 위해 필요한 질문들을 한 번에 하나씩 나에게 인터뷰하듯 물어봐라` 추가 → 같은 요청에 모델이 먼저 되물음: "이 코스의 주 타겟 독자는 누구인가요? (스킬 수준, 업종, 목표 등)"
- 대안 지시문: `필요한 정보를 모으기 위해 한 번씩 질문을 이어서 해줘` — 정확한 문구를 외울 필요 없이 **"AI에게 인터뷰를 요청한다"는 개념**만 이해하면 됨
- 답변이 구체적일수록 결과 품질도 좋아짐 — 모델이 정보가 충분하다고 판단하면 답변을 생성하고, 아니면 추가 질문을 계속함

## 요약
- [02 Interview Pattern Approach](02%20Interview%20Pattern%20Approach.md)의 이론을 **피트니스 프로그램**과 **블로그 포스트 작성** 두 시나리오로 실습
- 핵심 교훈: 인터뷰 패턴은 **페르소나 패턴과 결합**했을 때 특히 강력함 — "역할 부여 + 질문을 통한 정보 수집"의 조합이 나이브 프롬프트보다 훨씬 개인화된 결과를 만듦
- 정확한 문구가 아니라 **"AI가 필요한 정보를 먼저 물어보게 만든다"는 개념**이 핵심
