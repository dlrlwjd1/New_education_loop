# 14 Reading: Lesson Summary: Key Techniques of Prompt Engineering (레슨 요약)

## 개요
- Module 2 "Prompt Engineering: Techniques and Approaches" 전체를 마무리하는 공식 요약 읽기 자료 (오디오 포함)

## 내용
- 효과적인 프롬프트를 능숙하게 작성하는 기법과, 생성형 AI 모델의 응답을 최적화하는 다양한 프롬프트 엔지니어링 접근법을 학습함
- **텍스트 프롬프트로 LLM의 신뢰성·품질을 높이는 6대 기법**: 작업 명시(Task Specification) · 맥락적 안내(Contextual Guidance) · 도메인 전문성(Domain Expertise) · 편향 완화(Bias Mitigation) · 프레이밍(Framing) · 사용자 피드백 루프(User Feedback Loop)
- **Zero-shot prompting**: 사전 훈련 없이도 프롬프트만으로 LLM이 의미 있는 응답을 생성하는 능력
- **Few-shot prompting**: 인컨텍스트 학습(in-context learning)에 의존 — 프롬프트 안에 시연(demonstration)을 제공해 모델을 더 나은 성능으로 유도
- 텍스트 프롬프트를 효과적으로 쓰면 **설명가능성(explainability) 향상, 윤리적 고려사항 해결, 사용자 신뢰 구축**의 이점이 있음
- **인터뷰 패턴(Interview Pattern)**은 기존 프롬프팅 접근법보다 우수함 — 생성형 AI 모델과 상호작용할 때 더 동적이고 반복적인 대화를 가능케 함
- **Chain-of-Thought**는 생성형 AI 모델의 인지 능력을 강화하고 단계별 사고 과정을 이끌어냄
- **Tree-of-Thought**는 Chain-of-Thought를 기반으로 한 혁신적인 기법으로, 프롬프트를 나무처럼 계층적으로 구조화해 모델의 추론과 출력 생성을 안내함

## 요약
