# 11 Lab: Multimodal Prompts (실습)

## 개요
- ChatGPT·Gemini 같은 실제 GenAI 도구로 텍스트+이미지를 결합한 멀티모달 프롬프트를 직접 실습하는 30분 실습

### 학습 목표
- PDF 문서의 멀티모달 콘텐츠를 생성형 AI로 요약
- 멀티모달 프롬프트 기법으로 이미지에서 핵심 데이터 포인트 추출·분석
- 시각 이미지에서 영감을 받은 창의적 서사/설명 생성

## 내용

### Task 1 — PDF 문서의 멀티모달 콘텐츠 분석
- 시나리오: "일상 업무에서의 GenAI 도입" 설문 보고서(텍스트+표+차트 혼합 PDF)를 분석하는 리서치 팀의 일원
- 예시 프롬프트:
  1. "이 PDF 설문의 핵심 발견을 텍스트와 차트·표 같은 시각 데이터를 모두 포함해 간략히 요약해줘"
  2. "이 문서 내용을 바탕으로, 사용자들이 GenAI를 채택했다고 보고한 가장 흔한 일상 업무는 무엇인가?"
  3. "이 PDF의 설문 결과를 바탕으로, 일상 워크플로에서 GenAI 도입을 개선하기 위한 추천 사항은?"

### Task 2 — 이미지 분석 (개인 지출 추적)
- 시나리오: 식료품 체인의 소비자 분석팀 일원으로, 고객의 영수증 이미지에서 재고 계획·가격 비교·세금 계산·트렌드 분석에 필요한 인사이트 추출
- 예시 프롬프트:
  1. "구매한 모든 품목 목록을, 수량·단가·총액을 포함해 추출해줘" (데이터 추출)
  2. "품목 카테고리별(농산물·유제품·육류·식료품) 평균 가격을 계산해줘" (수학적 추론)
  3. "이 쇼핑객의 예산이 $80로 엄격히 제한되어 있었다고 가정할 때, 구매한 품목 중 어떤 것을 생략하거나 더 저렴한 대안으로 바꿔 예산 내에서 다양한 식료품을 확보할 수 있었을지 근거와 함께 제안해줘" (의사결정·최적화)

### Task 3 — 창의적 콘텐츠 생성
- 시나리오: 사용자가 업로드한 사진(석양 속 고요한 알프스 풍경, 작은 오두막, 타오르는 모닥불, 그 주위에 모인 4명)에서 영감을 받은 몰입형 서사 콘텐츠 앱의 콘텐츠 디자이너
- 예시 프롬프트:
  1. "이 이미지에서 영감을 받은 짧은 이야기를 써줘. 모닥불 주위의 사람들과 그들이 이 외딴 장소에 석양 무렵 오게 된 이유에 초점을 맞춰줘" (단편 소설)
  2. "이 황혼의 풍경이 지닌 분위기와 아름다움을 담아내는 시나 서정적인 글을 자연·연결·평온이라는 주제를 반영해 써줘" (시적 응답)

## 요약
- [10 Reading - Multimodal Prompts](10%20Reading%20-%20Multimodal%20Prompts.md)의 개념(문서 요약·창의적 콘텐츠·캡션/태깅)을 3가지 실전 과제로 직접 실습: **PDF 분석(요약→통계 추출→추천), 이미지 분석(데이터 추출→계산→최적화 의사결정), 창의적 생성(단편 소설→시)**
- 공통 패턴: 모든 과제가 **단순 추출 → 분석/계산 → 창의적 결론이나 의사결정 제안**으로 단계가 심화되는 구조 — 멀티모달 프롬프트가 텍스트만으로는 불가능한 시각 정보 기반 추론을 가능케 함을 확인
- ChatGPT·Gemini 모두 사용 가능하며 과제별로 자유롭게 선택 가능
