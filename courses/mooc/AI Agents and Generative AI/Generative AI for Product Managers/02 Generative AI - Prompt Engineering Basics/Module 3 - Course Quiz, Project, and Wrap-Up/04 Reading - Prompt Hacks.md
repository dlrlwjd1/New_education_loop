# 04 Reading: Prompt Hacks

## 개요
- 프롬프트 해킹(Prompt Hacks)의 개념과, 이를 텍스트·이미지 생성 모델에 적용해 더 효과적인 출력을 얻는 방법, 그리고 프롬프트 엔지니어링과의 차이를 다루는 6분 읽기 자료

## 내용

### 프롬프트 해킹이란
- LLM이나 이미지 생성 모델에 제공하는 **프롬프트(입력)를 조작/변형**해, 원하는 특정 출력을 만들어내는 기법이나 전략
- 프롬프트 해킹이 LLM 성능을 개선하는 방식:
  1. **출력의 품질·정확도 향상** — 프롬프트를 세심히 설계해 모델을 원하는 출력으로 유도하고 오류 가능성을 줄임
  2. **새롭고 혁신적인 작업 수행 가능** — 프롬프트를 이미지·코드 같은 다른 입력과 결합해, 원래는 불가능했던 작업을 수행하게 함
  3. **LLM을 더 접근하기 쉽고 사용하기 편하게 만듦**

### 텍스트 생성에서의 프롬프트 해킹
- **특수 수정자(Special Modifiers) 사용** — 생성 출력의 스타일·톤 등을 제어. 예: "write in a humorous style"
- **맥락과 예시 제공** — 더 많은 맥락과 예시를 줄수록 LLM이 원하는 바를 더 잘 이해함
- **다른 입력과 프롬프트 결합** — 이미지·코드 등과 결합해 더 복잡하고 정보가 풍부한 출력 생성
- 실전 예시: "고양이에 대한 시를 써줘" → 평범한 시 생성 / "갱스터 래퍼 스타일로 고양이에 대한 시를 써줘"(수정자 추가) → 훨씬 창의적이고 유머러스한 시 생성

### 이미지 생성에서의 프롬프트 해킹
- LLM을 활용해 DALL-E, Imagen 같은 이미지 생성 모델을 안내하는 방식 — LLM에 원하는 이미지의 텍스트 설명을 주고, 그 출력을 이미지 생성 모델의 안내로 사용
- 예시: "빨간 소파에 앉아 카메라를 보는 복슬복슬한 주황 고양이" 프롬프트 → LLM이 더 상세한 묘사로 응답 → 이 응답을 이미지 생성에 활용
- **프롬프트 재작성 체이닝 예시**: "Twinkle Twinkle Little Star" 시를 위한 배경 이미지가 필요할 때 → (1) LLM에게 "이 시를 표현하는 이미지의 텍스트 설명을 만들어줘" 요청 → (2) 그 설명을 바탕으로 "이 설명에 맞는 이미지를 생성할 프롬프트를 제안해줘" 요청 → (3) 필요하면 "이 프롬프트를 DALL-E용으로 다시 써줘" 요청 — **LLM 자신에게 프롬프트 생성/변환을 맡기는 다단계 해킹**

### 프롬프트 해킹 vs 프롬프트 엔지니어링

| | 프롬프트 해킹(Prompt Hacks) | 프롬프트 엔지니어링(Prompt Engineering) |
|---|---|---|
| **목적** | LLM의 출력을 예상치 못한/의도치 않은 방식으로 조작 | 특정 작업에서 LLM의 성능을 향상 |
| **접근 방식** | 실험적이고 창의적 | 체계적이고 규율 있는 |
| **적용** | 유머러스하거나 창의적인 출력 생성 | 기계 번역, 질의응답 등 LLM 성능 향상 |

- 프롬프트 해킹과 프롬프트 엔지니어링의 경계는 항상 명확하지는 않음 — 특수 수정자로 톤을 제어하는 기법은 창의적 출력에도, 특정 스타일의 텍스트 생성 성능 향상에도 쓰일 수 있음

### 강력한 프롬프트 해킹을 위한 팁
- 창의적으로 시도하고 새로운 것을 두려워하지 말 것
- 지시를 구체적이고 명확하게 할 것
- LLM의 문서를 활용해 역량과 한계를 파악할 것
- 다양한 프롬프트를 실험하며 자신에게 맞는 것을 찾을 것

## 요약
- 프롬프트 해킹 = **프롬프트를 조작해 예상치 못하거나 창의적인 출력을 이끌어내는 실험적 기법** — 체계적으로 성능을 개선하는 프롬프트 엔지니어링과는 목적과 접근이 다르지만 서로 겹치는 부분도 있음
- 텍스트 생성(특수 수정자·맥락 제공)과 이미지 생성(LLM으로 이미지 생성 모델 안내, 프롬프트 재작성 체이닝) 양쪽에 적용 가능
- 정해진 정답이 없는 새로운 분야이므로, **직접 실험하며 자신만의 방법을 찾는 것**이 최선의 학습법
