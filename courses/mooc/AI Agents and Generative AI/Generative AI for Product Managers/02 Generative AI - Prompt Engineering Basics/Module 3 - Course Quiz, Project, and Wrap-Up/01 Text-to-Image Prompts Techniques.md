# 01 Text-to-Image Prompts Techniques (텍스트-투-이미지 프롬프트 기법)

## 개요
- 텍스트만으로 이미지를 생성할 때, 이미지의 품질과 임팩트를 높이는 5가지 이미지 프롬프팅 기법을 소개하는 영상

## 내용

### 이미지 프롬프트란
- **이미지 프롬프트** = 생성하고자 하는 이미지를 서술하는 텍스트 — 한 단어/구절처럼 단순할 수도, 구도·색상·분위기까지 상세히 묘사할 수도 있음
- 이미지 프롬프팅 기법의 목표: 생성형 AI 모델이 만드는 이미지의 **품질·다양성·관련성**을 향상시키는 것

### 5가지 이미지 프롬프팅 기법
1. **스타일 수정자(Style Modifiers)** — 이미지의 예술적 스타일·시각적 속성에 영향을 주는 서술어. 색상·대비·질감·형태·크기 같은 시각 요소를 조정하거나, 특정 예술 사조·시대·사진 기법·재료·유명 브랜드/작가의 스타일을 프롬프트에 포함시켜 원하는 외양을 유도
2. **품질 부스터(Quality Boosters)** — 이미지의 시각적 매력과 충실도·선명도를 높이는 용어. 예: "high resolution", "4k", "hyper-detailed", "sharp focus", "complementary colors" — 노이즈 감소·샤프닝·색보정·해상도 향상 같은 효과를 유도
3. **반복(Repetition)** — 반복 샘플링(iterative sampling)의 힘을 활용해 이미지의 다양성을 높이는 기법. 프롬프트 내에서 같은 단어나 유사 문구를 반복해 특정 시각 요소를 강조 → 모델이 그 개념에 집중하게 하고, 추상적이거나 모호한 프롬프트에 대해 다양한 잠재적 출력을 생성하는 데 특히 유용
4. **가중 용어(Weighted Terms)** — 강한 감정적·심리적 임팩트를 가진 단어나 구를 사용하고, 이를 **양수/음수 가중치**로 강조하거나 약화시키는 기법. 예: "warm"에 +10, "crackling"에 +8을 주면 모델이 warm에 더 집중; "colorful"에 -6, "exotic"에 +10을 주면 exotic을 강조하고 colorful을 약화
5. **기형 생성 수정(Fix Deformed Generations)** — 이미지 속 왜곡·이상(특히 손·발 같은 신체 부위의 뒤틀림)이나 픽셀화 등 품질 문제를 완화하는 기법. **좋은 네거티브 프롬프트(negative prompt)**를 사용해 이런 문제를 어느 정도 줄일 수 있음

## 요약
- 5대 이미지 프롬프팅 기법: **스타일 수정자 · 품질 부스터 · 반복 · 가중 용어 · 기형 생성 수정**
- 이 기법들을 결합하면 더 기억에 남고, 매력적이며, 설득력 있는 시각물을 만들어 의도한 메시지를 효과적으로 전달할 수 있음
