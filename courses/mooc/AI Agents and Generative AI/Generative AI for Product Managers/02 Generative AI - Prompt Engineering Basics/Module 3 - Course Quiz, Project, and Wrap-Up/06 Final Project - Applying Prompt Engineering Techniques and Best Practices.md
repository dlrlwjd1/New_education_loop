# 06 Final Project: Applying Prompt Engineering Techniques and Best Practices (최종 프로젝트)

## 개요
- 코스 전체에서 배운 프롬프트 엔지니어링 기법(명확성/정밀성, Tree-of-Thought, 인터뷰 패턴)을 3개 실습 과제로 종합 적용하는 45분 최종 프로젝트 (GPT-5 Nano 사용)

### 학습 목표
- 특정 요구사항에 맞춰 효과적인 프롬프트를 만들기 위해 프롬프트 엔지니어링 접근법 적용
- 명확성·맥락·정밀성 차원에서 효과적인 프롬프트 작성 모범 사례 적용

## 내용

### Exercise 1 — 명확하고 정밀한 프롬프트 작성 모범 사례
- 시나리오: 컴퓨터공학 졸업생이 "내 관심사·기술·기술 트렌드·AI의 영향·워라밸·개인 성장 기회를 모두 고려해 커리어를 안내해달라"는 **모호하고 복잡한 프롬프트**로 시작
- 힌트: 위 프롬프트를 **중첩된(nested) 프롬프트**로 쪼개, 각각 하나의 측면(관심사/기술, AI 영향, 워라밸, 성장 기회)에 집중하도록 설계
- 실습 결과: "머신러닝·NLP에 관심 있고 프로그래밍을 잘한다 — 이를 어떻게 커리어에 활용할까?" / "AI가 중요해지는데 AI 중심 커리어를 어떻게 준비할까?" / "워라밸과 유연 근무를 중시하는데 어떤 커리어가 이를 제공하나?" / "장기적으로 리더십 역할을 원하는데 어떤 단계를 밟아야 하나?" 4개의 **분리되고 명확한 프롬프트**로 각각 훨씬 구체적이고 실행 가능한 답변을 얻음
- 핵심 교훈: 복잡하고 다차원적인 질문 하나보다, **측면별로 분리된 명확한 프롬프트 여러 개**가 훨씬 유용한 답을 이끌어냄

### Exercise 2 — Tree-of-Thought 접근법 실험
- 시나리오: 고급 스마트폰 신제품 출시를 위한 마케팅 전략 수립
- Dave Hulbert가 제안한 ToT 프롬프트 패턴 적용: "3명의 마케팅 전문가가 협업해 전략을 개발한다고 상상해줘. 각 단계마다 전문가들이 먼저 개별 의견을 내고, 그다음 토론을 통해 아이디어를 정제하고, 각 단계 후 의견 수렴/차이를 요약해줘"
- 이 구조화된 프롬프트를 **나이브 프롬프트**("고급 스마트폰 신제품 출시 마케팅 전략을 알려줘")와 비교 → ToT 버전은 3명의 가상 전문가(Ava/Bruno/Chloe)가 시장 정의, 포지셔닝, 채널 전략, 출시 타임라인, 가격 정책, 출시 후 성장까지 **6단계에 걸쳐 개별 의견 → 토론 → 합의**를 도출하는 훨씬 풍부하고 구조화된 전략을 생성
- 후속 정제 단계로 실습한 패턴:
  1. **구체적 전술 요청**: "각 전문가별로 제안한 단계마다 실행 가능한 전술 2가지씩 제공해줘"
  2. **입력 데이터로 재정제**: 마케팅 목표(프리미엄 포지셔닝, 온·오프라인 채널 최대화 등)를 제공하고 "이 목표를 고려해 전술을 수정/정제해줘"
  3. **특정 전문가·특정 단계 심화**: "전문가 A에게 — 1단계와 관련해, 인구통계 정보를 수집할 시장 조사 설문 유형을 더 구체적으로 알려줘"
- 핵심 교훈: ToT는 **광범위한 전략(1단계) → 전술 구체화(2단계) → 목표 기반 재정제(3단계) → 특정 부분 심화(4단계)**로 점진적으로 좁혀가는 다단계 대화에 강력함

### Exercise 3 — 인터뷰 패턴 접근법 실험
- 시나리오: "생성형 AI가 여러 산업에 미치는 영향"을 주제로 블로그를 쓰는 AI 컨설턴트 역할
- **중첩 프롬프트(nested prompts)**로 인터뷰 패턴 적용:
  1. 초기 질문: "생성형 AI가 여러 산업에 미치는 영향에 대한 인사이트를 알려줘" → 헬스케어·금융·리테일·제조·기술·미디어·교육·자동차·에너지 등 산업 전반의 개괄적 답변
  2. 특정 산업 심화: "헬스케어 산업에서 생성형 AI가 어떻게 활용되고 있나요? 큰 차이를 만든 구체적 사례가 있나요?" → Med-PaLM, AI 보조 임상 문서화, 영상의학 워크플로 등 헬스케어 특화 사례로 좁혀짐
  3. 윤리적 고려사항 추가: "생성형 AI가 헬스케어에 미치는 과제와 윤리적 고려사항은 무엇인가요?" → 데이터 프라이버시, 편향·공정성, 설명가능성, 인간 개입(human-in-the-loop), 책임 소재 등 심층 답변
- 핵심 교훈: 인터뷰 패턴은 **넓은 질문에서 시작해 점점 좁고 구체적인 후속 질문으로 이어가며**, 블로그처럼 여러 섹션이 필요한 콘텐츠를 체계적으로 완성하는 데 효과적

## 요약
- 3개 실습이 공유하는 패턴: **모호하고 복잡한 단일 질문보다, 측면별로 나눈 여러 개의 명확한 프롬프트(또는 후속 질문)가 항상 더 유용한 결과를 만든다**
