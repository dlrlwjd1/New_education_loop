# 07 Course Wrap Up

## 내용

### 프롬프트와 프롬프트 엔지니어링
- **프롬프트** = 생성형 AI 모델에게 제공하는 입력/일련의 지시 — 모델이 정보를 수집하고 추론해 최적의 응답을 제공하게 함
- 잘 구조화된 프롬프트의 구성요소: **지시(instruction) · 맥락(context) · 입력 데이터(input data) · 출력 지표(output indicator)**
- **프롬프트 엔지니어링** = 생성형 AI 모델의 전체 역량을 활용하도록 효과적인 프롬프트를 설계하는 과정 — 성능 향상, 모델 제약 이해, 모델 보안 강화에 기여

### 모범 사례와 도구
- 효과적인 프롬프트 작성 모범 사례: **명확성을 위한 간결한 언어 사용, 맥락을 위한 배경 정보 제공, 정밀성을 위한 구체성과 예시 제공, 역할극(roleplay)을 위한 관련 맥락 제공**
- 프롬프트 엔지니어링 도구는 주어진 입력을 바탕으로 프롬프트를 제안하고, 더 나은 맥락적 소통을 위해 프롬프트를 구조화하며, 반복적으로 정제해 가장 효과적인 프롬프트를 찾고, 편향을 완화하며, 특정 도메인용 프롬프트를 생성하는 데 도움

### 텍스트-투-텍스트 기법 (재확인)
- 신뢰성 향상 8가지: **작업 명시 · 맥락적 안내 · 도메인 전문성 · 편향 완화 · 프레이밍 · Zero-shot 프롬프팅 · 사용자 피드백 루프 · Few-shot 프롬프팅**

### 프롬프트 엔지니어링 접근법 (재확인)
- **인터뷰 패턴**: 정적인 단일 프롬프트 대신, 모델과 주고받는 대화를 통해 질의를 명확히 하고 실시간으로 응답 방향을 안내
- **Chain-of-Thought**: 관련 질문과 그 해법을 모델에 제공해 문제 해결 논리를 학습시킴으로써 단계별 사고 과정을 이끌어내고 인지 능력을 강화
- **Tree-of-Thought**: Chain-of-Thought를 기반으로, 프롬프트를 계층적으로 구조화해 모델이 의사결정 나무처럼 여러 가능성과 아이디어를 동시에 탐색하도록 함
- **멀티모달 프롬프팅**: 텍스트·이미지·오디오 등 여러 입력 유형을 통합해 더 풍부하고 정확한 이해·상호작용·창의성을 가능케 함
- **Playoff Method**: 여러 프롬프트-응답 쌍을 생성해 명확성·정밀성·맥락적 관련성 기준으로 평가하는 반복적 접근으로, 프롬프트 설계를 지속적으로 개선

### 이미지 프롬프팅 기법 (재확인)
- 이미지의 임팩트를 높이는 5가지 기법: **스타일 수정자 · 품질 부스터 · 반복 · 가중 용어 · 기형 생성 수정**

### 실습 경험 총정리
