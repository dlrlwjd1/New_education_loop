# 03 Specialization Overview (이 코스가 속한 특화 과정들)

## 개요
- 이 코스(**Generative AI: Prompt Engineering Basics**)는 IBM의 **18개 이상의 서로 다른 특화 과정·전문 자격증**에 공통 2번째 코스로 포함되어 있는, 매우 범용적인 입문 코스임
- [Course 1의 03 Course in Multiple Programs](../../01%20Generative%20AI%20-%20Introduction%20and%20Applications/Module%201%20-%20Introduction%20and%20Capabilities%20of%20Generative%20AI/03%20Course%20in%20Multiple%20Programs.md)와 같은 패턴 — "Introduction and Applications" + "Prompt Engineering Basics" 두 코스가 거의 모든 IBM 생성형 AI 트랙의 공통 앞부분을 이룸

## 내용

### 이 코스가 포함된 대표 프로그램들
- Generative AI Fundamentals Specialization
- Applied AI Professional Certificate
- Generative AI for Data Scientists / Software Developers / Data Analysts / Data Engineering
- Generative AI for Educators / HR Professionals / Cybersecurity Professionals / Customer Support
- Generative AI for Java and Spring Developers / Mobile App Developers
- **Generative AI for Product Managers**(← 내가 듣는 과정) / Project Managers / Program Managers
- IBM Generative AI Engineering Professional Certificate, IBM AI Product Manager Professional Certificate, IBM AI Developer Professional Certificate 등

### 대표 프로그램 상세 — Generative AI Fundamentals Specialization
- 5개 코스로 구성(각 4~6시간): **Introduction and Applications → Prompt Engineering Basics → Foundation Models and Platforms → Impact, Considerations, and Ethical Issues → Business Transformation and Career Growth**
- 대상: 커리어 향상을 원하는 직장인, AI 트렌드를 따라가고 싶은 사람, 생성형 AI 입문자, 관리자·임원, 취업 준비 학생

### 직군별 특화 과정 예시
- **Generative AI for Data Scientists**: 데이터 증강·생성, 피처 엔지니어링, 모델 개발·정제, 시각화·인사이트에 생성형 AI 적용. 구성: Introduction and Applications / Prompt Engineering Basics / Elevate your Data Science Career
- **Generative AI for Software Developers**: GitHub Copilot·ChatGPT·Gemini로 코드 설계·개발·번역·테스트·문서화·배포. 구성: Introduction and Applications / Prompt Engineering Basics / Elevate your Software Development Career
- **Applied AI Professional Certificate**: 머신러닝·데이터 사이언스·NLP·이미지 처리·IBM Watson AI·OpenCV·API 등 폭넓게 다루며, 프로그래밍 배경 없이도 파이썬으로 AI 웹 앱을 만드는 실무 역량 습득

## 요약
- 공통 패턴 재확인: **"Introduction and Applications" → "Prompt Engineering Basics"**가 거의 모든 IBM 생성형 AI 트랙(데이터 사이언스, 소프트웨어 개발, PM 등)의 공통 도입부이고, 이후 직군별 3번째 코스(예: "Elevate your ~ Career")로 갈라지는 구조
- 내가 듣는 **Generative AI for Product Managers**도 동일 구조를 따름 — Course 1·2가 공통 기초, Course 3·4(Building AI-Powered Products, Supercharge Your PM Career)가 PM 특화 심화
