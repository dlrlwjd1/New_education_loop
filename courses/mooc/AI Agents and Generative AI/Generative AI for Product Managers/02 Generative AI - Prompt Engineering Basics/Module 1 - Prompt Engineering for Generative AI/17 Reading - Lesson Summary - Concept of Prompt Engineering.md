# 17 Reading: Lesson Summary: Concept of Prompt Engineering (레슨 요약)

## 개요
- Module 1의 Lesson 2 "Concept of Prompt Engineering" 전체를 마무리하는 공식 요약 읽기 자료 (오디오 포함)

## 내용
- 프롬프트 = 원하는 출력을 만들기 위해 생성형 모델에 제공하는 입력/일련의 지시. 모델의 창의성을 방향 짓고 관련성 있고 논리적인 응답을 만들도록 도움
- 잘 구성된 프롬프트의 구성요소: **지시(instruction) · 맥락(context) · 입력 데이터(input data) · 출력 지표(output indicator)**
- 프롬프트 엔지니어링 = 생성형 AI 모델의 전체 역량을 활용해 최적의 응답을 만들도록 효과적인 프롬프트를 설계하는 것
- 프롬프트 정제(refining)는 출력에 영향을 줄 수 있는 다양한 요인을 실험하는 과정을 포함
- 프롬프트 엔지니어링은 **모델 효율 최적화, 성능 향상, 모델 제약 이해, 보안 강화**에 도움
- 효과적인 프롬프트 작성은 출력의 **스타일·톤·콘텐츠**를 감독하는 데 필수적이며, 4대 차원(**명확성·맥락·정밀성·역할극**)으로 구현 가능
- 프롬프트 엔지니어링 도구는 프롬프트 제안, 맥락 이해, 반복적 정제, 편향 완화, 도메인 특화 지원, 사전 정의 프롬프트 라이브러리 등의 기능 제공
- 대표 도구: **IBM watsonx Prompt Lab, Spellbook, Dust, PromptPerfect**

## 요약
