# 06 What Is Prompt Engineering? (프롬프트 엔지니어링이란)

## 개요
- 프롬프트 엔지니어링을 정의하고 그 중요성을 설명하며, 효과적인 프롬프트를 만드는 반복적(iterative) 프로세스를 다루는 영상

## 내용

### 정의
- **프롬프트 엔지니어링 = 더 낫고 원하는 응답을 생성하도록 효과적인 프롬프트를 설계하는 과정**
- 생성형 AI는 인간의 창의성을 보완할 잠재력이 있지만, **정확한 프롬프트를 제공하지 못하면 부적절한 결과나 허위·오해의 소지가 있는 정보**를 생성할 수 있음
- 프롬프트 엔지니어링 = **비판적 분석 + 창의성 + 기술적 감각**의 조합 — 단순히 "올바른 질문을 하는 것"에 그치지 않고, **올바른 맥락과 정보, 원하는 결과에 대한 기대치까지 담아 질문을 프레이밍**하는 것을 포함

### 예시로 이해하기 — 선박 선장의 일기예보 요청
- 단순 프롬프트("대서양의 일기예보")로는 원하는 결과를 얻기 어려움
- 프롬프트를 엔지니어링하려면: **위도·경도로 특정 위치를 정의 + 예측 기간(시간 범위)을 명시**
- 최종 예시: "대서양에서 전략적 항해를 계획 중인 선장을 위해 2023년 8월 28일~9월 1일 기간, 북위 20~30도·서경 20~40도 좌표의 바람 패턴·파고·강수확률·구름량·잠재적 폭풍 정보를 상세히 제공해줘"

### 효과적인 프롬프트를 만드는 단계별 프로세스
1. **목표 정의(Define the goal)** — 모델이 정확히 무엇을 생성하길 원하는지 파악. 예: "AI와 자동차 산업의 이점·위험에 대한 간단한 개요"
2. **초안 프롬프트 작성(Craft initial prompt)** — 목표에 따라 질문/지시/상황 형태로 작성
3. **프롬프트 테스트(Test the prompt)** — 응답이 관련성은 있어도 원하는 특정 관점이 빠질 수 있음 (예: 윤리적 우려나 긍정/부정 함의에 대한 논의 부재)
4. **응답 분석(Analyze the response)** — 응답이 목표에 부합하는지 검토하고 부족한 부분을 기록
5. **프롬프트 정제(Refine the prompt)** — 구체성 강화, 맥락 추가, 표현 재구성으로 프롬프트 수정
6. **반복(Iterate)** — 3~5단계를 만족스러운 응답이 나올 때까지 반복
- 여러 차례 정제를 거친 최종 프롬프트 예시: "AI가 자율주행과 실시간 교통 분석 등 긍정적 발전을 중심으로 자동차 산업을 어떻게 재편하는지 다루되, 의사결정 알고리즘·사이버보안 침해 같은 기술적 복잡성 문제와 차량 안전에 미치는 함의까지 철저히 탐구하고, 예시로 뒷받침하며 비판적 사고를 유도하는 글을 써줘"

### 프롬프트 엔지니어링의 중요성 (4가지)
1. **모델 효율 최적화** — 추가 재훈련 없이도 모델의 전체 역량을 활용하는 지능적 프롬프트 설계
2. **특정 작업 성능 향상** — 뉘앙스 있고 맥락에 맞는 응답으로 특정 작업에 더 효과적
3. **모델 제약 이해** — 반복적으로 프롬프트를 정제하고 응답을 연구하며 모델의 강점·약점을 파악 → 향후 기능 개선이나 모델 개발에 활용
4. **모델 보안 강화** — 잘못 설계된 프롬프트로 인한 유해 콘텐츠 생성 문제를 능숙한 프롬프트 엔지니어링으로 예방 → 안전한 활용 촉진

## 요약
- 프롬프트 엔지니어링 = **목표 정의 → 초안 작성 → 테스트 → 분석 → 정제 → 반복**의 구조화된 반복 프로세스
- [05 What Is a Prompt](05%20What%20Is%20a%20Prompt.md)의 4대 구성요소(지시·맥락·입력데이터·출력지표)를 이 반복 프로세스 안에서 실제로 적용하는 것이 프롬프트 엔지니어링의 실체
- 중요성: **효율 최적화 · 작업 성능 향상 · 모델 제약 이해 · 보안 강화** — 단순한 "질문 잘하기"가 아니라 체계적 스킬
