# 14 Expert Viewpoints: Exploring Prompt Engineering in Generative AI (전문가 관점 — 프롬프트 엔지니어링 탐구)

## 개요
- 프롬프트 엔지니어링이 생성형 AI에서 하는 역할을 전문가들이 논의하는 영상 — **Module 2에서 자세히 다룰 기법들(Zero-shot, Few-shot, Chain of Thought)을 실무자 경험으로 미리 맛보기**

## 내용

### 프롬프트 엔지니어링 기본 정의
- **좋고 효과적인 프롬프트를 작성하는 기술** — 모델이 일관되고 두드러진(prominent) 출력을 만들도록 함
- 애플리케이션마다 구체적 기법은 다르지만, 기본은 **사고의 명료함 + 맥락 + 원하는 특징 나열**

### Zero-shot / One-shot / Few-shot (예고편)
- **Zero-shot**: 예시 없이 그냥 시키는 것 — 오늘날 ChatGPT를 쓰는 가장 일반적인 방식
- **One-shot**: "이 형식의 예시가 여기 있어, 이렇게 써줘"처럼 **예시 1개**를 줘서 형식을 안내
- **Few-shot**: **예시 2~3개 이상**을 제공 — 흥미로운 점은 **예시가 내용상 정확할 필요는 없고, 형식만 올바르면 됨**. 예시 몇 개를 만든 뒤 생성형 AI로 같은 형식의 예시를 더 만들어 프롬프트에 추가하는 것도 가능

### Chain of Thought (예고편)
- "일련의 단계를 줄 테니, 계획을 세우고 한 단계씩 생각하며 실행해줘"라는 방식 — LLM이 **궤도를 벗어나지 않도록** 도움
- 모델이 내부적으로 계획을 세우고 각 지시를 하나씩 처리한 뒤 마지막에 답을 종합함 → **복잡한 작업**일수록 효과적

### 역할(persona) 지정의 중요성 재확인
- "자바스크립트 전문가로서", "프로덕트 매니저로서", "소규모 사업체의 CEO로서"처럼 **특정 역할을 부여**할수록 결과 품질이 좋아짐

### 도구와 파라미터
- **watsonx Studio Prompt Engineering Lab** — 특정 애플리케이션에 맞는 프롬프트를 연습·개발하기 좋은 도구
- OpenAI, Microsoft Copilot 등도 좋은 프롬프트 작성법 가이드 제공
- **temperature, top-k, top-p** 같은 파라미터로 모델의 생성 정도(창의성 vs 제약)를 조절 가능

### 실무 사례 — 워크플로 설명하기
- ChatGPT에게 "워크플로를 분석하고 싶은데, 어떤 형식으로 주는 게 가장 좋을까?"라고 **직접 물어봄** → 모델이 스스로 구조를 제안 → 그 구조에 맞춰 프롬프트를 구성하니 필드를 정확히 매칭해 원하는 작업을 수행
- **Llama2** 같은 모델은 **특정 문법(syntax)**을 따라야 함 — 안 지켜도 결과는 나오지만, 목표는 **시행착오와 시간·비용 낭비를 최소화**하며 원하는 출력을 얻는 것

## 요약
