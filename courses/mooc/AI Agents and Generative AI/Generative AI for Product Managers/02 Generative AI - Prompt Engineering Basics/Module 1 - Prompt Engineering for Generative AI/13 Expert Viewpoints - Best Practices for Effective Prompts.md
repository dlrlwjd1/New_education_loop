# 13 Expert Viewpoints: Best Practices for Effective Prompts (전문가 관점 — 효과적인 프롬프트 모범 사례)

## 개요
- 생성형 AI 전문가들이 실무에서 쓰는 프롬프트 작성 노하우를 공유하는 영상 — [10 Best Practices for Prompt Creation](10%20Best%20Practices%20for%20Prompt%20Creation.md)의 이론을 실무자 관점에서 보강

## 내용

### 명확하고 구체적으로 요청하기
- 사람과 대화할 때는 열린 질문(open-ended question)으로 탐색 기회를 주지만, **AI 모델과 작업할 때는 더 구체적이고 지시적(directive)**이어야 함
- 가장 핵심적인 3가지: **① 명확한 요청 ② 맥락(어떤 애플리케이션을 대상으로 하는지) ③ 응답에서 원하는 특징들을 나열**
- 비유: "초창의적인 로봇에게 지시하는 것" — 명확하고 간결하되(예: "캐치한 로봇 노래를 써줘"), 너무 통제적이지 말고 로봇 자신의 아이디어가 들어갈 여지를 남겨둘 것. 프롬프트 길이도 상황에 따라 실험(짧게 충분할 때 vs 더 많은 디테일이 필요할 때)

### 맥락·자연어·예시 제공
- 모델이 활용할 수 있도록 **배경 정보(context)**를 제공
- **자연어**로 소통하고 어려운 용어나 모호함은 피할 것
- **예시를 포함**(few-shot learning 개념) — 질문-답변 예시나 응답의 구조/스타일 예시를 주면 그에 맞춰 결과를 생성

### 전문가 역할(role) 지정
- 특정 분야의 전문가(예: 헬스케어 전문가, 프로덕트 매니저)를 지정하면 LLM이 해당 정보에 초점을 맞추도록 유도
- 실무 예시: "프로덕트 매니저로서, 표준 문제 정의서(problem statement) 형식으로 문제 정의서 작성을 도와줘" → 일관되게 좋은 품질의 결과를 얻음

### 반복(iterate)과 제약 조건
- 원하는 결과가 나올 때까지 **질문을 반복(iterate)**할 것
- **제약 조건(constraints)** 제공 가능 — 콘텐츠 제한, 특정 구조 회피, 가이드라인 제시, 토큰 수 제한, 맥락 윈도우 지정 등
- 반복적으로 프롬프트를 평가·정제하며 **모델의 창의성/무작위성과 맥락 관련성 사이의 균형**을 맞출 것
- 최신 모델은 **메모리(기억력)**가 더 좋아서 이전 대화 내용을 기억함 — 빠진 정보가 있으면 추가해달라고 요청하거나 다시 써달라고 요청 가능
- **팁**: 프롬프트 작성법 자체가 확실치 않다면, "플로우차트를 얻으려면 어떻게 프롬프트를 써야 할까?"처럼 **모델에게 직접 물어보라** — 모델이 어떤 유형의 프롬프트가 필요한지 알려줌

## 요약
- 실무 프롬프트 작성의 핵심: **명확성 + 맥락 + 예시 + 전문가 역할 지정 + 반복 + 제약 조건**
- "연습이 완벽을 만든다" — 다양한 방식으로 지시를 바꿔가며 최적의 표현을 찾을 것, 모델마다 강점이 다르므로 그에 맞게 프롬프트를 조정할 것
- 모르겠으면 **모델에게 프롬프트 작성법 자체를 물어보라**는 조언이 특히 실용적 — [10 Best Practices for Prompt Creation](10%20Best%20Practices%20for%20Prompt%20Creation.md)의 4대 차원(명확성·맥락·정밀성·역할극)을 실무 팁으로 재확인
