# 05 What Is a Prompt? (프롬프트란 무엇인가)

## 개요
- 프롬프트(prompt)를 정의하고 그 구성 요소를 설명하며, 효과적인 프롬프트 작성이 왜 중요한지 다루는 영상
- 생성형 AI 모델의 핵심 역량 중 하나는 결과물이 인간이 만든 것과 매우 유사(관련성·맥락성·창의성·뉘앙스·언어적 정확성)하다는 것 — 이 출력의 품질을 좌우하는 핵심 요인이 바로 **프롬프트**

## 내용

### 프롬프트의 정의
- **프롬프트 = 원하는 출력을 만들기 위해 생성형 모델에 제공하는 모든 입력** — 모델에게 주는 "지시(instruction)"라고 생각할 수 있음
- 단순한 프롬프트: "가장 좋아하는 휴가지를 짧은 단락으로 써줘", "온라인 폼의 도시 드롭다운 선택을 위한 HTML 코드를 써줘"
- 프롬프트는 **단계별로 결과를 다듬어가는 일련의 지시**일 수도 있음: "화성 생명체를 연구하는 과학자에 대한 짧은 이야기를 써줘. 그가 연구 중 겪은 어려움은 무엇이었을까?"
- 프롬프트에는 **질문, 맥락 텍스트, 안내 패턴/예시, 모델을 위한 부분 입력**이 담김

### 나이브 프롬프팅(Naive Prompting)의 한계
- 예: "작은 마을 출신 부자 이야기, 그의 고난과 성취" → 너무 단순해 **일반적이고 두루뭉술한 결과**만 나옴 (나이브 프롬프팅 = 가장 단순한 방식으로 질의하는 것)
- 개선: "10년 만에 부유하고 영향력 있는 사업가가 된 농부의 고난과 성취에 대한 짧은 이야기를 써줘" — 맥락과 구조를 갖추면 결과가 크게 개선됨
- 이미지 예시: "산 사이의 석양 이미지"(너무 짧고 구체성 부족) → "산으로 둘러싸인 강 계곡 위로 고요한 석양이 지는 풍경 이미지를 생성해줘"(구체적)

### 잘 구성된 프롬프트의 4가지 구성 요소
1. **지시(Instruction)** — 수행하고자 하는 작업에 대한 명확한 가이드라인. 예: "해양 생물에 대한 지구온난화의 영향을 분석하는 600단어 에세이를 써줘"
2. **맥락(Context)** — 지시의 배경이 되는 상황을 설정해 관련성 있는 콘텐츠 생성의 틀을 제공. 예: 위 지시 앞에 "최근 수십 년간 지구온난화로 해수면 상승, 폭풍 강도 증가, 기후 패턴 변화가 있었다..."는 배경 설명 추가
3. **입력 데이터(Input Data)** — 프롬프트의 일부로 제공하는 구체적 정보/참조 자료. 예: "태평양의 수온 기록과 해수면 측정 데이터셋이 주어졌다..."를 추가해 특정 데이터 기반 응답 유도
4. **출력 지표(Output Indicator)** — 원하는 출력의 톤·스타일·길이 등 속성을 평가하는 기준 제시. 예: "600단어 에세이"라는 명시가 곧 출력 지표 — 분석의 명료성, 관련 데이터/사례 반영 여부로 평가됨

## 요약
- 프롬프트 = **원하는 출력을 만들기 위한 모든 입력/일련의 지시** — 모델의 창의성을 방향 짓고 관련성 있고 논리적인 응답을 이끌어냄
- 잘 구성된 프롬프트의 4대 구성 요소: **지시 · 맥락 · 입력 데이터 · 출력 지표**
- 나이브 프롬프팅(너무 단순한 질의)은 일반적인 결과만 낳음 — 구체성을 더할수록 결과 품질이 좋아진다는 원칙은 이후 [11 Lab - Naive Prompting and Persona Pattern](11%20Lab%20-%20Naive%20Prompting%20and%20Persona%20Pattern.md)에서 실습으로 이어짐
