# 02 Course Overview (코스 개요)

## 개요
- 생성형 AI 모델은 강력하지만, **그 효과는 모델을 이끄는 프롬프트의 품질에 달려 있음** — 이 코스는 프롬프트 엔지니어링 기법을 마스터하고 LLM의 잠재력을 최대한 끌어내는 법을 다룸

## 내용

### 학습 목표
- 생성형 AI 모델에서 프롬프트 엔지니어링의 개념과 중요성 설명
- 자주 쓰이는 프롬프트 엔지니어링 도구 평가
- 효과적인 프롬프트 작성을 위한 모범 사례 적용
- 프롬프트 작성을 위한 일반적인 기법·접근법 적용

### 핵심 기법·접근법 (코스 전체 미리보기)
- **기초 기법**: Zero-shot, Few-shot 프롬프팅
- **고급 접근법**: Interview Pattern, Chain of Thought(사고의 연쇄), Tree of Thought(사고의 나무)
- 이 전략들은 생성형 AI 작업 시 **신뢰성·관련성·창의성**을 향상시킴

### 코스 구성 (주차별)
- **Week 1 / Module 1: Prompt Engineering for Generative AI** — 프롬프트 엔지니어링 개념, 효과적인 프롬프트 작성 모범 사례, 일반적인 도구 평가
- **Week 2 / Module 2: Prompt Engineering: Techniques and Approaches** — 생성형 AI 모델을 효과적으로 조종하는 프롬프트 작성 기법과 접근법
- **Week 3 / Module 3: Course Quiz, Project and Wrap-Up** — 채점 퀴즈, 용어집, 다음 학습 단계 안내. **텍스트-투-이미지 프롬프팅**과 **IBM watsonx의 프롬프트 엔지니어링 기능** 관련 선택 주제 포함

### 학습 자원
- 팟캐스트, **인터랙티브 역할극(role-play)**, 영상, 실습 랩, 전문가 관점(Expert Viewpoints), 토론, 퀴즈
- 실습 랩은 **IBM Generative AI Classroom**에서 진행 — 프로그래밍 배경이나 학위 불필요

### 수강 대상
- 프롬프트 엔지니어링 입문자, 취업 준비생, 업무 효율을 높이려는 전문가, 조직에 전략적으로 활용하려는 관리자·임원 — **특별한 사전 지식 불필요**

## 요약
- 이 코스의 핵심: **좋은 프롬프트 = 신뢰성 있고 관련성 높은 결과**를 얻는 열쇠
- 3개 모듈 흐름: **개념·도구(M1) → 기법·접근법(M2) → 프로젝트·평가(M3)**, IBM watsonx/Spellbook/Dust 같은 실무 도구와 IBM Generative AI Classroom 실습으로 이론과 실무를 연결
