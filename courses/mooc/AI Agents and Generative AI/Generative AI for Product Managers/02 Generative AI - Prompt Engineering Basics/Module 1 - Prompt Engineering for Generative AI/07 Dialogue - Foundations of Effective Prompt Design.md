# 07 Dialogue: Foundations of Effective Prompt Design (대화 실습)

## 개요
- [05 What Is a Prompt](05%20What%20Is%20a%20Prompt.md)·[06 What Is Prompt Engineering](06%20What%20Is%20Prompt%20Engineering.md)에서 배운 개념을 AI 코치와의 대화로 직접 적용해보는 15분 실습

## 내용
다루는 4가지 주제:
1. **나이브 프롬프트 → 엔지니어링된 프롬프트**: 기본적이고 모호한 프롬프트가 어떻게 의도적으로 설계된 프롬프트로 발전해 결과를 개선하는지 분석
2. **4대 구성요소 실전 적용**: 프롬프트의 4요소(지시·맥락·입력 데이터·출력 지표)를 실제 시나리오에 적용
3. **반복적 정제 사이클 마스터하기**: 프롬프트 엔지니어링의 6단계 프로세스(목표 정의→초안→테스트→분석→정제→반복)를 왜 계속 반복해야 하는지 이해
4. **프롬프트 엔지니어링이 왜 중요한가**: 이 스킬을 실제 응용 사례에 연결

## 요약
- 이 대화는 별도의 새 개념이 아니라, 앞선 두 영상의 이론(4대 구성요소, 6단계 반복 프로세스)을 **직접 적용해보며 체화**하는 것이 목적
- 막히면 "I'm stuck" 버튼으로 힌트를 받을 수 있는 AI 코치 대화형 실습
