# 01 Course Introduction (코스 소개)

## 개요
- "전문가는 올바른 질문을 던지면 모든 답을 안다" — 생성형 AI 프롬프트 설계도 같은 원리
- 프롬프트는 챗봇, 이미지·오디오·비디오 생성 도구, 가상 세계 등 모든 생성형 AI 애플리케이션에 질의하는 데 쓰이며, **프롬프트가 곧 응답의 품질을 좌우**함

## 내용

### 코스 학습 목표
- 생성형 AI 모델에서 프롬프트 엔지니어링의 개념과 중요성 설명
- 효과적인 프롬프트 작성을 위한 모범 사례 적용
- 자주 쓰이는 프롬프트 엔지니어링 도구 평가
- 효과적인 프롬프트를 쓰기 위한 일반적인 프롬프트 엔지니어링 기법·접근법 적용

### 코스 구성 (3개 모듈, 각 1~2시간)
- **Module 1** — 프롬프트 엔지니어링 개념(프롬프트의 정의·구성 요소), 효과적인 프롬프트 작성 모범 사례, 일반적인 도구 평가(**IBM watsonx, Prompt Lab, Spellbook, Dust**)
- **Module 2** — 다양한 프롬프트 엔지니어링 접근법(**Interview Pattern, Chain-of-Thought, Tree-of-Thought**)과 기법(**Zero-shot, Few-shot**)으로 정밀하고 관련성 높은 응답 생성
- **Module 3** — 최종 프로젝트 + 채점 퀴즈, 용어집, 다음 학습 단계 안내

### 학습 방식
- 개념 영상 + 보충 읽기 자료, 실습 랩과 최종 프로젝트(IBM Generative AI Classroom에서 효과적인 프롬프트로 결과를 최적화하는 법 실습)
- 레슨별 연습 퀴즈 + 코스 끝 채점 퀴즈
- 토론 포럼, **전문가 관점(Expert Viewpoint) 영상** — 실무자들이 프롬프트 엔지니어링 도구·접근법·효과적인 프롬프트 작성의 노하우 공유

## 요약
- 이 코스의 핵심 메시지: **프롬프트의 힘은 "어떤 질문을 던지는가"에 있다**
- 3개 모듈 흐름: **개념·모범사례·도구(M1) → 접근법·기법(M2) → 최종 프로젝트·평가(M3)**
- 배경·경험 무관하게 모든 학습자를 위한 입문 과정 — [03 Course in Multiple Programs](../../01%20Generative%20AI%20-%20Introduction%20and%20Applications/Module%201%20-%20Introduction%20and%20Capabilities%20of%20Generative%20AI/03%20Course%20in%20Multiple%20Programs.md)에서 다룬 것과 마찬가지로 이 코스도 여러 특화 과정에 공통으로 포함됨
