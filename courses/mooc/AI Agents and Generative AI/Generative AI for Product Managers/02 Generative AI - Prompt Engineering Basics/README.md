# Generative AI: Prompt Engineering Basics

**Course URL:** [mooc.org/learn/generative-ai-prompt-engineering-for-everyone](https://www.mooc.org/learn/generative-ai-prompt-engineering-for-everyone)

IBM · Rav Ahuja. **Generative AI for Product Managers** 특화 과정의 Course 2. 이 코스는 IBM의 18개 이상의 다른 특화 과정에도 공통으로 포함되어 있음 ([Module 1 - 03 Specialization Overview](Module%201%20-%20Prompt%20Engineering%20for%20Generative%20AI/03%20Specialization%20Overview.md) 참고).

## 모듈 구성

- [Module 1 - Prompt Engineering for Generative AI](Module%201%20-%20Prompt%20Engineering%20for%20Generative%20AI/) — 프롬프트의 정의와 4대 구성요소, 프롬프트 엔지니어링 개념, Persona Pattern, 프롬프트 엔지니어링 도구 생태계
- [Module 2 - Prompt Engineering - Techniques and Approaches](Module%202%20-%20Prompt%20Engineering%20-%20Techniques%20and%20Approaches/) — 텍스트-투-텍스트 기법, 인터뷰 패턴, Chain-of-Thought, Tree-of-Thought, 멀티모달 프롬프트, Playoff Method
- [Module 3 - Course Quiz, Project, and Wrap-Up](Module%203%20-%20Course%20Quiz%2C%20Project%2C%20and%20Wrap-Up/) — 텍스트-투-이미지 프롬프팅, 용어집, 프롬프트 해킹, 최종 프로젝트, 코스 마무리

> 2026-07-15: `Generative AI for Product Managers` 스페셜라이제이션 전체를 정리하는 작업의 일환으로, 이 코스도 MOOC 실제 강좌 구조(3개 모듈)에 맞춰 각 모듈의 빠진 항목(영상 트랜스크립트, 랩, 팟캐스트, 읽기 자료 등)을 모두 채워 넣음.
