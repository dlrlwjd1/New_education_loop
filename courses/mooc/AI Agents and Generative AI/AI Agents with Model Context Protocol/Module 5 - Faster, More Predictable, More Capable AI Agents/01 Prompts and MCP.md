# Prompts and MCP

## 개요
- MCP의 세 번째 핵심 요소인 **프롬프트(prompts)** — 잘 만든 프롬프트를 **재사용 가능한 템플릿(template)**으로 만들어, AI가 도구/리소스처럼 발견하고 스스로 사용할 수 있게 하는 개념을 다루는 강의.

## 내용
### 프롬프트 자체가 하나의 강력한 "도구"다
- 저자는 일상에서 가장 강력하게 쓰는 도구 중 하나가 **LLM에게 쓰는 프롬프트 자체**라고 말한다.
- 좋은 프롬프트는 원래 사람이 해야 했던 **인지적 작업(cognitive task)을 컴퓨터가 할 수 있는 작업으로 변환**한다.
  - 예: "이 사람에게 맞춤화된 신나는 마케팅 계획을 써줘", "아이를 위한 재미있는 포켓몬 게임을 디자인해줘" — 예전엔 컴퓨터가 할 수 없었지만, 프롬프트 덕분에 가능해짐.
- 좋은 프롬프트/템플릿은 저장해서 재사용할 만큼 가치가 있다.

### MCP의 "prompts" — AI가 프롬프트 템플릿을 스스로 발견하고 쓰게 하기
- 아이디어: 좋은 프롬프트(템플릿)를 매번 사람이 새로 짜지 않고, **AI 자신이 발견해서 스스로에게(또는 다른 LLM에게) 사용**하게 만드는 것.
- 즉, "AI에게 자기 자신과 대화하기 위한 템플릿을 준다"는 다소 신기한 개념.
- 관점 정리: 도구(tool), 리소스(resource), 프롬프트(prompt) 모두 결국 **AI가 발견해서 사용하는 대상**이라는 점에서 유사하다.
  - 도구 = 행동을 수행하는 것
  - 리소스 = 읽기 전용으로 정보를 제공하는 것 ("읽기 전용 도구"에 가까움)
  - 프롬프트 = 특정 형식의 결과물을 안정적으로 생성하기 위한 템플릿

### 실습 예시 — 영수증(receipt) 생성 프롬프트
- 목표: 영수증을 아무 형식으로나 생성하게 두지 않고, **일관된 형식으로 생성되도록 프롬프트 템플릿을 미리 정의**해서 AI가 그것을 쓰게 만드는 것.
- 흐름:
  1. 과제: "거래 ID 1234에 대한 인보이스(영수증)를 만들어줘."
  2. AI가 먼저 **거래 상세정보(transaction details)를 조회하는 도구**를 사용해 필요한 데이터를 가져온다.
  3. 영수증을 만들기 위해, 사전 정의된 **"영수증 생성 프롬프트(receipt prompt)"**를 사용하겠다고 판단.
  4. 그 프롬프트 템플릿에 조회한 데이터(파라미터)를 채워 넣도록 요청.
  5. 일부 항목(개별 품목 등)은 아직 채워지지 않은 채로, 미리 정의된 형식(마크다운 등)의 프롬프트를 돌려받는다.
  6. AI는 이 채워진 프롬프트를 **자기 자신(LLM)에게 다시 사용**해, 나머지 빈칸을 채워 최종 인보이스를 완성한다.

### 왜 이것이 강력한가
- 우리가 평소 LLM에게 입력하는 프롬프트 중 **"이건 정말 잘 작동한다", "이건 우리 회사 포맷에 딱 맞다"**고 검증된 것들을 골라, **MCP를 통해 AI 자신에게 노출(expose)**할 수 있다.
- 이렇게 하면 AI가 매번 임의로 형식을 재발명하지 않고, **검증된 템플릿을 일관되게 재사용**하며 작업을 수행하게 된다.

## 예시
```
사용 가능한 프롬프트: generate_receipt (설명: "결제 영수증을 마크다운 형식으로 생성")

AI 실행 흐름:
1. use: get_transaction_details (transaction_id=1234)
2. use_prompt: generate_receipt (조회한 거래 데이터를 파라미터로 채움)
3. (일부 빈칸이 남은 프롬프트 템플릿을 반환받음)
4. 그 프롬프트를 LLM에 다시 입력 → 최종 영수증 완성
```

## 요약
- MCP의 **prompts**는 검증된 프롬프트 템플릿을 도구/리소스처럼 AI가 발견하고 스스로 사용할 수 있게 만드는 요소다.
- 프롬프트 자체가 "인지적 작업을 컴퓨터 작업으로 바꾸는 강력한 도구"이며, 좋은 프롬프트를 템플릿화해 노출하면 결과물의 **형식 일관성**을 크게 높일 수 있다.
- 도구(행동 수행), 리소스(정보 읽기), 프롬프트(템플릿 재사용)는 모두 "AI가 발견해서 쓰는 대상"이라는 공통된 MCP의 틀 안에 있다.
