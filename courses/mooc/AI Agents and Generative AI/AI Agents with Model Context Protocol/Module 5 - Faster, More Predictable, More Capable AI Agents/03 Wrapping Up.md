# Wrapping Up

## 개요
- 강좌 전체를 마무리하며, MCP가 실제로 왜 가치 있는지를 **여행 일정 정리**라는 실생활 예제로 다시 한 번 보여주는 마지막 강의.

## 내용
### 왜 이 모든 수고를 들이는가 — MCP의 실질적 가치
- AI에게 우리가 쓰는 도구(앱)에 대한 접근권을 주면, 정말 **"마법 같은" 일들이 일어나기 시작한다.**
- 흔한 문제: 이메일로 오는 정보(예약 확인서 등)를 정리하고 필요한 곳에 모아두는 일은 늘 번거롭다 — 계속 복사/붙여넣기를 해야 한다.
- MCP를 통해 AI가 이런 앱들에 직접 접근하면, 이 과정이 훨씬 단순해진다.

### 실전 시연 — 여행 일정 자동 정리
- 프롬프트(Claude에게): "힐튼 호텔 예약 확인서를 방금 받았어. 세부 내용은 말하지 말고, 그냥 가져와서 Notion에 올바른 날짜로 여행 일정 페이지를 만들어줘."
- AI의 동작:
  1. "도와드릴게요"라고 응답.
  2. **이메일을 검색**해 힐튼 호텔 확인서를 찾음.
  3. 세부 정보(날짜 등)를 추출.
  4. **Notion 페이지를 생성**해 여행 일정과 중요 정보를 정리.
- 결과: 사용자가 직접 이메일을 뒤지고 정보를 복사해 Notion에 붙여넣는 수고 없이, **AI가 이메일과 Notion이라는 서로 다른 두 앱을 넘나들며 작업을 완결**함.

### 확장 가능한 활용 예시
- "이걸 이메일에서 찾아줘", "여행 일정을 만들어줘", "이 영수증들을 모아서 경비 보고서로 만들어줘", "관련 문서를 찾아서 초안을 작성해줘" 등 다양한 방식으로 확장 가능.

### 핵심 결론
- MCP 덕분에 우리는 각 앱마다 따로따로 들어있는 "작은 AI(little AI)"에 갇히지 않고, **여러 앱을 넘나들며 일할 수 있는 "큰 AI(big AI)"**를 가질 수 있다.
- 이는 사람이 AI와 각 도구 사이의 **중간 전달자(intermediary)** 역할에서 벗어나게 해준다 (강좌 첫 강의에서 제기했던 문제의 해결).
- 결과적으로 AI를 **진짜 노동력(labor)**으로 위임(delegate)해 활용할 수 있게 되며, 수작업으로 복사·붙여넣기를 반복하며 AI의 결과물을 억지로 쓸모 있게 만드는 것과는 차원이 다른 생산성을 얻는다.

## 예시
```
프롬프트: "I just got my Hilton hotel confirmation. Don't talk about the details.
Just grab it and start an itinerary in Notion with a Notion page for the trip with the correct dates."
→ AI가 이메일 검색(도구) → 정보 추출 → Notion 페이지 생성(도구)까지 자동 수행.
```

## 요약
- MCP는 여행 일정 정리처럼 **여러 앱(이메일, Notion 등)을 넘나드는 실생활 작업**을 사람의 개입 없이 AI가 처리하게 해준다.
- 이것이 가능한 이유는 앱마다 갇힌 "little AI"가 아니라, **모든 도구에 접근할 수 있는 "big AI"**를 MCP로 구성했기 때문.
- 최종 결론: MCP는 사람을 AI와 도구 사이의 "중간 전달자"에서 해방시켜, AI를 진짜 위임 가능한 노동력으로 활용하게 만든다.
