# Model Context Protocol & AI Agents

## 개요
- **"AI 에이전트(AI agent)"**라는 용어의 의미와, MCP가 AI 에이전트의 핵심 동작 방식인 **"루프(loop)"**를 어떻게 가능하게 하는지를 여행 경비 추가라는 예제로 설명하는 강의.

## 내용
### AI 에이전트란 — "에이전시(agency)"를 가진 존재
- 예시 과제: "이 여행 경비를 추가하는 걸 도와줘(help me add this travel expense)."
- AI 에이전트는 스파게티 요리 예시처럼 **자신이 쓸 수 있는 도구를 활용해 과제를 수행**한다.
- 핵심 특징: **에이전시(agency)** — 스스로 무엇을 할지 결정하고 행동을 취하는 능력. 사람을 대신해 과제를 수행하기 위해 스스로 판단하고 행동한다.

### 실습 흐름 — 여행 경비 스프레드시트에 행 추가하기
1. AI: "여행 경비 스프레드시트의 행들을 나열하는 도구가 있으니 그걸 써야겠다" → 도구 호출.
2. 컴퓨터(MCP를 통해 메시지 수신) → 행 목록을 MCP의 문법·의미·타이밍 규칙에 맞춰 AI에게 반환.
3. AI: "이 영수증이 스프레드시트에 없네. 추가해야겠다" → `add row` 도구 호출 + 세부 정보 제공.
4. 컴퓨터: 행 추가 실행.

### AI 에이전트의 "루프(loop)" 구조
- 사람이 AI에게 과제를 넘기면, AI 에이전트는 **루프**에 들어간다:
  1. "지금 무엇을 해야 하지?" 판단
  2. 적절한 **도구를 선택**
  3. 컴퓨터에게 **그 도구를 쓰라고 지시**
  4. **결과**를 받음
  5. "다음엔 무엇을 해야 하지?" 다시 판단 → 반복
  6. 문제가 해결됐다고 판단되면 **루프를 종료**하고 사람에게 요약 보고
- 이 반복 과정을 저자는 "문제를 한 조각씩 깎아나가는 것(chisel away at the problem)"이라고 표현.

### 앱(app)이 아니라 "특정 기능(capability)"이 도구가 된다
- AI 에이전트가 쓰는 "도구"는 이메일 앱 자체가 아니라, 그 안의 **구체적인 기능**이다.
  - 예: "이메일 보내기(send email)", "이메일 확인(check email)", "최근 이메일 10개 가져오기", "다음 주 캘린더 일정 보여주기" 등 각각이 개별 도구가 된다.

### 도구 발견(tool discovery) 과정
- AI 에이전트가 시작되어 **MCP 서버**(=컴퓨터, 다음 강의에서 자세히 다룰 개념)에 연결되면, 가장 먼저 하는 일은 **"사용 가능한 도구 목록을 달라"**고 요청하는 것.
- MCP를 통해 도구 목록(예: send email, check calendar 등)을 받으면, 이는 마치 앞선 스파게티 예시에서 "strainer, pot, faucet"를 프롬프트에 채워 넣었던 것과 동일한 방식으로, **디지털 도구 버전으로 채워진다.**
- 이후 루프에 들어가 도구를 하나씩 호출하며 문제를 해결.

### 이 모든 과정에서 "보이지 않는" 것 — 사람의 개입이 사라짐
- 핵심 포인트: 이 흐름에는 **사람이 캘린더를 확인해서 알려주거나, 이메일 프로그램을 열어 수신자 필드에 복사·붙여넣기 하는 과정이 전혀 없다.**
- AI가 **애플리케이션 내부의 함수(기능)에 직접 접근**해서 작업을 수행하기 때문 — 이것이 바로 MCP가 가능하게 하는 것.

## 예시
```
사용자: "Help me add this travel expense."
→ AI 에이전트 루프:
  1. use: list_rows (여행 경비 스프레드시트 행 나열)
  2. (결과: 현재 행 목록)
  3. use: add_row (누락된 영수증 추가)
  4. (결과: 행 추가 완료)
  5. 루프 종료 → 사용자에게 요약 보고
```

## 요약
- **AI 에이전트**는 에이전시(스스로 판단하고 행동하는 능력)를 가지고, 과제를 받으면 **"도구 선택 → 호출 → 결과 확인 → 다음 행동 결정"을 반복하는 루프**에 들어가 문제를 해결한다.
- MCP는 이 루프에서 AI가 컴퓨터와 주고받는 모든 메시지(도구 목록 요청, 도구 호출, 결과 반환)의 통신 방식을 제공한다.
- 도구는 앱 전체가 아니라 앱 안의 **구체적인 기능 단위**이며, MCP 덕분에 AI는 사람의 개입 없이 이런 기능들에 직접 접근해 작업을 완수한다.
