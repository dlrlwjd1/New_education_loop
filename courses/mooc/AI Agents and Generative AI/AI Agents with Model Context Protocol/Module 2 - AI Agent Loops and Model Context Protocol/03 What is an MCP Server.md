# What is an MCP Server?

## 개요
- MCP를 실제로 사용하기 위해 필요한 **MCP 서버(MCP server)**가 무엇인지, 어떻게 구조화되어 있는지를 다루는 강의.

## 내용
### MCP 서버란
- **AI가 실제로 대화하는 대상**이 되는 소프트웨어 애플리케이션.
- 내 컴퓨터에 있을 수도 있고, 클라우드에 있을 수도 있다.
- 목적이 단 하나: **AI가 특정 앱과 소통할 수 있게 해주는 것.**

### MCP 서버를 구하는 방법
- 대부분의 경우, 직접 서버를 구축·실행할 필요는 없다 — **벤더(vendor)에게 "이 애플리케이션용 MCP 서버가 있느냐"고 물어보고, 필요한 설정 정보만 받으면 된다.** 이미 실행 중인 경우가 많음.
- 다만 사내에 자체 구축한 온프레미스 데이터베이스처럼, **직접 MCP 서버를 실행해야 하는 경우**도 있다.

### MCP 서버의 가장 기본적인 역할 — "도구 목록 제공"
- AI가 사용할 프롬프트에는 "사용 가능한 도구 목록"이 채워져야 하는데, 이 목록을 채워주는 것이 MCP 서버의 가장 근본적인 역할.
- AI가 MCP 서버에 접속하면 가장 먼저 **"당신이 제공하는 도구 목록을 달라(list your tools)"**고 요청한다.
- 애플리케이션 버전에 따라 사용 가능한 도구가 다를 수 있으므로, AI는 매번 **그 시점에 어떤 도구들이 있는지 발견(discover)**해야 한다.

### "앱마다 하나의 MCP 서버"라는 구조
- 일반적으로 이메일, 캘린더, CRM(고객관계관리 시스템), 메시징 시스템, 데이터베이스 등 **중요한 애플리케이션마다 각각의 MCP 서버**가 존재한다.
- 클라우드 기반 서비스(이메일 등)는 벤더가 이미 MCP 서버를 운영 중일 가능성이 높고, 사용자는 계정 정보 등만 설정하면 된다.
- 사내에 있는 자체 데이터베이스 등은 **조직이 직접 MCP 서버를 실행**해야 할 수 있다.

### AI 시작 시의 흐름 — 여러 MCP 서버를 순회하며 도구 발견
1. AI가 시작되면, 연결된 **각 MCP 서버마다 "도구 목록을 달라"**고 순서대로 요청한다 (이메일 서버 → 캘린더 서버 → CRM 서버 → ...).
2. 모든 서버로부터 받은 도구들을 **하나의 통합된 목록**으로 합쳐 프롬프트에 채운다.
3. 이 통합된 도구 목록을 바탕으로, 주어진 문제를 어떻게 분해해서 풀지 계획을다.

### 하나의 MCP 서버 안에 여러 도구가 있을 수 있다
- 예: 이메일 MCP 서버 하나에 다음과 같은 여러 도구가 있을 수 있음:
  - 이메일 보내기(send email)
  - 최근 10개/100개 이메일 가져오기
  - 특정 기간의 이메일 모두 가져오기
  - 이메일 초안 만들기
  - 이메일에 라벨 붙이기
  - 이메일 삭제하기
- MCP 서버의 역할: 이런 도구 목록을 AI에게 제공하고, AI가 특정 도구를 쓰겠다고 하면 **MCP 언어로 그 요청을 받아, 실제로 해당 기능(이메일 발송/삭제 등)을 실행**하는 것.

### 정리 — MCP 서버 = "MCP 언어를 구사하는 애플리케이션 관리자"
- MCP 서버는 **MCP라는 언어를 구사할 줄 아는 소프트웨어**이며, 보통 이메일, 캘린더 등 **하나의 애플리케이션을 담당**한다.
- AI를 시작할 때는 **연결할 MCP 서버 목록**을 지정해주고, AI는 그 서버들로부터 도구를 발견한 뒤 MCP로 대화하며 문제를 해결한다.

## 예시
```
AI 시작 시 연결 대상 MCP 서버 목록:
- Email MCP Server → send_email, get_last_10_emails, create_draft, label_email, delete_email ...
- Calendar MCP Server → check_availability, create_event, ...
- CRM MCP Server → lookup_contact, update_deal, ...
```
AI는 각 서버에 "list your tools"를 요청 → 통합 도구 목록 확보 → 문제 해결에 필요한 도구를 선택해 MCP로 호출.

## 요약
- MCP 서버는 AI가 실제로 대화하는 소프트웨어이며, **주로 애플리케이션 하나당 하나씩 존재**한다 (이메일 서버, 캘린더 서버 등).
- 대부분 벤더가 이미 MCP 서버를 운영 중이라 설정만 하면 되고, 온프레미스 시스템은 직접 구축해야 할 수도 있다.
- AI는 시작 시 연결된 모든 MCP 서버에 "도구 목록을 달라"고 요청해 통합 도구 목록을 만들고, 이를 바탕으로 문제를 해결하며 각 서버와 MCP로 소통한다.
