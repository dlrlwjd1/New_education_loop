# Try Out an Agent that Calls Python Functions

## 개요
- **Module 1의 Building Your First Agent (Part 1~3)**.md)에서 만든 에이전트를 직접 실행해보는 실습(Reading).

## 내용
- 노트북: https://colab.research.google.com/drive/1W3LEOFjAQs69PJ3rM1aYG8Cofo_de6XH?usp=sharing
- 노트북의 두 번째 코드 블록을 실행하면, 에이전트가 어떤 행동을 할지 입력하라는 프롬프트가 뜬다.
- 예: **"tell me the files in the current directory"**라고 입력하면 에이전트가 적절한 도구(tool)를 선택해 실행한다.
- **이 에이전트가 할 수 있는 것은 디렉토리의 파일 목록 조회와 파일 읽기뿐** — 그 범위 안에서 자유롭게 실험해보고 무엇이 되고 안 되는지 확인해볼 것.

## 요약
- Module 1에서 구현한 파일 목록/읽기 에이전트를 직접 실행하며, 한정된 도구 집합 안에서 에이전트가 어떻게 행동을 선택하는지 체감하는 핸즈온 실습.
