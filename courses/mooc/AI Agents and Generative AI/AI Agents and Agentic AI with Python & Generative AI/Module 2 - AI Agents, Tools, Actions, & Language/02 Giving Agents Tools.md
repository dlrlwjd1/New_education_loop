# Giving Agents Tools — 에이전트에게 도구(Tool)/행동(Action) 부여하기

## 개요
- 에이전트가 세상과 상호작용하는 방식은 **도구(tool) 또는 행동(action)**을 통해서다. 에이전트가 작업을 완수하기 위해 마음대로 아무 방법이나 "상상해내지" 않도록, **사용 가능한 도구의 범위를 명시적으로 제한**해야 하는 이유와 방법을 다루는 영상.

## 내용

### 왜 도구를 제한해야 하는가
- 예: 여행 계획을 짜달라고 했는데 "비행기를 타야 한다"고 말하면 곤란하다 — 우리가 원하는 교통수단이 아닐 수 있다. 따라서 **허용된 이동 수단이 무엇인지** 먼저 알려줘야 한다.
- 예: 인터넷 연결 문제를 파악할 때 "스크린샷을 찍어서 알려줘"를 허용할 수도, "그냥 나에게 물어봐서 보고받아라"로 제한할 수도 있다.
- 즉, 에이전트가 문제를 풀 때 **어떤 방법/자원을 쓸 수 있는지 경계(bound)를 정해줘야** 한다 — 실제 컴퓨터 시스템은 제한된 행동만 수행할 수 있는 rigid한 존재이기 때문.

### 예시 — 요리 에이전트에 도구 제한 부여
> "이것들이 너에게 주어진 유일한 도구다: 1쿼트 소테팬, 스킬릿, 대형 무쇠 스킬릿, 참나무로 피운 장작불. 너는 내가 요리하는 걸 도와줄 거야. 냄비를 직접 들거나 재료를 꺼낼 수 없으니, 단계를 알려주면 내가 수행할게. 한 번에 한 단계씩, 뭘 요리하고 싶은지 물어봐줘."

- 이는 "요리에 쓸 수 있는 모든 도구의 우주"가 아니라, **명시적으로 제한된 도구 집합**이다 — 인스턴트팟이나 전자레인지는 없다, 장작불·스킬릿·팬뿐.
- 에이전트는 **주어진 도구만으로 문제를 해결하는 방법을 찾아야** 한다.
- 실제 대화 흐름: "피자를 굽고 싶다" → "재료를 모아라" → "반죽을 준비해라" → "장작불을 준비해라" (주어진 도구 사용) → "무쇠 스킬릿을 불 위에 올려라" → ... 매 단계가 **허용된 도구 범위 안에서만** 진행된다.

### 왜 이것이 중요한가 — 실제 세계의 제약
- 현실에서는 무한한 자원으로 아무렇게나 문제를 풀 수 없다 — **한정된 자원/도구**로 풀어야 한다. Agentic AI도 마찬가지로 이 제약을 받아야 한다.
- "컴퓨터로 X를 하고 싶다"고 해서 세계 최고 슈퍼컴퓨터에 마음대로 접근할 수 있는 게 아니다 — **접근 권한이 없다.**
- 따라서 프롬프트 안에서 **어떤 도구를 쓸 수 있는지 제약을 명시**해야 하며, 이것이 실제 컴퓨터 시스템과 연동될 때 특히 중요해진다 (CRM 시스템, 이메일 시스템 등은 극히 제한된 행동만 지원하기 때문).

### "Tool"이라고 부를까, "Action"이라고 부를까?
- 엄격한 규칙은 없지만 대체로:
  - **컴퓨터 시스템과 인터페이스할 때는 "Action(행동)"으로 표현하는 것이 더 적합** — 시스템이 할 수 있는 일의 가짓수가 유한하므로 행동의 나열로 구체적으로 명시하는 편이 낫다. (비유: CPU가 수행할 수 있는 명령어 집합이 제한적인 것과 같음.)
  - **사람처럼 개방적인 대상과 인터페이스할 때는 "Tool(도구)"로 표현하는 것이 더 적합** — 사람은 하나의 도구로 다양한 행동을 유연하게 수행하고 적응할 수 있기 때문에, "이 도구로 이걸 해줘"라고만 해도 사람이 알아서 세부사항을 채울 수 있다.
- 상황과 목적에 따라 둘 중 무엇을 쓸지 선택하면 된다 — 다른 표현 방식도 있을 수 있지만, 이 둘이 가장 흔한 두 가지 접근법.

## 요약
- 에이전트가 임의로 문제를 해결하지 않도록, **사용 가능한 도구/행동의 범위를 명시적으로 제한**하는 것이 핵심 — 이것이 [01 GAIL](01%20GAIL%20-%20Goals%2C%20Actions%2C%20Information%2C%20Language.md)의 "A(Actions)"에 해당하는 부분을 구체화한 것.
- 실제 컴퓨터 시스템은 제한된 행동만 지원하므로, 에이전트의 자유도를 그 시스템이 실제로 지원하는 범위로 좁혀줘야 한다.
- 표현 방식: **컴퓨터 시스템 → Action(구체적 행동 나열)**, **사람 → Tool(유연하게 해석 가능한 도구)**로 구분해서 생각하면 도움이 된다.
