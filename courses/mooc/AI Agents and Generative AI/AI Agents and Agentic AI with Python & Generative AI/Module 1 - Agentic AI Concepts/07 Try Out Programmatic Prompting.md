# Try Out Programmatic Prompting

## 개요
- [06 Programmatic Prompting for Agents](06%20Programmatic%20Prompting%20for%20Agents.md)에서 배운 코드를 직접 실행해보는 실습(Reading) 자료. Google Colab 노트북으로 진행.

## 내용
- 노트북: https://colab.research.google.com/drive/10USwjwaJ-1J-I_2igKIbJ-GdMDWlHKRU?usp=sharing

### 할 일 (What you'll do)
- 제공된 Google Colab 노트북을 열고 실행해보기
- LLM과 상호작용하는 예제 코드 검토
- 입력(`messages`)이 모델에 어떻게 전달되는지 관찰
- 응답이 어떻게 생성되고 출력되는지 확인
- 원한다면 노트북을 조금씩 수정해보며 탐색

### 집중해서 볼 포인트 (Suggested focus)
- `messages` 입력이 어떤 구조로 되어 있는지
- 코드에서 모델을 어떻게 호출하는지
- 응답이 어떻게 반환되고 출력되는지

### 팁
- 노트북이 보기 전용(view-only)으로 열리면 **"Copy to Drive"**를 클릭해 내 드라이브에 복사한 뒤 직접 수정/실행한다.

## 요약
- 이론(06)에서 배운 `litellm.completion()` 기반 프롬프트 전송 코드를 실제로 Colab에서 실행해보며 `messages` 구조, 모델 호출 방식, 응답 처리 흐름을 직접 확인하는 핸즈온 실습.
