# AI Agents and Agentic AI with Python & Generative AI

**Course URL:** [mooc.org/learn/ai-agents-python](https://www.mooc.org/learn/ai-agents-python)

Vanderbilt University (Jules White) 강좌. **AI Agents and Agentic AI in Python: Powered by Generative AI** 스페셜라이제이션의 1번째 강좌 — 다음 강좌는 **[AI Agents and Agentic AI Architecture in Python](../AI%20Agents%20and%20Agentic%20AI%20Architecture%20in%20Python/README.md)**. Programmatic Prompting과 Agent Loop 같은 기초 개념부터 GAME 프레임워크로 재사용 가능한 에이전트를 구축하는 법까지 5개 모듈로 구성.

## 모듈 구성
- [Module 1 - Agentic AI Concepts](Module%201%20-%20Agentic%20AI%20Concepts/README.md) — Agentic AI 개념, Flipped Interaction Pattern, Agent Loop(6단계) 이론과 Python 구현
- [Module 2 - AI Agents, Tools, Actions, & Language](Module%202%20-%20AI%20Agents%2C%20Tools%2C%20Actions%2C%20%26%20Language/README.md) — GAIL 프레임워크, 도구/행동 설계, Function Calling API
- [Module 3 - GAME - A Conceptual Framework for AI Agents](Module%203%20-%20GAME%20-%20A%20Conceptual%20Framework%20for%20AI%20Agents/README.md) — GAME(Goals/Actions/Memory/Environment) + AgentLanguage로 재사용 가능한 에이전트 프레임워크 구축
- [Module 4 - Agent Tool Management](Module%204%20-%20Agent%20Tool%20Management/README.md) — `@register_tool` 데코레이터와 태그로 도구를 자동 동기화하고 조직화
- [Module 5 - Rethinking How Software is Built in the Age of AI Agents](Module%205%20-%20Rethinking%20How%20Software%20is%20Built%20in%20the%20Age%20of%20AI%20Agents/README.md) — 불가능했던 문제 해결, 환각(hallucination)의 재해석, 데이터 접근 방식의 재정의
