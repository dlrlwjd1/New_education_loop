# BeeAI -  Introduction and Core Components

> MOOC video · [원본 학습 항목](https://www.mooc.org/learn/agentic-ai-with-langgraph-crewai-autogen-and-beeai/lecture/ALXAS/beeai-introduction-and-core-components)

## 개요
- BeeAI 프레임워크의 CORE 기능을 이해할 수 있습니다 BeeAI가 Python의 async 및 await 구문을 사용하는 이유를 설명할 수 있습니다 BeeAI를 사용하여 프롬프트 템플릿과 구조화된 출력을 생성할 수 있습니다 BeeAI 프레임워크의 기본적인 메모리 관리 개념을 이해할 수 있습니다 BeeAI는 실제 운영 환경에 바로 적용 가능한 AI 에이전트 및 다중 에이전트 시스템을 구축하기 위한 최첨단 오픈소스 플랫폼입니다.

## 내용
- BeeAI 프레임워크의 CORE 기능을 이해할 수 있습니다 BeeAI가 Python의 async 및 await 구문을 사용하는 이유를 설명할 수 있습니다 BeeAI를 사용하여 프롬프트 템플릿과 구조화된 출력을 생성할 수 있습니다 BeeAI 프레임워크의 기본적인 메모리 관리 개념을 이해할 수 있습니다 BeeAI는 실제 운영 환경에 바로 적용 가능한 AI 에이전트 및 다중 에이전트 시스템을 구축하기 위한 최첨단 오픈소스 플랫폼입니다.
- 내장된 캐싱, 메모리 최적화, 리소스 관리, 개방형 텔레메트리 통합을 포함하는 프로덕션 준비 완료 아키텍처 OpenAI, WatsonX.ai, Grok, Olama 등을 포함한 OpenAI, WatsonX.ai, Grok, Olama 등 10개 이상의 LLM 제공업체를 지원하는, 제공업체에 구애받지 않는 백엔드 React, Reasoning and Acting, 체계적 사고, 다중 에이전트 조정과 같은 검증된 패턴을 구현합니다.
- 이 예제에서는 WatsonX.ai의 IBM Granite 모델을 사용하겠지만, BeeAI는 Anthropic 및 OpenAI를 포함한 다양한 제공업체의 기초 모델을 사용할 수 있을 만큼 유연합니다.다음으로, 시스템 지침을 인스턴스로 전달하여 대화 메시지를 정의합니다.
- 마지막으로, async 및 await 함수 내에서 LLM 객체의 create 메서드를 호출하여 async 및 await 함수 내에서 Await를 사용하여 모델을 비동기적으로 실행합니다.
- 동적 프롬프트 템플릿을 사용하면 가변 데이터를 포함한 재사용 가능한 프롬프트를 생성할 수 있으며, 이는 이는 여러 유사한 요청 전반에 걸쳐 일관성을 유지하는 데 필수적입니다.
- 이렇게 하면 모든 프로젝트가 LLM으로 전송되기 전에 동일한 형식으로 정리되어 LLM으로 전송되기 전에 모든 프로젝트가 동일한 형식으로 구성되도록 보장하여, 서로 다른 프로젝트에 서로 다른 형식을 사용할 때 발생할 수 있는 편향을 줄이는 데 도움이 됩니다.
- 또한 AI 에이전트 개발에 BeeAI 프레임워크를 사용할 때의 주요 이점은 모듈성, 구조화된 출력, 비동기 실행, 다중 에이전트 지원, 표준 준수 및 가시성입니다.

## 예시
- 이는 서로 다른 프로젝트에 걸쳐 일관된 분석이 필요한 데이터 과학 프로젝트 평가와 같은 시나리오에 이상적입니다.
