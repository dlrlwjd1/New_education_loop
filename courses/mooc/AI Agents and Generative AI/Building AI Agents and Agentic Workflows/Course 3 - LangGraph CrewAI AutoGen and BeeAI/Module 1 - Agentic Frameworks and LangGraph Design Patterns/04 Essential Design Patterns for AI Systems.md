# Essential Design Patterns for AI Systems

> MOOC video · [원본 학습 항목](https://www.mooc.org/learn/agentic-ai-with-langgraph-crewai-autogen-and-beeai/lecture/IbAjJ/essential-design-patterns-for-ai-systems)

## 개요
- 이 영상에서는 세 가지 CORE LLM 워크플로우 패턴, 즉 순차적 처리, 프롬프트 연쇄, 라우팅, 병렬화 등 세 가지 핵심 LLM 워크플로우 패턴을 살펴보게 됩니다.

## 내용
- 이 영상에서는 세 가지 CORE LLM 워크플로우 패턴, 즉 순차적 처리, 프롬프트 연쇄, 라우팅, 병렬화 등 세 가지 핵심 LLM 워크플로우 패턴을 살펴보게 됩니다.
- 체인 상태 객체를 생성하고, 이 표를 참고하여 상태 변수가 그래프를 따라 어떻게 진행되는지 이해해 봅시다 이 표를 참조하여 상태 변수가 그래프를 통해 어떻게 진행되는지 이해하세요.
- 마지막으로, 체인 상태를 입력으로 사용하여 워크플로 그래프를 생성하고, ‘이력서 요약 생성’ 노드를 추가하고, 자기소개서 노드를 추가한 다음, 이들을 순차적으로 연결합니다.
- 직무 설명 입력 상태를 완성하고, 워크플로를 실행한 다음, 직무 설명이 기입된 표 형식으로 상태 변수를 표시합니다 을 직무 설명이 채워진 표 형태로 표시합니다.
- 사용자 입력이 메시지에 추가되고, LLM이 호출되며, 번역 또는 요약 중 하나인 도구 호출 출력이 추출되어 '번역' 또는 '요약' 중 하나가 추출되어 task_underscore_type으로 전달됩니다.
- 라우터 노드를 추가하고, 요약 노드를 추가하고, 번역 노드를 추가한 다음, 라우터 밑줄 노드를 진입점으로 설정합니다.
- 원본 영어 입력을 위한 텍스트 필드와 각 번역에 대한 언어 필드가 포함된 상태 컨테이너를 정의하고 및 번역 결과를 병합하기 위한 결합된 언더스코어(_) 출력 필드가 포함된 상태 컨테이너를 정의합니다.

## 예시
- 원본 영어 입력을 위한 텍스트 필드와 각 번역에 대한 언어 필드가 포함된 상태 컨테이너를 정의하고 및 번역 결과를 병합하기 위한 결합된 언더스코어(_) 출력 필드가 포함된 상태 컨테이너를 정의합니다.

## 요약
- 라우터 노드를 추가하고, 요약 노드를 추가하고, 번역 노드를 추가한 다음, 라우터 밑줄 노드를 진입점으로 설정합니다. 원본 영어 입력을 위한 텍스트 필드와 각 번역에 대한 언어 필드가 포함된 상태 컨테이너를 정의하고 및 번역 결과를 병합하기 위한 결합된 언더스코어(_) 출력 필드가 포함된 상태 컨테이너를 정의합니다.
