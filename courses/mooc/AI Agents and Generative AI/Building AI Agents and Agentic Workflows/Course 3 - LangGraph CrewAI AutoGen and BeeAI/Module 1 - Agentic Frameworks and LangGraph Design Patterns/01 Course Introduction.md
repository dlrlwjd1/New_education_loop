# Course Introduction

> MOOC video · [원본 학습 항목](https://www.mooc.org/learn/agentic-ai-with-langgraph-crewai-autogen-and-beeai/lecture/GFNnj/course-introduction)

## 개요
- 이 과정에서는 LangGraph, CrewAI, BeeAI, AG2 또는 Autogen을 비롯한 주요 프레임워크를 다룰 것입니다.

## 내용
- 이 과정에서는 LangGraph, CrewAI, BeeAI, AG2 또는 Autogen을 비롯한 주요 프레임워크를 다룰 것입니다.
- CORE 설계 패턴, 오케스트레이터 워크플로우, 다중 에이전트 조정 및 고급 통합에 대해 배우게 됩니다.
- 이 실습 중심 과정은 소프트웨어 엔지니어, 데이터 과학자, 머신러닝 엔지니어, AI 아키텍트, 자동화 엔지니어 또는 관련 분야에 종사하는 분들을 위해 마련되었습니다.
- 에이전트 기반 AI의 기초를 탐구하고, 선도적인 오픈소스 프레임워크를 활용해 에이전트를 구축하는 방법을 배우게 됩니다.
- 먼저 에이전트 워크플로를 처음부터 구축한 다음, YAML과 CrewBase를 활용하여 구성 및 통합을 수행하면서 Pydantic을 사용하여 구조화된 출력을 생성하는 방법을 배우게 됩니다.
- 사용자 정의 도구를 사용하여 CrewAI를 확장하는 방법을 탐구하고, 도구를 사용하는 에이전트와 도구를 사용하는 작업 간의 차이점을 이해하게 됩니다.
- 이 과정을 최대한 활용하려면 동영상을 시청하고, 각 읽기 자료를 꼼꼼히 살펴보며, 치트 시트를 참고하고, 연습 퀴즈를 통해 이해도를 확인하며, 실습 과제를 수행하고, 채점 평가로 지식을 점검해 보시기 바랍니다.

## 예시
- 이 실습 중심 과정은 소프트웨어 엔지니어, 데이터 과학자, 머신러닝 엔지니어, AI 아키텍트, 자동화 엔지니어 또는 관련 분야에 종사하는 분들을 위해 마련되었습니다.

## 요약
- 사용자 정의 도구를 사용하여 CrewAI를 확장하는 방법을 탐구하고, 도구를 사용하는 에이전트와 도구를 사용하는 작업 간의 차이점을 이해하게 됩니다. 이 과정을 최대한 활용하려면 동영상을 시청하고, 각 읽기 자료를 꼼꼼히 살펴보며, 치트 시트를 참고하고, 연습 퀴즈를 통해 이해도를 확인하며, 실습 과제를 수행하고, 채점 평가로 지식을 점검해 보시기 바랍니다.
