# Course Wrap-up

> MOOC video · [원본 학습 항목](https://www.mooc.org/learn/agentic-ai-with-langchain-and-langgraph/lecture/wBot1/course-wrap-up)

## 개요
- 반면, 에이전트형 AI는 능동적이며 프롬프트를 사용하여 의사 결정, 실행, 학습의 순환 과정을 통해 목표를 추구합니다.

## 내용
- 반면, 에이전트형 AI는 능동적이며 프롬프트를 사용하여 의사 결정, 실행, 학습의 순환 과정을 통해 목표를 추구합니다.
- LangGraph는 루핑, 분기, 상태 지속성 및 인간 개입(human-in-the-loop) 기능을 지원하므로 복잡하고 적응력이 뛰어난 에이전트를 구축하는 데 이상적입니다.
- LangChain은 개발자가 프롬프트, 메모리, 도구와 같은 모듈형 구성 요소를 사용하여 LLM 기반 애플리케이션을 구축할 수 있도록 지원합니다.
- 반면 LangGraph는 노드와 에지로 구성된 그래프를 통해 상태 기반 다중 에이전트 워크플로우를 구현함으로써 LangChain의 기능을 확장합니다.
- LangGraph의 메시지 그래프는 메시지 흐름을 추적하고, ‘인간 메시지’ 및 ‘AI 메시지’와 같은 메시지 유형을 사용하여 턴 전반에 걸쳐 에이전트의 상태를 정의합니다.
- 이 에이전트의 구조화된 응답 흐름은 ‘사고(Thought)’, ‘행동(Action)’, ‘행동 입력(Action Input)’, ‘관찰(Observation)’, ‘최종 답변(Final Answer)’ 순으로 이루어집니다.
- 이 과정이 포함된 전문 수료증 프로그램에 아직 등록하지 않으셨다면 포함된 이 과정을 아직 등록하지 않으셨다면, 등록하시기를 권장합니다.
