# Agentic RAG - Enhance Retrieval with Multi-Agent Systems

> MOOC video · [원본 학습 항목](https://www.mooc.org/learn/agentic-ai-with-langchain-and-langgraph/lecture/3yGeH/agentic-rag-enhance-retrieval-with-multi-agent-systems)

## 개요
- 검색 강화 생성(Retrieval Augmented Generation)은 대규모 언어 모델의 응답 품질을 향상시키는 대규모 언어 모델의 응답 품질을 향상시킵니다.

## 내용
- 검색 강화 생성(Retrieval Augmented Generation)은 대규모 언어 모델의 응답 품질을 향상시키는 대규모 언어 모델의 응답 품질을 향상시킵니다.
- 예를 들어, 여러 데이터베이스가 있을 때 어떤 벡터 데이터베이스를 쿼리할지 결정하거나, 혹은 어떤 형식의 응답을 제공해야 할지 결정하는 것과 같은 텍스트로 답변해야 할까요, 차트를 생성해야 할까요, 아니면 코드 스니펫을 제공해야 할까요?
- 그렇다면 LLM이 쿼리와 가장 관련성이 높은 데이터를 포함하는 벡터 데이터베이스를 이 쿼리와 가장 관련성이 높은 데이터를 포함하고 있는 벡터 데이터베이스를 사용하도록 할 수 있을까요?
- 따라서 직원이 다음과 같이 질문하면, "휴일 동안의 재택근무에 대한 회사 정책은 무엇입니까?" 이 에이전트는 해당 질문을 내부 문서로 연결해 줄 것입니다.
- 하지만 질문이 다음과 같이 더 일반적인 경우, "기술 기업에서 원격 근무에 대한 업계 표준은 무엇인가요?" 에이전트는 해당 질문을 일반 지식 데이터베이스로 연결할 것입니다.
- 예를 들어, 변호사는 내부 브리핑 자료를 바탕으로 내부 브리핑에서 답변을 찾아내고, 그리고 다른 쿼리에서는 공개된 사건 데이터베이스에서 정보를 가져올 수도 있습니다.
- 에이전트가 최적의 데이터 소스를 선택하고 심지어 실시간 데이터나 제3자 서비스와 같은 실시간 데이터나 제3자 서비스와 같은 정보를 통합할 수 있게 함으로써, 우리는 반응성이 더 뛰어나고, 정확성이 높고, 적응력이 뛰어난 파이프라인을 구축할 수 있습니다.

## 예시
- 예를 들어, 여러 데이터베이스가 있을 때 어떤 벡터 데이터베이스를 쿼리할지 결정하거나, 혹은 어떤 형식의 응답을 제공해야 할지 결정하는 것과 같은 텍스트로 답변해야 할까요, 차트를 생성해야 할까요, 아니면 코드 스니펫을 제공해야 할까요?

## 요약
- 예를 들어, 변호사는 내부 브리핑 자료를 바탕으로 내부 브리핑에서 답변을 찾아내고, 그리고 다른 쿼리에서는 공개된 사건 데이터베이스에서 정보를 가져올 수도 있습니다. 에이전트가 최적의 데이터 소스를 선택하고 심지어 실시간 데이터나 제3자 서비스와 같은 실시간 데이터나 제3자 서비스와 같은 정보를 통합할 수 있게 함으로써, 우리는 반응성이 더 뛰어나고, 정확성이 높고, 적응력이 뛰어난 파이프라인을 구축할 수 있습니다.
