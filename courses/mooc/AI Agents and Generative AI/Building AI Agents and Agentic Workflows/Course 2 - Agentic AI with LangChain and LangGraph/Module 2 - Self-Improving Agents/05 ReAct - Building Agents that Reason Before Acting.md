# ReAct - Building Agents that Reason Before Acting

> MOOC video · [원본 학습 항목](https://www.mooc.org/learn/agentic-ai-with-langchain-and-langgraph/lecture/Ubd1Y/react-building-agents-that-reason-before-acting)

## 개요
- 마지막으로, 에이전트가 도구 호출을 통해 어떻게 추론을 수행하여 최종 응답을 생성하는지 분석하게 됩니다.

## 내용
- 마지막으로, 에이전트가 도구 호출을 통해 어떻게 추론을 수행하여 최종 응답을 생성하는지 분석하게 됩니다.
- "당신은 단계별로 사고하고 필요할 때 도구를 사용하는 유용한 AI 어시스턴트입니다." 또한 LLM이 다음과 같은 방식으로 응답하도록 프롬프트를 줄 수도 있습니다.
- LLM은 도구를 사용하여 환경(이 경우 현재 날씨)를 얻어야 하며, 의류 추천 도구를 사용하여 어떤 옷이 있는지 확인해야 합니다.
- 문서 설명에 나와 있듯이, LLM의 응답에 포함된 키워드(예: '비'나 '젖음' 등)를 분석하여 ‘rain’이나 ‘wet’과 같은 키워드를 분석하여 docstring에 설명된 대로 적절한 의류를 추천하는 ‘recommend_clothing’ 도구를 만듭니다.
- 에이전트 상태 객체는 ‘messages’를 키로 하고, 대화 중에 교환된 모든 메시지를 저장하는 대화에서 교환된 모든 메시지를 저장하는 리스트입니다.
- 에이전트에게 단계별로 응답하고 필요할 때 도구를 사용하도록 지시하는 시스템 메시지를 정의합니다 사용하도록 지시하는 시스템 메시지를 정의합니다.
- React 에이전트는 단계별 추론을 수행하고 도구를 사용하여 복잡한 쿼리에 답한다는 사실을 배웠습니다.
