# Understanding Reflexion Agents

> MOOC video · [원본 학습 항목](https://www.mooc.org/learn/agentic-ai-with-langchain-and-langgraph/lecture/SPJOd/understanding-reflexion-agents)

## 개요
- 이 영상에서는 리플렉션 에이전트가 반복적인 자기 비판과 도구 활용을 통해 반복적인 자기 비판과 도구 활용을 통해 AI 응답을 어떻게 개선하는지 분석해 보겠습니다.

## 내용
- 이 영상에서는 리플렉션 에이전트가 반복적인 자기 비판과 도구 활용을 통해 반복적인 자기 비판과 도구 활용을 통해 AI 응답을 어떻게 개선하는지 분석해 보겠습니다.
- Reflexion 워크플로우 내에서 생성자(generator)와 반성자(reflector) 역할을 적용하고, 외부 도구를 활용해 실시간 정보를 통합하고, 투명성을 높이기 위해 인용 및 참고 문헌을 포함하여 결과물을 구성하는 방법을 배우게 됩니다.
- Reflexion 에이전트는 리플렉션 에이전트의 개념을 기반으로 하며, 반성 에이전트는 출력을 반복적으로 검토하고 다듬는 개념을 기반으로 합니다.
- “식단에서 미네랄 섭취량을 늘리려면 시금치(철분 및 마그네슘), 아몬드(마그네슘), 유제품(칼슘)과 같은 음식을 섭취해 보세요." 하지만 모델 훈련이 끝난 후에 새로운 연구 결과가 나온다면 어떻게 될까요?
- Reflexion 에이전트는 반성 에이전트를 기반으로 하여, 자기 비판, 외부 도구 및 인용을 활용하여 응답을 반복적으로 개선함으로써 리플렉션 에이전트가 발전합니다.
- 또한 웹 검색 API와 같은 외부 도구를 호출하여 실시간 데이터를 반영함으로써 웹 검색 API와 같은 외부 도구를 호출하여 응답의 관련성을 높일 수 있습니다.
- 응답 생성기는 쿼리 및 응답과 같은 필드를 포함한 출력을 생성하며, 이를 바탕으로 수정자 같은 후속 구성 요소가 작업을 이어갈 수 있습니다.

## 예시
- 예를 들어, “당신은 피트니스 Coach입니다.” LLM에게 자신의 출력 결과를 평가하도록 지시합니다.

## 요약
- 또한 웹 검색 API와 같은 외부 도구를 호출하여 실시간 데이터를 반영함으로써 웹 검색 API와 같은 외부 도구를 호출하여 응답의 관련성을 높일 수 있습니다. 응답 생성기는 쿼리 및 응답과 같은 필드를 포함한 출력을 생성하며, 이를 바탕으로 수정자 같은 후속 구성 요소가 작업을 이어갈 수 있습니다.
