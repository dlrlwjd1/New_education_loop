# Getting Started with LangGraph 101

> MOOC video · [원본 학습 항목](https://www.mooc.org/learn/agentic-ai-with-langchain-and-langgraph/lecture/Vh0uD/getting-started-with-langgraph-101)

## 개요
- 상태는 일반적으로 TypedDict로 정의되지만, 리스트, 중첩된 구조, 또는 메시지 시퀀스 형태일 수도 있으며, 모든 그래프 입력, 중간 값 및 출력을 포함할 수 있습니다.

## 내용
- 상태는 일반적으로 TypedDict로 정의되지만, 리스트, 중첩된 구조, 또는 메시지 시퀀스 형태일 수도 있으며, 모든 그래프 입력, 중간 값 및 출력을 포함할 수 있습니다.
- LangGraph에서는 TypedDict 클래스를 사용하여 'n' 및 'letter'와 같은 상태 변수를 정의할 수 있습니다.
- 첫 번째 단계는 체인 상태 클래스를 사용하여 상태 그래프 객체를 생성하는 것입니다.
- 이 함수는 print라는 이름의 노드에서 입력 상태를 받아 라는 노드에서 입력 상태를 받아 그래프의 흐름을 결정하는 부울 값을 반환합니다.
- 또는 상태에 따라 조건부 노드가 다음 노드 이름을 직접 반환하도록 설계할 수도 있습니다 'n'이 print 노드에서 반환된 값보다 13보다 크면 end로 반환하고, end를 반환합니다.
- LangGraph의 'State'는 모든 입력, 중간 값, 출력을 모두 포함하는 복잡하고 지속적으로 변화하는 메모리라는 점을 배웠습니다.노드는 현재 상태를 처리하는 함수입니다.
- LangGraph 애플리케이션을 실행하려면 상태 그래프 객체를 생성하고, 노드를 포함시키며, 이들을 연결하고, 진입점을 설정한 다음, 그래프를 실행 가능한 애플리케이션으로 컴파일하는 과정을 포함합니다.

## 예시
- 예를 들어, 'n'이 13보다 크거나 같은지 확인하고 true 또는 false를 반환하는 경우를 들 수 있습니다.

## 요약
- LangGraph의 'State'는 모든 입력, 중간 값, 출력을 모두 포함하는 복잡하고 지속적으로 변화하는 메모리라는 점을 배웠습니다.노드는 현재 상태를 처리하는 함수입니다. LangGraph 애플리케이션을 실행하려면 상태 그래프 객체를 생성하고, 노드를 포함시키며, 이들을 연결하고, 진입점을 설정한 다음, 그래프를 실행 가능한 애플리케이션으로 컴파일하는 과정을 포함합니다.
