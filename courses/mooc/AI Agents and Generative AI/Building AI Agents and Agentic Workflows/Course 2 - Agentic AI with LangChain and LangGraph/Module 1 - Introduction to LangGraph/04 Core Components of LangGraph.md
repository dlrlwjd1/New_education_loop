# Core Components of LangGraph

> MOOC video · [원본 학습 항목](https://www.mooc.org/learn/agentic-ai-with-langchain-and-langgraph/lecture/ius5N/core-components-of-langgraph)

## 개요
- 이 영상에서는 LangGraph가 에이전트 워크플로우를 유연한 그래프로 모델링하는 방법을 알아보고, 노드, 에지, 상태의 CORE 역할을 이해하게 될 것입니다.

## 내용
- 이 영상에서는 LangGraph가 에이전트 워크플로우를 유연한 그래프로 모델링하는 방법을 알아보고, 노드, 에지, 상태의 CORE 역할을 이해하게 될 것입니다.
- 단순하고 반복적인 작업에는 효과적이지만, 복잡한 상태 기반 워크플로우에 필요한 유연성은 복잡한 상태 기반 워크플로우에 필요한 유연성이 크게 부족합니다.
- 반면 LangGraph는 명시적인 상태 관리 기능을 제공하여, 워크플로가 서로 다른 노드 간에 컨텍스트를 유지하고 수정할 수 있게 해줍니다.
- 반면 LangGraph 워크플로는 분기, 반복, 사용자 입력을 위한 일시 정지, 실행 재개까지 모두 수행할 수 있으며, 이 모든 과정에서 대화 내역을 완벽하게 기억합니다.
- LangGraph의 독특한 기능으로는 동적인 의사 결정을 내리기 위한 루프 및 분기, 장기간의 상호작용 동안 컨텍스트를 유지하기 위한 상태 지속성, 를 통해 적시에 사람이 개입할 수 있도록 하며, 편리한 디버깅을 돕는 ‘타임 트래블’ 기능이 있습니다.
- LangGraph는 상태 관리 기능을 제공하여 워크플로가 서로 다른 노드 간에 컨텍스트를 유지하고 수정할 수 있도록 합니다.
- LangGraph 워크플로는 대화 내역을 완전히 보존한 상태에서 분기, 반복, 사용자 입력을 위한 일시 중지 및 실행 재개를 모두 동시에 대화 내역을 완전히 보존할 수 있습니다.

## 예시
