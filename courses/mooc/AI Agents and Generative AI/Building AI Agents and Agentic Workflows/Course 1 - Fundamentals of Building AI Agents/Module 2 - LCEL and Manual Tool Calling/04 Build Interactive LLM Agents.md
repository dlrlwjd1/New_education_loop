## 개요
- 또한, 더 스마트하고 문맥을 고려한 응답을 제공하기 위해 도구 호출 프로세스 전체를 관리하는 에이전트 클래스를 구축하는 방법을 더 스마트하고 문맥을 고려한 응답을 제공하는 에이전트 클래스를 구축하는 방법을 배우게 됩니다.

## 내용
- 또한, 더 스마트하고 문맥을 고려한 응답을 제공하기 위해 도구 호출 프로세스 전체를 관리하는 에이전트 클래스를 구축하는 방법을 더 스마트하고 문맥을 고려한 응답을 제공하는 에이전트 클래스를 구축하는 방법을 배우게 됩니다.
- "3 더하기 2는 얼마인가요?" 먼저, 사용자의 질문을 채팅 기록에 삽입하여 모델이 이를 대화 맥락의 일부로 인식할 수 있도록 하세요.
- HumanMessage는 "이 텍스트는 사용자가 입력한 것입니다." 이 객체는 사용자의 입력을 담고 있으며, 대화 중에 모델이 이를 적절히 인식할 수 있도록 표시합니다.
- 이 리스트에는 사용자 입력, 도구 출력, 모델 응답을 포함하여 대화 중에 주고받은 모든 메시지를 저장하며, 이를 통해 모델이 매 단계마다 완전한 맥락을 확보할 수 있도록 보장합니다 단계에서 모델이 완전한 맥락을 파악할 수 있도록 보장합니다.
- 이 비디오에서는 채팅 기록에 쿼리를 추가하여 실시간이며 문맥을 인식하는 대화를 위해 채팅 기록에 쿼리를 추가하는 방법을 배웠습니다.
- 복잡한 도구 지침을 분석하고, 여러 도구 호출을 처리하며 응답을 연결하여 매끄러운 실행을 위한 응답 연결을 포함하여 복잡한 도구 지침을 분석합니다.
- 전체 도구 호출 프로세스를 자동화하기 위해 에이전트 클래스를 구축하고 개선하여, LLM이 반응성이 뛰어난 다단계 에이전트 역할을 수행할 수 있도록 합니다.

- 예를 들어, "A는 3이고 B는 2입니다." 다음은 이 도구 호출에 대한 고유 식별자입니다.

- 복잡한 도구 지침을 분석하고, 여러 도구 호출을 처리하며 응답을 연결하여 매끄러운 실행을 위한 응답 연결을 포함하여 복잡한 도구 지침을 분석합니다. 전체 도구 호출 프로세스를 자동화하기 위해 에이전트 클래스를 구축하고 개선하여, LLM이 반응성이 뛰어난 다단계 에이전트 역할을 수행할 수 있도록 합니다.
