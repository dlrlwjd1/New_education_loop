## 개요
- 그 다음, LLM에 사용자 정의 도구를 정의하고 바인딩한 LLM에 바인딩하고, 기능을 확장하기 위해 더 많은 도구를 추가하게 됩니다.

## 내용
- 그 다음, LLM에 사용자 정의 도구를 정의하고 바인딩한 LLM에 바인딩하고, 기능을 확장하기 위해 더 많은 도구를 추가하게 됩니다.
- 먼저, 덧셈, 뺄셈, 곱셈을 위한 도구를 사용하여 간단한 산술 연산을 수행할 수 있는 에이전트를 구축해 보겠습니다 이 경우, LLM을 사용하여 일련의 도구에 접근할 수 있도록 할 것입니다.
- 다음으로, 모델 제공자를 ‘_’로 지정하여 GPT 4.0 mini를 로드하고 equals openAI를 사용하여 GPT 4.0 mini를 로드하고, 메시지를 주고받을 수 있는 객체를 생성합니다.
- 다이어그램에서 LLM 상자는 모든 도구 호출과 사용자 질의의 중심 허브인 이 LLM 객체를 나타내며, 이는 모든 도구 호출과 사용자 쿼리의 중심 허브 역할을 합니다.
- 이는 LangChain에 해당 함수가 다음으로, 두 정수 a와 b를 인수로 받아 두 정수 a와 b를 인수로 받아 그 합을 반환하는 add라는 함수를 정의합니다.
- 이를 위해 먼저 도구 이름을 문자열로 지정하여 도구 이름을 문자열로, 해당 도구 함수와 연결하는 매핑 사전(dictionary)을 생성합니다.
- 그런 다음, 매핑 사전에서 함수에 접근하기 위해 도구 (예: add)를 키로 사용하여 매핑 사전에서 함수에 접근함으로써 함수를 호출합니다.

## 예시
- 예를 들어, 입력 쿼리가 “3 더하기 2는 얼마인가요?”라면, LLM은 먼저 3과 2라는 매개변수를 추출한 후, 어떤 도구를 호출할지 결정합니다.
