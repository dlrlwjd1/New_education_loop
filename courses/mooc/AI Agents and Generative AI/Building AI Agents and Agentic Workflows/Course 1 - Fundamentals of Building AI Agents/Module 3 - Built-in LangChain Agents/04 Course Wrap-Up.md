# Course Wrap-Up

> MOOC video · [원본 학습 항목](https://www.mooc.org/learn/fundamentals-of-building-ai-agents/lecture/wd1ca/course-wrap-up)

## 개요
- 내장된 도구 호출 기능은 전용 라이브러리나 프레임워크 내에서 도구 처리를 중앙 집중화함으로써 전용 라이브러리나 프레임워크 내에서 도구 처리를 중앙 집중화함으로써 오류가 발생하기 쉬운 클라이언트 측 구현 방식을 대체함으로써 오류를 줄입니다.

## 내용
- 내장된 도구 호출 기능은 전용 라이브러리나 프레임워크 내에서 도구 처리를 중앙 집중화함으로써 전용 라이브러리나 프레임워크 내에서 도구 처리를 중앙 집중화함으로써 오류가 발생하기 쉬운 클라이언트 측 구현 방식을 대체함으로써 오류를 줄입니다.
- 도구는 LLM이 올바른 함수를 선택할 수 있도록 돕는데, 이를 위해 함수의 목적을 간략히 설명하고, 예상 출력을 정의하고, 필요한 입력 및 출력 형식을 표시함으로써 LLM이 올바른 기능을 선택하도록 돕습니다.
- 에이전트는 도구를 선택하고, 도구를 호출하며, 결과 답변을 검토하고, 결과를 프로세스에 반영하며, LLM과 도구가 최종 응답을 생성할 때까지 필요에 따라 이 과정을 반복하는단계별 추론 루프를 선택합니다.
- LangChain에서 에이전트를 구축할 때는 도구 사용 및 복잡한 추론을 지원하며, JSON으로 직렬화 가능한 입력 및 출력을 가진 도구를 사용하는 LLM을 선택하고, 을 선택해야 합니다.
- 덧셈, 뺄셈, 곱셈, 나눗셈 도구 등을 사용자 정의 수학 도구 모음으로 묶을 수 있으며, 에이전트는 이를 사용하여 계산을 수행하고 .invoke 메서드를 사용하여 채팅 상호작용을 시뮬레이션하고, 에이전트에게 메시지를 보내며, 구조화된 응답을 받을 수 있습니다.
- AI 기반 SQL 에이전트를 사용하면 더 폭넓은 사용자가 깊은 기술적 전문 지식 없이도 깊은 기술적 전문 지식 없이도 더 다양한 사용자가 데이터에 접근하고 해석할 수 있게 해줍니다.
- 환경 준비가 완료되면 LangChain의 SQL 에이전트를 사용하여 자연어 쿼리를 실행할 수 있으며, 이 에이전트는 쿼리를 SQL로 변환하여 데이터베이스에서 결과를 가져옵니다.

## 예시
- 에이전트 사용을 시작할 때 모범 사례를 검토하지 않고서는 어떤 리뷰도 완전할 수 없습니다.

## 요약
- AI 기반 SQL 에이전트를 사용하면 더 폭넓은 사용자가 깊은 기술적 전문 지식 없이도 깊은 기술적 전문 지식 없이도 더 다양한 사용자가 데이터에 접근하고 해석할 수 있게 해줍니다. 환경 준비가 완료되면 LangChain의 SQL 에이전트를 사용하여 자연어 쿼리를 실행할 수 있으며, 이 에이전트는 쿼리를 SQL로 변환하여 데이터베이스에서 결과를 가져옵니다.
