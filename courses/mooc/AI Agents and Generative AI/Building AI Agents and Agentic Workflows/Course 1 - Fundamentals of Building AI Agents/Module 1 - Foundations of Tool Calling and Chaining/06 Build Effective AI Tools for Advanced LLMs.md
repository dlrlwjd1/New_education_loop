# Build Effective AI Tools for Advanced LLMs

> MOOC video · [원본 학습 항목](https://www.mooc.org/learn/fundamentals-of-building-ai-agents/lecture/qsVBv/build-effective-ai-tools-for-advanced-llms)

## 개요
- 이 영상에서는 복잡한 입력과 출력을 가진 구조화된 도구를 정의하는 방법, 실시간 의사 결정을 위한 에이전트를 설정하는 방법, 그리고 동적 도구 통합을 위해 다양한 대규모 언어 모델이나 LLM을 실험하여 도구를 동적으로 통합하는 방법을 배우게 됩니다.

## 내용
- 이 영상에서는 복잡한 입력과 출력을 가진 구조화된 도구를 정의하는 방법, 실시간 의사 결정을 위한 에이전트를 설정하는 방법, 그리고 동적 도구 통합을 위해 다양한 대규모 언어 모델이나 LLM을 실험하여 도구를 동적으로 통합하는 방법을 배우게 됩니다.
- 도구란 LLM이 단순한 텍스트 예측을 넘어 현실 세계와 상호작용할 수 있게 해주는 기능을 말합니다 실제 세계와 상호작용할 수 있게 해주는 기능입니다.
- 도구를 통해 LLM은 최신 뉴스와 같은 실시간 데이터에 접근하고, 이메일 보내기와 같은 작업을 수행하고, 수학적·논리적 정확성을 보장하며, 개인 또는 기업 전용 데이터를 검색하고, 다단계 추론 능력을 향상시킬 수 있게 해줍니다.
- LLM과 에이전트는 입력과 출력을 처리하는 방식이 다르며, 특정 조합의 경우 신뢰성 있게 작동하려면 특정 형식이 필요할 수 있습니다.
- 도구 클래스를 사용하여 동일한 논리를 구현할 수도 있지만, 핵심적인 차이점은 툴 데코레이터가 이를 구조화된 툴로 감싸, LLM이 명명된 인자와 사전 등을 포함한 더 복잡한 유연성과 함수 호출 모델과의 통합성을 향상시킵니다.
- 이 영상에서는 실제 상호작용을 가능하게 하는 데 있어 도구가 수행하는 핵심적인 도구가 실제 상호작용을 가능하게 하는 데 있어 핵심적인 역할을 살펴보며, LLM과 에이전트를 구별하는 방법을 배웠습니다.
- 유연하고 맥락을 인식하는 상호작용을 위한 구조화된 도구를 구축하여, 복잡한 입력과 견고한 데이터 처리를 지원하는 구조화된 도구를 구축하십시오.
