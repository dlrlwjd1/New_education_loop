# Build a Custom Math Toolkit Agent with LangChain

> MOOC video · [원본 학습 항목](https://www.mooc.org/learn/fundamentals-of-building-ai-agents/lecture/zZhCH/build-a-custom-math-toolkit-agent-with-langchain)

## 개요
- 지금까지 Initialize Agent를 사용하여 React나 Structured Chat과 같은 이제, 훨씬 더 유연하게 에이전트를 구축할 수 있는 또 다른 방법인 LangGraph를 살펴보겠습니다.

## 내용
- 지금까지 Initialize Agent를 사용하여 React나 Structured Chat과 같은 이제, 훨씬 더 유연하게 에이전트를 구축할 수 있는 또 다른 방법인 LangGraph를 살펴보겠습니다.
- 이 접근 방식은 견고한 다단계 에이전트 워크플로우를 구축하는 데 있어 Initialize_Agent를 대체하는 선호되는 방식으로 빠르게 자리 잡고 있습니다 견고하고 다단계인 에이전트 워크플로를 구축하는 데 있어 Initialize_Agent를 대체하는 선호되는 접근 방식으로 빠르게 자리 잡고 있습니다.
- "create react agent"를 사용하면 단일 에이전트 유형만 다룰 수 있지만, 프롬프트 템플릿을 완전히 사용자 정의할 수 있어, 에이전트의 행동과 추론 스타일을 더 세밀하게 제어할 수 있습니다.
- 예를 들어, 은행 거래용 에이전트를 구축하는 경우, 입금용 도구 하나, 출금용 도구 하나, 그리고 이체용 도구 하나가 필요할 수 있습니다.
- 그런 다음 "create react agent" 함수를 사용하여 LLM과 도구 목록을 매개변수로 전달하여 ReAct 에이전트를 생성합니다.
- 그런 다음 "create react agent"를 사용하여 계산과 위키백과에서 정보를 가져올 수 있는 새로운 에이전트를 생성합니다.
- Create_React_Agent 메서드를 사용하여 React 스타일의 에이전트를 구축함으로써 더 높은 수준의 사용자 정의와 제어를 가능하게 하는 방법을 배웠습니다.

## 예시
- 예를 들어, 복잡한 출력을 가진 숫자의 합을 구하는 등의 작업을 수행할 수 있습니다.

## 요약
- 그런 다음 "create react agent"를 사용하여 계산과 위키백과에서 정보를 가져올 수 있는 새로운 에이전트를 생성합니다. Create_React_Agent 메서드를 사용하여 React 스타일의 에이전트를 구축함으로써 더 높은 수준의 사용자 정의와 제어를 가능하게 하는 방법을 배웠습니다.
