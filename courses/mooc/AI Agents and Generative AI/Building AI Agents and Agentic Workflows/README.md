# Building AI Agents and Agentic Workflows

IBM의 3강좌 전문과정으로, LangChain tool calling·LCEL에서 LangGraph의 stateful·self-improving·multi-agent workflow, CrewAI·BeeAI·AG2 기반 orchestration까지 진행한다.

- 전문과정: https://www.mooc.org/specializations/building-ai-agents-and-agentic-workflows
- 구성: 3개 하위 강좌 · 9개 모듈 · 강의별 학습 노트 45개
- 수준: Intermediate
- 선수 지식: Python, LangChain 기초, core AI 개념 권장
- 실습 모델: OpenAI GPT, Meta Llama, IBM Granite 등 LLM을 활용하는 cloud lab
- 제외: 채점 퀴즈·과제와 해답

## 강좌

1. **[Fundamentals of Building AI Agents](Course%201%20-%20Fundamentals%20of%20Building%20AI%20Agents/README.md)** — 16개 강의, tool/function calling, LCEL, manual·built-in agent
2. **[Agentic AI with LangChain and LangGraph](Course%202%20-%20Agentic%20AI%20with%20LangChain%20and%20LangGraph/README.md)** — 15개 강의, stateful workflow, Reflection·Reflexion·ReAct, multi-agent RAG
3. **[Agentic AI with LangGraph, CrewAI, AutoGen and BeeAI](Course%203%20-%20LangGraph%20CrewAI%20AutoGen%20and%20BeeAI/README.md)** — 14개 강의, workflow pattern, CrewAI, BeeAI와 AG2

## 학습 흐름

```text
LLM + Tools -> Stateful Agent Workflow -> Self-Improvement
-> Multi-Agent/RAG -> Framework Selection & Orchestration
```

> 프레임워크 API는 빠르게 바뀔 수 있으므로 노트는 강좌의 설계 원리와 workflow 구조를 중심으로 정리한다.
