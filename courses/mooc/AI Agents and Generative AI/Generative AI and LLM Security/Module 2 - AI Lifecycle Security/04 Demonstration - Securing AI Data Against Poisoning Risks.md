# Demonstration: Securing AI Data Against Poisoning Risks

## 개요
- 훈련 파이프라인(training pipeline)을 상수도에 비유한다. 수원(source)이 깨끗하면 도시 전체가 잘 돌아가지만, 누군가 상류 탱크에 흙이나 염료를 몰래 넣으면 겉보기엔 멀쩡해도 수질이 서서히 떨어진다. 마찬가지로 소량의 손상된 레이블(label)이나 변조된 레코드가 조용히 모델 정확도를 떨어뜨리고 실제 위협을 숨길 수 있다.
- 이 데모는 작은 데이터셋을 만들고, 오염(poisoning)을 흉내 내기 위해 약간의 레이블 노이즈(label noise)를 추가하고, 그 영향을 측정한 뒤, 간단하고 설명 가능한 규칙으로 의심 샘플을 표시해 검토·격리(quarantine)할 수 있게 하는 과정을 Google Colab에서 보여준다.

## 내용

### 시나리오와 목표
- **시나리오**: Sentinel AI Co-op이 위협 탐지(threat detection) 모델을 만든다. SOC(보안 관제) 팀은 오염되거나 손상된 데이터가 조용히 정확도를 낮춰 공격을 놓치게 될까 우려한다. 노이즈 데이터를 시뮬레이션하고 이상치를 조기에 포착하며 파이프라인 전반의 보안 관행을 강화할 가벼운 방법이 필요하다.
- **목표**: (1) 깨끗하고 신뢰할 수 있는 훈련 데이터의 중요성 강조, (2) 오염의 안전한 대체물로서 소량의 레이블 노이즈를 시뮬레이션하고 영향 측정, (3) 쉽고 설명 가능한 휴리스틱(heuristic)으로 의심 샘플 탐지, (4) 파이프라인을 처음부터 끝까지 보호하는 모범 사례로 마무리.

### 1단계 - 환경 준비
- scikit-learn, pandas, matplotlib를 설치하고 필요한 라이브러리를 임포트한다.
- scikit-learn은 데이터 생성기, 간단한 로지스틱 회귀(logistic regression) 모델, 정확도 지표를 제공한다. pandas는 데이터를 표로 정리하고, matplotlib는 차트를 그린다. numpy는 수학 연산에, hashlib는 무결성 해시(integrity hash)에 사용한다.
- 임포트가 완료되는 것 외에 별다른 출력은 없으며, 이는 정상이다.

### 2단계 - 데이터 생성과 해시 지문
- 600개 샘플, 10개 특성(5개는 유의미한 정보 특성)을 가진 합성 2-클래스 데이터셋을 만들고 pandas 데이터프레임으로 감싼 뒤 정답(ground truth) 레이블 열을 추가한다.
- 각 행마다 SHA-256 해시를 계산한다. 이 해시는 샘플 내용의 지문(fingerprint) 역할을 한다. 나중에 누군가 행을 조용히 바꾸면(레이블을 뒤집거나 특성 값을 조작하면) 재계산한 해시가 일치하지 않아 변조를 탐지할 수 있다.
- 출력은 없지만, 개념적으로는 특성 열·레이블·행별 해시를 가진 정돈된 표가 만들어진다.

### 3단계 - 기준 모델과 오염 시뮬레이션
- 특성 X와 타깃 Y로 나누고, 클래스 균형이 유지되도록 계층적 분할(stratified train-test split)을 수행한다.
- 깨끗한 훈련 레이블로 기준(baseline) 로지스틱 회귀 모델을 훈련하고 테스트 정확도를 기록한다. 이것이 건강한 기준점이다.
- **오염 시뮬레이션**: 훈련 세트에만 10% 레이블 노이즈를 도입한다. 훈련 인덱스의 10%를 무작위로 골라 레이블을 0↔1로 뒤집고, 같은 모델을 이 노이즈 세트로 재훈련해 테스트 정확도를 다시 측정한다.
- 이번 실행에서는 노이즈가 작고 데이터셋이 단순해 정확도가 대략 80%대 중반으로 서로 비슷하다. 중요한 것은 방법론이다. 테스트 세트를 고정한 채 훈련 레이블만 손상시켜 오염 공격이 하듯 레이블 노이즈의 효과만 분리해 낸다. 다른 데이터셋에서 격차가 커지면 데이터 품질이 탐지 성능을 해치고 있다는 첫 신호다.

### 4단계 - 의심 샘플 탐지 (설명 가능한 휴리스틱)
- 노이즈 모델로 훈련 예제를 채점한다. 훈련 세트에 대해 클래스 1 예측 확률을 구하고, 노이즈 레이블에 대한 샘플별 로그 손실(log loss)을 계산한 뒤, 손실이 가장 높은 상위 5%를 의심 샘플로 표시한다.
- **직관**: 잘못 레이블링되거나 이상한 샘플은 모델이 맞추기 어려워 손실이 높다. 이는 무거운 방어책을 쓰기 전에 저렴하게 실행할 수 있는 간단하고 설명 가능한 휴리스틱이다.

### 5단계 - 결과 시각화
- 노이즈 레이블로 훈련한 모델의 훈련 세트 샘플별 로그 손실 히스토그램(histogram)을 그린다. 대부분의 막대가 왼쪽에 쌓여 있어 대다수 예제는 모델이 쉽게 설명함을 뜻한다.
- 빨간 수직선은 95번째 백분위(percentile) 임계값을 표시한다. 그 오른쪽의 "맞추기 어려운 꼬리(tail)"에 있는 것들이 의심 샘플로 표시된다.
- 실무에서는 이 행들을 먼저 검토해 레이블 오류나 오염을 확인하고, 현재 해시를 이전 스냅샷과 비교해 무결성을 점검한 뒤, 재훈련 전에 수정·격리하거나 가중치를 낮춘다(down-weight). 이 플롯은 모호한 데이터 품질 우려를 구체적인 검토 목록으로 바꿔준다.

## 예시
- 상수도 비유: 상류 탱크에 오염물을 넣으면 물이 겉보기엔 멀쩡해도 수질이 서서히 떨어지듯, 소량의 손상된 레이블이 조용히 모델 정확도를 갉아먹는다.
- 10% 레이블 노이즈 주입 후 테스트 정확도가 기준선 대비 어떻게 변하는지 측정하는 실험(테스트 세트는 고정, 훈련 레이블만 손상).
- SHA-256 행별 해시로 데이터 변조를 탐지하고, 샘플별 로그 손실 상위 5%를 의심 샘플로 플래그하는 휴리스틱.

## 요약
- 소량의 데이터 오염도 겉으로는 티가 나지 않게 모델 성능을 저하시킬 수 있으므로, 조기 탐지가 핵심이다.
- 테스트 세트를 고정하고 훈련 레이블만 손상시키면 오염 효과를 분리해 측정할 수 있다.
- 샘플별 로그 손실 기반 휴리스틱은 무거운 방어책 이전에 값싸게 의심 샘플을 골라내는 설명 가능한 방법이다.
- 행별 SHA-256 해시는 무결성 점검을 지원해 변조된 행을 탐지·격리하게 해준다.
