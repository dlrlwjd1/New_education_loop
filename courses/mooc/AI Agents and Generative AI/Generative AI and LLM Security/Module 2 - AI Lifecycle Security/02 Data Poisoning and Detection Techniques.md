# Data Poisoning and Detection Techniques

## 개요
- 훈련 데이터는 AI 모델의 식량 공급망과 같아서, 오염되면 시스템 전체가 병든다.
- 데이터 오염(data poisoning)의 정의, 공격 유형, 영향, 그리고 탐지·예방 전략을 다룬다.
- 수동 점검을 넘어 자동화된 탐지 기법과 다층 예방 전략의 필요성을 강조한다.

## 내용

### 데이터 오염이란
- 데이터 오염은 요리 전에 재료를 몰래 바꿔치기하는 것과 같다. 레시피는 그대로지만 결과물이 망가진다.
- 머신러닝에서 공격자는 모델의 동작을 바꾸기 위해 훈련 데이터를 의도적으로 손상시킨다. 크게 두 가지 방식이 있다.
  - **가용성 공격(availability attacks)**: 전반적 성능 저하가 목표. 오염된 데이터가 모델을 부정확하고 신뢰할 수 없게 만든다. 기계에 모래를 넣어 멈추게 하는 것과 같다.
  - **무결성 공격(integrity attacks)**: 더 표적화된 공격. 특정 오분류(misclassification)를 유발하거나 나중에 발동시킬 수 있는 숨겨진 백도어(backdoor)를 심는다. 공격자만 아는 비밀 함정문을 건물에 설치하는 것에 비유된다.

### 오염 공격의 유형
- **레이블 뒤집기 공격(label-flipping attacks)**: 올바른 레이블을 잘못된 것으로 바꾼다. 예: 고양이 사진을 개로 표시. 모델이 잘못된 패턴을 학습한다.
- **이상치 주입(outlier injection)**: 이상하거나 무관한 샘플을 추가해 모델이 정상 데이터를 이해하는 방식을 왜곡한다.
- **백도어 공격(backdoor attacks)**: 특정 키워드나 이미지 패턴 같은 숨겨진 트리거가 나타날 때마다 모델이 잘못된 예측을 하도록 만든다.
- **표적 공격 vs 가용성 공격(targeted vs availability attacks)**: 표적 오염은 특정 출력을 조작하고, 가용성 오염은 전반적 성능을 떨어뜨린다. 한 영역에서만 진실을 살짝 왜곡하는 것과 모든 곳에 거짓 정보를 퍼뜨리는 것의 차이다.

### 오염의 영향
- 기술적 오류를 넘어 **AI에 대한 신뢰를 훼손**한다.
- 결정 경계(decision boundary)를 변경해 모델이 클래스 구분에 혼란을 겪는다.
- 정확도(accuracy)가 감소해 예측을 신뢰할 수 없게 된다.
- 신뢰성(reliability)이 침식되어 사용자가 시스템에 대한 확신을 잃는다.
- 분류 오류(classification error)가 증가하며, 실제 환경에서는 치명적일 수 있다.
- 사기 탐지(fraud detection) 모델이 의심 거래를 놓치거나, 헬스케어 모델이 질병을 오분류하는 등 오염된 데이터의 결과는 산업 전체로 파급될 수 있다.

### 오염 데이터 탐지 절차
공급망의 모든 체크포인트에서 화물을 검사하듯 다음 단계를 적용한다.
- **데이터 정제(data sanitization)**: 레코드를 정리·필터링해 의심스러운 입력을 잡아낸다.
- **이상치 탐지(outlier detection)**: 통계적 도구로 맞지 않는 패턴을 찾는다.
- **강건한 훈련 기법(robust training)**: 모델이 노이즈와 이상값에 덜 민감하도록 만든다.
- **지속적 모니터링과 감사(continuous monitoring and auditing)**: 유입되는 데이터 스트림을 상시 감시한다.
- **피처 분석(feature analysis)**: 데이터의 피처가 과제를 논리적으로 뒷받침하는지 재확인한다.
- **교차 검증(cross-validation)**: 데이터를 서브셋으로 나누어 일관성을 테스트한다.

### 자동화된 탐지 접근법
사람 경비원에만 의존하지 않고 공항 보안 스캐너를 쓰듯 자동화된 탐지가 필수다.
- **거리 기반 탐지(distance-based detection)**: 유사도를 측정해 이상한 샘플을 찾는다.
- **레이블 뒤집기 탐지(flip-label detection)**: 비정상적이거나 일관성 없는 레이블링 패턴을 포착한다.
- **Z-점수 탐지(z-score detection)**: 정상 범위에서 멀리 벗어난 값을 찾는다.
- **손실 기반 탐지(loss-based detection)**: 손상된 데이터의 신호일 수 있는 훈련 손실(training loss) 급증을 식별한다.
- **이상 탐지(anomaly detection)**: 알고리즘으로 예상 밖의 모든 것을 플래깅한다.
- 이 접근법들은 데이터셋 무결성을 검증하고 오염 시도를 실시간으로 탐지하는 도구 모음을 제공한다.

### 예방 전략
최선의 방어는 자물쇠·카메라·경보기로 건물을 지키듯 다층 예방(layered prevention)이다.
- **적대적 훈련(adversarial training)**: 악의적 입력을 견디도록 모델을 준비시킨다.
- **접근 제어(access control)**: 훈련 데이터를 수정·추가할 수 있는 사람을 제한한다.
- **연합 학습(federated learning)**: 데이터를 분산시켜 단일 공격 지점을 줄인다.
- **검증과 필터링(validation and filtering)**: 깨끗한 데이터만 파이프라인에 들어오게 한다.
- **감사와 재훈련(auditing and retraining)**: 지속적으로 검증하고 모델을 갱신해 오염된 샘플을 제거한다.
- **데이터 버전 관리(data version control, DVC)**: 데이터셋 변경을 추적해 책임성을 확보한다.

## 예시
- 레이블 뒤집기: 고양이 사진에 개 레이블을 붙여 모델이 잘못된 패턴을 학습하게 만드는 공격.
- 사기 탐지 모델이 의심 거래를 잡지 못하거나 헬스케어 모델이 질병을 오분류하는 실제 피해 시나리오.

## 요약
- 데이터 오염은 AI의 식량 공급을 오염시키는 것과 같으며, 가용성 공격과 무결성 공격으로 나뉜다.
- 공격 기법에는 레이블 뒤집기, 이상치 주입, 백도어, 표적/가용성 공격이 있다.
- 오염은 결정 경계 변경, 정확도·신뢰성 저하, 분류 오류 증가로 이어져 산업 전반에 파급된다.
- 탐지는 데이터 정제, 이상치 탐지, 강건한 훈련, 지속 모니터링, 피처 분석, 교차 검증으로 수행한다.
- 자동화 탐지(거리 기반, 레이블 뒤집기, z-점수, 손실 기반, 이상 탐지)와 다층 예방(적대적 훈련, 접근 제어, 연합 학습, 검증·필터링, 감사·재훈련, DVC)이 핵심 방어책이다.
