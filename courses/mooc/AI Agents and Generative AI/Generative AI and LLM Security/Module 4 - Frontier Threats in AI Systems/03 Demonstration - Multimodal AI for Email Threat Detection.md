# Demonstration: Multimodal AI for Email Threat Detection

## 개요

- 멀티모달(multimodal) AI를 이메일 위협 탐지에 적용하는 실습 데모다.
- 텍스트(단어)와 비텍스트 신호(링크·첨부·발신자 평판 등 메타데이터)를 함께 읽는 "2인 보안팀" 비유로 접근한다.
- 텍스트와 수치 신호를 결합하는 **후기 융합(late-fusion)** 모델을 만들고, 텍스트만/수치만 쓰는 단일 모달리티(single-modality) 베이스라인과 비교한다.
- Google Colab에서 scikit-learn과 pandas로 진행한다.

## 내용

### 시나리오와 목표

- Blue Ledger Bank는 매일 수천 통의 이메일을 받는다.
- 피싱(phishing)은 제목의 위협적인 단어만으로 판별되지 않는다. 링크 개수가 많거나, 매크로(macro)를 품을 수 있는 큰 첨부, 무작위해 보이는 URL, 평판이 나쁜 발신자 같은 비텍스트(non-text) 단서도 함께 있다.
- 텍스트만 또는 수치만 보면 신호의 일부를 놓친다. 그래서 멀티모달 접근이 도움이 된다.
- 목표: 이메일 텍스트와 헤더/첨부 스타일 특징을 결합한 후기 융합 모델을 만들고, (1) 텍스트 전용, (2) 수치 전용 두 베이스라인과 비교한다.

### 환경 준비

- scikit-learn과 pandas를 설치하고 numpy, pandas, 파이썬 `random` 모듈을 임포트한다.
- scikit-learn에서 다음을 가져온다: `train_test_split`(학습/테스트 분할), TF-IDF 벡터라이저(텍스트를 수치로 변환), `ColumnTransformer`(텍스트+수치 결합), `Pipeline`(단계 연결), 로지스틱 회귀(logistic regression) 분류기, 평가 지표.
- 재현성(reproducibility)을 위해 랜덤 시드(seed)를 고정한다.
- 이 셀은 출력이 없다. 데이터 합성·모델 구축·채점에 필요한 환경만 갖춘 상태다.

### 합성 데이터 생성

- 500개 행의 작은 합성(synthetic) 데이터셋을 만든다.
- **텍스트 필드**: 두 개의 문구 풀에서 샘플링한다.
  - 피싱 풀: "urgent - approve wire transfer now", "account locked - click link to verify" 같은 문장.
  - 정상(benign) 풀: "team meeting notes attached" 같은 일상적 메시지.
- **수치 특징**: 이메일 메타데이터를 흉내 내어 텍스트로부터 생성한다.
  - 링크 개수: 포아송(Poisson) 분포에서 추출.
  - 첨부 크기(KB): 정규(normal) 분포.
  - URL 엔트로피(entropy): 정규 분포. 의심스러운 링크는 더 무작위해 보이도록.
  - 발신자 평판(sender reputation): 잘라낸(clipped) 정규 분포. 0은 나쁨, 1은 좋음.
  - 매크로 보유 플래그(has-macro): 나쁜(bad) 라벨 행에서 더 자주 등장.
- 텍스트 열, 5개 수치 열, 라벨(피싱 vs 정상) 열로 pandas 데이터프레임을 조립한다.
- 클래스 균형(class balance)을 유지하도록 계층화(stratified) 학습/테스트 분할을 만든다. 각 표에는 텍스트 1열 + 수치 여러 열 + 라벨이 담기며, 이것이 우리가 원하는 멀티모달 입력이다.

### 후기 융합(late fusion) 모델

- **정의**: 후기 융합은 각 모달리티를 따로 특징화(featurize)한 뒤 분류기 단계에서만 결합하는 멀티모달 파이프라인이다.
  - 이메일 텍스트는 한 갈래에서 TF-IDF 벡터로 변환.
  - 수치 메타데이터는 두 번째 갈래로 통과.
  - 두 특징 세트를 이어 붙인(concatenate) 뒤 최종 로지스틱 회귀가 결정 경계(decision boundary)를 학습.
- 대비 개념:
  - **초기 융합(early fusion)**: 원시 입력(raw input)을 먼저 병합.
  - **중기 융합(mid fusion)**: 신경망 내부의 중간 표현(intermediate representation)에서 융합.
- 구현: 텍스트 열과 수치 열 목록을 선언 → `ColumnTransformer`를 두 갈래로 구성(텍스트 갈래는 유니그램·바이그램 TF-IDF, 수치 갈래는 그대로 통과) → 변환기와 로지스틱 회귀를 파이프라인으로 감싸 학습 → 테스트 예측 → 정확도(accuracy) 출력.
- 수렴 경고(convergence warning)가 나오면 솔버(solver)가 반복 상한에 도달했다는 의미일 뿐, 이 작은 데모에서는 결과가 괜찮다.

### 베이스라인 비교와 지표 해석

- **텍스트 전용 베이스라인**: 텍스트 열에 TF-IDF를 적용하고 로지스틱 회귀를 학습.
- **수치 전용 베이스라인**: 수치 특징 벡터만으로 로지스틱 회귀를 학습.
- 동일한 테스트셋으로 두 베이스라인을 평가하고 정확도를 출력한 뒤, 멀티모달 모델의 상세 분류 리포트(precision·recall·F1)를 클래스별로 출력한다.
- 지표 읽는 법:
  - **정확도(accuracy)**: 전체 정답 비율.
  - **정밀도(precision)** — 피싱 클래스: 피싱으로 예측한 것 중 실제 피싱의 비율.
  - **재현율(recall)** — 피싱 클래스: 실제 피싱 중 잡아낸 비율.
  - **F1**: 정밀도와 재현율의 균형.

## 예시

- 코랩 워크플로 요약:
  - 텍스트 신호와 비텍스트 신호를 모두 담은 토이(toy) 이메일 데이터셋 생성.
  - TF-IDF 텍스트 특징과 수치 메타데이터를 결합한 후기 융합 모델 학습.
  - 텍스트 전용·수치 전용 베이스라인과 비교.
- 이 흐름은 모달리티를 깔끔하게 연결하는 방법과, 피싱 탐지의 트레이드오프를 판단하기 위해 정확도·정밀도·재현율·F1을 읽는 법을 보여준다.

## 요약

- 피싱은 텍스트뿐 아니라 링크 수·첨부 크기·URL 엔트로피·발신자 평판·매크로 여부 같은 비텍스트 신호도 함께 나타나므로 멀티모달 접근이 유리하다.
- 후기 융합(late fusion)은 텍스트(TF-IDF)와 수치 특징을 각각 처리한 뒤 분류기 단계에서 결합하는 방식이며, 초기·중기 융합과 구분된다.
- 후기 융합 모델을 텍스트 전용·수치 전용 베이스라인과 비교해 멀티모달 결합의 이점을 확인한다.
- 정확도·정밀도·재현율·F1을 함께 읽어 탐지 성능의 트레이드오프를 평가한다.
