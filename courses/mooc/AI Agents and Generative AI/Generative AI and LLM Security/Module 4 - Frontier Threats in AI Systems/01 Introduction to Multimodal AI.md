# Introduction to Multimodal AI

## 개요

- 멀티모달(multimodal) AI는 텍스트, 이미지, 오디오, 비디오 등 여러 데이터 모달리티(modality)를 하나의 모델로 통합해 더 깊은 맥락적 이해를 가능하게 하는 AI다.
- 시스템이 복잡해질수록 공격 표면(attack surface)도 넓어진다. 건물의 문이 많아지면 편리해지지만 침입 경로도 늘어나는 것과 같다.
- 이 강의는 데이터 모달리티 개념, 멀티모달 데이터 파이프라인, 멀티모달 워크플로의 구조를 다룬다.

## 내용

### 데이터 모달리티(data modality)란

모달리티는 AI 시스템이 처리하고 학습할 수 있는 특정 데이터 유형을 말한다.

- **자연어와 코드**: 문서, 대화, 프로그래밍 스크립트 같은 텍스트 입력
- **사진, 다이어그램, 차트**: 구조적·맥락적 정보를 제공하는 시각 데이터
- **음성, 음악, 소음**: 어조, 감정, 소리 패턴을 담는 오디오 신호
- **3D 모델, 센서 데이터, 보안 텔레메트리(telemetry)**: 엔지니어링, IoT, 모니터링 시스템에서 쓰이는 고급 데이터 형태
- **비디오 및 오디오-비주얼 결합 데이터**: 이미지와 소리를 합쳐 더 풍부한 실제 상황을 포착

각 모달리티는 고유한 도전과 기회를 가지며, 효과적으로 결합하면 AI가 세계를 더 깊고 총체적으로 이해하도록 돕는다.

### 멀티모달 AI의 정의와 장점

멀티모달 AI는 여러 모달리티를 하나의 통합 모델(unified model)로 결합해 더 깊은 맥락적 이해를 가능하게 하는 인공지능이다. 핵심 장점은 다음과 같다.

- 일부 데이터가 누락되어도 유지되는 견고성(robustness)
- 다양한 작업 전반의 성능 향상
- 더 풍부한 맥락 인식(contextual awareness)
- 실제 상황에 대한 더 나은 적응력

### 멀티모달 데이터 파이프라인(multimodal data pipeline)

멀티모달 시스템 작동의 근간이 되는 구조화된 순서다.

1. **데이터 수집(data collection)**: 텍스트, 이미지, 오디오, 비디오, 센서 판독값까지 다양한 유형의 데이터를 모은다.
2. **데이터 정렬(data alignment)**: 서로 다른 모달리티를 동기화한다. 예: 오디오를 올바른 비디오 프레임과 맞추거나, 텍스트를 올바른 이미지와 매칭.
3. **전처리(pre-processing)**: 데이터를 정제하고 표준화·구조화해 분석 준비를 마친다.
4. **특징 추출(feature extraction)**: 텍스트의 키워드, 이미지 속 객체, 음성의 어조 등 의미 있는 패턴을 식별한다.
5. **융합과 통합(fusion and integration)**: 멀티모달리티의 핵심으로, 서로 다른 데이터 스트림의 인사이트를 결합해 통합 표현(unified representation)을 만든다.
6. **학습과 평가(training and evaluation)**: 모델이 데이터로부터 학습하고 정확성, 견고성, 회복탄력성(resilience)을 검증받는다.

파이프라인의 **모든 단계**에서 데이터 포이즈닝(data poisoning), 정렬 불량(misalignment), 편향(bias) 같은 보안 위험이 스며들 수 있으므로 신중한 설계와 모니터링이 필수다.

### 멀티모달 워크플로(multimodal workflow)

서로 다른 데이터 유형이 함께 처리되어 의미 있는 출력을 만드는 흐름이다.

1. **멀티모달 입력(multimodal input)**: 텍스트, 시각 자료, 음성 또는 이들의 조합
2. **멀티모달 인코더(multimodal encoder)**: 입력 유형별로 전용 인코더가 처리한다. 예: 텍스트는 언어 인코더, 이미지는 비전 인코더
3. **특징 융합(feature fusion)**: 어텐션(attention), 프로젝션(projection), 연결(concatenation) 같은 기법으로 서로 다른 모달리티의 특징을 결합해 통합 표현을 만든다.
4. **대규모 언어 모델 백본(LLM backbone)**: 통합된 정보를 처리하며 추론, 맥락, 고급 이해를 더한다.
5. **작업별 헤드(task-specific head)**: 질의응답, 이미지 분류, 캡션 생성 등 특정 응용에 맞게 파인튜닝된 구성 요소
6. **출력(output)**: 작업에 맞춘 결과 생성

이 단계별 흐름이 멀티모달 AI가 단일 데이터 유형을 넘어 더 풍부하고 맥락 인식적인, 작업 특화 결과를 내놓을 수 있게 한다.

## 예시

강의에서 소개한 대표적인 멀티모달 AI 시스템:

- **GPT-4V**: GPT-4에 강력한 비전(vision) 기능을 추가
- **Gemini**: 텍스트, 코드, 비전 전반의 추론에 탁월
- **LLaVA**: 오픈소스 비전-언어 모델로, 지시 따르기(instruction following)에 강점

이러한 돌파구는 큰 잠재력을 가져오는 동시에 견고한 안전장치 구축의 시급성을 부각한다.

## 요약

- 모달리티는 AI가 처리·학습하는 데이터 유형이며, 텍스트·이미지·오디오·센서 데이터·비디오 등이 있다.
- 멀티모달 AI는 여러 모달리티를 통합 모델로 결합해 견고성, 성능, 맥락 인식, 적응력을 높인다.
- 데이터 파이프라인은 수집 → 정렬 → 전처리 → 특징 추출 → 융합·통합 → 학습·평가 순으로 진행되며, 각 단계마다 보안 위험이 존재한다.
- 워크플로는 모달리티별 인코더 → 특징 융합 → LLM 백본 → 작업별 헤드 → 출력 구조로 작동한다.
- 멀티모달의 발전은 잠재력과 함께 견고한 안전 대책의 필요성을 동시에 키운다.
