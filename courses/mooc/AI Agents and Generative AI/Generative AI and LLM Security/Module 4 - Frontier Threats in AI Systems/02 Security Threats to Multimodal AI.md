# Security Threats to Multimodal AI

## 개요

- 멀티모달(multimodal) AI는 텍스트·이미지·오디오·비디오를 결합하면서 공격 표면(attack surface)이 크게 확장된다.
- 이 강의는 멀티모달 시스템의 공격 벡터(attack vector), 비즈니스 위험, 방어 전략을 다룬다.
- 방어는 전략 수립 → 실시간 운영 → 거버넌스(governance)의 다층 접근이 필요하다.

## 내용

### 주요 공격 벡터(attack vectors)

적대자가 멀티모달 시스템을 노리는 주된 방법들이다.

- **이미지 교란(image perturbation)**: 사람 눈에는 보이지 않지만 모델에는 영향을 주는 미세한 이미지 수정으로 AI가 오분류(misclassification)하도록 속인다.
- **메타데이터 포이즈닝(metadata poisoning)**: 무해해 보이는 태그나 숨겨진 데이터에 악성 지시를 삽입해 모델 행동에 영향을 준다.
- **오디오 스푸핑(audio spoofing)**: 조작된 또는 적대적(adversarial) 오디오로 인증을 우회하거나 거짓 명령을 주입한다.
- **텍스트 주입(text injection)**: 프롬프트를 직접 조작해 유해한 출력을 유발한다.
- **크로스 모달 우회(cross-modal bypass)**: 모달리티 간의 차이를 악용한다. 예: 텍스트 기반 안전장치를 이미지 프롬프트로 무력화.

이들이 멀티모달 파이프라인에서 공격자가 악용할 수 있는 다양한 진입점을 이룬다.

### 모달리티를 넘나드는 연쇄 공격

단일 벡터 공격을 넘어, 적대자는 여러 모달리티에 걸쳐 기법을 연쇄(chaining)한다.

- **모달리티 체이닝(modality chaining)**: 입력을 조합하는 공격. 예: 이미지 캡션 안에 악성 텍스트를 심어 필터를 우회.
- **컨텍스트 스머글링(context smuggling)**: 민감한 프롬프트를 한 모달리티에 숨겨 다른 모달리티로 유출시킨다.
- **프롬프트 주입(prompt injection)**: 모델에 주어지는 지시를 직접 조작해 유해한 행동으로 유도한다.
- **도구 악용(tool exploitation)**: AI가 외부 API나 도구에 접근하는 통합 지점을 악용해 연쇄적(cascading) 위험을 만든다.

이 공격의 정교함은 약점을 조합하는 데 있다. 고도로 보안된 건물에 침입하려고 자물쇠를 순서대로 따는 해커와 비슷하다.

### 비즈니스·운영 차원의 위험

- **탐지 사각지대(detection blind spots)**: 조직이 시스템이 조작된 사실조차 인지하지 못할 수 있다.
- **에스컬레이션 경로(escalation paths)**: 작은 익스플로잇이 치명적 침해로 커질 수 있다.
- **데이터 유출 위험(data exfiltration)**: 민감 정보가 모달리티를 넘나들며 새어 나갈 수 있다.
- **공격 표면 확대(attack surface growth)**: 기업이 멀티모달 AI를 더 많은 용도로 도입할수록 확대된다.

운영 관점에서 이는 단순한 기술 문제가 아니라 신뢰, 컴플라이언스(compliance), 장기 회복탄력성(resilience)에 영향을 주는 비즈니스 위험이다.

### 완화 전략: 다층 방어 설계

- **위협 모델링(threat modeling)**: 배포 전에 위험을 미리 예측한다.
- **보안 기본값(secure defaults)**: 시스템이 최소 노출 상태로 시작하게 한다.
- **최소 권한(least privilege)**: 모델과 연결된 도구가 정말 필요한 것에만 접근하게 한다.
- **심층 방어(defense in depth)**: 모달리티 전반에 보안 통제를 계층화한다.
- **페일세이프 차단(fail-safe blocks)**: 안전하지 않은 동작을 자동으로 차단하는 메커니즘을 항상 준비한다.

이는 요새를 짓는 것과 같다. 높은 벽만이 아니라 성문, 경비, 예비 방어까지 갖추는 것이다.

### 실시간 운영 방어

전략을 넘어 방어는 실시간으로 운영화되어야 한다.

- **입력 정화(input sanitization)**: 멀티모달 입력에서 숨겨진 악성 지시를 제거한다.
- **정책 라우팅(policy routing)**: 데이터를 가장 안전한 모델 또는 필터 경로로 보낸다.
- **격리 실행(isolated execution)**: 고위험 작업을 샌드박스(sandbox) 환경에서 실행해 잠재 위협을 봉쇄한다.
- **콘텐츠 필터링(content filtering)**: 안전하지 않은 출력이 최종 사용자에게 도달하기 전에 차단한다.

이 메커니즘들은 능동적 공격 상황에서도 모델을 안전하게 유지하는, AI를 위한 실시간 방화벽(firewall)과 유사하다.

### 거버넌스(governance)

보안은 기술을 넘어 거버넌스로 확장되어야 한다.

- 정기적인 **위험 평가(risk assessment)** 로 격차를 식별
- **보안 태세 모니터링(posture monitoring)** 으로 보안 상태를 지속적으로 가시화
- **크로스 모달 텔레메트리(cross-modal telemetry)** 로 입력과 출력 전반의 활동을 추적
- **인시던트 플레이북(incident playbook)** 으로 빠르고 구조화된 대응 보장
- **지속적 레드팀(continuous red team)** 접근으로 공격을 시뮬레이션하며 적대자보다 앞서기
- 통제를 **컴플라이언스 프레임워크에 매핑**해 법적·규제적 의무 충족

거버넌스는 방어가 존재하는 것을 넘어 검증되고, 모니터링되며, 비즈니스 우선순위에 정렬되도록 보장한다.

## 요약

- 멀티모달 AI의 공격 벡터: 이미지 교란, 메타데이터 포이즈닝, 오디오 스푸핑, 텍스트 주입, 크로스 모달 우회.
- 공격자는 모달리티 체이닝, 컨텍스트 스머글링, 프롬프트 주입, 도구 악용을 조합해 연쇄 공격을 수행한다.
- 비즈니스 위험은 탐지 사각지대, 에스컬레이션 경로, 데이터 유출, 공격 표면 확대로 나타난다.
- 방어 전략: 위협 모델링, 보안 기본값, 최소 권한, 심층 방어, 페일세이프 차단.
- 실시간 방어: 입력 정화, 정책 라우팅, 격리 실행, 콘텐츠 필터링.
- 거버넌스: 위험 평가, 태세 모니터링, 크로스 모달 텔레메트리, 인시던트 플레이북, 지속적 레드팀, 컴플라이언스 매핑.
