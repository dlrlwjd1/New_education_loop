# Common Attack Vectors in Generative AI Systems

## 개요

- 공격 벡터(attack vector)의 개념과 공격 표면(attack surface)과의 차이를 정리한다.
- 생성형 AI 특유의 핵심 공격 벡터: 프롬프트 인젝션(prompt injection), 데이터 오염(data poisoning)과 백도어(backdoor), 모델 추출(model extraction), 모델 역전(model inversion)·멤버십 추론(membership inference).
- 공개 저장소의 변조 모델, 서드파티 연동, API 남용, 적대적 입력 조작 등 새롭게 부상하는 위협도 다룬다.

## 내용

### 공격 벡터란

- 도둑이 집에 침입할 때 문, 창문, 차고 같은 진입점을 노리듯, 사이버보안에서 공격자가 시스템을 침해하기 위해 사용하는 경로나 수법을 공격 벡터라 부른다.
- 생성형 AI 모델에서는 창문 대신 악성 프롬프트(malicious prompt)나 오염된 데이터셋(poisoned dataset)이 약점이 될 수 있다. 원리는 같다 — 공격자는 들어갈 길을 찾는다.

### 공격 벡터 vs 공격 표면

- **공격 벡터(attack vector)**: 실제 공격 방법. 피싱 이메일, 멀웨어 주입처럼 공격자가 쓰는 "무기".
- **공격 표면(attack surface)**: 취약점의 총합. 집으로 치면 잠기지 않은 문과 창문 전체, 즉 "전장(battlefield)".
- 벡터는 전술, 표면은 전장이다. AI 시스템을 지키려면 무기를 막는 동시에 전장의 크기도 줄여야 한다.

### 공격 벡터의 두 가지 악용 방식

- **수동적 공격(passive attack)**: 도청자처럼 변경 없이 트래픽이나 데이터를 조용히 감시. 예: 로그인 패턴을 수집해 나중에 시스템에 침입.
- **능동적/생성형 공격**: 창문을 깨고 침입하는 강도처럼 직접적이고 파괴적. 악성 입력 주입, 자격 증명 탈취, 출력 변조 등이 포함된다.
- 두 형태 모두 생성형 AI에 위협이 되며, 이 수법들을 인지하는 것이 더 강한 방어 설계에 도움이 된다.

### 생성형 AI의 핵심 공격 벡터

- **프롬프트 인젝션(prompt injection)**: 오해하게 만드는 질문으로 비밀을 털어놓게 속이는 것처럼, 공격자가 모델의 행동을 조작하는 입력을 만들어낸다.
- **데이터 오염과 백도어(data poisoning & backdoors)**: 수원(水源)을 오염시키는 것과 같다. 학습 중에 악성 데이터를 주입해 모델이 나중에 유해한 출력을 내도록 만든다.
- **모델 추출(model extraction)**: 보안 설계도를 복사하듯, 모델에 대량 쿼리를 보내 기능을 재구성하거나 훔친다.
- **모델 역전과 멤버십 추론(model inversion & membership inference)**: 일기 내용에서 개인 정보를 추론하듯, 출력으로부터 민감한 학습 데이터를 유추하거나 특정 개인의 데이터가 학습에 포함됐는지 확인한다.

이 공격들은 생성형 AI가 정보를 처리하는 고유한 방식을 악용한다.

### 새롭게 부상하는 위협 벡터

- **공개 저장소의 변조 모델(compromised models)**: 바이러스가 숨은 무료 소프트웨어를 내려받는 것처럼, 공격자가 저장소(repository)에 변조된 모델을 업로드할 수 있다.
- **서드파티 연동(third-party integrations)**: 생성형 AI를 외부 도구와 연결하면 위험이 확대된다. 약한 고리 하나가 전체 체인을 노출시킬 수 있다.
- **무단 접근과 API 남용(unauthorized access & API abuse)**: 훔친 키카드로 건물에 들어가듯, 허술하게 보호된 API를 악용한다.
- **적대적 입력 조작(adversarial input manipulation)**: 도로 표지판을 살짝 바꿔 운전자를 오도하듯, 입력의 작은 교란(perturbation)으로 AI가 잘못된 출력을 내게 속인다.

이 위협들은 AI 보안이 정적이지 않고 혁신과 함께 진화한다는 점을 보여준다.

## 요약

- 공격 벡터는 공격 방법(전술), 공격 표면은 취약점의 총합(전장)이며, 방어에는 둘 다 필요하다.
- 공격은 몰래 감시하는 수동적 방식과 직접 침입·변조하는 능동적 방식으로 나뉜다.
- 핵심 벡터: 프롬프트 인젝션, 데이터 오염·백도어, 모델 추출, 모델 역전·멤버십 추론.
- 부상 위협: 변조된 공개 모델, 서드파티 연동 리스크, API 남용, 적대적 입력 조작.
- 생성형 AI 보안은 끊임없이 변하는 도시를 지키는 것과 같다 — 알려진 공격 차단을 넘어 미지의 공격에 앞서 나가는 것이 진짜 과제다.
