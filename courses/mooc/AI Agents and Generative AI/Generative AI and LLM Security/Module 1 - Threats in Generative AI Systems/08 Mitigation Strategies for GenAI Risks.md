# Mitigation Strategies for GenAI Risks

## 개요

- 생성형 AI(generative AI)는 강력한 능력을 제공하지만 데이터 오용부터 적대적 공격까지 상당한 위험을 동반한다.
- 완화(mitigation)는 선택이 아니라 신뢰할 수 있는 AI 배포를 위한 필수 요소다. 자동차의 안전 브레이크와 에어백처럼 예상치 못한 상황에서도 시스템을 안전하게 지킨다.
- 입력 검증, 출력 통제, 모델 무결성, 인프라 보안, 인간 감독까지 여러 계층의 완화 전략을 구조적으로 다룬다.

## 내용

### 완화가 필요한 이유

- **유해 출력 방지(prevent harmful outputs)**: AI는 때때로 공격적·편향적·위험한 출력을 낼 수 있어, 안전장치로 이를 줄인다.
- **민감 데이터 보호(protect sensitive data)**: 사용자가 의도치 않게 개인·기밀 정보를 공유할 수 있는데, 강력한 완화 전략이 이런 데이터가 AI 응답에 유출되는 것을 막는다.
- **신뢰성 확보(ensure reliability)**: 완화가 없으면 모델이 일관성 없이 동작한다. 안전장치가 출력을 예측 가능하고 기대에 맞게 유지한다.

### 입력 검증 (첫 번째 방어선)

- **엄격한 입력 정제(strict input sanitization)**: 처리 전에 입력의 악성 코드나 유해 패턴을 무력화한다.
- **사전 프롬프팅(pre-prompting)**: 모델이 항상 따라야 하는 사전 지시(preset instructions) 같은 시스템 가드레일을 추가해, 안전하지 않은 사용자 프롬프트가 이를 덮어쓰지 못하게 한다.
- **의미 분석(semantic analysis)**: 무해해 보이는 요청 뒤에 숨은 악의를 탐지한다.
- **입력 길이 제한(input length limits)**: 지나치게 긴 프롬프트로 검사를 우회하려는 시도를 막는다.
- 이 단계는 공항 보안처럼 들어오는 모든 것을 먼저 검색하는 것과 같다.

### 출력 통제

- **페일세이프 출력(fail-safe outputs)**: 위험한 질의를 만나면 멈추지 않고 "I cannot provide that information" 같은 사전 정의된 안전 메시지로 응답한다. 시스템 침묵이나 위험한 답변을 방지한다.
- **LLM 샌드박싱(sandboxing the LLM)**: 모델을 통제된 구역에 두어, 유해 스크립트를 생성하더라도 샌드박스 밖에서 실행되지 못하게 한다. 후드 아래에서 화학물질을 실험하는 것과 같은 격리 전략이다.
- **실행 환경(execution environments)**: AI가 생성한 코드를 안전하게 테스트할 격리 공간을 제공한다. 악성 코드가 통과해도 프로덕션에 도달하지 못한다.
- **후처리 필터(post-processing filters)**: 마지막 계층으로, 출력이 사용자에게 도달하기 전 독성·편향·안전하지 않은 지시를 스캔한다. 공항 입구 검색 후에도 출발 전 다시 짐을 검사하는 세관 통제와 같다.

### 모델 무결성 방어

- **적대적 훈련(adversarial training)**: 알려진 공격 패턴에 맞서 훈련해 모델을 견고하게 만든다.
- **데이터 정제(data sanitization)**: 훈련 데이터셋에 오염되거나 악성인 데이터가 없도록 한다.
- **모델 버전 관리(model versioning)**: 업데이트를 추적해 새 취약점이 나타나면 안전한 버전으로 롤백(rollback)할 수 있게 한다.
- **워터마킹(watermarking)**: 모델 출력에 태그를 붙여 AI 생성 콘텐츠를 탐지하고 오용을 추적하기 쉽게 한다.
- 이는 요새의 벽과 감시 시스템을 함께 강화하는 것과 같다.

### 인프라 보안

- **위협 모델링(threat modeling)**: 발생 전 가능한 공격 경로를 예상한다.
- **API 보안(API security)**: AI에 접근하는 엔드포인트를 보호해 무단 행위자가 오용하지 못하게 한다.
- **최소 권한 원칙(least privilege principle)**: 권한을 최소화해 사용자·시스템이 꼭 필요한 것에만 접근하게 한다.
- **네트워크 분할(network segmentation)**: 핵심 시스템을 격리해 한 영역의 침해가 전체 인프라로 번지지 않게 한다.
- 금고만 잠그는 것이 아니라 출입구·경비·경보까지 통제하는 은행 보안과 같다.

### 인간 감독

- **인간 개입(human-in-the-loop)**: 핵심 AI 결정을 사람이 검토하거나 승인한다.
- **지속적 로깅(continuous logging)**: 시스템 활동을 추적해 추적성과 책임성을 확보한다.
- **보안 감사(security audits)**: 약점을 식별하고 표준 준수를 보장한다.
- **견고성 훈련(robustness training)**: 새로운 공격 방식에 대응하도록 팀과 시스템을 강화한다.
- 이 계층은 자동화와 인간 판단을 결합해 균형 잡히고 적응적인 방어를 만든다.

## 요약

- 생성형 AI에서의 완화는 여러 겹의 안전망을 쌓는 것과 같다.
- 입력 검증 → 출력 통제 → 모델 무결성 → 인프라 보안 → 인간 감독의 각 계층이 위험을 줄이고 신뢰를 강화한다.
- 이 전략들을 적용하면 조직은 생성형 AI의 힘을 자신 있게 활용하면서 위험을 최소화할 수 있다.
