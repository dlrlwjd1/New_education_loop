# Demonstration: LLM Integration with Gemini API

## 개요

- Google Gemini 모델에 프롬프트를 보내고 응답을 받는 과정을 단계별로 실습하는 데모다.
- 라이브러리 설치, API 키 설정, 모델 초기화, 응답 함수 정의, 다양한 프롬프트 테스트 순서로 진행한다.

## 내용

### 1단계 - 라이브러리 설치

- Google Generative AI 라이브러리를 설치해 Gemini API와 상호작용하고 그 기능에 접근할 수 있게 한다.
- 한 번만 설치하면 되며, 이후 단계에서 필요한 도구를 모두 임포트할 수 있는 환경을 마련해 준다.

### 2단계 - 라이브러리 임포트

- `google.generativeai`를 `genai`로 임포트해 Gemini API에 연결하고 프롬프트를 보내는 데 쓸 함수들을 가져온다.
- `os` 모듈을 임포트해 Gemini 접근을 인증하는 API 키 같은 환경 변수(environment variable)를 관리한다.

### 3단계 - API 키 설정

- Google의 MakerSuite에서 자신의 API 키를 발급받아야 한다. 이 키가 요청을 인증하고 안전하게 만든다.
- API 키를 환경 변수에 저장해 코드에 직접 노출되지 않도록 한다.
- 키를 가져온 뒤 Gemini API를 이 키로 설정(configure)해 모델 사용을 준비한다.

### 4단계 - Gemini 모델 초기화

- Gemini 2.0 Flash 버전을 사용해 다양한 작업에 최적화된 모델을 초기화한다.
- 모델을 초기화하는 것은 시스템에 어떤 모델과 상호작용할지 알려주어 프롬프트 처리와 응답 생성을 준비시키는 단계다.

### 5단계 - 응답 함수 정의

- `getGeminiResponse`라는 함수를 정의해 프롬프트를 Gemini 모델에 보내고 응답을 받는다.
- 함수의 동작:
  1. `generateContent` 함수를 사용해 프롬프트를 모델로 보낸다.
  2. 출력을 받아 텍스트 응답을 반환한다.
  3. 처리 중 오류가 있으면 이를 포착해 오류 메시지를 반환한다.
- 이 함수를 정의해 두면 프롬프트마다 반복 코드를 작성하지 않고도 같은 로직을 재사용할 수 있다.

### 6단계 - 기본 프롬프트 테스트

- 머신러닝을 쉬운 말로 설명해 달라는 기본 프롬프트로 설정을 테스트한다.
- 셀을 실행해 프롬프트와 응답을 함께 출력함으로써 설정이 제대로 작동하고 Gemini 모델이 올바르게 응답하는지 확인한다.
- 출력에서 모델은 머신러닝을 개에게 새로운 재주를 가르치는 것에 비유하며, 데이터·알고리즘·학습이 어떻게 맞물리는지 보여주는 명확하고 이해하기 쉬운 설명을 제공한다.

### 7단계 - 다양한 프롬프트로 테스트

- 기본 프롬프트가 작동함을 확인한 뒤, 여러 프롬프트로 Gemini가 다른 유형의 질의에 어떻게 반응하는지 시험한다.
- 세 가지 프롬프트:
  1. **창작 과제**: AI에 관한 짧은 시를 써 달라고 요청한다.
  2. **지식 기반 과제**: 자연어 처리(NLP)의 이점을 나열해 달라고 요청한다.
  3. **비교 과제**: AI와 머신러닝의 차이를 물어본다.
- 각 프롬프트마다 `getGeminiResponse` 함수가 응답을 반환하고, 프롬프트와 그에 대응하는 응답을 화면에 출력한다.
- 모델은 창작부터 정보 전달까지 다양한 유형의 작업을 처리할 수 있음을 보여준다. AI에 관한 시, NLP의 실제 응용을 보여주는 이점 목록, AI와 머신러닝의 명확한 구분이 출력으로 나온다.

## 예시

- 설치 명령: Google Generative AI 라이브러리를 설치하는 한 줄 명령.
- 임포트: `import google.generativeai as genai`, `import os`
- 응답 함수의 동작 순서: 프롬프트 전송(`generateContent`) → 텍스트 응답 반환 → 오류 시 오류 메시지 반환
- 테스트한 프롬프트:
  - "머신러닝을 쉬운 말로 설명해 달라" → 개에게 재주를 가르치는 비유로 설명
  - "AI에 관한 짧은 시를 써 달라" (창작 과제)
  - "자연어 처리(NLP)의 이점을 나열해 달라" (지식 기반 과제)
  - "AI와 머신러닝의 차이는 무엇인가" (비교 과제)

## 요약

- 라이브러리 설치, 임포트, API 키 설정, 모델 초기화, 응답 함수 정의, 프롬프트 테스트의 순서로 Gemini API를 통합했다.
- API 키는 환경 변수로 관리해 코드에 직접 노출하지 않는다.
- 하나의 재사용 가능한 함수로 다양한 프롬프트(설명, 창작, 지식, 비교)를 처리할 수 있음을 확인했다.
- Gemini는 챗봇, 추천 시스템, 창작 AI 콘텐츠 등 다양한 활용 사례에 쉽게 통합할 수 있는 강력한 도구다.
