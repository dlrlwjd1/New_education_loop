# Course Introduction

## 개요
- 첫 강좌의 학습 목표, 3개 핵심 모듈과 사용하는 개발 도구를 소개한다.

## 내용
- 단순 질의응답을 넘어 researcher·strategist·writer agent가 계획·협업·실행하는 system을 만드는 것이 목표다.
- Module 1은 agentic AI, multi-agent system과 CrewAI architecture·개발 환경을 다룬다.
- Module 2는 model 선택, prompt·context engineering과 execution flow를 설계한다.
- Module 3은 agent·task를 정의하고 crew로 조립해 실제 workflow를 실행한다.
- CrewAI, Python, Visual Studio Code, LLM과 `uv` package manager를 사용하며 Python·AI 기초 지식을 권장한다.

## 예시
```text
Researcher -> Strategist -> Content Writer
```
- 각 역할의 output이 다음 역할의 input이 되는 collaborative workflow를 구현한다.

## 요약
- 이 강좌는 이론·demonstration·reading·practice를 통해 첫 CrewAI multi-agent system을 완성하도록 구성된다.
