# Marketing Team’s Struggle with Traditional AI

## 개요
- 여러 AI tool이 개별 task는 잘 수행해도 공유 목표·context·coordination이 없으면 전체 campaign이 실패할 수 있음을 사례로 설명한다.

## 내용
- TeamSpark는 content, image, scheduling, email, analytics를 각각 독립 AI에 맡긴다.
- 각 output은 완성도가 있지만 brand positioning, tone, audience timezone과 다른 agent의 결과를 공유하지 않는다.
- launch 시점에는 메시지가 불일치하고 engagement가 하락하지만 tool 자체는 정상 작동한다.
- 문제는 capability가 아니라 shared goal, memory, planning과 feedback 부재다.
- 해결 방향은 개별 agent 개선보다 전체 목표를 분해하고 성과에 따라 조정하는 coordination layer를 만드는 것이다.

## 예시
```text
isolated agents: content | image | email | analytics
coordinated team: campaign goal -> shared context -> agents -> feedback -> adjustment
```

## 요약
- Task-level automation만으로는 end-to-end outcome을 보장할 수 없으며 agentic AI는 목표 소유와 협업을 추가한다.
