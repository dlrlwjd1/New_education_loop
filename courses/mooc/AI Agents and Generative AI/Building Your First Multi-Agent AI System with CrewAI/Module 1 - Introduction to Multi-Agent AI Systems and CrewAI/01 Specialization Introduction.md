# Specialization Introduction

## 개요
- CrewAI 전문과정 3개 강좌가 multi-agent system을 foundation, 연결·지식, production workflow 순으로 확장하는 구조를 소개한다.

## 내용
- 과정은 prompt 기반 단일 model에서 reasoning·collaboration·scaling을 수행하는 orchestrated system으로의 전환을 다룬다.
- 1강좌는 CrewAI agent design, prompt·context engineering과 첫 multi-agent system을 구축한다.
- 2강좌는 tool, memory, knowledge, agentic RAG와 MCP로 외부 system 접근과 grounded decision을 확장한다.
- 3강좌는 CrewAI Flow, state·routing, guardrail, human-in-the-loop, multi-crew orchestration과 monitoring을 다룬다.
- 최종 목표는 실험적 prompt를 넘어 확장 가능하고 관측 가능한 production agent system을 설계하는 것이다.

## 예시
```text
Course 1: agents/tasks/crews
-> Course 2: tools/memory/RAG/MCP
-> Course 3: flows/guardrails/monitoring
```

## 요약
- 전문과정은 CrewAI 기반 multi-agent application을 기초부터 production 운영까지 단계적으로 구성한다.
