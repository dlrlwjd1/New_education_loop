# Real-World Agentic AI Use Cases

## 개요
- IT support, HR와 recruitment에서 agentic AI가 reactive manual workflow를 proactive automation으로 바꾸는 사례를 살핀다.

## 내용
- IT support agent는 system을 계속 monitoring해 anomaly를 조기에 탐지하고 ticket 발생 전 또는 사용자 영향 전에 대응할 수 있다.
- Password reset·software installation 같은 routine request를 자동 실행하고 ticket을 내용에 따라 정확히 routing한다.
- HR agent는 benefits, leave와 policy 질문에 context-aware response를 제공하고 administrative workflow를 자동화한다.
- Recruitment에서는 resume screening, candidate matching, interview scheduling과 onboarding support를 연결한다.
- 기대 효과는 resolution·hiring cycle 단축, downtime 감소와 직원 경험 개선이지만 중요한 결정에는 policy와 human oversight가 필요하다.

## 예시
```text
IT telemetry -> anomaly agent -> diagnosis -> approved remediation -> outcome monitoring
resume -> screening agent -> scheduler -> onboarding agent
```

## 요약
- Agentic AI는 여러 단계와 system을 연결해 support·HR 업무의 속도, 일관성과 사전 대응 능력을 높인다.
