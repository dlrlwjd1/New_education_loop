# Introduction to Agentic AI

## 개요
- Agentic AI가 context를 해석하고 reason·decide·act하는 방식과 전통적 rule-based agent와의 차이를 소개한다.

## 내용
- Agentic AI는 사용자 goal을 이해하고 필요한 data·tool을 선택해 자율적으로 action을 수행한다.
- 핵심 능력은 language understanding, workflow optimization, multi-agent conversation, action autonomy와 adaptation이다.
- 전통적 agent는 고정 규칙과 제한된 input 안에서 동작해 예상하지 못한 조건에 적응하기 어렵다.
- Agent ecosystem은 user request, database·vector database, LLM reasoning, action과 interaction feedback의 cycle로 구성된다.
- 적용 분야에는 IT automation, robotics, healthcare, finance, smart home·IoT와 cybersecurity가 있다.

## 예시
```text
User -> Agent -> DB/Vector DB -> LLM decision -> API action -> feedback data
```

## 요약
- Agentic AI는 단순 응답이 아니라 목표를 위해 data를 모으고 판단한 뒤 행동하는 adaptive system이다.
