# Difference Between AI Agents and Agentic AI

## 개요
- 특정 task를 수행하는 AI agent와 여러 agent·tool을 조정해 변화하는 목표를 달성하는 agentic AI를 구분한다.

## 내용
- 현대 AI agent는 tool, short/long-term memory, planning·reflection과 action loop를 가질 수 있다.
- AI agent는 대개 단일 목적과 명확한 범위에서 task를 실행한다.
- Agentic AI는 여러 agent·tool 사이의 context를 공유하고 end-to-end objective를 위해 다음 action을 자율적으로 조정한다.
- 단일 agent는 predictable logic, local context와 한 workflow automation에 효율적이다.
- Agentic AI는 여러 system을 가로지르는 workflow, 변화하는 조건, planning·coordination과 outcome ownership이 필요할 때 적합하다.

## 예시
```text
AI agent: 입력 문서 한 개 요약
Agentic AI: 자료 수집 -> 검증 -> 요약 -> 배포 -> 성과에 따른 수정
```

## 요약
- AI agent는 task를 실행하고 agentic AI는 복잡한 목표를 관리·조정하며 완성된 outcome을 추구한다.
