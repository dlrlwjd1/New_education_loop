# Introduction to Context Engineering

> MOOC video · [원본 학습 항목](https://www.mooc.org/learn/multi-agent-ai-system-crewai/lecture/d1Ezg/introduction-to-context-engineering)

## 개요
- 이는 모델이 우리가 기대하는 바를 정확히 파악할 수 있도록 모델이 우리가 기대하는 바를 정확히 파악할 수 있도록 하는 데 중점을 둡니다.

## 내용
- 이는 모델이 우리가 기대하는 바를 정확히 파악할 수 있도록 모델이 우리가 기대하는 바를 정확히 파악할 수 있도록 하는 데 중점을 둡니다.
- 이어서 RAG로 확장하여, 프롬프트에 외부 지식을 보완함으로써 모델이 정확하고 최신 정보를 바탕으로 추론할 수 있도록 프롬프트에 외부 지식을 보완합니다.
- 이와 연계된 것이 바로 ‘기억’으로, 장기적인 통찰력, 선호도 또는 작업별 데이터를 보존하여 모델이 세션 간에 이를 참조할 수 있게 합니다.
- 그리고 프롬프트, 검색, 이력, 기억, 구조 등 이러한 모든 계층을 통합하면 이를 종합하면 ‘컨텍스트 엔지니어링’에 도달하게 됩니다.
- 이는 모델의 추론 방식과 출력 생성에 영향을 미치는 모든 형태의 컨텍스트를 모델이 추론하고 출력을 생성하는 방식에 영향을 미치는 모든 형태의 컨텍스트를 설계, 관리 및 조율하는 포괄적인 학문 분야입니다.
- 컨텍스트 엔지니어링이 토대를 마련하는 반면, 프롬프트 엔지니어링은 예를 들어 “이 기사를 요약해 주세요” 또는 “계획을 생성해 주세요”와 같은 구체적인 지시를 내립니다.
- 이를 통해 연속성이 유지되며, 시스템이 처음부터 다시 시작하는 대신 이전 단계를 바탕으로 작업을 진행할 수 있게 됩니다 처음부터 다시 시작하지 않고 이전 단계를 바탕으로 작업을 진행할 수 있게 해줍니다.

## 예시
- 컨텍스트 엔지니어링이 토대를 마련하는 반면, 프롬프트 엔지니어링은 예를 들어 “이 기사를 요약해 주세요” 또는 “계획을 생성해 주세요”와 같은 구체적인 지시를 내립니다.

## 요약
