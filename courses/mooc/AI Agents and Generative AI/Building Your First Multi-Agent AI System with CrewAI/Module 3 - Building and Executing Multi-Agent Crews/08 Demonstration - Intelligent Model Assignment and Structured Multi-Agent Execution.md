# Demonstration - Intelligent Model Assignment and Structured Multi-Agent Execution

> MOOC video · [원본 학습 항목](https://www.mooc.org/learn/multi-agent-ai-system-crewai/lecture/NidJM/demonstration-intelligent-model-assignment-and-structured-multi-agent-execution)

## 개요
- 지능형 모델 할당 및 구조화된 다중 에이전트 실행에 대한 데모에 오신 것을 환영합니다.

## 내용
- 지능형 모델 할당 및 구조화된 다중 에이전트 실행에 대한 데모에 오신 것을 환영합니다.
- 실제 다중 에이전트 시스템에서 가장 흔한 설계 실수 중 하나는 포트 생성이 아닙니다.
- 모든 에이전트는 해당 작업이 탐색, 심층적 추론, 창의성 또는 평가를 필요로 하는지 여부와 관계없이 탐색, 심층 추론, 창의성 또는 평가가 필요한지 여부와 상관없이 모든 에이전트가 동일한 모델로 구동되고 동일한 방식으로 구성됩니다.
- 이 데모에서는 크루(crew) 클래스 중 지능이 구성되고 실행되는 크루 클래스의 해당 부분을 단계별로 살펴보겠습니다.
- 모델이 어떻게 전문 과정을 거치는지, YAML 식별자를 통해 에이전트가 어떻게 구성되는지, 구조화된 출력을 통해 과제가 어떻게 정의되는지, 그리고 이 모든 것이 어떻게 깔끔하고 의존성 기반의 순차적 파이프라인으로 조립되는지 살펴보겠습니다.
- 설득력 있는 카피를 작성할 수 있는 동일한 모델이 구조화된 점수 산정 논리를 통해 이를 평가할 수도 있습니다.
- AT 크루 데코레이터를 사용하여, 에이전트 목록, 작업 목록, process.sequential-execution 모델, 상세 로깅 활성화, 순차적 실행이 의도된 것으로 설정된 크루 객체를 반환합니다.

## 예시
- 지능형 모델 할당 및 구조화된 다중 에이전트 실행에 대한 데모에 오신 것을 환영합니다.

## 요약
- 설득력 있는 카피를 작성할 수 있는 동일한 모델이 구조화된 점수 산정 논리를 통해 이를 평가할 수도 있습니다. AT 크루 데코레이터를 사용하여, 에이전트 목록, 작업 목록, process.sequential-execution 모델, 상세 로깅 활성화, 순차적 실행이 의도된 것으로 설정된 크루 객체를 반환합니다.
