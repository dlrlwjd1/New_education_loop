## 내용
- 이제 이 모든 내용을 종합하여 에이전트를 진정으로 강력하고, 신뢰할 수 있으며 실제 운영에 바로 적용할 수 있게 만드는 요소가 무엇인지 알아보겠습니다.
- 역할 수행이란 에이전트에게 명확한 인물상, 목표 및 전문 분야를 부여하여 해당 에이전트가 전문 과정을 거친 전문가처럼 행동하도록 하는 것을 말합니다.
- 에이전트는 일반적인 응답을 생성하는 대신, 규정된 역할(예: 규정 준수 분석가, 마케팅 전략가 또는 기술 아키텍트)에 따라 사고하고 응답합니다.
- 또한 문제가 발생했을 때, 에이전트의 책임 범위가 명확하게 정의되어 있으므로 에이전트의 책임 범위가 명확히 정의되어 있기 때문입니다.
- 가장 중요한 점은, 이러한 도구가 내부 모델 지식에만 의존하는 것을 줄이고 시스템을 최신 실제 정보에 기반을 두게 합니다.
- 다중 에이전트 시스템에서 협력이란, 에이전트들이 고립되어 작동하는 대신 함께 협력하여 공동의 목표를 달성하는 것을 의미합니다 각자 따로 움직이는 대신 함께 협력하는 것을 의미합니다.
- 에이전트가 실제 시스템에 배포될 때, 가드레일은 일관된 성능에 필요한 안정성과 안전성을 일관된 성능에 필요한 안정성과 안전성을 보장합니다.
