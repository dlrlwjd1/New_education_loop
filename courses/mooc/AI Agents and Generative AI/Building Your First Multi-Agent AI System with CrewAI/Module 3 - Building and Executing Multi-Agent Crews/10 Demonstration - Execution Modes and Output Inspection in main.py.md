# Demonstration - Execution Modes and Output Inspection in main.py

> MOOC video · [원본 학습 항목](https://www.mooc.org/learn/multi-agent-ai-system-crewai/lecture/Ino1R/demonstration-execution-modes-and-output-inspection-in-main-py)

## 개요
- 나머지 절반은 운영 측면으로, 에이전트 팀을 어떻게 운영할지, 런타임 입력을 어떻게 전달할지, 그리고 결과를 신뢰할 수 있는 방식으로 읽어오는 방법 등이 포함됩니다.

## 내용
- 나머지 절반은 운영 측면으로, 에이전트 팀을 어떻게 운영할지, 런타임 입력을 어떻게 전달할지, 그리고 결과를 신뢰할 수 있는 방식으로 읽어오는 방법 등이 포함됩니다.
- 첫 번째 패턴인 crewResult.pydantic은 실행 결과가 구조화된 pydantic 객체를 반환할 때 사용됩니다.
- 두 번째 패턴인 crewResult.pydantic은 실행 결과가 구조화된 pydantic 객체를 반환할 때 사용됩니다.
- 그 후, 함수는 가장 중요한 부분인 실행 결과에서 캠페인 보고서를 추출하는 단계로 넘어갑니다 을 추출하는 가장 중요한 부분으로 넘어갑니다.
- 이 함수는 다시 태스크 출력 결과를 검색하며, 이번에는 전체 점수 필드가 포함된 `.pedantic` 객체를 찾습니다.
- 그런 다음 종합 점수와 ‘실행 준비 완료’ 또는 ‘실행 전 수정 필요’와 같은 최종 실행 판정을 출력합니다 '출시 전 수정'과 같은 최종 출시 판정을 출력합니다.
- 이 파일은 런타임 입력을 주입하는 방법, 작업별 실행을 관찰하는 방법, 그리고 pedantic을 사용하여 구조화된 출력을 안정적으로 추출하는 방법을 보여줍니다.

## 예시
- 따라서 이번 데모에서는 실행 및 출력 검사를 총괄하는 ‘제어실’인 main.py 파일에 중점을 두고 살펴보겠습니다.

## 요약
- 그런 다음 종합 점수와 ‘실행 준비 완료’ 또는 ‘실행 전 수정 필요’와 같은 최종 실행 판정을 출력합니다 '출시 전 수정'과 같은 최종 출시 판정을 출력합니다. 이 파일은 런타임 입력을 주입하는 방법, 작업별 실행을 관찰하는 방법, 그리고 pedantic을 사용하여 구조화된 출력을 안정적으로 추출하는 방법을 보여줍니다.
