# Agent Collaboration Mechanisms

> MOOC video · [원본 학습 항목](https://www.mooc.org/learn/multi-agent-ai-system-crewai/lecture/tySvi/agent-collaboration-mechanisms)

## 개요
- 지금까지 개별 에이전트가 어떻게 작동하는지 살펴보았지만, 에이전트들이 더 이상 서서히 조화를 이루는 팀으로 기능하기 시작할 때 비로소 진정한 힘이 발휘됩니다.

## 내용
- 지금까지 개별 에이전트가 어떻게 작동하는지 살펴보았지만, 에이전트들이 더 이상 서서히 조화를 이루는 팀으로 기능하기 시작할 때 비로소 진정한 힘이 발휘됩니다.
- 이번 영상에서는 크루 AI에서 협업이 어떻게 이루어지는지, 그리고 이를 효과적으로 구현하는 방법을 알아보겠습니다.
- 협업이란 에이전트들이 독립적으로 작동하는 대신, 질문을 하고, 서로의 전문 지식을 활용하는 등, 독립적으로 운영되는 대신 조율된 팀으로서 기능하는 능력입니다.
- 또한 작업 수행 중에 구체적인 질문을 통해 누락된 정보를 수집하거나 요구 사항을 명확히 할 수도 있습니다.
- 또한 업무 위임이 어떻게 이루어지는지 명확하게 파악하기 위해, 상세 로그를 활성화하여 협업 행동을 단계별로 모니터링할 수 있습니다.
- 셋째, 이러한 접근 방식은 작업의 순서와 감독이 체계적으로 순서 지정과 감독이 필요한 복잡한 다단계 프로젝트에 가장 효과적입니다.
- 에이전트가 역할과 작업 요구 사항에 따라 에이전트가 어떻게 작업을 위임하고, 질문을 하고, 조율하는지 살펴보았습니다.

## 예시
- 에이전트가 역할과 작업 요구 사항에 따라 에이전트가 어떻게 작업을 위임하고, 질문을 하고, 조율하는지 살펴보았습니다.

## 요약
- 셋째, 이러한 접근 방식은 작업의 순서와 감독이 체계적으로 순서 지정과 감독이 필요한 복잡한 다단계 프로젝트에 가장 효과적입니다. 에이전트가 역할과 작업 요구 사항에 따라 에이전트가 어떻게 작업을 위임하고, 질문을 하고, 조율하는지 살펴보았습니다.
