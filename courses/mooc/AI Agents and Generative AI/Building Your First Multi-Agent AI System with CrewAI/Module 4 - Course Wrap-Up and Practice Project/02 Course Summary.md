# Course Summary

## 개요
- 여러분은 단일 에이전트 아키텍처와 다중 에이전트 아키텍처의 차이점을 배웠으며, 다중 에이전트 시스템이 더 복잡한 문제 해결을 가능하게 하는지 배웠습니다.

## 내용
- 여러분은 단일 에이전트 아키텍처와 다중 에이전트 아키텍처의 차이점을 배웠으며, 다중 에이전트 시스템이 더 복잡한 문제 해결을 가능하게 하는지 배웠습니다.
- 또한 완전한 CrewAI 개발 환경을 구축하여, 에이전트 기반 애플리케이션을 빌드하고 에이전트 기반 애플리케이션을 구축하고 실행할 수 있도록 시스템을 준비했습니다.
- 이러한 기초를 바탕으로, 다중 에이전트 워크플로우를 위한 플로우 엔지니어링을 탐구하며, 에이전트가 작업을 조정하고 컨텍스트를 공유하는 방법을 배웠습니다.
- 마지막으로, 에이전트 크루를 운영하고 관리하는 방법을 배웠으며, 명령줄에서 전체 워크플로를 실행하고 실제 AI 시스템을 조율하는 방법을 배웠습니다.
- AI 자동화 엔지니어로서, 조직 전반에 걸쳐 복잡한 워크플로를 자동화하는 시스템을 설계할 수도 있습니다 조직 전반에 걸쳐 복잡한 워크플로를 자동화하는 시스템을 설계할 수도 있습니다.또한 LLM 애플리케이션 개발자가 되어, 또한 LLM 애플리케이션 개발자가 되어 대규모 언어 모델을 기반으로 한 첨단 AI 솔루션을 개발할 수도 있습니다.
- 혹은 AI 솔루션 아키텍트로서, 실제 문제를 해결하는 확장 가능한 AI 시스템을 설계하는 역할을 맡을 수도 있습니다 문제를 해결하는 확장 가능한 AI 시스템을 설계할 수도 있습니다.
- 이제 여러분은 AI 에이전트를 설계하고, 구조화된 워크플로를 구축하며, 다중 에이전트 시스템을 조율할 수 있는 지식과 실무적 이해를 갖추게 되었습니다.

## 예시
- 이어서, 작업 설계와 구조화된 출력 생성을 실습하여 에이전트가 신뢰할 수 있고 활용 가능한 결과를 산출할 수 있도록 했습니다.

## 요약
