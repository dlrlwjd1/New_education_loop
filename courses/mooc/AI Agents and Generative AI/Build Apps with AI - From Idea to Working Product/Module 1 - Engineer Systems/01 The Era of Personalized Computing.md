# The Era of Personalized Computing

## 개요
- 이 강좌의 도입 강의. "개인용 컴퓨터(personal computer)"라는 이름과 달리 실제로는 전혀 개인화되지 않았던 소프트웨어의 현실을 지적하고, AI가 이를 어떻게 진정한 **"개인화 컴퓨팅(personalized computing)"**의 시대로 바꾸는지 소개한다.

## 내용
### 기존 "개인용 컴퓨터"의 역설
- 우리가 쓰는 노트북/데스크톱은 "개인용"이라 불리지만, 실제로는 **소프트웨어 엔지니어들이 대량 생산한 소프트웨어**로 가득하다.
- 엔지니어들이 "이렇게 써야 한다"고 한 번 설계하고 대량으로 만들어 배포하면, 모든 사람이 같은 방식으로 써야 한다.
- 게다가 이런 도구들은 서로 잘 연동되지 않고, **사용자가 실제로 문제를 생각하는 방식과 다르게** 동작하는 경우가 많다.

### AI가 여는 새로운 가능성
- 이제는 AI 덕분에 **원하는 대로 분석하고, 시각화하고, 소프트웨어를 만들고, 계산할 수 있게** 되었다.
- 더 이상 "내 방식과 안 맞는 기성 도구"를 억지로 써야 하는 세상에 살지 않아도 된다.
- 다만 이를 위해서는 **컴퓨팅에 접근하는 사고방식의 전환(mentality shift)**이 필요하다 — 이 강좌가 가르치는 것이 바로 이것.

### 실전 시연 — 개인 맞춤 예산 관리 앱을 한 번의 프롬프트로 만들기
- 밴더빌트에서 만든 도구 **MAJK(Magic)**를 예시로 사용 (다른 여러 도구도 이 강좌에서 다룰 예정 — 일반 원칙을 배우고 원하는 도구에 적용하면 됨).
- 시중의 예산 관리 앱들은 "누군가 다른 사람이 생각한 예산 관리 방식"일 뿐, 저자가 원하는 방식과 정확히 맞지 않았음.
- 해결: 원하는 기능/요구사항을 직접 적어서 프롬프트로 제시:
  > "신용카드 영수증과 은행 명세서를 임포트하고, 지출 트렌드와 잊고 있던 반복 구독을 식별하고, 모든 지출을 카테고리화해서 돈이 어디로 가는지 이해하도록 돕는 개인 예산 관리 앱의 요구사항을 작성했습니다. README 파일의 요구사항을 읽고 완전한 웹 애플리케이션을 만들어주세요."
- AI의 진행: 요구사항을 이해했다고 응답 → 기술적 세부사항 결정(버전 관리 설정 등 — 나중에 문제가 생기면 롤백 가능하도록) → 몇 분 후 완성된 앱과 실행 방법 안내.
- **비개발자도 기술적 세부사항에 얽매이지 않고 소통할 수 있는 방법**을 이 강좌에서 다룰 예정 (예: 실행 명령어를 직접 치는 대신 "실행해줘"라고 요청하는 식).

### 완성된 결과물
- 요청한 요구사항이 모두 반영된, **아름답게 디자인된** 개인 맞춤 예산 관리 앱 완성:
  - 명세서 임포트 기능
  - 임포트된 개별 거래 내역
  - 반복 구독 자동 감지
  - 지출 카테고리 분류
  - **은행 계좌 직접 연동 없이, 다운로드한 명세서를 AI가 읽어서 거래 내역을 자동 추출**하는 기능(요청했던 대로)

### 핵심 통찰 — "AI가 내장된 나만의 앱을 만들 수 있다"
- 단순히 개인화된 앱을 만드는 것을 넘어, **앱 안에 AI 자체를 통합**시킬 수도 있다 (예: 명세서를 AI로 읽어 자동으로 거래를 추출하는 기능).
- 즉, "나만을 위한 맞춤 솔루션"을 만들면서 동시에 그 솔루션 안에 AI 기능까지 내장시키는 것이 가능하다.

### 요구사항의 정도에 따른 선택
- **딱 원하는 대로 만들고 싶다면**: 요구사항을 상세히 적어서 제공.
- **AI가 알아서 판단해도 괜찮다면**: 그냥 "개인 예산 관리 앱을 만들어줘"라고만 요청해도 충분 — 다만 이 경우 결과가 자신의 요구와 정확히 맞지 않을 수 있음.

### 이 강좌의 목표 — "당신은 이제 당신 회사의 CEO다"
- 이 강좌를 마칠 때 느꼈으면 하는 것: **"나는 내 회사의 CEO다."**
- 컴퓨터로 할 수 있는 것이라면 무엇이든, **AI를 개인 PhD 팀처럼 활용**해 요청하고 실현할 수 있다.
- 필요한 것은 기술적 경험이 아니라, **창의성과 AI를 자신의 팀처럼 대하는 태도**뿐이다.

## 예시
```
프롬프트: "I wrote down a set of requirements for a personal budgeting application that can import
my credit card receipts and my bank statements, help me identify spending trends, recurring subscriptions
I may have forgotten about, and categorize all of my spending. Read the requirements in the README file
and then build out a complete web application that can do this."
```

## 요약
- 기존의 "개인용 컴퓨터"는 실제로 개인화되지 않은 대량 생산 소프트웨어로 채워져 있었지만, AI는 **진짜 나만을 위한 맞춤 소프트웨어**를 만들 수 있게 해준다.
- 원하는 요구사항을 적어서 AI에게 주면, 비개발자도 완전한 웹 애플리케이션을 한 번의 프롬프트로 만들 수 있으며, 그 앱 안에 AI 기능까지 통합시킬 수 있다.
- 이 강좌의 목표는 "AI를 개인 PhD 팀처럼 부리며, 컴퓨터로 할 수 있는 무엇이든 스스로 만들어내는 CEO의 태도"를 갖추는 것이다.
