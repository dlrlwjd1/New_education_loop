# The Mental Model for Working with AI Agents

## 개요
- 이 강좌 전체를 관통하는 **핵심 멘탈 모델(mental model)** — "내 컴퓨터를 컴퓨터공학 박사(CS PhD)에게 맡긴다"는 비유를 소개하는 강의.

## 내용
### 핵심 비유 — "내 컴퓨터를 CS PhD에게 맡긴다"
- 만약 당신이 회사의 CEO이고, **컴퓨터공학 박사를 개인 컴퓨팅 전문가로 고용**할 수 있다면 어떻게 할까?
- 노트북을 그 PhD에게 건네주고 "이 컴퓨터, 이제 내가 다시는 만질 필요 없이 당신이 알아서 해줬으면 좋겠다. 나는 그냥 내가 이루고 싶은 목표와 필요한 것들만 말할 테니, 당신이 이 컴퓨터로 알아서 실현해달라"고 말할 것이다.
- 그 PhD는 컴퓨터의 모든 애플리케이션에 능통하고, 정보를 읽고 이해할 수 있고, 필요하면 코드도 작성할 수 있는 전문가다.
- 진짜 원하는 것은 바로 이것 — **컴퓨터가 나의 창의성과 일을 뒷받침해야지, 인지 부하를 더하는 장벽이 되어서는 안 된다.**

### AI 에이전트 = "번역가"로서의 역할
- AI는 힌디어와 영어, 독일어와 스페인어처럼 **언어 간 번역**을 할 수 있듯, **"내가 쓰는 언어"와 "내 컴퓨터가 이해하는 언어" 사이도 번역**할 수 있다.
- 그래서 AI 에이전트에게 일을 맡기는 것은 곧 "컴퓨터를 CS PhD에게 맡기는 것"과 같다 — AI가 나와 대화하는 동시에, **뒤에서 내 컴퓨터와도 대화**하며 일을 처리한다.

### 실전 시연 — 출장 경비 보고서 자동 생성
- 프롬프트(Magic 도구에서): "이 폴더에 최근 출장 경비 자료가 있어. 경비 보고 프로세스도 들어있어. 이걸로 경비 보고서를 만들어줘."
- 핵심: **고수준의 지시만 주고 세부사항은 AI가 알아서 찾아내게** 한다 ("가서 알아내라"는 태도로 지시).

### "도구(tools)" = 에이전트가 컴퓨터와 대화하는 방식
- **에이전트(agent) = 도구(tools)를 가진 AI.**
- 도구는 AI가 컴퓨터에게 메시지를 보내 행동을 지시하거나 정보를 수집하게 해주는 수단이며, 컴퓨터는 그 메시지에 대한 결과를 다시 돌려준다.
- 실제 화면에서는 `bash`, `read`, `write` 같은 동작들이 나타나는데, 이것이 바로 **AI가 컴퓨터와 나누는 대화**다.
- AI는 "경비 프로세스를 읽고, 영수증들을 읽고, 경비 보고서로 변환해줘"라는 고수준 요청을, **컴퓨터가 이해할 수 있는 여러 개의 작은 "도구 호출" 메시지들로 스스로 분해**한다.
- 컴퓨터 자체는 그렇게 똑똑하지 않기 때문에, **AI가 고수준 목표를 잘게 쪼개는 역할**을 담당한다.

### 결과물
- AI가 작업 완료 후 요약 보고: 요청한 형식에 맞춘 CSV 파일(모든 경비 내역 포함)과, 경비 요약·정보를 보여주는 **대시보드**까지 생성.

### 이 강좌의 핵심 멘탈 모델 정리
- "Magic"이나 "Claude Code" 같은 도구로 작업한다는 것은, **내 컴퓨터를 CS 박사에게 맡기는 것**과 같다.
- 고수준의 목표를 저수준 세부사항(어떤 파일을 읽고, 어떤 코드를 쓰고 등)으로 변환하는 부담에서 벗어나게 된다.
- CS PhD에 비유하는 이유: AI는 폴더 확인·파일 읽기 같은 일반적 작업부터, 코드 작성·실행처럼 코더가 아니면 하기 힘든 일까지 **모두 컴퓨터의 언어로 실현**할 수 있기 때문.
- **결론적으로 이 강좌 내내 취해야 할 태도**: 저수준을 고민하지 말고, "이 폴더를 봐줘, 이 정책을 읽어줘, 경비 보고서를 만들어줘" 같은 방식으로 **AI에게 직접 말을 걸며 원하는 것을 실현시키는 것.**

## 예시
```
프롬프트: "Look in this folder, it has expenses for my latest trip, and it includes the expense reporting process.
I need you to build an expense report for me."
```
→ AI가 폴더 탐색(bash/read) → 정책·영수증 읽기(read) → CSV 생성(write) → 대시보드 생성까지 자동 수행.

## 요약
- 이 강좌의 핵심 멘탈 모델은 **"내 컴퓨터를 CS 박사에게 맡긴다"**는 것 — AI 에이전트에게 고수준 목표만 말하면, 저수준 실행은 AI가 알아서 처리한다.
- **에이전트 = 도구(tools)를 가진 AI**이며, 도구는 AI가 컴퓨터와 대화하는 수단이다. AI는 고수준 요청을 여러 개의 작은 도구 호출로 스스로 분해한다.
- 이 강좌 내내 유지해야 할 태도는 저수준 실행 방법을 고민하지 않고, **원하는 목표를 있는 그대로 AI에게 말하고 맡기는 것**이다.
