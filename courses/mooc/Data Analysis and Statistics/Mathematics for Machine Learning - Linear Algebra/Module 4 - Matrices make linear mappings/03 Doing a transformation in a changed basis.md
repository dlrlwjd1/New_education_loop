# 03 Doing a transformation in a changed basis

## 개요
- 강좌: Mathematics for Machine Learning - Linear Algebra (Imperial College London)
- 모듈: Module 4 — Matrices make linear mappings
- 강사: David Dye
- [MOOC 원본 강의](https://www.mooc.org/learn/linear-algebra-machine-learning/lecture/Dk7MB/doing-a-transformation-in-a-changed-basis)
- ⭐⭐ **`B⁻¹ R B`** — 낯선 기저에서 변환을 수행하는 공식. **PCA로 이어지는 준비.**

---

## 내용

### 문제
곰의 기저는 **(3, 1)** 과 **(1, 1)**. 곰의 기저에서 정의된 벡터 `(x, y)` 를 **45도 회전**시키고 싶다.

> ⚠️ **문제는 곰의 이상한 좌표계에서 45도 회전을 어떻게 쓰는지 모른다는 것**이다. **나는 내 평범한 (1,0),(0,1) 좌표계에서만 45도 회전을 쓸 줄 안다.**

**내 세계에서의 45도 회전**
```
(1, 0) → 1/√2 · (1, 1)
(0, 1) → 1/√2 · (−1, 1)

R = 1/√2 · ⎡ 1  −1 ⎤
           ⎣ 1   1 ⎦
```

### 해법 — 세 단계 ⭐⭐
1. **곰의 벡터를 내 기저로 옮긴다** → **B** 를 곱한다
2. **내 기저에서 회전한다** → **R** 을 곱한다
3. **결과를 다시 곰의 기저로 되돌린다** → **B⁻¹** 을 곱한다

```
곰의 좌표계에서의 회전 = B⁻¹ R B
```

**B⁻¹ 구하기**: 주대각선 항을 뒤집고 비대각 항에 마이너스를 붙인 뒤 **행렬식(=2)으로 나눈다** → ½을 곱한다.

> ⭐ **이것이 곰의 좌표계에서 본 45도 회전이다. 내 표준 기저에서의 것과 완전히 다르다.**
>
> ⚠️ **머릿속으로 직관하기 쉽거나 자명하지 않다. 계산을 해야 한다.**

### 핵심 교훈 ⭐
> **어떤 이상한 기저에서 변환을 하고 싶다면 `B⁻¹ R B` 라는 이 식이 아주 유용하다.**
>
> **한 걸음 물러서서 보면 — 정규 좌표계로 변환하면 변환 행렬 자체도 바뀐다는 것을 유념해야 한다.**
>
> **이것은 늘 보게 되는 대수 형태다. 변환 행렬 R이 B와 B⁻¹ 로 감싸여 있고, 그 B들이 내 세계와 새 기저 체계의 세계 사이의 변환을 한다.**

### 두 강의를 마치며
> 이 두 강의에서 한 것: **기저를 바꿀 때 벡터의 숫자가 어떻게 바뀌는지**, **좌표계**, **직교가 아닌 좌표계에서 변환을 하는 법.**
>
> **꽤 힘든 작업이었지만, 이것이 예컨대 주성분분석(PCA)에서 서로 다른 기저 체계로 작업할 수 있게 준비시켜 준다.**

---

## 요약
- ⭐⭐ **`B⁻¹ R B`** — 낯선 기저에서 변환 R을 수행하는 법. **B로 내 세계로 → R로 변환 → B⁻¹로 되돌리기.**
- 결과 행렬은 **표준 기저에서의 것과 완전히 다르며 직관으로 알 수 없다. 계산해야 한다.**
- **변환 행렬 R이 B와 B⁻¹ 로 감싸인 이 형태는 선형대수에서 늘 나온다.**
- 이 준비가 **PCA**로 이어진다.
