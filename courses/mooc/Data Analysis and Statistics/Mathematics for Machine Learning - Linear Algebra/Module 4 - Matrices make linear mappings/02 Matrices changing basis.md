# 02 Matrices changing basis

## 개요
- 강좌: Mathematics for Machine Learning - Linear Algebra (Imperial College London)
- 모듈: Module 4 — Matrices make linear mappings
- 강사: David Dye
- [MOOC 원본 강의](https://www.mooc.org/learn/linear-algebra-machine-learning/lecture/q8iik/matrices-changing-basis)
- ⭐ **행렬로 기저를 바꾸는 법.** 직교가 아닌 기저에서도 통한다. **판다 곰(Panda Bear)의 세계** 비유.

---

## 내용

### 설정 — 곰의 기저 ⭐
| | 기저 벡터 |
|---|---|
| **내 세계(파란색)** | ê₁ = (1, 0), ê₂ = (0, 1) |
| **곰의 세계(주황색)** | 내 좌표로 **(3, 1)** 과 **(1, 1)** |

곰의 변환 행렬:
```
B = ⎡ 3  1 ⎤       ← 곰의 기저를 내 좌표로 적은 것
    ⎣ 1  1 ⎦
```

### 곰의 벡터 → 내 세계 ⭐
곰의 세계에서 벡터가 `(3/2, 1/2)` 이라면:
```
B · (3/2, 1/2)
= 3×(3/2) + 1×(1/2) = 9/2 + 1/2 = 5
= 1×(3/2) + 1×(1/2) = 3/2 + 1/2 = 2
→ (5, 2)  in my world
```
> **같은 대상**이다. 곰의 벡터 `(3/2, 1/2)` = 내 벡터 `(5, 2)`.

> ⚠️ **이 변환 행렬 B는 "내 좌표계로 적은 곰의 기저"이고, 곰의 벡터를 내 세계로 옮긴다.** 그런데 **보통은 내 세계를 곰의 세계로 옮기고 싶다.**

### 내 벡터 → 곰의 세계: 역행렬 ⭐
```
B⁻¹ = 1/det(B) · ⎡  1  −1 ⎤ = 1/2 · ⎡  1  −1 ⎤
                 ⎣ −1   3 ⎦          ⎣ −1   3 ⎦

det(B) = 3×1 − 1×1 = 2
```
> ⭐ **B⁻¹ 는 "곰의 좌표계로 적은 내 기저"** 다. 내 (1,0)은 곰의 세계에서 `½(1, −1)`, 내 (0,1)은 `½(−1, 3)`.

**검산**: `½(1, −1)` 을 곰의 기저로 조합하면 → `½(3−1, 1−1) = ½(2, 0) = (1, 0)` ✓

**적용**: 내 벡터 `(5, 2)` 에 B⁻¹ 을 곱하면 → **곰의 벡터 `(3/2, 1/2)`** 로 되돌아온다 ✓

> ⚠️ **꽤 직관에 반한다** — **곰의 벡터를 내 세계로 옮기려면 "내 좌표로 적은 곰의 기저"가 필요하고, 반대로 하려면 "곰의 좌표로 적은 내 기저"가 필요하다.**

### 정규직교 기저인 경우 — 훨씬 쉽다 ⭐
곰의 기저가 **단위 길이이고 직교**라면:
```
B = 1/√2 · ⎡ 1  −1 ⎤        det(B) = 1
           ⎣ 1   1 ⎦
```
> **행렬식이 1**이라 모든 것이 쉬워진다. 역행렬은 **주대각선은 그대로, 비대각선의 부호만 뒤집으면** 된다(2×2이므로).

**그리고 내적만으로도 된다** ⭐⭐
> [모듈 2](../Module%202%20-%20Vectors%20are%20objects%20that%20move%20around%20space/05%20Changing%20basis.md)에서 **새 기저가 직교하면 투영만으로 기저 변환이 된다**고 했다. 확인해 보면:
```
내 벡터 1/√2·(1, 3) 을 곰의 축들과 내적:

첫 축과: 1/√2 × 1/√2 × (1 + 3) = ½ × 4 = 2
둘째 축과: 1/√2 × 1/√2 × (−1 + 3) = ½ × 2 = 1

→ 곰의 벡터 (2, 1)  ✓
```
> ⚠️ **길이로 정규화하는 것을 잊지 말아야 하는데, 이 경우 길이가 모두 1이라 정말 쉽다.**
>
> ⭐ **곰의 벡터가 직교면 복잡한 행렬 계산 없이 내적만으로 된다.**

### ⚠️ 마지막 경고
> 앞의 예제, 즉 곰의 기저가 **(3,1)과 (1,1)** 인 경우로 내적을 시도하면 **통하지 않는다.** **서로 직교가 아니기 때문**이다.
>
> **직교가 아니면 행렬 변환으로는 여전히 할 수 있지만 내적으로는 할 수 없다.**

---

## 요약
- **B = 내 좌표로 적은 상대의 기저.** → **상대의 벡터를 내 세계로** 옮긴다.
- **B⁻¹ = 상대 좌표로 적은 내 기저.** → **내 벡터를 상대 세계로** 옮긴다. (직관에 반하니 주의)
- **기저가 정규직교면** 행렬식이 1이라 역행렬이 쉽고, ⭐ **내적(투영)만으로 기저 변환이 된다.**
- ⚠️ **직교가 아니면 내적으로는 안 되고 반드시 행렬을 써야 한다.**
