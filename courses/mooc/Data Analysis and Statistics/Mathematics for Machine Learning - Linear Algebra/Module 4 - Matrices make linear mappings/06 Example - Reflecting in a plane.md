# 06 Example: Reflecting in a plane

## 개요
- 강좌: Mathematics for Machine Learning - Linear Algebra (Imperial College London)
- 모듈: Module 4 — Matrices make linear mappings
- 강사: David Dye
- [MOOC 원본 강의](https://www.mooc.org/learn/linear-algebra-machine-learning/lecture/oXE0Y/example-reflecting-in-a-plane)
- ⭐ **이 강좌에서 가장 긴 강의.** 그람-슈미트 + 기저 변환 + 변환을 **모두 합쳐** 이상한 각도의 거울에 비친 모습을 구한다.

---

## 내용

### 문제 설정
> **이상한 각도로 놓인 거울에 비친 모습이 나에게 어떻게 보일까?**
>
> 강사의 예: **화이트보드에 글을 쓰면 보는 사람에게는 거울처럼 뒤집혀 보인다.** 그래서 **후반 작업에서 좌우를 반사**해 제대로 나오게 만든다.

⚠️ **첫 번째 난관: 거울의 평면을 잘 모른다.** 아는 것은 —

| 벡터 | 값 | 위치 |
|---|---|---|
| **v₁** | (1, 1, 1) | **거울 평면 안** |
| **v₂** | (2, 0, 1) | **거울 평면 안** |
| **v₃** | (3, 1, −1) | **평면 밖** |

### 1단계 — 그람-슈미트로 정규직교 기저 만들기 ⭐

**e₁**
```
|v₁| = √(1² + 1² + 1²) = √3
e₁ = 1/√3 · (1, 1, 1)
```

**e₂**
```
u₂ = v₂ − (v₂ · e₁)·e₁
   = (2,0,1) − [(2,0,1)·(1,1,1)/√3] · (1/√3)(1,1,1)
   ← (2,0,1)·(1,1,1) = 2 + 0 + 1 = 3, √3들이 밖으로 나와 1/3
   ← 3 × 1/3 = 1
   = (2,0,1) − (1,1,1)
   = (1, −1, 0)

|u₂| = √2
e₂ = 1/√2 · (1, −1, 0)
```

**e₃**
```
u₃ = v₃ − (v₃ · e₁)·e₁ − (v₃ · e₂)·e₂
   ← (3,1,−1)·(1,1,1) = 3 + 1 − 1 = 3  → 1/√3 항들과 만나 1
   ← (3,1,−1)·(1,−1,0) = 3 − 1 − 0 = 2 → 1/√2 항들(½)과 만나 1
   = (3,1,−1) − (1,1,1) − (1,−1,0)
   = (1, 1, −2)

e₃ = 1/√6 · (1, 1, −2)
```

> ⚠️ 강사의 고백: **"인정한다, 예제를 (계산이 깔끔하게 떨어지도록) 손봤다."**

**검산**: (1,1,−2)는 (1,−1,0)과 직교하고 (1,1,1)과도 직교하며, **셋 다 단위 길이**다. ✓

### 2단계 — 변환 행렬 E
```
E = [ e₁ | e₂ | e₃ ]      ← e₁, e₂, e₃ 를 열벡터로
```
> ⭐ **이 행렬은 먼저 평면(e₁, e₂)을 담고 그다음 평면의 법선(e₃)을 담는다.**

### 남은 절차 (이 기저에서의 반사)
> 이 정규직교 기저에서는 **거울 반사가 아주 간단하다** — **평면 안의 두 성분(e₁, e₂)은 그대로 두고 법선 성분(e₃)의 부호만 뒤집으면** 된다.
>
> 그다음 [앞 강의](03%20Doing%20a%20transformation%20in%20a%20changed%20basis.md)의 **`E⁻¹ R E`** 공식으로 원래 좌표계에서의 반사 행렬을 얻는다. ⚠️ **E가 직교행렬이므로 `E⁻¹ = Eᵀ`** 라 계산이 아주 쉽다.

> ※ 이 마지막 계산 단계는 자막에서 화면의 판서에 의존해 진행되어 **정리본에서는 절차만 적었다.** 구체적인 수치는 **원본 영상**을 참조할 것.

## 요약
- 문제: **이상한 각도의 거울에 비친 벡터**를 구하기. 아는 것은 **평면 안의 두 벡터와 평면 밖의 한 벡터**뿐이다.
- **① 그람-슈미트**로 `e₁ = (1,1,1)/√3`, `e₂ = (1,−1,0)/√2`, `e₃ = (1,1,−2)/√6` 를 만든다.
- **② 이 기저의 행렬 E**는 **평면 두 축 + 법선**으로 구성된다.
- **③ 이 기저에서는 반사가 "법선 성분의 부호만 뒤집기"** 로 아주 단순해진다.
- **④ `E⁻¹ R E` 로 원래 좌표계로 되돌린다.** E가 직교행렬이라 **`E⁻¹ = Eᵀ`**.
- ⭐ **어려운 변환을 쉬운 기저로 옮겨 푸는 것** — 이것이 이 모듈 전체의 요지이고 **PCA의 발상**이기도 하다.
