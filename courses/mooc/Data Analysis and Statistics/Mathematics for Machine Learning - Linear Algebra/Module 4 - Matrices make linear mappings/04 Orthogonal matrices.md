# 04 Orthogonal matrices

## 개요
- 강좌: Mathematics for Machine Learning - Linear Algebra (Imperial College London)
- 모듈: Module 4 — Matrices make linear mappings
- 강사: David Dye
- [MOOC 원본 강의](https://www.mooc.org/learn/linear-algebra-machine-learning/lecture/uYJRz/orthogonal-matrices)
- ⭐⭐ **직교행렬(orthogonal matrix)** — **역행렬이 전치(transpose)와 같은** 가장 편리한 행렬.

---

## 내용

### 전치(transpose) ⭐
> **행과 열의 모든 원소를 서로 바꾸는** 연산. 표기는 위첨자 **T**.
```
(Aᵀ)ᵢⱼ = Aⱼᵢ

⎡ 1  2 ⎤ᵀ = ⎡ 1  3 ⎤
⎣ 3  4 ⎦     ⎣ 2  4 ⎦
```
> **주대각선 원소(1,1)·(2,2)는 그대로 있고**, (1,2)와 (2,1)이 서로 바뀐다.

### 정규직교 기저 집합의 조건 ⭐
n×n 행렬 A의 열들이 새 공간의 기저 벡터 a₁, a₂, …, aₙ 이라 하고, **다음 조건을 부과**한다.
```
aᵢ · aⱼ = 0    (i ≠ j)      ← 서로 직교
aᵢ · aⱼ = 1    (i = j)      ← 단위 길이
```

### 마법 같은 결과 ⭐⭐
**Aᵀ를 왼쪽에서 곱하면** — Aᵀ의 행들은 A의 열들(a₁, a₂, …)이다.
```
(AᵀA)₁₁ = a₁ · a₁ = 1
(AᵀA)₁₂ = a₁ · a₂ = 0
(AᵀA)₁₃ = a₁ · a₃ = 0
…
```
> **점점 항등행렬이 쌓인다.**
```
Aᵀ A = I
```
> ⭐⭐ **즉 Aᵀ가 A의 유효한 역행렬이다.** 강사: **"정말 꽤 깔끔하다."**

### 이름 ⭐
| 용어 | 뜻 |
|---|---|
| **정규직교 기저 집합(orthonormal basis set)** | 서로 수직이고 모두 단위 길이인 기저 벡터들 |
| **직교행렬(orthogonal matrix)** | 그것들로 이루어진 행렬 |

### 행렬식은 ±1 ⭐
> 기저 벡터가 모두 단위 길이이므로 **공간을 1배로만 스케일해야 한다.**
```
det(직교행렬) = +1 또는 −1
```
> **−1은 새 기저 벡터 집합이 공간을 뒤집는 경우**에 나온다 — **왼손 좌표계**가 된다.

### 행도 정규직교다
> Aᵀ가 역행렬이라면 **A를 오른쪽에서 곱해도 항등행렬**이 나와야 한다(`A Aᵀ = I`).
>
> **같은 논리로 직교행렬의 행들도 열들과 마찬가지로 정규직교**다.
>
> 그리고 [앞 강의](02%20Matrices%20changing%20basis.md)에서 봤듯 **역행렬은 역변환을 하는 행렬**이므로, **정규직교 기저 벡터 집합의 전치 행렬은 그 자체로 또 하나의 직교 기저 벡터 집합**이다.

### 데이터 과학에서의 의미 ⭐⭐
> **가능하다면 데이터를 변환할 때 정규직교 기저 벡터 집합을 쓰고 싶다. 즉 변환 행렬이 직교행렬이기를 원한다.**

| 이득 |
|---|
| **역행렬 계산이 쉽다** (그냥 전치) |
| **변환이 되돌릴 수 있다** — 공간을 붕괴시키지 않으므로 |
| **투영이 그냥 내적**이다 |
| **행렬식이 1**이 되게 기저 순서를 정할 수 있고, **아니면 두 개를 맞바꾸면 −1이 +1이 된다** |

---

## 요약
- **전치 `(Aᵀ)ᵢⱼ = Aⱼᵢ`** — 행과 열을 바꾼다.
- ⭐⭐ **열들이 정규직교(직교 + 단위 길이)이면 `AᵀA = I`, 즉 `A⁻¹ = Aᵀ`.** 이런 행렬을 **직교행렬**이라 한다.
- **행렬식은 ±1.** −1이면 좌표계가 뒤집힌(왼손) 것이다.
- **행도 열과 마찬가지로 정규직교**다.
- ⭐ **데이터 과학에서는 되도록 직교행렬로 변환하라** — 역행렬이 전치, 되돌릴 수 있고, 투영이 내적이 된다.
