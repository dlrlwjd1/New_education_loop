## 내용

### 출발 가정
> **관심 있는 공간을 span 하는 선형독립 벡터들 v₁, v₂, …, vₙ 이 이미 있다**고 가정한다.
>
> ⚠️ **선형독립을 확인하려면** 그 벡터들을 열로 하는 행렬을 쓰고 **행렬식이 0이 아닌지 보면 된다.** 선형종속이면 행렬식이 0이다.
>
> 다만 이 벡터들은 **서로 직교하지도 단위 길이도 아니다.** 그래서 정규직교 기저를 만들고 싶다.

### 절차 ⭐

**1단계 — v₁은 무사히 살아남는다**
> 첫 벡터는 **정규화만** 한다.
```
e₁ = v₁ / |v₁|
```

**2단계 — v₂에서 e₁ 성분을 뺀다**
> **v₂는 두 가지로 구성된다고 볼 수 있다** — **e₁ 방향 성분** + **e₁에 수직인 성분**.
>
> e₁ 방향 성분은 **v₂를 e₁에 벡터 투영**한 것이다. **e₁의 길이가 1이므로 나눌 필요가 없다.**
```
u₂ = v₂ − (v₂ · e₁)·e₁
e₂ = u₂ / |u₂|
```
> **e₂는 e₁과 90도**를 이룬다.

**3단계 — v₃에서 e₁, e₂ 성분을 모두 뺀다**
> v₃는 v₁, v₂의 선형결합이 아니므로 **v₁, v₂가 정의하는 평면 위에 있지 않다.** 즉 **e₁, e₂ 평면 위에도 없다.**
>
> **v₃를 e₁·e₂ 평면으로 투영한 것**을 빼면 **평면에 수직인 벡터만 남는다.**
```
u₃ = v₃ − (v₃ · e₁)·e₁ − (v₃ · e₂)·e₂
e₃ = u₃ / |u₃|
```

**계속** — 모든 vₙ에 대해 반복해 **원래 공간을 span 하기에 충분한 정규직교 기저 벡터**를 얻을 때까지.

### 왜 이 고생을 하는가 ⭐
> **어색하고 직교도 아니고 단위 길이도 아닌 벡터 다발에서, 멋진 직교 단위 벡터 다발 — 정규직교 기저 집합 — 으로 갔다.**

그러면 [앞 강의](04%20Orthogonal%20matrices.md)의 이득을 전부 얻는다.

- **변환 행렬이 좋아진다**
- **전치·역행렬 같은 좋은 것들을 할 수 있다**
- **변환에 내적 투영을 쓸 수 있다**
- 회전이든 무엇이든 **벡터로 하고 싶은 모든 일이 훨씬 편해진다**

---

## 요약
- **그람-슈미트 = 선형독립 벡터들 → 정규직교 기저**를 만드는 절차.
- 절차: **① 첫 벡터를 정규화 → ② 다음 벡터에서 앞의 e들 방향 성분을 모두 빼고 정규화 → ③ 반복.**
```
uₖ = vₖ − Σᵢ₌₁^(k−1) (vₖ · eᵢ)·eᵢ
eₖ = uₖ / |uₖ|
```
- ⚠️ **선형독립 확인은 행렬식 ≠ 0** 으로 한다.
- 결과로 [직교행렬](04%20Orthogonal%20matrices.md)의 모든 이점을 얻는다.
