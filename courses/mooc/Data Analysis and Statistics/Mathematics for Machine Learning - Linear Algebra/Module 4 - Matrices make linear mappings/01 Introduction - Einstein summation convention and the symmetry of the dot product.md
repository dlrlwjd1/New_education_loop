## 내용

### 아인슈타인 합 규약(Einstein summation convention) ⭐
행렬 곱 `AB`의 원소를 쓰면:
```
(AB)₂₃ = a₂₁b₁₃ + a₂₂b₂₃ + … + a₂ₙbₙ₃
```
> 첫 첨자가 **행**, 둘째가 **열**이다.

일반화하면:
```
(AB)ᵢₖ = Σⱼ aᵢⱼ bⱼₖ
```
> **아인슈타인의 규약**: **반복되는 첨자가 있으면 합 기호를 생략**하고 그냥 이렇게 쓴다.
```
(AB)ᵢₖ = aᵢⱼ bⱼₖ
```

**코딩에 왜 좋은가** ⭐
> **i, j, k에 대해 루프를 세 개 돌리고, j에 대해 누산기(accumulator)를 쓰면** 곱 행렬 AB의 원소를 구할 수 있다. **합 규약은 이런 연산을 빠르게 코딩하는 방법을 준다.**

### 정사각이 아닌 행렬도 곱할 수 있다 ⭐
> **j의 개수만 같으면 모양이 달라도 곱할 수 있다.**
```
(2×3) × (3×4) = (2×4)
```
> **왼쪽 것의 행 수**와 **오른쪽 것의 열 수**를 갖는 행렬이 나온다.

⚠️ **역행렬·행렬식 같은 성질들은 이런 경우 지저분해지고 아예 계산할 수 없기도 하다.** 하지만 **필요할 때가 있고, 합 규약이 그것을 쉽게 보게 해 준다.**

### 내적 = 행렬 곱셈 ⭐⭐
두 열벡터 u, v의 내적:
```
u · v = u₁v₁ + u₂v₂ + … = uᵢvᵢ      (합 규약)
```
> 이것은 **u를 행 행렬로 밀어 놓고** v(열 행렬)와 곱하는 것과 **같다.**
```
[u₁ u₂ … uₙ] · ⎡v₁⎤
                ⎢v₂⎥  =  u·v
                ⎣vₙ⎦
```
> ⭐ **즉 행렬 곱셈과 내적은 같은 것이다.** 벡터 u를 눕히기만 하면 내적이 행렬 곱셈이 된다.

### 투영이 대칭인 이유 — 기하학적 증명 ⭐⭐
단위 벡터 **û** = (u₁, u₂) 와 축 벡터 **ê₁** = (1, 0) 을 생각한다.

| 방향 | 결과 |
|---|---|
| **û를 ê₁에 투영** | 길이 **u₁** (û의 x 성분) |
| **ê₁을 û에 투영** | 어떤 투영 길이 |

> ⭐ **두 투영이 교차하는 곳으로 대칭선을 그을 수 있고, 두 작은 삼각형이 실제로 같다.** (직접 기하로 증명해 볼 수 있다.)
>
> **따라서 두 투영의 길이가 같고**, 이것이 곧 **내적이 대칭(`û·ê₁ = ê₁·û`)** 이라는 뜻이다.
>
> **다른 축 ê₂에 대해서도, 어떤 축에 대해서도 같은 결과**가 나온다.

> ⭐⭐ **그래서 투영이 대칭이고, 내적이 대칭이며, 투영이 곧 내적이다.**
>
> **수치적인 것(행렬 곱셈)과 기하학적인 것(투영) 사이의 이 연결은 꽤 아름답고 정말로 놀랍다.**
>
> **그래서 벡터와의 행렬 곱셈을 "그 벡터를 행렬을 구성하는 벡터들(행렬의 열들) 위로 투영하는 것"이라고 말하는 것이다.**

---

## 요약
- **아인슈타인 합 규약: `(AB)ᵢₖ = aᵢⱼbⱼₖ`** — 반복 첨자는 합을 뜻한다. **i, j, k 삼중 루프로 그대로 코딩**된다.
- **j의 개수만 맞으면 비정사각 행렬도 곱할 수 있다.** `(2×3)×(3×4) = (2×4)`.
- ⭐⭐ **내적 = 행렬 곱셈.** 열벡터 u를 행벡터로 눕히면 그대로 행렬 곱이 된다.
- **투영이 대칭인 것을 기하학으로 보일 수 있고**, 이것이 내적의 대칭성이다.
- 그래서 **행렬 × 벡터 = 벡터를 행렬의 열들 위로 투영하는 것**이라 부른다.
