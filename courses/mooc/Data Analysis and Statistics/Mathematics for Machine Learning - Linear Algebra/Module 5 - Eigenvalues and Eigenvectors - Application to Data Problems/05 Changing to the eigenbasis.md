# 05 Changing to the eigenbasis

## 개요
- 강좌: Mathematics for Machine Learning - Linear Algebra (Imperial College London)
- 모듈: Module 5 — Eigenvalues and Eigenvectors: Application to Data Problems
- 강사: Sam Cooper
- [MOOC 원본 강의](https://www.mooc.org/learn/linear-algebra-machine-learning/lecture/EcsN0/changing-to-the-eigenbasis)
- ⭐⭐ **대각화(diagonalisation)** — 고유벡터를 기저로 삼아 **행렬 거듭제곱을 극도로 싸게** 만든다. **이 강좌의 클라이맥스.**

---

## 내용

### 문제 — 같은 변환을 여러 번 적용해야 할 때
> 변환 행렬 **T**가 **한 시간 단계 뒤 입자의 위치 변화**를 나타낸다고 하자.
```
v₁ = T v₀
v₂ = T v₁ = T² v₀
…
vₙ = Tⁿ v₀
```
> ⚠️ **T가 1초 동안의 변화를 말해 주는데 2주 뒤 입자의 위치를 알고 싶다면 n ≈ 120만**이다. **T를 자기 자신과 100만 번 넘게 곱해야 하고 꽤 오래 걸린다.**

### 대각 행렬은 거듭제곱이 쉽다 ⭐
> **주대각선을 뺀 모든 항이 0인 행렬**을 **대각 행렬(diagonal matrix)** 이라 한다.
```
T = ⎡ a  0  0 ⎤          Tⁿ = ⎡ aⁿ  0   0  ⎤
    ⎢ 0  b  0 ⎥               ⎢ 0   bⁿ  0  ⎥
    ⎣ 0  0  c ⎦               ⎣ 0   0   cⁿ ⎦
```
> **대각선의 각 항을 n제곱하면 끝**이다.

### T가 대각이 아니면? — 고유 해석이 답이다 ⭐⭐
> **T가 대각이 되는 기저로 바꾸면 된다.** 그 기저를 **고유기저(eigenbasis)** 라 한다.
>
> 그러면 **대각화된 형태에 n제곱을 쉽게 적용하고, 결과 행렬을 다시 되돌리면** Tⁿ을 얻으면서 **일의 대부분을 피할 수 있다.**

### 변환 행렬 C 만들기 ⭐
> [기저 변환](../Module%204%20-%20Matrices%20make%20linear%20mappings/02%20Matrices%20changing%20basis.md)에서 봤듯 **변환 행렬의 각 열은 변환된 단위 벡터의 새 위치**다. 따라서 **고유벡터들을 열로 넣으면** 된다.
```
C = [ 고유벡터₁ | 고유벡터₂ | 고유벡터₃ ]
```
> ⚠️ **일부는 복소수일 수 있어 순수 기하학적 접근으로는 찾기 쉽지 않지만, 수학에서는 나머지와 똑같이 나타난다.**

### 대각 행렬 D
> 이 변환을 적용하면 **T를 곱하는 것이 사실상 순수한 스케일**이 되는 세계에 있게 된다. 즉 **대각 행렬로 표현할 수 있다.**
>
> ⭐ **결정적으로, 이 대각 행렬 D는 T의 대응하는 고유값들을 담는다.**
```
D = ⎡ λ₁  0   0  ⎤
    ⎢ 0   λ₂  0  ⎥
    ⎣ 0   0   λ₃ ⎦
```

### 마지막 연결 ⭐⭐
> **T를 적용하는 것 = 고유기저로 바꾸고 → 대각 행렬을 적용하고 → 다시 되돌리는 것.**
```
T = C D C⁻¹
```

**거듭제곱하면**
```
T² = (C D C⁻¹)(C D C⁻¹)
```
> ⭐ **가운데에 `C⁻¹C` 가 있다. 행렬과 그 역을 곱하는 것은 아무것도 안 하는 것과 같으므로 지울 수 있다.**
```
T² = C D D C⁻¹ = C D² C⁻¹
```

**일반화**
```
Tⁿ = C Dⁿ C⁻¹
```

> ⭐⭐ **이제 큰 계산 비용을 치르지 않고 변환 행렬을 원하는 만큼 여러 번 적용하는 방법을 갖게 됐다.**
>
> **이 결과는 이 강좌에서 지금까지 만난 많은 아이디어를 한데 모은다.**

---

## 요약
- 문제: **같은 변환을 n번(수백만 번) 적용해야 하는데 비용이 크다.**
- **대각 행렬은 거듭제곱이 쉽다** — 대각 항을 각각 n제곱하면 끝.
- ⭐⭐ **고유벡터들을 열로 하는 행렬 C를 만들면, 그 기저에서 T가 대각 행렬 D가 되고 D의 대각 항이 곧 고유값이다.**
- **`T = C D C⁻¹`**, 따라서 **`Tⁿ = C Dⁿ C⁻¹`** — 가운데 `C⁻¹C` 들이 소거되기 때문이다.
- 이것이 **대각화(diagonalisation)** 이며, 이 강좌의 여러 아이디어(기저 변환·역행렬·고유값)가 한 식에서 만난다.
