# 04 Calculating eigenvectors

## 개요
- 강좌: Mathematics for Machine Learning - Linear Algebra (Imperial College London)
- 모듈: Module 5 — Eigenvalues and Eigenvectors: Application to Data Problems
- 강사: Sam Cooper
- [MOOC 원본 강의](https://www.mooc.org/learn/linear-algebra-machine-learning/lecture/We8G9/calculating-eigenvectors)
- ⭐ **고유값·고유벡터를 대수적으로 계산**하는 법. 그리고 **왜 손으로 풀 필요가 없는지.**

---

## 내용

### 기본 식 ⭐⭐
```
A x = λ x
```
| 변 | 뜻 |
|---|---|
| **좌변** | 벡터 x에 **변환 행렬 A를 적용** |
| **우변** | 벡터 x를 **스칼라 λ만큼 늘리기만** 함 |

> **양변을 같게 만드는 x를 찾는 것**이다. 다르게 말하면 — **고유벡터에 A를 적용하면 길이만 스케일되거나(λ=1이면) 아무 일도 일어나지 않는다.**
>
> A가 n차원 변환이면 **n×n 정사각 행렬**이고, 고유벡터 x는 **n차원 벡터**다.

### 정리하기
```
A x − λ x = 0
(A − λI) x = 0
```
> ⚠️ **I가 왜 나오는가**: **A와 같은 크기의 항등행렬**이다. **벡터에 스칼라를 곱하는 것은 정의돼 있지만, 행렬에서 스칼라를 빼는 것은 정의돼 있지 않다.** I는 **의미를 바꾸지 않고 수식을 정돈**해 준다.

### 행렬식으로 조건 만들기 ⭐
> 좌변이 0이 되려면 **괄호 안이 0이거나 벡터 x가 0**이어야 한다.
>
> **x = 0인 경우는 관심 없다** — 길이도 방향도 없는 **자명해(trivial solution)** 다.
>
> 따라서 **괄호 안이 0일 때**를 찾아야 하고, [모듈 3](../Module%203%20-%20Matrices%20in%20Linear%20Algebra%20-%20Objects%20that%20operate%20on%20Vectors/07%20Determinants%20and%20inverses.md)에서 배운 대로 **행렬 연산이 0 출력을 내는지는 행렬식으로 검사**한다.

```
det(A − λI) = 0
```

### 특성 다항식(characteristic polynomial) ⭐
2×2 `A = [[a, b], [c, d]]` 에 적용하면:
```
det ⎡ a−λ    b  ⎤ = 0
    ⎣  c    d−λ ⎦

→ λ² − (a + d)λ + (ad − bc) = 0
```
> 이것을 **특성 다항식**이라 한다. **고유값은 이 방정식의 해**이고, 그것을 원래 식에 다시 넣어 **고유벡터**를 구한다.

### 예제 1 — 수직 2배 스케일
```
A = ⎡ 1  0 ⎤
    ⎣ 0  2 ⎦

det ⎡ 1−λ   0  ⎤ = (1−λ)(2−λ) = 0
    ⎣  0   2−λ ⎦

→ λ = 1, λ = 2
```

**λ = 1 일 때**
```
⎡ 0  0 ⎤ ⎡x₁⎤ = 0    →  x₂ = 0
⎣ 0  1 ⎦ ⎣x₂⎦
```
> **x₂는 0이어야 하지만 x₁에 대해서는 아무것도 모른다.** 당연하다 — **수평축을 따르는 어떤 벡터든 이 시스템의 고유벡터**이기 때문이다. **임의 파라미터 t**로 쓴다.
```
λ = 1 → x = (t, 0)
```

**λ = 2 일 때**
```
⎡ −1  0 ⎤ ⎡x₁⎤ = 0    →  −x₁ = 0
⎣  0  0 ⎦ ⎣x₂⎦

λ = 2 → x = (0, t)
```
> **수평 방향으로 전혀 움직이지 않는 순수 수직 벡터라면 무엇이든 고유벡터**다. 전부 같은 span 위에 있으므로.

### 예제 2 — 90도 반시계 회전 (고유벡터 없음 확인)
```
A = ⎡ 0  −1 ⎤
    ⎣ 1   0 ⎦

det ⎡ −λ   −1 ⎤ = λ² + 1 = 0
    ⎣  1   −λ ⎦
```
> ⭐ **실수 해가 전혀 없다. 따라서 실수 고유벡터가 없다.** (앞의 기하학적 관찰과 일치한다.)
>
> **허수를 쓰면 복소 고유벡터를 계산할 수 있지만 이 강좌의 범위를 넘는다.**

### ⚠️ 손으로 풀 필요가 없는 이유 ⭐⭐
> **거의 확실히 이 계산을 손으로 할 일은 없을 것이다.**
>
> 이 방법은 **차수 n(행렬의 차원)의 다항식의 근을 찾아야** 하는데, **금세 해석적 방법만으로는 불가능해진다.**
>
> **컴퓨터가 100차원 문제의 고유해를 찾을 때는 반복적 수치 방법을 쓸 수밖에 없다.**
>
> ⭐ **강사의 단언: "고유 문제에 대한 강한 개념적 이해를 기르는 것이 손으로 잘 계산하는 것보다 훨씬 유용하다. 공대 학부에서 흔히 하듯 수많은 고유 문제를 풀어 보는 것은, 개념을 이미 이해했다면 시간을 잘 쓰는 것이 아니다. 그것이 컴퓨터가 있는 이유다."**

---

## 요약
- ⭐⭐ **`A x = λ x`** → **`(A − λI)x = 0`** → **`det(A − λI) = 0`**.
- **I를 넣는 이유**: 행렬에서 스칼라를 빼는 것은 정의되지 않기 때문. 의미는 바뀌지 않는다.
- **x = 0은 자명해**라 관심 없다.
- 2×2의 **특성 다항식: `λ² − (a+d)λ + (ad − bc) = 0`**.
- 수직 2배 스케일 → λ=1은 `(t, 0)`, λ=2는 `(0, t)`. **한 방향 전체가 고유벡터**라 파라미터 t로 쓴다.
- 90도 회전 → `λ² + 1 = 0` **실수 해 없음 = 실수 고유벡터 없음.**
- ⚠️ **손 계산은 n차 다항식의 근 찾기라 고차원에서 불가능하다.** 컴퓨터는 **반복적 수치 방법**을 쓴다. **개념 이해가 계산 숙련보다 중요하다.**
