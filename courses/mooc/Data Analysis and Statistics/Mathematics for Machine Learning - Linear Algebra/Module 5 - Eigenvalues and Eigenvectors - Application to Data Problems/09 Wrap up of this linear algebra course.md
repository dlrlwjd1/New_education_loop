## 내용

### 목표 ⭐
> **신경망·머신러닝·데이터 과학 강좌 전반에 접근할 수 있게 해 주는 선형대수의 기초를 주는 것.**
>
> **사회과학자·엔지니어·물리학자가 다른 머신러닝 도구 강좌에 접근하고, 현실 세계에서 머신러닝으로 문제를 푸는 유용한 일을 하는 데 필요한 통찰을 기르기 위한 강좌**다.

### 이 강좌가 아닌 것 ⚠️
> **대학원 선형대수 강좌의 토대로 의도된 것이 아니다.** 또한 **머신러닝에 응용이 없는 외적(cross product) 같은 주제를 논할 시간도 없었다.**

## 요약
- 이 강좌의 목표: **ML·데이터 과학 강좌에 접근하기 위한 선형대수의 기초와 직관.**
- ⚠️ **대학원 선형대수의 토대가 아니며**, ML에 응용이 없는 주제(외적 등)는 다루지 않았다.
- 흐름: **데이터 문제 → 벡터 → 행렬 → 선형 사상 → 고유값·고유벡터 → PageRank.**
- 다음은 **Multivariate Calculus → PCA → 머신러닝·신경망.**
- 이 강좌로 [인공지능융합공학부 로드맵](../../../../../study-progress/%EC%9D%B8%EA%B3%B5%EC%A7%80%EB%8A%A5%EC%9C%B5%ED%95%A9%EA%B3%B5%ED%95%99%EB%B6%80%20%EB%A1%9C%EB%93%9C%EB%A7%B5/README.md)의 **선형대수 공백**이 닫힌다.
