# 03 Types of matrix transformation

## 개요
- 강좌: Mathematics for Machine Learning - Linear Algebra (Imperial College London)
- 모듈: Module 3 — Matrices in Linear Algebra: Objects that operate on Vectors
- 강사: David Dye
- [MOOC 원본 강의](https://www.mooc.org/learn/linear-algebra-machine-learning/lecture/AGcCv/types-of-matrix-transformation)
- **행렬이 공간에 할 수 있는 모든 종류의 변형** — 항등·스케일·거울·전단·회전.

---

## 내용

### 항등 행렬(Identity Matrix) — 아무것도 하지 않는다
```
I = ⎡ 1  0 ⎤        I·(x, y) = (x, y)
    ⎣ 0  1 ⎦
```
> **기저 벡터 자체로 이루어져 있어 아무것도 바꾸지 않는다.** 이름은 **I**.

### 스케일(scaling) — 주대각선의 수
```
⎡ 3  0 ⎤     ê₁ → (3, 0)   x축을 3배
⎣ 0  2 ⎦     ê₂ → (0, 2)   y축을 2배
```
> 단위 정사각형이 **직사각형**이 된다.
>
> ⚠️ **스케일 인자가 분수(예: ⅓)면 그 방향으로 공간이 눌린다.** 더 얇고 높아진다.

### 음수 스케일 — 뒤집기와 손잡이(handedness) ⭐
```
⎡ −1  0 ⎤     ê₁ → (−1, 0)  ← x축이 반대편으로
⎣  0  2 ⎦     ê₂ → (0, 2)
```
> 넓이는 **1×2 = 2배**가 되지만 **뒤집혔다.**
>
> ⭐ 원래는 **오른손 좌표계**로 반시계 방향이었는데, 이제 **왼손 좌표계**가 되어 시계 방향이 된다. **뒤집으면 좌표계의 방향(sense)이 바뀐다.**

### 반전(Inversion)
```
⎡ −1   0 ⎤     ê₁ → (−1, 0)
⎣  0  −1 ⎦     ê₂ → (0, −1)
```
> **두 좌표 모두 뒤집는다.** 이것을 **반전(inversion)** 이라 한다.

### 거울(mirror) — 다섯 가지 ⭐
| 행렬 | ê₁ → | ê₂ → | 거울면 |
|---|---|---|---|
| `⎡0 1⎤ ⎣1 0⎦` | (0, 1) | (1, 0) | **45도** 거울 |
| `⎡0 −1⎤ ⎣−1 0⎦` | (0, −1) | (−1, 0) | **−45도** 거울 |
| `⎡−1 0⎤ ⎣0 1⎦` | (−1, 0) | (0, 1) | **수직** 거울 (x축 뒤집기) |
| `⎡1 0⎤ ⎣0 −1⎦` | (1, 0) | (0, −1) | **수평** 거울 (y축 뒤집기) |
| `⎡−1 0⎤ ⎣0 −1⎦` | (−1, 0) | (0, −1) | **반전**(위 참조) |

### 전단(shear)
```
ê₁ 은 그대로 (1, 0), ê₂ 만 (1, 1) 로 옮기고 싶다면

⎡ 1  1 ⎤
⎣ 0  1 ⎦
```
> **단위 정사각형이 평행사변형이 된다.** x축을 전단할 수도, 여러 전단을 조합할 수도 있다.

### 회전(rotation) ⭐
**90도 회전 예**
```
ê₁ → (0, 1),  ê₂ → (−1, 0)

⎡ 0  −1 ⎤
⎣ 1   0 ⎦
```

**일반적인 각 θ 회전 (2D)**
```
R(θ) = ⎡ cos θ  −sin θ ⎤
       ⎣ sin θ   cos θ ⎦
```
> ⚠️ **마이너스 부호의 위치**가 양의 θ가 어느 방향인지를 정한다.
>
> 3D에서 회전하려면 **어느 축을 중심으로 도는지**를 생각해야 한다. 예컨대 z축 중심 회전이면 **z 성분을 보존**한다.

### 데이터 과학에서 왜 필요한가
> 이 강좌는 **행렬 회전이나 행렬 기하학(결정학 같은)에 관한 강좌가 아니라 데이터 과학에 관한 강좌**라 회전을 너무 깊게 볼 필요는 없다.
>
> 다만 **얼굴 인식을 하려면 얼굴을 변환해야 한다** — 카메라가 이상한 각도에서 본 얼굴을 **늘리고 거울로 뒤집고 전단하고 회전시켜** 모두 같은 방향을 보게 만들어야 한다. **데이터 과학에서도 가끔 필요하다.**

---

## 요약
- **항등 `I`** — 아무것도 하지 않는다.
- **스케일** — 주대각선의 수. **분수면 눌리고, 음수면 뒤집힌다**(좌표계의 손잡이가 바뀐다).
- **반전** — 모든 좌표 뒤집기. **거울** — 45도·−45도·수직·수평 등.
- **전단** — 한 기저 벡터만 옮겨 정사각형을 평행사변형으로.
- **회전** — `R(θ) = [[cos θ, −sin θ], [sin θ, cos θ]]`.
