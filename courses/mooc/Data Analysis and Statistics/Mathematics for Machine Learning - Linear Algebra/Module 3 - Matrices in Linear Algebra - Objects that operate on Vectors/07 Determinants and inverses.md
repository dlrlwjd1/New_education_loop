# 07 Determinants and inverses

## 개요
- 강좌: Mathematics for Machine Learning - Linear Algebra (Imperial College London)
- 모듈: Module 3 — Matrices in Linear Algebra: Objects that operate on Vectors
- 강사: David Dye
- [MOOC 원본 강의](https://www.mooc.org/learn/linear-algebra-machine-learning/lecture/nK1Eb/determinants-and-inverses)
- ⭐ **행렬식(determinant) = 행렬이 공간을 얼마나 키우는가.** 그리고 **행렬식이 0이면 역행렬이 없다.**

---

## 내용

### 행렬식의 기하학적 뜻 ⭐
**대각 행렬**
```
⎡ a  0 ⎤     ê₁ → (a, 0),  ê₂ → (0, d)
⎣ 0  d ⎦
```
> 원래 **1×1 크기**였던 공간이 이 방향으로 a배, 저 방향으로 d배가 됐다.
>
> ⭐ **공간의 모든 넓이가 `ad` 배 커졌다. 이것을 변환 행렬의 행렬식이라 부른다.**

**전단이 섞인 경우**
```
⎡ a  b ⎤     ê₁ → (a, 0),  ê₂ → (b, d)
⎣ 0  d ⎦
```
> 정사각형이 **평행사변형**이 되지만 **넓이는 여전히 `ad`** 다 — **밑변 × 수직 높이**이므로.

**일반적인 2×2**
```
⎡ a  b ⎤
⎣ c  d ⎦

넓이(행렬식) = ad − bc

표기: |A|  또는  det(A)
```

### 학교에서 배운 역행렬 공식의 증명 ⭐
학교에서는 **주대각선 항을 뒤집고 비대각 항에 마이너스를 붙이는** 방식으로 2×2 역행렬을 구했다. 실제로 곱해 보면:
```
⎡ a  b ⎤ ⎡  d  −b ⎤ = ⎡ ad − bc      0     ⎤
⎣ c  d ⎦ ⎣ −c   a ⎦   ⎣    0      ad − bc  ⎦
```
- (1,2) 성분: `a(−b) + b(a) = 0` ✓
- (2,1) 성분: `cd − cd = 0` ✓
- 대각 성분이 모두 **`ad − bc` = 행렬식**

> 따라서 **`1/(ad − bc)` 를 곱하면 항등행렬**이 된다.
```
A⁻¹ = 1/det(A) · ⎡  d  −b ⎤
                 ⎣ −c   a ⎦
```

> ⭐ **왜 행렬식으로 나누는가**: 항을 뒤집는 조작은 **공간의 스케일을 바꾸지 않았다.** 그 스케일을 되돌려 **1로 만들어야** 제대로 된 역행렬이 된다.

### 일반적인 행렬식 계산은 배우지 않는다 ⚠️
> 강사: **"n차원의 일반적인 행렬식을 구하는 법을 보여 주는 것은 까다롭기도 하고 무의미하다. 그 연산을 할 줄 아는 것은 더 이상 유용한 기술이 아니다 — 컴퓨터에 `det A` 라고 치면 되기 때문이다."**
>
> 궁금하면 **QR 분해(QR decomposition)** 를 찾아보거나 선형대수 교과서를 보면 된다.

### 행렬식이 0인 경우 ⭐⭐
```
A = ⎡ 1  2 ⎤       ê₁ → (1, 1),  ê₂ → (2, 2)
    ⎣ 1  2 ⎦
```
> **두 변환된 기저 벡터가 같은 직선 위에 있다.** 서로의 배수일 뿐 **선형독립이 아니다.**
>
> **이 행렬은 공간의 모든 점을 하나의 직선 위로 변환한다.**
```
det(A) = 1×2 − 2×1 = 0
```
> **넓이가 직선으로 가 버렸으므로 넓이가 0**이다. 기하학적으로 계산하든 대수적으로 계산하든 **행렬식이 0**이다.

**3×3에서도 마찬가지** — 새 기저 벡터 중 하나가 다른 둘의 선형결합이면, 새 공간은 **평면**(독립이 둘이면)이거나 **직선**(하나면)이 되고 **부피가 0** 이므로 행렬식이 0이다.

### 연립방정식 관점에서 ⭐
```
행3 = 행1 + 행2   (셋째 행이 앞 두 행의 합)
열3 = 2×열1 + 열2
```
> **이 변환 행렬은 세 개의 독립 기저 벡터를 기술하지 않는다.** 하나가 다른 둘에 선형종속이다. **3D 공간을 기술하지 못하고 2D로 붕괴시킨다.**

**에셜론 형태로 줄여 보면**
```
행2 − 행1, 행3 − (행1 + 행2)
→ 마지막 행이 (0, 0, 0 | 0)

즉  0·c = 0
```
> **참이지만 쓸모없다.** c에 대한 **무한히 많은 해**가 있다 — **어떤 값이든 통한다.**
>
> **더 이상 연립방정식을 풀 수 없다. 정보가 충분하지 않다.**

**가게 비유** ⭐
> 실수는 **세 번째로 가게에 갔을 때 앞의 두 주문을 그대로 복사해 주문한 것**이다. **새로운 정보를 전혀 얻지 못했으므로** 개별 가격을 알아낼 데이터가 부족하다.

### 결론 ⭐⭐
| 상황 | 결과 |
|---|---|
| **기저 벡터가 선형종속** | **행렬식 = 0** |
| 행렬식 = 0 | **연립방정식을 풀 수 없다** |
| 〃 | **`1/det` 을 취할 수 없으므로 역행렬이 존재하지 않는다** |

> **차원 수를 줄이는 변환을 하고 싶을 수도 있지만 대가가 따른다.**
>
> 다르게 보면 — **역행렬은 변환을 되돌리게 해 준다.** **2D 공간을 직선으로 만들었다면 되돌릴 수 없다.** 변환 중에 **정보를 잃어버렸기 때문**이다.
>
> ⭐ **그러므로 새 기저 벡터 집합을 제안하고 행렬로 데이터를 변환하기 전에, 그 변환을 되돌릴 수 있는지 — 즉 새 기저 벡터가 선형독립인지 — 확인하는 것이 좋다.**

---

## 요약
- ⭐ **행렬식 = 변환이 공간(넓이·부피)을 얼마나 키우는가.** 2×2에서 **`det = ad − bc`**.
- **`A⁻¹ = (1/det) · [[d, −b], [−c, a]]`** — **행렬식으로 나누는 이유는 스케일을 되돌리기 위해서**다.
- ⚠️ 일반 n차원 행렬식 계산법은 배우지 않는다. **`det A` 를 컴퓨터에 맡긴다.** (원리는 QR 분해)
- ⭐⭐ **기저 벡터가 선형종속 → 행렬식 0 → 공간이 붕괴 → 연립방정식 해가 무한 → 역행렬 없음.**
- **가게에서 앞선 주문을 그대로 반복한 것**과 같아 새 정보가 없다.
- **변환 전에 새 기저가 선형독립인지 확인하라** — 되돌릴 수 없는 변환은 정보를 잃는다.
