# 02 How matrices transform space

## 개요
- 강좌: Mathematics for Machine Learning - Linear Algebra (Imperial College London)
- 모듈: Module 3 — Matrices in Linear Algebra: Objects that operate on Vectors
- 강사: David Dye
- [MOOC 원본 강의](https://www.mooc.org/learn/linear-algebra-machine-learning/lecture/IhJAZ/how-matrices-transform-space)
- **행렬 곱셈은 변환된 기저 벡터들의 벡터 합**이라는 것. 그래서 **격자가 평행하고 균등하게 유지된다.**

---

## 내용

### 왜 공간이 휘지 않는가 ⭐
> 어떤 벡터든 **ê₁과 ê₂의 스케일된 버전들의 벡터 합**으로 만들 수 있다. 따라서 **변환의 결과도 변환된 벡터들(ê₁′, ê₂′)의 합**일 뿐이다.
>
> 이것이 뜻하는 바: **공간의 격자선이 평행하고 균등 간격을 유지한다.** 늘어나거나 전단(shear)될 수는 있지만 **원점은 그대로 있고 공간에 곡률이 생기지 않는다. 휘어지지 않는다.**
>
> **이것은 벡터의 스칼라 덧셈·곱셈 규칙의 결과다.**

### 대수적 확인
행렬을 **A**, 변환할 벡터를 **r**, 결과를 **r′** 이라 하면:
```
A(n·r) = n·(A r) = n·r′           ← 스칼라 곱이 통과한다
A(r + s) = A r + A s              ← 덧셈이 분배된다
```
따라서 `r = n·ê₁ + m·ê₂` 이면:
```
A r = n·(A ê₁) + m·(A ê₂) = n·ê₁′ + m·ê₂′
```
> **공간이 변환되어 ê₁과 ê₂가 옮겨지고, 그다음 그것들로 벡터를 더하면 된다.**

### 구체 예제 ⭐
```
A = ⎡  2   3 ⎤        r = (3, 2)
    ⎣ 10   1 ⎦
```

**보통 방식으로 곱하면**
```
2×3 + 3×2 = 6 + 6 = 12
10×3 + 1×2 = 30 + 2 = 32
→ (12, 32)
```

**기저 벡터 관점으로 하면**
```
A r = A · (3·(1,0) + 2·(0,1))
    = 3·(A·(1,0)) + 2·(A·(0,1))
    = 3·(2, 10) + 2·(3, 1)         ← ê₁′ 과 ê₂′
    = (6 + 6, 30 + 2)
    = (12, 32)                      ✓ 같다
```

> ⭐⭐ **행렬 곱셈은 그저 변환된 기저 벡터들의 벡터 합의 곱셈이라고 생각할 수 있다.**
>
> 강사: **"잠시 멈추고 직접 예를 들어 확인해 보라. 이것은 정말 꽤 깊은 내용이다."**
>
> **이 행렬은 기저 벡터들이 어디로 가는지를 말해 줄 뿐이다. 그것이 이 행렬이 하는 변환이다. 복잡하게 곱해 내는 일이 아니다. 합의 역학을 걱정할 필요 없이, 공간의 벡터들에 무엇을 하는지로 생각하면 된다.**

---

## 요약
- **행렬 곱셈 = 변환된 기저 벡터들의 벡터 합.** `A r = n·ê₁′ + m·ê₂′`.
- 그 결과 **격자가 평행하고 균등하게 유지되고, 원점이 고정되며, 공간이 휘지 않는다.**
- 대수적으로 `A(nr) = n(Ar)`, `A(r+s) = Ar + As` 가 성립하기 때문이다.
- ⭐ **행렬은 "기저 벡터를 어디로 보내는가"만 말해 준다.** 곱셈의 기계적 절차보다 이 관점이 본질이다.
