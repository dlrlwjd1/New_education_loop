## 내용

### 벡터의 크기(modulus) ⭐
> 벡터를 처음 정의할 때는 **어떤 좌표계도 참조하지 않았다.** 기하학적 대상 r은 **길이와 방향** 두 성질만 갖는다.

좌표계가 **서로 직교하는 단위 벡터** î, ĵ 로 구성됐다면 `r = a·î + b·ĵ` 이고, **피타고라스**로:
```
|r| = √(a² + b²)
```
- 세로 두 줄 `| |` 로 크기를 표기한다. `|a·î| = a` 인 이유는 **î의 길이가 1**이기 때문이다.
- 보통 î, ĵ 를 생략하고 **열벡터**로 쓴다: `r = (a, b)`.

> ⭐ **이 정의는 공간의 두 방향보다 훨씬 일반적이다.** 벡터의 성분들이 공간의 차원이든, **길이·시간·가격처럼 물리 단위가 서로 달라도** 상관없다. **여전히 성분들의 제곱합으로 크기를 정의한다.**

### 내적(dot product)의 정의 ⭐
> 두 벡터를 곱하는 여러 방법 중 하나다.
```
r = (rᵢ, r_j),  s = (sᵢ, s_j)

r · s = rᵢ·sᵢ + r_j·s_j
```
> **내적은 그냥 수(스칼라)** 다. **성분끼리 차례로 곱해 더한 것.**

예: `r = (3, 2)`, `s = (−1, 2)` → `r·s = −3 + 4 = 1`

### 내적의 세 가지 성질 ⭐

**① 교환법칙 (commutative)**
```
r · s = s · r
```
> 수를 곱하는 순서는 상관없으므로 (`−1 × 3 = 3 × −1`) 자명하다.

**② 덧셈에 대한 분배법칙 (distributive over addition)**
```
r · (s + t) = r·s + r·t
```
**일반적인 n차원 증명**
```
좌변 = r₁(s₁+t₁) + r₂(s₂+t₂) + … + rₙ(sₙ+tₙ)
     = r₁s₁ + r₁t₁ + r₂s₂ + r₂t₂ + … + rₙsₙ + rₙtₙ
     = (r₁s₁ + r₂s₂ + … + rₙsₙ) + (r₁t₁ + r₂t₂ + … + rₙtₙ)
     = r·s + r·t
```

**③ 스칼라 곱에 대한 결합법칙 (associative over scalar multiplication)**
```
r · (a·s) = a · (r·s)         (a는 스칼라)
```
**2차원 증명**
```
좌변 = r₁(a·s₁) + r₂(a·s₂) = a(r₁s₁ + r₂s₂) = a(r·s)
```

### 표기 관습 (여담)
> **물리·공학**에서는 벡터를 **굵게** 쓰거나 **밑줄**을 그어 스칼라와 구분하는 경우가 많다. **수학·컴퓨터과학**에서는 그렇게 하지 않는 편이다.
>
> **공동체 사이의 표기 차이일 뿐 근본적으로 걱정할 것은 없다.**

### 내적과 크기의 연결 ⭐⭐
벡터를 **자기 자신과 내적**하면:
```
r · r = r₁² + r₂² + … = |r|²
```
> ⭐ **벡터의 크기를 구하려면 자기 자신과 내적한 뒤 제곱근을 취하면 된다.**
>
> 강사의 표현: **"정말 깔끔하고, 바라건대 꽤 만족스러운 결과다."**

---

## 요약
- **크기 `|r| = √(성분들의 제곱합)`.** 성분의 **물리 단위가 서로 달라도** 그대로 적용된다.
- **내적 `r·s = Σ rᵢsᵢ`** — 결과는 **스칼라**.
- 세 성질: **교환법칙 · 덧셈에 대한 분배법칙 · 스칼라 곱에 대한 결합법칙.**
- ⭐ **`r·r = |r|²`** — 자기 자신과의 내적이 크기의 제곱이다.
