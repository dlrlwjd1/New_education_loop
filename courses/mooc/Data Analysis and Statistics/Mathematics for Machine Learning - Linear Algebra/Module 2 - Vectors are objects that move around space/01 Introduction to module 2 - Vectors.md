# 01 Introduction to module 2 - Vectors

## 개요
- 강좌: Mathematics for Machine Learning - Linear Algebra (Imperial College London)
- 모듈: Module 2 — Vectors are objects that move around space
- 강사: David Dye
- [MOOC 원본 강의](https://www.mooc.org/learn/linear-algebra-machine-learning/lecture/gq8wi/introduction-to-module-2-vectors)
- 모듈 2 안내. **이 강좌의 벡터 본편**이다.

---

## 내용

이 모듈에서 벡터로 할 수 있는 것들:

| 주제 | 내용 |
|---|---|
| **크기(modulus / magnitude)** | 벡터의 길이 |
| **내적(dot product)** | 두 벡터를 결합해 **수** 하나를 얻는 방법 |
| **스칼라·벡터 투영(projection)** | 내적에서 이어진다 |
| **기저 벡터(basis vectors)** | 공간을 정의하는 데 쓰는 벡터들 |
| **선형독립·선형결합** | 공간의 차원을 이해하게 해 준다 |

> **이것이 벡터에 대한 메인 모듈**이다. 이 다음 모듈부터는 **행렬**로 넘어간다.
