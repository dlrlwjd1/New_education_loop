# 06 Basis, vector space, and linear independence

## 개요
- 강좌: Mathematics for Machine Learning - Linear Algebra (Imperial College London)
- 모듈: Module 2 — Vectors are objects that move around space
- 강사: David Dye
- [MOOC 원본 강의](https://www.mooc.org/learn/linear-algebra-machine-learning/lecture/YRjz5/basis-vector-space-and-linear-independence)
- **기저(basis) · 벡터 공간(vector space) · 선형독립(linear independence)** 의 형식적 정의. **공간의 차원이 몇인지**를 결정한다.

---

## 내용

### 기저의 정의 ⭐
> **기저란 서로의 선형결합이 아닌 n개 벡터의 집합**이다. 즉 **서로 선형독립**이며, 그것들이 **span(생성)** 하는 공간이 곧 그 공간이다. **그 공간은 n차원**이 된다.

### 선형독립을 쌓아 가기
| 단계 | 내용 |
|---|---|
| **b₁** | b₁의 배수를 취하면 **직선이라는 1차원 공간의 어디든** 갈 수 있다 |
| **b₂** (b₁의 단순 배수가 아닌) | b₁과 b₂의 조합으로 **평면 어디든** 갈 수 있다 → **2차원 공간** |
| **b₃** | 아래 조건을 만족해야 유효한 세 번째 기저 벡터다 |

**b₃의 조건** ⭐
```
b₃ = a₁·b₁ + a₂·b₂   를 만족하는 수 a₁, a₂ 를 찾는 것이 불가능해야 한다
```
| 결과 | 의미 |
|---|---|
| **찾을 수 없다** | **b₃는 선형독립**이다. b₃에 **칠판 밖으로 나가는 성분**이 있어야 하므로 **3차원 공간**을 준다 |
| **찾을 수 있다** | **b₃는 b₁, b₂에 선형종속(linearly dependent)** 이고 **b₁, b₂와 같은 평면 위에 있다** |

- b₁, b₂, b₃의 선형결합이 아닌 b₄가 있으면 **4차원 공간**, 그런 식으로 원하는 만큼 차원을 늘릴 수 있다.

### 기저가 만족하지 않아도 되는 것 ⚠️
> 기저 벡터 b는 **단위 벡터일 필요가 없고**(길이 1), **직교할 필요도 없다**(서로 90도).
>
> **하지만 그렇다면 모든 것이 훨씬 쉬워진다.**
>
> ⭐ **가능하다면 정규직교(orthonormal) 기저 집합 — 90도이고 단위 길이 — 을 쓰고 싶을 것이다.**

### 기저를 바꿀 때 공간에 무슨 일이 일어나는가 ⭐
> 원래 격자의 축의 수직선이 **새 격자 위로 투영되어** 그 격자에서 다른 값을 가질 수 있지만, **투영은 격자가 균등 간격을 유지하게 한다.**
>
> 따라서 **한 기저 집합에서 다른 기저 집합으로, 한 좌표계에서 다른 좌표계로 하는 어떤 사상(mapping)도 벡터 공간을 규칙적으로 균등한 격자로 유지한다.**
>
> **원래의 벡터 규칙 — 덧셈과 스칼라 곱 — 이 여전히 작동한다.**

> ⭐⭐ **공간을 접지(fold) 않는다. 이것이 선형대수의 "선형(linear)"이 뜻하는 바다.**
>
> **늘어나거나 회전하거나 뒤집힐 수는 있지만, 모든 것이 균등 간격을 유지하고 선형결합이 여전히 작동한다.**

### 직교가 아니면 ⚠️
> **새 기저 벡터가 직교하지 않으면 기저 변환에 내적만으로는 안 되고 행렬이 필요하다.** → 다음 모듈.

## 요약
- **기저 = 서로 선형결합이 아닌 n개 벡터.** 그것들이 생성하는 공간이 **n차원**이다.
- **선형독립 판정: `b₃ = a₁b₁ + a₂b₂` 를 만족하는 수를 찾을 수 없으면 독립**이다. 찾을 수 있으면 **같은 평면 위에 있는 종속 벡터.**
- 기저는 **단위 길이도 직교도 필수가 아니다.** 하지만 ⭐ **정규직교(orthonormal)이면 훨씬 쉽다.**
- ⭐⭐ **어떤 기저 변환도 공간을 접지 않는다** — 늘어나고 회전하고 뒤집힐 뿐 **균등 격자와 선형결합이 유지된다.** 이것이 **"선형"대수**의 뜻이다.
- 직교가 아니면 **행렬이 필요**하다 → 모듈 3.
