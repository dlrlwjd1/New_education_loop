# 05 Changing basis

## 개요
- 강좌: Mathematics for Machine Learning - Linear Algebra (Imperial College London)
- 모듈: Module 2 — Vectors are objects that move around space
- 강사: David Dye
- [MOOC 원본 강의](https://www.mooc.org/learn/linear-algebra-machine-learning/lecture/AN3cB/changing-basis)
- ⭐ **기저 변환(changing basis)** — 좌표계를 바꿔 같은 벡터를 다른 숫자로 기술한다. **투영만으로 되는 특수한 경우.**

---

## 내용

### 기저 벡터(basis vectors)
표준 좌표계를 **ê₁ = (1, 0)**, **ê₂ = (0, 1)** 이라 하자 (모자 ^ 는 단위 길이).
```
r = 3ê₁ + 4ê₂  →  r = (3, 4)
```
> **(3, 4)라는 표기는 "ê₁을 3번, ê₂를 4번 하라"는 지시**다.

### 핵심 통찰 ⭐⭐
> **ê₁, ê₂를 고른 것은 임의적이다.** 좌표계를 어떻게 세웠느냐에 전적으로 달려 있다.
>
> **어떤 각도로 좌표계를 세울 수도 있고, 심지어 서로 90도가 아니거나 길이가 다른 벡터로 축을 정의할 수도 있다.** 그래도 r을 **공간을 정의하는 데 쓴 벡터들의 합**으로 기술할 수 있다.

다른 기저 예:
```
b₁ = (2, 1),   b₂ = (−2, 4)      ← e 좌표로 기술한 것
```

> ⭐ **벡터 r은 우리가 그것을 기술하는 데 쓴 좌표계와 완전히 독립적으로, 깊은 수학적 의미에서 존재한다.** 원점에서 그 점으로 데려가는 그 벡터는 **r을 적은 숫자들과 무관하게 여전히 존재한다.**
>
> **r을 정의하는 숫자들은 기저 벡터를 알 때만 의미가 있다.**

### 언제 투영만으로 되는가 ⚠️
> **새 기저 벡터들이 서로 90도(직교)라면** 투영(내적)으로 새 기저에서의 r의 숫자를 구할 수 있다. **단 b를 e로 표현한 것을 알아야 한다.**
>
> **이것은 큰 "만약"이다.** 직교하지 않으면 곤란해지고 **e에서 b로의 축 변환(transformation of axis)을 하는 행렬이 필요**해진다. (모듈 3에서 다룬다.)
>
> ⭐ **새 축을 직교하게 배치할 수 있다면 그렇게 하라. 계산이 훨씬 빠르고 쉬워진다.**

### 절차
1. **r을 b₁에 투영**한다 → 그 방향의 벡터 투영을 얻는다
2. **r을 b₂에 투영**한다 → 그 방향의 벡터 투영을 얻는다
3. ⭐ **두 벡터 투영의 벡터 합이 곧 r이다**
4. 따라서 **그 두 투영의 계수가 새 기저에서의 r의 숫자**다

### 직교 확인 먼저
```
b₁ · b₂ = 2×(−2) + 1×4 = −4 + 4 = 0
```
> **내적이 0 → 90도.** 길이를 계산할 필요도 없이 **투영을 써도 안전**하다.

### 수치 계산 ⭐
`r_e = (3, 4)`

**b₁ 방향 벡터 투영**
```
(r·b₁)/|b₁|² = (3×2 + 4×1) / (2² + 1²) = 10/5 = 2
→ 벡터 투영 = 2 × b₁ = 2 × (2, 1) = (4, 2)
```

**b₂ 방향 벡터 투영**
```
(r·b₂)/|b₂|² = (3×(−2) + 4×4) / ((−2)² + 4²) = (−6 + 16)/20 = 10/20 = ½
→ 벡터 투영 = ½ × b₂ = ½ × (−2, 4) = (−1, 2)
```

**검산 — 둘을 더하면 원래 r**
```
(4, 2) + (−1, 2) = (3, 4)  ✓
```

**결과**
```
r_b = (2, ½)          즉  r = 2·b₁ + ½·b₂
```

---

## 요약
- **기저 벡터**는 공간을 정의하는 벡터들이다. **`(3,4)`라는 숫자는 기저를 알아야 의미가 있다.**
- ⭐ **벡터 자체는 좌표계와 무관하게 존재한다.** 숫자만 기저에 따라 달라진다.
- **새 기저가 직교하면** 투영(내적)만으로 기저 변환이 된다. `b₁·b₂ = 0` 으로 확인한다.
- 절차: **각 새 기저 벡터로 벡터 투영 → 그 계수들이 새 좌표.** 벡터 합이 원래 벡터가 되는지로 검산한다.
- ⚠️ **직교하지 않으면 행렬이 필요하다** → [모듈 3](../Module%203%20-%20Matrices%20in%20Linear%20Algebra%20-%20Objects%20that%20operate%20on%20Vectors/01%20Matrices,%20vectors,%20and%20solving%20simultaneous%20equation%20problems.md).
- **데이터를 기술하는 벡터는 원래 축에 묶여 있지 않다.** 문제를 풀기 좋게 **기저를 신중히 고르는 것**이 선형대수에서 매우 중요하다.
