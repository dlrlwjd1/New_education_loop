# 03 Cosine & dot product

## 개요
- 강좌: Mathematics for Machine Learning - Linear Algebra (Imperial College London)
- 모듈: Module 2 — Vectors are objects that move around space
- 강사: David Dye
- [MOOC 원본 강의](https://www.mooc.org/learn/linear-algebra-machine-learning/lecture/mMKOw/cosine-dot-product)
- **코사인 법칙**으로부터 **`r·s = |r||s|cos θ`** 를 유도한다. **내적이 두 벡터의 방향 관계를 말해 준다**는 것.

---

## 내용

### 코사인 법칙에서 출발
학교에서 배운 코사인 법칙 — 변이 a, b, c인 삼각형에서:
```
c² = a² + b² − 2ab·cos θ        (θ는 a와 b 사이 각)
```

**벡터 표기로 옮기면**
- 한 벡터를 **r**, 다른 벡터를 **s** 라 하면 나머지 변은 **r − s**.
```
|r − s|² = |r|² + |s|² − 2|r||s|cos θ
```

### 내적으로 좌변을 전개하기 ⭐
```
|r − s|² = (r − s)·(r − s)
         = r·r − s·r − s·r + (−s)·(−s)
         = |r|² − 2(s·r) + |s|²
```

**우변과 비교하면**
```
|r|² − 2(s·r) + |s|²  =  |r|² + |s|² − 2|r||s|cos θ

→ |r|², |s|² 가 양변에서 소거
→ −2(s·r) = −2|r||s|cos θ
→ 마이너스와 2를 약분
```

**결론** ⭐⭐
```
r · s = |r| |s| cos θ
```

### 이것이 뜻하는 것 ⭐
> **내적은 정말로 꽤 심오한 일을 한다.** 두 벡터의 크기를 취하고 **그 사이 각의 코사인을 곱한다.**
>
> **두 벡터가 같은 방향으로 가는 정도**를 말해 주는 것이다.

| θ | cos θ | r·s | 뜻 |
|---|---|---|---|
| **0°** | **1** | **`\|r\|\|s\|`** | **같은 방향.** 두 크기의 곱 그대로 |
| **90°** | **0** | **0** | ⭐ **직교(orthogonal).** 내적이 0이면 90도다 |
| **180°** | **−1** | **`−\|r\|\|s\|`** | **정반대 방향.** 부호가 음수로 나온다 |

> 정리하면 — **내적이 0이면 서로 직교, 같은 쪽을 향하면 양수, 대체로 반대 방향이면 음수.**

---

## 요약
- **코사인 법칙 + 내적 전개**로 **`r·s = |r||s|cos θ`** 를 얻는다.
- 유도의 핵심: `|r−s|² = (r−s)·(r−s)` 로 전개해 코사인 법칙과 비교하면 `|r|²`·`|s|²`가 소거된다.
- ⭐ **내적의 부호가 방향 관계를 알려 준다** — **양수=같은 쪽, 0=직교, 음수=반대 쪽.**
- **내적 = 0 이 직교의 판정법**이며, 이후 [기저 변환](05%20Changing%20basis.md)에서 계속 쓰인다.
