## 내용

### 문제 1 — 사과와 바나나 (가격 발견) ⭐
장을 두 번 봤다고 하자.
```
1차: 사과 2개 + 바나나 3개 = 8 유로
2차: 사과 10개 + 바나나 1개 = 13 유로
```
> **a와 b는 사과 한 개, 바나나 한 개의 가격**이다. 개별 가격을 알아내려면 이 **연립방정식(simultaneous equations)** 을 풀어야 한다.

⚠️ **품목이 많고 장보기 횟수가 많은 일반적인 경우**에는 손으로 푸는 것이 꽤 어렵다. **그래서 컴퓨터 알고리즘이 필요하다.**

**이것이 선형대수 문제인 이유**
- **2, 10, 3, 1** 같은 **일정한 선형 계수(linear coefficients)** 가 **입력 변수 a, b를 출력 8, 13에 연결**한다.
- 가격 벡터 `[a, b]` 가 **비용으로 번역**되고, 그 비용이 1차에 8, 2차에 13이다.

**행렬 문제로 쓰면**
```
⎡  2   3 ⎤ ⎡ a ⎤ = ⎡  8 ⎤
⎣ 10   1 ⎦ ⎣ b ⎦   ⎣ 13 ⎦
    행렬       벡터    벡터
```
> **모듈 1~3에 걸쳐 이 수학적 대상들(벡터와 행렬)이 무엇이고 어떻게 다루는지 쌓아 올린 뒤, 이 문제를 일반적인 경우에 어떻게 푸는지로 돌아온다.**

### 문제 2 — 데이터에 방정식 맞추기 ⭐
> **신경망과 머신러닝에서는 컴퓨터가 방정식을 맞추는 것뿐 아니라 어떤 방정식을 쓸지까지 알아내기를 원한다.** (아주 부정확한 서술이지만 대략의 맛은 맞다.)

- 예: 히스토그램 데이터. **평균이 있고 폭이 있는 모집단**처럼 보인다.
- 풀고 싶은 문제: **이 선을 기술하는 방정식의 파라미터의 최적값을 찾는 것** — 히스토그램 데이터에 가장 잘 맞는 값.

**왜 유용한가** ⭐
> 그 방정식만 있으면 **원본 데이터 전부 없이도 모집단을 기술하는 쉽고 이식 가능한 설명**을 들고 다닐 수 있다. **예컨대 프라이버시 문제에서 자유로워진다.**

- 그리고 **적합이 얼마나 좋은지를 파라미터의 함수로 그릴 수 있다** — 다음 강의의 주제다.

## 요약
- 이 강좌를 끌고 갈 두 문제:
  1. **사과와 바나나** — **연립방정식**. `행렬 × 벡터 = 벡터` 형태로 쓰인다
  2. **데이터 피팅** — 파라미터의 **최적값을 찾는 최적화 문제**
- 첫 문제는 **모듈 1~3(벡터·행렬)** 을 거쳐 풀고, 둘째는 **선형대수 + [다변량 미적분](../../Mathematics%20for%20Machine%20Learning%20-%20Multivariate%20Calculus/README.md)** 이 함께 필요하다.
- 피팅의 실용적 가치: **원본 데이터 없이도 모집단을 기술할 수 있고, 프라이버시 문제에서 자유롭다.**
