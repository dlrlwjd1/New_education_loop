# 03 Getting a handle on vectors

## 개요
- 강좌: Mathematics for Machine Learning - Linear Algebra (Imperial College London)
- 모듈: Module 1 — Introduction to Linear Algebra and to Mathematics for Machine Learning
- 강사: David Dye
- [MOOC 원본 강의](https://www.mooc.org/learn/linear-algebra-machine-learning/lecture/cHM7e/getting-a-handle-on-vectors)
- ⭐ **이 강좌에서 가장 중요한 관점 전환** — 벡터는 물리 공간의 화살표가 아니라 **어떤 공간에서든 위치를 기술하는 목록**이다.

---

## 내용

### 다시 키 분포 문제로
사람들의 키 히스토그램. **2m 넘는 사람도, 1.5m 안 되는 사람도 별로 없다.** 이 분포를 **파라미터 두 개짜리 방정식**으로 맞추고 싶다.

| 파라미터 | 뜻 |
|---|---|
| **μ (mu)** | 분포의 **중심** |
| **σ (sigma)** | 분포의 **폭** |

**정규분포(가우시안) 식**
```
f(x) = 1/(σ√(2π)) · exp( −(x − μ)² / (2σ²) )
```
- **넓이가 1**이다 — 모집단 전체가 100%이므로.
- ⚠️ 강사: **"식의 형태에 너무 신경 쓰지 말라."** 중심 μ, 폭 σ, 넓이 1로 정규화된 것이 전부다.

### 적합의 좋고 나쁨을 재기 ⭐
> **폭을 실제보다 넓게 추측했다고 하자** (넓이 1은 유지). 그러면 **가장자리에서는 너무 높고 가운데서는 너무 낮다.**
>
> **모든 측정값과 모든 추정값의 차이를 더한다** — 사실은 **차이의 제곱**을 더해 **적합의 좋음(goodness) 또는 나쁨(badness)의 척도**를 얻는다.

- 그다음 **피팅 파라미터 σ와 μ를 바꿔 가며 그 좋음이 어떻게 변하는지 그린다.**
- 최적 μ, σ에서는 **제곱합이 0**이고, μ가 어긋나면 값이 커진다. 너무 넓거나 좁아도 마찬가지다.
- 같은 값의 좋음/나쁨을 잇는 **등고선(contour)** 들을 그릴 수 있다.

### 벡터가 등장하는 지점 ⭐
> 모든 가능한 μ, σ에 대해 좋음을 계산하고 싶지는 않다. **몇 번만 계산하고 최적 적합으로 가는 길을 찾고 싶다.**
>
> 너무 큰 μ와 너무 작은 폭에서 시작했다고 하자(사람들이 실제보다 크고 키가 더 촘촘하다고 생각한 것). 그러면 **"μ와 σ를 조금 움직이면 좋아지나 나빠지나?"** 를 묻고 **좋아지면 그 방향으로 계속 간다.**
>
> ⭐ **μ의 변화와 σ의 변화로 이루어진 벡터를 만들 수 있다.** 원래 (μ, σ)가 있고 새 값 (μ′, σ′)이 있어 더 나은지 묻는 것이다.

> **이것들이 벡터다. 공간 주위의 작은 이동이다. 물리 공간의 이동이 아니라 파라미터 공간의 이동이지만 같은 것이다.**
>
> **벡터를 이해하고 언덕을 내려가는 법(= 미적분)을 이해하면 이런 문제를 풀 수 있다.**

### 벡터는 그냥 목록이다 ⭐⭐
> **벡터가 물리적 공간 질서의 기하학적 대상일 필요는 없다. 어떤 종류의 축을 따르는 방향이든 기술할 수 있다. 그러니 벡터를 그냥 목록이라고 생각할 수 있다.**

**예 — 자동차의 공간**
| 성분 | 단위 |
|---|---|
| 가격 | 유로 |
| 배기 성능 | 100km당 CO₂ 그램 |
| NOx 성능 | 대기오염으로 도시를 얼마나 오염시키고 사람을 죽이는가 |
| Euro NCAP 별점 | 충돌 시 안전 |
| 최고 속도 | — |

> **이것이 벡터에 대한 컴퓨터과학의 관점**이고, **공간적 관점은 물리학에서 더 익숙한 것**이다.

**다른 예들**
- **야금학(강사의 분야)**: 어떤 합금이든 **가능한 모든 성분·조성을 기술하는 벡터**로 볼 수 있다.
- **아인슈타인**: 상대성을 구상할 때 **시간을 또 하나의 차원**으로 봤다. **시공간(space-time)은 4차원 공간** — 미터 3차원 + 초 1차원 — 이며 `(x, y, z, t)` 벡터로 썼다.

> 이렇게 놓고 보면 **어떤 함수의 모든 피팅 파라미터의 공간을 생각하고, 벡터를 그 공간을 돌아다니게 해 주는 것으로 생각하는 것이 그리 미친 일이 아니다.**
>
> 우리가 하려는 것은 **그 공간에서 나쁨이 최소화되고 좋음이 최대화되어 함수가 데이터에 가장 잘 맞는 위치를 찾는 것**이다. 나쁨 표면이 지형의 등고선 지도라면 **언덕의 바닥, 지형에서 가능한 가장 낮은 점**을 찾는 것이다.

## 요약
- 데이터 피팅 문제 → **적합의 좋음을 파라미터의 함수로 그린 등고선 지형** → 그 위에서 최저점 찾기.
- ⭐ **피팅 파라미터 공간에서의 이동이 곧 벡터다.** 물리 공간이 아니어도 같은 것이다.
- ⭐⭐ **벡터 = 목록.** 자동차의 속성, 합금의 조성, 시공간 `(x,y,z,t)` 전부 벡터다. **공간적 관점(물리)과 목록 관점(데이터 과학)** 둘 다 유효하다.
- 그래서 필요한 것: **벡터를 다루는 법 + 그 위에서 미적분(기울기·최소)을 하는 법.**
