## 내용

이번 모듈에서 한 것:

1. **데이터의 문제** — 세상에 데이터가 너무 많고, **그것을 분석하고 쓰는 법을 알아내면 실제 세계의 문제를 풀 수 있다.** 이 강좌들이 **머신러닝·데이터 과학의 세계로 가는 데 어디에 놓이는지** 봤다.
2. **두 예제 문제**
   - [사과와 바나나](02%20Motivations%20for%20linear%20algebra.md) — **연립방정식**을 풀어 물건 가격을 발견하기
   - **모델 방정식을 데이터에 최적화**해 맞추기 (피팅 파라미터)
3. **두 문제 모두 벡터와 (아마) 미적분이 필요하다.**
4. 그래서 여정을 **벡터에서 시작**했다 — **벡터 덧셈**과 **스칼라 곱**의 정의.

**다음 모듈 예고**: 벡터로 할 수 있는 **더 많은 연산**, **벡터 공간(vector space)** 의 정의, 그리고 벡터 공간의 **좌표계 = 기저(basis)**.
