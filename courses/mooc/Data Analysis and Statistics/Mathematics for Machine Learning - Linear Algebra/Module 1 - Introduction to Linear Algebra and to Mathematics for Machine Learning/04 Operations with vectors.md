# 04 Operations with vectors

## 개요
- 강좌: Mathematics for Machine Learning - Linear Algebra (Imperial College London)
- 모듈: Module 1 — Introduction to Linear Algebra and to Mathematics for Machine Learning
- 강사: David Dye
- [MOOC 원본 강의](https://www.mooc.org/learn/linear-algebra-machine-learning/lecture/Pd6NY/operations-with-vectors)
- **벡터를 벡터로 만드는 두 규칙** — **덧셈**과 **스칼라 곱**. 그리고 좌표계와 기저 벡터.

---

## 내용

### 벡터란 무엇으로 정의되는가 ⭐
> **벡터는 두 규칙에만 기반한 것이다 — ① 덧셈, ② 스칼라(수)에 의한 곱.**

**집 예제 (데이터 과학의 관점)**
```
집 = (120 m², 침실 2, 욕실 1, 15만 유로)
```
> 물리학에서는 벡터를 **공간을 돌아다니게 하는 것**으로 보지만, **데이터 과학에서는 집이라는 대상을 기술하는 것**으로 본다.

### 규칙 1 — 벡터 덧셈
- 벡터 **r** 끝에 벡터 **s**를 붙이면 **r + s**.
- 반대로 s 다음에 r을 붙이면 **s + r**.
- ⭐ **둘은 같은 결과다: `r + s = s + r`** — **교환법칙(commutative)**.

### 규칙 2 — 스칼라 곱
- 수 a로 벡터를 **늘리거나 줄인다.** `3r` 은 r을 세 번, `½r` 은 절반.
- ⚠️ **음수의 의미**: `−r` 은 **같은 거리를 반대 방향으로 가는 것**이다.

### 좌표계 정하기 ⭐
공간을 두 벡터로 정의한다.

| 기저 벡터 | 뜻 |
|---|---|
| **i** | 왼쪽에서 오른쪽, **단위 길이(길이 1)** |
| **j** | 위아래, **단위 길이** |

```
r = (3, 2)  는  3개의 i  +  2개의 j  를 뜻한다
```
> **(3, 2)라는 표기는 "i를 3번 스칼라 곱하고 j를 2번 스칼라 곱해 벡터 합을 하라"는 지시**다.

**성분별 덧셈**
```
r = (3, 2),  s = (−1, 2)
r + s = (3 + (−1), 2 + 2) = (2, 4)
```
> **벡터 덧셈은 성분끼리 더하면 된다.**

### 결합법칙(associativity)
> 성분별로 하기 때문에 **벡터 덧셈은 결합적이다.**
```
(r + s) + t = r + (s + t)      — 괄호를 어디 두든 상관없다
```

### 좌표계에서의 스칼라 곱
```
2r = 2 × (3, 2) = (6, 4)
```
> **각 성분에 곱한다.** `2r`은 r을 한 번 하고 또 한 번 하는 것과 같다.

### 뺄셈의 정의 ⭐
```
−r = (−3, −2)
r + (−r) = (3 + (−3), 2 + (−2)) = (0, 0)      ← 원점으로 돌아온다
```
> **벡터 뺄셈은 그저 −1을 곱한 것을 더하는 것**이다.
```
r − s = (3, 2) − (−1, 2) = (3 + 1, 2 − 2) = (4, 0)
```

### 다시 집 예제로 — 이 규칙이 데이터에도 통한다 ⭐
```
집 = (120 m², 침실 2, 욕실 1, 15만 유로)

집 두 채 = 2 × (120, 2, 1, 150)
        = (240, 4, 2, 300)
```
> **똑같은 집 두 채를 나란히 샀다면 240 m², 침실 4, 욕실 2, 30만 유로 — 말이 된다.**
>
> 세 채든, 모양이 다른 집이든, **심지어 음수 집이든** — **우리가 벡터를 정의한 방식은 이런 대상에도 그대로 적용된다.**

---

## 요약
- **벡터를 정의하는 것은 두 연산뿐 — 덧셈과 스칼라 곱.**
- **덧셈은 교환적(`r+s = s+r`)이고 결합적(`(r+s)+t = r+(s+t)`)** 이다. **성분별로 더하면 된다.**
- **`−r`은 같은 거리를 반대 방향으로.** 그래서 **뺄셈 = (−1)배를 더하는 것.**
- **기저 벡터(basis vectors) i, j** 로 좌표계를 정의하면 `(3, 2)`는 **"3i + 2j를 하라"는 지시**다.
- ⭐ **기하학적으로 생각하는 게 가장 쉽지만 실제 공간일 필요는 없다.** 집의 속성 같은 **데이터 목록**에도 같은 규칙이 그대로 적용된다.
