## 내용

이번 주에 배운 것을 순서대로:

| 단계 | 내용 |
|---|---|
| **문제 설정** | 에이전트가 **행동을 취하고 그에 따른 보상**을 받는다. **각 행동의 가치 = 그 행동을 취했을 때 받는 기대 보상.** ⚠️ **가치 함수 q\*는 에이전트에게 알려져 있지 않다** |
| **표본 평균법** | q\* 추정. **a를 취해 받은 보상의 합 ÷ a를 취한 횟수** |
| **증분 갱신 규칙** | 표본 평균의 **재귀적 정의**를 찾아 유도. ⭐ **행동을 취한 횟수와 직전 추정값만 저장하면 된다** |
| **일반 스텝 크기** | 스텝 크기를 더 일반적으로 만들 수 있고, ⭐ **상수 스텝 크기를 쓰면 시간에 따라 변하는 밴딧 문제를 더 효과적으로 풀 수 있다** |
| **탐험 vs 활용** | **탐험 = 지식을 개선할 기회.** 어떤 행동은 우리가 아는 것보다 나을 수 있으므로 **최선이 아니라고 생각하는 행동도 시도해 추정을 개선**해야 한다. **활용 = 지금 최선이라 생각하는 행동을 취해 가장 많은 보상을 얻으려는 것** |
| **ε-탐욕** | **ε의 비율로 탐험, 1−ε의 비율로 활용.** 활용할 때는 **현재 추정값을 최대화하는 행동**, 탐험할 때는 **균등 무작위** |
| **낙관적 초기값** | **초기값이 q\*보다 크면 에이전트가 행동들을 체계적으로 탐험**한다. ⚠️ **낙관은 시간이 지나며 옅어지고 에이전트는 결국 탐험을 멈춘다** |
| **UCB** | **신뢰구간을 써서 활용과 탐험을 섞는다.** ⭐ **불확실성 앞에서의 낙관** 전략 |

### 밴딧과 RL의 관계 ⭐
> **밴딧 문제는 대체로 더 큰 강화학습 문제의 부분집합으로 볼 수 있다.**
>
> **보상 최대화, 불확실성에 직면했을 때의 행동 선택 같은 개념이 강화학습의 핵심**이다.
