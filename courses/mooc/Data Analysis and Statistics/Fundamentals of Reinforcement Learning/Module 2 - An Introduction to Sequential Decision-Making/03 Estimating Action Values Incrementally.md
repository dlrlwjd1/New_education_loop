# 03 Estimating Action Values Incrementally

## 개요
- 강좌: Fundamentals of Reinforcement Learning (University of Alberta · Amii)
- 모듈: Module 2 — An Introduction to Sequential Decision-Making
- 강사: Martha White · Adam White
- [MOOC 원본 강의](https://www.mooc.org/learn/fundamentals-of-reinforcement-learning/lecture/XWqhe/estimating-action-values-incrementally)
- ⭐⭐ **증분 갱신 규칙** — 이 강좌 전체에서 몇 번이고 다시 나올 **일반 학습 규칙**이 여기서 나온다.

---

## 내용

### 문제 — 데이터를 다 저장할 수 없다
> **하루 수백만 히트를 받는 웹사이트**를 운영한다고 하자. 이것도 k-armed bandit으로 볼 수 있다 — **추정 가치는 각 광고가 벌어들인 총액**이고 목표는 **가장 돈을 많이 버는 광고를 띄우는 것**이다.
>
> ⚠️ **수백만 클릭의 데이터를 저장하지 않고 어떻게 가치 추정을 최신으로 유지할까?**

### 표본 평균을 재귀 형태로 ⭐
현재 보상을 합에서 빼내고, `n−1`로 곱하고 나누는(= 1을 곱하는) 조작을 거치면 **이전 추정값으로 다음 추정값을 쓸 수 있다.**

```
Qₙ₊₁ = Qₙ + (1/n) · [ Rₙ − Qₙ ]
```

> ⭐ **더 이상 모든 데이터를 저장할 필요가 없다.** 필요한 것은 **행동을 취한 횟수와 직전 추정값**뿐이다.

### 일반 학습 규칙 ⭐⭐
> **이 방정식은 이 강좌 내내 여러 번 나타날 형태다.**

```
새 추정값 ← 이전 추정값 + 스텝 크기 × [ 목표 − 이전 추정값 ]
                                      └────┬────┘
                                        오차(error)
```

| 용어 | 뜻 |
|---|---|
| **오차(error)** | **이전 추정값과 새 목표의 차이** |
| **목표(target)** | 여기서는 **새로 받은 보상 R** |
| **스텝 크기(step size)** | **오차 쪽으로 얼마나 이동할지.** `α` 로 쓰며 **0~1 사이의 수** |

> **그 목표 쪽으로 한 걸음 내디디면 오차를 줄이는 새 추정값이 만들어진다.**
>
> ⭐ **표본 평균의 경우 스텝 크기가 `1/n`** 이다.

### 비정상(non-stationary) 문제 ⭐
> 의사 예제로 돌아가서 — **치료 B가 겨울철에 더 효과적**이라면? **보상 분포가 시간에 따라 변하는 비정상 밴딧 문제**다.
>
> **의사는 이 변화를 모르지만 적응하고 싶다.**

**해법: 고정 스텝 크기** ⭐⭐
> **αₙ이 0.1 같은 상수**라면 **최근 보상이 오래된 보상보다 추정에 더 큰 영향**을 준다.

**왜 그런가 — 지수적 감쇠**
증분 갱신식을 전개하고 재귀를 계속 풀어 초기값 Q₁까지 되돌리면:
```
Qₙ₊₁ = (1−α)ⁿ·Q₁ + Σ α(1−α)^(n−i)·Rᵢ
```
| 항 | 뜻 |
|---|---|
| 첫째 항 | ⭐ **Q₁(초기값)의 기여가 시간에 따라 지수적으로 감소한다** |
| 둘째 항 | ⭐ **시간상 더 먼 과거의 보상일수록 합에 지수적으로 적게 기여한다** |

> **종합하면 — 초기화의 영향은 데이터가 쌓일수록 0으로 가고, 가장 최근 보상이 현재 추정에 가장 크게 기여한다.**

---

## 요약
- ⭐⭐ **증분 갱신: `Qₙ₊₁ = Qₙ + α·[Rₙ − Qₙ]`.** 모든 데이터를 저장할 필요가 없다.
- **일반 형태: `새 추정 ← 이전 추정 + 스텝 크기 × 오차`.** 이 강좌 내내 반복해 나온다.
- **표본 평균 = 스텝 크기 `1/n`.**
- ⭐ **비정상 문제에는 고정 스텝 크기 `α`** 를 쓴다 — **최근 보상에 더 큰 가중치**를 주고 **초기값과 먼 과거의 영향이 지수적으로 감쇠**한다.
