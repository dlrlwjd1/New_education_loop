# 02 Learning Action Values

## 개요
- 강좌: Fundamentals of Reinforcement Learning (University of Alberta · Amii)
- 모듈: Module 2 — An Introduction to Sequential Decision-Making
- 강사: Martha White · Adam White
- [MOOC 원본 강의](https://www.mooc.org/learn/fundamentals-of-reinforcement-learning/lecture/aMAXQ/learning-action-values)
- **표본 평균법(sample-average method)** 으로 q*를 추정하고, **탐욕적 행동 선택**과 **탐험-활용 딜레마**를 도입한다.

---

## 내용

### 문제
> 의사가 **각 치료의 장기 결과를 이미 안다면** 적절한 치료를 고르는 것은 사소한 일이다. **불행히도 대개 그렇지 않다.**
>
> 보통 의사는 **각 치료에 대해 배우려고 여러 번 시험을 돌린다.** 매일 **지금까지 모은 데이터로 어느 치료가 최선이라고 믿는지 추정**할 수 있다.

### 표본 평균법 ⭐
```
Qₜ(a) = (행동 a를 취했을 때 관측한 보상의 합) / (행동 a를 취한 횟수)
```
> **t 시점의 가치는 t 이전에 취한 행동들에 기반**하므로 `t − 1`까지를 쓴다.
>
> ⚠️ **아직 행동 a를 한 번도 취하지 않았다면 기본값(예: 0)으로 둔다.**

### 진행 예시 (보상: 나아지면 1, 아니면 0)
| 시점 | 사건 | Q(치료 P) |
|---|---|---|
| 1 | 치료 P 처방 → 환자가 나아짐(보상 1) | **1** (데이터 한 점뿐) |
| 2 | 다시 무작위로 치료 P → 실패(보상 0) | **0.5** |
| — | 다른 행동들은 아직 미시도 | **0** (초기 추정을 0으로 뒀으므로) |

> ⭐ **의사가 더 많은 환자를 관찰할수록 추정값이 참 행동 가치에 접근한다.**

### 탐욕적(greedy) 행동 선택 ⭐
> 현실의 의사라면 **환자에게 치료를 무작위로 배정하지 않을 것**이다. 지금 최선이라고 생각하는 치료를 배정할 것이다. 이 방법을 **탐욕적(greedy)** 이라 한다.
```
탐욕적 행동 = argmax_a Qₜ(a)
```
> **탐욕적 행동을 고른다는 것은 에이전트가 현재 지식을 활용(exploiting)한다는 뜻**이다. **지금 얻을 수 있는 최대 보상을 얻으려 한다.**

### 탐험(exploration) ⭐
> 대안으로 에이전트는 **비탐욕적 행동을 골라 탐험**할 수 있다.
>
> **즉각적 보상을 희생하고 다른 행동들에 대한 정보를 더 얻기를 바라는 것**이다.

### 탐험-활용 딜레마 ⭐⭐
> ⚠️ **에이전트는 탐험과 활용을 동시에 선택할 수 없다.**
>
> **이것이 강화학습의 근본 문제 중 하나 — 탐험-활용 딜레마(exploration-exploitation dilemma)** 다.

---

## 요약
- **표본 평균법: `Q(a) = (a를 취해 받은 보상 합) / (a를 취한 횟수)`.** 데이터가 쌓일수록 참값에 접근한다.
- **탐욕적 행동 = `argmax Q(a)`** — **현재 지식을 활용**하는 것.
- **탐험 = 비탐욕적 행동을 골라** 즉각 보상을 희생하고 **정보를 얻는 것.**
- ⭐⭐ **둘을 동시에 할 수 없다 — 탐험-활용 딜레마.**
