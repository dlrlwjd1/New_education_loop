# 05 Optimistic Initial Values

## 개요
- 강좌: Fundamentals of Reinforcement Learning (University of Alberta · Amii)
- 모듈: Module 2 — An Introduction to Sequential Decision-Making
- 강사: Martha White · Adam White
- [MOOC 원본 강의](https://www.mooc.org/learn/fundamentals-of-reinforcement-learning/lecture/mUlAM/optimistic-initial-values)
- **낙관적 초기값** — **불확실성 앞에서의 낙관(optimism in the face of uncertainty)** 원칙을 초기값으로 구현한다.

---

## 내용

### 아이디어 ⭐
> **의사가 처음에 각 치료의 결과에 대해 아주 낙관적이라면?**
>
> **불확실성 앞에서 낙관적이라는 이 원칙은 탐험-활용의 균형을 잡는 흔한 전략**이다.

의사가 **각 치료가 반대 증거가 나오기 전까지 100% 효과적이라고 가정**하면 — **한 치료가 환자를 못 고칠 때까지 무작위로 처방**하고, 그다음엔 나머지 둘 중에서 고르고, 이런 식으로 계속 간다.

### 구체 예시 (초기값 2, α = 0.5, 항상 탐욕적 선택)
> 이전에는 초기 추정값을 0으로 뒀는데 **그것이 반드시 낙관적인 것은 아니다.** 이제 **확실히 과대평가하도록 초기값을 2로** 둔다.

| 시점 | 사건 | 결과 |
|---|---|---|
| 1 | 값이 다 같아 무작위로 **치료 P** → 환자가 나아짐(보상 1) | ⭐ **치료가 성공했는데도 P의 추정값이 2 → 1.5로 감소**한다. **보상 1이 낙관적 초기 추정 2보다 작기 때문** |
| 2 | 가장 높은 값(Y 또는 B) 중 **Y** 선택 → 실패(보상 0) | Y가 **2 → 1**로 감소. P(1.5)보다 낮아진다 |
| 3 | 가장 높은 **B** 선택 → 나아짐(보상 1) | B가 **2 → 1.5**로만 감소 |

> ⭐ **낙관적 초기값이 학습 초기에 탐험을 유도한다.** 의사가 **첫 세 시간 단계에 세 치료를 모두 시도**했고 이후에도 계속 모두 시도한다.

### 10-armed 문제에서
> 행동 가치가 정규분포에서 표집되므로 **초기 추정값 5는 낙관적일 가능성이 높다**(그림의 모든 값이 3 미만).
>
> **어떤 행동을 처음 선택할 때 관측 보상은 낙관적 초기 추정보다 작을 가능성이 높다.** 그러면 **그 행동의 추정값이 내려가고 다른 행동들이 상대적으로 더 매력적으로 보이게 된다.**

**실험 결과** ⭐
- 기준선: **ε=0.1, 초기값 0인 ε-탐욕 에이전트**
- 비교: **낙관적 초기값을 가진 탐욕 에이전트**
- ⭐ **학습 초기에는 낙관적 에이전트가 더 많이 탐험하므로 성능이 더 나쁘다.** 그러나 **표본이 쌓이며 낙관이 씻겨 나가 탐험이 줄어든다.**

### ⚠️ 한계 두 가지 ⭐⭐
**① 초기에만 탐험을 유도한다**
> **낙관적 초기값은 학습 초기에만 탐험을 이끈다. 즉 어느 시점 이후에는 에이전트가 탐험을 계속하지 않는다.**
>
> ⚠️ **이것이 비정상 문제에서 문제를 일으킨다.** 예컨대 **어떤 행동 가치가 몇 시간 단계 뒤에 바뀌면, 낙관적 에이전트는 이미 특정 행동에 정착해 있어 다른 행동이 이제 더 낫다는 것을 알아채지 못한다.**

**② 얼마나 낙관적으로 둘지 모를 수 있다**
> **실무에서 최대 보상을 모를 수 있기 때문**이다.

> 그럼에도 **낙관적 초기값은 매우 유용한 휴리스틱으로 입증되었고**, 강좌의 나머지에서 **종종 다른 탐험 접근과 결합해** 계속 쓴다.

---

## 요약
- **낙관적 초기값 = 불확실성 앞에서의 낙관**을 초기 추정값으로 구현한 것.
- ⭐ **성공한 행동조차 추정값이 내려가므로**(보상 < 낙관적 초기값) **모든 행동을 골고루 시도하게 된다.**
- 실험: **초기에는 탐험 때문에 성능이 나쁘지만 낙관이 씻겨 나가며 탐험이 줄어든다.**
- ⚠️ **한계 둘: ① 초기에만 탐험 → 비정상 문제에서 변화를 못 알아챈다. ② 최대 보상을 몰라 값을 정하기 어려울 수 있다.**
