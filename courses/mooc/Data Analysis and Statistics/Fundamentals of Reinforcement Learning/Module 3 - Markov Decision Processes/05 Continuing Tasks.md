## 내용

### 에피소드형 vs 연속형 ⭐⭐
| | **에피소드형(episodic)** | **연속형(continuing)** |
|---|---|---|
| 구조 | **에피소드로 나뉜다** | ⭐ **독립적인 에피소드로 나눌 수 없다.** 상호작용이 계속 이어진다 |
| 종단 상태 | **모든 에피소드는 종단 상태로 끝나야 한다** | ⭐ **종단 상태가 없다** |
| 다음 시작 | **직전 에피소드가 어떻게 끝났든 무관하게 시작** | — |
| 이득 | **종료까지의 보상 합** | 아래의 **할인 이득** |

**예 — 스마트 온도조절기**
> 건물의 온도를 조절하는 온도조절기는 **환경과의 상호작용을 멈추지 않으므로 연속 과제**로 형식화한다.

| 요소 | 설계 |
|---|---|
| **상태** | **현재 온도** + **하루 중 시각, 건물 안 사람 수** 같은 상황 정보 |
| **행동** | **히터를 켠다 / 끈다** (둘뿐) |
| **보상** | ⭐ **누군가 수동으로 온도를 조정할 때마다 −1**, 그 외에는 0 |

> **음의 보상을 피하려고 온도조절기는 사용자의 선호를 미리 예측하는 법을 배우게 된다.**

### 왜 할인이 필요한가 ⭐⭐
> 에피소드형처럼 미래 보상을 다 더하려 하면 **이제는 무한 수열을 더하는 것이 되어 이득이 유한하지 않을 수 있다.**

**해법 — 할인율(discount rate) γ**
```
G_t ≐ R_(t+1) + γ·R_(t+2) + γ²·R_(t+3) + …
    = Σ_(k=0..∞) γ^k · R_(t+k+1)          (0 ≤ γ < 1)
```
> ⭐ **즉시 보상이 합에 더 많이 기여하고, 먼 미래의 보상은 점점 커지는 γ의 거듭제곱이 곱해져 덜 기여한다.**
>
> **직관적으로도 말이 된다 — 오늘의 1달러가 1년 뒤의 1달러보다 당신에게 더 값지다.**

### 유한함의 증명 ⭐
`R_max`를 **에이전트가 어느 시간 단계에서든 받을 수 있는 최대 보상**이라 하자.

```
G_t ≤ Σ_(k=0..∞) γ^k · R_max = R_max · Σ_(k=0..∞) γ^k = R_max · 1/(1−γ)
```
> **모든 보상을 R_max로 바꿔 상계(upper bound)를 잡고, 상수 R_max를 합 밖으로 빼면 남는 것은 기하급수(geometric series)다. 기하급수는 `1/(1−γ)`로 수렴하므로 `R_max/(1−γ)`는 유한하고 이것이 G_t의 상계다. 따라서 G_t는 유한하다.**

### γ의 두 극단 ⭐⭐
| γ | 이득 | 에이전트 |
|---|---|---|
| **γ = 0** | ⭐ **다음 시간 단계의 보상만** | **근시안적(shortsighted).** 즉시 기대 보상만 신경 쓴다 |
| **γ → 1** | **즉시 보상과 미래 보상이 거의 동등하게 가중** | ⭐ **원시안적(farsighted)** |

### 이득의 재귀식 ⭐⭐
> **두 번째 항부터 γ를 밖으로 묶어내면**

```
G_t = R_(t+1) + γ·( R_(t+2) + γ·R_(t+3) + … )
    = R_(t+1) + γ·G_(t+1)
```
> ⭐ **놀랍게도 괄호 안의 수열이 바로 다음 시간 단계의 이득이다. 그래서 그냥 `G_(t+1)`로 바꿔 쓸 수 있다.**
>
> **왼쪽에 G_t, 오른쪽에 G_(t+1)이 있는 재귀 방정식이다. 이 단순한 식은 보이는 것보다 훨씬 강력하다. 앞으로 이 식을 이용해 학습 알고리즘을 설계한다.**

---

## 요약
- **연속 과제**는 **종단 상태 없이 상호작용이 무한히 이어진다**(스마트 온도조절기).
- ⭐⭐ **할인 `G_t = Σ γ^k R_(t+k+1)`, `0 ≤ γ < 1`** — **이득이 유한함을 보장**한다. 증명은 **기하급수 → `R_max/(1−γ)` 상계**.
- **γ = 0이면 근시안, γ → 1이면 원시안.**
- ⭐⭐ **재귀식 `G_t = R_(t+1) + γ·G_(t+1)`** — 이후 **벨만 방정식과 학습 알고리즘의 뼈대**가 된다.
