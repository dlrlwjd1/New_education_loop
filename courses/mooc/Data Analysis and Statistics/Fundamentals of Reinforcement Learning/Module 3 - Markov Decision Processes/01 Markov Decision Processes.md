## 내용

### 밴딧의 두 가지 한계 ⭐⭐
> **k-armed 밴딧 문제는 흥미로운 질문을 많이 던지지만 실세계 문제의 많은 면을 담지 못한다. 에이전트는 매번 같은 상황을 마주하고 같은 행동이 항상 최적이다.**

**토끼 예제로 보는 두 한계**

| # | 한계 | 예 |
|---|---|---|
| **①** | ⭐ **다른 상황은 다른 행동을 요구한다** | 오른쪽에 당근·왼쪽에 브로콜리면 오른쪽으로 가지만, **반대로 놓이면 왼쪽으로 가야 한다.** 밴딧은 이걸 담지 못한다 |
| **②** | ⭐ **지금의 행동이 미래에 얻을 보상의 양에 영향을 준다** | 당근(보상 +10) 바로 옆에 **호랑이**가 있다면, 오른쪽으로 가면 당근은 먹지만 **도망칠 만큼 빠르지 않을 수 있다.** **장기 영향을 고려하면 왼쪽으로 가 브로콜리(+3)로 만족하는 편이 낫다** |

> **밴딧 토끼는 즉시 보상만 신경 쓰므로 당근을 향해 간다. 하지만 결정의 장기적 영향을 고려하면 더 나은 결정을 내릴 수 있다.**

호랑이 옆 상태에서 왼쪽 행동을 하면 **호랑이가 토끼를 먹고 보상 −100**을 받는다. 어떤 **상태(state) 연쇄**가 일어나는지는 **토끼가 취하는 행동에 달려 있다.**

### 에이전트–환경 상호작용 형식화 ⭐⭐
> **에이전트와 환경은 이산 시간 단계(discrete time steps)에서 상호작용한다.**

```
        상태 S_t, 보상 R_t
환경 ─────────────────────▶ 에이전트
  ▲                            │
  └────────── 행동 A_t ─────────┘
```

| 기호 | 뜻 |
|---|---|
| **S_t ∈ 𝒮** | 가능한 상태 집합에서 온 시각 t의 상태 |
| **A_t ∈ 𝒜(S_t)** | ⭐ **`𝒜(S_t)`는 상태 S_t에서 유효한 행동들의 집합** — 상태마다 가능한 행동이 다를 수 있다 |
| **S_(t+1)** | 한 시간 단계 뒤, **부분적으로 에이전트의 행동에 근거해** 도달하는 새 상태 |
| **R_(t+1) ∈ ℛ** | 환경이 주는 **스칼라 보상** |

> ⭐ **이 상호작용은 상태·행동·보상으로 이루어진 경험의 궤적(trajectory)을 만든다. 행동은 즉시 보상뿐 아니라 미래 상태에, 그리고 그를 통해 미래 보상에 영향을 준다.**

### 전이 동역학 함수 p ⭐⭐
> **밴딧에서처럼 결과는 확률적이므로 확률의 언어를 쓴다. 에이전트가 어떤 상태에서 행동을 취하면 가능한 다음 상태와 보상이 여럿 있다.**

```
p(s', r | s, a) ≐ Pr{ S_(t+1) = s', R_(t+1) = r | S_t = s, A_t = a }
```
> **상태 s와 행동 a가 주어졌을 때, p는 다음 상태 s'와 보상 r의 결합 확률(joint probability)을 알려 준다.**

**성질**
- 이 강좌에서는 보통 **상태·행동·보상의 집합이 유한**하다고 가정한다. (걱정할 것 없다 — **무한 집합과 비가산 집합을 다루는 알고리즘도 배운다.**)
- p는 확률분포이므로 **음이 아니어야 하고**, **모든 가능한 다음 상태와 보상에 대한 합이 1**이어야 한다.

### 마르코프 성질(Markov property) ⭐⭐
> ⭐ **미래의 상태와 보상은 오직 현재 상태와 행동에만 의존한다. 이것을 마르코프 성질이라 한다.**
>
> **현재 상태만으로 충분하며, 더 이전의 상태들을 기억한다고 해서 미래에 대한 예측이 나아지지 않는다는 뜻이다.**

---

## 요약
- **밴딧의 두 한계**: ① **상황마다 최적 행동이 다르다**, ② **지금 행동이 미래 보상에 영향을 준다.** MDP가 이 둘을 담는다.
- **에이전트–환경 상호작용**은 이산 시간 단계에서 일어나며 **상태·행동·보상의 궤적**을 만든다.
- ⭐⭐ **전이 동역학 `p(s', r | s, a)`** — 상태와 행동이 주어졌을 때 **다음 상태와 보상의 결합 확률.** 합이 1인 확률분포다.
- ⭐⭐ **마르코프 성질** — **현재 상태만으로 충분하다.** 과거를 더 기억해도 예측이 나아지지 않는다.
