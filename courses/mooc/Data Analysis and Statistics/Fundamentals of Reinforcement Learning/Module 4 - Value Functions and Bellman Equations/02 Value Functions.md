## 내용

### 왜 가치 함수인가 ⭐
> **많은 문제가 어느 정도의 지연 보상(delayed reward)을 수반한다. 상점 관리자는 가격을 내려 재고를 다 팔아 단기 이익을 극대화할 수 있다. 하지만 수요가 높을 때 팔 재고를 유지하는 편이 장기적으로 낫다.**
>
> **강화학습에서 보상은 단기 이익의 개념을 담는다. 그러나 목표는 장기적으로 가장 많은 보상을 얻는 정책을 배우는 것이다. 가치 함수가 이것이 무슨 뜻인지 형식화한다.**

### 상태 가치 함수 ⭐⭐
> **대략 말하면, 상태 가치 함수는 특정 상태에서 출발해 에이전트가 받을 것으로 기대하는 미래 보상이다. 더 정확히는 주어진 상태로부터의 기대 이득(expected return)이다.**

```
v_π(s) ≐ E_π[ G_t | S_t = s ]
```
⭐ **에이전트의 행동 방식도 총 보상에 영향을 주므로, 가치 함수는 항상 주어진 정책에 대해 정의된다.**
- **아래첨자 π**는 **가치 함수가 π에 따라 행동을 선택하는 것에 조건부**임을 나타낸다.
- **기댓값 위의 아래첨자 π**도 마찬가지로 **기댓값이 정책 π에 대해 계산됨**을 뜻한다.

### 행동 가치 함수 ⭐⭐
> **행동 가치는 에이전트가 먼저 특정 행동을 선택했을 때 무슨 일이 일어나는지를 기술한다. 더 형식적으로는, 에이전트가 행동 a를 선택한 뒤 정책 π를 따를 때의 기대 이득이다.**

```
q_π(s, a) ≐ E_π[ G_t | S_t = s, A_t = a ]
```

### 왜 가치 함수가 결정적인가 ⭐⭐
> **가치 함수는 강화학습에서 결정적으로 중요하다. 장기적 결과를 관측할 때까지 기다리는 대신 에이전트가 자기 현재 상황의 질을 질의할 수 있게 해 주기 때문**이다.

**이점은 두 가지다.**
1. **이득은 즉시 얻을 수 있는 것이 아니다.**
2. ⭐ **이득은 정책과 환경 동역학 양쪽의 확률성 때문에 무작위일 수 있다.** **가치 함수는 이득에 대한 평균을 냄으로써 가능한 모든 미래를 요약한다.**

> **궁극적으로 우리가 가장 신경 쓰는 것은 좋은 정책을 배우는 것이고, 가치 함수는 서로 다른 정책의 질을 판단할 수 있게 해 준다.**

### 예 1 — 체스 ⭐
| 요소 | 설계 |
|---|---|
| MDP 유형 | **에피소드형** |
| **상태** | **판 위 모든 말의 위치** |
| **행동** | **합법적인 수(legal moves)** |
| **종료** | **승·패·무승부로 게임이 끝날 때** |
| **보상** | **승리 시 +1, 그 밖의 모든 수는 0** |

⚠️ **이 보상은 경기 중에 에이전트가 얼마나 잘하고 있는지 별로 말해 주지 않는다. 0이 아닌 보상을 보려면 게임이 끝날 때까지 기다려야 한다.**

⭐⭐ **가치 함수는 훨씬 더 많은 것을 말해 준다.**
> **상태 가치는 미래 보상 합의 기댓값과 같다. 0이 아닌 유일한 보상이 승리 시 +1이므로, 상태 가치는 곧 현재 정책 π를 따를 때 이길 확률이다.**

- **이 2인 게임에서 상대의 수는 상태 전이의 일부다.** 환경이 **에이전트의 말과 상대의 말을 모두 움직여** 새 상태 s'로 만든다.
- **s'의 가치가 s의 가치보다 낮다면, 정책 π를 계속 따를 때 이 새 상태에서 이길 가능성이 더 낮다는 뜻**이다.
- **행동 가치 함수는 각 가능한 수마다 (나머지 게임에서 π를 따른다는 전제 아래) 이길 확률을 평가하게 해 준다.**

### 예 2 — 격자 세계(Grid World) ⭐⭐
| 요소 | 설계 |
|---|---|
| **상태** | 격자 위 위치 |
| **행동** | 상 · 하 · 좌 · 우 |
| ⚠️ **벽** | **격자 밖으로 나갈 수 없고, 부딪히면 보상 −1** |
| 그 밖 | 대부분의 행동은 보상 0 |
| ⭐ **특수 상태 A** | **A에서의 모든 행동이 +10 보상**을 내고 **A′로 전이** |
| ⭐ **특수 상태 B** | **B에서의 모든 행동이 +5 보상**을 내고 **B′로 전이** |

> ⚠️ **가치 함수가 무엇인지 알아내려면 먼저 정책을 명시해야 한다.** 여기서는 **균등 무작위 정책(uniform random policy)**, **연속 과제이므로 γ = 0.9**.

**결과 해석** ⭐⭐

| 관찰 | 이유 |
|---|---|
| **아래쪽 근처 값이 음수** | **A와 B에 닿기 전에 벽에 부딪힐 가능성이 높기 때문.** A와 B가 이 MDP에서 양의 보상의 유일한 원천이다 |
| **A가 가장 높은 값 — 그런데 10보다 작다** | ⭐ **A에서의 모든 전이가 에이전트를 아래쪽 벽 가까이로 옮기고, 아래쪽 벽 근처에서는 무작위 정책이 벽에 부딪혀 음의 보상을 받을 가능성이 높기 때문** |
| **B의 값은 5보다 약간 크다** | ⭐ **B에서의 전이는 에이전트를 가운데로 옮긴다. 가운데에서는 부딪힐 가능성이 낮고 값이 높은 A·B에 가깝기 때문** |

> **가치 함수가 이 모든 가능성을 얼마나 간결하게 요약하는지 정말 놀랍다.**

---

## 요약
- ⭐⭐ **상태 가치 `v_π(s)` = 정책 π 아래 상태 s에서의 기대 이득.**
- ⭐⭐ **행동 가치 `q_π(s,a)` = 상태 s에서 행동 a를 먼저 고른 뒤 π를 따를 때의 기대 이득.**
- **가치 함수는 항상 특정 정책에 대해 정의된다.**
- **가치 함수의 효용**: ① 장기 결과를 기다리지 않고 **지금 상황의 질을 질의**할 수 있다, ② **확률성을 평균 내어 무한한 미래를 하나의 수로 요약**한다.
- **체스** — 보상이 승리 시 +1뿐이면 **상태 가치 = 이길 확률**.
- **격자 세계** — 값의 크기가 **벽 충돌 위험과 고가치 상태와의 거리**를 반영한다.
