- ⭐⭐ **정책 반복(policy iteration)** — **평가와 개선을 번갈아 하는 "정책과 가치의 춤"** 으로 최적 정책을 찾는다.

---

## 내용

### 알고리즘 ⭐⭐
```
π₁ ──평가(evaluation)──▶ v_π₁ ──개선(improvement, 탐욕화)──▶ π₂
π₂ ──평가──▶ v_π₂ ──개선──▶ π₃ ──▶ …
```
> **정책 개선 정리는, 주어진 정책이 이미 최적이 아닌 한, 그 가치 함수에 대해 탐욕적으로 행동함으로써 엄격히 더 나은 정책을 만들 수 있다고 말한다.**
>
> **이는 점점 더 나은 정책들의 수열을 준다. 각 정책은 직전 것보다 개선임이 보장된다 — 직전 것이 이미 최적이 아닌 한.**

**종료** ⭐
> **한 반복을 마쳤는데 정책이 그대로면 최적 정책을 찾은 것이므로 알고리즘을 끝낼 수 있다.**
>
> ⭐ **이렇게 생성되는 각 정책은 결정적이고, 결정적 정책의 수는 유한하므로 이 반복적 개선은 결국 최적 정책에 도달해야 한다.**

### "정책과 가치의 춤" ⭐⭐
> **먼저 현재 정책 π₁을 평가해 π₁의 가치를 정확히 반영하는 새 가치 함수를 얻는다. 개선 단계는 `v_π₁`을 써서 탐욕적 정책 π₂를 만든다.**
>
> ⚠️ **이 시점에서 π₂는 π₁의 가치 함수에 대해 탐욕적이지만, `v_π₁`은 더 이상 π₂의 가치를 정확히 반영하지 않는다.**
>
> **다음 단계인 평가가 가치 함수를 π₂에 대해 정확하게 만든다. 그러고 나면 정책이 다시 탐욕적이지 않게 된다.**
>
> ⭐⭐ **이 정책과 가치의 춤은, 자기 자신의 가치 함수에 대해 탐욕적인 유일한 정책 — 최적 정책 — 에 도달할 때까지 오간다. 그 지점에서, 그리고 오직 그 지점에서만, 정책이 탐욕적이면서 동시에 가치 함수가 정확하다.**

**기하학적 시각화** ⭐
> **가치 함수가 정확한 선과 정책이 탐욕적인 선 사이를 오가는 것으로 그릴 수 있다. 두 선은 오직 최적 정책과 최적 가치 함수에서만 교차한다.**
>
> **정책 반복은 먼저 `v = v_π` 선 위로 사영하고, 그다음 `π가 v에 대해 탐욕적인` 선 위로 사영함으로써 언제나 교차점을 향해 전진한다.** (물론 실제 기하는 더 복잡하지만 같은 직관이 성립한다.)

### 의사 코드 ⭐
```
1. 초기화: 각 상태 s에 대해 V(s)와 π(s)를 임의로 설정

2. 정책 평가:
   반복 정책 평가를 호출해 V가 π의 가치를 반영하게 만든다

3. 정책 개선:
   policy_stable ← true
   각 상태 s에 대해:
       old_action ← π(s)
       π(s) ← argmax_a Σ_(s',r) p(s',r|s,a)[ r + γ V(s') ]
       if π(s) ≠ old_action:  policy_stable ← false

4. policy_stable이면 종료, 아니면 2로 돌아간다
```

### 예제 — 더 어렵게 만든 격자 세계 ⭐⭐
> **앞서 4×4 격자에서 무작위 정책을 평가하고 한 번만 탐욕화해도 최적 정책을 찾았다. 이건 정책 반복에 그다지 흥미로운 경우가 아니다. 제어 과제를 조금 더 어렵게 문제를 수정하자.**

| 변경 | 내용 |
|---|---|
| **종단 상태 하나 제거** | **에피소드를 끝낼 방법이 하나뿐이 되게** |
| ⭐ **나쁜 상태 추가** | **파란색으로 표시된 상태로 전이하면 보상 −10** |
| **최적 정책** | **흰색의 구불구불한 저비용 경로를 따라 종단 상태로 가야 한다** |

> **이 추가된 복잡성 때문에 정책 반복이 경로를 발견하는 데 여러 반복이 걸린다.**

**진행 과정**

| 단계 | 결과 |
|---|---|
| **초기화** | 균등 무작위 정책, 모든 가치 추정 0 |
| **평가 ①** | **값이 어디서나 꽤 음수**, 목표 근처가 조금 덜 음수 |
| **개선 ①** | ⭐ **종단 상태 근처에서는 정책이 저비용 경로를 올바르게 따른다.** ⚠️ **그러나 맨 아랫줄에서는 더 직접적이지만 가치가 낮은, 나쁜 상태를 지나는 경로를 택한다** |
| **평가 ②** | **한 번의 개선만으로도 값이 훨씬 합리적으로 보이기 시작한다.** 아직 끝은 아니다 |
| **개선 ②** | ⭐ **우하단 상태가 이제 저비용 경로를 따라 곧장 위로 간다** |
| **평가 ③** | ⭐ **우하단 상태의 값이 −15에서 −6으로 올라간다** |
| **개선 · 평가 반복** | 또 다른 상태의 행동 선택이 개선되고, 평가가 그 변화를 반영하고… |
| **수렴** | **정책이 최적에 도달해 파란 상태를 피하는 저비용 경로를 따른다.** 한 번 더 평가하면 최적 가치 함수를 얻고, **다시 탐욕화해도 정책이 바뀌지 않는다 → 정책 반복 완료** |

> ⭐ **이 예제는 정책 반복의 힘을 보여 준다 — 점점 나아지는 정책의 수열을 따라 최적 정책에 도달함을 보장한다. 정책 반복은 탐색 공간을 가로질러 나아가며, 이는 최적 정책이 (이 경우 문자 그대로) 단순하지 않을 때 핵심적이다.**

---

## 요약
- ⭐⭐ **정책 반복 = 평가 ↔ 개선의 반복.** **정책이 더 이상 바뀌지 않으면 최적이다.**
- **결정적 정책은 유한하므로 반드시 유한 번에 최적에 도달한다.**
- ⭐⭐ **"정책과 가치의 춤"** — 개선하면 가치가 부정확해지고, 평가하면 정책이 탐욕적이지 않게 된다. **두 조건이 동시에 성립하는 유일한 지점이 최적**이다.
- **나쁜 상태(−10)를 넣은 격자 예제**에서는 여러 번의 평가·개선을 거쳐 저비용 경로를 찾아낸다.
