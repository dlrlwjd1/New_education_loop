## 내용

### 일반화된 정책 반복(GPI) ⭐⭐
> **지금까지 정책 반복을 꽤 경직된 절차로 제시했다 — 현재 정책을 평가하고 탐욕화하기를 번갈아 하며, 각 단계를 끝까지 완료한다. 직관적으로 이것을 느슨하게 할 수 있다.**
>
> ⭐ **각 평가 단계가 추정을 현재 정책의 가치에 조금 더 가깝게 하되 끝까지는 아니고, 각 정책 개선 단계가 정책을 조금 더 탐욕적으로 하되 완전히 탐욕적이지는 않다고 하자. 직관적으로 이 과정도 여전히 최적 정책과 가치 함수를 향해 전진할 것이다. 실제로 이론도 같은 것을 말해 준다.**
>
> ⭐⭐ **"일반화된 정책 반복"이라는 용어로, 정책 평가와 정책 개선을 교차시키는 모든 방식을 가리킨다.**

### 가치 반복(value iteration) ⭐⭐
> **첫 GPI 알고리즘. 가치 반복에서도 여전히 모든 상태를 훑으며 현재 가치 함수에 대해 탐욕화한다. 그러나 정책 평가를 끝까지 돌리지 않는다 — 모든 상태에 대해 딱 한 번의 스윕만 수행하고, 그 뒤 다시 탐욕화한다.**

```
v_(k+1)(s) ← max_a  Σ_(s',r) p(s',r | s,a) [ r + γ · v_k(s') ]
```
> ⭐ **이 갱신은 어떤 특정 정책도 참조하지 않는다. 그래서 이름이 "가치 반복"이다.**
>
> **전체 알고리즘은 반복 정책 평가와 아주 비슷하게 생겼다. 고정된 정책에 따라 값을 갱신하는 대신, 현재 가치 추정을 최대화하는 행동을 써서 갱신한다.**

| 항목 | 내용 |
|---|---|
| **수렴** | ⭐ **극한에서 `v*`로 수렴한다** |
| **정책 추출** | **최적 가치 함수에서 argmax를 취해 최적 정책을 복원**한다 |
| **종료 조건** | ⚠️ **영원히 기다릴 수 없으므로 종료 조건이 필요하다.** 정책 평가와 같은 조건을 쓴다 — **한 전체 스윕에서 가치 함수의 최대 변화가 작은 값 `θ`보다 작아지면 종료** |

### 동기 vs 비동기 DP ⭐⭐
| 방식 | 내용 |
|---|---|
| **동기(synchronous)** | ⭐ **가치 반복도 정책 반복처럼 매 반복마다 전체 상태 공간을 훑는다. 이렇게 체계적인 스윕을 하는 방법을 동기적이라 부른다.** ⚠️ **상태 공간이 크면 문제가 된다 — 스윕 하나가 아주 오래 걸릴 수 있다** |
| **비동기(asynchronous)** | ⭐ **어떤 순서로든 상태의 값을 갱신한다. 체계적인 스윕을 하지 않는다. 어떤 상태를 다른 상태가 한 번 갱신되기도 전에 여러 번 갱신할 수도 있다** |

⚠️ **비동기의 필수 조건**
> **수렴을 보장하려면 비동기 알고리즘도 모든 상태의 값을 계속 갱신해야 한다.** 예컨대 **같은 세 상태만 영원히 갱신하고 나머지를 무시하는 것은 허용되지 않는다. 전혀 갱신되지 않는 다른 상태들이 올바를 수 없기 때문**이다.

⭐ **비동기의 장점**
> **비동기 알고리즘은 선택적 갱신을 통해 가치 정보를 빠르게 전파할 수 있다. 때로는 체계적 스윕보다 효율적일 수 있다. 예를 들어 최근에 가치가 바뀐 상태들 근처의 상태를 갱신할 수 있다.**

---

## 요약
- ⭐⭐ **GPI = 정책 평가와 개선을 교차시키는 모든 방식.** **각 단계를 끝까지 돌릴 필요가 없다.**
- ⭐⭐ **가치 반복** = **평가 한 스윕 + 탐욕화를 한 갱신으로 합친 것.** `v_(k+1)(s) ← max_a Σ p[r + γ v_k(s')]`. **정책을 참조하지 않는다.**
- **동기적 방법은 전체 상태 공간을 체계적으로 훑는다.** ⚠️ **상태 공간이 크면 스윕 하나가 너무 오래 걸린다.**
- **비동기적 방법은 순서가 자유롭다.** ⚠️ **단, 모든 상태를 계속 갱신해야 수렴이 보장된다.** ⭐ **선택적 갱신으로 가치 정보를 빠르게 전파할 수 있다.**
- ⭐ **GPI는 가치 반복, 비동기 DP, 그리고 이 전문과정에서 다룰 거의 모든 방법을 통합한다.**
