---

## 내용

### 핵심 아이디어 ⭐⭐
> **동적 계획법 알고리즘은 벨만 방정식을 갱신 규칙(update rule)으로 바꿈으로써 얻어진다.**
>
> ⭐ **반복 정책 평가의 아이디어는 너무 단순해서 처음엔 좀 시시해 보일 수 있다. 벨만 방정식을 가져다 그대로 갱신 규칙으로 쓴다.**

```
v_(k+1)(s) ← Σ_a π(a|s) Σ_(s',r) p(s',r | s,a) [ r + γ · v_k(s') ]
```
> **이제 참 가치 함수에 대해 성립하는 방정식이 아니라, 가치 함수의 추정을 반복적으로 다듬는 절차를 갖게 됐다. 이것이 가치 함수에 대한 점점 더 나은 근사의 수열을 만든다.**

### 스윕(sweep)과 수렴 ⭐⭐
- **임의의 초기화 `v_0`에서 시작**한다.
- ⭐ **각 반복은 상태 공간의 모든 상태 s에 이 갱신을 적용한다. 이것을 스윕(sweep)이라 부른다.**
- **반복 적용하면 `v_π`에 대한 점점 더 나은 근사가 된다.**

⭐⭐ **왜 이게 통하는가**
> **이 갱신이 가치 함수 근사를 바꾸지 않는다면, 즉 모든 상태에서 `v_(k+1) = v_k`이면, `v_k = v_π`이고 우리는 가치 함수를 찾은 것이다.**
>
> **`v_π`가 벨만 방정식의 유일한 해이기 때문이다. 갱신이 `v_k`를 그대로 두는 유일한 경우는 `v_k`가 이미 벨만 방정식을 따르는 경우뿐이다.**
>
> ⭐ **사실 어떤 `v_0`를 골라도 `k → ∞`의 극한에서 `v_k`가 `v_π`로 수렴함을 증명할 수 있다.**

### 구현 — 두 배열 vs 한 배열 ⭐
| 방식 | 내용 |
|---|---|
| **두 배열(two-array)** | `V`에 **현재 근사 가치 함수**, `V'`에 **갱신된 값**을 저장. ⭐ **옛 값이 도중에 바뀌지 않은 채로 한 상태씩 새 값을 계산할 수 있다.** 전체 스윕이 끝나면 새 값들을 `V`에 쓴다 |
| **한 배열(single-array)** | ⚠️ **일부 갱신이 옛 값 대신 새 값을 쓰게 된다.** ⭐ **그래도 수렴이 보장되고 보통 더 빨리 수렴한다 — 갱신된 값을 더 일찍 쓰기 때문.** 다만 강의는 단순함을 위해 두 배열 버전에 집중한다 |

### 예제 — 4×4 격자 세계 ⭐⭐
| 요소 | 설계 |
|---|---|
| **유형** | **에피소드형 MDP** |
| **종단 상태** | ⭐ **좌상단과 우하단.** **그림에 두 곳으로 보이지만 형식적으로는 같은 하나의 상태다** |
| **보상** | **모든 전이에 −1** |
| **할인** | ⭐ **에피소드형이므로 할인 없는 경우 γ = 1** |
| **행동** | **상 · 하 · 좌 · 우, 각각 결정적.** ⚠️ **격자 밖으로 나가는 행동은 제자리에 남긴다** |
| **평가 대상 정책** | **균등 무작위 — 각 행동 1/4** |

> ⭐ **이 가치 함수는 주어진 상태에서 종료까지의 기대 스텝 수를 나타낸다.**
>
> **두 배열 버전을 쓰므로 상태를 훑는 순서는 중요하지 않다.** (예시는 좌→우, 위→아래 순서)
>
> ⚠️ **종단 상태의 값은 0으로 정의되므로 절대 갱신하지 않는다.**

**첫 스윕**
> **모든 값을 0으로 초기화했다. 상태 1의 갱신을 계산하려면 모든 행동에 대해 합한다. 왼쪽 행동은 균등 무작위 정책에서 확률 1/4이고, `p`가 결정적이므로 하나의 `s'`에 대한 보상과 가치만 합에 기여한다 — 보상 −1과 종단 상태 가치 0.**
>
> **모든 상태 가치를 0으로 초기화했고 각 전이 보상이 −1이므로 다른 행동들의 계산도 똑같이 생겼다. 결과적으로 `V'(1) = −1`.**
>
> ⚠️ **상태 2로 넘어가면, 상태 1의 값을 이미 갱신했지만 우리가 돌리는 버전은 `V`에 저장된 옛 값을 쓰므로 갱신 식에서 상태 1의 값은 여전히 0이다.**
>
> ⭐ **결국 모든 상태 값이 0으로 초기화됐으므로, 모든 상태의 값이 −1이 된다.** 스윕이 끝나면 `V'`를 `V`로 복사한다.

### 종료 조건 ⭐
> **바깥 루프는 근사 가치 함수의 변화가 작아질 때까지 계속된다. 한 반복에서 상태 가치에 대한 가장 큰 갱신량을 추적해 이를 `Δ`(delta)라 하고, 이 최대 변화량이 사용자가 정한 상수 `θ`(theta)보다 작아지면 바깥 루프를 종료한다.**
>
> ⭐ **근사 가치 함수가 변하지 않게 되면 `v_π`에 수렴한 것이고, 마찬가지로 변화가 아주 작아지면 `v_π`에 가까워진 것이다.**
>
> ⭐ **`θ`를 작게 고를수록 최종 가치 추정이 더 정확해진다.** (예시는 θ = 0.001, 첫 반복의 최대 변화는 1.0이라 계속 진행)

### 값이 퍼져 나가는 모습 ⭐
> **두 번째 스윕 후, 종단 상태가 가장 가까운 상태들의 값에 먼저 영향을 주기 시작하는 것을 보라. 한 번 더 돌리면 그 영향이 더 멀리 전파된다. 몇 번 더 돌리면 각 상태의 값이 종단 상태와의 근접도와 어떻게 관련되는지 보이기 시작한다.**
>
> **최대 `Δ`가 `θ`보다 작아질 때까지 돌리면, 근사 가치 함수가 무작위 정책의 가치 함수로 수렴한다.**

---

## 요약
- ⭐⭐ **반복 정책 평가 = 벨만 방정식을 그대로 갱신 규칙으로 쓰는 것.**
- **스윕** = 모든 상태에 갱신을 한 번씩 적용. **어떤 `v_0`에서 시작해도 `v_k → v_π`가 보장된다.**
- **갱신이 값을 바꾸지 않으면 이미 `v_π`다** — `v_π`가 벨만 방정식의 **유일한 해**이기 때문.
- **두 배열 구현**이 개념적으로 깔끔하고, ⭐ **한 배열 구현이 보통 더 빨리 수렴**한다.
- **종료 조건**: 한 스윕에서의 **최대 변화 `Δ < θ`**.
- **4×4 격자 예제** — γ=1, 전이마다 −1, 종단 상태 값은 갱신하지 않음. ⭐ **가치가 종단 상태에서 바깥으로 퍼져 나간다.**
