## 내용

> **이번 주에는 동적 계획법과, 그것으로 정책 평가와 제어 과제를 푸는 법을 배웠다. 이 알고리즘들은 이후 배울 강화학습 알고리즘의 토대를 이룬다.**

### 정리 ⭐
| 항목 | 내용 |
|---|---|
| **정책 평가** | **특정 정책 π의 상태 가치 함수 `v_π`를 결정하는 과제** |
| **반복 정책 평가** | ⭐ **`v_π`에 대한 벨만 방정식을 갱신 규칙으로 바꾼다.** `v_π`에 대한 점점 더 나은 근사의 수열을 만든다 |
| **제어** | **정책을 개선하는 과제** |
| **정책 개선 정리** | ⭐ **현재 가치에 대해 탐욕화(greedify)하기만 하면 새 정책 π′를 만들 수 있고, π′는 π가 이미 최적이 아닌 한 엄격히 더 낫다** |
| **정책 반복** | **정책 평가 + 정책 개선(탐욕화)의 두 단계를 정책이 바뀌지 않을 때까지 반복.** 그때 **정책은 최적임이 보장된다** |
| **일반화된 정책 반복(GPI)** | ⭐ **평가와 개선 단계를 끝까지 돌릴 필요가 없다.** 한 예가 **가치 반복**이고, **비동기 DP 방법들도 포함**한다 |
| **동기 vs 비동기** | **동기 방법은 전체 상태 공간을 반복해 훑는다.** ⭐ **비동기 방법은 더 유연해서 어떤 순서로든 상태를 갱신할 수 있고, 가치 정보를 더 효율적으로 전파할 수 있다. 상태 공간이 아주 클 때 특히 유용하며, 소수의 관련 상태에 집중하도록 설계할 수 있다** |

### ⭐⭐ 마무리 관점
> **동적 계획법에서 우리는 어떤 의미로 가능한 최선의 상황을 가정한다 — MDP가 정확히 어떻게 작동하는지 안다. 그런데도 최적 정책을 효율적으로 계산하는 데 상당한 사고와 영리한 알고리즘이 필요했다.**
>
> **이 강좌 나머지에서 보게 될 거의 모든 알고리즘에서 이 영리함의 이득을 계속 거두게 된다.**

## 요약
- **평가**: 벨만 방정식 → 갱신 규칙 = **반복 정책 평가**.
- **개선**: **정책 개선 정리** — 탐욕화하면 엄격히 더 나은 정책.
- **제어**: **정책 반복 = 평가 + 개선의 반복**, 정책이 안 바뀌면 최적.
- ⭐ **GPI**는 두 단계를 끝까지 안 돌려도 된다 — **가치 반복**과 **비동기 DP**를 포함한다.
- ⭐⭐ **모델을 완전히 안다는 최선의 상황에서조차 영리한 알고리즘이 필요했다.** 그 영리함이 이후 알고리즘의 토대다.
