# IV analysis in R

## 개요
- 실제 공개 데이터(Card 데이터)로 R에서 도구변수(instrumental variable, IV) 분석을 수행한다: 4년제 대학 근접성이 교육 연수를 통해 임금에 미치는 효과.
- 순응자 비율(도구변수 강도)과 처치 의도(intention-to-treat, ITT) 효과를 추정하고, CACE = ITT / 순응자 비율을 계산한다.
- 2단계 최소제곱(2SLS)을 수작업(두 번의 회귀)과 `ivpack`의 `ivreg`로 수행하고, 공변량을 통제한 분석까지 확장한다.

## 내용
### 연구 설정
- 데이터: 오래전 출판된 공개 데이터셋 — 4년제 대학 근접성이 학교 교육 연수, 궁극적으로 소득에 미치는 영향.
- A(처치) = 교육 연수(years of education), Y(결과) = 소득(임금), Z(제안된 도구변수) = 4년제 대학 근처에서 성장했는지 여부.
- 공변량: 부모의 교육 연수, 거주 지역, 나이, 인종 등.
- 동기: 교육이 많을수록 소득이 높은 경향은 있지만, 실제 인과 효과가 얼마인지는 교란 효과와 분리하기 어렵다 — 교육을 더 받는 사람은 그 외에도 여러 면에서 다를 수 있어 비측정 교란 우려가 있다.
- 도구변수 논리: 4년제 대학 근처에서 자란 것은 더 많은 교육을 받도록 하는 일종의 권유(encouragement)이며, (인구통계·부모 교육 연수 등을 통제하면) 소득에 직접적으로는 관련되지 않는다고 주장할 수 있다.

### 데이터 탐색
- `ivpack` 패키지의 `card.data` 사용. 도구변수 = `nearc4`, 결과 = `lwage`(로그 임금 — 소득 데이터는 치우쳐 있어 원 논문처럼 로그 변환), 처치 = `educ`(교육 연수).
- 권유받은 비율: `mean(nearc4)` ≈ **0.68** (약 68%가 4년제 대학 근처 거주).
- 히스토그램: 로그 임금은 비교적 대칭이고 뚜렷한 이상치 없음. 교육 연수는 변동이 크며 12년(고졸)에 큰 스파이크가 있고 그 이상은 일부 대학 수학 또는 4년제 졸업자.

### 순응자 비율(도구변수 강도)
- 순응자 개념을 보여주기 위해 교육을 이분화한다: `educ12` = 교육 연수 > 12년 지시변수(연속형 그대로 분석할 수도 있음).
- 여기서 순응자란: 4년제 대학 근처에 살면 12년 초과 교육을 받고, 아니면 받지 않았을 사람.
- 추정: E[educ12|nearc4=1] − E[educ12|nearc4=0] = **0.12** — 순응자 약 12%.
- 해석: 극단적으로 강한 도구는 아니지만 걱정할 만큼 약하지도 않다. 4년제 대학 근처 거주가 12년 초과 교육 확률을 실제로 높인다. 이 값은 권유가 처치받음에 미치는 인과 효과이기도 하다.

### ITT와 CACE
- ITT 효과: 권유(4년제 대학 근처 거주)가 임금에 미치는 인과 효과 = E[lwage|nearc4=1] − E[lwage|nearc4=0] ≈ **0.16** — 근처에 산 사람들의 로그 임금이 더 높다.
- CACE = ITT / 순응자 비율 = 0.16 / 0.12 ≈ **1.28** — 순응자(근처에 살면 12년 초과 교육을 받고 아니면 안 받았을 사람들)에서의 교육의 임금 효과.
- CACE가 ITT보다 큰 것은 반항자 없음(no defiers) 가정 하에서 기대되는 바다. 여기서 반항자란 권유와 반대로 행동하는 사람 — 근처에 살면 12년 초과 교육을 받지 않고, 멀리 살면 받는 사람. 그런 사람이 없다는 가정이 그럴듯한지 생각해야 한다.

### 2SLS 수작업 (두 번의 회귀)
- 1단계: 처치(educ12)를 도구변수(nearc4)에 `lm`으로 회귀하고 예측값을 얻는다. 도구변수가 이진이므로 예측값은 두 개뿐: 권유군의 12년 초과 교육 예측 확률 **0.54**, 비권유군 **0.42**.
- 2단계: 결과(lwage)를 처치 자체가 아니라 **1단계의 처치 예측값**에 회귀한다.
- 예측값의 계수 = 인과 효과 = **1.28** — 공변량이 없는 단순한 경우 ITT/순응자 비율과 정확히 같은 답.

### ivreg 사용
- `ivpack`의 `ivreg`로 2SLS를 직접 수행할 수 있다: 결과 ~ 처치 | 도구변수 형식.
- 장점: 표준오차를 자동으로 준다 — `robust.se`로 강건 표준오차를 얻을 수 있고, 이전 수작업 방식은 표준오차를 얻으려면 추가 단계가 필요했다.
- 교육 계수 = 약 1.28(앞과 동일), 표준오차와 p-값 제공 — 도구변수 가정이 만족된다면 인과 효과의 강한 증거(매우 유의).

### 공변량을 통제한 IV 분석
- 이 예에서 IV 가정이 무조건적으로는 그럴듯하지 않을 수 있다: 4년제 대학 근처는 주거비가 비싸 고소득 가정일 수 있는 등, 근처 거주자와 아닌 사람이 여러 면에서 다를 수 있다.
- 인구통계 변수·부모 교육 연수 등을 통제하면, **공변량이 같은 사람들 사이에서(조건부로)** IV 가정이 성립한다고 볼 수 있다.
- `ivreg`에서 결과 ~ 처치 + 공변량들 | 도구변수 + 공변량들 형식으로 두 단계 모두에 공변량을 넣는다.
- 결과: 처치 계수 약 **1.2**, 여전히 매우 유의 — 여러 변수를 통제한 뒤에도 교육 연수 증가가 임금 상승으로 이어진다는 꽤 강한 증거.

## 예시
```r
library(ivpack)

# 데이터: Card 데이터 (도구변수 nearc4, 결과 lwage, 처치 educ)
data(card.data)

# 탐색
mean(card.data$nearc4)      # 약 0.68 = 권유(근처 거주) 비율
hist(card.data$lwage)       # 로그 임금: 비교적 대칭
hist(card.data$educ)        # 교육 연수: 12년에 스파이크

# 처치 이분화: 12년 초과 교육
educ12 <- card.data$educ > 12

# 순응자 비율 = P(A=1|Z=1) - P(A=1|Z=0)
propcomp <- mean(educ12[card.data$nearc4 == 1]) -
            mean(educ12[card.data$nearc4 == 0])
propcomp   # 0.12

# ITT 효과
itt <- mean(card.data$lwage[card.data$nearc4 == 1]) -
       mean(card.data$lwage[card.data$nearc4 == 0])
itt        # 약 0.16

# CACE = ITT / 순응자 비율
itt / propcomp   # 약 1.28

# 2SLS 수작업
s1 <- lm(educ12 ~ card.data$nearc4)        # 1단계: 처치 ~ 도구변수
predtx <- predict(s1, type = "response")
table(predtx)                               # 0.42 (Z=0), 0.54 (Z=1)
lm(card.data$lwage ~ predtx)                # 2단계: 계수 1.28

# ivreg로 직접 2SLS (표준오차 자동)
ivmodel <- ivreg(lwage ~ educ12 | nearc4, data = card.data)
robust.se(ivmodel)   # 계수 약 1.28, 강건 SE와 p-값 (매우 유의)

# 공변량 통제 IV 분석 (두 단계 모두에 공변량 포함)
ivmodel <- ivreg(lwage ~ educ12 + exper + reg661 + reg662 + ... |
                 nearc4 + exper + reg661 + reg662 + ...,
                 data = card.data)
robust.se(ivmodel)   # 처치 계수 약 1.2, 여전히 매우 유의
```

## 요약
- Card 데이터에서 4년제 대학 근접성(nearc4)을 교육(educ)의 도구변수로, 로그 임금(lwage)을 결과로 IV 분석을 수행했다.
- 순응자 비율 0.12(도구변수가 아주 강하지도 걱정스럽게 약하지도 않음), ITT 효과 약 0.16, CACE = 0.16/0.12 ≈ 1.28.
- 2SLS 수작업(1단계 예측값 0.42/0.54 → 2단계 회귀)과 ITT/순응자 비율 계산이 같은 답(1.28)을 준다.
- `ivreg`는 같은 결과에 표준오차(`robust.se`)까지 자동으로 제공한다.
- 무조건적 IV 가정이 의심스러우면 공변량을 두 단계 모두에 넣어 조건부 IV 가정 하에 분석한다 — 통제 후에도 계수 약 1.2로 유의했다.
