# Doubly robust estimators

## 개요
- 이중 강건 추정량(doubly robust estimator), 다른 이름으로 증강 IPTW(augmented IPTW, AIPTW)의 직관과 성질을 다룬다.
- 잠재적 결과 평균 E[Y^1]을 추정하는 두 가지 방법 — IPTW와 결과 회귀 모형(outcome regression) — 을 복습한 뒤 이 둘을 결합한다.
- 성향점수 모형과 결과 모형 중 **하나만 맞아도** 불편(unbiased) 추정이 되는 이중 강건성의 원리를 직관적으로 설명한다.

## 내용
### 배경 1: IPTW 추정량 복습
- 모두가 처치받았을 때의 잠재적 결과 평균 E[Y^1]에 집중한다(다른 잠재적 결과도 가중치만 다를 뿐 유사).
- IPTW 추정량: **(1/n) Σ_i A_i Y_i / π(X_i)**
  - 분모는 성향점수 π(X) — 처치군이므로 그 그룹의 처치 확률의 역수로 가중.
  - A는 이진 처치 지시변수. Y 옆에 A를 곱해 합에 처치군의 값만 포함되게 한다(대조군은 A=0이라 계산되지 않음).
  - 교란이 없는 유사 모집단(pseudo-population)에서의 Y 표본 평균으로 생각할 수 있다.
- 성향점수가 올바르게 특정되면(correctly specified) — 즉 실제 P(A=1|X) = π(X)이면 — 이 추정량은 불편이다.

### 배경 2: 결과 회귀 모형 접근
- 처치군에 국한한 결과 모형 **m1(X) = E[Y | A=1, X]** 를 세운다(첨자 1은 처치군을 뜻함).
- 잠재적 결과 평균을 원하면 이 조건부 평균을 교란 변수의 분포에 대해 평균(여기서는 경험적 분포에 대한 평균)해야 한다.
- 추정량: **(1/n) Σ_i [A_i Y_i + (1−A_i) m1(X_i)]**
  - 처치군(A=1)이면 관찰된 Y를 그대로 사용 — 일관성(consistency) 가정에 의해 Y = Y^1이므로.
  - 대조군(1−A = 1)이면 처치군에서 적합한 회귀 모형을 적용해, **만약 그들이 처치받았다면 가졌을 Y 값의 최선의 추측**(모형 평균)을 사용.
  - 이를 모두 더해 n으로 나누면, X로 교란이 통제되었다면(unconfoundedness) 유효한 추정이다.
- 결과 모형이 올바르게 특정되면 — E[Y | A=1, X] = m1(X)이면 — 불편 추정량이다.

### 이중 강건 추정량의 정의
- 이중 강건 추정량은 **성향점수 모형이 맞거나 결과 회귀 모형이 맞으면(둘 중 하나만 맞아도, 어느 쪽이든) 불편**인 추정량이다.
- 한 예:
  - **(1/n) Σ_i { A_i Y_i / π(X_i) − [ (A_i − π(X_i)) / π(X_i) ] · m1(X_i) }**
  - 왼쪽은 표준 IPTW 부분, 오른쪽은 결과 회귀 모형이 들어간 **증강(augmentation)** 부분이다.

### 경우 1: 성향점수 모형이 맞고 결과 모형이 틀린 경우
- 결과 모형이 틀림: E[Y|A=1, X] ≠ m1(X). 성향점수는 맞음: E[A|X] = P(A=1|X) = π(X).
- 표본 평균은 표본이 커지면 기대값이 되므로, 중괄호 안의 기대값이 E[Y^1]과 같은지가 관건이다.
- E[A|X] = π(X)이므로 (A − π(X)) 부분의 기대값이 0 → 증강 항 전체가 기대값에서 사라진다.
- 남는 것은 IPTW 부분뿐인데, 성향점수가 맞으면 그것이 이미 E[Y^1]의 유효한 추정량이다. → 회귀 모형이 틀려도 괜찮다.

### 경우 2: 성향점수 모형이 틀리고 결과 모형이 맞는 경우
- 성향점수 틀림: E[A|X] ≠ π(X). 결과 모형 맞음: E[Y|A=1, X] = m1(X).
- 대수적으로 항을 재배열하면(동치 변형) [Y − m1(X)]에 어떤 계수가 곱해진 항과 m1(X)의 평균 항으로 나뉜다.
- 결과 모형이 맞으면 [Y − m1(X)] 부분의 기대값이 0으로 가고, 곱해지는 부분은 상수로 수렴할 뿐 폭발하지 않으므로 그 항 전체가 사라진다(형식적 증명이 아닌 직관).
- 남는 것은 회귀 모형 m1(X)를 X 분포에 대해 평균한 것 — E[Y|A=1, X]를 X에 대해 주변화한 것으로 곧 E[Y^1]이다. → 성향점수가 틀려도 괜찮다.

### 성질과 명칭
- 이런 추정량을 **증강 IPTW(augmented IPTW, AIPTW)** 라고도 부른다 — 표준 IPTW에 결과 모형이 들어간 증강 항을 더한 형태.
- 이런 추정량은 매우 많으며, 준모수 이론(semiparametric theory)으로 가장 효율적인(most efficient) 형태를 식별할 수 있다(이 강의 범위 밖).
- 이중 강건성 외의 보너스: 일반 IPTW 추정량보다 **더 효율적**(분산이 더 작음)인 경향이 있다.
- 구현은 조금 더 복잡하지만 성능이 더 좋은 편이다.

## 요약
- E[Y^1]은 IPTW((1/n) Σ A_i Y_i/π(X_i)) 또는 결과 회귀((1/n) Σ [A_i Y_i + (1−A_i) m1(X_i)])로 추정할 수 있고, 각각 해당 모형이 맞을 때 불편이다.
- 이중 강건(AIPTW) 추정량은 두 접근을 결합해, 성향점수 모형과 결과 모형 중 **하나만 맞으면** 불편이다.
- 성향점수가 맞으면 증강 항의 기대값이 0이 되어 IPTW 부분만 남고, 결과 모형이 맞으면 IPTW 관련 항이 사라져 회귀 모형의 평균만 남는다.
- AIPTW는 일반 IPTW보다 효율적인(분산이 작은) 경향이 있으며, 준모수 이론으로 최적 형태를 찾을 수 있다.
