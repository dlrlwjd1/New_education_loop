# Analyzing data after matching

## 개요
- 매칭(matching)과 균형 확인(balance check)을 마친 뒤 결과(outcome) 데이터를 분석하는 통계 방법을 다룬다.
- 무작위화 검정(randomization test, 순열 검정 permutation test / 정확 검정 exact test)의 원리와 이진·연속 결과에서의 적용을 예시로 설명한다.
- McNemar 검정, 짝지은 t-검정(paired t-test), 그리고 매칭을 고려하는 기타 결과 모형들을 소개한다.

## 내용
### 매칭 후 결과 분석의 목표
- 매칭이 성공적으로 끝나고 균형에 만족했다면 결과 분석으로 넘어간다.
- 하고 싶은 것: (1) 처치 효과에 대한 가설 검정(hypothesis testing) — 처치 효과가 있는가?, (2) 처치 효과의 추정과 신뢰구간(confidence interval).
- 어떤 방법을 쓰든 **매칭을 고려(take matching into account)** 해야 한다.

### 무작위화 검정(randomization test)의 아이디어
- 순열 검정(permutation test), 정확 검정(exact test)이라고도 하며, 실제 무작위 시험(randomized trial) 데이터에 쓸 수 있는 검정이다. 매칭을 마쳤으므로 데이터를 무작위 시험 데이터처럼 취급한다.
- 절차:
  1. 검정통계량(test statistic)을 정하고 관찰 데이터에서 계산한다.
  2. 귀무가설(처치 효과 없음)이 참이라고 가정한다.
  3. 각 쌍(pair) 안에서 처치 배정을 무작위로 순열(permute)하고 검정통계량을 다시 계산한다.
  4. 이를 반복해 기록한다.
  5. 관찰된 검정통계량이 순열로 얻은 분포에 비해 이례적(unusual)인지 본다. 귀무가설이 참이면 관찰값은 순열 분포와 잘 어울려야 한다.

### 이진 결과 예시: 13개 매칭 쌍
- 이진(yes/no) 결과와 13개 매칭 쌍. 검정통계량은 **처치군의 사건(event) 수** (다른 통계량을 골라도 결론은 본질적으로 같다).
- 데이터 표: 각 행이 매칭 쌍, 값은 결과. 예: 쌍 1은 처치 0, 대조 0 → 일치 쌍(concordant pair); 쌍 2는 처치 1, 대조 0 → 불일치 쌍(discordant pair).
- 관찰된 검정통계량: 처치군의 1의 개수 = **6**.
- 순열 시 일치 쌍은 아무 영향이 없다(0-0 쌍은 라벨을 바꿔도 0-0). **처치 효과에 대한 정보는 모두 불일치 쌍에서 나온다.** 이 예에서는 불일치 쌍이 7개.
- 각 쌍에서 확률 0.5의 이항분포(동전 던지기)로 처치/대조 라벨을 뒤집을지 결정하고, 검정통계량을 재계산한다(예: 순열 1 → 5, 순열 2 → 7, 순열 3 → 3, …).
- 1,000번 반복해 검정통계량 분포를 그리면, 1 같은 값은 매우 드물고(약 10/1,000) 4, 5는 흔하다. 관찰값 6은 분포의 중앙 부근이라 귀무가설과 모순되지 않는다 — 처치 효과의 증거가 없다.
- p-값: 관찰값만큼 또는 그보다 극단적인 값의 확률. 여기서는 6, 7, 8의 확률에, 분포가 대칭이므로(사건 수 대신 비사건 수를 셀 수도 있으므로 1은 8과 똑같이 이례적) 1, 2, 3의 확률까지 더한다(양쪽 꼬리).

### McNemar 검정
- 짝지은 이항 데이터(paired binomial data)에 흔히 쓰는 검정. 결과에 따라 처치–대조 쌍의 개수를 세는 2×2 표를 만든다.
  - 둘 다 결과 1인 쌍: 1개, 둘 다 0인 쌍: 5개(일치 쌍).
  - 처치만 결과 있음: 5개, 대조만 결과 있음: 2개(불일치 쌍).
- 처치 효과 정보는 불일치 쌍(5 vs 2)에 있다. 효과가 없다면 비대각(off-diagonal) 두 수가 비슷해야 하고, 크게 다르면 효과의 증거다.
- 결과 p-값 ≈ 0.45로 처치 효과의 증거가 없으며, 순열 분포에서 여섯 구간의 확률을 더해 1,000으로 나눈 값과 대략 같다.

### 연속 결과 예시: 수축기 혈압, 20개 쌍
- 결과가 수축기 혈압(systolic blood pressure)인 20개 처치–대조 쌍. 검정통계량은 표본 평균의 차이(처치군 평균 − 대조군 평균).
- 예: 첫 쌍의 대조 106, 처치 101. 그룹별 평균을 내고 차이를 구하면 **−8.2**.
- 같은 방식으로 각 쌍에서 동전을 던져 처치/대조 라벨을 무작위 재배정(쌍 안에는 여전히 처치 1명, 대조 1명)하고 1,000번 반복.
- 순열 분포는 0 근처에 중심이 있고(효과가 없을 때 기대되는 모습), ±4~5 정도는 드물지 않다. 그러나 관찰값 −8은 매우 이례적 — 1,000번 중 한 번도 −8만큼 작은 값이 나오지 않았다. p-값 ≈ 0.
- 따라서 귀무가설을 기각한다 — 처치 효과의 증거가 있다.

### 짝지은 t-검정(paired t-test)
- 연속 결과의 매칭 쌍 데이터에는 짝지은 t-검정을 쓸 수 있다. 결과: 평균 차이의 점추정 −8.2, 95% 신뢰구간 (−10.7, −5.7), 매우 작은 p-값 — 음의 방향 처치 효과의 강한 증거.

### 그 밖의 결과 모형
- **조건부 로지스틱 회귀(conditional logistic regression)**: 매칭된 이진 결과 데이터에 적합.
- **층화 Cox 모형(stratified Cox model)**: 사건 발생까지의 시간(time-to-event)/생존 데이터. 일반 Cox 모형과 같지만 기저 위험 함수(baseline hazard function)를 매칭 집합(matched sets)으로 층화한다 — 데이터의 매칭 ID 변수로 층화하도록 소프트웨어에 지정.
- **일반화 추정 방정식(generalized estimating equations, GEE)**: 매칭 ID로 군집화(cluster). 특히 이진 결과에 유용 — 인과 위험차(causal risk difference), 인과 위험비(causal risk ratio), 인과 오즈비(causal odds ratio)를 추정할 수 있고, 어떤 것을 원하느냐에 따라 연결 함수(link function)를 고른다: 위험차는 항등 연결(identity link), 위험비는 로그 연결(log link).

## 예시
McNemar 검정 R 코드 (2×2 쌍 집계표 입력):

```r
ex <- matrix(c(1, 5, 2, 5), nrow = 2, ncol = 2)
mcnemar.test(ex)
# p-value 약 0.45 -> 처치 효과의 증거 없음
```

짝지은 t-검정:

```r
t.test(treated, control, paired = TRUE)
# 평균 차이 -8.2, 95% CI (-10.7, -5.7), 매우 작은 p-값
```

## 요약
- 매칭 후 결과 분석은 반드시 매칭을 고려해야 하며, 가설 검정과 효과 추정(신뢰구간)을 목표로 한다.
- 무작위화(순열) 검정: 귀무가설 하에 쌍 안에서 처치 라벨을 무작위로 뒤집으며 검정통계량 분포를 만들고, 관찰값이 이례적인지 본다.
- 이진 결과에서 처치 효과 정보는 불일치 쌍에만 있으며, McNemar 검정이 순열 검정과 거의 같은 p-값을 준다(예시: p ≈ 0.45, 효과 없음).
- 연속 결과 예시(수축기 혈압)에서는 관찰된 평균 차이 −8.2가 순열 분포에서 극히 이례적이어서 효과의 증거가 있었고, 짝지은 t-검정도 같은 결론(95% CI −10.7 ~ −5.7).
- 대안 모형: 조건부 로지스틱 회귀(이진), 층화 Cox 모형(생존), GEE(매칭 ID로 군집화; 연결 함수 선택으로 인과 위험차·위험비·오즈비 추정).
