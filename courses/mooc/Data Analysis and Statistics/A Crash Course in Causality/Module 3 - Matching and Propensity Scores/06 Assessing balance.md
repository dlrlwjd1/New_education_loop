# Assessing balance

## 개요
- 매칭 후 매칭이 성공했는지 공변량 균형(covariate balance)을 점검하는 방법을 다룬다.
- 표준화 차이(standardized difference, SMD)가 가설검정(p-value)보다 선호되는 이유를 이해한다.
- Table 1과 SMD 플롯으로 매칭 전후 균형을 비교한다.

## 내용

### 균형 점검의 위치
- 무작위 시험에서는 무작위화 덕분에 공변량이 자동으로 균형을 이룬다. 매칭의 목표도 매칭 후 비슷한 균형을 달성하는 것이다.
- 균형 평가는 **결과(outcome)를 보지 않고** 수행한다. 매칭이 잘 안 됐으면 첫 단계로 돌아가 매칭 방법을 다시 고민할 수 있다.
- 흔히 매칭 전(pre-matching) 대 매칭 후(post-matching) 균형을 보여주는 Table 1을 만든다.

### 가설검정의 문제
- 매칭 후 두 군의 평균이 같은지 검정할 수도 있다: 연속형 공변량은 이표본 t-검정(two sample t-test), 이산형 공변량은 카이제곱 검정(chi-square test)으로 p-value를 보고.
- 단점: p-value는 표본 크기에 의존한다. 연구가 크면 실제 평균 차이가 아주 작아도 유의하게 나올 수 있다. 아주 작은 차이는 중요하지 않으므로 p-value는 최선의 방법이 아니고, 보통 표준화 차이를 선호한다.

### 표준화 차이(standardized difference)
- 각 공변량 X에 대해:

  smd = (X̄_treatment − X̄_control) / sqrt( (s²_treatment + s²_control) / 2 )

  - 분자: 처치군과 대조군의 표본 평균 차이.
  - 분모: 두 군의 표본 분산을 평균 낸 뒤 제곱근을 취한 합동 표준편차(pooled standard deviation).
- smd = 표준편차 단위의 평균 차이(standardized mean difference). smd가 1이면 평균이 1 표준편차만큼 다르다는 뜻으로 큰 차이다.
- 척도 불변: 나이를 연 단위에서 일 단위로 바꿔도 smd는 변하지 않는다.
- 공식에 표본 크기 n이 없으므로 p-value처럼 표본 크기에 직접 의존하지 않는다.
- 부호가 있을 수 있어 보통 절댓값으로 보고하며, 매칭에 쓴 모든 변수에 대해 하나씩 계산한다.

### 경험 법칙(rules of thumb)
- |smd| < 0.1: 적절한 균형(adequate balance). 무작위 시험이라면 보통 모든 공변량이 이 수준.
- 0.1 ≤ |smd| ≤ 0.2: 완전한 균형은 아니지만 크게 걱정할 정도는 아님. 매칭을 잘해도 이 구간의 공변량이 두어 개 나올 수 있다.
- |smd| > 0.2: 심각한 불균형(serious imbalance).

### Table 1 예시 (우심도자술 RHC 데이터)
- Table 1은 논문의 첫 표로 자주 나오는, 분석에 쓰인 주요 변수의 요약 통계 표를 가리키는 일반적 명칭이다. 처치군으로 층화해 제시한다.
- 우심도자술(right heart catheterization, RHC) 연구: RHC 군 대 no RHC 군, 각 수천 명.
- 매칭 전: 나이 평균은 두 군 모두 약 61세로 비슷(smd 0.06). 그러나 신경계(neuro) 진단 변수는 대조군 16.2% 대 처치군 5.4%로 smd 0.35 → 0.2 초과, 불균형.
- 매칭 후(쌍 매칭이므로 두 군 인원이 정확히 같음): 모든 smd가 0.1 미만. neuro는 5.3% 대 5.7%로 개선 — 무작위 시험에서 볼 법한 표가 된다.

### SMD 플롯
- 공변량이 수십 개일 때는 smd를 그림으로 그리는 것이 유용하다.
- 예시 그림: 빨간 선은 비매칭(unmatched) 모집단의 변수별 smd, 파란 선은 매칭 후. 기준선을 0.1에 그어 두면, 빨간 선은 여러 변수가 0.1 오른쪽에 있지만 파란 선은 모두 왼쪽에 있어 매칭이 균형을 크게 개선했음을 한눈에 볼 수 있다.

## 요약
- 매칭 후에는 결과를 보지 않은 채 공변량 균형을 점검하고, 불충분하면 매칭을 다시 한다.
- p-value는 표본 크기에 의존하므로 표준화 차이(smd)가 선호된다.
- smd는 합동 표준편차로 나눈 평균 차이로, 척도와 표본 크기에 민감하지 않다.
- 경험 법칙: |smd| < 0.1 적절, 0.1~0.2 허용 범위, > 0.2 심각한 불균형.
- Table 1(매칭 전후)과 smd 플롯으로 매칭의 성공 여부를 시각적으로 평가한다.
