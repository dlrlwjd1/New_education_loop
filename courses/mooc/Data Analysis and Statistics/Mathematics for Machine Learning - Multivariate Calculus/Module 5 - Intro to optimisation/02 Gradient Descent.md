## 내용

### 예제 함수
```
f(x, y) = x²y
```
- x가 크고 y가 양수면 **크고 양수**, y가 음수면 **음수**가 된다.
- y축을 따라 보면 **직선의 투영**, x축을 따라 보면 **y가 양수일 때 위로 열린 포물선, 음수일 때 아래로 열린 포물선**.
- **두 축을 따라 함수는 0**이다.
- MATLAB의 `surfc` 로 **등고선(contour)** 을 함께 그린다 — 지형도의 등고선과 같다.

### Grad 벡터 ⭐
편미분:
```
∂f/∂x = 2xy       (y를 상수로)
∂f/∂y = x²        (x²를 상수로, y는 1로 미분)
```
이 둘을 **벡터의 x·y 자리에 적어 넣은 것**이 **Grad f (∇f)** 다.
```
∇f = ( ∂f/∂x , ∂f/∂y )
```

> 강사의 표현: **"Grad는 역사상 가장 굉장한 벡터다. Grad는 선형대수와 미적분을 하나로 합치는 작은 벡터다."**

### 방향 도함수(directional gradient) ⭐
작은 벡터 `r = (dx, 0)` 을 `∇f` 와 내적하면:
```
∇f · r = (∂f/∂x)·dx + 0
```
> **x축을 따라 dx만큼 움직인 만큼의 변화**를 준다. 제대로 된 일을 하고 있다.

일반적으로 **단위 벡터 `r̂ = (c, d)` (단, c² + d² = 1)** 방향으로 움직일 때:
```
df = ∇f · r̂ = (∂f/∂x)·c + (∂f/∂y)·d
```
> 이것을 **방향 도함수**라 부른다. ⚠️ **∇f는 공간의 특정 위치에서 평가된다는 점**을 기억한다.

### 최대 방향 도함수는 얼마인가 ⭐
`∇f · r̂ = |∇f||r̂|cos θ` 이고 `|r̂| = 1` 이므로 **cos θ 항만 남는다.**

> **cos θ = 1, 즉 θ = 0일 때 최대**가 된다. 즉 **r̂이 ∇f와 평행할 때.**

```
∇f · (∇f/|∇f|) = |∇f|²/|∇f| = |∇f|
```
> ⭐ **방향 도함수가 가질 수 있는 최댓값은 `|∇f|` — 즉 가능한 가장 가파른 기울기의 크기는 Grad의 크기이며, 그것은 Grad 성분들의 제곱합(의 제곱근)이다.**

### Grad는 어느 쪽을 가리키는가 ⭐
> **Grad는 가장 가파른 방향을 가리키며, 등고선에 수직이다.**

- **안개 낀 산에서 국소적으로만 보이고 내려가고 싶다면, 등고선을 따라 걷지 않고 언덕 아래로 내려간다.** 그 방향은 **등고선에 90도**다.
- 위인지 아래인지 판단: **올라갈 때 ∂f/∂x 가 양수**다. 따라서
  - **∇f 는 가장 가파르게 올라가는 방향**
  - **−∇f 는 가장 가파르게 내려가는 방향**

### 경사하강법 ⭐
> 데이터 값과 모델 적합의 차이를 최소화하고 싶은 데이터 사이언스 문제라면, **함수의 가장 낮은 점을 찾고 싶다.** 그 함수는 말하자면 **"나쁨(badness)"** 이고, 우리는 **나쁨이 최소인 지점**을 찾는 것이다.

**뉴턴-랩슨과의 차이** ⚠️
> 뉴턴-랩슨에서는 **0이 되는 지점**을 찾았다. 여기서는 **함수의 최솟값이 얼마인지 모른다.** 즉 **얼마나 내려가야 하는지 모른다.** **산 어딘가에 있는데 계곡의 고도를 모르는 상황.**

**갱신 공식**
```
s_{n+1} = s_n − γ · ∇f(s_n)
```
> 현재 위치 `s_n` 에서 **언덕 아래로 작은 걸음**을 딛는다. 그 걸음은 **−(어떤 양) × Grad**, 그리고 **Grad는 이전 위치 s_n에서 평가**한다.

**성질** ⭐
- **지나쳐도(overshoot) 괜찮다.** Grad가 다시 최소로 데려다준다.
- ⭐ **전환점에 가까워질수록 기울기가 완만해지므로 Grad가 작아지고, 따라서 걸음도 자동으로 작아진다.** 아주 좋은 성질이다.

**한계** ⚠️
- **풍경에 국소 최소가 여럿이면 그중 하나에 갇힐 수 있다.** 어느 것을 찾는지는 **시작점에 달려 있다.** **나머지는 찾지 못하고 한 번에 하나만 찾는다.**

> 그럼에도 **언덕 아래로 작은 걸음을 따라가는 이 깔끔한 방법이, 현실에서 사람들이 쓰는 수치 최적화기(numerical optimiser) 대부분이 작동하는 주된 방식**이다.

## 요약
- **Grad `∇f = (∂f/∂x, ∂f/∂y, ...)`** — 편미분을 성분으로 갖는 벡터. **선형대수와 미적분이 합쳐지는 지점.**
- **방향 도함수 `∇f · r̂`** 는 **r̂이 ∇f와 평행할 때 최대**이고, 그 최댓값은 **`|∇f|`** 다.
- **∇f는 등고선에 수직이며 가장 가파른 오르막**을 가리킨다. **−∇f가 가장 가파른 내리막.**
- **경사하강법: `s_{n+1} = s_n − γ∇f(s_n)`.** 지나쳐도 되돌아오고, **최소에 가까워지면 걸음이 자동으로 작아진다.**
- ⚠️ **국소 최소에 갇힐 수 있고, 어디에 갇히는지는 시작점이 정한다.**
- 이것이 **실제 수치 최적화기 대부분의 작동 원리**다.
