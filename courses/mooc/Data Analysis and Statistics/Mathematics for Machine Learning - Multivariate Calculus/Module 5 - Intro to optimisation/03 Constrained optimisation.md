---

## 내용

### 문제 설정
> 경사하강법은 다변수 함수의 최소·최대를 찾는다. 그런데 **어떤 제약 조건 아래에서, 예를 들어 어떤 선 위 어딘가에서 최대를 찾고** 싶다면?

**예제**: `f(x, y) = x²y` 의 최댓값을 찾되, **반지름이 a인 원 위에 있어야 한다**는 제약.
> **그 원 위 어디가 가장 높은 지점인가?**

⚠️ **원형 경로를 돌면서 x²y가 어떻게 변하는지 식으로 쓰는 것은 완전히 악몽**이다. 하지만 **우리가 물은 것은 그게 아니다** — 원 위 **모든 곳의 값**이 아니라 **원 위의 최댓값**을 물었다.

### 라그랑주의 관찰 ⭐
> **등고선이 경로에 딱 접할 때 최대 또는 최소 지점을 찾은 것이다.**
>
> - f가 조금 더 작으면 **경로에 닿지 못한다.**
> - 조금 더 크면 **두 번 가로지를 수 있다.**
> - **딱 접할 때** 그 경로를 돌 때의 f의 최소·최대를 찾은 것이다.

그리고 결정적으로:
> **등고선이 경로에 접할 때, 등고선에 수직인 벡터는 경로에 수직인 벡터와 (부호를 제외하면) 같은 방향이다.**

### 라그랑주 승수 방정식 ⭐
```
최대화할 함수:  f(x, y) = x²y
제약 조건:      g(x, y) = x² + y² = a²

풀 방정식:      ∇f = λ · ∇g          (λ = 라그랑주 승수)
```
> **이 방정식들을 세우고 풀기만 하면 된다.**

### 풀이 ⭐
```
∇f = ( 2xy , x² )
∇g = ( 2x , 2y )

∇f = λ∇g  →
  ① 2xy = λ·2x      → x 소거 →  y = λ
  ② x²  = λ·2y      → λ = y 대입 →  x² = 2y²  →  x = ±√2·y
  ③ x² + y² = a²    ← 제약 조건 자체 (세 번째 방정식)

③에 x² = 2y² 대입:
  2y² + y² = 3y² = a²
  →  y = ± a/√3
```

**네 개의 해**
```
(x, y) = a/√3 · ( √2,  1)
         a/√3 · ( √2, −1)
         a/√3 · (−√2,  1)
         a/√3 · (−√2, −1)
```

**각 해에서 f = x²y 를 계산하면**

| 해 | f 값 | 종류 |
|---|---|---|
| y가 **양수**인 둘 | **+2a³/(3√3)** | **최대** |
| y가 **음수**인 둘 | **−2a³/(3√3)** | **최소** |

> x가 제곱되므로 **x의 부호는 사라지고, y의 부호가 최대·최소를 가른다.**
>
> 3D로 보면 **y가 양수인 둘이 최대, 음수인 둘이 최소**임이 확인된다.

### 왜 유용한가
> 맞추려는 함수의 **일부 변수들이 서로 고정된 관계로 묶여 있는 경우**가 매우 자주 있다 — 마치 원 위에 있어야 하는 것처럼. **그럴 때 쓸 수 있는 아주 편리한 도구**다.

## 요약
- **제약 최적화**: 어떤 경로(선·원 등) 위에서의 최대·최소를 찾는 문제.
- **라그랑주의 관찰**: **등고선이 경로에 접할 때** 극값이며, 그때 **두 법선 벡터가 같은 방향(부호 제외)** 이다.
- **풀 식: `∇f = λ∇g`** + **제약 방정식 `g = const`**. 미지수 수만큼 방정식이 나온다.
- 예제 `f = x²y`, `g = x² + y² = a²` → 해 넷, **y > 0 인 둘이 최대, y < 0 인 둘이 최소.**
- 변수들이 **고정된 관계로 묶여 있을 때** 쓰는 도구다.
