## 내용

### 종속 변수와 독립 변수
- 지금까지의 예는 **한 변수가 다른 변수의 함수**인 경우였다. `y = f(x)`는 되지만 **`x = g(y)`는 말이 안 될 수 있다.**
- 예: **차량의 속도는 분명히 시간의 함수**다(각 시각에 속도는 하나뿐). 그러나 **시간을 속도의 함수라고는 할 수 없다** — 어떤 속도로 달린 시각이 여러 개일 수 있으니까.
- 그래서 속도를 **종속 변수(dependent variable)**, 시간을 **독립 변수(independent variable)** 라 부른다.

### 무엇이 상수인지는 맥락이 정한다 ⭐
자동차 엔진의 힘 F를 질량 m, 가속도 a, 공기저항 계수 d, 속도 v와 엮은 아주 단순화된 식을 생각한다.

| 관점 | 독립 변수 | 종속 변수 | 상수 |
|---|---|---|---|
| **운전자** | **힘 F** (가속 페달로 직접 조절) | **속도·가속도** (가한 힘의 결과) | **질량·항력 계수** (차 설계의 고정 특성) |
| **차를 설계하는 사람** | 힘 F | — | **속도·가속도** (시장 조사로 정해진 목표치) |
| 〃 | | **질량·항력** (차를 다시 설계해 조절 가능) → **변수가 된다** | |

> 이렇게 **헷갈리는 "변수인 설계 상수"를 파라미터(parameter)** 라 부른다. 파라미터를 바꾸는 것은 **하나의 변수라기보다 비슷한 함수들의 가족(family)을 탐험하는 것**으로 생각한다.
>
> ⚠️ **[모듈 6의 데이터 피팅](../Module%206%20-%20Regression/01%20Simple%20linear%20regression.md)에서 최적 적합을 찾기 위해 바꾸는 것이 바로 이 피팅 함수의 파라미터**다. 즉 **파라미터에 대해 미분하게 된다.**

**핵심 정리**
> **원칙적으로 어떤 항이든 다른 어떤 항에 대해서도 미분할 수 있다. 그러니 상수라고 생각했던 것이 갑자기 변하기 시작해도 당황하지 말 것.**

### 예제 — 금속 캔의 질량
캔의 빈 질량 m을 넓이를 조각내어 근사한다.

| 부분 | 넓이 |
|---|---|
| 위·아래 원 두 개 | `2 × πr²` |
| 몸통(펼치면 직사각형) | 가로 = 원의 둘레 `2πr`, 세로 = 높이 `h` → `2πrh` |

여기에 **두께 t**를 곱하면 금속의 부피, 다시 **밀도 ρ**를 곱하면 질량이다.
```
m = 2πr²·t·ρ + 2πr·h·t·ρ
```
(나중이 편하도록 일부러 풀어 쓴 형태다.)

### 무엇이 상수인가? — π 말고는 분명하지 않다
> **π는 확실히 이 우주의 상수**지만, 나머지는 그렇지 않다. **반지름·높이·벽 두께·심지어 재료의 밀도까지 원칙적으로 모두 바꿀 수 있다.**

그래서 **각각에 대한 도함수를 다 구해 본다.**

### 편미분의 규칙 ⭐
> **어떤 변수로 미분할 때는 나머지 전부를 상수처럼 취급한다.**

```
∂m/∂h = 2πr·t·ρ
  ← 첫 항에는 h가 없으므로 상수 → 0으로 미분되어 사라진다
  ← 둘째 항은 h에 상수들이 곱해진 형태 → 그 상수들만 남는다

∂m/∂r = 4πr·t·ρ + 2πh·t·ρ
  ← r² 항은 2r로, r 항은 r이 사라진다

∂m/∂t = 2πr²·ρ + 2πrh·ρ

∂m/∂ρ = 2πr²·t + 2πrh·t
```

- **`∂m/∂h`에는 더 이상 h가 없다.** 다른 것을 고정했을 때 **질량이 높이에 선형으로 변하기 때문**이며, 예상대로다.
- ⚠️ **표기 주의**: 보통의 `d` 대신 **둥근 ∂(curly partial) 기호**를 써야 한다. **둘 이상의 변수를 가진 함수를 미분했음을 뜻한다.**

### 결론
> **편미분은 본질적으로 다차원 문제를 가져와, 각 변수를 따로 볼 때는 그냥 표준적인 1차원 문제인 척하는 것이다.**
>
> 모듈 1의 일변수 미적분보다 조금도 더 복잡하지 않다. **유일한 차이는 각 도함수를 취할 때 무엇을 고정으로 볼지 계속 추적해야 한다는 점**이다.

## 요약
- **종속 변수 vs 독립 변수**는 맥락이 정한다. 속도는 시간의 함수지만 그 역은 아니다.
- **무엇이 상수인지도 관점에 따라 바뀐다.** 운전자에게 질량은 상수지만 설계자에게는 변수다. 이런 것을 **파라미터**라 부른다.
- **원칙적으로 어떤 항이든 다른 항에 대해 미분할 수 있다.**
- **편미분 = 다른 변수를 전부 상수로 두고 미분하는 것.** 표기는 `d`가 아니라 **`∂`**.
- 캔 예제: `m = 2πr²tρ + 2πrhtρ` 를 r, h, t, ρ 각각에 대해 미분해 본다.
