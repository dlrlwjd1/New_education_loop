# 05 Jacobian applied

## 개요
- 강좌: Mathematics for Machine Learning - Multivariate Calculus (Imperial College London)
- 모듈: Module 2 — Multivariate calculus

- 야코비안을 **벡터에서 행렬로** 확장한다. **벡터값 함수(vector-valued function)의 변화율**을 기술하기 위해서다.

---

## 내용

### 복습 — 벡터장에서 함수를 역으로 읽기
```
f(x, y) = e^(−(x² + y²))
```
편미분으로 야코비안 벡터를 구하는 것은 어렵지 않다. 이번엔 **반대로 벡터장을 먼저 보고 함수 모양을 짐작**해 본다.

| 점 | 야코비안 |
|---|---|
| **(−1, 1)** | **원점을 곧장 가리키는 벡터** |
| **(2, 2)** | **훨씬 작은 벡터**, 역시 **원점을 곧장 가리킨다** |
| **(0, 0)** | **영벡터** — 이 점에서 함수가 평평하다는 뜻 |

> 영벡터가 나왔다는 것은 셋 중 하나다 — **최대(maximum) · 최소(minimum) · 안장점(saddle)**. ([07 The Hessian](07%20The%20Hessian.md)에서 구분법을 배운다.)
>
> 벡터장 전체를 보면 **원점이 이 시스템의 최대임이 분명해진다.**

### 야코비안 행렬 — 입력도 벡터, 출력도 벡터 ⭐
지금까지는 **벡터를 받아 스칼라를 내는** 함수였다. 이제 **벡터를 받아 벡터를 내는** 경우를 본다.

```
u(x, y) = x + 2y
v(x, y) = 3y − 2x
```
- 두 개의 벡터 공간으로 생각할 수 있다 — 하나는 **(u,v) 좌표**, 다른 하나는 **(x,y) 좌표**. **xy의 각 점이 uv에 대응하는 위치**를 갖는다.
- u와 v 각각에 대해 **따로 행벡터 야코비안**을 만들 수도 있다. 하지만 **u와 v를 하나의 벡터의 성분으로 보면**, 그 벡터들을 **행으로 쌓아 행렬**로 만드는 편이 자연스럽다.

```
J = ⎡ ∂u/∂x   ∂u/∂y ⎤
    ⎣ ∂v/∂x   ∂v/∂y ⎦
```

**계산** (강의에서는 `u = x − 2y`로 말한다)
```
∂u/∂x = 1     ∂u/∂y = −2
∂v/∂x = −2    ∂v/∂y = 3

J = ⎡  1  −2 ⎤
    ⎣ −2   3 ⎦
```

⭐ **야코비안 행렬에 변수가 하나도 남지 않았다.** u와 v가 x, y의 **선형 함수**이므로 **기울기가 어디서나 일정**한 것이 당연하다.

> 또한 **이 행렬은 xy 공간에서 uv 공간으로 가는 선형 변환 그 자체**다.
> 예: 벡터 (2,3)을 적용하면 → `(2 − 6, −4 + 9) = (−4, 5)`

### 비선형 함수에서는 — 국소적으로 선형 ⭐
> 실제로 마주치는 함수 상당수는 **매우 비선형**이고 이 예보다 훨씬 복잡하다.
>
> 그러나 **매끄럽기만 하다면, 충분히 확대했을 때 공간의 각 작은 영역을 근사적으로 선형으로 볼 수 있다.** 따라서 **공간의 각 점에서 야코비안 행렬식(determinant)의 기여를 모두 더하면, 변환 후 영역 크기의 변화를 계산할 수 있다.**

### 고전적 예 — 직교좌표 ↔ 극좌표
반지름 r과 x축에서의 각 θ로 표현된 벡터를 x, y로 바꾸고 싶다면 **삼각법만 생각하면 식이 나온다.**

야코비안 행렬을 만들고 **행렬식을 취하면 결과가 그냥 `r`** 이다 (θ의 함수가 아니다).

> 이것이 말해 주는 것: **원점에서 멀어지며 r을 따라 이동하면, 작은 공간 영역이 r의 함수로 스케일된다.**

---

## 요약
- **벡터장을 먼저 보고 함수 모양을 역으로 읽을 수 있다.** 야코비안이 **영벡터**면 최대·최소·**안장점** 중 하나다.
- **야코비안 행렬**: 벡터값 함수의 경우, 각 출력 변수를 각 입력 변수로 편미분해 **행으로 쌓는다.**
- **선형 함수의 야코비안 행렬에는 변수가 남지 않는다** — 기울기가 어디서나 일정하고, **그 행렬 자체가 선형 변환**이다.
- **비선형이어도 매끄러우면 국소적으로 선형**으로 볼 수 있어, **행렬식으로 영역 크기의 변화**를 계산할 수 있다.
- 극좌표 → 직교좌표의 **야코비안 행렬식은 r**이다.
