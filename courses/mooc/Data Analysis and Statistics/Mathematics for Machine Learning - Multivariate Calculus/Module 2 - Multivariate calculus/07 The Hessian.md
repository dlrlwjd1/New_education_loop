# 07 The Hessian

## 개요
- 강좌: Mathematics for Machine Learning - Multivariate Calculus (Imperial College London)
- 모듈: Module 2 — Multivariate calculus
- [MOOC 원본 강의](https://www.mooc.org/learn/multivariate-calculus-machine-learning/lecture/hyqnv/the-hessian)
- **헤시안(Hessian)** — 2계 편미분을 모은 행렬. **기울기가 0인 지점이 최대인지 최소인지 안장점인지 판별**한다.

---

## 내용

### 정의 ⭐
| | 모으는 것 | 형태 |
|---|---|---|
| **야코비안** | **1계 도함수** 전부 | **벡터** |
| **헤시안** | **2계 도함수** 전부 | **행렬** |

- n개 변수의 함수라면 헤시안은 **n × n 정사각 행렬**이다.
- **2계 편미분 구하는 법**: x₁로 미분(다른 변수는 상수) → 그 결과를 다시 x₂로 미분(역시 다른 변수는 상수). 그냥 두 번 반복하면 된다.

> 실전 요령: **먼저 야코비안을 구하고 그 항들을 다시 미분해 헤시안을 만드는 편이 편하다.**

### 예제 — `f(x,y,z) = x²yz`
**야코비안**
```
J = ( 2xyz ,  x²z ,  x²y )
```

**헤시안** — 야코비안의 각 항을 x, y, z로 다시 미분해 행으로 쌓는다
```
      x로      y로      z로
2xyz → 2yz     2xz     2xy
x²z  → 2xz      0      x²
x²y  → 2xy     x²       0

H = ⎡ 2yz  2xz  2xy ⎤
    ⎢ 2xz   0   x²  ⎥
    ⎣ 2xy  x²    0  ⎦
```

⭐ **헤시안은 주대각선(leading diagonal)에 대해 대칭이다.** 그래서 **오른쪽 위 영역만 계산하면 왼쪽 아래는 그대로 옮겨 적을 수 있다.**
> **함수가 연속이면(급격한 계단 변화가 없으면) 항상 참이다.**

### 헤시안으로 극값 판별하기 ⭐
2차원으로 내려와 `f(x,y) = x² + y²` 를 보자.

- 야코비안과 헤시안 모두 구하기 쉽다. **(0,0)에서 야코비안이 0벡터**다.
- 그런데 **이것이 최대인지 최소인지 어떻게 아는가?** 다른 점을 찍어 위인지 아래인지 확인할 수도 있지만 **견고하지 않다.**
- 대신 **헤시안**을 본다. 이 단순한 경우 헤시안은 **더 이상 x, y의 함수도 아니다.** 행렬식은 `2×2 − 0×0 = 4`.

**판별 규칙** ⭐

| 조건 | 결론 |
|---|---|
| **행렬식(determinant) > 0** | **최대 또는 최소**임이 확실하다 |
| 그리고 **좌상단 첫 항 > 0** | **최소(minimum)** |
| 그리고 **좌상단 첫 항 < 0** | **최대(maximum)** |
| **행렬식 < 0** | **최대도 최소도 아니다 → 안장점(saddle point)** |

### 안장점(saddle point)
함수에 마이너스를 넣어 살짝 바꾸고 다시 계산하면 **헤시안 행렬식이 음수**가 되는 세 번째 경우가 나온다.

- 그 점 (0,0)에서 **기울기는 분명히 평평하다.** 그런데 최대도 최소도 아니다.
- 애니메이션으로 보면 — **기울기가 0인 위치인데, 한 방향으로는 경사가 내려오고 다른 방향으로는 올라온다.**
- 이런 특징을 **안장점**이라 부르며, **봉우리를 찾을 때 많은 혼란을 일으킨다.**

> **[모듈 5](../Module%205%20-%20Intro%20to%20optimisation/01%20Welcome%20to%20Module%205.md)에서 헤시안이 최적화를 돕는 또 다른 방식**을 보게 된다.

## 요약
- **헤시안 = 2계 편미분을 모은 n×n 행렬.** 야코비안(1계, 벡터)의 자연스러운 확장이다.
- **먼저 야코비안을 구하고 그 항들을 다시 미분**하면 편하다.
- **함수가 연속이면 헤시안은 대각선에 대해 대칭**이라 절반만 계산하면 된다.
- 판별: **행렬식 > 0 → 극값** (좌상단 항이 **양수면 최소, 음수면 최대**). **행렬식 < 0 → 안장점.**
- **안장점**은 기울기가 0이지만 한 방향은 내려오고 다른 방향은 올라오는 지점이다.
