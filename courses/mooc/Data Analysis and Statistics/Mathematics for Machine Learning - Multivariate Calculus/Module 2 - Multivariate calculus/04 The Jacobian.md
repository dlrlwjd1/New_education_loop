# 04 The Jacobian

## 개요
- 강좌: Mathematics for Machine Learning - Multivariate Calculus (Imperial College London)
- 모듈: Module 2 — Multivariate calculus
- [MOOC 원본 강의](https://www.mooc.org/learn/multivariate-calculus-machine-learning/lecture/BfvWV/the-jacobian)
- **야코비안(Jacobian)** — 편미분들을 선형대수와 결합해 **가장 가파른 오르막 방향을 가리키는 벡터**로 만든다. **이 강좌의 핵심 개념 중 하나.**

---

## 내용

### 정의 ⭐
> 여러 변수의 함수 `f(x₁, x₂, x₃, ...)` 가 있을 때,
> **야코비안은 각 성분이 f를 각 변수로 편미분한 값인 벡터**다.

```
J = [ ∂f/∂x₁ , ∂f/∂x₂ , ∂f/∂x₃ , ... ]
```
- ⚠️ **관례상 열벡터가 아니라 행벡터(row vector)로 쓴다.** 이유는 [모듈 3](../Module%203%20-%20Multivariate%20chain%20rule%20and%20its%20applications/03%20More%20multivariate%20chain%20rule.md)에서 분명해진다.
- 최적화와 머신러닝을 시작하는 맥락에서 자주 나오는 시나리오는 **"여러 변수의 스칼라 함수 하나"의 야코비안**이다.

### 예제 — `f(x,y,z) = x²y + 3z`
```
∂f/∂x = 2xy
∂f/∂y = x²
∂f/∂z = 3          ← 3z는 상수 계수만 남고 z가 사라진다

J = (2xy, x², 3)
```

**이것이 말해 주는 것**
> **특정 (x,y,z) 좌표를 넣으면, 그 함수의 가장 가파른 경사 방향을 가리키는 벡터를 돌려주는 대수적 표현**을 얻은 것이다.

- 이 함수의 야코비안은 **z 방향으로 위치와 무관한 일정한 기여**를 갖는다.
- 예: `J(0,0,0) = (0, 0, 3)` → **길이 3이고 z 방향을 곧장 가리키는 벡터.**

### 2D로 내려가 그림으로 보기 ⭐
- 이 강좌 뒤에서 쓰는 수치 방법 중에는 **수백 차원의 야코비안을 계산해야 하는 것**도 있다. 3D 예제조차 그림으로 표현하기 어렵다. 그래서 **2D로 내려간다.**
- 복잡하지만 보기 좋은 함수 하나를 고른다. 강사의 말 — **"괴물 같지만, 지금까지 배운 도구만으로 이것의 편미분을 정말로 계산할 수 있다. 다만 갈아 넣어 봐야 새로 배울 게 없으니 결과를 그림으로 보여 주겠다."**

**표현 방식 세 가지를 차례로 본다**

| 표현 | 내용 |
|---|---|
| **색상 지도(2D)** | x는 가로, y는 세로, **색이 z 값** — 밝은 영역이 높고 어두운 영역이 낮다 |
| **3D 표면** | z를 **높이**로도 표현. 기울기 직관을 얻기 위해 잠시 3D로 |
| **등고선(contour plot)** | 실제 산의 지도처럼 **같은 높이(같은 z)를 잇는 선**을 그린다. 격자점을 다 그리는 것보다 훨씬 깔끔하다 |

### 야코비안 벡터장 ⭐
등고선 위에 야코비안 벡터를 잔뜩 겹쳐 그리면:

- **모두 오르막을 가리킨다** — 어두운(낮은) 영역에서 **멀어지고** 밝은(높은) 영역을 **향한다.**
- ⭐ **등고선이 촘촘히 모인 곳에서 야코비안 벡터가 가장 크다.**
- **산의 봉우리, 계곡 바닥, 넓고 평평한 평야에서는 기울기가 작고 따라서 야코비안도 작다.**

> 강사의 의도: **이 명확한 2차원 예제가, 나중에 훨씬 높은 차원 문제를 만났을 때 수학을 믿을 자신감을 준다.**

---

## 요약
- **야코비안 = 각 변수에 대한 편미분을 모은 행벡터.** `J = [∂f/∂x₁, ∂f/∂x₂, ...]`
- 좌표를 넣으면 **가장 가파른 오르막 방향을 가리키는 벡터**를 돌려주고, **크기는 국소 가파름에 비례**한다.
- `f = x²y + 3z` → `J = (2xy, x², 3)`. `J(0,0,0) = (0,0,3)`.
- 2D 등고선 + 벡터장으로 보면: **벡터는 항상 오르막을 향하고, 등고선이 촘촘한 곳에서 가장 크며, 봉우리·계곡·평야에서는 작다.**
