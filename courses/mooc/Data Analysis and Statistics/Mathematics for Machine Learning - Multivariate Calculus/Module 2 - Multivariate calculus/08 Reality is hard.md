# 08 Reality is hard

## 개요
- 강좌: Mathematics for Machine Learning - Multivariate Calculus (Imperial College London)
- 모듈: Module 2 — Multivariate calculus
- [MOOC 원본 강의](https://www.mooc.org/learn/multivariate-calculus-machine-learning/lecture/3t2Wj/reality-is-hard)
- 지금까지 피해 온 **현실의 어려움 넷**과, 그에 대한 답인 **유한차분법(finite difference method)**.

---

## 내용

### 지금까지의 도구
- 2차원 함수를 **풍경(landscape)** 으로 생각한다.
- **야코비안 벡터**로 각 점의 **기울기 방향과 크기**를 안다.
- **헤시안**으로 **기울기 0인 점이 어떤 종류인지** 재확인한다.

### 현실의 어려움 넷 ⚠️

**1. 차원이 훨씬 많다**
> 신경망 훈련 같은 최적화 응용에서는 **2차원이 아니라 수백~수천 차원**을 다루게 된다.
>
> **더 이상 멋진 표면을 그려 산을 오를 수 없다.** 수학은 전부 그대로 통하지만, **2D 직관으로 길잡이를 삼아 수학을 믿어야 한다.**

**2. 해석적 함수가 없고, 점 하나 계산이 비싸다**
> 2D 문제라도 **문제를 기술하는 깔끔한 해석적 함수가 없는 경우가 많고**, 각 점 계산이 매우 비쌀 수 있다.
>
> 원리적으로 그림을 그릴 수는 있어도 **슈퍼컴퓨터 시간이나 실험실 인력을 감당할 수 없다.**

**3. 불연속(sharp feature)**
> 지금까지 다룬 함수는 모두 매끄럽고 얌전했다. **불연속 같은 날카로운 특징이 있으면** 모래밭 항해가 훨씬 혼란스러워진다.

**4. 잡음(noise)**
> 여러 요인으로 함수가 **잡음 섞인(noisy)** 것이 될 수 있다. 그러면 **조심하지 않는 한 야코비안 벡터가 꽤 쓸모없어진다.**

### 그러면 함수도 없는데 야코비안을 어떻게 만드는가? ⭐
> 강사도 인정한다 — **"지난 몇 분간 여러분이 화면에 대고 외치고 있었을 질문"**.

답은 **수치 방법(numerical methods)** 이라는 거대한 연구 분야다.

> 명시적 공식이 없거나, 공식이 있어도 **직접 푸는 데 세상이 끝날 때까지 걸리는 문제**가 많다. 그래서 **근사해를 만드는 기법들**이 개발됐다.

### 유한차분법(finite difference method) ⭐
> 이 접근은 **강좌 초반의 도함수 정의로 곧장 돌아간다.**
>
> 우리는 **유한한 구간에서 계산한 rise over run 근사**로 시작했고, 그 구간이 **0에 다가가면 어떻게 되는지** 봤다.
>
> **유한차분법이 하는 일은, 공간의 모든 점에서 함수 값을 구하지 않겠다고 받아들이고, 가진 점들만으로 기울기 근사를 만드는 것**이다.

**고차원에서의 절차**
1. 초기 위치에서 시작한다
2. **각 편미분을 차례로 근사한다**
   - **x 방향으로 작은 걸음** → x에 대한 근사 편미분
   - **y 방향으로 작은 걸음** → y에 대한 근사 편미분

### 주의할 두 가지 ⚠️

**① 걸음(step)은 얼마나 커야 하나 — 균형의 문제**

| 걸음이 | 문제 |
|---|---|
| **너무 크면** | **근사가 나빠진다** (이유는 이 시점에 자명할 것) |
| **너무 작으면** | **수치 문제(numerical issues)** 가 생긴다. 컴퓨터는 함수 값을 **유효숫자 몇 자리까지만 저장**한다. 점이 너무 가까우면 **변화를 아예 감지하지 못할 수 있다** |

**② 데이터가 잡음 섞였다면**
- 여러 접근법이 개발돼 있지만 **가장 단순한 것은 서로 다른 걸음 크기 몇 개로 기울기를 계산해 평균 같은 것을 취하는 것**이다.

---

## 요약
- 현실의 어려움 넷: **고차원(수백~수천) · 해석적 함수 부재와 비싼 계산 · 불연속 · 잡음.**
- 고차원에서는 그림을 그릴 수 없다. **2D 직관을 길잡이로 수학을 믿어야 한다.**
- 함수가 없어도 야코비안을 만드는 방법이 **수치 방법**, 그중 **유한차분법**이다.
- **유한차분법 = 가진 점들로 rise over run 근사.** 각 축 방향으로 **작은 걸음**을 떼어 편미분을 하나씩 근사한다.
- 걸음 크기는 **균형**이 필요하다 — **크면 근사가 나쁘고, 작으면 컴퓨터가 변화를 감지하지 못한다.**
- 잡음에는 **여러 걸음 크기로 계산해 평균**내는 것이 가장 단순한 대응이다.
