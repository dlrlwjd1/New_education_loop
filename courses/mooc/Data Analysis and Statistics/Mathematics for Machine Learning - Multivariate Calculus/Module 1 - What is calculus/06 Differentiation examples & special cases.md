## 내용

### 1. `f(x) = 1/x` — 불연속(discontinuity)
그래프를 보면 **x = 0을 빼고는 어디서나 기울기가 음수**다. 음수 쪽에서 −∞로 떨어지다가 양수 쪽에서 위에서 다시 나타난다. 이 **갑작스러운 끊김이 불연속**이다.

- **0으로 나누기는 정의되지 않으므로** 이 함수는 **x = 0에서 값 자체가 없다.**

**미분 과정**
```
f'(x) = lim [ 1/(x+Δx) − 1/x ] / Δx
      ← 분자의 두 분수를 통분: 분모를 x(x+Δx)로 맞춘다
      = lim [ x/(x(x+Δx)) − (x+Δx)/(x(x+Δx)) ] / Δx
      ← 분자에서 x와 −x가 소거되어 −Δx만 남는다
      = lim [ −Δx / (x(x+Δx)) ] / Δx        ← Δx 소거
      = lim [ −1 / (x² + xΔx) ]
      ← xΔx 항은 Δx→0에서 매우 작아져 무시된다
      = −1 / x²
```
- 결과 **`−1/x²`** — 예상대로 **어디서나 음수**이고, 원래 함수처럼 **x=0에서 정의되지 않는다.**

### 2. `e^x` — 자기 자신이 도함수인 함수 ⭐
> **함수 값 f(x)가 항상 자기 자신의 기울기 f'(x)와 같은 함수.**

**추론 과정**
- 지루한 답이 하나 있다 — **f(x) = 0**. 수평선이라 함수도 기울기도 어디서나 0이다.
- 더 흥미로운 경우를 찾으려면:
  1. 이 신비의 함수는 **항상 양수이거나 항상 음수여야 한다.** 가로축을 가로지르는 순간 **함수와 기울기가 둘 다 0이 되어 막히고**, 결국 지루한 0 함수가 되기 때문이다.
  2. 항상 증가하거나 항상 감소하므로 **같은 값으로 다시 돌아올 수 없다.**
- 이 조건을 만족하는 함수는 여럿 있어 보이지만, **0 함수를 빼면 모든 요구를 만족하는 함수는 단 하나다.**

> **지수 함수 `e^x`.** 여기서 **e는 오일러 수(Euler's number)**, 18세기 수학자의 이름을 땄고 **약 2.718**이다.

- **e는 π처럼 수학 곳곳에 등장하며 우주의 구조에 새겨진 것처럼 보인다**고 강의는 표현한다.
- `e^x`를 미분하면 `e^x`이므로 **몇 번을 미분해도 아무것도 바뀌지 않는다.** 이 **자기 유사성(self similarity)이 나중에 매우 쓸모 있어진다.**

### 3. 삼각함수 sin·cos — 4번이면 제자리 ⭐
- 직각삼각형에서 **sin(x) × 빗변 r = 각 x의 대변 길이.**
- sin x의 기울기를 눈으로 따라가면 — **양의 기울기로 시작해 완만히 줄어 봉우리 꼭대기에서 0이 되고, 다음 골 바닥까지 다시 음수**가 된다.

```
sin x  --미분-->  cos x
cos x  --미분--> −sin x
−sin x --미분--> −cos x
−cos x --미분-->  sin x     ← 네 번 만에 원래로
```

> 이 자기 유사성이 지수 함수를 떠올리게 하는 것은 우연이 아니다 — **삼각함수는 사실 변장한 지수 함수**다. (꽤 그럴듯한 변장이지만, 이 강좌에서는 다루지 않는다.)

### 강의가 강조하는 태도 ⭐
> 이 영상의 세부는 다소 빠르게 넘어갔다. **이 강좌에서 필요한 것은 미분이 근본적으로 꽤 단순한 개념이라는 이해다.** 대수를 끝까지 밀고 갈 수 없을 때조차, **결국 각 점에서의 rise over run 기울기를 찾고 있을 뿐**이다.
>
> 이 **실용적 태도는 컴퓨터로 기울기를 계산할 때 다시 등장한다.** 지금까지의 예제처럼 **기울기의 식을 정말로 구할 수 있는 경우**도 있지만, **매끄러운 함수 대신 이산적인 데이터 점만 있으면 미분할 대상이 없어 보인다.** 그때 **rise over run이 다시 돌아와 해결해 준다.**

---

## 요약
- **`1/x` → `−1/x²`.** 어디서나 음수이고 **x=0에서 불연속**이라 도함수도 그 점에서 정의되지 않는다.
- **`e^x` → `e^x`.** 자기 자신이 도함수인 (0이 아닌) 유일한 함수. **e ≈ 2.718(오일러 수).** 몇 번을 미분해도 그대로다.
- **sin → cos → −sin → −cos → sin.** 네 번 미분하면 제자리. 삼각함수는 **변장한 지수 함수**다.
- 태도: **대수를 다 못 따라가도 괜찮다.** 미분은 결국 **각 점의 rise over run**이며, 이 실용적 관점이 **이산 데이터를 다룰 때 그대로 쓰인다.**
