---

## 내용

### 직선에서 출발 — rise over run
- **일차 함수는 어디서나 기울기가 같다.** 아무 두 점을 잡으면
  ```
  기울기 = (구간에서 함수가 증가한 양) / (구간의 길이)
         = rise / run
  ```
- **rise** = 세로 방향 증가, **run** = 가로축 방향 거리.
- 함수가 아래로 기울면 **run은 같고 rise가 음수**가 되어 기울기가 음수가 된다.

### 곡선으로 — 두 번째 점을 δx 만큼 떨어뜨린다 ⭐
기울기를 알고 싶은 점을 **x**라 하자. 그 점에서 함수 값은 **f(x)** 다.

1. 두 번째 점을 잡는다. 두 점의 **가로 거리를 Δx**(작은 변화를 뜻하는 델타)라 하면, 두 번째 점의 위치는 **x + Δx**.
2. 두 번째 점의 세로 위치는 **f(x + Δx)**.
3. 근사 기울기:
   ```
   기울기 ≈ [ f(x + Δx) − f(x) ] / Δx
   ```
4. **매끄럽고 연속인 함수라면, Δx가 작아질수록 두 점을 잇는 직선이 x에서의 실제 기울기에 점점 더 좋은 근사**가 된다.

**극한 표기로 형식화하면 — 도함수의 정의**
```
f'(x) = lim         [ f(x + Δx) − f(x) ] / Δx
        Δx → 0

표기: f'(x)  또는  df/dx  (어느 쪽이든 취향)
```

> ⚠️ **Δx = 0을 말하는 것이 아니다.** 0으로 나누는 것은 정의되지 않는다. **0에 극도로 가까울 때**를 말한다.
>
> **이 "극단적인 rise over run"이 곧 미분(differentiation)이다.** "함수를 미분하라"는 말은 문자 그대로 **그 함수를 위 식에 대입하라**는 뜻이다.

### 예제 1 — 일차 함수 `f(x) = 3x + 2`
```
f'(x) = lim [ 3(x+Δx) + 2 − (3x + 2) ] / Δx
      = lim [ 3x + 3Δx + 2 − 3x − 2 ] / Δx      ← 3x끼리, +2와 −2가 소거
      = lim [ 3Δx / Δx ]                          ← Δx끼리 소거
      = lim 3
      = 3
```
- **Δx가 남아 있지 않으므로 극한 표기는 아무 효과가 없다.** 답은 그냥 **3**.
- 일반형 **f = ax + b 의 기울기는 a** 라는 익숙한 결과가 식에서 나오는 것을 확인한 셈이다.

**여기서 얻는 것 — 합의 법칙(Sum Rule)** ⭐
> `3x` 부분과 `+2` 부분을 **한꺼번에 미분했지만, 따로 미분해서 더해도 같은 결과**가 나온다. 이 교환 가능성을 **합의 법칙**이라 한다.

### 예제 2 — `f(x) = 5x²`
```
f'(x) = lim [ 5(x+Δx)² − 5x² ] / Δx
      ← (x+Δx)² = x² + 2xΔx + Δx²
      = lim [ 5x² + 10xΔx + 5Δx² − 5x² ] / Δx    ← 5x²끼리 소거
      = lim [ 10xΔx + 5Δx² ] / Δx                 ← 분자·분모의 Δx 소거
      = lim [ 10x + 5Δx ]
      ← 둘째 항만 Δx를 갖는다. Δx → 0 이면 극도로 작아져 무시된다
      = 10x
```

**여기서 얻는 것 — 거듭제곱 법칙(Power Rule)** ⭐
```
f(x) = a·x^b   →   f'(x) = a·b·x^(b−1)
```
> **원래 지수가 앞으로 곱해져 나오고, 새 지수는 원래보다 1 작다.**

### 지금까지의 도구 상자
| 도구 | 내용 |
|---|---|
| **도함수의 정의** | `lim (Δx→0) [f(x+Δx) − f(x)] / Δx` |
| **합의 법칙** | 항별로 따로 미분해서 더해도 된다 |
| **거듭제곱 법칙** | `a·x^b → a·b·x^(b−1)` |

> 긴 복잡한 식을 매번 극한 정의로 미분하면 **몹시 지루해진다.** 그래서 **속도를 높이는 규칙들**을 더 배운다 — 다만 그 전에 **특별한 경우의 함수들**을 먼저 본다.

---

## 요약
- **도함수의 정의: `f'(x) = lim(Δx→0) [f(x+Δx) − f(x)] / Δx`.** Δx=0이 아니라 **0에 극도로 가까울 때**다.
- "미분하라" = **함수를 이 식에 대입하라**.
- `3x + 2` → **3** (일차 함수 `ax+b`의 기울기는 **a**). 여기서 **합의 법칙**을 얻는다.
- `5x²` → **10x**. 여기서 **거듭제곱 법칙 `a·x^b → a·b·x^(b−1)`** 을 얻는다.
- 계산의 요령: **전개 → 소거 → Δx로 약분 → Δx가 남은 항은 극한에서 버린다.**
