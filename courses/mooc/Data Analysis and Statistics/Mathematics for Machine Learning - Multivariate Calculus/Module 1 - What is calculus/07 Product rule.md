# 07 Product rule

## 개요
- 강좌: Mathematics for Machine Learning - Multivariate Calculus (Imperial College London)
- 모듈: Module 1 — What is calculus?
- [MOOC 원본 강의](https://www.mooc.org/learn/multivariate-calculus-machine-learning/lecture/dL6Zt/product-rule)
- **곱의 법칙(product rule)** 을 **직사각형 넓이 그림**으로 유도한다. 대수적 유도 대신 직관을 남기는 것이 목적이다.

---

## 내용

### 왜 규칙이 필요한가
- 미분을 정확한 수식으로 정의하고 나니, **비교적 단순한 함수조차 도함수 계산이 꽤 지루하다**는 것이 분명해졌다.
- 그래서 수학자들은 **가능하면 극한의 rise over run 연산을 거치지 않게 해 주는 편리한 규칙들**을 찾아냈다.
- 지금까지: **합의 법칙, 거듭제곱 법칙.** 이번엔 **두 함수의 곱**을 미분하는 지름길.

> 곱의 법칙은 **순수하게 대수적으로도 유도할 수 있지만, 무슨 일이 벌어지는지에 대한 통찰을 별로 주지 못한다.** 그래서 그림으로 간다.

### 직사각형 그림 ⭐
- 한 변의 길이가 **f(x)**, 다른 변이 **g(x)** 인 직사각형을 상상한다.
- 그러면 **두 함수의 곱이 직사각형의 넓이 A(x)** 다.
- `f(x)g(x)`를 미분한다는 것은 곧 **x를 조금 바꿀 때 직사각형 넓이가 어떻게 변하는가**를 찾는 것이다.

**x를 Δx만큼 늘리면**

> ※ 그림에서는 **두 함수가 모두 x에 따라 증가하는 친절한 경우**를 골랐다. 항상 그렇진 않지만 **그리기 훨씬 쉽고 결론은 결국 같다.**

직사각형이 **네 영역**으로 나뉜다.
1. **원래 넓이 A(x)**
2. 가로로 늘어난 띠 — 위쪽 전체 길이가 이제 `f(x + Δx)`이므로 **새 영역의 폭은 새 폭과 원래 폭의 차이**
3. 세로로 늘어난 띠 — 높이도 같은 논리
4. **모서리의 작은 직사각형**

**늘어난 넓이 ΔA = 새로 생긴 세 직사각형의 넓이 합**

### 작은 직사각형을 버릴 수 있는 이유 ⭐
> Δx → 0 이면 **새 직사각형들이 모두 줄어들지만, 가장 작은 직사각형이 가장 빨리 줄어든다.**
>
> 이것이 **모서리의 작은 직사각형을 무시하고 미분 식에서 아예 빼도 되는 직관**이다.

### 식으로 정리하기
1. 우리가 원하는 것은 **`lim ΔA / Δx`** — 즉 rise over run. 그러니 우변도 **Δx로 나눈다.**
2. **두 분수로 쪼갠다.**
3. 각각의 분자에서 **f(x)와 g(x)를 밖으로 꺼낸다.**
4. 그러면 **첫 부분에 g(x)의 도함수 정의가, 둘째 부분에 f(x)의 도함수 정의가 들어 있는 것이 보인다.**

**결과 — 곱의 법칙**
```
A(x) = f(x)·g(x)

A'(x) = f(x)·g'(x) + g(x)·f'(x)
```

> 두 함수의 곱을 미분하려면 **`f(x)g'(x)` 와 `g(x)f'(x)` 의 합**을 구하면 된다.

### 도구 상자 현황
| 도구 | 식 |
|---|---|
| 합의 법칙 | 항별로 미분해 더한다 |
| 거듭제곱 법칙 | `a·x^b → a·b·x^(b−1)` |
| **곱의 법칙** | **`(fg)' = f·g' + g·f'`** |

---

## 요약
- **곱의 법칙: `(fg)' = f·g' + g·f'`.**
- 유도는 **변이 f(x), g(x)인 직사각형의 넓이 변화**로 본다. x를 Δx 늘리면 새 영역이 셋 생기고, **모서리의 작은 직사각형은 Δx→0에서 가장 빨리 줄어들어 무시할 수 있다.**
- Δx로 나누고 분수를 쪼개 정리하면 **f'과 g'의 정의가 그대로 나타난다.**
- 이 강좌의 방침대로 **대수 유도 대신 그림 한 장으로 규칙의 의미를 남긴다.**
