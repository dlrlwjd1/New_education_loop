## 내용

### 중첩 함수 — 돈 → 피자 → 행복 ⭐
헷갈리지 않도록 각 함수에 의미를 붙인다. 중첩 함수 **h(p(m))**:

| 함수 | 뜻 |
|---|---|
| **h** | **행복(happiness)** — 그날 먹은 피자 수 p의 함수 |
| **p** | **하루에 먹는 피자 수** — 버는 돈 m의 함수 |
| 최종 관심 | **돈 → 행복**, 단 **피자라는 개념을 거쳐서** |

> 이렇게 **개념의 사슬을 엮는 중첩 함수 상황은 과학과 공학에서 매우 자주 나온다.**

**행복-피자 함수**
```
h(p) = −(1/3)p² + p + 1/5
```
- 피자가 없어도 원리적으로 행복할 수는 있다.
- **최고 행복은 피자 약 1.5판.**
- 그보다 더 먹으면 덜 행복해지고, **3판을 넘으면 행복이 급격히 음수**가 된다.

**피자-돈 함수**
```
p(m) = e^m − 1
```
- **돈이 없으면 피자를 못 산다.**
- 돈이 많을수록 **피자 구매력이 지수적으로 증가**한다 — 처음엔 대량 구매 할인, 아주 부유해지면 자기 피자 오븐을, 결국엔 피자 공장을 지을 수 있으니까.

### 질문과 두 가지 풀이
> **지금 가진 돈을 고려할 때, 행복해지는 것이 목표라면 돈을 더 버는 데 얼마나 노력해야 하는가?**
>
> 필요한 것은 **돈에 대한 행복의 변화율, 즉 `dh/dm`**.

| 방법 | 내용 | 한계 |
|---|---|---|
| **직접 대입** | 피자-돈 함수를 행복-피자 함수에 넣고 한 번에 미분 | 이 예처럼 간단할 때만 가능. **복잡한 함수에서는 대입 자체가 불가능할 수 있다** |
| **연쇄 법칙** ⭐ | 아래 참조 | 복잡한 경우에도 통한다 |

### 연쇄 법칙 ⭐
```
dh/dm = (dh/dp) · (dp/dm)
```
> 도함수를 **몫(quotient) 형태로 쓰는 이 표기 관습**에서는, **두 양의 곱이 원하는 `dh/dm`을 줄 것처럼 보인다.** 실제로도 무슨 일이 벌어지는지 이해하는 데 아주 합리적인 방식이다.
>
> **도함수 관계의 사슬(chain)을 만든다**는 뜻에서 연쇄 법칙이라 부른다.

⚠️ 강사도 인정하듯 **형식적 유도는 아니지만, 연쇄 법칙을 효과적으로 쓰기에는 이미 충분하다.**

### 적용
```
dh/dp = 1 − (2/3)p
dp/dm = e^m

dh/dm = [1 − (2/3)p] · e^m
      ← 최종 식에 피자 p가 남지 않게 p = e^m − 1 을 대입
      = (1/3)·e^m·(5 − 2e^m)
```
- 영상 시작에서 보여 준 식이 그대로 복원된다.

### 왜 연쇄 법칙이 강력한가 ⭐
> 이 간단한 예에서는 **미분 전에 대입하는 것에 비해 시간을 크게 아끼지 못한다. 하지만 속으면 안 된다.**
>
> **연쇄 법칙의 마법은, 실제 응용에서 함수의 깔끔한 해석적 표현이 없을 수도 있지만 도함수는 여전히 가질 수 있다는 데 있다.** 그것들을 연쇄 법칙으로 **그냥 결합할 수 있다는 점이 매우 강력하다.**

### 결과 해석
돈-행복 함수와 그 도함수를 그래프로 보면 — **빈털터리라면 돈을 좀 버는 것이 정말 가치 있다. 하지만 (특히 피자가 충분해진 뒤로는) 더 버는 것의 이득이 급격히 줄고 곧 음수가 된다.**

## 요약
- **연쇄 법칙: `dh/dm = (dh/dp)·(dp/dm)`.** 중첩 함수 `h(p(m))`을 **도함수의 사슬**로 분해한다.
- 예제: **돈 → 피자 → 행복.** `h(p) = −(1/3)p² + p + 1/5`, `p(m) = e^m − 1`.
- 마지막에 **중간 변수(p)가 남지 않도록 대입**해 정리한다.
- **핵심 위력**: 함수의 해석적 표현이 없어도 **도함수만 있으면 결합할 수 있다.** → [Module 3의 신경망 역전파](../Module%203%20-%20Multivariate%20chain%20rule%20and%20its%20applications/04%20Simple%20neural%20networks.md)가 정확히 이것이다.
