# 09 Taming a beast

## 개요
- 강좌: Mathematics for Machine Learning - Multivariate Calculus (Imperial College London)
- 모듈: Module 1 — What is calculus?
- [MOOC 원본 강의](https://www.mooc.org/learn/multivariate-calculus-machine-learning/lecture/W9vED/taming-a-beast)
- 지금까지 배운 **네 규칙을 모두** 써야 하는 험한 함수 하나를 끝까지 미분한다.

---

## 내용

### 대상 함수
```
f(x) = sin(2x⁵ + 3x) / e^(7x)
```
> 이 함수는 **아무것도 설명하지 않는다.** 익숙한 대상이 없으니 **눈 감고 수학만 믿고 가는** 연습이다.

### 전략 — 관리 가능한 조각으로 쪼갠다 ⭐
> **합·곱·연쇄 법칙의 본질은 전부 함수를 다룰 수 있는 조각으로 분해하는 것이다.**

**1단계 — 분수를 곱으로 바꾼다**
```
f(x) = sin(2x⁵ + 3x) · e^(−7x)
```
> 분수를 직접 다루는 **몫의 법칙(quotient rule)** 도 있지만, **식을 하나 더 외워야 하므로 이 강좌에서는 다루지 않는다.** 항상 이렇게 **분수를 곱으로 다시 써서** 처리하면 된다.

**2단계 — 곱의 두 부분으로 나눈다**
```
g(x) = sin(2x⁵ + 3x)
h(x) = e^(−7x)
```

### g(x) 미분 — 연쇄 법칙
삼각함수 sin이 다항식에 적용된 **연쇄 법칙의 전형적 표적**이다.
```
g(u) = sin(u),     u(x) = 2x⁵ + 3x

g'(u) = cos(u)                    ← sin은 cos으로 미분된다
u'(x) = 10x⁴ + 3                  ← 거듭제곱 법칙 + 합의 법칙

dg/dx = (dg/du)·(du/dx)
      = cos(u) · (10x⁴ + 3)
      ← u를 되돌려 대입
      = cos(2x⁵ + 3x) · (10x⁴ + 3)
```
> 여기까지 **연쇄 법칙 · 합의 법칙 · 거듭제곱 법칙** 셋을 이미 썼다.

### h(x) 미분 — 연쇄 법칙
```
h(v) = e^v,        v(x) = −7x

h'(v) = e^v                       ← e^x는 자기 자신
v'(x) = −7

dh/dx = (dh/dv)·(dv/dx)
      = e^v · (−7)
      = −7·e^(−7x)                ← v가 이미 사라져 이것이 최종형
```

### 합치기 — 곱의 법칙
```
f'(x) = g(x)·h'(x) + h(x)·g'(x)
      = sin(2x⁵ + 3x)·(−7e^(−7x)) + e^(−7x)·cos(2x⁵ + 3x)·(10x⁴ + 3)
```

### 강의가 남기는 조언 ⭐
> 이걸 여러 방식으로 정리하고 인수분해하거나 원래 함수로 표현할 수도 있다. 하지만 코더들 사이의 말을 빌리면 —
>
> **"성급한 최적화는 만악의 근원(premature optimisation is the root of all evil)"**
>
> 이 경우엔 **어질러 놓기가 끝났다고 확신하기 전까지는 정리하고 재배열하는 데 시간을 쓰지 말라**는 뜻이다.

> 미적분에서는 **처음에 무섭게 생긴 함수가 올바른 도구만 있으면 길들이기 쉬운 경우가 많다.** 반대로 **단순해 보이는 함수가 짐승으로 밝혀지기도 한다.**

---

## 요약
- `sin(2x⁵+3x) / e^(7x)` 를 **네 규칙을 모두 써서** 미분한다.
- 순서: **① 분수 → 곱으로 (`e^(−7x)`) ② 두 부분으로 분해 ③ 각각 연쇄 법칙으로 미분 ④ 곱의 법칙으로 결합.**
- **몫의 법칙은 배우지 않는다** — 분수를 음의 지수 곱으로 바꾸면 되기 때문이다.
- 결과: `f'(x) = −7e^(−7x)·sin(2x⁵+3x) + e^(−7x)·cos(2x⁵+3x)·(10x⁴+3)`
- **정리는 다 끝낸 뒤에 한다** — 성급한 최적화 금지.
