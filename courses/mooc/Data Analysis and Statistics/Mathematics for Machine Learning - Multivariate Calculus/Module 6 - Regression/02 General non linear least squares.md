# 02 General non linear least squares

## 개요
- 강좌: Mathematics for Machine Learning - Multivariate Calculus (Imperial College London)
- 모듈: Module 6 — Regression
- 강사: David Dye
- [MOOC 원본 강의](https://www.mooc.org/learn/multivariate-calculus-machine-learning/lecture/sMQdK/general-non-linear-least-squares)
- 직선을 넘어 **임의로 복잡한 비선형 함수를 데이터에 맞추는** 일반 방법 — **비선형 최소제곱(non-linear least squares)**.

---

## 내용

### 설정
```
함수:      y = y(x ; a_k),   k = 1 … m        (파라미터 m개)
예:        y = (x − a₁)² + a₂
데이터:    (xᵢ, yᵢ),  i = 1 … n,  각각 불확실성 σᵢ
```
> ⚠️ **이 함수는 a₁에 대해 선형이 아니다.** a₁을 두 배로 해도 함수가 두 배가 되지 않는다. 그래서 **비선형 최소제곱**이다.

- **σᵢ**: 데이터 점 yᵢ에 대해 **더 불확실할수록 σ가 크다.**

### 가중된 카이제곱 ⭐
```
χ² = Σᵢ [ ( yᵢ − y(xᵢ ; a_k) ) / σᵢ ]²
```
> **각 차이를 불확실성 σ²로 벌준다.** 그래서 **불확실한 데이터 점은 χ² 합에서 낮은 가중치를 갖고 적합에 너무 큰 영향을 주지 못한다.**
>
> **σ를 모르면 전부 1로 두면 되고, 그러면 이 항은 사라진다.** 하지만 불확실성을 아는 경우 **그것을 반영하는 방법**을 제공한다.

### 왜 반복법이 필요한가 ⚠️
> 최소 χ²는 당연히 **`∇χ² = 0`** 일 때다.
>
> 일반적인 경우 **∇의 식을 쓸 수는 있어도 대수적으로 풀지 못할 수 있다.**
>
> 그래서 **최급강하(steepest descent)로 등고선을 따라 내려가며 피팅 파라미터 벡터 a를 갱신**해 `∇χ² = 0` 을 푼다.

```
a_next = a_current − γ · ∇χ²
```
> γ는 **최급강하로 얼마나 공격적으로 내려갈지 조절하는 손잡이**다.

**멈추는 조건 셋**
1. **`∇χ² = 0`** — 최소를 찾았다
2. **χ²가 더 이상 변하지 않는다** — 같은 뜻이어야 한다
3. ⭐ **반복이 너무 많아 지겨워서 포기하고 뭔가 잘못됐다고 판단한다** (강사의 표현 그대로)

### ∇χ² 를 실제로 구하기 ⭐
각 k에 대해 `∂χ²/∂a_k` 를 구한다.
```
합(Σ)은 i에 대한 것이라 k와 무관하고, σ²도 k와 무관하다.

∂χ²/∂a_k = Σᵢ  2·( yᵢ − y(xᵢ; a_k) ) / σᵢ² · ( −∂y/∂a_k )
         = −2 Σᵢ  ( yᵢ − y(xᵢ; a_k) ) / σᵢ² · ∂y/∂a_k
```
> **−2는 밖으로 뺄 수 있고, 갱신식의 상수 γ에 흡수시키면 부호가 +로 바뀐다.**

**최종 최급강하 공식**
```
a_next = a_current + γ · Σᵢ  ( yᵢ − y(xᵢ; a) ) / σᵢ² · (∂y/∂a_k)|_{a_current}
```
> ⚠️ **∂y/∂a_k 는 a_next를 아직 모르므로 a_current에서 평가**한다.

### 겁먹을 필요 없다 ⭐
> 강사: **"이런 공식은 정말 겁나 보이지만, 실제로 써 보면 전혀 그렇지 않다."**

예제 `y = (x − a₁)² + a₂` 에서:
```
∂y/∂a₁ = −2(x − a₁)      ← 2를 내리고, 괄호 안 미분에서 마이너스
∂y/∂a₂ = 1               ← 그냥 1
```
> **막상 쓸 때는 정말 쉽다. 식이 겁나 보일 뿐이다.**

---

## 요약
- **비선형 최소제곱** = 파라미터에 대해 선형이 아닌 모델을 데이터에 맞추기.
- **가중 χ² = Σ [(yᵢ − y(xᵢ;a))/σᵢ]²** — **불확실한 점의 가중치를 낮춘다.** σ를 모르면 전부 1.
- **∇χ² = 0 을 대수로 못 풀 수 있으므로 최급강하로 반복**한다: **`a_next = a_current + γ Σ (yᵢ − y)/σᵢ² · ∂y/∂a_k`**.
- 필요한 것은 **모델을 각 피팅 파라미터로 미분할 수 있는 능력**뿐이다.
- 멈춤 조건: **∇χ²=0 / χ² 정체 / 반복 과다.**
