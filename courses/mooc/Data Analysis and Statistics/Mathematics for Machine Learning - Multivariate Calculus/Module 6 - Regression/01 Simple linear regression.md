# 01 Simple linear regression

- 드디어 **다변량 미적분을 데이터 피팅에 적용**한다. **잔차·카이제곱(χ²)·최소제곱**의 정의.

---

## 내용

### 먼저 데이터를 정리한다
> 큰 데이터 뭉치가 있으면 **가장 먼저 할 일은 정리(clean up)** 다. 수학을 시작할 수 있는 형태로 만드는 것이다.

| 할 일 |
|---|
| **부분적으로 빈 항목, 0 같은 것**을 어떻게 처리할지 정한다 |
| **비닝(binning)이나 그룹화**로 차원 축소가 가능한지 본다 |
| **중복·쓰레기 데이터** 제거 |
| **모든 데이터에 태그를 붙여** 순서를 바꿨다가 되돌릴 수 있게 한 뒤, **정렬해 이상한 값을 찾아** 없애거나 합리적인 값으로 대체한다 |
| 정리 후 **그래프를 그리고, 평균·표준편차** 등을 본다 |

> ⭐ 강사의 조언: **데이터에 관심을 가져야 한다. 알아 가고 싶은 사람처럼 여겨 오랜 친구가 될 때까지 파악하라.** 시간이 지나 데이터가 늘고 변하기 시작할 때 **그 변화를 실제로 알아챌 수 있는 지점까지** 가야 한다.

### 직선 피팅 설정
데이터가 직선처럼 보인다면, **물리적으로 아는 것**이나 **변수 관계에 대한 가설**이 있으면 그 모델을 맞춰 본다. 아니면 **그냥 직선처럼 보이니 합리적인 것을 맞춰** 본다.

```
y = y(xᵢ ; a)      a = 피팅 파라미터 벡터
직선이면  y = mx + c,  a = (m, c)
```
- 예시 데이터의 최적 직선: **기울기 215 GPa, 절편 0.3 GPa.**
- **x̄, ȳ (x·y의 평균)** 은 그 데이터셋의 **기하학적 무게중심(center of mass)** 이다.

### 잔차와 카이제곱 ⭐
**잔차(residual) r** — 데이터와 직선 위 예측 위치의 차이
```
rᵢ = yᵢ − m·xᵢ − c
```

**적합의 전체 품질 χ² (카이제곱)** — 잔차의 제곱합
```
χ² = Σ rᵢ²
```

**왜 제곱하는가** ⭐
- **선 위의 데이터와 아래의 데이터를 모두 벌주기 위해서다.** 플러스와 마이너스가 서로 상쇄되기를 원하지 않는다.
- **선에서 아주 멀리 떨어진 데이터를 강하게 벌주고 싶어서**이기도 하다.
- 그리고 **가장 낮은 χ²를 찾는다** — **최소화 문제**다.

### χ² 등고선의 모양 ⚠️
여러 m, c 값에 대해 χ²를 그려 보면:
- **m ≈ 215, c ≈ 0** 근처에서 최소이고, 멀어질수록 나빠진다.
- ⭐ **등고선이 기울어져 있다** — **트레이드오프**가 있다. **c가 클수록 최적 기울기 m은 작아지고 그 반대도 마찬가지**다. **무게중심을 축으로 회전(pivot)하기 때문**이다.
- ⚠️ **χ² 골짜기가 아주 얕다.** 그래서 **경사하강 계열 알고리즘에는 꽤 까다로운 문제**가 된다 — **골짜기 옆면을 내려가기는 쉽지만 바닥에서 진짜 최소를 찾기가 어렵다.**
- 그래도 **눈에 띄는 최소가 하나뿐**이라 **풀 만한 문제**다.

> ⚠️ 계산 비용: **MATLAB에서 이 등고선 그림 하나를 만드는 데 약 20만 번의 계산**이 들었다. **단순한 문제조차 더 효율적인 알고리즘이 필요한 이유**다.

### 해석적으로 푸는 법 ⭐
> **최소는 χ²의 Grad가 0일 때 찾아진다.** 즉 **χ²를 피팅 파라미터로 미분해 0으로 놓으면 해가 나온다.**

**m으로 미분할 때의 요령**
> 데이터 항목 i에 대한 합(Σ)이 먼저 걱정되지만, **사실 걱정할 필요가 없다.** **xᵢ나 yᵢ 자체를 미분하는 것이 아니므로 합 안에 얌전히 앉아 있다.**
> `mx₁ + mx₂ + mx₃` 를 m으로 미분하면 그냥 `x₁ + x₂ + x₃` 인 것과 같다.

```
∂χ²/∂m :  제곱을 미분 → 지수 1 감소, 2를 곱함
          괄호 안을 m으로 미분 → −xᵢ
          →  −2 Σ xᵢ(yᵢ − mxᵢ − c)          (−2는 합 밖으로)

∂χ²/∂c :  괄호 안을 c로 미분하면 그냥 −1 이라 더 쉽다
          →  −2 Σ (yᵢ − mxᵢ − c)
```

**c에 대한 식을 정리하면** — c에 데이터 개수를 곱한 항을 합 밖으로 빼고, 데이터 개수로 나누면:
```
c = ȳ − m·x̄
```
> m에 대한 답도 같은 방식으로 계속하면 나온다. (강사는 **"낡은 수학을 한 줄씩 다 보여 줄 이유가 없다"** 며 결과만 제시한다.)

### 불확실성 ⭐
> **c와 m의 불확실성 추정치 σ_c, σ_m 도 구할 수 있다.**
>
> ⚠️ **피팅을 할 때 그 피팅 파라미터의 불확실성을 파악하고 함께 인용하는 것이 매우 중요하다.**

- 예시 데이터: **꽤 잡음이 있는데도 기울기 215에 불확실성은 9 — 약 5%.** **정말 놀랍다.**

### 반드시 눈으로 확인하라 — 앤스컴의 사중주 ⚠️⭐
> **항상 피팅 결과를 그려서 눈으로 비교해 보라. 온전성 검사(sanity check)다.**

**Anscombe's quartet** (Wikipedia에서 볼 수 있다)
> **네 데이터셋이 χ²·평균·최적 직선·불확실성이 전부 같은데도 데이터는 완전히 다르다.**
- **두 경우는 애초에 직선을 맞추는 것 자체가 잘못된 일**이다.
- **왼쪽 아래는 이상치(flyer) 하나를 빼면 기울기와 절편이 달라진다.**
- **왼쪽 위만이 피팅이 제대로 일을 하고 있는 경우**다.

### 문제를 다시 세우기 — 무게중심 기준 ⭐
> 절편 c를 보면 **c가 기울기 m에 의존한다.** (χ² 등고선이 기울어져 있던 이유다.)
>
> **무게중심 x̄로부터의 편차로 문제를 다시 쓰면** 상수항 **b**를 얻는다. 이때 **c는 y의 무게중심 ȳ의 위치**가 되고,
> ⭐ **상수항 b는 더 이상 기울기에 의존하지 않으며, 따라서 그 불확실성에도 m의 불확실성 항이 들어가지 않는다.**
>
> 이렇게 하면 **χ² 등고선이 기울어지지 않고 원형에 가까운 모양**이 된다. **m과 상수항 사이의 상호작용이 제거되어 수학적으로 훨씬 잘 세워진(well-posed) 문제**가 된다.

---

## 요약
- 피팅 전에 **데이터 정리**가 먼저다. 결측·이상치·중복을 처리하고 그려 본다.
- **잔차 `rᵢ = yᵢ − mxᵢ − c`**, **`χ² = Σ rᵢ²`**. **제곱하는 이유는 부호 상쇄를 막고 먼 점을 강하게 벌주기 위해서**다.
- **최소는 `∇χ² = 0`** 에서 나온다. 정리하면 **`c = ȳ − m·x̄`**.
- ⚠️ **χ² 등고선이 기울어져 있어(m과 c의 트레이드오프) 골짜기가 얕다** — 경사하강에 까다롭다.
- **피팅 파라미터의 불확실성 σ_m, σ_c 를 반드시 함께 인용**한다. 예시에서 215 ± 9 (≈5%).
- ⭐ **앤스컴의 사중주** — 통계량이 같아도 데이터는 전혀 다를 수 있다. **반드시 그려서 눈으로 확인한다.**
- **무게중심 기준으로 다시 쓰면** 상수항이 기울기와 독립이 되어 **χ² 등고선이 원형이 되고 문제가 잘 세워진다.**
