# 07 Linearisation

## 개요
- 강좌: Mathematics for Machine Learning - Multivariate Calculus (Imperial College London)
- 모듈: Module 4 — Taylor series and linearisation
- [MOOC 원본 강의](https://www.mooc.org/learn/multivariate-calculus-machine-learning/lecture/QlsGq/linearisation)
- 테일러 급수를 다시 써서 **근사의 오차 크기를 예상**한다. 그리고 **모듈 1의 rise over run으로 되돌아온다.**

---

## 내용

### 표기 바꾸기 — x − p 를 Δx 로 ⭐
1차 근사가 말하는 것:
> **높이 f(p)에서 시작해, p에서 멀어지면 그에 따른 높이 변화는 "p로부터의 거리 × p에서의 기울기"다.**
>
> 즉 **`기울기 = rise/run`** 을 **`rise = 기울기 × run`** 으로 재배열한 것이다.

- 어차피 **p 근처에서 함수를 평가하려고 근사를 쓰는 것**이므로(p에서는 이미 알고 있다),
- `x − p` 를 **`Δp`** 라 부르고 — **p에서 떨어진 작은 걸음 크기**를 나타낸다 —
- **x = p + Δp** 로 다시 쓴다.
- 마지막으로 **모든 p를 x로 바꿔** 사람들이 보통 기대하는 형태로 만든다. **개념적으로 바뀐 것은 없다.**

```
f(x + Δx) = f(x) + f'(x)·Δx + f''(x)/2!·Δx² + f'''(x)/3!·Δx³ + ...
```

### 1차 근사의 오차는 얼마나 되는가 ⭐
> **1차 근사를 쓸 때 오차는 얼마나 클 것으로 예상해야 하는가?**
>
> 함수는 **이 무한히 긴 급수로 정확히 표현된다는 것을 안다.** 모든 항을 평가할 수는 없지만, **1차 근사를 쓸 때 무시하는 첫 번째 항에는 `Δx²`이 들어 있다.**
>
> **Δx가 작은 수라면 Δx²은 정말 작은 수이고, Δx³은 터무니없이 작은 수**다.

```
f(x + Δx) = f(x) + f'(x)·Δx + O(Δx²)
```
> 이를 **2차 정확도(second order accurate)** 라 한다.

### 선형화(linearisation)란 ⭐
> **함수를 가져와 Δx보다 높은 차수의 항을 무시하는 과정을 선형화라 한다.**
>
> **잠재적으로 아주 험한 함수를 그냥 직선으로 근사한 것**이니 이름이 왜 그런지 분명하다.

### 가장 흥미로운 부분 — rise over run으로의 귀환 ⭐
- 녹색 선은 점 x에서의 **1차 테일러 근사**이며 곧 **그 점의 접선**이다.
- 여기에 **Δx만큼 떨어진 두 번째 점을 써서 rise over run으로 기울기를 근사한 선**을 하나 더 그린다.
- 이 **전진 차분법(forward difference method)** 은 강좌 초반 도함수 정의를 세울 때 쓴 것이고, **Δx → 0 이면 근사가 정확해진다**고 봤다.

> **그런데 Δx가 0으로 가지 않고 두 번째 점이 유한한 거리에 남아 있으면?**
>
> **계산한 기울기에 오차가 생긴다.** 테일러 급수 전체를 재배열해 그 오차 크기를 알아낼 수 있다.

**약간 성가신 대수를 거쳐** `f'(x)` 를 좌변에 고립시키면:
- 급수가 무한하므로 이것은 **여전히 x에서의 기울기에 대한 정확한 표현**이다.
- 우변에 나오는 것은 **rise over run 표현처럼 생긴 것 + 고차 항들의 모음**이다.
- **고차 항 중 첫 번째에 Δx가 들어 있으므로**, 전부 묶어서 말할 수 있다:

> ⭐ **유한한 간격의 두 점 사이에서 rise over run 방법을 쓰면, 기울기 근사에 `Δx에 비례하는 오차`가 들어 있다.**
>
> 더 간단히: **전진 차분법은 1차 정확도(first order accurate)다.**

### 왜 이런 수고를 하는가
> 근사의 오차를 알기 위해 이 모든 수고를 하는 것이 조금 이상해 보일 수 있다. 하지만 **전형적인 경우처럼 컴퓨터에게 해석적이 아니라 수치적으로 풀게 할 때 대단히 중요한 개념**이 된다.

---

## 요약
- 표기를 **`x − p` → `Δx`** 로 바꾸면 테일러 급수가 **`f(x+Δx) = f(x) + f'(x)Δx + ...`** 형태가 된다.
- **1차 근사의 오차는 `O(Δx²)`** — **2차 정확도**다. 무시한 첫 항에 Δx²이 있기 때문이다.
- **선형화 = Δx보다 높은 차수 항을 버리는 것.** 험한 함수를 직선으로 근사한다.
- ⭐ **전진 차분법(rise over run)은 1차 정확도** — 오차가 **Δx에 비례**한다.
- 이 오차 분석은 [모듈 2의 유한차분법](../Module%202%20-%20Multivariate%20calculus/08%20Reality%20is%20hard.md)에서 "걸음 크기를 어떻게 정하나"라는 질문에 대한 이론적 답이다.
