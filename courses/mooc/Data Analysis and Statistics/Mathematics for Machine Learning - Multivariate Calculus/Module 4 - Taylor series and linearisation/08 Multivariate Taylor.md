## 내용

### 표기 정리
> 테일러 급수는 두 형태가 **완전히 동등하다.**
> - **점 p에서 근사를 세우는 것**을 강조하는 형태
> - **그 함수로 Δx만큼 떨어진 다른 점을 평가하는 것**을 강조하는 형태
>
> 이 영상에서는 **Δx 표기를 계속 쓴다.** 더 간결해서 **고차원에서 유용**하기 때문이다.

### 2차원 경우 — 곡선이 아니라 곡면 ⭐
f가 이제 **두 변수 x, y의 함수**다. 절단 테일러 급수는 **가까운 점 `(x+Δx, y+Δy)`** 에서 함수를 근사한다.

**예제 함수**: 2차원 **가우시안(Gaussian)** — 통계의 정규분포에서 익숙한 함수. **얌전하고 (0,0)에 단순한 최대**를 갖는다.

> 1차원 거듭제곱 급수는 **1차원 함수**를 주지만, **2차원에서는 2차원 함수, 즉 곡면(surface)** 을 준다.

| 차수 | 1D에서 | **2D에서** | 봉우리(peak)에서 | 종 옆면에서 |
|---|---|---|---|---|
| **0차** | 수평선 | **평평한 곡면** | 평평한 판 | 평평한 판 |
| **1차** | 직선 | **기울어질 수 있는 평평한 곡면** | **기울기가 0이라 재미없다**(전환점이므로) | **같은 높이·같은 기울기의 곡면** |
| **2차** | 포물선 | **포물면(parabolic surface)** | **종 곡선 안쪽에 포물면이 생겨** 밑에서 봐야 보인다 | ⭐ **안장(saddle) 모양 함수**가 나온다. 그 점에서 **기울기와 곡률이 잘 맞는 것이 눈으로도 분명**하다 |

⚠️ **이 근사는 그 점 주변의 꽤 작은 영역 밖에서는 분명히 쓸모없다.**

### 식으로 쓰기 ⭐
점 (x, y)에서 전개해 `(x+Δx, y+Δy)` 를 평가한다.

**0차** — 전개점과 같은 높이의 평평한 곡면
```
f(x, y)
```

**1차** — 두 방향의 기울기 정보를 포함. 다시 **rise = 기울기 × run**
```
f(x,y) + ∂ₓf·Δx + ∂_yf·Δy
```
> 간결함을 위해 **∂에 아래첨자로 어떤 변수로 미분했는지** 표시한다.

**2차** — ⚠️ **1/2 계수는 1차원과 마찬가지로 그대로 남는다.** 그리고 **항이 셋**이며 전부 2계 도함수다.
```
+ ½ [ ∂ₓₓf·Δx² + 2·∂ₓ_yf·ΔxΔy + ∂_y_yf·Δy² ]
```
| 항 | 미분 방식 |
|---|---|
| 첫째 | **x로 두 번** |
| 가운데 | **x와 y로 각각 한 번씩** |
| 마지막 | **y로 두 번** |

### 야코비안과 헤시안으로 압축하기 ⭐⭐
**1차 항을 다시 보면** — **1계 도함수들과 걸음 크기들의 곱의 합**이다.
> 이것은 **[야코비안](../Module%202%20-%20Multivariate%20calculus/04%20The%20Jacobian.md) 논의를 떠올리게 한다.**
```
1차 항 = J · Δx        (Δx는 Δx, Δy를 담은 벡터)
```

**2차 항을 같은 방식으로 보면** — **2계 도함수들을 행렬로 모을 수 있고, 그것은 이미 정의한 [헤시안](../Module%202%20-%20Multivariate%20calculus/07%20The%20Hessian.md)** 이다.
> 필요한 합을 만들려면 **Δx 벡터에 헤시안을 곱하고, 다시 Δx 벡터의 전치를 곱한다.**

**완성 — 2차 다변량 테일러 급수**
```
f(x + Δx) ≈ f(x) + J·Δx + ½ · Δxᵀ · H · Δx
```

> ⭐ **이 간결한 표현이 우리가 배운 미적분과 선형대수를 대단히 많이 한데 묶고, 강좌 앞부분에서 정의한 야코비안·헤시안 개념을 실제로 쓴다.**
>
> 그리고 **지금까지 2차원을 이야기했지만, J·H·Δx 항에 차원이 몇이든 담을 수 있다.** 즉 **2D에서 다차원 초곡면(hyper surface)으로 곧바로 일반화된다.** 꽤 멋진 일이다.

---

## 요약
- 다변량 테일러 급수는 **근사 곡선이 아니라 근사 곡면(그리고 초곡면)** 을 만든다.
- 2D에서 **0차=평평한 판, 1차=기울어진 판, 2차=포물면**. 종 옆면의 2차 근사는 **안장 모양**이 된다.
- 2차 항에는 **셋**이 있다 — `∂ₓₓ`, `∂ₓ_y`(×2), `∂_y_y`. **1/2 계수는 그대로.**
- ⭐ **압축형: `f(x + Δx) ≈ f(x) + J·Δx + ½·Δxᵀ·H·Δx`**
- **1차 항 = 야코비안, 2차 항 = 헤시안.** 강좌의 미적분과 선형대수가 한 식에서 만난다.
- **차원 수에 무관하게 그대로 일반화**된다.
