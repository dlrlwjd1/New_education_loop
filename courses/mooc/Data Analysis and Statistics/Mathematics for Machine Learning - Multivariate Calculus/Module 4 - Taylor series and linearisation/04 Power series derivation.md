# 04 Power series derivation

## 개요
- 강좌: Mathematics for Machine Learning - Multivariate Calculus (Imperial College London)
- 모듈: Module 4 — Taylor series and linearisation
- [MOOC 원본 강의](https://www.mooc.org/learn/multivariate-calculus-machine-learning/lecture/C6x2C/power-series-derivation)
- **거듭제곱 급수 표현을 처음부터 유도**한다. 결과는 **매클로린 급수(Maclaurin series)** — x=0 주변 전개다.

---

## 내용

### 워밍업 — e^x 를 급수로
```
e^x = 1 + x + x²/2 + x³/6 + ...
```
> 강사: **"우선 여러분의 머리를 날려 버리며 시작하겠다."**

### 테일러 급수가 말하는 것 ⭐
> **어떤 점에서 함수에 대해 "모든 것"을 안다면** — 여기서 모든 것이란 **함수값, 1계 도함수, 2계 도함수, 3계 도함수 등** — **그 정보로 다른 모든 곳에서의 함수를 재구성할 수 있다.**
>
> **한 곳에서 전부 알면, 모든 곳에서 전부 아는 것이다.**

⚠️ **단, 얌전한(well behaved) 함수에 한해서다** — **연속이고 원하는 만큼 몇 번이든 미분할 수 있는** 함수. 다행히 그런 함수를 많이 안다.

### 단계별 유도 (x = 0 주변) ⭐

**0차 근사 g₀**
- 쓰는 정보 **하나**: `f(0)`
- 만들 수 있는 것: **수평선**
```
g₀(x) = f(0)
```
> 이 선은 평평해서 **사실 x의 함수도 아니다.**

**1차 근사 g₁**
- 쓰는 정보 **둘**: `f(0)`, `f'(0)`
- `y = mx + c` 형태의 직선. **세로축 절편 c = f(0)**, **기울기 m = f'(0)**
```
g₁(x) = f(0) + f'(0)·x
```

**2차 근사 g₂**
- 쓰는 정보 **셋**: `f(0)`, `f'(0)`, `f''(0)`
- 세 정보를 쓰려면 **이차식**이 필요하다: `y = ax² + bx + c`
```
y'  = 2ax + b
y'' = 2a

x=0에서 y'' = f''(0)  →  2a = f''(0)  →  a = f''(0)/2
x=0에서 y'  = f'(0)   →  b = f'(0)
x=0에서 y   = f(0)    →  c = f(0)
```
> **근사를 갱신할 때마다 f(x)와 일치하는 영역이 조금씩 넓어진다.**

**3차 근사 g₃**
- `y = ax³ + bx² + cx + d`
- 앞의 세 단계에서 본 대로 **b, c, d는 g₂에서 찾은 것과 같다.** **새로 찾을 것은 계수 a뿐**이다.
```
y'   = 3ax² + 2bx + c
y''  = 6ax + 2b
y''' = 6a

x=0에서 y''' = f'''(0)  →  6a = f'''(0)  →  a = f'''(0)/6
```
> ⭐ **근사가 크게 개선될 뿐 아니라, 더 높은 차수 항을 조각별로 더해도 낮은 차수 항은 그대로 유지된다.**

### 일반항 — 팩토리얼의 등장 ⭐
> 3차 항 앞의 **6**은 3차 항을 **두 번 미분**한 결과다. 마찬가지로 **x⁴을 세 번 미분하면 앞에 `4×3×2`가 붙으므로** 계수는 **`1/(4×3×2)` = `1/24`**.
>
> `4×3×2` 라는 연산에는 이름이 있다 — **4 팩토리얼(4!)**.
>
> 사실 **모든 항이 앞에 팩토리얼을 가진 것으로 볼 수 있다. 심지어 0! 도 (여기서 다루지 않을 이유로) 1이다.**

```
n번째 항 = f⁽ⁿ⁾(0) / n! · xⁿ
```

**완성 — 매클로린 급수**
```
       ∞
f(x) = Σ  [ f⁽ⁿ⁾(0) / n! ] · xⁿ
      n=0
```

### 이름 정리 ⚠️
> 여기서 쓴 것도 분명히 테일러 급수에 해당하지만, **구체적으로 x = 0 점을 보고 있으므로 이 경우를 흔히 매클로린 급수(Maclaurin series)라 부른다.**
>
> **테일러 급수의 완전한 모습은 [다음 강의](05%20Power%20series%20details.md)에서 본다.**

## 요약
- 핵심 주장: **한 점에서 함수값과 모든 계도함수를 알면 함수를 어디서든 재구성할 수 있다.** 단 **연속이고 무한히 미분 가능한(얌전한)** 함수여야 한다.
- 차수별 유도: **0차=수평선(f(0)) → 1차=직선(+f'(0)x) → 2차=이차식(계수 f''(0)/2) → 3차(계수 f'''(0)/6)**.
- **높은 차수를 더해도 낮은 차수 항은 변하지 않는다.**
- 계수의 분모는 **팩토리얼**이다: **n번째 항 = `f⁽ⁿ⁾(0)/n! · xⁿ`**.
- **매클로린 급수 = x=0 주변의 테일러 급수.**
- `e^x = 1 + x + x²/2 + x³/6 + ...`
