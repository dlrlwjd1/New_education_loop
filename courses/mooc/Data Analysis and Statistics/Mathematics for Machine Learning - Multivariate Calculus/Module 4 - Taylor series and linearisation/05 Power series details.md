# 05 Power series details

## 개요
- 강좌: Mathematics for Machine Learning - Multivariate Calculus (Imperial College London)
- 모듈: Module 4 — Taylor series and linearisation
- [MOOC 원본 강의](https://www.mooc.org/learn/multivariate-calculus-machine-learning/lecture/VBOX7/power-series-details)
- **매클로린 급수를 임의의 점 p 주변으로 일반화**한다. 드디어 **테일러 급수의 완전한 모습**.

---

## 내용

### 먼저 다시 놀라기 — e^x 를 항별로 미분하면
```
e^x = 1 + x + x²/2 + x³/6 + x⁴/24 + ...
```
이것을 **항별로 미분**하면 (다항식이라 어렵지 않다):
```
0 + 1 + x + x²/2 + x³/6 + ...  =  원래 급수 그대로
```
> **e^x의 도함수가 e^x라는 예상대로, 이 무한히 긴 급수가 변하지 않는다.** 강사는 이것을 **"꽤 굉장하다"** 고 표현한다.

### 매클로린 → 테일러 ⭐
| | 주장 |
|---|---|
| **매클로린 급수** | **x = 0에서** 함수에 대해 모든 것을 알면 어디서든 재구성할 수 있다 |
| **테일러 급수** | **x = 0이라는 점에 특별할 것이 없다.** **임의의 점에서** 모든 것을 알면 어디서든 재구성할 수 있다 |

> **작은 변화지만 중요한 변화다.**

### 점 p 주변 1차 근사 유도 ⭐
> 0차 항은 간단하다 — **f(p)를 어디서나 쓰는 수평선.**
>
> **1차 근사를 자세히 보면 나머지 고차 항도 다룰 통찰이 나온다.**

우리가 만들려는 것은 **점 p에서 곡선에 접하는 접선**이다. 직선은 `y = mx + c`.

```
점의 좌표는 (p, f(p))
기울기 m = f'(p)

y = f'(p)·x + c

점 (p, f(p))를 대입:
f(p) = f'(p)·p + c
  →  c = f(p) − f'(p)·p

되돌려 넣으면:
y = f'(p)·x + f(p) − f'(p)·p

f'(p)로 묶으면:
y = f'(p)·(x − p) + f(p)
```

> ⭐ **이것이 보여 주는 것**: 근사를 **점 p 주변에 세우면, 기울기 항 f'(p)를 x에 직접 적용하는 것이 아니라 `(x − p)`에 적용한다.** `(x − p)`는 **"p에서 얼마나 떨어져 있는가"** 로 생각하면 된다.

### 완성 — 테일러 급수 ⭐
> 매클로린에서 테일러로 바꾸려면 **① 도함수를 0이 아니라 p에서 평가하고 ② x를 (x − p)로 바꾸면 된다.** ⚠️ **1/2 같은 팩토리얼 계수는 그대로 남는다.**

```
       ∞
f(x) = Σ  [ f⁽ⁿ⁾(p) / n! ] · (x − p)ⁿ
      n=0
```

> **p = 0으로 두면 매클로린 급수와 완전히 같아진다.**

---

## 요약
- `e^x`의 급수를 **항별로 미분하면 자기 자신**이 나온다 — 도함수가 자기 자신이라는 성질과 일치한다.
- **테일러 급수 = 매클로린 급수의 일반화.** x=0이라는 점에 특별할 것이 없다.
- 1차 근사 유도의 핵심: **기울기를 x가 아니라 `(x − p)`, 즉 "p로부터의 거리"에 적용**한다.
- **테일러 급수: `f(x) = Σ [f⁽ⁿ⁾(p)/n!]·(x−p)ⁿ`.** p=0이면 매클로린.
