---

## 내용

### 예제 1 — cos(x) 의 매클로린 급수 ⭐
> **코사인은 얌전한 함수의 전형**이다 — 어디서나 연속이고 무한히 미분 가능하다.

**미분의 순환 패턴** (모듈 1에서 본 것)
```
cos → −sin → −cos → sin → cos ...   (4단계면 제자리)
```

**x = 0에서 평가하면**
- **cos 항은 1 또는 −1**
- **sin 항은 전부 0**

> ⭐ **거듭제곱 급수 관점에서 이것은 한 항 걸러 계수가 0이라는 뜻**이다. 0은 **홀수 번 미분할 때마다** 나오므로 **x, x³, x⁵ 같은 홀수 거듭제곱이 급수에서 전부 사라진다.**
>
> 남는 **짝수 거듭제곱은 전부 우함수(even function)** — **세로축에 대해 대칭**이며, **코사인 자체가 그렇다.**

**간결한 합 기호로**
```
        ∞
cos x = Σ  (−1)ⁿ · x^(2n) / (2n)!
       n=0
```
> ⭐ **이 식에는 cosine이라는 말이 아예 나오지 않는다.** 필요한 모든 것이 **`(−1)ⁿ`** — 음수와 양수를 계속 뒤집는 항 — 에 담겨 있다.

**그래프로 보면**
- `y = 1` 인 수평선에서 시작해 차수를 올리면 점점 정확해진다.
- ⚠️ **x = 0에서 꽤 가까운 영역을 벗어나면 근사가 폭발해 쓸모없어진다.**
- **16차 근사쯤 되면 그래프에 보이는 영역은 거의 완벽하다.** 다만 **축 바로 바깥에서는 함수가 엄청나게 커진다.**

> **급수 근사를 다룰 때는 그것이 통하는 정의역(domain)을 반드시 알아야 한다.**

### 예제 2 — 1/x 의 테일러 급수 ⭐
> **x = 0에서 불연속**이다. **전혀 얌전하지 않다.**

**x = 0에서는 아예 시작할 수 없다**
- **0차 근사조차** 만들려면 **1÷0** 을 해야 하는데 정의되지 않는다.
- 컴퓨터에 시키면 **NaN(Not a Number)** 을 돌려줄 수 있다.

**그래서 다른 점에서 전개한다 — x = 1**
- 이 점에서는 **함수를 평가할 수 있다**는 첫 시험을 통과한다.
- ⚠️ **x = 0에서 벗어났으므로 매클로린이 아니라 테일러 급수를 써야 한다.**

**도함수들을 x = 1에서 평가하면 팩토리얼 수열이 나타난다** — 거듭제곱 급수 공식을 유도할 때와 똑같이.

**테일러 공식에 대입하면 팩토리얼 항이 소거되고** 남는 것은:
```
       ∞
1/x =  Σ  (−1)ⁿ · (x − 1)ⁿ
      n=0
```
> **부호가 번갈아 바뀌는 `(x−1)ⁿ` 의 합**이다.

**그래프에서 보이는 흥미로운 점 셋** ⚠️
1. **근사들이 점근선(asymptote)을 무시하고 곧장 가로질러 간다.**
2. **x < 0 영역은 근사가 전혀 기술하지 못한다.**
3. **x가 커지는 쪽으로는 점점 나아지지만, 각 항의 부호가 양수·음수로 뒤집힐 때마다 꼬리가 격렬하게 요동친다.**

---

## 요약
- **cos(x)**: 얌전한 함수. 홀수 항이 모두 0이 되어 **짝수 거듭제곱만 남고**, `cos x = Σ (−1)ⁿ x^(2n)/(2n)!` 로 깔끔하게 정리된다. **cosine이라는 말 없이 cosine을 표현**한다.
- ⚠️ **전개점에서 멀어지면 근사가 폭발한다.** **정의역을 알고 써야 한다.**
- **1/x**: 얌전하지 않은 함수. **x=0에서는 0차 근사조차 불가능(NaN)** 하므로 **x=1에서 테일러 전개**한다 → `1/x = Σ (−1)ⁿ(x−1)ⁿ`.
- 그 결과 **점근선을 무시하고 지나가고, x<0 영역은 전혀 기술하지 못하며, 꼬리가 요동친다.**
- 교훈: **테일러 급수는 얌전한 함수는 훌륭히 재구성하지만, 얌전하지 않은 함수에는 고전한다.**
