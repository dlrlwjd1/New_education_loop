# 04 Simple neural networks

- 강좌: Mathematics for Machine Learning - Multivariate Calculus (Imperial College London)
- 모듈: Module 3 — Multivariate chain rule and its applications
- [MOOC 원본 강의](https://www.mooc.org/learn/multivariate-calculus-machine-learning/lecture/e1Zao/simple-neural-networks)
- **인공 신경망**을 다변량 연쇄 법칙이 왜 필요한지 볼 수 있을 만큼만 소개한다. **순전파(feed forward) 구조의 선형대수**를 세운다.

---

## 내용

### 신경망은 결국 함수다 ⭐
> 원이 뉴런이고 선이 연결인 예쁜 그림을 자주 보지만, **근본적으로 신경망은 그냥 수학 함수다.** 변수를 받아 다른 변수를 돌려주며, **둘 다 벡터일 수 있다.**

### 가장 단순한 경우 — 스칼라 하나 in, 하나 out
```
a¹ = σ(w·a⁰ + b)
```

| 항 | 이름 | 뜻 |
|---|---|---|
| **a** | **활성(activity)** | 입력·출력 값 |
| **w** | **가중치(weight)** | 그냥 수 |
| **b** | **편향(bias)** | 그냥 수 |
| **σ** | **활성화 함수(activation function)** | **그 자체가 함수** |

### 왜 하필 σ(시그마)인가 ⭐
> **σ가 신경망을 뇌와 연결짓는 부분**이기 때문이다.
>
> 뇌의 뉴런은 화학적·전기적 자극으로 이웃에게서 정보를 받는다. **그 자극의 합이 어떤 임계값을 넘으면 뉴런이 갑자기 활성화되어 이번엔 자기 이웃을 자극한다.**

- 이런 **임계 성질**을 가진 함수의 예가 **쌍곡탄젠트 tanh** 다 — **−1에서 1까지의 범위**를 갖는 얌전한 함수.
- tanh는 **지수 항들의 비**일 뿐이라 **이미 가진 스칼라 도구로 다룰 수 있다.**
- tanh는 **특유의 S자 모양을 가진 함수 가족인 시그모이드(sigmoid)** 에 속한다. **그래서 이 항을 σ로 쓴다.**

### 뉴런을 늘려 가기
**입력을 2개로** — 출력은 여전히 스칼라 `a¹`, 입력은 `a⁰₀`, `a⁰₁`
```
a¹ = σ( w₀a⁰₀ + w₁a⁰₁ + b )
```
> **연결 하나하나에 가중치가 붙는다.**

**입력을 3개, 그리고 n개로** — 지저분해지므로 **합 기호(Σ)** 로 일반화한다. 그런데
> **입력마다 가중치가 있으니, 가중치 벡터와 입력 벡터를 만들어 내적을 취하면 같은 효과**다.

**출력도 2개로** — `a¹₀`, `a¹₁`
- **연결 수가 두 배**가 되고, **각 연결에 자기 가중치**, **각 뉴런에 자기 편향**이 있다.
- 출력마다 식을 하나씩 쓰면 두 식이 되는데, **같은 a⁰를 쓰지만 편향과 가중치 벡터가 다르다.**
- 이를 압축하면 — **두 출력이 열벡터의 각 행**, **두 가중치 벡터는 가중치 행렬(weight matrix)**, **두 편향은 편향 벡터**가 된다.

### 단일 층 신경망의 완성형 ⭐
```
a¹ = σ( W·a⁰ + b )

W = 가중치 행렬 (m × n)
b = 편향 벡터
n = 입력 수, m = 출력 수
```
> 이 식 하나로 **m개 출력·n개 입력의 단일 층 신경망이 나타내는 함수를 완전히 기술**할 수 있다.

### 은닉층(hidden layer)
> 신경망에는 입력과 출력 사이에 **한 개 이상의 뉴런 층**이 있는 경우가 많다. 이를 **은닉층**이라 한다.
>
> **지금까지 본 것과 정확히 같은 방식으로 동작하되, 출력이 다음 층의 입력이 된다는 점만 다르다.**

이것으로 **단순 순전파 신경망의 출력을 계산하는 데 필요한 선형대수가 모두 갖춰졌다.**

### 그런데 남은 문제
> 신경망이 이미지 인식 같은 흥미로운 일을 하게 만들려면 **올바른 가중치와 편향을 전부 가르치는 문제**가 된다. **다음 강의에서 다변량 연쇄 법칙이 등장하는 지점**이다.

---

## 요약
- **신경망은 벡터를 받아 벡터를 돌려주는 수학 함수**일 뿐이다.
- 기본식: **`a¹ = σ(W·a⁰ + b)`**. **a = 활성, W = 가중치 행렬, b = 편향 벡터, σ = 활성화 함수.**
- **σ가 뇌와의 연결점**이다 — 자극 합이 임계값을 넘으면 활성화되는 성질. **tanh** 같은 **시그모이드** 계열을 쓴다.
- 입력·출력을 늘리면 **가중치는 행렬로, 편향은 벡터로** 자연스럽게 확장된다.
- **은닉층**은 같은 구조의 반복이며 **출력이 다음 층의 입력**이 된다.
- 남은 문제는 **가중치와 편향을 어떻게 학습시킬 것인가** → 다음 강의.
