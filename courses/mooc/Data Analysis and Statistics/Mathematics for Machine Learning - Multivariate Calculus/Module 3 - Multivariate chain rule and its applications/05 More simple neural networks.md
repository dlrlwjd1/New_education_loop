# 05 More simple neural networks

## 개요
- 강좌: Mathematics for Machine Learning - Multivariate Calculus (Imperial College London)
- 모듈: Module 3 — Multivariate chain rule and its applications
- [MOOC 원본 강의](https://www.mooc.org/learn/multivariate-calculus-machine-learning/lecture/7IIlS/more-simple-neural-networks)
- **역전파(back propagation)** — 다변량 연쇄 법칙으로 가중치와 편향을 반복 갱신해 신경망을 학습시킨다. **이 강좌에서 미적분과 머신러닝이 만나는 핵심 강의.**

---

## 내용

### 훈련이란 무엇인가
> **신경망을 훈련시킨다**는 것은 보통 **레이블된 데이터**, 즉 **입력과 출력이 짝지어진 쌍**을 쓴다는 뜻이다.

**예 — 얼굴 사진이 행복한지 예측하는 신경망**
- **각 입력**: 이미지의 **픽셀 하나의 밝기**
- **짝지어진 출력**: 이 이미지에 **얼굴이 있는지**, 그리고 **행복한 얼굴인지**

### 역전파라는 이름의 유래 ⭐
> 고전적인 훈련 방법을 **역전파(back propagation)** 라 부르는 이유는 **먼저 출력 뉴런을 보고 그다음 신경망을 거꾸로 거슬러 올라가기 때문**이다.

**예시 구조**: 입력 4개 · 은닉층 3개 · 출력 2개
> 우리가 하려는 것은 **훈련 입력을 그 레이블에 가장 잘 대응시키는 18개의 가중치와 5개의 편향을 찾는 것**이다.

### 비용 함수(cost function) ⭐
1. 처음에는 **모든 가중치와 편향을 무작위 수로** 설정한다. 그래서 처음 데이터를 넣으면 **나오는 값은 무의미하다.**
2. 그다음 **비용 함수**를 정의한다:
```
C = Σ (y − a)²

y = 원하는 출력
a = 훈련되지 않은 신경망이 현재 내놓는 출력
```
> **원하는 출력과 현재 출력의 차이를 제곱해 모두 더한 것.**

### 하나의 가중치와 비용의 관계
- 특정 가중치 W 하나와 비용의 관계만 그려 보면 — **너무 크거나 너무 작으면 비용이 높고, 어느 특정 값에서 비용이 최소**인 곡선이 된다.
- 미적분의 이해를 쓰면: **초기 지점 W₀에서 C의 W에 대한 기울기를 알아낼 수 있다면, 그 반대 방향으로 가면 된다.**
  - 예: 그림의 지점에서 **기울기가 양수**라면 W를 키우면 비용도 커진다. → **W를 줄여야 신경망이 좋아진다.**

### 그러나 현실은 ⚠️
- 비용 함수는 **여러 국소 최소를 가진 구불구불한 곡선**에 더 가까울 수 있어 **항해하기가 더 복잡하다.**
- 게다가 이것은 **가중치 하나만 따로 본 것**이다. 우리가 정말 원하는 것은 **[모듈 2](../Module%202%20-%20Multivariate%20calculus/06%20The%20Sandpit.md)에서 본 2D 예제처럼, 다차원 초곡면(hyper surface)의 최소를 찾는 것**이다.
- 따라서 **내리막으로 가려면 [야코비안](../Module%202%20-%20Multivariate%20calculus/04%20The%20Jacobian.md)을 만들어야 한다** — **비용 함수를 모든 관련 변수로 편미분한 것들을 모아서**.

### 연쇄 법칙으로 잇기 ⭐
단순한 2노드 신경망을 다시 보면, **비용을 가중치 또는 편향으로 편미분하는 연쇄 법칙 식을 바로 쓸 수 있다.** 두 도함수를 잇는 것이 **a¹ 항**이다.

**중간 항 z¹을 도입하면 편해진다**
```
z¹ = w·a⁰ + b          ← 가중 활성 + 편향
a¹ = σ(z¹)
```
> 이렇게 하면 **우리가 고른 특정 시그모이드 함수를 미분하는 일을 따로 떼어 생각할 수 있다.** 따라서 **도함수 사슬에 링크를 하나 더** 넣는다.

```
∂C/∂w = (∂C/∂a¹)·(∂a¹/∂z¹)·(∂z¹/∂w)
∂C/∂b = (∂C/∂a¹)·(∂a¹/∂z¹)·(∂z¹/∂b)
```

> 이제 이 단순 신경망의 비용을 최소화하기 위해 **2차원 (w, b) 공간을 항해하는 데 필요한 두 개의 연쇄 법칙 식**을 갖췄다.

### 뉴런이 늘어나면
> 분명히 조금 더 복잡해지지만, **근본적으로는 여전히 연쇄 법칙을 적용해 각 가중치와 편향을 그것이 비용에 미치는 영향에 잇는 것**이며, 그것이 결국 신경망을 훈련시킨다.

## 요약
- **훈련 = 레이블된 (입력, 출력) 쌍으로 가중치·편향을 맞춰 가는 것.** 가중치·편향은 **무작위로 초기화**한다.
- **비용 함수 `C = Σ(y − a)²`** — 원하는 출력과 현재 출력 차이의 제곱합.
- **기울기의 반대 방향으로 가면 비용이 줄어든다.** 다차원에서는 **비용 함수의 야코비안**을 만든다.
- **중간 항 `z = w·a + b`** 를 도입해 사슬을 한 단계 늘리면 **활성화 함수 미분을 분리**할 수 있다.
- **`∂C/∂w = (∂C/∂a)(∂a/∂z)(∂z/∂w)`** — 이것이 **역전파**이며, [모듈 3의 다변량 연쇄 법칙](03%20More%20multivariate%20chain%20rule.md)의 직접 응용이다.
- **역전파라는 이름은 출력에서 시작해 신경망을 거꾸로 거슬러 오르기 때문**에 붙었다.
