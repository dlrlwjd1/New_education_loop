# 03 More multivariate chain rule

## 개요
- 강좌: Mathematics for Machine Learning - Multivariate Calculus (Imperial College London)
- 모듈: Module 3 — Multivariate chain rule and its applications
- [MOOC 원본 강의](https://www.mooc.org/learn/multivariate-calculus-machine-learning/lecture/Ht9dM/more-multivariate-chain-rule)
- **야코비안이 다변량 연쇄 법칙의 가장 편리한 표현**임을 확인하고, **사슬을 셋 이상으로 늘린다.**

---

## 내용

### 놓쳤을 수 있는 디테일 — 그것은 야코비안이다 ⭐
> 지난 영상의 **편미분 벡터 `∂f/∂x` 는 사실 [모듈 2의 야코비안 벡터](../Module%202%20-%20Multivariate%20calculus/04%20The%20Jacobian.md)와 같다.** 다만 **행벡터가 아니라 열벡터로 썼을 뿐**이다.

선형대수의 지식으로 정리하면:
```
∂f/∂x = (J_f)ᵀ          ← f의 야코비안의 전치
```
> 그리고 **두 열벡터의 내적은 행벡터 × 열벡터의 곱과 같은 연산**이다. 따라서 —
>
> ⭐ **옛 친구 야코비안이 다변량 연쇄 법칙의 가장 편리한 표현을 제공한다.**
```
df/dt = J_f · (dx/dt)
```

### 사슬이 셋 이상일 때 — 일변량 예제
```
f(x) = 5x,    x(u) = 1 − u,    u(t) = t²
```
**직접 대입**
```
f = 5(1 − t²) = 5 − 5t²
df/dt = −10t
```
**2단계 연쇄 법칙**
```
df/dt = (df/dx)·(dx/du)·(du/dt)
      = 5 · (−1) · 2t
      = −10t          ← 같은 답
```
> **f와 t 사이에 중간 함수가 몇 개든 이 방식으로 확장할 수 있다.**

### 다변량에서 사슬 셋 — 차원을 맞춘다 ⭐
`f(x(u(t)))` 를 생각한다.

| 함수 | 입력 | 출력 |
|---|---|---|
| **f** | **벡터 x** | 스칼라 |
| **x** | **벡터 u** | **벡터** (벡터값 함수) |
| **u** | **스칼라 t** | **벡터** (벡터값 함수) |

> 결국 **스칼라 입력 t를 스칼라 출력 f에 잇되, 중간에 두 개의 벡터값 함수 x와 u를 거친다.**

식은 일변량과 거의 같지만 **여러 항이 굵은 글씨(벡터)** 다.

| 항 | 무엇인가 |
|---|---|
| **`∂f/∂x`** | 스칼라값 함수 f를 입력 벡터 x로 미분 → **야코비안 행벡터** |
| **`du/dt`** | 벡터값 함수 u를 스칼라 t로 미분 → **도함수 열벡터** |
| **`∂x/∂u`** ⭐ | 함수 x의 **각 출력 변수를 각 입력 변수로** 미분 → 2×2면 **항이 넷** → **행렬**. 이것도 **야코비안**이라 부른다 |

```
df/dt = J_f · J_x · (du/dt)
        (행벡터) (행렬)  (열벡터)
```

> ⭐ **이 벡터·행렬들의 차원이 이 연산이 가능하도록, 그리고 결과가 기대대로 스칼라가 되도록 맞아떨어진다.**

> 강사의 마무리: **선형대수와 다변량 미적분의 여러 갈래가 함께 엮이는 것이 보이기 시작할 것이다.**

---

## 요약
- **`∂f/∂x` 는 야코비안의 전치**다. 그래서 **다변량 연쇄 법칙은 야코비안 곱으로 쓰는 것이 가장 편하다.**
- 사슬은 **몇 단계든 늘릴 수 있다**: `df/dt = (df/dx)(dx/du)(du/dt)`.
- 다변량에서 **중간 항 `∂x/∂u`는 벡터값 함수의 야코비안 행렬**이다.
- 전체는 **행벡터 × 행렬 × 열벡터 = 스칼라**로 차원이 맞아떨어진다.
- **선형대수와 미적분이 만나는 지점**이며, 다음 강의의 신경망 역전파가 정확히 이 구조다.
