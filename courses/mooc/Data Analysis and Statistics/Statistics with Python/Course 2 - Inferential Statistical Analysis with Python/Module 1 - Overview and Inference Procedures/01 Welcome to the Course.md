# Welcome to the Course!

## 개요
- Statistics with Python 전문과정의 두 번째 코스인 Inferential Statistical Analysis with Python에 대한 환영 및 코스 전체 구성 소개
- 코스는 네 부분(part)으로 구성: 추론 기법 개관 → 신뢰구간(confidence interval) 추정 → 가설검정(hypothesis testing) → 심화 응용
- 각 코스는 이전 코스 위에 쌓이는 구조로, 통계 개념을 Python으로 직접 적용하며 학습

## 내용

### 코스의 위치와 성격
이 코스는 Statistics with Python 전문과정(specialization)의 두 번째 코스다. 각 코스는 이전 코스 내용 위에 쌓이는 구조로, 통계가 무엇인지에 대한 균형 잡힌 시각과 함께 배운 내용을 Python으로 적용하는 능력을 기른다.

### Part 1 — 추론 기법 미리보기
- 앞으로 다룰 추론 기법(inference techniques)과 탐구 가능한 연구 질문(research question)들을 미리 살펴본다.
- 학습자가 자신의 삶에서 발견한 연구 질문을 공유하는 기회가 있다.
- "Bag A or Bag B" 활동을 통해 데이터를 사용해 경쟁하는 이론(competing theories) 사이에서 어떻게 의사결정을 하는지 이해한다.
- "This or That" 활동으로 코스에서 사용할 언어와 표기법(notation)에 익숙해진다.
- 프로그래밍 측면에서는 Jupyter Notebook을 다루며 중급(intermediate) Python 개념으로 넘어간다.

### Part 2 — 모수 추정: 신뢰구간
- "그 모수(parameter) 값은 무엇인가?"라는 질문을 다룬다.
- 모수를 신뢰(confidence)를 가지고 추정하는 방법을 배운다.
- 최선의 추정치(best estimate)에서 오차범위(margin of error)만큼 ±로 나아가, 해당 모수에 대해 타당하다고 상당히 확신할 수 있는 값의 범위를 구한다.

### Part 3 — 가설검정
- "유의한 차이(significant difference)가 있는가?"라는 성격의 질문에 답하는 가설검정(hypothesis testing) 기법을 다룬다.
- 데이터를 검정통계량(test statistic)으로 변환하고, 그에 대응하는 p-값(p-value)을 계산해 경쟁하는 이론 사이에서 결정을 내린다.
- p-값, p-해킹(p-hacking), 그리고 연구 수행 시의 좋은 관행(good practices)에 대한 흥미로운 논의가 포함된다.
- 활동 중 하나는 초콜릿에 관한 것으로, 사이클 선수의 기량 향상을 위해 식단에 초콜릿을 도입할지 결정하는 실험을 다룬다.

### Part 4 — 심화 응용
- 학습 내용의 응용과 다른 개념들에 대한 심화 탐구(deeper dives)를 진행한다.
- 추론 결과를 전달(communicating)하는 연습을 훨씬 더 많이 한다.
- 복잡 표본설계(complex sampling designs)를 다루고, 추론을 위한 대안적 방법(alternative methods for inference)도 약간 논의한다.

### 학습 지원 요소
- 코스 전반에 걸쳐 학습 평가(assessment) 기회, 심화 학습을 위한 자료, 웹 애플릿(web applet)과 Python 튜토리얼을 통한 실습이 제공된다.
- 여러 팀 구성원들이 통계적 추론(statistical inference)에 대한 각자의 관점과 통찰을 공유한다.

## 요약
- 이 코스는 전문과정의 두 번째 코스로, 통계적 추론을 Python과 함께 배운다.
- Part 1: 추론 기법 개관, 언어·표기법, Jupyter Notebook과 중급 Python.
- Part 2: 신뢰구간을 이용한 모수 추정 — 최선의 추정치 ± 오차범위.
- Part 3: 가설검정 — 검정통계량과 p-값으로 경쟁 이론 사이의 의사결정, p-해킹 논의 포함.
- Part 4: 결과 전달 연습, 복잡 표본설계, 대안적 추론 방법.
