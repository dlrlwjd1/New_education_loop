# Inferential Statistical Analysis with Python Guidelines

## 개요
- 이 코스에서 최대한 많이 얻어가기 위한 학습 가이드라인과 팁을 제공하는 짧은 강의
- 핵심 조언: 강의 영상과 Jupyter Notebook을 동시에 열어 두고, 강의를 일시정지하며 노트북에서 직접 따라 해 볼 것
- 2~4주차는 다양한 추론 기법의 표본(sampling)을 제공하므로, 기초 내용(readings)을 잘 활용해 스스로 확장 학습할 수 있는 토대를 다질 것

## 내용

### Jupyter Notebook 활용 방법
- 이 코스는 강의에서 다룬 개념을 Python으로 설명·시연하기 위해 Jupyter Notebook에 크게 의존한다.
- 노트북은 보통 각 주차의 강의, 연습문제, 퀴즈 뒤에 배치되어 있다. 예를 들어 1주차에는 여러 영상, 읽기 자료, 토론 프롬프트가 있고 맨 끝에 노트북들이 있다.
- 영상과 노트북은 종종 짝(pair)을 이루므로, 강의를 다 본 뒤에야 노트북을 여는 것이 아니라 **강의를 들으면서 노트북을 동시에 열어 두기를 강력히 권장**한다.
- 강의를 일시정지하고 배운 내용을 노트북에서 바로 시도해 볼 수 있다. 큰 모니터나 다중 모니터를 쓰면 이 작업이 수월해진다.
- 과거 수강생들은 이 방식이 정보 습득과 Python 적용 감각을 극대화한다고 평가했다.
- 강사의 실제 작업 공간 예시: 한 화면에는 Python의 함수(function)가 무엇인지, 함수를 어떻게 정의하는지 안내하는 팀원의 영상을 띄우고, 다른 화면에는 노트북을 열어 같은 단계를 바로 따라 할 준비를 해 두었다.

### 2~4주차 학습 전략
- 2, 3, 4주차에서는 다양한 추론 기법의 표본(sampling)을 제공한다. 몇 가지 유형의 모집단 모수(population parameter)에 대한 신뢰구간 추정(confidence interval estimation)과 가설검정(hypothesis testing)을 소개한다.
- 모집단 비율(population proportion)에 대한 첫 번째 추론에서는 좀 더 많은 영상이 제공되고, 이후의 모수들에 대해서는 해당 시나리오에 익숙해질 수 있는 좋은 예시 하나씩을 제공한다.
- 모든 추론 방법의 세세한 디테일을 배우는 것도, 보고 싶을 모든 추론 방법을 다루는 것도 아니다.
- 따라서 이미 익힌 **기초 내용을 잘 활용**하고, **읽기 자료(readings)를 건너뛰지 말 것**. 읽기 자료가 이 추론 기법들이 무엇인지에 대한 탄탄한 기초를 제공한다.
- 그 기초 위에서 학습자 스스로 조사(research)를 통해 세부 사항과 관련 기법들을 익혀 나갈 수 있다. 즉, 코스가 끝나도 계속 배울 준비가 된다.

### 질문과 지원
- 강사진은 코스 내용에 대한 개별 질문을 환영한다. 즉시 답변되지 않을 수 있지만, 답변되면 FAQ로 정리되어 미래 학습자에게 제공된다.
- 대부분의 질문은 토론 포럼(discussion forums)에서 빠르게 답변된다. 더 복잡한 질문도 자유롭게 올리면 강사에게 전달된다.

### 어려운 주제와 읽기 자료
- 강사진도 학습자들로부터 배우고 있으며, 과거 학습자들이 더 어렵게 느낀 주제들이 있다. 예: 4주차의 복잡 표본설계(complex sampling designs)를 고려하는 것이 추론 절차에 미치는 영향.
- 코스 곳곳에 배치된 읽기 자료를 잘 활용할 것. 상당수가 핵심 아이디어 요약(big ideas summaries)과 추가 자료 링크를 담고 있다.

## 요약
- 강의 영상과 Jupyter Notebook을 동시에 열어 두고 일시정지하며 직접 실습하는 것이 가장 효과적인 학습법이다.
- 2~4주차는 신뢰구간 추정과 가설검정을 모수 유형별 대표 예시로 소개하며, 모든 세부 기법을 다루지는 않는다.
- 읽기 자료를 건너뛰지 말 것 — 스스로 확장 학습할 수 있는 기초를 제공한다.
- 질문은 토론 포럼에 올리면 되고, 복잡한 질문은 강사에게 전달되어 FAQ로 축적된다.
