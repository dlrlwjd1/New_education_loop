# Testing a Population Mean Difference

## 개요
- 대응 자료(paired data)에서 모평균 차이(population mean difference) μ_d 를 검정하는 방법을 다룬다.
- 사례: 주방 리모델링 중인 주택 20채가 두 캐비닛 공급업체(A, B)에서 견적을 받음 — 같은 집에서 두 측정값이 나오므로 대응 자료다.
- t = 2.72, p-값 = 0.014 < 0.05 → 기각. 평균 견적 차이는 0과 유의하게 다르다. 신뢰구간과 Wilcoxon Signed Rank Test도 같은 결론.

## 내용

### 대응 자료와 연구 질문
- 주택 20채가 두 공급업체(supplier A, B)에 캐비닛 견적을 요청. **같은 개체(집)에서 두 측정값**이 나오므로 개체(집) 기준으로 짝지어진(paired/matched) 자료다.
- 분석 변수는 견적 차이(difference in cabinet quotes)로, **A − B** 로 정의한다. 차이를 어느 방향으로 계산했는지 항상 명시해야 한다.
- 연구 질문: 두 공급업체의 캐비닛 견적에 평균적인 차이가 있는가? (평균 차이가 0인가 아닌가)
- 모집단: 모든 주택. 모수: 모평균 견적 차이 μ_d (아래 첨자 d는 차이(difference)를 의미).

### 가설과 유의수준
- H₀: μ_d = 0
- Hₐ: μ_d ≠ 0 — 어느 업체가 더 비쌀지에 대한 사전 방향성이 없으므로 양측(two-sided).
- α = 0.05 (5% 유의수준).

### 데이터 살펴보기
- 각 집마다 A 견적, B 견적, 차이를 기록. 첫 행의 차이는 $55 (A가 B보다 $55 비쌈).
- 차이의 부호가 어느 업체가 비싼지 알려준다. 5번째 행(−$6)을 제외하면 대부분 한쪽 방향.
- A 견적 vs B 견적 산점도(scatter plot)를 보면 상당히 상관되어 있다 — 집에 따라 두 업체의 견적이 함께 움직인다.
- 대응 자료이므로 모든 표본 통계량은 **차이 변수**로 계산한다.
- 요약 통계: n = 20, 최소 −$30 (한 집에서는 A가 $30 더 저렴), 최대 $90, 중앙값 $13.50, 평균 $17.30, 표준편차 약 $28.50.

### 가정 확인
1. 차이들의 확률표본 — 즉 주택들의 확률표본. 집의 확률표본이면 차이의 확률표본도 된다.
2. 차이의 모집단이 정규분포일 것. 표본이 약 25 이상이면 이 가정을 완화할 수 있는데, 여기는 20개뿐이므로 정규 Q-Q plot을 확인한다.
   - 점들이 대체로 직선을 따라 놓여 있고 20은 25에 가까우므로 합리적인 가정으로 본다.
   - 차이의 히스토그램도 대략 종 모양(bell-shaped)이다.

### 검정통계량과 p-값
- 표본평균 차이의 표집분포가 정규라고 가정하면 t 검정통계량을 쓴다:
  - t = (x̄_d − 0) / (s_d / √n)
- 대입: n = 20, x̄_d = 17.30, s_d ≈ 28.50 → t = **2.72**
- 해석: 관측된 평균 차이는 가설값 0보다 **2.72 추정 표준오차** 위에 있다 — 꽤 크다.
- t는 자유도 20 − 1 = **19**의 t-분포를 따른다 (모표준편차 대신 추정 표준편차를 썼으므로 정규분포보다 꼬리가 약간 두껍다).
- Hₐ: μ_d ≠ 0 이므로 **양쪽**을 색칠한다: 2.72 이상과 −2.72 이하 (3은 −3과 똑같이 극단적이다).
- p-값 = **0.014** — 이만큼 극단적인 검정통계량은 약 1.4%의 확률로만 관측된다.

### 결정과 결론
- 0.014 < 0.05 → 귀무가설 **기각(reject)**.
- 결론: A − B 캐비닛 견적의 평균 차이는 0과 유의하게 다르다.

### 신뢰구간으로 방향 확인
- 95% 신뢰구간: x̄_d ± t* × s_d/√n, 여기서 n = 20 기준 t* = 2.093.
- 구간: 약 **$3.97 ~ $30.63**. 0이 구간에 없다 → 평균 차이가 0이 아니라는 결론과 일치.
- 모든 값이 양수이므로 A가 B보다 비쌀 가능성이 크다는 방향성도 알 수 있다.

### 비모수 대안: Wilcoxon Signed Rank Test
- 차이 모집단의 정규성이 성립하지 않으면 윌콕슨 부호순위 검정(Wilcoxon Signed Rank Test)을 사용한다. 평균 대신 **중앙값(median)** 이 0과 다른지 검정한다.
- 기술 도구로 계산한 p-값 = 0.02 → 역시 기각. 중앙값 차이도 0과 다르다는, 전반적으로 같은 결론이다.

## 요약
- 대응 자료 검정은 일표본 평균 검정의 확장이다: 두 측정값에서 차이 변수를 만들어 μ_d 를 검정한다.
- H₀: μ_d = 0, Hₐ: μ_d ≠ 0, t = (x̄_d − 0)/(s_d/√n) = 2.72, df = 19, 양측 p-값 = 0.014 < 0.05 → 기각.
- 95% 신뢰구간($3.97~$30.63)에 0이 없어 검정 결과와 일치하고, A가 더 비싼 방향임을 시사한다.
- 정규성이 의심되면 Wilcoxon Signed Rank Test(중앙값 기반, p = 0.02)로도 같은 결론을 얻는다.
