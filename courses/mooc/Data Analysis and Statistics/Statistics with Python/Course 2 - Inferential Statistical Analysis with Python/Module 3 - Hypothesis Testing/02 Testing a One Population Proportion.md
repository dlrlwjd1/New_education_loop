# Testing a One Population Proportion

## 개요
- 앞 강의에서 설정한 일표본 비율 검정을 실제로 수행한다: 검정통계량(test statistic) 계산 → p-값(p-value) 도출 → 결론.
- 검정통계량의 일반형은 (최선의 추정치 − 가설값) / 표준오차(standard error)이며, 비율 검정에서는 귀무 표준오차(null standard error)를 사용한다.
- p-값 0.0053 < α 0.05 이므로 귀무가설을 기각(reject)한다.

## 내용

### 설정 복습
- H₀: p = 0.52, Hₐ: p > 0.52 (유의한 증가를 확인하려는 검정).
- p = 전자기기·소셜미디어가 청소년 수면 부족의 원인이라고 믿는, 청소년을 둔 부모의 모비율.
- α = 0.05, 최선의 추정치(best estimate) p̂ = 0.56, 표본 크기 n = 1,018.

### 검정통계량 계산
- 검정통계량의 일반형:
  - (최선의 추정치 − 가설된 추정치) / 추정치의 표준오차
- 일표본 비율 검정에서는: Z = (p̂ − p₀) / SE
- 표준오차는 원래 SE(p̂) = √(p(1−p)/n) 인데, p를 모르므로 p₀로 대체한다:
  - 귀무 표준오차(null standard error): SE = √(p₀(1−p₀)/n)
- 계산: Z = (0.56 − 0.52) / 0.0157 = **2.555**
- 비율은 (표본이 충분히 크면) 정규분포를 따르므로 Z 검정통계량(Z test statistic)이라 부른다.
- 해석: 관측된 표본비율이 가설된 모비율보다 **2.555 귀무 표준오차만큼 위에** 있다.

### Z 검정통계량의 분포
- 검정통계량도 하나의 확률변수(random variable)로, 자체 분포를 가진다: N(0, 1) 표준정규분포.
- 이유: 원래 데이터가 정규분포였고, 분자에서 가설된 평균을 빼서 **중심화(centering)**, 표준오차로 나눠 **척도화(scaling)** 했기 때문이다.

### p-값 구하기
- N(0,1) 곡선에서 Z = 2.55 위치에 선을 긋는다.
- Hₐ가 p > 0.52 이므로 부등호 방향(>)에 따라 검정통계량 **오른쪽** 영역을 색칠한다. 그 넓이가 p-값이다.
- Python 같은 프로그래밍 언어에 넣거나 Z-표(Z-table)에서 2.55를 찾으면 p-값 = **0.0053**.

### 결론 내리기
- p-값 0.0053 < α 0.05 → 귀무가설 H₀: p = 0.52 를 **기각(reject)** 한다. 매우 일어나기 힘든 결과가 나왔으므로 처음의 가정을 믿기 어렵게 된 것이다.
- 결론 문장: "청소년을 둔 부모 중 전자기기와 소셜미디어가 수면 부족의 원인이라고 믿는 모비율이 0.52(52%)보다 크다고 결론 내릴 충분한 증거가 있다."
- 반대로 p-값이 α보다 크면 기각 실패(fail to reject)이며, 그에 맞는 결론 문장을 쓴다.
- 앞으로의 검정도 가정과 가설은 달라지지만 검정통계량은 항상 같은 형태를 따르고 대입하는 값만 바뀐다. Z 대신 T 검정통계량(T test statistic)을 쓰는 경우도 나온다.

## 요약
- 가설검정의 4단계: (1) 가설 수립 + 유의수준 α 선택 → (2) 가정 확인 → (3) 검정통계량 계산과 p-값 도출 → (4) p-값으로 결론.
- 검정통계량 공식: (최선의 추정치 − 가설값) / 표준오차. 비율에서는 귀무 표준오차 √(p₀(1−p₀)/n) 사용.
- 이번 예시: Z = 2.555, p-값 = 0.0053 < 0.05 → H₀ 기각, 비율이 52%보다 유의하게 크다.
- Z 검정통계량이 N(0,1)을 따르는 이유는 정규분포인 원 데이터를 중심화·척도화했기 때문이다.
