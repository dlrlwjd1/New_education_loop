# Testing for a Difference in Population Means (for Independent Groups)

## 개요
- 두 독립 집단(independent groups)의 모평균 차이 μ₁ − μ₂ 에 대한 독립표본 t-검정(independent samples t-test)을 다룬다.
- 사례(NHANES): 미국 거주 18~29세 멕시코계 미국인 성인에서 남성의 평균 BMI가 여성보다 유의하게 높은가?
- 합동(pooled) 접근으로 t = 1.30, p-값 = 0.1942 > 0.05 → 기각 실패. 신뢰구간(−0.385 ~ 1.865)에 0이 포함되어 결과가 일치한다.

## 내용

### 연구 질문과 모수
- 연구 질문: 미국에 사는 18~29세 멕시코계 미국인(Mexican-American) 성인 중, 남성의 평균 체질량지수(BMI, body mass index)가 여성보다 유의하게 높은가?
- 모집단: 18~29세 멕시코계 미국인 성인. 두 하위 모집단은 남성 그룹과 여성 그룹.
- BMI는 kg/m² 단위로, 저체중/정상/과체중을 분류하기 위해 조직량을 수치화한 지표다.
- 모수 표기: μ₁ − μ₂ (μ₁ = 남성 모평균 BMI, μ₂ = 여성 모평균 BMI).

### 가설검정 단계
1. 귀무·대립가설 정의
2. 데이터 검토, 가정 확인, 검정통계량 계산
3. 대응하는 p-값 결정
4. p-값에 근거해 귀무가설에 대한 결정

### 가설 설정
- H₀: μ₁ = μ₂ (또는 μ₁ − μ₂ = 0) — 남녀 평균 BMI에 차이가 없다.
- Hₐ: μ₁ ≠ μ₂ (또는 μ₁ − μ₂ ≠ 0) — 유의한 차이가 있다.
- 충분한 통계적 증거가 나오기 전까지 귀무가설이 참이라고 가정한다.
- 유의수준 α = 0.05.

### 데이터 검토와 가정 확인
- NHANES 데이터에서 인종 = 멕시코계 미국인, 연령 18~29로 필터링. 성별 코딩: 남성 = 1, 여성 = 2.
- 요약 통계(평균, 표준편차, 최소·최대, 표본 크기)와 상자그림(boxplot)으로 분포를 확인. 표본평균 차이는 **0.74** — 이것이 유의한 차이인지 검정한다.
- 가정:
  1. 두 표본이 단순확률표본(simple random samples)일 것 — 이 예제에서는 그렇게 가정.
  2. 두 표본이 서로 **독립(independent)** 일 것 — 짝지어질 수 없어야 한다. 여기서는 성별로 나눴을 뿐이므로 의존성을 의심할 이유가 없다.
  3. 두 모집단의 반응이 근사적으로 정규분포일 것 — 히스토그램과 Q-Q plot으로 확인. 여성 그룹은 정규에서 꽤 벗어나 있지만 두 그룹 모두 표본이 200 이상으로 매우 커서 중심극한정리(central limit theorem)를 적용할 수 있고, 표본이 크면 두 평균 검정의 결과는 상당히 강건(robust)하다.

### 검정통계량: 합동 vs 비합동 접근
- 검정통계량 = 표본 통계량이 가설된 모수에서 **추정 표준오차 몇 개만큼** 떨어져 있는지의 측도. 모두 귀무가설이 참이라는 가정 하에 계산한다.
- 일반형: (최선의 추정치 − 가설된 귀무값) / 추정 표준오차.
- 두 평균의 추정 표준오차는 접근법에 따라 달라진다:
  - **합동 접근(pooled approach)**: 두 모집단의 분산(variance)이 같다고 가정할 수 있을 때. 합동 표준편차(pooled standard deviation) S_p 를 사용한다.
  - **비합동 접근(unpooled approach)**: 그 가정을 버릴 때. 분자는 같고 추정 표준오차(분모)만 달라진다.
- 접근 선택: 두 그룹 표본표준편차가 약 0.2 차이로 매우 비슷하고, 상자그림의 IQR(가운데 50%) 높이도 비슷하다 → **합동 접근** 채택 (모분산이 같다고 가정).

### 계산과 p-값
- 값을 대입해 계산하면 검정통계량 t ≈ **1.30**.
- 해석: 표본평균 차이는 귀무 차이 0 kg/m²보다 **1.30 추정 표준오차** 위에 있을 뿐이다.
- p-값 = 귀무가설이 참일 때 1.3 또는 그보다 극단적인 검정통계량을 관측할 확률.
- 자유도 n₁ + n₂ − 2 = **495** 인 t-분포 사용. Hₐ가 ≠ 이므로 양측 — 양쪽 꼬리(+1.30 위, −1.30 아래)를 모두 색칠.
- p-값 = **0.1942** — 남녀 모평균 BMI 차이가 실제로 0이라면, 표본평균 차이 0.74 이상을 볼 확률이 거의 20%다. 꽤 일어날 만한 일이다.

### 결정과 결론
- 0.1942 > 0.05 → 귀무가설 **기각 실패(fail to reject)**. 귀무가설에 반하는 증거가 매우 약하다.
- 결론: 18~29세 멕시코계 미국인 성인에서 남성과 여성의 모평균 BMI에 유의한 차이가 있다고 지지할 수 없다.

### 신뢰구간과의 일치
- 이전 강의에서 만든 95% 신뢰구간: **−0.385 ~ +1.865**.
- 가설값 0 kg/m²가 구간 안에 있다 — 0이 그럴듯한 값이므로 신뢰구간과 가설검정 결과가 서로 일치한다.

## 요약
- 독립 두 표본 t-검정: H₀: μ₁ − μ₂ = 0 vs Hₐ: μ₁ − μ₂ ≠ 0, α = 0.05.
- 가정: 두 단순확률표본, 상호 독립, 모집단 정규성(표본이 크면 CLT로 완화).
- 모분산이 같다고 볼 수 있으면 합동(pooled), 아니면 비합동(unpooled) 표준오차 사용 — 표준편차와 IQR 비교로 판단.
- t = 1.30, df = 495, 양측 p-값 = 0.1942 → 기각 실패. 95% 신뢰구간(−0.385~1.865)에 0이 포함되어 같은 결론.
