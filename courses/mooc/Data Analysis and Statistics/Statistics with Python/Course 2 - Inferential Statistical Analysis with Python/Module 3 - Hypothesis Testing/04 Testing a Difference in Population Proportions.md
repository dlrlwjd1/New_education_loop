# Testing a Difference in Population Proportions

## 개요
- 앞 강의에서 설정한 두 모비율 차이 검정을 완성한다: 검정통계량 계산 → 양측(two-sided) p-값 → 결론.
- Z = −0.48, p-값 0.63 > α 0.1 이므로 귀무가설 기각 실패(fail to reject) — 두 비율에 유의한 차이가 없다.
- 대안적 접근으로 카이제곱 검정(chi-square test)과 피셔의 정확검정(Fisher's exact test)을 소개한다.

## 내용

### 설정 복습
- H₀: 두 모비율이 같다(차이 = 0), Hₐ: 두 모비율이 다르다. α = 0.1.
- p̂₁ = 0.37, p̂₂ = 0.39, 표본비율 차이 = −0.02, 공통 표본비율(common sample proportion) = 0.38.

### 검정통계량 계산
- 일반형: (최선의 추정치 − 가설된 추정치) / 추정치의 표준오차.
- 최선의 추정치 = p̂₁ − p̂₂, 가설된 추정치 = 0 (귀무가설 p₁ − p₂ = 0에서 옴 — 모수 차이를 볼 때는 대개 0이다).
- 표준오차: SE = √( p̂(1−p̂) × (1/n₁ + 1/n₂) ) — 여기서 p̂은 공통 표본비율. 보통 계산기나 컴퓨터로 계산하지만 손으로 할 때를 위한 공식이다.
- 대입하면 SE = 0.041, Z = −0.02 / 0.041 = **−0.48**
- 해석: 관측된 표본비율 차이는 "두 모비율이 같다"는 가설값보다 **0.48 추정 표준오차만큼 아래**에 있다.

### p-값과 결론
- Z 검정통계량은 표준정규분포(standard normal distribution, 평균 0·표준편차 1)를 따른다. −1과 1 사이에 데이터의 약 68%가 있다.
- 색칠할 영역은 대립가설이 결정한다. Hₐ: p₁ − p₂ ≠ 0 (양측)이므로 0에서 먼 **양쪽 꼬리**를 모두 색칠한다.
- 색칠된 넓이 = p-값 = **0.63** (표, 공식 카드, 컴퓨터로 계산 가능).
- 0.63 > α 0.1 → 귀무가설 **기각 실패(fail to reject)**.
  - 이는 귀무가설을 "채택(accept)"한다는 뜻이 아니다. 같은 모비율이라는 가설에 반하는 증거가 없다는 뜻일 뿐이다.
- 결론: 자녀가 수영 강습을 받았다고 응답한 흑인 아동 부모와 히스패닉 아동 부모의 모비율 사이에 유의한 차이가 없다. 두 모비율이 대략 비슷해 보인다.

### 대안적 접근 1: 카이제곱 검정 (chi-square test)
- 데이터가 비율 대신 이원표(two-way table)로 주어질 수 있다. 각 표본에서 강습을 받은/받지 않은 아동 수를 내부에, 합계를 가장자리에 적는다.
- 카이제곱 검정과의 차이:
  - 가설의 표현이 약간 다르다 (보통 분포의 차이가 있는지 등으로 서술).
  - 카이제곱 검정은 **양측 가설일 때만** 이 검정과 동등하다. Hₐ가 ≠ 0일 때만 해당하며, > 0 이나 < 0 이면 같지 않다.
  - 양측 대립가설이었다면 p-값은 이 검정과 동일하게 나온다.

### 대안적 접근 2: 피셔의 정확검정 (Fisher's exact test)
- **표본이 작을 때** 사용할 수 있는 검정. 큰 표본에도 쓸 수 있지만 계산이 오래 걸린다.
- 단측(one-sided) 대립가설도 가능하다 (>, <, ≠ 모두 가능).
- 검정통계량에 정규분포 가정을 쓰지 않으므로 p-값이 약간 다르게 계산되지만, 일반적으로 가정을 두었을 때와 상당히 비슷하고, 표본이 충분히 크면 p-값이 정확히 같아진다.

## 요약
- 두 비율 차이 검정통계량: Z = (p̂₁ − p̂₂ − 0) / √( p̂(1−p̂)(1/n₁ + 1/n₂) ) = −0.48 (p̂은 공통 표본비율).
- 양측 검정이므로 양쪽 꼬리를 색칠 → p-값 = 0.63 > 0.1 → 기각 실패. 기각 실패는 귀무가설 채택이 아니다.
- 결론: 흑인·히스패닉 아동의 수영 강습 비율에 유의한 차이가 없다.
- 대안: 이원표 기반 카이제곱 검정(양측일 때만 동등), 작은 표본용 피셔의 정확검정.
