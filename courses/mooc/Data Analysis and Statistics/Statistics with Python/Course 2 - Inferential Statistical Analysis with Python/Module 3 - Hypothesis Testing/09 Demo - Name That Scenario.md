# Demo: Name That Scenario

## 개요
- 미시간 대학교 박사과정 Laura Tennis가 진행하는 "Name That Scenario" 웹사이트 사용법 데모.
- 통계 시나리오(일표본 비율, 두 표본 비율 등)를 구분하는 연습을 할 수 있는 오픈 액세스(open-access) 웹사이트다.
- 코스의 보조 자료(supplementary materials) 페이지에서 접속할 수 있다.

## 내용

### 사이트 소개와 시작하기
- Name That Scenario는 통계 시나리오를 구분하는 능력을 연습하게 해 주는 무료 웹사이트다.
- 첫 화면에서 이메일 주소와 비밀번호를 입력하고 계정 이름을 정한다.
- "Statistics"(유일한 옵션)를 클릭하면 여러 통계 시나리오 유형이 나온다.
- 시나리오 유형은 **최소 2개** 이상 선택해야 하고, 원하는 만큼 고를 수 있다. 데모에서는 일표본 비율(one proportion)과 두 표본 비율(two proportion)을 선택했다.
- 한 라운드에 10문제가 주어지고 전체 점수가 기록된다.

### 예시 문제 풀이
- 문제 1: 새 ctools 레이아웃을 검토 중이다. ctools 웹페이지에 새 레이아웃을 원하는지 묻는 설문을 게시했고, 응답자의 40% 이상이 원하면 개발팀이 변경을 적용한다. → 한 가지만 보고 있으므로 **일표본 비율(one proportion)** — 정답.
- 문제 2: 두 캠퍼스가 있는 대학교에서, 학생 조직 참여 가능성이 캠퍼스별로 다른지 알고 싶다. 각 캠퍼스에서 학부생 확률표본을 뽑아 참여 여부를 물었다. → 두 캠퍼스를 비교하므로 **두 표본 비율(two proportions)** — 정답.
- 정답 여부와 관계없이 문제마다 하단에 해설(explanation)이 제공되어 자신의 추론을 점검할 수 있다.

### 문제 은행과 세션 요약
- 각 라운드의 10문제는 문제 은행에서 **비복원(without replacement)** 추출되므로 한 라운드 안에서 중복 문제가 나오지 않는다.
- 라운드가 끝나면 세션 요약(session summary)을 보여 준다. 데모에서는 일표본 비율 4문제 중 2문제, 두 표본 비율 6문제 중 5문제, 총 10문제 중 7문제를 맞혀 7점을 얻었다.
- 계속 사용하면 누적 점수를 기록해 준다. 라운드가 끝나면 메인 설정으로 돌아가 다른 시나리오 조합을 선택할 수 있다.

## 요약
- Name That Scenario는 어떤 통계 검정 시나리오인지(예: 일표본 비율 vs 두 표본 비율) 판별하는 연습용 오픈 액세스 사이트다.
- 라운드당 10문제, 비복원 추출, 문제마다 해설 제공, 누적 점수 기록.
- 핵심 판별 기준: 하나의 집단·비율만 다루면 one proportion, 두 집단을 비교하면 two proportions.
