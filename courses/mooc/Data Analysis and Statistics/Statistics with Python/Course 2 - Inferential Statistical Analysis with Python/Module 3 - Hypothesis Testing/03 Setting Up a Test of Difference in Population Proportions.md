# Setting Up a Test of Difference in Population Proportions

## 개요
- 두 모비율의 차이(difference in population proportions) p₁ − p₂ 에 대한 가설검정의 설정 단계를 다룬다.
- CS Mott 어린이병원의 수영 강습(swimming lessons) 조사 사례: 흑인 아동 부모와 히스패닉 아동 부모의 비율 차이를 검정.
- 표본 크기 가정 확인에는 공통 표본비율(common sample proportion)을 계산해 사용한다.

## 내용

### 연구 질문과 모집단·모수
- 질문: 자녀가 수영 강습을 받은 적이 있다고 응답한 흑인 아동 부모와 히스패닉 아동 부모의 모비율 사이에 유의한 차이가 있는가?
- 모집단 1: 6~18세 흑인 아동의 모든 부모 / 모집단 2: 6~18세 히스패닉 아동의 모든 부모.
- 관심 모수: p₁ − p₂ (두 모비율의 차이). 그룹 1 = 흑인 아동 부모, 그룹 2 = 히스패닉 아동 부모로 지정.
- 유의수준은 10% (α = 0.1)로 검정하며, 데이터를 보기 **전에** 정한다.

### 가설 설정
- 귀무가설에는 항상 관심 모수와 등호(=)가 들어간다. 비율 차이를 볼 때 귀무값(null value)은 보통 0이다:
  - H₀: p₁ − p₂ = 0
- 대립가설은 >, <, ≠ 중 하나. 여기서는 어느 방향이든 상관없이 "차이가 있는지"만 보므로:
  - Hₐ: p₁ − p₂ ≠ 0
- α = 0.1.

### 데이터
- 흑인 아동 부모 표본 247명 중 91명이 자녀가 수영 강습을 받았다고 응답.
- 히스패닉 아동 부모 표본 308명 중 120명이 같은 응답.

### 가정 확인
1. **두 개의 독립 확률표본(two independent random samples)** — 데이터만으로는 확인할 수 없고, 그렇게 수집되었다고 알려져야 한다.
2. **충분히 큰 표본** — 추정치의 분포를 정규로 가정하기 위해 n₁·p̂, n₁·(1−p̂), n₂·p̂, n₂·(1−p̂) 가 모두 10 이상이어야 한다.
   - 여기서 p̂은 **공통 표본비율(common sample proportion)** 이다. 신뢰구간 때(각 그룹의 예/아니오 개수 확인)와 달리 계산이 필요하다.
   - 공통 비율 = 전체 "예" 수 ÷ 전체 응답자 수 = (91 + 120) / (247 + 308) = **0.38**
   - 네 값을 계산하면 94, 153, 117, 191 — 모두 10보다 크므로 충족.
   - 이 가정이 충족되지 않으면 이를 우회하는 다른 검정을 쓸 수 있다 (다음 강의 끝에서 다룸).

### 모수의 최선 추정치
- 모수 p₁ − p₂ 의 최선 추정치는 p̂₁ − p̂₂.
- p̂₁ = 91 / 247 = 0.37
- p̂₂ = 120 / 308 = 0.39
- p̂₁ − p̂₂ = **−0.02** — 흑인 아동 표본비율이 히스패닉 아동 표본비율보다 약간 작다.

## 요약
- 두 비율 차이 검정: H₀: p₁ − p₂ = 0, Hₐ: p₁ − p₂ ≠ 0 (방향 없는 차이 검정), α = 0.1.
- 가정: 두 독립 확률표본 + 공통 표본비율 기준으로 각 그룹의 기대 예/아니오가 모두 10 이상.
- 공통 표본비율 0.38, 표본비율 차이 p̂₁ − p̂₂ = −0.02.
