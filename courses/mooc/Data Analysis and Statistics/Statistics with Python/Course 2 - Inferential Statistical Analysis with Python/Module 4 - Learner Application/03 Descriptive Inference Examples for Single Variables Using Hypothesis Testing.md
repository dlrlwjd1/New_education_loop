# Descriptive Inference Examples for Single Variables Using Hypothesis Testing

## 개요
- 단일 변수의 기술적 수량(모비율, 모평균)에 대해 가설검정(hypothesis testing)으로 추론하는 두 가지 NHANES 예제를 다룬다.
- 공통 4단계: (1) 귀무·대립가설과 유의수준 정의 → (2) 검정통계량 계산 → (3) p-값 결정 → (4) 귀무가설에 대한 판단.
- 비율 예제에서는 귀무가설을 기각하고, 평균 예제에서는 기각에 실패하는 대조적 결과를 보여준다.

## 내용

### 예제 1 — 모비율에 대한 일표본 검정 (one-sample test for a proportion)
- 연구 질문: 2015-2016년 미국의 18세 이상 비히스패닉계 아프리카계 미국인 중 수축기 혈압이 130 mmHg를 초과한 비율이 33%(1/3)였는가, 아니면 달랐는가?
- 접근: 일표본·양측(two-tailed) 검정으로 "모비율 = 0.33"이라는 귀무가설을 기각하거나 기각에 실패한다.

**Step 1 — 가설과 유의수준 정의**
- 귀무가설(null hypothesis): P = 0.33
- 대립가설(alternative hypothesis): P ≠ 0.33 (더 클 수도, 작을 수도 있음 → 양측검정, 기각에 더 많은 증거 필요)
- 유의수준(significance level): 5% (0.05) = 제1종 오류율(Type I error rate). 귀무가설이 참인데 기각할 확률을 0.05로 설정.

**Step 2 — 검정통계량 계산**
- 점추정치: 465 / 1135 = 0.4097
- 추정 비율의 표집분포가 정규분포라고 가정하고 Z 통계량 형성:
  - Z = (0.4097 − 0.33) / (귀무가설 하에서의 표준오차)
  - 분모의 표준오차는 귀무값 0.33을 사용해 계산한다 — 귀무가설이 성립할 때 기대되는 표집 변동성 대비 추정치가 얼마나 이례적인지 보기 위해서다.
- 결과: **Z = 5.71** → 추정치가 귀무값 0.33에서 5 표준오차 이상 떨어져 있다는 뜻 (매우 멀다).

**Step 3 — p-값 결정**
- p-값 = 귀무가설이 참이라고 가정할 때 5.71 이상으로 극단적인 검정통계량을 볼 확률.
- 귀무가설이 참이면 Z는 표준정규분포(standard normal distribution, 평균 0, 분산 1)를 따른다.
- 양측검정이므로 P(Z > 5.71) + P(Z < −5.71)를 계산 → 사실상 **0**. 귀무가설을 지지하는 증거가 전혀 없다.

**Step 4 — 판단**
- 모비율이 정말 0.33이라면 표본비율 0.4097 이상을 관측할 가능성은 극히 낮다.
- p-값 < 0.05(유의수준)이므로 **귀무가설 기각**. 130 mmHg 초과 모비율은 0.33이 아니며, 그보다 훨씬 클 가능성이 높다.

### 예제 2 — 모평균에 대한 일표본 검정 (one-sample test for a mean)
- 연구 질문: 같은 모집단의 평균 수축기 혈압이 128 mmHg였는가, 아니면 달랐는가?

**Step 1 — 가설과 유의수준 정의**
- 귀무가설: μ = 128 mmHg / 대립가설: μ ≠ 128 mmHg (양측검정)
- 유의수준 5%. (연구 설계자가 원하는 수준으로 정할 수 있으나 사전에 명확히 밝혀야 한다.)

**Step 2 — 검정통계량 계산**
- 점추정치: 표본평균 = 128.252
- t 통계량 (스튜던트 t 분포, Student's t distribution) 사용:
  - t = (128.252 − 128) / 표준오차, 표준오차 = 19.958 / √1135
- 결과: **t = 0.425** → 점추정치가 귀무값 128에서 반(0.5) 표준오차도 안 떨어져 있음. 귀무값을 지지하는 쪽 증거.

**Step 3 — p-값 결정**
- 귀무가설이 참이면 t는 자유도(degrees of freedom) = n − 1 = 1134의 스튜던트 t 분포를 따른다 (정규분포와 비슷한 모양이나 자유도로 정의됨).
- 양측: P(t > 0.425) + P(t < −0.425) = **0.3175** → 귀무가설이 참일 때 이 정도 통계량은 꽤 흔하게 나온다.

**Step 4 — 판단**
- p-값(약 0.32)이 0.05보다 훨씬 크므로 귀무가설에 반하는 증거가 매우 약함 → **귀무가설 기각 실패(fail to reject)**.
- 주의: 대립가설을 "채택(accept)"하는 것이 아니라, 기각에 실패한다고만 판단한다. 128은 모평균으로 충분히 그럴듯한 값이다.

### 다음 내용
- 지금까지는 전체 모집단의 평균·비율에 대한 신뢰구간과 가설검정을 다뤘다. 다음은 **하위집단(subgroup) 간 차이**에 대한 추론 — 평균·비율 차이의 신뢰구간과 가설검정 — 을 다룬다.

## 예시
비율 검정 (강의 수치):

```text
H0: P = 0.33,  Ha: P ≠ 0.33,  α = 0.05
p̂ = 465/1135 = 0.4097
Z = (0.4097 − 0.33) / SE(H0 기준) = 5.71
p-값 ≈ 0  →  H0 기각
```

평균 검정 (강의 수치):

```text
H0: μ = 128,  Ha: μ ≠ 128,  α = 0.05
x̄ = 128.252,  SE = 19.958/√1135
t = (128.252 − 128) / SE = 0.425,  df = 1134
p-값 = 0.3175  →  H0 기각 실패
```

## 요약
- 가설검정 4단계: 가설·유의수준 정의 → 검정통계량 계산 → p-값 결정 → 판단.
- 검정통계량 분모의 표준오차는 (비율의 경우) 귀무가설 값으로 계산한다.
- p-값 < 유의수준이면 기각(비율 예제, Z = 5.71), 크면 기각 실패(평균 예제, t = 0.425, p = 0.3175).
- 기각 실패는 대립가설 채택이 아니며, 귀무값이 그럴듯하다는 의미다.
