# Comparing Means for Two Independent Samples: An Example

## 개요
- 전체 모집단 수량이 아니라 두 독립 하위집단(independent subgroups)의 평균을 비교하는 NHANES 예제를 다룬다.
- 접근: (1) 두 평균 차이에 대한 신뢰구간, (2) 이표본 t-검정(two-sample t-test), (3) 가정(assumption) 점검.
- 등분산 가정(pooling) 여부와 정규성(normality) 위반에 대한 결과의 강건성(robustness)을 확인한다.

## 내용

### 연구 질문과 데이터
- 연구 질문: 2015-2016년 미국에 거주하는 아프리카계 미국인 성인 중, 남성과 여성의 평균 수축기 혈압이 유의하게 달랐는가?
- 단순 무작위 표본 가정 하의 요약 통계:
  - 남성: 평균 131.01, 값의 표준편차 20.59, n = 536
  - 여성: 평균 125.79, 표준편차는 남성보다 약간 낮음, n = 599
- 점추정치: 평균 차이 = **5.22 mmHg** → "2015-2016년 흑인 성인 남성의 평균 수축기 혈압이 여성보다 5.22 mmHg 높다고 추정" — 이것이 유의한 차이인지, 표집 잡음(sampling noise)인지 확인해야 한다.

### 가정 점검 (시각적 진단)
- **히스토그램**: 남녀 모두 오른쪽 꼬리가 긴 우측 왜도(right skew) — 매우 큰 혈압 값이 소수 존재. 정규분포라 보기 어렵다.
- **정규 Q-Q 플롯(normal quantile-quantile plot)**: 정규분포라면 점들이 직선 위에 놓여야 하는데, 직선에서 벗어남 → 정규성 가정이 의심스럽다.
- 다만 표본이 크므로(중심극한정리, central limit theorem) 이표본 t-검정은 경미한 정규성 위반에 상당히 강건하다(robust).
- **나란한 상자그림(side-by-side box plot)**: 남성(gender=1) 쪽 분산이 약간 더 커 보임 → 등분산(constant standard deviation) 가정도 다소 의심스러움. 분석을 두 방식(등분산/이분산) 모두로 확인한다.
- 교훈: 구간 형성이나 검정 전에 반드시 이런 플롯으로 가정을 시각적으로 점검할 것.

### 접근 1 — 평균 차이에 대한 95% 신뢰구간
- 형태: 점추정치 ± 1.96 × (차이의 표준오차)
- **등분산 가정(표준편차 풀링, pooling)**: 95% CI = **(2.91, 7.53)**
  - 차이가 0이면 두 평균이 동일하다는 뜻인데, 구간이 0을 포함하지 않음 → 남성이 유의하게 높다는 증거.
- **이분산 가정(풀링 없음)**: 95% CI = **(2.90, 7.54)** — 아주 약간 넓어질 뿐 거의 동일. 결론은 등분산 가정 위반 가능성에 강건하다.

### 접근 2 — 이표본 t-검정
- 귀무가설: 남녀 모평균이 같다 / 대립가설: 다르다 (양측검정, 유의수준 5%)
- 핵심 가정: ① 각 모집단에서 혈압이 정규분포, ② 두 모집단의 표준편차 동일
- **풀링 결과**: t = **4.436**, 자유도 = 1135 − 2 = **1,133** (평균을 2개 추정하므로 −2), p-값 < 0.001 → 귀무가설 기각, 두 평균은 다르다.
- **풀링 없음**: t = **4.417**, 자유도는 약간 달라지지만 여전히 큼, p-값 < 0.001 → 같은 결론. 등분산 가정에 강건.

### 정규성이 의심될 때 — 비모수 검정 (non-parametric test)
- 이표본 t-검정의 비모수 대응은 **Mann-Whitney 검정(Mann-Whitney U test)**: 분포 가정 없이 중위수(median) 기준으로 두 분포의 위치(location)를 비교한다.
- 결과: p-값 < 0.001 → 두 분포의 위치가 같다는 귀무가설 기각. 정규성 위반 가능성에도 결론이 강건하다.

### 종합 결론과 다음 내용
- 가정을 어떻게 두든(풀링/비풀링, 모수/비모수), 어떤 추론 접근(신뢰구간/가설검정)을 쓰든 남녀 간 중심경향(central tendency) 차이의 일관된 증거가 있다.
- 다음 강의: **짝지어진(paired) 데이터**의 두 평균 비교 — 예: 같은 사람의 오른팔·왼팔 혈압, 개입(intervention) 전후 측정치.

## 예시
강의 수치 정리:

```text
남성: x̄ = 131.01, s = 20.59, n = 536
여성: x̄ = 125.79, n = 599
차이 추정치 = 131.01 − 125.79 = 5.22 mmHg

95% CI (풀링):   (2.91, 7.53)   → 0 미포함
95% CI (비풀링): (2.90, 7.54)   → 0 미포함

t-검정 (풀링):   t = 4.436, df = 1133, p < 0.001 → 기각
t-검정 (비풀링): t = 4.417, p < 0.001 → 기각
Mann-Whitney:    p < 0.001 → 기각
```

## 요약
- 두 독립집단 평균 비교: 차이의 신뢰구간 + 이표본 t-검정을 함께 사용.
- 검정 전 히스토그램, Q-Q 플롯, 상자그림으로 정규성·등분산 가정을 시각적으로 점검한다.
- 대표본에서는 중심극한정리 덕분에 경미한 정규성 위반에 t-검정이 강건하다.
- 풀링/비풀링, Mann-Whitney(비모수) 모두 같은 결론 → 남성 평균이 여성보다 유의하게 높으며 결과는 가정 위반에 강건하다.
