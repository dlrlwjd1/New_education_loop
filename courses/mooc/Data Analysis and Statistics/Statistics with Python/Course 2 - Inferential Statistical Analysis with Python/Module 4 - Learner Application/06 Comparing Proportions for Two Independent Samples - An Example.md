# Comparing Proportions for Two Independent Samples: An Example

## 개요
- 두 독립집단의 비율(proportion)을 비교하는 NHANES 예제 — 이번에는 **소표본(small samples)** 상황이다.
- 접근: (1) 비율 차이의 신뢰구간, (2) 카이제곱 검정(chi-square test), (3) 가정 점검과 소표본용 정확(exact) 기법.
- 통계적 유의성(statistical significance)과 실질적 유의성(practical significance)의 구분, 통계적 검정력(statistical power) 한계를 다룬다.

## 내용

### 연구 질문과 데이터
- 연구 질문: 2015-2016년 미국에 거주하는 80세 이상 고령 히스패닉 성인(elderly Hispanic adults)에서, 흡연자 비율이 남녀 간에 유의하게 달랐는가?
- 남성: 흡연 비율 0.565 (56.5%), **n = 16** — 표본이 매우 작음
- 여성: 흡연 비율 0.25 (25%), **n = 32**
- 점추정치: 비율 차이 = 0.565 − 0.25 = **0.315**
- 해석 주의: "31.5 **퍼센트포인트(percentage points)** 높다"이지 "31.5% 높다"가 아니다 — 두 표현은 다른 결과를 뜻한다.

### 가정 평가
1. 표본비율 차이의 표집분포가 정규인가? — 표본이 너무 작아 중심극한정리에 기댈 수 없으므로 **성립하기 어려움**.
2. 각 그룹에 결과(흡연/비흡연)가 최소 10건씩 있는가? — **아니오** (특히 남성 표본이 문제).
3. 두 표본이 독립인가? — **예** (상호배타적 하위집단인 남/여).
4. 각 하위집단 내 관측치가 독립인가? — 일단 가정 (복잡 표본설계 특성은 이번 주 후반에 다룸).

### 접근 1 — 비율 차이에 대한 95% 신뢰구간
- 표준오차: 각 그룹에서 p(1−p)/n을 계산해 더한 뒤 제곱근 → SE = **0.146**
- 95% CI = 0.315 ± 1.96 × 0.146 = **(0.027, 0.598)** (표집분포 정규성 가정)
- 0을 포함하지 않으므로 유의한 차이로 보이지만, 하한 0.027이 0에 근접 → 증거가 아주 강하지는 않다.
- **정확 95% 신뢰구간(exact confidence interval)**: 가정에 크게 의존하지 않는 소표본 기법. 계산이 훨씬 오래 걸린다(Python 코드 제공).
  - 결과: **(0.015, 0.574)** — 유사한 결과. 여전히 0은 그럴듯하지 않으나 하한이 0에 가까워 증거는 압도적이지 않다.

### 접근 2 — 카이제곱 검정 (chi-square test)
- 귀무가설: 두 모비율이 같다 / 대립가설: 다르다 (양측검정, 유의수준 5%)
- 카이제곱 검정의 가정: 귀무가설 하에서 2×2 테이블(남/여 × 흡연/비흡연) 각 셀의 기대빈도(expected counts)가 5 이상.
  - 전체 흡연율 17/48을 적용하면 남성 16명 중 약 6명, 여성 32명 중 약 11명이 흡연자로 기대됨 → 네 셀 모두 5 초과, 가정은 (아슬아슬하게) 충족.
- 결과: 카이제곱 통계량 = **4.554**, 자유도 = (행−1)×(열−1) = **1**, p-값 ≈ **0.033**
- 5% 유의수준에서는 기각 → 흡연 비율이 다르다는 결론 지지. 그러나 유의수준을 1%(0.01)로 잡았다면 기각 실패 → 압도적 증거는 아니다.

### 강건성 확인 — Fisher's Exact Test
- 소표본에서 비율을 비교하는 또 다른 정확 검정.
- 결과: p-값 = **0.054** → 0.05 컷오프를 살짝 넘음. 귀무가설에 반하는 강한 증거를 제공하지 못한다.

### 결론 — 통계적 유의성 vs 실질적 유의성
- 종합: 이 모집단에서 남녀 흡연 비율 차이에 대한 **약한 증거(weak evidence)**. 표본이 매우 작아 차이를 탐지할 통계적 검정력(statistical power)이 제한적이었다는 caveat을 달아야 한다.
- 31.5 퍼센트포인트는 실질적으로 매우 큰 효과 크기(effect size)다. 같은 차이가 더 큰 표본에서 나타났다면 유의수준이 0.01이든 0.05든 거의 확실히 유의했을 것이다.
- 소표본에서는 더 큰 불확실성(표집 변동성)을 허용해야 하며, 그래서 정확 검정 같은 강건한 기법을 사용했다.

## 예시
강의 수치 정리:

```text
남성: p̂ = 0.565, n = 16   /   여성: p̂ = 0.25, n = 32
차이 추정치 = 0.315 (31.5 퍼센트포인트)

SE = √( 0.565(1−0.565)/16 + 0.25(1−0.25)/32 ) = 0.146
95% CI (정규 가정) = 0.315 ± 1.96 × 0.146 = (0.027, 0.598)
95% CI (exact)     = (0.015, 0.574)

카이제곱 검정: χ² = 4.554, df = 1, p ≈ 0.033 → 5% 수준에서 기각
Fisher's Exact Test: p = 0.054 → 강한 증거 아님
```

## 요약
- 두 독립집단 비율 비교: 차이의 신뢰구간 + 카이제곱 검정, 소표본에서는 exact 기법으로 강건성 확인.
- 비율 차이는 "퍼센트포인트"로 해석해야 하며 "%"와 혼동하면 안 된다.
- 소표본(n=16, n=32)이라 정규성 가정이 흔들리고 검정력이 낮음 → 결과적으로 약한 증거 (χ² p ≈ 0.033 vs Fisher p = 0.054).
- 31.5 퍼센트포인트는 실질적으로 큰 효과 크기 — 통계적 유의성과 실질적 유의성을 함께 따져야 한다.
