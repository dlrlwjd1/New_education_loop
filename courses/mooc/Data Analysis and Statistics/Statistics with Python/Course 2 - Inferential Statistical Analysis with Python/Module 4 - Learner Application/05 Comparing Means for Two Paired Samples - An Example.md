# Comparing Means for Two Paired Samples: An Example

## 개요
- 서로 상관된(correlated) 짝지어진 표본(paired samples)에서 두 평균을 비교하는 NHANES 예제를 다룬다.
- NHANES는 측정 신뢰성(reliability) 확인을 위해 응답자마다 혈압을 두 번 측정하는데, 두 측정치가 체계적으로 다른지 검토한다.
- 접근: (1) 평균 차이(mean difference)에 대한 신뢰구간, (2) 대응표본 t-검정(paired samples t-test), (3) 가정 점검(Wilcoxon signed rank test 포함).

## 내용

### 연구 질문과 데이터
- 연구 질문: 2015-2016년 미국에 거주하는 히스패닉 성인 여성에서, 두 번의 수축기 혈압 측정치(SBP1, SBP2)가 서로 유의하게 달랐는가?
- 기대: 신뢰할 만한 측정이라면 두 측정치가 체계적으로 다르지 않아야 한다.
- 각 여성에 대해 차이 = SBP2 − SBP1을 계산:
  - 차이의 평균 = **−0.977 mmHg**, 차이의 표준편차 = **4.848**, n = **911**
- 해석: 첫 번째 측정치가 평균적으로 약 1 mmHg 더 컸다는 뜻 — 매우 비슷해야 할 측정치치고는 꽤 큰 차이.

### 가정 점검
- **차이의 히스토그램**: 대략 0 근처지만 중심이 0보다 약간 왼쪽으로 치우침.
- **정규 Q-Q 플롯**: 정규분포라면 45도 직선 위에 점들이 놓여야 하는데 약간 벗어남 → 정규성에 대한 가벼운 우려. 다만 n = 911로 크므로 중심극한정리에 기대어 정규성 가정이 결정적이지는 않다. 그래도 민감도(sensitivity)를 확인한다.
- **산점도(scatter plot)** (SBP2 vs SBP1): 두 측정치 간 강한 상관의 명확한 증거. Pearson 상관계수 = **0.966** → 데이터가 실제로 짝지어져 있음이 확인되어 대응표본 절차 사용이 정당화된다.

### 접근 1 — 평균 차이에 대한 95% 신뢰구간
- 표준오차 = 차이의 표준편차 ÷ √n = 4.848 / √911 = **0.161 mmHg** (크기 911의 표본을 반복 추출했을 때 평균 차이 추정치들의 표집분포 표준편차)
- 평균 차이(−0.977)가 표준오차 대비 상당히 크다 → 표집 변동성을 감안해도 큰 차이라는 신호.
- 95% CI = −0.977 ± 1.96 × 0.161 = **(−1.292, −0.662)**
- 구간이 0을 포함하지 않음 → 첫 번째 측정치가 두 번째보다 유의하게 큰 경향이 있다는 증거. 왜 그런지는 NHANES 데이터 수집 절차(첫 측정이 더 크게 나오는 이유)를 추가로 조사해야 할 문제다.

### 접근 2 — 대응표본 t-검정
- 귀무가설: 모집단 평균 차이 = 0 (두 측정치가 평균적으로 동일)
- 대립가설: 평균 차이 ≠ 0 (첫 측정이 크거나 작을 수 있음 → 양측검정)
- 유의수준 5% (95% 신뢰구간과 일관되게)
- 가정: ① 차이들의 표본이 단순 무작위 표본, ② 차이가 정규분포(대표본이라 덜 결정적), ③ 짝 측정치의 상관(산점도로 확인됨)
- 결과: t = **−6.082**, 자유도 = 911 − 1 = **910**, p-값 < 0.001 → 귀무가설 기각. 평균 차이는 0이 아니다.

### 정규성이 의심될 때 — Wilcoxon signed rank test
- 대응표본 t-검정의 비모수(non-parametric) 대응 검정. 차이의 분포에 정규성 같은 모수적(parametric) 가정을 하지 않고, 중위수(median)로 차이 분포의 위치를 검토한다.
- 결과: p-값 < 0.001 → 두 측정치의 중위수가 같다는 귀무가설 기각.
- 결론은 정규성 위반 가능성에 강건(robust)하다.

### 종합 결론과 다음 내용
- 어떤 가정·접근을 쓰든 두 수축기 혈압 측정치가 이 모집단에서 유의하게 다르다는 일관된 증거 → 두 측정이 신뢰성 있게 일치한다고 보기 어렵다.
- 다음 강의: 독립표본에서 두 **비율(proportion)** 비교.

## 예시
강의 수치 정리:

```text
차이 = SBP2 − SBP1 (여성 히스패닉 성인, n = 911)
차이 평균 = −0.977 mmHg, 차이 SD = 4.848
SE = 4.848 / √911 = 0.161
95% CI = −0.977 ± 1.96 × 0.161 = (−1.292, −0.662)  → 0 미포함

대응표본 t-검정: t = −6.082, df = 910, p < 0.001 → 기각
Wilcoxon signed rank: p < 0.001 → 기각
Pearson 상관(SBP1, SBP2) = 0.966
```

## 요약
- 짝지어진 데이터는 개체별 차이를 만들어 단일 변수처럼 분석한다: 차이의 평균에 대한 신뢰구간 + 대응표본 t-검정.
- 산점도와 상관계수(0.966)로 데이터가 실제로 짝지어져 있는지 먼저 확인한다.
- 신뢰구간 (−1.292, −0.662)이 0을 포함하지 않고, t-검정과 Wilcoxon 검정 모두 p < 0.001 → 첫 측정치가 유의하게 더 크다.
- 결론은 정규성 가정 위반에 강건하며, 차이의 원인은 데이터 수집 절차에서 추가로 규명할 문제다.
