# Descriptive Inference Examples for Single Variables Using Confidence Intervals

## 개요
- 단일 변수의 기술적 파라미터(모비율, 모평균)에 대해 신뢰구간(confidence interval)으로 추론하는 두 가지 NHANES 예제를 다룬다.
- 공통 절차: (1) 점추정치 계산 → (2) 추정 표준오차(standard error) 계산 → (3) 점추정치 ± 승수 × 표준오차로 구간 형성.
- 신뢰구간은 "추정치"가 아니라 **모집단 파라미터(population parameter)** 에 대한 구간이라는 점을 강조한다.

## 내용

### 예제 1 — 모비율(proportion)에 대한 95% 신뢰구간
- 연구 질문: 2015-2016년 미국의 18세 이상 비히스패닉계 아프리카계 미국인(non-Hispanic African-Americans) 중 수축기 혈압(systolic blood pressure)이 130 mmHg를 초과하는(고혈압을 시사) 비율은 얼마인가?
- 추론 접근: 모비율에 대한 95% 신뢰구간(하한·상한) 추정.
- **주의**: 신뢰구간은 추정치(estimate)에 대한 것이 아니라 모집단 수량(population quantity), 즉 파라미터에 대한 것이다.

**Step 1 — 모비율 점추정**
- 첫 번째 수축기 혈압 측정치에 결측이 없는 흑인 응답자 수: 1,135명 (표본 크기)
- 그중 수축기 혈압 130 mmHg 이상인 사람: 465명
- 표본비율 = 465 / 1,135 = **0.4097** → 해당 모집단의 40.97%가 이 범주에 속한다고 추정

**Step 2 — 표준오차 추정**
- 표준오차 = 표집분산(sampling variance)의 제곱근 = 표집분포(sampling distribution)의 표준편차
- 같은 크기(1,135)의 표본을 반복 추출해 비율을 계산했을 때 그 추정치들이 얼마나 변동하는가를 나타낸다.
- 계산 결과: **0.0146**
- 핵심: 표본 하나만으로도 표집분포의 표준편차를 추정할 수 있다.

**Step 3 — 신뢰구간 형성**
- 오차한계(margin of error) = 승수 × 표준오차. 표본이 크므로 95% 신뢰구간에는 승수 1.96 사용 (2로 반올림하기도 함)
- 하한 = 0.4097 − 1.96 × 0.0146 = **0.3811**
- 상한 = 0.4097 + 1.96 × 0.0146 = **0.4383**
- 95% 신뢰구간: **(0.3811, 0.4383)**

**해석과 추론**
- 정확한 의미: NHANES가 단순 무작위 표본이라고 가정할 때, 이런 방식(점추정치 ± 오차한계)으로 형성된 구간들의 95%가 참 모비율을 덮을(cover) 것으로 기대된다.
- 가설값이 0.35였다면(예: 연구 후원자의 추측), 0.35는 구간 밖에 있으므로 그럴듯한 값(plausible value)이 아니다. 실제 비율은 0.35보다 높다는 증거가 있다.

### 예제 2 — 모평균(mean)에 대한 95% 신뢰구간
- 연구 질문: 같은 목표 모집단의 평균 수축기 혈압은 얼마였는가?

**Step 1 — 모평균 점추정**
- 표본 크기는 동일하게 1,135명, 표본평균 = **128.252 mmHg**

**Step 2 — 표준오차 추정**
- 1,135개 혈압 측정값의 표본 표준편차(sample standard deviation) = 19.958 — 이는 **값들 자체**의 표준편차
- 추정 표준오차 = 값의 표준편차 ÷ √표본크기 = 19.958 / √1135 = **0.592 mmHg** — 이는 **표집분포**의 표준편차 추정치 (둘을 혼동하지 말 것)

**Step 3 — 신뢰구간 형성**
- 하한 = 128.252 − 1.96 × 0.592 = **127.091**
- 상한 = 128.252 + 1.96 × 0.592 = **129.413**
- 95% 신뢰구간: **(127.091, 129.413)**

**해석과 추론**
- 가설 평균이 128 mmHg였다면, 128은 구간 안에 있으므로 표집 변동성을 감안할 때 그럴듯한 값이다 (비율 예제와 대조적).

### 신뢰구간 접근의 장점
- 다음 강의에서 다룰 가설검정(hypothesis testing)은 특정 값에 대해 기각/기각 실패만 판단하지만(5% 유의수준은 95% 구간에 대응), 신뢰구간은 일정 신뢰수준 하에서 **그럴듯한 값들의 범위**를 제공한다.

## 예시
비율 신뢰구간 계산 (강의 수치):

```text
p̂ = 465 / 1135 = 0.4097
SE = 0.0146
95% CI = 0.4097 ± 1.96 × 0.0146 = (0.3811, 0.4383)
```

평균 신뢰구간 계산 (강의 수치):

```text
x̄ = 128.252,  s = 19.958,  n = 1135
SE = 19.958 / √1135 = 0.592
95% CI = 128.252 ± 1.96 × 0.592 = (127.091, 129.413)
```

## 요약
- 신뢰구간 3단계: 점추정 → 표준오차 추정 → 점추정치 ± 1.96 × 표준오차 (95% 기준, 대표본).
- 신뢰구간은 모집단 파라미터에 대한 구간이며, "이 방식으로 만든 구간의 95%가 참값을 덮는다"로 해석한다.
- 가설값이 구간 밖이면 그럴듯하지 않은 값(비율 예제의 0.35), 구간 안이면 그럴듯한 값(평균 예제의 128).
- 값들의 표준편차(19.958)와 추정치의 표준오차(0.592)를 구분해야 한다.
