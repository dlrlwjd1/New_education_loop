# Estimating a Mean Difference for Paired Data

## 개요
- 짝지은 데이터(paired data)에서 평균 차이(mean difference, μd)의 신뢰구간 추정
- 짝지은 데이터는 두 측정값을 따로 볼 수 없고, 쌍 내부의 차이(difference within pairs)라는 새 변수를 만들어 1표본 평균 절차를 적용한다
- 쌍둥이(twins)의 자기보고 교육 수준 차이를 예시로 95% 신뢰구간 계산

## 내용

### 짝지은 데이터란
- 예시 데이터: 오하이오주 Twinsburg에서 1976년부터 매년 열리는 Twin Days 축제에서 수집한 쌍둥이 교육 수준 데이터.
- 손위 쌍둥이(older twin)와 손아래 쌍둥이(younger twin)의 교육 수준은 같은 쌍둥이 세트에서 나온 값이라 독립적으로 볼 수 없고 동시에(simultaneously) 다뤄야 한다 — 이것이 짝지은 데이터의 핵심.
- 짝지은 데이터가 생기는 방식:
  1. **같은 개인에게서 두 번 측정**: 주로 쓰는 손/안 쓰는 손으로 이름 쓰기, 피아니스트의 양손 손가락 길이, 치료 전후(pre/post treatment) 측정 등.
  2. **짝지어진(matched) 개체에서 측정**: 쌍둥이처럼 서로 관련된 개인(손자와 할아버지 등), 높이 등 특성으로 짝지은 양초(두 심지 비교), 체중 감량 프로그램에서 나이·성별·몸무게로 짝지은 사람들 등. 개체가 꼭 사람일 필요는 없다.
- 어떤 경우든 **쌍 내부 측정값의 차이**라는 새 변수를 만들어 두 측정값을 직접 비교한다.

### 연구 질문과 모수
- 연구 질문: "손위 쌍둥이와 손아래 쌍둥이의 자기보고(self-reported) 교육 수준의 평균 차이는 얼마인가?"
- 모집단: 모든 일란성 쌍둥이(identical twins).
- 모수: 자기보고 교육 수준의 모평균 차이 **μd** — 차이 변수임을 나타내는 아래첨자 d를 사용.
- 차이 계산 방향을 반드시 명시: 여기서는 **손위 쌍둥이 − 손아래 쌍둥이**.
- 목표: 이 평균 차이에 대한 95% 신뢰구간.

### 데이터 살펴보기
- 예: 둘 다 16년이면 차이 0, 손위가 18년·손아래가 16년이면 차이 +2, 차이가 −2이면 손아래 쪽 교육이 2년 더 많음을 의미.
- 관측치 340쌍. 차이 분포는 0에 큰 봉우리 — 예상대로 약 3/4의 쌍둥이가 같은 교육 수준.
- 차이 범위: −3.5년(손아래가 3.5년 더 많음) ~ +4년(손위가 4년 더 많음).
- 차이의 평균 = 0.08년, 표준편차 = 0.76년.

### 신뢰구간 계산
- 기본 형태: 최선의 추정치 ± 오차한계 = 표본평균 차이 ± "몇 개"의 추정 표준오차.
- 공식은 1표본 평균(single mean) 신뢰구간과 같은 형태이며, 표본평균과 표본표준편차에 아래첨자 d가 붙는 것만 다르다: x-bar_d ± t* × s_d/sqrt(n)
- 표준오차를 추정하므로 t-분포(t-distribution)의 t*를 사용 — 꼬리가 약간 더 두꺼워 구간이 조금 더 보수적이 된다.
- n = 340일 때 소프트웨어로 구한 t* = 1.967.
- 계산 결과: **95% 신뢰구간 = 0.0025년 ~ 0.1652년**

### 해석과 0의 포함 여부
- 해석: "95% 신뢰수준으로, 손위 쌍둥이에서 손아래 쌍둥이를 뺀 자기보고 교육의 모평균 차이는 0.0025년에서 0.1652년 사이로 추정된다."
- 구간의 양 끝이 모두 양수 → 95% 신뢰수준에서 손위 쌍둥이의 교육이 더 많을 것으로 기대된다(양수 = 손위가 더 많음).
  - 다만 값들이 모두 0에 가까워 증가폭이 크지는 않다.
- 두 교육 수준이 대체로 같다면 평균 차이는 0일 것 → 합리적인 값의 범위에서 0을 찾는다.
  - 이 구간은 전부 양수라 0을 포함하지 않으므로, 쌍둥이 간 교육 수준이 같지 않아 보인다.

### 가정
- 일란성 쌍둥이 세트의 무작위 표본(random sample)이어야 한다.
- 차이의 모집단이 정규(normal)여야 한다 — 히스토그램은 대략 종 모양이었고, n = 340으로 표본이 충분히 커서 정규성 가정의 중요성이 줄어든다(우회 가능).

## 예시
```text
n = 340쌍 (차이 = 손위 − 손아래)
x-bar_d = 0.08년, s_d = 0.76년, t* = 1.967
95% CI = 0.08 ± 1.967 × 0.76/sqrt(340) = (0.0025, 0.1652) 년
→ 0 미포함, 전부 양수 → 손위 쌍둥이의 교육 수준이 약간 더 높음
```

## 요약
- 짝지은 데이터는 1표본 평균 신뢰구간을 확장한 것으로, 원래 변수 대신 차이 변수(difference variable)를 사용한다.
- 짝지음은 주로 (1) 같은 개인의 두 측정, (2) 사전에 짝지어진 유사 개체의 두 측정으로 발생한다.
- 절차 자체는 1표본 평균과 동일: x-bar_d ± t* × s_d/sqrt(n).
- 구간에 0이 없으면 평균 차이가 0이 아니라는(참 차이가 있다는) 것을 시사한다 — 이 예시에서는 0이 없었다.
