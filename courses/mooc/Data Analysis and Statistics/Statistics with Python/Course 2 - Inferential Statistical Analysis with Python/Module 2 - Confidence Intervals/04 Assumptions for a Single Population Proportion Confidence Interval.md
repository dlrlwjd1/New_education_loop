# Assumptions for a Single Population Proportion Confidence Interval

## 개요
- 1표본 모비율(single population proportion) 신뢰구간을 만들기 전에 확인해야 하는 두 가지 가정(assumption)
- 가정 1: 단순 무작위 표본(simple random sample, SRS)
- 가정 2: 충분히 큰 표본 크기 — 각 응답 결과가 최소 10개

## 내용

### 신뢰구간 복습
- 신뢰구간은 모비율에 대한 좋은 추정을 제공한다.
- 구간의 중점(midpoint/center)은 최선의 추정치, 즉 표본비율(sample proportion, 점추정치 point estimate)이다.
- 중점 양쪽에 오차한계(margin of error)를 더하고 뺀다.
- 오차한계는 추정치의 "여유 범위(wiggle room)"로, 표본 추정치들에서 기대되는 변동성(variability)을 반영한다.

### 가정 1: 단순 무작위 표본
- 데이터가 단순 무작위 표본(simple random sample)이어야 한다.
- 단순 무작위 표본이란 관심 모집단(population of interest)을 대표하는 부분집합으로, 각 관측치/대상이 뽑힐 확률이 동일해야 한다.
- 단순 무작위 표본이면 모집단을 신뢰성 있게 대표하므로 구간의 중점이 좋은 값이 된다.

### 가정 2: 충분히 큰 표본 크기
- 표본 크기가 충분히 크면 표본추출분포(sampling distribution)를 정규곡선(normal curve)으로 근사할 수 있다.
- 오차한계 계산에는 표준정규곡선(standard normal curve)에서 가져온 임계 z-값(critical z-value, z 승수 z multiplier)을 사용하기 때문이다.
- "충분히 크다"의 기준은 관점에 따라 다양하지만, n이 커질수록 표본추출분포가 더 종 모양(bell shaped)에 가까워지므로 클수록 좋다.
- 이 과목에서 1표본 비율 신뢰구간의 기준: **각 응답 결과가 최소 10개** — 일반적으로 "예" 최소 10개, "아니오" 최소 10개.

### 가정 확인 방법
- 단순 무작위 표본 확인: 표본이 어떻게 수집되었는지 분석하고 모집단을 대표하는지 확인한다.
  - 이 과목에서는 일반적으로 단순 무작위 표본이라고 가정한다.
  - 실제로는 더 복잡한 표본설계(sampling design)가 있을 수 있으며, 가중치(weighting) 등 다양한 기법으로 반영할 수 있다.
- 표본 크기 확인: 표본 안에 각 응답 결과("예"와 "아니오")가 최소 10개씩 있는지 확인한다.
- 두 가정이 모두 충족되면 신뢰구간을 만들 수 있고, 이 구간이 참 모비율에 대한 좋은 추정을 제공한다.

## 요약
- 1표본 비율 신뢰구간의 두 가정: (1) 단순 무작위 표본, (2) 충분히 큰 표본 크기.
- 큰 표본 크기가 필요한 이유는 표본추출분포를 정규분포로 근사해 z 승수를 쓰기 위해서다.
- "충분히 크다" = 표본 안에 "예" 최소 10개, "아니오" 최소 10개.
- 가정 충족 후 만든 신뢰구간이 참 모비율의 좋은 추정이 된다.
