# Conservative Approach & Sample Size Consideration

## 개요
- 보수적 접근(conservative approach): p-hat = 0.5를 대입해 표준오차(standard error)를 최대화하여 더 안전하게(더 넓은 오차한계로) 구간을 만드는 방법
- 보수적 오차한계는 표본 크기에만 의존하므로, 원하는 오차한계(margin of error)로부터 필요한 표본 크기를 역산할 수 있다.
- Mott 카시트 예시로 보수적 95% 신뢰구간과 표본 크기 계산을 시연

## 내용

### 보수적 표준오차의 도출
- 기본 구조 복습: 신뢰구간 = 최선의 추정치 ± 오차한계, 오차한계 = "몇 개"의 추정 표준오차.
- 1표본 비율 95% 수준: p-hat ± 1.96 × sqrt( p-hat × (1 − p-hat) / n )
- 문제 제기: 추정 표준오차는 p-hat에 의존하는데, 무작위 표본이 충분히 좋지 않았다면 p-hat이 부정확할 수 있다.
- 해결: 표준오차를 **최대화**하도록 p-hat = 0.5를 대입한다.
  - sqrt( 0.5 × 0.5 / n ) = 0.5 / sqrt(n) = 1 / (2 × sqrt(n))
  - 이것이 보수적 표준오차(conservative standard error): 1/2 × 1/sqrt(n)

### 보수적 95% 신뢰구간
- 95% 수준에서 승수로 2를 쓰면 2 × (1/2) × 1/sqrt(n)에서 2가 약분되어:
  - **보수적 95% 신뢰구간 = p-hat ± 1/sqrt(n)**
- 오차한계가 표본 크기에만 의존하게 된다 — 표본 크기만 바꾸면 구간의 폭을 조절할 수 있는 매우 편리한 성질.
- Mott 카시트 예시 (p-hat = 0.85, n = 659):
  - 통상적 방법의 구간: 0.823 ~ 0.877
  - 보수적 방법: 오차한계 약 4%, 구간 0.81 ~ 0.89
  - 오차한계를 최대화했으므로 이전보다 넓은 구간이 나오는 것이 당연하다.

### 오차한계와 표본 크기의 관계 (95% 수준)
- 오차한계는 두 가지에만 의존한다: 신뢰수준(승수 결정)과 표본 크기.
- 질문: 95% 보수적 신뢰구간에서 오차한계를 3%로 만들려면 표본이 얼마나 필요한가?
- 95% 수준의 보수적 오차한계 = 1/sqrt(n)이므로 n에 대해 풀면:
  - **n = (1 / MoE)²**
  - n = (1 / 0.03)² = 1,111.11
- 사람 수는 분수가 될 수 없고 오차한계를 "최대 3%"로 보장해야 하므로 **항상 올림(round up)** 한다: n ≥ 1,112

### 일반 신뢰수준에서의 표본 크기 공식
- 99% 신뢰수준에서 오차한계 3%를 원한다면?
- 오차한계 = z* × 1/2 × 1/sqrt(n)을 n에 대해 풀면:
  - **n = ( z* / (2 × MoE) )²**
- 99% 수준의 z* = 2.576 (표 또는 검색으로 확인), MoE = 0.03:
  - n = ( 2.576 / (2 × 0.03) )² = 1,843.27 → 올림하여 n ≥ 1,844

## 예시
```text
보수적 95% CI: p-hat ± 1/sqrt(n)
  카시트: 0.85 ± 1/sqrt(659) → 오차한계 약 4% → (0.81, 0.89)

표본 크기 (95%, MoE 3%): n = (1/0.03)² = 1111.11 → n ≥ 1112
표본 크기 (99%, MoE 3%): n = (2.576 / (2×0.03))² = 1843.27 → n ≥ 1844
```

## 요약
- 표본에 따라 추정 표준오차가 너무 작거나 부정확할 수 있으므로, p-hat = 0.5를 대입해 표준오차를 최대화하는 보수적 접근을 쓴다.
- 보수적 95% 신뢰구간은 p-hat ± 1/sqrt(n)으로 단순화되어 오차한계가 표본 크기에만 의존한다.
- 신뢰수준(z* 승수)과 원하는 오차한계를 정하면 필요한 표본 크기를 n = (z* / (2 × MoE))²로 계산할 수 있다.
- 계산된 표본 크기는 항상 올림한다. 임상시험(clinical trial)에서는 오차한계 3%가 흔히 쓰인다.
