# Optional: Introduction to Jupyter Notebooks

## 개요
- Jupyter Notebook은 이 코스에서 Python 코드를 작성하는 주요 도구다
- 웹 기반 대화형 개발 환경(interactive development environment)으로 텍스트와 코드를 한 문서에 담아 재현 가능한 분석(reproducible analysis)을 만들 수 있다
- 파일 브라우저, 마크다운(Markdown), 커널(kernel)과 변수 환경, 명령/편집 모드(command/edit mode)와 단축키, 설치 방법을 다룬다

## 내용
### Jupyter Notebook이란
Jupyter는 여러 프로그래밍 언어를 지원하는 웹 기반 대화형 개발 환경이며, Python과 함께 가장 흔히 사용된다. 학생·과학자·연구자가 하나의 문서 안에서 재현 가능한 분석을 만들고 이야기를 구성할 수 있게 해 준다. 예시로 미시간의 Richard Styron이 작성한 완성된 노트북을 보여 주는데, 텍스트뿐 아니라 Python 코드를 문서에 직접 임베드해 하나의 연구 논문을 만들었다 — 이것이 Jupyter Notebook의 특별한 점이다.

### 파일 브라우저
메뉴 바의 File → Open으로 파일 디렉터리에 들어갈 수 있다. 자신의 PC에서 업로드하거나 새 텍스트 파일, 폴더, 터미널, 특정 언어의 노트북을 만들 수 있다.

### 마크다운(Markdown) 셀과 문법
마크다운은 일반 텍스트 형식 문법을 쓰는 마크업 언어(markup language)로, 키보드의 여러 기호를 지시자로 사용해 텍스트를 꾸민다.

- **헤더**: 해시(`#`)를 사용하며 개수로 크기를 지정한다.
- **텍스트 강조**: 별표(`*`)나 밑줄(`_`)의 개수에 따라 이탤릭/볼드가 되고, 조합해 볼드 이탤릭도 만들 수 있다. 물결표(`~`)로 취소선을 긋는다.
- **목록**: 숫자로 순서 있는 목록, 하위 목록, 별표·마이너스·플러스로 순서 없는 목록을 만든다.
- **링크**: URL에 캡션을 붙여 링크할 수 있다(예: University of Michigan 웹사이트).
- 그 외 표, 이미지 임베드 등이 가능하며, 온라인에 마크다운 문법 레퍼런스가 많다.

### 커널(kernel), 변수, 환경
- **노트북 커널**은 노트북 문서에 담긴 코드를 실행하는 계산 엔진(computational engine)이다. 여러 언어의 커널이 있지만 이 코스에서는 Python 커널만 사용한다. 노트북을 열면 연결된 커널이 자동으로 실행되고, 우측 상단에서 현재 커널(Python 3)을 확인할 수 있다. 메뉴 바의 Kernel → Change kernel로 바꿀 수도 있다.
- **코드 셀 실행**: 상단 바의 Run을 눌러 Python 셀을 실행하고 출력을 확인한다.
- **변수와 환경**: 커널은 코드 실행뿐 아니라 초기화된 변수를 환경(environment)에 저장한다. 예컨대 변수 X에 1738을 넣고 출력할 수 있다. **커널을 재시작하면 모든 변수가 사라지므로** 커널 문제가 생기면 변수를 다시 초기화해야 한다 — 재시작 후 X를 출력하면 "not defined" 에러가 나고, X를 다시 초기화하면 정상 실행된다.
- **사용자 입력**: `input`으로 사용자 입력을 문서에 임베드할 수 있다.
- **인라인 셀 실행(inline cell execution)**: 앞 셀의 작업이 끝나야 다음 셀이 실행된다. 입력을 기다리는 셀이 있는 상태에서 아래 셀을 실행하면 별표(`*`)가 표시되어 앞 셀이 아직 완료되지 않았음을 나타내고, 입력을 마치면 별표가 숫자로 바뀌며 셀들이 실행된다.

### 명령 모드 vs. 편집 모드, 단축키
- 모드는 셀 왼쪽 테두리 색으로 구분한다: **초록 = 편집 모드(edit mode)** — 텍스트를 추가·삭제할 수 있다. **파랑 = 명령 모드(command mode)** — 설정을 조작할 수 있다.
- 예: 명령 모드에서 셀 줄 번호 토글이 가능하며, 단축키 `L`을 누르면 줄 번호가 토글된다.
- 메뉴 바(File, Edit, View, Insert)까지 가지 않아도 명령 모드에서 키 조합으로 많은 작업을 할 수 있는 단축키가 많다. 생산성을 높여 주므로 참고 자료를 확인하기를 권한다.

### 설치와 코스에서의 사용
- MOOC가 코스 안에 임베디드 Jupyter Notebook을 제공하므로 다운로드는 필수가 아니다. 직접 탐구하고 싶다면 공식 설치 가이드를 확인하라 — Windows, macOS, Linux와 호환되는 **Anaconda** 플랫폼 사용을 권장한다(강사도 개인 컴퓨터에서 사용).
- 코스에서 노트북을 여는 방법: 1주차 과제(assignments)로 스크롤해 노트북을 클릭하면 애플리케이션이 로드되며 열린다.

## 예시
강의에서 시연한 코드 흐름을 실행 가능한 형태로 옮기면 다음과 같다.

```python
# 변수 초기화와 출력 — 변수는 커널 환경에 저장된다
x = 1738
print(x)

# 커널을 재시작하면 x는 사라진다 (NameError: name 'x' is not defined)
# 다시 초기화하면 정상 동작한다
x = 1738
print(x)

# 사용자 입력 임베드
name = input("What is your name? ")
print("The name you've entered is " + name)
```

## 요약
- Jupyter Notebook은 텍스트(마크다운)와 실행 가능한 Python 코드를 한 문서에 담는 웹 기반 대화형 환경이다
- 커널은 코드를 실행하고 변수를 환경에 저장하는 엔진이며, 재시작하면 변수가 모두 사라진다
- 셀은 순차 실행되며(인라인 실행), 별표는 앞 셀이 아직 완료되지 않았음을 뜻한다
- 편집 모드(초록)와 명령 모드(파랑)를 구분하고, 명령 모드 단축키(예: L = 줄 번호 토글)로 작업 효율을 높일 수 있다
- MOOC에 노트북이 임베드되어 있어 설치는 선택이며, 로컬 설치 시 Anaconda를 권장한다
