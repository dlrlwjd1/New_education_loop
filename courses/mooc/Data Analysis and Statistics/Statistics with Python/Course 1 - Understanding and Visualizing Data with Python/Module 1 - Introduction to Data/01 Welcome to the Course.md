# Welcome to the Course!

## 개요
- Statistics with Python 전문과정(specialization)의 첫 번째 코스 소개 강의
- 코스는 네 파트로 구성되며, 통계 개념 학습과 Python 실습을 병행한다
- 각 코스는 이전 코스 위에 쌓아 올리는 구조로 통계 전반을 다룬다

## 내용
### 전문과정과 코스의 위치
이 코스는 더 큰 Statistics with Python 전문과정의 첫 번째 코스다. 각 코스는 이전 코스를 기반으로 확장되며, 통계가 무엇인지에 대한 균형 잡힌 시각과 배운 내용을 Python으로 연습할 능력을 함께 기른다.

### 코스의 네 파트 구성
- **파트 1**: 통계(statistics)란 무엇인가, 데이터(data)란 무엇인가를 살펴본다. 통계를 다양한 관점이 공존하는 "큰 천막(big tent)" 학문으로 바라보며, 실제 삶에서 통계를 어떻게 활용하는지 동료 교수진의 인터뷰를 듣는다. 데이터가 어디에나 있다는 점과 오늘날 데이터로 할 수 있는 흥미로운 일들을 다룬다. 프로그래밍 측면에서는 Jupyter Notebook 소개와 Python 기초를 배운다.
- **파트 2~3**: 데이터를 그래프와 수치로 요약(summarizing graphically and numerically)하는 방법을 배운다. 단변량(univariate)에서 다변량(multivariate) 요약 방법으로 나아간다. 다양한 데이터셋을 다루는데, 그중 하나는 팀원과 동료들이 실제로 수행한 카트휠(cartwheel) 데이터다. 또한 피자 연구(pizza study) 결과를 글로 정리해 공유하는 글쓰기·커뮤니케이션 과제도 있다.
- **파트 4**: 확률 표본추출(probability sampling)과, 표본(sample) 데이터만으로 더 큰 모집단(population)에 대해 추론(inference)하는 방법을 살펴본다.

### 학습 지원 요소
코스 전반에 걸쳐 학습 점검 기회(assessment), 특정 주제를 더 깊이 파고들 수 있는 자료, 웹 애플릿(web applet)과 Python 튜토리얼 같은 실습 경험이 제공된다. 여러 팀 구성원이 번갈아 강의를 진행한다.
