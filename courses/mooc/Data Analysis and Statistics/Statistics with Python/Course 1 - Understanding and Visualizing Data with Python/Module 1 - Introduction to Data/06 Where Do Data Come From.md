# Where Do Data Come From?

## 개요
- 데이터 분석에 들어가기 전에 데이터가 어떤 과정에서 생성됐는지 이해하는 것이 중요하다
- 데이터의 두 가지 핵심 유형: 유기적/과정 데이터(organic/process data)와 설계된 데이터 수집(designed data collection)
- 데이터가 i.i.d(independent and identically distributed, 독립·동일분포)인지가 어떤 분석 절차를 쓸지 결정하는 핵심 질문이다

## 내용
### 유기적/과정 데이터 (organic or process data)
컴퓨터화된 정보 시스템이 생성하거나 영상·음성 기록에서 추출되는 데이터로, 어떤 과정(process)의 결과로 유기적으로, 흔히 시간에 걸쳐 생성된다는 공통점이 있다.

- **금융·판매 시점(point of sale) 거래, 주식시장 거래**: 시간에 따라 수많은 이벤트가 발생하고 모두 기록되어 매우 큰 데이터셋이 된다.
- **Netflix 시청 이력**: 구독자가 무엇을 볼지 예측하는 대회가 열리기도 했다. 개인의 시청 이력에서 자연스럽게 발생하는 매우 큰 데이터다.
- **웹 브라우저 활동**: 어떤 페이지를 방문하는지, 페이지마다 얼마나 머무는지, 얼마나 자주 방문하는지 — 웹을 이용하는 모든 사람에 걸쳐 곱하면 엄청난 규모의 이벤트·거래 데이터가 된다.
- **스포츠 경기**: 프로·세미프로·대학·고교, 심지어 일부 중학교 경기까지 팀과 개인의 경기 결과·성과 지표가 기록된다. 모두 과정의 결과로 유기적으로 발생하는 대규모 데이터다.
- **온도·오염 센서**: 도시의 오염 문제나 기온 변동을 이해하기 위해 여러 위치에 기상 관측소나 모니터를 설치하고 초당 여러 번 측정하면, 시간에 따른 흥미로운 이야기를 담은 유기적 과정 데이터가 된다.

### 빅데이터(Big Data)와 계산 자원
이런 과정들은 막대한 양의 데이터를 생성하며, 요즘 흔히 듣는 "빅데이터"라는 용어가 바로 이런 유기적 과정에서 나오는 데이터셋을 가리킨다. 야구 경기, 특정 맥도날드 매장의 하루 주문, 특정 도시의 하루 기온 변화 등을 모든 영역에 걸쳐 생각하면 데이터셋은 엄청나게 커진다. 이런 데이터의 처리는 상당한 계산 자원(computational resources)을 요구한다. 데이터 과학자는 이 데이터를 마이닝(mining)해 트렌드와 흥미로운 관계를 연구하는데, 데이터를 분석에 적합한 형태로 만드는 과정 자체가 컴퓨터 과학과 통계 방법론 훈련을 받은 많은 인력을 필요로 하며, 더 효율적인 처리 방법은 현재 매우 활발한 연구 분야다.

### 설계된 데이터 수집 (designed data collection)
자연스러운 유기적 과정이 아니라 **특정 연구 목적(research objective)에 답하기 위해 설계된 연구**에서 나오는 데이터다.

- **모집단에서 표본추출 후 인터뷰**: 관심 있는 목표 모집단(target population) 전체를 측정하기 어렵기 때문에 개인의 표본(sample)을 설계해 뽑고, 그들에게 질문해 모집단에 대해 배운다.
- **트위터에서 추출해 코딩한 트윗**: 매일 쏟아지는 전체 트윗이라는 큰 모집단에서 특정 트윗 부분집합을 추출하는 방식을 설계하고, 특정 코딩 설계(coding design)에 따라 연구팀이 코딩해 특정 주제에 대한 의견 표현 빈도를 분석한다.

설계된 데이터의 공통 특징: 모집단으로부터의 표본추출, 큰 모집단에서 뽑은 작은 표본에 신중하게 설계된 설문 문항을 시행. 유기적/과정 데이터보다 일반적으로 훨씬 작아 계산 측면에서 다루기 쉽고, 진행 중인 자연 과정의 반영이 아니라 매우 구체적인 이유로 수집된다. 이 전문과정에서는 두 유형의 데이터를 모두 다룬다.

### 데이터는 i.i.d인가?
데이터 출처와 무관하게 분석 전에 물어야 할 중요한 질문: 데이터를 **i.i.d**로 볼 수 있는가?

- 첫 번째 i = **독립(independent)**: 관심 변수의 각 관측값이 다른 모든 관측값과 완전히 독립이다. 서로 다른 단위(다른 주식 거래, 다른 야구 경기, 설문에 응답하는 다른 개인)에서 수집된 측정값들 사이에 상관(correlation)이 없다.
- i.d = **동일분포(identically distributed)**: 관측되는 모든 값이 하나의 공통된 통계적 분포(common statistical distribution)에서 나온다.

**예시 — 시험 점수와 종 모양 곡선**: 대규모 통계학 입문 수업의 기말시험 점수를 생각하자. 각 학생이 자기 답안을 작성하고 개별적으로 채점되므로 점수들은 독립 관측값이고, 점수 값들은 자연스러운 정규분포(normal distribution), 즉 종 모양 곡선(bell-shaped curve)을 따를 수 있다. 데이터가 i.i.d이면 그 분포의 특징 — 평균(mean) 시험 점수, 분산(variance), 극단 백분위수(extreme percentiles) — 을 추정하고, 더 큰 모집단에 대해 추론(inference)할 수 있으며, 추정치가 갖는 정밀도(precision)도 결정할 수 있다. i.i.d 가정은 특정 통계 절차를 가능하게 하는 중요한 가정이다.

### 데이터가 i.i.d가 아닌 경우
- **부정행위(cheating)**: 서로 옆에 앉은 학생들이 답을 보고 비슷한 답을 쓰면 점수가 다른 학생의 점수에 의존하게 되어 독립성 가정이 깨진다.
- **남녀 평균이 다른 경우**: 남학생과 여학생의 시험 점수 분포가 다르다면 데이터가 동일한 분포에서 나오지 않는다. 하위집단(subgroup)마다 다른 분포를 따를 수 있다.
- **토론 분과(discussion section) 효과**: 같은 분과 출신 학생들이 비슷한 점수를 받을 수 있다 — 어떤 대학원생 강사가 개념을 더 잘 설명한다면 분과 간 변동이 생겨 동일분포가 아니게 된다.

데이터가 i.i.d가 아니면 이런 의존성(dependency)과 차이를 분석에서 반영해야 하며, 다른 분석 절차(analytic procedure)가 필요할 수 있다. 앞으로 다룰 통계 절차들은 데이터가 i.i.d라고 가정하거나 i.i.d가 아니라고 가정하는 것으로 나뉜다.

### 핵심 질문 정리
분석에 앞서 항상 물어야 한다: i.i.d를 가정하는 통계 절차를 이 데이터에 적용할 수 있는가? 데이터가 유기적 과정에서 왔다면 그 과정이 의존성을 만들지 않았는가? 설계된 데이터 수집에서 왔다면 그 설계의 특징을 분석에서 반영해야 하지 않는가? 데이터가 어디서 왔는지 항상 고려해야 한다. 이 코스 후반의 표본추출(sampling) 단원에서 설계된 데이터 수집과 i.i.d 개념을 더 자세히 다룬다.

## 요약
- 데이터의 두 핵심 유형: 유기적/과정 데이터(거래, 시청 이력, 웹 활동, 스포츠, 센서 — 크고 계산 자원이 필요)와 설계된 데이터 수집(특정 연구 목적, 표본추출, 작고 다루기 쉬움)
- "빅데이터"는 유기적 과정에서 나오는 대규모 데이터셋을 가리킨다
- i.i.d = 독립(independent) + 동일분포(identically distributed): 관측값들이 서로 독립이고 공통 분포에서 나온다는 가정
- i.i.d이면 분포의 평균·분산·백분위수를 정밀도와 함께 추정하고 모집단을 추론할 수 있다
- 부정행위(독립성 위반), 성별·분과 간 분포 차이(동일분포 위반) 같은 비-i.i.d 상황에서는 다른 분석 절차가 필요하다
- 어떤 분석 절차를 쓸지 결정하려면 데이터의 출처를 반드시 이해해야 한다
