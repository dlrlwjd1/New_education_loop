# What is Statistics?

## 개요
- 통계학(statistics)은 데이터로부터 배우는 모든 측면을 아우르는 학문이다
- 통계량(a statistic)과 통계학이라는 학문(the field of statistics)의 구분이 중요하다
- 통계학을 바라보는 다양한 관점(요약, 오도 방지, 의사결정, 변동성, 예측, 측정, 원칙 있는 데이터 수집)을 소개한다
- 통계학의 간략한 역사와 인접 분야(컴퓨터 과학, 수학, 데이터 과학)와의 연결을 다룬다

## 내용
### 통계학이란 무엇인가
통계학은 데이터로부터 배우는 것(learning from data)의 모든 측면을 아우르는 학문이다. 방법론(methodology)으로서의 통계학은 데이터를 이해하기 위해 데이터를 다루는 도구와 방법을 말한다. 통계학자는 데이터 분석 방법을 적용·개발하고, 그 방법의 성질 — 언제 통찰을 주고 언제 오도할 수 있는지 — 을 끊임없이 연구한다. 여러 학문 분야의 연구자와 다양한 산업 현장의 종사자들도 통계 방법론을 적용·확장하며 새로운 아이디어와 방법을 기여하고 있다.

### 통계량 vs. 통계학
- **통계량(statistic)**: 데이터 모음의 수치적·그래픽 요약. 예: 기말시험 평균 점수, 특정 지역·기간의 최저 기온, 설문에서 은퇴자의 비율.
- **통계학(the field of statistics)**: 연구 방법론에 초점을 두는 학문 분야. 통계학자는 새로운 통계 도구를 개발하고, 데이터로부터 통계량을 계산하며, 무엇보다 주제 전문가(subject matter expert)와 협업해 결과를 적절하게 해석한다.

통계학은 진화하는 역동적인 분야다. 다양한 통계 방법의 성질은 계속 연구되고 있으며, 새로운 응용 분야가 새로운 분석 방법의 개발을 이끌고, 새로운 센서 등 새로운 측정 방식이 분석이 필요한 새로운 유형의 데이터를 만들어 낸다. 컴퓨팅의 발전은 대용량 데이터에 대한 더 정교한 분석을 가능하게 한다.

### 통계학을 바라보는 여러 관점
통계학은 이론, 실무, 인접 분야의 아이디어를 흡수하는 "큰 천막(big tent)" 학문이다.

- **데이터 요약의 기술(the art of summarizing data)**: 데이터는 압도적일 수 있어 축소·요약이 필요하다. 요약의 주요 목표는 데이터셋을 사람이 이해할 수 있게(comprehensible) 만드는 것이며, 요약 기법은 데이터 소비자의 목표와 맞아야 의미가 있다.
- **데이터는 오도할 수 있다(data can be misleading)**: 통계학 발전의 주요 동기는 데이터 기반 주장(claim)이 의미 있는지 평가할 틀을 갖추는 것이었다. 데이터에서 얻는 통찰은 100% 정확하지 않지만, 보고된 결과가 진실에서 얼마나 떨어져 있을 수 있는지 정량화할 수 있다. 여론조사의 오차범위(margin of error)가 그 예다.
- **의사결정(decision-making)**: 이해에서 그치지 않고 배운 것에 근거해 행동해야 한다. 우리는 불확실성 속에서 비용과 편익을 저울질하며 결정을 내린다. 예: 특정 암 위험이 평균보다 높다고 판정된 사람이 예방적 시술을 받아야 하는가 — 통계는 이런 의사결정을 돕는다.
- **변동성의 이해(understanding variation)**: 요약할 때 흔히 중심값(central value)에 먼저 주목하지만, 통계학은 데이터의 변동(variation) 이해를 매우 중시한다. 예: 미국인의 평균 신용카드 부채가 약 $6,000이라는 것은 중심값 정보이고, 10%가 $30,000 이상이라는 백분위수(percentile) 정보는 변동성에 대한 추가 정보를 준다.
- **예측(forecasting/prediction)**: 미래를 확실히 알 수는 없지만 가용 데이터를 효율적으로 쓰면 꽤 정확한 예측이 가능하다. 예: 날씨 예보, 지진 위험 시점, 신제품 수요 추정, 선거 결과 예측, 환자의 치료 반응 예측.
- **측정(measurement)**: 나이·키처럼 높은 정확도로 측정되는 변수도 있고, 혈압처럼 분 단위로 변해 측정이 까다로운 변수도 있다. 기분(mood), 성격(personality), 정치 이념(political ideology) 같은 구성개념(construct)은 정의하고 정량화하기 훨씬 어렵다. 통계학은 이런 개념을 측정하는 엄밀한 접근법을 만들고 그 품질을 평가하는 데 중요한 역할을 한다.
- **원칙 있는 데이터 수집(principled data collection)**: 데이터 수집은 비싸고 어려울 수 있다(예: 측정을 위해 제품을 파괴해야 하는 경우). 자원 제약은 수집 가능한 데이터 양을 제한하지만, 데이터가 너무 적으면 결과의 질이 떨어진다. 통계학은 "더 많은 데이터"와 "자원 제약" 사이의 트레이드오프를 합리적으로 관리하는 방법을 제공한다.

### 통계학의 역사적 이정표
- 고대 문명부터 수확량, 홍수, 인구 규모 등의 데이터를 수집해 왔다.
- 1700년대: 확률론(probability theory)이 발전하며 무작위성(randomness)과 변동을 수학적으로 정의할 수 있게 됐다.
- 19세기: 유전학(genetics), 계량경제학(econometrics)의 질문들을 다루며 현대 통계학이 등장했다.
- 20세기: 과학·산업의 새로운 응용 분야와 함께 통계 이론이 발전했고, 컴퓨터로 데이터 분석이 가능해졌다.
- 현재: 빅데이터(Big Data), 데이터 과학(data science), 머신러닝(machine learning)의 시대.

### 인접 분야와의 연결
- **컴퓨터 과학(computer science)**: 데이터를 다루는 알고리즘·자료구조와 데이터를 조작하는 프로그래밍 언어를 제공한다.
- **수학(mathematics)**: 통계 개념을 간결하게 표현하는 언어와 표기법, 통계 방법의 성질을 평가·이해하는 도구를 제공한다. 수학의 한 분야인 확률론은 무작위성과 불확실성(uncertainty)을 표현하게 해 주는 통계학 기초의 핵심이다.
- **데이터 과학(data science)**: 데이터베이스 관리, 머신러닝 등 데이터 분석을 수행하기 위한 인프라를 제공한다.

통계학은 작지만 중요한 분야에서 이제 연구와 산업의 핵심 축(linchpin)으로 성장했다. 새로운 응용 분야로 컴퓨터 비전, 자율주행, 얼굴 인식, 추천 시스템(recommender system), 보건 분야의 예측 분석과 정밀의료(precision medicine), 사기 탐지(fraud detection), 환경·인프라 리스크 평가, 직업 훈련·행동 치료 등 사회·정부 서비스가 있다.

## 요약
- 통계학은 데이터로부터 배우는 모든 측면을 아우르는 학문이며, 통계량(수치·그래픽 요약)과는 구분된다
- 통계학의 관점: 데이터 요약, 오도 가능성 평가(오차범위), 의사결정 지원, 변동성 이해, 예측, 어려운 개념의 측정, 원칙 있는 데이터 수집
- 역사: 고대의 데이터 수집 → 1700년대 확률론 → 19세기 현대 통계학 → 20세기 이론 발전 → 빅데이터·데이터 과학 시대
- 컴퓨터 과학, 수학(확률론), 데이터 과학과 긴밀히 연결되어 있다
