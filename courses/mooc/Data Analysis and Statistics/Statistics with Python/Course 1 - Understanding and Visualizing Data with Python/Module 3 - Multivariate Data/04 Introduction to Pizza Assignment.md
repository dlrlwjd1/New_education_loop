# Introduction to Pizza Assignment

## 개요
- 지금까지 배운 개념을 실전에 적용하는 글쓰기·커뮤니케이션 중심 과제 소개
- 피자 회사 컨설턴트 역할로 데이터 수집·요약 계획을 담은 메모(memorandum)를 작성
- 제출 후 동료 평가(peer review)를 통해 서로의 작업을 검토하는 과정이 과제의 핵심 가치

## 내용

### 과제의 목적
- 이번 과제는 지금까지 배운 개념을 실제로 적용해 보는 기회다.
- 초점은 **글쓰기와 커뮤니케이션**이다. 통계 정보를 현실 세계에서 다른 사람에게 전달하는 데 필수적인 능력이기 때문이다.

### 과제 시나리오
- 학습자는 작은 피자 회사의 **컨설턴트** 역할을 맡는다. 회사 이름은 스스로 지어도 된다.
- CEO가 광고 캠페인에 사용할 데이터의 수집과 요약을 계획해 달라고 요청했다. 광고는 회사의 강점 중 하나를 부각한다:
  - 슬라이스당 더 많은 치즈 또는 토핑(more cheese or toppings per slice)
  - 더 맛있는 크러스트(better tasting crust)
  - 더 빠른 서비스(faster service)
- 어떤 강점을 내세울지는 학습자가 결정한다.

### 작성할 내용 — 연구 계획 메모(memorandum)
- 제안하는 연구(study)를 자신의 언어로 설명한다:
  - 어떤 데이터를 수집할 것인가
  - 어떤 유형의 변수(variable)를 측정할 것인가
  - 그 변수들을 어떻게 측정하고 기록할 것인가
- 데이터 요약 계획도 설명한다: 어떤 그래프와 수치 요약(numerical summaries)이 유용할지.
- 하지 **않아도** 되는 것: 데이터를 지어내기, 실제 통계 검정(statistical test) 수행, 실제 그래프나 수치 요약 생성, 상세한 공식. 목적은 연구 계획을 **전달(communicate)** 하는 것이다.
- 더 구체적인 지침은 과제 안에 있다.

### 동료 평가(peer review)
- 이 과제의 가장 큰 가치는 메모 제출 이후에 온다. 여러 동료의 작업을 검토하게 된다.
- 동료들이 어떤 아이디어를 잘 다루고 연결했는지, 덜 잘했는지 보게 되며 "오, 좋은 생각이다. 나도 저 생각을 했으면 좋았을 텐데" 하는 순간을 경험할 것이다.
- 미시간대의 다른 온라인 강좌 경험에 따르면, 이런 형식의 사려 깊은 피드백을 받은 학습자들은 자기 작업을 더 정확하게 평가하고, 개선점을 찾고, 다른 사람이 자신의 작업을 어떻게 해석할지 이해할 수 있게 되었다고 보고한다.
- 자신이 받고 싶은 피드백을 생각하며, 정중하고(courteous) 전문적인(professional), 사려 깊고 도움이 되는 피드백을 제공하라. 좋은 삶의 기술(life skill)이기도 하다.

## 요약
- 피자 회사 컨설턴트로서 광고 캠페인용 데이터 수집·요약 **계획**을 메모 형식으로 작성하는 과제다.
- 부각할 강점(치즈/토핑, 크러스트 맛, 서비스 속도)과 회사 이름은 자유롭게 정한다.
- 실제 데이터·검정·그래프는 만들지 않으며, 수집할 데이터·변수 유형·측정 방법·요약 계획을 글로 전달하는 것이 목표다.
- 제출 후 동료 평가를 통해 서로 배우며, 정중하고 전문적인 피드백을 주는 연습을 한다.
