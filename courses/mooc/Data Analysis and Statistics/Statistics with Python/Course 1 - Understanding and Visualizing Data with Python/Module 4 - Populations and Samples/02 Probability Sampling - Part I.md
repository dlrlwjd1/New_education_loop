# Probability Sampling: Part I

## 개요
- 단순무작위표본(simple random sample, SRS)의 정의와 성질: 모든 단위의 선택확률이 n/N으로 동일
- SRS와 i.i.d(independent and identically distributed) 데이터의 연결
- SRS 추정치는 편향이 없지만(unbiased), 큰 모집단에서는 비용 문제로 실제로는 거의 쓰이지 않음
- 고객 서비스 이메일 응답 시간 예시로 SRS와 나이브한 접근의 차이를 설명

## 내용

### 단순무작위표본추출(simple random sampling, SRS)
- 크기 N인 모집단 단위의 알려진 목록, 즉 표본추출틀(sampling frame)에서 시작한다. 단위는 개인, 가구, 사업체 등일 수 있다.
- 목록에서 n개의 단위를 무작위로 선택한다(n = 표본 크기).
- 모든 단위의 선택확률이 동일하며, 그 값은 **n / N** 이다. 이것이 **표집비율(sampling fraction)**, 즉 모집단 중 표본으로 선택되는 비율의 첫 예다.
- 이 설계에서는 크기 n의 **모든 가능한 표본이 동일한 확률**로 선택된다.
- SRS 데이터로 계산한 평균, 비율, 총계 등의 추정치는 **편향이 없다(unbiased)**. 즉, 가상의 반복 표본들 전체에서 평균적으로 추정치가 모집단 값과 같다. 어떤 표본이 뽑히는지에 따라 추정치는 변동하지만 평균적으로는 관심 모집단 값과 일치한다.

### 경기장(stadium) 그림 예시
- 10,000명 목록에서 134명을 무작위 선택한 경기장 조감도 그림: 검은 점(선택된 사람)이 경기장의 모든 구역(quadrant)에 고루 퍼져 있다.
- 무작위 선택 덕분에 134명만 측정해도 경기장 전체 모집단에 대해 대표성 있는 진술이 가능하다.

### 복원/비복원 추출
- **복원추출(with replacement)**: 선택된 단위를 목록에 되돌려 다시 선택될 기회를 준다.
- **비복원추출(without replacement)**: 한 번 표본으로 뽑힌 단위는 다시 뽑힐 수 없다. 실제로는 이 방식이 더 일반적이다.
- 어느 방식이든 각 단위의 선택확률은 여전히 n / N으로 같다.

### SRS가 실무에서 드문 이유
- 매우 큰 모집단에서 무작위로 뽑힌 n개 단위의 데이터를 수집하는 비용이 지나치게 클 수 있다.
- 예: 미국 전역에서 1,000명을 SRS로 뽑아 각 가구를 직접 방문해 인터뷰해야 한다면, 흩어진 가구들로 운전해 다니는 비용이 엄청나게 커진다.
- 따라서 큰 모집단에서는 더 저렴한 대안적 확률표본 설계를 사용하고, SRS는 모집단이 작고 데이터 수집이 쉬운 경우에 주로 쓴다.

### i.i.d 데이터와의 연결
- i.i.d 관측치는 독립적이고(independent) 동일한 분포를 따르는(identically distributed) 데이터다.
- SRS는 이론상 특정 변수에 대해 i.i.d 데이터를 생성한다.
  - **독립(independent)**: 무작위로 뽑힌 단위들 사이에는 연결이 없고, 서로 독립적으로 선택되며 관심 측정값이 서로 상관되지 않는다.
  - **동일 분포(identically distributed)**: 측정값들이 더 큰 모집단의 값 분포를 나타내는 동일한 분포에서 나온다.

## 예시

### 고객 서비스 이메일 응답 시간
- 상황: 2018년에 들어온 이메일 요청 N = 2,500건의 고객 서비스 데이터베이스가 있고, 부서장이 평균 이메일 응답 시간(mean email response time)을 추정하려 한다.
- 문제: 정확한 계산에는 각 이메일 스레드의 수작업 검토(타임스탬프 추적)가 필요해 2,500건 전부 측정하기 어렵다. 그래서 n = 100건의 표본을 분석하기로 한다.
- **나이브한 접근**: 목록의 처음 100건만 처리한다.
  - 상담원들이 시간이 지나며 응답 속도가 빨라졌다면 추정 평균이 너무 크게 편향될 수 있다.
  - 처음 100건이 소수의 특정 직원에게서 나왔을 수 있어 대표성이 없다 — 독립적이지 않고(같은 직원이 응답), 동일 분포도 아니다(부서 전체의 응답 시간 분포와 다른 분포에서 나옴).
  - 무작위 선택이 없으므로 본질적으로 비확률표본(non-probability sample)이며 중요한 한계를 가진다.
- **더 나은 SRS 접근**: 이메일에 1~2,500 번호를 붙이고 난수 생성기(random number generator)로 100개의 번호를 무작위 선택한다.
  - 모든 이메일이 알려진 선택확률 100/2,500을 가진다.
  - 이론상 전체 이메일에서 무작위로 뽑힌 대표표본 100건이 만들어진다.
  - 추정 평균 응답 시간은 모집단 평균의 편향 없는 추정치가 된다 — 크기 100의 표본을 아주 많이 뽑아 각각 평균을 계산하면 그 평균들의 평균이 참 모집단 값과 같다.

## 요약
- SRS에서는 모든 단위의 선택확률이 n/N으로 같고, 크기 n의 모든 가능한 표본이 동일한 확률로 뽑힌다.
- SRS 기반 추정치(평균, 비율, 총계 등)는 편향이 없다.
- 복원/비복원 여부와 무관하게 선택확률은 n/N이다.
- SRS는 이론상 i.i.d 데이터를 생성하지만, 큰 모집단에서는 비용 때문에 실무에서 드물게 사용된다.
- 목록 앞부분만 취하는 나이브한 접근은 비확률표본이 되어 편향 위험이 크고, 난수 기반 무작위 선택이 올바른 대안이다.
