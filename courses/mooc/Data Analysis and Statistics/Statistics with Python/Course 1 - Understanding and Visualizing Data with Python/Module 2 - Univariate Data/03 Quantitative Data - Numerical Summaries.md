# Quantitative Data: Numerical Summaries

## 개요
- 수치 요약(numerical summary, summary statistics)은 히스토그램 같은 대략적인 그래프 표현을 소수점 단위까지 정확한 값으로 보완한다.
- 핵심은 다섯 수 요약(five number summary): 최솟값(min), 제1사분위수(Q1), 중앙값(median), 제3사분위수(Q3), 최댓값(max)이다.
- 사분위수 범위(IQR)와 표준편차(standard deviation)는 범위(range) 외의 퍼짐(spread) 측도이며, 치우친 분포에서는 IQR이 더 유용하다.

## 내용

### 다섯 수 요약 (Five Number Summary)
소프트웨어마다 출력 형태는 조금씩 다르지만(강의에서는 R 출력 예시를 먼저 보여 줌) 보통 다섯 수 요약을 제공한다.

- **최솟값(minimum)**: 가장 작은 값
- **제1사분위수(first quartile, Q1)**: 25번째 백분위수(25th percentile). 데이터의 25%가 이 값 아래에 있다.
- **중앙값(median)**: 50번째 백분위수. 데이터의 50%가 이 값 아래에 있다.
- **제3사분위수(third quartile, Q3)**: 75번째 백분위수. 데이터의 75%가 이 값 아래에 있다.
- **최댓값(maximum)**: 가장 큰 값

### 예시 1 — 성인 남성 키
이전 강의의 종 모양(bell-shaped) 성인 남성 키 히스토그램에 대한 수치 요약.

- 최솟값 61.7
- Q1 = 66.5 → 참가자의 25%가 키 66.5인치 이하
- 중앙값 = 68.3 → 절반이 68.3 미만, 절반이 그 위
- 평균(mean)도 68.3 → 대칭(symmetric) 분포이므로 평균과 중앙값이 같다(보통 비슷해진다)
- Q3 = 70.1 → 데이터의 75%가 70.1 아래, 25%가 위
- 최댓값 75.1 → 표본에서 가장 큰 사람의 키

여기서 **사분위수 범위(IQR, interquartile range)** = Q3 − Q1을 구할 수 있다. IQR은 또 하나의 퍼짐 측도로, 범위(최댓값 − 최솟값) 대신 사용할 수 있다.

### 예시 2 — 샌프란시스코 급여
오른쪽으로 치우친(right skewed) 이봉(bimodal) 분포였으므로 평균이 중앙값보다 클 것으로 예상되며, 수치 요약으로 정확히 얼마나 차이 나는지 확인한다. Python에서는 흔히 describe 함수를 사용해 수치 요약을 얻으며, 최솟값·25%(Q1)·50%(중앙값)·75%(Q3)·최댓값에 더해 평균, 표준편차(SD), 표본 크기(n)를 보여 준다.

- 표본 크기 n = 148,654 (3년간 수집한 매우 큰 표본)
- 표준편차(standard deviation) = 50,517달러. 표준편차는 데이터 포인트가 평균에서 떨어진 거리의 대략적인 평균으로, 평균적으로 한 사람이 평균값에서 약 $50,000 위 또는 아래에 있다는 뜻이다.
- 평균 = $74,768, 중앙값 = $71,427 → 평균이 중앙값보다 약 $3,000 크다. 오른쪽 치우침 때문이다.
- 최댓값 = 567,595 → 매우 큰 급여
- 최솟값 = −618.1 → 직원이 고용주에게 돈을 낼 이유는 없으므로 의아한 값이다. 입력 오류이거나 샌프란시스코의 세금 규정 같은 다른 원인이 있을 수 있다. 수치 요약을 볼 때는 이렇게 "왜 이런 값이 나왔는가"라는 질문을 제기하는 것이 중요하다.

### 예시 3 — 시험 점수
왼쪽으로 치우친(left skewed) 분포로, 중심 약 80점, 15~100점 범위, 50점 미만에 이상치가 많다고 봤었다. 왼쪽 치우침이면 평균이 중앙값보다 작을 것으로 예상된다.

- 중앙값 = 78, 평균 = 76.3 → 예상대로 평균 < 중앙값. 낮은 쪽 이상치들이 평균을 끌어내리기 때문이다.
- **중앙값은 이상치의 영향을 받지 않는 중심의 강건한(robust) 추정치다.**
- 표준편차 = 14.4 → 평균적으로 시험 점수가 평균에서 약 14.4점 떨어져 있다.
- IQR = Q3 − Q1 = 87 − 68 = 19
- 치우친 분포에서는 IQR을 함께 제시하는 것이 좋다. 범위(14~100)는 이상치에 덜 강건해 대부분의 데이터가 어디 있는지 알기 어렵지만, IQR은 데이터의 대부분이 놓인 곳을 알려 준다.

## 요약
- 수치 요약(summary statistics)은 히스토그램·박스플롯 같은 그래프 표현과 함께 사용해 데이터를 더 깊이 분석하게 해 준다.
- 다섯 수 요약: 최솟값, Q1(25th percentile), 중앙값, Q3(75th percentile), 최댓값. 소프트웨어에 따라 평균·표준편차·표본 크기가 추가된다.
- 대칭 분포에서는 평균 ≈ 중앙값, 오른쪽 치우침에서는 평균 > 중앙값, 왼쪽 치우침에서는 평균 < 중앙값이다.
- 중앙값은 이상치에 강건(robust)하고, 범위보다 IQR이 데이터의 대부분이 놓인 위치를 더 잘 보여 준다.
- 이상한 값(예: 음수 급여)이 보이면 왜 그런지 질문을 제기해야 한다.
