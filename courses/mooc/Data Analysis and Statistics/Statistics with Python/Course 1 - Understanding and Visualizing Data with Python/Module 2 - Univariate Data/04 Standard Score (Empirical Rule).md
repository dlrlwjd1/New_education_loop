# Standard Score (Empirical Rule)

## 개요
- 종 모양(bell-shaped, 정규) 분포에서는 경험적 법칙(Empirical Rule), 즉 68-95-99.7 법칙이 성립한다.
- 표준 점수(standard score, Z-score)는 관측값이 평균에서 표준편차 몇 개만큼 떨어져 있는지를 나타내며, 값이 얼마나 특이한지 판단하는 기준(frame of reference)을 준다.
- 예시: 대학생의 평일 수면 시간 — 평균(mean) 7시간, 표준편차(standard deviation) 1.7시간.

## 내용

### 종 모양 분포와 수면 시간 예시
많은 변수가 종 모양 분포를 따르고, 많은 추정치도 근사적으로 종 모양이 된다. 강의에서는 대학생의 평일 수면 시간을 예로 든다. 여러 연구에 따르면 평균 수면 시간은 약 7시간이며, 대칭 분포의 한가운데에 이 평균을 표시한다.

평균과 함께 자주 보고되는 퍼짐(spread)의 측도가 표준편차(standard deviation)다. 이 예시에서 표준편차는 1.7시간이다. 표준편차는 값들이 평균에서 얼마나 떨어져 있는지를 재며, 대략 "값들이 평균에서 떨어진 평균 거리"로 해석한다. 즉 대학생들의 수면 시간은 평균 7시간에서 평균적으로 약 1.7시간씩 벗어난다.

### 경험적 법칙 (Empirical Rule, 68-95-99.7 법칙)
표준편차를 잣대(yardstick)로 삼아 분포 위에 값들을 배치한다.

- **±1 표준편차** (5.3 ~ 8.7시간): 종 모양·정규 분포에서 관측값의 약 **68%** 가 이 범위에 들 것으로 기대된다.
- **±2 표준편차** (3.6 ~ 10.4시간): 약 **95%** 가 이 범위에 든다.
- **±3 표준편차** (1.9 ~ 12.1시간, 12시간 넘는 쪽과 2시간 미만 쪽): 약 **99.7%**, 거의 전부가 이 범위에 든다.

이를 68-95-99.7 법칙 또는 경험적 법칙(Empirical Rule)이라 부른다. 값이 얼마나 특이한지에 대한 기준을 얻는 데 매우 유용하다.

### 표준 점수 (Standard Score, Z-Score)
표준 점수는 다음 식으로 계산한다.

- 표준 점수 = (관측값 − 평균) ÷ 표준편차

**예시 1 — Reed의 10시간 수면**: 관측값이 10시간이면 평균보다 3시간 위다.

- Z = (10 − 7) ÷ 1.7 = **1.76**
- 데이터의 95%가 3.6~10.4 사이에 있는데 10은 10.4 바로 아래이므로, 상당히 특이한(unusual) 값이다.

**예시 2 — 룸메이트의 6시간 수면**:

- Z = (6 − 7) ÷ 1.7 = **−0.59**
- 음수 부호는 평균보다 아래임을 뜻하며, 0.59는 평균에서 약간만 아래라는 뜻이다. 반면 +1.76은 평균보다 꽤 위이고 양수는 평균 위를 뜻한다.

### 표준 점수에서 관측값 역산하기
친구 Mark는 표준 점수가 평균보다 2.7 표준편차 아래(Z = −2.7)라고 한다. 2 표준편차 아래가 3.6, 3 표준편차 아래가 1.9이므로 그 사이 어딘가다. 관측값 X를 역산하면,

- −2.7 = (X − 7) ÷ 1.7 → X = 7 − 2.7 × 1.7 = **2.41시간**
- 즉 평균 7에서 2.7 표준편차만큼(2.7 × 1.7) 아래로 내려간 값이다. Mark는 수면이 매우 부족하며, 새벽 2~3시에 이메일 답장을 보내는 이유가 설명된다.

## 예시
```python
# 수면 시간 예시: 평균 7시간, 표준편차 1.7시간
mean = 7
sd = 1.7

# 표준 점수(Z-score) = (관측값 - 평균) / 표준편차
z_reed = (10 - mean) / sd      # 1.76  (평균보다 꽤 위, 특이한 값)
z_roommate = (6 - mean) / sd   # -0.59 (평균보다 약간 아래)

# Z-score로 관측값 역산: X = 평균 + Z * 표준편차
x_mark = mean + (-2.7) * sd    # 2.41시간
```

## 요약
- 종 모양(정규) 분포에서 평균과 표준편차를 알면 경험적 법칙과 표준 점수로 기준(frame of reference)을 얻을 수 있다.
- 경험적 법칙: 평균에서 1, 2, 3 표준편차 이내에 각각 관측값의 약 68%, 95%, 99.7%가 든다.
- 표준 점수(Z-score) = (관측값 − 평균) ÷ 표준편차. 부호는 평균 위(+)/아래(−)를, 크기는 평균에서 떨어진 정도를 나타낸다.
- 표준 점수를 알면 관측값을 역산할 수 있다: X = 평균 + Z × 표준편차.
