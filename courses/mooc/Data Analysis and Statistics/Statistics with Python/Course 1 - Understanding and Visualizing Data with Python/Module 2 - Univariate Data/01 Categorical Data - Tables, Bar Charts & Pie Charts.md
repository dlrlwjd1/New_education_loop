# Categorical Data: Tables, Bar Charts & Pie Charts

## 개요
- 범주형 데이터(categorical data)는 개인이나 항목을 서로 다른 그룹으로 분류하는 데이터다.
- 범주형 데이터를 요약하는 가장 일반적인 방법은 빈도표(frequency table)이며, 개수(count) 또는 백분율(percentage)로 나타낸다.
- 시각화에는 막대 그래프(bar chart)가 가장 권장되며, 파이 차트(pie chart)는 판독이 어려워 주의해서 사용해야 한다.

## 내용

### 범주형 데이터와 예시: 혼인 상태
범주형 데이터는 개인이나 항목을 서로 다른 그룹으로 분류(classify)하는 데이터다. 강의에서는 혼인 상태(marital status)를 예시 변수로 사용하며, 다음과 같이 코딩되어 있다.

- 1 = 기혼(married), 2 = 사별(widowed), 3 = 이혼(divorced), 4 = 별거(separated), 5 = 미혼(never married), 6 = 동거(living with partner), 7 = 응답 거부(refused), 8 = 모름(don't know)

### 빈도표 (Frequency Table)
범주형 데이터를 요약하는 가장 일반적인 방법은 개수 또는 백분율을 담은 빈도표다. 모든 범주를 나열하고 각 범주의 개수와 백분율을 함께 표시한다.

- 예시 데이터셋: 전체 5,560명 중 기혼 2,683명, 사별 467명 등
- 백분율 계산: 각 그룹의 개수를 전체 개수로 나눈다.
  - 기혼 비율 = 2,683 ÷ 5,560 ≈ 48.3%

### 막대 그래프 (Bar Chart)
범주형 데이터를 시각화하는 가장 일반적인 방법이다.

- x축: 혼인 상태의 8개 범주, y축: 빈도(frequency, 개수). 첫 번째 막대는 기혼 2,683명을 보여준다.
- y축을 개수 대신 백분율로 바꿔도 막대와 그래프의 전체 모양은 변하지 않으며, 경우에 따라 백분율 표시가 실제 개수보다 더 유용하다.
- 혼인 상태처럼 범주의 순서가 의미 없는 명목형(nominal) 데이터에서는 막대를 내림차순으로 재배열할 수 있다. 어떤 그룹이 가장 큰 비중을 차지하는지 파악하기 쉬워진다. 예시에서는 기혼, 미혼, 이혼이 상위 3개 범주였다.

### 파이 차트 (Pie Chart)의 문제점
파이 차트도 범주형 데이터 시각화 옵션이지만, 두 가지 이유로 막대 그래프보다 권장하지 않는다.

1. **레이블 겹침**: 매우 작은 조각(slice)의 레이블이 서로 겹쳐 읽기 어렵다. 예시에서 "refused"와 "don't know" 레이블이 겹쳤고, 사용하는 프로그램에 따라 이를 해결하기 어려울 수 있다.
2. **크기 비교의 어려움**: 적절한 레이블이 없으면 어느 조각이 더 큰지 구분하기 어렵다. 예시에서 사별, 이혼, 동거는 크기가 매우 비슷해서 "10.3%"라는 백분율 표기가 없었다면 이혼이 더 큰 조각임을 알기 어려웠을 것이다.

## 요약
- 범주형 데이터의 최선의 요약 방법은 개수나 백분율(또는 둘 다)을 담은 빈도표(frequency table)다.
- 시각화에는 막대 그래프(bar chart)가 가장 좋으며, 개수와 백분율 어느 쪽으로도 표시할 수 있다.
- 명목형(nominal) 데이터는 막대를 내림차순으로 재배열하면 더 유용할 수 있다.
- 파이 차트는 레이블 겹침과 조각 크기 비교의 어려움 때문에 사용 시 주의가 필요하다.
