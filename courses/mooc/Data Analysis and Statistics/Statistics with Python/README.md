# Statistics with Python Specialization

- 플랫폼: MOOC
- 제공: University of Michigan
- 강사: Brenda Gunderson · Brady T. West · Kerby Shedden
- 링크: <https://www.mooc.org/specializations/statistics-with-python>
- 수집일: 2026-07-24 (영상 91개 Transcript 기반 한국어 정리)
- 제외: 읽기 자료·퀴즈·Jupyter 실습(Lab)·채점 과제의 정답 및 제출

Python으로 통계적 사고를 다지는 3개 코스 전문과정. 데이터의 출처와 표본 설계, 시각화에서 시작해 신뢰구간·가설검정 같은 추론 절차를 거쳐 선형·로지스틱 회귀, 다층 모델, 베이지안 접근까지 이어진다.

## 코스 구성

### Course 1 - Understanding and Visualizing Data with Python (영상 33개)

데이터 유형·연구 설계, 단변량·다변량 시각화, 확률·비확률 표본추출과 표집분포.

- [Course 1 README](Course%201%20-%20Understanding%20and%20Visualizing%20Data%20with%20Python/README.md)
  - Module 1 - Introduction to Data (11)
  - Module 2 - Univariate Data (6)
  - Module 3 - Multivariate Data (4)
  - Module 4 - Populations and Samples (12)

### Course 2 - Inferential Statistical Analysis with Python (영상 32개)

추론의 언어와 표기법, 비율·평균의 신뢰구간, 가설검정과 p-값·p-해킹, NHANES 실전 적용.

- [Course 2 README](Course%202%20-%20Inferential%20Statistical%20Analysis%20with%20Python/README.md)
  - Module 1 - Overview and Inference Procedures (6)
  - Module 2 - Confidence Intervals (10)
  - Module 3 - Hypothesis Testing (10)
  - Module 4 - Learner Application (6)

### Course 3 - Fitting Statistical Models to Data with Python (영상 26개)

모델 적합의 목적(추론 vs 예측), 선형·로지스틱 회귀, 다층·주변 모델(GEE), 조사 가중치와 베이지안 접근.

- [Course 3 README](Course%203%20-%20Fitting%20Statistical%20Models%20to%20Data%20with%20Python/README.md)
  - Module 1 - Overview and Considerations for Statistical Modeling (8)
  - Module 2 - Fitting Models to Independent Data (5)
  - Module 3 - Fitting Models to Dependent Data (7)
  - Module 4 - Special Topics (6)
