# Linear Regression Inference

## 개요
- 카트휠 거리 ~ 키 회귀에서 기울기(slope)에 대한 가설검정(hypothesis test)과 신뢰구간(confidence interval)으로 추론(inference)을 수행한다.
- 평균 반응에 대한 신뢰구간(confidence interval for the mean response)과 개별 반응에 대한 예측구간(prediction interval)을 구분한다.
- 추론의 전제인 오차항(error term) 가정(정규성, 상수 분산)을 잔차(residual)로 점검한다.
- 완수 여부(completion status) 지시변수(indicator variable)를 추가해 다중회귀로 확장하고 계수 해석 방법을 배운다.

## 내용

### 왜 기울기가 관심 대상인가
- 기울기가 0이면 직선이 평평해서 x에 어떤 값을 넣어도 같은 반응을 예측한다. 즉 **x를 아는 것이 예측에 도움이 되지 않는다.**
- 표본에서 얻은 기울기 1.1은 추정치(b₁)일 뿐이다. 다른 성인 25명으로 반복하면 다른 추정치가 나온다.
- 모집단 전체 데이터가 있다면 참 회귀직선(true regression line)이 존재하며, 그 참 기울기가 모수 **β₁(Beta one)** 이다. 검정 대상은 "β₁이 0인가 아닌가"(여기서는 양수인가)이다.

### 기울기에 대한 가설검정
- 출력의 height 행에서:
  - 추정 기울기 b₁ = **1.1**
  - 표준오차(standard error) = **0.67** — 이런 추정 기울기들이 참 기울기에서 평균적으로 얼마나 떨어지는지를 추정
- **t 통계량** = 추정 기울기가 0에서 표준오차 단위로 얼마나 떨어져 있는지 → 기울기는 0보다 **1.65 표준오차** 위에 있다.
- 양측(two-sided) p-값 = **0.112** — 10% 수준에서도 유의하지 않다. 단, 이것은 "β₁ ≠ 0" 검정용.
- 연구 질문은 **양의(positive)** 선형 관계이므로 단측 검정: 양측 p-값을 반으로 → **0.056**. 10% 수준에서는 유의하지만 5% 수준에서는 유의하지 않은, 경계적으로 유의한(marginally significant) 결과.

### 기울기의 신뢰구간
- 95% 신뢰구간: 키 1인치 증가에 따른 모집단 평균 카트휠 거리 변화는 **−0.2인치에서 +2.5인치** 사이로 추정된다 (95% 신뢰수준).

### 평균 반응의 신뢰구간 vs 예측구간
- 키 64인치에서의 추정 평균 78.4인치 주위로 표준오차 몇 배만큼의 구간을 만들면 **주어진 x에서의 평균 반응에 대한 신뢰구간**이 된다. 데이터 범위 안의 모든 키에 대해 만들면 95% 신뢰구간 밴드(confidence interval bands)가 생긴다.
- 이 밴드는 회귀직선과 평행하지 않고 **곡선**이다. x가 표본 평균에 가까울수록 좁아진다. 이 데이터의 평균 키는 **67.6인치**이며 그 지점에서 밴드가 가장 좁다. 평균에서 먼 값의 평균을 추정할수록 변동성이 커진다.
- **예측구간(prediction interval)**: 특정 키의 **개인** 반응값 범위. 개인 예측이 평균 추정보다 어렵고 변동성이 더 크므로, 예측구간은 대응하는 평균 반응 신뢰구간보다 **항상 더 넓다.**

### 모형 가정과 잔차 점검
- 모형: 개인의 카트휠 거리 = (키의 선형함수인 참 평균 반응) + 오차 e.
- 가정: 오차 e는 **평균 0 주위로 정규분포**하며, 키에 의존하지 않는 **상수 분산(constant variance)** 을 가진다.
- 참 오차는 볼 수 없으므로(참 회귀직선을 모름) **잔차** — 오차항의 실현값 — 로 점검한다.
  - **잔차의 Q-Q plot**: 점들이 양의 기울기 직선 위에 잘 놓이면 정규성이 타당. 이 데이터에서는 정규성이 타당해 보임.
  - **잔차 플롯(residual plot)** (잔차 vs 키): 0 주위의 무작위 산포, 일정한 수평 밴드(낮은 키와 높은 키에서 변동성이 비슷)면 상수 분산이 타당. 여기서도 확인됨.
- 상수 표준편차 σ의 추정: 예측값과 관측값이 평균적으로 얼마나 떨어지는가 → 약 **14.5인치**. 아직 다뤄야 할 변동성이 상당히 크다.

### 설명변수 추가: 완수 여부 지시변수
- 카트휠 완수 여부를 지시변수(indicator variable)로 코딩: 완수 = 1, 미완수 = 0.
- 새 회귀 결과: 새로운 절편, 키 계수는 **1.26**으로 갱신, 완수 상태 계수는 **약 6**.
  - 완수 계수 6 = 기준(reference) 수준인 미완수(0)에서 완수(1)로 이동할 때 기대되는 **6인치의 이동(shift)**.
- **다중회귀 계수 해석의 핵심**: 각 계수는 **다른 모든 변수의 수준이 같을 때** 비교해야만 의미가 있다.
  - 키 계수 1.26: 완수 상태가 같은 두 성인이 키가 1인치 차이나면 카트휠 거리가 평균 약 1과 1/4인치 차이.
  - 완수 계수 6: 키가 같은 두 성인 중 완수한 사람이 평균 약 6인치 더 길다.
- 시각적으로는 완수자와 미완수자의 회귀직선 두 개가 6인치만큼 위아래로 떨어져 있는 그림이 된다 (완수자 직선이 위).
- 잔차 플롯도 다시 확인: 0 주위 무작위 산포와 상수 분산을 보여 추론이 타당함.

### 조정 후 추론
- 질문: 완수 상태를 조정(adjusting)한 후에도 카트휠 거리와 키 사이에 유의한 양의 선형 관계가 있는가?
- 조정 후 키 계수 추정 = **1.26**, 표준오차 ≈ **0.7**.
- 양측 p-값 **0.085**를 반으로 → 단측 p-값 ≈ **0.04**. → 완수 상태 조정 후 키와 카트휠 거리 사이에 **유의한 양의 연관**이 있다.
- 예측이 관측값에서 벗어나는 정도의 추정은 여전히 약 **14.5인치**.

## 요약
- 기울기 추론: t = b₁/SE = 1.1/0.67 = 1.65, 양측 p = 0.112, 단측(양의 관계) p = 0.056 → 경계적 유의.
- 95% CI: 키 1인치당 평균 거리 변화 −0.2 ~ +2.5인치.
- 평균 반응 신뢰구간 밴드는 곡선이며 표본 평균 x(키 67.6인치)에서 가장 좁다. 개인용 예측구간은 항상 더 넓다.
- 가정(오차의 정규성, 상수 분산)은 잔차 Q-Q plot과 잔차 플롯으로 점검한다. σ 추정 ≈ 14.5인치.
- 지시변수(완수=1/미완수=0) 추가 후: 키 계수 1.26, 완수 계수 ≈ 6. 각 계수는 다른 변수 수준이 같을 때만 의미가 있다.
- 완수 상태 조정 후 단측 p ≈ 0.04로 키의 양의 효과가 유의하다. 반응변수가 이진(binary)이면 다음 주제인 로지스틱 회귀(logistic regression)를 쓴다.
