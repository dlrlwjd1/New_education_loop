# Linear Regression Introduction

## 개요
- 카트휠 연구(cartwheel study) 데이터(성인 25명)를 이용해 선형회귀(linear regression)의 기초를 소개한다.
- 산점도(scatter plot)로 관계를 시각화하고 상관계수(correlation coefficient) r과 결정계수 r²로 관계의 강도를 수치화한다.
- 최소제곱법(least squares)으로 최적의 직선(best fitting line)을 구하고, 예측(prediction)과 잔차(residual)의 개념을 익힌다.

## 내용

### 데이터와 연구 질문
- 성인 25명에게 카트휠(옆돌기)을 수행하게 한 연구다. 반응변수(response variable)는 **카트휠 거리(cartwheel distance, 인치)** — 시작점에서 끝점까지 이동한 거리.
- 연구 질문:
  - 이런 성인 모집단의 평균 카트휠 거리를 예측하는 모델을 만들 수 있는가?
  - 키(height)가 카트휠 거리의 유용한 예측변수(predictor)인가?
  - 카트휠 완수 여부(completion status)가 평균 카트휠 거리에 차이를 만드는가?
- 반응변수만 요약하면: 히스토그램과 Q-Q plot이 대체로 정규성(normality)을 보이며, 다른 정보 없이 다음 성인의 거리를 예측한다면 표본평균인 **82.48인치**를 보고하게 된다.

### 산점도로 관계 살펴보기
- 종속변수(dependent variable)/반응변수인 카트휠 거리를 y축에, 독립변수(independent variable)/설명변수(explanatory variable)인 키를 x축에 놓는다.
- 산점도를 기술할 때는 **형태(form), 방향(direction), 강도(strength), 이상치(outliers)** 를 언급한다.
- 이 데이터의 해석: 대략 선형(linear) 관계, 방향은 양(positive), 점들이 흩어져 있어 강도는 약~중간(weak to moderate), 뚜렷한 이상치는 없음.

### 상관계수 r과 r²
- 상관계수 r은 −1과 1 사이의 값. 여기서는 **r = 0.33**으로 약~중간 수준의 양의 관계.
- 설명변수와 반응변수가 모두 양적변수이고 설명변수가 하나일 때 **r² 은 상관계수의 제곱**이다.
- r² ≈ 0.11 → 카트휠 거리 변동성의 **약 11%** 만이 키와의 선형 관계로 설명된다. (거리 자체는 70인치 미만에서 110인치 이상까지 변동이 큼)

### 회귀직선의 표기와 계수의 의미
- 일반적인 직선 y = mx + b 대신 회귀에서는 다음 표기를 쓴다.
  - **ŷ = b₀ + b₁x** (ŷ: 예측값, b₀: 절편(intercept), b₁: 기울기(slope))
  - 이 표기는 설명변수를 추가해 b₂w처럼 모델을 확장하기 쉽다.
- **절편(y-intercept)**: x = 0일 때의 추정 반응값. 맥락에 따라 의미가 없을 수도 있다.
- **기울기(slope)**: 보통 더 관심 있는 계수. x가 1단위 증가할 때 반응변수의 추정 변화량(change in y / change in x).

### 최소제곱 회귀직선 (least squares regression line)
- 점들이 직선 위에 정확히 놓이지 않으므로, 직선으로 예측할 때 각 점마다 관측 오차(observed error), 즉 **잔차(residual)** 가 생긴다. 잔차는 직선으로부터의 수직 거리다.
- 양수·음수가 상쇄되지 않도록 **오차를 제곱해서 모두 더한 값(총 제곱오차)을 최소화**하는 직선이 최소제곱 회귀직선이다.
- 소프트웨어 출력의 계수(coefficient) 부분에서: 상수항(절편) **7.55**, 키의 계수(기울기) **1.1**.
- 기울기 해석: 키가 1인치 더 큰 성인은 평균적으로 카트휠 거리가 **약 1.1인치 더 길 것**으로 추정된다.

### 예측과 잔차 계산
- 키 64인치인 성인의 예측: x = 64를 대입 → 예측 카트휠 거리 **78.4인치**.
- 예측 시 x 값이 모델링에 사용한 데이터 범위 안에 있는지 확인해야 한다. 범위를 벗어난 예측은 **외삽(extrapolation)** 으로 위험하다. (64인치는 관측 범위 안)
- 이 78.4인치는 키 64인치인 **모든 성인의 평균 카트휠 거리 추정치**이기도 하다. 회귀모형은 사실 x가 주어졌을 때의 **조건부 평균 반응(estimated mean response conditional on x)** 을 추정한다.
- 실제 데이터에 키 64인치, 거리 87인치인 관측이 있었다.
  - 잔차 = 관측값 − 예측값 = 87 − 78.4 = **8.6인치**
- 모든 관측에 대해 잔차를 계산할 수 있으며, 이후 모델 점검(model checking)에 사용된다.

## 요약
- 반응변수(카트휠 거리)와 설명변수(키)의 관계는 산점도로 살피고 방향·강도·이상치를 기술한다.
- r = 0.33, r² ≈ 11%: 키와의 선형 관계는 카트휠 거리 변동의 약 11%만 설명한다.
- 최소제곱법은 잔차 제곱합을 최소화하는 직선을 찾는다: ŷ = 7.55 + 1.1 × height.
- 기울기 1.1 = 키 1인치 차이당 평균 카트휠 거리 약 1.1인치 차이.
- 예측은 데이터 범위 안에서만 (외삽 주의). 잔차 = 관측값 − 예측값 (예: 87 − 78.4 = 8.6).
- 다음 단계는 유의한 관계인지 평가하는 추론(inference)과 가정 점검, 예측변수 추가 확장이다.
