# Logistic Regression Introduction

## 개요
- 반응변수가 이진(binary, 0/1)일 때 선형회귀(linear regression)를 확장한 로지스틱 회귀(logistic regression)를 소개한다.
- 이진 반응에 선형회귀를 그대로 쓰면 확률이 100%를 넘는 등 말이 안 되는 예측이 생기므로, 성공 확률 p를 로짓(logit) = 로그 오즈(log odds)로 변환해 모델링한다.
- 카트휠 데이터로 나이(age)에 따른 카트휠 완수 확률 모형을 적합하고, 기울기를 오즈(odds)의 배수 변화로 해석한다.

## 내용

### 데이터와 목표
- 성인 25명의 무작위 표본이 카트휠을 시도했다. 관심 변수는 **완수 여부**: 손을 땅에 짚고 발이 머리 위로 넘어가 시작 지점 앞에 발로 착지했는지 — 완수 = 1, 미완수 = 0.
- 목표: **나이(age)를 기반으로 카트휠 완수 확률을 추정**한다.
- 산점도를 보면 완수 여부는 0 또는 1 두 값만 가진다. 나이는 약 22세에서 55세 조금 넘게 분포하지만, 대부분의 관측은 **약 22~35세**에 몰려 있다.

### 선형회귀를 그대로 쓰면 생기는 문제
- 선형회귀를 적합하면: **ŷ = 0.34 + 0.015 × age** (ŷ는 완수 확률의 예측값).
- 이 직선은 약 **45세** 부근에서 y = 1 선을 넘는다. 그러면 50세인 사람의 완수 확률이 **약 110%** 가 되는데, 확률이 100%를 넘는 것은 통계적으로 말이 되지 않는다.
- 따라서 예측값이 0과 1 사이에 있도록 모형을 수정해야 한다.

### 로짓(logit) 변환 = 로그 오즈(log odds)
- 완수 상태를 직접 예측하는 대신 **성공 확률의 변환값**을 예측한다.
- p = 성공 확률일 때, **오즈(odds) = p / (1 − p)** — 성공 확률을 실패 확률로 나눈 것.
- **로짓 함수 = 자연로그를 취한 오즈**: logit(p) = ln(p / (1 − p)). 이를 로그 오즈라고도 부른다.
- 로짓 함수의 성질:
  - p = 0.5 (성공과 실패가 같은 확률)이면 로짓 값은 **0**.
  - p = 0.75와 p = 0.25의 로짓 값은 서로 **부호만 반대**다. 성공/실패 라벨을 바꾸면 부호가 뒤집히는 **대칭(symmetric)** 구조로, 매우 좋은 특성이다.
  - 로짓 값이 높을수록 성공 확률이 높고, 낮을수록 성공 확률이 낮다.
  - 그래프에서는 ±7 부근에서 멈추는 것처럼 보여도 실제 범위는 **−∞에서 +∞** 까지다.

### 로지스틱 회귀 모형과 곡선의 형태
- 선형회귀와 같은 형식(절편 + 기울기)을 유지하되 y 대신 로짓을 사용한다: **logit(ŷ) = b₀ + b₁ × age**.
- **확률 척도**에서 보면 로지스틱 회귀선은 곧지 않은 **곡선**이다. **로그 오즈 척도**에서 보면 직선이다. 로그 오즈는 해석이 어렵기 때문에 해석할 때는 주로 성공 확률 척도로 본다.
- 나이 범위를 0~60세로 확장해 보면 **S자 형태(S shape)** — 언덕을 오르는 모양이다. 반대로 좌에서 우로 언덕을 내려가는(스키 타는) 거울상 형태일 수도 있다.
- **외삽(extrapolation) 주의**: 15세의 완수 확률을 이 선으로 추정하면 약 20%처럼 보이지만, 관측된 최연소가 약 22세이므로 15세는 관측 범위를 상당히 벗어난다. 관측한 나이 범위를 넘는 추정은 신뢰할 수 없다.

### Python 출력 읽기
- Python에서는 **일반화 선형모형(generalized linear model, GLM)** 으로 적합한다. 이는 **최대우도추정(maximum likelihood estimation)** 의 한 형태로, 모든 데이터를 사용해 최적의 적합선을 찾는다.
- 출력에서 확인할 것:
  - **모형 패밀리(family) = binomial**: y가 성공/실패 두 값만 가진다는 뜻.
  - **링크 함수(link function) = logit**.
  - **계수(coefficients)**: 절편 = **−4.42**, 나이 계수 = **약 0.2096**.
- 적합된 식: **logit(ŷ) = −4.42 + 0.2096 × age**

### 기울기의 해석
- 로그 오즈 척도: 나이가 1살 증가할 때마다 카트휠 성공의 **로그 오즈가 평균 약 0.2096 증가**한다.
- 오즈 척도: 나이가 1살 증가할 때마다 성공의 **오즈가 약 1.23배**가 된다. 이 1.23은 **e^0.2096** 으로 계산한다.
  - 오즈에 **곱해지는(multiplicative)** 배수라는 점이 중요하다.
  - 이 배수가 1보다 크면 나이가 들수록 성공 가능성이 높아지고, 1보다 작으면 낮아지는 것을 의미한다.

### 예측 예시: 36세
- 36을 식에 대입: logit(ŷ) = −4.42 + 0.2096 × 36 = **3.13** (예측 로그 오즈).
- 로그 오즈 3.13을 그래프로 확률로 바꿔 보면 성공 확률은 **약 95%** 로 추정된다.

### 예측 불확실성 밴드
- 적합한 선에는 불확실성이 있으므로 선 주위에 불확실성 밴드(회색 음영)를 만들 수 있다.
- 로그 오즈 척도에서: 데이터가 몰려 있는 곳(평균 나이 약 26세 부근)에서는 밴드가 좁고, 관측이 적은 곳에서는 훨씬 넓다.
- 확률 척도로 되돌리면 밴드는 여전히 곡선이지만 매끄럽지 않다 (선형 척도에서 비선형 척도로 변환했기 때문).
- 최대 나이 부근에서는 예측 확률이 **약 0%에서 약 100%까지** 걸쳐 있어 선의 정확성에 확신이 낮다. 관측이 25개뿐인 것이 한 원인이다.

### 가정과 잔차 플롯의 한계
- 주된 가정: **모형(logit)이 옳다** — 즉 y의 로짓이 나이와 선형으로 연관되어 있다.
- 이 가정은 점검하기 까다롭다. 잔차 플롯(residual plot)으로 점검할 수 있지만:
  - 잔차 = 관측된 성공/실패(y) − 예측 확률. y가 0/1 두 값뿐이므로 주어진 x에서 잔차도 두 값으로 제한된다.
  - 따라서 로지스틱 회귀의 잔차 플롯은 선형회귀만큼 유용하지 않다.
  - x가 넓은 범위의 값을 가지면 더 유익해진다 (이 데이터는 대부분 22~35세로 좁음). 공변량(covariates)이 추가되어도 더 유익한 잔차 플롯을 만들 수 있다.

## 예시
```python
# 강의의 Python 출력 요지 (statsmodels GLM)
# Model family: Binomial, Link function: logit
# 적합 결과:
#   Intercept: -4.42
#   Age:        0.2096

import math

# 적합된 로지스틱 회귀식: logit(p_hat) = -4.42 + 0.2096 * age
def log_odds(age):
    return -4.42 + 0.2096 * age

# 36세의 예측 로그 오즈
print(log_odds(36))          # 약 3.13 -> 확률로 약 95%

# 기울기의 오즈비(odds ratio) 해석: 1살 증가당 오즈가 약 1.23배
print(math.exp(0.2096))      # 약 1.23
```

## 요약
- 이진 반응(0/1)에 선형회귀를 쓰면 확률이 [0, 1]을 벗어난다 (예: 50세의 완수 확률 약 110%).
- 해결책: 성공 확률 p를 로짓 = 로그 오즈 ln(p/(1−p))로 변환해 선형모형을 적합한다. 로짓은 p=0.5에서 0이고 대칭적이며 범위는 −∞ ~ +∞.
- 적합식: logit(ŷ) = −4.42 + 0.2096 × age. GLM(binomial family, logit link), 최대우도추정으로 적합.
- 기울기 해석: 나이 1살 증가당 로그 오즈 +0.2096, 오즈는 e^0.2096 ≈ 1.23배 (곱셈적).
- 확률 척도에서 회귀선은 S자 곡선이며, 로그 오즈 척도에서는 직선이다. 관측 범위 밖 예측은 외삽으로 신뢰할 수 없다.
- 불확실성 밴드는 데이터가 많은 평균 나이 부근에서 좁고 관측이 적은 곳에서 넓다. y가 이진이라 잔차 플롯의 유용성은 제한적이다.
