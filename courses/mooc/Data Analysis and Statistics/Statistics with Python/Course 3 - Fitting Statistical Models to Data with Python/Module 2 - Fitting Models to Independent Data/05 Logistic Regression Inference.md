# Logistic Regression Inference

## 개요
- 로지스틱 회귀(logistic regression)의 기울기(slope)에 대한 추론: 신뢰구간(confidence interval)과 가설검정(hypothesis testing).
- 형식은 선형회귀와 매우 비슷하지만, t 분포 대신 **z 검정통계량(z-test statistic)** 을 사용하고 해석을 로그 오즈(log odds) 맥락으로 바꿔야 한다.
- 카트휠 데이터(성인 25명, 완수=1/미완수=0, 예측변수 나이)로 계산을 진행한다.

## 내용

### 설정
- 이전 강의에서 적합한 로지스틱 회귀선(곡선 형태)은 나이에 따른 카트휠 완수의 예측 확률을 보여준다.
- 이번에는 Python 출력의 계수 외 나머지 열(표준오차, z, p-값, 신뢰구간)을 활용해 추론을 수행한다.

### 기울기의 신뢰구간
- 형식은 이전 코스와 동일: **최선의 추정치(best estimate) ± 오차한계(margin of error)**.
- 로지스틱 회귀에서는 t 분포가 아닌 **z 통계량**을 사용한다:
  - **b₁ ± z\* × SE(b₁)**
- Python 출력에서 값 대입: 추정 계수 b₁ = **0.2096**, 표준오차 = **0.171**, 95% 신뢰수준의 z\* = **1.96**.
  - 0.2096 ± 1.96 × 0.171
- 결과: 신뢰구간은 **(−0.126, 0.545)**.
- 같은 구간이 Python 출력에도 표시된다. 단, **Python 출력은 95% 신뢰구간만 제공**하므로 주의한다.

### 기울기의 가설검정
- 가설:
  - 귀무가설 H₀: β₁ = 0 (모집단/참 기울기가 0)
  - 대립가설: 양측(two-sided) — 나이가 완수 확률에 어떤 방향으로 영향을 주는지 미리 알지 못하므로, 어떤 효과든 있는지만 본다.
- 검정통계량: (최선의 추정치 − 가설값) / 표준오차
  - z = (0.2096 − 0) / 0.171 = **1.225**
  - Python 출력의 z 값과 일치한다.
- p-값: Python 출력이 제공하며 **0.221**.
- 판단 (유의수준 α = 0.05):
  - 0.221 > 0.05 → **귀무가설을 기각하지 못한다(fail to reject)**.
  - 따라서 나이와 카트휠 완수 확률의 로그 오즈 사이에 **유의한 선형 관계가 있다고 결론지을 수 없다**.

### 신뢰구간과 검정 결과의 일치
- 신뢰구간 (−0.126, 0.545)은 **0을 포함**한다. 즉 0이 계수의 그럴듯한(reasonable) 값이다.
- 이는 "기울기가 0과 유의하게 다르다고 결론지을 수 없다"는 가설검정의 결정과 일치한다.

## 예시
```python
# 강의의 손계산을 그대로 재현
b1 = 0.2096      # Python 출력의 나이 계수
se = 0.171       # 표준오차
z_star = 1.96    # 95% 신뢰수준

# 95% 신뢰구간: (-0.126, 0.545)
ci = (b1 - z_star * se, b1 + z_star * se)
print(ci)

# 가설검정 H0: beta1 = 0
z = (b1 - 0) / se
print(z)         # 1.225 -> 양측 p-값 0.221 (Python 출력 제공)
# alpha = 0.05에서 0.221 > 0.05 이므로 귀무가설 기각 실패
```

## 요약
- 로지스틱 회귀 기울기의 신뢰구간: b₁ ± z\* × SE(b₁) — 선형회귀와 형식은 같지만 z 통계량을 쓴다.
- 95% CI = 0.2096 ± 1.96 × 0.171 = (−0.126, 0.545). Python 출력은 95% 구간만 제공한다.
- 검정: z = 0.2096/0.171 = 1.225, 양측 p = 0.221 > α = 0.05 → 귀무가설 기각 실패. 나이와 완수의 로그 오즈 사이 유의한 선형 관계를 결론지을 수 없다.
- CI가 0을 포함하는 것과 검정 결과는 서로 일치한다.
- 해석 시 예측 대상이 로그 오즈(logit)라는 로지스틱 맥락을 반영해야 한다. 다음은 NHANES 데이터(혈압과 흡연) 예제.
