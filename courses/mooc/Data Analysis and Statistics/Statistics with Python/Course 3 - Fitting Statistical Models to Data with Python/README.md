# Fitting Statistical Models to Data with Python

- 전문과정: Statistics with Python (Course 3)
- 제공: University of Michigan
- 링크: <https://www.mooc.org/learn/fitting-statistical-models-data-python>
- 구성: 4개 모듈, 영상 26개 — Transcript 기반 한국어 정리 완료 (2026-07-24)
- 제외: 읽기 자료·퀴즈·Jupyter 실습(Lab)·채점 과제

통계 모델을 데이터에 적합(fitting)하는 과학과 기술을 다루는 코스. 추론(inference)과 예측(prediction)이라는 두 목적을 구분하고, 독립 데이터에는 선형·로지스틱 회귀를, 군집·종단 등 종속 데이터에는 다층 모델(multilevel model)과 주변 모델(marginal model, GEE)을 적용하며, 조사 가중치와 베이지안 접근 같은 특수 주제로 마무리한다.
