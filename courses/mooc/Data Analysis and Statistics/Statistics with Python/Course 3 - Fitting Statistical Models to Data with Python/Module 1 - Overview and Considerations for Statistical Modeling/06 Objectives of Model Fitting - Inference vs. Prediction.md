# Objectives of Model Fitting: Inference vs. Prediction

## 개요
- 모델 적합의 두 가지 주요 목적: 변수 간 관계에 대한 추론(inference)과 미래 결과의 예측(prediction)
- 추론: 회귀 모수의 추정치와 표준오차로 검정통계량(test statistic)을 계산해 모수가 0인지 가설 검정하거나 신뢰구간을 구성
- 예측: 적합된 모델에 예측변수 값을 대입해 예측값을 계산하되, 반드시 예측의 불확실성(uncertainty)을 함께 기술

## 내용

### 두 가지 주요 목적
1. **추론(inference)**: 주어진 데이터셋에서 변수들 사이의 관계에 대해 추론한다.
2. **예측(prediction)**: 과거 데이터로 추정한 모델에 기반해 미래 결과를 예측·전망(forecast)한다. 대중 매체에서 접하는 미래 사건 예측이 모두 통계 모델에 기반한다.

### 예시 모델 복습 — 나이와 시험 성적
- 표준화 나이(standardized age)로 시험 성적(0~8점)을 예측하는 비선형 모델:
  `performance = a + b·age + c·age² + E`
- 회귀 함수(regression function) `a + b·age + c·age²`가 나이의 함수로서 성적의 기대 평균을 정의한다.
- 오차 E = 실제 성적 − 모델 기반 예측 성적이며, 평균 0, 상수 분산 σ²의 정규분포를 따른다.
- 중간 정도의 나이에서 기대 성적이 가장 높은 비선형 관계다.

### 목적 1 — 추론: 모수에 대한 가설 검정
- 나이-성적 관계에 대한 추론은 회귀 모수 a, b, c의 추정치를 살펴보는 것이다.
- 추정치와 표준오차가 있으면 모수가 0인지 가설 검정을 하거나, 신뢰구간에 0이 포함되는지로 예측변수의 중요성을 추론할 수 있다.
- 적합 결과: â = 5.11, b̂ = 0.24, ĉ = −0.26 (각각 표준오차 제시됨).
- 검정통계량 = (모수 추정치 − 0) / 표준오차. 여기서 0은 귀무가설(null hypothesis) 값이다.
- 예: b에 대한 t-통계량 = 0.24 / 0.06 = **4** → 추정된 나이 계수가 귀무가설 값보다 4 표준오차 위에 있다. 귀무가설이 참이라면 이렇게 큰 추정치가 나올 가능성이 매우 낮으므로, b = 0이라는 귀무가설을 기각하고 유의(significant)하다고 결론짓는다.
- a와 c도 같은 방식으로 검정통계량을 계산하며, 모두 매우 커서 각 모수가 0이라는 귀무가설이 강하게 기각된다 → 나이와 성적의 관계는 유의하다.
- 만약 b와 c가 모두 0과 다르지 않다면 나이는 성적과 관계가 없다고 추론했을 것이다.

### 각 모수의 해석
- **a = 5.11 (SE 0.10)**: 나이가 데이터셋의 전체 평균 나이일 때(표준화 나이 = 0)의 평균 시험 성적. 평균 나이인 사람들의 평균 성적은 5.11점이고 0과 유의하게 다르다.
- **b = 0.24**: 표준화 나이가 0일 때 성적의 기대 증가율(expected rate of increase). age²이 모델에 포함되어 포물선(parabola)으로 정의되는 이차 관계이기 때문에 이런 특별한 해석을 갖는다. 양수이고 유의하므로 초기 증가율이 유의하게 양(+)이다.
- **c = −0.26 (SE 0.03)**: 나이의 함수로서 성적의 비선형 가속(non-linear acceleration)을 나타내며 비선형 관계의 정도를 포착한다. 음수라는 것은 초기 가속 이후 나이가 더 들수록 성적이 감소함을 뜻하고, 이 비선형 측면은 0과 유의하게 다르다.
- 만약 c가 0과 유의하게 다르지 않았다면 모델은 `a + b·age`(절편과 기울기)로 정의되어, 성적과 나이의 관계가 순수하게 선형(strictly linear)이라는 증거가 되었을 것이다. 여기서는 명백히 그렇지 않다.

### 목적 2 — 예측
- 적합된 회귀 모델: `performance = 5.11 + 0.24·age − 0.26·age² + E`
- 나이 값을 대입해 성적 예측값을 계산할 수 있고, 산점도의 점선(dashed red line)이 나이의 함수로서 기대 성적을 보여준다.
- IVQ 예시: 표준화 나이 = +1일 때의 예측 성적
  - 5.11 + 0.24×1 − 0.26×1² = **5.09점**
  - 이 값은 플롯의 적합선 위 해당 위치와 일치한다.

### 예측 불확실성
- 오차를 잊으면 안 된다 — 모든 예측에는 불확실성이 따른다. 적합된 모델이 관계를 잘 기술하지 못할수록 불확실성이 커진다.
- 나이를 예측변수로 넣지 않은 단순 모델이라면 나이에 상관없이 모두에게 같은 예측(종속변수의 전체 평균)을 하게 되고, 그 예측의 불확실성은 더 크다.
- 평균을 정의하는 데 예측변수를 포함하면 불확실성이 줄어 더 정밀한 예측을 얻는다.
- 평균 외의 것도 예측할 수 있다. 예: 95번째 백분위수(95th percentile).
- 핵심: 적합된 모델로 예측을 할 때는 항상 그 예측에 수반되는 불확실성을 함께 기술해야 한다. 실제 관측값은 예측값 주위에서 흔들리기 때문이다.

### 다음 강의 예고
- 다양한 종속변수에 모델을 적합할 때 모수 추정치를 계산하는 방법.
- 가설 검정, 신뢰구간 구성, 추론과 예측의 상세한 방법.
- 모델 적합 후에는 항상 전체 적합 품질(quality of model fit)을 평가해야 한다.
- 모델 기반 추론의 학파 차이: 빈도주의 추론(Frequentist Inference) vs 베이지안 추론(Bayesian Inference).

## 예시

적합된 모델로 표준화 나이 +1의 성적을 예측하는 계산:

```python
a, b, c = 5.11, 0.24, -0.26
age = 1
predicted = a + b * age + c * age**2
print(predicted)  # 5.09
```

b에 대한 검정통계량:

```python
b_hat, se_b = 0.24, 0.06
t_stat = (b_hat - 0) / se_b
print(t_stat)  # 4.0 -> 귀무가설(b = 0) 기각
```

## 요약
- 모델 적합의 목적은 관계에 대한 추론과 미래 결과의 예측, 두 가지다.
- 추론은 검정통계량 = (추정치 − 0)/표준오차로 모수의 유의성을 판단한다. 예: b의 t-통계량 = 0.24/0.06 = 4.
- a는 평균 나이에서의 평균 성적(5.11), b는 표준화 나이 0에서의 증가율(0.24), c는 비선형 가속(−0.26)을 나타낸다.
- c가 유의하지 않았다면 관계는 선형이라는 증거가 된다.
- 예측은 모델에 값을 대입해 계산하되(예: age=1 → 5.09점), 반드시 예측 불확실성을 함께 기술한다.
- 예측변수를 포함하면 예측 불확실성이 줄어든다.
