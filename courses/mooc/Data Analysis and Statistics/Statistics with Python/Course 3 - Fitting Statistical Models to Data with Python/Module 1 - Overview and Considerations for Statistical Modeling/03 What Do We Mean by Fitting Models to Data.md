# What Do We Mean by Fitting Models to Data?

## 개요
- "데이터를 모델에 맞추는 것"이 아니라 "모델을 데이터에 적합(fitting models to data)"하는 것 — 이론·주제 지식에 기반해 모델을 설정하고 수집한 데이터에 적합한다
- 모델 적합의 목적: 분포 특성 추정, 변수 간 관계 요약과 추론(inference), 예측(prediction)과 예측 불확실성의 정량화
- 이 코스의 초점은 모수적 모델(parametric model) — 분포를 정의하는 모수(parameter)를 추정하고 그에 대해 추론한다
- 시험 성적과 나이의 곡선형 관계(curvilinear relationship) 예시로 평균만 있는 모델과 조건부 모델을 적합하고, 잔차(residual)로 모델 적합도를 평가한다

## 내용

### 모델을 데이터에 적합한다는 것
- 목표는 수집한 데이터에 통계 모델을 적합해 연구 질문(research question)에 답하는 것이다.
- 데이터를 모델에 맞추는 것이 아니다. 이론이나 주제 지식(subject matter knowledge)에 근거해 모델을 설정(specify)하고, 그 모델을 데이터에 적합한다.
- 핵심 아이디어: 데이터셋의 변수들은 어떤 분포를 따르거나 어떤 관계를 갖고 있으며, 적합하는 모델이 그 분포와 관계를 기술한다.

### 왜 모델을 적합하는가
1. **분포 특성 추정**: 변수의 평균(mean), 분산(variance), 분위수(quantile) 등 분포 특성을 — 경우에 따라 다른 변수 값에 조건부(conditional)로 — 추정한다.
2. **관계 요약과 추론**: 변수 간 관계를 간결하게 요약하고 그 관계에 대해 추론적 진술(inferential statement)을 한다. 예: 특정 예측변수(predictor)와 종속변수(dependent variable)의 관계.
3. **예측**: 다른 예측변수 값에 조건부로 관심 변수의 값을 예측하고, 그 예측의 불확실성(uncertainty)을 기술한다. 선거·스포츠·날씨·주식 예측이 모두 통계 모델에 기반한다.

### 모수적 모델(parametric model)
- 이 코스의 초점은 모수적 모델: 관심 변수의 분포를 기술하는 모수를 추정한다.
- 예: 혈압이나 시험 성적 같은 연속변수가 정규분포(normal distribution)를 따른다고 가정하면, 그 분포는 평균과 분산이라는 두 모수로 정의된다.
- 모델의 모수와 그 추정치의 표본 분산(sampling variance)을 추정하고, 이를 바탕으로 모수에 대한 추론 — 신뢰구간(confidence interval) 구성, 가설 검정(hypothesis testing) — 을 수행한다(코스 2 내용의 확장).

### 예시 설정 — 시험 성적과 나이
- 관심 변수: 대학생의 시험 성적(test performance), 0~8점 범위.
- 예측변수: 표준화한 나이(standardized age, 평균과 표준편차로 표준화).
- 작업 이론(working theory): 나이와 성적은 곡선형 관계(curvilinear relationship) — 나이가 중간(평균·중앙값 부근)일 때 성적이 가장 좋고, 나이가 매우 적거나 많으면 성적이 낮다.
- 목표: (1) 나이에 무관한 성적의 주변 평균(marginal mean) 추정, (2) 나이에 조건부인 평균 성적 추정.

### 데이터의 기술적 탐색
- 200개 관측치를 수집해 히스토그램(histogram)과 정규 Q-Q 플롯(normal quantile-quantile plot)으로 성적의 주변 분포를 살핀다.
- 히스토그램은 대략 정규 형태, Q-Q 플롯의 값들이 45도 직선 위에 놓여 정규분포가 합리적 모델임을 시사한다.
- 산점도(scatter plot, y축: 성적, x축: 표준화 나이 약 -3~4)를 그리면 역 U자 형태(inverse U-shaped)가 보여, 곡선형 관계 이론이 기술적으로(descriptively) 지지된다.

### 평균만 있는 모델(mean only model) 적합
- 회귀 모델: `performance = M + E`
  - M: 나이에 무관한 성적의 주변 평균(추정할 미지 상수)
  - E: 개별 관측치가 전체 평균에서 벗어나는 정도를 나타내는 무작위 오차(random error)로, 평균 0, 분산 σ²의 정규분포를 따른다고 가정
- 적합 결과:
  - 주변 평균 추정치 M̂ = 4.57점 (표준오차 standard error 0.10) → 추정치/표준오차 비를 생각하면 평균이 0이라는 귀무가설은 기각되어 평균은 명백히 0이 아님
  - 분산 추정치 σ̂² = 1.82

### 평균만 있는 모델의 적합도 평가
- 오차의 정규성 가정을 잔차(residual)로 확인한다. 잔차 = 관측 성적 − 모델이 정의한 전체 평균 추정치.
- 잔차의 히스토그램과 정규 Q-Q 플롯이 처음의 기술적 플롯과 매우 비슷해 정규성 가정이 타당해 보인다.
- 정규 모델이 부적합했다면 잔차에서 정규분포로부터의 큰 이탈이 보였을 것이다 — 이것이 모델 적합도 확인(checking model fit)의 예다.

### 조건부 모델(conditional model) 적합
- 회귀 모델: `performance = a + b·age + c·age² + E`, 오차 E ~ N(0, σ²)
- a, b, c는 회귀계수(regression coefficients)로 나이와 성적의 관계를 기술하며, 이차 함수(quadratic function)가 곡선형 관계 이론을 담아낸다.
- 적합 결과(추정치와 표준오차):
  - â = 5.11 (SE 0.10): 표준화 나이가 0(=평균 나이)일 때 기대 성적 5.11
  - b̂ = 0.24 (SE 0.06): 이차 관계의 선형 부분
  - ĉ = −0.26 (SE 0.03): 나이에 따른 성적의 가속/감속(acceleration/deceleration)
  - 추정치/표준오차 비율을 보면 모두 0이 아닌 것으로 보인다(가설 검정의 예고편).
  - σ̂² = 1.29: 나이에 조건부인 분산(conditional variance) — 나이를 조건으로 한 뒤 남는 설명되지 않은 변동

### 조건부 모델의 적합도 평가
- 적합된 이차 함수의 예측값(점선)이 산점도에서 곡선형 관계를 잘 따라가 시각적으로 좋은 적합이다.
- 잔차의 Q-Q 플롯: 정규분포 가정에 부합.
- 잔차 vs 예측값 산점도: 잔차가 0을 중심으로 대체로 대칭이고, 예측값에 관계없이 퍼짐이 일정(constant variance)해 등분산 가정에 부합한다.
- 남은 질문: 더 잘할 수 있는가? 인종/민족(race ethnicity), 교육 수준, 사회경제적 지위(socioeconomic status) 같은 사회인구학적 예측변수를 추가하면 잔차에 남아 있는 변동을 더 설명할 수 있을지 이 코스에서 살펴본다.

### 잘못 설정된 모델(misspecified model)의 예
- 이론에 신중하지 못해 나이와 성적의 관계를 선형(linear)으로 가정하면:
  - 적합선이 산점도와 잘 맞지 않아 적합이 나빠 보인다.
  - 잔차가 0을 중심으로 대칭적으로 흩어지지 않고, 잔차와 예측값 사이에 곡선형 패턴이 남는다.
  - 표준화 나이가 아주 작거나 클 때 예측이 매우 나쁘다.
- 이렇게 잔차의 패턴이 모델 설정 오류(misspecification)를 드러낸다.

## 요약
- 모델 적합은 이론에 근거해 설정한 모수적 모델을 데이터에 적합해 분포 특성 추정, 관계 추론, 예측을 수행하는 것이다.
- 평균만 있는 모델(M̂ = 4.57, σ̂² = 1.82)과 나이의 이차 함수 조건부 모델(â = 5.11, b̂ = 0.24, ĉ = −0.26, σ̂² = 1.29)을 비교했다.
- 예측변수를 조건으로 하면 조건부 분산이 줄어든다(1.82 → 1.29).
- 모델 적합 후에는 반드시 잔차의 히스토그램·Q-Q 플롯·잔차 vs 예측값 플롯으로 적합도를 평가한다.
- 잘못 설정된 모델은 잔차에 체계적 패턴(예: 곡선형)을 남긴다.
- 이번 주에는 변수 유형, 연구 설계별 데이터 유형과 모델링 함의, 추정·추론 접근을 이어서 다룬다.
