# Fitting Statistical Models to Data with Python Guidelines

## 개요
- 코스를 효과적으로 학습하기 위한 가이드라인을 안내하는 강의
- 선수 지식: 앞선 두 코스(데이터 시각화·관리, 추론 통계) 수준의 Python 활용 능력을 전제
- 핵심 메시지: "통계를 제대로 배우는 유일한 방법은 직접 해보는 것" — 강의를 보면서 Jupyter 노트북으로 병행 실습할 것

## 내용

### 코스의 전제와 목표
- 이 코스는 전문과정의 앞선 두 코스(Understanding and Visualizing Data with Python, Inferential Statistical Analysis with Python)의 내용 위에 세워진다.
- 수강자가 Python으로 데이터를 시각화·관리할 수 있고, 데이터의 출처를 이해하는 것의 중요성을 알며, 가설 검정(hypothesis testing)과 기본 기술 분석(descriptive analysis)에 익숙하다고 가정한다.
- 목표는 데이터에 적합한 통계 모델(statistical model)을 바탕으로 변수 간 관계에 대해 추론(inference)하는 법을 배우는 것이다.

### Jupyter 노트북 활용
- 강의에서 다룬 개념을 Python으로 시연하기 위해 Jupyter 노트북을 집중적으로 사용한다.
- 각 주차 강의 뒤에 두 종류의 노트북이 제공된다:
  - 사례 연구 노트북(case study notebooks): 예제를 단계별로 안내
  - 연습 노트북(practice notebooks): 직접 모델을 적합해보는 실습

### 가이드라인 1 — 강의와 노트북 병행 실습
- 강의 영상을 열어 둔 채(다른 모니터 또는 같은 기기에서) 노트북의 모델 적합 예제를 함께 진행할 것을 강력히 권장한다.
- 영상을 자주 일시정지하고 예제 노트북에서 모델을 직접 적합해 개념을 강화한다.
- 강사가 인용한 University of Bath의 Julian Faraway 교수의 교훈: "통계를 제대로 배우는 유일한 방법은 실제로 해보는 것이다." 노트북과 퀴즈는 이 연습을 위해 설계되었다.

### 가이드라인 2 — 영상 내 질문(IVQ) 활용
- 강의 개념을 강화하기 위한 영상 내 질문(in-video questions, IVQs)이 준비되어 있다.
- IVQ는 출력(output)과 결과 해석을 추가로 연습하게 해 주며, 개념이 불분명하면 상세 해설을 주의 깊게 볼 것.

### 가이드라인 3 — 토론 포럼 활용
- 질문이 생기면 바로 올리고, 자주 묻는 질문(FAQ) 아카이브와 토론 포럼(discussion forums)을 자주 확인한다.

### 추가 자료와 베이지안 분석 안내
- 준비된 추가 읽기 자료와 리소스를 활용한다.
- 마지막 주에는 베이지안 통계 분석(Bayesian statistical analysis)을 소개하는데, 이 전문과정에서 가장 수준 높은 내용이며 기존 접근과 다르므로, 시작 전에 베이지안 분석 개요 블로그 글을 먼저 읽을 것을 강력히 권한다.
- 질문·의견·피드백은 토론 포럼과 강사에게 자유롭게 전달한다.

## 요약
- 앞선 두 코스의 Python·통계 지식을 전제로 모델 기반 추론을 배운다.
- 강의 영상을 자주 멈추고 사례 연구·연습 노트북에서 직접 모델을 적합하며 학습한다.
- IVQ와 상세 해설, 토론 포럼, 추가 읽기 자료를 적극 활용한다.
- 마지막 주의 베이지안 분석은 사전 개요 자료를 먼저 읽고 시작한다.
