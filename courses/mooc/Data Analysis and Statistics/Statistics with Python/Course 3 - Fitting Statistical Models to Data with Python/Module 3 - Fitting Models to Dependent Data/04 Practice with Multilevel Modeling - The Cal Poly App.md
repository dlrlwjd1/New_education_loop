# Practice with Multilevel Modeling: The Cal Poly App

## 개요
- Cal Poly 통계학과(Jimmy Wong 설계)가 만든 웹 애플리케이션으로 다층 모델(multilevel model)의 핵심 개념을 시각적으로 연습하는 강의다.
- 통합(pooled) 방법 vs 비통합(unpooled) 방법 vs 다층 모델의 절충 관계를 보여준다.
- 음악 전공생 수행 불안 데이터로 임의절편(random intercept) 모델과 임의기울기(random slope) 모델을 적합하고 급내상관계수(ICC) 등을 확인한다.

## 내용

### 앱 소개와 핵심 개념
- 앱에서는 다층 모델링을 **위계적 모델링(hierarchical modeling)** 이라 부른다 — 위계적 선형 모델(hierarchical linear model)이라고도 불리는 같은 개념이다.
- **통합(pooled) 방법**: 모든 데이터를 함께 분석하고 군집의 임의효과를 명시적으로 반영하지 않는다 — 모두가 같은 일반적 효과를 따른다고 가정.
- **비통합(unpooled) 방법**: 모든 군집마다 명시적 고정효과를 넣는다. 즉 각 군집에 대해 별도의 분석을 수행.
- **다층 모델**은 이 두 접근(상위 수준 단위 효과를 완전히 무시 vs 각 단위마다 별도 분석)의 **절충(compromise)** 이다.
- 앱이 강조하는 개념: 군집들 간 정보를 **빌려오는 것(borrowing strength)** 과 **수축(shrinkage)** — 작은 군집의 추정치는 전체 모델 추정치에 큰 영향을 주지 않는다.
- 용어: 수준 1(level 1) 단위 = 최하위 수준에서 관측된 단위, 수준 2(level 2) 단위 = 수준 1 단위가 중첩된(nested) 상위 그룹.

### 데이터셋 — 음악 전공생 수행 일지
- 내장 데이터셋은 동료심사 논문에서 나온 것으로, 학부 음악 전공생 **37명**이 한 학년 동안 수행 일지(performance diaries)를 작성했다.
- 각 공연 전에 PANAS(positive affect, negative affect schedule)를 작성해 두 변수를 측정:
  - **부정 정서(negative affect)**: 공연 전 불안(anxiety)의 측정치
  - **긍정 정서(positive affect)**: 행복(happiness)의 측정치
- 다층 구조: 음악가(ID)가 **수준 2 단위**, 각 ID에서 수집된 여러 일지 측정치가 **수준 1 관측치**.
- 분석의 종속변수는 부정 정서이며, 음악가 특성과 공연 특성(공연 유형, 청중 등)으로 예측하는 다층 모델을 개발한다.
- 자기 데이터를 업로드(콤마/탭 구분)해 종속변수, 수준 2 군집 ID, 수준 1 예측변수 등을 직접 지정해 모델을 적합할 수도 있다.

### 사례 연구(case studies) 세 가지
1. **임의절편(random intercepts)**: 상위 군집마다 고유한 절편만 허용.
2. **변동 절편 + 변동 기울기(varying intercepts and varying slopes)**: ESS 예시에서처럼 절편과 특정 예측변수의 기울기가 모두 임의로 변하는 임의계수 모델.
3. **변동 절편·기울기 + 상위 수준 예측변수**: 음악가의 특성 같은 상위 수준 예측변수로 임의절편·기울기의 변동을 설명.

### 임의절편 모델 살펴보기
- **Pooled 탭**: 임의 음악가 효과를 무시하고 모든 수준 1 관측치를 합친(pooling) 종속변수 히스토그램에 통합 평균(pooled mean, 세로 점선)이 표시된다. 전체 평균은 약 **16.2**.
- **Unpooled 탭**: 음악가별로 별도의 박스플롯이 그려진다. 음악가 간에 공연 전 부정 정서의 변동이 매우 크다 — 평균이 훨씬 높은 사람, 낮은 사람, 변동이 큰 사람이 보인다. 임의효과 접근이 타당함을 시각적으로 보여준다. 아래 표에서 음악가별 평균, 분산, 표본 크기도 확인 가능.
- **Hierarchical linear model 탭**:
  - 모델 식: 평균이 임의절편과 고정효과로 정의된다. 임의계수는 전체 평균 mu_alpha와 임의효과 eta_j로 정의된다(표기만 다르고 개념은 동일). 다층 명세와 단일 수준 식(single level equation)을 전환해 볼 수 있고, 임의오차와 임의효과의 분포 정의(추정할 두 분산성분)도 명확히 보여준다.
  - **캐터필러 플롯(caterpillar plot)**: 각 임의효과의 분포와 표집분산을 보여주어 그룹(음악가) 간 변동을 시각화한다.
  - 음악가별 평균들의 히스토그램과 전체 평균도 볼 수 있다.
  - **급내상관계수(intraclass correlation coefficient, ICC)**: 분산성분들의 함수로 계산되는 개인 내 상관. 같은 음악가 내 부정 정서 관측치들의 추정 상관은 약 **0.181** — 같은 음악가에 중첩된 두 관측치 간에 꽤 강한 상관이 있다.
  - **HLM 출력 탭**: 예측변수가 없는 모델에서 고정 절편(전체 평균) 약 **16.2**, 임의 음악가 효과의 분산 약 **4.95**, 잔차 분산 약 **22.46**.

### 예측변수 추가와 수렴 문제
- Analyze data 탭에서 모델을 커스터마이즈할 수 있다. 예로 수준 1 예측변수인 공연 유형(performance type)을 추가하면 출력이 갱신되어 그 고정효과 추정치가 나타난다.
- 이 경우 **수렴(convergence) 경고 메시지**가 나온다 — 최대우도추정이 해에 수렴하지 않아 추정치를 신뢰할 수 없으며, 시도해 볼 만한 제안들이 표시된다.

### 임의기울기 추가
- 변동 절편·기울기 사례 연구에서, 예측변수 previous와 부정 정서의 관계를 본다.
  - **Pooled**: 모든 데이터를 합친 산점도에서는 강한 관계가 보이지 않는다.
  - **Unpooled**: 음악가마다 별도의 회귀선이 그려지고, 이 관계에 음악가 간 변동이 있음이 드러난다 — previous와 부정 정서의 관계가 음악가에 따라 달라지도록 두 번째 임의효과(임의기울기)를 추가할 시각적 동기.
- 모델 식 탭에서 임의계수 두 개(절편 alpha_j, 기울기 beta_j)에 대한 수준 2 식, 임의효과의 가정 분포, 추정할 두 분산성분, 수준 1 오차 분산을 확인할 수 있다.
- HLM 출력: 예측변수의 고정효과 추정치는 약 **-0.11**로 0.05 수준에서 유의하지 않다 — 평균적으로 강한 효과는 없어 보인다. 임의기울기의 분산은 **0.07816**이며, 이 분산이 유의한지는 우도비 검정(likelihood ratio test)으로 확인할 수 있다.

### 앱의 가치
- 기저 방정식을 보여주고, 데이터를 시각화하고, 모델을 자동으로 적합해 출력을 생성하며, 무료로 공개되어 있다. 이번 주 웹 링크에서 직접 다양한 모델, 예측변수, 종속변수를 시도해 보며 다층 모델의 작동을 익힐 수 있다.

## 예시
- 음악가 데이터의 임의절편 모델 추정 결과 (예측변수 없음):
  - 전체 평균(고정 절편) ≈ 16.2
  - 임의 음악가 효과 분산 ≈ 4.95
  - 잔차 분산 ≈ 22.46
  - ICC ≈ 0.181
- 임의기울기 모델: previous의 고정효과 ≈ -0.11 (비유의), 임의기울기 분산 ≈ 0.07816

## 요약
- 다층(위계적) 모델은 통합(pooled)과 비통합(unpooled) 분석의 절충으로, 정보 빌려오기(borrowing strength)와 수축(shrinkage)이 특징이다.
- 음악가 37명의 수행 일지 데이터에서 일지 측정치(수준 1)가 음악가(수준 2)에 중첩된 구조를 다층 모델로 분석한다.
- 임의절편 모델에서 ICC ≈ 0.181 — 같은 음악가 내 관측치 간 상관이 상당하다.
- unpooled 시각화(음악가별 박스플롯·회귀선)는 임의절편·임의기울기를 추가할 시각적 동기를 제공한다.
- 예측변수 추가 시 수렴 실패가 발생할 수 있으며, 그 경우 추정치를 신뢰하면 안 된다.
