# Marginal Logistic Regression

## 개요
- 이진 종속변수(binary dependent variable)를 위한 주변 로지스틱 회귀(marginal logistic regression)를 GEE로 적합하는 방법을 다룬다.
- 이진 변수는 평균과 분산이 모두 지정한 모델로 정의되므로, GEE에서 남는 일은 작업 상관 구조(working correlation structure) 선택이다.
- NHANES 흡연 예시를 GEE로 재분석해 다층 모델과 고정효과 추정치·표준오차가 매우 유사함을 확인한다.

## 내용

### 주변 모델링 복습
- 주변 모델에서는 관심 계수의 군집 간 분산(between-cluster variance)에 대한 추론에 명시적 관심이 없다.
- GEE는 군집 표집(cluster sampling)이나 반복 측정으로 생긴 군집 내 종속성을 반영하며 주변 회귀모델을 추정하는 일반적 기법이다.
- 이 강의의 관심은 예측변수와 이진 종속변수 사이의 **모집단 평균(population averaged) 주변 관계** — 모든 군집에 걸친 전체 관계다.

### 이진 결과변수를 위한 주변 모델
- GEE 방법은 Liang과 Zeger 등이 **종단적으로 측정된 비정규 결과변수**를 쉽게 수용하도록 설계했다 — 같은 피험자의 반복 측정치가 상관될 것으로 보는 경우.
- 추정방정식의 평균 구조는 해당 일반화 선형모델(generalized linear model) 유형으로 정의된다.
- 로지스틱 회귀의 경우, 종속변수의 평균은 종속변수가 1일 확률(비율)이다. GEE 표기로는 시점 t, 개인 i의 mu_ti = pi_ti = E(y | x_ti), 즉 예측변수 값이 주어졌을 때 종속변수의 기댓값이다.
- **로짓 링크(logit link)** 를 쓰는 로지스틱 회귀에서는 종속변수가 1일 확률을 **역로짓(inverse logit) 함수**로 쓴다:
  - P(y=1) = exp(선형결합) / (1 + exp(선형결합)) — 선형결합은 예측변수와 회귀모수의 결합.
  - 이렇게 베타 모수가 추정방정식에 들어오고, 점수함수(score function)를 푸는 모수 값을 찾는다.

### 이진 변수의 분산과 작업 상관 구조
- 베르누이 분포(Bernoulli distribution)를 따르는 0/1 확률변수의 분산은 **P(1) × (1 - P(1))**, 즉 평균 × (1 - 평균)이다.
- 따라서 확률 모델을 쓰는 순간 **평균 모델과 분산 모델이 동시에 정해진다**.
- GEE에서 우리가 할 일은 **작업 상관 구조 선택**뿐이다. 군집화된 이진 관측치(군집 표집 또는 반복 측정)에 가장 타당한 구조를 고른다 — 교환가능(exchangeable), 1차 자기회귀(first-order autoregressive), 비구조화(unstructured), 독립(independence) 중 어느 것이 가장 좋은 적합을 주는지 찾는다.

### NHANES 흡연 예시 — GEE 재분석
- 종속변수: 평생 담배 100개비 이상 흡연 지표(lifetime smoking indicator).
- 다층 접근에서는 NHANES 표집 군집 간 흡연율 변동의 증거를 발견했다 — 군집 내 종속성의 증거. 주변 접근에서도 같은 증거가 보이는지 확인한다.
- 임의효과를 포함하지 않는 모집단 평균 모델을 GEE로 적합해 추론이 달라지는지 검토한다.
- **결과 (다층 vs GEE 고정효과 추정치 비교 표)**:
  - 남성(male), 나이(age), 백인/흑인/기타 인종, BMI, 가구 크기(household size), 가구소득 대비 빈곤 비율(family income to poverty ratio) 등 예측변수들의 회귀모수 추정치가 두 접근에서 매우 유사하다.
  - 유의한 모수(표의 별표): 남성이면 흡연 확률이 상당히 높아지고, 나이가 많을수록 흡연 확률이 높다. 가구 크기가 클수록, 소득 대비 빈곤 비율이 높을수록 흡연 확률이 낮다(음의 고정효과).
  - 군집화를 반영하는 **표준오차도 두 접근에서 매우 유사**하다.
  - 차이점: 다층 모델은 임의 군집효과의 분산성분(표에는 미표시)을 추가로 가지며 군집효과를 명시적으로 통제한다. GEE는 군집 내 상관을 반영하는 작업 상관 구조만 지정한다.

### 모델 진단
- 교환가능 상관 구조를 가정했을 때 표집 군집 내 성가심(nuisance) 상관 추정치는 **0.01**에 불과했고, 이 모델의 QIC는 **628.534**.
- 비구조화·1차 자기회귀 구조는 여기서 타당하지 않다 — NHANES는 횡단(cross-sectional) 지역 표집 군집이라 군집 내 관측치에 시간 순서가 없다.
- **독립 모델**(군집 내 상관 0 가정)의 QIC는 **628.054**로 교환가능 구조보다 **더 작다** — 같은 표집 군집 내 관측치들이 강한 상관을 갖지 않는다는 증거.
- 결론: 이 주변 모델에서 상관은 상당히 약하고, 이를 반영해도 모델 적합이 크게 개선되지 않는다.

### 결론
- 주변적으로(표집 군집 전체에 걸친 모집단 평균 관계) 보나 다층 모델로 보나, **본질적으로 같은 고정효과 추정치**를 얻고 평생 흡연 행동 예측변수들의 중요성에 대해 매우 유사한 결론에 도달한다.
- 다층 접근에서는 군집 간 분산의 증거가 있었지만, 군집 내 상관 자체는 크지 않았다.
- 주변 모델링에서는 추정된 고정효과를 **군집에 걸쳐 주변적으로(marginally across clusters)** 해석한다 — 특정 표집 군집에 조건을 두지 않고, 모든 군집에 걸쳐 예측변수 값이 변할 때 무슨 일이 일어나는지 말한다.

## 요약
- 주변 로지스틱 회귀에서 평균은 역로짓 함수 P(y=1) = exp(Xb) / (1 + exp(Xb))로 정의되고, 베르누이 분산은 평균 × (1 - 평균)으로 자동 결정된다 — GEE에서 남는 선택은 작업 상관 구조다.
- NHANES 흡연 재분석: 다층 vs GEE의 고정효과 추정치와 표준오차가 매우 유사 — 남성·나이는 양의 효과, 가구 크기·소득 대비 빈곤 비율은 음의 효과.
- 교환가능 구조의 군집 내 상관 추정치는 0.01로 약했고, 독립 모델의 QIC(628.054)가 교환가능(628.534)보다 작아 군집 내 상관 반영이 적합을 개선하지 못했다.
- 주변 모델의 고정효과는 항상 군집에 걸친 모집단 평균으로 해석하며, 군집 간 분산에 대한 추론은 하지 않는다.
