# Multilevel Logistic Regression models

## 개요
- 이진 종속변수(binary dependent variable)를 위한 다층 로지스틱 회귀모델(multilevel logistic regression model)을 다룬다.
- 로짓 링크(logit link)에 임의효과(random effect)를 결합하며, 비정규(non-normal) 결과변수에서는 우도(likelihood)를 근사한 뒤 최대화해야 해 계산이 훨씬 어렵다.
- NHANES 흡연 데이터에 임의절편 모델을 적합해, 군집화를 무시했을 때 표준오차가 과소평가되는 문제를 확인한다.

## 내용

### 모델 작성
- 이진 종속변수 y(군집 j 안의 사람 i에서 측정)가 1일 확률의 **로짓(logit)**, 즉 자연로그 오즈(log odds)를 모델링한다: logit(P(y_ij = 1)) = log(P / (1-P)).
- 다층 명세에서 이 로짓은 다음의 결합으로 정의된다.
  - **고정효과(fixed effects)**: 예측변수와 로그 오즈의 관계를 나타내는 고정 미지 상수 모수.
  - **임의효과(random effects)**: 같은 상위 군집 j 내의 종속성을 포착. u_0j는 군집마다 고유한 절편을, u_1j는 군집마다 x와 로그 오즈의 고유한 관계(기울기)를 허용하는 임의계수 모델(random coefficient model)이다.
- 분포 가정은 다층 선형 회귀와 동일: 임의효과는 평균 벡터 0의 정규분포를 따르고 고유한 분산·공분산을 가진다.
- 다층 모델을 쓰는 이유도 동일: 군집 간 분산(between-cluster variance) — 여기서는 종속변수가 1일 로그 오즈의 군집 간 분산 — 추정이 연구 질문의 명시적 부분이어야 한다.

### 추정의 어려움
- 비정규 결과변수에 임의효과를 포함한 일반화 선형모델(generalized linear model)을 적합하면 수학적으로 추정이 훨씬 어려워진다.
- 우도함수(likelihood function)를 명시적으로 쓰기 어렵고, 닫힌 형태 해(closed form solution)가 없을 수 있다.
- 실무 절차: (1) 수학적 방법으로 우도함수를 **근사(approximate)** 하고, (2) 그 근사 우도를 최대화하는 모수 추정치(고정효과, 분산, 공분산)를 찾는다. 결과적으로 계산 시간이 더 오래 걸린다.
- 한 가지 방법이 **적응적 가우스 구적법(Adaptive Gaussian Quadrature)** 이다. 이번 주 심화 읽기 자료(Kim et al.)의 시뮬레이션 연구에 따르면 특히 작은 표본에서 다양한 시나리오에 걸쳐 대체로 잘 작동한다.

### 모수 검정
- 신뢰구간 계산과 가설검정이 가능하다. 고정효과가 0이라거나 분산성분이 0(임의효과가 변하지 않음)이라는 귀무가설을 **우도비 검정(likelihood ratio testing)** 으로 검정한다.
- 다층 선형 모델과 같은 우도비 검정 접근을 쓰되, 군집 수와 군집당 관측 수가 충분히 커야 한다.

### NHANES 흡연 예시 — 왜 군집을 반영해야 하나
- 2주차에 "평생 담배 100개비 이상 흡연 여부" 확률을 예측변수들의 함수로 모델링하는 로지스틱 회귀를 적합했고, 그때는 모든 NHANES 관측치가 독립이라고 가정했다.
- 실제로는 NHANES가 **다단계 확률표집(multistage probability sampling)** 을 사용해 표집 군집(지리적 지역)을 여러 단계로 무작위 선택했으므로, 같은 군집에 속한 사람들의 흡연 지표 관측치는 상관될 수 있다.
- 흡연 관측치가 지역 내에서 상관되어 있다면, 2주차의 순진한(naive) 로지스틱 회귀의 **표준오차는 과소평가(understated)** 되었을 가능성이 크다 — 군집 내 상관이 추정치의 표집분산(sampling variance)을 키우기 때문이다.
- 임의 군집효과 포함은 이를 반영하는 한 방법이며, 일반적으로 표준오차가 커져 연구 설계를 정확히 반영하게 된다. 또한 표집 군집 간 흡연 확률의 분산 자체에 명시적 관심이 있을 수도 있다.
- 시각화: 각 막대가 NHANES 표집 군집 하나이고 높이가 그 군집에서 100개비 이상 흡연자 비율인 그래프를 보면, 군집마다 비율이 크게 출렁인다 — 군집 간 분산의 시각적 증거.

### 다층 로지스틱 모델 적합 결과
- 무작위 표집된 NHANES 군집의 임의효과를 포함하되, 이 예시에서는 **임의절편(random intercept)만** 허용하고 임의기울기는 고려하지 않는다 — 모든 예측변수의 계수는 군집에 걸쳐 상수로 가정.
- 결과:
  - 어떤 예측변수가 유의한지는 2주차(임의효과 미반영)와 매우 유사하고, 고정효과 추정치도 약간만 달라진다.
  - **핵심 차이**: 고정효과 추정치의 표준오차가 더 커졌다 — 임의효과가 포착하는 군집 간 변동이 표집분산에 반영되기 때문.
  - 임의 군집절편의 추정 분산은 **0.046**. 커 보이지 않지만 우도비 검정 결과 분산이 0이라는 귀무가설을 기각 — 모든 공변량을 포함한 후에도 절편의 군집 간 변동이 존재한다는 강한 증거이며, 임의 군집효과 포함이 모델 적합에 중요한 기여를 한다.

### 모델 진단
- 단순 로지스틱 회귀에서는 잔차를 걱정할 필요가 없다 — 종속변수의 분산이 평균으로 정의되기 때문(2주차 내용).
- 대신 임의효과의 예측값(EBLUP) 분포를 본다. 임의절편 EBLUP의 정규 QQ 플롯에서 점들이 45도 선 위에 놓여 정규분포를 따르는 것으로 보이며, ESS 면접원 분석과 달리 이상치가 없다.
- 참고: 연속형 예측변수는 평균 중심화(centering)하면 절편을 "예측변수들이 평균일 때 흡연 확률의 로그 오즈 기댓값"으로 해석할 수 있다.

### 결론과 주의사항
- 임의 군집효과를 반영하지 않은 모델과 비교해 같은 흡연 예측변수들이 발견되지만, 임의 군집효과에 유의한 미설명 분산이 남아 있으므로 다음 단계로 **군집 수준 예측변수의 고정효과**(예: NHANES 표집 군집의 사회경제적 지위 지표)를 추가해 임의절편 분산을 설명해볼 수 있다.
- **주의**: 서로 다른 군집 수준 고정효과를 가진 다층 모델 간 분산성분을 비교할 때는, 두 모델이 **같은 응답자 수준(respondent-level) 고정효과**와 **정확히 같은 사례(관측치 수)** 를 포함해야 한다. 수준 1 예측변수를 바꾸면 분산성분 변화를 평가할 수 없다.
- 심화 참고문헌: Joop Hox et al., *Multilevel Analysis: Techniques and Applications* (3판) — 6.5절이 다층 모델 간 분산성분 비교 문제를 명시적으로 다룬다.

### 다음 내용
- Python으로 종단 데이터에 다층 모델을 적합하고 추론하는 전체 예시, 모델 적합을 시각화하는 웹 애플리케이션 탐색, 그리고 임의효과에 의존하지 않는 대안인 주변 모델(marginal model)로 넘어간다.

## 요약
- 다층 로지스틱 회귀는 로짓(logit) 스케일에서 고정효과 + 임의효과로 모델을 정의하며, 분포 가정은 다층 선형 모델과 같다.
- 비정규 결과변수에서는 우도를 근사(예: Adaptive Gaussian Quadrature)한 뒤 최대화해야 해 계산이 오래 걸린다 — 군집 간 분산에 대한 명시적 관심이 그만큼 중요하다.
- NHANES는 다단계 확률표집이므로 독립 가정은 틀렸고, 군집화를 무시하면 표준오차가 과소평가된다.
- 임의절편 모델 적합 결과: 유의한 예측변수는 그대로, 표준오차는 커짐, 임의절편 분산 0.046은 우도비 검정에서 유의.
- 분산성분을 모델 간 비교할 때는 수준 1 고정효과와 사례 수를 동일하게 유지해야 한다.
