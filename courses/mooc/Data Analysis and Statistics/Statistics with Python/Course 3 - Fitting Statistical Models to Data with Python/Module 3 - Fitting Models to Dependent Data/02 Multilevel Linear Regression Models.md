# Multilevel Linear Regression Models

## 개요
- 연속형 종속변수(continuous dependent variable)를 위한 다층 선형 회귀모델(multilevel linear regression model)을 다룬다.
- 고정효과(fixed effect)와 임의효과(random effect)의 구분, 임의효과의 분포 가정(이변량 정규분포), 분산성분(variance component) 추정을 설명한다.
- 최대우도추정(MLE)과 우도비 검정(likelihood ratio test)으로 모수를 추정·검정한다.
- 유럽사회조사(European Social Survey, ESS) 데이터의 면접원 효과(interviewer effect) 예시로 모델 적합, 진단, 이상치 탐지를 실습한다.

## 내용

### ESS 데이터 복습
- 벨기에 성인 1,703명의 전국 표본을 대면 면접(face-to-face survey)으로 조사한 데이터.
- 변수: 응답자 ID, 면접원 ID, 태도·의견을 측정하는 22개 변수, 복합표본설계(complex sample design)에 기반한 최종 응답자 가중치, 면접원별 응답률(면접원 수준 공변량으로 활용 가능).
- 관심사: **면접원 효과** — 면접원이 질문을 다르게 하거나 다른 유형의 응답자를 모집하면 수집된 데이터에 다른 영향을 줄 수 있다. 면접원 간 변동을 모델링하고자 한다.

### 다층 모델의 여러 이름
분야에 따라 다층 모델은 다음처럼 불린다.
- 임의계수 모델(random coefficient model) — 계수가 임의로 변하므로
- 변동계수 모델(varying coefficient model)
- 피험자 특정 모델(subject-specific model) — 종단 연구 맥락
- 위계적 선형 모델(hierarchical linear model, HLM) — 일부 사회과학 분야
- 혼합효과 모델(mixed effects model) — 고정효과와 임의효과가 섞여 있으므로 (통계학)

### 모델 명세
- 군집 j 안의 개인 i에서 측정된 연속형 종속변수 y에 대해:
  - **고정효과(fixed effects)** Beta_0, Beta_1: 아래첨자 j가 없는 고정 모수로, 전체 절편과 x-y의 전체 관계를 포착한다. 주로 종속변수의 평균(mean)을 정의한다.
  - **임의효과(random effects)**: u_0j는 군집마다 고유한 절편을 허용하고, u_1j는 예측변수 x_1ij에 곱해져 Beta_1과 결합해 군집 j의 고유 기울기를 정의한다.
  - 오차항 e_ij: 회귀계수와 임의효과로 예측되지 않는 부분을 포착.

### 임의효과의 분포 가정
- 임의효과는 확률변수이므로 분포를 정의해야 한다. 흔히 평균 0의 정규분포를 가정한다.
- 임의효과가 둘(u_0j, u_1j)이므로 **이변량 정규분포(bivariate normal distribution)** 를 가정한다.
  - 평균 벡터 (0, 0): 평균적인 군집은 Beta_0, Beta_1과 같아 보인다.
  - 분산-공분산 행렬(variance-covariance matrix) **D**: u_0j의 분산은 sigma^2_0, u_1j의 분산은 sigma^2_1, 비대각 원소 sigma_01은 임의절편과 임의기울기의 **공분산(covariance)**. 예컨대 임의절편이 클수록 임의기울기가 작을 수 있다(음의 공분산 가능).
- 군집 내 오차항은 평균 0, 분산 sigma^2의 정규분포를 가정한다.
- 따라서 세 개의 분산성분 sigma^2, sigma^2_0, sigma^2_1과 공분산 sigma_01을 추정한다.

### 다층 명세(multilevel specification)
- 수준 1: y_ij = 군집별 임의계수 + 같은 수준에서 측정된 예측변수 + e_ij. 수준 1의 모든 데이터는 ij 아래첨자를 가진다.
- 수준 2: 임의계수는 모수가 아니라, 고정 회귀모수 + 임의효과로 정의된다 (Beta_0j = Beta_0 + u_0j 등).
- 수준 2 식을 수준 1 식에 대입하면 앞의 단일 식 모델과 동일해진다.
- 다층 명세의 가치: **상위 수준에서 측정된 공변량의 역할을 명확히 정의**한다. 각 수준 2 식을 절편만 있는 회귀모델로 볼 수 있고, 수준 2 공변량의 고정효과를 추가해 임의효과의 분산을 설명하려 한다.

### 수준 2 공변량으로 분산 설명하기 — 수치 예시
- 임의절편 식 Beta_0j = Beta_0 + u_0j로 모델을 적합해 u_0j의 분산 추정치가 **2**라고 하자.
- 종단 연구에서 j가 반복 측정된 피험자라 할 때, 시간에 따라 변하지 않는 피험자 수준 공변량 male(성별)을 추가한다 — 아래첨자는 j (ij가 아님). 고정효과 Beta_2를 추정한다.
- male이 Beta_0j의 좋은 예측변수라면 u_0j의 분산이 줄어들 것으로 기대한다 (표준 선형회귀에서 예측변수를 추가하면 오차분산이 줄어드는 것과 같은 원리).
- 재적합 후 sigma^2_0 추정치가 **1**이 되었다면, 성별의 고정효과 추가만으로 절편 변동의 **50%를 설명**한 것이다. 이런 상위 수준 예측변수 발굴이 다층 모델링의 주요 추론 목표 중 하나다.

### 모수 추정과 검정
- **최대우도추정(maximum likelihood estimation, MLE)**: 관측 데이터를 가장 그럴듯하게(likely) 만드는 모수 값을 찾는다. Python으로 고정효과(Beta_0, Beta_1, Beta_2 등)와 분산성분(sigma^2, sigma^2_0, sigma^2_1)의 MLE와 표준오차를 계산할 수 있다.
- **우도비 검정(likelihood ratio testing)**: 특정 모수(고정효과 또는 분산성분)가 0이라는 귀무가설을 검정한다. 어떤 모수를 모델에서 제거했을 때 관측 데이터의 우도가 크게 변하는지(모델 적합이 나빠지는지)를 본다. 분산성분 제거는 임의효과 제거를 의미한다. 구체적 절차는 이번 주 읽기 자료에서 다룬다.

### ESS 예시 — 적합 결과
- 가정: ESS 면접원들은 고용될 수 있었던 더 큰 면접원 풀에서 무작위로 선택되었다.
- 연구 질문: 경찰 신뢰(trust in police)와 "사람들이 일반적으로 남을 도우려 한다"는 인식(perceived helpfulness)의 관계. 면접원이 데이터에 군집화를 만들 수 있으므로 면접원 임의효과를 포함한다.
- **고정효과 추정치**:
  - 기울기(경찰 신뢰 → 인식된 도움): **0.14**, 양수이며 유의. 추정 계수를 표준오차로 나눈 검정통계량을 t-분포에 비교하면 p-값이 매우 작다. 즉 경찰 신뢰가 높을수록 사람들이 남을 돕는다는 믿음도 높은 경향.
  - 전체 절편 Beta_0: **3.89**, 유의. 경찰 신뢰가 0인 사람들의 도움 인식 척도(0~10) 평균이 3.89라는 의미.
- **분산성분 추정치**:
  - 임의절편의 분산: **0.696**
  - 임의기울기의 분산: **0.012**
  - 우도비 검정 결과 두 분산 모두 0보다 유의하게 크다 — 면접원들이 절편과 기울기 모두에서 유의하게 변동한다. 면접원마다 고유한 절편(질문 방식이나 모집 대상 때문에 더 높은 평균을 수집할 수 있음)과 고유한 기울기(면접원마다 경찰 신뢰-도움 인식 관계의 추정치가 다름)를 가진다.

### 모델 진단(diagnostics)
- 임의효과와 오차의 분포 가정이 합리적이었는지 검토한다.
1. **잔차(residuals)**: 정규 QQ 플롯에서 잔차가 45도 직선 위에 거의 완벽히 놓여 정규성 가정에 문제 없음. 잔차 대 예측값 산점도에서 등분산(constant variance)에도 문제 없음 — 종속변수 값이 11개뿐이라 평행한 직선 모양이 나타난다.
2. **EBLUP(empirical best linear unbiased predictor)**: 임의효과는 확률변수라 직접 추정할 수 없고, 적합 후 예측값(EBLUP)을 계산해 이상치 면접원이 있는지 본다.
   - 임의절편 EBLUP: 전반적으로 정규분포를 따르지만 **면접원 4976**이 튀어나온다.
   - 임의기울기 EBLUP: 역시 대체로 정규지만 **면접원 7519**가 특이하다.

### 이상치 면접원 분석
- **면접원 4976** (특이한 임의절편): 도움 인식 응답 중 4 미만이 비정상적으로 많았다. 질문을 이상하게 했거나 유도성 발언을 했을 수 있다 — 기대보다 낮은 절편의 원인.
- **면접원 7519** (특이한 임의기울기): 산점도에서 예측변수(경찰 신뢰) 값이 **88**인 점 하나가 발견됐다. ESS에서 88은 **결측 데이터(missing data) 코드**인데 실제 값처럼 분석에 들어가 이 면접원의 기울기를 매우 평평하게 만들었다.
  - 교훈: 분석 전 기술통계(descriptive statistics)를 꼼꼼히 확인해 결측 코드를 진짜 결측값으로 재코딩해야 한다. 88을 결측으로 재코딩한 후 분석을 다시 실행해야 한다.

### 결론과 다음 단계
- 결측 문제를 처리한다는 전제하에, ESS 면접원들은 실제로 고유한 절편과 기울기를 만들어내고 있다.
- 이 맥락에서 이 분산은 좋은 것이 아니다 — 모수 추정치에 불확실성을 더한다. 이상치 제거 후 면접원 분산을 재평가해야 한다. 각 면접원이 전체 표본의 무작위 부분표본을 담당했다면 비슷한 절편과 기울기를 만들어야 정상이다.
- 다음 단계: 수준 2 식에 면접원 수준 공변량(면접원 응답률, 또는 면접원 자신의 도움·경찰 신뢰에 대한 태도 측정치가 있다면)을 추가해 절편·기울기의 분산을 설명해 볼 수 있다.
- 더 깊은 참고문헌: *Linear Mixed Models: A Practical Guide Using Statistical Software* (강사, Kathy Welch, Andrzej Galecki 공저, 2판 2014).

## 요약
- 다층 선형 회귀는 고정효과(전체 절편·기울기)와 임의효과(군집별 편차)를 함께 포함하는 혼합효과 모델(mixed effects model)이다.
- 임의절편·임의기울기는 이변량 정규분포(평균 0, 공분산행렬 D)를 가정하며, 분산성분 sigma^2, sigma^2_0, sigma^2_1과 공분산 sigma_01을 추정한다.
- 수준 2 공변량을 추가해 임의효과 분산을 설명할 수 있다 (예: 분산 2 → 1이면 50% 설명).
- 추정은 MLE, 검정은 우도비 검정(고정효과·분산성분 모두)으로 한다.
- ESS 예시: 기울기 0.14, 절편 3.89 (둘 다 유의), 임의절편 분산 0.696, 임의기울기 분산 0.012 (둘 다 유의) — 면접원 간 변동이 실재한다.
- 진단은 잔차 QQ 플롯·등분산 확인 + EBLUP 분포 확인으로 하며, 이상치 면접원 데이터 검토에서 결측 코드(88) 미처리 문제가 드러났다 — 기술통계 점검의 중요성.
