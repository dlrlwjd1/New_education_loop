# What Is AI?

## 개요
- 데이터 과학과 AI를 제품 관리자가 협업에 사용할 수 있는 실무적 관점으로 소개한다.
- 원문: https://www.mooc.org/learn/uva-darden-digital-product-management/lecture/jSepo/what-is-ai

## 내용
### 데이터 과학의 구성
- 데이터 과학은 수학·통계 지식, 프로그래밍·소프트웨어 역량, 도메인 전문성이 만나는 영역이다.
- 어느 하나만으로는 제품 맥락에 맞는 유용한 결과를 만들기 어렵다.

### 제품 속 기계 지능
- Google Photos나 Google Analytics의 보조 기능처럼 기계 지능은 사용자가 이미 접하는 제품 기능이다.
- AI를 별도의 마법 같은 기술로 보기보다 관찰, 예측, 개입을 개선하는 제품 역량으로 본다.
- 제품 관리자는 데이터 과학 팀에 문제 맥락과 결과 기준을 제공해야 한다.

## 예시
이미지 분류 모델의 정확도만 묻지 않고, 사용자가 사진을 찾는 과업을 얼마나 더 잘 완료하는지 정의한다.

## 요약
- 데이터 과학은 통계, 프로그래밍, 도메인 지식의 결합이다.
- AI는 제품 경험 안의 관찰과 판단을 지원한다.
- PM은 명확한 문제와 성과 기준을 제공한다.
