# Open Source Data Engineering with Spark, dbt & Airflow

**Program URL:** [mooc.org/professional-certificates/open-source-data-engineering-with-spark-dbt-and-airflow](https://www.mooc.org/professional-certificates/open-source-data-engineering-with-spark-dbt-and-airflow)

MOOC의 6강좌 전문 자격증 과정이다. Spark, dbt, Airflow를 중심으로 데이터 흐름 설계, 다중 소스 수집, SCD Type 2, 분산 처리 최적화, CI/CD, 데이터 품질과 커리어 준비를 다룬다. 강의별 노트 117개 (프로젝트·실습 모듈은 정리 노트 포함).

## 강좌 구성

- [Course 1 - Building Automated Data Pipelines with Spark, dbt, and Airflow](Course%201%20-%20Building%20Automated%20Data%20Pipelines%20with%20Spark%2C%20dbt%2C%20and%20Airflow/) — 22개 노트: DFD, Airbyte 커넥터, SCD2·dbt snapshots, 프로덕션 Airflow(백오프·SLA·파라미터화)
- **Course 2 - Optimizing Spark and Cloud Data Storage for Analytics** — 24개 노트: Spark UI·실행 계획·AQE, Delta Lake(ACID·타임 트래블·MERGE), 심층 방어·Terraform 보안 S3, 저장 형식 평가
- **Course 3 - Data Modeling and Warehousing Fundamentals in Data Engineering** — 22개 노트: 스타 스키마·그레인, 3NF+인덱싱, 윈도 함수·롤링 계산, 스트리밍 복제·pg_stat_replication, 증분 적재·MERGE
- **Course 4 - DevOps and CI/CD for Data Engineering Performance** — 31개 노트: Git 충돌·bisect·브랜칭, Docker 멀티 스테이지·ECR, Ansible, GitHub Actions CI/CD, PostgreSQL 최적화
- **Course 5 - Data Quality and Debugging for Reliable Pipelines** — 16개 노트: 품질 3차원, dbt+Great Expectations, 4단계 조사·해결, 조건부 브레이크포인트, 데드락 분석
- **Course 6 - Career Development for Open Source Data Engineering** — 2개 노트: 데이터 엔지니어의 하루, 포트폴리오·30일 실행 계획

참고: Course 2의 Module 1~4·9~10과 Course 4의 Module 11~12는 Performance Engineering for Data Systems 전문과정과 동일한 공유 콘텐츠다.
