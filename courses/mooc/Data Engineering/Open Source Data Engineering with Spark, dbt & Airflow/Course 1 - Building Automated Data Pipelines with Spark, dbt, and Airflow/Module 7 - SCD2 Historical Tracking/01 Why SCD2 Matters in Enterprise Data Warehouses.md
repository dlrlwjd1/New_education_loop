# Why SCD2 Matters in Enterprise Data Warehouses

## 개요

- 파괴적 갱신이 지운 이력이 초래하는 비즈니스 위기와 SCD2(Slowly Changing Dimension Type 2)의 가치 (모듈 도입 강의)

## 내용

### 시나리오

- 분석팀이 지난 분기 고객 세그먼테이션 리포트가 완전히 틀렸음을 발견 — 누군가 고객 주소를 갱신하며 지역 매출 분석에 결정적인 **역사적 위치를 덮어씀**. 6개월치 추세 분석 소실
- SME 경험담: 구독 변경을 추적하는 고객 웨어하우스에서 단순 업데이트(덮어쓰기) 사용 → 제품 출시를 위한 고객 생애주기 분석이 필요해졌을 때 시간에 따른 고객 진화를 재구성할 방법이 없음 → 이력 추적 시스템을 처음부터 재구축하며 몇 달 지연

### SCD2의 가치

- 기업 데이터 웨어하우스의 85%가 시간에 따른 데이터 무결성 유지를 위해 SCD에 의존
- 파괴적 갱신 대신 **변경을 포착하는 새 레코드 생성** — 완전한 감사 추적 보존
- 답할 수 있게 되는 질문: "3개월 전 구매 당시 고객 주소는?", "경쟁 분석 기간 동안 상품 가격은 어떻게 진화했나?"
- HubSpot 사례 — 통제된 리프레시 일정으로 SCD2 구현, 참조 무결성을 유지하며 상품 차원의 역사적 변화 추적

### 커리어 관점

- 헬스케어(환자 정보 변경), 리테일(상품 진화), 금융(규제 컴플라이언스) — 업계를 가로지르는 핵심 역량

## 요약

- SCD2는 단순 갱신이 영원히 파괴하는 비즈니스 맥락을 보존한다.
- 신뢰할 수 있고 감사 가능한 분석 시스템의 기본기다.
