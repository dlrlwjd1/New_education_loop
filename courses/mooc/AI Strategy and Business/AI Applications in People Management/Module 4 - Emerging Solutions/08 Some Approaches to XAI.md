# Some Approaches to XAI

## 개요
- 설명 가능한 AI(XAI)를 구현하는 대표적 기법들을 소개한다.
- **SHAP**, **LIME**, **대리 트리(surrogate trees)**, **오토인코더(autoencoder)** 를 다룬다.
- 공통 목표는 **예측력이 높으면서도 설명 가능한** 스위트 스팟을 찾는 것이다.

## 내용

### SHAP — 각 특성의 기여도를 보여 준다
- 예측 모델에 들어가는 서로 다른 정보 조각들, 즉 예측에 사용되는 **특성(feature)** 들과 출력을 살펴본다.
- **각 특성이 그 예측에 얼마나 기여했는지** 알려 준다.
- 예: 어떤 지원자나 직원에 대한 여러 정보 조각이 있고 모델이 결정을 내렸을 때, 그 결정에 각 정보 조각이 **얼마나 중요했는지**를 말해 준다.

### LIME — 국소적으로 정확한 단순 모델
- 매우 복잡해서 해석하거나 설명하기 어려운 모델에서 출발한다.
- **문제의 후보자와 비슷한 사람들에 대해서는 정확한, 더 단순한 비교 모델**을 생성한다.
- 전체적으로는 해석 불가능한 복잡한 모델이라도, 예를 들어 **직원 X와 아주 비슷하지만 어떤 점에서 다른 직원 Y**를 비교하면, 왜 한쪽에 다른 결정이 내려졌는지를 설명하는 더 단순한 설명을 만들 수 있다.
- 즉 **전역 모델(global model)은 설명하기 어려워도, 국소적으로(locally) 정확한 단순 모델**을 만드는 접근이다.

### 대리 트리(surrogate trees) — 흉내 내는 단순 모델
- 복잡한 모델의 성능을 **흉내 내면서 해석하기 쉬운 더 단순한 모델**을 만든다.
- 의사결정 트리처럼 근본적으로 해석하기 쉬운 모델 유형이 있다는 점을 활용한다.
- 대리 트리는 복잡한 모델과 **대부분의 차원에서 비슷하게 행동하는**(100%는 아닐 수 있다) 단순한 모델을 쓴다. 대신 해석이 훨씬 쉽다.
- 두 모델을 **함께 사용**해 예측의 이점과 설명의 이점을 모두 얻을 수 있다.

### 오토인코더(autoencoder) — 더 작은 특성 집합으로 압축
- 새로 등장하는 기법이다.
- 데이터를 받아 **더 작은 특성 집합으로 압축(boil down)** 해, 모델이 예측에 무엇을 쓰고 있는지 출력을 해석하기 쉽게 만든다.

### 업계의 투자
- IBM, 마이크로소프트 등 여러 기업이 이 영역에 많은 에너지를 쏟고 있다.
- 기업이 AI를 **더 설명 가능한 방식으로** 쓸 수 있게 하는 솔루션과 플랫폼을 개발하고 있다.
- 모두 **예측력이 높으면서도 설명 가능한** 스위트 스팟을 찾으려는 시도다.

## 예시

```text
[XAI 기법 비교]

SHAP          각 특성이 이 예측에 얼마나 기여했는가
              → "학력 +0.3, 경력 +0.5, 통근거리 -0.2"

LIME          복잡한 전역 모델 → 유사한 사람들 구간에서만 정확한 단순 모델
              → "X와 Y는 거의 같은데 이 항목이 달라서 결과가 갈렸다"

Surrogate     복잡한 모델의 행동을 대부분 흉내 내는 해석 쉬운 트리
Tree          → 예측은 복잡 모델, 설명은 대리 트리

Autoencoder   데이터를 더 작은 특성 집합으로 압축
              → 무엇을 쓰고 있는지 해석하기 쉬워짐
```

## 요약
- **SHAP**: 각 특성이 예측에 기여한 정도를 정량적으로 보여 준다.
- **LIME**: 전역적으로는 해석 불가능한 모델도 **비슷한 사례들 구간에서 국소적으로 정확한 단순 모델**로 설명한다.
- **대리 트리**: 복잡한 모델의 행동을 대체로 흉내 내는 해석 쉬운 트리를 함께 쓴다.
- **오토인코더**: 데이터를 더 작은 특성 집합으로 압축해 해석을 돕는다.
- IBM·마이크로소프트 등이 예측력과 설명 가능성의 스위트 스팟을 찾는 솔루션에 투자하고 있다.
