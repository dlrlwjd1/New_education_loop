# Introduction to DevOps

## 개요
- DevOps의 문화·원칙·실천법과 조직 구조, 성과 측정을 이해한다.

## 내용
- DevOps는 개발과 운영의 인수인계를 없애고 제품 결과에 공동 책임을 지는 문화다. 작은 배치, 자동화, 빠른 피드백과 지속적 학습을 중시한다.
- CI/CD, infrastructure as code, 자동 테스트와 관측성으로 변경을 반복 가능하게 만든다.
- 심리적 안전, blameless postmortem, cross-functional team은 로컬 최적화 대신 전체 흐름을 개선한다.
- 배포 빈도·변경 리드타임·변경 실패율·복구 시간 같은 지표를 함께 보며 속도와 안정성을 균형 있게 측정한다.

## 예시
- 하루 한 번의 큰 배포를 작은 독립 변경으로 나누고 자동 검증·점진 배포·rollback을 붙이면 실패 영향과 복구 시간이 줄어든다.

## 요약
- 6개 모듈은 DevOps 개요, 사고방식, 실천, 조직, 측정, 사례연구로 구성된다.
