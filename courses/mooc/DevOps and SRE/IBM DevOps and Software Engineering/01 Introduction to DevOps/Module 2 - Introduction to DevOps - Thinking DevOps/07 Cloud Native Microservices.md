# Cloud Native Microservices

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/intro-to-devops/lecture/9yGgd/cloud-native-microservices)

## 개요
- 이 동영상을 시청하고 나면 클라우드 네이티브 마이크로서비스가 애플리케이션 설계에 미치는 영향을 파악하고, 스테이트리스 마이크로서비스를 설명하고, 모놀리식 아키텍처와 마이크로서비스 아키텍처를 비교할 수 있습니다.

## 내용
- 이 동영상을 시청하고 나면 클라우드 네이티브 마이크로서비스가 애플리케이션 설계에 미치는 영향을 파악하고, 스테이트리스 마이크로서비스를 설명하고, 모놀리식 아키텍처와 마이크로서비스 아키텍처를 비교할 수 있습니다.
- 이러한 서비스는 클라우드 네이티브 애플리케이션의 작동 방식을 설명하는 “Twelve-Factor App”에 명시된 지침을 따르고 있습니다.
- “마이크로서비스 아키텍처 스타일은 단일 애플리케이션을 각각 자체 프로세스에서 실행되는 소규모 서비스 제품군으로 개발하는 접근 방식입니다...” 라고 말했습니다.
- Fowler와 Lewis는 “이러한 서비스는 비즈니스 기능을 중심으로 구축되었으며 완전 자동화된 배포 시스템을 통해 독립적으로 배포할 수 있습니다.” 라고 말하고자 합니다.
- 라이드 쉐어 애플리케이션의 각 서비스가 운전자 서비스, 승객 서비스, 알림 서비스와 같은 비즈니스 기능을 중심으로 구축되었음을 알 수 있었습니다.
- 각 마이크로서비스는 자체 상태를 추적하는 자체 데이터베이스를 갖게 됩니다.독립적으로 배포하고 데이터베이스를 독립적으로 변경할 수 있습니다.
- 스테이트리스 마이크로서비스는 각각 별도의 데이터베이스 또는 영구 오브젝트 저장소에서 자체 상태를 유지합니다.

## 예시
- 예를 들어 다른 서비스를 확장하지 않고도 알림 서비스를 확장할 수 있습니다.

## 요약
- 각 마이크로서비스는 자체 상태를 추적하는 자체 데이터베이스를 갖게 됩니다.독립적으로 배포하고 데이터베이스를 독립적으로 변경할 수 있습니다. 스테이트리스 마이크로서비스는 각각 별도의 데이터베이스 또는 영구 오브젝트 저장소에서 자체 상태를 유지합니다.
