# Social Coding Principles

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/intro-to-devops/lecture/areFT/social-coding-principles)

## 개요
- 소셜 코딩 원칙을 설명하고 페어 프로그래밍이 어떻게 더 나은 코드와 더 나은 프로그래머를 만드는지 알아볼 수 있습니다.

## 내용
- 소셜 코딩 원칙을 설명하고 페어 프로그래밍이 어떻게 더 나은 코드와 더 나은 프로그래머를 만드는지 알아볼 수 있습니다.
- 아니면 다른 팀에 의존하지 않기 위해 필요한 20% 를 얻기 위해 코드를 100% 다시 빌드합니까?
- 안타깝지만, 많은 팀이 후자를 선택하고 필요한 기능을 얻기 위해 전체 휠을 다시 발명합니다.
- 이를 통해 고객이 수행한 모든 작업을 활용하고 필요한 기능을 추가할 수 있습니다.
- 모든 작업을 완료하고 다시 기여할 내용이 있으면 검토할 준비가 되었다는 신호를 보내는 풀 리퀘스트를 실행하면 리포지토리 소유자가 코드를 메인 프로젝트에 다시 병합할지 여부를 결정할 수 있습니다.
- 다른 팀의 코드와 필요한 모든 기능을 활용할 수 있고, 다른 팀은 무료로 기능을 추가할 수 있습니다.
- 페어 프로그래밍은 같은 양의 작업을 얻기 위해 두 배의 리소스를 사용한다고 생각할 수도 있지만, 그렇지 않습니다.

## 예시
- 예를 들어, 필요한 구성 요소의 80% 를 차지하지만 일부 기능이 누락되었다고 가정해 보겠습니다.

## 요약
- 다른 팀의 코드와 필요한 모든 기능을 활용할 수 있고, 다른 팀은 무료로 기능을 추가할 수 있습니다. 페어 프로그래밍은 같은 양의 작업을 얻기 위해 두 배의 리소스를 사용한다고 생각할 수도 있지만, 그렇지 않습니다.
