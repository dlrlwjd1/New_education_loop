# Useful Features of the Bash Shell

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/hands-on-introduction-to-linux-commands-and-shell-scripting/lecture/pLqoL/useful-features-of-the-bash-shell)

## 개요
- 예를 들어, 이 표현식은 이름이 ba로 시작하고 그 뒤에 임의의 문자 (이 경우 Bash) 가 오는 슬래시 빈 디렉터리의 모든 개체를 반환합니다.그리고 물음표는 별표 메타문자의 단일 문자 버전 역할을 합니다.예를 들어, 다음 표현식은 물음표 대신 단일 문자로 구성된 슬래시 빈 디렉터리의 모든 개체, 즉 bash 및 dash 경로를 나열합니다.

## 내용
- 예를 들어, 이 표현식은 이름이 ba로 시작하고 그 뒤에 임의의 문자 (이 경우 Bash) 가 오는 슬래시 빈 디렉터리의 모든 개체를 반환합니다.그리고 물음표는 별표 메타문자의 단일 문자 버전 역할을 합니다.예를 들어, 다음 표현식은 물음표 대신 단일 문자로 구성된 슬래시 빈 디렉터리의 모든 개체, 즉 bash 및 dash 경로를 나열합니다.
- 백슬래시를 사용하면 단일 문자를 메타문자로 해석하지 않아도 됩니다.여기서 백슬래시는 달러 기호를 디폴트 변수 이름이 아닌 텍스트로 해석하도록 Bash에 지시하므로 출력은 말 그대로 '각각 1달러'가 됩니다.
- 예를 들어, 앞에 백슬래시가 없는 'dollar one' 표현식은 변수로 해석되며, 이 경우에는 비어 있습니다 (아래 참조).“each” 앞에 공백이 출력된 것을 볼 수 있습니다.
- 반면 작은따옴표는 모든 내용을 리터럴 문자로 해석하는 데 사용됩니다.예를 들어, 이 표현식은 위의 첫 번째 예제와 동일한 결과를 반환합니다.
- 입력/출력 또는 'I' O '리디렉션은 표준 입력, 키보드 또는 표준 출력인 터미널을 리디렉션하는 데 사용되는 일련의 기능을 말합니다.'>' 기호는 명령의 표준 출력을 파일로 리디렉션하는 데 사용됩니다.또한 파일이 없는 경우 파일을 생성하고 이미 있는 경우 해당 내용을 덮어씁니다.
- '2>' 조합은 오류 메시지를 파일로 리디렉션합니다.예를 들어, 오류 로그 파일에 오류 메시지를 추가하려면 기호보다 큰 기호를 하나 더 추가합니다.마지막으로, less than sign은 파일 내용을 입력으로 표준 입력에 전달하는 데 사용되는 리디렉션입니다.
- 이제 파일에 한 줄을 더 추가해 볼 수 있습니다.내용을 다시 보면 추가한 두 줄이 파일에 정확히 들어 있음을 알 수 있습니다.쓰레기 같은 단어를 입력하면 오류가 반환됩니다.이 표현식은 오류 메시지를 포착하여 'err.txt' 파일로 리디렉션합니다.실제로 'err.txt '의 내용은 예상할 수 있는 것과 같습니다.

## 예시
- 메타문자는 셸에 의미가 있는 특수 문자입니다.파운드 기호는 셸에서 무시하는 주석을 포함하는 데 사용됩니다.예를 들어, 이 주석은 아무 것도 반환하지 않습니다.
