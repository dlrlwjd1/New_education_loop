# Shell Scripting Basics

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/hands-on-introduction-to-linux-commands-and-shell-scripting/lecture/9xMbm/shell-scripting-basics)

## 개요
- 스크립트는 스크립팅 언어라는 프로그램에서 해석하고 실행할 수 있는 명령 목록입니다.명령은 명령줄에서 대화식으로 입력하거나 텍스트 파일에 한 줄씩 나열할 수 있습니다.스크립팅 언어는 일반적으로 컴파일되지 않습니다.런타임 시 해석됩니다.

## 내용
- 스크립트는 스크립팅 언어라는 프로그램에서 해석하고 실행할 수 있는 명령 목록입니다.명령은 명령줄에서 대화식으로 입력하거나 텍스트 파일에 한 줄씩 나열할 수 있습니다.스크립팅 언어는 일반적으로 컴파일되지 않습니다.런타임 시 해석됩니다.
- 응용 프로그램 통합, 플러그인 및 웹 응용 프로그램 개발을 비롯한 거의 모든 계산 작업에 스크립트를 사용할 수 있습니다.셸 스크립트는 일반적으로 첫 줄이 인터프리터 지시문의 형태를 띠는 실행 가능한 텍스트 파일입니다.인터프리터 지시문은 '셔뱅' 지시어라고도 하며 '파운드, 뱅, 인터프리터' 형식에 선택적 인수를 더한 형식입니다.
- 여기서는 간단한 'hello world' 예제를 통해 셸 스크립트를 사용하여 프로그램을 실행하는 방법을 보여줍니다.명령 프롬프트에서 다음과 같이 간단한 'hello world 셸 스크립트'를 만들 수 있습니다.
- 이제 bash shebang을 반영하고 파일에 출력을 추가하는 데 사용되는 Bash '출력 리디렉션' 연산자인 'double greater than symbol '을 사용하여 반향된 텍스트를 파일에 추가하여 텍스트 파일을 bash 스크립트로 변환합니다.
- bash 스크립트를 실행하려면 먼저 실행 가능하게 만들어야 합니다.먼저 'ls' 명령과 '-l' 옵션을 함께 사용하여 스크립트의 현재 권한 설정을 확인합니다.R 및 W 항목은 스크립트를 읽고 쓸 수 있음을 나타내지만 X가 없으면 실행할 수 없음을 나타냅니다.R, W, X 항목은 세 개의 사용자 기반 권한 그룹 (소유자, 사용자, 그룹 및 모든 사용자) 에 적용됩니다.'plus X' 옵션과 함께 'chmod' 명령을 호출하여 모든 사용자가 이 명령을 실행 가능하게 만들 수 있습니다.
- 이제 '를 입력하여 마침내 bash 스크립트를 실행할 수 있습니다./hello_world.sh '를 누르고 엔터를 누르면 명령줄에 'hello world'라는 텍스트가 나타납니다.이 비디오에서는 다음을 배웠습니다.
- 셸 스크립트를 사용하여 명령을 실행하고 다른 프로그램을 실행할 수 있습니다.스크립팅 언어는 컴파일되지 않으며 런타임에 해석됩니다.컴파일된 언어는 스크립팅 언어보다 훨씬 빠를 수 있지만 개발 시간도 더 많이 걸립니다.

## 예시
- 스크립트가 무엇인지 간략하게 설명하십시오.스크립팅 사용 사례를 나열하세요.'shebang' 인터프리터 지침을 설명하세요.

## 요약
- 이제 '를 입력하여 마침내 bash 스크립트를 실행할 수 있습니다./hello_world.sh '를 누르고 엔터를 누르면 명령줄에 'hello world'라는 텍스트가 나타납니다.이 비디오에서는 다음을 배웠습니다. 셸 스크립트를 사용하여 명령을 실행하고 다른 프로그램을 실행할 수 있습니다.스크립팅 언어는 컴파일되지 않으며 런타임에 해석됩니다.컴파일된 언어는 스크립팅 언어보다 훨씬 빠를 수 있지만 개발 시간도 더 많이 걸립니다.
