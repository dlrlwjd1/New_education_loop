## 개요
- 이 비디오를 시청하고 나면 파이프와 필터를 설명 및 사용하고 셸 및 환경 변수를 설명하고 설정할 수 있습니다.일반적으로 키보드의 표준 입력에서 입력을 받아 출력을 표준 출력 (일반적으로 터미널) 으로 되돌리는 필터 또는 셸 명령 또는 프로그램.

## 내용
- 이 비디오를 시청하고 나면 파이프와 필터를 설명 및 사용하고 셸 및 환경 변수를 설명하고 설정할 수 있습니다.일반적으로 키보드의 표준 입력에서 입력을 받아 출력을 표준 출력 (일반적으로 터미널) 으로 되돌리는 필터 또는 셸 명령 또는 프로그램.
- 예를 들어, -r 옵션을 사용하여 ls의 출력을 sort 명령으로 파이프할 수 있습니다.
- set 명령을 호출하여 현재 셸에서 볼 수 있는 모든 변수와 해당 정의를 나열할 수 있습니다.
- 새 변수 Greetings의 내용을 보려면 달러 기호를 사용하여 해당 값에 액세스한 다음 다시 반향하십시오.
- 값 world를 사용하여 또 다른 변수 Audience를 정의한 다음 두 변수를 다시 반복하면 Hello World가 반환됩니다.
- export 명령을 적용하여 모든 셸 변수를 환경 변수로 확장할 수 있습니다.
- env의 출력을 grep로 파이핑하고 GREE 패턴을 사용하여 결과를 필터링하여 Greetings를 환경 변수로 내보냈는지 확인해 보겠습니다.
