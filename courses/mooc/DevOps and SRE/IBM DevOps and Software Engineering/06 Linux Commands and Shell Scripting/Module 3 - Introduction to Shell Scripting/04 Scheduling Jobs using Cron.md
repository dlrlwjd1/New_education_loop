# Scheduling Jobs using Cron

## 내용
- Cron을 사용한 작업 스케줄링에 오신 것을 환영합니다.이 비디오를 시청한 후에는 crontab을 사용하여 크론 작업을 예약할 수 있습니다.크론 구문을 설명해 주세요.크론 작업 적용 및 제거.
- 시스템 관리자든 데이터 엔지니어든 개발자든 관계없이 특정 작업이 특정 시간에 자동으로 실행되도록 예약해야 하는 경우가 있을 수 있습니다.예를 들어 로드 스크립트는 매일 자정에 실행되도록 예약하고 백업 스크립트는 매주 일요일 오전 2시에 실행되도록 예약할 수 있습니다.Linux 및 Unix와 유사한 운영 체제의 cron 유틸리티를 사용하면 바로 이 작업을 수행할 수 있습니다.
- Crond는 1분마다 “crontab 파일”을 해석하고 예약된 시간에 해당 작업을 cron에 제출하는 데몬 또는 서비스입니다.
- “크론 테이블”의 줄임말인 크론탭은 작업과 스케줄 데이터를 포함하는 파일입니다.크론탭은 텍스트 편집기를 호출하여 크론탭 파일을 편집할 수 있도록 하는 명령이기도 합니다.
- “command”는 셸 스크립트 호출을 포함한 모든 셸 명령이 될 수 있습니다.기호는 분, 시, 월, 일, 요일을 나타냅니다.다섯 자리 모두 숫자 입력이나 별표 (“임의”를 의미하는 와일드카드 기호) 가 있어야 합니다.예를 들어, 다음 구문은 매주 일요일 15:30 에 'sundays.txt' 파일에 현재 날짜를 추가하는 것을 의미합니다.편집기를 닫고 변경 내용을 저장하면 크론 테이블에 작업이 추가됩니다.
- 명령줄에 crontab “minus e”를 입력하면 기본 텍스트 편집기가 열립니다.이 경우 기본 편집기는 GNU nano입니다.편리하게도 크론 작업 설정 지침이 여기에 주석으로 포함되어 있습니다.편집기 사용 지침도 포함되어 있지만, 이 문맥에서는 “control x”만 있으면 될 것입니다.여기서는 세 가지 예제 cron 작업을 입력했습니다.여분의 공백은 무시되므로 가독성을 높이기 위해 항목을 헤더 아래의 열로 정렬할 수 있습니다.
- 다음 줄은 매일 자정에 실행할 “데이터 로드” 셸 스크립트를 지정하고, 마지막 줄에서는 cron이 일요일 오전 2시에 “백업” 데이터 셸 스크립트를 실행하도록 지정합니다.작업을 저장하려면 먼저 “control x”를 입력하여 편집기를 종료한 다음 “y”를 입력하여 변경 내용을 저장합니다.작업이 현재 제작 중입니다!crontab을 “l” 옵션과 함께 실행하면 모든 크론 작업 및 해당 일정 목록이 반환됩니다.crontab 파일에서 모든 주석이 반환되는 것을 피하기 위해 “tail”을 사용했습니다.작업을 제거하려면 crontab 편집기를 호출하고 crontab 파일에서 해당 줄을 삭제한 다음 변경 내용을 저장하면 됩니다.

## 예시
- 시스템 관리자든 데이터 엔지니어든 개발자든 관계없이 특정 작업이 특정 시간에 자동으로 실행되도록 예약해야 하는 경우가 있을 수 있습니다.예를 들어 로드 스크립트는 매일 자정에 실행되도록 예약하고 백업 스크립트는 매주 일요일 오전 2시에 실행되도록 예약할 수 있습니다.Linux 및 Unix와 유사한 운영 체제의 cron 유틸리티를 사용하면 바로 이 작업을 수행할 수 있습니다.
