# Linux Distributions

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/hands-on-introduction-to-linux-commands-and-shell-scripting/lecture/ELeiv/linux-distributions)

## 개요
- 그리고 오늘날에는 수백 개의 Linux 배포판이 있으며 각 배포판은 특정 사용자나 작업에 맞게 조정되어 있습니다.

## 내용
- 그리고 오늘날에는 수백 개의 Linux 배포판이 있으며 각 배포판은 특정 사용자나 작업에 맞게 조정되어 있습니다.
- 각 Linux 배포판에는 배포판과 함께 사전 패키지로 제공되는 명령 및 응용 프로그램과 같이 운영 체제의 일부인 고유한 기본 유틸리티 세트가 포함되어 있습니다.
- 데비안은 1993년에 첫 번째 릴리스 ( 버전 0.01) 를, 1996년에 처음으로 공식적으로 안정적인 릴리스 (버전 1.1) 를 출시한 가장 초창기 배포판 중 하나입니다.
- 그리고 우분투에는 데스크톱 (개인용 컴퓨터, 노트북, 워크스테이션용) 서버 ( 단순 파일 서버 또는 멀티노드 클라우드용), 코어 (사물 인터넷용) 의 세 가지 공식 버전이 있습니다.
- SLE라고도 하는 SUSE 리눅스 엔터프라이즈는 서버 또는 SLES와 데스크톱 또는 SLED의 두 가지 버전으로 제공됩니다.
- Raspberry Pi용 ARM과 같은 다양한 아키텍처를 지원하며, 사용자가 공식적으로 SLE에 속하지 않는 패키지를 설치할 수 있는 SUSE 패키지 허브를 사용합니다.
- 이 비디오에서는 Linux 배포판이 사용자 인터페이스, 셸 응용 프로그램, 운영 체제 지원 및 구축 방식에 따라 차별화될 수 있다는 것을 알게 되었습니다.

## 예시
- 또한 인기 있는 일부 Linux 배포판의 사용 사례도 확인해 보세요.

## 요약
- Raspberry Pi용 ARM과 같은 다양한 아키텍처를 지원하며, 사용자가 공식적으로 SLE에 속하지 않는 패키지를 설치할 수 있는 SUSE 패키지 허브를 사용합니다. 이 비디오에서는 Linux 배포판이 사용자 인터페이스, 셸 응용 프로그램, 운영 체제 지원 및 구축 방식에 따라 차별화될 수 있다는 것을 알게 되었습니다.
