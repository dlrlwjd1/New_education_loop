# Overview of Linux Architecture

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/hands-on-introduction-to-linux-commands-and-shell-scripting/lecture/tsFM3/overview-of-linux-architecture)

## 개요
- Linux 아키텍처의 가장 바깥쪽 계층은 UI(사용자 인터페이스)로, 사용자가 다음을 사용하여 시스템과 상호 작용할 수 있습니다 사용자가 키보드나 마우스를 사용하여 시스템과 상호 작용할 수 있습니다.

## 내용
- Linux 아키텍처의 가장 바깥쪽 계층은 UI(사용자 인터페이스)로, 사용자가 다음을 사용하여 시스템과 상호 작용할 수 있습니다 사용자가 키보드나 마우스를 사용하여 시스템과 상호 작용할 수 있습니다.
- 모든 Linux 운영 체제는 Linux 커널 위에 구축되며, 이 커널은 가장 중요한 하위 수준 작업을 가장 중요한 하위 수준 작업을 수행합니다.
- 커널은 하드웨어 계층과 상호 작용하며, 여기에는 프로세서와 같은 컴퓨터의 모든 물리적 또는 전자적 프로세서, 메모리 모듈, 입력 장치, 저장 장치 등 컴퓨터의 모든 물리적 또는 전자적 장치를 포함합니다.
- 리눅스 시스템에서 운영 체제는 리눅스 커널 위에 구축되어 가장 중요한 작업을 수행하는 가장 중요한 작업을 수행합니다.
- 또한 앱과 컴퓨터 하드웨어 사이의 가교 역할도 합니다, 둘이 "시스템 호출"을 사용하여 효과적으로 통신할 수 있게 해줍니다 커널에는 네 가지 주요 작업이 있습니다: 메모리 관리, 프로세스 관리, 적절한 하드웨어 지원을 위한 디바이스 드라이버 관리, 그리고 시스템의 보안 유지 리눅스 시스템의 마지막 계층은 하드웨어로, 컴퓨터를 구성하는 물리 또는 전자 장치로 구성된 하드웨어입니다.
- 애플리케이션 실행에 필요한 임시 정보를 저장하는 데 사용되는 빠른 저장 장치인 랜덤 액세스 메모리 또는 RAM 임시 정보를 저장하는 데 사용되는 빠른 저장 장치입니다.
- 다른 주요 디렉토리로는 사용자 프로그램이 들어 있는 /usr이 있습니다, 모든 개인 파일을 저장해야 하는 개인 작업 디렉터리인 /home, 시스템 부팅 파일, 시스템 시작에 필수적인 지침이 들어 있는 /boot, cD나 USB 드라이브와 같은 임시 미디어와 관련된 파일이 들어 있는 /media는 시스템에 연결된 시스템에 연결되어 있습니다.
