- 패키지 관리자는 여러 가지 이점을 제공합니다: 패키지 간의 종속성을 자동으로 해결할 수 있습니다 업데이트가 있을 때 알려줄 수 있습니다 GUI 기반 패키지 관리자는 정기적으로 보안 및 소프트웨어 업데이트를 보안 및 소프트웨어 업데이트를 정기적으로 확인할 수 있습니다 또한 업데이트를 자동으로 설치하거나 원하는 업데이트만 선택해 설치할 수 있습니다.
- 기본적으로 업데이트 관리자는 매일 소프트웨어 업데이트를 확인하고, 보안 업데이트를 자동으로 다운로드하여 보안 업데이트를 매일 자동으로 다운로드하고 설치합니다.
- 업데이트 관리자는 소프트웨어 업데이트를 사용할 수 있을 때 알려줍니다: 설치하려는 업데이트를 선택합니다 '업데이트 설치'를 클릭합니다 메시지가 표시되면 사용자 비밀번호를 입력하고 확인을 클릭합니다.
- 별표 아이콘을 클릭하면 소프트웨어 업데이트 창이 열립니다, 사용 가능한 모든 소프트웨어 업데이트가 나열됩니다: 설치하려는 업데이트를 선택한 다음 를 선택한 다음 업데이트 설치를 클릭합니다.
- "pip install pandas"를 입력하여 pip 패키지 관리자에게 지시합니다: 최신 pandas 패키지를 검색합니다, Pandas 패키지를 다운로드합니다, 종속성을 확인하고 필요에 따라 업데이트합니다, 그리고 pandas 패키지를 설치합니다.
- 이 동영상에서는 .deb 및 .rpm은 Linux 운영 체제에서 패키지 관리자가 사용하는 고유한 파일 형식입니다 deb 및 RPM 형식은 서로 변환할 수 있습니다 업데이트 관리자와 PackageKit은 deb 및 RPM 기반 패키지 관리자에서 널리 사용되는 각각 deb 및 RPM 기반 배포판에서 사용됩니다 그리고 apt와 yum은 인기있는 명령 줄 패키지 관리자입니다 는 각각 deb 및 RPM 기반 배포판에서 널리 사용되는 명령줄 패키지 관리자입니다.
