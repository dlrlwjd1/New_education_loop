# Linux Terminal Overview

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/hands-on-introduction-to-linux-commands-and-shell-scripting/lecture/gDrnz/linux-terminal-overview)

## 개요
- 이 비디오를 보고 나면 다음을 수행할 수 있습니다 Linux 셸이 무엇인지 설명하기 Linux 터미널이 무엇인지 설명하기 Linux 터미널과 셸이 함께 작동하는 방식 설명하기 Linux 터미널을 사용하여 디렉터리 탐색하기 Linux 셸은 명령을 해석하는 OS 수준의 애플리케이션입니다.

## 내용
- 이 비디오를 보고 나면 다음을 수행할 수 있습니다 Linux 셸이 무엇인지 설명하기 Linux 터미널이 무엇인지 설명하기 Linux 터미널과 셸이 함께 작동하는 방식 설명하기 Linux 터미널을 사용하여 디렉터리 탐색하기 Linux 셸은 명령을 해석하는 OS 수준의 애플리케이션입니다.
- 셸 명령을 사용하여 다음과 같은 작업을 수행할 수 있습니다 파일 이동 및 복사 파일에 쓰기 및 읽기 데이터 추출 및 필터링 데이터 검색 셸 버전은 여러 가지가 있지만 대부분의 기본 기능은 동일합니다.
- 예를 들어 Python 애플리케이션을 시작하고 myprogram.py라는 프로그램을 실행하려면 python space myprogram.py를 입력합니다.
- 이 예에서 현재 작업 디렉터리는 문서 디렉터리로, 홈 디렉터리 안에 있는 me 디렉터리 안에 있습니다.
- 현재 작업 디렉터리인 슬래시 홈 슬래시 미에 ls 프로그램이 포함되어 있지 않더라도 명령을 성공적으로 실행할 수 있습니다.
- 다시 슬래시 홈 디렉터리에서 시작하여 cd space 점 점을 입력하여 현재 작업 디렉터리를 기존 현재 작업 디렉터리의 상위 디렉터리로 변경합니다.
- 그런 다음 홈 디렉터리의 me 디렉터리에 있는 문서 디렉터리로 내려가려면 슬래시 홈 슬래시 나 슬래시 문서를 입력합니다.
