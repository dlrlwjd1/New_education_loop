# Creating and Editing Text Files

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/hands-on-introduction-to-linux-commands-and-shell-scripting/lecture/XW701/creating-and-editing-text-files)

## 개요
- 인기 있는 Linux용 텍스트 편집기 목록 작성 및 널리 사용되는 GUI 기반 텍스트 편집기에 대해 설명하고 명령줄 편집기를 사용하여 파일 작업을 수행할 수 있습니다.

## 내용
- 인기 있는 Linux용 텍스트 편집기 목록 작성 및 널리 사용되는 GUI 기반 텍스트 편집기에 대해 설명하고 명령줄 편집기를 사용하여 파일 작업을 수행할 수 있습니다.
- 작고 친숙한 모델리스 텍스트 편집기 vi인 GNU nano와 원래 Unix용으로 만들어진 전통적인 명령줄 편집기인 vim과 vi를 기반으로 하는 강력한 모드 기반 명령줄 편집기인 vim은 널리 사용되는 GUI 기반 편집기인 gedit입니다.
- Gedit은 통합 파일 브라우저 실행 취소 및 다시 실행 기능, 검색 문자열의 정규 표현식 지원을 통한 검색 및 바꾸기 기능, gedit-plugins 패키지의 플러그인을 사용한 확장성 등 텍스트 편집 경험을 향상시키는 다양한 기능을 제공합니다.
- 실행 취소 및 다시 실행 기능 검색 문자열의 정규 표현식 지원으로 검색 및 바꾸기 구문 강조 코드 자동 들여쓰기 코드 자동 들여쓰기 줄 번호 매기기 줄 단위 스크롤 그리고 여러 버퍼를 사용하여 동시에 여러 파일을 작업할 수 있습니다.
- 이제 명령 모드로 돌아와서 'colon save' 명령을 파일 이름과 함께 사용하여 'example dot txt'와 같은 파일 이름을 사용하여 파일을 저장할 수 있습니다.
- 텍스트 버퍼를 탐색하고 텍스트 검색, 복사, 붙여넣기, 이동 등의 작업을 수행하는 데 사용할 수 있는 명령이 많이 있습니다.
- 다양한 명령줄 또는 GUI 기반 텍스트 편집기를 사용하여 Linux 코드를 작업할 수 있습니다.

## 예시
- 예를 들어, 도움말을 보려면 'control' 및 'G' 키를 누르십시오.

## 요약
- 텍스트 버퍼를 탐색하고 텍스트 검색, 복사, 붙여넣기, 이동 등의 작업을 수행하는 데 사용할 수 있는 명령이 많이 있습니다. 다양한 명령줄 또는 GUI 기반 텍스트 편집기를 사용하여 Linux 코드를 작업할 수 있습니다.
