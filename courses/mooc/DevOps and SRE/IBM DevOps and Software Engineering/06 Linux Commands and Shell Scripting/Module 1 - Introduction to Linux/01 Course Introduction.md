# Course Introduction

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/hands-on-introduction-to-linux-commands-and-shell-scripting/lecture/tsaHl/course-introduction)

## 개요
- 또한 셸 스크립트를 작성하여 작업을 자동화하고, 배치 작업을 실행하고, 유용한 프로그램을 빠르게 구성하는 방법도 배우게 됩니다.

## 내용
- 또한 셸 스크립트를 작성하여 작업을 자동화하고, 배치 작업을 실행하고, 유용한 프로그램을 빠르게 구성하는 방법도 배우게 됩니다.
- 소프트웨어 개발자, 데이터 과학자, 데이터 엔지니어, 시스템 관리자, DevOps 전문가, 시스템 설계자 또는 소프트웨어 엔지니어인 경우 Bash 명령을 잘 이해하면 모든 종류의 데이터 파이프라인 및 애플리케이션 워크플로의 구축 프로세스를 간소화하는 스크립트를 작성할 수 있습니다.Linux에 대한 소개부터 시작하겠습니다.
- Unix와 Linux의 기원, Linux 배포판의 아키텍처, Linux 터미널에서 간단한 작업을 수행하는 방법에 대해 알아봅니다.
- 새 디렉터리를 만들고, 불필요한 디렉터리를 제거하고, 새 파일을 만들고, 파일과 디렉터리를 복사 및 이동하여 파일 시스템을 탐색하고 파일 및 디렉터리를 관리하는 방법을 배웁니다.
- 디렉터리 트리에 파일과 디렉터리를 보관하고, 아카이브에서 파일과 폴더를 추출하고, 압축된 아카이브에서 파일을 추출 및 압축 해제하는 작업을 직접 경험하게 됩니다.
- 계속 진행하면서 스크립트와 Bash 셸 스크립팅의 모든 측면, 셸 스크립팅의 용도, 자체 셸 스크립트를 만들고 실행하는 방법을 살펴보겠습니다.
- 또한 메타문자 사용, 입력 및 출력 리디렉션, 명령줄에 지정된 인수를 셸 스크립트로 전달하는 등 Bash 셸의 유용한 기능도 알아보게 될 것입니다.

## 예시
- 그리고 가장 중요한 것은 실습을 완료하여 새로운 기술을 연습하고 능력을 입증해야 한다는 것입니다.

## 요약
- 계속 진행하면서 스크립트와 Bash 셸 스크립팅의 모든 측면, 셸 스크립팅의 용도, 자체 셸 스크립트를 만들고 실행하는 방법을 살펴보겠습니다. 또한 메타문자 사용, 입력 및 출력 리디렉션, 명령줄에 지정된 인수를 셸 스크립트로 전달하는 등 Bash 셸의 유용한 기능도 알아보게 될 것입니다.
