# Useful Commands for Wrangling Text Files

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/hands-on-introduction-to-linux-commands-and-shell-scripting/lecture/frBog/useful-commands-for-wrangling-text-files)

## 개요
- “sort - R pets 도트 텍스트”를 입력하면 줄이 역순으로 다시 정렬되고 “개” 줄이 “고양이” 줄 앞에 나타납니다.

## 내용
- “sort - R pets 도트 텍스트”를 입력하면 줄이 역순으로 다시 정렬되고 “개” 줄이 “고양이” 줄 앞에 나타납니다.
- 파일에 반복되는 줄이 있는 경우 “unique” 명령을 사용하여 반복되는 줄을 필터링할 수 있습니다.
- cut 명령을 사용하면 “cut minus C 2 dash 9인용 도트 텍스트”를 입력하여 모든 줄에서 두 번째에서 아홉 번째 문자를 추출할 수 있습니다.
- 같은 사람의 성을 포함하는 “마지막 점 텍스트”라는 보조 텍스트 파일과 각 사람의 생년월일을 나열하는 “Y O B dot text”라는 세 번째 텍스트 파일입니다.
- 예를 들어 이 표를 통해 찰스 배비지가 1791년에 태어났음을 알 수 있습니다.“paste” 명령과 함께 “minus D” 옵션을 사용하면 Tab 이외의 구분 기호를 지정할 수 있습니다.
- 예를 들어, “ first”, “last” 및 “Y O B” 텍스트 파일과 함께 “paste minus D”를 큰 따옴표로 묶어 쉼표를 입력하여 쉼표를 구분자로 사용할 수 있습니다.
- 이 비디오에서는 정렬을 사용하여 파일의 줄 영숫자순으로 보기, 뷰에서 반복되는 줄 제거하기, grep을 사용하여 원하는 기준에 맞는 파일의 줄 가져오기, 잘라내기를 사용하여 줄에서 슬라이스와 필드를 추출하는 방법, 붙여넣기를 사용하여 여러 파일의 줄 병합하는 방법을 배웠습니다.

## 예시
- 예를 들어 이 표를 통해 찰스 배비지가 1791년에 태어났음을 알 수 있습니다.“paste” 명령과 함께 “minus D” 옵션을 사용하면 Tab 이외의 구분 기호를 지정할 수 있습니다.
