# File and Directory Navigation Commands

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/hands-on-introduction-to-linux-commands-and-shell-scripting/lecture/OFZjk/file-and-directory-navigation-commands)

## 개요
- "파일 및 디렉터리 탐색 명령"에 오신 것을 환영합니다 이 동영상에서는 방법을 배웁니다: '목록' 명령을 사용하여 디렉터리 콘텐츠 나열하기 "디렉터리 변경" 명령으로 여러 디렉터리 간 이동하기 상대 경로와 절대 경로에 대해 설명합니다 "find" 명령으로 파일 찾기 Ls 또는 "list" 명령은 디렉터리 내의 파일과 디렉터리를 나열합니다.

## 내용
- "파일 및 디렉터리 탐색 명령"에 오신 것을 환영합니다 이 동영상에서는 방법을 배웁니다: '목록' 명령을 사용하여 디렉터리 콘텐츠 나열하기 "디렉터리 변경" 명령으로 여러 디렉터리 간 이동하기 상대 경로와 절대 경로에 대해 설명합니다 "find" 명령으로 파일 찾기 Ls 또는 "list" 명령은 디렉터리 내의 파일과 디렉터리를 나열합니다.
- 현재 문서 폴더에서 작업 중이고 디렉터리 내의 파일에 대한 자세한 정보를 알고 싶다고 가정해 보겠습니다 자세한 정보가 필요하다고 가정해 보겠습니다.
- 터미널에 모든 하위 파일, 디렉터리 및 추가 세부 정보가 나열된 것을 볼 수 있습니다 권한, 마지막으로 수정한 날짜, 소유자 등의 세부 정보가 나열된 것을 볼 수 있습니다.
- 홈 디렉터리에 있는데 그 안에 있는 하위 디렉터리로 이동하고 싶다고 가정해 보겠습니다, 문서 폴더와 같은 하위 디렉터리로 이동하고 싶다고 가정해 봅시다.
- "문서" 폴더의 파일 구조가 그림과 같이 두 개의 하위 폴더로 구성되어 있고 각각 몇 개의 파일이 들어 있다고 가정해 보겠습니다 두 개의 하위 폴더가 있다고 가정해 보겠습니다.
- "문서" 폴더에서 작업 중이고 그 안에 있는 "a.txt"라는 이름의 모든 파일의 경로를 찾고 싶다고 가정해 보겠습니다 모든 파일의 경로를 찾고 싶다고 가정해 보겠습니다.
- 그러면 동일한 파일과 이름이 같지만 대문자( 대문자 "A"가 있는 파일을 찾을 수 있습니다 이 동영상에서 이 방법을 배웠습니다: Ls 명령은 지정된 디렉터리 내에 포함된 모든 파일과 디렉터리를 나열합니다 tree Cd 명령은 디렉터리 사이를 이동하는 데 사용됩니다 상대 경로는 현재 작업 디렉터리를 기준으로 하고 절대 경로는 독립적으로 Find 명령은 디렉터리에서 파일을 찾는 데 사용됩니다
