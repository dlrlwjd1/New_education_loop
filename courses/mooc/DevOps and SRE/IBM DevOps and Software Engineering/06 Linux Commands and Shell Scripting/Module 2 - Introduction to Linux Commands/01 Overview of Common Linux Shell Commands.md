# Overview of Common Linux Shell Commands

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/hands-on-introduction-to-linux-commands-and-shell-scripting/lecture/3lRqW/overview-of-common-linux-shell-commands)

## 개요
- 셸 명령의 응용 프로그램에는 정보 가져오기, 파일 및 디렉터리 탐색 및 작업, 파일 및 문자열 내용 인쇄, 파일 압축 및 보관, 네트워크 작업 수행, 시스템, 구성 요소 및 응용 프로그램의 성능 및 상태 모니터링, ETL 작업과 같은 배치 작업 실행 등이 포함됩니다.

## 내용
- 셸 명령의 응용 프로그램에는 정보 가져오기, 파일 및 디렉터리 탐색 및 작업, 파일 및 문자열 내용 인쇄, 파일 압축 및 보관, 네트워크 작업 수행, 시스템, 구성 요소 및 응용 프로그램의 성능 및 상태 모니터링, ETL 작업과 같은 배치 작업 실행 등이 포함됩니다.
- whoami — 사용자의 사용자 이름, id (현재 사용자 이름, 그룹 ID 반환), uname — 운영 체제 이름 반환, ps — 실행 중인 프로세스와 해당 ID 표시, 맨 위 — 메모리, CPU, IO 등 실행 중인 프로세스 및 리소스 사용량 표시, df — 마운트된 파일 시스템에 대한 정보 표시, man — 셸 명령에 대한 참조 설명서 가져오기, 날짜 — 오늘 날짜 인쇄.파일 작업을 위한 몇 가지 일반적인 셸 명령으로는 cp — 파일 복사, mv — 파일 이름 또는 경로 변경, rm — 파일 제거, 터치 — 빈 파일 생성, 파일 타임스탬프 업데이트, changemod — 파일 권한 변경 또는 수정, wc — 파일의 줄, 단어 수, 문자 수 가져오기 , grep — 파일 일치 패턴으로 줄 반환 등이 있습니다.
- LS — 현재 디렉토리의 파일 및 디렉토리를 나열하고, find — 현재 디렉토리 트리에서 패턴과 일치하는 파일을 찾는 데 사용, pwd — 현재 또는 '현재 작업 중' 디렉토리를 출력합니다.
- 파일 내용이나 문자열을 인쇄할 때 자주 사용하는 명령으로는 파일의 전체 내용을 인쇄하는 등 파일 내용을 한 번에 한 페이지씩 인쇄하는 cat, 파일의 처음 'N' 줄만 인쇄하는 head, 파일의 마지막 'N' 줄만 인쇄하는 tail, 입력 문자열을 인쇄하여 '반향'하는 매우 일반적인 echo 명령이 있습니다.
- 파일 압축 및 보관 응용 프로그램과 관련된 셸 명령에는 파일 세트를 보관하는 데 사용되는 tar, 파일 집합을 압축하는 zip, 압축되거나 압축된 아카이브에서 파일을 추출하는 unzip이 포함됩니다.
- 호스트 이름 인쇄, ping — URL로 패킷 전송 및 응답 인쇄, ifconfig — 시스템의 네트워크 인터페이스를 표시 또는 구성, curl — URL에 있는 파일의 내용 표시, wget 명령을 사용하여 URL에서 파일을 다운로드할 수 있습니다.
- Windows 컴퓨터를 실행 중이고 Linux를 실행하려는 경우 다양한 방법으로 실행할 수 있다는 점을 언급해야 합니다.Linux는 별도의 드라이브 파티션에 설치할 수 있습니다.두 운영 체제 간에 전환하려면 재부팅해야 합니다.또는 가상 머신에 Linux를 설치하거나 CygWin과 같은 Linux 에뮬레이터를 설치하거나 Windows에서 기본적으로 Linux 바이너리 실행 파일을 실행하기 위한 호환성 계층인 Linux용 Windows 하위 시스템을 사용할 수 있습니다.
