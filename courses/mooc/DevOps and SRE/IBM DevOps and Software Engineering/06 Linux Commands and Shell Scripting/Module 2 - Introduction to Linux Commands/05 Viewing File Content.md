# Viewing File Content

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/hands-on-introduction-to-linux-commands-and-shell-scripting/lecture/NRDyr/viewing-file-content)

## 개요
- 이 비디오에서는 파일에서 작동하는 명령을 적용하여 파일 내용을 유용한 방식으로 보고 줄, 단어 수, 문자 수를 결정하는 방법을 알아봅니다.

## 내용
- 이 비디오에서는 파일에서 작동하는 명령을 적용하여 파일 내용을 유용한 방식으로 보고 줄, 단어 수, 문자 수를 결정하는 방법을 알아봅니다.
- tail numbers.txt 를 입력하면 numbers.txt 파일의 마지막 10개 줄, 즉 90에서 99까지의 숫자가 반환됩니다.
- head 명령과 마찬가지로 -n 옵션을 사용하여 tail -n, 3 numbers.txt 를 입력하여 반환되는 줄 수를 변경할 수 있습니다.
- WC 명령을 사용하여 파일의 문자, 단어 또는 줄 수를 계산할 수 있습니다.
- cat pets.txt 를 입력하면 파일의 각 줄에 cat이라는 단어 또는 dog라는 단어가 포함되어 있음을 알 수 있습니다.
- 단어 수만 보려면 -w 옵션을 사용하고, 문자 수만 보려면 -c 옵션을 사용할 수 있습니다.
- 이 비디오에서는 cat, more, head, tail 명령을 적용하여 다양한 방법으로 파일 내용을 보고 WC를 사용하여 파일의 줄, 단어 수, 문자 수를 결정하는 방법을 배웠습니다.

## 예시
- 이 비디오에서는 cat, more, head, tail 명령을 적용하여 다양한 방법으로 파일 내용을 보고 WC를 사용하여 파일의 줄, 단어 수, 문자 수를 결정하는 방법을 배웠습니다.

## 요약
- 단어 수만 보려면 -w 옵션을 사용하고, 문자 수만 보려면 -c 옵션을 사용할 수 있습니다. 이 비디오에서는 cat, more, head, tail 명령을 적용하여 다양한 방법으로 파일 내용을 보고 WC를 사용하여 파일의 줄, 단어 수, 문자 수를 결정하는 방법을 배웠습니다.
