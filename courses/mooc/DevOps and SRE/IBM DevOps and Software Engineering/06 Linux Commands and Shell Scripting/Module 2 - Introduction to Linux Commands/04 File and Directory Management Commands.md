# File and Directory Management Commands

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/hands-on-introduction-to-linux-commands-and-shell-scripting/lecture/pwUDl/file-and-directory-management-commands)

## 개요
- 현재 비어 있는 문서 폴더에 있다고 가정해 보겠습니다.“test”라는 폴더를 만들려면 “mkdir test”를 입력하면 됩니다.이제 현재 디렉터리에 “test”라는 하위 폴더가 생겼습니다.

## 내용
- 현재 비어 있는 문서 폴더에 있다고 가정해 보겠습니다.“test”라는 폴더를 만들려면 “mkdir test”를 입력하면 됩니다.이제 현재 디렉터리에 “test”라는 하위 폴더가 생겼습니다.
- 왼쪽에 표시된 것과 같은 파일 구조가 있다고 가정해 보겠습니다.문서 폴더에서 “file1"을 제거하려고 한다고 가정해 보겠습니다.“rm file1"을 입력하기만 하면 이 작업을 수행할 수 있습니다.이제 “folder1"만 남았음을 알 수 있습니다.
- 하지만 -r 옵션과 함께 “rm”을 입력하면 이 문제를 쉽게 해결할 수 있습니다.-r 옵션은 디렉토리를 모든 하위 파일 객체와 함께 제거하려는 것을 의미합니다.이제 문서 폴더가 비어 있습니다.
- cp 명령을 사용하면 파일 또는 디렉터리를 복사할 수 있습니다.파일을 복사하려면 원본 디렉토리에서 파일을 복사하고 대상 디렉토리의 파일 이름을 지정하거나, 대상 파일 이름을 생략하고 기본적으로 동일한 파일 이름을 유지할 수 있습니다.
- 작업 디렉토리에 "notes.txt “라는 파일과 “Documents”라는 폴더가 있다고 가정해 보겠습니다.“ cp notes.txt 문서”를 사용하여 notes.txt 파일을 “문서” 폴더에 복사할 수 있습니다.이제 문서 폴더에 notes.txt 사본이 들어 있는 것을 확인할 수 있습니다.
- 파일을 이동하려면 “mv”를 입력한 다음 이동할 파일의 경로와 파일을 이동할 대상 폴더를 차례로 입력하면 됩니다.마찬가지로 디렉터리를 이동하려면 “mv”를 입력하고 이동할 디렉터리 경로를 입력한 다음 이동할 경로와 디렉터리를 입력합니다.
- 왼쪽의 구문을 사용하여 “my_script.sh”를 “Scripts” 폴더로 이동할 수 있습니다.따라서 “ls my_script.sh”를 입력하면 아무 것도 반환되지 않지만 “ls Scripts”를 입력하면 my_script.sh 를 Scripts 폴더로 성공적으로 이동했음을 알 수 있습니다.다음으로 왼쪽의 구문을 사용하여 Notes 및 Scripts 폴더를 Documents 폴더로 옮길 수 있습니다.

## 예시
- 예를 들어 "my_script.sh “라는 파일과 “ 스크립트”, “노트”, “문서”라는 세 개의 폴더가 있다고 가정해 보겠습니다.

## 요약
- 파일을 이동하려면 “mv”를 입력한 다음 이동할 파일의 경로와 파일을 이동할 대상 폴더를 차례로 입력하면 됩니다.마찬가지로 디렉터리를 이동하려면 “mv”를 입력하고 이동할 디렉터리 경로를 입력한 다음 이동할 경로와 디렉터리를 입력합니다. 왼쪽의 구문을 사용하여 “my_script.sh”를 “Scripts” 폴더로 이동할 수 있습니다.따라서 “ls my_script.sh”를 입력하면 아무 것도 반환되지 않지만 “ls Scripts”를 입력하면 my_script.sh 를 Scripts 폴더로 성공적으로 이동했음을 알 수 있습니다.다음으로 왼쪽의 구문을 사용하여 Notes 및 Scripts 폴더를 Documents 폴더로 옮길 수 있습니다.
