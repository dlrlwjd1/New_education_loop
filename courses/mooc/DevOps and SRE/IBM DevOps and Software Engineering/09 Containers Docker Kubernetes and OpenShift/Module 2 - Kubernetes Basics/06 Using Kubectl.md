# Using Kubectl

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/ibm-containers-docker-kubernetes-openshift/lecture/tcNh4/using-kubectl)

## 개요
- Kubectl은 Kubernetes 작업을 위한 주요 도구 중 하나이며, 사용자가 애플리케이션을 배포하고, 클러스터 리소스를 검사 및 관리하고, 로그를 보는 등의 작업을 할 수 있도록 도와줍니다.

## 내용
- Kubectl은 Kubernetes 작업을 위한 주요 도구 중 하나이며, 사용자가 애플리케이션을 배포하고, 클러스터 리소스를 검사 및 관리하고, 로그를 보는 등의 작업을 할 수 있도록 도와줍니다.
- 그리고 세 가지 Kubectl 명령 유형은 명령형 명령이며, 명령형 오브젝트 구성 및 선언적 오브젝트 구성 Kubectl 명령은 다음과 같은 구조를 사용합니다.
- 타입은 파드 디플로이먼트나 레플리카 세트와 같은 리소스 유형을 의미하고, 이름은 해당하는 경우 리소스 이름을 의미하며, 플래그는 기본값을 재정의하는 특수 옵션 또는 수정자를 의미한다.
- 예를 들어, 개발자가 구성 파일에 병합되지 않은 업데이트 작업을 수행하는 경우 다른 개발자는 향후 배포에서 업데이트된 구성을 사용할 수 없습니다.
- 예를 들어 cubectal apply 명령은 표시된 대로 디렉터리를 언급한 다음 해당 디렉터리의 모든 파일에 구성 데이터를 적용합니다.
- 이제 다른 개발자가 이러한 업데이트 중 몇 개를 놓치더라도 현재 구성 템플릿을 적용하여 배포된 개체가 예상대로 작동하는지 확인하기만 하면 됩니다.
- Kubectl get 커맨드를 사용하면 현재 네임스페이스의 서비스, 모든 네임스페이스의 파드, 특정 디플로이먼트, 현재 네임스페이스의 파드를 수신할 수 있다.

## 예시
- 예를 들어, 특정 컨테이너로 포드를 생성하려면 그림과 같이 포드 이름과 컨테이너 이미지만 지정하여 명령을 실행하기만 하면 됩니다.

## 요약
- 이제 다른 개발자가 이러한 업데이트 중 몇 개를 놓치더라도 현재 구성 템플릿을 적용하여 배포된 개체가 예상대로 작동하는지 확인하기만 하면 됩니다. Kubectl get 커맨드를 사용하면 현재 네임스페이스의 서비스, 모든 네임스페이스의 파드, 특정 디플로이먼트, 현재 네임스페이스의 파드를 수신할 수 있다.
