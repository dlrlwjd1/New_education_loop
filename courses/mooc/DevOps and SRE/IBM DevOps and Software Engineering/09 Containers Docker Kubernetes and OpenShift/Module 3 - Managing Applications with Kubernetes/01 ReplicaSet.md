# ReplicaSet

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/ibm-containers-docker-kubernetes-openshift/lecture/KyXOz/replicaset)

## 개요
- 장애가 발생한 포드를 교체하거나 원하는 상태를 유지하기 위해 추가 포드를 삭제합니다.

## 내용
- 장애가 발생한 포드를 교체하거나 원하는 상태를 유지하기 위해 추가 포드를 삭제합니다.
- 이를 확인하려면 배포를 생성한 다음 get ReplicaSet 명령을 사용하여 레플리카셋이 자동으로 생성되었는지 확인하십시오.
- get pods 명령을 사용하여 생성되었는지 확인하고 상태를 실행 중인지 확인한 다음 get rs 명령을 사용합니다.
- 하지만 독립형 레플리카셋을 만드는 것보다 레플리카셋을 포함하는 디플로이먼트를 만드는 것이 좋다는 점을 기억하자.
- 이제 디플로이먼트와 파드가 준비되면 scale 명령어를 사용하여 디플로이먼트를 확장하고 원하는 레플리카 수를 설정한다.
- 그리고 원하는 상태가 실제 상태와 일치하지 않고 삭제된 포드가 자동으로 새 포드로 대체된다는 점을 알 수 있습니다.
- 그런 다음 get pods 명령을 다시 사용하면 출력에 이제 네 개의 포드가 표시됩니다.

## 예시
- 그런 다음 get pods 명령을 다시 사용하면 출력에 이제 네 개의 포드가 표시됩니다.

## 요약
- 그리고 원하는 상태가 실제 상태와 일치하지 않고 삭제된 포드가 자동으로 새 포드로 대체된다는 점을 알 수 있습니다. 그런 다음 get pods 명령을 다시 사용하면 출력에 이제 네 개의 포드가 표시됩니다.
