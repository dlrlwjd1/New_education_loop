# Autoscaling

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/ibm-containers-docker-kubernetes-openshift/lecture/iAa1C/autoscaling)

## 개요
- 쿠버네티스에서는 수평 포드 자동 스칼라 또는 HPA, 수직 포드 자동 스칼라 또는 VPA, 클러스터 자동 스칼라 또는 CA의 세 가지 유형의 자동 스칼라를 사용할 수 있습니다.

## 내용
- 쿠버네티스에서는 수평 포드 자동 스칼라 또는 HPA, 수직 포드 자동 스칼라 또는 VPA, 클러스터 자동 스칼라 또는 CA의 세 가지 유형의 자동 스칼라를 사용할 수 있습니다.
- 이전 autoscale 명령에서 지정한 최소 수가 2개로 변경된 이후 이 자동 크기 조정된 복제본 세트의 복제본 수가 2개로 변경된 것을 알 수 있습니다.
- 수직 포드 오토 스칼라 ( VPA) 는 파드의 리소스 크기 또는 속도를 늘리거나 줄임으로써 컨테이너의 리소스 요청 및 제한을 조정합니다.
- 예를 들어 이른 아침에는 시스템 부하가 낮아 포드에서 사용하는 시스템 리소스가 적습니다.오전 11시가 되면 로드가 최고조에 달해 더 많은 용량이 필요합니다.
- 수요가 증가하면 새 포드 요청이 들어오고 CA는 수요에 맞게 새 노드와 포드를 추가하여 클러스터를 자동으로 확장합니다.오전 11:00 이 되면 최대 로드로 새 노드의 용량이 가득 차게 됩니다.
- 예를 들어, 야간 및 주말에는 순수 개발 또는 지속적 통합 테스트 부하가 있을 수 있고, 클러스터에는 모든 배치 처리 작업이 완료되고 하루 늦게까지 새 배치가 시작되지 않는 기간이 있을 수 있습니다.
- 오토스케일러 유형에는 수평 포드 또는 HPA, 수직 포드 (VPA), 클러스터 또는 CA가 포함되며, 세 가지 자동 확장 처리 유형을 모두 조합하면 가장 최적화된 솔루션을 제공하는 경우가 많습니다.A

## 예시
- 예를 들어 이른 아침에는 시스템 부하가 낮기 때문에 포드 하나면 충분합니다.

## 요약
- 예를 들어, 야간 및 주말에는 순수 개발 또는 지속적 통합 테스트 부하가 있을 수 있고, 클러스터에는 모든 배치 처리 작업이 완료되고 하루 늦게까지 새 배치가 시작되지 않는 기간이 있을 수 있습니다. 오토스케일러 유형에는 수평 포드 또는 HPA, 수직 포드 (VPA), 클러스터 또는 CA가 포함되며, 세 가지 자동 확장 처리 유형을 모두 조합하면 가장 최적화된 솔루션을 제공하는 경우가 많습니다.A
