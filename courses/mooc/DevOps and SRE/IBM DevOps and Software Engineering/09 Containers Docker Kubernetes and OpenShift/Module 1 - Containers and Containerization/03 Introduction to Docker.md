- Docker는 하드웨어, 운영 체제, 컨테이너 런타임을 포함한 인프라로부터 애플리케이션을 분리합니다, 컨테이너 런타임을 포함한 인프라로부터 애플리케이션을 격리합니다.
- 그리고 Docker는 모든 컨테이너에 대해 네임스페이스 집합을 생성하고 각 측면은 액세스 권한이 제한된 별도의 네임스페이스에서 실행되며 액세스는 해당 네임스페이스로 제한됩니다.

- Docker 이미지는 크기가 작고 재사용이 가능하므로 개발 속도가 크게 빨라집니다 프로세스를 크게 단축하고, Docker 자동화 기능으로 오류를 제거하여 유지보수 주기를 간소화합니다.
