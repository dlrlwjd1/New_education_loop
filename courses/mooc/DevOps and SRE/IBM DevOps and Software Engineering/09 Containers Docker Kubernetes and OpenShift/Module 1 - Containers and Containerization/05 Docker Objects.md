# Docker Objects

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/ibm-containers-docker-kubernetes-openshift/lecture/lOkqH/docker-objects)

## 개요
- 이 동영상을 보고 나면 docker 객체를 식별하고 설명할 수 있습니다, 필수 Docker 파일 명령어를 식별하고 컨테이너 이미지 이름 지정에 대해 설명합니다, 그리고 Docker 가 네트워크, 스토리지 및 플러그인을 사용하는 방법을 설명할 수 있습니다.

## 내용
- 이 동영상을 보고 나면 docker 객체를 식별하고 설명할 수 있습니다, 필수 Docker 파일 명령어를 식별하고 컨테이너 이미지 이름 지정에 대해 설명합니다, 그리고 Docker 가 네트워크, 스토리지 및 플러그인을 사용하는 방법을 설명할 수 있습니다.
- Docker에는 다음과 같은 개체가 포함됩니다 도커 파일, 이미지, 컨테이너 네트워크, 스토리지 볼륨, 기타 오브젝트, 플러그인 및 애드온과 같은 기타 개체를 포함합니다.
- 보통 기본 이미지는 공개 리포지토리에서 가져오는 경우가 많습니다, 운영 체제 또는 go 또는 Node.js와 같은 특정 언어에서 가져올 수 있습니다.
- 이 때 쓰기 가능한 컨테이너 레이어 가 읽기 전용 레이어 위에 배치됩니다, 쓰기 가능한 레이어가 필요한 이유는 컨테이너는 이미지로 불변하지 않기 때문에 쓰기 가능한 레이어가 필요합니다.
- 리포지토리는 관련 컨테이너 이미지의 그룹입니다, 태그는 특정 버전 또는 변형에 대한 이미지의 특정 버전 또는 변형에 대한 정보를 제공합니다.
- Docker는 볼륨과 바인드 마운트를 사용하여 를 사용하여 컨테이너가 중지된 후에도 데이터를 유지합니다, 그리고 스토리지 플러그인과 같은 플러그인은 외부 스토리지 플랫폼에 연결할 수 있는 기능을 제공합니다.
- 이 비디오에서는 다음 내용을 학습합니다 도커에는 도커 파일, 이미지, 컨테이너, 네트워크, 스토리지 볼륨, 그리고 플러그인 및 애드온과 같은 기타 개체를 포함합니다.

## 예시
- 이 비디오에서는 다음 내용을 학습합니다 도커에는 도커 파일, 이미지, 컨테이너, 네트워크, 스토리지 볼륨, 그리고 플러그인 및 애드온과 같은 기타 개체를 포함합니다.

- Docker는 볼륨과 바인드 마운트를 사용하여 를 사용하여 컨테이너가 중지된 후에도 데이터를 유지합니다, 그리고 스토리지 플러그인과 같은 플러그인은 외부 스토리지 플랫폼에 연결할 수 있는 기능을 제공합니다. 이 비디오에서는 다음 내용을 학습합니다 도커에는 도커 파일, 이미지, 컨테이너, 네트워크, 스토리지 볼륨, 그리고 플러그인 및 애드온과 같은 기타 개체를 포함합니다.
