# Building and Running Container Images

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/ibm-containers-docker-kubernetes-openshift/lecture/JjETU/building-and-running-container-images)

## 개요
- [음악] 컨테이너 구축 및 실행에 오신 것을 환영합니다 컨테이너를 빌드하고 실행하는 것을 환영합니다.

## 내용
- [음악] 컨테이너 구축 및 실행에 오신 것을 환영합니다 컨테이너를 빌드하고 실행하는 것을 환영합니다.
- 이미지를 사용하여 실행 중인 컨테이너를 만들고 주요 Docker 명령어를 설명합니다.
- 컨테이너를 만들고 실행하는 단계는 다음과 같습니다 컨테이너 실행 도커파일 생성 도커파일을 사용하여 컨테이너 이미지를 생성하고 컨테이너 이미지를 사용하여 실행 중인 컨테이너를 만듭니다.
- 이 빌드를 실행한 후 출력 메시지에는 빌드 컨텍스트를 다음 주소로 보내는 내용이 포함됩니다 Docker 데몬, 성공적으로 빌드됨 , 이미지 생성을 확인하고 성공적으로 내 앱에 태그가 지정되었습니다.
- 빌드 명령은 다음에서 태그를 사용하여 컨테이너 이미지를 만드는 데 사용됩니다 태그가 있는 컨테이너 이미지를 만드는 데 사용됩니다.
- Push 명령은 이미지를 구성된 레지스트리에 저장합니다, 그리고 pull 명령은 구성된 레지스트리에서 이미지를 검색합니다.
- 이 비디오에서는 빌드 명령이 다음과 함께 사용된다는 것을 배웠습니다 도커파일과 함께 컨테이너 이미지를 빌드하는 방법을 배웠습니다.
