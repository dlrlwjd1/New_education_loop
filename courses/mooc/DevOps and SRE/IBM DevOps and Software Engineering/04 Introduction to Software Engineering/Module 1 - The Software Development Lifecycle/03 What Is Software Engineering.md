# What Is Software Engineering

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/introduction-to-software-engineering/lecture/cLsoS/what-is-software-engineering)

## 개요
- 이 비디오를 시청한 후에는 다음을 수행할 수 있습니다 소프트웨어 엔지니어링을 정의합니다, 소프트웨어 엔지니어의 책임을 나열하고, 소프트웨어 개발자와 소프트웨어 엔지니어를 비교하고 대조할 수 있습니다.

## 내용
- 이 비디오를 시청한 후에는 다음을 수행할 수 있습니다 소프트웨어 엔지니어링을 정의합니다, 소프트웨어 엔지니어의 책임을 나열하고, 소프트웨어 개발자와 소프트웨어 엔지니어를 비교하고 대조할 수 있습니다.
- 이 분야에서는 체계적인 접근 방식을 사용하여 비즈니스 요구 사항을 수집하고 분석하여 이러한 비즈니스 요구 사항을 충족하는 소프트웨어 애플리케이션을 설계, 구축 및 테스트하기 위해 체계적인 접근 방식을 사용합니다.
- 소프트웨어 엔지니어링 분야는 1960년대에 하나의 학문으로 자리 잡았고 새로운 기술이 개발되고 소프트웨어 개발에 대한 접근 방식이 더욱 과학적으로 발전했습니다.
- CASE 도구는 여섯 가지 범주로 나눌 수 있습니다, 비즈니스 분석 및 모델링 디버깅 환경과 같은 개발 도구 검증 및 유효성 검사 도구 구성 관리 메트릭 및 측정 그리고 프로젝트 관리.
- 소프트웨어 엔지니어는 소프트웨어 개발에 대해 체계적으로 큰 그림을 그리는 접근 방식을 취합니다, 반면 개발자는 보다 창의적인 접근 방식을 취할 수 있습니다.
- 그리고 소프트웨어 엔지니어와 소프트웨어 개발자 모두 전문 지식을 가지고 있습니다, 하지만 소프트웨어 엔지니어는 전체 시스템을 구축하는 데 그 지식을 사용합니다, 소프트웨어 개발자는 자신의 지식을 사용하여 시스템 내에서 특정 기능을 구현하기 위해 시스템 내에서 특정 기능을 구현하는 데 사용합니다.
- 소프트웨어 엔지니어의 책임은 다음과 같습니다 소프트웨어 시스템을 설계, 구축 및 유지 관리합니다, 코드 작성 및 테스트 이해관계자와의 상담 타사 공급업체 보안 전문가 그리고 다른 팀원들과 협의합니다.
