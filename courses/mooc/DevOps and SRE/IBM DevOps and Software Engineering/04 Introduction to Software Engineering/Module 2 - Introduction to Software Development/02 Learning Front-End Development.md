# Learning Front-End Development

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/introduction-to-software-engineering/lecture/hTvIz/learning-front-end-development)

## 개요
- 온라인 쇼핑 웹 사이트를 탐색하거나, 페이지를 탐색하거나, 다른 제품 범주를 선택하거나, 제품을 비교할 때 웹 사이트의 프런트 엔드와 상호 작용하고 있습니다.

## 내용
- 온라인 쇼핑 웹 사이트를 탐색하거나, 페이지를 탐색하거나, 다른 제품 범주를 선택하거나, 제품을 비교할 때 웹 사이트의 프런트 엔드와 상호 작용하고 있습니다.
- 웹 개발자는 웹 사이트를 만들 때 일반적으로 하이퍼텍스트 마크업 언어, HTML, 캐스케이딩 스타일 시트, CSS 및 JavaScript를 사용합니다.
- 공간에 스타일을 더하기 위해 인테리어 디자이너가 필요한 것처럼 웹 사이트에 필요한 화려함과 매력을 더할 프런트 엔드 개발자가 필요합니다.
- CSS는 프런트 엔드 개발자에게 웹 사이트 및 각 구성 요소에 대한 다양한 스타일 특성 세트를 정의, 적용 및 관리하는 표준 방법을 제공합니다.
- 예를 들어 HTML을 사용하여 페이지에 로그인 버튼을 추가하고 CSS를 사용하여 해당 버튼의 스타일을 지정합니다.
- 예를 들어 모바일 기기에서 제품 웹사이트를 열면 작은 화면 크기에 맞게 자동으로 조정되면서도 모든 기능이 표시됩니다.
- 이들이 만드는 웹 사이트는 여러 브라우저, 여러 운영 체제 및 여러 장치에서 작동해야 합니다.

## 예시
- 예를 들어 HTML을 사용하여 페이지에 로그인 버튼을 추가하고 CSS를 사용하여 해당 버튼의 스타일을 지정합니다.

## 요약
- 예를 들어 모바일 기기에서 제품 웹사이트를 열면 작은 화면 크기에 맞게 자동으로 조정되면서도 모든 기능이 표시됩니다. 이들이 만드는 웹 사이트는 여러 브라우저, 여러 운영 체제 및 여러 장치에서 작동해야 합니다.
