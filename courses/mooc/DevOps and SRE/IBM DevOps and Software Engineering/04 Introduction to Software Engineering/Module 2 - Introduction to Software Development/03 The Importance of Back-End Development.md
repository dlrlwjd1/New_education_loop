# The Importance of Back-End Development

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/introduction-to-software-engineering/lecture/LBkB2/the-importance-of-back-end-development)

## 개요
- 프론트엔드 개발자는 HTML, CSS, JavaScript를 사용하여 웹 사이트와 클라우드 애플리케이션을 만들어 사용자가 클라이언트 소프트웨어에서 보고 상호 작용하는 콘텐츠를 만듭니다.

## 내용
- 프론트엔드 개발자는 HTML, CSS, JavaScript를 사용하여 웹 사이트와 클라우드 애플리케이션을 만들어 사용자가 클라이언트 소프트웨어에서 보고 상호 작용하는 콘텐츠를 만듭니다.
- 백엔드 개발자 작업은 이 서버 인프라 또는 백엔드가 요청을 처리하고, 데이터를 제공하고, 기타 서비스를 안전하게 제공할 수 있도록 하는 데 중점을 둡니다.
- 웹 사이트 또는 클라우드 앱의 수명 주기 전반에 걸쳐 프론트엔드 및 백엔드 개발자는 협업하여 문제를 해결하고 기능을 추가합니다.
- 이를 용이하게 하기 위해 백엔드 개발자는 웹 애플리케이션이 사용하는 언어, 데이터베이스에 올바른 데이터를 쿼리하는 방법, 이 둘을 통합하는 방법을 이해해야 합니다.
- 이미지와 같은 데이터 요청, 양식 작성 사용자의 입력 수락, 신용 카드 번호와 같은 민감한 정보 보호 등 프런트 엔드 클라이언트 상호 작용에는 모두 백엔드 서버의 다양한 서비스가 필요합니다.
- 백엔드 개발자는 데이터베이스의 요청을 처리하기 위해 객체 관계형 매핑 도구 또는 ORM을 사용하여 데이터베이스에 연결하고 올바른 데이터를 검색할 수 있습니다.
- 백엔드 개발자의 일상 업무는 웹 사이트, 클라우드 앱, 모바일 앱을 계속 가동하고 운영할 수 있게 해주는 비하인드 스토리 기능에 초점을 맞춥니다.

## 예시
- 백엔드 개발자의 일상 업무는 웹 사이트, 클라우드 앱, 모바일 앱을 계속 가동하고 운영할 수 있게 해주는 비하인드 스토리 기능에 초점을 맞춥니다.

## 요약
- 백엔드 개발자는 데이터베이스의 요청을 처리하기 위해 객체 관계형 매핑 도구 또는 ORM을 사용하여 데이터베이스에 연결하고 올바른 데이터를 검색할 수 있습니다. 백엔드 개발자의 일상 업무는 웹 사이트, 클라우드 앱, 모바일 앱을 계속 가동하고 운영할 수 있게 해주는 비하인드 스토리 기능에 초점을 맞춥니다.
