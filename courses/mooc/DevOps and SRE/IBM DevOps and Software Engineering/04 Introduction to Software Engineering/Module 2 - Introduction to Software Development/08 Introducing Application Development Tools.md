# Introducing Application Development Tools

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/introduction-to-software-engineering/lecture/AJ2yp/introducing-application-development-tools)

## 개요
- 버전 관리 시스템은 언제 어떤 변경이 이루어졌는지 어떤 변경이 언제, 누가 수행되었는지 추적합니다, 변경 사항 간의 충돌을 해결합니다.

## 내용
- 버전 관리 시스템은 언제 어떤 변경이 이루어졌는지 어떤 변경이 언제, 누가 수행되었는지 추적합니다, 변경 사항 간의 충돌을 해결합니다.
- 버전 관리를 적절히 사용하면 코드가 변경되었을 경우 이전 버전의 코드로 되돌릴 수 있습니다, 그리고 시간이 지남에 따라 코드가 어떻게 발전했는지에 대한 기본적인 정보를 제공할 수 있습니다.
- 버전 관리 기능은 일반적으로 사용 중인 스토리지 시스템과 연결되어 있습니다, 그렇기 때문에 코드 리포지토리를 사용하는 것이 좋습니다, 코드 저장소를 권장하는 이유입니다.
- Git은 리포지토리에 파일을 저장하여 에 파일을 저장하고 변경 사항을 추적할 수 있습니다, 코드를 여러 브랜치로 분할하여 보다 집중적인 개발을 위해 그리고 다시 메인 코드 본문에 병합할 수 있습니다.
- 프레임워크는 따라야 하는 워크플로우를 정의합니다, 필요할 때마다 함수를 호출할 수 있는 라이브러리와 달리 를 호출할 수 있는 라이브러리와 달리 따라야 하는 워크플로를 정의합니다.
- 이들은 워크플로를 어떻게 사용해야 하는지에 대한 의견을 가지고 있으며 그리고 코드가 어떻게 사용되어야 하는지에 대해 코드 작성 방식에 대해 사용자가 결정해야 하는 많은 부분을 제거합니다, 파일 위치, 심지어 파일 이름까지도 결정할 수 있습니다.
- 이 비디오에서는 앞으로 커리어에서 활용할 수 있는 몇 가지 도구에 대해 개발자로서의 커리어에 활용할 수 있는 몇 가지 도구에 대해 배웠습니다, 버전 관리, 라이브러리, 프레임워크 등 개발자로서의 커리어에 도움이 되는 도구에 대해 배웠습니다.
