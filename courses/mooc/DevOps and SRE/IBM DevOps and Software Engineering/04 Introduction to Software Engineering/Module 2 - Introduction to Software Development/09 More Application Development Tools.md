# More Application Development Tools

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/introduction-to-software-engineering/lecture/ywV0v/more-application-development-tools)

## 개요
- CI/CD, 빌드 도구, 패키지 관리자 등 앱을 빌드하고 배포하는 데 도움이 되는 몇 가지 도구를 살펴보겠습니다.

## 내용
- CI/CD, 빌드 도구, 패키지 관리자 등 앱을 빌드하고 배포하는 데 도움이 되는 몇 가지 도구를 살펴보겠습니다.
- 빌드 자동화 서버를 통해 구현되는 지속적 통합 (CI) 은 모든 코드 구성 요소가 원활하게 작동하도록 합니다.
- CI 빌드 환경을 사용하면 프로젝트 변경 속도에 따라 새로 개발된 코드를 적어도 매일, 적어도 매시간 통합할 수 있습니다.
- 지속적 전달 (CD) 은 CI가 끝나는 지점에서 시작됩니다.CI 프로세스가 코드를 자동으로 빌드하고 테스트한 다음 CD는 빌드의 모든 코드 변경 사항을 테스트 또는 스테이징 환경에 배포합니다.
- 이러한 환경에서는 어떤 변경이 있었는지, 어떤 순서로, 어떤 종속성이 존재하는지, 다음 빌드에 무엇을 통합해야 하는지 추적하기가 매우 어려울 수 있습니다.
- macOS의 경우 - 홈브루 및 맥포트.애플리케이션의 일부로 개발된 모든 라이브러리 또는 유틸리티 코드는 클라우드 애플리케이션 패키지 관리자를 통해 관리됩니다.
- 이 비디오에서는 CI/CD, 빌드 도구, 패키지 및 패키지 관리자를 포함하여 개발자 경력에서 활용할 수 있는 몇 가지 도구에 대해 배웠습니다.

## 예시
- CI/CD는 개발자가 빈번한 변경 사항을 안정적으로 제공할 수 있도록 하는 데브옵스 팀을 위한 모범 사례입니다.

## 요약
- macOS의 경우 - 홈브루 및 맥포트.애플리케이션의 일부로 개발된 모든 라이브러리 또는 유틸리티 코드는 클라우드 애플리케이션 패키지 관리자를 통해 관리됩니다. 이 비디오에서는 CI/CD, 빌드 도구, 패키지 및 패키지 관리자를 포함하여 개발자 경력에서 활용할 수 있는 몇 가지 도구에 대해 배웠습니다.
