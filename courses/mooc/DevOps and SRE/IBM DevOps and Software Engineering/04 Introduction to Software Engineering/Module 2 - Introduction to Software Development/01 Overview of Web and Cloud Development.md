# Overview of Web and Cloud Development

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/introduction-to-software-engineering/lecture/G044X/overview-of-web-and-cloud-development)

## 개요
- 웹 사이트에서 표시되는 콘텐츠에는 이전에 서버에 저장되어 있거나 (“정적”이라고 함) 클라이언트가 요청할 때마다 생성되는 요소 (“동적”이라고 함) 가 포함될 수 있습니다.

## 내용
- 웹 사이트에서 표시되는 콘텐츠에는 이전에 서버에 저장되어 있거나 (“정적”이라고 함) 클라이언트가 요청할 때마다 생성되는 요소 (“동적”이라고 함) 가 포함될 수 있습니다.
- Cloud Apps는 클라우드 기반 백엔드 인프라, 클라우드 기반 데이터 스토리지 및 데이터 처리, 기타 클라우드 서비스와 원활하게 작동하도록 구축되어 확장성과 복원력이 뛰어납니다.
- 백엔드 코딩은 일반적으로 웹 사이트 또는 앱이 작동하도록 하는 로직과 기능, 데이터를 안전하게 유지하는 인증 프로세스를 처리합니다.
- 백엔드 개발자는 관계형 또는 NoSQL 데이터베이스를 사용할 수도 있으며 대규모 프로젝트에서는 데이터베이스 관리자와 협업할 수도 있습니다.
- 풀스택 개발자는 프론트엔드 및 백엔드 환경 모두에서 기술, 지식 및 경험을 갖추고 있습니다.어떤 방식으로 전문화하든 작업에 도움이 되는 적절한 도구가 필요합니다.
- 통합 개발 환경 (IDE) 은 코드 편집 외에도 이러한 추가 기능 중 일부를 통합하여 코드를 더 쉽게 빌드하고 관리할 수 있도록 합니다.
- 코드 에디터와 IDE의 예로는 서브라임 텍스트, 아톰, 빔, VS 코드, 비주얼 스튜디오, 이클립스, 넷빈즈 등이 있습니다.
