# Insiders' Viewpoint - Tools and Technologies

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/introduction-to-software-engineering/lecture/4xkhn/insiders-viewpoint-tools-and-technologies)

## 개요
- 내부자의 관점: 도구 및 기술에 오신 것을 환영합니다.이 비디오에서는 전문가들이 소프트웨어 엔지니어링 프로젝트를 위해 즐겨 사용하는 도구와 기술에 대해 논의하는 이야기를 들을 것입니다.

## 내용
- 내부자의 관점: 도구 및 기술에 오신 것을 환영합니다.이 비디오에서는 전문가들이 소프트웨어 엔지니어링 프로젝트를 위해 즐겨 사용하는 도구와 기술에 대해 논의하는 이야기를 들을 것입니다.
- 사실 저는 정적 웹 사이트를 만들기 시작했고, 그 후 JavaScript를 사용하여 동적 콘텐츠를 넣는 방법을 서서히 배웠습니다.그런 다음 Java 또는 PHP를 사용하여 서버에 백엔드 시스템을 구축해야 했습니다.
- 백엔드 개발의 경우 도구가 상당히 다양하므로 구체적인 권장 사항을 제시하기가 어렵습니다.하지만 Node.js 를 선택하면 앞서 언급한 것과 동일한 도구를 프론트엔드 개발에 사용할 수 있습니다.그렇지 않으면 어떤 IDE 확장 프로그램을 사용할 수 있는지, 어떤 린터와 자동 포맷터를 사용할 수 있는지 살펴보는 것이 좋습니다.
- React JS는 페이스북에서 매우 유명하게 개발되었습니다.Angular는 Google에서 운영하는 프레임워크로, 단일 페이지 애플리케이션을 개발할 수 있습니다.SPA의 jQuery는 아마도 John Resig가 2006년에 만든 가장 인기 있고 가장 오래된 라이브러리일 것입니다.
- 매우 많은 수의 동시 연결을 제공할 수 있는 비동기식 단일 스레드 아키텍처를 사용합니다.플라스크는 파이썬에서 사용되는 프레임워크로 파이썬에서 널리 사용되고 있으며 Java 기반의 Spring 프레임워크는 수년간 사용되어 왔으며 여전히 인기가 있습니다.
- Express JS를 사용하여 JavaScript를 사용하여 프런트 엔드와 백 엔드를 쉽게 코딩할 수 있습니다.Express JS는 Google V8 엔진에서 지원되므로 처리 지연이나 오류없이 더 높은 성능을 얻을 수 있습니다.
- 화살표 함수나 도트 도트 연산자와 같은 코드를 더 깔끔하고 읽기 쉽고 더 아름답게 만들 수 있기 때문입니다.그래서 저는 여러분이 자바스크립트를 배우고 나면 ES6에 대해 조금 더 깊이 들어가서 재미있게 사용해 보길 권합니다.
