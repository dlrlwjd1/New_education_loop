# Software Engineering Job Titles

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/introduction-to-software-engineering/lecture/EeU6w/software-engineering-job-titles)

## 개요
- 프런트 엔드 엔지니어, 백엔드 엔지니어, 풀스택 엔지니어, DevOps 엔지니어, 소프트웨어 품질 보증 엔지니어, 소프트웨어 통합 엔지니어, 소프트웨어 보안 엔지니어, 모바일 앱 개발자, 게임 개발자, 프론트엔드 엔지니어는 소프트웨어 솔루션의 사용자 인터페이스 (UI) 개발에 중점을 둡니다.

## 내용
- 프런트 엔드 엔지니어, 백엔드 엔지니어, 풀스택 엔지니어, DevOps 엔지니어, 소프트웨어 품질 보증 엔지니어, 소프트웨어 통합 엔지니어, 소프트웨어 보안 엔지니어, 모바일 앱 개발자, 게임 개발자, 프론트엔드 엔지니어는 소프트웨어 솔루션의 사용자 인터페이스 (UI) 개발에 중점을 둡니다.
- 이러한 유형의 역할에서는 애플리케이션 프로그래밍 인터페이스 ( API) 를 사용하여 데이터 및 데이터베이스 액세스, 정보 로깅, 시스템 캐싱과 같은 작업을 수행하는 기능을 구현하는 소프트웨어의 핵심 논리를 담당합니다.
- 이러한 유형의 역할에서는 프런트 엔드 및 백엔드 엔지니어의 기술을 사용하여 응용 프로그램 또는 웹 사이트의 사용자 인터페이스와 백엔드 기능을 모두 만들 수 있습니다.
- 풀스택 엔지니어의 주요 기술에는 웹 개발 언어, 프로그래밍 언어, UX, UI 및 백엔드 프레임워크, 웹 및 애플리케이션 서버, 데이터베이스, API 및 웹 서비스, 배포 및 컨테이너화 도구가 포함됩니다.
- DevOps 엔지니어가 사용할 가능성이 높은 기술, 제품에는 소스 코드 관리 도구, 프로그래밍 언어 및 프레임워크, 스크립트, 배포, 컨테이너화 및 모니터링 도구가 포함됩니다.
- 소프트웨어 QA 엔지니어의 주요 기술에는 프로그래밍 언어, 셸 스크립팅, 버그 추적 및 문제 관리 도구, 테스트 자동화 도구, 응용 프로그램 배포 방법에 따른 특정 소프트웨어 스택이 포함됩니다.
- 웹 기술을 사용하여 프런트 엔드 앱을 만들 수 있을 뿐만 아니라 특정 유형의 장치와 상호 작용하는 백엔드 코드를 작성하기 위한 다양한 플랫폼을 배우게 됩니다.

## 예시
- 웹 기술을 사용하여 프런트 엔드 앱을 만들 수 있을 뿐만 아니라 특정 유형의 장치와 상호 작용하는 백엔드 코드를 작성하기 위한 다양한 플랫폼을 배우게 됩니다.

## 요약
- 소프트웨어 QA 엔지니어의 주요 기술에는 프로그래밍 언어, 셸 스크립팅, 버그 추적 및 문제 관리 도구, 테스트 자동화 도구, 응용 프로그램 배포 방법에 따른 특정 소프트웨어 스택이 포함됩니다. 웹 기술을 사용하여 프런트 엔드 앱을 만들 수 있을 뿐만 아니라 특정 유형의 장치와 상호 작용하는 백엔드 코드를 작성하기 위한 다양한 플랫폼을 배우게 됩니다.
