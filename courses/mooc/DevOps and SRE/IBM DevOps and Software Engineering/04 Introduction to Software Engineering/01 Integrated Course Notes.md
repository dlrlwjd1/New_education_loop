# Introduction to Software Engineering

## 개요
- SDLC, 프로그래밍 기초, 설계·아키텍처 패턴과 소프트웨어 엔지니어 직무를 살핀다.

## 내용
- 요구 분석, 설계, 구현, 테스트, 배포, 유지보수는 피드백을 통해 반복되는 수명주기다.
- 코드 품질은 명확한 이름, 작은 함수, 버전 관리, 리뷰, 자동 테스트와 문서로 유지한다.
- architecture는 구성요소와 상호작용을, design pattern은 반복되는 문제의 검증된 구조를 제공한다. 결합도는 낮추고 응집도는 높인다.
- front-end, back-end, full-stack, test, DevOps 역할은 초점이 다르지만 협업과 문제 해결 역량을 공유한다.

## 예시
- MVC는 입력·화면·업무 상태를 분리해 변경 영향을 제한하지만 작은 애플리케이션에는 불필요한 계층이 될 수 있다.

## 요약
- 6개 모듈은 SDLC, 개발, 프로그래밍, 아키텍처·패턴, 직무, 최종 프로젝트로 구성된다.
