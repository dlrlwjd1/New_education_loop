## 개요
- 플로차트는 다양한 기호, 도형, 도형을 사용하여 알고리즘을 그래픽 또는 그림으로 표현한 것입니다 다양한 크기와 색상의 기호, 도형, 화살표를 사용하여 프로세스나 프로그램을 설명하기 위한 그래픽 또는 그림 표현입니다.

## 내용
- 플로차트는 다양한 기호, 도형, 도형을 사용하여 알고리즘을 그래픽 또는 그림으로 표현한 것입니다 다양한 크기와 색상의 기호, 도형, 화살표를 사용하여 프로세스나 프로그램을 설명하기 위한 그래픽 또는 그림 표현입니다.
- 의사 코드는 비공식적인 유형의 프로그래밍 설명으로, 엄격한 프로그래밍 언어 구문이나 기본 기술 고려 사항이 프로그래밍 언어 구문이나 기본 기술 고려 사항이 필요하지 않은 비공식적인 유형의 프로그래밍 설명입니다.
- 시스템 설계자는 프로그래머가 소프트웨어 프로젝트의 요구 사항을 이해하고 그에 따라 코드를 요구 사항을 이해하고 그에 따라 코드를 조정할 수 있도록 의사 코드를 작성합니다.
- 의사 코드는 프로그래머의 두뇌와 컴퓨터 사이의 다리 역할을 합니다 논리적 패턴을 따르는 명령어를 계획할 수 있는 기능을 제공하는 코드 실행기입니다, 모든 기술적 세부 사항을 포함하지 않고도 논리적 패턴을 따르는 명령을 계획할 수 있는 기능을 제공합니다.
- 다음은 사용자가 홀수 또는 짝수를 입력했는지 확인하기 위해 작성된 의사 코드의 한 예입니다 숫자를 입력했는지 확인하기 위해 작성된 의사 코드의 예입니다: 다음 예제는 C++로 작성된 의사 코드를 표시합니다: 의사 코드를 사용하면 플로차트보다 많은 이점이 있습니다.
- 플로차트는 알고리즘을 그림으로 표현한 것으로, 단계를 화살표로 연결된 다양한 종류의 상자( 의 다양한 종류로 순서를 나타내는 화살표로 연결된 알고리즘을 그림으로 표현한 것입니다.
- 의사 코드의 주요 목표는 프로그램의 각 줄이 무엇을 해야 하는지 정확히 설명하는 것입니다 해야 할 일을 정확히 설명하여 프로그래머가 코드 작성 단계를 더 쉽게 수행할 수 있도록 하는 것입니다.
