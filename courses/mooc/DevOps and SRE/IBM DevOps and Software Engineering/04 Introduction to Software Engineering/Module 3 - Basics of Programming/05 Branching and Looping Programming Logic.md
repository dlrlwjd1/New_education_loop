# Branching and Looping Programming Logic

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/introduction-to-software-engineering/lecture/okO5Y/branching-and-looping-programming-logic)

## 개요
- 일반적으로 프로그램은 컴퓨터에 수행할 작업을 지시하는 명령과 프로그램이 실행될 때 사용하는 데이터로 구성됩니다.변수의 값은 프로그램에 전달되는 조건이나 정보에 따라 변경될 수 있습니다.부울 로직은 변수와 함께 프로그래밍의 기초를 형성합니다.

## 내용
- 일반적으로 프로그램은 컴퓨터에 수행할 작업을 지시하는 명령과 프로그램이 실행될 때 사용하는 데이터로 구성됩니다.변수의 값은 프로그램에 전달되는 조건이나 정보에 따라 변경될 수 있습니다.부울 로직은 변수와 함께 프로그래밍의 기초를 형성합니다.
- 분기 로직은 프로그램 실행 중에 특정 조건이 충족되는지 여부에 따라 컴퓨터 프로그램이 다른 명령 집합에 따라 결정을 내리는 것입니다.
- if 문은 프로그램이 지정된 기준에 따라 결정을 내리도록 안내하는 의사 결정 구조입니다.if 문은 특정 조건이 충족되면 하나의 코드 세트 (TRUE) 를 실행하고, 조건이 충족되지 않으면 다른 코드 세트 (FALSE) 를 실행합니다.
- if-else 문을 사용하면 프로그램이 실제 코드 블록 또는 거짓 코드 블록을 실행하므로 항상 if-else 문을 사용하여 특정 작업을 수행합니다.
- 컴퓨터 프로그래밍 언어에서 switch 문은 변수 또는 표현식의 값이 검색과 맵을 통해 프로그램 실행의 제어 흐름을 변경할 수 있도록 하는 데 사용되는 일종의 선택 제어 메커니즘입니다.
- 이제 루핑 프로그래밍의 논리를 살펴보겠습니다.루프는 특정 조건에 도달할 때까지 계속 반복되는 명령 시퀀스입니다.일반적으로 데이터 검색 및 변경과 같은 특정 프로세스를 수행한 다음 카운터가 지정된 수에 도달했는지 여부와 같은 일부 조건을 확인합니다.그렇지 않은 경우 시퀀스의 다음 명령은 시리즈의 첫 번째 명령으로 돌아가서 시퀀스를 반복하는 것입니다.조건에 도달하면 다음 명령이 다음 순차 명령으로 “넘어가거나” 루프 외부로 분기됩니다.루프는 프로그램 작성에 일반적으로 사용되는 기본적인 프로그래밍 아이디어입니다.
- 부울 표현식에는 true와 false 중 두 가지 값만 사용할 수 있으며 변수는 보다 광범위한 프로그램 내에서 함수나 서브루틴으로 전달되는 값을 할당합니다.변수에 있는 값은 프로그램에 전달된 조건이나 정보에 따라 변경될 수 있습니다 .

## 예시
- 부울 표현식에는 true와 false 중 두 가지 값만 사용할 수 있으며 변수는 보다 광범위한 프로그램 내에서 함수나 서브루틴으로 전달되는 값을 할당합니다.변수에 있는 값은 프로그램에 전달된 조건이나 정보에 따라 변경될 수 있습니다 .
