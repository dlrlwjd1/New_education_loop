# Introduction to Programming Concepts Part 2

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/introduction-to-software-engineering/lecture/4vGgj/introduction-to-programming-concepts-part-2)

## 개요
- 함수는 프로그램을 프로그램 내에서 특정 작업을 수행하는 여러 모듈식 구성 요소로 분리하도록 장려하는 모듈식 프로그래밍 소프트웨어 개발 방법론의 결과입니다.

## 내용
- 함수는 프로그램을 프로그램 내에서 특정 작업을 수행하는 여러 모듈식 구성 요소로 분리하도록 장려하는 모듈식 프로그래밍 소프트웨어 개발 방법론의 결과입니다.
- 일부 프로그래밍 언어에서는 이를 서브루틴, 프로시저, 메서드 또는 모듈과 같이 다른 것으로 지칭할 수 있지만 대부분의 최신 프로그래밍 언어에서는 이를 함수라고 합니다.
- 함수를 구성하는 코드 블록이 식별되는 방식은 프로그래밍 언어마다 다릅니다.예를 들어 중괄호를 사용하는 사람도 있고, 시작 및 끝 문을 사용하는 사람도 있고, 들여쓰기를 사용하는 사람도 있습니다.
- 가장 먼저 해야 할 일은 함수를 정의 (또는 생성) 하는 것입니다.함수를 정의할 때 함수 키워드를 제공한 다음 함수에 고유한 이름을 지정하고 함수 본문을 구성하는 명령문을 입력합니다.
- 함수를 정의한 후에는 함수를 호출 (또는 호출) 해야 합니다.함수를 호출하면 함수 내에서 지정된 작업이 지정된 매개 변수를 사용하여 수행됩니다.
- “물체는 어떤 상태에 있을 수 있습니까?”및 “객체는 어떤 동작을 수행할 수 있습니까?” 이러한 질문에 대한 답을 생각해 보면, 이 질문에 대한 답이 사물마다 다르다는 것을 알게 될 것입니다.
- 객체는 필드 (일부 프로그래밍 언어에서는 변수라고 함) 에 속성을 저장하고 메서드 (일부 프로그래밍 언어에서는 함수라고 함) 를 통해 동작을 노출합니다.

## 예시
- 함수를 구성하는 코드 블록이 식별되는 방식은 프로그래밍 언어마다 다릅니다.예를 들어 중괄호를 사용하는 사람도 있고, 시작 및 끝 문을 사용하는 사람도 있고, 들여쓰기를 사용하는 사람도 있습니다.
