# Query and Assembly Programming Languages

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/introduction-to-software-engineering/lecture/yo43u/query-and-assembly-programming-languages)

## 개요
- 이 동영상을 시청한 후에는 다음을 수행할 수 있습니다 고급 프로그래밍 언어와 저수준 프로그래밍 언어를 비교할 수 있습니다, 쿼리 언어에 대해 설명합니다, 그리고 어셈블리 언어에 대해 설명합니다.

## 내용
- 이 동영상을 시청한 후에는 다음을 수행할 수 있습니다 고급 프로그래밍 언어와 저수준 프로그래밍 언어를 비교할 수 있습니다, 쿼리 언어에 대해 설명합니다, 그리고 어셈블리 언어에 대해 설명합니다.
- 쿼리 및 어셈블리 프로그래밍 언어에 대해 알아보겠습니다, 먼저 프로그래밍 언어를 하이레벨과 로우레벨의 두 가지 수준으로 를 하이레벨과 로우레벨의 두 가지 수준으로 분류해야 합니다.
- 고급 프로그래밍 언어의 예 에는 다음과 같은 쿼리 언어가 포함됩니다 구조화된 쿼리 언어 또는 SQL, 구조화된 프로그래밍 언어(예: PASCAL, 파이썬과 같은 객체 지향 프로그래밍 언어 등이 있습니다.
- 쿼리 언어가 주로 사용됩니다 데이터베이스에서 데이터를 요청하거나 또는 데이터베이스에서 데이터를 만들고, 읽고, 업데이트하고, 삭제하는 데 주로 쿼리 언어가 사용됩니다.
- 쿼리 문은 다음과 같은 용도로도 사용할 수 있습니다 다른 관리 기능을 수행하는 데 사용자 만들기 및 권한 수정과 같은 다른 관리 기능도 수행할 수 있습니다.
- 어셈블리 언어는 하드웨어 제조업체의 프로세서 아키텍처와 하드웨어 제조업체의 프로세서 아키텍처와 밀접하게 연관되어 있습니다, 따라서 각 CPU 유형 에는 일반적으로 고유한 어셈블리 언어가 있습니다.
- 어셈블리 언어와의 또 다른 주요 차이점 중 하나는 의 또 다른 주요 차이점은 컴파일러나 인터프리터 대신 어셈블러( 를 사용하여 번역된다는 점입니다, 그리고 하나의 문이 하나의 머신 코드 명령어로 번역된다는 점입니다, 하나의 명령문이 하나의 기계어 명령어로 하나의 문장이 여러 개의 머신 코드 명령어로 여러 개의 머신 코드 명령어로 번역할 수 있는 하이레벨 언어와는 다릅니다.
