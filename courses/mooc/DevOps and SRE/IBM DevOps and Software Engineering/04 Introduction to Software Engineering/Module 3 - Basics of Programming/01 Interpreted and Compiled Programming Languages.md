# Interpreted and Compiled Programming Languages

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/introduction-to-software-engineering/lecture/kK7GG/interpreted-and-compiled-programming-languages)

## 개요
- 이 비디오를 시청한 후에는 해석된 프로그래밍 언어를 식별하고 컴파일된 프로그래밍 언어를 식별할 수 있습니다.

## 내용
- 이 비디오를 시청한 후에는 해석된 프로그래밍 언어를 식별하고 컴파일된 프로그래밍 언어를 식별할 수 있습니다.
- 따라서 컴퓨터와 더 쉽게 통신할 수 있도록 사람이 읽을 수 있는 프로그래밍 언어가 있습니다.
- Python과 같이 해석되거나 스크립팅된 언어로 작성된 프로그램은 컴퓨터 운영 체제 또는 웹 브라우저의 프로그래밍 인터프리터를 통해 실행됩니다.
- 프로그래밍 언어는 사람이 읽을 수 있는 코드로 되어 있으므로 인터프리터는 사람이 읽을 수 있는 스크립트 코드를 가져와서 이를 기계 코드로 변환하여 컴퓨터가 요청된 작업을 완료할 수 있도록 한다는 점을 기억하십시오.
- 일반적으로 해석되는 프로그래밍 언어 유형의 예로는 웹 브라우저 인터프리터를 통해 실행되는 간단한 스크립팅 언어인 JavaScript , 개발자가 쉽게 배우고 사용할 수 있어 널리 사용되는 언어인 Python, 배우고 사용하기 쉬운 범용 경량 게임 스크립팅 언어인 Lua가 있습니다.
- 이들은 Microsoft Windows, Apple의 Mac OS 및 오픈 소스 운영 체제인 Linux와 같은 많은 운영 체제에서 사용됩니다.
- 일반적으로 사용하는 컴파일된 프로그램은 Linux, Microsoft Windows, Apple의 Mac OS 또는 Android와 같은 장치의 운영 체제입니다.

## 예시
- 일반적으로 사용하는 컴파일된 프로그램은 Linux, Microsoft Windows, Apple의 Mac OS 또는 Android와 같은 장치의 운영 체제입니다.

## 요약
- 이들은 Microsoft Windows, Apple의 Mac OS 및 오픈 소스 운영 체제인 Linux와 같은 많은 운영 체제에서 사용됩니다. 일반적으로 사용하는 컴파일된 프로그램은 Linux, Microsoft Windows, Apple의 Mac OS 또는 Android와 같은 장치의 운영 체제입니다.
