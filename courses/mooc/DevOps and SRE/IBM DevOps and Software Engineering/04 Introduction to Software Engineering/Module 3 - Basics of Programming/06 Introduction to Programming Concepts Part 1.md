# Introduction to Programming Concepts Part 1

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/introduction-to-software-engineering/lecture/fWAe2/introduction-to-programming-concepts-part-1)

## 개요
- 소프트웨어 개발자는 식별자를 사용하여 저장된 값, 메서드, 인터페이스 또는 클래스와 같은 프로그램 구성 요소에 사용자 지정 이름 레이블을 할당하여 프로그램 구성 요소를 참조합니다.

## 내용
- 소프트웨어 개발자는 식별자를 사용하여 저장된 값, 메서드, 인터페이스 또는 클래스와 같은 프로그램 구성 요소에 사용자 지정 이름 레이블을 할당하여 프로그램 구성 요소를 참조합니다.
- 이는 pi의 수학적 값과 같은 숫자 상수일 수도 있고, 게임 내 플레이어 이름과 같이 일정하게 유지되는 텍스트 문자열일 수도 있습니다.
- 예를 들어 파이, 원가, 세율과 같은 프로그램 내의 숫자 값을 참조하도록 하려는 경우 동일한 숫자 값을 반복해서 다시 입력하는 대신 값에 대한 상수를 선언하고 파이 밑줄 값, 비용 밑줄 가격 또는 세금 밑줄 비율과 같이 의미 있는 이름을 지정할 수 있습니다.
- 하나는 코드의 가독성을 높이기 위한 것이고, 다른 하나는 지정된 값이 나중에 변경될 경우 코드 내에서 해당 숫자 값의 모든 인스턴스를 찾아 변경하는 대신 상수에서 한 번만 변경하면 된다는 것입니다.
- 또는 변수를 정의할 때 초기 값을 할당하지 않고 대신 프로그램 내의 지침에 따라 나중에 값을 할당하도록 결정할 수 있습니다.
- 배열을 선언할 때는 배열에 포함된 값의 데이터 유형 (예: 정수, Boolean 또는 문자열) 을 지정한 다음 포함할 수 있는 최대 요소 수를 지정합니다.배열을 선언하는 구문은 먼저 데이터 유형을 지정한 다음 배열 이름을 지정한 다음 대괄호로 묶어 배열의 최대 크기를 지정하는 것입니다.
- 벡터를 선언하는 구문은 먼저 벡터의 컨테이너 유형을 지정한 다음 꺾쇠 괄호 안에 데이터 유형을 지정한 다음 배열 이름을 지정하는 것입니다.

## 예시
