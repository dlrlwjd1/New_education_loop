# Architectural Patterns in Software

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/introduction-to-software-engineering/lecture/cNdAw/architectural-patterns-in-software)

## 개요
- 이 비디오를 시청한 후에는 2계층, 3계층, P2P, 이벤트 기반 및 마이크로서비스와 같은 다양한 소프트웨어 아키텍처를 설명할 수 있습니다.

## 내용
- 이 비디오를 시청한 후에는 2계층, 3계층, P2P, 이벤트 기반 및 마이크로서비스와 같은 다양한 소프트웨어 아키텍처를 설명할 수 있습니다.
- 클라이언트-서버라고도 하는 2계층 아키텍처는 서버가 클라이언트에 전달되는 대부분의 리소스와 서비스를 호스팅, 전달 및 관리하는 컴퓨팅 모델입니다.
- 이 유형의 아키텍처에는 일반적으로 네트워크 연결을 통해 서버 구성 요소에 연결된 클라이언트 컴퓨터가 두 대 이상 있습니다.
- 3계층 아키텍처 또는 계층이 3개 이상인 n-계층 아키텍처가 가장 일반적인 소프트웨어 아키텍처입니다.
- 3계층 아키텍처는 단일 소프트웨어 단위로 함께 작동하는 여러 수평 계층으로 구성됩니다.
- 웹 서버를 사용하여 사용자 인터페이스를 제공하고, 응용 프로그램 서버를 사용하여 사용자 입력을 처리하고, 데이터 관리를 처리하는 데이터베이스 서버를 사용합니다.
- 또한 피어투피어 아키텍처에서는 단일 시스템이 클라이언트와 서버를 모두 나타내는 반면 2계층 아키텍처는 클라이언트와 서버를 구분하기 때문에 피어투피어는 2계층일 수 없습니다.

## 예시
- 예를 들어 3계층 아키텍처는 마이크로서비스 기반일 수도 있고 P2P 아키텍처도 이벤트 기반일 수 있습니다.

## 요약
- 웹 서버를 사용하여 사용자 인터페이스를 제공하고, 응용 프로그램 서버를 사용하여 사용자 입력을 처리하고, 데이터 관리를 처리하는 데이터베이스 서버를 사용합니다. 또한 피어투피어 아키텍처에서는 단일 시스템이 클라이언트와 서버를 모두 나타내는 반면 2계층 아키텍처는 클라이언트와 서버를 구분하기 때문에 피어투피어는 2계층일 수 없습니다.
