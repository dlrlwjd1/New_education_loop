# Production Deployment Components

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/introduction-to-software-engineering/lecture/w68SQ/production-deployment-components)

## 개요
- 이 계층에는 트래픽을 다른 애플리케이션 서버로 라우팅하는 앱 로드 밸런서 또는 프록시 서버가 포함됩니다.

## 내용
- 이 계층에는 트래픽을 다른 애플리케이션 서버로 라우팅하는 앱 로드 밸런서 또는 프록시 서버가 포함됩니다.
- 또한 모든 배포에 이러한 구성 요소 모두가 필요한 것은 아닙니다.예를 들어, 일부 환경에서는 웹 서버 외에 애플리케이션 서버가 모두 필요하지 않을 수 있습니다.
- 웹 및 응용 프로그램 서버는 클라이언트라는 다른 컴퓨터 프로그램에 서비스, 리소스, 데이터 또는 응용 프로그램을 제공하는 소프트웨어 또는 컴퓨터입니다.
- 주요 작업은 최종 사용자와 서버 측 애플리케이션 코드 간의 상호 작용을 가능하게 하는 것입니다.애플리케이션 코드는 데이터의 생성 , 저장 및 변경 방법을 결정하는 비즈니스 로직을 나타냅니다.
- 프록시 서버는 로드 밸런싱, 시스템 최적화, 캐싱, 방화벽 역할, 요청 소스 숨기기, 암호화, 멀웨어 검사 등과 같은 다양한 용도로 사용될 수 있습니다.또한 프록시 서버는 네트워크를 통해 흐르는 데이터의 효율성, 개인 정보 보호 및 보안을 개선할 수 있습니다.
- 프로덕션 환경에 필요한 일반적인 구성 요소에는 방화벽, 로드 밸런서, 웹 및 애플리케이션 서버, 프록시 서버, 데이터베이스 서버가 포함됩니다.
- 애플리케이션 서버는 자체 머신에서 앱을 실행하는 클라이언트가 아닌 비즈니스 로직을 실행하고 클라이언트에게 애플리케이션을 제공하며, 마지막으로 데이터베이스 서버는 데이터베이스 관리 시스템을 통해 데이터 흐름을 저장하고 제어합니다.

## 예시
- 또한 모든 배포에 이러한 구성 요소 모두가 필요한 것은 아닙니다.예를 들어, 일부 환경에서는 웹 서버 외에 애플리케이션 서버가 모두 필요하지 않을 수 있습니다.

## 요약
- 프로덕션 환경에 필요한 일반적인 구성 요소에는 방화벽, 로드 밸런서, 웹 및 애플리케이션 서버, 프록시 서버, 데이터베이스 서버가 포함됩니다. 애플리케이션 서버는 자체 머신에서 앱을 실행하는 클라이언트가 아닌 비즈니스 로직을 실행하고 클라이언트에게 애플리케이션을 제공하며, 마지막으로 데이터베이스 서버는 데이터베이스 관리 시스템을 통해 데이터 흐름을 저장하고 제어합니다.
