# Software Design and Modeling

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/introduction-to-software-engineering/lecture/7ivJf/software-design-and-modeling)

## 개요
- 커플링은 서로 다른 모듈 간의 통신입니다.시스템이 느슨하게 연결되려면 한 구성 요소의 변경 사항이 다른 구성 요소에 미치는 영향이 최소화되도록 모듈이 약하게 연결되어야 합니다.루즈 커플링은 서비스 지향 아키텍처와 마이크로서비스 기반 아키텍처 패턴에서 자주 사용되는 아키텍처 원칙이며, 이에 대해서는 이 모듈의 뒷부분에서 설명합니다.

## 내용
- 커플링은 서로 다른 모듈 간의 통신입니다.시스템이 느슨하게 연결되려면 한 구성 요소의 변경 사항이 다른 구성 요소에 미치는 영향이 최소화되도록 모듈이 약하게 연결되어야 합니다.루즈 커플링은 서비스 지향 아키텍처와 마이크로서비스 기반 아키텍처 패턴에서 자주 사용되는 아키텍처 원칙이며, 이에 대해서는 이 모듈의 뒷부분에서 설명합니다.
- 통합 모델링 언어의 약자인 UML은 복잡한 소프트웨어 시스템의 아키텍처, 설계 및 구현을 시각적으로 표현하는 방법입니다.UML은 개발 프로세스 전반에서 사용할 수 있는 표준화된 모델링 언어입니다.
- UML을 사용하여 아키텍처, 동작 및 구조를 개발 팀과 커뮤니케이션하면 몇 가지 이점이 있습니다.UML 다이어그램의 가장 큰 장점은 코딩이 시작되기 전에 기능을 계획할 수 있어 시간과 비용을 절약할 수 있다는 것입니다.둘째, 다이어그램을 사용하면 새로운 팀원이나 팀을 바꾸는 개발자들이 빠르게 적응할 수 있도록 할 수 있습니다.
- 마지막으로, 시스템을 시각적으로 표현하면 개발자가 모듈 간의 관계를 볼 수 있기 때문에 소스 코드를 탐색할 수 있습니다.따라서 UML 다이어그램에는 여러 유형이 있지만 일반적으로 UML 다이어그램은 동작 다이어그램과 구조적 다이어그램으로 분류할 수 있습니다.
- 상태 전환 다이어그램이라는 UML 다이어그램을 사용하여 시스템의 동작을 설명하고 표현할 수 있습니다.상태 전환 다이어그램은 시스템의 다양한 상태와 시스템의 상태 변경을 유발하는 이벤트를 설명하는 상태 및 이벤트 모음입니다.표시된 다이어그램은 병원에서 의사를 만나러 가는 환자를 모델링한 상태 전환 다이어그램의 예입니다.각 상태에는 “대기 중”, “검사 중”, “의사와 함께” 등이 있습니다.화살표는 한 상태에서 다른 상태로의 가능한 전환을 나타내며 전환을 트리거하는 이벤트의 이름을 지정합니다.
- 여기에 표시된 상호 작용 다이어그램의 유형인 시퀀스 다이어그램은 시간에 따른 개체 간의 통신을 표시합니다.이 예는 온라인 포털에서 예약을 하는 환자를 보여줍니다.이것은 행동 UML 다이어그램의 또 다른 예입니다.
- 상태 전환 다이어그램은 시스템의 다양한 상태와 상태 변경을 유발하는 이벤트를 설명하는 상태 및 이벤트 모음을 포함하는 동작 모델입니다.

## 예시
- 상태 전환 다이어그램은 시스템의 다양한 상태와 상태 변경을 유발하는 이벤트를 설명하는 상태 및 이벤트 모음을 포함하는 동작 모델입니다.
