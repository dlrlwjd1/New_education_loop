# Summary & Highlights - Introducing OWASP Top 10

> MOOC 읽기 자료 · [원본 강의](https://www.mooc.org/learn/application-security-for-developers-devops/supplement/JO6pk/summary-highlights-introducing-owasp-top-10)

## 개요
- Module 3 전반부(OWASP Top 10 소개와 1~10위 취약점)의 핵심 내용을 정리한 공식 요약.

## 내용
- OWASP(Open Web Application Security Project) Top 10은 현재의 소프트웨어 보안 취약점 우려 사항을 식별하는 리포트.
- OWASP Top 10을 개발하는 5대 주요 단계: 일정 계획과 데이터 요청 공고, 업계 설문, 데이터 분석, 데이터와 설문에서 나온 카테고리로 리스트 초안 작성 후 리뷰, 합의 도달 후 리스트 발표.
- 해커가 접근 제어를 악용하면 애플리케이션 보안을 손상시키고, 회사 평판을 훼손하고, 재정적 손실을 초래.
- 해커는 흔한 암호화 방법을 쉽게 복호화할 수 있으므로, 데이터베이스에 저장된 데이터와 전송 중인 데이터 모두 암호화해야 함.
- 안전하지 않은 설계는 보안 부재를 의미하고, 보안 설정 오류는 간과된 취약점으로 구성되며, 취약하고 오래된 구성 요소는 애플리케이션을 공격에 더 취약하게 만듦.
- 보안 조치를 사용하고 보안 업데이트 정보를 계속 파악하면 애플리케이션을 보호할 수 있음.
- 안전한 애플리케이션 설계, 견고한 로깅과 모니터링, 안전한 웹 서버 사용으로 SSRF 공격을 예방해 애플리케이션과 인프라를 보호.
- 무결성 검사는 변조를 방지하고, 웹 서버는 올바르게 설정되어야 하며, 입력 데이터는 살균되어야 하고, 서명되지 않은 데이터는 신뢰할 수 없는 클라이언트에 절대 전송되어서는 안 됨.

## 요약
- Module 3 전반부는 OWASP Top 10의 정의와 5단계 개발 과정을 소개한 뒤, 접근 제어·암호화·설계·설정·구성 요소·인증·무결성·로깅·SSRF에 걸친 10대 취약점 각각의 위험과 예방 원칙(암호화, 최소 권한, 최신 업데이트, 견고한 로깅/모니터링, 무결성 검사, 입력 살균)을 요약한다.
