# What is OpenSSL?

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/application-security-for-developers-devops/lecture/voVct/what-is-openssl)

## 개요
- 암호화가 제공하는 기밀성(Confidentiality)과 무결성(Integrity)이라는 두 서비스를 설명하고, 이를 실제로 구현하는 오픈소스 도구 **OpenSSL**과, 메시지 다이제스트 알고리즘·공개 키 암호화(RSA)를 소개.

## 내용
### 암호화 서비스 1 — 기밀성(Confidentiality)
- 암호화 서비스는 데이터를 비밀로 유지하는 기밀성 서비스 — 필요한 자격 증명이 없는 사람으로부터 데이터를 안전하게 지키는 것이 목적. 데이터가 안전하지 않은 네트워크를 지나가더라도 마찬가지.
- 암호화 키, 특히 개인 키(private key)가 사이버 공격으로부터 데이터를 기밀로 유지하는 데 사용하는 도구 — 공개·개인 키가 없으면 전자상거래 거래에서 데이터는 암호화된 상태로 남아, 사용자 정보가 기밀로 유지되도록 보장.

### 암호화 서비스 2 — 무결성(Integrity)
- 무결성은 데이터가 수신 중과 수신 후에 수정되거나 변조되지 않았음을 보장 — 예: 파일 체크섬(checksum)은 다운로드한 파일이 온라인에서 제공되는 것과 동일한지 확인하는 한 방법.
- 암호화적 무결성은 발신자와 수신자 사이의 데이터 검증이 필요한 사용자를 위해 데이터의 변조 방지를 지원.

### OpenSSL이란
- **SSL(Secure Socket Layer) 프로토콜**을 구현하는 소프트웨어 라이브러리 — 개인적인 것부터 상업적·전자상거래 거래까지 모든 종류의 통신에서 암호화로 안전한 통신을 보장하는 오픈소스 툴킷.
- 이 소프트웨어 라이브러리에는 대칭·공개 키 암호화, 메시지 다이제스트, 해시 알고리즘이 포함됨. OpenSSL은 또한 의사 난수 생성기(pseudorandom number generator)를 포함하고 키 자료(key material)와 일반적인 인증서 형식을 관리.
- 애플리케이션 개발자는 OpenSSL 라이브러리를 포함시켜 프로그램에 강력한 암호화를 제공할 수 있음. 로컬 컴퓨터에 설치한 후 명령줄에서 직접 OpenSSL을 사용할 수도 있음 — Linux나 Mac에서는 `openssl`, Windows에서는 `OpenSSL.exe`를 실행.
- 명령줄 도구는 수많은 옵션을 제공하며, 특정 요구사항에 더 잘 맞도록 기본값을 설정할 수 있는 설정 파일도 사용 가능.

### 메시지 다이제스트 알고리즘(Message Digest Algorithms)
- 데이터 블록의 체크섬을 계산하는 데 사용되는 암호화 해시 함수 — 해시 계산 외에도 메시지 다이제스트로 서명을 만들고 검증할 수 있음. 서명을 검증하는 것은 단순히 서명할 때의 명령을 역으로 실행하는 것.
- OpenSSL은 암호화된 메시지가 같은 키를 사용할 수 있게 해주는 대칭 암호(symmetric cipher)도 지원.

### 공개 키 암호화(Public Key Cryptography)
- 공개 키와 개인 키를 사용하는 공개 암호화 알고리즘 — **RSA(Rivest, Shamir, Adleman)**가 공개 키 암호화의 가장 인기 있는 구현.
- RSA는 누구나 사용할 수 있는 비밀성, 인증, 암호화를 제공. 필요한 암호화 수준에 따라 다양한 키 길이 크기로 개인 키를 생성하는 소수(prime number) 생성을 구현하는 데도 RSA를 사용할 수 있음.

## 요약
- 암호화는 데이터를 비밀로 유지하는 기밀성과 변조되지 않았음을 보장하는 무결성이라는 두 서비스를 제공하며, OpenSSL은 이를 실제로 구현하는 오픈소스 툴킷(라이브러리 또는 `openssl`/`OpenSSL.exe` 명령줄 도구)으로 대칭·공개 키 암호화, 메시지 다이제스트(체크섬 계산과 서명 검증), 그리고 공개·개인 키를 사용하는 RSA 기반 공개 키 암호화까지 지원한다.
