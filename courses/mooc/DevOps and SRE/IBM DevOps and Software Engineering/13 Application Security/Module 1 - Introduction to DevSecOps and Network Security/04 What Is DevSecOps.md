# What is DevSecOps?

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/application-security-for-developers-devops/lecture/6x270/what-is-devsecops)

## 개요
- DevSecOps의 정의와 5가지 핵심 이점(빠르고 저렴한 고품질 소프트웨어, 선제적 조치를 통한 향상된 보안, 신속한 취약점 패치, 현대적인 자동화 접근, 반복과 적응 가능성)을 정리.

## 내용
### DevSecOps란
- 원래의 설계부터 통합, 테스트, 배포, 소프트웨어 전달까지 SDLC 전반에 걸쳐 보안 통합을 자동화하는 일련의 관행 — 위험을 줄이고 보안을 IT 및 기업의 목표에 더 가깝게 통합하기 위해 애플리케이션 개발 생애주기 초기에 보안을 추가하는 규율.
- DevSecOps는 보안을 강조하는 DevOps에 관한 것 — Development(개발), Security(보안), Operations(운영)에서 이름을 따옴.
  - **Development(개발)**는 새로운 소프트웨어 릴리스와 업데이트를 의미.
  - **Security(보안)**는 접근성(accessibility), 무결성(integrity), 기밀성(confidentiality)을 나타냄.
  - **Operation(운영)**은 신뢰성에 기반한 성능 확장을 의미.

### DevSecOps의 5가지 핵심 이점
1. **빠르고 저렴하게 고품질 소프트웨어 전달** — DevSecOps가 아닌 환경에서 소프트웨어를 만들면 보안 이슈가 상당한 시간 지연을 유발할 수 있음. 코딩과 보안 결함을 해결하는 것은 시간이 많이 들고 비쌀 수 있음. DevSecOps는 절차를 반복해야 할 필요를 줄여 보안 취약점을 고치는 데 쓰는 시간을 줄이고 개발 비용을 최소화하는 데 도움. 통합된 보안은 중복된 리뷰와 재빌드를 없애 작업을 더 생산적이고 비용 효율적으로 만들며 더 나은 안전한 코드로 이어짐 — 전달 속도는 높아지고 비용은 줄어듦.
2. **선제적 조치를 통한 향상된 보안** — DevSecOps는 처음부터 사이버 보안 관행을 개발 생애주기에 통합해 보안 확인, 모니터링, 배포, 알림 시스템을 점검. 우려 사항이 발견되는 즉시 해결됨. 보안 취약점이 생애주기 초기에 인식·해결되면 고치는 데 비용이 덜 듦. 추가적인 의존성은 보안 문제가 해결된 후에만 도입됨. DevSecOps 접근은 취약점을 패치하는 데 필요한 시간을 단축시켜, 보안 팀이 더 높은 가치의 작업에 집중할 수 있게 함. 이런 기법들은 애플리케이션 개발 프로젝트가 보안을 위해 수정될 필요를 피하면서 컴플라이언스를 보장하고 완화하는 데 도움.
3. **신속한 취약점 패치** — DevSecOps의 주요 이점 중 하나는 새로 발견된 보안 결함을 관리하는 속도. 취약점 스캐닝과 패치를 릴리스 사이클에 통합하면 위협 행위자가 공개적으로 노출된 프로덕션 시스템의 취약점을 악용할 가능성이 줄어듦. DevSecOps는 개발 초기부터 접근성과 투명성을 강화.
4. **현대적인 자동화 접근** — 조직이 소프트웨어를 배포하는 데 CI/CD 파이프라인을 사용한다면, 운영 팀을 위한 자동화된 테스트 스위트에 사이버 보안 테스트를 포함해야 함. 보안 절차의 자동화는 프로젝트와 조직의 목표에 크게 영향받음. 자동화된 테스트는 포함된 모든 소프트웨어 의존성이 최신 상태인지 확인하고 소프트웨어가 보안 단위 테스트를 통과하도록 보장하며, 정적·동적 분석 테스트가 프로덕션에 릴리스되기 전에 코드를 확인·보안. 또한 불변 인프라(immutable infrastructure)를 가능하게 하는 것도 완전한 보안을 강화하는 보안 자동화를 포함.
5. **반복 사이클과 적응 능력** — 기업이 발전하면서 보안 태세도 함께 발전. DevSecOps는 반복 가능하고 적응 가능한 프로세스를 가능하게 해, 환경이 발전하고 새로운 요구사항에 적응하는 동안 보안이 일관되게 구현되도록 보장. 성숙한 DevSecOps 시스템은 강력한 자동화, 설정 관리, 오케스트레이션, 컨테이너, 불변 인프라, 심지어 서버리스 컴퓨팅 환경까지 갖춰 보안 사고 후 더 빠른 복구를 가능하게 함.

### 결론
- 결국 DevSecOps는 개발, 배포, 운영 절차 전반에 걸친 보안 통제의 자연스러운 통합에 관한 것.

## 요약
- DevSecOps는 개념·구현·테스트·배포·전달 전반에 걸쳐 SDLC에 보안 통합을 자동화하는 실천으로, 시간·비용을 절감하는 빠르고 고품질인 소프트웨어 전달, 선제적 조치를 통한 향상된 보안, 릴리스 사이클에 통합된 신속한 취약점 패치, CI/CD 기반의 현대적 자동화, 그리고 조직이 성장해도 보안을 일관되게 유지하는 반복·적응 능력이라는 5가지 핵심 이점을 제공한다.
