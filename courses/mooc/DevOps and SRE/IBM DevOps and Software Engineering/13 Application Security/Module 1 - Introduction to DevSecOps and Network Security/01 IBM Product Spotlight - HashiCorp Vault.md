# IBM Product Spotlight: HashiCorp Vault

> MOOC 읽기 자료 · [원본 강의](https://www.mooc.org/learn/application-security-for-developers-devops/supplement/OQ1MX/ibm-product-spotlight-hashicorp-vault)

## 개요
- 코스 시작 시점에 소개되는 시크릿 관리 솔루션 **HashiCorp Vault** 스팟라이트 — 애플리케이션 보안을 배우는 동안 DevOps 파이프라인 전반의 민감한 데이터를 보호하는 도구로 소개됨.

## 내용
- HashiCorp Vault는 시크릿(secret), 암호화 키, 접근 제어를 관리하는 플랫폼 — 팀이 개발부터 프로덕션까지 애플리케이션을 보안하도록 도움.
- HashiCorp Vault로 할 수 있는 것:
  - 시크릿을 중앙화해 안전하게 관리.
  - 암호화와 키 관리를 자동화.
  - ID 기반 정책으로 민감한 데이터에 대한 접근을 통제.
  - CI/CD 파이프라인을 처음부터 끝까지 안전하게 보호.
- HashiCorp Vault 살펴보기(원본 자료 링크): `https://ibm.biz/mooc-hashi`

## 요약
- HashiCorp Vault는 DevOps 파이프라인 전반에서 시크릿·암호화 키·접근 제어를 중앙에서 관리하고 자동화해, 개발부터 프로덕션까지 CI/CD 파이프라인을 안전하게 지키는 시크릿 관리 솔루션이다.
