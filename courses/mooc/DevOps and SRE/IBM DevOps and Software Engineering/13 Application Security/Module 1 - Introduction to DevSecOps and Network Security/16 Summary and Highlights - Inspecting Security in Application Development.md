# Summary and Highlights - Inspecting Security in Application Development

> MOOC 읽기 자료 · [원본 강의](https://www.mooc.org/learn/application-security-for-developers-devops/supplement/00CJv/summary-and-highlights-inspecting-security-in-application-development)

## 개요
- Module 1 마지막 부분(위협 모니터링, 인증/인가, 암호화)의 핵심 내용을 정리한 공식 요약.

## 내용
- 위협 모니터링은 코드 저장소와 컨테이너를 스캔해 보안 이슈를 찾는 것.
- 저장소와 위협 모니터링을 통합하면 코드 체커가 소스 코드를 스캔해 보안 이슈를 찾을 수 있게 됨.
- 인증은 사용자의 신원을 검증하고, 인가는 사용자의 접근 권한을 결정.
- 대칭 암호화는 같은 키로 암호화·복호화하는 것을 의미하며, 비대칭 암호화는 서로 다른 키로 암호화·복호화하는 것을 의미.

## 요약
- Module 1의 마지막 강의들은 코드 저장소·컨테이너 스캔을 통한 위협 모니터링과 코드 체커의 역할, 그리고 인증(신원 검증)·인가(접근 권한 결정)·대칭/비대칭 암호화라는 핵심 보안 개념을 요약하며 Module 1 전체를 마무리한다.
