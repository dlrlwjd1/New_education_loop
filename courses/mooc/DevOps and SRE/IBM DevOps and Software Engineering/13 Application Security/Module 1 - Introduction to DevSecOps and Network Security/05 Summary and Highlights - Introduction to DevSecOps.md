# Summary & Highlights - Introduction to DevSecOps

> MOOC 읽기 자료 · [원본 강의](https://www.mooc.org/learn/application-security-for-developers-devops/supplement/tDRFN/summary-highlights-introduction-to-devsecops)

## 개요
- Module 1의 앞부분(Secure SDLC, DevSecOps)에 대한 공식 요약.

## 내용
- Secure SDLC(보안이 통합된 소프트웨어 개발 생애주기)는 기존 개발 모델에 보안 테스트와 그 모범 사례를 통합하는 과정.
- SDLC 단계는 요구사항, 설계, 개발, 테스트, 배포 — 위험 평가를 수행하고 개인이 코드를 어떻게 공격할 수 있는지 살펴봄으로써 Secure SDLC를 이 단계들에 매핑할 수 있음.
- DevSecOps는 개념, 구현, 테스트, 배포, 전달의 SDLC 과정 전반에 걸쳐 보안 통합을 자동화.
- DevSecOps는 더 높은 품질의 소프트웨어, 향상된 보안, 취약점 수정, 보안 사고 후 더 빠른 복구를 제공.

## 요약
- Module 1의 초반 강의는 보안 테스트를 요구사항·설계·개발·테스트·배포의 SDLC 단계에 통합하는 Secure SDLC와, 이 전 과정에 걸쳐 보안 통합을 자동화해 품질·보안·취약점 수정 속도·사고 복구력을 향상시키는 DevSecOps를 요약한다.
