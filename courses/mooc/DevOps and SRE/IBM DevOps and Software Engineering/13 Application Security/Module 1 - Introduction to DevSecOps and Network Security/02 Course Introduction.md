# Course Introduction

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/application-security-for-developers-devops/lecture/VM3Ls/course-introduction)

## 개요
- IBM Research의 John Rofrano가 소개하는 코스 오리엔테이션 — 인프라 보안이 아니라 **개발자와 DevOps 전문가**를 위한 애플리케이션 보안에 초점을 맞추며, 심각한 보안 통계와 코스 전체 여정을 안내.

## 내용
### 이 코스의 초점 — 인프라 보안이 아니다
- 이 코스는 인프라를 안전하게 만드는 것(보안 팀, 운영/SRE 팀의 몫)을 다루지 않음 — 소프트웨어 엔지니어가 "만든 사람이 운영한다(if you build it, you run it)"는 DevOps 신조를 진정으로 받아들이기 위해 알아야 할 것에 특화되어 있음.

### 놀라운 통계 — 20년째 같은 문제
- 20년 전 개발자들이 겪던 가장 중대한 보안 위험과 우려가 오늘날과 거의 같음 — OWASP Top 10 리스트에 포함된 최근 우려 사항 상당수가 2007년의 것과 동일.
- IBM의 최근 리포트에 따르면, 데이터 유출을 탐지하는 데 걸리는 평균 시간은 **212일**(7개월 이상) — 공격자가 작은 익스플로잇을 이용해 본격적인 공격을 감행하기에 충분한 시간.
- 더 나쁜 것은 평균 데이터 유출 비용이 **미국에서 940만 달러, 전 세계적으로 430만 달러**라는 점 — 대부분 제대로 구현되지 않은 보안 기능 때문이며, 이런 기능이 있었다면 악의적인 침입 시도를 팀에 경고할 수 있었을 것.
- 우리는 더 잘할 수 있음 — **설계 단계부터 보안(security by design)**을 실천해야 함.

### 코스에서 다룰 내용
- 애플리케이션과 시스템을 위협하는 흔한 위험과 취약점을 이해하는 데 도움.
- **DevSecOps** — 개발과 운영의 필수적인 부분, 보안을 소프트웨어 개발 과정에 선제적으로 통합하는 것.
- 최신 TLS와 OpenSSL을 이용한 네트워크 보안의 역할에 대한 통찰.
- 보안을 개발 계획에 매핑하면 공격으로부터 회복하는 능력이 향상되고, 심지어 공격이 발생하기 전에 시스템을 보호할 수 있다는 것.
- 취약점 스캐닝과 위협 모델링, 그리고 위협 모니터링에 대한 더 깊은 이해.
- 코스를 마칠 때쯤엔 보안 팀이 흔히 사용하는 핵심 보안 용어와 개념에 익숙해질 것.
- 보안 테스트와, 보안 위협·취약점의 위험과 영향을 완화하는 데 사용할 수 있는 다양한 도구와 절차를 탐구.
- 실습에서는 정적·동적 분석 도구로 코드를 분석하고 테스트를 실행하는 연습을 함 — 오늘 당장 프로젝트에 사용할 수 있는 오픈소스 도구들.
- 현재의 보안 취약점과 우려 사항을 식별하는 **OWASP Top 10** 리스트를 다룸 — 해커가 애플리케이션과 시스템의 흔한 취약점을 어떻게 악용하는지 발견.
- 실습에서 UI를 통해서든 프로그래밍적으로 시크릿을 vault에 읽고 쓰든, **Vault Secrets Manager** 같은 도구를 설정하는 실습도 진행. 코드, 의존성, 개발 환경의 보안을 확인·테스트하는 데 도움이 되는 도구들도 배움.
- 코스를 마칠 때쯤이면 보안 위험과 취약점이 애플리케이션과 시스템을 어떻게 위협하는지 이해하고, 이런 보안 악몽에 대처할 준비가 되어 있을 것.

### 강사의 개인적 경험
- 강사는 보안을 전혀 생각하지 않고 애플리케이션을 배포하던 시절, 운영 팀이 그를 막아서며 보안 스캔에 실패했다고 알려주던 경험을 회상 — "고쳐야 할 취약점 목록이 여기 있다"는 말을 들었을 때, "어떻게 고치나요?"라고 물으면 "그걸 제가 어떻게 알아요? 개발자잖아요"라는 답을 들었음 — 용어의 의미조차 이해하지 못한 채 홀로 남겨졌음.
- 이 코스는 강사가 배포가 보안 팀에 의해 막혔을 때 자신이 있었으면 좋았을 코스 — 여러분에게는 그런 일이 일어나지 않게 하기 위함.

### 학습 방식
- 방어적으로 코딩하는 법을 배우고 애플리케이션이 설계 단계부터 안전하도록 만들 것.
- 영상을 보고, 실습에 몰입하고, 퀴즈를 풀고, 포럼에서 동료들과 교류할 것 — 소프트웨어 엔지니어링은 팀 스포츠이며 협업이 장려됨.

## 요약
- 이 코스는 인프라가 아니라 개발자와 DevOps 전문가를 위한 애플리케이션 보안에 초점을 맞추며, 데이터 유출 탐지에 평균 212일이 걸리고 평균 유출 비용이 수백만 달러에 달한다는 현실 속에서 DevSecOps·네트워크 보안(TLS/OpenSSL)·취약점 스캐닝과 위협 모델링·OWASP Top 10·Vault를 이용한 시크릿 관리를 실습을 통해 배워, 설계 단계부터 보안을 내장하는 방어적 코딩 습관을 기르는 것을 목표로 한다.
