# Getting Started with Network and Port Scanning with Nmap

> MOOC 읽기 자료 · [원본 강의](https://www.mooc.org/learn/application-security-for-developers-devops/supplement/l3RBH/getting-started-with-network-and-port-scanning-with-nmap)

## 개요
- 오픈소스 네트워크 스캐닝·보안 감사 도구 **Nmap**의 목적, 다양한 사용자층, 여러 스캔 유형과 명령 예시, 역사, 유사 도구를 소개.

## 내용
### Nmap 소개
- Nmap(Network Mapper)은 네트워크 장치, 서비스, 운영체제를 탐지·식별하고 보안 취약점을 발견하는 오픈소스 네트워크 스캐닝·보안 감사 도구.
- 네트워크에서 열린 포트를 스캔하고, 운영체제를 탐지하며, 버퍼 오버플로우·침입·서비스 거부 공격 같은 취약점을 탐지하는 데 사용 가능. 보안 감사, 침투 테스트, 시스템 관리에서 흔히 사용됨.
- Gordon Lyon("Fyodor"라는 필명으로 널리 알려짐)이 개발했으며 1997년 9월에 처음 출시됨. 컴퓨터 네트워크의 호스트와 서비스를 발견해 네트워크 구조의 지도를 만들도록 설계됨.

### 누가 Nmap을 사용하는가
- 네트워크 관리자, 보안 전문가, 침투 테스터, 시스템 관리자, 호기심 많은 애호가까지 폭넓은 사용자층이 사용:
  - **네트워크 관리자** — 네트워크 자산을 발견·매핑하고, 네트워크 상태를 모니터링하고, 잘못된 설정을 식별하고, 승인된 서비스만 노출되도록 보장.
  - **보안 전문가**(보안 분석가, 침투 테스터, 윤리적 해커) — 네트워크의 보안 태세를 평가하고, 열린 포트·서비스·잠재적 취약점을 식별하고, 침투 테스트로 잠재적 공격 벡터를 발견.
  - **시스템 관리자** — 네트워크 연결 문제를 해결하고, 네트워크 관련 문제를 진단하고, 서비스·포트가 올바르게 설정되었는지 확인.
  - **IT 관리자** — 네트워크 인프라에 대한 통찰을 얻고, 보안 조치에 대한 정보에 기반한 결정을 내리고, 기존 보안 통제의 효과성을 평가.
  - **침투 테스터** — 네트워크 방어의 잠재적 진입점, 취약점, 약점을 식별. Nmap의 포괄적인 스캐닝 역량은 실제 공격을 시뮬레이션하는 데 유용.
  - **보안 컨설턴트** — 네트워크 보안 개선과 위험 완화에 대해 조직에 전문적인 조언과 권고를 제공하는 데 활용.
  - **컴플라이언스·감사 전문가** — 네트워크 설정을 평가하고, 보안 표준 준수를 검증하고, 규제 요구사항에 영향을 줄 수 있는 잠재적 취약점을 식별.
  - **연구자** — 연구를 수행하고, 데이터를 수집하고, 네트워크 보안과 사이버 보안 위협에 대한 이해에 기여.
  - **교육자** — 커리큘럼의 일부로 네트워크 스캐닝, 보안 평가, 취약점 분석을 가르침.
  - **오픈소스 애호가** — Nmap은 오픈소스 소프트웨어라, 네트워킹·보안·기술에 관심 있는 애호가들이 실습 경험을 쌓고 개발에 기여 가능.
- Nmap은 강력한 도구지만, 항상 윤리적 가이드라인과 법적 경계를 준수하며 사용해야 함.

### Nmap의 목적
- 주된 목적은 네트워크 발견과 보안 감사 — 네트워크상의 활성 호스트를 식별하고, 열린 포트와 서비스를 발견하고, 해당 호스트에서 실행 중인 운영체제를 판단하는 데 도움. 또한 네트워크 인프라 내의 잠재적 보안 위험과 약점을 식별해 취약점 평가에도 도움.

### 다양한 Nmap 스캔 유형과 예시
- **TCP Connect Scan(기본 스캔)** — 각 대상 포트에 완전한 TCP 연결을 여는 기본 스캔. `nmap -sT target`
- **SYN Stealth Scan** — 하프오픈(half-open) 스캔이라고도 하며, SYN 패킷을 보내고 응답을 분석. `nmap -sS target`
- **UDP Scan** — 대상 포트에 UDP 패킷을 보내 열린 UDP 서비스를 식별. `nmap -sU target`
- **ACK Scan** — TCP ACK 패킷을 보내 방화벽 설정을 판단. `nmap -sA target`
- **Version Detection(-sV)** — 열린 포트에서 실행 중인 서비스 버전을 식별. `nmap -sV target`
- **OS Detection(-O)** — 대상의 운영체제를 식별 시도. `nmap -O target`
- **Script Scanning(-sC)** — 미리 정의된 스크립트를 실행해 추가 정보를 수집. `nmap -sC target`
- **Ping Scans** — 대상의 가용성을 확인하는 다양한 핑 기법. `nmap -PE target`(ICMP Echo Request)
- **Traceroute(--traceroute)** — 패킷이 거치는 경로를 판단하기 위해 traceroute 수행. `nmap --traceroute target`
- **TCP Null Scan** — TCP 플래그를 전혀 설정하지 않은 패킷을 보내 응답을 관찰. `nmap -sN target`
- **TCP FIN Scan** — FIN 플래그를 설정한 패킷을 보내 응답을 관찰. `nmap -sF target`
- **TCP Xmas Scan** — 다양한 TCP 플래그를 설정한 패킷을 보내 응답을 관찰. `nmap -sX target`
- 각 스캔 유형은 대상 네트워크에 대한 정보를 수집하는 데 특정 목적을 수행 — 어떤 스캔을 선택할지는 찾고자 하는 정보의 종류와 필요한 가시성 수준에 따라 다름.
- 참고: 항상 Nmap을 책임감 있게 사용하고, 대상 네트워크를 스캔할 필요한 권한을 확보해야 함.

### 진화와 역사
- Nmap은 처음에 Fyodor가 단순한 네트워크 스캐닝 도구로 개발 — 수년에 걸쳐 강력하고 포괄적인 네트워크 매핑·보안 평가 도구로 발전. Fyodor의 지속적인 헌신과 활발한 기여자 커뮤니티가 Nmap 역량의 지속적인 개선과 확장으로 이어짐.
- Nmap의 개발 역사에는 OS 탐지, 버전 탐지, 스크립팅 엔진(Nmap Scripting Engine, NSE), 성능 최적화 같은 고급 기능 도입이 포함됨. Nmap의 채택은 빠르게 성장해 전 세계 네트워크 관리자와 보안 전문가에게 필수 도구가 됨.

### 시장의 유사 제품
- **Zmap** — 대규모 인터넷 전체 네트워크 조사를 위해 설계된 빠른 오픈소스 네트워크 스캐너. 네트워크 정찰과 데이터 수집에 초점.
- **Masscan** — 인터넷 규모 스캐닝을 위해 설계된 또 다른 고속 네트워크 스캐너. 전체 IPv4 주소 공간을 몇 분 만에 스캔 가능.
- **OpenVAS(Open Vulnerability Assessment System)** — 네트워크에 대한 보안 감사를 수행하고 발견된 취약점에 대한 상세 리포트를 제공하는 포괄적인 취약점 스캐너.
- **Zenmap** — Nmap의 GUI(그래픽 사용자 인터페이스) 버전. Nmap 스캔의 시각적 표현을 제공하고 스캔을 설정·시작하는 더 쉬운 방법을 제공.
- **Wireshark** — 주로 네트워크 프로토콜 분석기이지만, 네트워크 발견과 보안 분석에도 사용 가능. 네트워크를 흐르는 패킷을 캡처·분석.

## 요약
- Nmap은 Gordon Lyon("Fyodor")이 1997년 개발한 오픈소스 네트워크 스캐닝·보안 감사 도구로, 네트워크 관리자부터 침투 테스터, 연구자, 교육자까지 폭넓은 사용자가 활용하며, TCP Connect·SYN Stealth·UDP·ACK 스캔부터 버전/OS 탐지, 스크립트 스캔, Traceroute까지 다양한 스캔 유형(`-sT`, `-sS`, `-sU`, `-sV`, `-O` 등)으로 네트워크의 열린 포트·서비스·취약점을 발견하며, Zmap·Masscan·OpenVAS·Zenmap·Wireshark 같은 유사 도구들과 함께 네트워크 보안 분야의 필수 도구로 자리 잡았다.
