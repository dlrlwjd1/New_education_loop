# Summary & Highlights - Introduction to Security Testing and Mitigation Strategies

> MOOC 읽기 자료 · [원본 강의](https://www.mooc.org/learn/application-security-for-developers-devops/supplement/Uua4V/summary-highlights-introduction-to-security-testing-and-mitigation-strategies)

## 개요
- Module 2 앞부분(보안 테스트 개요, 정적/동적 분석)의 핵심 내용을 정리한 공식 요약.

## 내용
- 완화 전략을 사용하면 보안 위협·취약점의 위험과 영향을 줄이는 데 도움.
- 정적 분석은 실행 전에 소스 코드를 자동으로 검사.
- 정적 코드 분석 도구는 깊이, 속도, 정확도를 제공.
- 프로덕션에 코드를 배포한 이후에 동적 분석을 수행.
- 동적 테스트는 다른 테스트가 놓칠 수 있는 동적 코드 경로의 결함을 탐지하는 데 도움.

## 요약
- Module 2의 초반 강의는 위험·영향을 줄이는 완화 전략의 중요성과, 실행 전 소스 코드를 검사해 깊이·속도·정확도를 제공하는 정적 분석, 그리고 배포 후 실행 중인 애플리케이션에서 다른 테스트가 놓친 결함을 잡아내는 동적 분석을 요약한다.
