# Summary & Highlights - Implementing Key Analysis in Applications

> MOOC 읽기 자료 · [원본 강의](https://www.mooc.org/learn/application-security-for-developers-devops/supplement/XKHB0/summary-highlights-implementing-key-analysis-in-applications)

## 개요
- Module 2 후반부(코드 리뷰, 취약점 분석, 런타임 보호, SCA, 지속적 보안 분석)의 핵심 내용을 정리한 공식 요약.

## 내용
- 안전한 코드 리뷰는 노출된 위협이나 보안에 중요한 구성 요소를 담은 소스 코드에 초점을 맞춤.
- 자동화된 코드 리뷰는 대규모 코드베이스를 빠르고 효율적으로 평가.
- 사용할 수 있는 3가지 취약점 도구는 Burp Suite, Nessus, ZAP.
- 훈련, 정책 업데이트, 프로세스 자동화는 취약점 분석에서 따라야 할 모범 사례.
- 런타임 보호는 애플리케이션이 실행되는 동안 취약점으로부터 보호하는 보안 메커니즘.
- SCA(Software Component Analysis)의 목표는 코드베이스에서 오픈소스 구성 요소를 발견해 보안과 라이선스 컴플라이언스 위험을 더 잘 관리하는 것.
- 지속적 보안 분석은 위험을 줄이고, 소프트웨어 개발의 병목을 제거하며, 새 기능 개발을 가속화.

## 요약
- Module 2의 후반 강의는 안전한 코드 리뷰(자동화/수동)와 Burp Suite·Nessus·ZAP 같은 취약점 분석 도구, 애플리케이션 실행 중 보호하는 런타임 보호(IAST/RASP), 오픈소스 구성 요소를 관리하는 SCA, 그리고 SDLC 전반에 보안을 통합해 병목을 줄이고 개발을 가속화하는 지속적 보안 분석을 요약하며 Module 2를 마무리한다.
