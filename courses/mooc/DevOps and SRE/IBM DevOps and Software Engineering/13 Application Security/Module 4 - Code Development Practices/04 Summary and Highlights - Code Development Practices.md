# Summary & Highlights - Code Development Practices

> MOOC 읽기 자료 · [원본 강의](https://www.mooc.org/learn/application-security-for-developers-devops/supplement/ijXAL/summary-highlights-code-development-practices)

## 개요
- Module 4 전반부(코드 관행, 의존성, 안전한 개발 환경)의 핵심 내용을 정리한 공식 요약.

## 내용
- 코드 관행은 취약점을 완화하는 데 도움이 되며, 소프트웨어 개발 생애주기 초기에 보안을 포함시키면 비용을 절감할 수 있음.
- 신뢰할 수 있는 코드를 사용하면 위험이 줄어들며, 의미 있고 안전한 오류 처리가 목표.
- 의존성은 다른 코드가 의존하는 코드로, 애플리케이션에 기능과 특성을 더할 수 있음.
- 의존성은 개발 속도를 높여주지만, 사용 전에 철저히 검증되어야 함.
- 안전한 개발 환경은 보안 팀과의 협업을 포함하며, 이는 방어적 코드 개발에 도움이 됨.
- 안전하지 않은 개발 환경은 손상된 개발 머신, 보호 모니터링·로깅·감사의 부재, 머신과 코드 저장소에 대한 무제한 접근을 포함.

## 요약
- Module 4 전반 강의는 초기 보안 반영이 비용을 절감하는 코드 관행, 철저한 검증이 필요한 의존성, 그리고 보안 팀과의 협업이 핵심인 안전한 개발 환경(반대로 안전하지 않은 환경은 손상된 머신·모니터링 부재·무제한 접근이 특징)을 요약한다.
