# What's Next: Explore Hashicorp Vault

> MOOC 읽기 자료 · [원본 강의](https://www.mooc.org/learn/application-security-for-developers-devops/supplement/sfftm/whats-next-explore-hashicorp-vault)

## 개요
- 강좌를 마무리하기 전에 HashiCorp Vault를 실제로 탐색해볼 것을 권하는 짧은 안내.

## 내용
- 이 강좌 앞부분에서 시크릿을 관리하고 DevOps 파이프라인을 안전하게 지키는 방법으로 HashiCorp Vault를 소개했음(참고: [[12 Storing Secrets Securely]]).
- 애플리케이션 보안 역량을 심화한 지금, HashiCorp Vault가 실제로 작동하는 모습을 살펴볼 준비가 되었음을 안내.
- HashiCorp Vault 탐색 링크: `https://ibm.biz/mooc-hashi`

## 요약
- 강좌에서 다룬 HashiCorp Vault를 실습 형태로 직접 탐색해볼 수 있는 외부 링크를 안내하는 짧은 다음 단계 페이지다.
