# Congratulations and Next Steps

> MOOC 읽기 자료 · [원본 강의](https://www.mooc.org/learn/application-security-for-developers-devops/supplement/a9BLG/congratulations-and-next-steps)

## 개요
- "Application Security for Developers and DevOps Professionals" 강좌 수료를 축하하며, 추가 학습 링크와 관련 전문 자격증 프로그램을 안내.

## 내용
### 추가 학습 링크
- OWASP: `https://owasp.org/`
- Snyk: `https://snyk.io/`
- Nmap: `https://nmap.org/`
- HashiCorp: `https://www.hashicorp.com/`
- Monitoring and Observability for Development and DevOps(관련 강좌)

### 이 강좌가 속한 프로그램
- **IBM DevOps and Software Engineering Professional Certificate** — DevOps 관련 직무를 시작하려는 학습자를 위한 프로그램. DevOps, 클라우드 네이티브, 애자일 실천법·기술·도구로 역량을 높이려는 초급자를 위한 강좌.
- **IBM Back-End Development Professional Certificate** — 엔트리 레벨 백엔드 개발자로서 취업 시장에서 경쟁력을 갖추려는 학습자를 위한 프로그램. 데이터베이스(DBMS), 컨테이너(Docker, Kubernetes, OpenShift), 마이크로서비스 등으로 역량을 높이려는 초급자를 위한 강좌.
- **IBM Applied DevOps Engineering Professional Certificate** — 최신 개발 실천법과 역량으로 경력을 발전시키려는 기존 소프트웨어·IT 전문가를 위한 프로그램. 소프트웨어 엔지니어링 기초, 최소 한 가지 프로그래밍 언어(Python 권장), Linux 명령어와 셸 스크립트, Git과 GitHub에 이미 익숙한 학습자를 대상으로 하며, scrum, 컨테이너(Docker, Kubernetes, OpenShift, 마이크로서비스), REST, 서버리스, 테스트 주도 개발(TDD), CI/CD 등 최신 DevOps 실천법·애자일 방법론·클라우드 네이티브 기술을 마스터하려는 사람들을 위한 프로그램.

## 요약
- 강좌 수료를 축하하며 OWASP·Snyk·Nmap·HashiCorp 등 추가 학습 자료와, 이 강좌가 속한 IBM DevOps and Software Engineering·IBM Back-End Development·IBM Applied DevOps Engineering 세 전문 자격증 프로그램을 안내하는 페이지다.
