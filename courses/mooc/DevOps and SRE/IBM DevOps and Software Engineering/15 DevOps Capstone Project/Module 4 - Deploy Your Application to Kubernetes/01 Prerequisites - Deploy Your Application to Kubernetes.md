# Prerequisites: Deploy Your Application to Kubernetes

> MOOC 읽기 자료 · [원본 강의](https://www.mooc.org/learn/devops-capstone-project/supplement/rdlKC/prerequisites-deploy-your-application-to-kubernetes)

## 개요
- Module 4(Kubernetes 배포) 실습을 시작하기 전에 갖춰야 할 사전 요구 사항을 안내.

## 내용
- [[07 Hands-On Lab - Add Security to Your RESTful Service]]에 설명된 모든 단계를 완료했어야 함(Module 3 체크리스트 참고).
- Docker와 컨테이너화에 대한 기본적인 이해.
- Docker 명령에 대한 익숙함.
- Kubernetes와 OpenShift에 대한 기본 지식.
- YAML에 대한 기본적인 이해.
- `kubectl`과 `oc` 명령에 대한 익숙함.
- GitHub 계정과 GitHub 저장소.
- Kubernetes 매니페스트 문법에 대한 익숙함.

## 요약
- Module 3의 보안 강화 완료, Docker·Kubernetes·OpenShift에 대한 기본 지식, YAML과 `kubectl`·`oc` 명령 숙지가 Module 4의 사전 요구 사항이다.
