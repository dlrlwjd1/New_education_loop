# Prerequisites: Agile Planning

> MOOC 읽기 자료 · [원본 강의](https://www.mooc.org/learn/devops-capstone-project/supplement/zHp71/prerequisites-agile-planning)

## 개요
- Module 1의 Agile 계획 수립 실습을 시작하기 전에 갖춰야 할 사전 요구 사항을 안내.

## 내용
- Agile 계획과 Scrum에 대한 기본적인 이해가 있어야 함 — 이 모듈을 진행하기 전에 *Introduction to Agile Development and Scrum* 강좌를 완료했는지 확인.
- GitHub 계정이 있어야 함 — 무료 계정을 가입하거나 GitHub 웹사이트에서 계정을 확인 가능.
- 공식 이메일 ID가 있다면 Zenhub 계정을 만들어 Zenhub 칸반 보드를 설정 가능.
- 또는 GitHub 계정을 사용해 GitHub 칸반 보드를 설정할 수도 있음.

## 요약
- Agile/Scrum 기본 지식, GitHub 계정, 그리고 Zenhub 또는 GitHub 중 하나의 칸반 보드 준비가 이 모듈의 사전 요구 사항이다.
