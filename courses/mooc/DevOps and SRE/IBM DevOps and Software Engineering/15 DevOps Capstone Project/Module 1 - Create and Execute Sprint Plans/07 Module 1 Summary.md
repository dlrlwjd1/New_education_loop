# Module 1 Summary

> MOOC 읽기 자료 · [원본 강의](https://www.mooc.org/learn/devops-capstone-project/supplement/OMu06/module-1-summary)

## 개요
- Module 1(Agile 계획 수립)에서 배운 핵심 내용을 정리한 공식 요약.

## 내용
- 템플릿을 클론하고 저장소에 적절한 명명 규칙을 사용하면 스타터 코드를 이용할 수 있고 저장소를 쉽게 식별할 수 있음.
- 저장소가 공개적으로(publicly) 보이면 누구나 이를 보고 유용한 피드백을 줄 수 있음.
- 잘 만들어진 사용자 스토리 템플릿은 워크플로우를 표준화하고 스토리가 완전하도록 보장하는 데 도움을 줌.
- 사용자 스토리는 Agile 개발에 필수적이며 계획부터 배포까지의 과정을 간소화하는 데 도움을 줌.
- 사용자 스토리의 우선순위를 매기는 것은 어떤 스토리가 우선하고 어떤 스토리를 나중 스프린트에서 다시 다룰 수 있는지 아는 데 필수적.
- "technical debt" 같은 커스텀 라벨을 사용하면 스토리를 더 빠르고 쉽게 설명·필터링·검색할 수 있음.
- 스토리 포인트는 스토리의 노력(effort), 복잡도, 불확실성 — 즉 스토리 완료에 걸리는 시간에 영향을 미치는 모든 요소를 측정한 값.
- 적절히 설계된 스프린트 계획은 모두가 이미 한 일, 아직 해야 할 일, 스프린트 목표 달성 가능성을 이해하는 데 도움을 줌.

## 요약
- Module 1은 템플릿 클론과 명명 규칙, 공개 저장소, 사용자 스토리 템플릿과 스토리 자체의 중요성, 우선순위와 커스텀 라벨을 통한 백로그 관리, 스토리 포인트를 통한 노력 추정, 그리고 스프린트 진행 상황을 명확히 보여주는 스프린트 계획의 가치를 요약하며 마무리된다.
