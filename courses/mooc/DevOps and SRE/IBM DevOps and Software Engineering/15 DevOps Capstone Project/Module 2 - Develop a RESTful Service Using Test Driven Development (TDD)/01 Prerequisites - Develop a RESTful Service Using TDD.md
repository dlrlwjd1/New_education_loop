# Prerequisites: Develop a RESTful Service Using Test Driven Development (TDD)

> MOOC 읽기 자료 · [원본 강의](https://www.mooc.org/learn/devops-capstone-project/supplement/otekK/prerequisites-develop-a-restful-service-using-test-driven-development-tdd)

## 개요
- Module 2(TDD로 RESTful 서비스 개발) 실습을 시작하기 전에 갖춰야 할 사전 요구 사항을 안내.

## 내용
- [[05 Hands-on Lab - Agile Planning using Github]]에 설명된 모든 단계를 완료했어야 함(기대 사항 요약은 Checklist: Agile Planning 참고).
- 테스트 주도 개발(TDD) 기법에 대한 좋은 이해.
- Python에 대한 기본 지식.
- REST API와 REST API 가이드라인에 대한 이해.
- 마이크로서비스를 개발하기 위해 코드를 작성하고 테스트 케이스를 설계하는 실습 역량.
- 브랜치 생성, 저장소에 코드 커밋, pull request 생성, main 브랜치로 코드 병합, pull request 종료를 포함한 GitHub 작업에 대한 기본 지식.

## 요약
- Module 1의 Agile 계획 완료, TDD·Python·REST API에 대한 이해, 그리고 브랜치·커밋·PR 등 GitHub 작업 역량이 Module 2의 사전 요구 사항이다.
