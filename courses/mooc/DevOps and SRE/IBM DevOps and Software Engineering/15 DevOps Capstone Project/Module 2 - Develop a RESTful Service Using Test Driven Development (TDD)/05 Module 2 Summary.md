# Module 2 Summary

> MOOC 읽기 자료 · [원본 강의](https://www.mooc.org/learn/devops-capstone-project/supplement/badTH/module-2-summary)

## 개요
- Module 2(TDD로 RESTful 서비스 개발)에서 배운 핵심 내용을 정리한 공식 요약.

## 내용
- `setup.cfg` 파일로 매개변수를 자동화하면 `nosetests`를 실행할 때마다 매번 옵션을 입력할 필요가 없음.
- 칸반 보드에서 작업할 스토리는 우선순위에 따라 선택하며, 완료되면 스토리를 "Done" 컬럼으로 옮김.
- `curl` 명령을 사용해 REST 호출을 테스트.

## 요약
- Module 2는 `setup.cfg`를 통한 테스트 명령 자동화, 우선순위 기반 칸반 보드 스토리 진행, 그리고 `curl`을 이용한 REST API 테스트라는 세 가지 실무 핵심을 요약하며 Sprint 1 개발 과정을 마무리한다.
