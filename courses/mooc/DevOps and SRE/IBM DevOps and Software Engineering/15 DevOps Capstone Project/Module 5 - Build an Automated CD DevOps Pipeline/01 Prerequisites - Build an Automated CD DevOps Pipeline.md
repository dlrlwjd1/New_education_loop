# Prerequisites: Build an Automated CD DevOps Pipeline

> MOOC 읽기 자료 · [원본 강의](https://www.mooc.org/learn/devops-capstone-project/supplement/auHxr/prerequisites-build-an-automated-cd-devops-pipeline)

## 개요
- Module 5(자동화된 CD 파이프라인 구축) 실습을 시작하기 전에 갖춰야 할 사전 요구 사항을 안내.

## 내용
- [[04 Hands-on Lab - Deploy Your Application to Kubernetes]]에 설명된 모든 단계를 완료했어야 함(Module 4 체크리스트 참고).
- Kubernetes에 대한 기본적인 이해.
- 지속적 전달(CD) 개념에 대한 익숙함.
- Tekton 파이프라인에 대한 기본적인 이해.
- YAML에 대한 기본적인 이해.
- `kubectl`과 `oc` 명령에 대한 익숙함.
- GitHub 계정과 GitHub 저장소.
- GitHub Actions 문법에 대한 익숙함.

## 요약
- Module 4의 Kubernetes 배포 완료, Kubernetes·CD·Tekton·YAML에 대한 이해, `kubectl`/`oc` 명령과 GitHub Actions 문법 숙지가 Module 5의 사전 요구 사항이다.
