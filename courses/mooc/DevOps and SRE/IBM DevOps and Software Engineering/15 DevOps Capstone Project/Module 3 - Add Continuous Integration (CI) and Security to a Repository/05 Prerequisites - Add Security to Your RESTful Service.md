# Prerequisites: Add Security to Your RESTful Service

> MOOC 읽기 자료 · [원본 강의](https://www.mooc.org/learn/devops-capstone-project/supplement/7xE5I/prerequisites-add-security-to-your-restful-service)

## 개요
- Module 3 후반부(RESTful 서비스에 보안 추가) 실습을 시작하기 전에 갖춰야 할 사전 요구 사항을 안내.

## 내용
- [[04 Hands-On Lab - Add Continuous Integration]]에 설명된 모든 단계를 완료했어야 함(Add Continuous Integration Checklist 참고).
- 보안 헤더(security header)에 대한 기본적인 이해.
- CORS(Cross-Origin Resource Sharing) 정책에 대한 익숙함.
- Flask-Talisman과 Flask-Cors에 대한 기본적인 이해.
- 테스트 주도 개발(TDD) 기법에 대한 좋은 이해.
- GitHub Actions에 대한 익숙함.
- 브랜치 생성, 병합, 코드 커밋, push 이벤트, pull request를 포함한 GitHub 작업에 대한 익숙함.

## 요약
- Module 3 전반부의 CI 추가 완료, 보안 헤더·CORS·Flask-Talisman/Flask-Cors에 대한 이해, TDD와 GitHub Actions·GitHub 작업에 대한 익숙함이 이번 실습의 사전 요구 사항이다.
