# Prerequisites: Add Continuous Integration

> MOOC 읽기 자료 · [원본 강의](https://www.mooc.org/learn/devops-capstone-project/supplement/zAddN/prerequisites-add-continuous-integration)

## 개요
- Module 3의 CI 추가 실습을 시작하기 전에 갖춰야 할 사전 요구 사항을 안내.

## 내용
- [[04 Hands-On Lab - Develop a RESTful Service Using TDD]]에 설명된 모든 단계를 완료했어야 함(체크리스트 참고).
- GitHub 계정과 GitHub 저장소.
- YAML에 대한 기본적인 이해.
- GitHub Actions 문법에 대한 익숙함.
- Python, Pip, `nosetests`에 대한 기본 지식.

## 요약
- Module 2의 RESTful 서비스 개발 완료, GitHub 저장소, YAML과 GitHub Actions 문법에 대한 이해, Python·Pip·nosetests 기본 지식이 Module 3의 사전 요구 사항이다.
