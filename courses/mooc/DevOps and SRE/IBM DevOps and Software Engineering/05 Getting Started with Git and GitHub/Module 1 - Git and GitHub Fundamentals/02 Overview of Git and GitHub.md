# Overview of Git and GitHub

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/getting-started-with-git-and-github/lecture/Q2qCC/overview-of-git-and-github)

## 개요
- Git과 GitHub는 개발자와 데이터 사이언티스트들 사이에서 인기 있는 환경이지만 버전 관리에 대한 기본적인 이해가 없으면 논의할 수 없습니다.

## 내용
- Git과 GitHub는 개발자와 데이터 사이언티스트들 사이에서 인기 있는 환경이지만 버전 관리에 대한 기본적인 이해가 없으면 논의할 수 없습니다.
- Git은 분산 버전 제어 시스템 (DVCS) 으로, 전 세계 어디서나 사용자가 자신의 컴퓨터에 프로젝트 사본을 보관할 수 있습니다.
- Git이 유일한 버전 제어 시스템은 아니지만, Git이 현존하는 가장 인기 있는 버전 관리 시스템 중 하나가 된 주된 이유 중 하나는 분산형 기능입니다.
- 버전 제어 시스템은 코드와 관련된 작업에 널리 사용되지만 이미지 , 문서 및 다양한 파일 유형의 버전을 관리할 수도 있습니다.
- 명령줄 인터페이스를 사용하면 웹 인터페이스 없이도 Git을 사용할 수 있지만 GitHub는 Git 리포지토리에 가장 많이 사용되는 웹 호스팅 서비스 중 하나입니다.
- 분산 버전 관리 시스템 덕분에 Git을 사용하면 이전 상태로 되돌아가거나 프로젝트 기록을 검토할 수 있습니다.
- GitHub는 Git 리포지토리에 가장 많이 사용되는 웹 호스팅 서비스 중 하나입니다.Git과 GitHub와 관련된 기본 용어로는 SSH, 프로토콜 리포지토리, 포크, 풀 리퀘스트, 작업 디렉터리, 커밋, 브랜치, 병합, 클론이 있습니다.

## 예시

## 요약
- 분산 버전 관리 시스템 덕분에 Git을 사용하면 이전 상태로 되돌아가거나 프로젝트 기록을 검토할 수 있습니다. GitHub는 Git 리포지토리에 가장 많이 사용되는 웹 호스팅 서비스 중 하나입니다.Git과 GitHub와 관련된 기본 용어로는 SSH, 프로토콜 리포지토리, 포크, 풀 리퀘스트, 작업 디렉터리, 커밋, 브랜치, 병합, 클론이 있습니다.
