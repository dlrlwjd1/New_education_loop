# Course Introduction

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/getting-started-with-git-and-github/lecture/HPf1W/course-introduction)

## 개요
- Git과 GitHub는 버전 제어 및 협업 소프트웨어 개발을 위해 업계에서 널리 사용됩니다.

## 내용
- Git과 GitHub는 버전 제어 및 협업 소프트웨어 개발을 위해 업계에서 널리 사용됩니다.
- 버전 제어 및 협업 소프트웨어는 소프트웨어 개발 프로젝트를 효과적으로 완료하는 데 매우 중요합니다.
- 이 과정은 버전 제어 및 Git 및 GitHub와의 공동 작업을 배우고자 하는 모든 사람에게 적합합니다.
- 이 과정은 특히 소프트웨어 엔지니어, 애플리케이션 개발자, 데이터 과학자 및 데이터 엔지니어와 같은 역할에 관심이 있는 사람들에게 적합합니다.
- 리포지토리를 생성하고, 변경 사항을 공유 및 통합하여 팀 프로젝트에서 협업하고, GitHub 포트폴리오를 구축할 수도 있습니다.
- 모듈 3에서는 GitHub 사용자 인터페이스 (UI) 를 기반으로 하는 프로젝트와 Git 명령줄 인터페이스 (CLI) 를 기반으로 하는 두 부분으로 구성된 최종 프로젝트로 학습을 통합합니다.
- 강좌를 최대한 활용하려면 모든 비디오를 시청하고, 실습 활동을 완료하여 새로운 기술을 연습하고, 모든 퀴즈에 도전하고, 최종 프로젝트를 완료하고, 공유 가능한 포트폴리오를 만드세요.

## 예시
- 실습 활동의 일환으로 GitHub 계정과 프로젝트 리포지토리를 생성하게 됩니다.
