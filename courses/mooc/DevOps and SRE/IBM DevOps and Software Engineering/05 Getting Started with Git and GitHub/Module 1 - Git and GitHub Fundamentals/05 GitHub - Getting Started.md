# GitHub - Getting Started

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/getting-started-with-git-and-github/lecture/fe489/github-getting-started)

## 개요
- 이전 비디오에서는 Git과 GitHub에 대해 배웠습니다.이 동영상을 계속 시청하기 전에 GitHub 계정을 등록하고 로그인하세요.먼저 새 리포지토리를 만들어 보겠습니다.

## 내용
- 이전 비디오에서는 Git과 GitHub에 대해 배웠습니다.이 동영상을 계속 시청하기 전에 GitHub 계정을 등록하고 로그인하세요.먼저 새 리포지토리를 만들어 보겠습니다.
- +를 클릭한 다음 새 리포지토리를 클릭합니다.새 리포지토리를 만들려면 다음과 같은 세부 정보를 제공해야 합니다.
- 새 리포지토리의 이름을 지정하고, 선택적으로 리포지토리에 대한 설명을 추가하고, 리포지토리를 공개 또는 비공개로 할지 선택하고, 이 리포지토리를 readme 파일로 초기화하는 옵션을 선택하십시오.그런 다음 리포지토리 생성을 클릭합니다.
- 이제 추가 정보를 편집할 차례입니다.브라우저에서 이 작업을 수행할 수 있습니다.연필을 클릭하여 온라인 편집기를 열면 추가 정보의 텍스트를 변경할 수 있습니다.변경 내용을 저장소에 저장하려면 변경 내용을 커밋해야 합니다.변경한 후 아래로 스크롤하여 변경 내용 커밋 섹션으로 이동합니다.커밋 메시지를 추가하고 선택적으로 설명을 추가한 다음 변경 사항 커밋을 클릭합니다.
- 리포지토리 이름 링크를 클릭하여 홈 화면으로 돌아가십시오.Readme 파일이 업데이트되었으니 변경 내용을 확인하십시오.브라우저에서 실행되는 GitHub에서 제공하는 내장 웹 편집기를 사용하여 새 파일을 만드는 방법을 알아보겠습니다.파일 추가를 클릭한 다음 새 파일 생성을 클릭하여 새 파일을 생성합니다.
- firstpython.py 라는 파이썬 파일을 만들려면 먼저 파일 이름을 입력합니다.그런 다음 코드를 설명하는 설명을 추가한 다음 코드를 추가합니다.
- 업로드하는 항목에 따라 파일 업로드 프로세스에 다소 시간이 걸릴 수 있습니다.파일 업로드가 끝나면 변경 내용 커밋을 클릭합니다.이제 리포지토리에 업로드된 파일이 반영됩니다.이 비디오에서는 웹 인터페이스를 사용하여 리포지토리를 만들고, 파일을 편집하고, 변경 사항을 적용하는 방법을 배웠습니다.
