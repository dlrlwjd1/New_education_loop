# GitHub Repositories

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/getting-started-with-git-and-github/lecture/NPMOC/github-repositories)

## 개요
- GitHub 계정에 가입하는 방법과 리포지토리를 만드는 방법을 설명하세요.

## 내용
- GitHub 계정에 가입하는 방법과 리포지토리를 만드는 방법을 설명하세요.
- 사용자 이름을 선택하고 이메일 주소를 입력하고 비밀번호를 선택한 다음 GitHub 가입을 클릭해야 합니다.
- 저장소는 버전 제어를 추적하고 유지 관리하는 애플리케이션 소스 코드를 비롯한 문서를 저장하기 위한 데이터 구조라는 점을 기억하십시오.
- 사람들이 귀하의 코드를 사용할 수 있는 방법을 명시하는 라이선스 등 리포지토리를 비공개 (볼 수 있는 권한이 있는 계정만 사용 가능) 또는 공개 (모든 사람이 검색하고 볼 수 있음) 로 설정할 수도 있습니다.
- 리포지토리를 만들면 여러 탭이 있고 코드 탭이 열려 있는 것을 알 수 있습니다.
- 이슈 — 상상할 수 있듯이 프로젝트 기반에 대해 미해결 항목을 모두 나열하는 “이슈”와 같은 도구를 사용하여 추적하고 계획할 수 있습니다.
- Wiki, 보안 및 인사이트 — 고급 사용자만 사용할 수 있는 이러한 도구는 외부 사용자 커뮤니티에 커뮤니케이션 기반을 제공합니다.

## 예시
- Wiki, 보안 및 인사이트 — 고급 사용자만 사용할 수 있는 이러한 도구는 외부 사용자 커뮤니티에 커뮤니케이션 기반을 제공합니다.
