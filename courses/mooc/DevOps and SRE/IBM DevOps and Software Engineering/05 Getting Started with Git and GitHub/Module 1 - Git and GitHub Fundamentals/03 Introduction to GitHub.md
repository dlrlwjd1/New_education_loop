# Introduction to GitHub

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/getting-started-with-git-and-github/lecture/Vtjgd/introduction-to-github)

## 개요
- 이 동영상을 보고 나면 소스 리포지토리의 용도를 설명하고 GitHub가 소스 리포지토리의 요구 사항을 어떻게 충족하는지 설명할 수 있습니다.

## 내용
- 이 동영상을 보고 나면 소스 리포지토리의 용도를 설명하고 GitHub가 소스 리포지토리의 요구 사항을 어떻게 충족하는지 설명할 수 있습니다.
- 많은 개발 경로로 인해 명시적인 통합 전략이 필요할 수 있는 복잡한 통합 결정으로 이어질 수 있습니다.
- 중앙 버전 관리 시스템에서는 모든 개발자가 중앙 시스템에서 코드를 체크아웃하고 다시 코드를 작성해야 합니다.
- Git은 분산 버전 관리이므로 각 개발자는 전체 개발 기록의 로컬 사본을 가지고 있으며 이러한 저장소에서 다른 저장소로 변경 내용이 복사됩니다.각 개발자가 허브 역할을 할 수 있습니다.
- Git은 GitHub Desktop 클라이언트를 통해 로컬에서 함께 사용할 수도 있고 GitHub 웹 인터페이스에 연결된 브라우저를 통해 직접 사용할 수도 있습니다.
- GitLab을 통해 개발자는 공동 작업하고, 코드를 검토하고, 댓글을 달고, 서로의 코드를 개선하는 데 도움을 줄 수 있습니다.
- 리포지토리는 애플리케이션 소스 코드를 포함한 문서를 저장하고 기여자가 버전 관리를 추적하고 유지할 수 있도록 합니다.

## 예시
- 리포지토리는 애플리케이션 소스 코드를 포함한 문서를 저장하고 기여자가 버전 관리를 추적하고 유지할 수 있도록 합니다.

## 요약
- GitLab을 통해 개발자는 공동 작업하고, 코드를 검토하고, 댓글을 달고, 서로의 코드를 개선하는 데 도움을 줄 수 있습니다. 리포지토리는 애플리케이션 소스 코드를 포함한 문서를 저장하고 기여자가 버전 관리를 추적하고 유지할 수 있도록 합니다.
