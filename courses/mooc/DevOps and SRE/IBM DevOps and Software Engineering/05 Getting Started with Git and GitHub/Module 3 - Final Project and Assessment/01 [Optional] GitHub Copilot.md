# [Optional] GitHub Copilot

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/getting-started-with-git-and-github/lecture/9Kj6D/optional-github-copilot)

## 개요
- Visual Studio 코드를 비롯한 다양한 코드 편집기의 플러그인으로 작동하도록 설계되었으며 상황에 맞는 코드 제안을 제공합니다.깃허브 코파일럿의 기능을 살펴보겠습니다.

## 내용
- Visual Studio 코드를 비롯한 다양한 코드 편집기의 플러그인으로 작동하도록 설계되었으며 상황에 맞는 코드 제안을 제공합니다.깃허브 코파일럿의 기능을 살펴보겠습니다.
- GitHub Copilot은 현재 작업 중인 코드의 컨텍스트를 기반으로 전체 코드 줄 또는 블록 전체를 제안합니다.
- GitHub Copilot은 코드 컨텍스트를 기반으로 함수 이름, 변수 이름, 알고리즘 구현을 비롯한 제안을 생성합니다.
- 예를 들어, Python 프로젝트에서 코딩하는 동안 네 개의 루프를 작성하기 시작하고 전체 밑줄 , 수량 등의 변수를 선언하면 GitHub Copilot이 루프 구조 및 계산에 대한 제안을 제공할 수 있습니다.
- GitHub Copilot은 널리 사용되는 다양한 코드 편집기 및 Pycharm과 같은 통합 개발 환경 또는 ID와 통합됩니다.
- 또 다른 예로 새 변수를 선언하기 시작할 때 GitHub Copilot에서 변수 이름에 대한 자동 완성 제안을 제공하는 경우를 들 수 있습니다.
- 제안을 수락하려면 탭 키를 사용하거나 제안을 선택하면 됩니다.코드를 생성하거나 편집한 후에는 코드를 검토하여 프로젝트의 요구 사항 및 베스트 코딩 관행에 맞는지 확인해야 합니다.

## 예시
- 예를 들어, Python 프로젝트에서 코딩하는 동안 네 개의 루프를 작성하기 시작하고 전체 밑줄 , 수량 등의 변수를 선언하면 GitHub Copilot이 루프 구조 및 계산에 대한 제안을 제공할 수 있습니다.
