# Managing GitHub Projects

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/getting-started-with-git-and-github/lecture/UR6eC/managing-github-projects)

## 개요
- 그룹 프로젝트의 참여자로 일하는 개발자는 독립 실행형 개발자가 필요로 하는 명령 외에도 다른 사람과 통신하고 이러한 명령을 사용하는 방법을 배워야 합니다.

## 내용
- 그룹 프로젝트의 참여자로 일하는 개발자는 독립 실행형 개발자가 필요로 하는 명령 외에도 다른 사람과 통신하고 이러한 명령을 사용하는 방법을 배워야 합니다.
- 그룹 프로젝트의 통합자는 다른 사용자가 변경한 내용을 받아 검토 및 통합하고, 풀 요청에 응답하고, 다른 사람들이 사용할 수 있도록 결과를 게시합니다.
- 또한 웹 서비스 및 문서에 액세스하는 데 필요한 서버를 구성하고, 이메일 및 색인 설정을 정의하고, 애플리케이션의 모양과 느낌을 관리합니다.
- 그룹 프로젝트에서 작업하는 개발자는 git clone, git pull, git fetch, git push, git request pull 등의 명령을 사용합니다.
- 독립 실행형 개발자가 필요로 하는 작업 외에도 그룹 프로젝트의 통합자는 다른 사용자가 변경한 내용을 검토하고 통합합니다.
- 통합자는 참가자에게 필요한 명령 외에도 git pull, git revert, git push와 같은 명령을 사용합니다.
- 또한 웹 서비스 및 문서에 액세스하는 데 필요한 서버를 구성하고, 전자 메일과 색인 설정을 정의하고, 응용 프로그램의 모양과 느낌을 관리합니다.

## 예시
- 또한 웹 서비스 및 문서에 액세스하는 데 필요한 서버를 구성하고, 전자 메일과 색인 설정을 정의하고, 응용 프로그램의 모양과 느낌을 관리합니다.

## 요약
- 통합자는 참가자에게 필요한 명령 외에도 git pull, git revert, git push와 같은 명령을 사용합니다. 또한 웹 서비스 및 문서에 액세스하는 데 필요한 서버를 구성하고, 전자 메일과 색인 설정을 정의하고, 응용 프로그램의 모양과 느낌을 관리합니다.
