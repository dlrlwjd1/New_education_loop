# Cloning and Forking GitHub Projects

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/getting-started-with-git-and-github/lecture/0CWLT/cloning-and-forking-github-projects)

## 개요
- 팀에 합류하든 이전 작업을 기반으로 프로젝트를 시작하든, 가장 강력한 도구 중 가장 강력한 도구는 리포지토리 포크와 복제입니다.

## 내용
- 팀에 합류하든 이전 작업을 기반으로 프로젝트를 시작하든, 가장 강력한 도구 중 가장 강력한 도구는 리포지토리 포크와 복제입니다.
- 이 기능은 기존 프로젝트를 새 프로젝트의 시작점으로 삼는 데 자주 사용됩니다 새 프로젝트의 시작점으로 만드는 데 자주 사용됩니다.
- 원격 리포지토리는 인터넷, 네트워크, 로컬 컴퓨터 등 다른 곳에 저장된 리포지토리입니다 네트워크, 심지어 로컬 컴퓨터에도 저장되어 있습니다.
- 다른 사람들과 공동 작업하려면 이러한 원격 리포지토리를 관리해야 하며, 푸시, 작업을 공유해야 할 때 리포지토리를 오가는 푸시, 풀, 가져오기 작업이 포함됩니다.
- 원격 리포지토리의 변경 내용을 로컬 리포지토리로 전송하고 브랜치에 병합하려면 git pull을 사용하여 브랜치에 병합한다.
- 다른 관심 있는 명령으로는 업스트림 브랜치를 가져오는 git fetch upstream, 업스트림 브랜치를 가져오는 git merge upstream/main은 변경 내용을 메인 브랜치에 병합하는 명령이다.
- 리포지토리를 복제하여 로컬 컴퓨터로 복사하고 변경 내용을 원래 리포지토리에 다시 동기화할 수 있습니다.

## 예시
- 리포지토리를 복제하여 로컬 컴퓨터로 복사하고 변경 내용을 원래 리포지토리에 다시 동기화할 수 있습니다.

## 요약
- 다른 관심 있는 명령으로는 업스트림 브랜치를 가져오는 git fetch upstream, 업스트림 브랜치를 가져오는 git merge upstream/main은 변경 내용을 메인 브랜치에 병합하는 명령이다. 리포지토리를 복제하여 로컬 컴퓨터로 복사하고 변경 내용을 원래 리포지토리에 다시 동기화할 수 있습니다.
