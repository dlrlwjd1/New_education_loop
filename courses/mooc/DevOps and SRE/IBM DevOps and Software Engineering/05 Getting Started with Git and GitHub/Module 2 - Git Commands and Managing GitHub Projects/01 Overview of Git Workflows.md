# Overview of Git Workflows

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/getting-started-with-git-and-github/lecture/ZL8gJ/overview-of-git-workflows)

## 개요
- git 워크플로를 명확히 이해하면 버전 제어 및 협업에 git을 효과적으로 사용할 수 있습니다.이러한 지식을 통해 코드 충돌이나 팀원의 작업을 실수로 무력화하는 등의 문제를 방지할 수 있습니다.

## 내용
- git 워크플로를 명확히 이해하면 버전 제어 및 협업에 git을 효과적으로 사용할 수 있습니다.이러한 지식을 통해 코드 충돌이나 팀원의 작업을 실수로 무력화하는 등의 문제를 방지할 수 있습니다.
- 또한 원격 리포지토리에서 로컬 리포지토리로 변경 내용을 가져와서 업데이트할 수도 있습니다.
- 다음 단계는 git에서 추적할 모든 프로젝트 파일을 선택하고 스테이징 영역으로 이동한 다음 초기 커밋을 수행하는 것입니다.
- 그런 다음 로컬 리포지토리의 모든 프로젝트 파일을 원격 리포지토리로 푸시합니다.
- Anne은 pull 요청을 검토하고 이를 승인하여 변경 내용을 메인 브랜치에 병합하여 다른 개발자들이 John이 변경한 내용에 액세스할 수 있도록 합니다.
- 그런 다음 Git에서 추적할 파일을 선택하고 스테이징 영역으로 이동한 다음 초기 커밋을 수행합니다.
- 변경 사항을 푸시하여 다른 개발자가 이 원격 리포지토리를 복제하고 프로젝트 파일을 업데이트하는 정규 워크플로를 따를 수 있도록 하세요.

## 예시
- 이 동영상을 보고 나면 Git 워크플로의 단계를 설명하고 실제 시나리오에서 워크플로를 설명할 수 있습니다.

## 요약
- 그런 다음 Git에서 추적할 파일을 선택하고 스테이징 영역으로 이동한 다음 초기 커밋을 수행합니다. 변경 사항을 푸시하여 다른 개발자가 이 원격 리포지토리를 복제하고 프로젝트 파일을 업데이트하는 정규 워크플로를 따를 수 있도록 하세요.
