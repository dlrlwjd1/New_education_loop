# Overview of Git Commands

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/getting-started-with-git-and-github/lecture/1LQzR/overview-of-git-commands)

## 개요
- 깃 명령은 변경 사항을 추적 및 저장하고 다른 사람과 변경 사항을 공유하는 등 다양한 용도로 사용됩니다 .

## 내용
- 깃 명령은 변경 사항을 추적 및 저장하고 다른 사람과 변경 사항을 공유하는 등 다양한 용도로 사용됩니다 .
- 또한 git init, git add, git commit, git log, git branch, git checkout, git merge, git status와 같은 몇 가지 기본적인 Git 명령에 대해 설명합니다.
- 이를 위해 git commit-m 명령을 사용하여 변경 사항의 스테이징 스냅샷을 만들고 설명 메시지와 함께 프로젝트에 저장합니다.
- 분리된 상태에서 작업하기 위해서는 Git 저장소 내에서 브랜치를 나열, 생성, 이름 변경, 심지어 삭제까지 할 수 있는 git 브랜치 명령을 사용하면 됩니다.
- Git 작업 디렉터리에서 변경한 모든 변경 사항의 상태를 확인하려면 git status 명령을 실행해 보겠습니다.
- 이 예에서는 git checkout 명령을 사용하여 먼저 메인 브랜치로 이동한 다음 이 경우 코드_목록이라는 브랜치 이름 뒤에 git merge를 사용합니다.
- 이 비디오에서는 다양한 작업을 수행하는 데 사용할 수 있는 CLI 명령어에 대해 배웠습니다.<새 디렉터리를 생성하는 mkdir, 특정 디렉터리로 이동하는 cd, Git 저장소를 시작하는 git init, 작업 디렉터리 에서 스테이징 영역으로 변경 내용을 이동하는 git add, 프로젝트에 변경 내용을 커밋하는 git commit 명령이 있습니다, 이전 변경 내용을 찾아보려면 git log, 새 브랜치를 만들려면 git branch, 기존 브랜치를 전환하려면 git checkout, 브랜치를 메인 브랜치로 업데이트하려면 git merge, 작업 디렉터리의 상태를 보려면 git status를 사용합니다.

## 예시
- 프로젝트의 원활한 기능에 도움이 될 수있는 mkdir, cd와 같은 일반적인 명령 줄 명령을 이해하기 위한 시나리오를 고려해 보겠습니다.
