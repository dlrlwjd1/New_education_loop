# Introduction to Agile Development and Scrum

## 개요
- Agile 원칙, Scrum 역할·이벤트·산출물과 반복 계획·실행을 익힌다.

## 내용
- 가치 있는 작은 increment를 자주 전달하고 피드백에 따라 backlog를 조정한다.
- Product Owner는 우선순위, Scrum Master는 흐름과 장애 제거, Developers는 완료 가능한 increment에 책임진다.
- epic을 사용자 story와 task로 나누고 acceptance criteria, 상대 추정, velocity로 sprint를 계획한다.
- daily scrum에서 계획을 조정하고 review에서 결과 피드백, retrospective에서 작업 방식을 개선한다.

## 예시
```text
As a customer, I want to reset my password so that I can regain access.
Given a valid account, when reset is requested, then an expiring link is sent.
```
