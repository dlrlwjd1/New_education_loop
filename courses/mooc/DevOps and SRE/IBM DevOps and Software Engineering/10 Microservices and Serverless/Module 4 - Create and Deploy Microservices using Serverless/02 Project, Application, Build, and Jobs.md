# Project, Application, Build, and Jobs

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/applications-development-microservices-serverless-openshift/lecture/uvwok/project-application-build-and-jobs)

## 개요
- 이 비디오를 시청한 후에는 IBM Cloud Code Engine에서 프로젝트가 무엇인지 설명하고, IBM Cloud Code Engine에서 애플리케이션이 무엇인지 설명하고, IBM Cloud Code Engine의 빌드가 무엇인지 설명하고, IBM Cloud Code Engine에서 어떤 작업이 있는지 설명할 수 있습니다.

## 내용
- 이 비디오를 시청한 후에는 IBM Cloud Code Engine에서 프로젝트가 무엇인지 설명하고, IBM Cloud Code Engine에서 애플리케이션이 무엇인지 설명하고, IBM Cloud Code Engine의 빌드가 무엇인지 설명하고, IBM Cloud Code Engine에서 어떤 작업이 있는지 설명할 수 있습니다.
- Code Engine 컨텍스트에서 빌드 또는 이미지 빌드는 소스 코드에서 컨테이너 이미지를 만드는 데 사용할 수 있는 메커니즘입니다.
- 컨테이너 이미지에는 실행 가능한 소스 코드, 종속성, 리소스, 컨테이너 엔진, 시스템 라이브러리, 구성 설정 등 컨테이너가 실행해야 하는 모든 자산이 포함됩니다.
- 여기에는 소스 코드 검사, 빌드 계획 작성 또는 이미지 생성을 위한 빌드 계획 실행과 같은 작업을 수행하는 실행 파일이 포함되어 있습니다.
- 소스 코드에서 컨테이너 이미지를 빌드한 후 빌드된 컨테이너 이미지를 Code Engine에 배포하고 그에 따라 애플리케이션을 만들 수 있습니다.
- 일반적인 작업으로는 데이터를 일괄적으로 쿼리하고 변환하는 데이터 처리 작업, 기계 학습 모델 교육 작업, 사전 설정된 일정에 따라 보고서를 생성하기 위한 보고 작업, 청구서를 생성하고 전송하는 청구 작업이 있습니다.
- 프로젝트는 애플리케이션, 작업, 빌드와 같은 Code Engine 엔티티를 그룹화하고, 애플리케이션은 코드를 실행하여 HTTP 요청을 처리하거나 WebSocket 세션을 생성하고, 빌드는 소스 코드에서 컨테이너 이미지를 만드는 프로세스이며, 작업은 실행 코드의 인스턴스를 하나 이상 실행합니다.

## 예시
- 예를 들어 여기에서 11개의 애플리케이션과 2개의 작업이 있는 것을 볼 수 있습니다.

## 요약
- 일반적인 작업으로는 데이터를 일괄적으로 쿼리하고 변환하는 데이터 처리 작업, 기계 학습 모델 교육 작업, 사전 설정된 일정에 따라 보고서를 생성하기 위한 보고 작업, 청구서를 생성하고 전송하는 청구 작업이 있습니다. 프로젝트는 애플리케이션, 작업, 빌드와 같은 Code Engine 엔티티를 그룹화하고, 애플리케이션은 코드를 실행하여 HTTP 요청을 처리하거나 WebSocket 세션을 생성하고, 빌드는 소스 코드에서 컨테이너 이미지를 만드는 프로세스이며, 작업은 실행 코드의 인스턴스를 하나 이상 실행합니다.
