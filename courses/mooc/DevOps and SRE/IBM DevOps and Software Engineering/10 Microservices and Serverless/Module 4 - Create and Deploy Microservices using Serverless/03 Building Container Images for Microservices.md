# Building Container Images for Microservices

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/applications-development-microservices-serverless-openshift/lecture/etSjt/building-container-images-for-microservices)

## 개요
- 이 비디오를 보고 나면 컨테이너가 무엇인지 설명하고, Docker가 무엇인지 설명하고, Docker 컨테이너 이미지를 구축할 수 있습니다.

## 내용
- 이 비디오를 보고 나면 컨테이너가 무엇인지 설명하고, Docker가 무엇인지 설명하고, Docker 컨테이너 이미지를 구축할 수 있습니다.
- 일단 구축되면 컨테이너는 랩톱, 데스크톱 PC 또는 온프레미스 서버와 같은 모든 디바이스에서 실행할 수 있습니다.
- 이제 컨테이너는 가상 머신과 달리 모든 인스턴스에 게스트 운영 체제가 필요하지 않고 대신 호스트 운영 체제의 기능과 리소스를 활용할 수 있기 때문에 작고 빠르며 이식성이 뛰어납니다.
- 이미지는 애플리케이션 실행에 필요한 소스 코드, 라이브러리 및 종속성과 같은 모든 애플리케이션 자산을 포함하는 변경 불가능한 파일입니다.
- 이 기본 이미지는 운영 체제와 같은 공용 저장소에서 가져온 것이거나 여기서는 Python과 같은 특정 언어의 기본 이미지에서 가져온 경우가 많습니다.
- 선택적으로 일반 Python 도커 이미지 대신 마이크로서비스를 더 잘 지원하기 위해 보다 구체적이고 고급 기본 이미지를 추가할 수 있습니다.
- 일반적으로 이들은 동일한 애플리케이션 또는 서비스의 서로 다른 버전이므로 애플리케이션 또는 서비스의 이름이 저장소 이름으로 사용하기에 적합합니다.

## 예시
- 예를 들어 uwsgi-nginx-flask를 사용하면 단일 컨테이너에서 uWSGI 및 Nginx와 함께 실행되는 플라스크 마이크로서비스를 파이썬으로 만들 수 있습니다.

## 요약
- 선택적으로 일반 Python 도커 이미지 대신 마이크로서비스를 더 잘 지원하기 위해 보다 구체적이고 고급 기본 이미지를 추가할 수 있습니다. 일반적으로 이들은 동일한 애플리케이션 또는 서비스의 서로 다른 버전이므로 애플리케이션 또는 서비스의 이름이 저장소 이름으로 사용하기에 적합합니다.
