# IBM Cloud Code Engine

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/applications-development-microservices-serverless-openshift/lecture/4W2RZ/ibm-cloud-code-engine)

## 개요
- 이 비디오를 시청한 후에는 셀프 호스팅 마이크로서비스의 문제를 설명하고, IBM Cloud Code Engine을 설명하고, IBM Cloud Code Engine이 애플리케이션 배포에 어떻게 도움이 되는지 설명할 수 있습니다.

## 내용
- 이 비디오를 시청한 후에는 셀프 호스팅 마이크로서비스의 문제를 설명하고, IBM Cloud Code Engine을 설명하고, IBM Cloud Code Engine이 애플리케이션 배포에 어떻게 도움이 되는지 설명할 수 있습니다.
- IBM Cloud Code Engine (간단히 “Code Engine”) 은 개발자가 코드 개발에 집중할 수 있도록 워크로드의 구축, 배포 및 관리에 따른 운영 부담을 줄여줍니다.
- IBM Cloud Code Engine의 주요 목표는 개발자의 배포 부담을 덜어주는 것입니다.이를 통해 개발자는 코드를 클라우드 플랫폼으로 푸시하고 인프라를 무시할 수 있습니다.
- IBM Cloud Code Engine은 완전 관리형 서버리스 플랫폼이라고 할 수 있습니다.서비스형 플랫폼 (PaaS), 서비스형 컨테이너 (CaaS), 서버리스 배포 모델에 필요한 모든 기능을 결합합니다.
- 마이크로서비스를 구축한 경우 인프라를 쉽게 관리할 필요 없이 이를 IBM Cloud Code Engine 애플리케이션으로 실행하여 수신되는 HTTPS 요청을 직관적인 사용자 경험으로 처리할 수 있습니다.
- 따라서 배포된 모든 마이크로서비스와 작업은 모두 동일한 인프라 내에서 호스팅되기 때문에 원활하게 함께 작동할 수 있습니다.이제 IBM Cloud Code Engine이 제공할 수 있는 잠재적 이점을 요약해 보겠습니다.
- 그리고 IBM Cloud Code Engine의 세 가지 주요 사용 사례는 애플리케이션 배포, 애플리케이션 구축 및 배포, 작업 실행입니다.

## 예시
- 예를 들어 전자 상거래 웹 사이트의 트래픽은 휴일에 항상 최고조에 달하며 며칠 또는 일주일 후에는 트래픽이 크게 감소할 수 있습니다.

## 요약
- 따라서 배포된 모든 마이크로서비스와 작업은 모두 동일한 인프라 내에서 호스팅되기 때문에 원활하게 함께 작동할 수 있습니다.이제 IBM Cloud Code Engine이 제공할 수 있는 잠재적 이점을 요약해 보겠습니다. 그리고 IBM Cloud Code Engine의 세 가지 주요 사용 사례는 애플리케이션 배포, 애플리케이션 구축 및 배포, 작업 실행입니다.
