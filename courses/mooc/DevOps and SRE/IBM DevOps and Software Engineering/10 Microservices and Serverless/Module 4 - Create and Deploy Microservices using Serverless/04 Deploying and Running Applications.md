# Deploying and Running Applications

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/applications-development-microservices-serverless-openshift/lecture/jmrN4/deploying-and-running-applications)

## 개요
- 이 동영상을 시청한 후에는 컨테이너 이미지 기반 애플리케이션을 배포하는 두 가지 주요 모드를 설명하고, 앱 배포 프로세스에 IBM Cloud Console을 사용하는 방법을 설명하고, 앱 배포 프로세스에 IBM Cloud CLI를 사용하는 방법을 설명할 수 있습니다.

## 내용
- 이 동영상을 시청한 후에는 컨테이너 이미지 기반 애플리케이션을 배포하는 두 가지 주요 모드를 설명하고, 앱 배포 프로세스에 IBM Cloud Console을 사용하는 방법을 설명하고, 앱 배포 프로세스에 IBM Cloud CLI를 사용하는 방법을 설명할 수 있습니다.
- 두 모드 중 하나를 사용하여 컨테이너 이미지 기반 애플리케이션을 IBM Cloud Code에 배포할 수 있습니다.
- Cloud Code Engine은 고유한 이미지 이름을 가진 이미지를 가져온 다음 레지스트리 액세스 권한을 부여하여 자동으로 배포할 수 있습니다.
- 또는 이미지를 수동으로 빌드하지 않으려는 경우 코드와 함께 dockerfile 또는 빌드팩을 지정하고 Cloud Engine에 지침을 제공하여 소스 코드에서 애플리케이션을 빌드한 다음 배포할 수 있습니다.
- 명령줄 인터페이스 (CLI) 에 익숙하고 보다 정확한 배치를 수행하려는 경우 IBM Cloud CLI를 선택하여 애플리케이션을 생성하고 배포할 수 있습니다.
- 여기에는 애플리케이션 이름, 컨테이너 레지스트리의 이미지 참조, 컨테이너 레지스트리가 공개되지 않은 경우 레지스트리 액세스 등 세 가지 주요 인수가 있습니다.
- 이 비디오에서는 푸시된 컨테이너 이미지 또는 소스 코드 리포지토리에서 Cloud Engine 애플리케이션을 만들 수 있다는 것을 배웠습니다.

## 예시
- 이 비디오에서는 푸시된 컨테이너 이미지 또는 소스 코드 리포지토리에서 Cloud Engine 애플리케이션을 만들 수 있다는 것을 배웠습니다.

## 요약
- 여기에는 애플리케이션 이름, 컨테이너 레지스트리의 이미지 참조, 컨테이너 레지스트리가 공개되지 않은 경우 레지스트리 액세스 등 세 가지 주요 인수가 있습니다. 이 비디오에서는 푸시된 컨테이너 이미지 또는 소스 코드 리포지토리에서 Cloud Engine 애플리케이션을 만들 수 있다는 것을 배웠습니다.
