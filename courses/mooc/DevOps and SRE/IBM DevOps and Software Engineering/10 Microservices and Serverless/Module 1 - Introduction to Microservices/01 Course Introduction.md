# Course Introduction

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/applications-development-microservices-serverless-openshift/lecture/b6hg7/course-introduction)

## 개요
- 이 교육 과정은 마이크로서비스 및 서버리스와 같은 클라우드 네이티브 기술을 사용하여 솔루션을 설계, 개발, 배포 및 관리하려는 모든 사람을 포함하여 모든 소프트웨어 개발 전문가를 대상으로 합니다.

## 내용
- 이 교육 과정은 마이크로서비스 및 서버리스와 같은 클라우드 네이티브 기술을 사용하여 솔루션을 설계, 개발, 배포 및 관리하려는 모든 사람을 포함하여 모든 소프트웨어 개발 전문가를 대상으로 합니다.
- 아니면 유지보수를 단순화하고, 관리가 쉽고, 속도와 확장성을 제공하고, 구축하기 쉬운 소형 애플리케이션을 포함하는 마이크로서비스 아키텍처일까요?
- 마이크로서비스는 모든 기능을 수행하는 모놀리스로 알려진 대규모 애플리케이션을 구축하는 대신 대규모 애플리케이션을 독립적으로 유지 관리 및 확장 가능한 작은 조각으로 나누어 많은 이점을 제공합니다.
- 다음으로 모듈 2에서는 마이크로서비스 기반 애플리케이션의 기본 구성 요소인 RESTful API를 만드는 방법을 배웁니다.
- 그런 다음 모듈 3에서는 서버리스 프레임워크의 이점을 이해하고 다양한 서버리스 플랫폼에 대해 알아봅니다.
- 모듈 4에서는 IBM Cloud의 서버리스 환경인 Code Engine을 사용하여 마이크로서비스를 배포, 업데이트 및 확장합니다.
- 마지막으로 모듈 5에서는 마이크로서비스를 기반으로 애플리케이션을 만들고 서버리스 프레임워크를 사용하여 배포함으로써 과정 전반에 걸쳐 학습한 내용을 시연하는 최종 실습 프로젝트를 완료하게 됩니다.

## 예시
- 마지막으로 모듈 5에서는 마이크로서비스를 기반으로 애플리케이션을 만들고 서버리스 프레임워크를 사용하여 배포함으로써 과정 전반에 걸쳐 학습한 내용을 시연하는 최종 실습 프로젝트를 완료하게 됩니다.

## 요약
- 모듈 4에서는 IBM Cloud의 서버리스 환경인 Code Engine을 사용하여 마이크로서비스를 배포, 업데이트 및 확장합니다. 마지막으로 모듈 5에서는 마이크로서비스를 기반으로 애플리케이션을 만들고 서버리스 프레임워크를 사용하여 배포함으로써 과정 전반에 걸쳐 학습한 내용을 시연하는 최종 실습 프로젝트를 완료하게 됩니다.
