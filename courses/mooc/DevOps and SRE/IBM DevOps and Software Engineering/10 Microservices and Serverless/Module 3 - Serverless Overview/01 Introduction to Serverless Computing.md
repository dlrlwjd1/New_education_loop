# Introduction to Serverless Computing

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/applications-development-microservices-serverless-openshift/lecture/Hvcf7/introduction-to-serverless-computing)

## 개요
- “이는 하나 이상의 함수로 번들로 제공되는 애플리케이션을 플랫폼에 업로드한 다음 현재 필요한 정확한 수요에 따라 실행, 확장 및 청구하는 세분화된 배포 모델을 설명합니다.” 즉, 서버리스 컴퓨팅은 인프라 관리 책임을 클라우드 공급자에게 오프로드하여 개발자가 애플리케이션 비즈니스 로직에 집중할 수 있도록 합니다.

## 내용
- “이는 하나 이상의 함수로 번들로 제공되는 애플리케이션을 플랫폼에 업로드한 다음 현재 필요한 정확한 수요에 따라 실행, 확장 및 청구하는 세분화된 배포 모델을 설명합니다.” 즉, 서버리스 컴퓨팅은 인프라 관리 책임을 클라우드 공급자에게 오프로드하여 개발자가 애플리케이션 비즈니스 로직에 집중할 수 있도록 합니다.
- 서버리스 컴퓨팅은 서비스형 기능 (또는 FaaS) 플랫폼과 서비스형 백엔드 (또는 BaaS) 서비스의 조합이라고 생각하시면 됩니다.
- 개발자는 널리 사용되는 프로그래밍 언어를 사용하여 함수를 빌드하고, 추가 기능을 추가하여 앱 기능을 확장하고, 함수는 한 번에 하나의 작업만 수행하므로 더 나은 테스트를 수행하고, 앱과 함수를 최적화하고, 사용자 경험을 개선할 수 있습니다.
- 운영 고려 사항이 전혀 없다는 목표를 달성하기 위해 클라우드 공급자는 비용을 최소화하면서 컴퓨팅, 메모리 및 네트워킹 활용도를 극대화하고, OS 업데이트 및 보안 패치를 포함하는 서버 관리, 자동 확장 지원, 고가용성 유지, 보안 구현, 고성능 (또는 짧은 지연 시간) 구성, 모니터링 및 로깅 설정과 같은 일상적인 인프라 관리 및 유지 관리 작업을 담당합니다.
- 이제 이 그림에 표시된 다양한 클라우드 서비스 모델을 비교하면서 서버리스 서비스 모델과 관련하여 클라우드 공급자와 귀사의 책임에 대해 살펴보겠습니다.먼저 맨 왼쪽 스택 (기존 스택) 부터 시작하겠습니다.
- 서버리스는 서버 관리가 필요 없는 애플리케이션을 구축하고 실행하는 개념이고, 서버리스 컴퓨팅은 BaaS 서비스 및 FaaS 플랫폼을 사용하며, IT 컴퓨팅의 역사는 기존 컴퓨팅에서 서버리스 컴퓨팅으로 생산성 증가 추세를 보여줍니다.
- 서버리스 컴퓨팅의 경우 서버 관리, OS 업데이트, 보안 패치 및 모니터링과 같은 인프라 관리를 클라우드 공급자가 처리하고, 서버리스 컴퓨팅을 통해 개발자는 애플리케이션과 코드에 집중할 수 있습니다.마지막으로, 사용자에게는 CPU 유휴 시간이 아닌 사용량에 대해서만 요금이 청구됩니다.

## 예시
- 예를 들어 Docker 또는 Kubernetes 컨테이너를 만드는 데 필요한 단계를 생각해 보십시오.

## 요약
- 서버리스는 서버 관리가 필요 없는 애플리케이션을 구축하고 실행하는 개념이고, 서버리스 컴퓨팅은 BaaS 서비스 및 FaaS 플랫폼을 사용하며, IT 컴퓨팅의 역사는 기존 컴퓨팅에서 서버리스 컴퓨팅으로 생산성 증가 추세를 보여줍니다. 서버리스 컴퓨팅의 경우 서버 관리, OS 업데이트, 보안 패치 및 모니터링과 같은 인프라 관리를 클라우드 공급자가 처리하고, 서버리스 컴퓨팅을 통해 개발자는 애플리케이션과 코드에 집중할 수 있습니다.마지막으로, 사용자에게는 CPU 유휴 시간이 아닌 사용량에 대해서만 요금이 청구됩니다.
