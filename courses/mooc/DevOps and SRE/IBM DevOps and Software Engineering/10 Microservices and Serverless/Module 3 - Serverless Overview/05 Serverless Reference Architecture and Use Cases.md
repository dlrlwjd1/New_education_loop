# Serverless Reference Architecture and Use Cases

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/applications-development-microservices-serverless-openshift/lecture/EPUzB/serverless-reference-architecture-and-use-cases)

## 개요
- 이 동영상을 시청한 후에는 서버리스 프레임워크를 사용한 웹 애플리케이션 참조 아키텍처 설명, 서버리스 프레임워크의 기타 사용 사례 설명 등을 할 수 있습니다.

## 내용
- 이 동영상을 시청한 후에는 서버리스 프레임워크를 사용한 웹 애플리케이션 참조 아키텍처 설명, 서버리스 프레임워크의 기타 사용 사례 설명 등을 할 수 있습니다.
- 웹 애플리케이션 참조 아키텍처는 비즈니스 로직에 Amazon API Gateway인 AWS Lambda를 사용하는 범용 이벤트 기반 백엔드입니다.
- 프런트 엔드 애플리케이션에는 Create React App을 사용하여 생성된 모든 정적 콘텐츠가 포함되어 있습니다.
- 이러한 애플리케이션은 사전 인프라를 설정하지 않고도 작성 및 배포할 수 있습니다.또한 게시자, 구독자 주제 또는 이벤트 로그에서 트리거될 수 있으므로 복잡한 클러스터를 유지 관리할 필요 없이 탄력적이고 확장 가능한 이벤트 파이프라인을 제공합니다.
- 이러한 이벤트 스트리밍 파이프라인은 분석 시스템을 강화하고, 보조 데이터 저장소 및 캐시를 업데이트하거나, 피드 모니터링 시스템을 업데이트할 수 있습니다.
- 후처리는 이미지 인식이나 인공 지능 용도로도 사용되어 여권 사진에 그림자가 있는지 감지할 수 있습니다.애플리케이션을 구축할 때는 애플리케이션에서 사용할 언어를 결정해야 합니다.
- 웹 애플리케이션 참조 아키텍처는 AWS Lambda, Amazon API Gateway, Amazon DynamoDB, Amazon Cognito 및 Amazon Amplify Console을 사용하는 이벤트 기반 아키텍처입니다.

## 예시
- “서버리스 참조 아키텍처 및 사용 사례”에 오신 것을 환영합니다.

## 요약
- 후처리는 이미지 인식이나 인공 지능 용도로도 사용되어 여권 사진에 그림자가 있는지 감지할 수 있습니다.애플리케이션을 구축할 때는 애플리케이션에서 사용할 언어를 결정해야 합니다. 웹 애플리케이션 참조 아키텍처는 AWS Lambda, Amazon API Gateway, Amazon DynamoDB, Amazon Cognito 및 Amazon Amplify Console을 사용하는 이벤트 기반 아키텍처입니다.
