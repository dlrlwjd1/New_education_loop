# Introduction to the FaaS Model

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/applications-development-microservices-serverless-openshift/lecture/0PPGW/introduction-to-the-faas-model)

## 개요
- 이 동영상을 시청한 후에는 FaaS가 무엇인지 설명하고, FaaS 모델의 이점을 설명하고, FaaS의 원칙과 모범 사례를 설명할 수 있습니다.

## 내용
- 이 동영상을 시청한 후에는 FaaS가 무엇인지 설명하고, FaaS 모델의 이점을 설명하고, FaaS의 원칙과 모범 사례를 설명할 수 있습니다.
- FaaS (Function-as-a-Service) 는 일반적으로 마이크로서비스 애플리케이션 구축 및 실행과 관련된 복잡한 인프라 없이도 이벤트에 대응하여 코드를 실행할 수 있는 클라우드 컴퓨팅 서비스의 일종입니다.
- FaaS는 온프레미스 환경뿐만 아니라 하이브리드 클라우드에도 배포할 수 있습니다.상태를 저장하지 않지만 외부 캐시를 사용하여 상태를 유지할 수 있습니다.
- 그런 다음 함수는 이러한 요청을 처리하고, 필요한 경우 추가 처리 및/또는 저장을 위해 백엔드 서비스 (예: 파일 및 오브젝트 스토리지, 블록 스토리지, 알림 서비스 등) 로 전달됩니다.
- 일반적인 관리형 FaaS 제공업체로는 아마존의 AWS Lambda, Google Cloud Functions, Microsoft의 Azure 함수, IBM의 클라우드 함수, Red Hat의 OpenShift 클라우드 함수, Netlify, Oracle 및 Twilio와 같은 몇 가지 다른 공급자가 있습니다.
- 여기에는 쿠버네티스의 서버리스 기능을 위한 프레임워크인 Fission, 컨테이너 네이티브 서버리스 플랫폼인 Fn Project, 서버리스 워크로드를 구축, 배포 및 관리하기 위한 쿠버네티스 기반 플랫폼인 Knative, 모든 Linux 또는 Windows 프로세스를 함수로 전환할 수 있는 OpenFaaS가 포함됩니다.
- FaaS는 복잡한 인프라 없이 이벤트에 응답하여 코드를 실행할 수 있게 해주는 일종의 클라우드 컴퓨팅 서비스이고, FaaS는 여러 함수의 형태로 애플리케이션을 생성하는 서버리스 컴퓨팅의 하위 집합이며, FaaS는 하이브리드 클라우드와 온프레미스 환경에 배포할 수 있습니다.
