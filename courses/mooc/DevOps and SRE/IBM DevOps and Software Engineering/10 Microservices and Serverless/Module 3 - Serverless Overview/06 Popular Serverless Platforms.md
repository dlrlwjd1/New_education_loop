# Popular Serverless Platforms

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/applications-development-microservices-serverless-openshift/lecture/M2BfI/popular-serverless-platforms)

## 개요
- 이 서비스를 사용하면 서버를 프로비저닝하거나 관리할 필요 없이 애플리케이션 또는 백엔드 서비스의 코드를 실행할 수 있습니다.

## 내용
- 이 서비스를 사용하면 서버를 프로비저닝하거나 관리할 필요 없이 애플리케이션 또는 백엔드 서비스의 코드를 실행할 수 있습니다.
- C#, Java, JavaScript, PowerShell 또는 Python으로 함수를 작성하거나 사용자 지정 핸들러를 사용하여 거의 모든 다른 언어를 사용할 수 있습니다.
- Microsoft Azure는 우수한 개발자 운영 또는 DevOps 기능을 장려하여 지속적인 통합 및 제공을 위한 간편한 설정을 제공합니다.
- 소비량 요금제를 사용하면 기능이 실행되는 동안에만 비용을 지불하는 반면, 프리미엄 및 앱 서비스 요금제는 특수 요구 사항에 맞는 기능을 제공합니다.
- IBM Cloud 함수는 이벤트에서 또는 REST API를 통해 직접 액션을 트리거할 수 있도록 하여 다른 서비스와의 간편한 통합을 촉진합니다.
- 액션 코드와 같은 고객 데이터는 여러 영역에서 자동으로 동기화됩니다.코드를 실행하는 런타임 환경 및 인프라에 액세스할 수 없기 때문에 프로덕션 환경에서 서버리스 애플리케이션을 디버깅하는 것은 어려울 수 있습니다.
- 다른 서버리스 플랫폼에 비해 Knative의 장점은 Kubernetes를 기반으로 개발된 플랫폼을 제공함으로써 벤더 종속을 피할 수 있다는 것입니다.

## 예시
- 또한 파일 처리, 웹 애플리케이션, 사물 인터넷, IoT, 모바일 백엔드와 같은 다양한 사용 사례에 사용할 수 있습니다.

## 요약
- 액션 코드와 같은 고객 데이터는 여러 영역에서 자동으로 동기화됩니다.코드를 실행하는 런타임 환경 및 인프라에 액세스할 수 없기 때문에 프로덕션 환경에서 서버리스 애플리케이션을 디버깅하는 것은 어려울 수 있습니다. 다른 서버리스 플랫폼에 비해 Knative의 장점은 Kubernetes를 기반으로 개발된 플랫폼을 제공함으로써 벤더 종속을 피할 수 있다는 것입니다.
