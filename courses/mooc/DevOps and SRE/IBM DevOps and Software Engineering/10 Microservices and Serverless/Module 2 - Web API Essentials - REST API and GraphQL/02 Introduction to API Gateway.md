# Introduction to API Gateway

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/applications-development-microservices-serverless-openshift/lecture/vJCLd/introduction-to-api-gateway)

## 개요
- 이 동영상을 시청한 후에는 API Gateway에 대해 설명하고, API Gateway를 사용할 때의 이점을 설명하고, API Gateway 사용의 단점을 설명하고, 사용 가능한 API Gateway 제품을 설명할 수 있습니다.

## 내용
- 이 동영상을 시청한 후에는 API Gateway에 대해 설명하고, API Gateway를 사용할 때의 이점을 설명하고, API Gateway 사용의 단점을 설명하고, 사용 가능한 API Gateway 제품을 설명할 수 있습니다.
- 또한 게이트웨이는 다양한 마이크로서비스에 대한 단일 접점을 제공하고 요청에 대한 단일 응답을 제공합니다.
- 마지막으로, 백엔드에서 실행 중인 서비스에 대한 클라이언트의 지식 없이도 API를 원활하게 추가하거나 제거할 수 있습니다.
- 온라인 스토어는 마이크로서비스 아키텍처를 따르므로 이러한 서비스 중 일부에는 ID, 이름, 가격과 같은 제품에 대한 기본 정보를 공유하는 제품 정보 서비스, 재고를 알려주는 인벤토리 서비스, 고객이 제품을 주문할 수 있도록 하는 주문 서비스, 플랫폼에서 사용자를 검증하는 인증 서비스 등이 있습니다.
- API Gateway를 사용하면 이러한 복잡성을 제거하여 호스트와 위치를 변경하고, 서비스 인스턴스 수를 늘리거나 줄이고, 기존 서비스 (예: 주문 서비스) 를 새 것으로 교체할 수 있습니다.
- 관리형 제품이긴 하지만 오픈소스 세계에서는 유명한 이름으로는 인기 순위 1위에 오른 Kong, Apache APISIX, 관리형 버전도 있는 Tyk , 마지막으로 엔터프라이즈 버전으로도 제공되는 Gloo 등이 있습니다.
- 이 동영상에서는 API Gateway가 백엔드 서비스의 문 역할을 하고, 클라이언트에 서비스에 대한 통합 액세스를 제공하면서 추가 서비스를 연결할 수 있으며, 백엔드 서비스의 복잡성을 클라이언트로부터 숨기고, 백엔드 서비스를 쉽게 확장하거나 교체할 수 있게 해주고, 선택할 수 있는 관리형 및 오픈 소스 API Gateway 제품이 많다는 것을 배웠습니다.

## 예시
- 예를 들어 API Gateway를 사용하면 클라이언트가 한 번의 왕복으로 여러 서비스에서 데이터를 검색할 수 있습니다.

## 요약
- 관리형 제품이긴 하지만 오픈소스 세계에서는 유명한 이름으로는 인기 순위 1위에 오른 Kong, Apache APISIX, 관리형 버전도 있는 Tyk , 마지막으로 엔터프라이즈 버전으로도 제공되는 Gloo 등이 있습니다. 이 동영상에서는 API Gateway가 백엔드 서비스의 문 역할을 하고, 클라이언트에 서비스에 대한 통합 액세스를 제공하면서 추가 서비스를 연결할 수 있으며, 백엔드 서비스의 복잡성을 클라이언트로부터 숨기고, 백엔드 서비스를 쉽게 확장하거나 교체할 수 있게 해주고, 선택할 수 있는 관리형 및 오픈 소스 API Gateway 제품이 많다는 것을 배웠습니다.
