# Creating REST APIs

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/applications-development-microservices-serverless-openshift/lecture/E0Ob5/creating-rest-apis)

## 개요
- 파이썬으로 RESTful API를 생성하고 플라스크를 사용하여 REST API를 호스팅할 수 있습니다.

## 내용
- 파이썬으로 RESTful API를 생성하고 플라스크를 사용하여 REST API를 호스팅할 수 있습니다.
- Python은 수학, 과학 및 공학을 위한 SciPy와 같은 라이브러리의 도움을 받아 과학 및 수치 컴퓨팅에 널리 사용됩니다.
- Flask는 특정 도구나 라이브러리가 필요하지 않기 때문에 마이크로 웹 프레임워크로 분류됩니다.
- Flask는 어떤 데이터베이스 또는 템플릿 엔진을 사용할지에 대해 의견이 없기 때문에 RESTful API에 적합합니다.
- 브라우저에서 127 도트 0 도트 0 도트 1 및 포트 5000으로 이동하여 이 '헬로 월드' 웹 애플리케이션을 열면 “Hello World”라는 응답이 표시됩니다.
- 이제 'products.py '라는 이름의 새 Python 파일을 생성하여 제품 마이크로서비스를 위한 모든 엔드포인트를 제공합니다.
- Flask는 Python 웹 애플리케이션을 호스팅하는 마이크로 웹 프레임워크이며, Python을 사용하여 첫 번째 RESTful API를 마이크로서비스로 생성할 수 있으며, Flask를 사용하여 첫 번째 RESTful API를 호스팅할 수 있습니다.

## 예시
- Flask는 Python 웹 애플리케이션을 호스팅하는 마이크로 웹 프레임워크이며, Python을 사용하여 첫 번째 RESTful API를 마이크로서비스로 생성할 수 있으며, Flask를 사용하여 첫 번째 RESTful API를 호스팅할 수 있습니다.
