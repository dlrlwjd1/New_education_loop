# What is REST

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/applications-development-microservices-serverless-openshift/lecture/DyPop/what-is-rest)

## 개요
- 이 동영상을 시청한 후에는 RESTful API에 대해 설명하고, REST API의 주요 특징을 설명하고, REST API 사용의 이점을 설명할 수 있습니다.

## 내용
- 이 동영상을 시청한 후에는 RESTful API에 대해 설명하고, REST API의 주요 특징을 설명하고, REST API 사용의 이점을 설명할 수 있습니다.
- REST API는 애플리케이션을 통합하는 유연하고 가벼운 방법을 제공하며 마이크로서비스 아키텍처에서 구성 요소를 연결하는 가장 일반적인 방법으로 부상하고 있습니다.
- HTTP를 통해 모든 요청을 관리하고, 상태 비저장, 클라이언트-서버 통신을 제공하며, 구성 요소 간의 통일된 인터페이스로 구성됩니다.
- REST API는 HTTP 요청을 통해 통신하여 리소스 내에서 레코드 (CRUD라고도 함) 생성, 읽기, 업데이트 및 삭제와 같은 표준 기능을 수행합니다.
- 예를 들어 REST API는 POST 요청을 사용하여 레코드를 생성하고, GET 요청을 사용하여 레코드를 검색하고, PUT 요청을 사용하여 레코드를 업데이트하고, DELETE 요청을 사용하여 레코드를 삭제합니다.
- “클라이언트에서 서버로의 각 요청에는 요청을 이해하는 데 필요한 모든 정보가 포함되어야 하며 서버에 저장된 컨텍스트를 활용할 수 없습니다.
- 이 비디오에서는 REST API가 구성 요소 간에 유연하지만 균일한 인터페이스를 제공하고, REST API는 상태를 저장하지 않고 확장 가능하며, REST API는 POST, GET, PUT 및 DELETE HTTP 메서드를 사용하여 통신하고, REST는 애플리케이션의 통신 방식을 정의하는 아키텍처 스타일이라는 것을 배웠습니다.

## 예시
