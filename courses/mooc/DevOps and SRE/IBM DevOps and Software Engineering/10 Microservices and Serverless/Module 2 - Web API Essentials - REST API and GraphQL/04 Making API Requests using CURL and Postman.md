# Making API Requests using CURL and Postman

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/applications-development-microservices-serverless-openshift/lecture/9VPp3/making-api-requests-using-curl-and-postman)

## 개요
- 이 비디오를 시청한 후에는 cURL을 사용하여 HTTP 요청을 만드는 방법을 설명하고 Postman을 사용하여 HTTP 요청을 만드는 방법을 설명할 수 있습니다.

## 내용
- 이 비디오를 시청한 후에는 cURL을 사용하여 HTTP 요청을 만드는 방법을 설명하고 Postman을 사용하여 HTTP 요청을 만드는 방법을 설명할 수 있습니다.
- curl은 “Client URL”의 줄임말로 다양한 네트워크 프로토콜을 통해 데이터를 전송할 수 있는 명령줄 도구입니다.
- curl은 다양한 옵션을 지원하므로 매우 다양한 명령을 사용할 수 있습니다.
- 이제 Postman은 매우 사용자 친화적인 다양한 도구를 기반으로 API를 구축 및 사용하기 위한 API 플랫폼으로, 개발자가 API를 쉽게 작성, 테스트, 공유 및 문서화할 수 있도록 합니다.
- Postman은 여러 번 반복하거나 반복하여 수행할 수 있는 여러 요청을 오케스트레이션하여 API 라이프사이클의 각 단계를 간소화하고 협업을 간소화하여 더 나은 API를 더 빠르게 만들 수 있도록 도와줍니다.
- 또한 단순하기 때문에 GET, POST, PUT 및 Patch와 같은 HTTP 요청과 같은 다양한 프로토콜을 지원하는 다양한 API를 테스트한 다음 API를 JavaScript 및 Python과 같은 언어의 코드로 변환하는 데 가장 인기 있고 편리한 도구 중 하나입니다.
- 이 비디오에서는 cURL로 데이터를 전송하는 데 cURL이 사용되고, 명령줄 또는 스크립트에서 cURL을 사용할 수 있고, Postman은 API를 빌드하고 사용하기 위한 API 플랫폼이며, Postman은 API를 테스트하기 위한 간단하고 널리 사용되는 도구라는 것을 배웠습니다.

## 예시
- curl의 가장 일반적인 사용 사례는 인터넷에서 파일 다운로드, 엔드포인트 테스트, 디버깅 및 오류 로깅입니다.
