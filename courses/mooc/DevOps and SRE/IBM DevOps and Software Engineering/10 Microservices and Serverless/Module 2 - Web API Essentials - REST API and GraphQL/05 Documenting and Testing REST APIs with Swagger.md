# Documenting and Testing REST APIs with Swagger

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/applications-development-microservices-serverless-openshift/lecture/H4L9b/documenting-and-testing-rest-apis-with-swagger)

## 개요
- 이 비디오를 시청한 후에는 Swagger를 사용하여 REST API를 문서화하고 Swagger를 사용하여 REST API를 테스트할 수 있습니다.

## 내용
- 이 비디오를 시청한 후에는 Swagger를 사용하여 REST API를 문서화하고 Swagger를 사용하여 REST API를 테스트할 수 있습니다.
- Swagger는 OpenAPI 사양을 실행하여 지침을 충족하는지 확인함으로써 API 문서를 작성하는 시간을 절약합니다.
- 이 구조는 OpenAPI 사양을 준수하는 JSON 또는 YAML 파일에 정의되어 있습니다.
- 반면 OpenAPI 사양은 RESTful API에 대한 언어에 구애받지 않는 표준 인터페이스를 정의합니다.
- 또한 소스 코드에 액세스하거나 추가 문서를 작성하거나 네트워크 트래픽을 검사하지 않고도 사람과 컴퓨터가 서비스의 기능을 검색하고 이해할 수 있습니다.
- 그런 다음 Swagger를 사용할 수 있는 경로로 구성된 기본 구성을 정의합니다.
- 이 비디오에서는 Swagger가 API를 문서화하는 데 도움이 되고, OpenAPI 사양은 API를 나타내는 표준 방법이며, Swagger는 API를 테스트하기 위한 메커니즘을 제공한다는 것을 배웠습니다.

## 요약
- 그런 다음 Swagger를 사용할 수 있는 경로로 구성된 기본 구성을 정의합니다. 이 비디오에서는 Swagger가 API를 문서화하는 데 도움이 되고, OpenAPI 사양은 API를 나타내는 표준 방법이며, Swagger는 API를 테스트하기 위한 메커니즘을 제공한다는 것을 배웠습니다.
