# Optional - Basics of GraphQL

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/applications-development-microservices-serverless-openshift/lecture/2smnm/optional-basics-of-graphql)

## 개요
- 이 비디오를 시청한 후에는 GraphQL에 대해 설명하고, GraphQL API의 주요 특징을 설명하고, GraphQL API 사용의 이점을 설명할 수 있습니다.

## 내용
- 이 비디오를 시청한 후에는 GraphQL에 대해 설명하고, GraphQL API의 주요 특징을 설명하고, GraphQL API 사용의 이점을 설명할 수 있습니다.
- GraphQL을 사용하면 API에서 필요한 것을 정확히 검색할 수 있습니다.
- RESTful API와 달리 GraphQL은 필요한 모든 것을 검색하기 위해 단 하나의 엔드포인트만 있으면 됩니다.
- REST를 사용하면 여러 번 전화를 걸고 서버에서 보낸 모든 것을 수신할 수 있습니다.
- 기존 클라이언트가 필요한 것만 요청했기 때문에 기존 클라이언트를 손상시키지 않고 새 필드를 추가할 수 있습니다.
- 그리고 뮤테이션 유형의 모든 필드는 RESTful API에서 POST, PUT 또는 DELETE 요청으로 간주할 수 있습니다.
- GraphQL은 언어에 구애받지 않는 API용 쿼리 언어로서, 더도 말고 덜도 말고 정확한 데이터를 제공하며 엔드포인트가 하나라는 것을 배웠습니다.

## 예시
- GraphQL은 언어에 구애받지 않는 API용 쿼리 언어로서, 더도 말고 덜도 말고 정확한 데이터를 제공하며 엔드포인트가 하나라는 것을 배웠습니다.

## 요약
- 그리고 뮤테이션 유형의 모든 필드는 RESTful API에서 POST, PUT 또는 DELETE 요청으로 간주할 수 있습니다. GraphQL은 언어에 구애받지 않는 API용 쿼리 언어로서, 더도 말고 덜도 말고 정확한 데이터를 제공하며 엔드포인트가 하나라는 것을 배웠습니다.
