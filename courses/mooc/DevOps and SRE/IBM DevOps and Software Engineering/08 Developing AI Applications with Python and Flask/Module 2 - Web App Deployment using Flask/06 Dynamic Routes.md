# Dynamic Routes

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/python-project-for-ai-application-development/lecture/d64E7/dynamic-routes)

## 개요
- 하지만 결과를 다시 클라이언트에 보내기 전에 결과를 처리할 수도 있습니다.

## 내용
- 하지만 결과를 다시 클라이언트에 보내기 전에 결과를 처리할 수도 있습니다.
- 요청 라이브러리를 사용하여 오픈라이브러리 API를 요청하고 작성자 마이클 크라이튼의 정보를 검색하세요.
- 마지막으로, 이 가상의 경우 응답이 다른 것이면 상태가 500이고 “서버 오류”라는 메시지와 함께 반환됩니다.
- 예를 들어, ISBN (International Standard Book Number) 으로 책 정보를 반환하는 엔드포인트를 만들고 싶지만 ISBN을 하드 코딩하는 대신 클라이언트가 URL의 일부로 전송하도록 하려는 경우 Flask는 이를 위한 동적 라우팅을 제공합니다.
- 문자열, int, float는 단순한 매개변수이지만 웹 경로나 폴더 경로를 나타내는 경로와 같은 복잡한 매개변수를 사용하거나 GUID ( 글로벌 고유 식별자) 와 같은 고유 ID를 나타내는 UUID (범용 고유 식별자) 와 같은 복잡한 매개변수를 사용할 수도 있습니다.
- 네트워크에 대한 정보를 얻기 위해 특정 UUID를 가진 엔드포인트 “네트워크”를 생성할 수 있습니다.
- 경로가 uuid 유형의 변수 uuid를 예상하고, uuid가 메서드에 인수로 전달되고, uuid가 발견되면 성공 메시지를 반환하고 , 그렇지 않으면 적절한 메시지와 함께 오류 코드를 반환하는 곳에서 이 코드를 작성할 수 있습니다.

## 예시
- 예를 들어, ISBN (International Standard Book Number) 으로 책 정보를 반환하는 엔드포인트를 만들고 싶지만 ISBN을 하드 코딩하는 대신 클라이언트가 URL의 일부로 전송하도록 하려는 경우 Flask는 이를 위한 동적 라우팅을 제공합니다.

## 요약
- 네트워크에 대한 정보를 얻기 위해 특정 UUID를 가진 엔드포인트 “네트워크”를 생성할 수 있습니다. 경로가 uuid 유형의 변수 uuid를 예상하고, uuid가 메서드에 인수로 전달되고, uuid가 발견되면 성공 메시지를 반환하고 , 그렇지 않으면 적절한 메시지와 함께 오류 코드를 반환하는 곳에서 이 코드를 작성할 수 있습니다.
