# Flask - Basic Applications and Routes

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/python-project-for-ai-application-development/lecture/Zg8Hi/flask-basic-applications-and-routes)

## 개요
- 내장 이름 변수에 앱 모듈의 이름을 전달하여 스캐폴드에서 이름을 설정합니다.이 이름은 파일 시스템에서 리소스를 찾는 데 사용되며 확장자를 통해 디버깅 정보를 제공하는 데 사용됩니다.

## 내용
- 내장 이름 변수에 앱 모듈의 이름을 전달하여 스캐폴드에서 이름을 설정합니다.이 이름은 파일 시스템에서 리소스를 찾는 데 사용되며 확장자를 통해 디버깅 정보를 제공하는 데 사용됩니다.
- 또한 개발 또는 프로덕션 환경을 정의하는 FLASK_ENV 변수가 필요합니다.이 변수는 Flask 2.3에서 더 이상 사용되지 않습니다.
- 첫 번째 Flask 애플리케이션을 실행한 것을 축하합니다.애플리케이션을 실행하기 전에 각 애플리케이션에 대한 환경 변수를 설정해야 합니다.
- 두 번째 방법은 Flask에서 제공하는 jsonify 메서드를 사용하는 것입니다.이 메서드는 입력 시 키-값 쌍을 받아 적절한 JSON을 반환합니다.
- FLASK_ENV 및 FLASK_APP 변수를 사용하여 두 가지 구성을 살펴보았습니다.Flask는 애플리케이션에서 사용할 수 있는 다양한 기타 구성 옵션을 제공합니다.
- 마지막으로 구성 옵션을 별도의 JSON 파일에 보관하고 구성 객체에서 제공하는 “from_file” 메서드를 사용하여 로드할 수 있습니다.
- 앱이 커지면 단일 Python 파일을 사용하는 대신 디렉터리 구조를 만들어야 합니다.애플리케이션을 구조화하는 방법에는 여러 가지가 있습니다.다음은 한 가지 예입니다.
