# Deploying Web Apps using Flask

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/python-project-for-ai-application-development/lecture/A4uhA/deploying-web-apps-using-flask)

## 개요
- Flask 설치 Flask를 사용하여 Python 웹 앱을 만들고 배포하는 것은 Python으로 웹 애플리케이션을 빠르고 쉽게 만들 수 있는 마이크로 프레임워크입니다.

## 내용
- Flask 설치 Flask를 사용하여 Python 웹 앱을 만들고 배포하는 것은 Python으로 웹 애플리케이션을 빠르고 쉽게 만들 수 있는 마이크로 프레임워크입니다.
- 참고로 대부분의 웹 애플리케이션은 객체와 데이터를 생성, 업데이트 및 삭제하는 데 POST를 사용하고 읽기에는 GET을 사용하는 경향이 있습니다.
- 예를 들어, myapp.root에 둥근 괄호 열기, 작은 따옴표, 슬래시, 작은 따옴표 닫기 둥근 괄호를 입력하십시오.
- 엔드포인트를 확인하려면 브라우저를 열고 포트 5000의 서버 출력 127.0.0.1에 표시되는 이 엔드포인트에 연결하면 웹 서버 애플리케이션에서 hello world라는 문자열이 반환되는 것을 볼 수 있습니다.
- 먼저 Flask를 가져와 웹 애플리케이션을 생성하고, 들어오는 요청을 처리하도록 요청하고, 정적 및 동적 HTML 페이지를 렌더링하기 위한 밑줄 템플릿을 렌더링합니다.
- 예를 들어 myapp은 Flask (둥근 괄호) 를 대문자 M과 같이 대문자 M과 같이 합니다.
- 이 작업을 수행하는 코드는 myapp 도트 루트 열린 둥근 대괄호 작은 따옴표 슬래시 샘플 작은 따옴표 닫기 둥근 대괄호입니다.
