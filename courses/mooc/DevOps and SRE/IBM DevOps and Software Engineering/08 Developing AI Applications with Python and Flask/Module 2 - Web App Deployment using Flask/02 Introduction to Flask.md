# Introduction to Flask

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/python-project-for-ai-application-development/lecture/zUc34/introduction-to-flask)

## 개요
- 플라스크의 주요 종속성을 설명하고 플라스크와 Django라는 다른 파이썬 웹 프레임워크 사이의 주요 차이점을 설명하세요.

## 내용
- 플라스크의 주요 종속성을 설명하고 플라스크와 Django라는 다른 파이썬 웹 프레임워크 사이의 주요 차이점을 설명하세요.
- Flask는 애플리케이션 로그에 표준 Python 로깅을 사용하며, 동일한 로거를 사용하여 애플리케이션에 대한 사용자 지정 메시지를 기록할 수 있습니다.
- Jinja 템플릿 프레임워크를 사용하여 동적 페이지를 개발할 수도 있으며, 이러한 동적 페이지는 각 요청마다 변경될 수 있는 정보를 표시하거나 사용자가 로그인했는지 확인할 수 있습니다.
- 다양한 HTTP 메서드에 대한 경로를 생성하고 애플리케이션에서 리디렉션을 제공할 수 있습니다.애플리케이션 수준에서 작동하는 글로벌 오류 처리기를 Flask에서 작성할 수 있습니다.
- 내장 종속성을 확인하기 위해 가상 환경에서 pip freeze 명령을 사용하면 모든 내장 패키지가 기본적으로 설치되는 것을 확인할 수 있습니다.
- 반면 Django에는 풀스택 애플리케이션을 만드는 데 필요한 모든 것이 포함되어 있습니다.
- Flask는 웹 사이트 구축을 위해 디버깅 서버, 라우팅, 템플릿, 오류 처리와 같은 기능을 제공합니다.커뮤니티 확장을 사용하여 Flask를 확장할 수 있습니다.
