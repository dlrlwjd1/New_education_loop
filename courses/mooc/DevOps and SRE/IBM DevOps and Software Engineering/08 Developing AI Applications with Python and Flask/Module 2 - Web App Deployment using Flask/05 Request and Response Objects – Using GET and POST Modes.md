# Request and Response Objects – Using GET and POST Modes

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/python-project-for-ai-application-development/lecture/dKTU1/request-and-response-objects-using-get-and-post-modes)

## 개요
- 이 비디오를 시청한 후에는 Flask 요청 객체를 설명하고 Flask 응답 객체를 설명할 수 있습니다.

## 내용
- 이 비디오를 시청한 후에는 Flask 요청 객체를 설명하고 Flask 응답 객체를 설명할 수 있습니다.
- 플라스크에 대한 모든 HTTP 호출에는 Flask.Request 클래스에서 생성된 요청 객체가 포함되어 있습니다.
- 튜플 호스트 포트 형태의 서버 주소, 요청과 함께 전송된 헤더, 요청에서 요청한 리소스인 URL 여러 번 전달되는 요청의 모든 IP 주소를 나열하는 AccessRoute.
- 요청에 JSON 데이터가 포함된 경우 isJSON은 참입니다.또한 쿠키 사전에는 요청과 함께 전송된 모든 쿠키가 포함됩니다.
- GET JSON 메서드를 사용하여 POST 요청에서 JSON으로 파싱된 데이터를 가져올 수도 있습니다.
- 이제 요청 객체의 모양과 요청 파라미터 및 본문에서 데이터를 가져오는 메서드에 대해 알아보았으니, 이 데이터에서 특정 값을 추출하는 방법을 살펴보겠습니다.
- Flask는 요청 객체를 제공하는 것처럼 응답 객체를 제공하며 응답 객체를 사용하여 사용자 지정 속성과 헤더를 클라이언트에 다시 보낼 수 있습니다.

## 예시
- Flask는 요청 객체를 제공하는 것처럼 응답 객체를 제공하며 응답 객체를 사용하여 사용자 지정 속성과 헤더를 클라이언트에 다시 보낼 수 있습니다.

## 요약
- 이제 요청 객체의 모양과 요청 파라미터 및 본문에서 데이터를 가져오는 메서드에 대해 알아보았으니, 이 데이터에서 특정 값을 추출하는 방법을 살펴보겠습니다. Flask는 요청 객체를 제공하는 것처럼 응답 객체를 제공하며 응답 객체를 사용하여 사용자 지정 속성과 헤더를 클라이언트에 다시 보낼 수 있습니다.
