# Application Development Lifecycle

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/python-project-for-ai-application-development/lecture/mWKhF/application-development-lifecycle)

## 개요
- 애플리케이션 개발 라이프사이클의 각 단계를 나열하고 애플리케이션 개발 라이프사이클의 여러 단계를 설명하고 여러 파일에 애플리케이션 코드를 작성하는 것이 얼마나 중요한지 생각해 보세요.

## 내용
- 애플리케이션 개발 라이프사이클의 각 단계를 나열하고 애플리케이션 개발 라이프사이클의 여러 단계를 설명하고 여러 파일에 애플리케이션 코드를 작성하는 것이 얼마나 중요한지 생각해 보세요.
- 애플리케이션 개발 수명 주기를 요구 사항 수집, 분석, 설계, 코드 및 테스트, 사용자 및 시스템 테스트, 생산 및 유지 관리의 7단계로 나눌 수 있습니다.
- 요구 사항 수집 단계에서는 사용자 요구 사항, 비즈니스 요구 사항, 기술 요구 사항 등 응용 프로그램의 모든 측면에 대한 요구 사항을 파악합니다.
- 분석 및 설계 중에 지정된 모든 요구 사항을 충족하는 모델 솔루션을 만들기 위해 여러 차례의 검증 및 수정이 필요할 수 있습니다.
- 코드 및 테스트 단계에서 팀은 설계 문서에 지정된 프로그래밍 요구 사항을 사용하여 코드가 문서화된 모든 요구 사항을 충족할 때까지 응용 프로그램을 코딩, 테스트, 수정 및 테스트합니다.
- 여기에는 요구 사항 수집, 애플리케이션에 대한 사용자, 비즈니스 및 기술 요구 사항 수집 , 요구 사항 분석, 요구 사항 분석, 전체 솔루션 설계 코드 및 테스트, 앱의 다양한 구성 요소 구축 및 테스트, 사용자 및 시스템 테스트, 사용자가 앱의 유용성을 테스트하는 단계, 시스템 통합 테스트 및 성능 테스트 수행 (애플리케이션이 제공되는 경우) 운영 단계가 포함됩니다.
- 에모든 최종 사용자 유지 관리: 사용자 또는 시스템 문제를 업그레이드하거나 수정하는 경우 효율적인 코딩을 위해 항상 중앙 프로그램을 사용하여 개별 파일 및 함수를 호출하여 다양한 작업을 수행합니다.

## 예시
- 이제 고객이 생성부터 고객 체크아웃까지 호텔 예약을 관리하는 웹 앱을 구축하기를 원하는 시나리오를 생각해 보십시오.

## 요약
- 여기에는 요구 사항 수집, 애플리케이션에 대한 사용자, 비즈니스 및 기술 요구 사항 수집 , 요구 사항 분석, 요구 사항 분석, 전체 솔루션 설계 코드 및 테스트, 앱의 다양한 구성 요소 구축 및 테스트, 사용자 및 시스템 테스트, 사용자가 앱의 유용성을 테스트하는 단계, 시스템 통합 테스트 및 성능 테스트 수행 (애플리케이션이 제공되는 경우) 운영 단계가 포함됩니다. 에모든 최종 사용자 유지 관리: 사용자 또는 시스템 문제를 업그레이드하거나 수정하는 경우 효율적인 코딩을 위해 항상 중앙 프로그램을 사용하여 개별 파일 및 함수를 호출하여 다양한 작업을 수행합니다.
