# Unit Testing

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/python-project-for-ai-application-development/lecture/PCCAF/unit-testing)

## 개요
- 단위 테스트 프로세스 설명 단위 테스트 구축 및 실행 단위 테스트의 출력 검토 단위 테스트는 코드 단위가 설계된 대로 작동하는지 확인하는 메서드입니다.

## 내용
- 단위 테스트 프로세스 설명 단위 테스트 구축 및 실행 단위 테스트의 출력 검토 단위 테스트는 코드 단위가 설계된 대로 작동하는지 확인하는 메서드입니다.
- 단위 테스트를 통과한 후에는 지속적 통합 지속적 전달 (CICD) 테스트 서버와 같은 서버 환경에서 장치를 테스트해야 합니다.
- 단위 테스트 프로세스를 개괄적으로 살펴본 후, 단위 테스트를 빌드하는 방법을 이해하기 위해 몇 가지 테스트 함수를 살펴보겠습니다.
- 예를 들어 TestMyModule이라는 클래스를 만들려면 클래스 테스트는 대문자로 T를 입력하고, my는 대문자 M을, 모듈은 대문자로 M을, 단위 테스트, 도트는 대문자로 입력하고, 테스트 케이스는 T와 C가 대문자로 입력됩니다.
- 예제에서 클래스 이름에 단위 이름 앞에 test 접두사가 붙은 것을 볼 수 있습니다.단위 클래스와 단위 테스트 클래스를 구분하는 데 도움이 되도록 클래스 이름 앞에 test 접두사를 붙이는 것이 좋은 이름 지정 규칙입니다.
- 예를 들어, 테스트 케이스는 단위 테스트 라이브러리의 테스트 케이스 클래스입니다.클래스를 상속하면 테스트 케이스 클래스의 기존 메서드를 활용할 수 있습니다.
- 예를 들어 TestMyModule 클래스에서 테스트 제곱과 테스트 더블러 두 함수는 mymodule 단위의 제곱 함수와 더블러 함수에 대응합니다.

## 예시
- 예를 들어 mymodule 단위에서 단위 테스트로 제곱과 더블러를 가져오려면 mymodule import square, doubler를 입력하세요.

## 요약
- 예를 들어, 테스트 케이스는 단위 테스트 라이브러리의 테스트 케이스 클래스입니다.클래스를 상속하면 테스트 케이스 클래스의 기존 메서드를 활용할 수 있습니다. 예를 들어 TestMyModule 클래스에서 테스트 제곱과 테스트 더블러 두 함수는 mymodule 단위의 제곱 함수와 더블러 함수에 대응합니다.
