# Python Style Guide and Coding Practices

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/python-project-for-ai-application-development/lecture/S1hBj/python-style-guide-and-coding-practices)

## 개요
- 이 문서는 파이썬 코드를 읽기 쉽고 일관되게 포맷하기 위한 규칙과 지침을 제공합니다.먼저 코드의 가독성을 개선하기 위한 주요 지침부터 살펴보겠습니다.

## 내용
- 이 문서는 파이썬 코드를 읽기 쉽고 일관되게 포맷하기 위한 규칙과 지침을 제공합니다.먼저 코드의 가독성을 개선하기 위한 주요 지침부터 살펴보겠습니다.
- 예를 들어 한 편집자는 탭을 세 개의 공백으로 해석하고 다른 편집자는 탭을 네 개의 공백으로 해석할 수 있습니다.
- PEP-8 지침을 따르지 않는 왼쪽 블록에서는 함수 1이 끝나는 지점과 클래스 UserClass, 대문자 U, 대문자 C (대문자 C) 사이에는 공백이 없습니다.
- 그러나 함수 밑줄 하나가 두 개의 매개 변수 A와 B가 있는 def 함수 밑줄 1로 작성된 것을 발견하면 쉽게 호출할 수 있습니다.
- 예를 들어 함수 이름을 대문자 S가 있는 컴포지션 표면, 대문자 R의 방사선으로 쓰는 대신 comp 밑줄 표면 밑줄 방사선으로 쓰십시오.
- 예를 들어, 양고기 밑줄 다람쥐 밑줄 케이지 클래스를 작성하는 대신 클래스 이름을 양고기 다람쥐 케이지로 지정하는 것이 가장 좋습니다.
- 정적 코드 분석 방법을 사용하면 코드를 실행하지 않고도 사전 정의된 스타일 및 표준에 따라 코드를 평가할 수 있습니다.

## 예시
- Python 스타일 가이드 및 코딩 실습에 오신 것을 환영합니다.

## 요약
- 예를 들어, 양고기 밑줄 다람쥐 밑줄 케이지 클래스를 작성하는 대신 클래스 이름을 양고기 다람쥐 케이지로 지정하는 것이 가장 좋습니다. 정적 코드 분석 방법을 사용하면 코드를 실행하지 않고도 사전 정의된 스타일 및 표준에 따라 코드를 평가할 수 있습니다.
