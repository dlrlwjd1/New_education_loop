# Demo - Working with an IDE

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/python-project-for-ai-application-development/lecture/i6zrI/demo-working-with-an-ide)

## 개요
- Cloud IDE는 개인용 장치에 소프트웨어나 도구를 설치하거나 구성할 필요 없이 브라우저에서 직접 코드를 작성, 실행, 디버깅 및 실행하는 데 사용할 수 있는 학습용 프로그래밍 환경입니다.

## 내용
- Cloud IDE는 개인용 장치에 소프트웨어나 도구를 설치하거나 구성할 필요 없이 브라우저에서 직접 코드를 작성, 실행, 디버깅 및 실행하는 데 사용할 수 있는 학습용 프로그래밍 환경입니다.
- Cloud IDE의 다양한 구성 요소 살펴보기 Python 패키지 또는 라이브러리 설치 코드 작성 코드 실행 Cloud IDE를 열면 두 개의 기본 창이 표시됩니다.
- 하지만 자주 사용하는 두 개의 탭에는 코드를 작성하는 편집기 탭과 코드를 실행하는 터미널 탭이 있습니다.
- 프로그래밍 창에는 Skills Network Toolbox도 있어 다양한 데이터베이스 관리 환경, 빅데이터 도구, 클라우드 도구, 내장된 AI 라이브러리를 사용하고 빌드한 애플리케이션을 실행할 수 있습니다.
- 편집기 탭에서 수동으로 코드를 입력하거나 지침 창 (있는 경우) 의 코드를 복사하여 파일에 붙여넣을 수 있습니다.
- 프로그래밍 창에는 코드를 작성할 수 있는 편집기 탭과 코드를 실행할 수 있는 터미널 탭이 있습니다.
- 실습을 진행하는 동안 언제든지 명령 창에서 코드 블록을 복사하여 편집기 또는 터미널 탭에 붙여넣을 수 있습니다.

## 예시
- IBM Skills Network 팀에서 제공하는 클라우드 IDE (또는 통합 개발 환경) 의 데모에 오신 것을 환영합니다.

## 요약
- 프로그래밍 창에는 코드를 작성할 수 있는 편집기 탭과 코드를 실행할 수 있는 터미널 탭이 있습니다. 실습을 진행하는 동안 언제든지 명령 창에서 코드 블록을 복사하여 편집기 또는 터미널 탭에 붙여넣을 수 있습니다.
