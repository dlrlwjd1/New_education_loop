# Introduction to Web Applications and APIs

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/python-project-for-ai-application-development/lecture/KgsLc/introduction-to-web-applications-and-apis)

## 개요
- 웹 애플리케이션 또는 웹 앱에 대해 설명하기 API (애플리케이션 프로그래밍 인터페이스) 에 대해 설명하기 웹 앱과 API를 비교하고 대조해 보겠습니다.

## 내용
- 웹 애플리케이션 또는 웹 앱에 대해 설명하기 API (애플리케이션 프로그래밍 인터페이스) 에 대해 설명하기 웹 앱과 API를 비교하고 대조해 보겠습니다.
- 일부 앱은 사용 중인 브라우저의 종류에 따라 달라질 수 있지만 대부분의 웹 앱은 모든 최신 웹 브라우저에서 작동합니다.
- 소프트웨어 개발자가 API를 만들 때 따르는 아키텍처는 여러 가지가 있지만 가장 많이 사용되는 아키텍처는 표현적 상태 전송 (REST) 또는 단순 객체 액세스 프로토콜 (SOAP) 입니다.
- 브라우저에서 전자 상거래 쇼핑 서비스에 액세스할 때 브라우저는 웹 앱에 연결하는 API 역할을 합니다.
- 모바일 장치를 사용하여 전자 상거래 쇼핑 서비스에 액세스하려고 하면 장치의 앱이 전자 상거래 쇼핑 서비스에 연결하는 API 역할을 합니다.
- 모든 웹 앱의 특성은 다른 앱과 데이터를 공유하는 것이며, 기본적으로 모든 웹 앱을 API로 간주할 수 있습니다.
- 애플리케이션 프로그래밍 인터페이스 (API) 는 연결되지 않은 두 앱이 통신할 수 있도록 하는 소프트웨어 구성 요소입니다.

## 예시
- 예를 들어 휴대폰의 앱에서는 위치, 카메라, 오디오, 녹음기 등 휴대폰의 다양한 기능에 대한 권한을 부여해야 합니다.

## 요약
- 모든 웹 앱의 특성은 다른 앱과 데이터를 공유하는 것이며, 기본적으로 모든 웹 앱을 API로 간주할 수 있습니다. 애플리케이션 프로그래밍 인터페이스 (API) 는 연결되지 않은 두 앱이 통신할 수 있도록 하는 소프트웨어 구성 요소입니다.
