# Introduction to the Course

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/python-project-for-ai-application-development/lecture/XE8yU/introduction-to-the-course)

## 개요
- 파이썬은 전 세계적으로 널리 사용되는 프로그래밍 언어 중 상위 10위 안에 드는 언어입니다, 전 세계에서 가장 널리 사용되는 프로그래밍 언어 중 하나입니다.

## 내용
- 파이썬은 전 세계적으로 널리 사용되는 프로그래밍 언어 중 상위 10위 안에 드는 언어입니다, 전 세계에서 가장 널리 사용되는 프로그래밍 언어 중 하나입니다.
- 프로그래머는 Python과 Flask를 사용하여 간결한 애플리케이션을 개발할 수 있습니다, 심지어 AI의 구성 요소를 통합할 수 있으며 확장 가능한 솔루션의 일부가 될 수도 있습니다.
- Python 모듈을 만들고, 단위 테스트를 실행하고, 애플리케이션을 패키징할 수 있습니다.
- 그리고 IBM 왓슨 임베디드 AI를 사용해 AI 기반 애플리케이션을 만들고 웹 서버에 AI 기반 애플리케이션을 생성하고 배포합니다.
- 이 과정은 기본적인 프로그래밍 지식이 있는 사람을 대상으로 합니다, python에 대한 기본적인 이해가 있고 aI 통합으로 재사용 가능한 웹 애플리케이션을 구축하는 데 관심이 있는 분을 대상으로 합니다.
- 마지막으로 모듈 3에서는 이전 모듈에서 배운 모든 지식을 적용하여 이전 모듈에서 배운 모든 지식을 적용하여 기능적인 웹 애플리케이션을 개발하고 및 왓슨 임베디드 AI 라이브러리를 사용한 AI 기반 웹 애플리케이션을 개발할 수 있습니다.
- 하나의 실습 프로젝트와 채점된 프로젝트를 통해 다음을 입증할 수 있습니다 flask를 사용하여 애플리케이션을 만들고 배포하는 데 능숙함을 입증할 수 있습니다.

## 예시
- 모듈 1에서는 애플리케이션 개발의 기본을 소개합니다, 코딩의 라이프사이클과 모범 사례를 포함한 애플리케이션 개발의 기본 사항을 소개합니다.
