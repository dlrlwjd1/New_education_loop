## 개요
- Python 모듈, 패키지, 라이브러리 구별하기 Python 패키지 만들기 Python 패키지 확인하기 Python 패키지 사용하기 모듈, 패키지, 라이브러리는 Python에서 자주 사용되는 용어입니다.<각 용어에 대해 자세히 살펴봅시다.

## 내용
- Python 모듈, 패키지, 라이브러리 구별하기 Python 패키지 만들기 Python 패키지 확인하기 Python 패키지 사용하기 모듈, 패키지, 라이브러리는 Python에서 자주 사용되는 용어입니다.<각 용어에 대해 자세히 살펴봅시다.
- 첫 번째 함수는 def square number 반환 번호 별표 별표 2, 입력을 제곱하여 결과를 출력으로 반환하는 함수입니다.
- 두 번째 함수는 def doubler number 반환 번호 별표 별표 2, 입력을 두 배로 하여 결과를 출력으로 반환하는 함수입니다.
- 함수가 같은 디렉터리에 있으면 해당 모듈에 있는 함수를 가져와서 사용할 수 있습니다.
- 패키지 테스트를 위한 일반적인 구조는 패키지 이름, .module 이름, .함수 이름, 뒤에 중괄호를 빼고 둥근 괄호를 유지한 매개변수입니다.
- 패키지를 만든 후 패키지 폴더가 같은 디렉터리에 있는 경우 다른 스크립트에서 사용할 수 있습니다.
- 패키지를 생성한 후 패키지 폴더가 같은 디렉터리에 있으면 다른 스크립트에서 패키지를 사용할 수 있습니다.

## 예시
- 예를 들어 두 개의 함수가 있는 module.py라는 모듈을 생각해 봅시다.

## 요약
- 패키지를 만든 후 패키지 폴더가 같은 디렉터리에 있는 경우 다른 스크립트에서 사용할 수 있습니다. 패키지를 생성한 후 패키지 폴더가 같은 디렉터리에 있으면 다른 스크립트에서 패키지를 사용할 수 있습니다.
