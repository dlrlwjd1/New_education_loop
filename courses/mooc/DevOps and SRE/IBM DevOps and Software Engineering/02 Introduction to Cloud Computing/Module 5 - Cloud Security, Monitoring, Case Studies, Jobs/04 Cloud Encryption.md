# Cloud Encryption

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/introduction-to-cloud/lecture/1cCaQ/cloud-encryption)

## 개요
- [음악] 특히 퍼블릭 클라우드 환경에서 데이터 보안 및 개인 정보 보호에 대한 우려를 감안할 때 암호화는 중요한 역할을 하며 계층형 보안 모델에서 최후의 방어선이라고도 합니다.

## 내용
- [음악] 특히 퍼블릭 클라우드 환경에서 데이터 보안 및 개인 정보 보호에 대한 우려를 감안할 때 암호화는 중요한 역할을 하며 계층형 보안 모델에서 최후의 방어선이라고도 합니다.
- 애플리케이션 및 비즈니스 요구 사항에 따라 블록 및 파일 스토리지의 암호화, 내장된 객체 스토리지 내 암호화, 데이터베이스 암호화 서비스 등 저장 데이터를 암호화하는 다양한 옵션이 있을 수 있습니다.
- 전송 중 암호화는 데이터가 한 위치에서 다른 위치로 전송되는 동안 데이터를 보호합니다.전송 중 암호화에는 전송 전 데이터 암호화, 엔드포인트 인증, 도착 시 데이터 암호 해독 및 확인이 포함됩니다.
- 서버 측 암호화의 경우 고객이 제공한 암호화 키라고 하는 자체 암호화 키를 생성 및 관리하거나 클라우드 스토리지 공급자가 제공하는 고객 관리 암호화 키라고 하는 키 관리 서비스를 사용하여 암호화 키를 생성 및 관리할 수 있습니다.
- 일부 클라우드 제공업체는 데이터 액세스 관리, 통합 키 관리, 정교한 암호화와 같은 다양한 기능을 갖춘 멀티클라우드 데이터 암호화 서비스를 제공합니다.
- 멀티클라우드 데이터 암호화 콘솔을 사용하면 액세스 정책을 정의 및 관리하고, 암호화 키를 생성, 교체 및 관리하고, 액세스 로그를 집계할 수 있습니다.
- 일부 클라우드 공급자가 제공하는 키 관리 서비스는 클라우드 서비스 또는 고객 구축 애플리케이션에 사용되는 암호화 키의 수명 주기 관리를 수행하는 데 도움이 됩니다.

## 예시
- 일부 클라우드 공급자가 제공하는 키 관리 서비스는 클라우드 서비스 또는 고객 구축 애플리케이션에 사용되는 암호화 키의 수명 주기 관리를 수행하는 데 도움이 됩니다.

## 요약
- 멀티클라우드 데이터 암호화 콘솔을 사용하면 액세스 정책을 정의 및 관리하고, 암호화 키를 생성, 교체 및 관리하고, 액세스 로그를 집계할 수 있습니다. 일부 클라우드 공급자가 제공하는 키 관리 서비스는 클라우드 서비스 또는 고객 구축 애플리케이션에 사용되는 암호화 키의 수명 주기 관리를 수행하는 데 도움이 됩니다.
