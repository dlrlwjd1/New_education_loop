# What is Cloud Security - Part 1

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/introduction-to-cloud/lecture/mhiwp/what-is-cloud-security-part-1)

## 개요
- 클라우드 기반 기술을 안전하게 사용하지 않으면 조직은 비즈니스 보안에 위험을 초래할 수 있는 외부 위협에 노출될 수 있습니다.

## 내용
- 클라우드 기반 기술을 안전하게 사용하지 않으면 조직은 비즈니스 보안에 위험을 초래할 수 있는 외부 위협에 노출될 수 있습니다.
- 서비스형 인프라 (IaaS), 서비스형 플랫폼 (PaaS), 서비스형 소프트웨어 (SaaS) 컴퓨팅 모델 등이 그 예입니다.
- 타사 클라우드 컴퓨팅 공급자가 보안 모범 사례를 따르고 서버의 무결성을 보장하지만 데이터 자산 관리는 여전히 이러한 서비스를 이용하는 조직의 책임입니다.
- 이러한 위협은 클라우드 전반의 데이터 이동 및 액세스에 대한 투명성이 부족하기 때문에 클라우드 컴퓨팅 공급자를 대상으로 합니다.
- 비즈니스 연속성과 보안을 보장하려면 사설, 공용, 하이브리드 등 모든 클라우드 환경에서 적절한 클라우드 보안 솔루션을 갖추어야 합니다.
- 동일한 클라우드 컴퓨팅 공급자가 여러 클라이언트 인프라를 호스팅할 수 있습니다.다른 비즈니스를 대상으로 삼을 때 악의적인 공격자가 서비스를 손상시킬 수 있습니다.
- PaaS에서는 공급자가 OS, 사용자 구독 및 로그인 자격 증명을 포함한 플랫폼을 보호하지만 플랫폼에서 생성되는 모든 코드나 데이터 또는 기타 콘텐츠의 보안에 대한 책임은 사용자에게 있습니다.

## 예시
- 타사 클라우드 컴퓨팅 공급자가 보안 모범 사례를 따르고 서버의 무결성을 보장하지만 데이터 자산 관리는 여전히 이러한 서비스를 이용하는 조직의 책임입니다.

## 요약
- 동일한 클라우드 컴퓨팅 공급자가 여러 클라이언트 인프라를 호스팅할 수 있습니다.다른 비즈니스를 대상으로 삼을 때 악의적인 공격자가 서비스를 손상시킬 수 있습니다. PaaS에서는 공급자가 OS, 사용자 구독 및 로그인 자격 증명을 포함한 플랫폼을 보호하지만 플랫폼에서 생성되는 모든 코드나 데이터 또는 기타 콘텐츠의 보안에 대한 책임은 사용자에게 있습니다.
