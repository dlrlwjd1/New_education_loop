# Expert Viewpoints - Components of Cloud Computing

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/introduction-to-cloud/lecture/b1RTn/expert-viewpoints-components-of-cloud-computing)

## 개요
- 이 비디오에서는 여러 클라우드 애플리케이션 전문가들이 클라우드의 컴퓨팅 리소스를 결정할 때 고려되는 몇 가지 요소에 대해 논의하는 것을 들어보겠습니다.

## 내용
- 이 비디오에서는 여러 클라우드 애플리케이션 전문가들이 클라우드의 컴퓨팅 리소스를 결정할 때 고려되는 몇 가지 요소에 대해 논의하는 것을 들어보겠습니다.
- 컨테이너 가상 서버와 베어메탈 서버 중 하나를 선택할 때는 확장성과 비용 효율성 때문에 컨테이너를 먼저 선택하는 경우가 거의 대부분입니다.
- 예를 들어 보안상의 이유로 다른 고객의 VM과 동일한 VM에서 컨테이너를 실행하는 것을 허용하지 않을 수 있습니다.
- 아니면 지속적으로 가능한 최고의 성능이 필요한데 하이퍼바이저로 인한 부담이나 주변 환경의 소음으로 인한 영향을 감당하고 싶지 않을 수도 있습니다.
- 가상 시스템의 경우 컨테이너를 몇 초가 아닌 밀리초 단위로 매우 빠르게 스핀업할 수도 있습니다.
- 일부 클라우드 제공업체에서는 밀리초 단위로만 사용료를 부과하고 서버리스 기능을 사용하면 운영 체제 패치와 같은 작업에 시간을 할애하지 않아도 되기 때문입니다.
- 클라우드에 구애받지 않고 하이브리드 클라우드 설정, 즉 동시에 다른 클라우드 제공업체를 사용하려는 경우 Docker는 어디서나 동일하게 실행되므로 컨테이너를 선택하는 것이 좋습니다.

## 예시
- 예를 들어 보안상의 이유로 다른 고객의 VM과 동일한 VM에서 컨테이너를 실행하는 것을 허용하지 않을 수 있습니다.

## 요약
- 일부 클라우드 제공업체에서는 밀리초 단위로만 사용료를 부과하고 서버리스 기능을 사용하면 운영 체제 패치와 같은 작업에 시간을 할애하지 않아도 되기 때문입니다. 클라우드에 구애받지 않고 하이브리드 클라우드 설정, 즉 동시에 다른 클라우드 제공업체를 사용하려는 경우 Docker는 어디서나 동일하게 실행되므로 컨테이너를 선택하는 것이 좋습니다.
