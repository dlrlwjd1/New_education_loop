# Basics of Storage on Cloud

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/introduction-to-cloud/lecture/kGmOP/basics-of-storage-on-cloud)

## 개요
- 특정 스토리지는 컴퓨팅 노드에 연결해야 스토리지에 액세스할 수 있지만, 다른 스토리지 유형은 공용 인터넷 또는 전용 사설망 연결을 통해 직접 액세스할 수 있습니다.

## 내용
- 특정 스토리지는 컴퓨팅 노드에 연결해야 스토리지에 액세스할 수 있지만, 다른 스토리지 유형은 공용 인터넷 또는 전용 사설망 연결을 통해 직접 액세스할 수 있습니다.
- 클라우드 스토리지는 직접 연결, 파일 스토리지, 블록 스토리지, 오브젝트 스토리지의 네 가지 주요 유형으로 제공됩니다.
- '로컬 스토리지'라고도 하는 직접 연결 스토리지는 클라우드 기반 서버에 직접 제공되는 스토리지로서 호스트 서버 섀시 또는 동일한 랙 내에 위치합니다.
- 직접 연결 스토리지가 운영 체제를 저장하는 것 외에 다른 용도에 적합하지 않은 주된 두 가지 이유는 일반적으로 '일시적' ( 즉 , 연결된 컴퓨팅 리소스에서만 지속되는 기간) 이기 때문입니다.
- NFS 장착 스토리지는 일반적이지만 데이터가 이더넷 네트워크를 통해 이동하기 때문에 직접 연결 스토리지나 블록 스토리지보다 속도가 느린 경향이 있습니다.
- 클라우드에 데이터를 백업하는 방법은 여러 가지가 있지만 파일 스토리지와 블록 스토리지를 모두 백업하는 한 가지 방법은 특정 순간의 스토리지 이미지인 스냅샷을 찍는 것입니다.
- 특정 스토리지 용량을 프로비저닝하고 시간이 지나면서 용량이 가득 차는 파일 및 블록 스토리지와 달리, 오브젝트 스토리지는 파일을 계속 추가할 수 있고 용량이 절대 차지 않기 때문에 사용한 만큼만 비용을 지불하면 됩니다.

## 예시
- 이 스토리지는 속도가 빠르며 일반적으로 서버의 운영 체제를 저장하는 용도로만 사용되지만 다른 사용 사례도 있을 수 있습니다.

## 요약
- 클라우드에 데이터를 백업하는 방법은 여러 가지가 있지만 파일 스토리지와 블록 스토리지를 모두 백업하는 한 가지 방법은 특정 순간의 스토리지 이미지인 스냅샷을 찍는 것입니다. 특정 스토리지 용량을 프로비저닝하고 시간이 지나면서 용량이 가득 차는 파일 및 블록 스토리지와 달리, 오브젝트 스토리지는 파일을 계속 추가할 수 있고 용량이 절대 차지 않기 때문에 사용한 만큼만 비용을 지불하면 됩니다.
