# CDN - Content Delivery Networks

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/introduction-to-cloud/lecture/uRvMZ/cdn-content-delivery-networks)

## 개요
- CDN (콘텐츠 전송 네트워크) 은 사용자의 지리적 위치에 따라 일시적으로 저장되거나 캐시된 웹사이트 콘텐츠 사본을 사용자에게 전송하는 분산 서버 네트워크입니다.

## 내용
- CDN (콘텐츠 전송 네트워크) 은 사용자의 지리적 위치에 따라 일시적으로 저장되거나 캐시된 웹사이트 콘텐츠 사본을 사용자에게 전송하는 분산 서버 네트워크입니다.
- 간단히 말해서 콘텐츠 전송 네트워크, 즉 CDN (콘텐츠 전송 네트워크) 은 인터넷 콘텐츠 전송을 가속화하는 서비스입니다.
- 이를 달성하는 방법과 기타 이점에 대해 설명하기 전에 먼저 전 세계에 사용자가 있지만 전 세계에 서버가 없는 상황에서 발생하는 몇 가지 문제와 이러한 역동성으로 인해 사용자가 경험하게 되는 경험에 대해 설명하고자 합니다.
- 이제 시드니, 런던, 뉴욕, LA에 있는 사용자가 일부 콘텐츠에 액세스하려고 하면 먼저 콘텐츠 전송 네트워크 서비스를 통해 해당 콘텐츠를 검색한 다음 전 세계로 배포합니다.
- 이제 런던에 있는 사용자들은 댈러스로 가는 대신 가장 가까운 지리적 위치에서 직접 콘텐츠를 검색할 수 있게 되어 해당 콘텐츠를 검색하는 데 걸리는 시간이 크게 단축되었습니다.
- 따라서 간접적인 이점은 댈러스에서 이러한 모든 사용자에게 서비스를 제공하는 데 필요한 부하가 감소하거나 용량이 감소한다는 것입니다.
- 왜냐하면 이 모든 사용자들이 여행을 해야 하기 때문입니다.게다가 멀리 있는 사용자들과 소통할 필요도 없고요.댈러스 환경에서도 가동 시간이 증가할 수 있습니다.마지막으로, 사용자가 댈러스에 있는 서버와 직접 통신하지 않기 때문에 모호성을 통해 보안을 강화하는 간접적인 이점을 얻을 수 있습니다.
