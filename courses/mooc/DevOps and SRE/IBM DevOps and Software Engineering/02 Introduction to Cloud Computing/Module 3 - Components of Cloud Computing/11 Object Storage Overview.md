# Object Storage Overview

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/introduction-to-cloud/lecture/GxiTE/object-storage-overview)

## 개요
- 이 비디오에서는 오브젝트 스토리지가 무엇인지, 데이터가 오브젝트 스토리지에 어떻게 저장되는지, 파일 및 블록 스토리지와 같은 기존 스토리지 유형과 어떻게 다른지 이해하기 시작할 것입니다.오브젝트 스토리지에 대해 가장 먼저 알아두어야 할 점은 오브젝트 스토리지를 사용하기 위해 특정 컴퓨팅 노드에 연결하지 않는다는 것입니다.

## 내용
- 이 비디오에서는 오브젝트 스토리지가 무엇인지, 데이터가 오브젝트 스토리지에 어떻게 저장되는지, 파일 및 블록 스토리지와 같은 기존 스토리지 유형과 어떻게 다른지 이해하기 시작할 것입니다.오브젝트 스토리지에 대해 가장 먼저 알아두어야 할 점은 오브젝트 스토리지를 사용하기 위해 특정 컴퓨팅 노드에 연결하지 않는다는 것입니다.
- 즉, API를 호출할 수 있는 모든 것과 함께 오브젝트 스토리지를 직접 사용할 수 있으며 기본 컴퓨팅 노드가 필요하지 않습니다.
- 오브젝트 스토리지에 대해 두 번째로 주목해야 할 점은 다른 클라우드 스토리지 옵션보다 저렴하다는 것입니다.
- 그런 다음 같은 지역의 여러 데이터 센터나 영역, 심지어 여러 지역에 데이터가 여러 번 저장되는 여러 지역에 걸쳐 가용성이 높은 버킷을 제공할 것입니다.
- 이 데이터는 텍스트 파일부터 오디오 파일, 비디오 파일, IoT 데이터부터 가상 시스템 이미지까지 백업 파일에서 데이터 아카이브에 이르는 모든 것이 될 수 있습니다.
- 그러나 오브젝트 스토리지는 운영 체제나 데이터베이스 같은 애플리케이션 또는 파일 내용이 변경되는 기타 애플리케이션을 실행하는 데 적합하지 않습니다.
- 오브젝트 스토리지를 사용하여 저장할 수 있는 데이터는 텍스트 파일에서 오디오 및 비디오 파일, IoT 데이터에서 가상 머신 이미지, 백업 파일에서 데이터 아카이브에 이르기까지 모든 것이 될 수 있습니다.

## 예시
- 예를 들어 복원력이 뛰어난 버킷을 제공하지만 데이터는 하나의 데이터 센터에만 저장됩니다.

## 요약
- 그러나 오브젝트 스토리지는 운영 체제나 데이터베이스 같은 애플리케이션 또는 파일 내용이 변경되는 기타 애플리케이션을 실행하는 데 적합하지 않습니다. 오브젝트 스토리지를 사용하여 저장할 수 있는 데이터는 텍스트 파일에서 오디오 및 비디오 파일, IoT 데이터에서 가상 머신 이미지, 백업 파일에서 데이터 아카이브에 이르기까지 모든 것이 될 수 있습니다.
