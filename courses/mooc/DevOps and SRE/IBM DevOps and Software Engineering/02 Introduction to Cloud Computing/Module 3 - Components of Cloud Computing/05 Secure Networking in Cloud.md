# Secure Networking in Cloud

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/introduction-to-cloud/lecture/ghYQp/secure-networking-in-cloud)

## 개요
- [음악] 클라우드 환경이 점점 더 많이 채택되고 디지털 데이터로 인해 사이버 보안 위협이 급격히 증가함에 따라 클라우드에 보안 네트워크를 구축하는 것이 중요합니다.

## 내용
- [음악] 클라우드 환경이 점점 더 많이 채택되고 디지털 데이터로 인해 사이버 보안 위협이 급격히 증가함에 따라 클라우드에 보안 네트워크를 구축하는 것이 중요합니다.
- 클라우드에서 네트워크를 만들려면 먼저 네트워크 크기 또는 경계 또는 클라우드 네트워크를 설정하는 IP 주소 범위를 정의해야 합니다.
- 클라우드 네트워크는 가상, 사설 클라우드 또는 VPC와 같은 옵션을 사용하여 논리적으로 분리된 네트워크 세그먼트인 네트워킹 공간에 배포되며, 이러한 옵션은 서브넷이라는 더 작은 세그먼트로 나눌 수 있습니다.
- 이 경우 웹 기반 VSI는 하나의 보안 그룹에, 애플리케이션 VSI는 두 번째 보안 그룹에, 데이터베이스 VSI는 세 번째 보안 그룹에 배치합니다.
- 퍼블릭 게이트웨이는 인터넷으로 클라우드에 액세스하는 데 유용하지만, 기업은 가상 사설망 또는 VPN을 사용하여 리소스를 안전하게 연결하여 자체 온프레미스 리소스를 클라우드로 확장하는 데 관심이 있습니다.
- 하이브리드 클라우드 환경을 갖춘 기업은 클라우드와 온프레미스 리소스 간에 전용 고속 연결을 사용하는 것이 공용 연결 솔루션보다 더 안전하고 효율적인 방법이라는 것을 알게 되었습니다.필요에 따라 온프레미스 리소스를 클라우드로 확장할 수 있는 IBM Cloud 및 Direct Link 솔루션 등 일부 클라우드 서비스 제공업체는 이러한 연결을 제공합니다.
- 클라우드 네트워크를 구축하려면 모든 IT 전문가가 환경을 보호하고 고성능 비즈니스 애플리케이션을 보장하기 위해 의존하는 데이터 센터 네트워크와 유사한 네트워킹 기능을 제공하는 일련의 논리적 구조를 만들어야 합니다.

## 예시
- 예를 들어 네트워크 인터페이스 컨트롤러 또는 NIC는 클라우드 환경에서 vNIC로 표시됩니다.

## 요약
- 하이브리드 클라우드 환경을 갖춘 기업은 클라우드와 온프레미스 리소스 간에 전용 고속 연결을 사용하는 것이 공용 연결 솔루션보다 더 안전하고 효율적인 방법이라는 것을 알게 되었습니다.필요에 따라 온프레미스 리소스를 클라우드로 확장할 수 있는 IBM Cloud 및 Direct Link 솔루션 등 일부 클라우드 서비스 제공업체는 이러한 연결을 제공합니다. 클라우드 네트워크를 구축하려면 모든 IT 전문가가 환경을 보호하고 고성능 비즈니스 애플리케이션을 보장하기 위해 의존하는 데이터 센터 네트워크와 유사한 네트워킹 기능을 제공하는 일련의 논리적 구조를 만들어야 합니다.
