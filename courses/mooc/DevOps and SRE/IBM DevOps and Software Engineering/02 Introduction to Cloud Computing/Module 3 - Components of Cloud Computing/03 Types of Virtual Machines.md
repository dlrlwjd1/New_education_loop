# Types of Virtual Machines

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/introduction-to-cloud/lecture/1ZIyL/types-of-virtual-machines)

## 개요
- (음악) 가상 머신 또는 VM은 클라우드 공급자에 따라 가상 서버 또는 가상 인스턴스 또는 간단히 인스턴스라고도 합니다.

## 내용
- (음악) 가상 머신 또는 VM은 클라우드 공급자에 따라 가상 서버 또는 가상 인스턴스 또는 간단히 인스턴스라고도 합니다.
- 클라우드에서 가상 서버를 생성할 때 서버를 프로비전할 지역, 영역 또는 데이터 센터와 해당 서버에 원하는 운영 체제를 지정합니다.
- 공유 또는 공용 클라우드 VM은 사전 정의된 크기로 온디맨드로 프로비저닝할 수 있는 공급자가 관리하는 멀티테넌트 배포입니다.
- 다양한 워크로드를 충족하기 위해 클라우드 공급자는 단일 가상 코어 및 소량의 RAM에서 다중 가상 코어 및 훨씬 더 큰 용량의 RAM에 이르는 사전 정의된 크기 및 구성을 제공합니다.
- 일부 공급자는 사전 정의된 크기만 선택하는 대신 사용자가 코어 수, RAM 및 로컬 스토리지 특성을 정의할 수 있는 사용자 지정 구성도 제공합니다.
- 원하는 만큼의 가상 서버 용량을 예약하고, 필요할 때 해당 용량에서 인스턴스를 프로비저닝하고, 예약된 용량에 대해 1년 또는 3년 등의 기간을 선택합니다.
- 예약된 용량을 초과할 경우 언제든지 시간별 또는 월별 VM으로 계획되지 않은 사용량 및 용량 요구 사항을 보완할 수 있습니다.

## 예시
- 다양한 클라우드 제공업체는 VM을 다양한 구성 및 배포 옵션으로 제공하여 다양한 사용 사례를 지원합니다.

## 요약
- 원하는 만큼의 가상 서버 용량을 예약하고, 필요할 때 해당 용량에서 인스턴스를 프로비저닝하고, 예약된 용량에 대해 1년 또는 3년 등의 기간을 선택합니다. 예약된 용량을 초과할 경우 언제든지 시간별 또는 월별 VM으로 계획되지 않은 사용량 및 용량 요구 사항을 보완할 수 있습니다.
