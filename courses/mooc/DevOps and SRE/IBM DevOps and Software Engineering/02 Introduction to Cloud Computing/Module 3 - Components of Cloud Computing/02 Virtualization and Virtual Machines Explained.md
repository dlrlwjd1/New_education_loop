# Virtualization and Virtual Machines Explained

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/introduction-to-cloud/lecture/znoex/virtualization-and-virtual-machines-explained)

## 개요
- 간단히 말해 가상화는 컴퓨팅, 스토리지, 네트워킹, 서버, 애플리케이션 등 어떤 것의 소프트웨어 기반 또는 가상 버전을 만드는 프로세스이며 가상화를 가능하게 하는 것을 하이퍼바이저라고 합니다.

## 내용
- 간단히 말해 가상화는 컴퓨팅, 스토리지, 네트워킹, 서버, 애플리케이션 등 어떤 것의 소프트웨어 기반 또는 가상 버전을 만드는 프로세스이며 가상화를 가능하게 하는 것을 하이퍼바이저라고 합니다.
- 다른 유형의 하이퍼바이저는 여기 있는 유형 2 하이퍼바이저입니다.이 둘이 다른 점은 물리적 서버와 하이퍼바이저 사이에 호스트 OS 계층이 있다는 점입니다.
- 실제 컴퓨터처럼 실행됩니다.운영 체제와 애플리케이션이 있고 서로 완전히 독립적이지만 하이퍼바이저에서 여러 개를 실행할 수 있으며 하이퍼바이저는 물리적 서버에서 이러한 가상 환경에 할당된 리소스를 관리합니다.
- 가상 머신을 한 하이퍼바이저에서 완전히 다른 머신의 다른 하이퍼바이저로 거의 즉각적으로 이동할 수 있어 환경 내에서 유연성이 뛰어나고 이동성이 뛰어납니다.이 모든 것을 살펴보면, 이것이 프로세스로서의 핵심 가상화입니다.
- 이러한 점을 생각해 보고 하나의 인프라에서 여러 가상 환경을 실행할 수 있다는 사실을 고려하면 물리적 인프라 풋프린트를 크게 줄일 수 있다는 뜻입니다.
- 이것이 바로 통합이며, 거의 많은 서버를 유지 관리할 필요가 없고, 전기를 많이 가동하고, 유지 관리 비용을 절감할 수 있다는 사실은 결국 수익을 절감할 수 있다는 것을 의미합니다.
- 이 호스트가 예기치 않게 종료된다고 가정해 보겠습니다.다른 물리적 서버의 한 하이퍼바이저에서 다른 하이퍼바이저로 가상 시스템을 이동할 수 있다는 것은 훌륭한 백업 계획을 갖추고 있다는 뜻이죠?

## 예시
- 예를 들어 여기서는 Windows를, 여기서는 Linux를, 여기서는 UNIX를 실행할 수 있습니다.

## 요약
- 이것이 바로 통합이며, 거의 많은 서버를 유지 관리할 필요가 없고, 전기를 많이 가동하고, 유지 관리 비용을 절감할 수 있다는 사실은 결국 수익을 절감할 수 있다는 것을 의미합니다. 이 호스트가 예기치 않게 종료된다고 가정해 보겠습니다.다른 물리적 서버의 한 하이퍼바이저에서 다른 하이퍼바이저로 가상 시스템을 이동할 수 있다는 것은 훌륭한 백업 계획을 갖추고 있다는 뜻이죠?
