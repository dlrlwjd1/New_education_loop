# Expert Viewpoints - Cloud Storage

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/introduction-to-cloud/lecture/wgqot/expert-viewpoints-cloud-storage)

## 개요
- 따라서 이 스토리지를 사용하는 데 필요한 용도를 정확히 이해한 다음 답변에 다양한 요소를 고려하면 문제를 해결하는 데 필요한 올바른 스토리지 또는 다중 스토리지를 찾는 데 도움이 되기를 바랍니다.

## 내용
- 따라서 이 스토리지를 사용하는 데 필요한 용도를 정확히 이해한 다음 답변에 다양한 요소를 고려하면 문제를 해결하는 데 필요한 올바른 스토리지 또는 다중 스토리지를 찾는 데 도움이 되기를 바랍니다.
- 블록 스토리지는 동시 액세스를 지원하지 않지만 지연 시간이 매우 짧고 일반적으로 데이터베이스와 같은 성능 집약적인 애플리케이션에 적합한 스토리지입니다.
- 클라우드 오브젝트 스토리지는 느리긴 하지만 클라우드 오브젝트 저장소 내에서 만들 수 있는 무제한 공간 또는 버킷을 제공합니다.
- 예를 들어 데이터베이스용 스토리지와 같이 속도가 중요한 곳에서 조금 더 빠른 스토리지를 찾고 있다면 블록 레벨 스토리지를 고려해 볼 수 있습니다.
- 또 다른 유형의 스토리지는 블록 스토리지입니다.또한 클라우드에서는 블록 스토리지와 서버 간의 지연 시간이 매우 짧은 최적화된 가상 머신인 블록 스토리지를 선택할 수 있습니다.
- 고려해야 할 다른 요소로는 대기 시간이 짧은 매우 활성 상태부터 빈도가 낮은 데이터 액세스 빈도, 사용 빈도가 낮거나 콜드 스토리지, 장기 보관을 위한 아카이브에 이르기까지 데이터 액세스 빈도가 포함됩니다.
- 콘텐츠 전송 네트워크의 경우 , 예를 들어 미디어를 최종 사용자와 최대한 가까운 곳에 저장하여 사용자가 웹 사이트를 로드하고 이미지를 볼 때 미디어가 모든 영역에 복제되므로 해당 이미지가 즉시 로드되도록 하려는 경우에 사용할 수 있습니다.

## 예시
- 예를 들어, 대용량 데이터 세트, 비디오 파일, 데이터베이스 백업 같은 것들이죠.

## 요약
- 고려해야 할 다른 요소로는 대기 시간이 짧은 매우 활성 상태부터 빈도가 낮은 데이터 액세스 빈도, 사용 빈도가 낮거나 콜드 스토리지, 장기 보관을 위한 아카이브에 이르기까지 데이터 액세스 빈도가 포함됩니다. 콘텐츠 전송 네트워크의 경우 , 예를 들어 미디어를 최종 사용자와 최대한 가까운 곳에 저장하여 사용자가 웹 사이트를 로드하고 이미지를 볼 때 미디어가 모든 영역에 복제되므로 해당 이미지가 즉시 로드되도록 하려는 경우에 사용할 수 있습니다.
