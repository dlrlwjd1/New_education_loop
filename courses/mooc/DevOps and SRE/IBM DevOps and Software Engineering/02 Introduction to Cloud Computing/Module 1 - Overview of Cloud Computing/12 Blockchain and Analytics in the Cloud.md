# Blockchain and Analytics in the Cloud

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/introduction-to-cloud/lecture/XXfhq/blockchain-and-analytics-in-the-cloud)

## 개요
- 이러한 기업은 여러 클라우드에서 애플리케이션과 데이터를 쉽고 안전하게 이동할 수 있어야 하며, 이로 인해 멀티 클라우드 환경을 위한 블록체인과 같은 비즈니스 애플리케이션을 구축하고 관리해야 하는 수요가 증가하고 있습니다.

## 내용
- 이러한 기업은 여러 클라우드에서 애플리케이션과 데이터를 쉽고 안전하게 이동할 수 있어야 하며, 이로 인해 멀티 클라우드 환경을 위한 블록체인과 같은 비즈니스 애플리케이션을 구축하고 관리해야 하는 수요가 증가하고 있습니다.
- 클라우드는 전 세계에 분산되고 확장 가능하며 비용 효율적인 컴퓨팅 리소스를 제공하여 수집되는 전례 없는 양의 데이터와 해당 데이터에서 통찰력을 도출하는 데 필요한 처리 능력을 모두 지원합니다.
- 블록체인은 의사 결정에 필요한 데이터와 변수를 AI 알고리즘에 기록함으로써 AI를 더 이해하기 쉽게 만들어 이러한 알고리즘이 내린 결론과 결정에 대한 신뢰와 투명성을 높이는 역할을 합니다.
- KONE이 매일 10억 명이 넘는 사람들이 사용하는 도시 인프라의 데이터 애널리틱스 및 예측 유지보수 솔루션을 강화하기 위해 어떻게 클라우드 및 IoT 기술에 투자했는지 살펴보겠습니다.
- 우리는 함수를 사용하여 해당 데이터를 처리하고 해당 데이터에 대한 추가 이벤트를 생성하여 애플리케이션과 고객 전체가 이를 활용하고 사용합니다.
- 애널리틱스 플랫폼에서 데이터 세트를 분석한 결과 향후 장비의 고장률을 일정 비율까지 예측할 수 있다는 점에서 예측 가치를 생성하고 이를 통해 예측 유지보수를 수행할 수 있습니다.
- 우리는 클라우드의 스토리지를 사용하고, Cloud Functions를 사용하고, 메시징 서비스를 사용하고, IoT 서비스를 사용합니다.

## 예시
- 우리는 클라우드의 스토리지를 사용하고, Cloud Functions를 사용하고, 메시징 서비스를 사용하고, IoT 서비스를 사용합니다.
