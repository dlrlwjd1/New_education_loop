# Cloud Adoption - Some case studies

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/introduction-to-cloud/lecture/qBrB9/cloud-adoption-some-case-studies)

## 개요
- 이 비디오에서는 일부 주요 기업이 클라우드 기술을 사용하여 더 나은 고객 서비스를 제공하고, 혁신의 장벽을 제거하고, 엔터프라이즈 규모를 달성하고, 성장을 가속화하기 위해 업무 방식을 어떻게 변화시켰는지 살펴보겠습니다.

## 내용
- 이 비디오에서는 일부 주요 기업이 클라우드 기술을 사용하여 더 나은 고객 서비스를 제공하고, 혁신의 장벽을 제거하고, 엔터프라이즈 규모를 달성하고, 성장을 가속화하기 위해 업무 방식을 어떻게 변화시켰는지 살펴보겠습니다.
- 고객 요구에 보다 신속하게 대응하기 위해 American Airlines는 전사적으로 디지털 셀프 서비스 도구와 고객 가치를 더 빠르게 제공하는 데 도움이 되는 새로운 기술 플랫폼과 새로운 개발 접근 방식이 필요했습니다.
- 이 항공사는 모놀리식 코드를 기반으로 하는 기존 고객 대상 애플리케이션의 제약을 클라우드 기반 클라우드 기반 마이크로서비스 아키텍처로 없앨 기회를 포착했습니다.
- 결과, 새로운 앱의 개발 및 출시 가속화, 운영 안정성, 생산성 향상 및 최종 고객 응답 시간 향상 IBM Cloud로의 마이그레이션을 통해 기존 업그레이드 비용을 제거하여 비용 절감 혁신 장벽 제거: UBank는 자체 인원수 제한이 있는 간결한 조직으로서 수요를 충족하는 혁신적인 방법을 찾는 데 탁월합니다.
- 보다 효율적인 운영 방법을 찾기 위해 끊임없이 고민하던 uBank의 IT 팀은 PaaS (Platform as a Service) 클라우드 개발 모델을 모색했습니다.
- 유연하고 비용 효율적인 Cloud Object Storage 환경에서 10억 개의 사용자 상호 작용 데이터 세트를 저장하고 관리합니다.IT 운영을 혁신하여 성장에 맞게 확장하고 비용을 제어하며 귀중한 리소스를 신제품 개발에 집중했습니다.
- 가용성이 매우 높고 보안이 강화된 클라우드 플랫폼은 고객의 투자를 보호합니다.새로운 요구 사항에 더 빠르게 대응하기 위해 새로운 리소스를 가동하는 데 며칠이 아닌 몇 시간이 걸립니다.다음 비디오에서는 클라우드에서 사용할 수 있는 몇 가지 새로운 기술과 이러한 기술이 비즈니스에 가져다주는 기회에 대해 살펴보겠습니다.

## 예시
- 살펴볼 사례 연구는 IBM Cloud에서 선별한 것이지만, 다른 클라우드 서비스 공급자를 활용하는 다양한 기업에서도 비즈니스에 큰 영향을 미치는 유사한 사례를 찾아볼 수 있습니다.
