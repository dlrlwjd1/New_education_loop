# Expert Viewpoints - Definition and Essential Characteristics of Cloud Computing

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/introduction-to-cloud/lecture/nIOyD/expert-viewpoints-definition-and-essential-characteristics-of-cloud-computing)

## 개요
- 이 비디오에서는 여러 클라우드 네이티브 및 애플리케이션 개발 전문가들이 클라우드 컴퓨팅의 정의와 클라우드 컴퓨팅의 고유한 특성에 대해 논의하는 내용을 들어보겠습니다.

## 내용
- 이 비디오에서는 여러 클라우드 네이티브 및 애플리케이션 개발 전문가들이 클라우드 컴퓨팅의 정의와 클라우드 컴퓨팅의 고유한 특성에 대해 논의하는 내용을 들어보겠습니다.
- >> 클라우드 컴퓨팅이란 인터넷 또는 클라우드를 통해 서버, 데이터베이스, 네트워킹, 분석 등을 포함할 수 있는 컴퓨팅 서비스를 제공하는 것을 말합니다.
- 모든 것을 주문하고 설정하고 가용성을 직접 관리해야 하는 데이터 센터와 달리 클라우드 컴퓨팅에서는 클라우드 공급자가 서비스의 물리적 보안을 관리하므로 사용자는 서비스에 대한 물리적 보안을 관리하기만 하면 됩니다.
- >> 클라우드 컴퓨팅을 엔터프라이즈 컴퓨팅을 위한 컴퓨팅 네트워킹 리소스의 모든 측면을 관리하는 API 기반 서비스 제품군으로 요약하겠습니다.
- 아이디어로는 클라우드 컴퓨팅을 사용해 인증과 같은 용도로 사용하거나, 소셜 로그인을 사용하여 사람들이 Facebook이나 Google 로그인으로 로그인할 수 있도록 하거나, 끝까지 진행하여 전체 프로젝트를 클라우드 기반 인프라에서 호스팅할 수 있다는 것입니다.
- 클라우드라는 공백에 도달할 때마다 클라우드 기술을 활용하고 컴퓨팅 파워나 다른 것, 즉 스토리지를 사용할 때마다 클라우드 기술을 사용하든 상관 없습니다.그리고 이 점을 이해하는 것이 정말 중요하다고 생각합니다.
- >> 클라우드의 고성능 컴퓨팅을 사용하면 매우 빠른 컴퓨터 클러스터를 손쉽게 사용할 수 있으며 필요할 때만 비용을 지불할 수 있습니다.또한 클라우드 덕분에 중소기업은 고성능 컴퓨팅 클러스터를 구축하고 빠르게 혁신할 수 있습니다.

## 예시
- >> 클라우드의 고성능 컴퓨팅을 사용하면 매우 빠른 컴퓨터 클러스터를 손쉽게 사용할 수 있으며 필요할 때만 비용을 지불할 수 있습니다.또한 클라우드 덕분에 중소기업은 고성능 컴퓨팅 클러스터를 구축하고 빠르게 혁신할 수 있습니다.

## 요약
- 클라우드라는 공백에 도달할 때마다 클라우드 기술을 활용하고 컴퓨팅 파워나 다른 것, 즉 스토리지를 사용할 때마다 클라우드 기술을 사용하든 상관 없습니다.그리고 이 점을 이해하는 것이 정말 중요하다고 생각합니다. >> 클라우드의 고성능 컴퓨팅을 사용하면 매우 빠른 컴퓨터 클러스터를 손쉽게 사용할 수 있으며 필요할 때만 비용을 지불할 수 있습니다.또한 클라우드 덕분에 중소기업은 고성능 컴퓨팅 클러스터를 구축하고 빠르게 혁신할 수 있습니다.
