# Serverless Computing

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/introduction-to-cloud/lecture/Ndt1M/serverless-computing)

## 개요
- [음악] 서버리스는 애플리케이션 스택의 크기 조정, 스케줄링, 패치 적용 및 프로비저닝과 같은 일반적인 인프라 관리 작업을 클라우드 공급자에게 맡기는 컴퓨팅 접근 방식으로, 개발자는 애플리케이션 또는 프로세스별 코드 및 비즈니스 로직에 시간과 노력을 집중할 수 있습니다.

## 내용
- [음악] 서버리스는 애플리케이션 스택의 크기 조정, 스케줄링, 패치 적용 및 프로비저닝과 같은 일반적인 인프라 관리 작업을 클라우드 공급자에게 맡기는 컴퓨팅 접근 방식으로, 개발자는 애플리케이션 또는 프로세스별 코드 및 비즈니스 로직에 시간과 노력을 집중할 수 있습니다.
- 예를 들어 웹 사이트의 프런트 엔드와 스토리지 레이어 사이에 개별 기능을 실행하는 서버리스 플랫폼을 두고 서버리스 앱이 텍스트 파일을 번역하여 클라우드 기반 스토리지 서비스에 저장하는 시나리오를 살펴보겠습니다.
- 서버리스 아키텍처에 적합한 애플리케이션에는 다음과 같은 몇 가지 특징, 단기 실행 상태를 저장하지 않는 함수, 초 또는 분, 피크 시간대가 다양한 계절적 워크로드, 유휴 시간이 너무 많은 프로덕션 볼륨 데이터, 사용 사례 구현을 위한 이벤트 기반 처리 또는 비동기 요청 처리 등이 있습니다.
- 고유한 자동 확장, 빠른 프로비저닝, 유휴 시간에도 변하지 않는 가격 책정 모델을 고려할 때 마이크로서비스 아키텍처 지원은 오늘날 서버리스 컴퓨팅의 가장 일반적인 사용 사례 중 하나가 되었습니다.
- 서버리스는 데이터 강화, 변환, 검증 및 정리, PDF 처리, 오디오 표준화, 썸네일 생성, 비디오 트랜스코딩과 같은 작업과 관련된 정형 텍스트, 오디오, 이미지 및 비디오 데이터를 처리하는 데 매우 적합합니다.
- 서버리스는 비즈니스 데이터 스트림, IoT 센서 데이터, 로그 데이터, 금융 시장 데이터 등 모든 종류의 데이터 스트림 수집 작업에도 적합합니다.
- 서버리스 애플리케이션 아키텍처는 벤더에 따라 달라질 수 있으므로 특히 인증, 확장, 모니터링 또는 구성 관리와 같은 플랫폼 기능과 관련하여 벤더에 종속될 가능성이 있습니다.

## 예시
- 예를 들어 웹 사이트의 프런트 엔드와 스토리지 레이어 사이에 개별 기능을 실행하는 서버리스 플랫폼을 두고 서버리스 앱이 텍스트 파일을 번역하여 클라우드 기반 스토리지 서비스에 저장하는 시나리오를 살펴보겠습니다.

## 요약
- 서버리스는 비즈니스 데이터 스트림, IoT 센서 데이터, 로그 데이터, 금융 시장 데이터 등 모든 종류의 데이터 스트림 수집 작업에도 적합합니다. 서버리스 애플리케이션 아키텍처는 벤더에 따라 달라질 수 있으므로 특히 인증, 확장, 모니터링 또는 구성 관리와 같은 플랫폼 기능과 관련하여 벤더에 종속될 가능성이 있습니다.
