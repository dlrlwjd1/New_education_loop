# Expert Viewpoints - Cloud Native and Emergent Cloud Trends

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/introduction-to-cloud/lecture/bRi2x/expert-viewpoints-cloud-native-and-emergent-cloud-trends)

## 개요
- 이제는 용어들이 서로 상당히 다르고 서로 분리된 것처럼 보일 수도 있지만, 여러 측면에서 클라우드 컴퓨팅은 엣지 역할을 할 것입니다.

## 내용
- 이제는 용어들이 서로 상당히 다르고 서로 분리된 것처럼 보일 수도 있지만, 여러 측면에서 클라우드 컴퓨팅은 엣지 역할을 할 것입니다.
- 클라우드 제공업체가 이러한 모든 운영 문제를 처리하므로 코드를 제공하면 온디맨드 방식으로 실행하기만 하면 됩니다.예를 들어, 이벤트가 트리거될 때마다 음성 어시스턴트와 대화할 때마다 클라우드 기능을 트리거한다고 가정해 보겠습니다.
- >> 따라서 신기술 측면에서 가장 큰 기술 중 하나는 클라우드 네이티브, 클라우드 네이티브 아키텍처입니다.여기에는 마이크로서비스로 향하는 추세도 포함됩니다.
- 또 다른 하나는 서버리스 서비스로, 가상 서버를 관리할 필요 없이 일부 기능 코드를 매우 짧은 지연 시간으로 실행할 수 있습니다.
- 특히, 이미지 인식, 음성 애플리케이션 등을 위한 사전 학습된 상위 수준의 AI 솔루션과 함께 처음부터 AI 솔루션을 구축할 수 있는 저수준 AI 서비스가 등장하고 있습니다.
- 따라서 많은 기능을 제공하는 이러한 놀라운 서비스를 제공하는 클라우드 제공업체가 출시되면서 회사들은 “잠시만요, 클라우드 제공업체가 우리 애플리케이션의 특정 기능을 우리보다 더 잘 수행하고 있습니다.” 라고 생각하고 있습니다.
- “애플리케이션의 해당 부분을 계속 유지 관리하는 대신 이러한 클라우드 네이티브 서비스를 활용할 수 있도록 애플리케이션을 다시 작성해 봅시다.” 예를 들어, 이제는 트랜스크립션이나 이미지 인식을 수행하는 서비스가 있습니다.
