# Microservices

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/introduction-to-cloud/lecture/LZ6bb/microservices)

## 개요
- 마이크로서비스 아키텍처는 단일 애플리케이션이 여러 개의 느슨하게 결합되고 독립적으로 배포할 수 있는 소형 구성 요소 또는 서비스로 구성되는 접근 방식입니다.

## 내용
- 마이크로서비스 아키텍처는 단일 애플리케이션이 여러 개의 느슨하게 결합되고 독립적으로 배포할 수 있는 소형 구성 요소 또는 서비스로 구성되는 접근 방식입니다.
- 너무 많은 부하에 직면한 구성 요소를 독립적으로 확장할 수 있으므로 전체 애플리케이션을 확장해야 하는 데 따르는 낭비와 비용을 줄일 수 있습니다.
- 컨테이너는 플러그 앤 플레이 방식이므로 하나의 마이크로서비스가 애플리케이션에서 작동하지 않는 경우 개발자는 애플리케이션의 나머지 기능에 지장을 주지 않고 이를 꺼내 다른 마이크로서비스에 넣을 수 있습니다.
- 세 번째 마이크로서비스인 Recommendations는 모든 Dream Game 사용자에게 가장 인기 있는 콘텐츠에 대한 데이터를 캡처합니다.
- 추천 마이크로서비스는 분석을 사용하여 Ron의 시청 기록 및 선호도를 Ron의 지리적 지역 및 인구 통계에 속한 축구 팬 및 시청자를 포함한 다른 사용자에게 인기 있는 콘텐츠와 비교합니다.
- Ron이 다음에 Dream Game을 확인하면 가장 인기 있는 콘텐츠나 최신 콘텐츠만 보는 대신 개인화된 재생 목록이 나오는데, 이 재생 목록은 시스템이 시청 습관과 선호도에 대해 더 많이 알게 됨에 따라 계속 개선될 것입니다.
- 마이크로서비스 접근 방식을 통해 개발자는 동시에 애플리케이션을 빠르게 혁신하고 Ron과 같은 사용자는 자신이 정말로 관심을 갖는 것에 집중할 수 있습니다.

## 예시
- 이 비디오에서는 마이크로서비스가 애플리케이션 개발을 어떻게 변화시켰는지 살펴보고 실제 마이크로서비스를 보여주는 사용 사례도 살펴보겠습니다.

## 요약
- Ron이 다음에 Dream Game을 확인하면 가장 인기 있는 콘텐츠나 최신 콘텐츠만 보는 대신 개인화된 재생 목록이 나오는데, 이 재생 목록은 시스템이 시청 습관과 선호도에 대해 더 많이 알게 됨에 따라 계속 개선될 것입니다. 마이크로서비스 접근 방식을 통해 개발자는 동시에 애플리케이션을 빠르게 혁신하고 Ron과 같은 사용자는 자신이 정말로 관심을 갖는 것에 집중할 수 있습니다.
