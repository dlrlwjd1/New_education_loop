# Introduction to Cloud Computing

## 개요
- 클라우드의 서비스·배포 모델, 핵심 구성요소, 최신 경향과 보안·모니터링을 다룬다.

## 내용
- IaaS·PaaS·SaaS는 고객과 제공자의 관리 책임 경계를 다르게 한다. public, private, hybrid cloud는 통제·비용·연결 요구에 따라 선택한다.
- virtualization, container, storage, network, API와 orchestration이 탄력적 자원 제공을 구성한다.
- serverless, microservices, edge와 cloud-native는 관리 단위를 줄이고 배포 속도를 높이지만 vendor dependency와 분산 복잡성을 만든다.
- shared responsibility에 따라 IAM, 암호화, 네트워크 통제, 로그·지표와 비용 모니터링을 설계한다.

## 예시
```text
사용자 -> Load Balancer -> Auto-scaled App -> Managed Database/Object Storage
```
