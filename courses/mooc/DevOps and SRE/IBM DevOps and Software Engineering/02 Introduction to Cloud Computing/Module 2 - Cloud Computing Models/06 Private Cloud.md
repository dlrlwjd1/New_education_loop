# Private Cloud

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/introduction-to-cloud/lecture/Cn1ph/private-cloud)

## 개요
- 미국 표준 기술 연구소 (National Institute of Standards and Technology) 는 사설 클라우드를 조직 내 사업부와 같이 여러 소비자로 구성된 단일 조직이 독점적으로 사용하도록 프로비저닝하는 클라우드 인프라라고 정의합니다.

## 내용
- 미국 표준 기술 연구소 (National Institute of Standards and Technology) 는 사설 클라우드를 조직 내 사업부와 같이 여러 소비자로 구성된 단일 조직이 독점적으로 사용하도록 프로비저닝하는 클라우드 인프라라고 정의합니다.
- VPC는 조직이 공유 퍼블릭 클라우드의 논리적으로 격리된 부분에 클라우드와 유사한 자체 프라이빗 보안 컴퓨팅 환경을 구축할 수 있도록 하는 퍼블릭 클라우드 서비스입니다.
- VPC를 사용하면 조직은 퍼블릭 클라우드의 동적 확장성, 고가용성, 낮은 소유 비용을 활용하는 동시에 조직의 고유한 요구 사항에 맞게 인프라와 보안을 조정할 수 있습니다.
- 조직의 개발자 및 사업부와 같은 사설 클라우드 사용자는 여전히 규모의 경제, 세분화된 규모, 운영 효율성, 사용자 셀프 서비스와 같은 이점을 활용하는 동시에 조직 및 비즈니스에 맞는 액세스, 보안 및 규정 준수를 완벽하게 제어할 수 있습니다.
- 사설 클라우드는 첫째, 조직의 내부 IT에서 직접 관리되거나 통제 하에 있는 시스템을 사용하여 클라우드 컴퓨팅의 가치를 활용할 수 있는 기능을 제공합니다.
- 이를 통해 기업은 프라이빗 클라우드의 컴퓨팅 기능을 대규모 작업에 활용하는 동시에 프라이빗 클라우드의 애플리케이션으로 데이터를 가져와 퍼블릭 클라우드 서비스를 활용할 수 있습니다.
- 사설 클라우드는 이러한 조직에 온디맨드 엔터프라이즈 리소스의 이점을 제공하는 동시에 전용 클라우드 환경 내에서 중요한 보안 및 규정 준수 문제를 완벽하게 제어할 수 있습니다.

## 예시
- 사설 클라우드는 이러한 조직에 온디맨드 엔터프라이즈 리소스의 이점을 제공하는 동시에 전용 클라우드 환경 내에서 중요한 보안 및 규정 준수 문제를 완벽하게 제어할 수 있습니다.

## 요약
