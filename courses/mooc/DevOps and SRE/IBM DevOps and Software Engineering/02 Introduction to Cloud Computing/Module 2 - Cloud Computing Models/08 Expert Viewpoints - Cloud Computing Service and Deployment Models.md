# Expert Viewpoints - Cloud Computing Service and Deployment Models

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/introduction-to-cloud/lecture/RzNdv/expert-viewpoints-cloud-computing-service-and-deployment-models)

## 개요
- [음악] 클라우드 컴퓨팅 서비스 모델에 오신 것을 환영합니다 - 전문가 관점 이 비디오에서는 여러 클라우드 전문가들이 다양한 클라우드 모델의 선택 및 채택에 대해 논의하는 것을 들어보겠습니다.

## 내용
- [음악] 클라우드 컴퓨팅 서비스 모델에 오신 것을 환영합니다 - 전문가 관점 이 비디오에서는 여러 클라우드 전문가들이 다양한 클라우드 모델의 선택 및 채택에 대해 논의하는 것을 들어보겠습니다.
- 따라서 데이터 센터의 임대 기간이 곧 만료되는 경우 애플리케이션을 클라우드 네이티브로 다시 작성할 시간이 없을 수도 있습니다.
- 데이터 센터의 가상 시스템에 있는 그대로 애플리케이션을 가져와서 클라우드의 가상 시스템으로 옮길 시간이 있을 수도 있습니다.이를 서비스형 인프라라고 합니다.
- 즉, 이를 컨테이너와 같은 서비스형 플랫폼 또는 운영 체제를 대신 운영하는 서비스에 설치하여 운영 체제를 패치하고 추가 종속 항목을 직접 설치하기만 하면 됩니다.
- 서비스형 인프라를 사용하는 시나리오로는 웹 사이트 호스팅, 가상 데이터 센터 또는 데이터 분석 수행 등이 있습니다.
- 서비스형 소프트웨어에서 서비스형 인프라로 추상화 계층을 내려갈수록 리소스 구성 방식을 더 잘 제어할 수 있다는 이점과 함께 더 많은 관리 책임을 스스로 떠맡게 된다는 단점이 있습니다.
- 그런데 알고 보니 제가 만들고 있는 웹사이트가 다소 복잡해서 리액트 앱이 되었으면 하는 생각이 드네요.서비스형 플랫폼 ( Platform-as-a-Service) 에서 앱을 호스팅할 수도 있겠지만, 서비스형 플랫폼 (Platform-as-a-Service) 에서 지원하지 않는 운영 체제에서 앱을 실행해야 한다는 요구 사항이 있다고 가정해 보겠습니다.

## 예시
- 조직에 적합한 클라우드 모델을 선택하기 위한 사용 사례 시나리오 또는 고려 사항에 대해 말씀해 주시겠습니까?

## 요약
- 서비스형 소프트웨어에서 서비스형 인프라로 추상화 계층을 내려갈수록 리소스 구성 방식을 더 잘 제어할 수 있다는 이점과 함께 더 많은 관리 책임을 스스로 떠맡게 된다는 단점이 있습니다. 그런데 알고 보니 제가 만들고 있는 웹사이트가 다소 복잡해서 리액트 앱이 되었으면 하는 생각이 드네요.서비스형 플랫폼 ( Platform-as-a-Service) 에서 앱을 호스팅할 수도 있겠지만, 서비스형 플랫폼 (Platform-as-a-Service) 에서 지원하지 않는 운영 체제에서 앱을 실행해야 한다는 요구 사항이 있다고 가정해 보겠습니다.
