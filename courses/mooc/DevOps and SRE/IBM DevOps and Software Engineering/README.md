# IBM DevOps and Software Engineering

DevOps 문화, 클라우드·Agile·소프트웨어 공학에서 Python, 컨테이너·마이크로서비스, 테스트·CI/CD·보안·관측성과 캡스톤까지 잇는 IBM 전문 자격증이다.

- 과정: https://www.mooc.org/professional-certificates/devops-and-software-engineering
- 현재 구성: 15개 하위 강좌 모두 모듈별 강의 노트로 세분화 완료(14번은 최상위 독립 코스로 정리된 동일 강좌를 교차 참조)
- 제외: 채점 평가와 해답

## 학습 흐름

```text
DevOps/Cloud/Agile -> Git/Linux/Python -> Container/Microservice
-> TDD/BDD -> CI/CD -> Security/Observability -> Capstone
```
