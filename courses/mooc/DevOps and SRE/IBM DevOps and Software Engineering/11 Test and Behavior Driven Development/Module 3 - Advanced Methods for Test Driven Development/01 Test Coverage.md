# Test Coverage

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/test-and-behavior-driven-development-tdd-bdd/lecture/XARH9/test-coverage)

## 개요
- 이 동영상을 시청한 후에는 테스트 커버리지의 중요성을 설명하고, 테스트 커버리지 보고서를 사용하여 테스트 커버리지를 높이는 방법을 요약하고, 100% 테스트 커버리지에서도 지속적인 테스트가 중요한 이유를 설명할 수 있습니다.

## 내용
- 이 동영상을 시청한 후에는 테스트 커버리지의 중요성을 설명하고, 테스트 커버리지 보고서를 사용하여 테스트 커버리지를 높이는 방법을 요약하고, 100% 테스트 커버리지에서도 지속적인 테스트가 중요한 이유를 설명할 수 있습니다.
- 테스트 커버리지를 요청하면 커버리지 툴이 실행 가능한 모든 코드 라인을 카운트한 다음 테스트를 모니터링하여 테스트가 실행하는 코드 라인을 확인합니다.
- 그런 다음 도구는 실행 가능한 코드 줄 수를 총 코드 줄 수로 나누고, 이 결과를 테스트에서 실제로 다룬 코드 줄의 백분율을 구합니다.
- 결과적으로 테스트를 위해 더 많은 코드 줄을 실행할수록 코드 줄이 예상대로 작동한다는 확신을 가질 수 있습니다.테스트 커버리지 수준을 결정하려면 테스트 커버리지 보고서를 사용합니다.
- 이러한 보고서를 통해 테스트된 코드 줄을 확인할 수 있지만 더 중요한 것은 테스트되지 않은 코드 줄을 확인할 수 있으므로 해당 코드를 실행하는 더 많은 테스트 사례를 작성할 수 있다는 것입니다.
- 다시 말하지만, 이 누락 보고서는 -m 매개 변수를 coverage 명령에 추가하거나 적용 범위와 함께 해당 테스트를 실행하는 동안 매개 변수로 지정한 경우에만 표시됩니다.
- 이 비디오에서는 테스트 커버리지가 높을수록 개발자가 코드가 예상대로 작동한다는 확신을 가질 수 있다는 것을 알게 되었습니다.

## 예시
- 이러한 보고서를 통해 테스트된 코드 줄을 확인할 수 있지만 더 중요한 것은 테스트되지 않은 코드 줄을 확인할 수 있으므로 해당 코드를 실행하는 더 많은 테스트 사례를 작성할 수 있다는 것입니다.

## 요약
- 다시 말하지만, 이 누락 보고서는 -m 매개 변수를 coverage 명령에 추가하거나 적용 범위와 함께 해당 테스트를 실행하는 동안 매개 변수로 지정한 경우에만 표시됩니다. 이 비디오에서는 테스트 커버리지가 높을수록 개발자가 코드가 예상대로 작동한다는 확신을 가질 수 있다는 것을 알게 되었습니다.
