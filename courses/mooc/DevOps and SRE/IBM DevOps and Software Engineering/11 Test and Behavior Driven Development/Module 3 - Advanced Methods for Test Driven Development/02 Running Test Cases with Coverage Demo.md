# Running Test Cases with Coverage Demo

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/test-and-behavior-driven-development-tdd-bdd/lecture/JwrzZ/running-test-cases-with-coverage-demo)

## 개요
- 몇 가지 임포트가 있고, 계정 데이터 글로벌 변수가 있고, 설정 메서드에서 모든 테이블을 만들고, 테스트 픽스처 계정 데이터 JSON에서 가져온 것을 이 글로벌 계정 변수에 로드하고 있습니다.

## 내용
- 몇 가지 임포트가 있고, 계정 데이터 글로벌 변수가 있고, 설정 메서드에서 모든 테이블을 만들고, 테스트 픽스처 계정 데이터 JSON에서 가져온 것을 이 글로벌 계정 변수에 로드하고 있습니다.
- 딕셔너리에서 데이터를 가져와서 계정 데이터에서 데이터를 가져와서 무작위 계정을 만들고 빈 계정을 만든 다음 account.from_dictory라고 하고 데이터를 전달했는데 계정을 만드는 또 다른 방법입니다.
- 네 개의 테스트 케이스가 있고, 다섯 개의 테스트 케이스가 실행되고, 80% 의 코드 커버리지를 얻었습니다.45와 48개의 코드가 없는 다음 줄입니다.
- 사실 모든 변수가 거기에 들어갔다는 것을 증명하기 위해 모든 것을 업데이트하고 싶을 수도 있습니다.하지만 이걸 실행해 봅시다.네 , 그럼 코 검사를 다시 해볼게요.
- 코드를 복제해도 괜찮습니다.계정 삭제 테스트, 계정 삭제를 테스트하고, 무작위 계정을 만들어 데이터베이스에 생성하여 데이터베이스에 있다는 것을 증명할 것입니다.
- 커버리지 보고서를 보고, 누락된 코드 줄을 살펴보고, 코드 줄을 찾아보고, 해당 코드를 실행할 테스트 케이스를 어떻게 작성할 수 있는지 생각해 보는 것이 얼마나 쉬운지 알 수 있기를 바랍니다.
- 테스트 케이스를 작성하고 테스트 보고서를 가져온 다음 어떤 코드 줄이 누락되었는지 확인한 다음 해당 코드 줄을 통과하도록 테스트 케이스를 몇 개 더 작성하십시오.

## 예시
- 이 실습에서는 커버리지 도구, 특히 누락 커버리지 보고서를 사용하여 테스트 케이스가 없는 누락된 라인을 보여주는 방법을 보여드리겠습니다.
