# Mocking with Patch

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/test-and-behavior-driven-development-tdd-bdd/lecture/cTtBq/mocking-with-patch)

## 개요
- 이 비디오를 시청한 후에는 패치를 정의하고, Python의 모의 라이브러리에서 사용할 수 있는 두 가지 패치 기술을 나열하고, 각 패치 기술이 유용한 상황을 설명할 수 있습니다.

## 내용
- 이 비디오를 시청한 후에는 패치를 정의하고, Python의 모의 라이브러리에서 사용할 수 있는 두 가지 패치 기술을 나열하고, 각 패치 기술이 유용한 상황을 설명할 수 있습니다.
- 하나는 함수의 반환 값을 패치하는 것이고 다른 함수는 다른 함수로 바꾸는 것입니다.이를 부작용이라고 합니다.
- 이는 오류 조건 코드를 다시 전달하고 이러한 반환 코드를 수신했을 때 애플리케이션이 어떻게 동작하는지 확인할 수 있으므로 오류 핸들러를 테스트하는 데 유용합니다.
- return_value 패치를 사용하면 함수 호출에서 반환 값으로 다시 보낼 수 있는 모든 것을 반환할 수 있습니다.
- 결과적으로 실제 서비스를 호출하거나 잘못된 반환 코드를 반환하도록 시도하지 않고도 양호한 반환 코드와 잘못된 반환 코드를 테스트할 수 있습니다.
- 데코레이터를 사용하면 누군가가 test () 함수를 호출할 때마다 patch () 가 먼저 호출된 다음 patch () 가 테스트 함수를 호출합니다.
- 파이썬의 모의 라이브러리는 두 가지 패치 기법을 제공합니다: 함수의 반환 값을 패치하는 것과 함수를 다른 함수로 바꾸는 것 (부작용 기법)

## 예시
- 파이썬의 모의 라이브러리는 두 가지 패치 기법을 제공합니다: 함수의 반환 값을 패치하는 것과 함수를 다른 함수로 바꾸는 것 (부작용 기법)

## 요약
- 데코레이터를 사용하면 누군가가 test () 함수를 호출할 때마다 patch () 가 먼저 호출된 다음 patch () 가 테스트 함수를 호출합니다. 파이썬의 모의 라이브러리는 두 가지 패치 기법을 제공합니다: 함수의 반환 값을 패치하는 것과 함수를 다른 함수로 바꾸는 것 (부작용 기법)
