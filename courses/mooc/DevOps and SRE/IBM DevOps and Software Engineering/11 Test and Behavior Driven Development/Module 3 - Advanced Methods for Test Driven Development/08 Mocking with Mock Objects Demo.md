# Mocking with Mock Objects Demo

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/test-and-behavior-driven-development-tdd-bdd/lecture/egfmJ/mocking-with-mock-objects-demo)

## 개요
- 제목 검색, 영화 리뷰, 영화 평점 조회 등을 통해 이들이 실제로 요청을 하고 있는 것을 확인할 수 있습니다.

## 내용
- 제목 검색, 영화 리뷰, 영화 평점 조회 등을 통해 이들이 실제로 요청을 하고 있는 것을 확인할 수 있습니다.
- 잘못 입력하지 않도록 잘라서 붙여 넣을 것입니다.이 검색 제목의 이름은 다음과 같습니다.따라서 호출되면 패치를 만들 것입니다.따라서 테스트 케이스에 패치를 넣은 후에는 패치를 나타내는 모의 객체인 새 매개변수를 전달해야 합니다.
- 따라서 오류 메시지가 나타나지 않고 결과를 가져와서 해당 ID가 거기에 있는지 확인하고 JSON을 살펴보면 실제로 거기에 있습니다.
- 그래서 이 모의 객체에게 실제 JSON, 즉 유효하지 않은 API인 실제 파이썬 딕셔너리를 반환할 JSON이라는 메서드를 줘야 합니다.
- 그래서 이제 잘못된 API 키로 IMDb를 인스턴스화한 다음 검색을 수행한 다음 결과가 NONE이 아니며 오류 메시지가 잘못된 API 키와 동일하다는 것을 알고 있습니다.
- 해당 네임스페이스에서 호출을 패치한 다음 반환 값을 가져와서 JSON에 대한 호출을 갱신한 반환 코드가 있는 모의 객체를 반환할 수 있습니다.
- 이제 과제는 프로젝트의 테스트 케이스로 가서 외부 시스템이나 사용자가 제어할 수 없는 다른 시스템에 대한 몇 가지 호출을 모킹하여 항상 작동하는 테스트 케이스를 더 잘 제어할 수 있는지 확인하는 것입니다.

## 예시
- 모의 객체를 이용한 모의 객체 모킹 실습에 오신 것을 환영합니다.

## 요약
- 해당 네임스페이스에서 호출을 패치한 다음 반환 값을 가져와서 JSON에 대한 호출을 갱신한 반환 코드가 있는 모의 객체를 반환할 수 있습니다. 이제 과제는 프로젝트의 테스트 케이스로 가서 외부 시스템이나 사용자가 제어할 수 없는 다른 시스템에 대한 몇 가지 호출을 모킹하여 항상 작동하는 테스트 케이스를 더 잘 제어할 수 있는지 확인하는 것입니다.
