# Practicing Test Driven Development Demo

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/test-and-behavior-driven-development-tdd-bdd/lecture/DJPPV/practicing-test-driven-development-demo)

## 개요
- 즉, 갖고 싶었던 코드에 대한 테스트를 작성한 다음 테스트를 통과하도록 코드를 작성하는 것입니다.

## 내용
- 즉, 갖고 싶었던 코드에 대한 테스트를 작성한 다음 테스트를 통과하도록 코드를 작성하는 것입니다.
- 오류 코드를 확인할 때 사용할 수 있는 몇 가지 HTTP 오류 코드가 있는 status.py 모듈이 있습니다.
- 필자는 요구 사항을 문서화하여 요구 사항이 무엇인지 확인할 수 있도록 요구 사항을 작성하기 위해 이미 counters.py 를 만들었습니다.코드 없음.
- 나머지 API 또는 나머지 API에서 생성하는 경우 RESTful 지침을 따르는 경우 생성된 201을 다시 가져와야 한다는 것을 알고 있습니다.
- 그런 다음 Flask에 이 메서드에서 호출할 수 있는 유일한 메서드는 post 메서드라는 것을 알려줄 것입니다.
- 이제 “ 카운터 슬래시에 이름을 넘겨 post를 호출하는 사람이 있으면 제가 래핑하고 있는 이 함수, 이 데코레이터가 호출할 함수가 될 것입니다.” 이제 함수를 정의해서 카운터를 만들겠습니다.
- 하지만 Python이 로컬 변수가 아님을 알 수 있도록 함수에서 수정하려면 global이라고 말하고 이 함수가 이 글로벌 카운터 변수를 수정할 것이라고 말해야 합니다.

## 예시
- 이 데모에서는 테스트 주도 개발을 실제로 실습하는 워크플로를 보여 드리겠습니다.
