# Factories and Fakes Demo

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/test-and-behavior-driven-development-tdd-bdd/lecture/sxcz9/factories-and-fakes-demo)

## 개요
- 그래서 이 실습에서는 고정된 데이터가 있는 테스트 픽스처를 사용하는 것에서 팩토리를 사용하여 동적으로 데이터를 생성하는 것으로 넘어갈 것입니다.

## 내용
- 그래서 이 실습에서는 고정된 데이터가 있는 테스트 픽스처를 사용하는 것에서 팩토리를 사용하여 동적으로 데이터를 생성하는 것으로 넘어갈 것입니다.
- 몇 가지 퍼지 옵션이 있고 퍼지 데이터는 이미 가져왔기 때문에 이를 사용하여 퍼지 날짜를 만들 날짜를 정했습니다.
- 그래서 Faker는 우리가 가짜 데이터, 가짜 이름, 가짜 이메일, 가짜 전화번호를 만들 수 있게 해줍니다.
- 연구실에서는 이 계정들을 하나하나 살펴보면서 이 계정 데이터를 없애고 대체하고, 이 데이터를 없애고, 다음 데이터를 없애고, 그냥 살펴보면서 대체하라고 지시할 것입니다.
- 그런 다음 수정하고, 다음 테스트를 실행하고, 수정하고, 다음 테스트를 실행하고, 수정하고, 다음 테스트를 실행합니다.
- 그래서 실제 계정을 사용할 수 있는 모든 곳에서 데이터를 로드하고 어카운트 팩토리를 사용할 수 있습니다.
- 문제는 프로젝트의 객체 중 하나를 위한 팩토리를 만든 다음 페이커, 퍼지 옵션, 퍼지 날짜, 가짜 데이터로 채워서는 안 되는 항목을 사용하여 테스트 케이스에 사용하는 것입니다.

## 예시
- 이 실습에서는 팩토리, 특히 다른 랩에서 작업했던 계정의 계정 팩토리를 직접 만들 수 있습니다.

## 요약
- 그래서 실제 계정을 사용할 수 있는 모든 곳에서 데이터를 로드하고 어카운트 팩토리를 사용할 수 있습니다. 문제는 프로젝트의 객체 중 하나를 위한 팩토리를 만든 다음 페이커, 퍼지 옵션, 퍼지 날짜, 가짜 데이터로 채워서는 안 되는 항목을 사용하여 테스트 케이스에 사용하는 것입니다.
