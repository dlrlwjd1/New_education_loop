# Practicing Test Driven Development

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/test-and-behavior-driven-development-tdd-bdd/lecture/h8fg1/practicing-test-driven-development)

## 개요
- 이 비디오를 시청한 후에는 테스트 주도 개발 (TDD) 워크플로를 구현하고 TDD 워크플로가 어떻게 코드 개선으로 이어지는지 설명할 수 있습니다.테스트 기법, 특히 테스트 기반 개발에 대해 많이 이야기했습니다.

## 내용
- 이 비디오를 시청한 후에는 테스트 주도 개발 (TDD) 워크플로를 구현하고 TDD 워크플로가 어떻게 코드 개선으로 이어지는지 설명할 수 있습니다.테스트 기법, 특히 테스트 기반 개발에 대해 많이 이야기했습니다.
- 먼저 테스트 케이스를 작성합니다.둘째, 테스트 케이스를 통과하도록 코드를 작성합니다.
- 셋째, 코드의 동작을 변경하면 테스트 케이스를 통해 알 수 있다는 점을 염두에 두고 코드를 리팩터링하여 더 강력하게 만듭니다.
- 마지막으로, 코드의 동작을 변경하면 테스트 케이스를 통해 알 수 있다는 점을 염두에 두고 해당 코드를 리팩토링하여 더욱 견고하게 만드세요.
- API는 RESTful이어야 하므로 RESTful 가이드라인에 따라 201_CREATED 반환 코드를 반환해야 한다는 것을 알고 있습니다.
- 이 두 테스트 사례 모두 코드가 지정된 요구 사항을 따른다고 주장할 수 있었기 때문에 애플리케이션 코드를 작성하기 전에 쉽게 작성할 수 있었습니다.
- 테스트 케이스를 작성한 후 테스트 케이스를 통과하도록 코드를 작성합니다.또한 코드가 어떻게 동작해야 하는지 이미 알고 있기 때문에 코드 작성도 더 쉽습니다.

## 예시
- 이 두 테스트 사례 모두 코드가 지정된 요구 사항을 따른다고 주장할 수 있었기 때문에 애플리케이션 코드를 작성하기 전에 쉽게 작성할 수 있었습니다.

## 요약
- 이 두 테스트 사례 모두 코드가 지정된 요구 사항을 따른다고 주장할 수 있었기 때문에 애플리케이션 코드를 작성하기 전에 쉽게 작성할 수 있었습니다. 테스트 케이스를 작성한 후 테스트 케이스를 통과하도록 코드를 작성합니다.또한 코드가 어떻게 동작해야 하는지 이미 알고 있기 때문에 코드 작성도 더 쉽습니다.
