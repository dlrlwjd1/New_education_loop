# Mocking with Mock Objects

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/test-and-behavior-driven-development-tdd-bdd/lecture/ad7Um/mocking-with-mock-objects)

## 개요
- 이 비디오를 시청한 후에는 모의 객체가 무엇이고 왜 테스트에 유용한지 설명하고, Python에서 Mock과 MagicMock 클래스를 구현하는 방법을 요약하고, 패치와 모의 객체를 함께 사용하는 방법을 설명할 수 있습니다.

## 내용
- 이 비디오를 시청한 후에는 모의 객체가 무엇이고 왜 테스트에 유용한지 설명하고, Python에서 Mock과 MagicMock 클래스를 구현하는 방법을 요약하고, 패치와 모의 객체를 함께 사용하는 방법을 설명할 수 있습니다.
- 그런 다음 “spec” 파라미터를 사용하여 모의 객체를 생성하여 이 모의 객체가 Response 클래스처럼 동작하기를 원한다는 것을 나타냅니다.
- requests.get () 은 Response 객체를 반환한다는 것을 알고 있기 때문에 이 MagicMock이 반환될 때 코드가 예상하는 Response 객체처럼 동작하기를 원합니다.
- 다음으로 새 imdb_info () 함수가 이 반환 코드를 예상한다는 것을 알고 있기 때문에 status_code를 200으로 설정했습니다.
- Mock 및 MagicMock과 같은 모의 객체를 사용하는 것이 얼마나 강력한지, 특히 패치된 함수 호출의 반환 값으로 사용하는 것이 얼마나 효과적인지 알 수 있기를 바랍니다.
- 필요한 모든 반환 코드를 제어하여 잘못된 반환 코드뿐만 아니라 양호한 반환 코드도 시뮬레이션할 수 있습니다.또한 예제의 json () 함수처럼 어떤 함수 호출이 반환되는지 제어할 수도 있습니다.
- 하지만 모의 객체를 사용하는 것이 아니라 코드를 테스트하고 있는지 확인하고 싶기 때문에 모의 객체를 아껴서 사용해야 합니다.

## 예시
- 모의 객체를 사용하면 테스트 사례에 필요한 모든 동작을 모방할 수 있는 완벽한 제어가 가능합니다.

## 요약
- 필요한 모든 반환 코드를 제어하여 잘못된 반환 코드뿐만 아니라 양호한 반환 코드도 시뮬레이션할 수 있습니다.또한 예제의 json () 함수처럼 어떤 함수 호출이 반환되는지 제어할 수도 있습니다. 하지만 모의 객체를 사용하는 것이 아니라 코드를 테스트하고 있는지 확인하고 싶기 때문에 모의 객체를 아껴서 사용해야 합니다.
