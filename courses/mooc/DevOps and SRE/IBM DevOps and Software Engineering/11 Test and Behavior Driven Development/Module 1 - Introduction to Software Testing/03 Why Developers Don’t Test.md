# Why Developers Don’t Test

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/test-and-behavior-driven-development-tdd-bdd/lecture/1UaEh/why-developers-don-t-test)

## 개요
- 원래 코드에서 테스트를 실행하고 해당 코드가 제대로 작동하는지 확인하지 않으면 문제가 발생했는지 알 수 없습니다.

## 내용
- 원래 코드에서 테스트를 실행하고 해당 코드가 제대로 작동하는지 확인하지 않으면 문제가 발생했는지 알 수 없습니다.
- 그렇지 않으면 나중에 코드가 작동하지 않는 이유를 알아내려고 합니다.
- 테스트 케이스는 여러분과 다른 사람들이 무엇이 효과가 있고 무엇이 그렇지 않은지, 코드를 호출하는 방법을 알 수 있도록 도와줍니다.
- 개발자가 코드를 테스트하지 않는 또 다른 이유는 깨진 코드를 작성하지 않기 때문입니다!
- 코드를 테스트하고 해당 라이브러리의 새 버전에서 작동하는지 확인하는 테스트 케이스가 없다면 아마도 그렇게 하지 말아야 할 것입니다.
- 이제 몇 가지 테스트 사례를 작성하는 데 소요되는 시간을 나중에 디버깅하는 데 드는 시간과 시간을 절약할 수 있습니다.
- 이 비디오에서는 테스트를 통해 향후 코드 중단과 호환성 문제를 방지하고, 테스트를 통해 전체 개발 시간을 단축하고, 테스트를 통해 다른 사용자가 코드를 사용할 때 코드가 예상대로 동작한다는 것을 배웠습니다.

## 예시
- 이제 몇 가지 테스트 사례를 작성하는 데 소요되는 시간을 나중에 디버깅하는 데 드는 시간과 시간을 절약할 수 있습니다.

## 요약
- 이제 몇 가지 테스트 사례를 작성하는 데 소요되는 시간을 나중에 디버깅하는 데 드는 시간과 시간을 절약할 수 있습니다. 이 비디오에서는 테스트를 통해 향후 코드 중단과 호환성 문제를 방지하고, 테스트를 통해 전체 개발 시간을 단축하고, 테스트를 통해 다른 사용자가 코드를 사용할 때 코드가 예상대로 동작한다는 것을 배웠습니다.
