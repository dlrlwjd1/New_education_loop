# Course Introduction

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/test-and-behavior-driven-development-tdd-bdd/lecture/0yZqX/course-introduction)

## 개요
- Cucumber의 행동 기반 개발 현황 보고서에 따르면 행동 주도 개발 (BDD) 은 팀 협업을 재정의하고 있습니다.

## 내용
- Cucumber의 행동 기반 개발 현황 보고서에 따르면 행동 주도 개발 (BDD) 은 팀 협업을 재정의하고 있습니다.
- 이 강좌에서는 테스트 우선 접근 방식을 취하여 원하는 코드에 대한 테스트 케이스를 작성한 다음 통과하도록 코드를 작성하는 방법을 배웁니다.
- 이 강좌에서는 테스트 주도 개발과 행동 기반 개발을 통해 코딩 속도를 높일 수 있다는 자신감을 어떻게 얻을 수 있는지 살펴보겠습니다.
- TDD와 BDD 테스트 케이스를 통해 코드의 동작을 깨뜨렸는지 바로 알 수 있습니다.이 강좌의 TDD 섹션에서는 코드가 예상대로 작동하는지 확인하기 위해 테스트 어설션을 작성하는 방법을 배웁니다.
- 팩토리와 페이크를 사용하여 자체 테스트 데이터를 쉽게 생성하는 방법과 프로덕션 시스템의 샘플 테스트 데이터를 사용하는 방법을 배우게 됩니다.
- 이러한 도구를 사용하면 테스트 케이스가 포함된 코드의 비율을 확인하고 테스트 케이스가 없는 코드 줄을 확인할 수 있습니다.
- 모킹을 사용하여 테스트 케이스를 외부 영향으로부터 독립적으로 유지하고 다른 사람의 서비스가 아닌 코드 테스트에 초점을 맞추는 방법을 배우게 됩니다.

## 예시
- 팀의 74% 가 BDD 시나리오 작성에 여러 역할을 참여하여 협업이 개선될 뿐만 아니라 소프트웨어 품질도 향상되었습니다.

## 요약
- 이러한 도구를 사용하면 테스트 케이스가 포함된 코드의 비율을 확인하고 테스트 케이스가 없는 코드 줄을 확인할 수 있습니다. 모킹을 사용하여 테스트 케이스를 외부 영향으로부터 독립적으로 유지하고 다른 사람의 서비스가 아닌 코드 테스트에 초점을 맞추는 방법을 배우게 됩니다.
