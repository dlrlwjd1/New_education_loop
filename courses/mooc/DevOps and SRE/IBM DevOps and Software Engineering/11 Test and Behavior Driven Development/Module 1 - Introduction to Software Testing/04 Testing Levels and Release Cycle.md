# Testing Levels and Release Cycle

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/test-and-behavior-driven-development-tdd-bdd/lecture/SZ8GA/testing-levels-and-release-cycle)

## 개요
- 이 비디오를 시청한 후에는 소프트웨어 테스트 프로세스의 각 수준을 설명하고 기존 릴리스 주기의 각 단계를 요약할 수 있습니다.

## 내용
- 이 비디오를 시청한 후에는 소프트웨어 테스트 프로세스의 각 수준을 설명하고 기존 릴리스 주기의 각 단계를 요약할 수 있습니다.
- 가장 낮은 레벨은 유닛 테스트입니다.이 수준의 소프트웨어 테스트 프로세스에서는 소프트웨어 시스템의 개별 장치 또는 구성 요소를 테스트합니다.
- 이는 단일 개발자가 단일 모듈에서 수행하는 작업입니다.단위 테스트의 목적은 내 모듈이 작동하는지 확인하는 것입니다.
- 모듈에 예외를 포착하는 코드가 있는 경우 예외 핸들러가 제대로 작동하는지 테스트할 수 있도록 예외를 발생시키는 테스트 케이스를 작성해야 합니다.
- 그 목적은 시스템이 특정 요구 사항을 준수하는지 평가하고 전체 시스템이 함께 작동하는지 확인하는 것입니다.
- 맨 왼쪽에 있는 개발 환경은 개발자가 단위 테스트를 수행하고 Git과 같은 소스 코드 관리 시스템에 코드를 저장하는 곳입니다.
- 이제 소규모 개발 서버에서는 할 수 없는 통합 테스트, 성능 테스트, 규정 준수 테스트, 시스템 테스트, 승인 테스트와 같은 작업을 수행할 수 있습니다.

## 예시
- 이제 소규모 개발 서버에서는 할 수 없는 통합 테스트, 성능 테스트, 규정 준수 테스트, 시스템 테스트, 승인 테스트와 같은 작업을 수행할 수 있습니다.

## 요약
- 맨 왼쪽에 있는 개발 환경은 개발자가 단위 테스트를 수행하고 Git과 같은 소스 코드 관리 시스템에 코드를 저장하는 곳입니다. 이제 소규모 개발 서버에서는 할 수 없는 통합 테스트, 성능 테스트, 규정 준수 테스트, 시스템 테스트, 승인 테스트와 같은 작업을 수행할 수 있습니다.
