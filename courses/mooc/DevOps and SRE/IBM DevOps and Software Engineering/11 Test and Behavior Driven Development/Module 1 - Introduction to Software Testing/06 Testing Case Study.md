# Testing Case Study

## 개요
- 이 동영상을 시청한 후에는 테스트 사례를 사용하는 목적을 요약하고 개발자가 테스트되지 않은 코드를 절대 신뢰해서는 안 되는 이유를 설명할 수 있습니다.테스트가 왜 그렇게 중요한지 보여주는 테스트 사례 연구를 안내해 드리고자 합니다.한 줄의 코드로 얼마나 많은 문제가 발생할 수 있는지 보여줍니다.네, 한 줄의 코드입니다.뭐가 잘못될 수 있을까요?

## 내용
- 이 동영상을 시청한 후에는 테스트 사례를 사용하는 목적을 요약하고 개발자가 테스트되지 않은 코드를 절대 신뢰해서는 안 되는 이유를 설명할 수 있습니다.테스트가 왜 그렇게 중요한지 보여주는 테스트 사례 연구를 안내해 드리고자 합니다.한 줄의 코드로 얼마나 많은 문제가 발생할 수 있는지 보여줍니다.네, 한 줄의 코드입니다.뭐가 잘못될 수 있을까요?
- 함수를 정의하는 것부터 시작합니다.이것을 삼각형의 면적이라고 부릅니다.파이썬은 뱀의 대소문자를 사용하기 때문에 좋은 파이썬 규칙에 따라 밑줄을 사용하여 이름의 단어를 구분합니다.또한 계산에 사용할 함수에 전달되는 두 개의 매개변수 (base) 와 높이 (height) 를 정의합니다.이 함수는 한 줄의 코드로 구현할 수 있으므로 결과를 수식 베이스를 높이의 2배로 나눈 값을 반환합니다.이 시점에서 당신은 자신을 매우 자랑스럽게 생각합니다.뭐가 잘못될 수 있을까요?한 줄의 코드입니다.끝났어요.
- 프로덕션에 적용하세요.다음 작업으로 넘어가세요.그런 다음 코드를 위해 작성한 몇 가지 테스트 사례를 작성하여 코드를 테스트해야 한다는 점을 기억하세요.테스트 케이스는 샘플 데이터와 같은 일부 알려진 입력이 주어지면 이를 사용하여 코드를 호출하고 예상 출력을 테스트할 수 있는 코드입니다.테스트 케이스를 사용하여 코드가 제대로 작동하는지 확인합니다.따라서 특정 테스트 프레임워크를 사용하지 않고 Python으로 몇 가지 테스트를 작성하는 것으로 시작합니다.
- 함수를 처음부터 강력한 방식으로 작성하면 다음과 같은 모습입니다.이 함수에는 몇 가지 유형 힌트가 포함되어 있습니다.발신자가 잘못된 데이터를 전달하는 것을 막지는 못하지만 최소한 예상하는 데이터 유형을 알 수 있습니다.이 경우에는 부동 소수점 숫자가 필요합니다.또한 이 함수에는 문서 문자열이 포함되어 있어 개발자들에게 음수가 아닌 숫자를 기대한다는 사실을 알릴 수 있습니다.다음으로 코드에 추가할 사항은 올바른 유형을 받았는지 확인하는 것입니다.
- float 힌트는 좋지만 Python에서는 어떤 유형이든 전달할 수 있으므로 명시적으로 확인해야 합니다.기본 유형 또는 높이 유형이 목록 int 또는 float에 없으면 기본 또는 높이가 숫자여야 한다는 메시지와 함께 유형 오류 예외가 발생합니다.따라서 예상했던 유형의 숫자가 아닌 모든 것을 즉시 제거할 수 있습니다.이렇게 하면 불리언, 문자열, 딕셔너리, 목록 등 함수가 처리할 수 없는 복소수를 포함하여 던지고 싶은 기타 모든 파이썬 유형과 같은 유형이 제거됩니다.데이터가 이 검사를 통과하면 int 또는 부동 소수점 숫자가 있음을 알 수 있습니다.다음으로 양수인지 확인합니다.
- 너무 광범위한 예외를 제기하는 것을 피하고 가능한 한 명시적으로 말하고 싶다는 점을 지적하고 싶습니다.값 오류는 오류를 일으킨 원인에 따라 밑수가 양수이거나 높이가 양수여야 한다는 메시지를 반환합니다.호출자에게 어떤 매개변수로 인해 오류가 발생했는지 알려주는 것이 중요합니다.이렇게 하면 발신자에게 양수로 보내야 한다는 좋은 정보가 제공됩니다.마지막으로 기본 코드의 1/2에 높이를 곱한 계산을 수행하고 결과를 반환하는 원래 코드 한 줄을 얻습니다.이것이 바로 코드 한 줄을 취미로 작성하는 것과 프로덕션에 적용하려는 코드를 개발하는 데 좋은 소프트웨어 엔지니어링 방법을 적용하는 것의 차이입니다.
- 효과가 있는 것처럼 보일지 모르지만 바보 같은 데이터를 던지면 폭발할 거라고 장담할 수 있습니다.코드에 그런 일이 발생하는 것을 원하지 않을 것입니다.테스트 케이스를 사용하면 코드가 어떤 방식으로 중단될 수 있는지 생각한 다음 코드를 깨뜨리는 테스트 케이스를 작성한 다음 코드가 다시 정상적으로 실패하고 테스트 케이스가 통과되도록 하는 데 필요한 코드를 작성해야 합니다.이 비디오에서는 개발자가 테스트 케이스를 사용하여 코드가 제대로 작동하는지 확인하는 방법을 배웠습니다.테스트 케이스는 개발자가 코드에서 손상될 수 있는 부분을 식별하고 수정하는 데 도움이 됩니다.
