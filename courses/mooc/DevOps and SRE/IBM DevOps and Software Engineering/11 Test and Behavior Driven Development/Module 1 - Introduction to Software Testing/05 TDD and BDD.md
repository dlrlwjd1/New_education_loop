# TDD and BDD

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/test-and-behavior-driven-development-tdd-bdd/lecture/gNrGR/tdd-and-bdd)

## 개요
- 이 비디오를 시청한 후에는 테스트 기반 개발과 행동 기반 개발을 비교 및 대조하고 개발자에게 TDD와 BDD가 모두 필요한 이유를 설명할 수 있습니다.

## 내용
- 이 비디오를 시청한 후에는 테스트 기반 개발과 행동 기반 개발을 비교 및 대조하고 개발자에게 TDD와 BDD가 모두 필요한 이유를 설명할 수 있습니다.
- 행동 기반 개발은 이름에서 알 수 있듯이 시스템이 내부에서 작동하는 방식의 세부 사항이 아니라 외부에서 관찰된 시스템의 동작에 초점을 맞춥니다.
- BDD는 외부에서 시스템에 초점을 맞추는 반면, 테스트 기반 개발은 시스템이 내부에서 어떻게 작동하는지에 초점을 맞춥니다.
- 직관적이지 않게 들릴 수도 있습니다.예를 들어, 아직 코드를 작성하지 않은 테스트용 코드를 작성하려면 어떻게 해야 할까요?
- 따라서 행동 기반 개발은 외부에서 시스템의 동작을 테스트하고 시스템이 어떻게 작동해야 하는지를 고려합니다.
- 각 구성 요소가 제대로 작동하는지 확인하고 BDD는 모든 구성 요소가 더 높은 수준에서 함께 작동하는지 확인합니다.
- 이 비디오에서는 BDD가 외부 시스템에 초점을 맞추고 TDD는 내부 시스템에 초점을 맞추는 것을 배웠습니다.

## 예시
- 직관적이지 않게 들릴 수도 있습니다.예를 들어, 아직 코드를 작성하지 않은 테스트용 코드를 작성하려면 어떻게 해야 할까요?

## 요약
- 각 구성 요소가 제대로 작동하는지 확인하고 BDD는 모든 구성 요소가 더 높은 수준에서 함께 작동하는지 확인합니다. 이 비디오에서는 BDD가 외부 시스템에 초점을 맞추고 TDD는 내부 시스템에 초점을 맞추는 것을 배웠습니다.
