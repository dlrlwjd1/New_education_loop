# Tools for TDD

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/test-and-behavior-driven-development-tdd-bdd/lecture/nESA0/tools-for-tdd)

## 개요
- 이 비디오를 시청한 후에는 테스트 주도 개발에 널리 사용되는 테스트 도구를 나열하고 테스트 주도 개발을 위한 인기 있는 Python 테스트 도구의 기능을 요약할 수 있습니다.

## 내용
- 이 비디오를 시청한 후에는 테스트 주도 개발에 널리 사용되는 테스트 도구를 나열하고 테스트 주도 개발을 위한 인기 있는 Python 테스트 도구의 기능을 요약할 수 있습니다.
- 자동화된 테스트를 통해 개발자는 수동 테스트에서 벗어나고 테스트 주도 개발과 같은 기술을 사용하여 테스트를 작성하는 방식을 변경할 수 있습니다.
- XUnit의 모든 버전은 공통 구문을 공유하므로 한 언어에 대해 한 버전을 배웠다면 다른 버전을 배우는 것이 훨씬 쉽습니다.
- Ruby on Rails 코드를 작성할 때 TDD를 처음 배웠기 때문에 RSpec 코드를 많이 작성했는데 Python에서 구문을 지원한다는 사실에 만족했습니다.
- Python에서 가장 많이 사용되는 두 가지 테스트 프레임워크는 PyUnit과 Pytest입니다.
- Python에서 널리 사용되는 두 가지 다른 테스트 프레임워크는 Doctest와 RSpec입니다.
- Nose는 테스트 출력에 색상을 추가한 다음 코드 커버리지 도구를 호출할 수 있는 Python 테스트 러너입니다.

## 예시
- 이 보고서를 사용하여 누락된 코드 줄을 찾고 어디에서 더 많은 테스트 사례를 작성해야 하는지 알 수 있습니다.

## 요약
- Python에서 널리 사용되는 두 가지 다른 테스트 프레임워크는 Doctest와 RSpec입니다. Nose는 테스트 출력에 색상을 추가한 다음 코드 커버리지 도구를 호출할 수 있는 Python 테스트 러너입니다.
