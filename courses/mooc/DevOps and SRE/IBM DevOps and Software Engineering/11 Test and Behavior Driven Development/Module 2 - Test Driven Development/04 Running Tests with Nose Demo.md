# Running Tests with Nose Demo

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/test-and-behavior-driven-development-tdd-bdd/lecture/6VJjN/running-tests-with-nose-demo)

## 개요
- 이제 각 테스트 스위트, Python 파일의 테스트 클래스에 있는 테스트 케이스는 긴 테스트 줄 대신 헤더가 있는 작은 섹션과 그 아래에 있는 모든 테스트로 표시됩니다.

## 내용
- 이제 각 테스트 스위트, Python 파일의 테스트 클래스에 있는 테스트 케이스는 긴 테스트 줄 대신 헤더가 있는 작은 섹션과 그 아래에 있는 모든 테스트로 표시됩니다.
- 그래서 실패한 테스트 케이스에 대한 멋진 빨간색 테스트 케이스가 나타납니다.
- 취재를 통해 제가 할 수 있는 또 다른 일은 누락된 코드 줄에 대한 보고서를 실행하는 것입니다.
- 따라서 누락에 대한 커버리지 리포트 -m이라고 하면 이제 누락된 코드 줄이 추가되지만 적용 범위가 100% 이기 때문에 아무 것도 없습니다.
- 정수 또는 부동 소수점이어야 합니다.다시 triangle.py 로 돌아가서 Boolean이라는 문자열인 Boolean을 바로 전달하는 테스트 케이스를 찾을 수 있습니다.
- 실험실에 있을 때는 멋진 컬러 출력을 얻고, 프로젝트를 진행할 때는 Nose를 설치해도 아무 것도 얻을 수 없어요.”이 모든 매개 변수가 설정 파일에 있고 피노키오가 사양과 색상을 추가하고 커버리지 도구가 커버리지 보고서를 추가하고 있다는 것을 알려 주셨으면 좋겠어요.
- 이제 setup.cfg 파일을 가져와서 저장소의 루트에 넣으면 프로젝트의 테스트 결과물이 여기 있는 것과 똑같이 멋지게 보일 수 있습니다.

## 예시
- 실습을 통해 실험실에서 무엇을 기대할 수 있는지 보여 드리고자 합니다.

## 요약
- 실험실에 있을 때는 멋진 컬러 출력을 얻고, 프로젝트를 진행할 때는 Nose를 설치해도 아무 것도 얻을 수 없어요.”이 모든 매개 변수가 설정 파일에 있고 피노키오가 사양과 색상을 추가하고 커버리지 도구가 커버리지 보고서를 추가하고 있다는 것을 알려 주셨으면 좋겠어요. 이제 setup.cfg 파일을 가져와서 저장소의 루트에 넣으면 프로젝트의 테스트 결과물이 여기 있는 것과 똑같이 멋지게 보일 수 있습니다.
