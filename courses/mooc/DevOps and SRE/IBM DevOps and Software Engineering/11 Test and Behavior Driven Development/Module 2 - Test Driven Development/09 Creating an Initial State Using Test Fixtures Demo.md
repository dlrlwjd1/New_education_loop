# Creating an Initial State Using Test Fixtures Demo

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/test-and-behavior-driven-development-tdd-bdd/lecture/amy2R/creating-an-initial-state-using-test-fixtures-demo)

## 개요
- 따라서 데이터베이스를 초기화하는 몇 가지 테스트 케이스를 작성한 다음 테스트 픽스처를 사용하여 일부 데이터를 초기화한 다음 해당 클래스에 대해 몇 가지 테스트 케이스를 작성할 것입니다.

## 내용
- 따라서 데이터베이스를 초기화하는 몇 가지 테스트 케이스를 작성한 다음 테스트 픽스처를 사용하여 일부 데이터를 초기화한 다음 해당 클래스에 대해 몇 가지 테스트 케이스를 작성할 것입니다.
- 맞아요.따라서 설치 클래스는 모든 테스트 전에 한 번, 즉 한 번 실행된 다음 모든 테스트가 실행되고 테어 다운 클래스가 실행됩니다.
- 이게 할 일은 모든 테이블을 생성하고, 데이터베이스에 연결하고, 모든 테스트 실행 전에 모든 테이블을 생성하는 것입니다.
- 그래서 저는 ACCOUNT_DATA = 로 가서 JSON.load를 호출하고 열린 파일을 나타내는 JSON 데이터를 로드하라고 말할 것입니다.
- 그런 다음 이 파일을 열고 여기에 계정 데이터를 로드하고 싶습니다.이제 코 테스트를 다시 실행하여 오류와 오류가 없는지 확인해 보겠습니다.
- 그래서 제가 한 일은 모든 테스트 전에 실행을 설정하고 모든 테스트 후에 실행을 해체하는 것입니다.
- 특히 테스트 픽스처를 사용하여 데이터를 로드하여 테스트를 실행하기 전에 필요한 모든 종류의 계정이나 모든 종류의 정보를 데이터베이스에 로드할 수 있습니다.

## 예시
- 특히 테스트 픽스처를 사용하여 데이터를 로드하여 테스트를 실행하기 전에 필요한 모든 종류의 계정이나 모든 종류의 정보를 데이터베이스에 로드할 수 있습니다.

## 요약
- 그래서 제가 한 일은 모든 테스트 전에 실행을 설정하고 모든 테스트 후에 실행을 해체하는 것입니다. 특히 테스트 픽스처를 사용하여 데이터를 로드하여 테스트를 실행하기 전에 필요한 모든 종류의 계정이나 모든 종류의 정보를 데이터베이스에 로드할 수 있습니다.
