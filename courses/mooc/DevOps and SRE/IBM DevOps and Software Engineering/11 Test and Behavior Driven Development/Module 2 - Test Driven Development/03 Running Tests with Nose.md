# Running Tests with Nose

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/test-and-behavior-driven-development-tdd-bdd/lecture/91maE/running-tests-with-nose)

## 개요
- Nose 모듈을 사용하여 단위 테스트를 실행하고, unittest와 Nose가 제공하는 단위 테스트 보고서를 대조해 봅시다.

## 내용
- Nose 모듈을 사용하여 단위 테스트를 실행하고, unittest와 Nose가 제공하는 단위 테스트 보고서를 대조해 봅시다.
- Python 단위 테스트를 실행하는 두 가지 방법, 즉 기본 Python 테스트 실행기인 unittest와 코드의 버그를 “스니핑”하기 위한 Nose라는 도구에 대해 이야기해 보겠습니다.
- 파일을 가리키면서 단일 테스트를 실행할 수도 있지만 unittest가 test 폴더에 있는 모든 테스트를 실행하도록 하려고 하므로 검색 모드를 사용하겠습니다.
- Nose는 훨씬 더 자세한 유용한 보고서를 제공하므로 기본 유닛 테스트 러너 대신 사용하고 싶습니다.테스트 출력에 색상을 추가하는 Pinocchio라는 플러그인으로 Nose를 실행하는 방법을 살펴보겠습니다.
- 디폴트 유닛 테스트 러너와 nosetest 모두 이와 같이 더 자세한 출력을 생성할 수 있지만, 오직 nosetest만이 적록색 출력을 얻을 수 있도록 색상을 지정할 수 있습니다.
- 이 정보를 사용하여 해당 줄 번호의 코드를 검토하고 어떤 테스트를 작성할 수 있는지 파악할 수 있습니다.해당 코드 경로를 사용하여 해당 라인을 실행할 수 있는 테스트 케이스에 대해 어떻게 생각할 수 있을까요?
- unittest는 간단한 단위 테스트 보고서를 제공하고, Nose는 더 자세한 보고서를 제공하며, Nose는 테스트 결과에 색상을 지정하고, 코드 적용 범위를 보고하고, 누락된 테스트 사례를 나열할 수 있습니다.

## 예시
- 테스트를 실행하면 모든 성공적인 테스트 사례에 대해 화면에 점이 표시됩니다.
