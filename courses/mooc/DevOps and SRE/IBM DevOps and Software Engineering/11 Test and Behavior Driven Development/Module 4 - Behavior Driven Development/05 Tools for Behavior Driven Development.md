# Tools for Behavior Driven Development

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/test-and-behavior-driven-development-tdd-bdd/lecture/B5xEn/tools-for-behavior-driven-development)

## 개요
- 이 비디오를 시청한 후에는 오이, 동작 및 Concordion을 포함한 BDD 도구의 기능을 요약하고 BDD 도구를 선택할 때 고려해야 할 요소를 나열할 수 있습니다.

## 내용
- 이 비디오를 시청한 후에는 오이, 동작 및 Concordion을 포함한 BDD 도구의 기능을 요약하고 BDD 도구를 선택할 때 고려해야 할 요소를 나열할 수 있습니다.
- 선택할 수 있는 BDD 도구가 많이 있으며, 그중에서도 Ruby, .NET, Python, Java, Java, JavaScript 및 PHP와 같은 인기 있는 프로그래밍 언어에 대한 지원을 찾을 수 있습니다.
- 실제로 Cucumber 웹사이트에서 Python 버전을 확인하면 Beare 웹 사이트로 연결되므로 Behave는 Cucumber의 Python 버전이라고 말할 수 있습니다.
- 또한 다양한 단계에서 환경을 설정하고 해제할 수 있는 환경 설정 및 테스트 픽스처를 지원하므로 테스트 환경을 완벽하게 제어할 수 있습니다.
- 모든 BDD 도구가 지원하는 것은 아니기 때문에 Gherkin은 이해관계자와 개발자 모두가 쉽게 작성하고 이해할 수 있는 간단한 구문을 제공하기 때문에 항상 지원하는 도구를 찾고 있습니다.
- Cucumber 및 Behave와 같은 도구는 Gherkin 구문을 사용하는 반면 Concordion과 같은 도구는 다른 사양 구문을 사용합니다.
- 도구를 선택할 때는 해당 도구가 지원하는 프로그래밍 언어와 사양 구문을 고려해야 합니다.

## 요약
- Cucumber 및 Behave와 같은 도구는 Gherkin 구문을 사용하는 반면 Concordion과 같은 도구는 다른 사양 구문을 사용합니다. 도구를 선택할 때는 해당 도구가 지원하는 프로그래밍 언어와 사양 구문을 고려해야 합니다.
