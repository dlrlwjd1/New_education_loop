# Overview of Behave

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/test-and-behavior-driven-development-tdd-bdd/lecture/nGaXi/overview-of-behave)

## 개요
- 이 비디오를 시청한 후에는 Behave를 실행하기 위한 폴더 구조 및 파일 이름 규칙을 설명하고 Behave가 기능 및 단계 파일의 코드를 사용하여 단계 함수를 실행하는 방법을 요약할 수 있습니다.

## 내용
- 이 비디오를 시청한 후에는 Behave를 실행하기 위한 폴더 구조 및 파일 이름 규칙을 설명하고 Behave가 기능 및 단계 파일의 코드를 사용하여 단계 함수를 실행하는 방법을 요약할 수 있습니다.
- Behave는 각 기능 파일의 단계를 읽고, 단계 파일에서 일치하는 Python 단계를 찾고, 해당 함수를 실행합니다.
- 그런 다음 해당 시나리오의 첫 문장인 “일부 알려진 상태가 주어짐”을 처리합니다.이제 Behave는 Given 키워드로 시작하고 “일부 알려진 상태”라는 텍스트가 있는 Python 단계를 찾습니다.
- And는 Given 다음에 오므로 Behave는 단계 파일에서 Given 키워드로 시작하고 “다른 알려진 상태”라는 문자열과 일치하는 Python 단계를 찾습니다.
- 다음으로 행동 프로세스 “그러면 일부 결과가 관찰됩니다.” “일부 결과가 관찰되었습니다”라는 텍스트가 있는 Then 단계를 찾고 해당 함수를 실행합니다.
- Behave를 실행하려면 기능 파일을 위한 기능 폴더를 만들고 그 아래에 Python 단계 파일을 위한 단계 폴더를 만들어야 합니다.
- Behave는 각 기능 파일의 단계를 읽고 단계 파일에서 일치하는 Python 단계를 찾은 다음 해당 함수를 실행합니다.

## 예시
- 저는 보통 이 파일을 사용하여 시나리오를 설정하기 위해 샘플 데이터를 로드합니다.

## 요약
- Behave를 실행하려면 기능 파일을 위한 기능 폴더를 만들고 그 아래에 Python 단계 파일을 위한 단계 폴더를 만들어야 합니다. Behave는 각 기능 파일의 단계를 읽고 단계 파일에서 일치하는 Python 단계를 찾은 다음 해당 함수를 실행합니다.
