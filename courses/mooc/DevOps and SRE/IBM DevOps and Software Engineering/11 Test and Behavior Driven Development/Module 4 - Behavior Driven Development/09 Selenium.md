# Selenium

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/test-and-behavior-driven-development-tdd-bdd/lecture/M3YZO/selenium)

## 개요
- 이 비디오를 시청한 후에는 Selenium에 대해 설명하고 BDD 테스트에 대한 가치에 대해 논의하고 Selenium을 초기화하는 데 필요한 단계를 나열하고 Selenium을 사용하여 HTML 요소를 찾고 조작하는 방법을 요약할 수 있습니다.

## 내용
- 이 비디오를 시청한 후에는 Selenium에 대해 설명하고 BDD 테스트에 대한 가치에 대해 논의하고 Selenium을 초기화하는 데 필요한 단계를 나열하고 Selenium을 사용하여 HTML 요소를 찾고 조작하는 방법을 요약할 수 있습니다.
- Selenium의 핵심은 WebDriver로, 몇 가지 예를 들자면 Chrome, Firefox, Safari 및 Edge와 같은 널리 사용되는 브라우저에서 상호 교환하여 실행할 수 있는 명령 세트를 작성하는 인터페이스입니다.
- 필드에 데이터를 입력하고, 필드에서 데이터를 다시 읽고, 링크를 클릭하고, 버튼을 클릭하는 등 실제 사용자가 할 수 있는 모든 작업을 수행할 수 있습니다.
- 셀레늄은 클래스 이름, CSS 선택기, ID 이름, XPath, 링크, 부분 링크, 텍스트 태그 이름으로 요소를 찾을 수 있습니다.
- Selenium에는 웹 페이지에서 여러 요소를 찾는 S로 요소를 찾는 버전도 있습니다.
- 해당 요소를 지운 다음 send keys 함수를 사용하여 입력 필드에 텍스트 문자열을 입력할 수 있습니다.
- Selenium으로 HTML을 조작하려면 요소를 찾는 방법을 선택하고 해당 요소로 수행할 작업을 지정해야 합니다.

## 예시
- 이 예시에서는 Chrome 드라이버의 몇 가지 옵션을 설정해 보겠습니다.

## 요약
- 해당 요소를 지운 다음 send keys 함수를 사용하여 입력 필드에 텍스트 문자열을 입력할 수 있습니다. Selenium으로 HTML을 조작하려면 요소를 찾는 방법을 선택하고 해당 요소로 수행할 작업을 지정해야 합니다.
