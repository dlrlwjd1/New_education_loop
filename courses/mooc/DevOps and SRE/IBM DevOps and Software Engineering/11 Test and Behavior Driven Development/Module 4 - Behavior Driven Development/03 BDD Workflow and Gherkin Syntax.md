# BDD Workflow and Gherkin Syntax

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/test-and-behavior-driven-development-tdd-bdd/lecture/FbcxG/bdd-workflow-and-gherkin-syntax)

## 개요
- 이 비디오를 시청하고 나면 행동 기반 개발 워크플로를 요약하고 Given, When, Then, And, But 키워드를 Gherkin 구문으로 사용하는 방법을 설명할 수 있습니다.BDD 워크플로를 단계별로 살펴보겠습니다.

## 내용
- 이 비디오를 시청하고 나면 행동 기반 개발 워크플로를 요약하고 Given, When, Then, And, But 키워드를 Gherkin 구문으로 사용하는 방법을 설명할 수 있습니다.BDD 워크플로를 단계별로 살펴보겠습니다.
- Behave는 Gherkin 구문을 분석하고 시스템이 예상대로 작동하는지 확인하는 데 사용할 수 있는 테스트 단계를 찾습니다.Behare를 사용하여 이 예제를 실행하면 어떤 테스트 단계가 누락되었는지 알 수 있습니다.
- 팀이 솔루션을 개발하는 동안 Behave는 어떤 예제가 구현되어 있고 효과가 있는지 알려주고 그렇지 않은 예제에 대해서는 경고를 해주는데, 어느새 소프트웨어의 사양이자 테스트 역할을 하는 하나의 문서가 생깁니다.이는 시스템이 어떻게 작동해야 하는지를 정확히 나타냅니다.
- “장바구니에 물건이 두 개 있으니 말이에요.” 라고 적을 수도 있습니다.그러면 테스트 시스템에 작업을 진행하기 전에 장바구니에 두 개의 품목이 있는지 확인해야 한다는 메시지가 표시됩니다.
- “이런 일이 일어날 때, 그리고 그 일이 일어난다” 또는 “그러면 이것이 관찰되고 저것은 관찰된다”라고 쓸 수도 있습니다.
- 이 동영상에서는 BDD 워크플로우에서 원하는 동작을 설명하는 예제를 만들고, 해당 예제를 자동화된 테스트로 실행하고, 필요에 따라 추가 테스트를 작성하는 방법을 배웠습니다.
- Gherkin 구문으로 예제를 만들려면 Given, When, Then, And, Bit 키워드를 사용하여 예제를 단계별로 구분합니다.

## 예시
- 먼저 개발자, 테스터, 이해 관계자가 문제 영역을 탐색하여 모든 사람이 문제를 이해하도록 하고, 협업하여 원하는 동작을 설명하는 구체적인 예시나 시나리오를 생성합니다.

## 요약
- 이 동영상에서는 BDD 워크플로우에서 원하는 동작을 설명하는 예제를 만들고, 해당 예제를 자동화된 테스트로 실행하고, 필요에 따라 추가 테스트를 작성하는 방법을 배웠습니다. Gherkin 구문으로 예제를 만들려면 Given, When, Then, And, Bit 키워드를 사용하여 예제를 단계별로 구분합니다.
