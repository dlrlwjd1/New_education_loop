# Environment Setup

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/test-and-behavior-driven-development-tdd-bdd/lecture/mcfCF/environment-setup)

## 개요
- 이 동영상을 시청한 후 Behave에서 각 테스트 픽스처를 설명하고 Behave에서 테스트 환경을 설정하고 테스트 픽스처를 선언하는 프로세스를 요약할 수 있습니다.

## 내용
- 이 동영상을 시청한 후 Behave에서 각 테스트 픽스처를 설명하고 Behave에서 테스트 환경을 설정하고 테스트 픽스처를 선언하는 프로세스를 요약할 수 있습니다.
- Behave에는 기능 시나리오 , 단계 또는 태그 이전 또는 이후에 실행하여 테스트 실행 환경을 제어할 수 있는 테스트 픽스처 세트가 있습니다.
- 이름에서 알 수 있듯이 이러한 픽스쳐에 삽입한 코드는 모든 기능보다 먼저 한 번 실행되고 모든 기능 이후에 다시 실행됩니다.
- 또한 이 세트는 모든 단계에서 액세스할 수 있는 컨텍스트 값을 설정하고 Behave가 모든 기능을 처리한 후 드라이버를 종료하는 데에도 적합합니다.
- 여러 기능을 사용하는 경우 이 세트는 각 기능 실행 전후에 깨끗한 환경을 설정하는 데 이상적입니다.
- 다시 말하지만, 이 컨텍스트는 각 단계별로 파싱되므로 context.driver를 참조하기만 하면 모든 단계가 WebDriver에 액세스할 수 있으며 이를 사용하여 UI에서 작업을 구동할 수 있습니다.
- 이 비디오에서는 Behave에 기능, 시나리오, 단계 또는 태그 이전 또는 이후에 실행할 수 있는 테스트 픽스처 세트가 있다는 것을 배웠습니다.

## 예시
- Behave에는 기능 시나리오 , 단계 또는 태그 이전 또는 이후에 실행하여 테스트 실행 환경을 제어할 수 있는 테스트 픽스처 세트가 있습니다.

## 요약
- 다시 말하지만, 이 컨텍스트는 각 단계별로 파싱되므로 context.driver를 참조하기만 하면 모든 단계가 WebDriver에 액세스할 수 있으며 이를 사용하여 UI에서 작업을 구동할 수 있습니다. 이 비디오에서는 Behave에 기능, 시나리오, 단계 또는 태그 이전 또는 이후에 실행할 수 있는 테스트 픽스처 세트가 있다는 것을 배웠습니다.
