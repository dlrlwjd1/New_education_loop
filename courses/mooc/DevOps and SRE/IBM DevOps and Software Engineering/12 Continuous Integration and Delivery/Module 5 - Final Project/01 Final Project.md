# Final Project

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/continuous-integration-and-continuous-delivery-ci-cd/lecture/LUIfw/final-project)

## 개요
- 코스 전체에서 배운 CI/CD·GitOps 지식을 실제로 종합해보는 최종 프로젝트 소개 — 샘플 애플리케이션에 GitHub Actions 기반 CI 파이프라인과 OpenShift Pipelines 기반 CD 파이프라인을 직접 구축.

## 내용
### 프로젝트 개요
- 필수 모듈을 모두 마쳤으니 이제 DevOps, CI/CD, GitOps의 세계에서 배운 모든 것을 하나의 최종 프로젝트로 종합할 차례 — 이론이 실제 구현과 만나는 지점이며, 그 중심에 학습자가 있음.

### 1단계 — 사전 준비
- Git 저장소에서 소스 코드를 클론 — 이것이 이제 학습자의 소스 코드가 되며, 이 최종 프로젝트의 미션은 이 애플리케이션에 CI와 CD 파이프라인을 추가하는 것.

### 2단계 — CI 파이프라인 만들기
- Git Feature Branch 워크플로우를 이용해 CI 파이프라인을 만듦 — GitHub Actions 지식을 실전에 적용.
- CI 파이프라인은 린팅(linting), 단위 테스트, 이미지 생성과 태깅을 포함해, 코드가 다듬어지고 테스트되어 실행 준비가 되었음을 보장.

### 3단계 — CD 파이프라인 만들기
- 스포트라이트가 CD 파이프라인으로 옮겨감 — **OpenShift Pipelines**를 깊이 파고들어 애플리케이션을 실제 세계에 배포하는 워크플로우를 설계.
- 소스 코드와 린팅, 테스트부터 이미지 생성, 그리고 최종적으로 OpenShift 클러스터로의 배포까지 이어지는 애플리케이션의 매끄러운 파이프라인을 계획.

### 증거(Evidence) 수집
- 프로젝트 전반에 걸쳐 증거를 수집하도록 요청받게 되므로, 최종 제출을 위해 안전한 곳에 저장해둬야 함.

### 마무리 당부
- 이 프로젝트는 배운 모든 것을 실전에 적용할 기회 — 단순히 파이프라인에 관한 것이 아니라, 견고하고 효율적이며 신뢰할 수 있는 소프트웨어를 전달하기 위한 도구와 개념들의 시너지를 이해하는 것에 관한 것.

## 요약
- 최종 프로젝트는 샘플 애플리케이션 저장소를 클론한 뒤, Git Feature Branch 워크플로우와 GitHub Actions로 린팅·단위 테스트·이미지 생성/태깅을 포함한 CI 파이프라인을 구축하고, OpenShift Pipelines로 소스 코드부터 테스트·이미지 생성·OpenShift 클러스터 배포까지 이어지는 CD 파이프라인을 설계함으로써, 코스에서 배운 CI/CD·GitOps 지식과 도구들의 시너지를 실전에서 종합하는 과제이다.
