# Summary & Highlights: Understanding Continuous Delivery

> MOOC 읽기 자료 · [원본 강의](https://www.mooc.org/learn/continuous-integration-and-continuous-delivery-ci-cd/supplement/7t8qv/summary-highlights-understanding-continuous-delivery)

## 개요
- Module 3 전반부(CD 개념·원칙·모범 사례·도구)까지의 핵심 내용을 정리한 공식 요약.

## 내용
- Continuous Delivery(CD)는 업데이트된 소프트웨어가 릴리스 준비가 되었는지 확인하기 위해 코드 변경 사항을 프로덕션과 유사한 환경에 자동으로 전달하는 소프트웨어 개발 관행.
- CD는 배포 시간 단축, 비용 절감, 프로젝트 규모에 따른 확장 등 많은 이점을 가짐.
- CD의 5가지 핵심 원칙:
  - 품질을 내장해야 함.
  - 작은 배치 단위로 작업해야 함.
  - 사람은 반복 작업이 아니라 문제 해결을 해야 함.
  - 지속적 개선을 끊임없이 추구해야 함.
  - 모두가 자신의 몫에 책임을 짐.
- CD 모범 사례에는 모든 변경을 릴리스 가능하게 만들기, 가능한 한 많은 프로세스 자동화, 애플리케이션 다운타임 없음 보장 등이 포함(이에 국한되지 않음).
- CI/CD 파이프라인은 코드 저장소, 빌드 서버, 통합 서버, 저장소를 필요로 함.
- Continuous Deployment는 프리프로덕션 환경에서 프로덕션으로 코드를 자동으로 배포하는 관행.
- CD 도구는 기능이 풍부하고, 사용하기 쉽고, 호환성이 높고, 유지보수 부담이 낮아야 함.
- CD 파이프라인 안의 도구들은 스캐닝과 배포 작업을 처리해야 함.

## 요약
- Module 3의 CD 관련 강의는 CD를 프로덕션과 유사한 환경으로의 자동화된 코드 전달로 정의하고, 5대 원칙(품질 내장, 작은 배치, 사람은 문제 해결에 집중, 지속적 개선, 공동 책임)과 모범 사례, CI/CD 파이프라인의 필수 구성 요소, 그리고 기능성·사용성·호환성·유지보수성을 갖춘 CD 도구 선택의 중요성을 요약한다.
