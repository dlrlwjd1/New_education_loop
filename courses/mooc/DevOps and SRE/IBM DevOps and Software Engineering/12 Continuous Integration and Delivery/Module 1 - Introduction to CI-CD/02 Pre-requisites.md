# Pre-requisites

> MOOC 읽기 자료 · [원본 강의](https://www.mooc.org/learn/continuous-integration-and-continuous-delivery-ci-cd/supplement/sJM5y/pre-requisites)

## 개요
- 이 코스를 듣기 전에 갖추고 있어야 할 선수 지식 목록.

## 내용
- IT와 클라우드 컴퓨팅 기초.
- DevOps 원칙.
- 컨테이너와 Kubernetes 기초.
- Linux 명령어.
- Git과 GitHub.
- 이 수준의 지식이 없다면, 관련 스킬을 배울 수 있는 코스(전문과정 내 앞선 강좌들)를 먼저 수강할 것을 권장.

## 요약
- 이 CI/CD 코스는 IT·클라우드·DevOps·컨테이너/Kubernetes·Linux·Git/GitHub에 대한 기초 지식을 이미 갖춘 학습자를 대상으로 하며, 전문과정의 앞선 강좌들(01~11)이 이 선수 지식을 제공한다.
