# Module 1 - Introduction to CI/CD

> MOOC 영상 · [원본 강의](https://www.mooc.org/learn/continuous-integration-and-continuous-delivery-ci-cd/lecture/rdNi4/module-1-introduction-to-ci-cd)

## 개요
- Module 1의 도입부 — CI/CD가 반복 가능하고 신뢰할 수 있게 소프트웨어를 개발·전달하는 자동화된 접근 방식임을 소개하고, 이번 모듈에서 다룰 내용을 미리 안내.

## 내용
- CI와 CD가 각각 무엇인지, 그리고 DevOps 파이프라인에 제대로 구현했을 때 얻는 이점을 다룸.
- 인기 있는 CI/CD 도구들을 살펴보고, 수동 절차를 없애기만 한다면 조직 내 서로 다른 팀이 서로 다른 CI/CD 도구를 사용해도 괜찮은 이유를 설명.
- **Infrastructure as Code(IaC)**도 다룸 — 코드를 사용해 인프라의 프로비저닝과 관리를 자동화하는 과정으로, 자동화 구현의 기초가 되는 개념.
- 이번 첫 모듈에는 실습(lab)이 없음 — 목표는 각 주제를 깊이 파고들기 전에 CI/CD가 무엇인지 높은 수준에서 이해하는 것.

## 요약
- Module 1은 CI/CD의 정의와 이점, 다양한 CI/CD 도구의 공존 가능성, 그리고 자동화의 기초 개념인 Infrastructure as Code를 실습 없이 개괄적으로 소개하는 도입 모듈이다.
