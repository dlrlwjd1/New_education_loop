# Summary & Highlights: Introduction to CI/CD

> MOOC 읽기 자료 · [원본 강의](https://www.mooc.org/learn/continuous-integration-and-continuous-delivery-ci-cd/supplement/M8UI8/summary-highlights-introduction-to-ci-cd)

## 개요
- Module 1의 핵심 내용을 정리한 공식 요약.

## 내용
- CI(Continuous Integration)와 CD(Continuous Delivery)는 순차적으로 일어나는 두 개의 별개 프로세스.
- CI는 개발자가 코드를 메인 브랜치에 지속적으로 통합하는 데 사용하는 자동화 프로세스.
- CD는 이렇게 통합된 코드를 스테이징, 테스트, 프리프로덕션 서버 같은 곳에 자동으로 배포.
- CI는 **Plan, Code, Build, Test** 단계로 구성.
- CD는 **Release, Deploy, Operate** 단계로 구성.
- 조직 내 서로 다른 팀이 CI/CD에 서로 다른 도구를 사용하는 것은 괜찮음 — 중요한 것은 프로세스가 자동화되어 있다는 것.
- 자신에게 가장 잘 맞는 CI/CD 도구를 선택할 수 있음.
- Infrastructure as Code(IaC) 도구는 개발 환경 인프라의 프로비저닝과 관리를 극적으로 빠르게 함.
- 다양한 IaC 도구 중에서 선택할 수 있음.

## 요약
- Module 1은 CI(Plan/Code/Build/Test)와 CD(Release/Deploy/Operate)가 순차적인 별개 프로세스임을 확립하고, 도구 선택의 자유(CI/CD 도구, IaC 도구 모두)와 자동화 자체가 핵심이라는 점을 강조하며 마무리된다.
