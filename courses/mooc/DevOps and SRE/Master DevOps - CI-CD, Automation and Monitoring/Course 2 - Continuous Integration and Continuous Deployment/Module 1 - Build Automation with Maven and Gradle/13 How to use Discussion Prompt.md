# How to use Discussion Prompt

## 개요
- MOOC 플랫폼의 Discussion Forum 사용법을 안내하는 리딩(DevOps 기술 내용은 아님, Course 1과 동일한 안내문).

## 내용
- Discussion prompt는 레슨 내 별도 항목으로 제공되는 토론 질문이다.
- 배운 내용을 복습하고, 새 지식을 기존 이해와 연결하며, 다른 학습자의 피드백을 받는 용도로 활용한다.
- 답변을 남기면 다른 학습자의 응답을 보고 댓글을 달 수 있어 토론·명확화·논쟁이 가능하다.

## 요약
- 정답이 정해진 질문이 아니라 관점을 공유하고 대화를 이어가기 위한 개방형 질문이다.
