# Maven Repositories

## 개요
- Maven Repository의 정의와 역할, 3가지 종류, 이점, 그리고 의존성을 찾는 실제 조회 흐름(local → remote → central)을 설명.

## 내용
### Maven Repository란
- jar 파일, 플러그인, 의존성 등 Maven 아티팩트를 저장·관리하는 중앙 위치(로컬 머신 또는 원격 서버).
- 아티팩트의 효율적인 공유와 검색(retrieval)을 가능하게 한다.

### 주요 기능
1. **아티팩트 저장** — 가장 핵심적인 기능
2. **의존성 관리** — 올바른 버전의 아티팩트를 찾고 다운로드·관리
3. **공유·협업 촉진** — 프로젝트·개발자 간 아티팩트 공유
4. **미리 빌드된 아티팩트에 대한 폭넓은 접근** — 커스텀 빌드에 의존하지 않아도 됨

### 저장소 3가지 종류
1. **Local Repository** — 개발자 컴퓨터의 디렉터리(예: 사용자 홈). 다운로드한 아티팩트를 캐시해 빠른 빌드와 반복 다운로드 방지.
2. **Central Repository** — Maven이 중앙 관리하는 온라인 무료 오픈소스 저장소(mvnrepository 등). 누구나 접근 가능, 오픈소스 도구·언어·의존성을 다운로드.
3. **Remote Repository (Private Repository)** — 조직/서드파티가 운영하는 비공개 저장소. Central Repository에 없는 조직 내부 전용 아티팩트를 저장.

### 이점
- 의존성 관리 단순화, 빌드 일관성 향상, 협업 강화, 빌드 속도 향상

### 저장소 조회 흐름
1. 의존성이 필요하면 먼저 **로컬 저장소**를 확인(캐시 우선)
2. 로컬에 없으면 **원격(remote) 저장소** 확인
3. 원격에도 없으면 **중앙(central) 저장소**에서 확인
4. 다운로드한 뒤에는 로컬 저장소에 캐시되어 다음번에는 로컬에서 바로 사용

## 요약
- Maven Repository는 Local(캐시) → Remote(조직 전용) → Central(공개 오픈소스) 순으로 의존성을 조회하는 3계층 구조로, 이를 통해 빌드 속도와 협업 효율을 동시에 높인다.
