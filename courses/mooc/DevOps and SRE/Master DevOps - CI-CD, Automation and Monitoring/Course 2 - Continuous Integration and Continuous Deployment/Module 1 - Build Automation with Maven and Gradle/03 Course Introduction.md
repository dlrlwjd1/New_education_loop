# Course Introduction

## 개요
- 이 코스(Continuous Integration and Continuous Deployment)에서 다룰 내용과 모듈 구성을 소개.

## 내용
### 다루는 내용
- DevOps 라이프사이클에서 CI/CD가 소프트웨어 딜리버리 속도를 어떻게 개선하는지
- Maven·Gradle로 코드 빌드
- 빌드·배포 자동화를 위한 파이프라인 설계
- Ansible을 이용한 설정 관리(configuration management)와 push 방식 접근, Playbook·YAML 작성
- Ansible·Jenkins·GitHub를 통합해 협업·빠른 피드백·신속한 릴리스를 위한 CI/CD 워크플로우 구성

### 모듈 구성
1. **Build Automation** — Maven, Gradle로 코드 빌드
2. **Jenkins Pipelines** — GitHub·Maven·Gradle과 통합해 Jenkins 파이프라인 구축·관리, JUnit/Gradle로 자동화 테스트, Jenkins의 Master-Node 구성
3. **Configuration Management with Ansible** — Ansible 아키텍처와 핵심 요소(inventory, playbook, module, handler, role 등)
4. **Course Wrap-Up and Assessment** — 최종 프로젝트로 학습 내용 검증

### 대상 학습자
- DevOps에 새로 입문하는 사람, 신입, 개발자, DevOps 엔지니어, DevOps로 전환하려는 시스템 관리자

## 요약
- 이 코스는 빌드 자동화(Maven/Gradle) → 파이프라인 구축(Jenkins) → 설정 관리(Ansible)로 이어지는 실전 중심 학습을 통해 CI/CD 워크플로우 전체를 다루는 실무 지식과 실습 경험을 제공한다.
