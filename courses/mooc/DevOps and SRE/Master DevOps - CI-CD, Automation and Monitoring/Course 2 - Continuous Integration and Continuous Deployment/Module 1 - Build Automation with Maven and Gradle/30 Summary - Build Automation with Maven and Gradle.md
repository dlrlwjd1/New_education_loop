# Summary - Build Automation with Maven and Gradle

## 개요
- Module 1(Build Automation with Maven and Gradle) 전체를 4개 레슨 단위로 회고하는 요약 리딩.

## 내용
### Lesson 1: Maven Essentials
- 빌드 자동화 개념과 Maven의 등장 배경, Maven 아키텍처·의존성 관리·local/central/remote 저장소, Maven 설치·설정, CI/CD 파이프라인에서의 중요성.

### Lesson 2: Maven Project Management
- Maven 프로젝트 생성·커스터마이징, `pom.xml` 설정, Maven 빌드 라이프사이클, 플러그인·프로파일 사용, CI 워크플로우와의 통합.

### Lesson 3: Gradle Essentials
- Gradle을 대안 빌드 도구로 소개 — 아키텍처, 의존성 관리, Gradle Wrapper. Gradle vs Maven 비교, Gradle 설치와 샘플 애플리케이션 실행 실습.

### Lesson 4: Module Wrap-Up and Assessment
- 빌드 자동화 핵심 개념 복습 — Maven과 Gradle이 의존성 관리와 프로젝트 빌드 간소화에서 하는 역할. 빌드 도구 아키텍처·설정·CI/CD 적용에 대한 이해도 평가.

## 요약
- Module 1은 "왜 빌드 자동화인가"(Lesson 1) → "Maven 프로젝트 관리"(Lesson 2) → "Gradle 대안"(Lesson 3) 순으로 이어지며, Module 2에서 다룰 Jenkins CI/CD 파이프라인의 토대가 되는 빌드 도구 지식을 완성한다.
