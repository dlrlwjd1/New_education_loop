# Welcome to Continuous Integration and Continuous Deployment

## 개요
- 코스 전체 구조(4개 모듈)와 학습 목표를 안내하는 오리엔테이션 리딩.

## 내용
### 학습 목표
- CI/CD가 DevOps 라이프사이클과 소프트웨어 딜리버리에 미치는 역할 평가
- Maven·Gradle로 빌드 자동화 및 의존성 관리
- Jenkins 파이프라인으로 지속적 통합·배포 구축·관리
- Ansible로 설정 관리와 배포 자동화 수행
- 협업·빠른 피드백·신속한 릴리스를 촉진하는 CI/CD 워크플로우 설계

### 코스 구조 (약 4주 분량, 영상 50개 이상)
- **Module 1: Build Automation with Maven and Gradle**
  - Lesson 1: Maven Essentials
  - Lesson 2: Maven Project Management
  - Lesson 3: Gradle Essentials
  - Lesson 4: Module Wrap-Up and Assessment
- **Module 2: Continuous Integration and Deployment using Jenkins**
  - Lesson 1: Overview of Jenkins
  - Lesson 2: Jenkins Management - Plugins, Security, and Notifications
  - Lesson 3: Jenkins in DevOps Pipelines
  - Lesson 4: Jenkins for Automated Testing, Deployment, and Monitoring
  - Lesson 5: Module Wrap-Up and Assessment
- **Module 3: Configuration Management with Ansible**
  - Lesson 1: Concepts of Configuration Management
  - Lesson 2: Getting Started with Ansible
  - Lesson 3: Ansible Essentials - Playbooks and Roles
  - Lesson 4: Module Wrap-Up and Assessment
- **Module 4: Course Wrap-Up and Assessment**
  - Course Project, End Course Assessment

### 대상 학습자
- 초심자, 소프트웨어 개발자, DevOps 엔지니어, QA/테스트 엔지니어, 시스템 관리자
- CI/CD 도구 사전 경험은 필요 없으나 소프트웨어 개발 개념에 대한 이해가 도움이 됨

## 요약
- 영상 강의, 리딩 자료, 실습(데모·프로젝트), 토론 프롬프트, 퀴즈로 구성되며 마지막에 프로젝트와 최종 평가로 마무리된다.
