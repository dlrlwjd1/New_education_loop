# Summary - Continuous Integration using Jenkins

## 개요
- Module 2(Continuous Integration and Deployment using Jenkins) 전체를 5개 레슨 단위로 회고하는 요약 리딩.

## 내용
### Lesson 1: Overview of Jenkins
- 전통적 통합에서 Continuous Integration으로의 진화, 대표 자동화 서버로서의 Jenkins 소개. Jenkins 아키텍처, 설치 절차, 현대 CI/CD에서의 역할.

### Lesson 2: Jenkins Management - Plugins, Security, and Notifications
- 기능 확장과 시스템 안정성을 위한 플러그인 관리. 접근 통제·자격 증명 관리를 포함한 보안 설정. 빌드·배포 이벤트 알림 설정.

### Lesson 3: Jenkins in DevOps Pipelines
- Jenkins로 딜리버리 파이프라인을 만들고 모니터링 — Pipeline View, Jenkinsfile을 통한 Pipeline as Code, 버전 관리 시스템·Maven·Gradle·Ansible과의 통합.

### Lesson 4: Jenkins for Automated Testing, Deployment, and Monitoring
- Jenkins로 테스트 자동화, 파이프라인을 통한 Continuous Deployment 구현. Jenkins Job·파이프라인 모니터링으로 신뢰할 수 있고 효율적인 CI/CD 프로세스 확보.

### Lesson 5: Module Wrap-Up and Assessment
- CI/CD 핵심 원칙과 Jenkins 아키텍처·관리·파이프라인 자동화 복습. Jenkins 설정, 플러그인 관리, 파이프라인 생성, 다른 DevOps 도구와의 통합에 대한 평가.

## 요약
- Module 2는 "왜 Jenkins인가"(Lesson 1) → "관리·보안·알림"(Lesson 2) → "파이프라인 구축"(Lesson 3) → "테스트·배포·모니터링 자동화"(Lesson 4) 순으로 심화되며, Module 1의 빌드 도구(Maven/Gradle) 지식 위에 Jenkins라는 CI/CD 엔진의 전체 그림을 완성한다.
