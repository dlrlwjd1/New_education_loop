# Summary - Configuration Management with Ansible

## 개요
- Module 3(Configuration Management with Ansible) 전체를 4개 레슨 단위로 회고하는 요약 리딩.

## 내용
### Lesson 1: Concepts of Configuration Management
- Configuration Management의 기초, DevOps에서의 역할, Infrastructure as Code 개념. 자동화의 이점을 보여주는 핵심 개념과 업계 사례.

### Lesson 2: Getting Started with Ansible
- Ansible 아키텍처 개요와 Ad-hoc Command를 이용한 기본 자동화 작업 — Ansible이 반복 작업과 인프라 관리를 어떻게 단순화하는지 시연.

### Lesson 3: Ansible Essentials - Playbooks and Roles
- Ansible Playbook 생성·실행, 변수·Handler 활용, Role을 이용한 자동화 조직화. Jenkins와의 통합을 통한 자동화 파이프라인 구성도 다룸.

### Lesson 4: Module Wrap-Up and Assessment
- Configuration Management 개념과 Ansible 자동화 복습. Ansible 아키텍처·Playbook·Role, 그리고 자동화된 배포 파이프라인 내 통합에 대한 이해도 평가.

## 요약
- Module 3은 "왜 Configuration Management인가"(Lesson 1) → "Ansible 기초"(Lesson 2) → "Playbook·Role 심화 및 Jenkins 통합"(Lesson 3) 순으로 이어지며, Module 2의 Jenkins CI/CD 지식과 결합해 완전한 자동화 배포 파이프라인을 완성한다.
