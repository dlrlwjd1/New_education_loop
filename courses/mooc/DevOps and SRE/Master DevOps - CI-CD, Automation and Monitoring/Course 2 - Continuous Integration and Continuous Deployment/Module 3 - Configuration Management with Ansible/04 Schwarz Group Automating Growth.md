# Schwarz Group Automating Growth

## 개요
- 유럽 최대 소매업체 Schwarz Group의 사례를 통해 Ansible이 대규모 매장 운영 성장에 어떻게 기여했는지 소개.

## 내용
### Schwarz Group 소개
- 유럽 최대 소매업체 — 약 57만 5천 명의 직원, 32개국 13,900개 이상의 매장, 2개의 리테일 사업부.

### 직면한 문제
- **확장성 부족** — 매년 새 시장에 매장이 빠르게 늘어나 수동 관리가 한계에 부딪힘
- **재고·직원 데이터 관리의 어려움**
- **배송 시간** — 경쟁력 유지를 위해 배송 시간을 크게 단축해야 함
- **현지 시장 대응 유연성** — 32개국 각각의 현지 수요에 빠르게 적응해야 함
- **다양한 시장으로의 확장** 필요

### Ansible 도입 후 변화
- **Inventory**를 만들어 여러 매장의 변경사항을 업데이트 — 수천 개 매장에 걸쳐 신뢰할 수 있는 인프라 관리를 실현.
- **디지털 배포(Digital Deployment)**로 각 매장에 재고 가용성 정보를 즉시 업데이트해 고객 경험 향상.
- 고객이 주문·결제하는 애플리케이션도 최신 상태로 유지되어 배송 누락·주문 취소 위험 감소.
- 통제된(Controlled) 배포 덕분에 주문 관리가 훨씬 쉬워짐.

## 요약
- Schwarz Group은 Ansible의 Inventory 기반 자동화로 32개국 수천 개 매장의 인프라·재고·주문 관리를 일관되게 통제하며, 이를 통해 확장성과 고객 경험을 동시에 개선했다.
