# Course Summary

## 개요
- Course 2(Continuous Integration and Continuous Deployment) 전체를 마무리하며 배운 내용을 회고.

## 내용
### 코스 전체 회고
- Maven·Gradle을 이용한 **빌드 자동화**
- **Jenkins**를 이용한 통합 프로세스
- **Ansible**을 이용한 지속적 관리·설정 관리
- Jenkins·Ansible의 다양한 도전 과제와 실시간 활용 사례

### 코스 이후의 진로
- DevOps Engineer, Automation Engineer, Site Reliability Engineer 등의 역할 준비
- Docker, Kubernetes, 모니터링 도구 등 다른 DevOps 도구 탐색 권장
- GitHub Actions 같은 다른 오픈소스 CI 도구도 함께 탐색 권장

## 요약
- 이 코스를 통해 Maven·Gradle·Jenkins·Ansible이라는 업계 표준 도구에 대한 이해를 갖추었으며, 이는 소프트웨어 딜리버리를 간소화하고 조직의 DevOps 팀에 기여할 준비가 되었음을 의미한다.
