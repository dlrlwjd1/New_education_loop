# Course Summary

## 개요
- "Containerization and Orchestration" 코스 전체(Module 1~4)를 되짚고, 수료 후 진로 방향(DevOps, Automation Engineering, SRE)을 안내하는 코스 최종 요약.

## 내용
### 코스 전체 구성 회고
- **Module 1, 2**: Docker에 집중 — 컨테이너 기초부터 고급 컨테이너 관리(Docker Compose, Swarm, 모니터링 등)까지.
- **Module 3**: Kubernetes 시작 — Kubernetes 기초 개념.
- **Module 4**: Kubernetes 고급 개념 — Helm/Helm Chart, Kubernetes 모니터링, 스토리지(Persistent Volume 등), StatefulSet 등.
- **Module 5**(현재): 코스 마무리(Wrap-up)와 평가(Assessment).

### 수료 후 진로 방향
- **DevOps 엔지니어** — CI/CD 파이프라인 구축, 애플리케이션을 Docker 컨테이너로 구현하고 Kubernetes로 오케스트레이션.
- **자동화 엔지니어(Automation Engineer)** — 애플리케이션을 컨테이너 기반으로 구축하는 작업에 집중.
- **SRE(Site Reliability Engineer)** — 기존에 가상 머신에서 운영하던 프로덕션 애플리케이션을 컨테이너로 옮기고 Kubernetes로 오케스트레이션하는 것이 게임 체인저가 될 수 있음.

### 코스에서 습득한 핵심 역량
- Docker를 이용해 컨테이너에서 실행되는 애플리케이션을 **배포·관리·모니터링**하는 방법.
- Kubernetes를 이용해 애플리케이션을 **대규모로 구축·오케스트레이션**하는 방법.
- Prometheus와 Grafana를 이용해 Kubernetes에서 실행 중인 애플리케이션을 **모니터링**하는 방법.
- 이를 통해 확장 가능한(scalable) 애플리케이션과 회복탄력성 있는(resilient) 시스템을 구축하고, 현대적인 DevOps 환경에서 성공을 이끌 준비를 갖추게 됨.

## 요약
- 이 코스는 Docker 기반 컨테이너화(Module 1~2)에서 시작해 Kubernetes 기초와 고급 개념(Module 3~4, Helm·모니터링·스토리지·StatefulSet 포함)까지 다뤘으며, 수료 후에는 DevOps 엔지니어·자동화 엔지니어·SRE 등 다양한 진로에서 컨테이너 기반 애플리케이션의 배포·오케스트레이션·모니터링 역량을 실무에 바로 적용할 수 있다.
