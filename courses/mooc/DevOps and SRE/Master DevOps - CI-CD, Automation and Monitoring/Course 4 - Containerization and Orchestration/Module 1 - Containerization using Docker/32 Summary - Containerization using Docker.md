# Summary: Containerization using Docker

## 개요
- Module 1(Containerization using Docker) 전체를 4개 레슨 단위로 회고하는 요약 리딩.

## 내용
### Lesson 1: Getting Started with Containers
- 컨테이너화의 개념을 소개하고, 컨테이너가 어떻게 동작하는지 설명하며 VM과 비교. 실제 컨테이너화 사례(Yelp)를 통해 맥락을 제공하며 Docker 실습을 위한 기초 지식을 다짐.

### Lesson 2: Docker Fundamentals
- Docker의 목적, 아키텍처, 컨테이너 라이프사이클을 다룸. 핵심 Docker 작업을 실습으로 시연해 기초 지식을 확립하고, Docker가 애플리케이션 배포를 어떻게 간소화하는지 명확히 이해시킴.

### Lesson 3: Docker CLI and Port Binding
- Docker CLI 명령어를 설명하고 Port Binding 기법을 시연해 컨테이너 포트를 관리하는 방법을 보여줌. 실습 중심 접근으로 컨테이너가 외부와 어떻게 통신하는지 명확히 이해.

### Lesson 4: Module Wrap-Up and Assessment
- 지식 점검과 요약으로 컨테이너화와 Docker 기초의 핵심 개념을 강화. 더 고급의 컨테이너 관리 주제로 넘어갈 준비를 갖춤.

## 요약
- Module 1은 "컨테이너 개념·VM 비교"(Lesson 1) → "Docker 기초·아키텍처·라이프사이클"(Lesson 2) → "CLI·Port Binding 실습"(Lesson 3) 순으로 이어지며, Module 2에서 다룰 Docker 고급 관리(Compose·Swarm·모니터링)의 토대가 되는 Docker 기초 지식을 완성한다.
