# Port Binding - Syntax and Example

## 개요
- Port Binding을 실제로 수행하는 `-p` 플래그 문법과, 웹 애플리케이션을 예로 든 사용 사례를 정리.

## 내용
### Port Binding 문법
```bash
docker run -p <호스트 포트>:<컨테이너 포트> <이미지>
```
- 컨테이너를 생성할 때 **`-p` 플래그를 사용하지 않으면** 컨테이너 포트가 호스트 포트에 매핑되지 않아, Docker Host 내부에서는 언제든 접근 가능하지만 **외부(WWW)에서는 접근 불가능**.
- 외부에서 접근하려면 컨테이너 생성 시점에 반드시 Host Port와 Container Port를 바인딩해야 함.
- 예: 호스트 포트 `32000`을 컨테이너 포트 `80`(Nginx의 기본 포트)에 바인딩:
```bash
docker run -p 32000:80 nginx
```

### 사용 사례 예시: 웹 애플리케이션
- 웹 기반 애플리케이션을 배포해 전 세계 사용자가 접근할 수 있게 하려는 경우 Port Binding이 필요.
- 컨테이너 안의 웹 애플리케이션이 포트 `80`에서 리스닝 중이고, 이를 호스트의 포트 `8080`을 통해 접근하고 싶다면:
```bash
docker run -p 8080:80 <이미지>
```
- 이 명령은 호스트의 포트 `8080`을 컨테이너의 포트 `80`에 매핑해, `localhost:8080`(또는 Docker Host의 IP 주소:8080)으로 웹 애플리케이션에 외부 접근을 허용.

## 요약
- `docker run -p <호스트포트>:<컨테이너포트> <이미지>` 형태로 컨테이너 생성 시점에 `-p` 플래그를 지정해야 컨테이너 내부 애플리케이션이 외부에서 접근 가능해지며, 예를 들어 `-p 8080:80`은 호스트의 8080번 포트로 들어온 요청을 컨테이너의 80번 포트로 전달해 웹 애플리케이션을 외부에 노출한다.
