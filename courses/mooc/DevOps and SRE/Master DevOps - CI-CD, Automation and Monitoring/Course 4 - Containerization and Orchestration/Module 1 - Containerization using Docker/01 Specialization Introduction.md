# Specialization Introduction

## 개요
- Master DevOps 전문과정 전체(4개 강좌)를 소개하는 영상 — Course 1의 동일한 강의와 내용이 같다.

## 내용
- Course 1 Module 1의 [01 Specialization Introduction](../../Course%201%20-%20DevOps%20Essentials%20and%20Git/Module%201%20-%20Introduction%20to%20DevOps%20and%20Linux/01%20Specialization%20Introduction.md)에 동일한 내용의 정리본이 있다.
- 이 강의(Course 4 도입부)에서 강조하는 지점: 전문과정의 네 번째이자 마지막 강좌인 **Containerization and Orchestration**에서는 Docker로 애플리케이션을 컨테이너화하고 Kubernetes로 오케스트레이션하는 방법을 배우며, 확장 가능하고 이식 가능한 애플리케이션 배포와 컨테이너 환경에서의 리소스 최적화, 프로덕션 시나리오에서의 모니터링·트러블슈팅까지 다룬다.

## 요약
- 전문과정 전체 소개 내용은 Course 1의 동일 강의 정리본을 참고하고, 이 강의는 그중 Course 4(Docker·Kubernetes 컨테이너화·오케스트레이션)의 역할을 강조하는 도입부다.
