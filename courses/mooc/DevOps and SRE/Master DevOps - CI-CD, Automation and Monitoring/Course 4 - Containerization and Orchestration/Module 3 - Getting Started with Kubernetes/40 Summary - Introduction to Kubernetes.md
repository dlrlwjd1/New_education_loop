# Summary: Introduction to Kubernetes

## 개요
- Module 3(Getting Started with Kubernetes) 전체를 4개 레슨 단위로 회고하는 요약 리딩.

## 내용
### Lesson 1: Getting Started with Kubernetes
- Pod, Controller, Service, ConfigMap, Secret, 클러스터 아키텍처 같은 Kubernetes 핵심 개념을 실습 예제와 함께 소개. Kubernetes 기능을 이해하기 위한 토대를 마련.

### Lesson 2: kubectl Essentials
- Kubernetes 클러스터를 관리하기 위한 필수 kubectl 명령어를 다루고 실습. Kubernetes 환경과 상호작용하고 제어하는 데 필요한 도구를 제공.

### Lesson 3: Pods and Scaling in Kubernetes
- Pod 라이프사이클, ReplicaSet, Deployment, DaemonSet, 롤링 업데이트, 롤백, 스케일링 전략을 탐구. Kubernetes에서 애플리케이션을 유지·확장하는 데 핵심적인 개념들.

### Lesson 4: Module Wrap-Up and Assessment
- 지식 점검과 요약으로 Kubernetes 기본 개념을 마무리. 다음 단계로 나아가기 전에 핵심 Kubernetes 역량이 잘 다져졌는지 확인.

## 요약
- Module 3은 "핵심 개념"(Lesson 1) → "kubectl 명령어"(Lesson 2) → "Pod·스케일링·업데이트·롤백"(Lesson 3) 순으로 이어지며, Module 4에서 다룰 Kubernetes Service·퍼시스턴트 스토리지·모니터링의 토대가 되는 Kubernetes 기초 역량을 완성한다.
