# Kubernetes Case Study

## 개요
- 미국 정부의 recreation.gov 웹사이트를 현대화한 Booz Allen Hamilton의 사례를 통해 Kubernetes 도입 배경과 그 효과를 정리.

## 내용
### 회사 소개
- Booz Allen Hamilton — 미국의 경영·IT 컨설팅 기업, 약 3만 5,900명의 인력 보유. 공공·민간 조직에 컨설팅, 분석, 엔지니어링 서비스를 제공하는 선도 기업.

### 도전 과제
- 2017년 미국 연방정부와 협력해 약 10만 개의 캠핑장·시설을 서비스하던 **10년 된 recreation.gov 웹사이트**를 현대화하는 프로젝트 진행.
- 주요 목표: **애자일(Agile)하고 신뢰할 수 있으며(Reliable) 확장 가능하고(Scalable) 복제 가능한(Replicable)** 인프라 구축.
  - **Agile** — 배포·업그레이드가 빠르게 이루어져야 함.
  - **Reliable** — 시스템이 깨지지 않아야 함.
  - **Scalable** — 서버 수를 필요에 따라 늘릴 수 있어야 함.
  - **Replicable** — 한 부서의 데이터·인프라가 다른 연방 기관에서도 동일하게 재현 가능해야 함.
- 두 번째 과제: 다양한 기관의 요구를 충족하면서 높은 성능과 사용자 만족도를 보장하는 시스템 구축.

### 채택한 접근 방식
- **마이크로서비스 아키텍처** 채택 — 모든 구성 요소를 Docker 컨테이너로 배포하고, 이 컨테이너들을 **Kubernetes**로 관리.
- 이 접근 방식 덕분에 각 기관의 고유한 요구에 동적이고 민첩하게 대응 가능(예: 필요시 즉시 컨테이너 수를 늘릴 수 있음), 신뢰성·확장성·복제 가능성·성능을 모두 확보.
- 정부의 IT 현대화 목표에 부합하는 오케스트레이터로 Kubernetes를 최종 선택.

### Kubernetes 도입의 영향
1. **신속한 배포(Rapid Deployment)** — 기존에는 서버 생성, OS 설치, 네트워킹 구성, 사전 요구사항 설치, 배포, 테스트까지 하루 이상 걸렸지만, 컨테이너 이미지(애플리케이션+의존성 포함)로 배포하니 애플리케이션이 20~30분 만에 완전히 온라인 상태가 됨.
2. **개발자 생산성 향상** — Kubernetes에 통합된 모니터링·보안·로깅 도구 덕분에 개발자가 애플리케이션 성능을 쉽게 파악할 수 있게 되어, 새로운 서비스를 일주일 이내에 배포 가능해짐(빠른 버그 수정·코드 변경을 개발/테스트 환경에서 검증 후 프로덕션에 반영).
3. **비용 효율성** — 모놀리식 아키텍처에서 컨테이너화된 아키텍처로 전환하며 **플랫폼 비용을 약 50% 절감**. 예를 들어 100대의 VM을 운영하던 것을, Kubernetes가 관리하는 10~20개 노드로 대체해 훨씬 적은 서버로 더 많은 마이크로서비스를 운영.

## 요약
- Booz Allen Hamilton은 정부의 오래된 웹사이트를 현대화하기 위해 모놀리식 아키텍처를 Docker+Kubernetes 기반 마이크로서비스 아키텍처로 전환함으로써, 배포 시간을 며칠에서 20~30분으로 단축하고 개발자 생산성을 높이며 플랫폼 비용을 약 50% 절감하는 성과를 거두었다.
