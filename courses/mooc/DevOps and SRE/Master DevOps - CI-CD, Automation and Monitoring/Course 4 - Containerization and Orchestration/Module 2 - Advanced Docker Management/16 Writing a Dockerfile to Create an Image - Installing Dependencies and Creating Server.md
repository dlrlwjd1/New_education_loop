# Writing a Dockerfile to Create an Image - Installing Dependencies and Creating Server

## 개요
- 이 강의 페이지의 Transcript는 실제로 [04 Starting Containers in Different Modes - Detached Mode](04%20Starting%20Containers%20in%20Different%20Modes%20-%20Detached%20Mode.md)와 동일한 내용(Attach/Detach 모드 실습, `docker logs`, `docker container/image/system prune`)이 나온다 — MOOC 강의 페이지의 제목과 실제 Transcript가 일치하지 않는 것으로 보인다.

## 내용
- 강의 제목("Node.js 의존성 설치와 서버 생성")에 해당하는 실제 내용(Express 설치, `server.js` 작성 등)은 이 Transcript에 없어 임의로 작성하지 않는다.
- Transcript에 실제로 담긴 내용은 04번 파일과 동일하므로 해당 파일을 참고한다: Attach/Detach 모드 컨테이너 실행, `docker logs`로 로그 확인, `docker container prune`/`docker image prune`/`docker system prune -a`로 정리하는 방법.
- Node.js 프로젝트 초기화(`npm init`)까지는 [15 Writing a Dockerfile to Create an Image - Installing node.js](15%20Writing%20a%20Dockerfile%20to%20Create%20an%20Image%20-%20Installing%20node.js.md)에서 다뤘으며, 이어지는 실제 진행(Express 설치, 서버 코드 작성, Dockerfile 작성)은 다음 강의인 [17 Writing a Dockerfile to Create an Image - Building Image](17%20Writing%20a%20Dockerfile%20to%20Create%20an%20Image%20-%20Building%20Image.md)에서 확인한다.

## 요약
- 이 강의는 제목과 실제 Transcript 내용이 어긋나 있어([04](04%20Starting%20Containers%20in%20Different%20Modes%20-%20Detached%20Mode.md)와 동일한 내용) 임의로 내용을 지어내지 않았으며, Node.js 서버 구축의 실제 진행 상황은 앞뒤 강의 노트를 참고한다.
