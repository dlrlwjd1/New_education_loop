# Docker Compose - Introduction

## 개요
- 멀티 컨테이너 애플리케이션을 관리하는 도구인 Docker Compose의 정의와, YAML 파일로 여러 컨테이너를 정의·배포하는 방식을 정리.

## 내용
### Docker Compose란
- 여러 Docker 컨테이너로 구성된(멀티 컨테이너) 애플리케이션을 관리하기 위한 또 다른 Docker 도구/플러그인.
- 예: 프론트엔드 컨테이너와 데이터베이스 컨테이너가 각각 별도의 Docker 환경에서 실행되는 애플리케이션이 있을 때, 이를 하나의 도구로 함께 관리하고 싶다면 Docker Compose가 필요.
- 마이크로서비스처럼 여러 하위 컴포넌트로 구성된 애플리케이션(예: Nginx 프론트엔드 + Python 백엔드 + Redis 캐시)에서, 각 구성 요소가 서로 데이터·네트워크 등에 의존 관계를 가질 때 그 의존성을 정의하고 함께 생성·배포하는 데 사용.

### 동작 방식
- 개발자가 복잡한 애플리케이션 환경을 **YAML 파일**로 정의하고 이를 실행.
- 예시 애플리케이션의 3계층 구조: **Nginx(프론트엔드) + Python(백엔드/로직 계층) + Redis(데이터베이스/캐시)**.
- 이 세 구성 요소에 대한 설정을 하나의 YAML 파일에 모두 담아 작성.
- **YAML(YAML Ain't a Markup Language)** — 마크업 언어가 아니라 **데이터 직렬화(serialization) 언어**로, 도구에 입력값을 제공하거나 설정·의존성을 정의하는 데 주로 사용.
- 이 YAML 파일을 Docker Compose 도구로 실행하면, Docker Compose가 자동으로 Nginx, Python, Redis 컨테이너를 생성하고 이들을 하나의 애플리케이션으로 함께 관리.

## 요약
- Docker Compose는 프론트엔드·백엔드·데이터베이스처럼 서로 연관된 여러 컨테이너로 구성된 애플리케이션을, YAML(데이터 직렬화 언어) 파일 하나에 모든 설정을 담아 정의하고 한 번에 생성·관리할 수 있게 해주는 도구로, 개발 환경에서 복잡한 멀티 컨테이너 애플리케이션을 정의·실행하는 데 특히 유용하다.
