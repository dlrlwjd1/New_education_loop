# Summary: Advanced Docker Management and Orchestration

## 개요
- Module 2(Advanced Docker Management) 전체를 5개 레슨 단위로 회고하는 요약 리딩.

## 내용
### Lesson 1: Docker Container Modes and Image Creation
- Docker 컨테이너의 다양한 실행 모드(Detached/Foreground)를 탐구하고, Dockerfile로 Docker 이미지를 만드는 과정을 실습. 컨테이너 커스터마이징과 배포에 대한 이해를 심화.

### Lesson 2: Managing Docker Images and Volumes
- 이미지 Pull·Push, Docker Hub 설정을 포함한 이미지 관리와, 실습 예제를 통한 스토리지·볼륨 관리를 다룸. 컨테이너 리소스를 효율적으로 관리할 수 있게 됨.

### Lesson 3: Orchestrating Containers: Docker Compose and Swarm
- Docker Compose와 Docker Swarm을 이용한 컨테이너 오케스트레이션 소개 — 설치, 멀티 컨테이너 배포, Swarm 모드 운영을 포함. 복잡한 컨테이너화 애플리케이션을 다루는 능력을 키움.

### Lesson 4: Monitoring and Visualizing Docker Containers with Prometheus and Grafana
- 컨테이너 모니터링을 설명하고, Prometheus·Grafana를 설정해 지표를 수집·시각화하는 과정을 실습. 컨테이너 성능과 상태에 대한 가시성을 향상.

### Lesson 5: Module Wrap-Up and Assessment
- 지식 점검과 요약으로 Docker 고급 관리·오케스트레이션·모니터링 주제를 통합. Kubernetes 중심 모듈을 위한 준비를 갖춤.

## 요약
- Module 2는 "컨테이너 모드·이미지 생성"(Lesson 1) → "이미지·볼륨 관리"(Lesson 2) → "Compose·Swarm 오케스트레이션"(Lesson 3) → "Prometheus·Grafana 모니터링"(Lesson 4) 순으로 이어지며, Module 3에서 다룰 Kubernetes의 토대가 되는 Docker 고급 역량을 완성한다.
