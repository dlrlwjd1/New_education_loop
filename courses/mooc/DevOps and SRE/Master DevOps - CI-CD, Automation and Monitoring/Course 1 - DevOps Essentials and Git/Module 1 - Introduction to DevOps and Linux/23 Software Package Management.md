# Software Package Management

## 개요
- Linux의 소프트웨어 패키지 관리 개념과 Debian 계열의 대표 도구 apt-get/apt-cache를 설명.

## 내용
### 패키지 관리란
- 소프트웨어를 설치·업데이트·삭제하는 시스템. 수동 다운로드·설정 없이도 원하는 만큼만 정확히 설치할 수 있다.
- 배포판마다 패키지 매니저가 다름: Ubuntu/Debian → `apt-get`, Red Hat/Fedora → `yum`

### 패키지 관리 시스템의 주요 기능
1. 도구 설치 — 수동 설정 없이 새 소프트웨어 설치
2. 소프트웨어 업그레이드 — 설치된 프로그램을 자동으로 최신 상태 유지
3. 체크섬(checksum) 검증 — 다운로드한 소프트웨어가 변조되지 않았는지 확인
4. 디지털 서명 검증 — 소프트웨어의 신뢰성·안전성 확인
5. 의존성 관리 — 프로그램이 필요로 하는 다른 소프트웨어를 함께 설치
6. 오래된 버전 제거 — 사용하지 않는 구버전을 정리해 시스템을 깔끔하게 유지

## 예시
### apt-get
- Debian 계열(Ubuntu 등)의 명령줄 패키지 관리 도구. apt 라이브러리와 함께 설치·업그레이드·삭제를 처리한다.
- 자동 의존성 관리 지원, 업그레이드/삭제 시 버전을 신중히 관리해 시스템 안정성 유지.
- GUI를 선호하면 Synaptic, Aptitude 같은 도구 사용 가능.

### apt-cache
- 사용 가능한 패키지를 검색·탐색하는 명령줄 도구. `/etc/apt/sources.list`에 명시된 소스에서 패키지 정보를 가져온다.
- 다운로드한 패키지 파일은 캐시 폴더에 저장되어 재설치 시 다시 받지 않아도 된다.

```bash
# 특정 문자열로 시작하는 패키지 이름 목록 (예: python으로 시작)
apt-cache pkgnames python

# 이름/설명으로 패키지 검색
apt-cache search python

# 특정 패키지의 상세 정보(설명, 버전, 크기 등)
apt-cache show python

# 특정 패키지가 의존하는 다른 패키지 확인
apt-cache showpkg python
```

## 요약
- 패키지 관리자는 설치·업그레이드·검증·의존성 관리·정리를 자동화하며, Debian 계열에서는 apt-get(설치/삭제/업그레이드)과 apt-cache(검색/조회)가 핵심 도구다.
