# Users in Linux

## 개요
- Linux의 다중 사용자(multi-user) 개념, 사용자 정보가 저장되는 파일, root 사용자, `su`/`sudo`를 설명.

## 내용
### 다중 사용자 시스템
- Linux는 여러 사용자가 각기 다른 접근 권한으로 동시에 또는 다른 시점에 같은 머신을 사용할 수 있는 multi-user OS.
- 사용자마다 자신의 파일·환경설정·애플리케이션 접근 권한을 가진다.
- 일반 사용자는 시스템 파일 변경, 전역 소프트웨어 설치, 다른 사용자 홈 디렉터리 접근 등이 제한된다.

### 사용자 정보 저장 파일
- **`/etc/passwd`** — 모든 사용자 계정 목록. 사용자명, UID, GID, 홈 디렉터리, 기본 셸 등 포함. 누구나 읽을 수 있지만 비밀번호 자체는 저장되지 않음.
- **`/etc/shadow`** — 실제 암호화된 비밀번호, 비밀번호 만료·마지막 변경일·계정 잠금 규칙 저장. root만 접근 가능.
- **`/etc/group`** — 사용자 그룹 정보. 그룹 단위로 여러 사용자에게 한 번에 권한을 부여할 수 있음.

### Root 사용자(Superuser)
- UID/GID가 0이며 시스템 설치 시 자동 생성, 모든 권한을 가진다(파일 삭제·설정 변경 등 무제한).
- 실수 시 시스템 전체에 영향을 줄 수 있어 신중하게 사용해야 한다.
- 비밀번호가 없을 수 있으며, `sudo passwd root`로 설정 가능.
- **베스트 프랙티스**: root로 직접 로그인하지 말고, 일반 사용자 계정에서 `sudo`로 필요할 때만 권한을 일시적으로 상승시킨다.

### su vs sudo
- **`su`** — 다른 사용자로 전환(계정 자체를 바꿈). 인자 없이 실행하면 root로 전환하며 해당 사용자의 비밀번호가 필요(root로 이미 로그인한 경우는 예외). `exit`으로 원래 세션 복귀.
- **`sudo`** (superuser do) — 계정을 바꾸지 않고 단일 명령어만 root 권한으로 실행. `/etc/sudoers` 파일로 누가 무엇을 실행할 수 있는지 결정하며, 문법 오류 방지를 위해 `visudo`로 편집한다. 새 사용자는 기본적으로 sudo 권한이 없으며 `sudo`/`wheel` 그룹에 추가해야 사용 가능.

## 요약
- Linux는 `/etc/passwd`(계정 정보)·`/etc/shadow`(비밀번호)·`/etc/group`(그룹)으로 사용자를 관리하며, root 직접 로그인 대신 일반 계정+`sudo`를 쓰는 것이 다중 사용자·프로덕션 환경의 안전한 표준 관행이다.
