# Course Introduction

## 개요
- 이 코스(DevOps Essentials and Version Control with Git)에서 다룰 내용과 대상 학습자를 소개.

## 내용
### 다루는 내용
- DevOps 핵심 원칙과 소프트웨어 딜리버리 파이프라인(delivery pipeline)
- DevOps 엔지니어가 알아야 할 Linux 필수 명령어
- Git 기초(브랜칭·머징)부터 고급 워크플로우(머지 충돌 해결)까지

### 모듈 구성 (3개)
1. Introduction to DevOps and Linux — DevOps 개념과 Linux 기초
2. Version Control with Git — Git 기본 명령어부터 브랜칭 전략, 머징, 충돌 해결까지
3. Course Wrap-Up and Assessment — 복습 및 평가

### 대상 학습자
- Git/DevOps 사전 경험이 없어도 무관: 초심자, 소프트웨어 개발자, DevOps 엔지니어, 시스템 관리자 모두 대상

## 요약
- 이론과 실습을 결합해 팀 규모·복잡도에 맞는 브랜칭 전략까지 실무에 바로 적용할 수 있는 수준을 목표로 한다.
