# Common Linux Commands

## 개요
- DevOps 실무에서 자주 쓰는 Linux 명령어를 9가지 카테고리로 정리한 레퍼런스 리딩.

## 내용
### 1. 파일시스템 탐색
- `pwd` — 현재 디렉터리 경로 출력
- `ls` — 디렉터리 내용 나열
- `cd` — 디렉터리 이동

### 2. 파일·디렉터리 관리
- `mkdir` — 디렉터리 생성
- `touch` — 빈 파일 생성
- `cp` — 파일/디렉터리 복사
- `mv` — 파일 이동/이름 변경
- `rm` — 파일/디렉터리 삭제 (`-r` 옵션은 영구 삭제되므로 주의)

### 3. 파일 보기·편집
- `cat` — 파일 내용 출력
- `less` — 페이지 단위로 스크롤하며 보기 (`q`로 종료)

### 4. 권한과 소유권
- `chmod` — 권한 변경 (숫자 코드: 7=읽기+쓰기+실행, 6=읽기+쓰기, 5=읽기+실행, 4=읽기)
- `chown` — 파일 소유자 변경

### 5. 검색
- `find` — 디렉터리 계층에서 파일 검색
- `grep` — 파일 내 패턴 검색 (`-r`로 재귀 검색)

### 6. 시스템 정보·모니터링
- `uname` — 시스템 정보 표시
- `top` — 실행 중인 프로세스와 자원 사용량 표시
- `df` — 디스크 사용량 표시
- `free` — 메모리 사용량 표시

### 7. 패키지 관리
- 배포판마다 명령어가 다름 (Debian/Ubuntu vs Red Hat/CentOS)

### 8. 사용자 관리
- `adduser` — 새 사용자 계정 생성
- `passwd` — 사용자 비밀번호 설정/변경
- `whoami` — 현재 로그인한 사용자 표시

### 9. 도움말
- `man` — 명령어 매뉴얼 표시 (화살표로 탐색, `q`로 종료)
- `--help` — 명령어별 도움말 정보 제공

## 요약
- 탐색·파일 관리·보기·권한·검색·시스템 모니터링·패키지·사용자 관리·도움말이라는 9개 카테고리의 명령어에 익숙해지는 것이 Linux 실무의 기초 체력이다.
