# Welcome to DevOps Essentials and Version Control with Git

## 개요
- 코스 전체 구조(3개 모듈)와 학습 목표를 안내하는 오리엔테이션 리딩.

## 내용
### 학습 목표
- DevOps 문화의 핵심 원칙과 실천 방법 설명
- Linux 기반 환경에서 개발·운영 관리
- Git으로 소스 코드 관리 및 팀 협업
- 효율적인 개발 프로세스를 위한 Git 워크플로우·전략 적용

### 코스 구조 (약 3주 분량, 영상 50개 이상)
- **Module 1: Introduction to DevOps and Linux**
  - Lesson 1: Overview of DevOps
  - Lesson 2: DevOps Stages and Delivery Pipeline
  - Lesson 3: Linux for DevOps
  - Lesson 4: Module Wrap-Up and Assessment
- **Module 2: Version Control with Git**
  - Lesson 1: Fundamentals of Version Control
  - Lesson 2: Git Essentials
  - Lesson 3: Git Branching and Merging Fundamentals
  - Lesson 4: Advanced Git Techniques and Workflows
  - Lesson 5: Module Wrap-Up and Assessment
- **Module 3: Course Wrap-Up and Assessment**
  - Course Project, Final Graded Assessment

### 대상 학습자
- DevOps Engineer, System Administrator, Software Developer 지망생
- 커맨드라인 기본 조작과 일반적인 소프트웨어 개발 개념에 대한 사전 지식 권장

## 요약
- 영상 강의, 리딩 자료, 실습(데모·프로젝트), 토론 프롬프트, 퀴즈로 구성되며 마지막에 프로젝트와 최종 평가로 마무리된다.
