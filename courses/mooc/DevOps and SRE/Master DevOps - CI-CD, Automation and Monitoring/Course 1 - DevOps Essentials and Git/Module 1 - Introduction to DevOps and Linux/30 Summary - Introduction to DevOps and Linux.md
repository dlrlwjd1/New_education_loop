# Summary - Introduction to DevOps and Linux

## 개요
- Module 1(Introduction to DevOps and Linux) 전체를 4개 레슨 단위로 회고하는 요약 리딩.

## 내용
### Lesson 1: Overview of DevOps
- 개발과 운영을 잇는 DevOps의 역할, 전통적 개발 모델의 한계, 자동화·지속적 딜리버리 등 핵심 원칙, 더 빠른 배포와 높은 품질이라는 도입 효과를 다룸.

### Lesson 2: DevOps Stages and Delivery Pipeline
- 버전 관리, Continuous Integration, 배포, Configuration Management, 모니터링 등 DevOps 라이프사이클 단계와 자동화된 딜리버리 파이프라인의 중요성. Jenkins, Git 등의 도구가 핵심 구성요소로 다뤄짐.

### Lesson 3: Linux for DevOps
- DevOps 환경에서 Linux가 지배적인 이유, 파일 관리·패키지 처리·사용자 권한 등 Linux 시스템 구성요소, 시스템 관리에 필수적인 Linux 명령어, 그룹·소유권 관리를 통한 보안·자원 통제.

### Lesson 4: Module Wrap-Up and Assessment
- DevOps 핵심 원칙과 Linux 도구 복습, DevOps 라이프사이클·자동화·Linux 시스템 관리에 대한 평가 진행.

## 요약
- Module 1은 "왜 DevOps인가"(Lesson 1) → "DevOps 파이프라인 단계"(Lesson 2) → "Linux 기초"(Lesson 3) 순으로 이어지며, 이 세 축이 Module 2의 Git 학습을 위한 토대가 된다.
