# Summary - Version Control with Git

## 개요
- Module 2(Version Control with Git) 전체를 5개 레슨 단위로 회고하는 요약 리딩.

## 내용
### Lesson 1: Version Control
- 버전 관리 시스템의 중요성 — 코드 변경 관리와 협업 지원. Git으로 변경 추적, 여러 버전 관리, 복잡한 프로젝트에서의 협업이라는 이점을 다룸.

### Lesson 2: Git Essentials
- 저장소 생성, 변경사항 커밋, 프로젝트 이력 검토 등 Git의 기초 개념. 기본 Git 명령어와 운영체제별 설치 과정을 강조.

### Lesson 3: Git Branching and Merging
- 독립적인 개발 경로를 만드는 브랜칭, 브랜치 생성·전환·병합, 머지 충돌 처리와 해결 전략을 다뤄 팀원 간 원활한 협업을 지원.

### Lesson 4: Advanced Git Techniques and Workflows
- Rebase, Stash, Revert 같은 고급 기법과 GitFlow·Forking Workflow 같은 대표적인 Git 워크플로우. Git Hooks와 서브모듈을 활용한 의존성 관리도 다룸.

### Lesson 5: Module Wrap-Up and Assessment
- 버전 관리, 브랜칭, 고급 워크플로우 등 Git 핵심 기능 복습. 실제 개발 시나리오에서 Git을 효과적으로 사용하는 능력을 평가.

## 요약
- Module 2는 "왜 버전 관리인가"(Lesson 1) → "Git 기초"(Lesson 2) → "브랜칭·머징"(Lesson 3) → "고급 기법·워크플로우"(Lesson 4) 순으로 심화되며, Module 1에서 다진 DevOps·Linux 기초 위에 Git이라는 협업 도구의 전체 그림을 완성한다.
