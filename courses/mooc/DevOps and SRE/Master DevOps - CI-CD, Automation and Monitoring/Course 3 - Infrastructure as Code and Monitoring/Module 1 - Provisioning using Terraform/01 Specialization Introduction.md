# Specialization Introduction

## 개요
- Master DevOps: CI/CD, Automation & Monitoring 전문과정 전체를 소개하는 강의 (Course 1·2와 동일한 영상).

## 내용
### 전문과정 구성 (4개 강좌)
1. DevOps Essentials and Version Control with Git — DevOps 원칙, Agile, Linux 명령어, Git 브랜칭·머징
2. Continuous Integration and Deployment — Maven/Gradle 빌드 자동화, Jenkins CI/CD, Ansible 인프라 자동화
3. Infrastructure as Code and Monitoring — Terraform·CloudFormation으로 인프라 프로비저닝, Prometheus·Grafana 모니터링
4. Containerization and Orchestration — Docker 컨테이너화, Kubernetes 오케스트레이션, 모니터링·트러블슈팅

### 학습 목표
- 팀 환경에서 협업하는 개발 워크플로우 이해
- 테스트·배포를 자동화하는 CI/CD 파이프라인 구축
- Infrastructure as Code로 클라우드 리소스 프로비저닝 및 라이브 시스템 모니터링
- Docker/Kubernetes로 실제 프로덕션 시나리오의 컨테이너 배포 관리

## 요약
- 각 강좌는 이전 강좌의 지식을 기반으로 하며, 전문과정을 마치면 DevOps 실무 인증 준비가 가능한 수준의 종합 스킬셋을 갖추게 된다.
