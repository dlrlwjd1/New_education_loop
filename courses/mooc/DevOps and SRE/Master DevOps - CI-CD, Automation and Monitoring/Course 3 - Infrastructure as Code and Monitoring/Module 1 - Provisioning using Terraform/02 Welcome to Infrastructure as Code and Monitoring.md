# Welcome to Infrastructure as Code and Monitoring

## 개요
- 코스 전체 구조(4개 모듈)와 학습 목표를 안내하는 오리엔테이션 리딩.

## 내용
### 학습 목표
- Infrastructure as Code와 클라우드 자동화의 개념·이점 설명
- Terraform과 AWS CloudFormation으로 인프라 생성·관리
- 드리프트(drift) 감지·관리, 자동 업데이트, 복잡한 스택 작업 처리
- Prometheus와 Grafana로 지속적 모니터링 구현
- DevOps 환경을 위한 확장 가능하고 자동화된 인프라·모니터링 솔루션 설계

### 코스 구조 (약 4주 분량)
- **Module 1: Infrastructure as Code with Terraform**
  - Terraform으로 인프라 프로비저닝·관리, 설정(configuration)·상태 파일(state file)·모듈·Jenkins 기반 배포 자동화
- **Module 2: Cloud Provisioning with AWS CloudFormation**
  - CloudFormation 템플릿으로 인프라 개발, 스택 관리, Mapping·Condition 적용, 드리프트 감지와 스택 정책으로 일관성 확보
- **Module 3: Monitoring Automation with Prometheus and Grafana**
  - DevOps 모니터링 기초, Prometheus·Grafana로 엔드투엔드 관측성(observability) 구현, 자동화된 모니터링을 인프라 파이프라인에 통합
- **Module 4: Course Wrap-Up and Assessment**
  - 최종 프로젝트와 코스 평가로 학습 내용 검증

### 대상 학습자
- 초심자, 소프트웨어 개발자, DevOps 엔지니어, 시스템 관리자
- IaC·모니터링 도구 사전 경험은 필요 없으나 클라우드 서비스·소프트웨어 개발에 대한 기본 이해가 도움이 됨

## 요약
- 영상 강의, 리딩 자료, 실습(데모·프로젝트), 토론 프롬프트, 퀴즈로 구성되며 Terraform·CloudFormation으로 인프라를 프로비저닝하고 Prometheus·Grafana로 모니터링하는 실무 역량을 완성하는 것으로 마무리된다.
