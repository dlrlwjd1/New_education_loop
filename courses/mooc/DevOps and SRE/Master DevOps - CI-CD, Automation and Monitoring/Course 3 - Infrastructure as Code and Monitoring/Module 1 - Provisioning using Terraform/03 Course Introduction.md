# Course Introduction

## 개요
- 이 코스(Infrastructure as Code and Monitoring)에서 다룰 내용과 모듈 구성을 소개.

## 내용
### 코스 목표
- Infrastructure as Code(IaC)의 원칙과 인프라 관리 자동화에서의 역할 설명
- Terraform과 CloudFormation으로 인프라 배포 설정
- Terraform 모듈과 상태 파일(state file)을 활용한 확장 가능한 인프라 관리 구현
- Prometheus Metrics와 Grafana Dashboard로 시스템 성능 모니터링

### 모듈 구성
1. **Provisioning using Terraform** — Terraform 파일 작성법, State 관리 방식, HCL 기반 설정, 다양한 Terraform 설정 파일 종류, 변수화(variabilize), 프로덕션급 Terraform 코드 작성법
2. **Infrastructure as Code with AWS CloudFormation** — Stack, StackSet(단일 관리 계정으로 여러 AWS 계정 배포 관리), Nested Stack, Drift Detection, JSON/YAML 설정 파일 작성
3. **Monitoring with Prometheus and Grafana** — Prometheus의 메트릭 수집 방식과 Grafana 대시보드 시각화
4. **Course Wrap-Up and Assessment**

### 대상 학습자
- 특정 분야에 국한되지 않음 — 신입, 개발자, DevOps 엔지니어, 시스템 관리자, 또는 DevOps/운영 분야로 전환하려는 누구나

## 요약
- 이 코스는 Terraform·CloudFormation을 이용한 인프라 프로비저닝 자동화와 Prometheus·Grafana를 이용한 실시간 모니터링·관측성(observability) 구축을 실습 중심으로 다룬다.
