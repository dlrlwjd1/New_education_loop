# Summary - Provisioning using Terraform

## 개요
- Module 1(Provisioning using Terraform) 전체를 4개 레슨 단위로 회고하는 요약 리딩.

## 내용
### Lesson 1: Introduction to IaC and Terraform
- Infrastructure as Code(IaC)의 개념과 DevOps에서의 중요성. Terraform 아키텍처, Ansible 등 다른 도구와의 차이, 인프라 코드 라이프사이클. AWS와의 Terraform 셋업 실습.

### Lesson 2: Managing Infrastructure with Terraform
- Terraform 설정·리소스·명령어로 인프라를 생성·관리. 초기화·수정 실습, Meta Argument 사용, 리소스 참조. Terraform의 선언적 문법과 자동화 역량을 실습으로 확인.

### Lesson 3: Advanced Terraform - State, Modules, and Security
- State Management로 인프라 변경 추적, Module로 코드 조직화·재사용. Provisioner를 이용한 설정 작업, 안전한 인프라 배포를 위한 베스트 프랙티스.

### Lesson 4: Module Wrap-Up and Assessment
- Terraform의 핵심·고급 기능 복습. 인프라 프로비저닝, State 관리, 모듈, DevOps 맥락에서의 CI/CD 통합에 대한 이해도 평가.

## 요약
- Module 1은 "왜 IaC/Terraform인가"(Lesson 1) → "Terraform으로 인프라 관리"(Lesson 2) → "State·Module·보안 심화"(Lesson 3) 순으로 이어지며, Module 2에서 다룰 AWS CloudFormation의 토대가 되는 IaC 지식을 완성한다.
