# Creating an AWS Account

## 개요
- AWS 계정을 처음부터 생성하는 5단계 절차를 안내하는 실습 가이드.

## 내용
### 1단계: 이메일·계정명·비밀번호 설정
- aws.amazon.com → **Create an AWS Account**
- 이메일 주소·계정 이름 입력 → 이메일 인증 코드로 확인
- Root 사용자 비밀번호 생성 — 대문자·소문자·숫자·특수문자를 포함해야 하며, 신용카드 접근 권한이 있는 사람에게만 공유해야 하는 민감한 정보

### 2단계: 연락처 정보 입력
- 비즈니스 계정 vs 개인 계정 선택 (기능 차이는 없고 청구용 정보 요구사항만 다름)
- 계정 접근을 잃었을 때 AWS Support가 신원을 확인하는 데 사용하므로 연락처 정보를 안전하게 보관
- AWS Customer Agreement 약관 동의 후 진행

### 3단계: 결제 수단 등록
- 신용/체크카드 정보 입력 (소액 인증 결제가 발생하므로 금융기관에 등록된 주소와 일치해야 함)

### 4단계: 신원 확인
- SMS 또는 음성 통화로 인증 코드 수신 → 캡차 입력 → 코드 확인

### 5단계: 지원 플랜 선택
- Basic Support(무료, 기본값 권장), 이후 언제든 변경 가능
- **Complete sign up**으로 가입 완료 → 계정 활성화 완료 시 이메일 수신

## 요약
- AWS 계정 생성은 이메일·비밀번호 설정 → 연락처 정보 → 결제 수단 → 신원 확인 → 지원 플랜 선택의 5단계로 진행되며, 완료 후 활성화 이메일을 받으면 Terraform 등으로 AWS 리소스를 프로비저닝할 준비가 된다.
