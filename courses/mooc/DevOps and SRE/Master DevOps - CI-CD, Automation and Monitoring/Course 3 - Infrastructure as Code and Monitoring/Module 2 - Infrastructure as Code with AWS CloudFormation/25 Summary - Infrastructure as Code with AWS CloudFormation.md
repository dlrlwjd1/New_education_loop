# Summary: Infrastructure as Code with AWS CloudFormation

## 개요
- Module 2(Infrastructure as Code with AWS CloudFormation) 전체를 4개 레슨 단위로 회고하는 요약 리딩.

## 내용
### Lesson 1: Getting Started with AWS CloudFormation
- AWS CloudFormation과 인프라 배포 자동화에서의 역할 소개. 템플릿, 스택, 스택 활동(Create/Update/Delete, 상태)을 다루고 AWS 콘솔에서 스택을 생성·관리하는 방법 학습. StackSets를 이용한 다중 스택 관리도 함께 다룸.

### Lesson 2: CloudFormation Template Deep Dive
- 템플릿의 핵심 구성 요소인 Parameters, Outputs, Mappings, Conditions에 초점. Intrinsic Function을 다루고 유연하고 재사용 가능한 템플릿을 만들기 위한 Nested Stack을 실습으로 구성.

### Lesson 3: Advanced CloudFormation Features
- Stack Policy, Change Set, Drift Detection 등 인프라 무결성을 유지하기 위한 고급 주제 학습. 자동 롤백·업데이트, AWS CLI를 통한 스택 관리, 배포 활동의 모니터링·로깅도 포함.

### Lesson 4: Module Wrap-Up and Assessment
- 안전하고 확장 가능한 인프라 관리를 자동화하는 CloudFormation의 역량을 요약. 템플릿 설계, 스택 관리, 자동화, 모니터링 역량을 평가.

## 요약
- Module 2는 "CloudFormation 기초"(Lesson 1) → "템플릿 심화"(Lesson 2) → "고급 기능(정책·변경 관리·드리프트·CLI·모니터링)"(Lesson 3) 순으로 이어지며, Module 3에서 다룰 Prometheus·Grafana 기반 모니터링의 토대가 되는 CloudFormation 지식을 완성한다.
