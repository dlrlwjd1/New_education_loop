# Course Summary

## 개요
- Course 3(Infrastructure as Code and Monitoring) 전체 4개 모듈(Terraform, CloudFormation, Prometheus/Grafana, Wrap-Up)을 회고하고 커리어 전망을 안내하는 마무리 강의.

## 내용
### Module 1: Provisioning using Terraform
- 선언적(declarative) HCL 문법으로 여러 클라우드 프로바이더에 걸쳐 인프라를 정의·자동화하는 방법 학습.
- Terraform으로 EC2 인스턴스, VPC, S3 버킷을 구축·관리.
- State 파일, 모듈(Module), 프로비저너(Provisioner)의 동작 원리 이해.

### Module 2: Infrastructure as Code with AWS CloudFormation
- YAML 또는 JSON으로 AWS 리소스를 생성·관리하는 방법 학습.
- Parameters, Outputs, Mappings, Conditions 같은 기능 활용.
- Stack, StackSet, Nested Stack, Drift Detection, 스택 라이프사이클까지 탐구.

### Module 3: Monitoring with Prometheus and Grafana
- Prometheus를 설정해 지표를 수집하고 인프라 성능을 모니터링하는 방법 이해.
- Grafana로 실시간 대시보드에 지표를 시각화.
- 알림(Alert)과 데이터 소스를 통합해 Observability 확보.

### 향후 진로와 기회
- 이 코스는 **DevOps Engineer, Automation Engineer, Site Reliability Engineer** 등 다양한 커리어 역할을 준비시켜 줌.
- Terraform, CloudFormation, Prometheus, Grafana는 최신 클라우드 네이티브 환경에서 수요가 높은 기술.

## 요약
- Course 3는 Terraform으로 인프라를 프로비저닝하고, CloudFormation으로 AWS 네이티브하게 인프라를 코드화하며, Prometheus·Grafana로 모니터링·시각화·알림까지 아우르는 흐름으로 구성되어, 이수자는 DevOps/Automation/SRE 역할에 필요한 프로비저닝·자동화·모니터링 역량을 갖추게 된다.
