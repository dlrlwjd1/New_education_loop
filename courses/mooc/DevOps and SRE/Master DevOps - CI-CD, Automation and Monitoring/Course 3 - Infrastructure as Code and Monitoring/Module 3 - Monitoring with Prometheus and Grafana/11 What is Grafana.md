# What is Grafana

## 개요
- 시각화·쿼리·알림 오픈소스 플랫폼 Grafana의 정의, 핵심 기능, 동작 방식, 이점, 대표 지표·사용 사례를 정리.

## 내용
### Grafana란
- 다양한 데이터 소스의 데이터를 시각화·쿼리·알림하는 **오픈소스 플랫폼** — 메트릭, 로그, 트레이스용 대시보드를 만드는 데 자주 사용.

### 핵심 기능
1. **사용자 친화적 인터페이스** — 드래그 앤 드롭 방식으로 대시보드 생성.
2. **높은 확장성** — 개인 랩 환경부터 대규모 프로덕션 환경까지 모두 지원.
3. **내장 알림(Alerting)** — 임계값을 초과하면 Slack, Email, PagerDuty로 팀에 알림.
4. **다양한 데이터 소스 통합** — Prometheus, InfluxDB, Elasticsearch 등 여러 도구에 연결.
5. **오픈소스이며 커스터마이징 가능** — 커스텀 플러그인과 통합 지원.

### 동작 방식
1. Grafana가 시계열 데이터베이스, 로그, 클라우드 플랫폼 등 다양한 데이터 소스에 연결.
2. 사용자가 대시보드에 패널(Panel)을 정의하면, Grafana가 내장 통합 기능으로 데이터 소스를 쿼리.
3. 그래프, 테이블, 히트맵, 게이지 등으로 실시간 시각화 렌더링.
4. 패널의 데이터를 감시하도록 알림을 설정해 조건 충족 시 알림 전송.

### 이점
1. **중앙 집중식 모니터링** — 여러 도구·환경의 데이터를 통합 대시보드로 확인.
2. **높은 커스터마이징** — 라인 그래프, 히트맵, 파이 차트, 태그 패널 등 다양한 시각화 방식 선택 가능.
3. **강력한 시각화 도구**.
4. **비용 효율성** — 무료이며 오픈소스, 필요 시 엔터프라이즈 기능도 이용 가능.

### 주요 모니터링 지표 유형
- **시스템 지표(System Metrics)** — CPU 사용률, 메모리 사용률, 지연(latency), 디스크 IO, 네트워크 트래픽.
- **애플리케이션 지표(Application Metrics)** — 요청률(request rate), 오류율(error rate), 지연 시간.
- **비즈니스 지표(Business Metrics)** — 매출 추이, 사용자 참여도, 매출 추적.

### 대표 사용 사례
- **인프라 모니터링** — Prometheus와 Grafana로 CPU·메모리·디스크·업타임 추적.
- **애플리케이션 성능 모니터링(APM)** — API, 지연 시간, 오류율 추적.
- **비즈니스 KPI** — 실시간 매출 대시보드, 전환율, 사용자 참여도.
- **클라우드 모니터링** — AWS, GCP, Azure 등 클라우드 네이티브 대시보드.
- **IoT와 센서** — 온도 센서, 스마트 기기 등의 데이터를 플롯.

## 요약
- Grafana는 Prometheus 등 다양한 데이터 소스에 연결해 드래그 앤 드롭으로 대시보드를 구성하고 임계값 기반 알림을 내장 지원하는 오픈소스 시각화 플랫폼으로, 시스템·애플리케이션·비즈니스 지표를 아울러 인프라 모니터링부터 비즈니스 KPI, 클라우드·IoT 모니터링까지 폭넓게 활용된다.
