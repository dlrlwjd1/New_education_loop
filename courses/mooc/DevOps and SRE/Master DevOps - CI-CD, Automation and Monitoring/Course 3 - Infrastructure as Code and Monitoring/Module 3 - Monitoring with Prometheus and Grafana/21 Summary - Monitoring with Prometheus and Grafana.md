# Summary: Monitoring with Prometheus and Grafana

## 개요
- Module 3(Monitoring with Prometheus and Grafana) 전체를 4개 레슨 단위로 회고하는 요약 리딩.

## 내용
### Lesson 1: Prometheus for Monitoring
- 모니터링의 기초와 지속적 모니터링(Continuous Monitoring) 실무를 소개. 모니터링의 어려움을 보여주는 실제 시나리오(Trade Desk)를 살펴본 뒤, Prometheus의 지표(metrics), 아키텍처, 핵심 구성 요소를 학습. Prometheus 설치와 PromQL을 이용한 지표 쿼리도 실습으로 진행.

### Lesson 2: Grafana for Visualization
- 강력한 시각화 도구인 Grafana에 초점. Grafana의 기능, 설치·설정 과정을 학습하고, 모니터링 인사이트를 강화하는 알림(Alerting)과 주석(Annotation) 설정도 다룸.

### Lesson 3: Combining Prometheus and Grafana
- CI/CD 파이프라인 안에서 Prometheus와 Grafana를 통합해 모니터링을 자동화하는 방법을 실습. Grafana 데이터 소스를 설정하고 두 도구를 Jenkins 파이프라인에 연결해 엔드투엔드 모니터링 자동화를 구성.

### Lesson 4: Module Wrap-Up and Assessment
- Prometheus와 Grafana를 활용한 모니터링 개념과 실무 역량을 요약. 지표 수집, 시각화, 알림, 파이프라인 통합에 대한 지식을 평가.

## 요약
- Module 3은 "Prometheus로 지표 수집"(Lesson 1) → "Grafana로 시각화·알림"(Lesson 2) → "Jenkins CI/CD 파이프라인과의 통합"(Lesson 3) 순으로 이어지며, Course 3 전체(Terraform → CloudFormation → Prometheus/Grafana)를 마무리하는 모니터링 역량을 완성한다.
