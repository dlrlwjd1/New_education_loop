# Automating Monitoring with CI/CD Pipelines

## 개요
- CI/CD 파이프라인에 모니터링을 통합하는 이유와 방법, 핵심 구성 요소, 관련 도구, 도전 과제, 이점을 정리.

## 내용
### CI/CD 파이프라인에서 모니터링의 중요성
- Plan → Code → Build → Test → Release → Deploy → Operate로 이어지는 CI/CD의 모든 단계에서 지속적 모니터링(Continuous Monitoring)은 문제를 조기에 발견하게 함.
- 모니터링이 없으면: 빌드가 실패해도 개발자가 이를 모른 채 계속 개발을 이어갈 수 있고, 배포 후 애플리케이션이 실패해도 누군가 직접 테스트해보기 전까지는 알 수 없음 — 문제 탐지가 크게 지연됨.

### CI/CD에 모니터링을 통합하는 방법
1. **배포 후(Post-deployment)** — 배포 이후 애플리케이션·인프라 성능을 모니터링.
2. **배포 전(Pre-deployment)** — 배포 전 자동 테스트 실행과 빌드 상태를 점검.
3. **지속적 피드백(Continuous Feedback)** — 배포 후 시간이 지나(예: 일주일 뒤) 애플리케이션에 문제가 생겨도, 지속적 모니터링 덕분에 즉시 개발자에게 피드백이 전달됨.

### 모니터링 자동화의 핵심 구성 요소
1. **자동화된 테스트 케이스** — 코드가 정상 작동하는지 확인해 배포 준비 여부 판단.
2. **성능 지표(Performance Metrics)** — CPU·메모리 사용량 등 애플리케이션·인프라 성능 지표 수집.
3. **알림 시스템(Alerting Systems)** — Slack, Teams, WebEx, Email 등으로 문제 발생 시 즉시 알림을 보내 바로 대응 가능.
4. **로그 집계(Log Aggregation)** — 로그를 손쉽게 분류해 문제를 식별.
5. **대시보드(Dashboards)** — 인스턴스·인프라·애플리케이션 성능을 시각화.

### CI/CD 모니터링 자동화 도구
- **Prometheus** — 지표와 로그를 수집하는 서버 역할.
- **Jenkins** — Prometheus나 Grafana와 통합해 Jenkins에서 진행 중인 빌드를 모니터링.
- **Grafana** — 대시보드 시각화 담당(보통 Prometheus와 함께 사용).
- **ELK Stack** — 지표를 수집·저장하고 Kibana 대시보드로 시각화.
- **Sensu, New Relic** 등도 CI/CD에서 애플리케이션·인프라 상태를 지속적으로 모니터링하는 데 사용.

### 모니터링 자동화의 도전 과제
1. **인프라 비용 산정** — 모니터링 도구를 별도 서버에 배포해야 할 수 있어 인프라 비용 증가.
2. **대용량 데이터 저장 문제** — 로그·지표 데이터 양이 방대해 저장 공간 확보가 어려울 수 있음.
3. **도구 통합의 오버헤드** — CI 도구, 모니터링 도구, 알림 채널 등 여러 도구를 통합해야 하는 부담.
4. **오탐(False Positives)과 확장성 문제** — 네트워크나 서버의 일시적 결함으로 실제로는 문제가 없는데도 애플리케이션이 다운된 것처럼 오탐이 발생해 불필요한 인시던트·알림이 발생할 수 있음.

### 모니터링 자동화의 이점
1. **DevOps 협업 강화** — 모든 팀원이 알림을 통해 동일한 정보를 공유.
2. **빠른 문제 탐지** — 지속적 모니터링으로 문제 발생 즉시 대응 가능.
3. **코드 품질 향상** — 보안·코드 스캔 결과가 실패하면 즉시 통보되어 코드 품질 개선.
4. **시스템 가동 시간 향상** — 문제를 조기에 발견·수정해 다운타임을 최소화.
5. **더 나은 의사결정** — 모든 상황을 모두가 인지하고 있어 변경·의사결정을 더 쉽게 내릴 수 있음.

## 요약
- CI/CD 전 단계(Plan~Operate)에 자동화된 테스트·지표 수집·알림·로그 집계·대시보드를 통합하면 Prometheus·Jenkins·Grafana·ELK 같은 도구로 빌드·배포 실패를 즉시 탐지할 수 있지만, 인프라 비용·데이터 저장·도구 통합·오탐이라는 도전 과제가 따르며, 이를 감수하는 대가로 협업 강화·빠른 탐지·코드 품질·가동 시간·의사결정 개선이라는 이점을 얻는다.
