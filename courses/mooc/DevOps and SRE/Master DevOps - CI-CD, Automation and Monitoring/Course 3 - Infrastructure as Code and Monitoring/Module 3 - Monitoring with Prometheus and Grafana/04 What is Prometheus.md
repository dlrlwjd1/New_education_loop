# What is Prometheus

## 개요
- 클라우드 네이티브 모니터링 도구 Prometheus의 배경, 필요성, 핵심 기능, 이점을 정리.

## 내용
### Prometheus란
- 최신 클라우드 네이티브 인프라를 위해 만들어진 **오픈소스 시스템 모니터링·알림 툴킷** — 신뢰성과 확장성을 목표로 설계.
- **배경**: Go 언어로 작성, 2012년 SoundCloud에서 최초 개발, 현재는 **CNCF(Cloud Native Computing Foundation)**가 유지 관리, 2018년부터 성숙하고 안정적인 프로젝트로 자리잡음.
- 시스템에서 지속적으로 지표를 수집(scrape)해 실시간으로 쿼리·시각화·알림을 걸 수 있게 해주는 도구.

### 최신 인프라에서 Prometheus가 필요한 이유
- **클라우드 네이티브 기술의 부상** — 컨테이너화와 분산 시스템, Kubernetes 같은 오케스트레이션 도구 지원 필요.
- **전통적 모니터링 도구의 한계** — 레거시 도구는 마이크로서비스나 동적 환경을 제대로 다루지 못함.
- **확장성·적응성·유연성** — Prometheus는 경량이며 수평 확장 가능, 다양한 서비스·시스템·언어와 호환.
- 예: 전통적 도구는 서버를 폴링(poll)하지만, Prometheus는 애플리케이션 엔드포인트(예: `/my-app`)에서 직접 지표를 가져옴(pull).

### 핵심 기능
1. **Pull 기반 모델** — Prometheus가 일정 간격으로 대상(target)에서 지표를 가져오며, 대상은 HTTP `/metrics` 엔드포인트를 노출.
2. **다차원 데이터 모델(Multi-dimensional Data Model)** — 데이터를 시계열로 저장하며, 각 시계열은 메트릭 이름과 key-value 쌍의 차원(dimension)으로 식별.
3. **시계열 데이터 모델(Time Series Data Model)** — 시계열 데이터를 네이티브로 저장해 시간에 따른 지표 변화를 추적 용이(예: 오늘 오후 1시엔 CPU 사용률 30%, 3시간 뒤 오후 4시엔 75%로 변했다면, 타임스탬프 덕분에 언제부터 증가하기 시작했는지 파악 가능).
4. **PromQL** — 시계열 데이터를 추출·집계하는 강력한 Prometheus 전용 쿼리 언어.

### Prometheus의 이점
1. **Grafana와의 뛰어난 통합** — 시각화와 대시보드 생성을 위해 Grafana와 매끄럽게 연동.
2. **클라우드 네이티브 모니터링 지원** — Kubernetes, Docker, 마이크로서비스를 모니터링하도록 설계됨.
3. **커스텀 알림** — PromQL로 알림 조건을 정의하고 이메일, Webex, Slack, PagerDuty 등으로 알림 전송.
4. **실시간 모니터링** — 대상을 스크랩(scrape)해 몇 초 안에 그래프와 알림을 갱신.

## 요약
- Prometheus는 Go로 작성되고 CNCF가 관리하는 오픈소스 모니터링 툴킷으로, Pull 기반 모델로 `/metrics` 엔드포인트에서 시계열 지표를 수집하고 PromQL로 쿼리·집계하며, Grafana와의 통합과 커스텀 알림·실시간 모니터링을 통해 클라우드 네이티브 환경(Kubernetes, Docker, 마이크로서비스)에 최적화되어 있다.
