# Introduction to AI and Machine Learning in Observability (관찰 가능성에서의 AI·머신러닝 소개)

> 강좌: Observability Engineering: Metrics, Logs, and Traces · 모듈 3: Distributed Tracing and End-to-End Observability

## 개요
- 시스템이 방대한 메트릭·로그·트레이스를 생성하면 수동 분석이 어려워진다. AI가 어떻게 **이상 탐지·패턴 식별·통찰 자동화**를 돕고, 머신러닝(ML)이 선제적 모니터링·빠른 근본 원인 분석을 가능하게 하는지 다룬다.

## 내용

### 관찰 가능성의 실제 적용
- 시스템이 메트릭·로그·트레이스를 지속 방출 → 성능 추세·실패·서비스 상호작용 드러냄.
- 엔지니어가 이 신호를 분석해 동작 탐색·이상 조사·인과 관계 이해 → **증상에서 근본 원인으로** 이동 (추측 대신).

### 관찰 가능성에서 AI의 역할
- **행동 패턴 분석(behavior pattern analysis)** — 과거 텔레메트리로 **정상 동작**이 무엇인지 학습.
- **이상 식별(identifying anomalies)** — 경직된 수동 임계값·규칙 없이 비정상 동작·이탈 자동 탐지.
- **지속 분석(continuous analysis)** — 크고 계속 변하는 데이터셋을 실시간 모니터 (동적 클라우드 네이티브에 필수).
- **인간 증강(human augmentation)** — 엔지니어가 통제권 유지, AI는 대체가 아닌 **의사결정 지원 도구**.
- **맥락 상관(context correlation)** — 메트릭·로그·트레이스의 관련 신호 연결 → 고립된 경고가 아닌 의미 있는 통찰.

### Grafana가 적용하는 ML 기법
| 기법 | 설명 |
|------|------|
| **시계열 모델링(time-series modeling)** | 메트릭의 시간적 동작 학습 (일일 트래픽 주기, 예상 부하 변동) |
| **통계적 기준선(statistical baselines)** | 정상 동작 기준 확립 → 현재 성능을 과거 표준과 비교 |
| **비지도 이상 탐지(unsupervised anomaly detection)** | 사전 임계값·라벨 데이터 없이 비정상 패턴 자동 식별 |
| **패턴 클러스터링(pattern clustering)** | 유사 동작·이상 그룹화 → 노이즈 감소 |
| **추세·드리프트 탐지(trend & drift detection)** | 서서히 증가하는 지연·메모리 등 즉각 경고를 안 울리는 미래 위험 신호 |
| **교차 신호 상관(cross-signal correlation)** | 메트릭·로그·트레이스 간 이상 연결 → 깊은 맥락, 고립·오도성 경고 방지 |

### AI-보조(AI-assisted), AI-단독 아님
- **AI 생성 통찰**: 비정상 패턴 탐지, 교차 신호 이상 표면화, 조사 필요 영역 강조.
- **인간 주도 검증**: 분석가가 맥락적으로 AI 발견을 검토, 시스템 지식으로 검증, 적절한 시정 조치 실행.
- → AI가 트러블슈팅을 가속하되 **운영 결정은 사람이 통제**.

## 요약
- Grafana는 AI·ML로 **이상 탐지·텔레메트리 신호 상관·운영 노이즈 감소**를 통해 관찰 가능성을 강화한다.
- **자동 통찰 생성 + 인간 전문성**을 결합해 더 빠르게 대응·조사하고 신뢰성 있게 운영.
- 이 **AI-보조 접근**은 관찰 가능성을 반응적 모니터링에서 **선제적 시스템 이해**로 전환한다.
