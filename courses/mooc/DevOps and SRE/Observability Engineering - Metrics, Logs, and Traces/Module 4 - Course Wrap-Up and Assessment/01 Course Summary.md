# Course Summary (강좌 요약)

> 강좌: Observability Engineering: Metrics, Logs, and Traces · 모듈 4: Course Wrap-Up and Assessment

## 개요
- 강좌 전체를 마무리하며 배운 내용을 되짚고, 관찰 가능성 역량으로 나아갈 수 있는 진로를 정리한다.

## 내용

### 이 강좌에서 성취한 것
- 관찰 가능성의 **핵심 원리**와 현대 분산 시스템 적용 학습.
- **로그·메트릭·트레이스**를 탐구, 각 신호가 시스템 동작을 설명하는 방식 이해.
- 업계 표준 도구로 **텔레메트리 파이프라인 구축** (Prometheus·Grafana·Loki·Promtail·OpenTelemetry·Jaeger·Fluent Bit).
- 시스템 성능·지연·실패 패턴을 분석해 **근본 원인 식별**.
- 관찰 가능성 관행을 적용해 **신뢰성·가시성·운영 자신감** 향상.
- → 대규모에서 **관찰 가능하고 회복력 있으며 운영하기 쉬운** 시스템 설계 역량.

### 진로
- **관찰 가능성 엔지니어(Observability Engineer)** — 텔레메트리 플랫폼 설계·관리.
- **사이트 신뢰성 엔지니어(SRE)** — 관찰 가능성으로 시스템 신뢰성·성능 보장.
- **DevOps·플랫폼 엔지니어** — CI/CD·인프라 워크플로에 관찰 가능성 내장.
- **클라우드 운영 엔지니어** — 클라우드 네이티브 시스템 모니터·최적화.
- 공통 역량: **텔레메트리 → 통찰 → 행동**으로 전환하는 능력.

## 요약
- 메트릭·로그·트레이싱으로 현대 관찰 가능성을 구축하는 **실전 전문성**을 갖췄다.
- **반응적 모니터링을 넘어 선제적·통찰 주도(proactive, insight-driven) 시스템**을 설계할 준비 완료.
- (강좌 완료 🎉 — 이후 모듈 4에는 최종 평가(assessment)가 포함됨.)
