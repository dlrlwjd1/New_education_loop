# Metrics Visualization and Dashboard Design (메트릭 시각화와 대시보드 설계)

> 강좌: Observability Engineering: Metrics, Logs, and Traces · 모듈 2: Visualization, Alerting, and Logging Pipelines

## 개요
- 시각화가 원시 메트릭을 의미 있는 통찰로 바꾸는 방법, 운영용 **대시보드 설계**, 그리고 좋은 설계가 왜 효과적 모니터링에 중요한지 다룬다.

## 내용

### Grafana로 시각화
- **Grafana**는 Prometheus가 수집한 메트릭을 차트·그래프·인터랙티브 패널로 시각화 → 숫자 대신 한눈에 시스템 동작 이해.
- 관찰 가능성 분석 지원: 장기 추세 탐색, 서비스 간 값 비교, 이상·비정상 패턴 빠른 발견.
- **Prometheus를 데이터 소스로 직접 연결** → 추가 처리 계층 없이 실시간 조회 → 시스템 현재 상태를 지속 반영하는 **실시간 대시보드**.

### 시계열 시각화의 가치
- 단일 시점이 아니라 **시간에 따른 동작·성능 변화**를 드러냄.
- **추세 식별(trend identification)** — 느린 저하·부하 증가 같은 점진적 변화 포착.
- **성능 분석** — 피크 트래픽·배포·장애 시 시스템 반응 이해.
- **운영 통찰** — 여러 부분이 실제 조건에서 함께 어떻게 동작하는지.
- **이상 탐지(anomaly detection)** — 정상 패턴에서 벗어난 동작을 사용자 영향 전에 인식.

### 임계값·주석으로 실행 가능하게
- **임계값(thresholds)**: 허용 성능 한계를 정의하는 시각 경계 → 메트릭이 위험/비정상 범위로 갈 때 즉시 표시 → 빠른 문제 인식.
- **주석(annotations)**: 배포·운영 이벤트를 메트릭 타임라인에 직접 표시 → 갑작스러운 변화 설명, 조사 추측 감소.

### 대시보드의 실제 역할 (시각 요약 이상)
- **실시간 가시성** — 현재 메트릭으로 라이브 동작 모니터.
- **인시던트 조사** — 장애·저하 중 이상을 탐색.
- **맥락적 상관(contextual correlation)** — 관련 메트릭을 함께 보아 근본 원인 연결.
- **의사결정 지원** — 중요한 순간의 운영 행동 안내.
- **경고 보완(alert complement)** — 모니터링이 올린 경고를 검증·맥락화.

## 요약
- 효과적 시각화는 모니터링 데이터를 **운영적 명확성**으로 바꾼다.
- **Grafana + 잘 설계된 대시보드 + 의미 있는 임계값 + 정보성 주석**으로 이해·조사·행동에 필요한 가시성을 얻는다.
- 목적을 갖고 설계된 대시보드는 신뢰성·성능·의사결정을 지원하는 **공유된 진실의 원천(shared source of truth)**이 된다.
