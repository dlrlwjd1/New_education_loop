# Introduction to Performance Testing (성능 테스트 개요)

> 강좌: Foundations of Site Reliability Engineering Training (Simplilearn) · 모듈 7: Performance Testing & Advanced SRE

## 개요
- **성능 테스트(performance testing)**의 정의, 핵심 측면, 유형, 메트릭, 도구, 프로세스를 다룬다.

## 내용

### 성능 테스트란
- 시스템이 **특정 조건에서 어떻게 동작하는지** 평가 (프로덕션 환경 모방). 응답성·안정성·확장성·리소스 사용에 초점.
- 기능 테스트(functional)는 "제대로 동작하는가"를, **성능 테스트는 "사용자에 어떻게 반응하는가"**를 본다.

### 핵심 측면
- **응답 시간(response time)**, **처리량(throughput)**, **리소스 사용률**(CPU·RAM), **최대 부하 용량**, **스트레스 하 안정성**, **확장성 특성**.

### 성능 테스트 유형
- **부하 테스트(load)** — 특정 부하 조건에서의 동작.
- **스트레스 테스트(stress)** — 정상 한계를 넘겨 어디서·어떻게 실패하는지.
- **내구 테스트(endurance)** — 장시간 연속 운영.
- **스파이크 테스트(spike)** — 갑작스러운 대규모 부하 증가.
- **볼륨 테스트(volume)** — 대량 데이터.
- **확장성 테스트(scalability)** — 리소스 증감에 따른 성능 변화.

### 메트릭
- **응답 관련**: 응답 시간, 지연(latency), **TTFB(time to first byte)**, 페이지 로드 시간, 트랜잭션 시간.
- **리소스 관련**: CPU 사용률, 메모리, 디스크 I/O, 네트워크 처리량, 커넥션 풀 사용.

### 도구
- **JMeter**(오픈소스), **Gatling**(Scala), **k6**(JavaScript), **Locust**(Python 분산), **BlazeMeter**(클라우드), **LoadRunner**(엔터프라이즈).

### 프로세스
1. **계획·설계** — 목표·시나리오·성공 기준 정의.
2. **스크립트 작성**.
3. **테스트 실행·모니터링**.
4. **결과 분석** — 병목 식별.
5. **최적화·재테스트**.

## 요약
- 성능 테스트는 **프로덕션을 모방한 조건에서 응답성·안정성·확장성·리소스**를 평가한다.
- 유형: **부하·스트레스·내구·스파이크·볼륨·확장성**. 메트릭: 응답 시간/TTFB + CPU/메모리/IO.
- 도구(JMeter·Gatling·k6·Locust·LoadRunner) + 프로세스(**계획→스크립트→실행→분석→최적화·재테스트**).
