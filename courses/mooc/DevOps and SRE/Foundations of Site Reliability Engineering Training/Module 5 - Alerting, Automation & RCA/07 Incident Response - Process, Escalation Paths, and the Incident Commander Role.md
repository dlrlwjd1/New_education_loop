# Incident Response: Process, Escalation Paths, and the Incident Commander Role (인시던트 대응)

> 강좌: Foundations of Site Reliability Engineering Training (Simplilearn) · 모듈 5: Alerting, Automation & RCA

## 개요
- 인시던트 대응(incident response)의 원칙·프로세스·우선순위, 커뮤니케이션·자동화, **에스컬레이션 경로**, **인시던트 커맨더 역할**을 다룬다.

## 내용

### 원칙과 프로세스
- **원칙**: 빠른 탐지·대응, 명확한 소통 채널, 정의된 역할·책임, 문서화된 절차.
- **프로세스**: **탐지(Detection) → 분류(Triage) → 완화(Mitigate) → 조사(Investigate, 근본 원인·영향 시스템) → 해결(Resolve) → 포스트모템(학습·문서화)**. 전체 팀이 관여.

### 우선순위
- **P0**: 재해 복구 시나리오 수준.
- **P1**: 전체 다운(매우 치명).
- **P2**: 부분 서비스 장애 (예: 20% 사용자 체크아웃 실패).
- **P3**: 사소한 기능 이슈 (예: 검색 안 되지만 결제 가능) — 그래도 빨리 수정.
- **P4**: 외형 이슈 (버튼 정렬 등, 비긴급).

### 커뮤니케이션 채널
- 인시던트 전용 **Slack/Teams 채널**(실시간), **컨퍼런스 브리지**(모두 통화), **상태 페이지**(외부 이해관계자, DownDetector 유사), **인시던트 대응 관리 시스템**(추적·문서화).

### 대응 자동화 (3 pillars)
- **자동 진단(automated diagnosis)** → **런북(runbook)** 자동 실행(자동 완화) → **자가 치유(self-healing)** 시스템(탐지·복구·인간 개입 제거).

### 에스컬레이션 경로
- **1차 온콜(primary on-call)** — 첫 대응자, 분류·즉시 대응.
- **SME(Subject Matter Expert)** — 깊은 기술 지식 전문가 (온콜과 협력).
- **경영 리더십(executive leadership)** — 전체 파악, 영향 기반 결정.
- **팀 리더/매니저** — 전체 조율, 이들 간 conduit.

### 인시던트 커맨더 역할
- 대응 조율·감독, 팀원에게 작업 배정, 중요 결정, 명확한 소통 보장, **인시던트 타임라인 유지**, 정기 상태 업데이트, 인시던트 해결 선언.

## 요약
- 인시던트 대응 프로세스: **탐지 → 분류 → 완화 → 조사 → 해결 → 포스트모템**.
- 우선순위 **P0~P4**, 명확한 **소통 채널**과 **대응 자동화(진단·런북·자가 치유)**.
- **에스컬레이션 경로**(1차 온콜 → SME → 리더십, 매니저 조율)와 **인시던트 커맨더**가 전체를 조율한다.
