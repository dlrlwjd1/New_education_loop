# Correlating Observability Data (관찰 가능성 데이터 상관)

> 강좌: Foundations of Site Reliability Engineering Training (Simplilearn) · 모듈 2: Error Budgets & Observability

## 개요
- 로그·메트릭·트레이스 데이터를 **상관(correlate)**시켜 이슈의 전체 맥락과 근본 원인을 파악하는 법을 다룬다.

## 내용

### 효과적 상관
- **로그·메트릭·트레이스 전반의 데이터를 연결**해 이슈의 전체 맥락 이해.
- 핵심 방법:
  1. **이상 식별(identifying anomalies)** — 메트릭의 비정상 패턴 탐지. 요즘은 **AI**가 이를 대신할 수 있음 (과거엔 사람이 판단, 이제 여러 플랫폼에 내장).
  2. **분산 트레이스 검토** — 이상 발생 시간대의 관련 트레이스 조사.
  3. **로그 분석** — 영향받은 서비스의 로그에서 오류 메시지 검토.
  4. **정보 상관** — 이 모든 것을 종합·상관해 **근본 원인(root cause)** 규명.

## 요약
- 관찰 가능성 데이터 상관은 **로그·메트릭·트레이스를 연결**해 전체 맥락을 이해하는 것이다.
- **이상 식별(AI 활용) → 트레이스 검토 → 로그 분석 → 상관 → 근본 원인** 순으로 진행한다.
