# 6.4: Process Mining Software

## 개요
- 프로세스 마이닝 도구의 지형도와 **도구 선택 체크리스트**.
- **ProM(전 스펙트럼) vs Disco(발견·성능 특화)** 를 양 극단으로 놓는다.
- 경고: **"프로세스 마이닝은 데이터 마이닝의 일부"라는 정의상의 함정**을 피하라.

## 내용

### 도구 지형도

| 범주 | 예 | 특징 |
|---|---|---|
| **프로세스 마이닝 전용** | **ProM**, **Disco** | 프로세스 마이닝 목적으로 개발됐다. 어느 큰 스위트의 일부도 아니다 |
| **고전적 데이터 마이닝** | **RapidMiner, R, KNIME** | **프로세스 마이닝 기능이 없다** |
| **기타 상업 도구** | **Perceptive Process Mining, Celonis Discovery** | |
| **결합** | **RapidProM** | RapidMiner + ProM |

### 도구 선택 체크리스트
**정교화된 참조 모델**을 기준으로 묻는다.

1. **10개 프로세스 마이닝 활동 중 무엇이 나에게 중요하고, 무엇이 지원되는가?** 발견은? 적합성 검사는? **남은 처리 시간 예측**이 필요한가?
2. **어떤 관점이 지원되는가?** 자원? 데이터? 시간?
3. **어떤 모델링 표기법이 지원되는가?** 페트리 넷, BPMN, 그 밖에?
4. **이벤트 로그·모델·정렬 등의 임포트·익스포트 형식**은?

### ProM과 Disco 비교

| | **ProM** | **Disco** |
|---|---|---|
| 범위 | **전 프로세스 마이닝 스펙트럼**을 목표 | **발견과 성능 분석**(애니메이션 포함)에 집중 |
| 표기법 | 페트리 넷, BPMN, 선언형 언어 **Declare** 같은 이색 형식까지 | **퍼지 모델의 변형** — 밑에 실행 가능한 모델이 없다 |
| 적합성 검사 | **지원**(많은 상업 도구와 달리) | **매우 기본적인 형태만** — 특정 행동 패턴이 나타나는지 확인하는 정도 |
| 운영 지원 | **지원** | 미지원 |
| 필터링 | — | **매우 강력하다.** 이것으로 **비교 프로세스 마이닝**을 할 수 있다 |
| 사용성 | 플러그인 **수백 개**이지만 **상당수가 실험적이고 사용자 친화적이지 않다** | **매우 쉽고 성능이 뛰어나다** — **성숙한 데이터 마이닝 도구보다 훨씬 빠르다** |

### 다른 상업 도구들
> Perceptive Process Mining, Celonis Discovery 등이 있다. **범위 면에서는 Disco와 유사**하다 — **제어 흐름과 성능 분석**에 집중한다. **적합성 검사, 운영 지원, ProM의 정교한 기능들은 지원하지 않는다.** 종종 **덜 사용자 친화적이고 조금 더 느리다.**

**Celonis Discovery**: 웹 기반. 프로세스 발견을 지원하지만 **동시성을 발견하지 못한다** — 발견되는 모델이 본질적으로 **전이 시스템**이다. 빈도, 시간 정보, **애니메이션**, **매끄러운 추상화(슬라이더)**, 성능 대시보드를 제공한다.

**Perceptive Process Mining**: 웹 기반. Perceptive의 BPM 제품과 연동돼 **발견한 모델을 BPM 시스템에 자동 업로드**할 수 있다. **두 종류의 발견**을 지원 — 빠르지만 동시성을 못 찾는 것(전이 시스템)과, **유전 프로세스 마이닝 기반의 더 정교한 알고리즘**(동시성 발견 가능). 특징적 기능: **토큰을 이벤트나 케이스의 속성으로 색칠**할 수 있다 — 예: **처리 시간으로 색칠**하면 **매우 느린 케이스가 어떤 경로를 타는지** 볼 수 있다. **자원 관점**으로 바꿔 소셜 네트워크를 보고 토큰이 사람에서 사람으로 흐르는 것도 볼 수 있다.

### RapidProM
> ProM을 RapidMiner에 **임베드**해, **수십 개의 프로세스 마이닝 빌딩 블록**이 있는 그래픽 환경에서 **분석 흐름(workflow)을 구성**할 수 있다.

**워크플로 예 1**: ProM 컨텍스트 생성 → **이벤트 로그 읽기** → **알파 알고리즘**(로그 → 페트리 넷) → **정렬 기반 적합성 검사**.

**워크플로 예 2**: 이벤트 로그 로드 → **병렬로** 점 차트 생성 / 귀납적 마이너로 페트리 넷 생성 / 업무 인계 기반 소셜 네트워크 생성.

**용도**:
- **다른 이벤트 로그에 같은 워크플로를 매우 쉽게 재적용**한다
- **파라미터를 바꿔 가며 하는 과학 실험**에 유용
- **미리 포장된 분석의 재사용**
- **프로세스 마이닝과 다른 형태의 데이터 마이닝, 나아가 텍스트 마이닝의 결합**

### 다른 도구 범주는 어떤가

| 범주 | 현황 |
|---|---|
| **BPM 시스템** | **현시점에 프로세스 발견이나 적합성 검사를 지원하는 BPM 시스템은 거의 없다.** 미래에는 늘어날 것으로 예상된다 |
| **데이터 마이닝·머신러닝 소프트웨어** | 매우 관련 있지만 **어떤 형태의 프로세스 마이닝도 지원하지 않는다** |
| **예측 분석 소프트웨어** | **전혀 프로세스 지향적이지 않은** 경우가 많다 |
| **BI 도구** | 정의(Forrester)상으로는 프로세스 마이닝이 그 안에 들어가지만, **시장의 어떤 BI 제품도 실제로 프로세스 마이닝을 지원하지 않는다.** 제공하는 것은 **ETL, 질의, 리포팅, 대화형 대시보드, 경보** — **프로세스 지향적이지 않고, 이름과 달리 분석이 대체로 단순하며 스프레드시트에 가깝다** |

### 피해야 할 함정
> **"정의상 프로세스 마이닝은 데이터 마이닝의 일부"** 라는 함정을 피하라. **정의로는 참이지만**, **데이터 마이닝 소프트웨어는 프로세스 발견, 적합성 검사, 운영 지원 같은 것을 제공하지 않는다.** BI도 마찬가지다.
>
> **이 함정을 피하고 앞의 체크리스트를 쓰라.**

## 요약
- **도구 선택 체크리스트**: ① 10개 활동 중 무엇이 지원되는가 ② 어떤 관점이 지원되는가 ③ 어떤 표기법 ④ 임포트·익스포트 형식.
- **ProM**은 전 스펙트럼·다양한 표기·적합성 검사·운영 지원을 지원하지만 **복잡하고 실험적 플러그인이 많다.** **Disco**는 발견·성능·필터링에 특화돼 **매우 쉽고 빠르다.**
- 다른 상업 도구는 대체로 **Disco와 범위가 비슷**하고 **적합성 검사와 운영 지원이 없다.**
- **RapidProM**으로 프로세스 마이닝 워크플로를 만들어 **재사용·실험·다른 마이닝과의 결합**을 할 수 있다.
- **BI, 데이터 마이닝, BPM 소프트웨어는 현재 프로세스 마이닝을 지원하지 않는다.** 정의상 포함된다는 말에 속으면 안 된다.
