# Course Background and Practical Information

## 개요
- 강의: **Wil van der Aalst**(TU/e 교수, "프로세스 마이닝의 대부"로 불림) · **Joos Buijs**(조교수, 프로그램 매니저)
- 개설: **TU/e**(에인트호번 공과대학교) 데이터 사이언스 센터. 2014년 10월~2015년 12월 3회 운영, 누적 **8만 명 이상** 수강. 2016년부터 상시 수강 가능.
- 구성: **6개 모듈**(모듈당 약 1주), 모듈마다 8~15분짜리 영상 약 8개.

## 내용

### 모듈 구성

| 모듈 | 주제 |
|---|---|
| 1 | 소개와 **데이터 마이닝** 기법 |
| 2 | **프로세스 모델**과 프로세스 발견(discovery) |
| 3 | 프로세스를 모델링하는 **여러 유형의 프로세스 모델** |
| 4 | 프로세스 발견 기법 확장 + **적합성 검사(conformance checking)** |
| 5 | 프로세스 모델의 **강화(enrichment)** |
| 6 | **운영 지원(operational support)** 과 결론 |

### 학습 목표
코스를 마치면 다음을 할 수 있다.

- **비즈니스 프로세스 인텔리전스** 기법, 특히 프로세스 마이닝을 이해한다
- 프로세스 마이닝 기법을 **다른 데이터 분석 기법과 연결**해 설명한다
- 이벤트 로그와 프로세스 모델에 **기본적인 프로세스 발견과 적합성 검사**를 적용한다
- 프로세스 모델을 **프로세스·시간 정보로 확장**한다
- 프로세스 마이닝 프로젝트를 **시작하는 데 필요한 데이터**를 이해하고, 프로젝트를 **구조화된 방식으로 수행**한다

### 사용하는 도구

| 도구 | 성격 | 설명 |
|---|---|---|
| **ProM** | 학술용 · 오픈소스 | TU/e가 개발을 시작했고 전 세계에서 기여했다. 플러그인이 매우 많고 여러 모델 유형을 지원. 이 코스에서는 검증된 플러그인만 담은 **ProM Lite**를 쓴다 (promtools.org) |
| **Disco** | 상업용 | 단순·빠르고 쉽다. **퍼지 모델(fuzzy model)** 한 가지만 지원. 상업 도구가 어떤 모습인지 보여주는 예시로 사용 |

### 인증

| 종류 | 요건 |
|---|---|
| **일반 수료증** | 모듈마다 퀴즈(10점 만점, 10문항, **8문항 이상** 정답) 6회 + 최종 퀴즈(40점, 20문항, **16문항 이상** 정답) |
| **Honors 배지** | 위 + **도구 퀴즈** + **동료 평가 과제**(실제 데이터셋으로 프로세스 마이닝 보고서 작성, 다른 3명 평가) |

> 퀴즈는 재응시할 수 있지만 **문제에 여러 변형이 있어** 재시도 때 문제가 미묘하게 바뀔 수 있다. 주의해서 읽는다.
>
> 권장 순서: 모듈 1~3 동안 **도구 퀴즈**를 먼저 마치고, 모듈 4~6에서 **동료 평가 과제**를 한다.

## 요약
- TU/e의 Wil van der Aalst가 이끄는 **프로세스 마이닝 표준 MOOC**다. 6모듈 60강.
- **ProM(학술·오픈소스)** 과 **Disco(상업용)** 두 도구를 실제로 쓴다.
- 강의자의 말: **"이것은 빙산의 일각이다."** 각 기법 뒤에는 여러 편의 과학 논문이 있고, 전 세계 여러 연구 그룹이 프로세스 마이닝을 계속 확장하고 있다.
