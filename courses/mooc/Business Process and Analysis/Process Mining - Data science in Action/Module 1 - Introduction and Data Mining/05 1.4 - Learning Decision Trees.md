# 1.4: Learning Decision Trees

## 개요
- **의사결정 트리(decision tree)** 는 지도학습 기법이다 — 예측변수로 응답변수를 예측한다.
- 학습 원리는 **엔트로피(entropy)를 줄이는 방향으로 노드를 분할**하는 것이다.
- 프로세스 마이닝에서는 **발견된 프로세스 모델의 분기점(decision point)을 설명**하는 데 쓴다.

## 내용

### 의사결정 트리 읽기
**예시 1 — 생활습관과 수명.** 예측변수: 음주 여부, 흡연 여부, 몸무게. 응답변수: 사망 나이를 **70세 기준으로 이산화**해 old/young이라는 범주형으로 만든다.

학습된 트리가 말하는 것: 흡연자는 젊어서 죽을 가능성이 높다. 비흡연·비음주자는 오래 살 가능성이 높다.

**잎(leaf)의 숫자**는 학습 데이터에서 무슨 일이 있었는지 알려 준다. 예: 흡연자 195명이 모두 young으로 분류됐지만, 그중 **11명은 실제로 늙어서 죽었다** — 잘못 분류된 것이다.

**분류 확인 예**: Mary는 음주하지만 비흡연, 몸무게 70kg, 85세 사망 → 트리를 따라가면 비흡연 → 음주 → 90 미만 → **old로 예측**, 실제로도 old. **맞게 분류됨.**
Sue는 비흡연·비음주 → **old로 예측**되지만 35세에 사망. **틀리게 분류됨.**

**예시 2 — 학생 성적.** 과목별 점수가 예측변수, 결과(cum laude/pass/fail)가 응답변수. 예: 논리학이 8점 미만이고 선형대수가 6점 이상이면 pass로 예측. 논리학 성적이 없으면 fail로 예측.

**예시 3 — 카페 주문.** 응답변수를 muffin 열로 잡고 **muffin/no muffin으로 이산화**한다(수량은 무시하고 존재 여부만). 트리: 차를 마시는 사람은 머핀도 먹는다. 차도 라떼도 안 마시는 사람은 머핀을 안 시킨다.

### 학습 원리 — 엔트로피를 줄인다
> 노드를 분할해 **각 노드 안의 변동성(variability)을 줄인다.**

6명이 한 그룹에 있고 3명이 빨강, 3명이 초록이면 **엔트로피가 높다** — 어느 쪽인지 매우 불확실하다.

불확실한 노드를 **더 작고 동질적인 부분집합으로 나눈다.** 예: 흡연자/비흡연자로 나누니 흡연자 2명은 모두 젊어서 죽었다(빨강). 비흡연자는 아직 불확실하니 다시 음주자/비음주자로 나눈다. 그러면 **비흡연·비음주 그룹은 모두 오래 산다.**

### 엔트로피의 정의
> **엔트로피 = 불확실성의 정도.** 다르게 보면 **압축 가능성(compressibility)의 역수**다. 그룹 안에 변동이 거의 없으면 데이터를 많이 압축할 수 있다.

k개의 가능한 값이 있고 pᵢ가 그 값을 갖는 원소의 비율(= cᵢ/n)일 때:

```
Entropy = − Σ pᵢ · log₂(pᵢ)
```

**로그 복습**: log(2ⁿ) = n, log(1/2ⁿ) = −n, log(1) = 0, log(1024) = 10.

**계산 예시** (빨강 3, 초록 3):
- 엔트로피 = **1** → 어느 클래스인지 인코딩하는 데 **1비트**가 필요하다

흡연자로 분할한 뒤:
| 그룹 | 구성 | 엔트로피 |
|---|---|---|
| 흡연자 | 2명 모두 빨강 | **0** — 인코딩에 비트가 필요 없다 |
| 비흡연자 | 3명 초록, 1명 빨강 | **0.811** |

음주자로 한 번 더 분할:
| 그룹 | 엔트로피 |
|---|---|
| 흡연자 | 0 |
| 비흡연·음주 | **1** (반반) |
| 비흡연·비음주 | **0** |

### 정보 이득(information gain)
분할 후에는 잎들의 엔트로피를 **가중 평균**한다.

| 트리 | 가중 평균 엔트로피 | 정보 이득 |
|---|---|---|
| 분할 전(잎 1개) | **1** | — |
| smoker로 분할 | **0.54** | **0.46** |
| + drinker로 분할 | **0.33** | (추가) **0.21** |

> **엔트로피를 줄이고 싶고, 정보 이득을 최대화하는 레이블로 분할한다.**

### 알고리즘
1. **루트 노드**에서 시작 — 모든 인스턴스를 담는다
2. 모든 노드를 반복하며 **정보 이득이 가능한지** 확인
3. 가능한 **모든 속성으로 분할해 보고** 엔트로피가 실제로 줄어드는지 본다
4. **정보 이득이 가장 큰 속성**을 선택하되 **임계값 이상**일 때만
5. 그 노드를 분할하고, 유의미한 개선이 불가능해질 때까지 반복
6. 의사결정 트리를 반환

### 파라미터와 변형
- **분할 전/후 노드의 최소 크기** — **과적합 방지**(잎마다 인스턴스 하나만 있는 상황을 피함)
- **최소 이득 임계값** — 이 이득을 못 얻으면 분할 중단
- **최대 깊이**
- 한 경로에서 **같은 레이블을 여러 번 쓸지** 허용 여부 (알고리즘마다 다름)
- 엔트로피 대신 **지니 계수(Gini index of diversity)** 사용 가능
- **수치형 변수를 자동으로 범주형으로** 만들기(도메인 분할)
- **사후 가지치기(post pruning)** — 설명력을 유의미하게 높이지 않는 잎 제거

## 예시 — 엔트로피 계산 문제

9개 칸에 색깔 공이 들어 있다. **가운데 칸**에는 16개 공이 8가지 색으로 2개씩, **나머지 8칸**은 각각 16개 공이 모두 같은 색이다.

| 상황 | 엔트로피 |
|---|---|
| 가운데 칸 | **3** (8색 → 3비트 필요) |
| 나머지 칸 각각 | **0** |
| **9칸 전체의 가중 평균** | **1/3 ≈ 0.33** |
| 모든 공(144개, 18색)을 **한 통에 섞으면** | **3** |

> 정보 이득 = 3 − 0.333 = **2.666**. 이것이 의사결정 트리 학습이 하는 일이다.

## 요약
- 의사결정 트리 = **지도학습**. 응답변수는 여기서 **범주형**이다.
- 학습 원리는 **엔트로피(불확실성) 감소**다. 엔트로피는 "인코딩에 몇 비트가 필요한가"로 이해하면 직관적이다.
- 분할 후 잎들의 **가중 평균 엔트로피**와 분할 전을 비교한 것이 **정보 이득**이고, 이것을 최대화하는 속성으로 분할한다.
- 과적합을 막는 파라미터(최소 노드 크기, 최소 이득, 최대 깊이, 사후 가지치기)가 핵심 조절 수단이다.
- **프로세스 마이닝에서의 용도**: 발견된 프로세스 모델의 **분기점에서 왜 어떤 케이스는 왼쪽으로, 어떤 케이스는 오른쪽으로 가는지** 설명한다. 실행 중인 케이스가 **지연될지 거절될지 예측**하는 데도 쓴다.
- **중요**: 이 질문들은 **먼저 프로세스를 발견해야만** 가능하다. 프로세스 발견이 선행 조건이다.
