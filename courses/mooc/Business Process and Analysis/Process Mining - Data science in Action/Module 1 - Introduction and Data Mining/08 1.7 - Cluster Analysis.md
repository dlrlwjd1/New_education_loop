# 1.7: Cluster Analysis

## 개요
- **군집화(clustering)** 도 비지도학습이다 — 인스턴스를 동질적 그룹으로 묶는다.
- 대표 기법 **k-means**의 동작을 단계별로 본다.
- 프로세스 마이닝에서의 용도: **이벤트 로그를 나눠** 각 군집마다 프로세스 모델을 따로 만든다.

## 내용

### k-means의 동작
전제: **k(군집 수)를 미리 정해야 한다.** (예시에서는 k=3)

> 2차원 다이어그램으로 설명하지만 이는 **오해를 부를 수 있다.** 실제로는 수백~수천 차원인 경우가 많아 군집화가 훨씬 어렵다.

**절차**:
1. **중심점(centroid)** 을 설정한다 — n차원 공간의 점들. 무작위로 두거나 인스턴스 중 하나에 맞춘다
2. 각 인스턴스를 **가장 가까운 중심점에 배정**한다 (색칠하기)
3. 같은 색 인스턴스들의 **평균 위치로 중심점을 다시 계산**한다
4. 새 중심점을 기준으로 **다시 색칠**한다
5. 2~4를 반복한다

**수렴**: 어느 순간 더 이상 아무것도 변하지 않는 **고정점(fixpoint)** 에 도달한다.

**주의**: 무작위 초기화를 쓰면 **비결정적(non-deterministic)** 이다. 그래서 보통 **실험을 여러 번 반복해 가장 좋은 군집화를 택한다.**

### 활용
> 핵심 아이디어: **같은 군집 안의 인스턴스가 다른 군집의 인스턴스보다 서로 더 비슷하다.**

동질적 집단을 찾는 데 쓴다 — 고객, 환자, 세션, 학생 등.

**군집화 후에는 더 작은 데이터셋들이 생긴다.** 예를 들어 데이터셋을 **충성 고객 / 할인 고객 / 충동 고객**으로 나눈 뒤, 각 군집에 **다른 데이터 마이닝이나 프로세스 마이닝 기법을 따로 적용**할 수 있다 — 군집별 의사결정 트리, 군집별 연관 규칙 등.

## 예시 — 이탈리아 레스토랑 (메뉴 6개로 축소)

클래스 레이블은 무시하고(비지도) **k=2**로 실행.

**결과**: 크기가 비슷한 두 군집이 나오고, 중심점을 보면 무엇을 뜻하는지 명확하다.

| 군집 | 특징 |
|---|---|
| **군집 0** | 라자냐, 스파게티 카르보나라를 먹고 **맥주**를 마신다 |
| **군집 1** | 피자(마르게리타·시칠리아나)를 먹고 **와인**을 마신다 |

**산점도로 검증**:
- y축 = 피자 시칠리아나 주문 수, x축 = 피자 마르게리타 주문 수 → **군집 0(파랑)은 피자를 거의 안 시키고**, 빨강 군집은 피자를 시킨다
- y축 = 스파게티 카르보나라, x축 = 라자냐 → **파랑은 파스타를 시키고 빨강은 파스타를 안 시킨다**
- 음료 차원에서도 **빨강은 와인, 파랑은 맥주**

> 자동으로 발견한 군집이 이 데이터셋에서 **실제로 말이 된다는 증거**다.

## 내용 (계속)

### k-means의 한계와 대안
**단점**: **k를 미리 정해야 한다.** 군집이 3개가 말이 되는지 보려면 k=3으로 같은 작업을 다시 해야 한다.

**대안 — 계층적 군집화**: **덴드로그램(dendrogram)** 으로 군집의 **계층**을 제공한다. 유사한 인스턴스 집합을 계층적·점진적으로 묶는다.

**읽는 법**: 계층을 **어느 높이에서 자르느냐**에 따라 군집 수가 정해진다 — 자를 때 **가로지르는 선의 개수**만큼 군집이 나온다.
- 높은 추상 수준에서 자르면 → 군집 2개 (예: {a,b,c,d}와 나머지)
- 낮은 곳에서 자르면 → 더 많은 군집 (예: {a,b}, {c,d}, {e}, {f,g}, {h,i}, {j})

> 이렇게 하면 **군집 수를 매끄럽게 선택**할 수 있다.

### 프로세스 마이닝에서의 용도
**이벤트 로그를 나누는 데 쓴다.**

서로 다른 유형의 고객을 담은 이벤트 로그가 있다면:
1. 먼저 **환자나 고객의 특성으로 군집화**한다
2. 그 다음 **각 군집마다 프로세스 모델을 자동 생성**한다

이것이 프로세스 마이닝과 데이터 마이닝을 결합하는 한 방식이다.

## 요약
- **k-means**: 중심점 설정 → 가장 가까운 중심점에 배정 → 중심점 재계산 → 반복 → 고정점.
- 비결정적이므로 **여러 번 돌려 가장 좋은 결과**를 택한다.
- **k를 미리 정해야 하는 것이 약점**이다. **계층적 군집화(덴드로그램)** 는 자르는 높이로 군집 수를 나중에 정할 수 있다.
- 2차원 그림에 속지 말 것 — **실제로는 수백~수천 차원**이다.
- 프로세스 마이닝에서는 **이질적인 이벤트 로그를 동질적 군집으로 나눈 뒤 각각 프로세스 모델을 만드는** 전처리로 쓴다.
