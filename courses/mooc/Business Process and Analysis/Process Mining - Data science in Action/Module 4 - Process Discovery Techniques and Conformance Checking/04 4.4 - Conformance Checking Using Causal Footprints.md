# 4.4: Conformance Checking Using Causal Footprints

## 개요
- 적합성 검사 기법 1 — **인과 발자국(causal footprint)** 비교.
- 로그의 발자국과 모델의 발자국을 겹쳐 **불일치 셀의 비율**로 적합성을 계산한다.
- 매우 유연하지만 **빈도를 보지 않고 행동을 간접적으로만** 다룬다는 한계가 있다.

## 내용

### 아이디어
알파 알고리즘에서 쓴 **발자국 행렬**을 재활용한다. 네 관계(인과 →, 병렬 ‖, 선택 #)를 **직접 후속 관계**에서 유도한다.

> **핵심**: 발자국은 **로그에서도 만들 수 있고 모델에서도 만들 수 있다.** 모델은 트레이스를 생성할 수 있고, **모델을 정적으로 분석해서도** 이 인과 행렬을 유도할 수 있다.

### 발자국 기반 적합성 지표
> **발자국 행렬에서 로그와 모델이 일치하는 셀의 비율.**
> 1이면 완벽한 일치, 낮으면 로그와 모델이 잘 맞지 않는다.

## 예시 — 네 모델 비교

같은 로그에 대해 네 모델의 발자국 기반 적합성을 계산한다.

**모델 1 (알파 알고리즘 결과)**
> 모델의 발자국과 로그의 발자국이 **정확히 일치**한다 → **적합성 = 1**

**모델 2**
불일치 예:
- a와 d: **로그**에서는 a가 가끔 d를 뒤따르고 반대는 없다. **모델 N2**에서는 a와 d가 **서로 절대 뒤따르지 않는다**
- b와 d: **로그**에서는 어떤 순서로든 일어나 **동시(병렬)** 로 간주된다. **모델**에서는 b가 d를 뒤따르지만 d는 b를 뒤따르지 않는다 → **순차**

> **64개 셀 중 12개가 불일치** → 1 − 12/64 = **0.8125**

이 불일치를 **모델 위에 시각화**할 수 있다. 예: "원래 로그에서는 a 다음에 d가 올 수 있었는데 이제는 불가능하다".

**모델 3 (활동이 여럿 빠진 모델)**
> 모델에 **없는 활동들**은 서로도, 다른 어떤 활동도 뒤따르지 않는다. 로그에서는 뒤따랐는데 말이다.
> **16개 셀 불일치** → **0.75**

**모델 4 (꽃 모델)**
> 로그에서 본 것보다 **훨씬 많은 행동을 허용**한다.
> **45개 셀 불일치** → **0.29**
>
> 앞의 세 모델보다 **적합성이 나쁘다.** 꽃 모델이 허용하는 **막대한 추가 행동** 때문이다.

### 장점과 한계

**장점**
- **매우 유연하다** — **로그 대 로그, 모델 대 모델, 모델 대 로그** 어떤 조합이든 비교할 수 있다
- **적합도·정밀도·일반화를 암묵적으로 함께 담는다**(다만 다소 간접적으로)

**한계**
- **로그에서 트레이스의 빈도를 보지 않는다**
- **행동을 간접적으로만 고려한다** — 발자국 행렬을 만들 때 **직접 후속 관계만** 본다
  > 그래서 **행동이 다른 두 프로세스가 정확히 같은 발자국을 가질 수 있다** — 직접 후속 관계만 같으면
- **한 번에 적합도·정밀도·일반화를 뭉뚱그려 다룬다.** 실제로는 **각 차원마다 별도의 지표**를 원하는 경우가 많다

## 요약
- 인과 발자국 비교 = **로그의 발자국과 모델의 발자국을 겹쳐 불일치 셀 비율**로 적합성을 계산.
- 알파 알고리즘 결과는 **1.0**, 순서가 어긋난 모델은 **0.81**, 활동이 빠진 모델은 **0.75**, **꽃 모델은 0.29**로 가장 나쁘다.
- **꽃 모델이 재생 적합도로는 완벽한데 발자국 기반으로는 최악**이라는 점이 흥미롭다 — 발자국이 **정밀도를 간접적으로 반영**하기 때문이다.
- 한계: **빈도 무시**, **직접 후속만 보므로 행동이 달라도 같은 발자국일 수 있음**, **차원별 분리 불가**.
