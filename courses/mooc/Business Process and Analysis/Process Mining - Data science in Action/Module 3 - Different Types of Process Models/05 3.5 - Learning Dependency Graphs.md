# 3.5: Learning Dependency Graphs

## 개요
- **휴리스틱 마이너의 1단계** — 빈도를 이용해 의존 그래프를 학습한다.
- 두 가지 측정값: **직접 후속 횟수**와 **의존도(dependency measure)**.
- **의존도가 동시성과 인과성을 구분**하는 핵심 장치다.

## 내용

### 왜 필요한가 — 알파 알고리즘의 실패
예제 C-net에서 시뮬레이션으로 로그를 만들고 **이상치 두 개**(`a,b,e`와 `a,c,e` — 유효 바인딩 시퀀스가 아닌 것)를 섞었다. 여기에 알파 알고리즘을 적용하면:
- **활동 d가 다른 모든 활동과 연결되지 않는다**
- 모델상 **b와 c가 항상 실행돼야** 하는데, 로그에는 `a,e`가 있어 명백히 틀렸다

> 휴리스틱 계열 기법은 이런 문제가 없다. **핵심 재료는 빈도를 고려해 중요한 인과성만 남기는 것**이다.

### 측정값 1 — 직접 후속(direct succession)
> **|a > b|** = 로그 전체에서 **a 다음에 b가 바로 온 횟수**. 모든 트레이스를 돌며 그 안에서 몇 번인지 센다.

알파 알고리즘은 **어딘가에서 뒤따랐는지 여부**만 봤다면, 여기서는 **얼마나 자주** 일어나는지를 본다 — **더 많은 정보를 쓴다.**

### 측정값 2 — 의존도(dependency measure)
**동시성 때문에 우연히 서로 뒤따르는 것을 인과성과 혼동하면 안 된다.** 그래서 필요하다.

**a ≠ b일 때**:
```
dep(a, b) = ( |a > b| − |b > a| ) / ( |a > b| + |b > a| + 1 )
```
항상 **−1과 1 사이**의 값이 나온다.
- **1에 가까우면 매우 강한 인과성**
- **음수이거나 0에 가까우면** 그 방향의 인과성이 약하다

**a = b일 때(루프)**: 위 공식을 적용하면 **항상 0**이 나온다. 그래서 **특별 공식**을 쓴다.
```
dep(a, a) = |a > a| / ( |a > a| + 1 )
```
역시 0~1 사이이고, **클수록 자기 자신에 대한 의존(루프)이 있을 가능성이 높다.**

### 두 임계값(threshold)
의존 그래프의 각 호에 **두 숫자**를 붙인다 — **빨강 = 직접 후속 횟수**, **파랑 = 의존도**.

> **두 값 모두 임계값을 넘어야 호를 포함**한다. 요건을 만족하지 않는 호는 모두 제거한다.

## 예시 — 패턴별 계산

**순차(sequence)** — a가 b를 10번 뒤따른다.
| 방향 | 직접 후속 | 의존도 |
|---|---|---|
| a → b | 10 | (10−0)/(10+0+1) = **10/11 ≈ 0.9** |
| b → a | 0 | (0−10)/11 = **−10/11** |

임계값(직접 후속 ≥ 1, 의존도 ≥ 0.5)을 **a→b만 만족** → 호 하나 추가.

**XOR-split** — a→b 8번, a→c 2번.
- dep(a, b) = 8/9, dep(a, c) = 2/3 → **둘 다 임계값 통과** → 호 두 개

**XOR-join** — a→c 8번, b→c 2번. 마찬가지로 **호 두 개**.

**AND-split — 여기가 핵심**
a 다음에 b와 c가 오는데 **순서가 섞인다.** 고르게 분포한 로그라면 `a-b-c`와 `a-c-b`가 같은 수만큼 나온다.

> **b가 c를 5번 뒤따르고, c도 b를 5번 뒤따른다.** 동시적이라 어떤 순서로든 올 수 있기 때문이다. **그런데 b와 c 사이에 연결을 만들고 싶지 않다.**
>
> **그래서 의존도가 필요하다**: dep(b, c) = (5−5)/(5+5+1) = **0/11 = 0** → **임계값을 못 넘는다** → **연결 없음.** 정확히 원하는 결과다.

**AND-join** — 대칭적으로 같다. a와 b가 서로 5번씩 뒤따라도 dep = 0이므로 **a-b 연결이 생기지 않고**, a→c와 b→c만 승인된다.

**루프(self-loop)** — b를 포함한 셀프 루프. 로그에 `ac`, `abc`, `abbc`(3번) 등이 있다.
- **일반 공식을 쓰면 dep(b, b) = 0**이라 **b가 자기 자신과 연결되지 않는다**
- **특별 공식**을 쓰면 dep(b, b) = 3/(3+1) = **3/4** → 임계값 통과 → **셀프 루프 추가**

> **특별 공식이 없으면 b가 나머지와 연결되지 않고 떨어져 나간다.**

### 임계값으로 단순화하기
- **임계값을 낮게** 설정하면 **모든 연결이 포함**된다
- **임계값을 올리면** 호가 사라진다 — 예제에서는 **d의 셀프 루프**와 **첫 활동과 마지막 활동 사이의 연결**이 사라졌다

> **임계값을 조절해 의존 그래프를 더 단순하게** 만들 수 있다.

### 알고리즘 정리
1. **임계값을 설정**한다
2. **직접 후속을 센다**
3. 두 공식으로 **의존도를 계산**한다
4. **두 임계값을 모두 만족하는 호만** 포함해 의존 그래프를 그린다

### Disco와의 관계
> Disco의 모델도 **페트리 넷이나 BPMN처럼 명시적 의미론을 갖는 것이 아니라 의존 그래프로 생각**하면 된다. **슬라이더를 조절하면** 임계값을 조절하는 것과 같다 — 낮추면 모든 호가 포함되고, 올리면 임계값을 못 넘는 연결이 사라져 **모델이 점점 단순해진다.**
>
> 밑에 깔린 알고리즘은 다르지만 **정확히 같은 유형의 아이디어**를 쓴다.

## 요약
- 휴리스틱 마이너 1단계 = **빈도 기반 의존 그래프 학습**.
- 두 측정값: **직접 후속 횟수**(빈도)와 **의존도**(인과성의 강도, −1~1).
- **의존도의 존재 이유는 동시성 배제**다. 동시 활동은 양방향으로 비슷하게 뒤따르므로 **분자가 0에 가까워져 연결이 생기지 않는다.**
- **루프(a = b)에는 별도 공식**이 필요하다 — 안 그러면 항상 0이 되어 활동이 고립된다.
- **두 임계값을 모두 넘는 호만** 남기고, **임계값 조절이 곧 모델 단순화**다. Disco의 슬라이더가 같은 원리다.
