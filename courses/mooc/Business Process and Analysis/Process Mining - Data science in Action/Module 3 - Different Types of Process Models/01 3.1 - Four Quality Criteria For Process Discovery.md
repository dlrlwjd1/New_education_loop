# 3.1: Four Quality Criteria For Process Discovery

## 개요
- 프로세스 발견 품질의 **네 가지 힘**: **적합도(fitness) · 단순성(simplicity) · 정밀도(precision) · 일반화(generalization)**.
- **혼동 행렬을 그대로 쓸 수 없는 이유** — 실제 프로세스를 모르고, 음성 예시가 없다.
- 비행기를 띄우는 네 힘처럼 **네 힘의 균형**을 잡아야 한다.

## 내용

### 근본 문제 — 실제 프로세스를 모른다
프로세스가 이벤트 로그에 흔적을 남긴다. 우리는 모델과 **실제 프로세스**의 관계를 말하고 싶은데, **실제 프로세스는 알 수 없다.** 오직 **이벤트 데이터에 대해서만** 말할 수 있다.

**분류 문제로 보면** (벤 다이어그램: 사각형 = 모든 가능한 행동, 빨강 = 실제 행동, 초록 = 모델 행동):

| 칸 | 뜻 |
|---|---|
| **TP** | 모델에서도 가능하고 실제 프로세스에서도 가능한 트레이스 ✅ |
| **TN** | 모델에서도 불가능하고 실제로도 불가능 ✅ |
| **FP** | **모델에서는 가능한데 실제로는 불가능** ❌ |
| **FN** | **모델에서는 불가능한데 실제로는 가능** ❌ |

**그런데 적용할 수 없다.** 발견한 모델이 허용하는 행동은 알지만, **실제 프로세스가 허용하는 행동은 모른다.** 작은 예시 집합만 보고 결론을 내려야 한다. **공식을 그냥 쓸 수 없다.**

**대신 쓸 수 있는 것 — 재생 적합도(replay fitness)**: 로그에서 본 행동을 기준으로 TP′/(TP′+FN′)를 계산한다. 로그의 모든 행동이 모델에서 가능하면 **재생 적합도 = 1**이다.

### 그 밖의 어려움
- **음성 예시가 없다.** 로그는 무엇이 **불가능했는지** 절대 말해 주지 않는다
- 로그는 가능한 트레이스의 **아주 작은 일부**만 담는다 → **과적합을 피해야** 한다
- 맞고 틀리고의 이분법이 아니라 **"이 케이스가 저 케이스보다 더 잘 맞는다"** 를 따질 수 있어야 한다
- 모델에 루프가 있으면 **가능한 트레이스가 무한**하다 → **트레이스를 셀 수 없다**

> **프로세스 마이닝의 머피의 법칙**: **충분히 오래 기다리면 무엇이든 일어난다.** 그러므로 "가능한가"는 흥미로운 질문이 아니다. **중요한 것은 가능성(likelihood)** 이고, 모델은 **일정 수준 이상의 가능성을 가진 것만** 나타내야 한다.

### 네 가지 힘
비행기를 공중에 띄우는 네 힘처럼, 프로세스 마이닝에도 네 힘이 있다.

| 힘 | 뜻 |
|---|---|
| **적합도(fitness)** | 관찰된 행동을 모델이 재생할 수 있는가 |
| **단순성(simplicity)** | **오컴의 면도날.** 가능한 한 단순해야 한다 |
| **정밀도(precision)** | 본 데이터와 **무관한 온갖 행동을 허용하면 안 된다** |
| **일반화(generalization)** | **과적합하면 안 된다.** 충분히 일반적이어야 한다 |

### 극단 사례로 이해하기
예제 로그: 21개의 서로 다른 트레이스, 총 약 1,400건.

| 모델 | 적합도 | 단순성 | 정밀도 | 일반화 |
|---|---|---|---|---|
| **적절한 모델** | 좋음 | 좋음 | 좋음 | 좋음 |
| **가장 빈번한 트레이스만 허용** | **나쁨** — 나머지가 안 맞음 | 좋음 | 좋음 | **나쁨** — 다음 관찰이 안 맞을 가능성이 크다 |
| **꽃 모델(flower model)** — 시작·끝 빼고 사이에 무엇이든 몇 번이든 | **완벽** | 매우 좋음 | **나쁨(과소적합)** — `a,b,b,b,g` 같은 말도 안 되는 트레이스도 허용 | 좋음 |
| **21개 트레이스를 그대로 나열한 모델** | 좋음 | **나쁨** — 매우 복잡 | 좋음 | **나쁨(과적합)** — 예시 행동만 허용, **예측력이 없다** |

> **과적합 모델의 정의**: **다음에 관찰할 트레이스가 모델에 맞지 않을 가능성이 높은** 모델.
> **과소적합 모델의 문제**: **정밀도** — 본 것보다 훨씬 많은 행동을 허용한다.

## 예시 — 판정 연습

| 상황 | 판정 | 이유 |
|---|---|---|
| 로그는 `a,c,e`(77회)·`b,c,d`(92회)인데 모델은 `a,c,d`·`b,c,e`만 허용 | **적합도 나쁨** | 로그의 어떤 트레이스도 모델에서 불가능하다 |
| 모델이 로그와 크게 다른 행동을 허용하지 않음 | **정밀도 좋음** | 과소적합이 아니다 |
| 모델이 `c`를 10번 연속 허용 | **정밀도 나쁨** | 로그에서 매우 있을 법하지 않은 트레이스를 허용 |
| 트레이스 5개가 모두 매우 드묾 | **일반화 나쁨** | 6번째 트레이스가 본 것과 다를 가능성이 크다 |
| 모든 트레이스가 빈번 | **일반화 좋음** | 다음 관찰이 크게 다를 이유가 없다 |
| 모델이 `b`가 최대 4번 반복되는 것만 허용(로그가 그랬으므로) | **단순성 나쁨** | 지나치게 복잡하고 이 로그에만 특화됐다. 5~6번 반복이 쉽게 일어날 수 있다 |

> **일반화는 아직 보지 못한 행동에 대해 추론**하므로 가장 어려운 개념이다.

## 요약
- 네 힘: **적합도 · 단순성 · 정밀도 · 일반화**. 서로 **트레이드오프**가 있어 프로세스 발견이 어렵다.
- **혼동 행렬을 그대로 쓸 수 없다** — 실제 프로세스를 모르고, **음성 예시가 없고**, 루프가 있으면 트레이스가 무한하다.
- **꽃 모델**(적합도 100%, 정밀도 0)과 **트레이스 나열 모델**(정밀도 좋음, 일반화 0)이 두 극단이다.
- **머피의 법칙**: 충분히 기다리면 무엇이든 일어난다. 중요한 것은 **가능성**이지 가능 여부가 아니다.
- **표현 방식(representational bias)** — 모델이 동시성, OR-join, 취소, 우선순위, 중복 활동을 허용하는지 — 가 이 네 힘과 밀접하게 연결된다.
