# 3.8: Using Regions to Discover Concurrency

## 개요
- **영역 기반 발견의 2단계** — 전이 시스템을 **접어서(fold)** 동시성을 가진 훨씬 간결한 페트리 넷으로 만든다.
- **상태 기반 영역(state-based region)** = 페트리 넷의 **자리 하나에 대응하는 상태 집합**.
- 영역이 폭발하므로 **최소·비자명(minimal, non-trivial) 영역**만 쓴다.

## 내용

### 기본 아이디어
> 전이 시스템에서 **정확히 하나의 자리에 대응하는 상태 부분집합**을 찾아낸다. 이렇게 만든 자리는 **행동에 대한 제약**이 되고 동시성까지 담아낸다.
>
> **수천 개 상태를 가진 전이 시스템을 자리 몇 개짜리 페트리 넷으로 줄일 수 있다.**

### 영역의 정의
상태 집합 R을 보고, R로 **들어오는 화살표 · 나가는 화살표 · 안에 머무는 것 · 밖에 머무는 것**을 따진다.

> **모든 활동 레이블에 대해 합의(consensus)가 있어야 한다.**
> - 어떤 **a 화살표 하나가 들어오면(entering)**, **모든 a 화살표가 들어와야** 한다. 나가거나 안에 머물러서는 안 된다
> - 어떤 **c 화살표 하나가 나가면(exiting)**, **모든 c 화살표가 나가야** 한다
> - 어떤 **a가 경계를 넘지 않으면**, **어떤 a도 경계를 넘어서는 안 된다**

이 성질을 만족하는 상태 집합이 **영역**이고, 대응하는 페트리 넷의 **자리 후보**가 된다.

**전제**: 초기 상태가 하나여야 한다(없으면 인공 시작 활동을 추가하면 된다). 최종 상태도 하나가 선호된다. **모든 상태가 도달 가능**해야 한다.

### 예시 — 영역인 것과 아닌 것

**영역인 예 1**: 빨간 상태 4개. a 호 하나가 **들어오고**, b 호 4개가 **모두 나간다**(빨강→무색). c, d, e는 **안에 머물거나 밖에 머물러 경계를 넘지 않는다.**
> → **a가 토큰을 넣고 b가 토큰을 가져가는 자리**에 대응한다.

**영역인 예 2**: a는 안 넘고, **b가 들어오고, e가 나간다**, c·d는 안 넘는다.
> → **b를 마지막 전이에 잇는 자리**에 대응한다.

**영역인 예 3**: **상태 하나짜리** 영역. a가 나가고 나머지는 안 넘는다.
> 이 영역이 **초기 상태를 포함**한다 → **대응하는 자리에 토큰 하나를 놓는다.**

**영역이 아닌 예**: 빨간 상태 3개인데 **어떤 b는 나가고 어떤 b는 경계를 안 넘는다** → **b에 대한 합의가 없다.** c, d에 대해서도 마찬가지다. → **영역이 아니다.**

### 영역의 폭발과 두 가지 정리

> **두 영역의 임의의 조합도 다시 영역**이다. 그래서 **영역의 수가 폭발**한다.

**연습 1 — 동시 활동 n개**: 상태는 2^n개.
> 영역 안에서 **두 활동이 동시에 나가는 상황은 있을 수 없다** — 그러면 경계를 안 넘는 a와 b도 반드시 생기기 때문이다. 따라서 **영역 경계를 넘을 수 있는 전이 레이블은 최대 하나**다.
>
> 이 논리로 상태를 두 그룹으로 나누는 방법이 **n가지**이고 각각이 영역이다. 여기에 **공집합**과 **전체 집합**을 더해 **2n + 1개**. **괜찮은 수준이다.**

**연습 2 — 순차 활동 n개**: 상태는 n+1개.
> **모든 상태 부분집합이 영역**이다 → **2^(n+1)개**. 활동 10개를 순차 실행하는 데 **2,000개 넘는 영역**, 즉 자리가 2,000개 넘는 페트리 넷이 나온다.

> 그래서 **최소·비자명 영역만** 고려해야 한다.

### 최소·비자명 영역

| 개념 | 정의 |
|---|---|
| **자명한(trivial) 영역** | **공집합**과 **모든 상태의 집합**. 정의상 영역이지만 **아무 정보도 담지 않으므로 버린다** |
| **여집합(complement)** | 어떤 영역 R이 있으면 **전체 상태 − R도 정의상 영역**이다 |
| **최소(minimal) 영역** | **더 작은 비자명 영역으로 분해될 수 없는** 영역. 큰 영역에 작은 영역이 포함돼 있으면 **그 차집합도 정의상 영역**이므로, 큰 영역은 쪼갤 수 있다 |

> **모든 추론에서 최소 영역만 고려**해 페트리 넷의 자리 폭발을 막는다.

### 알고리즘
1. 전이 시스템의 **각 전이 레이블마다 페트리 넷 전이를 하나** 추가한다. (전이 시스템에 같은 레이블의 전이가 여럿이어도 **모두 하나의 전이로 매핑**된다)
2. **최소 비자명 영역을 계산**한다 — 더 이상 분해할 수 없을 때까지 영역을 쪼갠다
3. 각 최소 비자명 영역을 **자리로 변환**한다. 입력과 출력은 **무엇이 들어오고 나가는지**를 보면 명확하다
4. **초기 상태를 포함하는 영역에 대응하는 자리에 토큰**을 놓는다

결과는 **최소 포화 넷(minimal saturated net)** 이다.

## 예시 — ProM에서의 검증

**검증 방법**: 페트리 넷을 하나 잡고 → **도달가능성 그래프를 구성**(1,000개 넘는 상태로 시각화조차 어려운 거대한 전이 시스템) → **상태 기반 영역을 적용**.
> **이 상태와 전이의 난장판에서 원래 있었던 동시성을 다시 발견해 낸다.**

**알파 알고리즘과 비교 1**: 알파 알고리즘 강의에서 본 로그에 이 접근을 쓰면 **알파 알고리즘과 정확히 같은 페트리 넷**이 나온다(끝의 중복 자리 두 개까지 동일).

**알파 알고리즘과 비교 2 — 영역이 이기는 경우**
로그: `a, c, d` 와 `b, c, e`. 전이 시스템을 **과거 + 다중집합 추상화**로 만들고 영역을 계산하면:

> **a와 d 사이의 인과성, b와 e 사이의 인과성을 담는 자리 두 개**가 발견된다. **a와 d, b와 e가 서로 절대 직접 뒤따르지 않는데도** 말이다.
>
> **알파 알고리즘은 이 상황에서 너무 일반적인(과소적합) 모델을 만들지만, 영역을 쓰면 올바른 모델을 찾는다.**

## 요약
- **상태 기반 영역** = 모든 활동 레이블에 대해 **들어옴/나감/안 넘음의 합의**가 성립하는 상태 집합. **페트리 넷의 자리**에 대응한다.
- **초기 상태를 포함하는 영역** → 그 자리에 **초기 토큰**.
- 영역은 조합으로 폭발한다(순차 n개 → 2^(n+1)개). 그래서 **자명한 영역(공집합·전체)을 버리고 최소 영역만** 쓴다.
- 알고리즘: 전이 레이블 → 전이, **최소 비자명 영역** → 자리, 초기 상태 포함 영역 → 토큰.
- **영역 기반 접근의 강점**: 알파 알고리즘이 놓치는 **비국소 의존성(a→d, b→e)** 을 발견할 수 있다.
