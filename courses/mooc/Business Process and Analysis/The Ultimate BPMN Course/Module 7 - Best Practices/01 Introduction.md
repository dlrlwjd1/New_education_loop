# Introduction

## 개요

- Module 5와 마찬가지로 **새 요소가 없는 특별 챕터**
- 대신 **모델링 best practice**를 배운다
- 강사의 표현: **모델의 정확성·품질·표현력을 즉시 끌어올리는 지름길(shortcut)**

## 내용

### 이 챕터에서 다루는 다섯 가지

| 주제 | 배우는 것 |
|---|---|
| **Scoping(범위 설정)** | 프로세스가 너무 커지거나 압도적이 되지 않게 **명확하고 관리 가능하게** 유지하는 간단한 규칙 |
| **Collaboration(협업)** | 서로 다른 프로세스 참여자 간의 **상호작용을 올바르게 정의**하는 법 |
| **Naming(명명)** | BPMN 요소에 **정확하게 레이블을 붙이는** 직관적 기법 |
| **Consistent process flow(일관된 프로세스 흐름)** | **숙련된 모델러도 저지르는 흔한 실수**를 피하는 법 |
| **Success path(성공 경로)** | 프로세스 품질을 **진정한 전문가 수준으로** 끌어올리는 강력한 개념 |

## 요약

- 이 챕터는 **"맞는 모델"에서 "좋은 모델"로** 넘어가는 규칙을 다룬다
- 다섯 축: scoping · collaboration · naming · consistent flow · success path
