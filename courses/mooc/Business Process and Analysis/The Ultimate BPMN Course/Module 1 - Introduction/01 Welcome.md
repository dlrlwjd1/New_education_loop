# Welcome

## 개요

- 강사 소개와 코스 전체 로드맵을 안내하는 오리엔테이션 강의
- 강사는 두 명이며 서로 다른 직군에서 BPMN을 사용해 온 경험을 공유한다
- BPMN을 "도구"가 아니라 **역할 간 공용 언어(universal language)** 로 규정한다

## 내용

### 강사

| 이름 | 직군 | 배경 |
|---|---|---|
| Fabian | 대기업 lead software engineer | 8년간 복잡한 소프트웨어 시스템 구축·관리·최적화. BPMN을 기술 관점과 비즈니스 관점을 잇는 도구로 활용 |
| Sebastian | 빠르게 움직이는 스타트업의 product manager | 10년간 여러 산업에서 risk management, automation, business transformation 업무 수행 |

두 사람은 서로 다른 직군에 있지만 **BPMN이라는 공통 기반**을 찾았다고 말한다. 대기업의 대규모 시스템 관리부터 스타트업의 빠른 혁신까지, 환경을 가리지 않고 역할 사이를 연결하며 가치를 만든다는 것이 이 강의의 전제다.

### 강의 분담

- **Fabian** — BPMN의 기초 원리와 실제 시나리오 적용
- **Sebastian** — 고급 BPMN 요소와 개념, 복잡한 use case 처리

### 코스 전체 흐름

1. **기초** — token, task, pool, lane
2. **고급 요소** — gateway, event, sub-process
3. **실전 case study**
   - 컨설팅 회사의 채용(hiring) 프로세스 간소화
   - 소매업체의 판매 전략 개선
   - 병원의 risk management 최적화
   - 은행 프로세스 현대화
4. **Best practice**
   - **15 task rule** 을 이용한 scoping
   - 명확한 naming convention
   - deadlock, multi-merge 같은 흔한 함정 피하기

각 챕터에는 이해도를 검증하는 실습 과제(practical assignment)가 포함된다.

## 요약

- BPMN은 특정 직군의 도구가 아니라 기술·비즈니스 양쪽이 함께 쓰는 공용 언어다
- 코스는 기초 요소 → 고급 요소 → 실전 case study → best practice 순으로 진행된다
- 코스를 마치면 BPMN을 아는 데서 그치지 않고 조직을 더 agile·efficient·compliant하게 만드는 데 적용할 수 있어야 한다
