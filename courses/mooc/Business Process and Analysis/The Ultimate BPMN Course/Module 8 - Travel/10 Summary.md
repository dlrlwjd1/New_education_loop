# Summary

## 개요

- **BPMN 기초(fundamentals)를 다루는 마지막 챕터의 정리**
- 이 시점에서 코스 전반부가 끝나고, 후반부는 Sebastian이 진행한다

## 내용

### 이 챕터에서 추가한 요소

| 요소 | 역할 |
|---|---|
| **Link event** | **sequence flow를 대체**하고 **가독성을 위해 프로세스를 자른다** |
| **Sub-process** | **level 1에서 정보를 추상화**하고 **level 2에서 상세 서술**을 제공한다 |
| **Call activity** | **여러 workflow에서 재사용 가능한 전역 정의 프로세스**에 접근한다 |
| **Data object** | 프로세스 내의 **데이터 흐름을 시각화**한다 |
| **Data store** | **프로세스와 독립적으로 데이터를 저장·수정할 수 있는 장소**를 정의한다 |

### 강사의 마무리

> 이 새로운 기술과 도구로 **명확하고 효율적이며 효과적인 프로세스를 설계할 준비**가 되었고, **공동 강사 Sebastian이 소개할 고급 프로세스 시나리오에 도전할 준비**도 되었다.

## 요약

- **BPMN 기초 파트가 여기서 끝난다**
- 구조화 도구 3종(link event · sub-process · call activity)과 데이터 표현 2종(data object · data store)이 이 챕터의 수확이다
- **구조화 도구의 차이를 다시 정리하면**
  - **Link event** — 같은 레벨, 옆으로 자른다
  - **Sub-process** — 아래 레벨로 파고든다 (그 프로세스 전용)
  - **Call activity** — 아래 레벨로 파고든다 (전역 재사용)
