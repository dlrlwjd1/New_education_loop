# Introduction

## 개요

- **코스 전반부(first part)의 마지막 챕터**
- 이 섹션 이후 진행자가 **Fabian에서 Sebastian으로 교체**된다
- 배울 것: **link event, data object, sub-process, call activity**

## 내용

### 이 챕터에서 배울 것

1. **Link event** — 프로세스를 구조화하는 도구
2. **Data object** — 프로세스를 흐르는 데이터
3. **Sub-process** — 계층적으로 상세도를 나누는 방법
4. **Call activity** — 전역으로 정의된 재사용 가능한 프로세스

### 실전 사례

**휴가 비자(holiday visa) 규정 준수 절차(compliance procedure)** 에 이 요소들을 적용한다. 아름다운 **Dream Island** 여행을 앞두고 남은 마지막 단계라는 설정이다.
