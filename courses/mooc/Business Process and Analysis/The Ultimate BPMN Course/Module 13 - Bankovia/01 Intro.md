# Intro

## 개요

- Module 13 도입부. 사례는 구식 은행 **Bankovia**
- 이 챕터를 마치면 **BPMN 2.0의 모든 event를 알게 된다**
- 배울 것: **compensation · cancel · multiple · multiple parallel** event

## 내용

### 상황

**Bankovia**는 **디지털 제품을 이제 막 탐색하기 시작한 매우 구식인 은행**이다.

**요청 사항**: **고객이 송금할 수 있는 앱을 제공**하는 것

> **21세기에 은행이라면 당연히 할 수 있어야 할 것 같은데 말이다.**

우리가 할 일은 **정확히 그것을 수행하는 프로세스를 수립**하는 것이다.

> **이것은 상당히 기술적인(technical) 프로세스가 될 것이고, 그래서 여기서 BPMN event 세트 전체가 매우 유용해진다.**

### 이 챕터에서 배울 마지막 4가지 event

1. **Compensation event(보상 이벤트)**
2. **Cancel event(취소 이벤트)**
3. **Multiple event(다중 이벤트)**
4. **Multiple parallel event(다중 병렬 이벤트)**

> **뒤의 두 개(multiple, multiple parallel)는 말하자면 선택적(optional) event이고 자주 쓰이지 않는다. 하지만 완전성을 위해 당연히 다룬다.**

### 이 챕터를 마치면

> **BPMN 2.0에 존재하는 모든 event를 알게 되고, 어떤 프로세스 설계 과제든 해결할 준비가 된다.**

## 요약

- Module 13은 **BPMN event 13종을 완성**하는 챕터다
- **compensation과 cancel은 실용적**이고, **multiple 계열 두 개는 강사도 사용을 권하지 않는다**
- 사례는 구식 은행의 **모바일 송금 앱 프로세스**다
