# Summary

## 개요

- Module 2에서 배운 BPMN 기초 요소를 정리하는 강의

## 내용

### 이 챕터에서 익힌 요소

| 요소 | 역할 |
|---|---|
| **Start event** | 프로세스를 촉발하는 **상태(state)** 를 정의한다 |
| **End event** | 프로세스의 **종료**를 나타낸다 |
| **Activity / Task** | 수행되어야 할 **행동(action)** 을 서술한다 |
| **Exclusive gateway** | **결정 지점(decision point)**. 오직 하나의 경로만 선택된다 |
| **Pool과 Lane** | 특정 task를 역할이나 부서에 배정해 **책임을 명확히** 한다 |

이 요소들이 효과적이고 명확한 프로세스 모델을 만드는 토대다.

## 요약

- event(상태) · activity(행동) · gateway(논리) — 세 축을 기억한다
- exclusive gateway의 핵심은 **하나의 경로만 선택된다**는 것
- pool·lane은 "무엇을 하는가"가 아니라 **"누가 하는가"** 를 담당한다
