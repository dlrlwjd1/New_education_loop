# Introduction

## 개요

- BPMN 첫 강의. 이 챕터에서 다룰 내용을 예고한다
- BPMN을 강력하게 만드는 **세 가지 핵심 요소**: event, activity, gateway

## 내용

### 이 챕터에서 배울 것

1. **세 가지 core element** — event(이벤트), activity(활동), gateway(게이트웨이)
2. **Pool과 Lane** — 프로세스에서 **누가 무엇을 책임지는지**를 명확하게 만드는 요소
3. **소매(retail) 실전 사례** — 신입 매장 직원 Max가 BPMN을 활용해 업무를 처리하고 고객을 만족시키는 과정

### 학습 순서

기초 요소를 먼저 익힌 뒤(`event` · `activity` · `gateway`), 책임 소재를 표현하는 `pool`·`lane`으로 한 단계 올라가고, 마지막으로 실제 소매 현장 시나리오에 적용한다.

## 요약

- BPMN의 세 가지 핵심 요소는 event, activity, gateway다
- pool과 lane은 "누가 책임지는가"를 그림에 담는 장치다
- 이 챕터는 신입 직원 Max의 소매 매장 사례로 마무리된다
