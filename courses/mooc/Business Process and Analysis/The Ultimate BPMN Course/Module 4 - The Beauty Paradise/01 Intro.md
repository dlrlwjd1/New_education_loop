# Intro

## 개요

- Module 4 도입부. 이 챕터에서 다룰 새 기호들을 예고한다
- **세 번째 gateway**와 **네 가지 새 event 유형**을 배운다

## 내용

### 이 챕터에서 배울 것

1. **세 번째 BPMN gateway** — inclusive gateway
2. **네 가지 새 event 유형** — message event 계열
3. **Collapsed pool** — 외부 주체(entity)와의 협업(collaboration)을 모델링하는 방법
4. **실습 파트** — **정보를 아는 closing gateway(informed closing gateway)** 가 왜 중요한지 확인한다

### 학습 순서

collapsed pool → message event → gateway 순으로 이론을 본 뒤 실습으로 넘어간다.

## 요약

- Module 4의 세 축은 **inclusive gateway**, **message event 4종**, **collapsed pool**이다
- 실습의 초점은 **closing gateway가 들어오는 토큰 흐름을 알고 있어야 한다**는 점이다
