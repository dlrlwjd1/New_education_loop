# Exercise

## 개요

- Module 4 실습 과제
- 과제: Susan이 **고객 경험을 더 최적화하기 위해 만든 또 다른 프로세스**를 모델링한다

## 내용

### 과제

Susan은 고객 경험을 더 개선하고 싶어 하며 새로운 프로세스를 구상했다. 그 내용을 코스 슬라이드의 과제 텍스트에서 확인하고 직접 모델링한다.

### Token simulator로 검증하기

> 모델링을 마치면 **token simulator를 사용해 토큰이 프로세스를 흘러가는 모습을 관찰**한다. 모델을 테스트하고 다듬는 빠른 방법이다.

- 접속: `processcamp.io/profile/links`
- 질문이 있으면 `fabian@processcamp.io`

### 해설에 대한 강사의 안내

> **activity 표현이 조금 다르더라도 전혀 문제없다.** 같은 것을 서술하는 방법은 대개 여러 가지다.

중요한 것은 **구조**이지 문구가 아니다. 해설을 보며 자기 모델을 차분히 검토하고 평가하면 된다.

## 요약

- 실습의 목적은 Module 4의 요소(inclusive gateway · message event · collapsed pool)를 실제로 배치해 보는 것이다
- **token simulator가 검증 도구**다. 토큰 흐름을 눈으로 보면 구조적 오류를 빨리 찾을 수 있다
- **activity 문구는 정답이 하나가 아니다.** 구조가 맞는지를 본다
