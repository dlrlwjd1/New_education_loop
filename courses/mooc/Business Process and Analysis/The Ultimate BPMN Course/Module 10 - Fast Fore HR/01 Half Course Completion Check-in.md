# ½ Course Completion Check-in

## 개요

- **코스 후반부(advanced part)의 시작**. 진행자가 **Sebastian**으로 교체된다
- 앞으로 다룰 내용의 전체 로드맵을 안내한다

## 내용

### 후반부 전체 로드맵

**1. BPMN task types — Fast Fore 컨설팅 회사**

- 컨설팅 회사 **Fast Fore**의 사례로 시작한다
- 이들은 **많은 인력을 채용하려 하며, 그러려면 잘 다듬어지고 자동화된 채용 프로세스가 필요하다**
- **BPMN 프로세스가 시작점으로 완벽하지만, 이를 한 단계 끌어올려 자동화 준비를 갖추려면 task type이 필수적(indispensable)이다**

> **BPMN을 자동화(automation) use case에 어떻게 적용하는지 이해하고 싶다면 이 부분이 핵심이다.**

**2. Sub-process와 loop — 두부 소매업체**

- 짧은 이론 후 **두 번째 case study: 빠르게 성장하려는 작은 두부(tofu) 소매업체**
- 늘어나는 수요를 따라잡으려면 **판매 프로세스가 잘 설계되고 매끄럽게 돌아가야 한다**
- 목표: **각 리드(lead)를 하나씩 처리하면서 전체 판매 목표를 관리하는 판매 프로세스** 구현
- **이를 BPMN으로 표현하는 방법이 sub-process와 loop다**

**3. 고급 BPMN 요소 — Nilla Care 병원**

- **병원 Nilla Care의 risk management 프로세스를 점검**해 환자와 직원의 안전을 확보한다

**4. 고급 event — Bankovia 은행**

- **구식이고 종이 중심인 은행 Bankovia가 고객용 모바일 앱을 도입**하도록 돕는다
- 강사의 예고: **"이 프로세스는 좀 정신없어 보일 수 있지만 걱정하지 마라. 하나하나 상세히 짚어 나갈 것이다"**

**5. 조직 차원의 BPMN**

- 마지막으로 **BPMN이 조직 전체를 어떻게 더 agile·efficient·compliant하게 만드는지** 다룬다

### 각 챕터의 구성

> **각 챕터마다 과제(assignment)가 포함되어 이해를 깊게 하고 학습 내용을 검증할 수 있다.**

## 요약

- 후반부는 **task type(자동화) → sub-process·loop(확장) → 고급 event(예외 처리) → 조직 차원 적용** 순으로 진행된다
- 네 개의 case study: **Fast Fore(채용)**, **Tofisu(판매)**, **Nilla Care(병원 위험관리)**, **Bankovia(은행 모바일 앱)**
- 후반부의 관통 주제는 **자동화 준비(automation-ready) 프로세스**다
