# Introduction

## 개요

- Module 6 도입부. 고급 기호(advanced symbols)로 넘어간다
- 새로 배울 것: **timer event**, **conditional event**, **event based gateway**(네 번째이자 마지막 gateway), **attached event**

## 내용

### 이 챕터에서 배울 것

1. **두 가지 새 event 유형**
   - **Timer event** — 특정 날짜나 기간
   - **Conditional event** — 특정 조건이 참이 될 때
2. **Event based gateway** — **네 번째이자 마지막 gateway**
3. **Attached event** — **예상치 못한 일이 생겼을 때 activity를 중단시키는** 편리한 개념

### 실전 사례

**우주선 제조사(spaceship manufacturer)** 의 하이테크 현장에서, **내열 패널(heat resistant panels)** 생산 프로세스를 간소화하는 데 이 요소들을 적용한다.

## 요약

- Module 6은 **시간과 조건, 그리고 중단(interruption)** 을 다루는 고급 요소를 배운다
- 이 챕터를 마치면 **BPMN의 gateway 4종이 모두 완성**된다
