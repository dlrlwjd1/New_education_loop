# Practical – Space Ship Manufacturing Process (Part 2)

## 개요

- 성공 경로 너머의 **대안 시나리오(alternate scenarios)** 를 다룬다
- 이 강의에서 **event based gateway**와 **attached event**가 실제로 쓰이는 모습을 본다

## 내용

### 시나리오 1 — 원자재가 없는 경우

1. 자재 확인이 실패하면 토큰이 **아래쪽 경로**로 간다
2. 기획부가 **부족한 부품을 기록(records the missing components)** 한다
3. 토큰이 **event based gateway**로 이동한다
4. gateway가 **두 event 중 하나가 일어날 때까지 프로세스를 일시 정지**시킨다

| 발생한 event | 결과 |
|---|---|
| **부품이 도착함** → catching intermediate message event 촉발 | 해당 경로를 따라 **생산 계속** |
| **3일 내에 부품이 도착하지 않음** → timer event 활성화 | 토큰이 **더 긴 경로**로 가서 **생산팀이 공급업체에서 직접 부품을 조달** |

**어느 쪽이든 토큰은 대체 트랙(alternate track)에 재진입해 평소대로 진행된다.**

> 이것이 event based gateway의 전형적 용도다 — **"기다리던 것이 오는가, 아니면 시간이 먼저 다 되는가"**

### 시나리오 2 — QA가 생산 계획에 문제를 발견한 경우

1. 토큰이 **기획부로 되돌아간다(sent back)** — 조정을 위해
2. 계획이 갱신되면 토큰이 **QA로 돌아가 재평가**를 받는다
3. 동시에 **생산팀은 새 계획을 직원들에게 공지**한다
4. QA가 갱신된 계획에 만족하면 토큰이 전진하고, 생산팀이 기계를 조정해 생산을 시작한다

> **되돌아가는 루프(loop)** 가 프로세스에 자연스럽게 표현된다.

### 시나리오 3 — 샘플에서 결함이 발견된 경우 (attached event)

1. 생산 도중 **부착된 event(attached event)가 샘플의 육안 결함(visual defects)을 감지**하면
2. 토큰이 **대체 경로를 촉발하고 생산이 즉시 중단(stopped immediately)** 된다
3. 토큰이 **exclusive gateway로 되돌아가** 생산팀이 **두 번째 샘플링을 위해 기계를 재조정**한다
4. **두 번째 샘플도 실패**하면 QA가 불승인하고, 생산팀이 **세 번째 시도를 위해 다시 기계를 조정**한다
5. 마침내 샘플이 모든 요구사항을 충족하면 QA가 승인하고 **프로세스가 성공적으로 종료**된다

> attached event가 **진행 중인 생산 activity를 중단**시키는 실제 사례다.

## 예시

```text
시나리오 1 — 원자재 부족

      ◇ 자재가 충분한가? ── no(아래 경로)
                            ↓
                    [부족 부품 기록]
                            ↓
                            ⬡  ← event based gateway
                         ┌──┴──┐
                   (✉ 부품    (⏱ 3일
                    도착)      경과)
                         │       │
                    [생산 계속]  [공급업체에서
                         │        직접 조달]
                         └──┬──┘
                            ↓
                     대체 트랙 재진입


시나리오 3 — 생산 중 결함 감지 (attached event)

      ◇ ←──────────────────────┐  기계 재조정 루프
      ↓                        │
[기계 조정] → ┌──────────────┐  │
              │ [샘플 제작]   │  │
              └──────(◇)─────┘  │
                      ↑          │
              부착 event:        │
              "육안 결함 감지"    │
                      └──────────┘
                      생산 즉시 중단

      정상 완료 시 ↓
      [QA 패널 평가] ── 불승인 → (위 루프로)
              └──── 승인 → (◎ 종료)
```

## 요약

- **Event based gateway**로 **"부품 도착 vs 기한 만료"** 같은 경쟁 상황을 표현한다
- **되돌아가는 루프**로 재작업(rework)과 반복 개선을 자연스럽게 그린다
- **Attached event**가 진행 중인 생산을 즉시 중단시키고 대체 경로로 보낸다
- BPMN은 **자재 부족, 생산 결함, 반복 개선** 같은 현실의 도전을 그대로 담아낼 수 있다
- **성공 경로보다 예외 경로를 그리는 것이 실전 모델링의 본체**다
