# Summary

## 개요

- Module 6 정리
- **강사의 중요한 평가**: 여기까지의 요소로 **실무에서 마주칠 프로세스 모델의 약 90%를 만들 수 있다**

## 내용

### 강사의 진단

> **지금까지 배운 요소들로 여러분은 실무에서 마주칠 프로세스 모델의 약 90%를 만들 수 있다고 본다.**

즉 Module 6까지가 **실용적 BPMN의 핵심**이고, 이후 모듈들은 나머지 10%의 고급 상황을 다룬다.

### 이 챕터에서 추가한 요소

| 요소 | 핵심 |
|---|---|
| **Timer event** | 특정 **기간이나 날짜**를 나타낸다 |
| **Conditional event** | **참 또는 거짓**인 조건을 나타낸다 |
| **Event based gateway** | 다른 gateway와 달리 **발생하는 event에 반응**한다 |
| **Attached event** | task에 붙어 **진행 중인 activity를 중단**시킨다 |

### 반드시 기억할 것

> **Event based gateway는 exclusive gateway로 닫는다.**

## 요약

- Module 6까지가 실무 BPMN의 **90% 지점**이다
- timer(시간) · conditional(조건) · event based gateway(반응) · attached event(중단) — 네 가지가 이 챕터의 수확이다
- event based gateway의 닫는 짝은 **closing exclusive gateway**다
