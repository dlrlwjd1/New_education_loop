# Theory - Token Concept — 대화정리

## 개요

- 학습일: 2026-09-08
- 원본: [02 Theory - Token Concept](02%20Theory%20-%20Token%20Concept.md)
- 사용자 정리: “토큰은 구슬로서 현재 업무가 어디에 있는지를 나타낸다.”

## 내용

### 작업에서의 위치와 이동

토큰(token)은 프로세스를 따라 움직이는 구슬로 생각할 수 있다. 작업(task)에 도착하면 그 작업이 완료될 때까지 머무르고, 완료되면 다음 요소로 이동한다.

### 배타적 게이트웨이에서의 이동

배타적 게이트웨이(exclusive gateway)에서는 선택된 경로 하나만 따라간다. ‘재고가 있는가?’에서 ‘있다’가 선택되면 ‘없다’ 경로에는 토큰이 가지 않는다.

### 실제 쓰임에 대한 질문

사용자는 “이거를 실제로 쓰는 데가 있어?”라고 질문했다. 대화에서는 흐름도 위에서 토큰을 이동시켜 보며 업무의 진행 상태와 분기 규칙을 검토하는 용도로 설명했다.

### 오해 여부와 확인한 지점

사용자가 드러낸 오개념은 없었다. 작업 완료 전에 토큰을 옮기는 가정을 통해, 실제 업무와 그림 사이의 불일치를 확인했다. 실제로는 창고 확인 중이어도 토큰이 다음 작업에 있으면 그림을 보는 사람은 창고 확인이 끝났다고 판단한다.

## 예시

대화에서 사용한 흐름:

```text
시작 → 창고 확인 → 신발 가져오기 → 종료
```

- 창고를 확인하는 동안 토큰은 ‘창고 확인’에 머문다.
- 창고 확인이 완료되면 ‘신발 가져오기’로 이동한다.
- 확인이 끝나기 전에 옮기면 실제 진행 상태를 잘못 표현한다.

## 요약

- 토큰의 위치는 업무가 어느 단계까지 진행됐는지 나타낸다.
- 작업 완료 전에는 다음 단계로 이동하지 않는다.
- 배타적 게이트웨이에서는 선택된 한 경로만 따라간다.
