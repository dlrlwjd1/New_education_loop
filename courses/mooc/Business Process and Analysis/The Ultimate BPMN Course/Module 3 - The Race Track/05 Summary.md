# Summary

## 개요

- Module 3 정리. 여기까지 확보한 BPMN 요소 전체를 점검한다

## 내용

### 이 챕터에서 새로 배운 것

- **Token concept** — 아주 복잡한 비즈니스 프로세스도 이해할 수 있게 해 주는 사고 도구
- **Parallel gateway** — 모든 branch를 동시에 활성화하고, 닫을 때 모두 기다려 병합한다

### 지금까지 확보한 요소 전체

| 요소 | 역할 |
|---|---|
| **Start / End event** | 프로세스를 촉발하고 종료한다 |
| **Activity** | 수행할 행동을 정의한다 |
| **Pool과 Lane** | 책임 소재를 결정한다 |
| **Exclusive gateway** | 하나의 경로만 선택하는 결정 지점 |
| **Parallel gateway** | 모든 경로를 동시에 활성화하고 동기화한다 |
| **Token concept** | 위 요소들 사이를 흐름이 어떻게 지나가는지 추적하는 방법 |

두 가지 gateway를 갖췄으므로 프로세스에 논리를 더할 수 있게 되었다.

## 요약

- 이 시점에서 **논리적이고 효율적인 프로세스를 만들 기본 도구는 모두 갖춰졌다**
- gateway 두 종류(exclusive · parallel)와 token concept이 그 핵심이다
