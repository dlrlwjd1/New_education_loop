# Theory – Token Concept

## 개요

- BPMN 프로세스의 흐름을 이해하는 핵심 사고 도구인 **token(토큰)** 개념
- 비유: **토큰은 프로세스 전체를 굴러가는 공(ball) 또는 구슬(marble)이다**

## 내용

### 토큰이란

토큰을 **start event에서 end event까지 프로세스 전체를 굴러가는 공**이라고 상상한다. 굴러가는 도중에 여러 task와 gateway를 만나고, 그것들이 토큰의 여정에 영향을 준다.

### 동작 규칙

**규칙 1 — Task에 도착하면 머문다**

토큰이 task에 도착하면 **그 task가 완료될 때까지 거기 머문다.** 완료되면 다음 task나 요소로 굴러간다.

**예시 — task 두 개가 연속인 경우**

1. 토큰이 첫 번째 task에 도착 → 완료될 때까지 대기
2. 완료되면 두 번째 task로 이동 → 완료될 때까지 대기
3. 완료되면 계속 굴러간다

**규칙 2 — Gateway에서 경로가 갈린다**

토큰 개념은 **gateway를 다룰 때 특히 유용해진다.**

**Exclusive gateway의 경우** — 토큰은 **선택된 경로 하나만** 따라간다. 예를 들어 위쪽 경로가 선택되면 토큰은 위쪽으로만 간다.

## 예시

```text
Task 두 개가 연속인 경우 토큰의 이동

(○ Start)   →   [Task A]   →   [Task B]   →   (◎ End)
   ●
   토큰 생성

             (● 대기)
             Task A 완료될 때까지 머문다

                            (● 대기)
                            Task B 완료될 때까지 머문다

                                            ●
                                            종료


Exclusive gateway의 경우

           ┌─ 위쪽 경로  ● ← 토큰은 선택된 하나만 따라간다
(●) → ◇ ──┤
           └─ 아래쪽 경로  (비어 있음)
```

## 요약

- **토큰은 프로세스를 굴러가는 공**이다. start event에서 생겨 end event까지 간다
- **task에 도착하면 완료될 때까지 머물고**, 완료되면 다음으로 굴러간다
- **exclusive gateway에서는 선택된 하나의 경로만** 따라간다
- 이 개념이 있어야 다음 강의의 parallel gateway를 정확히 이해할 수 있다
