# Intro Race

## 개요

- Module 3 도입부. 이 챕터에서 다룰 두 가지 새 개념을 예고한다
- **Parallel gateway** — 동시에 실행되는 workflow를 표현하는 새로운 gateway
- **Token concept** — 프로세스가 어떻게 흘러가는지 시각화하는 방법

## 내용

### 이 챕터에서 배울 것

1. **병렬 실행 gateway** — 때로는 여러 task가 **동시에 일어나야 한다**. 이를 모델링하는 새 gateway 유형을 배운다
2. **Token concept** — 프로세스가 어떻게 상호작용하는지 시각화하는 영리한 방법. 강사는 이것을 **아무리 복잡한 프로세스라도 이해할 수 있게 해 주는 진짜 게임 체인저**라고 표현한다
3. **실전 사례** — 경주 트랙(racetrack). 고압 상황의 **pit stop에서 정비팀이 어떻게 협업하는지** 모델링한다

## 요약

- Module 3의 두 축은 **parallel gateway**와 **token concept**이다
- token concept은 복잡한 프로세스를 이해하는 핵심 도구다
- 실전 사례는 F1 pit stop이다
