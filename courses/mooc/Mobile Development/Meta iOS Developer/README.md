# Meta iOS Developer Professional Certificate

Meta의 iOS 개발 전문과정 12개 강좌 전체를 정리한다. iOS·Swift 기초부터 SwiftUI, 데이터 처리, UX/UI, React Basics·React Native, Little Lemon 음식 주문 앱 캡스톤과 코딩 면접 준비까지 포함한다.

- 전문과정 링크: <https://www.mooc.org/professional-certificates/meta-ios-developer>
- 수집 범위: 12개 강좌 전체 (2026-09-06 완료)
- 노트 기준: 저장소에 수집된 강의 노트와 각 강좌 README

## 강좌 목록

1. **Introduction to iOS Mobile Application Development**
2. **Version Control**
3. **Programming Fundamentals in Swift**
4. [Principles of UX UI Design](04%20Principles%20of%20UX%20UI%20Design/README.md)
5. **Create the User Interface with SwiftUI**
6. **Advanced Programming in Swift**
7. **Working with Data in iOS**
8. **Mobile Development and JavaScript**
9. **React Basics** — Meta Front-End Developer와 동일 강좌, 기존 정리본 재사용
10. **React Native** — `Mobile Development/React Native`와 동일 강좌, 기존 정리본 재사용
11. **iOS App Capstone**
12. [Coding Interview Preparation](12%20Coding%20Interview%20Preparation/README.md)

> 9·10번은 Meta Android Developer·Meta Front-End Developer 전문과정과 **같은 MOOC 강좌**를 공유한다. 중복 노트를 만들지 않고 포인터 README로 기존 정리본을 가리킨다. 어느 전문과정에서 보든 같은 노트를 쓴다.

## Meta Android Developer와의 관계

같은 전문과정 계열의 **Meta Android Developer**도 12개 강좌 구조가 동일하며, 1·3·5·6·7·11번만 플랫폼별로 다르다.
