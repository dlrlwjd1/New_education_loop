## 핵심 주제

- 채용 3단계(지원·인터뷰·캘리브레이션)와 인터뷰 3유형(기술·아키텍처·행동)
- 커뮤니케이션: 80/20 규칙, STAR 기법, 사고 과정 소리 내어 설명하기
- CS 기초: 이진법·위치 표기법, 메모리 계층(캐시·RAM/ROM·보조), Big-O 시간/공간 복잡도
- 자료구조: 리스트·셋·스택·큐·트리·해시 테이블·힙·그래프
- 알고리즘: 선택/삽입/퀵 정렬, 선형/이진 탐색, 분할 정복·재귀·동적 프로그래밍·탐욕
