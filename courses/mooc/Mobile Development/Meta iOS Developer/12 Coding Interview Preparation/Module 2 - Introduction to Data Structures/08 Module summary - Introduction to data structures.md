# Module summary: Introduction to data structures

## 개요

- Module 2(자료구조 입문)에서 배운 내용을 되짚는 요약 강의

## 내용

### 기본 자료구조

- 불변(생성 후 불변) vs 가변(내용 연산 가능)
- 분류: **선형**(배열·큐·스택·리스트 — 각 원소가 앞 원소에 연결) vs **비선형**(트리·그래프 — 특정 경로를 탐사)

### 리스트와 셋

- 리스트: 문자열·정수·실수 선언이 일반적, 언어에 따라 혼합 타입·동적 확장 지원
- 연결 리스트: 데이터 + 다음 항목 포인터
- 셋: 무순서·유일 원소, 해시 함수 덕분에 탐색이 매우 빠름

### 스택과 큐

- 추상 구조 — 언어별 구현은 다양하지만 추가·제거 원칙 공통
- 순차 접근, push·pop·isEmpty 등 메서드
- 스택 = **FILO**, 큐 = **FIFO**

### 트리

- 값 추가·탐색에 유연한 구조 — 데이터 간 관계를 구조로 표현해 시간·코드 절약

### 고급 자료구조

- **해시 테이블** — 키에 해싱 함수를 적용해 고정 크기 값으로 축소(압축·전송·해제 비유), 인덱스로 저장·탐색, 충돌 개념
- **힙** — 원소를 중요도 순으로 조직: min-heap(최소 키 우선)/max-heap(최대 키 우선), insert·find·delete 핵심 연산, 임의 삭제 제한으로 성능 유지
- **그래프** — 가중/무방향/방향 그래프, 약결합(한 방향)·강결합(양방향), 도시 연결 예제

## 요약

- 선형(배열·리스트·스택·큐)과 비선형(트리·그래프), 고급 구조(해시 테이블·힙)의 원리와 장단점을 정리했다.
- 자료구조 선택의 핵심은 "적재적소" — 문제의 연산 요구를 먼저 생각하라. 다음 모듈은 알고리즘이다.
