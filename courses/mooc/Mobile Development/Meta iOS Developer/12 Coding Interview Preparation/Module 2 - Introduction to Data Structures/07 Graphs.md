# Graphs

## 개요

- 그래프(graph)의 구성(노드·간선), 가중/방향 그래프, 트리와의 차이, 순회 방법, 대표 문제(최단 경로·외판원)

## 내용

### 그래프란

- **노드(node)** = 대상(예: 도시), **간선(edge)** = 노드 간 관계
- 모든 상세를 저장할 필요 없이 관계로 추론 — 예: 시카고-보스턴 거리를 직접 저장하지 않아도 조직 방식에서 도출
- 활용: 인터넷 목적지, 단어 간 관계, 소셜 네트워크의 인물 관계

### 종류와 용어

- **가중 그래프(weighted)** — 간선에 값(비용)이 있음
- **무방향(undirected)** — 화살표 없음, 우선순위 없음 (양방향 도로) / **방향(directed)** — 진행 방향 존재 (일방통행)
- **경로(path)** — 간선으로 연결된 2개 이상의 노드 시퀀스
- 방향 그래프에서 간선이 한쪽뿐이면 **약결합(weakly connected)**, 양쪽으로 있으면 **강결합(strongly connected)**
- **이웃(neighbor)** — 인접한 두 노드, 이웃을 통해 연결되면 **인접(adjacent)**
- 트리와의 차이: 트리는 시작점이 있고 부모-자식 계층을 모델링하는 **단순한 그래프** — 그래프는 시작도 끝도 없는 더 복잡한 구조

### 순회

- **너비 우선(breadth-first)** — 시작 위치의 이웃들을 모두 순회, 이웃의 연결 노드를 **큐**에 넣어 체계적으로 방문 (FIFO)
- **깊이 우선(depth-first)** — 이웃 노드를 **스택**에 쌓아 가지 끝까지 파고든 뒤 다음 가지로 (LIFO)

### 대표 문제

- **최단 경로(shortest path)** — A→E의 가장 빠른 길, 간선 가중치가 각 경로의 비용 — 인터넷 패킷 라우팅, Google Maps 경로 계산에 사용
- **외판원 문제(traveling salesman)** — 방문할 노드들을 최단 시간에 모두 도는 경로 — 배송 라우팅(x개 목적지, y대 차량의 최소 자원 경로)

### 유연성

- 최소 정보만 유지하면서 데이터 구성 방식으로 정보를 추론
- 데이터 구조를 바꾸지 않고 다른 질문 가능 — 운전 시간 대신 도보 시간 계산으로 쉽게 대체

## 요약

- 그래프는 노드와 간선(가중/방향 여부)으로 관계를 모델링하며, 트리보다 일반적인 구조다.
- 너비 우선은 큐, 깊이 우선은 스택으로 순회한다.
- 최단 경로·외판원 같은 라우팅 문제의 기반이며, 최소 정보로 다양한 질의를 지원한다.
