# Trees

## 개요

- 트리(tree) 자료구조의 구조와 용어, 이진 트리의 삽입 규칙, 깊이/너비 우선 순회, 활용 예

## 내용

### 구조와 용어

- 노드(node)들이 서로 연결된 나무 모양 구조 — 노드에 데이터, **간선(edge)** 이 노드 간 관계를 모델링
- **루트(root)** — 최상위 노드 / **자식(child)** — 아래로 연결된 노드 / **부모(parent)** — 자식을 가진 노드
- **형제(sibling)** — 같은 부모를 가진 같은 레벨의 노드
- **리프(leaf)** — 자식이 없는 노드
- **경로(path)** — 연결된 노드의 연속; 최단 경로가 짧을수록 공통점이 많다고 직관할 수 있음
- **깊이(depth)** — 해당 노드에서 루트까지의 간선 수
- **높이(height)** — 최상위 노드에서 가장 깊은 노드까지의 간선 수
- **크기(size)** — 전체 노드 수
- 변형: 이진 트리(binary tree), B-트리, B+트리, 쿼드 트리, AVL 트리 등

### 이진 트리 삽입 예

- 규칙: 왼쪽 = 더 작은 값, 오른쪽 = 더 큰 값
- 23 삽입 → 4는 23보다 작아 왼쪽 → 1은 4보다도 작아 그 왼쪽 → 30은 23보다 커 오른쪽 → 24는 30보다 작아 그 왼쪽 → 56은 30보다 커 오른쪽

### 순회 방법

- **깊이 우선(depth-first)** — 위에서 아래로 각 노드를 순차 방문
- **너비 우선(breadth-first)** — 같은 레벨의 노드를 모두 확인한 뒤 다음 레벨로

### 장점과 활용

- 노드 간 연결이 데이터에 내재한 관계를 표현 — **계층적 저장**: 상위 노드에 개요, 가지를 따라가면 상세 정보
- 유연한 구현 덕분에 삽입·삭제가 효율적
- 비선형이라 다양한 순회 방식 가능
- 활용: 파일 시스템, Java 클래스 계층, 조직도 모델링

## 요약

- 트리는 루트-부모-자식-리프로 이어지는 계층 구조로, 관계·계층 데이터를 자연스럽게 담는다.
- 이진 트리는 작으면 왼쪽·크면 오른쪽 규칙으로 빠른 탐색·삽입을 지원한다.
- 순회는 깊이 우선과 너비 우선 두 방식이 기본이다.
