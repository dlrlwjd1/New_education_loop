# Introduction to the course

## 개요

- 코딩 인터뷰 준비 코스 소개 — 4개 모듈에서 다룰 인터뷰 준비, 컴퓨터 과학 기초, 자료구조, 알고리즘 미리보기

## 내용

### Module 1 — 코딩 인터뷰 입문

- 코딩 인터뷰의 정의·구성·유형, 준비 방법
- 커뮤니케이션: 사고 과정 설명, 실수 대처, **STAR 기법**
- 의사코드(pseudocode)로 해법 도출 과정 시연, 실전 설계 팁, 솔루션 테스트
- 컴퓨터 과학 기초: 이진법(binary)과 하드웨어, 메모리(RAM·ROM)와 컴퓨터의 정보 처리·저장
- **시간 복잡도**와 Big-O 표기법, **공간 복잡도**(결과 계산에 필요한 공간)

### Module 2 — 자료구조 입문

- 각 자료구조의 장점과 한계 — 솔루션 설계의 핵심
- 기본: 문자열, 정수, 불리언, 배열, 객체 (언어 간 구현·능력 비교)
- 컬렉션: 리스트, 셋, 스택, 큐, 트리
- 고급: 해시 테이블, 힙, 그래프

### Module 3 — 알고리즘 입문

- 정렬 알고리즘: 선택 정렬, 삽입 정렬, 퀵소트 — 각 접근의 트레이드오프와 적합 환경
- 탐색 알고리즘과 정렬·탐색의 시간·공간 복잡도
- 분할 정복(divide and conquer), 재귀(recursion), 동적 프로그래밍(dynamic programming), 탐욕 알고리즘(greedy)

### Module 4 — 최종 프로젝트

- 전체 복습과 종합 퀴즈

## 요약

- 인터뷰 프로세스·커뮤니케이션, CS 기초(이진법·메모리·복잡도), 자료구조(기본·컬렉션·고급), 알고리즘(정렬·탐색·설계 기법)을 거쳐 종합 평가로 마무리하는 과정이다.
