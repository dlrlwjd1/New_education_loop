# Module summary: Introduction to the coding interview

## 개요

- Module 1(코딩 인터뷰 입문)에서 배운 내용을 되짚는 요약 강의

## 내용

### 코딩 인터뷰

- 기술 인터뷰는 역할 수행의 기술적 능력 판별 — 적절한 도구 사용, 시간 제약 인식
- 코드 최적화: 최소 메모리·디스크·CPU·대역폭
- 모르는 문제, 시간 초과여도 추론과 모범 사례를 보여주기 — 온라인 문제 연습과 일관된 방법론으로 편안한 프레임 구축

### 커뮤니케이션

- 첫인상, 언어적·비언어적 소통 모두 중요
- **STAR 기법** — 상황(Situation)·과제(Task)·행동(Action)·결과(Result)로 기술 질문에 답하기

### 컴퓨터 과학 기초

- **이진법** — base 10 vs base 2, 위치 표기법, 바이트(8비트), 지수로 상태 수 계산(자물쇠 예제)
- **메모리** — 메모리 용량(바이트 수), 캐시·메인·보조 메모리, 전송률, RAM vs ROM
- **시간 복잡도** — Big-O 표기법으로 입력별 실행 시간 추정
- **공간 복잡도** — 보조 공간(해법 계산용 임시 공간) + 입력 공간 = 공간 복잡도

## 요약

- 인터뷰 접근법(도구·최적화·추론 시연), STAR 커뮤니케이션, CS 기초(이진법·메모리·시간/공간 복잡도)를 갖췄다. 다음 모듈은 자료구조다.
