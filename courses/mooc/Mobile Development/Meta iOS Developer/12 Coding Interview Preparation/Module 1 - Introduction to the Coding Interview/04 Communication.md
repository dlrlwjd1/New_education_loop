# Communication

## 개요

- 인터뷰에서의 언어적·비언어적 커뮤니케이션과 STAR 답변 기법

## 내용

### 비언어적 커뮤니케이션

- **첫인상**의 힘을 과소평가하지 말 것 — 모든 상호작용이 조직에 가져올 역량을 반영
- **시간 엄수** — 최소 10분 일찍 도착 (건물 이동 시간 감안, 여유 있는 모습)
- 시선 접촉(eye contact) 유지, 질문을 능동적으로 경청
- 단정한 전문 복장 — 존중의 표시
- 좋은 자세 유지 — 꼼지락거림, 얼굴 만지기, 손 비틀기는 자신 없음으로 비칠 수 있음
- 긴장 완화의 지름길은 사전 조사: 직무 내용, 회사가 하는 일과 지향점 파악

### 언어적 커뮤니케이션

- 면접관은 **80/20 규칙**을 지향 — 면접관이 20%, 지원자가 80% 발화
- 질문이 완전히 끝난 후 답하기
- 명확하고 간결한 언어 — 아는 것을 전부 쏟아내는 장광설 대신 주제에 머무르며 후속 질문 여지 남기기
- 능력 과장 금지, 자기 비하 금지 — "그 과제에 실패했다" 대신 "도전적이었지만 향후 탐구할 아이디어를 얻었다"
- 과도한 은어·욕설·부적절한 유머 자제

### STAR 기법

- 인터뷰가 진행되며 질문은 비즈니스 요구(사용 기술, 극복한 문제)에 집중 — 업무 중 발생하는 문제에 어떻게 대응할지를 본다
- 답변에 4요소 포함:
  1. **Situation(상황)** — 맥락은? 어떤 프로젝트, 어떤 도전이었나
  2. **Task(과제)** — 나의 책임과 할 일은 무엇이었나
  3. **Action(행동)** — 문제 해결을 위해 어떤 행동을 했나
  4. **Result(결과)** — 행동의 결과·성과는? 접근이 결과에 어떤 영향을 줬나
- 답에 깊이를 주는 틀이자, 편하게 논의할 수 있는 영역으로 후속 질문을 유도하는 장치

## 요약

- 인터뷰 성공은 커뮤니케이션에 달렸다 — 시간 엄수·복장·자세(비언어)와 간결하고 긍정적인 화법(언어) 모두 중요하다.
- 기술 질문에는 STAR(상황-과제-행동-결과) 프레임으로 답하라.
