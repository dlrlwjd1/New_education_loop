# Introduction to the technical recruitment process

## 개요

- Meta 엔지니어 4인(Julie, Moxxy, Chanel, Mari)이 말하는 기술 채용 프로세스의 3단계와 합격을 위한 조언

## 내용

### 채용 프로세스 3단계

1. **지원(application)** — 리크루터가 이력서·경력 스크리닝 후 미팅으로 역량·경험·희망 사항 파악, 역할 적합성 확인
2. **인터뷰(interviewing)** — 1~5회 이상 가능:
   - **기술 인터뷰** — 코더패드(CoderPad) 등으로 전화·음성 채팅하며 기술 과제 해결
   - **행동 인터뷰(behavioral)** — 함께 일하는 방식, 문제 해결 방식
   - **아키텍처 인터뷰** — 엔드투엔드 제품을 설계하고 전체 아키텍처 논의
   - iOS·Android·ML/AI 등 특정 파이프라인 지원 시 해당 도메인 질문 추가
3. **캘리브레이션(calibration)** — 관계자들이 모여 전 단계 성과를 논의하고 오퍼 여부 결정. 수락 시 부트캠프에서 적응 후 팀을 직접 선택

### 탈락 원인과 대비

- **지원 단계** — 많은 후보가 걸러짐: 실제 경험 중심으로 이력서 작성, 직무 경험이 없으면 사이드 프로젝트로 구체적 경험과 의지 증명
- **코딩 인터뷰 단계** — 최대 탈락 지점:
  - 사고 과정을 설명하지 않음, 명확화 질문을 하지 않음, 면접관의 힌트를 듣지 않음 → **커뮤니케이션** 부족
  - 처음 보는 문제에 대한 구조화된 해결 프로세스 없이 "카우보이 코딩" 시작
  - 막혔을 때 피드백을 받아들이지 못함
- 면접관이 보는 것은 문제 풀이 자체가 아니라 **전체적 접근과 면접관과의 협업**

### 엔지니어들의 조언

- 자신을 있는 그대로 보여줘라 — 덜 스트레스 받고 결과와 무관하게 나아진다
- 보상·명성 외에 자신의 가치와 공명하는 회사를 선택하라
- 최대한 많이 연습하라: LeetCode 문제·모의 인터뷰를 실전처럼 끝까지, 그리고 많은 곳에 지원해 실전 경험을 쌓아라
- 기술 업계는 다양한 배경·관점·경험을 원한다 — 그것이 제품을 더 좋게 만든다

## 요약

- 채용은 지원 → 인터뷰(기술·행동·아키텍처) → 캘리브레이션의 3단계다.
- 코딩 인터뷰의 최대 탈락 요인은 실력보다 커뮤니케이션과 구조화된 문제 해결 프로세스의 부재다.
- 실전 같은 반복 연습과 다수 지원이 최고의 대비책이다.
