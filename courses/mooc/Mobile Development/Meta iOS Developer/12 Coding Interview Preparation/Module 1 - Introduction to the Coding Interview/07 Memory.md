# Memory

## 개요

- CPU를 중심으로 한 컴퓨터 메모리 계층 구조: 캐시 메모리, 메인 메모리(RAM·ROM), 보조 메모리

## 내용

### CPU와 메모리

- 컴퓨터는 정보와 처리 명령을 담은 메모리 블록들로 구성. **메모리 용량** = 컴퓨터가 담을 수 있는 바이트 수
- **CPU**(central processing unit)는 정보를 전송받는 속도보다 빠르게 일한다 — 여러 작업을 거의 동시에 전환하며 처리
- CPU와 메모리 셀의 **근접성**이 로드 시간을 좌우 — 빠르고 비싼 메모리일수록 CPU 가까이 배치
- **전송률(transfer rate)** — 처리를 위해 메모리를 캐시로 옮기는 속도

### 캐시 메모리 (cache memory)

- 가장 비싼 메모리, CPU 칩에 인접
- CPU는 명령을 받으면 먼저 캐시 확인 → 있으면 처리, 없으면 더 크고 느린 메인 메모리에서 캐시로 로드
- 최근 접근한 정보를 캐시에 저장해 자주 쓰는 데이터의 탐색·전송 시간 절감
- 중요도 존(zone)으로 조직 — 가장 자주 필요한 정보가 zone 1, 이후 zone 2·3·4…

### 메인 메모리 (main memory)

- 현재 작업 중인 정보만 보유. 휘발성(전원 차단 시 소실) / 비휘발성(유지)으로 구분
- **ROM**(Read Only Memory) — 덮어쓸 수 없음, 공장에서 1회 프로그래밍. 컴퓨터 기능에 필수적인 명령·데이터 보관, 부팅 시 가장 바쁨
- **RAM**(Random Access Memory) — 프로그래밍 가능, 현재 사용 중인 데이터·명령 보유
  - RAM 용량 ∝ 속도 (전송률 때문) — 크면 정보를 계속 옮길 필요 없이 여러 앱을 동시에 보유·실행
  - 프로그램을 너무 많이 열면 RAM 고갈로 성능 저하

### 보조 메모리 (secondary memory)

- 외부에 연결해 저장 용량을 늘리는 메모리 — 접근이 느리고 필요한 정보·명령을 RAM으로 옮겨야 함
- 예: 클라우드 스토리지, 외장 하드, USB 메모리

## 요약

- 메모리는 CPU 중심으로 계층화된다: 캐시(가장 빠름·비쌈·인접) → 메인(RAM·ROM, 현재 작업) → 보조(느림·대용량·외부).
- RAM 용량이 전송률 부담을 줄여 시스템 속도를 좌우한다.
