# Binary

## 개요

- 이진법(binary)의 원리 — 위치 표기법(positional notation), 컴퓨터의 전기 신호 표현, 지수(exponentiation)로 상태 수 계산

## 내용

### 십진법과 위치 표기법

- 인간은 손가락 10개에서 유래한 **10진법(base ten)** 사용 — 0~9를 소진하면 왼쪽 자리를 올리고 오른쪽을 리셋
- 숫자의 **위치**로 점진적 값 증가를 표현하는 것이 위치 표기법 — 유한한 숫자로 무한한 값을 기록하는 초기 알고리즘

### 이진법

- 같은 위치 표기법을 **base two**로 적용 — 모든 값을 0과 1로 표현
- 컴퓨터는 정보를 **바이트(byte)** 로 저장, 1바이트 = **8비트(bit)**, 각 비트는 0 또는 1
- 카운트 진행: 0 → 1 → (자리 올림) 10 → 11 → 100 → … 모든 1이 차면 리셋하고 왼쪽에 1 추가

### 컴퓨팅에서의 활용

- 전기를 코드로 번역하는 편리한 방법 — 신호 있음 = 1, 없음 = 0
- **불리언(Boolean)** 저장도 동일: 1 = true, 0 = false
- **ASCII**(American Standard Code for Information Interchange) — 이진수 ↔ 문자 매핑: 숫자·문자·특수문자(물음표, 괄호, 마침표, 스페이스)마다 이진수 예약

### 지수로 상태 수 계산

- 2³ = 2×2×2 = 8
- 이진 자물쇠 예: 자리마다 0/1인 4자리 → 2⁴ = 16가지, 5자리 → 2⁵ = 32가지
- **1바이트(8비트) = 2⁸ = 256가지** 조합

## 요약

- 이진법은 켜짐/꺼짐 두 상태를 위치 표기법으로 확장해 무한한 값을 표현하는 컴퓨터의 언어다.
- n비트는 2ⁿ개의 상태를 표현하며, 1바이트(8비트)는 256가지 조합을 가진다.
