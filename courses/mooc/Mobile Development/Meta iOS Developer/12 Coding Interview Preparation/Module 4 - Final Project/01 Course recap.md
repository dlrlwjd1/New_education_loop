# Course recap

## 개요

- Coding Interview Preparation 코스 전체를 되짚는 총정리 강의

## 내용

### Module 1 — 코딩 인터뷰 입문

- 기술 인터뷰: 역할 수행 능력 판별, 도구 활용·시간 제약 인식
- 준비: 첫인상, 사고 과정 설명, 실수 대처, **STAR 기법**, 의사코드, 설계 팁, 솔루션 테스트
- CS 기초: 이진법(base 10 vs 2, 위치 표기법), 메모리 계층과 전송률, **시간 복잡도(Big-O)**, **공간 복잡도**(속도 vs 압축성의 선택)

### Module 2 — 자료구조

- 기본(문자열·불리언·배열)부터 고급(컬렉션·그래프·힙)까지 — 각자의 이점과 한계
- 분류: 선형 vs 비선형
- 스택·큐(추가·제거 규칙, FIFO), 트리(유연한 추가·탐색)
- 고급: 해시 테이블, 힙(중요도 조직, 기능 제한 = 생산성), 그래프(노드·간선, 가중/무방향/방향, 약결합·강결합)

### Module 3 — 알고리즘

- 정렬: 선택·삽입·퀵소트 — 정렬된 데이터의 시간 절약 효과
- 탐색: 선형(전수 확인) vs 이진(공간 절반씩), 시간·공간 복잡도
- 기법: 분할 정복(분할→정복→결합), 재귀(기저 사례·축소 구조·재귀 호출), 동적 프로그래밍(목적 함수→분해→접근 선택), 탐욕(국소 최적, 낮은 오버헤드·비보장)

## 요약

- 인터뷰 전략·CS 기초·자료구조·알고리즘을 모두 갖췄다 — 남은 것은 최종 퀴즈다.
