# Module summary: Introduction to algorithms

## 개요

- Module 3(알고리즘 입문)에서 배운 내용을 되짚는 요약 강의

## 내용

### 정렬과 탐색

- 정렬 3방식: 선택·삽입·퀵소트 — 각 단계와 장단점, **모든 시나리오에 최적인 정렬은 없다**
- 탐색 2방식: 선형(모든 항목을 차례로 확인) vs 이진(반복마다 탐색 공간 절반)
- 정렬·탐색 알고리즘의 시간·공간 복잡도 분석

### 알고리즘 작업 기법

- **분할 정복** — 분할(입력을 작은 세그먼트로) → 정복(세그먼트별 과제 해결) → 결합(선택) — 효과적인 문제 해결 프레임
- **재귀** — 함수가 더 작은 문제로 자신을 반복 호출, 종료 조건에서 멈춤. 3요소: 기저 사례, 축소 구조, 재귀 호출
- **동적 프로그래밍** — 작은 문제로 나눠 풀고 **메모이제이션**(하위 문제 해 저장)으로 재계산 방지. 절차: 목적 함수 결정 → 작은 단계로 분해 → 접근 방식 선택
- **탐욕 알고리즘** — 국소 최적화(현재 가장 보상 큰 선택). 오버헤드가 낮고 구현이 쉬우나 최선을 보장하지 않음

## 요약

- 정렬(선택·삽입·퀵)과 탐색(선형·이진), 그리고 설계 기법(분할 정복·재귀·동적 프로그래밍·탐욕)을 정리했다. 남은 것은 모듈 퀴즈와 최종 평가다.
