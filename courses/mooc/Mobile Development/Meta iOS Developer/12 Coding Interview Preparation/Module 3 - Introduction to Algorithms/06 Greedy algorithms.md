# Greedy algorithms

## 개요

- 탐욕 알고리즘(greedy algorithm) — 국소 최적(local optimization)을 선택하는 단순한 접근과 동적 프로그래밍(전역 최적)과의 비교

## 내용

### 탐욕 접근이란

- 오컴의 면도날(Occam's razor) — "가장 단순한 해법이 대개 최선" — 의 알고리즘 판
- 동적 프로그래밍의 대안: 즉각적인 해를 제시하며 전역(global) 최적화보다 **국소 최적화**를 선호
- 매 순간 **현재 가장 보상이 큰 선택**을 함

### 동적 vs 탐욕 비교

- **동적** — 하위 문제를 모두 풀고 최적 부분집합을 선택 (전역 최적 보장). 배낭 문제라면 가치를 최대화하는 부분집합 계산
- **탐욕** — 다른 항목의 배제는 고려하지 않고 항상 가장 가치 있는 항목부터 담음. CPU 스케줄링이라면 가장 짧은 작업부터 차례로 실행
- 탐욕은 전역 최적이 아닐 수 있지만 최적 부분집합 계산 오버헤드가 없다

### 최단 경로 예시

- 9개 노드(A~H, S)의 가중 그래프에서 E → F 경로 찾기
- **동적 접근** — E에서 각 노드로의 비용 테이블을 만들고 누적 비용 계산 (상향식 전역 접근). 메모이제이션으로 이후 조회는 더 빨라짐. 확실히 최적해 도달
- **탐욕 접근** — E의 연결(가중치 5, 3, 2, 4, 12) 중 최소인 2(노드 D) 선택 → D에서 다시 연결 중 F(5) 선택 → 총 비용 7로 도착
  - 이 예에서는 표 없이 최적 경로에 도달했지만, 만약 G-F 간선이 2였다면 **차선책을 선택**했을 것

### 트레이드오프

- 오버헤드가 낮고 구현이 단순하다
- 최선의 답을 **보장하지 않는다**

## 요약

- 탐욕 알고리즘은 매 단계 국소 최적을 선택해 빠르고 단순하지만 전역 최적을 보장하지 않는다.
- 동적 프로그래밍은 전역 최적을 보장하는 대신 계산·저장 오버헤드가 있다.
- 문제의 구조와 정확도 요구에 따라 두 접근을 선택한다.
