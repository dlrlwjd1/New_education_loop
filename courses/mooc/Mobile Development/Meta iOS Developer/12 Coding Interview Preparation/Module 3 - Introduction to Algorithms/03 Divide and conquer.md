# Divide and conquer

## 개요

- 분할 정복(divide and conquer) 패러다임 — 분할·정복·(결합) 단계, 병합 정렬(merge sort) 예시, 병렬화와 메모리 관리 이점

## 내용

### 단계

1. **분할(divide)** — 필수: 입력을 더 작은 세그먼트로 쪼개 개별 처리
2. **정복(conquer)** — 필수: 각 세그먼트의 과제를 해결
3. **결합(combine)** — 선택: 해결된 세그먼트들을 합침 (병합 정렬처럼 필요할 때만)

### 병합 정렬 예시

- 배열을 절반으로, 다시 절반으로 나누기를 원소가 1개 남을 때까지 반복
- 과정을 역으로 되짚으며 작은 리스트들을 정렬해 상위 절반과 재결합
- "작은 문제로 나누면 전체 과제가 쉬워진다"는 발상

### 실생활 비유 — 공동 장보기

- 룸메이트 4명이 긴 장보기 목록을 처리:
  - 모두 함께 돌기 → 느림
  - 목록을 4등분해 분담 → 시간 단축 (겹침 발생 가능)
  - 목록을 품목별(음료·과일·육류)로 **먼저 정렬**하고 구역을 배정 → 가장 효율적

### 컴퓨터에서의 이점

- **병렬화(parallelization)** — 여러 스레드·컴퓨터가 같은 문제를 동시에 처리해 시간 단축. 분할 정복 해법은 병렬 코딩이 가능해짐
- **메모리 관리** — 각 배열을 다른 코어·서버로 보내 처리 후 결과 수합. 메모리에 담기 어려운 대용량 데이터를 청크로 처리하거나 클라우드 서버로 일부를 내보내는 식으로 가용 메모리를 관리

## 요약

- 분할 정복 = 분할(필수) + 정복(필수) + 결합(선택)의 문제 해결 프레임워크다.
- 병합 정렬이 대표 예이며, 병렬화와 메모리 관리라는 실질적 이점을 준다.
