# Dynamic programming

## 개요

- 동적 프로그래밍(dynamic programming)과 메모이제이션(memoization) — 하위 문제 결과를 저장·재사용해 계산을 최적화

## 내용

### 동적 프로그래밍이란

- 문제를 작은 하위 문제로 나눠 풀고, 그 해를 자료구조에 **저장**하는 패러다임
- 같은 하위 문제가 다시 필요하면 재계산 대신 **조회** — 이 기법이 **메모이제이션**
- 분할 정복(큰 문제 → 하위 문제)과 재귀(자기 호출)의 확장 — 여기에 실행 결과 기록을 더한 것

### 예시 — 지수 계산

- 6자리 이진 자물쇠의 조합 수 = 2⁶ = 64
- 2⁶ = (2×2×2) × (2×2×2) = 8 × 8 로 두 그룹으로 분할 가능
- 메모이제이션 적용: 첫 2³을 계산·저장하고 두 번째 괄호에 **재사용** → 전체 계산량 감소

### 적합한 문제 유형

- **조합(combination)·최적화(optimization)** 문제
- 조합 예: 피보나치 수열
- **배낭 문제(knapsack problem)** — 조합+최적화:
  - 아이템마다 무게(토치 1kg, 물 2kg, 텐트 3kg)와 가치(1, 2, 3)가 있고 배낭 용량이 제한될 때 최적 조합 찾기
  - 자원 할당에 응용 — CPU 용량과 실행할 작업들
  - 용량이 7kg에서 10kg으로 바뀌어도 7kg 최적해의 계산을 재사용 → 시간 절약

### 해법 설계 절차

1. **목적 함수(objective function)** 결정 — 최적 결과가 무엇인지 기술
2. 문제를 작은 단계로 분해 — 재귀 함수 활용 가능
3. 이미 작성한 메서드의 코드를 바꾸지 않고도 결과를 바꿀 수 있게 작성

## 요약

- 동적 프로그래밍 = 분할 정복 + 재귀 + 메모이제이션(결과 저장·재사용)이다.
- 겹치는 하위 문제가 있는 조합·최적화 문제(피보나치, 배낭 문제)에 효과적이다.
- 목적 함수 정의 → 분해 → 재사용 가능한 구조가 설계의 순서다.
