# What Is UI

## 개요
- 사용자 인터페이스(UI)의 역할, 구성과 발전 과정을 살펴본다.

## 내용
### 기술과의 의사소통
UI는 사람이 기술과 작업하고 소통하는 접점이다. 화면의 정보 배치, 아이콘, 색상, 텍스트, 도형뿐 아니라 클릭이나 탭 이후의 반응도 포함한다.

### 작업과 피드백
자동차 대시보드처럼 사용자의 행동에 시스템 상태로 응답해야 한다. 의료 장비와 항공기처럼 중요한 환경에서는 직관적인 인터페이스가 안전에도 직접 영향을 준다.

### 발전 과정
Xerox PARC와 Xerox Star가 데스크톱, 창, 메뉴, 아이콘 같은 친숙한 은유를 도입했고, 스마트폰과 태블릿의 멀티터치가 제스처 기반 상호작용을 확산했다.

## 예시
주문 버튼을 누르면 장바구니 수량과 상태가 즉시 변해 사용자의 행동이 성공했음을 명확히 알려 준다.

## 요약
- UI는 시각 요소와 상호작용을 통한 사람-기술 간 의사소통이다.
- 명확한 상태와 피드백이 중요하다.
- 친숙한 은유와 터치 제스처가 현대 UI를 형성했다.
