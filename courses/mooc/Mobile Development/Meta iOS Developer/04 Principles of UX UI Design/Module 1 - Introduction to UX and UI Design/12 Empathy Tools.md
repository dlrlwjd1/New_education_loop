# Empathy Tools

## 개요
- 페르소나, 공감 지도와 시나리오로 사용자 관점에 기반한 설계 기준을 만든다.

## 내용
### 페르소나
페르소나는 여러 인터뷰·관찰 참가자의 공통 특성을 결합한 현실적인 가상 사용자다. 사진, 인구통계, 기술 능력, 소개, 필요와 좌절을 담아 설계자가 가정 대신 연구에 근거하도록 한다.

### 공감 지도
사용자가 말하고, 생각하고, 행동하고, 느끼는 것을 네 영역으로 정리한다. 시간 순서가 아니라 사용자의 성격과 관점을 전체적으로 이해하는 도구다.

### 시나리오
페르소나의 구체적인 목표, 원하는 결과, 필요한 행동과 해결 과정을 정의한다. 이 단계에서는 아직 화면을 설계하지 않고 문제에 공감하는 데 집중한다.

## 예시
Tilly는 60세의 재방문 고객으로 휴대전화에서 좋아하는 비건 파스타를 배달 주문하려 한다. 사이트 접근, 메뉴 선택·맞춤 설정, 정보 입력, 결제와 주문 추적이 필요하다.

## 요약
- 페르소나는 연구 참가자의 특성을 대표하는 가상 사용자다.
- 공감 지도는 사용자의 말·생각·행동·감정을 정리한다.
- 시나리오는 사용자의 목표와 필요한 해결 흐름을 구체화한다.
