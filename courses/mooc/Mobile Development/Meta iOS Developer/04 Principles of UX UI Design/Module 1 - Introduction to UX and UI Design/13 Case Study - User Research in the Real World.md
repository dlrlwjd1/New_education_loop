# Case Study - User Research in the Real World

## 개요
- Meta에서 사용자 조사를 제품 전 과정에 적용하는 방식과 가치를 살펴본다.

## 내용
### 조사 방법과 시점
A/B 테스트, 설문, 사용 관찰과 페르소나로 정량·정성 피드백을 수집한다. 아이디어 단계부터 MVP 제작, 출시 후까지 일찍 자주 조사한다.

### 직군 간 역할
사용자 연구자는 질문과 실험을 수행하고, 디자이너와 제품 관리자는 결과를 제품 변경으로 연결한다. 엔지니어도 예상과 다른 결과를 받아들이고 방향을 수정해야 한다.

### 편향 없는 질문
원하는 답을 유도하지 않는 질문으로 솔직한 반응을 얻어야 한다. 이는 사용자가 이해하지 못하거나 쓰지 않는 제품을 만드는 위험을 줄인다.

## 예시
Meta의 그룹 기능은 MVP 테스트 후 사용자가 이름과 개념을 이해하지 못한다는 결과를 받아 기능 방향과 제품 이름까지 변경했다.

## 요약
- 사용자 조사는 제품 전 생애주기에서 반복한다.
- 결과는 기존 가정을 뒤집고 제품 방향을 바꿀 수 있다.
- 편향 없는 질문과 조기 조사가 큰 재작업을 줄인다.
