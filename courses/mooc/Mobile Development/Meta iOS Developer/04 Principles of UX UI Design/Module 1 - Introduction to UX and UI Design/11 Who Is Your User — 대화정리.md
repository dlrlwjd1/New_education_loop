# Who Is Your User — 대화정리

## 개요
- 인터뷰와 관찰 결과로 사용자를 이해하고 고객 여정 지도를 작성한다.
- 06강("추측하지 말고 관찰하라")의 구체적인 실행 방법을 보여주는 강의.

## 내용

### 사용자 조사
- **인터뷰**는 사용자의 생각과 목표를, **관찰**은 실제 행동과 막히는 지점을 보여준다.
- 조사 없이 설계하면 개인적인 가정에 의존해 실패할 수 있다.

### 발견한 주문 문제 (Little Lemon 실제 사례)
- 메뉴 버튼과 음식 분류가 불명확
- 장바구니 아이콘과 뒤로 가기가 안 보임
- 주문을 수정하거나 재료를 추가할 수 없음
- 입력이 끝난 뒤에야 검증 오류(validation error)가 나타나 사용자가 작업을 포기

### 07강 사용성 요소와 연결 — 대화에서 정리
- "입력이 끝난 뒤에야 검증 오류가 나타남" 문제는 07강의 **Errors(오류)** — "실수를 예방하고 복구 방법을 제공하는가" — 에 해당한다.
- 오류를 미리 막지 못하고 다 끝난 뒤에야 알려주는 건 "예방"에 완전히 실패한 사례다. 미리 알려줬다면 바로 고쳤을 텐데, 다 끝나고서야 알려주니 사용자가 처음부터 다시 해야 한다는 느낌을 받고 포기했다.

### 고객 여정 지도
- 사용자가 과제를 완료하는 단계와 각 단계의 **행동, 생각, 말, 감정**을 시간 순서로 기록한다.
- 시나리오와 기대, 핵심 기회(key opportunities)도 함께 정리해 개선 우선순위를 찾는다.

### 왜 감정까지 기록하는가 — 대화에서 정리
- 행동만 적으면 "어떤 순서로 뭘 했는지"만 알 수 있지만, 감정까지 기록하면 **어느 지점에서 가장 크게 무너졌는지**가 드러난다.
- 예시(`웹사이트 진입 → 메뉴 선택 → 주문 맞춤 설정 실패 → 좌절 → 전화 주문으로 전환`)에서 "좌절"이라는 감정이 기록되었기 때문에, "주문 맞춤 설정 실패" 지점이 가장 시급히 고쳐야 할 곳이라는 게 명확해진다.
- 즉 감정 기록은 07강의 **Satisfaction(만족도)**을 실제로 측정하는 방법이자, "핵심 기회"를 찾아 개선 우선순위를 정하는 도구다.

## 예시
```text
웹사이트 진입 → 메뉴 선택 → 주문 맞춤 설정 실패
→ 좌절 → 전화 주문으로 전환
```

## 요약
- 인터뷰와 관찰은 사용자 목표와 실제 문제를 밝히며, 가정 대신 근거로 설계하게 한다.
- Little Lemon 사례의 "뒤늦은 검증 오류"는 07강의 Errors 요소 실패에 해당한다.
- 여정 지도는 행동뿐 아니라 감정까지 기록해, 가장 시급히 고쳐야 할 지점(핵심 기회)을 찾는 도구다.
