# Introduction to the Principles of UX and UI Design

## 개요
- UX와 UI 과정의 목표, 프로젝트와 학습 방법을 소개한다.

## 내용
### 과정 프로젝트
Little Lemon 웹사이트의 음식 주문과 테이블 예약 문제를 UX·UI 방법론으로 개선한다. 과정 중에는 모바일 주문 흐름의 재설계를 따라가고, 최종 과제에서는 예약 흐름을 직접 설계한다.

### 학습 목표
UX와 UI를 구분하고 Figma를 사용해 인터랙티브 디자인을 평가하며 현대적인 UI를 만든다. 종이 기반 저충실도 설계에서 기능적인 고충실도 디자인과 프로토타입으로 발전시키는 과정도 다룬다.

### 학습 방식
영상과 읽기, 실습, 지식 점검과 토론을 활용한다. 자기 주도 과정이지만 정기적인 학습 일정을 정해 반복해서 연습하는 것이 권장된다.

## 예시
종이에 주문 화면을 그린 뒤 Figma에서 시각 요소와 상호작용을 추가하고, 사용자가 실제로 주문을 완료할 수 있는지 프로토타입으로 검증한다.

## 요약
- Little Lemon 모바일 웹사이트를 사례로 UX·UI 프로세스를 배운다.
- 저충실도 설계부터 고충실도 프로토타입까지 제작한다.
- 반복 학습과 실습으로 디자인 기술을 익힌다.
