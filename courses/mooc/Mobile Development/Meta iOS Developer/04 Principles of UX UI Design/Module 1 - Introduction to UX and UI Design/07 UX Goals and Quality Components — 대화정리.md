# UX Goals and Quality Components — 대화정리

## 개요
- 사용자 목표와 Nielsen의 다섯 가지 사용성 품질 요소를 설계에 적용한다.
- 이 로드맵에서 초벌 디자인을 평가할 합격 기준으로 가장 자주 되돌아올 핵심 강의.

## 내용

### 사용성 품질 요소 (Nielsen 5가지)
사용성은 제품을 얼마나 직관적이고 쉽게 쓸 수 있는지 나타낸다.

- **Learnability (학습성)**: 처음에도 쉽게 배울 수 있는가
- **Efficiency (효율성)**: 작업과 변경을 빠르게 할 수 있는가
- **Memorability (기억성)**: 중단 후에도 사용법과 위치를 기억할 수 있는가
- **Errors (오류)**: 실수를 예방하고 복구 방법을 제공하는가
- **Satisfaction (만족도)**: 사용 과정이 즐겁고 만족스러운가

### Learnability vs Memorability — 대화에서 정리
- 핵심 차이는 **"언제"**다.
  - **Learnability**: **처음** 접했을 때 얼마나 쉽고 빠르게 배우는가 (신규 사용자 기준)
  - **Memorability**: 한동안 안 쓰다가 **돌아왔을 때** 얼마나 빨리 다시 적응하는가 (복귀 사용자 기준)
- 둘은 독립적으로 나빠질 수 있다. 예: 처음엔 쉽게 배웠지만(학습성 ✓), 6개월 만에 돌아오니 어디에 뭐가 있는지 기억이 안 난다(기억성 ✗).

### 경험 목표
제품은 즐겁고 편안하며 효율적이고 직관적이어야 한다. 느리고 혼란스럽거나 복잡해 사용자가 지루함·좌절·스트레스를 느끼게 해서는 안 된다.

### 사용자 목표와 사업 목표의 연결 — 대화에서 정리
- 고객이 목표를 쉽게 달성하도록 명확한 정보와 지원을 제공하면서 Little Lemon의 **주문·예약 증가**라는 사업 목표와 정렬한다.
- 왜 연결되는가: 화면이 혼란스럽거나(Errors), 느리거나(Efficiency), 배우기 어려우면(Learnability) 사용자는 중간에 포기하고 **이탈(drop-off)**한다.
- 반대로 사용자가 목표를 쉽게 달성하도록 만들면 → 이탈 없이 완료 → 완료된 주문·예약 건수 증가로 직결된다.
- 즉 사용자 목표와 사업 목표가 "우연히 같다"기보다, **사용성이 나쁘면 둘 다 같이 무너지는 관계**다.

## 예시
예약 화면에서 이용 가능한 시간과 이용 시간을 명확히 보여 주고, 출입문 가까운 좌석 같은 특별 요청을 쉽게 입력하도록 한다.

## 요약
- 사용성은 학습성·효율성·기억성·오류·만족도 5가지로 평가하며, 이는 앞으로 초벌 디자인의 합격 기준으로 반복 사용된다.
- 학습성=처음 배우기 쉬움, 기억성=복귀 후 적응력으로 서로 다른 시점을 본다.
- 사용성이 나쁘면 사용자는 이탈하므로, 사용자를 돕는 것이 곧 사업 목표(주문·예약 증가) 달성 수단이 된다.
