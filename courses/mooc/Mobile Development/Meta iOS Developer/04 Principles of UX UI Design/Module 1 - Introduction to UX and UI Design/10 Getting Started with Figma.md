# Getting Started with Figma

## 개요
- Figma의 특징과 주요 편집기 영역을 익힌다.

## 내용
### 협업 디자인 도구
Figma는 웹 기반 UX·UI 디자인과 프로토타이핑 도구다. 여러 플랫폼에서 실행되며 디자이너와 개발자가 동시에 편집, 댓글, 검토를 수행할 수 있다.

### 주요 화면
- **Canvas**: 디자인을 만드는 중앙 작업 공간
- **Toolbar**: 프레임, 도형, 이동, 텍스트 등 자주 쓰는 도구
- **Left sidebar**: 페이지, 레이어와 에셋
- **Right sidebar**: Design, Prototype, Inspect 패널과 선택 객체 속성

### 컨텍스트 UI
도구 모음과 오른쪽 패널은 선택한 객체에 따라 표시 항목이 바뀐다. Inspect에서는 CSS 값을 확인할 수 있으며 과정은 Design과 Prototype 패널을 주로 사용한다.

## 예시
새 Design File을 만들고 도형을 선택하면 우측 Design 패널에서 위치, 크기, 채우기, 선과 효과를 조정한다.

## 요약
- Figma는 웹 기반 협업 디자인·프로토타이핑 도구다.
- Canvas, Toolbar, 좌우 Sidebar로 구성된다.
- 선택한 객체에 따라 도구와 속성이 달라진다.
