# Introduction to UX and UI

## 개요
- 사용자 경험(UX)과 사용자 인터페이스(UI)의 차이와 관련 직무를 구분한다.

## 내용
### UX
UX는 웹사이트 화면뿐 아니라 직원, 서비스, 음식, 공간과 디지털 제품 등 사용자가 사업과 접촉하는 전체 경험이다. 사용자의 필요, 목표 달성을 막는 요소, 사용 흐름의 직관성과 효율성을 조사하고 해결한다.

### UI
UI는 사용자가 보고 조작하는 글자, 색상, 버튼, 도형, 아이콘, 이미지 등을 구성한다. 요소를 논리적이고 아름답게 조합해 사용자가 브랜드 경험 속에서 목표를 빠르게 달성하게 한다.

### 역할과 조직 규모
작은 회사에서는 한 사람이 조사, 설계, 구현까지 맡을 수 있다. 큰 회사에서는 UX 연구, UX 카피, 디자인 시스템, 접근성 같은 전문 역할로 세분화된다.

## 예시
UX 디자이너가 음식 주문 문제를 조사해 흐름과 프로토타입을 만들면, UI 디자이너는 디자인 시스템을 활용해 명확하고 일관된 화면과 상호작용을 구성한다.

## 요약
- UX는 사용자의 전체 경험과 문제 해결 과정이다.
- UI는 사용자가 보는 시각 요소와 상호작용을 설계한다.
- 두 분야는 서로 정보를 주고받아 사용하기 좋은 제품을 만든다.
