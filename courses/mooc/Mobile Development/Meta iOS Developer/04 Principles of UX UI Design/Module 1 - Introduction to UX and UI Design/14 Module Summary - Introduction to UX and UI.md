# Module Summary - Introduction to UX and UI

## 개요
- UX·UI와 사용자 중심 설계 입문 모듈의 핵심을 복습한다.

## 내용
### UX와 UI
UX와 UI의 차이, 관련 직무와 경력 경로를 살펴봤다. UX 프로세스의 공감·정의·아이디어·프로토타입·테스트와 사용성 품질 요소를 익혔다.

### UI와 도구
UI의 역할과 역사, 인터랙션·인간 중심·보편적 디자인과 디자인 사고를 소개하고 Figma의 기본 화면을 탐색했다.

### 사용자 중심 설계
인터뷰와 관찰로 문제를 찾고 고객 여정 지도, 페르소나와 공감 도구로 고객을 의사결정의 중심에 두었다.

## 예시
Little Lemon 고객 조사를 바탕으로 페르소나와 여정 지도를 만들고 주문 과정의 핵심 문제를 정의한다.

## 요약
- UX와 UI의 역할을 구분할 수 있다.
- 반복적인 UX 프로세스와 사용성 원칙을 설명할 수 있다.
- 사용자 조사 결과를 설계 판단의 근거로 사용한다.
