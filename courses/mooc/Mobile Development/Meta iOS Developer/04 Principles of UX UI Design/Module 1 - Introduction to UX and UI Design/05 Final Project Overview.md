# Final Project Overview

## 개요
- Little Lemon 모바일 웹사이트의 테이블 예약 흐름을 설계하는 최종 프로젝트를 살펴본다.

## 내용
### 문제와 학습 사례
고객은 음식 배달 주문과 테이블 예약에서 어려움을 겪고 있다. 과정에서는 사용자 중심으로 온라인 주문 요소를 조사·재설계·테스트하는 사례를 따라간다.

### 최종 과제
학습자는 같은 UX·UI 원칙과 모범 사례를 테이블 예약 요소에 적용해 인터랙티브 결과물을 만든다. 고객 사용 데이터에서 출발해 필요한 기능과 흐름을 설계한다.

### 예약 흐름
식사 인원, 날짜와 시간, 특별 요청을 선택하고 이름, 전화번호, 이메일, 결제 정보를 입력한다. 예약을 확정하면 화면과 이메일로 확인을 받는다.

## 예시
```text
인원·날짜·시간 선택
→ 특별 요청 입력
→ 고객 정보 입력
→ 예약 확인
→ 화면·이메일 확인
```

## 요약
- 실제 고객 문제와 데이터를 기반으로 설계한다.
- 최종 결과물은 모바일 테이블 예약 인터랙션이다.
- 완성한 디자인은 취업 포트폴리오로 활용할 수 있다.
