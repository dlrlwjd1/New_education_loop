# What Is UI — 대화정리

## 개요
- 사용자 인터페이스(UI)의 역할, 구성과 발전 과정을 다룬다.
- 06강(What Is UX)의 짝이 되는 강의로, UI 구성 요소를 부르는 어휘의 시작이 된다.

## 내용

### 기술과의 의사소통
- UI는 사람이 기술과 작업하고 소통하는 **접점(interface)**이다.
- 화면의 정보 배치, 아이콘, 색상, 텍스트, 도형뿐 아니라 **클릭이나 탭 이후의 반응**도 포함한다.

### 03강 정의와 비교 — 대화에서 정리
- 03강은 UI를 "보고 조작하는 시각 요소"로 정의했다.
- 09강은 여기에 **사용자와의 인터랙션(interaction)**, 그리고 그 인터랙션에 대한 **반응/피드백**까지 더한다.
- 즉 화면이 예쁜 것만으로는 부족하고, 사용자 행동에 시스템이 명확하게 응답해야 완성된 UI라는 것.

### 작업과 피드백
- 자동차 대시보드처럼, 사용자의 행동에 시스템이 상태로 응답해야 한다.
- 의료 장비와 항공기처럼 중요한 환경에서는 직관적인 인터페이스가 **안전(safety)**에도 직접 영향을 준다.

### 왜 안전과 연결되는가 — 대화에서 정리
- 의료·항공 환경에서는 사용자(의사, 조종사)가 빠르고 정확하게 판단해 즉시 행동해야 하는 경우가 많다.
- 시스템 상태에 대한 피드백이 불명확하거나 늦으면 사용자가 상황을 잘못 읽거나 판단이 늦어질 수 있다.
- 일반 앱에서는 이런 문제가 "불편함"에 그치지만, 의료·항공 환경에서는 생명과 직결되는 사고로 이어질 수 있다.
- 즉 "명확한 피드백" 원칙은 같지만, 맥락에 따라 사용성(usability) 문제가 안전(safety) 문제로 격상된다.

### 발전 과정
- Xerox PARC와 Xerox Star가 데스크톱, 창, 메뉴, 아이콘 같은 친숙한 은유를 도입했다.
- 스마트폰과 태블릿의 멀티터치가 제스처 기반 상호작용을 확산시켰다.

## 예시
주문 버튼을 누르면 장바구니 수량과 상태가 즉시 변해 사용자의 행동이 성공했음을 명확히 알려 준다.

## 요약
- UI는 시각 요소뿐 아니라 인터랙션과 그에 대한 피드백까지 포함하는 사람-기술 간 의사소통이다.
- 명확한 피드백이 늦거나 불분명하면 일반 앱에서는 불편함이지만, 의료·항공처럼 중요한 환경에서는 안전 문제가 된다.
- 친숙한 은유(데스크톱·창·메뉴·아이콘)와 터치 제스처가 현대 UI를 형성했다.
