# Introduction to the Principles of UX and UI Design — 대화정리

## 개요
- 이 강의는 UX/UI 코스 전체의 오리엔테이션이다.
- 실습 대상: `Little Lemon`이라는 가상 웹사이트(음식 주문 + 테이블 예약).
- 저충실도(low-fidelity) 설계에서 기능적인 고충실도(high-fidelity) 디자인과 프로토타입(prototype)으로 발전시키는 흐름을 예고한다.

## 내용

### 과정 프로젝트와 역할 분담
- **강의 중 (같이 따라가는 실습)**: `Little Lemon`의 **모바일 주문(ordering) 흐름**을 재설계하는 과정을 따라간다.
- **최종 과제 (직접 하는 것)**: **예약(reservation) 흐름**을 직접 설계한다.
- 즉 "주문 화면은 배운 걸 따라 하기, 예약 화면은 스스로 적용해보기"로 나뉜다.

### 저충실도 vs 고충실도
- **저충실도(low-fidelity)**: 종이에 빠르게 끄적인 러프 스케치. 색상·폰트·정확한 배치는 신경 쓰지 않고, 구조와 아이디어의 방향만 빠르게 확인하는 게 목적이다.
- **고충실도(high-fidelity)**: 실제 색상·타이포·간격까지 다듬어 진짜 제품처럼 보이는 디자인. 강의에서 "기능적인(functional)"이라는 표현을 쓴 게 핵심 — 예쁘기만 한 게 아니라 버튼을 누르면 반응하는 식으로 **작동**한다는 뜻이며, 이게 다음 단계인 **프로토타입**으로 이어진다.
- 정리 흐름: **종이 스케치(저충실도) → 실제로 작동하는 정교한 디자인(고충실도) → 클릭 가능한 프로토타입**

> 대화 중 "AI로 저충실도를 보여주면 고충실도가 나오지 않을까"라는 질문이 있었다. 흥미로운 워크플로 아이디어지만, 이 강의에서 말하는 저충실도/고충실도는 AI 변환 도구 이야기가 아니라 **디자이너가 직접 밟는 작업 단계**를 가리킨다. (AI를 활용한 저충실도→고충실도 변환 자체는 실존하는 워크플로이지만 이 강의 내용은 아니다.)

### 학습 방식
- 영상, 읽기 자료, 실습, 지식 점검(퀴즈), 토론으로 구성된 자기주도 학습.
- 꾸준한 학습 일정과 반복 연습이 권장된다.

## 예시
종이에 주문 화면을 그린 뒤(저충실도) Figma에서 시각 요소와 상호작용을 추가해 고충실도로 발전시키고, 사용자가 실제로 주문을 완료할 수 있는지 프로토타입으로 검증한다.

## 요약
- `Little Lemon`을 사례로 UX·UI 프로세스를 배운다: 강의는 주문 흐름, 최종 과제는 예약 흐름.
- 저충실도(러프 스케치) → 고충실도(작동하는 정교한 디자인) → 프로토타입(클릭 가능) 순으로 발전시킨다.
- 반복 학습과 실습으로 디자인 기술을 익히는 자기주도 과정이다.
