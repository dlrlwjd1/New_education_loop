# Who Is Your User

## 개요
- 인터뷰와 관찰 결과로 사용자를 이해하고 고객 여정 지도를 작성한다.

## 내용
### 사용자 조사
인터뷰는 사용자의 생각과 목표를, 관찰은 실제 행동과 막히는 지점을 보여 준다. 조사 없이 설계하면 개인적인 가정에 의존해 실패할 수 있다.

### 발견한 주문 문제
메뉴 버튼과 음식 분류가 불명확하고 장바구니 아이콘과 뒤로 가기가 보이지 않았다. 주문을 수정하거나 재료를 추가할 수 없었고, 입력이 끝난 뒤에야 검증 오류가 나타나 사용자가 작업을 포기했다.

### 고객 여정 지도
사용자가 과제를 완료하는 단계와 각 단계의 행동, 생각, 말, 감정을 시간 순서로 기록한다. 시나리오와 기대, 핵심 기회도 함께 정리해 개선 우선순위를 찾는다.

## 예시
```text
웹사이트 진입 → 메뉴 선택 → 주문 맞춤 설정 실패
→ 좌절 → 전화 주문으로 전환
```

## 요약
- 인터뷰와 관찰은 사용자 목표와 실제 문제를 밝힌다.
- 조사 결과를 통해 가정 대신 근거로 설계한다.
- 여정 지도는 단계별 행동과 감정을 시각화한다.
