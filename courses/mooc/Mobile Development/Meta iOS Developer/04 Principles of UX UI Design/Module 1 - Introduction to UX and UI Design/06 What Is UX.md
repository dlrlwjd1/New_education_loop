# What Is UX

## 개요
- 사용자 경험(UX)의 범위와 반복적인 UX 설계 프로세스를 이해한다.

## 내용
### 전체 경험
UX는 사용자가 회사, 서비스, 제품과 상호작용하기 전·중·후의 모든 경험을 포함한다. 사용자가 목표를 쉽게 달성하고 통제감을 느끼는지, 기능이 발견 가능하며 행동에 적절한 피드백을 주는지가 중요하다.

### 사용자를 위한 설계
설계자가 사용자를 대신해 추측하지 않고 실제 사용자의 연령과 능력, 행동을 관찰해야 한다. 직관적이지 않거나 상태가 불명확한 제품 문제를 찾아 개선한다.

### 반복 프로세스
사용자의 작업을 관찰하고 문제를 식별한 뒤 아이디어를 만들고 프로토타입을 제작·테스트한다. 고객과 사업 목표를 만족할 때까지 이전 단계로 돌아가 설계를 수정한다.

## 예시
Little Lemon의 주문 과정을 관찰해 고객이 멈추는 지점을 찾고, 개선 흐름을 프로토타입으로 만든 뒤 반복 테스트한다.

## 요약
- UX는 제품 사용 전후를 포함한 전체 사용자 경험이다.
- 발견 가능성, 피드백, 쉬운 목표 달성이 중요하다.
- 관찰·문제 정의·아이디어·프로토타입·테스트를 반복한다.
