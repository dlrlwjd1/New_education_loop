# Overview of the UX Process

## 개요
- UX 프로세스의 핵심 단계를 이해하고 Little Lemon 재설계에 적용한다.

## 내용
### 다섯 단계
1. **Empathize**: 인터뷰와 관찰로 사용자 요구와 감정을 이해
2. **Define**: 조사 결과를 종합해 문제와 불편을 우선순위화
3. **Ideate**: 스케치, 브레인스토밍, 마인드맵으로 다양한 해결책 생성
4. **Prototype**: 와이어프레임을 실제와 비슷한 인터랙티브 시뮬레이션으로 발전
5. **Test**: 사용자가 과제를 수행하게 하고 피드백과 문제를 관찰

### 반복과 구축
UX는 선형 과정이 아니라 이전 단계로 돌아가 계속 수정하는 반복 과정이다. 충분히 검증한 후 실제 제품을 구축한다.

## 예시
주문 고객을 관찰해 페르소나와 여정 지도를 만들고 문제 진술을 정의한 뒤, 여러 아이디어를 와이어프레임과 프로토타입으로 만들어 과제 기반 테스트를 수행한다.

## 요약
- 공감, 정의, 아이디어, 프로토타입, 테스트가 핵심 단계다.
- 피드백에 따라 여러 단계로 되돌아가 개선한다.
- 검증된 설계를 실제 제품으로 구축한다.
