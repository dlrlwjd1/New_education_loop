# Empathy Tools — 대화정리

## 개요
- 페르소나, 공감 지도와 시나리오로 사용자 관점에 기반한 설계 기준을 만든다.
- 11강(인터뷰·관찰·여정 지도)에서 얻은 데이터를 구체적인 도구 3가지로 정리하는 방법.

## 내용

### 페르소나
- 여러 인터뷰·관찰 참가자의 **공통 특성을 결합**한 현실적인 가상 사용자다.
- 사진, 인구통계, 기술 능력, 소개, 필요와 좌절을 담아, 설계자가 가정 대신 **연구에 근거**하도록 한다.

### 공감 지도
- 사용자가 **말하고(Say), 생각하고(Think), 행동하고(Do), 느끼는(Feel) 것**을 네 영역으로 정리한다.
- 11강 여정 지도와의 차이: 여정 지도는 **시간 순서**대로 단계를 기록하지만, 공감 지도는 시간 순서가 아니라 **사용자의 성격과 관점을 전체적으로** 이해하는 도구다.

### 시나리오
- 페르소나의 구체적인 목표, 원하는 결과, 필요한 행동과 해결 과정을 정의한다.
- 이 단계에서는 아직 **화면을 설계하지 않고** 문제에 공감하는 데 집중한다.

### 페르소나와 공감 지도의 관계 — 대화에서 정리
- 강의 본문은 페르소나와 공감 지도 사이의 명시적인 순서를 말하지 않는다.
- 둘 다 결국 같은 원재료 — 11강의 인터뷰·관찰 데이터 — 에서 나온다. 페르소나는 여러 참가자의 공통 특성을 결합한 것이고, 공감 지도는 그 데이터를 말·생각·행동·감정 네 칸으로 정리한 것이다.
- (참고: 실무에서는 개별 인터뷰 데이터를 공감 지도로 먼저 정리한 뒤, 여러 공감 지도의 공통 패턴을 페르소나로 묶어내는 순서를 쓰기도 한다. 다만 이는 일반적인 UX 실무 관행이며 이 강의가 명시적으로 가르친 내용은 아니다.)

## 예시
Tilly는 60세의 재방문 고객으로 휴대전화에서 좋아하는 비건 파스타를 배달 주문하려 한다. 사이트 접근, 메뉴 선택·맞춤 설정, 정보 입력, 결제와 주문 추적이 필요하다.

## 요약
- 페르소나는 연구 참가자의 특성을 대표하는 가상 사용자, 공감 지도는 사용자의 말·생각·행동·감정을 정리한 도구, 시나리오는 목표와 해결 흐름을 구체화한 것이다.
- 여정 지도(시간 순서)와 공감 지도(전체 관점)는 목적이 다르다.
- 페르소나·공감 지도 모두 같은 인터뷰·관찰 데이터에서 나오며, 강의는 둘의 선후 관계를 명시하지 않는다.
