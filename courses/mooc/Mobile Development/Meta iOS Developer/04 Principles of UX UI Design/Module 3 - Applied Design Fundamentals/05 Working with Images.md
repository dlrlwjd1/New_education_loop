# Working with Images

## 개요
- Figma에 이미지를 삽입하고 표시 방식과 마스크를 조정한다.

## 내용
### 이미지 삽입
Place Image 명령(`Command/Control-Shift-K`), 객체의 Fill을 Image로 변경, 파일 끌어 놓기의 세 가지 방법을 사용할 수 있다.

### 표시 방식
- **Fill**: 영역을 채우도록 이미지 배치
- **Fit**: 전체 이미지를 표시하되 빈 공간이 생길 수 있음
- **Crop**: 원하는 영역으로 자름
- **Tile**: 반복 패턴 생성

노출과 대비 같은 사진 속성도 조절할 수 있다.

### 마스크
이미지와 원하는 형태의 도형을 겹치고 함께 선택한 뒤 Mask를 적용하면 도형 내부만 보인다. 생성된 Mask Group에서 이미지 위치와 크기를 다시 조절한다.

## 예시
인물 사진 위에 원을 놓고 두 레이어를 선택해 원형 프로필 이미지 마스크를 만든다.

## 요약
- 명령, Fill, 드래그 앤 드롭으로 이미지를 추가한다.
- Fill·Fit·Crop·Tile로 표시 방식을 결정한다.
- 마스크로 특정 모양 안의 이미지 영역만 보여 준다.
