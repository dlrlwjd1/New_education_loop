# Module Summary - Applied Design Fundamentals

## 개요
- Figma 기초와 반복적 설계에 관한 Module 3 내용을 복습한다.

## 내용
### Figma 기초
프레임과 레이어, 기본 도형을 만들고 그룹화·정렬·조작했다. 글자와 텍스트 속성, 반응형 그리드와 제약 조건, 이미지 삽입과 마스크도 익혔다.

### 반복적 설계
사용자 요구 사항을 저충실도 와이어프레임으로 바꾸고 빠르게 공유·수정했다. 사용성 테스트의 참여자와 과제, 다양한 테스트 방식도 살펴봤다.

## 예시
모바일 4열 그리드로 주문 와이어프레임을 만든 뒤 실제 사용자에게 음식 선택·주문 과제를 주고 문제를 발견해 설계를 수정한다.

## 요약
- Figma의 기본 도구로 화면 구조를 설계할 수 있다.
- 그리드와 제약으로 반응형 레이아웃을 고려한다.
- 와이어프레임과 사용성 테스트로 아이디어를 반복 검증한다.
