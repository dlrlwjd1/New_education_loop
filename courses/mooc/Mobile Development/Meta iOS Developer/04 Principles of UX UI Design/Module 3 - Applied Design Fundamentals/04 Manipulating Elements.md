# Manipulating Elements

## 개요
- Figma에서 도형을 결합하고 정렬·배분·크기 조절하는 방법을 익힌다.

## 내용
### 불리언 도형 연산
여러 도형을 선택해 Union으로 합치고, Subtract로 다른 도형 영역을 제거하며, Intersect로 겹친 부분만 남기거나 Exclude로 겹친 영역을 제외할 수 있다.

### 정렬과 배분
Design 패널의 도구로 왼쪽·가운데·오른쪽, 위·세로 가운데·아래를 기준으로 정렬한다. 여러 객체의 간격은 가로 또는 세로 배분 기능으로 맞춘다.

### 일반 크기 조절과 Scale
모서리를 끌어 그룹 크기를 바꾸면 자식 도형은 변하지만 글자 크기, 선과 효과는 그대로일 수 있다. Scale 도구를 사용하면 이런 속성까지 비례해 조절된다.

## 예시
카드 안의 아이콘, 텍스트, 테두리와 그림자를 함께 축소할 때 일반 리사이즈 대신 Scale 도구를 사용한다.

## 요약
- 불리언 연산으로 기존 도형을 조합해 새 형태를 만든다.
- 정렬과 배분으로 객체를 정확히 배치한다.
- 전체 속성을 비례 조절하려면 Scale 도구를 사용한다.
