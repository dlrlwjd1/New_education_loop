# Frames, Layers and Basic Shapes

## 개요
- Figma의 프레임(frame)·레이어(layer)·그룹(group) 개념을 정리하고 기본 도형을 그려 복제·정렬·그룹화하는 방법을 익힌다.

## 내용
### 프레임
디자인이 담기는 컨테이너다. 다른 디자인 도구의 아트보드(artboard)에 해당하며, 앱의 화면 하나로 생각하면 된다. 프레임을 추가할수록 Screen 1, Screen 2처럼 화면이 늘어난다. 툴바의 프레임 아이콘을 누르고 드래그하거나, 아이콘을 선택한 뒤 오른쪽 패널에 준비된 프레임 프리셋(desktop 등)에서 고른다.

### 레이어
프레임 안의 개별 객체다. 프레임에 객체를 추가하면 새 레이어가 생성된다.

### 그룹
여러 객체를 하나로 결합하면 그 객체들을 담은 단일 상위 레이어가 만들어진다. 프레임과 그룹은 레이어를 중첩하거나 묶어 파일을 정리한다는 점에서 매우 비슷해 보이지만, 프레임은 독립적인 크기 조절 같은 기능을 훨씬 많이 제공한다.

### 화면 이동과 확대·축소
오른쪽 위 Zoom 메뉴에서 현재 배율과 확대·축소 단축키를 확인할 수 있다. `Command`(또는 `Control`) + `+`로 확대하고 `-`로 축소한다. 화면을 이동할 때는 툴바의 손 아이콘을 선택하거나 키보드의 `Shift`를 사용한다.

### 기본 도형 그리기와 복제
프레임을 선택하고 툴바의 기본 도형 도구에서 원 아이콘 옆 화살표를 눌러 도형 목록을 열어 사각형이나 타원을 고른 뒤 드래그한다. 도형 아이콘을 선택한 상태에서 `Shift`를 누르고 드래그하면 정사각형·정원이 된다. 선택한 도형은 `Control`(또는 `Command`) + `D`로 복제해 원하는 위치에 배치한다.

### 도형 속성
도형을 선택하면 오른쪽 패널에서 x·y 좌표와 너비, 높이, 회전, 코너 반경(corner radius)을 확인하고 바꿀 수 있다. 모든 도형은 기본적으로 회색 채움에 외곽선이 없다. Fill 영역의 작은 사각형을 클릭해 색상 팔레트를 열고 색을 고르며, 슬라이더로 색조를 바꾸거나 투명도와 색상 참조 번호를 직접 입력한다. Stroke로 외곽선을 넣고 위치를 Inside·Outside·Center 중에서 고르며, 오른쪽의 고급 설정에서 선 종류도 바꾼다. 플러스 아이콘으로 그림자(drop shadow) 같은 효과를 추가한다.

### 레이어 패널 관리
왼쪽 레이어 패널에는 그린 순서대로 도형이 레이어로 쌓인다. 쌓임 순서를 바꾸려면 해당 레이어를 드래그해 원하는 레이어 위에 놓는다. 레이어 이름은 알아보기 쉽게 정확히 유지하는 것이 중요하다. 레이어는 켜고 끌 수 있고, 잠그면 이동되지 않는다.

### 그룹으로 묶기
따로 동작하는 요소들을 하나의 객체처럼 움직이게 하려면 함께 선택한 뒤 우클릭해 Group Selection을 고르거나 `Control`(또는 `Command`) + `G`를 누른다. 그룹 안의 도형 하나만 수정하려면 그 도형을 더블클릭한다.

## 예시
사각형을 그린 뒤 코너 반경을 100으로 바꿔 둥근 사각형을 만들고, 레이어 이름을 `Rectangle 2` → `square`, `Ellipse 1` → `circle`로 정리한 다음 둘을 그룹으로 묶어 함께 움직이게 한다.

## 요약
- 프레임은 디자인을 담는 화면 단위 컨테이너이고, 레이어는 그 안의 객체다.
- 프레임과 그룹은 둘 다 레이어를 정리하지만 프레임이 기능이 더 많다.
- 도형은 `Shift`로 비율을 고정하고 `Command`/`Control` + `D`로 복제한다.
- 레이어 패널에서 쌓임 순서와 이름, 표시·잠금을 관리한다.
