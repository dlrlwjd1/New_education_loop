# Type and Text

## 개요
- Figma의 텍스트·폰트 도구를 다룬다. 폰트 선택은 텍스트의 가독성(readability)과 매력도를 결정하며, 색·크기·자간·너비가 모두 제품의 메시지를 전달한다.

## 내용
### 텍스트 요소 만드는 두 가지 방법
툴바의 `T` 아이콘을 클릭하거나 키보드 `T` 단축키를 누른 뒤 바로 입력하면 **자동 크기 조절(auto-resize)** 텍스트 박스가 만들어져 글자가 늘어날수록 너비가 가로로 커진다. 반대로 클릭 후 드래그해 만들면 크기가 고정된 텍스트 박스가 되고, 긴 문장은 박스 끝에 닿는 순간 다음 줄로 넘어간다. 기존 텍스트를 수정할 때는 텍스트 박스 안을 더블클릭한다.

### 세 가지 크기 조절 방식
| 방식 | 적용 시점 |
|---|---|
| **Grow horizontally** — 가로로 확장 | `T`를 눌러 새 텍스트 박스를 만들 때의 기본값 |
| **Fixed** — 고정 | 클릭·드래그로 새 텍스트 박스를 만들 때의 기본값 |
| **Grow vertically** — 세로로 확장 | 오른쪽 Design 패널에서 auto-resize 값을 height로 바꿀 때 |

세로 확장으로 바꾸면 텍스트를 추가할 때 경계 박스가 가로가 아니라 세로로 늘어난다. 이 설정을 쓸 때는 폰트 스타일에 지정된 행간(line height)을 기준으로 텍스트 박스 높이가 잡히게 하고, 내용에 비해 너무 작은 텍스트 박스는 높이가 자동으로 맞춰진다.

### 폰트와 스타일
오른쪽 Design 패널의 드롭다운에서 폰트를 고르거나 필드에 이름을 입력해 검색한다. 스타일은 드롭다운에서 고르거나 단축키를 쓴다 — 굵게는 Windows `Control` + `B` / Mac `Command` + `B`, 기울임은 `Control`/`Command` + `I`, 밑줄은 `Control`/`Command` + `U`다. 폰트 크기는 직접 입력하거나 필드를 선택해 위·아래 화살표로 조절한다.

### 행간과 자간
행간(line height)의 기본값은 `auto`이며 숫자로 바꿀 수 있다. 그 오른쪽의 자간(character spacing) 옵션은 특정 글자 조합의 간격, 즉 커닝(kerning)을 조절한다. Figma는 기본적으로 퍼센트 값을 쓰지만 픽셀 값을 입력하면 단위가 픽셀로 바뀐다.

### 정렬
가로 정렬(horizontal alignment)은 경계 박스 안에서 텍스트가 왼쪽·오른쪽·가운데로 배치되는 방식을 정하고, 세로 정렬(vertical alignment)은 위·아래·중앙으로 배치되는 방식을 정한다.

### 세부 옵션 세 탭
텍스트 옵션 영역 아래 점 세 개를 누르면 탭 세 개가 열린다.

- **Basics** — 가로 크기 조절 방식, 가로 정렬, 취소선·밑줄 같은 장식(decoration), 문단 간격, 첫 줄 들여쓰기, 번호·불릿 목록, 대소문자 변환
- **Details** — 스타일과 위쪽·아래쪽 첨자(superscript, subscript), 분수 같은 위치 설정, 글자 형태(letter form)·문자 변형·가로 간격 등 오픈타입 기능
- **Variables** — 폰트의 가변 축(variable axes) 설정

### 텍스트 속성 패널 밖의 속성
텍스트 색 변경, 외곽선(stroke) 추가, 효과(effect) 추가는 텍스트 속성 패널이 아닌 곳에서 적용한다.

## 예시
Oswald 폰트를 검색해 적용하고 행간을 43으로 올린 뒤 자간을 4픽셀로 지정한다. 그다음 Fill로 글자를 초록색으로 바꾸고 같은 초록색 1포인트 외곽선과 그림자 효과를 텍스트 레이어에 더한다.

## 요약
- `T`를 눌러 만들면 가로 확장, 드래그로 만들면 크기 고정 텍스트 박스가 된다.
- auto-resize 값을 height로 바꾸면 세로로 확장된다.
- 행간·자간은 퍼센트가 기본이고 픽셀 값을 입력하면 단위가 바뀐다.
- 색·외곽선·효과는 텍스트 속성 패널 밖에서 적용한다.
