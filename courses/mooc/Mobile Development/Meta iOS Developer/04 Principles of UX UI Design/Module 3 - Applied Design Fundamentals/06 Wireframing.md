# Wireframing

## 개요
- 사용자 과제와 콘텐츠 구조에 집중한 저충실도 와이어프레임을 Figma로 만든다.

## 내용
### 와이어프레임
브랜드, 색상과 실제 이미지 전에 각 화면의 기본 구조, 콘텐츠 계층과 기능을 표현하는 설계 청사진이다. 아이디어를 빠르게 공유하고 수정하는 데 사용한다.

### 요구 사항과 콘텐츠 블록
Little Lemon 주문 화면에는 브랜드 소개, 메뉴 분류와 가격, 주문 맞춤 설정, 음식 설명·사진, 배달·포장, 수량, 주문 추가, 로그인·결제와 탐색이 필요하다.

### 모바일 우선
대부분의 웹 사용자가 모바일 기기를 사용하므로 작은 화면부터 설계한다. 4열 그리드 위에 탐색, 소개, 메뉴 분류, 음식 카드 블록을 배치하고 큰 화면으로 확장한다.

### 상호작용 메모
로고는 홈으로, 햄버거 메뉴는 탐색 오버레이로, 장바구니는 주문 수정과 결제로 연결된다. 실제 색·글꼴·사진 대신 단순 도형과 설명으로 동작을 표시한다.

## 예시
사진은 대각선이 있는 사각형으로 표시하고, 음식 카드를 탭하면 상세 화면으로 이동한다는 주석을 남긴다.

## 요약
- 와이어프레임은 레이아웃과 기능을 빠르게 검토하는 청사진이다.
- 사용자 요구 사항을 콘텐츠 블록으로 변환한다.
- 모바일 화면에서 시작해 더 큰 화면으로 확장한다.
