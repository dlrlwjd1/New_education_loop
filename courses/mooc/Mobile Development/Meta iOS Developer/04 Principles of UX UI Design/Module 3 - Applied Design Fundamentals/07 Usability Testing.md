# Usability Testing

## 개요
- 사용성 테스트의 참여자, 과제와 정성·정량 및 원격 테스트 방식을 알아본다.

## 내용
### 사용성 테스트
실제 사용자가 웹사이트나 앱에서 과제를 수행하게 하고 행동과 반응을 관찰하는 과정이다. 반복되는 혼란과 어려움을 찾아 개선 권고로 연결한다.

### 주요 구성
진행자(facilitator)는 과제를 제시하고 행동을 관찰하며 후속 질문을 한다. 참가자는 대상 제품 사용자이고, 과제는 실제 생활에서 수행할 법한 행동을 편향 없이 명확하게 표현해야 한다. 생각 말하기(think aloud)도 활용한다.

### 정성·정량 테스트
정성 테스트는 행동의 이유와 문제를 깊게 찾고, 정량 테스트는 과제 성공률과 소요 시간 같은 지표와 기준선을 수집한다. 단일 사용자 그룹의 일반적인 정성 연구에는 약 5명을 권장한다고 소개한다.

### 원격 테스트
진행형 원격 테스트는 화면 공유로 실시간 진행하며, 비진행형 테스트는 참가자가 서면 과제를 자기 속도로 수행하고 녹화와 지표를 연구자에게 전달한다.

## 예시
“샐러드를 장바구니에 담고 수량을 변경한 뒤 결제로 이동하세요”라는 과제를 제시하고 성공 여부, 시간과 막힌 지점을 기록한다.

## 요약
- 실제 사용자의 과제 수행을 관찰해 문제를 찾는다.
- 진행자, 참가자와 정확히 표현된 과제가 핵심이다.
- 목적에 따라 정성·정량, 대면·원격 방식을 선택한다.
