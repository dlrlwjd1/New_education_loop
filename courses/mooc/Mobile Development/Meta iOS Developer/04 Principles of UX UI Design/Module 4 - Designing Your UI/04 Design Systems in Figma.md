# Design Systems in Figma

## 개요
- Auto Layout과 컴포넌트의 마스터·인스턴스로 재사용 가능한 버튼을 만든다.

## 내용
### Auto Layout
텍스트와 배경을 Auto Layout 프레임으로 만들면 내용에 따라 버튼 크기가 자동 조절된다. 텍스트 주변 패딩과 요소 배치 방향도 속성에서 관리한다.

### 컴포넌트와 인스턴스
프레임을 Component로 변환하면 마스터 컴포넌트가 된다. 복제한 인스턴스는 마스터의 공통 속성을 이어받으면서 색이나 내용 같은 개별 속성을 재정의할 수 있다.

### 변경 전파
마스터의 모서리 반경처럼 공통 속성을 수정하면 모든 인스턴스에 반영된다. 특정 인스턴스의 Fill을 바꾸면 해당 인스턴스만 변경된다.

## 예시
메뉴 카테고리 버튼을 Auto Layout 컴포넌트로 만들고 인스턴스별 텍스트와 배경색을 바꾸되 패딩과 모서리 반경은 마스터에서 관리한다.

## 요약
- Auto Layout은 콘텐츠에 맞춰 프레임과 간격을 조절한다.
- 마스터 컴포넌트에서 재사용 가능한 인스턴스를 만든다.
- 공통 변경과 개별 재정의를 구분해 관리한다.
