# Animate and Test Your Prototype

## 개요
- 인터랙티브 컴포넌트와 오버플로 스크롤을 만들어 프로토타입을 테스트·공유한다.

## 내용
### 토글 상태
Auto Layout 버튼을 컴포넌트로 만들고 선택 상태 Variant를 추가한다. Prototype에서 두 상태를 `On click → Change to`로 서로 연결하면 탭할 때 상태가 전환된다.

### 카테고리 목록
버튼 인스턴스를 복제하고 레이블을 바꿔 여러 메뉴 카테고리를 만든다. 가로 Auto Layout 프레임으로 묶어 한 줄에 배치한다.

### 오버플로 스크롤
버튼 목록을 화면 경계보다 넓은 프레임에 넣고 Prototype의 Overflow Scrolling을 Horizontal로 지정한다. 음식 목록은 같은 방식으로 Vertical 스크롤을 설정한다.

### 공유
Present 모드에서 토글과 스크롤을 확인한 뒤 Share에서 링크를 복사해 테스트 참가자에게 전달한다.

## 예시
Starters 버튼을 탭하면 어두운 선택 상태로 바뀌고 다시 탭하면 기본 상태로 돌아오며, 카테고리 행은 좌우로 스크롤된다.

## 요약
- Variant와 Change to로 상태 전환을 만든다.
- Auto Layout 인스턴스로 반복 버튼을 구성한다.
- 오버플로 스크롤을 설정하고 링크로 프로토타입을 공유한다.
