# Module Summary - Designing Your UI

## 개요
- 고충실도 UI, 컴포넌트와 프로토타입 제작에 관한 Module 4를 복습한다.

## 내용
### 시각적 완성도
이미지, 색, 도형, 글자와 공간이 설계에 미치는 영향을 이해하고 브랜드 기준에 맞게 와이어프레임을 고충실도 화면으로 발전시켰다.

### 컴포넌트와 디자인 시스템
좋은 양식 설계와 컴포넌트 기반 제품, 디자인 시스템의 중요성을 살펴봤다. Figma Auto Layout, 마스터 컴포넌트와 인스턴스로 재사용 요소를 만들었다.

### 프로토타입
고충실도 화면을 연결해 인터랙티브 프로토타입을 만들고 Variant와 스크롤 동작을 추가했다. 링크를 공유해 고객과 동료의 테스트와 피드백을 받을 수 있다.

## 예시
브랜드 스타일을 적용한 주문 화면에 재사용 카테고리 버튼과 상세·장바구니 흐름을 연결하고 테스트 링크를 배포한다.

## 요약
- 디자인 요소로 UI의 시각적 완성도를 높인다.
- 컴포넌트와 디자인 시스템으로 일관성을 유지한다.
- Figma에서 프로토타입을 제작·애니메이션·공유할 수 있다.
