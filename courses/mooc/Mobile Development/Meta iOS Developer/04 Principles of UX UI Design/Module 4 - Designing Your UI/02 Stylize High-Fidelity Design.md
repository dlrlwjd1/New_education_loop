# Stylize High-Fidelity Design

## 개요
- 브랜드 가이드와 UI 키트를 적용해 와이어프레임을 고충실도 목업으로 발전시킨다.

## 내용
### 브랜드 자료
브랜드 스타일 가이드는 글꼴, 색상 팔레트, 사진과 이미지 사용법을 규정한다. UI 키트에는 글자 크기, 아이콘과 주요 UI 컴포넌트가 포함된다.

### Figma 스타일
UI 키트의 제목 글꼴과 브랜드 색을 Text Style과 Color Style로 저장한다. 저장된 스타일은 여러 화면 요소에 일관되게 적용할 수 있다.

### 와이어프레임 스타일링
배경과 텍스트에 브랜드 색·글자 스타일을 적용하고 버튼의 색, 글자 대비와 모서리 반경을 UI 키트에 맞춘다. 이미지 플레이스홀더는 실제 음식 사진으로 교체한다.

## 예시
버튼 모서리를 반경 `16`으로 바꾸고 Primary 색상 스타일을 적용한 뒤, 배경과 충분히 대비되는 검정 글자를 사용한다.

## 요약
- 브랜드 가이드와 UI 키트가 고충실도 디자인의 기준이다.
- 글자와 색을 Figma 스타일로 만들어 재사용한다.
- 와이어프레임에 실제 시각 요소와 이미지를 적용한다.
