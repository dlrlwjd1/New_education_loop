# What Are Design Systems

## 개요
- 디자인 시스템과 UI 키트를 구분하고 Atomic Design의 구성 단계를 이해한다.

## 내용
### 디자인 시스템
타이포그래피, 색, 아이콘, 레이아웃, 그리드, 코딩·명명 규칙, 콘텐츠 어조, 스타일 가이드와 개발 문서를 포함하는 제품 제작의 전체 기준이다. 팀이 함께 배우고 일하는 단일 기준을 제공한다.

### UI 키트
UI 키트는 글자 체계, 색상 체계, 버튼과 메뉴 등 인터페이스를 채우는 요소에 집중한다. 디자인 시스템보다 범위가 좁으며 과정 프로젝트에서는 UI 키트를 사용한다.

### Atomic Design
- **Atoms**: 텍스트, 입력, 링크, 버튼 같은 기본 요소
- **Molecules**: 레이블과 입력처럼 원자를 결합한 구성
- **Organisms**: 탐색 바처럼 분자들의 그룹
- **Templates**: 구성 요소를 배치한 기본 화면
- **Pages**: 실제 콘텐츠와 이미지를 적용한 구체적 화면

## 예시
버튼과 입력 필드를 원자로 만들고 로그인 양식 분자로 조합한 뒤, 탐색 바와 함께 페이지 템플릿에 배치한다.

## 요약
- 디자인 시스템은 제품 제작 전반의 규칙과 자산을 포함한다.
- UI 키트는 인터페이스 요소에 한정된 더 작은 체계다.
- Atomic Design은 작은 재사용 요소에서 완성 페이지로 확장한다.
