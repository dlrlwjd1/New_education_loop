# Case Study - How Meta Uses Micro Interactions

## 개요
- Meta 제품에서 마이크로 인터랙션이 상태와 피드백, 감성적 경험을 전달하는 방식을 알아본다.

## 내용
### 마이크로 인터랙션
하나의 목적을 수행하는 작고 반복적인 상호작용이다. 행동 성공 여부, 다음 단계나 오류를 명확히 알려 주면서 제품에 사람다운 즐거움을 더한다.

### 사례
Facebook의 Like 버튼에 마우스를 올리면 반응 선택지가 애니메이션으로 나타난다. 이벤트 생성 결과는 성공 체크 또는 경고 표시가 있는 Toast로 전달된다.

### 설계와 검증
디자이너가 전체 흐름과 화면 상태를 정의하고 엔지니어가 구현한다. 테스트 중 버튼을 눌러도 반응이 없거나 피드백이 지나치게 방해되는 지점을 찾아 수정한다.

### 단순성
마이크로 인터랙션은 화려함보다 명확성과 이해 가능성이 중요하다. 너무 많거나 복잡한 애니메이션은 사용자를 산만하게 한다.

## 예시
예약 제출이 성공하면 녹색 체크 Toast를, 네트워크 오류가 나면 경고 Toast와 재시도 안내를 표시한다.

## 요약
- 마이크로 인터랙션은 행동 결과와 다음 단계를 알려 준다.
- 제품에 피드백과 즐거움을 더하지만 단순해야 한다.
- 설계와 사용성 테스트에서 누락과 과도함을 모두 확인한다.
