# Make It Beautiful

## 개요
- 선, 글자, 색, 도형, 이미지와 공간이 시각적 메시지를 만드는 방식을 이해한다.

## 내용
### 선과 글자
선의 방향과 두께는 시선을 유도하고 강조 수준을 전달한다. 웹 타이포그래피는 글꼴, 크기, 색, 줄 높이와 자간을 화면 크기에 맞게 균형 잡아야 한다.

### 색
색은 분위기와 브랜드 정체성, 강조를 만든다. 디지털 화면은 RGB 색 체계를 사용한다. Hue는 기본 색상 관계, Tint는 흰색 혼합, Tone은 회색 혼합, Shade는 검정 혼합, Saturation은 색의 강도를 뜻한다.

### 도형과 이미지
도형은 정확한 기하학적 형태, 자연스러운 유기적 형태, 현실을 단순화한 추상 형태로 나뉜다. 이미지는 관심과 감정을 유도하고 기억과 신뢰 형성에 도움을 준다.

### 공간
관심 대상은 양의 공간, 주변은 음의 공간이다. 가까운 간격과 겹침은 관계를, 넓은 간격은 분리를 표현한다.

## 예시
주문 카드의 제목은 굵은 글자와 브랜드 색으로 강조하고, 음식 사진과 설명은 좁게 묶되 서로 다른 카드는 충분한 음의 공간으로 구분한다.

## 요약
- 모든 시각 요소의 조합이 디자인 해석에 영향을 준다.
- 색과 글자, 이미지로 브랜드와 계층을 표현한다.
- 공간과 간격으로 요소 사이의 관계를 전달한다.
