# Moving from Design to Prototyping

## 개요
- 고충실도 화면을 연결해 실제 흐름을 시뮬레이션하는 Figma 프로토타입을 만든다.

## 내용
### 프로토타입
프로토타입은 완성 제품과 비슷하게 작동하는 목업이다. 사용자와 이해관계자에게 최종 동작을 보여 주고 구축 전에 피드백을 수집한다.

### 시나리오와 사용자 흐름
페르소나 Tilly가 메뉴를 보고 브루스케타 상세를 확인해 장바구니에 담고, 그리스 샐러드를 추가한 뒤 이전 화면으로 돌아오는 흐름을 정의한다.

### 화면 연결
Prototype 패널에서 탭할 요소의 연결 핸들을 대상 프레임으로 끌어 `Navigate to` 상호작용을 설정한다. Present 모드에서 전체 흐름을 실행하며 확인한다.

## 예시
```text
메뉴 홈 → 브루스케타 상세 → 주문 요약
→ 그리스 샐러드 상세 → 갱신된 주문 요약 → 메뉴 홈
```

## 요약
- 프로토타입은 완성 전 동작과 흐름을 검증한다.
- 페르소나의 현실적인 시나리오를 사용자 흐름으로 만든다.
- Figma에서 요소와 프레임을 연결하고 Present 모드로 시험한다.
