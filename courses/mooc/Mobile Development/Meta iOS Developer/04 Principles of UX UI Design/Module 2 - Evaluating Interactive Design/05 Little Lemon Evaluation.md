# Little Lemon Evaluation

## 개요
- 페르소나(persona) Tilly의 관점으로 Little Lemon 웹사이트의 온라인 주문 기능을 평가해 개선 기회를 찾는다.
- 굿 디자인 원칙(Rams), 휴리스틱 평가(Nielsen), 인터페이스 지침(Shneiderman)으로 위반 사항을 판정한다.

## 내용
### 페르소나가 되어 평가한다
평가하는 동안 앞선 레슨에서 만든 페르소나 Tilly를 계속 염두에 둔다. "이걸 쓰면서 Tilly는 무슨 생각을 할까"를 소리 내어 말하고, 스스로 페르소나가 되어야 한다. 평가할 때 공감 지도(empathy map)나 여정 지도(journey map) 같은 산출물을 채워 보는 것도 좋다.

### Tilly가 겪은 문제
Tilly는 Little Lemon의 단골이고, 집에서 좋아하는 프로그램을 보며 먹는 것을 즐겨 배달 주문을 하려 한다. 모바일에서 사이트를 열고 `Order online` 버튼을 누른 순간부터 막힌다.

- 콘텐츠를 읽기 어렵다.
- 음식을 주문하려는데 **테이블 예약(reserve a table)** 페이지에 도착한다.
- 메뉴를 찾을 수 없다. 이번 주 특별 메뉴와 그릭 샐러드만 보인다.
- 뭔가 잘못했나 싶은데 돌아갈 방법도 모른다.
- `Menu`라는 단어와 그릭 샐러드가 **탭할 수 있다는 표시가 전혀 없다.**
- `Go` 버튼이 있는데 그게 무슨 뜻인지 알 수 없다.
- `Go`를 눌러 보니 메뉴가 그릭 샐러드와 브루스케타 둘뿐이다.
- 이 화면에 왜 후기(testimonial)가 있는지 모르겠다.
- 주문하려면 `Go`인지 `Add`인지 알 수 없고, 장바구니가 어디 있는지도 모른다.
- 버튼 라벨과 동작, 디자인이 일관되지 않고 브루스케타에는 `Add` 버튼조차 없다.

### 위반 판정 — 읽기 어려운 텍스트와 불필요한 예약 버튼
텍스트를 읽기 어렵고 예약 버튼이 왜 있는지 모르겠다는 문제는 **Rams 원칙 3·4·8**을 위반한다 — 3번 "좋은 디자인은 심미적이다", 4번 "좋은 디자인은 제품을 이해할 수 있게 만든다", 8번 "좋은 디자인은 마지막 디테일까지 철저하다". 또 **Nielsen 휴리스틱 8번**도 위반한다. 인터페이스에 무관하거나 거의 필요 없는 정보를 담지 말라는 원칙인데, 여기서는 테이블 예약이 그렇다.

### 위반 판정 — 탭 가능 여부 불분명과 탐색·장바구니 부재
`Menu`가 문장의 일부처럼 보이고 탭할 수 있다는 표시가 없으며, `Go` 버튼이 버튼처럼 보이지 않고, 브루스케타 텍스트가 대부분 가려져 있으며, 탐색과 장바구니가 없다는 문제는 다음을 위반한다.

| 기준 | 위반 항목 |
|---|---|
| **Rams 원칙** | 2번(제품을 유용하게 만든다) · 3번(심미적이다) · 4번(이해할 수 있게 만든다) · 8번(마지막 디테일까지 철저하다) |
| **Nielsen 휴리스틱** | 1번 시스템 상태 가시성 — 무슨 일이 일어나는지 항상 알려 준다 · 4번 일관성과 표준 — 다른 단어·상황·동작이 같은 뜻인지 사용자가 고민하게 하지 않는다 · 6번 기억보다 인지 — 요소·동작·선택지를 보이게 해 기억 부담을 줄인다 · 8번 심미적이고 미니멀한 디자인 |
| **Shneiderman 8가지 황금률** | 1번 일관성을 추구한다 · 7번 내적 통제 위치(internal locus of control)를 지원해 사용자가 행동의 주체가 되게 한다 · 8번 단기 기억 부담을 줄인다 |

## 예시
Tilly가 `Order online`을 눌렀는데 테이블 예약 페이지로 이동하는 흐름을 그대로 따라가 보고, 각 화면에서 "무엇을 눌러야 주문이 되는가"를 판단할 수 없다는 사실을 Nielsen 휴리스틱 1번(시스템 상태 가시성) 위반으로 기록한다. 그다음 "Tilly라면 무엇을 원했을까"를 물으며 두 화면을 다시 설계한다.

## 요약
- 평가는 페르소나가 되어 화면을 실제로 통과해 보는 것에서 시작한다.
- 발견한 문제는 Rams·Nielsen·Shneiderman의 어느 항목을 위반했는지로 판정한다.
- Little Lemon의 핵심 결함은 잘못된 목적지, 탭 가능성 표시 부재, 일관되지 않은 버튼, 탐색·장바구니 부재다.
- 위반 사항을 정리하면 그것이 곧 재설계의 근거가 된다.
