# Components in UI Design

## 개요
- 재사용 가능한 컴포넌트와 디자인 시스템으로 일관된 UI를 효율적으로 만든다.

## 내용
### 컴포넌트
논리적으로 묶이고 독립적으로 재사용할 수 있는 디자인 단위다. 작은 버튼이나 검색창을 결합해 헤더 같은 복합 컴포넌트를 만들고, 이를 조합해 전체 인터페이스를 구성한다.

### 장점
디자인과 개발 작업을 빠르게 반복할 수 있고 일관성이 높아진다. 사용자는 같은 패턴을 쉽게 학습하고 기억한다.

### 디자인 시스템
규모 있게 제품을 만들기 위한 사전 제작 컴포넌트와 패턴, 규칙의 집합이다. 보통 디자인 지침, 패턴 라이브러리, UI 키트·컴포넌트 라이브러리, 프로세스 지침을 포함한다.

## 예시
버튼, 검색창, 탐색 메뉴를 각각 컴포넌트로 만든 뒤 헤더에 조합하고 모든 페이지에서 같은 헤더 인스턴스를 재사용한다.

## 요약
- 컴포넌트는 독립적으로 재사용하는 UI 단위다.
- 작은 요소를 조합해 복잡한 인터페이스를 만든다.
- 디자인 시스템은 일관된 규칙과 자산으로 제품 제작을 확장한다.
