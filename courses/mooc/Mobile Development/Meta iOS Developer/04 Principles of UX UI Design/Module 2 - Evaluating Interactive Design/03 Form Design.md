# Form Design

## 개요
- 명확한 레이아웃, 진행 상태와 즉시 검증으로 사용하기 좋은 양식을 만든다.

## 내용
### 구조와 그룹
입력 필드 사이 간격을 일관되게 두고 레이블과 필드의 관계를 명확히 한다. 주소와 결제처럼 관련 항목을 논리적으로 묶고 대비로 구분한다.

### 진행과 이동
진행 표시기로 현재 단계와 남은 작업을 알리고 이전 단계로 돌아가 입력을 검토할 수 있게 한다.

### 즉시 검증
모든 입력 후가 아니라 각 필드 작성 시 오류를 검증하고 위치와 원인을 구체적으로 알려 준다. 비밀번호 요구 사항과 강도도 입력 중 즉시 보여 준다.

## 예시
예약 정보 → 고객 정보 → 결제의 단계 표시를 제공하고, 이메일 형식과 비밀번호 조건을 필드 바로 옆에서 실시간 검증한다.

## 요약
- 필드와 섹션을 명확히 구분한다.
- 현재 위치와 완료 경로를 보여 준다.
- 오류와 요구 사항을 입력 시점에 구체적으로 안내한다.
