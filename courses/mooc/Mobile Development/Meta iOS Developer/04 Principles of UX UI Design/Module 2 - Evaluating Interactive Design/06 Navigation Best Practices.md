# Navigation Best Practices

## 개요
- "내가 어디 있는지 모르겠다"는 사용자 피드백은 콘텐츠와 그 조직 방식의 문제다.
- 사용성(usability)을 염두에 두고 콘텐츠와 구조를 검토하는 방법, 그리고 정보구조(information architecture)와 콘텐츠 전략(content strategy) 관점의 탐색 모범 사례를 다룬다.

## 내용
### 사용자를 편안하게 만드는 두 가지 방법
사용자가 언제나 자기 위치를 알고 편안함을 느끼게 하는 접근은 크게 둘이다 — **콘텐츠 전략**과 **정보구조**. 두 방법론은 깊고 풍부해서 이 코스에서는 입문 수준으로 다루고 핵심 원칙만 적용한다. 더 깊이 이해하려면 추가 자료 읽기를 참고한다.

### 콘텐츠 전략
웹사이트의 콘텐츠를 제품 홍보에 도움이 되도록 의미 있게 제시하는 일이다. 클라이언트의 비즈니스 목표와 UX 목표를 정렬시키고, 콘텐츠를 페르소나와 시나리오 중심으로 맞추는 데 도움을 준다. 대략 네 가지 표제로 콘텐츠를 구조화한다.

| 표제 | 내용 |
|---|---|
| **우선순위(prioritization)** | 어떤 콘텐츠를 넣을지, 그것이 사용자에게 얼마나 관련 있는지 결정한다 |
| **조직(organization)** | 관련 콘텐츠를 묶고 라벨을 붙이는 틀 — 사용자가 자기에게 중요한 것을 찾을 수 있게 한다 |
| **제시(presentation)** | 콘텐츠 조각들이 조립되어 사용자에게 보이는 형태 |
| **명세(specifications)** | 콘텐츠 조각별 요구 사항 |

### 정보구조와 카드 소팅
좋은 탐색을 설계하기 위해 무엇을 알아야 하는지 알아내는 데 쓴다. 규모가 큰 웹사이트는 좋은 탐색을 뒷받침하려고 정보를 특정한 방식으로 구조화하고 색인해야 할 수 있지만, Little Lemon 같은 경우에는 단순한 **카드 소팅(card sorting)** 으로 충분하다. 사이트에 넣고 싶은 개별 요소를 모두 포스트잇에 적고, 잠재 사용자에게 자기 기준으로 논리적인 그룹으로 정렬하게 한 뒤 결과를 묶는다. 테이블이나 벽에서 진행하며 menu, about 같은 섹션으로 카드를 모은다.

### Little Lemon의 탐색 구조
카드 소팅 결과 웹사이트 탐색은 다섯 섹션으로 정리된다.

- **Home** — 사이트의 도입 요약
- **About** — 식재료 정보, 형제의 이야기와 할머니 이야기, 소셜 채널 링크
- **Menu** — 전통적인 레스토랑 메뉴를 최신 상태로, 인쇄 가능하게 정리
- **Reservations** — 테이블 예약
- **Order Online** — 배달 주문

이 탐색 바는 **주 탐색(primary navigation)** 이며 모든 페이지 상단에 놓인다.

### 탐색 바 모범 사례
탐색 바 같은 요소의 위계와 순서는 의미와 장소감(sense of place)을 만든다. 탐색 바 요소는 장소감에 강한 영향을 주며, 모든 페이지에 존재해 사이트 구조를 강화한다.

- 탐색을 페이지 **상단**에 둔다 — 익숙한 모델이다.
- 탐색에 **여백**을 주고 다른 정보나 그래픽으로 어지럽히지 않는다.
- 링크가 눈에 띄도록 **대비되는 색**을 쓴다.
- 링크가 링크처럼 보이게 하고 숨기지 않는다.
- 현재 페이지의 링크는 **더 굵은 굵기나 다른 색과 밑줄**로 활성 상태를 표시한다.
- **로고**는 홈으로 가는 링크 역할을 한다.
- 페이지 하단 **푸터**에도 모든 개별 페이지와 소셜 채널 링크를 넣는다.
- **모바일**은 공간이 부족하므로 햄버거 메뉴를 쓰고, 누르면 다른 페이지 링크를 담은 사이드 메뉴가 열린다.

## 예시
사이트에 넣을 요소를 포스트잇에 적어 사용자에게 그룹핑하게 한 결과를 Home · About · Menu · Reservations · Order Online 다섯 개로 확정하고, 이를 모든 페이지 상단의 주 탐색 바로 만든 뒤 현재 페이지 링크만 굵게·밑줄로 표시하고 모바일에서는 햄버거 메뉴로 대체한다.

## 요약
- "여기가 어딘지 모르겠다"는 피드백은 콘텐츠 전략과 정보구조로 해결한다.
- 콘텐츠 전략은 우선순위 · 조직 · 제시 · 명세로 구조화한다.
- 작은 사이트의 정보구조는 카드 소팅으로 도출할 수 있다.
- 주 탐색은 모든 페이지 상단에 두고, 활성 링크를 표시하며, 모바일에서는 햄버거 메뉴를 쓴다.
