# Course Recap for Principles of UX and UI

## 개요
- UX·UI 원칙 과정에서 학습한 사용자 중심 설계와 Figma 실습을 종합한다.

## 내용
### UX·UI와 사용자 중심 설계
UX와 UI를 구분하고 UX 목표와 품질 요소, 다양한 디자인 접근을 학습했다. 인터뷰와 관찰, 페르소나와 공감 도구를 이용해 사용자를 의사결정의 중심에 두었다.

### 평가와 접근성
Rams, Nielsen, Shneiderman의 방법론으로 인터랙티브 디자인을 평가했다. 접근성과 탐색, 양식 설계의 모범 사례도 실제 문제에 적용했다.

### 반복 설계와 Figma
프레임, 레이어, 글자, 그리드, 도형과 이미지를 사용해 와이어프레임을 만들고 사용성 테스트를 수행했다. 브랜드 스타일, 컴포넌트와 디자인 시스템으로 고충실도 UI를 만든 뒤 프로토타입과 마이크로 인터랙션을 추가했다.

## 예시
최종 과제에서는 Little Lemon의 테이블 예약 흐름을 사용자 조사에서 시작해 와이어프레임, 고충실도 화면과 테스트 가능한 프로토타입으로 완성한다.

## 요약
- 사용자 중심 UX 프로세스를 반복적으로 수행할 수 있다.
- 검증된 원칙으로 인터페이스와 접근성을 평가한다.
- Figma에서 컴포넌트 기반 고충실도 프로토타입을 만든다.
