# React Native

**Course URL:** [mooc.org/learn/react-native-course](https://www.mooc.org/learn/react-native-course)

Meta 강좌. React 지식을 바탕으로 하나의 코드베이스(codebase)로 iOS·Android 모바일 앱을 만드는 **React Native**를 다루는 5모듈 강좌. Expo 개발 환경, 코어 컴포넌트(View·Text·ScrollView), 리스트(FlatList·SectionList)와 텍스트 입력(TextInput), Pressable·이미지·훅(hook), React Navigation(스택·탭·드로어)까지 Little Lemon 레스토랑 앱 시나리오로 실습하며 익힌다.

## 모듈 구성

- [Module 1 - Introduction to React Native](Module%201%20-%20Introduction%20to%20React%20Native/) — React Native 개념과 개발자 역할, Expo 개발 환경, 컴포넌트(component)와 View·Text·ScrollView, StyleSheet 스타일링
- [Module 2 - Lists and Text Input in React Native](Module%202%20-%20Lists%20and%20Text%20Input%20in%20React%20Native/) — FlatList·SectionList로 대용량 리스트 렌더링, TextInput과 가상 키보드(virtual keyboard) 처리
- [Module 3 - Pressable, Images and Hooks in React Native](Module%203%20-%20Pressable%2C%20Images%20and%20Hooks%20in%20React%20Native/) — Pressable 터치 처리, Image·ImageBackground, useColorScheme·useWindowDimensions·커뮤니티 훅
- [Module 4 - React Navigation](Module%204%20-%20React%20Navigation/) — 스택(stack)·탭(tab)·드로어(drawer) 내비게이션 설정과 화면 이동, 헤더 바 커스터마이즈
- [Module 5 - Final project assessment](Module%205%20-%20Final%20project%20assessment/) — 강좌 전체 회고와 Little Lemon 뉴스레터 가입 폼 동료 평가 과제. **영상 3개 중 1개(`02` Solution walk-through)는 선행 평가 잠금으로 정리하지 않았다** — 동료 평가 과제를 제출해야 열리며, 채점 과제를 건너뛰는 저장소 정책상 구조적 제약이다

## 핵심 개념 요약

- **React Native**: Meta가 만든 오픈 소스 라이브러리. JavaScript/React로 작성한 코드가 네이티브(native) UI로 렌더링되어 하나의 코드베이스로 iOS·Android 앱을 만든다.
- **Expo**: React Native 위의 추상화 계층(abstraction layer). `npx create-expo-app`으로 빠르게 시작하고 OTA(over-the-air) 업데이트와 내장 네이티브 API를 제공한다.
- **코어 컴포넌트(core components)**: View(레이아웃 컨테이너), Text(텍스트 표시), ScrollView(스크롤, 부모 높이 제한 필요), 스타일은 `StyleSheet.create`로 분리한다.
- **리스트 렌더링**: FlatList는 지연 렌더링(lazy rendering)으로 대용량 리스트에 적합하고(`data`·`renderItem` 필수), SectionList는 섹션 헤더가 있는 그룹형 리스트를 렌더링한다.
- **TextInput과 가상 키보드**: `onChangeText`·`keyboardType` 등으로 입력을 처리하고, `KeyboardAvoidingView`와 `keyboardDismissMode`로 가상 키보드(virtual keyboard) 가림 문제를 해결한다.
- **Pressable·Image·훅**: Pressable은 onPressIn/onPressOut/onLongPress를 지원하는 터치 컴포넌트, Image/ImageBackground는 `resizeMode`로 이미지 표시를 제어하며, useColorScheme·useWindowDimensions 훅으로 다크 모드와 화면 크기에 대응한다.
- **React Navigation**: `NavigationContainer` + `createNativeStackNavigator`/`createBottomTabNavigator`/`createDrawerNavigator`로 스택·탭·드로어 내비게이션을 구성하고, `navigation.navigate`/`goBack` 등으로 화면을 이동한다.
