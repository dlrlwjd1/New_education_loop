# Module summary: React Navigation

## 개요
- React Navigation 모듈 전체를 복습하는 요약 강의다.
- React Navigation의 개념·장단점, 스택(stack)·탭(tab)·드로어(drawer) 내비게이션의 구현과 커스터마이즈를 배웠다.

## 내용

### 모듈 도입 — React Navigation 기초
- React Navigation이 무엇인지 설명할 수 있다.
- React Native에서 화면 간 전환에 어떻게 사용되는지 설명할 수 있다.
- React Navigation 사용의 장점(benefits)과 트레이드오프(trade-offs)를 설명할 수 있다.
- React Navigation 설치·설정과 네이티브 스택 내비게이터(Native Stack Navigator)의 생성·구성을 할 수 있다.

### 스택 내비게이터 적용
- Little Lemon 앱에 두 화면으로 구성된 스택 내비게이터를 만들었다.
- 옵션과 props 전달로 화면을 커스터마이즈하고 내비게이션 라우트(route)를 설정했다.

### 화면 간 이동
- navigation prop의 메서드로 동작을 커스터마이즈했다.
  - `navigate`: 지정한 라우트로 이동
  - `push`: 새 라우트 추가
  - `goBack`: 뒤로 이동
  - `popToTop`: 스택 맨 위(첫 화면)로 이동
- 스택에서 화면 간 이동, 이전 화면으로 돌아가기, 헤더 바(header bar) 구성·커스터마이즈 코드를 작성했다.

### 탭 내비게이션
- 탭 내비게이션이 무엇이고 스택 내비게이션과 어떻게 다른지 설명할 수 있다.
- React Native 앱에 탭 내비게이터를 적용·구성하는 방법을 익혔다.
- React Navigation으로 탭 내비게이션 코드를 작성하고 탭 내비게이터를 커스터마이즈했다.

### 드로어 내비게이션
- 드로어 내비게이션이 무엇이고 스택·탭 내비게이션과 어떻게 다른지 설명할 수 있다.
- React Native 앱에 드로어 내비게이터를 적용·구성하는 방법을 익혔다.
