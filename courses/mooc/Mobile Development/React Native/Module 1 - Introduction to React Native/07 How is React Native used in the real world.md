# How is React Native used in the real world?

## 개요
- 모바일 앱 산업은 매년 수천억 달러의 매출과 분기당 수십억 건의 다운로드를 기록하며 성장 중 — 모바일 개발자에게 좋은 시기
- 금융기관, 이커머스(e-commerce) 플랫폼, 금융 자문 회사 등 실제 기업들의 React Native 도입 사례 소개
- 공통 이점: 개발 속도, 플랫폼 간 코드 공유, 웹·모바일 팀 간 지식 공유, 배포(deployment)의 용이성

## 내용
### 모바일 앱 산업 배경
모바일 앱 산업은 매년 수천억 달러(hundreds of billions USD)의 매출을 창출하고, 매 분기 수십억 건의 앱 다운로드가 일어난다. React Native 개발자는 교차 플랫폼 네이티브 앱을 만들 수 있어 이 성장하는 산업에 참여할 수 있다.

### 사례 1: 금융기관 (financial institution)
한 유명 금융기관은 iOS·Android 소비자 앱을 React Native로 만들어 효율성을 높였다. iOS 버전과 Android 버전을 코드 공유 없이 병렬로 따로 개발하는 대신 React Native를 선택해 코드를 공유하고 지연과 반복 작업을 줄였다. 또한 React Native는 코드를 자동으로 새로 고침(refresh)해 신규 기능 출시를 가속했다. 새 버전마다 앱 스토어 승인(approval)을 기다리는 지연을 피할 수 있었고, 사용자는 앱을 열면 자동으로 최신 업데이트를 받는다.

### 사례 2: 다국적 이커머스 플랫폼
수년간 네이티브 모바일 개발을 하다가 React Native로 전환했다. 이 회사는 이미 웹 애플리케이션에서 React를 광범위하게 사용하고 있었고, React Native도 React를 사용하므로 기존 코드의 재사용 가능성이 있고 React에서 React Native로의 학습 곡선(learning curve)이 상대적으로 낮았다. 인기 앱 일부를 React Native로 재작성한 결과 iOS와 Android 간 코드의 **95%가 공유**되었다.

### 사례 3: 금융 자문 회사 (financial advisor company)
React Native로 앱을 만들어 얻은 가장 큰 성과는 **시장 출시 시간(time to market) 단축**이었다. 개발 속도(velocity)가 매우 높아 개발 시작 5주 만에 iOS와 Android 양쪽에 앱 첫 버전을 출시했다. 프로덕트 엔지니어가 React와 React Native 앱 양쪽에 쉽게 기여할 수 있어, 웹 팀과 모바일 팀(React·React Native 개발자)이 공유된 원칙·이념·패러다임(paradigm) 아래 협업하게 되었다.

### 공통 이점 정리
- 개발 속도(speed of development)
- 플랫폼 간 코드베이스 공유
- 웹과 모바일(React와 React Native) 간 아이디어·코드 공유
- 배포의 용이성(ease of deployment)

## 요약

- 금융기관은 코드 공유와 자동 코드 새로 고침으로 앱 스토어 승인 지연을 줄였다.
