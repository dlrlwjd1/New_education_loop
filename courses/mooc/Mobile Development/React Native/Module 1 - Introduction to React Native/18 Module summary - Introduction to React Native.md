# Module summary: Introduction to React Native

## 개요
- Module 1 (Introduction to React Native)에서 배운 내용을 레슨별로 되짚는 요약 강의
- React Native 개념, 개발자 역할, Expo, 컴포넌트 분류, View/Text/ScrollView, StyleSheet 스타일링까지의 학습 성과 정리

## 내용
### 레슨 1: 코스 소개
- React Native가 무엇인지 설명하고, React Native를 사용하는 동기를 설명할 수 있다.
- 네이티브(native)·교차 플랫폼(cross-platform)·하이브리드(hybrid) 개발자 역할 관련 용어를 설명할 수 있다.
- 이 코스에서 성공하기 위한 단계를 적용하고, React Native CLI로 VS Code에서 React Native 프로젝트를 설정할 수 있다.

### 레슨 2: React Native 본격 소개
- React Native의 기초를 설명하고, 모바일 개발에서 다른 언어 대비 React Native의 이점을 설명할 수 있다.
- React Native가 실제 세계에서 어떻게 쓰이는지 설명할 수 있다.
- Expo 플랫폼이 무엇인지, 교차 플랫폼 모바일 앱을 만드는 데 어떻게 쓰이는지 배웠고, Expo로 간단한 React Native 앱을 만들 수 있다.

### 레슨 3: React Native 컴포넌트
- React Native 컴포넌트가 어떻게 분류되는지(코어·커뮤니티·네이티브) 설명할 수 있다.
- 서로 다른 컴포넌트 집합이 앱을 만드는 데 어떻게 쓰이는지 설명할 수 있다.
- 첫 커스텀 컴포넌트를 직접 만들 수 있다.

### 레슨 4: View, Text, ScrollView
- React Native의 두 기본 코어 컴포넌트인 `View`와 `Text`의 사용법을 시연하고 기본 기능과 용법을 설명할 수 있다.
- `ScrollView` 컴포넌트로 스크롤 가능한 뷰를 만들고 기본 사용법을 설명할 수 있다.

### 레슨 5: 컴포넌트 스타일링
- 인라인 스타일링(inline styling)이 무엇인지 설명할 수 있다.
- 스타일시트(StyleSheet) 사용의 이점을 설명할 수 있다.
- 실전 스타일링 예제를 경험했다.

## 요약
- React Native의 개념·동기, 개발자 역할 유형(네이티브/교차 플랫폼/하이브리드)을 배웠다.
- Expo로 개발 환경을 설정하고 간단한 앱을 만들 수 있다.
- 컴포넌트 분류(코어/커뮤니티/네이티브)를 이해하고 첫 컴포넌트를 만들었다.
- View, Text, ScrollView로 화면을 구성하고 StyleSheet API로 깔끔하게 스타일링할 수 있다.
- 코딩 실습을 통해 React Native의 기초에 익숙해졌다 — 학습 여정의 좋은 출발점이다.
