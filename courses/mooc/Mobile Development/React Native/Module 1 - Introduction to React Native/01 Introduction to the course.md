# Introduction to the course

## 개요
- React Native 입문 코스의 전체 구성과 학습 목표를 소개하는 오리엔테이션 강의
- 지중해 레스토랑 Little Lemon의 모바일 앱을 만드는 개발자의 관점에서 코스를 진행
- 최종적으로 Little Lemon 뉴스레터 가입 폼(sign-up form)을 만드는 동료 평가(peer review) 과제로 마무리

## 내용
### 코스 배경 설정
이 코스는 클라이언트로부터 모바일 앱 제작을 의뢰받은 개발자의 시나리오로 진행된다. 클라이언트는 캐주얼한 분위기에서 심플한 음식과 칵테일을 제공하는 지중해 레스토랑 **Little Lemon**이다.

### 모듈별 학습 내용
1. **React Native 소개** — React Native가 무엇인지, 장점과 활용 사례(use case), 기본 컴포넌트(component)와 스타일링, 이를 활용한 앱 구축
2. **핵심 컴포넌트** — `View`, `Text`, `ScrollView` 등 앱의 시각적 레이아웃(visual layout)을 구성하는 코어 컴포넌트(core components)
3. **리스트와 텍스트 입력** — `FlatList`, `SectionList`로 크고 성능 좋은(performant) 리스트 렌더링, `TextInput` 컴포넌트로 키보드 사용자 입력 구성
4. **Pressable·이미지·훅** — 버튼 등 누를 수 있는(pressable) 영역을 만들어 상호작용성(interactivity) 추가, 이미지 표시와 스타일링, React Native 훅(hooks)으로 컴포넌트 기능 확장
5. **내비게이션** — React Navigation을 활용한 화면 간 이동. 스택(stack), 탭(tab), 드로어(drawer) 내비게이션 등 모바일 앱에서 널리 쓰이는 유형 학습
6. **졸업 과제(graded assessment)** — Little Lemon 뉴스레터 가입 폼을 React Native로 제작하고, 동료 평가(peer review)로 서로 피드백 제공

### 학습 방법
- 영상은 시청·일시정지·되감기·재시청하며 자신감이 생길 때까지 반복한다.
- 읽기 자료(readings)와 실습(exercises)으로 지식을 다진다.
- 지식 퀴즈(knowledge quiz)로 스스로 진도를 점검한다.
- 토론 프롬프트(discussion prompts)로 동료 수강생과 지식을 공유하고 네트워크를 만든다.

## 요약
- Little Lemon 레스토랑 앱을 만드는 개발자 시나리오로 React Native를 배운다.
- 기본 컴포넌트 → 코어 컴포넌트(View/Text/ScrollView) → 리스트·입력 → Pressable·이미지·훅 → 내비게이션 순으로 진행된다.
- 최종 과제는 뉴스레터 가입 폼 제작이며 동료 평가로 채점된다.
- 새로운 용어가 많더라도 코스를 진행하며 자연스럽게 이해하게 된다.
