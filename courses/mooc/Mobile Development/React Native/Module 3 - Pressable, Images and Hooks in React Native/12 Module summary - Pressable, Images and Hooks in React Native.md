# Module summary: Pressable, Images and Hooks in React Native

## 개요
- Pressable, Images, Hooks 모듈에서 배운 내용을 되짚는 요약 강의다.
- 세 레슨(Pressable 컴포넌트, Image 컴포넌트, 훅)의 학습 성과를 정리한다.

## 내용

### 레슨 1 — Pressable 컴포넌트
- 사용자가 앱과 상호작용하는 방식에 대한 설명으로 모듈을 시작했다.
- 학습 성과:
  - Pressable 컴포넌트가 무엇인지 설명할 수 있다.
  - onPressIn, onPressOut 같은 Pressable의 공통 메서드를 식별할 수 있다.
  - Pressable 컴포넌트가 텍스트나 이미지 등 다양한 형태로 표현될 수 있음을 설명할 수 있다.
  - 사용자 프레스에 반응하는 Pressable 컴포넌트를 만들고, useState 훅으로 그 상태를 추적할 수 있다.

### 레슨 2 — Image 컴포넌트
- 학습 성과:
  - Image 컴포넌트가 무엇인지 설명할 수 있다.
  - 이미지를 어디에서 소싱할 수 있는지 식별할 수 있다.
  - 지원되는 이미지 포맷을 식별할 수 있다.
  - React Native 앱에서 Image 컴포넌트를 만들고, 그 안의 이미지를 스타일링할 수 있다.

### 레슨 3 — React Native의 훅(hooks)
- 학습 성과:
  - 훅이 유용한 상황을 설명할 수 있다.
  - 컴포넌트에 훅을 적용하는 기본 코딩 구조를 설명할 수 있다.
  - useColorScheme 훅, useWindowDimensions 훅, 그리고 React Native 개발자 커뮤니티가 만든 여러 커뮤니티 훅을 언제 어떻게 쓰는지 안다.

## 예시
- 이 강의는 요약 강의로 별도 코드 예시는 없다. 모듈 중 코딩 연습(coding exercises)을 통해 관련 기능 사용을 실습했다.

## 요약
- Pressable: 프레스 상호작용 감지, onPressIn/onPressOut, useState로 상태 추적.
- Image: 이미지 소스와 지원 포맷 이해, 컴포넌트 생성과 스타일링.
- Hooks: 훅의 활용 상황과 기본 구조, useColorScheme·useWindowDimensions·커뮤니티 훅 사용.
- 이 기술들을 모두 Little Lemon 앱에 적용할 수 있다.
