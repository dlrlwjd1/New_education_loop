# Congratulations, you have completed React Native!

## 개요
- React Native 강좌 수료를 축하하는 마무리 강의
- 랩 프로젝트(뉴스레터 가입 폼)에서 활용한 핵심 역량을 되짚음
- 다음 학습 단계와 Meta 수료증(certificate)에 대한 안내

## 내용

### 지금까지의 성장
- 강좌 초반에는 크로스 플랫폼 개발(cross-platform development)에서 React Native의 장점을 배우는 단계였음
- 이제는 스크롤, 텍스트 입력, 화면 간 이동 등이 가능한 앱을 만들 수 있게 됨

### 랩 프로젝트 요구사항 정리
- React Native로 뉴스레터 가입 폼(newsletter sign-up form)을 구축하는 프로젝트를 완료
- 폼에서 활용해야 하는 핵심 컴포넌트(core components):
  - `View`, `Text`
  - `TextInput`, `Image`, `Pressable` 또는 `Button`
- 폼에서 보여줘야 하는 능력:
  - React Navigation으로 사용자가 화면 간 이동(move between screens)을 할 수 있게 구성
  - `Pressable` 또는 `Button` 컴포넌트가 사용자 동작(user actions)에 반응하도록 구성
  - 문맥에 맞는(context sensitive) `TextInput` 컴포넌트 구성
- 이 랩을 통해 앞으로 만들 많은 React Native 앱에 적용 가능한, 이전 가능한(transferable) 기술을 경험

### 다음 단계
- 지식을 더 넓히고 싶다면 React advanced 코스가 다음 단계로 가장 적합
- 프로그램의 모든 코스를 성공적으로 마치면 성취를 증명할 수 있는 수료증(certificate)을 받음
- 이는 다른 Meta 역할 기반 수료증(role based certificates)으로 진행하는 경로가 됨
- 목표에 따라 특정 역할을 더 깊이 탐구하거나 다른 기초 코스에 등록할 수 있음
- Meta 수료증은 기술 역량에 대한 세계적으로 인정받는(globally recognized) 증거를 제공

## 예시
- 축하·마무리 영상으로 별도의 코드 예시는 없음

## 요약
- React Native 강좌를 완주하며 스크롤, 텍스트 입력, 화면 이동이 가능한 앱을 만드는 능력을 갖춤
- 뉴스레터 가입 폼 랩에서 `View`/`Text`/`TextInput`/`Image`/`Pressable`(또는 `Button`)과 React Navigation 활용 능력을 검증
- 다음 단계는 React advanced 코스이며, 프로그램 수료 시 Meta 수료증을 취득
