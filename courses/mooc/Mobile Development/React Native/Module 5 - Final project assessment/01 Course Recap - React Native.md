# Course Recap: React Native

## 개요
- React Native 강좌 전체 내용을 모듈별로 되짚어보는 요약 강의
- Little Lemon 레스토랑 앱(메뉴 보기, 피드백 폼 등)을 만들며 배운 기술 정리
- 마지막 모듈의 동료 평가(peer graded) 과제인 뉴스레터 가입 폼 안내

## 내용

### 모듈 1 — React Native 소개
- React Native가 무엇인지, 장점과 사용 사례(use-cases)를 학습
- 기본 컴포넌트(component)와 스타일링(styling)을 배우고 이를 활용해 React Native 앱을 구축

### 모듈 2 — 핵심 컴포넌트와 레이아웃
- `View`, `Text`, `ScrollView` 같은 핵심 컴포넌트(core components) 학습
- 주로 앱의 시각적 레이아웃(visual layout) 구성에 관한 내용

### 모듈 3 — 리스트와 텍스트 입력
- `FlatList`와 `SectionList` 컴포넌트로 크고 성능 좋은(performant) 리스트 구축
- `TextInput` 컴포넌트로 키보드를 통한 사용자 입력 구성

### 모듈 4 — Pressable, 이미지, Hooks, 내비게이션
- `Pressable` 컴포넌트로 버튼 등 눌 수 있는 영역을 만들어 인터랙티비티(interactivity) 추가
- 앱에서 이미지를 표시하고 스타일링하는 방법 학습
- React 컴포넌트의 기능을 확장하는 주요 React Native 훅(hooks) 학습
- React Navigation으로 화면 간 이동: Stack, Tab, Drawer 내비게이션 등 다양한 유형과 핵심 기능을 익히고 앱에 설정

### 모듈 5 — 최종 평가
- 졸업 과제로 Little Lemon 뉴스레터 가입 폼(newsletter sign-up form)을 React Native로 제작
- 동료 평가(peer graded assignment)이므로 다른 수강생의 프로젝트도 리뷰

### 학습 방식 회고
- 영상 시청(일시정지·되감기·재시청), 읽기 자료, 실습 과제로 지식을 다짐
- 지식 퀴즈(knowledge quiz)로 자가 점검, 토론 프롬프트로 수강생과 교류

## 예시
- 이 강의는 요약 영상으로 별도의 코드 예시는 없음

## 요약
- 강좌 전반에서 React Native 기초 → 핵심 컴포넌트 → 리스트/입력 → Pressable·이미지·훅 → 내비게이션 순으로 학습
- Little Lemon 앱을 통해 배운 내용을 실전에 적용
- 마지막 단계는 뉴스레터 가입 폼을 만드는 동료 평가 과제
