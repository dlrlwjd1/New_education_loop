# Advanced React Native Techniques & Deployment

**Course URL:** [mooc.org/learn/packt-advanced-react-native-techniques-deployment-gqmg9](https://www.mooc.org/learn/packt-advanced-react-native-techniques-deployment-gqmg9)

Packt의 **The Complete React Native Bootcamp 2026** 전문과정에 포함된 8모듈 강좌. React Native CLI 환경 구성부터 Firebase, 네이티브 모듈, AI 채팅 앱, 배포, 애니메이션까지 다룬다.

## 진행 상태

- 완료: Module 1~8
- 남음: 없음
- 영상 기준: **86/86강 완료**

## 모듈 구성

- [Module 1 - Introduction to React Native CLI](Module%201%20-%20Introduction%20to%20React%20Native%20CLI/) — React Native CLI 환경 구성과 시뮬레이터·실기기 실행
- [Module 2 - Firebase with React Native CLI](Module%202%20-%20Firebase%20with%20React%20Native%20CLI/) — Android·iOS Firebase 연동, 푸시 알림, Google 로그인
- [Module 3 - Native Code and Native Modules](Module%203%20-%20Native%20Code%20and%20Native%20Modules/) — 카메라·갤러리, 앱 아이콘·스플래시 화면, 지도, SVG와 벡터 아이콘
- [Module 4 - AI Chat App - Folder Structure](Module%204%20-%20AI%20Chat%20App%20-%20Folder%20Structure/) — AI 채팅 앱 폴더 구조, 개발 스크립트, Reactotron
- [Module 5 - AI Chat App - App UI and Integration](Module%205%20-%20AI%20Chat%20App%20-%20App%20UI%20and%20Integration/) — 채팅 UI, 메시지 상태, Hugging Face·OpenAI 연동
- [Module 6 - React Native CLI Deployment](Module%206%20-%20React%20Native%20CLI%20Deployment/) — APK·AAB 생성과 Android·iOS OTA 업데이트
- [Module 7 - Animations with React Native](Module%207%20-%20Animations%20with%20React%20Native/) — 이동·페이드·회전·크기·색상 애니메이션
- [Module 8 - JavaScript Crash Course (Optional)](Module%208%20-%20JavaScript%20Crash%20Course%20%28Optional%29/) — JavaScript 문법 복습
