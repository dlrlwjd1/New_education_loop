# Animation Section Introduction

## 개요
- React Native 애니메이션이 앱의 사용자 경험과 시각적 피드백을 개선하는 이유를 소개한다.
- 내장 Animated API의 기본부터 복합 애니메이션까지 단계적으로 학습한다.

## 내용
### 애니메이션의 역할
- 애니메이션은 앱을 보기 좋게 만드는 것뿐 아니라 상태 변화와 사용자 동작의 결과를 자연스럽게 전달한다.
- 앱에 개성을 더하고 실제 제품에서 느껴지는 반응성을 높인다.

### 학습 범위
- Animated API의 기본 사용법을 익힌다.
- 위치(position), 투명도(opacity), 크기(scale), 색상(color)을 애니메이션한다.
- 실제 앱에 적용하는 예제와 성능 관련 팁을 다룬다.

## 예시
```text
학습 흐름: 단일 값 → 위치 이동 → 복합 순서 → 페이드/회전 → 크기/색상
```

## 요약
- 애니메이션은 자연스러운 피드백과 더 나은 사용자 경험을 만든다.
- 이 모듈은 단순한 Animated API 사용에서 실제 UI 패턴까지 확장한다.
