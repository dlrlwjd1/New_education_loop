# Task Time - Task 3

## 개요
- 펼침 패널의 화살표가 열림·닫힘 상태에 따라 회전하도록 만든다.
- 제공된 `Task 3 Before` 코드를 수정하고 강의 해설과 비교한다.

## 내용
### 과제 요구사항
- 패널을 열면 아래쪽 화살표가 위쪽을 향하도록 회전한다.
- 패널을 닫으면 화살표가 다시 원래 방향으로 돌아온다.

### 강의 해설
- `useRef`로 회전 애니메이션 값을 만든다.
- 펼쳐진 상태이면 목표값 `0`, 닫힌 상태이면 `1`을 사용하도록 `Animated.timing`을 구성한다.
- `0`과 `1`을 `0deg`와 `180deg`에 매핑하고 duration은 `300ms`로 설정한다.
- 화살표 Text를 `Animated.Text`로 바꾸고 rotate transform을 적용한다.

## 예시
```text
닫힘: 0deg ↓
열림: 180deg ↑
전환 시간: 300ms
```

## 요약
- UI 상태와 애니메이션 목표값을 연결해 화살표 방향으로 펼침 여부를 표현한다.
- 다음 강의에서는 패널 내용 자체의 크기도 애니메이션한다.
