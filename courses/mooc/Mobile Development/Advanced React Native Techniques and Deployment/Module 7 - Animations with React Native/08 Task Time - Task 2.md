# Task Time - Task 2

## 개요
- 태양 이미지는 페이드 인하고 로고는 왼쪽에서 들어오는 복합 인트로 화면을 만든다.
- 앞에서 배운 이동과 투명도 애니메이션을 동시에 적용한다.

## 내용
### 과제 요구사항
- 제공된 소스 코드의 이미지 리소스를 사용한다.
- 태양의 초기 opacity를 `0`으로 두고 `1`로 변경한다.
- 로고의 초기 `translateX`를 화면 왼쪽 밖에 두고 중앙으로 이동시킨다.
- 두 애니메이션은 마운트 2초 뒤 시작하며 각각 약 1.5초 동안 실행된다.

## 예시
```text
2초 대기
├─ 태양: opacity 0 → 1
└─ 로고: translateX 음수 → 0
```

## 요약
- 하나의 화면에서 페이드와 이동 애니메이션을 함께 실행한다.
- 초기값, 지연 시간, 목표값을 분리해 원하는 인트로 연출을 만든다.
