# Statements

## 개요
- JavaScript 문장이 기본적으로 위에서 아래로 순차 실행되는 방식을 이해한다.
- 변수 재할당 전후의 출력값으로 실행 순서의 영향을 확인한다.

## 내용
### 순차 실행
- 동기 JavaScript 코드는 작성된 순서대로 한 줄씩 실행된다.
- 로그의 위치를 바꾸면 출력 순서도 달라진다.
- 변수는 재할당 문장이 실행된 시점부터 새 값을 가진다.

## 예시
```js
let x = 5;
console.log(x); // 5

x = 10;
console.log(x); // 10

console.log(1);
console.log(2);
console.log(3);
```

## 요약
- 기본 실행 흐름은 소스 코드의 위에서 아래 방향이다.
- 같은 변수도 어느 문장 전에 읽는지에 따라 값이 달라진다.
