# Logging

## 개요
- 온라인 JavaScript 편집기에서 `console.log`로 첫 코드를 실행한다.
- 콘솔이 값과 계산 결과를 확인하는 개발 도구임을 이해한다.

## 내용
### console.log
- `console`은 브라우저 등이 제공하는 개발 도구 객체다.
- `log` 메서드는 전달된 메시지나 값을 콘솔에 출력한다.
- 문자열, 숫자, 산술식 결과를 출력해 코드의 동작을 확인할 수 있다.

## 예시
```js
console.log('Hello world');
console.log(1);
console.log(5 + 5); // 10
```

## 요약
- `console.log`는 코드의 값과 실행 결과를 확인하는 기본 도구다.
- 문자열과 표현식을 전달하면 평가된 결과가 콘솔에 표시된다.
