# Variables Rules

## 개요
- 변수(variable)가 값을 저장하는 이름 있는 컨테이너임을 이해한다.
- 변수 선언의 구성 요소와 유효한 변수 이름 규칙을 배운다.

## 내용
### 변수 선언 구성
- 변수 키워드: `var`, `let`, `const` 중 하나를 사용한다.
- 변수 이름: 저장된 값을 다시 참조할 식별자다.
- 할당 연산자 `=` 오른쪽의 값을 왼쪽 변수에 저장한다.

### 이름 규칙
- 숫자로 시작할 수 없다.
- `if`, `switch`, `else` 같은 예약어를 사용할 수 없다.
- 이름 안에 공백을 넣을 수 없다.
- 특수 문자 중에서는 `_`와 `$`를 사용할 수 있다.

## 예시
```js
let number = 5;
const myAge = 27;
let user_1 = 'Hero';

console.log(5 + number); // 10
```

## 요약
- 변수 선언은 키워드, 이름, 할당 연산자, 값으로 구성된다.
- 숫자 시작·예약어·공백·허용되지 않은 특수 문자를 피한다.
