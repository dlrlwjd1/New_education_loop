# Comparison

## 개요
- 동등·부등·대소 비교 연산자를 배운다.
- 느슨한 동등 비교와 엄격한 동등 비교의 차이를 이해한다.

## 내용
### 동등 비교
- `==`는 타입 변환을 허용하며 값을 비교한다.
- `===`는 값과 타입이 모두 같은지 비교한다.
- `!=`와 `!==`는 각각 느슨한 부등, 엄격한 부등 비교다.

### 대소 비교
- `>`, `<`는 크고 작음을 비교한다.
- `>=`, `<=`는 같은 경우도 참으로 포함한다.

## 예시
```js
console.log(5 == '5');   // true
console.log(5 === '5');  // false
console.log(5 != '5');   // false
console.log(5 !== '5');  // true
console.log(5 >= 5);     // true
console.log(4 < 5);      // true
```

## 요약
- 엄격한 비교 `===`와 `!==`는 값과 타입을 함께 검사한다.
- 대소 비교에는 `>`, `<`, `>=`, `<=`를 사용한다.
