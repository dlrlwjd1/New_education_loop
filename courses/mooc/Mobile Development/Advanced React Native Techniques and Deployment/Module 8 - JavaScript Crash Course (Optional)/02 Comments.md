# Comments

## 개요
- JavaScript 코드에 설명이나 TODO를 기록하는 주석(comment)을 배운다.
- 한 줄 주석과 여러 줄 주석의 문법을 구분한다.

## 내용
### 주석의 용도
- 코드의 의도를 설명해 가독성을 높인다.
- 할 일이나 주의사항을 기록한다.
- 특정 코드를 임시로 실행하지 않게 만들 수도 있다.

### 문법
- `//` 뒤의 내용은 한 줄 주석이다.
- `/*`와 `*/` 사이의 내용은 여러 줄 주석이다.
- 주석은 JavaScript 코드로 실행되지 않는다.

## 예시
```js
// 한 줄 주석
console.log('실행됨');

/*
  TODO: 작업 1 완료
  TODO: 작업 2 완료
*/
// console.log('실행되지 않음');
```

## 요약
- `//`는 한 줄, `/* ... */`는 여러 줄 주석이다.
- 주석은 설명과 임시 실행 차단에 사용한다.
