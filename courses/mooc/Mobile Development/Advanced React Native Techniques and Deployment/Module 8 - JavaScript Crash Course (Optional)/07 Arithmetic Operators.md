# Arithmetic Operators

## 개요
- 숫자에 사용하는 주요 산술 연산자를 배운다.
- 덧셈·뺄셈·곱셈·나눗셈·나머지와 증가·감소 연산을 실행한다.

## 내용
### 주요 연산자
- `+`: 덧셈, `-`: 뺄셈, `*`: 곱셈, `/`: 나눗셈이다.
- `%`는 나눗셈의 나머지를 반환한다.
- `++`는 변수 값을 1 증가시키고 `--`는 1 감소시킨다.
- 따옴표로 감싼 숫자는 문자열이므로 숫자 연산 예제에서는 따옴표를 사용하지 않는다.

## 예시
```js
let x = 7;
const y = 3;

console.log(x + y); // 10
console.log(x - y); // 4
console.log(x * y); // 21
console.log(x / y); // 2.333...
console.log(x % y); // 1
x++;
console.log(x);     // 8
```

## 요약
- 산술 연산자는 숫자를 계산하고 나머지나 증감 결과를 만든다.
- 연산 전 피연산자의 타입이 숫자인지 확인한다.
