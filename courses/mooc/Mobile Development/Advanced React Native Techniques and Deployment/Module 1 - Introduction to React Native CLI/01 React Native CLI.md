# React Native CLI

## 개요
- 취업이 목표라면 React Native CLI를 반드시 배워야 한다 — 대부분의 회사가 Expo보다 React Native CLI를 선호한다.
- 강사의 경험상 근무한 5개 회사 중 4곳이 React Native CLI를 사용했고, 프리랜싱 프로젝트도 모두 CLI 기반이었다.
- CLI는 네이티브 코드 접근성, 성능, 앱 크기 면에서 Expo보다 유리하다.

## 내용
### 회사들이 React Native CLI를 선호하는 이유
- **네이티브 코드(native code) 완전 접근**: Android와 iOS의 네이티브 코드에 직접 접근할 수 있어 서드파티 라이브러리(third-party library)와 커스텀 네이티브 모듈(custom native module) 통합이 더 쉽다.
- **성능(performance)**: React Native CLI가 Expo보다 성능이 더 좋다.
- **앱 크기(app size)**: Expo에 비해 더 작은 앱 크기를 만들 수 있다.

### Expo를 쓰면 좋은 경우
- 작은 프로젝트나 빠른 개발(fast development)이 필요할 때
- 비즈니스 오너로서 빠르게 앱을 배포하고 싶을 때

### 다음 강의 예고
- Expo와 React Native CLI는 공유하는 부분이 많아, 이전 섹션(Expo)에서 배운 내용을 거의 그대로 CLI에서도 구현할 수 있으며 약간의 차이만 존재한다.

## 요약
- 대부분의 회사는 Expo보다 React Native CLI를 사용하므로 취업을 위해서는 CLI 학습이 필수다.
- CLI의 장점: 네이티브 코드 완전 접근, 쉬운 서드파티/네이티브 모듈 통합, 더 나은 성능, 더 작은 앱 크기.
- Expo는 소규모 프로젝트나 빠른 배포가 필요한 경우에 적합하다.
