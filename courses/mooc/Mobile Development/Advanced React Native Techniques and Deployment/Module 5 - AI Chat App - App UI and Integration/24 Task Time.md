# Task Time

## 개요
- 제공된 리소스를 사용해 AI 채팅 앱의 아이콘과 스플래시 화면을 교체하는 실습 과제다.
- Android와 iOS의 앱 아이콘, 스플래시 이미지, 앱 내부 아이콘을 새 디자인으로 통일한다.
- 이전 모듈에서 배운 플랫폼별 아이콘·스플래시 변경 절차를 직접 적용한다.

## 내용
### 제공 리소스
- 리소스 압축 파일을 풀어 과제용 이미지와 컴포넌트를 확인한다.
- 앱 아이콘용 1024px PNG 이미지가 제공된다.
- 스플래시 화면용 아이콘 이미지와 앱 코드에서 사용할 `Icon.tsx`도 제공된다.

### 과제 범위
- 기존 Android 앱 아이콘을 새 AI 채팅 앱 아이콘으로 교체한다.
- 기존 iOS 앱 아이콘도 같은 디자인으로 교체한다.
- Android·iOS 스플래시 화면의 이미지를 새 리소스로 바꾼다.
- 앱 화면 내부에서 사용 중인 아이콘을 제공된 `Icon.tsx`로 변경한다.

## 예시
```text
완료 확인 목록
[ ] Android 앱 아이콘 교체
[ ] iOS 앱 아이콘 교체
[ ] Android/iOS 스플래시 이미지 교체
[ ] 앱 내부 아이콘 컴포넌트 교체
```

## 요약
- 제공된 세 가지 리소스를 사용해 앱의 시각적 정체성을 통일한다.
- 플랫폼별 앱 아이콘과 스플래시 화면을 모두 변경한다.
- 이전 강의에서 배운 네이티브 리소스 변경 방법을 복습하는 독립 실습이다.
