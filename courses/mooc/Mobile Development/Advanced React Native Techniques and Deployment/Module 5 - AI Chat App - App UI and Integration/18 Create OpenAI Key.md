# Create OpenAI Key

## 개요
- OpenAI Platform 계정과 프로젝트를 만들고 API 키를 생성한다.
- OpenAI API 사용에는 결제 수단과 크레딧이 필요할 수 있음을 확인한다.
- API 키는 한 번 복사한 뒤 안전하게 보관하고 공개 저장소에 포함하지 않는다.

## 내용
### 계정과 프로젝트 생성
- OpenAI Platform에서 계정을 만들고 조직(organization)과 프로젝트 이름을 지정한다.
- 프로젝트 안에서 새 API 키의 이름을 정하고 키를 생성한다.
- 강의에서는 SDK 대신 직접 HTTP 요청을 만드는 방식을 사용한다.

### 결제와 사용량
- 강의 시점의 OpenAI API는 무료 Hugging Face 예제와 달리 유료 사용을 전제로 한다.
- 결제 수단을 등록하고 크레딧을 구매한 뒤 대시보드의 Usage에서 사용량을 확인한다.
- 실제 결제 금액이나 화면은 계정·지역·시점에 따라 달라질 수 있으므로 강의의 금액은 절차 예시로 본다.

### 키 보안
- API 키는 비밀번호와 같은 비밀 정보다.
- 실제 키를 소스 코드, Git 기록, 노트, 로그에 남기지 않는다.
- 키가 노출되면 폐기(revoke)하고 새 키를 생성해야 한다.

## 예시
```ts
// 실제 키 값은 공개 코드에 직접 작성하지 않는다.
const OPENAI_API_KEY = '<securely-loaded-token>';
```

## 요약
- OpenAI Platform의 프로젝트에서 API 키를 생성한다.
- API 호출 전에 계정의 결제·크레딧 상태를 준비하고 Usage에서 사용량을 확인한다.
- API 키는 공개하지 않고 안전한 설정 경로로 주입한다.
