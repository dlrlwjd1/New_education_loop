# Create Hugging Face Access Token

## 개요
- 정적 응답을 실제 AI 응답으로 바꾸기 위해 Hugging Face 계정에서 액세스 토큰을 만든다.
- 강의에서는 무료로 시험할 수 있는 Hugging Face 모델을 먼저 사용한 뒤 OpenAI API를 연결한다.
- 생성된 토큰은 한 번만 표시될 수 있으므로 안전하게 보관해야 한다.

## 내용
### Hugging Face 선택 이유
- OpenAI API를 연결하기 전에 Hugging Face의 모델로 HTTP 요청 흐름을 시험한다.
- 강의에서는 텍스트 생성 모델인 GPT-2를 예로 사용한다.
- 무료 모델은 응답 품질이나 로딩 가능한 모델 크기에 제약이 있을 수 있다.

### 토큰 생성 절차
- Hugging Face 계정을 만든 뒤 프로필 메뉴의 `Settings`로 이동한다.
- `Access Tokens`에서 새 토큰을 만들고 이름과 필요한 추론(inference) 권한을 지정한다.
- 생성 직후 토큰을 복사해 안전한 위치에 보관한다.

### 보안 주의
- 액세스 토큰은 인증 정보이므로 문서, 공개 저장소, 화면 캡처에 포함하지 않는다.
- 다음 강의에서는 예제를 위해 코드에 임시로 넣지만, 강의도 이후 환경 파일로 옮기고 저장소에 게시하지 말 것을 강조한다.

## 예시
```ts
// 실제 토큰 값은 저장소에 커밋하지 않는다.
const HUGGING_FACE_TOKEN = '<securely-loaded-token>';
```

## 요약
- Hugging Face 액세스 토큰은 추론 API 요청의 인증에 사용한다.
- 강의에서는 GPT-2로 API 연결을 먼저 시험한다.
- 토큰은 비밀 정보로 취급하고 공개 코드나 학습 노트에 실제 값을 기록하지 않는다.
