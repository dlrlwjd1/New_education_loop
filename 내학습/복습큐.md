# 복습큐

틀린 것만 들어온다. 맞은 것은 넣지 않는다.

복습 간격: **1일 → 3일 → 7일 → 16일 → 35일**
복습해서 맞히면 다음 칸으로, 틀리면 1일로 되돌린다.
**5회차(35일 간격)에서 맞히면 이 표에서 빼고 아래 "마스터 완료" 표로 옮긴다.**

| 항목 | 주제 | 처음 틀린 날 | 다음 복습일 | 상태 |
|---|---|---|---|---|
| TCP 3-way handshake가 왜 3번인가 | 네트워크 서비스 Phase 1 | 2026-09-14 | 2026-09-19 | 2회차 |
| 사설 IP가 공인 IP로 바뀌는 지점(NAT) | 네트워크 서비스 Phase 1 | 2026-09-14 | 2026-09-15 | 1회차 |
| DevOps 파이프라인 5단계 순서 | 데브옵스 Phase 1 | 2026-09-15 | 2026-09-19 | 2회차 |
| 표현 계층(Presentation Layer)의 보안 역할 (SQL 인젝션 방어와 혼동) | 네트워크 서비스 Phase 1 1-A (OSI Model) | 2026-09-17 | 2026-09-18 | 1회차 |
| OSI 세션 계층 vs HTTP 쿠키/세션 (다른 개념인데 혼동) | 네트워크 서비스 Phase 1 1-A (OSI Model) | 2026-09-17 | 2026-09-18 | 1회차 |
| SSL/TLS = 인증서 핸드셰이크 + 암호화는 한 흐름 (별개 기술로 오해, SSH와도 혼동) | 네트워크 서비스 Phase 1 1-A (Securing Layers) | 2026-09-17 | 2026-09-18 | 1회차 |
