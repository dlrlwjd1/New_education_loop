## 1. 이걸로 뭘 하나

1주차에 배운 다섯 전략 — 인출 연습 · 간격 반복 · 인터리빙 · 청킹 · 정교화 — 이
여기서는 **말이 아니라 실행되는 절차**로 들어 있습니다.

`/study` 라고 치면 AI가 **여러분에게 질문을 시작합니다.** 답을 주는 게 아니라요.
여러분이 답하면 채점하고, 틀린 건 복습큐에 쌓입니다. 다음에 켤 때 그게 다시 나옵니다.

## 2. 5분 안에 시작하기

### ① 내 GitHub에 올린다

압축을 풀고, **한글과 공백이 없는 경로**에 두세요.

```
macOS     ~/dev/netsvc
Windows   C:\dev\netsvc
```

```bash
cd ~/dev/netsvc
git init
git add -A
git commit -m "학습 시스템 시작"
```

그리고 GitHub에서 **비공개(Private) 저장소**를 새로 만들고 연결합니다.

```bash
git remote add origin https://github.com/{내아이디}/{저장소이름}.git
git branch -M main
git push -u origin main
```

> **왜 올리나** — 학기 끝까지 여기에 뭐가 쌓였는지가 여러분의 제출물입니다.
> 노트북이 죽어도 살아남아야 하고, 언제 무엇을 했는지가 커밋에 남습니다.

## 5. 읽고 시작하기 전에 — 이게 제일 중요합니다

1주차 마지막에 이런 말을 했습니다.

> **정교화는 재료가 없으면 작동하지 않고, AI는 재료 없이도 답을 줍니다.**

모르는 주제에 "왜?"를 던지면, 사람은 침묵하지 않고 **소설을 씁니다.**
그리고 **AI는 그 소설을 아주 매끄러운 문장으로 대신 써 줍니다.**
읽으면 이해한 것 같습니다. 그게 유창성의 착각입니다.

그래서 이 시스템의 스킬은 **답을 먼저 주지 않게** 만들어져 있습니다.
질문부터 하고, 여러분이 답한 뒤에만 채점합니다. 불편하면 제대로 작동하고 있는 겁니다.

**첫 바퀴를 이미 아는 과목으로 도는 이유도 같습니다.**
AI가 틀린 말을 유창하게 할 때, 그걸 잡아낼 수 있는 건 그 주제를 아는 사람뿐입니다.
아는 과목에서 AI가 틀리는 걸 한 번 잡아 봐야, 모르는 과목에서 조심하게 됩니다.

## 6. 매주 하는 것

1. `/study` 로 한 판 돈다
2. 틀린 게 `내학습/복습큐.md` 에 쌓인다
3. 커밋하고 푸시한다

```bash
git add -A && git commit -m "학습: {오늘 한 것}" && git push
```
