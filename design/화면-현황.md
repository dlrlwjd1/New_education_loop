## 로드맵 만들기 흐름 변경 — 명세서와 동기화 완료

`Roadmap.dc.html`은 **자료 넣기(URL·파일) → 로드맵 만들기 시작** 두 단계로만 사용자에게 노출된다. 목표를 먼저 한 문장으로 적는 입력은 폼 안의 "자료 없이 목표만 적을게요" 보조 경로로 남아 있다.

이전 버전의 이 문서는 이걸 "로컬 HTML 시안과 캔버스가 다르다"는 시안 간 불일치로만 기록했지만, 실제로는 `웹전환_기능명세_및_개발가이드.md` F08(로드맵 생성 순서 = 목표 → 필요 지식 → 사용자 검토 → 의존 관계 → 자료 연결)과 어긋나는 **정책 불일치**였다. 논의 후 명세서 쪽을 캔버스 흐름에 맞춰 갱신했다 — F08은 이제 자료 입력을 1단계 기본 경로로, 목표 직접 입력을 보조 경로로 기술한다. 자세한 내용은 `웹전환_기능명세_및_개발가이드.md` F08과 8.1(또는 해당 개정 각주)을 참고.

### 진행바(1~5단계) 제거 → 생성 중 화면으로 교체

화면 상단에 "1 자료 넣기 · 2 필요한 지식 · 3 Phase 구성 · 4 자료 연결 · 5 최종 검토" 5단계를 나열한 진행바(`wizard-steps`)가 있었는데, 실제로는 1단계 화면만 있고 2~5단계 화면은 아예 없어서 "자료 넣기" 이후 바로 학습실로 건너뛰었다 — 진행바가 약속한 것과 실제 화면이 어긋나는 문제였다(`사용흐름-리뷰.md`에서 발견).

진행바를 없애고 **생성 중 화면**으로 바꿨다. `Roadmap.dc.html`은 이제 3단계 상태를 오간다(`DCLogic` 컴포넌트로 구현, 버튼으로 전환):

1. **자료 입력** — 기존 폼 그대로. "이 내용으로 로드맵 만들기"를 누르면 다음 단계로.
2. **생성 중** — 퍼센트(예시: 68%)와 진행 바, "필요한 지식 정리 → Phase 구성 → 자료 연결"을 한 문장으로 설명. 필요한 지식·Phase·자료 연결을 화면 3개로 쪼개 사용자에게 하나씩 확인시키는 대신, AI가 처리하는 동안이라는 것만 보여준다. (데모용 "완료 상태 미리보기" 버튼으로 다음 단계 확인 가능)
3. **완료** — 체크 표시와 "N개 Phase · N개 항목으로 정리했어요" 요약, "로드맵 확인하기"(`#roadmap-overview`)·"바로 학습 시작"(`#study`) 버튼.

이 방식은 F08의 "필요한 지식 → Phase 구성 → 자료 연결"을 사용자가 일일이 승인하는 절차에서, AI가 처리하고 결과만 보고하는 쪽으로 방향을 바꾼 것이다. "생성 중간에 검토·승인 화면이 없으면 마음에 안 드는 결과는 어떻게 고치나"라는 질문에는 **"로드맵 수정(`RoadmapEdit`)에서 고친다"**로 정리했다 — 생성은 확인 없이 끝까지 진행하고, 교정은 그 이후 F08의 수정 절차 하나로 처리한다. F08 문서도 이 결정에 맞춰 갱신했다.

## 사용 흐름 점검

`AI 학습실` 진입에 "무엇을 공부할지 고르는" 화면이 없다는 지적을 계기로 전체 화면의 실제 링크·버튼 연결을 감사했다. 발견한 문제와 조치 내역은 [`사용흐름-리뷰.md`](사용흐름-리뷰.md)에 근거와 함께 정리했다. 요약:

- 모든 화면의 사이드바 "AI 학습실"이 예외 없이 이미 완료된 특정 대화로 직행하던 문제 → `StudyLaunch.dc.html` 신설, 대상이 정해지지 않은 진입만 재배선.
- `RoadmapOverview`의 "수정" 버튼, `RoadmapEdit`의 "취소" 버튼 등 실제로 존재하는 화면과 연결되지 않고 방치된 버튼 다수 → 실제 링크로 교체.
- 이미 만들어진 화면(`#study-history`, `#review-queue`, `#roadmap` 등)으로 갈 수 있었는데 안내 문구만 뜨던 버튼들 → 실제 링크로 교체.
- 여전히 화면 자체가 없어 안내 문구로 남겨둔 것과, 실제로 갈 곳이 있어 링크로 바꾼 것을 구분한 기준도 리뷰 문서에 근거로 남겼다.

## 남은 과제

- **자료실**의 실제 검색·색인, 본문 렌더링은 이 시안에서 다루지 않는다. 자료 연결 후 F09 상세 요구사항을 따른다.
- **학습 기록**의 "상세보기"는 세션의 질문·답변·판정 원문을 보여주는 화면으로 아직 이어지지 않는다. F10 참고.
- **브리핑 기록**의 "상세보기"도 마찬가지로 날짜별 상세 화면은 아직 없다.
- **로드맵 수정**은 diff 화면까지만 있고, 실제 반영 후 버전 번호 증가·이전 버전 열람 화면은 없다.
- **로드맵 만들기**의 "자료 없이 목표만 적을게요" 보조 경로는 아직 실제 입력 폼으로 전환되지 않는다(안내 문구만 표시).
- 내비게이션에 화면이 늘어난 만큼(WORKSPACE 6개 + RECORDS 2개 + 설정) 실제 정보구조·모바일 하단 내비게이션 재배치가 필요할 수 있다.
