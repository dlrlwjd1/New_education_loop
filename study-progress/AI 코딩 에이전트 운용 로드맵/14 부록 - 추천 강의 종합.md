## 최소 세트 — 이것만 등록하면 된다

**MOOC Plus 4개, 추가 결제 없음.** 순서대로 등록한다.

1. **Mastering Claude Code** — Phase 1·2·4. 저장소의 Antigravity 강좌와 **같은 전문과정의 자매 코스**라 구성이 똑같고, 이쪽이 2026-05로 한 달 더 최신이다. `Rules & Memories` → `Agent Skills` 모듈이 도착점과 정확히 맞는다
2. **Claude Code (Vanderbilt)** — Phase 7. **이 로드맵 최대 공백을 메우는 강좌.** Module 4에 git worktree 병렬 개발이 통째로 들어 있다
3. **GitHub: Governing AI-Generated Code** — Phase 5. 저장소 자료가 실물 위주라 "검증을 제도로 만드는 법"이 비어 있다
4. **AI Security Fundamentals (OWASP 2026)** — Phase 6. LLM06 Excessive Agency가 이 Phase의 정확한 주제다

MCP 서버를 직접 만들 생각이면 **Anthropic 공식 2강좌**를 추가한다(역시 Plus 포함).

## MCP 강좌의 사양 문제 ⚠️

**Anthropic 공식 강좌 2개가 이미 뒤처져 있다.** 두 강좌 모두 sampling·roots·transports를 가르치는데, **현행 개정판(2026-07-28)에서 roots·sampling·logging은 전부 deprecated**다. 게다가 두 강좌 어디에도 elicitation과 OAuth 인가가 나오지 않는데, 인가는 현행 사양에서 PKCE S256과 RFC8707 `resource` 파라미터를 필수로 요구한다.

Udemy 쪽도 마찬가지다 — MCP Bootcamp는 SSE와 Streamable HTTP를 **둘 다** 가르치는데 SSE는 폐기된 전송이다.

> **결론: 개념은 강좌로, 사양은 [modelcontextprotocol.io/specification/latest](https://modelcontextprotocol.io/specification/latest)로 본다.** MCP 서버를 실제로 만들 거면 강좌를 보고 나서 현행 changelog를 반드시 대조한다.

## worktree 병렬 실습은 강좌가 없다

2026-09-10 기준으로 **"에이전트 3개를 worktree에 격리해 동시에 굴리고 머지 충돌을 처리한다"를 한 시간 이상 다루는 강좌가 Udemy·MOOC 어디에도 없다.** worktree를 언급하는 Udemy 강좌 4개는 전부 1~2강 10분 안팎이다.

Vanderbilt 강좌의 Module 4가 현재 최선이고, 나머지는 [Phase 7](07%20Phase%207%20-%20병렬로%20굴린다.md)의 산출물 과제로 채운다.

## 새 강의를 추가할 때

`AGENTS.md`의 플랫폼별 폴더 규칙을 따른다.

- MOOC 강좌 → `courses/mooc/AI Agents and Generative AI/{코스명}/Module N - {모듈명}/`
- Udemy 강좌 → `courses/udemy/{코스명}/Section N - {섹션명}/`
- 새 MOOC 코스를 추가하면 `courses/mooc/index.md`에도 항목을 추가한다

정리를 마치면 해당 Phase 문서의 「추천 강의 (미확보)」 절을 **실제 체크리스트로 교체**하고, 이 표의 상태 칸과 [README](README.md)의 진행 현황을 함께 갱신한다.
