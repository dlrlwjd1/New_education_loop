## 이 로드맵이 쓰지 않는 관련 자료

주제상 가까워 보이지만 뺀 것들. 왜 뺐는지 적어 둔다.

- `Mastering Google Antigravity` · `Liftoff with Google Antigravity` — **특정 IDE 사용법**이다. Phase 8의 코드 생산 수단은 도구 중립적으로 두는 편이 낫다. Antigravity를 쓰기로 정했다면 Module 5(규칙·워크플로)와 Module 6(에이전트 스킬)만 Phase 4·8에 보태 본다.
- `Accelerate Your Learning with ChatGPT` · `Better Learning` · `Learning How to Learn` — 학습법 주제. **AI 학습법 로드맵**이 다룬다.
- `AI Prompting for Everyone` · `ChatGPT Prompt Engineering for Developers` — 프롬프트 기본기. Phase 3의 CrewAI M2가 **에이전트 맥락에서** 같은 내용을 다뤄 그쪽을 골랐다. 프롬프트 자체가 약하다고 느끼면 이 둘로 보충한다.
- `AI Agents in LangGraph` · `Build Interactive Agents with Generative UI` — LangGraph 전용, 생성형 UI 전용. Phase 5에서 LangGraph를 고르거나 사용자 화면이 필요해지면 돌아온다.
- `Deep Learning Specialization` · `MLOps` 카테고리 전체 — 모델을 만드는 쪽. **MLOps 로드맵**이 다룬다.
- `Monitoring and Observability for Development and DevOps` · Master DevOps 나머지 — 운영 인프라를 제대로 세우는 쪽. **개발운영 로드맵**·[데브옵스 로드맵](../데브옵스%20로드맵/)이 다룬다.
- `Digital Product Management` · PM 로드맵 대상 강좌들 — 문제 발견·검증. [PM 로드맵](../PM%20로드맵/)이 다룬다.
- `2026 Instagram Marketing` — 고객 확보. **마케팅 로드맵**이 다룬다.
- `Complete Guide to Elasticsearch` — 검색 엔진 자체. Phase 4는 벡터·하이브리드 검색만 다룬다. 사내 검색을 Elasticsearch로 세울 거라면 여기가 보충 자료다.
- `Microservices with Node JS and React` · `Fundamentals of NestJS` — 서비스 아키텍처. 에이전트를 붙일 백엔드를 새로 짤 때 참고.
- `Protecting and Managing APIs` — API 보안·게이트웨이. 사내 MCP 서버를 여러 팀에 열 때 보충 자료.
- `Generative AI for Product Managers` C1·C2·C4 — Phase 1·2·10과 겹치거나 PM 로드맵 영역이다. C3의 일부 강의만 골라 썼다.
