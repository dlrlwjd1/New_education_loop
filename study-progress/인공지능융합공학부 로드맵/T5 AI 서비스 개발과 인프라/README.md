# T5 — AI 서비스 개발과 인프라

학부 교과 **인공지능웹개발기초(2-1) · 자바스크립트(2-1) · 인공지능앱개발(2-2) · 서버프로그래밍(3-1) · 네트워크서비스(3-2) · 클라우드AI응용(4-1)** 을 담는 트랙이다.
[T3](../T3%20%EB%A8%B8%EC%8B%A0%EB%9F%AC%EB%8B%9D%EA%B3%BC%20%EB%94%A5%EB%9F%AC%EB%8B%9D/README.md)·[T4](../T4%20%EC%9D%91%EC%9A%A9%20AI%20%EC%96%B8%EC%96%B4%20%EC%8B%9C%EA%B0%81%20%EB%A1%9C%EB%B4%87/README.md)에서 만든 모델을 **사람이 쓸 수 있는 물건으로 바꾸는** 트랙이다.

- 상위 로드맵: [인공지능융합공학부 로드맵](../README.md)
- 도착점 기여: 캡스톤 서비스의 **화면·API·배포**를 전부 직접 만든다
- 분량: 약 110시간

## 뼈대가 되는 강좌

1. **[Meta Front-End Developer](../../../courses/mooc/Web%20and%20APIs/Meta%20Front-End%20Developer/README.md)** (MOOC · 9강좌 245강) — Phase 1의 메인. HTML·CSS·JavaScript·React를 한 흐름으로 간다.
2. **[RESTful Microservices Using Node.js and Express](../../../courses/mooc/Web%20and%20APIs/RESTful%20Microservices%20Using%20Node.js%20and%20Express/README.md)** — Phase 2의 메인. 서버사이드 JS·REST·SQL/NoSQL 연동·마이크로서비스.
3. **[Mastering NestJS](../../../courses/mooc/Web%20and%20APIs/Mastering%20NestJS/README.md)** (12모듈) — Phase 2의 심화. 구조화된 서버 프레임워크로 인증·DB까지.
4. **[React Native](../../../courses/mooc/Mobile%20Development/React%20Native/README.md)** 외 2강좌 — Phase 3.
5. **[The Bits and Bytes of Computer Networking](../../../courses/mooc/Computer%20Science%20Fundamentals/The%20Bits%20and%20Bytes%20of%20Computer%20Networking/README.md)** — Phase 4의 메인.
6. **[NAVER Cloud Platform Boot Camp](../../../courses/udemy/NAVER%20Cloud%20Platform%20Boot%20Camp%20-%20%EB%84%A4%EC%9D%B4%EB%B2%84%20%ED%81%B4%EB%9D%BC%EC%9A%B0%EB%93%9C%20%EB%B6%80%ED%8A%B8%20%EC%BA%A0%ED%94%84/README.md)** · **[MLOps Platforms - Amazon SageMaker and Azure ML](../../../courses/mooc/MLOps/MLOps%20Platforms%20-%20Amazon%20SageMaker%20and%20Azure%20ML/README.md)** — Phase 5.
