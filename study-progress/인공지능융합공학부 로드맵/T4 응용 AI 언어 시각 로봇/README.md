# T4 — 응용 AI (언어 · 시각 · 로봇)

학부 교과 **자연어처리 I·II(3-1·3-2) · 컴퓨터비전(3-1) · 컴퓨터비전응용(3-2) · 지능형로봇시스템(3-2)** 을 담는 트랙이다.
[T3](../T3%20%EB%A8%B8%EC%8B%A0%EB%9F%AC%EB%8B%9D%EA%B3%BC%20%EB%94%A5%EB%9F%AC%EB%8B%9D/README.md)에서 만든 신경망을 **어떤 데이터에 붙이느냐**로 갈라지는 자리다.

- 상위 로드맵: [인공지능융합공학부 로드맵](../README.md)
- 선행: T3 Phase 3(신경망) — 강남대 커리큘럼도 신경망을 자연어처리 I·컴퓨터비전의 선이수로 지정한다
- 도착점 기여: 캡스톤에 넣을 **모델의 종류를 고르고 직접 학습시킨다**
- 분량: 약 90시간

## 뼈대가 되는 강좌

1. **[Deep Learning Specialization](../../../courses/deeplearning-ai/Deep%20Learning%20Specialization/README.md)** — `04 Convolutional Neural Networks`가 Phase 3·4, `05 Sequence Models`가 Phase 1·2의 메인.
2. **[Retrieval Augmented Generation](../../../courses/deeplearning-ai/Retrieval%20Augmented%20Generation/README.md)** (DeepLearning.AI · 5모듈) — Phase 2의 메인. 학부 교과목해설의 "질의응답·텍스트 요약"에 해당하는 현대적 구현이다.
3. **[MLOps Tools - MLflow and Hugging Face](../../../courses/mooc/MLOps/MLOps%20Tools%20-%20MLflow%20and%20Hugging%20Face/README.md)** — Phase 2의 실습 축. 사전학습 모델을 가져다 쓰는 법.
4. **[The Complete Agentic AI Engineering Masterclass (2026)](../../../courses/udemy/The%20Complete%20Agentic%20AI%20Engineering%20Masterclass%20%282026%29/README.md)** (Udemy) — Phase 2의 보조. LLM 내부·파인튜닝 vs RAG·Hugging Face 생태계.
5. **ROS 2 · Modern Robotics 계열** — Phase 5. 자세한 목록은 Phase 5 문서 참조.

## 중복 안내 — 로보틱스 로드맵과 겹친다

Phase 5(지능형로봇시스템)가 참조하는 강의는 대부분 **로보틱스 로드맵**이 이미 다룬다. 이 로드맵은 **학부 한 과목 분량으로 압축한 자체 체크박스**를 둔다 — 한쪽에서 이미 봤다면 다른 쪽에도 학습일을 옮겨 적는다.
