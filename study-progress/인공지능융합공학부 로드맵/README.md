# 인공지능융합공학부 학습 로드맵 — 4년 커리큘럼을 온라인 강의로 완주한다

강남대학교 **인공지능융합공학부 인공지능전공**의 2026학년도 교육과정표와 [교과목해설 페이지](https://ace.kangnam.ac.kr/menu/e185812b4c8ebfe6d90a1e3f35587ef6.do)를 원본으로, **전공 27개 과목을 저장소의 온라인 강의로 대체 학습**하는 로드맵이다.

범위가 학부 4년치라 다른 로드맵과 달리 **로드맵 안에 로드맵을 두는 2단 구조**를 쓴다. 최상위는 지도 역할만 하고, 실제 Phase 체크리스트는 여섯 개 트랙 폴더 안에 있다.

- 작성일: 2026-09-04
- 웹 리서치 기준일: 2026-09-04
- 대상: 프로그래밍 경험은 있으나 AI는 처음인 사람. 학부생·편입생·독학자 모두
- 원칙: 저장소 자료 우선. ⭐ **처음 6개였던 공백을 2026-09-04에 전부 해소했다.** 이제 **전공 27과목 모두 저장소 자료만으로 시작할 수 있다**
- 도착점: **직접 학습시킨 모델을 붙인 웹·모바일 AI 서비스를 클라우드에 배포하고 4주 이상 운영한다** (커리큘럼의 캡스톤디자인(AI) I·II 도착점과 동일)

## 트랙을 도는 순서

학부는 학기 단위로 여러 과목을 병행하지만, 혼자 공부할 때는 **한 트랙씩 끝내는 편이 낫다.** 다만 의존 관계는 지킨다.

```text
T1 (Phase 1~3)  ──┐
                  ├──→ T3 ──→ T4 ──┐
T2 (Phase 1~5)  ──┘                ├──→ T6
                                   │
T5 (Phase 1~2) ────────────────────┘
```

1. **T1 Phase 1~3** — 파이썬과 알고리즘. 여기가 없으면 아무것도 안 된다
2. **T2 전체** — 특히 Phase 4(인공지능수학)·Phase 5(회귀분석)는 T3의 선이수다
3. **T3 전체** — 이 로드맵의 심장
4. **T5 Phase 1~2** — 웹과 서버. T3와 병행해도 된다
5. **T4** — 관심 있는 응용 분야부터. 언어(Phase 1·2)·시각(3·4)·로봇(5)은 서로 독립이다
6. **T5 Phase 3~5** · **T1 Phase 4**
7. **T6** — Phase 5(캡스톤)는 나머지가 다 끝난 뒤다

## 주의 사항

- **각 트랙 Phase 문서의 체크리스트가 이 로드맵이 다루는 코스들의 진행 기록 원본이다.** 별도의 코스 단위 진행 기록 파일은 두지 않는다.
- **교육과정표는 수시 개편에 따라 변동될 수 있다** (PDF 원본 명시). 이 로드맵은 2026학년도 입학자 기준이다.
