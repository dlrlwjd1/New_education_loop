# T6 — 기획 · 통합 · 현장

학부 교과 **인공지능서비스기획(2-2) · 인공지능서비스개발 I·II(3-1·3-2) · 인공지능특론 I·II(4-1·4-2) · 캡스톤디자인(AI) I·II(4-1·4-2) · 현장실습 · 졸업종합평가** 를 담는 트랙이다.
앞의 다섯 트랙에서 만든 것들을 **하나의 서비스로 합치고 세상에 내놓는** 트랙이며, 이 로드맵의 도착점이 여기 있다.

- 상위 로드맵: [인공지능융합공학부 로드맵](../README.md)
- 선행: T1~T5. 특히 Phase 5(캡스톤)는 나머지 전부가 끝난 뒤다
- 도착점: **직접 학습시킨 모델을 붙인 웹·모바일 AI 서비스를 클라우드에 배포하고 운영한다**
- 분량: 약 95시간 + 캡스톤 프로젝트 시간
