# T6 Phase 2 — 인공지능 서비스 개발 I

> 학부 교과 **인공지능서비스개발 I(3학년 1학기, 이론실습병행 3학점)** · 선이수 = 인공지능서비스기획
> 교과목해설: "AI 기술을 활용한 서비스의 설계와 구현 방법을 배우며, 실제 프로젝트를 통해 AI 서비스의 요구 사항 분석, 설계, 개발 및 배포 과정을 경험하게 된다"

- 목표: [Phase 1](01%20Phase%201%20-%20%EC%9D%B8%EA%B3%B5%EC%A7%80%EB%8A%A5%20%EC%84%9C%EB%B9%84%EC%8A%A4%20%EA%B8%B0%ED%9A%8D.md)의 기획서를 **동작하는 v1**으로 바꾼다.
- 분량: 약 22시간
- 마지막 학습일: (미학습)

## 이 단계가 끝나면 할 수 있어야 하는 것

- 요구사항을 명세(spec)로 쓰고, 그 명세로 구현을 지시한다
- AI 코딩 에이전트를 도구로 써서 개발 속도를 올리되, **결과를 검수한다**
- 프론트·백엔드·모델을 하나의 서비스로 연결한다
- 모델 서빙의 형태(직접 서빙 / 관리형 / 외부 API)를 상황에 맞게 고른다
- 배포 파이프라인을 만들어 코드 변경이 자동으로 반영되게 한다
- 만든 것을 테스트하고 평가한다

## 산출물

**동작하는 AI 서비스 v1.** [T5](../T5%20AI%20%EC%84%9C%EB%B9%84%EC%8A%A4%20%EA%B0%9C%EB%B0%9C%EA%B3%BC%20%EC%9D%B8%ED%94%84%EB%9D%BC/README.md)에서 만든 화면·API·배포를 [Phase 1](01%20Phase%201%20-%20%EC%9D%B8%EA%B3%B5%EC%A7%80%EB%8A%A5%20%EC%84%9C%EB%B9%84%EC%8A%A4%20%EA%B8%B0%ED%9A%8D.md)의 기획서에 맞춰 하나로 합친다.

1. 명세 문서 → 구현 → 배포까지의 이력이 Git에 남아 있을 것
2. 사용자 한 명이 처음부터 끝까지 한 바퀴 도는 시나리오가 실제로 동작
3. 테스트 — 최소한 핵심 경로 하나에 통합 테스트
4. 배포 자동화 — `push` 하면 반영되는 구성
5. 사용자 3명에게 써 보게 하고 **막힌 지점을 기록**
