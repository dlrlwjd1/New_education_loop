## 강좌 탐색 결과

**세 항목 모두 MOOC·Udemy에서 전용 강좌를 확인하지 못했다.** 웹 검색으로 나온 것은 아래가 전부다.

| 공백 | 찾은 것 | 판단 |
|---|---|---|
| 마이그레이션 | LinkedIn Learning `Advanced SQL for Application Development`에 Liquibase를 다루는 **영상 한 편**이 있다 | 한 편 때문에 별도 구독을 하지 않는다. **원문 미열람** |
| 마이그레이션 | Flyway·Liquibase 공식 문서 | **이쪽이 낫다.** 도구 문서가 곧 교재인 종류의 주제다 |
| 데이터 계약 | 강좌 없음. 업계 정리 글만 있다 | 산출물 과제로 대체 |
| OBT vs 스타 | 강좌 없음. Fivetran·dataarchitect.studio 등의 비교 글 | 아티클 + 직접 벤치마크 |

## 사지 않아도 되는 것

| 강의 | 이유 |
|---|---|
| 일반 "데이터베이스 설계" 입문 강좌 전반 | **저장소에 이미 네 개가 있다.** Database Design - A Modern Approach · Relational Database Design · Illinois Tech · Meta `01` Module 4가 같은 범위를 서로 다른 깊이로 덮는다. 다섯 번째를 살 이유가 없다 |
| Kimball 차원 모델링 전문 교육 (DecisionWorks 등) | 오프라인 유료 교육이고, 이 로드맵의 분석계 비중에 비해 과하다. [Meta 07 Module 2](../../courses/mooc/Databases%20and%20SQL/Meta%20Database%20Engineer/07%20Advanced%20Data%20Modeling/Module%202%20-%20Data%20Warehousing)로 충분하다 |
| SQL 문법 강좌 | 이 로드맵은 SQL을 안다고 가정한다. 흔들리면 **DB 운영 안정화 10 부록**이 저장소 자료로 채워 준다 |
| 인덱스·성능 튜닝 강좌 | **DB 운영 안정화 로드맵**이 소유한다. 그쪽 **12 부록**에서 판단한다 |
