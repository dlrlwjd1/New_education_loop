## Meta Database Engineer 중 이 로드맵이 쓰지 않는 강좌

- `02 Version Control` — git. 설계와 무관하다. 다만 Phase 7의 "스키마도 코드처럼 버전 관리한다"의 배경 개념이라 개념만 빌린다.
- `03 Database Structures` Module 1·3 — SQL 문법과 저장 프로시저. **DB 운영 안정화 10 부록**이 다룬다.
- `04 Advanced MySQL Topics` — 인덱스·EXPLAIN·트랜잭션. **DB 운영 안정화 로드맵** Phase 2·3·5가 소유한다.
- `05 Programming in Python` · `06 Database Clients` — 애플리케이션 연결. Phase 7에서 개념만 스친다.
- `07 Advanced Data Modeling` Module 3 — Tableau 시각화. 분석 도구지 모델링이 아니다.
- `09 Coding Interview Preparation` — [인공지능융합공학부 로드맵 T1 P3](../인공지능융합공학부%20로드맵/T1%20프로그래밍%20기초와%20알고리즘/03%20Phase%203%20-%20그래프%20문자열과%20코딩테스트%20실전.md)이 소유한다.
