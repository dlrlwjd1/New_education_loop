# 스펙 주도 개발(Spec-Driven Development) 학습 로드맵

**이 저장소에 이미 정리된 강의 자료만으로** 코딩 에이전트에게 「명세(spec)를 넘겨 구현시키고, 결과를 검증하고, 그 워크플로 자체를 자동화하는」 상태까지 가는 순서를 정리했다.

- 작성일: 2026-08-06
- 대상: 코딩 에이전트를 쓰고는 있으나 매번 프롬프트로 즉흥 지시하고, 결과물의 품질이 들쭉날쭉한 상태
- 원칙: 새 강의를 사거나 외부 자료를 찾지 않고, [`courses/`](../../courses/) 안에 이미 정리된 노트로 완주한다.
- 도착점: **명세 → 구현 → 검증이 반복 가능한 루프가 되고, 그 루프의 상당 부분이 스킬·서브에이전트로 자동화된 상태**

## 시작 지점 — Phase 1은 개념 트랙이다

이 로드맵의 개념 트랙인 [Spec-Driven Development with Coding Agents](../../courses/deeplearning-ai/Spec-Driven%20Development%20with%20Coding%20Agents/) 15개 강의부터 시작한다. 대화정리본도 전부 있다.

개념을 잡고 나면 이 로드맵의 무게중심은 Phase 2부터다. **개념은 아는데 실제 프로젝트에 적용이 안 되는 구간**을 메우는 것이 목적이다.

- Phase 1은 복습용이다. 용어가 흐려졌을 때만 펼친다.
- Phase 2~6이 본체다. 「Coding with AI」의 실제 프로젝트(DevStash)를 따라가며 명세를 직접 쓴다.
- Phase 7~9는 워크플로를 자기 것으로 만드는 단계다.

## 뼈대가 되는 세 자료

1. **[Spec-Driven Development with Coding Agents](../../courses/deeplearning-ai/Spec-Driven%20Development%20with%20Coding%20Agents/)** (DeepLearning.AI · JetBrains · 15강)
   → 헌법(constitution) → 기능 루프(명세·구현·검증) → 재계획 → MVP → 레거시 → 워크플로 자동화. **개념 트랙이자 이 로드맵의 골격이다.**
2. **[Coding with AI](../../courses/udemy/Coding%20with%20AI/)** (Udemy · 10모듈 · DevStash 프로젝트)
   → 같은 워크플로를 **하나의 실제 앱을 처음부터 끝까지** 만들며 적용한다. **명세 파일·컨텍스트 문서·서브에이전트 정의가 저장소에 실물로 들어 있다.** 실전 트랙.
3. **[Matt Pocock Skills](../../courses/youtube/Matt%20Pocock%20Skills/)** (YouTube · 23편)
   → 스킬 설계, 코드베이스를 AI가 읽을 수 있게 만들기, 리뷰·디슬롭(de-slop), **그리고 「명세 대신 프로토타입」이라는 반대 주장까지.** 워크플로를 자기 것으로 만드는 트랙.

## 추천 진행 방식

- **주 5시간 기준 약 10주** 코스다. Phase 1이 끝나 있으므로 실제로는 Phase 2부터 시작한다.
- 강의 하나를 볼 때마다 `study` 스킬로 Q&A 학습을 하면 정리본이 자동 생성된다. (`.claude/skills/study/SKILL.md`)
- **Phase 2부터는 담당 프로젝트 하나를 정해 놓고 본다.** 「Coding with AI」의 DevStash를 그대로 따라 만들어도 되고, 회사/개인 프로젝트에 바로 적용해도 된다. **후자가 학습 효율이 훨씬 높지만, 막혔을 때 비교할 정답지가 없다.** 둘 다 하는 것이 가장 좋다 — DevStash를 정답지로 두고 자기 프로젝트에 적용한다.
- **명세를 쓰는 것 자체가 실습이다.** 강의를 다 보고 나서 쓰는 게 아니라, Phase 3에서 강의 한 편 볼 때마다 자기 명세를 한 문단씩 채운다.

## 주의 사항

- **각 Phase 문서의 체크리스트가 이 로드맵이 다루는 코스들의 진행 기록 원본이다.** 별도의 코스 단위 진행 기록 파일은 두지 않는다. SDD 코스 15강의 완료 기록(2026-07-28)은 [Phase 1](01%20Phase%201%20-%20SDD%20%EA%B0%9C%EB%85%90%EA%B3%BC%20%EC%9B%8C%ED%81%AC%ED%94%8C%EB%A1%9C.md)에 있다.
- 「Coding with AI」의 module 1~4는 코스 README에 **이미 아는 내용**으로 표시돼 있다. 이 로드맵도 module 5부터를 본체로 삼고, module 1~4는 [부록 11](11%20%EB%B6%80%EB%A1%9D%20-%20%EB%B0%98%EB%A1%A0%EA%B3%BC%20%ED%95%9C%EA%B3%84.md)에서 프로토타이핑 논의에만 쓴다.
- YouTube 자료는 발표 시점의 도구 버전에 묶인 내용이 많다. 스킬·설정 파일 형식은 바뀌었을 수 있으니 **원칙만 취하고 문법은 현재 도구 문서로 확인한다.**
